{#- The left navigation lists Home, the sections that lead to the page, the page's siblings, and its own entries. Listing every subject, field and topic beside the page made it the largest part of the site. Readers with JavaScript use the explorer's Contents pane instead, since the explorer hides this sidebar; the list serves readers without JavaScript and the layout the site falls back to. Material's classes are kept, so the sidebar and the drawer on narrow screens style it as before, and a page without entries of its own keeps its table of contents in the drawer, as in Material's navigation. -#} {%- macro href(item) -%} {%- if item.is_section -%} {#- A section opens its index page (navigation.indexes); a section without one is only a heading. -#} {%- for child in item.children if child.is_page and child.is_index -%} {%- if loop.first -%}{{ child.url | url }}{%- endif -%} {%- endfor -%} {%- else -%} {{- item.url | url -}} {%- endif -%} {%- endmacro -%} {%- macro entries(items, node, toc) -%} {%- for item in items -%} {%- set target = href(item) -%} {%- if item.is_section and not target -%} {{- entries(item.children, node, toc) -}} {%- elif item.parent and target == href(item.parent) -%} {#- The section's own index page: the section's entry already opens it. -#} {%- elif item == node and item.is_section -%}
  • {{ item.title }}
      {{ entries(item.children, node, toc) }}
    • {%- elif item == node -%}
  • {%- if toc -%} {%- endif -%} {{ item.title }}{{ toc }}
    • {%- else -%}
  • {{ item.title }}
    • {%- endif -%} {%- endfor -%} {%- endmacro -%} {#- The page's entry: its section when it is that section's index page. -#} {%- set node = page -%} {%- if page.parent and page.is_index and href(page.parent) == href(page) -%} {%- set node = page.parent -%} {%- endif -%} {%- set ancestors = node.ancestors | reverse | list -%} {#- The page's table of contents, which Material's drawer shows under the page's entry. -#} {%- set headings = page.toc -%} {%- set first = headings | first -%} {%- if first and first.level == 1 -%} {%- set headings = first.children -%} {%- endif -%} {%- set toc -%} {%- if headings and node == page -%}{% include "partials/toc.html" %}{%- endif -%} {%- endset -%}
      {#- Top-level entries, Home among them, are the page's siblings when it has no parent. -#} {%- if nav.homepage and node and node.parent -%}
    • {{ nav.homepage.title }}
      • {%- endif -%} {%- for section in ancestors if href(section) -%}
    • {{ section.title }}
        {%- endfor -%} {{- entries(node.parent.children if node.parent else nav.items, node, toc) -}} {%- for section in ancestors if href(section) -%}
