# Exterior, tensor and matrix interfaces

The added MathlibExt APIs give contraction, wedge and base-change operations on exterior powers; graded coalgebra and derivation operations on exterior algebras; and nonunital tensor constructions. Supporting matrix APIs cover coordinate insertion, stabilization, pivot reduction and elementary transformations, with the associated group and cocycle constructions.

These are the algebraic dependencies of the functional-analysis export. The contribution reuses the C-star, operator and linear foundations in the preceding components. Production imports stay within Mathlib and MathlibExt. The provenance records in `provenance/functional-analysis/linear-exterior-tensor/` identify the original and exported file contents, and the scoped declaration sync supplies their pages.
