# Mathlib-Derived Backports

This ledger records Mathlib-derived code temporarily maintained under
`MathlibExt/`. Each row records the exact upstream source revision, the local
adaptations, and the condition under which the backport may be removed.

## Policy

- Preserve the upstream copyright and Apache 2.0 notice. Retain the original
  authors block and source attribution in `NOTICE`, under the local module path.
- Add a `BACKPORT` banner after `module` that links to this document and
  identifies the immutable upstream commit.
- Record all import-path or other local adaptations in the table below.
- Remove a backport only after the project's pinned Mathlib commit contains
  the listed upstream file and declarations. Merely upgrading beyond the
  previous pin is not sufficient.

The compatibility entries below were compared with Lean 4.35.0 and Mathlib
`56a005855ea17e0b0958f73ec801ae140b0a1679` (`v4.35.0`). A supplied upstream
foundation is imported directly. A retained helper has its own namespace,
argument types and return type; a similarly named generic lemma is not treated
as a replacement without matching that complete interface. This source audit
does not claim a new compiler run.

## Related structural extension

`MathlibExt/AlgebraicTopology/ModelCategory/SemiModel/Transfer.lean` adapts the
geometric iteration in pinned
[`Mathlib/CategoryTheory/SmallObject/Basic.lean`](https://github.com/leanprover-community/mathlib4/blob/56a005855ea17e0b0958f73ec801ae140b0a1679/Mathlib/CategoryTheory/SmallObject/Basic.lean).
Its source-restricted right-lifting hypothesis and semi-model transfer scope
differ from the upstream full small-object argument. This is a structural
extension with its Mathlib attribution retained in `NOTICE`, rather than a
temporary compatibility backport removable upon a version upgrade.
