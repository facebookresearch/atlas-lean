# Hilbert-module and asymptotic operator APIs

The JSONL records identify original and contributed MathlibExt file contents by hash. They preserve mathematical code, source cases and attribution while recording header/documentation adaptation.

This group adds Hilbert C-star modules, adjointable and compact-operator interfaces, asymptotic morphisms, crossed products, operator-algebra weight/domain constructions and their reusable supporting APIs. It depends on the foundation contribution and imports only Mathlib and MathlibExt production modules. Source-organized textbook/paper modules and copied test libraries are excluded. Native build results are supplied by the PR checks.
