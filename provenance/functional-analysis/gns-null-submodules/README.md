# GNS null submodules

These modules identify the kernel of the GNS coefficient map of a positive complex-linear
functional, prove it closed in the original C*-algebra norm, and package it as a closed
complex submodule. The quadratic-null set is a closed left ideal.

`source-records.json` records the current source paths and hashes and contains both original
MathlibExt sources as exact UTF-8 text. Each `snapshot_path` names that committed container;
`snapshot_entry_path` selects the corresponding JSON string. Hash the decoded UTF-8 bytes to
verify `original_sha256`. The original Git blob identifiers and author notices are retained.
Source adaptations are listed separately for each module. The consumer has its own source hash.

The Lean toolchain is 4.36.0. The Mathlib repository and exact revision are recorded in the JSON.

For the GNS construction, see Gerard J. Murphy, *C*-Algebras and Operator Theory*, Chapter 3,
"Ideals and Positive Functionals". The publisher lists that chapter in its [contents][murphy],
and the [nLab GNS bibliography][gns] identifies its discussion of the construction.

[murphy]: https://shop.elsevier.com/books/c-algebras-and-operator-theory/murphy/978-0-12-511360-1

[gns]: https://ncatlab.org/nlab/print/Gelfand-Naimark-Segal+construction
