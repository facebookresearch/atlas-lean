# Finite-filtration bases and endomorphism invariants

Four MathlibExt modules assemble filtration bases, prove stage stability for
arbitrary graded index sets, and factor determinants and characteristic
polynomials. Determinant formulas retain finite graded indices; the intrinsic
stage condition gives determinant one. Four Atlas consumers cover empty and
proper finite flags, public simp values, and an infinite Finsupp shear.

source-originals.jsonl preserves four whole UTF-8 originals and author notices.
files.jsonl binds exact source hashes and archive rows, and records code changes.
