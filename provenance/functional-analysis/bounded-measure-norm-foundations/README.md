norm models and source credit. The first revision used pinned proof-name aliases
and one line reflow. N1/N2 expose arbitrary signed-measure variation finiteness,
remove its duplicated proof, and add pointwise bounded-function extensionality.
The continuous inclusion uses ofBound with its original norm bound; a whole-rfl
scope guard passed. Existing public types and complex homogeneity are preserved.

source-originals.jsonl retains the ten original library/71-line consumer sources
byte-for-byte. consumer-originals.jsonl separately retains the copied Dirac test
from source revision 0259e755, before removal of one redundant simp argument.
Both containers use literal JSON UTF-8 strings; each decoded original hash matches.
The other three added consumers are new Atlas tests with no upstream attribution.
They cover negative signed Dirac integration, empty-source reciprocal bounds and
endpoints, and bundled identity completion extensions with chosen dictionaries.

scope guard. Exact unchanged inputs were reused with transitive/facet checks;
