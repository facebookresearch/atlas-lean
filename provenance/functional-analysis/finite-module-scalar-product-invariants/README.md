# Scalar and product transport of finite-module invariants

Nine MathlibExt modules normalize chosen basis columns, clear lattice denominators,
transport determinant and characteristic polynomial through compatible scalar
actions and quotients, and compute invariants of dependent products and towers.
Five Atlas consumers use unequal ranks, empty blocks/products, a concrete quotient
modulo (2), compatible ULift scalar actions, and scalar 2 and zero column cases.

This contribution requires the finite-filtration characteristic-polynomial module
and its determinant-filtration provider from the finite-filtration contribution.
The source records and literal archives identify only this part's own files.

source-originals.jsonl preserves nine whole UTF-8 originals and author notices.
files.jsonl binds current source hashes and archive entries, and states actual
header, documentation and API adaptations. The dependent-product determinant
proof credits Mathlib's Determinant.lean, its copyright, Apache-2.0 license and authors.
