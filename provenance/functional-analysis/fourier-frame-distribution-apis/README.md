# Fourier frames and distribution scaling

These modules provide signed finite Fourier matrices, regular two-dimensional frames,
Pontryagin integral interfaces, and scalar pullbacks of smooth compactly supported test
functions. The consumers use nonzero matrix and frame data and cover negative and zero
scalars for test-function scaling.

`source-records.json` gives the current source paths, hashes, origins, adaptations, and project
imports. Each original MathlibExt source is stored as exact UTF-8 text in
`source-originals.jsonl`. The snapshot path, line number, and entry path select its string;
hash the decoded UTF-8 bytes to verify the recorded original SHA-256.

The signed Fourier matrices reuse the existing quantum Fourier matrix and its adjoint.
The entry formula retains every integer sign, and both signed unitary bundles include
zero dimension. The existing project dependency paths and hashes are recorded in the JSON.

The Lean toolchain is 4.36.0. The exact Mathlib repository and revision are recorded in the JSON.
