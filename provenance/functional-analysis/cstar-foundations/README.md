# C-star algebra foundation APIs

These records identify each contributed MathlibExt file before and after header and documentation adaptation. They record content hashes rather than relying on an external source repository. Original mathematical code, assumptions, norms and attribution are preserved.

The source group covers nonunital C-star and multiplier algebras, positive and completely positive maps, compact operators, tensor and completion foundations, and their reusable support. It introduces no source-organized textbook or paper modules.

Validation is recorded by the pull request checks. Source hashes and static import checks are provenance, not a claim of Lean compilation.

Lean 4.36 compatibility repairs retain the mathematical types, hypotheses, domains, norms, universes and attribution. Their file records distinguish import/notation and proof-expression adaptations from unchanged proof bytes. Native validation is reported by the pull-request checks.
