# Original MathlibExt sources

This snapshot contains only the 6 source files installed by this theme.
Each JSONL row preserves the literal original source and its SHA-256. The row bytes
are copied from the historical source dataset without changing source text. The
manifest lists the selected rows and the hash of their current archive chunk.
Run verify_snapshot.py to verify the manifest and original source bytes before
restoring into a fresh destination. Export adaptations are recorded in ../files.jsonl.
