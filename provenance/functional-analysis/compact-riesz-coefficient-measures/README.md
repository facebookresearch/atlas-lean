# Compact Riesz representations and CFC coefficients

These MathlibExt modules develop positive, signed-real and complex Riesz representation,
real functional Jordan decomposition, and scalar CFC coefficient measures of normal operators.

`files.jsonl` records current source hashes, original-source pointers, author notices and pins.
`source-originals.jsonl` stores five complete original UTF-8 bodies with standard JSON escaping.
Every original byte, author notice and SHA256 is retained; current hashes are recorded separately.

The source files are contributions to `facebookresearch/atlas-lean` in its MathlibExt library.
