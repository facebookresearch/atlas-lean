# Remaining residual-analysis source bindings

This aggregate retains 51 active MathlibExt exports after the five contour/grid/Riesz
and holomorphic-calculus sources transferred to their source-coherent split. Their
original and current bindings are preserved in transferred-exports.jsonl. The empty
grid consumer and 264 statement plus three module-navigation identities move with
the five sources; the nonempty scalar client is new to the destination slice.

The whole original dataset is retained as historical custody: its manifest and four
JSONL chunks preserve all 56 complete original source rows, author notices, source
revision, hashes and snapshot-file/line references. Archive size and active export
count describe different scopes. Every remaining active source/provenance row and
unrelated page/identity is unchanged.
