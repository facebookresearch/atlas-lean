# Completed Hilbert tensors and operator actions

The twelve MathlibExt modules cover completed tensor maps and comparison
isometries, tensor-product Hilbert bases, compact and rank-one tensor operators,
adjoint and operator-algebra laws, and algebraic tensor/Hom injectivity.
Six Atlas consumers check tensor actions and basis values, comparison maps on
finite-support and zero factors, and completed adjoints between distinct spaces.

files.jsonl records current source hashes, reviewed Atlas hashes and archive
bindings. source-originals.jsonl holds twelve literal UTF-8 archives: six original
MathlibExt sources and six earlier Atlas provider files. Every decoded string
retains its exact bytes, author notices and final newline. Atlas provider
snapshots match the recorded public repository revision.

Per-file adaptations identify stock completion-map reuse, four new pure-tensor
unitary value lemmas, mathematical prose corrections and proof simplifications.
The two new consumers are Atlas contributions with no upstream source attribution.
The reference pins are Lean 4.36.0 and Mathlib fc4f59e577feb1a4956671bc04ac18aaaf8cd842.
