# Current MathlibExt source-to-export bindings

The seven JSONL files bind the 332 MathlibExt source files still installed by this
aggregate to their original SHA-256, current exported SHA-256, original snapshot
row and export adaptations. Ten Fourier sources and their existing mathematical
pages are now published separately in PR #9643 at
c841f46ebcffdf16069ae2f28da18022107d1b78.

The original 348-file snapshot and historical ledgers remain byte-exact. Their
historical scope includes the sixteen transferred files. The transfer custody records
both the preceding aggregate exports and the destination exports, including the
whitespace-only RapidSequence source correction. Source text is preserved across
the destination and the historical archive.

These files record source and export provenance. Validation results remain in the
pull requests and their CI checks.

The six quadratic-form and Pfister sources are published in PR #11042 at
2a509dd817c853c7ff94fc6ffc866df7bc674829 as a source-only Lean contribution.
The 35 statement IDs, five navigation IDs and 42 corresponding graph-file
afterimages remain in private transfer custody. No graph identity is assigned
automatically in the new PR; a later graph batch needs an explicit mapping.
