# Operator, measure and linear-analysis source bindings

This aggregate retains 338 MathlibExt source files for operators, measures, normal
actions and reusable algebraic/topological interfaces. Its original 348-file source
snapshot remains an immutable historical dataset. The ten Fourier sources, 110
article IDs, eight navigation IDs and frequency-one consumer are published in
PR #9643 at c841f46ebcffdf16069ae2f28da18022107d1b78.

Historical ledgers and source snapshots retain their original hashes and source
text. The current-export records describe the installed 338 sources; transferred
export records identify the preceding and destination hashes. Further source-coherent
theme splits remain under preparation without dropping their mathematical content.
