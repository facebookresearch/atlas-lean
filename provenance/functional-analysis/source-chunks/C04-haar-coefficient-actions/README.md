# Haar integrated forms and coefficient actions

The five MathlibExt modules give the Haar-twisted star ring, integrated star homomorphisms,
coefficient multiplier actions and their seminorm-completion extensions.

`files.jsonl` records current source hashes, exact author credit, original-relative mathematical
adaptations and Lean/Mathlib pins. Its pointers resolve in `source-originals.jsonl`, which
stores five complete original UTF-8 source strings using standard JSON escaping.
The current sources preserve the original mathematical scopes, hypotheses, norms and credit.
