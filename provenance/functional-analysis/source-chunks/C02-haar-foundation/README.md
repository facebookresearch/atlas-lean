# Haar regular models and twisted convolution

Haar regular covariant models, coefficient faithfulness, twisted convolution and involution, the
L1 gauge, and integrated operators.

`files.jsonl` records each current MathlibExt source hash, author credit, mathematical
adaptations and Lean/Mathlib pins. Its original-source pointers resolve within
`source-originals.jsonl`, which stores 9 complete original UTF-8 source strings.
Every original byte, author notice and SHA256 is retained with standard JSON escaping.
The current sources are contributions to `facebookresearch/atlas-lean`; their archived
original library is MathlibExt. Current source changes are described separately from
the exact original bodies.

The Atlas consumer evaluates the constructed complex coefficient representation and
its operator norm, a nonreal scalar, the zero coefficient, and nonreal scaling of the
L1 gauge. It has no invented upstream original or snapshot.
