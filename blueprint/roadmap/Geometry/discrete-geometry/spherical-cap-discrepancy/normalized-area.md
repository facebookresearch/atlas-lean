# Normalized surface area on $S^2$

For a set $s \subseteq S^2$, the normalized area is

$$\alpha(s) = \frac{\sigma(s)}{\sigma(S^2)},$$

where $\sigma$ is the surface measure on $S^2$ induced by Lebesgue measure on $\mathbb{R}^3$ (the measure of $s$ is $3$ times the Lebesgue volume of the cone $\{r x : x \in s,\ 0 < r < 1\}$). Thus $\alpha(S^2) = 1$. The value is taken as a real number; for a non-measurable set $s$, $\sigma(s)$ is its outer measure.
