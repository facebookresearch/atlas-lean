# Erdős problem 214: unit squares in the complement

Conjecture (Erdős): let $S \subseteq \mathbb{R}^2$ be a set with no two points at distance exactly $1$. Then the complement of $S$ contains the four vertices of a unit square: there are points $a, b, c, d \notin S$ with

$$\langle b - a, d - a \rangle = 0, \qquad \lvert b - a \rvert = \lvert d - a \rvert = 1, \qquad c = b + (d - a).$$

The square may have any position and orientation. It holds; the resolution is [Erdős problem 214: the complement contains a unit square](unit-distance-avoiding-complement-has-un-2.md).
