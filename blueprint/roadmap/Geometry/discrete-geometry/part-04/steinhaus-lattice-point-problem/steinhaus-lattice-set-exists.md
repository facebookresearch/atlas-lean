# Erdős problem 215: Steinhaus' lattice point problem

Identify the plane with $\mathbb{C}$, so that a rotation followed by a translation is a map $w \mapsto u w + t$ with $u, t \in \mathbb{C}$ and $|u| = 1$, and the lattice $\mathbb{Z}^2$ is $\{a + b i : a, b \in \mathbb{Z}\}$.

Question (Steinhaus): there is a set $S \subseteq \mathbb{C}$ such that for all $u, t \in \mathbb{C}$ with $|u| = 1$, the set $\{u w + t : w \in S\}$ contains exactly one point of $\mathbb{Z}^2$. It holds; the resolution is [Erdős problem 215: a Steinhaus lattice set exists](steinhaus-lattice-set-exists-holds.md).
