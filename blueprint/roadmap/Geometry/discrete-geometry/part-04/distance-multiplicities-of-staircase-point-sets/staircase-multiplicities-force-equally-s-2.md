# Erdős problem 958: multiplicities $n-1, \dots, 1$ do not force equal spacing

This result refutes the proposition stated as [Erdős problem 958: distance multiplicities $n-1, \dots, 1$](staircase-multiplicities-force-equally-s.md). The conjecture is false: for every $N$ there is a finite set $A \subseteq \mathbb{R}^2$ with $n = |A| \ge N$ that determines exactly $n - 1$ distinct distances, whose multiplicities (numbers of unordered pairs of distinct points at that distance) are exactly $1, 2, \dots, n - 1$, and which is neither a set of equally spaced points $a, a + v, \dots, a + (n-1)v$ on a line ($v \ne 0$) nor a set of equally spaced points $c + r(\cos(\theta + i\alpha), \sin(\theta + i\alpha))$, $0 \le i < n$, along an arc of a circle ($r > 0$, $\alpha \ne 0$).
