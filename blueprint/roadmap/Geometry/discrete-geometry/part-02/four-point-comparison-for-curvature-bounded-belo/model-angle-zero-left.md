# Model Angle zero left

For curvature `0` and reals `a`, `b`, `c`, the model angle opposite `a` with adjacent sides `b` and `c` is given by the Euclidean cosine law: it equals `arccos((b² + c² - a²) / (2bc))`.

The formula holds for all reals, with no admissibility hypothesis. The cosine-law formula returns a real number for every input: division by zero gives $0$ (so when an adjacent side is $0$ the argument of $\arccos$ is $0$ and the angle is $\pi/2$), and the real $\arccos$ returns $\pi$ below $-1$ and $0$ above $1$.
