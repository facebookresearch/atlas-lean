# The Wigner–Seitz cell is a fundamental domain

Let $\Lambda$ be a Bravais lattice with basis matrix $B$ ($\det B \ne 0$), primitive vectors
$a_0, a_1, a_2$ (the columns of $B$) and lattice $L = \{Bn : n \in \mathbb{Z}^3\}$. The Wigner–Seitz
cell of $\Lambda$ is $\{x : \lVert x \rVert \le \lVert x - R\rVert \text{ for all } R \in L\}$. It
is a fundamental domain for the translations by vectors of $L$, for Lebesgue measure on
$\mathbb{R}^3$: it is measurable up to a null set, almost every point of $\mathbb{R}^3$ has a
translate by a vector of $L$ in the cell, and translates of the cell by distinct vectors of $L$
overlap only in sets of measure zero. Every point in fact has such a translate
([covering](../unit-cells-and-bravais-types/wigner-seitz-cell-cover.md)).
