# Points per conventional cell as a volume ratio

A Bravais lattice $\Lambda$ has a real $3 \times 3$ basis matrix $B$ with $\det B \ne 0$, primitive vectors the columns of $B$, and lattice $L(\Lambda) = \{Bn : n \in \mathbb{Z}^3\}$. For Bravais lattices $\Lambda_c, \Lambda_f$, the number of points per cell is the index of $L(\Lambda_c) \cap L(\Lambda_f)$ in $L(\Lambda_f)$, the cardinality of the quotient group (not the number of lattice points in a closed cell). If $L(\Lambda_c) \subseteq L(\Lambda_f)$, the number of points per cell is a natural number $k$ with $|\det B_c| = k\,|\det B_f|$ and $|\det B_c|/|\det B_f| = k$.
