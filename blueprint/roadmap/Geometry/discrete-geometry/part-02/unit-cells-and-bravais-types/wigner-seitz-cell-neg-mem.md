# The Wigner–Seitz cell is centrally symmetric

A Bravais lattice $\Lambda$ has a real $3 \times 3$ basis matrix $B$ with $\det B \ne 0$, primitive vectors the columns of $B$, and lattice $L(\Lambda) = \{Bn : n \in \mathbb{Z}^3\}$. Its Wigner–Seitz cell $W$ is the closed set $\{x : \lVert x\rVert \le \lVert x - R\rVert \text{ for all } R \in L(\Lambda)\}$. Then $-x \in W$ if and only if $x \in W$.
