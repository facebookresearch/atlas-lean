# A sublattice has an integer change-of-basis matrix

A Bravais lattice $\Lambda$ has a real $3 \times 3$ basis matrix $B$ with $\det B \ne 0$, primitive vectors the columns of $B$, and lattice $L(\Lambda) = \{Bn : n \in \mathbb{Z}^3\}$. If $L(\Lambda_c) \subseteq L(\Lambda_f)$ for Bravais lattices with basis matrices $B_c, B_f$, there is an integer matrix $M$ with $B_c = B_f M$.
