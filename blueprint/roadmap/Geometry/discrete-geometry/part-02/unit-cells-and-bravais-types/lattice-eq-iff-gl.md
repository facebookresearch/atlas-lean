# Two bases span the same lattice exactly when they differ by a unimodular matrix

A Bravais lattice $\Lambda$ has a real $3 \times 3$ basis matrix $B$ with $\det B \ne 0$, primitive vectors the columns of $B$, and lattice $L(\Lambda) = \{Bn : n \in \mathbb{Z}^3\}$. For Bravais lattices with basis matrices $B, B'$, $L(\Lambda) = L(\Lambda')$ if and only if $B' = BP$ for an integer matrix $P$ with $\det P = \pm 1$.
