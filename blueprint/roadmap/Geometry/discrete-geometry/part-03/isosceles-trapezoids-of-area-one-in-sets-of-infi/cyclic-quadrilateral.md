# Statement of Erdős problem 353: cyclic quadrilaterals of area one

A variant of Erdős Problem 353 asks for the following statement: for every Lebesgue measurable set $A \subseteq \mathbb{R}^2$ of infinite Lebesgue measure, there is a set $Q \subseteq A$ of exactly four points, all lying on one circle, whose convex hull has area $1$. It holds; the resolution is [Erdős problem 353: cyclic quadrilaterals of area one](cyclic-quadrilateral-holds.md).
