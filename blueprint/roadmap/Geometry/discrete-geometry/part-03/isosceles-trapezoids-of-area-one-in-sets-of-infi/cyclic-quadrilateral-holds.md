# Erdős problem 353: cyclic quadrilaterals of area one

This result proves the proposition stated as [Statement of Erdős problem 353: cyclic quadrilaterals of area one](cyclic-quadrilateral.md). Precisely, for every Lebesgue measurable set $A \subseteq \mathbb{R}^2$ of infinite Lebesgue measure, there is a set $Q \subseteq A$ of exactly four points, all lying on one circle, whose convex hull has area $1$.
