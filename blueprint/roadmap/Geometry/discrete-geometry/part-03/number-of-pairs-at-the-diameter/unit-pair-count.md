# Ordered unit-distance pairs of a finite point set

For a finite set $A \subset \mathbb{R}^d$, the unit pair count of $A$ is the number of ordered pairs $(x, y)$ of distinct points of $A$ with $\lVert x - y \rVert = 1$:

$$\#\{\, (x, y) \in A \times A : x \ne y,\ \lVert x - y \rVert = 1 \,\}.$$

It equals twice the number of unordered pairs $\{x, y\} \subseteq A$ at distance $1$.
