# Criterion for a length space

A pseudo-extended-metric space `X` is a length space if and only if
`inducedLengthEdist x y ≤ edist x y` for all `x, y ∈ X`.

Here `X` is a pseudo-extended-metric space, the length of a path is its
total variation (the supremum over finite monotone sequences of parameters
of the sums of extended distances between consecutive points), and the
induced length distance `inducedLengthEdist x y` is the infimum of the
lengths of all paths from `x` to `y`, equal to `∞` when no path exists.
