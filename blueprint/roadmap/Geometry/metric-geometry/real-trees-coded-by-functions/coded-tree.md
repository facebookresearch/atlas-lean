# The tree coded by a function

For a function $g \colon \mathbb{R} \to \mathbb{R}$, the coded tree is the real line carrying the
distance $d_g$ coded by $g$; for continuous $g$ this is a pseudometric, and its metric quotient
is the real tree $T_g$ coded by $g$ (Le Gall, *Random trees and applications*, Section 2.2).
