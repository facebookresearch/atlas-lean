# Minimum of a function between two times

For $g \colon \mathbb{R} \to \mathbb{R}$, the minimum of $g$ between $s$ and $t$ is
$m_g(s, t) = \inf g([s \wedge t, s \vee t])$. For continuous $g$ the infimum is attained (Le Gall,
*Random trees and applications*, Section 2.2); if $g$ is unbounded below on the interval, the
value is $0$ by convention.
