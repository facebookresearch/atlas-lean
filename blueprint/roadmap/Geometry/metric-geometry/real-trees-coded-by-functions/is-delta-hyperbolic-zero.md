# The tree coded by a continuous function is $0$-hyperbolic

For continuous $g$, the pseudometric space $(\mathbb{R}, d_g)$ satisfies Gromov's four-point
condition with constant $0$: $(x \mid z)_w \ge \min((x \mid y)_w, (y \mid z)_w)$ for all points, as
every real tree does. Le Gall, *Random trees and applications*, Theorem 2.2, shows that the
quotient $(T_g, d_g)$ is a real tree; $0$-hyperbolicity is the metric half of that statement.

## Informally uses

- [Four-point inequality for the minimum](tree-min-four-point.md): after expanding the Gromov
  products, the values of $g$ cancel and the hyperbolicity inequality with constant $0$ is the
  four-point inequality for $m_g$.
