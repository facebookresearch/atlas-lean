# Geodesic segment

A map $\gamma \colon \mathbb{R} \to X$ into a pseudometric space is a geodesic segment from $x$ to $y$ if
$\gamma(0) = x$, $\gamma(d(x, y)) = y$ and $d(\gamma(s), \gamma(t)) = |s - t|$ for all $s, t \in [0, d(x, y)]$: it is
an isometry from $[0, d(x, y)]$ onto its image (Gromov, *Hyperbolic groups*, 1987, §1.6).
