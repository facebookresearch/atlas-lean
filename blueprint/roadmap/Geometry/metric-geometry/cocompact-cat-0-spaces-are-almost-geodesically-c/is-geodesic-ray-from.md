# Geodesic rays

Let $(X, d)$ be a metric space, $a \in X$ and $\gamma : \mathbb{R} \to X$. Then $\gamma$ is a geodesic ray from $a$ when $\gamma(0) = a$ and $\gamma$ restricted to $[0, \infty)$ is an isometric embedding:

$$d(\gamma(s), \gamma(t)) = \lvert s - t \rvert \quad \text{for all } s, t \ge 0.$$
