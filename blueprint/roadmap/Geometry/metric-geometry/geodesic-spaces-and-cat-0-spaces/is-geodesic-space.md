# Geodesic metric spaces

A metric space $(X, d)$ is geodesic when any two points are joined by an isometric copy of a segment: for all $x, y \in X$ there is a map $\gamma : \mathbb{R} \to X$ with $\gamma(0) = x$, $\gamma(d(x, y)) = y$, and

$$d(\gamma(s), \gamma(t)) = \lvert s - t \rvert \quad \text{for all } s, t \in [0, d(x, y)].$$
