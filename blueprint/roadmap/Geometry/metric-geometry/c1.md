# L1 distortion of a metric space

For a set `X` and a function `ρ : X × X → ℝ`, the `L₁` distortion `c₁(X, ρ)`
is the infimum, in `ℝ ∪ {∞}`, of the real numbers `D ≥ 1` for which there is
a map `f : X → L¹(ℝ)` (integrable real functions on `ℝ` with Lebesgue
measure) such that `ρ(x, y) ≤ ‖f x - f y‖₁ ≤ D ρ(x, y)` for all `x, y ∈ X`
with `ρ(x, y) ≠ 0`. If no such `D` exists, `c₁(X, ρ) = ∞`.

The usual definition is for a metric space `(X, ρ)`; the definition makes
sense for any real function `ρ` on pairs.
