# Definition 12.5

Define a matrix $L_{x}$ by $L_{x} = G_{x}^{-1} H_{x} = (H_{x} G_{x}^{-1})^{\mathrm{tr}}$. We call this the shape operator. Equivalently, this is characterized by the property that $II_{x}(X, Y) = I_{x}(L_{x} X, Y)$.
