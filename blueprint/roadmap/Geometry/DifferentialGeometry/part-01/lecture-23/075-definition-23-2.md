# Definition 23.2

Given a set of Gauss normal vectors, we define the second fundamental forms $H^{w}$, $w = 1, \ldots, m$, by $H_{ij}^{w} = -\langle \partial_{i} \nu^{w}, \partial_{j} f \rangle = \langle \nu^{w}, \partial^{2} f / \partial x_{i} \partial x_{j} \rangle$. The corresponding shape operators are $L^{w} = G^{-1} H^{w}$.
