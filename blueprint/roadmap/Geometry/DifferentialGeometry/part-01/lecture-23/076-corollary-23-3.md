# Corollary 23.3

Take any Riemannian metric on $\mathbb{R}^{2}$ which is doubly-periodic, $G_{(x_{1}+T_{1}, x_{2})} = G_{(x_{1}, x_{2})} = G_{(x_{1}, x_{2}+T_{2})}$. Then $\kappa_{\text{gauss}}^{\text{tot}} = \int_{[0, T_{1}] \times [0, T_{2}]} \kappa_{\text{gauss}} \sqrt{\operatorname{det}(G)} \, dx_{1} \, dx_{2} = 0$.
