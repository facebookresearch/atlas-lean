# Theorem 28.2 (Inverse function theorem)

Let $\tilde{V} \subset \mathbb{R}^{n+1}$ be an open subset, $y \in \tilde{V}$ a point, and $\phi \colon \tilde{V} \rightarrow \mathbb{R}^{n+1}$ a smooth map such that $D\phi_{y}$ is invertible. Then there is an open subset $V \subset \tilde{V}$, still containing $y$, such that $U = \phi(V)$ is open, and $\phi|_{V} \colon V \rightarrow U$ is a diffeomorphism.
