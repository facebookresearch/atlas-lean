# Definition 16.1

Write $\frac{\partial^{2} f}{\partial x_{i} \partial x_{j}} = \sum_{k} \Gamma_{ij}^{k} \frac{\partial f}{\partial x_{k}} + H_{ij} \nu$. The functions $\Gamma_{ij}^{k}(x)$ are called Christoffel symbols.
