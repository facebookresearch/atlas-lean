# Definition 24.1

A hypersurface is a subset $M \subset \mathbb{R}^{n+1}$ with the following property. For every $y \in M$ there is an open subset $V \subset \mathbb{R}^{n+1}$ containing $y$, and a function $\psi \colon V \rightarrow \mathbb{R}$ whose zero set $\psi^{-1}(0)$ is precisely $M \cap V$, and whose derivative is nonzero at any point of $M \cap V$.
