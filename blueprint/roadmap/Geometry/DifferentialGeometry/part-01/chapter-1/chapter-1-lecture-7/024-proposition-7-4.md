# Proposition 7.4

Let $\|p\| = 1$ be a point on the circle with the following properties: (i) There are only finitely many $0 \leq t_{1} < t_{2} < \cdots < t_{m} < T$ for which $f(t_{k}) = p$; (ii) each such $t_{k}$ satisfies $f^{\prime}(t_{k}) \neq 0$. In that case, $\operatorname{deg}(f) = \sum_{k=1}^{m} \operatorname{sign} \operatorname{det}\left(p, f^{\prime}(t_{k})\right)$.
