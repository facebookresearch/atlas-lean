# Definition 40.3

Let $X$ be a geodesic metric space. $X$ is called nonpositively curved in the sense of Busemann (or a Busemann space) if it has the following property. Whenever $\gamma_{1}, \gamma_{2} \colon [0,l] \rightarrow X$ are metric geodesics starting at the same point $\gamma_{1}(l) = \gamma_{2}(l)$, then we have $d(\gamma_{1}(t), \gamma_{2}(t)) \leq (t/l)\, d(\gamma_{1}(l), \gamma_{2}(l))$.
