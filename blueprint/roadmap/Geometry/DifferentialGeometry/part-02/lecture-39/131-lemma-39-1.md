# Lemma 39.1

If $M$ is a connected hypersurface, then $(M, \operatorname{dist})$ is a metric space. By this we mean that it satisfies the following axioms: $\operatorname{dist}(p,q) \geq 0$, with equality if and only if $p = q$; $\operatorname{dist}(p,q) = \operatorname{dist}(q,p)$; $\operatorname{dist}(p,q) \leq \operatorname{dist}(p,r) + \operatorname{dist}(r,q)$.
