# Corollary 39.3

For any path $\gamma \colon [a,b] \rightarrow M$, we have $L(\gamma) \leq 2^{1/2}(b-a)^{1/2} E(\gamma)^{1/2}$, with equality if and only if $\gamma$ has constant speed.
