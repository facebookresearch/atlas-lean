# Definition 36.2

Let $M \subset \mathbb{R}^{n+1}$ be a hypersurface. A smooth map $\gamma \colon I \rightarrow M$, where $I \subset \mathbb{R}$ is an interval, is called a geodesic if $\gamma^{\prime\prime}(t)$ is perpendicular to $TM_{\gamma(t)}$ for all $t$.
