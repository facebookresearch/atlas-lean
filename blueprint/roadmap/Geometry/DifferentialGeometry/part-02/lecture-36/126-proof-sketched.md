# Corollary 36.6 (proof sketched)

Given any point $y \in M$ and any tangent vector $Y \in TM_{y}$, there is an interval $I \subset \mathbb{R}$ containing 0 and a geodesic $\gamma \colon I \rightarrow \mathbb{R}$ such that $\gamma(0) = y$, $\gamma^{\prime}(0) = Y$. If $M$ is a closed subset of $\mathbb{R}^{n+1}$, one can take $I = \mathbb{R}$, which means that geodesics are defined for all times.
