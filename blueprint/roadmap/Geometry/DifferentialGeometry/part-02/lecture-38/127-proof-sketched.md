# Theorem 38.1 (proof sketched)

A curve $\gamma \colon [a,b] \rightarrow M$ is a geodesic if and only if the following holds. For any smooth family of paths $(\gamma_{s})$, $-\epsilon < s < \epsilon$, with the same endpoints $\gamma_{s}(a) = p$, $\gamma_{s}(b) = q$ and with $\gamma_{0} = \gamma$, we have $\left.\frac{\partial}{\partial s} E(\gamma_{s})\right|_{s=0} = 0$.
