# Definition 34.3

Let $M \subset \mathbb{R}^{3}$ be a compact surface. A moving frame with singularities is given by a finite set of points $\{p_{1}, \ldots, p_{k}\}$ on $M$, together with maps $Y_{1}, Y_{2} \colon M \setminus \{p_{1}, \ldots, p_{k}\} \rightarrow \mathbb{R}^{3}$ which at each point $y$ form a positively oriented orthonormal basis of $TM$, and such that around each $p_{k}$ there is a partial parametrization in which $Y_{j} = Df(X_{j})$ for some frame with singularity of order $m(p_{i})$ at $p$.
