# Correctness of branch and bound and validity of Chvátal–Gomory cuts

(Branch and bound.) Let $P$ be a polyhedron and $B$ a finite box of integer points, and maximize $c^{\mathsf T}x$ over $P \cap B \cap \mathbb{Z}^n$. Splitting a node on a coordinate $j$ whose relaxation value $v_j$ is fractional into $x_j \le \lfloor v_j\rfloor$ and $x_j \ge \lceil v_j\rceil$ partitions the node's integer points. Consider a search that keeps a list of open nodes, starting from the root; removes a node and solves its relaxation; discards the node when the relaxation is infeasible or its value is at most the incumbent value; when the relaxation optimum is integral, updates the incumbent if it is better and discards the node; and otherwise splits it as above and adds both children. Each node carries integer bounds $l \le x \le u$ inside $B$ that are part of its relaxation, so a fractional value satisfies $l_j < v_j < u_j$; hence each child's integer box is strictly smaller than its parent's, and the search terminates because $B$ is finite. Since every discarded node contains no integer point better than the incumbent, at termination the incumbent is an optimal integer point, or there is none and the problem is infeasible. (Chvátal–Gomory cuts.) If $Ax \le b$ for $x \in P$, $u \ge 0$ and $u^{\mathsf T}A$ is integral, then every integer point of $P$ satisfies $u^{\mathsf T}Ax \le \lfloor u^{\mathsf T}b\rfloor$. No bound on the number of nodes or cuts is claimed.
