# Finitely many basic feasible points

Let $\iota$ be a finite index set, $E$ a real vector space, $L : \mathbb{R}^\iota \to E$ a linear map and $c \in E$. Then the set of points $z \in \mathbb{R}^\iota$ with $z \ge 0$ (componentwise), $L z = c$ and $z$ basic for $L$ (the only $d$ with $L d = 0$ and $d_i = 0$ wherever $z_i = 0$ is $d = 0$) is finite.
