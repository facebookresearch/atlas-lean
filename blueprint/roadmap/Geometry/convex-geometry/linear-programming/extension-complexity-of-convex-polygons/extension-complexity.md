# Extension complexity of a planar set (bounded linear lifts)

For a set $P \subseteq \mathbb{R}^2$, the extension complexity $\operatorname{xc}(P)$ is the least $r \in \mathbb{N}$ such that $P$ has an extended formulation of size $r$: there are $m$, $a_1, \dots, a_r \in \mathbb{R}^m$, $b_1, \dots, b_r \in \mathbb{R}$ and a linear map $\pi : \mathbb{R}^m \to \mathbb{R}^2$ with $Q = \{y : a_i \cdot y \le b_i \ \forall i\}$ bounded and $\pi(Q) = P$. If no such $r$ exists, $\operatorname{xc}(P) = 0$. This is extension complexity in the bounded, linear, inequality-only convention of [extended formulations](has-extended-formulation.md); for a convex polygon with nonempty interior it equals the usual extension complexity, the least number of facets of a polytope mapped affinely onto the polygon.
