# Circumradius of a set in $\mathbb{R}^n$

For a set $K \subseteq \mathbb{R}^n$, the circumradius is

$$R(K) = \inf\{\rho \in \mathbb{R} : K \subseteq \bar B(c, \rho) \text{ for some } c \in \mathbb{R}^n\},$$

where $\bar B(c, \rho)$ is the closed Euclidean ball of radius $\rho$ about $c$. The infimum is taken in $\mathbb{R}$, with the value $0$ when the set of radii is empty ($K$ unbounded) or unbounded below ($K = \emptyset$).
