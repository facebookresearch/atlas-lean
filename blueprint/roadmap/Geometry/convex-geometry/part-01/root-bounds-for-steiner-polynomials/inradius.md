# Inradius of a set in $\mathbb{R}^n$

For a set $K \subseteq \mathbb{R}^n$, the inradius is

$$r(K) = \sup\{\rho \in \mathbb{R} : \bar B(c, \rho) \subseteq K \text{ for some } c \in \mathbb{R}^n\},$$

where $\bar B(c, \rho)$ is the closed Euclidean ball of radius $\rho$ about $c$ (empty for $\rho < 0$). The supremum is taken in $\mathbb{R}$, with the value $0$ when the set of radii is unbounded above (for example $K = \mathbb{R}^n$).
