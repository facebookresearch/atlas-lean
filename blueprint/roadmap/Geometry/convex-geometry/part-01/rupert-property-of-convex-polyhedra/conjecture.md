# Rupert's property for convex polyhedra

Conjecture: every convex polyhedron in $\mathbb{R}^3$ has Rupert's property. Precisely, for every finite set $S \subseteq \mathbb{R}^3$ whose convex hull has nonempty interior, $\operatorname{conv} S$ has Rupert's property.

Here $\pi(x) = (x_1, x_2)$ is the projection of $\mathbb{R}^3$ onto the first two coordinates, and a set $P \subseteq \mathbb{R}^3$ has Rupert's property when there are rotations $Q_1, Q_2$ of $\mathbb{R}^3$ (linear isometries with determinant $1$) and $t \in \mathbb{R}^2$ with

$$\{\pi(Q_1 x) + t : x \in P\} \subseteq \operatorname{int} \{\pi(Q_2 x) : x \in P\}.$$

It is false; the refutation is [A convex polyhedron without Rupert's property](conjecture-refuted.md).
