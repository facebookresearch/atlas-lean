# Steiner polynomial of a set

A real polynomial $f$ is a Steiner polynomial of a set $K \subseteq \mathbb{R}^n$ if

$$f(\lambda) = \operatorname{vol}\bigl(K + \lambda B^n\bigr) \quad\text{for every real } \lambda \ge 0,$$

where $B^n$ is the closed Euclidean unit ball, $K + \lambda B^n$ is the Minkowski sum, and $\operatorname{vol}$ is Lebesgue measure, read as a real number (an infinite volume is read as $0$). For a convex body, Steiner's formula gives such a polynomial, and it is unique.
