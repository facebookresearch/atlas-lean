# Convex embedding of a surface in $\mathbb{R}^3$

A map $f : M \to \mathbb{R}^3$ is a convex embedding if $f$ is injective and there is a convex body $K \subseteq \mathbb{R}^3$, that is, a compact convex set with nonempty interior, such that

$$f(M) = \partial K,$$

the topological boundary of $K$.
