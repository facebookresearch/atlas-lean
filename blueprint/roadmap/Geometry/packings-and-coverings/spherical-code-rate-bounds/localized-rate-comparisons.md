# Strict comparisons of localized spherical code rates

For every $0<s<1$,

$$L_*^{\rm loc}(s)<L_1^{\rm loc}(s)<L_{\rm row}^{\rm loc}(s)<L_0^{\rm loc}(s)=L_{\rm clsl}^{\rm loc}(s).$$

The last comparison is equality with the classical localized rate, not a strict inequality.

- [Sidelnikov localization of spherical code bounds](sidelnikov-localized-rates.md)

## Proof depends on

## Expansion

Use strict improvement at the next level for the first inequality. Prove the row comparison inequalities and identify the level-zero objective under localization with the classical one, including the t=0 boundary.
