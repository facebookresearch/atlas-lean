# Spherical code rate bounded by the localized hierarchy

For every $0<s<1$, $R(s)\le L_*^{\rm loc}(s)$, the infimum over all localized interlacing levels.

## Depends on

- [Spherical code maximum and asymptotic rate](spherical-code-maximum-and-rate.md)

## Proof depends on

- [Eventual spherical code bound from a feasible interlacing](eventual-code-bound-from-a-feasible-interlacing.md)

## Expansion

Prove that the sphere-slice argument costs the stated logarithmic term and yields a bound at each level, then take the infimum over levels.
