# Three-coloring points against homothets of a convex set

Conjecture (Keszegh and Pálvölgyi, for arbitrary planar convex sets): for every convex set $D \subseteq \mathbb{R}^2$, with no boundedness, closedness, openness, nonempty-interior or general-position assumption, there is an integer $m \ge 1$, depending only on $D$, with the following property. For every finite set $S \subset \mathbb{R}^2$ there is a coloring $c : S \to \{0, 1, 2\}$ (not necessarily using all three colors) such that for every $a \in \mathbb{R}^2$ and every $r > 0$, if the homothet $a + rD$ contains at least $m$ points of $S$, then it contains two points $x, y \in S$ with $c(x) \ne c(y)$.

In other words, every finite point set can be $3$-colored so that no positive homothet of $D$ containing at least $m$ of its points is monochromatic. It is false; the refutation is [Three-coloring against convex homothets fails for disks](conjecture-refuted.md).
