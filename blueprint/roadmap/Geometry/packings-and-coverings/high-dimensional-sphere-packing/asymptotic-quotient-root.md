# Asymptotic infimum of rooted Cohn–Elkies quotients

For positive integer $d$ set $A_d=\inf_f Q(f)^{1/d}$ with the infimum over all admissible functions. Then $A_d/\sqrt d\to 1/\pi$. Equivalently, there is a real sequence $e_d\to0$ with $A_d=(1/\pi+e_d)\sqrt d$ for every $d>0$.

## Expansion

Prove the matching lower and upper asymptotics for the full admissible class using the unrestricted test-function comparison, controlling the real-power and infimum operations. Use the normalized difference to obtain the vanishing-error form.
