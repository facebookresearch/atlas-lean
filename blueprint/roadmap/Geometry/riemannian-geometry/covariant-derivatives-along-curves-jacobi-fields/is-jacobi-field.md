# Jacobi fields along a geodesic

Let $u$ be a curve in the tangent bundle of a finite-dimensional smooth Riemannian manifold, defined on all of $\mathbb{R}$, and $J$ a vector field along it, defined at every real time. Then $J$ is a Jacobi field along $u$ when $u$ is a geodesic velocity curve and $J$ satisfies the [Jacobi equation](satisfies-jacobi-equation.md) along it (Lee, Ch. 10; do Carmo, Ch. 5, Def. 2.1). The Jacobi equation by itself does not require the curve to be a geodesic; this definition adds that requirement.
