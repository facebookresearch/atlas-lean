# Injectivity Domain

For a Riemannian manifold `M` with exponential map `exp` and a point `x`, the injectivity domain `I(x)` is the set of tangent vectors `v ∈ T_x M` for which some `t > 1` satisfies `d(x, exp_x (t · v)) = ‖t · v‖`, where `d` is the Riemannian distance; that is, the geodesic `s ↦ exp_x (s · v)` still minimizes distance slightly beyond time `1`.
