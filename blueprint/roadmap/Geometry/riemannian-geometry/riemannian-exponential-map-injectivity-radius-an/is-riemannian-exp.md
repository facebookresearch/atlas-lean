# Is Riemannian Exp

Let `M` be a finite-dimensional smooth Riemannian manifold. A map `exp` assigning to each point `x` and tangent vector `v ∈ T_x M` a point of `M` is the Riemannian exponential map if for every `x` and `v` the curve `t ↦ exp_x (t · v)` is the geodesic with initial point `x` and initial velocity `v`, defined for all real `t`; in particular `exp_x v = γ_v(1)`. On a complete manifold without boundary exactly one such map exists; on an incomplete manifold or one with boundary there is none.
