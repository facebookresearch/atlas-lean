# Dirichlet Eigenvalue

For an open set `U` of a finite-dimensional smooth Riemannian manifold `M` and an index `k ≥ 0`, the `k`-th Dirichlet eigenvalue of `U` is the `k`-th variational (min-max) eigenvalue over the smooth functions with compact support in `U`, with respect to the Riemannian volume. For `k = 0`, an open set of a manifold without boundary and dimension at least `2`, this is the first Dirichlet eigenvalue `λ₁(U)`.
