# Dirichlet variational values of an open set

For an open set $U$ of a finite-dimensional smooth Riemannian manifold $M$ and an index $k \ge 0$, the $k$-th Dirichlet variational value of $U$ (zero-based) is the $k$-th [variational value](variational-eigenvalue.md) over the smooth functions with compact support in $U$, for the Riemannian volume. In general it is a min-max value only and need not be an eigenvalue: for $U = M = \mathbb{R}^2$, dilating a fixed bump drives the quotient to $0$, but no nonzero constant lies in $L^2(\mathbb{R}^2)$, so the bottom value $0$ is not an eigenvalue. For an open set of a manifold without boundary of dimension at least $2$, the value for $k = 0$ agrees with the first Dirichlet eigenvalue $\lambda_1(U)$ as defined by minimization over $H^1_0(U)$ (Lamboley–Sicbaldi, eq. (1)), which is a separate statement from its attainment.
