# Levi-Civita connection shifted by a cubic tensor

Let $g : \mathbb{R}^n \to \mathbb{R}^{n \times n}$ be a matrix-valued function with Christoffel symbols $\Gamma^k_{ij}$, let $g^{kl}(x)$ be the entries of $g(x)^{-1}$ (zero if $g(x)$ is singular), let $T_{ijl}(x)$ be a $(0,3)$-tensor field on $\mathbb{R}^n$ and let $s \in \mathbb{R}$. The shifted connection has coefficients

$$\Gamma^{(s)\,k}_{\ \ ij}(x) = \Gamma^k_{ij}(x) + \frac{s}{2} \sum_{l=1}^{n} g^{kl}(x)\, T_{ijl}(x).$$

The value $s = -1$ gives the connection $\nabla$ and $s = 1$ its $g$-dual $\nabla^*$.
