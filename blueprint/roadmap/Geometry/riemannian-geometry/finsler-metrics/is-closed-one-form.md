# Closed 1-forms as locally exact differentials

Let $M$ be a smooth surface. A function $\beta : TM \to \mathbb{R}$ on the tangent bundle is a closed $1$-form if it is locally the differential of a smooth function: for every $x \in M$ there are an open set $U \ni x$ and a function $f : M \to \mathbb{R}$ that is $C^\infty$ on $U$ such that

$$\beta(y, w) = df_y(w) \qquad \text{for all } y \in U,\ w \in T_yM.$$

By the Poincaré lemma, these are exactly the closed $1$-forms.
