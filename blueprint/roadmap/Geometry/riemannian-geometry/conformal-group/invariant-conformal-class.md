# Invariant Conformal Class

For a smooth Riemannian metric `g` on `M` and a set `G` of smooth self-diffeomorphisms of `M`, the `G`-invariant conformal class of `g` is the set of metrics `g'` conformal to `g` (that is, `g' = u · g` for a smooth positive function `u`) such that every `σ ∈ G` is an isometry of `g'`.
