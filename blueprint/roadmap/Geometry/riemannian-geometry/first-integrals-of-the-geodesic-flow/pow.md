# Pow

If a function $F$ on the tangent bundle of a finite-dimensional Riemannian manifold is a first integral of the geodesics, then so is its $n$-th power $p \mapsto F(p)^n$ for every natural number $n$.

Here a first integral of the geodesics is a function on the tangent bundle that is constant along every geodesic velocity curve defined on all of $\mathbb{R}$; local geodesics defined only on an interval are not tested. On a manifold whose local geodesics do not all extend (for instance the open interval $(0, 1)$, where every geodesic defined on all of $\mathbb{R}$ is constant), this is weaker than constancy along local geodesics.
