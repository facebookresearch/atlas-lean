# Rayleigh Quotient test Function

For an open set $\Omega$ of $\mathbb{R}^n$ and a smooth test function $f$ on $\Omega$, the Rayleigh quotient of $f$ on the manifold $\mathbb{R}^n$ with Lebesgue measure equals the Euclidean Rayleigh quotient $\int |\nabla f|^2 \,/\, \int f^2$, viewed in $[0, \infty]$ with the convention $0/0 = 0$. This includes the zero test function, for which both sides are $0$.
