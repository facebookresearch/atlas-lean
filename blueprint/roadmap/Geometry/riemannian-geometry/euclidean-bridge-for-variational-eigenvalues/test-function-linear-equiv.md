# Test functions as compactly supported smooth functions

For an open set $\Omega$ of a real normed space $E$ (no finite dimension is assumed), the real-linear equivalence identifies the two descriptions of the smooth real functions on $E$ with compact support contained in $\Omega$: bundled test functions on $\Omega$, and smooth functions on $E$, viewed as a manifold, with compact support in $\Omega$. The underlying function is unchanged in both directions.
