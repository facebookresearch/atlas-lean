# Sets with smooth boundary have local defining functions

Let $M$ be a manifold modelled on a boundaryless model. A set $\Omega \subseteq M$ with [smooth boundary](has-smooth-boundary.md) has a [local defining function](is-local-defining-function.md) at each frontier point. The boundaryless model matters: in the closed half-plane, $\rho(x, y) = -(x + y^2)$ cuts out the complement of the origin as $\{\rho < 0\}$ and has nonzero differential at the origin, yet the relative frontier is a single point, not a hypersurface.
