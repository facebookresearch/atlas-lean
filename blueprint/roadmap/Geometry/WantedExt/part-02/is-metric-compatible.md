# Metric Compatibility Shared

A covariant derivative `cov` is **compatible with the Riemannian metric**:
`v · ⟨Y, Z⟩ = ⟨∇_v Y, Z⟩ + ⟨Y, ∇_v Z⟩` for all smooth vector fields `Y, Z`
and every point/direction `(x, v)`.
