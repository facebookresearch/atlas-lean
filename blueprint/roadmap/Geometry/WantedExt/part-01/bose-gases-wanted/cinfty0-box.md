# CInfty0 Box

We define `C₀^∞(([0,L]³)ᴺ)\{0}` to be the set of functions `Ψ : (ℝ³)ᴺ → ℝ` such that
`Ψ` is smooth on `([0,L]³)ᴺ`, the support of `Ψ` is contained in
the interior of `([0,L]³)ᴺ`, and `Ψ ≠ 0`.
