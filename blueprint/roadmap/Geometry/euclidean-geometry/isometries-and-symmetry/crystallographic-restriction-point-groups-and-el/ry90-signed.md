# The quarter-turn about y is a signed permutation matrix

Let $R_y = \begin{pmatrix} 0 & 0 & 1 \\ 0 & 1 & 0 \\ -1 & 0 & 0 \end{pmatrix}$ be the quarter-turn about the $y$-axis. Then each row of $R_y$ has exactly one nonzero entry, equal to $\pm 1$, in distinct columns: $R_y$ is a signed permutation matrix.
