# A Voigt matrix with cubic and forty-five-degree invariance is isotropic

Voigt indices $0, \dots, 5$ encode the symmetric index pairs $xx, yy, zz, yz, xz, xy$. The axis swaps act on Voigt indices by the permutations $s_{xy} = (1, 0, 2, 4, 3, 5)$, $s_{xz} = (2, 1, 0, 5, 4, 3)$ and $s_{yz} = (0, 2, 1, 3, 5, 4)$, and the quarter-turn $R_z^{\mathsf T}$ about $z$ acts by the permutation $q = (1, 0, 2, 4, 3, 5)$ with signs $\varepsilon = (1, 1, 1, -1, 1, -1)$. A $6 \times 6$ matrix $C$ is invariant under them when $C_{ij} = C_{s(i)s(j)}$ for each swap $s$ and $C_{ij} = \varepsilon_i \varepsilon_j C_{q(i)q(j)}$. A $6 \times 6$ Voigt matrix $C$ encodes the rank-four tensor $c_{ijkl} = C_{v(i,j)\,v(k,l)}$, where $v$ maps the pairs $xx, yy, zz, yz, xz, xy$ to $0, \dots, 5$; a $3 \times 3$ matrix $R$ acts by $c'_{ijkl} = \sum R_{ia}R_{jb}R_{kc}R_{ld}\,c_{abcd}$, read back in Voigt form as $R \cdot C$. Let $R_{45}$ be the rotation by $45°$ about the $z$-axis, with rows $(\tfrac{\sqrt2}{2}, -\tfrac{\sqrt2}{2}, 0)$, $(\tfrac{\sqrt2}{2}, \tfrac{\sqrt2}{2}, 0)$, $(0, 0, 1)$. The isotropic (Lamé) Voigt matrix with constants $\lambda, \mu$ is the cubic Voigt matrix with $c_{11} = \lambda + 2\mu$, $c_{12} = \lambda$ and $c_{44} = \mu$. If $C$ is a real symmetric $6 \times 6$ matrix with these invariances and $R_{45} \cdot C = C$, then $C$ is the isotropic Voigt matrix of $(C_{01}, C_{33})$.
