# Isotropic stiffness is invariant under every orthogonal matrix

A $6 \times 6$ Voigt matrix $C$ encodes the rank-four tensor $c_{ijkl} = C_{v(i,j)\,v(k,l)}$, where $v$ maps the pairs $xx, yy, zz, yz, xz, xy$ to $0, \dots, 5$; a $3 \times 3$ matrix $R$ acts by $c'_{ijkl} = \sum R_{ia}R_{jb}R_{kc}R_{ld}\,c_{abcd}$, read back in Voigt form as $R \cdot C$. The isotropic (Lamé) Voigt matrix with constants $\lambda, \mu$ is the cubic Voigt matrix with $c_{11} = \lambda + 2\mu$, $c_{12} = \lambda$ and $c_{44} = \mu$. If $R^{\mathsf T}R = I$, then $R \cdot C = C$ for every isotropic Voigt matrix $C$.
