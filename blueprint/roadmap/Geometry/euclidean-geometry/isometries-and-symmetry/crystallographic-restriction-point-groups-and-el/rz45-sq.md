# The forty-five-degree rotation squares to the quarter-turn

Let $R_{45}$ be the rotation by $45°$ about the $z$-axis, with rows $(\tfrac{\sqrt2}{2}, -\tfrac{\sqrt2}{2}, 0)$, $(\tfrac{\sqrt2}{2}, \tfrac{\sqrt2}{2}, 0)$, $(0, 0, 1)$. Then $R_{45}^2$ is the quarter-turn about $z$ with rows $(0, -1, 0)$, $(1, 0, 0)$, $(0, 0, 1)$.
