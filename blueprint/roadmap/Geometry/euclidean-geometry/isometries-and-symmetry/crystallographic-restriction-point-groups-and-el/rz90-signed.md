# The quarter-turn about z is a signed permutation matrix

Let $R_z = \begin{pmatrix} 0 & -1 & 0 \\ 1 & 0 & 0 \\ 0 & 0 & 1 \end{pmatrix}$ be the quarter-turn about the $z$-axis. Then each row of $R_z$ has exactly one nonzero entry, equal to $\pm 1$, in distinct columns: $R_z$ is a signed permutation matrix.
