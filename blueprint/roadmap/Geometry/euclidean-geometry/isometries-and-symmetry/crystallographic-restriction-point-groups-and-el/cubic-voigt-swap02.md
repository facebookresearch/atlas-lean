# Cubic Voigt matrices are invariant under swapping x and z

For reals $c_{11}, c_{12}, c_{44}$, the cubic Voigt matrix has $c_{11}$ on the diagonal and $c_{12}$ off the diagonal of its upper-left $3 \times 3$ normal block, the shear block $c_{44} I_3$, and zero normal-shear couplings. Voigt indices $0, \dots, 5$ encode the symmetric index pairs $xx, yy, zz, yz, xz, xy$. Swapping the axes x and z permutes the Voigt indices by $s_{xz}$ as listed: $s_{xy} = (1, 0, 2, 4, 3, 5)$, $s_{xz} = (2, 1, 0, 5, 4, 3)$, $s_{yz} = (0, 2, 1, 3, 5, 4)$. Every cubic Voigt matrix $C$ satisfies $C_{ij} = C_{s_{xz}(i)s_{xz}(j)}$.
