# The quarter-turn about x is a signed permutation matrix

Let $R_x = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 0 & -1 \\ 0 & 1 & 0 \end{pmatrix}$ be the quarter-turn about the $x$-axis. Then each row of $R_x$ has exactly one nonzero entry, equal to $\pm 1$, in distinct columns: $R_x$ is a signed permutation matrix.
