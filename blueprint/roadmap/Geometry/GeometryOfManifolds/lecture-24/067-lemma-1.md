# Lemma 1 (Lecture 24, Section 2 (Seiberg-Witten Invariants))

We can represent complexified forms via $\gamma \colon \bigwedge^{*} \otimes \mathbb{C} \xrightarrow{\sim} \operatorname{End}(S^{+} \oplus S^{-})$. More specifically, we have decompositions $\bigwedge^{\text{even}} \otimes \mathbb{C} \cong \operatorname{End}(S^{+}) \oplus \operatorname{End}(S^{-})$, $\bigwedge^{\text{odd}} \otimes \mathbb{C} \cong \operatorname{Hom}(S^{+}, S^{-}) \oplus \operatorname{Hom}(S^{-}, S^{+})$, with $\gamma(\ast\alpha) = \gamma(\alpha)$ on $S^{+}$ and $-\gamma(\alpha)$ on $S^{-}$ for any $\alpha \in \bigwedge^{2}$, so $\operatorname{End}(S^{+}) = \mathbb{C} \oplus (\bigwedge_{+}^{2} \otimes \mathbb{C})$, $\operatorname{End}(S^{-}) = \mathbb{C} \oplus (\bigwedge_{-}^{2} \otimes \mathbb{C})$.
