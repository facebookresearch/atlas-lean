# The moment inequality $F_1 F_{2k-1} \le n^{1-1/k} F_k^2$

Let $x_1, \dots, x_n$ be nonnegative real numbers (indexed by a finite set of size $n$) and $k \ge 1$. Then

$$\Big(\sum_i x_i\Big) \Big(\sum_i x_i^{2k-1}\Big) \le n^{1 - 1/k} \Big(\sum_i x_i^k\Big)^2,$$

with $n^{1-1/k}$ the real power ($0^0 = 1$). This is the "Fact" in the proof of Theorem 2.1 of N. Alon, Y. Matias and M. Szegedy, *J. Comput. System Sci.* 58 (1999), stated there for positive reals, with the remark that $x_1 = n^{1/k}$, $x_2 = \dots = x_n = 1$ shows it is tight up to a constant factor. Applied to the multiplicities it reads $F_1 F_{2k-1} \le n^{1-1/k} F_k^2$.
