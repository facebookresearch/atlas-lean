# Types of the extended simply typed lambda calculus

Given a type $B$ of base types, the
types over $B$ are generated by six rules: every base type $b \in B$ is a type; for types $A$ and
$C$, the function type $A \Rightarrow C$ is a type; the unit type $\mathsf{unit}$ is a type; for
types $A$ and $C$, the product type $A \times C$ and the sum type $A + C$ are types; and the type
$\mathsf{bool}$ of booleans is a type.
