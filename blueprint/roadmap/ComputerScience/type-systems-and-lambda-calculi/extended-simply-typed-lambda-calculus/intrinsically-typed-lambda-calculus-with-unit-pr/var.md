# Typed de Bruijn variables of the extended simply typed lambda calculus

For a context
$\Gamma$ (a list of types) and a type $A$, the variables of type $A$ in $\Gamma$ are generated by
two rules: the variable $0$ is a variable of type $A$ in the context $A :: \Gamma$ obtained by
prepending $A$ to $\Gamma$, and if $x$ is a variable of type $A$ in $\Gamma$, then for every type
$B$ the successor of $x$ is a variable of type $A$ in $B :: \Gamma$.
