# Intrinsically typed terms of the extended simply typed lambda calculus

Let $A$, $B$ and
$C$ range over types and $\Gamma$ over contexts, and write $A :: \Gamma$ for the context obtained
by prepending $A$ to $\Gamma$. The terms of type $A$ in context $\Gamma$ are generated by
fourteen rules:

* every variable of type $A$ in $\Gamma$ is a term of type $A$;
* if $t$ is a term of type $B$ in $A :: \Gamma$, the abstraction $\lambda t$ is a term of type
  $A \Rightarrow B$; if $f$ has type $A \Rightarrow B$ and $a$ has type $A$, the application
  $f\,a$ has type $B$;
* $\langle\rangle$ is a term of type $\mathsf{unit}$;
* if $a$ has type $A$ and $b$ has type $B$, the pair $\langle a, b\rangle$ has type
  $A \times B$; if $p$ has type $A \times B$, the projections $\mathsf{fst}\,p$ and
  $\mathsf{snd}\,p$ have types $A$ and $B$;
* if $a$ has type $A$, the injection $\mathsf{inl}\,a$ has type $A + B$; if $b$ has type $B$,
  the injection $\mathsf{inr}\,b$ has type $A + B$; if $s$ has type $A + B$, $l$ has type $C$ in
  $A :: \Gamma$ and $r$ has type $C$ in $B :: \Gamma$, the case analysis
  $\mathsf{case}\,s\,l\,r$ has type $C$, binding the payload of the injection in each branch;
* $\mathsf{tt}$ and $\mathsf{ff}$ are terms of type $\mathsf{bool}$, and if $c$ has type
  $\mathsf{bool}$ and $t$ and $e$ have type $A$, the conditional $\mathsf{ite}\,c\,t\,e$ has
  type $A$;
* if $a$ has type $A$ and $b$ has type $B$ in $A :: \Gamma$, the definition
  $\mathsf{let}\,a\,b$ has type $B$, binding $a$ in $b$.

All terms are in context $\Gamma$ unless another context is named.
