# No closed System F term inhabits $\forall X, X$

No closed term $t \in \mathrm{Tm}_{0,0}$ has type $\forall \alpha_0$ in the empty context ([typing](../the-five-typing-rules-of-pure-system-f/typing.md)). Interpreting $\alpha_0$ by the [empty relation](../binary-beta-invariant-relations/empty.md) rules out every inhabitant.
