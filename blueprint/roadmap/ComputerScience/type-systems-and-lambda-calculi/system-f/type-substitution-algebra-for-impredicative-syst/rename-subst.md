# Renaming after a type substitution

For a type substitution $\sigma$ from $n$ to $k$ type variables, a renaming $\rho : \{0, \dots, k - 1\} \to \{0, \dots, l - 1\}$ and every type $A \in \mathrm{Ty}_n$, $A[\sigma]\langle\rho\rangle = A[\sigma']$ with $\sigma'(i) = \sigma(i)\langle\rho\rangle$: renaming after substitution renames each image ([renaming](../scoped-pure-system-f/rename.md), [substitution](../scoped-pure-system-f/subst.md)).
