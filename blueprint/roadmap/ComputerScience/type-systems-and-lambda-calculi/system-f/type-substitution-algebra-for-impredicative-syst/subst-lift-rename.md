# Lifted type substitution commutes with weakening

For a type substitution $\sigma$ from $n$ to $k$ type variables and every type $A \in \mathrm{Ty}_n$, $A\langle j \mapsto j + 1\rangle[\sigma^{\uparrow}] = A[\sigma]\langle j \mapsto j + 1\rangle$ ([lifted substitution](../scoped-pure-system-f/lift-sub.md)).
