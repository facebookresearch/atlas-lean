# Substitution after a type renaming

For a renaming $\rho : \{0, \dots, n - 1\} \to \{0, \dots, k - 1\}$, a type substitution $\sigma$ from $k$ to $l$ type variables and every type $A \in \mathrm{Ty}_n$, $A\langle\rho\rangle[\sigma] = A[\sigma \circ \rho]$ ([renaming](../scoped-pure-system-f/rename.md), [substitution](../scoped-pure-system-f/subst.md)).
