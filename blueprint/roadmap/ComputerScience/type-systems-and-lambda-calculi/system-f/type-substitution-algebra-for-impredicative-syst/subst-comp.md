# Successive type substitutions fuse into one substitution

For type substitutions $\sigma$ from $n$ to $k$ and $\tau$ from $k$ to $l$ type variables and every type $A \in \mathrm{Ty}_n$, $A[\sigma][\tau] = A[\sigma']$ with $\sigma'(i) = \sigma(i)[\tau]$ ([substitution](../scoped-pure-system-f/subst.md)).
