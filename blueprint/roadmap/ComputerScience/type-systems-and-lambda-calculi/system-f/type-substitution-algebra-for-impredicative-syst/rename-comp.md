# Successive type renamings fuse into their composition

For renamings $\rho : \{0, \dots, n - 1\} \to \{0, \dots, k - 1\}$, $\eta : \{0, \dots, k - 1\} \to \{0, \dots, l - 1\}$ and every type $A \in \mathrm{Ty}_n$, $A\langle\rho\rangle\langle\eta\rangle = A\langle\eta \circ \rho\rangle$ ([renaming](../scoped-pure-system-f/rename.md)).
