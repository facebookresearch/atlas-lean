# Variable-valued substitution is a type renaming

For a renaming $\rho : \{0, \dots, n - 1\} \to \{0, \dots, k - 1\}$ and every type $A \in \mathrm{Ty}_n$, the [substitution](../scoped-pure-system-f/subst.md) $i \mapsto \alpha_{\rho(i)}$ applied to $A$ gives the [renaming](../scoped-pure-system-f/rename.md) $A\langle\rho\rangle$.
