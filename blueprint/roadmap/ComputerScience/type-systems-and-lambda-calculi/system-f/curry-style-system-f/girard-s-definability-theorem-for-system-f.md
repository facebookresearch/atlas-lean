# Girard's definability theorem for System F

With the Church numerals $\underline{n} = \Lambda a.\, \lambda f{:}a \to a.\, \lambda x{:}a.\, f^n\, x$ of type $\mathrm{int} = \forall a.\, (a \to a) \to a \to a$, call a function
$f : \mathbb{N}^k \to \mathbb{N}$ *definable in System F* if a closed term $F : \mathrm{int} \to \cdots \to \mathrm{int} \to \mathrm{int}$ satisfies
$F\, \underline{m_1} \cdots \underline{m_k} =_\beta \underline{f(m_1, \dots, m_k)}$ for all arguments, where $=_\beta$ is the equivalence generated by term and type β-reduction. The functions definable in System F are exactly the functions provably
total in second-order Peano arithmetic.

Strong normalization of System F as a whole is not provable in second-order arithmetic, since it implies that theory's consistency. One direction instead
fixes the defining term $F$: its applications to numerals involve only finitely many types, and for those the reducibility argument can be carried out
in second-order arithmetic, which proves the totality of the defined function. The other direction extends Gödel's Dialectica interpretation to
second-order arithmetic and System F.
