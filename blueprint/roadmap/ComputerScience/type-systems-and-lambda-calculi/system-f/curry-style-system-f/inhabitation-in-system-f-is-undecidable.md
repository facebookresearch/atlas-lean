# Inhabitation in System F is undecidable

It is undecidable, given a System F type $\tau$, whether some closed term has type $\tau$. By the
[Curry–Howard correspondence](curry-howard-correspondence-for-second-order-logic.md) this is provability in the $\{\forall, \to\}$-fragment of second-order intuitionistic
propositional logic, which is undecidable (Löb, 1976).
