# Closing System F terms in the term model

For an environment $\sigma$ assigning a term $\sigma(i)$ of the [untyped term model](../the-existing-untyped-beta-conversion-term-model/model.md) to each $i < m$ and a System F term $t \in \mathrm{Tm}_{n,m}$, the closing $t\{\sigma\}$ is the [erasure](erase-with.md) $|t|_\sigma$, which is locally closed and hence a term of the model.
