# Relational interpretation of an instantiated System F type

For every type $B \in \mathrm{Ty}_{n+1}$, type $A \in \mathrm{Ty}_n$ and environment $\rho$ of β-invariant relations for $n$ type variables, $[\![B[A]]\!]_\rho = [\![B]\!]_{[\![A]\!]_\rho \cdot \rho}$: instantiating a universal type inserts the whole relation of the argument ([interpretation](interpret.md), [instantiation](../scoped-pure-system-f/instantiate.md)).
