# Relational interpretation of a weakened System F type

For every type $A \in \mathrm{Ty}_n$, environment $\rho$ of β-invariant relations for $n$ type variables and β-invariant relation $R$, $[\![A\langle j \mapsto j + 1\rangle]\!]_{R \cdot \rho} = [\![A]\!]_\rho$: a weakened type does not depend on the new relation ([interpretation](interpret.md)).
