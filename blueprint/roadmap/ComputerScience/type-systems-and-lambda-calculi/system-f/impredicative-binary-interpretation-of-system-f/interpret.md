# Binary logical relation of a System F type

For a [type](../scoped-pure-system-f/ty.md) $A \in \mathrm{Ty}_n$ and an environment $\rho$ assigning a [β-invariant relation](../binary-beta-invariant-relations/rel.md) $\rho(i)$ to each type variable $i < n$, the relation $[\![A]\!]_\rho$ is defined by $[\![\alpha_i]\!]_\rho = \rho(i)$, $[\![A \to B]\!]_\rho = [\![A]\!]_\rho \to [\![B]\!]_\rho$ (the [function-space relation](../binary-beta-invariant-relations/arrow.md)) and $[\![\forall B]\!]_\rho = \forall_R\, [\![B]\!]_{R \cdot \rho}$, the [universal quantification](../binary-beta-invariant-relations/universal.md) over all β-invariant relations $R$, where $R \cdot \rho$ sends $0$ to $R$ and $i + 1$ to $\rho(i)$. The quantification ranges over all relations, including those defined from the type being interpreted, so the interpretation is impredicative.
