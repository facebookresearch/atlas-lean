# Relational interpretation of a renamed System F type

For every renaming $\eta : \{0, \dots, n - 1\} \to \{0, \dots, k - 1\}$, type $A \in \mathrm{Ty}_n$ and environment $\rho$ of β-invariant relations for $k$ type variables, $[\![A\langle\eta\rangle]\!]_\rho = [\![A]\!]_{\rho \circ \eta}$ ([interpretation](interpret.md), [renaming](../scoped-pure-system-f/rename.md)).
