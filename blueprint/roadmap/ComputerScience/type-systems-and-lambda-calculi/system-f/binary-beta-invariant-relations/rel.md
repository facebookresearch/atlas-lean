# Beta-invariant binary relations on the term model

A β-invariant relation is a binary relation $R$ on the [untyped term model](../the-existing-untyped-beta-conversion-term-model/model.md) such that, whenever $f =_\beta f'$ and $g =_\beta g'$, $R(f, g)$ holds if and only if $R(f', g')$ holds: β-conversion may replace either argument independently.
