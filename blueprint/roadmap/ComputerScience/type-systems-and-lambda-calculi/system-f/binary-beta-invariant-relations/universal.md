# Universal quantification over a family of relations

For a family $(R_i)_{i \in I}$ of [β-invariant relations](rel.md), indexed by an arbitrary index collection $I$ (possibly larger than any set of terms, which makes the construction impredicative), the relation $\forall_i R_i$ relates $f$ and $g$ when $R_i(f, g)$ holds for every $i \in I$. It is β-invariant.
