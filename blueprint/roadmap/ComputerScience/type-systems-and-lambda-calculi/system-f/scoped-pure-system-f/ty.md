# Scoped types of pure System F

For a natural number $n$, the types $\mathrm{Ty}_n$ of pure System F over $n$ type variables are generated by: type variables $\alpha_i$ for $i < n$ (de Bruijn indices); arrow types $A \to B$ with $A, B \in \mathrm{Ty}_n$; and universal types $\forall B$ with $B \in \mathrm{Ty}_{n+1}$, which bind the index $0$ of $B$.
