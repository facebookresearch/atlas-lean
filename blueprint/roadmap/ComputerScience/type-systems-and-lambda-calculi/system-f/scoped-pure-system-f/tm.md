# Scoped terms of pure System F

For natural numbers $n$ and $m$, the terms $\mathrm{Tm}_{n,m}$ of pure System F with $n$ type variables and $m$ term variables are generated by: term variables $x_i$ for $i < m$; abstractions $\lambda A.\,b$ with a [type](ty.md) $A \in \mathrm{Ty}_n$ and $b \in \mathrm{Tm}_{n,m+1}$, binding the term index $0$; applications $f\,a$; type abstractions $\Lambda b$ with $b \in \mathrm{Tm}_{n+1,m}$, binding the type index $0$; and type applications $f\,[A]$ with $A \in \mathrm{Ty}_n$.
