# Lifting a scoped renaming under a binder

For a map $\rho : \{0, \dots, n - 1\} \to \{0, \dots, k - 1\}$ (a renaming of variables), its lifting $\rho^{\uparrow} : \{0, \dots, n\} \to \{0, \dots, k\}$ sends $0$ to $0$ and $i + 1$ to $\rho(i) + 1$: it keeps the newly bound variable and shifts the others.
