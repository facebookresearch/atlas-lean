# Extrinsic typing of pure System F terms

The typing judgement $\Gamma \vdash t : A$ of pure System F, for a [term context](../scoped-pure-system-f/ctx.md) $\Gamma$ with $m$ term variables over $n$ type variables, a [term](../scoped-pure-system-f/tm.md) $t \in \mathrm{Tm}_{n,m}$ and a [type](../scoped-pure-system-f/ty.md) $A \in \mathrm{Ty}_n$, is generated by five rules:

- $\Gamma \vdash x_i : \Gamma(i)$;
- if $A \cdot \Gamma \vdash b : B$, where $A \cdot \Gamma$ sends $0$ to $A$ and $i + 1$ to $\Gamma(i)$, then $\Gamma \vdash \lambda A.\,b : A \to B$;
- if $\Gamma \vdash f : A \to B$ and $\Gamma \vdash a : A$, then $\Gamma \vdash f\,a : B$;
- if $\Gamma^{\uparrow} \vdash b : C$, where $\Gamma^{\uparrow}(i)$ is $\Gamma(i)$ with type variables [renamed](../scoped-pure-system-f/rename.md) by $j \mapsto j + 1$, then $\Gamma \vdash \Lambda b : \forall C$;
- if $\Gamma \vdash f : \forall C$, then $\Gamma \vdash f\,[A] : C[A]$ ([instantiation](../scoped-pure-system-f/instantiate.md)).
