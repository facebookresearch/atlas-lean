# Subject reduction for full reduction in System F

Pure System F terms $\mathrm{Tm}_{n,m}$ have $n$ type variables and $m$ term variables, in scoped de Bruijn form: variables $x_i$ ($i < m$), abstractions $\lambda A.\,b$ with $A \in \mathrm{Ty}_n$ and $b \in \mathrm{Tm}_{n,m+1}$, applications $f\,a$, type abstractions $\Lambda b$ with $b \in \mathrm{Tm}_{n+1,m}$, and type applications $f\,[A]$ with $A \in \mathrm{Ty}_n$. For $b \in \mathrm{Tm}_{n,m+1}$ and $a \in \mathrm{Tm}_{n,m}$, $b[a]$ is the capture-avoiding instantiation of the newest term variable by $a$; for $b \in \mathrm{Tm}_{n+1,m}$ and $A \in \mathrm{Ty}_n$, $b[A]$ is the capture-avoiding type substitution sending type index $0$ to $A$ and $i+1$ to the type variable $\alpha_i$.

One step $t \leadsto t'$ of *full reduction* on $\mathrm{Tm}_{n,m}$ is generated by:

- $(\lambda A.\,b)\,a \leadsto b[a]$, for any argument $a$ (no value restriction);
- $(\Lambda b)\,[A] \leadsto b[A]$;
- if $b \leadsto b'$ then $\lambda A.\,b \leadsto \lambda A.\,b'$;
- if $f \leadsto f'$ then $f\,a \leadsto f'\,a$;
- if $a \leadsto a'$ then $f\,a \leadsto f\,a'$;
- if $b \leadsto b'$ then $\Lambda b \leadsto \Lambda b'$;
- if $f \leadsto f'$ then $f\,[A] \leadsto f'\,[A]$.

Redexes may thus be contracted at any position, including under term and type binders. The relation preserves both scopes $n$ and $m$.

Write $\Gamma \vdash t : A$ for the typing relation of pure System F (variable, abstraction, application, type abstraction and type application rules, with no subsumption or conversion rule), where a context $\Gamma$ assigns a type in $\mathrm{Ty}_n$ to each of the $m$ term variables.

For all $n, m$, every context $\Gamma$ over $n$ type variables and $m$ term variables, every type $A \in \mathrm{Ty}_n$ and all terms $t, t' \in \mathrm{Tm}_{n,m}$: if $\Gamma \vdash t : A$ and $t \leadsto t'$, then $\Gamma \vdash t' : A$. The context is arbitrary, so the result holds for open terms, and the type is preserved exactly.
