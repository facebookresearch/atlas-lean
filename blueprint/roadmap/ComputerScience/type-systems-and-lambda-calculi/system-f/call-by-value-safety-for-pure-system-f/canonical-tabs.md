# Canonical forms of universally typed values

Let $\Gamma$ be a term context, $t$ a term and $C$ a type with one more type variable. If $\Gamma \vdash t : \forall C$ ([typing](../the-five-typing-rules-of-pure-system-f/typing.md)) and $t$ is a [value](value.md), then $t = \Lambda b$ for some body $b$.
