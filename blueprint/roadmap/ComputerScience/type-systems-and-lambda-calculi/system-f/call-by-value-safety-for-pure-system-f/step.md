# One-step call-by-value evaluation

One step $t \to t'$ of weak, left-to-right call-by-value evaluation of pure System F [terms](../scoped-pure-system-f/tm.md) is generated by the rules:

- if $f \to f'$ then $f\,a \to f'\,a$;
- if $f$ is a [value](value.md) and $a \to a'$, then $f\,a \to f\,a'$;
- if $a$ is a value, then $(\lambda A.\,b)\,a \to b[a]$ ([instantiation](../scoped-pure-system-f/instantiate-2.md));
- if $f \to f'$ then $f\,[A] \to f'\,[A]$;
- $(\Lambda b)\,[A] \to b[A]$, the [type substitution](../scoped-pure-system-f/ty-subst.md) of $b$ sending $0$ to $A$ and $i + 1$ to $\alpha_i$.

No step takes place under a binder.
