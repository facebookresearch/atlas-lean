# Renaming a related environment and substitution

Let $\xi$ be a semantic environment for a context $\Gamma$ in a context $\Delta$ that is
[syntactically related](syntactically-related.md) to a substitution $\sigma$ from $\Gamma$ to
$\Delta$, and let $\rho$ be a renaming from $\Delta$ to a context $\Theta$. Then $\xi$ renamed
along $\rho$ is syntactically related to the substitution that sends each variable $x$ of
$\Gamma$ to the term $\sigma(x)$ renamed along $\rho$.
