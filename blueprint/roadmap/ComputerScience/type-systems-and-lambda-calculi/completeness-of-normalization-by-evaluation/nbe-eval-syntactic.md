# Fundamental theorem of the syntactic logical relation

Let $t$ be a term of type $A$ in a context $\Gamma$, let $\xi$ be a semantic environment for
$\Gamma$ in a context $\Delta$ and let $\sigma$ be a substitution from $\Gamma$ to $\Delta$. If
$\xi$ is [syntactically related](syntactically-related.md) to $\sigma$, then the evaluation of $t$
in $\xi$ is [syntactically related](syntactic-related.md) to the term $t$ with $\sigma$ applied.
