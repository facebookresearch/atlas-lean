# A logical semantic function sends logical arguments to logical values

Let $f$ be a [logical](logical.md) semantic value of type $A \Rightarrow B$ in a context
$\Gamma$, let $\rho$ be a renaming from $\Gamma$ to a context $\Delta$ and let $a$ be a logical
semantic value of type $A$ in $\Delta$. Then $f(\rho, a)$ is a logical semantic value of type $B$.
