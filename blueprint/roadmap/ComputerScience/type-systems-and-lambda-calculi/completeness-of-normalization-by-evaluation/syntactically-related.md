# Semantic environments related to substitutions

A semantic environment $\xi$ for a context $\Gamma$ in a context $\Delta$ is syntactically related
to a simultaneous substitution $\sigma$ from $\Gamma$ to $\Delta$, which sends every variable of
type $A$ in $\Gamma$ to a term of type $A$ in $\Delta$, when for every type $A$ and every variable
$x$ of type $A$ in $\Gamma$ the semantic value $\xi(x)$ is
[syntactically related](syntactic-related.md) to the term $\sigma(x)$.
