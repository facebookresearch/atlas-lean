# Renaming preserves logicality and relatedness

For every type $A$, every renaming $\rho$ from a context $\Gamma$ to a context $\Delta$, and all
Kripke semantic values $v$ and $w$ of type $A$ in $\Gamma$: if $v$ is [logical](logical.md), then
$v$ renamed along $\rho$ is logical; and if $v$ and $w$ are [related](related.md), then $v$ and $w$
renamed along $\rho$ are related.
