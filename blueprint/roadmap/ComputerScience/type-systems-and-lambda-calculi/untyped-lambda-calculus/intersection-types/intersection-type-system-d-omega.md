# The intersection type system DΩ

The *types* of system DΩ are built from type variables $X, Y, \dots$ and a constant $\Omega$ by the connectives $\to$ and $\wedge$. A *context* $\Gamma$ is a finite map
$x_1 : A_1, \dots, x_k : A_k$ from distinct term variables to types. The judgment $\Gamma \vdash_{D\Omega} t : A$, for an untyped λ-term $t$, is generated by:

1. $\Gamma, x : A \vdash x : A$;
2. if $\Gamma, x : A \vdash t : B$ then $\Gamma \vdash \lambda x.\, t : A \to B$;
3. if $\Gamma \vdash t : A \to B$ and $\Gamma \vdash u : A$ then $\Gamma \vdash t\, u : B$;
4. if $\Gamma \vdash t : A \wedge B$ then $\Gamma \vdash t : A$ and $\Gamma \vdash t : B$;
5. if $\Gamma \vdash t : A$ and $\Gamma \vdash t : B$ then $\Gamma \vdash t : A \wedge B$;
6. $\Gamma \vdash t : \Omega$ for every term $t$ and context $\Gamma$.

By rule 6 a term can be typed in a context that does not declare all its free variables. The *trivial* types are generated by: $\Omega$ is trivial;
$B \to A$ is trivial when $A$ is; $A \wedge B$ is trivial when $A$ and $B$ are. Positive and negative occurrences of $\Omega$ in a type are defined as usual,
the polarity flipping on the left of $\to$ and preserved through $\wedge$.
