# The intersection type system D

System D is [system DΩ](intersection-type-system-d-omega.md) without the constant $\Omega$: its types are built from type variables by $\to$ and $\wedge$, and its judgment
$\Gamma \vdash_D t : A$ is generated by rules 1–5 of DΩ (variable, abstraction, application, $\wedge$-elimination and $\wedge$-introduction), without rule 6. If
$x_1 : A_1, \dots, x_k : A_k \vdash_D t : A$ then every free variable of $t$ is among $x_1, \dots, x_k$. Typing in D is preserved by enlarging the context and by
restricting it to the free variables of the term.
