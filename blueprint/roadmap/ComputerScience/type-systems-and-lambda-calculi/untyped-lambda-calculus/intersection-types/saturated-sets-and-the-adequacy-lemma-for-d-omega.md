# Saturated sets and the adequacy lemma for DΩ

Let $\Lambda$ be the set of untyped λ-terms. For $X, Y \subseteq \Lambda$ let $X \to Y = \{u : u\, t \in Y \text{ for all } t \in X\}$. A set $X \subseteq \Lambda$ is *saturated* if
$(u[t/x])\, t_1 \cdots t_n \in X$ implies $(\lambda x.\, u)\, t\, t_1 \cdots t_n \in X$. Intersections of saturated sets are saturated, and $X \to Y$ is saturated whenever $Y$ is.

An *interpretation* $I$ assigns to each type variable a saturated set $|X|_I$, and extends to types of [system DΩ](intersection-type-system-d-omega.md) by $|\Omega| = \Lambda$,
$|B \to C| = |B| \to |C|$ and $|B \wedge C| = |B| \cap |C|$.

**Adequacy lemma.** If $x_1 : A_1, \dots, x_k : A_k \vdash_{D\Omega} u : A$ and $t_i \in |A_i|_I$ for each $i$, then $u[t_1/x_1, \dots, t_k/x_k] \in |A|_I$.

Moreover, if $N_0 \subseteq N$ are sets with $N$ saturated, $N_0 \subseteq \Lambda \to N_0$ and $N_0 \to N \subseteq N$, and $|X|_I = N$ for every type variable, then $|A|_I \supseteq N_0$
for every type and $|A|_I \subseteq N$ for every non-trivial type. A type is *trivial* if no type variable has a final occurrence in it; equivalently, the
trivial types are generated by: $\Omega$ is trivial, $B \to A$ is trivial if $A$ is, and $A \wedge B$ is trivial if $A$ and $B$ are (for example $A \to \Omega \wedge (B \to \Omega)$).
Every trivial type has value $\Lambda$ under every interpretation.
