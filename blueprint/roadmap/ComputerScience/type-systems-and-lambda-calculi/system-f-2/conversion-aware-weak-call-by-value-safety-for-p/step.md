# Weak call-by-value reduction of Fω

The weak call-by-value step relation $t \to t'$ on $\mathrm{Tm}_{\Delta,m}$ is generated by the
rules:

- $(\lambda A.\,b)\,a \to b[a]$ if $a$ is a [value](value.md)
  ([instantiation](../scoped-pure-f-terms/instantiate.md));
- $(\Lambda_\kappa b)\,[A] \to b[A]$ for $A \in \mathrm{Ty}^{\kappa}_{\Delta}$, the [type
  substitution](../scoped-pure-f-terms/ty-subst.md) of $A$ for $\alpha_0$;
- if $f \to f'$ then $f\,a \to f'\,a$;
- if $f$ is a value and $a \to a'$ then $f\,a \to f\,a'$;
- if $f \to f'$ then $f\,[A] \to f'\,[A]$.

There is no reduction under $\lambda$ or $\Lambda$.
