# Canonical forms for Fω values of function type

Let $\Gamma$ be a term context, $A, B \in \mathrm{Ty}^{\star}_{\Delta}$ and $t$ a [value](value.md)
with $\Gamma \vdash t : A \to B$
([typing](../pure-f-typing-with-proved-type-beta-conversion/typing.md)). Then $t = \lambda C.\,b$
for some type $C$ and body $b$.
