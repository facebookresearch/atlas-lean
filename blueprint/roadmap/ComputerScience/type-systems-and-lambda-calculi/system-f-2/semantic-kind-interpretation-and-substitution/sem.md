# Semantic interpretation of kinds

Let $X$ be a set (the carrier interpreting types of kind $\star$). The interpretation of
[kinds](../intrinsically-kinded-type-operators-for-pure-f/kind.md) over $X$ is defined by
$[\![\star]\!]_X = X$ and $[\![\kappa \Rightarrow \mu]\!]_X$ the set of all functions from
$[\![\kappa]\!]_X$ to $[\![\mu]\!]_X$.
