# Kind algebra of arrow and universal type constructors

Let $X$ be a set. A kind algebra on $X$ consists of a binary operation $\mathrm{arr} : X \times X
\to X$ and, for every kind $\kappa$, an operation $\mathrm{all}_\kappa$ sending each function
$[\![\kappa]\!]_X \to X$ to an element of $X$ ([interpretation of kinds](sem.md)). No laws are
required.
