# Composition of kind-preserving renamings

For [kind-preserving renamings](../intrinsically-kinded-type-operators-for-pure-f/kren.md) $\rho :
\Delta \to \mathrm{E}$ and $\tau : \mathrm{E} \to \mathrm{Z}$ and every [type
operator](../intrinsically-kinded-type-operators-for-pure-f/ty.md) $A \in
\mathrm{Ty}^{\kappa}_{\Delta}$, $A\langle\rho\rangle\langle\tau\rangle = A\langle\tau \circ
\rho\rangle$ ([renaming](../intrinsically-kinded-type-operators-for-pure-f/rename.md)).
