# Substitution of type operators depends only on variable images

Let $\sigma, \tau : \Delta \to \mathrm{E}$ be [kind-preserving
substitutions](../intrinsically-kinded-type-operators-for-pure-f/sub.md) with $\sigma(\alpha_i) =
\tau(\alpha_i)$ for every type variable $\alpha_i$ of $\Delta$. Then $A[\sigma] = A[\tau]$ for every
[type operator](../intrinsically-kinded-type-operators-for-pure-f/ty.md) $A \in
\mathrm{Ty}^{\kappa}_{\Delta}$
([substitution](../intrinsically-kinded-type-operators-for-pure-f/subst.md)).
