# Identity renaming fixes type operators

For every [type operator](../intrinsically-kinded-type-operators-for-pure-f/ty.md) $A \in
\mathrm{Ty}^{\kappa}_{\Delta}$, renaming by the identity renaming of $\Delta$ gives $A$:
$A\langle\mathrm{id}\rangle = A$
([renaming](../intrinsically-kinded-type-operators-for-pure-f/rename.md)).
