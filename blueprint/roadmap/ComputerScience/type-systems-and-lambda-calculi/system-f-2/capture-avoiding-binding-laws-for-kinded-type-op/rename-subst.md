# Renaming after substitution of type operators

For a [kind-preserving substitution](../intrinsically-kinded-type-operators-for-pure-f/sub.md)
$\sigma : \Delta \to \mathrm{E}$, a [kind-preserving
renaming](../intrinsically-kinded-type-operators-for-pure-f/kren.md) $\rho : \mathrm{E} \to
\mathrm{Z}$ and every [type operator](../intrinsically-kinded-type-operators-for-pure-f/ty.md) $A
\in \mathrm{Ty}^{\kappa}_{\Delta}$, $A[\sigma]\langle\rho\rangle = A[\sigma']$, where
$\sigma'(\alpha_i) = \sigma(\alpha_i)\langle\rho\rangle$.
