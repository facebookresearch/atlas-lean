# Renaming of type operators depends only on variable images

Let $\rho, \tau : \Delta \to \mathrm{E}$ be [kind-preserving
renamings](../intrinsically-kinded-type-operators-for-pure-f/kren.md) that agree on every type
variable of $\Delta$. Then $A\langle\rho\rangle = A\langle\tau\rangle$ for every [type
operator](../intrinsically-kinded-type-operators-for-pure-f/ty.md) $A \in
\mathrm{Ty}^{\kappa}_{\Delta}$
([renaming](../intrinsically-kinded-type-operators-for-pure-f/rename.md)).
