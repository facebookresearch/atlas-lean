# Composition of simultaneous type-operator substitutions

For [kind-preserving substitutions](../intrinsically-kinded-type-operators-for-pure-f/sub.md)
$\sigma : \Delta \to \mathrm{E}$ and $\tau : \mathrm{E} \to \mathrm{Z}$ and every [type
operator](../intrinsically-kinded-type-operators-for-pure-f/ty.md) $A \in
\mathrm{Ty}^{\kappa}_{\Delta}$, $A[\sigma][\tau] = A[\sigma']$, where $\sigma'(\alpha_i) =
\sigma(\alpha_i)[\tau]$.
