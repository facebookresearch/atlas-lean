# Identity substitution fixes type operators

For every [type operator](../intrinsically-kinded-type-operators-for-pure-f/ty.md) $A \in
\mathrm{Ty}^{\kappa}_{\Delta}$, substituting every variable by itself gives $A$: $A[\alpha_i \mapsto
\alpha_i] = A$ ([substitution](../intrinsically-kinded-type-operators-for-pure-f/subst.md)).
