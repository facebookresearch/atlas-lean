# Term translation commutes with term-variable renaming

For every map $\varphi$ from $\{0, \dots, n-1\}$ to $\mathrm{Ty}^{\star}_{\Delta}$, every map $\rho
: \{0, \dots, m-1\} \to \{0, \dots, k-1\}$ and every System F term $t \in \mathrm{Tm}_{n,m}$,
$\mathcal{T}_\varphi(t\langle\rho\rangle) = \mathcal{T}_\varphi(t)\langle\rho\rangle$ ([term
translation](from-system-f-2.md)).
