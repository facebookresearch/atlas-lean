# Type translation of a source renaming

For every map $\varphi$ from $\{0, \dots, k-1\}$ to $\mathrm{Ty}^{\star}_{\Delta}$, every renaming
$\rho : \{0, \dots, n-1\} \to \{0, \dots, k-1\}$ and every System F type $A \in \mathrm{Ty}_n$,
$\mathcal{T}_\varphi(A\langle\rho\rangle) = \mathcal{T}_{\varphi \circ \rho}(A)$
([translation](from-system-f.md), [System F
renaming](../../system-f/scoped-pure-system-f/rename.md)).
