# Term translation depends only on type-variable images

Let $\varphi$, $\psi$ assign types of kind $\star$ over $\Delta$ to $\{0, \dots, n-1\}$ with
$\varphi(i) = \psi(i)$ for every $i < n$. Then $\mathcal{T}_\varphi(t) = \mathcal{T}_\psi(t)$ for
every System F term $t \in \mathrm{Tm}_{n,m}$ ([term translation](from-system-f-2.md)).
