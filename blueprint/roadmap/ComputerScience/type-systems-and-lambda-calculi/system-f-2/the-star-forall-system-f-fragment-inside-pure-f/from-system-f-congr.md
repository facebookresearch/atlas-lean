# Type translation depends only on variable images

Let $\varphi$, $\psi$ assign types of kind $\star$ over $\Delta$ to $\{0, \dots, n-1\}$ with
$\varphi(i) = \psi(i)$ for every $i < n$. Then $\mathcal{T}_\varphi(A) = \mathcal{T}_\psi(A)$ for
every System F type $A \in \mathrm{Ty}_n$ ([translation](from-system-f.md)).
