# Term translation commutes with weakening under a type binder

For every map $\varphi$ from $\{0, \dots, n-1\}$ to $\mathrm{Ty}^{\star}_{\Delta}$ and every System
F term $t \in \mathrm{Tm}_{n,m}$, $\mathcal{T}_{\varphi^{\uparrow}}(t\langle\uparrow\rangle) =
\mathcal{T}_\varphi(t)\langle\uparrow\rangle$, where on the left $\uparrow$ is the successor
renaming of System F type variables ([type renaming in
terms](../../system-f/scoped-pure-system-f/ty-rename.md)) and on the right the successor renaming of
Fω type variables ([type renaming in Fω terms](../scoped-pure-f-terms/ty-rename.md)).
