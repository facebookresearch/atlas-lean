# Term translation preserves weak call-by-value values

For every map $\varphi$ from $\{0, \dots, n-1\}$ to $\mathrm{Ty}^{\star}_{\Delta}$ and every System
F term $t$ that is a [value](../../system-f/call-by-value-safety-for-pure-system-f/value.md),
$\mathcal{T}_\varphi(t)$ is an Fω
[value](../conversion-aware-weak-call-by-value-safety-for-p/value.md).
