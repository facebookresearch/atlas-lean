# Term translation of a source type substitution

For every map $\varphi$ from $\{0, \dots, k-1\}$ to $\mathrm{Ty}^{\star}_{\Delta}$, every System F
type substitution $\sigma$ from $n$ to $k$ type variables and every System F term $t \in
\mathrm{Tm}_{n,m}$, $\mathcal{T}_\varphi(t[\sigma]) = \mathcal{T}_{\varphi'}(t)$ with $\varphi'(i) =
\mathcal{T}_\varphi(\sigma(i))$ ([term translation](from-system-f-2.md), [System F type substitution
in terms](../../system-f/scoped-pure-system-f/ty-subst.md)).
