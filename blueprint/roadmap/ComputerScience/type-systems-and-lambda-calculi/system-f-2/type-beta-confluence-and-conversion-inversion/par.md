# Parallel type-beta reduction in Fω

Parallel type β-reduction $A \Rrightarrow B$ between [type
operators](../intrinsically-kinded-type-operators-for-pure-f/ty.md) of the same kind over the same
kinding context is generated by the rules: $\alpha_i \Rrightarrow \alpha_i$; if $B \Rrightarrow C$
then $\lambda B \Rrightarrow \lambda C$ and $\forall_\kappa B \Rrightarrow \forall_\kappa C$; if $F
\Rrightarrow G$ and $A \Rrightarrow B$ then $F\,A \Rrightarrow G\,B$; if $A \Rrightarrow A'$ and $B
\Rrightarrow B'$ then $A \to B \Rrightarrow A' \to B'$; and if $B \Rrightarrow C$ and $A
\Rrightarrow A'$ then $(\lambda B)\,A \Rrightarrow C[A']$
([instantiation](../intrinsically-kinded-type-operators-for-pure-f/instantiate.md)).
