# Type-beta conversion is joinability by a common reduct

For $A, B \in \mathrm{Ty}^{\kappa}_{\Delta}$: $A \equiv_\beta B$ if and only if there is $C$ with $A
\Rrightarrow^* C$ and $B \Rrightarrow^* C$ ([type
β-conversion](../proved-type-beta-conversion-for-pure-f/conv.md), [multistep reduction](red.md)).
