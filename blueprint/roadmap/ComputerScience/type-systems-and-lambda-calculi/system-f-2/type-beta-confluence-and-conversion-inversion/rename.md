# Parallel type-beta reduction is stable under renaming

If $A \Rrightarrow B$ for $A, B \in \mathrm{Ty}^{\kappa}_{\Delta}$ ([parallel type
β-reduction](par.md)) and $\rho : \Delta \to \mathrm{E}$ is a [kind-preserving
renaming](../intrinsically-kinded-type-operators-for-pure-f/kren.md), then $A\langle\rho\rangle
\Rrightarrow B\langle\rho\rangle$.
