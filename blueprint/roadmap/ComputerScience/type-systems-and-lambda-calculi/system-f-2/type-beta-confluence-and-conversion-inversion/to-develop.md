# Parallel reducts reduce to the complete development

For [type operators](../intrinsically-kinded-type-operators-for-pure-f/ty.md) $A$, $B$, if $A
\Rrightarrow B$ ([parallel type β-reduction](par.md)) then $B \Rrightarrow A^{\circ}$, where
$A^{\circ}$ is the [complete development](develop.md) of $A$.
