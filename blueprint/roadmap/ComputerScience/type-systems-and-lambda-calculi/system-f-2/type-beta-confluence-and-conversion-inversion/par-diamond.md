# Diamond property of parallel type-beta reduction

For every kinding context $\Delta$ and kind $\kappa$, parallel type β-reduction on
$\mathrm{Ty}^{\kappa}_{\Delta}$ has the diamond property: if $A \Rrightarrow B$ and $A \Rrightarrow
C$ then there is $D$ with $B \Rrightarrow D$ and $C \Rrightarrow D$ ([parallel type
β-reduction](par.md)).
