# Embedding preserves closings

For every environment $\sigma$ of model terms for $m$ term variables and every System F term $t \in
\mathrm{Tm}_{n,m}$, the [Fω closing](../f-closing-instances-in-the-single-existing-term/close.md) of
the [embedding](../the-star-forall-system-f-fragment-inside-pure-f/embed-2.md) $\mathcal{E}(t)$
under $\sigma$ equals the [System F
closing](../../system-f/system-f-erasure-and-closing-environments/close.md) $t\{\sigma\}$.
