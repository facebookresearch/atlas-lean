# Translated System F terms have the same closings

For every map $\varphi$ from $\{0, \dots, n-1\}$ to $\mathrm{Ty}^{\star}_{\Delta}$, every
environment $\sigma$ of terms of the [untyped term
model](../../system-f/the-existing-untyped-beta-conversion-term-model/model.md) for $m$ term
variables and every System F term $t \in \mathrm{Tm}_{n,m}$, the [Fω
closing](../f-closing-instances-in-the-single-existing-term/close.md) of the
[translation](../the-star-forall-system-f-fragment-inside-pure-f/from-system-f-2.md)
$\mathcal{T}_\varphi(t)$ under $\sigma$ equals the [System F
closing](../../system-f/system-f-erasure-and-closing-environments/close.md) $t\{\sigma\}$.
