# Typing rules of pure Fω

The typing judgement $\Gamma \vdash t : A$ of pure Fω, for a [term
context](../scoped-pure-f-terms/ctx.md) $\Gamma$ with $m$ term variables over a kinding context
$\Delta$, a [term](../scoped-pure-f-terms/tm.md) $t \in \mathrm{Tm}_{\Delta,m}$ and a
[type](../intrinsically-kinded-type-operators-for-pure-f/ty.md) $A \in
\mathrm{Ty}^{\star}_{\Delta}$, is generated by six rules:

- $\Gamma \vdash x_i : \Gamma(i)$;
- if $A \cdot \Gamma \vdash b : B$, where $A \cdot \Gamma$ sends $0$ to $A$ and $i + 1$ to
  $\Gamma(i)$, then $\Gamma \vdash \lambda A.\,b : A \to B$;
- if $\Gamma \vdash f : A \to B$ and $\Gamma \vdash a : A$, then $\Gamma \vdash f\,a : B$;
- if $\Gamma^{\uparrow} \vdash b : C$ with $b \in \mathrm{Tm}_{\kappa \cdot \Delta,m}$ and $C \in
  \mathrm{Ty}^{\star}_{\kappa \cdot \Delta}$, where $\Gamma^{\uparrow}(i)$ is $\Gamma(i)$
  [renamed](../intrinsically-kinded-type-operators-for-pure-f/rename.md) by the successor renaming,
  then $\Gamma \vdash \Lambda_\kappa b : \forall_\kappa C$;
- if $\Gamma \vdash f : \forall_\kappa C$ and $A \in \mathrm{Ty}^{\kappa}_{\Delta}$, then $\Gamma
  \vdash f\,[A] : C[A]$
  ([instantiation](../intrinsically-kinded-type-operators-for-pure-f/instantiate.md));
- if $\Gamma \vdash t : A$ and $A \equiv_\beta B$ ([type
  β-conversion](../proved-type-beta-conversion-for-pure-f/conv.md)), then $\Gamma \vdash t : B$.
