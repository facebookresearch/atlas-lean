# Type-beta conversion is stable under substitution

Let $A, B \in \mathrm{Ty}^{\kappa}_{\Delta}$ with $A \equiv_\beta B$ ([type β-conversion](conv.md))
and $\sigma : \Delta \to \mathrm{E}$ a [kind-preserving
substitution](../intrinsically-kinded-type-operators-for-pure-f/sub.md). Then $A[\sigma]
\equiv_\beta B[\sigma]$
([substitution](../intrinsically-kinded-type-operators-for-pure-f/subst.md)).
