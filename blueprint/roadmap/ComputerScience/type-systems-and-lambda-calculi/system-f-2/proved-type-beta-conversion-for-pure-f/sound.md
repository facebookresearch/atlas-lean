# Soundness of type-beta conversion in kind algebras

Let $A, B \in \mathrm{Ty}^{\kappa}_{\Delta}$ with $A \equiv_\beta B$ ([type β-conversion](conv.md)).
Then for every set $X$, every [kind
algebra](../semantic-kind-interpretation-and-substitution/kind-algebra.md) $M$ on $X$ and every
[semantic environment](../semantic-kind-interpretation-and-substitution/kenv.md) $\eta$ for
$\Delta$, $[\![A]\!]_\eta = [\![B]\!]_\eta$
([evaluation](../semantic-kind-interpretation-and-substitution/eval.md)).
