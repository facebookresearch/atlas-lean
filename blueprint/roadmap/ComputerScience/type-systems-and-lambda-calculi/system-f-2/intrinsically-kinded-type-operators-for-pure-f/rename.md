# Renaming of Fω type operators

For a [kind-preserving renaming](kren.md) $\rho : \Delta \to \mathrm{E}$, the renaming
$A\langle\rho\rangle \in \mathrm{Ty}^{\kappa}_{\mathrm{E}}$ of $A \in \mathrm{Ty}^{\kappa}_{\Delta}$
is defined by $\alpha_i\langle\rho\rangle = \rho(\alpha_i)$, $(\lambda B)\langle\rho\rangle =
\lambda(B\langle\rho^{\uparrow}\rangle)$, $(F\,A)\langle\rho\rangle =
F\langle\rho\rangle\,A\langle\rho\rangle$, $(A \to B)\langle\rho\rangle = A\langle\rho\rangle \to
B\langle\rho\rangle$ and $(\forall_\kappa B)\langle\rho\rangle =
\forall_\kappa(B\langle\rho^{\uparrow}\rangle)$, with the [lifted renaming](lift.md)
$\rho^{\uparrow}$ under both kinds of binder.
