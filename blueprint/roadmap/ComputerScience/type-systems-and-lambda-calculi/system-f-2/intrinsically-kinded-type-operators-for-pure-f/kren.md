# Kind-preserving renamings of type variables

For kinding contexts $\Delta$ and $\mathrm{E}$, a kind-preserving renaming $\rho : \Delta \to
\mathrm{E}$ assigns to every [type variable](kvar.md) of kind $\kappa$ in $\Delta$ a type variable
of the same kind $\kappa$ in $\mathrm{E}$, for every kind $\kappa$.
