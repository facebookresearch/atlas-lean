# Intrinsically kinded Fω type operators

For a kinding context $\Delta$ and a kind $\kappa$, the type operators
$\mathrm{Ty}^{\kappa}_{\Delta}$ of kind $\kappa$ over $\Delta$ are generated by the rules:

- every [type variable](kvar.md) $\alpha_i$ of kind $\kappa$ in $\Delta$ is in
  $\mathrm{Ty}^{\kappa}_{\Delta}$;
- if $B \in \mathrm{Ty}^{\mu}_{\kappa \cdot \Delta}$, then $\lambda B \in \mathrm{Ty}^{\kappa
  \Rightarrow \mu}_{\Delta}$ (operator abstraction, binding $\alpha_0$ of kind $\kappa$);
- if $F \in \mathrm{Ty}^{\kappa \Rightarrow \mu}_{\Delta}$ and $A \in
  \mathrm{Ty}^{\kappa}_{\Delta}$, then $F\,A \in \mathrm{Ty}^{\mu}_{\Delta}$;
- if $A, B \in \mathrm{Ty}^{\star}_{\Delta}$, then $A \to B \in \mathrm{Ty}^{\star}_{\Delta}$;
- if $B \in \mathrm{Ty}^{\star}_{\kappa \cdot \Delta}$, then $\forall_\kappa B \in
  \mathrm{Ty}^{\star}_{\Delta}$ (quantification over $\alpha_0$ of kind $\kappa$).

Every type operator thus carries its kind; there are no ill-kinded type operators.
