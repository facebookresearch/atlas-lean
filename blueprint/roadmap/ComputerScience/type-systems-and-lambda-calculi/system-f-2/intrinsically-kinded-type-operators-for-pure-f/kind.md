# Kinds of pure Fω

The kinds of pure System Fω are generated by $\kappa ::= \star \mid \kappa_1 \Rightarrow \kappa_2$:
the kind $\star$ classifies the types of terms, and $\kappa_1 \Rightarrow \kappa_2$ classifies type
operators taking an argument of kind $\kappa_1$ to a result of kind $\kappa_2$.
