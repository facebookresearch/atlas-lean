# Simultaneous substitution of Fω type operators

For a [kind-preserving substitution](sub.md) $\sigma : \Delta \to \mathrm{E}$, the substitution
$A[\sigma] \in \mathrm{Ty}^{\kappa}_{\mathrm{E}}$ of $A \in \mathrm{Ty}^{\kappa}_{\Delta}$ is
defined by $\alpha_i[\sigma] = \sigma(\alpha_i)$, $(\lambda B)[\sigma] =
\lambda(B[\sigma^{\uparrow}])$, $(F\,A)[\sigma] = F[\sigma]\,A[\sigma]$, $(A \to B)[\sigma] =
A[\sigma] \to B[\sigma]$ and $(\forall_\kappa B)[\sigma] = \forall_\kappa(B[\sigma^{\uparrow}])$,
with the [lifted substitution](lift-sub.md) under both kinds of binder; it avoids capture.
