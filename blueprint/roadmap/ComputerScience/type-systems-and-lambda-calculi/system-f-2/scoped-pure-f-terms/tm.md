# Scoped pure Fω terms

For a kinding context $\Delta$ and a natural number $m$, the terms $\mathrm{Tm}_{\Delta,m}$ of pure
Fω with type variables from $\Delta$ and $m$ term variables are generated by: term variables $x_i$
for $i < m$; abstractions $\lambda A.\,b$ with a
[type](../intrinsically-kinded-type-operators-for-pure-f/ty.md) $A \in \mathrm{Ty}^{\star}_{\Delta}$
and $b \in \mathrm{Tm}_{\Delta,m+1}$, binding the term index $0$; applications $f\,a$; type
abstractions $\Lambda_\kappa b$ with $b \in \mathrm{Tm}_{\kappa \cdot \Delta,m}$ for a kind
$\kappa$, binding a type variable of kind $\kappa$; and type applications $f\,[A]$ with a type
operator $A \in \mathrm{Ty}^{\kappa}_{\Delta}$ of any kind $\kappa$.
