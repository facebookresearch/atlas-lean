# Beta-eta conversion of simply typed terms

Work in the intrinsically typed simply typed lambda calculus over a type of base types, with de Bruijn variables: the terms of type $A$ in a context $\Gamma$ (a list of simple types) are the variables of type $A$, the applications $f\,a$ of a term $f$ of type $D \Rightarrow A$ to a term $a$ of type $D$, both in $\Gamma$, and, when $A = D \Rightarrow E$, the abstractions $\lambda t$ whose body $t$ is a term of type $E$ in $D :: \Gamma$, the context $\Gamma$ extended by a newest variable $0$ of type $D$.

For a term $t$ in $A :: \Gamma$ and a term $a$ of type $A$ in $\Gamma$, the instantiation $t[a]$ substitutes $a$ for the newest variable and replaces each older variable $x+1$ by $x$; for a term $f$ in $\Gamma$, the weakening $f^{\uparrow}$ is $f$ with every variable renamed to its successor.

Beta-eta conversion $t \simeq u$, between terms $t$ and $u$ of the same type in the same context, is the inductively defined relation generated by the following rules:

- reflexivity: $t \simeq t$;
- symmetry: $t \simeq u$ gives $u \simeq t$;
- transitivity: $t \simeq u$ and $u \simeq v$ give $t \simeq v$;
- application: for $f, g$ of type $A \Rightarrow B$ and $a, b$ of type $A$, $f \simeq g$ and $a \simeq b$ give $f\,a \simeq g\,b$;
- abstraction: for bodies $t, t'$ of type $B$ in $A :: \Gamma$, $t \simeq t'$ gives $\lambda t \simeq \lambda t'$;
- beta: $(\lambda t)\,a \simeq t[a]$ for every $t$ of type $B$ in $A :: \Gamma$ and $a$ of type $A$ in $\Gamma$;
- eta: $\lambda(f^{\uparrow}\,0) \simeq f$ for every $f$ of type $A \Rightarrow B$ in $\Gamma$.

Each derivation is a finite equational derivation built from these rules.
