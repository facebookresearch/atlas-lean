# Evaluating a single-variable substitution extends the semantic environment

Fix a type $B$ of base types. Simple types over $B$ are the base types and the arrows $A \Rightarrow C$; a context $\Gamma$ is a list of simple types, $A :: \Gamma$ extends it by a newest variable of type $A$, and $\mathrm{Tm}(\Gamma, A)$ is the type of intrinsically typed de Bruijn terms of type $A$ in $\Gamma$ (variables of type $A$, applications $f\,a$ with $f \in \mathrm{Tm}(\Gamma, D \Rightarrow A)$ and $a \in \mathrm{Tm}(\Gamma, D)$, and, when $A = D \Rightarrow E$, abstractions $\lambda t$ with body $t \in \mathrm{Tm}(D :: \Gamma, E)$).

Kripke semantic values $\mathrm{Sem}(\Delta, A)$ are defined by recursion on $A$: at a base type they are the neutral terms of that type in $\Delta$, and at $A \Rightarrow C$ they are families sending each renaming $\rho$ from $\Delta$ to a context $\Theta$ and each value in $\mathrm{Sem}(\Theta, A)$ to a value in $\mathrm{Sem}(\Theta, C)$. A semantic environment $\eta$ for $\Gamma$ in $\Delta$ assigns to each variable $x$ of $\Gamma$ of type $C$ a value $\eta(x) \in \mathrm{Sem}(\Delta, C)$, and $v \cdot \eta$ is the environment for $A :: \Gamma$ sending the newest variable to $v$ and each older variable $x$ to $\eta(x)$. Evaluation $[\![t]\!]\eta \in \mathrm{Sem}(\Delta, A)$ of $t \in \mathrm{Tm}(\Gamma, A)$ is $\eta(x)$ for a variable $x$, $[\![f]\!]\eta\,(\mathrm{id}, [\![a]\!]\eta)$ for $f\,a$, and for $\lambda t$ the family sending $(\rho, v)$ to $[\![t]\!](v \cdot \rho^{*}\eta)$, where $\rho^{*}\eta$ renames every value of $\eta$ along $\rho$.

Let $a \in \mathrm{Tm}(\Gamma, A)$ and let $\eta$ be a semantic environment for $\Gamma$ in $\Delta$. Evaluating, in $\eta$, the image of each variable under the single-variable substitution for $a$ (the newest variable to $a$, each older variable $x$ to the variable $x$) gives the extension of $\eta$ by the value of $a$: as semantic environments for $A :: \Gamma$ in $\Delta$,

$$ x \;\mapsto\; [\![\,\mathrm{single}(a)(x)\,]\!]\eta \quad=\quad [\![a]\!]\eta \cdot \eta. $$
