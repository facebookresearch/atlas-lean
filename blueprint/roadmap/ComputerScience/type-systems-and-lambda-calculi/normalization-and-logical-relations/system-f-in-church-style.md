# System F in Church style

This page presents System F in the Church-style notation of Girard, Lafont and Taylor, as used by the normalization pages in this folder; the formal definitions are the [scoped types](../system-f/scoped-pure-system-f/ty.md), [scoped terms](../system-f/scoped-pure-system-f/tm.md) and [five typing rules](../system-f/the-five-typing-rules-of-pure-system-f/README.md) of pure System F. Types are built from type variables $X, Y, Z, \dots$ by the arrow $U \to V$ and the universal quantifier $\Pi X.\, V$, and typed terms are formed by five schemes:

1. variables $x^T$ of type $T$;
2. application $t\,u$ of type $V$, where $t$ has type $U \to V$ and $u$ has type $U$;
3. $\lambda$-abstraction $\lambda x^U.\, v$ of type $U \to V$, where $v$ has type $V$;
4. universal abstraction $\Lambda X.\, v$ of type $\Pi X.\, V$, where $v$ has type $V$ and $X$ is not free in the type of a free variable of $v$;
5. universal application $t\,U$ of type $V[U/X]$, where $t$ has type $\Pi X.\, V$ and $U$ is a type.

Reduction is generated by the conversions $(\lambda x^U.\, v)\,u \rightsquigarrow v[u/x]$ and $(\Lambda X.\, v)\,U \rightsquigarrow v[U/X]$ applied anywhere in a term. What the normalization pages add to these definitions is full reduction under all term formers and the notion of a *neutral* term: one that does not start with an abstraction symbol, that is, one of the form $x$, $t\,u$ or $t\,U$.
