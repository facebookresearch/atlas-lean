# System F in Church style

The types of System F are built from type variables $X, Y, Z, \dots$ by the arrow $U \to V$ and the universal quantifier $\Pi X.\, V$. Its terms carry their types and are formed by five schemes:

1. variables $x^T$ of type $T$;
2. application $t\,u$ of type $V$, where $t$ has type $U \to V$ and $u$ has type $U$;
3. $\lambda$-abstraction $\lambda x^U.\, v$ of type $U \to V$, where $v$ has type $V$;
4. universal abstraction $\Lambda X.\, v$ of type $\Pi X.\, V$, where $v$ has type $V$ and $X$ is not free in the type of a free variable of $v$;
5. universal application $t\,U$ of type $V[U/X]$, where $t$ has type $\Pi X.\, V$ and $U$ is a type.

Reduction is generated by the conversions $(\lambda x^U.\, v)\,u \rightsquigarrow v[u/x]$ and $(\Lambda X.\, v)\,U \rightsquigarrow v[U/X]$ applied anywhere in a term. A term is *neutral* if it does not start with an abstraction symbol, that is, if it has the form $x$, $t\,u$ or $t\,U$.

## Sources

- J.-Y. Girard, Y. Lafont and P. Taylor, *Proofs and Types*, Cambridge University Press, 1989, Section 11.1 and Section 14.1.3 (neutral terms)
