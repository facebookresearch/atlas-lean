# Locally nameless typing contexts with natural-number names

For a type $B$ of base types, a locally nameless typing context with natural-number names is a finite list of pairs $(x, \tau)$ of a name $x \in \mathbb{N}$ and a locally nameless simple type $\tau$ over $B$ (built from base types and arrows $\sigma \rightsquigarrow  \tau$).
