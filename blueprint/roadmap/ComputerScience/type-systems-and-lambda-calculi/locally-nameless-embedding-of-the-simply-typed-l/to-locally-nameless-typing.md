# The canonical locally nameless embedding preserves typing

The embedding with names $\mathit{names}$ of an intrinsically typed term $t$ is $\mathrm{tr}_{0,\mathit{names}}$ applied to the erasure of $t$ (variables replaced by their de Bruijn positions in the context, lambdas keeping their parameter types); the canonical embedding $t^{\mathrm{LN}}$ uses $\mathit{names} = [0, 1, \dots, |\Gamma| - 1]$ for a term in context $\Gamma$. In the locally nameless typing of the simply typed lambda calculus, a free variable $\mathrm{fvar}\,x$ has type $\tau$ in a context when the context has pairwise distinct names and contains $(x, \tau)$; $\mathrm{app}\,t\,u$ has type $\tau$ when $t$ has type $\sigma \rightsquigarrow  \tau$ and $u$ has type $\sigma$; and $\mathrm{abs}\,t$ has type $\sigma \rightsquigarrow  \tau$ when, for all names $x$ outside some finite set, $\mathrm{open}'\,t\,(\mathrm{fvar}\,x)$ has type $\tau$ in the context extended at the front by $(x, \sigma)$.

For every context $\Gamma$, simple type $A$ and term $t$ of type $A$ in $\Gamma$ (open terms included), $t^{\mathrm{LN}}$ has type $A^{\mathrm{LN}}$ in the canonical locally nameless context, which pairs each name $j < |\Gamma|$ with $A_j^{\mathrm{LN}}$ for the entry $A_j$ of $\Gamma$ at position $j$; $A^{\mathrm{LN}}$ is the translation of simple types into the locally nameless simple types (base $b \mapsto$ base $b$, $A \Rightarrow C \mapsto A^{\mathrm{LN}} \rightsquigarrow  C^{\mathrm{LN}}$).
