# Canonical locally nameless context of a simply typed context

For a context $\Gamma$ (a list of simple types over base types $B$), the canonical locally nameless context pairs the names $0, 1, \dots, |\Gamma| - 1$ with the types of $\Gamma$ in order: it is the list of pairs $(j, A_j^{\mathrm{LN}})$ for $j < |\Gamma|$, where $A_j$ is the entry of $\Gamma$ at position $j$ and $A^{\mathrm{LN}}$ is the translation of simple types into the locally nameless simple types (base $b \mapsto$ base $b$, $A \Rightarrow C \mapsto A^{\mathrm{LN}} \rightsquigarrow  C^{\mathrm{LN}}$).
