# A term that reaches a value is strongly normalizing for call-by-value reduction

Consider call-by-value reduction $t \to u$ on intrinsically typed terms of the simply typed lambda calculus (left-to-right and weak: an application first reduces its function position, then its argument once the function is a value, and $(\lambda b)\,a$ contracts to the instantiation $b[a]$ only when $a$ is a value, a value being a lambda abstraction; no step goes under a binder). Let $t$ and $v$ be terms of type $A$ in any context $\Gamma$ (open terms allowed). If $t \to^* v$ in zero or more steps and $v$ is a value, then $t$ is strongly normalizing for call-by-value reduction (accessible for the converse relation: inductively, a term is strongly normalizing when every term it reduces to in one step is).
