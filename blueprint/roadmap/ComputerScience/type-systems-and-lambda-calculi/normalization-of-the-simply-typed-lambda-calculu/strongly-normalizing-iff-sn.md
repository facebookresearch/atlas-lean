# Call-by-value strong normalization is the generic strong normalization predicate

Consider call-by-value reduction $t \to u$ on intrinsically typed terms of the simply typed lambda calculus (left-to-right and weak: an application first reduces its function position, then its argument once the function is a value, and $(\lambda b)\,a$ contracts to the instantiation $b[a]$ only when $a$ is a value, a value being a lambda abstraction; no step goes under a binder). For every term $t$ of type $A$ in context $\Gamma$, $t$ is strongly normalizing for call-by-value reduction if and only if $t$ is strongly normalizing for the one-step relation $\to$ in the generic sense of a binary relation (accessible for the converse relation). The two predicates coincide by definition.
