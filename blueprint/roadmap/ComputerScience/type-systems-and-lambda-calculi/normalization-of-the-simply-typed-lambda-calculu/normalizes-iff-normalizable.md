# Normalization of closed terms is generic normalizability

Consider call-by-value reduction $t \to u$ on intrinsically typed terms of the simply typed lambda calculus (left-to-right and weak: an application first reduces its function position, then its argument once the function is a value, and $(\lambda b)\,a$ contracts to the instantiation $b[a]$ only when $a$ is a value, a value being a lambda abstraction; no step goes under a binder). For every term $t$ of type $A$ in the empty context, $t$ normalizes (there is a term $n$ with $t \to^* n$ in zero or more steps such that $n$ has no one-step reduct) if and only if $t$ is normalizable for the one-step relation $\to$ in the generic sense of a binary relation: there is $n$ with $t \to^* n$ in the reflexive transitive closure and $n$ normal, that is, there is no $y$ with $n \to y$.
