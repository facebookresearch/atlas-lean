# Evaluating a substitution

Fix a type $B$ of base types. Simple types over $B$ are base types and arrows $A \Rightarrow A'$. A context $\Gamma$ is a list of types; a variable of type $A$ in $\Gamma$ is a de Bruijn index into $\Gamma$ (index $0$ is the head of the list, the innermost binder), and $A :: \Gamma$ is $\Gamma$ extended by a new innermost variable $x_0$ of type $A$. Terms of type $A$ in $\Gamma$ are intrinsically typed: variables of type $A$, applications $f\,a$ of a term $f$ of type $D \Rightarrow A$ to a term $a$ of type $D$, both in $\Gamma$, and, when $A = D \Rightarrow E$, abstractions $\lambda t$ whose body $t$ has type $E$ in $D :: \Gamma$. A renaming $\rho : \Gamma \to \Delta$ sends each variable of $\Gamma$ to a variable of $\Delta$ of the same type, and a substitution $\sigma : \Gamma \to \Delta$ sends each variable of $\Gamma$ of type $A$ to a term of type $A$ in $\Delta$; $t[\rho]$ and $t[\sigma]$ denote their actions on a term $t$. For renamings $\rho : \Gamma \to \Delta$ and $\sigma : \Delta \to \Theta$, $\sigma \circ \rho : \Gamma \to \Theta$ is the renaming $\rho$ followed by $\sigma$, which sends each variable $x$ to $\sigma(\rho(x))$.

A Kripke semantic value of base type $b$ in $\Gamma$ is a neutral term of type $b$ in $\Gamma$; a value $f$ of type $A \Rightarrow A'$ in $\Gamma$ assigns to every context $\Delta$, renaming $\rho : \Gamma \to \Delta$ and value $a$ of type $A$ in $\Delta$ a value $f(\rho, a)$ of type $A'$ in $\Delta$. Renaming a value $v$ along $\rho : \Gamma \to \Delta$, written $v[\rho]$, renames the neutral term at a base type and sends $f$ to $(\sigma, a) \mapsto f(\sigma \circ \rho, a)$ at an arrow type. Reflection $\mathrm{reflect}_A$ turns a neutral term $n$ into a value ($n$ itself at a base type, $(\rho, a) \mapsto \mathrm{reflect}_{A'}(n[\rho]\;\mathrm{quote}_A(a))$ at $A \Rightarrow A'$), and reification $\mathrm{quote}_A$ turns a value into a normal form ($v$ itself at a base type, $\lambda\,\mathrm{quote}_{A'}(f(\uparrow, \mathrm{reflect}_A(x_0)))$ at $A \Rightarrow A'$, where $\uparrow$ is the successor renaming).

A semantic environment $\eta$ for $\Gamma$ in $\Delta$ assigns to each variable of $\Gamma$ of type $A$ a value of type $A$ in $\Delta$; $\eta[\rho]$ renames every value along $\rho : \Delta \to \Theta$, $a \cdot \eta$ extends $\eta$ by the value $a$ for a new innermost variable, and the identity environment $\mathrm{id}_\Gamma$ (for $\Gamma$ in $\Gamma$) sends each variable $x$ to $\mathrm{reflect}_A(x)$. Evaluation $[\![t]\!]\eta$ sends a variable $x$ to $\eta(x)$, an application $f\,a$ to $([\![f]\!]\eta)(\mathrm{id}, [\![a]\!]\eta)$, and an abstraction $\lambda t$ to $(\rho, a) \mapsto [\![t]\!](a \cdot \eta[\rho])$.

For a substitution $\sigma : \Gamma \to \Delta$ and a semantic environment $\eta$ for $\Delta$ in $\Theta$, the environment $[\![\sigma]\!]\eta$ for $\Gamma$ in $\Theta$ sends each variable $x$ of $\Gamma$ to $[\![\sigma(x)]\!]\eta$, the evaluation in $\eta$ of the term that $\sigma$ assigns to $x$.
