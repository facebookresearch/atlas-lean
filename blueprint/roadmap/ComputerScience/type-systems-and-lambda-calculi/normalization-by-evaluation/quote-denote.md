# Reification preserves denotations

Fix an interpretation $I$ of the base types. Let $\eta$ be an environment for a context $\Gamma$
in $I$, let $v$ be a Kripke semantic value of type $A$ in $\Gamma$ and let $d$ be an element of the
denotation of $A$. If $v$ realizes $d$ at $\eta$, then the denotation at $\eta$ of the term
underlying the reification of $v$ is $d$.
