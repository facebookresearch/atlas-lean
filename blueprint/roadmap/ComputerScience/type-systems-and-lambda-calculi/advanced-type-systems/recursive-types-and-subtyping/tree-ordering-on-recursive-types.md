# The tree ordering on recursive types

On μ-free types, subtyping $\le$ is generated by $\bot \le \alpha$, $\alpha \le \top$, $t \le t$ and: $\alpha' \le \alpha$ and $\beta \le \beta'$ imply $\alpha \to \beta \le \alpha' \to \beta'$; it is a partial order.
For [tree expansions](recursive-types-and-their-tree-expansions.md), call a path $\pi$ *positive* (negative) in a tree if it passes to the left child of a node labeled $\to$ an even
(odd) number of times. The *cut* $A|_k$ of a tree $A$ at level $k$ is the finite tree that agrees with $A$ on paths of length less than $k$, is undefined on longer
paths, and at a path $\pi$ of length $k$ in the domain of $A$ carries $\bot$ if $\pi$ is positive and $\top$ if $\pi$ is negative.

- Finite trees are ordered by $A \le_{\mathrm{fin}} B$ if the corresponding μ-free types satisfy $T^{-1}A \le T^{-1}B$.
- Arbitrary trees are ordered by $A \le_\infty B$ if $A|_k \le_{\mathrm{fin}} B|_k$ for every $k$; this is a partial order.
- Recursive types are ordered by the *tree ordering* $\alpha \le_T \beta$ if $T\alpha \le_\infty T\beta$; it is a preorder, and $\alpha|_k \le_T \alpha$ for every $k$.

For example $\mu t.\, \top \to t \le_T \mu t.\, \bot \to (\bot \to t)$, since $\top$ and $\bot$ occur only in negative positions. The inductively defined ordering on trees, the least
reflexive relation ($A \le A$ for every tree $A$) closed under $\bot \le A$, $A \le \top$ and the arrow rule, is strictly smaller than $\le_\infty$.
