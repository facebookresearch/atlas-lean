# Complete rules for equality of recursive types

Let $\alpha =_R \beta$ be derivable from reflexivity, symmetry, transitivity, congruence for $\to$ and $\mu$, the axioms $\mu t.\, t = \bot$ and
$[\mu t.\, \alpha / t]\alpha = \mu t.\, \alpha$ (fold–unfold), and the rule

$$\text{(contract)}\quad [\beta/t]\alpha = \beta,\ [\beta'/t]\alpha = \beta',\ \alpha \text{ contractive in } t \ \Longrightarrow\ \beta = \beta'.$$

Then $\alpha =_R \beta$ if and only if $T\alpha = T\beta$, where $T$ is the [tree expansion](recursive-types-and-their-tree-expansions.md). For example
$\mu t.\, s \to t =_R \mu t.\, s \to (s \to t)$, which the congruence generated by fold–unfold alone does not derive.
