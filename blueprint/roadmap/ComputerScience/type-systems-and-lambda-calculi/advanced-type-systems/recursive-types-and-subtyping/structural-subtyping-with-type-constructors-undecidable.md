# Structural subtyping with recursively defined type constructors is undecidable

Once recursive type definitions may take type parameters, structural subtyping over records becomes undecidable: subtyping between the types encoding two basic process algebra terms coincides with simulation between the processes.

**Types (DeYoung, Mordido, Pfenning and Das).** Types are in a normal form alternating between named and structural types. Named types are $\tau ::= t[\theta] \mid \alpha \mid x$, where $t$ is a defined type constructor, $\theta$ substitutes named types for its parameters $\alpha$, and $x$ is a quantified type variable. Structural types are products $\tau_1 \times \tau_2$, the unit $\mathbf{1}$, variant records $+\{\ell : \tau_\ell\}_{\ell \in L}$, records $\mathsf{N}\{\ell : \tau_\ell\}_{\ell \in L}$ ($L$ a finite set of labels), function types $\tau_1 \to \tau_2$ and quantified types $\exists x.\tau$, $\forall x.\tau$. A signature contains exactly one definition $t[\vec{\alpha}] \triangleq A$ per type constructor, with $A$ structural and closed apart from $\vec{\alpha}$; definitions may be recursive and are unfolded transparently. *Structural subtyping* $\tau \le \sigma$ is the coinductive (greatest fixed point) relation generated by the rules of Fig. 1 of the source: width and depth rules for records and variant records, covariant products, functions contravariant in the argument, unfolding of defined type constructors, each type variable below only itself, and rules for the quantifiers, with all types read coinductively.

**Theorem (DeYoung, Mordido, Pfenning and Das).** In the presence of record types and recursively defined type constructors, structural subtyping is undecidable: no algorithm decides, given a signature of definitions and two named types $\tau$, $\sigma$, whether $\tau \le \sigma$.

Records with no alternatives are not needed: undecidability holds when every record type has at least one alternative, and, by the same encoding with variant records in place of records, also with variant record types and no record types at all. This motivates the authors' replacement of structural subtyping by parametric subtyping, which is decidable.

## Expansion

The reduction is from simulation between processes of guarded basic process algebra (BPA), undecidable by Groote and Hüttel. For each guarded BPA equation in Greibach normal form $X \triangleq \sum_{\ell \in L} \ell \cdot p_\ell$, a type constructor $t_X[\alpha] \triangleq \mathsf{N}\{\ell : [p_\ell]\,(\alpha)\}_{\ell \in L} \mathbin{\mathsf{N}} \{\mathsf{end} : t_0\}$ is defined, with a fresh end-marker label $\mathsf{end}$, where $[\varepsilon]\,(\tau) = \tau$, $[X \cdot p]\,(\tau) = t_X[[p]\,(\tau)]$ and $t_0$ is a closed type such as $\mathsf{N}\{\mathsf{end} : t_0\}$. With $t = \mathsf{N}\{\mathsf{end} : t_0\}$, $p$ is simulated by $q$ if and only if $[q]\,(t) \le [p]\,(t)$: width subtyping lets $q$ match every transition of $p$, and depth subtyping makes the simulation hereditary.
