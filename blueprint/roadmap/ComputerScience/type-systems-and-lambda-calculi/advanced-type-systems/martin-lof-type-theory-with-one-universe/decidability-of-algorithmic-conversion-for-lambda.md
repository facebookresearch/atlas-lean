# Decidability of algorithmic conversion for λΠUN

Let $\vdash \Gamma = \Delta$ be context conversion, generated by $\vdash \epsilon = \epsilon$ and $\vdash \Gamma.A = \Delta.B$ if $\vdash \Gamma = \Delta$ and $\Gamma \vdash A = B$. For [the algorithmic conversion relations](algorithmic-conversion-for-lambda-pi-u-n.md) of λΠUN:

1. if $\Gamma \vdash t\, \hat\leftrightarrow\, t : A$ and $\Delta \vdash u\, \hat\leftrightarrow\, u : B$, it is decidable whether $\Gamma \vdash t\, \hat\leftrightarrow\, u : C$ for some $C$;
2. if $\Gamma \vdash A\, \hat\Leftrightarrow\, A$ and $\Delta \vdash B\, \hat\Leftrightarrow\, B$, it is decidable whether $\Gamma \vdash A\, \hat\Leftrightarrow\, B$;
3. if $\Gamma \vdash t\, \hat\Leftrightarrow\, t : A$ and $\Delta \vdash u\, \hat\Leftrightarrow\, u : A$, it is decidable whether $\Gamma \vdash t\, \hat\Leftrightarrow\, u : A$.

The hypotheses that each side is related to itself supply the termination measure.
