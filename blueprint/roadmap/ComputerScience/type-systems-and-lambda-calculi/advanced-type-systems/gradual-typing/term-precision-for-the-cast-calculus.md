# Term precision for the cast calculus

Precision on terms of the [cast calculus](cast-calculus-and-cast-insertion.md) is a relation $\Gamma, \Gamma' \vdash f \sqsubseteq f'$ between a term $f$ typed in $\Gamma$ and a term
$f'$ typed in $\Gamma'$, generated by the congruence rules of [term precision](precision-of-gradual-types-and-terms.md) together with:

- $(f : T_1 \Rightarrow^{\ell_1} T_2) \sqsubseteq (f' : T_1' \Rightarrow^{\ell_2} T_2')$ if $f \sqsubseteq f'$, $T_1 \sqsubseteq T_1'$ and $T_2 \sqsubseteq T_2'$;
- $\mathrm{blame}_T\, \ell \sqsubseteq f'$ if $\Gamma' \vdash f' : T'$ and $T \sqsubseteq T'$;
- (extra cast on the left) $(f : T_1 \Rightarrow^\ell T_2) \sqsubseteq f'$ if $f \sqsubseteq f'$, $\Gamma' \vdash f' : T'$, $T_1 \sqsubseteq T'$ and $T_2 \sqsubseteq T'$;
- (extra cast on the right) $f \sqsubseteq (f' : T_1' \Rightarrow^\ell T_2')$ if $f \sqsubseteq f'$, $\Gamma \vdash f : T$, $T \sqsubseteq T_1'$ and $T \sqsubseteq T_2'$.

Write $f \sqsubseteq f'$ for $\emptyset, \emptyset \vdash f \sqsubseteq f'$. The extra-cast rules let a less precise program carry casts that the more precise one lacks, and conversely.
