# The blame calculus and its subtyping relations

The blame calculus has types $S, T ::= B \mid S \to T \mid \mathrm{Dyn} \mid \{x : B \mid t\}$, with base types $B$, the dynamic type $\mathrm{Dyn}$ and subset (refinement)
types; a type is well formed when, in every subset type $\{x : B \mid t\}$, the predicate $t$ has type $\mathrm{Bool}$ assuming $x : B$, with no other free variables. Ground
types are $G ::= B \mid \mathrm{Dyn} \to \mathrm{Dyn}$. *Compatibility* $S \sim T$ is the least relation with $B \sim B$, $\mathrm{Dyn} \sim T$, $S \sim \mathrm{Dyn}$, $S \to T \sim S' \to T'$ when $S \sim S'$ and $T \sim T'$, and
$\{x : B \mid t\} \sim T$ and $T \sim \{x : B \mid t\}$ when $B \sim T$; it is reflexive and symmetric but not transitive. Terms include casts $\langle T \Leftarrow S \rangle^p\, s$ between compatible types $S \sim T$, where the blame
label $p$ has a complement $\bar p$ with $\bar{\bar p} = p$, and a failed cast reduces to blame $\Uparrow p$. Blaming $p$ (positive blame) means the term inside the cast
is at fault; blaming $\bar p$ (negative blame) means the context is. A cast between function types checks its argument with the labels swapped.

Four relations compare types:

- **Entailment** $x : T \Leftarrow S \models t$, for compatible $S \sim T$, holds if for all values $v$ of type $S$ and $w$ such that $\langle T \Leftarrow S \rangle^p\, v \longrightarrow^* w$,
  $t[x := w] \longrightarrow^* \mathrm{true}$.
- **Subtyping** $S <: T$ is generated by $B <: B$, $\mathrm{Dyn} <: \mathrm{Dyn}$; $S \to T <: S' \to T'$ if $S' <: S$ and $T <: T'$; $\{x : B \mid s\} <: T$ if $B <: T$;
  $S <: \{x : B \mid t\}$ if $S <: B$ and $x : B \Leftarrow S \models t$; and $S <: \mathrm{Dyn}$ if $S <: G$ for a ground type $G$. So the only subtypes of $\mathrm{Dyn}$ are
  $\mathrm{Dyn}$ and the subtypes of ground types.
- **Positive subtyping** $S <:^+ T$ and **negative subtyping** $S <:^- T$ are defined together by the same rules for base types, subset domains and functions,
  with the function rule swapping them in the domain ($S \to T <:^+ S' \to T'$ if $S' <:^- S$ and $T <:^+ T'$, and dually), and with $S <:^+ \mathrm{Dyn}$ and
  $\mathrm{Dyn} <:^- T$ for all $S$, $T$. Into a subset type, $S <:^+ \{x : B \mid t\}$ needs $S <:^+ B$ and $x : B \Leftarrow S \models t$, while $S <:^- \{x : B \mid t\}$ needs only
  $S <:^- B$; and $S <:^- T$ whenever $S <:^- G$ for a ground type $G$.
- **Naive subtyping** $S <:^n T$ has the same rules with the function rule covariant in both domain and range, $S <:^n \mathrm{Dyn}$ for every $S$, and
  $S <:^n \{x : B \mid t\}$ if $S <:^n B$ and $x : B \Leftarrow S \models t$; it relates a more precise type to a less precise one.

All four are reflexive and transitive; $S <: T$, $S <:^+ T$ and $S <:^n T$ each imply $S \sim T$, but $S <:^- T$ does not. For example
$\mathrm{Int} \to \mathrm{Nat} <: \mathrm{Nat} \to \mathrm{Int}$ and $\mathrm{Nat} \to \mathrm{Nat} <:^n \mathrm{Int} \to \mathrm{Int}$, with $\mathrm{Nat} = \{x : \mathrm{Int} \mid x \ge 0\}$.
