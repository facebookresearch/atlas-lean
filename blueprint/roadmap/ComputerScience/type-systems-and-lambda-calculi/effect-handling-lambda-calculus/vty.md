# Value types

For a type `Op` of operations, the value types are generated by the
grammar $A, B ::= \mathsf{unit} \mid \mathsf{bool} \mid A \to B \mathbin{!} \Delta \mid
A \mathbin{!} \Delta \Rightarrow B \mathbin{!} \Delta'$ with $\Delta, \Delta'$ finite sets of
operations: the unit type, booleans, functions whose bodies have computation type
$B \mathbin{!} \Delta$, and handlers from computations of type $A \mathbin{!} \Delta$ to
computations of type $B \mathbin{!} \Delta'$ (Pretnar 2015, Fig. 5, with `unit` added).
