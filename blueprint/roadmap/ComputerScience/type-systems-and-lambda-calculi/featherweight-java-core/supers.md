# Superclass chain

For any class table and class name `C`, the superclass chain starts at `C` and follows declared superclasses for at most `ct.length + 1` names. It stops at `Object`, which ends the chain, at a class with no declaration in the table, which is the last entry, or when that fuel bound is reached. It need not reach `Object`: for a table containing only `C extends D`, with `C` and `D` distinct from `Object` and `D` undeclared, it is `[C, D]`. For a declared starting class in a well-formed table, whose superclass chains have no repetition and whose references are declared, it ends at `Object`.
