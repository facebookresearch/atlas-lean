# Featherweight Java expressions

Featherweight Java expressions are built by five constructors: a variable $x$; a field selection $e.f$ with receiver $e$ and field name $f$; a method invocation $e.m(\bar a)$ with receiver $e$, method name $m$ and [argument list](args.md) $\bar a$; an object construction $\mathtt{new}\ C(\bar a)$ with class name $C$ and argument list $\bar a$; and a cast $(C)\,e$ with class name $C$ and expression $e$.
