# Strong normalization of System T

Every well-typed term of Gödel's System T is strongly normalizing, by Tait's reducibility method. Consequently, since closed normal terms of type $\mathrm{nat}$ are numerals, every closed term of type $\mathrm{nat} \to \mathrm{nat}$ defines a total computable function on the natural numbers.
