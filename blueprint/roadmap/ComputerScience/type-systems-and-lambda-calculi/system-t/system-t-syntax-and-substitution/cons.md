# Extending a substitution by a term

Given a substitution $\sigma$ from $\Gamma$ to
$\Delta$ and a term $a$ of type $A$ in $\Delta$, the extension goes from $\Gamma$ extended by a
newest variable of type $A$ to $\Delta$: it sends the newest variable to $a$ and every older
variable $x$ to $\sigma(x)$.
