# System T terms

Write $\mathsf{nat}$ for the type of natural numbers and $A \Rightarrow B$
for the type of functions from $A$ to $B$. The intrinsically typed terms of type $A$ in a
context $\Gamma$ (a list of types) are generated by the following rules: every variable of type
$A$ in $\Gamma$ is a term of type $A$; if $t$ has type $B$ in the context $\Gamma$ extended by a
newest variable of type $A$, then $\lambda t$ has type $A \Rightarrow B$; if $f$ has type
$A \Rightarrow B$ and $a$ has type $A$, then $f\,a$ has type $B$; $\mathsf{zero}$ has type
$\mathsf{nat}$; if $t$ has type $\mathsf{nat}$, so does $\mathsf{succ}\,t$; and if $u$ has type
$A$, $v$ has type $A \Rightarrow \mathsf{nat} \Rightarrow A$ and $t$ has type $\mathsf{nat}$,
then the recursor $\mathsf{R}\,u\,v\,t$, written `natRec u v t`, has type $A$
(Girard-Lafont-Taylor §7.1.2, Sørensen-Urzyczyn Definition 11.6.1).
