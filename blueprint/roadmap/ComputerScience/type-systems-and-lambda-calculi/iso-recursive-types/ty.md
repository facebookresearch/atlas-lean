# Types with iso-recursive types

The types of the call-by-value lambda calculus with iso-recursive types form the inductive type generated by: the unit type $\mathrm{unit}$; function types $a \to b$ for types $a, b$; de Bruijn type variables $X_n$ for $n \in \mathbb{N}$; and recursive types $\mu.\,a$ for a type $a$, the recursive type $\mu X.\,a$ in which $\mu$ binds the variable $X$ as type index $0$ of $a$. Equality of types is decidable.

## Sources

- B. C. Pierce, *Types and Programming Languages*, MIT Press, 2002, Chapter 20 (iso-recursive types). In that presentation $\mathrm{fold}$ and $\mathrm{unfold}$ carry the recursive type as an annotation; here they are unannotated.
