# Call-by-value reduction with fold and unfold

Consider the call-by-value lambda calculus with iso-recursive types. Its types are $\mathrm{unit}$, arrows $a \to b$, de Bruijn type variables $X_n$ ($n \in \mathbb{N}$) and recursive types $\mu.\,a$, where $\mu$ binds type index $0$ in $a$. Its terms are $\mathrm{unit}$, de Bruijn variables $x_n$, abstractions $\lambda.\,t$ without a type annotation (binding index $0$ in $t$), applications $t\,u$, and $\mathrm{fold}\,t$ and $\mathrm{unfold}\,t$, neither annotated with a type. The *values* are $\mathrm{unit}$, every abstraction $\lambda.\,t$, and $\mathrm{fold}\,v$ for a value $v$. Write $t[0 := u]$ for the substitution of $u$ for variable $0$ of $t$, lowering the other free variables.

Call-by-value reduction $t \to t'$ is generated by: if $t \to t'$ then $t\,u \to t'\,u$; if $t$ is a value and $u \to u'$ then $t\,u \to t\,u'$; if $u$ is a value then $(\lambda.\,t)\,u \to t[0 := u]$; if $t \to t'$ then $\mathrm{unfold}\,t \to \mathrm{unfold}\,t'$ and $\mathrm{fold}\,t \to \mathrm{fold}\,t'$; and if $v$ is a value then $\mathrm{unfold}\,(\mathrm{fold}\,v) \to v$.

Reduction is left to right: the argument of an application reduces only once the function part is a value, and a fold–unfold pair cancels only when its argument is a value.

## Sources

- B. C. Pierce, *Types and Programming Languages*, MIT Press, 2002, Chapter 20 (iso-recursive types). In that presentation $\mathrm{fold}$ and $\mathrm{unfold}$ carry the recursive type as an annotation; here they are unannotated.
