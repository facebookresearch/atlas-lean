# Progress for iso-recursive types

Consider the call-by-value lambda calculus with iso-recursive types. Its types are $\mathrm{unit}$, arrows $a \to b$, de Bruijn type variables $X_n$ ($n \in \mathbb{N}$) and recursive types $\mu.\,a$, where $\mu$ binds type index $0$ in $a$. Its terms are $\mathrm{unit}$, de Bruijn variables $x_n$, abstractions $\lambda.\,t$ without a type annotation (binding index $0$ in $t$), applications $t\,u$, and $\mathrm{fold}\,t$ and $\mathrm{unfold}\,t$, neither annotated with a type. The *unfolding* of a body $a$ is $a[0 := \mu.\,a]$, the type $[X \mapsto \mu X.\,a]\,a$.

Contexts are lists of types, the head having index $0$. The typing relation $\Gamma \vdash t : a$ is generated by the rules: $\Gamma \vdash \mathrm{unit} : \mathrm{unit}$; $\Gamma \vdash x_n : a$ when the entry of $\Gamma$ at index $n$ exists and equals $a$; if $a :: \Gamma \vdash t : b$ then $\Gamma \vdash \lambda.\,t : a \to b$; if $\Gamma \vdash t : a \to b$ and $\Gamma \vdash u : a$ then $\Gamma \vdash t\,u : b$; if $\Gamma \vdash t : a[0 := \mu.\,a]$ then $\Gamma \vdash \mathrm{fold}\,t : \mu.\,a$; and if $\Gamma \vdash t : \mu.\,a$ then $\Gamma \vdash \mathrm{unfold}\,t : a[0 := \mu.\,a]$.

The *values* are $\mathrm{unit}$, every abstraction $\lambda.\,t$, and $\mathrm{fold}\,v$ for a value $v$. Call-by-value reduction $t \to t'$ is generated by: if $t \to t'$ then $t\,u \to t'\,u$; if $t$ is a value and $u \to u'$ then $t\,u \to t\,u'$; if $u$ is a value then $(\lambda.\,t)\,u \to t[0 := u]$; if $t \to t'$ then $\mathrm{unfold}\,t \to \mathrm{unfold}\,t'$ and $\mathrm{fold}\,t \to \mathrm{fold}\,t'$; and if $v$ is a value then $\mathrm{unfold}\,(\mathrm{fold}\,v) \to v$.

**Progress.** For every term $t$ and type $a$ with $[\,] \vdash t : a$ in the empty context, either $t$ is a value or there is a term $t'$ with $t \to t'$.

## Sources

- B. C. Pierce, *Types and Programming Languages*, MIT Press, 2002, Chapter 20 (iso-recursive types). In that presentation $\mathrm{fold}$ and $\mathrm{unfold}$ carry the recursive type as an annotation; here they are unannotated.
