# Terms of the lambda calculus with iso-recursive types

The terms of the call-by-value lambda calculus with iso-recursive types form the inductive type generated by: the unit value $\mathrm{unit}$; de Bruijn variables $x_n$ for $n \in \mathbb{N}$; abstractions $\lambda.\,t$, binding variable $0$ in the body $t$ and carrying no type annotation; applications $t\,u$; folds $\mathrm{fold}\,t$; and unfolds $\mathrm{unfold}\,t$. Neither $\mathrm{fold}$ nor $\mathrm{unfold}$ is annotated with a recursive type. Equality of terms is decidable.

## Sources

- B. C. Pierce, *Types and Programming Languages*, MIT Press, 2002, Chapter 20 (iso-recursive types). In that presentation $\mathrm{fold}$ and $\mathrm{unfold}$ carry the recursive type as an annotation; here they are unannotated.
