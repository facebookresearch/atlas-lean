# Consistency of the likelihood-weighting numerator

For a Bayesian network over a nonempty alphabet, evidence $x_E = e$ and a function $f$, if the samples $X_1, X_2, \ldots$ are measurable, pairwise independent and distributed as the network with the evidence nodes clamped to $e$, then the likelihood-weighting estimate converges almost surely to $\sum_{x : x_E = e} P(x) f(x)$.
