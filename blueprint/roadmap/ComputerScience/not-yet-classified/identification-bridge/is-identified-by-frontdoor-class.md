# Front-door identification

Fix a graph on $n$ ordered nodes, a finite nonempty value set, a treatment node $k$, an outcome node $y \ne k$ and a mediator set $M$ containing neither $k$ nor $y$. On the class of causal Bayesian networks with this graph that satisfy the front-door criterion for $(k, y, M)$ and the positivity condition $P(X_k = a', X_M = m) > 0$ for all $a'$ and $m$, the interventional probability $P(X_y = v \mid \mathrm{do}(X_k = a))$ is identified by the observational joint law: any two networks in the class with the same joint law give it the same value.
