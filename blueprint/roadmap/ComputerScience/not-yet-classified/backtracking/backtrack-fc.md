# Backtracking with forward checking

For a binary constraint satisfaction problem on finitely many variables, initial domains, and a search order (a rule that picks an unassigned variable from the current domains, and an enumeration of the current domain of the picked variable), backtracking with forward checking starts with every variable unassigned. It picks a variable $x$ and tries its values $a$ in order. A value is skipped when a constraint of $x$ with itself rejects $x = a$, or when forward checking empties the domain of an unassigned variable; forward checking sets the domain of $x$ to $\{a\}$ and shrinks the domain of every other variable joined to $x$ by a constraint to the values compatible with $x = a$. Otherwise the search recurses on the remaining variables and backtracks to the next value on failure. It returns a total assignment, or no assignment.
