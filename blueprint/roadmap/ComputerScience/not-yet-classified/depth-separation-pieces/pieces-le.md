# Bounded number of affine pieces

A function $f : \mathbb R \to \mathbb R$ has at most $n$ affine pieces when there is a finite set $s$ of breakpoints with $|s| + 1 \le n$ such that for all $x \le y \le z$ with no breakpoint strictly between $x$ and $z$,

$$(f(y) - f(x))(z - x) = (f(z) - f(x))(y - x),$$

that is, $f$ is affine on each closed interval between consecutive breakpoints. Minimality of $s$ is not required.
