# Kernel causal Bayesian network

A kernel causal Bayesian network on nodes $0, \dots, n - 1$ in topological order, without input nodes, with node $k$ taking values in a standard Borel space $\Omega_k$: each node $k$ has a set of parents among $0, \dots, k - 1$ and a Markov kernel giving the conditional law of node $k$ given the values of its parents.
