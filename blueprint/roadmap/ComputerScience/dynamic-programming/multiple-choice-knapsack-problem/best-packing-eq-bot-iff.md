# Packing recurrence is bottom iff no selection fits the capacity

Let $\beta$ be a linearly ordered additive commutative monoid in which addition is monotone. For
every list of groups of knapsack items with values in $\beta$ and every capacity $c$, the packing
recurrence at $c$ equals $\bot$ if and only if no selection (one item from each group) has total
weight at most $c$.
