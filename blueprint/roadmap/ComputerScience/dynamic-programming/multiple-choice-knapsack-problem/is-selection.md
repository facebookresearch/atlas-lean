# Multiple-choice knapsack selection

Let $G_1, \dots, G_k$ be a list of groups, each a list of knapsack items. A selection for these
groups is a list $(a_1, \dots, a_k)$ of items of the same length $k$ with $a_i \in G_i$ for every
$i$: it chooses exactly one item from each group, in group order. For the empty list of groups
the only selection is the empty list.
