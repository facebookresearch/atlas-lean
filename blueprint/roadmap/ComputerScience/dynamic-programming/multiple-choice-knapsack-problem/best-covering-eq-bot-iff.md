# Covering recurrence is bottom iff no selection reaches the target

Let $\beta$ be a linearly ordered additive commutative monoid in which addition is monotone. For
every list of groups of knapsack items with values in $\beta$ and every target $L$, the covering
recurrence at $L$ equals $\bot$ if and only if no selection (one item from each group) has total
weight at least $L$.
