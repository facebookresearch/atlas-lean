# Values of bounded rewards are bounded

Let $M$ be a Markov decision process with a finite set of states $S$, a finite set of actions $A$, real rewards $r(s,a)$ and transition probabilities $P(s,a,s')$ that are nonnegative and sum to $1$ over $s'$, and let $0 \le \gamma < 1$. If all rewards lie in $[0,1]$ then $0 \le V^\pi(s) \le 1/(1-\gamma)$ for every stochastic policy $\pi$ and state $s$.
