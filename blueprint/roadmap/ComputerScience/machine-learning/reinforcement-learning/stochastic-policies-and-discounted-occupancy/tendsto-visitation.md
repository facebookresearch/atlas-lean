# The visitation is a discounted sum of transition probabilities

Let $P$ be a row-stochastic matrix on a finite set $S$ (nonnegative entries, each row summing to $1$) and let $0 \le \gamma < 1$. For all states $s_0, s$, the partial sums $(1 - \gamma) \sum_{t < n} \gamma^t (P^t)_{s_0 s}$ converge to the discounted visitation $d_{s_0}(s)$.
