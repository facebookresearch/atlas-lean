# An optimal policy exists for the terminal-value finite-horizon problem

For a finite MDP with stochastic transitions, a nonempty finite set of actions and discount `γ ≥ 0`, some nonstationary policy (one decision rule for each number of remaining steps) has terminal-value return equal to `valueIteration M γ k g` at every horizon `k` and state, and no policy's terminal-value return exceeds it. No `γ < 1` is needed: the horizon is finite.
