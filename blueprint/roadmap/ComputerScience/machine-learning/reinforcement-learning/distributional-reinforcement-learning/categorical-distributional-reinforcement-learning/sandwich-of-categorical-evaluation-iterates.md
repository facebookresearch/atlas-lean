# Categorical evaluation iterates are eventually sandwiched between monotone bounds

Along sample-based categorical policy evaluation, every averaged bound $U_k$ from above and $L_k$ from below eventually sandwiches the iterates in stochastic dominance, almost surely.

Fix a grid $z_1 < z_2 < \dots < z_K$ with $K \ge 2$. Run the [categorical evaluation algorithm](../categorical-distributional-reinforcement-learning/categorical-evaluation-with-mixture-updates.md) (evaluation variant) for a policy $\pi$ with $\gamma \in [0,1)$ and step sizes satisfying the Robbins–Monro conditions. Let $U_k$ and $L_k$ be the [averaged projected iterates from the grid endpoints](../categorical-distributional-reinforcement-learning/monotone-averaged-projected-iterates.md) and $\preceq$ element-wise [stochastic dominance](../categorical-distributional-reinforcement-learning/categorical-operators-are-monotone.md). Then for every $k \ge 0$ there is a random time $T_k$, finite almost surely, with

$$L_k \preceq \eta_t \preceq U_k \quad \text{for all } t > T_k, \text{ almost surely.}$$

## Expansion

**Missing prerequisite.** The proof needs the scalar noise-averaging lemma of stochastic approximation: on a filtered probability space, if $W_{t+1} = (1 - \alpha_t) W_t + \alpha_t w_t$ for $t \ge T$, with $\alpha_t \in [0,1]$ $\mathcal{F}_t$-measurable, $\sum_t \alpha_t = \infty$ and $\sum_t \alpha_t^2 < C$ almost surely, $w_t$ $\mathcal{F}_{t+1}$-measurable with $\mathbb{E}[w_t \mid \mathcal{F}_t] = 0$ and $|w_t| \le 1$, and $W_T = 0$, then $W_t \to 0$ almost surely. This is needed for every deterministic start $T = s$; a random start $T$, not necessarily a stopping time, then follows by running the recursion from each $s$, intersecting the countably many almost sure events, and using that the run started at $T$ equals the run started at $s$ on $\{T = s\}$. Without the $\mathcal{F}_{t+1}$-measurability of $w_t$ the lemma is false (trivial filtration, $w_t = \xi$ a fixed random sign, $\alpha_t = 1/(t+1)$: then $W_t = \xi$). No page states this lemma on its own. Tsitsiklis's box-shrinking theorem for asynchronous stochastic approximation ([asynchronous stochastic approximation](../../asynchronous-stochastic-approximation-convergence-by-box-shr.md)) works in $\mathbb{R}^n$ with the componentwise order and a translation hypothesis that grid distribution functions do not satisfy, so it is not the route here.

**Proof given the lemma** (Rowland's Lemma 6, a variant of Tsitsiklis's Lemma 6). Induction on $k$; the case $k = 0$ holds because all iterates live in $[z_1, z_K]$. Given $T_k$, define for $t \ge T_k + 1$ the laws $H_t$ by $H_{T_k + 1} = U_k$, $H_{t+1} = (1 - \alpha_t) H_t + \alpha_t \Pi_{\mathcal{C}} \mathcal{T}^\pi U_k$, and the signed measures $W_t$ by $W_{T_k + 1} = 0$, $W_{t+1} = (1 - \alpha_t) W_t + \alpha_t N_t$, where $N_t$ is the [sampling noise](../categorical-distributional-reinforcement-learning/sampled-categorical-target-is-unbiased.md); the start $T_k + 1$ is used because the hypothesis gives $\eta_t \preceq U_k$ only for $t > T_k$. The noise $N_t((-\infty, z_i])$ is a function of $\eta_t$, $(x_t, a_t)$ and the sample $(r_t, x_{t+1}, a^*_t)$, hence $\mathcal{F}_{t+1}$-measurable, with conditional mean $0$ given $\mathcal{F}_t$ and absolute value at most $1$. Dominance between signed measures of total mass $1$ is read through distribution functions. The [monotonicity](../categorical-distributional-reinforcement-learning/categorical-operators-are-monotone.md) of $\Pi_{\mathcal{C}} \mathcal{T}^\pi$ and $\alpha_t \in [0,1]$ give $\eta_t \preceq H_t + W_t$. Once $\prod_{\tau = T_k + 1}^{t-1} (1 - \alpha_\tau) \le \frac14$ at every pair, which happens because $\sum \alpha = \infty$, this gives $\eta_t \preceq U_{k+1} + W_t - \frac14 (U_k - \Pi_{\mathcal{C}} \mathcal{T}^\pi U_k)$. Let $\delta$ be the smallest nonzero gap $|F_{U_k}(z_i) - F_{\Pi_{\mathcal{C}} \mathcal{T}^\pi U_k}(z_i)|$. At grid points where the gap is $0$, $F_{U_{k+1}}(z_i) = F_{U_k}(z_i)$, and the comparison there comes from the induction hypothesis $\eta_t \preceq U_k$, not from the noise bound; if every gap is $0$, $U_{k+1} = U_k$ and there is nothing to show. Comparing at grid points suffices although $\eta_t$ need not live on the grid: $F_{U_{k+1}}$ is $0$ below $z_1$ and constant on each $[z_i, z_{i+1})$, while $F_{\eta_t}$ is nondecreasing, so $F_{\eta_t}(z_i) \ge F_{U_{k+1}}(z_i)$ for all $i$ gives $F_{\eta_t} \ge F_{U_{k+1}}$ everywhere. The noise has conditional mean zero and is bounded by $1$, so the lemma gives $W_t((-\infty, z_i]) \to 0$ almost surely. Once $|W_t((-\infty, z_i])| < \delta/4$ everywhere, $\eta_t \preceq U_{k+1}$. The bound from below is symmetric, with $L_k$, $\Pi_{\mathcal{C}} \mathcal{T}^\pi L_k$ and the reversed inequality $H_t + W_t \preceq \eta_t$; here comparing at grid points alone does not suffice, because $F_{\eta_t}$ may rise above its value at $z_i$ inside the cell $[z_i, z_{i+1})$, while the lower bound needs $F_{\eta_t} \le F_{L_{k+1}}$ there. The argument works because $H_t + W_t \preceq \eta_t$ holds at every $y$, and $H_t$, $W_t$, $L_k$ and $\Pi_{\mathcal{C}} \mathcal{T}^\pi L_k$ have distribution functions constant on each cell $[z_i, z_{i+1})$, so for $y$ in that cell $F_{\eta_t}(y) \le F_{H_t + W_t}(y) = F_{H_t + W_t}(z_i)$, and, at a grid point $z_i$ with nonzero gap, the margin argument gives $F_{\eta_t}(y) \le F_{L_{k+1}}(z_i) = F_{L_{k+1}}(y)$. At a grid point with zero gap, $F_{L_{k+1}} = F_{L_k}$ on the whole cell $[z_i, z_{i+1})$, and the induction hypothesis $L_k \preceq \eta_t$ gives $F_{\eta_t}(y) \le F_{L_k}(y) = F_{L_{k+1}}(y)$ there, without the noise bound. Outside $[z_1, z_K)$ both distribution functions are $0$ or both $1$. Rowland and coauthors cite the lemma as "standard stochastic approximation theory" and print $(\infty, z_i]$ for $(-\infty, z_i]$.
