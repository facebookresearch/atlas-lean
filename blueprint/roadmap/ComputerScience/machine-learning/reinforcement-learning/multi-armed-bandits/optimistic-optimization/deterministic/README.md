# Deterministic case

The function is evaluated without noise. DOO uses the diameters $\delta(h)$ of the cells for a semi-metric under which
the function is locally smooth around a maximizer; SOO uses no such knowledge, and its loss bound is that of DOO with
the number of expansions divided by the maximal depth of its tree, and the depth limited by it.
