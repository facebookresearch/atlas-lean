# Reward laws as a kernel

The reward laws of a stochastic bandit $\nu = (P_1, \dots, P_k)$ form a probability kernel from the arms, with the
discrete $\sigma$-algebra, to $\mathbb{R}$: it maps arm $i$ to $P_i$.

## Sources

- T. Lattimore and Cs. Szepesvári, *Bandit Algorithms*, Cambridge University Press, 2020 (author copy), Section 4.7 (a bandit environment as a probability kernel from the actions to $(\mathbb{R}, \mathcal{B}(\mathbb{R}))$). <https://tor-lattimore.com/downloads/book/book.pdf>
