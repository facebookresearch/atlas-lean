# Sample complexity of exploration

The sample complexity of exploration of a learning algorithm counts the time steps, along one infinite run in an MDP, at which the algorithm's current non-stationary policy is more than $\varepsilon$ worse than optimal from the current state. An algorithm is PAC-MDP if this count is polynomial with high probability.

Let $M = \langle S, A, T, R, \gamma\rangle$ be a finite MDP with $S = |S|$ states, $A = |A|$ actions, transition distributions $T(\cdot \mid s, a)$, reward distributions $R(s, a)$ supported in $[0, 1]$ and discount $0 \le \gamma < 1$. The agent starts in an arbitrary state, observes its state, chooses an action, receives a reward drawn from $R(s, a)$ and moves to a state drawn from $T(\cdot \mid s, a)$, forever; the agent receives $S$, $A$ and $\gamma$ as input. A learning algorithm $\mathcal A$, which also takes inputs $\varepsilon$ and $\delta$ and is then written $\mathcal A(\varepsilon, \delta)$, is viewed as a non-stationary policy: at each time $t$ it defines a policy $\mathcal A_t$ mapping the future path to future actions, and $V^{\mathcal A_t}_M(s_t)$ denotes the expected discounted return of continuing to run the algorithm from its current state $s_t$ given its history.

**Definition.** For a random path $c = (s_1, a_1, r_1, s_2, a_2, r_2, \dots)$ generated by executing $\mathcal A$ in $M$ and a fixed $\varepsilon > 0$, the sample complexity of exploration of $\mathcal A$ is the number of time steps $t$ with

$$V^{\mathcal A_t}_M(s_t) < V^*_M(s_t) - \varepsilon.$$

It is a random quantity, possibly infinite. An algorithm $\mathcal A$ is PAC-MDP (probably approximately correct in MDPs) if there is a polynomial $p$ such that for every finite MDP $M$ as above, with $S$ states, $A$ actions and discount $\gamma$, and all $\varepsilon > 0$ and $0 < \delta < 1$, the sample complexity of $\mathcal A(\varepsilon, \delta)$ run on $M$ is at most $p(S, A, 1/\varepsilon, 1/\delta, 1/(1-\gamma))$ with probability at least $1-\delta$. It is efficient PAC-MDP if, in addition, its per-time-step computation and its space are bounded, with the same probability, by such a polynomial.

The source writes the definition with "some polynomial" after $\varepsilon$ and $\delta$, for a fixed MDP; read that way it would be vacuous, since any count that is finite almost surely is below some constant with probability $1-\delta$. Its theorems bound the count by one expression for all MDPs, which is the form stated here.

The definition places no restriction on when the non-$\varepsilon$-optimal steps occur or how bad they are; it is closer to a mistake bound than to the offline PAC model, in which all mistakes precede a final hypothesis.

## Expansion

Kakade introduced the definition in his thesis; the E3 and the original R-max analyses use slightly different notions (halting with a near-optimal policy from the current state, respectively near-optimal average reward after a polynomial time), which this definition replaces without mixing-time arguments. The source notes that efficient learnability in this sense implies efficient learnability under the average-loss criterion, which compares the realized sum of rewards with the expected return of an optimal policy.
