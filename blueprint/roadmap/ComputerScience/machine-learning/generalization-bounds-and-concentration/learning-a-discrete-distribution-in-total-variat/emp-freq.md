# Empirical frequency of a value in a sample

For a sample $x = (x_1, \dots, x_n)$ of values in a set $\alpha$ and a value $a \in \alpha$, the empirical frequency of $a$ is $\hat p_x(a) = \#\{i \le n : x_i = a\} / n$. No finiteness of $\alpha$ is needed: only the $n$ sample indices are counted. Division by zero is read as $0$, so for the empty sample ($n = 0$) every frequency is $0$; then the frequencies do not sum to $1$ and do not form a probability mass function.
