# Parent sets of a topologically numbered structure

For a structure $Pa$ on a vertex set $V$ with decidable equality and a bijection $e : V \to \{0, \dots, m-1\}$, intended to be topological for $Pa$ ($u \in Pa(v)$ implies $e(u) < e(v)$), the parent map on $\{0, \dots, m-1\}$ that gives node $k$ the parents $j < k$ with $e^{-1}(j) \in Pa(e^{-1}(k))$.
