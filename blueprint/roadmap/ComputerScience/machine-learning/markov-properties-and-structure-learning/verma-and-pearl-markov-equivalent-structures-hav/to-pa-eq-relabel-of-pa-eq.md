# A structure is the relabeling of its network

Let $Pa$ be a structure on a vertex set $V$ with decidable equality and $e : V \to \{0, \dots, m-1\}$ a bijection that is topological for $Pa$. Every Bayesian network on $m$ nodes, with any value set and any tables, whose parent map is the one induced by $e$ and $Pa$ has the parent-set structure obtained by transporting $Pa$ along $e$.
