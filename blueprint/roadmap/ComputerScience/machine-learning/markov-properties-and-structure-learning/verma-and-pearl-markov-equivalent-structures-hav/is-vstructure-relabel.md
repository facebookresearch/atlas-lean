# V-structures are invariant under relabeling

For a parent-set structure $Pa$ on a set $V$ and a bijection $e : V \to W$, the images $e(u), e(w), e(z)$ form a v-structure in the structure transported along $e$ if and only if $u, w, z$ form a v-structure in $Pa$: relabelling preserves v-structures.
