# Global Markov property gives conditional independence of separated sets

Let $V$ be a finite set of vertices with decidable equality and $\alpha$ a finite set of values. If a weight $p$ satisfies the global Markov property for a simple graph $G$ on $V$, then for pairwise disjoint sets $A$, $B$, $S$ of vertices such that $S$ separates $A$ from $B$ in $G$, the variables on $A$ and on $B$ are conditionally independent given those on $S$ under $p$. This is the global Markov property in its usual form, for pairwise disjoint sets.
