# Gibbs factorization implies the pairwise Markov property

Let $V$ be a finite set of vertices with decidable equality and $\alpha$ a finite set of values. If a weight $p : \alpha^V \to \mathbb{R}$ factorizes over the cliques of a simple graph $G$ on $V$, then $p$ satisfies the pairwise Markov property for $G$.
