# Gibbs-factorized weights are nonnegative

Let $V$ be a finite set of vertices with decidable equality and $\alpha$ a finite set of values. If a weight $p : \alpha^V \to \mathbb{R}$ factorizes over the cliques of a simple graph $G$ on $V$, then $p$ is nonnegative, being a product of nonnegative potentials.
