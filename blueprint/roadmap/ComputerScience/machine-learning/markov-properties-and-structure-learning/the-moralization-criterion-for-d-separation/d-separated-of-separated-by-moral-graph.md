# Moralization criterion, backward direction

Let $b$ be a Bayesian network on $n$ nodes and $X$, $Y$, $Z$ pairwise disjoint sets of nodes. If $Z$ separates $X$ from $Y$ in the moral graph of the ancestral set $\operatorname{an}(X \cup Y \cup Z)$, then $Z$ d-separates $X$ from $Y$ in the graph of $b$.
