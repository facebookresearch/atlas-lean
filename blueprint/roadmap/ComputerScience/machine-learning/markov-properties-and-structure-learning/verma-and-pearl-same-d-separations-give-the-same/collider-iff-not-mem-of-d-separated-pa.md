# Collider exactly when outside a separating set

Let $V$ be a set of variables and $\mathrm{Pa}$ a parent-set structure on $V$ (each $v$ has a finite set $\mathrm{Pa}(v)$ of parents) that is acyclic: no variable is its own proper ancestor. Let $a, c, b \in V$ with $a$ adjacent to $c$, $c$ adjacent to $b$ and $a \ne b$, and let $S \subseteq V$ d-separate $\{a\}$ from $\{b\}$. Then $a \to c \leftarrow b$ is a collider (both $a$ and $b$ are parents of $c$) if and only if $c \notin S$ (Verma and Pearl, Lemma 2).
