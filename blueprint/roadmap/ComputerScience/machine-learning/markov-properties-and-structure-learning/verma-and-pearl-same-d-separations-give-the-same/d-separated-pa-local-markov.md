# Local Markov separator

Let $V$ be a set of variables and $\mathrm{Pa}$ a parent-set structure on $V$ (each $v$ has a finite set $\mathrm{Pa}(v)$ of parents) that is acyclic: no variable is its own proper ancestor. For every variable $w$, the parents $\mathrm{Pa}(w)$ d-separate $\{w\}$ from the set of variables $u$ that are neither descendants of $w$ nor parents of $w$.
