# Same d-separations give the same adjacencies

Let $\mathrm{Pa}$ and $\mathrm{Pa}'$ be acyclic parent-set structures on a set $V$ with the same d-separations: for all sets $X, Y, Z \subseteq V$, $Z$ d-separates $X$ from $Y$ in $\mathrm{Pa}$ if and only if it does in $\mathrm{Pa}'$. Then for all $u, w \in V$, $u$ and $w$ are adjacent in $\mathrm{Pa}$ if and only if they are adjacent in $\mathrm{Pa}'$ (Verma and Pearl, Theorem 1).
