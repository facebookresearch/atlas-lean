# Adjacent exactly when no set d-separates

Let $V$ be a set of variables and $\mathrm{Pa}$ a parent-set structure on $V$ (each $v$ has a finite set $\mathrm{Pa}(v)$ of parents) that is acyclic: no variable is its own proper ancestor. For distinct variables $u \ne w$, $u$ and $w$ are adjacent (one is a parent of the other) if and only if no set $Z \subseteq V$ d-separates $\{u\}$ from $\{w\}$ (Verma and Pearl, Lemma 1).
