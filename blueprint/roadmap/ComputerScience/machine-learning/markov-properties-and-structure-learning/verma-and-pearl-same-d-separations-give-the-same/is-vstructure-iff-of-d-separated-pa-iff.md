# Same d-separations give the same v-structures

Let $\mathrm{Pa}$ and $\mathrm{Pa}'$ be acyclic parent-set structures on a set $V$ with the same d-separations: for all sets $X, Y, Z \subseteq V$, $Z$ d-separates $X$ from $Y$ in $\mathrm{Pa}$ if and only if it does in $\mathrm{Pa}'$. Then for all $u, w, z \in V$, $u \to w \leftarrow z$ is a v-structure of $\mathrm{Pa}$ (with $u \ne z$ nonadjacent parents of $w$) if and only if it is a v-structure of $\mathrm{Pa}'$ (Verma and Pearl, Theorem 1).
