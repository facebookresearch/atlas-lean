# A nonnegative matrix with a nonnegative inverse is monomial

Let $k$ be a finite index set and $G, K$ real $k \times k$ matrices with nonnegative entries and
$G K = I$. Then there are a permutation $\sigma$ of $k$ and positive weights $d_b$ such that
$G_{ab} = d_b$ if $a = \sigma(b)$ and $G_{ab} = 0$ otherwise.
