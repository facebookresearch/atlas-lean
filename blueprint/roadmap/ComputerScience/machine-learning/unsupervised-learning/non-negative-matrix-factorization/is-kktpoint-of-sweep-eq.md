# Positive fixed points are KKT points

Let $m, n, k$ be finite index sets and $X \in \mathbb{R}^{m \times n}$. If $(W, H)$ is a fixed point
of the [Lee–Seung sweep](sweep.md) and all entries of $W$ and $H$ are positive, then both
gradients $\nabla_W$ and $\nabla_H$ vanish, and $(W, H)$ is a
[Karush–Kuhn–Tucker point](is-kktpoint.md).
