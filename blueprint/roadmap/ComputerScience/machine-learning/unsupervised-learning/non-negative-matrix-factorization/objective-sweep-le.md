# One Lee–Seung sweep does not increase the objective

**One Lee–Seung sweep does not increase the objective**: let $m, n, k$ be finite index sets,
$X \in \mathbb{R}^{m \times n}$, $W \in \mathbb{R}^{m \times k}$ and $H \in \mathbb{R}^{k \times n}$,
all entrywise nonnegative. If $(W', H')$ is the result of one [Lee–Seung sweep](sweep.md) from
$(W, H)$, then $\|X - W' H'\|_F^2 \le \|X - W H\|_F^2$.
