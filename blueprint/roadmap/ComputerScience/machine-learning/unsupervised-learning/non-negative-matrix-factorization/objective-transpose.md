# The NMF objective is invariant under transposition

Let $m, n, k$ be finite index sets. Transposing exchanges the roles of $W$ and $H$: for all
$X \in \mathbb{R}^{m \times n}$, $W \in \mathbb{R}^{m \times k}$ and $H \in \mathbb{R}^{k \times n}$,
$\|X^\top - H^\top W^\top\|_F^2 = \|X - W H\|_F^2$.
