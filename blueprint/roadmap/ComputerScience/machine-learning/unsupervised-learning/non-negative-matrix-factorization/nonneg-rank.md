# Nonnegative rank of a matrix

The nonnegative rank of a real $m \times n$ matrix $X$ is the least $r \in \mathbb{N}$ such that
$X = W H$ with $W \in \mathbb{R}^{m \times r}$ and $H \in \mathbb{R}^{r \times n}$ entrywise
nonnegative (Cohen and Rothblum 1993). If no such factorization exists (for instance if $X$ has a
negative entry), the nonnegative rank is $0$ by convention.
