# Perturbing the dissimilarity shifts the scale

Let $d_1, d_2$ be dissimilarities on a set $X$ with $d_2 \le d_1 + \eta$ pointwise. Then
[$r$-equivalence](sl-equiv.md) for $d_1$ implies $(r + \eta)$-equivalence for $d_2$: the chain
argument in the proof of Carlsson and Mémoli, JMLR 11 (2010), Lemma 15.
