# Stability of single linkage in the sup norm

Let $X$ be a set and $d_1, d_2 : X \times X \to \mathbb{R}$ dissimilarities with
$|d_1(x, y) - d_2(x, y)| \le \eta$ for all $x, y$. Then their
[single-linkage ultrametrics](sl-dist.md) satisfy $|u_1^*(x, y) - u_2^*(x, y)| \le \eta$ for all
$x, y$ (Carlsson and Mémoli, JMLR 11 (2010), Lemma 15, stated there for two metrics on a finite
set; the chain argument needs neither hypothesis).
