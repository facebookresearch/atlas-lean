# Single linkage never merges below the separation

Let $d$ be a dissimilarity on a set $X$ and $s$ a real number with $s \le d(a, b)$ for all
$a \ne b$. Then the [single-linkage ultrametric](sl-dist.md) satisfies $u^*(x, y) \ge s$ for
$x \ne y$ (the fact that single linkage satisfies condition (III) of Carlsson and Mémoli, JMLR 11
(2010), Thm. 18).
