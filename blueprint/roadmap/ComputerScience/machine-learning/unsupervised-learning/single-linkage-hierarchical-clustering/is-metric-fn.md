# Metric on a set, as a function

A function $d : X \times X \to \mathbb{R}$ is a metric on the set $X$ if it is symmetric,
$d(x, x) = 0$ for all $x$, $d(x, y) > 0$ for $x \ne y$, and it satisfies the triangle inequality
$d(x, z) \le d(x, y) + d(y, z)$; then $(X, d)$ is a metric space in the sense of Carlsson and
Mémoli, JMLR 11 (2010), §2 (their finite metric spaces). Several such functions may be compared
on the same set.
