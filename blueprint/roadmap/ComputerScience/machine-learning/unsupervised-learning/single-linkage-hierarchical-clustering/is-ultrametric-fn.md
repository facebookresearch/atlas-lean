# Ultrametric on a set, as a function

A function $u : X \times X \to \mathbb{R}$ is an ultrametric on the set $X$ if it is a
[metric](is-metric-fn.md) satisfying the strong triangle inequality
$u(x, z) \le \max(u(x, y), u(y, z))$ (Carlsson and Mémoli, JMLR 11 (2010), §2).
