# Candidate hierarchical clustering methods

A candidate hierarchical clustering method $T$ assigns to every finite set $X$ and every
dissimilarity $d : X \times X \to \mathbb{R}$ a function $T(X, d) : X \times X \to \mathbb{R}$. A
[hierarchical clustering method](is-hc-method.md) is one that sends metrics to ultrametrics
(Carlsson and Mémoli, JMLR 11 (2010), Def. 11).
