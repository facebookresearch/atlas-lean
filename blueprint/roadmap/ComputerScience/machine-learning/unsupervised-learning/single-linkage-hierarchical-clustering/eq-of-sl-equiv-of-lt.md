# Below the separation, clusters are singletons

Let $d$ be a dissimilarity on a set $X$ and $s$ a real number with $s \le d(a, b)$ for all
$a \ne b$. If $r < s$, then [$r$-equivalent](sl-equiv.md) points are equal (Carlsson and Mémoli,
JMLR 11 (2010), Remark 19 on condition (III): the dendrogram is the partition into singletons for
$t < \mathrm{sep}(X, d)$).
