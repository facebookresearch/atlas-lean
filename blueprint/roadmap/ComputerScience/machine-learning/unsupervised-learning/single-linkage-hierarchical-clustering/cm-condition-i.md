# Condition (I)

A [candidate hierarchical clustering method](hc-method.md) $T$ satisfies condition (I) if for
every $\delta > 0$ it sends the [two-point metric space](two-point-dist.md) at distance $\delta$
to itself: $T(\{p, q\}, d_\delta) = d_\delta$ (Carlsson and Mémoli, JMLR 11 (2010), Thm. 18 (I)).
