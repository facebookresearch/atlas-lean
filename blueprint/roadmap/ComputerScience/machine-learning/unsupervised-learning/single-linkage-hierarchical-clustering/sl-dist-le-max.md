# Strong triangle inequality for the single-linkage distance

For every dissimilarity $d$ on a set $X$ and all $x, y, z \in X$, the
[single-linkage ultrametric](sl-dist.md) satisfies $u^*(x, z) \le \max(u^*(x, y), u^*(y, z))$
(Carlsson and Mémoli, JMLR 11 (2010), §3.4, Example 7: single linkage is a hierarchical
clustering method, whose output on a finite metric space is an ultrametric).
