# Single linkage outputs an ultrametric

Let $X$ be a finite set and $d$ a [metric](is-metric-fn.md) on $X$. Its
[single-linkage ultrametric](sl-dist.md) $u^*$ is an [ultrametric](is-ultrametric-fn.md):
symmetric, zero exactly on the diagonal and satisfying the strong triangle inequality (Carlsson
and Mémoli, JMLR 11 (2010), Example 7: single linkage is a hierarchical clustering method).
