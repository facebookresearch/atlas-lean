# Hierarchical clustering method

A [candidate hierarchical clustering method](hc-method.md) $T$ is a hierarchical clustering
method if it sends every finite [metric space](is-metric-fn.md) $(X, d)$ to an
[ultrametric](is-ultrametric-fn.md) $T(X, d)$ on the same set (Carlsson and Mémoli, JMLR 11
(2010), Def. 11, with dendrograms identified with ultrametrics by their Thm. 9).
