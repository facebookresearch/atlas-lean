# Norm bound for a sub-convex combination of vectors

Gillis–Vavasis Lemma 1 (with $f = \|\cdot\|^2$), bound: let $w_1, \dots, w_r$ be vectors of a real
inner product space with $\|w_k\| \le M$ for all $k$, where $M \ge 0$, and let
$h_1, \dots, h_r \ge 0$ with $\sum_k h_k \le 1$. Then $\|\sum_k h_k w_k\| \le M$.
