# SPA picks only archetypes

**SPA recovers archetypes** (Gillis–Vavasis Theorem 1, noiseless case): let $(m_j)_{j \in \iota}$
be a [separable](separable.md) data matrix with archetypes $w_1, \dots, w_r$. In any
[run of the successive projection algorithm](is-sparun.md) with at most $r$ picks, every picked
column is an archetype.
