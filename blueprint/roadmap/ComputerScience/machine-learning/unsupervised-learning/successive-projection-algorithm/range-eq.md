# Successive projection finds every archetype after r picks

Let $(m_j)_{j \in \iota}$ be a [separable](separable.md) data matrix with archetypes
$w_1, \dots, w_r$. After exactly $r$ picks, any
[run of the successive projection algorithm](is-sparun.md) has found every archetype: the set of
picked columns is $\{w_1, \dots, w_r\}$.
