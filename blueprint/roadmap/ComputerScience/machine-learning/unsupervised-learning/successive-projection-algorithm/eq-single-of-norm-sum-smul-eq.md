# Equality case of the sub-convex combination norm bound

Gillis–Vavasis Lemma 1 (with $f = \|\cdot\|^2$), equality case: let $w_1, \dots, w_r$ be linearly
independent vectors of a real inner product space with $\|w_k\| \le M$ for all $k$, where
$M > 0$, and let $h_1, \dots, h_r \ge 0$ with $\sum_k h_k \le 1$. If
$\|\sum_k h_k w_k\| = M$, then $h$ is a unit vector $e_k$ for some $k$, and $\|w_k\| = M$.
