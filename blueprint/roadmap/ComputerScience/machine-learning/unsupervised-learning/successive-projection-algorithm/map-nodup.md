# SPA picks distinct columns

**SPA recovers archetypes** (Gillis–Vavasis Theorem 1, noiseless case): let $(m_j)_{j \in \iota}$
be a [separable](separable.md) data matrix with $r$ archetypes. In any
[run of the successive projection algorithm](is-sparun.md) with at most $r$ picks, the picked
column vectors are pairwise distinct.
