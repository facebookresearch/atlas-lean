# Under intervention the intervened coordinate is Dirac

Let $c$ be a kernel causal Bayesian network on nodes $0, \dots, n - 1$ with measurable state spaces, $k$ a node and $a$ a value of $X_k$. After $\mathrm{do}(X_k = a)$, for every prefix of length $m$ with $k < m \le n$, the marginal law of coordinate $k$ in that prefix is $\delta_a$.
