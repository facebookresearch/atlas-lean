# Joint law of a kernel causal Bayesian network

For a kernel causal Bayesian network on nodes $0, \dots, n-1$ in topological order, each node $k$ with parents among the earlier nodes and a Markov kernel from its parents' values to its own value space, the joint law is the measure on full assignments built by sampling the nodes in order: node $k$ is drawn from its kernel applied to the values already drawn for its parents.
