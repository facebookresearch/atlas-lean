# Marginal of a set with one node added as a Q-factor

Let $b$ be a Bayesian network on $n$ nodes with values in a finite nonempty set, and $L$ a set of latent nodes. Let $\sigma$ be an ordering of the observed nodes in which every directed edge of the latent projection goes from a lower to a higher rank. For every observed node $i$, the marginal of the observed law on $i$ together with the nodes ranked below $i$ equals $Q$ of that set, the probability of those values after intervening on all other observed nodes.
