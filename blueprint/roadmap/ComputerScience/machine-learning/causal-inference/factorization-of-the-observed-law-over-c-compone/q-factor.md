# Q-factor of a set of observed nodes

For a Bayesian network whose values lie in a finite nonempty set, a set $L$ of latent nodes and a set $S$ of observed nodes, the Q-factor $Q[S](v) = P_{v \setminus s}(s)$ is the probability of the values $v$ on $S$ after the intervention $do(V \setminus S = v \setminus s)$ on the observed nodes outside $S$; the latent nodes are not intervened (J. Tian and J. Pearl, "A general identification condition for causal effects", AAAI 2002, eq. (28)).
