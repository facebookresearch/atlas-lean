# Q-factor as a truncated product

Let $b$ be a Bayesian network on $n$ nodes with values in a finite nonempty set and $L$ a set of latent nodes. For a set $H$ of observed nodes and observed values $v$, the Q-factor $Q[H](v)$ equals the truncated product of the conditional probability tables of the nodes of $H$ and of the latent nodes, summed over the values of the latent nodes with the observed nodes fixed at $v$ (Tian and Pearl 2002, equation (26)).
