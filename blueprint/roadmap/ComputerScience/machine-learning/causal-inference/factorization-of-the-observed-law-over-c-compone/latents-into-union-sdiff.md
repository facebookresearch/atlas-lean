# Latents reaching a set split along a subset

Let $b$ be a Bayesian network on $n$ nodes with values in a finite nonempty set, and $L$ a set of latent nodes. For sets of observed nodes $T \subseteq H$, the set of latent nodes that reach $H$ along a latent path is the union of those reaching $T$ and those reaching $H \setminus T$.
