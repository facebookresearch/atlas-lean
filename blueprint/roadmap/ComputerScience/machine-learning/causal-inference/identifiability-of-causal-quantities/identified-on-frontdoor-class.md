# Front-door identification

Let $\alpha$ be a finite nonempty value set with decidable equality, and let $k \ne y$ be nodes, $M$ a set of nodes containing neither $k$ nor $y$, and $a$, $v$ values. On the class of networks with a fixed graph satisfying the front-door criterion for $(k, y, M)$ and positivity, the interventional probability $P(X_y = v \mid do(X_k = a))$ is identified from the observational joint law: any two networks in the class with the same joint law have the same interventional probability.
