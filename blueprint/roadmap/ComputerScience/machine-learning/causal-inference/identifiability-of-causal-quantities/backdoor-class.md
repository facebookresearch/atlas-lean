# Class of models satisfying the back-door criterion

Let $\alpha$ be a finite nonempty value set with decidable equality. For a fixed graph on $n$ nodes, nodes $k$, $y$, a set $Z$ and a treatment value $a$, the class of causal Bayesian networks with that graph that satisfy the back-door criterion for $(k, y, Z)$ and the positivity condition $P(X_k = a, Z = z) > 0$ whenever $P(Z = z) > 0$.
