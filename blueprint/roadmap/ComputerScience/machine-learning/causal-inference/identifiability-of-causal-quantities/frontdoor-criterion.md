# Front-door criterion

The front-door criterion for the effect of node $k$ on node $y$ with mediator set $M$, in the graph of a Bayesian network $b$: $M$ intercepts every directed path from $k$ to $y$, every path from $k$ to a node of $M$ beginning with an edge into $k$ is blocked by the empty set, and every path from a node of $M$ to $y$ beginning with an edge into that node is blocked by $\{k\}$.
