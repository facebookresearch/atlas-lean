# Class of models satisfying the front-door criterion

Let $\alpha$ be a finite nonempty value set with decidable equality. For a fixed graph on $n$ nodes, nodes $k$, $y$ and a set $M$, the class of causal Bayesian networks with that graph that satisfy the front-door criterion for $(k, y, M)$ and the positivity condition $P(X_k = a', M = m) > 0$ for all treatment values $a'$ and mediator values $m$.
