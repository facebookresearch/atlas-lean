# Solution of linear structural equations

For $n$ nodes, a coefficient matrix $B$, where $B_{ij}$ is the coefficient of $X_j$ in the equation of $X_i$, and a noise vector $e$, the solution of the linear structural equations $X = B X + e$ is $X = (1 - B)^{-1} e$. When $B$ is strictly lower triangular this is the unique solution.
