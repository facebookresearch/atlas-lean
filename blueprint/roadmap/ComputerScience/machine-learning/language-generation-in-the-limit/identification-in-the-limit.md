# Identification in the limit from positive examples

Let $U$ be a countable set of strings and $\mathcal{C} = \{L_1, L_2, \dots\}$ a countable collection of nonempty languages $L_i \subseteq U$ (in the generation-in-the-limit setting all $L_i$ are infinite), given by a membership oracle. An adversary picks a target $K \in \mathcal{C}$ and enumerates its elements $w_1, w_2, \dots$ (every element of $K$ eventually appears; repetitions allowed); $S_t = \{w_1, \dots, w_t\}$. An **identifier** maps each finite sequence $w_1, \dots, w_t$ to an index $i_t$. The collection $\mathcal{C}$ is **identifiable in the limit** (from positive data, in the sense of Gold) if there is an identifier such that for every $K \in \mathcal{C}$ and every enumeration of $K$ there exist $t^*$ and a single index $i$ with $L_i = K$ and $i_t = i$ for all $t \ge t^*$; alternating among several indices of $K$, when $K$ occurs more than once in the list, does not count. This is Gold's index-valued convention. Under the function-valued convention, which views languages as binary hypotheses $h_i = \mathbf{1}_{L_i}$ and only asks that $h_{i_t} = \mathbf{1}_K$, that is $L_{i_t} = K$, for all large $t$, the requirement on a given identifier is weaker when $\mathcal{C}$ lists some language twice: if $L_1 = L_2 = K$, an identifier alternating between the indices $1$ and $2$ outputs the constant hypothesis $\mathbf{1}_K$ but its index never stabilizes. When the naming is injective ($L_i \ne L_j$ for $i \ne j$) the two conventions coincide: the identifier must eventually output one fixed hypothesis forever, with exactly the target's support.
