# Dirichlet MAP estimate of a categorical distribution

Let $\alpha$ be a finite nonempty set of categories and $n : \alpha \to \mathbb{N}$ the observed counts. For Dirichlet concentrations $c_a \ge 1$, the maximum a posteriori estimate is the normalization of the pseudo-counts $n(a) + c_a - 1$, and the uniform distribution when all pseudo-counts are zero.
