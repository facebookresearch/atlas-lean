# Categorical likelihood times Dirichlet kernel

Let $\alpha$ be a finite set and $n : \alpha \to \mathbb{N}$ counts. For concentrations $c_a \ge 1$ and every probability vector $\theta$ on $\alpha$,

$$\left(\prod_a \theta_a^{n(a)}\right)\left(\prod_a \theta_a^{c_a - 1}\right) = \prod_a \theta_a^{n(a) + c_a - 1}$$

(real powers): the [likelihood](likelihood.md) of the counts times the [Dirichlet kernel](dirichlet-kernel.md) is a product of powers with the pseudo-counts as exponents.
