# MAP estimation under a Dirichlet prior

Let $\alpha$ be a finite nonempty set of categories and $n : \alpha \to \mathbb{N}$ the observed counts. For Dirichlet concentrations $c_a \ge 1$, the maximum a posteriori estimate maximizes the unnormalized posterior $\prod_a \theta_a^{n(a)} \cdot \prod_a \theta_a^{c_a - 1}$ over all probability vectors $\theta$ on $\alpha$.
