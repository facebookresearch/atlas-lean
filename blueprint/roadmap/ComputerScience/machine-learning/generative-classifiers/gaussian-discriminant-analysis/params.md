# Parameters of Gaussian discriminant analysis

The parameters of Gaussian discriminant analysis with a shared covariance on $\mathbb{R}^\iota$, for a finite index set $\iota$, and a finite set of classes $C$: a prior distribution on $C$, a mean $\mu_c \in \mathbb{R}^\iota$ for each class, and a real matrix $S$ shared by the classes in the role of the precision matrix. No condition is imposed on $S$; it is the inverse of a covariance matrix exactly when it is positive definite.
