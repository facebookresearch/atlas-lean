# Positive definiteness of the scatter matrix

Consider a Gaussian discriminant model on $\mathbb{R}^\iota$, for a finite index set $\iota$, with a finite set of classes, a prior on classes, class means, and a shared precision matrix $S$. Let $(y_k, x_k)_{k < m}$ be labelled data. The pooled scatter matrix of the residuals $x_k - \mu_{y_k}$ is positive definite when these residuals do not all lie in one affine hyperplane.
