# Maximum likelihood shared covariance

Consider a Gaussian discriminant model on $\mathbb{R}^\iota$, for a finite index set $\iota$, with a finite set of classes, a prior on classes, class means, and a shared precision matrix $S$. Let $(y_k, x_k)_{k < m}$ be labelled data. The covariance estimate is the pooled scatter matrix about the class sample means.

When it is positive definite, its inverse is the maximum likelihood precision matrix ([Maximum likelihood estimation of Gaussian discriminant analysis](likelihood-le-mle-mle-cov.md)).
