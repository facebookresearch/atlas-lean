# The naive Bayes classifier minimizes the 0-1 risk

Consider a naive Bayes model with a finite nonempty set of classes $C$, finitely many features $i \in \iota$ with finite value sets $V_i$, a prior on classes, and for each class and feature a distribution of the feature value. The naive Bayes classifier minimizes the expected 0-1 loss under the model among all classifiers from feature vectors to classes.
