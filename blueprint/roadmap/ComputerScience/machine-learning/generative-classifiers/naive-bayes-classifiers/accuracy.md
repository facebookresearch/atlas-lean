# Accuracy of a naive Bayes classifier

Consider a naive Bayes model with a finite nonempty set of classes $C$, finitely many features $i \in \iota$ with finite value sets $V_i$, a prior on classes, and for each class and feature a distribution of the feature value. The accuracy of a classifier $h$ from feature vectors to classes is the probability under the model that $h$ applied to the feature vector equals the class.
