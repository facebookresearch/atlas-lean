# Risk of a naive Bayes classifier

Consider a naive Bayes model with a finite nonempty set of classes $C$, finitely many features $i \in \iota$ with finite value sets $V_i$, a prior on classes, and for each class and feature a distribution of the feature value. The risk of a classifier $h$ is its expected 0-1 loss under the model: the probability that $h$ applied to the feature vector differs from the class.
