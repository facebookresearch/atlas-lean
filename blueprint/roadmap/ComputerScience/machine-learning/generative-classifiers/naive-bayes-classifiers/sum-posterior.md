# Posterior probabilities sum to one

Consider a naive Bayes model with a finite nonempty set of classes $C$, finitely many features $i \in \iota$ with finite value sets $V_i$, a prior on classes, and for each class and feature a distribution of the feature value. If the evidence of a feature vector $x$ is positive, then the posterior probabilities of the classes given $x$ sum to $1$.
