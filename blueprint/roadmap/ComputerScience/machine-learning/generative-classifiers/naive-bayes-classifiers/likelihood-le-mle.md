# Count estimates maximize the categorical naive Bayes likelihood

Consider a naive Bayes model with a finite nonempty set of classes $C$, finitely many features $i \in \iota$ with finite value sets $V_i$, a prior on classes, and for each class and feature a distribution of the feature value. Assume every value set $V_i$ is nonempty and let $(y_k, x_k)_{k < m}$ be labelled data. The estimate from normalized class and feature counts maximizes the likelihood of the data over all naive Bayes parameters.
