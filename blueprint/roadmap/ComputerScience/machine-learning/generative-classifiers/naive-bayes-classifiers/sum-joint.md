# Joint probabilities sum to one

Consider a naive Bayes model with a finite nonempty set of classes $C$, finitely many features $i \in \iota$ with finite value sets $V_i$, a prior on classes, and for each class and feature a distribution of the feature value. The joint probabilities of classes and feature vectors sum to $1$: the joint is a probability distribution on pairs of a class and a feature vector.
