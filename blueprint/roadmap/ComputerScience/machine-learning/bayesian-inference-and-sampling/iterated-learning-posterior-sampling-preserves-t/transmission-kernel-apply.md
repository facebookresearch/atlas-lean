# Value of the transmission kernel

Let $H$ be a finite set of hypotheses with prior $\pi$, $D$ a finite set of data, and $L(h)$ a probability distribution on $D$ for each hypothesis $h$. The transmission kernel of Griffiths and Kalish's iterated-learning model is $K(h, h') = \sum_d L(h)(d) P(h' \mid d)$.
