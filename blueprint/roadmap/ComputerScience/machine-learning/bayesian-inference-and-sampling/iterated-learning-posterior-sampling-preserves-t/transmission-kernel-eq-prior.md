# Uninformative data

Let $H$ be a finite set of hypotheses with prior $\pi$, $D$ a finite set of data, and $L(h)$ a probability distribution on $D$ for each hypothesis $h$. If the likelihood $L(h)$ is the same distribution for every hypothesis $h$, then for every prior the transmission kernel forgets in one step: $K(h, \cdot) = \pi$ for every $h$.
