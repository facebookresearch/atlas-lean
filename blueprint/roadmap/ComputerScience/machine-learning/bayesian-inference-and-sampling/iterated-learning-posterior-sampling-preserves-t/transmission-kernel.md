# Transmission kernel of iterated learning

Let $H$ be a finite set of hypotheses with prior $\pi$, $D$ a finite set of data, and $L(h)$ a probability distribution on $D$ for each hypothesis $h$. The transmission kernel of Griffiths and Kalish's iterated-learning model moves from a hypothesis $h$ by drawing a datum from $L(h)$ and then a new hypothesis from the posterior given that datum.
