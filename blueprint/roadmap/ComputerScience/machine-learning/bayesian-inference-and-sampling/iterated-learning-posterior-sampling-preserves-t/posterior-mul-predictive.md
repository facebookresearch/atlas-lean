# Posterior times predictive

Let $H$ be a finite set of hypotheses with prior $\pi$, $D$ a finite set of data, and $L(h)$ a probability distribution on $D$ for each hypothesis $h$. For every prior, datum $d$ and hypothesis $h$, $P(d) \cdot P(h \mid d) = \pi(h) L(h)(d)$. When $P(d) = 0$ both sides vanish, since every term $\pi(h) L(h)(d)$ of the zero sum is zero.
