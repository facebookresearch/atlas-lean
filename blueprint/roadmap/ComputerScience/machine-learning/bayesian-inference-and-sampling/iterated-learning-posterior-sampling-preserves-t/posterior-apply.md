# Value of the posterior

Let $H$ be a finite set of hypotheses with prior $\pi$, $D$ a finite set of data, and $L(h)$ a probability distribution on $D$ for each hypothesis $h$. If the predictive probability $P(d)$ of a datum $d$ is nonzero, then the posterior probability of every hypothesis $h$ is $\pi(h) L(h)(d) / P(d)$.
