# Detailed balance of the transmission kernel

Let $H$ be a finite set of hypotheses with prior $\pi$, $D$ a finite set of data, and $L(h)$ a probability distribution on $D$ for each hypothesis $h$. For all hypotheses $h, h'$, $\pi(h) K(h, h') = \sum_d P(d) P(h \mid d) P(h' \mid d)$. This sum is symmetric in $h$ and $h'$, so it also equals $\pi(h') K(h', h)$.
