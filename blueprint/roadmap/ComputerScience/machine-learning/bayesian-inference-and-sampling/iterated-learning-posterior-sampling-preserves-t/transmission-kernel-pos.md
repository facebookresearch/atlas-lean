# Positivity of the transmission kernel

Let $H$ be a finite set of hypotheses with prior $\pi$, $D$ a finite set of data, and $L(h)$ a probability distribution on $D$ for each hypothesis $h$. Suppose $D$ is nonempty, the prior gives positive mass to every hypothesis, and every likelihood $L(h)(d)$ is positive. Then every transmission probability $K(h, h')$ is positive.
