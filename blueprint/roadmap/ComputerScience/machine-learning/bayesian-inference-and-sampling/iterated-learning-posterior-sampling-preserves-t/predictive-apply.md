# Value of the predictive distribution

Let $H$ be a finite set of hypotheses with prior $\pi$, $D$ a finite set of data, and $L(h)$ a probability distribution on $D$ for each hypothesis $h$. The predictive probability of a datum $d$ is the prior-weighted sum of likelihoods, $P(d) = \sum_h \pi(h) L(h)(d)$.
