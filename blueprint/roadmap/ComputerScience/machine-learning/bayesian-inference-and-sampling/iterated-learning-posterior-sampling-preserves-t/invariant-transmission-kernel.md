# The prior is invariant under the transmission kernel

Let $H$ be a finite set of hypotheses with prior $\pi$, $D$ a finite set of data, and $L(h)$ a probability distribution on $D$ for each hypothesis $h$. The prior is an invariant distribution of the transmission kernel of iterated learning, viewed as a Markov kernel on $H$ with the discrete measurable structure; this follows from reversibility.
