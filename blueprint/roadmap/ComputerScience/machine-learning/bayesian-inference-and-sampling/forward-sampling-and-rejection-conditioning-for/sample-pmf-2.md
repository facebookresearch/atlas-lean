# Ancestral sampling from a Bayesian network

Let $B$ be a Bayesian network on the nodes $0, \dots, n-1$ (in topological order) with values in a finite nonempty type $\alpha$. Ancestral (forward) sampling from $B$ is the probability mass function on $\alpha^n$ obtained by sampling the nodes $0, 1, \dots, n-1$ in order, each from its conditional probability table given the already sampled values of its parents.
