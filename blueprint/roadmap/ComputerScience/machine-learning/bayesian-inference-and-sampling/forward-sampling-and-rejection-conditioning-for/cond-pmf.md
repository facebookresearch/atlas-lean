# Conditional distribution of a chain as a probability mass function

Let $c$ be a chain of conditional distributions with values in a finite type $\alpha$: for each $k \in \mathbb{N}$ and each assignment $y = (y_0, \dots, y_{k-1}) \in \alpha^k$ of the earlier variables, a probability vector $p_k(\cdot \mid y)$ on $\alpha$. The conditional distribution of variable $k$ given $y$ is the probability mass function on $\alpha$

$$a \mapsto p_k(a \mid y) ,$$

with the real weights mapped into $[0, \infty]$.
