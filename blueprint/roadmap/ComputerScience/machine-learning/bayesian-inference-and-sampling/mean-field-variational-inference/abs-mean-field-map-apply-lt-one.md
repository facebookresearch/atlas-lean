# The mean-field map takes values in the open cube

**The mean-field map takes values in the open cube** $(-1, 1)^\iota$: for every linear map $U$ of
$\mathbb{R}^\iota$, every $h, m \in \mathbb{R}^\iota$ and every coordinate $i$, the
[mean-field map](mean-field-map.md) $T(m) = \tanh(U m + h)$ satisfies $\lvert T(m)_i \rvert < 1$.
