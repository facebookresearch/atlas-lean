# Error of an approximate fixed-point iteration

Let $(X, d)$ be a pseudometric space, $C \subseteq X$, $T : X \to X$ with $T(C) \subseteq C$, and
$T^\star : X \to X$ $q$-Lipschitz on $C$ (with $q \ge 0$) with a fixed point $\hat x \in C$. If
$d(T x, T^\star x) \le \zeta$ for every $x \in C$, then for every $x_0 \in C$ and every
$k \in \mathbb{N}$,

$$d(T^k x_0, \hat x) \le q^k\, d(x_0, \hat x) + \zeta \sum_{j < k} q^j.$$

$T^\star$ need not map $C$ into itself and $q$ need not be below $1$.
