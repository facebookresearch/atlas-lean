# Global minima of the energy

Let $S$ be a finite state space with a proposal kernel $R$ (for each state $s$, a probability mass function $R(s, \cdot)$ on $S$) and an energy $V : S \to \mathbb{R}$. The set of global minima is

$$S^\ast = \{\, s \in S : V(s) \le V(t) \text{ for all } t \in S \,\}.$$
