# The joint probability of a response pattern and a latent state is positive

Let $Z$ be a finite set of latent states and $\iota$ a finite set of items, with fixed item success probabilities $P_z(i) \in (0, 1)$ for each latent state $z$ and item $i$. For every valid weight function, response pattern and latent state, the joint probability $w_z \cdot P_z(x)$ is strictly positive.
