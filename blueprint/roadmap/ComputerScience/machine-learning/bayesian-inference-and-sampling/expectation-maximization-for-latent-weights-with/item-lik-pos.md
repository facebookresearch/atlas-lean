# The likelihood of a response pattern is positive

Let $Z$ be a finite set of latent states and $\iota$ a finite set of items, with fixed item success probabilities $P_z(i) \in (0, 1)$ for each latent state $z$ and item $i$. The item likelihood $P_z(x)$ of every response pattern $x$ at every latent state $z$ is strictly positive.
