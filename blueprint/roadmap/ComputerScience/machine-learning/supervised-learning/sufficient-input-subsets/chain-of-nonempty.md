# Backward-selection chain at a nonempty set

Let $g$ be a real function on the finite subsets of a set $\iota$ of features and let a rule
choose an element $\pi(R) \in R$ of every nonempty finite set $R$. For a nonempty $R$, the
[backward-selection chain](chain.md) from $R$ is $R$ followed by the chain from
$R \setminus \{\pi(R)\}$.
