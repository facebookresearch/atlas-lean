# FindSIS returns a set when the start reaches the threshold

Let $g$ be a real function on the finite subsets of a set of features, $\tau \in \mathbb{R}$ and
$\pi$ a rule choosing an element of every nonempty finite set. If the starting set $R$ satisfies
$\tau \le g(R)$, then [FindSIS](find-sis.md) from $R$ returns a set.
