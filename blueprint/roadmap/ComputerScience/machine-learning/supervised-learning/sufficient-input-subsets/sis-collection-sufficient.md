# Sets of the SIS-collection are nonempty and sufficient

Let $g$ be a real function on the finite subsets of a set of features, $\tau \in \mathbb{R}$ and
$\pi$ a rule choosing an element of every nonempty finite set. Every set $S$ of the
[SIS-collection](sis-collection.md) from a finite set $R$ is nonempty, satisfies $S \subseteq R$,
and is sufficient: $\tau \le g(S)$.
