# Kernel matrix of the marker kernel

Let $\iota$ be a finite set of markers and $s \in \mathbb{R}$. For genotype matrices $Z' \in \mathbb{R}^{\tau \times \iota}$ and $Z \in \mathbb{R}^{\nu \times \iota}$, the kernel matrix of the [marker kernel](marker-kernel.md) with variance $s$ between the rows of $Z'$ and of $Z$ is $s Z' Z^\top$.
