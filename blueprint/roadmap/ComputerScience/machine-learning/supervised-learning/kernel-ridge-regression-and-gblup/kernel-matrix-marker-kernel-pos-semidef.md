# Positive semidefiniteness of the marker kernel matrix

Let $\iota$ be a finite set of markers and $s \ge 0$. The [marker kernel](marker-kernel.md) with variance $s$ is a covariance kernel: for every finite index set $\nu$ and genotype matrix $Z \in \mathbb{R}^{\nu \times \iota}$, its kernel matrix $s Z Z^\top$ on the rows of $Z$ is positive semidefinite.
