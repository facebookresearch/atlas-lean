# Likelihood

Consider a Gaussian discriminant model on $\mathbb{R}^\iota$, for a finite index set $\iota$, with a finite set of classes, a prior on classes, class means, and a shared precision matrix $S$. Let $(y_k, x_k)_{k < m}$ be labelled data. The likelihood of the data is the product over examples of the joint density of $(y_k, x_k)$ under the Gaussian discriminant model.
