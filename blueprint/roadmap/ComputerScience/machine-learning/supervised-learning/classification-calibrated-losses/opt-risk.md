# Optimal conditional surrogate risk

For a loss $\varphi : \mathbb{R} \to \mathbb{R}$ and $\eta \in \mathbb{R}$, $H(\eta) = \inf_{\alpha \in \mathbb{R}} C_\eta(\alpha)$, taken as an infimum in $\mathbb{R}$, which is $0$ by convention when $C_\eta$ is unbounded below (the infimum is meaningful when $C_\eta$ is bounded below, as it is for a nonnegative loss and $\eta \in [0, 1]$).

## Sources

- P. L. Bartlett, M. I. Jordan and J. D. McAuliffe, *Convexity, classification, and risk bounds*, Journal of the American Statistical Association 101 (2006) 138–156; numbering of the technical report version <https://www.stat.berkeley.edu/~bartlett/papers/bjm-ccrb-05.pdf>, Section 2.2.
