# Convexity of the softplus function

The function $t \mapsto \log(1 + e^t)$ is convex on $\mathbb{R}$, since its derivative, the sigmoid, is nondecreasing. It is the two-term log-sum-exp function $\log(e^0 + e^t)$.

## Sources

- S. Boyd and L. Vandenberghe, *Convex Optimization*, Cambridge University Press, 2004 (https://web.stanford.edu/~boyd/cvxbook/), §3.1.5 (log-sum-exp is convex) and §7.1.1.
