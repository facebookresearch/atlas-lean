# Path norm with bias

**Path norm with bias** of a two-layer network with outer weights $a_k \in \mathbb{R}$, inner
weights $b_k \in \mathbb{R}^d$ and biases $c_k \in \mathbb{R}$, $k = 1, \dots, m$:
$\sum_k \lvert a_k \rvert (\lVert b_k \rVert_1 + \lvert c_k \rvert)$ (E, Ma and Wu, *The Barron
space and the flow-induced function spaces*, Theorem 4, there with the factor $1/m$).
