# Path-norm ball with bias on a sample

For a sample $x_1, \dots, x_n \in \mathbb{R}^d$ and $Q \in \mathbb{R}$, this is the set of value
vectors $(f(x_1), \dots, f(x_n))$ of the [two-layer ReLU networks with bias](two-layer-re-lubias.md)
$f$ of any width $m \in \mathbb{N}$ with [path norm with bias](path-norm-bias.md) at most $Q$.
