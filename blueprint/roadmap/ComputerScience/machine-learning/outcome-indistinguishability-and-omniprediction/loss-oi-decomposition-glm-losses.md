# Loss OI decomposes into calibration plus multiaccuracy and yields omnipredictors for GLM losses

For every family of losses $\mathcal{L}$ and hypothesis class $\mathcal{C}$, $\varepsilon$-loss OI implies $(\mathcal{L}, \mathcal{C}, \varepsilon)$-omniprediction, and it is not equivalent to omniprediction. Loss OI splits into hypothesis OI, which is equivalent to multiaccuracy for the class $\partial\mathcal{L} \circ \mathcal{C} = \{\partial\ell \circ c\}$ of discrete derivatives $\partial\ell(t) = \ell(t,1) - \ell(t,0)$ composed with the hypotheses, and decision OI, which is equivalent to weighted calibration with respect to the weights $\{\partial\ell \circ k_\ell\}_{\ell \in \mathcal{L}}$; hence $\alpha_1$-weighted calibration for these weights together with $(\partial\mathcal{L} \circ \mathcal{C}, \alpha_2)$-multiaccuracy implies $(\mathcal{L}, \mathcal{C}, \alpha_1 + \alpha_2)$-loss OI. Plain $\varepsilon$-calibration yields that weighted calibration only up to the factor $\sup|\partial\ell \circ k_\ell|$, so it gives $(\mathcal{L}, \mathcal{C}, O(\varepsilon))$-loss OI when these weights are bounded by a constant. For the convex matching losses $\mathcal{L}_{\mathrm{GLM}}$ arising from generalized linear models (squared loss, logistic loss and others), with bounded $\mathcal{C}$, $\alpha_1$-weighted calibration with respect to the weights $k_\ell = (g')^{-1}$ together with $(\mathcal{C}, \alpha_2)$-multiaccuracy implies $(\mathcal{L}_{\mathrm{GLM}}, \mathrm{Lin}(\mathcal{C}, B), \alpha_1 + B\alpha_2)$-loss OI for every $B \ge 1$, without full multicalibration. When $(g')^{-1}$ is bounded (identity, ReLU) plain calibration supplies the weighted calibration; for the logistic loss $k_\ell(p) = \log(p/(1-p))$ is unbounded, so plain calibration does not suffice, and one either uses the weighted calibration error directly or truncates $k_\ell$ to $|k_\ell| \le O(\log(1/\varepsilon))$, which costs at most $\varepsilon$ in loss and leaves that $O(\log(1/\varepsilon))$ weight factor on the calibration error. The loss-OI guarantee above holds for every continuous increasing transfer function $g'$ with $\mathrm{Im}(g') \supseteq [0,1]$, ReLU included. The geometric characterization needs more (Theorem 5.5): if $g'$ is strictly increasing and differentiable, so that $g' : \mathbb{R} \to I = \mathrm{Im}(g')$ is a bijection (this excludes the ReLU, which is constant on $(-\infty, 0]$), and $f(v) = \max_t\,(vt - g(t))$ on $I$ is the Legendre dual of $g$ with Bregman divergence $D_f$, then $\tilde p$ is $(\ell_g, H, \alpha)$-loss OI if and only if $\big|\mathbb{E}[D_f(p^*(x), \tilde p(x))] + \mathbb{E}[D_f(\tilde p(x), g'(h(x)))] - \mathbb{E}[D_f(p^*(x), g'(h(x)))]\big| \le \alpha$ for every $h \in H$, an approximate Pythagorean theorem in $D_f$. Calibrated multiaccuracy can be achieved with computational cost comparable to multiaccuracy.

## Proof sketch

Loss OI implies omniprediction because under simulated outcomes the action $k_\ell(p(x))$ is optimal pointwise, and indistinguishability transfers the inequality to Nature. Every test $\ell(c(x), y) - \ell(k_\ell(p(x)), y)$ is affine in $y$, so its advantage is $\mathbb{E}[(\partial\ell(c(x)) - \partial\ell(k_\ell(p(x))))(y - p(x))]$, a multiaccuracy term for $\partial\ell \circ c$ minus a weighted calibration term. For a matching loss $\ell_g(t, y) = g(t) - yt$ of a GLM with increasing transfer function $g'$, $\partial\ell_g(t) = -t$, so $\partial\mathcal{L} \circ \mathcal{C} = -\mathcal{C}$ and multiaccuracy for $\mathcal{C}$ itself suffices; the remaining term $\mathbb{E}[k_\ell(p(x))(y - p(x))]$, with $k_\ell = (g')^{-1}$, is exactly a weighted calibration error with weight $k_\ell$, bounded by $\sup|k_\ell|$ times the calibration error when $k_\ell$ is bounded. For strictly increasing differentiable $g'$, the Pythagorean identity expresses the same split in the Bregman divergence of the Legendre dual $f = g^*$ of $g$.
