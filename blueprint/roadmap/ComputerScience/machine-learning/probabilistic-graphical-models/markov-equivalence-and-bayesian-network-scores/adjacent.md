# Adjacent vertices in a network structure

Let $V$ be a set of vertices and $\mathrm{Pa}$ a structure assigning to each vertex $v$ a finite
set $\mathrm{Pa}(v) \subseteq V$ of parents. Two vertices $u$ and $w$ are adjacent if they are
joined by an arrow in either direction: $u \in \mathrm{Pa}(w)$ or $w \in \mathrm{Pa}(u)$.
