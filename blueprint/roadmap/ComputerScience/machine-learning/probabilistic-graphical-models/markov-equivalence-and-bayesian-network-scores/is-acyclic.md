# Acyclic network structure

Let $\mathrm{Pa}$ be a structure on a set $V$, assigning to each vertex $w$ a finite set
$\mathrm{Pa}(w)$ of parents, with arrows $u \to w$ for $u \in \mathrm{Pa}(w)$. The structure is
acyclic if it has no directed cycle: no vertex can be reached from itself along one or more
arrows (in particular no vertex is its own parent).
