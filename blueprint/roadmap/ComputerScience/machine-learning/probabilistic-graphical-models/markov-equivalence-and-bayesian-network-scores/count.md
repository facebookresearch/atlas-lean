# Count of cases matching a configuration

Let $V$ be a set of variables, each $v$ taking values in a set $\sigma_v$, and $D$ a finite list
of cases $x \in \prod_v \sigma_v$. For a finite $S \subseteq V$ and a configuration $c$ of $S$,
$N_S(c)$ is the number of cases in $D$, counted with multiplicity, that take the values $c$ on
the variables of $S$.
