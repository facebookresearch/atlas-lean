# Score equivalence of BDe

Let $V$ be a finite set of variables, each with a finite nonempty set of values, let $p$ be a prior joint distribution with $p(x) > 0$ for every joint value $x$, let $\alpha > 0$ be an equivalent sample size, and let $D$ be a list of complete observations. If two acyclic parent-set structures on $V$ have the same skeleton and the same v-structures, then they have the same BDe score: the Bayesian Dirichlet score of $D$ with hyperparameters $\alpha\, p(\cdot)$ marginalized to each family.
