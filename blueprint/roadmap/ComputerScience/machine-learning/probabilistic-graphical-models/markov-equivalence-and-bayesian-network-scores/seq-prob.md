# Sequential Pólya–Dirichlet product of the data

Let $V$ be a finite set of variables with finite value sets and $\mathrm{Pa}$ a structure on $V$
with family hyperparameters $\alpha$. The sequential Pólya–Dirichlet product of a finite list of
cases $D$ is its [product after the empty list of prior cases](seq-prob-after.md): each case
contributes its [prediction factor](predictive.md) given the cases before it. It is a genuine
probability of the data only when $\mathrm{Pa}$ is a DAG.
