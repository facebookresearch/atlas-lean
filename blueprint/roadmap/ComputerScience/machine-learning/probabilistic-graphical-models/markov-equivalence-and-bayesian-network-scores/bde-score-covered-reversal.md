# Covered-edge reversal preserves the BDe score

**Covered-edge reversal preserves the BDe score**: let $V$ be a finite set of variables, each $v$
taking values in a finite nonempty set $\sigma_v$, let $p : \prod_v \sigma_v \to \mathbb{R}$ with
$p(x) > 0$ for all $x$ (a prior when $\sum_x p(x) = 1$), $\mathrm{ess} > 0$ and $D$ a finite list
of cases. If the structure $\mathrm{Pa}'$ is obtained from $\mathrm{Pa}$ by a
[covered-edge reversal](covered-reversal.md), then $\mathrm{Pa}$ and $\mathrm{Pa}'$ have the same
[BDe score](bde-score.md).
