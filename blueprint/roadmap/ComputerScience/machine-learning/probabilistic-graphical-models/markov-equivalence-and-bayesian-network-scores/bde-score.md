# BDe network score

Let $V$ be a finite set of variables, each $v$ taking values in a finite set $\sigma_v$, let
$p : \prod_v \sigma_v \to \mathbb{R}$, $\mathrm{ess} \in \mathbb{R}$ and $D$ a finite list of
cases. The BDe score of a structure $\mathrm{Pa}$ is its [BD score](bd-score.md) with the
[BDe hyperparameters](bde-hyper.md) of each family $\{v\} \cup \mathrm{Pa}(v)$.
