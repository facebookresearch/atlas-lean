# Covered-edge reversals preserve the BDe score

Let $V$ be a finite set of variables, each $v$ taking values in a finite nonempty set $\sigma_v$,
let $p : \prod_v \sigma_v \to \mathbb{R}$ with $p(x) > 0$ for all $x$, $\mathrm{ess} > 0$ and $D$ a
finite list of cases. Structures connected by a finite (possibly empty) sequence of
[covered-edge reversals](covered-reversal.md) have the same [BDe score](bde-score.md).
