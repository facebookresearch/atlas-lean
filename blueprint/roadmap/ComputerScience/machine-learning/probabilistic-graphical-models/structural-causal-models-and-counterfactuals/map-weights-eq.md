# Push-forward of the noise law is the induced law

For a finite structural causal model with finite noise sets and values in a set with decidable equality, the push-forward of the noise law of node $t$ along its structural function at parent values $w$ gives each value $a$ the total noise weight $\sum_v [f_t(w, v) = a]\, \mu_t(v)$, summed over all noise values.
