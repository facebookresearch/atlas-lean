# Constant-response causal model

The constant-response model is the binary structural causal model on $X \to Y$ with noise $u = (u_X, u_Y) \in \{0,1\}^2$, uniform weights $p_U(u) = 1/4$, and structural equations $X = u_X$ and $Y = u_Y$, so that $Y$ does not depend on $X$ (the response types "always 1" and "always 0").
