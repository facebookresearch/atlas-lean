# Parent values in a structural causal model

Let $M$ be a Markovian structural causal model on the nodes $0, \dots, n - 1$ with values in
$\alpha$. For a node $k$ and a full assignment $x \in \alpha^n$, the parent values of $k$ in $x$
are $x_{\mathrm{pa}(k)} = (x_j)_{j \in \mathrm{pa}(k)}$.
