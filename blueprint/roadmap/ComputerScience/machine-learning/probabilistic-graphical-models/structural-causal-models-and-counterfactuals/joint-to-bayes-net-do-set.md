# Network of a submodel

Let $M$ be a Markovian structural causal model on the nodes $0, \dots, n - 1$ with values in a
nonempty set $\alpha$, $W$ a finite set of nodes and $w \in \alpha^n$. The
[causal network](to-bayes-net.md) of the [submodel](do-set.md) of $\mathrm{do}(X_W = w)$ has the
same joint distribution as the
[mutilated network](../causal-bayesian-networks/mutilate-set.md) of $\mathrm{do}(X_W = w)$ in the
causal network of $M$.
