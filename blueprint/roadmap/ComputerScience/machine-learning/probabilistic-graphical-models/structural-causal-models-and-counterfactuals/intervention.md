# Interventions on a binary structural causal model

An intervention on the two observed nodes $X \to Y$ is a pair $(i_X, i_Y)$ with each component either a value in $\{0,1\}$ or "none". A value $i_X = x$ sets $X := x$ and a value $i_Y = y$ sets $Y := y$; "none" keeps the structural equation. The pair (none, none) is the observational regime, and the four kinds of pair cover every intervention on one or both nodes.
