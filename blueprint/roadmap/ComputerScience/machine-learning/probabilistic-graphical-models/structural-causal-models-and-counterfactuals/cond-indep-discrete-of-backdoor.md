# The back-door criterion implies conditional ignorability

For a finite structural causal model with values in a finite nonempty set, finite noise sets and independent noise laws, let $t$ be a treatment node, $y$ an outcome node and $Z$ a set of nodes containing no descendant of $t$ in the induced graph that blocks every path between $t$ and $y$ starting with an edge into $t$. Then the treatment event $[X_t = a_1]$ is conditionally independent of the potential outcome $g(Y_a)$ given the values on $Z$.
