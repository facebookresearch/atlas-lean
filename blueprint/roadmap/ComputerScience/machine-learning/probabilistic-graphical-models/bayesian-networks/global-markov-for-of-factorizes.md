# Factorization implies the global Markov property

**Factorization implies the global Markov property** ((F) ⇒ (G)): let $\alpha$ be a finite
nonempty type and let $B$, $B'$ be Bayesian networks on the nodes $0, \dots, n - 1$ with values
in $\alpha$ and the same parent sets. Then the joint distribution of $B'$ has the global Markov
property for the graph of $B$.
