# The global Markov property implies the local one

**The global Markov property implies the local one** ((G) ⇒ (L)): let $\alpha$ be a finite type,
$P : \alpha^n \to \mathbb{R}$ and $B$ a Bayesian network on the nodes $0, \dots, n - 1$. If $P$
has the global Markov property for the graph of $B$, then it has the local Markov property for
the graph of $B$.
