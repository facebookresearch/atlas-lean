# A marginal depends only on the fixed variables

Let $\alpha$ be a finite type, $P : \alpha^n \to \mathbb{R}$ and $S$ a finite set of nodes, and
write $P(x_S)$ for the sum of $P(y)$ over the configurations $y$ that agree with $x$ on $S$. If
$x, y \in \alpha^n$ satisfy $x_i = y_i$ for all $i \in S$, then $P(x_S) = P(y_S)$.
