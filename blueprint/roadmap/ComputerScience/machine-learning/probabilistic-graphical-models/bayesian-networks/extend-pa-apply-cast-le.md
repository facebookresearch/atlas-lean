# The extension has the prescribed parent values

Let $\alpha$ be a nonempty type, let $\mathrm{pa}(k) \subseteq \{0, \dots, k - 1\}$ be parent
sets, let $k$ be a node and $z$ values in $\alpha$ for the parents of $k$. The
[extension](extend-pa.md) of $z$ takes the value $z_j$ at every parent $j$ of $k$.
