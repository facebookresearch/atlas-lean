# Extension of parent values

Let $\alpha$ be a nonempty type with a fixed element $a_0$, and let
$\mathrm{pa}(k) \subseteq \{0, \dots, k - 1\}$ be parent sets on the nodes $0, \dots, n - 1$. For a
node $k$ and values $z = (z_j)_{j \in \mathrm{pa}(k)}$ in $\alpha$, the extension of $z$ is the
configuration $x \in \alpha^n$ with $x_i = z_i$ if $i$ is a parent of $k$ and $x_i = a_0$
otherwise.
