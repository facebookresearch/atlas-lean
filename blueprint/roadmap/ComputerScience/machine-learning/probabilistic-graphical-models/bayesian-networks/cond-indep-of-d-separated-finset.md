# Global Markov property for finite sets of nodes

Let $B$ be a Bayesian network on the nodes $0, \dots, n - 1$ with values in a finite nonempty
type $\alpha$. If $X, Y, Z$ are finite sets of nodes such that $Z$ d-separates $X$ from $Y$ in
the graph of $B$, then $X$ and $Y$ are conditionally independent given $Z$ under the joint
distribution of $B$. The same holds for arbitrary sets of nodes
([the global Markov property](cond-indep-of-d-separated.md)).
