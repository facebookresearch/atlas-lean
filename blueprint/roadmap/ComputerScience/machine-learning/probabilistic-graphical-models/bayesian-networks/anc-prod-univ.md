# The ancestral product on all nodes is the joint

Let $B$ be a Bayesian network on the nodes $0, \dots, n - 1$ with values in a finite nonempty
type $\alpha$, with joint distribution $P$. The [ancestral product](anc-prod.md) $Q_A$ of $B$ on
the set $A = \{0, \dots, n - 1\}$ of all nodes is the joint distribution: $Q_A(x) = P(x)$ for
every $x \in \alpha^n$.
