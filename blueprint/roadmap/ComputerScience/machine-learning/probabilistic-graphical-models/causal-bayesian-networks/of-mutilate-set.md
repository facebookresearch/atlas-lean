# Descendants in the mutilated network are descendants in the original

Let $B$ be a Bayesian network with values in $\alpha$, $W$ a finite set of nodes and
$w \in \alpha^n$. If $j$ is a descendant of $i$ in the [mutilated network](mutilate-set.md) of
$\mathrm{do}(X_W = w_W)$, where the arrows into $W$ are removed, then $j$ is a descendant of $i$
in $B$.
