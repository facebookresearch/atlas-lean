# Arrows of the mutilated network

Let $B$ be a Bayesian network on the nodes $0, \dots, n - 1$ with values in $\alpha$, $W$ a finite
set of nodes and $w \in \alpha^n$. The arrows of the [mutilated network](mutilate-set.md) of
$\mathrm{do}(X_W = w)$ are the arrows $i \to j$ of the graph of $B$ with $j \notin W$.
