# Skeleton theorem under faithfulness

Skeleton theorem under faithfulness (Kalisch and Bühlmann 2007, Proposition 1, skeleton part): for a Bayesian network $b$ and a probability law $P$ on assignments with values in a finite set ($P \ge 0$, $\sum_x P(x) = 1$) that is faithful to the graph of $b$, the adjacency phase of the PC algorithm run with the population oracle of $P$ returns the skeleton of $b$.
