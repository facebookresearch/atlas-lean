# Composition

**Composition** `Y_{x, Z_x} = Y_x` (Pearl 2000, p. 229, used in P01's proof of Theorem 1): at every
noise value `u`, setting the mediator to the value `Z_x(u)` it takes under `do(X = x)` changes
nothing, `X_{t ← x, m ← Z_x(u)}(u) = X_{t ← x}(u)`.

Equivalently, with the mediator value named: if `Z_x(u) = b`, then
`X_{t ← x, m ← b}(u) = X_{t ← x}(u)`.
