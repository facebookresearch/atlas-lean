# Conditional independence of functions of the noise

Conditional independence `A ⫫ B | C` of functions `A`, `B`, `C` of the noise, in product form: for
all values `a`, `b`, `c`, `P(A = a, B = b, C = c) P(C = c) = P(A = a, C = c) P(B = b, C = c)`.

The noise laws have finite support, so only finitely many values of `A`, `B` and `C` have positive
probability.
