# Number of restrictions of a multiclass concept class to a sample

Let $\beta$ be a finite label type, $C$ a class (possibly infinite) of functions $\alpha \to \beta$ and $s \subseteq \alpha$ a finite sample. The trace count of $C$ on $s$ is the number of labelings of $s$ realized by some concept:

$$\#\{\, g : s \to \beta \;:\; \exists c \in C,\ \forall x \in s,\ c(x) = g(x) \,\} \in \mathbb{N}.$$
