# Trace count of a finite class

Let $\beta$ be a finite label type and $H$ a finite set of functions $\alpha \to \beta$. For every finite sample $s \subseteq \alpha$, the number of labelings of $s$ realized by some member of $H$ equals the number of distinct restrictions $h|_s$ for $h \in H$:

$$\#\{\, g : s \to \beta : \exists h \in H,\ h|_s = g \,\} = \#\{\, h|_s : h \in H \,\}.$$
