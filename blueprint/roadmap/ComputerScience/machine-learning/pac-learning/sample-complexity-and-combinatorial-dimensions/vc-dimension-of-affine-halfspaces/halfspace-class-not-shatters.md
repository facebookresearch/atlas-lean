# Affine halfspaces shatter no set of d + 2 points

Let $d \in \mathbb{N}$ and let $s \subseteq \mathbb{R}^d$ be a finite set with exactly $d + 2$ points. Then the class of affine halfspaces $x \mapsto [0 < \langle w, x\rangle + b]$ does not shatter $s$.

The points are affinely dependent, so by Radon's theorem $s$ splits into two parts whose convex hulls meet; no affine functional is positive on one part and nonpositive on the other at a common point.
