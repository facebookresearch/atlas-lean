# Concept class of affine halfspaces

For $d \in \mathbb{N}$, the class of affine halfspaces in $\mathbb{R}^d$ (Euclidean space) is the binary concept class of all classifiers of the form

$$x \mapsto \big[\, 0 < \langle w, x\rangle + b \,\big], \qquad w \in \mathbb{R}^d,\ b \in \mathbb{R},$$

which label a point true exactly when it lies on the strict positive side of the affine functional $x \mapsto \langle w, x\rangle + b$.
