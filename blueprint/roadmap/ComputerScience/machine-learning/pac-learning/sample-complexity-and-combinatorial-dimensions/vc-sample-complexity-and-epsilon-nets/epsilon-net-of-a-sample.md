# Epsilon-net of a sample for a class of events

Let $G$ be a class of functions $Z \to \{0,1\}$ on a measurable space $Z$, $\mu$ a probability measure on $Z$ and $\varepsilon > 0$. A finite sequence $S = (S_1, \dots, S_m) \in Z^m$ is an $\varepsilon$-net for $G$ under $\mu$ if every $g \in G$ with $\mu(g = 1) \ge \varepsilon$ takes the value $1$ at some point $S_i$.
