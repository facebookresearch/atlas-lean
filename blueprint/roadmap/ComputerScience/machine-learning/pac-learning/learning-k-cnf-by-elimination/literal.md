# Literal over $t$ Boolean variables

A literal over the variables $p_0, \dots, p_{t-1}$ is a pair $(i, b)$ with $i < t$ and
$b \in \{\mathrm{true}, \mathrm{false}\}$: the variable $p_i$ when $b$ is true and its negation
$\bar p_i$ when $b$ is false.

## Sources

- L. G. Valiant, *A theory of the learnable*, Communications of the ACM 27 (1984), 1134-1142, Section 5.
