# The elimination learner is consistent with the k-CNF class

On every labelled sample realizable by a $k$-CNF function $f$, the elimination learner outputs a
$k$-CNF function that agrees with every label, i.e. it is consistent with the class of $k$-CNF
functions: its output is true at the positive examples,
which satisfy it, and false at the negative examples, because it implies $f$.

## Sources

- L. G. Valiant, *A theory of the learnable*, Communications of the ACM 27 (1984), 1134-1142, Section 5, proof of Theorem A.
