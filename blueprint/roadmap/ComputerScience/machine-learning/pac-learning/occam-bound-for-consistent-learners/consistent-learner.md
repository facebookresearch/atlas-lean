# A consistent learner for a finite class

For a nonempty finite set $H$ of hypotheses and a sample size $m$: on a sample realizable by $H$,
output a member of $H$ that agrees with every labelled example (chosen by the axiom of choice);
on any other sample, output a fixed member of $H$. (On samples realizable by $H$ the output is therefore consistent; elsewhere it is arbitrary.)
