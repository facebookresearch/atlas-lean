# Number of samples on which a hypothesis is consistent

Let $X$ be a finite set, $c, h : X \to \{0, 1\}$ and $m \in \mathbb{N}$. A hypothesis $h$ is consistent with the target $c$ on a sample $s \in X^m$ when $h(s_i) = c(s_i)$ for every $i$. The number of such samples is $a^m$, where $a$ is the number of points of $X$ at which $h$ and $c$ agree.
