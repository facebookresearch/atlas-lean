# Trace count is bounded by the growth function

Let $C$ be a binary concept class on $\alpha$ and $s \subseteq \alpha$ a finite sample. The number of distinct traces $|C|_s|$ that $C$ realizes on $s$ is at most the growth function at the sample size:

$$|C|_s| \le \tau_C(|s|),$$

where $\tau_C(m)$ is the supremum, in $\mathbb{N}$, of $|C|_{s'}|$ over all $m$-element subsets $s' \subseteq \alpha$.
