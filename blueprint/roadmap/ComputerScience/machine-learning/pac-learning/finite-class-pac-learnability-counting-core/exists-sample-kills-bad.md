# A sample that rules out every wrong hypothesis of a finite class

Let $X$ be a finite set, $c : X \to \{0, 1\}$ a target, $C$ a finite class of hypotheses $X \to \{0, 1\}$, and $m \in \mathbb{N}$ with $|C|\,(|X| - 1)^m < |X|^m$. Then some sample $s \in X^m$ rules out every wrong hypothesis of $C$: every $h \in C$ that agrees with $c$ at all sampled points equals $c$.
