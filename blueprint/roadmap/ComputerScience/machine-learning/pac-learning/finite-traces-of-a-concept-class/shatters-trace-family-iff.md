# Shattering by the trace family is shattering by the class

Let $C$ be a binary concept class on $\alpha$, $s \subseteq \alpha$ a finite sample and $t \subseteq s$. Then the trace family $C|_s$ shatters $t$ (every subset of $t$ is $t \cap u$ for some $u \in C|_s$) if and only if $C$ shatters $t$ viewed as a subset of $\alpha$: for every $W' \subseteq t$ there is $c \in C$ with $c^{-1}(\text{true}) \cap t = W'$.
