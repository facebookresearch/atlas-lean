# Natarajan lemma for finite classes

Let $\beta$ be a finite label type with $k = |\beta|$ and $H$ a finite set of functions $\alpha \to \beta$ with Natarajan dimension at most $d$ (no set of $d+1$ points is N-shattered by $H$). Then for every nonempty finite sample $s \subseteq \alpha$,

$$\#\{\, h|_s : h \in H \,\} \le |s|^{d}\, k^{2d} .$$


## Sources

B. K. Natarajan, *On learning sets and functions*, Machine Learning 4 (1989), 67–97. S. Shalev-Shwartz and S. Ben-David, *Understanding Machine Learning: From Theory to Algorithms*, Cambridge University Press, 2014, Chapter 29.
