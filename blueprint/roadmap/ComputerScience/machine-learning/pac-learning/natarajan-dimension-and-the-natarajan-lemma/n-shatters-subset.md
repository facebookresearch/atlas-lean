# N-shattering is hereditary

Let $C$ be a class of functions $\alpha \to \beta$ and $t \subseteq s$ finite subsets of $\alpha$. If $C$ N-shatters $s$, then $C$ N-shatters $t$.

A class $C$ N-shatters a finite set $s$ when there are labelings $f_0, f_1 : \alpha \to \beta$ with $f_0(x) \ne f_1(x)$ for all $x \in s$ such that for every $u \subseteq s$ some $h \in C$ agrees with $f_1$ on $u$ and with $f_0$ on $s \setminus u$.
