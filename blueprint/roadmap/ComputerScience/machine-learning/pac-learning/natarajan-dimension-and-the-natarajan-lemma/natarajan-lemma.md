# Natarajan lemma

Let $\beta$ be a finite label type with $k = |\beta|$, and let $C$ be a class (possibly infinite) of functions $\alpha \to \beta$ with Natarajan dimension at most $d$: no set of $d + 1$ points is N-shattered by $C$. Then for every nonempty finite sample $s \subseteq \alpha$ the number of distinct restrictions of $C$ to $s$ satisfies

$$\#\{\, c|_s : c \in C \,\} \le |s|^{d}\, k^{2d} .$$

A set $s$ is N-shattered by $C$ when there are labelings $f_0, f_1$ disagreeing at every point of $s$ such that every $u \subseteq s$ is realized by a concept agreeing with $f_1$ on $u$ and with $f_0$ on $s \setminus u$. The sample must be nonempty: on the empty sample there is one restriction while $0^d k^{2d} = 0$ for $d \ge 1$.


## Sources

B. K. Natarajan, *On learning sets and functions*, Machine Learning 4 (1989), 67–97. S. Shalev-Shwartz and S. Ben-David, *Understanding Machine Learning: From Theory to Algorithms*, Cambridge University Press, 2014, Chapter 29.
