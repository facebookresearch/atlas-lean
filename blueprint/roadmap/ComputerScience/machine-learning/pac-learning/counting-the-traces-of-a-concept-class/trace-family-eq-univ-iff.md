# Realizing every trace is shattering

For a binary concept class $C$ on $\alpha$ and a finite sample $s \subseteq \alpha$, the trace family $C|_s$ is the set of all subsets of $s$ if and only if $C$ shatters $s$, i.e. for every $W' \subseteq s$ there is $c \in C$ with $c^{-1}(\text{true}) \cap s = W'$.
