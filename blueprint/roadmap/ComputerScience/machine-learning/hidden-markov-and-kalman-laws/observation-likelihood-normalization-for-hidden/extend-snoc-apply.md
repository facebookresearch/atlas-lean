# Extension of an appended string agrees with the prefix extension

Let $t \in \mathbb{N}$, $v = (v_0, \dots, v_t) \in O^{t+1}$ and $o \in O$, and let $v o = (v_0, \dots, v_t, o) \in O^{t+2}$. Then the extended streams agree on $0, \dots, t$:

$$\overline{v o}_i = \bar v_i \quad \text{for every } i \le t,$$

where a string $w$ of length $r + 1$ is extended by $\bar w_i = w_i$ for $i \le r$ and $\bar w_i = w_0$ for $i > r$.
