# Prior-variance formula for the final state

Let $F, H_0, H_1, Q, R_0, R_1, m_0, P_0$ be real numbers, read as the parameters of the scalar linear model $x_1 = F x_0 + w$, $y_0 = H_0 x_0 + v_0$, $y_1 = H_1 x_1 + v_1$: prior mean $m_0$ and variance $P_0$ of $x_0$, process variance $Q$ and observation variances $R_0, R_1$. The prior-variance formula for the final state $x_1$ is

$$F^2 P_0 + Q .$$

This is a formula in the parameters. It is the variance $\operatorname{Var}(x_1)$ when $x_0$ has variance $P_0$, the process noise $w$ has variance $Q$, and $x_0$ and $w$ are independent.
