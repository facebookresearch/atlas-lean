# Telescoping bound with nondecreasing weights

Let $a, w : \mathbb{N} \to \mathbb{R}$, $D \in \mathbb{R}$ and $T \ge 1$. Assume $a_t \le D^2$ for all $t$, the weights are nonnegative ($0 \le w_t$) and nondecreasing ($w_t \le w_{t+1}$ for all $t$). Then

$$\sum_{t=0}^{T-1} (a_t - a_{t+1})\, w_t \le (D^2 - a_T)\, w_{T-1} .$$
