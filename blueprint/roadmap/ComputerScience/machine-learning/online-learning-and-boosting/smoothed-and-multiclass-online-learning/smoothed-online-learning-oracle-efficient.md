# Smoothed online learning is as easy as statistical learning

Let $\mathcal{F}$ be a class of predictors $X \to [-1,1]$, let $\mathrm{vc}(\mathcal{F}, \delta)$ be its scale-sensitive VC dimension at scale $\delta > 0$, and let $\sigma \in (0,1]$; the adversary's context distributions are $\sigma$-smooth with respect to a known base measure $\mu$. All regret rates below require a growth bound on $\mathrm{vc}(\mathcal{F}, \delta)$; without one there is no sublinear rate, since for atomless i.i.d. contexts, fair coin labels and the class of all measurable binary predictors, some predictor interpolates every sample in hindsight while any learner errs on half the rounds in expectation. For an $L$-Lipschitz loss, the minimax regret against $\sigma$-smooth adaptive adversaries is at most $L\log^{3/2}(T)\log(T/\sigma)\inf_{\alpha > 0}\big(T\alpha + \sqrt{T}\int_\alpha^2 \sqrt{\mathrm{vc}(\mathcal{F}, c\delta)}\,d\delta\big)$ up to a constant factor, which is $\lesssim L\log^{3/2}(T)\log(T/\sigma)\sqrt{dT}$ if $\mathrm{vc}(\mathcal{F}, \delta) \le d\log(1/\delta)$ and $\lesssim L\log^{3/2}(T)\log(T/\sigma)\,T^{\max(1/2,\,1-1/p)}$ if $\mathrm{vc}(\mathcal{F}, \delta) \lesssim \delta^{-p}$ (Theorem 3), so up to logarithmic factors smoothed online learning is as easy as i.i.d. learning, with nearly optimal dependence on $T$ and $\sigma$. Moreover there are oracle-efficient algorithms using an empirical risk minimization oracle. An improper relaxation-based algorithm, for an $L$-Lipschitz loss that is convex in the prediction $\hat y \in [-1,1]$, has optimal dependence on $T$, with expected regret $\lesssim L\,(T\log(T)/\sigma)^{\max(1/2,\,1-1/p)}$ when $\mathrm{vc}(\mathcal{F}, \delta) \lesssim \delta^{-p}$ for some $p > 0$ (Theorem 7), that is $\sigma^{-1/2}$ times the i.i.d. rate up to logarithmic factors for $p \le 2$. A proper follow-the-perturbed-leader algorithm makes a single (approximate, with additive slack $\zeta$) oracle call per round; for binary $\mathcal{F}$ and labels with $\mathrm{vc}(\mathcal{F}) \le d$ its expected regret is $\lesssim \sqrt{dT\log(T)/\sigma} + \zeta T$ (Theorem 9), the optimal horizon dependence for classification, and for a loss $[-1,1] \times [-1,1] \to [0,1]$ that is $L$-Lipschitz in both arguments it is $\lesssim T^{2/3}\log(T)\,\sigma^{-1/3} + \zeta T$ when $\mathrm{vc}(\mathcal{F}, \delta) \lesssim \delta^{-p}$ with $p < 2$, and $o(T)$ for suitable parameters when $2 \le p < \infty$ (Theorem 10). Both oracle-efficient algorithms have exponentially worse ($\mathrm{poly}(1/\sigma)$ instead of $\log(1/\sigma)$) dependence on $\sigma$ than the minimax rate. In the worst case over classes, every algorithm with an ERM oracle, proper or improper, needs total time $\tilde\Omega(\sigma^{-1/2})$ to guarantee expected regret below $T/200$ (Theorem 11): the lower bound is witnessed by binary classes with $|\mathcal{F}| \le 1/\sigma$ on a domain of size $1/\sigma$, on which every adaptive adversary is $\sigma$-smooth. This matches the upper bounds up to a polynomial factor and exhibits a statistical-computational gap.

## Proof sketch

By the coupling lemma, each smooth instance is one of $k = O(\log(T)/\sigma)$ i.i.d. proposals from $\mu$, so the adaptive problem embeds into an online problem over a fixed i.i.d. pool of size $Tk$, whose sequential complexity is controlled by the statistical complexity of $\mathcal{F}$ on $Tk$ points. The improper algorithm instantiates the relaxation method of Rakhlin, Shamir and Sridharan with hallucinated future samples drawn from $\mu$; the proper algorithm is follow-the-perturbed-leader whose perturbation is a Gaussian white noise with intensity approximated by $\mu$, so each round needs a single ERM call on the history plus the perturbation.
