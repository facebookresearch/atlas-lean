# Query and communication complexity of approximate correlated equilibria

Consider normal-form games with $m$ players and $N$ actions per player whose payoffs $u_i : [N]^m \to [0,1]$ are normalized to $[0,1]$, so that $\varepsilon$ is an additive error on that scale (multiplying all payoffs by $R$ turns an $\varepsilon$-approximate equilibrium of the original game into an $R\varepsilon$-approximate one, so the tolerance must be read relative to the payoff range). Here an **$\varepsilon$-approximate correlated equilibrium** is a distribution $\mathcal{D}$ over action profiles such that for every player $i$ and every deviation map $\phi_i : [N] \to [N]$, applied to all recommendations at once, $\mathbb{E}_{a \sim \mathcal{D}}[u_i(\phi_i(a_i), a_{-i})] \le \mathbb{E}_{a \sim \mathcal{D}}[u_i(a)] + \varepsilon$ (Peng and Rubinstein, Definition 2.2; Dagan, Daskalakis, Fishelson and Golowich, Definition 2.4). For $\varepsilon > 0$ this is stronger than the condition of the linked correlated-equilibrium page, which bounds the gain of each single replacement of one recommended action by another: pairwise gains of at most $\varepsilon$ can add up over the $N$ recommended actions; at $\varepsilon = 0$ the two coincide. For every constant $\varepsilon > 0$ and a constant number of players: uncoupled no-swap-regret dynamics converge, with high probability, to the set of $\varepsilon$-approximate correlated equilibria within $(\log N)^{O(1/\varepsilon)}$ rounds (Peng and Rubinstein, Corollary 1.3); there is a randomized communication protocol that computes an $\varepsilon$-approximate correlated equilibrium with probability $1 - \delta$ using $(\log(N)/\varepsilon)^{O(1/\varepsilon)} \cdot O(m\log(m/\delta))$ bits (Dagan et al., Corollary 3.7), and for two players one using $(\log N)^{O(1/\varepsilon)}$ bits with probability $1 - N^{-\omega(1)}$ (Peng and Rubinstein, Corollary 1.5), which is polylogarithmic in $N$ and resolves an open problem; and there is a randomized algorithm in the payoff-query model that computes one with probability $1 - \delta$ using $(\log(N)/\varepsilon)^{O(1/\varepsilon)} \cdot O(mN\log(m/\delta))$ payoff queries (Dagan et al., Corollary 3.9), respectively with probability $1 - (mN)^{-\omega(1)}$ using $mN(\log(mN))^{O(1/\varepsilon)}$ queries (Peng and Rubinstein, Corollary 1.4), that is $N$ times a polylogarithmic factor, giving the first separation between $\varepsilon$-correlated and $\varepsilon$-Nash equilibria in query complexity. For extensive-form games with perfect recall and utilities normalized to $[0,1]$ (so that $\varepsilon$ is an additive error on that scale), an $\varepsilon$-approximate normal-form correlated equilibrium, with deviation maps on the players' pure policies, can be computed in time $\mathrm{poly}\big(m, A^\star, (I^\star\log A^\star/\varepsilon)^{1/\varepsilon}\big)$ (Dagan et al., Theorem 3.11), where $m$ is the number of players, $I^\star$ the largest number of information sets and $A^\star$ the largest number of actions at an information set of any player; this is polynomial in the game tree for every constant $\varepsilon$ (a polynomial-time approximation scheme), although such equilibria were conjectured to be intractable.

## Proof sketch

Each player runs the fast swap-regret algorithm on estimated losses; the empirical distribution of joint play is an approximate correlated equilibrium whose error is the maximum swap regret. Rewards are estimated by sampling the other players' mixed strategies, which costs few payoff queries or few bits per round. For extensive-form games, counterfactual regret minimization supplies an efficient external-regret learner over the exponentially many pure strategies, and the tree reduction turns it into a swap-regret learner of the same per-round cost.
