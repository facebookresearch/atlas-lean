# The Needham–Schroeder public-key protocol

In the Needham–Schroeder public-key protocol an initiator $A$ and a responder $B$, each knowing the other's public key, exchange the
[Dolev–Yao messages](dolev-yao-terms-and-deduction.md)

$$1.\ A \to B : \mathrm{aenc}(\langle A, N_a\rangle, \mathrm{pk}(B)) \qquad 2.\ B \to A : \mathrm{aenc}(\langle N_a, N_b\rangle, \mathrm{pk}(A)) \qquad 3.\ A \to B : \mathrm{aenc}(N_b, \mathrm{pk}(B)),$$

where $N_a$ and $N_b$ are fresh nonces generated by $A$ and $B$. On receiving message 2, $A$ checks that its first component is $N_a$ and returns the second
component, whatever it is, in message 3; $B$ checks that message 3 contains $N_b$. The protocol is intended to give mutual authentication of $A$ and $B$ and the
secrecy of $N_a$ and $N_b$, against an attacker who controls the network: it may intercept, reroute and modify messages, and may itself be a principal with a
key pair. Lowe's fix adds the responder's identity to the second message, $\mathrm{aenc}(\langle N_a, \langle N_b, B\rangle\rangle, \mathrm{pk}(A))$.
