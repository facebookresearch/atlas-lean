# Security typing of Boolean expressions

The judgment that an IMP Boolean expression has level $l$ under policy $\Gamma$, meaning it reads only variables at or below $l$. It is generated by:

- a Boolean constant has every level $l$;
- $a = b$ and $a \le b$ have level $l$ when the arithmetic expressions $a$ and $b$ both have level $l$;
- $\lnot b$ has level $l$ when $b$ has level $l$;
- $a \land b$ has level $l$ when $a$ and $b$ both have level $l$.
