# Security typing of commands

A syntax-directed security judgment for IMP commands under policy $\Gamma$ with an explicit program-counter level $pc$. It is generated by:

- $\mathrm{skip}$ is secure at every $pc$;
- $x := e$ is secure at $pc$ when $pc \le \Gamma(x)$ and $e$ has level $\Gamma(x)$;
- $a; b$ is secure at $pc$ when $a$ and $b$ are secure at $pc$;
- $\mathrm{if}\ e\ \mathrm{then}\ a\ \mathrm{else}\ b$ is secure at $pc$ when $e$ has some level $l$ and $a$ and $b$ are secure at $pc \sqcup l$;
- $\mathrm{while}\ e\ \mathrm{do}\ a$ is secure at $pc$ when $e$ has some level $l$ and $a$ is secure at $pc \sqcup l$.
