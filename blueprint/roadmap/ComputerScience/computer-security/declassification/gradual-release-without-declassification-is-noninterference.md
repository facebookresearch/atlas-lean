# Without declassification, gradual release is noninterference

**Proposition.** If a command $c$ contains no $\mathrm{declassify}$ assignment, then $c$ satisfies [gradual release](gradual-release.md) if and only if $c$ satisfies
[noninterference](noninterference-as-constant-knowledge.md).
