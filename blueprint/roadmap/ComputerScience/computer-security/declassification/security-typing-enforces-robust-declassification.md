# A security type system enforces robust declassification

**Theorem.** If $\Gamma, pc \vdash c[\vec\bullet]$ in the [typing rules for robust declassification](typing-rules-for-robust-declassification.md), then $c[\vec\bullet]$ satisfies
[robustness](robust-declassification.md) with respect to fair attacks.

## Depends on

- [Robust declassification](robust-declassification.md)
- [Typing rules for robust declassification](typing-rules-for-robust-declassification.md)

## Proof depends on

- [Typable contexts are robust against attacks that change low-integrity data](typable-contexts-resist-attacks-on-low-integrity-data.md)
- [Fair attacks are A-attacks](fair-attacks-are-a-attacks.md)

## Sources
