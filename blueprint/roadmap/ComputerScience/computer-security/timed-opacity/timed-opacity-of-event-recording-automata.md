# Timed opacity of event-recording automata is undecidable

Whether an attacker who observes only some actions of a timed automaton, together with their time stamps, can never be sure that the run belongs to a secret is undecidable, already when both the system and the secret are given by event-recording automata.

**Timed automata.** A timed automaton $A = (L, \ell_0, X, \Sigma_\tau, E, F)$ has finitely many locations $L$, an initial location $\ell_0$, finitely many clocks $X$, a finite alphabet $\Sigma$ with $\Sigma_\tau = \Sigma \cup \{\tau\}$, edges $(\ell, g, a, R, \ell')$ with a clock guard $g$, a label $a \in \Sigma_\tau$ and a set $R \subseteq X$ of clocks reset, and accepting locations $F$; time is dense. A finite timed word over $\Sigma$ is a finite sequence $(a_1, t_1) \cdots (a_n, t_n)$ of letters $a_i \in \Sigma$ with time stamps $t_i \in \mathbb{R}_{\geq 0}$ forming an increasing sequence; the source's constructions fire several actions at the same instant, so the order is not strict. $\mathrm{Tr}(A)$ is the set of finite timed words over $\Sigma$ generated by runs of $A$ ($\tau$-steps are invisible) and $L(A)$ those generated by runs ending in $F$. The source uses the subclasses $\mathrm{ERA} \subseteq \mathrm{DTA} \subseteq \mathrm{NTA} \subseteq \tau\mathrm{NTA}$: $\tau\mathrm{NTA}$ allows $\tau$-edges, NTA forbids them, DTA are the deterministic NTA, and an *event-recording automaton* (ERA) is a DTA with one clock $x_a$ per action $a$ that is reset exactly when $a$ occurs.

**Opacity.** Fix observable actions $\Sigma_o \subseteq \Sigma$ and let $\pi$ be the projection of timed words onto $\Sigma_o$ (keeping time stamps). For $w \in \pi(\mathrm{Tr}(A))$ let $[w] = \pi^{-1}(w) \cap \mathrm{Tr}(A)$. A secret $S$, a set of timed words, is *opaque* with respect to $A$ and $\Sigma_o$ if $[w] \not\subseteq S$ for every $w \in \pi(\mathrm{Tr}(A))$: no observation proves that a secret word occurred. In the location-based version, a set $F$ of secret locations is *L-opaque* if for every $w \in \pi(\mathrm{Tr}(A))$ some run with trace in $[w]$ ends outside $F$.

**Theorem (Cassez).**

1. The L-opacity problem (given a timed automaton $A$, secret locations $F$ and $\Sigma_o \subseteq \Sigma$, is $F$ L-opaque?) is undecidable for NTA (Theorem 1), for DTA (Theorem 2) and for ERA (Theorem 3).
2. The opacity problem (given $A$, a secret $S$ and $\Sigma_o$, is $S$ opaque?) is undecidable when the system $A$ and the secret $S$ are both given by event-recording automata (Theorem 4).

The automata, the secret and the observable alphabet are all part of the input.

## Expansion

For NTA, complete $A$ with a non-accepting sink and take $\Sigma_o = \Sigma$; then $L \setminus F$ is L-opaque iff $A$ accepts every timed word, so universality of timed automata over finite timed words, undecidable by Alur and Dill, reduces to L-opacity; main states only the version of that result for timed Büchi automata on infinite words, which is not the one used here. For DTA, the remaining nondeterminism of a $\tau\mathrm{NTA}$ is confined to $\tau$-edges, which are renamed to fresh unobservable letters, giving a deterministic automaton with the same L-opacity. For ERA, every edge that resets an arbitrary set of clocks is replaced by a gadget that first fires the original action and then, in zero time, fires one fresh unobservable action per clock to be reset, so that every clock becomes an event clock. Opacity with an ERA secret reduces to L-opacity on the product of the system with the secret automaton, whose accepting locations are the secret locations. By contrast, opacity of finite automata with regular secrets is decidable.
