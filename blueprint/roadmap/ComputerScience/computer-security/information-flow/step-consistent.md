# Step consistency

A family of equivalence relations $\sim_u$ on states, one for each
domain $u$ (`view u`), is step consistent if $s \sim_u t$ implies
$\mathrm{step}(s, a) \sim_u \mathrm{step}(t, a)$ for all domains $u$, states $s$, $t$ and
actions $a$.

## Sources

- J. Rushby, *Noninterference, transitivity, and channel-control security policies*, Technical Report CSL-92-02, SRI International, 1992, Definition 4.
