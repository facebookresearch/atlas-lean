# Output consistency

A family of equivalence relations $\sim_u$ on states, one for each
domain $u$ (`view u`), is output consistent if $s \sim_{\mathrm{dom}(a)} t$ implies
$\mathrm{output}(s, a) = \mathrm{output}(t, a)$ for all states $s$, $t$ and actions $a$.

## Sources

- J. Rushby, *Noninterference, transitivity, and channel-control security policies*, Technical Report CSL-92-02, SRI International, 1992, Definition 3.
