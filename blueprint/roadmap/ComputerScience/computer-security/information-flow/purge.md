# Purge of an action sequence

For a relation $\rightsquigarrow$ on domains (`policy`), an
action sequence $\alpha$ and a domain $u$, $\mathrm{purge}(\alpha, u)$ is the subsequence of
$\alpha$ formed by deleting every action $a$ with $\mathrm{dom}(a) \not\rightsquigarrow u$.

## Sources

- J. Rushby, *Noninterference, transitivity, and channel-control security policies*, Technical Report CSL-92-02, SRI International, 1992, Definition 2.
