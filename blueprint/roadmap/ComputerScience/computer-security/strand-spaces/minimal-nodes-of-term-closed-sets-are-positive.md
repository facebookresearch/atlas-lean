# Minimal nodes of term-closed sets are positive

**Lemma.** Let $\mathcal C$ be a [bundle](bundles-in-a-strand-space.md) and $S$ a set of nodes of $\mathcal C$ closed under equality of unsigned terms: whenever $m$ and
$m'$ carry the same unsigned term, $m \in S$ if and only if $m' \in S$. Then every $\preceq_{\mathcal C}$-minimal member of $S$ has a positive term.

A negative minimal node would receive its term from a node $n' \to n$ of the bundle carrying the same term, which would lie in $S$ below $n$.
