# Bundle precedence is a well-founded partial order

**Lemma.** For every [bundle](bundles-in-a-strand-space.md) $\mathcal C$, the relation $\preceq_{\mathcal C}$ is a partial order on its nodes (reflexive, antisymmetric and
transitive), and every nonempty set of nodes of $\mathcal C$ has $\preceq_{\mathcal C}$-minimal members.

The existence of minimal members serves as the induction principle of strand-space proofs.
