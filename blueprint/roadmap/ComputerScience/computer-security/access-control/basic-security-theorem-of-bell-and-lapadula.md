# Basic security theorem of Bell and LaPadula

In the Bell–LaPadula model a *state* records a current access set $b$ of triples (subject, object, access attribute), an access permission matrix $M$,
and a level function giving each subject a clearance and current level and each object a classification, with levels partially ordered by
dominance. A state satisfies:

- the *ss-property* (simple security) if for every current access (subject, object, attribute) whose attribute involves observation, the level of
  the subject dominates the level of the object;
- the *$*$-property* if whenever a subject has simultaneous observe access to object 1 and alter access to object 2, the level of object 2
  dominates the level of object 1;
- the *ds-property* (discretionary security) if every current access is permitted by the matrix $M$.

A state is *secure* if it has all three properties. A *system* is generated from an initial state $z_0$ by a set $W$ of actions, each a request,
decision and state change.

**Theorem (basic security theorem).** The system generated by $W$ from $z_0$ is secure, that is, every reachable state is secure, if and only if $z_0$ is
secure and every action of $W$ satisfies the preservation conditions for the three properties: every triple it adds to $b$ satisfies the
ss-, $*$- and ds-conditions relative to the resulting state, and every current access that no longer satisfies them relative to the
resulting levels and matrix is removed from $b$ (the $*$-conditions being imposed on the subjects that are not trusted). In particular, if every rule preserves the three properties and $z_0$
is secure, the system is secure.
