# Lower envelopes of functions are Davenport–Schinzel sequences

Let $F = \{f_1, \dots, f_n\}$ be continuous real functions on a common interval $I \subseteq \mathbb{R}$, any two of which intersect in at most $s$ points. The *lower envelope* $L_F(x) = \min_i f_i(x)$ splits $I$ into maximal intervals $I_1, \dots, I_\ell$, in this order, on each of which a single function $f_{\varphi_j}$ attains the minimum. Then the sequence $\varphi(F) = (\varphi_1, \dots, \varphi_\ell)$ is an $(n, s)$-Davenport–Schinzel sequence; in particular $\ell \le \lambda_s(n)$.
