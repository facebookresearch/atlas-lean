# Davenport–Schinzel sequence

Let $n, s \ge 1$. An *$(n, s)$-Davenport–Schinzel sequence* is a finite sequence over an alphabet $A$ of $n$ symbols in which no two consecutive symbols are equal and which contains no alternating subsequence $\dots a \dots b \dots a \dots b \dots$ of length $s + 2$ for any two distinct symbols $a, b \in A$. Write $\lambda_s(n)$ for the largest length of an $(n, s)$-Davenport–Schinzel sequence. For example, $abcbacb$ is a $(3, 4)$- but not a $(3, 3)$-Davenport–Schinzel sequence, since it contains $bcbcb$.
