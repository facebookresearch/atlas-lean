# Terminal paths of bounded symbolic execution of an IMP command

Bounded symbolic execution $\operatorname{run}_k(c, p)$ of a command $c$ from a symbolic path $p$ (a guard, a symbolic store and a cost) with bound $k$ produces an ordered list of leaves, each a terminal leaf $\operatorname{done}(q)$ or a cutoff leaf $\operatorname{cut}(q)$ carrying a path $q$; branches are explored then-branch first, assumptions are pruned only when they constant-fold to the literal false, and a loop iteration is cut off once the path cost reaches $k$ or the loop fuel $k \mathbin{\dot-} n$ (with $n$ the cost on entering the loop) is used up. With the initial path (guard the literal true, identity store $x \mapsto x$, cost $0$), the leaves of a command $c$ with bound $k$ are the list $\operatorname{run}_k(c, p_0)$ of bounded symbolic execution from the initial path $p_0$. The terminal paths of $c$ with bound $k$ are the paths $q$ of the terminal leaves $\operatorname{done}(q)$ among these leaves, in their order.
