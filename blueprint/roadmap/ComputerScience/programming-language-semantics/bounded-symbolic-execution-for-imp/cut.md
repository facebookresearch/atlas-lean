# Path of a cutoff leaf

A leaf of bounded symbolic execution is either a terminal leaf $\operatorname{done}(p)$ or a cutoff leaf $\operatorname{cut}(p)$ carrying a symbolic path $p$. The cutoff projection of a leaf is the path $p$ (present) for $\operatorname{cut}(p)$ and absent for $\operatorname{done}(p)$.
