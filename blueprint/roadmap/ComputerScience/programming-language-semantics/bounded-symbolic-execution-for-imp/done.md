# Path of a terminal leaf

A leaf of bounded symbolic execution is either a terminal leaf $\operatorname{done}(p)$ or a cutoff leaf $\operatorname{cut}(p)$ carrying a symbolic path $p$. The terminal projection of a leaf is the path $p$ (present) for $\operatorname{done}(p)$ and absent for $\operatorname{cut}(p)$.
