# The one-point abstract domain gives a Galois connection

For every type of states $\Sigma$, with sets of states ordered by inclusion and the one-point type $\{\ast\}$ ordered trivially, the abstraction sending every set of states to $\ast$ and the concretization sending $\ast$ to the set of all states form a Galois connection: for every $X \subseteq \Sigma$, $\ast \le \ast$ if and only if $X \subseteq \Sigma$, and both sides hold.
