# Abstract sign multiplication is exact

Abstract multiplication $\otimes$ on signs is given by $0 \otimes t = s \otimes 0 = \{0\}$, $(-) \otimes (-) = (+) \otimes (+) = \{+\}$ and $(-) \otimes (+) = (+) \otimes (-) = \{-\}$. For all signs $s, t \in \{-, 0, +\}$, $s \otimes t$ is the singleton $\{s \cdot t\}$, where $s \cdot t$ is the product of signs (with $-, 0, +$ multiplied as $-1, 0, 1$).
