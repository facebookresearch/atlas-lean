# Abstract multiplication on signs

Abstract multiplication sends two signs $s, t \in \{-, 0, +\}$ to a finite set of signs, meant to contain the sign of every product of an integer of sign $s$ and an integer of sign $t$:

- $0 \otimes t = \{0\}$ for every sign $t$, and $s \otimes 0 = \{0\}$ for every sign $s$;
- $(-) \otimes (-) = \{+\}$, $(-) \otimes (+) = \{-\}$, $(+) \otimes (-) = \{-\}$ and $(+) \otimes (+) = \{+\}$.
