# Soundness of abstract sign multiplication

Write $\operatorname{sgn} : \mathbb{Z} \to \{-, 0, +\}$ for the sign of an integer ($-$ for negative, $0$ for zero, $+$ for positive). Abstract multiplication $\otimes$ on signs is given by $0 \otimes t = s \otimes 0 = \{0\}$, $(-) \otimes (-) = (+) \otimes (+) = \{+\}$ and $(-) \otimes (+) = (+) \otimes (-) = \{-\}$. For all integers $a$ and $b$,

$$\operatorname{sgn}(a b) \in \operatorname{sgn}(a) \otimes \operatorname{sgn}(b).$$
