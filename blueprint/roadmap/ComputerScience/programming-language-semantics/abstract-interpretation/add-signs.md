# Abstract addition on signs

Abstract addition sends two signs $s, t \in \{-, 0, +\}$ to a finite set of signs, meant to contain the sign of every sum of an integer of sign $s$ and an integer of sign $t$:

- $(-) \oplus (-) = \{-\}$, $(-) \oplus 0 = \{-\}$ and $(-) \oplus (+) = \{-, 0, +\}$;
- $0 \oplus t = \{t\}$ for every sign $t$;
- $(+) \oplus (-) = \{-, 0, +\}$, $(+) \oplus 0 = \{+\}$ and $(+) \oplus (+) = \{+\}$.
