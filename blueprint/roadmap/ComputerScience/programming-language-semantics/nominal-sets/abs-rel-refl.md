# Reflexivity of α-equivalence

Let $\mathbb{A}$ be a set of atoms and $X$ a set with an action of the group $\mathrm{Perm}_f(\mathbb{A})$ of [finitely supported permutations](fin-perm.md) of $\mathbb{A}$. Every pair $(a, x)$ of an atom and an element of $X$ is [α-equivalent](abs-rel.md) to itself.
