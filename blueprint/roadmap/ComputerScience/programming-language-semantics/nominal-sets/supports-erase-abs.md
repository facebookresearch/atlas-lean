# Abstractions are supported by the body's support minus the atom

Let $\mathbb{A}$ be an infinite set of atoms and $X$ a [nominal set](nominal-set.md) over $\mathbb{A}$. Let $a$ be an atom and $x \in X$. Every finitely supported permutation $\pi$ that fixes every atom of $\mathrm{supp}(x) \setminus \{a\}$ fixes the abstraction: $\pi \cdot [a]x = [a]x$.
