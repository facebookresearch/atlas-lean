# A pair is supported by the union of its components' supports

Let $\mathbb{A}$ be a set of atoms and $X$, $Y$ sets with actions of the group of finitely supported permutations of $\mathbb{A}$, and let $X \times Y$ carry the componentwise action. If a finite set $S$ [supports](supports.md) $x \in X$ and a finite set $T$ supports $y \in Y$, then $S \cup T$ supports the pair $(x, y)$.
