# Supporting set of atoms for an element

Let $\mathbb{A}$ be a set of atoms and $X$ a set with an action of the group $\mathrm{Perm}_f(\mathbb{A})$ of [finitely supported permutations](fin-perm.md) of $\mathbb{A}$. A finite set $S \subseteq \mathbb{A}$ supports an element $x \in X$ when every finitely supported permutation $\pi$ that fixes every atom of $S$ fixes $x$: $\pi \cdot x = x$.
