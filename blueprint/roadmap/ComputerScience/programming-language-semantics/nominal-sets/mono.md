# Enlarging a support

Let $\mathbb{A}$ be a set of atoms and $X$ a set with an action of the group $\mathrm{Perm}_f(\mathbb{A})$ of [finitely supported permutations](fin-perm.md) of $\mathbb{A}$. If a finite set $S$ [supports](supports.md) $x \in X$ and $S \subseteq T$ for a finite set $T$, then $T$ supports $x$: fixing the larger set pointwise is a stronger hypothesis.
