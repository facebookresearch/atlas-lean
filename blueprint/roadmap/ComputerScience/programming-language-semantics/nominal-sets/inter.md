# Intersection of two supports is a support

Let $\mathbb{A}$ be an infinite set of atoms and $X$ a set with an action of the group $\mathrm{Perm}_f(\mathbb{A})$ of [finitely supported permutations](fin-perm.md) of $\mathbb{A}$. If finite sets $S_1$ and $S_2$ [support](supports.md) $x \in X$, then $S_1 \cap S_2$ supports $x$: a permutation fixing $S_1 \cap S_2$ pointwise fixes $x$, since every atom it moves outside $S_1 \cap S_2$ is fresh for $x$.
