# Equivariant elements of a nominal set

Let $\mathbb{A}$ be a set of atoms and $X$ a set with an action of the group $\mathrm{Perm}_f(\mathbb{A})$ of [finitely supported permutations](fin-perm.md) of $\mathbb{A}$. An element $x \in X$ is equivariant when every finitely supported permutation fixes it: $\pi \cdot x = x$ for all $\pi$.
