# Freshness of an atom for an element

Let $\mathbb{A}$ be a set of atoms and $X$ a set with an action of the group $\mathrm{Perm}_f(\mathbb{A})$ of [finitely supported permutations](fin-perm.md) of $\mathbb{A}$. An atom $a$ is fresh for an element $x \in X$, written $a \mathrel{\#} x$, when some finite [support](supports.md) of $x$ does not contain $a$.
