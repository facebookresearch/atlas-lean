# Subgroup of finitely supported permutations of atoms

Let $\mathbb{A}$ be a set of atoms. The finitely supported permutations of $\mathbb{A}$, those $\pi$ for which some finite set $S \subseteq \mathbb{A}$ satisfies $\pi(a) = a$ for every $a \notin S$, form a subgroup of the group of all permutations of $\mathbb{A}$.
