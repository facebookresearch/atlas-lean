# Transposition of atoms outside a support fixes the element

Let $\mathbb{A}$ be a set of atoms and $X$ a set with an action of the group $\mathrm{Perm}_f(\mathbb{A})$ of [finitely supported permutations](fin-perm.md) of $\mathbb{A}$. If a finite set $S$ [supports](supports.md) $x \in X$ and $a, b \notin S$, then the [transposition](swap.md) $(a\ b)$ fixes $x$.
