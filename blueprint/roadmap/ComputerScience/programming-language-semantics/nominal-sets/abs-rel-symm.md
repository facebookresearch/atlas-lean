# Symmetry of α-equivalence

Let $\mathbb{A}$ be an infinite set of atoms and $X$ a [nominal set](nominal-set.md) over $\mathbb{A}$. If $(a, x)$ is [α-equivalent](abs-rel.md) to $(b, y)$, then $(b, y)$ is α-equivalent to $(a, x)$. The proof uses the [equivariance of the least support](supp-smul.md).
