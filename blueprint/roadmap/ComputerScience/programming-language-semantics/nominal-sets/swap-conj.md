# Conjugation of a transposition

Let $\mathbb{A}$ be a set of atoms. For every finitely supported permutation $\sigma$ of $\mathbb{A}$ and all atoms $b, c$, conjugating the [transposition](swap.md) $(b\ c)$ by $\sigma$ gives the transposition of the images: $\sigma\,(b\ c)\,\sigma^{-1} = (\sigma(b)\ \sigma(c))$.
