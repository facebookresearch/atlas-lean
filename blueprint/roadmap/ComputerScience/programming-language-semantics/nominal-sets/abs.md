# Atom abstraction of a nominal set

Let $\mathbb{A}$ be an infinite set of atoms and $X$ a [nominal set](nominal-set.md) over $\mathbb{A}$. The atom abstraction $[\mathbb{A}]X$ of $X$ is the quotient of $\mathbb{A} \times X$ by [α-equivalence](abs-setoid.md); the class of $(a, x)$ is written $[a]x$.
