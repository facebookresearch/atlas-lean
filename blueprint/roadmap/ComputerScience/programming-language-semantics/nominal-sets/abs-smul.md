# Permutation action on abstractions

Let $\mathbb{A}$ be an infinite set of atoms and $X$ a [nominal set](nominal-set.md) over $\mathbb{A}$. A finitely supported permutation $\pi$ acts on the [atom abstraction](abs.md) $[\mathbb{A}]X$ by $\pi \cdot [a]x = [\pi(a)](\pi \cdot x)$; this is well defined because α-equivalent pairs have α-equivalent images.
