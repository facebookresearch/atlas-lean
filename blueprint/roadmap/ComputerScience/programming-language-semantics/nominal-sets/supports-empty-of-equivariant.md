# Equivariant elements are supported by the empty set

Let $\mathbb{A}$ be a set of atoms and $X$ a set with an action of the group $\mathrm{Perm}_f(\mathbb{A})$ of [finitely supported permutations](fin-perm.md) of $\mathbb{A}$. Every [equivariant](is-equivariant.md) element of $X$ is [supported](supports.md) by the empty set.
