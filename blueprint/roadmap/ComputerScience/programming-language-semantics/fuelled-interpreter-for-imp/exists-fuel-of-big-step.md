# Completeness of the fuelled IMP evaluator for big-step semantics

The fuelled evaluator $\operatorname{exec}(k, c, s)$ returns either a final state or failure $\bot$, for fuel $k \in \mathbb{N}$, an IMP command $c$ and a state $s$. It is defined by recursion on the fuel: $\operatorname{exec}(0, c, s) = \bot$ for every $c$ and $s$, and at fuel $k + 1$: $\mathtt{skip}$ returns $s$; $x := a$ returns $s[x \mapsto a(s)]$, the state $s$ with variable $x$ set to the value of $a$ in $s$; $c_1 ; c_2$ returns $\bot$ if $\operatorname{exec}(k, c_1, s) = \bot$ and $\operatorname{exec}(k, c_2, m)$ if $\operatorname{exec}(k, c_1, s) = m$; $\mathtt{if}\ b\ \mathtt{then}\ c_1\ \mathtt{else}\ c_2$ returns $\operatorname{exec}(k, c_1, s)$ if $b$ is true at $s$ and $\operatorname{exec}(k, c_2, s)$ otherwise; and $\mathtt{while}\ b\ \mathtt{do}\ c$ returns $s$ if $b$ is false at $s$, and otherwise $\bot$ if $\operatorname{exec}(k, c, s) = \bot$ and $\operatorname{exec}(k, \mathtt{while}\ b\ \mathtt{do}\ c, m)$ if $\operatorname{exec}(k, c, s) = m$. For every command $c$ and all states $s, t$, if $c$ run from $s$ terminates in $t$ under the big-step semantics, then there is a fuel $k$ with $\operatorname{exec}(k, c, s) = t$.
