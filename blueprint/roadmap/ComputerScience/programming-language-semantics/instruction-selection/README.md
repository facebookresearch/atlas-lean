# Instruction selection

Translating intermediate-code trees into machine instructions by covering them with tiles, each tile a tree pattern implemented by an instruction sequence. Greedy tiling takes the largest matching tile at each node; under an additive cost model, dynamic programming over the tree finds a tiling of least total cost or reports that none exists.
