# Behaviors of a configuration

The behaviors of a configuration `c` under an operational semantics `S`: termination with a finite trace `μs` when some execution from `c` with trace `μs` reaches a final configuration; going wrong with a finite trace `μs` when some execution from `c` with trace `μs` reaches a stuck configuration (non-final, with no outgoing transition); and reaction with an infinite trace when some infinite execution from `c` carries that trace.
