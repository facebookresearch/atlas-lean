# Contextual equivalence

Given a context algebra and an observation, terms $t$ and $u$ of the same judgment are contextually equivalent when, for every program judgment $k$, every context $C$ from their judgment to $k$ and every outcome $o$, $C[t]$ yields $o$ if and only if $C[u]$ yields $o$. The terms need not be programs themselves; only their pluggings are run.
