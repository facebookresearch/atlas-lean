# Transition systems for operational semantics

A *transition system* is a pair $\langle \Gamma, \to \rangle$ of a set $\Gamma$ of *configurations* and a *transition relation* $\to \subseteq \Gamma \times \Gamma$. A *terminal transition system* $\langle \Gamma, \to, T \rangle$ adds a set $T \subseteq \Gamma$ of *terminal* (final) configurations from which there is no transition. A *structural operational semantics* of a language is a terminal transition system whose configurations are built from program terms, possibly paired with a store or environment, and whose transitions are generated by rules that follow the syntax of the terms. The following notions are derived from it:
- $\to^\ast$ is the reflexive-transitive closure, the *multi-step* relation;
- a configuration $\gamma$ is a *normal form* if $\gamma \not\to \gamma'$ for all $\gamma'$;
- it is *stuck* if it is a normal form that is not terminal;
- it *diverges* if there is an infinite sequence $\gamma \to \gamma_1 \to \gamma_2 \to \cdots$;
- the semantics is *deterministic* if $\to$ is a partial function: $\gamma \to \gamma'$ and $\gamma \to \gamma''$ imply $\gamma' = \gamma''$;
- the induced *evaluation* (big-step) relation relates $\gamma$ to $t \in T$ when $\gamma \to^\ast t$.

For a deterministic semantics, every configuration either reaches exactly one terminal configuration, gets stuck, or diverges. *Labelled* transition systems $\langle \Gamma, A, \to \rangle$ with $\to \subseteq \Gamma \times A \times \Gamma$ record observable actions on transitions.

The [small-step semantics of IMP](step.md) is an example. Its configurations are pairs of a command and a state, its terminal configurations have the command $\mathtt{skip}$, and termination by multi-step reduction [agrees](terminates-iff-big-step.md) with the [big-step semantics](big-step.md).
