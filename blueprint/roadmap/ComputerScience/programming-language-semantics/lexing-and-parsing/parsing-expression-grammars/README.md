# Parsing expression grammars

Recognition-based grammars with prioritized choice, greedy repetition and syntactic predicates, whose interpretation is a deterministic function of the input rather than a generative relation. Their languages are closed under intersection, and the standard constructions give union and complement for complete grammars; they include non-context-free languages; emptiness, equivalence and completeness are undecidable, but well-formed grammars, which have no left recursion, are complete, and every grammar has a linear-time parser.
