# The paradoxical combinator $Y$

The closed term $Y = \lambda u.(\lambda x.\,u(x\,x))(\lambda x.\,u(x\,x))$, written with de Bruijn indices as $\lambda.(\lambda.1\,(0\,0))\,(\lambda.1\,(0\,0))$ (D. Scott, *Data types as lattices*, SIAM J. Comput. 5(3) (1976), 522–587, equation (2.8)).
