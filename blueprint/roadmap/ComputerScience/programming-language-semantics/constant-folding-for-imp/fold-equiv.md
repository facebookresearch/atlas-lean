# Constant folding preserves terminating IMP executions when the table agrees with the initial state

A constant table is a function $t : \mathbb{N} \to \mathbb{N} \cup \{\bot\}$ (an option of a natural number) recording, for some variable indices $x$, a known value $t(x) = n$; $t(x) = \bot$ means no known value. A table $t$ approximates an IMP state $s$ when $s(x) = n$ whenever $t(x) = n$. Let $\operatorname{fold}_t(c)$ be the constant folding and propagation of the command $c$ starting from $t$: expressions are folded with the known constants, an assignment $x := a$ sets the entry of $x$ to the value of the folded $a$ when that is a constant and clears it otherwise, conditionals join the tables of their branches where they agree, and loops first forget the variables their body assigns. If $t$ approximates the state $s$, then for every command $c$ and every state $f$, $\operatorname{fold}_t(c)$ run from $s$ terminates in $f$ under the big-step semantics if and only if $c$ run from $s$ terminates in $f$.
