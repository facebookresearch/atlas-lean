# Constant folding of IMP Boolean expressions

Let $t : \mathbb{N} \to \mathbb{N} \cup \{\bot\}$ be a constant table and $\operatorname{afold}_t$ constant folding of arithmetic expressions with $t$ (variables with a known value become constants, and operations on two constants are evaluated, with truncated subtraction). Boolean folding $\operatorname{bfold}_t$ is defined by recursion: a truth value stays; $a_1 = a_2$ and $a_1 \le a_2$ fold both operands with $\operatorname{afold}_t$ and become the truth value of the comparison when both are constants $m, n$ (that is, $m = n$, respectively $m \le n$), else the comparison of the folded operands; $\neg b$ becomes the negated truth value when $b$ folds to a truth value, else $\neg$ of the folded $b$; $b_1 \wedge b_2$ becomes the truth value $v_1 \wedge v_2$ when both fold to truth values $v_1, v_2$, else the conjunction of the folded operands.
