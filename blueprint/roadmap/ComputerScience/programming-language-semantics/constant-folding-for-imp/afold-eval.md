# Constant folding preserves the value of an IMP arithmetic expression when the table agrees with the state

A constant table is a function $t : \mathbb{N} \to \mathbb{N} \cup \{\bot\}$ (an option of a natural number) recording, for some variable indices $x$, a known value $t(x) = n$; $t(x) = \bot$ means no known value. A table $t$ approximates an IMP state $s$ when $s(x) = n$ whenever $t(x) = n$. Arithmetic folding $\operatorname{afold}_t$ is defined by recursion: a constant stays; a variable $x$ becomes the constant $n$ when $t(x) = n$ and stays $x$ when $t(x) = \bot$; for $a_1 + a_2$, $a_1 - a_2$ and $a_1 \cdot a_2$ both operands are folded first, and if both folded operands are constants $m$ and $n$ the result is the constant $m + n$, $m \mathbin{\dot-} n$ (truncated subtraction) or $m \cdot n$; otherwise the operation is rebuilt from the folded operands, except that a difference whose folded left operand is the constant $0$ (and whose folded right operand is not a constant) becomes the constant $0$. If $t$ approximates $s$, then for every arithmetic expression $a$, the value of $\operatorname{afold}_t(a)$ in $s$ equals the value of $a$ in $s$.
