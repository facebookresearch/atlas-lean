# Constant folding preserves the value of an IMP Boolean expression when the table agrees with the state

A constant table is a function $t : \mathbb{N} \to \mathbb{N} \cup \{\bot\}$ (an option of a natural number) recording, for some variable indices $x$, a known value $t(x) = n$; $t(x) = \bot$ means no known value. A table $t$ approximates an IMP state $s$ when $s(x) = n$ whenever $t(x) = n$. Arithmetic folding $\operatorname{afold}_t$ is defined by recursion: a constant stays; a variable $x$ becomes the constant $n$ when $t(x) = n$ and stays $x$ when $t(x) = \bot$; for $a_1 + a_2$, $a_1 - a_2$ and $a_1 \cdot a_2$ both operands are folded first, and if both folded operands are constants $m$ and $n$ the result is the constant $m + n$, $m \mathbin{\dot-} n$ (truncated subtraction) or $m \cdot n$; otherwise the operation is rebuilt from the folded operands, except that a difference whose folded left operand is the constant $0$ (and whose folded right operand is not a constant) becomes the constant $0$. Boolean folding $\operatorname{bfold}_t$ is defined by recursion: a truth value stays; $a_1 = a_2$ and $a_1 \le a_2$ fold both operands with $\operatorname{afold}_t$ and become the truth value of the comparison when both are constants $m, n$ (that is, $m = n$, respectively $m \le n$), else the comparison of the folded operands; $\neg b$ becomes the negated truth value when $b$ folds to a truth value, else $\neg$ of the folded $b$; $b_1 \wedge b_2$ becomes the truth value $v_1 \wedge v_2$ when both fold to truth values $v_1, v_2$, else the conjunction of the folded operands. If $t$ approximates $s$, then for every Boolean expression $b$, the truth value of $\operatorname{bfold}_t(b)$ in $s$ equals the truth value of $b$ in $s$.
