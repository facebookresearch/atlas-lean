# Stack-machine code compiled from IMP commands constant-folded from the empty table is correct

The stack machine runs a program $P$, a list of instructions, on configurations $(pc, \sigma, s)$ consisting of a program counter $pc \in \mathbb{N}$, a stack $\sigma$ (a list of natural numbers, top first) and an IMP state $s$; a configuration steps by executing the instruction at position $pc$ of $P$ (counted from $0$), and there is no step when $pc \ge |P|$. The machine is deterministic. For an IMP command $d$, $C_0(d)$ is the code compiled from $d$ at base address $0$ and $\ell(d)$ its instruction count. Let $\operatorname{fold}_\emptyset(c)$ be the constant folding and propagation of the command $c$ starting from the empty constant table. For every command $c$ and all states $s, s'$, the machine running $C_0(\operatorname{fold}_\emptyset(c))$ goes in zero or more steps from $(0, [\,], s)$ to $(\ell(\operatorname{fold}_\emptyset(c)), [\,], s')$ if and only if $c$ run from $s$ terminates in $s'$ under the big-step semantics.
