# Translated arithmetic expressions evaluate as in IMP

For every renaming $\rho$ from natural numbers to strings, IMP arithmetic expression $a$ and state $s$ of the imperative language with arrays, the value of the translation $\tau_\rho(a)$ in $s$ equals the IMP value of $a$ in the projected state $\pi_\rho(s)$. No injectivity of $\rho$ is needed.
