# Translated commands leave unrenamed variables unchanged

Let $\rho$ be an injective renaming from natural numbers to strings and $c$ an IMP command. If the translation of $c$ takes the state $s$ to the state $t$, then $t(x) = s(x)$ for every variable $x$ with $x \ne \rho(n)$ for all $n \in \mathbb{N}$.
