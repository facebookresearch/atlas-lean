# Big-step evaluation is finite reduction to a value

In the [call-by-value λ-calculus with constants](call-by-value-lambda-calculus-with-constants.md), $a \Rightarrow v$ if and only if $a \to^* v$ and $v$ is a value.

## Depends on

## Sources

- X. Leroy and H. Grall, "Coinductive big-step operational semantics", arXiv:0808.0586v1, 2008, <https://arxiv.org/abs/0808.0586v1>: Section 4, Theorem 9 and its proof (values evaluate to themselves, and evaluation is closed under backward reduction steps).
