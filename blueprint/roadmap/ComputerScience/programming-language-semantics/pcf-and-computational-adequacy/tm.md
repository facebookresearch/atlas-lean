# PCF terms

Write $\mathsf{nat}$ for the ground type of natural numbers and $A \Rightarrow B$
for the type of functions from $A$ to $B$. The intrinsically typed PCF terms of type $A$ in a
context $\Gamma$ (a list of PCF types) are generated by the following rules: every variable of
type $A$ in $\Gamma$ is a term of type $A$; if $t$ has type $B$ in the context $\Gamma$ extended
by a newest variable of type $A$, then $\lambda t$ has type $A \Rightarrow B$; if $f$ has type
$A \Rightarrow B$ and $a$ has type $A$, then $f\,a$ has type $B$; $\mathsf{zero}$ has type
$\mathsf{nat}$; if $t$ has type $\mathsf{nat}$, so do $\mathsf{succ}\,t$ and $\mathsf{pred}\,t$;
if $t$, $s_1$ and $s_2$ have type $\mathsf{nat}$, so does the zero test
$\mathsf{ifz}\,t\,s_1\,s_2$; and if $t$ has type $A \Rightarrow A$, then the fixed point
$\mathsf{fix}\,t$ has type $A$.
