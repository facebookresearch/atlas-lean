# Reachable configurations of compiled IMP code are at the halt address or can step

The stack machine runs a program $P$, a list of instructions, on configurations $(pc, \sigma, s)$ consisting of a program counter $pc \in \mathbb{N}$, a stack $\sigma$ (a list of natural numbers, top first) and an IMP state $s$; a configuration steps by executing the instruction at position $pc$ of $P$ (counted from $0$), and there is no step when $pc \ge |P|$. The machine is deterministic. For an IMP command $c$, $C_0(c)$ is the code compiled from $c$ at base address $0$, and $\ell(c)$ is its instruction count, the length of $C_0(c)$ and its halt address. Write $x \to^{*} y$ for zero or more machine steps of $C_0(c)$. Let $c$ be a command, $s$ a state, $\sigma$ a stack and $z$ a configuration with $(0, \sigma, s) \to^{*} z$. Then the program counter of $z$ equals $\ell(c)$, or $z$ has a machine step of $C_0(c)$ to some configuration.
