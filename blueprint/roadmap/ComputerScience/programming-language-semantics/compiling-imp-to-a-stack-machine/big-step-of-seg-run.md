# A run that starts each step in embedded compiled code and reaches the code's end reflects a big-step execution

The stack machine runs a program $P$, a list of instructions, on configurations $(pc, \sigma, s)$ consisting of a program counter $pc \in \mathbb{N}$, a stack $\sigma$ (a list of natural numbers, top first) and an IMP state $s$; a configuration steps by executing the instruction at position $pc$ of $P$ (counted from $0$), and there is no step when $pc \ge |P|$. The machine is deterministic. For a list of instructions $B$ and an IMP command $c$, let $C_{|B|}(c)$ be the code compiled from $c$ at base address $|B|$ (the length of $B$), $\ell(c)$ its instruction count, and $P = B \mathbin{+\!\!+} C_{|B|}(c) \mathbin{+\!\!+} A$ for any list of instructions $A$. Let $\sigma$ be a stack, $s$ a state and $y$ a configuration, and suppose that $(|B|, \sigma, s)$ reaches $y$ in $n$ steps of $P$, each of which starts at a program counter in $[|B|, |B| + \ell(c))$, and that the program counter of $y$ is $|B| + \ell(c)$. Then there is a state $s'$ such that $c$ run from $s$ terminates in $s'$ under the big-step semantics and $y = (|B| + \ell(c), \sigma, s')$; in particular the stack is restored.
