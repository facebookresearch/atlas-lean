# Partial correctness of an IMP command transfers to its compiled code and back

The stack machine runs a program $P$, a list of instructions, on configurations $(pc, \sigma, s)$ consisting of a program counter $pc \in \mathbb{N}$, a stack $\sigma$ (a list of natural numbers, top first) and an IMP state $s$; a configuration steps by executing the instruction at position $pc$ of $P$ (counted from $0$), and there is no step when $pc \ge |P|$. The machine is deterministic. For an IMP command $c$, $C_0(c)$ is the code compiled from $c$ at base address $0$, and $\ell(c)$ is its instruction count, the length of $C_0(c)$ and its halt address. Write $x \to^{*} y$ for zero or more machine steps of $C_0(c)$. For every command $c$ and all assertions $P, Q$ on states, the Hoare triple $\{P\}\,c\,\{Q\}$ is partial-correctness valid (if $P(s)$ holds and $c$ run from $s$ terminates in $s'$ under the big-step semantics, then $Q(s')$ holds) if and only if, for all states $s, s'$ and every stack $\sigma'$, if $P(s)$ holds and $(0, [\,], s) \to^{*} (\ell(c), \sigma', s')$, then $Q(s')$ holds. The machine side ranges over every final stack.
