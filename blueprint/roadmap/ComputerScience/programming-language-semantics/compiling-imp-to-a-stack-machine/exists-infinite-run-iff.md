# Compiled IMP code runs forever exactly when the source has no big-step result

The stack machine runs a program $P$, a list of instructions, on configurations $(pc, \sigma, s)$ consisting of a program counter $pc \in \mathbb{N}$, a stack $\sigma$ (a list of natural numbers, top first) and an IMP state $s$; a configuration steps by executing the instruction at position $pc$ of $P$ (counted from $0$), and there is no step when $pc \ge |P|$. The machine is deterministic. For an IMP command $c$, $C_0(c)$ is the code compiled from $c$ at base address $0$. For every command $c$, state $s$ and stack $\sigma$, there is a sequence $(f_n)_{n \in \mathbb{N}}$ of machine configurations with $f_0 = (0, \sigma, s)$ and a step of $C_0(c)$ from $f_n$ to $f_{n+1}$ for every $n$ if and only if for every state $s'$, $c$ run from $s$ does not terminate in $s'$ under the big-step semantics.
