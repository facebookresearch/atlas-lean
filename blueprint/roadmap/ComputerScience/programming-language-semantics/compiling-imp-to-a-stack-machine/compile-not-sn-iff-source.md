# Compilation of IMP preserves and reflects failure of strong normalization

The stack machine runs a program $P$, a list of instructions, on configurations $(pc, \sigma, s)$ consisting of a program counter $pc \in \mathbb{N}$, a stack $\sigma$ (a list of natural numbers, top first) and an IMP state $s$; a configuration steps by executing the instruction at position $pc$ of $P$ (counted from $0$), and there is no step when $pc \ge |P|$. The machine is deterministic. IMP configurations are pairs $(c, s)$ of a command and a state, and $\to$ is the small-step relation on them. For an IMP command $c$, $C_0(c)$ is the code compiled from $c$ at base address $0$. An element $x$ is strongly normalizing for a relation $r$ when it is accessible for the converse of $r$: inductively, $x$ is strongly normalizing when every $y$ with $r\,x\,y$ is. For every command $c$, state $s$ and stack $\sigma$, the configuration $(c, s)$ is not strongly normalizing for the small-step relation if and only if the machine configuration $(0, \sigma, s)$ is not strongly normalizing for the step relation of $C_0(c)$.
