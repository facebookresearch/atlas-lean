# Compilation of IMP preserves and reflects the existence of infinite executions

The stack machine runs a program $P$, a list of instructions, on configurations $(pc, \sigma, s)$ consisting of a program counter $pc \in \mathbb{N}$, a stack $\sigma$ (a list of natural numbers, top first) and an IMP state $s$; a configuration steps by executing the instruction at position $pc$ of $P$ (counted from $0$), and there is no step when $pc \ge |P|$. The machine is deterministic. IMP configurations are pairs $(c, s)$ of a command and a state, and $\to$ is the small-step relation on them. For an IMP command $c$, $C_0(c)$ is the code compiled from $c$ at base address $0$. For every command $c$, state $s$ and stack $\sigma$, there is an infinite small-step sequence $(g_n)$ with $g_0 = (c, s)$ and $g_n \to g_{n+1}$ for all $n$ if and only if there is an infinite machine run $(f_n)$ of $C_0(c)$ with $f_0 = (0, \sigma, s)$ and a step from $f_n$ to $f_{n+1}$ for all $n$. This is an equivalence of existence; it relates no particular traces or step counts.
