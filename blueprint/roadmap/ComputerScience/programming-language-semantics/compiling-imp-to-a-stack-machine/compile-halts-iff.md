# Compiled IMP code reaches its halt address exactly when the source terminates

The stack machine runs a program $P$, a list of instructions, on configurations $(pc, \sigma, s)$ consisting of a program counter $pc \in \mathbb{N}$, a stack $\sigma$ (a list of natural numbers, top first) and an IMP state $s$; a configuration steps by executing the instruction at position $pc$ of $P$ (counted from $0$), and there is no step when $pc \ge |P|$. The machine is deterministic. For an IMP command $c$, $C_0(c)$ is the code compiled from $c$ at base address $0$, and $\ell(c)$ is its instruction count, the length of $C_0(c)$ and its halt address. Write $x \to^{*} y$ for zero or more machine steps of $C_0(c)$. For every command $c$, state $s$ and stack $\sigma$, there are a stack $\sigma'$ and a state $s'$ with $(0, \sigma, s) \to^{*} (\ell(c), \sigma', s')$ if and only if there is a state $s'$ such that $c$ run from $s$ terminates in $s'$ under the big-step semantics.
