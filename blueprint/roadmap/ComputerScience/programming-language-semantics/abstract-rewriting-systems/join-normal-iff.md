# Joining a normal state

Let $\to$ be a binary relation on a type $\alpha$, an abstract reduction system oriented from a state to its reduct. Write $\to^*$ for its reflexive–transitive closure and $\leftrightarrow^*$ for *conversion*, the equivalence relation generated by $\to$. A state $n$ is *normal* if there is no $y$ with $n \to y$ (a state with a loop $n \to n$ is not normal), and $n$ is a *reachable normal form* of $a$ if $a \to^* n$ and $n$ is normal.

Let $n$ be normal. For every state $a$, the states $a$ and $n$ are joinable (there is $c$ with $a \to^* c$ and $n \to^* c$) if and only if $a \to^* n$.
