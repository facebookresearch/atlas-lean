# Newman's lemma for the chosen normalizer

Let $\to$ be a binary relation on a type $\alpha$, an abstract reduction system oriented from a state to its reduct. Write $\to^*$ for its reflexive–transitive closure and $\leftrightarrow^*$ for *conversion*, the equivalence relation generated by $\to$. A state $n$ is *normal* if there is no $y$ with $n \to y$ (a state with a loop $n \to n$ is not normal), and $n$ is a *reachable normal form* of $a$ if $a \to^* n$ and $n$ is normal. Two states $a, b$ are *joinable* if there is $c$ with $a \to^* c$ and $b \to^* c$.

Call $\to$ *terminating* if there is no infinite chain $a_0 \to a_1 \to \cdots$ (the reversed relation is well founded), and *locally confluent* if whenever $a \to b$ and $a \to c$ in one step each, $b$ and $c$ are joinable. Let $N$ be the normalizer chosen from termination (for each state, some reachable normal form picked by the axiom of choice). If $\to$ is terminating and locally confluent and $a \leftrightarrow^* b$, then $N(a) = N(b)$.

This follows from Newman's lemma, by which a terminating, locally confluent relation is confluent.
