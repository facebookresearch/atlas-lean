# Normalizer of a terminating reduction system

Let $\to$ be a binary relation on a type $\alpha$, an abstract reduction system oriented from a state to its reduct. Write $\to^*$ for its reflexive–transitive closure and $\leftrightarrow^*$ for *conversion*, the equivalence relation generated by $\to$. A state $n$ is *normal* if there is no $y$ with $n \to y$ (a state with a loop $n \to n$ is not normal), and $n$ is a *reachable normal form* of $a$ if $a \to^* n$ and $n$ is normal. A *normalizer* for $\to$ is a function $N : \alpha \to \alpha$ together with, for every $a$, a proof that $a \to^* N(a)$ and a proof that $N(a)$ is normal; it asserts nothing about which reachable normal form is chosen.

Call $\to$ *terminating* if the relation $(a, b) \mapsto b \to a$ is well founded, that is, there is no infinite chain $a_0 \to a_1 \to a_2 \to \cdots$. Every terminating relation is normalizing, and this gives a normalizer for $\to$: for each state $a$ it chooses, by the axiom of choice, a normal state $n$ with $a \to^* n$. The construction is noncomputable and prescribes no reduction strategy.
