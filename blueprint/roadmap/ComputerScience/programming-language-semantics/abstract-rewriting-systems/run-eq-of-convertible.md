# Conversion preserves the normalizer's result under confluence

Let $\to$ be a binary relation on a type $\alpha$, an abstract reduction system oriented from a state to its reduct. Write $\to^*$ for its reflexive–transitive closure and $\leftrightarrow^*$ for *conversion*, the equivalence relation generated by $\to$. A state $n$ is *normal* if there is no $y$ with $n \to y$ (a state with a loop $n \to n$ is not normal), and $n$ is a *reachable normal form* of $a$ if $a \to^* n$ and $n$ is normal. Two states $a, b$ are *joinable* if there is $c$ with $a \to^* c$ and $b \to^* c$. The relation $\to$ is *confluent* if for all $a, b, c$ with $a \to^* b$ and $a \to^* c$, the states $b$ and $c$ are joinable. A *normalizer* for $\to$ is a function $N : \alpha \to \alpha$ together with, for every $a$, a proof that $a \to^* N(a)$ and a proof that $N(a)$ is normal; it asserts nothing about which reachable normal form is chosen.

Assume $\to$ is confluent and let $N$ be a normalizer for $\to$. If $a \leftrightarrow^* b$, then $N(a) = N(b)$.
