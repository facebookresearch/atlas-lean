# Sound, optimal and complete abstractions

The abstract-interpretation view of program analysis: an analysis lattice related to a collecting semantics by an abstraction function and a concretization function forming a Galois connection, and the notions of soundness, optimality and completeness for the abstract counterparts of semantic operations. The optimal abstraction $\alpha \circ f \circ \gamma$ is the most precise sound one, and sound and complete abstractions transfer least fixed points exactly. The octagon domain is a relational abstract domain of constraints $\pm x \pm y \le c$ with normal forms computed by shortest-path closure.
