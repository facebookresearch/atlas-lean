# Dyck reachability

For $k \ge 0$ let $\Sigma_k = \{\epsilon\} \cup \{\alpha_i, \bar\alpha_i\}_{i=1}^k$ consist of $k$ types of opening and closing parentheses and a null symbol $\epsilon$, and let the *Dyck language* $L_k$ be generated by

$$S \to S\,S \mid A_1\,\bar A_1 \mid \dots \mid A_k\,\bar A_k \mid \epsilon, \qquad A_i \to \alpha_i\,S, \qquad \bar A_i \to S\,\bar\alpha_i.$$

In a $\Sigma_k$-labeled directed graph $G = (V, E)$, with $E \subseteq V \times V \times \Sigma_k$ and at most one label per ordered pair of nodes, a node $v$ is *Dyck-reachable* from $u$ if some path from $u$ to $v$ has its word in $L_k$, where the word of a path is the concatenation of its labels and the null symbol $\epsilon$ stands for the empty word, both there and in the grammar; this is [CFL-reachability](context-free-language-reachability.md) for $L_k$. A set of nodes is a *Dyck SCC* if each of its nodes is Dyck-reachable from each other. The graph is *bidirected* if for all nodes $u, v$: $(u, v, \epsilon) \in E$ iff $(v, u, \epsilon) \in E$, and $(u, v, \alpha_i) \in E$ iff $(v, u, \bar\alpha_i) \in E$ for every $i$.
