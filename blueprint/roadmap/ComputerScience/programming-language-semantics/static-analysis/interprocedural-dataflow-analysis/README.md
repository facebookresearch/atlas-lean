# Interprocedural dataflow analysis

Dataflow analysis across procedure calls in the IFDS framework of Reps, Horwitz and Sagiv: interprocedural, finite, distributive, subset problems on a supergraph, solved over the interprocedurally valid paths, in which calls and returns match like parentheses. Functions on a powerset that distribute over union have compact graph representations, which turn such problems into reachability along realizable paths of an exploded supergraph, solved by the polynomial tabulation algorithm.
