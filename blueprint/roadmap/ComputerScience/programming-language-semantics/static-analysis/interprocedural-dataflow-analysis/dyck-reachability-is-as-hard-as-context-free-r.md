# Dyck reachability is as hard as context-free recognition

Fix a context-free grammar $G$ in [Chomsky normal form](../../../../TheoryOfComputation/context-free-languages/grammars-and-pushdown-automata/chomsky-normal-form/is-chomsky-normal-form.md). For the empty word, the answer is whether $G$ has the production $S \to \varepsilon$, and a constant-size instance with that answer serves. For every nonempty word $s$ of length $n$ there is a labeled graph $G^s$ with $O(n)$ nodes and edges, built in linear time, and nodes $v$ and $u_n$ of it, such that $u_n$ is [Dyck-reachable](dyck-reachability.md) from $v$ if and only if $s$ is generated by $G$. Consequently, a combinatorial algorithm for single-pair Dyck reachability in time $T(n)$ gives one for context-free recognition in time $O(n + T(n))$.

**Proof idea.** For nonempty $s$, $G^s$ consists of a path $v \to u_0 \to \dots \to u_n$ whose edges carry parentheses for the start symbol and for the letters of $s$, together with $n$ copies of a gadget whose edges encode the productions $A \to B\,C$ and $A \to a$ of $G$, linked to the path by $\epsilon$-edges. Along a path from $v$ to $u_n$ whose word is in $L_k$, the closing parentheses list a preorder traversal of a derivation tree of $s$, and conversely.
