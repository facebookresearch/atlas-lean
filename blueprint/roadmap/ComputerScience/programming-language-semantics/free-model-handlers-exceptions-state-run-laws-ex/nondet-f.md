# Signature of explicit nondeterminism

Raw explicit-nondeterminism signature: failure `fail : 0` and
binary choice `choice` (the paper's `pick : 2`), as in Plotkin and
Pretnar's Section 6.4.

The signature carries no equations: neither the monoid equations of Section 6.4 nor the semilattice equations of `or : 2` are imposed.
