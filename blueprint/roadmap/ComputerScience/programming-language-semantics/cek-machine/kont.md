# Continuations of the CEK machine

For the CEK machine, where a closure $\langle t, e\rangle$ pairs an untyped de Bruijn lambda term with a list of closures, the *continuations* form the inductive type generated by:

- $\mathsf{mt}$: nothing remains, and the value being computed is the result;
- $\mathsf{arg}(u, e, k)$ for a term $u$, an environment $e$ and a continuation $k$: when it receives the value $v$ of the function part, evaluate the argument $u$ in $e$ under the continuation $\mathsf{fn}(v, k)$;
- $\mathsf{fn}(v, k)$ for a closure $v$ and a continuation $k$: $v$ is the value of the function part; when the value of the argument returns, apply $v$, whatever its term and environment, to it under $k$.

## Sources

- M. Felleisen and D. P. Friedman, *Control operators, the SECD-machine, and the λ-calculus*, 3rd Working Conference on the Formal Description of Programming Concepts, 1986. The machine here is a de Bruijn reformulation for the pure lambda calculus, without the control operators of that paper.
