# Untyped lambda terms for the CEK machine

The terms run by the CEK machine form the inductive type of untyped lambda terms with de Bruijn indices, generated by variables $x_n$ for $n \in \mathbb{N}$, abstractions $\lambda.\,t$ (index $0$ of the body $t$ refers to the bound variable) and applications $t\,u$.

## Sources

- M. Felleisen and D. P. Friedman, *Control operators, the SECD-machine, and the λ-calculus*, 3rd Working Conference on the Formal Description of Programming Concepts, 1986. The machine here is a de Bruijn reformulation for the pure lambda calculus, without the control operators of that paper.
