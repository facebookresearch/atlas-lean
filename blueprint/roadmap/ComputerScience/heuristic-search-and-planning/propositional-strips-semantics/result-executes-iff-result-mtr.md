# Total STRIPS execution is multistep transition

Fix a type $\alpha$ of atoms. A state is a finite set $s \subseteq \alpha$ of true atoms. An operator $o$ consists of finite sets of atoms $\mathrm{pre}^+(o)$, $\mathrm{pre}^-(o)$ (positive and negative preconditions), $\mathrm{add}(o)$ and $\mathrm{del}(o)$ (add and delete lists). The operator $o$ is applicable in $s$ when $\mathrm{pre}^+(o) \subseteq s$ and $\mathrm{pre}^-(o) \cap s = \emptyset$. Its progression is $o(s) = (s \cup \mathrm{add}(o)) \setminus \mathrm{del}(o)$. Its total result is $\mathrm{res}_o(s) = o(s)$ if $o$ is applicable in $s$, and $\mathrm{res}_o(s) = s$ otherwise. A task consists of an initial state $s_0$, finite goal sets $g^+, g^- \subseteq \alpha$ and a list $O$ of operators; a state $s$ is a goal state when $g^+ \subseteq s$ and $g^- \cap s = \emptyset$. A plan $(o_1, \dots, o_n)$ totally executes from $s$ to $s'$ when there are states $s = t_0, t_1, \dots, t_n = s'$ with $o_i \in O$ and $t_i = \mathrm{res}_{o_i}(t_{i-1})$ for each $i$; an inapplicable operator is an identity step. The total result transition system has a transition $s \xrightarrow{o} s'$ when $o \in O$ and $s' = \mathrm{res}_o(s)$. For all states $s, s'$ and every plan $(o_1, \dots, o_n)$, the plan totally executes from $s$ to $s'$ if and only if there is a sequence of transitions $s = t_0 \xrightarrow{o_1} t_1 \xrightarrow{o_2} \cdots \xrightarrow{o_n} t_n = s'$ in the total result system. In particular a trace may contain inapplicable operators as identity steps.
