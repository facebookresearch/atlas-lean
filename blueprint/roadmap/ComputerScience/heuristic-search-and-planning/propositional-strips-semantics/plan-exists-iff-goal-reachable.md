# STRIPS plan existence equals strict goal reachability

Fix a type $\alpha$ of atoms. A state is a finite set $s \subseteq \alpha$ of true atoms. An operator $o$ consists of finite sets of atoms $\mathrm{pre}^+(o)$, $\mathrm{pre}^-(o)$ (positive and negative preconditions), $\mathrm{add}(o)$ and $\mathrm{del}(o)$ (add and delete lists). The operator $o$ is applicable in $s$ when $\mathrm{pre}^+(o) \subseteq s$ and $\mathrm{pre}^-(o) \cap s = \emptyset$. Its progression is $o(s) = (s \cup \mathrm{add}(o)) \setminus \mathrm{del}(o)$. Its total result is $\mathrm{res}_o(s) = o(s)$ if $o$ is applicable in $s$, and $\mathrm{res}_o(s) = s$ otherwise. A task consists of an initial state $s_0$, finite goal sets $g^+, g^- \subseteq \alpha$ and a list $O$ of operators; a state $s$ is a goal state when $g^+ \subseteq s$ and $g^- \cap s = \emptyset$. A plan $(o_1, \dots, o_n)$ totally executes from $s$ to $s'$ when there are states $s = t_0, t_1, \dots, t_n = s'$ with $o_i \in O$ and $t_i = \mathrm{res}_{o_i}(t_{i-1})$ for each $i$; an inapplicable operator is an identity step. A plan is valid when it totally executes from $s_0$ to some goal state, and a task has a plan when some plan is valid. The strict transition system has states as states and operators as labels, with a transition $s \xrightarrow{o} s'$ when $o \in O$, $o$ is applicable in $s$ and $s' = o(s)$. A goal state is strictly reachable when some goal state can be reached from $s_0$ by finitely many transitions of the strict system. A task has a plan if and only if a goal state is strictly reachable.
