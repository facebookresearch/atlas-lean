# Strict execution of a STRIPS plan

Fix a type $\alpha$ of atoms. A state is a finite set $s \subseteq \alpha$ of true atoms. An operator $o$ consists of finite sets of atoms $\mathrm{pre}^+(o)$, $\mathrm{pre}^-(o)$ (positive and negative preconditions), $\mathrm{add}(o)$ and $\mathrm{del}(o)$ (add and delete lists). The operator $o$ is applicable in $s$ when $\mathrm{pre}^+(o) \subseteq s$ and $\mathrm{pre}^-(o) \cap s = \emptyset$. Its progression is $o(s) = (s \cup \mathrm{add}(o)) \setminus \mathrm{del}(o)$. Let $O$ be the operator list of a task. Strict execution is the relation between a state, a list of operators and a final state generated by two rules:

- the empty plan executes from $s$ to $s$;
- if $o \in O$, $o$ is applicable in $s$, and the plan $\pi$ executes from $o(s)$ to $s'$, then the plan $o :: \pi$ executes from $s$ to $s'$.

So $(o_1, \dots, o_n)$ executes from $s$ to $s'$ exactly when firing the operators in order, each a task operator applicable in the current state, ends in $s'$.
