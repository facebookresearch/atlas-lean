# Total execution of a STRIPS plan

Fix a type $\alpha$ of atoms. A state is a finite set $s \subseteq \alpha$ of true atoms. An operator $o$ consists of finite sets of atoms $\mathrm{pre}^+(o)$, $\mathrm{pre}^-(o)$ (positive and negative preconditions), $\mathrm{add}(o)$ and $\mathrm{del}(o)$ (add and delete lists). The operator $o$ is applicable in $s$ when $\mathrm{pre}^+(o) \subseteq s$ and $\mathrm{pre}^-(o) \cap s = \emptyset$. Its progression is $o(s) = (s \cup \mathrm{add}(o)) \setminus \mathrm{del}(o)$. Its total result is $\mathrm{res}_o(s) = o(s)$ if $o$ is applicable in $s$, and $\mathrm{res}_o(s) = s$ otherwise. Let $O$ be the operator list of a task. Total execution is the relation between a state, a list of operators and a final state generated by two rules:

- the empty plan executes from $s$ to $s$;
- if $o \in O$ and the plan $\pi$ executes from $\mathrm{res}_o(s)$ to $s'$, then the plan $o :: \pi$ executes from $s$ to $s'$.

Every operator must belong to the task, but an inapplicable operator is an identity step rather than making the plan inexecutable.
