# Step-indexed randomized planner

Let $C$ be a topological space and $\Omega$ a sample space. A randomized planner on $C$ over $\Omega$ is a function that assigns to every path problem $P$ on $C$, every sample $\omega \in \Omega$ and every step $k \in \mathbb{N}$ a planner answer for $P$: a found path from start to goal, a no-path report, or "still running".
