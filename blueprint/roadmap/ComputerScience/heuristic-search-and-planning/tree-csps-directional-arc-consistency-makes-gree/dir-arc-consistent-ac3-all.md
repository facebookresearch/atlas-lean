# AC-3 makes the domains directionally arc consistent

For finitely many variables and a symmetric binary CSP with no arc from a variable to itself, the domains AC-3 returns are directionally arc consistent for any parent map such that, for every variable $x$ with parent $p$, the arc $(p, x)$ from the parent to the child is an arc of the problem. The orientation matters: arcs are directed, and symmetry concerns only the allowed pairs.
