# Visibility around two squares is symmetric

Consider the closed squares $O_1 = [0,1] \times [0,1]$ and $O_2 = [2,3] \times [0,1]$ in the Euclidean plane $\mathbb{R}^2$ and the free set $G = \mathbb{R}^2 \setminus \operatorname{int}(O_1 \cup O_2)$. For points $a, b \in \mathbb{R}^2$, if $[a, b] \subseteq G$ then $[b, a] \subseteq G$: visibility is symmetric.
