# Solution of a path problem

A path problem on a topological space $C$ consists of a free set $F \subseteq C$, a start $q_I \in F$ and a goal $q_G \in F$. A continuous path $\gamma : [0,1] \to C$ with $\gamma(0) = q_I$ and $\gamma(1) = q_G$ solves the problem when $\gamma(t) \in F$ for every $t \in [0,1]$.
