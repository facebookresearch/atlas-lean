# All Leaves

The function $k^{\lceil d/2 \rceil}$ of a branching factor $k$ and a height $d$. On a uniform $k$-ary tree that is perfectly ordered, it is the number of leaves alpha-beta evaluates at an all node of height $d$, a node whose value fails the window in the other direction (at most the lower bound at a maximizer node, at least the upper bound at a minimizer node), so that every child is evaluated as a cut node.
