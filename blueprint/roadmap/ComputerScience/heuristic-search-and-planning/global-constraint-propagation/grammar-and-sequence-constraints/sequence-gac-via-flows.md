# Generalized arc consistency of SEQUENCE by network flows

The 0/1 SEQUENCE constraint is equivalent to a network flow problem on a graph with $O(n)$ vertices and arcs; given a feasible flow, the alternative value of an unfixed variable is supported exactly when its arc's flow can be switched along a residual cycle, so generalized arc consistency costs $O(n)$ once a flow is known, and $O(n^2)$ along a branch of fixings after initialization.

Let $C=\mathrm{SEQUENCE}(l,u,k,[X_1,\dots,X_n],\{1\})$ be a [SEQUENCE constraint](sequence-constraint.md) on distinct 0/1 variables, with $1\le k\le n$, $0\le l\le u\le k$ and $w=n-k+1$ windows.

*The network.* Write each window as two equations with a surplus $Y_j\ge0$ and a slack $Z_j\ge0$: $\sum_{i=j}^{j+k-1}X_i-Y_j=l$ and $\sum_{i=j}^{j+k-1}X_i+Z_j=u$, listed alternately. Every column of this system has its nonzero entries in consecutive rows, so appending a zero row and replacing each row $r\ge2$ by row $r$ minus row $r-1$ (Veinott–Wagner) leaves a single $+1$ and a single $-1$ in each column: rows become vertices and columns become tagged arcs (columns of different variables can give parallel arcs, for example all $X_i$ when $k=n$). Each nonzero right-hand side $b_r$ becomes an arc from a source $s$ (if $b_r>0$) or to a sink $t$ (if $b_r<0$) with bounds $[|b_r|,|b_r|]$; for $b_r=0$ the arc is kept with bounds $[0,0]$. The arc of $X_i$ has bounds $[0,1]$ if $D(X_i)=\{0,1\}$, $[0,0]$ if $D(X_i)=\{0\}$ and $[1,1]$ if $D(X_i)=\{1\}$; an empty domain fails at once. The arcs of $Y_j$ and $Z_j$ have bounds $[0,u-l]$, which no solution exceeds.

**Theorem.**

1. The network has $2w+3$ vertices (with $s$ and $t$) and $n+4w+1=5n-4k+5$ arcs, and every feasible flow is an $s$–$t$ flow of value $f=u+(w-1)(u-l)=(n-k)(u-l)+u$. The solutions of $C$ correspond one-to-one to the integral feasible flows, $X_i=1$ exactly when the arc of $X_i$ carries one unit.
2. Let $g$ be an integral feasible flow and $X_i$ a variable with $D(X_i)=\{0,1\}$ whose arc $e_i$ carries $g_i$. The value $1-g_i$ has a support iff the endpoints of $e_i$ are strongly connected in the residual graph of $g$ (whose only residual copy of $e_i$ is forward if $g_i=0$ and backward if $g_i=1$). The value $g_i$ itself is supported by $g$, and the value of a singleton domain is supported iff a feasible flow exists. Hence, given $g$, [generalized arc consistency](../generalized-arc-consistency.md) is enforced in $O(n)$ time by one strongly connected components computation.
3. If every initial domain is $\{0,1\}$, a feasible flow is found, or shown not to exist, by the Ford–Fulkerson augmenting path method in $O(n(1+f))$ time.
4. Along one branch of the search tree, starting from a feasible flow on which GAC has been enforced, suppose a variable is fixed to a value that is still in its domain. If the flow already uses that value, only the components are recomputed, in $O(n)$; otherwise the residual cycle that certified the value's support is found and the flow is rerouted by one unit around it, in $O(n)$, after which GAC is enforced again. With at most $n$ such fixings, maintaining GAC costs $O(n^2)$ along the branch, in addition to obtaining the initial flow.

## Expansion

*Item 1* is Theorem 1 of Maher, Narodytska, Quimper and Walsh. The row operations do not change the solutions of the linear system, and the resulting network matrix has one arc per column. Integral feasible flows are the 0/1 solutions in $X$ with nonnegative integral surplus and slack, i.e. the solutions of $C$. The counts follow from the transformed matrix: $2w+1$ rows plus $s$ and $t$, one arc per column ($n+2w$) and one source or sink arc per row.

*Item 2.* For a variable with domain $\{0,1\}$ the arc $e_i$ has bounds $[0,1]$, and changing $X_i$ to $1-g_i$ means switching the flow on $e_i$ while keeping the value $f$; by the unit-arc theorem this is possible iff the endpoints of $e_i$ are strongly connected in the residual graph, the only residual copy of $e_i$ being forward if $g_i=0$ and backward if $g_i=1$. Maher et al. state this strongly-connected-components test for pushing an extra unit and say that removing a unit is checked similarly. For a variable with singleton domain the arc bounds are equal, there is no residual copy of $e_i$, and its value is supported by any feasible flow. Since $n\ge k\ge1$, the network has $2w+3\le 2n+3$ vertices and $5n-4k+5\le 5n+1$ arcs, so its residual graph has $O(n)$ vertices and arcs; in compressed sparse row form, built in $O(n)$ instructions from indexed arc records by counting outdegrees and prefix sums, its strongly connected components are computed in $O(n)$ word-RAM instructions by the linked linear-time algorithm, on a machine whose word size $\beta$ satisfies $|V|+|E|<2^{\beta}$ for the residual graph, and is also large enough for the flow arithmetic, flow values being at most $f\le nk$ (the symbol $\beta$ is used because $w$ denotes the number of windows; the source cites Tarjan's algorithm, and any linear-time algorithm serves).

*Item 3.* With full Boolean domains every lower bound other than those on the source and sink arcs is zero. Treating the prescribed source and sink amounts as capacities and ignoring their lower bounds, a maximum $s$–$t$ flow saturates all source arcs iff it saturates all sink arcs (both totals equal $f$, the sum of the right-hand sides being zero), and such a flow is exactly a feasible flow; Ford–Fulkerson performs at most $f$ augmentations, each one search in a residual graph with $O(n)$ vertices and arcs, which costs $O(n)$ by the linked BFS bound, followed by path reconstruction (linear by the linked reconstruction cost) and a flow update along the path, also $O(n)$; one final search that finds no augmenting path, and $O(n)$ set-up, complete the $O(n(1+f))$ bound. The source states this initial cost as $O(n((n-k)(u-l)+u))$ and also quotes Goldberg and Rao's maximum-flow algorithm. For initial domains with variables already fixed to 1, the reduction to a maximum flow moves those lower bounds into the source and sink amounts and the augmentation bound above is not claimed.

*Item 4* follows Régin's incremental scheme for ALLDIFFERENT and the global cardinality constraint, as the source does. When $X_i$ is fixed to the value $g_i$ its arc already carries, the flow is kept, and only the bounds of $e_i$ and the components change, in $O(n)$. When it is fixed to $1-g_i$, that value was kept by the previous GAC pass, so in the residual graph of $g$, before the new bounds are imposed, the residual copy of $e_i$ (from $u$ to $v$, say) lies on a cycle. One search from $v$ finds $u$, in $O(n)$ by the linked BFS bound; walking the parent pointers back from $u$ gives the path, in $O(n)$ by the linked reconstruction cost, and for each step one residual arc from the parent to the child is chosen by scanning the parent's adjacency list, $O(n)$ in total because the path visits each vertex once and the graph has $O(n)$ arcs (parallel arcs are distinct records, and any one of them will do); adding one unit on forward arcs and subtracting one on backward arcs of the cycle, including $e_i$, takes $O(n)$. Then the bounds of $e_i$ are fixed and the components recomputed as in item 2, in $O(n)$. This improves the $O(n^3)$ algorithm of van Hoeve, Pesant, Rousseau and Sabharwal and the $O(n^2\log n)$ encoding of Brand et al.

*Missing proof prerequisites (not expanded here).* A complete expansion adds pages for two results. (i) The Veinott–Wagner transformation: a linear system whose matrix has the consecutive-ones property in every column becomes, after appending a zero row and differencing consecutive rows, the node–arc incidence matrix of a network, with the same solutions; this gives item 1. (ii) The Ford–Fulkerson bound: on a network with integral capacities, each augmentation raises the flow value by at least one, so a maximum flow of value $f$ needs at most $f$ augmentations, each found by one search in $O(|V|+|E|)$ time by the linked BFS bound (which makes $|V|$ dequeue attempts), that is $O(n)$ in this network; this gives item 3 together with the linked BFS bound for each search. The other prerequisites are linked: the bounded-flow reduction for items 1 and 3, the unit-arc rerouting theorem for item 2, the linear-time strongly-connected-components algorithm for items 2 and 4, and the BFS and path-reconstruction bounds for items 3 and 4.
