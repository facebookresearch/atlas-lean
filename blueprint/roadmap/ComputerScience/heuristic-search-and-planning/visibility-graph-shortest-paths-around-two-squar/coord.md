# Coordinates of the two-squares graph vertices

The coordinates of the ten vertices of the two-squares visibility graph, as points of the Euclidean plane, are

$$s = (-1, \tfrac12),\ t = (4, \tfrac12),\ A = (0,0),\ B = (1,0),\ C = (1,1),\ D = (0,1),$$

$$E = (2,0),\ F = (3,0),\ P = (3,1),\ Q = (2,1).$$
