# Collision of a translating rigid body

Let $V$ be an additive commutative group and $A_0 \subseteq V$ a body given at the reference placement $0$. The translating placement sends a configuration $q \in V$ to $A(q) = \{ a + q : a \in A_0 \}$, and the obstacle region of an obstacle set $O \subseteq V$ is $\mathcal{C}_{\mathrm{obs}} = \{ q \in V : A(q) \cap O \neq \emptyset \}$.

For every $q \in V$,

$$q \in \mathcal{C}_{\mathrm{obs}} \iff \exists a \in A_0,\ a + q \in O .$$
