# Solvable path problem

A path problem on a topological space $C$ consists of a free set $F \subseteq C$, a start $q_I \in F$ and a goal $q_G \in F$. The problem is solvable when some continuous path $\gamma : [0,1] \to C$ from $q_I$ to $q_G$ stays in $F$, that is $\gamma(t) \in F$ for all $t \in [0,1]$.
