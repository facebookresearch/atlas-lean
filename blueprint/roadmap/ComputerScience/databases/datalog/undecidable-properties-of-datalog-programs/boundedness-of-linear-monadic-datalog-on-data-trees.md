# Boundedness of linear monadic datalog on data trees is undecidable

On finite trees whose nodes carry labels from an infinite alphabet that can be compared for equality, it is undecidable whether a linear monadic datalog program using the child and descendant relations is bounded on its goal predicate, with recursion depth independent of the database. Without the descendant relation the problem is decidable over words and ranked trees.

**Setting (Mazowiecki, Ochremiak and Witkowski).** Databases are finite words, or finite ranked or unranked trees, whose nodes carry labels from an infinite alphabet; programs can test a node for a fixed label and test whether two nodes carry equal labels. A datalog program is *monadic* if all intensional predicates in rule heads are unary, *linear* if every rule body uses at most one intensional predicate, and *connected* if within each rule all variables are connected; only connected monadic programs are considered. $\mathsf{Datalog}(\downarrow, \downarrow_+)$ allows the child relation $\downarrow$ and the descendant relation $\downarrow_+$ in rule bodies, $\mathsf{Datalog}(\downarrow)$ only the child relation, and $\mathsf{L\text{-}Datalog}(\downarrow, \downarrow_+)$ is the linear fragment of the former. Each program has a designated unary *goal* predicate, and on a database $D$ it computes the unary relation $P(D)$ of the nodes where the goal holds; two programs are equivalent if they compute the same relation on every database (Section 2). For a program $P$ and a database $D$ write $P^n(D)$ for the set of goal facts derivable from $D$ by at most $n$ applications of the rules, that is, by proof trees of height at most $n$; this is the goal's part of the $n$-th stage of the [immediate consequence operator](../datalog-programs-and-the-immediate-consequence-operator.md). $P$ is *bounded* if there is a number $n$, depending only on $P$, such that $P(D) = P^n(D)$ for every database $D$ of the considered class (Section 4 of the source); the other intensional predicates need not stabilize within $n$ stages. The source notes that only the output on the goal predicate matters, which is why this property is sometimes called predicate boundedness (footnote 4); it is what [boundedness of Datalog programs and queries](../boundedness-of-datalog-is-undecidable.md) calls boundedness of the query $(P, \text{goal})$, not of the program. The *boundedness problem* asks whether a given program is bounded. For $\mathsf{Datalog}(\downarrow)$ a program is bounded exactly when it is equivalent to a union of conjunctive queries (Proposition 9), but with the descendant relation the two notions differ: a $\mathsf{Datalog}(\downarrow, \downarrow_+)$ program can be unbounded and still equivalent to a union of conjunctive queries (Example 10).

**Theorem (Mazowiecki, Ochremiak and Witkowski).** The boundedness problem for $\mathsf{L\text{-}Datalog}(\downarrow, \downarrow_+)$ is undecidable over words and over ranked or unranked trees.

The same paper notes, from the proofs of an earlier undecidability result for containment, that containment of an $\mathsf{L\text{-}Datalog}(\downarrow, \downarrow_+)$ program in a union of conjunctive queries is undecidable over ranked and unranked trees (Proposition 4), and proves that boundedness for $\mathsf{Datalog}(\downarrow)$ is in PSPACE over words and in 2EXPTIME over ranked trees, and that containment of a linear $\mathsf{Datalog}(\downarrow)$ program in a union of conjunctive queries is EXPSPACE-complete over unranked trees.

## Expansion

The reduction asks whether a Turing machine has halting runs from the empty tape of arbitrary length, which is undecidable because a halting machine can be modified to idle arbitrarily long before halting. A tree encodes a run as a word of configurations separated by $\#$, each tape cell written as four consecutive nodes giving the row number, the next row number, the column number and the tape symbol, placed on a path from some node up to the root. The program is the disjunction of a recursive program $P$ that follows a correct encoding and a program $Q$, equivalent to a union of conjunctive queries, that detects errors in the encoding; on any tree with an error the combined program holds everywhere after three steps. Only the goal is controlled: the combined program takes the goal from either $P$ or $Q$, and on a tree with an error the goal holds at every node after three steps, while the auxiliary predicates may need more. The combined program is unbounded if and only if the machine has arbitrarily long halting runs.
