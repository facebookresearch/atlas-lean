# Well-founded semantics agrees with stratified semantics

The well-founded semantics assigns to every Datalog program with negation and every input instance a
three-valued model, computable by the alternating fixpoint construction. If the program is stratifiable,
then its well-founded model is total (two-valued) on every input instance and coincides with the
stratified semantics.
