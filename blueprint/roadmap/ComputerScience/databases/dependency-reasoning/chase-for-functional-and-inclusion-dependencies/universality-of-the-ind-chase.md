# Universality of the chase for inclusion dependencies

Let $S$ be a finite set of atoms, $\Sigma$ a finite set of inclusion dependencies and $S'$ a possibly infinite set of atoms that
satisfies $\Sigma$. If $(S, \bar u) \to (S', \bar v)$, then $(\mathrm{Chase}(S, \Sigma), \bar u) \to (S', \bar v)$.
