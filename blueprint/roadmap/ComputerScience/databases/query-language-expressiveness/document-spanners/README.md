# Document spanners

Document spanners extract relations of spans from strings; core spanners combine regex formulas with projection, union, natural join and string-equality selection, and their static analysis is undecidable.

- [Core spanners](core-spanners.md)
- [Universality and equivalence of core spanners are not semi-decidable](universality-of-core-spanners.md)
- [Containment of core spanners is not semi-decidable](containment-of-core-spanners.md)
- [Minimization of core spanner representations is not computable](minimization-of-core-spanners.md)
