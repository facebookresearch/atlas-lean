# The result of the chase for inclusion dependencies satisfies them

For a finite set of atoms $S$ and a finite set $\Sigma$ of inclusion dependencies, the possibly infinite set of atoms
$\mathrm{Chase}(S, \Sigma)$ satisfies $\Sigma$. When only infinite chase sequences exist, this relies on their fairness.
