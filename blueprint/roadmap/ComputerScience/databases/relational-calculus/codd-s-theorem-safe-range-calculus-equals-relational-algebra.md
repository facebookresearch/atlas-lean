# Codd's theorem: safe-range calculus equals relational algebra

The safe-range relational calculus and the relational algebra have the same expressive power: for every
safe-range calculus query there is a relational algebra expression with the same answer on every
instance, and conversely. Moreover, every safe-range query is domain independent.
