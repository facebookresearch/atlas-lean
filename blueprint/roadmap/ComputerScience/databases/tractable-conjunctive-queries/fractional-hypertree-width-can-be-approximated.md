# Fractional hypertree width can be approximated

**Theorem (Marx).** For every $r \ge 1$ there is an algorithm running in time $n^{O(r^3)}$ that, given a hypergraph of
[fractional hypertree width](fractional-hypertree-decompositions-and-width.md) at most $r$ and $n$ vertices and edges, finds a
fractional hypertree decomposition of width $O(r^3)$. Deciding whether a hypergraph has fractional hypertree width at most
$r$ is NP-hard when $r$ is part of the input.
