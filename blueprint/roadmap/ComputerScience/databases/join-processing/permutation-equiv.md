# Permutation representation of a matching relation

On a domain of size $n>0$, families
of $k$ permutations correspond bijectively to matching relations of arity $k+1$. Fixing the
first column as the index removes the freedom to reorder the rows: each other column's
permutation sends $x$ to its value in the unique row whose first value is $x$.

## Sources

- Derived from the matching condition in Beame, Koutris and Suciu, *Communication Steps for Parallel Query Processing* (PODS 2013), §2.5, which mentions the binary case explicitly.
