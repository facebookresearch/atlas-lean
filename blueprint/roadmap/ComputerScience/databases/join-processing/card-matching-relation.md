# Counting matching relations

On a domain of size $n>0$, there are $(n!)^k$ matching
relations of arity $k+1$: there is one arbitrary permutation per non-first column.

## Sources

- Beame, Koutris and Suciu, *Communication Steps for Parallel Query Processing* (PODS 2013), §3.2.1, paragraph beginning “Observe that for a randomly chosen matching database”.
