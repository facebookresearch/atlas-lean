# Restrictions by lists with the same members up to observation congruence in static CCS

Let the channel names form a type with decidable equality, and consider the static CCS processes (prefix by a CCS label, choice, parallel composition with communication, restriction $P \setminus L$ by a finite list $L$ of names, and relabelling $P[f]$ by a finite relabelling $f$) with the transitions of static CCS. For all finite lists $L_1$, $L_2$ of names with the same members ($a \in L_1$ if and only if $a \in L_2$, for every name $a$) and every process $P$, $P \setminus L_1$ and $P \setminus L_2$ are observation congruent (rooted weakly bisimilar) in this transition system.
