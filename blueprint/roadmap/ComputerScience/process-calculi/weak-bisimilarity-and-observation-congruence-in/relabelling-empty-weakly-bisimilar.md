# Relabelling by the empty table up to weak bisimilarity in static CCS

Let the channel names form a type with decidable equality, and consider the static CCS processes (prefix by a CCS label, choice, parallel composition with communication, restriction $P \setminus L$ by a finite list $L$ of names, and relabelling $P[f]$ by a finite relabelling $f$) with the transitions of static CCS. For every process $P$, the relabelling of $P$ by the relabelling with the empty table (which sends the input on every name $a$ to the input on $a$) and $P$ are weakly bisimilar in this transition system: some bisimulation of the saturated system, whose transitions are the weak transitions, relates them.
