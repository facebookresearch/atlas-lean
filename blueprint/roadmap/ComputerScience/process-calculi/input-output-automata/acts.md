# Actions of a signature

Let $S$ be an action signature, with input actions $\mathrm{in}(S)$, output actions $\mathrm{out}(S)$ and internal actions $\mathrm{int}(S)$. The actions of $S$ are all its input, output and internal actions: $\mathrm{acts}(S) = \mathrm{in}(S) \cup \mathrm{out}(S) \cup \mathrm{int}(S)$.
