# Finite schedule of an I/O automaton

Let $A$ be an [input/output automaton](ioautomaton.md). A finite sequence $\beta$ of actions is a finite schedule of $A$ when it labels a finite execution of $A$ from a start state: $s_0 \xrightarrow{\beta} s$ for some start state $s_0$ and some state $s$ (Lynch and Tuttle, 1989, §3.1).

## Sources

- N. A. Lynch, M. R. Tuttle, *An introduction to input/output automata*, CWI Quarterly 2(3), 1989, 219–246: §3.1.
