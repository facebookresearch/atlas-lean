# Action signature

An action signature over a set $\alpha$ of actions consists of three pairwise disjoint subsets of $\alpha$: the input actions $\mathrm{in}(S)$, the output actions $\mathrm{out}(S)$ and the internal actions $\mathrm{int}(S)$ (Lynch and Tuttle, 1989, §3.1).

## Sources

- N. A. Lynch, M. R. Tuttle, *An introduction to input/output automata*, CWI Quarterly 2(3), 1989, 219–246: §3.1.
