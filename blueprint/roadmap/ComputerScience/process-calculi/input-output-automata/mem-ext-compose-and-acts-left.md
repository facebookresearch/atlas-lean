# External actions of a composition in its first component

Let $S_1$ and $S_2$ be [strongly compatible](strongly-compatible.md) action signatures. An action $a$ is an external action of the [composition](compose-signatures.md) $S_1 \cdot S_2$ and an action of $S_1$ if and only if it is an external action of $S_1$: $\mathrm{ext}(S_1 \cdot S_2) \cap \mathrm{acts}(S_1) = \mathrm{ext}(S_1)$.
