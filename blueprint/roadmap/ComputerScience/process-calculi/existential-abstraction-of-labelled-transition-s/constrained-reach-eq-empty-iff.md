# Spuriousness criterion for abstract paths

Let $L$ be a labelled transition system with states $S$ and labels $\Lambda$, given by its transition relation $s \xrightarrow{\mu} t$, and let $\alpha : S \to T$. For a predicate $\mathrm{Init}$ on $S$, a sequence $p : \mathbb{N} \to T$ of abstract states and a sequence $\mu : \mathbb{N} \to \Lambda$ of labels, the constrained reachability sets $C_k \subseteq S$ are $C_0 = \{ s : \mathrm{Init}(s) \text{ and } \alpha(s) = p_0 \}$ and $C_{n+1} = \{ t : \alpha(t) = p_{n+1} \text{ and } s \xrightarrow{\mu_n} t \text{ for some } s \in C_n \}$. For every $k \in \mathbb{N}$, $C_k = \emptyset$ if and only if there is no sequence $(s_i)_{i \in \mathbb{N}}$ of states with $\mathrm{Init}(s_0)$, $\alpha(s_i) = p_i$ for every $i \le k$, and $s_i \xrightarrow{\mu_i} s_{i+1}$ for every $i < k$; that is, exactly when the first $k$ steps of the abstract path have no concrete realization from an initial state.
