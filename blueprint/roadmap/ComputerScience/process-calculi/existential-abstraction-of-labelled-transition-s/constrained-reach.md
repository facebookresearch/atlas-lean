# Constrained reachability sets along an abstract path

Let $L$ be a labelled transition system with states $S$ and labels $\Lambda$, given by its transition relation $s \xrightarrow{\mu} t$, and let $\alpha : S \to T$. For a predicate $\mathrm{Init}$ on $S$, a sequence $p : \mathbb{N} \to T$ of abstract states and a sequence $\mu : \mathbb{N} \to \Lambda$ of labels, the constrained reachability sets $C_k \subseteq S$ are $C_0 = \{ s : \mathrm{Init}(s) \text{ and } \alpha(s) = p_0 \}$ and $C_{n+1} = \{ t : \alpha(t) = p_{n+1} \text{ and } s \xrightarrow{\mu_n} t \text{ for some } s \in C_n \}$. Thus $C_k$ holds the concrete states abstracting to $p_k$ that are reached from an initial state abstracting to $p_0$ by steps labelled $\mu_0, \dots, \mu_{k-1}$ through states abstracting to $p_1, \dots, p_{k-1}$; they test whether the first $k$ steps of an abstract path are feasible in $L$. Only the entries $p_0, \dots, p_k$ and $\mu_0, \dots, \mu_{k-1}$ affect $C_k$.
