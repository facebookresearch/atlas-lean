# Reduction relation of the π-calculus

The reduction relation $\to$ on [processes](proc.md) is generated by the following rules:

- communication: if the output $\bar{a}\langle b\rangle.P'$ is [selectable](select.md) from $P$ and the input $a(\cdot).Q'$ is selectable from $Q$, then $P \mid Q \to P' \mid Q'[b]$, where $Q'[b]$ [substitutes](subst.md) the sent name $b$ for the input variable;
- reduction under parallel composition, on either side: if $P \to P'$ then $P \mid Q \to P' \mid Q$ and $Q \mid P \to Q \mid P'$;
- reduction under restriction: if $P \to P'$ then $\nu P \to \nu P'$;
- reduction up to [structural congruence](cong.md): if $P \equiv P'$, $P' \to Q'$ and $Q' \equiv Q$, then $P \to Q$.
