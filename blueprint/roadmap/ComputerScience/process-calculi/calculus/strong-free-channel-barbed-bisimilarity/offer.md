# Free-channel guard offered without reduction

The relation "the process $P$ offers the [observable](observable.md) $o$" is generated by the following rules:

- if an input $c_n(\cdot).Q$ on a free channel is [selectable](../the-calculus-syntax-substitution-structural-cong/select.md) from $P$, then $P$ offers the input on $c_n$;
- if an output $\bar{c}_n\langle b\rangle.Q$ on a free channel is selectable from $P$, then $P$ offers the output on $c_n$;
- if $P$ offers $o$, then $P \mid Q$, $Q \mid P$ and $\nu P$ offer $o$.

A guard is thus exposed without any reduction; restrictions hide bound subjects but not free channels.
