# Structural congruence preserves unguarded outputs

If the processes $P$ and $Q$ are [structurally congruent](../the-calculus-syntax-substitution-structural-cong/cong.md), then $P$ has an [unguarded output](has-unguarded-output.md) if and only if $Q$ does: no structural rearrangement, replication and scope laws included, exposes an output from an input-guarded process.
