# Barbs of an input prefix

For a [channel name](../the-calculus-syntax-substitution-structural-cong/name.md) $a$, a process $P$ and a free-channel observable $o$: the input $a(\cdot).P$ has the [barb](barb.md) $o$ if and only if $a = c_n$ is a free channel and $o$ is the input on $c_n$. A waiting input is observable although it cannot reduce alone.
