# Barbs of an output prefix

For [channel names](../the-calculus-syntax-substitution-structural-cong/name.md) $a$, $b$, a process $P$ and a free-channel observable $o$: the output $\bar{a}\langle b\rangle.P$ has the [barb](barb.md) $o$ if and only if $a = c_n$ is a free channel and $o$ is the output on $c_n$. The barb sees only the free subject and the direction, not the object $b$ or the continuation $P$.
