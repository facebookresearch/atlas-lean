# Free-channel input is not barbed bisimilar to nil

For every natural number $n$ and process $P$, the input $c_n(\cdot).P$ on the free channel $c_n$ is not [strongly barbed bisimilar](barbed-bisimilar.md) to $\mathbf{0}$: waiting for input is not equivalent to doing nothing. Bisimilarity of reductions alone would not distinguish them, since neither process reduces.
