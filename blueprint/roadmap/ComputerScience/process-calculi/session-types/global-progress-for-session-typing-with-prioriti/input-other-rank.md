# Active roles on other names rank after an input subject

Let $n$ be a natural number, $\Delta$ an ownership context, $a$ a name and $p$ a process with
$\Delta \vdash^{\mathrm{rk}}_n a(\cdot).p$. Let $d$ be an endpoint whose name differs from $a$ and
$u$ a capability with $\Delta(d) = u$ whose protocol does not have head $\mathrm{end}$. Then there
are an endpoint $e$ with name $a$ and a capability $c$ with $\Delta(e) = c$ and the rank of $c$
strictly less than the rank of $u$.
