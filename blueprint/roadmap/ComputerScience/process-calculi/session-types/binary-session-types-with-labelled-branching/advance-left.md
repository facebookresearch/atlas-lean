# Advancing one side of an ownership split advances the context

If a context $\Gamma$ splits into $\Delta$ and $\Theta$, and $\Delta$ advances at channel $a$ by an action to $\Delta'$, then $\Gamma$ advances at $a$ by that action to $\Delta' \cup \Theta$, and $\Delta' \cup \Theta$ splits into $\Delta'$ and $\Theta$.
