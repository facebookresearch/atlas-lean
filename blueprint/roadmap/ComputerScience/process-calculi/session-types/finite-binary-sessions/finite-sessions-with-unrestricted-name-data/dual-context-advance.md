# Dualizing a context commutes with advancing an endpoint

For every session context $\Gamma$, channel number $a$ and finite binary session type $S$,

$$
\overline{\Gamma[a \mapsto S]} = \overline{\Gamma}[a \mapsto \overline{S}],
$$

where $\Gamma[a \mapsto S]$ replaces the entry of $\Gamma$ at $a$ by $S$ and $\overline{\Gamma}$ is
the pointwise dual of $\Gamma$.
