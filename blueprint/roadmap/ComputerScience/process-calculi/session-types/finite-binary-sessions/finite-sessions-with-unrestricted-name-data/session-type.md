# Finite binary session types

The finite binary session types are generated by the grammar

$$
S ::= \mathrm{end} \mid {!S} \mid {?S},
$$

where $\mathrm{end}$ is the completed protocol, ${!S}$ sends one name and continues as $S$, and
${?S}$ receives one name and continues as $S$. The transmitted names carry no type of their own.
