# Session communication steps are π-calculus reductions

Let $(p,q)$ and $(p',q')$ be pairs of π-calculus processes. If $(p,q) \to (p',q')$ is a
communication step of binary configurations (an output on a free channel constant in one component
synchronising with an input on the same constant in the other), then $p \mid q$ reduces to $p' \mid
q'$ in one step of π-calculus reduction.
