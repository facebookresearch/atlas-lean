# Receiver worker process

For a name $b$, the receiver worker is $W_r(b) = b(\cdot).\overline{\mathrm{c}_{711}}\langle
\uparrow_0 b\rangle.\mathbf{0}$: it receives one name on $b$ and then sends $b$ on the trigger
$\mathrm{c}_{711}$, where $\uparrow_0 b$ is $b$ with its index raised by one if it is a variable (so
that it refers to $b$ under the input binder).
