# Sender service signature of the recurring example

For a polarity $r$, the sender signature is $\sigma_s(r) = (0, r, \kappa)$: priority $0$, polarity
$r$ of the transferred endpoint and capability $\kappa = (7,R)$, where $R$ is the recurring send
protocol (the cursor at the single node of the one-node graph that sends a name and loops to
itself).
