# The recurring interface is balanced

For every name $b$ and polarity $r$, the recurring interface $I_{b,r} = \{b^{r} \mapsto \kappa\}
\cup \{b^{\bar r} \mapsto \bar\kappa\}$ is semantically balanced: for every endpoint $e$ with
$I_{b,r}(e) = c$ there is $d$ with $I_{b,r}(\bar e) = d$ and $d \approx \bar c$ (equal ranks,
tree-equivalent protocols). Here $\kappa = (7,R)$ is the recurring capability.
