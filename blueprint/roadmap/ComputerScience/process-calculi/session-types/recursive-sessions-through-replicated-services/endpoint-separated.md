# A fresh endpoint singleton is separated from the triggers

Let $r$, $r'$ be polarities, $b$ a name with $b \ne \mathrm{c}_{710}$ and $b \ne \mathrm{c}_{711}$,
and $c$ a capability. Then the ownership context $\{b^{r'} \mapsto c\}$ is separated from
$\Gamma_r$: no endpoint it owns has as name a constant $\mathrm{c}_s$ declared in $\Gamma_r$ (here
$s \in \{710, 711\}$).
