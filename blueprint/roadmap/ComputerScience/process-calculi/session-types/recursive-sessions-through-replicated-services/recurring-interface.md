# Two-role linear interface of the recurring session

For a name $b$ and a polarity $r$, the recurring interface is the ownership context $I_{b,r} =
\{b^{r} \mapsto \kappa\} \cup \{b^{\bar r} \mapsto \bar\kappa\}$, owning both endpoints of $b$: the
endpoint of polarity $r$ with the recurring capability $\kappa = (7,R)$ and the opposite endpoint
with its dual $\bar\kappa = (7,\overline{R})$.
