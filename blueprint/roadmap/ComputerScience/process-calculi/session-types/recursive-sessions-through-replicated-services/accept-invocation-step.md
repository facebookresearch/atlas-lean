# Unguarded shared input communicates with a matching output

Let $s$ be a natural number, $p$ a process with an unguarded input on $\mathrm{c}_s$ (an input
$\mathrm{c}_s(\cdot).q$ occurring in $p$ under parallel compositions, restrictions and replications
only), $b$ a name and $c$ a process. Then $\overline{\mathrm{c}_s}\langle b\rangle.c \mid p$ reduces
in one π-calculus step to some process.
