# Characterization of tree equivalence by matching heads

For all protocols $S$, $T$: $S \simeq T$ if and only if $\mathrm{unf}(S)$ and $\mathrm{unf}(T)$ are
related by $\mathcal{H}(\simeq)$, i.e. they are both $\mathrm{end}$, or the same kind of action with
the same polarity and rank metadata and tree-equivalent payloads and continuations.
