# Root unrolling preserves protocol-tree edges

For all protocols $S$, $T$ and every label $\ell$, $\mathrm{unf}(S) \xrightarrow{\ell} T$ if and
only if $S \xrightarrow{\ell} T$, where $\mathrm{unf}(S)$ is the head of $S$ (a graph cursor
unrolled once) and the edges of a protocol are determined by its head.
