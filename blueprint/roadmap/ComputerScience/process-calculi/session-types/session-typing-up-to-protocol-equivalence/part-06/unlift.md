# Conversion ranked typing descends from a lifted process

Let $n$ be a natural number, $\Gamma$ an ownership context none of whose endpoints has the name
$\mathrm{v}_0$, and $q$ a process. If $\Gamma \vdash^{\mathrm{rk}\simeq}_{n+1} \uparrow_0 q$, then
$\downarrow\Gamma \vdash^{\mathrm{rk}\simeq}_n q$, where $\downarrow\Gamma$ lowers the index of
every variable name of an endpoint of $\Gamma$ by one.
