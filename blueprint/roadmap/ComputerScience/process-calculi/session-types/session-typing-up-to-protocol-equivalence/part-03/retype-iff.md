# Ownership-map equivalence preserves typing in both directions

Let $n$ be a natural number, $\Delta \approx \Xi$ equivalent ownership contexts (equal domains, and
at each endpoint capabilities with equal ranks and tree-equivalent protocols) and $p$ a process.
Then $\Delta \vdash^{\simeq}_n p$ if and only if $\Xi \vdash^{\simeq}_n p$.
