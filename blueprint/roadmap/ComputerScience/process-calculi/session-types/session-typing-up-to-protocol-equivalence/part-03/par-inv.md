# Parallel inversion for conversion typing

Let $n$ be a natural number, $\Delta$ an ownership context and $p$, $q$ processes. If $\Delta
\vdash^{\simeq}_n p \mid q$, then there are ownership contexts $\Gamma$, $\Theta$ with disjoint
domains such that $\Delta = \Gamma \cup \Theta$, $\Gamma \vdash^{\simeq}_n p$ and $\Theta
\vdash^{\simeq}_n q$.
