# Ranked typing embeds into conversion ranked typing

Let $n$ be a natural number, $\Delta$ an ownership context and $p$ a process. If $\Delta
\vdash^{\mathrm{rk}}_n p$ (ranked typing, where a delegated payload carries exactly the announced
capability), then $\Delta \vdash^{\mathrm{rk}\simeq}_n p$ (conversion ranked typing, where it need
only carry an equivalent capability).
