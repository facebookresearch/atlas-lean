# Parallel inversion for conversion ranked typing

Let $n$ be a natural number, $\Delta$ an ownership context and $p$, $q$ processes. If $\Delta
\vdash^{\mathrm{rk}\simeq}_n p \mid q$, then there are ownership contexts $\Gamma$, $\Theta$ with
disjoint domains such that $\Delta = \Gamma \cup \Theta$, $\Gamma \vdash^{\mathrm{rk}\simeq}_n p$
and $\Theta \vdash^{\mathrm{rk}\simeq}_n q$.
