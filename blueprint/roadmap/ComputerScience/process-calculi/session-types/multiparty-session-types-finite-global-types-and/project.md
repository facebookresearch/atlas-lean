# Projection of a global type onto a participant

Let participants, payload sorts and labels have decidable equality. The projection of a finite global type onto a participant (Def. 4.1, finite fragment) is a partial map to local types. The sender and receiver of a message or choice project it to a send, receive, select or branch; a third party skips the interaction, and on a choice it requires every branch to project to brace-equal local types and takes that common projection (plain merging). An interaction whose sender equals its receiver has no projection onto that participant (the principal); a third party still projects it as above, following the continuation of a message and applying plain merging to a choice. For example, a message from $p$ to itself followed by $\mathsf{end}$ has no projection onto $p$, but projects to $\mathsf{end}$ onto every $q \ne p$.
