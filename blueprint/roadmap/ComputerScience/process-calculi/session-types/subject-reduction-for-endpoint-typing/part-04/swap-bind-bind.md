# Swapping nested restrictions exchanges their bound pairs

For every ownership context $\Delta$ and capabilities $c$, $d$, $(\nu_d\nu_c\Delta)[0
\leftrightarrow 1] = \nu_c\nu_d\Delta$, where $\nu_c\Theta$ is $\uparrow_0\Theta$ (every variable
name index raised by one) extended by $\mathrm{v}_0^{+} \mapsto c$ and $\mathrm{v}_0^{-} \mapsto
\bar c$.
