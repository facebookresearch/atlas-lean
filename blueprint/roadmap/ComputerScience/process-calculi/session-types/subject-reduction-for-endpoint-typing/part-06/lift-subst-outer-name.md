# Lowering then lifting an outer key returns it

Let $x^{r}$ be an endpoint whose name $x$ is not $\mathrm{v}_0$. Then
$(\uparrow_0(x\{\mathrm{c}_0/0\}))^{r} = x^{r}$, where $x\{\mathrm{c}_0/0\}$ lowers a variable index
by one (and would send $\mathrm{v}_0$ to $\mathrm{c}_0$) and $\uparrow_0$ raises a variable index by
one.
