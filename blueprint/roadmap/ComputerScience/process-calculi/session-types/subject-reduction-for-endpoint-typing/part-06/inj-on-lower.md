# Lowering is injective on contexts without fresh-name keys

Let $\Gamma$ be an ownership context none of whose endpoints has the name $\mathrm{v}_0$. Then the
map $x^{r} \mapsto (x\{\mathrm{c}_0/0\})^{r}$, which lowers every variable index $\ge 1$ by one and
fixes constants, is injective on the domain of $\Gamma$.
