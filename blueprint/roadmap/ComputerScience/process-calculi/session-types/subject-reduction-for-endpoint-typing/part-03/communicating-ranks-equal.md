# Communicating subjects in a compatible split have equal ranks

Let $\Delta$, $\Theta$ be ownership contexts with disjoint domains such that $\Delta \cup \Theta$ is
compatible, $e$, $d$ endpoints with the same name and $c$, $t$ capabilities with $\Delta(e) = c$ and
$\Theta(d) = t$. Then $t$ and $c$ have the same rank.
