# Unguarded shared input on a given name

Let $s$ be a natural number. A process has an unguarded input on $\mathrm{c}_s$ if it is an input
$x(\cdot).q$ with $x = \mathrm{c}_s$, or a parallel composition one of whose components has one, or
a restriction $\nu\,p$ or a replication $!p$ such that $p$ has one. $\mathbf{0}$, outputs and
choices have none, and the search does not enter prefixes.
