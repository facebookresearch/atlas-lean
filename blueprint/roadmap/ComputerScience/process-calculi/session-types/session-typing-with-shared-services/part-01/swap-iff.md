# Service templates are invariant under binder swapping

For every service environment $\Gamma$, natural number $k$ and process $p$, $p[k \leftrightarrow
k+1]$ is a service template for $\Gamma$ if and only if $p$ is, where $[k \leftrightarrow k+1]$
exchanges the variable indices $k$ and $k+1$ (raised by one under each binder).
