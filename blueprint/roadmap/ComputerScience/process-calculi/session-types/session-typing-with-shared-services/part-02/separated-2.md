# Rekeying along a nonaliasing name map yields separation

Let $\Gamma$ be a service environment, $\Delta$ an ownership context and $f$ a map from names to
names such that $f$ applied to the name of an endpoint of $\Delta$ is never a declared trigger
$\mathrm{c}_s$, and $x^{r} \mapsto f(x)^{r}$ is injective on the domain of $\Delta$. Then $\Gamma$
and $f_*\Delta$ are separated, where $f_*\Delta$ maps $f(x)^{r}$ to $\Delta(x^{r})$.
