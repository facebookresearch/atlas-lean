# Passive substitution creates no owned shared-name alias

Let $\Gamma$ be a service environment, $\Delta$ an ownership context such that $\uparrow_0\Delta$ is
separated from $\Gamma$, and $b$ a name. Then the name substitution $x \mapsto x\{b/0\}$ (sending
$\mathrm{v}_0$ to $b$, $\mathrm{v}_{i+1}$ to $\mathrm{v}_i$ and fixing constants) sends no endpoint
name of $\uparrow_0\Delta$ to a declared trigger.
