# Output subjects are owned endpoints or declared shared names

Let $n$ be a natural number, $\Gamma$ a service environment, $\Delta$ an ownership context, $a$, $b$
names and $p$ a process with $\Gamma; \Delta \vdash_n \overline{a}\langle b\rangle.p$. Then either
$\Delta$ owns some endpoint with name $a$, or $a = \mathrm{c}_s$ for some $s$ declared in $\Gamma$.
