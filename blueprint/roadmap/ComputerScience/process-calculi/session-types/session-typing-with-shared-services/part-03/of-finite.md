# Finite ranked typing embeds into runtime typing under separation

Let $n$ be a natural number, $\Gamma$ a service environment, $\Delta$ an ownership context separated
from $\Gamma$ and $p$ a process. If $\Delta \vdash^{\mathrm{rk}\simeq}_n p$ (conversion ranked
typing), then $\Gamma; \Delta \vdash_n p$ in runtime typing with shared services.
