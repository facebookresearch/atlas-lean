# Non-request-free frontier exposes a shared output up to congruence

Let $\Gamma$ be a service environment and $p$ a guarded frontier for $\Gamma$ that is not
request-free. Then there are a declared service $s$ (with signature $\sigma = \Gamma(s)$), a name
$b$ and processes $c$, $r$ with $p \equiv \overline{\mathrm{c}_s}\langle b\rangle.c \mid r$.
