# Global types and projection in multiparty session types

Global types are generated by $G ::= p \to q : \{\ell_i\langle U_i\rangle . G_i\}_{i \in I} \mid \mu t.G \mid t \mid \mathbf{end}$, with $p \ne q$ and $I$ nonempty, describing an interaction in which role $p$ sends role $q$ one of the labelled messages. The projection $G \upharpoonright r$ of a global type onto a role $r$ is a partial function to local types: an interaction is projected to a send for $p$, a receive for $q$, and, for every other role $r$, to the common value of the projections $G_i \upharpoonright r$, which must all be defined and equal for $G \upharpoonright r$ to be defined (plain merge). A global type is well formed if it is closed, contractive and projectable onto every role; well-formedness is decidable, since projection is computed by structural recursion on the global type.
