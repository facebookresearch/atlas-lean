# Erasing the bound pair leaves the lifted context

For every capability $c$ and ownership context $\Delta$, $(\nu_c\Delta \setminus \mathrm{v}_0^{-})
\setminus \mathrm{v}_0^{+} = \uparrow_0\Delta$, where $\uparrow_0\Delta$ raises every variable name
index of an endpoint of $\Delta$ by one and $\nu_c\Delta$ is $\uparrow_0\Delta$ extended by
$\mathrm{v}_0^{+} \mapsto c$ and $\mathrm{v}_0^{-} \mapsto \bar c$.
