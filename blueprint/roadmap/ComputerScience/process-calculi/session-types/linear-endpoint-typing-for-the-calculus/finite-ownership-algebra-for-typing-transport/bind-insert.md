# Restriction binding commutes with inserting an outer key

For all capabilities $c$, $u$, every ownership context $\Delta$ and every endpoint $x^{r}$,

$$
\nu_c(\Delta[x^{r} \mapsto u]) = (\nu_c\Delta)[(\uparrow_0 x)^{r} \mapsto u],
$$

where $\uparrow_0$ adds one to every variable index and $\nu_c\Theta$ is $\uparrow_0\Theta$ extended
by $\mathrm{v}_0^{+} \mapsto c$ and $\mathrm{v}_0^{-} \mapsto \bar c$.
