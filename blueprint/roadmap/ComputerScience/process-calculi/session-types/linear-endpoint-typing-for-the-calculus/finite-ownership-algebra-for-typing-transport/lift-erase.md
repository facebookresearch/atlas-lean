# Context lifting commutes with erasing an owned key

Let $\Delta$ be an ownership context, $x^{r}$ an endpoint in the domain of $\Delta$ and $k$ a
natural number. Then $\uparrow_k(\Delta \setminus x^{r}) = (\uparrow_k\Delta) \setminus (\uparrow_k
x)^{r}$, where $\uparrow_k$ adds one to every variable index $\ge k$ (applied to the names of all
endpoints of a context).
