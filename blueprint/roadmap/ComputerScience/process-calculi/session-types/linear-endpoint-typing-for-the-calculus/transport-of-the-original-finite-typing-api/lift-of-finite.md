# Binder lift fixes the finite ownership map

Let $\Gamma$ be a finite binary session context, $N$, $k$ natural numbers, $r$ a polarity and $\rho$
a rank assignment. Then $\uparrow_k\Gamma^{r}_{N,\rho} = \Gamma^{r}_{N,\rho}$, where
$\Gamma^{r}_{N,\rho}$ maps $\mathrm{c}_i^{r}$ to $(\rho(i), \iota(\Gamma(i)))$ for $i < N$ and
$\uparrow_k$ adds one to every variable index $\ge k$ (all keys of $\Gamma^{r}_{N,\rho}$ are
constants, which are fixed).
