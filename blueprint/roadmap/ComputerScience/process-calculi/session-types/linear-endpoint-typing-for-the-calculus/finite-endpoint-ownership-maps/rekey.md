# Collision-free rekeying of an ownership map

Let $\Delta$ be an ownership context and $f$ a map from endpoints to endpoints that is injective on
the domain of $\Delta$ (not necessarily injective elsewhere). The rekeyed context $f_*\Delta$ has
the entries $(f(e), c)$ for the entries $(e,c)$ of $\Delta$; injectivity on the domain ensures that
no two entries receive the same key.
