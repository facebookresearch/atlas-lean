# Lookups in a lifted ownership map

Let $k$ be a natural number, $\Delta$ an ownership context, $e = x^{r}$ an endpoint and $c$ a
capability. Then $\uparrow_k\Delta$ maps $(\uparrow_k x)^{r}$ to $c$ if and only if $\Delta$ maps
$e$ to $c$; here $\uparrow_k$ adds one to every variable index $\ge k$, applied to names and to the
names of all endpoints of $\Delta$.
