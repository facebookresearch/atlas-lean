# Substitution preserves and reflects the finite linear fragment

For every name $b$, natural number $k$ and process $p$, $p\{b/k\}$ is finite linear (contains no
replication and no choice) if and only if $p$ is, where $p\{b/k\}$ replaces the variable with index
$k$ by $b$ and lowers larger indices by one (raising the cutoff and lifting $b$ under binders).
