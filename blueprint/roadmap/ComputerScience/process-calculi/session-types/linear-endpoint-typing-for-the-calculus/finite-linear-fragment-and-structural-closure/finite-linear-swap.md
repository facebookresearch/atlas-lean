# Restriction swap preserves and reflects the finite linear fragment

For every natural number $k$ and process $p$, $p[k \leftrightarrow k+1]$ is finite linear (contains
no replication and no choice) if and only if $p$ is, where $p[k \leftrightarrow k+1]$ exchanges the
variable indices $k$ and $k+1$ (both raised by one under each binder).
