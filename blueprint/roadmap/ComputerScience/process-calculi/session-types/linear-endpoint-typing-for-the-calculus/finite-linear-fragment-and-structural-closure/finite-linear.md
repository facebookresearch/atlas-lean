# Finite linear π fragment without choice or replication

A π-calculus process is finite linear when it contains no replication and no choice anywhere.
Recursively: $\mathbf{0}$ is finite linear; $\overline{a}\langle b\rangle.p$, $a(\cdot).p$ and
$\nu\,p$ are finite linear if $p$ is; $p \mid q$ is finite linear if $p$ and $q$ are; $!p$ and $p +
q$ are never finite linear.
