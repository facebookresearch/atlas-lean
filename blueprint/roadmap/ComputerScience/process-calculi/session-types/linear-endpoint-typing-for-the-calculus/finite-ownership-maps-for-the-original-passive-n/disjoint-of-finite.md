# Ownership maps for opposite roles are disjoint

Let $\Gamma$, $\Theta$ be finite binary session contexts, $b$, $c$ natural numbers, $r \ne s$
polarities and $\rho$, $\rho'$ rank assignments. Then $\Gamma^{r}_{b,\rho}$ and
$\Theta^{s}_{c,\rho'}$ have disjoint domains (the first contains only endpoints of polarity $r$, the
second only of polarity $s$).
