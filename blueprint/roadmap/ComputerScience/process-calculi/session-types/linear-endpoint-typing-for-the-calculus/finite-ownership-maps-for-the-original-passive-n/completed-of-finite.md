# Completed finite contexts give completed ownership maps

Let $\Gamma$ be a finite binary session context with $\Gamma(i) = \mathrm{end}$ for every $i$, $N$ a
natural number, $r$ a polarity and $\rho$ a rank assignment. Then $\Gamma^{r}_{N,\rho}$ is
completed: every capability in it has a protocol with head $\mathrm{end}$.
