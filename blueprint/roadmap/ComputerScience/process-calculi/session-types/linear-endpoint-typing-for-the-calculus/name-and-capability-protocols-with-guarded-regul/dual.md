# Dual of an endpoint protocol

The dual $\overline{S}$ of a protocol $S$ is defined by $\overline{\mathrm{end}} = \mathrm{end}$,
$\overline{{!\mathrm{N}}.S} = {?\mathrm{N}}.\overline{S}$, $\overline{{?\mathrm{N}}.S} =
{!\mathrm{N}}.\overline{S}$, $\overline{{!(r,k,T)}.S} = {?(r,k,T)}.\overline{S}$,
$\overline{{?(r,k,T)}.S} = {!(r,k,T)}.\overline{S}$ and $\overline{\langle G,i,b\rangle} = \langle
G,i,\neg b\rangle$. The payload description $(r,k,T)$ of an endpoint exchange is not dualized.
