# Endpoint protocol with guarded regular recursion

Protocols are generated by the grammar

$$
S ::= \mathrm{end} \mid {!\mathrm{N}}.S \mid {?\mathrm{N}}.S \mid {!(r,k,T)}.S \mid {?(r,k,T)}.S \mid
\langle G, i, b\rangle,
$$

where ${!\mathrm{N}}.S$ and ${?\mathrm{N}}.S$ send and receive a passive name, ${!(r,k,T)}.S$ and
${?(r,k,T)}.S$ send and receive an endpoint of polarity $r$ carrying a capability of rank $k \in
\mathbb{N}$ and protocol $T$, and $\langle G,i,b\rangle$ is a cursor at node $i$ of a finite
protocol graph $G$ with an orientation flag $b$ (reversed when $b$ is true).
