# Ownership-map equivalence preserves semantic compatibility

Let $\Delta \approx \Xi$ be equivalent ownership contexts. If $\Delta$ is semantically compatible,
then so is $\Xi$; a context $\Theta$ is semantically compatible when $\Theta(e) = c$ and
$\Theta(\bar e) = d$ imply $d \approx \bar c$ (equal ranks, and the protocol of $d$ tree-equivalent
to the dual of the protocol of $c$), $\bar e$ being the opposite endpoint of $e$.
