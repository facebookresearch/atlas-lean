# Finite protocol embedding commutes with duality

For every finite binary session type $S$, $\iota(\overline{S}) = \overline{\iota(S)}$, where $\iota$
sends $\mathrm{end}$, ${!S}$, ${?S}$ to $\mathrm{end}$, ${!\mathrm{N}}.\iota(S)$,
${?\mathrm{N}}.\iota(S)$ and the duals exchange sends and receives.
