# Linear input installs the received role on the bound name

For every ownership context $\Delta$, polarity $r$ and capability $c$, the context
$(\uparrow_0\Delta)[\mathrm{v}_0^{r} \mapsto c]$ maps $\mathrm{v}_0^{r}$ to $c$, where
$\uparrow_0\Delta$ raises every variable name index of an endpoint of $\Delta$ by one.
