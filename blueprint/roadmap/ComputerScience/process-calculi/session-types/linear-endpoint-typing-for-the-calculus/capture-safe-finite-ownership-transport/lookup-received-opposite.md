# Received role's opposite is absent at the bound name

For every ownership context $\Delta$, polarity $r$ and capability $c$, the context
$(\uparrow_0\Delta)[\mathrm{v}_0^{r} \mapsto c]$ has no entry at $\mathrm{v}_0^{\bar r}$, the
endpoint on $\mathrm{v}_0$ with the opposite polarity; here $\uparrow_0\Delta$ raises every variable
name index of an endpoint of $\Delta$ by one.
