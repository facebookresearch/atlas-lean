# Binder extension commutes with lifting on endpoint keys

Let $f$ be a map from names to names and $f^{\uparrow}$ its extension under one binder:
$f^{\uparrow}(\mathrm{v}_0) = \mathrm{v}_0$, $f^{\uparrow}(\mathrm{v}_{i+1}) = \uparrow_0
f(\mathrm{v}_i)$ and $f^{\uparrow}(\mathrm{c}_a) = \uparrow_0 f(\mathrm{c}_a)$, where $\uparrow_0$
adds one to every variable index. Then for every endpoint $x^{r}$, $f^{\uparrow}(\uparrow_0 x)^{r} =
(\uparrow_0 f(x))^{r}$.
