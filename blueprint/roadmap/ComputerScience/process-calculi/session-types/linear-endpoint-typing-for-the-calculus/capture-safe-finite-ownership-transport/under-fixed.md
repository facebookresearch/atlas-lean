# Binder extension fixes the fresh binder's endpoint keys

Let $f$ be a map from names to names and $e$ an endpoint whose name is $\mathrm{v}_0$. Then the
extension $f^{\uparrow}$ of $f$ under one binder (which fixes $\mathrm{v}_0$ and sends
$\mathrm{v}_{i+1}$, $\mathrm{c}_a$ to $\uparrow_0 f(\mathrm{v}_i)$, $\uparrow_0 f(\mathrm{c}_a)$)
fixes $e$: $f^{\uparrow}(\mathrm{v}_0)^{r} = \mathrm{v}_0^{r}$.
