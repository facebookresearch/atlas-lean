# Injectivity of rekeying survives updating an owned key

Let $f$ be a map from endpoints to endpoints, $\Delta$ an ownership context, $e$ an endpoint in the
domain of $\Delta$ and $c$ a capability. If $f$ is injective on the domain of $\Delta$, then $f$ is
injective on the domain of $\Delta[e \mapsto c]$ (which is the same set).
