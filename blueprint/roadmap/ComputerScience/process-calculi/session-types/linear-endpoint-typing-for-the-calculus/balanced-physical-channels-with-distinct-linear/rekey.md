# Rekeying preserves balance

Let $\Delta$ be a balanced ownership context and $f$ a map from names to names such that the induced
map $x^{r} \mapsto f(x)^{r}$ on endpoints is injective on the domain of $\Delta$. Then the ownership
context $f_*\Delta$, which maps $f(x)^{r}$ to $\Delta(x^{r})$ for every endpoint $x^{r}$ in the
domain of $\Delta$, is balanced.
