# A fresh restriction pair is balanced

For every capability $c$, the ownership context $\{\mathrm{v}_0^{+} \mapsto c,\ \mathrm{v}_0^{-}
\mapsto \bar c\}$ installed by a restriction over the empty context is balanced (every endpoint
mapped to a capability has its opposite endpoint mapped to the dual capability); here $\mathrm{v}_0$
is the name bound by the restriction and $\bar c$ has the same rank as $c$ and the dual protocol.
