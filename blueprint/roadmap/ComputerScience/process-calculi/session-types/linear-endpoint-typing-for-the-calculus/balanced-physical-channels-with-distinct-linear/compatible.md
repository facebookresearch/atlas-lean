# Compatibility of a partial endpoint interface

An ownership context $\Delta$ is compatible when for every endpoint $e$ and capabilities $c$, $d$
with $\Delta(e) = c$ and $\Delta(\bar e) = d$, we have $d = \bar c$; here $\bar e$ is the opposite
endpoint (same name, other polarity) and $\bar c$ has the rank of $c$ and the dual protocol. An
endpoint whose opposite is absent imposes no condition.
