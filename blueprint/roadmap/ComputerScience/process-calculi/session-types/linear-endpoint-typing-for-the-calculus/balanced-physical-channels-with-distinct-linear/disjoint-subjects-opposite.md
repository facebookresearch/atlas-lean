# Disjoint owned keys on one name have opposite roles

Let $\Delta$, $\Theta$ be ownership contexts with disjoint domains, $e$, $d$ endpoints with the same
name and $c$, $t$ capabilities with $\Delta(e) = c$ and $\Theta(d) = t$. Then $d = \bar e$, the
endpoint with the name of $e$ and the opposite polarity.
