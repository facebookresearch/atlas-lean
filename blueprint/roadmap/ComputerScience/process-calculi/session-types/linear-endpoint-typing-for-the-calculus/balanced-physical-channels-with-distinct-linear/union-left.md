# Compatibility passes to the left part of a union

Let $\Delta$, $\Theta$ be ownership contexts. If the union $\Delta \cup \Theta$ (in which entries of
$\Delta$ take precedence) is compatible, then $\Delta$ is compatible; compatibility means that
whenever an endpoint $e$ is mapped to $c$ and its opposite $\bar e$ to $d$, then $d = \bar c$.
