# Labelled infinite executions give state runs

Let $s_0, s_1, s_2, \dots$ be states and $\mu_0, \mu_1, \mu_2, \dots$ labels of a labelled transition system with $s_i \xrightarrow{\mu_i} s_{i+1}$ for every $i$. Then $s_0, s_1, s_2, \dots$ is an [infinite run](omega-run.md): forgetting the labels of an infinite execution leaves a run.
