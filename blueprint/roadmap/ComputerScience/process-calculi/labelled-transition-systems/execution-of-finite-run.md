# A finite run of states gives a labelled execution through the same states

Let $L$ be a labelled transition system with states $S$ and labels $\Lambda$, given by its transition relation $s \xrightarrow{\mu} t$. A sequence of states $(s_i)_{i \in \mathbb{N}}$ is a finite run of length $k$ when for every $i < k$ there is a label $\mu$ with $s_i \xrightarrow{\mu} s_{i+1}$; the states after index $k$ are unconstrained. An execution from $s$ to $t$ with label list $\mu_0, \dots, \mu_{n-1}$ through the state list $s'_0, \dots, s'_m$ means that $m = n$, $s'_0 = s$, $s'_n = t$ and $s'_j \xrightarrow{\mu_j} s'_{j+1}$ for every $j < n$. If $(s_i)$ is a finite run of length $k$, then there are a list of labels $\mu_0, \dots, \mu_{k-1}$ of length exactly $k$ and a list of states $s'$ such that there is an execution from $s_0$ to $s_k$ with labels $\mu_0, \dots, \mu_{k-1}$ through $s'$, and $s'_i = s_i$ for every index $i$ of $s'$. So $s' = (s_0, \dots, s_k)$; each label $\mu_i$ is chosen (by the axiom of choice) among the labels witnessing the step $s_i \to s_{i+1}$.
