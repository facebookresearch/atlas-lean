# A labelled execution gives a finite run of states through the same states

Let $L$ be a labelled transition system with states $S$ and labels $\Lambda$, given by its transition relation $s \xrightarrow{\mu} t$. A sequence of states $(s_i)_{i \in \mathbb{N}}$ is a finite run of length $k$ when for every $i < k$ there is a label $\mu$ with $s_i \xrightarrow{\mu} s_{i+1}$; the states after index $k$ are unconstrained. An execution from $s$ to $t$ with label list $\mu_0, \dots, \mu_{n-1}$ through the state list $s'_0, \dots, s'_m$ means that $m = n$, $s'_0 = s$, $s'_n = t$ and $s'_j \xrightarrow{\mu_j} s'_{j+1}$ for every $j < n$. If there is an execution from $s$ to $t$ with label list $\mu_0, \dots, \mu_{n-1}$ through the state list $s'_0, \dots, s'_n$, then there is a sequence $(s_i)_{i \in \mathbb{N}}$ with $s_0 = s$, $s_n = t$, $(s_i)$ a finite run of length $n$, and $s_i = s'_i$ for every $i \le n$. (The sequence can be taken to equal $t$ after index $n$.)
