# The critical instant theorem

In the Liu–Layland periodic task model (over intervals in which no non-periodic routine runs) under a preemptive fixed-priority scheduling algorithm, a critical instant for any task occurs whenever the task is requested simultaneously with requests for all higher-priority tasks. Consequently, if for every task the request made at such an instant is fulfilled before its deadline, the priority assignment is feasible.
