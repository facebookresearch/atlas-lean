# Reachability for transfer and copy integer VASS is undecidable with three counters

Integer vector addition systems whose transitions may apply transfer matrices and copy matrices to counters over $\mathbb{Z}$ have an undecidable reachability problem already with three counters, although each kind of matrix alone gives a PSPACE-complete problem.

**Setting (Blondin, Haase, Mazowiecki and Raskin).** An *affine $\mathbb{Z}$-VASS* of dimension $d$ is $\mathcal{V} = (d, Q, T)$ with a finite set of control states $Q$ and a finite set of transitions $T \subseteq Q \times \mathbb{Z}^{d \times d} \times \mathbb{Z}^d \times Q$; a transition $(p, A, \vec{b}, q)$ leads from $p(\vec{u})$ to $q(A\vec{u} + \vec{b})$, and counters range over $\mathbb{Z}$. *Reachability* asks, given $\mathcal{V}$ and configurations $p(\vec{u})$ and $q(\vec{v})$, whether $q(\vec{v})$ is reachable from $p(\vec{u})$. A matrix $A \in \{0, 1\}^{d \times d}$ is a *transfer matrix* if it has exactly one $1$ in each column, and a *copy matrix* if it has exactly one $1$ in each row. Following the source (Section 2), a *transfer + copy $\mathbb{Z}$-VASS* is an affine $\mathbb{Z}$-VASS whose matrix monoid (generated by the matrices on its transitions) lies in the monoid generated by all transfer and all copy matrices of its dimension; this holds in particular when each matrix on a transition is a transfer matrix or a copy matrix, which is the form the proof of Proposition 6.3 builds (Figure 5), so the undecidability holds for that narrower form too.

**Theorem (Blondin, Haase, Mazowiecki and Raskin).** The reachability problem for transfer + copy $\mathbb{Z}$-VASS is undecidable, even when restricted to three counters.

The same paper proves reachability PSPACE-complete for transfer $\mathbb{Z}$-VASS and for copy $\mathbb{Z}$-VASS. It also notes that coverability, which is inter-reducible with reachability for affine $\mathbb{Z}$-VASS, is decidable for nonnegative affine VASS whose counters range over $\mathbb{N}$.

## Expansion

Reichert's reduction from the Post correspondence problem over $\{0, 1\}$, which represents the two words with an artificial leading $1$ so that their binary values determine them, shows that reachability is undecidable for two-counter affine $\mathbb{Z}$-VASS whose only matrices are the identity, $\mathrm{diag}(2, 1)$ and $\mathrm{diag}(1, 2)$. Each doubling transition is replaced by a gadget with a third counter that is $0$ outside the gadget: a copy matrix maps $(x, y, 0)$ to $(x, y, x)$, and then a transfer matrix, together with the transition's vector $(b_1, b_2, 0)$, maps it to $(2x + b_1, y + b_2, 0)$. So the three-counter transfer + copy system reaches the target exactly when Reichert's two-counter system does.
