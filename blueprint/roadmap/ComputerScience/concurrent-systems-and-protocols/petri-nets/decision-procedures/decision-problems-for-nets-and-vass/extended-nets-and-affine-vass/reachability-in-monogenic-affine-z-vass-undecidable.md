# Reachability for affine Z-VASS with a monogenic matrix monoid is undecidable

Affine integer VASS update integer counters by affine maps along the transitions of a finite control. Reachability is decidable when the matrices generate a finite monoid, and also for some infinite monoids generated by a single matrix. For monogenic monoids in general it is undecidable, and already for one fixed system.

**Setting (Blondin, Haase, Mazowiecki and Raskin).** An *affine integer vector addition system with states* (affine $\mathbb{Z}$-VASS) is $\mathcal{V} = (d, Q, T)$ with a dimension $d$, a finite set of control-states $Q$ and a finite set of transitions $T \subseteq Q \times \mathbb{Z}^{d \times d} \times \mathbb{Z}^d \times Q$. A transition $t = (p, A, \vec{b}, q)$ moves from configuration $p(\vec{u})$ to $q(\vec{v})$ with $\vec{v} = A \vec{u} + \vec{b}$; counters range over all of $\mathbb{Z}$. The *reachability relation* $\to^\ast$ is the reflexive-transitive closure of these steps, and the reachability problem asks, given $\mathcal{V}$ and configurations $p(\vec{u}), q(\vec{v})$, whether $p(\vec{u}) \to^\ast q(\vec{v})$. The *monoid* of $\mathcal{V}$ is the monoid of $d \times d$ matrices generated by the matrices of its transitions. A class of matrix monoids $\mathcal{C} = \bigcup_{d \ge 1} \mathcal{C}_d$ is *monogenic* if each $\mathcal{C}_d$ is generated by a single matrix, and an affine $\mathbb{Z}$-VASS is monogenic if its monoid is contained in such a monoid.

**Theorem (Blondin, Haase, Mazowiecki and Raskin).** Reachability for monogenic affine $\mathbb{Z}$-VASS is undecidable. Moreover, there exists a fixed monogenic affine $\mathbb{Z}$-VASS whose reachability relation is undecidable.

The same paper shows that affine $\mathbb{Z}$-VASS with a finite monoid have semilinear, decidable reachability relations (PSPACE-complete for $\mathbb{Z}$-VASS with transfers or with copies), and that reachability is decidable for a non-trivial class of infinite monogenic monoids.

## Expansion

The first part reduces from solvability of Diophantine equations over $\mathbb{N}$. Using counter programs with loops and zero tests (a zero test on a counter is expressed by requiring a final configuration where it is $0$), the system guesses values for the variables and evaluates a polynomial $P(x_1, \dots, x_k)$ monomial by monomial; a squaring loop based on $(n + 1)^2 = n^2 + (2n + 1)$, which adds a multiple of one counter to another through an affine update, and the identity $2mn = (m + n)^2 - m^2 - n^2$ implement multiplication; the whole program uses only the identity matrix and one further matrix, so the system is monogenic. A target configuration with the result counter equal to $0$ is reachable exactly when $P$ has a root in $\mathbb{N}^k$. For the second part, by Matiyasevich's theorem there is a polynomial $P$ with $x$ the code of a halting Turing machine iff $\exists \vec{y}\, P(x, \vec{y}) = 0$; the system built from this fixed $P$, with $x$ supplied in the initial configuration, has an undecidable reachability relation.
