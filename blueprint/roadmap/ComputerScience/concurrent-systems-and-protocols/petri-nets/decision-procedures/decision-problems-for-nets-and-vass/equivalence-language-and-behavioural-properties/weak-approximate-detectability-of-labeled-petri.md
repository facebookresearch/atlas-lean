# Weak approximate detectability of labeled Petri nets is undecidable

A labeled Petri net is weakly approximately detectable with respect to a finite partition of its reachable markings if, along some infinite observation, an observer eventually always knows which class the current marking lies in. For every fixed number of classes greater than one, this property is undecidable.

**Setting (Zhang and Giua).** A *labeled P/T net* $G = (N, M_0, \Sigma, \ell)$ is a [Petri net](../../../place-transition-petri-nets.md) $(N, M_0)$ with a labeling $\ell : T \to \Sigma \cup \{\varepsilon\}$ of its transitions by letters of a finite alphabet $\Sigma$; it is *$\varepsilon$-free* when no transition is labeled $\varepsilon$. For a finite label sequence $\sigma$, let $\mathcal{M}(G, \sigma)$ be the set of markings $M$ with $M_0 [s\rangle M$ for some firing sequence $s$ with $\ell(s) = \sigma$, and let $L^\omega(G)$ be the set of infinite label sequences generated by $G$. Given an integer $n > 1$ and a partition $\{R_1, \dots, R_n\}$ of the set of reachable markings, $G$ is *weakly approximately detectable* with respect to the partition if there are $\sigma \in L^\omega(G)$ and a positive integer $k$ such that for every prefix $\sigma'$ of $\sigma$ with $|\sigma'| \ge k$,

$$
\emptyset \ne \mathcal{M}(G, \sigma') \subseteq R_i \quad \text{for some } i \in \{1, \dots, n\}.
$$

**Theorem (Zhang and Giua).** Let $n > 1$ be an integer. It is undecidable whether an $\varepsilon$-free labeled P/T net is weakly approximately detectable with respect to a partition $\{R_1, \dots, R_n\}$ of its reachable markings (Theorem 1 of the source).

The partition is part of the input, so it must be given finitely. In the reduction of the source each class is the set of reachable markings in which the token of a designated control path lies in a given set of places (for example $R_1 = \{M : M(p_0) = 1 \text{ or } M(p_{11}) = 1 \text{ or } M(p_2) = 1,\ M(p_{21}) = M(p_3) = 0\}$ for $n = 2$), so the undecidability holds for partitions given by such Boolean conditions on finitely many places.

For finite automata the same property is PSPACE-complete, by the same paper.

## Expansion

The proof reduces the language equivalence problem for $\varepsilon$-free labeled P/T nets with the same alphabet (Hack) to the negation of weak approximate detectability, treating $n = 2$, $n = 3$ and $n > 3$ separately. From nets $G_1$ and $G_2$ it builds a net $G$ that starts with a token in a new place $p_0$ and, by a transition labeled with a fresh letter, chooses to run either $G_1$ or $G_2$, each gated by a new place; further transitions with the fresh label lead both branches into a common cycle of new places $p_2, \dots, p_l$ entered at different points. The partition separates markings by these control places. Equal languages make the two branches indistinguishable along every infinite observation, while a word generated by only one of the nets yields an observation along which the class of the current marking is eventually determined.
