# Backward reachability from an upward-closed set stabilizes

Let $\mathcal{M}$ be an [upward-closed set of markings](upward-closed-sets-of-markings.md) of an ordinary Petri net. There is $i \ge 0$ with $\mathrm{pre}^*(\mathcal{M}) = \bigcup_{j=0}^{i} \mathrm{pre}^j(\mathcal{M})$ (see [Predecessor sets of markings](predecessor-sets-of-markings.md)). Every upward-closed set of markings is generated by a finite set $B$ of markings, a *basis*: it consists of the markings that are $\ge$ some member of $B$; removing the members of $B$ that are not minimal in $B$ leaves exactly its set of minimal markings. If $\mathcal{M}$ is given by a finite basis $B$, the backward algorithm decides whether $M_0 \in \mathrm{pre}^*(\mathcal{M})$, that is, whether some marking of $\mathcal{M}$ is reachable from $M_0$: start from $B$; at each step add, for every transition $t$ with input vector $a$ and output vector $b$ and every current generator $v$, the generator $a + \max(v - b, 0)$ (componentwise), a basis of $\mathrm{pre}({\uparrow} v, t)$, and keep only the minimal generators; stop when the generated set no longer grows, and accept if $M_0 \ge$ some generator. Without an effective representation the decision claim fails: for a one-place net that can add one token, membership in the upward-closed set of $n$ such that a fixed machine halts within $n$ steps is decidable, but deciding whether that set is reachable from $0$ would decide halting.
