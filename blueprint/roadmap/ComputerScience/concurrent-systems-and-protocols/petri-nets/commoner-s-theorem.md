# Commoner's theorem for free-choice nets

A [free-choice net](subclasses-of-petri-nets.md) $(N, M_0)$ is [live](liveness-and-deadlock-freedom.md) if and only if every [siphon](siphons-and-traps.md) of $N$ contains a trap that is marked at $M_0$.
