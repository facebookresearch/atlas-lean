# S-invariants of connected state machines

Let $N$ be a connected [state machine](../subclasses-of-petri-nets.md). A vector $I : P \to \mathbb{Q}$ is an S-invariant of $N$ (see [A positive S-invariant implies boundedness](../invariants-siphons-and-traps/positive-s-invariant-implies-boundedness.md)) if and only if $I$ is constant: $I(s) = x$ for every place $s$, for some $x \in \mathbb{Q}$.
