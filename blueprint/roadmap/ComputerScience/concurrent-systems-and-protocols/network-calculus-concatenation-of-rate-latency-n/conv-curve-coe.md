# The concatenated curve equals the min-plus convolution

For curves $\beta_1, \beta_2 : [0, \infty) \to [0, \infty)$ and $t \ge 0$, the concatenated curve
at $t$ equals the min-plus convolution $(\beta_1 \otimes \beta_2)(t)$ computed in $[0, \infty]$.
The convolution is finite because the term $s = 0$ is finite.
