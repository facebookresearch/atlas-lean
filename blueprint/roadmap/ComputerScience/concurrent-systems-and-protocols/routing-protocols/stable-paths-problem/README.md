# Stable paths problem

A combinatorial model of policy-based interdomain routing such as BGP: each node ranks its permitted paths to an origin, and a solution is a path assignment in which every node uses its best path consistent with its neighbours'. Solvability is NP-complete in general, and the absence of a dispute wheel guarantees a unique solution.
