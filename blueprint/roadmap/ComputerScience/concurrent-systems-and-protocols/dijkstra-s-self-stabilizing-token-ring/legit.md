# Legitimate configurations of the token ring

In Dijkstra's self-stabilizing token ring with $n + 1$ machines indexed by $\mathbb{Z}/(n+1)$, each holding a value in $\mathbb{Z}/K$, a configuration $x$ is legitimate when exactly one machine is privileged in $x$. For $K \ne 0$ the values are Dijkstra's states $0, \dots, K - 1$; for $K = 0$ there are still $n + 1$ machines, but their values are integers, since $\mathbb{Z}/0 = \mathbb{Z}$, and machine $0$ increments an unbounded integer rather than wrapping.
