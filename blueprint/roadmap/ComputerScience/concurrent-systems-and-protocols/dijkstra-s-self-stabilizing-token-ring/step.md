# One step of the token ring

In Dijkstra's token ring, a configuration $x$ steps to $y$ under a central daemon when some machine $i$ is privileged in $x$ and $y$ is obtained from $x$ by replacing the value of machine $i$ with the value machine $i$ moves to, all other machines keeping their values. There are $n + 1$ machines with values in $\mathbb{Z}/K$; for $K = 0$ the values are integers, since $\mathbb{Z}/0 = \mathbb{Z}$, and machine $0$ increments an unbounded integer rather than wrapping.
