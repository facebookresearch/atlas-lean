# Automatic speedup theorem for round elimination

Let $\Pi$ be a node-edge-checkable problem, whose node constraint consists of multisets of at most $\Delta$ labels so that a vertex of degree $d \le \Delta$ is checked on its $d$ half-edge labels (Brandt, Section 3; a path endpoint has a single port), and let $\mathcal{G}_{n,\Delta}$ be a class of input-labelled $n$-vertex graphs of maximum degree $\Delta$ and girth at least $2t + 2$ that is $t$-independent: when a vertex that knows its radius-$(t-1)$ view extends it by one hop along one incident edge, what it sees there constrains nothing about what it may see along its other incident edges (and likewise for edges). Inputs such as vertex colourings, edge colourings and edge orientations, known at both endpoints, preserve $t$-independence, but globally unique identifiers violate it: an identifier seen along one edge cannot reappear along another. In this anonymous setting, assume moreover that the inputs contain an orientation of every edge, known to both endpoints. Then $\Pi$ can be solved in $t \ge 1$ rounds on $\mathcal{G}_{n,\Delta}$ if and only if $\overline{\mathrm{R}}(\mathrm{R}(\Pi))$ can be solved in $t - 1$ rounds (Brandt, Theorem 2). The orientation is what lets both endpoints of an edge agree on the same maximal label set, the pruning built into $\mathrm{R}$ and $\overline{\mathrm{R}}$; without input orientations the equivalence holds for Brandt's unpruned derived problem, whose constraints keep every label set satisfying the universal condition, not only the maximal ones (Theorem 1). Consequently, under the same assumptions, if $\Pi_0 = \Pi$ and $\Pi_{i+1} = \overline{\mathrm{R}}(\mathrm{R}(\Pi_i))$, the class is $t'$-independent of girth at least $2t'+2$ for all $t' \le T$, and no $\Pi_i$ with $i < T$ is $0$-round solvable, then $\Pi$ requires at least $T$ rounds. For identifiers there is a separate transfer, restricted to order-invariant algorithms: if unique identifiers are drawn from a set of at least $4\Delta^{2t}$ values, $\Pi$ has an order-invariant $t$-round algorithm exactly when $\overline{\mathrm{R}}(\mathrm{R}(\Pi))$ has an order-invariant $(t-1)$-round algorithm. Randomized versions with explicit error bounds are not part of this theorem; they are derived separately for specific problem families.

## Proof sketch

In a tree-like neighbourhood of radius $t$, the output of a node depends on its view; let each edge output the set of labels that its endpoint could output given the part of the view shared by both endpoints. High girth and $t$-independence make the possible extensions of the views of the two endpoints independent beyond the shared part, which shows the edge constraint of $\mathrm{R}(\Pi)$ is satisfied after $t - 1/2$ rounds; repeating the argument with nodes gives the derived problem in $t - 1$ rounds. Restricting to maximal label sets uses the input orientation: from it both endpoints of an edge infer the same order on themselves and deterministically pick the same maximal superset of the computed set, so the pruned problem $\overline{\mathrm{R}}(\mathrm{R}(\Pi))$ is solved in the same time. The converse simulates one additional round to reconstruct concrete labels. For order-invariant algorithms only the relative order of identifiers matters, and with at least $4\Delta^{2t}$ identifiers available the same argument goes through.
