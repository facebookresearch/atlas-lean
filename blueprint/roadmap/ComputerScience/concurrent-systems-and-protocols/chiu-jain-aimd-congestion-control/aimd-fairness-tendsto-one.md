# Aimd fairness tendsto one

For `n ≥ 1` users, additive increase `a > 0`, multiplicative decrease factor `0 < b < 1`, a nonnegative initial load vector with positive total, and a goal `> 0`, the fairness index of the AIMD loads tends to `1` (Chiu–Jain, abstract: convergence to an efficient and fair state; Section 2.3 defines convergence to fairness as `F(x(t)) → 1`).
