# Aimd eventual confined

For `n ≥ 1` users, additive increase `a > 0`, multiplicative decrease factor `0 < b < 1`, a nonnegative initial load vector with positive total, and a goal `> 0`, the total AIMD load eventually stays in `[b * goal, goal + n * a]`. This is a precise form of the claim that AIMD oscillates around the goal (Chiu–Jain, abstract and Section 2).
