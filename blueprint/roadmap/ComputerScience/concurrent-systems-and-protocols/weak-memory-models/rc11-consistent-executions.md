# RC11-consistent executions

In the RC11 repair of the C/C++11 memory model, an *execution* $G$ consists of a finite set $E$ of events containing an initialization write $\mathtt{W}^{na}(x, 0)$ for each location $x$; a labelling of each event as a read $\mathtt{R}^o(x, v)$ with mode $o \in \{na, rlx, acq, sc\}$, a write $\mathtt{W}^o(x, v)$ with $o \in \{na, rlx, rel, sc\}$ or a fence $\mathtt{F}^o$ with $o \in \{acq, rel, acqrel, sc\}$, modes being ordered $na \sqsubset rlx \sqsubset rel, acq \sqsubset acqrel \sqsubset sc$; a strict partial order $\mathtt{sb}$ (sequenced-before) that puts the initialization events before all others; a relation $\mathtt{rmw}$ pairing the read and the write of each read-modify-write, an immediate $\mathtt{sb}$-edge between accesses to one location whose pair of modes is $(rlx, rlx)$, $(acq, rlx)$, $(rlx, rel)$, $(acq, rel)$ or $(sc, sc)$; a reads-from relation $\mathtt{rf}$ from writes to reads of the same location and value, with at most one write per read; and a modification order $\mathtt{mo}$, a strict total order on the writes to each location. It is *complete* if every read reads from some write. A program $P$ of finitely many sequential threads determines a set of executions, those representing prefixes of the traces of memory accesses and fences that its threads generate, with read values, $\mathtt{rf}$ and $\mathtt{mo}$ unconstrained; the set is closed under $\mathtt{sb}$-prefixes that contain the initialization events, and the *full* executions of $P$ are those representing traces generated by the whole program. Completeness is a separate condition: a full execution need not be complete. With $[S]$ the identity on a set $S$, $;$ composition, $^?$ reflexive and $^+$ transitive closure, and superscripts selecting events by mode, define

- $\mathtt{rb} = \mathtt{rf}^{-1} ; \mathtt{mo}$ and $\mathtt{eco} = (\mathtt{rf} \cup \mathtt{mo} \cup \mathtt{rb})^+$;
- the release sequence $\mathtt{rs} = [\mathtt{W}] ; \mathtt{sb}|_{loc}^? ; [\mathtt{W}^{\sqsupseteq rlx}] ; (\mathtt{rf} ; \mathtt{rmw})^*$;
- synchronizes-with $\mathtt{sw} = [\mathtt{E}^{\sqsupseteq rel}] ; ([\mathtt{F}] ; \mathtt{sb})^? ; \mathtt{rs} ; \mathtt{rf} ; [\mathtt{R}^{\sqsupseteq rlx}] ; (\mathtt{sb} ; [\mathtt{F}])^? ; [\mathtt{E}^{\sqsupseteq acq}]$ and happens-before $\mathtt{hb} = (\mathtt{sb} \cup \mathtt{sw})^+$;
- $\mathtt{scb} = \mathtt{sb} \cup \mathtt{sb}|_{\ne loc} ; \mathtt{hb} ; \mathtt{sb}|_{\ne loc} \cup \mathtt{hb}|_{loc} \cup \mathtt{mo} \cup \mathtt{rb}$, where $\mathtt{sb}|_{\ne loc} = \mathtt{sb} \setminus \mathtt{sb}|_{loc}$ consists of the $\mathtt{sb}$-edges that are not between two accesses to the same location;
- $\mathtt{psc}_{base} = ([\mathtt{E}^{sc}] \cup [\mathtt{F}^{sc}] ; \mathtt{hb}^?) ; \mathtt{scb} ; ([\mathtt{E}^{sc}] \cup \mathtt{hb}^? ; [\mathtt{F}^{sc}])$, $\mathtt{psc}_F = [\mathtt{F}^{sc}] ; (\mathtt{hb} \cup \mathtt{hb} ; \mathtt{eco} ; \mathtt{hb}) ; [\mathtt{F}^{sc}]$ and $\mathtt{psc} = \mathtt{psc}_{base} \cup \mathtt{psc}_F$.

$G$ is *RC11-consistent* if it is complete and

- (coherence) $\mathtt{hb} ; \mathtt{eco}^?$ is irreflexive;
- (atomicity) $\mathtt{rmw} \cap (\mathtt{rb} ; \mathtt{mo}) = \emptyset$;
- (SC) $\mathtt{psc}$ is acyclic;
- (no thin air) $\mathtt{sb} \cup \mathtt{rf}$ is acyclic.
