# In the doorway

A process $i$ of the bakery algorithm is in the doorway when its program counter is in the reading phase (any set of entries still to read, any running maximum), about to write its ticket, or about to reset $\mathrm{choosing}[i]$: it has set $\mathrm{choosing}[i]$ and not yet reset it (Lamport 1974, p. 454).

## Sources

- L. Lamport, *A New Solution of Dijkstra's Concurrent Programming Problem*, Communications of the ACM 17(8), August 1974, 453–455: p. 454.
