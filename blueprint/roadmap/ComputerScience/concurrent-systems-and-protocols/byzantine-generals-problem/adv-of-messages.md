# Traitor relays matching the protocol messages

The traitor strategy for $\mathrm{OM}(m)$ that matches the messages $a$ of the traitors in the
oral-message protocol: a traitor $q$ relaying along the path $\pi q$ sends to $p$ the entry, at the
reverse of $\pi$, of the table it sends to $p$ in round $|\pi|$. The empty path, which the algorithm
never uses, gets the default value.
