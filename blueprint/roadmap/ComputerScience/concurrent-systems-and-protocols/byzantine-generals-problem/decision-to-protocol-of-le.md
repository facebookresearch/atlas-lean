# The protocol runs the oral messages algorithm

With finitely many generals, after any number $r \ge m + 1$ of rounds of the protocol for
$\mathrm{OM}(m)$ with commander $c$, order $v$, a set of traitors and traitor messages $a$, every general
$p$ decides the value that $\mathrm{OM}(m)$, run by the commander $c$ holding $v$ with no superiors and
all the other generals as lieutenants, gives $p$ when the loyal generals are those outside the set of
traitors and the traitors relay by the strategy matching $a$. Rounds after the first $m + 1$ write only
the entries for paths longer than $m + 1$, which the decision does not read.
