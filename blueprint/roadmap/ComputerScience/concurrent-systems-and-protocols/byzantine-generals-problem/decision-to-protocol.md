# The protocol runs the oral messages algorithm in the expected number of rounds

With finitely many generals, after exactly $m + 1$ rounds of the protocol for $\mathrm{OM}(m)$ with
commander $c$, order $v$, a set of traitors and traitor messages $a$, every general $p$ decides the value
that $\mathrm{OM}(m)$, run by the commander $c$ holding $v$ with no superiors and all the other generals
as lieutenants, gives $p$ when the loyal generals are those outside the set of traitors and the traitors
relay by the strategy matching $a$. This is the case $r = m + 1$ of the statement for any $r \ge m + 1$
rounds.
