# Satisfiability of loop-connected high-level message sequence charts is undecidable

Whether a high-level message sequence chart over FIFO channels generates any complete message sequence chart is undecidable, already for loop-connected charts over two processes, for flat loop-connected charts over three processes, and for charts over a one-element message alphabet.

**Setting (Bollig, Fortin and Gastin).** Fix a finite set of processes $\mathcal P$ with peer-to-peer FIFO channels $(p, q)$ between distinct processes, and a finite set of messages $\mathrm{Msg}$. A *compositional message sequence chart* (cMSC) $M = (E, \le, \lhd, \lambda, \mu)$ has a nonempty, finite or countably infinite set $E$ of events, each labeled by $\lambda$ with a send $p!q$ or a receive $q?p$ of the process $p$, respectively $q$, executing it, and a partial order $\le$ (Definition 1). Its restriction to the events of each process is a total order that is finite or isomorphic to $(\mathbb N, \le)$; with $\to$ the union of the direct-successor relations of these orders, $\le$ is the reflexive transitive closure of $\to \cup \lhd$, so the order has no cycle. The matching $\lhd \subseteq {\le}$ pairs sends $p!q$ with receives $q?p$ in FIFO order: for matches $(e, f)$ and $(e', f')$ on the same channel, $e \le e'$ iff $f \le f'$. The *unmatched* events, those in no match, are exactly the domain of the partial map $\mu$, which gives each a message of $\mathrm{Msg}$. For every match $(e, f)$ and unmatched event $g$, if $g$ has the label of $e$ then $e < g$, and if $g$ has the label of $f$ then $g < f$: on each channel, unmatched sends come after the matched ones and unmatched receives before them. An *MSC* is a cMSC with no unmatched events.

For a finite cMSC $M_1$ and a cMSC $M_2$, the concatenation $M_1 \circ M_2$ is the *set* of cMSCs $M$ on the disjoint union of their events such that: on every process, the order of $M$ is the order of $M_1$ on that process followed by the order of $M_2$ on it, so the events of $M_1$ come first and the order within each factor is preserved; the matching of $M$ contains both matchings, and every further match goes from an unmatched send of $M_1$ to an unmatched receive of $M_2$ carrying the same message; and every event keeps its action label, and every event that stays unmatched keeps its message (the four clauses of the definition in Section 2.1). For example, an unmatched send followed by an unmatched receive with the same message yields both the chart with the new match and the chart without it (Example 2). A *high-level message sequence chart* (HMSC) $\mathcal H = (S, \iota, \mathrm{Msg}, R, F, F_\omega)$ has a finite set $S$ of states, an initial state $\iota$, a finite transition relation $R \subseteq S \times \mathrm{fcMSC} \times S$ labeled by finite cMSCs, and sets $F, F_\omega \subseteq S$ (Definition 2). A *finite path* $s_0 M_1 s_1 \cdots M_n s_n$ has $n \ge 1$ transitions, and $\mathrm{cmscs}(\rho)$ is the set of concatenations of its labels; infinite paths and their infinite products are defined similarly, with the same preservation of each factor's order, labels and unmatched messages. A path is accepting if it starts in $\iota$ and either is finite and ends in $F$, or is infinite and visits $F_\omega$ infinitely often; $L(\mathcal H)$ is the set of MSCs in $\mathrm{cmscs}(\rho)$ for accepting paths $\rho$. A cMSC is *connected* if the undirected graph $(E, {\le} \cup {\le^{-1}})$ is connected, and $\mathcal H$ is *loop-connected* if, for every state $s$ and every finite path $\rho$ from $s$ to $s$, every cMSC in $\mathrm{cmscs}(\rho)$ is connected (Definition 3). $\mathcal H$ is *flat* if a path from $s$ to $s'$ and a path from $s'$ to $s$ imply $s = s'$ (Section 6). *Satisfiability* asks whether $L(\mathcal H) \ne \emptyset$.

**Theorem (Bollig, Fortin and Gastin).**
1. Satisfiability of loop-connected HMSCs with at least two processes is undecidable; it remains undecidable for flat loop-connected HMSCs with three processes.
2. Satisfiability of HMSCs whose message set $\mathrm{Msg}$ is a singleton is undecidable.

In contrast, the same paper shows that every loop-connected HMSC can be effectively translated into an equivalent communicating finite-state machine, which complements the realizability of globally cooperative HMSCs by Genest, Kuske and Muscholl, whose MSC languages are channel-bounded; the authors call the two results orthogonal and leave open whether every globally cooperative HMSC has an equivalent loop-connected one (Section 7, Problem 1). HMSCs with $F_\omega = \emptyset$ whose labels are MSCs correspond to the [MSC graphs](msc-graphs.md) of earlier work, which accept finite walks only.

## Expansion

For flat charts with processes $p, q, r$ and a Post correspondence instance given by morphisms $f, g : A^\ast \to B^\ast$, the HMSC lets $p$ send each chosen letter $a \in A$ to both $q$ and $r$; $q$ answers with the letters of $f(a)$ and $r$ with those of $g(a)$, and $p$ finally receives the letters of $B$ one at a time from both channels in the same order. Each label has events on a single process and is therefore connected, and the HMSC is flat with only self-loops, so every loop at a given state repeats labels on a single process and all its products are connected, which makes the HMSC loop-connected (Section 6.1, Figure 4); a complete MSC exists exactly when some nonempty word $u$ has $f(u) = g(u)$. The two-process case reduces from the halting problem of a Turing machine on the empty word, with a non-flat HMSC, and the singleton-message case reduces from the halting problem of two-counter machines and uses four processes.
