# Whether a population protocol over ordered agents is a decider is undecidable

For population protocols whose finite-state agents are totally ordered and whose transitions may test the agents' relative positions, it is undecidable whether the protocol always stabilizes to a consensus, already when the only test is the order $<$, or immediate-observation protocols use the successor relation; for classical unordered protocols the question is decidable.

**Setting (Blondin, Cadilhac, Courchesne, Guillou, Mascle and Vialard).** For a set $\mathcal N \subseteq 2^{\mathbb N \times \mathbb N}$ of *numerical predicates*, a population protocol in $\mathrm{PP}[\mathcal N]$ is $(Q, \Sigma, O, \Delta)$ with finitely many states $Q$, initial states $\Sigma \subseteq Q$, an opinion map $O : Q \to \{\top, \bot\}$, and transitions $q_1, q_2 \xrightarrow{P} q_3, q_4$ with $P \in \mathcal N$ or $P$ always true. A configuration is a word in $Q^+$, one state per agent in the order of the agents; a transition lets two distinct agents at positions $i$ and $j$ with $(i, j) \in P$, in states $q_1$ and $q_2$, move to $q_3$ and $q_4$. Initial configurations are words in $\Sigma^+$. A configuration is a *$b$-consensus* if all its states have opinion $b$, and *$b$-stable* if every configuration reachable from it is a $b$-consensus. A run is an infinite sequence of configurations in which each one follows from the previous one by a transition or, as in the source, by an implicit "no operation" step, so that every configuration can be extended into a run. A run is *fair* if every configuration reachable from a configuration that occurs infinitely often also occurs infinitely often. The protocol is a *decider* (also called well specified) if for every initial configuration $w$ there is $b \in \{\top, \bot\}$ such that every fair run from $w$ visits a $b$-stable configuration; equivalently, for every configuration $u$ reachable from $w$ there is a path from $u$ to a $b$-stable configuration. A protocol is *immediate-observation* if each transition changes the state of at most one agent; these form $\mathrm{IOPP}[\mathcal N]$. The predicate $<$ is $\{(i, j) : i < j\}$ and $+1$ is $\{(i, i + 1)\}$.

**Theorem (Blondin, Cadilhac, Courchesne, Guillou, Mascle and Vialard).** It is undecidable whether a given protocol of $\mathrm{PP}[<]$ is a decider, and likewise for $\mathrm{IOPP}[+1]$ and $\mathrm{PP}[+1]$.

For classical population protocols $\mathrm{PP}[\emptyset]$, being a decider is decidable (Esparza, Ganty, Leroux and Majumdar). For $\mathrm{IOPP}[<]$ the same paper shows the question decidable assuming a natural conjecture.

## Expansion

The *emptiness problem* asks whether some initial configuration of a protocol can reach a $\top$-stable configuration. It reduces to the complement of the decider property (Lemma 35, proved in Appendix A.9). If some initial state has opinion $\top$, the one-agent configuration of that state is $\top$-stable, and the reduction outputs a fixed protocol that is not a decider. Otherwise the new protocol has, for each initial state $a$, a fresh initial copy $\bar a$ with opinion $\bot$ and a transition $(\bar a, q) \to (a, q)$ for every state $q$, and a fresh sink $q_\bot$ with opinion $\bot$ and a transition $(q_1, q_2) \to (q_1, q_\bot)$ for every pair of states at least one of which has opinion $\bot$, all with the always-true predicate. Then from every configuration with at least two agents that is not a $\top$-consensus the sink consensus $q_\bot^\ast$ is reachable, so the new protocol is a decider exactly when the old one has empty language; each new transition changes one agent, so immediate observation is preserved. Emptiness is undecidable for $\mathrm{IOPP}[+1]$, and hence for $\mathrm{PP}[+1]$, because such protocols simulate linear bounded automata with the same language (Section 6, Corollary 36), and it is undecidable for $\mathrm{PP}[<]$ by a reduction from Post's correspondence problem (Theorem 37).
