# State reached along a schedule in test-and-set consensus

For fixed inputs of the two processes and a schedule $\sigma = (i_1, \dots, i_k)$, a finite list of processes, the state reached along $\sigma$ is the result of starting from the initial state of the two-process test-and-set consensus protocol and letting processes $i_1, \dots, i_k$ take one atomic step each, in this order.
