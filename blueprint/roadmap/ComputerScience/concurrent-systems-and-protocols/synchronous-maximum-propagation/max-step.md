# Synchronous maximum propagation

On nodes $\{0, \dots, n-1\}$ holding natural numbers, where each node $i$ hears from one node $\rho(i)$, one synchronous round replaces the value at each node $i$ by the maximum of its own value and the value at $\rho(i)$.

## Sources

- N. Lynch, *Distributed Algorithms*, Morgan Kaufmann, 1996, Chapter 4.
