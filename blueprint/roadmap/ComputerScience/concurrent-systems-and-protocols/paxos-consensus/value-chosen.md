# Chosen value in a state

Let $Q$ be a quorum system and $s$ a state of single-decree Paxos. A value $v$ is chosen in $s$ when, for some number $b$ and some quorum $C$, every acceptor of $C$ has accepted the proposal $(b, v)$ in $s$ (Section 2.2).
