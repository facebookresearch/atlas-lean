# Chosen proposal

In a [Paxos voting history](voting.md) for a [quorum system](quorum-system.md), the proposal numbered $b$ with value $v$ is chosen when every acceptor of some quorum accepted it (Lamport, *Paxos Made Simple*, Section 2.2: "A value is chosen when a single proposal with that value has been accepted by a majority of the acceptors").

## Sources

- L. Lamport, *Paxos Made Simple*, ACM SIGACT News 32(4), December 2001, 51–58; author's version dated 01 Nov 2001: Section 2.2.
