# History variables preserve the externally visible property

If $S^h$ is obtained from the specification $S$ by [adding a history variable](adding-a-history-variable.md), then $S$ and $S^h$ define the same externally visible property.

## Depends on

- [Adding a history variable](adding-a-history-variable.md)

## Sources

- M. Abadi and L. Lamport, *The Existence of Refinement Mappings*, SRC Research Report 29, Digital Equipment Corporation, 1988, <https://lamport.azurewebsites.net/pubs/abadi-existence.pdf>; journal version in *Theoretical Computer Science* 82(2):253–284, 1991, Section 5.1, Proposition 4.
