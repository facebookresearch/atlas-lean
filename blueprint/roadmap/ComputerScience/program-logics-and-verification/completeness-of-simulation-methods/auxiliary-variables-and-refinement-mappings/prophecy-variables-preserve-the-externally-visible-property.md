# Prophecy variables preserve the externally visible property

If $S^p$ is obtained from the specification $S$ by [adding a prophecy variable](adding-a-prophecy-variable.md), then $S$ and $S^p$ define the same externally visible property. The proof uses König's lemma, which needs the finiteness condition on the prophecy values of each state.
