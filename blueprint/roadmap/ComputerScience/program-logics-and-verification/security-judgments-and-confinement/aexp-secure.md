# Security typing of arithmetic expressions

The judgment that an IMP arithmetic expression $e$ has level $l$ under policy $\Gamma$, meaning $e$ reads only variables at or below $l$ (with $\mathrm{false} \le \mathrm{true}$). It is generated by:

- a constant has every level $l$;
- a variable $x$ has level $l$ when $\Gamma(x) \le l$;
- $a + b$, $a - b$ and $a \cdot b$ have level $l$ when $a$ and $b$ both have level $l$.
