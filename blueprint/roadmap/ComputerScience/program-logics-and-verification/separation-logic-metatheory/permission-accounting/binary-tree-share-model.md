# Binary tree share model

Boolean-labelled binary trees, taken up to folding of uniform subtrees, form a Boolean algebra; the separation algebra in which disjoint trees join by pointwise disjunction is disjoint, has cross-splits, is infinitely splittable and embeds the finite and cofinite sets of naturals that model token counting.

1. *Lattice separation algebras.* Let $(A, \sqsubseteq, \sqcap, \sqcup, 0, 1)$ be a bounded distributive lattice and set $x \oplus y = z$ if and only if $x \sqcup y = z$ and $x \sqcap y = 0$. Then $(A, \oplus)$ is a separation algebra with unit $0$ satisfying disjointness and cross-split. If $A$ is a Boolean algebra, then $x \preceq y$ if and only if $x \sqsubseteq y$.
2. *Trees.* Trees are $\tau ::= \circ \mid \bullet \mid \langle \tau\ \tau \rangle$. *Unfolding* replaces a leaf $\circ$ by $\langle \circ\ \circ \rangle$ or a leaf $\bullet$ by $\langle \bullet\ \bullet \rangle$, and *folding* is the reverse; any two trees can be unfolded to a common shape. Set $x \sqsubseteq y$ if, after unfolding $x$ and $y$ to a common shape, every leaf labelled $\bullet$ in $x$ is labelled $\bullet$ in $y$ (equivalently, $x$ has a $\circ$ at least wherever $y$ does), and $x \cong y$ if $x \sqsubseteq y$ and $y \sqsubseteq x$, that is, if $x$ and $y$ unfold to the same tree. Each $\cong$-class contains a unique tree with fewest nodes, its canonical tree, obtained by folding as long as possible. On canonical trees $\sqsubseteq$ is a [partial order](../../../../Order/ordered-sets/partial-order.md) with least element $\circ$ and greatest element $\bullet$; joins, meets and complements are computed as pointwise disjunction, conjunction and negation of leaves after unfolding the arguments to a common shape, followed by folding the result to its canonical tree. Canonical trees with these operations form a [Boolean algebra](../../../../Order/lattices-boolean-algebras/boolean-algebra.md), so by part 1 they form a disjoint, cross-split separation algebra, and equality of canonical trees is decidable structurally.
3. *Splitting.* The relativization $x \bowtie y$ replaces every $\bullet$ leaf of $x$ by $y$. It satisfies $x \bowtie \bullet = x = \bullet \bowtie x$, $x \bowtie \circ = \circ = \circ \bowtie x$, $x \bowtie (y \bowtie z) = (x \bowtie y) \bowtie z$, $x \bowtie (y \sqcup z) = (x \bowtie y) \sqcup (x \bowtie z)$, $x \bowtie (y \sqcap z) = (x \bowtie y) \sqcap (x \bowtie z)$, and the injectivity laws $x \bowtie y_1 = x \bowtie y_2 \Rightarrow x = \circ \vee y_1 = y_2$ and $x_1 \bowtie y = x_2 \bowtie y \Rightarrow x_1 = x_2 \vee y = \circ$. The function $\mathrm{split}\,x = (x \bowtie \langle \bullet\ \circ \rangle,\ x \bowtie \langle \circ\ \bullet \rangle)$ makes the model infinitely splittable.
4. *Token counting.* The finite and cofinite subsets of $\mathbb{N}$ form a Boolean subalgebra of $\mathcal{P}(\mathbb{N})$. Encoding a set as the right-biased tree whose $i$-th left leaf records membership of $i$ and whose last right leaf records membership of all larger numbers is a Boolean-algebra homomorphism into trees. Set $[\![p]\!]_{\mathbb{Z}} = -|p|$ for finite nonempty $p$ and $|\mathbb{N} \setminus p|$ for cofinite $p$; the empty set receives no integer and corresponds to the unit share $\bot$, while the integer $0$ is the full factory $\mathbb{N}$. Then disjoint sets that are nonempty and finite or cofinite join exactly as the counting shares do, with the empty set acting as the unit.

## Expansion

Part 1: functionality and commutativity are clear; cancellativity holds because in a distributive lattice $x \sqcup y = x' \sqcup y$ and $x \sqcap y = x' \sqcap y$ imply $x = x'$; associativity uses distributivity to see that $y \sqcap z = 0$ and $x \sqcap (y \sqcup z) = 0$ whenever the left association is defined. Disjointness: $a \oplus a = b$ forces $a = a \sqcap a = 0$. Cross-split: take $ac = a \sqcap c$ and so on, since $a = a \sqcap (c \sqcup d) = (a \sqcap c) \sqcup (a \sqcap d)$ with $(a \sqcap c) \sqcap (a \sqcap d) \sqsubseteq c \sqcap d = 0$. In a Boolean algebra the witness for $x \sqsubseteq y \Rightarrow x \preceq y$ is $\neg x \sqcap y$. Parts 2–4 are inductions over trees, carried out in the source's Coq development; the source presents the order by generating rules together with the common-shape reading used here, and works with canonical trees by normalizing after every operation. Token counting combines with splitting through a points-to $\ell \mapsto^{s,n} v$ that owns $s \bowtie [\![p]\!]_\tau$ for a (co)finite $p$ with $[\![p]\!]_{\mathbb{Z}} = n$. Missing prerequisites: bounded distributive lattices and Boolean algebras, standard in Mathlib's order library.
