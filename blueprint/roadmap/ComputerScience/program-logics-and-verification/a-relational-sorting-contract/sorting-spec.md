# Relational sorting contract

For a type $\alpha$ with a relation $\le$ (no order laws assumed) and lists $xs$, $ys$, $ys$ satisfies the sorting contract for $xs$ when $ys$ is a permutation of $xs$, preserving duplicate occurrences, and $ys$ is pairwise nondecreasing ($y_i \le y_j$ for all $i < j$).
