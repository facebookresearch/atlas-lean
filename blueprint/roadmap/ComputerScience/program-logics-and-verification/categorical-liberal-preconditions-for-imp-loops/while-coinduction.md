# Coinduction for liberal while preconditions

For the guarded liberal transformer $F$ determined by an IMP guard $b$, body $c$ and postcondition $Q$, every set $I$ satisfying $I\subseteq F(I)$ is contained in $\{s:\operatorname{wlp}(\mathrm{while}\ b\ c,Q)(s)\}$. No termination assumption is made.
