# Commuting with a test and its complement

In any [Kleene algebra with tests](kleene-algebras-with-tests.md), for every element $p$ and test $b$ the following are equivalent:

1. $pb = bp$;
2. $p\bar b = \bar b p$;
3. $b p \bar b + \bar b p b = 0$.

Any two tests commute, $bc = cb$, by the Boolean algebra axioms.
