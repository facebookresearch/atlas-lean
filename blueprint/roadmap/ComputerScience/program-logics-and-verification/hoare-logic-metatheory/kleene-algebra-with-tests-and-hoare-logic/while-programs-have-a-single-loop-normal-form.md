# While programs have a single-loop normal form

Interpret a while program in a [Kleene algebra with tests](kleene-algebras-with-tests.md) by $p; q \mapsto pq$, $\mathbf{if}\ b\ \mathbf{then}\ p\ \mathbf{else}\ q \mapsto bp + \bar b q$ and $\mathbf{while}\ b\ \mathbf{do}\ p \mapsto (bp)^\ast \bar b$. A while program is in *normal form* if it has the shape $p;\ \mathbf{while}\ b\ \mathbf{do}\ q$ with $p$ and $q$ while-free. Every while program, augmented with finitely many new subprograms of the form $s;\ (bc + \bar b \bar c)$ that store the values of tests in fresh test variables $c$, is equivalent to a while program in normal form, by reasoning in Kleene algebra with tests from commutativity assumptions $cp = pc$ for subprograms $p$ that do not modify $c$. The transformation proceeds by induction on the program from the inside out, with one case for each programming construct.
