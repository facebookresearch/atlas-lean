# Relative completeness of partial-correctness Hoare logic

For all assertions $P$ and $Q$ and every command $c$, if the partial-correctness triple $\{P\}\,c\,\{Q\}$ is valid (every terminating big-step execution of $c$ from a state satisfying $P$ ends in a state satisfying $Q$), then it is derivable in partial-correctness Hoare logic, whose consequence rule takes semantic entailments between assertions as premises.
