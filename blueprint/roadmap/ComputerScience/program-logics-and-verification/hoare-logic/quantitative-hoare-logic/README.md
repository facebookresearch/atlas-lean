# Quantitative Hoare logic

Potential-valued assertions account for the time consumed by the deterministic while programs of the source, whose states map strings to integers. A finite prepotential guarantees termination, and the difference between the pre- and postpotential bounds the running time. The cost model charges one unit for skip, assignment and each guard evaluation.
