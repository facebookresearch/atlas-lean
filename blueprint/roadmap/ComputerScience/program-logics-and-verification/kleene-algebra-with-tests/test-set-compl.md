# Test of a negated assertion is the complement within identity

Let $W$ be a set of states and $P \subseteq W$. The [diagonal test relation](test-set.md) of the complement $W \setminus P$ is the complement of $[P]$ in $W \times W$ intersected with the identity relation: $[W \setminus P] = ((W \times W) \setminus [P]) \cap 1$. Negating a test is complementation relative to the identity, not the full complement of relations, which also contains the off-diagonal pairs.
