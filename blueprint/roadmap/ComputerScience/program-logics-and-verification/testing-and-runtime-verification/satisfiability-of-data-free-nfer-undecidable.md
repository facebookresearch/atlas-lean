# Satisfiability of data-free nfer specifications is undecidable

Nfer is a rule language for runtime verification that builds named intervals from timestamped events. Even without data, it is undecidable whether some event trace makes a specification produce an interval with a given name.

**Setting (Kauffman, Larsen and Zimmermann).** Each instance fixes finite alphabets $\Sigma \subseteq \mathcal{I}$ of event and interval identifiers. An *event* is a pair $(\eta, t)$ with $\eta \in \Sigma$ and $t \in \mathbb{N}$; a *trace* is a finite sequence of events with nondecreasing timestamps. An *interval* is a triple $(\eta, s, e)$ with $\eta \in \mathcal{I}$ and $s \le e$ in $\mathbb{N}$, and a *pool* is a set of intervals. A data-free nfer *specification* is a finite list of rules. An *inclusive rule* $\eta \leftarrow \eta_1 \oplus \eta_2$, with $\oplus$ one of the clock predicates $\mathsf{before}$, $\mathsf{meet}$, $\mathsf{during}$, $\mathsf{coincide}$, $\mathsf{start}$, $\mathsf{finish}$, $\mathsf{overlap}$, $\mathsf{slice}$, produces an $\eta$-labeled interval $i$ from an $\eta_1$-labeled interval $i_1$ and an $\eta_2$-labeled interval $i_2$ when the constraint of its clock predicate holds (Table 1 of the source): $\mathsf{before}$: $\mathrm{end}(i_1) < \mathrm{start}(i_2)$, $\mathrm{start}(i) = \mathrm{start}(i_1)$, $\mathrm{end}(i) = \mathrm{end}(i_2)$; $\mathsf{meet}$: $\mathrm{end}(i_1) = \mathrm{start}(i_2)$, $\mathrm{start}(i) = \mathrm{start}(i_1)$, $\mathrm{end}(i) = \mathrm{end}(i_2)$; $\mathsf{during}$: $\mathrm{start}(i_2) = \mathrm{start}(i) \le \mathrm{start}(i_1)$ and $\mathrm{end}(i_1) \le \mathrm{end}(i_2) = \mathrm{end}(i)$; $\mathsf{coincide}$: $\mathrm{start}(i_1) = \mathrm{start}(i_2) = \mathrm{start}(i)$ and $\mathrm{end}(i_1) = \mathrm{end}(i_2) = \mathrm{end}(i)$; $\mathsf{start}$: $\mathrm{start}(i_1) = \mathrm{start}(i_2) = \mathrm{start}(i)$ and $\mathrm{end}(i) = \max(\mathrm{end}(i_1), \mathrm{end}(i_2))$; $\mathsf{finish}$: $\mathrm{end}(i_1) = \mathrm{end}(i_2) = \mathrm{end}(i)$ and $\mathrm{start}(i) = \min(\mathrm{start}(i_1), \mathrm{start}(i_2))$; $\mathsf{overlap}$: $\mathrm{start}(i_1) < \mathrm{end}(i_2)$, $\mathrm{start}(i_2) < \mathrm{end}(i_1)$, and $i$ is the hull, from $\min(\mathrm{start}(i_1), \mathrm{start}(i_2))$ to $\max(\mathrm{end}(i_1), \mathrm{end}(i_2))$; $\mathsf{slice}$: the same test as $\mathsf{overlap}$, and $i$ is the intersection, from $\max(\mathrm{start}(i_1), \mathrm{start}(i_2))$ to $\min(\mathrm{end}(i_1), \mathrm{end}(i_2))$. These are not Allen's relations: $\mathsf{during}$, $\mathsf{start}$ and $\mathsf{finish}$ allow equal endpoints, and $\mathsf{slice}$ has no Allen counterpart. An *exclusive rule* $\eta \leftarrow \eta_1 \;\mathsf{unless}\; \ominus\; \eta_2$, with $\ominus \in \{\mathsf{after}, \mathsf{follow}, \mathsf{contain}\}$, copies an $\eta_1$-labeled interval $i_1$ as an $\eta$-labeled one exactly when there is no $\eta_2$-labeled interval $i_2 \ne i_1$ with $\ominus(i_1, i_2)$, where $\mathsf{after}(i_1, i_2)$ means $\mathrm{start}(i_1) > \mathrm{end}(i_2)$, $\mathsf{follow}(i_1, i_2)$ means $\mathrm{start}(i_1) = \mathrm{end}(i_2)$, and $\mathsf{contain}(i_1, i_2)$ means that $i_2$ lies within $i_1$ (Table 2 of the source). A trace is turned into the pool of zero-length intervals $(\eta, t, t)$; rules are evaluated in topological order of their strongly connected dependency components, iterating cycles to a fixed point, and exclusive rules may not occur in cycles. The *satisfiability problem* asks, given a specification, a set $\Sigma' \subseteq \Sigma$ of input identifiers and a target identifier $\eta_T$, whether some nonempty trace with identifiers in $\Sigma'$ makes the specification produce an $\eta_T$-labeled interval.

**Theorem (Kauffman, Larsen and Zimmermann).** The satisfiability problem for data-free nfer is undecidable.

The same work shows that satisfiability is decidable for cycle-free specifications (Theorem 3 of arXiv:2407.03155v4) and in polynomial time for specifications with inclusive rules only (Theorem 2); the extended journal version, accepted for the special issue of the International Journal on Software Tools for Technology Transfer dedicated to RV 2024, adds a NEXPTIME lower bound for the cycle-free case (Theorem 4 in Section 3.3 of arXiv:2407.03155v4).

## Proof sketch

The proof reduces nonemptiness of the intersection of two context-free languages. Exclusive rules first discard events whose timestamps are shared with differently named events and then cut the trace into minimal contiguous intervals labeled by their starting events, so that the remaining intervals spell a word in order. For grammars in Chomsky normal form, recursive inclusive rules then label an interval by each nonterminal that derives the corresponding factor of that word, and a final rule produces a target interval when the start symbols of two grammars $G_1$ and $G_2$ label the same interval. So the specification is satisfiable exactly when $L(G_1) \cap L(G_2)$ is nonempty.
