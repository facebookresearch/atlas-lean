# Symbolic store

A *symbolic store* maps each program variable of IMP, indexed by a natural number, to an [arithmetic expression](../../programming-language-semantics/operational-semantics-of-imp/aexp.md) whose variables are read as the values of the initial state.

## Sources

- J. C. King, "Symbolic execution and program testing", *Communications of the ACM* 19(7):385–394, 1976 (symbolic execution, symbolic values and path conditions).
