# Evaluation of a symbolic store

The evaluation of a [symbolic store](symbolic-store.md) $\sigma$ at an initial [state](../../programming-language-semantics/operational-semantics-of-imp/state.md) $s$ is the state $x \mapsto [\![\sigma(x)]\!]\,s$.
