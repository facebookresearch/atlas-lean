# Substitution lemma for Boolean expressions

For every symbolic store $\sigma$, a map from the variables of IMP to arithmetic expressions over the initial state, Boolean expression $b$ and state $s$, evaluating the substitution $\sigma(b)$, which replaces every variable $x$ of $b$ by $\sigma(x)$, in $s$ gives the value of $b$ in the state $x \mapsto [\![\sigma(x)]\!]\,s$.
