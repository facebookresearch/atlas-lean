# Substitution lemma for Boolean expressions

For every [symbolic store](symbolic-store.md) $\sigma$, Boolean expression $b$ and state $s$, evaluating the [substitution](substitution-into-boolean-expressions.md) $\sigma(b)$ in $s$ gives the value of $b$ in the state $x \mapsto [\![\sigma(x)]\!]\,s$.

## Sources

- J. C. King, "Symbolic execution and program testing", *Communications of the ACM* 19(7):385–394, 1976 (symbolic execution, symbolic values and path conditions).
