# Size-change graphs and size-change termination

Consider a first-order functional program, a list of definitions $f(f_1, \dots, f_n) = e_f$ whose first function $f_{\mathrm{init}}$ is the entry point, with expressions built from parameters, conditionals, primitive operations that always terminate, and labelled calls $c : g(e_1, \dots, e_m)$. Values carry a well-founded strict order $\prec$ (on natural numbers the usual order, on pairs and lists a decrease in size), and $\preceq$ is $\prec$ or equality. A call $c$ from the body of $f$ to $g$ is written $f \xrightarrow{c} g$; a *call sequence* is a finite or infinite word $c_1 c_2 \cdots$ of calls with $f_0 \xrightarrow{c_1} f_1 \xrightarrow{c_2} \cdots$, and $\mathrm{Flow}$ is the set of call sequences with $f_0 = f_{\mathrm{init}}$.

A *size-change graph* $G : f \to g$ is a bipartite graph from the parameters of $f$ to those of $g$, each edge labelled $\downarrow$ or $\overline{\downarrow}$. It is *safe* for the call $c : g(e_1, \dots, e_m)$ in $e_f$ if an edge $f_i \xrightarrow{\downarrow} g_j$ implies that the value of $e_j$ is $\prec v_i$, and an edge $f_i \xrightarrow{\overline{\downarrow}} g_j$ implies that it is $\preceq v_i$, for all argument values $\vec v$ of $f$. Given a safe graph $G_c$ for every call $c$, the *multipath* of a call sequence $c_1 c_2 \cdots$ is $G_{c_1} G_{c_2} \cdots$, and a *thread* is a path of edges through consecutive graphs of it. Let $\mathrm{Flow}^\omega$ be the set of infinite call sequences in $\mathrm{Flow}$ and $\mathrm{Desc}^\omega$ the set of those whose multipath has a thread with infinitely many $\downarrow$ edges. The program is *size-change terminating* for the chosen graphs if $\mathrm{Flow}^\omega = \mathrm{Desc}^\omega$.
