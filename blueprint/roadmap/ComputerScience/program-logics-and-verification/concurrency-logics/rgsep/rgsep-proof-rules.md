# RGSep proof rules

RGSep derives judgments $\vdash C\ \mathbf{sat}\ (p, \mathcal{R}, \mathcal{G}, q)$ for commands built from primitive commands by sequencing, choice, iteration, atomic blocks and parallel composition: started in a state satisfying $p$, under interference within $\mathcal{R}$, $C$ does not fault, changes shared state only within $\mathcal{G}$, and establishes $q$ if it terminates.

Fix the separation algebra $(M, \uplus, \emptyset)$ of [actions and interference in RGSep](rgsep-actions-and-interference.md). *Primitive commands* $c$ are relations $c \subseteq M \times M$; $c$ *faults* at $m$ if no $m'$ has $c(m, m')$. Each satisfies locality: if $c$ faults at $m_1 \uplus m$, it faults at $m_1$; and if $c(m_1 \uplus m, m_2)$, then either $c$ faults at $m_1$ or $m_2 = m_2' \uplus m$ for some $m_2'$ with $c(m_1, m_2')$. A separation-logic triple $\{P\}\, c\, \{Q\}$ is *valid* for $c$ if for every $m$ and interpretation $i$ with $m, i \models_{SL} P$, $c$ does not fault at $m$ and every $m'$ with $c(m, m')$ has $m', i \models_{SL} Q$. Commands are

$$C ::= \mathbf{skip} \mid c \mid C_1 ; C_2 \mid C_1 + C_2 \mid C^\ast \mid \langle C \rangle_{P \rightsquigarrow Q} \mid C_1 \parallel C_2,$$

where $+$ is nondeterministic choice, $^\ast$ iteration, and the atomic block $\langle C \rangle_{P \rightsquigarrow Q}$ is annotated with separation-logic assertions $P, Q$ that are *uniformly precise*: the set $\{h \mid \exists i.\ h, i \models_{SL} P\}$ is [precise](../../separation-logic-metatheory/abstract-separation-logic/precise-predicates.md), that is, every heap has at most one sub-heap satisfying $P$ under some interpretation, and likewise for $Q$. Assertions $p, q, r$ and their stability are those of [RGSep assertions over local and shared state](rgsep-assertions-over-local-and-shared-state.md); $\mathcal{R}, \mathcal{G}$ are sets of actions, and $(P \rightsquigarrow Q) \subseteq \mathcal{G}$ is as in [actions and interference in RGSep](rgsep-actions-and-interference.md). The rules are:

- *Prim.* If $\{P\}\, c\, \{Q\}$ is valid for $c$, then $\vdash c\ \mathbf{sat}\ (P, \mathcal{R}, \mathcal{G}, Q)$ for the local assertions $P, Q$.
- *Skip.* If $p$ is stable under $\mathcal{R}$, then $\vdash \mathbf{skip}\ \mathbf{sat}\ (p, \mathcal{R}, \mathcal{G}, p)$.
- *Seq.* From $\vdash C_1\ \mathbf{sat}\ (p, \mathcal{R}, \mathcal{G}, r)$ and $\vdash C_2\ \mathbf{sat}\ (r, \mathcal{R}, \mathcal{G}, q)$ infer $\vdash C_1 ; C_2\ \mathbf{sat}\ (p, \mathcal{R}, \mathcal{G}, q)$.
- *Choice.* From $\vdash C_1\ \mathbf{sat}\ (p, \mathcal{R}, \mathcal{G}, q)$ and $\vdash C_2\ \mathbf{sat}\ (p, \mathcal{R}, \mathcal{G}, q)$ infer $\vdash C_1 + C_2\ \mathbf{sat}\ (p, \mathcal{R}, \mathcal{G}, q)$.
- *Loop.* From $\vdash C\ \mathbf{sat}\ (p, \mathcal{R}, \mathcal{G}, p)$ infer $\vdash C^\ast\ \mathbf{sat}\ (p, \mathcal{R}, \mathcal{G}, p)$.
- *Par.* From $\vdash C_1\ \mathbf{sat}\ (p_1, \mathcal{R} \cup \mathcal{G}_2, \mathcal{G}_1, q_1)$ and $\vdash C_2\ \mathbf{sat}\ (p_2, \mathcal{R} \cup \mathcal{G}_1, \mathcal{G}_2, q_2)$ infer $\vdash C_1 \parallel C_2\ \mathbf{sat}\ (p_1 \ast p_2, \mathcal{R}, \mathcal{G}_1 \cup \mathcal{G}_2, q_1 \ast q_2)$.
- *Atom.* If $P$ and $Q$ are uniformly precise, $\vdash C\ \mathbf{sat}\ (P \ast P', \emptyset, \emptyset, Q \ast Q')$ and $(P \rightsquigarrow Q) \subseteq \mathcal{G}$, then $\vdash \langle C \rangle_{P \rightsquigarrow Q}\ \mathbf{sat}\ (\boxed{P \ast F} \ast P', \emptyset, \mathcal{G}, \boxed{Q \ast F} \ast Q')$, for every separation-logic assertion $F$.
- *AtomR.* If $\vdash \langle C \rangle_{P \rightsquigarrow Q}\ \mathbf{sat}\ (p, \emptyset, \mathcal{G}, q)$ and $p$ and $q$ are stable under $\mathcal{R}$, then $\vdash \langle C \rangle_{P \rightsquigarrow Q}\ \mathbf{sat}\ (p, \mathcal{R}, \mathcal{G}, q)$.
- *Frame.* If $\vdash C\ \mathbf{sat}\ (p, \mathcal{R}, \mathcal{G}, q)$ and $r$ is stable under $\mathcal{R} \cup \mathcal{G}$, then $\vdash C\ \mathbf{sat}\ (p \ast r, \mathcal{R}, \mathcal{G}, q \ast r)$.
- *Weaken.* From $\vdash C\ \mathbf{sat}\ (p', \mathcal{R}', \mathcal{G}', q')$ with $p \Rightarrow p'$, $[\![\mathcal{R}]\!] \subseteq [\![\mathcal{R}']\!]$, $[\![\mathcal{G}']\!] \subseteq [\![\mathcal{G}]\!]$ and $q' \Rightarrow q$, infer $\vdash C\ \mathbf{sat}\ (p, \mathcal{R}, \mathcal{G}, q)$.
- *Disj, Conj.* From judgments for $p_1$ and $p_2$ with a common postcondition infer the one for $p_1 \vee p_2$; from judgments with postconditions $q_1$ and $q_2$ and a common precondition infer the one for $q_1 \wedge q_2$.
- *Ex, All.* If the logical variable $x$ is not free in $q$, $C$, $\mathcal{R}$ or $\mathcal{G}$, from $\vdash C\ \mathbf{sat}\ (p, \mathcal{R}, \mathcal{G}, q)$ infer $\vdash C\ \mathbf{sat}\ (\exists x.\, p, \mathcal{R}, \mathcal{G}, q)$; if $x$ is not free in $p$, $C$, $\mathcal{R}$ or $\mathcal{G}$, infer $\vdash C\ \mathbf{sat}\ (p, \mathcal{R}, \mathcal{G}, \forall x.\, q)$.

Every application of Atom to an atomic block uses the block's annotation $P \rightsquigarrow Q$. The guarantee premise may be discharged by derived rules: $(P \rightsquigarrow P) \subseteq \mathcal{G}$ for exact $P$; $(P \rightsquigarrow Q) \subseteq \mathcal{G}$ for $(P \rightsquigarrow Q) \in \mathcal{G}$; substitution of an expression for a logical variable; and consequence, from $P' \Rightarrow P$, $(P \rightsquigarrow Q) \subseteq \mathcal{G}$ and $Q' \Rightarrow Q$ infer $(P' \rightsquigarrow Q') \subseteq \mathcal{G}$.

## Expansion

Uniform precision is this page's reading, stronger than the thesis's precision for each interpretation (its Definition 8): the thesis prints the oracle of atomic blocks with $s_1 \models_{SL} P$ and no interpretation, while its proof of soundness identifies the split under the judgment's interpretation. Under the existential reading, precision for each interpretation does not suffice. Take heaps over one location $y$ with the single value $0$, a logical variable $N$, $F = \mathrm{emp}$, $P = \mathrm{emp}$, $P' = y \mapsto 0$, $Q = (N = 0 \wedge \mathrm{emp}) \vee (N \ne 0 \wedge y \mapsto 0)$ and $Q' = (N = 0 \wedge y \mapsto 0) \vee (N \ne 0 \wedge \mathrm{emp})$. For each value of $N$, $P$ and $Q$ are precise and $P \ast P'$ implies $Q \ast Q'$, so Skip, Weaken and $(P \rightsquigarrow Q) \subseteq \mathcal{G}$ give the premises of Atom for $\langle \mathbf{skip} \rangle_{P \rightsquigarrow Q}$; but from local heap $y \mapsto 0$ and empty shared heap the oracle has the two splits $(y \mapsto 0, \mathrm{emp})$ and $(\mathrm{emp}, y \mapsto 0)$, and each violates the postcondition $\boxed{Q \ast F} \ast Q'$ for one value of $N$, however an ambiguous oracle is resolved; $Q$ is not uniformly precise. With uniform precision, the notion the conference paper defines (its footnote 7) applied to annotations read existentially in the interpretation, the split is unique and the thesis's argument applies unchanged. The premise of Prim is printed in the thesis as a derivable separation-logic triple $\vdash_{SL} \{P\}\, c\, \{Q\}$; the thesis's soundness proof, like the basic-action case of the 2007 report, uses only its validity, which is the reading taken here. The thesis states that the conference paper's single atomic rule, with precondition $\boxed{\exists \vec y.\, P} \ast P''$ and postcondition $\exists \vec y.\, (\boxed{Q} \ast Q'')$ and the updated parts $P' \rightsquigarrow Q'$ as annotation, is derivable by AtomR, consequence, Ex and Atom; read with the literal boxes of this system, the derivation needs Atom's premises for that annotation, so here $P'$ and $Q'$ must be uniformly precise. The thesis encodes conditionals, while loops and guarded atomic blocks with assume statements, as $(\mathrm{assume}(B) ; C_1) + (\mathrm{assume}(\neg B) ; C_2)$, $(\mathrm{assume}(B) ; C)^\ast ; \mathrm{assume}(\neg B)$ and $\langle \mathrm{assume}(B) ; C \rangle$; the system above contains no Boolean tests and only unguarded atomic blocks, so these encodings are outside it. They cannot be added as primitive commands: in the thesis's assume, a false test diverges, while a primitive command with no successor faults in the operational semantics used here. Program variables are not separated from $M$. For a concrete instance whose states pair a store with a heap and whose separation splits only the heap, primitive commands are not local, the frame rule needs the side condition that the frame mention no variable the command modifies, and the parallel rule needs stack variables local to threads. The conference paper also gives an axiom for a non-atomic read of shared state in the concrete heap model; its report derives it in that model by encoding the read as two atomic reads followed by a consistency check, and it is not a rule of the abstract system.
