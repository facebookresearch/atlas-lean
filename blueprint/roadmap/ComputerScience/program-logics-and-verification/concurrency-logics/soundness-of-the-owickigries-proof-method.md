# Soundness of the Owicki–Gries proof method

Consider a while language with basic atomic state transformations, sequential composition, conditionals, loops annotated with invariants, and $\mathbf{await}\ b\ \mathbf{then}\ c\ \mathbf{end}$, whose body $c$ is loop-free and is executed atomically once $b$ holds; programs run component programs $c_1, \dots, c_n$ of this language in parallel, without nested parallelism, by interleaving: each step executes one step of one unfinished component. A *proof outline* $\vdash c\ Q$ annotates every command of a component $c$ with a precondition (and every loop with an invariant) according to the Hoare-style formation rules, $Q$ being the postcondition. An assertion $P$ is *invariant* under an atomic command $r$ with precondition $\mathrm{pre}(r)$ if every execution of $r$ from a state in $P \cap \mathrm{pre}(r)$ ends in $P$. Proof outlines $\vdash c_1\ Q_1, \dots, \vdash c_n\ Q_n$ are *interference free* if, for all $i \ne j$, every assertion of the outline of $c_j$, including $Q_j$, is invariant under every basic command and every await body of $c_i$.

**Theorem (strong soundness for parallel composition).** If $\vdash c_i\ Q_i$ for each $i$ and the outlines are interference free, then for every computation of $c_1 \parallel \cdots \parallel c_n$ from a state in $\bigcap_i \mathrm{pre}(c_i)$, at every point each unfinished component's current command has its precondition true and each finished component $c_j$ has $Q_j$ true. In particular, a terminating computation ends in a state satisfying $\bigcap_i Q_i$, so $\{\bigcap_i \mathrm{pre}(c_i)\}\ c_1 \parallel \cdots \parallel c_n\ \{\bigcap_i Q_i\}$ holds in the sense of partial correctness.
