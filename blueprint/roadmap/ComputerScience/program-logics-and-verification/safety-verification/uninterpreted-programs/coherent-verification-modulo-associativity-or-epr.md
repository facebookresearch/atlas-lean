# Coherent verification modulo associativity or EPR axioms is undecidable

Verification of coherent uninterpreted programs is decidable without axioms, but becomes undecidable modulo a single associativity axiom for one function, and modulo axioms in the effectively propositional fragment, although single executions remain checkable under EPR axioms.

**Theorem (Mathur, Madhusudan and Viswanathan).**

1. Let $\mathcal{A} = \{\forall x, y, z.\ f(x, f(y, z)) = f(f(x, y), z)\}$ for a binary function symbol $f$. Given an execution that is coherent modulo $\mathcal{A}$, it is undecidable whether it is feasible modulo $\mathcal{A}$; consequently coherent verification modulo $\mathcal{A}$ is undecidable.
2. Coherent verification modulo EPR axioms is undecidable: no algorithm decides, given a finite set $\mathcal{A}$ of sentences $\exists \bar{x}\, \forall \bar{y}\, \varphi$ with $\varphi$ quantifier-free and purely relational, a program coherent modulo $\mathcal{A}$ and a postcondition, whether the program satisfies the postcondition modulo $\mathcal{A}$.

In part 1 the axiom set is fixed and even a single coherent execution cannot be checked. In part 2 the axioms are part of the input; feasibility of a single execution modulo EPR axioms is decidable, through decidability of EPR satisfiability.

## Expansion

Part 1 reduces from the word problem for finitely generated semigroups, undecidable by Post: from identities $u_1 = v_1, \dots, u_n = v_n$ and a query identity $u_0 = v_0$ over a finite alphabet, with words read as products under the associative function $f$, it builds a single execution, coherent modulo associativity, that is infeasible modulo associativity exactly when $u_0 = v_0$ holds in every semigroup generated by the alphabet that satisfies the given identities. Part 2 reduces from the Post correspondence problem by a separate encoding given in an appendix of the paper.
