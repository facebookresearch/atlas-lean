# Proposition 2 (Lecture 11, Section 3)

For a polytope $C$ given by $C = \{x \mid a_i \cdot x \leq b_i,\, i = 1, \ldots, k\}$, the sets $C_1 = C_2$ where $C_1 = \{x \in \mathbb{R}^n \mid x \cdot c \leq 1 \ \forall c \in C\}$ and $C_2 = \operatorname{conv}(a_1, \ldots, a_k)$.
