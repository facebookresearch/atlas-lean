# Theorem 5 (Lecture 3, Section 4.1)

For any $x \perp \mathbf{1}$, $x_1 \leq x_2 \leq \cdots \leq x_n$, there is some $i$ for which $\frac{x^\top L x}{x^\top x} \geq \frac{\varphi(\{1, \ldots, i\})^2}{2 d_{\max}}$.
