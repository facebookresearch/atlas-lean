# Theorem 2 (Chernoff Bound)

Let $X_1, \ldots, X_n$ be random variables so that $X_i \in [0, 1]$, and let $X = \sum X_i$. Then, $$\Pr[|X - \mathbf{E}[X]| \geq \epsilon X] \leq 2 e^{-\Theta(1) \epsilon^2 \mathbf{E}[X]}.$$
