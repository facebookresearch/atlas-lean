# Definition 2 (Lecture 10, Section 2)

We say a set $C \subseteq \mathbb{R}^n$ is convex when for all $x, y \in C$ and $t \in [0, 1]$, $tx + (1 - t)y \in C$. A function $f : \mathbb{R}^n \to \mathbb{R}$ is convex if and only if the region above its graph (in $\mathbb{R}^{n+1}$) is convex. A function $f : \mathbb{R}^n \to \mathbb{R}$ is concave if and only if $-f$ is convex. A convex body is a convex set which is both compact and has non-empty interior.
