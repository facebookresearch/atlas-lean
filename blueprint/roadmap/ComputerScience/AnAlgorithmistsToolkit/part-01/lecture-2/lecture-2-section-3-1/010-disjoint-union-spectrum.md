# Theorem 4 (Disjoint Union Spectrum)

If $L_G$ has eigenvectors $v_1, \ldots, v_n$ with eigenvalues $\lambda_1, \ldots, \lambda_n$, and $L_H$ has eigenvectors $w_1, \ldots, w_n$ with eigenvalues $\mu_1, \ldots, \mu_n$, then $L_{G \sqcup H}$ has eigenvectors $v_1 \oplus 0, \ldots, v_n \oplus 0, 0 \oplus w_1, \ldots, 0 \oplus w_n$ with corresponding eigenvalues $\lambda_1, \ldots, \lambda_n, \mu_1, \ldots, \mu_n$.
