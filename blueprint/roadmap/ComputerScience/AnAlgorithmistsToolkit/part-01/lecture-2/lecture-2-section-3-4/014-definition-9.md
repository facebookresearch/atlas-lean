# Definition 9

Let $m$ be the number of edges and $n$ be the number of vertices. Then the incidence matrix $\nabla = \nabla_G$ is the $m \times n$ matrix given by: $\nabla_{e,v} = 1$ if $e = (v,w)$ and $v < w$, $-1$ if $e = (v,w)$ and $v > w$, $0$ otherwise.
