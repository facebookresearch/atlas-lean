# Lemma 17 (Path graph)

The Laplacian for the path graph $P_n$ on $n$ vertices has the same eigenvalues as $R_{2n}$ and eigenvectors $v_k(u) = \sin(\pi k u / n + \pi / (2n))$ for $0 \leq k < n$.
