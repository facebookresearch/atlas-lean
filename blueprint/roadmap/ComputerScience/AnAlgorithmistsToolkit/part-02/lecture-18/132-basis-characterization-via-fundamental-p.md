# Lemma (Basis characterization via fundamental parallelepiped)

Let $\Lambda$ be a rank $n$ full-rank lattice and $B$ an invertible $n \times n$ matrix. Then $B$ is a basis (of $\Lambda$) if and only if $P(B) \cap \Lambda = \{0\}$.
