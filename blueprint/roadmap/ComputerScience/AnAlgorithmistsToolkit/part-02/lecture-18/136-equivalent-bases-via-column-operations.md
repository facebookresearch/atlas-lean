# Corollary (Equivalent bases via column operations)

Nonsingular matrices $B_1$, $B_2$ are equivalent if and only if one can be obtained from the other by the following operations on columns: (1) $b_i \leftrightarrow b_i + k b_j$ for some $k \in \mathbb{Z}$, (2) $b_i \leftrightarrow b_j$, (3) $b_i \leftarrow -b_i$.
