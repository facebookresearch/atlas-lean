# Theorem (Multiplicative Weights, deterministic)

Let $m_i^t$ denote the number of mistakes that expert $i$ makes in the first $t$ games and $m^t$ denote the number of mistakes that Mr.\ X makes in the first $t$ games. Then for all $i$ and $t$, $m^t \leq \frac{2 \log(n)}{\epsilon} + 2(1+\epsilon) m_i^t$, and in particular, this holds for the $i$ that minimizes $m_i^t$.
