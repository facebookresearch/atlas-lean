# Composition of edit scripts is subadditive in cost

Let $x$, $y$ and $z$ be lists over a type whose Boolean equality test agrees with equality. If an
edit script $E_1$ transforms $x$ into $y$ and an edit script $E_2$ transforms $y$ into $z$, then
some edit script transforms $x$ into $z$ and has unit cost at most the cost of $E_1$ plus the cost
of $E_2$.
