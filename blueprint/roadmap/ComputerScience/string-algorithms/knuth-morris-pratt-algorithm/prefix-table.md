# The KMP prefix table

The prefix-table representation used by the Knuth–Morris–Pratt algorithm: an array $t = [(x_0, n_0), (x_1, n_1), \dots]$ of symbols paired with fallback lengths, subject only to $n_i \le i$ for every entry. The representation does not require $n_i$ to be a longest border: $[(a, 0), (a, 0)]$ is a valid table although $aa$ has a proper border of length $1$. The construction from a pattern accepts any Boolean equality test on symbols. When that test agrees with equality, each $n_i$ of the constructed table is the length of the longest proper prefix of $x_0 \dots x_i$ that is also a suffix of it (see [the failure-function specification](mk-prefix-table-failure-spec.md)); otherwise it can fail: with a test that always answers false, the table built from $aa$ has fallback lengths $[0, 0]$ rather than $[0, 1]$.
