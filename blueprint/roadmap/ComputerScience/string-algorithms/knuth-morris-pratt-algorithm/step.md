# Transition function of the KMP matcher

The transition of a prefix table on reading a symbol $x$ from state $k$ (a length at most the table size), for a Boolean equality test on symbols: if $k$ is below the table size and the test reports $x$ equal to the stored symbol $x_k$, the new state is $k + 1$; otherwise, from $k = 0$ it is $0$, and from $k + 1$ the transition continues from the stored fallback length $n_k$. For an arbitrary table this is only the raw fallback operation: under ordinary equality, with the table $[(a, 0), (a, 0)]$, reading $a$ from state $2$ gives $1$, while the table built from $aa$ gives $2$. For the table built from a pattern, over a type whose Boolean equality agrees with equality, the transition maps the length of the longest pattern prefix that is a suffix of the input to the same length for the extended input; see [the transition specification](mk-prefix-table-step-spec.md).
