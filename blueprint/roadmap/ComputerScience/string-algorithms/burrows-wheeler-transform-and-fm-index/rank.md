# Rank of a letter in a prefix of the last column

Let $L$ be a list over a linearly ordered alphabet with a least letter $\bot$ adjoined. For a
letter $c$ and a natural number $r$, $\mathrm{rank}_c(L, r)$ is the number of occurrences of $c$
among the first $r$ letters of $L$ (among all of $L$ if $r \ge |L|$).
