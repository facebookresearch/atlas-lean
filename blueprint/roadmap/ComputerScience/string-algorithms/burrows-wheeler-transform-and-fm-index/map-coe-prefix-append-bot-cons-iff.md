# The sentinel stops every prefix match

Let $\alpha$ be an alphabet and $\alpha_\bot$ the alphabet $\alpha$ with a new letter $\bot$
adjoined. For all words $P$ and $u$ over $\alpha$ and every word $v$ over $\alpha_\bot$, the word
$P$ (viewed over $\alpha_\bot$) is a prefix of $u \bot v$ if and only if $P$ is a prefix of $u$:
the sentinel stops every match.
