# Backward search returns a genuine row interval

Let $\alpha$ be a linearly ordered alphabet and $\alpha_\bot$ the alphabet $\alpha$ with a new least
letter $\bot$ adjoined. For every list $L$ over $\alpha_\bot$ and every pattern $P$ over $\alpha$,
the interval $[sp, ep)$ returned by backward search for $P$ on $L$ satisfies
$sp \le ep \le |L|$.
