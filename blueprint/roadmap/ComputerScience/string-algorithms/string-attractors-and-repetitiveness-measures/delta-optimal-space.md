# Strings are representable in $O(\delta\log(n/\delta))$ space, optimally

Write $\Lambda = \max\{1, \log\frac{n}{\delta}\}$, the logarithmic factor saturated below by $1$ so that the terminal level is counted. Every string $T$ of length $n$ with substring complexity $\delta$ can be represented in $O(\delta\Lambda)$ machine words with access to any position in $O(\Lambda)$ time, and with indexing support for pattern matching in the same asymptotic space. Without the saturation the bound would be wrong: at $\delta = n$, for instance for every permutation of $n$ distinct symbols, the unsaturated bounds grant zero words and zero access time. The space is worst-case optimal as a function of $n$ and $\delta$: for every length $n$ and every integer $\delta$ with $2 \le \delta \le n$ there is a family of length-$n$ strings, over alphabets of size at most $n$, all with substring complexity exactly $\delta$, some member of which needs $\Omega(\delta\Lambda\log n)$ bits, i.e. $\Omega(\delta\Lambda)$ words, to be encoded. The case $\delta = 1$ is excluded because $\delta(T) = 1$ forces $T$ to be a power of a single letter. The journal version further refines the bounds to account for the alphabet size $\sigma \ge 2$. For every string over an alphabet of size $\sigma \le n^{O(1)}$, $O\bigl(\delta\max\{1, \log\frac{n\log\sigma}{\delta\log n}\}\bigr)$ words suffice to represent it and to support access and pattern searches (Theorem IV.8(1), Corollaries VI.1 and VI.7). The converse is a worst-case statement over families, not a cost paid by each string: there is an absolute constant $\beta > 0$ such that for every length $n$, alphabet size $\sigma$ and value $\Delta$ with $14\sigma \le \Delta \le \frac{n}{2}\cdot\frac{\log\sigma}{\log n}$ there is a family of length-$n$ strings over an alphabet of size $\sigma$, all with $\delta \le \Delta$, some member of which needs $\beta\,\Delta\log\frac{n\log\sigma}{\Delta\log n}\cdot\log n$ bits to be encoded (Theorem IV.8(2)). An individual string can need far less: with $\delta = 1$, a constant string over a binary alphabet is determined by its letter and its length.

## Proof sketch

Kociumaka, Navarro and Prezza show that a block tree has $O(\delta)$ marked blocks per level: each position of a marked block of length $\tau^k$ is the centre of a distinct substring of length $4\tau^k$ (after padding), so there are at most $d_{4\tau^k}/\tau^k + 4 \le 4\delta + 4$ of them; with constant $\tau$ and $O(\log(n/\delta))$ levels this gives $O(\delta\log(n/\delta))$ words and $O(\log(n/\delta))$ access (also $z = O(\delta\log(n/\delta))$ by a bound of Raskhodnikova et al.). Indexing uses a run-length grammar of size $O(\delta\log(n/\delta))$ with the grammar-based index of Christiansen et al. The lower bound is a counting argument: an explicit family of length-$n$ strings of common measure $\delta$ needs $\Omega(\delta\log(n/\delta)\log n)$ bits.
