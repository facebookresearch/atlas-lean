# Maximum-rule value is one of the written values

If $0 < n$, then for every $w : \mathrm{Fin}\,n \to \mathbb{N}$ there is a processor $i \in \mathrm{Fin}\,n$ with

$$\sup_{j \in \mathrm{Fin}\,n} w_j = w_i ,$$

so with at least one processor the maximum-rule cell value is one of the written values.
