# Luby's selection step yields an independent set

For every graph on vertices $\{0, \dots, n-1\}$, choice of priorities and set of active vertices, the vertices chosen by the selection step of Luby's algorithm form an independent set.

## Sources

- M. Luby, "A simple parallel algorithm for the maximal independent set problem", *SIAM Journal on Computing* 15 (1986).
