# Hierarchically separated trees

For $\tau > 1$, a *$\tau$-hierarchically separated tree* ($\tau$-HST) is a rooted tree with positive edge lengths in which every root-to-leaf path has the same number of edges and edge lengths decrease by a factor of at least $\tau$ from each level to the next. The leaves, with the shortest-path distance of the weighted tree, form an *HST metric* (an ultrametric up to a constant factor).
