# Hierarchically separated trees

For $\tau > 1$, a *$\tau$-hierarchically separated tree* ($\tau$-HST) is a rooted tree with positive edge lengths in which all edges from a node to its children have the same length and edge lengths decrease by a factor of at least $\tau$ along every root-to-leaf path. Requiring in addition that all leaves have the same depth is a common normalization, not part of Bartal's definition. The leaves, with the shortest-path distance of the weighted tree, form an *HST metric* (an ultrametric up to a constant factor).
