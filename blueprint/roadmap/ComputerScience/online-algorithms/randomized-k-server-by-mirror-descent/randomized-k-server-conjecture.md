# The randomized k-server conjecture

The *randomized $k$-server conjecture* asserts that on every metric space with more than $k$ points there is a randomized online $k$-server algorithm that is $O(\log k)$-competitive against oblivious adversaries. On uniform metrics (paging) the optimal randomized ratio is the harmonic number $H_k = \Theta(\log k)$, so the conjecture would say that paging is the hardest case.
