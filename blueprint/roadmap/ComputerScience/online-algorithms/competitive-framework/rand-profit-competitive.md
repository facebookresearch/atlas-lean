# Rand Profit Competitive

Randomized profit-form competitiveness, for a nonnegative profit function and a strategy chosen by a random seed: $0 \le \rho \le 1$, $b \ge 0$, the strategy is feasible for every seed, and for every legal input $\sigma$ the profit of the run is a measurable function of the seed and $\rho \cdot \mathrm{OPT}_{\mathrm{profit}}(\sigma) \le \mathbb{E}[\mathrm{ALG}_{\mathrm{profit}}(\sigma)] + b$.
