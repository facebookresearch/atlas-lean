# Optimal profit

For a profit function $w$ on traces with values in $[0, \infty)$ and a request sequence $\sigma$, the optimal profit is $\mathrm{OPT}_{\mathrm{profit}}(\sigma) = \sup\{w(\tau) : \tau \text{ feasible with requests } \sigma\} \in [0, \infty]$ ($0$ if there is no such trace); it is the maximization counterpart of the optimal cost.
