# Edmonds–Karp algorithm

The augmenting-path method of Ford and Fulkerson with the rule of Edmonds and Karp (1972): augment along a residual path with fewest arcs, found by breadth-first search. On a capacity matrix with integer flows it returns a maximum flow and a minimum cut, and Edmonds and Karp's analysis applies: residual distances from the source and to the sink never decrease (Propositions 2 and 3), an arc used as a bottleneck must be used in reverse before it is a bottleneck again, at a cost of two arcs in path length (Lemmas 1 and 2), and hence at most $(n^3 - n)/4$ augmentations take place on $n$ vertices, independently of the capacities (Theorem 1).
