# Deferred acceptance is a man-optimal stable mechanism

For every natural number $n$ there is a matching mechanism on $n$ men and $n$ women that returns, for every stated profile of strict preferences, the man-optimal stable matching of that profile: present each stated preference by a ranking and run deferred acceptance. This is the mechanism of Roth's Theorem 5, whose proof in §5 uses this "repeated proposal procedure".
