# Dijkstra's algorithm with a binary heap

On a directed graph with nonnegative edge weights, Dijkstra's algorithm with a binary min-heap supporting insert, extract-min and decrease-key in $O(\log |V|)$ time computes exact shortest-path distances from a source and runs in $O((|V| + |E|) \log |V|)$ time.
