# Sum of a Boolean list counts its true entries

Let $(b_1, \dots, b_m)$ be a finite list of Booleans and map true to $1$ and false to $0$. Then

$$\sum_{k=1}^{m} [b_k] = \#\{k \in \{1, \dots, m\} : b_k = \text{true}\},$$

the number of true entries counted with multiplicity. For the empty list both sides are $0$.
