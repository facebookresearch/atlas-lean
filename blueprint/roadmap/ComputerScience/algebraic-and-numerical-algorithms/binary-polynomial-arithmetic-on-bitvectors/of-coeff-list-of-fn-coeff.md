# Reconstructing a polynomial from a fixed-width coefficient list

Let $R$ be a semiring, $p = \sum_i p_i X^i \in R[X]$ and $s$ a natural number with $\deg p < s$ (degree in $\{-\infty\} \cup \mathbb{N}$, with $\deg 0 = -\infty$). Then the polynomial built from the list of the first $s$ coefficients $(p_0, p_1, \dots, p_{s-1})$, namely $\sum_{i=0}^{s-1} p_i X^i$, equals $p$.
