# Rational value of a trace token

For a [trace token](trace-token.md), its value is the rational number `z / d` of its
[numerator](numerator.md) `z` and [denominator](denominator.md) `d`. With the convention
`a / 0 = 0`, the value is `0` when `d = 0`, which an [admissible](admissible.md) token excludes.
