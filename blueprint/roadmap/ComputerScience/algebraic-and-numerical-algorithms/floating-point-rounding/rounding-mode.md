# Rounding modes

The four rounding-direction attributes that IEEE 754 requires of binary
formats: round to nearest with ties to even (the default), toward $+\infty$, toward $-\infty$, and
toward zero.

## Sources

- IEEE Std 754-2019, Clause 4.3; Goldberg, *What every computer scientist should know about floating-point arithmetic*, ACM Computing Surveys 23(1), 1991, Section 2.3.
