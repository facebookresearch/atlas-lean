# Inner eq cross terms

Let $f \colon X \to \{0, 1\}$ and let each state decompose as $\psi_x = u_0(x) + u_1(x)$ with $\langle u_0(x), u_1(y) \rangle = 0$ for all $x, y$ (components with different labels are orthogonal). For inputs with $f(x) \ne f(y)$, $\langle \psi_x, \psi_y \rangle = \langle u_0(x), u_0(y) \rangle + \langle u_1(x), u_1(y) \rangle$: only the terms with matching labels survive, and each pairs the correct component of one input with the incorrect component of the other.
