# Adversary quad Form le

Let `X` be finite and `f : X → Bool`. Let unit vectors `ψ x` split as `ψ x = u_false x + u_true x` with `u_false x` orthogonal to `u_true y` for all `x, y`, and with wrong-answer part `‖u_{¬f x} x‖² ≤ ε` for every `x`, where `0 ≤ ε ≤ 1/2`. Then for every adversary matrix `Γ` for `f` and every unit vector `α`, `|∑_{x,y} Γ_{xy} conj(α_x) α_y ⟨ψ_x, ψ_y⟩| ≤ 2 √(ε(1 - ε)) ‖Γ‖`, where `‖Γ‖` is the operator (spectral) norm.
