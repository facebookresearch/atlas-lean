# The oracle-free run preserves the norm

Let $U_0, U_1, \dots$ be linear isometries of a complex inner product space and $\psi_0$ a vector, and let $\psi_0' = U_0 \psi_0$, $\psi_{k+1}' = U_{k+1} \psi_k'$ be the [run](query-run.md) with the identity as oracle. Then $\|\psi_k'\| = \|\psi_0\|$ for every $k$, since every step is a linear isometry.
