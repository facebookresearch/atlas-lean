# Phase oracle

For $f \colon \mathbb{Z}_2^n \to \mathbb{Z}_2$, the phase oracle $O_f$ is the diagonal matrix indexed by $\mathbb{Z}_2^n$ with entries $(O_f)_{x,x} = (-1)^{f(x)}$, that is, the unitary map $|x\rangle \mapsto (-1)^{f(x)} |x\rangle$ (Cleve, Ekert, Macchiavello and Mosca, arXiv:quant-ph/9708016, equation (3.5)).
