# Balanced Boolean function

A function $f \colon \mathbb{Z}_2^n \to \mathbb{Z}_2$ is balanced if it takes the values $0$ and $1$ equally often:

$$\#\{x : f(x) = 0\} = \#\{x : f(x) = 1\}$$

(Cleve, Ekert, Macchiavello and Mosca, arXiv:quant-ph/9708016, Section 3). For $n \ge 1$ this means each value is taken $2^{n-1}$ times; for $n = 0$ no function is balanced.
