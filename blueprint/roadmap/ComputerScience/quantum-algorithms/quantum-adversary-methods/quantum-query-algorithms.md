# Quantum query algorithms with phase and value oracles

A $T$-query *quantum query algorithm* on inputs $x \in \Sigma^N$ acts on a finite-dimensional space $\mathbb{C}^{[N] \times V \times W}$ (query register, value register, workspace) by alternating fixed unitaries $U_0, \dots, U_T$, independent of $x$, with $T$ applications of the oracle $O_x$. For Boolean inputs the *bit oracle* is $O_x|i, b, w\rangle = |i, b \oplus x_i, w\rangle$ and the *phase oracle* is $O_x|i, b, w\rangle = (-1)^{b x_i}|i, b, w\rangle$; one phase query is simulated by one bit query, and one bit query by two phase queries. For a general finite alphabet $\Sigma$, whose symbols are encoded as bit strings of a fixed length $\ell$, the value register holds $\ell$ bits and the *value oracle* is $O_x|i, a, w\rangle = |i, a \oplus x_i, w\rangle$ with $\oplus$ the bitwise exclusive or. The output is obtained by measuring the final state $U_T O_x U_{T-1} \cdots O_x U_0 |0\rangle$ with a fixed projective measurement; the algorithm computes $f$ with error $\varepsilon$ if the correct value is obtained with probability at least $1 - \varepsilon$ on every input. $Q_\varepsilon(f)$ is the least such $T$, and $Q(f) = Q_{1/3}(f)$.
