# A unitary block-encodes itself

Trivial block-encoding: if `U` is a unitary complex matrix on a finite type
`ι`, then `trivialEncoding U`, the matrix `U` viewed on `Fin 1 × ι` with a
one-point ancilla register, is a `(1, 0)` block-encoding of `U` with
reference vector `0 : Fin 1`. This is Definition 44 of Gilyén, Su, Low and
Wiebe (arXiv:1806.01838).
