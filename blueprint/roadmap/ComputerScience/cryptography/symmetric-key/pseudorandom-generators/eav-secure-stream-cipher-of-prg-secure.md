# Asymptotic eavesdropping security of the stream cipher from a PRG

Let the admissible eavesdropper families make no queries. If a family of generators is a secure PRG
relative to a class of distinguisher families containing the distinguishers built from every
admissible eavesdropper family, then the stream cipher family is asymptotically secure against the
admissible eavesdropper families (Katz and Lindell, Theorem 3.18, in the source's form). Only the
indistinguishability half of PRG security is used.
