# Computational difference unpredictability

For a keyed hash family into $\mathbb{Z}_N$ (or any abelian group), *computational difference unpredictability* requires that every efficient adversary, without the key, outputs $(m, m', \delta)$ with $m \ne m'$ and $H_k(m) - H_k(m') = \delta$ only with negligible probability.
