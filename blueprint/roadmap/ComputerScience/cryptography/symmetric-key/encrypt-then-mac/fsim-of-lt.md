# Before the guessed index the forger follows the simulation

If the simulated game ends with its query counter at most the guessed index $j$, then the forger run
against the MAC oracle $F(k_2, \cdot)$ has the output of its final stage on the final state of the
simulated game, and every value it asks to be tagged before the final stage is the ciphertext part
of an entry of the final table.
