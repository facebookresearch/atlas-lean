# Identical until bad

Suppose decryption recovers every encryption: $\mathrm{Dec}_{k_1}(E(k_1, m, r)) = m$ for all $k_1$, $m$
and $r$. If the simulated game, started from a table satisfying the invariant with no bad query
recorded, records no bad query, then the real game on the same tape has the same output, and the
final table satisfies the invariant.
