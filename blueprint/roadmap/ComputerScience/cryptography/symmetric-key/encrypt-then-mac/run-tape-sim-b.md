# The CPA reduction's run is the simulated game

On the same tape, the CPA reduction's simulation with MAC key $k_2$, an optional challenge and a
final step, started from a table and run against encryption under $k_1$, outputs the final step
applied to the output and the final table of the simulated chosen-ciphertext game under
$(k_1, k_2)$ with the same challenge, started from the same table.
