# A restriction of exact bounded-coin sampling

In a **bounded-coin** trapdoor function scheme there is one polynomial $q$ such that the cardinality of every generated domain divides $2^{q(n)}$ at security parameter $n$: every domain point must have the same number of sampling tapes. This conclusion does not apply to [variable-time exact sampling](variable-time-trapdoor-function-scheme.md); for example, an exact uniform three-point law can be sampled by rejection.
