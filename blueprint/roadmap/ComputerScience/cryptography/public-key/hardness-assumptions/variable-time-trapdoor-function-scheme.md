# Variable-time trapdoor function scheme

In addition to the deterministic operations, size bounds and matching-key inverse law, three fixed efficient fair-bit algorithms receive the unary security parameter. Setup uses an empty auxiliary word and realizes the specified setup law. For each system parameter in its support, key generation realizes the prescribed joint law of the keys under their canonical, injective bitstring encoding. For every public key occurring in a pair in that conditional law's support, the domain is nonempty and the sampler, given the encoded system parameter and public key, is exactly uniform on that domain.

These domain requirements apply only at generated public contexts. Almost-sure halting and the running-time tail bound apply to **every** auxiliary word within each algorithm's polynomial envelope, including words that do not encode a generated context.
