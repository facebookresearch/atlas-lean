# Bounded-coin one-wayness

A [bounded-coin trapdoor function scheme](is-bounded-coin-function-scheme.md) is one-way in this model if for every polynomial coin budget and every single polynomial-time bitstring algorithm, the success probability in the [bounded-coin experiment](bounded-coin-one-way-game.md) is negligible as the positive security parameter grows. The probability is extended by zero at zero for the natural-number negligibility predicate. This is not the [variable-time public-transcript property](is-transcript-one-way.md).
