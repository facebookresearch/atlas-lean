# The Diffie–Hellman KEM with a uniform key

For an adversary $B$ with uniform coins, the left-or-right KEM experiment of the Diffie–Hellman KEM
with a uniform key is the random world of the key-exchange experiment with key derivation, with $B$
as the eavesdropper: it receives the transcript $(g^a, g^b)$ in place of the public key and the
encapsulation.
