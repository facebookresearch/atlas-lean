# The Diffie–Hellman KEM with the encapsulated key

For an adversary $B$ with uniform coins, the left-or-right KEM experiment of the Diffie–Hellman KEM
with the encapsulated key is the real world of the key-exchange experiment with key derivation $H$,
with $B$ as the eavesdropper: it receives the transcript $(g^a, g^b)$ in place of the public key and
the encapsulation.
