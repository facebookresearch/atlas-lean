# Resampling one coordinate of a uniform vector

Drawing a uniform vector in $U^\ell$ (for a finite nonempty set $U$, here the units modulo $N$) and
then replacing its $j$-th coordinate by an independent uniform element of $U$ gives a uniform vector
in $U^\ell$. The map $(v, x) \mapsto (v[j \mapsto x], v_j)$ is a bijection of $U^\ell \times U$, and the
first marginal of the uniform distribution on a product is uniform.
