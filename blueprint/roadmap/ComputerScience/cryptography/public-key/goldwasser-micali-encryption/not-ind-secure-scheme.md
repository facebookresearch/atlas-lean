# The one-bit Goldwasser–Micali scheme is not indistinguishable against unbounded distinguishers

For the key distribution concentrated on a key whose $y$ is not a square, the
[one-bit scheme](scheme.md) does not have
[indistinguishable encryptions with error $\varepsilon$](../../security-games/semantic-security-and-indistinguishability/ind-secure.md) for any
$\varepsilon < 1$. This is an instance of the general
[unattainability of indistinguishability](../../security-games/semantic-security-and-indistinguishability/not-ind-secure-of-correct.md) for correct public-key
schemes.
