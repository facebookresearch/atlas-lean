# Residuosity reveals the bit

In a commutative group, if $y$ is not a square then the
[encryption](encrypt-bit.md) of a bit $b$ with any randomness $x$ is a square if and only if $b = 0$.
This is why the owner of the factorization, who can test residuosity, can decrypt.
