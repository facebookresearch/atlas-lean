# Spaces

The message algebra over the specified gate signature, the secret-key and ciphertext spaces, and fixed binary encodings of messages, secret keys and ciphertexts. These spaces and encodings may vary with the security parameter. At a given parameter they are common to all generated public keys and all depth levels. Gentry allows the public key to determine the plaintext and ciphertext spaces; the common-space convention is a specialization, not an assertion that those spaces must always be key-independent.
