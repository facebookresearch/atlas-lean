# An eavesdropper with advantage one half against textbook RSA

For every distribution of RSA keys, some eavesdropping adversary against textbook RSA that uses no
coins has advantage $\tfrac{1}{2}$ in the eavesdropping experiment with equal-length challenge pairs.
The eavesdropping attack, which challenges only on the units $1$ and $-1$, is one such adversary.
