# Bounded distance decoding

For $\alpha<1/2$, the *bounded distance decoding problem* $\mathrm{BDD}_{\alpha}$ is: given a basis of a lattice $\Lambda$ and a target $t\in\mathbb{R}^{n}$ with $\mathrm{dist}(t,\Lambda)\le\alpha\,\lambda_1(\Lambda)$, find the (unique) lattice vector closest to $t$. More generally one fixes an absolute distance bound $d$ with $d<\lambda_1(\Lambda)/2$. Uniqueness follows from the triangle inequality.
