# Selecting the challenge message by a bit in the deterministic public-key game

For a set $\alpha$ of messages, a pair $(m_0, m_1) \in \alpha \times \alpha$ and a challenge bit $b$, the
selected message is $m_1$ if $b$ is true and $m_0$ if $b$ is false. It is the selection of
[the ElGamal game](../elgamal-encryption/pick.md), for the messages of any set, as used by the
eavesdropping game for deterministic public-key encryption.
