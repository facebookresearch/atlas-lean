# Smoothing parameter of a lattice

For a full-rank lattice $L$ with dual lattice $L^* = \{y : \langle x, y\rangle \in \mathbb{Z} \text{ for all } x \in L\}$ and $\varepsilon > 0$, the *smoothing parameter* $\eta_\varepsilon(L)$ is the infimum of the widths $s > 0$ such that $\rho_{1/s}(L^* \setminus \{0\}) \le \varepsilon$. For $s \ge \eta_\varepsilon(L)$, a continuous Gaussian of width $s$ reduced modulo $L$ is within statistical distance $\varepsilon/2$ of uniform.
