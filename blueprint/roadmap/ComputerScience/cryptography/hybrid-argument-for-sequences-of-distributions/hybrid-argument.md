# Hybrid argument

The hybrid argument: if consecutive distributions in a
sequence `p 0, ..., p k` on a finite type are pairwise within
`ε` on the event `E` (in real probability), then the endpoints
are within `k * ε` on `E`. Equivalently, for every `j ≤ k` the
probabilities of `E` under `p 0` and `p j` differ by at most `j * ε`
(apply the statement to the first `j` steps).
