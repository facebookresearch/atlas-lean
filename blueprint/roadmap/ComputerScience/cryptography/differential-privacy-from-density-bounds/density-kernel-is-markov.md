# A normalized density kernel is Markov

Let $\mu$ be an s-finite measure on a measurable space $\Omega$ and $\rho : D \to \Omega \to [0, \infty]$ jointly measurable. If $\int \rho(d)(x)\, d\mu(x) = 1$ for every $d$, then the kernel with density $\rho$ against the constant kernel $d \mapsto \mu$ is a Markov kernel: each $\rho(d)\cdot\mu$ is a probability measure.
