# A discrete mechanism as a Markov kernel

Let $D$ be a countable measurable space with measurable singletons and $\Omega$ a measurable space. A mechanism $M$ assigning to each $d \in D$ a probability mass function on $\Omega$ defines the kernel $d \mapsto M(d)$, viewed as a measure on $\Omega$. Every function out of $D$ is measurable, so this is a kernel, and it is a Markov kernel since each $M(d)$ has total mass one.
