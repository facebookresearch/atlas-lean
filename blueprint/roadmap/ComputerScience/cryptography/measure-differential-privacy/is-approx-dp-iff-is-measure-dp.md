# Discrete and kernel approximate differential privacy agree

Let $D$ and $\Omega$ be countable measurable spaces with measurable singletons and $M$ a mechanism with values in probability mass functions on $\Omega$. Then $M$ is [$(\varepsilon, \delta)$-differentially private](../approximate-differential-privacy/is-approx-dp.md) for $\mathrm{adj}$ if and only if the associated [Markov kernel](pmf-kernel.md) is [$(\varepsilon, \delta)$-differentially private](is-measure-dp.md) for $\mathrm{adj}$.
