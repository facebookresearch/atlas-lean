# A database-independent kernel is (0, 0)-differentially private

Let $D$ and $\Omega$ be countable measurable spaces with measurable singletons. For any probability mass function $p$ on $\Omega$ and any relation $\mathrm{adj}$ on $D$, the [kernel](pmf-kernel.md) of the constant mechanism $d \mapsto p$ is [$(0, 0)$-differentially private](is-measure-dp.md).
