# Perfect honest-verifier zero knowledge

A [Sigma protocol](sigma-protocol.md) is perfectly honest-verifier zero knowledge with a simulator, a
function of the statement alone, if for every statement–witness pair in the relation the
[distribution of honest transcripts](transcript.md) equals the simulator's output distribution. Only
the honest verifier, which draws a uniform challenge, is simulated.

## Sources

- I. Damgård, *On Σ-protocols*, lecture notes, Aarhus University, 2010.
