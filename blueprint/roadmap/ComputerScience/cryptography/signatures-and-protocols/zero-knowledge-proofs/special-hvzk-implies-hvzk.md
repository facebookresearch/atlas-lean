# Special HVZK implies HVZK

If a Sigma protocol is [perfectly special honest-verifier zero knowledge](special-hvzk.md) with a
per-challenge simulator, it is [perfectly honest-verifier zero knowledge](hvzk.md) with the
[uniform-challenge simulator](uniform-challenge-sim.md) built from it: drawing the prover's coins and
the challenge together is drawing the challenge first and then the coins.
