# Witnesses are isomorphisms

For simple graphs $G_0$ and $G_1$ on the same vertex type, there is a permutation of the vertices
mapping $G_0$ onto $G_1$ if and only if there is a graph isomorphism $G_0 \cong G_1$. So the
witnesses of the [graph-isomorphism protocol](sigma.md) exist exactly for isomorphic pairs.
