# Succinct arguments and SNARKs

An argument system for circuit satisfiability is *succinct* if its total communication, and the verifier's running time apart from reading the statement, are bounded by $\mathrm{poly}(\lambda, \log |C|)$ for circuits of size $|C|$ and security parameter $\lambda$. A *SNARK* is a succinct non-interactive argument of knowledge. SNARKs are defined relative to a setup model: a uniform (transparent) reference string, a structured reference string generated by a trusted setup that may be universal and updatable, or a random oracle. A *zk-SNARK* is additionally zero knowledge, with a simulator that holds the setup trapdoor or programs the random oracle.
