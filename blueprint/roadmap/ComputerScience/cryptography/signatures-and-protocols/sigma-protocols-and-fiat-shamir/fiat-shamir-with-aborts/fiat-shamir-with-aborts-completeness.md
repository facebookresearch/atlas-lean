# Completeness of Fiat–Shamir with aborts

Let $\mathsf{ID} = (\mathsf{IGen}, P, \mathrm{ChSet}, V)$ be a canonical identification scheme, $\kappa_m$ a positive integer and $H : \{0,1\}^* \to \mathrm{ChSet}$ a hash function, and let $\mathsf{SIG} = \mathsf{FS}[\mathsf{ID}, H, \kappa_m]$ be the Fiat–Shamir transformation with aborts of Kiltz, Lyubashevsky and Schaffner (EUROCRYPT 2018, Section 3.1). Its signer repeats attempts while $Z = \bot$ and its counter is at most $\kappa_m$; each attempt computes $(W, \mathit{St}) \leftarrow P_1(sk)$, $c = H(W \| M)$ and $Z \leftarrow P_2(sk, W, c, \mathit{St})$. It outputs $\sigma = (W, Z)$ from the first attempt with $Z \ne \bot$, and $\sigma = \bot$ if every attempt aborts. Verification parses $\sigma = (W, Z) \in \mathrm{WSet} \times \mathrm{ZSet}$, rejecting anything else, and returns $V(pk, W, H(W \| M), Z)$. If $\mathsf{ID}$ has correctness error $0$ (their Definition 2.3 with $\delta = 0$: every transcript with $Z \ne \bot$ is valid, and an honestly generated transcript has $Z = \bot$ with probability $0$), then $\mathsf{SIG}$ has correctness error $0$: for every key pair $(pk, sk)$ of $\mathsf{IGen}$ and every message $M$, $\Pr[\mathrm{Ver}(pk, M, \mathrm{Sign}(sk, M)) = 0] = 0$ (the case $\delta = 0$ of their Section 3.1, "if ID has correctness error $\delta$, then SIG has correctness error $\gamma = \delta^{\kappa_m}$", with Definition 2.9).

## Proof sketch

The first condition of Definition 2.3 quantifies over all $(W, \mathit{St}) \in P_1(sk)$, all $c \in \mathrm{ChSet}$ and all $Z \in P_2(sk, W, c, \mathit{St})$ with $Z \ne \bot$. An output $\sigma = (W, Z) \ne \bot$ comes from an attempt that computed an honest commitment $W$ with state, the challenge $c = H(W \| M) \in \mathrm{ChSet}$, and an honest answer $Z \ne \bot$ on $c$, so $V(pk, W, c, Z) = 1$, and verification recomputes exactly this $c$ from $W$ and $M$, so it accepts. This step uses nothing about $H$ or $\kappa_m$, and it holds for every $\delta$: every non-aborting signature verifies, which is completeness up to aborts of Lyubashevsky's signing loop (EUROCRYPT 2012, Fig. 1). Hence signing fails only if every attempt aborts. With $\delta = 0$ and a finite challenge set, $\Pr[Z = \bot \mid c] = 0$ for every fixed $c$ (the uniform challenge gives each $c$ positive mass), hence also for the challenge $H(W \| M)$ computed from the commitment, so the first attempt succeeds with probability $1$ for every $H$. For $\delta > 0$ the bound $\delta^{\kappa_m}$ of Section 3.1 needs the challenges of distinct attempts to be independent and uniform, as for a random oracle $H$; for a fixed $H$ it can fail, since $H$ may map every commitment for $M$ to a challenge on which the prover always aborts. The variant used in the random oracle analysis, which runs all attempts and outputs the first non-aborting one, has the same output law for a fixed $H$: its output depends only on the attempts up to the first success, which are distributed as in the signer that stops there.
