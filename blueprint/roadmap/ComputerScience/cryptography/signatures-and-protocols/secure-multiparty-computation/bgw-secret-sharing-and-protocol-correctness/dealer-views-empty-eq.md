# The empty coalition sees a value-independent subshare matrix

Let `F` be a field and `Party` a finite type of parties with decidable
equality, with Shamir parameters `params` and a tail sampler `sampler`. For
all `h₁ h₂ : Party → F`, `dealerViews params sampler ∅ h₁ = dealerViews params
sampler ∅ h₂`.
