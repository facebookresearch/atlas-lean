# Approximate differential privacy with zero delta is pure differential privacy

For a mechanism $M$ with values in probability mass functions, a relation $\mathrm{adj}$ and $\varepsilon \in \mathbb{R}$, $M$ is [$(\varepsilon, 0)$-differentially private](is-approx-dp.md) if and only if it is [$\varepsilon$-differentially private](../differential-privacy/is-dp.md) in the pure, pointwise sense.
