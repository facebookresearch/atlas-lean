# Static query count of the exponentiation program

For every number of steps $m$, the [static query count](num-queries.md) of the [exponentiation program](pow-prog.md) with $m$ steps is exactly $m$.

This is a property of the syntax: no oracle or environment is involved. The length of the transcript of an actual run is the separate statement [the exponentiation program issues exactly $m$ queries](length-queries-of-pow-prog.md).
