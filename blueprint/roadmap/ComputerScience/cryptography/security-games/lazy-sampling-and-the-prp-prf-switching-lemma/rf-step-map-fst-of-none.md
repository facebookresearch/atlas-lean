# Fresh answers of the lazy random function are uniform

Let the input type $X$ have decidable equality (it need not be finite) and let the range $Y$ be finite and nonempty. A table is a partial function from $X$ to $Y$. If the table $T$ records no answer to $x$, the answer of one [lazy random function step](rf-step.md) at $T$ and $x$ is uniform on $Y$.
