# Switching bound

For natural numbers $N$, $m$ and $q$, the switching bound is
$$1 - \frac{m(m - 1) \cdots (m - q + 1)}{N^q},$$
the bound after $q$ more queries when $m$ of $N$ values are unused. A ratio with denominator $0$ is
taken to be $0$, so the bound is $1$ when $N = 0$ and $q \ge 1$. For $m = N \ge 1$ it is the
probability that $q$ independent uniform samples from a set of $N$ elements are not all distinct.
