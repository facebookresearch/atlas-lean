# Composition depends only on the support

Let $p$ be a probability distribution on a set $A$, and let $f$ and $g$ map each element of $A$ to a
distribution on a set $B$. If $f(a) = g(a)$ for every $a$ in the support of $p$, then drawing $a$
from $p$ and then drawing from $f(a)$ gives the same distribution as drawing $a$ from $p$ and then
drawing from $g(a)$.
