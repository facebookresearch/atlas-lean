# Semantic security is unattainable against unbounded adversaries

Under the hypotheses of [unattainability of indistinguishability](not-ind-secure-of-correct.md), a
correct public-key scheme is not [semantically secure](semantically-secure.md) with any error
$\varepsilon < \tfrac12$, already for trivial a priori information and Boolean targets: semantic
security with error $\varepsilon$ would give indistinguishability with error $2\varepsilon < 1$.
