# Selecting the challenge message by a bit, for any message set

For a set $M$, a pair of messages $(m_0, m_1) \in M \times M$ and a challenge bit $b$, the selected
message is $m_1$ if $b$ is true ($b = 1$) and $m_0$ if $b$ is false. It is the selection of
[the pseudorandom-function encryption game](../../symmetric-key/pseudorandom-functions/pick.md), for
the messages of any set, as used by the generic security games.
