# Polynomial-query unforgeability of signatures

A family of signature schemes is existentially unforgeable against polynomially many queries when
every family of forgers with coins in given nonempty sets $R_n$ that makes polynomially many signing
queries has negligible forgery advantage (the experiment of Katz and Lindell, Definition 12.2). This
is not the probabilistic polynomial-time notion. The message spaces must be nonempty.
