# Polynomial-query CCA security

A family of private-key encryption schemes is polynomial-query CCA secure when every family of
chosen-ciphertext adversaries with coins in given nonempty sets $R_n$ that makes polynomially many
queries has negligible CCA advantage (the experiment of Katz and Lindell, Definition 3.33). This is
not the probabilistic polynomial-time notion. The message spaces must be nonempty.
