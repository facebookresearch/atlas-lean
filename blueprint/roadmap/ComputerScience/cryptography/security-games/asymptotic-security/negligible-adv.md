# Negligible advantage

A real function $\varepsilon$ on the natural numbers is a negligible advantage when
$\varepsilon(n) \le e(n)$ for all $n$, for some negligible function $e$ with rational values:
for every natural number $c$, $e(n) \le 1/n^c$ for all large enough $n$ (Katz and Lindell,
Definition 3.4).
