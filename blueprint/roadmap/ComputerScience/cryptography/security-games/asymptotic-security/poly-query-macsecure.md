# Polynomial-query unforgeability of MACs

A family of message authentication codes is existentially unforgeable against polynomially many
queries when every family of forgers with coins in given nonempty sets $R_n$ that makes
polynomially many tagging queries has negligible forgery advantage (the experiment of Katz and
Lindell, Definition 4.2). This is not the probabilistic polynomial-time notion. The message spaces
must be nonempty.
