# Averaging a pointwise bound

Let $X$ be a probability distribution on a type $\alpha$, let $F$ and $G$ assign a game (a
distribution on $\{0, 1\}$) to each point, and let $\varepsilon \ge 0$. If
$\Pr[F(x) = 1] \le \Pr[G(x) = 1] + \varepsilon$ for every $x$ in the support of $X$, then the games
obtained by first drawing $x \leftarrow X$ satisfy the same bound:
$\Pr[F(X) = 1] \le \Pr[G(X) = 1] + \varepsilon$.
