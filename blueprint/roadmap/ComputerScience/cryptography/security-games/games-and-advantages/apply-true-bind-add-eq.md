# Averaging a pointwise identity between sums of success probabilities

Let $\mu$ be a probability distribution on a type $\alpha$ and let $f, g, f', g'$ assign a game to
each point. If $\Pr[f(a) = 1] + \Pr[g(a) = 1] = \Pr[f'(a) = 1] + \Pr[g'(a) = 1]$ for every $a$, then
the same identity holds for the games obtained by first drawing $a \leftarrow \mu$.
