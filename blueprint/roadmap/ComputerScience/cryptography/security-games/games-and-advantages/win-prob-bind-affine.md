# Averaging an affine identity

If three families of games satisfy
$\Pr[F(a) = 1] = \tfrac12 + \tfrac12 \bigl(\Pr[G(a) = 1] - \Pr[H(a) = 1]\bigr)$ for every $a$, the same
identity holds for the games that first draw $a$ from a probability distribution $\mu$.
