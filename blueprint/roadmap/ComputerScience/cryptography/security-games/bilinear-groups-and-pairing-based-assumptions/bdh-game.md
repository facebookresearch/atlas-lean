# Bilinear Diffie–Hellman game

Let $B$ be a [bilinear group interface](bilinear-group-data.md) of order $q > 1$, with source groups $G_1$, $G_2$, target group $G_T$, exponent isomorphisms $\phi_1$, $\phi_2$, $\phi_T$ from $\mathbb{Z}/q\mathbb{Z}$ and pairing $e : G_1 \times G_2 \to G_T$. Write $g_1 = \phi_1(1)$, $g_2 = \phi_2(1)$ and $g_T = \phi_T(1)$ for the generators. For a randomized adversary $A$ as in the [bilinear Diffie–Hellman win experiment](bdh-win.md), the bilinear Diffie–Hellman game draws $a$, $b$, $c$ independently and uniformly from $\mathbb{Z}/q\mathbb{Z}$, runs the win experiment at $(a, b, c)$, and outputs its result. It is a probability distribution on $\{\mathrm{true}, \mathrm{false}\}$; the adversary sees $g_1^a$, $g_1^b$, $g_2^c$ and must output $g_T^{abc}$.
