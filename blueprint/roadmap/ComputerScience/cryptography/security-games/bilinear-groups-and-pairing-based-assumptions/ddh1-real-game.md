# Real decisional Diffie–Hellman game in the first source group

Let $B$ be a [bilinear group interface](bilinear-group-data.md) of order $q > 1$, with source groups $G_1$, $G_2$, target group $G_T$, exponent isomorphisms $\phi_1$, $\phi_2$, $\phi_T$ from $\mathbb{Z}/q\mathbb{Z}$ and pairing $e : G_1 \times G_2 \to G_T$. Write $g_1 = \phi_1(1)$, $g_2 = \phi_2(1)$ and $g_T = \phi_T(1)$ for the generators. Let $D$ be a randomized distinguisher that, given $X, Y, W \in G_1$, outputs a probability distribution on $\{\mathrm{true}, \mathrm{false}\}$. The real decisional Diffie–Hellman game in $G_1$ draws $a$ and $b$ independently and uniformly from $\mathbb{Z}/q\mathbb{Z}$ and outputs $D\bigl(\phi_1(a), \phi_1(b), \phi_1(ab)\bigr)$, that is, $D$ run on $(g_1^a, g_1^b, g_1^{ab})$.
