# Random decisional Diffie–Hellman game in the second source group

Let $B$ be a [bilinear group interface](bilinear-group-data.md) of order $q > 1$, with source groups $G_1$, $G_2$, target group $G_T$, exponent isomorphisms $\phi_1$, $\phi_2$, $\phi_T$ from $\mathbb{Z}/q\mathbb{Z}$ and pairing $e : G_1 \times G_2 \to G_T$. Write $g_1 = \phi_1(1)$, $g_2 = \phi_2(1)$ and $g_T = \phi_T(1)$ for the generators. Let $D$ be a randomized distinguisher on triples of elements of $G_2$, as in the [real game](ddh2-real-game.md). The random decisional Diffie–Hellman game in $G_2$ draws $a$, $b$, $c$ independently and uniformly from $\mathbb{Z}/q\mathbb{Z}$ and outputs $D\bigl(\phi_2(a), \phi_2(b), \phi_2(c)\bigr)$, that is, $D$ run on $(g_2^a, g_2^b, g_2^c)$.
