# The toy BDH game is won with probability one

Let $q > 1$. In the [toy exponent model](toy-model.md) of order $q$, the [discrete-logarithm adversary](toy-bdh-adversary.md) has [bilinear Diffie–Hellman advantage](bdh-advantage.md) equal to $1$. The bilinear Diffie–Hellman game of an interface therefore places no restriction on adversaries: one that computes discrete logarithms wins it surely.
