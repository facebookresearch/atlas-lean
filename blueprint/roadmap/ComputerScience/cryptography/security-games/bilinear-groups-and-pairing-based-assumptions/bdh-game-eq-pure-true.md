# An adversary that always wins the BDH experiment wins the BDH game surely

Let $B$ be a [bilinear group interface](bilinear-group-data.md) of order $q > 1$, with source groups $G_1$, $G_2$, target group $G_T$, exponent isomorphisms $\phi_1$, $\phi_2$, $\phi_T$ from $\mathbb{Z}/q\mathbb{Z}$ and pairing $e : G_1 \times G_2 \to G_T$. Let $A$ be a randomized adversary such that, for all $a, b, c \in \mathbb{Z}/q\mathbb{Z}$, the [bilinear Diffie–Hellman win experiment](bdh-win.md) at $(a, b, c)$ outputs $\mathrm{true}$ with probability one. Then the [bilinear Diffie–Hellman game](bdh-game.md) against $A$ outputs $\mathrm{true}$ with probability one.
