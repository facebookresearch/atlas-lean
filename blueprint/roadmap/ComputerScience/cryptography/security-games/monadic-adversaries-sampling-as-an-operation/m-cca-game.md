# Monadic CCA indistinguishability game

For a private-key encryption scheme $S$ with decidable equality on ciphertexts and a [monadic CCA adversary](mccaadversary.md) $A$, the game draws a uniformly random bit $b$, runs the [fixed-bit experiment](m-cca-exp.md) with $b$ (in which stage-two decryption of the challenge returns $\bot$), and returns whether the guess equals $b$. It is a distribution on Booleans; its mass at true is the success probability. The game allows any pair of challenge messages and answers a decryption query on the challenge with $\bot$ rather than forbidding it. On equal-length pairs, for example with a fixed-length message type, and with that rejection convention, it models $\mathrm{PrivK}^{\mathrm{cca}}$ of Katz and Lindell, 2nd ed., Definition 3.33, for adversaries that sample on demand.
