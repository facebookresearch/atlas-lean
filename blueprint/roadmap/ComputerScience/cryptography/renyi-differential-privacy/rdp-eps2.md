# Privacy budget from Rényi differential privacy conversion

For real $\varepsilon$, $\delta$ and $\alpha$,

$$
\varepsilon' = \varepsilon + \frac{\log(1/\delta)}{\alpha - 1},
$$

with the conventions $x/0 = 0$ and $\log 0 = 0$; the formula is intended for $\alpha > 1$.

## Sources

- I. Mironov, *Rényi Differential Privacy*, IEEE Computer Security Foundations Symposium (CSF), 2017, Proposition 3.
