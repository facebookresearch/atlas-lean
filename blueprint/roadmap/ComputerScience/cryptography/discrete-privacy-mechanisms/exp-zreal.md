# Real partition function of the exponential mechanism

For a finite type $R$, $u : R \to \mathbb{R}$ and real $\varepsilon$, $\Delta$, the real partition function is the real number $\sum_{r \in R} \exp(\varepsilon\, u(r) / (2\Delta))$, the sum of the [scores](../laplace-and-exponential-mechanisms/exp-mech-weight.md).
