# Cryptography

Cryptographic schemes and their correctness and security reductions: the game-based framework of security proofs, the one-time pad and pseudorandom functions with the message authentication and encryption schemes built from them, hash functions (the birthday bound and the Merkle–Damgård construction), public-key encryption and key agreement, one-time signatures, identification protocols and zero-knowledge proofs; and differential privacy, the definition of privacy for statistical data analysis, with its composition theorems and the Laplace and exponential mechanisms.
