# Tradeoff condition as two-sided event bounds

For probability mass functions $P, Q$ on a finite type $\Omega$ and real $\varepsilon, \delta$, the pair satisfies the [Kairouz–Oh–Viswanath condition](kovpair.md) with parameters $(\varepsilon, \delta)$ if and only if for every $S \subseteq \Omega$

$$
P(S) \le e^{\varepsilon} Q(S) + \delta \quad\text{and}\quad Q(S) \le e^{\varepsilon} P(S) + \delta .
$$

## Sources

- P. Kairouz, S. Oh and P. Viswanath, *The Composition Theorem for Differential Privacy*, ICML 2015; IEEE Transactions on Information Theory, 2017; arXiv:1311.0776, Theorem 2.1.
