# Finite-sum and event forms of approximate differential privacy agree

For a mechanism $M$ with values in probability mass functions on a finite type, a relation $\mathrm{adj}$ and real $\varepsilon, \delta$, $M$ is [$(\varepsilon, \delta)$-differentially private in finite-sum form](is-approx-dpfin.md) if and only if it is [$(\varepsilon, \delta)$-differentially private](../approximate-differential-privacy/is-approx-dp.md) in event form.
