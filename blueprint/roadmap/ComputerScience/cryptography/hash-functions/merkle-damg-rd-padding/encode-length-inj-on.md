# Length encodings are injective below the bound

If $a, b < 2^w$ have the same $w$-bit encoding, then $a = b$.

In particular the $n$-bit block-count block of the [double-length-encoded full hash](../a-double-length-encoded-merkle-damg-rd-transform/full-hash.md), which packages the $n$-bit encoding as a block, separates block counts below $2^n$.
