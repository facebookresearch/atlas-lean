# p-systems

An independence system $\mathcal{I}$ on a finite set $E$ (containing $\emptyset$ and closed under subsets) is a **$p$-system** if for every $Y \subseteq E$, any two maximal independent subsets $A, B$ of $Y$ satisfy $|A| \le p\,|B|$.
