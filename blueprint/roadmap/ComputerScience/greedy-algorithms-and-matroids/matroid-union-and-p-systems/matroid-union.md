# Matroid union

For a finite family of matroids $M_1, \dots, M_k$ on a common ground set, a set $I$ is **union-independent** if $I = I_1 \cup \dots \cup I_k$ with each $I_i$ independent in $M_i$. On finite subsets these sets are the independent sets of a matroid, the **matroid union** $M_1 \vee \dots \vee M_k$.
