# Exchange-argument rules for single-machine scheduling

Consider a finite set of jobs $j$ with processing times $p_j \ge 0$, all released at time $0$, processed without preemption on one machine; $C_j$ is the completion time. (SPT.) Ordering by nondecreasing $p_j$ minimizes $\sum_jC_j$. (Smith's rule.) For weights $w_j \ge 0$, putting jobs with $w_j > 0$ first, ordered so that $p_iw_j \le p_jw_i$ when $i$ precedes $j$, and jobs with $w_j = 0$ last, minimizes $\sum_jw_jC_j$; the comparison uses cross-products, never $p_j/w_j$. (EDD.) For due dates $d_j$, ordering by nondecreasing $d_j$ minimizes the maximum lateness $\max_j(C_j - d_j)$, which may be negative; for an empty set of jobs the maximum is taken as $-\infty$. Each is proved by exchanging adjacent jobs that violate the order. The Moore–Hodgson algorithm for the number of late jobs and Johnson's rule for the two-machine flow shop are separate statements.
