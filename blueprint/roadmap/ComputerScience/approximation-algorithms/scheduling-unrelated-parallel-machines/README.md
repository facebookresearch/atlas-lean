# Scheduling unrelated parallel machines

Minimising the makespan on unrelated parallel machines, where job $j$ takes time $p_{ij}$ on
machine $i$, by rounding a linear programming relaxation: Lenstra, Shmoys and Tardos's rounding
theorem and the resulting $2$-approximation.
