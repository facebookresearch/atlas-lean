# Monotonicity of n-times coverage for nonnegative weights

If all weights $w_i$ are nonnegative, then for every $n \in \mathbb{N}$ and all finite sets of
overlays $O \subseteq O'$, the [$n$-times coverage](n-coverage.md) satisfies
$f_n(O) \le f_n(O')$.

## Sources

- G. Liu, A. Dimitrakakis, B. Carter and D. Gifford, "Maximum n-times coverage for vaccine design", *International Conference on Learning Representations (ICLR)*, 2022, arXiv:2101.10902, §2.2.
