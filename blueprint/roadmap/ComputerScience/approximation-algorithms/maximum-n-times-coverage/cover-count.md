# Cover count of an element under a family of overlays

Let each overlay $j$ of a set $A$ cover each element $i$ of a set $X$ some number
$c_j(i) \in \mathbb{N}$ of times. For a finite set $O \subseteq A$ of overlays, the cover count of
an element $i$ is

$$c_O(i) = \sum_{j \in O} c_j(i),$$

the number of times the overlays of $O$ together cover $i$ (equation (1) of Liu et al.); it is $0$
for $O = \emptyset$.

## Sources

- G. Liu, A. Dimitrakakis, B. Carter and D. Gifford, "Maximum n-times coverage for vaccine design", *International Conference on Learning Representations (ICLR)*, 2022, arXiv:2101.10902, §2.2, equation (1).
