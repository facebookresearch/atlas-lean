# Monotonicity of the cover count in the overlays

For finite sets of overlays $O \subseteq O'$ and every element $i$, the
[cover counts](cover-count.md) satisfy $c_O(i) \le c_{O'}(i)$: more overlays cover every element
at least as often.

## Sources

- G. Liu, A. Dimitrakakis, B. Carter and D. Gifford, "Maximum n-times coverage for vaccine design", *International Conference on Learning Representations (ICLR)*, 2022, arXiv:2101.10902, §2.2.
