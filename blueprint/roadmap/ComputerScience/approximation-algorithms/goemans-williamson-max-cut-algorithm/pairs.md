# Ordered pairs of vertices

For a finite linearly ordered vertex set $V$, the set of pairs $(i, j) \in V \times V$ with
$i < j$. Every sum $\sum_{i<j}$ of Goemans and Williamson runs over this set, so each unordered
pair $\{i, j\}$ of distinct vertices is counted once and the weight $w_{ij}$ is read only for
$i < j$.

## Sources

- M. X. Goemans and D. P. Williamson, "Improved approximation algorithms for maximum cut and satisfiability problems using semidefinite programming", *J. ACM* 42(6) (1995), 1115–1145 (journal version), §2.
