# Sum cut Count

For a finite simple, unweighted graph $G$ with edge set $E$, each unordered edge counted once, the cut sizes of all $2^{|V|}$ Boolean assignments add up to $2^{|V| - 1} |E|$: a uniformly random assignment cuts half the edges in expectation. No nonempty-vertex assumption is needed. A graph with loops would break this; a single loop is never cut.
