# Edges of a cut

For a finite simple graph $G$ and a vertex set $S$, the set $\delta(S)$ of edges with exactly
one endpoint in $S$.

## Sources

- M. X. Goemans and D. P. Williamson, "A general approximation technique for constrained forest problems", *SIAM J. Comput.* 24(2) (1995), 296–317 (journal version), §1.
