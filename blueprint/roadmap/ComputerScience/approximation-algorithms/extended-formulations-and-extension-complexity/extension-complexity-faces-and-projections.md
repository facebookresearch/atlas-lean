# Faces and projections do not increase extension complexity

For every set $P \subseteq K^d$: intersecting $P$ with linear equations (in particular passing to an exposed face) adds no inequalities, so $\mathrm{xc}(P \cap \{x : Cx = c\}) \le \mathrm{xc}(P)$; and for every affine map $\phi$, $\mathrm{xc}(\phi(P)) \le \mathrm{xc}(P)$. Hence if $Q$ is an affine image of a face of $P$ then $\mathrm{xc}(Q) \le \mathrm{xc}(P)$.
