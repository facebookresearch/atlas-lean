# Knapsack scaling loss

For $n$ items with weights $w$, profits $p$, capacity $W$ and a scaling factor $K \ge 1$, some feasible set $S$ (total weight at most $W$) is optimal for the rounded profits $\lfloor p_i / K \rfloor$, and the optimal knapsack value exceeds the true profit of $S$ by at most $nK$.
