# Arborally satisfied point sets

A finite set $Y \subset \mathbb{R}^2$ is *arborally satisfied* if for every two points $p, q \in Y$ that differ in both coordinates, the closed axis-parallel rectangle with opposite corners $p$ and $q$ contains a point of $Y \setminus \{p, q\}$. For an access sequence $X$, an *arborally satisfied superset* of $X$ is an arborally satisfied $Y \supseteq P(X)$ all of whose points have time coordinates in $\{1, \dots, m\}$ and key coordinates in $[n]$.
