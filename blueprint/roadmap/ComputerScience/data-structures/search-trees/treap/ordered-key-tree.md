# A treap is ordered by key exactly when its key tree is a binary search tree

Let the keys carry a relation $<$ (no order axioms assumed). A treap tree $t$ is ordered by key (at every node each key of the left subtree is less than the node's key and the node's key is less than each key of the right subtree) if and only if the key tree of $t$ is an ordered binary search tree for $<$.
