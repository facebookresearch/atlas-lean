# Minimum deletion preserves AVL validity

Let $\alpha$ be a linearly ordered type and let $t$ be a valid AVL tree over $\alpha$: it is ordered (the binary tree obtained by erasing the cached heights is a binary search tree for $<$: at every node each key of the left subtree is less than the node's key and the node's key is less than each key of the right subtree), has correct cached heights (every node stores one more than the larger cached height of its two subtrees, the empty tree having height $0$), and is balanced (at every node the cached heights of the two subtrees differ by at most one). Then the tree obtained from $t$ by minimum deletion (removing its leftmost key and rebalancing on the way back up; the empty tree stays empty) is again a valid AVL tree.
