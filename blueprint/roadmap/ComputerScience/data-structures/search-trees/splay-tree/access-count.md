# Access frequency

For a sequence $x_0, x_1, \dots$ of keys and $m \ge 0$, the access frequency $q(i)$ of a key
$i$ is the number of indices $j < m$ with $x_j = i$.

## Sources

- D. D. Sleator and R. E. Tarjan, *Self-adjusting binary search trees*, J. ACM 32(3) (1985)
  652–686, §2 (before Theorem 2).
