# Truncation is monotone for the lexicographic order

Let $x$ and $y$ be lists over a linear order with $x \le y$ in the lexicographic order (in which a
proper prefix is smaller). Then for every $m \in \mathbb{N}$, the list of the first $m$ elements of
$x$ (all of them if there are fewer) is lexicographically at most the list of the first $m$
elements of $y$.
