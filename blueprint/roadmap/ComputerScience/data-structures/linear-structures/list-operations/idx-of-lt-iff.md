# List positions agree with values of an increasing map

Let $f$ map a type to the natural numbers and let $L$ be a list along which $f$ is strictly
increasing: $f(x) < f(y)$ whenever $x$ occurs at an earlier position of $L$ than $y$. For all
elements $x$ and $y$ of $L$, the position of the first occurrence of $x$ in $L$ is less than that
of $y$ if and only if $f(x) < f(y)$.
