# Inclusive first-hit prefix of an append with a hit on the left

Let $p$ be a test that is true or false on each element, and let $L$ and $M$ be lists. If $p$ is
true on some element of $L$, then the inclusive first-hit prefix for $p$ of the concatenation
$L$ followed by $M$ equals the inclusive first-hit prefix of $L$ for $p$.
