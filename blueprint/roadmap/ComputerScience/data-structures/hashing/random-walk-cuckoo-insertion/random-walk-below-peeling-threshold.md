# Constant amortized random-walk insertion time below the peeling threshold

For every $d \ge 3$ and every fixed load factor $c < c_d^{\Delta}$, let $n = cm$ keys be inserted one after another into an initially empty $d$-ary cuckoo table with $m$ slots by random-walk insertion. There is an event $E$ of probability $1 - o(1)$ over the hash functions such that the expected total number of steps for all $n$ insertions, conditioned on $E$, is $O(n)$, with a constant depending only on $c$ and $d$. Hence the expected amortized insertion time is $O(1)$. This bounds the total work, not the expected time of each particular insertion.

## Proof sketch

Below the peeling threshold the hashing hypergraph peels completely, and each key gets a *peeling number*, the round of parallel peeling in which it is removed. Walzer analyzes the eviction process generated by the successive random walks and bounds the total number of evictions over all insertions in terms of the sum of the peeling numbers of the keys. Below $c_d^{\Delta}$ the number of keys surviving each peeling round decreases fast enough that this sum is $O(n)$ in expectation on the high-probability event $E$. The argument bounds total work and gives no tail bound for a walk started at a given slot.
