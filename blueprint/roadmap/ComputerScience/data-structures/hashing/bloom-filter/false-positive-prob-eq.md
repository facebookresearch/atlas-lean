# False-positive rate as the expected k-th power of the set fraction

Let $m, n, k \in \mathbb{N}$ with $m > 0$. The exact false-positive rate under uniform hashing
equals the average, over all maps $H$ from $\{0, \dots, n - 1\} \times \{0, \dots, k - 1\}$ to
$\{0, \dots, m - 1\}$, of $(s_H / m)^k$, where $s_H$ is the number of bits set by $H$.
