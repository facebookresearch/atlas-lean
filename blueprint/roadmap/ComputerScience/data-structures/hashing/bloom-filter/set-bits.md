# Bits set by the stored hash values

Let $m, n, k \in \mathbb{N}$. An outcome of the stored hash values is a map $H$ assigning to each
stored element $a \in \{0, \dots, n - 1\}$ and hash function $j \in \{0, \dots, k - 1\}$ a bit
$H(a, j) \in \{0, \dots, m - 1\}$. The set of bits set by $H$ is the finite set of all values
$H(a, j)$.
