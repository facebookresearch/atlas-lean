# The optimal number of hash functions

Let $m, n$ be positive natural numbers. For every real $\kappa > 0$, the exponential approximation
$g(\kappa) = \left(1 - e^{-\kappa n / m}\right)^{\kappa}$ satisfies
$g\bigl((m / n) \log 2\bigr) \le g(\kappa)$; that is, among positive real numbers of hash
functions it is minimal at $\kappa = (m / n) \log 2$.
