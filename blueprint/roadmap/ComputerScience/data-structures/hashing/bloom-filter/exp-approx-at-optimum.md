# Exponential approximation at the optimal number of hash functions

Let $m, n$ be positive natural numbers and $\kappa = (m / n) \log 2$. Then the exponential
approximation $\left(1 - e^{-\kappa n / m}\right)^{\kappa}$ equals $(1/2)^{\kappa}$, since
$e^{-\kappa n / m} = 1/2$. Here $\kappa$ is a positive real number, the minimiser of the
approximation over positive reals, not necessarily an integer number of hash functions; the
value $e^{-\kappa n / m} = 1/2$ is the exponential approximation of the expected fraction of
unset bits, not that fraction itself.
