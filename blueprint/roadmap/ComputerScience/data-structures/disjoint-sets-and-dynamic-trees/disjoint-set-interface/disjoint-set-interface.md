# Representation-independent disjoint-set interface

The *disjoint-set interface* on $[n]$ has as state an equivalence relation $\sim$ on $[n]$, initially the discrete partition into singletons, and operations $\mathrm{same}(x, y)$, returning whether $x \sim y$; $\mathrm{union}(x, y)$, replacing $\sim$ by the equivalence relation generated by $\sim$ and $(x, y)$ and returning whether two distinct classes were merged; and $\mathrm{numComponents}$, returning the number of classes. Unlike concrete union-find forests, it exposes no representative indices, which depend on the history.
