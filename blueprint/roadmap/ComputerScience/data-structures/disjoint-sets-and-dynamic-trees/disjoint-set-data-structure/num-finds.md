# Number of finds

The number of finds in a sequence of set-union operations, a union counting as two finds (one
for each argument) and make-sets counting as none. This is the $m$ of Tarjan and van Leeuwen's
bounds.

## Sources

- R. E. Tarjan and J. van Leeuwen, *Worst-case analysis of set union algorithms*, J. ACM 31(2)
  (1984) 245–281, §1.
