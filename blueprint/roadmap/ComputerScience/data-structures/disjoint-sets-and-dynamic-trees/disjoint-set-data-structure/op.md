# Set-union operations

The three operations of the set union problem: make-set (allocate a new singleton), find on an
element (return the representative of its set), and union of the sets of two elements.

## Sources

- R. E. Tarjan and J. van Leeuwen, *Worst-case analysis of set union algorithms*, J. ACM 31(2)
  (1984) 245–281, §1.
