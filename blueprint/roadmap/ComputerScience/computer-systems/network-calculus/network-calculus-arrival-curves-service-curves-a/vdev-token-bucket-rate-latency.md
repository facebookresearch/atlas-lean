# Vdev token Bucket rate Latency

Closed form (Le Boudec and Thiran, *Network Calculus*, online version, Figure 1.10): vertical deviation of token bucket against
rate latency with `r ≤ R` is `b + r * T`.

## Sources

- J.-Y. Le Boudec and P. Thiran, *Network Calculus: A Theory of Deterministic Queuing Systems for the Internet*, Lecture Notes in Computer Science 2050, Springer, 2001; online version of 2022, <https://leboudec.github.io/netcal/latex/netCalBook.pdf>, whose numbering is used here, Figure 1.10.
