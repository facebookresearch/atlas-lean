# Backlog le vdev

Backlog bound (Le Boudec and Thiran, *Network Calculus*, online version, Theorem 1.4.1): for cumulative input and output flows `R` and `R'`, if `α` is an arrival curve of `R` and the system offers service curve `β`, the backlog at every time is at most the vertical deviation `v α β`. Causality `R' ≤ R` is not needed.

## Sources

- J.-Y. Le Boudec and P. Thiran, *Network Calculus: A Theory of Deterministic Queuing Systems for the Internet*, Lecture Notes in Computer Science 2050, Springer, 2001; online version of 2022, <https://leboudec.github.io/netcal/latex/netCalBook.pdf>, whose numbering is used here, Theorem 1.4.1.
