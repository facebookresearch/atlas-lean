# Hdev

Horizontal deviation as in Le Boudec and Thiran, *Network Calculus*, online version, Definition 3.1.15:
`h α β = sup over s ≥ 0 of inf {τ ≥ 0 | α s ≤ β (s + τ)}` in `ℝ≥0∞`.

## Sources

- J.-Y. Le Boudec and P. Thiran, *Network Calculus: A Theory of Deterministic Queuing Systems for the Internet*, Lecture Notes in Computer Science 2050, Springer, 2001; online version of 2022, <https://leboudec.github.io/netcal/latex/netCalBook.pdf>, whose numbering is used here, Definition 3.1.15.
