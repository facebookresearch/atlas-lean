# Concatenated service curve

The concatenated service curve $\beta_1 \otimes \beta_2$ of two curves
$\beta_1, \beta_2 : [0, \infty) \to [0, \infty)$: the min-plus convolution
$t \mapsto \inf_{0 \le s \le t} \beta_1(t - s) + \beta_2(s)$, which is always finite, viewed as a
curve with values in $[0, \infty)$.
