# Delay

Virtual delay at time `t`: `inf {τ ≥ 0 | R t ≤ R' (t + τ)}` in `ℝ≥0∞`.
The infimum is total: an empty set gives `⊤`.

## Sources

- J.-Y. Le Boudec and P. Thiran, *Network Calculus: A Theory of Deterministic Queuing Systems for the Internet*, Lecture Notes in Computer Science 2050, Springer, 2001; online version of 2022, <https://leboudec.github.io/netcal/latex/netCalBook.pdf>, whose numbering is used here, Definition 1.1.1 (virtual delay).
