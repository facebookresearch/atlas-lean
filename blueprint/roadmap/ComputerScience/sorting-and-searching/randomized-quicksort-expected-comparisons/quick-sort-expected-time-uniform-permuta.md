# Exact expected number of quicksort comparisons

For a duplicate-free list of length $n$, the expected number of comparisons of quicksort on a
uniformly random ordering of it is exactly $2(n + 1) H_n - 4n$, where $H_n$ is the $n$-th harmonic
number (CLRS Section 7.4). This sharpens the upper bound $2 n H_n$.
