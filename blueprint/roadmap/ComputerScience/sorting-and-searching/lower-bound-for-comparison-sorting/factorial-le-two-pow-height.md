# A binary tree with n! leaves has height at least log n!

If a binary tree has at least $n!$ leaves, then $n! \le 2^d$ where $d$ is its height. Here the leaves of a binary tree are its empty subtrees, and its height is the number of nodes on a longest path from the root to a leaf.
