# First-order bound on the excess fraction for −1 ≤ x ≤ 1

First-order bound: for `|x| ≤ 1`, the excess fraction `ε(x) = (e^x - 1) / (e^x + 1)` satisfies
`|ε(x) - x / 2| ≤ x ^ 2`. This is a first-order approximation with an explicit bound, not an exact
equality; the population excess is `~ γ * hbar * B0 / (2 * kB * T)` only to first order (with
`x = γ * hbar * B0 / (kB * T)`).
