# Chemical shift is field independent in the shielding model

Field independence to first order inside the shielding model: if `ν = γ * B0 * (1 - σ) / (2 * π)`
and `νref = γ * B0 * (1 - σref) / (2 * π)` with `γ * B0 ≠ 0` and `σref ≠ 1`, then the shift equals
`1e6 * (σref - σ) / (1 - σref)`, which contains no `γ` and no `B0`. This is field independence to
first order inside the shielding model; higher-order (e.g. susceptibility) field dependence is
outside it.
