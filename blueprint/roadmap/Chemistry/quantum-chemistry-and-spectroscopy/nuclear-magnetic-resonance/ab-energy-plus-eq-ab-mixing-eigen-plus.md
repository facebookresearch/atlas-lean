# Mixed-state energies from mixing-matrix eigenvalues

The mixed-state energies are the eigenvalues of the mixing matrix `M = [[νA, J / 2], [J / 2, νB]]`
minus the scalar `(νA + νB) / 2 + J / 4`: `E₊ = -J / 4 + √((νA - νB) ^ 2 + J ^ 2) / 2` equals
`λ₊ - ((νA + νB) / 2 + J / 4)` and `E₋ = -J / 4 - √((νA - νB) ^ 2 + J ^ 2) / 2` equals
`λ₋ - ((νA + νB) / 2 + J / 4)`, where `λ± = (νA + νB) / 2 ± (1 / 2) * √((νA - νB) ^ 2 + J ^ 2)`.
