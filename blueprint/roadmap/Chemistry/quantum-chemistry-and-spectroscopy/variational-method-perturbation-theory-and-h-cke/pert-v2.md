# Second-order eigenvector correction

Second-order eigenvector coefficient for `n ≥ 1` levels, the Rayleigh–Schrödinger formula in
intermediate normalization: `(v2) 0 = 0` and, for `j ≠ 0`, `(v2) j = A j / (d 0 - d j)` with
`A j = (H2) j 0 + ∑_{k ≠ 0} (H1) j k * (H1) k 0 / (d 0 - d k) - E1 * (H1) j 0 / (d 0 - d j)` and
`E1 = (H1) 0 0`; terms with a vanishing denominator are `0`, by the convention `x / 0 = 0`. In the
[second-order projected residual](second-order-projected-residual.md) it enters only the `t ^ 3`
remainder of the `e₀`-component.
