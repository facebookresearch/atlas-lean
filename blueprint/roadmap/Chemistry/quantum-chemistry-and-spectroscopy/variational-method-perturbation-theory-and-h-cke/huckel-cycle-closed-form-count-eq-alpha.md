# Closed-form cycle energies equal to α for N = 4m

Count of the closed-form cycle energies equal to `α`: for `N = 4m` with `m ≥ 1` and `β ≠ 0`, exactly
`2` of the indices `k = 0, …, N - 1` give `α + 2 * β * cos (2 * π * k / N) = α`. This counts the
closed-form list by index; it does not identify that list with the spectrum, with multiplicity, of
the Hückel matrix of the `N`-cycle.
