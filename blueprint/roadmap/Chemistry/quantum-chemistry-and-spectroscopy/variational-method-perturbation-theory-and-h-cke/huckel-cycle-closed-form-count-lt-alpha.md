# Closed-form cycle energies below α for N = 4m + 2

Count of the closed-form cycle energies below `α`: for `N = 4m + 2` and `β < 0`, exactly `2m + 1` of
the indices `k = 0, …, N - 1` give `α + 2 * β * cos (2 * π * k / N) < α`. This counts the
closed-form list by index; it does not identify that list with the spectrum, with multiplicity, of
the Hückel matrix of the `N`-cycle, so it is not a statement about bonding levels or orbital
filling.
