# Second-order projected residual is of order t³

Second-order perturbation: for `n ≥ 1` levels, let `H1` be symmetric and the level `d 0`
nondegenerate, `d 0 ≠ d j` for every `j ≠ 0`. With the corrections [`E1 = (H1) 0 0`](pert-e1.md),
[`v1`](pert-v1.md), [`E2`](pert-e2.md) and [`v2`](pert-v2.md) of first and second order, let
`v = e₀ + t • v1 + t ^ 2 • v2` and `E = d 0 + t * E1 + t ^ 2 * E2`. Then for every `t` the
`e₀`-component of the residual `(diagonal d + t • H1 + t ^ 2 • H2) v - E • v` is
`t ^ 3 * (r₃ + t * r₄)`, with `r₃ = (H1 v2 - E1 • v2 - E2 • v1 + H2 v1) 0` and
`r₄ = (H2 v2 - E2 • v2) 0`: it is `O(t ^ 3)`.
