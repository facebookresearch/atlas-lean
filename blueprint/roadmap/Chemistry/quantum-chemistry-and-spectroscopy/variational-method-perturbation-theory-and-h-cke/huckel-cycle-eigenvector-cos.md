# Hückel cosine eigenvectors of a cycle graph

Hückel cycle eigenvector (cosine family): on the cycle with `N = n + 3` vertices, the Hückel matrix
maps the cosine mode `j ↦ cos (2 * π * k * j / N)` with wavenumber `k` to
`α + 2 * β * cos (2 * π * k / N)` times itself. The mode is nonzero (its entry at vertex `0` is
`cos 0 = 1`, see [nonzero cosine modes](huckel-cycle-cos-mode-ne-zero.md)), so it is an eigenvector
with this eigenvalue.
