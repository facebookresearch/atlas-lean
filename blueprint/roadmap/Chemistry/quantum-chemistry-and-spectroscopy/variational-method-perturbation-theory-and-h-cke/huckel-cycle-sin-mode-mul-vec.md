# Hückel matrix action on cycle sine modes

Action of the cycle Hückel matrix on the sine mode `j ↦ sin (2 * π * k * j / N)` with wavenumber
`k`, on the cycle with `N = n + 3` vertices: the mode is multiplied by
`α + 2 * β * cos (2 * π * k / N)`. This is an action identity, not an eigenvector statement: the
sine vector can vanish (it is identically zero at `k = 0`), and then the identity is trivial.
