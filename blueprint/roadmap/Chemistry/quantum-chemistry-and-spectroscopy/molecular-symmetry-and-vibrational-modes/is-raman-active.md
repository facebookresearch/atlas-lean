# Raman activity in the polarizability model

A vibrational mode transforming as the irreducible representation `σ` is Raman-active iff `σ` occurs
in the symmetric-square (quadratic-form) representation (with positive multiplicity), i.e.
transforms like a quadratic form in `x, y, z`. This is a definition inside the polarizability model;
it does not predict intensities or observation. Activity is defined only for irreducible `σ`. For a
vibrational mode, `σ` must moreover occur in the complexified internal-mode representation.
