# Representation dimensions 2l + 1 for l = 0, 1/2, 1

The spaces `ℂ¹`, `ℂ²` and `ℂ³` that carry the angular-momentum representations with `l = 0`,
`l = 1/2` and `l = 1` have complex dimensions `1`, `2` and `3`, that is `2 * l + 1`. Each of these
representations is irreducible: see [l = 0](l-zero-irreducible.md),
[spin 1/2](spin-half-irreducible.md) and [l = 1](l-one-irreducible.md).
