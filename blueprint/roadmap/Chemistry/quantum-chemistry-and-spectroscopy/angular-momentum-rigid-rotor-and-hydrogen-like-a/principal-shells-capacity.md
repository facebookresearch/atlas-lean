# Capacity of the first N principal shells

Capacity of the principal shells `n = 1, ..., N`: `∑_{n=1}^{N} 2 * n^2 = N * (N+1) * (2*N+1) / 3`,
so with `2 * n^2` electrons in shell `n` the first `N` shells hold `N * (N+1) * (2*N+1) / 3`
electrons. This counts complete principal shells; it is not the Aufbau filling order, in which for
example `4s` fills before `3d`.
