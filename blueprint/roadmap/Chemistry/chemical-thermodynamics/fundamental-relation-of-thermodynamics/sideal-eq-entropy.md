# Ideal-gas entropy in reference-state form

For `U > 0`, `V > 0` and `N > 0`, the [monatomic ideal-gas entropy](sideal.md)
`S = N * kB * (log (V/N) + (3/2) * log (U/N) + s0)` equals the reference-state form
`N * s₀ + N * R * (c * log (U / U₀) + log (V / V₀) - (c + 1) * log (N / N₀))` with `c = 3/2`,
`R = kB`, reference entropy `s₀ = kB * s0` per particle and the unit reference state
`U₀ = V₀ = N₀ = 1`; both equal `N * kB * s0 + N * kB * ((3/2) * log U + log V - (5/2) * log N)`.
