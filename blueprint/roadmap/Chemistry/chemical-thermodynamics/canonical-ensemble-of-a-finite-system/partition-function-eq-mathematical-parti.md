# Partition function equals that of the finite canonical ensemble

For every real `β`, the partition function `Z(β) = ∑ i, exp (-β * E i)` equals the partition
function at real inverse temperature `β` of the [finite canonical ensemble with counting
measure](canonical-ensemble.md) built from the energies `E`: both are the same finite sum. The
identity holds for every real `β`, including `β ≤ 0`.
