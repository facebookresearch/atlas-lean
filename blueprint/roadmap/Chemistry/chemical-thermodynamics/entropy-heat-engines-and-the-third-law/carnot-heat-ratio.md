# Carnot heat ratio equals the temperature ratio

For a reversible ideal-gas Carnot cycle with `0 < Tc < Th`, `n > 0`, `R > 0`, `V₁ > 0`, `V₄ > 0`,
expansion `V₁ < V₂`, compression `V₄ < V₃` and equal volume ratios `V₂ / V₁ = V₃ / V₄`, the
isothermal heats `Qh = n * R * Th * log (V₂ / V₁)` and `Qc = n * R * Tc * log (V₃ / V₄)` are
positive and `Qc / Qh = Tc / Th`. Positivity of the heats uses `V₁ < V₂` and `V₄ < V₃`; the ratio
uses `V₂ / V₁ = V₃ / V₄`.
