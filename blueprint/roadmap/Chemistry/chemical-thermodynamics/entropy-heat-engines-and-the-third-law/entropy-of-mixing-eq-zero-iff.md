# Mixing entropy vanishes exactly for a single component

For mole fractions `x` (`0 ≤ x i`, `∑ i, x i = 1`), `n > 0` and `R > 0`, the ideal entropy of mixing
vanishes exactly for a single component: `ΔS_mix = 0` if and only if some `x i = 1` and every other
`x j = 0`. Since `n * R ≠ 0`, this is the [equality case of the Shannon
entropy](../canonical-ensemble-of-a-finite-system/shannon-entropy-eq-zero-iff.md).
