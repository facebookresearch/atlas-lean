# Gibbs phase rule as a count: (P(C − 1) + 2) − C(P − 1) = C − P + 2

For all integers `C` and `P`, `(P (C - 1) + 2) - C (P - 1) = C - P + 2`. In the phase-rule reading,
a nonreacting system of `C` independent components in `P` phases with temperature and pressure free
has `P (C - 1) + 2` intensive variables (the compositions of each phase, plus temperature and
pressure) and `C (P - 1)` independent equalities of chemical potentials, so its number of degrees of
freedom is `F = C - P + 2`. The statement is the integer identity; it proves no existence of an
equilibrium.
