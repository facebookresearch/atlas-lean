# Gibbs phase rule as rank–nullity for a surjective linear map

Let `C ≥ 1` and `P ≥ 1` be natural numbers with `P ≤ C + 2`, and let
`f : ℝ^(P (C - 1) + 2) → ℝ^(C (P - 1))` be a surjective real linear map. Then the kernel of `f` has
dimension `C + 2 - P`. This is rank–nullity only: `f` is an arbitrary surjective linear map, not
identified with the derivative of the chemical-potential equalities at an equilibrium point, and
its kernel is not identified with the tangent space of an equilibrium set.
