# Integrated adiabatic relation along a path

Let `T` and `V` be positive on `[0, 1]` with derivatives `T'` and `V'` at every `t ∈ [0, 1]`, and
let `T' / T` and `V' / V` be integrable on `[0, 1]`. If the separated adiabatic equation
`Cv * T'(t) / T(t) + nR * V'(t) / V(t) = 0` holds for every `t ∈ [0, 1]`, then
`Cv * log (T(1) / T(0)) + nR * log (V(1) / V(0)) = 0`. Every hypothesis is required only on the
process interval `[0, 1]`.
