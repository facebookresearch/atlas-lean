# Molarity of a solution

Molarity `c = n / V`: amount of solute per volume of solution, with the volume in a fixed unit
(litres or m³). It is defined for every real `V`: for `V = 0` the convention `x / 0 = 0` makes
it `0`, and the intended domain is `V > 0`. Molarity is a different function from
[molality](molality.md): the denominator here is a solution volume, not a solvent mass.
