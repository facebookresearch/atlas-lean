# Splitting off the exponential factor of the Poisson weight

Let `S` be a finite set and `c ∈ ℝ^S`. For every state `x ∈ ℕ^S` the
[Poisson weight](../../../Biology/systems-biology/stochastic-mass-action-metabolic-control-and-flu/poisson-weight.md)
factors as `π_c(x) = (∏_s e^{-c_s}) · (∏_s c_s^{x_s}) / ∏_s x_s!`. This holds for every real `c`.
