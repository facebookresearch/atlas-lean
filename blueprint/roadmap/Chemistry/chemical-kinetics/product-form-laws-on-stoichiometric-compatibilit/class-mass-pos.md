# For positive means, a nonempty set of states has positive mass

Let `S` be a finite set and `c ∈ ℝ^S` with `c_s > 0` for every `s`. If `Γ ⊆ ℕ^S` contains some state
`x₀`, then its [Poisson mass](class-mass.md) is positive: `π_c(Γ) = ∑_{x ∈ Γ} π_c(x) > 0`, every
term being positive. Positivity of every `c_s` is needed: if `c_s = 0` and `(x₀)_s ≥ 1`, then
`π_c(x₀) = 0` and the set `{x₀}` has mass `0`.
