# Adding a constant does not change the generator

Let $N$ be a [stochastic chemical reaction network](stochastic-crn.md) on a set $S$ of species with
a finite set of reactions and [generator](generator.md) $L$. For every function
$V : \mathbb{N}^S \to \mathbb{R}$, every constant $b \in \mathbb{R}$ and every state
$x \in \mathbb{N}^S$,

$$L(V + b)(x) = L V(x).$$
