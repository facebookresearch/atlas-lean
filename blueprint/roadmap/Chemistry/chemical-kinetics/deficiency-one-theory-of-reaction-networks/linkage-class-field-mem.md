# Each linkage-class field takes values in its stoichiometric subspace

Let `N` be a [chemical reaction network](../../../Dynamics/smooth-dynamics/reaction-network.md) with
finite species set `S` and finite reaction set `ρ`, and let `θ` be a linkage class of `N`. For all
real rate constants `k ∈ ℝ^ρ` and all `x ∈ ℝ^S`, the value `f_θ(x)` of the
[mass-action field of `θ`](linkage-class-field.md) lies in the
[stoichiometric subspace `𝒮_θ` of `θ`](linkage-class-stoichiometric-subspace.md).
