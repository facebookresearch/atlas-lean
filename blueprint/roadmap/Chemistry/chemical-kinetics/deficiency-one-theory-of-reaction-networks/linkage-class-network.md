# Reaction network of a linkage class

Let `N` be a [chemical reaction network](../../../Dynamics/smooth-dynamics/reaction-network.md) with
species set `S` and reaction set `ρ`, and let `θ` be a linkage class of `N`, that is, a connected
component of its [linkage graph](../../../Dynamics/smooth-dynamics/linkage-graph.md). The reaction
network of `θ` has the same species set `S`; its reactions are the
[reactions of `θ`](linkage-class-of.md), the `r ∈ ρ` whose linkage class is `θ`, and each keeps its
source complex `src(r)` and product complex `prod(r)`.
