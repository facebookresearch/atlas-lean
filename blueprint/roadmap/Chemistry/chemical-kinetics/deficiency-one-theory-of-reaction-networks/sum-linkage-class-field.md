# The mass-action field is the sum of the linkage-class fields

Let `N` be a [chemical reaction network](../../../Dynamics/smooth-dynamics/reaction-network.md) with
finite species set `S` and finite reaction set `ρ`. For all real rate constants `k ∈ ℝ^ρ` and all
`x ∈ ℝ^S`, the [mass-action vector field](../../../Dynamics/smooth-dynamics/mass-action-field.md)
`f` with rate constants `k` is the sum of the
[mass-action fields `f_θ` of the linkage classes](linkage-class-field.md):

`f(x) = ∑_θ f_θ(x)`.
