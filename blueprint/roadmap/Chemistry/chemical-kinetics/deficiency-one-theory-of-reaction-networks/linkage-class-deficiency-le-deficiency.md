# Each linkage-class deficiency is at most the network deficiency

Let `N` be a [chemical reaction network](../../../Dynamics/smooth-dynamics/reaction-network.md) with
finite species set `S` and finite reaction set `ρ`. For every linkage class `θ` of `N`, the
[deficiency](linkage-class-deficiency.md) `δ_θ` of `θ` is at most the
[deficiency](../../../Dynamics/smooth-dynamics/deficiency.md) `δ` of `N`: `δ_θ ≤ δ`.
