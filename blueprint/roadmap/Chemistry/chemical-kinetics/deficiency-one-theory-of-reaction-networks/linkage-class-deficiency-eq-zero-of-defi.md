# In a deficiency-zero network every linkage class has deficiency zero

Let `N` be a [chemical reaction network](../../../Dynamics/smooth-dynamics/reaction-network.md) with
finite species set `S` and finite reaction set `ρ`. If the
[deficiency](../../../Dynamics/smooth-dynamics/deficiency.md) of `N` is `δ = 0`, then every linkage
class `θ` of `N` has [deficiency](linkage-class-deficiency.md) `δ_θ = 0`.
