# Deterministic renewal limit zero for superlinear renewal times

Let `F : ℝ → ℝ` be nondecreasing on `[0, ∞)` with `F(0) = 0`, and let `R : ℕ → ℝ` be strictly
increasing with `R_0 ≥ 0`, `R_n / n → ∞` and `F(R_n) / n → w` for some real `w`. Then

`F(t) / t → 0` as `t → ∞` through the reals.

It is the deterministic step behind
[positive recurrence from a stationary law](is-positive-recurrent-of-stationary.md), with `F(t)`
the time spent in the regeneration state up to time `t`.
