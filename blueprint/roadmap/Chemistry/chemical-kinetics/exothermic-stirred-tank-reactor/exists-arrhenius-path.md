# Global forward existence of the Arrhenius reactor path

For `a > 0`, `B > 0`, positive `T0`, `Tin` and `Tc`, and `A, b, h, cin, c0 ≥ 0`, the physical CSTR
path exists for all forward time and stays in the box: there are `c`, `T` with `c 0 = c0`,
`T 0 = T0` that, at every `t ≥ 0`, lie in the box `[0, cmax] × [Tmin, Tmax]` ([concentration
ceiling](concentration-ceiling.md), [temperature floor](temperature-floor.md) and
[ceiling](temperature-ceiling.md)) and solve the reactor balances with the Arrhenius rate.
