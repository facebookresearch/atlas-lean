# The detonation root tends to 1 as the heat release vanishes

For fixed and arbitrary `γ` and `a1`, as the heat release `q → 0⁺` the detonation root
`1 + Q + √(Q (Q + 2))` with `Q = (γ ^ 2 - 1) q / a1 ^ 2`, the squared upstream Mach number of the
Chapman-Jouguet detonation, tends to the sonic value `1`.
