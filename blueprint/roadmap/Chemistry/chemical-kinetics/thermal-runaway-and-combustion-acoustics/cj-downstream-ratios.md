# Downstream state of a sonic reactive jump

For `γ > 1`, `R > 0`, a positive upstream state (`ρ1, T1 > 0`) entering the wave at `u1 > 0`,
upstream sound speed `a1 ^ 2 = γ R T1` and Mach number `M1 = |u1| / a1`, and a [reactive
jump](is-reactive-jump.md) with heat release `q` to a sonic downstream state (`a2 ^ 2 = γ R T2` and
`|u2| / a2 = 1`), for any `q`: the downstream state is positive (`ρ2, u2, p2, T2 > 0`) and, at
`m = M1 ^ 2`, `ρ2 / ρ1 = (γ + 1) m / (1 + γ m)`, `u2 / u1 = (1 + γ m) / ((γ + 1) m)`,
`p2 / p1 = (1 + γ m) / (γ + 1)` and `T2 / T1 = (1 + γ m) ^ 2 / ((γ + 1) ^ 2 m)`. These ratios follow
from the conservation of mass and momentum and the sonic condition.
