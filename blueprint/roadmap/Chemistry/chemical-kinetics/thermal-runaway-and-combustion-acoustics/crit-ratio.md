# Semenov critical ratio

Semenov critical ratio `q(T) = (T - Tₐ) * exp(B / T)`, for the ambient temperature `Tₐ` and the
activation temperature `B = E / R`: for `H, T > 0`, equilibrium of the [net Arrhenius heating
rate](arrhenius-rate.md) is `G / H = q(T)`. It is defined for every real `T`: for `T = 0` the
convention `x / 0 = 0` makes it `-Tₐ`. The intended domain is `T > 0`.
