# Some supercritical solution reaches the top of the box in bounded time

Stopped exit from a declared validity box `[a, b]`, `a ≤ θ₀ < b`, for `δ > exp (-1)`: some solution
of `θ' = δ * exp θ - θ` starting at `θ₀` stays in the box on `[0, τ]` and reaches the top `b` at a
time `0 < τ ≤ (b - θ₀) / (1 + log δ)`.
