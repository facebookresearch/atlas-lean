# Selection of the detonation branch

For `γ > 1`, `R > 0`, a positive upstream state (`ρ1, T1 > 0`) entering the wave at `u1 > 0`,
upstream sound speed `a1 ^ 2 = γ R T1` and Mach number `M1 = |u1| / a1`, and a [reactive
jump](is-reactive-jump.md) with heat release `q` to a sonic downstream state (`a2 ^ 2 = γ R T2` and
`|u2| / a2 = 1`), with `q > 0`: the upstream state is on the detonation root exactly when it is
supersonic (`M1 ^ 2 > 1`), and on the deflagration root exactly when it is subsonic (`M1 ^ 2 < 1`).
