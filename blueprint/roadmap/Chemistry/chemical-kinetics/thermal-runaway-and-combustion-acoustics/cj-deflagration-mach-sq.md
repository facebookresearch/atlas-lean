# Squared Mach number of the Chapman-Jouguet deflagration

The other root `1 + Q - √(Q (Q + 2))` of `m ^ 2 - 2 (1 + Q) m + 1 = 0`, the Chapman-Jouguet
deflagration point. For `Q > 0` it is the smaller root, below `1`; at `Q = 0` both roots equal `1`.
Read for `Q ≥ 0`. It is defined for every real `Q`: for `-2 < Q < 0` it is `1 + Q`, since `√x = 0`
for `x < 0`.
