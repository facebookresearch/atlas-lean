# Dissolved-oxygen balance with interfacial transfer

Let the dissolved-oxygen concentration satisfy $C' = K_L a\,(C^* - C) - u(t) - D(t)\,C$ with $K_L a, C^* > 0$ constant on the horizon,
continuous uptake $u(t) \ge 0$ and dilution $D(t) \ge 0$, the feed carrying no oxygen. If $u(t) \le K_L a\,C^*$ and
$C(0) \in [0, C^*]$, then $C$ stays in $[0, C^*]$. If $0 \le C_{\mathrm{crit}} < C^*$, $C(0) \ge C_{\mathrm{crit}}$ and
$K_L a\,(C^* - C_{\mathrm{crit}}) \ge u(t) + D(t)\,C_{\mathrm{crit}}$ for every $t$, then $C \ge C_{\mathrm{crit}}$. For constant $u$ and
$D$ this condition is equivalent to $C_{\mathrm{eq}} = (K_L a\,C^* - u)/(K_L a + D) \ge C_{\mathrm{crit}}$. Using a $K_L a$ from an
interfacial mass-transfer correlation requires that correlation's assumptions; gas-phase dynamics are outside this result.
