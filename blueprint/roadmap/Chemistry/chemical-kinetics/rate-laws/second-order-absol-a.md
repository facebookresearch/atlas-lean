# Integrated A + B → P law for A, unequal amounts

`A + B` integrated law for `A` with unequal initial amounts:
`c_A(t) = [A]₀ ([B]₀ - [A]₀) exp(-k([B]₀ - [A]₀)t) / ([B]₀ - [A]₀ exp(-k([B]₀ - [A]₀)t))`, for
`[A]₀ ≠ [B]₀`. At `[A]₀ = [B]₀` numerator and denominator vanish and the value is `0` by the
convention `x / 0 = 0`; equal amounts follow [their own law](second-order-abequal-sol.md). The
denominator also vanishes for some `[A]₀ ≠ [B]₀` at a negative time (for instance `[A]₀ = 1`,
`[B]₀ = 2`, `k = 1`, `t = -ln 2`), where the value is again `0`; for positive unequal initial
amounts, `k > 0` and `t ≥ 0` it does not vanish.
