# Half-life of each rate-law model

Half-life of each model: `[A]₀ / (2k)` at zero order, `ln 2 / k` at first order, `1 / (2k[A]₀)` for
`2A → P` and `1 / (k[A]₀)` for `A + B → P` with equal amounts. Meaningful for `k > 0` and
`[A]₀ > 0`; outside that domain the convention `x / 0 = 0` gives meaningless values.
