# The exponential A₀ e^(−kt) takes the value A₀ at t = 0

The first-order solution starts at `[A]₀`: `[A]₀ exp(-k · 0) = [A]₀` for all real `[A]₀` and `k`.
With `k = -K` this says that the
[logarithmic-branch Paris crack](../../../Physics/elasticity-and-structures/fracture-fatigue-damage-and-failure-margins/paris-crack-exp.md)
`a(N) = a₀ exp(K N)` takes the value `a₀` at zero cycles.
