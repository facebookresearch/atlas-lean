# Integrated second-order law for 2A → P

`2A → P` integrated law with `ν = -2`: `[A]₀ / (1 + 2k[A]₀t)`. It is defined for all real `[A]₀`,
`k` and `t`: where `1 + 2k[A]₀t = 0` the convention `x / 0 = 0` makes it `0`. The intended domain
is `k > 0`, `[A]₀ > 0` and `t ≥ 0`, where the denominator is positive.
