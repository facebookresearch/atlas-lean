# Error bound for the pseudo-first-order approximation

Pseudo-first-order error bound, explicit in `r = [A]₀ / [B]₀ < 1`: for `0 < [A]₀ < [B]₀`, `k > 0`
and `t ≥ 0`, `|c_A(t) - [A]₀ exp(-k[B]₀t)| ≤ [A]₀ r (1 / (1 - r) + k[B]₀t)`, where `c_A(t)` is the
concentration of `A` at time `t` given by the [integrated A + B → P law for
A](second-order-absol-a.md).
