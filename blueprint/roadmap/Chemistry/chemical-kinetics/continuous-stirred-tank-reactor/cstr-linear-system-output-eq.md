# Output of the stirred-tank linear system has no feedthrough

For all real $V$, $Q$, $k$, $C$, every state $x \in \mathbb{R}^1$ and every input $u$, the
[output](../../../Analysis/control-theory/output.md) of the
[stirred-tank linear system](cstr-linear-system.md) is $C x_0$: the input does not enter the output.
