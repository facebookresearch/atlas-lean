# Continuous stirred-tank reactor

A continuous stirred-tank reactor of volume $V > 0$ is fed at the volumetric flow $Q > 0$ with inlet
concentration $c_{\mathrm{in}}$, and its perfectly mixed contents react with first-order rate
constant $k \ge 0$, so that the concentration solves $V c' = Q (c_{\mathrm{in}} - c) - k V c$. The
explicit solution relaxes exponentially to the steady concentration $Q c_{\mathrm{in}} / (Q + kV)$.
