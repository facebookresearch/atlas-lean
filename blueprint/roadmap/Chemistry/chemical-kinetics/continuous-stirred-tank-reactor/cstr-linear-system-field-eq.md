# Field of the stirred-tank linear system

For all real $V$, $Q$, $k$, $C$, every state $x \in \mathbb{R}^1$ and every input $u$, the
[field](../../../Analysis/control-theory/field.md) of the
[stirred-tank linear system](cstr-linear-system.md) is the one-component vector

$$-\Big(\frac{Q}{V} + k\Big) x_0 + \frac{Q}{V}\, u.$$

With the convention $a/0 = 0$, at $V = 0$ it is $-k x_0$.
