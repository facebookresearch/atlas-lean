# Scaled state of a count vector

Let $S$ be a set of species. For a natural number $N$, the system size (in the model, a volume times
Avogadro's number), and a count vector $z \in \mathbb{N}^S$, the scaled state, or concentration
vector, is $z/N \in \mathbb{R}^S$, with components $z_i/N$. It is meant for $N \ge 1$; for $N = 0$
the convention $a/0 = 0$ makes it the zero vector.
