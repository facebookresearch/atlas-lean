# Partial derivative of inverse prediction in the response

Partial derivative of inverse prediction with respect to the new response: for every slope `b`,
the map `t ↦ (t - a) / b` has derivative `1 / b` at `t = y₀`. At `b = 0` the map is constantly
`0` and `1 / b = 0`, by the convention `x / 0 = 0`.
