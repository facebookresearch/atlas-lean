# Expectation of an affine map of mean-zero errors

Expectation of an affine map of mean-zero errors: with `∑ ω, p ω = 1` and `E[ε i] = 0` for every
coordinate, where `E[f] = ∑ ω, p ω * f ω`, `E[c j + (M *ᵥ ε) j] = c j`. The unbiasedness of
[OLS](expectation-ols-estimator-calibration.md) and of
[every linear unbiased estimator](expectation-linear-unbiased-calibration.md) follows from this
computation.
