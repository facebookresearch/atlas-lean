# Standard addition recovers the unknown with an explicit blank

Standard addition with an explicit blank: under the linear-response model
`y s = a₀ + b * (x_u + s)` with the same blank `a₀` and nonzero sensitivity `b` for all
additions, and the fitted line `y s = a + b * s` exact in the model, the unknown is
`x_u = (a - a₀) / b`.
