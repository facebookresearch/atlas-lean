# Limit of detection with k = 3.3

Detection limit `LOD = 3.3·s/m`, a convention, with `s` the blank standard deviation and `m` the
calibration slope, meaningful for `m > 0` (at `m = 0` the value is `0`, by the convention
`x / 0 = 0`). It is `1.1` times the [`k = 3` limit](lod-k3.md), so a reported limit must say which
`k` it uses.
