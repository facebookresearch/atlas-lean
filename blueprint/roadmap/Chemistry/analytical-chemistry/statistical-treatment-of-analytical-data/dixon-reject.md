# Dixon's Q-test rejection rule

Dixon decision procedure: reject observation `j` of a sample of `n ≥ 3` observations at the
critical value `qcrit ≥ 0` when it is extreme and its Q statistic exceeds `qcrit`. The test is not
defined for fewer than three observations, which are
[never rejected](not-dixon-reject-of-lt-three.md). The critical value is an explicit nonnegative
input (tabulated values assume normality); a negative `qcrit` never rejects.
