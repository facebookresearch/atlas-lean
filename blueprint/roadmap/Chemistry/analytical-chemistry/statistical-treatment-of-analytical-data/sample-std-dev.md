# Sample standard deviation

Sample standard deviation `s = √s²`, from the unbiased sample variance
`s² = ∑ (xᵢ - x̄)² / (n - 1)`; meaningful for `n ≥ 2`. For `n ≤ 1` the sample variance is `0` by
convention (at `n = 1`, [the degenerate sample variance](sample-var-unbiased-fin-one.md)), so `s`
is `0` and carries no information.
