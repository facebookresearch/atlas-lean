# Binary matrix map as a descendant of row lifts

Binary matrix map as a descendant of row lifts.

In a preadditive category with binary biproducts, the map with entries fᵢⱼ : X_i → Y_j is
Biprod.ofComponents(f₁₁,f₁₂,f₂₁,f₂₂) = desc(lift(f₁₁,f₁₂),lift(f₂₁,f₂₂)). Its source is X₁ ⊞
X₂ and target Y₁ ⊞ Y₂.
