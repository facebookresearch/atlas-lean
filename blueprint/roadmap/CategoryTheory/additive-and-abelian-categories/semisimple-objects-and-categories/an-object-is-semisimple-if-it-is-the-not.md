# Semisimple object

Let $\mathcal{C}$ be a category with zero morphisms. An object $X$ of $\mathcal{C}$ is semisimple when there are an index set $I$ and a family $(S_i)_{i \in I}$ of simple objects of $\mathcal{C}$ whose biproduct $\bigoplus_{i \in I} S_i$ exists in $\mathcal{C}$, with $X \cong \bigoplus_{i \in I} S_i$. The family need not be finite.
