# Semisimple category

A category $\mathcal{C}$ with zero morphisms is semisimple when every object of $\mathcal{C}$ is semisimple, that is, isomorphic to the biproduct $\bigoplus_{i \in I} S_i$ of some family of simple objects $(S_i)_{i \in I}$, indexed by a set that need not be finite, for which that biproduct exists.
