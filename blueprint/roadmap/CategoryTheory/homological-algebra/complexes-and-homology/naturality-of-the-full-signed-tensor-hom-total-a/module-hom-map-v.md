# Inner module Hom map acts by precomposition and postcomposition

Inner module Hom map acts by precomposition and postcomposition.

For `g : Q' ⟶ Q` and `h : I ⟶ I'`, the inner Hom map takes a coordinate `z_(c,d)` of degree
`b`, where `c + b = d`, to the function `y ↦ (h.f d)(z_(c,d)((g.f (-c)) y))`.
