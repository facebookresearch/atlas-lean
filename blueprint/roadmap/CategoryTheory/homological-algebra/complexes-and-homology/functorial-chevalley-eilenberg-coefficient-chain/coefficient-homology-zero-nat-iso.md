# Degree-zero coefficient homology is naturally the coinvariant quotient

Let R : Type u be a commutative ring and L : Type v an R-Lie algebra with its Lie ring
structure. There is a natural isomorphism coefficientHomologyFunctor R L 0 ≅
coefficientCoinvariantsFunctor R L. At X it identifies H₀(⋀[R]^• L ⊗[R] X) with the lifted
quotient X/[L,X], and naturality uses the same coefficient Lie-module morphism on chains and
quotient classes.
