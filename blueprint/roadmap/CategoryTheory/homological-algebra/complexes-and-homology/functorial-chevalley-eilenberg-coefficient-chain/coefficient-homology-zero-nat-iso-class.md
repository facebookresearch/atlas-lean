# The empty-word homology class maps to the lifted coefficient class

structure. For X : LieModuleCat.{w} R L and m : X, the component of
coefficientHomologyZeroNatIso sends the degree-zero homology class of exteriorPower.ιMulti R 0
Fin.elim0 ⊗ₜ[R] m to ULift.up [m] in X/[L,X]. The class map is pOpcycles 0 followed by
