# Unit insertion annihilates Lie-action relations

Let R be a commutative ring, L an R-Lie algebra, U = U_R(L), and N a right U-module. Let J ⊆ N
be generated by [x,m] = −m·ι(x), and let j : N → N ⊗_U T send m to [m,up(1)] for the
augmentation module T. Then J ≤ ker(j). In particular, each Lie-action value maps to zero
because ι(x) acts as zero on T.
