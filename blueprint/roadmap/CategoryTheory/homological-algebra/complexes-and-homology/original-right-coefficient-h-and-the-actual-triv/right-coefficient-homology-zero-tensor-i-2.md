# Right-coefficient empty-exterior classes map to units

Let R be a commutative ring, L an R-Lie algebra, and N a right U_R(L)-module. In the
exterior-first coefficient complex for [x,m] = −m·ι(x), let cl(m) be the H₀ class of 1 ⊗ m,
where 1 ∈ Λ⁰_R L is the empty exterior product. The canonical H₀-to-tensor isomorphism sends
cl(m) to [m,up(1)] in N ⊗_{U_R(L)} T for the augmentation module T. The class is defined using
the opcycles projection and its degree-zero homology identification.
