# The enveloping action on coinvariants is augmentation

Let R be a commutative ring, L an R-Lie algebra, U = U_R(L), and N a right U-module. For the
left Lie action [x,m] = −m·ι(x), let J = [L,N] be the R-submodule generated by action values
and q : N → N/J the quotient map. If ε : U → R is the augmentation, then q(m·u) = ε(u)·q(m)
for every u ∈ U and m ∈ N. Thus the induced right action on coinvariants factors through ε.
