# Comparison of left-associated iterated pairings

Comparison of left-associated iterated pairings.

In a monoidal category, let f : A ⊗ B → X, g : X ⊗ D → L and c : L → Q, with primed
counterparts. If f ≫ x = (a ⊗ b) ≫ f', g ≫ l = (x ⊗ d) ≫ g' and c ≫ q = l ≫ c', then (f ⊗
id_D) ≫ g ≫ c ≫ q = ((a ⊗ b) ⊗ d) ≫ (f' ⊗ id_D') ≫ g' ≫ c'.
