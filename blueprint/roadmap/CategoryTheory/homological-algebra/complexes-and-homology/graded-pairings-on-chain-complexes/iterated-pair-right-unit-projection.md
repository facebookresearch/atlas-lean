# Comparison equation for right unit composites

Comparison equation for right unit composites.

In a monoidal category, let e : 𝟙 → A, f : B ⊗ A → D and c : D → B, with primed data. If e ≫ a
= e', f ≫ d = (b ⊗ a) ≫ f' and c ≫ b = d ≫ c', then (id_B ⊗ e) ≫ f ≫ c ≫ b = (b ⊗ id_𝟙) ≫
(id_B' ⊗ e') ≫ f' ≫ c'.
