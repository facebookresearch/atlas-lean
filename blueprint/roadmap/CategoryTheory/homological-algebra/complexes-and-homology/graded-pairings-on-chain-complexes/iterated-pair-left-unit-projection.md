# Comparison equation for left unit composites

Comparison equation for left unit composites.

In a monoidal category, let e : 𝟙 → A, f : A ⊗ B → D and c : D → B, with primed data. If e ≫ a
= e', f ≫ d = (a ⊗ b) ≫ f' and c ≫ b = d ≫ c', then (e ⊗ id_B) ≫ f ≫ c ≫ b = (id_𝟙 ⊗ b) ≫ (e'
⊗ id_B') ≫ f' ≫ c'.
