# Extension axiom for maps of cofiber sequences

Let C have a zero object and Waldhausen cofibration, weak-equivalence
and cofibration-pushout data.

The extension axiom says that for a commuting map between cofiber sequences A → B → Q and A′ → B′ → Q′, weak equivalences A → A′ and Q → Q′ imply a weak equivalence B → B′.
