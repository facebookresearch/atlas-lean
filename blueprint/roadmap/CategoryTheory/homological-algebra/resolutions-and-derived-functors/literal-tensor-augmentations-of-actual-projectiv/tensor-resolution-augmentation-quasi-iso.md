# Tensor-resolution augmentation is a quasi-isomorphism exactly for positive Tor vanishing

Tensor-resolution augmentation is a quasi-isomorphism exactly for positive Tor vanishing.

The augmentation `P ⊗ Q → (M ⊗ N)[0]` is a quasi-isomorphism if and only if `Tor_(n+1)^R(M,
N)` is zero for every natural `n`.
