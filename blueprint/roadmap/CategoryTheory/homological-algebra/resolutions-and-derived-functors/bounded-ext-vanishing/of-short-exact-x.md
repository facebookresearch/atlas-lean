# Kernel Ext vanishing from adjacent bounds in a short exact sequence

Kernel Ext vanishing from adjacent bounds in a short exact sequence.

For a short exact sequence and fixed probe `A`, if `Ext(A,S.X₂)` vanishes below `n + 1` and
`Ext(A,S.X₃)` below `n`, then `Ext(A,S.X₁)` vanishes below `n + 1`.
