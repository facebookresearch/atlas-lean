# Definition 1.8.1

A monoidal category $\mathcal{C}$ is strict if for all objects $X, Y, Z$ in $\mathcal{C}$ one has equalities $(X \otimes Y) \otimes Z = X \otimes (Y \otimes Z)$ and $X \otimes \mathbf{1} = X = \mathbf{1} \otimes X$, and the associativity and unit constraints are the identity maps.
