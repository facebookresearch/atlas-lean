# Corollary 1.29.5 (The Taft-Wilson theorem)

If $C$ is a pointed coalgebra, then $C_0$ is spanned by (linearly independent) grouplike elements $g$, and $C_1/C_0 = \bigoplus_{h,g} \operatorname{Prim}_{h,g}(C)/k(h - g)$. In particular, any noncosemisimple pointed coalgebra contains nontrivial skew-primitive elements.
