# Proposition 1.34.4

The following identities hold: $(\operatorname{Id} \otimes \Delta)(\Delta(h)) = \Phi (\Delta \otimes \operatorname{Id})(\Delta(h)) \Phi^{-1}$ for $h \in H$; $(\operatorname{Id} \otimes \operatorname{Id} \otimes \Delta)(\Phi)(\Delta \otimes \operatorname{Id} \otimes \operatorname{Id})(\Phi) = (1 \otimes \Phi)(\operatorname{Id} \otimes \Delta \otimes \operatorname{Id})(\Phi)(\Phi \otimes 1)$; $(\varepsilon \otimes \operatorname{Id})(\Delta(h)) = h = (\operatorname{Id} \otimes \varepsilon)(\Delta(h))$; $(\operatorname{Id} \otimes \varepsilon \otimes \operatorname{Id})(\Phi) = 1 \otimes 1$.
