# Definition 1.36.1

$J$ is called a bialgebra twist if $H^J$ is a bialgebra, i.e., $\Phi^J = 1$. Thus, a bialgebra twist for $H$ is an invertible element $J \in H \otimes H$ such that $(\varepsilon \otimes \operatorname{Id})(J) = (\operatorname{Id} \otimes \varepsilon)(J) = 1$, and $J$ satisfies the twist equation $(\operatorname{Id} \otimes \Delta)(J)(\operatorname{Id} \otimes J) = (\Delta \otimes \operatorname{Id})(J)(J \otimes \operatorname{Id})$.
