# Proposition 1.42.4

If $\mathcal{C}$ is a semisimple multitensor category then $\operatorname{Gr}(\mathcal{C})$ is a based ring. If $\mathcal{C}$ is semisimple tensor category then $\operatorname{Gr}(\mathcal{C})$ is a unital based ring. If $\mathcal{C}$ is a (multi)fusion category, then $\operatorname{Gr}(\mathcal{C})$ is a (multi)fusion ring.
