# Definition 2.4.3

We will say that a module category $\mathcal{M}$ over $\mathcal{C}$ is indecomposable if it is not equivalent to a nontrivial direct sum of module categories (that is, with $\mathcal{M}_1, \mathcal{M}_2$ nonzero).
