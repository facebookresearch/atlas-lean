# Feedback Step

For a relation `f : X ⊕ U ⟶ Y ⊕ U` and a postcondition `Q ⊆ Y`, the one-step safety operator sends a set `I` of hidden states to the set of hidden states `a` such that every step of `f` from `inr a` either exits to some `y ∈ Q` or moves to a hidden state in `I`. It is monotone in `I`.
