# Trace Of Pairing

In a monoidal category, given an exact pairing between `U` and `D` (so `D` is a right dual of `U`) and a morphism `f : X ⊗ U ⟶ Y ⊗ U`, the trace of `f` along this pairing is the morphism `X ⟶ Y` obtained by tensoring with the coevaluation `𝟙 ⟶ U ⊗ D`, applying `f` and closing the loop with the evaluation `D ⊗ U ⟶ 𝟙`.
