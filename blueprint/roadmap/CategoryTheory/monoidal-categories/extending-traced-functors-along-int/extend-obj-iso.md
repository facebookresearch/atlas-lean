# Object formula for the canonical extension

Let $C$ be a symmetric monoidal category with a symmetric trace $T$, let $\mathrm{Int}(T)$ be its [Int construction](../the-int-construction/README.md), whose objects are pairs $X = (X^+, X^-)$ of objects of $C$, and let $J : C \to \mathrm{Int}(T)$, $J(A) = (A, \mathbf{1})$, be the embedding. Let $D$ be a right rigid symmetric monoidal category, with chosen right duals $Y^\vee$ and canonical trace $T_D$ ([trace along the chosen duals](../symmetric-traces-and-dual-comparisons/symmetric-trace-of-rigid.md)), and let $F : C \to D$ be a braided strong monoidal functor that preserves $T$, sending it to $T_D$. For every object $X = (X^+, X^-)$ of $\mathrm{Int}(T)$, the [canonical extension](extend.md) satisfies $\operatorname{ext}(F)(X) \cong F(X^+) \otimes F(X^-)^\vee$, canonically.
