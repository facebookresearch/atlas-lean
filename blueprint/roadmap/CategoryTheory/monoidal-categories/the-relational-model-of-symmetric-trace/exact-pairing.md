# Every set is its own dual in the category of relations

In the category of sets and relations with the cartesian product as tensor, every set $X$ is a right dual of itself: the coevaluation $\mathbf{1} \to X \times X$ relates the point of the one-point set to each pair $(x, x)$, and the evaluation $X \times X \to \mathbf{1}$ relates each pair $(x, x)$ to the point. Both are the equality relation on $X$.
