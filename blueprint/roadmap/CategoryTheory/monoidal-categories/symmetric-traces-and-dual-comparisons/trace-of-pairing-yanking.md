# Yanking for the trace along an exact pairing

Let $C$ be a symmetric monoidal category with symmetry $\beta$. If $D$ is a right dual of $X$ through an exact pairing, the [trace along this pairing](trace-of-pairing.md) of the symmetry $\beta_{X,X} : X \otimes X \to X \otimes X$ is the identity: $\operatorname{tr}_D(\beta_{X,X}) = 1_X$.
