# Extend preserves trace

Let `T` be a symmetric trace on a symmetric monoidal category `C`, `D` a rigid symmetric monoidal category and `F : C ⥤ D` a braided functor that preserves `T` with respect to the canonical compact trace of `D`. Then the extension of `F` to the Int construction on `T` preserves the canonical traces: the compact trace of the Int construction is sent to the compact trace of `D`.
