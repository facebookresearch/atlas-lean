# Crossed action of a composite functor

Let $C$, $D$, $E$ be symmetric monoidal categories and $F : C \to D$, $G : D \to E$ braided strong monoidal functors, acting on crossed arrows by $F^\times(f) = \mu_{A,V} ; F(f) ; \delta_{B,U}$ as for the [Int construction](../the-int-construction/README.md). For every crossed arrow $f : A \otimes V \to B \otimes U$ of $C$,

$$(F ; G)^\times(f) = G^\times(F^\times(f)).$$

This law does not require trace preservation.
