# The Int lift commutes with the embedding

Let $C$ and $D$ be symmetric monoidal categories with symmetric traces $T$ and $S$, and let $\mathrm{Int}(T)$ be the [Int construction](../the-int-construction/README.md), whose objects are pairs $X = (X^+, X^-)$ and whose morphisms $X \to Y$ are crossed morphisms $X^+ \otimes Y^- \to Y^+ \otimes X^-$. For a braided strong monoidal functor $F : C \to D$, with tensor comparison $\mu$ and its inverse $\delta$, write $F^\times(f) = \mu_{A,V} ; F(f) ; \delta_{B,U}$ for its action on a crossed arrow $f : A \otimes V \to B \otimes U$, where $;$ is composition in forward order. If moreover $F$ preserves $T$ relative to $S$, the induced functor $L(F) : \mathrm{Int}(T) \to \mathrm{Int}(S)$ sends $(A, U)$ to $(FA, FU)$ and acts on morphisms by $F^\times$. Write $\mathrm{pair}(a, b) = a \otimes b$ for the [separated morphism](map-pair.md) $X \to Y$ given by $a : X^+ \to Y^+$ and $b : Y^- \to X^-$ (the negative argument points backwards), and $\mathrm{pairIso}(a, b)$ for the isomorphism with forward map $\mathrm{pair}(a.\mathrm{hom}, b.\mathrm{hom})$ and inverse $\mathrm{pair}(a.\mathrm{inv}, b.\mathrm{inv})$. Write $J_T : C \to \mathrm{Int}(T)$, $J_T(A) = (A, \mathbf{1})$, for the embedding. Then $J_T ; L(F) \cong F ; J_S$, with component at $X$ the isomorphism $\mathrm{pairIso}(1_{FX}, \varepsilon\mathrm{Iso}_F)$ from $L(F)(J_T X) = (FX, F\mathbf{1})$ to $J_S(FX) = (FX, \mathbf{1})$. The hypotheses matter: acting by an arbitrary functor on the two components of an embedded object need not give an object isomorphic to the embedding of its image (for the constant functor at $1$ on the discrete additive monoidal category of integers, $(1, 1)$ versus $(1, 0)$).
