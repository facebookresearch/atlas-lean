# The induced Int functor on separated morphisms

Let $C$ and $D$ be symmetric monoidal categories with symmetric traces $T$ and $S$, and let $\mathrm{Int}(T)$ be the [Int construction](../the-int-construction/README.md), whose objects are pairs $X = (X^+, X^-)$ and whose morphisms $X \to Y$ are crossed morphisms $X^+ \otimes Y^- \to Y^+ \otimes X^-$. Write $\mathrm{pair}(a, b) = a \otimes b$ for the [separated morphism](map-pair.md) $X \to Y$ given by $a : X^+ \to Y^+$ and $b : Y^- \to X^-$ (the negative argument points backwards), and $\mathrm{pairIso}(a, b)$ for the isomorphism with forward map $\mathrm{pair}(a.\mathrm{hom}, b.\mathrm{hom})$ and inverse $\mathrm{pair}(a.\mathrm{inv}, b.\mathrm{inv})$. For a braided strong monoidal $F : C \to D$ preserving $T$ relative to $S$, the [induced functor](../the-int-construction/map.md) $L(F)$ sends $\mathrm{pair}(a, b)$ to $\mathrm{pair}(Fa, Fb)$, for all $a : X^+ \to Y^+$ and $b : Y^- \to X^-$.
