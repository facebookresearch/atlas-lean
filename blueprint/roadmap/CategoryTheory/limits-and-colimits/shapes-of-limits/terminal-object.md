# Terminal object

An object $t$ of a category $\mathsf{C}$ is terminal when every object $x$ of $\mathsf{C}$ has exactly one morphism $x \to t$. Mathlib defines, for an object $X$ of a category, the data that $X$ is terminal as a limit structure on the cone over the empty diagram with apex $X$: since a cone over the empty diagram is just an object, such a structure packages, for every object $Y$, a morphism $Y \to X$ together with the property that every morphism $Y \to X$ equals it; this is data rather than a proposition, and it concerns the given object $X$, not the existence of some terminal object in the category. From such data Mathlib obtains a morphism $Y \to X$ for every object $Y$ and proves that any two morphisms $Y \to X$ are equal. Conversely, from a morphism $Y \to X$ chosen for every object $Y$ such that every morphism $Y \to X$ equals the chosen one, Mathlib constructs the data that $X$ is terminal.
