# Left Simple Root Coeff weyl01 inv mul transvection01 mul weyl01 neg one

for `Fin 3`: left root `0 ⋖ 1`. For `u : Fˣ`,
`(w₀₁ 1)⁻¹ * T₀₁(u) * w₀₁(-1)` has left coefficient

characteristic-two valid, using only `w(1)⁻¹ = w(-1)`.
