# Finite Stage succ exists last Boundary Blocks

Alternating boundary-block word for `g ∈ finiteStage (n+1)`.
Finite alternation of column/row blocks, `n=0` gives `1`. Uses
`finiteStage_succ_eq_sup_lastColumnRow`, `sup_eq_closure`,
`lastColumnProduct_range`, `lastRowProduct_range` with closure
induction; avoids commutative `mem_sup`, normality, unconditional
swaps. Inverses stay inside same side. No global
`finiteStage * column * row` normal form.
