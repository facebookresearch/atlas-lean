# Torus mem finite Stage succ

For `[Field F]`, `hi : i < n`, `u : Fˣ`, `torus (R := F) i n _ u`
lies in `finiteStage (R := F) (n + 1)`. The `n + 1` bound is minimal for
`i < n + 1` and `n < n + 1`; the statement is vacuous at `n = 0`,
characteristic-two safe, and asserts only subgroup membership, not exact
torus multiplicativity nor any boundary-torus intersection statement.
