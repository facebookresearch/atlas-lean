# Torus Cocycle Subgroup le finite Torus Subgroup

Torus-cocycle subgroup lies in the finite torus subgroup; the rank hypothesis is `2 ≤ n`.

Each `(0, 1)` torus factor satisfies `0 < n` and `1 < n`, hence lies in
`finiteTorusSubgroup n` via `torus_mem_finiteTorusSubgroup`; closure then gives
the inclusion. No reverse inclusion, equality, normality, or Matsumoto claim;
no claim for `n < 2`.
