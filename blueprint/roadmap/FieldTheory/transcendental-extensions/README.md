# Transcendental extensions and function fields

Algebraic independence, transcendence bases and transcendence degree, separably generated extensions, fields of rational functions and Lüroth's theorem, and differential fields with Liouville's theorem on elementary integrals. Algebraic extensions are under field extensions and algebraic closure; the arithmetic of global function fields is under number theory.
