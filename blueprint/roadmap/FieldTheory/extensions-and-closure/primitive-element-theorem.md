# Primitive element theorem for finite separable field extensions

Let $E/F$ be a finite separable extension of fields. Then there is an element $\alpha \in E$ with $F(\alpha) = E$: the smallest subfield of $E$ containing $F$ and $\alpha$ is $E$ itself.
