# Inverse test succeeds exactly for irreducible moduli

Let $s \ge 1$ and let $g = (g_0, \dots, g_{s-1})$ be an $s$-bit word. Then the
[exhaustive inverse test](passes-inverse-test.md) succeeds for $g$ if and only if the monic
polynomial $m_g(X) = X^s + \sum_{i < s} g_i X^i$ is irreducible over $\mathbb{F}_2$.
