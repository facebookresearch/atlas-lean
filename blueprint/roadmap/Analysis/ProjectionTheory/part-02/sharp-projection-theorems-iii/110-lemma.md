# Lemma (Section: Sharp Projection Theorems III, Subsection: Combining scales)

If $f \colon [0,1] \to \mathbb{R}$ is 2-Lip, increasing with $f(1) = t$, $f(x) \geq t \cdot x$, and $s < t < 2 - s$, then there is a decomposition $[0,1] = \bigsqcup I$ (plus some tiny leftovers) where on each interval $I$ either (1) $f$ is almost linear with slope $t_I$, $s < t_I < 2 - s$, or (2) $f$ is semi-well-spaced.
