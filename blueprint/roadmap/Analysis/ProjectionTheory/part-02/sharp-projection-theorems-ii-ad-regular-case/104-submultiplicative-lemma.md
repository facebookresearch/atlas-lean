# Lemma (Submultiplicative Lemma)

If $\delta = \delta_1 \delta_2$, $\delta_1, \delta_2 < 1$, then $R_{AD}(\delta) \lessapprox R_{AD}(\delta_1) R_{AD}(\delta_2)$.
