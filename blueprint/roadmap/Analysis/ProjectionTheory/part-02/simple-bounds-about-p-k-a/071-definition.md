# Definition (Section: Simple Bounds About $P_K(a, b)$)

A pair $(a_1, a_2)$ is $\epsilon$-bad if $P_2(a_1, a_2) < \epsilon K^{-2} |B|$. Let $BP_\epsilon(b) = \#\{(a_1, a_2) \in N(b)^2 \mid (a_1, a_2) \text{ is } \epsilon\text{-bad}\}$.
