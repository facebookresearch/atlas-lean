# Theorem (Lindenstrauss, Mohammadi, Wang, Yang, vague statement)

There is a constant $c > 0$ so that the following holds. If $G = \operatorname{SL}(3, \mathbb{R})$, $\Gamma = \operatorname{SL}(3, \mathbb{Z})$, $U$ as above, and $U \cdot x$ is not close to a proper homogeneous subspace, then $U_{[0,T]} x$ is $T^{-c}$-dense in $G / \Gamma$.
