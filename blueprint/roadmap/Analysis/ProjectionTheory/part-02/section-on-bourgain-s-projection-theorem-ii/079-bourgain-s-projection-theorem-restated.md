# Theorem (Bourgain's projection theorem, restated)

Given $0 < t < 2$, $0 < s \leq 1$, there exist $\varepsilon, \eta > 0$ such that if $X \subset B^2(0,1)$ is a $(\delta, t, \delta^{-\eta})_2$-set with $|X|_\delta = \delta^{-t}$ and $D \subset [0,1]$ is a $(\delta, s, \delta^{-\eta})_1$-set, then there exists some $\theta \in D$ such that $$\min_{\substack{X' \subset X \\ |X'|_\delta \geq \delta^\eta |X|_\delta}} |\pi_\theta X'| \geq \delta^{-\frac{t}{2} - \varepsilon}.$$
