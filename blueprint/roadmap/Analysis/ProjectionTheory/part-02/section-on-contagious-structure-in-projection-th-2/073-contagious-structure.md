# Lemma (Contagious Structure)

If $Z$ is an abelian group and $A \subset Z$, and $|A - t_1 A| \leq K|A|$ and $|A - t_2 A| \leq K|A|$, then $|A - (t_1 \cdot t_2) A| \leq K^2 |A|$.
