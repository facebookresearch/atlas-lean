# Theorem (BKT)

Let $X \subset \mathbb{F}_p^2$ be a subset with size $|X| = p^{s_X}$, $0 < s_X < 2$, and $D \subset \mathbb{F}_p$ be a set of directions with $|D| = p^{s_D}$, $s_D > 0$. Then $\max_{t \in D} |\pi_t(X)| \gtrsim p^{\epsilon} |X|^{1/2}$ for $\epsilon = \epsilon(s_X, s_D) > 0$.
