# Theorem (1982)

Let $E$ be a set of points in $\mathbb{R}^2$. Pick some integer $S > 1$. For every $x$ in $E$, let $L_x$ be a set of $S$ lines passing through $x$. Define $L = \bigcup_{x \in E} L_x$. Then $|L| \gtrsim \min(|E| \cdot S,\, |E|^{1/2} S^{3/2})$.
