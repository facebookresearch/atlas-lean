# Definition (Section: Sharp Projection Theorems I: Introduction and Beck's Theorem)

A set $E \subset \mathbb{R}^d$ contained in the unit ball centered at the origin is $(\delta, s, C)$ if $|E \cap B_x(r)|_\delta \leq C r^s |E|_\delta$ for all balls of radius $r$ with $r \geq \delta$ centered at arbitrary points $x$, where $|\cdot|_\delta$ is the $\delta$-ball covering number.
