# Theorem (Orponen-Shmerkin (2021))

Under the same hypotheses as the Furstenberg theorem, for every $0 < s < t$ there is $\epsilon > 0$ so that $|\mathbb{T}| \gtrsim \delta^{-2s - \epsilon}$.
