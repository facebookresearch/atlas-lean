# Theorem (GSW)

Let $E \subset \mathbb{R}^2$ be a set of $N$ $\delta$-balls with $E \subset B_1$ which is well-spaced, in the sense that $|E \cap B_{N^{-1/2}}|_\delta \lesssim 1$. Let $\mathcal{T}_R(E)$ be a set of $\delta$-tubes which are essentially distinct with $|T \cap E|_\delta \geq R$. Assume also that $R > \delta^{-\varepsilon} \delta \cdot |E|_\delta$. Then $|\mathcal{T}_R(E)| \lessapprox \frac{N^2}{R^3}$.
