# Theorem 12.1

If $A \subset \mathbb{F}_p$, $|A| = p^{s_A}$, $D \subset \mathbb{F}_p$, $|D| = p^{s_D}$, $0 < s_A, s_D < 1$, then there exists $\epsilon(s_A, s_D) > 0$ such that $\max_{t \in D}(|A + tA|) \geq p^{s_A + \epsilon(s_A, s_D)}$.
