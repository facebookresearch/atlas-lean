# Theorem (Beck)

Let $E$ be a set of points in $\mathbb{R}^2$ and for any line $\ell$, assume that $|\ell \cap E| \leq \frac{1}{2} |E|$. For every $x \in E$, let $L_{x,E}$ be the set of lines passing through $x$ that also pass through an additional point in $E$, i.e., $L_{x,E} = \{\ell \mid \text{$\ell$ is a line passing through $x$ such that } |\ell \cap E| \geq 2\}$. Then for every $x$, $|L_{x,E}| \gtrsim |E|$.
