# Lemma (Section on History of the Furstenberg conjecture)

If $0 < s < \min(u, 1)$, and if a typical set $L_{x,E}$ is uniform and $(\delta, s, C)$, then a typical $L_{x,E}$ is $(\delta, s + \epsilon, C')$ where $\epsilon = \epsilon(s, u) > 0$.
