# Lemma (Main Lemma 2R)

If the setup holds then we can decompose $f$ as $f = \sum_{\substack{1 \leq r \leq R \\ r \text{ dyadic}}} f_r$ with $f_r$ (nearly) orthogonal to each other, and for each $r$, $\hat{f_r} \subset B(1/r)$ and $\|f_r\|^2_{L^2} \lesssim |\mathcal{T}| N_{\mathcal{T}}(r) \frac{R}{r}$.
