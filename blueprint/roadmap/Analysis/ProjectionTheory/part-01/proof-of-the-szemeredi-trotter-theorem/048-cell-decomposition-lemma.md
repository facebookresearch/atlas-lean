# Lemma (Cell decomposition lemma)

Let $X$ be a set of points in $\mathbb{R}^2$ and pick an integer $s \geq 1$. Then the plane can be disjointly partitioned into a set of open sets $O_i$ and a closed set $W$ such that $\mathbb{R}^2 = W \cup \bigcup_i O_i$ and additionally, $|\ell \cap W| \leq s$ and for every $i$, $|X \cap O_i| \lesssim \frac{|X|}{s^2}$.
