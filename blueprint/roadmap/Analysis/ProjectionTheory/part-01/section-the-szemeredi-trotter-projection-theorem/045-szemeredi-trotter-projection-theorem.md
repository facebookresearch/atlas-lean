# Theorem (Szemeredi-Trotter projection theorem)

Let $X$ be a set of points in $\mathbb{R}^2$ and $D$ a set of directions in $S^1$. Define $S(X, D) = \max_{\theta \in D} |\pi_\theta(X)|$. Then $$|D| \leq \frac{S^2}{|X|} + 1.$$
