# Corollary (Section: Plunnecke inequality)

If $0 < s < t < 1$, then there exists $K = K(s, t)$ such that for all $A \subset \mathbb{F}_p$ with $|A| = p^s$, we have $|\operatorname{poly}_K(A)| \geq p^t$.
