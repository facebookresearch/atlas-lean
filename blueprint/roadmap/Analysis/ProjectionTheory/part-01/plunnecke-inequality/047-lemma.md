# Lemma (Section: Plunnecke inequality)

If $A \subset \mathbb{F}_p$, $|A| = p^s$ for $0 \leq s < 1$, then $|A^3 - A^3| \geq p^{s + \epsilon(s)}$ for some $\epsilon(s) > 0$.
