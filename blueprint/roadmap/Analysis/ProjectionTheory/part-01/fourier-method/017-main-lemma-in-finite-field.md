# Lemma (Main lemma in finite field)

If $\mathcal{L}$ is a set of lines in $\mathbb{F}_q^2$, write $f = \sum_{L \in \mathcal{L}} 1_L(x)$. Then $f = f_0 + f_h$ so $\operatorname{supp} \hat{f}_0 = \{0\}$, $\operatorname{supp} \hat{f}_h = \{0\}^c$. Then $f_0$ is a constant function, $\|f_0\|_2^2 = |\mathcal{L}|^2$, and $\|f_h\|_2^2 = |\mathcal{L}| q$.
