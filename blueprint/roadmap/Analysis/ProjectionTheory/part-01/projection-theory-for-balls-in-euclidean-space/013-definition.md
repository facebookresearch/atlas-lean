# Definition (Section: Projection theory for balls in Euclidean space)

We say that $X$ has Hausdorff spacing if it has $\alpha$-dimension spacing for some $\alpha$. Another way to say this is that $N_{R^\beta}(X) \lesssim |X|^\beta$ for any $0 \leq \beta \leq 1$.
