# Corollary (Double Counting Real Version)

If SETUP, and $X$, $D$ have Hausdorff spacing, then $$|D| \lesssim \log R \left(|S| + \frac{|S|}{|X|} |D|\right) \Rightarrow (S \sim X \text{ or } |D| \lesssim S).$$
