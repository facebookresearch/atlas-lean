# Column bounds for the conjugate-transpose matrix in Schur's test

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$ and let $a = (a_{ij})_{i, j \in \mathbb{N}}$ be an infinite matrix with entries in $\mathbb{K}$ such that $\sum_j |a_{ij}| \le R$ for every $i$, where a divergent series is given the value $0$. Then for every $j$, the column sum of the conjugate transpose satisfies $\sum_i |\overline{a_{ji}}| \le R$.
