# Row bound of a Schur matrix is nonnegative

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$, let $a = (a_{ij})_{i, j \in \mathbb{N}}$ be an infinite matrix with entries in $\mathbb{K}$ and let $R \in \mathbb{R}$ satisfy $\sum_j |a_{ij}| \le R$ for every $i$, where a divergent series is given the value $0$. Then $R \ge 0$.
