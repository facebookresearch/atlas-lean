# Schur's test for square Euclidean continuous linear maps

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$, let $n$ be a finite index set and let $A = (A_{ij})_{i, j \in n}$ be a square matrix with entries in $\mathbb{K}$. Let $R, C \ge 0$ be such that $\sum_j |A_{ij}| \le R$ for every row $i$ and $\sum_i |A_{ij}| \le C$ for every column $j$. Then the operator norm of $x \mapsto Ax$ on $\mathbb{K}^n$ with its Euclidean norm is at most $\sqrt{RC}$.
