# Schur's test for the $\ell^2$ operator norm of a matrix

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$, let $m$ and $n$ be finite index sets and let $A = (A_{ij})_{i \in m, j \in n}$ be a matrix with entries in $\mathbb{K}$. Let $R, C \ge 0$ be such that $\sum_j |A_{ij}| \le R$ for every row $i$ and $\sum_i |A_{ij}| \le C$ for every column $j$. Then the $\ell^2$ operator norm of $A$, its norm as an operator from $\mathbb{K}^n$ to $\mathbb{K}^m$ with their Euclidean norms, satisfies $\|A\| \le \sqrt{RC}$.
