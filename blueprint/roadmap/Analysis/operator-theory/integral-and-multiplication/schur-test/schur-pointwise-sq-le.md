# Per-row estimate in Schur's test

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$, let $m$ be an index set and $n$ a finite index set, and let $A = (A_{ij})_{i \in m, j \in n}$ be a matrix with entries in $\mathbb{K}$ whose row sums satisfy $\sum_{j} |A_{ij}| \le R$ for every $i \in m$. Then for every $x \in \mathbb{K}^n$ and every $i \in m$,

$$
|(Ax)_i|^2 \le R \sum_{j \in n} |A_{ij}|\, |x_j|^2.
$$
