# Norm estimate in Schur's test

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$, let $m$ and $n$ be finite index sets and let $A = (A_{ij})_{i \in m, j \in n}$ be a matrix with entries in $\mathbb{K}$. Let $R, C \ge 0$ be such that $\sum_j |A_{ij}| \le R$ for every row $i$ and $\sum_i |A_{ij}| \le C$ for every column $j$. Then, for the Euclidean norms on $\mathbb{K}^n$ and $\mathbb{K}^m$, $\|Ax\| \le \sqrt{RC}\, \|x\|$ for every $x \in \mathbb{K}^n$.
