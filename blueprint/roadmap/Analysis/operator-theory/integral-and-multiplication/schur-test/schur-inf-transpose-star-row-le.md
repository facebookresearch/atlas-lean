# Row bounds for the conjugate-transpose Schur matrix

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$ and let $a = (a_{ij})_{i, j \in \mathbb{N}}$ be an infinite matrix with entries in $\mathbb{K}$ such that $\sum_i |a_{ij}| \le C$ for every $j$, where a divergent series is given the value $0$. Then for every $i$, the row sum of the conjugate transpose satisfies $\sum_j |\overline{a_{ji}}| \le C$.
