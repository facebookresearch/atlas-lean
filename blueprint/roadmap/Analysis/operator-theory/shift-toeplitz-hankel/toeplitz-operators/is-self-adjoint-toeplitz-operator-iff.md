# Characterization of self-adjoint Toeplitz operators

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$ and let $a : \mathbb{Z} \to \mathbb{K}$ satisfy $\sum_{k} |a_k| < \infty$. The [Toeplitz operator](toeplitz-operator.md) $T_a$ is self-adjoint if and only if $\overline{a_{-k}} = a_k$ for every $k \in \mathbb{Z}$.
