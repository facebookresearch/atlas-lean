# Hankel operator with real symbol is self-adjoint

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$ and let $a : \mathbb{N} \to \mathbb{K}$ satisfy $\sum_{k} |a_k| < \infty$. If $\overline{a_k} = a_k$ for every $k$ (the symbol is real), then the [Hankel operator](hankel-operator.md) $H_a$ is self-adjoint.
