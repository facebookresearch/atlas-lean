# Composition operator as a linear map

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$ and let $\psi : \mathbb{N} \to \mathbb{N}$ have [fibers bounded](has-bounded-fibers.md) by some $M \in \mathbb{N}$. The composition operator of $\psi$, as a linear map, is $C_\psi : \ell^2(\mathbb{N}, \mathbb{K}) \to \ell^2(\mathbb{N}, \mathbb{K})$, $C_\psi x = x \circ \psi$.
