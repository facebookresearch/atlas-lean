# Composition operator is injective iff its symbol is surjective

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$ and let $\psi : \mathbb{N} \to \mathbb{N}$ have [fibers bounded](has-bounded-fibers.md) by some $M \in \mathbb{N}$. The [composition operator](comp-clm.md) $C_\psi$ is injective if and only if $\psi$ is surjective: a value $m$ not taken by $\psi$ gives the basis vector $e_m$ in the kernel, and when $\psi$ is surjective every coordinate of $x$ can be read off from $C_\psi x$.
