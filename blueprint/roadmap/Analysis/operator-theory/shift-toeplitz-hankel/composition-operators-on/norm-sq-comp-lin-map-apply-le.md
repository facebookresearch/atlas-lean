# Squared-norm bound for the composition linear map

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$ and let $\psi : \mathbb{N} \to \mathbb{N}$ have [fibers bounded](has-bounded-fibers.md) by some $M \in \mathbb{N}$, with [fiber supremum](fiber-sup.md) $s_\psi$. The [composition linear map](comp-lin-map.md) satisfies $\|C_\psi x\|^2 \le s_\psi \|x\|^2$ for every $x \in \ell^2(\mathbb{N}, \mathbb{K})$.
