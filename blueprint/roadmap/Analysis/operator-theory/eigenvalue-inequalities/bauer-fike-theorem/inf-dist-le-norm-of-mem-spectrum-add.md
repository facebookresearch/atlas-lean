# Bauer–Fike theorem for normal operators

For a normal operator $A$ on a complex Hilbert space and any bounded perturbation $E$, every point of the spectrum of $A + E$ lies within $\|E\|$ of the spectrum of $A$. For a normal matrix this is the Bauer–Fike theorem with a unitary eigenvector matrix $V$, so that $\kappa_2(V) = 1$.
