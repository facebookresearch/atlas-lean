# Row vector of a Hilbert–Schmidt matrix

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$, let $a = (a_{ij})$ be a [Hilbert–Schmidt matrix](is-hilbert-schmidt.md) and $i \in \mathbb{N}$. The (conjugated) row vector of index $i$ is the element $r_i = (\overline{a_{ij}})_{j \in \mathbb{N}}$ of $\ell^2(\mathbb{N}, \mathbb{K})$.
