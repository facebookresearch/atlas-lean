# Diagonal matrix with square-summable diagonal is Hilbert–Schmidt

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$. If $d : \mathbb{N} \to \mathbb{K}$ satisfies $\sum_i |d_i|^2 < \infty$, then the [diagonal matrix](hs-diagonal.md) $\operatorname{diag}(d)$ is [Hilbert–Schmidt](is-hilbert-schmidt.md).
