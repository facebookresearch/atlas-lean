# Hilbert–Schmidt matrix

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$. An infinite matrix $a = (a_{ij})_{i, j \in \mathbb{N}}$ with entries in $\mathbb{K}$ is Hilbert–Schmidt if the family $(|a_{ij}|^2)_{(i, j) \in \mathbb{N} \times \mathbb{N}}$ is summable, that is, $\sum_{i, j} |a_{ij}|^2 < \infty$.
