# Fredholm index is constant along a globally continuous path

Let $\mathbb{k}$ be a complete nontrivially normed field, let $E$ be a Banach space and $F$ a normed space over $\mathbb{k}$. If $\gamma : \mathbb{R} \to L(E, F)$ is continuous and $\gamma(t)$ is a Fredholm operator for every $t \in [0, 1]$, then $\operatorname{ind} \gamma(0) = \operatorname{ind} \gamma(1)$.
