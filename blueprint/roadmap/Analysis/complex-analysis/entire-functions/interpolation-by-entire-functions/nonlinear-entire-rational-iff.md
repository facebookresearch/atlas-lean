# Erdős Problem 226 on entire functions preserving the rationals

Erdős Problem 226: there is an entire function $f : \mathbb{C} \to \mathbb{C}$, not of the form $z \mapsto az + b$ with $a, b \in \mathbb{C}$, such that for every real $x$, $x$ is rational if and only if $f(x)$ is a rational number (in particular real). Only real arguments $x$ are constrained.

Its resolution: [A transcendental entire function preserving rationality on the real line](nonlinear-entire-rational-iff-holds.md).
