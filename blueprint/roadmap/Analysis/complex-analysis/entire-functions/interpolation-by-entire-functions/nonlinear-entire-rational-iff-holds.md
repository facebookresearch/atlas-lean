# A transcendental entire function preserving exactly the rationals

Barth and Schneider proved that for countable dense sets `A, B ⊆ ℝ` there is a
transcendental entire function `f` with `f(z) ∈ B` exactly when `z ∈ A`; `A = B = ℚ` answers the
question. erdosproblems.com/226 lists the problem as proved.

## Sources

- T. F. Bloom, Erdős Problems, Problem #226, https://www.erdosproblems.com/226 (status PROVED (LEAN)); resolution: K. F. Barth and W. J. Schneider, Entire functions mapping countable dense subsets of the reals onto each other monotonically, J. London Math. Soc. (2) 2 (1970), 620-626, erdosproblems.com/226: for countable dense A, B ⊆ ℝ there is a transcendental entire f with f(z) ∈ B if and only if z ∈ A, https://doi.org/10.1112/jlms/2.part_4.620.
