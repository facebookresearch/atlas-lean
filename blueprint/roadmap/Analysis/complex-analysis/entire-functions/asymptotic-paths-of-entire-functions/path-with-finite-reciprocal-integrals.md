# Erdős Problem 515 on paths with finite reciprocal integrals

Erdős Problem 515: for every entire `f` that is not a polynomial there is a locally rectifiable
path to `∞`, parametrized by arc length `γ : [0, ∞) → ℂ`, with
`∫_γ |f(z)| ^ (-λ) |dz| = ∫₀^∞ |f(γ t)| ^ (-λ) dt < ∞` for every `λ > 0`.

Its resolution: [Lewis–Rossi–Weitsman theorem on paths with finite reciprocal integrals](path-with-finite-reciprocal-integrals-ho.md).
