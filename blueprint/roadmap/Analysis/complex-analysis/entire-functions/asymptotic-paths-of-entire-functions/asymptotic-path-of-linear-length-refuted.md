# Entire functions of finite order without asymptotic paths of linear length

This settles [Erdős Problem 1115 on asymptotic paths of linear length](asymptotic-path-of-linear-length.md) in the negative: its statement is false.

Gol'dberg and Erëmenko proved: for each function $\varphi(r) \to \infty$ there exists a nonconstant entire function $f$ with $\log M(r) \ll \varphi(r) (\log r)^2$, where $M(r)$ is the maximum of $|f|$ on $|z| = r$, such that no path $\Gamma$ on which $f(z) \to \infty$ has $\ell(r) \ll r$. With a slowly growing $\varphi$, for instance $\varphi(r) = \log r$, such an $f$ has order $0$, so it is a nonconstant entire function of finite order and a counterexample to the linked statement; they also construct such functions of any prescribed finite order. This answers Hayman's question; Hayman had proved that a path with $\ell(r) = r$ exists when $\log M(r) \ll (\log r)^2$. erdosproblems.com/1115 records the disproof.
