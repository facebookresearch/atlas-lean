# Linden's entire function permuting the integers

This settles [Rubel's question on entire functions permuting the integers](integer-permutation-type-pi.md) in the negative: its statement is false.

Linden's function `f(z) = z + 4 cos(π(z - 2)/3)`, recorded in the list's Update
2.43, is transcendental entire, maps the integers injectively onto themselves, and has order `1`,
type `π/3 < π`.

## Sources

- W. K. Hayman and E. F. Lingham, Research Problems in Function Theory, Fiftieth Anniversary Edition (2019), arXiv:1809.07200, Problem 2.43 (L. A. Rubel); resolution: W. K. Hayman and E. F. Lingham, Research Problems in Function Theory, Fiftieth Anniversary Edition (2019), arXiv:1809.07200, Update 2.43 (example of Linden), Update 2.43: f(z) = z + 4 cos(π(z - 2)/3) gives (i) an injective mapping of the integers onto themselves and (ii) an injective mapping of the positive integers onto themselves, and has type π/3 (the update also corrects Buck's bound in the problem text to log((3 + √5)/2)), https://arxiv.org/abs/1809.07200.
