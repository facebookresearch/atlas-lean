# Erdős Problem 1118 on superlevel sets of finite measure

Erdős Problem 1118, second question: for every nonconstant entire function $f$ and every real $c$, if $E(c) = \{z : |f(z)| > c\}$ has finite Lebesgue measure, then $E(c')$ has finite measure for some real $c' < c$.

Its resolution: [Gol'dberg's counterexample on superlevel sets of finite measure](finite-measure-superlevel-lowerable-refu.md).
