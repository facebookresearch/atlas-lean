# Parabolic Möbius transformations have zero discriminant

For a Möbius transformation $g$, given by an invertible complex $2 \times 2$ matrix up to scaling, $g$ is parabolic if and only if its discriminant $(\operatorname{tr} g)^2 - 4 \det g$ vanishes. Here “parabolic” includes the identity, which has discriminant zero and fixes every point, as well as the transformations with exactly one fixed point.
