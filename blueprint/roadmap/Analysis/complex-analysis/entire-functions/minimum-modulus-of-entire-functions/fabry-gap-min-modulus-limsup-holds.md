# Fuchs's theorem on the minimum modulus of Fabry gap series

Fuchs proved that for every `ε > 0`, `log m(r) > (1 - ε) log M(r)` holds
outside a set of `r` of logarithmic density `0`, so at arbitrarily large `r`.

## Sources

- T. F. Bloom, Erdős Problems, Problem #516, https://www.erdosproblems.com/516 (status PROVED (LEAN)); resolution: W. H. J. Fuchs, Proof of a conjecture of G. Pólya concerning gap series, Illinois J. Math. 7 (1963), 661-667, Theorem 1: if f = ∑ c_n z^\{λ_n\} is entire of finite order and the increasing exponents satisfy λ_n / n → ∞, then for every ε > 0, log L(r, f) > (1 - ε) log M(r, f) outside a set of r of logarithmic density 0 (L the minimum modulus); erdosproblems.com/516, https://doi.org/10.1215/ijm/1255645102.
