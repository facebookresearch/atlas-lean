# Hayman's lower bound for the limsup of b(r)

Let $b(r) = (r\,d/dr)^2 \log M(r, f)$ as defined on [Hayman's function b(r)](hayman-b.md), including its convention at radii where a derivative does not exist, where $M(r, f)$ is the maximum modulus of $f$ on $|z| \le r$. There is an absolute constant $A$ with $0.18 < A \le 1/4$ such that $\limsup_{r\to\infty} b(r) \ge A$ for every transcendental entire function $f$ (an entire function that is not a polynomial), the limsup being taken in the extended reals, so that it may be $+\infty$.
