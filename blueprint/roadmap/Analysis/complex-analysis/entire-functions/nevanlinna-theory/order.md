# Order of a meromorphic function

For $f : \mathbb{C} \to \mathbb{C}$, the order is

$$
\rho(f) = \limsup_{r \to \infty} \frac{\log T(r, f)}{\log r},
$$

with $T(r, f)$ the [Nevanlinna characteristic](nevanlinna-t.md). The quotient is computed in $\mathbb{R}$ with $\log 0 = 0$ and $x / 0 = 0$, and the limsup is taken in the extended reals, so $\rho(f)$ may be $+\infty$. For a nonconstant meromorphic $f$, $T(r, f) \to \infty$, so these conventions affect only bounded $r$ and $\rho(f)$ is the classical order; for a constant function (for instance $f = 0$) the value is fixed by the conventions.
