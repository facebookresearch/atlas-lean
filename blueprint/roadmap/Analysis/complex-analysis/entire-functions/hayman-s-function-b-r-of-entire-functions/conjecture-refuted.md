# Kjellberg's refutation of the lower bound 1/4 for b(r)

This settles [Hayman's conjectured lower bound 1/4 for the limsup of b(r)](conjecture.md) in the negative: its statement is false.

Hayman and Lingham's Update 2.17 reports that Kjellberg disproved the conjectured constant $1/4$: the best constant $A$ in Hayman's bound $\limsup_{r\to\infty} b(r) \ge A$, with $b(r) = (r\,d/dr)^2 \log M(r, f)$ as on [Hayman's function b(r)](hayman-b.md), lies strictly between $0.24$ and $0.248$. Since the best constant is below $0.248$, some transcendental entire function $f$ has $\limsup_{r\to\infty} b(r) < 0.248 < 1/4$, which contradicts the linked statement.

## Sources

- W. K. Hayman and E. F. Lingham, Research Problems in Function Theory (Fiftieth Anniversary Edition), arXiv:1809.07200v2, Problem 2.17 and Update 2.17, https://arxiv.org/abs/1809.07200v2.
