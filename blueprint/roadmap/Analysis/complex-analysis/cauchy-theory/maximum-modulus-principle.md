# A holomorphic map into a strictly convex space is constant if its norm attains a maximum on a connected open set

Let $E$ be a normed vector space over $\mathbb{C}$, and let $F$ be a normed vector space over $\mathbb{C}$ that is strictly convex as a real normed space: for all distinct $x, y \in F$ with $\|x\| = \|y\| = 1$ and all real $t$ with $0 < t < 1$, $\|tx + (1 - t)y\| < 1$. For example, $E = F = \mathbb{C}$. Let $U \subseteq E$ be an open set that is preconnected, that is, not the union of two disjoint nonempty sets that are open in $U$, and let $f\colon E \to F$ be complex differentiable at every point of $U$. If $c \in U$ and $\|f(z)\| \le \|f(c)\|$ for every $z \in U$, then $f(z) = f(c)$ for every $z \in U$: $f$ is constant on $U$. Since $U$ contains $c$, it is nonempty, so it is connected. For $E = F = \mathbb{C}$ this is the maximum modulus principle: if $f$ is holomorphic on a connected open set $\Omega \subseteq \mathbb{C}$ and there is $z_0 \in \Omega$ with $|f(z)| \le |f(z_0)|$ for all $z \in \Omega$, then $f$ is constant on $\Omega$.
