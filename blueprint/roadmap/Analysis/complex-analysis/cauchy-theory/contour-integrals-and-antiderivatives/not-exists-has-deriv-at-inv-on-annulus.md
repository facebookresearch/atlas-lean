# The reciprocal function has no antiderivative on an annulus

Let
$U = \{z \in \mathbb{C} : 1 < |z| < 2\}$. There is no function $F : \mathbb{C} \to \mathbb{C}$
that is complex differentiable at every $z \in U$ with $F'(z) = 1/z$.
