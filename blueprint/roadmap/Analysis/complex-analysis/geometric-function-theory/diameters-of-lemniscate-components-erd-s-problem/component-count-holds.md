# Sublevel sets of zⁿ - rⁿ with r > 1 have n components

For every real $r > 1$ and every natural number $n \ge 1$, the closed sublevel set $\{ z \in \mathbb{C} : |z^n - r^n| \le 1 \}$ has exactly $n$ connected components.
