# Some sublevel component has diameter above 2 - r when r ≤ 1

For every real $r$ with $0 < r \le 1$ and every monic polynomial $f \in \mathbb{C}[X]$ of degree at least $1$ all of whose roots satisfy $|z| \le r$, some connected component of the strict sublevel set $\{ z \in \mathbb{C} : |f(z)| < 1 \}$ has diameter strictly greater than $2 - r$. Diameters are taken in $[0, \infty]$.
