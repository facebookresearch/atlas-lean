# Connected components of a planar set

For a set $s \subseteq \mathbb{C}$, its family of connected components is

$$\{ C_s(z) : z \in s \},$$

where $C_s(z) \subseteq \mathbb{C}$ is the connected component of $z$ in $s$ (with the subspace topology), regarded as a subset of $\mathbb{C}$. The empty set has no components.
