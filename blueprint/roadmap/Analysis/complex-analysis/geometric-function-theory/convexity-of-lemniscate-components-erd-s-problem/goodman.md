# Goodman's non-convex sublevel set

The statement: the strict sublevel set

$$\Big\{ z \in \mathbb{C} : \big|(z^2 + 1)(z - 2)^2\big| < \frac{5^{3/2}}{4} \Big\}$$

has exactly $3$ connected components, and at least one of them is not convex.
