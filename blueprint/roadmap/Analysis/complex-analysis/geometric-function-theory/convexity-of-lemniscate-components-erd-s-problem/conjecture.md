# Convexity of components of polynomial sublevel sets

The statement: for every monic polynomial $f \in \mathbb{C}[X]$ with exactly $m$ distinct roots and every real $c > 0$, if the closed sublevel set $\{ z \in \mathbb{C} : |f(z)| \le c \}$ has exactly $m$ connected components, then every connected component of that set is convex.

The number of components is a natural-number count, taken to be $0$ for an infinite family.

## Sources

erdosproblems.com/1047, https://www.erdosproblems.com/1047. Disproved by Ch. Pommerenke (1961) and A. W. Goodman (1966).
