# Pommerenke's non-convex sublevel sets

The statement: for every sufficiently large natural number $k$, writing

$$A_k = \Big(1 + \frac{1}{k}\Big)\, k^{1/(k+1)},$$

there exists $\delta > 0$ such that for every real $a$ with $A_k < a < A_k + \delta$, the set $\{ z \in \mathbb{C} : |z^k (z - a)| \le 1 \}$ has exactly $2$ connected components and its connected component containing $0$ is not convex.
