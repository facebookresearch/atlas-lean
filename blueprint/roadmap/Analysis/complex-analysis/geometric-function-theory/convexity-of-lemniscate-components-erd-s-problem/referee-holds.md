# Sublevel set of z(z⁵ - 1) has a non-convex component

The strict sublevel set $\{ z \in \mathbb{C} : |z (z^5 - 1)| < 5 \cdot 6^{-6/5} \}$ has exactly $6$ connected components, and at least one of them is not convex.

## Sources
