# Sublevel sets of z^k(z - a) with a non-convex component

For every sufficiently large natural number $k$ there exists $\delta > 0$ such that for every real $a$ with

$$\Big(1 + \frac{1}{k}\Big) k^{1/(k+1)} < a < \Big(1 + \frac{1}{k}\Big) k^{1/(k+1)} + \delta,$$

the set $\{ z \in \mathbb{C} : |z^k (z - a)| \le 1 \}$ has exactly $2$ connected components and its component containing $0$ is not convex.
