# Goodman's sublevel set has a non-convex component

The strict sublevel set $\{ z \in \mathbb{C} : |(z^2 + 1)(z - 2)^2| < 5^{3/2}/4 \}$ has exactly $3$ connected components, and at least one of them is not convex.
