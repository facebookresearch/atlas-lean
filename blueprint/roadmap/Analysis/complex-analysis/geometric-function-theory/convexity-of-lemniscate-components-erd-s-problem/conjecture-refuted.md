# Polynomial sublevel sets can have non-convex components

There exist a monic polynomial $f \in \mathbb{C}[X]$ with exactly $m$ distinct roots and a real $c > 0$ such that the closed sublevel set $\{ z \in \mathbb{C} : |f(z)| \le c \}$ has exactly $m$ connected components and at least one of them is not convex. This is the negation of the sublevel-set convexity conjecture.
