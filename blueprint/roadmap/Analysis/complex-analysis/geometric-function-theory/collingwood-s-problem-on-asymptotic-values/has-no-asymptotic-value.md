# Functions without asymptotic values

A function $f$ with pole set $P$ has no asymptotic value in the sense of Problem 5.19 when it has neither a [finite asymptotic value](is-finite-asymptotic-value.md) nor an [infinite asymptotic value](has-infinite-asymptotic-value.md). That is, there is no continuous curve $\gamma : \mathbb{R} \to D \setminus P$ in the open unit disc $D$, avoiding the poles and with $\gamma(t) \to \zeta$ as $t \to \infty$ for some $\zeta$ on the unit circle, along which either $f(\gamma(t)) \to w$ for some $w \in \mathbb{C}$ or $|f(\gamma(t))| \to \infty$.
