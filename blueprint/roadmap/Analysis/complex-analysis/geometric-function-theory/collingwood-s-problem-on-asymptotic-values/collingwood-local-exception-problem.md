# Collingwood's problem on locally exceptional values

The statement that there is a function meromorphic in the open unit disc $D$ that has no asymptotic value, takes every value infinitely often, has every point of the unit circle $T$ as a Picard point, and has a locally exceptional value at some point of $T$. This is Problem 5.19 of E. F. Collingwood in Hayman and Lingham's list, which asks whether such a function exists.
