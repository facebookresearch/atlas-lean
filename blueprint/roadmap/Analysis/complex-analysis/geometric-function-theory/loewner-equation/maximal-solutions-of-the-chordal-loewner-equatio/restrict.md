# Restriction of a Loewner forward solution

Let $W : \mathbb{R} \to \mathbb{R}$, $z \in \mathbb{C}$ and $S \le T$. If $\gamma$ is a [forward solution](loewner-forward-solution.md) of the Loewner equation driven by $W$ from $z$ on $[0, T]$, then the same curve $\gamma$ is a forward solution from $z$ on $[0, S]$.
