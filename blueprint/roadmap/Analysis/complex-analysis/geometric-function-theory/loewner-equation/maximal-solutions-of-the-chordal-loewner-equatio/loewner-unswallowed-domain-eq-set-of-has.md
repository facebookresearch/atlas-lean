# Unswallowed domain equals the forward-extension domain

Let $\mathbb{H}$ be the upper half-plane, $W : \mathbb{R} \to \mathbb{R}$ and $t \ge 0$. The [unswallowed domain](loewner-unswallowed-domain.md) $H_t$, defined through lifetimes, is exactly the set of $z \in \mathbb{H}$ whose Loewner trajectory extends in $\mathbb{H}$ beyond $t$: those for which there are $T > t$ and a curve $\gamma$ with $\gamma(0) = z$ that stays in $\mathbb{H}$ on $[0, T]$ and solves $\gamma'(s) = 2/(\gamma(s) - W(s))$ on $[0, T]$ (one-sided derivatives at the endpoints).
