# Compact hull in the upper half-plane

Let $\mathbb{H} = \{z \in \mathbb{C} : \operatorname{Im} z > 0\}$. A set $K \subseteq \mathbb{C}$ is a compact $\mathbb{H}$-hull if $K \subseteq \mathbb{H}$, $K$ is bounded, $K = C \cap \mathbb{H}$ for some closed set $C \subseteq \mathbb{C}$ (so $K$ is relatively closed in $\mathbb{H}$), and the complement $\mathbb{H} \setminus K$ is open and simply connected.
