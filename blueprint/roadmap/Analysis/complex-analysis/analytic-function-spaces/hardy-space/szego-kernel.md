# Szegő kernel of the Hardy space

In the Taylor-coefficient model of the Hardy space $H^2$ of the unit disc, a sequence $a \in \ell^2(\mathbb{N}, \mathbb{C})$ stands for the function $f_a(z) = \sum_n a_n z^n$, whose $H^2$ norm is $\|a\|$. For $z \in \mathbb{C}$ with $|z| < 1$, the **Szegő kernel** at $z$ is the element $k_z$ of $\ell^2(\mathbb{N}, \mathbb{C})$ with coefficients $(k_z)_n = \bar z^n$.
