# Dirichlet kernel norm is bounded by the Szegő kernel norm

For every $z \in \mathbb{C}$ with $|z| < 1$, the [Dirichlet kernel](dirichlet-kernel.md) satisfies

$$
\|k_z\|^2 \le \frac{1}{1 - |z|^2},
$$

the right-hand side being the squared norm of the Szegő kernel of the Hardy space. For $z \ne 0$ this is $\log x \le x - 1$ at $x = (1 - |z|^2)^{-1}$.
