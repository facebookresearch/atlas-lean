# Inner products of rescaled Bergman monomials are Kronecker deltas

For all $m, n \in \mathbb{N}$, the standard basis vectors $e_m, e_n$ of $\ell^2(\mathbb{N}, \mathbb{C})$, which represent the [rescaled monomials](bergman-monomial.md), satisfy $\langle e_m, e_n \rangle = 1$ if $m = n$ and $0$ otherwise.
