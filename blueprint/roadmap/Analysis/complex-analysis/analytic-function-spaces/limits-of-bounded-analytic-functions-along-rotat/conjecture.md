# Bounded analytic functions without limits along all rotated non-tangential arcs (original formulation)

The statement, in the original formulation of Problem 5.76 as described in Update 5.76: for every non-tangential arc $\gamma$ at $1$ there is a bounded analytic function $g$ on the unit disc such that, for every real angle $\theta$, the limit $\lim g(w)$ as $w \to e^{i\theta}$ with $w \in e^{i\theta}\gamma \setminus \{e^{i\theta}\}$ does not exist in $\mathbb{C}$.

A non-tangential arc at $1$ is an injective continuous image of $[0,1]$ starting at $1$, otherwise inside the open unit disc, and contained in a Stolz angle $|1 - z| \le K(1 - |z|)$.

Fatou's theorem refutes this original formulation: [every bounded analytic function has a limit along some rotation of a non-tangential arc](fatou-obstruction-holds.md). The corrected Problem 5.76, for arcs that fail to be non-tangential, is a different question and is not stated here.
