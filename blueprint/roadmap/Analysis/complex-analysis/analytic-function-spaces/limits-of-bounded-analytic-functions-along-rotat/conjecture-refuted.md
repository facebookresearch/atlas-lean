# For some non-tangential arc, every bounded analytic function has a limit along a rotation of it

There is a non-tangential arc $\gamma$ at $1$ (an injective continuous image of $[0,1]$ starting at $1$, otherwise in the open unit disc, inside a Stolz angle $|1 - z| \le K(1 - |z|)$ with $K > 0$) such that for every bounded analytic function $g$ on the unit disc there is a real angle $\theta$ for which the limit $\lim g(w)$ as $w \to e^{i\theta}$ with $w \in e^{i\theta}\gamma \setminus \{e^{i\theta}\}$ exists in $\mathbb{C}$. This is the negation of the [original formulation](conjecture.md) of Problem 5.76, as described in Update 5.76; it does not concern the corrected problem for arcs that fail to be non-tangential.
