# Bounded analytic function on the unit disc

A function $g : \mathbb{C} \to \mathbb{C}$ is bounded analytic on the unit disc when it is complex differentiable at every point of the open unit disc $\mathbb{D} = \{ z : |z| < 1 \}$ and there is a real $M$ with $|g(z)| \le M$ for all $z \in \mathbb{D}$.
