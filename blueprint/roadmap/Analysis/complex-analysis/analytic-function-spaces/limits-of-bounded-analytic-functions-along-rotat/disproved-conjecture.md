# Negation of the original rotated-arc statement

The statement, negating the [original formulation](conjecture.md) of Problem 5.76 as described in Update 5.76: there is a non-tangential arc $\gamma$ at $1$ such that for every bounded analytic function $g$ on the unit disc there is a real angle $\theta$ for which the limit $\lim g(w)$ as $w \to e^{i\theta}$ with $w \in e^{i\theta}\gamma \setminus \{e^{i\theta}\}$ exists in $\mathbb{C}$.

## Sources

W. K. Hayman and E. F. Lingham, *Research Problems in Function Theory*, Fiftieth Anniversary Edition, Springer (2019), Update 5.76, which says that the original formulation of Problem 5.76 erroneously assumed a non-tangential arc (in that edition Problem 5.76 assumes an arc that fails to be non-tangential); E. F. Collingwood and A. J. Lohwater, *The Theory of Cluster Sets*, Cambridge Univ. Press (1966).
