# Nikolski's critical constant 1/2 for the analytic Wiener algebra

Nikolski proved that for the analytic Wiener algebra `W₊` of absolutely convergent
Taylor series the critical constant is `δ₁(W₊, 𝔻) = 1/2`: if `‖f‖_{W₊} ≤ 1` and `|f| ≥ δ` on the
disc, then `‖f⁻¹‖_{W₊} ≤ 1/(2δ - 1)` for `δ > 1/2`, while no bound exists for `δ ≤ 1/2`, confirming
Shapiro's guess (Katznelson had the unbounded range `δ < 1/2`).

## Sources

- W. K. Hayman and E. F. Lingham, Research Problems in Function Theory, Fiftieth Anniversary Edition (2019), arXiv:1809.07200, Problem 5.42 (H. S. Shapiro); resolution: N. Nikolski, In search of the invisible spectrum, Ann. Inst. Fourier (Grenoble) 49 (1999), no. 6, 1925-1998, Theorem B with Section 2.3.1 (S = ℤ₊, whose bounded characters fill the closed disc 𝔻): δ₁(W₊, 𝔻) = 1/2 and c₁(δ, W₊, 𝔻) = 1/(2δ - 1) for 1/2 < δ ≤ 1, where by (0.2.5) c₁(δ) = sup\{‖f⁻¹‖ : f ∈ W₊, δ ≤ |f(z)| for z ∈ 𝔻, ‖f‖ ≤ 1\} and δ₁ = inf\{δ : c₁(δ) < ∞\}; Subsection 3.3 shows c₁(δ) = ∞ for δ ≤ 1/2, https://doi.org/10.5802/aif.1743.
