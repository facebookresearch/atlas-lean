# Kahane's ultraflat polynomials refute Erdős Problem 230

This settles [Erdős Problem 230 on the supremum of unimodular polynomials](unimodular-polynomial-sup-norm-gap.md) in the negative: its statement is false.

Kahane constructed ultraflat polynomials with unimodular coefficients and `|P(z)| =
(1 + o(1)) √n` uniformly on `|z| = 1`, so no `c > 0` works; erdosproblems.com/230 lists the problem
as disproved.
