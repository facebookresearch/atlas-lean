# Lemniscates with many large components

This settles [Erdős Problem 511 on large components of lemniscates](bounded-large-lemniscate-components.md) in the negative: its statement is false.

Pommerenke (and independently Huang) proved that for every `0 < d < 4` and `k ≥ 1`
some monic polynomial has `{|f| ≤ 1}` with at least `k` connected components of diameter `≥ d`; any
`d ∈ (c, 4)` refutes the bound for `c ∈ (1, 4)`. Pólya showed no component has diameter `> 4`.
