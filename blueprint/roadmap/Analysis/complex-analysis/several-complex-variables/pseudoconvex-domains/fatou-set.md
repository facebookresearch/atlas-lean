# Bounded-iterate Fatou set of a self-map of ℂ²

For a map $F : \mathbb{C}^2 \to \mathbb{C}^2$, this is the set of points $z$ having a neighborhood $U$ and a bound $M$ with $\|F^{k}(w)\| \le M$ for every $k \ge 0$ and every $w \in U$: the points near which the forward iterates of $F$ are uniformly bounded.

This is the convention of the SCV Problem List, Problem 10.2.2 (E. Bedford), which, for a polynomial automorphism of $\mathbb{C}^2$, calls the set of points where the forward iterates are locally bounded the Fatou set. It is not the general definition of the Fatou set as the set where the iterates form a normal family. For the translation $(z, w) \mapsto (z + 1, w)$ the bounded-iterate set is empty, although the iterates converge locally uniformly to a point at infinity in projective space and so form a normal family there.
