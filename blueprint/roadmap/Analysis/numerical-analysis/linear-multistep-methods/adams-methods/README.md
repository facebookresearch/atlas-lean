# Adams methods

Adams methods have first characteristic polynomial $z^k - z^{k-1}$: they advance the solution by integrating a polynomial interpolant of past values of $f$ over one step. The explicit Adams–Bashforth and implicit Adams–Moulton families are zero-stable for every $k$, with orders $k$ and $k + 1$; the two-step Adams–Bashforth method is the simplest explicit multistep method of order two.
