# Implications between the stability notions for stiff problems

For linear multistep methods,

$$\text{A-stability} \Rightarrow \text{stiff stability} \Rightarrow \text{A}(\alpha)\text{-stability} \Rightarrow \text{A}(0)\text{-stability} \Rightarrow \text{A}_0\text{-stability},$$

where a [stiffly stable](stiff-stability.md) method with constants $a$ and $c$ is [A(α)-stable](a-alpha-stability.md) with $\alpha = \arctan(c/a)$.
