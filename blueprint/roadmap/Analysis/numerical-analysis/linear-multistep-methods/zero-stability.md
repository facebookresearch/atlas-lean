# Zero-stability

A [linear $k$-step method](linear-multistep-method.md) is *zero-stable* for the differential equation $y' = f(x, y)$ on $[x_0, X_M]$ if there are constants $K$ and $h_0 > 0$ such that, for every step $0 < h \le h_0$ and any two sequences $(y_n)$ and $(\hat y_n)$ generated by the method with the same $f$ and $h$ but from starting values $y_0, \dots, y_{k-1}$ and $\hat y_0, \dots, \hat y_{k-1}$ respectively,

$$|y_n - \hat y_n| \le K \max\{|y_0 - \hat y_0|, |y_1 - \hat y_1|, \dots, |y_{k-1} - \hat y_{k-1}|\}$$

for every $n$ with $x_n = x_0 + nh \le X_M$. Small perturbations of the starting values thus cause uniformly small perturbations of the computed values as $h \to 0$.
