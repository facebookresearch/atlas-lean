# Zero-stability

A [linear $k$-step method](linear-multistep-method.md) is *zero-stable* for the differential equation $y' = f(x, y)$ on $[x_0, X_M]$, whose right-hand side $f$ is continuous on $[x_0, X_M] \times \mathbb{R}$ and satisfies a Lipschitz condition $|f(x, y) - f(x, z)| \le L|y - z|$ for all $x \in [x_0, X_M]$ and all real $y, z$, if there are constants $K$ and $h_0 > 0$, with $h_0 |\beta_k| L < |\alpha_k|$, such that, for every step $0 < h \le h_0$ and any two sequences $(y_n)$ and $(\hat y_n)$ generated by the method with the same $f$ and $h$ but from starting values $y_0, \dots, y_{k-1}$ and $\hat y_0, \dots, \hat y_{k-1}$ respectively,

$$|y_n - \hat y_n| \le K \max\{|y_0 - \hat y_0|, |y_1 - \hat y_1|, \dots, |y_{k-1} - \hat y_{k-1}|\}$$

for every $n$ with $x_n = x_0 + nh \le X_M$. For such steps each implicit equation for $y_{n+k}$ has exactly one solution, so the sequences are determined by their starting values. Small perturbations of the starting values thus cause uniformly small perturbations of the computed values as $h \to 0$.

## Sources

- E. Süli, *Numerical Solution of Ordinary Differential Equations*, lecture notes, Mathematical Institute, University of Oxford, version of 2 March 2022, Section 3.2, Definition 4 (inequality (43), required "for $x_n \le X_M$, and as $h$ tends to $0$", read here as for all sufficiently small $h$). The notes state the Lipschitz condition on a rectangle $|y - y_0| \le Y_M$. For an implicit method that does not control the computed values, which may leave the rectangle: implicit Euler for $y' = y^2$, $y(0) = 0$, has besides $y_n = 0$ the solution with $y_n = 0$ for $n < N$ and $y_N = 1/h$. So a global Lipschitz condition is used here, with steps $h|\beta_k| L < |\alpha_k|$ for which each implicit equation has exactly one solution. <https://people.maths.ox.ac.uk/suli/nsodes.pdf>
