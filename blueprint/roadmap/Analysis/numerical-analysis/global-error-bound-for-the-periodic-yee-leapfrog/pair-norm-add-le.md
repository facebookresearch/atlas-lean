# The pair norm is subadditive

For $h \in \mathbb{R}$ and $u, v \in \mathbb{R}^N$, the squared weighted grid norm is $\|w\|_h^2 = h \sum_j w_j^2$ and the pair norm is $\|(u, v)\|_h = \sqrt{\|u\|_h^2 + \|v\|_h^2}$ (the Euclidean pair norm, with $\sqrt{\cdot} = 0$ on negative numbers). For $h \ge 0$, $\|(u + u', v + v')\|_h \le \|(u, v)\|_h + \|(u', v')\|_h$.
