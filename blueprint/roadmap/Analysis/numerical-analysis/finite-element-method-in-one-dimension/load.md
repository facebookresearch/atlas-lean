# Load vector of the P1 method

Let $0 = x_0 < \dots < x_n = 1$ be a partition of $[0, 1]$ with [hat functions](hat.md)
$\varphi_j$, and $f : \mathbb{R} \to \mathbb{R}$. The load vector has entries
$F_j = \int_0^1 f(x)\, \varphi_j(x)\, dx$, taken to be $0$ when $f \varphi_j$ is not integrable on
$(0, 1)$; for continuous $f$ it is always integrable.
