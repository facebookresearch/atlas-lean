# Classical solution of the Dirichlet problem $-u'' = f$

A function $u : \mathbb{R} \to \mathbb{R}$ is a classical solution of $-u'' = f$ on $(0, 1)$ with
$u(0) = u(1) = 0$ if $u$ is $C^2$ on $\mathbb{R}$, $f : \mathbb{R} \to \mathbb{R}$ is continuous,
$u(0) = u(1) = 0$, and $-u''(x) = f(x)$ for every $x \in (0, 1)$. Asking $u$ to be $C^2$ on all of
$\mathbb{R}$ is no loss for the interval problem, since a $C^2$ function on $[0, 1]$ extends. The
equation is stated on the open interval, as in the Dirichlet problem; with $f$ continuous it then
holds on $[0, 1]$ by continuity ([the closed interval](eq-icc.md)).
