# P1 finite element space with zero boundary values

Let $0 = x_0 < \dots < x_n = 1$ be a partition of $[0, 1]$. The P1 finite element space $V_h$ is the
image, under $d \mapsto p_d$, of the [nodal vectors with zero boundary values](dirichlet-nodal.md):
the continuous piecewise linear functions on the mesh that vanish at $0$ and $1$.
