# Continuous piecewise linear function with given nodal values

Let $0 = x_0 < \dots < x_n = 1$ be a partition of $[0, 1]$. For nodal values $d \in \mathbb{R}^{n+1}$,

$$p_d(x) = d_0 + \sum_{i=0}^{n-1} s_i(d)\, r_i(x),$$

with the [element slopes](element-slope.md) $s_i(d)$ and the [clamped ramps](ramp.md) $r_i$. On
$[0, 1]$ it is linear on each element and takes the value $d_j$ at $x_j$; outside $[0, 1]$ it is
constant.
