# Nodal values of the exact solution solve the Galerkin system

Let $0 = x_0 < \dots < x_n = 1$ be a partition of $[0, 1]$ and let $u$ be a [classical
solution](is-classical-solution.md) of $-u'' = f$ with $u(0) = u(1) = 0$. Then the nodal values
$(u(x_j))_j$ [solve the Galerkin system](is-galerkin-solution.md).
