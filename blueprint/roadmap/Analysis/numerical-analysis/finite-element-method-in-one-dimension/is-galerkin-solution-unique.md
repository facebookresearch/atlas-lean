# Uniqueness of the Galerkin solution

Let $0 = x_0 < \dots < x_n = 1$ be a partition of $[0, 1]$ and $f : \mathbb{R} \to \mathbb{R}$. If
$c$ and $c'$ both [solve the Galerkin system](is-galerkin-solution.md) for $f$, then $c = c'$: the
stiffness matrix is positive definite on nodal vectors with zero boundary values.
