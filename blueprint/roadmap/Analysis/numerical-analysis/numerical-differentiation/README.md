# Numerical differentiation

Difference quotients approximate derivatives from function values at nearby points, with a truncation error given by Taylor's theorem: the one-sided quotient is first order, the centered quotient and the standard second difference are second order. Differentiating an interpolating polynomial produces such formulas systematically, with an error term from the interpolation error formula, and Richardson extrapolation combines one formula at two step sizes to cancel the leading error term.
