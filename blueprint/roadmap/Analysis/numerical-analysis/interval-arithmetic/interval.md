# Interval

An *interval* is a nonempty, closed and bounded set of reals

$$[a, b] = \{x \in \mathbb{R} : a \le x \le b\}, \qquad a, b \in \mathbb{R},\ a \le b .$$

Its *width* is $w([a,b]) = b - a$; a *point interval* $[a, a]$ has width $0$. Intervals are regarded as sets: two intervals are equal when they have the same members, and the operations on them are defined from operations on their members.
