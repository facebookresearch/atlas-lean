# The wrapped upstream sample is the wave one cell upstream

For real numbers `L ≠ 0`, `c₀`, `a`, `v` and `Δt`, a number of cells `N_c ≥ 1`, a time level `n` and
a node `j`, the [sample](sampled-wave.md) at node `j - 1` is `c(n Δt, x_j - Δx)`, with
`Δx = L / N_c`; this holds also at `j = 0`, where `j - 1` is the last node, by spatial periodicity.
