# Bath-cooling vector field

For real $C$, $G$, $T_{\mathrm{amb}}$, the bath-cooling field is the time-independent right-hand side of $C\,T' = Q(T)$:

$$f(t, T) = \frac{Q(T)}{C} = \frac{-G\,(T - T_{\mathrm{amb}})}{C},$$

with value $0$ when $C = 0$ (real division by zero is $0$). For $C \neq 0$ it is the right-hand side of $T' = Q(T)/C$, equivalent to $C\,T' = Q(T)$. At $C = 0$ the field is $0$ even when $Q(T) \neq 0$, so it does not then solve $C\,T' = Q(T)$, which would require $Q(T) = 0$.
