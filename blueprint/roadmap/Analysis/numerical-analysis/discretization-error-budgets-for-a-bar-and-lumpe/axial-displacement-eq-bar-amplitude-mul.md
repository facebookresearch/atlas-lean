# Bar displacement is the amplitude times the unit profile

If $L \ne 0$, then for all real $EA$, $q$, $x$ (real division, with $x/0 = 0$, so the identity also holds for $EA = 0$),

$$\frac{q\, x(L - x)}{2\,EA} = \alpha\, \hat u(x/L), \qquad \alpha = \frac{q L^2}{2\,EA}, \qquad \hat u(\xi) = \xi(1-\xi).$$
