# Defect recurrence for a computed bath-cooling sequence

Let $C > 0$, $G > 0$, real $T_{\mathrm{amb}}$, $\tau = C/G$ and $Q(T) = -G(T - T_{\mathrm{amb}})$. Let $X$ satisfy $X_{j+1} = X_j + (\tau/10)\,Q(X_j)/C$ for every $j$, and let $Y : \mathbb{N} \to \mathbb{R}$ be any sequence with residuals $\eta_j = Y_{j+1} - (Y_j + (\tau/10)\,Q(Y_j)/C)$. Then for every $j$,

$$Y_{j+1} - X_{j+1} = \tfrac{9}{10}\,(Y_j - X_j) + \eta_j.$$
