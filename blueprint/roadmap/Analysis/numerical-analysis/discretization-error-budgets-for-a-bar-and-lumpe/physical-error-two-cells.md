# Physical bar error on two cells

For the two-cell partition $0 < \tfrac12 < 1$, $L > 0$ and real $EA$, $q$, with $e(x) = u(x) - \alpha\,(I_P \hat u)(x/L)$, with $u(x) = \frac{q\, x (L - x)}{2\,EA}$, $\alpha = \frac{q L^2}{2\,EA}$ and $\hat u(\xi) = \xi(1-\xi)$:

- $e(L/4) = \alpha/16$;
- $\int_0^L EA\, e'(x)^2\,dx = \dfrac{EA}{L}\,\dfrac{\alpha^2}{12}$;
- $\int_0^L e(x)^2\,dx = \dfrac{L\,\alpha^2}{480}$.

Derivatives are pointwise, with value $0$ at the finitely many points where the derivative does not exist.

Real division uses $x/0 = 0$, so the statement also covers $EA = 0$.
