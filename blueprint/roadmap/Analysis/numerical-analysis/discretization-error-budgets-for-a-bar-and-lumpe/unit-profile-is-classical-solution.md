# Unit profile solves the unit bar problem

The unit profile $\hat u(\xi) = \xi(1-\xi)$ is a classical solution of $-\hat u'' = 2$ on $(0,1)$ with $\hat u(0) = \hat u(1) = 0$: it is $C^2$ on $\mathbb{R}$, the constant load $2$ is continuous, the equation holds on the open interval, and both boundary values vanish.
