# Unit interpolation error

Let $P$ be a partition $0 = \xi_0 < \xi_1 < \dots < \xi_n = 1$ of $[0,1]$ and $I_P$ its nodal interpolant (the continuous piecewise linear function, constant outside $[0,1]$, that agrees with a given function at the nodes). The unit error is

$$\hat e(\xi) = \hat u(\xi) - (I_P \hat u)(\xi), \qquad \hat u(\xi) = \xi(1-\xi).$$
