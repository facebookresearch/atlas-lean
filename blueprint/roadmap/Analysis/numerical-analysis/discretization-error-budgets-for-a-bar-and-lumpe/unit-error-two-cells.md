# Unit interpolation error on two cells

For the two-cell partition $0 < \tfrac12 < 1$ and the unit error $\hat e = \hat u - I_P \hat u$ with $\hat u(\xi) = \xi(1-\xi)$:

- $\hat e$ vanishes at the three nodes;
- $\hat e(1/4) = 1/16$;
- $\int_0^1 \hat e'(\xi)^2\,d\xi = 1/12$;
- $\int_0^1 \hat e(\xi)^2\,d\xi = 1/480$.

The derivative is pointwise, with value $0$ at the nodes where it does not exist.
