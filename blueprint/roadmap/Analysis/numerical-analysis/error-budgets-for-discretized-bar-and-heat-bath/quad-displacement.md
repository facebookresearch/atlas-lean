# Displacement of a bar under a quadratic load

For real numbers `EA`, `L`, `Q` and `x`, the displacement is `u(x) = β û(x / L)`, with the
[amplitude](quad-amplitude.md) `β` and the [quadratic-load profile](quad-profile.md) `û`. With the
convention `a / 0 = 0`, `x / L = 0` when `L = 0`. For `L > 0` and `EA > 0` it
[solves the fixed-fixed bar problem](is-fixed-fixed-solution-quad-displacemen.md) with rigidity `EA`
and load `Q (x / L)²`.
