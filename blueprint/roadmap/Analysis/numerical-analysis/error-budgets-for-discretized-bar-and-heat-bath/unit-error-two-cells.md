# Unit interpolation error on two equal cells

On the [two-cell partition](two-cells.md) `0 < 1/2 < 1`, the [unit error](unit-error.md) `ê`
vanishes at the three nodes, `ê(1/4) = 1/16`, `∫_0^1 ê'(ξ)² dξ = 1/12` and `∫_0^1 ê(ξ)² dξ = 1/480`
(derivatives taken to be `0` where `ê` is not differentiable).
