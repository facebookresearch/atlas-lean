# L² error of an approximate midpoint coefficient

For real numbers `EA > 0`, `L > 0`, `Q` and `c`, with the [displacement](quad-displacement.md) `u`,
the [hat reconstruction](two-cell-reconstruction.md) `R(c)` of `c` and
`‖w‖ = (∫_0^L w(x)² dx)^{1/2}`,
`‖u - R(c)‖ ≤ ‖u - R(c_ex)‖ + √(L / 3) |β| / 384 + √(L / 3) L |r| / (4 EA)`, where `c_ex` is the
[exact-load coefficient](quad-coeff.md), `β` the [amplitude](quad-amplitude.md) and `r` the
[residual](quad-midpoint-residual.md) of `c` in the midpoint system.
