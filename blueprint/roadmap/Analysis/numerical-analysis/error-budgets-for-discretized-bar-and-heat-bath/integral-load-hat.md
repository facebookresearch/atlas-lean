# The consistent load is the load integrated against the rescaled hat

For a real `L > 0` and a real `q`, `∫_0^L q φ(x / L) dx = q L / 2`, the
[consistent load](two-cell-load.md), where `φ` is the
[hat function](../finite-element-method-in-one-dimension/hat.md) of the interior node of the
[two-cell partition](two-cells.md).
