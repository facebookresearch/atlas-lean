# Piecewise linear reconstruction of the bar displacement

For a [partition](../../real-functions/integration/riemann-integral/partition.md) `P` of `[0, 1]`
and real numbers `EA`, `L`, `q` and `x`, the reconstruction is `u_h(x) = α (I_P û)(x / L)`, with the
[amplitude](bar-amplitude.md) `α`, the [unit profile](unit-profile.md) `û` and the
[nodal interpolant](../finite-element-method-in-one-dimension/interp.md) `I_P`. With the convention
`a / 0 = 0`, `x / L = 0` when `L = 0`.
