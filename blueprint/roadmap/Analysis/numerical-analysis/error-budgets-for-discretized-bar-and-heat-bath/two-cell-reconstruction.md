# Reconstruction from an interior coefficient through the hat function

For real numbers `L`, `c` and `x`, the hat reconstruction is `c φ(x / L)`, where `φ` is the
[hat function](../finite-element-method-in-one-dimension/hat.md) of the interior node `1/2` of the
[two-cell partition](two-cells.md). With the convention `a / 0 = 0`, `x / L = 0` when `L = 0`.
