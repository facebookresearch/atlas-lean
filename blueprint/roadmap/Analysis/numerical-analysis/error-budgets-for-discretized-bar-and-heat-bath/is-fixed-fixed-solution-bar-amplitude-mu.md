# The rescaled unit profile solves the fixed-fixed bar problem

For real numbers `L > 0`, `EA > 0` and `q`, the function `x ↦ α û(x / L)`, with the
[amplitude](bar-amplitude.md) `α` and the [unit profile](unit-profile.md) `û`, is a
[solution of the fixed-fixed bar problem](../../../Physics/elasticity-and-structures/prismatic-bars-shafts-and-beams/is-fixed-fixed-solution.md)
with rigidity `EA` and the uniform load `q`: it is twice continuously differentiable on `[0, L]`,
satisfies `-(EA u'') = q` on `[0, L]` and vanishes at `0` and `L`.
