# Error of the reconstructed bar displacement

For a [partition](../../real-functions/integration/riemann-integral/partition.md) `P` of `[0, 1]`
and real numbers `EA`, `L`, `q` and `x`, the physical error is `e(x) = u(x) - u_h(x)`, the
[fixed-fixed displacement](../../../Physics/elasticity-and-structures/prismatic-bars-shafts-and-beams/axial-displacement.md)
`u(x) = q x (L - x) / (2 EA)` minus the [reconstruction](physical-p1.md) `u_h(x)`.
