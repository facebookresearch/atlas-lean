# The bar error is the amplitude times the rescaled unit error

For a [partition](../../real-functions/integration/riemann-integral/partition.md) `P` of `[0, 1]`, a
real `L ≠ 0` and all real `EA`, `q` and `x`, the [physical error](physical-error.md) satisfies
`e(x) = α ê(x / L)`, with the [amplitude](bar-amplitude.md) `α` and the [unit error](unit-error.md)
`ê`.
