# The quadratic-load displacement solves the fixed-fixed bar problem

For real numbers `L > 0`, `EA > 0` and `Q`, the [displacement](quad-displacement.md)
`u(x) = β û(x / L)` is a
[solution of the fixed-fixed bar problem](../../../Physics/elasticity-and-structures/prismatic-bars-shafts-and-beams/is-fixed-fixed-solution.md)
with rigidity `EA` and load `Q (x / L)²`: it is twice continuously differentiable on `[0, L]`,
satisfies `-(EA u'') = Q (x / L)²` on `[0, L]` and vanishes at `0` and `L`.
