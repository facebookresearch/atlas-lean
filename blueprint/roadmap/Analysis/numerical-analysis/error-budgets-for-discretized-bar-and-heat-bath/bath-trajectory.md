# Temperature of a body cooling in a bath

For real numbers `C`, `G`, `T_amb`, `Δ` (initial excess) and `t`, the bath-cooling trajectory is
`T(t) = T_amb + Δ exp(-t / τ)` with the [thermal time constant](thermal-time-constant.md)
`τ = C / G`. With the convention `a / 0 = 0`, it is the constant `T_amb + Δ` when `τ = 0`.
