# At zero load the inverse amplitude map does not recover the profile

For all real `EA` and `L`, at the load `q = 0`, `α⁻¹ u(L / 2) = 0` (with `α = 0` and the convention
`0⁻¹ = 0`), which differs from `û(1/2) = 1/4`, where `α` is the [amplitude](bar-amplitude.md), `u`
the
[fixed-fixed displacement](../../../Physics/elasticity-and-structures/prismatic-bars-shafts-and-beams/axial-displacement.md)
and `û` the [unit profile](unit-profile.md).
