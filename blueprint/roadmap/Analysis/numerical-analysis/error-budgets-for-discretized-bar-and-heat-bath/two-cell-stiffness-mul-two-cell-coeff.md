# The interior coefficient solves the one-equation system K c = F

For real numbers `EA ≠ 0`, `L ≠ 0` and `q`, the [interior coefficient](two-cell-coeff.md) `c`
satisfies `K c = F`, with the [stiffness](two-cell-stiffness.md) `K = 4 EA / L` and the
[consistent load](two-cell-load.md) `F = q L / 2`.
