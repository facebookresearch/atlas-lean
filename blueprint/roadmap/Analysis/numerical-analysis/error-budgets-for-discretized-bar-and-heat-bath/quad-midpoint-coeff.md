# Midpoint interior coefficient for the quadratic load

For real numbers `EA`, `L` and `Q`, the midpoint coefficient is `F_mid / K`, with the
[midpoint load](phys-midpoint-load.md) `F_mid` of `Q (x / L)²` and the
[interior stiffness](two-cell-stiffness.md) `K`. With the convention `a / 0 = 0`, it is `0` when
`K = 0`.
