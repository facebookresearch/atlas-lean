# Terminal value of an accepted thermal trace

A list $y$ of rationals is accepted by the thermal trace checker when it has exactly eleven entries $y_0, \dots, y_{10}$, $y_0 = 1$, and $y_{j+1} = \tfrac{9}{10}\, y_j$ for $j = 0, \dots, 9$. If $y$ is accepted, then, as a real number, $y_{10} = (9/10)^{10}$.
