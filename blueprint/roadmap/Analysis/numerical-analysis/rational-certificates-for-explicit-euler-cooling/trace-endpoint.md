# Endpoint reconstructed from a thermal trace

For a bath temperature $T_{\mathrm{amb}}$, an initial excess $\Delta$ (real) and a list $y$ of rationals, the reconstructed endpoint is

$$T_{\mathrm{amb}} + \Delta\, y_{10},$$

where $y_{10}$ is the entry of index $10$, read as $0$ when the list is shorter. For $\Delta = 0$ the endpoint is $T_{\mathrm{amb}}$ for every list.
