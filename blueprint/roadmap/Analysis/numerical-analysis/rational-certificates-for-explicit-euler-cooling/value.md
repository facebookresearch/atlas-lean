# Value of a thermal trace token

The value of a token is the rational number $z/d$, with $z$ its signed numerator and $d$ its denominator (with $z/0 = 0$). For an [admissible](admissible.md) token $d \ge 1$, so the value is an honest quotient; for a raw token with denominator $0$ the value is $0$ whatever its numerator.
