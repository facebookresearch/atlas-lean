# Value of a decimal digit character

For a character $c$, the digit value is $\operatorname{code}(c) - \operatorname{code}(\texttt{'0'})$ as a natural number (truncated subtraction, so it is $0$ for characters below $\texttt{'0'}$). On the ASCII digits $\texttt{'0'}, \dots, \texttt{'9'}$ it gives $0, \dots, 9$.
