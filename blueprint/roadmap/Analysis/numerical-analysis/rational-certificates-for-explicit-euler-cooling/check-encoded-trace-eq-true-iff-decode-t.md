# Accepted encoded traces decode to the powers of 9/10

For a list of characters $s$, the encoded trace checker accepts $s$ if and only if trace decoding of $s$ returns the list

$$\left(1, \tfrac{9}{10}, \left(\tfrac{9}{10}\right)^{2}, \dots, \left(\tfrac{9}{10}\right)^{10}\right) \in \mathbb{Q}^{11}.$$
