# Curvature bound from an operator-norm bound

If $B$ is a bounded linear operator with operator norm $\|B\| \le M$, then
$v^\top B v \le M \|v\|^2$ for every $v$, by the Cauchy–Schwarz inequality
$v^\top B v \le \|Bv\|\, \|v\| \le \|B\|\, \|v\|^2$. It converts the operator-norm form of the
[Cauchy decrease](exists-cauchy-step.md) into the curvature form used there.
