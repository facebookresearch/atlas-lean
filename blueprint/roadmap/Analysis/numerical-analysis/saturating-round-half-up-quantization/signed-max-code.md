# Greatest signed w-bit code

For $w \in \mathbb{N}$, the greatest signed $w$-bit code is $2^{w-1} - 1$, where $w - 1$ is truncated subtraction, so the value at $w = 0$ is $0$. The reading as the greatest value of a signed $w$-bit word applies for $w \ge 1$; at $w = 0$ the two endpoint values $-1$ and $0$ do not both describe the single word of length zero.
