# Taylor enclosure of the exponential

For a rational $q$ and $n \in \mathbb{N}$, the rational interval centered at the Taylor partial sum $\sum_{k < n} q^k / k!$ with radius $|q|^n \frac{n + 1}{n!\, n}$ (radius $0$ for $n = 0$). It encloses $e^q$ when $|q| \le 1$ and $n > 0$; outside that range it need not.
