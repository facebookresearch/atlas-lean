# Bisection brackets stay ordered and nested

Bisection on a rational bracket $[l, u]$ with midpoint $m$ replaces it by $[l, m]$ on the decision true and by $[m, u]$ on the decision false; a run applies a list of decisions in order. If $l \le u$, then for every list of decisions the final bracket $[l', u']$ satisfies $l \le l' \le u' \le u$.
