# Provenance record of a numerical capstone

A provenance record of a numerical capstone has four fields: a string naming the unit system and the unit of the reported quantity, a string naming the version of the source data, a rational tolerance, and a list of names of the library lemmas the certificate cites. All four fields are metadata: the record itself proves nothing about them. The list is a plain list of names and may contain an anonymous or undeclared name; when a certificate writes the names as name literals, those literals are checked to exist when they are elaborated, not by the record. That the proof uses the cited lemmas is not checked, and no dimensional analysis is performed. The tolerance carries no width or positivity proof here; in a [certified root](certified-root.md) a separate field proves that the width of the final bracket is at most the recorded tolerance, so that every point of the bracket is within this distance of the root.
