# Perturbed entries in the ordered dot-product error model

For $m \in \mathbb{N}$, vectors $v, \delta v \in \mathbb{R}^m$ and an index $k$, the perturbed entry is $\hat v_k = v_k + \delta v_k$. The error model uses it twice: for the perturbed coefficient $\hat h_k = h_k + \delta h_k$ and for the perturbed input $\hat x_k = x_k + \delta x_k$; the two are the same operation on the two vectors.
