# Integral bound against a monotone integrator

Write $\int_a^b f\, dh = I$ when the Riemann–Stieltjes integral exists in the refinement sense with value $I$: for every $\varepsilon > 0$ there is a partition $P$ of $[a, b]$ such that every tagged partition refining $P$ has Riemann–Stieltjes sum $\sum_k f(\xi_k)(h(x_{k+1}) - h(x_k))$ within $\varepsilon$ of $I$. If $\int_a^b f\, dh = I$, $|f(x)| \le M$ for $x \in [a, b]$ and $h$ is monotone on $[a, b]$, then $|I| \le M\,(h(b) - h(a))$.
