# Cellwise errors of the product integral

A function $V$ controls $A$ on $[a, b]$ when $|A(x) - A(y)| \le V(x) - V(y)$ for all $a \le y \le x \le b$. The product integral $\prod_{(a, b]}(1 + dA)$ is the limit of the partition products $\prod (1 + A(t_i) - A(t_{i-1}))$ over partitions of $[a, b]$ along refinement. Let $a \le b$ and let $V$ control $A$ on $[a, b]$. For every partition $a = t_0 < \dots < t_n = b$ from a finite set $s$,

$$\sum_i \Big|\prod_{(t_{i-1}, t_i]}(1 + dA) - \big(1 + A(t_i) - A(t_{i-1})\big)\Big| \le \prod_{(a,b]}(1 + dV) - \prod_i \big(1 + V(t_i) - V(t_{i-1})\big).$$
