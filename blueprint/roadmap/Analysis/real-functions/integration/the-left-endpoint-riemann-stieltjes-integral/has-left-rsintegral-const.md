# Left-endpoint integral of a constant

The left-endpoint Riemann–Stieltjes integral $\int_a^b f\, dh = I$ means that the sums $\sum_i f(t_{i-1})(h(t_i) - h(t_{i-1}))$ over the partitions of $[a, b]$ converge to $I$ along refinement; the partition generated by a finite set $s$ consists of $a$, $b$ and the points of $s$ strictly between them. For $a \le b$, every constant $c$ and every $h$, $\int_a^b c\, dh = c\,(h(b) - h(a))$.
