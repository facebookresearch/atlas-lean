# Unit-window bound for the integral of $\sin(t^2)$

Let $f : \mathbb{R} \to \mathbb{R}$ be
given by $f(x) = \int_x^{x+1} \sin(t^2)\,dt$. Then $|f(x)| < 1/x$ for every real $x > 0$.
