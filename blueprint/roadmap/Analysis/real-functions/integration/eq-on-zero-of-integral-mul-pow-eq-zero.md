# A function continuous on $(0,1)$ with vanishing moments is zero on $(0,1)$

Let
$f : \mathbb{R} \to \mathbb{R}$ be continuous on $[0,1]$, and suppose that
$\int_0^1 f(x)\,x^n\,dx = 0$ for every natural number $n = 0, 1, 2, \dots$. Then $f(x) = 0$ for
every $x \in [0,1]$.
