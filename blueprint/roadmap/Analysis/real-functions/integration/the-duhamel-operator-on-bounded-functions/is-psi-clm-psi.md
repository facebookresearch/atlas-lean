# The Duhamel operator satisfies the Duhamel-operator hypotheses

For every $\tau \in \mathbb{R}$, the Duhamel operator $\Psi$ on the bounded functions on $[0, \tau]$ satisfies the three [Duhamel-operator hypotheses](is-psi-clm.md): for integrators $A, B$ of bounded variation on $[0, \tau]$, $\Psi_{A,B}\, h$ is the limit of the two-tag sums whenever that limit exists, $\|\Psi_{A,B}\| \le 6\, e^{V(A)}\, e^{V(B)}$, and $\Psi_{A,B}$ sends $B - A$ to $\prod_{(0,t]}(1 + dB) - \prod_{(0,t]}(1 + dA)$.
