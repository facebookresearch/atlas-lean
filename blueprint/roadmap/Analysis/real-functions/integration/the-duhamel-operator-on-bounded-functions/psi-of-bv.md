# The Duhamel operator for integrators of bounded variation

For $A, B$ of bounded variation on $[0, \tau]$, the Duhamel operator $\Psi_{A,B}$ on the bounded functions on $[0, \tau]$ (sup norm) sends $h$ to $t \mapsto \int_{(0,t]} \prod_{(0,s]}(1 + dA)\, dh(s)\, \prod_{(s,t]}(1 + dB)$, taken as the two-tag limit along the fixed refining ultrafilter. It is a continuous linear map.
