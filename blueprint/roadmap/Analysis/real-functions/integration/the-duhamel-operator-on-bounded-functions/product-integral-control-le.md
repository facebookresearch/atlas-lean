# Product integrals of a control increase with the interval

A function $V$ controls $A$ on $[a, b]$ when $|A(x) - A(y)| \le V(x) - V(y)$ for all $a \le y \le x \le b$. The product integral $\prod_{(a, b]}(1 + dA)$ is the limit of the partition products $\prod (1 + A(t_i) - A(t_{i-1}))$ over partitions of $[a, b]$ along refinement. If $V$ controls some $A$ on $[a, b]$ and $a \le c \le d \le b$, then $\prod_{(c,d]}(1 + dV) \le \prod_{(a,b]}(1 + dV)$.
