# Raw two-tag value behind the Duhamel operator

For $A, B : \mathbb{R} \to \mathbb{R}$, a bounded $h$ on $[0, \tau]$ and $t \in [0, \tau]$, this raw value is the limit along the fixed refining ultrafilter of the two-tag sums of $u \mapsto \prod_{(0,u]}(1 + dA)$ and $x \mapsto \prod_{(x,t]}(1 + dB)$ against the zero extension of $h$ over partitions of $[0, t]$ when they converge along it, as they do when the sums are bounded (for instance when $A$ and $B$ have bounded variation on $[0, \tau]$); otherwise it is an unspecified real number. It is the value of the Duhamel operator only when $A$ and $B$ both have bounded variation on $[0, \tau]$ (see [the Duhamel operator for integrators of bounded variation](psi-of-bv.md)); otherwise the operator is $0$ while this expression need not be.
