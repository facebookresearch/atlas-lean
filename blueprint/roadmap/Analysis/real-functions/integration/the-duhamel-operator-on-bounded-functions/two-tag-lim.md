# Limit of two-tag sums

For $F, G, h : \mathbb{R} \to \mathbb{R}$ and $a, b \in \mathbb{R}$, the limit of the two-tag sums of $F$ and $G$ against $h$ over the partitions of $[a, b]$ along a fixed ultrafilter refining every finite set of points. It equals the two-tag Riemann–Stieltjes integral whenever that integral exists, and is linear in $h$ on integrators with bounded sums; otherwise its value is a convention.

The partitions are those of the point sets formed by inserting both endpoints $a$ and $b$ into the points of a finite set that lie strictly between $a$ and $b$, ordered increasingly. For $a > b$ the interval $[a, b]$ is empty and every such point set is $\{b, a\}$, with the single cell $(b, a]$, so the limit is the two-tag sum $F(b)\,(h(a) - h(b))\,G(a)$ of that cell; it is not an oriented integral.
