# The two-tag limit agrees with the two-tag integral

If the two-tag Riemann–Stieltjes integral $\int_{(a,b]} F(s)\, dh(s)\, G(s)$ exists with value $I$ (the sums $\sum F(u)(h(x) - h(u)) G(x)$ over the cells $(u, x]$ of partitions of $[a, b]$ converge to $I$ along refinement), then the limit of two-tag sums along the fixed refining ultrafilter equals $I$.
