# Control of the right kernel factor

A function $V$ controls $A$ on $[a, b]$ when $|A(x) - A(y)| \le V(x) - V(y)$ for all $a \le y \le x \le b$. The product integral $\prod_{(a, b]}(1 + dA)$ is the limit of the partition products $\prod (1 + A(t_i) - A(t_{i-1}))$ over partitions of $[a, b]$ along refinement. If $W$ controls $B$ on $[a, t]$, then $x \mapsto -\prod_{(x,t]}(1 + dW)$ controls $x \mapsto \prod_{(x,t]}(1 + dB)$ on $[a, t]$.
