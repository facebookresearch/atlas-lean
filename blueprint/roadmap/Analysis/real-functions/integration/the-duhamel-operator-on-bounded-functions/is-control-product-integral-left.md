# Control of the left kernel factor

A function $V$ controls $A$ on $[a, b]$ when $|A(x) - A(y)| \le V(x) - V(y)$ for all $a \le y \le x \le b$. The product integral $\prod_{(a, b]}(1 + dA)$ is the limit of the partition products $\prod (1 + A(t_i) - A(t_{i-1}))$ over partitions of $[a, b]$ along refinement. If $V$ controls $A$ on $[a, b]$, then $u \mapsto \prod_{(a,u]}(1 + dV)$ controls $u \mapsto \prod_{(a,u]}(1 + dA)$ on $[a, b]$.
