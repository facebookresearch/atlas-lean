# Operator-norm constant of the Duhamel operator

For $A, B : \mathbb{R} \to \mathbb{R}$, the operator-norm constant is $6\, e^{V(A)}\, e^{V(B)}$, where $V(\cdot)$ is the total variation on $[0, \tau]$, an extended real converted to a real number before exponentiation: an infinite variation is converted to $0$ and so contributes the factor $e^0 = 1$.
