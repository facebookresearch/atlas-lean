# The square law attains the remainder bound with M = 2

For the square law $i(v) = v^2$ on $\mathbb{R}^1 = \mathbb{R}$ and every real $a$, the
[remainder](small-signal-remainder.md) at $0$ with the perturbation $dv = (a)$ satisfies
$|r| = 2 \|dv\|^2 / 2$: the bound $M \|dv\|^2 / 2$ with $M = 2$ is attained, so the factor $1/2$ of
the remainder bounds cannot be improved in general.
