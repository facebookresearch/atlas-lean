# Borel's lemma

For every sequence $(a_n)_{n \ge 0}$ of real numbers there is an infinitely
differentiable function $f : \mathbb{R} \to \mathbb{R}$ whose derivatives at $0$ are
$f^{(n)}(0) = a_n$ for every $n \ge 0$.
