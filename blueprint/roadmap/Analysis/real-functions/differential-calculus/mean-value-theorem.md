# Mean value theorem for real functions

Let $a < b$ be real numbers and let $f\colon \mathbb{R} \to \mathbb{R}$ be a function whose restriction to $[a, b]$ is continuous and which is differentiable on the open interval $(a, b)$. Then some $c \in (a, b)$ satisfies

$$f'(c) = \frac{f(b) - f(a)}{b - a}.$$
