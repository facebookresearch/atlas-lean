# Lebesgue's theorem: a non-decreasing function on the real line is differentiable almost everywhere

Let $f\colon \mathbb{R} \to \mathbb{R}$ be non-decreasing, that is, $f(x) \le f(y)$ whenever $x \le y$. Then $f$ is differentiable at almost every point of $\mathbb{R}$: the set of points at which $f$ is not differentiable has Lebesgue measure zero.
