# Erdős Problem 255 on intervals of unbounded discrepancy

Erdős Problem 255: every sequence in `[0, 1]` has an interval `[a, b] ⊆ [0, 1]` with `a < b`
on which `|D_N([a, b])|` is unbounded, i.e. `limsup_N |D_N([a, b])| = ∞`.

Its resolution: [Schmidt's theorem on intervals of unbounded discrepancy](unbounded-discrepancy-interval-holds.md).
