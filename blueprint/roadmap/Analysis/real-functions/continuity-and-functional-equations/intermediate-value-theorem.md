# Intermediate value theorem

Let $\alpha$ be a densely ordered conditionally complete linear order with its order topology, for example $\mathbb{R}$, and let $\delta$ be a linear order with a topology in which the order is closed. If $a \le b$ in $\alpha$ and $f : \alpha \to \delta$ is continuous on $[a, b]$, then every value between $f(a)$ and $f(b)$ is attained: $[f(a), f(b)] \subseteq f([a, b])$.
