# A continuous nowhere differentiable function

There exists a continuous function
$f : \mathbb{R} \to \mathbb{R}$ that is differentiable at no point of $\mathbb{R}$.

## Sources

- K. Weierstrass, 1872 lecture; P. du Bois-Reymond, J. Reine Angew. Math. 79 (1875), 21-37, DOI 10.1515/crll.1875.79.21. Proves `Wanted` entry `exists_continuous_nowhere_differentiable`.
