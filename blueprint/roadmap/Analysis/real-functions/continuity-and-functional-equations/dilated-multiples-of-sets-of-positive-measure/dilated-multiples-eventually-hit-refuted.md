# A counterexample to Erdős Problem 1197

This settles [Erdős Problem 1197 on dilated multiples of a set of positive measure](dilated-multiples-eventually-hit.md) in the negative: its statement is false.

erdosproblems.com/1197 records a counterexample by ebarschkis, built from a variant of the Buczolich–Mauldin construction of an open set $E$ and an interval $J$ such that almost every $x \in J$ satisfies $x \notin E/n$ for all large $n$.
