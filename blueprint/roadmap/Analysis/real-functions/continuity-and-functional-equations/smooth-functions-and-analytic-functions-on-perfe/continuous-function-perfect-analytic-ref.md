# Zahorski's negative answer to Ulam's perfect set problem

Problem 17.1 has a negative answer: there is a function continuous on $[0, 1]$ that agrees with no function analytic
on $[0, 1]$ on any perfect subset of $[0, 1]$. Source: S. Ulam, Problem 17.1 of the Scottish Book; Z. Zahorski gave a
negative answer by constructing a $C^\infty$ function that agrees with every real-analytic function on at most
finitely many points, so no nonempty perfect set $C$ can work for it: Z. Zahorski, "Sur l'ensemble des points
singuliers d'une fonction d'une variable reelle admettant les derivees de tous les ordres", Fund. Math. 34 (1947),
183-245. The 2026 survey "90+ years of the Scottish Book" (arXiv:2603.27867) confirms the negative solution.
