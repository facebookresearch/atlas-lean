# Zahorski's smooth counterexample to Ulam's Problem 17.1

This settles [Ulam's Problem 17.1 for smooth functions](scottish-book-problem17-point1-smooth-cl.md) in the negative: its statement is false.

Ulam's Problem 17.1 fails already for smooth functions: there is a $C^\infty$ function $f : \mathbb{R} \to \mathbb{R}$ such that for no nonempty [perfect set](is-perfect-set.md) $C \subseteq [0, 1]$ (closed and without isolated points) and no function $\varphi$ analytic on $[0, 1]$ does $f$ agree with $\varphi$ on all of $C$.

## Sources

- Z. Zahorski, Fund. Math. 34 (1947), 183-245.
