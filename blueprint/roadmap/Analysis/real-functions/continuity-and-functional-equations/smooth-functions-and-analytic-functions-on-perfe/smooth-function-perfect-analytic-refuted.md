# Zahorski's smooth counterexample to Ulam's Problem 17.1

Ulam's Problem 17.1 fails already for smooth functions: there is a $C^\infty$ function $f : \mathbb{R} \to \mathbb{R}$ such that for no perfect set $C \subseteq [0, 1]$ and no function $\varphi$ analytic on $[0, 1]$ does $f$ agree with $\varphi$ on all of $C$.

## Sources

- Z. Zahorski, Fund. Math. 34 (1947), 183-245.
