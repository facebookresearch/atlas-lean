# Ulam's Problem 17.1 for smooth functions

For every $C^\infty$ function $f : \mathbb{R} \to \mathbb{R}$ there are a nonempty [perfect set](is-perfect-set.md) $C \subseteq [0, 1]$ (closed and without isolated points) and a function $\varphi$ analytic on $[0, 1]$ with $f(x) = \varphi(x)$ for every $x \in C$.

Its resolution: [Zahorski's smooth counterexample to Ulam's Problem 17.1](smooth-function-perfect-analytic-refuted.md).
