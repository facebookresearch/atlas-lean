# Ulam's problem on analytic agreement on a perfect set

Ulam's Problem 17.1 from the Scottish Book: for every function $f$ continuous on $[0, 1]$, do there exist a perfect
set $C \subseteq [0, 1]$ (closed, nonempty, without isolated points) and a function $\varphi$ analytic on $[0, 1]$
with $f(x) = \varphi(x)$ for every $x \in C$? Zahorski's $C^\infty$ counterexample answers it in the negative, already
for smooth functions.
