# Marstrand's refutation of Khinchin's conjecture

This settles [Khinchin's conjecture on strong uniform distribution](khinchin-strong-uniform-distribution.md) in the negative: its statement is false.

Marstrand disproved Khinchin's conjecture, giving a Borel set `E ⊆ (0, 1)` for which
the averages `(1/n) #{k ≤ n : {kα} ∈ E}` fail to converge to `λ(E)` for almost every `α`;
erdosproblems.com/994 lists the problem as disproved.

## Sources

- T. F. Bloom, Erdős Problems, Problem \#994, https://www.erdosproblems.com/994 (status DISPROVED (LEAN)); resolution: J. M. Marstrand, On Khinchin's conjecture about strong uniform distribution, Proc. London Math. Soc. (3) (1970), 540-556, erdosproblems.com/994: 'In fact this is false, and was disproved by Marstrand'; the erdosproblems database (teorth/erdosproblems) records Marstrand's answer in the fixed-set quantifier order: one Borel set fails for almost every α, https://www.erdosproblems.com/994.
