# Erdős Problem 1197 on dilated multiples of a set of positive measure

Erdős Problem 1197: for every measurable $E \subseteq (0, \infty)$ of positive Lebesgue measure (the measure
may be infinite), for almost every $x > 0$ and all sufficiently large integers $n$, there is an integer
$r \ge 1$ with $n x \in r E = \{r e : e \in E\}$.

A counterexample must therefore give a measurable $E \subseteq (0, \infty)$ of positive measure and a set of
$x > 0$ of positive measure such that, for each such $x$, there are infinitely many $n$ with $n x \notin r E$
for every integer $r \ge 1$. Avoiding $E$ itself, that is $n x \notin E$ or $x \notin E/n$ for all large
$n$, is the case $r = 1$ only and does not suffice. No set $E$ containing an interval $(a, b)$ with
$0 < a < b$ can be a counterexample, so no nonempty open set can: for every $x > 0$, once $n x (1/a - 1/b) > 1$
the interval $(n x / b, n x / a)$ contains an integer $r \ge 1$, and then $n x / r \in (a, b) \subseteq E$.
