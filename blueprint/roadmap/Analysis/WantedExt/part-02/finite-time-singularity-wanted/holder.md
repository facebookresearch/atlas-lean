# Holder

We say that a function `f : X → Y` is `r-Hölder` if there exists `C ≥ 0`, such that
for all `x₁, x₂ : X`, `d_Y(f x₁, f x₂) ≤ C * d_X(x₁, x₂) ^ r`.
