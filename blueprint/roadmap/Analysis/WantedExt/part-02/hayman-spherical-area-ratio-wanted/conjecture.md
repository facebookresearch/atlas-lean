# Conjecture

[AMR-022-1016] Hayman's question: is
`liminf_{r → ∞} n(r)/A(r) = 1` for every globally meromorphic,
nonconstant `f` with bounded root counts at each radius?
The known bounds `1 ≤ liminf n(r)/A(r) ≤ e` are not formalized here.
