# Root Count

`rootCount f a r`: number of roots of `f(z) = a` in `|z| < r`,
counted with multiplicity, as the finite-support sum over `z : ℂ` of the
nonnegative part of the divisor of `f - a` on `Metric.ball 0 r`.
