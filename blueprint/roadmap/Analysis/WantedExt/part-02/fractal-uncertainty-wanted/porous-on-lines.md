# Porous On Lines

We say a set `X` is `ν`-porous on lines from scales `α₀` to `α₁` if for all line segments `τ`
with length `α₀ < R < α₁`, there is some `x ∈ τ` such that `closedBall x (ν * R) ∩ X = ∅`.
