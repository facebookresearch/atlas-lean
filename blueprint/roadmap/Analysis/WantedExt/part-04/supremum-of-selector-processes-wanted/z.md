# Z

Given a sequence of `𝕋`-valued random variables `Y_1, …, Y_N` and a function `f : 𝕋 → ℝ≥0`,
define the random variable

`Z N Y f := N⁻¹ ∑ i ∈ {1,…,N}, f(Yᵢ)`

When the sequence `Y_1, …, Y_N` is i.i.d, we call `Z N Y f` an empirical process.
