# E C1 Norm On

Given a function `f : E → F` we define the `ℝ≥0∞`-valued `C¹` norm on `s : Set E` by:
`‖f‖_{C¹(s)} := ‖f‖_{L∞(s)} + ‖Df‖_{L∞(s)}`.
