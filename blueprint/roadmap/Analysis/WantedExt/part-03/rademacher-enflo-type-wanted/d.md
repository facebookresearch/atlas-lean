# D

Definition of the discrete partial derivative. Given a function `f : {-1, 1}ⁿ → X`
we define

`Dⱼf(ε) := (f(ε₁, …, εⱼ, …, εₙ) - f(ε₁, …, -εⱼ, …, εₙ)) / 2`.
