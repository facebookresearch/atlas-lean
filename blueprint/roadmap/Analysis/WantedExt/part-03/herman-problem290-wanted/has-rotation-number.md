# Has Rotation Number

Poincaré rotation number of a circle-map lift F : ℝ → ℝ: the mean motion
(F^[n] x - x) / n tends to α for every base point x.
Cites: Hayman (2018), Problem 2.90; https://arxiv.org/abs/1809.07200.
