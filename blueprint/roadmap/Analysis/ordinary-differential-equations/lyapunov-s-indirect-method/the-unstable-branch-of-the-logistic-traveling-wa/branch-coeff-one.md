# First branch coefficient

The coefficients $a_n$ of the unstable branch are defined by $a_0 = 0$, $a_1 = 1$ and, for $n \ge 2$, $a_n = \frac{-\rho}{(n-1)(\kappa n + \rho)} \sum_{i + j = n,\ i, j \ge 1} a_i a_j$, with real division by zero equal to $0$: when $\kappa n + \rho = 0$, as for $\kappa = 1$, $\rho = -2$, $n = 2$, the coefficient $a_n$ is $0$ rather than an undefined quotient. For all real $\kappa$ and $\rho$, $a_1 = 1$.
