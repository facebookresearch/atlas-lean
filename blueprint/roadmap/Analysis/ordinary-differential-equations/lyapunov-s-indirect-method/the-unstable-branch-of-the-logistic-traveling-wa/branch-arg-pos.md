# The branch amplitude is positive

For all real $D$, $r$, $c$, $z$, the branch amplitude $x(z) = \frac{1}{4} e^{\lambda_+ z}$, with $\lambda_+ = \frac{-c + \sqrt{c^2 + 4 r D}}{2D}$, is positive. Here real division by zero is $0$ and $\sqrt{y} = 0$ for $y < 0$, as in [the amplitude variable](branch-arg.md), so $\lambda_+$ is a real number for all parameters.
