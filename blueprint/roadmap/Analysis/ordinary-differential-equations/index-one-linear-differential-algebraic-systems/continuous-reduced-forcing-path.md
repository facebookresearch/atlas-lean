# Continuous forcing gives a continuous reduced forcing path

Let `B` be a real `n × m` matrix and `D` an invertible real `m × m` matrix, for finite index sets
`n` and `m`. If `f : ℝ → ℝⁿ` and `g : ℝ → ℝᵐ` are continuous, the
[reduced forcing path](reduced-forcing-path.md) `s ↦ f(s) - B D⁻¹ g(s)` is continuous.
