# Every value of a descriptor trajectory is a consistent pair

Let `n` and `m` be finite index sets and `A`, `B`, `C`, `D` real matrices of sizes `n × n`, `n × m`,
`m × n` and `m × m`, and let `f : ℝ → ℝⁿ` and `g : ℝ → ℝᵐ` be forcing terms and `x : ℝ → ℝⁿ`,
`y : ℝ → ℝᵐ` be a trajectory pair that
[satisfies the descriptor system](satisfies-descriptor-system.md). Then for every time `t₀` the pair
`(x(t₀), y(t₀))` is [consistent](consistent-pair.md) for the forcing value `g(t₀)`. No invertibility
of `D` is needed.
