# A pair is consistent iff its algebraic part is the reconstruction

Let `n` and `m` be finite index sets, `C` a real `m × n` matrix and `D` an invertible real `m × m`
matrix. For `g₀ ∈ ℝᵐ`, `x₀ ∈ ℝⁿ` and `y₀ ∈ ℝᵐ`, the pair `(x₀, y₀)` is
[consistent](consistent-pair.md) for `g₀` exactly when `y₀` is the
[reconstruction](algebraic-reconstruction.md) `−D⁻¹ (C x₀ + g₀)`.
