# The algebraic component of a solution need not be differentiable

For the scalar [descriptor system](satisfies-descriptor-system.md) `x' = 0`, `0 = y + |t|` (one
state and one algebraic variable, with `A = B = C = 0`, `D = 1`, `f = 0` and `g(t) = |t|`), there is
a solution `(x, y)` whose algebraic component `y` is not differentiable at `t = 0`. The proof takes
`x ≡ 0` and `y(t) = -|t|`, the only algebraic component the second equation allows.
