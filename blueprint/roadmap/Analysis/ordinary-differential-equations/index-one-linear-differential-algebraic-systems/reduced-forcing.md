# Forcing of the reduced differential equation

Let `n` and `m` be finite index sets, `B` a real `n × m` matrix and `D` an invertible real `m × m`
matrix. For forcing values `f ∈ ℝⁿ` and `g ∈ ℝᵐ`, the reduced forcing is

`f − B D⁻¹ g`,

the forcing of the differential equation after the algebraic variable has been eliminated.
