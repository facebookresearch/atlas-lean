# Reconstruction of the algebraic variable from the state

Let `n` and `m` be finite index sets and `C`, `D` real matrices of sizes `m × n` and `m × m`, with
`D` invertible. For a state `x ∈ ℝⁿ` and an algebraic forcing value `g ∈ ℝᵐ`, the reconstructed
algebraic vector is

`−D⁻¹ (C x + g)`.

Taking `y = −D⁻¹ (C x + g)` [solves](algebraic-equation-of-eq-algebraic-recon.md) the algebraic
equation `C x + D y + g = 0`, and every `y` that solves it
[equals this vector](eq-algebraic-reconstruction-of-algebraic.md).
