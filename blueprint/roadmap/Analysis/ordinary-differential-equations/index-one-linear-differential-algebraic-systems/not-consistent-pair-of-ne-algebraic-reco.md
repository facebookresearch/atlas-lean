# An algebraic value other than the reconstruction is inconsistent

Let `n` and `m` be finite index sets, `C` a real `m × n` matrix and `D` an invertible real `m × m`
matrix, and let `g₀ ∈ ℝᵐ`, `x₀ ∈ ℝⁿ` and `y₀ ∈ ℝᵐ`. If `y₀` differs from the
[reconstruction](algebraic-reconstruction.md) `−D⁻¹ (C x₀ + g₀)`, then the pair `(x₀, y₀)` is not
[consistent](consistent-pair.md) for `g₀`: inconsistent initial algebraic values are excluded,
not adjusted.
