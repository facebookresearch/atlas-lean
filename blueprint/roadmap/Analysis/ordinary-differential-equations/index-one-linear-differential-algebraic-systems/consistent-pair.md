# Consistent initial pair of a descriptor system

Let `n` and `m` be finite index sets and `C`, `D` real matrices of sizes `m × n` and `m × m`. A pair
`(x₀, y₀) ∈ ℝⁿ × ℝᵐ` is consistent for the algebraic forcing value `g₀ ∈ ℝᵐ` when

`C x₀ + D y₀ + g₀ = 0`.

No invertibility of `D` is assumed in the definition.
