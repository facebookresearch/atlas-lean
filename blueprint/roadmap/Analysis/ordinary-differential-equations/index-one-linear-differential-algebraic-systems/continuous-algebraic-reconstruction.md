# The algebraic reconstruction of continuous x and g is continuous

Let `C` be a real `m × n` matrix and `D` an invertible real `m × m` matrix, for finite index sets
`n` and `m`. If `x : ℝ → ℝⁿ` and `g : ℝ → ℝᵐ` are continuous, so is `t ↦ -D⁻¹ (C x(t) + g(t))`, the
[algebraic reconstruction](algebraic-reconstruction.md) at each time.
