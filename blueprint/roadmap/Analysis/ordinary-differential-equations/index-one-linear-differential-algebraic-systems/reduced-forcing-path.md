# Reduced forcing path of an index-one descriptor system

Let `n` and `m` be finite index sets, `B` a real `n × m` matrix and `D` an invertible real `m × m`
matrix. For forcing paths `f : ℝ → ℝⁿ` and `g : ℝ → ℝᵐ`, the reduced forcing path is

`r(s) = f(s) - B D⁻¹ g(s)`,

the [reduced forcing](reduced-forcing.md) of `f(s)` and `g(s)` at each time `s`.
