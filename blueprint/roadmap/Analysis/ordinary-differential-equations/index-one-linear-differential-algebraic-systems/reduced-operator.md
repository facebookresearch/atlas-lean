# Schur-reduced operator of an index-one descriptor system

Let `n` and `m` be finite index sets and `A`, `B`, `C`, `D` real matrices of sizes `n × n`, `n × m`,
`m × n` and `m × m`, with `D` invertible. The reduced operator is the linear map
`v ↦ (A - B D⁻¹ C) v` on `ℝⁿ`, multiplication by the Schur complement `A - B D⁻¹ C` of `D`, viewed
as a bounded linear operator (every linear map on the finite-dimensional space `ℝⁿ` is bounded).
