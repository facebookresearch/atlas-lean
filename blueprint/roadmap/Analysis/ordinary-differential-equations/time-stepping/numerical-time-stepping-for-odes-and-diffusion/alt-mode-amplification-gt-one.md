# The alternating mode is amplified outside the stability regime

For $r > 1/2$, the scalar inequality $|1 - 4r| > 1$ holds. On a nonempty periodic grid with an even number of cells, one explicit heat step multiplies the alternating mode $(1, -1, 1, \dots)$ by $1 - 4r$, so there the mode grows in norm. On other grids this need not be growth: on a one-cell grid the step leaves the mode unchanged.
