# Convex-combination form of an FTCS step

For a grid function $u$ on $m$ periodic cells and any real $r$, one forward-time centred-space step $u_i + r(u_{i-1} + u_{i+1} - 2u_i)$, with neighbours taken cyclically, equals $(1 - 2r)u_i + ru_{i-1} + ru_{i+1}$; for $0 \le r \le 1/2$ this is a convex combination.
