# The spectrum of a real 2 × 2 matrix through complex eigenvectors

For a real $2 \times 2$ matrix $M$ and a complex number $z$, $z$ lies in the spectrum of $M$ over
$\mathbb{C}$, that is, of the complex matrix with the same entries, if and only if there is a
nonzero $v \in \mathbb{C}^2$ with $M v = z v$.
