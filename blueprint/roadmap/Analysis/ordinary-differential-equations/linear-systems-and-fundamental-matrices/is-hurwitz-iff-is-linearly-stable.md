# Hurwitz 2 × 2 matrices are those with a stable trace–determinant pair

For a real $2 \times 2$ matrix $M$, $M$ is
[Hurwitz](../../../LinearAlgebra/special-matrices/m-matrices-and-hurwitz-stability/nonsingular-m-matrices/is-hurwitz.md)
(every complex eigenvalue has negative real part) if and only if the pair
$(\operatorname{tr} M, \det M)$ is [linearly stable](is-linearly-stable.md).
