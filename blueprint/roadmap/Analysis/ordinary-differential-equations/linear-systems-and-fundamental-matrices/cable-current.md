# Transfer-form axial current of a uniform cable

For real numbers $r_m$, $r_i$, $V_0$, $I_0$ and $x$, the transfer-form steady-state axial current
is

$$I(x)=I_0\cosh(x/\lambda)-\frac{V_0}{r_\infty}\sinh(x/\lambda),$$

where $\lambda=\sqrt{r_m/r_i}$ is the [length constant](length-constant.md) and
$r_\infty=\sqrt{r_m r_i}$ the [characteristic resistance](char-resistance.md); $I(0)=I_0$. For
$r_m,r_i>0$, together with the [transfer-form voltage](cable-voltage.md) it is a
[steady state on every set of positions](is-steady-state-cable.md), with inlet voltage $V_0$ and
inlet current $I_0$ at $x=0$. The formula is defined for all real inputs: with the convention
$u/0=0$, the second term is $0$ when $r_\infty=0$, and $I(x)=I_0$ for every $x$ when $\lambda=0$.
