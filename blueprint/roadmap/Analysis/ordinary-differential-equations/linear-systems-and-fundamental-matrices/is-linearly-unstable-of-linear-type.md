# Saddles, unstable nodes and unstable foci are linearly unstable

For real numbers $\tau$ and $\Delta$, if the [trace–determinant class](linear-type-2.md) of
$(\tau, \Delta)$ is a saddle, an unstable node or an unstable focus, then $(\tau, \Delta)$ is
[linearly unstable](is-linearly-unstable.md). This is only a sufficient condition: a degenerate pair
with $\tau > 0$ is also linearly unstable, by the
[instability criterion](is-linearly-unstable-iff.md).
