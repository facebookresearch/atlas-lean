# A real 2 × 2 matrix has an eigenvector exactly at characteristic roots

For a real $2 \times 2$ matrix $M$ and a complex number $z$, there is a nonzero $v \in \mathbb{C}^2$
with $M v = z v$ if and only if $z^2 - (\operatorname{tr} M) z + \det M = 0$, that is, if and only
if $z$ is a [characteristic root](is-char-root.md) of $(\operatorname{tr} M, \det M)$.
