# Trace–determinant classification of a planar linearization

For real numbers $\tau$ and $\Delta$, the class of $(\tau, \Delta)$ among the
[types of a planar linearization](linear-type.md) is: saddle if $\Delta < 0$; degenerate if
$\Delta = 0$; center if $\Delta > 0$ and $\tau = 0$; for $\Delta > 0$ and $\tau < 0$, stable node if
$4\Delta \le \tau^2$ and stable focus otherwise; for $\Delta > 0$ and $\tau > 0$, unstable node if
$4\Delta \le \tau^2$ and unstable focus otherwise. Every pair of real numbers has exactly one class.
