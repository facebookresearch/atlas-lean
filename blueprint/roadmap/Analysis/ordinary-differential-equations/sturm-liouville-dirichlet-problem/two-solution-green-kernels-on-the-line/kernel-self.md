# Diagonal value of a two-solution Green kernel

For $u, v, C : \mathbb{R} \to \mathbb{R}$, let $K(x, y) = C(y)\,u(x)$ for $x \le y$ and $K(x, y) = C(y)\,\frac{u(y)}{v(y)}\,v(x)$ for $y < x$ (real division, with the quotient $0$ where $v(y) = 0$). Only the left branch is used here: $K(y, y) = C(y)\,u(y)$ for every $y$.
