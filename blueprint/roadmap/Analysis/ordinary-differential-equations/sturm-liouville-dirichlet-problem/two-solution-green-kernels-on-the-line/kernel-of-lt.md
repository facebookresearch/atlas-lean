# Right branch of the Green kernel

Let $u, v, C : \mathbb{R} \to \mathbb{R}$ and let $G(x, y) = C(y)\, u(x)$ for $x \le y$ and $G(x, y) = C(y)\, \frac{u(y)}{v(y)}\, v(x)$ for $y < x$ be the two-solution Green kernel (real division, with the quotient $0$ where $v(y) = 0$). For $y < x$, $G(x, y) = C(y)\, \frac{u(y)}{v(y)}\, v(x)$.
