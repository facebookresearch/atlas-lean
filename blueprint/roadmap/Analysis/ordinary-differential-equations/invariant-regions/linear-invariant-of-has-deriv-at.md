# Linear invariants

Let $\iota$ be a finite index set, $F : \mathbb{R}^\iota \to \mathbb{R}^\iota$ a vector field and $w \in \mathbb{R}^\iota$ a weight vector that annihilates it: $\sum_i w_i F(y)_i = 0$ for every state $y$. If $I \subseteq \mathbb{R}$ is convex and $x : \mathbb{R} \to \mathbb{R}^\iota$ satisfies $x'(t) = F(x(t))$ at every $t \in I$, then the weighted total $\sum_i w_i\, x(t)_i$ takes the same value at any two times of $I$.

Finiteness matters: the weighted total is a finite sum, and for an infinite family, such as the constant all-ones sequence with all weights one, it need not be a real number.
