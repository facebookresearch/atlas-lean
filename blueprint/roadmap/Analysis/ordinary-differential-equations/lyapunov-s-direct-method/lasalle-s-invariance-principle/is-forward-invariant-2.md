# Invariant sets are forward invariant

For a vector field $f$ on a real normed space, a set $A$ is invariant when through every point of $A$ there is a solution of $x' = f(x)$ on all of $\mathbb{R}$ staying in $A$, and forward invariant when through every point of $A$ there is a solution on $[0, \infty)$ staying in $A$. Every invariant set is forward invariant.
