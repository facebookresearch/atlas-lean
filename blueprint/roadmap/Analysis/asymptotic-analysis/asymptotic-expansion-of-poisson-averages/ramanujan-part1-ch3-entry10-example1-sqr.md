# Logarithmic asymptotics of the square-root Poisson series

For real $x$ let
$S(x) = \sum_{k=1}^{\infty} x^k \sqrt{k} / k!$. Then, as $x \to \infty$,

$$\log S(x) = x + \tfrac{1}{2} \log x - \frac{1}{8x} - \frac{1}{16 x^2} + O\left(x^{-3}\right).$$
