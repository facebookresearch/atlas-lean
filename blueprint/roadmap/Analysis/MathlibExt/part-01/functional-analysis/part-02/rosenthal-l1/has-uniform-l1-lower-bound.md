# Has Uniform L1 Lower Bound

`y : ℕ → E` has a uniform `ℓ¹` lower bound when some `c > 0` satisfies
`‖∑ i, a i • y i‖ ≥ c * ∑ i, ‖a i‖` for every finitely supported `a : ℕ →₀ 𝕜`.
