# Chapter7 Phi

Berndt's `φ_r(x)`, restricted to `-1 < x < 0`.  On this interval `x + 1`
is the canonical Hurwitz-zeta parameter, so coercion to `UnitAddCircle` does
not introduce the spurious period-one identification present outside it.
