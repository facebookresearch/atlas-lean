# Chapter7 Integer Phi

The polynomial `(B_{r+1}(x + 1) - B_{r+1}(1)) / (r + 1)`, which extends Berndt's `φ_r` to
all of `ℂ`; `chapter7Phi_eq_chapter7IntegerPhi` shows it agrees with `chapter7Phi` on `-1 < x < 0`.
