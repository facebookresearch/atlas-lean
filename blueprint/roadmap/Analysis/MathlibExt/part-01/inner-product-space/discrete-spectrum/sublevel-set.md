# Sublevel Set

Strict sublevel set: indices with eigenvalue strictly below the cutoff.
The strict inequality encodes the standard convention `(Λ - E_j)_+^0 = 1`
only when `E_j < Λ`, avoiding `0 ^ 0 = 1` at the cutoff.
