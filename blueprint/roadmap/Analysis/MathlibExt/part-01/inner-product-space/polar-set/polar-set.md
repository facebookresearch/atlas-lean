# Polar Set

The polar of a set `A` in a real inner-product space:
`polarSet A = {y | ∀ x ∈ A, ⟪x, y⟫_ℝ ≤ 1}`, using the one-sided real
inner-product convention `⟪x, y⟫_ℝ ≤ 1`.
