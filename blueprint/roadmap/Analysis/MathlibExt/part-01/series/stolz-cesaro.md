# Stolz Cesaro

Stolz–Cesàro theorem (discrete l'Hôpital): for real sequences `a`, `b`
with `b` strictly increasing and unbounded, if the difference quotient
`(a (n+1) - a n) / (b (n+1) - b n)` tends to `L` then `a n / b n` tends to `L`.
