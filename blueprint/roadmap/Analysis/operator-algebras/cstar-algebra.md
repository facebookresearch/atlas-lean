# C*-algebra, not necessarily with an identity element

A *C\*-algebra*, not necessarily with an identity element, is a complex Banach algebra $A$ with an involution $a \mapsto a^*$ that satisfies the *C\*-identity* $\|a^* a\| = \|a\|^2$ for every $a \in A$. Here a complex Banach algebra is a complex vector space $A$ with an associative multiplication that is bilinear over $\mathbb{C}$ and a complete norm such that $\|ab\| \le \|a\|\,\|b\|$ for all $a, b \in A$; no identity element is required. An involution is a map $a \mapsto a^*$ from $A$ to $A$ with $(a + b)^* = a^* + b^*$, $(\lambda a)^* = \bar{\lambda} a^*$, $(ab)^* = b^* a^*$ and $a^{**} = a$ for all $a, b \in A$ and $\lambda \in \mathbb{C}$. Mathlib takes the inequality $\|a\|^2 \le \|a^* a\|$ as its axiom. It implies $\|a^*\| = \|a\|$, hence $\|a^* a\| \le \|a^*\|\,\|a\| = \|a\|^2$, so the axiom is equivalent to the C\*-identity.
