# Anderson's conjecture that every pure state is diagonalizable

Anderson's conjecture, the statement whose consistency with ZFC AimPL Problem 5.3 (Set theory
and C* algebras) asks about: every pure state on `B(ℓ²)` is diagonalizable.

Its resolution: [Koszmider's non-diagonalizable pure state](every-pure-state-diagonalizable-refuted.md).
