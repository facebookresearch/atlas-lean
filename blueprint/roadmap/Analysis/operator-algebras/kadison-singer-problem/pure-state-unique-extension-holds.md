# Marcus–Spielman–Srivastava solution of the Kadison–Singer problem

This settles [Kadison–Singer problem](pure-state-unique-extension.md) in the affirmative: its statement holds.

Marcus, Spielman and Srivastava proved Weaver's $\mathrm{KS}_2$ conjecture and Anderson's
paving conjecture, each known to imply that every pure state on the diagonal operators of $B(\ell^2)$
has a unique extension to a state on $B(\ell^2)$ (Kadison-Singer).
