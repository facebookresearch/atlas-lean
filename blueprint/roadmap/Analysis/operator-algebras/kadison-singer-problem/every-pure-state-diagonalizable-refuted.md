# Koszmider's non-diagonalizable pure state

This settles [Anderson's conjecture that every pure state is diagonalizable](every-pure-state-diagonalizable.md) in the negative: its statement is false.

Resolved false in ZFC, so the statement is not consistent: Koszmider constructed, without extra
set-theoretic axioms, a pure state on `B(ℓ²)` that is not of the form `T ↦ lim_{k → u} ⟨T eₖ, eₖ⟩`
for any orthonormal basis `(eₖ)` and ultrafilter `u` on `ℕ`, a counterexample to
Anderson's conjecture.

## Sources

- AimPL: Set theory and C* algebras, Problem 5.3, http://aimpl.org/settheorycstar/5/; resolution: P. Koszmider, A non-diagonalizable pure state, Proc. Natl. Acad. Sci. USA 117 (2020), 33084-33089, Theorem 11 (a ZFC construction): there is a non-diagonalizable pure state on B(ℓ²), i.e. one not of the form lim_u ⟨T(e_k), e_k⟩ for any orthonormal basis (e_k) of ℓ² and ultrafilter u on ℕ; a counterexample to Anderson's conjecture, https://doi.org/10.1073/pnas.2011885117.
