# The square is operator convex, as a convex function

The map $a \mapsto a^2$ is convex, for the star order, on the convex set of self-adjoint elements of a star-ordered real algebra (E. A. Carlen, *Trace inequalities and quantum entropy: an introductory course*, lecture-notes draft of May 3, 2009, Definition 2.1 and Theorem 2.6 with $p = 2$).

For complex matrices with the Loewner order this is operator convexity of $t \mapsto t^2$ in the sense of Carlen's Definition 2.1. The rest of the elementary Loewner–Heinz theory in C⋆-algebras: $t^p$ is operator concave and operator monotone for $0 \le p \le 1$, the logarithm is operator concave and operator monotone, $t \mapsto -t^{-1}$ is operator monotone and $t \mapsto t^{-1}$ is operator convex on strictly positive elements (Carlen's Lemma 2.7), and $t^p$ is operator convex on positive elements for $1 \le p \le 2$ ([Loewner–Heinz](convex-on-cfc-rpow.md)). The present result is not a special case of the last one: it holds for all self-adjoint elements, not only positive ones, of any star-ordered real algebra.
