# Definition (Set Relations) (Basic Set Theory) (1)

We want to relate different sets, and thus we get the following notation/definitions: (1) A set $A$ is a subset of $B$, $A \subset B$, if every element of $A$ is in $B$. Given $A \subset B$, if $a \in A \implies a \in B$. (2) Two sets $A$ and $B$ are equal, $A = B$, if $A \subset B$ and $B \subset A$. (3) A set $A$ is a proper subset of $B$, $A \subsetneq B$, if $A \subset B$ and $A \neq B$.
