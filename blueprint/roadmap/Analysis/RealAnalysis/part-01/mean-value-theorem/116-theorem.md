# Theorem (Mean Value Theorem section)

Let $f:I\to \mathbb{R}$ be differentiable. Then, (1) $f$ is increasing if and only if $f'(x) \geq 0$ for all $x\in I$ and (2) $f$ is decreasing if and only if $f'(x) \leq 0$ for all $x\in I.$
