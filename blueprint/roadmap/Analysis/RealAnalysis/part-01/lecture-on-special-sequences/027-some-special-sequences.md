# Theorem (Some Special Sequences) (Lecture on special sequences)

What follows are some special sequences to have in our toolbox. (1) If $p>0$, then $\lim_{n\to \infty} n^{-p} = 0$. (2) If $p>0$ then $\lim_{n\to\infty} p^{1/n} = 1$. (3) $\lim_{n\to \infty} n^{1/n} = 1$.
