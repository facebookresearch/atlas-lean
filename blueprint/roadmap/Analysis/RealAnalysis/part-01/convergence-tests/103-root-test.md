# Theorem (Root test) (Convergence tests) (2)

Let $\sum x_n$ be a series and suppose that $L = \lim_{n\to \infty} |x_n|^{1/n}$ exists. Then, (1) if $L<1$ then $\sum x_n$ converges absolutely; (2) if $L>1$ then $\sum x_n$ diverges.
