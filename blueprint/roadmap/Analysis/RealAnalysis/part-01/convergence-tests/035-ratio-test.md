# Theorem (Ratio test) (Convergence tests) (1)

Suppose $x_n \neq 0$ for all $n$ and $L = \lim_{n\to \infty} \frac{|x_{n+1}|}{|x_n|}$ exists. Then, (1) if $L<1$ then $\sum x_n$ converges absolutely; (2) if $L>1$ then $\sum x_n$ diverges.
