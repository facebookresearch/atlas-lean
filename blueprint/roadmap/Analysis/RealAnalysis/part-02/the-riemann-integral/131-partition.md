# Definition (Partition) (The Riemann Integral)

A partition $\underline{x}$ of $[a,b]$ is a finite set $\underline{x} = \{a= x_0 < x_1\lt \dots \lt x_n = b\}.$ The norm of $\underline{x}$, denoted $\lVert \underline{x}\rVert$, is the number $\lVert \underline{x}\rVert \coloneqq \max\{x_1-x_0, x_2-x_1,\dots, x_n-x_{n-1}\}.$
