# Definition (Tag) (The Riemann Integral section)

If $\underline{x}$ is a partition, a tag of $\underline{x}$ is a finite set $\underline{\xi} = \{\xi_1,\dots, \xi_n\}$ such that $a = x_0 \leq \xi_1\leq x_1\leq \xi_2\leq x_2\leq \dots \leq x_{n-1}\leq \xi_n \leq x_n = b.$ The pair $(\underline{x},\underline{\xi})$ is referred to as a tagged partition.
