# Theorem (Some Special Sequences) (Lecture 9)

The following hold: (1) If $p>0$, then $\lim_{n\to \infty} n^{-p} = 0$. (2) If $p>0$ then $\lim_{n\to\infty} p^{1/n} = 1$. (3) $\lim_{n\to \infty} n^{1/n} = 1$.
