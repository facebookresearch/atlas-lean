# Definition (Ordered field) (Lecture 4)

A field $F$ is an ordered field if $F$ is also an ordered set with ordering $<$ and (i) $\forall x,y,z\in F$, $x\lt y\implies x+z\lt y+z$. (ii) If $x>0$ and $y>0$ then $xy>0$. If $x>0$ we say $x$ is positive, and if $x\geq 0$ we say $x$ is non-negative.
