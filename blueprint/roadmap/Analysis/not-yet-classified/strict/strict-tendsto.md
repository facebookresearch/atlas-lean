# Convergence in the strict topology

Let `A` be a nonunital complex C*-algebra and `M(A)` its
multiplier algebra. For `a ∈ A`, strict convergence tests the two coefficient products `a T` and `T
a` in the norm of `A`. For a filter `l` on an arbitrary set `X`, a function `f : X → M(A)` converges
strictly to `T` when it tends to the strict neighborhood filter of `T`.
