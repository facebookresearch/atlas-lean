# Small-noise bound for Tikhonov regularization

Let $A : H \to K$ be a bounded linear map between real Hilbert spaces with adjoint $A^*$. Suppose $x^\dagger = A^* w$, $b = A x^\dagger$, $\|b^\delta - b\| \le \delta$, $\lambda > 0$, and $x_\lambda$ solves $(A^* A + \lambda I)\, x_\lambda = A^* b^\delta$. Then

$$\|x_\lambda - x^\dagger\| \le \frac{\delta}{2\sqrt\lambda} + \frac{\sqrt\lambda\,\|w\|}{2}.$$
