# Rodrigues matrix of an axis-angle rotation

For a unit axis $u \in \mathbb{R}^3$, $u_0^2 + u_1^2 + u_2^2 = 1$, and an angle $\theta$, the rotation matrix of the quaternion $\cos(\theta/2) + \sin(\theta/2)(u_0 i + u_1 j + u_2 k)$ is the Rodrigues matrix $\cos\theta\, I + \sin\theta\,[u]_\times + (1 - \cos\theta)\,uu^{\mathsf T}$.
