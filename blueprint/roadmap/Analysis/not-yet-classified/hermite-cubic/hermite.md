# Hermite cubic

For a length $L$, end values $v_1, v_2$ and end slopes $t_1, t_2$, the Hermite cubic $H(x) = (2s^3 - 3s^2 + 1)v_1 + s^2(3 - 2s)v_2 + (s^3 - 2s^2 + s)Lt_1 + (s^3 - s^2)Lt_2$ with $s = x/L$, where $s = 0$ when $L = 0$ by the convention $x/0 = 0$. For $L \ne 0$ it is the cubic on $[0, L]$ with those end values and end slopes.
