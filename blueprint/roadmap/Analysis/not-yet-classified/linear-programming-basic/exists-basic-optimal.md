# A linear program attaining its minimum attains it at a basic point

Let $L$ be a linear map on real vectors indexed by a finite set, $\varphi$ a linear objective, and $c$ a target. If $z \ge 0$ with $Lz = c$ minimizes $\varphi$ over $\{z' \ge 0 : Lz' = c\}$, then there is a minimizer $z'$ with $z' \ge 0$, $Lz' = c$, $\varphi(z') = \varphi(z)$ that is basic: the only $d$ with $Ld = 0$ and $d_i = 0$ wherever $z'_i = 0$ is $d = 0$.
