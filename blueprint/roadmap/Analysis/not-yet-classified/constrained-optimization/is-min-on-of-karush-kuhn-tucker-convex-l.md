# Convex KKT sufficiency with affine equality constraints

Let $E$ be a real normed space, $f$ and $g_1, \dots, g_m$ convex on $E$ and differentiable at $x$, and $\ell_1, \dots, \ell_p$ continuous linear functionals with constants $c_j$ such that $\ell_j(x) + c_j = 0$ for all $j$. Suppose $\lambda_i \ge 0$, $\lambda_i g_i(x) = 0$, and
$$Df(x) + \sum_i \lambda_i Dg_i(x) + \sum_j \mu_j \ell_j = 0.$$
Then $x$ minimizes $f$ on $\{y : g_i(y) \le 0 \text{ for all } i,\ \ell_j(y) + c_j = 0 \text{ for all } j\}$.
