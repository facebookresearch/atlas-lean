# A uniform bound controls the weighted seminorm

Let 𝕜 be a real or complex scalar field and E a normed 𝕜-vector space. Write s(𝕜,E) for the
sequences f : ℕ → E such that pₖ(f) = supₙ (n+1)^k‖fₙ‖ is finite for every k ∈ ℕ. Let k ∈ ℕ, f
∈ s(𝕜,E) and C ≥ 0. If (n+1)^k‖fₙ‖ ≤ C for every n, then pₖ(f) ≤ C.
