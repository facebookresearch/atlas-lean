# Convergence in every weighted supremum seminorm

Let 𝕜 be a real or complex scalar field and E a normed 𝕜-vector space. Write s(𝕜,E) for the
sequences f : ℕ → E such that pₖ(f) = supₙ (n+1)^k‖fₙ‖ is finite for every k ∈ ℕ. Equip s(𝕜,E)
with the locally convex topology generated by the seminorms pₖ. For a filter l on a set X, u :
X → s(𝕜,E) and f ∈ s(𝕜,E), one has u → f along l if and only if, for every k and ε > 0,
eventually pₖ(u(x)−f) < ε. Thus all polynomial weights converge uniformly.
