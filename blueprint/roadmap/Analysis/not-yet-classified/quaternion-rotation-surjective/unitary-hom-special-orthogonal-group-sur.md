# Unit quaternions map onto SO(3)

Let $\mathbb{H}$ be the real quaternions. Each unit quaternion $u$ acts on the pure imaginary quaternions $\mathbb{R}^3 \cong \{x \in \mathbb{H} : \operatorname{Re} x = 0\}$ by conjugation $x \mapsto u\,x\,u^{-1}$; let $\rho(u) \in SO(3)$ be the matrix of this action, so that $\rho$ is a group homomorphism from the unit quaternions to $SO(3)$. The homomorphism $\rho$ is surjective: every $3 \times 3$ special orthogonal real matrix is $\rho(u)$ for some unit quaternion $u$.
