# Ultraweak closure of a bounded-operator set

Let `H` be a complex normed inner-product
space, with no completeness assumption. Write `ℓ²(H)=lp (fun _ : ℕ => H) 2` for its
square-summable vector sequences. For `x,y ∈ ℓ²(H)`, put `ω_(x,y)(T)=Σ_n ⟨y_n,T x_n⟩`.
`OperatorUltraweak.closure A` is the closure of `A ⊆ B(H)` in the topology generated by
all square-summable coefficients.
