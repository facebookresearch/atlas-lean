# Bounded operator underlying a spatial tensor element

Let `H,K` be complete complex
Hilbert spaces, `M ⊆ B(H)` and `N ⊆ B(K)` concrete von Neumann algebras. Write
`L=Completion (H ⊗[ℂ] K)` for their Hilbert tensor product, and `x⊗y` for the bounded
factor operator on `L`. for `x ∈ M`, `y ∈ N`, the operator underlying `spatialTensor M N x
y` is `TensorProduct.mapLCompletion x y=x⊗y`.
