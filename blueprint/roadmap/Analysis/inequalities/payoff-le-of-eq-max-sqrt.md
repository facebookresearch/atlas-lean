# The one-step payoff has a unique maximiser

Let $b > 0$, let $m_+, m_-$ be real numbers, $D = m_+ - m_-$ (of any sign), and $s = \max(0, \sqrt{bD} - b)$, where
$\sqrt{t} = 0$ for $t < 0$. For every stake $a \ge 0$, the payoff $F(a) = -a + \dfrac{a m_+ + b m_-}{a + b}$
satisfies $F(a) \le F(s)$, and $F(a) = F(s)$ only if $a = s$. The maximiser is interior when $D > b$ and is $0$ when
$D \le b$.
