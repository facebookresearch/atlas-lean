# The first-order equation holds at the maximiser exactly when $D \ge b$

Let $b > 0$, let $m_+, m_-$ be real numbers, $D = m_+ - m_-$ (of any sign), and $s = \max(0, \sqrt{bD} - b)$, where
$\sqrt{t} = 0$ for $t < 0$. Then $(s + b)^2 = bD$ if and only if $b \le D$; this includes the boundary case $D = b$,
where $s = 0$. This is the algebraic equation, not a statement about derivatives.
