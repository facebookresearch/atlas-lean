# C

The constant $C(g) = \tfrac{8g}{\pi}\bigl(1 + 2g^2 \log(4g)\bigr)$ of Pazuki's Remark 1.2,
bounding the period term by the matrix lemma.

## Sources

- F. Pazuki, *Theta height and Faltings height*, Bull. Soc. Math. France 140 (2012), 19–49, <https://doi.org/10.24033/bsmf.2623>, Remark 1.2, p. 21.
