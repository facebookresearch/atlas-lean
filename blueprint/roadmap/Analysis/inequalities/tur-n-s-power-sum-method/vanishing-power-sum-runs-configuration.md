# Erdős Problem 974 on runs of vanishing power sums

Erdős Problem 974 (Turán's conjecture): for every $N \ge 1$ and all $z_1, \dots, z_N \in \mathbb{C}$ with
$z_1 = 1$, write $s_k = \sum_i z_i^k$ (so $s_0 = N$). If there are infinitely many $k \ge 0$ with
$s_k = s_{k+1} = \dots = s_{k+N-2} = 0$, that is, infinitely many starts of a run of $N - 1$ consecutive
vanishing power sums, then $z_1, \dots, z_N$ form a
[Tijdeman configuration on the unit circle](is-turan-configuration.md). For $N = 1$ the run is empty and the
hypothesis holds trivially.

Its resolution: [Tijdeman's theorem on runs of vanishing power sums](vanishing-power-sum-runs-configuration-h.md).
