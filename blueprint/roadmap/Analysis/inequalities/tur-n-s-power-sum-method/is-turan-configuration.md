# Tijdeman's configurations on the unit circle

The configuration in Tijdeman's theorem, for complex numbers $z_1, \dots, z_N$. If $N$ is odd, the set of
values $\{z_1, \dots, z_N\}$ is exactly the set of $N$-th roots of unity. If $N$ is even, there is a
$c \in \mathbb{C}$ with $|c| = 1$ and $c \ne 1$ such that $\{z_1, \dots, z_N\}$ is the union of the
$(N/2)$-th roots of $1$ and the $(N/2)$-th roots of $c$: the vertices of two distinct regular $(N/2)$-gons
inscribed in the unit circle, one of them containing $1$. These are configurations on the unit circle, not in
general configurations of roots of unity: for $N = 2$ the predicate allows $\{1, c\}$ for any $|c| = 1$ with
$c \ne 1$. For $N > 0$ the prescribed set has exactly $N$ elements, so the $z_i$ are distinct.
