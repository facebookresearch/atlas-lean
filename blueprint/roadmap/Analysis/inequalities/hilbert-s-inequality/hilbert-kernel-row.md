# Row integrand for the Hilbert kernel

For $M \in \mathbb{R}$, the row integrand is $x \mapsto \dfrac{1}{(M + x)\sqrt{x}}$, used to bound the row sums of the
Hilbert kernel by an integral. It is read as $0$ where the denominator vanishes, and for $x < 0$ the square root is
taken to be $0$, so the function vanishes for $x \le 0$.
