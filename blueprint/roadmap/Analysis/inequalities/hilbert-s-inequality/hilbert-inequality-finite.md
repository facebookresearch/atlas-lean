# Finite Hilbert inequality

For nonnegative real sequences $(a_n)_{n \ge 0}$, $(b_n)_{n \ge 0}$ and every $N \in \mathbb{N}$,

$$
\sum_{m=0}^{N-1} \sum_{n=0}^{N-1} \frac{a_m b_n}{m + n + 2} \le
\pi \Bigl(\sum_{m=0}^{N-1} a_m^2\Bigr)^{1/2} \Bigl(\sum_{n=0}^{N-1} b_n^2\Bigr)^{1/2}.
$$

It follows from the Schur test with the weights $r_n = 1/\sqrt{n + 1}$ and the row sum bound for the Hilbert kernel.
