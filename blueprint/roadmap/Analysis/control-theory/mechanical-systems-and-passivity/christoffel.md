# First-kind Christoffel symbols of a mass matrix

For an index set $\iota$ and a derivative tensor $D : \iota^3 \to \mathbb{R}$, where $D_{ijk}$ stands for the derivative of the mass-matrix entry $M_{ij}$ along coordinate $k$, the Christoffel symbol of the first kind is

$$\Gamma_{ijk} = \tfrac12\big(D_{ijk} + D_{ikj} - D_{jki}\big).$$
