# Christoffel correction matrix

For a finite index set $\iota$, a derivative tensor $D : \iota^3 \to \mathbb{R}$ and a velocity $v \in \mathbb{R}^\iota$, the Christoffel correction matrix is $C(v)_{ij} = \sum_k \Gamma_{ijk}\,v_k$, where $\Gamma_{ijk} = \tfrac12(D_{ijk} + D_{ikj} - D_{jki})$ is the [Christoffel symbol](christoffel.md).
