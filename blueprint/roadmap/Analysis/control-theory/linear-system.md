# Single-input single-output linear time-invariant system

A single-input single-output linear time-invariant system with state space $\mathbb{R}^n$, for an index
set $n$, consists of a state matrix $A \in \mathbb{R}^{n \times n}$, an input vector $b \in \mathbb{R}^n$,
an output functional $c \in \mathbb{R}^n$ and a direct feedthrough $d \in \mathbb{R}$; it describes
$\dot x = A x + u b$, $y = c \cdot x + d u$.
