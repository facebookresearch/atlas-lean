# Time-invariant linear systems

Let $T$ be a time set with subtraction and $S$ a linear map from signals $T \to E$ to signals $T \to F$. The system $S$ is time invariant when it commutes with every time shift: $S(\sigma_a x) = \sigma_a(Sx)$ for every $a \in T$ and every signal $x$, where $(\sigma_a x)(t) = x(t - a)$.
