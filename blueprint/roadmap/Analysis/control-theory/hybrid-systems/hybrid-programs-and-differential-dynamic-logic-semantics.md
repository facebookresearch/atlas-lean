# Hybrid programs and differential dynamic logic semantics

Hybrid programs are generated by $x := e$, nondeterministic assignment $x := *$, tests $?Q$, continuous evolution
$x' = f(x) \,\&\, Q$, $\alpha;\beta$, $\alpha \cup \beta$ and $\alpha^*$; differential dynamic logic extends first-order real arithmetic with
$[\alpha]P$ and $\langle \alpha \rangle P$. States assign real numbers to variables. Programs denote reachability relations: assignment
$x := e$ changes only $x$, to the value of $e$ in the initial state; nondeterministic assignment $x := *$ relates $s$ to every state
that agrees with $s$ except possibly at $x$; a test relates a state to itself when $Q$ holds; continuous evolution relates $s$ to $t$ when some
solution $\varphi : [0, r] \to$ states of the differential equation, of any duration $r \ge 0$, starts at $s$, ends at $t$, changes only the
evolving variables and satisfies $Q$ throughout; composition, choice and iteration are relational composition, union and
reflexive-transitive closure. $[\alpha]P$ holds at $s$ when $P$ holds at every $\alpha$-successor of $s$, and $\langle \alpha \rangle P$ when it
holds at some.
