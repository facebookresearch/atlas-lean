# Point-to-point reachability for linear dynamical systems under floating-point rounding is undecidable

When a rational matrix is applied repeatedly to a vector and every coordinate is rounded to a floating-point number after each step, no algorithm decides whether a given target vector appears in the rounded orbit, although without rounding point-to-point reachability is decidable in polynomial time.

**Setting.** A $d$-dimensional linear dynamical system $(M, x)$ consists of $M \in \mathbb Q^{d \times d}$ and $x \in \mathbb Q^d$. For a precision $p \in \mathbb N$, a floating-point number is $\pm m \cdot 10^\alpha$ with $\alpha \in \mathbb Z$ and mantissa $m \in \{0\} \cup [0.1, 1)$ having $p$ decimal digits after the point (the source writes the mantissa without a sign, but its sign-preserving rounding sends negative reals to negative values, so negative floating-point numbers are included); the rounding $[y]$ of a real $y$ is the closest floating-point number with precision $p$ based on the first $p + 1$ digits of $y$, with any fixed deterministic choice on ties for which the rounding has the following four properties, and it acts on vectors coordinatewise: it is *log-bounded*, that is, there is a constant $c > 0$ with $|y|/c \le |[y]| \le c|y|$ for every real $y$; *mantissa-based*, that is, $[10^\alpha y'] = 10^\alpha [y']$ for every real $y'$ and every $\alpha \in \mathbb Z$; *$(p+1)$-finite*, that is, writing a nonzero real as $y = m \cdot 10^\alpha$ with $\alpha \in \mathbb Z$ and $|m| \in [0.1, 1)$, $[y]$ does not depend on the digits of $m$ after the $(p+1)$-st: two reals with the same sign and the same exponent $\alpha$ whose mantissas agree in their first $p + 1$ digits have the same rounding; and *sign preserving*, that is, $[y]$ has the sign of $y$ (so $[y] = 0$ exactly when $y = 0$). The *rounded orbit* is the sequence $x^{(0)} = [x]$, $x^{(t)} = [M x^{(t-1)}]$ for $t \ge 1$.

**Theorem (Lefaucheux, Ouaknine, Purser and Sharifi).** The floating-point point-to-point reachability problem is undecidable: no algorithm decides, given a linear dynamical system $(M, x)$ and a target $y \in \mathbb Q^d$, whether $y$ belongs to the rounded orbit.

The reduction uses precision $p = 1$ in base $10$ and matrices with negative entries. For non-negative matrices the same paper proves the full model-checking problem against semialgebraic predicates and $\omega$-regular specifications decidable.

## Proof sketch

The proof reduces the halting problem for two-counter Minsky machines started with both counters at $0$. For each state $j$ the linear dynamical system has variables $x_j$, $y_j$ and $a_j$, with copies and temporary variables for the steps of the filter functions below. While the machine is in state $j$ with counter values $x$ and $y$, $x_j = 10^x$, $y_j = 10^y$ and $a_j = 10^{x+y}$, and the variables of every other state are $0$; so at the end of each simulated machine step every one of these variables is $0$ or a power of $10$ (Appendix A writes $10^c$ for the floating-point number $0.1 \cdot 10^{c+1}$), while the temporary variables inside a filter step can hold other values such as $2 \cdot 10^c$. Each machine step takes exactly four steps of the system. An increment or decrement of $x$ multiplies $x_i$ and $a_i$ by $10$ or by $10^{-1}$ and moves the three values to the next state. Branching on a zero test uses filter functions: $\mathrm{filter}^+(u, v)$ is $v$ if $v \ge u$ and $0$ otherwise, $\mathrm{filter}^-(u, v)$ is $v$ if $v < u$ and $0$ otherwise, and for $u, v$ powers of $10$ they are computed by three and four linear operations with rounding (for example $u + v$, then subtracting $u$, then multiplying by $1.1$), which needs negative coefficients. A zero test on $x$ in state $i$ routes $x_i$ by comparing it with $10$, $y_i$ by comparing it with $a_i$ (since $y_i \ge a_i$ exactly when $x = 0$) and $a_i$ by comparing it with $10 \cdot y_i$, sending the three values to the variables of the successor state for $x = 0$ or to those of the other successor. The halting state sets every variable to $0$ at the next step, so the machine halts if and only if the rounded orbit from $x_1 = y_1 = a_1 = 1$, all other coordinates $0$, reaches the zero vector, which is the target.
