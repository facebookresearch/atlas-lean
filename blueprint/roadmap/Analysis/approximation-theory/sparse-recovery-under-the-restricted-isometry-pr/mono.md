# Monotonicity of the restricted isometry property

Let $\iota$ be a finite index set and $\Phi \in \mathbb{R}^{m \times \iota}$. If $\Phi$ has the
[restricted isometry property](has-rip.md) of order $s$ with constant $\delta$, then it has it of
every order $s' \le s$ with every constant $\delta' \ge \delta$; in particular
$\delta_{s'} \le \delta_s$.
