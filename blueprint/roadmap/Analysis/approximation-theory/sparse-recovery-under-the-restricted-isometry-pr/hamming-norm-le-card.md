# A vector supported on a set $T$ is $|T|$-sparse

Let $\iota$ be a finite index set, $T \subseteq \iota$ and $x \in \mathbb{R}^\iota$ with $x_j = 0$ for
every $j \notin T$. Then $x$ has at most $|T|$ nonzero entries.
