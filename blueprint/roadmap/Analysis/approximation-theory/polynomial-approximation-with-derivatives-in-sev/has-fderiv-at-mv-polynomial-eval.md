# Derivative of a polynomial function via formal partial derivatives

For every real polynomial `p` in `n` variables and every point `x ∈ ℝⁿ`, the polynomial function
`y ↦ p(y)` has derivative at `x` the linear map `h ↦ ∑_{i < n} (∂p/∂Xᵢ)(x) hᵢ`, where
`∂p/∂Xᵢ` is the formal (algebraic) partial derivative of `p` in the variable `Xᵢ`.
