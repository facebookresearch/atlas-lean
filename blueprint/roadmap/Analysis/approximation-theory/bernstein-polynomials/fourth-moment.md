# Fourth central moment of the Bernstein weights

For every integer $n \ge 1$ and every $x \in [0, 1]$, with the Bernstein weights
$b_{n,k}(x) = \binom{n}{k} x^k (1 - x)^{n-k}$,

$$\sum_{k=0}^{n} \Big(x - \frac{k}{n}\Big)^4 b_{n,k}(x) = \frac{x(1 - x)\big(1 + 3(n - 2)\, x (1 - x)\big)}{n^3},$$

that is, $\mathbb{E}[(S - nx)^4] = n x (1 - x)\big(1 + 3(n - 2)\, x(1 - x)\big)$ for $S$ binomial
with parameters $n$ and $x$.
