# Rank sum le card

Let $K$ be a field, let $m$ be any row index set and $n$ a finite column index set, let $s$ be a finite set, and let $M_i \in K^{m \times n}$ for $i \in s$ with $\operatorname{rank} M_i \le 1$ for every $i \in s$. Then

$$\operatorname{rank}\Bigl(\sum_{i \in s} M_i\Bigr) \le \lvert s \rvert.$$
