# Definition 2.0.1 (Class Meeting #24, Section 2 (Burger's Equation))

Let $u$ be a solution of. The characteristic curves associated to $u$ are the solutions to the following system of ODEs: $\frac{d}{ds} \gamma^{0} = 1$ and $\frac{d}{ds} \gamma^{1} = u \circ \gamma = u(\gamma^{0}(s), \gamma^{1}(s))$.
