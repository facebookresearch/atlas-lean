# Definition 7.2.1 (Vectorfield)

A vectorfield $\mathbf{F}$ on $\Omega \subset \mathbb{R}^{n}$ is an $\mathbb{R}^{n}$-valued (i.e. vector-valued) function defined on $\Omega$. That is, $\mathbf{F}: \Omega \rightarrow \mathbb{R}^{n}$, $\mathbf{F}\left(x^{1}, \cdots, x^{n}\right) = \left(F^{1}\left(x^{1}, \cdots, x^{n}\right), \cdots, F^{n}\left(x^{1}, \cdots, x^{n}\right)\right)$, where each of the $F^{i}$ are scalar-valued functions on $\mathbb{R}^{n}$.
