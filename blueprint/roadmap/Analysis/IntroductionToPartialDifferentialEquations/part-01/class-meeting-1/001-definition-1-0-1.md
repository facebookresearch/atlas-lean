# Definition 1.0.1 (Class Meeting #1, Section 1)

A PDE in a single unknown $u$ is an equation involving $u$ and its partial derivatives. All such equations can be written as $F\left(u, u_{x^{1}}, \cdots, u_{x^{n}}, u_{x^{1} x^{1}}, \cdots, u_{x^{i_{1} \cdots x^{i} N}}, x^{1}, x^{2}, \cdots, x^{n}\right)=0, \quad i_{1}, \cdots, i_{N} \in\{1,2, \cdots, n\}$ for some function $F$. Here $N$ is called the order of the PDE. $N$ is the maximum number of derivatives appearing in the equation.
