# Definition 4.0.2

A linear differential operator $\mathcal{L}$ is a differential operator such that $\mathcal{L}(a u+b v)=a \mathcal{L} u+b \mathcal{L} v$ for all constants $a, b \in \mathbb{R}$ and all functions $u, v$.
