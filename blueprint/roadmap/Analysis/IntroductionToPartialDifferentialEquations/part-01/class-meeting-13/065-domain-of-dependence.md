# Definition 3.0.5 (Domain of dependence)

Let $\Omega \subset \mathbb{R}^{1+n}$. Assume that $\phi$ is a solution to the wave equation in $\Omega$. A domain of dependence for $\Omega$ is a set $S$ such that $\phi$ is completely determined on $\Omega$ from only the data $\left.\phi\right|_{S}$ and $\left.\nabla_{t,x} \phi\right|_{S}$.
