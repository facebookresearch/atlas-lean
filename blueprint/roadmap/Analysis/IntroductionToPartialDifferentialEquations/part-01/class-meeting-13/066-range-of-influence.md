# Definition 3.0.6 (Range of influence)

Assume that $\phi$ is a solution to the wave equation in $\mathbb{R}^{1+n}$. The range of influence $\mathcal{R}$ for a set $S \subset \mathbb{R}^{1+n}$ is the set of all points $(t,x) \in \mathbb{R}^{1+n}$ such that $\phi(t,x)$ is affected by the initial data $\left.\phi\right|_{S}$ and $\left.\nabla_{t,x} \phi\right|_{S}$.
