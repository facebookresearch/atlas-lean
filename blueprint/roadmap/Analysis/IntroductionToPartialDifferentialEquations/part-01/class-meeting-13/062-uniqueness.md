# Corollary 2.0.4 (Uniqueness)

Suppose that two $C^{2}$ solutions $\phi_{1}$ and $\phi_{2}$ to the wave equation have the same initial data on $B_{R}(p) \subset \{(\tau,y) \mid \tau=0\}$. Then the two solutions agree on the solid backwards light cone $\mathcal{C}_{p;R} \coloneqq \{(\tau,y) \mid 0 \leq \tau \leq R, 0 \leq |y-p| \leq R-\tau\}$.
