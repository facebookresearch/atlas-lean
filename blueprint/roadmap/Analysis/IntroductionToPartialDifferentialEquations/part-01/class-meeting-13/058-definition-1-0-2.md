# Definition 1.0.2 (Class Meeting #13, Section 1)

Given any vectorfield $X$, we associate to it the following compatible current, which is itself a vectorfield: ${}^{(X)} J^{\mu} \coloneqq T^{\mu \alpha} X_{\alpha}$.
