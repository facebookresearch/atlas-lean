# Definition 1.0.1 (Class Meeting #13, Section 1)

The energy-momentum tensor associated to equation $\square_{m} \phi=0$ is $T_{\mu \nu} \coloneqq \partial_{\mu} \phi \partial_{\nu} \phi-\frac{1}{2} m_{\mu \nu}(m^{-1})^{\alpha \beta} \partial_{\alpha} \phi \partial_{\beta} \phi$.
