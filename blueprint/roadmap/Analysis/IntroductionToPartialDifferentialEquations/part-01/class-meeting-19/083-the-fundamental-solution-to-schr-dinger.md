# Definition 2.0.1 (The Fundamental Solution to Schrödinger's equation)

The fundamental solution associated to $i\partial_{t}\psi(t,x) + \frac{1}{2}\Delta\psi(t,x) = V(t,x)\psi(t,x)$ is the function $K(t,x) = \frac{1}{(2\pi it)^{n/2}} e^{i\frac{|x|^{2}}{2t}}$.
