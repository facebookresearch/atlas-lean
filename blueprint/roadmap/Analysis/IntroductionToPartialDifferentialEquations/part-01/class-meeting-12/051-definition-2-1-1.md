# Definition 2.1.1

A Lorentz transformation is a linear transformation $\Lambda^{\mu}{}_{\nu}$ (i.e., a matrix) that preserves the form of the Minkowski metric $m_{\mu \nu} \coloneqq \operatorname{diag}(-1,1,1, \cdots, 1)$:
$$\Lambda_{\mu}^{\alpha} \Lambda_{\nu}^{\beta} m_{\alpha \beta}=m_{\mu \nu}.$$
In standard matrix notation, this reads $\Lambda^{T} m \Lambda=m$, where $T$ denotes the transpose.
