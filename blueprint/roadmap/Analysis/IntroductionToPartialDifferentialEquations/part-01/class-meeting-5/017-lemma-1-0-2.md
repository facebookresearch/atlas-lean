# Lemma 1.0.2

$\Gamma_{D}(t, x)$ has the following properties: (1) If $x \neq 0$, then $\lim_{t \rightarrow 0^{+}} \Gamma_{D}(t, x)=0$. (2) $\lim_{t \rightarrow 0^{+}} \Gamma_{D}(t, 0)=\infty$. (3) $\int_{\mathbb{R}^{n}} \Gamma_{D}(t, x) d^{n} x=1$ for all $t>0$.
