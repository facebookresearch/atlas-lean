# Definition 1.0.2 (Class Meeting #5, Section 1 (The Fundamental solution))

The delta distribution $\delta$ is an example of a mathematical object called a distribution. It acts on suitable functions $\phi(x)$ as follows: $\langle\delta, \phi\rangle \coloneqq \phi(0)$.
