# Definition 1.0.1 (Class Meeting #5, Section 1 (The Fundamental solution))

The fundamental solution $\Gamma_{D}(t, x)$ to the inhomogeneous heat equation $u_{t}-D \Delta u=f$ is defined to be $\Gamma_{D}(t, x) \coloneqq \frac{1}{(4 \pi D t)^{n/2}} e^{-\frac{|x|^{2}}{4 D t}}$, for $t>0, x \in \mathbb{R}^{n}$, where $x \coloneqq(x^{1}, \cdots, x^{n})$, $|x|^{2} \coloneqq \sum_{i=1}^{n}(x^{i})^{2}$.
