# Lemma 1.0.3

Suppose that $\phi(x)$ is a continuous function on $\mathbb{R}^{n}$ and that there exist constants $a, b \geq 0$ such that $|\phi(x)| \leq a e^{b|x|^{2}}$. Then $\lim_{t \rightarrow 0^{+}} \int_{\mathbb{R}^{n}} \Gamma_{D}(t, x) \phi(x) d^{n} x=\phi(0)$.
