# Corollary 1.0.2 (Representation formula for $\widetilde{U}(t, r ; x)$)

Under the assumptions of Proposition 1.0.1, for $0 \leq r \leq t$, we have that
$$\widetilde{U}(t, r ; x) \coloneqq r U(t, r ; x)=\frac{1}{2}(\widetilde{F}(r+t ; x)-\widetilde{F}(r-t ; x))+\frac{1}{2} \int_{\rho=-r+t}^{\rho=r+t} \widetilde{G}(\rho ; x) d \rho.$$
