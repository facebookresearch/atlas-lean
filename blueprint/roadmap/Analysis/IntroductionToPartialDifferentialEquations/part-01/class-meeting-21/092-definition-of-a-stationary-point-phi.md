# Definition 1.0.5 (Definition of a stationary point $\phi$)

We say that $\phi$ is a stationary point of the action if the following relation holds for all compact subsets $\mathfrak{K}$ and all variations $\psi \in C_{c}^{\infty}(\mathfrak{K})$: $$\left.\frac{d}{d\epsilon}\right|_{\epsilon=0} \mathcal{A}[\phi_{\epsilon}; \mathfrak{K}]=0.$$
