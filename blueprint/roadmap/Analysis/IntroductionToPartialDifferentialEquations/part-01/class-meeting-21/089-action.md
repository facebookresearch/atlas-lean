# Definition 1.0.2 (Action)

Let $\mathfrak{K} \subset \mathbb{R}^{1+n}$ be a compact subset of spacetime. We define the action $\mathcal{A}$ of $\phi$ over the set $\mathfrak{K}$ by $$\mathcal{A}[\phi; \mathfrak{K}] \coloneqq \int_{\mathfrak{K}} \mathcal{L}(\phi(x), \nabla \phi(x)) d^{1+n} x.$$ Above, $d^{1+n} x \coloneqq d t\, d x^{1}\, d^{2} \cdots d x^{n}$ denotes spacetime integration.
