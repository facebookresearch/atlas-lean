# Definition 1.1.1

If $f$ and $g$ are two functions on $\mathbb{R}^{n}$, then we define their convolution $f * g$ to be the following function on $\mathbb{R}^{n}$: $(f * g)(x) \coloneqq \int_{\mathbb{R}^{n}} f(y) g(x-y) d^{n} y$.
