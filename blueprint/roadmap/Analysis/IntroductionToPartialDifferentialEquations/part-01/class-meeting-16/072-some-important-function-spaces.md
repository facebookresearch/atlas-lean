# Definition 1.0.4 (Some important function spaces)

$C^{k} \coloneqq \{f: \mathbb{R}^{n} \rightarrow \mathbb{C} \mid \partial_{\vec{\alpha}} f \text{ is continuous for } |\vec{\alpha}| \leq k\}$; $C_{0} \coloneqq \{f: \mathbb{R}^{n} \rightarrow \mathbb{C} \mid f \text{ is continuous and } \lim_{|x| \rightarrow \infty} f(x)=0\}$. We also recall the following norm on the space of bounded, continuous functions $f: \mathbb{R}^{n} \rightarrow \mathbb{C}$: $\|f\|_{C_{0}} \coloneqq \max_{x \in \mathbb{R}^{n}}|f(x)|$.
