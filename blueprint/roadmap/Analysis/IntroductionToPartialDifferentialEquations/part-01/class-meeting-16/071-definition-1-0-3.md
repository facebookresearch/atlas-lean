# Definition 1.0.3

If $\vec{\alpha} \coloneqq(\alpha^{1}, \cdots, \alpha^{n})$ is an array of non-negative integers, then we define $\partial_{\vec{\alpha}}$ to be the differential operator $\partial_{\vec{\alpha}} \coloneqq \partial_{1}^{\alpha^{1}} \cdots \partial_{n}^{\alpha^{n}}$. Note that $\partial_{\vec{\alpha}}$ is an operator of order $|\vec{\alpha}| \coloneqq \alpha^{1}+\cdots+\alpha^{n}$. If $x=(x^{1}, \cdots, x^{n})$ is an element of $\mathbb{C}^{n}$, then we also define $x^{\vec{\alpha}}$ to be the monomial $x^{\vec{\alpha}} \coloneqq(x^{1})^{\alpha^{1}} \cdots (x^{n})^{\alpha^{n}}$.
