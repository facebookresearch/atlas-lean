# Definition 2.0.6 (Translation of a function)

If $f: \mathbb{R}^{n} \rightarrow \mathbb{C}$ is a function and $y \in \mathbb{R}^{n}$ is any point, then we define the translated function $\tau_{y} f$ by $\tau_{y} f(x) \coloneqq f(x-y)$.
