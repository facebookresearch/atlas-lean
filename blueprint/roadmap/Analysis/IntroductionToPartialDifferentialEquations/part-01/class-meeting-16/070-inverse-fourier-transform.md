# Definition 1.0.2 (Inverse Fourier transform)

Given a function $f(\xi) \in L^{1}(\mathbb{R}^{n})$, its inverse Fourier transform, which is denoted by $f^{\vee}$, is a new function of $x$ defined as follows: $f^{\vee}(x) \coloneqq \hat{f}(-x) \coloneqq \int_{\mathbb{R}^{n}} f(x) e^{2 \pi i \xi \cdot x} d^{n} \xi$.
