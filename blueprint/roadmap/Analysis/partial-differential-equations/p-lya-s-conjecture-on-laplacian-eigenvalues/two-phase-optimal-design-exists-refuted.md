# Optimal two-phase designs for the first Dirichlet eigenvalue do not always exist

This settles [Existence of optimal two-phase designs for the first eigenvalue](two-phase-optimal-design-exists.md) in the negative: its statement is false.

Casado-Díaz proved that for a smooth, simply connected bounded domain $\Omega \subseteq \mathbb{R}^N$ with
connected boundary the problem has a solution if and only if $\Omega$ is a ball, so a smooth non-ball
such domain, for instance an open ellipse in $\mathbb{R}^2$, has no optimal $A$ for any $0 < \kappa < |\Omega|$ and
$0 < \alpha < \beta$.
