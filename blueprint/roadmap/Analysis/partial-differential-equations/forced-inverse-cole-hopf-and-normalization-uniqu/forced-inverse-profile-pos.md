# The forced inverse profile is positive

For all $\nu$, $u$, $F$, $t_0$, $x_0$, $t$ and $x$, the forced inverse profile

$$\varphi(t, x) = \exp\Big(\int_{t_0}^{t} r(s)\, ds - \frac{1}{2\nu} \int_{x_0}^{x} u(t, y)\, dy\Big), \qquad r(s) = \frac{u(s, x_0)^2}{4\nu} - \frac{\partial_x u(s, x_0)}{2} + F(s, x_0)$$

is strictly positive, being an exponential.
