# Potential-heat positivity and order

Exponential multiples of free heat bound the actual potential-heat evolution for nonnegative initial data. These bounds give nonnegativity and strict positivity without a uniform positive lower bound on the initial profile. Ordered initial data remain ordered, including signed data with different exponential growth rates.
