# The initial heat profile equals 1 at the anchor

For all $\nu$, $u_0 : \mathbb{R} \to \mathbb{R}$ and $x_0$, the initial heat profile $\varphi_0(x) = \exp\big(-\frac{1}{2\nu}\int_{x_0}^{x} u_0(y)\,dy\big)$ satisfies $\varphi_0(x_0) = 1$.

Division is total, with $a/0 = 0$; so for $\nu = 0$ the exponent is $0$ and the profile is identically $1$.
