# The initial heat profile is continuously differentiable

Let $u_0 : \mathbb{R} \to \mathbb{R}$ be continuous. For all $\nu, x_0$, the initial heat profile $x \mapsto \exp\big(-\frac{1}{2\nu}\int_{x_0}^x u_0(y)\, dy\big)$ is $C^1$.

Division is total, with $a/0 = 0$; so for $\nu = 0$ the exponent is $0$ and the profile is identically $1$.
