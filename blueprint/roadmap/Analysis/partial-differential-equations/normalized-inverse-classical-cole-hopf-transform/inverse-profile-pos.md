# The inverse Cole–Hopf profile is positive

For all $\nu$, $u$, $t_0$, $x_0$, $t$ and $x$, the inverse Cole–Hopf profile

$$\varphi(t, x) = \exp\Big(\int_{t_0}^{t} \Big(\frac{u(s,x_0)^2}{4\nu} - \frac{\partial_x u(s, x_0)}{2}\Big) ds - \frac{1}{2\nu} \int_{x_0}^{x} u(t, y)\, dy\Big)$$

is strictly positive, being an exponential.
