# Gaussian solution of the diffusion equation on the line

The Gaussian solution on the line with total mass `M`: `gauss M D x t = M /
√(4πDt) · exp(-x² / (4Dt))`, intended for `D > 0` and `t > 0`. For `D > 0` and
`t ≤ 0` the square root is `0` and the quotient by `0` is taken to be `0`, so
the value is `0`.
