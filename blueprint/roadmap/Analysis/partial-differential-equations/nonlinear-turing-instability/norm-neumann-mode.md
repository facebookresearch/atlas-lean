# For L ≥ 0, a Neumann mode has the sup norm of its amplitude

For real $L \ge 0$, $n \in \mathbb{N}$ and $w \in \mathbb{R}^2$, the [Neumann mode](neumann-mode.md)
$x \mapsto \cos(k_n x)\, w$ on $[0, L]$ has sup norm $\lVert w \rVert = \max(|w_0|, |w_1|)$: the
cosine takes the value $1$ at $x = 0$. For $L < 0$ the interval is empty and the mode has norm $0$.
