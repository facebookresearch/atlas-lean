# Real Neumann mode x ↦ cos(k_n x) w on an interval

For real $L$, $n \in \mathbb{N}$ and an amplitude $w \in \mathbb{R}^2$, the Neumann mode is the
continuous map $[0, L] \to \mathbb{R}^2$, $x \mapsto \cos(k_n x)\, w$, as an element of
$C([0, L], \mathbb{R}^2)$ with the sup norm. Here $k_n = n\pi/L$ is the
[Neumann wavenumber](../../../Biology/pattern-formation/turing-patterns-and-diffusion-driven-instability/neumann-wavenumber.md),
read as $0$ when $L = 0$. For $L > 0$ the derivative $-k_n \sin(k_n x)\, w$ vanishes at $x = 0$ and
$x = L$ (zero flux), and the second derivative is $-k_n^2$ times the mode. For $L < 0$ the interval
is empty.
