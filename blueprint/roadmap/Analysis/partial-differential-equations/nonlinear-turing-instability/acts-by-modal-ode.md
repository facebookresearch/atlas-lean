# Operators acting on a Neumann mode through the ODE c′ = M c

Let $L$ be real, $n \in \mathbb{N}$, $M$ a real $2 \times 2$ matrix and $S = (S(t))_{t \ge 0}$ any
family of bounded linear operators on $C([0, L], \mathbb{R}^2)$. The family acts on the Neumann mode
$n$ through the modal ODE of $M$ when for every amplitude $w \in \mathbb{R}^2$ there is a
differentiable $c : \mathbb{R} \to \mathbb{R}^2$ with $c(0) = w$ and $c'(t) = M\, c(t)$ for every
real $t$, such that

$$S(t)\bigl(\cos(k_n \cdot)\, w\bigr) = \cos(k_n \cdot)\, c(t) \qquad \text{for every } t \ge 0,$$

with $\cos(k_n \cdot)\, w$ the [Neumann mode](neumann-mode.md) and $k_n = n\pi/L$ ($0$ for every $n$
when $L = 0$, when the mode is the constant $w$ on $[0, 0]$). As $c(t) = e^{tM} w$, this says that
$S(t)$ maps $\cos(k_n \cdot)\, w$ to $\cos(k_n \cdot)\, e^{tM} w$. For the semigroup generated by
the linearization $D \Delta_N + J$ of the Turing system it holds with $M = J - k_n^2 D$, because
$\Delta_N \cos(k_n x) = -k_n^2 \cos(k_n x)$.

In the model $L > 0$; the definition is stated for every real $L$.
