# A spectral value outside the unit disc destabilizes the flow

Let $Y$ be a complex Banach space and $L$ a continuous linear operator on $Y$. Let $\Phi : \mathbb{R} \times Y \to Y$, $u_0 \in Y$, $T \ge 0$, $\rho > 0$, $C \ge 0$ and $p > 1$ satisfy: $\Phi(0, x) = x$; $\Phi((n+1)T, x) = \Phi(T, \Phi(nT, x))$ whenever $\|\Phi(kT, x) - u_0\| \le \rho$ for all $k \le n$; and $\|\Phi(T, u_0 + y) - u_0 - L y\| \le C \|y\|^p$ for $\|y\| \le \rho$. If the spectrum of $L$ contains some $z$ with $|z| > 1$, then $u_0$ is not Lyapunov stable for $\Phi$.
