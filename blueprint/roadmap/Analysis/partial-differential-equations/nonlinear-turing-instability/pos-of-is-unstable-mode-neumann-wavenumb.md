# If tr J < 0 < det J, an unstable Neumann mode has n ≥ 1

Let $J$ be a real $2 \times 2$ matrix with $\operatorname{tr} J < 0$ and $\det J > 0$ (kinetics
stable without diffusion), let $d_u, d_v, L$ be real and $n \in \mathbb{N}$. If the mode with the
[Neumann wavenumber](../../../Biology/pattern-formation/turing-patterns-and-diffusion-driven-instability/neumann-wavenumber.md)
$k_n = n\pi/L$ is
[linearly unstable](../../../Biology/pattern-formation/turing-patterns-and-diffusion-driven-instability/is-unstable-mode.md)
for $D = \operatorname{diag}(d_u, d_v)$, then $n \ge 1$: the mode $n = 0$ is the homogeneous mode
$k_0 = 0$, which is
[not unstable](../../../Biology/pattern-formation/turing-patterns-and-diffusion-driven-instability/not-is-unstable-mode-zero.md).
No sign condition on $d_u$, $d_v$ or $L$ is needed. For $L = 0$ every $k_n$ is $0$, so no Neumann
mode is then unstable.

In the model $d_u, d_v > 0$ and $L > 0$.
