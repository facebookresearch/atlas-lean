# Heat Duhamel time only

For any real function $a$, any real viscosity $\nu$ and any real $t,x$, spatially constant forcing satisfies

$$D_\nu((s,y)\mapsto a(s))(t,x)=\int_0^t a(s)\,ds.$$

This identity uses the [oriented integral and stationary extension](heat-duhamel.md); no integrability assertion is included.
