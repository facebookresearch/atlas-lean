# The interface test vanishes outside a bounded rectangle

For a bump `β` centred at `t₀` with outer radius `r_β`, a bump `θ` centred at `0` with outer radius
`r_θ`, and a real `c`, the [interface test](interface-test.md) vanishes outside the rectangle
`[t₀ - r_β, t₀ + r_β] × [-X, X]` with `X = |c| (|t₀| + r_β) + r_θ`.
