# Straight moving step between two constant states

For real numbers `u_L`, `u_R` and `c`, the moving step is the field `u(t, x) = u_L` if `x < c t` and
`u(t, x) = u_R` if `x ≥ c t`: a single jump along the line `x = c t`. Its value on that line, a null
set of the plane, does not affect the integrals in which it is used.
