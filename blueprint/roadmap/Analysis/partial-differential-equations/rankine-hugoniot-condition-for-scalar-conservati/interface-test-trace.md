# On the front the interface test is the time bump

For a bump `β` centred at `t₀` with outer radius `r_β`, a bump `θ` centred at `0` and a real `c`,
the [interface test](interface-test.md) satisfies `φ(t, c t) = β(t)` for every `t` (since
`θ(0) = 1`), the interval `(t₀ - r_β, t₀ + r_β)` is nonempty, and `φ(t, c t) > 0` on it.
