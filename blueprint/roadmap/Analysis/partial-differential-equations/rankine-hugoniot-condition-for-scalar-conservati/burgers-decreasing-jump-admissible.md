# At the Rankine–Hugoniot speed a decreasing Burgers jump is admissible

For real numbers `u_R < u_L` and `c` with `c (u_R - u_L) = f(u_R) - f(u_L)` for the
[Burgers flux](burgers-flux.md), the [entropy production](burgers-entropy-production.md) is
nonpositive and `u_R < c < u_L`: the jump satisfies the entropy inequality.
