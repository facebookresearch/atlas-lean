# The interface test has the stated time derivative

For bumps `β` (centred at `t₀`) and `θ` (centred at `0`) and all real `c`, `t` and `x`, the
[interface test](interface-test.md) `τ ↦ φ(τ, x)` has derivative
`β'(t) θ(x - c t) - c β(t) θ'(x - c t)` at `t`, the [time partial](interface-test-dt.md).
