# Weak residual of a field for a scalar conservation law

For a flux `f : ℝ → ℝ`, a field `u(t, x)` and functions `φ_t`, `φ_x` (the intended time and space
partial derivatives of a test function `φ`), the weak residual is the integral over the whole
`(t, x)` plane `∫∫ (u φ_t + f(u) φ_x) dt dx`, with respect to Lebesgue measure; the integral of a
non-integrable function is taken to be `0`.
