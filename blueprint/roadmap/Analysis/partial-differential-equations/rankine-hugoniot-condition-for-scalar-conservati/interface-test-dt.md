# Time partial derivative of the interface test

For bumps `β` (centred at `t₀`) and `θ` (centred at `0`) and real numbers `c`, `t` and `x`, the
function `β'(t) θ(x - c t) - c β(t) θ'(x - c t)`, with `β'` and `θ'` the derivatives of the bumps.
It is the [time partial derivative](has-deriv-at-interface-test-time.md) at `(t, x)` of the
[interface test](interface-test.md) `φ(t, x) = β(t) θ(x - c t)`.
