# The Burgers entropy pair is compatible and strictly convex

For every real `u`, the [Burgers flux](burgers-flux.md), the [entropy](burgers-entropy.md) and the
[entropy flux](burgers-entropy-flux.md) have derivatives `f'(u) = u`, `η'(u) = u` and
`q'(u) = u · u`, so `q' = η' f'`; and `η` is strictly convex on `ℝ`.
