# Optimal two-phase designs for the first Dirichlet eigenvalue do not always exist

Casado-Díaz proved that for a smooth, simply connected bounded domain `Ω ⊆ ℝ^N` with
connected boundary the problem has a solution if and only if `Ω` is a ball, so a smooth non-ball
such domain, for instance an open ellipse in `ℝ²`, has no optimal `A` for any `0 < κ < |Ω|` and `0 <
α < β`.

Casado-Díaz, A characterization result for the existence of a two-phase material minimizing the first eigenvalue, Ann. Inst. H. Poincaré C Anal. Non Linéaire 34 (2017), no. 5, 1215-1226, DOI 10.1016/j.anihpc.2016.09.006, abstract: for 0 < α < β, 0 < κ < |Ω| and Ω ⊂ ℝ^N smooth, simply connected and with connected boundary, minimizing the first eigenvalue of u ∈ H¹₀(Ω) ↦ -div((αχ_ω + β(1 - χ_ω))∇u) over measurable ω with |ω| ≤ κ has a solution if and only if Ω is a ball; an earlier paper of the author shows that the problem has no solution in general, https://www.sciencedirect.com/science/article/pii/S0294144916300695.
