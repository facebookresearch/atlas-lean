# Proposition 3

If $\lim_{j \to \infty} \int_{\mathbb{R}} f \, d\mu_j = \int_{\mathbb{R}} f \, d\mu$ for all $f \in C_0^{\infty}(\mathbb{R})$, then $\limsup_{j \to \infty} \mu_j((a, b)) \leq \mu([a, b])$ and $\liminf_{j \to \infty} \mu_j((a, b)) \geq \mu((a, b))$. In particular if $\mu$ is continuous then $\mu_j((a, b)) \to \mu((a, b)) = \mu([a, b])$.
