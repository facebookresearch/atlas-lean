# Lemma 1 (Section 2, An application to the central limit theorem)

$e^{ix} = 1 + ix + (ix)^2/2 + R(x)$ with $|R(x)| \leq 4 \min(|x|^2, |x|^3) \leq 4|x|^{2+\alpha}$ for all $\alpha$, $0 < \alpha < 1$.
