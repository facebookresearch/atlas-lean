# Lemma 2

If $a_k$ are mean zero variance $1$ Gaussians, then $\mathbb{E}(|a_{i_1} a_{i_2} a_{i_3} a_{i_4}|) \leq \mathbb{E}(|a_1|^4) = 3 < \infty$.
