# Lemma 5

If $F$ satisfies (5) on $|z| \leq 1$, for some $\alpha$, $0 < \alpha \leq 1$, then $F(e^{it})$ is Hölder continuous with exponent $\alpha$, that is, $|F(e^{it_1}) - F(e^{it_2})| \leq C |t_1 - t_2|^{\alpha}$.
