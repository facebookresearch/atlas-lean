# Fréchet derivatives

The Fréchet derivative and the derivative of functions of one variable over a normed field: rules
for sums, products, compositions, inverses and linear and bilinear maps, strict differentiability,
mean value inequalities, tangent cones and unique differentiability, and line (Gateaux) derivatives.
