# Tree-like paths and uniqueness of the signature

The signature forgets the parametrisation of a path, its starting point, and every excursion
that is retraced backwards. Hambly and Lyons showed that nothing more is lost: a path of bounded
variation has trivial signature exactly when it is tree-like, that is, when it factors through an
ℝ-tree, so two paths have the same signature exactly when one followed by the reverse of the other
is a Lipschitz tree-like path; every class contains a unique path of minimal length (B. Hambly and T. Lyons,
*Uniqueness for the signature of a path of bounded variation and the reduced path group*, Ann. of
Math. 171 (2010), Theorem 1 and Corollaries 1.5–1.7). Boedihardjo, Geng, Lyons and Yang extended
the theorem to weakly geometric rough paths (Adv. Math. 293 (2016), Theorem 1.1).
