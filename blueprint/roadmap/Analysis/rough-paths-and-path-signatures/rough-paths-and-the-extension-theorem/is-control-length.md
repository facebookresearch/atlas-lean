# The length of a path is a control

Let $\iota$ be a finite alphabet and let $v = (v^j)_{j \in \iota}$ be a continuous velocity. The $\ell^1$ length $\omega(s, t) = \int_s^t \sum_j |v^j(u)|\, du$ of the path between $s$ and $t$ is a [control](is-control.md) on every set of times $J \subseteq \mathbb{R}$: it is continuous, nonnegative for $s \le t$, zero on the diagonal and additive, hence superadditive.
