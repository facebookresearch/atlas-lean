# The signature is a multiplicative functional

Let $\iota$ be an index set and let $X$ be a path in $\mathbb{R}^\iota$ whose velocity coordinates $v^j$ are interval integrable on every bounded interval. Then $(s, t) \mapsto S(X)_{s,t}$, its [signature](../signature-of-a-path/signature.md), is a [multiplicative functional](is-multiplicative-functional.md) of every degree on every set of times: this is Chen's identity (T. Lyons, Rev. Mat. Iberoam. 14 (1998), §2.1, where multiplicative functionals are introduced as the abstraction of Chen's identity for iterated integrals).
