# Chen's identity, algebraic form

Let the velocity of a path $X$ be interval integrable on every interval. For all reals
$a, b, c$,

$$S(X)_{a,c} = S(X)_{a,b} \otimes S(X)_{b,c},$$

where $\otimes$ is the concatenation product of tensor series, computed coefficientwise as in
[Product of tensor series, coefficientwise](tensor-mul.md). The source notes that this has the
same content as the coordinate form, [Chen's identity](signature-chen.md).
