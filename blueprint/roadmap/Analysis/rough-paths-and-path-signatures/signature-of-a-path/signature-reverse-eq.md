# Signature of the time-reversed path over a sub-interval

Fix reals $a, b$ and let $\overleftarrow{X}_u = X_{a+b-u}$ be the time reversal of $X$, whose
velocity is $u \mapsto -v(a + b - u)$. Then for every real $t$ and every word $w$,

$$S(\overleftarrow{X})^w_{a,t} = S(X)^w_{b,\,a+b-t}.$$

In particular $S(\overleftarrow{X})_{a,b} = S(X)_{b,a}$: running the path backwards is the same as
integrating it from $b$ back to $a$. No integrability is needed: the identity follows from the
recursive definition and the substitution $r = a + b - u$.
