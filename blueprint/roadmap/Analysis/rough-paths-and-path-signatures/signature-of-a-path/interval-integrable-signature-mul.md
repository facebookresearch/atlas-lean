# Integrability of the integrand of the signature recursion

Let $X$ be a path in $\mathbb{R}^\iota$ whose velocity components $v^i$ are interval integrable on every bounded interval. Then for every real $s$, word $w$ and letter $i$, the integrand $u \mapsto S(X)^w_{s,u}\, v^i(u)$ of the recursion is interval integrable on every bounded interval.
