# Composite linear map along a word

Let $E$ be a real normed space and $(A_i)_{i \in \iota}$ a family of bounded linear maps $E \to E$. For a word $w = i_1 \cdots i_k$, the composite along $w$ is $A_w = A_{i_k} \circ \cdots \circ A_{i_1}$, the identity for the empty word: the letters act in the order in which the path visits them.
