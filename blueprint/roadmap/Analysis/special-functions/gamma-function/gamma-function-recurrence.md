# Recurrence of the gamma function

Let $\Gamma$ be the gamma function on $\mathbb{C}$: Euler's integral $\int_0^\infty t^{s-1} e^{-t} \, dt$ for
$\operatorname{Re} s > 0$, continued meromorphically to $\mathbb{C}$ and taken to be $0$ at its poles $0, -1, -2, \dots$.
Then $\Gamma(s + 1) = s \, \Gamma(s)$ for every complex number $s \neq 0$.

## Sources

- F. W. J. Olver et al. (eds.), *NIST Digital Library of Mathematical Functions*, Version 1.2.8 of 2026-09-15,
  <https://dlmf.nist.gov/5.5>, equation 5.5.1, $\Gamma(z + 1) = z \Gamma(z)$.
