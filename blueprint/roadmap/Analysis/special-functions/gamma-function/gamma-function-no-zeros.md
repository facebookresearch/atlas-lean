# The complex gamma function has no zeros away from its poles

Let $\Gamma$ be the gamma function on $\mathbb{C}$, the meromorphic continuation of $\Gamma(s) = \int_0^\infty t^{s-1} e^{-t}\, dt$ from the half-plane $\operatorname{Re}(s) > 0$. For every complex number $s$ other than $0, -1, -2, \dots$, we have $\Gamma(s) \neq 0$.
