# Christol's criterion for N-integrality of hypergeometric series

Christol's criterion (Delaygue–Rivoal–Roques, Theorem 3,
after Christol). For admissible rational parameters `α β` (no
parameter in `ℤ_{≤ 0}`), the hypergeometric series with coefficients
`pochhammerCoeff α β` is `N`-integral if and only if Christol's
counting function `christolXi α β a x` is nonnegative for every
`a ∈ {1, …, d}` coprime to the denominator lcm `d = paramDenLcm α β`
and every real `x`.

## Sources

- E. Delaygue, T. Rivoal, J. Roques, *On Dwork's `p`-adic formal congruences theorem and hypergeometric mirror maps*, Mem. Amer. Math. Soc. **246** (2017), no. 1163, Theorem 3; G. Christol, *Fonctions hypergéométriques bornées*, Groupe de Travail d'Analyse Ultramétrique **14** (1986–1987), exp. 8, 1–16.
