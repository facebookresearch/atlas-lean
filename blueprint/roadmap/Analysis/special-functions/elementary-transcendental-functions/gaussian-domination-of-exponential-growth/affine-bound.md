# Exponential growth survives bounded affine shifts

Let $f : \mathbb{R} \to \mathbb{R}$ have at most exponential growth: $|f(x)| \le M e^{c|x|}$ for some $M, c \ge 0$ and all $x$. Then for all $R, S \in \mathbb{R}$ there are $A, c' \ge 0$ with

$$|f(z - s y)| \le A\, e^{c' |y|} \quad \text{whenever } |z| \le R \text{ and } |s| \le S,$$

for every $y \in \mathbb{R}$.
