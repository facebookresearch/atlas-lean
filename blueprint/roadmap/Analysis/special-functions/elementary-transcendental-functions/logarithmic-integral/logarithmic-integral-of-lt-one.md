# The logarithmic integral below $1$

For every real number $x$ with $0 \le x < 1$, the
logarithmic integral $\mathrm{li}$ satisfies $\mathrm{li}(x) = \int_0^x \frac{dt}{\log t}$.

## Sources

- Immediate from the definition of $\mathrm{li}$ for $x < 1$; see Shane Chern, *Hitting a prime by rolling a die with infinitely many faces*, arXiv:2306.14073v1 (2023), and M. Boran, J. Byun, Z.
