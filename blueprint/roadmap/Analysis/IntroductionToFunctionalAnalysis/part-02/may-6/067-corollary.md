# Corollary (May 6, 2021)

Let $A^\ast = A \in \mathcal{B}(H)$ be a self-adjoint linear operator. Then $\langle Au, u \rangle \geq 0$ for all $u$ if and only if $\operatorname{Spec}(A) \subset [0, \infty)$.
