# Theorem (May 4, 2021)

If we have a self-adjoint operator $A \in \mathcal{B}(H)$, meaning that $A = A^\ast$, then $\langle Au, u \rangle$ is real for all $u$, and $||A|| = \sup_{||u|| = 1} |\langle Au, u \rangle|$.
