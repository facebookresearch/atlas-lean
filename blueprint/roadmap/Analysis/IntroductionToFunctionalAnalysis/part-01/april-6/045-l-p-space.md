# Definition ($L^p$ space)

For any $1 \leq p \leq \infty$, we define the $L^p$ space $L^p(E) = \left\{f: E \to \mathbb{C} \mid f \text{ measurable and } ||f||_p < \infty\right\}$, where we consider two elements $f, g$ of $L^p(E)$ to be equivalent (in other words, the same) if $f = g$ almost everywhere.
