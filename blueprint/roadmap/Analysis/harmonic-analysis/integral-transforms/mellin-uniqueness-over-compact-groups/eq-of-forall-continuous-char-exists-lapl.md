# Mellin uniqueness over a compact group

Let $C$ be a compact group with a Haar measure $\mu$ (Borel), whose continuous characters $\chi : C \to \mathbb{C}^\times$ separate points: for every $x \ne 1$ some continuous $\chi$ has $\chi(x) \ne 1$. Let $f_1, f_2 : C \times \mathbb{R} \to \mathbb{C}$ be continuous, and for every continuous character $\chi$ let $\Lambda_\chi : \mathbb{C} \to \mathbb{C}$ be entire and bounded on vertical strips. Suppose that for every continuous character $\chi$ there is $c \in \mathbb{R}$ such that

- for $\operatorname{Re} s > c$, the function $(x, t) \mapsto f_1(x, t)\, \chi(x)\, e^{s t}$ is integrable for $\mu \otimes dt$ with integral $\Lambda_\chi(s)$, and
- for $\operatorname{Re} s < -c$, the function $(x, t) \mapsto f_2(x, t)\, \chi(x)\, e^{s t}$ is integrable with integral $\Lambda_\chi(s)$.

Then $f_1 = f_2$.
