# Moment problem for compactly supported measures

A finite measure on $\mathbb{R}$ supported in a compact interval is determined by its moments
$\int x^k \, d\mu$, and moment growth of order $C R^{2k}$ forces support in $[-R, R]$. Together they
give the uniqueness half of the moment method in probability; the semicircle law of random matrix
theory is the motivating example.
