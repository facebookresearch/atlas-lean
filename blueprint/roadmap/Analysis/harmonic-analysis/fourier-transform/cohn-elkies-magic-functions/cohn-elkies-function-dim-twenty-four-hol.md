# The magic function in dimension 24

Cohn, Kumar, Miller, Radchenko and Viazovska constructed the analogous radial
Schwartz function on `ℝ²⁴` with `f(0) = f̂(0) = 1`, `f(x) ≤ 0` for `|x| ≥ 2` and `f̂ ≥ 0`, proving
that the Leech lattice gives the densest sphere packing in dimension 24.

## Sources

- A. Kumar (with H. Cohn), in Gitter und Anwendungen, Oberwolfach Reports 2 (2005), no. 1, p. 36, DOI 10.4171/OWR/2005/01; resolution: H. Cohn, A. Kumar, S. D. Miller, D. Radchenko and M. Viazovska, The sphere packing problem in dimension 24, Ann. of Math. (2) 185 (2017), arXiv:1603.06518, Section 4 (proof of Theorem 1.1): the radial Schwartz function f on ℝ²⁴ constructed there has f(0) = f̂(0) = 1 and satisfies the hypotheses of the linear programming bound, Theorem 1.2, with r = 2 (f(x) ≤ 0 for |x| ≥ 2, f̂ ≥ 0), where f̂(y) = ∫ f(x) e^\{-2πi⟨x, y⟩\} dx, https://arxiv.org/abs/1603.06518.
