# Viazovska's magic function in dimension 8

This settles [A Cohn–Elkies function in dimension 8](cohn-elkies-function-dim-eight.md) in the affirmative: its statement holds.

Viazovska constructed a radial Schwartz function $g$ on $\mathbb{R}^8$ with $g(x) \le 0$ for
$|x| \ge \sqrt{2}$, $\hat g \ge 0$ and $g(0) = \hat g(0) = 1$, proving that $E_8$ gives the densest sphere packing
in dimension 8.

## Sources

- A. Kumar (with H. Cohn), in Gitter und Anwendungen, Oberwolfach Reports 2 (2005), Report 1/2005, p. 36, DOI 10.4171/OWR/2005/01; resolution: M. S. Viazovska, The sphere packing problem in dimension 8, Ann. of Math. (2) 185 (2017), arXiv:1603.04246, Theorem 3: there is a radial Schwartz function g : ℝ⁸ → ℝ with g(x) ≤ 0 for |x| ≥ √2, ĝ(x) ≥ 0 for all x and g(0) = ĝ(0) = 1, https://arxiv.org/abs/1603.04246.
