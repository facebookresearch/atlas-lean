# Viazovska's magic function in dimension 8

Viazovska constructed a radial Schwartz function `g` on `ℝ⁸` with `g(x) ≤
0` for `|x| ≥ √2`, `ĝ ≥ 0` and `g(0) = ĝ(0) = 1`, proving that `E₈` gives the densest sphere packing
in dimension 8.

## Sources

- A. Kumar (with H. Cohn), in Gitter und Anwendungen, Oberwolfach Reports 2 (2005), no. 1, p. 36, DOI 10.4171/OWR/2005/01; resolution: M. S. Viazovska, The sphere packing problem in dimension 8, Ann. of Math. (2) 185 (2017), arXiv:1603.04246, Theorem 3: there is a radial Schwartz function g : ℝ⁸ → ℝ with g(x) ≤ 0 for |x| ≥ √2, ĝ(x) ≥ 0 for all x and g(0) = ĝ(0) = 1, https://arxiv.org/abs/1603.04246.
