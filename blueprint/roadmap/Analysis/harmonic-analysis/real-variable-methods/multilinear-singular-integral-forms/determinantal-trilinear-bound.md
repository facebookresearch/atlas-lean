# Lᵖ bounds for the determinantal trilinear form

The AIM question (Carleson theorems and multilinear operators, Question 6) in the form of its
answer by Gressman, He, Kovač, Street, Thiele and Yung: for all real $p, q, r > 2$ with
$1/p + 1/q + 1/r = 1$, there is a constant $C = C(p, q, r)$ such that for all complex-valued Schwartz functions $f, g, h$ on $\mathbb{R}^2$, the [truncated forms](truncated-determinantal-form.md) $\Lambda_\varepsilon(f, g, h)$, over $|\det[1\ 1\ 1;\, x\ y\ z]| > \varepsilon$, converge as $\varepsilon \downarrow 0$ to a limit $\Lambda(f, g, h)$, the principal value
$\Lambda(f, g, h) = \mathrm{p.v.} \int f(x)\, g(y)\, h(z)\, \delta(x + y + z) / \det[1\ 1\ 1;\, x\ y\ z]$, and
$|\Lambda(f, g, h)| \le C \|f\|_p \|g\|_q \|h\|_r$. The constant does not depend on $f$, $g$, $h$.

Its resolution: [Gressman–He–Kovač–Street–Thiele–Yung bound for the determinantal form](determinantal-trilinear-bound-holds.md).
