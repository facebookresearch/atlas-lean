# Dyadic index

The index of the level-$k$ [dyadic interval](dyadic-interval.md) that contains $x \in \mathbb{R}$ is $\lfloor 2^k x \rfloor$: one has $x \in I_{k,m}$ if and only if $\lfloor 2^k x \rfloor = m$. It is the integer $m$ in the description $2^{-k}([0,1) + m)$ of the level-$k$ dyadic cubes of T. Hytönen, *Dyadic analysis and weights*, lecture notes, University of Helsinki, version of 2 May 2014, §1.A (with $d = 1$). Through this index, every statement about which dyadic intervals contain a point becomes a statement about integer floors, and every set that is a union of level-$k$ intervals is a preimage under $x \mapsto \lfloor 2^k x \rfloor$, hence measurable.

## Sources

- T. Hytönen, *Dyadic analysis and weights*, lecture notes, University of Helsinki, version of 2 May 2014 (a secondary source: lecture notes presenting the dyadic theory of C. Fefferman and E. M. Stein, *Some maximal inequalities*, Amer. J. Math. 93 (1971), 107–115, and of E. M. Stein, *Harmonic Analysis*, Princeton University Press, 1993).
