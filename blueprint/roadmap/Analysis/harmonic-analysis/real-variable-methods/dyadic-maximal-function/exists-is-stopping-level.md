# Existence of the stopping level

If $\int \|f\| < \infty$, $c \ne 0$ and $M_d f(x) > c$, then $x$ has a [stopping level](is-stopping-level.md) at height $c$. Since $A_k f(x) \le 2^k \int \|f\|$, only levels bounded below can have average above $c$, and a nonempty set of integers bounded below has a least element. This is the absence of infinite increasing chains of dyadic cubes with average above $\lambda$ in the proof of T. Hytönen, *Dyadic analysis and weights*, lecture notes, University of Helsinki, version of 2 May 2014, Proposition 1.5, combined with Lemma 1.3(1) there.

The hypotheses are needed: for $f = 1$ every average equals $1$, so at height $c = 1/2$ no level is a stopping level.

## Informally uses

- [Dyadic average](dyadic-average.md): the bound $A_k f(x) \le 2^k \int \|f\|$.

## Background

- [Stopping level](is-stopping-level.md): the property whose existence is asserted.
