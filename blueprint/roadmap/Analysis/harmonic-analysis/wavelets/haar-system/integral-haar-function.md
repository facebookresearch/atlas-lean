# The Haar function has mean zero

$\int_{\mathbb{R}} H(x)\,dx = \tfrac12 - \tfrac12 = 0$: the Haar wavelet has one vanishing moment, like the wavelets of other multiresolution bases (its Fourier transform vanishes at $0$). It has no second vanishing moment, $\int x H(x)\,dx = -1/4$, which is why Haar coefficients of smooth functions decay slowly.
