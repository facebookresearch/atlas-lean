# Cascade identity

Let $X$ be a set, $a, c : X \to [0, \infty]$ and $u_\lambda : X \to X$ for $\lambda \in \Lambda$. If $a(x) + \sum_\lambda c(u_\lambda x) = c(x)$ for every $x$, then for every depth $m$,

$$\sum_{n < m} \sum_{|p| = n} a(u[p]\, x) + \sum_{|p| = m} c(u[p]\, x) = c(x),$$

the identity form of the [cascade inequality](cascade-le.md).
