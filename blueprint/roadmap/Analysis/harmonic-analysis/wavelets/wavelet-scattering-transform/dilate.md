# Dilated wavelet

For a wavelet $\psi : \mathbb{R} \to \mathbb{C}$ and $j \in \mathbb{Z}$, $\psi_{2^j}(x) = 2^j \psi(2^j x)$, so that $\hat\psi_{2^j}(\omega) = \hat\psi(2^{-j}\omega)$: equation (4) of S. Mallat, *Group invariant scattering*, Comm. Pure Appl. Math. 65 (2012), 1331–1398 (arXiv:1101.2286), in dimension $d = 1$ with the rotation $r = 1$.
