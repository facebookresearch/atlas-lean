# Convolution is commutative

For all $f, g : \{-1, 1\}^n \to \mathbb{R}$, $f * g = g * f$: both have Fourier coefficients
$\hat f(S)\, \hat g(S)$, and a function is determined by its Fourier coefficients.

## Sources

- R. O'Donnell, *Analysis of Boolean Functions*, Cambridge University Press, 2014 (arXiv:2105.10386), Definition 1.24 and Theorem 1.27.
