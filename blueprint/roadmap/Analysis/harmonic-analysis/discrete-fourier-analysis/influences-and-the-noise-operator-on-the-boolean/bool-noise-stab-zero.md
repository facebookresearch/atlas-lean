# Noise stability at $\rho = 0$

For every $f : \{-1, 1\}^n \to \mathbb{R}$, $\mathrm{Stab}_0[f] = \mathbb{E}[f]^2$: $T_0 f$ is the
constant $\mathbb{E}[f]$, so a $0$-correlated pair is independent.

## Sources

- R. O'Donnell, *Analysis of Boolean Functions*, Cambridge University Press, 2014 (arXiv:2105.10386), Section 2.4.
