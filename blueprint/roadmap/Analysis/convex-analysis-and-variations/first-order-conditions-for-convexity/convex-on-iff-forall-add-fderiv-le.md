# First-order characterization of convexity

Let $E$ be a real normed space, let $s \subseteq E$ be open and convex, and let $f \colon E \to \mathbb{R}$ be differentiable on $s$. Then $f$ is convex on $s$ if and only if

$$f(a) + Df(a)(x - a) \le f(x) \quad \text{for all } a, x \in s.$$

## Sources

- S. Boyd and L. Vandenberghe, *Convex Optimization*, Cambridge University Press, 2004 (https://web.stanford.edu/~boyd/cvxbook/), §3.1.3, eq. (3.2).
