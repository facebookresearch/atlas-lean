# A linear program attaining its minimum attains it at a basic point

Let $\iota$ be a finite index set, $E$ a real vector space, $L : \mathbb{R}^\iota \to E$ a linear map, $\varphi : \mathbb{R}^\iota \to \mathbb{R}$ a linear objective and $c \in E$. If $z \ge 0$ with $Lz = c$ minimizes $\varphi$ over $\{z' \ge 0 : Lz' = c\}$, then there is a minimizer $z'$ with $z' \ge 0$, $Lz' = c$, $\varphi(z') = \varphi(z)$ that is basic: the only $d$ with $Ld = 0$ and $d_i = 0$ wherever $z'_i = 0$ is $d = 0$.
