# Basic feasible points are the extreme points

Let $\iota$ be a finite index set, $E$ a real vector space, $L : \mathbb R^\iota \to E$ linear and $c \in E$. A point $z \ge 0$ with $L z = c$ is basic (the only $d$ with $L d = 0$ and $d_i = 0$ wherever $z_i = 0$ is $d = 0$) if and only if $z$ is an extreme point of the feasible set $\{w \ge 0 : L w = c\}$.
