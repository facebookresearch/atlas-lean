# Basic points of a linear system

Let $\iota$ be an index set (not necessarily finite), $E$ a real vector space and $L : \mathbb{R}^\iota \to E$ a linear map. A point $z \in \mathbb{R}^\iota$ is basic for $L$ when the only $d \in \mathbb{R}^\iota$ with $L d = 0$ and $d_i = 0$ for every $i$ with $z_i = 0$ is $d = 0$.
