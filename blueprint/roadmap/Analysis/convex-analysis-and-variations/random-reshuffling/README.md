# Random reshuffling

Random reshuffling visits the labeled terms of a finite sum in a uniformly
random order. The labels visited in a prefix of length $k$ form a uniform
$k$-subset: every such subset is the prefix set of exactly $k!(N-k)!$
permutations of the $N$ labels. The sampling identities below apply to this
prefix even when distinct labels have the same vector value.
