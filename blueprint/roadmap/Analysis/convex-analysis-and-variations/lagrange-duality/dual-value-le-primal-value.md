# Weak duality

Throughout, $E$ is a real vector space, $D \subseteq E$, $\iota$ is a finite index set, and the problem is to minimize $f_0(x)$ subject to $x \in D$ and $f_i(x) \le 0$ for $i \in \iota$, with $f_0, f_i \colon E \to \mathbb{R}$. Then $d^\star \le p^\star$: the dual optimal value never exceeds the primal optimal value. No convexity is assumed.
