# Dual optimal value

Throughout, $E$ is a real vector space, $D \subseteq E$, $\iota$ is a finite index set, and the problem is to minimize $f_0(x)$ subject to $x \in D$ and $f_i(x) \le 0$ for $i \in \iota$, with $f_0, f_i \colon E \to \mathbb{R}$. The **dual optimal value** is $d^\star = \sup_{\mu \ge 0} g(\mu)$, the optimal value of the Lagrange dual problem of maximizing the dual function $g$ over $\mu \ge 0$.
