# Scaling-invariant condition number χ̄*

The scaling-invariant condition number $\bar\chi^*_A = \inf \{\bar\chi_{AD} : D \text{ positive diagonal}\}$,
with $\bar\chi$ as on [Condition number χ̄ of a matrix](chi-bar.md). The set is nonempty ($D = I$) and
bounded below by $0$, so this is a genuine infimum. Since $AD$ has full row rank exactly when $A$ does, it is
the classical quantity when $A$ has full row rank; otherwise every $\bar\chi_{AD}$ is the empty-set value
$0$, and so is $\bar\chi^*_A$.
