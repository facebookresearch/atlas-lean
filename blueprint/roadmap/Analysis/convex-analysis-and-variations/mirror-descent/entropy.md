# The entropy distance-generating function

$\omega(x) = \sum_{i} x_i \log x_i$ on $\mathbb{R}^n$, where $\log t = \log|t|$ for $t \ne 0$ and $\log 0 = 0$ (so $0 \log 0 = 0$). It is the negative Shannon entropy, and the distance-generating function of the $\ell_1$-setup of mirror descent on the simplex.
