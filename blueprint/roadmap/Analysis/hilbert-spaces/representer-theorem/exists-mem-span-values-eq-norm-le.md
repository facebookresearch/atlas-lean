# Projection onto Riesz representers does not increase the norm

Let $H$ be a real Hilbert space, let $\iota$ be a finite index set and let $L_i : H \to \mathbb{R}$, $i \in \iota$, be bounded linear functionals with Riesz representers $r_i$. For every $g \in H$ there is $s$ in the span of the $r_i$ with $L_i(s) = L_i(g)$ for every $i$ and $\|s\| \le \|g\|$.
