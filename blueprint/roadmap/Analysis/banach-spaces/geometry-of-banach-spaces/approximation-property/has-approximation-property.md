# Approximation property

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$. A normed space $E$ over $\mathbb{K}$ has the **approximation property** if for every compact set $K \subseteq E$ and every $\varepsilon > 0$ there is a bounded operator $T$ on $E$ with finite-dimensional range such that $\|T x - x\| < \varepsilon$ for every $x \in K$: on compact sets, the identity is a uniform limit of finite-rank operators.
