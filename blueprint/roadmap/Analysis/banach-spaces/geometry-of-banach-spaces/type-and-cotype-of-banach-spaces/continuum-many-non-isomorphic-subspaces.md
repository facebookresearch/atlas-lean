# Dodos–Lopez-Abad question on continuum many non-isomorphic subspaces

Dodos–Lopez-Abad, Problem 8: every separable real Banach space that fails type `2 - ε` or fails
cotype `2 + ε` for some `ε > 0` contains continuum many pairwise non-isomorphic closed subspaces. (`ε < 1` loses nothing: every space has type `p` for `p ≤ 1`, and failing cotype `2 + ε` implies
failing cotype `2 + ε'` for every `ε' < ε`.)
