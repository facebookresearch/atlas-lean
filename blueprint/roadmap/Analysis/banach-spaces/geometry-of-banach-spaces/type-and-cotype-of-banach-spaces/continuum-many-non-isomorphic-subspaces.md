# Dodos–Lopez-Abad–Todorcevic question on continuum many non-isomorphic subspaces

Dodos–Lopez-Abad–Todorcevic, Problem 8: every separable real Banach space that, for some $0 < \varepsilon < 1$,
fails type $2 - \varepsilon$ or fails cotype $2 + \varepsilon$ contains continuum many pairwise non-isomorphic
closed linear subspaces (isomorphic meaning linearly homeomorphic).

The source asks this for some $\varepsilon > 0$. Restricting to $\varepsilon < 1$ loses nothing for
$1 \le \varepsilon < 2$: every space has type $p$ for $0 < p \le 1$ (with constant $1$, since
$(\sum_i \|x_i\|^p)^{1/p} \ge \sum_i \|x_i\|$ bounds every signed sum), and failing cotype $2 + \varepsilon$
implies failing cotype $2 + \varepsilon'$ for every $\varepsilon' < \varepsilon$. The restriction is not a
change of notation for $\varepsilon \ge 2$: there the [type](has-type.md) formula has exponent
$p = 2 - \varepsilon \le 0$, and at $\varepsilon = 2$ a one-vector family would require $\|x\| \le C$ for
every $x$, so even the real line fails "type $0$" although it has only two closed linear subspaces.

Its resolution: [Separable real Banach spaces failing type 2 − ε or cotype 2 + ε for some 0 < ε < 1 have continuum many non-isomorphic closed subspaces](continuum-many-non-isomorphic-subspaces-2.md).
