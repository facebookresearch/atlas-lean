# Separable real Banach spaces failing type 2 − ε or cotype 2 + ε for some 0 < ε < 1 have continuum many non-isomorphic closed subspaces

This settles [Dodos–Lopez-Abad–Todorcevic question on continuum many non-isomorphic subspaces](continuum-many-non-isomorphic-subspaces.md) in the affirmative: its statement holds.

Every separable real Banach space that, for some $0 < \varepsilon < 1$, fails type $2 - \varepsilon$ or fails
cotype $2 + \varepsilon$ has continuum many pairwise non-isomorphic closed linear subspaces. Cuellar
Carrera's Theorem 16 says that every separable Banach space that is not near Hilbert satisfies the
Cantorized-Enflo criterion, and his Remark 7 that a space satisfying that criterion has a continuum of
pairwise non-isomorphic subspaces. Near Hilbert means $p(X) = q(X) = 2$, and since type $p$ implies type $r$
for $0 < r < p$ and cotype $q$ implies cotype $s$ for $s > q$, failing type $2 - \varepsilon$ or cotype
$2 + \varepsilon$ for some $0 < \varepsilon < 1$ is exactly not being near Hilbert.

Soc. 370 (2018), 8691-8707, doi:10.1090/tran/7319, arXiv:1611.05500, Theorem 16: 'Every separable Banach space non near Hilbert satisfies the Cantorized-Enflo criterion and therefore is ergodic'; Remark 7 (with proof): 'A Banach space satisfying the Cantorized-Enflo criterion has a continuum of non isomorphic subspaces'; Section 1: near Hilbert means $p(X) = q(X) = 2$, where $p(X) = \sup\{p : X \text{ has type } p\}$ and $q(X) = \inf\{q : X \text{ has cotype } q\}$, https://arxiv.org/abs/1611.05500.
