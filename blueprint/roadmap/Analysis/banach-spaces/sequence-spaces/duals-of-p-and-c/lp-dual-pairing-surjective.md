# Every functional on $\ell^p$ comes from an $\ell^q$ sequence

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$, let $\iota$ be an index set and let $p, q \in [1, \infty]$ be conjugate exponents, $1/p + 1/q = 1$. If $p < \infty$, the [duality pairing](lp-dual-pairing.md) is surjective: every bounded linear functional on $\ell^p(\iota, \mathbb{K})$ is $x \mapsto \sum_i a_i x_i$ for some $a \in \ell^q(\iota, \mathbb{K})$.
