# Riesz–Fréchet–Kolmogorov relative compactness criterion in $\ell^p$

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$ and $1 \le p < \infty$. A set $K \subseteq \ell^p(\mathbb{N}, \mathbb{K})$ has compact closure if and only if it is bounded and its tails [vanish uniformly](uniform-tail-vanishing.md).
