# Riesz–Fréchet–Kolmogorov criterion for compactness in $\ell^p$

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$ and $1 \le p < \infty$. A set $K \subseteq \ell^p(\mathbb{N}, \mathbb{K})$ is compact if and only if it is complete, bounded, and its tails [vanish uniformly](uniform-tail-vanishing.md).
