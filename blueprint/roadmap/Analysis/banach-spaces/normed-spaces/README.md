# Normed spaces

Seminormed and normed vector spaces, balls and spheres, finite-dimensional norm equivalence, completions, complemented subspaces, linear isometries, normed affine spaces and operator norms of multilinear and alternating maps. Geometric isometry theorems such as the Mazur–Ulam theorem belong to Geometry of Banach spaces.
