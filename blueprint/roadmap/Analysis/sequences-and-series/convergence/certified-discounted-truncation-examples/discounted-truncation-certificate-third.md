# Discounted truncation error for discount one third

For discount factor $\beta = 1/3$, constant reward $2$ and truncation $T = 3$, the difference between the discounted value $\sum_{t \ge 0} \beta^t \cdot 2$ and its truncation $\sum_{t < 3} \beta^t \cdot 2$ has absolute value exactly $2 (1/3)^3 / (1 - 1/3) = 1/9$.
