# Theorem 20

If $u$ is harmonic in $\Omega$, and $\{z \mid r_{1} \leq |z - z_{0}| \leq r_{2}\} \subset \Omega$, then $$\frac{1}{2\pi} \int_{0}^{2\pi} u(z_{0} + r e^{i\theta})\, d\theta = \alpha \log r + \beta, \quad r_{1} \leq r \leq r_{2}$$ where $\alpha$ and $\beta$ are constants.
