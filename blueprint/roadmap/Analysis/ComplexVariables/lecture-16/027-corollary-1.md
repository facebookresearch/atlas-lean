# Corollary 1 (Lecture 16: Harmonic Functions)

If $u$ is harmonic in $\Omega$, then if the disk $|z - z_{0}| \leq r$ lies in $\Omega$, $$u(z_{0}) = \frac{1}{2\pi} \int_{0}^{2\pi} u(z_{0} + r e^{i\theta})\, d\theta.$$
