# Theorem 2 (Cauchy's Integral Formula)

Let $f$ be holomorphic in an open set $\Omega$. Then $$n(\gamma, z)\, f(z) = \frac{1}{2\pi i} \int_{\gamma} \frac{f(\zeta)}{\zeta - z}\, d\zeta$$ where $\gamma \sim 0$ with respect to $\Omega$.
