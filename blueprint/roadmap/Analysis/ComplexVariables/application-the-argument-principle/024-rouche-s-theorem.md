# Corollary 1 (Rouche's Theorem)

Let $f$ and $g$ be holomorphic in a region $\Omega$. Let $\gamma$ be a simple closed curve in $\Omega$ with interior $\subset \Omega$. Assume $$|f(z) - g(z)| < |f(z)| \quad \text{on} \quad \gamma.$$ Then $f$ and $g$ have the same number of zeros inside $\gamma$, say $N_f$ and $N_g$.
