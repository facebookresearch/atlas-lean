# Proposition 16.3

If $A$ is a bounded self-adjoint operator and $p$ is a real polynomial in one variable, $p(t) = \sum_{i=0}^{N} c_i t^i$, $c_N \neq 0$, then $p(A) = \sum_{i=0}^{N} c_i A^i$ satisfies $\|p(A)\| \leq \sup_{t \in [m,M]} |p(t)|$.
