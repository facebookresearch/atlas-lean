# Proposition 16.2

If $A$ is a bounded self-adjoint operator then, with $m = \inf_{\|\phi\|=1}\langle A\phi, \phi\rangle$ and $M = \sup_{\|\phi\|=1}\langle A\phi, \phi\rangle$, $\{m\} \cup \{M\} \subset \operatorname{spec}(A) \subset [m, M]$.
