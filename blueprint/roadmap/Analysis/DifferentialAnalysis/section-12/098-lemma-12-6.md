# Lemma 12.6

If $\operatorname{Css}(u) \cap \mathbb{S}^{n-1} = \emptyset$ then $u * v$ is defined unambiguously by $u * v = u_{1} * v + u_{2} * v$, $u_{1} = (1-\chi(x/r))u$, $u_{2} = u - u_{1}$ where $\chi \in \mathcal{C}_{c}^{\infty}(\mathbb{R}^{n})$ has $\chi(x) = 1$ in $|x| \leq 1$ and $R$ is sufficiently large; there is a similar definition if $\operatorname{Css}(v) \cap \mathbb{S}^{n-1} = \emptyset$.
