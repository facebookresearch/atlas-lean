# Definition 4.1

For a non-negative $\mu$-measurable extended function $f \colon X \to [0, \infty]$ the integral (with respect to $\mu$) over any measurable set $E \subset X$ is $$\int_{E} f\, d\mu = \sup\left\{\int_{E} h\, d\mu \mid 0 \leq h \leq f,\, h \text{ simple and measurable}\right\}.$$
