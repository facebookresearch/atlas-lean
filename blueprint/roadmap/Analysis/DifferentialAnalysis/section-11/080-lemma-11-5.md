# Lemma 11.5

$E(x, y) = \frac{1}{2\pi}(x + iy)^{-1}$ for $(x,y) \neq 0$ is locally integrable and so defines $E \in \mathcal{S}'(\mathbb{R}^{2})$ by $E(\varphi) = \frac{1}{2\pi} \int_{\mathbb{R}^{2}} (x + iy)^{-1} \varphi(x,y)\, dx\, dy$, and $E$ so defined is a tempered fundamental solution of $\bar{\partial}$.
