# Definition 6.5

For any $k, l \in \mathbb{N} = \{1, 2, \cdots\}$ set $\langle x\rangle^{-l} \mathcal{C}_0^{k}(\mathbb{R}^{n}) = \{u \in \mathcal{C}_0^{k}(\mathbb{R}^{n}) \mid u = \langle x\rangle^{-l} v,\, v \in \mathcal{C}_0^{k}(\mathbb{R}^{n})\}$ with norm $\|u\|_{k,l} = \|v\|_{\mathcal{C}^{k}}$, $v = \langle x\rangle^{l} u$.
