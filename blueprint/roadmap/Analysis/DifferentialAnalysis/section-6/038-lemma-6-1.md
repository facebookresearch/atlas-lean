# Lemma 6.1

If $V \hookrightarrow U$ is a subspace with a stronger norm, $\|\varphi\|_{U} \leq C\|\varphi\|_{V}$ for all $\varphi \in V$, then restriction gives a continuous linear map $U' \to V'$, $U' \ni L \longmapsto \tilde{L} = L|_{V} \in V'$, with $\|\tilde{L}\|_{V'} \leq C\|L\|_{U'}$. If $V$ is dense in $U$ then the map is injective.
