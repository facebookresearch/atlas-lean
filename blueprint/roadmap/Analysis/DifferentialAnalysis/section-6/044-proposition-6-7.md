# Proposition 6.7

For $u \in \mathcal{S}(\mathbb{R}^{n})$, set $\|u\|_{(k)} = \|\langle x\rangle^{k} u\|_{\mathcal{C}^{k}}$ and define $d(u, v) = \sum_{k=0}^{\infty} 2^{-k} \frac{\|u-v\|_{(k)}}{1+\|u-v\|_{(k)}}$. Then $d$ is a distance function in $\mathcal{S}(\mathbb{R}^{n})$ with respect to which it is a complete metric space.
