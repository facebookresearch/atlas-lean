# Lemma 7.1

The condition $\varphi \in \mathcal{S}(\mathbb{R}^{n})$ can be written $\langle x\rangle^{k} D^{\alpha} \varphi \in \mathcal{C}_0^{0}(\mathbb{R}^{n})$ for all $|\alpha| \leq k$, for all $k$.
