# Lemma 7.4

A linear map $T \colon \mathcal{S}(\mathbb{R}^{n}) \to \mathcal{S}(\mathbb{R}^{n})$ is continuous if and only if for each $k$ there exist $C$ and $j$ such that if $|\alpha| \leq k$ and $|\beta| \leq k$ then $\sup |x^{\alpha} D^{\beta} T\varphi| \leq C \sum_{|\alpha''| \leq j,\, |\beta''| \leq j} \sup_{\mathbb{R}^{n}} |x^{\alpha''} D^{\beta''} \varphi|$ for all $\varphi \in \mathcal{S}(\mathbb{R}^{n})$.
