# Proposition 3.3

For any non-negative $\mu$-measurable extended function $f \colon X \to [0, \infty]$ there is an increasing sequence $f_n$ of simple measurable functions such that $\lim_{n \to \infty} f_n(x) = f(x)$ for each $x \in X$ and this limit is uniform on any measurable set on which $f$ is finite.
