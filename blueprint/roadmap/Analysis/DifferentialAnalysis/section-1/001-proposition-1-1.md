# Proposition 1.1

A map $f \colon X \to Y$ between metric spaces is continuous if and only if one of the three following equivalent conditions holds: (1) $f^{-1}(O) \subset X$ is open $\forall O \subset Y$ open. (2) $f^{-1}(C) \subset X$ is closed $\forall C \subset Y$ closed. (3) $\lim_{n \to \infty} f(x_n) = f(x)$ in $Y$ if $x_n \to x$ in $X$.
