# Definition 1.6

A positive extended function, $\mu^*$, defined on the power set of $X$ is called an outer measure if $\mu^*(\emptyset) = 0$, $\mu^*(A) \leq \mu^*(B)$ whenever $A \subset B$ and $\mu^*(\bigcup_j A_j) \leq \sum_j \mu^*(A_j)$ for all $\{A_j\}_{j=1}^{\infty} \subset \mathcal{P}(X)$.
