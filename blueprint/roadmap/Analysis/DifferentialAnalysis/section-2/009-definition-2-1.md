# Definition 2.1

A collection of subsets $\mathcal{M}$ of a set $X$ is a $\sigma$-algebra if (1) $\emptyset, X \in \mathcal{M}$, (2) $E \in \mathcal{M} \Longrightarrow E^C = X \setminus E \in \mathcal{M}$, (3) $\{E_i\}_{i=1}^{\infty} \subset \mathcal{M} \Longrightarrow \bigcup_{i=1}^{\infty} E_i \in \mathcal{M}$.
