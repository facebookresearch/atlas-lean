# Definition 2.2

A set $E \subset X$ is $\mu^*$-measurable (for an outer measure $\mu^*$ on $X$) if $\mu^*(A) = \mu^*(A \cap E) + \mu^*(A \cap E^{\complement})$ for all $A \subset X$.
