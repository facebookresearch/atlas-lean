# Worked example of an interior source in a one-port reduction

For the conductance matrix `[[2, −1], [−1, 2]]`, with the first node as the port and the second as
the only interior node, carrying the injection `2`, the
[port conductance](kron-port-conductance.md) is `2 − (−1) · 2⁻¹ · (−1) = 3/2`, and the
[effective injection](kron-port-injection.md) for every port source `j_S` is `j_S + 1`.
