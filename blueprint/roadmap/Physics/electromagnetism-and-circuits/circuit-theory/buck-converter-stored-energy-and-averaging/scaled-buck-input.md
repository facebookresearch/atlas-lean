# Scaled input vector of the ideal buck converter

For real numbers `L`, `Vin` and `Iref`, the scaled input vector is `b̃ = (Vin / (L Iref), 0)`, with
`a / 0 = 0`. For `Iref ≠ 0` it satisfies [`S b̃ = b`](state-scaling-mul-vec-scaled-buck-input.md) for
the [input vector](buck-input.md) `b` and the [state scaling](state-scaling.md) `S`.
