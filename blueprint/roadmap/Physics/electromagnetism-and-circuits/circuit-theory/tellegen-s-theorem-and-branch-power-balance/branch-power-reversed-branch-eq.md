# Negating one branch voltage and current preserves total power

Let `E` be a finite set of branches, `v` and `i` real branch voltages and currents, and `e₀` a
branch. Negating both the voltage and the current of `e₀`, `v'(e₀) = −v(e₀)` and
`i'(e₀) = −i(e₀)`, with the other branches unchanged, preserves the total branch power:

`∑ₑ v'(e) i'(e) = ∑ₑ v(e) i(e)`.
