# The network laws on a set depend only on the signals on that set

For a [network plant](network-plant.md), a set `S` of times and two
[trajectories](network-trajectory.md) `x` and `y` whose potentials, injections, branch voltages and
branch currents agree at every time of `S`, if `x` [obeys the laws on `S`](is-network-trajectory-on.md)
then so does `y`.
