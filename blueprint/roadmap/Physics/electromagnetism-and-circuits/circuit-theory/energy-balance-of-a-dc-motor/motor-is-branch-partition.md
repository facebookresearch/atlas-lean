# Branch partition of the DC motor loop

The four branches of the [motor loop](motor-incidence.md) form a
[branch partition](../energy-balance-of-rlc-networks/is-branch-partition.md): the resistor set `{1}`, the inductor set `{2}`, the
empty capacitor set and the source set `{0, 3}` are pairwise disjoint and cover `{0, 1, 2, 3}`.
