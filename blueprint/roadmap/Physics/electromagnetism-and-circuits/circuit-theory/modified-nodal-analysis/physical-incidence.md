# Tail-positive incidence matrix of a network

For finitely many nodes and branches, with branch `e` running from the node `tail(e)` to the node
`head(e)`, the electrical incidence matrix has entry `1` at `(tail(e), e)`, `-1` at `(head(e), e)`,
and `0` elsewhere; a branch with `tail(e) = head(e)` has a zero column. It is the negation of the
head-positive incidence matrix of the directed graph.
