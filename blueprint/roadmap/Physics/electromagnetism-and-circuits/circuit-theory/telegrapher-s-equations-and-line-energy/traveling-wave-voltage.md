# Voltage of a forward traveling wave

For real constants `L` and `C`, a real function `f` and a point `(x, t)`, the forward wave voltage
is

`v(x, t) = f(x − t / √(L C))`,

a profile `f` moving in the `+x` direction at the speed `1 / √(L C)`. The intended domain is
`L, C > 0`; with the conventions `√y = 0` for `y < 0` and `t / 0 = 0`, the voltage is `f(x)` when
`L C ≤ 0`.
