# Current of a forward traveling wave

For real constants `L` and `C`, a real function `f` and a point `(x, t)`, the forward wave current
is

`i(x, t) = f(x − t / √(L C)) / √(L / C)`,

the [forward wave voltage](traveling-wave-voltage.md) divided by the characteristic impedance
`√(L / C)`. The intended domain is `L, C > 0`; with the conventions `√y = 0` for `y < 0` and
`y / 0 = 0`, the current is `0` when `L / C ≤ 0`.
