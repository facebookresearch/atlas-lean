# Wave speed of a lossless line

For real numbers `L` and `C`, the wave speed of the lossless line with inductance `L` and
capacitance `C` per unit length is

`v = 1 / √(L C)`.

The intended domain is `L, C > 0`; with the conventions `√y = 0` for `y < 0` and `1 / 0 = 0`, the
value is `0` when `L C ≤ 0`.
