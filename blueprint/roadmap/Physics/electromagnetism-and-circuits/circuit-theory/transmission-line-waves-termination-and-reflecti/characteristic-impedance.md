# Characteristic impedance of a lossless line

For real numbers `L` and `C`, the characteristic impedance of the lossless line with inductance
`L` and capacitance `C` per unit length is

`Z₀ = √(L / C)`,

[positive](characteristic-impedance-pos.md) for `L, C > 0`, the intended domain. With the
conventions `√y = 0` for `y < 0` and `L / 0 = 0`, the value is `0` when `L / C ≤ 0`.
