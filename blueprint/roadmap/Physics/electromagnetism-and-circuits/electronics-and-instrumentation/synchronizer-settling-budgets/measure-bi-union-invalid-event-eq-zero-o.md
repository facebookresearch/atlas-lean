# With no observations, the invalid event has measure zero

Let the index set $\iota$ be empty. For every measure $\mu$ on a sample space $\Omega$, all real
thresholds $V_{il}$, $V_{ih}$ and all observed voltages, the union of the
[invalid events](invalid-event.md) over $\iota$ is empty, so

$$\mu\Bigl(\bigcup_{i \in \iota} \{\omega : x_i(\omega) \text{ is invalid}\}\Bigr) = 0.$$
