# Reverse branch current of the Ebers–Moll model

For real numbers $I_{SR}$ (the reverse saturation current), $V_T$ (the thermal voltage) and
$V_{BC}$ (the base-collector voltage), the reverse (base-collector) branch current is

$$I_R = I_{SR} \left(e^{V_{BC}/V_T} - 1\right) .$$

With the convention $a / 0 = 0$, at $V_T = 0$ the exponent is $0$ and $I_R = 0$ for every
$V_{BC}$. In the device $V_T > 0$ and $I_{SR} > 0$; the definition accepts any real inputs.
