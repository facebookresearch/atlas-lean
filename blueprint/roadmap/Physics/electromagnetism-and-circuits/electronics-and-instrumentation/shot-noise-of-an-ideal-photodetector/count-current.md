# Window-averaged current from a photoelectron count

For a real charge $q$, a real window length $T$ and a count $n \in \mathbb{N}$ of photoelectrons,
the window-averaged current is

$$\frac{|q|\, n}{T}.$$

It is a current averaged over a window of positive length $T > 0$. With the convention
$x / 0 = 0$, the value is $0$ for $T = 0$, which is not a current.
