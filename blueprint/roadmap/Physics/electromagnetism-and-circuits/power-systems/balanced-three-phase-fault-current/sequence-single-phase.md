# The phase set I, 0, 0 has all three sequence components equal to I/3

For every complex $I$, the phase set $(I, 0, 0)$, with current $I$ in phase $a$ and none in phases
$b$ and $c$, has [zero-sequence](../symmetrical-components-of-three-phase-systems/zero-sequence.md),
[positive-sequence](../symmetrical-components-of-three-phase-systems/positive-sequence.md) and
[negative-sequence](../symmetrical-components-of-three-phase-systems/negative-sequence.md)
components all equal to $I / 3$.
