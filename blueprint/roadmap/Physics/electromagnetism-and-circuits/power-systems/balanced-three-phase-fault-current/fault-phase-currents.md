# Fault phase currents: the balanced set of the fault current

For complex $E$, $Z_{\mathrm{th}}$ and $Z_f$, the fault phase currents are the
[balanced positive-sequence set](../balanced-three-phase-power/balanced-phases.md) built from the
[fault current](fault-current.md) $I_f$: phases $a$, $b$ and $c$, indexed by $0$, $1$ and $2$ in the
integers modulo 3, carry

$$I_f, \qquad \alpha^2 I_f, \qquad \alpha I_f,$$

where $\alpha = e^{2\pi i/3}$ is the
[rotation operator](../symmetrical-components-of-three-phase-systems/alpha.md). With the convention
$x / 0 = 0$, all three are $0$ when $Z_{\mathrm{th}} + Z_f = 0$.
