# A nonzero single-phase set is not a balanced positive-sequence set

For complex $I \neq 0$ and every complex $X$, the phase set $(I, 0, 0)$ differs from the
[balanced positive-sequence set](../balanced-three-phase-power/balanced-phases.md)
$(X, \alpha^2 X, \alpha X)$, where $\alpha = e^{2\pi i/3}$ is the
[rotation operator](../symmetrical-components-of-three-phase-systems/alpha.md): a nonzero current in
phase $a$ alone is not a balanced positive-sequence set.
