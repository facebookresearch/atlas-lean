# Sequence components as a function on the integers modulo 3

For complex phase quantities `V_a`, `V_b`, `V_c`, the sequence array is the function on the integers
modulo 3 with values `V₀`, `V₁`, `V₂` at `0`, `1`, `2`: the [zero](zero-sequence.md),
[positive](positive-sequence.md) and [negative](negative-sequence.md) sequence components.
