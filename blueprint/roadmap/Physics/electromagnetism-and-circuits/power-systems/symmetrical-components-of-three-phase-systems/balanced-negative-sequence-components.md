# A balanced negative-sequence set has only a negative sequence

For every complex `A`, the set with reversed phase order `(V_a, V_b, V_c) = (A, α A, α² A)` has
zero-sequence component `0`, positive-sequence component `0` and negative-sequence component `A`,
where `α = e^(2πi/3)` ([sequence components](sequence-vector.md)).
