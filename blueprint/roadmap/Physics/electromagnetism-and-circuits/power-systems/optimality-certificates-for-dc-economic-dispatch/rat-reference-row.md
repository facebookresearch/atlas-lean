# Rational row selecting the reference angle

For finitely many buses and a reference bus `r`, the rational reference row is the `1 × n_N` row
with entry `1` at `r` and `0` elsewhere. The rational objects copy the real ones entrywise, so that
the checker is computable; the [casting lemmas](rat-lp-matrix-map.md) identify them with the real
linear program.
