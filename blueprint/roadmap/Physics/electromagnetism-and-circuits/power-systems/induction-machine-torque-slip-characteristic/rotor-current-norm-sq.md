# At nonzero slip, the squared rotor current magnitude

For every complex `V_th`, real `R_th`, `R₂`, `X_eq` and slip `s ≠ 0`, the
[rotor current](rotor-current.md) satisfies `‖I₂‖² = ‖V_th‖² / ((R_th + R₂ / s)² + X_eq²)`. With the
convention `x / 0 = 0` both sides are `0` when `R_th + R₂ / s = 0` and `X_eq = 0`.
