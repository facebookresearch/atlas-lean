# Per-unit system for three-phase quantities

Per-unit coordinates for balanced three-phase quantities: from root-mean-square phase voltage and
current bases $V_b$ and $I_b$, the power base $S_b = 3 V_b I_b$, the impedance base
$Z_b = V_b / I_b$ and the line-voltage base $V_{L,b} = \sqrt{3}\, V_b$, and the voltage, current,
impedance and complex power divided by their bases. The results hold for positive bases, as each
page states.
