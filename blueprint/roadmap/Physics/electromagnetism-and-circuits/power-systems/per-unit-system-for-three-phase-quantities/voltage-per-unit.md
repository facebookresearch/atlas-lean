# Voltage in per-unit coordinates

For a real phase-voltage base $V_b$ and a complex voltage phasor $V$, the per-unit voltage is
$V_{\mathrm{pu}} = V / V_b$, the base read as a complex number. With the convention $x / 0 = 0$,
$V_{\mathrm{pu}} = 0$ when $V_b = 0$. In the per-unit system $V_b > 0$, and the per-unit voltage is
a dimensionless coordinate for the same phasor.
