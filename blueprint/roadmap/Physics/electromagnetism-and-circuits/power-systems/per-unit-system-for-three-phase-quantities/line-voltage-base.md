# Line-voltage base

For a real phase-voltage base $V_b$, the line-voltage base is $V_{L,b} = \sqrt{3}\, V_b$. For
$V_b > 0$ it is the magnitude of every line voltage of a balanced phase set with phase voltage $V_b$
([line voltages of a balanced set](line-voltage-base-eq-norm-line-voltage.md)). The definition
allows every real $V_b$.
