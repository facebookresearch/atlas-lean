# Impedance base

For real numbers $V_b$ and $I_b$, the phase voltage and current bases, the impedance base is
$Z_b = V_b / I_b$. With the convention $x / 0 = 0$, $Z_b = 0$ when $I_b = 0$. In the per-unit system
$V_b$ and $I_b$ are positive root-mean-square phase bases; the definition allows all real values.
