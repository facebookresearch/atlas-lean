# For V_b > 0, every balanced line voltage has magnitude √3 V_b

For a real phase-voltage base $V_b > 0$, let $V_p$ be the
[balanced phase set](../balanced-three-phase-power/balanced-phases.md)
$(V_b, \alpha^2 V_b, \alpha V_b)$, $\alpha = e^{2\pi i/3}$, with phase voltage $V_b$. Every
[line voltage](../balanced-three-phase-power/line-voltage.md) $V_p - V_{p+1}$ of this set has
magnitude equal to the [line-voltage base](line-voltage-base.md):

$$|V_p - V_{p+1}| = \sqrt{3}\, V_b = V_{L,b} \quad \text{for each phase } p,$$

by the
[magnitude of balanced line voltages](../balanced-three-phase-power/norm-line-voltage-balanced-phases.md),
$\sqrt{3}\, |V_b|$, with $|V_b| = V_b$.
