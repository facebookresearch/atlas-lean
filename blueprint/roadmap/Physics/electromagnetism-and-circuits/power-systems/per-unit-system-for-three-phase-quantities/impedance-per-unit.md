# Impedance in per-unit coordinates

For real phase bases $V_b$ and $I_b$ and a complex impedance $Z$, the per-unit impedance is
$Z_{\mathrm{pu}} = Z / Z_b$, where $Z_b = V_b / I_b$ is the [impedance base](impedance-base.md),
read as a complex number. With the convention $x / 0 = 0$, $Z_{\mathrm{pu}} = 0$ when $Z_b = 0$,
that is, when $V_b = 0$ or $I_b = 0$. In the per-unit system $V_b$ and $I_b$ are positive
root-mean-square phase bases; the definition allows all real values.
