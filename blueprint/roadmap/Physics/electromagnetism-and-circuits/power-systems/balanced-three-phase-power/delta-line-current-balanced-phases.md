# Balanced delta: line currents are √3 branch currents rotated by −30°

For every complex `J`, the [line currents of the delta connection](delta-line-current.md) whose
branch currents are the [balanced positive-sequence](balanced-phases.md) set
`(I_ab, I_bc, I_ca) = (J, α² J, α J)`, with `α = e^{2πi/3}`, form again a balanced
positive-sequence set, built from `√3 e^{-iπ/6} J`:

`(I_a, I_b, I_c) = (K, α² K, α K)` with `K = √3 e^{-iπ/6} J`,

where `√3` is the positive square root. So `I_a = √3 e^{-iπ/6} I_ab`: each line current has `√3`
times the branch magnitude and, with phasors rotating as `e^{iωt}`, lags the branch current of
its index (`I_a` lags `I_ab`, `I_b` lags `I_bc`, `I_c` lags `I_ca`) by `π/6` (30°).
