# Perturbing phase c of a balanced set by δ gives neutral current δ

For all complex `I` and `δ`, the [neutral current](neutral-current.md) of the
[balanced set with phase c perturbed](altered-phases.md), `(I, α² I, α I + δ)` with
`α = e^{2πi/3}`, is

`I + α² I + (α I + δ) = δ`,

because `1 + α + α² = 0`: the neutral current measures the departure from balance.
