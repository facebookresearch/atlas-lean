# Balanced set with phase c perturbed

For complex `I` and `δ`, this is the [balanced positive-sequence set](balanced-phases.md)
`(I, α² I, α I)` with `δ` added to phase `c`:

`(I_a, I_b, I_c) = (I, α² I, α I + δ)`,

indexed by the integers mod 3, where `α = e^{2πi/3}` is the
[rotation operator](../symmetrical-components-of-three-phase-systems/alpha.md). It models a set of
star-connected line currents in which one phase departs from balance by `δ`.
