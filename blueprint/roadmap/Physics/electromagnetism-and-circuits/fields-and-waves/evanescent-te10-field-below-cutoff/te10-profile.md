# Transverse profile of the TE10 mode

For a real guide width `a`, the TE10 transverse profile is `x ↦ sin(k_c x)`, with the
[cutoff wavenumber](cutoff-wavenumber.md) `k_c = π/a`. It vanishes at `x = 0` and, for `a ≠ 0`, at
`x = a`; it is identically `0` when `a = 0`.

The same profile `sin(k_c x)` is the transverse factor of both the
[propagating TE10 fields](../te10-mode-of-a-rectangular-waveguide/te10-electric-field.md) above
cutoff and the [evanescent TE10 fields](evanescent-electric-field.md) below cutoff.
