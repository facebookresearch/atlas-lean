# Components of the evanescent magnetic field

For all real `a`, `E₀`, `ω`, `κ`, every time `t` and point `(x, y, z)`, the
[evanescent magnetic field](evanescent-magnetic-field.md) is

`B = (-(κE₀/ω) sin(k_c x) e^{-κz} sin(ωt), 0, -(k_c E₀/ω) cos(k_c x) e^{-κz} sin(ωt))`,

with the [cutoff wavenumber](cutoff-wavenumber.md) `k_c = π/a` and quotients by `0` read as `0`, so
that `B = 0` when `ω = 0`.
