# Below cutoff the factor with the decay rate solves the mode equation

Let `c > 0` be the speed of light. Let `a` be real and `0 < ω < c k_c`, strictly below cutoff, with
the [cutoff wavenumber](cutoff-wavenumber.md) `k_c = π/a`. For every real `E₀`, the
[longitudinal factor](evanescent-mode.md) with the [decay rate](decay-rate.md) `κ = √(k_c² - ω²/c²)`
as rate satisfies the [mode equation](../separable-vacuum-maxwell-fields/mode-equation.md)
`f_tt = c² (f_zz - k_c² f)` at every `(t, z)`.
