# The TE10 profile solves the profile equation at the cutoff wavenumber

For every real `a`, the [TE10 profile](te10-profile.md) `u(x) = sin(k_c x)` satisfies the
[profile equation](../separable-vacuum-maxwell-fields/profile-equation.md) `u''(x) = -k_c² u(x)` at
every `x`, with the [cutoff wavenumber](cutoff-wavenumber.md) `k_c = π/a`.

The equation does not involve the frequency, so it holds for the profile of the propagating mode
above cutoff and of the evanescent field below cutoff alike.
