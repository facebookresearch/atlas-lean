# For E₀, ω ≠ 0 the mode equation holds exactly when ω² = c₀²kc² − c₀²κ²

Let `c₀`, `a`, `κ` be real and `E₀ ≠ 0`, `ω ≠ 0`. The [longitudinal factor](evanescent-mode.md)
`f(t, z) = -(E₀/ω) e^{-κz} sin(ωt)` satisfies the
[mode equation](../separable-vacuum-maxwell-fields/mode-equation.md) `f_tt = c₀² (f_zz - k_c² f)` at
every `(t, z)` if and only if `ω² = c₀² (k_c² - κ²)`, with the
[cutoff wavenumber](cutoff-wavenumber.md) `k_c = π/a`.
