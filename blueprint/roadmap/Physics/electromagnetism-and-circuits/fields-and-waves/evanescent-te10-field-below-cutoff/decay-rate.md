# Decay rate of the TE10 field below cutoff

For real `c₀`, `a` and `ω`, the below-cutoff decay rate is

`κ = √(k_c² - ω²/c₀²)`,

with the [cutoff wavenumber](cutoff-wavenumber.md) `k_c = π/a`. With the conventions `√x = 0` for
`x < 0` and `x/0 = 0`, it is `0` at or above cutoff (`ω²/c₀² ≥ k_c²`), and `ω²/c₀²` is read as `0`
when `c₀ = 0`. It is meaningful strictly below cutoff, `0 < ω < c₀ k_c`.
