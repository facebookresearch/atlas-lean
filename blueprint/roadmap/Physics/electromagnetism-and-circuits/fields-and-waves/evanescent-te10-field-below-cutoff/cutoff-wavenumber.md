# TE10 cutoff wavenumber of a guide of width a

For a real guide width `a`, the TE10 cutoff wavenumber is `k_c = π/a`. With the convention `x/0 = 0`
it is `0` for `a = 0`, a degenerate guide; in the physical reading `a > 0`.

The same wavenumber serves the propagating TE10 mode above cutoff, through the
[dispersion relation](../te10-mode-of-a-rectangular-waveguide/te10-dispersion.md)
`ω² = c₀²(k_c² + β²)`, and the evanescent field below cutoff, through the
[decay rate](decay-rate.md) `κ = √(k_c² − ω²/c₀²)`.
