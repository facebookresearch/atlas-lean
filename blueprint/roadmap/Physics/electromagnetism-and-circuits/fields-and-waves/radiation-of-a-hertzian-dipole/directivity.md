# Directivity of an axisymmetric intensity pattern

For an intensity pattern `U : ℝ → ℝ` and a polar angle `θ`, the directivity is

`D(θ) = 4π U(θ) / P(U)`,

with `P(U)` the [radiated power](radiated-power.md). It is meant for a pattern of positive radiated
power; with the convention `x/0 = 0` it is `0` for every `θ` when `P(U) = 0`, which is not a
directivity.
