# With K = 0 the directivity at θ = π/2 is not 3/2

For `K = 0` the radiated power is `0`, so by the convention `x/0 = 0` the
[directivity](directivity.md) of `U(θ) = 0 · sin²θ` is `0`; in particular it is not `3/2` at
`θ = π/2`. So the value `3/2` fails at `K = 0`; it is
[proved](directivity-short-dipole-intensity.md) for `K > 0`, the physical range.
