# With a loss factor p, the Friis value holds exactly when p = 1

Let `r, λ, Pt, Gt, Gr > 0`, the flux `S = Pt Gt / (4π r²)` and the aperture `Ae = Gr λ² / (4π)`. For
every real `p` (a polarization or impedance loss factor when `0 ≤ p ≤ 1`),
`p S Ae = Pt Gt Gr (λ / (4π r))²` if and only if `p = 1`.
