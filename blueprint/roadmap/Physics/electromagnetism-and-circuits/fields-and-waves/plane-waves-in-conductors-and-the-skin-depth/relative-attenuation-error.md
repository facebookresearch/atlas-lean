# Relative attenuation error of the good-conductor approximation

For reals `ε`, `μ`, `ω` and `σ`, `1 − α / α0`, with [attenuation constant](attenuation-constant.md)
`α = ω √(μ ε / 2) √(√(1 + (σ / (ω ε))²) − 1)` and
[good-conductor attenuation](good-conductor-attenuation.md) `α0 = √(ω μ σ / 2)`. With the convention
`x / 0 = 0` it is `1` when `α0 = 0`.
