# For ε, μ, ω > 0 and σ ≥ 0, the opposite root −γ has Re ≤ 0 and Im < 0

Let `ε > 0`, `μ > 0`, `ω > 0` and `σ ≥ 0`. Then the opposite root `-γ` of the
[propagation constant](propagation-constant.md) `γ = α + iβ` has `Re(-γ) ≤ 0` and `Im(-γ) < 0`. It
has the same square as `γ`, so it satisfies the
[squared propagation equation](satisfies-dispersion-equation.md) too, but the wave `e^{+iωt} e^{γz}`
travels in the negative `z` direction.
