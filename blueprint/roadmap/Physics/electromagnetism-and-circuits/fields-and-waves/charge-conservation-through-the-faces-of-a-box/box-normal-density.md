# Outward-normal component of a current density on a box face

For `a, b ∈ ℝ³` the box is `[a, b] = {x ∈ ℝ³ : a_i ≤ x_i ≤ b_i for i = 0, 1, 2}`, with coordinate
axes indexed `0, 1, 2`. For a current density `J : ℝ³ → ℝ³` and face `f`, the outward-normal density
at the parameter point `y ∈ ℝ²` is `s_f J_k(φ_f(y))`, where `k` is the [normal axis](face-axis.md),
`s_f = ±1` the [outward sign](face-sign.md) and `φ_f` the [embedding](box-face-embed.md) of the
face.
