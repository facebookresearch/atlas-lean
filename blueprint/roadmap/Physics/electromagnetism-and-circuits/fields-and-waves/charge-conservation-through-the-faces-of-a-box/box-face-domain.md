# Parameter rectangle of a box face

For `a, b ∈ ℝ³` the box is `[a, b] = {x ∈ ℝ³ : a_i ≤ x_i ≤ b_i for i = 0, 1, 2}`, with coordinate
axes indexed `0, 1, 2`. For face `f` with [normal axis](face-axis.md) `k`, let `i < j` be the two
other axes. The parameter rectangle of `f` is `[a_i, b_i] × [a_j, b_j] ⊆ ℝ²`, in the coordinates
`(x_i, x_j)`; it is empty when `a_i > b_i` or `a_j > b_j`.
