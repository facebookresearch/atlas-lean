# Embedding of a face rectangle into space

For `a, b ∈ ℝ³` the box is `[a, b] = {x ∈ ℝ³ : a_i ≤ x_i ≤ b_i for i = 0, 1, 2}`, with coordinate
axes indexed `0, 1, 2`. For face `f` with [normal axis](face-axis.md) `k` and other axes `i < j`,
the embedding sends `(y_0, y_1) ∈ ℝ²` to the point `x ∈ ℝ³` with `x_k` the
[face level](face-level.md), `x_i = y_0` and `x_j = y_1`. For `a ≤ b` it maps the
[parameter rectangle](box-face-domain.md) onto face `f` of `[a, b]`; it is defined on all of `ℝ²`.
