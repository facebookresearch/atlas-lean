# Charge enclosed by a box

For `a, b ∈ ℝ³` the box is `[a, b] = {x ∈ ℝ³ : a_i ≤ x_i ≤ b_i for i = 0, 1, 2}`, with coordinate
axes indexed `0, 1, 2`. For a time-dependent charge density `ρ : ℝ × ℝ³ → ℝ`, the charge enclosed at
time `t` is

`Q(t) = ∫_{[a, b]} ρ(t, x) dx`,

with respect to Lebesgue measure; the integral is `0` when the integrand is not integrable there; it
is `0` for an empty box.
