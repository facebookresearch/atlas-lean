# Components of the TE10 magnetic field

For all real `a`, `E₀`, `ω`, `β`, every time `t` and point `(x, y, z)`, the
[TE10 magnetic field](te10-magnetic-field.md) is

`B = (-(βE₀/ω) sin(k_c x) cos(ωt - βz), 0, -(k_c E₀/ω) cos(k_c x) sin(ωt - βz))`,

with the [cutoff wavenumber](../evanescent-te10-field-below-cutoff/cutoff-wavenumber.md) `k_c = π/a` and quotients by `0` read as `0`, so
that `B = 0` when `ω = 0`.
