# The four-wall PEC traces are the explicit component conditions

For all reals `a`, `b` and fields `E, B : ℝ³ → ℝ³` (components indexed `0, 1, 2` for `x, y, z`), the
[PEC trace conditions](rectangular-guide-pectraces.md) hold if and only if the
[component conditions](rectangular-guide-peccomponent-condition.md) hold.
