# The four-wall PEC traces are the explicit component conditions

For all reals `a`, `b` and fields `E, B : ℝ³ → ℝ³` (components indexed `0, 1, 2` for `x, y, z`), the
[PEC trace conditions](rectangular-guide-pectraces.md), stated with the vanishing of the tangential
electric and normal magnetic fields on each wall, hold if and only if their component form holds:
`a > 0`, `b > 0`, `E_y = E_z = B_x = 0` at the points `(0, y, z)` and `(a, y, z)` with `0 ≤ y ≤ b`,
and `E_x = E_z = B_y = 0` at the points `(x, 0, z)` and `(x, b, z)` with `0 ≤ x ≤ a`, for every `z`.
