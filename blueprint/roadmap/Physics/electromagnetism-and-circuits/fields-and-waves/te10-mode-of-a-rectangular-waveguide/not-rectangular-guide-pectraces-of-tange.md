# A nonzero tangential electric component on x = 0 breaks the traces

For all reals `a`, `b`, fields `E, B : ℝ³ → ℝ³` (components indexed `0, 1, 2` for `x, y, z`), and
`0 ≤ y ≤ b` and `z` with `E(0, y, z)_y ≠ 0`, the
[PEC trace conditions](rectangular-guide-pectraces.md) fail, whatever equations the fields satisfy
elsewhere.
