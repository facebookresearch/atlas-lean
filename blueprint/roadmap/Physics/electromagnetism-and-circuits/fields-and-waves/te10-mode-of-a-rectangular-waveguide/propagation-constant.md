# Propagation constant of the TE10 mode

For real `c₀`, `a` and `ω`, the TE10 propagation constant is

`β = √(ω²/c₀² - k_c²)`,

with the [cutoff wavenumber](cutoff-wavenumber.md) `k_c = π/a`. With the conventions `√x = 0` for
`x < 0` and `x/0 = 0`, it is `0` below cutoff (`ω²/c₀² < k_c²`) and `ω²/c₀²` is read as `0` when
`c₀ = 0`. It is meaningful at or above cutoff, `ω ≥ c₀ k_c` with `c₀ > 0`.
