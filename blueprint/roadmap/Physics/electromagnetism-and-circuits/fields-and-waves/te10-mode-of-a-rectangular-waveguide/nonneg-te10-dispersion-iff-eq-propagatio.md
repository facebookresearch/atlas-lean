# For ω ≥ c k_c, the dispersion root β ≥ 0 is the propagation constant

Let `c > 0` be the speed of light. Let `a > 0` and `ω ≥ c k_c`, with the
[cutoff wavenumber](../evanescent-te10-field-below-cutoff/cutoff-wavenumber.md) `k_c = π/a`. A real `β` satisfies `β ≥ 0` and the
[dispersion relation](te10-dispersion.md) `ω² = c²(k_c² + β²)` if and only if `β = √(ω²/c² - k_c²)`,
the [propagation constant](propagation-constant.md).
