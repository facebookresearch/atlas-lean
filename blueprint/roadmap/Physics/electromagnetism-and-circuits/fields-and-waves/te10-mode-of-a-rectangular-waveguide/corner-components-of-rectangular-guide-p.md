# On the corner line x = y = 0 the traces force E = 0 and B_x = B_y = 0

For reals `a`, `b` and fields `E, B : ℝ³ → ℝ³` (components indexed `0, 1, 2` for `x, y, z`)
satisfying the [PEC trace conditions](rectangular-guide-pectraces.md), for every `z`:
`E(0, 0, z) = 0` and `B(0, 0, z)_x = B(0, 0, z)_y = 0`. The component `B_z` is left unconstrained.
