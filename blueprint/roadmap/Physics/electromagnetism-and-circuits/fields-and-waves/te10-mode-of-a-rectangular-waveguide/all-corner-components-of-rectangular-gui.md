# On all four corner lines the traces force E = 0 and B_x = B_y = 0

For reals `a`, `b` and fields `E, B : ℝ³ → ℝ³` (components indexed `0, 1, 2` for `x, y, z`)
satisfying the [PEC trace conditions](rectangular-guide-pectraces.md), for every `z` and each corner
`(x, y)` among `(0, 0)`, `(a, 0)`, `(0, b)` and `(a, b)`: `E(x, y, z) = 0` and
`B(x, y, z)_x = B(x, y, z)_y = 0`. The component `B_z` is left unconstrained.
