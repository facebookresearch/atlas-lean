# Terminal current through a cross-section

For a set `S ⊆ ℝ²` and an axial current density `J : ℝ² → ℝ`, the current `I = ∫_S J dA` (Lebesgue
integral) in the `+x` direction through the cross-section `S`: current enters at terminal `0` and
leaves at terminal `1`. If `J` is not integrable on `S`, the integral, and so `I`, is `0` by
convention.
