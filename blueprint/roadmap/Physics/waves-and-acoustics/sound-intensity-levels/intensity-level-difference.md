# Level difference in decibels between two intensities

For real `I₁` and `I₂`, the level difference of `I₂` over `I₁` is `ΔL = 10 log₁₀ (I₂ / I₁)`
decibels, with `log₁₀` the base-10 logarithm. It is meant for positive intensities in the same
unit. With the conventions `x / 0 = 0`, `log 0 = 0` and `log x = log |x|`, the value is `0` when
`I₁ = 0` or `I₂ = 0`, and `10 log₁₀ |I₂ / I₁|` when the ratio is negative.
