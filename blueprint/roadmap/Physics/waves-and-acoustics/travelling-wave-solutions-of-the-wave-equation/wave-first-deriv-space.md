# Space derivative of the travelling wave A cos(kx − ckt)

For all real `A`, `k`, `c`, `x` and `t`, the travelling wave `u(x, t) = A cos(k x - c k t)` has,
at fixed `t`, the space derivative
`∂u/∂x (x, t) = A · (-sin(k x - c k t)) · k = -k A sin(k x - c k t)`. The wave is a function of
`x - c t`: for `c > 0` and `k ≠ 0` it travels towards increasing `x` at speed `c`. In the
physical reading `c > 0` is the wave speed; the identity holds for all real values.
