# Wavenumber and wavelength are inverse: 2π / (2π / x) = x for x ≠ 0

For every real `λ ≠ 0`, the [wavelength](wavelength.md) of the [wavenumber](wavenumber.md) `2π / λ`
is `λ`: `2π / (2π / λ) = λ`.

Likewise, for every real `k ≠ 0`, the [wavenumber](wavenumber.md) of the [wavelength](wavelength.md)
`2π / k` is `k`.
