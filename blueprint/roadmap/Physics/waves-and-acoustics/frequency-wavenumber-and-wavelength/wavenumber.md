# Wavenumber k = 2π/λ of a wavelength λ

For a real wavelength `λ`, the wavenumber is `k = 2π / λ`. This is the physics convention; the
crystallographic convention `k = 1 / λ` differs by the factor `2π`. Physical wavelengths are
positive; the definition takes any real `λ`, and with the convention `x / 0 = 0` it gives `0` at
`λ = 0`.
