# Wavelength λ = 2π/k of a wavenumber k

For a real wavenumber `k`, the wavelength is `λ = 2π / k`, in the physics convention
`k = 2π / λ` of the [wavenumber](wavenumber.md). Physical wavenumbers are positive; the
definition takes any real `k`, and with the convention `x / 0 = 0` it gives `0` at `k = 0`.
