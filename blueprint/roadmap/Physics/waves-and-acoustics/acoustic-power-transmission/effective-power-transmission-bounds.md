# On a nonempty set of positive patches, 0 < τ ≤ 1 passes to the average

Let `s` be a nonempty finite set of patches. If every patch `i` of `s` has positive incident
intensity `I i > 0`, positive area `A i > 0` and transmission coefficient `0 < τ i ≤ 1`, then
the [effective power transmission coefficient](effective-power-transmission.md) satisfies
`0 < τ_eff ≤ 1`.
