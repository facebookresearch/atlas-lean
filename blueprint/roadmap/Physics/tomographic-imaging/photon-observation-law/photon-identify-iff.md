# Identification on an admissible set

For finite index types `ι` (rays) and `κ` (cells), positive source
intensities `I0 : ι → ℝ≥0` (`0 < I0 j` for all `j`), a real design matrix `A
: Matrix ι κ ℝ` and every set `D` of coefficient vectors, the map `x ↦
photonLaw I0 A x` is injective on `D` if and only if `x ↦ A *ᵥ x` is
injective on `D`.
