# Rank deficiency defeats photon-law identification

For finite index types `ι` and `κ`, any source intensities `I0 : ι → ℝ≥0`, a
real design matrix `A : Matrix ι κ ℝ` and a set `D` of coefficient vectors:
if `v ≠ 0` satisfies `A *ᵥ v = 0` and both `x` and `x + v` lie in `D`, then
the photon law `x ↦ photonLaw I0 A x` is not injective on `D`.
