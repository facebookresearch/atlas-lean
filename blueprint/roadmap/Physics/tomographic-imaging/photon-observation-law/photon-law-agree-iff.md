# Photon law identification

For finite index types `ι` (rays) and `κ` (cells), positive source
intensities `I0 : ι → ℝ≥0` (`0 < I0 j` for all `j`), a real design matrix `A
: Matrix ι κ ℝ` and coefficient vectors `x, x' : κ → ℝ`, the
independent-Poisson photon count laws at `x` and `x'` are equal if and only
if `A *ᵥ x = A *ᵥ x'`.
