# Position operator on functions

The [operator with domain](operator-with-domain.md) whose domain is the set of all functions `ℝ → ℂ`
and whose action is `f ↦ (x ↦ x f(x))`. This is multiplication by the coordinate on all functions
`ℝ → ℂ`, not the self-adjoint position operator on its domain in `L²(ℝ)`.
