# The absolute value is outside the momentum domain

An operator with domain is a set $D$ of functions $\mathbb{R} \to \mathbb{C}$ together with a map defined on $D$ only; no linearity, continuity or self-adjointness is assumed. The momentum operator is $f \mapsto -if'$ (units with $\hbar = 1$) on the domain of functions $\mathbb{R} \to \mathbb{C}$ differentiable everywhere. The function $x \mapsto |x|$ is not in its domain.
