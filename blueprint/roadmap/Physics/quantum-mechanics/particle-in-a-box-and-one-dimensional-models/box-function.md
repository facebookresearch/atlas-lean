# Particle-in-a-box eigenfunctions

For `n ≥ 1` and `L > 0`, the `n`-th particle-in-a-box eigenfunction is
`ψ_n(x) = √(2/L) * sin (n * π * x / L)`, real-valued and
[normalized on `[0, L]`](box-orthonormality-diag.md). The formula is defined for every natural `n`
and every real `x` and `L`: it is identically `0` for `n = 0`, and also for `L ≤ 0`, where `√(2/L)`
is `0` by the conventions `√y = 0` for `y < 0` and `2 / 0 = 0`.
