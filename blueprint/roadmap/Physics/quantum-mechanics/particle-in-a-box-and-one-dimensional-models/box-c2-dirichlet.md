# C² functions vanishing at both walls

Real-valued `C²` functions on `ℝ` vanishing at `0` and `L`: a smooth Dirichlet class for the box
states. It is not the Sobolev domain `H²(0, L) ∩ H¹₀(0, L)` of the box Hamiltonian, whose elements
are complex-valued `L²` classes with weak derivatives, and it is not a complex vector space, so it
is not a Hamiltonian domain.
