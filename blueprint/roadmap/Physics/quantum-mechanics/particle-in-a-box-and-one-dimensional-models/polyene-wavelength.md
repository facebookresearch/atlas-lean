# Free-electron absorption wavelength of a polyene

Model: absorption wavelength `h * c / ΔE` with `h = 2πħ`, a symbolic constant `c` and `ΔE` the
[HOMO–LUMO gap](polyene-gap.md). It is defined for every real `L`, `m`, `ħ` and `c`: when
`ΔE = 0`, as for `ħ = 0`, `m = 0` or `L = 0`, the convention `x / 0 = 0` makes it `0`. The intended
domain is `L, m, ħ, c > 0`, where `ΔE > 0`.
