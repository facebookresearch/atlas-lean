# Free-electron HOMO–LUMO gap of a polyene

Model: HOMO-LUMO gap `ΔE = E(k+1) - E(k)` from the box energies `E(n) = n^2 h^2 / (8 m L^2)` (HOMO
`n = k`, LUMO `n = k + 1` for `N = 2k` π-electrons). It is defined for every real `m` and `L`: for
`m = 0` or `L = 0` the convention `x / 0 = 0` makes both box energies, hence the gap, `0`. The
intended domain is `m > 0` and `L > 0`.
