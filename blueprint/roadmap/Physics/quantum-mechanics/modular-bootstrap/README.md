# Spinless modular bootstrap

Virasoro primary-gap bounds at zero angular potential. The setting is positive spectral data satisfying a temperature-crossing identity, together with odd radial Fourier eigenfunctions whose vacuum action is absolutely integrable. These pages follow the [version 1 paper](https://hexagonmath.org/2611.00174v1); they distinguish the best bound certified by this functional class from the actual gaps of individual conformal field theories.
