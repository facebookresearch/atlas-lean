# For 0 ≤ a < 1/2, 4 a (1 − a)² ≤ 16/27 with equality exactly at a = 1/3

For every real `a` with `0 ≤ a < 1/2`, `4 a (1 - a)² ≤ 16/27`, with equality exactly when `a = 1/3`:
on this interval the largest value of `4 a (1 - a)²` is `16/27`, attained only at `a = 1/3`. The
bound follows from `16/27 - 4 a (1 - a)² = 4 (a - 1/3)² (4/3 - a)`. For an
[axial induction factor](induction-factor.md) `a` it bounds the
[power coefficient](power-coefficient-eq.md) `C_P = 4 a (1 - a)²`.
