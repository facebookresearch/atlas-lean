# Power coefficient C_P = T U_d / (ρ A U∞³ / 2)

For an [actuator-disk state](actuator-disk.md), the power coefficient is
`C_P = T U_d / (ρ A U∞³ / 2)`, the [extracted power](extracted-power.md) `T U_d` divided by the
[freestream kinetic power](power-normalization.md) `ρ A U∞³ / 2` through the disk area. With the
convention `x / 0 = 0` it is `0` when `ρ A U∞³ = 0`, in particular in still air (`U∞ = 0`); the
intended domain is `ρ > 0`, `A > 0` and `U∞ > 0`.
