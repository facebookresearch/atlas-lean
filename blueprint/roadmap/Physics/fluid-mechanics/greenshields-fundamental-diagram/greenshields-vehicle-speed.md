# Vehicle speed under the Greenshields closure

For a free-flow speed `vf`, a jam density `kj` and a density `k` (real numbers), the Greenshields
vehicle speed is `v(k) = vf (1 - k / kj)`. With the convention `x / 0 = 0` it is the constant `vf`
when `kj = 0`. The physical reading is `vf > 0`, `kj > 0` and `0 ≤ k ≤ kj`.
