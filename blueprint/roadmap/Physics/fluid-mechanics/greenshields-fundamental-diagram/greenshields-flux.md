# Greenshields traffic flux

For a free-flow speed `vf`, a jam density `kj` and a density `k` (real numbers), the Greenshields
traffic flux is `q(k) = vf k (1 - k / kj)`, the flux of the linear speed–density closure of the
Greenshields fundamental diagram. With the convention `x / 0 = 0` it is `vf k` when `kj = 0`. The
physical reading is `vf > 0`, `kj > 0` and `0 ≤ k ≤ kj`.
