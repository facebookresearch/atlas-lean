# Entropy jump across the distinct normal-shock branch

For real `γ` and `m`, the dimensionless entropy jump of the distinct branch is
`Δs / R = log P / (γ - 1) - γ log r / (γ - 1)`, with its pressure ratio
`P = (2 γ m - (γ - 1)) / (γ + 1)` and density ratio `r = (γ + 1) m / ((γ - 1) m + 2)`. The physical
domain is `γ > 1` and `m > (γ - 1) / (2 γ)`: for `γ > 1`, `R > 0` and an upstream state with
`ρ1, T1, u1 > 0`, `p1 = ρ1 R T1` and `m = M1²`, where `M1 = |u1| / a1` and `a1² = γ R T1`, the
distinct branch has positive pressure and temperature
[exactly above this threshold](is-normal-shock-jump-distinct-pos-iff.md). At or below the threshold
the value is given by the conventions `log 0 = 0` and `log x = log |x|`, and with `x / 0 = 0` it is
`0` at `γ = 1`.
