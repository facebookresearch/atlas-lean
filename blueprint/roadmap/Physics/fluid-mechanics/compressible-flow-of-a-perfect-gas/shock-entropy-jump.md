# Entropy jump across the distinct normal-shock branch

For real `γ` and `m`, the dimensionless entropy jump of the distinct branch is
`Δs / R = log P / (γ - 1) - γ log r / (γ - 1)`, with its pressure ratio
`P = (2 γ m - (γ - 1)) / (γ + 1)` and density ratio `r = (γ + 1) m / ((γ - 1) m + 2)`. The physical
domain is `γ > 1` and `m > (γ - 1) / (2 γ)`, the threshold above which the distinct branch has
[positive pressure](is-normal-shock-jump-distinct-pos-iff.md). Below the threshold the value is
given by the conventions `log 0 = 0` and `log x = log |x|`, and with `x / 0 = 0` it is `0` at
`γ = 1`.
