# The two branches coincide exactly at unit Mach number

For `γ > 1` and `m ≥ 0`, the density ratio `r = (γ + 1) m / ((γ - 1) m + 2)` and the pressure ratio
`P = (2 γ m - (γ - 1)) / (γ + 1)` of the distinct branch each equal `1` if and only if `m = 1`, and
at `m = 1` the temperature ratio `P / r` is `1`: the distinct branch is then the trivial one.
