# Entropy selects the compression branch of a normal shock

Let `γ > 1` and `R > 0`, and let an upstream state `(ρ1, u1, p1, T1)` and a downstream state
`(ρ2, u2, p2, T2)` with `ρ1, T1, ρ2, T2 > 0` satisfy the
[normal-shock jump conditions](is-normal-shock-jump.md). Let `a1² = γ R T1` and `M1 = |u1| / a1`.
Suppose the downstream state is not the upstream one. If `M1 > 0`, then the
[specific entropy change](specific-entropy-change.md) `Δs = cv log (T2 / T1) + R log (v2 / v1)` with
`cv = R / (γ - 1)` and the specific volumes `v_i = 1 / ρ_i` is positive if and only if `M1 > 1`, and
negative if and only if `M1 < 1`.
