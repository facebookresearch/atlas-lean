# Integral curves in affine coordinates

For a vector field $u$ on three-dimensional space, a curve $\gamma$, a set of times $s$ and an origin $o$, $\gamma$ is an integral curve of $u$ on $s$ if and only if $t \mapsto \gamma(t) - o$ is an integral curve on $s$ of the coordinate field $v \mapsto u(v + o)$.
