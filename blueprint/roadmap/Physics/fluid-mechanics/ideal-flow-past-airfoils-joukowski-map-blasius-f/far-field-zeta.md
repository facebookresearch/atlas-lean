# Far-field inverse branch ζ(z) of the Joukowski map

For complex numbers `a` and `z`, the far-field branch is `ζ(z) = (z/2)(1 + √(1 − 4a²/z²))`, where
`√` is the principal square root: `√w = exp((log w)/2)` for `w ≠ 0`, with the principal logarithm,
so that `√w` has nonnegative real part and `√(−r) = i√r` for real `r > 0`; and `√0 = 0`. With the
convention `x/0 = 0`, `ζ(0) = 0`; for `a = 0`, `ζ(z) = z`. The branch is meant for real `a > 0` on
the exterior region `‖z‖ > 2a`. There it is holomorphic
([holomorphy](differentiable-at-far-field-zeta.md)), the [Joukowski map](joukowski.md) sends it back
to `z` ([right inverse](joukowski-far-field-zeta.md)), and `‖ζ(z)‖ > a`
([outside the circle](abs-far-field-zeta-gt.md)). At the boundary points `z = ±2a` the square root
vanishes and `ζ(±2a) = ±a`.
