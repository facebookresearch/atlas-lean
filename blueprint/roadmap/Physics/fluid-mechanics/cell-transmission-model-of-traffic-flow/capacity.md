# Capacity v w kj / (v + w) of the triangular fundamental diagram

For a free-flow speed `v`, a wave speed `w` and a jam density `kj` (real numbers), the capacity of
the triangular fundamental diagram is `v w kj / (v + w)`, its peak flow, attained at the critical
density `kc = w kj / (v + w)` ([capacity attained](capacity-attained.md)). With the convention
`x / 0 = 0` it is `0` when `v + w = 0`. In the physical reading `v`, `w` and `kj` are positive; the
definition takes any real values.
