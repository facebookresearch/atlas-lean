# Wall values of the single-mode profile

For `L ≠ 0` and all real `A`, `ν` and `t`, the [single-mode profile](single-mode-profile.md)
`U(t, y) = A y / L - (A / π) sin(π y / L) exp(-ν (π / L)² t)` satisfies `U(t, 0) = 0` and
`U(t, L) = A`: the wall `y = 0` is at rest and the wall `y = L` moves with velocity `A`.
