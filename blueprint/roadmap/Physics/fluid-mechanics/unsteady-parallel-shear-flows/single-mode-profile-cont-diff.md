# The single-mode profile is twice continuously differentiable

For all real `A`, `L` and `ν`, the [single-mode profile](single-mode-profile.md)
`U(t, y) = A y / L - (A / π) sin(π y / L) exp(-ν (π / L)² t)` is jointly twice continuously
differentiable in `(t, y)` (at `L = 0` it is identically `0`).
