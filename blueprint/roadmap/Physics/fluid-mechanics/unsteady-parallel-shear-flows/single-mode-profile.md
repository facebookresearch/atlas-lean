# Single-mode transient between a fixed and a moving wall

For real `A`, `L`, `ν`, `t` and `y`, the single-mode profile is
`U(t, y) = A y / L - (A / π) sin(π y / L) exp(-ν (π / L)² t)`, the plane Couette profile `A y / L`
minus one decaying sine mode. For `L ≠ 0` it vanishes on the wall `y = 0` and equals `A` on the wall
`y = L` at every time ([wall values](single-mode-profile-walls.md)); with the convention `x / 0 = 0`
it is identically `0` when `L = 0`. It is not a start from rest: for `ρ, μ, L > 0`, `A ≠ 0` and
`ν = μ / ρ` its kinetic energy at `t = 0` is positive
([positive kinetic energy](single-mode-profile-energy-pos.md)).
