# Velocity of plane Poiseuille flow

For a pressure-drop rate `G` (`G = -∂p/∂x₀`, signed), a viscosity `μ` and a channel height `H`, the
plane Poiseuille velocity is `u(x) = (G x₁ (H - x₁) / (2 μ), 0, 0)`, with `x₁` the wall-normal
coordinate. With the convention `x / 0 = 0` it is `0` when `μ = 0`. The physical reading is the
channel `0 ≤ x₁ ≤ H` with `H > 0` and `μ > 0`.
