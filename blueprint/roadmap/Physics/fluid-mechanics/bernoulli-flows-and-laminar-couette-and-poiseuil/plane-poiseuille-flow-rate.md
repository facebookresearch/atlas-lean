# Flow rate per unit width of plane Poiseuille flow

For all real `G`, `μ`, `H`, `s` and `z`, the streamwise component of the
[plane Poiseuille velocity](plane-poiseuille-velocity.md) `u(x) = (G x₁ (H - x₁) / (2 μ), 0, 0)` on
the cross-section `x₀ = s`, `x₂ = z` has the integral `∫_0^H u₀(s, y, z) dy = G H³ / (12 μ)`. With
the convention `x / 0 = 0` both sides are `0` when `μ = 0`.
