# Integral curves of a velocity field in affine coordinates

For a vector field `u` on three-dimensional space, a curve `γ : ℝ → space`, a set `s ⊆ ℝ` and an
origin `o`, `γ` is an integral curve of `u` on `s` (for the manifold structure of space) if and only
if its coordinate curve `t ↦ γ(t) - o` is an integral curve of the coordinate field `v ↦ u(o + v)`
on `s`.
