# Rotating fluid with a polytropic enthalpy

For real `ρ`, `Ω` and `g`, the polytropic fixture is the [rotating fluid](rot-flow.md) with entropy
`0` and the enthalpy `h = (7 / 2) p / ρ`, that is `(γ / (γ - 1)) p / ρ` for `γ = 7 / 5`, with the
[balancing pressure](rot-pressure.md) `p`. With the convention `x / 0 = 0`, `h = 0` when `ρ = 0`.
