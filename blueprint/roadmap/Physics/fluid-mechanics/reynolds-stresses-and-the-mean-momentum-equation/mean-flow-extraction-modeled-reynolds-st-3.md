# For a nonzero trace-free strain, P ≥ 0 exactly when νt ≥ 0

For every real `k` and `νt` and every nonzero real `3 × 3` matrix `S` with trace `0`, the
[extraction](mean-flow-extraction.md) `P(Rm, S) = 2 νt ‖S‖²` of the
[closure](modeled-reynolds-stress.md) ([identity](mean-flow-extraction-modeled-reynolds-st.md)) is
nonnegative if and only if `νt ≥ 0`.
