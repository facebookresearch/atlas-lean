# Support of the interface test function

Let $\beta$ be a smooth bump function centered at $t_0$ with outer radius $\rho_\beta$, $\theta$ a smooth bump function centered at $0$ with outer radius $\rho_\theta$, and $\varphi(t, x) = \beta(t)\,\theta(x - c t)$ the interface test function of the line $x = c t$. Then $\varphi$ vanishes outside the rectangle $[t_0 - \rho_\beta, t_0 + \rho_\beta] \times [-X, X]$ with $X = |c|\,(|t_0| + \rho_\beta) + \rho_\theta$.
