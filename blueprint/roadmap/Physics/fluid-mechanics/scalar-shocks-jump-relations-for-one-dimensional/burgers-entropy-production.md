# Entropy production of a Burgers shock

For a jump from the left state $u_L$ to the right state $u_R$ moving with speed $c$, the entropy production is $[q] - c\,[\eta] = \big(q(u_R) - q(u_L)\big) - c\,\big(\eta(u_R) - \eta(u_L)\big)$ with $\eta(u) = u^2/2$ and $q(u) = u^3/3$; the entropy condition requires it to be nonpositive.
