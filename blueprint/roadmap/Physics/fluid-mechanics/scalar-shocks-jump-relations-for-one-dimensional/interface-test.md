# Test function concentrated near a moving front

For a smooth bump function $\beta$ centered at $t_0$, a smooth bump function $\theta$ centered at $0$ and a speed $c$, the interface test function of the front $x = c t$ is $\varphi(t, x) = \beta(t)\,\theta(x - c t)$. A smooth bump function centred at $a$ with radii $0 < r_{in} < r_{out}$ is a smooth function with values in $[0, 1]$ that equals $1$ on the closed ball of radius $r_{in}$ about $a$, is positive on the open ball of radius $r_{out}$ and vanishes outside it; in particular $\theta(0) = 1$.
