# Rankine–Hugoniot speed for the Burgers equation from conservation

Let $u_L \ne u_R$, let an interface $s$ be differentiable at time $t$ with speed $c = s'(t)$, and let $a < s(t) < b$. Then the mass $\int_a^{s(\tau)} u_L\,dx + \int_{s(\tau)}^b u_R\,dx$ has derivative $f(u_L) - f(u_R)$ at $t$, with $f(u) = u^2/2$, if and only if $c = (u_L + u_R)/2$.
