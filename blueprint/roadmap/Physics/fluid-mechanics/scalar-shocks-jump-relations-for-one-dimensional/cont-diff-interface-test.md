# The interface test function is smooth

Let $\beta$ be a smooth bump function centered at $t_0$ with outer radius $\rho_\beta$, $\theta$ a smooth bump function centered at $0$ with outer radius $\rho_\theta$, and $\varphi(t, x) = \beta(t)\,\theta(x - c t)$ the interface test function of the line $x = c t$. Then $\varphi$ is infinitely differentiable on the $(t, x)$ plane.
