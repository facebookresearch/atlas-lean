# Time derivative of the interface test function is correct

Let $\beta$ be a smooth bump function centered at $t_0$ with outer radius $\rho_\beta$, $\theta$ a smooth bump function centered at $0$ with outer radius $\rho_\theta$, and $\varphi(t, x) = \beta(t)\,\theta(x - c t)$ the interface test function of the line $x = c t$. Then for all $t$ and $x$, $\tau \mapsto \varphi(\tau, x)$ has derivative $\beta'(t)\,\theta(x - c t) - c\,\beta(t)\,\theta'(x - c t)$ at $t$.
