# The interface test function along the front

Let $\beta$ be a smooth bump function centered at $t_0$ with outer radius $\rho_\beta$, $\theta$ a smooth bump function centered at $0$ with outer radius $\rho_\theta$, both (normalized as on the [interface test function](interface-test.md) page: equal to $1$ on its closed inner ball, positive on its open outer ball, zero outside), and $\varphi(t, x) = \beta(t)\,\theta(x - c t)$ the interface test function of the line $x = c t$. Then $\varphi(t, c t) = \beta(t)$ for every $t$, the interval $(t_0 - \rho_\beta, t_0 + \rho_\beta)$ is nonempty, and $\varphi(t, c t) > 0$ for every $t$ in it.
