# Dissipation in a passive pipe network is nonnegative

Let a network have finite node and arc sets, arc tails and heads, resistance coefficients $r_e$, signed arc flows $q_e$, net node inflows $d_v$ and node heads $h_v$, satisfying the pipe-flow equations: $B q = d$ for the node–arc incidence matrix $B$, and $-B^{\mathsf T} h = (r_e\,q_e\,|q_e|)_e$. If $r_e \ge 0$ for every arc, then $-\sum_v h_v d_v \ge 0$.
