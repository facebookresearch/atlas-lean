# Head drop along a pipe

Let a network have finite node and arc sets, arc tails and heads, resistance coefficients $r_e$, signed arc flows $q_e$, net node inflows $d_v$ and node heads $h_v$, satisfying the pipe-flow equations: $B q = d$ for the node–arc incidence matrix $B$, and $-B^{\mathsf T} h = (r_e\,q_e\,|q_e|)_e$. Then on every arc $e$, $h_{tail(e)} - h_{head(e)} = r_e\,q_e\,|q_e|$.
