# Dissipation in a pipe network

Let a network have finite node and arc sets, arc tails and heads, resistance coefficients $r_e$, signed arc flows $q_e$, net node inflows $d_v$ and node heads $h_v$, satisfying the pipe-flow equations: $B q = d$ for the node–arc incidence matrix $B$, and $-B^{\mathsf T} h = (r_e\,q_e\,|q_e|)_e$. Then $-\sum_v h_v d_v = \sum_e r_e\,q_e^2\,|q_e|$.
