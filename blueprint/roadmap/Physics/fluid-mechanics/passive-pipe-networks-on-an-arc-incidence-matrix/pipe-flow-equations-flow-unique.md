# Pipe network flows are unique

Let a finite pipe network have nodes $V$, edges $E$ with tail and head maps, and incidence matrix $B$. Suppose every resistance is positive, $r_e > 0$. If $(q_1, h_1)$ and $(q_2, h_2)$ both satisfy the pipe-flow equations with the same nodal demand $d$, namely $B q = d$ and $-(B^{\mathsf T} h)_e = r_e\, q_e |q_e|$ for every edge $e$, then $q_1 = q_2$.
