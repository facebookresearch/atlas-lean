# Head drop in a passive pipe network

In a finite pipe network with resistances $r_e \ge 0$, flows $q_e$, nodal demands and heads $h$ satisfying the pipe-flow equations, every pipe $e$ from node $\mathrm{tail}(e)$ to node $\mathrm{head}(e)$ has head drop $h(\mathrm{tail}\,e) - h(\mathrm{head}\,e) = r_e q_e \lvert q_e\rvert$.
