# Left-travelling discharge q(t, x) = −(g A / a) F(x + a t)

For reals `g`, `A`, `a` and a profile `F : ℝ → ℝ`, the left-travelling discharge is
`q_L(t, x) = -(g A / a) F(x + a t)` for all real `t` and `x`, the discharge that accompanies the
[left-travelling head](h-l.md) `F(x + a t)`. With the convention `x / 0 = 0` it is `0` when `a = 0`.
In the physical reading `g` is the gravitational acceleration, `A` the pipe area and `a` the wave
speed, all positive.
