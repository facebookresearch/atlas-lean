# Darcy–Weisbach loss coefficient f L ρ / (2 D A²)

For a Darcy factor `f`, a duct length `L`, a hydraulic diameter `D`, a flow area `A` and a density
`ρ` (real numbers), the Darcy–Weisbach loss coefficient is `c = f L ρ / (2 D A²)`, so that the
[pressure drop](friction-pressure-drop.md) at the volumetric flow `Q` is `c Q |Q|`. With the
convention `x / 0 = 0` it is `0` when `D = 0` or `A = 0`. Physically all five quantities are
positive.
