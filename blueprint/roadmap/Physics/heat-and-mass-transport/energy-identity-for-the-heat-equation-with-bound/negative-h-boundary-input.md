# A negative transfer coefficient can make the boundary work positive

There are reals `k > 0`, `h₀ < 0`, `D > 0` and `θ₀`, `ux₀`, `θ_L`, `ux_L` with the outward Robin
condition `k ux₀ = h₀ θ₀` at `x = 0`, `-k ux_L = 0 · θ_L`, and positive boundary work

`D (θ_L ux_L - θ₀ ux₀) > 0`.

The proof takes `k = D = 1`, `h₀ = -1`, `θ₀ = 1`, `ux₀ = -1` and `θ_L = ux_L = 0`, giving boundary
work `1`. So `h₀ ≥ 0` is needed for dissipation.
