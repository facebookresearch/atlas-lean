# For x > 0 and D > 0 the profile tends to 0 as t → 0⁺

Let `x > 0` and `D > 0`. For every real `cs`, the [error-function profile](erfc-profile.md)
`C(x, t) = cs · erfc(x/√(4Dt))` satisfies `C(x, t) → 0` as `t → 0⁺`: the medium is initially empty.
At `t = 0` itself the profile is `cs`, because `x/√0` is read as `0`.
