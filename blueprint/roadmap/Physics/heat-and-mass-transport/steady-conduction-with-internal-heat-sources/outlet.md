# For ṁ, cp > 0, 0 < L ≤ Lₑ each steady profile ends at the outlet value

Let `ṁ > 0`, `cp > 0` and `0 < L ≤ Lₑ`. Every [steady coolant profile](is-steady-coolant-profile.md)
`T` with inlet value `T_in` satisfies

`T(L/2) = T_in + 2q₀Lₑ sin(πL/(2Lₑ))/(π ṁ cp)`,

the [outlet temperature](coolant-outlet-temp.md).
