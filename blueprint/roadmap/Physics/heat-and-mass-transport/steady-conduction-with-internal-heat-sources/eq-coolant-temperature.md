# For ṁ, cp, Lₑ > 0 every steady coolant profile is the integrated one

Let `ṁ > 0`, `cp > 0` and `Lₑ > 0`. If `T` is a
[steady coolant profile](is-steady-coolant-profile.md) with inlet value `T_in`, then for every `z`
with `-L/2 ≤ z ≤ L/2`,

`T(z) = T_in + q₀Lₑ (sin(πz/Lₑ) + sin(πL/(2Lₑ)))/(π ṁ cp)`,

the [integrated coolant temperature](coolant-temperature.md).
