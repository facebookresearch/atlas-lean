# For a nonzero slope, the calibrated value is x + ε / a

Let the reading of an instrument follow the known linear calibration `y = a x + b + ε`, with slope
`a ≠ 0`, offset `b`, true value `x` and error `ε` (all real). The calibrated value is the true value
plus the scaled error: `(a x + b + ε - b) / a = x + ε / a`.
