# The time-constant law τ = L / R is dimensionally correct

The [time-constant law](lrtime-constant.md) `τ = L / R` between a time, an inductance and a
resistance is dimensionally correct: for every two choices of units and all values of the
quantities, it holds for the numerical values in one choice of units exactly when it holds for the
values converted to the other. Here a choice of units assigns a positive magnitude to the unit of
each of length, time, mass, charge and temperature, and a value of dimension `L^l T^t M^m C^c Θ^θ`
is multiplied by `(ℓ₁/ℓ₂)^l (t₁/t₂)^t (m₁/m₂)^m (q₁/q₂)^c (θ₁/θ₂)^θ` when the units change from
magnitudes `ℓ₁, t₁, m₁, q₁, θ₁` to `ℓ₂, t₂, m₂, q₂, θ₂`.

This includes `R = 0`, where the law reads `τ = 0` by the convention `x / 0 = 0`: both sides scale
together.
