# Current maps to the ISQ current base

Let $\iota$ be the group homomorphism from dimensions over length, time, mass, charge and temperature to ISQ dimensions that sends length, time, mass and temperature to the ISQ base quantities of the same name and charge $\mathsf{C}$ to $\mathsf{I}\,\mathsf{T}$. Then the current dimension maps to the ISQ base dimension of electric current: $\iota(\mathsf{C}\,\mathsf{T}^{-1}) = \mathsf{I}$.
