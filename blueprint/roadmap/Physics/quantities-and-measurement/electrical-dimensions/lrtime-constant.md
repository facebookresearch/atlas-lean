# Time-constant law τ = L / R of an inductive circuit

The inductor–resistor time-constant law: a relation between a time `τ`, an inductance `L` and a
resistance `R` (values of the time, [inductance](inductance-dim.md) and
[resistance](resistance-dim.md) dimensions), which holds when their numerical values satisfy
`τ = L / R`. With the convention `x / 0 = 0`, for `R = 0` it says `τ = 0`; physically `R > 0`.
