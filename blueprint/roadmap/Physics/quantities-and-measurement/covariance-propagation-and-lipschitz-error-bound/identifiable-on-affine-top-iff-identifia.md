# On the whole space, affine identifiability is identifiability

For every real $m \times n$ matrix $A$, $A$ is [identifiable on](identifiable-on-affine.md) the
affine subspace $S = \mathbb{R}^n$ (the whole parameter space) if and only if the calibration
model $y = A\theta$ is [identifiable](identifiable.md), that is, $\theta \mapsto A\theta$ is
injective on $\mathbb{R}^n$.
