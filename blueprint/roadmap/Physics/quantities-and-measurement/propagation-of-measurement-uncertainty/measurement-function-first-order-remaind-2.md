# Explicit first-order remainder for a C² measurement function

If `f : ℝ^ι → ℝ` is of class `C²` on an open set `U` containing the box `[lo, hi]` (`lo ≤ y ≤ hi`
componentwise) and its second derivative satisfies `‖D²f(y)‖ ≤ H` on the box, then for `x` and
`x + h` in the box `|f (x + h) - f x - Df(x) h| ≤ 1 / 2 * H * ‖h‖ ^ 2`, for the sup norm on `ℝ^ι`
and the corresponding operator norm.
