# First-order law of propagation for a C¹ measurement function

Let `X i` (`i ∈ ι`, a finite index set) be real random variables with finite second moments on a
probability space. If `f` is of class `C¹` on an open set `U` containing the input estimate `x` (for
instance an open set containing a box around `x`), then `f` is differentiable at `x`, and the
variance of the linearization `ω ↦ f x + Df(x) (X ω - x)` is `∑ i, ∑ j, cᵢ * cⱼ * cov[X i, X j]`,
with the sensitivity coefficients `cᵢ = ∂f/∂xᵢ (x)`.
