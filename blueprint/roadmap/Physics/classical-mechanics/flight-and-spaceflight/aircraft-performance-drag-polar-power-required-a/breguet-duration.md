# Breguet endurance

For reals `Λ`, `cW`, `Wi` and `Wf`, `Λ / cW · log(Wi / Wf)`: the cruise time from the weight `Wi`
down to `Wf`. With the conventions `x / 0 = 0`, `log 0 = 0` and `log x = log |x|`, it is `0` when
`cW = 0`, `Wi = 0` or `Wf = 0`, and it takes the value `Λ / cW · log |Wi / Wf|` when `Wi / Wf < 0`.
In the physical reading `Λ, cW > 0` and `Wi ≥ Wf > 0`.
