# Level-flight drag as a function of speed

For reals `W`, `ρ`, `S`, `CD0`, `k` and `V`, `D(V) = a V² + b / V²` with `a = ρ S CD0 / 2` and
`b = 2 k W² / (ρ S)` (the [parasite-drag](parasite-drag-factor.md) and
[induced-drag](induced-drag-factor.md) factors). With the convention `x / 0 = 0`, `D(0) = 0`, which
is not a physical drag. In level flight (lift equal to weight) at a nonzero speed, with `ρ, S ≠ 0`,
it is the [polar drag](polar-drag.md) ([in level flight](polar-drag-eq-level-drag.md)).
