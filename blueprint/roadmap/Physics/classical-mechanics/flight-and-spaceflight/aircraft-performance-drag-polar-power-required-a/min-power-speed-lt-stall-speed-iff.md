# The minimum-power speed is below V_s iff CLmax < √(3 CD0 / k)

For `W > 0` and `ρ, S, CD0, k, CLmax > 0`, the [minimum-power speed](min-power-speed.md) `V_mp` is
below the [stall speed](stall-speed.md) `V_s = √(2 W / (ρ S CLmax))` if and only if
`CLmax < √(3 CD0 / k)`, its lift coefficient; it is then not an operating point.
