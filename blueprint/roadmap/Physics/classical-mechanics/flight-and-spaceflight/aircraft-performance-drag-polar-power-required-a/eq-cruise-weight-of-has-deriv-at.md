# Every solution of the fuel law on an interval is the cruise weight

For reals `cW`, `Λ` and `t₁`, if a function `W` has derivative `−cW W(t) / Λ` at every
`t ∈ [0, t₁]`, then `W(t) = W(0) exp(−(cW / Λ) t)` for every `t ∈ [0, t₁]`, the
[cruise weight](cruise-weight.md) from the initial value `W(0)`.
