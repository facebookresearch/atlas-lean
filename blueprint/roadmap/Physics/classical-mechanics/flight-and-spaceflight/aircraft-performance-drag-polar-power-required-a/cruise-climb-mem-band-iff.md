# The cruise-climb stays in a band exactly when its two ends do

For `Rs > 0`, `T > 0`, `cW > 0`, `Λ > 0`, `0 < Wf ≤ Wi` and every real `g`, the height
`z₀ + H (cW / Λ) t`, with `H = Rs T / |g|` the [scale height](scale-height.md), lies in `[z₁, z₂]`
for every `t` in `[0, Λ / cW · log(Wi / Wf)]` if and only if `z₁ ≤ z₀` and
`z₀ + H log(Wi / Wf) ≤ z₂`: the cruise climbs `H log(Wi / Wf)` in all.
