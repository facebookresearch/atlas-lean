# Density of an isothermal layer

For reals `ρ0`, `g`, `Rs`, `T` and a height `z`, the density `ρ(z) = p(z) / (Rs T)` given by the
ideal-gas relation from the
[isothermal pressure profile](../../../../EarthScience/atmosphere-and-climate/isothermal-atmosphere-and-scale-height/isothermal-pressure.md)
`p(z) = p0 exp(−g z / (Rs T))` with reference pressure `p0 = ρ0 Rs T`; for `Rs T ≠ 0` this is
`ρ(z) = ρ0 exp(−g z / (Rs T))`. With the convention `x / 0 = 0` the density is `0` when `Rs T = 0`.
In the physical reading `ρ0, g, Rs, T > 0`, with `z` measured upward and restricted to a declared
band of heights.
