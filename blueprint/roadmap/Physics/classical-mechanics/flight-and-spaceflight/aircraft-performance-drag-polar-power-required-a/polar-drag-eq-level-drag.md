# In level flight the polar drag is a V² + b / V²

For `ρ ≠ 0`, `S ≠ 0` and `V ≠ 0`, if the lift `ρ V² / 2 · S · CL` equals the weight `W`, then the
[polar drag](polar-drag.md) `ρ V² / 2 · S · (CD0 + k CL²)` equals the
[level-flight drag](level-drag.md) `D(V) = a V² + b / V²`, with `a = ρ S CD0 / 2` and
`b = 2 k W² / (ρ S)` (the [parasite-drag](parasite-drag-factor.md) and
[induced-drag](induced-drag-factor.md) factors). This is level flight with the thrust along the
velocity. Multiplying by the speed gives the same result as a power: the polar drag times the speed,
`ρ V² / 2 · S · (CD0 + k CL²) · V`, equals the [power required](level-power.md) `P(V) = D(V) V`.
