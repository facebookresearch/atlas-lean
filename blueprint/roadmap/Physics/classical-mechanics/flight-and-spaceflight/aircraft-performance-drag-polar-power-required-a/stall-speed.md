# Stall speed

For reals `W`, `ρ`, `S` and `CLmax` (the maximum lift coefficient of the polar),
`V_s = √(2 W / (ρ S CLmax))`. With the conventions `x / 0 = 0` and `√x = 0` for `x ≤ 0`, `V_s = 0`
when the radicand is not positive, in particular for `W ≤ 0` when `ρ, S, CLmax > 0`. In the physical
reading `W, ρ, S, CLmax > 0`.
