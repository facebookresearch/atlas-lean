# For η > 0 the shaft power has the same positive minimizers

For a constant efficiency `η > 0`, `ρ > 0`, `S > 0`, `CD0 > 0`, all real `W` and `k`, and a speed
`V > 0`, `V` minimizes the [shaft power](shaft-power-required.md) `P / η` over all positive speeds
if and only if `V⁴ = b / (3a)`, with `a = ρ S CD0 / 2` and `b = 2 k W² / (ρ S)` (the
[parasite-drag](parasite-drag-factor.md) and [induced-drag](induced-drag-factor.md) factors).
