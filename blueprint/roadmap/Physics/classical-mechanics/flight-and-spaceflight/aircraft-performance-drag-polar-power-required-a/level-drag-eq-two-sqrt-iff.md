# Level-flight drag equals 2 √(a b) exactly when V⁴ = b / a

For `ρ > 0`, `S > 0`, `CD0 > 0`, `k ≥ 0`, every real `W` and every speed `V ≠ 0`, the
[level-flight drag](level-drag.md) `D(V) = a V² + b / V²` equals `2 √(a b)` if and only if
`V⁴ = b / a`, with `a = ρ S CD0 / 2` and `b = 2 k W² / (ρ S)` (the
[parasite-drag](parasite-drag-factor.md) and [induced-drag](induced-drag-factor.md) factors).
