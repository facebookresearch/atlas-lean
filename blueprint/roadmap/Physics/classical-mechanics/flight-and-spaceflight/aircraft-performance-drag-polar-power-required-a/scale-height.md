# Scale height of an isothermal layer

For reals `Rs`, `T` and `g`, `H = Rs T / |g|`: the scale height of an isothermal layer with
mass-specific gas constant `Rs`, absolute temperature `T` and gravitational acceleration of
magnitude `|g|`; it is a length. With the convention `x / 0 = 0`, `H = 0` at `g = 0`. In the
physical reading `Rs, T > 0` and `g ≠ 0`.
