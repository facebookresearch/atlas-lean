# A depleted or negative stage mass is not admissible

For `k < n`, if `m₁ k ≤ 0` or `m₀ k ≤ 0`, then `m₀`, `m₁` are not
[admissible stage masses](admissible-stage-masses.md) for `n` burns. If `m₁ k = 0`, the
[stage increment](stage-increment.md) `ve log(m₀ k / m₁ k)` is `0` for every real `ve` (by the
conventions `x / 0 = 0` and `log 0 = 0`), which would price a burn to empty mass as free.
