# Zero beam current leaves the efficiency denominator zero

For `m_i > 0`, `q_i > 0`, `V_b > 0` and every real `P_in`, at zero beam current the
[beam mass flow](beam-mass-flow.md) is `0`, so the efficiency denominator `2 ṁ P_in` is `0`, while
the [ion exhaust speed](ion-exhaust-speed.md) `v_e = √(2 q_i V_b / m_i)` is positive. With the
convention `x / 0 = 0` the [thrust efficiency](thrust-efficiency.md) `T² / (2 ṁ P_in)` is then `0`,
which is not a physical efficiency.
