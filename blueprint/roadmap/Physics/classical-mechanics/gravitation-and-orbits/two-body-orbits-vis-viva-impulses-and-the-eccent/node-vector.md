# Ascending-node vector n = k × h

For a state `(x, v)` with `x, v ∈ ℝ³`, the ascending-node vector is `n = k × h = (−h₂, h₁, 0)`,
where `k = (0, 0, 1)` is the pole of the reference plane (the third coordinate axis) and
`h = x × v = (h₁, h₂, h₃)` is the specific angular momentum (cross product). The node direction
`n / |n|` is undefined where `n = 0`.
