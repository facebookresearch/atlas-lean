# For μ > 0 and r > 0, e = 0 iff the state is circular

For `μ > 0` and a state `(x, v)` with `r = √(x · x) > 0`, the
[eccentricity vector](eccentricity-vector.md) `e` vanishes if and only if the state is circular: its
velocity is transverse, `x · v = 0`, and its squared speed is the circular value `v · v = μ / r`. So
the pericenter direction `e / |e|` is undefined exactly for circular states.
