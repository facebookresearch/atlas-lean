# The spatial state is orthogonal to the plane normal Q e₃

For every rotation matrix `Q ∈ SO(3)`, planar function `z : ℝ → ℂ` and time `t`, the
[spatial state](spatial-state.md) `X = Q (Re z(t), Im z(t), 0)` is orthogonal to the normal `Q e₃`
of the orbit plane, `e₃ = (0, 0, 1)`: `X · (Q e₃) = 0`, so the spatial state stays in the orbit
plane.
