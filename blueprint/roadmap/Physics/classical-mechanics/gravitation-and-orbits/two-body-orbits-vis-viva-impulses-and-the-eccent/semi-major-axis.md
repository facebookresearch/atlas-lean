# Energy-defined semi-major axis a = −μ / (2 E)

For a real `μ` and a state `(x, v)` with [specific energy](specific-energy.md) `E`, the
energy-defined semi-major axis is `a = −μ / (2 E)`. Its intended domain is `μ > 0` and `E < 0` (a
bound state), where `a > 0`; for `μ > 0` and `E > 0` the value is negative, and for `μ = 0` it is
`0`. With the convention `c / 0 = 0` it is `0` at `E = 0` (for example a parabolic state). At the
collision point `x = 0` the specific energy takes its conventional value `|v|² / 2`.
