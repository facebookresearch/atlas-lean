# Without self-springs, rigid translation is a free network's zero mode

For a finite set `ι` of nodes and pair weights with `k_{ii} = 0` for every node, the
[stiffness matrix](stiffness-matrix.md) of the free network (`w = 0`) sends the all-ones vector to
`0`: `K 1 = 0`, so rigid translations are in its kernel. When `ι` is empty the all-ones vector is
itself `0` and the statement is trivial.
