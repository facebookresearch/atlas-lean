# Axial endpoint forces of a pin-jointed table have zero resultant

Let `J` be a set of joints with positions `r : J → ℝ²`, `M` a finite set of members, member `e`
joining the joints `a(e)` and `b(e)` with `r(a(e)) ≠ r(b(e))` for every member, and `N : M → ℝ`
axial forces. Then the [axial endpoint forces](axial-endpoint-force.md) have zero
[resultant](resultant-force.md). The distinct-endpoints hypothesis is the physical
two-force-member domain; the zero resultant holds for every coefficient table
([coefficient form](member-endpoint-resultant-force-eq-zero.md)).
