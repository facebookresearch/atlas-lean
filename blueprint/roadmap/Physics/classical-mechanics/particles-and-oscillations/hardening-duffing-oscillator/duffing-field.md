# Phase-plane field of the damped Duffing oscillator

For real numbers `m`, `c`, `k` and `β` and a state `(x, v) ∈ ℝ²`, the Duffing field is

`f(x, v) = (v, -(c v + k x + β x³) / m)`,

so that `x' = v`, `m v' = -c v - k x - β x³`: mass `m`, viscous damping `c`, linear stiffness `k`
and cubic stiffness `β`, hardening for `β > 0`. In the physical reading `m > 0`; with the
convention `u / 0 = 0` the second component is `0` when `m = 0`.
