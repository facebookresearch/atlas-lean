# In-phase coefficient of the steady-state response

For real numbers `m`, `c`, `k`, `F` and `Ω`, the in-phase coefficient of the steady-state response
of `m x'' + c x' + k x = F cos (Ω t)` is

`A = F (k - m Ω²) / D`,

with `D = (k - m Ω²)² + (c Ω)²` the [steady-state denominator](steady-state-denominator.md). With
the convention `u / 0 = 0`, `A = 0` when `D = 0`.
