# Damping regimes of the mass–spring–damper

Let `m > 0`, `c ≥ 0` and `k > 0`, with [damping rate](atlas-damping.md) `γ = c / (2 m)` and
[natural angular frequency](atlas-natural-frequency.md) `ω₀ = √(k / m)`. The
[damped oscillator](mass-spring-damper.md) of the mass–spring–damper is

- underdamped (`c² - 4 m k < 0`) if and only if `c² < 4 m k`, if and only if `γ < ω₀`;
- critically damped (`c² - 4 m k = 0`) if and only if `c² = 4 m k`, if and only if `γ = ω₀`;
- overdamped (`c² - 4 m k > 0`) if and only if `4 m k < c²`, if and only if `ω₀ < γ`.
