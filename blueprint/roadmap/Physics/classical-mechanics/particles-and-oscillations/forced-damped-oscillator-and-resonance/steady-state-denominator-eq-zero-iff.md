# If m, ω₀ > 0, k = m ω₀², Ω ≥ 0, the denominator is 0 iff c = 0, Ω = ω₀

Let `m > 0`, `ω₀ > 0`, `k = m ω₀²`, and let `c` and `Ω ≥ 0` be real numbers. Then the
[steady-state denominator](steady-state-denominator.md) vanishes exactly at the undamped exact
resonance:

`(k - m Ω²)² + (c Ω)² = 0` if and only if `c = 0` and `Ω = ω₀`.

The condition `Ω ≥ 0` matters: at `Ω = -ω₀` with `c = 0` the denominator also vanishes.
