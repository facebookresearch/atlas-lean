# Damping rate of the forced-oscillator convention

For real numbers `m` and `c`, the damping rate is `γ = c / (2 m)`, the coefficient in the
forced-oscillator convention `x'' + 2 γ x' + ω₀² x = f cos (Ω t)` for the mass–spring–damper
`m x'' + c x' + k x = F cos (Ω t)`. In the physical reading `m > 0` and `c ≥ 0`; the formula is
defined for all real inputs, and with the convention `u / 0 = 0` it is `0` when `m = 0`.
