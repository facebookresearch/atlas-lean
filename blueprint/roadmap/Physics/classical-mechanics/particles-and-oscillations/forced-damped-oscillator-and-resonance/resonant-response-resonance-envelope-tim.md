# Value of the resonant response at the envelope-touch times

Let `ω₀ > 0`, let `m` and `F` be real numbers and `n` a natural number. At the
[envelope-touch time](resonance-envelope-time.md) `t_n = (2 π n + π / 2) / ω₀`, the
[resonant response](resonant-response.md) takes the signed value

`x_r(t_n) = F t_n / (2 m ω₀)`.

No sign condition on `m` is needed; with the convention `u / 0 = 0` both sides are `0` when
`m = 0`.
