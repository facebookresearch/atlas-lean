# Forcing amplitude of the forced-oscillator convention

For real numbers `m` and `F`, the forcing amplitude of the forced-oscillator convention is
`f = F / m`, the force amplitude per unit mass, so that, for `m > 0` and `k ≥ 0`
([forced equation](forced-equation-iff.md)), `m x'' + c x' + k x = F cos (Ω t)` becomes
`x'' + 2 γ x' + ω₀² x = f cos (Ω t)`. It is an acceleration, not a force
([dimension](atlas-forcing-dimension.md)). In the physical reading `m > 0`; with the convention
`u / 0 = 0` it is `0` when `m = 0`.
