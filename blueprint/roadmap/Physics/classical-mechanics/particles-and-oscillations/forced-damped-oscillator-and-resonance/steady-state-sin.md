# Quadrature coefficient of the steady-state response

For real numbers `m`, `c`, `k`, `F` and `Ω`, the quadrature coefficient of the steady-state
response of `m x'' + c x' + k x = F cos (Ω t)` is

`B = F c Ω / D`,

with `D = (k - m Ω²)² + (c Ω)²` the [steady-state denominator](steady-state-denominator.md). With
the convention `u / 0 = 0`, `B = 0` when `D = 0`.
