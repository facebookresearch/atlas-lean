# Envelope-touch times of the resonant response

For a real `ω₀` and a natural number `n`, the `n`-th envelope-touch time is

`t_n = (2 π n + π / 2) / ω₀`.

For `ω₀ ≠ 0`, `sin (ω₀ t_n) = 1`; for `m, ω₀ > 0` the absolute value of the
[resonant response](resonant-response.md) meets its envelope `|F| |t| / (2 m ω₀)` there
([contact](abs-resonant-response-resonance-envelope.md)). For `m, ω₀ > 0` and `F ≠ 0` these times
are not extrema of the response: its velocity there is `F / (2 m ω₀) ≠ 0`. With the convention
`u / 0 = 0`, `t_n = 0` when `ω₀ = 0`.
