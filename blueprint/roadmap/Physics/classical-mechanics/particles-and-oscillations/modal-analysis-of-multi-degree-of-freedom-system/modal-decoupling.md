# Modal coordinates decouple M x″ + K x = 0 at each time

Let `n` be a finite set, `M`, `K` and `C` real `n × n` matrices and `μ : n → ℝ` with `Cᵀ M C = 1`
and `Cᵀ K C = diag(μ)`, and let `x : ℝ → ℝⁿ` be twice continuously differentiable. Then, at every
time `t`,

`M x''(t) + K x(t) = 0` if and only if `q_i''(t) + μ_i q_i(t) = 0` for every `i`,

where `q = C⁻¹ x` are the modal coordinates. No definiteness of `M` or `K` is needed.
