# Precessing body angular velocity of an axisymmetric body

For real numbers `I_⊥`, `I₃`, `A` (transverse amplitude) and `ω₃` (axial spin), the vector function
`ω_B(t) = (A cos(ν t), A sin(ν t), ω₃)`, with `ν = (I₃ - I_⊥) ω₃ / I_⊥` the
[precession rate](axisymmetric-precession-rate.md). For `I_⊥ > 0` it
[solves Euler's equations without torque](axisymmetric-precession-euler.md); it is a body angular
velocity only, and no orientation with this angular velocity is constructed.
