# The dependent-angle Jacobian is singular exactly at dead centres

For a [four-bar linkage](four-bar.md) and all angles `θ₃` and `θ₄`, the
[dependent-angle Jacobian](dependent-jacobian.md) has determinant `0` if and only if
`θ₃ - θ₄ = n π` for some integer `n`: coupler and rocker are collinear (a dead centre). This uses
that the coupler and rocker lengths are positive.
