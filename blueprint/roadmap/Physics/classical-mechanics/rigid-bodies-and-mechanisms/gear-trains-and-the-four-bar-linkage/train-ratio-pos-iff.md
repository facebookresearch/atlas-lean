# The train ratio is positive iff the number of external meshes is even

For every gear train of `n` [meshes](mesh.md), `n ≥ 0`, the [train ratio](train-ratio.md) `R`
satisfies `R > 0` if and only if the [number of external meshes](external-count.md) is even. Since
[`ω_n = R ω₀`](last-eq.md) on a no-slip motion, when `ω₀ ≠ 0` the last shaft turns in the same
sense as the first exactly when the number of external meshes is even.
