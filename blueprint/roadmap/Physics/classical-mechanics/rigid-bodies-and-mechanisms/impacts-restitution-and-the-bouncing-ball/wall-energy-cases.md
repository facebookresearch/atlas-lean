# For e ≥ 0 and nonzero velocity, the sign of the wall energy change

Let `m > 0`, `e ≥ 0` and `v⁻ ≠ 0`. With the [rebound velocity](wall-rebound-velocity.md)
`v⁺ = -e v⁻` and the [kinetic energy](body-kinetic-energy.md) `m x² / 2`:

- `K(v⁺) < K(v⁻)` if and only if `e < 1`;
- `K(v⁺) = K(v⁻)` if and only if `e = 1`;
- `K(v⁺) > K(v⁻)` if and only if `e > 1`.
