# For emissivities 0 < ε ≤ 1, the radiosity matrix is invertible

Let `ι` be a finite set of surfaces with areas `A` and view factors `F` forming a
[black enclosure](is-black-enclosure.md) and let the emissivities satisfy `0 < ε_i ≤ 1`. Then the
[radiosity matrix](radiosity-matrix.md) has nonzero determinant, by its strict row diagonal
dominance ([dominance](radiosity-matrix-sum-row-lt-diag.md)).
