# The radiosity matrix is invertible

Let $(A, F)$ be enclosure data on a finite set of surfaces: areas $A_i > 0$, view factors $F_{ij} \ge 0$ with $\sum_j F_{ij} = 1$, and reciprocity $A_i F_{ij} = A_j F_{ji}$. If $0 < \varepsilon_i \le 1$ for every surface, then the radiosity matrix has nonzero determinant.
