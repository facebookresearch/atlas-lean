# The linear slab profile has constant slope (T_L − T₀) / L

Let `L > 0` and let `T₀`, `T_L` and `z` be real numbers. Then the linear profile
`T(z) = T₀ + (T_L - T₀) z / L` has derivative `(T_L - T₀) / L` at `z`. The condition `L > 0` is not
used: with the convention `u / 0 = 0`, for `L = 0` the profile is constant and both sides are `0`.
