# Chopped-cosine linear power

For a signed midplane value $q_0$ and an extrapolated length $L_e$, the chopped-cosine linear power at axial position $z$ is $q'(z) = q_0 \cos(\pi z/L_e)$, a power per unit length taken as a prescribed model input. Its midplane value $q_0$ is a maximum for $q_0 \ge 0$ (for $q_0 < 0$ it is a minimum). It is intended for $L_e > 0$; with the convention $x/0 = 0$ it is the constant $q_0$ when $L_e = 0$.
