# For ṁ, cp > 0 and 0 < L ≤ Lₑ the enthalpy rise is the total power

Let `ṁ > 0`, `cp > 0` and `0 < L ≤ Lₑ`. Every [steady coolant profile](is-steady-coolant-profile.md)
`T` with inlet value `T_in` satisfies

`ṁ cp (T(L/2) - T_in) = ∫_{-L/2}^{L/2} q′(z) dz = 2q₀Lₑ sin(πL/(2Lₑ))/π`,

with the [linear power](cosine-linear-power.md) `q′(z) = q₀ cos(πz/Lₑ)`.
