# For q₀ ≥ 0 a steady profile stays at or below the outlet temperature

Let `ṁ > 0`, `cp > 0`, `q₀ ≥ 0` and `0 < L ≤ Lₑ`. Every
[steady coolant profile](is-steady-coolant-profile.md) `T` with inlet value `T_in` satisfies
`T(z) ≤ T_out` for every `z` with `-L/2 ≤ z ≤ L/2`, with the
[outlet temperature](coolant-outlet-temp.md) `T_out = T_in + 2q₀Lₑ sin(πL/(2Lₑ))/(π ṁ cp)`: the
coolant warms along the channel.
