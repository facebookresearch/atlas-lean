# Number of transfer units NTU = UA / C_min

For a real overall conductance `UA` and stream capacity rates `C_h`, `C_c`, the number of transfer
units is `NTU = UA / min(C_h, C_c)`. In the physical reading `UA ≥ 0` and `C_h, C_c > 0`; with the
convention `u / 0 = 0` it is `0` when `min(C_h, C_c) = 0`.
