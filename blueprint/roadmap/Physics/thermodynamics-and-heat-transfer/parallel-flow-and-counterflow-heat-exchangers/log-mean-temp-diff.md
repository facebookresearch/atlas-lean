# Logarithmic mean temperature difference

For real end temperature differences `Δ₁` and `Δ₂`, the logarithmic mean is

- `(Δ₁ - Δ₂) / log(Δ₁ / Δ₂)` when `Δ₁ ≠ Δ₂`;
- `Δ₁` when `Δ₁ = Δ₂`, so that no value divides by `log 1 = 0`.

It is meant for `Δ₁`, `Δ₂` of one strict sign. Outside that domain the conventions `u / 0 = 0`,
`log 0 = 0` and `log x = log |x|` apply: the value is `0` when exactly one of `Δ₁`, `Δ₂` is `0`, and
when `Δ₁ = -Δ₂ ≠ 0`.
