# Soundness of an accepted trace encoding

Let $s$ be a character string accepted by the encoded-trace checker, which decodes $s$ with the bounded trace decoder and then applies the thermal trace checker to the decoded list. Then $s$ decodes to a list $y = (y_0, \dots, y_{10})$ of rationals with exactly eleven entries, and, as real numbers,

$$y_j = \left(\tfrac{9}{10}\right)^j \qquad (j = 0, \dots, 10).$$
