# Queue length decreases at rate mu - lambda during green

For arrival rate $\lambda > 0$, discharge rate $\mu > \lambda$ and red duration $R$, let the queue length be $\ell(t) = \lambda t$ for $t \le R$ and $\ell(t) = \max\big(0, \lambda R - (\mu - \lambda)(t - R)\big)$ for $t > R$. If $R < t < R + \lambda R/(\mu - \lambda)$ and $t < R + G$, then $\ell'(t) = -(\mu - \lambda)$.
