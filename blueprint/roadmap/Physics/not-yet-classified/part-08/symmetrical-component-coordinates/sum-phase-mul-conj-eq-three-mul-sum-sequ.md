# Complex power in symmetrical-component coordinates

For $V_a, V_b, V_c \in \mathbb{C}$ and $\alpha = e^{2\pi i/3}$, the symmetrical components are $V_0 = (V_a + V_b + V_c)/3$, $V_1 = (V_a + \alpha V_b + \alpha^2 V_c)/3$ and $V_2 = (V_a + \alpha^2 V_b + \alpha V_c)/3$. Define $I_0, I_1, I_2$ from $I_a, I_b, I_c \in \mathbb{C}$ in the same way. Then

$$V_a \overline{I_a} + V_b \overline{I_b} + V_c \overline{I_c} = 3\bigl(V_0 \overline{I_0} + V_1 \overline{I_1} + V_2 \overline{I_2}\bigr).$$
