# Burgers expansion jump violates the entropy inequality

For Burgers flux $f(u) = u^2/2$ with entropy $\eta(u) = u^2/2$ and entropy flux $q(u) = u^3/3$, let $u_L < u_R$ and let $c$ satisfy the Rankine-Hugoniot condition $c(u_R - u_L) = f(u_R) - f(u_L)$. Then the entropy production $q(u_R) - q(u_L) - c(\eta(u_R) - \eta(u_L))$ is positive, so the jump violates the entropy inequality.
