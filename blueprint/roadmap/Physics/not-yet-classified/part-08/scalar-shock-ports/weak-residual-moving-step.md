# Weak residual of a moving step

Let $f$ be any flux, $u_L, u_R, c$ real, and $u(t,x) = u_L$ for $x < ct$ and $u_R$ otherwise. Let $\varphi$ be a smooth function on $\mathbb{R}^2$ supported in a bounded rectangle, with partial derivatives $\varphi_t$, $\varphi_x$. Then

$$\iint (u\,\varphi_t + f(u)\,\varphi_x)\,dt\,dx = -\big((f(u_R) - f(u_L)) - c(u_R - u_L)\big)\int \varphi(t, ct)\,dt.$$
