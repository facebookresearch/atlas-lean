# Tests vanishing on the shock line do not see the jump

Let $\varphi$ be a smooth function of $(t, x)$ supported in a rectangle $[T_0, T_1] \times [X_0, X_1]$, with partial derivatives $\varphi_t, \varphi_x$, and $\varphi(t, c t) = 0$ for all $t$. Then for every flux $f$ and states $u_L, u_R$, the moving step $u = u_L$ for $x < c t$ and $u = u_R$ for $x \ge c t$ has weak residual $\iint (u \varphi_t + f(u) \varphi_x)\,dt\,dx = 0$.
