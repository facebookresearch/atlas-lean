# Steady shear flow is plane Couette flow

For real $U_{\mathrm{wall}}$ and $H$ and any time $t$, the parallel shear velocity $(U(t, y), 0, 0)$ with the steady profile $U(t, y) = U_{\mathrm{wall}}\, y / H$ equals the plane Couette velocity $(U_{\mathrm{wall}}\, y/H, 0, 0)$, both profiles taking the value $0$ when $H = 0$, by the convention $x/0 = 0$.
