# Single-mode shear profile

For wall speed $A$, gap $L$ and kinematic viscosity $\nu$, the single-mode profile is

$$U(t, y) = \frac{A y}{L} - \frac{A}{\pi} \sin\!\left(\frac{\pi y}{L}\right) e^{-\nu (\pi/L)^2 t},$$

the plane Couette profile minus one decaying sine mode, with the value $0$ when $L = 0$, by the convention $x/0 = 0$.
