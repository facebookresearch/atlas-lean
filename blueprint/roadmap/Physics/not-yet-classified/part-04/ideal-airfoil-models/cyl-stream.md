# Cylinder stream function

For free-stream speed $U$, cylinder radius $a$ and circulation $\Gamma$, the stream function is $\psi(x, y) = U(y - a^2 y/r^2) - (\Gamma/2\pi)\log(r/a)$ with $r = \sqrt{x^2 + y^2}$, defined for all real $x, y, a$; when $a = 0$ the logarithmic term is $0$, by the conventions $x/0 = 0$ and $\log 0 = 0$, so $\psi(x, y) = U y$.
