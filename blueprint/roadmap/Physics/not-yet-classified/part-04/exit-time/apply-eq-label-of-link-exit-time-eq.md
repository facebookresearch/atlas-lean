# Departure count at the FIFO exit time equals the vehicle number

Let $N_0 \ge 0$ be the number of vehicles on a link at time $0$ and $A$, $D$ the cumulative arrival and departure counts (nonnegative functions of time $\ge 0$), with $D$ continuous. The exit time of the vehicle entering at $t$ is the infimum of the times $s \ge t$ with $D(s) \ge N_0 + A(t)$ (infinite if none). If $D(t) \le N_0 + A(t)$ and this exit time is a finite value $e$, then $D(e) = N_0 + A(t)$.
