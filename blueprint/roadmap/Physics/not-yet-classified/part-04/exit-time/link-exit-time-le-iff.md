# Generalized inverse at plateaus

On one traffic link with $N_0 \ge 0$ vehicles present at time $0$, nonnegative cumulative arrival count $A$ and departure count $D$ over times $s \ge 0$, the vehicle entering at time $t$ has number $N_0 + A(t)$, and its exit time is the infimum of the times $s \ge t$ with $D(s) \ge N_0 + A(t)$ (infinite if there is none). If $D$ is nondecreasing and right-continuous, then for every $s \ge t$ the exit time is at most $s$ if and only if $N_0 + A(t) \le D(s)$.
