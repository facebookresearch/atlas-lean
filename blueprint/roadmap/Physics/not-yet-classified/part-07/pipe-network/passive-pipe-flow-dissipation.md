# Dissipation of a passive pipe flow

On a finite pipe network with node-arc incidence matrix $B$, let arc flows $q$, node demands $d$, node heads $h$ and pipe resistances $r_e \ge 0$ satisfy $B q = d$ and $-(B^\top h)_e = r_e q_e |q_e|$ for every arc $e$. Then $-\sum_v h_v d_v = \sum_e r_e q_e^2 |q_e|$.
