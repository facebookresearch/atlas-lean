# Saturated crack path before failure follows the Paris law in time

Let $K > 0$, $r$ nonzero, $f > 0$, and $0 < a_0 < a_c$ with $a_c = (K_{IC}/(Y\sigma))^2/\pi$; let $a(N) = (a_0^r + rKN)^{1/r}$ and $N_f = (a_c^r - a_0^r)/(rK)$. For every $t \ge 0$ with $t \le N_f/f$, the event path satisfies $a(\min(f t, N_f)) = a(f t)$, and the function $s \mapsto a(f s)$ has derivative

$$f\,K\,a(f t)^{1-r}$$

at $t$.
