# First crossing of the critical length, power Paris branch

Let $K > 0$, $0 < a_0 < a_c$, $r$ nonzero, and let $N$ be a real cycle count with $a_0^r + rKN > 0$. Then

$$(a_0^r + rKN)^{1/r} < a_c \iff N < \frac{a_c^r - a_0^r}{rK}.$$

The strict positivity of the base is needed: at base $0$ with $r < 0$ the real power takes the value $0$ instead of the blow-up limit.
