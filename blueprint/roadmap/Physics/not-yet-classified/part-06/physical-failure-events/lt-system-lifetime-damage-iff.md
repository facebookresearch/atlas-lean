# System lifetime with damage lifetimes

Let $E$ be a finite set of components and $\mathcal A$ an increasing (upward-closed) set of configurations $x : E \to \{\mathrm{true}, \mathrm{false}\}$. For each component $i$ let $d_i(\omega, \cdot)$ be a continuous nondecreasing damage path on $[0,\infty)$ with threshold $D_i(\omega)$, and let $T_i(\omega)$ be its damage lifetime, the first time $t \ge 0$ with $d_i(\omega,t) \ge D_i(\omega)$ ($\infty$ if there is none). Let the system lifetime be $\max_{x \in \mathcal A} \min_{i : x_i = \mathrm{true}} T_i(\omega)$, where the minimum over no components is $\infty$ and the maximum over an empty $\mathcal A$ is $0$. Then for every $\omega$ and every finite time $t \ge 0$, $t$ is strictly less than the system lifetime if and only if the configuration $i \mapsto [\,d_i(\omega,t) < D_i(\omega)\,]$ lies in $\mathcal A$.
