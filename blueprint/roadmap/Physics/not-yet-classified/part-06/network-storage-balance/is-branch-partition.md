# Partition of branches into resistors, inductors, capacitors and sources

For the branch set $\{0, \dots, n_B - 1\}$ and subsets $\mathcal{R}, \mathcal{L}, \mathcal{C}, \mathcal{S}$, the subsets form a branch partition when they are pairwise disjoint and

$$\mathcal{R} \cup \mathcal{L} \cup \mathcal{C} \cup \mathcal{S} = \{0, \dots, n_B - 1\}.$$
