# Pulled-back unit profile solves the fixed-fixed bar problem

Let $L > 0$, $EA > 0$ and $q \in \mathbb{R}$, let $\alpha = \dfrac{q L^2}{2\,EA}$ and $\hat u(\xi) = \xi(1-\xi)$, and set $u(x) = \alpha\, \hat u(x/L)$. Then $u$ is $C^2$ on $[0, L]$,

$$-EA\, u''(x) = q \quad \text{for all } x \in [0, L]$$

(with $u''$ the second derivative within $[0, L]$), and $u(0) = u(L) = 0$.
