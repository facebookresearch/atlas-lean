# Small-signal remainder bound on an operating box

Let $\mathbb{R}^n$ carry the sup norm, let $i : \mathbb{R}^n \to \mathbb{R}$, and write the small-signal remainder at the operating point $v_0$ for the perturbation $\delta v$ as $r = i(v_0 + \delta v) - i(v_0) - Di(v_0)[\delta v]$. Let $U \subseteq \mathbb{R}^n$ be open and contain the box $[\ell, u] = \{y : \ell \le y \le u\}$ (componentwise), let $i$ be $C^2$ on $U$, and let $\|D^2 i(y)\| \le M$ (operator norm) for every $y$ in the box. If $v_0$ and $v_0 + \delta v$ lie in the box, then

$$|r| \le \frac{M\,\|\delta v\|^2}{2}.$$
