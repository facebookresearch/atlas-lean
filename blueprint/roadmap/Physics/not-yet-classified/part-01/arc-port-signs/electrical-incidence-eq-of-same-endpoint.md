# Branches with equal endpoints have equal incidence columns

Let $V$ and $E$ be finite sets of nodes and branches, each branch $e$ having a tail and a head node, and let $\mathcal{A} \in \mathbb{R}^{V \times E}$ be the electrical incidence matrix, $\mathcal{A}_{n e} = [\mathrm{tail}(e) = n] - [\mathrm{head}(e) = n]$. If branches $e_1$ and $e_2$ have the same tail and the same head, then $\mathcal{A}_{n e_1} = \mathcal{A}_{n e_2}$ for every node $n$.
