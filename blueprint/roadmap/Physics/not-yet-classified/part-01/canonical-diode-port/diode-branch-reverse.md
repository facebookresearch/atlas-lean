# Reversing a diode branch

In a network with finitely many nodes and branches, if a diode with anode $a$ and cathode $c$ occupies branch $e$ with branch voltages $v$ and currents $i$ (diode branch predicate with parameters $I_s, n, k_B, T, q$), then it also does so after the branch is reversed: replacing $\mathrm{tail}(e)$ by $\mathrm{head}(e)$ and $\mathrm{head}(e)$ by $\mathrm{tail}(e)$, and $v_e, i_e$ by $-v_e, -i_e$, with all other branches unchanged, gives again a diode branch with anode $a$ and cathode $c$ on $e$.
