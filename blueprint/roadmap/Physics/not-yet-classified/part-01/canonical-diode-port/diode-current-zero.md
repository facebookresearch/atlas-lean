# Diode current vanishes at zero bias

For all parameters $I_s, n, k_B, T, q$, the diode current $I_D(V) = I_s\left(e^{V/(n V_T)} - 1\right)$ with $V_T = k_B T/|q|$ satisfies $I_D(0) = 0$. No parameter is restricted: if $n V_T = 0$ (for instance $n = 0$, $T = 0$ or $q = 0$), the quotients are read by the convention $x/0 = 0$, so $V_T = 0$ when $q = 0$ and $I_D(0) = I_s(e^0 - 1) = 0$.
