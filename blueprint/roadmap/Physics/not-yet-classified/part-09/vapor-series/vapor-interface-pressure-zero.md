# First vapor interface pressure is the inner pressure

For layer resistances $R_i$ and boundary pressures $p_{in}$, $p_{out}$, with series flux $J = (p_{in} - p_{out}) / \sum_{i < n} R_i$, the interface pressure after the first $m$ layers is $p_m = p_{in} - J \sum_{i < m} R_i$; at $m = 0$ it equals $p_{in}$.
