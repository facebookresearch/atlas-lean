# Correlated two-input variance

On a finite sample space with any weight function $p$, define expectation as $\sum_\omega p(\omega) X(\omega)$ and covariance and variance from it. For a two-component random vector $(X_1, X_2)$ and any real weights $a_1, a_2$,

$$\mathrm{Var}(a_1 X_1 + a_2 X_2) = a_1^2 \mathrm{Var}\,X_1 + a_2^2 \mathrm{Var}\,X_2 + 2 a_1 a_2 \mathrm{Cov}(X_1, X_2).$$

No independence is assumed.
