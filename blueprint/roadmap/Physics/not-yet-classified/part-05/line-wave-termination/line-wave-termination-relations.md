# Lossless line and load termination relations

Let $L > 0$, $C > 0$, $\omega > 0$, $Z_0 > 0$ with $\beta = \omega\sqrt{LC}$ and $Z_0 = \sqrt{L/C}$. Let $A^+, A^-, Z_L \in \mathbb{C}$ and

$$V(x) = A^+ e^{-i\beta x} + A^- e^{i\beta x}, \qquad I(x) = \frac{A^+ e^{-i\beta x} - A^- e^{i\beta x}}{Z_0}.$$

Then:

1. the wave speed $v = 1/\sqrt{LC}$ satisfies $v\sqrt{LC} = 1$, and $\bigl(\sqrt{L/C}\bigr)^2 = L/C$;
2. for every $x$, $V'(x) = -i\omega L\, I(x)$ and $I'(x) = -i\omega C\, V(x)$;
3. for all $V_L, I_L \in \mathbb{C}$ with $V_L = A^+ + A^-$, $I_L = (A^+ - A^-)/Z_0$ and $V_L = Z_L I_L$, one has $(Z_L + Z_0) A^- = (Z_L - Z_0) A^+$, and if moreover $A^+ ≠ 0$ then $Z_L + Z_0 ≠ 0$ and

    $$\frac{A^-}{A^+} = \frac{Z_L - Z_0}{Z_L + Z_0}.$$
