# Loaded one-pole amplifier example

With the source divider $R_{in}/(R_s + R_{in})$, the load divider $R_L/(R_o + R_L)$, the loaded transfer $G(s) = \dfrac{a b A_0}{1 + s/\omega_p + \beta b A_0}$ and the closed-loop pole $p = -\omega_p(1 + \beta b A_0)$:

- for $R_s = R_{in} = 1$ the source divider is $1/2$, and for $R_o = R_L = 1$ the load divider is $1/2$;
- with $A_0 = 10$, $\omega_p = 2$, $\beta = 1$ and $a = b = 1/2$, $G(0) = 5/12$ and $p = -12$.
