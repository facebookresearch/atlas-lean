# Branch equations of a linear network

Let $B \in \mathbb{R}^{n_N \times n_B}$ be an incidence matrix, $\mathcal{R}, \mathcal{L}, \mathcal{C}, \mathcal{S}$ the resistor, inductor, capacitor and voltage-source branch sets with values $R_e, L_e, C_e$ and source values $s_e$, $g$ a ground node and $j(t)$ the supplied node injections. Node potentials $v(t)$, branch voltages $v_b(t)$ and branch currents $i_b(t)$ satisfy the branch equations when for every $t$: (i) $v(t)_g = 0$ at the ground node $g$; (ii) $v_b(t) = B^{\mathsf T} v(t)$; (iii) $B\, i_b(t) = j(t)$; (iv) $v_b(t)_e = R_e\, i_b(t)_e$ for $e \in \mathcal{R}$; (v) $i_b(t)_e = C_e \frac{d}{dt} v_b(t)_e$ for $e \in \mathcal{C}$; (vi) $v_b(t)_e = L_e \frac{d}{dt} i_b(t)_e$ for $e \in \mathcal{L}$; (vii) $v_b(t)_e = s_e$ for $e \in \mathcal{S}$. The derivatives follow the convention that the derivative of a function at a point where it is not differentiable is $0$.
