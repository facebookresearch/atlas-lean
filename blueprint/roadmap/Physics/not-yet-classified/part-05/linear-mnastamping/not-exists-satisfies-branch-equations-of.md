# Parallel voltage sources with different values admit no branch solution

Let $B \in \mathbb{R}^{n_N \times n_B}$ be an incidence matrix, $\mathcal{R}, \mathcal{L}, \mathcal{C}, \mathcal{S}$ sets of branches with element values $R, L, C$ and source values $s$, $g$ a ground node, $j(t)$ node injections and $v(t)$ node potentials. Suppose two source branches $e_1, e_2 \in \mathcal{S}$ have the same incidence column, $B_{u e_1} = B_{u e_2}$ for every node $u$, and $s_{e_1} \ne s_{e_2}$. Then there are no branch voltages $v_b(t)$ and branch currents $i_b(t)$ such that, for all $t$, (i) $v(t)_g = 0$ at the ground node $g$; (ii) $v_b(t) = B^{\mathsf T} v(t)$; (iii) $B\, i_b(t) = j(t)$; (iv) $v_b(t)_e = R_e\, i_b(t)_e$ for $e \in \mathcal{R}$; (v) $i_b(t)_e = C_e \frac{d}{dt} v_b(t)_e$ for $e \in \mathcal{C}$; (vi) $v_b(t)_e = L_e \frac{d}{dt} i_b(t)_e$ for $e \in \mathcal{L}$; (vii) $v_b(t)_e = s_e$ for $e \in \mathcal{S}$. The derivatives follow the convention that the derivative of a function at a point where it is not differentiable is $0$.
