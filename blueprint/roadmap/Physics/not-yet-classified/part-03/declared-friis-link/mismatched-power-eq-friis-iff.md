# Mismatched received power equals the Friis value iff there is no loss

For $r > 0$, $\lambda > 0$, $P_t > 0$, $G_t > 0$, $G_r > 0$, power density $S = P_t G_t / (4\pi r^2)$ and effective aperture $A_e = G_r \lambda^2 / (4\pi)$, the received power $p S A_e$ with loss factor $p$ equals the Friis value $P_t G_t G_r (\lambda / (4\pi r))^2$ if and only if $p = 1$.
