# Reciprocal parameterization of the Ebers-Moll currents

Let $V_T > 0$ and let $\alpha_F$, $\alpha_R$ be nonzero. With $F = I_{SF}(e^{V_{BE}/V_T} - 1)$, $R = I_{SR}(e^{V_{BC}/V_T} - 1)$, collector current $I_C = \alpha_F F - R$ and emitter current $I_E = F - \alpha_R R$ (positive out of the emitter), the reciprocity relation $\alpha_F I_{SF} = \alpha_R I_{SR}$ holds if and only if there is $I_S$ with $I_S = \alpha_F I_{SF}$, $I_{SF} = I_S/\alpha_F$, $I_{SR} = I_S/\alpha_R$,

$$I_C = I_S\left(e^{V_{BE}/V_T} - e^{V_{BC}/V_T}\right) - I_S\,\frac{1 - \alpha_R}{\alpha_R}\left(e^{V_{BC}/V_T} - 1\right),$$

$$I_E = I_S\left(e^{V_{BE}/V_T} - e^{V_{BC}/V_T}\right) + I_S\,\frac{1 - \alpha_F}{\alpha_F}\left(e^{V_{BE}/V_T} - 1\right).$$
