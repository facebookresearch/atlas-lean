# Ebers-Moll base current

The base current, positive into the base, is

$$I_B = (1 - \alpha_F)\,F + (1 - \alpha_R)\,R,$$

with forward branch current $F = I_{SF}(e^{V_{BE}/V_T} - 1)$ and reverse branch current $R = I_{SR}(e^{V_{BC}/V_T} - 1)$. For $V_T = 0$ the formula takes the convention $x/0 = 0$, so $F = R = 0$.
