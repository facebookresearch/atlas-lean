# Adjacent DAC step error

For a step $\Delta$ and a level error $e : \mathbb{Z} \to \mathbb{R}$, let $D(k) = \Delta k + e(k)$ be the DAC level of the integer code $k$. Let $k_{\min}, k_{\max}$ be integers and $\eta$ real with $|e(k)| \le \eta$ for every integer $k \in [k_{\min}, k_{\max}]$. If $k_{\min} \le k$ and $k + 1 \le k_{\max}$, then

$$|D(k+1) - D(k) - \Delta| \le 2\eta.$$
