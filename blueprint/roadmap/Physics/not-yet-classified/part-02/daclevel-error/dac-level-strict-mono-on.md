# DAC levels are strictly increasing

For a step $\Delta$ and a level error $e : \mathbb{Z} \to \mathbb{R}$, let $D(k) = \Delta k + e(k)$ be the DAC level of the integer code $k$. Let $k_{\min}, k_{\max}$ be integers and $\eta$ real with $|e(k)| \le \eta$ for every integer $k \in [k_{\min}, k_{\max}]$. If $2\eta < \Delta$, then $D$ is strictly increasing on the integers of $[k_{\min}, k_{\max}]$.
