# CSTR linear system vector field

For real $V$, $Q$, $k$, $C$, the one-state linear system of a continuous stirred-tank reactor (state matrix $-(Q/V + k)$, input vector $Q/V$, output gain $C$, zero feedthrough) has vector field $f(x, u) = -(Q/V + k)\,x + (Q/V)\,u$ in its single state component, where $Q/V = 0$ when $V = 0$, by the convention $x/0 = 0$.
