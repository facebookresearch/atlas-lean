# Attenuation of the travelling phasor

For real $\varepsilon, \mu, \omega, \sigma$ let

$$\alpha = \omega\sqrt{\tfrac{\mu\varepsilon}{2}}\sqrt{\sqrt{1 + \left(\tfrac{\sigma}{\omega\varepsilon}\right)^2} - 1}, \qquad \beta = \omega\sqrt{\tfrac{\mu\varepsilon}{2}}\sqrt{\sqrt{1 + \left(\tfrac{\sigma}{\omega\varepsilon}\right)^2} + 1},$$

with the conventions $\sqrt{x} = 0$ for $x < 0$ and $x/0 = 0$, so that $\alpha$ and $\beta$ are real for all inputs, and $\gamma = \alpha + i\beta$. Then for every real $z$,

$$\left|e^{-\gamma z}\right| = e^{-\alpha z}.$$
