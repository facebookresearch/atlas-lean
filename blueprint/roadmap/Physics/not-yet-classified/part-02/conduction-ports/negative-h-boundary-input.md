# A negative transfer coefficient can give positive boundary work

There exist $k > 0$, $h_0 < 0$, $D > 0$ and boundary values $\theta_0, u_0, \theta_L, u_L$ with $k u_0 = h_0 \theta_0$, $-k u_L = 0 \cdot \theta_L$ and positive boundary work $D(\theta_L u_L - \theta_0 u_0) > 0$. For example $k = D = 1$, $h_0 = -1$, $\theta_0 = 1$, $u_0 = -1$, $\theta_L = u_L = 0$.
