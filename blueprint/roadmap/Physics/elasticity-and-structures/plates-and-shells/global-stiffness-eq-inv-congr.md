# Global stiffness by inverse congruence with the material-to-global map

For every real `3 × 3` matrix `Q` and every real `θ`, the [global stiffness](global-stiffness.md)
`Q_global(θ) = T_e(θ)ᵀ Q T_e(θ)` equals `(A⁻¹)ᵀ Q A⁻¹` with `A = T_e(−θ)`, the map from material to
global engineering strains.
