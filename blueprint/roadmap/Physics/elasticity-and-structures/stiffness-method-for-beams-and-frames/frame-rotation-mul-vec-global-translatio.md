# A global translation maps to local translation modes

For all real `c`, `s`, `a` and `b`, the [frame transformation](frame-rotation.md) `T` maps the
global translation `(a, b, 0, a, b, 0)` to
`(c a + s b) (1, 0, 0, 1, 0, 0) + (-s a + c b) (0, 1, 0, 0, 1, 0)`, a combination of the local axial
and transverse translations.
