# The global frame stiffness matrix is symmetric

For all real `EA`, `EI`, `L`, `c` and `s`, the [global frame stiffness](frame-stiffness-global.md)
`K_g = Tᵀ K_f T` is symmetric: `K_gᵀ = K_g`. The physical reading is `EA > 0`, `EI > 0`, `L > 0` and
`c² + s² = 1`, with `(c, s)` the direction cosines of the element axis.
