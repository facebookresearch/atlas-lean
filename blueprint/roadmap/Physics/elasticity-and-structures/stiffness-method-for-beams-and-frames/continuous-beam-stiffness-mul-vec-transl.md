# A rigid translation is in the kernel of the two-span beam stiffness

For all real `EI1`, `L1`, `EI2` and `L2`, the
[assembled two-span stiffness](continuous-beam-stiffness.md) `K_c` (without supports) maps the rigid
translation to zero: `K_c (1, 0, 1, 0, 1, 0) = 0`. The physical reading is `EI1, L1, EI2, L2 > 0`.
