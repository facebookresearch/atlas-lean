# Consistent load vector of a uniform load on a beam element

For a uniform load `w` and a length `L` (real numbers), the consistent load vector of the beam
element in the nodal coordinates `(v1, θ1, v2, θ2)` (deflections and rotations at the two ends) is
`(w L / 2, w L² / 12, w L / 2, -w L² / 12)`.
