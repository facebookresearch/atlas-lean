# The kernel of the beam stiffness matrix is the rigid motions

For `EI > 0` and `L > 0` and every `d ∈ ℝ⁴`, the [beam stiffness matrix](beam-stiffness.md) `K`
satisfies `K d = 0` if and only if `d = a (1, 0, 1, 0) + b (0, 1, L, 1)` for some real `a` and `b`:
the kernel is spanned by the rigid translation and the rigid rotation.
