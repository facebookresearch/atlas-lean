# Consistent loads of a uniform load from the Hermite cubic

For `L ≠ 0` and every real `w`, let `H(v1, t1, v2, t2)` be the Hermite cubic on `[0, L]` with end
values `v1`, `v2` and end slopes `t1`, `t2`,
`H(x) = (2 ξ³ - 3 ξ² + 1) v1 + ξ² (3 - 2 ξ) v2 + (ξ³ - 2 ξ² + ξ) L t1 + (ξ³ - ξ²) L t2` with
`ξ = x / L`. Then `∫_0^L w H(1, 0, 0, 0) dx = w L / 2`, `∫_0^L w H(0, 1, 0, 0) dx = w L² / 12`,
`∫_0^L w H(0, 0, 1, 0) dx = w L / 2` and `∫_0^L w H(0, 0, 0, 1) dx = -w L² / 12`. The integrals are
oriented; the physical reading is `L > 0`.
