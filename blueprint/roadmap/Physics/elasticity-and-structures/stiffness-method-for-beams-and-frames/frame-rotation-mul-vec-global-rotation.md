# A global rigid rotation maps to the local rotation mode

For real `c` and `s` with `c² + s² = 1` and all real `L` and `w`, the
[frame transformation](frame-rotation.md) `T` maps `(0, 0, w, -L s w, L c w, w)`, the global
displacement of the linearized rigid rotation through `w` about end 1 of an element of length `L` in
the direction `(c, s)`, to `w (0, 0, 1, 0, L, 1)`, the local rigid rotation mode.
