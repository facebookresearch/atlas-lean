# Quadrature error of the interior coefficient

For the same two-cell bar under the quadratic load $Q(x/L)^2$, let $\beta = QL^2/EA$ and $u(x) = \beta\hat u_2(x/L)$ with $\hat u_2(\xi) = (\xi - \xi^4)/12$; the exact interior load is $F = \int_0^LQ(x/L)^2\varphi(x/L)\,dx$, the composite midpoint load is $F_{mid} = \tfrac L2\bigl(Q(\tfrac14)^2\varphi(\tfrac14) + Q(\tfrac34)^2\varphi(\tfrac34)\bigr)$, and the coefficients are $c = F/K$ and $c_{mid} = F_{mid}/K$ with $K = 4EA/L$. If $EA \ne 0$ and $L > 0$, then $c_{mid} - c = \beta/384$ and $|c - c_{mid}| = |\beta|/384$.
