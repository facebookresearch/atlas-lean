# The deflection is greatest at mid-span for a nonnegative load

For a load `w ≥ 0`, a bending stiffness `EI > 0`, a span `L > 0` and a position `0 ≤ x ≤ L`, the
[uniform-load deflection](uniform-load-deflection.md)
`y(x) = w * (L ^ 3 * x - 2 * L * x ^ 3 + x ^ 4) / (24 * EI)` satisfies `y(x) ≤ y(L / 2)`: the
mid-span deflection is the largest on the span.
