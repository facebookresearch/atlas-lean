# Mid-span deflection under uniform load

For all real `w`, `EI` and `L`, the [uniform-load deflection](uniform-load-deflection.md)
`y(x) = w * (L ^ 3 * x - 2 * L * x ^ 3 + x ^ 4) / (24 * EI)` at mid-span is
`y(L / 2) = 5 * w * L ^ 4 / (384 * EI)`. With the convention `x / 0 = 0` both sides are `0` when
`EI = 0`.
