# Deflection of a simply supported beam under uniform load

For a uniform load `w`, a bending stiffness `EI`, a span `L` and a position `x` (real numbers), the
deflection of a simply supported Euler–Bernoulli beam, positive downward (in the load direction), is
`y(x) = w * (L ^ 3 * x - 2 * L * x ^ 3 + x ^ 4) / (24 * EI)`. It is defined for all real inputs;
with the convention `x / 0 = 0` it is identically `0` when `EI = 0`. In the physical reading
`EI > 0`, `L > 0` and `0 ≤ x ≤ L`.
