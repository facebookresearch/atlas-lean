# Relaxation form of the Maxwell model

Let a Maxwell branch have modulus `E > 0` and viscosity `η > 0`, and `τ = η /
E`. A history with derivatives `σ'` and `ε'` on a set `I` obeys `ε' = σ' / E +
σ / η` there if and only if `σ' + σ / τ = E ε'` there. This is Maxwell's
`dF/dt = E dS/dt - F/T` with relaxation time `T = τ` and viscosity `E T = η`
(Roylance, section 4.1, Eqn. (22)).
