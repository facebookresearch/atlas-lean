# Creep of a Maxwell branch under constant stress

Let a Maxwell branch have modulus `E > 0` and viscosity `η > 0`, and let a
stress–strain history obey `ε' = σ' / E + σ / η` for `t ≥ 0`. If the stress is
held at `σ 0` for `t ≥ 0`, then `ε t = ε 0 + σ 0 t / η` for every `t ≥ 0`: for
`σ 0 ≠ 0` the branch creeps without bound.
