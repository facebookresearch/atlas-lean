# Clamped-clamped buckling mode

Let `L > 0` and let `EI` be any real number. With axial load `P = 4π²EI / L²`,
the mode `w = 1 - cos (2πx / L)` satisfies the Euler column equation `EI *
w'''' + P * w'' = 0` at every `x`, together with the clamped conditions `w =
w' = 0` at `x = 0` and `x = L`. This is one explicit eigenpair; for `EI = 0`
both sides vanish.
