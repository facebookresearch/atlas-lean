# Clamped-free buckling mode

Let `L > 0` and let `EI` be any real number. With axial load `P = π²EI /
(4L²)`, the mode `w = 1 - cos (πx / (2L))` satisfies the Euler column equation
`EI * w'''' + P * w'' = 0` at every `x`, the clamped conditions `w(0) = w'(0)
= 0`, and the free-end conditions `w''(L) = 0` and `EI * w'''(L) + P * w'(L) =
0`. For `EI = 0` both sides vanish.
