# Scenarios whose reading lies in a closed bin

For a finite scenario type $\Omega$, a real reading $z(\omega)$ in each scenario $\omega$ and real
bounds $z_{\mathrm{lo}}$ and $z_{\mathrm{hi}}$, the bin event is the set of scenarios

$$A = \{\omega \in \Omega : z_{\mathrm{lo}} \le z(\omega) \le z_{\mathrm{hi}}\},$$

both bounds included. It is empty when $z_{\mathrm{lo}} > z_{\mathrm{hi}}$.
