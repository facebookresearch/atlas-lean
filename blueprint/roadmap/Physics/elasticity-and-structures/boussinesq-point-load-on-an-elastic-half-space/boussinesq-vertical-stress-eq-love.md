# The Boussinesq vertical stress equals Love's form in the distance R

For all real `P`, `r` and `z`, the [Boussinesq vertical stress](boussinesq-vertical-stress.md)
`3 P z³ / (2 π (r² + z²)^(5/2))`, a real power of the nonnegative number `r² + z²`, equals Love's
form `3 P z³ / (2 π R⁵)` with `R = √(r² + z²)` the distance from the load point. At `r = z = 0`
both sides are `0`, with the convention `x / 0 = 0`; the physical domain is `z > 0`.
