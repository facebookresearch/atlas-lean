# Firm nonexpansiveness of the deviatoric return map

Let `K` be a nonempty, complete and convex set of `3 × 3` real matrices, and `μ`
real. For two trial stresses, the squared Frobenius distance between the
returned deviators plus `(2 μ)²` times the squared Frobenius distance between
the plastic strain increments is at most the squared Frobenius distance
between the trial deviators. Physically `μ > 0`; the inequality holds for
every real `μ`.
