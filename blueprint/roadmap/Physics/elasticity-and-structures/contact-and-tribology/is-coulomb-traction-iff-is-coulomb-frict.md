# On a tangent line the vector law is the scalar Coulomb law

For all real `μ`, `N`, `v` and `F`, with `E = ℝ`, the [vector Coulomb law](is-coulomb-traction.md) for the
slip velocity `v` and traction `F` holds if and only if the [scalar Coulomb law](is-coulomb-friction.md)
holds: for `v ≠ 0`, `v / |v| = sign(v)`, and `|F| ≤ μ N` holds exactly when `-μ N ≤ F ≤ μ N`.
