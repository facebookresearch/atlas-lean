# Upper endpoint load of a load box

For a finite index set `ι` and vectors `η` (the influence vector) and `cap` (the pattern capacities)
indexed by `ι`, the upper endpoint load of the box `0 ≤ f_i ≤ cap_i` has the coordinates
`f_i = cap_i` where `η_i ≥ 0` and `f_i = 0` where `η_i < 0`. At a zero coefficient the capacity
endpoint is chosen; its response contribution is zero either way.
