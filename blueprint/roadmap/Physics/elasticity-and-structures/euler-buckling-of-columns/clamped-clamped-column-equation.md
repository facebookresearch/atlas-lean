# The clamped–clamped mode solves the column equation for every EI

For `L > 0` and every real `EI`, the [clamped–clamped mode](clamped-clamped-mode.md)
`w(x) = 1 − cos(2πx / L)` and the axial load `P = 4π² EI / L²` (compression positive) satisfy
`EI w''''(x) + P w''(x) = 0` at every `x`, together with `w(0) = w(L) = 0` and `w'(0) = w'(L) = 0`.
For `EI = 0` both terms vanish. This is one explicit eigenpair: it is not claimed to give the lowest
buckling load or to belong to a complete set of modes.
