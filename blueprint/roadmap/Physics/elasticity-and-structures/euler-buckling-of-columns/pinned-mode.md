# Pinned–pinned column mode

For reals `L` (column length) and `x`, `w(x) = sin(πx / L)`, the half-sine profile of a column
pinned at both ends; it vanishes at [`x = 0`](pinned-mode-zero.md) and
[`x = L`](pinned-mode-length.md) for every `L`. With the convention `x / 0 = 0`, `w = 0` everywhere
when `L = 0`. In the physical reading `L > 0`.
