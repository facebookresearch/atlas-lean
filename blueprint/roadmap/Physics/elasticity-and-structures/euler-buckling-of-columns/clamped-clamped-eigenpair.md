# Clamped–clamped buckling eigenpair at the load 4π² EI / L²

For `EI > 0` (flexural rigidity) and `L > 0`, the [clamped–clamped mode](clamped-clamped-mode.md)
`w(x) = 1 − cos(2πx / L)` and the axial load `P = 4π² EI / L²` satisfy the Euler column equation
`EI w'''' + P w'' = 0` at every `x` and the clamped conditions `w(0) = w(L) = 0`,
`w'(0) = w'(L) = 0`. The load is four times the pinned–pinned Euler load `π² EI / L²` (effective
length `L / 2`). This is one explicit eigenpair: it is not claimed to give the lowest buckling load
or to belong to a complete set of modes.
