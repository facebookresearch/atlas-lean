# Work vector of the uniform load

For a span `L` (a real number), the work vector of the uniform load is the one-entry vector
`f(L) = (L / 2)`: the work done by a unit load intensity per unit central deflection of the
three-hinge mechanism of a fixed-ended beam, whose average displacement over the span is half the
central deflection. It is defined for every real `L`; the physical reading is `L > 0`.
