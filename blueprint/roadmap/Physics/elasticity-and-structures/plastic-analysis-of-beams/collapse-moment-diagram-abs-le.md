# The collapse moment diagram stays within the plastic moment

For every real span `L` and every plastic moment `Mp ≥ 0`, the bending-moment diagram at collapse,
the free moment `(w / 2) * (L * x - x ^ 2)` of the load intensity `w = 16 * Mp / L ^ 2` plus the end
moments `-Mp`, satisfies `|(w / 2) * (L * x - x ^ 2) - Mp| ≤ Mp` at every `x` in `[0, L]` (Neal,
Fig. 2.5(d)). For `L > 0` it takes the static certificate's values `-Mp`, `Mp`, `-Mp` at `x = 0`,
`L / 2` and `L`. For `L < 0` the interval is empty; at `L = 0` it is `{0}`, where the value is `-Mp`
(with `w = 0` by the convention `x / 0 = 0`). The physical reading is `L > 0`.
