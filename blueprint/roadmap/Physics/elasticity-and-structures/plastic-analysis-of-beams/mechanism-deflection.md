# Deflection of the three-hinge mechanism

For a span `L`, a central deflection `δ` (positive in the load direction) and a position `x`, all
real, the deflection of the three-hinge mechanism of a fixed-ended beam is
`2 * δ / L * min x (L - x)`: two rigid segments, linear from the supports to mid-span, read on
`0 ≤ x ≤ L`. It is defined for all real inputs; with the convention `x / 0 = 0` it is identically
`0` when `L = 0`. The physical reading is `L > 0`.
