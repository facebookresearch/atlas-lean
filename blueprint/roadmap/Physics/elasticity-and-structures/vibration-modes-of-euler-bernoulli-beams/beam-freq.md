# Modal frequency of a simply supported beam

For reals `EI` (flexural rigidity), `ρA` (mass per unit length) and `L`, and a positive integer `k`,
`ω_k = (kπ / L)² √(EI / ρA)`. With the conventions `x / 0 = 0` and `√x = 0` for `x < 0`, `ω_k = 0`
when `L = 0`, when `ρA = 0`, or when `EI / ρA < 0`. In the physical reading `EI, ρA, L > 0`.
