# Clamped–free mode shape for a root z

For reals `L`, `z` and `x`, with `β = z / L`,
`W(x) = (sin z + sinh z) (cos βx − cosh βx) − (cos z + cosh z) (sin βx − sinh βx)`. With the
convention `x / 0 = 0`, `W = 0` everywhere when `L = 0`. In the physical reading `L > 0` and `z` is
a positive root of `cos z cosh z + 1 = 0`; the formula is defined for all real `z`.
