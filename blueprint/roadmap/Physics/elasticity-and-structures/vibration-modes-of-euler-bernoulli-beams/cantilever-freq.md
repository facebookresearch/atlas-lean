# Natural frequency of the clamped–free mode

For reals `EI`, `ρA`, `L` and `z`, `ω = (z / L)² √(EI / ρA)`. With the conventions `x / 0 = 0` and
`√x = 0` for `x < 0`, `ω = 0` when `L = 0`, when `ρA = 0`, or when `EI / ρA < 0`. In the physical
reading `EI, ρA, L > 0` and `z` is a positive root of `cos z cosh z + 1 = 0`.
