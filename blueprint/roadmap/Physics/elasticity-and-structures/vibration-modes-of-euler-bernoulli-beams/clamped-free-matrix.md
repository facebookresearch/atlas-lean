# Boundary matrix of the clamped–free beam

For a real `z`, the `4 × 4` matrix `M(z)` with rows `(1, 0, 1, 0)`, `(0, 1, 0, 1)`,
`(−cos z, −sin z, cosh z, sinh z)` and `(sin z, −cos z, sinh z, cosh z)`. For all real `β` and `L`
and the coefficients `c` of a [family member](mode-family.md) `W`, the vector `M(βL) c` gives the
boundary traces `W(0) = (M c)₀`, `W'(0) = β (M c)₁`, `W''(L) = β² (M c)₂` and `W'''(L) = β³ (M c)₃`
([boundary traces](mode-family-traces.md)).
