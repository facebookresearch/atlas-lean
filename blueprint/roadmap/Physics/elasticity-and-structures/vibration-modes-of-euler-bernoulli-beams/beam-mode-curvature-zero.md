# For nonzero length the mode has zero curvature at both ends

For a positive integer `k`, a real `L ≠ 0` and all reals `ω` and `t`, the
[simply supported mode](beam-mode.md) `w(x, t) = sin(kπx / L) cos(ω t)` satisfies
`∂²w / ∂x² (0, t) = 0` and `∂²w / ∂x² (L, t) = 0`: the simply supported moment conditions.
