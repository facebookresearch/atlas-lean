# Simply supported beam mode

For a positive integer `k` and reals `L` (beam length), `ω` (angular frequency), `x` and `t`,
`w(x, t) = sin(kπx / L) cos(ω t)`: the `k`-th mode of a simply supported beam, with unit amplitude.
With the convention `x / 0 = 0`, `w = 0` everywhere when `L = 0`. In the physical reading `L > 0`.
