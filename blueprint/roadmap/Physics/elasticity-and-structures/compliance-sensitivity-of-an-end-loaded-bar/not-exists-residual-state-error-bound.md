# No residual bound on the state error uniform in k > 0

For every end force $F$ there is no constant $C$ such that

$$
\left| \frac{F}{k} - u \right| \le C\, |k u - F| \quad \text{for all } k > 0
\text{ and all real } u:
$$

the trial $u = F / k + 1$ has residual $k$ and state error $1$, and $1 \le C k$ fails for small $k$.
Without a lower bound on the stiffness the residual does not control the state error; with
$k \ge k_{\min} > 0$ the constant $1 / k_{\min}$ [does](abs-sub-le-residual-div.md).
