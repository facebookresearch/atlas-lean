# The linear displacement F x / EA solves the end-loaded bar problem

For a length $L > 0$, a rigidity $EA \ne 0$ and an end force $F$, the function $u(x) = F x / EA$
solves the fixed-traction problem on $[0, L]$ with zero distributed load, the derivatives being
taken within $[0, L]$ and so one-sided at the ends:

- $u$ is twice continuously differentiable on $[0, L]$;
- $-(EA\, u''(x)) = 0$ for every $x \in [0, L]$;
- $u(0) = 0$ at the fixed end;
- $EA\, u'(L) = F$ at the loaded end.

The end force is positive along the outward normal $+x$, so tension is positive. In the physical
reading $EA > 0$; the result uses only $EA \ne 0$.
