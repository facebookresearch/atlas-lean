# If kmin < kmax, the feasible directions at kmax are the d ≤ 0

If $k_{\min} < k_{\max}$, the [feasible directions](feasible-directions.md) at the upper endpoint
$k_{\max}$ of $[k_{\min}, k_{\max}]$ are exactly the real $d \le 0$. For a degenerate interval,
$k_{\min} = k_{\max}$, [only $d = 0$ is feasible](feasible-directions-self.md).
