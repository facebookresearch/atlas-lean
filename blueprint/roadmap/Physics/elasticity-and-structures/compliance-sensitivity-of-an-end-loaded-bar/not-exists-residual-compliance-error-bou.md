# For F ≠ 0, no residual bound on the compliance error uniform in k > 0

For an end force $F \ne 0$ there is no constant $C$ such that

$$|J(F, k) - F u| \le C\, |k u - F| \quad \text{for all } k > 0 \text{ and all real } u,$$

with $J(F, k) = F^2 / k$ the [compliance](compliance.md): the trial $u = F / k + 1$ has residual $k$
and compliance error $|F|$, and $|F| \le C k$ fails for small $k$. The force must be nonzero: at
$F = 0$ the compliance error $J - F u$ is $0$, and every $C \ge 0$ gives a bound.
