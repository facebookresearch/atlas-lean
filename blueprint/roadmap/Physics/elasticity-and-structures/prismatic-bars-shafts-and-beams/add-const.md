# A free-free bar solution shifted by a constant is again a solution

Let $k$, $L$, $P_0$ and $P_1$ be real numbers and $f \colon \mathbb{R} \to \mathbb{R}$. If $u$
solves the [free-free problem](is-free-free-solution.md) on $[0, L]$ with rigidity $k$, load $f$ and
end forces $P_0$ and $P_1$, then for every real $c$ the function $x \mapsto u(x) + c$ solves the
same problem. Two free ends admit every rigid translation, so a solution is never unique.
