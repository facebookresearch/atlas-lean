# Calibration of a Maxwell branch over a set of states

For a type $\Theta$ of calibration states (for example temperature, loading rate or frequency, and
material), a calibration of a Maxwell branch consists of two functions
$E, \eta \colon \Theta \to \mathbb{R}$, the calibrated spring modulus and dashpot viscosity, and a
set $D \subseteq \Theta$, the domain on which the calibration is valid, with $E(\theta) > 0$ and
$\eta(\theta) > 0$ for every $\theta \in D$. The values off $D$ are arbitrary and are not used.
