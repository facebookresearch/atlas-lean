# Saturated logarithmic-branch crack path is continuous and nondecreasing

Write $a(N) = a_0 e^{KN}$ for the logarithmic-branch Paris crack, $a_c = (K_{IC}/(Y\sigma))^2/\pi$ for the critical crack length (real $K_{IC}, Y, \sigma$) and $N_f = \log(a_c/a_0)/K$ for the Paris life.
If $K > 0$, $a_0 > 0$ and $f \ge 0$, then the saturated event path $t \mapsto a(\min(f t, N_f))$ on $\mathbb{R}_{\ge 0}$ is continuous and nondecreasing.

Real division by zero is $0$, and $\log 0 = 0$, $\log x = \log\lvert x\rvert$ for $x < 0$; so the critical length, the life $N_f$ and the logarithm are defined for all real inputs.
