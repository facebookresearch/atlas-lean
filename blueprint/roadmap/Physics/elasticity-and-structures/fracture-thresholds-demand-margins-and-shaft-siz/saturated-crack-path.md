# Saturated crack event path

For a crack path $a : \mathbb R \to \mathbb R$ (crack length against cycle count), a load frequency $f$ and a cycle count $N_f$, the saturated event path at time $t \ge 0$ is

$$t \mapsto a(\min(f t, N_f)).$$

For $f \ge 0$ it is the crack after $f t$ cycles until $f t$ reaches $N_f$, and stays at $a(N_f)$ afterwards; the constant part is an event model, not continued crack growth.
