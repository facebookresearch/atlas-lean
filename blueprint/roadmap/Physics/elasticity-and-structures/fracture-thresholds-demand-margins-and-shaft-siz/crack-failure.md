# Crack failure event

For fracture toughness $K_{IC}$, geometry factor $Y$, peak tensile stress $\sigma$ and crack length $a$, crack failure is the equality-inclusive event

$$K_{IC} \le Y\,\sigma\,\sqrt{\pi a},$$

that is, the mode-I stress intensity $K_I(a) = Y\sigma\sqrt{\pi a}$ reaches the fracture toughness. For $a < 0$ the square root takes the convention $\sqrt{x} = 0$ for $x < 0$.
