# Weak solutions of the fixed-fixed bar problem

For a real `L`, functions `EA` (axial rigidity) and `q` (axial load), and an element `u` of
[`H¹₀(0, L)`](weak-h10-on.md) with weak derivative `u'`, `u` is a weak solution of `-(EA u')' = q`
on `[0, L]` with zero displacement at both ends when
`∫_0^L EA(x) u'(x) v'(x) dx = ∫_0^L q(x) v(x) dx` for every element `v` of `H¹₀(0, L)`. The integral
of a non-integrable function is taken to be `0`.
