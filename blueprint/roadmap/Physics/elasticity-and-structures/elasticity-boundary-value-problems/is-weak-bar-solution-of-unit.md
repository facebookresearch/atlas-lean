# A weak solution of the unit problem gives a weak bar solution

For a real `L > 0`, functions `EA` and `q`, and an element `ŵ` of the
[unit space `H¹₀(0, 1)`](../../../Analysis/partial-differential-equations/weak-solutions-of-elliptic-equations/weak-h10.md) with `∫_0^1 κ ŵ' v' = ∫_0^1 f̂ v` for every `v` in that space,
where `κ` is the [rescaled rigidity](scaled-rigidity.md) and `f̂` the [rescaled load](scaled-load.md), the
[push-forward](of-unit.md) `x ↦ ŵ(x / L)` is a [weak bar solution](is-weak-bar-solution.md).
