# Pulling back and pushing forward returns the bar function

For a real `L > 0` and every element `v` of [`H¹₀(0, L)`](weak-h10-on.md), [pulling back](to-unit.md)
to `[0, 1]` and [pushing forward](of-unit.md) again gives the same representative and the same weak
derivative as `v`, as functions on `ℝ`.
