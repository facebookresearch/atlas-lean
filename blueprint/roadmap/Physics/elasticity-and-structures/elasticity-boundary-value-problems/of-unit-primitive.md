# Substituting ξ = x / L carries the primitive to the bar

For a real `L > 0` and every element `w` of the [unit space `H¹₀(0, 1)`](../../../Analysis/partial-differential-equations/weak-solutions-of-elliptic-equations/weak-h10.md) with weak
derivative `w'`, `w(x / L) = ∫_0^x w'(t / L) / L dt` for every `x ∈ [0, L]`.
