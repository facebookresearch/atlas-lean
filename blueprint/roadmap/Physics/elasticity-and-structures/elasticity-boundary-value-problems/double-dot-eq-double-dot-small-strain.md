# A symmetric stress does no work on the skew part of a gradient

For a [symmetric](../cauchy-stress-small-strain-and-mohr-s-circle/is-symmetric-stress.md) `3 × 3` matrix `σ` and every `3 × 3` matrix `H`,
`∑_{i,j} σ_ij H_ij = ∑_{i,j} σ_ij ε_ij`, where `ε = (H + Hᵀ) / 2` is the [small strain](../cauchy-stress-small-strain-and-mohr-s-circle/small-strain.md).
