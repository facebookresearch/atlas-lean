# Pushing an element of H¹₀(0, 1) forward to the bar

For a real `L > 0` and an element `w` of the [unit space `H¹₀(0, 1)`](../../../Analysis/partial-differential-equations/weak-solutions-of-elliptic-equations/weak-h10.md) with weak
derivative `w'`, the pushed-forward element of [`H¹₀(0, L)`](weak-h10-on.md) has representative
`x ↦ w(x / L)` and weak derivative `x ↦ w'(x / L) / L`.
