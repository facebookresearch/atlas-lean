# The boundary work is the outward flux of σᵀ v

For a box `[a, b] ⊂ ℝ³`, a stress field `σ` and a virtual displacement `v`, the
[boundary work](box-traction-work.md) equals `∑_i (∫_{x_i = b_i} F_i - ∫_{x_i = a_i} F_i)`, the outward
flux through the faces of the box of the vector field `F(x) = σ(x)ᵀ v(x)`.
