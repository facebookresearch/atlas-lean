# Under a nonzero load the fixed-free displacement is not in H¹₀(0, L)

For real numbers `L > 0`, `EA > 0` and `q ≠ 0`, no element of [`H¹₀(0, L)`](weak-h10-on.md) agrees on
`[0, L]` with the [fixed-free displacement](../prismatic-bars-shafts-and-beams/fixed-free-displacement.md) `q x (2L - x) / (2 EA)`,
which does not vanish at `x = L`: a traction end is not covered.
