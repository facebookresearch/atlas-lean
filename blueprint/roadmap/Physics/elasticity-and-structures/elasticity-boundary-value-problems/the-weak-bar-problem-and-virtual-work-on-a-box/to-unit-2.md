# Pulling a weak bar solution back to the unit interval

Let `L > 0`. If `u` is a weak solution of the bar problem on `[0, L]` with
rigidity `EA` and load `q`, its pullback to `[0, 1]` is a weak solution of the
unit problem with the scaled rigidity and scaled load: for every $v \in H^1_0(0, 1)$,
$\int_0^1 \kappa(\xi)\,\hat{u}'(\xi)\,v'(\xi)\,d\xi = \int_0^1 \hat{f}(\xi)\,v(\xi)\,d\xi$, where
$\hat{u}'(\xi) = L\,u'(L\xi)$, $\kappa(\xi) = EA(L\xi)/L$ and $\hat{f}(\xi) = L\,q(L\xi)$.
