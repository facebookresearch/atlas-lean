# Virtual work on a box with a clamped face

Let `[a, b]` be a nondegenerate box in three dimensions (`a i < b i`)
contained in an open set `U`, let the stress `σ` have components continuously
differentiable on `U` and be symmetric on the box, and let `div σ + body = 0`
on the box. If the virtual displacement `v` is continuously differentiable on
`U` and vanishes on the lower face `x i₀ = a i₀`, then `∫ σ : ε(v) = ∫ body ·
v` plus the traction work on the six faces with that lower face omitted.
