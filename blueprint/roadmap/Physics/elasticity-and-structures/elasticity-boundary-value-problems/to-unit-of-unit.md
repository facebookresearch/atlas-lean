# Pushing forward and pulling back returns the unit function

For a real `L > 0` and every element `w` of the [unit space `H¹₀(0, 1)`](../../../Analysis/partial-differential-equations/weak-solutions-of-elliptic-equations/weak-h10.md),
[pushing forward](of-unit.md) to `[0, L]` and [pulling back](to-unit.md) again gives the same
representative and the same weak derivative as `w`, as functions on `ℝ`.
