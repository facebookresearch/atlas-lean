# Closed-form pressure gradient of a plane slider

For real numbers `μ`, `U`, `h₀`, `h_L`, `L` and `x`, with `h = h(x)` the
[film thickness](slider-film.md), the pressure gradient is `6 μ U (h - h_m) / h³` with
`h_m = 2 h₀ h_L / (h₀ + h_L)`. With the convention `a / 0 = 0`, `h_m = 0` when `h₀ + h_L = 0` and
the gradient is `0` when `h = 0`.
