# Kern rule for eccentrically loaded footings

For a rigid strip footing of width `B > 0` carrying a vertical load `N > 0` and a moment `M` about
its centreline, both per unit out-of-plane length, the two edge pressures `N / B - 6 M / B²` and
`N / B + 6 M / B²` of the linear full-contact solution are both nonnegative if and only if the
eccentricity satisfies the kern bound `|M / N| ≤ B / 6`.
