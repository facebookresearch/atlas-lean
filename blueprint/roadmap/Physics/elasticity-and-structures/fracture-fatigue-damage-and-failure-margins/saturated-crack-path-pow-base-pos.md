# Along the event path the power-branch base stays positive

Let $K > 0$, $r \ne 0$ ($r = 1 - m/2$ for a Paris exponent $m \ne 2$), $f \ge 0$ and
$0 < a_0 < a_c$, where $a_c = (K_{IC}/(Y\sigma))^2/\pi$ is the [critical crack
length](critical-crack-length.md) for real $K_{IC}$, $Y$ and $\sigma$; let
$a(N) = (a_0^r + r K N)^{1/r}$ be the [power-branch solution](paris-crack-pow.md) and
$N_f = (a_c^r - a_0^r)/(r K)$ its [Paris life](paris-life-pow.md). Then at every time $t \ge 0$ the
base of the solution is positive at the cycle count $N = \min(f t, N_f)$ used by the [event
path](saturated-crack-path.md):

$$a_0^r + r K \min(f t, N_f) > 0 .$$

So the event path never evaluates the solution where its base is zero or negative; for $r < 0$
($m > 2$) the base would reach zero at the blow-up cycle count $a_0^r / (-r K)$.
