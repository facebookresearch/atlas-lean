# Class counts aggregated from cycle records

For a finite type $\kappa$ of records, each record $k$ carrying a class $g(k) \in \iota$ and a real
count $r_k$, the count of class $i$ is

$$n_i = \sum_{k \,:\, g(k) = i} r_k,$$

which is $0$ for a class with no record. No sign condition is put on the record counts; in the
physical reading they are nonnegative.
