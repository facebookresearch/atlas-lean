# For $K > 0$, $0 < a_0 < a_c$: $a_0 e^{KN} < a_c$ iff $N < N_f$

Let $K > 0$ and $0 < a_0 < a_c$. For every real cycle count $N$, the
[logarithmic-branch crack](paris-crack-exp.md) is below the target length exactly before the
[Paris life](paris-life-exp.md) $N_f = \log(a_c/a_0)/K$:

$$a_0\, e^{K N} < a_c \iff N < N_f,$$

both inequalities strict.
