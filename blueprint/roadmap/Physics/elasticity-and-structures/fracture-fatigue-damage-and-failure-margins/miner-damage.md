# Palmgren–Miner damage sum over finitely many cycle classes

For a finite type $\iota$ of cycle classes, real counts $n_i$ and positive lives $N_i > 0$, the
Palmgren–Miner damage sum is

$$D = \sum_{i \in \iota} \frac{n_i}{N_i}.$$

The definition takes a proof that every life is positive, so no ratio $n_i / 0$ arises (by the
convention $x / 0 = 0$ such a ratio would be $0$). Counts are real numbers of any sign in the
definition, so a half cycle counts $1 / 2$; in the physical reading $n_i \ge 0$ is the number of
cycles applied in class $i$ and $N_i$ the number of cycles to failure at that class under
constant-amplitude loading, both in the same cycle unit. With no class the sum is $0$. The sum is an
empirical bookkeeping index: no failure criterion at $D = 1$ or at any other value is part of the
definition.
