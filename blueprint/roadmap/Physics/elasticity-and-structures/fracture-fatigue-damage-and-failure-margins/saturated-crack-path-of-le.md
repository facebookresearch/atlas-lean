# For $f > 0$, the event path equals $a(N_f)$ from time $N_f / f$ on

Let $a : \mathbb{R} \to \mathbb{R}$ be any function, $N_f$ any real number and $f > 0$. At every
time $t \ge 0$ with $t \ge N_f / f$, the [event path](saturated-crack-path.md)
$d(t) = a(\min(f t, N_f))$ equals $a(N_f)$: from that time on it stays at the crack length after
$N_f$ cycles. The condition $f > 0$ is needed: at $f = 0$ the path is $a(\min(0, N_f))$, which is
$a(0)$ when $N_f \ge 0$.
