# Pulling an element of H¹₀(0, L) back to the unit interval

For a real `L > 0` and an element `v` of [`H¹₀(0, L)`](weak-h10-on.md) with weak derivative `v'`, the
pulled-back element of the [unit space `H¹₀(0, 1)`](../../../Analysis/partial-differential-equations/weak-solutions-of-elliptic-equations/weak-h10.md) has representative `ξ ↦ v(L ξ)`
and weak derivative `ξ ↦ L v'(L ξ)`.
