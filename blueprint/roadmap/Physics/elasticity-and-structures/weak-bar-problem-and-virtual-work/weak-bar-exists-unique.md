# The weak fixed-fixed bar problem with bounded rigidity is well posed

Let `L > 0`, `EA` a function almost everywhere strongly measurable on `[0, L]` with
`0 < EA_min ≤ EA ≤ EA_max` almost everywhere on `[0, L]`, and `q` square integrable on `[0, L]`.
Then a [weak bar solution](is-weak-bar-solution.md) `u` exists, and every weak solution `u'`
satisfies `u'(x) = u(x)` for every `x ∈ [0, L]`. The proof rescales the bar to the
[unit-interval problem](../../../Analysis/partial-differential-equations/weak-solutions-of-elliptic-equations/weak-diffusion-exists-unique.md).
