# Contracting with the engineering shear strain doubles the shear work

For real numbers `τ ≠ 0` and `γ ≠ 0` and every point `x`, with the
[simple-shear stress](simple-shear-stress.md) `σ` and the [small strain](../cauchy-stress-small-strain-and-mohr-s-circle/small-strain.md) `ε` of the
[simple shear](../cauchy-stress-small-strain-and-mohr-s-circle/simple-shear-field.md) `u(x) = (γ x₁, 0, 0)`: `∑_{i,j} σ_ij ε_ij = τ γ`; contracting `σ`
with the [engineering shear](../cauchy-stress-small-strain-and-mohr-s-circle/engineering-shear.md) `γ₀₁ = 2 ε₀₁` in both off-diagonal slots gives
`σ₀₁ γ₀₁ + σ₁₀ γ₀₁ = 2 τ γ`; and `2 τ γ ≠ τ γ`.
