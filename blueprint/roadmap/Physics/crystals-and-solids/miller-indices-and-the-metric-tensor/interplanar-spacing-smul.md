# For n ≠ 0, indices n h have the spacing of h over the modulus of n

For every [Bravais lattice](../bravais-lattices/bravais-lattice.md), every integer `n ≠ 0` and all
Miller indices `h ≠ 0`, the [interplanar spacings](interplanar-spacing.md) satisfy
`d_(n h) = d_h / |n|`: the family `(2 0 0)` has half the spacing of `(1 0 0)`.
