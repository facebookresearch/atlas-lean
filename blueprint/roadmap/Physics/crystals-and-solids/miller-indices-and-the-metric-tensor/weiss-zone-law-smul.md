# For n ≠ 0, scaling the plane indices by n keeps the zone law

For every [Bravais lattice](../bravais-lattices/bravais-lattice.md), every integer `n ≠ 0` and all
`h`, `u ∈ ℤ³`, `g_(n h) · [u] = 0` if and only if `g_h · [u] = 0`, where `g` denotes
[reciprocal-lattice vectors](reciprocal-vector.md) and `[u]` the
[lattice direction](lattice-direction.md): a direction lies in the planes `(2 0 0)` exactly when it
lies in the planes `(1 0 0)`.
