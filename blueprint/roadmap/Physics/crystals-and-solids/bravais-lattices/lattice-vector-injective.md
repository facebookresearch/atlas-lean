# For det B ≠ 0, distinct integer vectors n give distinct vectors B n

For every [Bravais lattice](bravais-lattice.md) with basis matrix `B` (`det B ≠ 0`), the map
`n ↦ B n` from cell indices `n ∈ ℤ³` to lattice vectors is injective. The basis matrices of Bravais
lattices are exactly the real `3 × 3` matrices with nonzero determinant, so equivalently: for every
real `3 × 3` matrix `B` with `det B ≠ 0`, the map `n ↦ B n` from integer vectors `n ∈ ℤ³`, with
entries read as reals, to `ℝ³` is injective.
