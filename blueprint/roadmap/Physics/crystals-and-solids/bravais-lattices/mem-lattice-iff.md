# The lattice consists of the vectors B n with n integral

For every [Bravais lattice](bravais-lattice.md) with basis matrix `B` and every `x ∈ ℝ³`, `x`
belongs to the [lattice](lattice.md) `L` if and only if `x = B n` for some `n ∈ ℤ³`. Equivalently,
as a set, `L = {B n : n ∈ ℤ³}`, the image of the [lattice-vector map](lattice-vector.md) `n ↦ B n`.
