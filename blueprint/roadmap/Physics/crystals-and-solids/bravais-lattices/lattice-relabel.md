# A unimodular relabeling preserves the lattice

For every [Bravais lattice](bravais-lattice.md) and an integer `3 × 3` matrix `P` with `det P = ±1`
(so that `P` has an integer inverse), the [relabeled lattice](relabel.md) has the same lattice `L`
as the original: `{(B P) n : n ∈ ℤ³} = {B n : n ∈ ℤ³}`.
