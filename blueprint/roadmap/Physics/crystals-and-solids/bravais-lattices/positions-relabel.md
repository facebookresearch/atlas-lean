# Relabeling the cells of a crystal moves no atom

For every [crystal](bravais-crystal.md) with finite nonempty motif `F` and an integer `3 × 3` matrix
`P` with `det P = ±1` (so that `P` has an integer inverse), the [relabeled crystal](relabel-2.md)
has the same set of [atomic positions](positions.md) as the original.
