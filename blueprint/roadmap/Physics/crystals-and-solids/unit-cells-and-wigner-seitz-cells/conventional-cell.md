# Closed conventional cell of a Bravais lattice

For a [Bravais lattice](../bravais-lattices/bravais-lattice.md) with primitive vectors `a₀`, `a₁`,
`a₂`, the conventional cell is the closed parallelepiped `{t₀ a₀ + t₁ a₁ + t₂ a₂ : 0 ≤ tᵢ ≤ 1}`.
Lattice points on its faces, edges and corners are shared with neighbouring cells, so the
[number of lattice points per cell](points-per-cell.md) is not the number of lattice points in this
closed set: for the cube in the face-centred cubic lattice the eight corners alone are lattice
points, while the count per cell is `4`.
