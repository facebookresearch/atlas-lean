# Elastic modulus estimated from the bond stiffness

For real numbers `S₀` (bond stiffness) and `r₀` (equilibrium spacing), the estimate is `S₀ / r₀`:
the simple-cubic model estimate of an elastic modulus, not a theorem about real solids. With the
convention `a / 0 = 0`, it is `0` when `r₀ = 0`; the intended domain is `r₀ > 0`.
