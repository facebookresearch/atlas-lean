# Each primitive vector is a lattice vector

Let `Λ` be a [Bravais lattice](../bravais-lattices/bravais-lattice.md) with basis matrix `B`, whose
columns are the primitive vectors `a₁`, `a₂`, `a₃` (so `det B ≠ 0`). Each primitive vector `aⱼ`
belongs to the [lattice](../bravais-lattices/lattice.md) of `Λ`, the set of integer combinations of
the primitive vectors.
