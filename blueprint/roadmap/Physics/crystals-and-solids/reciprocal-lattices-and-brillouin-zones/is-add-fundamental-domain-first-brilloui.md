# The first Brillouin zone is a fundamental domain for reciprocal shifts

For every [Bravais lattice](../bravais-lattices/bravais-lattice.md), the
[first Brillouin zone](first-brillouin-zone.md) is a fundamental domain for the translations by
vectors of the [reciprocal lattice](reciprocal.md), for Lebesgue measure on `ℝ³`: it is measurable
up to a null set, almost every wave vector has a reciprocal-lattice translate in the zone, and the
translates of the zone by distinct reciprocal lattice vectors overlap only in sets of measure zero.
