# Radius ratio of the face-centred cubic tetrahedral hole

For `a > 0`, `R = a / (2√2)` (face-centred cubic touching) and `r = √3 a / 4 − R`,
`r / R = √(3/2) − 1` and `|r / R − 0.225| < 0.001`. The same holds when the centre distance is a
separate quantity: for `a > 0`, `R = a / (2√2)`, `d = √3 a / 4` and `r = d − R`, again
`r / R = √(3/2) − 1` and `|r / R − 0.225| < 0.001`.
