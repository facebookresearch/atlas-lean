# Radius ratio of the face-centred cubic octahedral hole

For `a > 0`, `R = a / (2√2)` (face-centred cubic touching) and `r = a/2 − R`, `r / R = √2 − 1` and
`|r / R − 0.414| < 0.001`. The same holds when the centre distance is a separate quantity: for
`a > 0`, `R = a / (2√2)`, `d = a / 2` and `r = d − R`, again `r / R = √2 − 1` and
`|r / R − 0.414| < 0.001`.
