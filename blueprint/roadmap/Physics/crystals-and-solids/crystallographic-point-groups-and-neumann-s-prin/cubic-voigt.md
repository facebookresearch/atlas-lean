# Cubic Voigt

The cubic Voigt family: `3 × 3` normal block with `c11` on the diagonal
and `c12` off-diagonal, `3 × 3` shear block `c44 • 1`, zero couplings:
```
c11 c12 c12 0   0   0
c12 c11 c12 0   0   0
c12 c12 c11 0   0   0
0   0   0   c44 0   0
0   0   0   0   c44 0
0   0   0   0   0   c44
```
