# Inversion forces an invariant rank-three polar tensor to vanish

Let `T` be a real array `T_{ijk}` with indices `i, j, k ∈ {1, 2, 3}`. If `T_{ijk} = -T_{ijk}` for
all `i`, `j`, `k`, then `T = 0`. Read with Neumann's principle: the inversion acts on a rank-three
polar tensor by `T ↦ -T`, so such a property (for example piezoelectricity) vanishes in a crystal
whose point group contains the inversion. Axial tensors, which pick up an extra `det R` factor, are
not covered.
