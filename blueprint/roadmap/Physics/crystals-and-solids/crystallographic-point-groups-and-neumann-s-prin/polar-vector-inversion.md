# Inversion forces an invariant polar vector to vanish

For every `v ∈ ℝ³`, if `v = -v` then `v = 0`. Read with Neumann's principle: the inversion
`x ↦ -x` acts on a polar vector by `v ↦ -v`, so a polar vector property of a crystal whose point
group contains the inversion vanishes. The invariance is a modelling premise, carried as the
hypothesis `v = -v`.
