# Lattice endomorphism: a matrix conjugate to an integer matrix

For a natural number `n` and a real `n × n` matrix `R`, `R` is a lattice endomorphism if there are
an integer `n × n` matrix `M` and a real `n × n` matrix `P` with `det P ≠ 0` such that
`R = P M P⁻¹`. Equivalently, `R` maps the full-rank lattice `P ℤⁿ` into itself
([criterion](is-lattice-endomorphism-iff-maps-to.md)), not necessarily onto it: for `n = 1`,
`R = M = 2` and `P = 1` map `ℤ` onto `2ℤ`. A matrix mapping a full-rank lattice onto itself is a
[lattice symmetry](is-lattice-symmetry.md).
