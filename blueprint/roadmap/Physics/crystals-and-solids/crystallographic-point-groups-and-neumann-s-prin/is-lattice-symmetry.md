# Lattice symmetry: a matrix mapping a full-rank lattice onto itself

For a natural number `n` and a real `n × n` matrix `R`, `R` is a lattice symmetry if there is a real
`n × n` matrix `P` with `det P ≠ 0` such that the image of the [lattice](basis-lattice.md) `P ℤⁿ`
under `v ↦ R v` is `P ℤⁿ` itself. This is the defining property of the elements of a lattice's point
group; a [lattice endomorphism](is-lattice-endomorphism.md) need only map the lattice into itself.
