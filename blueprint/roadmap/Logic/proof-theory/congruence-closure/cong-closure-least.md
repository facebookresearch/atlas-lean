# Cong Closure least

Let $E$ and $R$ be binary relations on ground terms. Suppose $R$ contains $E$, is reflexive, symmetric and transitive, and is compatible with the function symbol: $R(t_1, t_2)$ and $R(s_1, s_2)$ imply $R(\mathrm{app}(t_1, s_1), \mathrm{app}(t_2, s_2))$. Then $R$ contains the congruence closure of $E$: for all ground terms $t, s$, if $t \equiv_E s$ then $R(t, s)$.
