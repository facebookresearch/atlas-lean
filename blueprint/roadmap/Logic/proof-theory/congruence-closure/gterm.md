# GTerm

Ground terms over a signature with constants $c_0, c_1, c_2, \dots$ indexed by $\mathbb{N}$ and one binary function symbol $\mathrm{app}$ are generated inductively by:

- for every $c \in \mathbb{N}$, the constant $c_c$ is a ground term;
- if $t$ and $s$ are ground terms, then $\mathrm{app}(t, s)$ is a ground term.
