BI combines intuitionistic propositional logic with multiplicative intuitionistic linear logic: an additive conjunction and implication and a multiplicative conjunction and implication sit side by side, so that contexts ("bunches") are built with two different combining operations. BI is closely connected with the propositional fragment of separation logic. LBI is complete for BI-algebras and for Grothendieck resource models; for the elementary semantics completeness holds without $\bot$ and fails with it; for resource models with an inconsistent world this topic states soundness for LBI, while the completeness results of Galmiche, Méry and Pym for them concern the tableau calculus TBI.

The literature on BI contains several algebraic and relational semantics, some of which capture only fragments of the logic or use more complex clauses for some connectives, such as Beth's clause for disjunction in the Grothendieck semantics. Galatos, Jipsen, Knudstorp and Ramanayake prove that provability in BI is undecidable, by encoding Wang tilings into the ternary relational semantics, and identify gaps in earlier publications claiming decidability; that result belongs with the other undecidable substructural calculi. Boolean BI, Classical BI and the non-commutative variant are separate logics and are not part of this topic.
