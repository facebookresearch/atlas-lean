# Circuit upper bounds unprovable in Cook's theory PV

For every $k\ge1$ there is a polynomial-time language that Cook's theory PV cannot prove to have circuits of size $O(n^k)$; equivalently, it is consistent with PV that this language is not in $\mathsf{SIZE}(n^k)$ (Krajíček and Oliveira).

PV is the theory whose language has a function symbol for every polynomial-time algorithm, generated by Cobham's limited recursion on notation, and whose axioms are universal sentences describing how these algorithms are defined from each other (Cook's equational theory, reformulated as a universal first-order theory). For a unary PV function symbol $f$ and integers $k,c\ge 1$, let $\mathrm{UP}_{k,c}(f)$ be the sentence

$$
\forall 1^{(n)}\ \exists\,\text{circuit } C_n\ \big(|C_n|\le c\,n^k\big)\ \forall x\ \big(|x|=n\to(f(x)\neq 0\leftrightarrow C_n(x)=1)\big),
$$

where $|C_n|$ is the number of gates of $C_n$ and $\forall 1^{(n)}$ quantifies over strings of $n$ ones.

**Theorem (Krajíček–Oliveira).** For every $k\ge 1$ there is a unary PV function symbol $h$ such that for no constant $c\ge 1$ does PV prove $\mathrm{UP}_{k,c}(h)$.

**Corollary.** For every $k\ge 1$ there is a unary PV function symbol $h$ and a model $M_k$ of PV such that $M_k\vDash\neg\mathrm{UP}_{k,c}(h)$ for every $c\ge1$.

The theorem remains true if PV is extended by any set of true universal sentences.

## Expansion

The proof adapts the Santhanam–Williams theorem that $\mathsf P$ has no polynomial-time uniform circuits of size $O(n^k)$. If PV proved $\mathrm{UP}_{k,c}(g)$ for a language $g$ in $\mathrm{DTIME}(n^{3k})$ that diagonalizes against time $n^{3k-1}$ algorithms with $n^{2/3}$ bits of advice, the KPT witnessing theorem for universal theories would give finitely many polynomial-time functions $f_1,\dots,f_r$ such that PV proves that one of them outputs a correct small circuit after seeing the previous counterexamples. Herbrand's theorem converts the uniform circuit lower bound, formalized in PV, into polynomial-time functions producing counterexamples, and an induction on $r$ removes the disjuncts one by one; one of the finitely many provability assumptions used must fail. The argument is non-constructive: the hard language may depend on a hypothetical proof.
