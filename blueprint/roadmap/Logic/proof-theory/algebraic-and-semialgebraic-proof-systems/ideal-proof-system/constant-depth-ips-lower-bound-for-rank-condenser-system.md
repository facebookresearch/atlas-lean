# Constant-depth IPS lower bound for the rank-condenser determinantal system

Over characteristic zero, no polynomial-size constant-depth circuit can even approximately compute an IPS refutation of the statement that an $n \times n$ matrix $X$ has rank below $r$, encoded succinctly with a rank condenser, yet is invertible with inverse $Y$, once $r \ge n^{\Omega(1)}$.

Let $\mathbb{F}$ have characteristic zero, let $r \le n$, and let $\mathcal{E} \subseteq \mathbb{F}^{r \times n}$ be the explicit weak $(r, r(n-r))$-lossless rank condenser of size $|\mathcal{E}| = 2r(n-r) + 1$. Let $X, Y$ be $n \times n$ matrices of variables and $I_n$ the identity, and consider the unsatisfiable system

$$
\det_r(E X E^\top) = 0 \;\; (E \in \mathcal{E}), \qquad XY - I_n = 0, \qquad X \odot X - X = 0, \qquad Y \odot Y - Y = 0,
$$

with $\odot$ the entrywise product. Let $C(X, Y, \vec{z}, W, U, V)$ be any IPS refutation of it, with placeholders $\vec{z}$ for the first family and matrices $W, U, V$ of placeholders for the other three. Then any circuit of product-depth $\Delta$ that computes $C + O(\varepsilon)$, i.e. computes $C$ in the border sense, has size at least

$$
r^{(\log r)^{\exp(-O(\Delta))}} - O(n^4) .
$$

In general characteristic the reduction states: if every product-depth-$\Delta$ circuit computing $\det_n(X) + O(\varepsilon)$ (or, in characteristic $p$, any $\det_n(X)^{p^k} + O(\varepsilon)$) needs size $t(n, \Delta)$, then every product-depth-$\Delta$ circuit computing $C + O(\varepsilon)$ needs size $t(\Omega(r^{1/3}), \Delta + 1) - O(n^4)$.

## Proof sketch

By the rank-condenser lemma, $\det_r(E M E^\top) = 0$ for all $E \in \mathcal{E}$ exactly when $\mathrm{rank}(M) < r$, so the system is unsatisfiable, while dropping the first family leaves the satisfiable point $X = Y = I_n$. The ideal version of the multiples lemma then shows that $1 - C(X, Y, 0, XY - I_n, X \odot X - X, Y \odot Y - Y)$ is a nonzero element of the ideal generated by the $r \times r$ minors (via Cauchy-Binet). The main theorem of the paper projects any nonzero element of this determinantal ideal, using standard bideterminants and the straightening law, to an approximation of the $\Theta(r^{1/3}) \times \Theta(r^{1/3})$ determinant with a small depth-three oracle circuit, so the Limaye-Srinivasan-Tavenas constant-depth lower bounds apply. Assuming super-polynomial border formula lower bounds for the determinant, the same system has no polynomial-size formula-IPS refutation.
