# Constant-depth IPS lower bound for the rank-condenser determinantal system

Over characteristic zero, once $r \ge n^{\Omega(1)}$, no polynomial-size constant-depth circuit can even approximately compute any IPS refutation of the rank-condenser system $\det_r(E X E^\top) = 0$ ($E \in \mathcal{E}$), $XY = I_n$, with Boolean axioms on $X$ and $Y$; the bound applies to every refutation that exists.

Let $\mathbb{F}$ have characteristic zero, let $r \le n$, and let $\mathcal{E} \subseteq \mathbb{F}^{r \times n}$ be the explicit weak $(r, r(n-r))$-lossless rank condenser of size $|\mathcal{E}| = 2r(n-r) + 1$. Let $X, Y$ be $n \times n$ matrices of variables and $I_n$ the identity, and consider the system

$$
\det_r(E X E^\top) = 0 \;\; (E \in \mathcal{E}), \qquad XY - I_n = 0, \qquad X \odot X - X = 0, \qquad Y \odot Y - Y = 0,
$$

with $\odot$ the entrywise product. Let $C(X, Y, \vec{z}, W, U, V)$ be any IPS refutation of it (the statement is conditional on $C$ being a refutation and says nothing about whether one exists), with placeholders $\vec{z}$ for the first family and matrices $W, U, V$ of placeholders for the other three. Then any circuit of product-depth $\Delta$ that computes $C + O(\varepsilon)$, i.e. computes $C$ in the border sense, has size at least

$$
r^{(\log r)^{\exp(-O(\Delta))}} - O(n^4) .
$$

In general characteristic the reduction states: if every product-depth-$\Delta$ circuit computing $\det_n(X) + O(\varepsilon)$ (or, in characteristic $p$, any $\det_n(X)^{p^k} + O(\varepsilon)$) needs size $t(n, \Delta)$, then every product-depth-$\Delta$ circuit computing $C + O(\varepsilon)$ needs size $t(\Omega(r^{1/3}), \Delta + 1) - O(n^4)$.

## Proof sketch

The argument uses only that $C$ is an IPS refutation, not the rank-condenser lemma discussed below. Dropping the first family leaves the satisfiable point $X = Y = I_n$, so the ideal version of the multiples lemma shows that $f = 1 - C(X, Y, 0, XY - I_n, X \odot X - X, Y \odot Y - Y)$ is nonzero (it equals $1$ at that point) and lies in the ideal generated by the $\det_r(E X E^\top)$; by Cauchy-Binet each of these lies in the ideal generated by the $r \times r$ minors of $X$, so $f$ is a nonzero element of the determinantal ideal of the $n \times 2n$ matrix $(X \mid Y)$. The main theorem of the paper projects any nonzero element of this ideal, using standard bideterminants and the straightening law, to an approximation of the $\Theta(r^{1/3}) \times \Theta(r^{1/3})$ determinant with a small depth-three oracle circuit, so the Limaye-Srinivasan-Tavenas constant-depth lower bounds apply. Assuming super-polynomial border formula lower bounds for the determinant, the same reasoning bounds formula-IPS refutations.

The source motivates the system by a rank-condenser lemma asserting that $\det_r(E M E^\top) = 0$ for all $E \in \mathcal{E}$ exactly when $\mathrm{rank}(M) < r$, which would make the system unsatisfiable. That equivalence fails: over $\mathbb{Q}$ with $n = 2$, $r = 1$, the skew-symmetric $M = \begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}$ has rank $2$, yet $E M E^\top = 0$ for every row $E$. The step from full rank of $EA$ and $EB$ to full rank of $(EA)(EB)^\top$ in its proof is not valid. Only the conditional lower bound above, which does not depend on that lemma, is recorded here.
