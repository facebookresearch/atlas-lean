# Cut admissibility with the Boolean cut-freeness test, for list contexts

Cut admissibility for cut-free proofs defined by the Boolean cut-freeness test, when equality of
atoms is decidable and the side contexts are lists: from cut-free proofs of `⊢ a, Γ` and
`⊢ a⫠, Δ` it builds a cut-free proof of `⊢ Γ, Δ`.
