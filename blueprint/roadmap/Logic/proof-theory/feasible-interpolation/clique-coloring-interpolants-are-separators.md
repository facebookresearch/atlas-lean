# Interpolants of clique–coloring formulas are clique–coloring separators

A Boolean function of the edge variables is an interpolant of $\mathrm{Clique}_{n,k} \wedge \mathrm{Color}_{n,r}$ if and only if it is $1$ on every graph containing a $k$-clique and $0$ on every $r$-colorable graph. In particular for $r < k$ the formula is unsatisfiable, since no graph with a $k$-clique is $(k-1)$-colorable.

## Proof sketch

Satisfiability of each part for a fixed graph is exactly the existence of a $k$-clique, respectively an $r$-coloring.
