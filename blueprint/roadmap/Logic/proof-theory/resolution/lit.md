# Lit

A literal is a pair $(v, b) \in \mathbb{N} \times \{\mathrm{true}, \mathrm{false}\}$: the variable $x_v$ when $b = \mathrm{true}$ and its negation $\neg x_v$ when $b = \mathrm{false}$. A clause is a finite set of literals, and a formula in conjunctive normal form is a finite list of clauses.
