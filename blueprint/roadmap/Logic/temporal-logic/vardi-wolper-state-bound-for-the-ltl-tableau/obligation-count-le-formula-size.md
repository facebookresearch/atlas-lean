# Until-obligations are bounded by the formula size

For every LTL formula $\varphi$, the number of until-obligations of $\varphi$ is at most the [size](../model-checking-for-linear-temporal-logic/size.md) of $\varphi$, the number of its connective and atom occurrences. This is implied by the [strict bound](../model-checking-for-linear-temporal-logic/obligation-count-lt-size.md): the number of until-obligations is less than the size.
