# Run semantics agrees with word semantics at every position

For every valuation of atoms on states, run $\rho$, position $k$ and LTL formula $\varphi$, $\varphi$ holds at position $k$ of $\rho$ under the run semantics if and only if it holds at position $k$ of the $\omega$-word $\rho(0)\rho(1)\rho(2)\dots$ under the word semantics with the same valuation.
