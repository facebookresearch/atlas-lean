# LTL satisfaction agrees on set-valued and Boolean words

For every LTL formula $\varphi$ and every ω-word $w$ of Boolean valuations, the word of [set views](to-set.md) $\{a : w_n(a) = \mathrm{true}\}$ [satisfies](../linear-temporal-logic/satisfies.md) $\varphi$, an atom $a$ holding at a set $s$ when $a \in s$, if and only if $w$ satisfies $\varphi$, an atom $a$ holding at a valuation $v$ when $v(a) = \mathrm{true}$.
