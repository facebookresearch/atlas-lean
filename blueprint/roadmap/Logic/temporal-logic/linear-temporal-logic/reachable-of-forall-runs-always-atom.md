# Reachability from safety on infinite runs

Let $s$ be a state of a labelled transition system with a valuation of atoms on states, and suppose every state reachable from $s$ in zero or more steps lies on some infinite run from $s$. Then, if the atom $a$ holds at every position of every infinite run from $s$, it holds at every state reachable from $s$. The extra hypothesis is needed: at a deadlocked state where $a$ is false no infinite run starts, so the condition on runs holds vacuously there.
