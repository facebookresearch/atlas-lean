# Expansion law for until on runs

For every valuation of atoms on states, every run $\rho$ and all LTL formulas $\varphi$ and $\psi$,
$\rho$ satisfies $\varphi \mathbin{\mathsf{U}} \psi$ if and only if either $\rho$ satisfies $\psi$, or
$\rho$ satisfies $\varphi$ and also $\mathsf{X}(\varphi \mathbin{\mathsf{U}} \psi)$. This is
[the expansion law for until](until-expansion.md), stated for runs instead of ω-words.
