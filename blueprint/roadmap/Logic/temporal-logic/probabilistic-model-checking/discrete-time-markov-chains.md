# Discrete-time Markov chains

A *discrete-time Markov chain* (DTMC) is a tuple $D = (S, \bar s, \mathbf{P}, L)$ of a countable set $S$ of states, an initial state $\bar s \in S$, a transition probability matrix $\mathbf{P} : S \times S \to [0, 1]$ with $\sum_{s' \in S} \mathbf{P}(s, s') = 1$ for every $s \in S$, and a labelling $L : S \to 2^{AP}$ by sets of atomic propositions. A *path* is a finite or infinite sequence $s_0 s_1 \cdots$ with $\mathbf{P}(s_i, s_{i+1}) > 0$ for all $i$. The probability of a finite path $\rho = s_0 \cdots s_n$ is $\mathbf{P}(\rho) = \prod_{i < n} \mathbf{P}(s_i, s_{i+1})$. For each state $s$, the infinite paths from $s$ carry the probability measure $\Pr_{D,s}$ on the $\sigma$-algebra generated by the *cylinders* $C_\rho$, the sets of infinite paths extending a finite path $\rho$ from $s$; it is the unique measure with $\Pr_{D,s}(C_\rho) = \mathbf{P}(\rho)$ for every such $\rho$.
