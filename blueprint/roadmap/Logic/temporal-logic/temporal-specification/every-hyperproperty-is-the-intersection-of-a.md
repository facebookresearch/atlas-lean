# Every hyperproperty is the intersection of a hypersafety and a hyperliveness property

Over a fixed set of infinite traces, every hyperproperty (a set of sets of traces) is the intersection of a hypersafety property and a hyperliveness property. Every hypersafety property is subset-closed: if a system $T$ satisfies it, so does every $T' \subseteq T$; consequently generalized noninterference, which is not subset-closed, is not a hypersafety property.
