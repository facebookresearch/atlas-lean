# HyperLTL model checking is PSPACE-hard in the system size

**Theorem.** For [HyperLTL](hyperltl.md) formulas, the model checking problem is hard for [PSPACE](../../../TheoryOfComputation/complexity-classes/time-and-space-complexity-classes/pspace.md) when complexity is measured in the size of the Kripke structure.
