# CTL$^{\ast}$ path satisfaction on labeled executions

Satisfaction of a CTL$^{\ast}$ path formula on an infinite labelled execution of a transition
system: a next formula $\bigcirc\pi$ holds when $\pi$ holds on the execution without its first
step, and $\pi\, \mathcal{U}\, \pi'$ holds when $\pi'$ holds on some suffix and $\pi$ on every
earlier suffix.
