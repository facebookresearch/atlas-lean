# Valid LTL formula

An LTL formula $\varphi$ is valid, for a valuation of its atoms on the letters, if every
infinite word satisfies $\varphi$.

## Sources

- M. Y. Vardi, "An automata-theoretic approach to linear temporal logic", in *Logics for Concurrency: Structure versus Automata*, LNCS 1043, Springer 1996, pp. 238-266. Numbering from the author's posted version (https://www.cs.rice.edu/~vardi/papers/banff94rj.pdf), which may differ from the published text. Section 4.1.
