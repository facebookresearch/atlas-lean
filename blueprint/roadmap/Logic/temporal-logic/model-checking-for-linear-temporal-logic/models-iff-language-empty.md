# LTL satisfaction iff the counterexample language is empty

Universal infinite-run satisfaction is emptiness of the counterexample language.

The counterexample automaton is the product of the system with the Büchi automaton of
$\neg\varphi$, so this is the emptiness form $L_\omega(A_P) \cap L_\omega(A_{\neg\varphi}) =
\emptyset$ of the verification problem.
