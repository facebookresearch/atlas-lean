# Fairness obligations are fewer than the formula size

The number of until occurrences of an LTL formula $\varphi$, which is the number of
generalized Büchi acceptance sets of its tableau, is strictly less than $|\varphi|$: every
formula has at least one atom or truth leaf, which is not an until.
