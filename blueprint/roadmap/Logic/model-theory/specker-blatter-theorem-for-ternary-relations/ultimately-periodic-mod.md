# Ultimately periodic sequences modulo $m$

A sequence $s : \mathbb{N} \to \mathbb{N}$ is ultimately periodic modulo $m \in \mathbb{N}$ if there exist a period $p \ge 1$ and a threshold $N \in \mathbb{N}$ such that for all $n \ge N$,

$$s(n + p) \bmod m = s(n) \bmod m.$$

For $m = 0$ this reads $s(n + p) = s(n)$, since $k \bmod 0 = k$.
