# Ehrenfeucht–Fraïssé theorem

Let $\mathfrak A$ and $\mathfrak B$ be structures over a finite relational vocabulary and $k \ge 0$. In the $k$-round Ehrenfeucht–Fraïssé game on $\mathfrak A$ and $\mathfrak B$, in each round the spoiler picks an element of either structure and the duplicator answers with an element of the other; the duplicator wins if the elements picked define a partial isomorphism between $\mathfrak A$ and $\mathfrak B$. Then $\mathfrak A$ and $\mathfrak B$ satisfy the same first-order sentences of quantifier rank at most $k$ if and only if the duplicator has a winning strategy in the $k$-round game. For finite linear orders $L_n = (\{1, \dots, n\}, <)$, the duplicator wins the $k$-round game on $L_m$ and $L_n$ whenever $m, n \ge 2^k - 1$; hence no first-order sentence holds in exactly the linear orders of even size.
