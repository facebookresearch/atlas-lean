# The numbering of WS1S terms is injective

The numbering of WS1S terms by tagged square-shell pairing (variable $x_i \mapsto \langle 0, i\rangle$, $0 \mapsto \langle 1, 0\rangle$, $t + 1 \mapsto \langle 2, c(t)\rangle$) is injective. This follows from the distinct tags, the injectivity of the pairing, and recursion on terms; consequently a code determines its term, by unpairing the tag and recursing.
