# Satisfaction of WS1S formulas

For a first-order assignment $v : \mathbb{N} \to \mathbb{N}$ and a set assignment $V$ sending each index to a finite set of natural numbers, truth of a WS1S formula is defined by recursion: $t_1 = t_2$ and $t_1 < t_2$ hold when the values of the terms under $v$ are equal, respectively in increasing order; $t \in X_i$ holds when the value of $t$ belongs to $V(i)$; $\bot$ never holds; $\varphi \to \psi$ holds when $\psi$ holds whenever $\varphi$ does; $\forall\varphi$ holds when $\varphi$ holds for every natural number $x$ under the first-order assignment that puts $x$ at index $0$ and shifts $v$ by one ($j + 1 \mapsto v(j)$), with $V$ unchanged; and $\forall^2\varphi$ holds when $\varphi$ holds for every finite set $X$ of naturals under the set assignment that puts $X$ at index $0$ and shifts $V$ by one, with $v$ unchanged.
