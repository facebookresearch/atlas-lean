# Gödel numbering of WS1S formulas

WS1S formulas are numbered by tagging each constructor, with $c$ the code of terms: $t_1 = t_2$ has code $\langle 0, \langle c(t_1), c(t_2)\rangle\rangle$; $t_1 < t_2$ has code $\langle 1, \langle c(t_1), c(t_2)\rangle\rangle$; membership $t \in X_i$ has code $\langle 2, \langle c(t), i\rangle\rangle$, pairing the term code with the set index in that order; $\bot$ has code $\langle 3, 0\rangle$; $\varphi \to \psi$ has code $\langle 4, \langle \ulcorner\varphi\urcorner, \ulcorner\psi\urcorner\rangle\rangle$; first-order universal quantification $\forall\varphi$ has code $\langle 5, \ulcorner\varphi\urcorner\rangle$; and set quantification $\forall^2\varphi$ has code $\langle 6, \ulcorner\varphi\urcorner\rangle$. Here $\langle a, b\rangle$ is the square-shell pairing of natural numbers, $\langle a, b\rangle = b^2 + a$ if $a < b$ and $a^2 + a + b$ otherwise (so $\langle 1, 1\rangle = 3$), not Cantor's diagonal pairing, which sends $(1, 1)$ to $4$. In particular $\bot$ is not coded by the bare constant $3$, which would collide with the code of a less-than formula.
