# Downward Löwenheim–Skolem theorem

Let $L$ be a first-order language with countably many symbols and $T$ an $L$-theory. If $T$ has an infinite model, then $T$ has a countably infinite model. The countability of the language is needed: a language with uncountably many constants, with axioms saying that distinct constants denote distinct elements, has an infinite model and no countable one. Consequently no set of first-order sentences in a countable language is satisfied exactly by its uncountable models.
