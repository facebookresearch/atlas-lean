# Downward Löwenheim–Skolem theorem

Let $\Gamma$ be a consistent set of sentences of a first-order language with countably many symbols. Then $\Gamma$ has a countable model: a structure satisfying $\Gamma$ whose domain is finite or countably infinite. If the language has no identity symbol, $\Gamma$ even has a countably infinite model. Consequently no set of first-order sentences in a countable language is satisfied exactly by the uncountable structures.
