# Kourovka Problem 15.86: squarelike and discriminating groups

Statement (Kourovka Notebook Problem 15.86, D. Spellman): every squarelike group is elementarily equivalent to a discriminating group. That is, for every group $G$, if $G$ is universally equivalent to some discriminating group, then there is a discriminating group $D$ such that $G$ and $D$ satisfy the same first-order sentences of the language of groups.

A group $D$ is discriminating if for every finite set $S$ of nontrivial elements of $D \times D$ there is a homomorphism $f : D \times D \to D$ with $f(x) \neq 1$ for all $x \in S$. A group is squarelike if it satisfies the same universal sentences of the first-order language of groups (multiplication, inversion and the identity) as some discriminating group; a universal sentence is a block of universal quantifiers followed by a quantifier-free formula. It holds; the resolution is [Squarelike groups are elementarily equivalent to discriminating groups](squarelike-elementarily-equivalent-to-di-2.md).
