# Sentences true in almost all finite groups

A coded sentence $\varphi$ of the language of groups holds in almost all finite groups if there is $N \in \mathbb{N}$ such that $\varphi$ holds in every finite group $G$ with $|G| \ge N$.

Since there are only finitely many groups of each order up to isomorphism, this is the same as holding in all but finitely many finite groups up to isomorphism.
