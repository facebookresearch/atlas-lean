# Finite model property for equality-free positive Horn logic

Statement (Open Problem Garden, B. Martin, equality-free form): the fragment $\mathrm{pH} \wedge \neg \mathrm{pH}$ has the finite model property. For every relational first-order language $L$ and all equality-free positive Horn sentences $\varphi$ and $\psi$ of $L$ (built from relational atoms by $\wedge$, $\forall$ and $\exists$), if $\varphi \wedge \neg \psi$ holds in some nonempty $L$-structure, then it holds in some finite nonempty $L$-structure.

Equivalently, $\varphi$ entails $\psi$ as soon as $\varphi \to \psi$ holds in every finite nonempty $L$-structure: entailment and finite entailment coincide for these sentences. Sentences containing equality and languages with function or constant symbols are not covered. It holds; the resolution is [Entailment equals finite entailment for equality-free positive Horn logic](positive-horn-finite-model-property-hold.md).
