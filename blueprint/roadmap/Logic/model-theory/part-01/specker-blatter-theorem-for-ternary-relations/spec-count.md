# Counting labelled ternary structures satisfying a sentence

For a first-order sentence $\varphi$ in the language of one ternary relation symbol $R$ and $n \in \mathbb{N}$, let $[n] = \{0, \dots, n-1\}$. The counting function is

$$f_\varphi(n) = \#\{A \subseteq [n]^3 : ([n], A) \models \varphi\},$$

the number of relations $A$ on $[n]$ such that the structure with universe $[n]$ interpreting $R$ by $A$ satisfies $\varphi$; that is, the number of labelled structures on $[n]$ in the class defined by $\varphi$.
