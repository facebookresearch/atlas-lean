# Specker–Blatter theorem for ternary relations

A sequence $s : \mathbb{N} \to \mathbb{N}$ is ultimately periodic modulo $m \in \mathbb{N}$ when the residue sequence $u(n) = s(n) \bmod m$ is [eventually periodic](../../../../Dynamics/topological-symbolic-dynamics/eventually-periodic-sequences/is-eventually-periodic.md): there are a period $p \ge 1$ and a threshold $N$ with $u(n + p) = u(n)$ for all $n \ge N$. It is the residue sequence, not necessarily $s$, that is periodic; for $m = 0$, since $k \bmod 0 = k$, the residue sequence is $s$ itself.
