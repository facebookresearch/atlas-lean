# Katsuno-Mendelzon update representation with partial orders

Over a finite set of atoms, an update operator on sets of interpretations satisfies the Katsuno-Mendelzon postulates (U1)-(U8) if and only if there is an assignment of a partial order $\le_I$ to each interpretation $I$ (reflexive, transitive and antisymmetric, with $I$ strictly below every other interpretation) such that for all model sets $A$, $B$,

$$\mathrm{upd}(A, B) = \bigcup_{I \in A} \min(B, \le_I).$$

(H. Katsuno and A. O. Mendelzon, On the difference between updating a knowledge base and revising it, Proceedings of KR 1991, Theorem 3.1, conditions 1 and 3.)
