# WS1S formulas

Formulas of WS1S are built from the atomic formulas $t_1 = t_2$, $t_1 < t_2$ and $t \in X_k$ for first-order terms $t_1, t_2, t$ and set variables $X_k$, falsity, implication, and universal quantification over first-order variables and over set variables, with variables indexed by position.
