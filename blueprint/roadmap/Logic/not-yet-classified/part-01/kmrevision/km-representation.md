# Katsuno–Mendelzon representation theorem

Over a finite set of propositional variables, a revision operator on finite sets of interpretations satisfies the Katsuno–Mendelzon postulates (R1)–(R6) if and only if there is a faithful assignment, that is, a total preorder $\le_A$ on interpretations for each set $A$ such that the members of $A$ are pairwise equivalent and strictly below every non-member, with the revision of $A$ by $B$ equal to the set of $\le_A$-minimal members of $B$, for all $A$ and $B$ (Katsuno and Mendelzon 1991, Theorem 2.1).
