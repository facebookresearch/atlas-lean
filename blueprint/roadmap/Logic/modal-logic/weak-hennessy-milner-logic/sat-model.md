# Model of the saturated transition system

For a labelled transition system with a silent label, the Hennessy–Milner model on its saturation: its transitions are those of the saturated system, in which each labelled step is a [weak transition](satisfies.md) of the original system (for $\tau$, zero or more silent steps, so every state has a $\tau$-step to itself), and its valuation is empty.
