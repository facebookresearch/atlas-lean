# Observation formulas

For a set of labels, the observation formulas are the finitary Hennessy–Milner formulas without atomic propositions, generated by the grammar $\varphi ::= \top \mid \neg\varphi \mid \varphi \wedge \varphi \mid \langle a\rangle\varphi$, with $a$ a label. Falsity, disjunction and the box modality are defined from these: $\bot = \neg\top$, $\varphi \vee \psi = \neg(\neg\varphi \wedge \neg\psi)$ and $[a]\varphi = \neg\langle a\rangle\neg\varphi$.
