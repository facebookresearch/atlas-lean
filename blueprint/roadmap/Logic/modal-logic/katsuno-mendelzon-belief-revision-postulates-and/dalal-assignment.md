# Dalal's faithful assignment

Let `σ` be a finite set of atoms with decidable equality, and represent each propositional formula over `σ` by its finite set of models (interpretations `σ → Bool`). The Dalal preorders form a faithful assignment in the sense of Katsuno–Mendelzon: for each model set `A` the Dalal preorder relative to `A` is a total preorder on interpretations, no model of `A` is strictly below another model of `A`, and every model of `A` is strictly below every non-model of `A`.
