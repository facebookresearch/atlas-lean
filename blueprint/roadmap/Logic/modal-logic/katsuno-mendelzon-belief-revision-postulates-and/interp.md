# Interpretations of a propositional signature

For any type $\sigma$ of atoms, an interpretation is a function $\sigma \to \{\mathrm{true}, \mathrm{false}\}$, an assignment of truth values to the atoms; no finiteness is required of $\sigma$ (for example $\sigma = \mathbb{N}$ is allowed). The model-set development of belief revision built on it takes $\sigma$ finite with decidable equality, and represents each propositional formula by its finite set of models; in that representation the syntax-irrelevance postulate (R4) of Katsuno and Mendelzon is congruence for equality of model sets.
