# ALC as multimodal K_m

Fix concept names $N_C$ and role names $N_R$. ALC concepts are generated by
$C ::= A \mid \top \mid \bot \mid \neg C \mid C \sqcap C \mid C \sqcup C \mid \exists r.C \mid \forall r.C$ with
$A \in N_C$, $r \in N_R$; multimodal formulas by
$\varphi ::= p_A \mid \top \mid \bot \mid \neg\varphi \mid \varphi \wedge \varphi \mid \varphi \vee \varphi \mid \langle r \rangle \varphi \mid [r]\varphi$.
The translation $t$ with $t(A) = p_A$, $t(\exists r.C) = \langle r \rangle t(C)$, $t(\forall r.C) = [r]\,t(C)$,
commuting with the Boolean constructors, is a bijection between the two term languages, with the
structural inverse. An interpretation $(\Delta, \cdot^I)$ and the Kripke model with worlds $\Delta$,
relations $R_r = r^I$ and valuation $V(p_A) = A^I$ determine each other, and $d \in C^I$ if and only if
$t(C)$ holds at $d$. Hence a concept is satisfiable (nonempty extension in some interpretation) if and
only if its translation is satisfiable in some $K_m$ model, and $C \sqsubseteq D$ holds in all
interpretations (without TBox) if and only if $t(C) \to t(D)$ is valid in $K_m$.

The truth condition $d \in C^I \iff$ $t(C)$ holds at $d$ is proved by induction on $C$: the Boolean cases are
immediate, and $d \in (\exists r.C)^I$ if and only if some $e$ with $(d, e) \in R_r$ has $e \in C^I$, which by induction
is the truth condition of $\langle r \rangle t(C)$; dually for $\forall r.C$ and $[r]$. The satisfiability and subsumption
statements follow, since an ALC interpretation and its Kripke model have the same domain.
