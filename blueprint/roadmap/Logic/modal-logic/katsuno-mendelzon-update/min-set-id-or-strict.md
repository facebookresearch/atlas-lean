# Minimal models under the identity-or-strict order

Let `σ` be a finite set of atoms with decidable equality, and represent each propositional formula over `σ` by its finite set of models (interpretations `σ → Bool`). For a relation `≤` on interpretations, let `J ≼ K` hold iff `J = K` or (`J ≤ K` and not `K ≤ J`). Then for every model set `B`, the minimal elements of `B` for `≼` are exactly the minimal elements of `B` for `≤`, where a minimal element is a member of `B` with no member of `B` strictly below it.
