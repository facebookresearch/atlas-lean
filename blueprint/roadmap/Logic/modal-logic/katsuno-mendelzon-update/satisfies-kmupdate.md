# Katsuno–Mendelzon update postulates

Let `σ` be a finite set of atoms with decidable equality, and represent each propositional formula over `σ` by its finite set of models (interpretations `σ → Bool`). An operator `upd` on model sets satisfies the Katsuno–Mendelzon update postulates (U1)–(U8) (Katsuno & Mendelzon, *On the Difference between Updating a Knowledge Base and Revising It*, §3.2) when, for all model sets `A`, `A₁`, `A₂` (old knowledge bases) and `B`, `B₁`, `B₂`, `C` (sentences): (U1) `upd A B ⊆ B`; (U2) if `A ⊆ B` then `upd A B = A`; (U3) if `A` and `B` are nonempty then so is `upd A B`; (U4) syntax irrelevance, here congruence in the model sets; (U5) `upd A B ∩ C ⊆ upd A (B ∩ C)`; (U6) if `upd A B₁ ⊆ B₂` and `upd A B₂ ⊆ B₁` then `upd A B₁ = upd A B₂`; (U7) if `A` is complete then `upd A B₁ ∩ upd A B₂ ⊆ upd A (B₁ ∪ B₂)`; (U8) `upd (A₁ ∪ A₂) B = upd A₁ B ∪ upd A₂ B`.
