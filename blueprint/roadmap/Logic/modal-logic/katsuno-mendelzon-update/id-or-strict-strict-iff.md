# The identity-or-strict relation has the same strict part

For a relation `R` on a type, let `J ≼ K` hold iff `J = K` or (`R J K` and not `R K J`). Then `≼` has the same strict part as `R` (Katsuno–Mendelzon, p. 10): `J ≼ K` and not `K ≼ J` hold iff `R J K` and not `R K J`. In particular the conversion preserves faithfulness.
