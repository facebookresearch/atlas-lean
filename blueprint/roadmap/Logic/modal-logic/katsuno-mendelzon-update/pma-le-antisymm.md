# Winslett's order is antisymmetric

Let `σ` be a finite set of atoms with decidable equality. Winslett's order relative to `I` is antisymmetric: if `J ≤_{I,pma} K` and `K ≤_{I,pma} J` then `J = K`, since an interpretation is determined by `I` and its `Diff` from `I`. Together with the fact that these orders form a faithful update assignment, Winslett's approach is given by a faithful assignment of partial orders.
