# Winslett's order relative to an interpretation

Let `σ` be a finite set of atoms with decidable equality. Winslett's order relative to an interpretation `I` (Katsuno–Mendelzon, §3.1), written `J₁ ≤_{I,pma} J₂`, holds iff `Diff(I, J₁) ⊆ Diff(I, J₂)`. Closeness is inclusion of the sets of changed atoms, not comparison of their sizes.
