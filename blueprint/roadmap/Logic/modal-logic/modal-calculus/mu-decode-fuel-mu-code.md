# Fuelled decoding inverts the μ-calculus number code

For every μ-calculus formula $\varphi$ and every natural number $f$ at least the depth of $\varphi$, decoding the
pairing code of $\varphi$ with fuel $f + 1$ returns $\varphi$. Since the depth of a formula is at most
its code, fuel equal to the code plus one always suffices. Fuel equal to the depth can fail: an
atom has depth $0$, and decoding with fuel $0$ always fails.
