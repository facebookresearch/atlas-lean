# Arithmetical soundness of GL

In a Hilbert–Bernays–Löb provability structure with the diagonal property of the formalized Löb
theorem, if $\mathrm{GL} \vdash \varphi$ then $T \vdash f^*(\varphi)$ for every realization $f$.

For Peano arithmetic the converse is Solovay's arithmetical completeness theorem (1976), stated in
prose on the topic page.
