# K4 does not prove Löb's axiom

$\mathrm{K4} \nvdash \Box(\Box\bot \to \bot) \to \Box\bot$. Hence GL strictly extends K4.

Proof: in the one-world model whose world sees itself (a transitive model), $\Box\bot$ fails
while $\Box(\Box\bot \to \bot)$ holds; every K4 theorem is valid there.
