# Frame correspondence for Löb's axiom

Let $W$ be a nonempty set of worlds, $R$ a relation on $W$, and assume there is at least one atom.
Löb's axiom $\Box(\Box\varphi \to \varphi) \to \Box\varphi$ holds at every world of every model on
the frame $(W, R)$, for every formula $\varphi$, if and only if $R$ is transitive and conversely
well-founded.



## Background

- [Löb's axiom is valid on transitive conversely well-founded frames](valid-axiom-lob.md): the direction from right
  to left.
