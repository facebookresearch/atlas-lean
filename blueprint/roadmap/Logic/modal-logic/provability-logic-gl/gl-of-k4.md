# Every theorem of K4 is a theorem of GL

If $\mathrm{K4} \vdash \varphi$ then $\mathrm{GL} \vdash \varphi$.

Proof: induction on the K4-derivation; the only new case, an instance of axiom 4, is a GL theorem.
