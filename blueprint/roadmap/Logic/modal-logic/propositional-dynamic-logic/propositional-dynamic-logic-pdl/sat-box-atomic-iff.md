# Atomic boxes in the translated model

For an atomic program $a$, the formula $[a]\varphi$ holds at a world $w$ of a PDL model if and only if $\varphi$ holds at every $a$-successor of $w$ in the labelled transition system of the model, that is, if and only if the Hennessy–Milner box $[a]\varphi$ holds at $w$ in the corresponding Hennessy–Milner model.
