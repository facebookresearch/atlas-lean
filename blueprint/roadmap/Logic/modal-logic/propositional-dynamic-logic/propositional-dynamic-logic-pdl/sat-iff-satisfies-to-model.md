# The translation to multimodal logic preserves satisfaction

For every PDL model $M$, world $w$ and formula $\varphi$, $\varphi$ holds at $w$ in $M$ if and only if its translation holds at $w$ in the multimodal model whose labels are the programs of PDL, each program $\alpha$ interpreted by the relation it denotes in $M$; the translation sends each box $[\alpha]$ to the modality labelled $\alpha$. In the multimodal model the programs are atomic labels, so sequencing, choice, iteration and tests have no structure there.
