# Kripke model with one atom reinterpreted

For a Kripke model $M$, an atom $p$ and a set $S$ of worlds, the model $M[p \mapsto S]$ has the
worlds and accessibility relation of $M$, makes $p$ true exactly at the worlds of $S$, and keeps
the valuation of every other atom.

## Background

- [Kripke model](kripke-model.md): the structure whose valuation is modified.
