# ALC syntax, semantics and reasoning tasks

ALC concepts over concept names $N_C$ and role names $N_R$ are generated by
$C ::= A \mid \top \mid \bot \mid \neg C \mid C \sqcap C \mid C \sqcup C \mid \exists r.C \mid \forall r.C$. An
interpretation $I = (\Delta^I, \cdot^I)$ has a nonempty domain, $A^I \subseteq \Delta^I$,
$r^I \subseteq \Delta^I \times \Delta^I$ and $a^I \in \Delta^I$ for individual names; complex concepts
are interpreted by the Boolean operations, $(\exists r.C)^I = \{d : \exists e\, ((d,e) \in r^I \wedge e \in C^I)\}$
and $(\forall r.C)^I = \{d : \forall e\, ((d,e) \in r^I \to e \in C^I)\}$. A TBox is a finite set of
inclusions $C \sqsubseteq D$, satisfied when $C^I \subseteq D^I$; an ABox is a finite set of assertions
$C(a)$ and $r(a,b)$. With respect to a TBox $T$: $C$ is satisfiable if $C^I \neq \emptyset$ in some model
of $T$; $C$ is subsumed by $D$ if $C^I \subseteq D^I$ in every model of $T$; an ABox is consistent if it
has a model together with $T$; and entailment of an assertion is truth in every such model. Subsumption reduces to unsatisfiability:
$C \sqsubseteq_T D$ if and only if $C \sqcap \neg D$ is unsatisfiable with respect to the same $T$.

The reduction of subsumption to unsatisfiability is a theorem, not part of the definition.
