# RC-frame

A family of relations $(R_n)_{n \in \mathbb{N}}$ on a set $W$ is an RC-frame when, for all
$x, y, z \in W$ and $m, n \in \mathbb{N}$:

- polytransitivity: $x R_m y R_n z$ implies $x R_{\min(m,n)} z$;
- condition (J): $x R_m y$ and $x R_n z$ with $m > n$ imply $y R_n z$;
- monotonicity: $R_m \subseteq R_n$ for $n < m$.

Polytransitivity and (J) define RJ-frames. Each $R_n$ is transitive.
