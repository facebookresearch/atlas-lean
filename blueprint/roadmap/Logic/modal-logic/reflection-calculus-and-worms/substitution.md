# Closure under substitution

If $A \vdash B$ is derivable in RC, then so is $A[C/p] \vdash B[C/p]$, for every strictly positive
$C$ and atom $p$: RC is a normal positive logic.

Proof: induction on the derivation; every axiom instance becomes an instance of the same axiom.
