# Kripke completeness of RC

A sequent $A \vdash B$ is derivable in RC if and only if it is true in every Kripke model on an
RC-frame.

The source proves completeness for the language
with modalities in $\omega + 1$ by a filtrated canonical model (Theorem 1(ii)); the version for
modalities in $\mathbb{N}$ follows with the conservativity of RC over its fragments (Theorem 2),
since an RC-model restricts to a model on an RC-frame for $\mathbb{N}$. The direction from left to right is soundness.
