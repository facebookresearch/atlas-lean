# Irreflexivity of `<₀` at the worm `0`

$\langle 0 \rangle\top \nvdash \langle 0 \rangle\langle 0 \rangle\top$ in RC, so $0 \not<_0 0$.

Proof: the two-world model with $0 R_0 1$ and all other relations empty is an RC-frame; at world
$0$, $\langle 0 \rangle\top$ holds and $\langle 0 \rangle\langle 0 \rangle\top$ fails, so soundness
excludes the sequent.
