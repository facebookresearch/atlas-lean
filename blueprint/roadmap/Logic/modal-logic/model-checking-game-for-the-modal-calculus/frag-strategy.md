# Positional strategy induced by a Verifier strategy

For a Kripke model $M$, an environment $\mathit{env}$ and a Verifier strategy $\sigma$ of the
model-checking game on $M$, the positional strategy of the even player (Verifier) in the fragment
game of $M$ and $\mathit{env}$ that plays, at each position, the next move induced by $\sigma$.
