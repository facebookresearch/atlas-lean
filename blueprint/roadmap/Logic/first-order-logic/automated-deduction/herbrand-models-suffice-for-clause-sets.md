# Herbrand models suffice for clause sets

Let $S$ be a set of first-order clauses without equality, read as universally closed, over a signature with at least one constant symbol. Then $S$ has a model if and only if it has a Herbrand model: a model whose universe is the set of ground terms of the signature, in which every ground term denotes itself.
