# Critical pair lemma

A term rewriting system $R$ is locally confluent if and only if all its critical pairs are joinable. Consequently, by Newman's lemma, a terminating term rewriting system is confluent if and only if all its critical pairs are joinable; for finite terminating systems this gives a decision procedure for confluence.
