# Satisfiability of regular theories is undecidable for the EPR and Gurevich classes

For infinite sets of first-order formulas generated by a regular grammar, both the conjunctive and the disjunctive satisfiability problems are undecidable already for theories inside the EPR class and inside the Gurevich class, although satisfiability of single formulas of these classes is decidable.

**Regular theories.** A *regular theory* is a set of first-order formulas generated from a start symbol by a regular grammar: a finite set of term nonterminals, each with productions of the forms $x$, $c$ or $f(X_1, \dots, X_k)$, and proposition nonterminals, each with productions of the forms $\neg\Phi$, $\Phi \wedge \Phi'$, $\Phi \vee \Phi'$, $\exists x.\,\Phi$, $\forall x.\,\Phi$, $X_1 = X_2$ or $R(X_1, \dots, X_k)$, over a finite vocabulary and finitely many variables; free variables and constants are allowed. For a regular theory $T$, the *conjunctive satisfiability problem* asks whether some structure satisfies every formula of $T$, and the *disjunctive satisfiability problem* asks whether some formula of $T$ is satisfiable. For a class $\mathcal{C}$ of formulas, a regular $\mathcal{C}$-theory is a regular theory all of whose formulas lie in $\mathcal{C}$.

**Classes.** In the notation $[\Pi, p, f]_=$ for prefix-vocabulary classes with equality, $\Pi$ is the set of allowed quantifier prefixes, $p$ lists the numbers of relation symbols and $f$ the numbers of function symbols of each arity $1, 2, \dots$. The *EPR* (Bernays–Schönfinkel–Ramsey) class consists of function-free formulas with prefixes $\exists^* \forall^*$; the *Gurevich* class consists of purely existential formulas.

**Theorem (Mathur, Mestel and Viswanathan).** The conjunctive and the disjunctive satisfiability problems for regular theories are undecidable

1. for the class $[\exists^* \forall^3, (0,2), (0)]_=$, contained in the EPR class: prefixes $\exists^* \forall^3$, two binary relation symbols, no function symbols, with equality (Theorem 1.2);
2. for the class $[\exists^*, (0), (2)]_=$, contained in the Gurevich class: purely existential formulas over two unary function symbols, with equality (Theorem 1.3).

For single formulas both classes are decidable (Ramsey; Gurevich). The source also identifies decidable subclasses, among them the purely existential and the purely universal function-free formulas, for which both problems are decidable for regular theories.

## Expansion

For the EPR class the proof reduces the Post correspondence problem over $\{0,1\}$. Two binary relations $s_0, s_1$ describe successor steps labeled by bits; a universal formula forces them to be functional and injective in the appropriate sense, and a regular grammar walks a variable $x$ along the letters of $u_{i_1} \cdots u_{i_n}$ and a variable $y$ along those of $v_{i_1} \cdots v_{i_n}$, ending with the test $x = y$. A formula of the generated theory is satisfiable exactly when it describes a solution (disjunctive version); a second grammar handles conjunctive satisfiability. Grammars can "move" a variable along a function application with a dummy existentially quantified variable, as in $\exists x'.\,(x' = f(x) \wedge \exists x.\,(x = x' \wedge \Psi))$, which is used repeatedly. For the Gurevich class the proof instead reduces the halting problem for two-counter Minsky machines, with the two unary functions acting as successor and predecessor on counter values. The undecidability for theories presented by Turing machines is trivial, which is why regular grammars are used.
