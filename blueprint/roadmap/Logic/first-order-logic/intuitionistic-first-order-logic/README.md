# Intuitionistic first-order logic

Natural deduction for intuitionistic first-order logic and its Kripke semantics with expanding domains: persistence, soundness and completeness for formulas with free variables under assignments, and the existence property. Constant-domain semantics validates additional principles; languages with equality need a separately justified extension in which each node interprets equality by a congruence that persists.
