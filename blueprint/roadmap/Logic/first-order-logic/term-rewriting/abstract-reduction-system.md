# Abstract reduction system

An *abstract reduction system* is a pair $(A, \to)$ of a nonempty set $A$ and a binary relation $\to\ \subseteq A \times A$, written $a \to b$ for $(a, b) \in {\to}$. Write $\to^0$ for the identity relation on $A$, $\to^{i+1}$ for the composition $\to \circ \to^i$, $\to^+ = \bigcup_{i > 0} \to^i$ for the transitive closure, $\to^* = \to^+ \cup \to^0$ for the reflexive transitive closure, $\leftarrow$ for the inverse relation, $\leftrightarrow\ = {\to} \cup {\leftarrow}$ for the symmetric closure and $\leftrightarrow^*$ for the reflexive transitive symmetric closure, the equivalence relation generated by $\to$.

An element $b \in A$ is *reducible* if $b \to c$ for some $c$, and *in normal form* (irreducible) otherwise; $c$ is *a normal form of* $b$ if $b \to^* c$ and $c$ is in normal form. The relation $\to$ is *terminating* if there is no infinite chain $b_0 \to b_1 \to b_2 \to \cdots$, and *normalizing* if every element of $A$ has a normal form.
