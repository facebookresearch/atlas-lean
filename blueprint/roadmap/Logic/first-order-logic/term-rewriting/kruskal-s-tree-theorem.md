# Kruskal's tree theorem

Let $\Sigma$ be a finite signature and $X$ a finite set of variables. For every infinite sequence $t_1, t_2, t_3, \dots$ of terms in $T_\Sigma(X)$ there are indices $i < j$ such that $t_j \unrhd_{\mathrm{emb}} t_i$, where $\unrhd_{\mathrm{emb}}$ is the homeomorphic embedding of the [simplification ordering](simplification-ordering.md) page. In other words, $\unrhd_{\mathrm{emb}}$ is a well-partial-ordering of $T_\Sigma(X)$.
