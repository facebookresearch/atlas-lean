# Variable condition for the lexicographic path ordering

For the [lexicographic path ordering](lexicographic-path-ordering.md), $s \succ_{\mathrm{lpo}} t$ implies $\mathrm{var}(s) \supseteq \mathrm{var}(t)$.

**Proof.** Induction on $|s| + |t|$ with a case analysis over the clauses of the definition.
