# Completion steps preserve orientation

If $E, R \vdash E', R'$ is a step of [Knuth–Bendix completion](knuth-bendix-completion.md) with reduction ordering $\succ$ and $\to_R\ \subseteq\ \succ$, then $\to_{R'}\ \subseteq\ \succ$.
