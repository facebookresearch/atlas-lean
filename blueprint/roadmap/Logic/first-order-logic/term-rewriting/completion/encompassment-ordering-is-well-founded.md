# The encompassment ordering is well-founded

The strict encompassment ordering $\sqsupset$ of [Knuth–Bendix completion](knuth-bendix-completion.md), the strict part of $s \sqsupseteq l \iff s|_p = l\sigma$ for some position $p$ and substitution $\sigma$, is a well-founded strict partial ordering on terms.
