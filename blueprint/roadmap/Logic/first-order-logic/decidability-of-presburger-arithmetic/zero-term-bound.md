# The constant $0$ in a context with bound variables

Terms and formulas of the language of Presburger arithmetic ($0$, $S$, $+$, $<$, $=$) with no free variables and $n$ bound variables in scope use the variables $x_0, \dots, x_{n-1}$.

This is the constant term $0$, regarded as a term with no free variables in a context with $n$ bound variables in scope (it uses none of them).
