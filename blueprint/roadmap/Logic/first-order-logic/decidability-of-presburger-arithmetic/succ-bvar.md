# The term $S x$ for a bound variable $x$

In the language of Presburger arithmetic, for any set $\alpha$ of free variables and a context with exactly one bound variable $x$, this is the term

$$S\,x,$$

the successor symbol applied to the bound variable $x$. It is used to form $\varphi(S x)$ from a formula $\varphi(x)$ in the induction schema.
