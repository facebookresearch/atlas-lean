# Decidability of Presburger arithmetic

The following holds: the set

$$\{\, \ulcorner \sigma \urcorner : \sigma \text{ a sentence of Presburger arithmetic with } \mathrm{Pr} \vdash \sigma \,\} \subseteq \mathbb{N}$$

is computable. Here $\mathrm{Pr} \vdash \sigma$ is derivability from the Presburger axioms in the classical natural deduction calculus (sentences regarded as formulas over the infinite set $\mathbb{N}$ of variable names), and $\ulcorner \sigma \urcorner$ is the Gödel number of $\sigma$ under the pairing numbering with tags $0$ for $\bot$, $1$ for equations, $2$ for order atoms, $3$ for implications and $4$ for universal quantifiers.
