# The constant term $0$

In the language of Presburger arithmetic ($0$, $S$, $+$, $<$, $=$), for any set $\alpha$ of variables, this is the constant term $0$: the function symbol $0$ of arity $0$ applied to no arguments, regarded as a term over $\alpha$ (it contains no variable). Taking $\alpha$ to be the variables $x_0, \dots, x_{n-1}$ of a context with no free variables and $n$ bound variables in scope, for any $n$ including $0$, gives the constant $0$ in that context.
