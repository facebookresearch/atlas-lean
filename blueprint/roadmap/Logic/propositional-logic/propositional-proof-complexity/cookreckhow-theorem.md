# Cook–Reckhow theorem

There is a polynomially bounded propositional proof system if and only if $\mathsf{NP} = \mathsf{coNP}$. Here a propositional proof system is a polynomial-time computable function whose range is exactly the set of propositional tautologies, and it is polynomially bounded if every tautology $\varphi$ is the image of a string of length polynomial in $|\varphi|$.
