# Size bounds for the parsimonious 3-CNF reduction

If every clause of a CNF formula $\varphi$ with $m$ clauses has at most $k$ literals, then its
parsimonious reduction to 3-CNF uses at most $(k - 3)\,m$ new variables and has at most
$m + 3\,(k - 3)\,m$ clauses, where $k - 3$ is zero when $k \le 3$.
