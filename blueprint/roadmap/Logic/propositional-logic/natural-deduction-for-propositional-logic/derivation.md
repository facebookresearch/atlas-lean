# Derivations in a theory

For a theory $T$, a finite set $\Gamma$ of propositions and a proposition $B$, a derivation of $\Gamma \vdash B$ in $T$ is built from the rules: axiom (any member of $T$, in any context), assumption (any member of $\Gamma$), introduction and elimination for $\wedge$ (pairing and both projections), for $\vee$ (both injections, and case analysis discharging one hypothesis in each case), and for $\to$ (introduction discharging the hypothesis, and modus ponens). There is no rule for $\bot$, so the empty theory gives minimal logic.
