# Changing the conclusion along an equivalence

Propositions over an atom type with decidable equality are built from atoms by $\wedge$, $\vee$ and $\to$; there is no primitive $\bot$ or $\top$. A theory $T$ is a set of propositions, and $T$ derives a sequent $\Gamma \vdash A$, for a finite set $\Gamma$ of propositions, by natural deduction with the members of $T$ as axioms. Propositions $A$ and $B$ are equivalent in $T$ when $T$ derives $\{A\} \vdash B$ and $\{B\} \vdash A$. Given such an equivalence and a derivation of $\Gamma \vdash A$ in $T$, this produces a derivation of $\Gamma \vdash B$ in $T$, with the same context $\Gamma$.
