# Weakening the context for derivability

Propositions over an atom type with decidable equality are built from atoms by $\wedge$, $\vee$ and $\to$; there is no primitive $\bot$ or $\top$. A theory $T$ is a set of propositions, and $T$ derives a sequent $\Gamma \vdash A$, for a finite set $\Gamma$ of propositions, by natural deduction with the members of $T$ as axioms. If $\Gamma \subseteq \Delta$ and $T$ derives $\Gamma \vdash A$, then $T$ derives $\Delta \vdash A$, in the same theory.
