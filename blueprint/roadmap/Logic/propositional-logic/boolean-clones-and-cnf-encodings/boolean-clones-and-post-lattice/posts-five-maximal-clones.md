# Post's five maximal clones

The five classes of Boolean operations in Post's completeness criterion are: $T_0$, the operations preserving $0$ ($f(0,\dots,0) = 0$); $T_1$, the operations preserving $1$; $M$, the monotone operations ($x \le y$ coordinatewise implies $f(x) \le f(y)$); $S$, the self-dual operations ($f(\bar x_1,\dots,\bar x_n) = \overline{f(x_1,\dots,x_n)}$); and $L$, the affine operations ($f(x) = a_0 \oplus a_1 x_1 \oplus \dots \oplus a_n x_n$ for some $a_i \in \{0,1\}$). Each is a clone, and each equals $\mathrm{Pol}$ of a single relation: $\{0\}$, $\{1\}$, $\le$, $\ne$, and $\{(x,y,z,w) : x \oplus y \oplus z = w\}$ respectively.
