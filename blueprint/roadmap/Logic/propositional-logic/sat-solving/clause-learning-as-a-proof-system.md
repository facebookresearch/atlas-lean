# Clause learning as a proof system

The clause-learning algorithm CLR keeps a [SAT state](unit-resolution-and-sat-solver-states.md) $(\Delta, \Gamma, D)$, starting from $\Gamma = \mathrm{true}$ and $D = \langle\rangle$. If the state is 1-inconsistent, it returns unsatisfiable when $D$ is empty, and otherwise adds the [asserting clause](conflict-clauses-and-asserting-clauses.md) $\alpha$ chosen by its learning scheme to $\Gamma$ and backtracks to the first $m$ decisions, $m$ the assertion level of $\alpha$. Otherwise it may restart, setting $D$ to $\langle\rangle$, and then extends $D$ by a literal that is neither implied nor falsified by unit resolution, returning $D$ when there is none; then $D$ together with the literals that unit resolution derives from $\Delta \wedge \Gamma \wedge D$ assigns every variable and is a model of $\Delta$. An *extended branching sequence*, a sequence of literals and restart symbols, fixes the decisions and restarts. Every state at which CLR tests for a conflict is normal, so its trails and asserting clauses are defined.

A learned clause need not be derivable by resolution itself. With the clauses $\bar a \vee x$, $\bar a \vee \bar x$ and $b \vee z$ and the decisions $b$, then $a$, the clause $\bar a \vee \bar b$ is an asserting conflict clause, but no input clause contains $\bar b$ and resolution introduces no literal, so only its subclause $\bar a$ is derivable by resolution without weakening. Resolution derivations here use no weakening: each clause is an input clause or a resolvent of two earlier clauses, as for [resolution derivability](../resolution/resolution-derivable.md). A run that returns unsatisfiable, at a 1-inconsistent state without decisions, after learning $C_1, \dots, C_k$ yields a refutation as follows: for each $i$, a resolution derivation of a subclause $C'_i \subseteq C_i$ from $\Delta$ and $C'_1, \dots, C'_{i-1}$, a trivial one being given by the lemma that empowering conflict clauses have trivial resolution derivations, since an asserting clause is 1-empowering with respect to the knowledge base at its conflict, followed by the unit-resolution refutation of $\Delta \wedge C'_1 \wedge \dots \wedge C'_k$, which exists because $\Delta \wedge C_1 \wedge \dots \wedge C_k$ is 1-inconsistent and replacing clauses by subclauses keeps it so. A derivation that uses a clause replaced by a subclause becomes, after dropping the resolution steps whose resolved literal is no longer present, a derivation of a subclause of each derived clause with no more steps, so the result is an ordinary resolution refutation of $\Delta$. Only runs that return unsatisfiable yield refutations: on the clauses $x \vee y$, $x \vee \bar y$, $\bar x \vee y$, $\bar x \vee \bar y$ and $b \vee z$, a run can decide $b$ and restart forever without a conflict. For a learning scheme LS, the proof system $\mathrm{CLR}_{\mathrm{LS}}$ consists of all refutations generated in this way. A proof system *p-simulates* another if, for every unsatisfiable formula, its shortest refutation is at most polynomially longer than the shortest refutation in the other.
