# Width of a clause

The number of distinct literals of the clause (Ben-Sasson and
Wigderson, J. ACM 48 (2001), Section 2.3).

Clauses are lists of literals and may repeat a literal; the width counts each literal once, as for the clauses (sets of literals) of Ben-Sasson and Wigderson. For example $x_0 \vee x_0 \vee \neg x_1$ has width $2$.
