# Soundness of propositional tableaux

If some [tableau](propositional-semantic-tableau.md) for a finite set $\{F_1, \dots, F_n\}$ of propositional formulas is closed, then $\{F_1, \dots, F_n\}$ is unsatisfiable. In particular, a formula with a tableau proof is valid.
