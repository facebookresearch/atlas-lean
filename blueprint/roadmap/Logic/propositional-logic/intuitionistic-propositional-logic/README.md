# Intuitionistic propositional logic

Natural deduction for intuitionistic propositional logic and its two semantics: Heyting algebras, with soundness and completeness through the Lindenbaum algebra, and Kripke models over partial orders, with soundness, completeness through the representation of Heyting algebras by prime filters, and the disjunction property. Minimal logic, without ex falso, is a different system.
