# Intuitionistic propositional logic

For any atom type with a designated bottom atom $\bot$, propositions are built from atoms by $\wedge$, $\vee$ and $\to$, there is no primitive $\bot$ or $\top$ other than that atom, and $\neg A$ is $A \to \bot$. A theory is a set of propositions. Intuitionistic propositional logic is the theory $\{\bot \to A : A \text{ a proposition}\}$ of all explosion instances. No decidability of equality of atoms is needed for this definition; the derivation calculus that uses theories assumes it separately.
