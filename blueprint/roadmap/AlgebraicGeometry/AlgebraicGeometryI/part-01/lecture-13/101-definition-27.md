# Definition 27

A functor $F \colon \mathcal{C}_1 \to \mathcal{C}_2$ is called conservative if for every $g \in \operatorname{Hom}(\mathcal{C}_1)$, $F(g)$ is an isomorphism implies that $g$ is an isomorphism.
