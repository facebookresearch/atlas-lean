# Lemma 27

$f \colon X \to Y$ is an affine morphism if and only if for every open $U \subseteq Y$, $f^{-1}(U)$ is affine. $f \colon X \to Y$ is a finite morphism if and only if it is affine and, for every open $U \subseteq Y$ such that $U = \operatorname{Spec} A$, if $f^{-1}(U) = \operatorname{Spec} B$ then $B$ is a finite $A$-algebra.
