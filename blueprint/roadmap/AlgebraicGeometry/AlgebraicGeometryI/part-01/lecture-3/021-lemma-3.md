# Lemma 3

Take $P \in k[x_1, \ldots, x_n]$ a nonconstant polynomial and let $d = \deg P$. There is a linear change of variables such that $P$ has the form $x_n^d + (\text{terms of } \deg_{x_n} < d)$.
