# Definition 25

Let $\mathcal{M}$ be a sheaf on $X$. We say that $\mathcal{M}$ is a sheaf of $\mathcal{O}_X$-modules if for any open subset $U \subset X$ the set $\mathcal{M}(U)$ is an $\mathcal{O}_X(U)$-module, and all restriction maps commute with the ring action.
