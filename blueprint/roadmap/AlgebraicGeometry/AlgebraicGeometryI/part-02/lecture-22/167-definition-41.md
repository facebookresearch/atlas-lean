# Definition 41

Let $\mathcal{F}$ be a coherent sheaf. The rank of $\mathcal{F}$ is defined as the rank of the locally free sheaf $(\mathcal{F}/\text{torsion})$ when we work over smooth varieties. More generically (for any irreducible variety), one defines rank as follows. For a field $K = \varinjlim_U k[U]$, we have the $K$-vector space $V_{\mathcal{F}} = \varinjlim_U \mathcal{F}[U]$. The rank is $\operatorname{rk}(\mathcal{F}) = \dim_K(V_{\mathcal{F}})$.
