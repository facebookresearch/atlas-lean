# Proposition 43

There is always a canonical map $H^i(\mathcal{F}(C)) \to \mathcal{R}^i \mathcal{F}(M)$; moreover, it is an isomorphism if the $M^i$ are adjusted to $\mathcal{F}$. (An object $M$ is called adjusted to $\mathcal{F}$ if $\mathcal{R}^i \mathcal{F}(M) = 0$. Of course, for left exact functors we use left resolutions.)
