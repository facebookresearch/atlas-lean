# Is Ample Line

Ampleness of a line bundle on a Noetherian scheme, by Serre's criterion: for every
finitely presented (that is, coherent) module `F`, the twists `F ⊗ L^{⊗ m}` are generated
by global sections for all large `m`. (Without quasi-compactness this criterion does not
characterize ampleness, so it is only stated on Noetherian schemes.)
