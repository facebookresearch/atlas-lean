# Fundamental Class is Iso

For a topological space $Z$ with a dualizing complex $D_Z$ and a purity isomorphism
$e : D_Z \cong \mathbb{Q}_Z[2d]$, the fundamental class $\mathbb{Q}_Z \to D_Z[-2d]$ defined by $e$
(a class in the Borel–Moore homology of $Z$ in degree $2d$) is an isomorphism in the derived
category of rational sheaves on $Z$.
