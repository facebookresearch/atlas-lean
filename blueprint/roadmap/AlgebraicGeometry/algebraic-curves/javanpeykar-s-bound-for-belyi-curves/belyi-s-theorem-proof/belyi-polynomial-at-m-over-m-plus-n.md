# The polynomial $c \, z^m (1 - z)^n$ takes the value $1$ at $m / (m + n)$

For positive $m$ and $n$, $q_1\bigl(\frac{m}{m + n}\bigr) = 1$, where $q_1 = c \, z^m (1 - z)^n$ and
$c = \dfrac{(m + n)^{m + n}}{m^m n^n}$.
