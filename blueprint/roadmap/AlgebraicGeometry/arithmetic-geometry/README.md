# Arithmetic geometry

Rational points, zero-cycles and point counts of varieties over number fields and finite fields, including the Mordell conjecture, the Weil conjectures, the Brauer–Manin pairing on zero-cycles and unramified cohomology. The Hasse principle and its failures for rational points are under number theory's arithmetic geometry.
