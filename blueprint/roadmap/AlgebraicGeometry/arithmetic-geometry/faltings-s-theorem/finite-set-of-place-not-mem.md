# Finitely many poles

Let $F$ be a function field over a field $K$, that is, a finite
extension of the rational function field $K(t)$. For every $x \in F$, there are only finitely
many places $P$ of $F/K$ whose valuation ring $\mathcal{O}_P$ does not contain $x$, that is,
$x$ has only finitely many poles. See [Stichtenoth, Corollary 1.3.4].

## Sources

- Henning Stichtenoth, *Algebraic Function Fields and Codes*, 2nd ed., Graduate Texts in Mathematics 254, Springer, 2009. Problem `faltings` of the lean-eval benchmark (https://github.com/leanprover/lean-eval/blob/38361be884302c7edce1908c4aef8296eb2cb27e/manifests/problems/faltings.toml).
