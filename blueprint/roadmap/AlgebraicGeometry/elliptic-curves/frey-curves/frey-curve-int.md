# Integral Frey curve

Given a Frey package $(a, b, c, p)$, the integral Frey curve is the Weierstrass curve over $\mathbb{Z}$ with coefficients

$$
a_1 = 1,\quad a_2 = \frac{b^p - 1 - a^p}{4},\quad a_3 = 0,\quad a_4 = \frac{-a^p b^p}{16},\quad a_6 = 0,
$$

where both quotients are integer (floor) divisions in $\mathbb{Z}$. Its equation is $y^2 + xy = x^3 + a_2 x^2 + a_4 x$.
