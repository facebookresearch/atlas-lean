# Rational Frey curve

Given a Frey package $(a, b, c, p)$, the rational Frey curve is the Weierstrass curve over $\mathbb{Q}$ with coefficients

$$
a_1 = 1,\quad a_2 = \frac{b^p - 1 - a^p}{4},\quad a_3 = 0,\quad a_4 = \frac{-a^p b^p}{16},\quad a_6 = 0,
$$

with division in $\mathbb{Q}$, that is, the curve $y^2 + xy = x^3 + a_2 x^2 + a_4 x$.
