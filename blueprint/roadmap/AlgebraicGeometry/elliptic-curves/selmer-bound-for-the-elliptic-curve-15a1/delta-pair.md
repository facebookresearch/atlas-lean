# Descent coordinates of a point on the 15a1 curve

Let $E : y^2 = x^3 + 5x^2 - 152x - 624$ over $\mathbb{Q}$. The descent coordinates of a rational point $P$ of $E$ are the pair $\delta(P) \in \mathbb{Q} \times \mathbb{Q}$ given by

- $\delta(O) = (1, 1)$ for the point at infinity $O$;
- for an affine point $P = (X, Y)$, $\delta(P) = (\delta_1, \delta_2)$ with $\delta_1 = X - 12$ if $X \neq 12$ and $\delta_1 = 400$ if $X = 12$, and $\delta_2 = X + 4$ if $X \neq -4$ and $\delta_2 = -144$ if $X = -4$.
