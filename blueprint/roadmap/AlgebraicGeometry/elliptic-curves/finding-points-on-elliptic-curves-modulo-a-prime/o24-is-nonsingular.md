# Nonsingular curves $y^2 = x^3 + ax + b$ modulo $p$

For natural numbers $a, b, p$, the curve $y^2 = x^3 + ax + b$ is nonsingular modulo $p$ when it has no singular point modulo $p$: for all $x, y < p$ with $y^2 \equiv x^3 + ax + b \pmod p$, it is not the case that both

$$2y \equiv 0 \pmod p \quad\text{and}\quad 3x^2 + a \equiv 0 \pmod p.$$
