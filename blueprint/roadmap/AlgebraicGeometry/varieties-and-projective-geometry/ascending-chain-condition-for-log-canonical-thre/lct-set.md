# Set of log canonical thresholds at the origin

For a natural number $n$, the set of log canonical thresholds in dimension $n$ is

$$T_n = \{ \operatorname{lct}_0(f_1, \dots, f_r) : r \in \mathbb{N},\ f_1, \dots, f_r \in \mathbb{C}[x_1, \dots, x_n],\ \text{some } f_i \neq 0,\ f_i(0) = 0 \text{ for all } i \},$$

where $\operatorname{lct}_0$ is the analytic log canonical threshold at the origin: the supremum in $\mathbb{R}$ of the $c \ge 0$ such that $\left(\sum_i |f_i|^2\right)^{-c}$ is Lebesgue integrable on some ball around $0 \in \mathbb{C}^n$. Thus $T_n$ collects the thresholds of nonzero ideals $(f_1, \dots, f_r)$ vanishing at the origin.
