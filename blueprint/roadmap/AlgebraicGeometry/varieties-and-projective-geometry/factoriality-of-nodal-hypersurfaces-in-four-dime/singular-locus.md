# Singular locus of a hypersurface in projective 4-space

For a polynomial $f \in \mathbb{C}[x_0, \dots, x_4]$, fix for every point $P \in \mathbb{P}^4(\mathbb{C})$ one representative $a_P \in \mathbb{C}^5 \setminus \{0\}$. The singular locus $\operatorname{Sing}(f)$ is the set of points $P$ with

$$\frac{\partial f}{\partial x_i}(a_P) = 0 \quad \text{for all } i \in \{0, \dots, 4\}.$$

For an arbitrary polynomial this test depends on the fixed representative: for $f = x_0^2 - x_0$ the partial derivatives vanish at $(1/2, 0, 0, 0, 0)$ but not at $(1, 0, 0, 0, 0)$, which represent the same point. For homogeneous $f$ the test does not depend on the representative, and for homogeneous $f$ of positive degree these points lie on $\{f = 0\}$ by Euler's formula, so $\operatorname{Sing}(f)$ is then the singular locus of the hypersurface $\{f = 0\} \subseteq \mathbb{P}^4(\mathbb{C})$.
