# Ed Sn seven wanted

Source: Duncan (2010), *Essential dimensions of `A₇` and `S₇`*,
exact value `ed_ℂ(S₇) = 4`. Buhler--Reichstein's general bounds give
only `3 ≤ ed_ℂ(S₇) ≤ 4` here.
