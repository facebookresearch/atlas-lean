# Language of a linear bounded automaton

Let $M$ be a linear bounded automaton with state set $Q$ and tape alphabet $\Gamma$. The language of $M$ is the set of words $w$ over $\Gamma$ that $M$ accepts, that is, such that some
configuration in the accepting state of $M$ is reachable from the initial configuration on $w$ by finitely
many (possibly zero) steps of $M$.
