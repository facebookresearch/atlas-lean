# Transitivity of grammar derivations

Let $Q$ and $\Gamma$ be finite sets, let $M$ be a linear bounded automaton with state set $Q$ and tape alphabet $\Gamma$, and let $G_M$ be the grammar of $M$. If $a$ derives $b$ and $b$ derives $c$ in $G_M$ (each in finitely many, possibly zero, rewriting
steps), then $a$ derives $c$ in $G_M$.
