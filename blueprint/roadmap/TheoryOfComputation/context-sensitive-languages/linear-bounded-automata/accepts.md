# Acceptance by a linear bounded automaton

Let $M$ be a linear bounded automaton with state set $Q$ and tape alphabet $\Gamma$. $M$ accepts a word $w$ over $\Gamma$ if some configuration $c$ is reachable from the initial
configuration of $M$ on $w$ by finitely many (possibly zero) steps of $M$ and the state of $c$ is the
accepting state of $M$.
