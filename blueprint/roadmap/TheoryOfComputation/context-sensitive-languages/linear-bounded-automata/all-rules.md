# All rules of the LBA grammar

Let $Q$ and $\Gamma$ be finite sets and let $M$ be a linear bounded automaton with state set $Q$ and tape
alphabet $\Gamma$. The list of all rules of the grammar of $M$ is the concatenation, in this order, of the
generation rules, the activation rules, the simulation rules for stay moves, the simulation rules for
right moves, the simulation rules for left moves and the conversion rules of $M$.
