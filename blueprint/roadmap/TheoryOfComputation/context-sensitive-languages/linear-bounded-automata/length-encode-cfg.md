# Length of a configuration encoding

Let $M$ be a linear bounded automaton with state set $Q$ and tape alphabet $\Gamma$. Write $\langle a, x, s, f, \beta\rangle$ for the cell nonterminal with original symbol $a \in \Gamma$, current symbol $x$ (a letter of $\Gamma$ or the blank $\sqcup$), head state $s$ (a state, or $\bot$ if the head is not on the cell), activity flag $f \in \{0, 1\}$ ($1$ meaning active) and boundary tag $\beta$. For a word $w = w_0 \cdots w_{n-1}$ over $\Gamma$ and a configuration $c$ of $M$ with state $q$, tape $x_0 \cdots x_{k-1}$ and head position $h$, the encoding $E_w(c)$ is the sentential form $\langle w_0, x_0, s_0, 1, \beta(0, n)\rangle \cdots \langle w_{m-1}, x_{m-1}, s_{m-1}, 1, \beta(m-1, n)\rangle$ with $m = \min(n, k)$, where $s_j = q$ if $j = h$ and $s_j = \bot$ otherwise, and $\beta(h, n)$ denotes the boundary tag of position $h$ on a tape of length $n$ (both if $h = 0$ and $n = 1$; left if $h = 0$ and $n \ne 1$; right if $h \ne 0$ and $h + 1 = n$; middle otherwise).

If the tape of $c$ has length $|w|$, then $E_w(c)$ has length $|w|$.
