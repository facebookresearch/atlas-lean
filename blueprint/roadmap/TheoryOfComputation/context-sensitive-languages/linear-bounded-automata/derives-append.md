# Derivations compose under concatenation

Let $Q$ and $\Gamma$ be finite sets, let $M$ be a linear bounded automaton with state set $Q$ and tape alphabet $\Gamma$, and let $G_M$ be the grammar of $M$. If $a$ derives $b$ and $c$ derives $d$ in $G_M$ (each in finitely many, possibly zero, rewriting
steps), then $ac$ derives $bd$ in $G_M$.
