# Initial configuration of a linear bounded automaton

Let $M$ be a linear bounded automaton with state set $Q$ and tape alphabet $\Gamma$. The initial configuration of $M$ on a word $w = w_1 \cdots w_n$ over $\Gamma$ has the initial state
of $M$, the tape $w_1 \cdots w_n$ (no blank cells; the empty tape if $w$ is empty) and head position $0$.
