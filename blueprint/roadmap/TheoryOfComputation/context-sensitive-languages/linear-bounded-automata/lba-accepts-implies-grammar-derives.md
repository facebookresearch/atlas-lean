# If the LBA accepts a nonempty word, the grammar derives it

Let $Q$ and $\Gamma$ be finite sets and let $M$ be a linear bounded automaton with state set $Q$ and tape alphabet $\Gamma$, with grammar $G_M$.
If $M$ accepts a nonempty word $w$ over $\Gamma$, then $w$ belongs to the language of $G_M$.

This is one inclusion of the LBA-to-grammar direction.
