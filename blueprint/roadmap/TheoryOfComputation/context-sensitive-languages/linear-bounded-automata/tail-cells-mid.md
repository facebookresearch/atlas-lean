# Middle generated cells of a word

Let $Q$ and $\Gamma$ be sets. A cell tuple is a tuple $(a, x, s, f, \beta)$ as in a cell nonterminal. For a word $w = w_1 \cdots w_n$ over $\Gamma$, the middle generated cells
of $w$ are the tuples $(w_1, w_1, \bot, 0, \mathrm{middle}), \dots, (w_n, w_n, \bot, 0, \mathrm{middle})$
(the empty list if $w$ is empty): inactive cells without the head, all tagged middle.
