# Derivations extend by a right context

Let $Q$ and $\Gamma$ be finite sets, let $M$ be a linear bounded automaton with state set $Q$ and tape alphabet $\Gamma$, and let $G_M$ be the grammar of $M$. If $u$ derives $v$ in $G_M$ (in finitely many, possibly zero, rewriting steps), then for every
sentential form $p$ of $G_M$, $up$ derives $vp$ in $G_M$.
