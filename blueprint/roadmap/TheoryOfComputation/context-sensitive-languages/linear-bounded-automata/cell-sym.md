# Cell symbol of the LBA grammar

Let $Q$ and $\Gamma$ be sets. For $a \in \Gamma$, a current symbol $x$ (a letter of $\Gamma$ or the
blank), a head state $s$ (a state of $Q$ or $\bot$), an activity flag $f \in \{0, 1\}$ and a boundary
tag $\beta$, the cell symbol $\langle a, x, s, f, \beta\rangle$ is the grammar symbol given by the cell
nonterminal with these five components.
