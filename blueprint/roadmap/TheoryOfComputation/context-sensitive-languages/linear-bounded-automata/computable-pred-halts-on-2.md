# Halting of a linear bounded automaton is decidable

Let $M$ be a single-tape machine over a nonempty finite alphabet $\Sigma$, and fix any primitive recursive coding of $\Sigma$. If $M$ is a linear
bounded automaton, then the set of input words over $\Sigma$ on which $M$ halts is computable.

## Sources

- M. Sipser, *Introduction to the Theory of Computation*, 3rd ed., Cengage Learning, 2013, Theorem 5.9, of which this is a fixed-machine halting analogue: Sipser decides acceptance uniformly over machine descriptions.
