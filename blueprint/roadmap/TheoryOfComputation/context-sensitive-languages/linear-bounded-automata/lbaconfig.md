# Configuration of a linear bounded automaton

Let $Q$ and $\Gamma$ be sets. A configuration of a linear bounded automaton with state set $Q$ and tape
alphabet $\Gamma$ consists of a state $q \in Q$, a tape, which is a finite list of cells each holding a
letter of $\Gamma$ or a blank, and a head position $h \in \mathbb{N}$ (not required to be less than the
tape length).
