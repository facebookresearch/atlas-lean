# Unrestricted grammars generate exactly the recursively enumerable languages

A language over a finite alphabet is generated by an unrestricted (type-0) grammar, that is, by finitely many productions $\alpha \to \beta$ between arbitrary strings of terminals and nonterminals, the language being the set of terminal words derivable from the start symbol, if and only if it is accepted by a Turing machine, that is, if and only if it is recursively enumerable.
