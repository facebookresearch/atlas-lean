# Count of c's in a sentential form

The $c$-count of a sentential form $u$ of the grammar $G_{abc}$ (a finite word over the symbols
$a, b, c, S, B, C$) is the number of occurrences of the terminal $c$ in $u$ plus the number of
occurrences of the nonterminal $C$ in $u$.

Each $C$ eventually becomes a $c$, so it is counted as a $c$ not yet produced.
