# First-order and quantifier-free reductions

A class $K$ of finite $\sigma$-structures *first-order reduces* to a class $K'$ of $\tau$-structures, $K \le_{\mathrm{fo}} K'$, if some first-order interpretation $I$ of $\tau$ in $\sigma$ satisfies $\mathfrak{A} \in K \iff I(\mathfrak{A}) \in K'$ for every finite $\sigma$-structure $\mathfrak{A}$. It is a *quantifier-free reduction* ($\le_{\mathrm{qf}}$) if $I$ is quantifier-free. On ordered structures the interpretation must also define the order and numeric predicates of its image. Both relations are reflexive on isomorphism-closed classes and transitive, and $K \le K'$ implies the complements reduce likewise.
