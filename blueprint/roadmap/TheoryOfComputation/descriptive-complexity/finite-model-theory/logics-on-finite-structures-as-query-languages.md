# Logics on finite structures as query languages

This node covers the logics used in descriptive complexity as query languages on finite structures: finite relational structures over a fixed finite signature, optionally with a built-in linear order; first-order logic (FO), existential second-order logic (ESO), FO with least fixed points (FO(LFP)) and FO with transitive closure (FO(TC)), each sentence defining the Boolean query of the structures satisfying it; and the standard binary encodings of ordered structures, of length polynomial in the size of the universe, under which queries become languages.

ESO and FO(TC) definability already have pages under descriptive complexity (Fagin's theorem and transitive closure logic). A good expansion adds one definition page per remaining logic and one for the encoding of ordered structures, each stated over the existing finite-structure semantics.
