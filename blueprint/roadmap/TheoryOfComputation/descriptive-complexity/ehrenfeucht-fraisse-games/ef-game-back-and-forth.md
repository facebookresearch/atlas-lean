# Duplicator wins the EF game iff there is a back-and-forth system

For structures $\mathfrak{A}, \mathfrak{B}$ with $k$-tuples $\bar a, \bar b$ and $n \in \mathbb{N}$, Duplicator has a winning strategy in the $n$-round Ehrenfeucht–Fraïssé game starting from the position $(\bar a, \bar b)$ if and only if there is a back-and-forth system of depth $n$ whose top level contains $\bar a \mapsto \bar b$. Duplicator's winning positions form such a system; the winning relation is monotone in $n$ and invariant under isomorphisms and permutations of pebbled pairs.

## Proof sketch

Positions from which Duplicator wins with $j$ rounds left form $I_j$; forth and back are exactly Duplicator's ability to answer moves in either structure.
