# Partial isomorphisms between pointed structures

For relational structures $\mathfrak{A}, \mathfrak{B}$ and tuples $\bar a \in A^k$, $\bar b \in B^k$, the map $a_i \mapsto b_i$ is a *partial isomorphism* if it is well defined and injective ($a_i = a_j \iff b_i = b_j$) and for every relation symbol $R$ of arity $r$ and all indices $i_1,\dots,i_r$, $(a_{i_1},\dots,a_{i_r}) \in R^{\mathfrak{A}} \iff (b_{i_1},\dots,b_{i_r}) \in R^{\mathfrak{B}}$. Equivalently $\bar a$ and $\bar b$ satisfy the same atomic formulas.
