# Grädel: SO∃-Horn captures polynomial time on ordered structures with successor

On finite structures with a built-in successor relation and endpoint constants $0$ and $\max$ (ordered structures whose successor is a primitive symbol), a class of structures is decidable in polynomial time if and only if it is definable by an SO∃-Horn sentence with quantifier-free guards. Equivalently, on such structures SO∃-Horn, FO(LFP) and $\mathrm{P}$ coincide.

## Proof sketch

SO∃-Horn ⊆ P by the least-model algorithm, and SO∃-Horn ⊆ FO(LFP) by the fixed-point translation. Conversely a polynomial-time machine's computation table, indexed by tuples, is generated by Horn clauses whose quantifier-free guards read the input and the successor structure (first-order guards, if used, are removed by guard elimination). The FO(LFP) comparison then follows from Immerman–Vardi.
