# Isomorphism-closed classes and first-order definability on finite structures

Fix a relational vocabulary $\sigma$. A class $K$ of finite $\sigma$-structures is *isomorphism-closed* if it contains, with every member, every structure isomorphic to it. $K$ is *first-order definable* (on finite structures) if there is a first-order sentence $\varphi$ over $\sigma$ such that for every finite $\sigma$-structure $\mathfrak{A}$, $\mathfrak{A} \in K$ iff $\mathfrak{A} \models \varphi$. Definable classes are isomorphism-closed and closed under complement (relative to the finite $\sigma$-structures), finite intersection and finite union. A *Boolean query* is an isomorphism-closed class of finite structures.
