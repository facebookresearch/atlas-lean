# Bijective pebble games characterize counting logic $C^k$

For finite structures $\mathfrak{A}, \mathfrak{B}$ with finitely many relation symbols, positions on at most $k$ pebbles and $n \in \mathbb{N}$: Duplicator wins the $n$-round bijective $k$-pebble game iff the positions satisfy the same $C^k$ formulas of quantifier rank at most $n$, and wins the infinite game iff they satisfy the same $C^k$ formulas (equivalently the same $C^k_{\infty\omega}$ formulas). Winning the bijective game implies winning the ordinary $k$-pebble game.

## Proof sketch

Counting types replace the set of extension types by a multiset recording how often each type is realized; a bijection preserving types exists iff the multisets agree, and counting Hintikka formulas define counting types using quantifiers $\exists^{\ge m}$.
