# Finite-variable counting logics $C^k$ and $C^k_{\infty\omega}$

The counting logic $C^k$ extends $\mathrm{FO}^k$ by counting quantifiers $\exists^{\ge m} x_i\, \varphi$, "at least $m$ values of $x_i$ satisfy $\varphi$", for every $m \ge 1$, still using only the variables $x_1,\dots,x_k$; $C^k_{\infty\omega}$ additionally allows arbitrary conjunctions and disjunctions. Counting quantifiers add expressive power over a fixed number of variables: $\exists^{\ge 3} x_1\, \top$ uses one variable, but no one-variable first-order sentence separates a three-element set from a two-element set. On finite structures every $C^k$ formula is equivalent to a first-order formula, in general with more variables.
