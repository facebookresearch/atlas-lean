# Satisfying assignments agree with the candidate on defined variables

String terms over an alphabet $\alpha$ with variables $x_0, x_1, \dots$ (indexed by $\mathbb{N}$) are built from constant words, variables, concatenation and letter-to-word morphisms; $\sigma(t)$ denotes the value of a term $t$ under an assignment $\sigma : \mathbb{N} \to \alpha^*$ of words to the variables, and string formulas are positive Boolean combinations (conjunction, disjunction, true, false) of atoms (term equations, regular memberships, length bounds). A closed straight-line system $S$ consists of a finite list of defining terms $t_0, \dots, t_{m-1}$ ($t_k$ defines $x_k$) and a query formula $\varphi$. $S$ is acyclic if every variable $x_j$ occurring in $t_k$ has $j < k$ and every variable $x_j$ occurring in $\varphi$ has $j < m$. An assignment $\sigma$ satisfies $S$ if $\sigma(x_k) = \sigma(t_k)$ for every $k < m$ and $\sigma$ satisfies $\varphi$. The values of $S$ are the folded list of $t_0, \dots, t_{m-1}$ starting from the empty list, and the candidate assignment $\hat\sigma_S$ sends $x_i$ to the $i$-th value, or to the empty word if $i \ge m$. Let $S$ be acyclic and let $\sigma$ satisfy $S$. Then $\sigma(x_k) =
\hat\sigma_S(x_k)$ for every $k < m$.
