# Enumeration of bounded length profiles

For $n, B \in \mathbb{N}$, the enumeration of bounded length profiles is a finite list of maps $\ell :
\{0, \dots, n-1\} \to \mathbb{N}$ that contains each map with values in $\{0, \dots, B\}$ exactly once
(the enumeration of the Cartesian product $\{0, \dots, B\}^n$).
