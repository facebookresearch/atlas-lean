# String term over variables

Let $\alpha$ be an alphabet and $V$ a set of variables. A string term over $\alpha$ with variables in $V$ is one of: a constant word $w \in \alpha^*$; a variable
$x \in V$; the concatenation $t_1 \cdot t_2$ of two terms; or the application $h(t)$ of a letter-to-word
morphism, given by a map $h : \alpha \to \alpha^*$, to a term $t$.
