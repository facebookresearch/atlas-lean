# Boolean checker for atom satisfaction

Let $\alpha$ be an alphabet and $V$ a set of variables. String terms over $\alpha$ with variables in $V$ are built from constant words $w \in \alpha^*$, variables $x \in V$, concatenations $t_1 \cdot t_2$ and morphism applications $h(t)$, where $h$ is a map $\alpha \to \alpha^*$ extended letter by letter to words. The value $\sigma(t)$ of a term $t$ under an assignment $\sigma : V \to \alpha^*$ is defined recursively: a constant word $w$ has value $w$, a variable $x$ has value $\sigma(x)$, $\sigma(t_1 \cdot t_2) = \sigma(t_1)\sigma(t_2)$, and $\sigma(h(t)) = h(a_1) \cdots h(a_k)$ where $\sigma(t) = a_1 \cdots a_k$. An atom is an equation $t_1 = t_2$, a membership $t \in L(e)$ for a regular expression $e$ over $\alpha$, or a length bound $|t| \le k$ or $|t| \ge k$ with $k \in \mathbb{N}$, where $t, t_1, t_2$ are terms. For an assignment $\sigma : V \to \alpha^*$, the Boolean atom checker returns: on $t_1 = t_2$,
true if and only if $\sigma(t_1) = \sigma(t_2)$; on $t \in L(e)$, the answer of the Boolean membership test of
$\sigma(t)$ in the language of $e$; on $|t| \le k$, true if and only if $|\sigma(t)| \le k$; and on
$|t| \ge k$, true if and only if $|\sigma(t)| \ge k$.
