# Formula satisfaction depends only on its variables

Let $\alpha$ be an alphabet and $V$ a set of variables. String terms over $\alpha$ with variables in $V$ are built from constant words $w \in \alpha^*$, variables $x \in V$, concatenations $t_1 \cdot t_2$ and morphism applications $h(t)$, where $h$ is a map $\alpha \to \alpha^*$ extended letter by letter to words. The value $\sigma(t)$ of a term $t$ under an assignment $\sigma : V \to \alpha^*$ is defined recursively: a constant word $w$ has value $w$, a variable $x$ has value $\sigma(x)$, $\sigma(t_1 \cdot t_2) = \sigma(t_1)\sigma(t_2)$, and $\sigma(h(t)) = h(a_1) \cdots h(a_k)$ where $\sigma(t) = a_1 \cdots a_k$. An atom is an equation $t_1 = t_2$, a membership $t \in L(e)$ for a regular expression $e$ over $\alpha$, or a length bound $|t| \le k$ or $|t| \ge k$ with $k \in \mathbb{N}$, where $t, t_1, t_2$ are terms. An assignment $\sigma$ satisfies $t_1 = t_2$ if $\sigma(t_1) = \sigma(t_2)$, satisfies $t \in L(e)$ if $\sigma(t)$ lies in the language of $e$, satisfies $|t| \le k$ if $|\sigma(t)| \le k$, and satisfies $|t| \ge k$ if $|\sigma(t)| \ge k$. Formulas are built from atoms, true and false by conjunction and disjunction (there is no negation). An assignment satisfies an atom formula as above, a conjunction if it satisfies both parts, a disjunction if it satisfies at least one part, always satisfies true and never satisfies false. The variables of a term are those occurring in it: none for a constant word, $x$ for a variable $x$, those of $t_1$ and $t_2$ for $t_1 \cdot t_2$, and those of $t$ for $h(t)$. The variables of an atom are the variables of the terms in it. The variables of a formula are the variables of its atoms. If two assignments $\sigma, \tau : V \to \alpha^*$ agree on every
variable of a formula $\varphi$, then $\sigma$ satisfies $\varphi$ if and only if $\tau$ satisfies $\varphi$.
