# Membership in the bounded assignment enumeration

Let $\alpha$ be a finite alphabet. Let $V$ be a set of variables, $vs$ a finite list of variables, $B \in \mathbb{N}$ and $l$ a finite
list of pairs of a variable and a word over $\alpha$. Then $l$ belongs to the bounded assignment
enumeration for $vs$ and $B$ if and only if the list of first components of $l$ is $vs$ and every second
component of $l$ has length at most $B$.
