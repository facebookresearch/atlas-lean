# Membership in a sum of regular expressions

Let $\alpha$ be an alphabet and $r_1, \dots, r_k$ a finite list of regular expressions over $\alpha$. A word
$w$ over $\alpha$ lies in the language of the sum $r_1 + \dots + r_k$ (the expression for the empty
language when $k = 0$) if and only if $w$ lies in the language of some $r_i$.
