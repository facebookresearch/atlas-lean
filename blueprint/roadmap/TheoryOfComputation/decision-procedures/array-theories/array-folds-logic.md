# Array folds logic

Array folds logic extends the quantifier-free theory of integer arrays with fold terms, which run a small counter program over an array element by element and return the final counter values.

*Array folds logic* (AFL) has sorts for arrays of integers, integers, Booleans, integer vectors of each length $m\ge1$, and *functional constants* of sort $\mathbb Z^m\times\mathbb Z\to\mathbb Z^m$. Array terms are array variables $a$ and writes $a\{T\leftarrow T\}$; integer terms are constants $n\in\mathbb Z$, variables, sums, reads $a[T]$ and lengths $|a|$; Boolean terms are array equalities, comparisons $T=T$ and $T<T$, Boolean combinations and equalities $V^m=V^m$ of vector terms. A vector term is a tuple of $m$ integer terms or a *fold* $\mathsf{fold}_a\,v\,f$, where $f$ is a list of branches (guarded commands) $\mathit{grd}\Rightarrow\mathit{upd}$ over the implicit variables $\mathsf{elem}$ (current element), $\mathsf{idx}$ (current index), counters $\mathsf{cnt}_1,\dots,\mathsf{cnt}_{m-1}$ and a state (control) variable $\mathsf{st}$; every other variable in $f$ is a free integer variable. A guard is a conjunction of atomic guards $\mathsf{elem}\approx T$, $\mathsf{idx}\approx T$, $\mathsf{cnt}_k\approx T$ and $\mathsf{st}\approx n$, with $T$ an integer term in which no implicit variable occurs, $n$ an integer constant and ${\approx}\in\{<,>,=,\ne\}$: the state is compared only to constants, and only the left operand of an atomic guard uses the current element, index, counters or state. The right operand $T$ is an outer term, evaluated in the interpretation and not in the fold (Table 2, rule 7); Definition 2 accordingly replaces each such $T$ by a fresh free variable $x$ and adds $x = T$ at the outermost level of the formula. Guards such as $\mathsf{elem}=\mathsf{idx}$ or $\mathsf{cnt}_1<\mathsf{cnt}_2$ are therefore not AFL guards. An update is a list of atomic updates $\mathsf{cnt}_k \mathrel{+}= n$, $\mathsf{st}\leftarrow n$, $\mathsf{skip}$ and $\mathsf{break}$, with at most one update of each implicit variable in a branch. Guards of the branches are mutually exclusive, and an implicit catch-all branch whose guard holds exactly when no other guard does executes $\mathsf{break}$. The *control-flow graph* of $f$ has as vertices the initial state $0$ and the constants assigned to $\mathsf{st}$, and an edge from $s_1$ to $s_2$ labeled by a branch when $s_1$ satisfies its $\mathsf{st}$-guards and the branch sets $\mathsf{st}$ to $s_2$, or leaves it unchanged with $s_2=s_1$. On the edges inside each strongly connected component of this graph, that is the edges whose two ends are [strongly connected](../../../ComputerScience/graph-algorithms/traversal-and-connectivity/strongly-connected-components/strongly-connected.md), the updates of each counter must be all non-decreasing or all non-increasing (Section 2.1, Table 1).

The fold starts from the vector $v$, whose first component is the initial index and whose other components are the initial counter values, with $\mathsf{st}=0$ (Table 2, rule 2). At each step it evaluates the branches at the current element $a[\mathsf{idx}]$. If $\mathsf{idx}<0$, $\mathsf{idx}\ge|a|$, or the enabled branch (possibly the catch-all) executes $\mathsf{break}$, the fold stops and returns the current index and counter vector, so the other updates of a breaking branch and the index advance do not take effect (rules 3 and 13). Otherwise the updates of the enabled branch are applied together, the components it does not update keep their values, $\mathsf{idx}$ increases by $1$, and the fold continues (rules 3–5). The read $a[i]$ returns the $i$-th element of $a$, and the write $a\{i\leftarrow x\}$ returns $a$ with its $i$-th element replaced by $x$ (Section 2); array equality and the rest of the array semantics are those of the quantifier-free theory of arrays that AFL extends, to which Section 2.2 refers without elaborating. For arrays that are finite sequences, neither passage settles a read or a write at an index outside $0\le i<|a|$, and the choice changes satisfiability: $|a|=0\wedge a[0]=5$ is satisfiable if such a read is unconstrained and unsatisfiable if it returns a fixed value, and $|a|=0\wedge|b|=1\wedge b=a\{0\leftarrow1\}$ is satisfiable exactly when a write at the end extends the array. This page fixes no convention for these cases; the bounds check of a fold applies only inside folds. An interpretation assigns integers to integer variables and finite integer sequences to array variables; free variables are existentially quantified, and *satisfiability* asks for a satisfying interpretation.

## Expansion

Folds express counting properties of arrays, such as that an array holds exactly as many zeros as ones, which are beyond the quantifier-free theory of arrays. Satisfiability of AFL is PSPACE-complete, and NP-complete for $m$-AFL, the formulas with at most $m$ fold expressions per array, for each fixed $m$ (Theorem 1 and Lemma 2 of the source).

The page is held back until reads and writes outside the bounds of an array are settled. A good expansion cites a source that gives a semantics of finite integer arrays fixing both boundary cases, the value of a read and the effect of a write at an index outside $0\le i<|a|$, together with the read-over-write behavior inside the bounds, and states it here. It should not default to reads returning $0$ with out-of-bounds writes ignored, which breaks same-index read-over-write outside the array, nor assume unconditional read-over-write.
