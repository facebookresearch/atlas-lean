# Purification into separate form

Let $\mathcal{T}_1, \dots, \mathcal{T}_n$ be first-order theories with equality whose signatures $\Sigma_1, \dots, \Sigma_n$ share no non-logical symbols, and let $\mathcal{T}$ be the theory over $\Sigma = \bigcup_i \Sigma_i$ generated by their union. A formula is in *simple conjunctive normal form* (sCNF) if it is a conjunction of literals. A $\Sigma$-term is an *$i$-term* if it is a variable or its top symbol belongs to $\Sigma_i$; a variable is an $i$-term for every $i$; a subterm $t$ of an $i$-term is *alien* if it is not a variable, its top symbol belongs to $\Sigma_j$ for some $j \ne i$, and all of its proper super-terms are $i$-terms; an $i$-term or literal is *$i$-pure* if it contains only symbols of $\Sigma_i$ (and variables).

The *separation procedure* turns an sCNF $\Sigma$-formula $\varphi$ into a conjunction $\ddot\varphi = \varphi_1 \wedge \cdots \wedge \varphi_n$ with each $\varphi_i$ an $i$-pure sCNF formula (the empty conjunction when no $i$-symbol occurs):

1. *variable abstraction*: recursively replace each alien predicate argument or alien subterm $t$ by a new variable $z$ and add the equation $z = t$; replace each equation $t_1 = t_2$ in which neither side is a variable by $z = t_1$ and $z = t_2$ for a new variable $z$, purifying $t_1$ and $t_2$ in turn;
2. *partition*: group the resulting literals into blocks of $i$-pure literals, placing equations between variables in any block.

Then $\varphi$ is logically equivalent to $\exists \tilde z\, \ddot\varphi$, where $\tilde z$ are the new variables, and so $\varphi$ is satisfiable if and only if its separate form $\ddot\varphi$ is.
