# Congruence closure decides conjunctions of ground equalities

Let $E$ be a finite set of equations and $D$ a finite set of disequations between ground terms over uninterpreted function symbols, and let $\sim$ be the congruence closure of $E$ on the set of subterms of $E \cup D$. Then $E \cup D$ is satisfiable (in some structure interpreting the function symbols arbitrarily) if and only if there is no disequation $s \ne t$ in $D$ with $s \sim t$.
