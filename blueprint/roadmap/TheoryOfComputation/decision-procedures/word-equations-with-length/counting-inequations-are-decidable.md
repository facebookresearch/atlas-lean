# Word equations with counting inequations are decidable

Whether a word equation with regular constraints has a solution on which an automaton-defined counting function, such as a difference of letter counts, is nonzero is decidable. Thus one can decide whether all solutions satisfy a counting identity, although solving with counting equations is undecidable.

Let $A$ be a finite alphabet, $\Omega = \{X_1, \dots, X_k\}$ a set of variables, $U = V$ a word equation over $(A, \Omega)$, and $R_X \subseteq A^*$ a regular language for each $X \in \Omega$ (rational constraints). A solution is a map $\sigma : \Omega \to A^*$ (empty words allowed) with $\sigma(U) = \sigma(V)$ and $\sigma(X) \in R_X$ for every $X$. Encode it as $\mathrm{enc}(\sigma) = \sigma(X_1) \# \cdots \# \sigma(X_k)$ over $\Sigma = A \cup \{\#\}$ with a fresh letter $\#$.

A *counting transducer* is a finite automaton, given by finitely many states, an initial state, final states and finitely many transitions, whose transitions are labelled by pairs $(w, \mathbf v) \in \Sigma^* \times \mathbb Z^n$; it defines the relation of pairs $(w_1 \cdots w_m, \mathbf v_1 + \cdots + \mathbf v_m)$ read along accepting runs. A function $f : \Sigma^* \to \mathbb Z^n$, defined on all of $\Sigma^*$, is a *counting function* if its graph is the relation of a counting transducer (which is then functional). Examples are $\mathrm{enc}(\sigma) \mapsto |\sigma(X)|_a$, $\mathrm{enc}(\sigma) \mapsto |\sigma(X)|$, the number of positions satisfying a fixed monadic second-order property, and integer linear combinations of counting functions.

The problem *word equations with rational constraints and counting inequations*, given $U = V$, the constraints $R_X$ and a counting function $f$, asks whether some solution $\sigma$ satisfies $f(\mathrm{enc}(\sigma)) \ne \mathbf 0$, that is, some coordinate of the vector is nonzero. This problem is decidable. It is a single vector-valued counting function tested for being nonzero; this is not a decision procedure for conjunctions of disequalities, for ordered inequalities, or for the existence of a solution with $f(\mathrm{enc}(\sigma)) = \mathbf 0$. For example, it is decidable whether a word equation with rational constraints has a solution with $|\sigma(X_1)|_a \ne |\sigma(X_2)|_a$, or one with $|\sigma(X_1)| \ne |\sigma(X_2)|$.

## Expansion

The language $L = \{\mathrm{enc}(\sigma) : \sigma \text{ a solution}\}$ is an EDT0L language (Ciobanu, Diekert and Elder), hence an indexed language, and an indexed grammar for it can be computed. From the counting transducer for $f$ build a finite-state transducer $R_f$ that outputs, for input $u$, words $v$ over $\{a_1, \bar a_1, \dots, a_n, \bar a_n\}$ with $f(u) = (|v|_{a_1} - |v|_{\bar a_1}, \dots, |v|_{a_n} - |v|_{\bar a_n})$; indexed languages are effectively closed under rational transductions. The instance is negative exactly when the Parikh image of $R_f L$ lies in $S = \{\mathbf z : \mathbf z(a_i) = \mathbf z(\bar a_i) \text{ for all } i\}$. A *slice* is a set $S \subseteq \mathbb N^m$ such that, for all $\mathbf u, \mathbf v, \mathbf w \in \mathbb N^m$, $\mathbf u, \mathbf u + \mathbf v, \mathbf u + \mathbf w \in S$ implies $\mathbf u + \mathbf v + \mathbf w \in S$; the set $S$ above is a slice (solution set of a homogeneous linear system), so the Parikh image is contained in $S$ exactly when its slice closure is. The main theorem of the source computes a semilinear representation of the slice closure of the Parikh image of any indexed language, by a saturation procedure that terminates because ascending chains of slices stabilise (Eilenberg and Schützenberger: every slice is semilinear). Inclusion of a semilinear set in $S$ is decidable. Three ingredients have no page here: the effective EDT0L description of solution sets of word equations *with rational constraints*, the effective inclusion of EDT0L languages in indexed languages together with the effective closure of indexed languages under rational transductions, and the slice-closure algorithm for indexed languages. Counting *equations* $f(\mathrm{enc}(\sigma)) = \mathbf 0$ are undecidable in general (Büchi and Senger), and length equations are open.
