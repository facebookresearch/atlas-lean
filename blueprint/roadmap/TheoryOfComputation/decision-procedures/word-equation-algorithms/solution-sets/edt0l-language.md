# EDT0L language

An EDT0L language is the set of words $\varphi(\#)$ obtained by applying to one start letter $\#$ the endomorphisms of a rational set of endomorphisms of an extended free monoid, where the rational set is required to produce only words over the terminal alphabet.

Let $A$ be a finite alphabet. A set $L \subseteq A^*$ is an EDT0L language if there are a finite alphabet $C \supseteq A$, a finite set $H$ of monoid endomorphisms of $C^*$, a rational subset $R$ of the submonoid of $\mathrm{End}(C^*)$ generated by $H$, and a letter $\# \in C$ such that

$$
\varphi(\#) \in A^* \ \text{ for every } \varphi \in R \quad \text{and} \quad L = \{ \varphi(\#) : \varphi \in R \} .
$$

Here $\mathrm{End}(C^*)$ is a monoid under composition, and a subset $R$ is rational if it is accepted by a nondeterministic finite automaton over this monoid: a finite set of states with initial and final states and finitely many transitions labelled by elements of $H$, where a path labelled $h_1, h_2, \dots, h_m$ (in this order) contributes the composite $h_1 \circ h_2 \circ \cdots \circ h_m$, so $h_m$ is applied first, the empty path contributes the identity, and $R$ is the set of contributions of paths from an initial to a final state. The letter $\#$ is the start letter; it may also occur in the words of $A$ when $\# \in A$. The endomorphisms need not fix the letters of $A$.

For a monoid $M$ generated by a finite set $A$, with canonical morphism $\pi : A^* \to M$, a set $L \subseteq M$ is EDT0L if $L = \{ \pi(\varphi(\#)) : \varphi \in R \}$ for $C$, $\#$ and a rational set $R$ of endomorphisms of $C^*$ that fix every letter of $A$, with $\varphi(\#) \in A^*$ for all $\varphi \in R$; for monoids with involution, $C$ carries an involution and the endomorphisms respect it.

## Expansion

The acronym stands for extended, deterministic, table, 0-interaction Lindenmayer system: each transition label is a table rewriting each letter by one word (deterministic), independently of its context (0-interaction), and the automaton controls which table is applied next. The characterisation of EDT0L languages by rational control of endomorphisms is due to P. R. J. Asveld (Information and Control 34 (1977)), and both sources take it as the definition: the first form is that of Ciobanu, Diekert and Elder for free monoids; the second, with endomorphisms fixing $A$, is that of Diekert, Jeż, Kufleitner and Thumm for monoids. For example, with $A = \{a, b\}$, $C = \{a, b, \#, s\}$ and the endomorphisms $f(\#) = ss$, $g_a(s) = sa$, $g_b(s) = sb$ and $h(s) = \varepsilon$, identical on the other letters, the rational set $h \{g_a, g_b\}^* f$ yields $\{vv : v \in A^*\}$, which is not context-free. The second source notes that every rational subset of $M$ is EDT0L.
