# Chen–Lu–Oliveira–Ren–Santhanam: Chen–Tell hitting sets with a Shaltiel–Umans core are printable in time poly(T)

Fix constants $\kappa,\rho\in\mathbb{N}$. There is a universal constant $c$ such that the following holds for all sufficiently large $n,T,d,M$ with $n\le T$, $d\le T$ and $c\log T\le M\le T^{1/(c\rho)}$. Let $f(1^n)\in\{0,1\}^n$ be the output of a circuit $C_{\mathrm{TM}}$ of size $T$ and depth at most $d$ that is generated by a Turing machine $\mathrm{TM}$ of description length $\kappa\log T$. A deterministic algorithm, given $\mathrm{TM}$, prints in time $T^{c\kappa}$ a list $H\subseteq\{0,1\}^M$, and a probabilistic oracle algorithm $R$ runs in time $(d+n)\cdot M^{c\rho}$ such that for every oracle $D:\{0,1\}^M\to\{0,1\}$, $R^D$ outputs $f(1^n)$ or $\bot$ with probability at least $1-2^{-M}$, and if $D$ accepts at least a $1/M^{\rho}$ fraction of $\{0,1\}^M$ but no element of $H$, then $R^D$ outputs $f(1^n)$ with probability at least $1-2^{-M}$. Moreover $H$ is itself the output of a circuit of size $T^{c\kappa}$ and depth $c(d\log T+\kappa^2\log^2T)+M^c$ generated by a Turing machine of description length $O(\kappa\log T)$, computable from $\mathrm{TM}$ in polynomial time, so the lemma can be applied again to the function that scans $H$.

## Proof sketch

Starting from the Chen–Tell layered-polynomial representation of the computation of $f$, the Nisan–Wigderson generator, which costs $2^{\Theta(\log^2T/\log M)}$, is replaced by a variant of the Shaltiel–Umans generator with polynomial construction time. That generator lacks the uniform learning reconstruction the framework needs; this is sidestepped by a further win-win analysis, and the circuit uniformity of the new generator is tracked so that it can be fed back as the next function $f$.
