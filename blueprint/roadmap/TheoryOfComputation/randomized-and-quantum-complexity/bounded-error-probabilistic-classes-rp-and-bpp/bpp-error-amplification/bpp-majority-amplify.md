# Majority-vote error amplification

Let $n$ independent votes each be true with the same probability $p \ge 2/3$. Then the probability that the [majority vote](../../../complexity-classes/time-and-space-complexity-classes/majority-dec.md) is false, that is, that at most $n/2$ votes are true (ties count as false), is at most $e^{-n/18}$.
