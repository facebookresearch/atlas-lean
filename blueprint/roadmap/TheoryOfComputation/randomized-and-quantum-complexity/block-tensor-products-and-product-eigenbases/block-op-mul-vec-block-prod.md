# A block operator acts blockwise on a product state

For $k$ complex $2^m \times 2^m$ matrices $A_i$ and vectors $\psi_i \in \mathbb{C}^{2^m}$, the block operator $A_0 \otimes \dots \otimes A_{k-1}$, whose entry at global indices $s, t$ is $\prod_i A_i(s_i, t_i)$ with $s_i, t_i$ the block digits, maps the product state $\psi_0 \otimes \dots \otimes \psi_{k-1}$ to the product state $A_0 \psi_0 \otimes \dots \otimes A_{k-1} \psi_{k-1}$.
