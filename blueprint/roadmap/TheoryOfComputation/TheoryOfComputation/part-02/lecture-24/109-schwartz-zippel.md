# Theorem (Schwartz-Zippel)

If $p(x_1, \ldots, x_m) \neq 0$ has degree $\leq d$ in each $x_i$ and we pick random $r_1, \ldots, r_m \in \mathbb{F}_q$ then $\Pr[p(r_1, \ldots, r_m) = 0] \leq \frac{dm}{q}$.
