# Amplification lemma

If $M_1$ is a poly-time PTM with error $\epsilon_1 < 1/2$ then, for any $0 < \epsilon_2 < 1/2$, there is an equivalent poly-time PTM $M_2$ with error $\epsilon_2$. Can strengthen to make $\epsilon_2 < 2^{-\mathrm{poly}(n)}$.
