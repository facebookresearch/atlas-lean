# Claim (Formula Game and TQBF)

Player $\exists$ has a forced win in the formula game on $\phi$ iff $\phi$ is TRUE. Therefore $\{\langle \phi \rangle \mid \text{Player } \exists \text{ has a forced win on } \phi\} = \mathrm{TQBF}$.
