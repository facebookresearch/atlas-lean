# Definition (Finite Automaton)

A finite automaton $M$ is a 5-tuple $(Q, \Sigma, \delta, q_0, F)$ where $Q$ is a finite set of states, $\Sigma$ is a finite set of alphabet symbols, $\delta \colon Q \times \Sigma \to Q$ is the transition function, $q_0$ is the start state, and $F$ is the set of accept states.
