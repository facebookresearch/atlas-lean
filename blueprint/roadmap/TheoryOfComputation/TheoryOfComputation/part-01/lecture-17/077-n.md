# Theorem (LADDER_DFA ∈ SPACE(n²))

$\mathrm{LADDER}_{\mathrm{DFA}} \in \mathsf{SPACE}(n^2)$. Write $u \to^b v$ if there is a ladder from $u$ to $v$ of length $\leq b$. A recursive procedure solves the bounded DFA ladder problem $\mathrm{BOUNDED\text{-}LADDER}_{\mathrm{DFA}} = \{\langle B, u, v, b \rangle \mid B \text{ a DFA and } u \to^b v \text{ by a ladder in } L(B)\}$. Each recursive level uses space $O(n)$ (to record $w$). Recursion depth is $\log t = O(m) = O(n)$. Total space used is $O(n^2)$.
