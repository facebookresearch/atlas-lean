# Definition (k-clique and CLIQUE)

A $k$-clique in a graph is a subset of $k$ nodes all directly connected by edges. $\mathrm{CLIQUE} = \{\langle G, k \rangle \mid \text{graph } G \text{ contains a } k\text{-clique}\}$.
