# Definition (Lecture 20, NL = coNL (part 1/4))

NTM $M$ computes function $f \colon \Sigma^* \to \Sigma^*$ if for all $w$: (1) All branches of $M$ on $w$ halt with $f(w)$ on the tape or reject. (2) Some branch of $M$ on $w$ does not reject.
