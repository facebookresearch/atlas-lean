# A URM-recognizable predicate is recursively enumerable

A predicate $P$ on $\mathbb{N}$ is URM-decidable if some program of an unlimited register machine
computes its characteristic function (value $1$ on members and $0$ elsewhere), and URM-recognizable
if some program halts on input $n$ exactly when $P(n)$ holds.
Every URM-recognizable predicate on $\mathbb{N}$ is recursively enumerable.
