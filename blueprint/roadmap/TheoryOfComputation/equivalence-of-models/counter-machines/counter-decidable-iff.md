# Counter-machine decidability by bounded runs

A predicate $P$ on the natural numbers is counter-machine decidable if and only if there is a single counter-machine program that, on every input $n$ placed in register $0$, halts after finitely many steps $t$ (its program counter is at or past the end of the program) with $1$ in register $0$ if $P(n)$ holds and $0$ otherwise.

## Sources

- Minsky, *Computation: Finite and Infinite Machines*, 1967, §11.
