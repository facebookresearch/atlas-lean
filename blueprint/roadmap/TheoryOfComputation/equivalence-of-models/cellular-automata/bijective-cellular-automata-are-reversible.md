# Bijective cellular automata are reversible

A [cellular automaton](cellular-automata-on-z-d.md) $G$ on $\mathbb{Z}^d$ is reversible if and only if its global transition
function is a bijection. If $G$ is bijective, its inverse commutes with the shifts and is continuous because the
configuration space is compact, so by the Curtis–Hedlund–Lyndon theorem it is the global transition function of a cellular
automaton.
