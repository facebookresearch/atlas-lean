# Injectivity and surjectivity on finite and periodic configurations

Let $G$ be a $d$-dimensional [cellular automaton](cellular-automata-on-z-d.md) with a quiescent state, and let $G_F$ and
$G_P$ be its restrictions to [finite and periodic configurations](finite-periodic-and-garden-of-eden-configurations.md). In
every dimension $d$:

- if $G$ is injective, then $G_P$ and $G_F$ are injective;
- if $G_P$ or $G_F$ is surjective, then $G$ is surjective;
- if $G_P$ is injective, then $G_P$ is surjective;
- if $G$ is injective, then $G_F$ is surjective.

For one-dimensional cellular automata moreover:

- if $G_P$ is injective, then $G$ is injective;
- if $G$ is surjective, then $G_P$ is surjective.
