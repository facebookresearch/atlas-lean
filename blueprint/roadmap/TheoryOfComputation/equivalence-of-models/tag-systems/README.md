# Tag systems

Tag systems read the first symbol of a word, delete a fixed number of symbols from the front and append a word determined by the
symbol read; cyclic tag systems use a fixed cyclic list of appendants over a two-letter alphabet. Both emulate Turing machines, and
cyclic tag systems are the intermediate model in the proof that the [elementary cellular automaton rule 110](../cellular-automata/rule-110-is-computationally-universal.md)
is universal.
