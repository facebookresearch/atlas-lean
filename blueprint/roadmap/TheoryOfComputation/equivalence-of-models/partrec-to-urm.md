# Every partial recursive function is URM-computable

The following holds: for every partial recursive function $f : \mathbb{N} \rightharpoonup \mathbb{N}$, the function of one input $n \mapsto f(n)$ is computable by an unlimited register machine (URM), that is, some URM program with one input register computes $f$, including its domain of definition.

## Sources

- R. I. Soare, *Recursively Enumerable Sets and Degrees*, Ch. I, Theorem 2.3.
- J. C. Shepherdson and H. E. Sturgis, "Computability of recursive functions", *Journal of the ACM* 10 (1963), 217–255.
