# Le Gall–Urrutia bound on the dual exponent

For every field $F$, the dual matrix
multiplication exponent $\alpha(F)$ of the arithmetic-circuit model satisfies
$\alpha(F) \ge 0.31389$.

## Sources

- F. Le Gall and F. Urrutia, "Improved rectangular matrix multiplication using powers of the Coppersmith–Winograd tensor", *Proceedings of the Twenty-Ninth Annual ACM-SIAM Symposium on Discrete Algorithms (SODA 2018)*, 1029–1046; arXiv:1708.05622. Section 1.2, the bound $\alpha \ge 0.31389$.
- Optimization Constants in Mathematics, constant $C_{15b}$ (the dual matrix multiplication exponent $\alpha$), https://github.com/teorth/optimizationproblems/blob/87b4ebbd426ff8db597a2004cc45da17903bdcf2/constants/15b.md.
