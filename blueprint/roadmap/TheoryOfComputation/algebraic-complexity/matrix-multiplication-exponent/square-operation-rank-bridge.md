# Circuit size and tensor rank give the same square exponent

For every infinite field $F$, the square matrix multiplication exponent of $F$ defined by
arithmetic-circuit size (circuits that compute the matrix product on all inputs from $F$) equals the
matrix multiplication exponent of $F$ defined by tensor rank.

## Sources

- M. Bläser, "Fast matrix multiplication", *Theory of Computing Graduate Surveys* 5 (2013), 1–60, Section 2 and Theorem 5.2 (over infinite fields).
- Optimization Constants in Mathematics, constant $C_{15a}$ (the matrix multiplication exponent $\omega$), https://github.com/teorth/optimizationproblems/blob/87b4ebbd426ff8db597a2004cc45da17903bdcf2/constants/15a.md.
