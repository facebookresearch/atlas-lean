# Coppersmith–Winograd 1990 bound on the square exponent

For every field $F$, the square
matrix multiplication exponent $\omega(F)$ of the arithmetic-circuit model satisfies
$\omega(F) \le 2.375477$.

## Sources

- D. Coppersmith and S. Winograd, "Matrix multiplication via arithmetic progressions", *Journal of Symbolic Computation* 9 (1990), 251–280.
- Optimization Constants in Mathematics, constant $C_{15a}$ (the matrix multiplication exponent $\omega$), https://github.com/teorth/optimizationproblems/blob/87b4ebbd426ff8db597a2004cc45da17903bdcf2/constants/15a.md.
