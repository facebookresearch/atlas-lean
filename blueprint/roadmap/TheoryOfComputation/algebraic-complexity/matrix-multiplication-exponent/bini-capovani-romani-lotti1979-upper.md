# Bini–Capovani–Romani–Lotti bound on the square exponent

For every field $F$, the square
matrix multiplication exponent $\omega(F)$ of the arithmetic-circuit model satisfies
$\omega(F) \le 3 \log_{12} 10$.

## Sources

- D. Bini, M. Capovani, F. Romani and G. Lotti, "$O(n^{2.7799})$ complexity for $n \times n$ approximate matrix multiplication", *Information Processing Letters* 8 (1979), 234–235.
- D. Bini, "Relations between exact and approximate bilinear algorithms. Applications", *Calcolo* 17 (1980), 87–97.
