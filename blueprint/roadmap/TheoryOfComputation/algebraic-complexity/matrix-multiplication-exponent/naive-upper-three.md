# Naive bound for square matrix multiplication

For every field $F$, the square matrix
multiplication exponent $\omega(F)$ of the arithmetic-circuit model satisfies $\omega(F) \le 3$.

## Sources

- Optimization Constants in Mathematics, constant $C_{15a}$ (the matrix multiplication exponent $\omega$), https://github.com/teorth/optimizationproblems/blob/87b4ebbd426ff8db597a2004cc45da17903bdcf2/constants/15a.md. The bound $3$ is the trivial one, from the definition of the matrix product.
