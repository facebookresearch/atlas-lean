# Le Gall's 2014 bound on the square exponent

For every field $F$, the square matrix
multiplication exponent $\omega(F)$ of the arithmetic-circuit model satisfies
$\omega(F) \le 2.3728639$.

## Sources

- F. Le Gall, "Powers of tensors and fast matrix multiplication", *Proceedings of the 39th International Symposium on Symbolic and Algebraic Computation (ISSAC 2014)*, 296–303.
- Optimization Constants in Mathematics, constant $C_{15a}$ (the matrix multiplication exponent $\omega$), https://github.com/teorth/optimizationproblems/blob/87b4ebbd426ff8db597a2004cc45da17903bdcf2/constants/15a.md.
