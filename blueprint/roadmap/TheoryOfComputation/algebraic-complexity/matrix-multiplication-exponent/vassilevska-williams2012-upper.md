# Vassilevska Williams's 2012 bound on the matrix multiplication exponent

For every
field $F$, the square matrix multiplication exponent $\omega(F)$ of the arithmetic-circuit model
satisfies $\omega(F) \le 2.372873$.

## Sources

- V. Vassilevska Williams, "Multiplying matrices faster than Coppersmith–Winograd", *Proceedings of the 44th Annual ACM Symposium on Theory of Computing (STOC 2012)*, 887–898.
- V. Vassilevska Williams, "Multiplying matrices in $O(n^{2.373})$ time", unpublished note, 2014, https://theory.stanford.edu/~virgi/matrixmult-f.pdf.
- Optimization Constants in Mathematics, constant $C_{15a}$ (the matrix multiplication exponent $\omega$), https://github.com/teorth/optimizationproblems/blob/87b4ebbd426ff8db597a2004cc45da17903bdcf2/constants/15a.md.
