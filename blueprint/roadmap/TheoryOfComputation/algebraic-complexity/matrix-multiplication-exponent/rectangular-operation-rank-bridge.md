# Circuit size and tensor rank give the same rectangular exponent

For every infinite field $F$ and every real $k \ge 0$, the rectangular matrix multiplication exponent
of $F$ at aspect $k$ defined by arithmetic-circuit size (circuits that compute the matrix product on
all inputs from $F$) equals the one defined by tensor rank.

## Sources

- F. Le Gall, "Faster algorithms for rectangular matrix multiplication", *2012 IEEE 53rd Annual Symposium on Foundations of Computer Science (FOCS 2012)*, 514–523; arXiv:1204.1111.
