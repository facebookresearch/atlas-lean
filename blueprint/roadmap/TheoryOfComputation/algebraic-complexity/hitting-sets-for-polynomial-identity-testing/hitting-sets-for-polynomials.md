# Hitting sets for classes of polynomials

Let $\mathcal{C}$ be a class of polynomials in $K[x_1,\dots,x_n]$. A finite set $H\subseteq K^n$ is a *hitting set* for $\mathcal{C}$ if every nonzero $f\in\mathcal{C}$ satisfies $f(a)\ne0$ for some $a\in H$. A hitting set yields a deterministic black-box polynomial identity test for $\mathcal{C}$ that evaluates the input at the $|H|$ points.
