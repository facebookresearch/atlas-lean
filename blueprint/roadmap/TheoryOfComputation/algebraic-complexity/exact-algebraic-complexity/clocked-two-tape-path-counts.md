# Clocked two-tape path counts

The input is the whole length-$n$ bit word $x$, not just a suffix. Read an initial unary field $1^t0$, then take exactly $t$ bits as the program table; the remaining payload is unrestricted. A missing unary terminator or truncated table fails. An empty table encodes the program with no running states. Otherwise read the entire table as unary fields $1^u0$: its first field is $e-1$, where $e\ge1$ is the number of running states, and the rest must give exactly $9e$ rows with no unused fields. Order the rows first by running state $2,\ldots,e+1$, then by the symbols scanned on the first and second tapes. Both tapes have symbol codes $0,1,2$ for blank, binary zero and binary one, respectively. A row starts with a field in $\{0,1,2\}$ giving the number of transition slots, followed by that many records. Each record consists of target state in $[e+2]$, symbol to write on tape one, move of head one, symbol to write on tape two, and move of head two. Symbol and move fields must be in $\{0,1,2\}$; move codes mean stay, left, right. Any malformed field or missing or surplus row data fails decoding.

Both heads start at position zero on two-way tapes. The first tape holds the entire input from cell zero, with blanks elsewhere, and the second tape is blank. With no running states the machine starts halted in state $1$; otherwise it starts in state $2$. States $0$ and $1$ halt with rejection and acceptance respectively. At a running state with fuel remaining, an empty row gives no accepting leaf, and each transition slot gives one branch: write both symbols, move both heads and enter the target state, spending one unit of fuel. Equal records in two slots count as two branches. A halt at time zero or at the final allowed transition is included when accepting; a halted branch is counted once. A running branch that exhausts fuel and a rejecting branch contribute zero.

The **unsigned** coefficient $U_n(x)$ counts accepting leaves within $n^{10^9}$ transitions. The **signed** coefficient $U_n^\star(x)$ instead uses $n^{100}$ transitions. Each accepting leaf contributes $-1$ if the work-tape head there reads binary one (symbol code $2$), and $+1$ otherwise, after the transition's writes and moves. Rejecting, stuck or timed-out branches contribute zero in both versions, as does a malformed input. In particular, a word starting with a zero bit decodes the empty program, which contributes $1$ in both versions; the empty word itself has no unary terminator and contributes zero.

## Expansion

Implement the prefix decoder, initial configuration, fuel-bounded transition tree and terminal weights together. Test truncation, empty programs, duplicate branch records, the clock boundary and the post-move work symbol. The unsigned and signed clocks are different, even though the transition table is shared.
