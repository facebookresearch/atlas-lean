# Valiant's class VP

$\mathsf{VP}_K$ is the class of p-families $f$ over $K$ whose circuit size $L(f_n)$ is bounded by a polynomial in $n$. The class is nonuniform (no relation between different $n$ is required) and is closed under p-projections.
