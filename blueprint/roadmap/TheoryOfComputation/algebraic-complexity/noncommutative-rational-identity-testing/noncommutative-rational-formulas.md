# Noncommutative rational formulas and their matrix evaluations

A *noncommutative rational formula* is a formula over rational constants, addition, ordered multiplication and inversion. It is evaluated at a substitution of the variables by square matrices over a field containing $\mathbb{Q}$ (of any common positive dimension); evaluation is partial, since an inverse node is defined only if its argument's value is invertible. A formula is *admissible* if some matrix substitution lies in its domain, and *nonzero* if it has a defined nonzero value at some matrix substitution.
