# Gödel numbers of arithmetic function symbols

The function symbols of the language of arithmetic are numbered by

$$\ulcorner 0 \urcorner = 0, \qquad \ulcorner S \urcorner = 1, \qquad \ulcorner + \urcorner = 2, \qquad \ulcorner \times \urcorner = 3,$$

where $0$ is the constant, $S$ the unary successor, and $+$, $\times$ the binary addition and multiplication symbols.
