# Slender languages

A language is $k$-slender if it has at most $k$ words of each length, and slender if it is $k$-slender for some $k$.

**Definition.** For a language $L \subseteq \Sigma^*$ let $f_L(n)$ be the number of words of length $n$ in $L$. For $k \ge 1$, $L$ is *$k$-slender* if $f_L(n) \le k$ for all $n \ge 0$; it is *thin* if it is $1$-slender, and *slender* if it is $k$-slender for some $k$. A language is *letter-bounded* if it is a subset of $a_1^* \cdots a_r^*$ for some letters $a_1, \dots, a_r$.
