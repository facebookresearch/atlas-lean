# Multi-tape automata

Multi-tape automata read several infinite words in parallel, consuming nonempty words of possibly different lengths on each tape.
Whether a state accepts every configuration, and whether it has a universal prefix, are undecidable already for two tapes and three
states; through graph-directed iterated function systems these give undecidable topological properties of self-affine sets.
