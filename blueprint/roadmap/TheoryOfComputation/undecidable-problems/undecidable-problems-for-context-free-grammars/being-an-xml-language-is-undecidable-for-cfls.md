# Whether a context-free language is an XML-language is undecidable

No algorithm decides whether a given context-free language is generated by an XML-grammar, the grammars that model document type definitions; likewise, regularity of the surfaces of a context-free subset of the Dyck primes is undecidable.

**XML-grammars.** Let $A$ be a finite set of opening tags and $\bar A$ the corresponding closing tags. An *XML-grammar* has terminal alphabet $A \cup \bar A$, one variable $X_a$ for each $a \in A$, one of them the axiom, and for each $a \in A$ a regular set $R_a$ of words over the variables giving the productions $X_a \to a\, m\, \bar a$ for all $m \in R_a$. An *XML-language* is a language generated by an XML-grammar; every XML-language is a deterministic context-free language of Dyck primes.

**Surfaces.** Let $D_a$ be the set of Dyck primes over $A \cup \bar A$ that begin with $a$. Every $w \in D_a$ factors uniquely as $w = a\, u_1 \cdots u_n\, \bar a$ with $u_i \in D_{a_i}$; its *trace* is $a_1 \cdots a_n \in A^*$. For a set $L$ of Dyck primes, $F_a(L)$ is the set of factors of words of $L$ that lie in $D_a$, and the *surface* $S_a(L)$ of $a$ in $L$ is the set of traces of the words of $F_a(L)$. The surfaces of an XML-language are regular.

**Theorem (Berstel and Boasson).** It is undecidable whether a context-free language is an XML-language. Moreover, given a context-free subset of the Dyck primes, it is undecidable whether its surfaces are regular.

In contrast, it is decidable whether the language of a context-free grammar is well formed (a set of Dyck primes), whether the surfaces of a context-free grammar are finite, and whether a given regular language is an XML-language.

## Expansion

For an instance $U = (u_1, \dots, u_n)$, $V = (v_1, \dots, v_n)$ of the Post correspondence problem over $C = \{a, b\}$ and new letters $B = \{a_1, \dots, a_n\}$, the languages $L_U = \{ a_{i_1} \cdots a_{i_k} h : h \ne u_{i_k} \cdots u_{i_1} \}$ and $L_V$ (defined likewise) are context-free, and $L_U \cup L_V$ is regular if and only if it equals $B^* C^*$, which holds if and only if the instance has no solution. Coding each letter $d$ as $d \bar d$ and wrapping the result in a new tag $c$ gives a context-free language $\hat L$ of Dyck primes whose surface at $c$ is $L_U \cup L_V$, so $\hat L$ is an XML-language, and its surfaces are regular, exactly when the instance has no solution. The step from regular surfaces to being an XML-language uses the source's characterization of XML-languages (Theorem 4.4 of the version read: a language is an XML-language exactly when it lies in some $D_\alpha$, its factors in each $D_a$ have equal contexts, and all its surfaces are regular), which has no page here.
