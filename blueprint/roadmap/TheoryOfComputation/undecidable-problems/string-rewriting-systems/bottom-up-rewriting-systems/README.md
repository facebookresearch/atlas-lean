# Bottom-up rewriting systems

Rewriting systems whose derivations can be reorganized to proceed bottom-up preserve regularity under inverse rewriting, but membership in $\mathrm{BU}(k)$, for each fixed $k \ge 1$, is undecidable already for length-increasing semi-Thue systems.
