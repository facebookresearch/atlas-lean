# Decipherability of directed figure codes

Directed figures are finite labeled subsets of the grid with start and end points; whether a finite set of them is a uniquely, multiset, set or numerically decipherable code is undecidable when the translation vectors do not all lie in an open half-plane bounded by a line through the origin, and decidable in the one-sided case.
