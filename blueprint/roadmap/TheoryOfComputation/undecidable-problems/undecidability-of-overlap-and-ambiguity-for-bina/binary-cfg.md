# Converting a grammar to the binary alphabet

An encoded context-free grammar over a terminal alphabet $T$ consists of a start nonterminal, a natural number, and a list of productions, each a nonterminal number with a right-hand side listing nonterminal numbers and terminals of $T$. Its language is the set of terminal words derivable from the start nonterminal. A grammar is ambiguous when some terminal word has two leftmost derivations from the start symbol using different lists of rules. The index of the source alphabet, the disjoint union of the two Booleans and the natural numbers, is the numbering that sends false to $0$, true to $1$ and a natural number $n$ to $n + 2$. The unary code of a letter with index $i$ is the binary word $1^i 0$ (true repeated $i$ times, then false); the unary word map sends a word to the concatenation of the unary codes of its letters. The binary conversion of an encoded grammar over the source alphabet replaces each terminal in every production by its unary code, giving an encoded grammar over the Booleans. Nonterminals and the start symbol are unchanged.
