# Halting problems for abelian sandpiles

An abelian sandpile on $\mathbb{Z}^3$ that starts from a periodic configuration with finitely many chips added can simulate a Turing machine, so whether the origin ever topples, whether it topples infinitely often, and whether the process makes infinitely many topplings are all undecidable.
