# The matrix-exponential problem is undecidable

No algorithm decides, given real algebraic square matrices $A_1,\dots,A_k,C$, whether $\exp(A_1t_1)\cdots\exp(A_kt_k)=C$ has a solution in nonnegative reals; the problem is decidable when the $A_i$ commute.

**Theorem.** The [matrix-exponential problem](the-matrix-exponential-problem.md) is undecidable in the non-commutative case: there is no algorithm that, given square matrices $A_1,\dots,A_k,C$ of the same dimension with real algebraic entries, decides whether there are reals $t_1,\dots,t_k\ge0$ with $\exp(A_1t_1)\cdots\exp(A_kt_k)=C$.

The undecidability holds for the basic version of the problem (real matrices, nonnegative real times); the number and dimension of the matrices are part of the input. The source announces, without proof, that membership of $C$ in the semigroup generated by $\{\exp(A_it):t\ge0\}$ is undecidable as well.

## Expansion

The reduction is from Hilbert's tenth problem, through MEP with additional constraints on the times: constraints $t_i\in\alpha+\beta\pi\mathbb Z$, linear equations with algebraic coefficients, and products $t_\ell=t_it_j$. Each class of constraints is simulated by block matrices that are added to the instance (rotation blocks force times into $\alpha+\beta\pi\mathbb Z$; unipotent blocks express linear and multiplicative relations), so MEP with all three classes reduces to plain MEP. Given $P\in\mathbb Z[x_1,\dots,x_k]$ of degree $d$, homogenize it to $Q(\mathbf x,\lambda)=\lambda^dP(\mathbf x/\lambda)$, and impose $t_0=Q(t_1,\dots,t_k,\lambda)=0$, $t_1,\dots,t_k,\lambda\in\pi\mathbb Z$ and $1\le\lambda\le4$ (via $\lambda=1+\alpha^2=4-\beta^2$). Then $\lambda=\pi$, $t_i=\pi n_i$, and the constraints are satisfiable iff $\pi^dP(n_1,\dots,n_k)=0$ for some $n_i\in\mathbb N$.
