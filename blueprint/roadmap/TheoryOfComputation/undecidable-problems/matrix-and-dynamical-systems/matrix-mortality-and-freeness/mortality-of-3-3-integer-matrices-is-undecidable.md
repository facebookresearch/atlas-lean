# Mortality of 3 × 3 integer matrices is undecidable

No algorithm decides, for a given finite set of $3 \times 3$ integer matrices, whether some product of matrices from the set
equals the zero matrix.

Precisely: the [mortality problem](the-matrix-mortality-problem.md) for $d = 3$ is undecidable. The instances are finite sets
$E \subseteq \mathbb{Z}^{3 \times 3}$ of arbitrary cardinality, and the question is whether the semigroup generated by $E$
contains the zero matrix.

The number of matrices in the set is part of the input here. Bounds with a fixed number of matrices are in
[mortality for six 3 × 3 or two 18 × 18 integer matrices](mortality-is-undecidable-for-six-3-3-or-two-18-1.md). For $2 \times 2$
integer matrices the decidability of mortality was open when the source below was written.

## Expansion

The proof reduces the Post correspondence problem. A direct product of two free monoids has a faithful representation in the
multiplicative semigroup $\mathbb{N}^{3 \times 3}$, so a pair of words can be stored in one $3 \times 3$ matrix in such a way
that products of matrices concatenate the stored words componentwise. Paterson (1970), as recalled by the source, builds from an instance of the Post
correspondence problem a finite set of $3 \times 3$ integer matrices that generates the zero matrix exactly when the instance
has a solution.
