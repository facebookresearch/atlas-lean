# The identity correspondence problem is undecidable

No algorithm decides whether some nonempty product of pairs of free-group words, chosen from a given finite set, reduces to the identity in
both components; consequently the identity problem for semigroups of 4×4 integer matrices is undecidable.

Let $F(\{a, b\})$ be the free group on $a, b$, whose elements are the reduced words over $a, b, a^{-1}, b^{-1}$, with identity $\varepsilon$. Given pairs $\Pi = \{(s_1, t_1), \dots, (s_m, t_m)\} \subseteq F(\{a, b\}) \times F(\{a, b\})$, the *identity correspondence problem*
(ICP) asks whether some nonempty sequence $l_1, \dots, l_k$ of indices satisfies

$$
s_{l_1} s_{l_2} \cdots s_{l_k} = t_{l_1} t_{l_2} \cdots t_{l_k} = \varepsilon .
$$

**Theorem.**

1. The identity correspondence problem is undecidable for $m = 8(n - 1)$ pairs, where $n$ is a number of pairs for which the restricted Post correspondence problem is undecidable; with $n = 7$ this gives $56$ pairs.
2. (*group problem*) It is undecidable, for the same number of pairs, whether the semigroup generated by a finite set of pairs of free-group words is a group.
3. Given a semigroup generated by $48$ square $4 \times 4$ integer matrices, it is undecidable whether it contains the identity matrix; it is also undecidable whether a finitely generated semigroup of integer matrices contains a diagonal
   matrix.
4. It is undecidable whether a given finite set of rotations of the $3$-sphere generates a group.

The number of matrices in item 3 was later reduced to eight in [the identity problem for 4×4 integer matrices of determinant one](the-identity-problem-for-eight-44-integer-matric.md).

## Expansion

The proof of item 1 reduces a restricted Post correspondence problem, in which a solution must start with the first pair, end with the last and use the others in between (undecidable for $7$ pairs by results of Matiyasevich and Sénizergues
and of Halava, Harju and Hirvensalo), through an index-coding variant in which a designated pair is used exactly once. The pairs are encoded over a free group with border letters whose inverses cancel only along a well-formed solution.
Item 2 follows from the same construction, for which the generated semigroup is a group exactly when the identity is reached; item 3 embeds pairs of free-group words into $4 \times 4$ integer matrices through a free subgroup of $\mathrm{SL}(2, \mathbb{Z})$, and item 4 uses
a free group of rational quaternions. A complete expansion links the restricted and index-coding Post correspondence problems, which have no pages.
