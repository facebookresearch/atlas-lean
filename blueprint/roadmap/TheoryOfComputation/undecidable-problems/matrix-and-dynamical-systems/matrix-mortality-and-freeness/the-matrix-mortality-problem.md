# The matrix mortality problem

The *mortality problem* for $d \times d$ integer matrices asks, for a finite set of such matrices, whether the zero matrix
is a product of matrices from the set; a set for which it is, is called *mortal*.

Fix $d \ge 1$. An instance is a finite set $E = \{M_1, \dots, M_k\}$ of matrices in $\mathbb{Z}^{d \times d}$. The set $E$ is
*mortal* if there are $\ell \ge 1$ and indices $i_1, \dots, i_\ell \in \{1, \dots, k\}$, repetitions allowed, with

$$
M_{i_1} M_{i_2} \cdots M_{i_\ell} = 0 ,
$$

that is, if the subsemigroup of $\mathbb{Z}^{d \times d}$ generated by $E$ contains the zero matrix. The *mortality problem*
for $d \times d$ integer matrices is the decision problem whose instances are such finite sets $E$, with the dimension $d$ fixed;
restricting it to sets with exactly $k$ elements gives the mortality problem for $k$
matrices of dimension $d$. The empty set is never mortal, since a product has at least one factor; a set containing the zero matrix is mortal with $\ell = 1$.

The dimension is part of the problem, not of the input: thresholds such as "six $3 \times 3$ matrices" fix both $d$ and $k$.
For $d = 1$ the problem is trivially decidable, since a product of integers is $0$ exactly when one factor is $0$.
