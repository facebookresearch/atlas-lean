# Wang tiles

Wang tiles are unit squares with colored edges, placed on the integer lattice so that adjacent edges match. Whether a
finite tile set tiles the plane is undecidable, also for the NW-deterministic tile sets whose valid tilings are the
space–time diagrams of one-dimensional cellular automata, and the reductions from it give undecidability results for
[cellular automata](../../equivalence-of-models/cellular-automata/README.md).
