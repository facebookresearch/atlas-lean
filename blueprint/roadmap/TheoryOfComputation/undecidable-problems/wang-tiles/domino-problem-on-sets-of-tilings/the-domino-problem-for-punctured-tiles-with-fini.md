# The domino problem for punctured tiles with finite local complexity is undecidable in every dimension

For every dimension $d \ge 2$ and every finite set of tiles of $\mathbb{R}^d$ whose tilings have finite local complexity, no algorithm decides whether
colored copies of the tiles, subject to finitely many forbidden patches, tile space; this holds even inside one fixed tiling.

Let $d \ge 2$. A finite set $\mathcal{P} = \{p_1, \dots, p_n\}$ of tiles of $\mathbb{R}^d$ is a set of *punctured tiles* if $0$ lies in the interior of each $p_i$ and no two distinct tiles are translates of each other. A tiling of $\mathbb{R}^d$ is *generated* by $\mathcal{P}$
if each of its tiles is a translate $\mathrm{pos}(t) + p$ of some $p \in \mathcal{P}$; $\Omega(\mathcal{P})$ is the space of such tilings, and $\mathcal{P}$ has *finite local complexity* (FLC) if for every $r > 0$ only finitely many patches meeting the ball of radius $r$ occur. For a finite
alphabet $A$, *colored tilings* use tiles from $\mathcal{P} \times A$, and a finite set of colored finite patches is forbidden, as in the [domino problem on a set of geometric tilings](geometric-tilings-and-the-domino-problem-on-a-se.md). The *$\mathcal{P}$-domino problem*
asks, given $A$ and the forbidden patches, whether some colored tiling generated by $(\mathcal{P}, A)$ avoids them; for a fixed tiling $\widehat{T} \in \Omega(\mathcal{P})$, the *$\widehat{T}$-domino problem* asks the same for colored tilings whose underlying tiling is $\widehat{T}$.

**Theorem.** Let $d \ge 2$ and let $\mathcal{P}$ be a finite set of punctured tiles with FLC. Then the $\mathcal{P}$-domino problem is undecidable, and for every tiling $\widehat{T} \in \Omega(\mathcal{P})$ the $\widehat{T}$-domino problem is undecidable.

This extends to every dimension $d \ge 2$ the planar results for rhombus tilings and for sets of tilings with finite local complexity; for example it applies to the hat monotile and its tilings.

## Expansion

The source introduces *blueprints*, partial actions of a monoid that generalize Cayley graphs, with subshifts of finite type on them, and proves that undecidability of the domino problem is invariant under quasi-isometries between finitely presented blueprints. For a
set of punctured tiles with FLC it builds a blueprint whose models are exactly the punctured tilings of $\Omega(\mathcal{P})$, which is quasi-isometric to $\mathbb{Z}^d$; undecidability of the domino problem on $\mathbb{Z}^d$ for $d \ge 2$ then transfers to the blueprint, and a computable translation of
nearest-neighbor forbidden patterns into forbidden colored patches transfers it to the $\mathcal{P}$-domino problem. A complete expansion links the quasi-isometry invariance theorem for blueprints, which has no page.
