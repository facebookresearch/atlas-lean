# Combinatorial substitutions

A multidimensional combinatorial substitution replaces each cell of a pattern by a pattern and places the images according to rules attached to pairs of cells at allowed offsets; whether the placement is always independent of the order of application (consistency), and whether images never overlap, are undecidable in dimension two.
