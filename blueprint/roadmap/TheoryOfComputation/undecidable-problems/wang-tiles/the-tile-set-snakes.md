# The tile set SNAKES and its plane-filling property

There is a finite set of [Wang tiles](wang-tiles-and-valid-tilings.md), *SNAKES*, each tile carrying in addition an arrow pointing to one of its four
neighbours, with the following properties. SNAKES is aperiodic. In any tiling of the plane by SNAKES, valid or not, the arrows define
paths, the successor of a tile being the neighbour its arrow points to; if a path $P$ continues indefinitely and the tiling is valid
at every tile that $P$ visits, then for every $N \ge 1$ the path visits all tiles of some $N \times N$ square (plane-filling property). The
paths are forced to follow the Hilbert curve. SNAKES is the tool behind the undecidability of reversibility of two-dimensional
cellular automata.
