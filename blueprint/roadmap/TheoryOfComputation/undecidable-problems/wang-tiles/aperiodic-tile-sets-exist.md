# Aperiodic tile sets exist

There is a finite tile set that admits a valid tiling of the plane but no valid periodic tiling, in the sense of
[Wang tiles and valid tilings](wang-tiles-and-valid-tilings.md). If no aperiodic tile set existed, the tiling problem
would be decidable: tile larger and larger squares until either some square cannot be tiled or a period of a periodic
tiling is found, one of which must happen.
