# The tiling problem for 4-way deterministic tile sets is undecidable

The tiling problem for Wang tiles stays undecidable when every tile is determined by the colors of any two of its adjacent edges, even for tile sets that admit no periodic tiling.

**Setting.** A [Wang tile set](wang-tiles-and-valid-tilings.md) $\mathcal W$ is a finite set of tiles $t=(t_W,t_S,t_E,t_N)$ with a color on each side, and it *tiles the plane* if some map $f:\mathbb Z^2\to\mathcal W$ gives adjacent tiles the same color on their common edge. For $(C,D)\in\{(S,W),(S,E),(N,W),(N,E)\}$, $\mathcal W$ is *$CD$-deterministic* if each tile $t\in\mathcal W$ is determined by its pair of colors $(t_C,t_D)$, and it is *4-way deterministic* if it is $CD$-deterministic for all four pairs. A tiling $f$ is *periodic* if $f(\mathbf t+\mathbf v)=f(\mathbf t)$ for all $\mathbf t$ and some nonzero $\mathbf v\in\mathbb Z^2$, and a tile set is *aperiodic* if it admits no periodic tiling, as in the source. This differs from the definition on the linked Wang tiles page, which also requires a valid tiling; under that definition every input would tile the plane and the restricted problem would be trivial.

**Theorem (Lukkarila).** The tiling problem restricted to 4-way deterministic aperiodic tile sets is undecidable: there is no algorithm that, on every 4-way deterministic tile set that admits no periodic tiling, halts and correctly says whether it tiles the plane. This is a promise problem: aperiodicity is a condition on the inputs, not part of what the algorithm must check, and the theorem says nothing about an algorithm's behavior on tile sets with a periodic tiling.

For tile sets that are deterministic in only one pair of directions, undecidability is Kari's earlier theorem ([NW-deterministic tile sets](the-tiling-problem-for-nw-deterministic-tile-sets.md)). Since a 4-way deterministic tile set gives a bi-reversible and bi-deterministic automaton, the theorem yields the undecidability of finiteness for semigroups generated by such automata (D'Angeli, Rodaro and Wächter).

## Expansion

From a Turing machine one constructs a 4-way deterministic tile set, whose tiles consist of several layers combined by direct products, so that the existence of a tiling is tied to the halting behavior of the machine (D'Angeli, Rodaro and Wächter outline the construction); the first layer is an aperiodic 4-way deterministic tile set of Kari and Papasoglu, which forces every tiling to be aperiodic, and the other layers carry the simulation of the machine. A good expansion links pages for an aperiodic 4-way deterministic tile set and for the layered simulation of Turing machines by 4-way deterministic tiles.
