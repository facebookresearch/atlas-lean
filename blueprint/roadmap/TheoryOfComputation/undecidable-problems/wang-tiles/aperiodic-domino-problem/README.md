# The aperiodic domino problem

The aperiodic domino problem asks whether a multidimensional subshift, given by forbidden patterns, contains a configuration with no nonzero period; it is $\Sigma^1_1$-complete for sofic subshifts from dimension three and for subshifts of finite type from dimension four.
