# Distributed automata

Distributed automata run one finite-state machine on every node of a directed graph, nodes updating their states in synchronous
rounds from the states of their incoming neighbors. Their emptiness problem is undecidable, already on directed paths and for
automata whose state diagram has no cycles except self-loops, while it is decidable for forgetful automata.
