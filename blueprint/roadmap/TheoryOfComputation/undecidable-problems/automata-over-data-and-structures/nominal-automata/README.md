# Nominal automata

Nominal automata extend finite automata to infinite alphabets of data values, using orbit-finite nominal sets in place of finite
sets. Universality of nondeterministic nominal automata is undecidable; for residual automata it becomes decidable, but equivalence
and the property of being residual stay undecidable.
