# CONJUNCTIVE QUERY CONTAINMENT is NP-complete

The decision problem CONJUNCTIVE QUERY CONTAINMENT, which asks for a well-formed pair of conjunctive queries $Q_1$, $Q_2$ whether $Q_1$ is contained in $Q_2$, lies in NP, and every problem in NP reduces to it by a polynomial-time many-one reduction.

## Sources

- A. K. Chandra and P. M. Merlin, "Optimal implementation of conjunctive queries in relational data bases", *STOC*, 1977.
- S. Abiteboul, R. Hull and V. Vianu, *Foundations of Databases*, Addison-Wesley, 1995, Theorem 6.2.10(a).
