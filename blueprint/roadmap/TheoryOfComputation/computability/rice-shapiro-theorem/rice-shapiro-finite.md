# Rice–Shapiro, finite approximation

Let $C$ be a class of partial functions from $\mathbb{N}$ to $\mathbb{N}$ whose index set, the set of
codes $c$ of partial recursive functions whose function belongs to $C$, is recognizable by a
multi-stack Turing machine.
If $f$ is a partial recursive function in $C$, then some partial recursive function $\theta$ with
finite domain that is a subfunction of $f$ ($\theta(x) = y$ implies $f(x) = y$) belongs to $C$.
