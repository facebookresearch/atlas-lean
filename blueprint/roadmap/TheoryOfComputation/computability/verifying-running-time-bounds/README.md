# Verifying running-time bounds of Turing machines

Whether a given Turing machine runs within a time bound is undecidable for multi-tape machines exactly when the bound is at least n+1, for one-tape machines for bounds of order n log n, and for every class of bounds containing arbitrarily large constants.
