# Linear set of vectors

Let $T$ be a set. A set $S$ of vectors $T \to \mathbb{N}$ is linear if there are a base vector $b : T \to \mathbb{N}$
and a finite list of period vectors $p_1, \dots, p_k : T \to \mathbb{N}$ such that

$$S = \{b + c_1 p_1 + \dots + c_k p_k : c_1, \dots, c_k \in \mathbb{N}\},$$

with one coefficient for each position in the list (a period repeated in the list gets independent
coefficients).

## Sources

- R. J. Parikh, "On context-free languages", *Journal of the ACM* 13 (1966), 570–581.
