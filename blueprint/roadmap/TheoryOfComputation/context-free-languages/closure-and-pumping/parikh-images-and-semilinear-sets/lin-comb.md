# Linear combination of period vectors

Let $T$ be a set. For a list $p_1, \dots, p_k$ of vectors $T \to \mathbb{N}$ and a list $c_1, \dots, c_m$ of
natural numbers, the linear combination is $c_1 p_1 + \dots + c_k p_k$ if $k = m$, and the zero vector if
$k \ne m$. Coefficients are indexed by position in the list of periods, so for the list $p, p$ the
coefficients $1, 0$ give $p$, not $2p$.
