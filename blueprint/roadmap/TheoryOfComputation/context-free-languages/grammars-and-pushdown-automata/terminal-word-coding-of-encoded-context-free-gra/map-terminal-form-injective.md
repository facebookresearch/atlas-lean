# Coding sentential forms is injective

If $\varphi$ sends terminals of $T$ to words over $T'$ and the induced word homomorphism is injective, then the map on sentential forms that replaces each terminal $a$ by the word $\varphi(a)$ and keeps each nonterminal is injective. The nonterminals delimit maximal blocks of terminals, including empty blocks, and each block is recovered by injectivity on words.
