# Cubic cost bound for indexed CYK on encoded grammars

Let $T$ be a set of terminals and $N$ a set of nonterminals, and let $c_t, c_n \in \mathbb{N}$ be the costs charged for a terminal comparison and for a nonterminal comparison. A costed computation returns a value together with a cost in $\mathbb{N}$. An encoded context-free grammar over an alphabet $T$ consists of a start nonterminal $n_0 \in \mathbb{N}$ and a finite list of encoded productions $(A, \gamma)$ with $A \in \mathbb{N}$ and $\gamma$ a finite word over the disjoint union of $\mathbb{N}$ (nonterminals) and $T$ (terminals); decoding a symbol reads an element of $\mathbb{N}$ as a nonterminal and an element of $T$ as a terminal, and decoding a production $(A, \gamma)$ gives the production $A \to \gamma'$ with $\gamma'$ the symbolwise decoding of $\gamma$. A table is a finite array of rows, each a finite array of finite lists of nonterminals; for a table $\tau$, the cell $\tau(i, \ell)$ (start $i$, length $\ell$) is entry $i$ of row $\ell$, and the empty list if row $\ell$ or its entry $i$ does not exist. The membership scan of $a \in N$ in a list $x_1 \cdots x_m$ of nonterminals has value true if and only if $a$ is some $x_j$, and is computed by recursion with cost $1$ for the empty list and cost $c_n + 3$ added per entry. The split scan $\mathrm{split}(\tau, i, \ell, B, C, k)$ has value true if and only if for some $k'$ with $1 \le k' \le k$ both $B \in \tau(i, k')$ and $C \in \tau(i + k', \ell - k')$ (with truncated subtraction); it has cost $1$ for $k = 0$, and for $k + 1$ the cost for $k$ plus the costs of the membership scans of $B$ in $\tau(i, k+1)$ and of $C$ in $\tau(i + k + 1, \ell - (k + 1))$ plus $16$. For a word $w = w_0 \cdots w_{n-1}$ over $T$, the fit test of a production right side $\gamma$ at $(i, \ell)$ is: if $\gamma$ is a single terminal $a$, value true if and only if $\ell = 1$, $i < n$ and $w_i = a$, cost $c_t + 12$; if $\gamma = BC$ with nonterminals $B, C$, the value of $\mathrm{split}(\tau, i, \ell, B, C, \ell - 1)$, with its cost plus $8$; otherwise value false, cost $8$. The cell computation for a list $r_1, \dots, r_m$ of productions at $(i, \ell)$ scans the productions in order: its value is the list of the left sides of those $r_j$ whose right side passes the fit test (in order, duplicates kept), and its cost is $1$ for the empty list and, for each production, the cost of its fit test plus $5$. The row computation of length $\ell$ from start $i$ with $c$ entries has as value the list of the $c$ cell computations at $(i, \ell), (i + 1, \ell), \dots, (i + c - 1, \ell)$ against $\tau$, with cost $1$ plus, per entry, the cost of its cell computation plus $4$. The table computation of depth $d$ for $w$ (of length $n$) and the productions is defined by recursion: depth $0$ gives $n + 1$ empty rows at cost $n + 4$; depth $d + 1$ takes the table $\tau'$ of depth $d$, computes the row of length $d + 1$ from start $0$ with $n + 1$ entries against $\tau'$, and replaces row $d + 1$ of $\tau'$ by it (no change if $d + 1 > n$), at the cost of depth $d$ plus the cost of the row plus $2(n + 1) + 8$. The epsilon scan for a start nonterminal $S$ has value true if and only if some production in the list has left side $S$ and empty right side, with cost $1$ plus $c_n + 6$ per production. The recognizer for start $S$ and a word $w$ of length $n$ returns, if $w$ is empty, the value of the epsilon scan for $S$ at its cost plus $1$; otherwise it computes the table $\tau$ of depth $n$ and returns the value of the membership scan of $S$ in $\tau(0, n)$, at cost the table cost plus the scan cost plus $3n + 12$. The recognizer for an encoded grammar $g$ and a word $w$ decodes the productions of $g$ and runs the indexed CYK recognizer with start $n_0$ and the decoded list of productions on $w$; its value is that of the recognizer and its cost is the decoding cost plus the recognizer cost plus $3$. For every encoded grammar $g$ with productions $(A_1, \gamma_1), \dots, (A_m, \gamma_m)$ and every
word $w$ of length $n$ over $T$, the cost of the recognizer for $g$ on $w$ is at most

$$\Bigl(m\,(c_t + c_n + 2m(c_n + 3) + 44) + 4\sum_{j=1}^{m} |\gamma_j| + 44\Bigr)(n + 1)^3.$$

No Chomsky normal form hypothesis is needed for the bound.
