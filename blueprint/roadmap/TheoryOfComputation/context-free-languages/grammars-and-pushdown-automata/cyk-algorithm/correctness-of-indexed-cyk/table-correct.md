# Correctness of the completed indexed CYK table

Let $T$ be a set of terminals and $N$ a set of nonterminals, and let $c_t, c_n \in \mathbb{N}$ be the costs charged for a terminal comparison and for a nonterminal comparison. A costed computation returns a value together with a cost in $\mathbb{N}$. A table is a finite array of rows, each a finite array of finite lists of nonterminals; for a table $\tau$, the cell $\tau(i, \ell)$ (start $i$, length $\ell$) is entry $i$ of row $\ell$, and the empty list if row $\ell$ or its entry $i$ does not exist. The membership scan of $a \in N$ in a list $x_1 \cdots x_m$ of nonterminals has value true if and only if $a$ is some $x_j$, and is computed by recursion with cost $1$ for the empty list and cost $c_n + 3$ added per entry. The split scan $\mathrm{split}(\tau, i, \ell, B, C, k)$ has value true if and only if for some $k'$ with $1 \le k' \le k$ both $B \in \tau(i, k')$ and $C \in \tau(i + k', \ell - k')$ (with truncated subtraction); it has cost $1$ for $k = 0$, and for $k + 1$ the cost for $k$ plus the costs of the membership scans of $B$ in $\tau(i, k+1)$ and of $C$ in $\tau(i + k + 1, \ell - (k + 1))$ plus $16$. For a word $w = w_0 \cdots w_{n-1}$ over $T$, the fit test of a production right side $\gamma$ at $(i, \ell)$ is: if $\gamma$ is a single terminal $a$, value true if and only if $\ell = 1$, $i < n$ and $w_i = a$, cost $c_t + 12$; if $\gamma = BC$ with nonterminals $B, C$, the value of $\mathrm{split}(\tau, i, \ell, B, C, \ell - 1)$, with its cost plus $8$; otherwise value false, cost $8$. The cell computation for a list $r_1, \dots, r_m$ of productions at $(i, \ell)$ scans the productions in order: its value is the list of the left sides of those $r_j$ whose right side passes the fit test (in order, duplicates kept), and its cost is $1$ for the empty list and, for each production, the cost of its fit test plus $5$. The row computation of length $\ell$ from start $i$ with $c$ entries has as value the list of the $c$ cell computations at $(i, \ell), (i + 1, \ell), \dots, (i + c - 1, \ell)$ against $\tau$, with cost $1$ plus, per entry, the cost of its cell computation plus $4$. The table computation of depth $d$ for $w$ (of length $n$) and the productions is defined by recursion: depth $0$ gives $n + 1$ empty rows at cost $n + 4$; depth $d + 1$ takes the table $\tau'$ of depth $d$, computes the row of length $d + 1$ from start $0$ with $n + 1$ entries against $\tau'$, and replaces row $d + 1$ of $\tau'$ by it (no change if $d + 1 > n$), at the cost of depth $d$ plus the cost of the row plus $2(n + 1) + 8$. Let $G$ be a context-free grammar with terminals $T$ in Chomsky normal form, with initial nonterminal $S$, and let $\rho$ be a list of productions whose members are exactly the productions of $G$ (in any order, repetitions allowed). For a word $w$ and $i, \ell \in \mathbb{N}$, $w[i, i+\ell)$ denotes the factor of $w$ obtained by removing the first $i$ letters and keeping the next $\ell$; a nonterminal $A$ derives a word $u$ if $u$ is obtained from $A$ by finitely many applications of productions. Let $w$ be a word over $T$ and $d \in \mathbb{N}$. For all $i, \ell$ with $0 < \ell \le d$ and $i + \ell \le
|w|$ and every nonterminal $A$, $A$ lies in the cell $(i, \ell)$ of the table of depth $d$ (for $w$ and $\rho$) if and only if $A$ derives $w[i, i+\ell)$.
