# Production-output fit test for indexed CYK

Let $T$ be a set of terminals and $N$ a set of nonterminals, and let $c_t, c_n \in \mathbb{N}$ be the costs charged for a terminal comparison and for a nonterminal comparison. A costed computation returns a value together with a cost in $\mathbb{N}$. A table is a finite array of rows, each a finite array of finite lists of nonterminals; for a table $\tau$, the cell $\tau(i, \ell)$ (start $i$, length $\ell$) is entry $i$ of row $\ell$, and the empty list if row $\ell$ or its entry $i$ does not exist. The membership scan of $a \in N$ in a list $x_1 \cdots x_m$ of nonterminals has value true if and only if $a$ is some $x_j$, and is computed by recursion with cost $1$ for the empty list and cost $c_n + 3$ added per entry. The split scan $\mathrm{split}(\tau, i, \ell, B, C, k)$ has value true if and only if for some $k'$ with $1 \le k' \le k$ both $B \in \tau(i, k')$ and $C \in \tau(i + k', \ell - k')$ (with truncated subtraction); it has cost $1$ for $k = 0$, and for $k + 1$ the cost for $k$ plus the costs of the membership scans of $B$ in $\tau(i, k+1)$ and of $C$ in $\tau(i + k + 1, \ell - (k + 1))$ plus $16$. For a word $w = w_0 \cdots w_{n-1}$ over $T$, a table $\tau$, $i, \ell \in \mathbb{N}$ and a right
side $\gamma$ (a word over terminals and nonterminals), the fit test is: if $\gamma$ is a single terminal
$a$, its value is true if and only if $\ell = 1$, $i < n$ and $w_i = a$, at cost $c_t + 12$; if $\gamma = BC$ for
nonterminals $B, C$, its value is that of $\mathrm{split}(\tau, i, \ell, B, C, \ell - 1)$ and its cost that of
the split scan plus $8$; for every other $\gamma$ its value is false at cost $8$.
