# Charged computation of one CYK cell

Let $T$ be a set of terminals and $N$ a set of nonterminals, and let $c_t, c_n \in \mathbb{N}$ be the costs charged for a terminal comparison and for a nonterminal comparison. A costed computation returns a value together with a cost in $\mathbb{N}$. A table is a finite array of rows, each a finite array of finite lists of nonterminals; for a table $\tau$, the cell $\tau(i, \ell)$ (start $i$, length $\ell$) is entry $i$ of row $\ell$, and the empty list if row $\ell$ or its entry $i$ does not exist. The membership scan of $a \in N$ in a list $x_1 \cdots x_m$ of nonterminals has value true if and only if $a$ is some $x_j$, and is computed by recursion with cost $1$ for the empty list and cost $c_n + 3$ added per entry. The split scan $\mathrm{split}(\tau, i, \ell, B, C, k)$ has value true if and only if for some $k'$ with $1 \le k' \le k$ both $B \in \tau(i, k')$ and $C \in \tau(i + k', \ell - k')$ (with truncated subtraction); it has cost $1$ for $k = 0$, and for $k + 1$ the cost for $k$ plus the costs of the membership scans of $B$ in $\tau(i, k+1)$ and of $C$ in $\tau(i + k + 1, \ell - (k + 1))$ plus $16$. For a word $w = w_0 \cdots w_{n-1}$ over $T$, the fit test of a production right side $\gamma$ at $(i, \ell)$ is: if $\gamma$ is a single terminal $a$, value true if and only if $\ell = 1$, $i < n$ and $w_i = a$, cost $c_t + 12$; if $\gamma = BC$ with nonterminals $B, C$, the value of $\mathrm{split}(\tau, i, \ell, B, C, \ell - 1)$, with its cost plus $8$; otherwise value false, cost $8$. For a word $w$ over $T$, a table $\tau$, $i, \ell \in \mathbb{N}$ and a list $r_1, \dots, r_m$ of
productions, the cell computation is defined by recursion on the list: for the empty list its value is the
empty list and its cost $1$; for $r_1, r_2, \dots, r_m$ it runs the fit test of the right side of $r_1$ at
$(i, \ell)$ and the cell computation for $r_2, \dots, r_m$, its value is the latter's value preceded by the
left side of $r_1$ if the fit test succeeds, and its cost is the sum of the two costs plus $5$.

Repetitions are kept; no duplicate removal takes place.
