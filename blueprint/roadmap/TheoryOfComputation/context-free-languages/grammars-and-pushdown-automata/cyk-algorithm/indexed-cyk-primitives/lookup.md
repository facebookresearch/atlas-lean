# CYK table lookup with empty default cells

Let $N$ be a set of nonterminals. A table is a finite array of rows, each a finite array of finite lists of
nonterminals. For a table $\tau$ and $i, \ell \in \mathbb{N}$, the cell $\tau(i, \ell)$ is entry $i$ of row $\ell$ if
row $\ell$ exists and has an entry $i$, and the empty list otherwise.
