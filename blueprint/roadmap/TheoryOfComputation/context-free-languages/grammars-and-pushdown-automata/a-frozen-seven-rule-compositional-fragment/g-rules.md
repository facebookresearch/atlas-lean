# The fragment grammar has exactly the seven rules

The fragment has tokens everybody, admires and someone and the rules
$S \to \mathrm{Subj}\ \mathrm{VP}$, $\mathrm{VP} \to \mathrm{TV}\ \mathrm{Obj}$,
$S \to \mathrm{SP}\ \mathrm{Obj}$, $\mathrm{SP} \to \mathrm{Subj}\ \mathrm{TV}$, $\mathrm{Subj} \to$
everybody, $\mathrm{Obj} \to$ someone and $\mathrm{TV} \to$ admires, numbered $0$ to $6$. The rule
set of the fragment's grammar is exactly the set of the seven rules numbered $0$ to $6$.
