# Probability of a cylinder under the binary-tree address law

For $0 \le p \le 1$, a finite set $s$ of binary addresses and an assignment $t$ of a bit to each address, the law of independent Bernoulli($p$) bits indexed by binary addresses gives the cylinder $\{\omega : \omega(a) = t(a) \text{ for } a \in s\}$ probability $\prod_{a \in s} q_a$, where $q_a = p$ if $t(a)$ is true and $q_a = 1 - p$ otherwise.
