# Shape of the example tree of a binary tree

The ambiguous example grammar has one nonterminal $A$, which is its start symbol, one terminal $a$, and the two rules $A \to A\,A$ and $A \to a$. Turning a one-nonterminal binary tree into the derivation tree of this grammar of the same shape, and then taking the shape of that derivation tree, gives back the original binary tree.
