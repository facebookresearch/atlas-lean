# Membership in the bounded example trees

The ambiguous example grammar has one nonterminal $A$, which is its start symbol, one terminal $a$, and the two rules $A \to A\,A$ and $A \to a$. The depth of a leaf is $1$, and the depth of a node is one more than the larger depth of its subtrees. A derivation tree belongs to the bounded set of example trees for $h$ if and only if it is valid for the grammar and its depth is at most $h$.
