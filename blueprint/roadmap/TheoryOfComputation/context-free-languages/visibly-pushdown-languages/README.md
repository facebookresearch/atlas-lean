# Visibly pushdown languages

Visibly pushdown automata push on calls, pop on returns and leave the stack alone on local letters, so the input determines the
stack height. Their languages, equivalently the regular languages of nested words, lie between the regular and the deterministic
context-free languages, are closed under all Boolean operations, concatenation and star, have EXPTIME-complete universality and
inclusion problems, and are the languages definable in monadic second-order logic with a matching relation.
