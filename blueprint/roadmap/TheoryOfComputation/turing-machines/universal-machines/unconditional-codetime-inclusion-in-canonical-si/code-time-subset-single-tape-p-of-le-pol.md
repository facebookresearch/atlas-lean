# Polynomially bounded time classes of machine codes lie in single-tape polynomial time

Let $t$ be a function from natural numbers to natural numbers and $p$ a polynomial with
natural-number coefficients such that $t(n) \le p(n)$ for every $n$. Then every decision problem
decided by some machine code within $t(|x|)$ steps on every input $x$ lies in the class of problems
decidable in polynomial time by a single-tape Turing machine. The time bound $t$ need not be
monotone or computable. The single-tape machine runs within the polynomial $4p + 2X + 10$.
