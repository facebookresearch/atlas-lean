# Unconditional canonical decision-time inclusion

A code is a finite transition table of a single-tape Turing machine whose states and tape symbols are natural numbers, with $0$ the blank; a missing entry halts the machine. The input word of a bit string $x$ writes each bit as the symbol $1$ (false) or $2$ (true). For a time bound $t : \mathbb{N} \to \mathbb{N}$, a code decides a decision problem $L$ on bit strings within $t$ when, on every bit string $x$, its machine, started with nothing left of the head and the input word of $x$ from the head rightwards, halts within $t(|x|)$ steps, and the symbol under the final head followed by the cells to its right, with trailing blanks removed, is exactly the single symbol of the answer: $2$ if $L(x)$ is true and $1$ if it is false. The cells left of the final head are unconstrained. The class of problems decided within $t$ by some code is called code time $t$. Because the table is finite, a run on bits only holds symbols below $B = m + 3$, where $m$ is the largest action number in the table ($0$ if the table has no transition): the blank, the two input symbols and the symbols the table writes. Each code is simulated step for step by a single-tape Turing machine over the alphabet $\{0, \dots, B - 1\}$, with an injective embedding of the two bits. If a decision problem $L$ is decided by some code within $t$, then there are a finite, nonempty alphabet $\Gamma$, an injective embedding $\iota$ of the two bits into $\Gamma$ and a single-tape Turing machine over $\Gamma$ such that, for every bit string $w$, the machine started on the encoded word $\iota(w)$ halts within $4\,t(|w|) + 2|w| + 10$ steps with the one-symbol output $\iota$ of the answer of $L$ on $w$, on an otherwise blank tape under the halting head.
