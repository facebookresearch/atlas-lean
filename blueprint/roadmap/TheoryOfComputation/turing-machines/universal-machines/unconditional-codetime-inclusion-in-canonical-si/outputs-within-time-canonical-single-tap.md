# The canonical machine of a deciding code outputs its answer in time

A code is a finite transition table of a single-tape Turing machine whose states and symbols are natural numbers below fixed bounds. For a time bound $t : \mathbb{N} \to \mathbb{N}$, a code decides a decision problem $L$ on bit strings within $t$ when, on every bit string $x$ written on its tape, it halts within $t(|x|)$ steps with the answer of $L$ on $x$. The class of problems decided within $t$ by some code is called code time $t$. Each code is simulated step for step by a single-tape Turing machine over a finite alphabet of non-blank symbols, with an injective embedding of the two bits. The canonical machine of a code runs this simulation on an alphabet with visited-cell markers and then erases the cells it visited, leaving only the answer, written on an otherwise blank tape under the halting head. If a code decides $L$ within $t$, then for every bit string $x$, its canonical machine started on the canonical encoding of $x$ halts within $4\,t(|x|) + 2|x| + 10$ steps with the one-symbol output encoding the answer of $L$ on $x$. No assumption about the tape left of the input is needed, and the bound includes the halting transition of the simulated code.
