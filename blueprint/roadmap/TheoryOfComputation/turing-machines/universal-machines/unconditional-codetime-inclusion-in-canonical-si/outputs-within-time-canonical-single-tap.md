# The canonical machine of a deciding code outputs its answer in time

A code is a finite transition table of a single-tape Turing machine whose states and tape symbols are natural numbers, with $0$ the blank; a missing entry halts the machine. The input word of a bit string $x$ writes each bit as the symbol $1$ (false) or $2$ (true). For a time bound $t : \mathbb{N} \to \mathbb{N}$, a code decides a decision problem $L$ on bit strings within $t$ when, on every bit string $x$, its machine, started with nothing left of the head and the input word of $x$ from the head rightwards, halts within $t(|x|)$ steps, and the symbol under the final head followed by the cells to its right, with trailing blanks removed, is exactly the single symbol of the answer: $2$ if $L(x)$ is true and $1$ if it is false. The cells left of the final head are unconstrained. The class of problems decided within $t$ by some code is called code time $t$. Because the table is finite, a run on bits only holds symbols below $B = m + 3$, where $m$ is the largest action number in the table ($0$ if the table has no transition): the blank, the two input symbols and the symbols the table writes. Each code is simulated step for step by a single-tape Turing machine over the alphabet $\{0, \dots, B - 1\}$, with an injective embedding of the two bits. The canonical machine of a code runs this simulation on an alphabet with visited-cell markers; when the simulated run halts with a one-symbol answer as above, it then erases the cells it visited, leaving only that answer, written on an otherwise blank tape under the halting head. If a code decides $L$ within $t$, then for every bit string $x$, its canonical machine started on the canonical encoding of $x$ halts within $4\,t(|x|) + 2|x| + 10$ steps with the one-symbol output encoding the answer of $L$ on $x$. The cells left of the simulated code's final head may hold anything; they are erased with the other visited cells. The bound includes the halting transition of the simulated code.
