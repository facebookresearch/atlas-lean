# The cells of a list of table entries

In the clocked universal Turing machine, the tape cells encoding a nonempty list of table entries, each a quadruple of natural numbers, are the cells encoding its first entry followed by the cells encoding the rest of the list. For a first entry $(q, a, q', s)$ the bit string is $\mathrm{cell}(q) \mathbin{+\!\!+} \mathrm{cell}(a) \mathbin{+\!\!+} \mathrm{cell}(q') \mathbin{+\!\!+} \mathrm{cell}(s)$ followed by the cells of the rest, where $\mathrm{cell}(n)$ is $n$ ones followed by a zero, following the order of the [numbers of a list of entries](entry-nums.md).
