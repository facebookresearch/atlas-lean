# When the single-tape machine outputs the answer

If a machine code $c$ decides a problem $L$ on bit strings within time $t$, then, for each bit string $x$, the single-tape machine of $c$ eventually halts on the input word of $x$ with output the one-symbol word consisting of the input symbol of $L(x)$ if and only if every cell to the left of the head of $c$ is blank after $t(|x|)$ steps on $x$.
