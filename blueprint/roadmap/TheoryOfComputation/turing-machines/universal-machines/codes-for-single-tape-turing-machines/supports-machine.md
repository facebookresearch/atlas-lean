# Codes denote finite machines

Let $c$ be a code and $S$ its finite set of states: $0$ together with every state that an entry of
its table enters. The decoded single-tape machine of $c$ is supported by $S$: its initial state
$0$ lies in $S$, and whenever the machine, in a state $q \in S$ reading a symbol $a$, has a
transition entering a state $q'$, then $q' \in S$.
