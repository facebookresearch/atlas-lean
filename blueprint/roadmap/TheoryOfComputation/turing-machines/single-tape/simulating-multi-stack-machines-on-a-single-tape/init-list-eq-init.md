# The initial configuration of a finite multi-stack machine is the generic one

Let $M$ be a finite multi-stack Turing machine with input stack $k_0$, main label $\lambda_0$ and
initial internal state $\sigma_0$, and let $l$ be a list over the alphabet of $k_0$. The initial
configuration of $M$ on $l$ equals the generic multi-stack initial configuration with $l$ on stack
$k_0$, whose starting label and starting internal state are the designated ones of the machine,
here $\lambda_0$ and $\sigma_0$: both have current label $\lambda_0$, internal state $\sigma_0$,
the list $l$ on $k_0$ and every other stack empty.
