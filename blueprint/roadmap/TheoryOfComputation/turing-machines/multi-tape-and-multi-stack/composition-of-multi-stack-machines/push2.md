# Push labels of the second copy loop

In the composite machine of $M_1$ and $M_2$, whose label set contains two copies of
$X \sqcup \{\bot\}$ with $X$ the input alphabet of $M_2$, for a symbol $x \in X$ this is the label
$x$ of the second copy; the composite program uses it to push $x$ on $M_2$'s input stack.
