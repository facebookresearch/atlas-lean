# Exact matching transports a bounded run

Let $M$ and $M'$ be multi-stack machines with stack index sets $K$ and $K'$, stack alphabets $(\Gamma_k)_{k \in K}$ and $(\Gamma'_{k'})_{k' \in K'}$, label sets $\Lambda$ and $\Lambda'$ and a common set $\sigma$ of internal states. Let $(e, \iota)$ be a stack embedding (an injective map $e : K \to K'$ with bijections $\iota_k : \Gamma_k \to \Gamma'_{e(k)}$) and $\varphi : \Lambda \to \Lambda'$ a renaming of labels, and suppose $M'$ matches $M$ exactly: for every label $l$, the statement of $M'$ at $\varphi(l)$ is the statement of $M$ at $l$ with stacks, symbols and labels translated by $e$, $\iota$ and $\varphi$. Host stack contents $S'$ agree with $S$ if $S'(e(k)) = \iota_k(S(k))$ (symbolwise) for every $k \in K$, and $T'$ frames $S'$ if $T'(k') = S'(k')$ for every $k'$ outside the image of $e$. A configuration is a label (or halted), an internal state and stack contents, and $\varphi$ maps the halted label to the halted label. Suppose $M$ runs in at most $B$ steps from the configuration $(l, v, S)$ to $(l', v', T)$, where $l$ and $l'$ are labels or halted, and let $S'$ be host stacks that agree with $S$. Then there are host stacks $T'$ that agree with $T$ and frame $S'$ such that $M'$ runs in at most $B$ steps from $(\varphi(l), v, S')$ to $(\varphi(l'), v', T')$; it uses the same number of steps as the run of $M$.
