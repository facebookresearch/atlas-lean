# Runs compose

A multi-tape Turing machine with $k$ tapes moves deterministically from configuration to configuration, and a halted configuration stays unchanged under further steps. For a configuration $c$ and $t \ge 0$, the run from $c$ for $t$ steps is the configuration reached after $t$ steps. The machine started in $c$ halts at step $t$ when the run for $t$ steps is halted but the run for every $s < t$ steps is not. For every configuration $c$ and all $m, n \ge 0$, the run from $c$ for $m + n$ steps equals the run for $n$ steps from the configuration reached after $m$ steps.
