# After halting the configuration stays fixed

A multi-tape Turing machine with $k$ work tapes, a read-only input tape and a write-only output tape (the last two present even when $k = 0$) moves deterministically from configuration to configuration, and a halted configuration stays unchanged under further steps. For a configuration $c$ and $t \ge 0$, the run from $c$ for $t$ steps is the configuration reached after $t$ steps. The machine started in $c$ halts at step $t$ when the run for $t$ steps is halted but the run for every $s < t$ steps is not. If the machine started in $c$ halts at step $t$ and $t \le s$, then the run from $c$ for $s$ steps equals the run for $t$ steps.
