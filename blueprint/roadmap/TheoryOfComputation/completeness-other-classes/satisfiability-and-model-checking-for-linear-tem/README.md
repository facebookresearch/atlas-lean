# Satisfiability and model checking for linear temporal logic

Satisfiability, validity and model checking of linear temporal logic are PSPACE-complete (Sistla and Clarke 1985). The upper bound comes from the automata-theoretic approach: the Büchi automaton of a formula has exponentially many states, and its nonemptiness, or that of its product with a finite-state program, can be tested on the fly in polynomial space.
