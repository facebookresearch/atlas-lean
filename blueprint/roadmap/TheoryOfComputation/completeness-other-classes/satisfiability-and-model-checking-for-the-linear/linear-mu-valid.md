# Validity of a linear μ-calculus formula

A linear μ-calculus formula $\varphi$ with atoms in $\mathbb{N}$ is valid when, for every word
(a valuation telling which atoms hold at each position $t \in \mathbb{N}$) and every position
$n$, $\varphi$ holds at position $n$ of the word in the empty environment, which interprets every
free fixpoint variable as the empty set of positions.
