# Satisfiability of a linear μ-calculus formula

A linear μ-calculus formula $\varphi$ with atoms in $\mathbb{N}$ is satisfiable when there are a
word, that is, a valuation telling which atoms hold at each position $t \in \mathbb{N}$, and a
position $n$ such that $\varphi$ holds at position $n$ of the word in the empty environment,
which interprets every free fixpoint variable as the empty set of positions.
