# Stable before a time

A signal $s : \mathbb{R} \to U$ is stable before $\tau \in \mathbb{R} \cup \{\infty\}$ when $s(t_1) = s(t_2)$ for all $t_1, t_2 \ge 0$ with $t_1, t_2 < \tau$, that is, $s$ takes a single value on $[0, \tau)$. With $\tau = \infty$ it never changes after the edge at time $0$; times before the edge are unconstrained.
