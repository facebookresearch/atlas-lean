# Causal gate-delay model for a program

A straight-line program with contamination delays $d_j$ on its gates, input signals and gate signals (functions of time) follows the causal gate-delay model when every gate does: each gate, with delay $d_j$, reading the signals of the inputs and of the earlier gates, satisfies the causal model for one gate with output signal the gate's own signal. The empty program satisfies it trivially.
