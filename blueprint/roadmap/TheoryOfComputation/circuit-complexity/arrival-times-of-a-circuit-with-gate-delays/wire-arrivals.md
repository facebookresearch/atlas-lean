# Arrival times of the wires of a program

A straight-line circuit program over a gate signature has a fixed number of input wires and a sequence of gates; each gate applies an operation of the signature to a list of wires (inputs or earlier gates), one for each argument position of the operation. Given a real delay for every gate and a real arrival time for every input, the arrival time of a wire is its given arrival time if it is an input, and the arrival time of the gate if it is a gate.
