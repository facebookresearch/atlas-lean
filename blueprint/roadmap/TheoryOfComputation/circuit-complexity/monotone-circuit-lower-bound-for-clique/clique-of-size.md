# The clique function CLIQUE(n, s) on adjacency-matrix bits

For a bitstring $x$ read as an $n \times n$ adjacency matrix in row-major order (positions beyond the end read as false), $\mathrm{CLIQUE}(n, s)$ holds when there is a set of $s$ vertices among $0, \dots, n-1$ whose entries $(a, b)$ are true for all distinct $a, b$ in it. Both entries $(a, b)$ and $(b, a)$ are read, so the usual clique function on $\binom{n}{2}$ edge variables is a monotone projection of this function (substitute the variable of the edge $\{a, b\}$ for both entries $(a, b)$ and $(b, a)$), and lower bounds for the usual function transfer to this one. [The clique function on adjacency-matrix bits](clique-holds.md) is the case $s = \lfloor n/3 \rfloor$.
