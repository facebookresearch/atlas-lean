# 2-SAT is in P

The 2-SAT decision problem lies in the complexity class P.

## Sources

- Martin Davis, George Logemann, and Donald Loveland, "A machine program for theorem-proving", Communications of the ACM 5 (1962), 394-397; Bengt Aspvall, Michael F. Plass, and Robert E. Tarjan, "A linear-time algorithm for testing the truth of certain quantified Boolean formulas", Information Processing Letters 8 (1979), 121-123.
