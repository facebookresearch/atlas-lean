# Strongly polynomial linear programming

Can general rational linear programs be solved with a number of arithmetic operations polynomial in the numbers of variables and constraints, independent of coefficient bit lengths?

## What would settle it

Prove correctness of an LP solver—optimal solution, infeasibility, or unboundedness—together with a dimension-only operation bound and polynomial bounds on intermediate bit sizes. Omitting the bit-size condition permits misleading “strongly polynomial” claims.

## Status

The cited sources pose this as an open question in the versions cited; this page does not certify its present status.

Dadush, Koh, Natura and Olver (preprint) solve restricted classes of linear programs in strongly polynomial time and state that finding a strongly polynomial algorithm for linear programming remains an outstanding open question.

This page records the cited research question and asserts no theorem or present-status certification.
