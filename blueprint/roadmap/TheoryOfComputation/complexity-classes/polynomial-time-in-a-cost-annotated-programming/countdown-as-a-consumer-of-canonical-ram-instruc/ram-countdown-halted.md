# The countdown program halts after 3n + 3 steps with accumulator zero

A random-access machine has a program counter, an accumulator and registers holding natural numbers; it starts with program counter $0$, accumulator $0$ and the inputs in registers $0, 1, \dots$ (other registers $0$), and it has halted once the program counter is at least the length of the program. The countdown program is the five-instruction program: load register $0$ into the accumulator; if the accumulator is $0$ jump to instruction $4$; subtract $1$ from the accumulator; jump to instruction $1$; halt. For every natural number $n$, after exactly $3n + 3$ steps from the initial state on the single input $n$, the machine is in the initial state except that the program counter equals the length of the program, $5$, and the accumulator is $0$.
