# Exact instruction cost of the countdown program

A random-access machine has a program counter, an accumulator and registers holding natural numbers; it starts with program counter $0$, accumulator $0$ and the inputs in registers $0, 1, \dots$ (other registers $0$), and it has halted once the program counter is at least the length of the program. The countdown program is the five-instruction program: load register $0$ into the accumulator; if the accumulator is $0$ jump to instruction $4$; subtract $1$ from the accumulator; jump to instruction $1$; halt. Each dispatched instruction costs one unit of time; space and peak memory are not measured by this cost model, and their fields are always $0$. For every input $n$ and every step budget $b$, running the countdown program on the single input $n$ for at most $b$ steps returns the cost annotation $(\min(b, 3n + 3), 0, 0)$: time cost exactly $\min(b, 3n + 3)$, since steps after halting cost nothing, and the two unmeasured fields $0$.
