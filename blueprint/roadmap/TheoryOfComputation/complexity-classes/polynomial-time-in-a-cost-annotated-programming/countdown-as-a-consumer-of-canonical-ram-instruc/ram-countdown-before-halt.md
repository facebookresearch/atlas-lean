# The countdown program runs without halting for its first 3n + 3 steps

A random-access machine has a program counter, an accumulator and registers holding natural numbers; it starts with program counter $0$, accumulator $0$ and the inputs in registers $0, 1, \dots$ (other registers $0$), and it has halted once the program counter is at least the length of the program. The countdown program is the five-instruction program: load register $0$ into the accumulator; if the accumulator is $0$ jump to instruction $4$; subtract $1$ from the accumulator; jump to instruction $1$; halt. For every natural number $n$ and every $k < 3n + 3$, after $k$ steps of the countdown program started on the single input $n$, the program counter is still less than the length of the program. So the halt reached after $3n + 3$ steps is the first.
