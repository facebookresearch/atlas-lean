# The countdown random-access machine program

A random-access machine has a program counter, an accumulator and registers holding natural numbers; it starts with program counter $0$, accumulator $0$ and the inputs in registers $0, 1, \dots$ (other registers $0$), and it has halted once the program counter is at least the length of the program. The countdown program is the five-instruction program: load register $0$ into the accumulator; if the accumulator is $0$ jump to instruction $4$; subtract $1$ from the accumulator; jump to instruction $1$; halt. Run on input $n$, it loads $n$, then performs $n$ iterations of the test, the subtraction and the jump back, and finally tests the accumulator once more and halts: one step for the load, three for each positive iteration and two at the end, so it halts after $3n + 3$ steps.
