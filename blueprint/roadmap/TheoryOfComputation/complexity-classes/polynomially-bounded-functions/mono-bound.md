# The normalized polynomial bound is polynomially bounded and monotone

A function $f : \mathbb{N} \to \mathbb{N}$ is polynomially bounded if there is $d \in \mathbb{N}$
with $f(n) \le n^d$ for all sufficiently large $n$.
For every $c \in \mathbb{N}$, the function $n \mapsto c\,(n + 1)^c$ is polynomially bounded and
monotone.
