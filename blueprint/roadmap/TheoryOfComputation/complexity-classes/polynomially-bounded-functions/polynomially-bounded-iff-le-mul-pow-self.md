# Polynomial bounds with equal coefficient and exponent

A function $f : \mathbb{N} \to \mathbb{N}$ is polynomially bounded if there is $d \in \mathbb{N}$
with $f(n) \le n^d$ for all sufficiently large $n$.
A function $f : \mathbb{N} \to \mathbb{N}$ is polynomially bounded if and only if there is
$c \in \mathbb{N}$ with $f(n) \le c\,(n + 1)^c$ for every $n \in \mathbb{N}$.
