# Powers of polynomially bounded functions are polynomially bounded

A function $f : \mathbb{N} \to \mathbb{N}$ is polynomially bounded if there is $d \in \mathbb{N}$
with $f(n) \le n^d$ for all sufficiently large $n$.
If $f$ is polynomially bounded and $k \in \mathbb{N}$, then $n \mapsto f(n)^k$ is polynomially
bounded.
