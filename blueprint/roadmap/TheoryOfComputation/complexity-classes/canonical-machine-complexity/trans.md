# Polynomial-time many-one reductions compose

Decision problems are predicates on finite bit strings. The classes P and NP and polynomial-time computable functions are the canonical ones defined by finite multi-stack Turing machines. A polynomial-time many-one reduction from $A$ to $B$ is a polynomial-time computable function $r$ on bit strings with $x \in A$ if and only if $r(x) \in B$ for every string $x$; a problem $L$ is NP-hard when every problem in NP reduces to $L$ in this way, and NP-complete when it is in NP and NP-hard. If $L_1$ has a polynomial-time many-one reduction to $L_2$ and $L_2$ has one to $L_3$, then $L_1$ has a polynomial-time many-one reduction to $L_3$.
