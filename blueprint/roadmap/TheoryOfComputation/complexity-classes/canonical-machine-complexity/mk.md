# NP membership and NP-hardness give NP-completeness

Decision problems are predicates on finite bit strings. The classes P and NP and polynomial-time computable functions are the canonical ones defined by finite multi-stack Turing machines. A polynomial-time many-one reduction from $A$ to $B$ is a polynomial-time computable function $r$ on bit strings with $x \in A$ if and only if $r(x) \in B$ for every string $x$; a problem $L$ is NP-hard when every problem in NP reduces to $L$ in this way, and NP-complete when it is in NP and NP-hard. If a decision problem $L$ belongs to NP and is NP-hard, then $L$ is NP-complete.
