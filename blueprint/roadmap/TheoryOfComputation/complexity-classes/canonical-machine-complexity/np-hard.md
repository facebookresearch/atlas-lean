# NP-complete problems are NP-hard

Decision problems are predicates on finite bit strings. The classes P and NP and polynomial-time computable functions are the canonical ones defined by finite multi-stack Turing machines. A polynomial-time many-one reduction from $A$ to $B$ is a polynomial-time computable function $r$ on bit strings with $x \in A$ if and only if $r(x) \in B$ for every string $x$; a problem $L$ is NP-hard when every problem in NP reduces to $L$ in this way, and NP-complete when it is in NP and NP-hard. Every NP-complete decision problem is NP-hard: every problem in NP has a polynomial-time many-one reduction to it.
