# Output of a polynomial-time map is polynomial in the input length

If $f$ is a map from bitstrings to bitstrings computable in polynomial time with the canonical
bitstring encodings, then there is a polynomial $q$ with natural-number coefficients such that
$|f(x)| \le q(|x|)$ for every bitstring $x$, where $|x|$ is the length of $x$ itself, not of its
encoding.
