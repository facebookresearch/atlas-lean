# All-zero state

The all-zero state on $a$ qubits is the vector in $\mathbb{C}^{2^a}$,
indexed by $s \in \{0, \dots, 2^a - 1\}$, whose entry at $s = 0$ is $1$ and whose other
entries are $0$; that is, the computational basis state $|0 \cdots 0\rangle$.
