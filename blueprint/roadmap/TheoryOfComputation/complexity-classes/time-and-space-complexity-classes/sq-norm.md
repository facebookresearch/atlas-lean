# Squared norm of a state vector

For a vector $\psi \in \mathbb{C}^{2^m}$, indexed by
$\{0, \dots, 2^m - 1\}$, its squared norm is the real number
$\sum_{s} \overline{\psi_s}\, \psi_s = \sum_{s} |\psi_s|^2$.

## Sources
