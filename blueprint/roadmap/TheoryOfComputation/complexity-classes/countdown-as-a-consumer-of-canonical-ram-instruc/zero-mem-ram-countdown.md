# The countdown program outputs zero

A random-access machine has a program counter, an accumulator and registers holding natural numbers; it starts with program counter $0$, accumulator $0$ and the inputs in registers $0, 1, \dots$ (other registers $0$), and it has halted once the program counter is at least the length of the program. The countdown program is the five-instruction program: load register $0$ into the accumulator; if the accumulator is $0$ jump to instruction $4$; subtract $1$ from the accumulator; jump to instruction $1$; halt. The output of a program on given inputs, when defined, is the accumulator after the least number of steps at which the machine has halted. For every natural number $n$, the output of the countdown program on the single input $n$ is defined and equals $0$.
