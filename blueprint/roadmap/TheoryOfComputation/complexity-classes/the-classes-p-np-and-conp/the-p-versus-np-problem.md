# The P versus NP question

The P versus NP question asks whether $\mathsf{P} = \mathsf{NP}$, where $\mathsf{P}$ is the class of languages decidable in polynomial time by deterministic Turing machines and $\mathsf{NP}$ the class of languages with polynomial-time verifiers for polynomially bounded certificates. It is one of the Millennium Prize Problems that the Clay Mathematics Institute announced on 24 May 2000. The following are equivalent: $\mathsf{P} = \mathsf{NP}$; some $\mathsf{NP}$-complete language is in $\mathsf{P}$; every $\mathsf{NP}$-complete language is in $\mathsf{P}$.
