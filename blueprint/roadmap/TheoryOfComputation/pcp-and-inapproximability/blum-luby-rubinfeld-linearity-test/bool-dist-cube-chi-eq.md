# Distance to a character

For $f : \{-1, 1\}^n \to \{-1, 1\}$ and every $S$,
$\mathrm{dist}(f, \chi_S) = \tfrac12 - \tfrac12 \hat f(S)$: the Fourier coefficient
$\hat f(S) = \langle f, \chi_S\rangle$ measures the correlation of $f$ with the linear function
$\chi_S$.

## Sources

- Ryan O'Donnell, *Analysis of Boolean Functions*, Cambridge University Press, 2014 (arXiv:2105.10386), Propositions 1.8 and 1.9.
