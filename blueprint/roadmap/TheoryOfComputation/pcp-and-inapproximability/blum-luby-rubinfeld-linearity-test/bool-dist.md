# Relative Hamming distance on the Boolean cube

For $f, g : \{-1, 1\}^n \to \mathbb{R}$, the relative Hamming distance is
$\mathrm{dist}(f, g) = \Pr_x[f(x) \ne g(x)]$ for uniform $x$; $f$ is $\varepsilon$-close to $g$
when $\mathrm{dist}(f, g) \le \varepsilon$.

## Sources

- Ryan O'Donnell, *Analysis of Boolean Functions*, Cambridge University Press, 2014 (arXiv:2105.10386), Definitions 1.10 and 1.29.
