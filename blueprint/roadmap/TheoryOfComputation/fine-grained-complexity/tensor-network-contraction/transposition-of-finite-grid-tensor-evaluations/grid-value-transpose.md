# Transposition preserves the grid evaluation

Let $\rho, \gamma$ be finite linear orders, $\Lambda, \Delta$ finite sets of labels, $R$ a
complete-graph tensor instance on $\rho \times \gamma$ and $G$ a family of rectangle kernels. The
grid value of $R^{\top}$ with kernels $G^{\top}$ (on the grid $\gamma \times \rho$) equals the grid
value of $R$ with kernels $G$, both with edge labels $\Lambda$ and diagonal labels $\Delta$.
