# Number of states of a merged vertex

Let $N$ be a factored tensor network on a finite linearly ordered vertex set $J$, $\chi : J \to J'$
a map to a linear order, and $s_0, t_0$ default state and label. For every $G \in J'$, the number
of allowed states of $G$ in the network merged along $\chi$ is $\prod_{\chi(a) = G} |S_a|$.
