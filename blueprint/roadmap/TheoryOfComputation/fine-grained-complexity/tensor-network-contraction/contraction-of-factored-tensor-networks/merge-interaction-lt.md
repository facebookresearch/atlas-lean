# Interaction of merged classes in increasing order

Let $N$ be a factored tensor network on a finite linearly ordered vertex set $J$ with interaction
$I$, $\chi : J \to J'$ a map to a linear order, and $s_0, t_0$ default state and label. For all
$G < G'$ in $J'$ and all maps $z, z' : J \to \sigma$, the interaction in the network merged along
$\chi$ satisfies

$$I'_{G,G'}(z, z') = \prod_{\chi(a) = G, \ \chi(b) = G'} I_{a,b}(z(a), z'(b)).$$
