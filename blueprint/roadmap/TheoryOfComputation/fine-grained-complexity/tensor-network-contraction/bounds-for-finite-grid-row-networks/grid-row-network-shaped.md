# Shape bound for the grid row network

Let $g, L, m \in \mathbb{N}$ with $m \ge 1$, let the row set $\rho$ and the column set $\gamma$ both
have $g$ elements, and suppose $|\Lambda| \le 2^L$, $|\Delta| \le 2^L$, $|T_\omega| \le
2^{\kappa_\omega}$ and $\kappa_\omega \le 2 m L$ for every $\omega$. Then the row network built from
$\Lambda, \Delta, R, T, \mathrm{top}, \mathrm{bot}, \kappa, L$ has shape parameter $m g^3 L$.
