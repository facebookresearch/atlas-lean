# Total capacity of the grid row network

Let $g, L \in \mathbb{N}$ and let the row set $\rho$ and the column set $\gamma$ both have $g$
elements. The directed total capacity of the row network built from $\Lambda, \Delta, R, T,
\mathrm{top}, \mathrm{bot}, \kappa, L$ is

$$g^2 (g - 1) L + 2 \sum_{\omega} \kappa_\omega,$$

the sum over the ordered rectangles $\omega$ of the grid.
