# Capacity bound between grid rows

Let $g, L, m \in \mathbb{N}$ with $m \ge 1$, let the column set $\gamma$ have $g$ elements, and
suppose the capacities satisfy $\kappa_\omega \le 2 m L$ for every $\omega$. Then in the row network
built from $\Lambda, \Delta, R, T, \mathrm{top}, \mathrm{bot}, \kappa, L$, every capacity satisfies
$c_{a,b} \le g^2 m L$.
