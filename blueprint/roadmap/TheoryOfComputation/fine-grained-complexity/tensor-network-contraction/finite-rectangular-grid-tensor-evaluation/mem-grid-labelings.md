# Characterization of directed grid labelings

For finite sets $\rho$ and $\gamma$, finite sets $\Lambda, \Delta$ in a type $A$ and a matrix $\ell$
indexed by $(\rho \times \gamma) \times (\rho \times \gamma)$ with entries in $A$, $\ell$ is a
directed grid labeling with edge labels $\Lambda$ and diagonal labels $\Delta$ if and only if for
all cells $w, w'$: if $w' = w$ then $\ell(w, w') \in \Delta$, and if $w' \ne w$ then
$\ell(w, w') \in \Lambda$.
