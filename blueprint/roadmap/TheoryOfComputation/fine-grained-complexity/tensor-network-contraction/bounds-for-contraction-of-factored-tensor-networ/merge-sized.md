# Size bound for contracted tensor networks

Let $N$ be a factored tensor network on a finite linearly ordered vertex set $J$ with size
parameters $P, B$, let $\chi : J \to J'$ be a map to a finite linear order such that every class
$\{a : \chi(a) = G\}$ has at most $m$ elements, and let $s_0, t_0$ be default state and label.
Then the network merged along $\chi$ has size parameters $P m$ and $B (m + m^2)$.
