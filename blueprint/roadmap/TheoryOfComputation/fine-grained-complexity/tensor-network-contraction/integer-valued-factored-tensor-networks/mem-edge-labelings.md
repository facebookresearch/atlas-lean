# Characterization of complete-graph edge labelings

Let $J$ be a finite linearly ordered set, $\Lambda$ a finite set of labels in a type $A$ and
$d \in A$. A map $\ell : J \times J \to A$ is an edge labeling of the complete graph on $J$ with
labels $\Lambda$ and default $d$ if and only if for every pair $(a, b)$: if $a < b$ then
$\ell(a, b) \in \Lambda$, and if $a \not< b$ then $\ell(a, b) = d$.
