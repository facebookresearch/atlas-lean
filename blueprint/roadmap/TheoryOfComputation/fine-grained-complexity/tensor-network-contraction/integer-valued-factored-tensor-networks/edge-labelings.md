# Edge labelings of the complete graph

Let $J$ be a finite linearly ordered set, $\Lambda$ a finite set of labels in a type $A$ and
$d \in A$ a default label. The edge labelings of the complete graph on $J$ form the finite set of
maps $\ell : J \times J \to A$ with $\ell(a, b) \in \Lambda$ whenever $a < b$ and $\ell(a, b) = d$
whenever $a \not< b$.
