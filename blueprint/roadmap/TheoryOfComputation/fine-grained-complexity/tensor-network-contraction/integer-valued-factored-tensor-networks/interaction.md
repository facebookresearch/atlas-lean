# Interaction of two states in a factored network

For a factored tensor network on a linearly ordered vertex set, vertices $a, b$ and states
$z, z'$, the interaction is the integer

$$I_{a,b}(z, z') = \sum_{\theta} f_{a,b}(z, \theta) \, f_{b,a}(z', \theta),$$

where $\theta$ ranges over the label set $\Theta_{\min(a,b), \max(a,b)}$ of the pair $\{a, b\}$.
