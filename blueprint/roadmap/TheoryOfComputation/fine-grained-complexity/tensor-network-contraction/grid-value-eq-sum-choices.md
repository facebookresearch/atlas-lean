# Grid value expanded over kernel choices

Let $\rho, \gamma$ be finite linear orders, $\Lambda, \Delta$ finite sets of labels, $R$ a
complete-graph tensor instance on the cells $\rho \times \gamma$ and $G_\omega$ a kernel of four
labels for each $\omega$. Suppose that for each ordered rectangle $\omega$ there are a finite set
$C_\omega$ of choices and kernels $K_{\omega,k}$, $k \in C_\omega$, with
$G_\omega = \sum_{k \in C_\omega} K_{\omega,k}$. Then the grid value with kernels $G$ equals the sum,
over all choice functions $k$ assigning to each ordered rectangle $\omega$ an element
$k(\omega) \in C_\omega$, of the grid value with the kernel $K_{\omega,k(\omega)}$ on each ordered
rectangle $\omega$ (and $G_\omega$ on the other indices, which do not affect the grid value).
