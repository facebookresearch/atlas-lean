# Bijective alphabet padding preserves instance value

Let $R$ be a complete-graph tensor instance on a finite linearly ordered vertex set with labels in
$A$, let $\Lambda$ be a finite set of labels in $A$ and $d \in A$, let $\Lambda'$ be a finite set of
labels in a type $A'$ and $d' \in A'$, and let $D \subseteq \Lambda'$ be finite and
$\delta : A' \to A$ restrict to a bijection from $D$ onto $\Lambda$. Then the value of the padding of
$R$ (with default $d$, names $D$ and renaming $\delta$), taken with labels $\Lambda'$ and default
$d'$, equals the value of $R$ with labels $\Lambda$ and default $d$.
