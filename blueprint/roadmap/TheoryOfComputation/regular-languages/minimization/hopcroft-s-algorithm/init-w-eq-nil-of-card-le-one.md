# No initial Hopcroft splitters with at most one state

Let $M$ be a deterministic finite automaton with a finite input alphabet $\Sigma$, listed in a fixed order, a finite state set $Q$ with $n = |Q|$, transition function $\delta$ and accepting set $F$. For $C \subseteq Q$ and $a \in \Sigma$, $\mathrm{pre}(C, a) = \{q \in Q : \delta(q, a) \in C\}$; a set $X$ splits a block $D$ if $D \cap X$ and $D \setminus X$ are both nonempty; and $\mathrm{sm}(A, B)$ is $A$ if $|A| \le |B|$ and $B$ otherwise. The initial partition is the list $F, Q \setminus F$ with empty blocks removed; the initial waiting list is $(\mathrm{sm}(F, Q \setminus F), b)$ for each letter $b$ in order if $F$ and $Q \setminus F$ are both nonempty, and empty otherwise. If $n \le 1$, the initial waiting list is empty: one of $F$ and $Q \setminus F$ is empty.
