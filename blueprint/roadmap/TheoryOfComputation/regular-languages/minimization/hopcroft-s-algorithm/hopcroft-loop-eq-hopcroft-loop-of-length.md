# Running Hopcroft's loop for the length of its trace gives the same result

Let $M$ be a deterministic finite automaton with a finite input alphabet $\Sigma$, listed in a fixed order, a finite state set $Q$ with $n = |Q|$, transition function $\delta$ and accepting set $F$. For $C \subseteq Q$ and $a \in \Sigma$, $\mathrm{pre}(C, a) = \{q \in Q : \delta(q, a) \in C\}$; a set $X$ splits a block $D$ if $D \cap X$ and $D \setminus X$ are both nonempty; and $\mathrm{sm}(A, B)$ is $A$ if $|A| \le |B|$ and $B$ otherwise. For a waiting list $W$ (a finite list of splitters $(C, b)$ with $C \subseteq Q$, $b \in \Sigma$), a set $X$ and a block $D$, the new splitters are, for each letter $b$ in order, the two entries $(D \cap X, b), (D \setminus X, b)$ if $(D, b)$ occurs in $W$, and the single entry $(\mathrm{sm}(D \cap X, D \setminus X), b)$ otherwise. A round with splitter $(C, a)$ on a partition $P$ (a list of blocks) and remaining waiting list $W$, with $X = \mathrm{pre}(C, a)$, replaces each block $D$ of $P$ split by $X$ by the two blocks $D \cap X$, $D \setminus X$ (in place), and replaces $W$ by the entries of $W$ whose block is not split by $X$, followed, for each block $D$ of $P$ split by $X$ in order, by the new splitters for $W$, $X$ and $D$. The initial partition is the list $F, Q \setminus F$ with empty blocks removed; the initial waiting list is $(\mathrm{sm}(F, Q \setminus F), b)$ for each letter $b$ in order if $F$ and $Q \setminus F$ are both nonempty, and empty otherwise. The loop with fuel $k$ from $(P, W)$ returns $(P, W)$ if $k = 0$, returns $(P, W)$ if $W$ is empty, and otherwise pops the first splitter $(C, a)$ of $W$, performs the round, and continues with fuel $k - 1$. The splitter trace of the loop with fuel $k$ from $(P, W)$ is the list of splitters it pops, in order. For every fuel $k$, partition $P$ and waiting list $W$, let $t$ be the splitter trace of the loop with fuel
$k$ from $(P, W)$. Then the loop with fuel $|t|$ from $(P, W)$ returns the same result as the loop with fuel $k$
from $(P, W)$.
