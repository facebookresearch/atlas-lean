# Initial splitter count is at most one

Let $M$ be a deterministic finite automaton with a finite input alphabet $\Sigma$, listed in a fixed order, a finite state set $Q$ with $n = |Q|$, transition function $\delta$ and accepting set $F$. For $C \subseteq Q$ and $a \in \Sigma$, $\mathrm{pre}(C, a) = \{q \in Q : \delta(q, a) \in C\}$; a set $X$ splits a block $D$ if $D \cap X$ and $D \setminus X$ are both nonempty; and $\mathrm{sm}(A, B)$ is $A$ if $|A| \le |B|$ and $B$ otherwise. The initial partition is the list $F, Q \setminus F$ with empty blocks removed; the initial waiting list is $(\mathrm{sm}(F, Q \setminus F), b)$ for each letter $b$ in order if $F$ and $Q \setminus F$ are both nonempty, and empty otherwise. For $q \in Q$, $b \in \Sigma$ and a list $W$ of splitters, the splitter count $\mathrm{cnt}(q, b, W)$ is the number of entries $(C, b')$ of $W$, counted with multiplicity, with $b' = b$ and $q \in C$. For every $q \in Q$ and $b \in \Sigma$, the initial waiting list $W_0$ satisfies
$\mathrm{cnt}(q, b, W_0) \le 1$.
