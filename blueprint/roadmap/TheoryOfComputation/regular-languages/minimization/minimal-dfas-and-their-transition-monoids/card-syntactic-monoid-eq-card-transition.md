# A minimal automaton has as many word-induced state transformations as the syntactic monoid has elements

A deterministic finite automaton $M$ over an alphabet $\Sigma$ has states, a start state, a transition function and a set of accepting states; it accepts the language $L(M)$. It is accessible when every state is reached from the start state by some word, and state-separated when two states accepting exactly the same words from them are equal. The transition monoid of $M$ is the monoid of the state transformations $T_x : q \mapsto$ (the state reached from $q$ after reading $x$), over all words $x$, with multiplication in reading order, $(f \cdot g)(q) = g(f(q))$, so that $T_{xy} = T_x \cdot T_y$. The syntactic monoid of a language $L$ is the monoid of words modulo the syntactic congruence, which identifies $u$ and $v$ when $xuy \in L \iff xvy \in L$ for all words $x, y$. Let $M$ be accessible and state-separated, and suppose the syntactic monoid of $L(M)$ and the transition monoid of $M$ are finite. Then they have the same number of elements: the number of distinct state transformations induced by words equals the number of syntactic classes.
