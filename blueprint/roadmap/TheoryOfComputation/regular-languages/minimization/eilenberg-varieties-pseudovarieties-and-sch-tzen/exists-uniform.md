# Aperiodicity of a finite monoid is uniform

If a finite monoid is aperiodic, then a single exponent $k$ works for every element: $x^{k+1} = x^k$ for all $x$.

## Sources

- S. Eilenberg, *Automata, Languages, and Machines*, Vol. B, Academic Press, 1976, Chapter V, Example 3.3 (the finite aperiodic monoids are described by the identities $x^{n+1} = x^n$ for a single $n$).
