# Is Aperiodic

A monoid is aperiodic when every element's powers eventually stabilize: for every `x`
there is an `n` with `x ^ (n + 1) = x ^ n`. This is the group-free condition: a finite group
is aperiodic only when it is trivial, since `x ^ (n + 1) = x ^ n` forces `x = 1` when `x` is
a unit. Source: Pin, "Mathematical Foundations of Automata Theory", Definition IV.3.1.
