# Is Star Free

Star-free languages: those built from the empty language and the one-letter languages $\{a\}$, one for each letter $a$, by complement, union and concatenation, with no Kleene star. The language containing only the empty word is not a generator. Source: Schützenberger, "On finite
monoids having only trivial subgroups", Information and Control 8 (1965), 190-194.
