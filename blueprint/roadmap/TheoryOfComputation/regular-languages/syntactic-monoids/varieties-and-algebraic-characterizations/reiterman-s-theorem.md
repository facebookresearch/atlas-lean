# Reiterman's theorem

A class of finite semigroups is a [variety of finite semigroups](varieties-of-finite-monoids.md) if and only if it is the class of all finite semigroups that
satisfy some set of identities $u = v$ with $u$ and $v$ in the free profinite semigroup $\widehat{\Sigma^+}$ on a countable alphabet $\Sigma$, where $S$ satisfies $u = v$
when $\varphi(u) = \varphi(v)$ for every continuous morphism $\varphi : \widehat{\Sigma^+} \to S$ (Reiterman). In the ordered case the identities are inequalities: a class of finite ordered semigroups is a variety of finite ordered semigroups
if and only if it is the class of all finite ordered semigroups satisfying some set of inequalities $u \le v$ with $u, v \in \widehat{\Sigma^+}$, where $S$
satisfies $u \le v$ when $\varphi(u) \le \varphi(v)$ for every continuous morphism $\varphi : \widehat{\Sigma^+} \to S$.
