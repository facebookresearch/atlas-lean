# The language of the empty word is regex-denoted

Let $\alpha$ be an alphabet. A language over $\alpha$ is regex-denoted if it is the language matched by some regular expression over $\alpha$ (regular expressions being built from $0$, $1$ and single letters by sum, concatenation and Kleene star). The language $\{\varepsilon\}$ is regex-denoted (by the expression $1$).
