# Language accepted from a DFA state

Let $\alpha$ be an alphabet. Let $M$ be a deterministic automaton with input alphabet $\alpha$, state set $Q$, transition function $\delta$ and set of accepting states $F$. For $q \in Q$, the language accepted from $q$ is the set $X_q$ of words $w$ over
$\alpha$ such that reading $w$ from $q$ leads to a state in $F$; it is the unknown for $q$ in the equation system of
$M$.
