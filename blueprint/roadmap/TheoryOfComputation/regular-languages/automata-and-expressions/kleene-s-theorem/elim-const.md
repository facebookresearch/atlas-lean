# Constant term after eliminating the last state

Let $\alpha$ be an alphabet, $n \in \mathbb{N}$, and let $A = (A_{ij})_{0 \le i, j \le n}$ and $B = (B_i)_{0 \le i \le n}$
be languages over $\alpha$. Eliminating the last index $n$ gives the constant terms $(B'_i)_{0 \le i < n}$ defined by

$$B'_i = B_i \cup A_{in}\, A_{nn}^*\, B_n.$$
