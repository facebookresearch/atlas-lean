# Letters occurring in a regular expression

Let $\alpha$ be an alphabet. The set of letters of a regular expression over $\alpha$ is the finite set defined
recursively by: $\emptyset$ for $0$ and for $1$; $\{a\}$ for a letter $a$; the union of the sets of $P$ and $Q$ for
$P + Q$ and for $PQ$; and the set of $P$ for $P^*$.
