# Constant term in the equation system of a DFA

Let $\alpha$ be an alphabet. Let $M$ be a deterministic automaton with input alphabet $\alpha$, state set $Q$, transition function $\delta$ and set of accepting states $F$. The constant term of the equation for $X_q$ is the language $\{\varepsilon\}$ if
$q \in F$ and the empty language otherwise.
