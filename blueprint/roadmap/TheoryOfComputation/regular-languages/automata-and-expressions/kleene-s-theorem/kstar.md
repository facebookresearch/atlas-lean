# Regex-denoted languages are closed under Kleene star

Let $\alpha$ be an alphabet. A language over $\alpha$ is regex-denoted if it is the language matched by some regular expression over $\alpha$ (regular expressions being built from $0$, $1$ and single letters by sum, concatenation and Kleene star). If $L$ is a regex-denoted language over $\alpha$, then so is its Kleene star $L^*$.
