# DFA accepting the one-letter words

Let $\alpha$ be an alphabet. The one-letter-word automaton is the deterministic automaton over $\alpha$ with states
$0, 1, 2$, start state $0$, accepting state $1$, and transitions sending state $0$ to $1$ and states $1$ and $2$ to $2$
on every letter. It accepts exactly the one-letter words.
