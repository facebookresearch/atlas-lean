# The one-letter-word DFA accepts exactly words of length one

Let $\alpha$ be an alphabet. The language accepted by the one-letter-word automaton (states $0, 1, 2$, start state $0$,
accepting state $1$, every letter leading from $0$ to $1$ and from $1$ and $2$ to $2$) is the set of words over $\alpha$
of length exactly $1$.
