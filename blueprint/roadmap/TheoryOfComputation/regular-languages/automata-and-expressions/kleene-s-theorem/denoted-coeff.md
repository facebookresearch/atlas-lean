# DFA equation coefficients are regex-denoted

Let $\alpha$ be a finite alphabet. A language over $\alpha$ is regex-denoted if it is the language matched by some regular expression over $\alpha$ (regular expressions being built from $0$, $1$ and single letters by sum, concatenation and Kleene star). Let $M$ be a deterministic automaton with input alphabet $\alpha$, state set $Q$, transition function $\delta$ and set of accepting states $F$. For states $q, j$, the coefficient $A_{qj}$ is the language $\{a : a \in \alpha,\ \delta(q, a) = j\}$ of one-letter words taking $q$ to $j$, and the constant term $B_q$ is $\{\varepsilon\}$ if $q \in F$ and $\emptyset$ otherwise. For all states $q, j$, the coefficient $A_{qj}$ is regex-denoted.
