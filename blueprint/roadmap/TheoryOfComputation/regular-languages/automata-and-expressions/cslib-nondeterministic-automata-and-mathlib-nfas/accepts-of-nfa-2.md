# The two presentations of an automaton with empty moves accept the same language

Let $M$ be a nondeterministic finite-word automaton with empty moves with set-valued transitions, sending a state and a letter or the empty label to a set of states, together with a set of start states and a set of accepting states. Its translation into a relation-valued-transition automaton (a labelled transition relation with start and accepting sets) accepts the same language as $M$.
