# The two presentations of a nondeterministic automaton accept the same language

Let $M$ be a nondeterministic automaton on finite words with set-valued transitions (no finiteness of the states is assumed), sending a state and a letter to a set of states, together with a set of start states and a set of accepting states. Its translation into a relation-valued-transition automaton (a labelled transition relation with start and accepting sets) accepts the same language as $M$. Equivalently, for the inverse translation, the set-valued-transition form of a relation-valued-transition automaton accepts exactly the words $w$ for which some start state reaches some accepting state by a run labelled $w$.
