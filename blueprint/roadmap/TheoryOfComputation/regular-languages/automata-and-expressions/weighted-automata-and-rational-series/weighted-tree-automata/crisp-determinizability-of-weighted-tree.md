# Crisp-determinizability of weighted tree automata is undecidable

No algorithm decides, for a bottom-up deterministic weighted tree automaton over a computable strong bimonoid, whether some
crisp-deterministic automaton has the same initial algebra semantics.

**Theorem.** It is undecidable whether, for a ranked alphabet $\Sigma$, a computable strong bimonoid $B$ and a bottom-up
deterministic $(\Sigma, B)$-wta $\mathcal{A}$, there is a crisp-deterministic $(\Sigma, B)$-wta $\mathcal{B}$ with
$[\![\mathcal{B}]\!]^{\mathrm{i}} = [\![\mathcal{A}]\!]^{\mathrm{i}}$, in the sense of
[weighted tree automata over strong bimonoids](weighted-tree-automata-over-strong-bimonoids.md).

The ranked alphabet, the strong bimonoid and the automaton are all part of the input (the proof uses a strong bimonoid built
from the instance). The problem stays undecidable for arbitrary (not necessarily bottom-up deterministic) wta, and for
weighted string automata. With the same reduction the source shows that it is undecidable whether the Nerode algebra of a
bottom-up deterministic wta is finite, and whether such a wta has the finite order property (which guarantees a
crisp-deterministic wta with the same run semantics).

## Expansion

Reduce Gillibert's theorem: it is undecidable whether the monoid generated by the maps $\nu_q : \Delta^* \to \Delta^*$ induced
by the states of a Mealy machine $\mathcal{M}$ is finite. From $\mathcal{M}$ build a strong bimonoid whose multiplicative part
contains the monoid of all maps $\Delta^* \to \Delta^*$ under composition, with an idempotent addition, and a bottom-up
deterministic wta $\mathcal{A}_\mathcal{M}$ over it whose initial algebra semantics maps each tree to the composite of the
maps along it. A crisp-deterministic wta computes a weighted tree language with finitely many values, and
$[\![\mathcal{A}_\mathcal{M}]\!]^{\mathrm{i}}$ is such a recognizable step mapping exactly when the monoid generated by
$\mathcal{M}$ is finite.
