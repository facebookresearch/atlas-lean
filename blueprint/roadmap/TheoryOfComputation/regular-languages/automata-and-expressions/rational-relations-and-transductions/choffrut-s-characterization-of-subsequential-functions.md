# Choffrut's characterization of subsequential functions

A partial function $\alpha : A^* \to B^*$ is [subsequential](sequential-and-subsequential-functions.md) if and only if it has bounded variation
and $\alpha^{-1}(L)$ is a regular language for every regular language $L \subseteq B^*$ (Choffrut).
