# Synthesis of rational resynchronizers for one-way transducers is undecidable

No algorithm decides, given two real-time one-way transducers, whether some rational resynchronizer makes the origin semantics of the first contained in the resynchronized origin semantics of the second; this holds even when the first transducer is functional and the output alphabet is unary.

**Definitions.** Let $T_1, T_2$ be one-way transducers from $\Sigma^*$ to $\Gamma^*$ in the sense of the source (Section 2), with $\Sigma$ and $\Gamma$ disjoint: every transition $(q, a, q')$ consumes exactly one input letter $a$ and outputs a word of a regular language $L(q, a, q')$, and every final state $q$ adds a final output from a regular language $L(q)$, so a run on $a_1 \cdots a_n$ outputs $v_1 \cdots v_n v_{n+1}$ with $v_{n+1} \in L(q_n)$. Unlike the ε-transitions after the input in the linked definition of transducers, the final output is a separate block. In the [origin semantics](origin-semantics-of-transducers-and-bounded-regu.md), a successful run on input $u$ yields an origin graph: the output word with each output position tagged by the input position that produced it. As on the linked origin-semantics page, inputs are nonempty; the theorem is unaffected, since on the empty input the transducers of the reduction have only the empty output (their final outputs are empty). For one-way transducers and nonempty inputs an origin graph is the same as a *synchronized word* over $\Sigma \uplus \Gamma$, obtained by writing after each input letter the output word produced while reading it, and the final output $v_{n+1}$ after the last input letter, so that its origin is the last input position (as in the origin semantics of one-way transducers). A *resynchronization* is a relation between origin graphs with the same input and the same output word; for a set $S$ of origin graphs, $R(S)$ is the set of graphs $G'$ with $(G, G') \in R$ for some $G \in S$. A *rational resynchronizer* is a one-way transducer over $\Sigma \uplus \Gamma$ that preserves the projections of synchronized words onto $\Sigma$ and onto $\Gamma$. Write $T_1 \subseteq_o S$ if every origin graph of $T_1$ lies in $S$. A transducer is *real-time* if it produces a bounded amount of output for each input letter it consumes. The *synthesis problem for rational resynchronizers* asks, given $T_1$ and $T_2$, whether $T_1 \subseteq_o R(T_2)$ for some rational resynchronizer $R$.

**Theorem.** Synthesis of rational resynchronizers is undecidable for real-time one-way transducers, even when $T_1$ is functional (Corollary 14 of the source).

The reduction produces instances with a unary output alphabet and empty final outputs (Proposition 12 of the source), so the theorem holds already for such transducers. The question lies between classical containment $[\![T_1]\!] \subseteq [\![T_2]\!]$ of one-way transducers, which is undecidable, and origin containment $T_1 \subseteq_o T_2$, which is decidable. By contrast, synthesis of rational resynchronizers is decidable when both transducers are functional (Theorem 7), and more generally finite-valued (Corollary 10).

## Expansion

The source shows that, for real-time one-way transducers with unary output alphabet, synthesis is inter-reducible with *language-boundedness* of one-counter automata: given a one-counter automaton $A$ over $\Omega$ with $L(A) = \Omega^*$, is there a bound $k$ such that every word is accepted by a run whose counter never exceeds $k$? The reductions use one-counter automata that accept with empty counter, so an accepting run starts and ends with counter $0$ (the source's proof of Proposition 12). From $A$ one builds $T_1$, which outputs one letter $c$ per input letter (real-time and functional), and $T_2$, which guesses a run of $A$ and outputs $cc$ on increments, nothing on decrements and $c$ otherwise. Runs of $A$ start with counter $0$, and in this direction the resynchronizer accepts when its simulated counter is back at $0$; since $T_2$ outputs $cc$, nothing or $c$, a run of $T_2$ on an input of length $n$ outputs $n$ plus the net counter change letters, so its output matches the $n$ letters of $T_1$ exactly when the guessed run of $A$ ends with counter $0$. If $A$ is bounded by $k$, a resynchronizer simulating a counter in $[-k, k]$ moves the origins of $T_2$ to those of $T_1$; conversely, by a result of Filiot, Jecker, Löding and Winter (bounded-delay resynchronizers suffice for real-time transducers, Theorem 11 of the source) one may assume a resynchronizer of bounded delay, which yields a bound for $A$. Language-boundedness of one-counter automata is undecidable by a reduction, due to Hofman and proved in the source, from the boundedness problem for Minsky machines; a good expansion links pages for both results.
