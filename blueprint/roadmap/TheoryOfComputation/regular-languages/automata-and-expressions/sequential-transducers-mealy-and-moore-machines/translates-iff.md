# The general translation of a sequential transducer is its own translation

A transducer, in the general sense, is anything that relates input words to output words; its translation relation says which output word it produces from which input word. A sequential transducer has states, a start state, a set of accepting states, a transition function giving for a state and an input letter a next state and an output word, an initial output word, and a final output word for each state. It translates an input word $x$ to an output word $y$ when the state reached from the start state after reading $x$ is accepting and $y$ is the initial output, followed by the outputs emitted while reading $x$, followed by the final output of the reached state. For input and output alphabets in the same universe, viewed as a general transducer, a sequential transducer relates $x$ to $y$ if and only if it translates $x$ to $y$ in this sense.
