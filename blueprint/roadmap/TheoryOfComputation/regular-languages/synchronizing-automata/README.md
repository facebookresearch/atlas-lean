# Synchronizing automata

A deterministic automaton is synchronizing if some word brings every state to the same state. The Černý conjecture asserts that
an $n$-state synchronizing automaton has such a reset word of length at most $(n-1)^2$, a bound attained by the Černý automata; the
best upper bounds known are cubic.
