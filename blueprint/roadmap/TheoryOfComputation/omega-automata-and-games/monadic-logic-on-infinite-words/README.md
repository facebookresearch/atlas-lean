# Monadic logic on infinite words

Monadic second-order logic over the natural numbers with successor and order defines exactly the languages of Büchi
automata, so its theory S1S is decidable, and over infinite words every monadic second-order formula is equivalent to one
whose set quantifiers range over finite sets. The finite-word counterpart is the
[Büchi–Elgot–Trakhtenbrot theorem](../logic-and-tree-automata/buchielgottrakhtenbrot-theorem.md).
