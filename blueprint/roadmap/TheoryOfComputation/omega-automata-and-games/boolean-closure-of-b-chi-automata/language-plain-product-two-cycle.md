# Vardi's plain product is empty

The plain product of the two-state cyclic automata with accepting sets $\{\mathsf{false}\}$
and $\{\mathsf{true}\}$ accepts no word: in the product run both components are in the same
state at every instant, so they are never accepting at the same time.

## Sources

- M. Y. Vardi, "An automata-theoretic approach to linear temporal logic", in *Logics for Concurrency: Structure versus Automata*, LNCS 1043, Springer 1996, pp. 238-266. Numbering from the author's posted version (https://www.cs.rice.edu/~vardi/papers/banff94rj.pdf), which may differ from the published text. Section 2.2, before Proposition 6.
