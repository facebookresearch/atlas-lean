# Timed Büchi automata and timed regular languages

Let $C$ be a finite set of *clocks*. The *clock constraints* over $C$ are generated by
$\delta ::= x \le c \mid c \le x \mid \neg \delta \mid \delta_1 \wedge \delta_2$ with $x \in C$ and $c \in \mathbb{Q}$ a
constant. A *clock interpretation* is a map $\nu : C \to \mathbb{R}$; along a run clocks start at $0$ and are only advanced or reset, so they take nonnegative values; for $t \ge 0$, $\nu + t$ adds $t$ to every clock, and
for $\lambda \subseteq C$, $[\lambda \mapsto 0]\nu$ sets the clocks in $\lambda$ to $0$ and leaves the others unchanged.

A *timed transition table* is a tuple $(\Sigma, S, S_0, C, E)$ of a finite alphabet $\Sigma$, a finite set $S$ of states, a set
$S_0 \subseteq S$ of start states, a finite set $C$ of clocks and a finite set
$E \subseteq S \times S \times \Sigma \times 2^C \times \Phi(C)$ of edges, where $\Phi(C)$ is the set of clock constraints; an edge
$(s, s', a, \lambda, \delta)$ goes from $s$ to $s'$ on the letter $a$, is enabled when the clocks satisfy $\delta$, and resets
the clocks in $\lambda$. A *run* over a [timed word](timed-words-and-timed-languages.md) $(\sigma, \tau)$ is an infinite sequence
$(s_0, \nu_0) (s_1, \nu_1) \cdots$ with $s_0 \in S_0$, $\nu_0(x) = 0$ for every clock and, with $\tau_0 = 0$, for every
$i \ge 1$ an edge $(s_{i-1}, s_i, \sigma_i, \lambda_i, \delta_i) \in E$ such that $\nu_{i-1} + \tau_i - \tau_{i-1}$ satisfies $\delta_i$
and $\nu_i = [\lambda_i \mapsto 0](\nu_{i-1} + \tau_i - \tau_{i-1})$. Its set $\inf(r)$ consists of the states $s$ with $s = s_i$ for
infinitely many $i$.

A *timed Büchi automaton* is a timed transition table together with a set $F \subseteq S$ of accepting states; a run is
accepting when $\inf(r) \cap F \ne \emptyset$, and the automaton accepts the timed language $L(\mathcal{A})$ of the timed words
over which it has an accepting run. A timed language is *timed regular* if it is accepted by some timed Büchi automaton.
