# Nash equilibria in stochastic multiplayer games

Deciding whether a multiplayer game on a finite graph, stochastic or concurrent, has a Nash equilibrium whose payoffs meet given bounds is undecidable for arbitrary, pure and finite-state strategy profiles, and for concurrent games even the existence of an equilibrium is undecidable.
