# Weakly definable tree languages

A set $L$ of infinite binary trees is definable in weak monadic second-order logic over the binary tree, where set quantifiers range only
over finite sets of nodes, if and only if both $L$ and its complement are recognized by Büchi tree automata, in the sense of
[tree automata on infinite trees](tree-automata-on-infinite-trees.md) (Rabin). These form a proper subclass of the recognizable tree
languages.
