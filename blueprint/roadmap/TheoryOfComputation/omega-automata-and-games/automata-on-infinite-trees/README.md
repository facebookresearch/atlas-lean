# Automata on infinite trees

Finite automata running top-down on infinite binary trees, with Muller, Rabin, Streett, parity or Büchi conditions on
every path of a run. Muller, Rabin and parity tree automata recognize the same tree languages, which are closed under
complementation by the positional determinacy of parity games; Büchi tree automata are weaker. Emptiness is decidable and
every nonempty recognizable set contains a regular tree, and monadic second-order logic over the binary tree defines exactly
the recognizable tree languages, so its theory S2S is decidable (Rabin's tree theorem).
