# McNaughton's theorem

The following holds: for all $n, k \in \mathbb{N}$ and every nondeterministic Büchi automaton $A$ with state set $\{0, \dots, n-1\}$ over the alphabet $\{0, \dots, k-1\}$, there are $m \in \mathbb{N}$ and a deterministic Muller automaton $D$ with state set $\{0, \dots, m-1\}$ over the same alphabet such that

$$L_\omega(D) = L_\omega(A).$$

So every ω-regular language is recognized by a finite deterministic Muller automaton.

## Sources

- R. McNaughton, "Testing and generating infinite sequences by a finite automaton", *Information and Control* 9 (1966), 521-530.
