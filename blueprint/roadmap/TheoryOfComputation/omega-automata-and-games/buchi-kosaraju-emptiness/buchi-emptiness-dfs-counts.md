# Step counts of the three depth-first passes of the emptiness check

A directed graph is given by a duplicate-free list of all its vertices and, for each vertex, a list of its successors (its adjacency list); there is an edge from $s$ to $t$ when $t$ occurs in the adjacency list of $s$. The vertex type has a Boolean equality test that agrees with equality and a hash function, so finite sets of vertices can be stored in hash sets. The vertex type also has decidable equality. The Kosaraju–Sharir blocks of a graph are obtained by a first depth-first pass over all vertices, giving the vertices in decreasing finishing order, and a second depth-first pass on the transpose graph with roots taken in that order; the blocks are the trees of the second pass, each listed in preorder. The start-reachable list is the preorder of one depth-first search of the graph whose roots are the vertices satisfying a decidable start predicate, taken in vertex-list order. Depth-first search is modelled as an abstract machine with a work list. For every such graph and decidable start predicate there are numbers $n_1, n_2, n_3$ such that: the first Kosaraju–Sharir pass reaches a final state with empty work list and the whole-graph result in exactly $n_1 = 2V + E$ steps, where $V$ is the number of vertices and $E$ the total length of the adjacency lists; the second pass, on the transpose in decreasing finishing order, does so in exactly $n_2 = R + P + E_2$ steps, where $R$ is the length of that order, $P$ the length of the second pass's preorder and $E_2$ the total length of the transpose adjacency lists over that preorder; and the start-reachability pass does so in exactly $n_3 = S + Q + E_3$ steps, where $S$ is the number of start vertices, $Q$ the length of the start-reachable list and $E_3$ the total length of the adjacency lists of its vertices. These counts do not include the cost of evaluating the adjacency lists.
