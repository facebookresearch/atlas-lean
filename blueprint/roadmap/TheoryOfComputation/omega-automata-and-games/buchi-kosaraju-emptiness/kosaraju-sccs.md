# Kosaraju–Sharir block decomposition

A directed graph is given by a duplicate-free list of all its vertices and, for each vertex, a list of its successors (its adjacency list); there is an edge from $s$ to $t$ when $t$ occurs in the adjacency list of $s$. The vertex type has a Boolean equality test that agrees with equality and a hash function, so finite sets of vertices can be stored in hash sets. The vertex type also has decidable equality. The Kosaraju–Sharir blocks of a graph are obtained by a first depth-first pass over all vertices, giving the vertices in decreasing finishing order, and a second depth-first pass on the transpose graph with roots taken in that order; the blocks are the trees of the second pass, each listed in preorder.
