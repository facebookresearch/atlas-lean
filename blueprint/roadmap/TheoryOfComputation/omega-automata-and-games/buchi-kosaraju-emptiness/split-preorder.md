# Splitting a depth-first preorder into its trees

A directed graph is given by a duplicate-free list of all its vertices and, for each vertex, a list of its successors (its adjacency list); there is an edge from $s$ to $t$ when $t$ occurs in the adjacency list of $s$. The vertex type has a Boolean equality test that agrees with equality and a hash function, so finite sets of vertices can be stored in hash sets. Splitting a preorder at a set of roots walks the preorder while accumulating a current block: a vertex that is a root, met while the current block is nonempty, closes the current block and starts a new one with itself; every other vertex is appended to the current block; at the end a nonempty current block is closed. Each closed block keeps the order of the preorder. The split of a preorder at a list of roots stores the roots in a hash set and runs this walk from an empty current block. In a depth-first preorder the vertices of one tree are contiguous and each tree starts with its root, so splitting at the forest roots recovers the trees.
