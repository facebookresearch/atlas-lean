# Block scan with cost counting

A directed graph is given by a duplicate-free list of all its vertices and, for each vertex, a list of its successors (its adjacency list); there is an edge from $s$ to $t$ when $t$ occurs in the adjacency list of $s$. The vertex type has a Boolean equality test and a hash function, used to store finite sets of vertices in hash sets; the Boolean test need not agree with equality. The vertex type also has decidable equality. The accept-and-reachable test of a block, for a decidable accepting predicate and a hash set $R$ of vertices, asks whether some vertex of the block is accepting and its lookup in $R$ returns true. The costed scan of a list of blocks returns a Boolean and a cost, by recursion on the list: the empty list gives false with cost $0$; for a list starting with a block, it runs the costed Boolean cyclicity test; if the block has length at least $2$ or contains a vertex with a self-loop, it runs the costed accept-and-reachable scan, returning true if that succeeds, and otherwise continuing with the remaining blocks; if the block has length below $2$ and no vertex with a self-loop, it continues with the remaining blocks. Costs of all tests run are added, and the scan stops at the first block that succeeds.
