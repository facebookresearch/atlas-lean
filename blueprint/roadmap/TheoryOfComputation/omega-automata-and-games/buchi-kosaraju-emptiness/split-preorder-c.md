# Splitting a preorder at roots, with cost counting

The vertex type has a Boolean equality test and a hash function, used to store finite sets of vertices in hash sets; the Boolean test need not agree with equality. Splitting a preorder at a set of roots walks the preorder while accumulating a current block: a vertex that is a root, met while the current block is nonempty, closes the current block and starts a new one with itself; every other vertex is appended to the current block; at the end a nonempty current block is closed. Each closed block keeps the order of the preorder. The costed split stores the roots in a hash set and runs the costed split accumulator from an empty current block; it returns the same blocks, with cost equal to the number of roots (one insertion each) plus the tests counted by the accumulator.
