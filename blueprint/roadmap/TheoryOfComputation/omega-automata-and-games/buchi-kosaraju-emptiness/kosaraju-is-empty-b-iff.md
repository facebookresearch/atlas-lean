# The Kosaraju scanner detects reachable accepting cyclic blocks

Let a Büchi automaton have a finite alphabet, a state type with decidable equality, a Boolean equality test agreeing with equality and a hash function, and decidable transitions, and let a duplicate-free list enumerate all its states. Its transition graph is the directed graph on the enumerated states in which the successors of $s$ are the enumerated states $t$ such that some letter takes $s$ to $t$, in enumeration order. Assume membership in the start and accepting sets is decidable. The Kosaraju–Sharir blocks of a graph are obtained by a first depth-first pass over all vertices, giving the vertices in decreasing finishing order, and a second depth-first pass on the transpose graph with roots taken in that order; the blocks are the trees of the second pass, each listed in preorder. A block (a list of vertices) is cyclic when it contains two distinct vertices or a vertex with an edge to itself. Suppose every Kosaraju–Sharir block of the transition graph is duplicate-free. Then the Kosaraju emptiness scanner returns true if and only if there is no block that is cyclic and contains a state that is accepting and reachable from some start state.
