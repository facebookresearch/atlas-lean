# Accept-and-reachable scan with test counting

The vertex type has a Boolean equality test and a hash function, used to store finite sets of vertices in hash sets; the Boolean test need not agree with equality. The accept-and-reachable test of a block, for a decidable accepting predicate and a set $R$ of vertices, asks whether some vertex of the block is accepting and belongs to $R$. The costed scan returns a Boolean answer and a test count, defined by recursion on the block: the empty block gives false with count $0$; for a block starting with $s$, if $s$ is accepting and lies in $R$ the result is true with count $2$; if $s$ is accepting but not in $R$ the result is that of the rest of the block with $2$ added to its count; and if $s$ is not accepting the result is that of the rest with $1$ added. So it stops at the first vertex that is accepting and in $R$.
