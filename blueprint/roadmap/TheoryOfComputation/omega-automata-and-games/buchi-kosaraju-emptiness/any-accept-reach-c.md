# Accept-and-reachable scan with test counting

A directed graph is given by a duplicate-free list of all its vertices and, for each vertex, a list of its successors (its adjacency list); there is an edge from $s$ to $t$ when $t$ occurs in the adjacency list of $s$. The vertex type has a Boolean equality test that agrees with equality and a hash function, so finite sets of vertices can be stored in hash sets. The accept-and-reachable test of a block, for a decidable accepting predicate and a set $R$ of vertices, asks whether some vertex of the block is accepting and belongs to $R$. The costed scan returns a Boolean answer and a test count, defined by recursion on the block: the empty block gives false with count $0$; for a block starting with $s$, if $s$ is accepting and lies in $R$ the result is true with count $2$; if $s$ is accepting but not in $R$ the result is that of the rest of the block with $2$ added to its count; and if $s$ is not accepting the result is that of the rest with $1$ added. So it stops at the first vertex that is accepting and in $R$.
