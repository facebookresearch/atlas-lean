# Kosaraju-based Büchi emptiness scanner

Let a Büchi automaton have a finite alphabet, a state type with decidable equality, a Boolean equality test agreeing with equality and a hash function, and decidable transitions, and let a duplicate-free list enumerate all its states. Its transition graph is the directed graph on the enumerated states in which the successors of $s$ are the enumerated states $t$ such that some letter takes $s$ to $t$, in enumeration order. Assume membership in the start and accepting sets is decidable. The Kosaraju–Sharir blocks of a graph are obtained by a first depth-first pass over all vertices, giving the vertices in decreasing finishing order, and a second depth-first pass on the transpose graph with roots taken in that order; the blocks are the trees of the second pass, each listed in preorder. The start-reachable list is the preorder of one depth-first search of the graph whose roots are the vertices satisfying a decidable start predicate, taken in vertex-list order. The scanner computes the Kosaraju–Sharir blocks of the transition graph and the set of states reachable from a start state, by one depth-first search from the start states, and returns true exactly when no block both passes the Boolean cyclicity test (length at least $2$, or a state with a self-loop) and contains a state that is both accepting and reachable.
