# Cost bound for the costed block scan

A directed graph is given by a duplicate-free list of all its vertices and, for each vertex, a list of its successors (its adjacency list); there is an edge from $s$ to $t$ when $t$ occurs in the adjacency list of $s$. The vertex type has a Boolean equality test and a hash function, used to store finite sets of vertices in hash sets; the Boolean test need not agree with equality. The vertex type also has decidable equality. A block (a list of vertices) is cyclic when it contains two distinct vertices or a vertex with an edge to itself. The accept-and-reachable test of a block, for a decidable accepting predicate and a hash set $R$ of vertices, asks whether some vertex of the block is accepting and its lookup in $R$ returns true. For every list of blocks, the cost of the costed block scan is at most the sum, over the blocks, of $1$ plus the total length of the adjacency lists of the block's vertices plus twice the length of the block.
