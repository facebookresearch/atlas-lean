# The costed split returns the same blocks

The vertex type has a Boolean equality test that agrees with equality and a hash function, so finite sets of vertices can be stored in hash sets. Splitting a preorder at a hash set of roots walks the preorder with an accumulator that holds the pending block in reverse order: at a vertex $v$, when the hash-set lookup of $v$ returns true and the pending block is nonempty, the pending block is emitted reversed and a new pending block $[v]$ starts; otherwise $v$ is put at the front of the pending block; at the end of the preorder a nonempty pending block is emitted reversed (so remaining input $[\,]$ with pending block $[a, b]$ gives $[[b, a]]$). Each emitted block therefore lists its vertices in the order of the preorder. For every list of roots and every preorder, the costed split returns the same blocks as the uncosted split.
