# Splitting a preorder at roots, with test counting

The vertex type has a Boolean equality test and a hash function, used to store finite sets of vertices in hash sets; the Boolean test need not agree with equality. Splitting a preorder at a set of roots walks the preorder while accumulating a current block: a vertex that is a root, met while the current block is nonempty, closes the current block and starts a new one with itself; every other vertex is appended to the current block; at the end a nonempty current block is closed. Each closed block keeps the order of the preorder. The costed split returns the blocks together with a count of Boolean tests, computed by the same recursion: at the end of the preorder it charges $1$ for testing whether the current block is empty; at a vertex that is not a root it charges $1$; and at a root it charges $2$, for the root test and the emptiness test of the current block.
