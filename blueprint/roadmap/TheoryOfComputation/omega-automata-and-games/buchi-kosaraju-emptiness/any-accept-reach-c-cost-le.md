# Cost bound for the accept-and-reachable scan

A directed graph is given by a duplicate-free list of all its vertices and, for each vertex, a list of its successors (its adjacency list); there is an edge from $s$ to $t$ when $t$ occurs in the adjacency list of $s$. The vertex type has a Boolean equality test that agrees with equality and a hash function, so finite sets of vertices can be stored in hash sets. The accept-and-reachable test of a block, for a decidable accepting predicate and a set $R$ of vertices, asks whether some vertex of the block is accepting and belongs to $R$. Scanning a block vertex by vertex with short-circuit evaluation, testing acceptance first and membership in $R$ only for accepting vertices, and stopping at the first success, performs at most two tests per vertex: the number of tests is at most twice the length of the block.
