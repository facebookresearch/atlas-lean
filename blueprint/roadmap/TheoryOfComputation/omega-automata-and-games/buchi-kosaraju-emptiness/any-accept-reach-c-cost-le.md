# Cost bound for the accept-and-reachable scan

The vertex type has a Boolean equality test and a hash function, used to store finite sets of vertices in hash sets; the Boolean test need not agree with equality. The accept-and-reachable test of a block, for a decidable accepting predicate and a hash set $R$ of vertices, asks whether some vertex of the block is accepting and its lookup in $R$ returns true. Scanning a block vertex by vertex with short-circuit evaluation, testing acceptance first and the lookup in $R$ only for accepting vertices, and stopping at the first success, performs at most two tests per vertex: the number of tests is at most twice the length of the block.
