# Cost bound for the costed split

The vertex type has a Boolean equality test and a hash function, used to store finite sets of vertices in hash sets; the Boolean test need not agree with equality. Splitting a preorder at a hash set of roots walks the preorder with an accumulator that holds the pending block in reverse order: at a vertex $v$, when the hash-set lookup of $v$ returns true and the pending block is nonempty, the pending block is emitted reversed and a new pending block $[v]$ starts; otherwise $v$ is put at the front of the pending block; at the end of the preorder a nonempty pending block is emitted reversed (so remaining input $[\,]$ with pending block $[a, b]$ gives $[[b, a]]$). Each emitted block therefore lists its vertices in the order of the preorder. The costed split of a preorder at a list of roots costs at most the number of roots (one hash-set insertion each) plus twice the length of the preorder plus $1$.
