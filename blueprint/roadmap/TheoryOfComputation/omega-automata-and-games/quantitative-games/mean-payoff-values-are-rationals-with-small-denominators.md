# Mean-payoff values are rationals with small denominators

In every finite mean-payoff game the games with objective $\mathrm{MeanPayoff}^+$ and $\mathrm{MeanPayoff}^-$ on the same arena and weights
have the same values, so a positional strategy is optimal for one exactly when it is optimal for the other, and one speaks of
$\mathrm{MeanPayoff}$ without a sign. If the game has $n$ vertices and weights in $[-W, W]$, every value is a rational number in $[-W, W]$
whose denominator is at most $n$: it is the average weight of a simple cycle.
