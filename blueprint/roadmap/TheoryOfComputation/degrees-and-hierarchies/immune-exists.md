# An immune set exists

A set $A \subseteq \mathbb{N}$ is immune when $A$ is infinite and every recursively enumerable set $B \subseteq A$ is finite.

The following holds: there is an immune set $A \subseteq \mathbb{N}$.

## Sources

- R. I. Soare, *Recursively Enumerable Sets and Degrees*, Ch. I, §5.
- H. Rogers, *Theory of Recursive Functions and Effective Computability*, §8.5.
