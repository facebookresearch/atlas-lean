# The effective enumeration of oracle codes is computable

The effective enumeration of oracle codes, which sends $n \in \mathbb{N}$ to the oracle code decoded
from $n$ (or to the basic code $\mathtt{zero}$ when $n$ is the number of no code), is a computable map
from $\mathbb{N}$ to oracle codes.

## Sources

- H. Rogers Jr., *Theory of Recursive Functions and Effective Computability*, McGraw-Hill, 1967 (standard enumerations).
