# The fuel-indexed decoder agrees with the total decoder

Let $\langle a, b \rangle$ denote the pairing function on $\mathbb{N}$, equal to $b^2 + a$ if $a < b$ and to
$a^2 + a + b$ otherwise. For natural numbers $f$, $t$ and $u$ with $\langle t, u \rangle < f$, the
decoder of oracle codes with fuel $f$, applied to the tag $t$ and the payload $u$, returns the oracle
code decoded from the number $\langle t, u \rangle$.
