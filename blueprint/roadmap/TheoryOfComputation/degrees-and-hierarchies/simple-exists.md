# A simple set exists

A set $A \subseteq \mathbb{N}$ is immune if it is infinite and every recursively enumerable set $B \subseteq A$ is finite. A set $P \subseteq \mathbb{N}$ is simple if it is recursively enumerable and its complement $\mathbb{N} \setminus P$ is immune.

Statement: there is a simple set $P \subseteq \mathbb{N}$.

## Sources

- R. I. Soare, Recursively Enumerable Sets and Degrees, Ch. III, Theorem 3.1 (Post's construction).
- H. Rogers, Theory of Recursive Functions and Effective Computability, §8.5.
