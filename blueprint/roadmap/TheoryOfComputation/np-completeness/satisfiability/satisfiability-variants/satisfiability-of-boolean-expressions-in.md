# Instances of SATISFIABILITY OF BOOLEAN EXPRESSIONS

An instance is a triple of a natural number $n$, a list $B$ of natural connective codes and a raw token list (a list of natural pairs), read as the postfix encoding of an expression $E$. A token list may be empty or fail to parse; which expression it represents is defined only when parsing succeeds. That every code is below $16$, that the tokens parse, and the variable and connective bounds belong to [validation](well-formed-2-6.md).
