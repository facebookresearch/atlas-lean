# MAXIMUM NUMBER OF SATISFIABLE FORMULAS is NP-complete

The decision problem MAXIMUM NUMBER OF SATISFIABLE FORMULAS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
