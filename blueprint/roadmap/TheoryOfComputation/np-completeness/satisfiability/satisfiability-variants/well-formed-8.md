# Well-formed instances of SATISFIABILITY OF BOOLEAN EXPRESSIONS OVER A FIXED SET OF CONNECTIVES

For a list $B$ of connective codes, an instance is well-formed when it is well-formed for SATISFIABILITY OF BOOLEAN EXPRESSIONS and every connective code it declares belongs to $B$. This is defined for every list $B$; that $B$ can express $x \land \lnot y$ is a hypothesis of the NP-completeness theorem, not part of well-formedness.
