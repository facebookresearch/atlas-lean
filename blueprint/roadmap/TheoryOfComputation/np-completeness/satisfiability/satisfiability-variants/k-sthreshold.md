# Occurrence threshold f(k)

The supremum $f(k)$ of the set of natural numbers $s$ such that every $(k, s)$-formula is satisfiable, where a set of natural numbers that is empty or unbounded has supremum $0$. For $k \ge 3$ the set contains $0$ and is bounded, so $f(k)$ is its largest element. For $k = 0$ the set is empty, since the formula made of one empty clause is an unsatisfiable $(0, s)$-formula for every $s$, so $f(0) = 0$.
