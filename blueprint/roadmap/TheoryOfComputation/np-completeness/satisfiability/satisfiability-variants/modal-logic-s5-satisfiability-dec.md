# MODAL LOGIC S5-SATISFIABILITY as a decision problem

The decision problem MODAL LOGIC S5-SATISFIABILITY accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a variable count and a postfix token list, to an instance that is [well-formed](well-formed-4-3.md) and [feasible](modal-logic-s5-satisfiability-feasible.md) for MODAL LOGIC S5-SATISFIABILITY. It rejects every bitstring that does not decode to such an instance.
