# ŁUKASIEWICZ LOGIC SATISFIABILITY as a decision problem

The decision problem ŁUKASIEWICZ LOGIC SATISFIABILITY accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of postfix token lists, to an instance that is well-formed and feasible for ŁUKASIEWICZ LOGIC SATISFIABILITY. It rejects every bitstring that does not decode to such an instance.
