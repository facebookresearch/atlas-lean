# Instances of WEIGHTED SATISFIABILITY WITH BOUND

An instance is a quintuple of a number $n$ of variables, the postfix token list of a Boolean expression $F$ (as in SATISFIABILITY OF BOOLEAN EXPRESSIONS), a bound $B$, a list of natural numbers meant as the weights $w(u_0), \dots, w(u_{n-1})$, and a bound $K$. The instance type does not tie the weight list to $n$: with $n = 1$ an empty weight list still decodes. That the list has length $n$ is part of well-formedness.
