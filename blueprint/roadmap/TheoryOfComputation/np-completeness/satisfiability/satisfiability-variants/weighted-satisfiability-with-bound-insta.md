# Instances of WEIGHTED SATISFIABILITY WITH BOUND

An instance is a quintuple of a natural number $n$, a raw token list (a list of natural pairs, read as the postfix encoding of a Boolean expression $F$ as in SATISFIABILITY OF BOOLEAN EXPRESSIONS), a natural bound $B$, a list of natural numbers meant as the weights $w(u_0), \dots, w(u_{n-1})$, and a natural bound $K$. A token list may be empty or fail to parse; which expression it represents is defined only when parsing succeeds. The instance type does not tie the weight list to $n$: with $n = 1$ an empty weight list still decodes. That the tokens parse and that the weight list has length $n$ are part of [validation](well-formed-4-3.md).
