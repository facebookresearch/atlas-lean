# Instances of PROBABILISTIC SATISFIABILITY

An instance is a pair of a number $n$ of variables and a list of clauses $C_i$, each with a pair $(a_i, b_i)$ of natural numbers giving the target probability $a_i / b_i$; [well-formed](well-formed-4-2.md) instances have $0 < b_i$ and $a_i \le b_i$, so that $a_i / b_i \in [0, 1]$.
