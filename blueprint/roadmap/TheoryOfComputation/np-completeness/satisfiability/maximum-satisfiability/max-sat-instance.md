# MAX-SAT instances

A MAX-SAT instance is a triple $(n, \varphi, K)$ of a natural number $n$
(the number of variables), a CNF formula $\varphi$ and a natural number $K$ (the bound).

RENAMABLE HORN SUBFORMULA uses the same triples: a variable count, a disjunctive CNF and a clause threshold. Switching signs and selecting satisfied clauses are tests on such a triple, not fields of it.
