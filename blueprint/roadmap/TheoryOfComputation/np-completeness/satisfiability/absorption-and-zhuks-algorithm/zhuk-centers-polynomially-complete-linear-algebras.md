# Zhuk's centers, polynomially complete algebras and linear quotients

Let $\mathbf{A}=(A;w)$ be a finite idempotent algebra whose basic operation $w$ is a WNU of arity $m$.

- $C\subseteq A$ is a **center** if there exist a finite algebra $\mathbf{B}=(B;w')$ with a WNU $w'$ of the same arity and **no proper binary absorbing subuniverse**, and a subdirect subuniverse $R\le_{sd}\mathbf{A}\times\mathbf{B}$, such that $C=\{a\in A:\ (a,b)\in R\text{ for all }b\in B\}$. Centers are absorbing (indeed ternary absorbing) subuniverses (Zhuk, Corollary 7.10.2).
- $\mathbf{A}$ is **polynomially complete (PC)** if the clone generated by $w$ together with all constant operations on $A$ is the clone of all operations on $A$.
- $\mathbf{A}$ is **linear** if it is isomorphic to $(\mathbb{Z}_{p_1}\times\dots\times\mathbb{Z}_{p_s};\ x_1+\dots+x_m)$ for primes $p_1,\dots,p_s$. Every finite algebra $(B;w)$ has a least congruence $\sigma$ with $(B;w)/\sigma$ linear, the **minimal linear congruence**; every relation on a linear algebra preserved by $x_1+\dots+x_m$ is the solution set of a system of linear equations over the prime fields.

These notions give the four alternatives of Zhuk's published dichotomy proof (Theorem 5.1, stated there for a special WNU, which exists in the clone of any WNU): if $|A|>1$, then $\mathbf{A}$ has a nonempty proper binary absorbing subuniverse, or a nonempty proper center, or a proper congruence $\sigma$ with $\mathbf{A}/\sigma$ polynomially complete, or a proper congruence $\sigma$ with $\mathbf{A}/\sigma\cong(\mathbb{Z}_p;x_1+\dots+x_m)$ for a prime $p$.
