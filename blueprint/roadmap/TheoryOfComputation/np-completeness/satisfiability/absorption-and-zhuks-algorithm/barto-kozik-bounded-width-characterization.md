# Barto–Kozik: CSPs solvable by local consistency are exactly those omitting types 1 and 2

For a finite structure $\mathbb{A}$ and integers $1\le k\le l$, the $(k,l)$-**consistency** algorithm computes the largest family of partial solutions on at most $l$ variables that is closed under restriction to subsets and in which every partial solution on at most $k$ variables extends to any further at most $l$ variables (a Datalog program with rules of width $(k,l)$). $\mathrm{CSP}(\mathbb{A})$ has **bounded width** if for some $(k,l)$ the instance has a solution whenever this family is nonempty. Barto and Kozik prove: for a finite core $\mathbb{A}$, $\mathrm{CSP}(\mathbb{A})$ has bounded width if and only if the variety generated by $(A;\mathrm{Pol}(\mathbb{A}^c))$ omits the unary and affine types (types 1 and 2), equivalently $\mathbb{A}$ has WNU polymorphisms of all but finitely many arities (Maróti–McKenzie). In particular, for cores, systems of linear equations over finite abelian groups are the only obstruction to solvability by local consistency.

## Proof sketch

Necessity: if the variety admits type 1 or 2, a module over a finite ring, hence linear equations over $\mathbb{Z}_p$, is pp-constructible, and such equations are known not to have bounded width. Sufficiency uses absorption: starting from a $(2,3)$-consistent instance, one repeatedly restricts domains to absorbing subuniverses ("Prague strategies") using the absence of affine behaviour, preserving consistency, until all domains are singletons, which then form a solution.
