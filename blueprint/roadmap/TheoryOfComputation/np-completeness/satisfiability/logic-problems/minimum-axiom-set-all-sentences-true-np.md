# MINIMUM AXIOM SET WITH ALL SENTENCES TRUE is NP-complete

The decision problem MINIMUM AXIOM SET WITH ALL SENTENCES TRUE belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [LO17] MINIMUM AXIOM SET, comment on p. 263 ("Remains NP-complete even if T = S").
- P. Pudlák, "Polynomially complete problems in the logic of automated discovery", Mathematical Foundations of Computer Science 1975, Lecture Notes in Computer Science 32, Springer (1975), 358-361, doi:10.1007/3-540-07389-2_221.
