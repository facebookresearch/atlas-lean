# PREDICATE LOGIC WITHOUT NEGATION as a decision problem

The decision problem PREDICATE LOGIC WITHOUT NEGATION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of token lists, to an instance that is [well-formed](well-formed-7.md) and [feasible](predicate-logic-feasible.md) for PREDICATE LOGIC WITHOUT NEGATION. It rejects every bitstring that does not decode to such an instance.
