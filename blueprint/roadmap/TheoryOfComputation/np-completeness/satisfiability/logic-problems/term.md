# Terms inside existential quantifiers

Inside $k$ nested existential quantifiers, code $0$ is the term $c_0$, code $1$ is $c_1$, and code $j + 2$ with $j < k$ is the variable bound by the $(j + 1)$-th quantifier counted from the outermost; a code $j + 2$ with $j \ge k$ gives no term. So at depth two, code $2$ refers to the outer and code $3$ to the inner bound variable.
