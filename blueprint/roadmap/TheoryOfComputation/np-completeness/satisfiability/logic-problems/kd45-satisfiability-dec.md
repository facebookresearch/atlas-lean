# KD45 SATISFIABILITY as a decision problem

The decision problem KD45 SATISFIABILITY accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a variable count and a postfix token list, to an instance that is well-formed for MODAL LOGIC S5 SATISFIABILITY and [feasible](kd45-satisfiability-feasible.md) for KD45 SATISFIABILITY. It rejects every bitstring that does not decode to such an instance.
