# Instances of TRUTH-FUNCTIONALLY COMPLETE CONNECTIVES

An instance is a pair of a natural number $n$ and a list $C$ of raw token lists, each a list of natural pairs, read as the postfix encodings of expressions. A token list may be empty or fail to parse; which expression it represents is defined only when parsing succeeds. Successful parsing and the variable bound belong to [validation](well-formed-3-5.md).
