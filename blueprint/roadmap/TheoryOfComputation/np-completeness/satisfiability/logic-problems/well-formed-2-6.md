# Well-formed instances of TRUTH-FUNCTIONALLY COMPLETE CONNECTIVES FOR TWO DISTINCT ENCODINGS

An instance is well-formed when every member of $C$ is the postfix token encoding of an expression over $u_0, \dots, u_{n-1}$, and $C$ consists of exactly two encodings that are different as token lists. Two different encodings can decode to the same expression (for instance, two token lists for the same NAND expression that differ only in the token used for a negation), so this does not require $C$ to contain two distinct expressions.
