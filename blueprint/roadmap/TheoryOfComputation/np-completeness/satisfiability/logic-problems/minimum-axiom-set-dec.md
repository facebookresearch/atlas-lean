# MINIMUM AXIOM SET as a decision problem

The decision problem MINIMUM AXIOM SET accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quadruples $(|S|, T, R, K)$, to an instance that is [well-formed](well-formed-6.md) and [feasible](minimum-axiom-set-feasible.md) for MINIMUM AXIOM SET. It rejects every bitstring that does not decode to such an instance.
