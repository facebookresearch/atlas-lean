# Instances of VALIDITY OF NEGATION-FREE EXISTENTIAL SENTENCES WITH TWO CONSTANTS

An instance is a list of tokens $(\mathit{code}, a, b)$ of natural numbers, read in prefix notation as a sentence of first-order logic with equality over the language with two constant symbols $c_0$ and $c_1$ and no function or relation symbols. The sentences it can spell are built from equations between terms, conjunction, disjunction and existential quantification; there is no negation, no universal quantifier and no relation symbol.
