# Feasible instances of MINIMUM DISTINGUISHED ONES

An instance $(n, Z, C, K)$ is feasible when some assignment of $n$ truth values satisfies every clause of $C$ (variables beyond the assignment read as false) and the number of entries $z$ of the list $Z$ with $z$ set to true is at most $K$. The count is over list entries: if $Z = [0, 0]$ and $x_0$ is true, the count is $2$. Well-formed instances list each variable of $Z$ once.
