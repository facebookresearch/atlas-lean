# Instances of MINIMUM AXIOM SET

An instance is a quadruple of a natural number $|S|$, a list $T$ of natural sentence labels, a list $R$ of pairs (a list of natural premise labels, a natural conclusion label) and a natural bound $K$. The labels are raw: with $|S| = 0$ the list $T$ can still store sentence label $7$. That every label is a sentence below $|S|$ and that $0 < K \le |S|$ belong to [validation](well-formed-6.md).
