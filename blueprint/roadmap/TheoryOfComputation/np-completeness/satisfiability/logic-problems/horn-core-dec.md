# HORN CORE as a decision problem

The decision problem HORN CORE accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples of a variable count, a list of assignments and a bound, to an instance that is [well-formed](well-formed-2-2.md) and [feasible](horn-core-feasible.md) for HORN CORE. It rejects every bitstring that does not decode to such an instance.
