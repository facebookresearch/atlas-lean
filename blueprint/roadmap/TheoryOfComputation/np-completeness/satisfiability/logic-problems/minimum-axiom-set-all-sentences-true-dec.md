# MINIMUM AXIOM SET WITH ALL SENTENCES TRUE as a decision problem

The decision problem MINIMUM AXIOM SET WITH ALL SENTENCES TRUE accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quadruples $(|S|, T, R, K)$, to an instance that is [well-formed](well-formed-3-3.md) for MINIMUM AXIOM SET WITH ALL SENTENCES TRUE and feasible for MINIMUM AXIOM SET. It rejects every bitstring that does not decode to such an instance.
