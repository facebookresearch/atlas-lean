# Prefix token list of a simple-function expression

For INEQUIVALENCE OF SIMPLE FUNCTIONS, an expression is a tree built from variables $x_k$ and the operators $s$ (successor), $p$ (predecessor), $\mathrm{plus}$, $\mathrm{div}(\cdot, t)$ and $\mathrm{mod}(\cdot, t)$ for a natural number $t$, $w$, and $\mathrm{select}_i^n$ with $n$ arguments. Its prefix token list writes the operator first and then the token lists of its operands in order, using the triples of natural numbers: $(0, k, 0)$ for the variable $x_k$, $(1, 0, 0)$ for $s$, $(2, 0, 0)$ for $p$, $(3, 0, 0)$ for $\mathrm{plus}$, $(4, t, 0)$ for $\mathrm{div}(\cdot, t)$, $(5, t, 0)$ for $\mathrm{mod}(\cdot, t)$, $(6, 0, 0)$ for $w$, and $(7, i, n)$ for $\mathrm{select}_i^n$, where $n$ is the number of its arguments. Each token fixes the arity of its operator, so the token list determines the expression.
