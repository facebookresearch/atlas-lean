# Feasible CONSISTENT FAULT SET instances

An instance $(n, T, t)$ of CONSISTENT FAULT SET is feasible when some set $F$ of at most $t$ units is consistent with the tests: for every test $((u_i, u_j), a_{ij})$ whose tester $u_i$ is not in $F$, the outcome $a_{ij}$ is $1$ if $u_j \in F$ and $0$ if $u_j \notin F$.
