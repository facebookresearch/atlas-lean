# Feasible instances of PROBABILISTIC SATISFIABILITY

An instance is feasible when some probability distribution on the assignments, a weight $\pi(v) \ge 0$ on each assignment $v$ with $\sum_v \pi(v) = 1$, gives every clause $C_i$ the [weight](prob.md) $P_\pi(C_i) = a_i / b_i$, read as $0$ when $b_i = 0$.
