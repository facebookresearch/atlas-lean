# MINIMUM NUMBER OF SATISFIABLE FORMULAS as a decision problem

The decision problem MINIMUM NUMBER OF SATISFIABLE FORMULAS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples of a variable count, a list of CNF formulas and a bound, to an instance that is well-formed and feasible for MINIMUM NUMBER OF SATISFIABLE FORMULAS. It rejects every bitstring that does not decode to such an instance.
