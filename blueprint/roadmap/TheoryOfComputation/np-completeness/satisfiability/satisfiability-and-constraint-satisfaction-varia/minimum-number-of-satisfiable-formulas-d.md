# MINIMUM NUMBER OF SATISFIABLE FORMULAS as a decision problem

The decision problem MINIMUM NUMBER OF SATISFIABLE FORMULAS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples of a variable count, a list of CNF formulas and a bound, to an instance that is [well-formed](well-formed-2-5.md) and [feasible](minimum-number-of-satisfiable-formulas-f.md) for MINIMUM NUMBER OF SATISFIABLE FORMULAS. It rejects every bitstring that does not decode to such an instance.
