# COMPATIBLE BINARY CONSTRAINT SATISFACTION as a decision problem

The decision problem COMPATIBLE BINARY CONSTRAINT SATISFACTION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a binary CSP instance and a bound, to an instance that is [well-formed](well-formed-2.md) and [feasible](compatible-binary-constraint-satisfactio-2.md) for COMPATIBLE BINARY CONSTRAINT SATISFACTION. It rejects every bitstring that does not decode to such an instance.
