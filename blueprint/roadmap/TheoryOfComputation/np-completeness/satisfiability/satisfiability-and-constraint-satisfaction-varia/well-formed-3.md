# Well-formed instances of CONJUNCTIVE SATISFIABILITY WITH FUNCTIONS AND INEQUALITIES

An instance is well-formed when node kinds are $0$, $1$ or $2$; only applications have arguments, all pointing to earlier nodes; unused number fields are $0$; each function symbol has one arity; literal relations are $0$ to $3$ and literal sides are nodes; and every node is used at most once, so the terms are trees.
