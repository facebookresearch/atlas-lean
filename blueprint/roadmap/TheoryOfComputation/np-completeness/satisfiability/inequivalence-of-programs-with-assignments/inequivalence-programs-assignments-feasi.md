# Feasible INEQUIVALENCE OF PROGRAMS WITH ASSIGNMENTS instances

An INEQUIVALENCE OF PROGRAMS WITH ASSIGNMENTS instance is feasible when some initial assignment $a$ of values in $V = \{0, \dots, |V| - 1\}$ to the variables $0, \dots, n - 1$ makes the two programs end with different values in some variable $x < n$; for $|V| = 0 < n$ no such assignment exists. Both programs start from the **same** zero-extended [initial store](initial-store.md), $a(j)$ at $j < n$ and $0$ elsewhere, and run left to right. A raw program may read an address outside $X$ into an in-range output; validation excludes such programs.
