# Instances of ALLEN INTERVAL ALGEBRA SATISFIABILITY

An instance is a pair of a natural number $n$ and a list of assertions $(i, j, R)$, each a pair of natural indices and a list $R$ of natural codes, read as the simple Allen relations allowed between $I_i$ and $I_j$. The data are raw: an index need not be below $n$, and a code can be $13$ or larger, although only $0, \dots, 12$ name simple relations. Legal codes and index bounds belong to [validation](well-formed.md).
