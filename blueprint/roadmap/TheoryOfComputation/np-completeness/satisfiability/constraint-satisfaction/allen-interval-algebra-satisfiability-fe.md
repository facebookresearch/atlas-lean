# Feasible instances of ALLEN INTERVAL ALGEBRA SATISFIABILITY

An instance $(n, A)$ is feasible when some assignment $I$ of a pair of reals $I_k = (l_k, r_k)$ to every natural number $k$, with $l_k < r_k$ for every $k < n$, satisfies every assertion: for $(i, j, R) \in A$, some relation of $R$ holds between $I_i$ and $I_j$. Positive length is required only for indices below $n$: with $n = 0$ an assertion that index $0$ meets itself is satisfied by the pair $(0, 0)$, which no interval of positive length can do. Well-formed instances use only indices below $n$.
