# Affine relations

A stored relation $(k, R)$ is affine when some system $Ax = b$ of linear equations over $\mathrm{GF}(2)$ in the coordinates $0, \dots, k-1$ has as solutions exactly the tuples $t$ for which $[t(0), \dots, t(k-1)]$ is a row of $R$. Rows of other lengths are ignored, so a relation whose only row has the wrong length is represented by an inconsistent system.
