# Feasible instances of COMPATIBLE BINARY CONSTRAINT SATISFACTION

An instance is feasible when some set $U$ of at least $K$ variables, each below the number of domains, has an assignment giving each variable of $U$ a value of its domain such that every listed constraint whose two variables both lie in $U$ is satisfied. Pairs of $U$ with no listed constraint impose nothing: two singleton domains, no constraints and $K = 2$ form a feasible instance. Well-formed instances list a constraint for every pair of variables.
