# Cores of finite relational structures

A finite structure $\mathbb{A}$ is a **core** if every endomorphism $e:\mathbb{A}\to\mathbb{A}$ is a bijection (equivalently, an automorphism). A **core of** $\mathbb{A}$ is a substructure $\mathbb{C}\subseteq\mathbb{A}$, induced on the image $e(A)$ of an endomorphism $e$ of minimal image size, which is itself a core. This extends the graph-theoretic notion of the core of a graph to arbitrary finite relational signatures. Two structures are **homomorphically equivalent** if $\mathbb{A}\to\mathbb{B}$ and $\mathbb{B}\to\mathbb{A}$.
