# FIRST ORDER SUBSUMPTION WITH n TARGETS is NP-complete

For every natural number $n \ge 3$, the decision problem FIRST ORDER SUBSUMPTION WITH n TARGETS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
