# FIRST ORDER SUBSUMPTION as a decision problem

The decision problem FIRST ORDER SUBSUMPTION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quadruples (function-symbol arities, a variable count, pattern token lists and target token lists), to an instance that is [well-formed](well-formed-4.md) and [feasible](first-order-subsumption-feasible.md) for FIRST ORDER SUBSUMPTION. It rejects every bitstring that does not decode to such an instance.
