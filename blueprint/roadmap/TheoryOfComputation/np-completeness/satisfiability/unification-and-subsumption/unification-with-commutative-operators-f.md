# Feasible instances of UNIFICATION WITH COMMUTATIVE OPERATORS

An instance is feasible when its token lists spell the pairs $(e_i, f_i)$ and some substitution $I$, defined on all natural-number variables, sends every variable $v$ below the declared variable count $|V|$ to a variable-free expression and makes $I(e_i) \equiv I(f_i)$ for every pair, where $\equiv$ is equality up to commuting the arguments of commutative operators. Images of variables $\ge |V|$ need not be ground; well-formed instances use only variables below $|V|$.
