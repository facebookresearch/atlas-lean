# Instances of FIRST ORDER SUBSUMPTION

An instance is a quadruple of a list of natural arities, a natural number $|U|$, and two lists of raw token lists (each a list of natural pairs), read as the terms $E_1, \dots, E_m$ and $F_1, \dots, F_n$. A token list may be empty or fail to parse; which term it represents is defined only when parsing succeeds. Symbol and variable bounds belong to [validation](well-formed-4.md).
