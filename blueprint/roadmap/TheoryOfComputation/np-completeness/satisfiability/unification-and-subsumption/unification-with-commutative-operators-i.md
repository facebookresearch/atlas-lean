# Instances of UNIFICATION WITH COMMUTATIVE OPERATORS

An instance is a triple of natural numbers $|V|$ and $|C|$ and a list of pairs of raw token lists, read as the prefix encodings of the expressions $(e_i, f_i)$. A token list may be empty or fail to parse; which expression pair it represents is defined only when parsing succeeds. Variable and constant bounds belong to [validation](well-formed-3-6.md).
