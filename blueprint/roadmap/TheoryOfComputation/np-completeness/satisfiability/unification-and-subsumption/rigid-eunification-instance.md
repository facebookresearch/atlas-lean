# Instances of RIGID E-UNIFICATION

An instance is a quintuple of a list of natural arities, a natural number $|V|$, a list of pairs of raw token lists (read as the equations $E$; a list of pairs, not a set) and two raw token lists, read as the terms $s$ and $t$. A token list may be empty or fail to parse; which term or equation it represents is defined only when parsing succeeds. Symbol and variable bounds belong to [validation](well-formed-8.md).
