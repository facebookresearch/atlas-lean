# Is Node

Node `k` of a network over the domain `{0, …, d - 1}`: its parents are distinct nodes `j < k`,
and its table has exactly one row for each instantiation of the parents (rows with distinct
parent values, each of the right length and with values below `d`, and `d ^ |U|` of them), each
row giving a distribution on `{0, …, d - 1}`.
