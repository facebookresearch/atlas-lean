# Encodes

The Bayesian network $b$ agrees with the structure and tables listed in the instance: for every node $k$ and every $j < k$, $j$ is a parent of $k$ exactly when $j$ is listed among the parents of $k$ (listed indices $\ge k$ are not tested), and for every listed table row $(u, \theta)$ and every instantiation $y$ of the parents of $k$ that agrees with $u$, the conditional distribution of node $k$ given $y$ assigns to each value $v$ the probability $a / b$, where $(a, b)$ is entry $v$ of $\theta$ (a missing entry reads as $(0, 1)$, probability $0$). Instantiations covered by no listed row are not constrained. So the listed data determine the network only for [well-formed](well-formed.md) input, whose parents are all earlier and whose table has one row per instantiation of the parents; otherwise several networks, or none, may agree with it.
