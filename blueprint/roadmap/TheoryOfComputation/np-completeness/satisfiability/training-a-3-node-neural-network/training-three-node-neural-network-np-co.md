# TRAINING A 3-NODE NEURAL NETWORK is NP-complete

The TRAINING A 3-NODE NEURAL NETWORK decision problem lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

Instance: a set of training examples on `n` inputs. Question: do there exist linear threshold functions `f₁, f₂, f₃` for the nodes `N₁, N₂, N₃` such that the network produces outputs consistent with the training set?
