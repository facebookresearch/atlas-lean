# Well-formed instances of TWO-LAYER MULTIPLE MODULE ROUTING

An instance of TWO-LAYER MULTIPLE MODULE ROUTING is well formed when every module is a rectangle with `x₁ < x₂` and `y₁ < y₂`, two different modules do not intersect, the terminals are distinct points, every terminal lies on the perimeter of a module, every net label is below `m`, and every net is non-empty.
