# Feasible instances of TWO-LAYER CHANNEL ROUTING

An instance of TWO-LAYER CHANNEL ROUTING is feasible when some trees `T₀, ..., Tₘ₋₁` route the nets: each `Tₖ` is a finite tree in the grid whose leaves are exactly the points of net `k`, every segment lies inside the channel, and two different trees meet only in orthogonal intersections. Feasibility does not include well-formedness; the decision problem requires both.
