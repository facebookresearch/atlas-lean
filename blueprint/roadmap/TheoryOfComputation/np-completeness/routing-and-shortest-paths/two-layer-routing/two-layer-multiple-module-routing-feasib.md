# Feasible instances of TWO-LAYER MULTIPLE MODULE ROUTING

An instance of TWO-LAYER MULTIPLE MODULE ROUTING is feasible when some trees `T₀, ..., Tₘ₋₁` and some rectangle `R` of area at most `B` route the nets: `R` includes every module and every segment, no segment is contained in a module, each `Tₖ` is a finite tree in the grid whose leaves are exactly the points of net `k`, and two different trees meet only in orthogonal intersections. Feasibility does not include well-formedness; the decision problem requires both.
