# Instances of TWO-LAYER CHANNEL ROUTING

An instance of TWO-LAYER CHANNEL ROUTING is a quadruple $(W, m, U, L)$ of the channel width $W$ and the number $m$ of nets, both natural numbers, and two lists $U$ and $L$ of upper and lower terminals. Each terminal is a pair of an $x$-coordinate and a natural net label $k$. The coordinate is any two naturals $(a, b)$ representing the integer $a - b$; the code is not canonical, so $(2, 1)$ and $(1, 0)$ both represent $1$. An upper terminal with coordinate $x$ stands for the grid point $(x, W)$, a lower one for the grid point $(x, 0)$.
