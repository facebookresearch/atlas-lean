# Instances of RURAL POSTMAN

An instance of RURAL POSTMAN is a value of type `ℕ × List (ℕ × ℕ × ℕ) × List (ℕ × ℕ) × ℕ`: vertex count `n` (vertices `Fin n`), the edge list with lengths (an entry `(u, v, l)` is the edge `{u, v}` of length `l`), the required edges `E'` (pairs of endpoints), and the bound `B`.
