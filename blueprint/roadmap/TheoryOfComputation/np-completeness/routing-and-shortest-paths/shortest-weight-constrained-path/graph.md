# The graph of an instance of SHORTEST WEIGHT-CONSTRAINED PATH

For an instance `i` of SHORTEST WEIGHT-CONSTRAINED PATH with `n` vertices, the graph of the instance is the simple graph on `Fin n` in which distinct vertices `u` and `v` are adjacent when `(u, v)` or `(v, u)` is the endpoint pair of a listed edge. Loops, and pairs with an endpoint outside `Fin n`, contribute no edge. It is the [graph of an edge list](../../graph-coloring-and-partitioning/graph-3-coloring/part-01/edge-graph.md) on these vertices and pairs.
