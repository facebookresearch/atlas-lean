# Value of a rational code in TERRAIN GUARDING

In TERRAIN GUARDING, the value of a [rational code](rat-code.md) $((a, b), d)$ is the rational number $(a - b)/d$, with $a - b$ computed as an integer. Every code has a value: when $d = 0$ the value is $0$, since division by zero gives zero. That the denominators are positive is a separate condition of [well-formedness](well-formed.md), not part of the value.
