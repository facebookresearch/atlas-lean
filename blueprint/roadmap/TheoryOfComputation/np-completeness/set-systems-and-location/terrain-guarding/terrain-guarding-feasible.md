# Feasible instances of TERRAIN GUARDING

An instance $(V, G, N, K)$ of TERRAIN GUARDING is feasible when there is a set $S$ of at most $K$ positions in the list $G$ such that, for every entry $p$ of $N$, the guard at some position in $S$ [sees](sees.md) $p$, where guards and points are read as [points of the plane](to-point.md). Feasibility does not include well-formedness; the decision problem requires both.
