# Instances of TERRAIN GUARDING

An instance of TERRAIN GUARDING is a value of type `List (RatCode × RatCode) × List (RatCode × RatCode) × List (RatCode × RatCode) × ℕ`: the terrain vertices `v₁, …, vₙ` in order, the candidate guards `G`, the points `N` to be guarded (all as pairs of rational coordinates), and the bound `K`.
