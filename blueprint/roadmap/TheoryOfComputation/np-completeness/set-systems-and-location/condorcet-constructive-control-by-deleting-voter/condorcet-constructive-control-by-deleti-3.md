# CONDORCET CONSTRUCTIVE CONTROL BY DELETING VOTERS as a decision problem

The CONDORCET CONSTRUCTIVE CONTROL BY DELETING VOTERS decision problem accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of instances, to a well-formed, feasible instance of CONDORCET CONSTRUCTIVE CONTROL BY DELETING VOTERS; it rejects every bitstring that does not decode to an instance.
