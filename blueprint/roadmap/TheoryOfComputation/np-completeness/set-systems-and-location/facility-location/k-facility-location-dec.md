# K-FACILITY LOCATION as a decision problem

The decision problem K-FACILITY LOCATION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples of a matrix and two natural numbers, to an instance that is [well-formed](well-formed-5.md) and [feasible](kfacility-location-feasible.md) for K-FACILITY LOCATION. It rejects every bitstring that does not decode to such an instance.
