# METRIC FACILITY LOCATION is NP-complete

The decision problem METRIC FACILITY LOCATION belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- S. Guha and S. Khuller, "Greedy strikes back: improved facility location algorithms", J. Algorithms 31 (1999), 228-248, doi:10.1006/jagm.1998.0993 (the metric uncapacitated facility location problem, proved max SNP-hard).
- P. Crescenzi and V. Kann (eds.), *A compendium of NP optimization problems* (web edition, 2000), problem MINIMUM FACILITY LOCATION (the same instance; its printed objective differs, see below).
