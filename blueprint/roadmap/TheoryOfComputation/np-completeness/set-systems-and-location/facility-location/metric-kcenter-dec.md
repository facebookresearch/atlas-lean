# METRIC K-CENTER as a decision problem

The decision problem METRIC K-CENTER accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of K-CENTER instances (a distance matrix, a number $k$ and a bound), to an instance that is [well-formed](well-formed-7.md) for METRIC K-CENTER and feasible for K-CENTER. It rejects every bitstring that does not decode to such an instance.
