# METRIC FACILITY LOCATION as a decision problem

The decision problem METRIC FACILITY LOCATION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quintuples $(n, c, F, d, K)$, to an instance that is [well-formed](well-formed-6.md) and [feasible](metric-facility-location-feasible.md) for METRIC FACILITY LOCATION. It rejects every bitstring that does not decode to such an instance.
