# MIN-SUM MULTICENTER as a decision problem

The decision problem MIN-SUM MULTICENTER accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quintuples $(n, E, w, K, B)$, to an instance that is [well-formed](well-formed-8.md) and [feasible](min-sum-multicenter-feasible.md) for MIN-SUM MULTICENTER. It rejects every bitstring that does not decode to such an instance.
