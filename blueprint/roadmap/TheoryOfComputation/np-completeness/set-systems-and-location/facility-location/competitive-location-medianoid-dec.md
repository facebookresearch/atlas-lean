# COMPETITIVE LOCATION (MEDIANOID) as a decision problem

The decision problem COMPETITIVE LOCATION (MEDIANOID) accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of sextuples $(n, E, w, X_p, r, W)$, to an instance that is [well-formed](well-formed-2.md) and [feasible](competitive-location-medianoid-feasible.md) for COMPETITIVE LOCATION (MEDIANOID). It rejects every bitstring that does not decode to such an instance.
