# K-FACILITY DISPERSION as a decision problem

The decision problem K-FACILITY DISPERSION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of K-CENTER instances (a distance matrix, a number $k$ and a bound), to an instance that is [well-formed](well-formed-4.md) and [feasible](kfacility-dispersion-feasible.md) for K-FACILITY DISPERSION. It rejects every bitstring that does not decode to such an instance.
