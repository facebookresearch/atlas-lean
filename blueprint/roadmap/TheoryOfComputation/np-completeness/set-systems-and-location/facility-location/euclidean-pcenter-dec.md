# EUCLIDEAN p-CENTER as a decision problem

The decision problem EUCLIDEAN p-CENTER accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples of a point list, a natural number and a radius pair, to an instance that is [well-formed](well-formed-2-2.md) and [feasible](euclidean-pcenter-feasible.md) for EUCLIDEAN p-CENTER. It rejects every bitstring that does not decode to such an instance.
