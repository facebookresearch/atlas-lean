# Is consideration order in RANKED PAIRS MANIPULATION (single manipulator, co-winner)

In RANKED PAIRS MANIPULATION: for a profile `P` with a finite set of voters, an order of consideration allowed by ranked pairs: a list of ordered pairs of distinct candidates, with no ordered pair occurring twice and exactly one orientation of each pair of distinct candidates, in which each pair `(a, b)` has at least as many votes ranking `a` ahead of `b` as `b` ahead of `a`, and along which the number of votes ranking the first candidate ahead of the second never increases.
