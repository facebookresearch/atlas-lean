# POSSIBLE WINNER for Borda is NP-complete

POSSIBLE WINNER for Borda is NP-complete: the decision problem over bitstrings that accepts exactly the bitstrings that decode to a well-formed instance with a solution lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it. Source: Xia and Conitzer (2011), Theorem 1; Betzler and Dorn (2010).
