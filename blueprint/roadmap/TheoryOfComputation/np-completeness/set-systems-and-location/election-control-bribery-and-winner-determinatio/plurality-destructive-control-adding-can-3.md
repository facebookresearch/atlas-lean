# PLURALITY DESTRUCTIVE CONTROL BY ADDING CANDIDATES is NP-complete

PLURALITY DESTRUCTIVE CONTROL BY ADDING CANDIDATES is NP-complete: the decision problem over bitstrings that accepts exactly the bitstrings that decode to a well-formed instance with a solution lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it. Source: Hemaspaandra, Hemaspaandra and Rothe (2007); Faliszewski, Hemaspaandra, Hemaspaandra and Rothe (2009), Table 1.
