# Line

An equation $a x + b y = c$ is given by three independent natural pairs $(a^+, a^-)$, $(b^+, b^-)$, $(c^+, c^-)$, read as the integers $a = a^+ - a^-$, $b = b^+ - b^-$ and $c = c^+ - c^-$. Every such triple is representable, including $0 x + 0 y = 1$, which is not a line; genuine lines are required only by [validation](well-formed.md).
