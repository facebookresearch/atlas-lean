# DODGSON SCORE as a decision problem

The decision problem DODGSON SCORE accepts a bitstring $x$ exactly when $x$ decodes, under the
canonical bitstring encoding of DODGSON SCORE instances, to an instance that is
[well-formed](well-formed.md) and [feasible](dodgson-score-feasible.md). It rejects every
bitstring that does not decode to an instance.
