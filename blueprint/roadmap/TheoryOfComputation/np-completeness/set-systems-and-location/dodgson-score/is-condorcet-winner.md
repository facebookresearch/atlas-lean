# Is Condorcet Winner

$c$ is a Condorcet winner for the ballots $V$ over $m$ candidates: the ballots are the orders of some profile $R$ (voter $v$ strictly prefers $a$ to $b$ exactly when $a$ comes before $b$ in $v$'s ballot), and in $R$ every candidate whose value is $c$ beats every other candidate by pairwise majority. For $c < m$ this is the ordinary Condorcet-winner condition; for $c \ge m$ no candidate has value $c$, so the majority tests are vacuous and only the existence of the profile is required (for $m = 1$, ballot $[0]$ and $c = 1$ the predicate holds).
