# Exact hitting set

Problem 15 of Karp's 1972 list, which he called HITTING SET: given subsets $U_1, \dots, U_m$ of a finite set, decide whether some set $W$ meets every $U_i$ in exactly one element. Exchanging the roles of sets and elements turns it into EXACT COVER, which is Karp's reduction. It differs from the hitting set problem of later usage, which bounds the size of a set meeting every $U_i$.
