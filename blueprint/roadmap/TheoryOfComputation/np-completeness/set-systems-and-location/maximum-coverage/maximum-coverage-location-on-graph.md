# Points of a network

$(a, b, t)$ is a point of $G$: the vertex $a$ ($a = b$, $t = 0$), or the point of the edge $\{a, b\}$ at distance $t$ from $a$, with $0 \le t \le d(\{a, b\})$. An edge's length is read from the first entry of the edge list with the same endpoints, and is $0$ when no entry has them. A vertex with no listed customer data has gain $0$ and radius $0$.
