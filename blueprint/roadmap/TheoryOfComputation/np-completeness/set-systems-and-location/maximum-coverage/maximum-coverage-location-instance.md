# Instances of MAXIMUM COVERAGE LOCATION ON A NETWORK

An instance of MAXIMUM COVERAGE LOCATION ON A NETWORK consists of the following data: vertex count $n$ (vertices $\{0, \dots, n - 1\}$), the edge list with lengths (an entry $(u, v, l)$ is the edge $\{u, v\}$ of length $l$), the customers of the vertices in order (an entry $(w, a, b)$ is the gain $w$ and the radius $a / b$, computed in the reals, so $0$ when $b = 0$), the number $p$ of facilities, and the target $W$.
