# Well-formed instances of MAXIMUM COVERAGE LOCATION ON A NETWORK

An instance of MAXIMUM COVERAGE LOCATION ON A NETWORK is well-formed when the edge list describes a simple graph on $\{0, \dots, n - 1\}$ (no duplicate edges in either orientation, no self-loops, endpoints in range), and there is one customer per vertex, each with a radius $a / b$ where $0 < a$ and $0 < b$.
