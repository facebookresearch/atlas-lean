# Feasible instances of 2-DIMENSIONAL CONSECUTIVE SETS

An instance of 2-DIMENSIONAL CONSECUTIVE SETS is feasible when some assignment `g` of the symbols to the sets `X_{g(x)}` of a partition puts the elements of each subset `Σⱼ` into distinct sets among `|Σⱼ|` consecutive ones `X_l, ..., X_{l+|Σⱼ|-1}`. Feasibility does not include well-formedness; the decision problem requires both.
