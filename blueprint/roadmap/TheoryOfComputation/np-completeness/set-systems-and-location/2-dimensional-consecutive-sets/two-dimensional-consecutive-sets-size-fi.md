# The 2-DIMENSIONAL CONSECUTIVE SETS with sets of size at most 5 decision problem

The 2-DIMENSIONAL CONSECUTIVE SETS with sets of size at most 5 decision problem accepts a bitstring exactly when it decodes, under the canonical bitstring encoding, to an instance that is well formed and feasible as an instance of 2-DIMENSIONAL CONSECUTIVE SETS. Bitstrings that do not decode to an instance are rejected.
