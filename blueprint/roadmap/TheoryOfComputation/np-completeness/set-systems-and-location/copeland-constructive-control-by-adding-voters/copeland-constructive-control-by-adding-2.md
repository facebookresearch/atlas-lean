# COPELAND^α CONSTRUCTIVE CONTROL BY ADDING VOTERS as a decision problem

For a fixed rational number $\alpha$, the COPELAND^α CONSTRUCTIVE CONTROL BY ADDING VOTERS decision problem with tie value $\alpha$ accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of instances, to an instance that is well-formed and feasible for that tie value; it rejects every bitstring that does not decode to an instance.
