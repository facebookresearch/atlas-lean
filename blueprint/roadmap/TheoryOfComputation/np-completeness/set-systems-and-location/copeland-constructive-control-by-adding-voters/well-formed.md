# Well-formed COPELAND^α CONSTRUCTIVE CONTROL BY ADDING VOTERS instances

An instance $(m, V, W, p, k)$ (the instance format of CONDORCET CONSTRUCTIVE CONTROL BY ADDING VOTERS) is well-formed for the Copeland$^\alpha$ version when every vote in $V$ and $W$ is a permutation of $0, \dots, m-1$ and $p < m$.
