# Symmetric matrices

For a number $n$ and a list $M$ of rows, $M_{kl} = M_{lk}$ for all $k, l < n$, where an entry missing from $M$ reads as $0$. This does not test the shape of $M$: for $n = 2$ the empty list passes. For a matrix with $n$ rows of length $n$, as well-formedness requires, it says that the matrix is symmetric.
