# DYNAMIC STORAGE ALLOCATION as a decision problem

The decision problem DYNAMIC STORAGE ALLOCATION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of an item list $(s, r, d)$ and a storage size $D$, to an instance that is well-formed and feasible for DYNAMIC STORAGE ALLOCATION. It rejects every bitstring that does not decode to such an instance.
