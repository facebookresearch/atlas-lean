# CIRCULAR ONES MATRIX AUGMENTATION as a decision problem

The decision problem CIRCULAR ONES MATRIX AUGMENTATION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of CONSECUTIVE ONES MATRIX AUGMENTATION instances, to an instance that is well-formed for CONSECUTIVE ONES MATRIX AUGMENTATION and [feasible](circular-ones-matrix-augmentation-feasib.md) for CIRCULAR ONES MATRIX AUGMENTATION. It rejects every bitstring that does not decode to such an instance.
