# BALANCED KNOCKOUT TOURNAMENT FIXING as a decision problem

The decision problem BALANCED KNOCKOUT TOURNAMENT FIXING accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(c, P, i^*)$, to an instance that is [well-formed](../part-09/well-formed.md) and [feasible](balanced-knockout-tournament-fixing-feas.md) for BALANCED KNOCKOUT TOURNAMENT FIXING. It rejects every bitstring that does not decode to such an instance.
