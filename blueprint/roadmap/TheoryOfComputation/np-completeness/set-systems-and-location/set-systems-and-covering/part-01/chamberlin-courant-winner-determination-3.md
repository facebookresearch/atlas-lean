# CHAMBERLIN-COURANT WINNER DETERMINATION as a decision problem

The decision problem CHAMBERLIN-COURANT WINNER DETERMINATION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quadruples $(m, V, k, B)$, to an instance that is [well-formed](../part-08/well-formed-2.md) and [feasible](chamberlin-courant-winner-determination-2.md) for CHAMBERLIN-COURANT WINNER DETERMINATION. It rejects every bitstring that does not decode to such an instance.
