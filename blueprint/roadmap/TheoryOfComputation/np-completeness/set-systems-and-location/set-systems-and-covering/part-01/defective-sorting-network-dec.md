# DEFECTIVE SORTING NETWORK as a decision problem

The decision problem DEFECTIVE SORTING NETWORK accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a wire count and a comparator list, to an instance that is [well-formed](../part-08/well-formed-4.md) and [feasible](../part-02/defective-sorting-network-feasible.md) for DEFECTIVE SORTING NETWORK. It rejects every bitstring that does not decode to such an instance.
