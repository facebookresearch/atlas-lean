# COMBINATORIAL AUCTION WINNER DETERMINATION as a decision problem

The decision problem COMBINATORIAL AUCTION WINNER DETERMINATION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(m, \text{bids}, K)$, to an instance that is [well-formed](../part-08/well-formed-3.md) and [feasible](combinatorial-auction-winner-determinati-2.md) for COMBINATORIAL AUCTION WINNER DETERMINATION. It rejects every bitstring that does not decode to such an instance.
