# EXPECTED COMPONENT SUM WITH 0/1 ENTRIES is NP-complete

The decision problem EXPECTED COMPONENT SUM WITH 0/1 ENTRIES belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [SP18] EXPECTED COMPONENT SUM, pp. 224-225 (comment: "NP-complete even if all entries are 0's and 1's.").
