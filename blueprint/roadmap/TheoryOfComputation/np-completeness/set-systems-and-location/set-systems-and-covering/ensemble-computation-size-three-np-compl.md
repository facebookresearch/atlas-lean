# ENSEMBLE COMPUTATION WITH SETS OF SIZE AT MOST THREE is NP-complete

The decision problem ENSEMBLE COMPUTATION WITH SETS OF SIZE AT MOST THREE belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources
