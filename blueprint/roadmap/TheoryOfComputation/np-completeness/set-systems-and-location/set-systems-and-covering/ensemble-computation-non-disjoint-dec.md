# ENSEMBLE COMPUTATION WITHOUT DISJOINTNESS as a decision problem

The decision problem ENSEMBLE COMPUTATION WITHOUT DISJOINTNESS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(m, C, J)$, to an instance that is well-formed and feasible for ENSEMBLE COMPUTATION WITHOUT DISJOINTNESS. It rejects every bitstring that does not decode to such an instance.
