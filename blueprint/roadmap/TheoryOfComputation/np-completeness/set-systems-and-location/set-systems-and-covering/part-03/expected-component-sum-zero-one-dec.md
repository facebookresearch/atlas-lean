# EXPECTED COMPONENT SUM WITH 0/1 ENTRIES as a decision problem

The decision problem EXPECTED COMPONENT SUM WITH 0/1 ENTRIES accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quadruples $(m, C, K, B)$, to an instance that is [well-formed](../part-09/well-formed-7.md) for EXPECTED COMPONENT SUM WITH 0/1 ENTRIES and feasible for EXPECTED COMPONENT SUM. It rejects every bitstring that does not decode to such an instance.
