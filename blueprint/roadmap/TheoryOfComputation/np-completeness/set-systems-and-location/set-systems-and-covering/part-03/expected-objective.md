# Expected objective of a mechanism

The weighted sum $\sum_{\theta_1, \theta_2} p_1(\theta_1) p_2(\theta_2) g(\theta_1, \theta_2, o(\theta_1, \theta_2))$ over the listed types, with the listed prior weights. When each prior is a probability distribution (nonnegative weights summing to $1$), it is the expectation of $g$ under the independent priors; for raw weights it need not be, for example a constant objective $1$ with single-type weights $2$ and $1$ gives $2$.
