# EXPECTED COMPONENT SUM as a decision problem

The decision problem EXPECTED COMPONENT SUM accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quadruples $(m, C, K, B)$, to an instance that is [well-formed](../part-08/well-formed-3-3.md) and [feasible](expected-component-sum-feasible.md) for EXPECTED COMPONENT SUM. It rejects every bitstring that does not decode to such an instance.
