# SET BASIS is NP-complete

The decision problem SET BASIS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [SP7] SET BASIS.
- L. J. Stockmeyer, "The set basis problem is NP-complete", Report RC-5431, IBM Research Center, Yorktown Heights, NY (1975).
