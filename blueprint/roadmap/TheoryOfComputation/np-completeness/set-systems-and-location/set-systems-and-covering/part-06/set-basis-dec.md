# SET BASIS as a decision problem

The decision problem SET BASIS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(m, C, K)$, to an instance that is [well-formed](../part-07/well-formed-10.md) and [feasible](set-basis-feasible.md) for SET BASIS. It rejects every bitstring that does not decode to such an instance.
