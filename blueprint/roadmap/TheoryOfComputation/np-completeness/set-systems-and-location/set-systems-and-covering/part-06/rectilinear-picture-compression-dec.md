# RECTILINEAR PICTURE COMPRESSION as a decision problem

The decision problem RECTILINEAR PICTURE COMPRESSION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a Boolean matrix and a bound, to an instance that is [well-formed](../part-08/well-formed-3-6.md) and [feasible](rectilinear-picture-compression-feasible.md) for RECTILINEAR PICTURE COMPRESSION. It rejects every bitstring that does not decode to such an instance.
