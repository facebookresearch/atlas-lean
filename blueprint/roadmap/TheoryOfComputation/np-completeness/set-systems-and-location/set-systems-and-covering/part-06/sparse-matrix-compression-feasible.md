# Feasible instances of SPARSE MATRIX COMPRESSION

An instance is feasible when some sequence $b$ of $n + K$ integers in $\{0, \dots, m\}$ and row shifts $s(r)$ with $0 \le s(r) < K$ make $a_{rc} = 1$ exactly when $b$ holds $r + 1$ at position $s(r) + c$ (entries missing from $A$ read as $0$, positions beyond $b$ as $0$).
