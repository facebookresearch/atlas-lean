# SET SPLITTING WITH SETS OF SIZE AT MOST THREE is NP-complete

The decision problem SET SPLITTING WITH SETS OF SIZE AT MOST THREE belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), p. 221, problem [SP4] SET SPLITTING (comment: remains NP-complete even if all `c ∈ C` have `|c| ≤ 3`).
- L. Lovász, "Coverings and colorings of hypergraphs", in *Proceedings of the Fourth Southeastern Conference on Combinatorics, Graph Theory, and Computing*, Utilitas Mathematica (1973), 3-12.
