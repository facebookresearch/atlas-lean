# SET SPLITTING WITH SETS OF SIZE AT MOST THREE as a decision problem

The decision problem SET SPLITTING WITH SETS OF SIZE AT MOST THREE accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of SET SPLITTING instances, to an instance that is [well-formed](../part-08/well-formed-3-7.md) for SET SPLITTING WITH SETS OF SIZE AT MOST THREE and feasible for SET SPLITTING. It rejects every bitstring that does not decode to such an instance.
