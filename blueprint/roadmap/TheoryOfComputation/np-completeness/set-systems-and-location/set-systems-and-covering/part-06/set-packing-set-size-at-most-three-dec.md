# SET PACKING WITH SETS OF SIZE AT MOST THREE as a decision problem

The decision problem SET PACKING WITH SETS OF SIZE AT MOST THREE accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of SET PACKING instances, to an instance that is [well-formed](../part-08/well-formed-2-8.md) for SET PACKING WITH SETS OF SIZE AT MOST THREE and feasible for SET PACKING. It rejects every bitstring that does not decode to such an instance.
