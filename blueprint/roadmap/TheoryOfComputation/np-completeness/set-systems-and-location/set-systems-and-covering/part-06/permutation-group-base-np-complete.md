# PERMUTATION GROUP BASE is NP-complete

The decision problem PERMUTATION GROUP BASE belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- K. D. Blaha, "Minimum bases for permutation groups: the greedy approximation", Journal of Algorithms 13 (1992), 297-306, doi:10.1016/0196-6774(92)90020-D.
- P. Crescenzi and V. Kann (eds.), *A compendium of NP optimization problems*, problem MINIMUM PERMUTATION GROUP BASE (section Miscellaneous).
