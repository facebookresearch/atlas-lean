# SET BASIS WITH SETS OF SIZE AT MOST THREE as a decision problem

The decision problem SET BASIS WITH SETS OF SIZE AT MOST THREE accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(m, C, K)$, to an instance that is [well-formed](../part-08/well-formed-4-3.md) for SET BASIS WITH SETS OF SIZE AT MOST THREE and feasible for SET BASIS. It rejects every bitstring that does not decode to such an instance.
