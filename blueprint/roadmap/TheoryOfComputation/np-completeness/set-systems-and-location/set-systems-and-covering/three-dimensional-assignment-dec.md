# 3-DIMENSIONAL ASSIGNMENT as a decision problem

The decision problem 3-DIMENSIONAL ASSIGNMENT accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quintuples $(p, q, r, c, K)$, to an instance that is [well-formed](well-formed-11.md) and [feasible](three-dimensional-assignment-feasible.md) for 3-DIMENSIONAL ASSIGNMENT. It rejects every bitstring that does not decode to such an instance.
