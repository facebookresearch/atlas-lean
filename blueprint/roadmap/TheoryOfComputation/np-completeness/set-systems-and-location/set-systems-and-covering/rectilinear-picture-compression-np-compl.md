# RECTILINEAR PICTURE COMPRESSION is NP-complete

The decision problem RECTILINEAR PICTURE COMPRESSION belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [SR25] RECTILINEAR PICTURE COMPRESSION, p. 232 (reference [Masek, 1978]: W. J. Masek, "Some NP-complete set covering problems", unpublished manuscript, as listed in Garey and Johnson's references; transformation from 3SAT).
