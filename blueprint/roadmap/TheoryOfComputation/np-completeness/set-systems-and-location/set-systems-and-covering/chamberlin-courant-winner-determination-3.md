# CHAMBERLIN-COURANT WINNER DETERMINATION as a decision problem

The decision problem CHAMBERLIN-COURANT WINNER DETERMINATION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quadruples $(m, V, k, B)$, to an instance that is well-formed and feasible for CHAMBERLIN-COURANT WINNER DETERMINATION. It rejects every bitstring that does not decode to such an instance.
