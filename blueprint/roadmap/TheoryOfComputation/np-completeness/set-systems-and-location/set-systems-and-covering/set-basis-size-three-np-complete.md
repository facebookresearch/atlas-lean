# SET BASIS WITH SETS OF SIZE AT MOST THREE is NP-complete

The decision problem SET BASIS WITH SETS OF SIZE AT MOST THREE belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), p. 222, problem [SP7] SET BASIS (comment: remains NP-complete if all `c ∈ C` have `|c| ≤ 3`).
- L. J. Stockmeyer, "The set basis problem is NP-complete", Report RC-5431, IBM Research Center, Yorktown Heights, NY (1975).
