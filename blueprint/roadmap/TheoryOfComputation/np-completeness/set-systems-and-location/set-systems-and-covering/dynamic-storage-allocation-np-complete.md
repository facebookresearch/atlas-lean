# DYNAMIC STORAGE ALLOCATION is NP-complete

The decision problem DYNAMIC STORAGE ALLOCATION belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [SR2] DYNAMIC STORAGE ALLOCATION, p. 226 (reference: [Stockmeyer, 1976b], a private communication; transformation from 3-PARTITION).
