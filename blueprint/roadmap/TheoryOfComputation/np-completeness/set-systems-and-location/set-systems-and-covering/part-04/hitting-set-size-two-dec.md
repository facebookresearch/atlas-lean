# HITTING SET WITH SETS OF SIZE AT MOST TWO as a decision problem

The decision problem HITTING SET WITH SETS OF SIZE AT MOST TWO accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(n, C, K)$, to an instance that is [well-formed](../part-08/well-formed-2-5.md) for HITTING SET WITH SETS OF SIZE AT MOST TWO and feasible for HITTING SET. It rejects every bitstring that does not decode to such an instance.
