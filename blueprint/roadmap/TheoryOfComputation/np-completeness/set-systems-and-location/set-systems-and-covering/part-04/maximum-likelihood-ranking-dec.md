# MAXIMUM LIKELIHOOD RANKING as a decision problem

The decision problem MAXIMUM LIKELIHOOD RANKING accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(n, A, B)$, to an instance that is [well-formed](../part-08/well-formed-4-2.md) and [feasible](maximum-likelihood-ranking-feasible.md) for MAXIMUM LIKELIHOOD RANKING. It rejects every bitstring that does not decode to such an instance.
