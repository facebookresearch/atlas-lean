# HITTING SET WITH SETS OF SIZE AT MOST TWO is NP-complete

The decision problem HITTING SET WITH SETS OF SIZE AT MOST TWO belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [SP8] HITTING SET, p. 222, comment: "Remains NP-complete even if |c| ≤ 2 for all c ∈ C".
- R. M. Karp, "Reducibility among combinatorial problems", in Complexity of Computer Computations (R. E. Miller and J. W. Thatcher, eds.), Plenum Press (1972), 85-103, doi:10.1007/978-1-4684-2001-2_9 (VERTEX COVER).
