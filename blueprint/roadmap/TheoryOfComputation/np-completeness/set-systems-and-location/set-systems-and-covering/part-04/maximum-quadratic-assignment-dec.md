# MAXIMUM QUADRATIC ASSIGNMENT as a decision problem

The decision problem MAXIMUM QUADRATIC ASSIGNMENT accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of QUADRATIC ASSIGNMENT instances, to an instance that is [well-formed](../part-09/well-formed-8.md) and [feasible](maximum-quadratic-assignment-feasible.md) for MAXIMUM QUADRATIC ASSIGNMENT. It rejects every bitstring that does not decode to such an instance.
