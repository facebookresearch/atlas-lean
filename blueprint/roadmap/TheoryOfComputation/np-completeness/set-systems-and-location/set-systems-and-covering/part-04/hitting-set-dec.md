# HITTING SET as a decision problem

The decision problem HITTING SET accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(n, C, K)$, to an instance that is [well-formed](../part-08/well-formed-3-4.md) and [feasible](hitting-set-feasible.md) for HITTING SET. It rejects every bitstring that does not decode to such an instance.
