# SPARSE MATRIX COMPRESSION WITH K = 3 as a decision problem

The decision problem SPARSE MATRIX COMPRESSION WITH K = 3 accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(n, A, K)$, to an instance that is [well-formed](../part-08/well-formed-4-4.md) for SPARSE MATRIX COMPRESSION WITH K = 3 and feasible for SPARSE MATRIX COMPRESSION. It rejects every bitstring that does not decode to such an instance.
