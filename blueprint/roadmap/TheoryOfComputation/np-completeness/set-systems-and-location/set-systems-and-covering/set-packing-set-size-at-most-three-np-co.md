# SET PACKING WITH SETS OF SIZE AT MOST THREE is NP-complete

The decision problem SET PACKING WITH SETS OF SIZE AT MOST THREE belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), p. 221, problem [SP3] SET PACKING (comment: remains NP-complete even if all `c ∈ C` have `|c| ≤ 3`).
- R. M. Karp, "Reducibility among combinatorial problems", in *Complexity of Computer Computations*, Plenum Press (1972), 85-103, doi:10.1007/978-1-4684-2001-2_9.
