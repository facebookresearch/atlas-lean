# ENSEMBLE COMPUTATION as a decision problem

The decision problem ENSEMBLE COMPUTATION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(m, C, J)$, to an instance that is [well-formed](../part-08/well-formed-5-2.md) and [feasible](ensemble-computation-feasible.md) for ENSEMBLE COMPUTATION. It rejects every bitstring that does not decode to such an instance.
