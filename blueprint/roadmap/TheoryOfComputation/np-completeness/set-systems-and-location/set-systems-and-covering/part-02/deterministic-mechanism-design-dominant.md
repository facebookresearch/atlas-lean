# Instances of DETERMINISTIC MECHANISM DESIGN IN DOMINANT STRATEGIES

An instance is a quintuple of a number $m$ of outcomes, the data of two agents, an objective table $g$ (by $\theta_1$, $\theta_2$, outcome), and a goal $G$; the table entries and $G$ are rational codes: a code $((p, q), r)$ of natural numbers stands for the rational $(p - q)/r$, read as $0$ when $r = 0$.
