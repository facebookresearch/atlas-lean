# DYNAMIC STORAGE ALLOCATION WITH SIZES 1 AND 2 as a decision problem

The decision problem DYNAMIC STORAGE ALLOCATION WITH SIZES 1 AND 2 accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of an item list $(s, r, d)$ and a storage size $D$, to an instance that is [well-formed](../part-09/well-formed-5.md) for DYNAMIC STORAGE ALLOCATION WITH SIZES 1 AND 2 and feasible for DYNAMIC STORAGE ALLOCATION. It rejects every bitstring that does not decode to such an instance.
