# MODULARITY MAXIMIZATION as a decision problem

The decision problem MODULARITY MAXIMIZATION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(n, E, K)$, to an instance that is [well-formed](../part-08/well-formed-3-5.md) and [feasible](modularity-maximization-feasible.md) for MODULARITY MAXIMIZATION. It rejects every bitstring that does not decode to such an instance.
