# PERMUTATION GROUP BASE as a decision problem

The decision problem PERMUTATION GROUP BASE accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples of a letter count, generator lists and a bound, to an instance that is [well-formed](../part-08/well-formed-2-7.md) and [feasible](permutation-group-base-feasible.md) for PERMUTATION GROUP BASE. It rejects every bitstring that does not decode to such an instance.
