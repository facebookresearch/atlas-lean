# MICROCODE BIT OPTIMIZATION as a decision problem

The decision problem MICROCODE BIT OPTIMIZATION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(a, C, K)$, to an instance that is [well-formed](../part-08/well-formed-2-6.md) and [feasible](microcode-bit-optimization-feasible.md) for MICROCODE BIT OPTIMIZATION. It rejects every bitstring that does not decode to such an instance.
