# PERMUTATION GENERATION as a decision problem

The decision problem PERMUTATION GENERATION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of an image list and a list of subsets, to an instance that is [well-formed](../part-09/well-formed-9.md) and [feasible](permutation-generation-feasible.md) for PERMUTATION GENERATION. It rejects every bitstring that does not decode to such an instance.
