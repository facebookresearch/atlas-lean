# FAULT DETECTION WITH TEST POINTS as a decision problem

The decision problem FAULT DETECTION WITH TEST POINTS accepts a bitstring $x$ exactly when $x$
decodes, under the canonical bitstring encoding of FAULT DETECTION WITH TEST POINTS instances,
to an instance that is [well-formed](well-formed.md) and
[feasible](fault-detection-with-test-points-feasibl.md). It rejects every bitstring that does
not decode to an instance.
