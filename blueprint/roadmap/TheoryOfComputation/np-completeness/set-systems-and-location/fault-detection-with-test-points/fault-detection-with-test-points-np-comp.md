# FAULT DETECTION WITH TEST POINTS is NP-complete

The decision problem FAULT DETECTION WITH TEST POINTS belongs to NP, and every decision problem
in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [MS19] FAULT DETECTION WITH TEST POINTS (p. 284), credited there to [Ibaraki, Kameda, and Toida, 1977], "NP-complete diagnosis problems on systems graphs", listed in the book's bibliography as an unpublished manuscript (transformation from X3C).
- T. Ibaraki, T. Kameda and S. Toida, "Some NP-complete diagnosis problems on system graphs", *Transactions of the IECE of Japan* E62 (1979), 81-88 (the published version of the manuscript Garey and Johnson cite).
