# Instances of FAULT DETECTION WITH TEST POINTS

An instance of FAULT DETECTION WITH TEST POINTS consists of a natural vertex count $n$, a list of natural pairs (a pair `(u, v)` is read as the arc $u \to v$), natural labels $s$ (source) and $t$ (sink), and a natural bound $K$. The labels need not be vertices below $n$. Range and the other conditions of the usual problem belong to [validation](well-formed.md).
