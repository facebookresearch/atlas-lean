# Well-formed instances of MINIMUM WEIGHT AND/OR GRAPH SOLUTION

An instance of MINIMUM WEIGHT AND/OR GRAPH SOLUTION is well-formed when $s < n$; arcs join vertices below $n$, have positive weights, and have distinct $(\text{tail}, \text{head})$ pairs; the graph is acyclic; $s$ is the only vertex of in-degree $0$; there is one label per vertex; and $0 < K$.
