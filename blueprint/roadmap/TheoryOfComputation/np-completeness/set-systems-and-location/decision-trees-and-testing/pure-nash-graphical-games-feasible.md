# Feasible instances of PURE NASH EQUILIBRIUM in graphical games (3-bounded neighbourhood)

An instance of PURE NASH EQUILIBRIUM in graphical games (3-bounded neighbourhood) is feasible when the game has a pure Nash equilibrium. A player with no listed entry has no actions and no neighbours, the first cell with the key is read (utility $0$ when there is none), and a neighbour index that is not a player contributes action $0$.
