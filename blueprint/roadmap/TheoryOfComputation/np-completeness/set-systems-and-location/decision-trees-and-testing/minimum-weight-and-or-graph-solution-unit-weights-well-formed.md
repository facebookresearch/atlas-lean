# Well-formed instances of MINIMUM WEIGHT AND/OR GRAPH SOLUTION with unit weights

An instance of MINIMUM WEIGHT AND/OR GRAPH SOLUTION with unit weights is well-formed when it is a well-formed MINIMUM WEIGHT AND/OR GRAPH SOLUTION instance ($s < n$; arcs join vertices below $n$, have positive weights and distinct $(tail, head)$ pairs; the graph is acyclic; $s$ is the only vertex of in-degree $0$; one label per vertex; $0 < K$), and every arc $(tail, head, weight)$ has weight $1$.
