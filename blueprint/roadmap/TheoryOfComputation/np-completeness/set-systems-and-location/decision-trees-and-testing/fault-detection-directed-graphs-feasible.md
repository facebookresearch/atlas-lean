# Feasible instances of FAULT DETECTION IN DIRECTED GRAPHS

An instance of FAULT DETECTION IN DIRECTED GRAPHS is feasible when there is a test set $T \subseteq I \times O$ with $|T| \le K$: every pair starts at a vertex of in-degree $0$ and ends at a vertex of out-degree $0$, and every vertex lies on a directed path from the first to the second vertex of some pair.
