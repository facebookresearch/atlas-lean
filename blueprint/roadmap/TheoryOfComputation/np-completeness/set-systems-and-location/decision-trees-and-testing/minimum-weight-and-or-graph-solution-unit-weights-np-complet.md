# MINIMUM WEIGHT AND/OR GRAPH SOLUTION is NP-complete with unit weights

The decision problem MINIMUM WEIGHT AND/OR GRAPH SOLUTION with unit weights belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [MS16] MINIMUM WEIGHT AND/OR GRAPH SOLUTION (p. 283), comment "Remains NP-complete even if w(a) = 1 for all a ∈ A" (credited there to Garey and Johnson, unpublished).
