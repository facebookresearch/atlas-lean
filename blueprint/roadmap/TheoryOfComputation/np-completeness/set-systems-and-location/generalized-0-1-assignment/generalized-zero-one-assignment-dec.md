# GENERALIZED 0-1 ASSIGNMENT as a decision problem

The decision problem GENERALIZED 0-1 ASSIGNMENT accepts a bitstring $x$ exactly when $x$
decodes, under the canonical bitstring encoding of GENERALIZED 0-1 ASSIGNMENT instances, to an
instance that is [well-formed](well-formed.md) and
[feasible](generalized-zero-one-assignment-feasible.md). It rejects every bitstring that does
not decode to an instance.
