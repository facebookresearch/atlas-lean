# Instances of GENERALIZED 0-1 ASSIGNMENT

An instance of GENERALIZED 0-1 ASSIGNMENT consists of $m$, $n$, the matrix $A$ (rows of (positive part, negative part) pairs), the vector $b$ (same encoding), a matrix $C$ given as rows of natural numbers, and the bound $K$. The raw entries of $C$ need not be bits (for example $[[2]]$ decodes); the dimensions of $A$, $b$ and $C$ and the binary entries of $C$ are checked separately by [well-formedness](well-formed.md).
