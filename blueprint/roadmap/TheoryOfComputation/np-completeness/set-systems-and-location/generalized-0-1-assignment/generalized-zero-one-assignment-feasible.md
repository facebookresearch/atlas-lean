# Feasible GENERALIZED 0-1 ASSIGNMENT instances

A 0-1 matrix $X$ of the same size $m \times n$ as $A$, with exactly one $1$ in each column, such that $\sum_j A_{r j} X_{r j} \le b_r$ for every row $r$ (entrywise products summed along the row, not a matrix product), and with total cost $\sum_i \sum_j C_{i j} X_{i j} \le K$.
