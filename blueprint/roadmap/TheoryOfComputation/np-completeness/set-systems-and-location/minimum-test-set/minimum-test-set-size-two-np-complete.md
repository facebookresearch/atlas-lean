# MINIMUM TEST SET with tests of size at most 2 is NP-complete

The decision problem MINIMUM TEST SET with tests of size at most 2 is NP-complete: it belongs to
NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

Source: De Bontridder, Halldórsson, Halldórsson, Hurkens, Lenstra, Ravi and Stougie (2003),
Section 4, which proves the case of tests of size at most $2$ NP-hard and corrects the
polynomial-time claim in Garey and Johnson (1979), [SP6].
