# The decision problem MINIMUM TEST SET FOR LOCATING SINGLE LINK FAILURES

MINIMUM TEST SET FOR LOCATING SINGLE LINK FAILURES as a decision problem on bitstrings: a
bitstring is accepted exactly when it decodes, under the canonical bitstring encoding, to an
instance that is well-formed for FAULT DETECTION IN DIRECTED GRAPHS and feasible. A bitstring
that does not decode to an instance is rejected.
