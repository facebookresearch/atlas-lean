# PLANAR 3-INDEX ASSIGNMENT is NP-complete

PLANAR 3-INDEX ASSIGNMENT is NP-complete: the decision problem over bitstrings that accepts exactly the encodings of well-formed instances with a solution lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it. Source: Frieze (1983); Ćustić, Klinz and Woeginger (2014).
