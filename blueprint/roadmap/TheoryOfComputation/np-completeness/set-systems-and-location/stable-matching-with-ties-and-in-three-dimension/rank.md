# Rank of agent `w` in agent `v`'s preference list in STABLE ROOMMATES WITH TIES (weak stability, complete lists)

For an instance `i` of STABLE ROOMMATES WITH TIES (weak stability, complete lists), the rank of agent `w` in agent `v`'s preference list, given by `(i.2.getD v []).getD w 0`. Positions beyond the end of the lists read as the default entries `[]` and `0`.
