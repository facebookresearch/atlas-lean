# Instances of STABLE ROOMMATES WITH TIES (weak stability, complete lists)

An instance of STABLE ROOMMATES WITH TIES (weak stability, complete lists) is a value of type `ℕ × List (List ℕ)`: the number `n` of agents and the rank table; row `v`, entry `w` is the rank of `w` in agent `v`'s preference list (smaller is better, equal ranks are ties).
