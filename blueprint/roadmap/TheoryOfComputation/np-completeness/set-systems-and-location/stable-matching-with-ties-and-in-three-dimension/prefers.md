# Strict preference in THREE-DIMENSIONAL STABLE MATCHING

In THREE-DIMENSIONAL STABLE MATCHING, under the preference list `r` the pair `x` is strictly preferred to the pair `y` when `x` occurs in `r` before `y`, that is, `r.idxOf x < r.idxOf y`. A pair that does not occur in `r` has index equal to the length of `r`, so it is never preferred to a listed pair.
