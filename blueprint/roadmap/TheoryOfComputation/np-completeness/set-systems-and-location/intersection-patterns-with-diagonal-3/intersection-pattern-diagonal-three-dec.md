# INTERSECTION PATTERN WITH ALL DIAGONAL ENTRIES 3 as a decision problem

The decision problem INTERSECTION PATTERN WITH ALL DIAGONAL ENTRIES 3 accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of lists of rows of natural numbers, to a square matrix with every diagonal entry $3$ that is feasible for INTERSECTION PATTERN. It rejects every bitstring that does not decode to such a matrix.
