# Instances of COVERING POINTS BY LINES

An instance of COVERING POINTS BY LINES is a pair $(P, K)$ of a list $P$ of points in the plane and a natural number $K$, the bound. Each point is a pair of integer coordinates, and each coordinate is given by any two natural numbers $(a, b)$ representing the integer $a - b$; the representation is not canonical, since, for example, $(2, 1)$ and $(1, 0)$ both represent $1$.
