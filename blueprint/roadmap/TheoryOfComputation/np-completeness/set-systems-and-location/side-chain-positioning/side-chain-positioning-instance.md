# Instances of SIDE-CHAIN POSITIONING (PROTEIN DESIGN)

An instance of SIDE-CHAIN POSITIONING (PROTEIN DESIGN) is a value of type `ℕ × List ℕ × List (ℕ × ℕ) × List (List (ℕ × ℕ)) × (ℕ × ℕ)`: the number `p` of positions, the position of each rotamer, the self energies, the pairwise energy matrix (rows and columns indexed by rotamers), and the bound `K`.
