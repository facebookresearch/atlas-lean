# Feasible LOBBYING IN MULTIPLE REFERENDA instances

Some choice of $b$ rows can be changed so that every issue has a strict majority for the target: a set $S$ of $b$ voters and new votes $F$ agreeing with $E$ outside $S$ such that, on every issue $j$, more than half of the $m$ voters vote $Z_j$ (that is, $m < 2\,|\{r : F_{rj} = Z_j\}|$). A tie is a strict majority for neither outcome; for example, with two "yes" votes on one issue, target "no" and $b = 1$, no change succeeds.
