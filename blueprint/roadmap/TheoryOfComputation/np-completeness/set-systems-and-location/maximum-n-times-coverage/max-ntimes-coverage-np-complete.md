# MAXIMUM n-TIMES COVERAGE is NP-complete

The decision problem [MAXIMUM $n$-TIMES COVERAGE](max-ntimes-coverage-dec.md) belongs to NP, and
every decision problem in NP has a polynomial-time many-one reduction to it.

For $n = 1$ and rows with entries $0$ and $1$ it contains maximum coverage, hence SET COVER.

## Sources

- Ge Liu, Alexander Dimitrakakis, Brandon Carter and David Gifford, "Maximum n-times coverage for vaccine design", International Conference on Learning Representations (ICLR 2022), arXiv:2101.10902.
