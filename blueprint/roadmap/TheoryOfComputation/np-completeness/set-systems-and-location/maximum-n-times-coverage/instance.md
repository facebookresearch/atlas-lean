# Instance of maximum n-times coverage

An instance of maximum $n$-times coverage is a tuple $(n, R, w, k, \tau)$ of a natural number $n$
(the coverage threshold), a list $R$ of rows of natural numbers, one row per overlay, whose entry
$e$ is the number of times that overlay covers element $e$, a list $w$ of natural-number element
weights, and natural numbers $k$ (the number of overlays allowed) and $\tau$ (the weight to
reach).
