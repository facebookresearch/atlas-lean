# SET SPLITTING for partial Steiner triple systems is NP-complete

The SET SPLITTING for partial Steiner triple systems decision problem lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

Instance: a set `V` and a collection `C` of `3`-element subsets of `V` such that every pair of elements of `V` lies in at most one member of `C` (a partial Steiner triple system). Question: can `V` be partitioned into two sets so that no member of `C` lies entirely within one of them?
