# SET SPLITTING is NP-complete

The SET SPLITTING decision problem belongs to NP, and every
decision problem in NP reduces to it by a polynomial-time many-one reduction.

## Sources

- Michael R. Garey and David S. Johnson, *Computers and Intractability* (1979), SET SPLITTING (hypergraph 2-coloring); László Lovász, "Coverings and colorings of hypergraphs" (1973).
