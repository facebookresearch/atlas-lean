# The SET SPLITTING for partial Steiner triple systems decision problem

The SET SPLITTING for partial Steiner triple systems decision problem accepts a bitstring exactly when it decodes, under the canonical bitstring encoding, to an instance $(n, C)$ that is [well formed for partial Steiner triple systems](well-formed-2.md) (that is, [well formed](well-formed.md) as an instance of SET SPLITTING, and the members of $C$, read as subsets of $\{0, \dots, n-1\}$, form a linear triple system: each has exactly three elements and two distinct ones share at most one element) and [feasible](set-splitting-feasible.md) as an instance of SET SPLITTING. Bitstrings that do not decode to an instance are rejected, and so are decoded instances whose members do not form a linear triple system, even when they can be split.
