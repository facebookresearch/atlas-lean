# Cost in PLANAR 3-INDEX ASSIGNMENT

In PLANAR 3-INDEX ASSIGNMENT: the cost `c_{ijk}` as an integer: the entry at position `(i n + j) n + k` of the cost list, a pair `(p, q)` read as `p - q`. A list entry that is not present (an index beyond the end of its list) reads as $(0, 0)$, that is, the cost $0$.
