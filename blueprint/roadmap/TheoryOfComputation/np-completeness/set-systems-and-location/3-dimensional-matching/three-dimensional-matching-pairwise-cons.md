# The 3-DIMENSIONAL MATCHING for pairwise consistent triples decision problem

The 3-DIMENSIONAL MATCHING for pairwise consistent triples decision problem accepts a bitstring exactly when it decodes, under the canonical bitstring encoding, to an instance $(n, T)$ that is [well formed for pairwise consistent triples](well-formed-2.md) (that is, [well formed](well-formed.md) as an instance of 3-DIMENSIONAL MATCHING, and the list of triples $T$ is [pairwise consistent](pairwise-consistent.md): whenever $(a, b, w)$, $(a, x, c)$ and $(y, b, c)$ are in $T$, so is $(a, b, c)$) and [feasible](three-dimensional-matching-feasible.md) as an instance of 3-DIMENSIONAL MATCHING. Bitstrings that do not decode to an instance are rejected, and so are decoded instances whose triples are not pairwise consistent, even when they have a perfect matching.
