# Incidence graph in PLANAR 3-DIMENSIONAL MATCHING

In PLANAR 3-DIMENSIONAL MATCHING: the element-triple incidence graph: vertex `3q + j` (the `j`-th triple `(w, x, y)`) is adjacent to the element vertices `w`, `q + x` and `2q + y`. A list entry that is not present (an index beyond the end of its list) reads as $(0, 0, 0)$.
