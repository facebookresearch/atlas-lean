# Feasible instances of INTERSECTION PATTERN

An $n \times n$ matrix $A = (a_{ij})$ is feasible for INTERSECTION PATTERN when there are finite sets $C_0, \dots, C_{n-1}$ with $|C_i \cap C_j| = a_{ij}$ for all $i, j$ (in particular $|C_i| = a_{ii}$). Entries outside the listed rows and columns count as $0$; for a well-formed (square) instance every entry is listed.
