# INTERSECTION PATTERN is NP-complete

The following decision problem is NP-complete: it belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it. Given a square matrix $A = (a_{ij})$ of natural numbers, decide whether there are finite sets $C_1, \dots, C_n$ with $|C_i \cap C_j| = a_{ij}$ for all $i$ and $j$.
