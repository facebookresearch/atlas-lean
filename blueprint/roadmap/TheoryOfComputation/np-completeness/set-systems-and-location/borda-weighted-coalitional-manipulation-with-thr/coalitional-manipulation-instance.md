# Instances of CONSTRUCTIVE COALITIONAL WEIGHTED MANIPULATION with three candidates

An instance of CONSTRUCTIVE COALITIONAL WEIGHTED MANIPULATION with three candidates is a triple $(S, T, p)$ of a list $S$ of the nonmanipulators' votes, each a ranking of the candidates $0, 1, 2$ (most preferred first) with a weight, a list $T$ of the weights of the manipulators' votes, and the preferred candidate $p$.
