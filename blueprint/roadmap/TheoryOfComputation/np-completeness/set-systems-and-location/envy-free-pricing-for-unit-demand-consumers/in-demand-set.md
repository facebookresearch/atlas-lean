# Demand sets of unit-demand consumers

For a consumer with valuation list $v$ and item prices $p$, write $u(j) = v_j - p_j$ for the
utility of item $j$ as an integer, where $v_j$ is $0$ when the list $v$ has fewer than $j+1$
entries. Buying nothing, with utility $0$, is in the demand set when $u(j) \le 0$ for every item
$j$; buying item $j$ is in the demand set when $u(j) \ge 0$ and $u(j') \le u(j)$ for every item
$j'$.
