# Instances of IWD-STRATEGY-ELIMINATION (eliminability by iterated weak dominance)

An instance: the number `m` of row strategies, the number `n` of column strategies, the utility
table (row `r`, entry `c` holds the row player's and the column player's utilities at `(r, c)`,
each as a `(positive part, negative part)` pair), the player who owns the distinguished strategy
(`false`: row player, `true`: column player), and the index of the distinguished strategy.
