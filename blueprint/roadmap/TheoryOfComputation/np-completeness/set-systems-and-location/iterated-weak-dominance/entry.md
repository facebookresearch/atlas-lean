# Entry

The table entry at row $r$ and column $c$: entry $c$ of row $r$ of the utility table, a pair
whose first component encodes the row player's utility and whose second component encodes the
column player's utility, each as a (positive part, negative part) pair. A position outside the
table reads as $((0, 0), (0, 0))$, that is, utility $0$ for both players.
