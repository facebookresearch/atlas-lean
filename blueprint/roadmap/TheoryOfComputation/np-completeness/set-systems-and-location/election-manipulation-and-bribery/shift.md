# Vote `v` after shifting `p` up by `k` places in SHIFT BRIBERY for Borda

In SHIFT BRIBERY for Borda, the vote `v` after shifting `p` up by `k` places: `p` is removed and reinserted at index `j - k`, where `j` is its index in `v`. Subtraction is natural-number subtraction, so `a - b = 0` whenever `a ≤ b`.
