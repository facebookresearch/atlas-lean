# Feasible instances of SECOND-ORDER COPELAND MANIPULATION (unique winner)

An instance of SECOND-ORDER COPELAND MANIPULATION (unique winner) is feasible when some order of the manipulator (the last voter) makes `p` the unique winner, the other voters voting their sincere orders: voter `k` prefers `a` to `b` exactly when `a` comes before `b` in the `k`-th vote. Feasibility does not include well-formedness; the decision problem requires both.
