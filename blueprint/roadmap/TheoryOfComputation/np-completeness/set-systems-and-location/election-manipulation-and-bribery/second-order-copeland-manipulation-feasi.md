# Feasible instances of SECOND-ORDER COPELAND MANIPULATION (unique winner)

An instance $(C, V, p)$ of SECOND-ORDER COPELAND MANIPULATION (unique winner) is feasible when $p \in C$ and there is a profile of strict total orders on the [candidates](candidate.md) (the distinct numbers occurring in the list $C$), with one voter for each entry of $V$ in order plus the manipulator as the last voter, such that $p$ is the [unique second-order Copeland winner](is-unique-winner.md) and each sincere voter $k$ prefers $a$ to $b$ exactly when $\operatorname{idx}_k(a) < \operatorname{idx}_k(b)$. Here $\operatorname{idx}_k(a)$ is the zero-based index of the first occurrence of $a$ in the $k$-th vote of $V$, or the length of that vote if $a$ does not occur in it; for example, with ballot $[a]$ and candidates $a, b$, the omitted $b$ has index one, so that voter must prefer $a$ to $b$. The manipulator's order is any strict total order on the candidates. Feasibility does not include well-formedness; the decision problem requires both.
