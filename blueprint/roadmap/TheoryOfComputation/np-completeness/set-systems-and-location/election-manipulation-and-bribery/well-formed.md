# Well-formed instances of SECOND-ORDER COPELAND MANIPULATION (unique winner)

An instance of SECOND-ORDER COPELAND MANIPULATION (unique winner) is well formed when the candidates are distinct, every sincere vote is a permutation of the candidates, and `p` is a candidate.

SINGLE TRANSFERABLE VOTE MANIPULATION uses this same test on the same encoded triple: the candidates are listed without repetition, the distinguished candidate is one of them, and every sincere ballot is a permutation of them.
