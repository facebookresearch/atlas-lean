# Consecutive entries of a row

For a row of booleans, an injective choice $f$ of columns indexed by $0, \dots, K-1$ and a boolean $b$, the entries equal to $b$ occur consecutively when, for all $j_1 \le j_2 \le j_3$, if the entries in columns $f(j_1)$ and $f(j_3)$ equal $b$ then so does the entry in column $f(j_2)$ (missing entries read as false).
