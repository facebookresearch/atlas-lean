# Feasible instances of CIRCULAR BLOCK MINIMIZATION

An instance $(n, A, K)$ is feasible for CIRCULAR BLOCK MINIMIZATION when some permutation $\sigma$ of the columns makes at most $K$ positions $(r, j)$ with $j < n$ satisfy $b_{rj} = 1$, $b_{r, j+1} = 0$ (with $b_{r, n} = 0$), and, when $j = n - 1$, also $b_{r, 0} = 0$.
