# CIRCULAR ONES SUBMATRIX is NP-complete

The decision problem CIRCULAR ONES SUBMATRIX belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [SR14] CONSECUTIVE ONES SUBMATRIX, p. 229 (comment: the variant in which `B` must have the "circular ones" property, i.e., the columns of `B` can be permuted so that in each row either all the `1`'s or all the `0`'s occur consecutively, is also NP-complete; main-entry reference [Booth, 1975]).
- K. S. Booth, *PQ-Tree Algorithms*, Ph.D. thesis, University of California, Berkeley (1975), as cited by Garey and Johnson (the thesis itself was not available).
