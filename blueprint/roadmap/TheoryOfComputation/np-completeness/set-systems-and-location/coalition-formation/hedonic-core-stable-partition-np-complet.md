# CORE STABLE PARTITION IN HEDONIC GAMES is NP-complete

The decision problem CORE STABLE PARTITION IN HEDONIC GAMES belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- C. Ballester, "NP-completeness in hedonic games", Games and Economic Behavior 49 (2004), 1-30, doi:10.1016/j.geb.2003.10.003.
- G. J. Woeginger, "Core stability in hedonic coalition formation", SOFSEM 2013, Lecture Notes in Computer Science 7741, 33-50, doi:10.1007/978-3-642-35843-2_4 (Definition 2.1 and Theorem 3.2, restating Ballester's result under the individually rational encoding).
