# The TREE t-SPANNER (fixed t ≥ 4) decision problem

The TREE t-SPANNER (fixed t ≥ 4) decision problem accepts a bitstring exactly when it decodes, under the canonical bitstring encoding, to an instance that is well formed and feasible. Bitstrings that do not decode to an instance are rejected. For each value of the fixed parameter `t` this is a separate decision problem.
