# Feasible instances of TREE t-SPANNER (fixed t ≥ 4)

An instance of TREE t-SPANNER (fixed t ≥ 4) is feasible when `G` has a tree `t`-spanner: a spanning tree `T` of `G` (a tree `T ≤ G` on all vertices of `G`) with `d_T(u, v) ≤ t · d_G(u, v)` for all `u, v`. Feasibility does not include well-formedness; the decision problem requires both.
