# SPANNING TREE WITH AT MOST K BRANCH VERTICES is NP-complete

The SPANNING TREE WITH AT MOST K BRANCH VERTICES decision problem lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

Instance: a graph `G = (V, E)` and a nonnegative integer `K`. Question: does `G` have a spanning tree with at most `K` branch vertices, that is, vertices of degree greater than two in the tree?
