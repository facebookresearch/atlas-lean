# Instances of CODE GENERATION WITH UNLIMITED REGISTERS

An instance of CODE GENERATION WITH UNLIMITED REGISTERS is a triple $(n, A, K)$ of a number $n$ of vertices $0, \dots, n-1$, a list $A$ of arcs $(v, u, b)$, where $b$ true means the arc $(v, u)$ belongs to the left set $L$ and $b$ false means it belongs to the right set $R$, and a bound $K$.
