# COMMUTATIVE CODE GENERATION WITH UNLIMITED REGISTERS is NP-complete

The COMMUTATIVE CODE GENERATION WITH UNLIMITED REGISTERS decision problem belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [PO5] CODE GENERATION WITH UNLIMITED REGISTERS, p. 273 (comment: the "commutative" variant in which instructions of the form $r_i \leftarrow r_j \mathbin{\mathrm{op}} r_i$ are also allowed is NP-complete [Aho, Johnson, and Ullman, 1977b]; Garey and Johnson list [Aho, Johnson, and Ullman, 1977b] as a private communication, which was not available).
- A. V. Aho, S. C. Johnson, and J. D. Ullman, "Code generation for expressions with common subexpressions", Journal of the ACM 24 (1977), 146-160, doi:10.1145/321992.322001 (the non-commutative problem [PO5]).
