# Feasible COMMUTATIVE CODE GENERATION WITH UNLIMITED REGISTERS instances

An instance $(n, A, K)$ is feasible when some program of at most $K$ commutative-machine instructions, with register contents $s_0, \dots, s_{|p|}$, satisfies: in $s_0$ every nonempty register holds a leaf (a vertex with no outgoing arc) and every leaf is in exactly one register; instruction $k$ is allowed in $s_k$ and leads to $s_{k+1}$; and every vertex with no incoming arc is held by some register in some $s_k$.
