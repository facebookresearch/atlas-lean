# CODE GENERATION WITH ADDRESS EXPRESSIONS with $B = 128$ and $C = 127$ is NP-complete

The CODE GENERATION WITH ADDRESS EXPRESSIONS with B = 128 and C = 127 decision problem belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [PO7] CODE GENERATION WITH ADDRESS EXPRESSIONS, p. 274, comment: "Remains NP-complete for certain fixed values of B and C, e.g., 128 and 127 (much smaller values also are possible)".
- T. G. Szymanski, "Assembling code for machines with span-dependent instructions", Communications of the ACM 21 (1978), 300-308, doi:10.1145/359460.359474.
