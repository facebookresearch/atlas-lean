# Instances of CODE GENERATION WITH UNFIXED VARIABLE LOCATIONS

An instance of CODE GENERATION WITH UNFIXED VARIABLE LOCATIONS is a tuple $(m, g, B, M)$ of the number $m$ of variables, the list $g = (g(I_1), \dots, g(I_n))$ of instruction targets, each $(0, j)$ for instruction $I_{j+1}$ or $(1, j)$ for variable $j$, and positive integers $B$ and $M$.
