# CODE GENERATION WITH UNFIXED VARIABLE LOCATIONS is NP-complete

The CODE GENERATION WITH UNFIXED VARIABLE LOCATIONS decision problem belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
