# CODE GENERATION FOR PARALLEL ASSIGNMENTS with at most two operands as a decision problem

The CODE GENERATION FOR PARALLEL ASSIGNMENTS with at most two operands decision problem accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of instances, to a well-formed, feasible instance of CODE GENERATION FOR PARALLEL ASSIGNMENTS with at most two operands; it rejects every bitstring that does not decode to an instance.
