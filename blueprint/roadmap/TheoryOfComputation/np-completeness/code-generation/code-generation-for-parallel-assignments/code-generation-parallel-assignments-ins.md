# Instances of CODE GENERATION FOR PARALLEL ASSIGNMENTS

An instance of CODE GENERATION FOR PARALLEL ASSIGNMENTS is a triple $(n, B, K)$ of the number $n$ of variables $v_0, \dots, v_{n-1}$, a $0$-based list $B$ of operand sets as lists of variable indices (written $(B_0, \dots, B_{n-1})$ when there are $n$ assignments, with assignment $i$ being $v_i \leftarrow \mathrm{op}(B_i)$), and a bound $K$.
