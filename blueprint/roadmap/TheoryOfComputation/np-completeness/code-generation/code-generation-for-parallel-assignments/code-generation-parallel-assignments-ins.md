# Instances of CODE GENERATION FOR PARALLEL ASSIGNMENTS

An instance of CODE GENERATION FOR PARALLEL ASSIGNMENTS is a triple $(n, (B_1, \dots, B_n), K)$ of the number $n$ of variables $v_0, \dots, v_{n-1}$ (and of assignments, assignment $i$ being $v_i \leftarrow \mathrm{op}(B_i)$), the operand sets $B_i$ as lists of variable indices, and a bound $K$.
