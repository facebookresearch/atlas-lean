# MPM OPEN SHOP, OUT-TREE, RELEASE DATES (OMPM|outtree; r_i; p_ij = 1|C_max) is NP-complete

The decision problem MPM OPEN SHOP, OUT-TREE, RELEASE DATES (OMPM|outtree; r_i; p_ij = 1|C_max)
is NP-complete: it belongs to NP, and every decision problem in NP has a polynomial-time
many-one reduction to it.

Source: Timkovsky (2003), as recorded in the Brucker-Knust classification (with the special case
`O|p_ij=1;outtree;r_i|C_max`); Brucker (2007), Chapter 10 (model).
