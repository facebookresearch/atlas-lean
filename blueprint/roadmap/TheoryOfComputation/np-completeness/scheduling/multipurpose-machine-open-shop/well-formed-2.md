# Well-formed MPM OPEN SHOP, OUT-TREE, RELEASE DATES (OMPM|outtree; r_i; p_ij = 1|C_max) instances

Well-formedness of an instance: the machine environment is well formed and every stage machine
set is nonempty, there is at least one job, the listed pairs describe a precedence relation on
the jobs, and it is an out-tree (every job has at most one immediate predecessor).
