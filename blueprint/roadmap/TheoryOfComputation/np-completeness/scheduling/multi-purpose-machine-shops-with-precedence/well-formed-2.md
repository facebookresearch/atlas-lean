# Well-formed two-machine multiprocessor task stage shops with chains

An instance $(\mu, d, A, K)$ is well-formed for the two-machine multiprocessor task flow shop when the environment with $2$ machines is well-formed (at least one stage, machine indices below $2$, pairwise different stage sets) and the arcs $A$ form chains on the jobs $0, \dots, n-1$ ($n$ the length of $d$): no repeated arcs, both ends below $n$, no two arcs with the same tail or the same head, and no directed cycle. Stage machine sets may be empty.
