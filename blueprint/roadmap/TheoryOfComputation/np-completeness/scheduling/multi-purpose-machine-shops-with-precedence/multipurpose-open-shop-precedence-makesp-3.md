# MULTI-PURPOSE MACHINE OPEN SHOP WITH PRECEDENCE, MAKESPAN is NP-complete

The decision problem MULTI-PURPOSE MACHINE OPEN SHOP WITH PRECEDENCE, MAKESPAN belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources
