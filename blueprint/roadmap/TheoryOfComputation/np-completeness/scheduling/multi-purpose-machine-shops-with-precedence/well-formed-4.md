# Well-formed instances of TWO-MACHINE MULTIPROCESSOR TASK OPEN SHOP WITH CHAINS, TOTAL TARDINESS

An instance is well-formed when $m = 2$, the environment is well-formed (at least one stage, machine indices below $m$, pairwise different stage sets as sets), every job has exactly $r$ processing times, all equal to $1$ ($r$ the number of stages), and the arcs form chains on the jobs (no repeated arcs, both ends in range, no shared tails or heads, no directed cycle).
