# Well-formed instances of MULTI-PURPOSE MACHINE OPEN SHOP, MAKESPAN

An instance $(m, \mu, P, K)$ is well-formed for MULTI-PURPOSE MACHINE OPEN SHOP, MAKESPAN when the environment is well-formed (at least one stage, machine indices below $m$, pairwise different stage sets), every stage machine set is nonempty, and every job lists one processing time per stage. Any number of jobs is allowed.
