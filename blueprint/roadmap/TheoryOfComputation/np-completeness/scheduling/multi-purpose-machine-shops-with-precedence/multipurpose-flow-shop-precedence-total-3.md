# MULTI-PURPOSE MACHINE FLOW SHOP WITH PRECEDENCE, TOTAL COMPLETION TIME as a decision problem

The decision problem MULTI-PURPOSE MACHINE FLOW SHOP WITH PRECEDENCE, TOTAL COMPLETION TIME accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quintuples $(m, \mu, P, A, K)$ (a natural number, a list of lists of natural numbers, a list of lists of natural numbers, a list of pairs and a natural number), to an instance that is well-formed for multi-purpose machine shops with precedence (the environment is well-formed (there is at least one stage, every stage machine set lists machines with indices below $m$, and different stages have different machine sets (as sets)), every stage machine set is nonempty, every job lists one processing time per stage, all equal to $1$, and the pairs in $A$ name jobs and form a strict partial order) and feasible for MULTI-PURPOSE MACHINE FLOW SHOP WITH PRECEDENCE, TOTAL COMPLETION TIME. It rejects every bitstring that does not decode to such an instance.
