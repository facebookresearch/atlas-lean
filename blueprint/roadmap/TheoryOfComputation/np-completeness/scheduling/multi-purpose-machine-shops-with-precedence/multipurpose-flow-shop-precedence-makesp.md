# Instances of multi-purpose machine shops with precedence

An instance is a quintuple $(m, \mu, P, A, K)$ of a number $m$ of machines, stage machine sets $\mu = (\mu_1, \dots, \mu_r)$, a list of jobs, each an arbitrary list of natural numbers (its processing times), a list $A$ of precedence pairs $(i, k)$, and a bound $K$.
