# Well-formed instances of multi-purpose machine shops with precedence

An instance $(m, \mu, P, A, K)$ is well-formed when the environment is well-formed (there is at least one stage, every stage machine set lists machines with indices below $m$, and different stages have different machine sets (as sets)), every stage machine set is nonempty, every job lists one processing time per stage, all equal to $1$, and the pairs in $A$ name jobs and form a strict partial order.
