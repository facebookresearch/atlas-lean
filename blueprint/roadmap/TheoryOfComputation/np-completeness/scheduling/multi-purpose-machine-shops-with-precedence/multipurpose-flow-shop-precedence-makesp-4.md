# MULTI-PURPOSE MACHINE FLOW SHOP WITH PRECEDENCE, MAKESPAN is NP-complete

The decision problem MULTI-PURPOSE MACHINE FLOW SHOP WITH PRECEDENCE, MAKESPAN belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- P. Brucker, *Scheduling Algorithms*, 5th ed., Springer (2007): Section 1.3 (precedence relations), Chapter 10 (the MPM flow-shop model) and Table 5.3 (`P|p_i = 1; prec|C_max` is NP-hard, Ullman).
- J. D. Ullman, "NP-complete scheduling problems", Journal of Computer and System Sciences 10 (1975), 384-393, doi:10.1016/S0022-0000(75)80008-0.
- P. Brucker and S. Knust, *Complexity results for scheduling problems*, http://www2.informatik.uni-osnabrueck.de/knust/class/, class "Shop problems with multipurpose machines", which lists `FMPM|prec; p_ij = 1|C_max` as strongly NP-hard with the attribution to Ullman (1975).
