# MULTIPROCESSOR TASK OPEN SHOP WITH RELEASE DATES, LATE JOBS is NP-complete

The decision problem MULTIPROCESSOR TASK OPEN SHOP WITH RELEASE DATES, LATE JOBS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- S. A. Kravchenko, "On the complexity of minimizing the number of late jobs in unit time open shop", Discrete Applied Mathematics 100 (2000), 127-132, doi:10.1016/S0166-218X(99)00202-4.
- P. Brucker and S. Knust, *Complexity results for scheduling problems*, http://www2.informatik.uni-osnabrueck.de/knust/class/, class "Shop problems with multiprocessor tasks", which lists `OMPT|r_i; p_ij = 1|∑ U_i` as minimal NP-hard in the strong sense with the attribution to Kravchenko (1999).
- P. Brucker, *Scheduling Algorithms*, 4th ed., Springer (2004), Chapter 11 (the MPT open-shop model).
