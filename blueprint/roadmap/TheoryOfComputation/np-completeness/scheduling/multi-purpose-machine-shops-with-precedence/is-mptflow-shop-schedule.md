# Multiprocessor task flow-shop schedules

Start times $\sigma_{i,s}$ form a multiprocessor task flow-shop schedule for processing times $p_{i,s}$ and stage machine sets $\mu$ when operation $(i, s+1)$ starts no earlier than operation $(i, s)$ completes, and two different operations whose machine sets share a machine occupy disjoint time intervals $[\sigma_{i,s}, \sigma_{i,s} + p_{i,s})$. Each operation occupies all machines of its stage.
