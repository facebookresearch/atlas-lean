# Instances of MULTIPROCESSOR TASK OPEN SHOP WITH RELEASE DATES, LATE JOBS

An instance is a quadruple $(m, \mu, J, K)$ of a number $m$ of machines, stage machine sets $\mu$, a list $J$ of jobs, each a pair of its processing times and the pair $(r_j, d_j)$ of release date and due date, and a bound $K$.
