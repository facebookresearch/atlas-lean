# MULTIPROCESSOR TASK FLOW SHOP WITH PRECEDENCE, MAKESPAN as a decision problem

The decision problem MULTIPROCESSOR TASK FLOW SHOP WITH PRECEDENCE, MAKESPAN accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quintuples $(m, \mu, P, A, K)$ (a natural number, a list of lists of natural numbers, a list of lists of natural numbers, a list of pairs and a natural number), to an instance that is well-formed and feasible for MULTIPROCESSOR TASK FLOW SHOP WITH PRECEDENCE, MAKESPAN. It rejects every bitstring that does not decode to such an instance.
