# Feasible instances of MULTIPROCESSOR TASK OPEN SHOP WITH RELEASE DATES, LATE JOBS

An instance is feasible when some unit-time multiprocessor task open-shop schedule (no overlap within a job, none between operations sharing a machine) starts no operation of a job before its release date and has at most $K$ late jobs ($d_j < C_j$, with $C_j = 0$ when there are no stages). Every operation takes time $1$, whatever processing times the jobs list, and the number $m$ of machines plays no role.
