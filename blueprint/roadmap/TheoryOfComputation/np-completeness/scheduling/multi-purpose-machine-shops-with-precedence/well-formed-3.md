# Well-formed instances of multiprocessor task shops with precedence

An instance $(m, \mu, P, A, K)$ is well-formed when the environment is well-formed (there is at least one stage, every stage machine set lists machines with indices below $m$, and different stages have different machine sets (as sets)), every job lists exactly $r$ processing times, all equal to $1$ ($r$ the number of stages), and every arc in $A$ names two jobs and no job reaches itself by a nonempty sequence of arcs.
