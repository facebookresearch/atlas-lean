# Well-formed instances of MULTI-PURPOSE MACHINE FLOW SHOP WITH PRECEDENCE, TOTAL COMPLETION TIME

An instance of MULTI-PURPOSE MACHINE FLOW SHOP WITH PRECEDENCE, TOTAL COMPLETION TIME is a tuple $(m, M, J, R, K)$ of a number $m$ of machines, a list $M = [\mu_1, \dots, \mu_r]$ of stage machine sets given as lists of machine indices, a list $J$ of jobs, each a list $[p_{i1}, \dots, p_{ir}]$ of processing times, a list $R$ of pairs $(i, k)$ meaning that job $i$ precedes job $k$, and a bound $K$ on the total completion time, all natural numbers. It is well formed when the machine environment is well formed, that is, there is at least one stage, every machine index in a machine set is below $m$, and different stages have different machine sets as sets; every machine set is nonempty; every job lists exactly one processing time per stage and all of them equal $1$; and the pairs of $R$ name jobs, that is, both entries are below the number of jobs, and form a strict partial order on the jobs.
