# Instances of TWO DEDICATED PROCESSORS WITH RELEASE DATES `P2|r_i;fix_i|Cmax`

An instance of TWO DEDICATED PROCESSORS WITH RELEASE DATES `P2|r_i;fix_i|Cmax` is a value of type `List (ℕ × List ℕ × ℕ) × ℕ`: the tasks `(p_i, fix_i, r_i)` (processing time, processors used, release date), one per entry, and the bound `K`.
