# Feasible instances of TWO-MACHINE MULTIPROCESSOR TASK OPEN SHOP WITH CHAINS, WEIGHTED COMPLETION TIME

An instance is feasible when there is a unit-time multiprocessor task open-shop schedule respecting the arcs (no overlap within a job, no overlap of operations sharing a machine, and every operation of $k$ starting after job $i$ completes whenever $(i, k)$ is an arc) with $\sum_j w_j C_j \le K$, where $C_j$ is $0$ when there are no stages. Every operation takes time $1$, whatever processing times the jobs list, and the number $m$ of machines plays no role.
