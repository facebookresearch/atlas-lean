# Well-formed instances of MULTI-PURPOSE MACHINE FLOW SHOP WITH THREE JOBS, MAKESPAN

An instance $(m, \mu, P, K)$ is well-formed for MULTI-PURPOSE MACHINE FLOW SHOP WITH THREE JOBS, MAKESPAN when the environment is well-formed (at least one stage, machine indices below $m$, pairwise different stage sets), there are exactly three jobs, and every job lists one processing time per stage.
