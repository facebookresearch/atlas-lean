# Feasible instances of TWO-MACHINE MULTIPROCESSOR TASK OPEN SHOP, MAXIMUM LATENESS

An instance is feasible when some multiprocessor task open-shop schedule (no overlap within a job, none between operations sharing a machine) has $C_i + y^- \le d_i + y^+$ for every job $i$ (due dates missing from the list read as $0$), where $C_i$ is $0$ when there are no stages. A processing time missing from a job's list counts as $0$.
