# Well-formed instances of TWO-MACHINE MULTIPROCESSOR TASK OPEN SHOP WITH CHAINS, WEIGHTED COMPLETION TIME

An instance of TWO-MACHINE MULTIPROCESSOR TASK OPEN SHOP WITH CHAINS, WEIGHTED COMPLETION TIME has the same data as an instance of TWO-MACHINE MULTIPROCESSOR TASK OPEN SHOP WITH CHAINS, TOTAL TARDINESS: a tuple $(m, M, J, A, K)$ of a number $m$ of machines, a list $M$ of stage machine sets, a list $J$ of jobs, each given as a pair of a list of processing times and one natural number, a list $A$ of chain arcs, and a bound $K$. It is well formed when it is a well-formed instance of TWO-MACHINE MULTIPROCESSOR TASK OPEN SHOP WITH CHAINS, TOTAL TARDINESS, that is, $m = 2$, the stage machine sets form a well-formed machine environment, every job has one processing time per stage, all equal to $1$, and the arcs form chains on the jobs; and, in addition, there is at least one job.
