# Well-formed instances of TWO-MACHINE MULTIPROCESSOR TASK OPEN SHOP, MAXIMUM LATENESS

An instance $(\mu, P, d, y)$ is well-formed for TWO-MACHINE MULTIPROCESSOR TASK OPEN SHOP, MAXIMUM LATENESS when the environment with $2$ machines is well-formed (at least one stage, machine indices below $2$, pairwise different stage sets), there is at least one job, every job lists one processing time per stage, and there is one due date per job. Stage sets may be empty.
