# Feasible instances of TWO-MACHINE MULTIPROCESSOR TASK OPEN SHOP WITH RELEASE DATES, MAKESPAN

An instance is feasible when some multiprocessor task open-shop schedule starts no task of job $j$ before $r_j$ and completes every job by $K$ (release dates missing from the list read as $0$). A processing time missing from a job's list counts as $0$, and the number $m$ of machines plays no role.
