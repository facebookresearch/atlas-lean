# Feasible instances of TWO-MACHINE MULTI-PURPOSE MACHINE OPEN SHOP, MAXIMUM LATENESS

An instance is feasible when some multi-purpose machine open-shop schedule on the two machines has $C_i + y^- \le d_i + y^+$ for every job $i$, that is, lateness $C_i - d_i \le y$ (due dates read as $0$ when missing), where $C_i$ is $0$ when there are no stages. A processing time missing from a job's list counts as $0$.
