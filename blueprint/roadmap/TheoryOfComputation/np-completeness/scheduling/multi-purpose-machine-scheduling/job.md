# Jobs of a stage shop with arbitrary processing times

An instance of a stage shop with arbitrary processing times, as in MULTI-PURPOSE MACHINE FLOW SHOP WITH THREE JOBS, MAKESPAN, is a tuple $(m, M, J, K)$ of a number $m$ of machines, a list $M = [\mu_1, \dots, \mu_r]$ of stage machine sets given as lists of machine indices, a list $J$ of jobs, each a list of natural-number processing times, and a bound $K$. Its jobs are the positions $0, \dots, n-1$ of the list $J$, where $n$ is the length of $J$; a well-formed instance of the three-job problem has $n = 3$.
