# Feasible instances of TWO-MACHINE MULTIPROCESSOR TASK OPEN SHOP, TOTAL COMPLETION TIME

An instance is feasible when some multiprocessor task open-shop schedule has $\sum_j C_j \le K$, where $C_j$ is $0$ when there are no stages. A processing time missing from a job's list counts as $0$, and the number $m$ of machines plays no role.
