# Instances of two-machine stage shops with due dates

An instance is a quadruple $(\mu, P, d, y)$ of stage machine sets $\mu$ (lists of machine indices; well-formedness requires indices $0, 1$), one list of processing times per job, a list of due dates, job $i$ having the $i$-th listed due date $d_i$, and a bound $y$ given as a pair $(y^+, y^-)$ with $y = y^+ - y^-$.
