# MULTIPROCESSOR TASK FLOW SHOP WITH THREE JOBS, MAKESPAN is NP-complete

The decision problem MULTIPROCESSOR TASK FLOW SHOP WITH THREE JOBS, MAKESPAN belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- A. Krämer, *Scheduling Multiprocessor Tasks on Dedicated Processors*, PhD thesis, Universität Osnabrück, Fachbereich Mathematik/Informatik (1995).
- P. Brucker, *Scheduling Algorithms*, 5th ed., Springer (2007), doi:10.1007/978-3-540-69516-5, Chapter 11 (the MPT flow-shop model).
- P. Brucker and S. Knust, *Complexity results for scheduling problems*, http://www2.informatik.uni-osnabrueck.de/knust/class/, class "Shop problems with multiprocessor tasks", which lists `FMPT|n = 3|C_max` as minimal NP-hard (in the ordinary sense), citing Krämer (1995).
