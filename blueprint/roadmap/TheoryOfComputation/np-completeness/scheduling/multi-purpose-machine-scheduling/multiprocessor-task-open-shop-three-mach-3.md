# THREE-MACHINE MULTIPROCESSOR TASK OPEN SHOP, MAKESPAN is NP-complete

The decision problem THREE-MACHINE MULTIPROCESSOR TASK OPEN SHOP, MAKESPAN belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- P. Brucker, *Scheduling Algorithms*, 5th ed., Springer (2007), Chapter 11 (multiprocessor tasks: the MPT open-shop model).
- T. Gonzalez and S. Sahni, "Open shop scheduling to minimize finish time", Journal of the ACM 23(4) (1976), 665-679, doi:10.1145/321978.321985.
- P. Brucker and S. Knust, *Complexity results for scheduling problems*, http://www2.informatik.uni-osnabrueck.de/knust/class/, class "Shop problems with multiprocessor tasks", which lists `OMPT3||C_max` as minimal NP-hard (in the ordinary sense) with the attribution to Gonzalez and Sahni (1976).
