# Well-formed instances of TWO-MACHINE MULTI-PURPOSE MACHINE OPEN SHOP WITH RELEASE DATES, MAKESPAN

An instance is well-formed when the open-shop instance is well-formed for multi-purpose machine open-shop makespan (the environment is well-formed (at least one stage, machine indices below $m$, pairwise different stage sets), nonempty stage sets, one processing time per stage), $m = 2$, and there is one release date per job.
