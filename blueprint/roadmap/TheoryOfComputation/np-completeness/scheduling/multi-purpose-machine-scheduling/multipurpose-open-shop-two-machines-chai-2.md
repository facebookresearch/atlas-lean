# Feasible instances of TWO-MACHINE MULTI-PURPOSE MACHINE OPEN SHOP WITH CHAINS, MAKESPAN

An instance is feasible when some multi-purpose machine open-shop schedule respects the listed arcs (for an arc $(i, k)$ no operation of $k$ starts before $C_i$) and completes every job by $K$. A processing time missing from a job's list counts as $0$.
