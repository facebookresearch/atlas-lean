# Well-formed instances of THREE-MACHINE MULTIPROCESSOR TASK OPEN SHOP, MAKESPAN

An instance $(m, \mu, P, K)$ is well-formed for THREE-MACHINE MULTIPROCESSOR TASK OPEN SHOP, MAKESPAN when $m = 3$, the environment is well-formed (at least one stage, machine indices below $m$, pairwise different stage sets), and every job lists one processing time per stage.
