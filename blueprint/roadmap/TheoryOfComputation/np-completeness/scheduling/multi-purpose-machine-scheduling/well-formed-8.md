# Well-formed instances of TWO-MACHINE MULTIPROCESSOR TASK OPEN SHOP, TOTAL COMPLETION TIME

An instance $(m, \mu, P, K)$ is well-formed for TWO-MACHINE MULTIPROCESSOR TASK OPEN SHOP, TOTAL COMPLETION TIME when $m = 2$, the environment is well-formed (at least one stage, machine indices below $m$, pairwise different stage sets), every job lists one processing time per stage, and there is at least one job.
