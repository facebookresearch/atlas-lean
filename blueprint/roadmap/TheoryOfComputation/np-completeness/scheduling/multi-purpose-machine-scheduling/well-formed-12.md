# Well-formed instances of TWO-MACHINE MULTI-PURPOSE MACHINE OPEN SHOP, MAXIMUM LATENESS

An instance is well-formed when the environment with $2$ machines is well-formed (at least one stage, machine indices below $2$, pairwise different stage sets), every stage machine set is nonempty, there is at least one job, every job lists one processing time per stage, and there is one due date per job.
