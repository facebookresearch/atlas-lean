# Well-formed instances of MULTIPROCESSOR TASK OPEN SHOP, MAKESPAN

An instance $(m, \mu, P, K)$ is well-formed for MULTIPROCESSOR TASK OPEN SHOP, MAKESPAN when $m \ge 1$, the environment is well-formed (at least one stage, machine indices below $m$, pairwise different stage sets), and every job lists one processing time per stage.
