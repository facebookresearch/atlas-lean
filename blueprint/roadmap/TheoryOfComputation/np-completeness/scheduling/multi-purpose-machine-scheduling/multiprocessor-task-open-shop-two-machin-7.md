# TWO-MACHINE MULTIPROCESSOR TASK OPEN SHOP WITH RELEASE DATES, MAKESPAN is NP-complete

The decision problem TWO-MACHINE MULTIPROCESSOR TASK OPEN SHOP WITH RELEASE DATES, MAKESPAN belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
