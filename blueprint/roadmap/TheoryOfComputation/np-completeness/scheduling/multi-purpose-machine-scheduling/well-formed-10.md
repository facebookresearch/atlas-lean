# Well-formed instances of MULTI-PURPOSE MACHINE OPEN SHOP WITH THREE JOBS, MAKESPAN

An instance $(m, \mu, P, K)$ is well-formed for MULTI-PURPOSE MACHINE OPEN SHOP WITH THREE JOBS, MAKESPAN when it is well-formed for the multi-purpose machine flow shop with three jobs (the environment is well-formed (at least one stage, machine indices below $m$, pairwise different stage sets), three jobs, one processing time per stage) and every stage machine set is nonempty.
