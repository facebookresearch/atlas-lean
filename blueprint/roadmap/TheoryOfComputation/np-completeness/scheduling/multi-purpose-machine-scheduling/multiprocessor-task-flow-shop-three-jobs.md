# Feasible instances of MULTIPROCESSOR TASK FLOW SHOP WITH THREE JOBS, MAKESPAN

An instance is feasible when some multiprocessor task flow-shop schedule (stages in order, operations sharing a machine never overlap, each operation occupying all machines of its stage) completes every job by $K$. A processing time missing from a job's list counts as $0$, and the number $m$ of machines plays no role.
