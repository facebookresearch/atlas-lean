# Stages of a stage shop with arbitrary processing times

An instance of a stage shop with arbitrary processing times, as in MULTI-PURPOSE MACHINE FLOW SHOP WITH THREE JOBS, MAKESPAN, is a tuple $(m, M, J, K)$ of a number $m$ of machines, a list $M = [\mu_1, \dots, \mu_r]$ of stage machine sets given as lists of machine indices, a list $J$ of jobs, each a list of natural-number processing times, and a bound $K$. Its stages are the positions $0, \dots, r-1$ of the list $M$, where $r$ is the length of $M$.
