# FIXED-START SCHEDULING ON TWO MACHINE TYPES, MACHINE COST as a decision problem

The decision problem FIXED-START SCHEDULING ON TWO MACHINE TYPES, MACHINE COST accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quadruples of a list of triples and three natural numbers, to an instance that is well-formed and feasible for FIXED-START SCHEDULING ON TWO MACHINE TYPES, MACHINE COST. It rejects every bitstring that does not decode to such an instance.
