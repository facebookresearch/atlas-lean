# CODE GENERATION ON A ONE-REGISTER MACHINE is NP-complete

The decision problem CODE GENERATION ON A ONE-REGISTER MACHINE belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), pp. 272-273, problem [PO4] CODE GENERATION ON A ONE-REGISTER MACHINE.
- J. Bruno and R. Sethi, "Code generation for a one-register machine", Journal of the ACM 23 (1976), 502-510, doi:10.1145/321958.321971.
