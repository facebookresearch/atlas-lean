# CODE GENERATION ON A ONE-REGISTER MACHINE as a decision problem

The decision problem CODE GENERATION ON A ONE-REGISTER MACHINE accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(n, A, K)$, to an instance that is well-formed and feasible for CODE GENERATION ON A ONE-REGISTER MACHINE. It rejects every bitstring that does not decode to such an instance.
