# Feasible instances of CODE GENERATION ON A ONE-REGISTER MACHINE with shared vertices pointing only to leaves

An instance of CODE GENERATION ON A ONE-REGISTER MACHINE (shared vertices have arcs only to leaves) is feasible when it is a [feasible instance of CODE GENERATION ON A ONE-REGISTER MACHINE](../special-scheduling-models/code-generation-on-aone-register-machine-2.md): some program of at most $K$ LOAD, STORE and OP instructions runs, step by step, from the state with an empty register and the leaves (out-degree $0$) in memory to a state in which every root (in-degree $0$) is in memory.
