# Instances of CODE GENERATION ON A ONE-REGISTER MACHINE with shared vertices pointing only to leaves

An instance of CODE GENERATION ON A ONE-REGISTER MACHINE (shared vertices have arcs only to leaves) is an [instance of CODE GENERATION ON A ONE-REGISTER MACHINE](../special-scheduling-models/code-generation-on-aone-register-machine.md): a triple $(n, A, K)$ of a vertex count, an arc list of a directed graph on the vertices $0, \dots, n - 1$, and a bound $K$.
