# FIXED-START SCHEDULING ON TWO MACHINE TYPES, MACHINE COST is NP-complete

The decision problem FIXED-START SCHEDULING ON TWO MACHINE TYPES, MACHINE COST belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- K. Nakajima, S. L. Hakimi and J. K. Lenstra, "Complexity results for scheduling tasks in fixed intervals on two types of machines", SIAM Journal on Computing 11 (1982), 512-520, doi:10.1137/0211040, Theorem 2 ("The FST problem is NP-hard in the strong sense").
