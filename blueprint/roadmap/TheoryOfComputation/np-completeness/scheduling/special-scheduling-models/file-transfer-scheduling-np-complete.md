# FILE TRANSFER SCHEDULING is NP-complete

The decision problem FILE TRANSFER SCHEDULING belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- E. G. Coffman, Jr., M. R. Garey, D. S. Johnson and A. S. LaPaugh, "Scheduling file transfers", SIAM Journal on Computing 14(3) (1985), 744-780, doi:10.1137/0214054.
- P. Crescenzi and V. Kann (eds.), *A compendium of NP optimization problems*, problem MINIMUM FILE TRANSFER SCHEDULING (the decision version of the optimization problem stated here).
- S. Nakano and T. Nishizeki, "Scheduling file transfers under port and channel constraints", ISA '91 Algorithms, Lecture Notes in Computer Science 557 (1991), 43-51, doi:10.1007/3-540-54945-5_48, Section 1 (restating the model of Coffman et al.).
