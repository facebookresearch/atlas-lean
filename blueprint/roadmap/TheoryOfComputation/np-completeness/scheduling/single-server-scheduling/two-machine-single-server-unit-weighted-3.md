# TWO MACHINES WITH A SINGLE SERVER AND UNIT PROCESSING TIMES, WEIGHTED NUMBER OF LATE JOBS is NP-complete

The decision problem TWO MACHINES WITH A SINGLE SERVER AND UNIT PROCESSING TIMES, WEIGHTED NUMBER OF LATE JOBS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- N. G. Hall, C. N. Potts and C. Sriskandarajah, "Parallel machine scheduling with a common server", Discrete Applied Mathematics 102 (2000), 223-243, doi:10.1016/S0166-218X(99)00206-1.
- P. Brucker and S. Knust, *Complexity results for scheduling problems*, Universität Osnabrück, class "Parallel machine problems with a single server" (`P2;S1|p_i=1|Σw_iU_i`, minimal NP-hard in the ordinary sense: "Single-machine problem, Hall et al. (2000)").
- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [SS3] SEQUENCING TO MINIMIZE TARDY TASK WEIGHT (the single-machine problem).
