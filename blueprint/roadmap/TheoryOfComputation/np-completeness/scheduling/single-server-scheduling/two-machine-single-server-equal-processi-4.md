# TWO MACHINES WITH A SINGLE SERVER AND EQUAL PROCESSING TIMES, MAKESPAN is NP-complete

The decision problem TWO MACHINES WITH A SINGLE SERVER AND EQUAL PROCESSING TIMES, MAKESPAN belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- P. Brucker, C. Dhaenens-Flipo, S. Knust, S. A. Kravchenko and F. Werner, "Complexity results for parallel machine problems with a single server", Journal of Scheduling 5 (2002), 429-457, doi:10.1002/jos.120.
- P. Brucker and S. Knust, *Complexity results for scheduling problems*, Universität Osnabrück, class "Parallel machine problems with a single server" (`P2;S1|p_i=p|C_max`, minimal NP-hard in the ordinary sense, citing Brucker et al. 2002).
