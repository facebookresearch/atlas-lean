# Feasible instances of PARALLEL MACHINES WITH A SINGLE SERVER AND UNIT SETUP TIMES, TOTAL COMPLETION TIME

An instance is feasible when some machine $\mu_j$ and setup start $t_j$ per job start the unit setups of different jobs at different times, keep different jobs on the same machine in disjoint intervals $[t_j, t_j + 1 + p_j)$, and give $\sum_j (t_j + 1 + p_j) \le K$.
