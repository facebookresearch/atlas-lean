# Feasible instances of TWO MACHINES WITH A SINGLE SERVER AND UNIT SETUP TIMES, MAXIMUM LATENESS

An instance is feasible when there is a single-server schedule on two machines (machine $\mu_j$ and setup start $t_j$ per job; setup during $[t_j, t_j + s_j)$ followed at once by processing; setups of different jobs disjoint in time; jobs on the same machine occupying disjoint intervals $[t_j, t_j + s_j + p_j)$), with every setup time $1$, and $t_j + 1 + p_j + K^- \le d_j + K^+$ for every job.
