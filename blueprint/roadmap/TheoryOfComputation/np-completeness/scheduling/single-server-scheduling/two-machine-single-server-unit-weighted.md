# Feasible instances of TWO MACHINES WITH A SINGLE SERVER AND UNIT PROCESSING TIMES, WEIGHTED NUMBER OF LATE JOBS

An instance is feasible when there is a single-server schedule on $2$ machines (setup during $[t_j, t_j + s_j)$ immediately followed by processing on machine $\mu_j$; setups of different jobs disjoint; jobs on the same machine disjoint), unit processing times, whose late jobs ($t_j + s_j + 1 > d_j$) have total weight at most $K$.
