# TWO MACHINES WITH A SINGLE SERVER AND UNIT PROCESSING TIMES, WEIGHTED TARDINESS is NP-complete

The decision problem TWO MACHINES WITH A SINGLE SERVER AND UNIT PROCESSING TIMES, WEIGHTED TARDINESS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
