# TWO MACHINES WITH A SINGLE SERVER AND UNIT PROCESSING TIMES, TOTAL TARDINESS is NP-complete

The decision problem TWO MACHINES WITH A SINGLE SERVER AND UNIT PROCESSING TIMES, TOTAL TARDINESS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- N. G. Hall, C. N. Potts and C. Sriskandarajah, "Parallel machine scheduling with a common server", Discrete Applied Mathematics 102 (2000), 223-243, doi:10.1016/S0166-218X(99)00206-1.
- P. Brucker and S. Knust, *Complexity results for scheduling problems*, Universität Osnabrück, class "Parallel machine problems with a single server" (`P2;S1|p_i=1|ΣT_i`, minimal NP-hard in the ordinary sense: "Single-machine problem, Hall et al. (2000)").
- J. Du and J. Y.-T. Leung, "Minimizing total tardiness on one machine is NP-hard", Mathematics of Operations Research 15 (1990), 483-495, doi:10.1287/moor.15.3.483 (the single-machine problem).
