# Feasible instances of TWO MACHINES WITH A SINGLE SERVER AND EQUAL PROCESSING TIMES, MAKESPAN

An instance is feasible when there is a single-server schedule on $2$ machines (setup during $[t_j, t_j + s_j)$ immediately followed by processing on machine $\mu_j$; setups of different jobs disjoint; jobs on the same machine disjoint), with setup times $s_j$ and processing times $p$, completing every job by $K$ ($t_j + s_j + p \le K$).
