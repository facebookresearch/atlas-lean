# TWO MACHINES WITH A SINGLE SERVER AND UNIT SETUP TIMES, MAXIMUM LATENESS is NP-complete

The decision problem TWO MACHINES WITH A SINGLE SERVER AND UNIT SETUP TIMES, MAXIMUM LATENESS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- N. G. Hall, C. N. Potts and C. Sriskandarajah, "Parallel machine scheduling with a common server", Discrete Applied Mathematics 102 (2000), 223-243, doi:10.1016/S0166-218X(99)00206-1.
- P. Brucker and S. Knust, *Complexity results for scheduling problems*, Universität Osnabrück, class "Parallel machine problems with a single server" (`P2;S1|s_i=1|L_max`, minimal NP-hard in the strong sense, citing Hall et al. 2000).
