# TWO MACHINES WITH A SINGLE SERVER AND UNIT SETUP TIMES, MAKESPAN as a decision problem

The decision problem TWO MACHINES WITH A SINGLE SERVER AND UNIT SETUP TIMES, MAKESPAN accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(x, L, K)$ (a natural number, a list of natural numbers and a natural number), to an instance that is well-formed ($s = 1$) and feasible for two machines with a single server and equal setup times, makespan. It rejects every bitstring that does not decode to such an instance.
