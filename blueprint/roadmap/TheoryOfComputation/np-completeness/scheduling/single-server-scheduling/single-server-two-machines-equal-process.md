# Instances of TWO MACHINES WITH A SINGLE SERVER AND EQUAL PROCESSING TIMES, TOTAL COMPLETION TIME

An instance of TWO MACHINES WITH A SINGLE SERVER AND EQUAL PROCESSING TIMES, TOTAL COMPLETION TIME is a triple $(p, s, K)$ of a natural number $p$, the processing time common to all jobs; a list $s = (s_0, \dots, s_{n-1})$ of natural numbers, the setup times of the jobs $0, \dots, n-1$, one per entry, where $n$ is the length of $s$; and a natural number $K$, the bound on the total completion time.
