# TWO MACHINES WITH A SINGLE SERVER AND EQUAL SETUP TIMES, MAKESPAN is NP-complete

The decision problem TWO MACHINES WITH A SINGLE SERVER AND EQUAL SETUP TIMES, MAKESPAN belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- N. G. Hall, C. N. Potts and C. Sriskandarajah, "Parallel machine scheduling with a common server", Discrete Applied Mathematics 102 (2000), 223-243, doi:10.1016/S0166-218X(99)00206-1.
- P. Brucker, C. Dhaenens-Flipo, S. Knust, S. A. Kravchenko and F. Werner, "Complexity results for parallel machine problems with a single server", Journal of Scheduling 5 (2002), 429-457, doi:10.1002/jos.120 (the model).
- P. Brucker and S. Knust, *Complexity results for scheduling problems*, Universität Osnabrück, class "Parallel machine problems with a single server" (`P2;S1|s_i=s|C_max`, minimal NP-hard in the strong sense, citing Hall et al. 2000).
