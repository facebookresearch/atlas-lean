# TWO MACHINES WITH A SINGLE SERVER AND UNIT SETUP TIMES, MAXIMUM LATENESS as a decision problem

The decision problem TWO MACHINES WITH A SINGLE SERVER AND UNIT SETUP TIMES, MAXIMUM LATENESS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a list of pairs and a pair of natural numbers, to an instance that is well-formed and feasible for TWO MACHINES WITH A SINGLE SERVER AND UNIT SETUP TIMES, MAXIMUM LATENESS. It rejects every bitstring that does not decode to such an instance.
