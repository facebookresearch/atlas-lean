# Single-server schedules on m parallel machines

For $m$ machines and jobs with setup times $s$ and processing times $p$, machines $\mu$ and setup starts $t$ form a schedule when each job's setup occupies the server during $[t_j, t_j + s_j)$ and is immediately followed by processing, job $j$ occupies machine $\mu_j$ during $[t_j, t_j + s_j + p_j)$, setups of different jobs are disjoint, and different jobs on the same machine are disjoint.
