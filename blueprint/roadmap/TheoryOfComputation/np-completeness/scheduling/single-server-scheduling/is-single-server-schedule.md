# Single-server schedules on parallel machines

For jobs with setup times $s$ and processing times $p$, machines $\mu$ and setup starts $t$ form a single-server schedule when job $j$ is set up on $\mu_j$ during $[t_j, t_j + s_j)$ and then processed during $[t_j + s_j, t_j + s_j + p_j)$, the setups of different jobs are disjoint in time, and different jobs on the same machine occupy disjoint intervals $[t_j, t_j + s_j + p_j)$.
