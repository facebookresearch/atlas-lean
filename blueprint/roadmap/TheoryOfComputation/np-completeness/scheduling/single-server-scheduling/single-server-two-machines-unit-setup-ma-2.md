# TWO MACHINES WITH A SINGLE SERVER AND UNIT SETUP TIMES, MAKESPAN is NP-complete

The decision problem TWO MACHINES WITH A SINGLE SERVER AND UNIT SETUP TIMES, MAKESPAN belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- S. A. Kravchenko and F. Werner, "Parallel machine scheduling problems with a single server", Mathematical and Computer Modelling 26 (1997), 1-11, doi:10.1016/S0895-7177(97)00236-7.
- N. G. Hall, C. N. Potts and C. Sriskandarajah, "Parallel machine scheduling with a common server", Discrete Applied Mathematics 102 (2000), 223-243, doi:10.1016/S0166-218X(99)00206-1.
- P. Brucker and S. Knust, *Complexity results for scheduling problems*, Universität Osnabrück, class "Parallel machine problems with a single server" (`P2;S1|s_i=1|C_max`, NP-hard and maximal pseudo-polynomially solvable, citing Hall et al. 2000 and Kravchenko and Werner 1997).
