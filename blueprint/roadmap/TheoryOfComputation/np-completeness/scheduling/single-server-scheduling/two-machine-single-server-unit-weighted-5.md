# TWO MACHINES WITH A SINGLE SERVER AND UNIT PROCESSING TIMES, WEIGHTED TARDINESS as a decision problem

The decision problem TWO MACHINES WITH A SINGLE SERVER AND UNIT PROCESSING TIMES, WEIGHTED TARDINESS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs $(J, K)$ (a list of triples and a natural number), to an instance that is feasible for TWO MACHINES WITH A SINGLE SERVER AND UNIT PROCESSING TIMES, WEIGHTED TARDINESS (no well-formedness condition is imposed). It rejects every bitstring that does not decode to such an instance.
