# TWO MACHINES WITH A SINGLE SERVER AND UNIT PROCESSING TIMES, TOTAL TARDINESS as a decision problem

The decision problem TWO MACHINES WITH A SINGLE SERVER AND UNIT PROCESSING TIMES, TOTAL TARDINESS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs $(J, K)$ (a list of pairs and a natural number), to an instance that is feasible for TWO MACHINES WITH A SINGLE SERVER AND UNIT PROCESSING TIMES, TOTAL TARDINESS (no well-formedness condition is imposed). It rejects every bitstring that does not decode to such an instance.
