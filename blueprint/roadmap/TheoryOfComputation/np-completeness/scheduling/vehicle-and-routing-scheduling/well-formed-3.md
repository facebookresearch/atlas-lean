# Well-formed VEHICLE SCHEDULING ON TREE instances

An instance $(P, R, K)$ of VEHICLE SCHEDULING ON TREE whose parent list $P = ((p_k, f_k, b_k))_{k < m}$ has $m$ entries is well formed when $p_k \le k$ for every $k < m$ (so the parent of vertex $k + 1$ is an earlier vertex), the task list $R$ has exactly $m + 1$ entries, and $K > 0$.
