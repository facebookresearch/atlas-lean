# RESOURCE CONSTRAINED SCHEDULING with `r = 1`, `m = 2` and a forest partial order is NP-complete

RESOURCE CONSTRAINED SCHEDULING with `r = 1`, `m = 2` and a forest partial order is NP-complete: the decision problem over bitstrings that accepts exactly the encodings of well-formed instances with a solution lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
