# Feasible instances of OPEN SHOP O|p_ij=1;outtree|Lmax

An instance of OPEN SHOP O|p_ij=1;outtree|Lmax is feasible when some open-shop schedule completes every operation of every job `j` by time `d_j + K` (maximum lateness `max_j (C_j - d_j) ≤ K`). Feasibility does not include well-formedness; the decision problem requires both. A position beyond the end of a list reads as the default entry `([], (0, 0))`.
