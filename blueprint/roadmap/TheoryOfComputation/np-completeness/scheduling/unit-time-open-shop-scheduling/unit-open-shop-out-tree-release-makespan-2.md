# Feasible instances of OPEN SHOP O|p_ij=1;outtree;r_i|Cmax

An instance of OPEN SHOP O|p_ij=1;outtree;r_i|Cmax is feasible when some open-shop schedule starts no operation of a job before its release date and completes every operation by time `K` (makespan `max_j C_j ≤ K`). Feasibility does not include well-formedness; the decision problem requires both.
