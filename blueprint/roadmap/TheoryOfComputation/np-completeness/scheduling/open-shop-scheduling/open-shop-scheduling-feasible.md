# Feasible instances of OPEN-SHOP SCHEDULING

An instance $(m, J, D)$ is feasible for OPEN-SHOP SCHEDULING when there is an open-shop schedule meeting the bound: start times $\sigma_p(j)$ of job $j$'s task on processor $p$, pairwise different on each processor, such that a task starting after another task $k$ on the same processor starts no earlier than $k$ finishes, the tasks of each job occupy pairwise disjoint time intervals, and every task finishes by the last component. A task length $l(t_p[j])$ missing from job $j$'s list counts as $0$.
