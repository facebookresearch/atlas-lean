# Instances of UNIT-TIME OPEN SHOP WITH SYMMETRIC TRANSPORTATION DELAYS

An instance is a pair of an open-shop instance $(m, J, K)$ and a delay matrix given as a list of rows, the $l$-th entry of row $k$ being the delay $t_{k,l}$ from machine $k$ to machine $l$. That the matrix has $m$ rows of $m$ entries, is symmetric and has a zero diagonal is part of well-formedness, not of the instance type.
