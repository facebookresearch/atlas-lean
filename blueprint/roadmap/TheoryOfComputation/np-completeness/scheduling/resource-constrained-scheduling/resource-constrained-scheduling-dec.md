# RESOURCE CONSTRAINED SCHEDULING as a decision problem

The decision problem RESOURCE CONSTRAINED SCHEDULING accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quintuples $(m, r, B, R, D)$ (two natural numbers, a list, a list of lists and a natural number), to an instance that is well-formed and feasible for RESOURCE CONSTRAINED SCHEDULING. It rejects every bitstring that does not decode to such an instance.
