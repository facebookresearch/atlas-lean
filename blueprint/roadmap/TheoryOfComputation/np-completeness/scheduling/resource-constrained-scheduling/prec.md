# Precedence relation of resource-constrained scheduling with a partial order

An instance of RESOURCE CONSTRAINED SCHEDULING with a partial order is a pair of a RESOURCE CONSTRAINED SCHEDULING instance, whose tasks are the rows $0, \dots, n-1$ of its requirement table, and a list $R$ of pairs of natural numbers. Task $t$ precedes task $t^\prime$, written $t < t^\prime$, when the pair $(t, t^\prime)$ occurs in $R$. That the listed pairs name tasks and form a strict partial order is a condition of a well-formed instance, not of this definition.
