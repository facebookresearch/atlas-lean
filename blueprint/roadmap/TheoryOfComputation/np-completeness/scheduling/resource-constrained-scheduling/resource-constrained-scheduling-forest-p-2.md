# RESOURCE CONSTRAINED SCHEDULING with `r = 1`, `m = 2` and a forest partial order is NP-complete

RESOURCE CONSTRAINED SCHEDULING with `r = 1`, `m = 2` and a forest partial order is NP-complete: the decision problem over bitstrings that accepts exactly the bitstrings that decode to a well-formed instance with a solution lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
