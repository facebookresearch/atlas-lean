# Feasible instances of THREE-PROCESSOR ONE-RESOURCE SCHEDULING, TOTAL COMPLETION TIME

An instance $(m, r, B, R, K)$ is feasible when some start times of the unit tasks run at most $m$ tasks at every time, keep the running tasks within each resource bound, and give $\sum_t (\sigma(t) + 1) \le K$. A resource bound or requirement missing from its list counts as $0$.
