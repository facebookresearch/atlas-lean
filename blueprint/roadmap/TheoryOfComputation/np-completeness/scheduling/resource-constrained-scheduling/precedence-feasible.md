# Feasible resource-constrained scheduling with a partial order

An instance is feasible when some start times of the unit tasks finish every task by $D$, run at most $m$ tasks at every time, and keep the total requirement of the running tasks within each bound $B_k$ at every time, and respect the precedence ($\sigma(t) + 1 \le \sigma(t')$). A resource bound or requirement missing from its list counts as $0$.
