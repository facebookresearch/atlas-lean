# Well-formed instances of THREE-PROCESSOR RESOURCE CONSTRAINED SCHEDULING WITH UNIT BOUNDS

An instance is well-formed for THREE-PROCESSOR RESOURCE CONSTRAINED SCHEDULING WITH UNIT BOUNDS when it is well-formed for RESOURCE CONSTRAINED SCHEDULING ($m > 0$, $r > 0$, there are $r$ positive bounds, every task row has $r$ requirements with $R_k(t) \le B_k$, and $D > 0$), $m = 3$, and every resource bound is $1$.
