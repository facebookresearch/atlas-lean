# Instances of RESOURCE CONSTRAINED SCHEDULING

An instance is a quintuple $(m, r, B, R, D)$ of a number $m$ of processors, a number $r$ of resources, a list of bounds, the $k$-th being $B_k$, a list of requirement rows, one per unit-length task $t$, the $k$-th entry of the row of $t$ being $R_k(t)$, and a deadline $D$. That there are $r$ bounds and every row has $r$ entries is part of well-formedness, not of the instance type.
