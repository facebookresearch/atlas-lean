# Well-formed MPM FLOW SHOP, IN-TREE, RELEASE DATES (FMPM|intree; r_i; p_ij = 1|C_max) instances

Well-formedness of an instance: the machine environment is well formed and every stage machine
set is nonempty (each operation is processed by one machine of its set), the listed pairs
describe a precedence relation on the jobs, and it is an in-tree (every job has at most one
immediate successor).
