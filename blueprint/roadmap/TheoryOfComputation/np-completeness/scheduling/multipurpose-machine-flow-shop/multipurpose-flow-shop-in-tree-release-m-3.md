# The decision problem MPM FLOW SHOP, IN-TREE, RELEASE DATES (FMPM|intree; r_i; p_ij = 1|C_max)

`FMPM|intree; r_i; p_ij = 1|C_max` as a decision problem on bitstrings: a bitstring is accepted
exactly when it decodes, under the canonical bitstring encoding, to an instance that is
well-formed and feasible. A bitstring that does not decode to an instance is rejected.
