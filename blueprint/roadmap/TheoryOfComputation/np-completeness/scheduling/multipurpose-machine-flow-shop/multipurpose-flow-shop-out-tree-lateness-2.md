# Feasible MPM FLOW SHOP, OUT-TREE, MAXIMUM LATENESS (FMPM|outtree; p_ij = 1|L_max) instances

An instance is feasible when some multipurpose-machine flow-shop schedule of the unit-time jobs,
with a machine from each stage's set assigned to each operation, obeys the outtree precedence
constraints and has maximum lateness at most $K$: $C_j - d_j \le K$ for every job $j$, computed
in the integers.
