# Instances of MPM FLOW SHOP, OUT-TREE, MAXIMUM LATENESS (FMPM|outtree; p_ij = 1|L_max)

An instance: the number of machines `m`, the stage machine sets `[μ_1, …, μ_r]`, the due dates
`[d_1, …, d_n]` (one per job) as `(positive part, negative part)` pairs, the pairs `(i, k)` with
`i → k`, and the bound `K` as a `(positive part, negative part)` pair.
