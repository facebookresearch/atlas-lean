# Instances of FLOW-SHOP SCHEDULING

An instance of FLOW-SHOP SCHEDULING is a triple $(m, J, D)$ of a number $m$ of processors, a list $J$ of jobs, job $j$ given by a list of task lengths in processor order (its $p$-th entry is $l(t_p[j])$), and a deadline $D$. That every job lists exactly $m$ task lengths is part of well-formedness, not of the instance type.
