# THREE-MACHINE MULTI-PURPOSE MACHINE FLOW SHOP as a decision problem

The decision problem THREE-MACHINE MULTI-PURPOSE MACHINE FLOW SHOP accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a flow-shop instance $(r, J, K)$ and a list of lists of natural numbers, to an instance that is well-formed and feasible for THREE-MACHINE MULTI-PURPOSE MACHINE FLOW SHOP. It rejects every bitstring that does not decode to such an instance.
