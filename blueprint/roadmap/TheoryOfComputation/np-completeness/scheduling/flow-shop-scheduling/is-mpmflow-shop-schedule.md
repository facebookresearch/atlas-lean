# Multi-purpose machine flow-shop schedules (flow-shop form)

Start times $\sigma_p(j)$ and machines $a_p(j)$ form a multi-purpose machine flow-shop schedule when each operation runs on a machine of its stage's set, two different operations on the same machine do not overlap, and each job's operations run in stage order. A processing time missing from job $j$'s list counts as $0$. A stage with no listed machine set has no machines, so no operation of it can be placed.
