# Well-formed instances of TWO-MACHINE MULTI-PURPOSE MACHINE FLOW SHOP, MEAN FLOW TIME

An instance is well-formed for TWO-MACHINE MULTI-PURPOSE MACHINE FLOW SHOP, MEAN FLOW TIME when the flow-shop instance $(r, J, K)$ is well-formed ($r > 0$, every job has $r$ tasks, $K > 0$), there is one machine set per stage, every machine set is nonempty with machines among $0, \dots, 1$, and the machine sets are pairwise different as sets.
