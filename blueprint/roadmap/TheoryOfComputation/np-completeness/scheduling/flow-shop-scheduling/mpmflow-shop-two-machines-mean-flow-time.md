# Feasible instances of TWO-MACHINE MULTI-PURPOSE MACHINE FLOW SHOP, MEAN FLOW TIME

An instance is feasible when some multi-purpose machine flow-shop schedule in which operations on the same machine start at different times has the completion times of the jobs at the last stage summing to at most $K$. A processing time missing from job $j$'s list counts as $0$. With no stages there is no last stage, and $K$ imposes no condition.
