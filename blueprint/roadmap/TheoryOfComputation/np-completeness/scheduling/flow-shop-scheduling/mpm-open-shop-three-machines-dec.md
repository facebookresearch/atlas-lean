# THREE-MACHINE MULTI-PURPOSE MACHINE OPEN SHOP as a decision problem

The decision problem THREE-MACHINE MULTI-PURPOSE MACHINE OPEN SHOP accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a flow-shop instance $(r, J, K)$ and a list of lists of natural numbers, to an instance that is well-formed for the three-machine multi-purpose machine flow shop (the flow-shop instance $(r, J, K)$ is well-formed ($r > 0$, every job has $r$ tasks, $K > 0$), there is one machine set per stage, every machine set is nonempty with machines among $0, \dots, 2$, and the machine sets are pairwise different as sets) and feasible for THREE-MACHINE MULTI-PURPOSE MACHINE OPEN SHOP. It rejects every bitstring that does not decode to such an instance.
