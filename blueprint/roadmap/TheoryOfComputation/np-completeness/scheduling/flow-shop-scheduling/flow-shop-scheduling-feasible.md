# Feasible instances of FLOW-SHOP SCHEDULING

An instance is feasible when there are start times $\sigma_p(j)$ such that every task finishes by $D$, each processor runs one task at a time (for distinct jobs $j, k$, one task finishes before the other starts), and each job's task on processor $p + 1$ starts no earlier than its task on processor $p$ finishes. A task length $l(t_p[j])$ missing from job $j$'s list counts as $0$.
