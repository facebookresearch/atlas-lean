# Well-formed instances of THREE-MACHINE MULTI-PURPOSE MACHINE FLOW SHOP

An instance is well-formed for THREE-MACHINE MULTI-PURPOSE MACHINE FLOW SHOP when the flow-shop instance $(r, J, K)$ is well-formed ($r > 0$, every job has $r$ tasks, $K > 0$), there is one machine set per stage, every machine set is nonempty with machines among $0, \dots, 2$, and the machine sets are pairwise different as sets.
