# Instances of multi-purpose machine flow shops

An instance is a pair of a FLOW-SHOP SCHEDULING instance $(r, J, K)$ (the number $r$ of stages, one list of processing times per job, its $s$-th entry for stage $s$, and the bound $K$) and a list of machine sets, the $s$-th for stage $s$, each a list of machine indices. That every job lists $r$ processing times and that there are $r$ machine sets is part of well-formedness, not of the instance type.
