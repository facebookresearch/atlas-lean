# Feasible instances of THREE-MACHINE MULTI-PURPOSE MACHINE OPEN SHOP

An instance is feasible when some multi-purpose machine open-shop schedule on the three machines $0, 1, 2$ (one operation of each job per listed stage machine set, each operation on a machine of its stage, no overlap within a job or on a machine, processing times read from the job lists with $0$ for missing entries) completes every job by $K$.
