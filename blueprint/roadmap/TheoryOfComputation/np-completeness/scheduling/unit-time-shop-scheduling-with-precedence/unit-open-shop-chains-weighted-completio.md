# Feasible instances of TWO-MACHINE UNIT-TIME OPEN SHOP WITH CHAINS, WEIGHTED COMPLETION TIME

An instance $(w, A, K)$ is feasible when some unit-time open-shop schedule on two machines respecting the arcs (each machine and each job start operations at pairwise different times; for every arc $(a, b)$ every operation of $b$ starts after every operation of $a$ completes) has $\sum_j w_j (\max(\sigma_0(j), \sigma_1(j)) + 1) \le K$.
