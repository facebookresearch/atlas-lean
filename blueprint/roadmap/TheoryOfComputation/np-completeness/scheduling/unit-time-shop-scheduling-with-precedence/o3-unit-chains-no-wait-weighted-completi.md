# Feasible instances of THREE-MACHINE UNIT-TIME NO-WAIT OPEN SHOP WITH CHAINS, WEIGHTED COMPLETION TIME

An instance $(w, A, K)$ is feasible when some no-wait schedule on three machines (as in the three-machine no-wait late-jobs problem: job $j$ occupies the three consecutive slots from $S(j)$, one operation per machine, obeying the chains) has $\sum_j w_j (S(j) + 3) \le K$.
