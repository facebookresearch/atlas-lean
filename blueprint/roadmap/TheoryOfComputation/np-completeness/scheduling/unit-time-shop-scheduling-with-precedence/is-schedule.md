# Unit-time flow-shop schedules with precedence

For $m$ machines, $n$ jobs and a list $A$ of precedence arcs, natural-number start times $\sigma_k(j)$ of job $j$ on machine $k$ form a unit-time flow-shop schedule for the arcs $A$ when each machine starts its operations at pairwise different times, each operation $O_{j,k+1}$ starts after $O_{j,k}$ completes ($\sigma_k(j) + 1 \le \sigma_{k+1}(j)$), and whenever $(i, j)$ is a listed arc every operation of $j$ starts at or after every operation of $i$ completes ($\sigma_k(i) + 1 \le \sigma_{k'}(j)$ for all machines $k, k'$). Each operation occupies the single unit slot $[\sigma_k(j), \sigma_k(j) + 1)$ of the integer time line, so two operations on one machine overlap exactly when they start at the same time; on a real time line, different start times alone would not prevent overlap.
