# Feasible instances of TWO-PROCESSOR UNIT-TIME FLOW-SHOP TOTAL TARDINESS WITH CHAINS

An instance is feasible when some start times $s_1(j)$ on $M_1$ and $s_2(j)$ on $M_2$ for unit operations run one operation at a time on each machine, start each job on $M_2$ only after it completes on $M_1$ ($s_1(j) + 1 \le s_2(j)$), for every listed arc $(j, k)$ start job $k$ on $M_1$ only after job $j$ completes on $M_2$, and give $\sum_j (s_2(j) + 1 - d_j) \le K$ with truncated subtraction.
