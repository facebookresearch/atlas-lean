# Feasible instances of UNIT-TIME OPEN SHOP WITH PRECEDENCE, MAKESPAN

An instance $(m, P, A, K)$ is feasible when there is a unit-time open-shop schedule respecting the arcs (start times $\sigma_k(j)$ for job $j$ on machine $k$, pairwise different on each machine and within each job, and every operation of $j$ starting at or after every operation of $i$ completes when $(i, j)$ is an arc) completing every operation by $K$. Every operation takes one unit of time, whatever processing times $P$ lists.
