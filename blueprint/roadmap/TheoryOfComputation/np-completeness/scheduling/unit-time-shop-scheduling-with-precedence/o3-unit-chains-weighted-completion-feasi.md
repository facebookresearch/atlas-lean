# Feasible instances of THREE-MACHINE UNIT-TIME OPEN SHOP WITH CHAINS, WEIGHTED COMPLETION TIME

An instance $(w, A, K)$ is feasible when there is a unit-time open-shop schedule on three machines obeying the chain arcs (each machine and each job start operations at pairwise different times; for every arc $(a, b)$ every operation of $b$ starts after every operation of $a$ completes) with $\sum_j w_j C_j \le K$, $C_j$ the latest $\sigma_k(j) + 1$.
