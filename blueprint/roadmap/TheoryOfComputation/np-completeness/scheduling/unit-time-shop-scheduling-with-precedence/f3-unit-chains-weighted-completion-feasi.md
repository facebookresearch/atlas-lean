# Feasible instances of THREE-MACHINE UNIT-TIME FLOW SHOP WITH CHAINS, WEIGHTED COMPLETION TIME

An instance $(w, A, K)$ is feasible when there is a three-machine unit-time flow-shop schedule obeying the chain arcs (the start times $S(j, k)$ of job $j$ on machine $k$ as in the three-machine late-jobs problem) with $\sum_j w_j (S(j, 2) + 1) \le K$.
