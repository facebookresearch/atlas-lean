# Feasible instances of THREE-MACHINE UNIT-TIME FLOW SHOP WITH CHAINS, TOTAL TARDINESS

An instance $(d, A, K)$ is feasible when there is a three-machine unit-time flow-shop schedule obeying the chain arcs (the start times $S(j, k)$ of job $j$ on machine $k$ as in the three-machine late-jobs problem) with $\sum_j (S(j, 2) + 1 - d_j) \le K$ using truncated subtraction.
