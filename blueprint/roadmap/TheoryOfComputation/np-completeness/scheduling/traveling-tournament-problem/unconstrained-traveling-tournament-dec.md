# UNCONSTRAINED TRAVELING TOURNAMENT PROBLEM as a decision problem

The decision problem UNCONSTRAINED TRAVELING TOURNAMENT PROBLEM accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a distance matrix and a bound, to an instance that is [well-formed](well-formed.md) and [feasible](unconstrained-traveling-tournament-feasi.md) for UNCONSTRAINED TRAVELING TOURNAMENT PROBLEM. It rejects every bitstring that does not decode to such an instance.
