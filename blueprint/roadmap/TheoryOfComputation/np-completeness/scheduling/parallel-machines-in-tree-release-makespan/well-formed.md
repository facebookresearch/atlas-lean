# Well Formed

Well-formedness of an instance of `P|intree; r_i; p_i = 1|C_max`: it is a well-formed PRECEDENCE CONSTRAINED SCHEDULING instance (unit processing times, `m > 0`, the listed pairs name jobs and form a strict partial order, `K > 0`), there is one release date per job, and the precedence relation is an in-tree: no job has more than one immediate successor.
