# Time-lag pairs of a single-machine makespan instance with chains and time lags

In an instance of single-machine makespan with chains, time lags and unit processing times, the
job $j$ is related to the job $k$ when the list of time lags contains a triple $(j, k, \ell)$ for
some lag $\ell$; these are the pairs whose transitive closure must be acyclic.
