# Tasks of a single-machine instance given by triples

For a single-machine sequencing instance given by a list of $n$ triples of natural numbers and a bound, the tasks, or jobs, are $0, \dots, n - 1$, one for each listed triple. The same indexing serves SEQUENCING TO MINIMIZE TARDY TASKS WITH RELEASE TIMES, SEQUENCING TO MINIMIZE TOTAL TARDINESS WITH RELEASE TIMES, SEQUENCING TO MINIMIZE WEIGHTED TARDINESS, SEQUENCING WITH RELEASE TIMES TO MINIMIZE WEIGHTED COMPLETION TIME and SINGLE-MACHINE WEIGHTED COMPLETION TIME WITH REJECTION.
