# Length of a task given by a triple

For a single-machine sequencing instance given by a list of triples of natural numbers and a bound, the length, or processing time, $l(t)$ of task $t$ is the first coordinate of the $t$-th triple. The same projection serves SEQUENCING TO MINIMIZE TARDY TASKS WITH RELEASE TIMES, SEQUENCING TO MINIMIZE TOTAL TARDINESS WITH RELEASE TIMES, SEQUENCING TO MINIMIZE WEIGHTED TARDINESS, SEQUENCING WITH RELEASE TIMES TO MINIMIZE WEIGHTED COMPLETION TIME and SINGLE-MACHINE WEIGHTED COMPLETION TIME WITH REJECTION.
