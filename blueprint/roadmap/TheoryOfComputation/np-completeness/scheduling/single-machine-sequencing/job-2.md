# Jobs of a single-machine instance with listed precedence pairs

For a single-machine instance given by a list of $n$ pairs of natural numbers (one per job), a list of precedence pairs and a bound, the jobs, or tasks, are $0, \dots, n - 1$, one for each pair of the first list. The same indexing serves SINGLE-MACHINE UNIT JOBS WITH CHAINS AND RELEASE DATES, WEIGHTED COMPLETION TIME, where the pairs are a release date and a weight, and SEQUENCING TO MINIMIZE TARDY TASKS, where they are a length and a deadline.
