# Tasks of a weighted completion time instance

For an instance $(T, K)$ of SEQUENCING WITH RELEASE TIMES TO MINIMIZE WEIGHTED COMPLETION TIME, where $T$ is a list of triples, the tasks are indexed by $\{0, \dots, n-1\}$ with $n$ the length of $T$; task $t$ is the $t$-th listed triple $(l(t), r(t), w(t))$.
