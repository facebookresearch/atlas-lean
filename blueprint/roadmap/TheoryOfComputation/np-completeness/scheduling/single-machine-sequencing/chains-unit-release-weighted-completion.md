# Feasible instances of SINGLE-MACHINE UNIT JOBS WITH CHAINS AND RELEASE DATES, WEIGHTED COMPLETION TIME

An instance is feasible when some one-processor schedule of unit-time jobs starts each job at or after its release date, completes $j$ before $k$ starts whenever $j$ precedes $k$, and has $\sum_j w_j (\sigma(j) + 1) \le K$.
