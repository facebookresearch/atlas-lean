# SINGLE-MACHINE EQUAL PROCESSING TIMES WITH RELEASE DATES, WEIGHTED TARDINESS is NP-complete

The decision problem SINGLE-MACHINE EQUAL PROCESSING TIMES WITH RELEASE DATES, WEIGHTED TARDINESS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- Z.-L. Chen and N. G. Hall, "Strong NP-hardness and approximation algorithm for weighted tardiness with release dates and identical processing times", arXiv:2609.28751 (2026), Section 3 and Theorem 1 (preprint).
- P. Brucker and S. Knust, *Complexity results for scheduling problems*, class `ein_ma` (single machine problems), entry `1|p_i=p;r_i|Σw_iT_i` (listed as open).
