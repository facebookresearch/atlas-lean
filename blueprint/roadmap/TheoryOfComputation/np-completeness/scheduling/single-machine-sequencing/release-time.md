# Release time of a task given by a triple

For a single-machine sequencing instance given by a list of triples of natural numbers and a bound, the release time $r(t)$ of task $t$ is the second coordinate of the $t$-th triple. The same projection serves SEQUENCING TO MINIMIZE TARDY TASKS WITH RELEASE TIMES, SEQUENCING TO MINIMIZE TOTAL TARDINESS WITH RELEASE TIMES and SEQUENCING WITH RELEASE TIMES TO MINIMIZE WEIGHTED COMPLETION TIME.
