# OUT-TREE TIME LAGS, MAXIMUM LATENESS (1|outtree(l); pᵢ = 1|L_max) as a decision problem

`1|outtree(l); pᵢ = 1|L_max` as a decision problem over bitstrings: a bitstring is accepted exactly when it decodes to an instance that is well formed and has a solution; every bitstring that decodes to no instance is rejected.
