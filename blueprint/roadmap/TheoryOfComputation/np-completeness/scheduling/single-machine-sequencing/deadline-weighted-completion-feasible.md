# Feasible instances of SEQUENCING TO MINIMIZE WEIGHTED COMPLETION TIME WITH DEADLINES

An instance $(T, K)$ of SEQUENCING TO MINIMIZE WEIGHTED TARDINESS type is feasible for SEQUENCING TO MINIMIZE WEIGHTED COMPLETION TIME WITH DEADLINES when some one-processor schedule meets every deadline ($\sigma(t) + l(t) \le d(t)$) and has $\sum_t (\sigma(t) + l(t)) \cdot w(t) \le K$.
