# Feasible instances of OUT-TREE TIME LAGS, MAXIMUM LATENESS (1|outtree(l); pᵢ = 1|L_max)

In `1|outtree(l); pᵢ = 1|L_max`: some one-processor schedule `σ` of the unit-time jobs (nonnegative integer start times `σ j`, completion times `σ j + 1`) satisfies every time lag (`j → j'` implies `σ j + 1 + l ≤ σ j'`) and has maximum lateness at most `K`: `(σ j + 1) - dⱼ ≤ K` for every job `j`.
