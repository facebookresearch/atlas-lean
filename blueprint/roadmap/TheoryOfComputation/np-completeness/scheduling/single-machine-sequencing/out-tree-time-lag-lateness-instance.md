# Instances of OUT-TREE TIME LAGS, MAXIMUM LATENESS (1|outtree(l); pᵢ = 1|L_max)

An instance of `1|outtree(l); pᵢ = 1|L_max`: the due dates `d₀, …, dₙ₋₁` as `(positive part, negative part)` pairs, the pairs `(i, j)` with `i → j`, the time lag `l`, and the bound `K` as a `(positive part, negative part)` pair.
