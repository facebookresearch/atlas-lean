# Feasible instances of PREEMPTIVE SEQUENCING TO MINIMIZE WEIGHTED COMPLETION TIME WITH RELEASE TIMES

An instance $(T, K)$ of sequencing with release times (tasks $(l, r, w)$) is feasible for PREEMPTIVE SEQUENCING TO MINIMIZE WEIGHTED COMPLETION TIME WITH RELEASE TIMES when some preemptive one-processor slot schedule uses no slot before a task's release time and has $\sum_t w(t) C(t) \le K$.
