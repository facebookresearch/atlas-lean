# SINGLE-MACHINE UNIT JOBS WITH CHAINS AND UNIT LAG, WEIGHTED COMPLETION TIME is NP-complete

The decision problem SINGLE-MACHINE UNIT JOBS WITH CHAINS AND UNIT LAG, WEIGHTED COMPLETION TIME belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
