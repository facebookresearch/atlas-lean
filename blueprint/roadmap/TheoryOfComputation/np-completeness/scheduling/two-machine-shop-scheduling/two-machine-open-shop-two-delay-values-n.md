# TWO-MACHINE OPEN SHOP WITH TWO DELAY VALUES is NP-complete

The decision problem TWO-MACHINE OPEN SHOP WITH TWO DELAY VALUES belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- W. Yu, *The two-machine flow shop problem with delays and the one-machine total tardiness problem*, PhD thesis, Technische Universiteit Eindhoven (1996), Chapter 2, Section 2.5, Theorem 4 (pp. 13-16).
- P. Brucker and S. Knust, *Complexity results for scheduling problems*, Universität Osnabrück (online tables), class "Open-shop problems with transportation delays" (records the problem `O2|tᵢ ∈ {T₁, T₂}|Cmax` as minimal NP-hard in the strong sense, citing Yu (1996)).
