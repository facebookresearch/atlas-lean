# Instances of TWO-MACHINE UNIT-TIME NO-WAIT JOB SHOP WITH RELEASE DATES, MAXIMUM LATENESS

An instance is a pair of a list of jobs, each $(\mu_{j1}, n_j, r_j, d_j)$ (first machine, number of operations, release date, integer due date as a pair $(d^+, d^-)$), and an integer bound $K$ as a pair $(K^+, K^-)$.
