# TWO-MACHINE FLOW SHOP WITH TWO DELAY VALUES is NP-complete

The decision problem TWO-MACHINE FLOW SHOP WITH TWO DELAY VALUES belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- W. Yu, *The two-machine flow shop problem with delays and the one-machine total tardiness problem*, PhD thesis, Technische Universiteit Eindhoven (1996), Chapter 2, Theorem 1.
- P. Brucker and S. Knust, *Complexity results for scheduling problems*, Universität Osnabrück (online tables), class "Flow-shop problems with transportation delays" (records the problem `F2|tⱼ ∈ {T₁, T₂}|Cmax` as minimal NP-hard, citing Yu (1996)).
