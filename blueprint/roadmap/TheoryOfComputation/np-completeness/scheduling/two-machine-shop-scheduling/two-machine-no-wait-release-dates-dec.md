# TWO-MACHINE NO-WAIT FLOW SHOP WITH RELEASE DATES, MAKESPAN as a decision problem

The decision problem TWO-MACHINE NO-WAIT FLOW SHOP WITH RELEASE DATES, MAKESPAN accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a triple $(m, J, D)$ and a list of natural numbers, to an instance that is well-formed and feasible for TWO-MACHINE NO-WAIT FLOW SHOP WITH RELEASE DATES, MAKESPAN. It rejects every bitstring that does not decode to such an instance.
