# Feasible instances of TWO-MACHINE OPEN SHOP WITH RELEASE DATES, MAKESPAN

An instance is feasible when some start times finish every task by $K$, run one task at a time on each processor, never overlap two tasks of the same job, and start every task of every job at or after its release date (release dates missing from the list read as $0$). A task length $l(t_p[j])$ missing from job $j$'s list counts as $0$.
