# Feasible instances of TWO-MACHINE UNIT-TIME NO-WAIT JOB SHOP, TOTAL WEIGHTED TARDINESS

An instance is feasible when there are start times in which distinct operations on the same machine occupy disjoint unit intervals and each later operation of a job starts exactly one time unit after the previous one, with $\sum_j w_j (C_j - d_j) \le K$ using truncated subtraction, $C_j$ the completion of job $j$'s last operation for each job $j$ with operations. A job with no operations has no last operation, so its $C_j$ is unconstrained and can be taken as $0$.
