# Feasible instances of TWO-MACHINE FLOW SHOP WITH RELEASE DATES, MAKESPAN

An instance is feasible when some flow-shop start times finishing every task by $D$, running one task at a time on each processor, running each job's tasks in processor order, and starting each job's first task at or after its release date (release dates missing from the list read as $0$). A task length $l(t_p[j])$ missing from job $j$'s list counts as $0$.
