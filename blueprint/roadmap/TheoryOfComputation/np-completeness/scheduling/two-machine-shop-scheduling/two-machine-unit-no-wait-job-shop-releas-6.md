# Feasible instances of TWO-MACHINE UNIT-TIME NO-WAIT JOB SHOP WITH RELEASE DATES, TOTAL COMPLETION TIME

An instance is feasible when some start times are one-to-one on each machine's operations, keep a later operation on a machine after an earlier one finishes, start each later operation of a job exactly when the previous one finishes, start no operation of job $j$ before $r_j$, and give $\sum_j C_j \le K$, where $C_j$ is the latest completion time of an operation of job $j$, and $0$ for a job with no operations.
