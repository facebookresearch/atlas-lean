# Feasible instances of TWO-MACHINE UNIT-TIME FLOW SHOP WITH DELAYS, WEIGHTED COMPLETION TIME

An instance is feasible when some start times $s_1(j), s_2(j)$ on $M_1, M_2$ have no two unit operations overlapping on either machine, satisfy $s_1(j) + 1 + t_j \le s_2(j)$, and give $\sum_j w_j (s_2(j) + 1) \le K$.
