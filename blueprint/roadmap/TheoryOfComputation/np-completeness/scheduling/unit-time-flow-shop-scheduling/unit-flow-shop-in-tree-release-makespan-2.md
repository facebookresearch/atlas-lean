# Feasible instances of FLOW SHOP F|p_ij=1;intree;r_i|Cmax

An instance of FLOW SHOP F|p_ij=1;intree;r_i|Cmax is feasible when some schedule starts no operation of job `j` before `r_j` and completes every operation by time `K` (makespan `max_j C_j ≤ K`). Feasibility does not include well-formedness; the decision problem requires both. A position beyond the end of a list reads as the default entry `([], 0)`.
