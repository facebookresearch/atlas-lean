# TWO-PROCESSOR UET CONCURRENT TASK SCHEDULING WITH CHAINS AND RELEASE DATES as a decision problem

The decision problem TWO-PROCESSOR UET CONCURRENT TASK SCHEDULING WITH CHAINS AND RELEASE DATES accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a resource-constrained scheduling instance with precedence and a list of natural numbers, to an instance that is well-formed and feasible for TWO-PROCESSOR UET CONCURRENT TASK SCHEDULING WITH CHAINS AND RELEASE DATES. It rejects every bitstring that does not decode to such an instance.
