# TWO-PROCESSOR SCHEDULING WITH TASK SIZES AND RELEASE DATES, MAKESPAN as a decision problem

The decision problem TWO-PROCESSOR SCHEDULING WITH TASK SIZES AND RELEASE DATES, MAKESPAN accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs $(T, K)$ (a list of triples of natural numbers and a natural number), to an instance that is well-formed and feasible for TWO-PROCESSOR SCHEDULING WITH TASK SIZES AND RELEASE DATES, MAKESPAN. It rejects every bitstring that does not decode to such an instance.
