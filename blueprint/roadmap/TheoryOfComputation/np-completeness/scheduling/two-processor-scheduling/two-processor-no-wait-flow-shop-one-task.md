# Instances of TWO-PROCESSOR NO-WAIT FLOW SHOP WITH ONE-TASK JOBS

An instance is a pair $(J, D)$ of a list of jobs, each a triple $(b, l_1, l_2)$ where $b$ true means the job has tasks of lengths $l_1$ and $l_2$ on processors 1 and 2, and $b$ false means it has only the task of length $l_2$ on processor 2; and a deadline $D$.
