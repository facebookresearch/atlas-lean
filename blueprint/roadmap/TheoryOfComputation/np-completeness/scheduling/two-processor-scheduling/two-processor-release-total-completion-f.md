# Feasible instances of TWO PARALLEL MACHINES WITH RELEASE DATES, TOTAL COMPLETION TIME

An instance $(T, K)$ of sequencing with release times (tasks $(l(t), r(t))$) is feasible for TWO PARALLEL MACHINES WITH RELEASE DATES, TOTAL COMPLETION TIME when some start times $\sigma$ and machines $\mu \in \{0, 1\}$ run different jobs on the same machine in disjoint intervals, start every job at or after its release time, and give $\sum_t (\sigma(t) + l(t)) \le K$.
