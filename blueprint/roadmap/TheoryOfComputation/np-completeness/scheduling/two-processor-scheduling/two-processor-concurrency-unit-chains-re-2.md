# Feasible instances of TWO-PROCESSOR UET CONCURRENT TASK SCHEDULING WITH CHAINS AND RELEASE DATES

An instance is feasible when some start times of the unit tasks respect release dates, finish every task by $D$, run at most $m$ tasks at a time, respect the precedence, and keep the total resource use of running tasks within the bound at every time. A release date, resource bound or resource requirement missing from its list counts as $0$.
