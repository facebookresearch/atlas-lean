# Feasible instances of TWO-PROCESSOR SCHEDULING WITH TASK SIZES, MAXIMUM LATENESS

An instance is feasible when some start times $S_j$ and processor sets $\pi_j \subseteq \{0, 1\}$ of $\mathrm{size}_j$ processors run two different tasks sharing a processor in disjoint intervals, and $S_j + p_j + K^- \le d_j + K^+$ for every task.
