# Feasible instances of TWO-PROCESSOR NO-WAIT FLOW SHOP WITH ONE-TASK JOBS

An instance is feasible when some start times $\sigma_1$ (on the first tasks) and $\sigma_2$ (on the second tasks) are one-processor schedules (pairwise different, a later task starting after an earlier one finishes; $\sigma_1$ compared only among jobs with a first task), every second task ends by $D$, and a job with two tasks starts its second task exactly when its first ends.
