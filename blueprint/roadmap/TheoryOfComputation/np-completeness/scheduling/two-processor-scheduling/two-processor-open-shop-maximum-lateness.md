# Feasible instances of TWO-MACHINE OPEN SHOP, MAXIMUM LATENESS

An instance of the two-machine flow-shop lateness type is feasible for TWO-MACHINE OPEN SHOP, MAXIMUM LATENESS when some start times $s_1, s_2$ run one operation at a time on each machine, never overlap the two operations of a job, and complete each of the two operations of every job $j$ at a time $C$ with $C + y^- \le d_j + y^+$.
