# Well-formed instances of TWO-PROCESSOR UET CONCURRENT TASK SCHEDULING WITH CHAINS AND RELEASE DATES

An instance is well-formed when the resource-constrained instance with precedence is well-formed, $m = 2$, $r = 1$, the single resource (the processors) has bound $2$, every task needs $1$ or $2$ units of it, the order is a set of chains, there is at least one task, and there is one release date per task.
