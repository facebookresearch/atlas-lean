# Instances of TWO-PROCESSOR UET CONCURRENT TASK SCHEDULING WITH CHAINS AND RELEASE DATES

An instance is a pair of a RESOURCE CONSTRAINED SCHEDULING instance with a list of precedence pairs (processor count $m$, resource count $r$, bounds, one requirement row per task, deadline $D$, and the pairs) and a list of release dates, the $i$-th for task $i$. That the release-date list has one entry per task, and that the pairs form a partial order, is part of well-formedness, not of the instance type.
