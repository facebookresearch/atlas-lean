# Feasible instances of TWO-PROCESSOR FLOW-SHOP SCHEDULING WITH CHAIN PRECEDENCE CONSTRAINTS

An instance is feasible when some flow-shop start times finish every task by $D$, run one task at a time on each processor, run each job's tasks in processor order, and for every listed arc $(j, k)$, start job $k$ on the first processor no earlier than job $j$ finishes on the last processor. A task length missing from a job's list counts as $0$. With no processors there are no tasks, so every such instance is feasible.
