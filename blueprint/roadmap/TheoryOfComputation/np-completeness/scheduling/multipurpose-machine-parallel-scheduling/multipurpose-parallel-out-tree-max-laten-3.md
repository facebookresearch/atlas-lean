# The decision problem MULTIPURPOSE-MACHINE PARALLEL SCHEDULING WITH OUT-TREE PRECEDENCE AND UNIT TIMES TO MINIMIZE MAXIMUM LATENESS

`PMPM|outtree; pᵢ = 1|L_max` as a decision problem on bitstrings: a bitstring is accepted
exactly when it decodes, under the canonical bitstring encoding, to an instance that is
well-formed and feasible. A bitstring that does not decode to an instance is rejected.
