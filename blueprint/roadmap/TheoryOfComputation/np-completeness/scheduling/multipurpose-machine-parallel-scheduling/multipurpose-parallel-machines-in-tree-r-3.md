# The decision problem MPM PARALLEL MACHINES `PMPM|intree; p_i = 1; r_i|C_max`

`PMPM|intree; p_i = 1; r_i|C_max` as a decision problem on bitstrings: a bitstring is accepted
exactly when it decodes, under the canonical bitstring encoding, to an instance that is
well-formed and feasible. A bitstring that does not decode to an instance is rejected.
