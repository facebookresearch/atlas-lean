# Feasible instances of PROJECT SCHEDULING WITH RESOURCES AND TIME WINDOWS: FEASIBILITY

In PROJECT SCHEDULING WITH RESOURCES AND TIME WINDOWS: FEASIBILITY: there are start times `S` satisfying every time lag such that in every period `t` the activities in process require at most `R_k` units of every resource `k`. A list entry that is not present (an index beyond the end of its list) reads as $0$.
