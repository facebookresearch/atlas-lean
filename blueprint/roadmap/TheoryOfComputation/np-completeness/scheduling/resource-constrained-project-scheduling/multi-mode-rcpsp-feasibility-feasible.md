# Feasible MULTI-MODE RCPSP FEASIBILITY (NONRENEWABLE RESOURCES) instances

A MULTI-MODE RCPSP FEASIBILITY instance is feasible when there is a mode assignment $\mu$,
choosing for each activity $j$ one of its listed modes, such that for every nonrenewable
resource $k < K$ the total consumption $\sum_j r_{j \mu(j) k}$ is at most the availability
$R_k$; a consumption or availability missing from its list counts as $0$.
