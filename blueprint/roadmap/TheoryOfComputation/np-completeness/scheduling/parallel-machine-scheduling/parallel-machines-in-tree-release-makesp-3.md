# PARALLEL MACHINES WITH IN-TREE AND RELEASE DATES (P|intree; r_i; p_i = 1|C_max) as a decision problem

`P|intree; r_i; p_i = 1|C_max` as a decision problem over bitstrings: a bitstring is accepted exactly when it decodes to an instance that is well formed and has a solution; every bitstring that decodes to no instance is rejected.
