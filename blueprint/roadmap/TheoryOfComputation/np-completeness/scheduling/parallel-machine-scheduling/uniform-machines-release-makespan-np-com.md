# UNIFORM MACHINES WITH RELEASE DATES, MAKESPAN is NP-complete

For every natural number $m_0 \ge 2$, the decision problem UNIFORM MACHINES WITH RELEASE DATES, MAKESPAN belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
