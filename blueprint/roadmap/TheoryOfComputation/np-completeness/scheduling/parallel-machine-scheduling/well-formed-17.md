# Well-formed instances of UNIT-TIME PARALLEL BATCHING WITH CHAINS, TOTAL TARDINESS

An instance is well-formed for UNIT-TIME PARALLEL BATCHING WITH CHAINS, TOTAL TARDINESS when the unit-task instance is well-formed with a chain-like order (the weighted-tardiness instance is well-formed (positive lengths, weights and deadlines, $K > 0$), every task has length $1$ and weight $1$, every pair in $P$ names two tasks, and the listed pairs form a strict partial order; chain-like) and $0 < b < n$, the number of jobs.
