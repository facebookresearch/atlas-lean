# UNRELATED PARALLEL MACHINES WITH MAKESPAN 2 is NP-complete

The decision problem UNRELATED PARALLEL MACHINES WITH MAKESPAN 2 belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- J. K. Lenstra, D. B. Shmoys and É. Tardos, "Approximation algorithms for scheduling unrelated parallel machines", Mathematical Programming 46 (1990), 259-271, doi:10.1007/BF01585745, Theorem 5 ("For the minimum makespan problem on unrelated parallel machines, the question of deciding if there exists a schedule with makespan at most 2 is NP-complete"; read in the CWI report OS-R8714, 1987, of the same title).
- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [SS8] MULTIPROCESSOR SCHEDULING (the identical machine version).
