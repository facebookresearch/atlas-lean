# Feasible instances of UNIT-TIME PARALLEL BATCHING WITH CHAINS, TOTAL TARDINESS

An instance is feasible when some batch start times $\sigma(t)$ put at most $b$ jobs at each start time, respect the precedence pairs ($\sigma(t) + l(t) \le \sigma(t')$), and give $\sum (\sigma(t) + l(t) - d(t)) \cdot w(t) \le K$ over the tardy jobs.
