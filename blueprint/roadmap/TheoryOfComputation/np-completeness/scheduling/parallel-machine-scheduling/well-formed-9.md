# Well-formed instances of TWO-PROCESSOR CHAINS SCHEDULING TO MINIMIZE TOTAL COMPLETION TIME

An instance $(m, T, K, P)$ is well-formed when $m = 2$, every length is positive, every weight is $1$, $K > 0$, every pair names two tasks, the pairs form a strict partial order, and the order is a set of chains: no task has more than one immediate predecessor or more than one immediate successor.
