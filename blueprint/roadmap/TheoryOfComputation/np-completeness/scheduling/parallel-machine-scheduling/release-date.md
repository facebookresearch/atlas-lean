# Release date of a task in multiprocessor scheduling with release dates

For any instance of MULTIPROCESSOR SCHEDULING WITH RELEASE DATES, the release date $r(t)$ of task $t$ is entry $t$ of the list of release dates, read as $0$ when the list has no entry $t$. No hypothesis on the number of processors is involved; the fixed processor count $m \ge 2$ belongs to the NP-completeness statement, not to this lookup.
