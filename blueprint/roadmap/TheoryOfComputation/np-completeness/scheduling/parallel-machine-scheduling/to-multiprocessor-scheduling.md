# Multiprocessor scheduling instance underlying a speed-factor instance

For a MULTIPROCESSOR SCHEDULING WITH SPEED FACTORS instance, given by task lengths, a list of speed records and a bound $K$, the underlying MULTIPROCESSOR SCHEDULING instance consists of the same task lengths, the number $m$ of speed records as the number of processors, and $K$. The instance stores no separate machine count; for an empty list of speed records, $m = 0$.
