# UNIFORM MACHINES WITH RELEASE DATES, MAKESPAN as a decision problem

Fix a natural number $m_0$. The decision problem UNIFORM MACHINES WITH RELEASE DATES, MAKESPAN accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a triple $(p, s, K)$ and a list of natural numbers, to an instance that is well-formed for $m_0$ machines and feasible for UNIFORM MACHINES WITH RELEASE DATES, MAKESPAN. It rejects every bitstring that does not decode to such an instance.
