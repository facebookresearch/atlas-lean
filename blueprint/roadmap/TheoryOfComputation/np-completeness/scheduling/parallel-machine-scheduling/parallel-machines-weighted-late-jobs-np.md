# IDENTICAL PARALLEL MACHINES, WEIGHTED NUMBER OF LATE JOBS is NP-complete

For every natural number $m_0 \ge 1$, the decision problem IDENTICAL PARALLEL MACHINES, WEIGHTED NUMBER OF LATE JOBS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
