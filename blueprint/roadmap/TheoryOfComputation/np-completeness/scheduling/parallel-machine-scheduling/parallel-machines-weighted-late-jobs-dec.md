# IDENTICAL PARALLEL MACHINES, WEIGHTED NUMBER OF LATE JOBS as a decision problem

Fix a natural number $m_0$. The decision problem IDENTICAL PARALLEL MACHINES, WEIGHTED NUMBER OF LATE JOBS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a uniform-machine instance with due dates and a list of natural numbers, to an instance that is well-formed for IDENTICAL PARALLEL MACHINES, WEIGHTED NUMBER OF LATE JOBS and feasible for uniform machines, weighted number of late jobs. It rejects every bitstring that does not decode to such an instance.
