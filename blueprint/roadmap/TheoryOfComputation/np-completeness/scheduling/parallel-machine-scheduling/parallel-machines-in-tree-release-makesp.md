# Instances of PARALLEL MACHINES WITH IN-TREE AND RELEASE DATES (P|intree; r_i; p_i = 1|C_max)

An instance of `P|intree; r_i; p_i = 1|C_max`: a PRECEDENCE CONSTRAINED SCHEDULING instance (processing times, all `1`; the number `m` of machines; the pairs `(t, t')` with `t → t'`; the bound `K`) and the release dates, job `t` having the `t`-th listed release date `r_t`.
