# Feasible instances of UNIFORM MACHINES, WEIGHTED NUMBER OF LATE JOBS

An instance is feasible when there is a machine $\mu(t)$ and a rational start time $S(t)$ for each job, with jobs on the same machine occupying disjoint intervals $[S(t), C_t)$, where $C_t = S(t) + p_t / s_{\mu(t)}$, all start times nonnegative, whose late jobs ($C_t > d_t$) have total weight at most $K$. The quotient is computed in $\mathbb{Q}$ with $x / 0 = 0$, so a job on a machine whose speed $a/b$ has $a = 0$ or $b = 0$ completes at $S(t)$; a job with no entry in the due-date list has due date $0$, and one with no entry in the weight list has weight $0$.
