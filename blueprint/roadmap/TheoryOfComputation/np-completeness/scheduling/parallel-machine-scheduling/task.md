# Tasks of an instance given by a list of lengths

For an instance given by a list of $n$ natural numbers and two further natural numbers, the tasks, or jobs, are $0, \dots, n - 1$, one for each listed number. The same indexing serves MULTIPROCESSOR SCHEDULING, with the listed task lengths, and EARLINESS-TARDINESS WITH A RESTRICTIVE COMMON DUE DATE, with the listed processing times.
