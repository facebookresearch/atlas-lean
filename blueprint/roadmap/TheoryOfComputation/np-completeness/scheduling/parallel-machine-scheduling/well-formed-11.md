# Well-formed instances of TWO-PROCESSOR UNIT-TIME CHAINS SCHEDULING TO MINIMIZE WEIGHTED COMPLETION TIME

An instance $(m, T, K, P)$ is well-formed when $m = 2$, every processing time is $1$, every pair names two jobs, the pairs form a strict partial order, and the order is a set of chains (in-tree and out-tree). Weights and $K$ are arbitrary.
