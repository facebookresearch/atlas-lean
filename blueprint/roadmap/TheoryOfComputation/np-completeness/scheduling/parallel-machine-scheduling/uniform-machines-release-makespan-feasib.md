# Feasible instances of UNIFORM MACHINES WITH RELEASE DATES, MAKESPAN

An instance is feasible when there is a machine $\mu(t)$ and a rational start time $S(t)$ for each job, with jobs on the same machine occupying disjoint intervals $[S(t), C_t)$, where $C_t = S(t) + p_t / s_{\mu(t)}$, and every job starts at or after its release date and completes by $K$. The quotient is computed in $\mathbb{Q}$ with $x / 0 = 0$, so a job on a machine whose speed $a/b$ has $a = 0$ or $b = 0$ completes at $S(t)$; a job with no entry in the release-date list has release date $0$.
