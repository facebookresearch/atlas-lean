# UNIT-TIME PARALLEL BATCHING WITH CHAINS, WEIGHTED COMPLETION TIME is NP-complete

The decision problem UNIT-TIME PARALLEL BATCHING WITH CHAINS, WEIGHTED COMPLETION TIME belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
