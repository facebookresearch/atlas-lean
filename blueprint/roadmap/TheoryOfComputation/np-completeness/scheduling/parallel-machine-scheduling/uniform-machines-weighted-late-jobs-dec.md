# UNIFORM MACHINES, WEIGHTED NUMBER OF LATE JOBS as a decision problem

Fix a natural number $m_0$. The decision problem UNIFORM MACHINES, WEIGHTED NUMBER OF LATE JOBS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a uniform-machine instance with due dates and a list of natural numbers, to an instance that is well-formed for $m_0$ machines and feasible for UNIFORM MACHINES, WEIGHTED NUMBER OF LATE JOBS. It rejects every bitstring that does not decode to such an instance.
