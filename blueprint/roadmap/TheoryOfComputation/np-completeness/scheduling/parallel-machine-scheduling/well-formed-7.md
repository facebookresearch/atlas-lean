# Well-formed instances of IDENTICAL PARALLEL MACHINES, WEIGHTED NUMBER OF LATE JOBS

Fix a natural number $m_0$. An instance is well-formed when it is well-formed for uniform machines with weighted late jobs (every processing time is positive, exactly $m_0$ speeds are listed, every speed $a/b$ has $a > 0$ and $b > 0$, and the per-job list has one entry per job, there is one weight per job, and all due dates, weights and $K$ are positive) and every speed is $(1, 1)$.
