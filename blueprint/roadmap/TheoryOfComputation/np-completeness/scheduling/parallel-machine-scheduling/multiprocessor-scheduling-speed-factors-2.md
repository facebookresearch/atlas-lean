# Feasible instances of MULTIPROCESSOR SCHEDULING WITH SPEED FACTORS

An instance is feasible when some assignment of tasks to processors has, for every processor $p$, the total length of its tasks divided by $s(p)$ at most $K$. The quotient is computed in $\mathbb{Q}$ with $x / 0 = 0$, so a processor whose speed factor $a/b$ has $a = 0$ or $b = 0$ meets the bound whatever it is assigned.
