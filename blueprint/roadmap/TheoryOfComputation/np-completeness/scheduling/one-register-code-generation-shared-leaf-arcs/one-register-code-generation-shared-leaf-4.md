# CODE GENERATION ON A ONE-REGISTER MACHINE (shared vertices have arcs only to leaves) is NP-complete

CODE GENERATION ON A ONE-REGISTER MACHINE (shared vertices have arcs only to leaves) is NP-complete: the decision problem over bitstrings that accepts exactly the encodings of well-formed instances with a solution lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
