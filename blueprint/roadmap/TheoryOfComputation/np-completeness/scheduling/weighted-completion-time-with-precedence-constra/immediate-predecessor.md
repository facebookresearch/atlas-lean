# Immediate predecessors in a precedence relation

In an instance of TWO-PROCESSOR TREE-PRECEDENCE SCHEDULING TO MINIMIZE TOTAL COMPLETION TIME with precedence relation $<$, task $t$ is an immediate predecessor of task $t'$ (and $t'$ an immediate successor of $t$) when $t < t'$ and there is no task $c$ with $t < c$ and $c < t'$.
