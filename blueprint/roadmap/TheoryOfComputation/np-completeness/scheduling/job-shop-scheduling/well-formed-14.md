# Well-formed instances of TWO-PROCESSOR UNIT-TIME MULTIPROCESSOR TASK JOB SHOP WITH RELEASE DATES, WEIGHTED COMPLETION TIME

An instance is well-formed when the job-shop instance is well-formed ($m = 2$, every job has at least one task, and every task has a nonempty processor set in $\{1, \dots, m\}$) and there is one pair per job.
