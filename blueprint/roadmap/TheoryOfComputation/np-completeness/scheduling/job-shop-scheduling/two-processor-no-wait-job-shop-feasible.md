# Feasible instances of TWO-PROCESSOR NO-WAIT JOB-SHOP SCHEDULING

An instance $(m, J, D)$ is feasible for TWO-PROCESSOR NO-WAIT JOB-SHOP SCHEDULING when there are start times $\sigma(t) \in \mathbb{N}$ for the tasks such that two tasks on the same processor never start at the same time, a task starting after another task $t'$ on the same processor starts no earlier than $\sigma(t') + l(t')$, each task of a job starts no earlier than the previous task of that job finishes, the last task of every job finishes by $D$, and each task of a job after the first starts exactly when the previous task of that job finishes (no wait).
