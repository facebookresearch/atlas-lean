# Feasible instances of TWO-PROCESSOR NO-WAIT JOB-SHOP TOTAL COMPLETION TIME

An instance $(m, J, K)$ is feasible for TWO-PROCESSOR NO-WAIT JOB-SHOP TOTAL COMPLETION TIME when there are start times $\sigma(t) \in \mathbb{N}$ for the tasks such that two tasks on the same processor never start at the same time, a task starting after another task $t'$ on the same processor starts no earlier than $\sigma(t') + l(t')$, each task of a job starts no earlier than the previous task of that job finishes, each task of a job after the first starts exactly when the previous task of that job finishes (no wait), and the job completion times $C_j$ satisfy $\sum_j C_j \le K$, with $C_j$ the finishing time of the last task of each job $j$ with tasks. A job with no tasks has no last task, so its $C_j$ is unconstrained and can be taken to be $0$.
