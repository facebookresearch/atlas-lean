# Instances of TWO-PROCESSOR UNIT-TIME MULTIPROCESSOR TASK JOB SHOP WITH RELEASE DATES, WEIGHTED COMPLETION TIME

An instance is a pair of a unit-time job-shop instance $(m, J, K)$ and a list of pairs $(r_j, w_j)$, job $j$ having the $j$-th listed pair. That the list has one entry per job is part of well-formedness, not of the instance type.
