# Feasible instances of TWO-PROCESSOR UNIT-TIME JOB SHOP WITH RELEASE DATES, WEIGHTED COMPLETION TIME

An instance is feasible when there are job-shop start times one-to-one on the tasks of each processor, a later task on a processor starting no earlier than an earlier one ends, and the tasks of each job in order, the first task of every job starting at or after $r_j$, with $\sum_j w_j C_j \le K$, $C_j$ the end of job $j$'s last task (pairs missing from the list read as $(0, 0)$).
