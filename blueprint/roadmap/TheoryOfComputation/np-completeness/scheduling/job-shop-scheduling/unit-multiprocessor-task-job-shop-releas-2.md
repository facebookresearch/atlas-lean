# Feasible instances of TWO-PROCESSOR UNIT-TIME MULTIPROCESSOR TASK JOB SHOP WITH RELEASE DATES, WEIGHTED COMPLETION TIME

An instance is feasible when some unit-time multiprocessor task job-shop schedule starts the first task of every job at or after $r_j$ and has $\sum_j w_j C_j \le K$ (pairs missing from the list read as $(0, 0)$).
