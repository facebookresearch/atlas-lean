# Feasible instances of TWO-PROCESSOR UNIT-TIME MULTIPROCESSOR TASK JOB SHOP WITH RELEASE DATES, WEIGHTED COMPLETION TIME

An instance is feasible when some unit-time multiprocessor task job-shop schedule starts the first task of every job at or after $r_j$ and has $\sum_j w_j C_j \le K$, with $C_j$ the completion time of the last task of each job $j$ with tasks (pairs missing from the list read as $(0, 0)$). A job with no tasks has no first or last task, so $r_j$ does not constrain it and its $C_j$ is unconstrained and can be taken to be $0$.
