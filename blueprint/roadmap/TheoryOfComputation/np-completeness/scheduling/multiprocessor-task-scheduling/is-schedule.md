# MULTIPROCESSOR TASKS `P2|intree;p_i=1;size_i|ΣC_i`: `σ j` is the start time of the unit task `j`

In MULTIPROCESSOR TASKS `P2|intree;p_i=1;size_i|ΣC_i`, `σ j` is the start time of the unit task `j`, that is, the tasks starting at any time `t` have total size at most `2`, and if `i` precedes `j`, then `j` starts after `i` is completed.
