# Instances of MULTIPROCESSOR TASKS `P2|intree;p_i=1;size_i|ΣC_i`

An instance of MULTIPROCESSOR TASKS `P2|intree;p_i=1;size_i|ΣC_i` is a value of type `List ℕ × List (ℕ × ℕ) × ℕ`: an instance `(sizes, A, K)`: the sizes `size_i` of the tasks `0, …, n - 1` (one per entry), the precedence arcs `A` (`(i, j)`: task `i` precedes task `j`), and the bound `K`.
