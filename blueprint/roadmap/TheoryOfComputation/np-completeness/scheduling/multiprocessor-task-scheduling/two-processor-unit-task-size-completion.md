# Feasible instances of MULTIPROCESSOR TASKS `P2|intree;p_i=1;size_i|ΣC_i`

An instance of MULTIPROCESSOR TASKS `P2|intree;p_i=1;size_i|ΣC_i` is feasible when some schedule has total completion time `Σ (σ j + 1)` at most `K`. Feasibility does not include well-formedness; the decision problem requires both.
