# The MULTIPROCESSOR TASKS `P2|outtree;p_i=1;size_i|ΣC_i` decision problem

The MULTIPROCESSOR TASKS `P2|outtree;p_i=1;size_i|ΣC_i` decision problem accepts a bitstring exactly when it decodes, under the canonical bitstring encoding, to an instance that is well formed and feasible. Bitstrings that do not decode to an instance are rejected.
