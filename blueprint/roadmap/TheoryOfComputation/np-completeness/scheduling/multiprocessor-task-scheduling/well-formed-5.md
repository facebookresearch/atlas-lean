# Well-formed instances of MULTIPROCESSOR TASKS `P2|outtree;p_i=1;size_i|ΣC_i`

An instance of MULTIPROCESSOR TASKS `P2|outtree;p_i=1;size_i|ΣC_i` is well formed when the tasks have sizes `1` or `2` and the arcs name tasks and generate an acyclic relation, and every task has at most one immediate predecessor (a task `a` with `a < j` and no task strictly between) in the order generated by the arcs.
