# IN-TREE TIME LAGS WITH RELEASE DATES is NP-complete

The decision problem IN-TREE TIME LAGS WITH RELEASE DATES belongs to NP, and every decision
problem in NP has a polynomial-time many-one reduction to it.

## Sources

- P. Brucker and S. Knust, "Complexity results for single-machine problems with positive finish-start time-lags", Computing 63 (1999), 299-316, doi:10.1007/s006070050036.
- P. Brucker and S. Knust, *Complexity results for scheduling problems*, http://www2.informatik.uni-osnabrueck.de/knust/class/, class "Single machine problems with non-negative time-lags", which lists `1|intree(l); pᵢ = 1; rᵢ|C_max` as strongly NP-hard with the attribution to Brucker and Knust (1999).
