# Instances of IN-TREE TIME LAGS WITH RELEASE DATES

An instance of IN-TREE TIME LAGS WITH RELEASE DATES consists of a list of natural release dates, a list of natural pairs $(i, j)$ (read as $i \to j$), a natural time lag $l$ and a natural bound $K$. With one job, the pair $(0, 1)$ can be stored but relates no two jobs; such conditions belong to [validation](well-formed.md).
