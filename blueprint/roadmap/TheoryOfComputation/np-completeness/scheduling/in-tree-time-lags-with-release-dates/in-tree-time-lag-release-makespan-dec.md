# IN-TREE TIME LAGS WITH RELEASE DATES as a decision problem

The decision problem IN-TREE TIME LAGS WITH RELEASE DATES accepts a bitstring $x$ exactly when
$x$ decodes, under the canonical bitstring encoding of IN-TREE TIME LAGS WITH RELEASE DATES
instances, to an instance that is [well-formed](well-formed.md) and
[feasible](in-tree-time-lag-release-makespan-feasib.md). It rejects every bitstring that does
not decode to an instance.
