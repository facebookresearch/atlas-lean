# Feasible IN-TREE TIME LAGS WITH RELEASE DATES instances

A IN-TREE TIME LAGS WITH RELEASE DATES instance is feasible when some one-processor schedule `σ`
of the unit-time jobs (start times `σ j`, completion times `σ j + 1`) respects the release
dates, satisfies every time lag (`j → j'` implies `σ j + 1 + l ≤ σ j'`) and has makespan at most
`K`.
