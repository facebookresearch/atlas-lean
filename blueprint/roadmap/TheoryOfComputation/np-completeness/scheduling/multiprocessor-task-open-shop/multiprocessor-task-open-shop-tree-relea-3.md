# MPT OPEN SHOP, TREE PRECEDENCE, RELEASE DATES (OMPT|tree; r_i; p_ij = 1|C_max) is NP-complete

The decision problem MPT OPEN SHOP, TREE PRECEDENCE, RELEASE DATES (OMPT|tree; r_i; p_ij =
1|C_max) is NP-complete: it belongs to NP, and every decision problem in NP has a
polynomial-time many-one reduction to it.

Source: Timkovsky (2003); Brucker and Knust, *Complexity results for scheduling problems*;
Brucker (2004), Chapter 11.
