# Feasible MPT OPEN SHOP WITH TREE PRECEDENCE AND UNIT TIMES (OMPT|tree; p_ij = 1|L_max) instances

An instance is feasible when some multiprocessor-task open-shop schedule of the unit-time jobs
obeys the tree precedence constraints and has maximum lateness at most $K$: $C_j - d_j \le K$
for every job $j$, computed in the integers, where $C_j$ is the completion time of job $j$.
