# The decision problem MPT OPEN SHOP, TREE PRECEDENCE, RELEASE DATES (OMPT|tree; r_i; p_ij = 1|C_max)

`OMPT|tree; r_i; p_ij = 1|C_max` as a decision problem on bitstrings: a bitstring is accepted exactly when it decodes, under the canonical bitstring encoding, to an instance that is [well-formed](../multiprocessor-task-flow-shop/well-formed-3.md) (in particular, every stage needs at least one processor) and feasible. A bitstring that does not decode to an instance is rejected.
