# Feasible instances of MULTIPROCESSOR TASK JOB SHOP WITH THREE JOBS, TOTAL COMPLETION TIME

An instance is feasible when some multiprocessor task job-shop schedule and values $C_j$, each at least the completion time of the last task of job $j$, satisfy $\sum_j C_j \le K$. A job with no tasks has no last task, so its $C_j$ is unconstrained and can be taken to be $0$.
