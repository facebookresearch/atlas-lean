# Multiprocessor task job-shop schedules

Start times $\sigma(t)$ form a multiprocessor task job-shop schedule when each task $t$ occupies all its machines $\mu_t$ during $[\sigma(t), \sigma(t) + p_t)$, two different tasks of positive length whose machine lists share a machine do not overlap, and each task of a job starts no earlier than the previous task of that job completes.
