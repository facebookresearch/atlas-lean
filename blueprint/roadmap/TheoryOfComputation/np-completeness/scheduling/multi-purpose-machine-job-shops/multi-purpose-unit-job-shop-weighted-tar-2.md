# Feasible instances of TWO-MACHINE UNIT-TIME MULTI-PURPOSE JOB SHOP, WEIGHTED TARDINESS

With $D$ listing pairs $(d_j, w_j)$, an instance is feasible when there is a multi-purpose machine job-shop schedule (each operation on an eligible machine, operations of a job in order, no overlap on a machine) with $\sum_j w_j (C_j - d_j) \le K$, using truncated subtraction (pairs missing from the list read as $(0, 0)$).
