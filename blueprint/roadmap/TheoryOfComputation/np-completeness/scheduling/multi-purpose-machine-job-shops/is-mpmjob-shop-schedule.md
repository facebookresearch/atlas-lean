# Multi-purpose machine job-shop schedules

Machine choices $a(t)$ and start times $\sigma(t)$ form a multi-purpose machine job-shop schedule when every operation runs on an eligible machine ($a(t) \in \mu_t$), two different operations of positive length on the same machine do not overlap ($\sigma(t) + p_t \le \sigma(t')$ or $\sigma(t') + p_{t'} \le \sigma(t)$), and each operation of a job starts no earlier than the previous operation of that job completes. Operations of length $0$ occupy no machine time.
