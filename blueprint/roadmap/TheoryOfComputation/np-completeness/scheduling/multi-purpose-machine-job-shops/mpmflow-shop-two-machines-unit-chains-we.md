# Feasible instances of TWO-MACHINE UNIT-TIME MULTI-PURPOSE MACHINE FLOW SHOP WITH CHAINS, WEIGHTED COMPLETION TIME

An instance is feasible when some unit-time multi-purpose flow-shop precedence schedule on the two machines obeying the arcs has $\sum_j w_j C_j \le K$. Here $C_j$ is the latest completion time of an operation of job $j$, taken in $\mathbb{N}$, where a maximum over no elements is $0$, so $C_j = 0$ when there are no stages.
