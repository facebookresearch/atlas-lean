# Instances of multi-purpose machine job shops

An instance is a triple $(m, J, K)$ of a number $m$ of machines, a list $J$ of jobs, each job the list of its operations in order, each operation a pair $(p, \mu)$ of a processing time $p$ and a list $\mu$ of eligible machine numbers (natural numbers; well-formedness requires them to lie in $\{1, \dots, m\}$), and a bound $K$.
