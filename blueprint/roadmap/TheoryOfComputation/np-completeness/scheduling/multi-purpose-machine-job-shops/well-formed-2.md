# Well-formed instances of THREE-MACHINE MULTI-PURPOSE JOB SHOP WITH THREE JOBS, TOTAL COMPLETION TIME

An instance $(m, J, K)$ is well-formed when the job-shop instance is well-formed with $3$ machines (every job has at least one operation, and every operation has a nonempty list of machines, all in $\{1, 2, 3\}$) and there are exactly three jobs.

The condition treats the machine lists only as lists of machine numbers, so it is the same whether a list gives the eligible machines of an operation (multi-purpose machines) or the processors it uses simultaneously (multiprocessor tasks).
