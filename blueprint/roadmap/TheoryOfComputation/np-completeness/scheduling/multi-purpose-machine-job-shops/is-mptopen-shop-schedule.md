# Multiprocessor task open-shop schedules

Start times $\sigma(t)$ form a multiprocessor task open-shop schedule when two different tasks of positive length that share a machine, or belong to the same job, do not overlap ($\sigma(t) + p_t \le \sigma(t')$ or $\sigma(t') + p_{t'} \le \sigma(t)$). Task order within a job is free.
