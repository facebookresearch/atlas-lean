# Well-formed MPT FLOW SHOP, TREE PRECEDENCE, RELEASE DATES (FMPT|tree; r_i; p_ij = 1|C_max) instances

Well-formedness of an instance: the machine environment is well formed (`StagesWellFormed`),
every job has `r` unit processing times (`UnitJobs`), the listed arcs describe an acyclic
precedence digraph on the jobs (`PrecWellFormed`), and its precedence relation is a tree
(`IsTreePrecedence`).
