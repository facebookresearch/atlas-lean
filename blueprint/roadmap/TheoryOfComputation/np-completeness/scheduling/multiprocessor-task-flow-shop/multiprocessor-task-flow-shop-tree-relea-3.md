# The decision problem MPT FLOW SHOP, TREE PRECEDENCE, RELEASE DATES (FMPT|tree; r_i; p_ij = 1|C_max)

`FMPT|tree; r_i; p_ij = 1|C_max` as a decision problem on bitstrings: a bitstring is accepted exactly when it decodes, under the canonical bitstring encoding, to an instance that is [well-formed](well-formed-3.md) (in particular, every stage needs at least one processor) and feasible. A bitstring that does not decode to an instance is rejected.
