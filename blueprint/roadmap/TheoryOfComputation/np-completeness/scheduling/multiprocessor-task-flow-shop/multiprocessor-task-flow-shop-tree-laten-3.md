# The decision problem MPT FLOW SHOP WITH TREE PRECEDENCE AND UNIT TIMES (FMPT|tree; p_ij = 1|L_max)

`FMPT|tree; p_ij = 1|L_max` as a decision problem on bitstrings: a bitstring is accepted exactly when it decodes, under the canonical bitstring encoding, to an instance that is [well-formed](well-formed-2.md) (in particular, every stage needs at least one processor) and feasible. A bitstring that does not decode to an instance is rejected.
