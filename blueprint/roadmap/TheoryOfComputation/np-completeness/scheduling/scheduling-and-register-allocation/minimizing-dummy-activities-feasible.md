# Feasible instances of MINIMIZING DUMMY ACTIVITIES IN PERT NETWORKS

An instance is feasible when some PERT network has at most $K$ dummy activities: events, each the start or end of a task, and an acyclic arc set with at most $n + K$ arcs containing the distinct task arcs, with a (possibly empty) path from the end of $u$ to the start of $v$ exactly when $G$ has a nonempty path from $u$ to $v$.
