# PARALLEL PROCESSOR TOTAL FLOW TIME as a decision problem

The decision problem PARALLEL PROCESSOR TOTAL FLOW TIME accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples of a task list and two natural numbers, to an instance that is [well-formed](well-formed-5.md) and [feasible](parallel-processor-total-flow-time-feasi.md) for PARALLEL PROCESSOR TOTAL FLOW TIME. It rejects every bitstring that does not decode to such an instance.
