# Feasible instances of PARALLEL BATCHING `1|outtree;p_i=1;p-batch;b<n|L_max`

In `1|outtree;p_i=1;p-batch;b<n|L_max`: some batch schedule `σ` (a nonnegative integer batch start time for each job) puts at most `b` jobs in each batch, obeys the precedence arcs, and has maximum lateness at most `K`: `(σ(t) + 1) - d_t ≤ K` for every job `t`.
