# Feasible instances of UNBOUNDED PARALLEL BATCHING WITH RELEASE DATES, WEIGHTED TARDINESS

An instance is feasible when there is a parallel-batching schedule with no capacity limit (batches in index order, a batch lasting as long as its longest job) starting every job's batch no earlier than the job's release date, with $\sum_j w_j (C_j - d_j) \le K$ using truncated subtraction.
