# Feasible instances of UNBOUNDED PARALLEL BATCHING WITH RELEASE DATES, WEIGHTED NUMBER OF LATE JOBS

An instance is feasible when there is a parallel-batching schedule with no capacity limit (batches in index order, a batch lasting as long as its longest job) starting every job's batch no earlier than its release date, in which the late jobs ($d_j < C_j$) have total weight at most $K$.
