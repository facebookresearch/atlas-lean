# BOUNDED PARALLEL BATCHING WITH RELEASE DATES, TOTAL COMPLETION TIME is NP-complete

The decision problem BOUNDED PARALLEL BATCHING WITH RELEASE DATES, TOTAL COMPLETION TIME belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
