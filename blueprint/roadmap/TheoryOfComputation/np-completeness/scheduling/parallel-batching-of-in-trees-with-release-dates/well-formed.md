# Well-formed PARALLEL BATCHING of unit in-tree jobs with release dates instances

A PARALLEL BATCHING of unit in-tree jobs with release dates instance is well-formed when it is
well-formed for `P|intree;r_i;p_i=1|C_max` (unit lengths, `b > 0`, a strict partial order that
is an in-tree, `K > 0`, one release date per job), and the batch capacity is bounded: `b < n`.
