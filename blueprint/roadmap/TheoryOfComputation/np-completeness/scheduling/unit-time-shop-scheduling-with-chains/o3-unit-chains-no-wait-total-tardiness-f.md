# Feasible instances of THREE-MACHINE UNIT-TIME NO-WAIT OPEN SHOP WITH CHAINS, MINIMIZING TOTAL TARDINESS

An instance $(d, A, K)$ is feasible when some job start times $S_j$ and some no-wait schedule on three machines have total tardiness $\sum_j (S_j + 3 - d_j) \le K$, with truncated subtraction.
