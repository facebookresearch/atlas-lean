# Well-formed PRECEDENCE CONSTRAINED SCHEDULING on dedicated processors for forests instances

A PRECEDENCE CONSTRAINED SCHEDULING on dedicated processors for forests instance is well-formed when it is a well-formed dedicated-processor instance for any number $m$ of processors (unit task lengths, $m > 0$, the listed pairs name tasks and form a strict partial order, a positive deadline $D$, one processor per task and every processor below $m$) and the partial order is a forest.
