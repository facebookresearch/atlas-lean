# Feasible instances of MULTI-PURPOSE UNIFORM MACHINES WITH CHAINS AND UNIT TIMES, MAKESPAN

An instance is feasible when some eligible machine $a(t)$ and rational start time $\sigma(t) \ge 0$ for each operation $t$ make different operations on the same machine not overlap, make every operation of $j$ complete by the start of every operation of $k$ for every arc $(j, k)$, and make every operation complete by $K$. Operation $t$ completes at $\sigma(t) + p_t / s_{a(t)}$, where $s_k$ is the speed of machine $M_k$ and division is that of $\mathbb{Q}$, where $x / 0 = 0$.
