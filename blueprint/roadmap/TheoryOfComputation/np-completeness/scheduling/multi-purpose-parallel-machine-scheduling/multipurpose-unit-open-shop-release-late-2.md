# Feasible instances of UNIT-TIME MULTI-PURPOSE MACHINE OPEN SHOP WITH RELEASE DATES, LATE JOBS

An instance is feasible when some multi-purpose machine open-shop schedule starts no operation of job $i$ before $r_i$ and has at most $K$ jobs with $d_i < C_i$ (pairs missing from the list read as $(0, 0)$). A processing time missing from job $i$'s list counts as $0$. Here $C_i$ is the latest completion time of an operation of job $i$, and a maximum over no stages is $0$.
