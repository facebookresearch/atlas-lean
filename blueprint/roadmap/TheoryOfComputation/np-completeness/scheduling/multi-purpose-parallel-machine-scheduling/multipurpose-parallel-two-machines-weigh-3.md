# TWO MULTI-PURPOSE PARALLEL MACHINES, WEIGHTED COMPLETION TIME as a decision problem

The decision problem TWO MULTI-PURPOSE PARALLEL MACHINES, WEIGHTED COMPLETION TIME accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a multi-purpose machine job-shop instance $(m, J, K)$ and a list, to an instance that is well-formed and feasible for TWO MULTI-PURPOSE PARALLEL MACHINES, WEIGHTED COMPLETION TIME. It rejects every bitstring that does not decode to such an instance.
