# Completion time on a uniform machine

For machine choices $a$ and rational start times $\sigma$, job $t$ completes at $\sigma(t) + p_t / s_{a(t)}$, where $s_k$ is the speed of machine $M_k$ and division is that of $\mathbb{Q}$, where $x / 0 = 0$: a job on a machine of speed $0$ completes at $\sigma(t)$.
