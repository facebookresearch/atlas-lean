# Instances of TWO-MACHINE MULTIPURPOSE-MACHINE SCHEDULING WITH CHAINS

An instance of TWO-MACHINE MULTIPURPOSE-MACHINE SCHEDULING WITH CHAINS is a pair of a multi-purpose machine job-shop instance $(m, J, K)$, with $m$ the number of machines, $J$ the list of jobs, each a list of operations given as pairs $(p, \mu)$ of a processing time and a list of eligible machines, and $K$ the bound on the makespan, and a list $A$ of precedence arcs $(i, k)$. Job $i$ precedes job $k$ when $k$ is reachable from $i$ along the arcs.
