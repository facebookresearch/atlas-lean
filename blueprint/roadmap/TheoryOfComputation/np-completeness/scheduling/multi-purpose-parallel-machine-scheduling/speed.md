# Speed of a machine

The speed of machine $M_k$ is $a/b$ in $\mathbb{Q}$ for the $k$-th listed pair $(a, b)$, and $1$ if there is none. It is defined for every natural number $k$ and reads list position $k - 1$ (positions counted from $0$) with truncated subtraction, so $k = 0$ reads the first pair, as $k = 1$ does. Division is that of $\mathbb{Q}$, where $a / 0 = 0$, so a listed pair $(a, 0)$ gives speed $0$.
