# Well-formed instances of TWO MULTI-PURPOSE PARALLEL MACHINES WITH CHAINS AND UNIT TIMES, WEIGHTED COMPLETION TIME

An instance is well-formed when the inner instance is well-formed (the job-shop instance is well-formed with $2$ machines (nonempty jobs, nonempty eligible lists in $\{1, 2\}$), every job has exactly one operation, of processing time $1$, the arcs name jobs and form an acyclic digraph, and they form chains) and the list of per-job numbers that completes the instance (the weights of the jobs, in this problem) has exactly one entry per job.

The last condition compares only the length of that list with the number of jobs; it does not depend on what the listed numbers stand for.
