# Well-formed instances of UNIT-TIME MULTI-PURPOSE MACHINE OPEN SHOP WITH RELEASE DATES, LATE JOBS

An instance is well-formed when the open-shop instance is well-formed for multi-purpose machine open-shop makespan (the environment is well-formed (at least one stage, machine indices below $m$, pairwise different stage sets), nonempty stage sets, one processing time per stage), every processing time is $1$, and there is one date pair per job.
