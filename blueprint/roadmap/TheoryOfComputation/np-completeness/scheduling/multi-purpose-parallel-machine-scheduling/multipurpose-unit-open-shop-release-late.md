# Instances of UNIT-TIME MULTI-PURPOSE MACHINE OPEN SHOP WITH RELEASE DATES, LATE JOBS

An instance is a pair of a multi-purpose open-shop makespan instance $(m, \mu, P, K)$ ($K$ bounding the number of late jobs) and a list of pairs $(r_i, d_i)$ of release date and due date, job $i$ having the $i$-th listed pair.
