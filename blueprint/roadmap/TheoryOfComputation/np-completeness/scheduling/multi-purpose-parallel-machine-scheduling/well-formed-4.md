# Well-formed instances of MULTI-PURPOSE PARALLEL MACHINES WITH PRECEDENCE AND UNIT TIMES, TOTAL COMPLETION TIME

An instance of MULTI-PURPOSE PARALLEL MACHINES WITH PRECEDENCE AND UNIT TIMES, TOTAL COMPLETION TIME is a pair of a multi-purpose machine job-shop instance $(m, J, K)$, with $m$ the number of machines, $J$ the list of jobs, each a list of operations given as pairs $(p, \mu)$ of a processing time and a list of eligible machines, and $K$ the bound on the total completion time, and a list $A$ of precedence arcs $(i, k)$. It is well formed when there is at least one machine, $m > 0$; it is a well-formed multi-purpose machine job shop with $m$ machines, that is, every job has an operation and every operation has a nonempty list of eligible machines, all in $\{1, \dots, m\}$; every job has exactly one operation, of processing time $1$; and the arcs name jobs, that is, both entries of every arc are below the number of jobs, and form an acyclic digraph.
