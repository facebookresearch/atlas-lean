# FIVE-PROCESSOR SCHEDULING WITH TASK SIZES, MAKESPAN as a decision problem

The decision problem FIVE-PROCESSOR SCHEDULING WITH TASK SIZES, MAKESPAN accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of instances of RESOURCE-CONSTRAINED PROJECT SCHEDULING, to an instance that is well-formed for FIVE-PROCESSOR SCHEDULING WITH TASK SIZES, MAKESPAN and feasible for RESOURCE-CONSTRAINED PROJECT SCHEDULING. It rejects every bitstring that does not decode to such an instance.
