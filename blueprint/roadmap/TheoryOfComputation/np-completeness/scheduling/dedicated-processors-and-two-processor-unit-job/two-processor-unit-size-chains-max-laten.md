# Instances of TWO-PROCESSOR UNIT TASKS WITH SIZES AND CHAINS, MAXIMUM LATENESS

An instance is a triple $(T, A, K)$ of a list of unit tasks, each a pair of its size and its integer due date $d_i$ (a pair $(a, b)$ standing for $a - b$), a list $A$ of chain arcs, and an integer bound $K$ given the same way.
