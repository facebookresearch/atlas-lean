# Feasible instances of TWO-PROCESSOR UNIT TASKS WITH SIZES AND CHAINS, MAXIMUM LATENESS

An instance is feasible when some start times have the sizes of the tasks starting at each time summing to at most $2$, obey the chain arcs ($S_j + 1 \le S_k$), and give $(S_j + 1) - d_j \le K$ in the integers for every task.
