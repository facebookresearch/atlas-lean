# UNIT-TIME PARALLEL TASKS, TOTAL COMPLETION TIME is NP-complete

The decision problem UNIT-TIME PARALLEL TASKS, TOTAL COMPLETION TIME belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. Drozdowski and P. Dell'Olmo, "Scheduling multiprocessor tasks for mean flow time criterion", Computers & Operations Research 27 (2000), 571-585, doi:10.1016/S0305-0548(99)00048-9 (abstract: "When tasks have unit execution time and the number of processors is arbitrary the problem is shown to be computationally hard").
- P. Brucker and S. Knust, *Complexity results for scheduling problems*, http://www2.informatik.uni-osnabrueck.de/knust/class/, class "Multiprocessor task problems with parallel processors", which lists `P|pᵢ = 1; sizeᵢ|∑ Cᵢ` as minimal NP-hard with this attribution.
