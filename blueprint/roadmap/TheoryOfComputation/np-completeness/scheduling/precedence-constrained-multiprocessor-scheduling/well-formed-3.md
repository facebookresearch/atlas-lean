# Well-formed instances of PRECEDENCE CONSTRAINED SCHEDULING ON HIERARCHIC PARALLEL ORDERS

An instance $(l, m, P, D)$ is well-formed for PRECEDENCE CONSTRAINED SCHEDULING ON HIERARCHIC PARALLEL ORDERS when it is well-formed for PRECEDENCE CONSTRAINED SCHEDULING (every task has length $1$, $m > 0$, every pair in $P$ names two tasks, the listed pairs form a strict partial order on the tasks (irreflexive and transitive), and $D > 0$) and its precedence order is hierarchic parallel.
