# Well-formed instances of UNIT-TIME PARALLEL BATCHING WITH PRECEDENCE, MAKESPAN

An instance $(l, b, P, K)$, on the PRECEDENCE CONSTRAINED SCHEDULING instance type with the batch capacity $b$ in the processor slot, is well-formed for UNIT-TIME PARALLEL BATCHING WITH PRECEDENCE, MAKESPAN when it is well-formed for PRECEDENCE CONSTRAINED SCHEDULING (every task has length $1$, $b > 0$, every pair in $P$ names two tasks, the listed pairs form a strict partial order on the tasks (irreflexive and transitive), and $K > 0$) and $b < n$, the number of jobs.
