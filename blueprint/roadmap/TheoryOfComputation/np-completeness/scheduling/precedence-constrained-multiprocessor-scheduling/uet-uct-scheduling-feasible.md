# Feasible instances of UET-UCT SCHEDULING

An instance is feasible when some start times $S_j$ and processors $P_j$ run at most one task at a time on each processor, respect every arc $j \to k$ ($S_j + 1 \le S_k$ on a common processor, $S_j + 2 \le S_k$ on different processors), and complete every task by $d$.
