# Open-shop schedules meeting a deadline

Start times $\sigma_p(j)$ form an open-shop schedule meeting the deadline $D$ when each processor starts its tasks at pairwise different times, a task starting after another task $k$ on the same processor starts no earlier than $\sigma_p(k) + l(t_p[k])$, the tasks of each job occupy pairwise disjoint intervals $[\sigma_p(j), \sigma_p(j) + l(t_p[j]))$, and every task finishes by $D$. A task length $l(t_p[j])$ missing from job $j$'s list counts as $0$.
