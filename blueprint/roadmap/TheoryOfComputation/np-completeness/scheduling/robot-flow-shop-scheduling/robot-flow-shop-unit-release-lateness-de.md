# TWO-MACHINE UNIT-TIME ROBOT FLOW SHOP WITH RELEASE DATES, MAXIMUM LATENESS as a decision problem

The decision problem TWO-MACHINE UNIT-TIME ROBOT FLOW SHOP WITH RELEASE DATES, MAXIMUM LATENESS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a list of triples and a pair of natural numbers, to an instance that is well-formed and feasible for TWO-MACHINE UNIT-TIME ROBOT FLOW SHOP WITH RELEASE DATES, MAXIMUM LATENESS. It rejects every bitstring that does not decode to such an instance.
