# Transport time from the first to the second machine in THREE-MACHINE ROBOT FLOW SHOP WITH EQUAL PROCESSING TIMES AND RELEASE DATES, MAKESPAN

An instance of THREE-MACHINE ROBOT FLOW SHOP WITH EQUAL PROCESSING TIMES AND RELEASE DATES, MAKESPAN is a triple $(L, p, K)$ of a list $L$ of triples $(t_{i1}, t_{i2}, r_i)$ of natural numbers, one per job, a processing time $p$, and a bound $K$ on the makespan. The transport time $t_{i1}$ of job $i$ from machine $M_1$ to machine $M_2$ is the first component of the triple at position $i$ of $L$.
