# THREE-MACHINE UNIT-TIME ROBOT FLOW SHOP, WEIGHTED NUMBER OF LATE JOBS as a decision problem

The decision problem THREE-MACHINE UNIT-TIME ROBOT FLOW SHOP, WEIGHTED NUMBER OF LATE JOBS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs $(J, K)$ (a list of quadruples of natural numbers and a natural number), to an instance that is feasible for THREE-MACHINE UNIT-TIME ROBOT FLOW SHOP, WEIGHTED NUMBER OF LATE JOBS (no well-formedness condition is imposed). It rejects every bitstring that does not decode to such an instance.
