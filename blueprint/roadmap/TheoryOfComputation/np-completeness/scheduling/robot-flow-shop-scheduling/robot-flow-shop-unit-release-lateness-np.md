# TWO-MACHINE UNIT-TIME ROBOT FLOW SHOP WITH RELEASE DATES, MAXIMUM LATENESS is NP-complete

The decision problem TWO-MACHINE UNIT-TIME ROBOT FLOW SHOP WITH RELEASE DATES, MAXIMUM LATENESS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
