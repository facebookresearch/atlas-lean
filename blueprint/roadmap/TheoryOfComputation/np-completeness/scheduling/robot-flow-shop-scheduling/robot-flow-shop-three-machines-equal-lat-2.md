# Feasible instances of THREE-MACHINE ROBOT FLOW SHOP WITH EQUAL PROCESSING TIMES, MAXIMUM LATENESS

An instance is feasible when there is a single-robot three-machine schedule with operations of length $p$ (start times $a, c, f$ on $M_1, M_2, M_3$ and $b, e$ of the transports of lengths $t_{j1}, t_{j2}$; each job's steps in order, operations on each machine pairwise disjoint in time, and all transports pairwise disjoint in time) with $f_j + p + y^- \le d_j + y^+$ for every job.
