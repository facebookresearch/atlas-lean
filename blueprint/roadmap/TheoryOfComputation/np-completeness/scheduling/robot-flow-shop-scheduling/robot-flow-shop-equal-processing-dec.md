# TWO-MACHINE ROBOT FLOW SHOP WITH EQUAL PROCESSING TIMES, MAKESPAN as a decision problem

The decision problem TWO-MACHINE ROBOT FLOW SHOP WITH EQUAL PROCESSING TIMES, MAKESPAN accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(p, t, K)$ (a natural number, a list of natural numbers and a natural number), to an instance that is feasible for TWO-MACHINE ROBOT FLOW SHOP WITH EQUAL PROCESSING TIMES, MAKESPAN (the well-formedness condition is always true). It rejects every bitstring that does not decode to such an instance.
