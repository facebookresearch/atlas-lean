# TWO-MACHINE ROBOT FLOW SHOP WITH CONSTANT TRANSPORT TIME, MAKESPAN as a decision problem

The decision problem TWO-MACHINE ROBOT FLOW SHOP WITH CONSTANT TRANSPORT TIME, MAKESPAN accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(J, T, K)$ (a list of pairs and two natural numbers), to an instance that is feasible for TWO-MACHINE ROBOT FLOW SHOP WITH CONSTANT TRANSPORT TIME, MAKESPAN (the well-formedness condition is always true). It rejects every bitstring that does not decode to such an instance.
