# TWO-MACHINE ROBOT FLOW SHOP WITH EQUAL PROCESSING TIMES, MAKESPAN is NP-complete

The decision problem TWO-MACHINE ROBOT FLOW SHOP WITH EQUAL PROCESSING TIMES, MAKESPAN belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- J. Hurink and S. Knust, "Makespan minimization for flow-shop problems with transportation times and a single robot", Discrete Applied Mathematics 112 (2001), 199-216, doi:10.1016/S0166-218X(00)00316-4 (Theorem 2: strongly NP-hard).
