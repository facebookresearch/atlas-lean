# Feasible instances of TWO-MACHINE UNIT-TIME ROBOT FLOW SHOP, WEIGHTED TARDINESS

An instance is feasible when there is a two-machine unit-time robot flow-shop schedule (start times $\sigma_1(j), \sigma_2(j)$ on $M_1, M_2$ forming a unit-time flow-shop schedule with delays $t_j$, transport start times $\rho_j$ with $\sigma_1(j) + 1 \le \rho_j$ and $\rho_j + t_j \le \sigma_2(j)$, and transports of distinct jobs not overlapping) with $\sum_j w_j (\sigma_2(j) + 1 - d_j) \le K$ using truncated subtraction.
