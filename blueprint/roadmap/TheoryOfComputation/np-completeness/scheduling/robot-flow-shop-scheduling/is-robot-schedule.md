# Three-machine unit-time robot flow-shop schedules

Start times $a, b, c, e, f$ form single-robot three-machine schedule (start times $a, c, f$ of the unit operations on $M_1, M_2, M_3$ and $b, e$ of the transports $M_1 \to M_2$, $M_2 \to M_3$ of lengths $t_{j1}, t_{j2}$; each job's steps in order, pairwise different start times on each machine, and all transports pairwise disjoint in time).
