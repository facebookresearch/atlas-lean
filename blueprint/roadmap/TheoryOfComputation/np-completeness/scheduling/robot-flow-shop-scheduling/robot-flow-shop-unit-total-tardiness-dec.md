# TWO-MACHINE UNIT-TIME ROBOT FLOW SHOP, TOTAL TARDINESS as a decision problem

The decision problem TWO-MACHINE UNIT-TIME ROBOT FLOW SHOP, TOTAL TARDINESS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs $(J, K)$ (a list of pairs and a natural number), to an instance that is feasible for TWO-MACHINE UNIT-TIME ROBOT FLOW SHOP, TOTAL TARDINESS (the well-formedness condition is always true). It rejects every bitstring that does not decode to such an instance.
