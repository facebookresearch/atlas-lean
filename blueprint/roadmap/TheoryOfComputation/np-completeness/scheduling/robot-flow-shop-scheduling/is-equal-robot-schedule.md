# Three-machine robot flow-shop schedules with equal processing times

Start times $a, b, c, e, f$ form single-robot three-machine schedule with operations of length $p$ (start times $a, c, f$ on $M_1, M_2, M_3$ and $b, e$ of the transports of lengths $t_{j1}, t_{j2}$; each job's steps in order, operations on each machine pairwise disjoint in time, and all transports pairwise disjoint in time).
