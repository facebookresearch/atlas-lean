# Feasible instances of THREE-MACHINE UNIT-TIME ROBOT FLOW SHOP, WEIGHTED TARDINESS

An instance is feasible when there is a single-robot three-machine schedule (start times $a, c, f$ of the unit operations on $M_1, M_2, M_3$ and $b, e$ of the transports $M_1 \to M_2$, $M_2 \to M_3$ of lengths $t_{j1}, t_{j2}$; each job's steps in order, pairwise different start times on each machine, and all transports pairwise disjoint in time) with $\sum_j w_j (f_j + 1 - d_j) \le K$ using truncated subtraction.
