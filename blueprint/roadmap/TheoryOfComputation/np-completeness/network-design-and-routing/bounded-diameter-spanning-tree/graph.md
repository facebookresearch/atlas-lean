# Graph of a BOUNDED DIAMETER SPANNING TREE instance

The graph of a BOUNDED DIAMETER SPANNING TREE instance is the simple graph on the vertices $0, \dots, n-1$ in which two distinct vertices are adjacent when the endpoint pairs of the edge list join them in either orientation. Several problems build their graph the same way from a list of triples whose third field (a weight, a length or a class) is ignored, applied to the instance's edge list or to a candidate list; those declarations are credited here.
