# BOUNDED DIAMETER SPANNING TREE is NP-complete for every fixed $D \ge 4$, even with edge weights 1 or 2

For every natural number $D \ge 4$, the BOUNDED DIAMETER SPANNING TREE with edge weights 1 or 2 decision problem with diameter bound $D$ belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [ND4] BOUNDED DIAMETER SPANNING TREE, p. 206, comment ("Remains NP-complete for any fixed D ≥ 4, even if all edge weights are either 1 or 2"; reference: [Garey and Johnson, unpublished], transformation from EXACT COVER BY 3-SETS).
