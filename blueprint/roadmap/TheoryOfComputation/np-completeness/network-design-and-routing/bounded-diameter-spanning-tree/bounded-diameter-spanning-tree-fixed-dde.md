# BOUNDED DIAMETER SPANNING TREE with a fixed diameter bound and weights 1 or 2 as a decision problem

For a fixed natural number $D$, the BOUNDED DIAMETER SPANNING TREE with edge weights 1 or 2 decision problem with diameter bound $D$ accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of instances, to an instance that is well-formed and feasible for that diameter bound; it rejects every bitstring that does not decode to an instance.
