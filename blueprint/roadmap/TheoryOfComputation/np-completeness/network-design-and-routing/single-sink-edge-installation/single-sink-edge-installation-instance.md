# Instances of SINGLE-SINK EDGE INSTALLATION

An instance of SINGLE-SINK EDGE INSTALLATION is a value of type `ℕ × List (ℕ × ℕ × ℕ) × List (ℕ × ℕ) × ℕ × List (ℕ × ℕ) × ℕ`: vertex count `n`, edges `(u, v, l)` with lengths, sources `(v, d)` with demands, the sink `t`, cable types `(u, c)` (capacity, cost per unit length), and the bound `K`.
