# Feasible CAPACITATED SPANNING TREE instances

An instance $(n, E, v_0, r, B)$ of CAPACITATED SPANNING TREE is feasible when $v_0 < n$ and some spanning tree $T$ of the instance's graph has total edge length at most $B$ and, for every edge $e$ of $T$, the requirements of the vertices whose path to $v_0$ in $T$ uses $e$ sum to at most $c(e)$.
