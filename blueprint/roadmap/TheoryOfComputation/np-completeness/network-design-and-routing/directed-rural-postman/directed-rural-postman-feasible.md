# Feasible DIRECTED RURAL POSTMAN instances

An instance $(n, A, A', B)$ of DIRECTED RURAL POSTMAN is feasible when some closed directed walk, given as a list of valid arc indices in which each arc's head is the next arc's tail and the last arc's head is the first arc's tail, traverses every required arc and has total length at most $B$, each traversal counting the arc's length.
