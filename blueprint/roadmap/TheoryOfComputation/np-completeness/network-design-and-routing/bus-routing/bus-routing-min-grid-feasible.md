# Feasible BUS ROUTING (minimization, grid) instances

An instance $(n, A, s, t, W, B)$ is feasible for the grid minimization version when some directed path from $s$ to $t$ along the arcs (distinct vertices, an arc from each vertex to the next) has total weight at most $B$, where the total weight sums the weights of the weighted pairs $(u, v)$ in the transitive closure of the path's arcs.
