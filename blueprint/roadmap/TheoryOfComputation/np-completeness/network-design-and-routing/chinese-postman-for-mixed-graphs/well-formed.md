# Well-formed CHINESE POSTMAN FOR MIXED GRAPHS instances

An instance $(n, A, E, B)$ of CHINESE POSTMAN FOR MIXED GRAPHS is well-formed when every directed edge joins two distinct vertices below $n$ and no endpoint pair of a directed edge is repeated; every undirected edge joins two distinct vertices below $n$, no endpoint pair of an undirected edge is repeated and none appears in both orientations; and $B > 0$.

STACKER-CRANE uses this same test on the same encoded instance.
