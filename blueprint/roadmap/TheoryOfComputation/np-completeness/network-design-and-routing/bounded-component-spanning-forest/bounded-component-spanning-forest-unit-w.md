# BOUNDED COMPONENT SPANNING FOREST with unit weights and a fixed weight bound as a decision problem

For a fixed natural number $B$, the BOUNDED COMPONENT SPANNING FOREST with unit weights decision problem with weight bound $B$ accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of instances, to an instance that is well-formed and feasible for that weight bound; it rejects every bitstring that does not decode to an instance.
