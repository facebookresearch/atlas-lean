# Well-formed instances with unit weights and weight bound B

For a weight bound $B$, an instance $(n, E, w, K)$ is well-formed when the edge list has no repeated edge, every edge joins two distinct vertices below $n$, and no edge appears in both orientations; there is one weight per vertex; $0 < K \le n$; $B > 0$; and every vertex weight is $1$.
