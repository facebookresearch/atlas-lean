# Instances of BOUNDED COMPONENT SPANNING FOREST with a fixed weight bound

For a fixed weight bound $B$, an instance of BOUNDED COMPONENT SPANNING FOREST is a tuple $(n, E, w, K)$ of a number $n$ of vertices $0, \dots, n-1$, an edge list $E$, a list $w$ of vertex weights $w_0, \dots, w_{n-1}$, and a bound $K$ on the number of parts.
