# Instances of BOUNDED COMPONENT SPANNING FOREST

An instance of BOUNDED COMPONENT SPANNING FOREST is a tuple $(n, E, w, K, B)$ of a number $n$ of vertices $0, \dots, n-1$, an edge list $E$, a list $w$ of vertex weights $w_0, \dots, w_{n-1}$, a bound $K$ on the number of parts and a weight bound $B$.
