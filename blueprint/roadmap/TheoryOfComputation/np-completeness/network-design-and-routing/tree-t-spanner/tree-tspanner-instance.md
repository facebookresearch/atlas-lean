# Instances of TREE t-SPANNER

An instance of TREE t-SPANNER is a pair $(n, E)$ of a vertex count $n$ (the vertices are $0, \dots, n - 1$) and an edge list $E$ of pairs of natural numbers. The stretch factor $t$ is not part of the instance: it is a natural-number parameter of the decision problem, and the instances are the same for every $t$.
