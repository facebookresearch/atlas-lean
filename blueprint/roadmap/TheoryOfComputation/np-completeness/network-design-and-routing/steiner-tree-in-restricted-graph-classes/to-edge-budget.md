# Edge-budget form of a STEINER TREE IN CHORDAL BIPARTITE GRAPHS instance

For an instance `i` of STEINER TREE IN CHORDAL BIPARTITE GRAPHS, the parent instance with edge budget `K - 1` (a tree with at most `K` vertices has at most `K - 1` edges). Subtraction is natural-number subtraction, so `a - b = 0` whenever `a ≤ b`.
