# Well-formed instances of STEINER TREE IN GRAPHS (unit weights) for K₃,₃-free graphs

An instance of STEINER TREE IN GRAPHS (unit weights) for K₃,₃-free graphs is well formed when it is a well-formed STEINER TREE IN GRAPHS instance in which every edge has weight `1`, with at least one vertex and `K > 0`, whose graph has no subgraph homeomorphic to `K₃,₃`.
