# The GRAPH THICKNESS instance of a STEINER TREE instance with bounded thickness

For a natural number $k$ and an instance $(n, E, R, B)$ of STEINER TREE IN GRAPHS (unit weights) on graphs of thickness at most $k$, its GRAPH THICKNESS instance is $(n, E', k)$, where $E'$ is the list of endpoint pairs $(u, v)$ of the entries $(u, v, w)$ of $E$, in the same order, with the weights dropped.
