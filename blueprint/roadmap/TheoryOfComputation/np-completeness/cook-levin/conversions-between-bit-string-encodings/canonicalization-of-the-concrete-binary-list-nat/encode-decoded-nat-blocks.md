# Re-encoding decoded payloads normalizes each one

For every list $(p^1, \ldots, p^k)$ of bit strings, the canonical code of the list of natural numbers
$(D(p^1), \ldots, D(p^k))$ (concatenated framed binary codes; $D$ as in [decoding a list of
naturals](decode-list-nat.md)) is the concatenation of the framed forms of the
[normalizations](../normalizing-the-total-binary-natural-number-deco/normalize-nat.md) of $p^1, \ldots, p^k$, in
the same order.
