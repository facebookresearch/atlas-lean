# Quadratic encoding bound for vertex lists below $n$

Use the canonical code of a list of natural numbers from [the framed length bound](list-nat-encode-length-le.md)
(framed binary codes). Let $n$ be a natural number and $(a_1, \ldots, a_k)$ a list of natural numbers with
$k \le n$ and $a_i < n$ for every $i$. Then the canonical code of the list has length at most $n(2n + 1)$.
