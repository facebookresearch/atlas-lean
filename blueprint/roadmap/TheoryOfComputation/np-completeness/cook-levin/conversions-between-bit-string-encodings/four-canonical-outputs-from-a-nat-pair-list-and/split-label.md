# Label map from the outer splitter to the list projector

The label map from the [pair-frame splitter](../raw-projection-of-the-canonical-pair-frame/lab.md) to the
[four-output decoder](lab.md) sends good to $\mathrm{items}(\text{loop})$, bad to bad, and every other label $\ell$
to $\mathrm{split}(\ell)$.
