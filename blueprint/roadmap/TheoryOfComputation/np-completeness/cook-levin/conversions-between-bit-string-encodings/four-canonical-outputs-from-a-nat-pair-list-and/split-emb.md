# Outer-splitter stack embedding in the four-output decoder

The stack embedding of the [pair-frame splitter](../raw-projection-of-the-canonical-pair-frame/k.md) into the
[four-output decoder](prog.md) sends the splitter's input to the input stack of the final pair workspace's
splitter, its left stack to the input of the item workspace, and its scratch stack to the buffer of the final pair
workspace, with the identity on the bit alphabets.
