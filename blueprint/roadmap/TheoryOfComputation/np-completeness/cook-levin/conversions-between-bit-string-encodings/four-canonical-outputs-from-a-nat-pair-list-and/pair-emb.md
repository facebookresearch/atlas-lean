# Final pair-projector stack embedding in the four-output decoder

The stack embedding of the [number-pair projector](../projecting-and-normalizing-a-pair-of-binary-natu/k.md) into
the [four-output decoder](prog.md) sends each of its six stacks to the corresponding stack of the final pair
workspace, with the identity on the bit alphabets; this workspace is disjoint from the item workspace.
