# Four-output pair-list decoder as a host component

The four-output decoder as a component machine: its seventeen [stacks](k.md) (the eleven item-workspace stacks, in
the order of the [pair-list projector component](../canonical-projection-of-lists-of-binary-nat-pair/component.md),
then the six final pair-workspace stacks, in the order of the [number-pair projector
component](../projecting-and-normalizing-a-pair-of-binary-natu/component.md)), every stack alphabet the set of bits,
its [labels](lab.md) and its [program](prog.md).
