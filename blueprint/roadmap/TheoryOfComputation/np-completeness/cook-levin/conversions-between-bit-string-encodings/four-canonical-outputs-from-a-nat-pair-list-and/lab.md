# Control labels of the four-output pair-list decoder

The labels of the four-output decoder are $\mathrm{split}(\ell)$ for each label $\ell$ of the [pair-frame
splitter](../raw-projection-of-the-canonical-pair-frame/lab.md), $\mathrm{items}(\ell)$ for each label $\ell$ of the
[pair-list projector](../canonical-projection-of-lists-of-binary-nat-pair/lab.md), $\mathrm{pair}(\ell)$ for each
label $\ell$ of the [number-pair projector](../projecting-and-normalizing-a-pair-of-binary-natu/lab.md), good and
bad.
