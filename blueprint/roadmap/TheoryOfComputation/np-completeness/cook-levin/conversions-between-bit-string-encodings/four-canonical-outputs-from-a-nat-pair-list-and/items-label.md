# Label map from the list projector to the final pair decoder

The label map from the [pair-list projector](../canonical-projection-of-lists-of-binary-nat-pair/lab.md) to the
[four-output decoder](lab.md) sends good to $\mathrm{pair}(\mathrm{pair}(\mathrm{read}))$, bad to bad, and every
other label $\ell$ to $\mathrm{items}(\ell)$.
