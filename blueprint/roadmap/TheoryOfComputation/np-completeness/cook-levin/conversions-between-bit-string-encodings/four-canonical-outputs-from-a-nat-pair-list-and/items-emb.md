# List-projector stack embedding in the four-output decoder

The stack embedding of the [pair-list projector](../canonical-projection-of-lists-of-binary-nat-pair/k.md) into the
[four-output decoder](prog.md) sends each of its eleven stacks to the corresponding stack of the item workspace,
with the identity on the bit alphabets; this workspace is disjoint from the final pair workspace.
