# Feasible BOUNDED POST CORRESPONDENCE instances

An instance $(s, D, K)$ of BOUNDED POST CORRESPONDENCE is feasible when there is a nonempty sequence $(a_{i_1}, b_{i_1}), \dots, (a_{i_k}, b_{i_k})$ of pairs from $D$, repetitions allowed, with $k \le K$ and $a_{i_1} \cdots a_{i_k} = b_{i_1} \cdots b_{i_k}$.
