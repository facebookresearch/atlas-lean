# EXTERNAL MACRO DATA COMPRESSION with logarithmic pointer cost as a decision problem

For a natural number $k$, the decision problem EXTERNAL MACRO DATA COMPRESSION with a fixed
alphabet and logarithmic pointer cost accepts a bitstring $x$ exactly when $x$ decodes, under
the canonical bitstring encoding of its instances, to an instance that is [well-formed for
$k$](well-formed.md) and [feasible for $k$](external-macro-data-compression-log-poin-2.md). It
rejects every bitstring that does not decode to an instance.
