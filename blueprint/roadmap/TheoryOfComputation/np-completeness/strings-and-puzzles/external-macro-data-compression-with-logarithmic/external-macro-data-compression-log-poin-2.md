# Feasible EXTERNAL MACRO DATA COMPRESSION with a fixed alphabet and logarithmic pointer cost instances

For a natural alphabet size $k$, $s$ has an external macro compression [within the bound](../macro-data-compression/compresses.md) $B$ over the literals $0, \dots, k-1$, with pointer parameter $c = \lceil h \log_2 |s| \rceil$. The alphabet size is a free parameter of raw feasibility: at $s = [1]$ and $h = B = 1$, literal $1$ works for $k = 2$ but cannot be produced over $k = 1$; the hardness theorem's $k \ge 3$ is not part of this predicate. Each pointer occurrence counts once in the string lengths and then adds $c - 1$ in natural-number subtraction, so its effective charge is $\max(1, c)$: for a one-symbol word $c = 0$, yet each occurrence still costs $1$. The parameter handed to the compression predicate is $c$, not the per-occurrence charge.
