# Instances of SHORT SYNCHRONIZING WORD

An instance is a quadruple of natural numbers $n$ and $k$, a list of rows of natural numbers (read as a transition table: row $q$ lists $\delta(q, a)$ for each letter $a$) and a natural bound $m$. The table is a list of rows, not necessarily a complete function: $(2, 1, [\,], 1)$ stores no row for either state. Row counts, row lengths and state bounds belong to [validation](well-formed-3-5.md).
