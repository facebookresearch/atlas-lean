# Instances of FINITE STATE AUTOMATON INEQUIVALENCE

An instance is a triple of a natural alphabet size $m$ and two [automaton records](automaton-data.md) $A_1$ and $A_2$, each a state count, an initial state, a list of accept states and a list of transitions $((s, a), t)$ of natural numbers. The alphabet size is a free field: the unary problem requires $m = 1$ in its validation, and the finite-language problem uses the same instances for every $m$.
