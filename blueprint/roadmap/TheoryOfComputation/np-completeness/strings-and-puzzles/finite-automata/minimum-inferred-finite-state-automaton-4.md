# MINIMUM INFERRED FINITE STATE AUTOMATON as a decision problem

The decision problem MINIMUM INFERRED FINITE STATE AUTOMATON accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quadruples $(m, S, T, K)$ of an alphabet size, strings to accept, strings to reject and a state bound, to an instance that is [well-formed](well-formed-5.md) and [feasible](minimum-inferred-finite-state-automaton-3.md) for MINIMUM INFERRED FINITE STATE AUTOMATON. It rejects every bitstring that does not decode to such an instance.
