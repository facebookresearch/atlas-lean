# Nondeterministic automaton given by automaton data

Automaton data $(n, q_0, F, \Delta)$ denotes the nondeterministic finite automaton whose only start state is $q_0$, whose accept states are those listed in $F$, whose transitions are those listed in $\Delta$ (a transition $((s, a), t)$ leads from $s$ on letter $a$ to $t$), and which has no $\varepsilon$-moves.
