# Instances of EYE-WITLESS

An instance of EYE-WITLESS is an arbitrary list of rows of natural numbers; in the usual reading `0` is a cell without an eye and $k + 1$ an eye of colour $k$. The grid width is the length of the first row (zero if there is none), so `[[], [1]]` has a stored nonzero entry but no cell in the grid. Validation is the [rectangular grid test](../choco-banana/well-formed.md) shared with CHOCO BANANA.
