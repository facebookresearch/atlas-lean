# Well-formed rectangular grid instances

A grid instance, given as a list of rows, is well-formed when the grid has at least one row and at least one column, and every row has the length of the first row. This test is shared by CHOCO BANANA, EYE-WITLESS and other puzzles with the same encoding.

HEXAGONAL SLITHER LINK uses this same test on its list of columns; no clue bound is checked.
