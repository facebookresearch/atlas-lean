# Number of columns of a Yosenabe puzzle

A Yosenabe puzzle is given as a list of rows, each a list of cell contents $(k, a)$ of natural numbers: $k = 0$ is an empty white cell, $k = 1$ a white cell with a circle numbered $a$, and $k = 2$ a gray cell, labelled $a$ when $a \ne 0$. Its number of columns is the length of the first row, and $0$ if there are no rows. The same function on the same lists of pairs gives the number of columns of a ZEIGER, Double Choco, Ripple Effect or Sashigane grid. No nonempty or rectangular grid is assumed.
