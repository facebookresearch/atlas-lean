# Well-formed instances of PARKS PUZZLE

Let $m$ be the number of rows of the board, which is also the number of parks, and let the number of columns be the length of the first row. An instance is well-formed when $m \ge 1$, there is at least one column, all rows have that length, every park index on the board is below $m$, and each of the $m$ parks $0, \dots, m - 1$ contains a square. A two-row board labelled only $0$ is not well-formed, whatever its width.
