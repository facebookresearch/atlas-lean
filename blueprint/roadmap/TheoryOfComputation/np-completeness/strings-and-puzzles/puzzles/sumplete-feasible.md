# Feasible instances of SUMPLETE

An instance is a grid given as a list of rows of integers, a list of row targets and a list of column targets. It is feasible when some cells can be crossed out so that: for every row index $r$ below the number of rows, the uncrossed numbers of row $r$ in columns below the number of column targets sum to the target of row $r$; and, for every column index $c$ below the number of column targets, the uncrossed numbers of column $c$ in rows below the number of rows sum to the target of column $c$. The two families of equations are independent: with no rows and one column target $1$, the column sum is $0$, not $1$, so that instance is infeasible. Numbers and targets missing from the lists read as $0$; entries of a row beyond the number of column targets are ignored, not added to the row sum.
