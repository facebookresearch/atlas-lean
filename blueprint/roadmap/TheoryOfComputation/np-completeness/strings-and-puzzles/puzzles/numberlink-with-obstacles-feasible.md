# Feasible instances of NUMBERLINK WITH OBSTACLES

An instance is feasible when there is one owner function on the squares such that every obstacle is owned by no label ($0$), and for every two distinct squares $s \ne t$ carrying the same positive label $c$ there is a simple path from $s$ to $t$ whose support is exactly the set of squares owned by $c$. The paths for different pairs of the same label need not be disjoint: on a $3 \times 3$ board without obstacles with label $1$ on three corners and $0$ elsewhere, owning every square by $1$ joins any two of those corners by a Hamilton path, and all these witnesses have the same support. On well-formed boards, which have exactly two terminals per used label, this is a family of vertex-disjoint paths, one per label, avoiding the obstacles.
