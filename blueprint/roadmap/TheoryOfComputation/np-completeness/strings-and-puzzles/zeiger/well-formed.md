# Well-formed ZEIGER instances

A ZEIGER instance $I$ is well formed when all of the following hold:

- $\mathrm{rows}(I) > 0$ and $\mathrm{cols}(I) > 0$;
- every row has length $\mathrm{cols}(I)$, so the grid is rectangular;
- every cell $(d, a)$ has $d < 4$, so every arrow is one of the four directions.
