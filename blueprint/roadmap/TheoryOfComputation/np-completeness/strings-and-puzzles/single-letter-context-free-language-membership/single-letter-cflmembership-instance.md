# Instances of SINGLE-LETTER CONTEXT-FREE LANGUAGE MEMBERSHIP

An instance of SINGLE-LETTER CONTEXT-FREE LANGUAGE MEMBERSHIP is a pair $(G, K)$ of a context-free grammar $G$, given by its number $n$ of nonterminals $0, \dots, n-1$, an initial nonterminal and a list of productions whose right-hand sides are lists of nonterminals and terminals (possibly empty), and a natural number $K$ written in binary.
