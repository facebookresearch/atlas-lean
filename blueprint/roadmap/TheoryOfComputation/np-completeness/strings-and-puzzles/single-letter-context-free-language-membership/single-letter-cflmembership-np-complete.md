# SINGLE-LETTER CONTEXT-FREE LANGUAGE MEMBERSHIP is NP-complete

The SINGLE-LETTER CONTEXT-FREE LANGUAGE MEMBERSHIP decision problem belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it. Since $K$ is given in binary, the word $0^K$ is not part of the input.
