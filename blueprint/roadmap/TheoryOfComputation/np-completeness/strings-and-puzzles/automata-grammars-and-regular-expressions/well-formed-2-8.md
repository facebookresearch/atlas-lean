# Well-formed instances of RIGHT-LINEAR MONADIC RECURSION SCHEME INEQUIVALENCE

A STRONG INEQUIVALENCE FOR MONADIC RECURSION SCHEMES instance is well-formed for RIGHT-LINEAR MONADIC RECURSION SCHEME INEQUIVALENCE when it is well-formed for that problem, the first scheme defines $f_0 x = \text{if } p\,x \text{ then } x \text{ else } x$ for some predicate $p$, and every branch of the second scheme is right linear.
