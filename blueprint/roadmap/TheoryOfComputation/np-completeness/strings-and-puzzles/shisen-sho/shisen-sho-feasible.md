# Feasible instances of GENERALIZED SHISEN-SHO

An instance of GENERALIZED SHISEN-SHO is feasible when all tiles can be removed: a sequence of pairs, removed in order, in which every tile occurs exactly once, the two tiles of each pair have the same label, and they can be connected while exactly the tiles of the earlier pairs are gone. Feasibility does not include well-formedness; the decision problem requires both.
