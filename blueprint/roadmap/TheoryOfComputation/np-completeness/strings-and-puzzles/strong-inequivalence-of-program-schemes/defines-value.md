# Value of $f_0(x_0)$ defined by a recursion scheme in STRONG INEQUIVALENCE FOR MONADIC RECURSION SCHEMES

In STRONG INEQUIVALENCE FOR MONADIC RECURSION SCHEMES, the value of $f_0(x_0) = g_{k_0}(x_0)$ defined by the scheme $S$ is $v$ when the one-letter word $g_{k_0}$ applied to $x_0$ has [value](computes.md) $v$ under $S$, that is, when this has a finite derivation.
