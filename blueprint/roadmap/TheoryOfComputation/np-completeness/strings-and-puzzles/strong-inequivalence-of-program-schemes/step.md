# One execution step of an Ianov scheme

In STRONG INEQUIVALENCE OF IANOV SCHEMES, one execution step on a configuration `(c, x)`, where `c` is the `0`-based index of the current instruction `I_{c+1}`: an assignment applies its function and moves to the next instruction, a test jumps to `Iⱼ` (index `j - 1`) or `Iₖ`, and a halted configuration is fixed. Subtraction is natural-number subtraction, so `a - b = 0` whenever `a ≤ b`.
