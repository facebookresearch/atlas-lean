# Control-flow relation of a scheme on `0`-based instruction indices in STRONG INEQUIVALENCE OF IANOV SCHEMES (loop-free, trivial `P₂`)

In STRONG INEQUIVALENCE OF IANOV SCHEMES (loop-free, trivial `P₂`), the control-flow relation of a scheme on `0`-based instruction indices: an assignment `x ← f_r(x)` at index `c` passes control to `c + 1`, and a test `if p_r(x) then goto Iⱼ else goto Iₖ` at index `c` passes control to `j - 1` or `k - 1`. Subtraction is natural-number subtraction, so `a - b = 0` whenever `a ≤ b`.
