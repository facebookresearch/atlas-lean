# Linear monadic recursion scheme over `F` in STRONG INEQUIVALENCE FOR MONADIC RECURSION SCHEMES

In STRONG INEQUIVALENCE FOR MONADIC RECURSION SCHEMES, a linear monadic recursion scheme over `F`, `P` and `G`: one defining statement `gₖ x = if pⱼ x then α x else β x` for each `gₖ ∈ G`, with `pⱼ ∈ P` and `α`, `β` linear words.
