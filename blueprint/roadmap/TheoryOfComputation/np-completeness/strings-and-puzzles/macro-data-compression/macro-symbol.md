# Macro symbols: letters and pointers

A macro symbol is either a letter $a$, for some $a \in \mathbb{N}$, or a pointer $p_{j+1}$, for some index $j \in \mathbb{N}$; a letter is never a pointer. Macro strings are finite strings of macro symbols, used both for compressed strings and for dictionary strings.
