# Instances of macro data compression

An instance of macro data compression is a quadruple $(k, s, h, B)$ of a natural number $k$ (the alphabet is $\{0, \dots, k - 1\}$), a finite string $s$ of natural numbers, a pointer cost $h \in \mathbb{N}$ and a bound $B \in \mathbb{N}$. No condition is imposed on these components; well-formedness is a separate condition.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [SR22] EXTERNAL MACRO DATA COMPRESSION, p. 231.
- J. A. Storer and T. G. Szymanski, "Data compression via textual substitution", Journal of the ACM 29 (1982), 928-951, doi:10.1145/322344.322346.
