# Inserting a fixed pointer cost

For the EXTERNAL ([SR22]) and the INTERNAL ([SR23]) MACRO DATA COMPRESSION problems with a fixed pointer cost, the instance with pointer cost $h$ built from an instance $(k, s, B)$ is $(k, s, h, B)$: both maps send $(h, (k, s, B))$ to $(k, s, h, B)$ in the same target type.
