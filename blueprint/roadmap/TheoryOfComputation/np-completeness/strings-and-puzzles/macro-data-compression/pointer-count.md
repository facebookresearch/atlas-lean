# Number of pointer occurrences in a macro string

A macro symbol is a letter $a \in \mathbb{N}$ or a pointer $p_{j+1}$ with index $j \in \mathbb{N}$. For a macro string $u$, $\pi(u)$ is the number of positions of $u$ that hold a pointer, counted with multiplicity.

- J. A. Storer and T. G. Szymanski, "Data compression via textual substitution", Journal of the ACM 29 (1982), 928-951, doi:10.1145/322344.322346.
