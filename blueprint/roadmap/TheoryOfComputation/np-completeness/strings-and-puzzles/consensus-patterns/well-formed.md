# Well-formed CONSENSUS PATTERNS instances

An instance $(a, (s_1, \dots, s_k), L, D)$ (the instance format of CLOSEST SUBSTRING: an alphabet size $a$, strings $s_i$, a pattern length $L$ and a bound $D$) is well-formed for CONSENSUS PATTERNS when there is at least one string, every letter is below $a$, $0 < L \le |s_i|$ for every string, the strings are pairwise distinct, and all strings have the same length.
