# Feasible CIRCULAR CONSECUTIVE SETS instances

An instance $(s, C, K)$ of CIRCULAR CONSECUTIVE SETS is feasible when some string $w$ over the symbols $0, \dots, s-1$ with $|w| \le K$ has, for every subset $\Sigma_i$, a contiguous block of the doubled string $ww$ whose symbols are exactly those of $\Sigma_i$, each once.
