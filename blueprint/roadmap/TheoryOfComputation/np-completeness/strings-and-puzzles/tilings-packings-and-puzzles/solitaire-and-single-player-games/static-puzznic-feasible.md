# Feasible instances of STATIC PUZZNIC SOLVABILITY (CUBIC)

An instance is feasible when some sequence of steps leaves no patterned block. A step does one of three things: a block with an empty cell directly below it falls one cell; when no block can fall, every block that has an orthogonally adjacent block of the same pattern is removed, all at once; when no block can fall and no two adjacent blocks match, one block moves one cell left or right into an empty cell. Cells outside the grid count as walls.
