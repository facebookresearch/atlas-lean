# STATIC PUZZNIC SOLVABILITY (CUBIC) as a decision problem

The decision problem STATIC PUZZNIC SOLVABILITY (CUBIC) accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of grids of cell codes, to an instance that is well-formed and feasible for STATIC PUZZNIC SOLVABILITY (CUBIC). It rejects every bitstring that does not decode to such an instance.
