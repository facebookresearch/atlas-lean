# ONE-PERSON PEBBLE GAME as a decision problem

The decision problem ONE-PERSON PEBBLE GAME accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quintuples $(n, A, v_0, S, R)$, to an instance that is well-formed and feasible for ONE-PERSON PEBBLE GAME. It rejects every bitstring that does not decode to such an instance.
