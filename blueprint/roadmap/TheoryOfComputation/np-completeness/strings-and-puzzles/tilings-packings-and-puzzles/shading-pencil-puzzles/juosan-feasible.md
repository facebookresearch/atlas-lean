# Feasible instances of JUOSAN

A HEYAWAKE instance (a rectangular grid divided into rectangular territories, some numbered) is feasible for JUOSAN when every cell can be filled with a $-$-mark or a $|$-mark so that each territory's number equals the count of the majority mark (or of either mark when tied), $-$-marks never extend more than two cells vertically, and $|$-marks never extend more than two cells horizontally.
