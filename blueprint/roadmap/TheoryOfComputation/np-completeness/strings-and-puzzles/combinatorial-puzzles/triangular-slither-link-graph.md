# Grid graph of a TRIANGULAR SLITHER LINK instance

The vertex set is $\mathbb{N} \times \mathbb{N}$. Inside $0 \le x \le w$, $0 \le y \le h$ the edges are those of the triangular grid described below; all vertices outside this rectangle are isolated. For an instance of TRIANGULAR SLITHER LINK with $h$ rows of $2w$ triangles, two points of the rectangle are adjacent when they are neighbours on the same horizontal line or neighbouring corners on consecutive lines. The row length is $w = \lfloor \ell / 2 \rfloor$ (natural-number division) for a first row of length $\ell$, and triangles beyond the end of a row carry no clue.
