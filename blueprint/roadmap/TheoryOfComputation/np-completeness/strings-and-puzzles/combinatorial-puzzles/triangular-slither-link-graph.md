# Grid graph of a TRIANGULAR SLITHER LINK instance

The grid graph of an instance of TRIANGULAR SLITHER LINK with $h$ rows of $2w$ triangles is the part of the triangular grid on the lattice points $(x, y)$ with $x \le w$ and $y \le h$: two such points are adjacent when they are neighbours on the same horizontal line or neighbouring corners on consecutive lines. The row length is $w = \lfloor \ell / 2 \rfloor$ (natural-number division) for a first row of length $\ell$, and triangles beyond the end of a row carry no clue.
