# Feasible instances of TRIANGULAR SLITHER LINK

An instance of TRIANGULAR SLITHER LINK is feasible when some cycle $c$ of the grid has, for every clue triangle, exactly as many of the triangle's sides among its edges as the clue value. The row length is $w = \lfloor \ell / 2 \rfloor$ (natural-number division) for a first row of length $\ell$, and triangles beyond the end of a row carry no clue.
