# Feasible instances of WITNESS PUZZLES WITH EDGE HEXAGONS

An instance of WITNESS PUZZLES WITH EDGE HEXAGONS is feasible when the puzzle has a solution: a path of the grid from a start circle to an end cap containing every edge that carries a hexagon. The number of grid columns is the length of the first row of marks; a vertex with no listed mark has no mark, and an edge with no listed flag carries no hexagon.
