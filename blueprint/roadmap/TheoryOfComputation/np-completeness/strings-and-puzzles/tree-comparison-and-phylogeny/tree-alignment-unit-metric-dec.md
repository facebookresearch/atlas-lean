# TREE ALIGNMENT (given phylogeny, unit metric) as a decision problem

The decision problem TREE ALIGNMENT (given phylogeny, unit metric) accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of its instances, to an instance that is well-formed and feasible for TREE ALIGNMENT (given phylogeny, unit metric). It rejects every bitstring that does not decode to such an instance.
