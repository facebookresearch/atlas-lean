# UNORDERED TREE EDIT DISTANCE is NP-complete

The decision problem UNORDERED TREE EDIT DISTANCE belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- K. Zhang, R. Statman and D. Shasha, "On the editing distance between unordered labeled trees", Information Processing Letters 42(3) (1992), 133-139, doi:10.1016/0020-0190(92)90136-J (NP-complete even for binary trees over a two-letter label alphabet).
- R. D. M. Page and G. Valiente, "An edit script for taxonomic classifications", BMC Bioinformatics 6 (2005), 208, doi:10.1186/1471-2105-6-208 (records the result for the least number of operations).
- R. Sridharamurthy, T. B. Masood, A. Kamakshidasan and V. Natarajan, "Edit distance between merge trees", IEEE Transactions on Visualization and Computer Graphics 26(3) (2020), 1518-1531, doi:10.1109/TVCG.2018.2873612, arXiv:2207.08511 (Section 2.3 and Section 3.1: the edit operations, and the edit distance as the cost of a cheapest one-to-one, ancestor-preserving mapping).
