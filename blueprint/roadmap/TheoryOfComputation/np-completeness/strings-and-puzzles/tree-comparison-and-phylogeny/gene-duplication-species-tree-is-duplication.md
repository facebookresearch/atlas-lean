# Duplication clusters of a gene tree

The gene cluster $C$ is a duplication for the species tree $S$ (a binary hierarchy on the species): for some child $D$ of $C$ (a gene cluster properly inside $C$ with no gene cluster strictly between them), $M(C) = M(D)$, i.e. every species cluster containing $λ(D)$ contains $λ(C)$. A leaf with no listed species is labeled by species $0$.
