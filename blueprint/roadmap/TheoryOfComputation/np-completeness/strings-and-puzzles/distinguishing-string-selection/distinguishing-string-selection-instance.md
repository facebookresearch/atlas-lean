# Instances of DISTINGUISHING STRING SELECTION

An instance of DISTINGUISHING STRING SELECTION consists of natural numbers $q$ (the alphabet size, symbols $0, \dots, q-1$) and $L$ (the string length), two lists of rows of natural numbers (the bad strings and the good strings) and natural distance bounds $k_b$ and $k_g$. Even at $q = L = 1$ the row `[3, 3]` is representable; only validated input consists of length-$L$ words over the alphabet ([validation](well-formed.md)).
