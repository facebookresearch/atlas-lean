# DISTINGUISHING STRING SELECTION is NP-complete

The decision problem DISTINGUISHING STRING SELECTION belongs to NP, and every decision problem
in NP has a polynomial-time many-one reduction to it.

## Sources

- J. K. Lanctot, M. Li, B. Ma, S. Wang, and L. Zhang, "Distinguishing string selection problems", Information and Computation 185 (2003), 41-55, doi:10.1016/S0890-5401(03)00057-9 (preliminary version: Proc. 10th ACM-SIAM SODA (1999)).
