# DISTINGUISHING STRING SELECTION as a decision problem

The decision problem DISTINGUISHING STRING SELECTION accepts a bitstring $x$ exactly when $x$
decodes, under the canonical bitstring encoding of DISTINGUISHING STRING SELECTION instances, to
an instance that is [well-formed](well-formed.md) and
[feasible](distinguishing-string-selection-feasible.md). It rejects every bitstring that does
not decode to an instance.
