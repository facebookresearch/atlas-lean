# Instances of LAMBEK CALCULUS DERIVABILITY

An instance of LAMBEK CALCULUS DERIVABILITY is a sequent $\Gamma \to A$ given as a list of token lists, one per type of $\Gamma$ in order, and a token list for $A$. A type is written in postfix notation: token $0$ is the product, $1$ is $/$ and $2$ is $\backslash$, each applied to the two most recent subtypes in their written order, and token $k + 3$ is the primitive type $p_k$.
