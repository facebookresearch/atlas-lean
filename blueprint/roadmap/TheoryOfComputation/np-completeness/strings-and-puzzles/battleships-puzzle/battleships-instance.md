# Instances of BATTLESHIPS

An instance of BATTLESHIPS is a tuple $(R, C, F, G)$: the row tallies $R$ (one per row), the column tallies $C$ (one per column), the fleet $F$ (entry $k$ is the number of ships of length $k + 1$), and the cells of the initial grid that are given, each as a pair of a cell $(r, c)$ and a flag saying whether the cell holds a ship segment.
