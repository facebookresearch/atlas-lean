# Well-formed DOSUN-FUWARI instances

A DOSUN-FUWARI instance is well-formed when the grid has at least one row and one column, every row has the same length, and, for each positive label, all the cells with that label are mutually reachable in the [room graph](room-graph.md). Feasibility counts objects per label, so this connectivity is what makes each label a single room.
