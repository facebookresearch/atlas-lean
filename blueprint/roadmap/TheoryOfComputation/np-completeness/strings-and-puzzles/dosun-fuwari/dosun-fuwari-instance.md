# Instances of DOSUN-FUWARI

An instance of DOSUN-FUWARI is an arbitrary list of rows of natural numbers, top to bottom; in the usual reading entry `0` is a black cell and an entry $k \ge 1$ a cell of room $k$. The grid width is the length of the first row (zero if there is none), so `[[], [1]]` has a stored nonzero entry but no cell in the grid. See the puzzle's local [validation](well-formed.md).
