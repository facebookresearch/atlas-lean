# REGULAR EXPRESSION INEQUIVALENCE FOR BOUNDED LANGUAGES as a decision problem

The decision problem REGULAR EXPRESSION INEQUIVALENCE FOR BOUNDED LANGUAGES accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(m, \mathit{toks}_1, \mathit{toks}_2)$ of an alphabet size and two postfix token lists, to an instance that is [well-formed](well-formed-7.md) and [feasible](regular-expression-inequivalence-bounded-2.md) for REGULAR EXPRESSION INEQUIVALENCE FOR BOUNDED LANGUAGES. It rejects every bitstring that does not decode to such an instance.
