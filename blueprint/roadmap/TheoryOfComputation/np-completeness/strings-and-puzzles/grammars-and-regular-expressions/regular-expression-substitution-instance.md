# Instances of REGULAR EXPRESSION SUBSTITUTION

An instance is a quadruple of a natural number $m$, a raw token list (read as the postfix encoding of $R$), a list of raw token lists (read as $R_1, \dots, R_n$) and a word $w$ (a list of natural letters). A token list may be empty or fail to parse; which expression it represents is defined only when parsing succeeds. Successful parsing and alphabet bounds belong to [validation](well-formed-2-7.md).
