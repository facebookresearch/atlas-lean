# NON-FREEDOM FOR LOOP-FREE PROGRAM SCHEMES is NP-complete

NON-FREEDOM FOR LOOP-FREE PROGRAM SCHEMES is NP-complete: the decision problem over bitstrings that accepts exactly the bitstrings that decode to a well-formed instance with a solution lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it. Source: Garey and Johnson (1979), [PO19]; Constable, Hunt, and Sahni (1974; journal version 1980).
