# Well-formed instances of NON-FREEDOM FOR LOOP-FREE PROGRAM SCHEMES

Well-formedness of an instance of NON-FREEDOM FOR LOOP-FREE PROGRAM SCHEMES: every instruction is an assignment `x ← f(y)` with `x, y ∈ X` and `f ∈ F`, a test of `p ∈ P` on `x ∈ X` with both targets among the instructions, or `halt`; and the flow graph has no directed cycle.
