# DELTOIDAL TRIHEXAGONAL SLITHER LINK is NP-complete

The DELTOIDAL TRIHEXAGONAL SLITHER LINK decision problem belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- J. Kölker, "Selected Slither Link variants are NP-complete", Journal of Information Processing 20(3) (2012), 709-712, doi:10.2197/ipsjjip.20.709, Theorem 4.
