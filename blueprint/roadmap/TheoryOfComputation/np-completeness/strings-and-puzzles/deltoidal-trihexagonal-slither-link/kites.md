# The six kites of a hexagon

Hexagon $(c, r)$ has corners $P_0, \dots, P_5$, side midpoints $M_0, \dots, M_5$ and center $Z$ at lattice points determined by $x = 2(2c + (r \bmod 2))$ and $y = 2r$: $P_0 = (x, y)$, $P_1 = (x + 2, y)$, $P_2 = (x + 4, y)$, $P_3 = (x + 4, y + 2)$, $P_4 = (x + 2, y + 2)$, $P_5 = (x, y + 2)$, $M_0 = (x + 1, y)$, $M_1 = (x + 3, y)$, $M_2 = (x + 4, y + 1)$, $M_3 = (x + 3, y + 2)$, $M_4 = (x + 1, y + 2)$, $M_5 = (x, y + 1)$ and $Z = (x + 2, y + 1)$. Kite $k$ is the kite at corner $P_k$, with sides $Z M_{k-1}$, $M_{k-1} P_k$, $P_k M_k$ and $M_k Z$ (indices modulo $6$).
