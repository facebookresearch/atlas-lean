# Number of hexagons per row

The number $w$ of hexagons per row of a DELTOIDAL TRIHEXAGONAL SLITHER LINK instance is the length of the first row of its clue grid, and $0$ when there are no rows. The other rows may have different lengths: that every row has exactly $w$ entries is a condition of [well-formedness](well-formed.md), not part of this definition. The [grid](graph.md) and the clue checks of [feasibility](deltoidal-trihexagonal-slither-link-feas.md) use this $w$.
