# Instances of THE HOUR-GLASS

An instance of THE HOUR-GLASS consists of a natural number $m$, the declared width of the top row (not necessarily the length of the first stored row), a list of rows of natural numbers (top to bottom, each left to right) and a natural target $t$: $(2, [[7]], 7)$ decodes. The hour-glass shape is required only by [validation](well-formed.md).
