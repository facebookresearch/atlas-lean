# CODE GENERATION WITH UNLIMITED REGISTERS (only leaves shared) is NP-complete

The CODE GENERATION WITH UNLIMITED REGISTERS (only leaves shared) decision problem lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [PO5] CODE GENERATION WITH UNLIMITED REGISTERS (comment: NP-complete even if only leaves have in-degree exceeding 1).
- A. V. Aho, S. C. Johnson and J. D. Ullman, "Code generation for expressions with common subexpressions", Journal of the ACM 24(1) (1977), 146-160, doi:10.1145/321992.322001.
