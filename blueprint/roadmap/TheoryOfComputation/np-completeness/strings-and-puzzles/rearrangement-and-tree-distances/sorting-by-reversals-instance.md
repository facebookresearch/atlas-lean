# Instances of SORTING BY REVERSALS and BLOCK SORTING

An instance is a pair of a list of natural numbers, read as a permutation $\pi$ written $[\pi(1), \dots, \pi(n)]$, and a natural-number bound. The same pairs are the instances of SORTING BY REVERSALS, with bound $K$, and of BLOCK SORTING, with bound $m$. The type does not require the list to be a permutation of $1, \dots, n$; that is a separate well-formedness condition.
