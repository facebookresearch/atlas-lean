# Transposition of adjacent factors

Exchange the factor in positions $i, \dots, j-1$ with the factor in positions $j, \dots, k-1$, for $i \le j \le k$; positions past the end are ignored. In general the result is the first $i$ entries, then those in positions $j, \dots, k-1$, then those in positions $i, \dots, j-1$, then those from position $k$ on, where a range that ends before it starts is empty (truncated subtraction).
