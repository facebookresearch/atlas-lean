# Feasible instances of DCJ MEDIAN

An instance is feasible when some graph $M$ on the extremities $0, \dots, 2n - 1$ is a genome (each extremity in at most one adjacency) and there are $k_1 + k_2 + k_3 \le K$ such that, for each of the three [constructed input graphs](genome.md), a sequence of at most $k_i$ DCJ operations leads **from that input graph to $M$**. Only the median $M$ is required to be a genome; the input graphs are built from the raw lists and need not be.
