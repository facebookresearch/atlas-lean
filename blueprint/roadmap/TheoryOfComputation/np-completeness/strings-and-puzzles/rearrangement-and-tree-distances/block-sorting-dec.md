# BLOCK SORTING as a decision problem

The decision problem BLOCK SORTING accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a permutation list and a bound, to an instance that is [well-formed](well-formed-7.md) and [feasible](block-sorting-feasible.md) for BLOCK SORTING. It rejects every bitstring that does not decode to such an instance.
