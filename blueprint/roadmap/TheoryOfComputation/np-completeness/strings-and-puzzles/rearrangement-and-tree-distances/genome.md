# Genome of an adjacency list

For an instance with $n$ genes and a list of pairs of natural numbers, the graph on the extremities $0, \dots, 2n - 1$ in which two distinct extremities are adjacent when the pair, in either order, is listed. The graph is built from any list, including one in which two pairs share an extremity; it is a genome, each extremity in at most one adjacency, only when the list describes one, as the genome-list condition requires.
