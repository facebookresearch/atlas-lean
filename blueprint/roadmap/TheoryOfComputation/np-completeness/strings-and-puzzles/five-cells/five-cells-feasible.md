# Feasible FIVE CELLS instances

A FIVE CELLS instance is feasible when every position of the [grid](../eye-witless/grid.md) rectangle, (number of rows) × (length of the first row), can be put into connected blocks of exactly five cells so that every numbered cell, showing the number $k$ (cell content $k + 1$, see [the cell contents](cell.md)), satisfies: its number of orthogonal neighbours in its own block **plus $k$ equals $4$**. Missing entries are blank, and entries outside the rectangle are not tested.
