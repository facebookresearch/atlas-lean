# Feasible HEXAGONAL SLITHER LINK instances

A HEXAGONAL SLITHER LINK instance is feasible when some cycle of the [graph](graph.md) has, for every clue hexagon of the rectangle (number of columns) × (length of the first column), exactly as many of the hexagon's [sides](sides.md) among its edges as the clue value. Missing entries are blank, and stored entries outside the rectangle are not tested.
