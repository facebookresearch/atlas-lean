# HEXAGONAL SLITHER LINK as a decision problem

The decision problem HEXAGONAL SLITHER LINK accepts a bitstring $x$ exactly when $x$ decodes,
under the canonical bitstring encoding of HEXAGONAL SLITHER LINK instances, to an instance that
is [well-formed](../choco-banana/well-formed.md) and [feasible](hexagonal-slither-link-feasible.md). It rejects
every bitstring that does not decode to an instance.
