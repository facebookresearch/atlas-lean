# HITTING STRING is NP-complete

The decision problem HITTING STRING belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [SR12] HITTING STRING (reference: [Fagin, 1974].
- transformation from 3SAT).
