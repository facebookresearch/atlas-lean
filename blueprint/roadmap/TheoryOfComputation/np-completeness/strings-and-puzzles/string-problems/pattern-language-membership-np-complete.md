# PATTERN LANGUAGE MEMBERSHIP is NP-complete

The decision problem PATTERN LANGUAGE MEMBERSHIP belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- D. Angluin, "Finding patterns common to a set of strings", Journal of Computer and System Sciences 21(1) (1980), 46-62, doi:10.1016/0022-0000(80)90041-0.
- A. Ehrenfeucht and G. Rozenberg, "Finding a homomorphism between two words is NP-complete", Information Processing Letters 9(2) (1979), 86-88, doi:10.1016/0020-0190(79)90135-2.
- both recorded in M. L. Schmid, *The Membership Problem of Pattern Languages and Related Topics*, PhD thesis, Loughborough University (2012), Theorem 2.7 (the membership problem for nonerasing pattern languages is NP-complete for `Σ = {a, b}`).
