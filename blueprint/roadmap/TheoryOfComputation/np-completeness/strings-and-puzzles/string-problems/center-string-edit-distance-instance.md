# Instances given by an alphabet size, a word list and a bound

An instance is a triple of a natural alphabet size, a raw list of words (each a list of natural letters, not necessarily below the alphabet size) and a natural bound $K$. The same triples are the instances of CENTER STRING and MEDIAN STRING UNDER EDIT DISTANCE, of SHORTEST COMMON SUPERSTRING and of STRING BARCODING; their size or cost measures, positive-bound tests and distinctness tests are separate predicates.
