# STRING-TO-STRING CORRECTION as a decision problem

The decision problem STRING-TO-STRING CORRECTION accepts a bitstring $z$ exactly when $z$ decodes, under the canonical bitstring encoding of quadruples $(s, x, y, K)$, to an instance that is [well-formed](well-formed-18.md) and [feasible](string-to-string-correction-feasible.md) for STRING-TO-STRING CORRECTION. It rejects every bitstring that does not decode to such an instance.
