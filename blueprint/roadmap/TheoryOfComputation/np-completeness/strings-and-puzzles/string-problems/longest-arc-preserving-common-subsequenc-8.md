# LONGEST ARC-PRESERVING COMMON SUBSEQUENCE FOR NESTED ARCS is NP-complete

The decision problem LONGEST ARC-PRESERVING COMMON SUBSEQUENCE FOR NESTED ARCS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- G.-H. Lin, Z.-Z. Chen, T. Jiang and J. Wen, "The longest common subsequence problem for sequences with nested arc annotations", Journal of Computer and System Sciences 65 (2002), 465-480, doi:10.1016/S0022-0000(02)00004-1.
- problem definitions as in V. Yu. Popov, "Arc-preserving subsequences of arc-annotated sequences", Acta Universitatis Sapientiae, Informatica 3 (2011), 35-47, arXiv:1104.4433.
