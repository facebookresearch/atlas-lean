# LONGEST ARC-PRESERVING COMMON SUBSEQUENCE FOR NESTED ARCS as a decision problem

The decision problem LONGEST ARC-PRESERVING COMMON SUBSEQUENCE FOR NESTED ARCS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quintuples $(S_1, P_1, S_2, P_2, k)$ of two sequences with arc lists and a bound, to an instance that is well-formed and feasible for LONGEST ARC-PRESERVING COMMON SUBSEQUENCE FOR NESTED ARCS. It rejects every bitstring that does not decode to such an instance.
