# STRING BARCODING is NP-complete

The decision problem STRING BARCODING belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- G. Lancia and R. Rizzi, "The approximability of the String Barcoding problem", Algorithms for Molecular Biology 1 (2006), article 12, doi:10.1186/1748-7188-1-12 (problem introduced by S. Rash and D. Gusfield, "String barcoding: uncovering optimal virus signatures", RECOMB 2002, doi:10.1145/565196.565229).
