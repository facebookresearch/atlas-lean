# MINIMUM COMMON STRING PARTITION is NP-complete

The decision problem MINIMUM COMMON STRING PARTITION belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- A. Goldstein, P. Kolman and J. Zheng, "Minimum common string partition problem: hardness and approximations", Electronic Journal of Combinatorics 12 (2005), #R50, doi:10.37236/1947, Theorem 2.2.
