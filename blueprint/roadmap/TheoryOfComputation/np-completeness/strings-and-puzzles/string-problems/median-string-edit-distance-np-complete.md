# MEDIAN STRING UNDER EDIT DISTANCE is NP-complete

The decision problem MEDIAN STRING UNDER EDIT DISTANCE belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- C. de la Higuera and F. Casacuberta, "Topology of strings: median string is NP-complete", Theoretical Computer Science 230 (2000), 39-48, doi:10.1016/S0304-3975(97)00240-5 (unbounded alphabets).
- F. Nicolas and E. Rivals, "Hardness results for the center and median string problems under the weighted and unweighted edit distances", Journal of Discrete Algorithms 3 (2005), 390-415, doi:10.1016/j.jda.2004.08.015 (bounded and binary alphabets).
