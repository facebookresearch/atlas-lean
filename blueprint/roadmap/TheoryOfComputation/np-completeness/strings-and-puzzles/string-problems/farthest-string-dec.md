# FARTHEST STRING as a decision problem

The decision problem FARTHEST STRING accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quadruples $(q, L, S, d)$, to an instance that is [well-formed](well-formed-4.md) and [feasible](farthest-string-feasible.md) for FARTHEST STRING. It rejects every bitstring that does not decode to such an instance.
