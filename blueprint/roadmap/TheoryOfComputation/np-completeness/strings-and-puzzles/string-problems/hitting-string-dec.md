# HITTING STRING as a decision problem

The decision problem HITTING STRING accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a length and a list of strings, to an instance that is [well-formed](well-formed-6.md) and [feasible](hitting-string-feasible.md) for HITTING STRING. It rejects every bitstring that does not decode to such an instance.
