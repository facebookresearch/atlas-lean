# Instances of LONGEST ARC-PRESERVING COMMON SUBSEQUENCE FOR NESTED ARCS

An instance is a quintuple of a list $S_1$ of natural letters with a list $P_1$ of natural pairs, a list $S_2$ with a list $P_2$, and a natural bound $k$; a pair $(i_1, i_2)$ is read as an arc joining two positions. The arc lists are raw: $([\,], [(0, 1)], [\,], [\,], 0)$ stores an arc although neither endpoint is a position. Arc endpoints, order, nesting and $k > 0$ belong to [validation](well-formed-8.md).
