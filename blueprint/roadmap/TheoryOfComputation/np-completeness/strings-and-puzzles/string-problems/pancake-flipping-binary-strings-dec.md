# PREFIX REVERSAL DISTANCE FOR BINARY STRINGS as a decision problem

The decision problem PREFIX REVERSAL DISTANCE FOR BINARY STRINGS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples of two strings and a bound, to an instance that is well-formed and feasible for PREFIX REVERSAL DISTANCE FOR BINARY STRINGS. It rejects every bitstring that does not decode to such an instance.
