# PREFIX REVERSAL DISTANCE FOR BINARY STRINGS as a decision problem

The decision problem PREFIX REVERSAL DISTANCE FOR BINARY STRINGS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples of two strings and a bound, to an instance that is [well-formed](well-formed-11.md) and [feasible](pancake-flipping-binary-strings-feasible.md) for PREFIX REVERSAL DISTANCE FOR BINARY STRINGS. It rejects every bitstring that does not decode to such an instance.
