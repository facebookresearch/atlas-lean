# CENTER STRING UNDER EDIT DISTANCE is NP-complete

The decision problem CENTER STRING UNDER EDIT DISTANCE belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- F. Nicolas and E. Rivals, "Complexities of the centre and median string problems", Combinatorial Pattern Matching (CPM 2003), Lecture Notes in Computer Science 2676 (2003), 315-327, doi:10.1007/3-540-44888-8_23 (Definition 2 and Theorem 4: the centre string problem is NP-complete even if the alphabet is binary).
- F. Nicolas and E. Rivals, "Hardness results for the center and median string problems under the weighted and unweighted edit distances", Journal of Discrete Algorithms 3 (2005), 390-415, doi:10.1016/j.jda.2004.08.015 (journal version).
