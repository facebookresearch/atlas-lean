# PATTERN LANGUAGE MEMBERSHIP as a decision problem

The decision problem PATTERN LANGUAGE MEMBERSHIP accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a pattern and a word, to an instance that is [well-formed](well-formed-12.md) and [feasible](pattern-language-membership-feasible.md) for PATTERN LANGUAGE MEMBERSHIP. It rejects every bitstring that does not decode to such an instance.
