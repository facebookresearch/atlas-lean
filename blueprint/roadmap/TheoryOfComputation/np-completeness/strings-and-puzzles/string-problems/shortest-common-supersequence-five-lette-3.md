# SHORTEST COMMON SUPERSEQUENCE OVER FIVE LETTERS as a decision problem

The decision problem SHORTEST COMMON SUPERSEQUENCE OVER FIVE LETTERS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a list of strings and a bound, to an instance that is [well-formed](well-formed-13.md) and [feasible](shortest-common-supersequence-five-lette-2.md) for SHORTEST COMMON SUPERSEQUENCE OVER FIVE LETTERS. It rejects every bitstring that does not decode to such an instance.
