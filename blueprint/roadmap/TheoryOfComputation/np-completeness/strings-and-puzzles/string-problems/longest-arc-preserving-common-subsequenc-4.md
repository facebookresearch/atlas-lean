# LONGEST ARC-PRESERVING COMMON SUBSEQUENCE FOR CROSSING ARCS is NP-complete

The decision problem LONGEST ARC-PRESERVING COMMON SUBSEQUENCE FOR CROSSING ARCS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
