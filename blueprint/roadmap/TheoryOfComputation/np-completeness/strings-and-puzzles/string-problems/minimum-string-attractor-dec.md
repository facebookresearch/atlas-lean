# MINIMUM STRING ATTRACTOR as a decision problem

The decision problem MINIMUM STRING ATTRACTOR accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a string and a bound, to an instance that is [feasible](minimum-string-attractor-feasible.md) for MINIMUM STRING ATTRACTOR (no well-formedness condition is imposed). It rejects every bitstring that does not decode to such an instance.
