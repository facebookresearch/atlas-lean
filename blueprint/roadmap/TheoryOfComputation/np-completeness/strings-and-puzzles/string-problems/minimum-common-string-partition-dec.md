# MINIMUM COMMON STRING PARTITION as a decision problem

The decision problem MINIMUM COMMON STRING PARTITION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples of two strings and a bound, to an instance that is [well-formed](well-formed-10.md) and [feasible](minimum-common-string-partition-feasible.md) for MINIMUM COMMON STRING PARTITION. It rejects every bitstring that does not decode to such an instance.
