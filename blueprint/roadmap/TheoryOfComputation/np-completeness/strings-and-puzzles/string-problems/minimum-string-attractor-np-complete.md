# MINIMUM STRING ATTRACTOR is NP-complete

The decision problem MINIMUM STRING ATTRACTOR belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- D. Kempa and N. Prezza, "At the roots of dictionary compression: string attractors", Proceedings of the 50th Annual ACM SIGACT Symposium on Theory of Computing (STOC 2018), 827-840, doi:10.1145/3188745.3188814; full version arXiv:1710.10964, Definition 3.1 (string attractor), Section 4 (the language `ATTRACTOR`) and Theorem 4.2 (with `k = n`).
