# STRING BARCODING as a decision problem

The decision problem STRING BARCODING accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(|\Sigma|, S, K)$ of an alphabet size, a list of strings and a bound, to an instance that is [well-formed](well-formed-17.md) and [feasible](string-barcoding-feasible.md) for STRING BARCODING. It rejects every bitstring that does not decode to such an instance.
