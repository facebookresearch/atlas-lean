# Instances of TRUNCATED HEXAGONAL SLITHER LINK

An instance of TRUNCATED HEXAGONAL SLITHER LINK is a value of type `List (List ℕ) × List (List ℕ)`: the dodecagon clue grid (row `r`, entry `c` for dodecagon `(c, r)`) and the triangle clue grid (row `y`, entry `x` for the triangle at hex vertex `(x, y)`); `0` for no clue and `v + 1` for clue value `v`.
