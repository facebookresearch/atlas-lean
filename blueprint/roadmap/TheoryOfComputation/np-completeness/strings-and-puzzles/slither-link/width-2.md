# Width of the first dodecagon row in TRUNCATED HEXAGONAL SLITHER LINK

For an instance of TRUNCATED HEXAGONAL SLITHER LINK, the width $w$ is the number of entries in the first row of the dodecagon clue grid, or $0$ when that grid has no rows. The other rows may have different lengths: that every row has exactly $w$ entries is a condition of [well-formedness](well-formed-3.md), not part of this definition. The [grid](graph-2.md), the face test and the clue checks of [feasibility](truncated-hexagonal-slither-link-feasibl.md) all use this $w$.
