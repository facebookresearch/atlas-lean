# Is threading in PROTEIN THREADING

In PROTEIN THREADING: `t` is a threading: `m` starting positions with `tᵢ + cᵢ ≤ tᵢ₊₁` for consecutive segments and `tₘ + cₘ ≤ n` (0-based positions). A missing starting position (an index beyond the end of `t`) reads as $0$, and a missing segment as the empty segment.
