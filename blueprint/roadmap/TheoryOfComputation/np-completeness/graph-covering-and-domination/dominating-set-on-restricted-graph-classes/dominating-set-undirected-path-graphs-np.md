# DOMINATING SET ON UNDIRECTED PATH GRAPHS is NP-complete

The decision problem DOMINATING SET ON UNDIRECTED PATH GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- K. S. Booth and J. H. Johnson, "Dominating sets in chordal graphs", SIAM Journal on Computing 11(1) (1982), 191-199, doi:10.1137/0211015 (finding a minimum dominating set is NP-complete for chordal graphs, "even when restricted to undirected path graphs").
- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT2] DOMINATING SET.
