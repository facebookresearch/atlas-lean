# Feasible instances of DOMINATING SET IN UNIT DISK GRAPHS

An instance $(P, K)$ of DOMINATING SET IN UNIT DISK GRAPHS is feasible when the [unit disk graph](unit-disk-graph.md) of $P$ has a dominating set of at most $K$ vertices, that is, a set $D$ of at most $K$ list indices such that every index lies in $D$ or is adjacent to an index in $D$. Feasibility does not include well-formedness; the decision problem requires both.
