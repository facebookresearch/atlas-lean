# DOMINATING SET ON SPLIT GRAPHS is NP-complete

The decision problem DOMINATING SET ON SPLIT GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- A. A. Bertossi, "Dominating sets for split and bipartite graphs", Information Processing Letters 19(1) (1984), 37-40, doi:10.1016/0020-0190(84)90126-1.
- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT2] DOMINATING SET.
