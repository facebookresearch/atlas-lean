# Undirected path graphs

A simple graph $G$ on the vertices $0, \dots, n-1$ is an undirected path graph when there are a tree $T$ on some vertex set $\{0, \dots, m-1\}$ and, for each vertex $v$ of $G$, the vertex set $P_v$ of some path in $T$, such that two distinct vertices $u, v$ of $G$ are adjacent exactly when $P_u$ and $P_v$ share a vertex.
