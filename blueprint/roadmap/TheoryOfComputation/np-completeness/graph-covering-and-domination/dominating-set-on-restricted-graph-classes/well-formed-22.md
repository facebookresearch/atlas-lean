# Well-formed instances of UPPER DOMINATION

An instance $(n, E, K)$ is well-formed for UPPER DOMINATION when it is a well-formed DOMINATING SET instance (the list $E$ has no repeated entries, and every pair $(u, v)$ in $E$ satisfies $u < n$, $v < n$, $u \ne v$ and $(v, u) \notin E$) and $0 < K \le n$.
