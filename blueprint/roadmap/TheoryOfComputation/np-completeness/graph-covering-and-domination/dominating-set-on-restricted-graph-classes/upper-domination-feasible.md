# Feasible instances of UPPER DOMINATION

An instance $(n, E, K)$ is feasible for UPPER DOMINATION when the graph of the instance (on the vertices $0, \dots, n-1$, with $u$ and $v$ adjacent when $u \ne v$ and $(u, v)$ or $(v, u)$ is in $E$) has a minimal dominating set with at least $K$ vertices: a set $S$ such that every vertex lies in $S$ or is adjacent to a vertex of $S$, and no proper subset of $S$ has this property.
