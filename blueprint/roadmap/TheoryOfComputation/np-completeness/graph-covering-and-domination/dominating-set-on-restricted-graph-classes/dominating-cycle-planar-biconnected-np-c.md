# DOMINATING CYCLE ON 2-CONNECTED PLANAR GRAPHS is NP-complete

The decision problem DOMINATING CYCLE ON 2-CONNECTED PLANAR GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- D. S. Johnson, "The NP-completeness column: an ongoing guide", J. Algorithms 5 (1984), 147-160, doi:10.1016/0196-6774(84)90045-2, Section 3 (the DOMINATING SET [GT2] variant whose dominating set must form a cycle: "NP-complete for planar 2-connected graphs, but solvable in polynomial time for outerplanar graphs"), crediting A.
