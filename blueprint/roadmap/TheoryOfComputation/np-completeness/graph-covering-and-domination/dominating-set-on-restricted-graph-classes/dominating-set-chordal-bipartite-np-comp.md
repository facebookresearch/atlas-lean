# DOMINATING SET ON CHORDAL BIPARTITE GRAPHS is NP-complete

The decision problem DOMINATING SET ON CHORDAL BIPARTITE GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- H. Müller and A. Brandstädt, "The NP-completeness of Steiner tree and dominating set for chordal bipartite graphs", Theoretical Computer Science 53(2-3) (1987), 257-265, doi:10.1016/0304-3975(87)90067-3.
- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT2] DOMINATING SET.
