# DOMINATING SET IN PENNY GRAPHS is NP-complete

DOMINATING SET IN PENNY GRAPHS is NP-complete: the decision problem over bitstrings that accepts exactly the bitstrings that decode to a well-formed instance with a solution lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it. Source: Clark, Colbourn and Johnson (1990); de Berg et al. (2020); ISGCI (`gc_1381`); Garey and Johnson (1979), [GT2].
