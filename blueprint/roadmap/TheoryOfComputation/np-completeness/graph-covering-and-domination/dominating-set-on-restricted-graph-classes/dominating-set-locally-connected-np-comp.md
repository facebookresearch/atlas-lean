# DOMINATING SET ON LOCALLY CONNECTED GRAPHS is NP-complete

The decision problem DOMINATING SET ON LOCALLY CONNECTED GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT2] DOMINATING SET.
- ISGCI, *Information System on Graph Classes and their Inclusions*, class `gc_932` (locally connected, https://www.graphclasses.org/classes/gc_932.html), problem Domination: NP-complete, with its note 1506 (communicated by A. Leitert): adding a true twin to every vertex gives a locally connected graph with the same domination number.
