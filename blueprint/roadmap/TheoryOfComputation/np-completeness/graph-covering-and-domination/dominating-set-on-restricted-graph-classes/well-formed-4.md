# Well-formed instances of DOMINATING SET ON CHORDAL BIPARTITE GRAPHS

An instance $(n, E, K)$ is well-formed for DOMINATING SET ON CHORDAL BIPARTITE GRAPHS when it is a well-formed DOMINATING SET instance (the list $E$ has no repeated entries, and every pair $(u, v)$ in $E$ satisfies $u < n$, $v < n$, $u \ne v$ and $(v, u) \notin E$), the graph of the instance (on the vertices $0, \dots, n-1$, with $u$ and $v$ adjacent when $u \ne v$ and $(u, v)$ or $(v, u)$ is in $E$) is bipartite and no cycle $C_k$ with $k \ge 6$ is an induced subgraph of it, and $K > 0$. Here a graph $F$ is an induced subgraph of a graph $G$ when some injective map from the vertices of $F$ to those of $G$ preserves both adjacency and non-adjacency.
