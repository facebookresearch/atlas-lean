# Subdivisions of K3,3

A simple graph $G$ contains a subdivision of $K_{3,3}$ when there are six distinct vertices $a_0, a_1, a_2, b_0, b_1, b_2$ and, for all $i, j \in \{0, 1, 2\}$, a path $P_{ij}$ in $G$ from $a_i$ to $b_j$, such that whenever a vertex lies on two different paths $P_{ij}$ and $P_{kl}$, it is an endpoint of $P_{ij}$.
