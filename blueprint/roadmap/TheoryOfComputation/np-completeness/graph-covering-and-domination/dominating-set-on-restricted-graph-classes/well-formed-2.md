# Well-formed instances of DOMINATING SET ON BIPARTITE GRAPHS OF MAXIMUM DEGREE 3

An instance $(n, E, K)$ is well-formed for DOMINATING SET ON BIPARTITE GRAPHS OF MAXIMUM DEGREE 3 when it is a well-formed DOMINATING SET instance (the list $E$ has no repeated entries, and every pair $(u, v)$ in $E$ satisfies $u < n$, $v < n$, $u \ne v$ and $(v, u) \notin E$), $0 < K \le n$, and the graph of the instance (on the vertices $0, \dots, n-1$, with $u$ and $v$ adjacent when $u \ne v$ and $(u, v)$ or $(v, u)$ is in $E$) is bipartite with every vertex of degree at most $3$.
