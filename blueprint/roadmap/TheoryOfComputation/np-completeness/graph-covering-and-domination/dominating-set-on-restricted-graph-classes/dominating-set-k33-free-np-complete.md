# DOMINATING SET ON GRAPHS WITHOUT A SUBDIVIDED K_{3,3} is NP-complete

The decision problem DOMINATING SET ON GRAPHS WITHOUT A SUBDIVIDED $K_{3,3}$ belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
