# Feasible instances of FEEDBACK VERTEX SET on digraphs with in- and out-degree at most 2

An instance of FEEDBACK VERTEX SET on digraphs with in- and out-degree at most 2 is feasible when there is a feedback vertex set of at most $K$ vertices: a set $V'$ of at most $K$ vertices containing at least one vertex of every directed cycle (closed directed walk of positive length).
