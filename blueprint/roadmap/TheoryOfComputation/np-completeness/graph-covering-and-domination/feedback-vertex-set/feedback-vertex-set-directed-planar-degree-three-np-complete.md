# FEEDBACK VERTEX SET is NP-complete on planar digraphs with in- and out-degree at most 3

The decision problem FEEDBACK VERTEX SET on planar digraphs with in- and out-degree at most 3 belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
