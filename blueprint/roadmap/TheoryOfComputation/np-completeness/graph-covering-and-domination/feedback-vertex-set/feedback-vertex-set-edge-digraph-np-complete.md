# FEEDBACK VERTEX SET on edge digraphs is NP-complete

The decision problem FEEDBACK VERTEX SET on edge digraphs belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT7] FEEDBACK VERTEX SET, comment on p. 192 ("for edge digraphs [Gavril, 1977a]").
