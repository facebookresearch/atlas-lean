# Instances of FEEDBACK VERTEX SET on digraphs

An instance of FEEDBACK VERTEX SET on digraphs (used by the variants with in- and out-degree at most 2, planar digraphs with in- and out-degree at most 3, and tournaments) consists of the following data: vertex count $n$ (vertices $0, \dots, n - 1$), the arc list, and the bound $K$.
