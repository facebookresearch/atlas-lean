# INDEPENDENT SET on 2-connected cubic planar graphs is NP-complete

The decision problem INDEPENDENT SET on 2-connected cubic planar graphs belongs to NP, and every
decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT20] INDEPENDENT SET, the problem restricted here.
- B. Mohar, "Face covers and the genus problem for apex graphs", Journal of Combinatorial Theory, Series B 82(1) (2001), 102-117, doi:10.1006/jctb.2000.2026, Theorem 4.1(a).
