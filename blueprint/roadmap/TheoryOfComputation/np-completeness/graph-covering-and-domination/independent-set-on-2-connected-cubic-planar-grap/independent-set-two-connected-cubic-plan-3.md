# INDEPENDENT SET on 2-connected cubic planar graphs as a decision problem

The decision problem INDEPENDENT SET on 2-connected cubic planar graphs accepts a bitstring $x$
exactly when $x$ decodes, under the canonical bitstring encoding of INDEPENDENT SET on
2-connected cubic planar graphs instances, to an instance that is [well-formed](well-formed.md)
and [feasible](../independent-set-on-restricted-graph-classes/triangle-free-independent-set-feasible.md). It rejects every bitstring that
does not decode to an instance.
