# GEODETIC SET is NP-complete

The following decision problem is NP-complete: it belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it. Given a connected simple graph on $\{0, \dots, n - 1\}$, given by a vertex count $n$ and an edge list without repeated edges (in either orientation) or loops, and a positive integer $K$, decide whether some set $S$ of at most $K$ vertices has every vertex on a shortest path between two vertices of $S$.
