# Feasible instances of BICLUSTER EDITING

An instance $(p, q, E, K)$ of BICLUSTER EDITING is feasible when some set $F \subseteq U \times V$ of at most $K$ pairs is a bicluster editing set: the bipartite graph with sides $U$ and $V$ and edge set $E \mathbin{\Delta} F = (E \setminus F) \cup (F \setminus E)$ is a bicluster graph.
