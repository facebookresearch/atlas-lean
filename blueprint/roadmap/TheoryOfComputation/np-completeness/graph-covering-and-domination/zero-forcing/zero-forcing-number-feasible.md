# Feasible instances of ZERO FORCING NUMBER

An instance $(n, E, K)$ is feasible for ZERO FORCING NUMBER when the graph of the instance (on the vertices $0, \dots, n-1$, with $u$ and $v$ adjacent when $u \ne v$ and $(u, v)$ or $(v, u)$ is in $E$) has a zero forcing set with at most $K$ vertices: a set $S$ of vertices from which every vertex is forced.
