# EFFICIENT EDGE DOMINATION as a decision problem

The decision problem EFFICIENT EDGE DOMINATION accepts a bitstring $x$ exactly when $x$ decodes,
under the canonical bitstring encoding of EFFICIENT EDGE DOMINATION instances, to an instance
that is [well-formed](well-formed.md) and [feasible](efficient-edge-domination-feasible.md). It
rejects every bitstring that does not decode to an instance.
