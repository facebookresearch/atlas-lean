# Graph

The graph of an instance of MULTIPLE CHOICE MATCHING: the simple graph on the vertices
$0, \dots, n - 1$, where $n$ is the vertex count of the instance, in which two distinct vertices
$u$ and $v$ are adjacent exactly when the labelled edge list $E$ of the instance contains an
triple $(u, v, c)$ or $(v, u, c)$, whatever its class label $c$. Loops $(u, u)$ add no edge, and
an entry with an endpoint outside $0, \dots, n - 1$ contributes nothing.
