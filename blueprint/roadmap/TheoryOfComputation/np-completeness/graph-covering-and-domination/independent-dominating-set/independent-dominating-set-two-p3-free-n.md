# INDEPENDENT DOMINATING SET ON 2P_3-FREE GRAPHS is NP-complete

The decision problem INDEPENDENT DOMINATING SET ON $2P_3$-FREE GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
