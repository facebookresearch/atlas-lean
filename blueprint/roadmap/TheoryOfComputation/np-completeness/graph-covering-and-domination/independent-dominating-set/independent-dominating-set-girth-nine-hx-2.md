# INDEPENDENT DOMINATING SET ON (C_3, \dots, C_8, H, X_{85}, K_{1,4})-FREE GRAPHS is NP-complete

The decision problem INDEPENDENT DOMINATING SET ON $(C_3, \dots, C_8, H, X_{85}, K_{1,4})$-FREE GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
