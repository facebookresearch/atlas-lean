# FEEDBACK VERTEX SET ON BIPARTITE PLANAR GRAPHS is NP-complete

The decision problem FEEDBACK VERTEX SET ON BIPARTITE PLANAR GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
