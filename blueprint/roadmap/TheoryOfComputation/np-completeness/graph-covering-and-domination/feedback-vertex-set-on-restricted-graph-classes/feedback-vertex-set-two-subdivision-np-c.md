# FEEDBACK VERTEX SET ON 2-SUBDIVISIONS is NP-complete

The decision problem FEEDBACK VERTEX SET ON 2-SUBDIVISIONS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), pp. 191-192, problem [GT7] FEEDBACK VERTEX SET, comment: "The corresponding problem for undirected graphs is also NP-complete".
- ISGCI, *Information System on Graph Classes and their Inclusions*, class `gc_472` (2-subdivision, https://www.graphclasses.org/classes/gc_472.html), problem Feedback vertex set: NP-complete, with its note 1648 (communicated by P. Irzhavsky): the 2-subdivision of a graph has a feedback vertex set of size `k` iff the graph does.
