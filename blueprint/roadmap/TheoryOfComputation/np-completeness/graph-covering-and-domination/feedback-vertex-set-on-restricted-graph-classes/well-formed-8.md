# Well-formed instances of FEEDBACK VERTEX SET ON 4-REGULAR HAMILTONIAN PLANAR GRAPHS

An instance $(n, E, K)$ is well-formed for FEEDBACK VERTEX SET ON 4-REGULAR HAMILTONIAN PLANAR GRAPHS when it is a well-formed FEEDBACK VERTEX SET instance (the list $E$ has no repeated entries, and every pair $(u, v)$ in $E$ satisfies $u < n$, $v < n$, $u \ne v$ and $(v, u) \notin E$), the graph of the instance (on the vertices $0, \dots, n-1$, with $u$ and $v$ adjacent when $u \ne v$ and $(u, v)$ or $(v, u)$ is in $E$) has a straight-line planar drawing (an injective placement of the vertices in $\mathbb{R}^2$ in which the segments of two distinct edges meet at most in common endpoints), $0 < K \le n$, every vertex has exactly $4$ neighbors, and the graph is Hamiltonian in Mathlib's sense (if $n \ne 1$ it has a Hamiltonian cycle).
