# FEEDBACK VERTEX SET ON PLANAR 2-SUBDIVISIONS is NP-complete

The decision problem FEEDBACK VERTEX SET ON PLANAR 2-SUBDIVISIONS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), pp. 191-192, problem [GT7] FEEDBACK VERTEX SET, comment: "The corresponding problem for undirected graphs is also NP-complete".
- E. Speckenmeyer, "On feedback vertex sets and nonseparating independent sets in cubic graphs", Journal of Graph Theory 12(3) (1988), 405-412, doi:10.1002/jgt.3190120311 (NP-complete on planar graphs of maximum degree 4).
- ISGCI, *Information System on Graph Classes and their Inclusions*, class `gc_675` (2-subdivision ∩ planar, https://www.graphclasses.org/classes/gc_675.html), problem Feedback vertex set: NP-complete, with its note 1648 (communicated by P. Irzhavsky): the 2-subdivision of a graph has a feedback vertex set of size `k` iff the graph does, and the reduction maintains planarity.
