# FEEDBACK VERTEX SET ON LINE GRAPHS OF PLANAR CUBIC BIPARTITE GRAPHS is NP-complete

The decision problem FEEDBACK VERTEX SET ON LINE GRAPHS OF PLANAR CUBIC BIPARTITE GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT7] FEEDBACK VERTEX SET, the problem restricted here.
- A. Munaro, "On line graphs of subcubic triangle-free graphs", Discrete Mathematics 340(6) (2017), 1210-1226, doi:10.1016/j.disc.2017.01.006, Theorem 24.
