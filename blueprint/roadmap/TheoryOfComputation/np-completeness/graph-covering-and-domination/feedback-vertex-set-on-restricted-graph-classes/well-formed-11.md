# Well-formed instances of FEEDBACK VERTEX SET ON k-REGULAR HAMILTONIAN GRAPHS

Fix a natural number $k$. An instance $(n, E, K)$ is well-formed for FEEDBACK VERTEX SET ON $k$-REGULAR HAMILTONIAN GRAPHS when it is a well-formed FEEDBACK VERTEX SET instance (the list $E$ has no repeated entries, and every pair $(u, v)$ in $E$ satisfies $u < n$, $v < n$, $u \ne v$ and $(v, u) \notin E$), every vertex of the graph of the instance (on the vertices $0, \dots, n-1$, with $u$ and $v$ adjacent when $u \ne v$ and $(u, v)$ or $(v, u)$ is in $E$) has exactly $k$ neighbors, and that graph has a Hamiltonian cycle.
