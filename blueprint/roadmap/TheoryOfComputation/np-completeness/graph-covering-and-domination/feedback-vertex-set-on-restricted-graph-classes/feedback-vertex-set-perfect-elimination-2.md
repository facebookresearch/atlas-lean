# FEEDBACK VERTEX SET IN PERFECT ELIMINATION BIPARTITE GRAPHS is NP-complete

The decision problem FEEDBACK VERTEX SET IN PERFECT ELIMINATION BIPARTITE GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
