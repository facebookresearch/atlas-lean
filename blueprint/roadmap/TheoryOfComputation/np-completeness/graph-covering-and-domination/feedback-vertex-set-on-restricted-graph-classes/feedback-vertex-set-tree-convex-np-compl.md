# FEEDBACK VERTEX SET IN TREE CONVEX BIPARTITE GRAPHS is NP-complete

The decision problem FEEDBACK VERTEX SET IN TREE CONVEX BIPARTITE GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

- W. Jiang, T. Liu, T. Ren and K. Xu, "Two hardness results on feedback vertex sets", Frontiers in Algorithmics and Algorithmic Aspects in Information and Management (FAW-AAIM 2011), Lecture Notes in Computer Science 6681 (2011), 233-243, doi:10.1007/978-3-642-21204-8_26.
