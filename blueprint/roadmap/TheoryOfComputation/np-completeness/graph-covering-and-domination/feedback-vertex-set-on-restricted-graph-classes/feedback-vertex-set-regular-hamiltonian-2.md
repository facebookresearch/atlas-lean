# FEEDBACK VERTEX SET ON k-REGULAR HAMILTONIAN GRAPHS is NP-complete

For every natural number $k \ge 4$, the decision problem FEEDBACK VERTEX SET ON $k$-REGULAR HAMILTONIAN GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- D. Cavallaro, *Hamiltonicity and the computational complexity of graph problems*, Bachelor thesis, Technische Universität Berlin (2019), https://fpt.akt.tu-berlin.de/publications/theses/BA-Cavallaro.pdf, Section 3.3, Theorem 3.29 (and Theorem 3.30 for `k = 5`, Theorem 3.5 for `k = 4`).
- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT7] FEEDBACK VERTEX SET (undirected version in the comment; the parent problem).
- ISGCI, *Information System on Graph Classes and their Inclusions*, class "5-regular ∩ hamiltonian" (gc_1317), problem Feedback vertex set: NP-complete.
