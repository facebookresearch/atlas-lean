# FEEDBACK VERTEX SET ON 4-REGULAR HAMILTONIAN PLANAR GRAPHS is NP-complete

The decision problem FEEDBACK VERTEX SET ON 4-REGULAR HAMILTONIAN PLANAR GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- D. Cavallaro, *Hamiltonicity and the computational complexity of graph problems*, Bachelor thesis, Technische Universität Berlin (2019), https://fpt.akt.tu-berlin.de/publications/theses/BA-Cavallaro.pdf, Theorem 3.5.
- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT7] FEEDBACK VERTEX SET (undirected version in the comment; the parent problem).
- ISGCI, *Information System on Graph Classes and their Inclusions*, class "4-regular ∩ hamiltonian ∩ planar" (gc_1315), problem Feedback vertex set: NP-complete.
