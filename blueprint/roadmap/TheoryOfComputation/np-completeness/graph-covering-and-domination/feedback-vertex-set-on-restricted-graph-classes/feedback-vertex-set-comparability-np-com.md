# FEEDBACK VERTEX SET ON COMPARABILITY GRAPHS is NP-complete

The decision problem FEEDBACK VERTEX SET ON COMPARABILITY GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT7] FEEDBACK VERTEX SET, the problem restricted here.
- A. Brandstädt, S. Brito, S. Klein, L. T. Nogueira and F. Protti, "Cycle transversals in perfect graphs and cographs", Theoretical Computer Science 469 (2013), 15-23, doi:10.1016/j.tcs.2012.10.030.
