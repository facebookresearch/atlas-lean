# FEEDBACK VERTEX SET ON BIPARTITE PLANAR GRAPHS OF MAXIMUM DEGREE 4 is NP-complete

The decision problem FEEDBACK VERTEX SET ON BIPARTITE PLANAR GRAPHS OF MAXIMUM DEGREE 4 belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT7] FEEDBACK VERTEX SET (the parent problem).
- ISGCI, *Information System on Graph Classes and their Inclusions*, class `gc_1153` (bipartite ∩ maximum degree 4 ∩ planar), problem Feedback vertex set: NP-complete (reference note 1593, V. B. Le: "Feedback vertex set is NP-complete for planar graph of maximum degree 4. By subdividing each edge by one new vertex, it easily follows that feedback vertex set is also NP-complete on bipartite planar graphs of maximum degree 4").
