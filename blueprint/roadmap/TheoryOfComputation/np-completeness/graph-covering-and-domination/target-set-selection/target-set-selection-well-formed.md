# Well-formed instances of TARGET SET SELECTION

An instance $(n, E, t, K)$ of TARGET SET SELECTION is well-formed when the edge list has no repeated edges (in either orientation) and no loops, and every endpoint is below $n$, so that it describes a simple graph on $\{0, \dots, n - 1\}$, the list $t$ has exactly $n$ entries, all positive, and $0 < K \le n$.
