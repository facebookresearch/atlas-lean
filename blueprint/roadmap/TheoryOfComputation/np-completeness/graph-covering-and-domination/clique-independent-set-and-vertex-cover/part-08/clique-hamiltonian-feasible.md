# Feasible instances of CLIQUE on Hamiltonian graphs

An instance $(n, E, K)$ of CLIQUE on Hamiltonian graphs is feasible when the graph of the instance
(the simple graph on $0, \dots, n - 1$ with the edges listed in $E$) has a clique of size $K$ or
more: a set of at least $K$ vertices any two of which are adjacent.
