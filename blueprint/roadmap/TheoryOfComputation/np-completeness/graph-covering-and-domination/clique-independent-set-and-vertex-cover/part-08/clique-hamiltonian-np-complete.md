# CLIQUE ON HAMILTONIAN GRAPHS is NP-complete

The decision problem CLIQUE ON HAMILTONIAN GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT19] CLIQUE (the parent problem).
- D. Cavallaro, *Hamiltonicity and the computational complexity of graph problems*, Bachelor thesis, Technische Universität Berlin (2019), https://fpt.akt.tu-berlin.de/publications/theses/BA-Cavallaro.pdf, Theorem 6.2 and Lemma 6.3 (stated there with the Hamiltonian cycle given; the reduction outputs Hamiltonian graphs, so it also applies when the cycle is not part of the instance).
- ISGCI, *Information System on Graph Classes and their Inclusions*, class "hamiltonian" (gc_1092), problem Clique: NP-complete.
