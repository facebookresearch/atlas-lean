# Ray points in CLIQUE in ray intersection graphs

In CLIQUE in ray intersection graphs: the point set of the open ray with origin `(x, y)` and direction `(d, e)`: `{(x + t d, y + t e) : t > 0}`. For a nonzero direction the origin itself is excluded; for the direction `(0, 0)` the set is the single point `(x, y)`. That directions are nonzero is a separate well-formedness condition.
