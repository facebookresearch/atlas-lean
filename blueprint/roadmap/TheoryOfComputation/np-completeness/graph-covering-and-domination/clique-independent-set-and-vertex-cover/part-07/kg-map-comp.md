# The CLIQUE-to-INDEPENDENT-SET and INDEPENDENT-SET-to-VERTEX-COVER map as a host component

For a [mode](../part-06/mode.md) $m$, standing for the reduction from CLIQUE to INDEPENDENT-SET
or the one from INDEPENDENT-SET to VERTEX-COVER, the component machine whose stack indices, stack
alphabets, labels and program are those of the [CLIQUE/VERTEX-COVER reduction machine](prog.md)
of mode $m$, with each of its stacks listed exactly once, in the order $X, O, A, B, D, Y$.
