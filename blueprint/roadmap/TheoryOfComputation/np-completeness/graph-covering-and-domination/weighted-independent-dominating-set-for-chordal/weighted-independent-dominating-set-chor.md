# Weighted independent dominating set instances (chordal graphs)

An instance of WEIGHTED INDEPENDENT DOMINATING SET for chordal graphs is a quadruple $(n, E, w, B)$ of a natural number $n$, the number of vertices (the vertices are $0, \dots, n-1$), a list $E$ of pairs of natural numbers, the edges, a list $w = (w(0), \dots, w(n-1))$ of natural numbers, the vertex weights, and a natural number $B$, the bound on the total weight.
