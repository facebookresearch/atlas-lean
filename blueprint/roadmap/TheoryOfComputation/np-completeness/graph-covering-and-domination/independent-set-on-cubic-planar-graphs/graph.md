# Graph of a INDEPENDENT SET on cubic planar graphs instance

The graph of a INDEPENDENT SET on cubic planar graphs instance with $n$ vertices and edge list
$E$ is the simple graph on $\{0, \dots, n-1\}$ in which distinct vertices $u$ and $v$ are
adjacent when $(u, v)$ or $(v, u)$ belongs to $E$. Loops are dropped, and pairs with an endpoint
at least $n$ contribute no edge.
