# Well-formed INDEPENDENT SET on boxicity-2 graphs instances

An INDEPENDENT SET on boxicity-2 graphs instance $(n, E, K)$ is well-formed when the edge list describes a simple graph on the vertices $0, \dots, n-1$ (a well-formed BOXICITY 2 instance), the graph has boxicity at most $2$ (it is a feasible BOXICITY 2 instance: an intersection graph of axis-parallel rectangles), and $0 < K \le n$. The edge-list encoding checks are those of a [simple edge list](../../graph-coloring-and-partitioning/partition-into-triangles/well-formed.md): no repeated entries, every pair $(u, v)$ has $u < n$, $v < n$ and $u \ne v$, and no pair is listed together with its reversal. These checks concern the encoding: adding the reversed copy of a listed edge makes the instance malformed although it does not change the simple graph.
