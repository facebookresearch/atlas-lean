# Well-formed INDEPENDENT SET on boxicity-2 graphs instances

An INDEPENDENT SET on boxicity-2 graphs instance $(n, E, K)$ is well-formed when the edge list describes a simple graph on the vertices $0, \dots, n-1$ (a well-formed BOXICITY 2 instance), the graph has boxicity at most $2$ (it is a feasible BOXICITY 2 instance: an intersection graph of axis-parallel rectangles), and $0 < K \le n$.
