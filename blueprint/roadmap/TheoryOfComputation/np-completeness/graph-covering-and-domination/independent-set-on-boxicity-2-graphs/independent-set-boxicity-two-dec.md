# INDEPENDENT SET on boxicity-2 graphs as a decision problem

The decision problem INDEPENDENT SET on boxicity-2 graphs accepts a bitstring $x$ exactly when
$x$ decodes, under the canonical bitstring encoding of INDEPENDENT SET on boxicity-2 graphs
instances, to an instance that is [well-formed](../../graph-coloring-and-partitioning/coloring-restricted-graph-classes/well-formed-5.md) and
[feasible](../independent-set-on-restricted-graph-classes/triangle-free-independent-set-feasible.md). It rejects every bitstring that does not
decode to an instance.
