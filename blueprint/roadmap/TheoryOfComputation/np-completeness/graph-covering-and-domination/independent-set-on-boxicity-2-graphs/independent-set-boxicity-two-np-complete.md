# INDEPENDENT SET on boxicity-2 graphs is NP-complete

The decision problem INDEPENDENT SET on boxicity-2 graphs belongs to NP, and every decision
problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT20] INDEPENDENT SET, the problem restricted here.
- C. S. Rim and K. Nakajima, "On rectangle intersection and overlap graphs", IEEE Transactions on Circuits and Systems I: Fundamental Theory and Applications 42(9) (1995), 549-553, doi:10.1109/81.414831.
