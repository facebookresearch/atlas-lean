# Well-formed INDEPENDENT SET on edge graphs of directed graphs instances

A INDEPENDENT SET on edge graphs of directed graphs instance is well-formed when the edge list
describes a simple graph on the vertices $0, \dots, n-1$, the graph is isomorphic to the edge graph of a digraph `D`
(on the vertices $0, \dots, m-1$), and `0 < K ≤ |V|`.
