# INDEPENDENT SET on edge graphs of directed graphs as a decision problem

The decision problem INDEPENDENT SET on edge graphs of directed graphs accepts a bitstring $x$
exactly when $x$ decodes, under the canonical bitstring encoding of INDEPENDENT SET on edge
graphs of directed graphs instances, to an instance that is [well-formed](well-formed.md) and
[feasible](../independent-set-on-restricted-graph-classes/triangle-free-independent-set-feasible.md). It rejects every bitstring that does
not decode to an instance.
