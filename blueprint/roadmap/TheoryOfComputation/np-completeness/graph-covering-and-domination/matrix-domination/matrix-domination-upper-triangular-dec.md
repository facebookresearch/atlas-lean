# The decision problem MATRIX DOMINATION for upper triangular matrices

MATRIX DOMINATION for upper triangular matrices as a decision problem on bitstrings: a bitstring
is accepted exactly when it decodes, under the canonical bitstring encoding, to a MATRIX
DOMINATION instance that is well-formed, whose matrix is upper triangular (every nonzero entry
$(r, c)$ has $r \le c$), and that is feasible. A bitstring that does not decode to an instance
is rejected.
