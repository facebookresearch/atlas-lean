# DOMINATING SET on circle graphs is NP-complete

The decision problem DOMINATING SET on circle graphs belongs to NP, and every decision problem
in NP has a polynomial-time many-one reduction to it.

## Sources

- J. M. Keil, "The complexity of domination problems in circle graphs", Discrete Applied Mathematics 42(1) (1993), 51-63, doi:10.1016/0166-218X(93)90178-Q.
- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT2] DOMINATING SET.
