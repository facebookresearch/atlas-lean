# Circle Graph

The circle graph of a chord model, a list of chords $(a_j, b_j)$, has the list positions as vertices; two distinct positions $j \ne k$ are adjacent when their chords interleave: $a_j < a_k < b_j < b_k$ or $a_k < a_j < b_k < b_j$. For a [well-formed](../../graph-coloring-and-partitioning/graph-coloring-variants/well-formed-7.md) instance every chord has $a_j < b_j$ and all endpoints are distinct, so distinct positions are distinct chords of a circle.
