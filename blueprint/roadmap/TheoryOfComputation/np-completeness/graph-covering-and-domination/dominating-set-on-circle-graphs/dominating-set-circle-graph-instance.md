# Instances of DOMINATING SET on circle graphs

An instance of DOMINATING SET on circle graphs consists of a list of chords, each a pair $(a, b)$ of endpoint positions, one chord per vertex, and the bound $K$. The raw pairs may have $a \ge b$ or shared endpoints; increasing endpoints, distinct endpoints and the range of $K$ are checked separately by [well-formedness](../../graph-coloring-and-partitioning/graph-coloring-variants/well-formed-7.md).
