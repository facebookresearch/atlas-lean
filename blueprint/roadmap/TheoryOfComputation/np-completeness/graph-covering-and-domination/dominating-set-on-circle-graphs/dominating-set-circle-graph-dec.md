# DOMINATING SET on circle graphs as a decision problem

The decision problem DOMINATING SET on circle graphs accepts a bitstring $x$ exactly when $x$
decodes, under the canonical bitstring encoding of DOMINATING SET on circle graphs instances, to
an instance that is [well-formed](../../graph-coloring-and-partitioning/graph-coloring-variants/well-formed-7.md) and
[feasible](dominating-set-circle-graph-feasible.md). It rejects every bitstring that does not
decode to an instance.
