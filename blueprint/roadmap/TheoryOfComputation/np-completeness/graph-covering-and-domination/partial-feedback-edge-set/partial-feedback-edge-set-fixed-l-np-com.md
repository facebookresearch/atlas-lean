# PARTIAL FEEDBACK EDGE SET is NP-complete for every fixed `L ≥ 3`

PARTIAL FEEDBACK EDGE SET is NP-complete for every fixed `L ≥ 3`: the decision problem over bitstrings that accepts exactly the bitstrings that decode to a well-formed instance with a solution (for each admissible value of the fixed parameter) lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it. Source: Garey and Johnson (1979), [GT9], comment; Yannakakis (1978).
