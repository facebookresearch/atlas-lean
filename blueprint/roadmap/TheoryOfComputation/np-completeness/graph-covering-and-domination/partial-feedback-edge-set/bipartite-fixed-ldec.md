# PARTIAL FEEDBACK EDGE SET for bipartite graphs with a fixed cycle-length bound `L` as a decision problem

For a fixed cycle-length bound `L`, PARTIAL FEEDBACK EDGE SET for bipartite graphs as a decision problem over bitstrings: a bitstring is accepted exactly when it decodes to an instance that is well formed for `L` and has a solution as a PARTIAL FEEDBACK EDGE SET instance whose cycle-length bound is set to `L`; every bitstring that decodes to no instance is rejected.
