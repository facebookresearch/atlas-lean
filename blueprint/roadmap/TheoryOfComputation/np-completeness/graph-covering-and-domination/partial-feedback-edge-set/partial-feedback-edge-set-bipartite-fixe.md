# PARTIAL FEEDBACK EDGE SET for bipartite graphs is NP-complete for every fixed `L ≥ 4`

PARTIAL FEEDBACK EDGE SET for bipartite graphs is NP-complete for every fixed `L ≥ 4`: the decision problem over bitstrings that accepts exactly the bitstrings that decode to a well-formed instance with a solution (for each admissible value of the fixed parameter) lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
