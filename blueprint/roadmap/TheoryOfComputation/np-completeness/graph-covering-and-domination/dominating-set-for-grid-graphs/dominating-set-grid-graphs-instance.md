# Instances of DOMINATING SET for grid graphs

An instance of DOMINATING SET for grid graphs consists of a list $V$ of points (each a pair of integer coordinates, each coordinate an integer $a - b$ given as the pair $(a, b)$) and the bound $K$. The vertices are the positions in the list: two copies of $(0, 0)$ followed by $(1, 0)$ give three vertices, not two sites. Positions can be identified with points only when the points are distinct, which [well-formedness](well-formed.md) checks.
