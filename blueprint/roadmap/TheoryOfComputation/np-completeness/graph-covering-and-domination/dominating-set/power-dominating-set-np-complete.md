# POWER DOMINATING SET is NP-complete

POWER DOMINATING SET is NP-complete: the decision problem over bitstrings that accepts exactly the bitstrings that decode to a well-formed instance with a solution lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it. Source: Haynes, Hedetniemi, Hedetniemi, and Henning (2002).
