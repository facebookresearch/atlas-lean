# The decision problem k-PATH-FREE DOMINATING SET (directed)

For a fixed natural number $k$, k-PATH-FREE DOMINATING SET as a decision problem on bitstrings:
a bitstring is accepted exactly when it decodes, under the canonical bitstring encoding, to an
instance that is well-formed and feasible (for the fixed parameter $k$). A bitstring that does
not decode to an instance is rejected.
