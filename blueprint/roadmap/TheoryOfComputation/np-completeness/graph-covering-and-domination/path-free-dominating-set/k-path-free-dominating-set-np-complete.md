# k-PATH-FREE DOMINATING SET (directed) is NP-complete for every fixed k ≥ 2

For every natural number $k \ge 2$, k-PATH-FREE DOMINATING SET in directed graphs, with the
parameter $k$ fixed, is NP-complete: the decision problem belongs to NP, and every decision
problem in NP has a polynomial-time many-one reduction to it.

Source: Bar-Yehuda and Vishkin (1982).
