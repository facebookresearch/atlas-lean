# INDEPENDENT SET OF UNIT SQUARES is NP-complete

The INDEPENDENT SET OF UNIT SQUARES decision problem lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

Instance: a finite set of `n` axis-parallel closed unit squares (side length `1`) in the plane, given by their centers, which have rational coordinates, and a positive integer `K ≤ n`. Question: are there `K` pairwise disjoint squares, that is, an independent set of size at least `K` in the intersection graph of the squares?
