# INDEPENDENT SET in segment intersection graphs is NP-complete

The decision problem INDEPENDENT SET in segment intersection graphs belongs to NP, and every
decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- J. Kratochvíl and J. Nešetřil, "INDEPENDENT SET and CLIQUE problems in intersection-defined classes of graphs", Commentationes Mathematicae Universitatis Carolinae 31(1) (1990), 85-93, http://dml.cz/dmlcz/106821 (Theorem 1).
- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT20] INDEPENDENT SET.
