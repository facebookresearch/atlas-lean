# INDEPENDENT SET on cubic Hamiltonian planar graphs is NP-complete

The decision problem INDEPENDENT SET on cubic Hamiltonian planar graphs belongs to NP, and every
decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT20] INDEPENDENT SET, the problem restricted here.
- H. Fleischner, G. Sabidussi and V. I. Sarvanov, "Maximum independent sets in 3- and 4-regular Hamiltonian graphs", Discrete Mathematics 310(20) (2010), 2742-2749, doi:10.1016/j.disc.2010.05.028.
