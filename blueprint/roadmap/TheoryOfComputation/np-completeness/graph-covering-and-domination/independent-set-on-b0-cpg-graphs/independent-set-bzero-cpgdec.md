# INDEPENDENT SET on B₀-CPG graphs as a decision problem

The decision problem INDEPENDENT SET on B₀-CPG graphs accepts a bitstring $x$ exactly when $x$
decodes, under the canonical bitstring encoding of INDEPENDENT SET on B₀-CPG graphs instances,
to an instance that is [well-formed](../../graph-coloring-and-partitioning/partition-into-cliques-on-restricted-graph-class/well-formed.md) and
[feasible](../independent-set-on-restricted-graph-classes/triangle-free-independent-set-feasible.md). It rejects every bitstring that does not
decode to an instance.
