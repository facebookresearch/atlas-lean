# INDEPENDENT SET on B₀-CPG graphs is NP-complete

The decision problem INDEPENDENT SET on B₀-CPG graphs belongs to NP, and every decision problem
in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT20] INDEPENDENT SET, the problem restricted here.
- N. Champseix, E. Galby, A. Munaro and B. Ries, "CPG graphs: Some structural and hardness results", Discrete Applied Mathematics 290 (2021), 17-35, doi:10.1016/j.dam.2020.11.018.
