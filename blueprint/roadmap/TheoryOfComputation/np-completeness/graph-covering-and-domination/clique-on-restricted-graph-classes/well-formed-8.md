# Well-formed CLIQUE on unit 3-track interval graphs instances

An instance $(n, E, K)$ of CLIQUE on unit 3-track interval graphs is well-formed when the edge list has no repeated edge, every edge joins two distinct vertices below $n$, and no edge appears in both orientations, its graph is a unit $3$-track interval graph (each vertex can be assigned one closed unit interval $[l, l+1]$ on each of three tracks so that two distinct vertices are adjacent exactly when their intervals on some track intersect), and $0 < K \le n$.
