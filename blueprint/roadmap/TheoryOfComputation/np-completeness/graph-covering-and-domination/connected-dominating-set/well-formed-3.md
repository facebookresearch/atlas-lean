# Well-formed CONNECTED DOMINATING SET on bipartite graphs instances

An instance $(n, E, K)$ of CONNECTED DOMINATING SET on bipartite graphs is well-formed when the edge list has no repeated edge, every edge joins two distinct vertices below $n$, and no edge appears in both orientations, its graph is bipartite, and $0 < K \le n$.

The same test is the well-formedness condition of INDUCED PATH for bipartite graphs; it requires bipartiteness, not connectivity of the host graph.
