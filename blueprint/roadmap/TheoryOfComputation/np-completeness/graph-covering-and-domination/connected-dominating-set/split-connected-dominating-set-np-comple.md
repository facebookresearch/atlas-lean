# CONNECTED DOMINATING SET ON SPLIT GRAPHS is NP-complete

The CONNECTED DOMINATING SET ON SPLIT GRAPHS decision problem lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

Instance: a split graph `G = (V, E)`, that is, a graph whose vertex set can be partitioned into a clique and an independent set, and a positive integer `K`. Question: is there a dominating set `V' ⊆ V` with `|V'| ≤ K` such that the induced subgraph `G[V']` is connected?
