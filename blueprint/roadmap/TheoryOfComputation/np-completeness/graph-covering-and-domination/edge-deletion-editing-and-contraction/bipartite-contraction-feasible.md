# Feasible BIPARTITE CONTRACTION instances

An instance $(n, E, K)$ of BIPARTITE CONTRACTION is feasible when at most $K$ edge contractions make its graph bipartite: for some $m$ there is a map $f$ from the vertices onto labels $0, \dots, m-1$ such that every label's set of vertices induces a connected subgraph, $n \le m + K$ (so at most $K$ contractions are used), and the quotient graph obtained by merging the vertices with the same label is bipartite.
