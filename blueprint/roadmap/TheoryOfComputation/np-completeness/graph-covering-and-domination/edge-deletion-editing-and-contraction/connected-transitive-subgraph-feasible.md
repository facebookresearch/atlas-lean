# Feasible CONNECTED TRANSITIVE SUBGRAPH instances

An instance $(n, A, K)$ (the instance format of TRANSITIVE SUBGRAPH: vertices $0, \dots, n-1$, an arc list $A$ and a bound $K$) is feasible for CONNECTED TRANSITIVE SUBGRAPH when some subdigraph $H$ of the instance's digraph on the same vertices has at least $K$ arcs, a transitive arc relation, and a connected underlying undirected graph.
