# INDEPENDENT SET ON 2-DIR GRAPHS is NP-complete

The decision problem INDEPENDENT SET ON 2-DIR GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- J. Kratochvíl and J. Nešetřil, "INDEPENDENT SET and CLIQUE problems in intersection-defined classes of graphs", Commentationes Mathematicae Universitatis Carolinae 31(1) (1990), 85-93, http://dml.cz/dmlcz/106821 (Theorem 1: "INDEPENDENT SET is polynomially solvable in 1-DIR and PURE-2-DIR, but it is NP-complete when restricted to 2-DIR and PURE-3-DIR").
- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT20] INDEPENDENT SET (the parent problem).
- ISGCI (https://www.graphclasses.org/classes/gc_864.html), class "2-DIR", problem "Independent set": NP-complete.
