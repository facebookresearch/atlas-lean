# INDEPENDENT SET ON GRAPHS WITHOUT A SUBDIVIDED K_{3,3} as a decision problem

The decision problem INDEPENDENT SET ON GRAPHS WITHOUT A SUBDIVIDED $K_{3,3}$ accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(n, E, K)$ (a natural number, a list of pairs of natural numbers and a natural number), to an instance that is well-formed for INDEPENDENT SET ON GRAPHS WITHOUT A SUBDIVIDED $K_{3,3}$ and feasible: some set of at least $K$ vertices contains no two adjacent vertices. It rejects every bitstring that does not decode to such an instance.
