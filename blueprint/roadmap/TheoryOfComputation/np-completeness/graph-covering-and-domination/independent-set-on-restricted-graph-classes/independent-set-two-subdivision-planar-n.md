# INDEPENDENT SET ON PLANAR 2-SUBDIVISIONS is NP-complete

The decision problem INDEPENDENT SET ON PLANAR 2-SUBDIVISIONS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- S. Poljak, "A note on stable sets and colorings of graphs", Commentationes Mathematicae Universitatis Carolinae 15 (1974), 307-309.
- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), p. 195, problem [GT20] INDEPENDENT SET, comment: "Remains NP-complete for cubic planar graphs".
- ISGCI, *Information System on Graph Classes and their Inclusions*, class 2-subdivision ∩ planar (gc_675, https://www.graphclasses.org/classes/gc_675.html), problem Independent set: NP-complete, from Poljak.
