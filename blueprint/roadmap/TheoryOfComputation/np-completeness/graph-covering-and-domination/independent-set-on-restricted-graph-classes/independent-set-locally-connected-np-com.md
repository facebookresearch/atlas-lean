# INDEPENDENT SET ON LOCALLY CONNECTED GRAPHS is NP-complete

The decision problem INDEPENDENT SET ON LOCALLY CONNECTED GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT20] INDEPENDENT SET (the parent problem).
- ISGCI, *Information System on Graph Classes and their Inclusions*, class "locally connected" (gc_932, https://www.graphclasses.org/classes/gc_932.html), problem Independent set: NP-complete, reference [1506] (a note communicated by P. Irzhavski: adding a universal vertex to a connected graph gives a locally connected graph, "Similarly for independent set").
