# INDEPENDENT SET ON TRIANGLE-FREE GRAPHS is NP-complete

The decision problem INDEPENDENT SET ON TRIANGLE-FREE GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT20] INDEPENDENT SET.
- S. Poljak, "A note on stable sets and colorings of graphs", Commentationes Mathematicae Universitatis Carolinae 15 (1974), 307-309.
