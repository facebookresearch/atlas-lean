# INDEPENDENT SET ON PURE-3-DIR GRAPHS is NP-complete

The decision problem INDEPENDENT SET ON PURE-3-DIR GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- J. Kratochvíl and J. Nešetřil, "INDEPENDENT SET and CLIQUE problems in intersection-defined classes of graphs", Commentationes Mathematicae Universitatis Carolinae 31(1) (1990), 85-93, http://dml.cz/dmlcz/106821 (Theorem 1).
- J. Kratochvíl and J. Matoušek, "Intersection graphs of segments", Journal of Combinatorial Theory, Series B 62 (1994), 289-315, doi:10.1006/jctb.1994.1071 (recognition of PURE-k-DIR is in NP).
- ISGCI, *Information System on Graph Classes and their Inclusions*, class PURE-3-DIR (gc_868), problem Independent set: NP-complete.
