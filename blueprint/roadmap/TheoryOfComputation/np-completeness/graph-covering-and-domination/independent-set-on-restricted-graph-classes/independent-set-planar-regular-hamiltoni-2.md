# INDEPENDENT SET ON PLANAR k-REGULAR HAMILTONIAN GRAPHS is NP-complete

For $k = 4$ and for $k = 5$, the decision problem INDEPENDENT SET ON PLANAR $k$-REGULAR HAMILTONIAN GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
