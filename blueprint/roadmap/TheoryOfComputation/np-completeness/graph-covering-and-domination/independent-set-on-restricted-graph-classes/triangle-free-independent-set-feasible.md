# Feasible independent set instances

An instance $(n, E, K)$ is feasible when its graph, on vertices $0, \dots, n-1$ with the listed edges, has an independent set (a set of pairwise non-adjacent vertices) with at least $K$ vertices. The predicate assumes no graph class: the INDEPENDENT SET problems restricted to triangle-free, cubic planar, 2-connected cubic planar, cubic Hamiltonian planar, $B_0$-CPG, boxicity-2, directed edge graphs and total graphs of bipartite graphs all use it, and impose their class through well-formedness.
