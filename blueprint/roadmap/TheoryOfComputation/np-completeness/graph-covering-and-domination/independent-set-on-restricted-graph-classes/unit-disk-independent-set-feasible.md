# Feasible instances of INDEPENDENT SET IN UNIT DISK GRAPHS

An instance $(P, K)$ of INDEPENDENT SET IN UNIT DISK GRAPHS is feasible when the [unit disk graph](../dominating-set-on-restricted-graph-classes/unit-disk-graph.md) of $P$ has an independent set of at least $K$ vertices, that is, a set of at least $K$ list indices no two of which are adjacent. Two equal listed points are adjacent, so they cannot both belong to such a set. Feasibility does not include well-formedness; the decision problem requires both.
