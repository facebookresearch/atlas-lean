# Well-formed instances of INDEPENDENT SET ON TRIANGLE-FREE GRAPHS

An instance $(n, E, K)$ is well-formed for INDEPENDENT SET ON TRIANGLE-FREE GRAPHS when its edge list $E$ has no repeated entries and every pair $(u, v)$ in $E$ satisfies $u < n$, $v < n$, $u \ne v$ and $(v, u) \notin E$, the graph of the instance (on the vertices $0, \dots, n-1$, with $u$ and $v$ adjacent when $u \ne v$ and $(u, v)$ or $(v, u)$ is in $E$) has no triangle, and $0 < K \le n$.
