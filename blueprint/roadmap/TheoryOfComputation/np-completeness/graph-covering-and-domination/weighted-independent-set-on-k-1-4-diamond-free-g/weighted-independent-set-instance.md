# Weighted independent set instances ($K_{1,4}$- and diamond-free)

An instance of WEIGHTED INDEPENDENT SET on $(K_{1,4}, \text{diamond})$-free graphs is a quadruple $(n, E, w, k)$ of a natural number $n$, the number of vertices (the vertices are $0, \dots, n-1$), a list $E$ of pairs of natural numbers, the edges, a list $w$ of natural numbers whose $v$-th entry is the weight of vertex $v$, and a natural number $k$, the target weight.
