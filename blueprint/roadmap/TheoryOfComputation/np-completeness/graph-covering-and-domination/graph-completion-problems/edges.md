# Edge set of a CHAIN GRAPH COMPLETION instance

The edge set $E \subseteq P \times Q$ of a CHAIN GRAPH COMPLETION instance with sides
$P = \{0, \dots, p - 1\}$ and $Q = \{0, \dots, q - 1\}$: the pairs $(a, b)$ with $a \in P$ and
$b \in Q$ that occur in the edge list of the instance. Listed pairs with a coordinate out of range
contribute nothing.
