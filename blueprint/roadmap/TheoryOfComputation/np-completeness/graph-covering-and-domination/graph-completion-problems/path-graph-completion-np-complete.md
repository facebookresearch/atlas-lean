# PATH GRAPH COMPLETION is NP-complete

The decision problem PATH GRAPH COMPLETION belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT36] PATH GRAPH COMPLETION, p. 199 (reference: [Gavril, 1977b], listed in Garey and Johnson's bibliography as F. Gavril, private communication; transformation from INTERVAL GRAPH COMPLETION).
