# Feasible instances of PATH GRAPH COMPLETION

An instance $(n, E, K)$ is feasible for PATH GRAPH COMPLETION when some graph $H$ on the vertices $0, \dots, n-1$ contains every edge of the graph $G$ on those vertices in which $u$ and $v$ are adjacent when $u \ne v$ and $(u, v)$ or $(v, u)$ is in $E$, has at most $K$ edges that are not edges of $G$, and is a path graph: there are a finite tree $T$ and, for each vertex $v$, the vertex set $P_v$ of a path in $T$, such that two distinct vertices are adjacent in $H$ exactly when $P_u$ and $P_v$ have a common vertex.
