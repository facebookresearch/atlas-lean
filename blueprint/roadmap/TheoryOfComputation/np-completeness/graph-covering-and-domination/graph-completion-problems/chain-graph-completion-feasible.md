# Feasible instances of CHAIN GRAPH COMPLETION

An instance $(p, q, E, K)$ is feasible for CHAIN GRAPH COMPLETION when some set $F$ of pairs $(a, b)$ with $a < p$ and $b < q$ contains every pair listed in $E$, has at most $K$ pairs not listed in $E$, and is a chain graph: for any two $u, v < p$, the set of $b$ with $(u, b) \in F$ is contained in the set of $b$ with $(v, b) \in F$, or the other way around.
