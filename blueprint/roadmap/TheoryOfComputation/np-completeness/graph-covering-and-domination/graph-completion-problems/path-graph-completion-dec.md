# PATH GRAPH COMPLETION as a decision problem

The decision problem PATH GRAPH COMPLETION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(n, E, K)$ (a natural number, a list of pairs and a natural number), to an instance that is well-formed and feasible for PATH GRAPH COMPLETION. It rejects every bitstring that does not decode to such an instance.
