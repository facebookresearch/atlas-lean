# ROOTED DIRECTED PATH GRAPH COMPLETION is NP-complete

The decision problem ROOTED DIRECTED PATH GRAPH COMPLETION belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT36] PATH GRAPH COMPLETION, p. 199 (comment: "Corresponding problem in which G' must be the intersection graph of a family of directed paths on an oriented tree (i.e., rooted, with all arcs directed away from the root) is also NP-complete"; reference: F. Gavril, 1977b).
