# Feasible instances of 2-RAINBOW DOMINATION

An instance of 2-RAINBOW DOMINATION is feasible when a 2-rainbow dominating function of weight at most `K` exists: `f` assigns each vertex a set of colors from `Fin 2`, every vertex with the empty set sees each color on some neighbor, and the total number of assigned colors is at most `K`. Feasibility does not include well-formedness; the decision problem requires both.
