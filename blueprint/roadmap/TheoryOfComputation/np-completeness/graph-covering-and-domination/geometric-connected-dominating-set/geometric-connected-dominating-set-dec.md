# GEOMETRIC CONNECTED DOMINATING SET as a decision problem

The decision problem GEOMETRIC CONNECTED DOMINATING SET accepts a bitstring $x$ exactly when $x$
decodes, under the canonical bitstring encoding of GEOMETRIC CONNECTED DOMINATING SET instances,
to an instance that is [well-formed](../../graph-coloring-and-partitioning/distance-d-partition-of-points-in-the-plane/well-formed.md) and
[feasible](geometric-connected-dominating-set-feasi.md). It rejects every bitstring that does
not decode to an instance.
