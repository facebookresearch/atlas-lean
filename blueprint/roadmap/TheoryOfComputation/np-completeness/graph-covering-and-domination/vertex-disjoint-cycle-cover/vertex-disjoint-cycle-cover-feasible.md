# Feasibility for VERTEX DISJOINT CYCLE COVER

An instance $(n, E, K)$ of VERTEX DISJOINT CYCLE COVER is feasible when there are a natural number $k \le K$ and cycles $C_0, \dots, C_{k-1}$ in the graph of the instance such that every vertex lies on exactly one of the $C_j$. Here a cycle is a closed walk at a base vertex that is nonempty, repeats no edge, and repeats no vertex other than its common start and end; a vertex lies on it when it is one of the vertices the walk visits. When $n = 0$ the empty family ($k = 0$) qualifies.
