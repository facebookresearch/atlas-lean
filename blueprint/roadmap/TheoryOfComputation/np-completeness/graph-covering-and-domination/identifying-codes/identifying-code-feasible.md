# Feasible instances of IDENTIFYING CODE

An instance $(n, E, K)$ of IDENTIFYING CODE is feasible when some set $C$ of at most $K$ vertices is an identifying code, with $B_1(v)$ the set of vertices $c$ with $d(c, v) \le 1$, where the distance $d$ is taken to be $0$ between vertices in different components (for a connected graph, as in every well-formed instance, $B_1(v)$ is the closed neighborhood of $v$): every $B_1(v)$ contains a vertex of $C$, and for any two distinct vertices $u$ and $v$ some vertex of $C$ lies in exactly one of $B_1(u)$ and $B_1(v)$.
