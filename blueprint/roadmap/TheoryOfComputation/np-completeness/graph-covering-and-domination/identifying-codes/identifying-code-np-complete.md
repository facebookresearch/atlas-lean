# IDENTIFYING CODE is NP-complete

The following decision problem is NP-complete: it belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it. Given a connected simple graph on $\{0, \dots, n - 1\}$, given by a vertex count $n$ and an edge list without repeated edges (in either orientation) or loops, and a natural number $K \le n$, decide whether some set $C$ of at most $K$ vertices meets every closed neighborhood and meets the closed neighborhoods of any two distinct vertices in different sets.

## Sources

- I. Charon, O. Hudry and A. Lobstein, "Minimizing the size of an identifying or locating-dominating code in a graph is NP-hard", Theoretical Computer Science 290 (2003), 2109-2120, doi:10.1016/S0304-3975(02)00536-4, Theorem 2.1 (with r = 1).
