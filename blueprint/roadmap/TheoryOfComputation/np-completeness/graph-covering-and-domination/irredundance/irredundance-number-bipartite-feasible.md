# Feasible instances of IRREDUNDANCE NUMBER ON BIPARTITE GRAPHS

An instance $(n, E, K)$ is feasible for IRREDUNDANCE NUMBER ON BIPARTITE GRAPHS when the graph of the instance (on the vertices $0, \dots, n-1$, with $u$ and $v$ adjacent when $u \ne v$ and $(u, v)$ or $(v, u)$ is in $E$) has a maximal irredundant set (an irredundant set not properly contained in another irredundant set) with at most $K$ vertices.
