# PARTIALLY ORDERED KNAPSACK WITH EQUAL SIZES AND VALUES as a decision problem

The decision problem PARTIALLY ORDERED KNAPSACK WITH EQUAL SIZES AND VALUES accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quadruples (a list of (size, value) pairs, a list of order pairs and two bounds), to an instance that is [well-formed](well-formed-10.md) for PARTIALLY ORDERED KNAPSACK WITH EQUAL SIZES AND VALUES and feasible for PARTIALLY ORDERED KNAPSACK. It rejects every bitstring that does not decode to such an instance.
