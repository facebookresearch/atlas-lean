# PACKING INTEGER PROGRAMMING as a decision problem

The decision problem PACKING INTEGER PROGRAMMING accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quadruples (a matrix, two vectors of rational codes and a natural number), to an instance that is [well-formed](well-formed-9.md) and [feasible](packing-integer-programming-feasible.md) for PACKING INTEGER PROGRAMMING. It rejects every bitstring that does not decode to such an instance.
