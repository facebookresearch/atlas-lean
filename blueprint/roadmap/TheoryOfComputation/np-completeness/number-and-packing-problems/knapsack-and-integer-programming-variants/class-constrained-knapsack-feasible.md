# Feasible instances of CLASS-CONSTRAINED KNAPSACK

An instance is feasible when some allotment $I$ of sets to knapsack compartments and some quantities $Q(k, j)$ of elements of set $k$ in knapsack $j$ satisfy: each knapsack holds at most its volume and uses at most $C_j$ compartments, each set contributes at most $U_k$ elements, only allotted pairs carry elements, and at least $K$ elements are packed.
