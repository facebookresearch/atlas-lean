# INTEGER KNAPSACK WITH EQUAL SIZES AND VALUES as a decision problem

The decision problem INTEGER KNAPSACK WITH EQUAL SIZES AND VALUES accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of UNBOUNDED KNAPSACK instances, to an instance that is [well-formed](well-formed-6.md) for INTEGER KNAPSACK WITH EQUAL SIZES AND VALUES and feasible for UNBOUNDED KNAPSACK. It rejects every bitstring that does not decode to such an instance.
