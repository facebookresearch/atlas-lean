# VECTOR BIN PACKING as a decision problem

The decision problem VECTOR BIN PACKING accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples (a dimension, a list of vectors and a number of bins), to an instance that is [well-formed](well-formed-13.md) and [feasible](vector-bin-packing-feasible.md) for VECTOR BIN PACKING. It rejects every bitstring that does not decode to such an instance.
