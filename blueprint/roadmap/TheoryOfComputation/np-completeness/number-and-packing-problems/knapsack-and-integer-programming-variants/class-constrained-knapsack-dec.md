# CLASS-CONSTRAINED KNAPSACK as a decision problem

The decision problem CLASS-CONSTRAINED KNAPSACK accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples (two lists and a natural number), to an instance that is [well-formed](well-formed-2.md) and [feasible](class-constrained-knapsack-feasible.md) for CLASS-CONSTRAINED KNAPSACK. It rejects every bitstring that does not decode to such an instance.
