# Instances of PACKING INTEGER PROGRAMMING

An instance is a quadruple of the rows of a matrix $A$ (each a list of rationals), a vector $b$ (one rational per row), a vector $c$, and a bound $K$; a rational is a pair $(p, q)$ for $p/q$, read as $0$ when $q = 0$ (well-formedness rejects zero denominators).
