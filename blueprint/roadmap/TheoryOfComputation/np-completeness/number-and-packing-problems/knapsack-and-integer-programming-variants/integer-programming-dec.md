# INTEGER PROGRAMMING as a decision problem

The decision problem INTEGER PROGRAMMING accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quadruples (a dimension, a constraint list, an objective tuple and a bound), to an instance that is [well-formed](well-formed-8.md) and [feasible](integer-programming-feasible.md) for INTEGER PROGRAMMING. It rejects every bitstring that does not decode to such an instance.
