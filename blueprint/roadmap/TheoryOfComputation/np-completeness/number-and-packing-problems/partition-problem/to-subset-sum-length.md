# PARTITION membership instance has linear bitlength

For every list $(a_1, \dots, a_n)$ of natural numbers, the encoding of the SUBSET-SUM instance
with numbers $2a_1, \dots, 2a_n$ and target $a_1 + \dots + a_n$ has length at most $5\ell + 1$,
where $\ell$ is the length of the canonical encoding of the list $(a_1, \dots, a_n)$.
