# Stacks of the raw-input PARTITION membership machine

The raw-input membership machine has a copy of each stack of the
[list normalizer](../../cook-levin/conversions-between-bit-string-encodings/a-finite-list-nat-canonicalizer/README.md), a copy of each
[stack of the membership transducer](k-5.md), kept apart, and a buffer stack of bits.
