# Control labels of the raw-input PARTITION membership machine

The labels of the raw-input membership machine are a copy of each label of the
[list normalizer](../../cook-levin/conversions-between-bit-string-encodings/a-finite-list-nat-canonicalizer/README.md), $\mathsf{move1}$ and $\mathsf{move2}$ (transfer the
normalized input), $\mathsf{start}$, a copy of each
[label of the membership transducer](lab-5.md), then $\mathsf{bad}$ and $\mathsf{done}$.
