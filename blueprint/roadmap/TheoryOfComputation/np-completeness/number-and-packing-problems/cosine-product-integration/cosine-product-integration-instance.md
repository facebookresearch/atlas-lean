# Instances of COSINE PRODUCT INTEGRATION

An instance of COSINE PRODUCT INTEGRATION is a list $(a_1, \dots, a_n)$ of integers, each given as any two naturals $(p, q)$ representing $p - q$; the code is not canonical (both $(2, 1)$ and $(1, 0)$ represent $1$), and no condition requires either component to be zero.
