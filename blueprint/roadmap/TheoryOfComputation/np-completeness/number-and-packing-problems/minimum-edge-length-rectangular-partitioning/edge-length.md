# Edge Length

The edge length of the partition `rs` of `P`: the number of occurrences in the list `P` of a cell whose right neighbor is in `P` with no rectangle of `rs` containing both, plus the same count for upper neighbors. A cell listed twice counts twice. For a duplicate-free `P`, as [well-formedness](well-formed.md) requires, this is the number of unit segments between neighboring cells of the figure that no rectangle contains together.
