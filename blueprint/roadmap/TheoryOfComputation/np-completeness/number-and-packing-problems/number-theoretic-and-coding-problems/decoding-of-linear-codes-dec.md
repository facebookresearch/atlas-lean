# DECODING OF LINEAR CODES as a decision problem

The decision problem DECODING OF LINEAR CODES accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(A, y, K)$ of the rows of a binary matrix, a binary vector and a bound, to an instance that is [well-formed](well-formed-3.md) and [feasible](decoding-of-linear-codes-feasible.md) for DECODING OF LINEAR CODES. It rejects every bitstring that does not decode to such an instance.
