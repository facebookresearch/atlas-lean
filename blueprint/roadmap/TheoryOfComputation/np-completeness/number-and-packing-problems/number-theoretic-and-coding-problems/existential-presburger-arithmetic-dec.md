# EXISTENTIAL PRESBURGER ARITHMETIC as a decision problem

The decision problem EXISTENTIAL PRESBURGER ARITHMETIC accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples of a variable count, an atom list and a token list, to an instance that is well-formed and feasible for EXISTENTIAL PRESBURGER ARITHMETIC. It rejects every bitstring that does not decode to such an instance.
