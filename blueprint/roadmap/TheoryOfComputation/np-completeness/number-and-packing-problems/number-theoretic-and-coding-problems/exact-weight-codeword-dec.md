# EXACT-WEIGHT CODEWORD as a decision problem

The decision problem EXACT-WEIGHT CODEWORD accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(A, y, K)$ of the rows of a binary matrix, a binary vector and a bound, to an instance that is [well-formed](well-formed-4.md) and [feasible](exact-weight-codeword-feasible.md) for EXACT-WEIGHT CODEWORD. It rejects every bitstring that does not decode to such an instance.
