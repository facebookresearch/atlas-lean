# Variables of a polynomial ring

The variable $x_j$ in the polynomial ring $(\mathbb{Z}/q\mathbb{Z})[x_0, \dots, x_{n-1}]$ over the integers modulo $q$ (the integers themselves for $q = 0$), and $0$ for $j \ge n$. For a prime $q$, the case [well-formedness](well-formed-17.md) requires, this is $\mathrm{GF}(q)[x_0, \dots, x_{n-1}]$; for other $q$ the coefficient ring is not a field, e.g. $2 \cdot 2 = 0$ modulo $4$.
