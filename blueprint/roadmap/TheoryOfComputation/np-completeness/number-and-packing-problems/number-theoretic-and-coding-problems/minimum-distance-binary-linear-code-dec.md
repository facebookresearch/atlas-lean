# MINIMUM DISTANCE OF A BINARY LINEAR CODE as a decision problem

The decision problem MINIMUM DISTANCE OF A BINARY LINEAR CODE accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(A, y, K)$ of the rows of a binary matrix, a binary vector and a bound, to an instance that is [well-formed](well-formed-4.md) and [feasible](minimum-distance-binary-linear-code-feas.md) for MINIMUM DISTANCE OF A BINARY LINEAR CODE. It rejects every bitstring that does not decode to such an instance.
