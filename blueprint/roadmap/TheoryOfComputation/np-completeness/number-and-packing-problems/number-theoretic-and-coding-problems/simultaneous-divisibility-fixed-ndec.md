# SIMULTANEOUS DIVISIBILITY OF LINEAR POLYNOMIALS as a decision problem

Fix a natural number $n$. The decision problem SIMULTANEOUS DIVISIBILITY OF LINEAR POLYNOMIALS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a variable count and a list of coefficient-vector pairs, to an instance that is well-formed for $n$ and feasible for SIMULTANEOUS DIVISIBILITY OF LINEAR POLYNOMIALS WITH n DIVISIBILITIES. It rejects every bitstring that does not decode to such an instance.
