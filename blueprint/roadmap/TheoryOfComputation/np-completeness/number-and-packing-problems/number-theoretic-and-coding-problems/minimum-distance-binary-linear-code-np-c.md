# MINIMUM DISTANCE OF A BINARY LINEAR CODE is NP-complete

The decision problem MINIMUM DISTANCE OF A BINARY LINEAR CODE belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [MS7] DECODING OF LINEAR CODES, comment (the case `y = 0` with a nonzero codeword, listed there as open).
- A. Vardy, "The intractability of computing the minimum distance of a code", IEEE Transactions on Information Theory 43 (1997), 1757-1766, doi:10.1109/18.641542.
