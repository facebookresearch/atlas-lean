# QUADRATIC PROGRAMMING as a decision problem

The decision problem QUADRATIC PROGRAMMING accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quintuples (a dimension, constraints, two tuples and a bound, in rational codes), to an instance that is [well-formed](well-formed-8.md) and [feasible](quadratic-programming-feasible.md) for QUADRATIC PROGRAMMING. It rejects every bitstring that does not decode to such an instance.
