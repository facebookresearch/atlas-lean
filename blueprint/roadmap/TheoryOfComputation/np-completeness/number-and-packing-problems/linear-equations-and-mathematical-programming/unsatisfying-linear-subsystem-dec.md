# UNSATISFYING LINEAR SUBSYSTEM as a decision problem

The decision problem UNSATISFYING LINEAR SUBSYSTEM accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(m, X, K)$ of a dimension, a list of encoded equations and a bound, to an instance that is [well-formed](well-formed-9.md) and [feasible](unsatisfying-linear-subsystem-feasible.md) for UNSATISFYING LINEAR SUBSYSTEM. It rejects every bitstring that does not decode to such an instance.
