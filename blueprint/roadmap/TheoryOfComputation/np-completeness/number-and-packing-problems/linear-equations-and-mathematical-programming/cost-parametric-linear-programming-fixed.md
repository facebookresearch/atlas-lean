# COST-PARAMETRIC LINEAR PROGRAMMING as a decision problem

Fix a rational number $q$. The decision problem COST-PARAMETRIC LINEAR PROGRAMMING accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quadruples (a dimension, a constraint list, a coordinate list and a rational bound), to an instance that is well-formed for bound $q$ and feasible for COST-PARAMETRIC LINEAR PROGRAMMING. It rejects every bitstring that does not decode to such an instance.
