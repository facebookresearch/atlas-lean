# LINEAR COMPLEMENTARITY as a decision problem

The decision problem LINEAR COMPLEMENTARITY accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples (a dimension, a matrix and a vector of encoded integers), to an instance that is [well-formed](well-formed-4.md) and [feasible](linear-complementarity-feasible.md) for LINEAR COMPLEMENTARITY. It rejects every bitstring that does not decode to such an instance.
