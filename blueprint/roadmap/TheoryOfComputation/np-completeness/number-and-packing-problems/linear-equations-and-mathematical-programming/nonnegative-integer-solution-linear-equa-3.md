# NON-NEGATIVE INTEGER SOLUTION OF LINEAR EQUATIONS as a decision problem

The decision problem NON-NEGATIVE INTEGER SOLUTION OF LINEAR EQUATIONS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a dimension and a list of encoded equations, to an instance that is [well-formed](well-formed-7.md) and [feasible](nonnegative-integer-solution-linear-equa-2.md) for NON-NEGATIVE INTEGER SOLUTION OF LINEAR EQUATIONS. It rejects every bitstring that does not decode to such an instance.
