# QUADRATIC PROGRAMMING is NP-complete

The decision problem QUADRATIC PROGRAMMING belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [MP2] QUADRATIC PROGRAMMING.
- S. Sahni, "Computationally related problems", SIAM Journal on Computing 3 (1974), 262-279, doi:10.1137/0203021 (NP-hardness).
- S. A. Vavasis, "Quadratic programming is in NP", Information Processing Letters 36 (1990), 73-77, doi:10.1016/0020-0190(90)90100-C (membership in NP).
