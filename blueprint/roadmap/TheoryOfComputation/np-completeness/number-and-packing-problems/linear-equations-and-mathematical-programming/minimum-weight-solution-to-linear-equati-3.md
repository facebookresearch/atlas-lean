# MINIMUM WEIGHT SOLUTION TO LINEAR EQUATIONS as a decision problem

The decision problem MINIMUM WEIGHT SOLUTION TO LINEAR EQUATIONS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(m, X, K)$ of a dimension, a list of encoded equations and a bound, to an instance that is [well-formed](well-formed-6.md) and [feasible](minimum-weight-solution-to-linear-equati-2.md) for MINIMUM WEIGHT SOLUTION TO LINEAR EQUATIONS. It rejects every bitstring that does not decode to such an instance.
