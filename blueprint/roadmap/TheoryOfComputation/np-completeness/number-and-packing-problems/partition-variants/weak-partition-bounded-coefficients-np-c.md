# WEAK PARTITION WITH BOUNDED COEFFICIENTS is NP-complete

For every natural number $K \ge 1$, the decision problem WEAK PARTITION WITH BOUNDED COEFFICIENTS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
