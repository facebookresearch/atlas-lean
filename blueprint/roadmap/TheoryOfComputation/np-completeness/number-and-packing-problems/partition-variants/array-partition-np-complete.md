# ARRAY PARTITION is NP-complete

The decision problem ARRAY PARTITION belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. Grigni and F. Manne, "On the complexity of the generalized block distribution", in *Parallel Algorithms for Irregularly Structured Problems (IRREGULAR '96)*, Lecture Notes in Computer Science 1117, Springer (1996), 319-326, doi:10.1007/BFb0030123, Theorem 2 ("GBD is NP-Complete"; the reduction from BALANCED COMPLETE BIPARTITE SUBGRAPH builds a square zero-one array with `p = q` and `K = 1`, and the conclusion notes that GBD "remains NP-complete for any derived cost function such as the sum of the elements in a block").
- P. Crescenzi and V. Kann, *A compendium of NP optimization problems* (2000), problem MINIMUM ARRAY PARTITION.
