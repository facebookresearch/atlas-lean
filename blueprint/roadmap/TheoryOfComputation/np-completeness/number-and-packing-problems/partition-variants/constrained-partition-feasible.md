# Feasible instances of CONSTRAINED PARTITION

An instance is feasible when some set $A'$ of positions of $A$ has the same total size as the remaining positions $A \setminus A'$ and at least $K$ distinct elements $a$ of $S$ lie on the same side as $a_0$, that is, $a \in A'$ exactly when $a_0 \in A'$. An element of $S$, or $a_0$, that is not a position of $A$ is never in $A'$.
