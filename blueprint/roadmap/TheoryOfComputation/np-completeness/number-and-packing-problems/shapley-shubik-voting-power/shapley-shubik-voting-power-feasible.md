# Feasible instances of SHAPLEY-SHUBIK VOTING POWER

An instance of SHAPLEY-SHUBIK VOTING POWER with vote list $(w_0, \dots, w_{n-1})$ and quota $q$ is feasible when some ordering $\pi$ of the voters $0, \dots, n - 1$ (a list that is a permutation of them) has voter $0$, the voter $v_1$, at some position $j$, counted from $0$, such that the votes of the first $j$ voters of $\pi$ total less than $q$ and the votes of the first $j + 1$ voters total at least $q$. The position $j$ must hold voter $0$: a position beyond the end of $\pi$ holds no voter, so an instance with no voters is not feasible. A voter's votes are read from the vote list by voter number, with $0$ for a number beyond its end; every voter in an ordering has a number below $n$, so this default is never used. Feasibility does not include well-formedness; the decision problem requires both.
