# Product of a generator word

For generator indices $w = [i_1, \dots, i_j]$, the value $g_{i_1}(g_{i_2}(\cdots g_{i_j}(x)))$, where $g_i(y)$ is entry $y$ of the list of $g_i$, read as $y$ when that list has no such entry; an index with no listed generator reads the empty list, which fixes every point.
