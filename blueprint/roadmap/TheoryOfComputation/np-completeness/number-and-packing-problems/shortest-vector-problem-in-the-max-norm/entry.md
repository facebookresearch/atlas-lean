# Integer entry of a stored row in SHORTEST VECTOR PROBLEM IN THE MAX NORM

For an instance $i$ of SHORTEST VECTOR PROBLEM IN THE MAX NORM and natural numbers $a$ and $j$, the entry $\mathrm{entry}(i, a, j)$ is the integer $p - q$, where $(p, q)$ is the pair at position $j$ of the stored row at position $a$, both positions counted from $0$. A row position beyond the stored rows reads as an empty row, and a coordinate position beyond the end of its row reads as the pair $(0, 0)$; either way the entry is $0$.
