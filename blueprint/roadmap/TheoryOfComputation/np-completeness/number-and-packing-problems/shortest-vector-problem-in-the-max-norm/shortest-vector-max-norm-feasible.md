# Feasible instances of SHORTEST VECTOR PROBLEM IN THE MAX NORM

An instance of SHORTEST VECTOR PROBLEM IN THE MAX NORM is feasible when some nonzero integer coefficient vector `x` gives a lattice vector `v = x₁v₁ + ⋯ + x_kv_k` with every coordinate of absolute value at most `K`. Feasibility does not include well-formedness; the decision problem requires both.
