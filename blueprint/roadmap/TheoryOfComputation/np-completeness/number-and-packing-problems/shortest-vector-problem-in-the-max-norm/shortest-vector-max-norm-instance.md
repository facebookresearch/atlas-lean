# Instances of SHORTEST VECTOR PROBLEM IN THE MAX NORM

An instance of SHORTEST VECTOR PROBLEM IN THE MAX NORM is a pair of a list of stored rows, each a list of pairs of natural numbers, and a natural number bound $K$. Each pair is any two naturals $(p, q)$ representing the integer $p - q$; the code is not canonical (both $(2, 1)$ and $(1, 0)$ represent $1$), and no condition requires either component to be zero. In a [well-formed](well-formed.md) instance the $k$ stored rows are the basis vectors $v_1, \dots, v_k$, each with $k$ coordinates.
