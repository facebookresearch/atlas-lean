# Feasible MAXIMUM-LIKELIHOOD DECODING OF REED-SOLOMON CODES instances

An instance is feasible when the defining polynomial $f$ is irreducible over $\mathbb{F}_2$ and, over the field $\mathbb{F}_2[X]/(f)$, some codeword $c$ of the [Reed-Solomon code](../../../../InformationTheory/error-correcting-codes/reed-solomon-codes/code.md) with the listed evaluation points and degree bound $k$, that is, the vector of values at the points of a polynomial of degree less than $k$, is within Hamming distance $w$ of the target vector $y$. This test does not require distinct points or $k \le n$: over the field defined by $f = X$, with two evaluation points both $0$, $k = 2$ and target $(0, 0)$, the zero polynomial is a witness, though every codeword has the form $(a, a)$ and the code has dimension $1$. Under [well-formedness](well-formed.md) (distinct points, $0 < k \le n$) the code has dimension $k$.
