# Feasible MAXIMUM-LIKELIHOOD DECODING OF REED-SOLOMON CODES instances

An instance is feasible when the defining polynomial $f$ is irreducible over $\mathbb{F}_2$ and,
over the field $\mathbb{F}_2[X]/(f)$, some codeword $c$ of the Reed-Solomon code with the listed
evaluation points and dimension $k$ is within Hamming distance $w$ of the target vector $y$.
