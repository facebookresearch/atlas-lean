# Well-formed MAXIMUM-LIKELIHOOD DECODING OF REED-SOLOMON CODES instances

Well-formedness of an instance: `f` has degree `m ≥ 1` with leading bit `1` and is irreducible;
the points are `m`-bit vectors, pairwise distinct; the target has one `m`-bit vector per point;
`0 < k ≤ n` (the code has length `n` and dimension `k`); and `w > 0`.
