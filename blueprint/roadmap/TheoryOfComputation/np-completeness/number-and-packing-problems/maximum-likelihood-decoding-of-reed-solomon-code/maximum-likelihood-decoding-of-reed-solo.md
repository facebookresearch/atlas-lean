# Instances of MAXIMUM-LIKELIHOOD DECODING OF REED-SOLOMON CODES

An instance: the bits $f_0, \dots, f_m$ of the defining polynomial $f$, the points $x_1, \dots, x_n$ of $D$ and the target $y_1, \dots, y_n$ as $m$-bit vectors, the degree bound $k$, and the bound $w$. The code has dimension $k$ only when the points are distinct and $k \le n$, as [well-formedness](well-formed.md) requires.
