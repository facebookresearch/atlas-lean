# Game

The game of an EQUILIBRIUM POINT instance has players $0, \dots, n-1$; the strategies of player $i$ are the elements of the range-set $M_i$, and the payoff of player $i$ at a strategy profile is the value of the polynomial $F_i$ at that profile. A strategic game needs every strategy set nonempty, so the game is defined only when every $M_i$ is nonempty.
