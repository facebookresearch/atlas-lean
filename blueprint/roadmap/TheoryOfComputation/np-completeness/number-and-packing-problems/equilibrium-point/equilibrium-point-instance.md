# Instances of EQUILIBRIUM POINT

An instance of EQUILIBRIUM POINT consists of a natural number $n$ (of variables and players), a list of payoff descriptions, each a product polynomial given as a list of factors, and a list of range lists, each a list of natural pairs $(a, b)$ encoding the integer $a - b$. The two lists have independent lengths: $n = 1$ with both lists empty is an instance. That each list has exactly $n$ entries is required only by [the well-formed interpretation](well-formed.md).
