# Instances of SPARSE APPROXIMATION

An instance of SPARSE APPROXIMATION is a tuple $(n, A, b, \varepsilon, k)$ of a natural number $n$ of columns, a list $A$ of stored rows, each a list of rational codes, a list $b$ of rational codes, a rational code $\varepsilon$, and a natural number $k$. A rational code is a triple of naturals $((p, q), d)$, read as $(p - q)/d$ when $d > 0$ and as $0$ when $d = 0$; it is not canonical, since many codes give the same number.
