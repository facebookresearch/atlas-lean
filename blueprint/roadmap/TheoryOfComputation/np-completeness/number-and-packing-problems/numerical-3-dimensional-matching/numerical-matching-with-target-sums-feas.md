# Feasible instances of NUMERICAL MATCHING WITH TARGET SUMS

In NUMERICAL MATCHING WITH TARGET SUMS: some permutations `σ`, `τ` of `Fin m` give sets `A_k = {x_{σ k}, y_{τ k}}` with `s(x_{σ k}) + s(y_{τ k}) = B_k` for every `k`. A list entry that is not present (an index beyond the end of its list) reads as $0$.
