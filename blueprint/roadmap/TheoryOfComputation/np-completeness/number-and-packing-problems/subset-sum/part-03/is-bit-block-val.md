# Value symbols form a bit block

For every list $l$ of bits, the list of value symbols $\mathrm{val}(b)$, one for each bit $b$ of
$l$ in order, is the bit block $l$ under the reading of value symbols as bits: reading
$\mathrm{val}(b)$ as $b$ turns it into $l$, and none of its symbols is unreadable.
