# EQUILIBRIUM POINT with binary range-sets as a decision problem

The decision problem EQUILIBRIUM POINT with binary range-sets accepts a bitstring $x$ exactly
when $x$ decodes, under the canonical bitstring encoding of its instances, to an instance that
is [well-formed](well-formed.md) and
[feasible](../equilibrium-point/equilibrium-point-feasible.md). It rejects every bitstring that
does not decode to an instance.
