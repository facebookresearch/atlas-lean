# Instances of CLOSEST VECTOR PROBLEM

An instance of the CLOSEST VECTOR PROBLEM is a triple $(V, b, K)$ of a list $V$ of basis vectors $v_1, \dots, v_k$ (each a list of integer coordinates), a target vector $b$ and a bound $K$; every integer is given as any two naturals $(p, q)$ representing $p - q$; the code is not canonical (both $(2, 1)$ and $(1, 0)$ represent $1$), and no condition requires either component to be zero.
