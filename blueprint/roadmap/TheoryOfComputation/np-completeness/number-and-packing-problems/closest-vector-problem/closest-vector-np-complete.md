# CLOSEST VECTOR PROBLEM is NP-complete

The CLOSEST VECTOR PROBLEM decision problem belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- P. van Emde Boas, "Another NP-complete partition problem and the complexity of computing short vectors in a lattice", Report 81-04, Mathematisch Instituut, University of Amsterdam (1981), p. 2, problem NEAREST VECTOR and Theorem 2.
- D. Micciancio, "The shortest vector in a lattice is hard to approximate to within some constant", SIAM J. Comput. 30 (2001), 2008-2035, doi:10.1137/S0097539700373039, Sections 1-2 (the closest vector problem "was proved NP-hard to solve exactly by van Emde Boas", who calls it "Nearest Vector").
