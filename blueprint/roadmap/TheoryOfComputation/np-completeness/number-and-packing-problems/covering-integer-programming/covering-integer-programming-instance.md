# Instances of COVERING INTEGER PROGRAMMING

An instance of COVERING INTEGER PROGRAMMING is a tuple $(n, C, c, K)$ of a number $n$ of variables, a list $C$ of constraint rows $(A_i, b_i)$ for the constraints $A_i \cdot x \ge b_i$, a cost vector $c$, and a bound $K$; every rational is given as a pair (numerator, denominator).
