# NP-completeness

The Cook–Levin theorem and NP-completeness of specific decision problems, by the problem's domain; includes both machine-level Karp reductions and stated NP-completeness results.

Karp's 21 complete problems ("Reducibility among combinatorial problems", 1972, Main Theorem) correspond to the following topics: 1. [SATISFIABILITY](cook-levin/README.md), 2. [0-1 INTEGER PROGRAMMING](number-and-packing-problems/0-1-integer-programming/README.md), 3. [CLIQUE](graph-covering-and-domination/clique-independent-set-and-vertex-cover/README.md), 4. [SET PACKING](set-systems-and-location/set-packing/README.md), 5. [NODE COVER](graph-covering-and-domination/clique-independent-set-and-vertex-cover/README.md), 6. [SET COVERING](set-systems-and-location/set-cover/README.md), 7. FEEDBACK NODE SET (no topic; compare the [undirected feedback vertex set](graph-covering-and-domination/feedback-vertex-set/README.md) problem), 8. [FEEDBACK ARC SET](graph-covering-and-domination/feedback-arc-set/README.md), 9. [DIRECTED HAMILTON CIRCUIT](paths-cycles-and-subgraphs/directed-hamiltonian-cycle/README.md), 10. [UNDIRECTED HAMILTON CIRCUIT](paths-cycles-and-subgraphs/undirected-hamiltonian-cycle/README.md), 11. [SATISFIABILITY WITH AT MOST 3 LITERALS PER CLAUSE](satisfiability/3-satisfiability/README.md), 12. [CHROMATIC NUMBER](graph-coloring-and-partitioning/graph-coloring/README.md), 13. [CLIQUE COVER](graph-coloring-and-partitioning/clique-cover/README.md), 14. [EXACT COVER](set-systems-and-location/exact-cover/README.md), 15. [HITTING SET](set-systems-and-location/exact-hitting-set/README.md), 16. [STEINER TREE](paths-cycles-and-subgraphs/steiner-tree/README.md), 17. [3-DIMENSIONAL MATCHING](set-systems-and-location/3-dimensional-matching/README.md), 18. [KNAPSACK](number-and-packing-problems/subset-sum/README.md), 19. [JOB SEQUENCING](scheduling/weighted-number-of-tardy-jobs/README.md), 20. [PARTITION](number-and-packing-problems/partition-problem/README.md), 21. [MAX CUT](graph-coloring-and-partitioning/maximum-cut/README.md). His KNAPSACK asks for a 0-1 solution of $\sum_j a_j x_j = b$, which is SUBSET-SUM; his JOB SEQUENCING bounds the total penalty of late jobs, which is the weighted number of tardy jobs; his HITTING SET is the exact version. Several topics state a variant of Karp's formulation: 0-1 INTEGER PROGRAMMING with inequalities $Ax \le b$ instead of equations $Cx = d$, MAX CUT without edge weights (a special case of Karp's weighted problem), and NODE COVER asking for a cover of exactly $k$ vertices instead of at most $\ell$. KNAPSACK, PARTITION, JOB SEQUENCING and STEINER TREE are stated with natural-number data, special cases of Karp's integer data. Karp's FEEDBACK NODE SET (problem 7) asks for a set of nodes meeting every directed cycle of a digraph, while the linked feedback vertex set problem is about undirected graphs; it is NP-complete too, but it is a different problem, not Karp's.
