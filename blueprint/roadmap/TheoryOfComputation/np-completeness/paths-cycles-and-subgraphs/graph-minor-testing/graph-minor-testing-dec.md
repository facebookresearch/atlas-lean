# GRAPH MINOR TESTING as a decision problem

The decision problem GRAPH MINOR TESTING accepts a bitstring $x$ exactly when $x$ decodes, under
the canonical bitstring encoding of GRAPH MINOR TESTING instances, to an instance that is
[well-formed](../../graph-coloring-and-partitioning/graph-homomorphism/well-formed.md) and [feasible](graph-minor-testing-feasible.md). It rejects every
bitstring that does not decode to an instance.
