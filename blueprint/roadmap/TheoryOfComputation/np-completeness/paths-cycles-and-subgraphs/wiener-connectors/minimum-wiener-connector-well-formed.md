# Well-formed instances of MINIMUM WIENER CONNECTOR

An instance $(n, E, Q, K)$ of MINIMUM WIENER CONNECTOR is well-formed when the edge list has no repeated edges (in either orientation) and no loops, and every endpoint is below $n$, so that it describes a simple graph on $\{0, \dots, n - 1\}$, this graph is connected, $Q$ is a list of distinct vertices below $n$, and $K > 0$.
