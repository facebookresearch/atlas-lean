# BOUNDED COMPONENT SPANNING FOREST with unit weights is NP-complete for every fixed $B \ge 3$

For every natural number $B \ge 3$, the BOUNDED COMPONENT SPANNING FOREST with unit weights decision problem with weight bound $B$ belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources
