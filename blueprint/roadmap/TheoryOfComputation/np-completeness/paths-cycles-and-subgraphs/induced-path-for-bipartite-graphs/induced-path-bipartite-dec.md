# INDUCED PATH for bipartite graphs as a decision problem

The decision problem INDUCED PATH for bipartite graphs accepts a bitstring $x$ exactly when $x$
decodes, under the canonical bitstring encoding of its instances, to an instance that is
[well-formed](well-formed.md) and [feasible](../induced-path/induced-path-feasible.md). It
rejects every bitstring that does not decode to an instance.
