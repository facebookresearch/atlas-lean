# Instances of COMMUTATIVE CODE GENERATION WITH UNLIMITED REGISTERS

An instance of COMMUTATIVE CODE GENERATION WITH UNLIMITED REGISTERS has the format of CODE GENERATION WITH UNLIMITED REGISTERS: a triple $(n, A, K)$ of a number $n$ of vertices, a list $A$ of arcs $(v, u, b)$ ($b$ true for an arc of $L$, false for an arc of $R$) and a bound $K$.
