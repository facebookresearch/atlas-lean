# Feasible EVEN ALTERNATING PATH (2-arc-colored digraphs) instances

An EVEN ALTERNATING PATH (2-arc-colored digraphs) instance is feasible when some simple directed path from $s$ to $t$ has an even number of arcs and alternating colors: a list of distinct vertices $p_0 = s, p_1, \dots, p_\ell = t$ with an arc from each $p_j$ to $p_{j+1}$, $\ell$ even, and any two consecutive arcs $(p_j, p_{j+1})$ and $(p_{j+1}, p_{j+2})$ of different colors.
