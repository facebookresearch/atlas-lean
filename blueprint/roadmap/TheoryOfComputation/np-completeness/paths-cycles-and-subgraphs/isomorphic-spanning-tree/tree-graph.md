# Tree Graph

The tree $T$ of an ISOMORPHIC SPANNING TREE instance $(n, E_G, m, E_T)$: the simple graph on the
vertices $0, \dots, m - 1$ in which two distinct vertices $u$ and $v$ are adjacent exactly when
$E_T$ contains the pair $(u, v)$ or the pair $(v, u)$. Loops add no edge, and a pair with an
endpoint at least $m$ contributes nothing. It is the [graph of an edge list](../../graph-coloring-and-partitioning/graph-3-coloring/part-01/edge-graph.md) on these vertices and pairs.
