# Graph

The graph of an instance of ISOMORPHIC SPANNING TREE: the simple graph on the vertices
$0, \dots, n - 1$, where $n$ is the vertex count of the instance, in which two distinct vertices
$u$ and $v$ are adjacent exactly when the edge list $E$ of the instance contains the pair
$(u, v)$ or the pair $(v, u)$. Loops $(u, u)$ add no edge, and an entry with an endpoint outside
$0, \dots, n - 1$ contributes nothing. It is the [graph of an edge list](../../graph-coloring-and-partitioning/graph-3-coloring/part-01/edge-graph.md) on these vertices and pairs.
