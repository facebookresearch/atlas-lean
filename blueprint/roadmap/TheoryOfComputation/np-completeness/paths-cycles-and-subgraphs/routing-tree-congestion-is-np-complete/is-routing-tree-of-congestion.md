# Is Routing Tree Of Congestion

In ROUTING TREE CONGESTION: `(T, τ)` is a routing tree for the graph on `0, …, n - 1` with weighted edges `es`, of congestion at most `K`: a binary phylogenetic tree with taxa `τ v` (a tree whose degree-one vertices are exactly the `τ v`, every other vertex of degree three), with at most `K` weight routed along every edge of `T`.
