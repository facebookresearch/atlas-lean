# Well-formed HAMILTONIAN CIRCUIT on strongly chordal split graphs instances

A HAMILTONIAN CIRCUIT on strongly chordal split graphs instance is well-formed when it is a well-formed instance of HAMILTONIAN CIRCUIT on split graphs and its graph is strongly chordal.

The same test is the well-formedness condition of HAMILTONIAN PATH on strongly chordal split graphs: both add the split-graph and strong-chordality tests to the base test.
