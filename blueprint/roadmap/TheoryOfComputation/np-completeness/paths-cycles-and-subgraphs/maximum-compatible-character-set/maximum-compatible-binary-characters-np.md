# MAXIMUM COMPATIBLE CHARACTER SET for binary characters is NP-complete

The decision problem MAXIMUM COMPATIBLE CHARACTER SET for binary characters is NP-complete: it
belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

Day and Sankoff state the problem for a positive threshold; the language here also accepts
$K = 0$ on well-formed input, by selecting no characters, which does not change its complexity.

Source: Day and Sankoff (1986); Estabrook, Johnson and McMorris (1976).
