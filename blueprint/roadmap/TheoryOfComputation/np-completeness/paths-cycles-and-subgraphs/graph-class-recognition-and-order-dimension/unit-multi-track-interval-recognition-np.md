# UNIT d-TRACK INTERVAL GRAPH RECOGNITION is NP-complete

For every natural number $d \ge 2$, the decision problem UNIT d-TRACK INTERVAL GRAPH RECOGNITION belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
