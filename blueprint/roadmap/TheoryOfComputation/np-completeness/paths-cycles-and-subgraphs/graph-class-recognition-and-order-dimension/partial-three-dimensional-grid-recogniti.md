# PARTIAL 3D GRID GRAPH RECOGNITION as a decision problem

The decision problem PARTIAL 3D GRID GRAPH RECOGNITION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs $(n, E)$ of a vertex count and an edge list, to an instance that is well-formed for PARTIAL GRID RECOGNITION (a simple edge list) and feasible for PARTIAL 3D GRID GRAPH RECOGNITION. It rejects every bitstring that does not decode to such an instance.
