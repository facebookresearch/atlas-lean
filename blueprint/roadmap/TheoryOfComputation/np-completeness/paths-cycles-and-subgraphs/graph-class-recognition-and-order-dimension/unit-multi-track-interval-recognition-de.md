# UNIT d-TRACK INTERVAL GRAPH RECOGNITION as a decision problem

Fix a natural number $d$. The decision problem UNIT d-TRACK INTERVAL GRAPH RECOGNITION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of TRACK INTERVAL GRAPH RECOGNITION instances, to an instance that is well-formed for TRACK INTERVAL GRAPH RECOGNITION and feasible for $d$. It rejects every bitstring that does not decode to such an instance.
