# PARTIAL ORDER DIMENSION OF HEIGHT-ONE ORDERS FOR FIXED K as a decision problem

Fix a natural number $K$. The decision problem accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of Boolean matrices, to a matrix $M$ that is well-formed for $K$ and with $(M, K)$ feasible for PARTIAL ORDER DIMENSION. It rejects every bitstring that does not decode to such a matrix.
