# PARTIAL GRID GRAPH RECOGNITION as a decision problem

The decision problem PARTIAL GRID GRAPH RECOGNITION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs $(n, E)$ of a vertex count and an edge list, to an instance that is well-formed for PARTIAL GRID GRAPH RECOGNITION and whose graph is a subgraph of the square grid $\mathbb{Z}^2$. It rejects every bitstring that does not decode to such an instance.
