# B1-EPG RECOGNITION as a decision problem

The decision problem B1-EPG RECOGNITION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs $(n, E)$ of a vertex count and an edge list, to an instance that is well-formed for B_k-VPG RECOGNITION (a simple edge list) and feasible for B1-EPG RECOGNITION. It rejects every bitstring that does not decode to such an instance.
