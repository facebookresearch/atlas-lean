# PARTIAL 3D GRID GRAPH RECOGNITION is NP-complete

The decision problem PARTIAL 3D GRID GRAPH RECOGNITION belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- V. G. P. de Sá, G. D. da Fonseca, R. C. S. Machado and C. M. H. de Figueiredo, "Complexity dichotomy on partial grid recognition", Theoretical Computer Science 412 (2011), 2370-2379, doi:10.1016/j.tcs.2011.01.018 (abstract: "the three-dimensional version of the problem was for the first time proven to be NP-complete").
- ISGCI (https://www.graphclasses.org/classes/gc_850.html), problem "Recognition" on partial 3d grid graphs: NP-complete.
