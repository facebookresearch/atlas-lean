# Well-formed instances of PARTIAL ORDER DIMENSION OF HEIGHT-ONE ORDERS FOR FIXED K

For a natural number $K$, an adjacency matrix $M$ is well-formed when $(M, K)$ is well-formed for PARTIAL ORDER DIMENSION ($M$ is $n \times n$, acyclic and transitive, $0 < K \le n^2$), and the order has height one (no arcs $(u, v)$ and $(v, w)$).
