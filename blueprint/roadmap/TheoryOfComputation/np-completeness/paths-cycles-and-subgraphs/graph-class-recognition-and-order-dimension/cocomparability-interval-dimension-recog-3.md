# COCOMPARABILITY INTERVAL DIMENSION RECOGNITION as a decision problem

Fix a natural number $d$. The decision problem COCOMPARABILITY INTERVAL DIMENSION RECOGNITION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs $(n, E)$ of a vertex count and an edge list, to an instance that is well-formed and feasible for interval dimension bound $d$. It rejects every bitstring that does not decode to such an instance.
