# NESETRIL-RODL DIMENSION as a decision problem

The decision problem NESETRIL-RODL DIMENSION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples (a unary list, an edge list and a bound), to an instance that is well-formed and feasible for NESETRIL-RODL DIMENSION. It rejects every bitstring that does not decode to such an instance.
