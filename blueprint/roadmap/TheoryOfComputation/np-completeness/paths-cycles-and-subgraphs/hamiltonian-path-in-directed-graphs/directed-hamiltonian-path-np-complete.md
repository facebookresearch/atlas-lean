# DIRECTED HAMILTONIAN PATH is NP-complete

The DIRECTED HAMILTONIAN PATH decision problem belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT39] HAMILTONIAN PATH, comment ("Corresponding DIRECTED HAMILTONIAN PATH problem is also NP-complete"), and Section 3.1.4, p. 60 (undirected Hamiltonian problems transformed to their directed counterparts).
