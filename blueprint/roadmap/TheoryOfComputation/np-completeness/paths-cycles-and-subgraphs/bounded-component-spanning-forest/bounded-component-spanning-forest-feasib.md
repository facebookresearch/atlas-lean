# Feasible BOUNDED COMPONENT SPANNING FOREST instances

An instance $(n, E, w, K, B)$ of BOUNDED COMPONENT SPANNING FOREST is feasible when, for some $k \le K$, the vertices can be assigned to parts $0, \dots, k-1$, every part receiving at least one vertex, so that every part induces a connected subgraph of the graph and has total vertex weight at most $B$ (a vertex with no weight entry counts as weight $0$).
