# HAMILTONIAN PATH BETWEEN TWO POINTS as a decision problem

The decision problem HAMILTONIAN PATH BETWEEN TWO POINTS accepts a bitstring $x$ exactly when
$x$ decodes, under the canonical bitstring encoding of HAMILTONIAN PATH BETWEEN TWO POINTS
instances, to an instance that is [well-formed](well-formed.md) and
[feasible](hamiltonian-path-between-two-points-feas.md). It rejects every bitstring that does
not decode to an instance.
