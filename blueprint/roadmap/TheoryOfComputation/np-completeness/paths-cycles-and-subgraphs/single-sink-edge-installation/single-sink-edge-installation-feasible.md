# Feasible instances of SINGLE-SINK EDGE INSTALLATION

An instance of SINGLE-SINK EDGE INSTALLATION is feasible when there are a path from each source to the sink and cable counts `x j c` (cables of type `c` on edge `j`) such that on every edge the summed demand of the sources whose path uses it is at most the installed capacity, and the total cost `∑_j l_j · ∑_c x j c · c_c` is at most `K`. Feasibility does not include well-formedness; the decision problem requires both.
