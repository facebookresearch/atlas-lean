# HAMILTONIAN PATH on k-regular graphs is NP-complete for every fixed `k ≥ 3`

HAMILTONIAN PATH on k-regular graphs is NP-complete for every fixed `k ≥ 3`: the decision problem over bitstrings that accepts exactly the encodings of well-formed instances with a solution (for each admissible value of the fixed parameter) lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
