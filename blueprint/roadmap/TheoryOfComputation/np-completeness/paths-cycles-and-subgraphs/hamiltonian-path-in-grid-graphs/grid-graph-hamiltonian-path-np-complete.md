# HAMILTONIAN PATH IN GRID GRAPHS is NP-complete

The decision problem HAMILTONIAN PATH IN GRID GRAPHS belongs to NP, and every decision problem
in NP has a polynomial-time many-one reduction to it.

## Sources

- A. Itai, C. H. Papadimitriou and J. L. Szwarcfiter, "Hamilton paths in grid graphs", SIAM Journal on Computing 11 (1982), 676-686, doi:10.1137/0211056.
- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT39] HAMILTONIAN PATH (the parent problem).
- ISGCI, *Information System on Graph Classes and their Inclusions*, class `gc_1057` (grid graph), problem Hamiltonian path: NP-complete (Itai, Papadimitriou and Szwarcfiter 1982).
