# Feasible instances of FIXED-POINT-FREE AUTOMORPHISM

An instance of FIXED-POINT-FREE AUTOMORPHISM is feasible when its graph has an automorphism that fixes no vertex: a bijection $f$ of the vertex set such that $u$ and $v$ are adjacent exactly when $f(u)$ and $f(v)$ are adjacent, with $f(v) \ne v$ for every vertex $v$. The instance with no vertices is feasible, since its identity map fixes no vertex.
