# CODE GENERATION WITH ADDRESS EXPRESSIONS is NP-complete

The CODE GENERATION WITH ADDRESS EXPRESSIONS decision problem belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [PO7] CODE GENERATION WITH ADDRESS EXPRESSIONS, pp. 273-274 (reference [Szymanski, 1978]; transformation from 3SAT).
- T. G. Szymanski, "Assembling code for machines with span-dependent instructions", Communications of the ACM 21 (1978), 300-308, doi:10.1145/359460.359474.
