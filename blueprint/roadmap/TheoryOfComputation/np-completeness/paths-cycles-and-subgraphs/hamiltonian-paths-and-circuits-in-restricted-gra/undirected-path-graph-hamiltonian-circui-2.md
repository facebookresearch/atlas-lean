# HAMILTONIAN CIRCUIT IN UNDIRECTED PATH GRAPHS is NP-complete

The HAMILTONIAN CIRCUIT IN UNDIRECTED PATH GRAPHS decision problem lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

Instance: an undirected path graph `G = (V, E)`, that is, the vertex intersection graph of a family of paths in an undirected tree. Question: does `G` have a Hamiltonian circuit, that is, a simple cycle through every vertex?
