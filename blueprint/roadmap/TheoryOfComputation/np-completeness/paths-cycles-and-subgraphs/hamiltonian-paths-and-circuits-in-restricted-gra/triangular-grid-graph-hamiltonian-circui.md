# The HAMILTONIAN CIRCUIT IN TRIANGULAR GRID GRAPHS decision problem

The HAMILTONIAN CIRCUIT IN TRIANGULAR GRID GRAPHS decision problem accepts a bitstring exactly when it decodes, under the canonical bitstring encoding, to an instance that is well formed as an instance of HAMILTONIAN CIRCUIT IN GRID GRAPHS and feasible after conversion by `toHamiltonianInstance`. Bitstrings that do not decode to an instance are rejected.
