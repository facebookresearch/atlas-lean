# Adjacency in the triangular lattice

In HAMILTONIAN CIRCUIT IN TRIANGULAR GRID GRAPHS, adjacency in the triangular lattice in the coordinates `(a, b)` of the point `a • (1, 0) + b • (1/2, √3/2)`: the squared distance `Δa² + Δa Δb + Δb²` is `1`. Subtraction is natural-number subtraction, so `a - b = 0` whenever `a ≤ b`.
