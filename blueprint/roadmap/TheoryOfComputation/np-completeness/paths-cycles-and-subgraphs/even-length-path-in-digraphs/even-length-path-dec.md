# EVEN LENGTH PATH (directed) as a decision problem

The decision problem EVEN LENGTH PATH (directed) accepts a bitstring $x$ exactly when $x$
decodes, under the canonical bitstring encoding of EVEN LENGTH PATH (directed) instances, to an
instance that is [well-formed](well-formed.md) and [feasible](even-length-path-feasible.md). It
rejects every bitstring that does not decode to an instance.
