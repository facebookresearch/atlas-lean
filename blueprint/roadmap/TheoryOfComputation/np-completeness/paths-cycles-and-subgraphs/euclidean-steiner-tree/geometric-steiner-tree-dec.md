# GEOMETRIC STEINER TREE as a decision problem

The decision problem GEOMETRIC STEINER TREE accepts a bitstring $x$ exactly when $x$ decodes,
under the canonical bitstring encoding of GEOMETRIC STEINER TREE instances, to an instance that
is [well-formed](well-formed.md) and [feasible](geometric-steiner-tree-feasible.md). It rejects
every bitstring that does not decode to an instance.
