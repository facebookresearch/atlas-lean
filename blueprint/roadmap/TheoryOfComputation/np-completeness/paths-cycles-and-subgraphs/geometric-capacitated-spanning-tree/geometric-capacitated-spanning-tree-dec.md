# GEOMETRIC CAPACITATED SPANNING TREE as a decision problem

The decision problem GEOMETRIC CAPACITATED SPANNING TREE accepts a bitstring $x$ exactly when
$x$ decodes, under the canonical bitstring encoding of GEOMETRIC CAPACITATED SPANNING TREE
instances, to an instance that is [well-formed](well-formed.md) and
[feasible](geometric-capacitated-spanning-tree-feas.md). It rejects every bitstring that does
not decode to an instance.
