# Instances of GEOMETRIC CAPACITATED SPANNING TREE

An instance of GEOMETRIC CAPACITATED SPANNING TREE consists of a list of encoded points (as in GEOMETRIC TRAVELING SALESMAN, each a pair of natural pairs read as integers), a candidate natural root index $p_0$, an independent list of natural requirements, a natural capacity $c$ and a natural bound $B$. A one-point list need not have one requirement or an in-range root; these belong to [validation](well-formed.md).
