# The graph of an instance of UNIT-LENGTH TREE EMBEDDING IN THE GRID

For an instance `i` of UNIT-LENGTH TREE EMBEDDING IN THE GRID with `n` vertices, the graph of the instance is the simple graph on `Fin n` in which distinct vertices `u` and `v` are adjacent when `(u, v)` or `(v, u)` is the endpoint pair of a listed edge. Loops, and pairs with an endpoint outside `Fin n`, contribute no edge.
