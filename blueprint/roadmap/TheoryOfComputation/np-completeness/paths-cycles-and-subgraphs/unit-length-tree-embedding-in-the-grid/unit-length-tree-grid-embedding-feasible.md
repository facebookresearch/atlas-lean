# Feasible instances of UNIT-LENGTH TREE EMBEDDING IN THE GRID

An instance of UNIT-LENGTH TREE EMBEDDING IN THE GRID is feasible when the tree is a subgraph of the infinite square grid: it is contained in the grid graph on `ℤ²`, whose vertices are adjacent when they differ by `1` in exactly one coordinate. Feasibility does not include well-formedness; the decision problem requires both.
