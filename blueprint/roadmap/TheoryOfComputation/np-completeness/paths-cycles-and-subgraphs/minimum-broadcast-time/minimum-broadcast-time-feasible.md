# Feasible instances of MINIMUM BROADCAST TIME

An instance $(n, E, V_0, K)$ of MINIMUM BROADCAST TIME is feasible when there is a sequence $V_0, E_1, V_1, \dots, E_K, V_K$ in which $V_0$ is the base set, $V_K$ is the whole vertex set, and each $(V_{j-1}, E_j, V_j)$ is a broadcast step: starting from the originators, information reaches every vertex in $K$ rounds in which each informed vertex calls at most one uninformed neighbor.
