# Instances of MINIMUM BROADCAST TIME FOR FIXED K

An instance of MINIMUM BROADCAST TIME FOR FIXED K is a triple $(n, E, V_0)$ of a vertex count $n$, an edge list $E$ on $\{0, \dots, n - 1\}$ and a list $V_0$ of originators: an instance of MINIMUM BROADCAST TIME without the time bound, which is fixed.
