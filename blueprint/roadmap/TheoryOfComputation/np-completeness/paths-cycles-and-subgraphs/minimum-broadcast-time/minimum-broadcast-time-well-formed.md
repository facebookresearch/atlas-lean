# Well-formed instances of MINIMUM BROADCAST TIME

An instance $(n, E, V_0, K)$ of MINIMUM BROADCAST TIME is well-formed when the edge list has no repeated edges (in either orientation) and no loops, and every endpoint is below $n$, so that it describes a simple graph on $\{0, \dots, n - 1\}$, $V_0$ is a list of distinct vertices below $n$, and $K > 0$.
