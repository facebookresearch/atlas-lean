# PATH CONSTRAINED NETWORK FLOW is NP-complete with unit capacities

PATH CONSTRAINED NETWORK FLOW is NP-complete with unit capacities: the decision problem over bitstrings that accepts exactly the bitstrings that decode to a well-formed instance with a solution lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it. Source: Garey and Johnson (1979), [ND34], comment (Prömel, 1978).
