# Well-formed instances of PATH CONSTRAINED NETWORK FLOW

Well-formedness of an instance of PATH CONSTRAINED NETWORK FLOW: the arc records describe a directed graph on `0, ..., n - 1` (endpoints in range, no self-loops, no repeated arcs), every capacity is positive, `s` and `t` are distinct vertices, every member of `P` is a directed path in `G` (its vertices are in `V`, also when it has a single vertex), and `R` is positive.
