# Well-formed instances of PATH CONSTRAINED NETWORK FLOW with unit capacities

Well-formedness of an instance of PATH CONSTRAINED NETWORK FLOW with unit capacities: the parent's (a directed graph on `0, ..., n - 1` with positive capacities, distinct vertices `s` and `t`, every member of `P` a directed path in `G`, `0 < R`) and every capacity is `1`.
