# The HAMILTONIAN CIRCUIT instance of a triangular grid graph

For an instance of HAMILTONIAN CIRCUIT IN TRIANGULAR GRID GRAPHS, a list of $|V|$ lattice points, the HAMILTONIAN CIRCUIT instance $(|V|, E)$ whose vertices are the positions $0, \dots, |V| - 1$ of the list and whose edges $E$ join the positions of adjacent points of the triangular lattice. It is a value of the HAMILTONIAN CIRCUIT instance type, not a type.
