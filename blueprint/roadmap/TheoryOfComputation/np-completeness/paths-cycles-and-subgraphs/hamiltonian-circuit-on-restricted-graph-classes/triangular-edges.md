# Edges of the triangular grid graph in HAMILTONIAN CIRCUIT IN TRIANGULAR GRID GRAPHS

For an instance `i` of HAMILTONIAN CIRCUIT IN TRIANGULAR GRID GRAPHS, the edges of the triangular grid graph: the pairs `(u, v)` with `u < v < |V|` whose sites are adjacent in the triangular lattice. A position beyond the end of a list reads as the default entry `((0, 0), (0, 0))`.
