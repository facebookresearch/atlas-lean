# Well-formed HAMILTONIAN PATH for undirected path graphs instances

A HAMILTONIAN PATH for undirected path graphs instance is well-formed when the parent's (a
simple edge list on the vertices $0, \dots, n-1$, `0 < n`), and the graph is an undirected path graph.

The same test is the well-formedness condition of HAMILTONIAN CIRCUIT for undirected path graphs.
