# Feasible INDUCED SUBGRAPH WITH PROPERTY Π instances

For a fixed graph property $\Phi$, an INDUCED SUBGRAPH WITH PROPERTY Π instance with $n$ vertices and bound $K$ is feasible when some set of at least $K$ vertices induces a subgraph with property $\Phi$: for some $m \ge K$ and some one-to-one map $f$ from $\{0, \dots, m-1\}$ to the vertices, the subgraph induced on the image of $f$, with its vertices numbered by $f$, has $\Phi$.
