# HAMILTONIAN PATH for bipartite graphs as a decision problem

The decision problem HAMILTONIAN PATH for bipartite graphs accepts a bitstring $x$ exactly when
$x$ decodes, under the canonical bitstring encoding of its instances, to an instance that is
[well-formed](../hamiltonian-circuit-on-restricted-graph-classes/well-formed.md) and
[feasible](../undirected-hamiltonian-path/hamiltonian-path-undirected-feasible.md). It rejects
every bitstring that does not decode to an instance.
