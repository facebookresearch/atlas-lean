# Is Rectilinear Path In

A list of points $w$ is a rectilinear path in the set $U$ when every two consecutive points share a coordinate and the segment between them lies in $U$. Only consecutive pairs are tested, so a one-point list $[p]$ is a rectilinear path in every set, including one that does not contain $p$; the feasibility test reads such a terminal as an
isolated vertex of the network graph.
