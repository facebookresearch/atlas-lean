# The decision problem MAXIMUM FIXED-LENGTH DISJOINT PATHS with a fixed path length

For a fixed natural number $K$, MAXIMUM FIXED-LENGTH DISJOINT PATHS with the length fixed to $K$
as a decision problem on bitstrings: a bitstring is accepted exactly when it decodes, under the
canonical bitstring encoding, to an instance that, with the fixed parameter $K$ added, is
well-formed and feasible. A bitstring that does not decode to an instance is rejected.
