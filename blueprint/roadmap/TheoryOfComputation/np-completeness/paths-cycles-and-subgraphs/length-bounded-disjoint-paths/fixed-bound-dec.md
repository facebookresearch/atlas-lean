# The decision problem MAXIMUM LENGTH-BOUNDED DISJOINT PATHS with a fixed length bound

For a fixed natural number $K$, MAXIMUM LENGTH-BOUNDED DISJOINT PATHS with the bound fixed to
$K$ as a decision problem on bitstrings: a bitstring is accepted exactly when it decodes, under
the canonical bitstring encoding, to an instance that, with the fixed parameter $K$ added, is
well-formed and feasible. A bitstring that does not decode to an instance is rejected.
