# Instances of MAXIMUM FIXED-LENGTH DISJOINT PATHS with a fixed path length

An instance of MAXIMUM FIXED-LENGTH DISJOINT PATHS for a fixed path length: a tuple
$(n, E, s, t, J)$ of the vertex count $n$ (the vertices are $0, \dots, n - 1$), the edge list
$E$, the terminals $s$ and $t$, and the number $J$ of required paths; the length $K$ is fixed
separately. The edge-disjoint version uses the same tuples, with the same meaning.
