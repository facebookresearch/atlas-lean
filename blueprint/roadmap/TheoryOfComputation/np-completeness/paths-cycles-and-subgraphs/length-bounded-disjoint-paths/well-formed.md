# Well-formed MAXIMUM FIXED-LENGTH DISJOINT PATHS instances

Well-formedness of an instance: the edge list describes a simple graph on `Fin n` (no duplicate edges in either orientation, no self-loops, endpoints in range), `s` and `t` are distinct vertices, and `0 < J ≤ n` and `0 < K ≤ n`. MAXIMUM LENGTH-BOUNDED DISJOINT PATHS uses the same instances and this same test; exact versus bounded path length enters only in feasibility.
