# Instances of MAXIMUM LENGTH-BOUNDED DISJOINT PATHS with a fixed length bound

An instance of MAXIMUM LENGTH-BOUNDED DISJOINT PATHS for a fixed length bound: a tuple
$(n, E, s, t, J)$ of the vertex count $n$ (the vertices are $0, \dots, n - 1$), the edge list
$E$, the terminals $s$ and $t$, and the number $J$ of required paths; the bound $K$ is fixed
separately. The edge-disjoint version uses the same tuples, with the same meaning.
