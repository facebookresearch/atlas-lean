# HAMILTONIAN CIRCUIT given a Hamiltonian path is NP-complete

The decision problem HAMILTONIAN CIRCUIT given a Hamiltonian path belongs to NP, and every
decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT37] HAMILTONIAN CIRCUIT (comment: NP-complete even if a Hamiltonian path for `G` is given as part of the instance).
- C. H. Papadimitriou and K. Steiglitz, "On the complexity of local search for the traveling salesman problem", SIAM Journal on Computing 6(1) (1977), 76-83, doi:10.1137/0206005.
