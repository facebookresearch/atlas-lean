# HAMILTONIAN CIRCUIT given a Hamiltonian path as a decision problem

The decision problem HAMILTONIAN CIRCUIT given a Hamiltonian path accepts a bitstring $x$
exactly when $x$ decodes, under the canonical bitstring encoding of HAMILTONIAN CIRCUIT given a
Hamiltonian path instances, to an instance that is [well-formed](well-formed.md) and
[feasible](hamiltonian-circuit-given-hamiltonian-pa-2.md). It rejects every bitstring that does
not decode to an instance.
