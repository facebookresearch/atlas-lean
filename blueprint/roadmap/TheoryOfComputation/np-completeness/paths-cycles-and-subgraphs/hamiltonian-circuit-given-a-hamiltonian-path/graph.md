# Graph of a HAMILTONIAN CIRCUIT given a Hamiltonian path instance

The graph of a HAMILTONIAN CIRCUIT given a Hamiltonian path instance with $n$ vertices and edge
list $E$ is the simple graph on $\{0, \dots, n-1\}$ in which distinct vertices $u$ and $v$ are
adjacent when $(u, v)$ or $(v, u)$ belongs to $E$. Loops are dropped, and pairs with an endpoint
at least $n$ contribute no edge.
