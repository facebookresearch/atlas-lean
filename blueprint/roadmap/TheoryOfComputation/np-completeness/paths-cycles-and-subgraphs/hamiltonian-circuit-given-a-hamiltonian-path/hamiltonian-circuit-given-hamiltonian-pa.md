# Instances of HAMILTONIAN CIRCUIT given a Hamiltonian path

An instance of HAMILTONIAN CIRCUIT given a Hamiltonian path consists of a vertex count $n$ (vertices $0, \dots, n - 1$), an edge list, and a candidate path as a list of vertices. That the candidate is a Hamiltonian path of the graph is checked separately by [well-formedness](well-formed.md).
