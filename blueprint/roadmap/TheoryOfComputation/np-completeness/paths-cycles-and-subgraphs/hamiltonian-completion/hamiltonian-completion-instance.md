# Instances of HAMILTONIAN COMPLETION

An instance of HAMILTONIAN COMPLETION is a triple $(L, E, K)$ of a vertex list $L$, an edge list $E$ and a bound $K$. The graph has the vertices $0, \dots, n-1$, where $n$ is the length of $L$, whatever the entries of $L$ are; a [well-formed](well-formed.md) instance has $L = [0, 1, \dots, n-1]$.
