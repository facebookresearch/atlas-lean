# Well-formed HAMILTONIAN COMPLETION instances

A HAMILTONIAN COMPLETION instance is well-formed when the vertex list is `[0, 1, ..., n - 1]`
with `n` its length, the edge list describes a simple graph on `Fin n` (no duplicate edges in
either orientation, no self-loops, endpoints in range), and `0 < K ≤ |V| = n`.
