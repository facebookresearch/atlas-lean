# Feasibility for UPWARD PLANARITY TESTING

An instance $(n, A)$ of UPWARD PLANARITY TESTING is feasible when there is a map $f : \{0, \dots, n-1\} \to \mathbb{R}^2$ that is a planar straight-line upward drawing of the digraph of the instance: $f$ is injective, every arc goes strictly upward in the second coordinate, the closed segments of two arcs with different endpoint sets meet only in common endpoints, and no vertex lies on the closed segment of an arc unless it is an endpoint of that arc.
