# CODE GENERATION WITH UNFIXED VARIABLE LOCATIONS with $B = 31$ is NP-complete

The CODE GENERATION WITH UNFIXED VARIABLE LOCATIONS with B = 31 decision problem belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [PO8] CODE GENERATION WITH UNFIXED VARIABLE LOCATIONS, p. 274, comment: "Remains NP-complete even for certain fixed values of B, e.g., B = 31" (reference [Robertson, 1977]: E. L. Robertson, "Code generation for short/long address machines", technical report, 1977; not available, the result and its attribution are those recorded by Garey and Johnson).
- journal version: E. L. Robertson, "Code generation and storage allocation for machines with span-dependent instructions", ACM Transactions on Programming Languages and Systems 1 (1979), 71-83, doi:10.1145/357062.357067.
