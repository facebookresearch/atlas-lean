# EMBEDDING BINARY TREES IN A DEFECTIVE GRID is NP-complete

The EMBEDDING BINARY TREES IN A DEFECTIVE GRID decision problem belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
