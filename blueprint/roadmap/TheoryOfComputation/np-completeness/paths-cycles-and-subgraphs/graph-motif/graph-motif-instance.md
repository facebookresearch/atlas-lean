# Instances of GRAPH MOTIF

An instance of GRAPH MOTIF consists of a natural vertex count $n$, a list of natural pairs (the edge list), an arbitrary list of natural colour labels, read as the colours of the vertices in order, and the motif $M$ as a list. At $n = 1$ an empty colour list is representable; in feasibility a missing colour reads as zero. Validation is [separate](well-formed.md).
