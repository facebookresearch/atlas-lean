# MAXIMUM MINIMUM METRIC K-SPANNING TREE is NP-complete

The decision problem MAXIMUM MINIMUM METRIC K-SPANNING TREE is NP-complete: it belongs to NP,
and every decision problem in NP has a polynomial-time many-one reduction to it.

Source: Crescenzi and Kann, MAXIMUM MINIMUM METRIC K-SPANNING TREE; Halldórsson, Iwano, Katoh,
and Tokuyama (1999).
