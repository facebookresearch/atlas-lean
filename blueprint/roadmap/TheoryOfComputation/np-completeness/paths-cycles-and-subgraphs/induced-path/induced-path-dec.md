# INDUCED PATH as a decision problem

The decision problem INDUCED PATH accepts a bitstring $x$ exactly when $x$ decodes, under the
canonical bitstring encoding of INDUCED PATH instances, to an instance that is
[well-formed](../../graph-coloring-and-partitioning/partition-into-cliques/well-formed-2.md) and [feasible](induced-path-feasible.md). It rejects every
bitstring that does not decode to an instance.
