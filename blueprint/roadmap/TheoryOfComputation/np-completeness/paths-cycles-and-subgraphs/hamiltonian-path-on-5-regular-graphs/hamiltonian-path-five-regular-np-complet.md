# HAMILTONIAN PATH on 5-regular graphs is NP-complete

The decision problem HAMILTONIAN PATH on 5-regular graphs belongs to NP, and every decision
problem in NP has a polynomial-time many-one reduction to it.

## Sources

- C. Picouleau, "Complexity of the hamiltonian cycle in regular graph problem", Theoretical Computer Science 131 (1994), 463-473, doi:10.1016/0304-3975(94)90185-6 ("we prove that for any fixed k ≥ 3, deciding whether a k-regular graph has a hamiltonian cycle (or path) is a NP-complete problem").
- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT39] HAMILTONIAN PATH (the parent problem).
