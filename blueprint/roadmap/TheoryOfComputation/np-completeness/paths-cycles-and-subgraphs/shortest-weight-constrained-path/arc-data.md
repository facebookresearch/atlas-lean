# SHORTEST WEIGHT-CONSTRAINED PATH for directed graphs: `(length, weight)` of the listed arc from `a` to `b`

For an instance `i` of SHORTEST WEIGHT-CONSTRAINED PATH for directed graphs, the `(length, weight)` of the listed arc from `a` to `b`; `(0, 0)` if there is none. Under `WellFormed` at most one listed arc goes from `a` to `b`. A position beyond the end of a list reads as a default entry.
