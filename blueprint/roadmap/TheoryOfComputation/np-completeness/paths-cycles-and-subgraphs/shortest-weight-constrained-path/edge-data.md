# Length and weight of an edge in SHORTEST WEIGHT-CONSTRAINED PATH

For an instance `i` of SHORTEST WEIGHT-CONSTRAINED PATH, the `(length, weight)` of the listed edge joining `a` and `b` (in either orientation); `(0, 0)` if there is none. Under `WellFormed` at most one listed edge joins them. A position beyond the end of a list reads as a default entry.
