# Well-formed CODE GENERATION WITH UNLIMITED REGISTERS instances

An instance $(n, A, K)$ is well-formed when no arc $(v, u)$ is listed twice (so $L$ and $R$ are disjoint), all endpoints are below $n$, the digraph is acyclic, no vertex has more than $2$ outgoing arcs, two arcs leaving the same vertex towards different vertices lie in different sets, and $K > 0$.
