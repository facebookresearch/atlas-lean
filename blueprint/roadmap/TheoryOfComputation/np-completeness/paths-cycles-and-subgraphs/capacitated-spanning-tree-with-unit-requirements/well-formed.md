# Well-formed CAPACITATED SPANNING TREE instances with unit requirements and capacities 3

An instance $(n, E, v_0, r, B)$ of CAPACITATED SPANNING TREE (an entry $(u, v, c, l)$ of $E$ is the edge $\{u, v\}$ with capacity $c$ and length $l$) is well-formed for this variant when the endpoint pairs of $E$ have no repetition, each joins two distinct vertices below $n$ and none appears in both orientations; $v_0 < n$; there is one requirement per vertex; every edge has capacity $c = 3$; and every vertex $v \ne v_0$ has requirement $r(v) = 1$.
