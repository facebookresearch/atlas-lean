# Raw edge-flip relation

The raw flip relation on graphs: $T'$ arises from $T$ by removing an edge $e$ of $T$ and adding an edge $f \ne e$, that is, the edge set of $T'$ is $(E \setminus \{e\}) \cup \{f\}$ with $e \in E$. When $f$ is already an edge of $T$, this merely removes $e$. A flip between triangulations is this relation restricted to pairs of triangulations, as in the flip graph.
