# Point Set

The point set of an instance is the CONSTRAINED TRIANGULATION instance $(n, [\,], \text{coordinates})$: the declared count $n$, no edges, and the coordinate list. It is not just the list of points: the counts $0$ and $2$ with the same empty list give different vertex domains, and in the latter the missing coordinates read as the origin. The plane points and the condition that segments meet only at their endpoints are those of CONSTRAINED TRIANGULATION.
