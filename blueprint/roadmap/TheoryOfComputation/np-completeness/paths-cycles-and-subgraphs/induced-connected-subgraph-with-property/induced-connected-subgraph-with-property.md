# Feasible INDUCED CONNECTED SUBGRAPH WITH PROPERTY Π instances

A INDUCED CONNECTED SUBGRAPH WITH PROPERTY Π instance is feasible when some set of at least `K`
vertices induces a connected subgraph with property `Φ`: for some `m ≥ K` and some injective `f
: Fin m ↪ Fin n`, the subgraph induced by the range of `f` is connected and has `Φ`.
