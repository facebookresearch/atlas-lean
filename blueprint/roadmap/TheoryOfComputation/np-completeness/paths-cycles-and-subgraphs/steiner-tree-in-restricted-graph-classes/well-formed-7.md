# Well-formed instances of STEINER TREE IN GRAPHS (unit weights) for grid graphs

An instance of STEINER TREE IN GRAPHS (unit weights) for grid graphs is well formed when it satisfies the parent problem's well-formedness (simple weighted edge list, terminals listed once and below `n`), every edge weight is 1, the graph is a subgraph of the grid up to isomorphism, `K` is positive, and the graph has a vertex.
