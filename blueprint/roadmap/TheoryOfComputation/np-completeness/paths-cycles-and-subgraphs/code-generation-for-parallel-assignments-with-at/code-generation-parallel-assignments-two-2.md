# CODE GENERATION FOR PARALLEL ASSIGNMENTS with at most two operands is NP-complete

The CODE GENERATION FOR PARALLEL ASSIGNMENTS with at most two operands decision problem belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [PO6] CODE GENERATION FOR PARALLEL ASSIGNMENTS, comment ("Remains NP-complete even if each $B_i$ satisfies $|B_i| \le 2$").
- R. Sethi, "A note on implementing parallel assignment instructions", Information Processing Letters 2 (1973), 91-95, doi:10.1016/0020-0190(73)90024-0.
