# Instances of PLANAR HAMILTONIAN COMPLETION

An instance of PLANAR HAMILTONIAN COMPLETION is a pair of a vertex list of natural numbers, given explicitly so that isolated vertices count toward the input size, and an edge list. The number of vertices $n$ is the length of the vertex list; the graph is built from $n$ alone, and well-formedness separately requires the list to be $[0, \dots, n - 1]$.
