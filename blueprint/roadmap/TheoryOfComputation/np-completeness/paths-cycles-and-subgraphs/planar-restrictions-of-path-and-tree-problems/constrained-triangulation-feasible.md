# Feasible CONSTRAINED TRIANGULATION instances

An instance $(n, E, P)$ of CONSTRAINED TRIANGULATION is feasible when some subgraph $T$ of the instance's graph has segments that meet only at endpoints and is maximal with this property among all graphs on the vertices $0, \dots, n - 1$, not only among subgraphs of the instance's graph. When the points are distinct, these graphs are the sets of segments with endpoints in the point set, so the segments of $T$ triangulate the point set.
