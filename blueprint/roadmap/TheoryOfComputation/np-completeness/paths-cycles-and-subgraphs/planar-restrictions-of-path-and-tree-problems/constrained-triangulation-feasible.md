# Feasible CONSTRAINED TRIANGULATION instances

An instance $(n, E, P)$ of CONSTRAINED TRIANGULATION is feasible when some subgraph $T$ of the instance's graph has segments that meet only at endpoints and is maximal with that property among all graphs on the vertices $0, \dots, n - 1$ (that is, among all sets of segments with endpoints in the point set, not only subgraphs of the instance's graph): the segments of $T$ triangulate the point set.
