# Feasible EMBEDDING BINARY TREES IN A DEFECTIVE GRID instances

An instance is feasible when the tree has a crossing-free grid embedding into the non-faulty part of the grid: a one-to-one map $\varphi$ from tree vertices to grid points and, for every listed edge $(u, v)$, a path of usable steps from $\varphi(u)$ to $\varphi(v)$ without repeated points, such that no path passes through the image of a tree vertex other than its two ends, and paths of distinct edges share only images of tree vertices.
