# Well-formed EMBEDDING BINARY TREES IN A DEFECTIVE GRID instances

An instance is well-formed when the tree's edge list is simple and its graph is a tree in which every vertex has exactly $1$ or $3$ neighbors; the grid has $h \ge 1$ rows, all of the same length $w \ge 1$; and the faulty segments are distinct, each a pair $(p, q)$ of grid points inside the grid with $q$ the right or lower neighbor of $p$.
