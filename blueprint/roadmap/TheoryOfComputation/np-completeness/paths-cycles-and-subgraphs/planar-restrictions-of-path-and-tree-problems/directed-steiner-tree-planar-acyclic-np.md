# DIRECTED STEINER TREE FOR PLANAR ACYCLIC DIGRAPHS is NP-complete

The decision problem DIRECTED STEINER TREE FOR PLANAR ACYCLIC DIGRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
