# Feasible DIRECTED HAMILTONIAN PATH instances

An instance $(n, A)$ (the instance format of directed HAMILTONIAN CYCLE: vertices $0, \dots, n-1$ and an arc list $A$) is feasible for DIRECTED HAMILTONIAN PATH when, for some start vertex $s$ and end vertex $t$, some list of all the vertices, each exactly once, starting at $s$ and ending at $t$, has an arc from each vertex to the next.
