# HAMILTONIAN CIRCUIT for rooted directed path graphs is NP-complete

The decision problem HAMILTONIAN CIRCUIT for rooted directed path graphs belongs to NP, and
every decision problem in NP has a polynomial-time many-one reduction to it.
