# MINIMUM CYCLE BASIS SPANNING TREE is NP-complete

The decision problem MINIMUM CYCLE BASIS SPANNING TREE is NP-complete: it belongs to NP, and
every decision problem in NP has a polynomial-time many-one reduction to it.

Source: Johnson (1985), NP-completeness column 14, problem [2]; Deo, Prabhu and Krishnamoorthy
(1982).
