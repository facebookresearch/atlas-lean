# HAMILTONIAN PATH on cubic bipartite planar graphs is NP-complete

The decision problem HAMILTONIAN PATH on cubic bipartite planar graphs belongs to NP, and every
decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- A. Munaro, "On line graphs of subcubic triangle-free graphs", Discrete Mathematics 340 (2017), 1210-1226, doi:10.1016/j.disc.2017.01.006, Theorem 23 ("Hamiltonian Path is NP-complete even for planar cubic bipartite graphs").
- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT39] HAMILTONIAN PATH (the parent problem).
