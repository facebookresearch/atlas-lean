# Well-formed BOUNDED DIAMETER SPANNING TREE instances with fixed D

For a fixed diameter bound $D$, an instance $(n, E, D', B)$ of BOUNDED DIAMETER SPANNING TREE is well-formed when it is a well-formed BOUNDED DIAMETER SPANNING TREE instance (a simple weighted edge list on the vertices $0, \dots, n-1$ with positive weights, $0 < D' \le n$ and $B > 0$), its diameter bound $D'$ equals $D$, and every edge weight is $1$ or $2$.
