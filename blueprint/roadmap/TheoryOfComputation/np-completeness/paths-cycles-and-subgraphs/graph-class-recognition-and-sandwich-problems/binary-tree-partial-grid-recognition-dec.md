# BINARY TREE PARTIAL GRID RECOGNITION as a decision problem

The decision problem BINARY TREE PARTIAL GRID RECOGNITION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs $(n, E)$ (a natural number and a list of pairs), to an instance that is well-formed for BINARY TREE PARTIAL GRID RECOGNITION and whose graph on the vertices $0, \dots, n-1$ (with $u$ and $v$ adjacent when $u \ne v$ and $(u, v)$ or $(v, u)$ is in $E$) is isomorphic to a subgraph, not necessarily induced, of the infinite square grid: the graph on $\mathbb{Z}^2$ in which two points are adjacent when they are at $\ell^1$ distance $1$. Equivalently, the tree has an embedding in the square grid with every edge of unit length. It rejects every bitstring that does not decode to such an instance.
