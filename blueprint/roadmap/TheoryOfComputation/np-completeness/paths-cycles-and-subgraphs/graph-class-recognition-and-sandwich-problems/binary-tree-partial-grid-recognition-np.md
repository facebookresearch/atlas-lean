# BINARY TREE PARTIAL GRID RECOGNITION is NP-complete

The decision problem BINARY TREE PARTIAL GRID RECOGNITION belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- A. Gregori, "Unit-length embedding of binary trees on a square grid", Information Processing Letters 31 (1989), 167-173, doi:10.1016/0020-0190(89)90118-X.
- V. G. P. de Sá, G. D. da Fonseca, R. C. S. Machado and C. M. H. de Figueiredo, "Complexity dichotomy on partial grid recognition", Theoretical Computer Science 412 (2011), 2370-2379, doi:10.1016/j.tcs.2011.01.018 (arXiv:1006.3541; abstract: deciding whether a graph can be embedded in a grid using only unit-length edges "is NP-complete, even when restricted to binary trees"; Section 2: "The NP-completeness for {1,2,3}-trees (binary trees) was demonstrated by Gregori").
- ISGCI, class "binary tree ∩ partial grid" (gc_848), problem Recognition, NP-complete, citing both.
