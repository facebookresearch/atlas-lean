# PATH ORDERABLE GRAPH RECOGNITION is NP-complete

PATH ORDERABLE GRAPH RECOGNITION is NP-complete: the decision problem over bitstrings that accepts exactly the bitstrings that decode to a well-formed instance with a solution lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it. Source: Corneil, Köhler, Olariu and Stewart (2006).
