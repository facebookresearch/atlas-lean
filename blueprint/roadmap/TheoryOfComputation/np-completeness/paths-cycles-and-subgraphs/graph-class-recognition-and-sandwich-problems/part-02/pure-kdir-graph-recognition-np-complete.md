# PURE-k-DIR GRAPH RECOGNITION is NP-complete for every fixed `k ≥ 2`

PURE-k-DIR GRAPH RECOGNITION is NP-complete for every fixed `k ≥ 2`: the decision problem over bitstrings that accepts exactly the bitstrings that decode to a well-formed instance with a solution (for each admissible value of the fixed parameter) lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it. Source: Kratochvíl and Matoušek (1989), Theorem 1; Kratochvíl (1994) for `k = 2`; membership in NP: Kratochvíl and Matoušek (1994).
