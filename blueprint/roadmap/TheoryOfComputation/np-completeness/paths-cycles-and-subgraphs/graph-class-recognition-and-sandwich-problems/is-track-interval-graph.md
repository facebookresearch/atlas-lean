# Track interval graphs in d-TRACK INTERVAL GRAPH RECOGNITION

In d-TRACK INTERVAL GRAPH RECOGNITION, for a natural number $d$, a graph $H$ is a $d$-track interval graph when each vertex $v$ can be assigned, on each track $j \in \{0, \dots, d - 1\}$, a closed real interval $[l_{v,j}, r_{v,j}]$ with $l_{v,j} \le r_{v,j}$, such that two distinct vertices are adjacent in $H$ exactly when their intervals on some track intersect.
