# d-TRACK INTERVAL GRAPH RECOGNITION: `H` is a `d`-track interval graph

In d-TRACK INTERVAL GRAPH RECOGNITION, `H` is a `d`-track interval graph, that is, each vertex `v` is assigned one closed real interval `[l v j, r v j]` on each track `j : Fin d`, and two distinct vertices are adjacent in `H` exactly when their intervals on some track intersect.
