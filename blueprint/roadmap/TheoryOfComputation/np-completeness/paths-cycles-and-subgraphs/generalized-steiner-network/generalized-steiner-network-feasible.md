# Feasible GENERALIZED STEINER NETWORK instances

A GENERALIZED STEINER NETWORK instance is feasible when there is a natural purchase $f_k$ **for each position $k$** of the edge list, with $f_k \le c_k$ and $\sum_k w_k f_k \le K$, that meets every requirement: for each listed $(a, b, r)$ with both $a$ and $b$ in range there is an indexed family of $r$ paths from $a$ to $b$, not necessarily distinct, such that for every position $k$ the number of those paths using the unordered pair at position $k$ is at most $f_k$, counted separately for each position. Requirements with an endpoint out of range impose nothing. Two identical unit-cost, unit-capacity entries joining $0$ and $1$ must both be bought for one path from $0$ to $1$; treating them as one edge gives the wrong budget. Repeated paths are allowed, so two purchased units of one position can serve a demand of two along the same path.
