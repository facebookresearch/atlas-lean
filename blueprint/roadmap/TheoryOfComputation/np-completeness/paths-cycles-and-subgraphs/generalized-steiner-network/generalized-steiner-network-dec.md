# GENERALIZED STEINER NETWORK as a decision problem

The decision problem GENERALIZED STEINER NETWORK accepts a bitstring $x$ exactly when $x$
decodes, under the canonical bitstring encoding of GENERALIZED STEINER NETWORK instances, to an
instance that is [well-formed](well-formed.md) and
[feasible](generalized-steiner-network-feasible.md). It rejects every bitstring that does not
decode to an instance.
