# Instances of GENERALIZED STEINER NETWORK

An instance of GENERALIZED STEINER NETWORK consists of vertex count `n` (vertices `Fin n`), the
edge list (an entry `(u, v, w, c)` is the edge `{u, v}` with weight `w` and capacity `c`), the
requirements (an entry `(i, j, r)` says `r(i, j) = r`), and the bound `K`.
