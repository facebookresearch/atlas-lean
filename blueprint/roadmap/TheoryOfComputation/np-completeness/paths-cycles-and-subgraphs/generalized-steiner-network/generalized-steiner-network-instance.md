# Instances of GENERALIZED STEINER NETWORK

An instance of GENERALIZED STEINER NETWORK consists of a natural vertex count $n$, a list of natural quadruples $(u, v, w, c)$ (the edge $\{u, v\}$ with weight $w$ and capacity $c$), a list of natural triples $(i, j, r)$ (the demands) and a natural bound $K$. The demands are a list of triples, not a function of an endpoint pair: both $(0, 1, 1)$ and $(0, 1, 2)$ can be present before [validation](well-formed.md).
