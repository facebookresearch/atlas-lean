# Instances of HAMILTONIAN CIRCUIT IN GRID GRAPHS

An instance of HAMILTONIAN CIRCUIT IN GRID GRAPHS is an ordered list of sites, repetitions allowed, each a pair of natural pairs `((a, b), (c, d))` read as the point $(a - b, c - d) \in \mathbb{Z}^2$. Different pairs can encode the same coordinate: `(0, 0)` and `(1, 1)` both encode $0$, and a repeated origin is still two entries. Nothing else is stored. Distinct sites, and the other conditions of the usual problem, belong to [validation](well-formed.md).
