# Instances of CAPACITATED SPANNING TREE

An instance of CAPACITATED SPANNING TREE is a tuple $(n, E, v_0, r, B)$ of a number $n$ of vertices $0, \dots, n-1$, an edge list $E$ (an entry $(u, v, c, l)$ is the edge $\{u, v\}$ with capacity $c$ and length $l$), a root vertex $v_0$, the list $r$ of vertex requirements in vertex order, and a length bound $B$.
