# Feasibility for WEIGHTED GRAPH EMBEDDABILITY on the line

An instance $(n, E)$ of WEIGHTED GRAPH EMBEDDABILITY on the line is feasible when there is a function $f : \{0, \dots, n-1\} \to \mathbb{R}$, not necessarily injective, such that every entry $(u, v, w)$ of $E$ with $u < n$ and $v < n$ satisfies

$$\lvert f(u) - f(v) \rvert = w.$$
