# HAMILTONIAN PATH on line graphs of bipartite graphs is NP-complete

The HAMILTONIAN PATH on line graphs of bipartite graphs decision problem belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- T.-H. Lai and S.-S. Wei, "The edge Hamiltonian path problem is NP-complete for bipartite graphs", Information Processing Letters 46 (1993), 21-26, doi:10.1016/0020-0190(93)90191-B.
- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT39] HAMILTONIAN PATH.
