# HAMILTONIAN PATH on k-regular graphs (fixed k) as a decision problem

For a fixed `k`, HAMILTONIAN PATH on `k`-regular graphs as a decision problem over bitstrings: a bitstring is accepted exactly when it decodes to an instance that is well formed for `k` (in particular a `k`-regular graph) and has a Hamiltonian path; every bitstring that decodes to no instance is rejected.
