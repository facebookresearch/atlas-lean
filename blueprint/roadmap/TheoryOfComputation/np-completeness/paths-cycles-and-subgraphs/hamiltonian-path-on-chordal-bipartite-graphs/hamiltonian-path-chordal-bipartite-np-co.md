# HAMILTONIAN PATH on chordal bipartite graphs is NP-complete

The decision problem HAMILTONIAN PATH on chordal bipartite graphs belongs to NP, and every
decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- H. Müller, "Hamiltonian circuits in chordal bipartite graphs", Discrete Mathematics 156 (1996), 291-298, doi:10.1016/0012-365X(95)00057-4 ("The main result of this paper is the NP-completeness of the HAMILTONIAN CIRCUIT problem for chordal bipartite graphs. ... On both classes the complexity of the HAMILTONIAN PATH problem coincides with the complexity of HAMILTONIAN CIRCUIT").
- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT39] HAMILTONIAN PATH (the parent problem).
