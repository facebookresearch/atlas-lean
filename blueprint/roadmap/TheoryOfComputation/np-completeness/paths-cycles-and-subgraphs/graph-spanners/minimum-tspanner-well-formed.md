# Well-formed instances of MINIMUM t-SPANNER

An instance $(n, E, K)$ of MINIMUM t-SPANNER is well-formed when the edge list has no repeated edges (in either orientation) and no loops, and every endpoint is below $n$, so that it describes a simple graph on $\{0, \dots, n - 1\}$, this graph is connected, and $K > 0$.
