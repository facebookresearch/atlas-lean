# Feasible MAXIMUM SUBFOREST instances

Some sublist $E'$ of the edge list of $G$, of length at least $K$, spans a subgraph $(V, E')$ that contains no copy of a tree of $H$. The length counts list entries: it is the number of edges of $(V, E')$ only when the list has no repeated edge, which [well-formedness](well-formed.md) checks.
