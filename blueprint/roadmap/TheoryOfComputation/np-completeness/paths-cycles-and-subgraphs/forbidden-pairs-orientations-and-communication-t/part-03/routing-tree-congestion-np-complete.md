# ROUTING TREE CONGESTION is NP-complete

ROUTING TREE CONGESTION is NP-complete: the decision problem over bitstrings that accepts exactly the bitstrings that decode to a well-formed instance with a solution lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it. Source: Seymour and Thomas (1994); Crescenzi and Kann, MINIMUM ROUTING TREE CONGESTION.
