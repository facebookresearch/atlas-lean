# The decision problem GEOMETRIC STEINER TREE in the L∞ metric

GEOMETRIC STEINER TREE in the `L∞` metric as a decision problem on bitstrings: a bitstring is
accepted exactly when it decodes, under the canonical bitstring encoding, to an instance that is
well-formed for RECTILINEAR STEINER TREE and feasible. A bitstring that does not decode to an
instance is rejected.
