# TRAVELING SALESMAN WITH TIME WINDOWS (FEASIBILITY) as a decision problem

The decision problem TRAVELING SALESMAN WITH TIME WINDOWS (FEASIBILITY) accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a travel-time matrix and a list of time windows, to an instance that is well-formed and feasible for TRAVELING SALESMAN WITH TIME WINDOWS (FEASIBILITY). It rejects every bitstring that does not decode to such an instance.
