# METRIC TRAVELING SALESPERSON as a decision problem

The decision problem METRIC TRAVELING SALESPERSON accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of TRAVELING SALESMAN instances $(m, d, B)$, to an instance that is [well-formed](well-formed-5.md) for METRIC TRAVELING SALESPERSON and feasible for TRAVELING SALESPERSON. It rejects every bitstring that does not decode to such an instance.
