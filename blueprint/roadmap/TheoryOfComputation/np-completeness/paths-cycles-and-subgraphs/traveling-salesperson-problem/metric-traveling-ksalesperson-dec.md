# METRIC TRAVELING K-SALESPERSON as a decision problem

The decision problem METRIC TRAVELING K-SALESPERSON accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quintuples $(m, d, s, k, K)$, to an instance that is [well-formed](well-formed-4.md) and [feasible](metric-traveling-ksalesperson-feasible.md) for METRIC TRAVELING K-SALESPERSON. It rejects every bitstring that does not decode to such an instance.
