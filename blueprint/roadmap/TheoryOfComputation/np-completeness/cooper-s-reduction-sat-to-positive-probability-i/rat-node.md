# Node of a rational Boolean network

A node of a rational Boolean network consists of a list of parent indices and a table of rows $(u, \mathit{num}, \mathit{den})$, where $u$ lists the parents' values in the order of the parent list and the probability that the node is true given $u$ is $\mathit{num}/\mathit{den}$, with $\mathit{num}, \mathit{den}$ natural numbers.
