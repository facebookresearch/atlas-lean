# Deterministic gate

For a Boolean function $f$ of two arguments and node indices $i$ and $j$, the deterministic gate node has parents $i$ and $j$, in that order, and four table rows, for parent values (false, false), (false, true), (true, false) and (true, true) in that order, each giving true the probability $1$ if $f$ is true at those values and $0$ otherwise.
