# Decision preservation on bit strings

Map a bit string that encodes a CNF formula $\varphi$ to the encoding of Cooper's network of
$\varphi$, and any other bit string to the encoding of the one-node network that is never true. For
every bit string $x$, $x$ encodes a satisfiable formula exactly when the image of $x$ encodes a
well-formed network whose output node is true with positive probability.
