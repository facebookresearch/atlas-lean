# Rational Boolean network

A rational Boolean network is a list of nodes: node $k$ is the $k$-th entry, and the output node is the last one when the list is nonempty. The type imposes no further condition: the empty list is a network with no output, a node may list itself or a later node as a parent, and a table row may have a zero denominator or a numerator above its denominator. Topological order, nonemptiness and normalization are requirements of well-formedness, not of the raw list type. Well-formedness also requires distinct parents and exactly one correctly sized row for each assignment of their values.
