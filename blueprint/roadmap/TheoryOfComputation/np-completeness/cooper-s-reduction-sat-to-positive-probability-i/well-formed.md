# Well-formed node

A node of a rational Boolean network is well formed at index $k$ when its parents are distinct and all below $k$, its table has exactly one row for each assignment of values to its parents (the rows have pairwise distinct parent values, each list as long as the parent list, and there are $2^p$ rows for $p$ parents), and every row has $0 < \mathit{den}$ and $\mathit{num} \le \mathit{den}$.
