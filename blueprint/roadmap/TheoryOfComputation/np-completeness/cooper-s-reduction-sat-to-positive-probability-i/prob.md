# Table entry

For a node of a rational Boolean network and a list $u$ of parent values, the table entry is the rational number $\mathit{num}/\mathit{den}$ from the first row whose parent values equal $u$, and $0$ when no row matches (a zero denominator gives $0$ by the convention for division by zero). For a well-formed node it is the conditional probability that the node is true given $u$; in general it is only a rational table value, for example $2$ for a parentless node with the row $([\,], 2, 1)$.
