# The node values depend only on the roots' variables

In Cooper's construction, if two assignments $\sigma_1$ and $\sigma_2$ agree on the variable of every recorded root of a state, then the list of node values of that state is the same under $\sigma_1$ and under $\sigma_2$.

Equivalently, every node of the state has the same value under $\sigma_1$ and under $\sigma_2$: the two lists have the same length, the number of nodes, so they are equal exactly when they agree at every index.
