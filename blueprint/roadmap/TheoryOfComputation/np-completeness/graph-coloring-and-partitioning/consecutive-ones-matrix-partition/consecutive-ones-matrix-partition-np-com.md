# CONSECUTIVE ONES MATRIX PARTITION is NP-complete

The CONSECUTIVE ONES MATRIX PARTITION decision problem belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [SR15] CONSECUTIVE ONES MATRIX PARTITION (attributed to W. Lipski, Jr. [1978], private communication).
