# Feasible CONSECUTIVE ONES SUBMATRIX instances

An instance $(n, A, K)$ (the instance format of CONSECUTIVE BLOCK MINIMIZATION) is feasible for CONSECUTIVE ONES SUBMATRIX when some $K$ distinct columns of $A$, taken in some order, form an $m \times K$ submatrix in which the $1$'s of every row occur consecutively; entries beyond a row's length are read as $0$.
