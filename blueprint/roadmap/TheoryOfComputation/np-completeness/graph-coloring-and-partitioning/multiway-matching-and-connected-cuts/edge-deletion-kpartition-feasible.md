# Feasible instances of EDGE DELETION k-PARTITION

For a fixed natural number $k$, an instance $(n,E,K)$ is feasible if there is a list of exactly $n$ vertex colors, each below $k$, for which the monochromatic edges have total weight at most $K$. A listed edge $(u,v,w)$ contributes $w$ when its two endpoint colors agree. An endpoint outside the color list is read as color zero, even though such edges are excluded by the separate well-formedness condition.
