# Feasible instances of INTEGRITY PRESERVING CUT

An instance $(n, E, U_1, U_2)$ is feasible for INTEGRITY PRESERVING CUT when some set $V_1 \subseteq V = \{0, \dots, n-1\}$ contains every vertex listed in $U_1$, contains no vertex listed in $U_2$, and both $V_1$ and $V_2 = V \setminus V_1$ induce connected subgraphs of the graph on $V$ in which $u$ and $v$ are adjacent when $u \ne v$ and $(u, v)$ or $(v, u)$ is in $E$. A connected graph is nonempty, so both parts are nonempty.
