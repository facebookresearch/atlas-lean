# EUMORPHOUS TREE LAYOUT as a decision problem

The decision problem EUMORPHOUS TREE LAYOUT accepts a bitstring $x$ exactly when $x$ decodes,
under the canonical bitstring encoding of EUMORPHOUS TREE LAYOUT instances, to an instance that
is [well-formed](well-formed.md) and [feasible](eumorphous-tree-layout-feasible.md). It rejects
every bitstring that does not decode to an instance.
