# Well-formed EUMORPHOUS TREE LAYOUT instances

A EUMORPHOUS TREE LAYOUT instance is well-formed when the root and all entries use vertices
below `n`, every vertex is the child in at most one entry, the root in none, every vertex has at
most one child on each side, every vertex descends from the root (so the entries form a binary
tree rooted there), and `K` is positive.
