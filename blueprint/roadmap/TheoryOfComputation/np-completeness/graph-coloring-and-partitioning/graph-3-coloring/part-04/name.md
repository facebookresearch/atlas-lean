# Name of a variable

The name of a variable $x \in \mathbb{N}$ is the list of name-bit
tokens $\mathtt{bit}(b)$, one for each bit $b$ of the binary code of $x$ (its binary digits, least
significant first, with no trailing zero, empty for $x = 0$), in that order; this is how the stacks $A$ and $D$
hold it.
