# Well-formed instances of POLARITY OF CLAW-FREE GRAPHS

An instance $(n, E)$ of POLARITY OF CLAW-FREE GRAPHS is well-formed when the edge list has no repeated edges (in either orientation) and no loops, and every endpoint is below $n$, so that it describes a simple graph on $\{0, \dots, n - 1\}$, and this graph is claw-free (has no induced $K_{1,3}$).
