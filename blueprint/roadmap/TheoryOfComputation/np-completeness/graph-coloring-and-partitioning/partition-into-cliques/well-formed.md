# Well-formed instances of PARTITION INTO k CLIQUES

Fix a natural number $k$. An instance $(n, E, K)$ is well-formed for PARTITION INTO $k$ CLIQUES when it is a well-formed PARTITION INTO CLIQUES instance (the list $E$ has no repeated entries, every pair $(u, v)$ in $E$ satisfies $u < n$, $v < n$, $u \ne v$ and $(v, u) \notin E$, and $0 < K \le n$) and $K = k$.
