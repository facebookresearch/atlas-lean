# Well-formed edge-list instances with 0 < K ≤ n

An instance $(n, E, K)$ is well-formed when the list $E$ has no repeated entries, every pair $(u, v)$ in $E$ satisfies $u < n$, $v < n$, $u \ne v$ and $(v, u) \notin E$, and $0 < K \le n$. This test is shared by PARTITION INTO CLIQUES, INDEPENDENT SEQUENCE, INDUCED PATH and INDUCED SUBGRAPH WITH PROPERTY $\Pi$.
