# Well-formed instances of CUT INTO CONNECTED COMPONENTS OF BOUNDED SIZE

An instance $(n, E, K)$ is well-formed for CUT INTO CONNECTED COMPONENTS OF BOUNDED SIZE when it is a well-formed GRAPH COLORING instance (the list $E$ has no repeated entries, and every pair $(u, v)$ in $E$ satisfies $u < n$, $v < n$, $u \ne v$ and $(v, u) \notin E$) and $n \le 2K$.
