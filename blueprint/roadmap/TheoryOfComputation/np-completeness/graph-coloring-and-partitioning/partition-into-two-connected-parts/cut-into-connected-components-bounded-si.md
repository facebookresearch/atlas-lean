# Feasible instances of CUT INTO CONNECTED COMPONENTS OF BOUNDED SIZE

An instance $(n, E, K)$ is feasible for CUT INTO CONNECTED COMPONENTS OF BOUNDED SIZE when the vertex set $\{0, \dots, n-1\}$ splits into a set $V_1$ and its complement $V_2$ with $|V_1| \le K$ and $|V_2| \le K$ such that the subgraphs of the graph of the instance (on the vertices $0, \dots, n-1$, with $u$ and $v$ adjacent when $u \ne v$ and $(u, v)$ or $(v, u)$ is in $E$) induced by $V_1$ and by $V_2$ are both connected. A connected graph is nonempty, so both parts are nonempty.
