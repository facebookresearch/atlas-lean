# Well-formed instances of GRAPH PARTITIONING WITH UNIT WEIGHTS

For a natural number $K$, an instance $(n, w, E, J)$ is well-formed for GRAPH PARTITIONING WITH UNIT WEIGHTS when the GRAPH PARTITIONING instance $(n, w, E, K, J)$ is well-formed (one positive weight per vertex, the edges form a simple graph on $\{0, \dots, n-1\}$ with positive lengths, $K > 0$ and $J > 0$), every vertex weight is $1$, and every edge length is $1$.
