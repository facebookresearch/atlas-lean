# Feasible instances of UNIFORM SPARSEST CUT

An instance $(n, E, (a, d))$ is feasible for UNIFORM SPARSEST CUT when some set $S \subseteq \{0, \dots, n-1\}$ with $0 < |S| < n$ satisfies $c(S) \cdot d \le a \cdot |S| \, (n - |S|)$, where $c(S)$ is the number of listed edges with exactly one end in $S$; that is, $c(S) / (|S| (n - |S|)) \le r$ for $r = a/d$.
