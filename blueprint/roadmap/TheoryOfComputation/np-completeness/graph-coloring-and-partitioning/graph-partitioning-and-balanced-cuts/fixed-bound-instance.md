# Instances of GRAPH PARTITIONING WITH UNIT WEIGHTS AND FIXED BLOCK BOUND

An instance of GRAPH PARTITIONING WITH UNIT WEIGHTS is a quadruple $(n, w, E, J)$: a vertex count $n$, a list $w$ of vertex weights, a list $E$ of edges with lengths $(u, v, l)$, and a cut-length bound $J$. The block-weight bound $K$ is not part of the instance; it is a fixed parameter of the problem.
