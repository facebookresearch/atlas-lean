# Well-formed instances of ACYCLIC PARTITION WITH UNIT WEIGHTS AND COSTS

An instance $(n, w, A, B, K)$ is well-formed for ACYCLIC PARTITION WITH UNIT WEIGHTS AND COSTS when it is a well-formed instance of ACYCLIC PARTITION in which every entry of $w$ equals $1$ and every arc $(u, v, c)$ of $A$ has cost $c = 1$. Then $B$ bounds the number of vertices in each block and $K$ the number of arcs between blocks.
