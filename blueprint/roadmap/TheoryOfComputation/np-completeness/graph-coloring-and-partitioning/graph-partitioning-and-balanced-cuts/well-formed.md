# Well-formed instances of ACYCLIC PARTITION FOR TREES

An instance $(n, w, A, B, K)$ is well-formed for ACYCLIC PARTITION FOR TREES when it is a well-formed instance of ACYCLIC PARTITION, no two entries of $A$ are arcs between the same two vertices in opposite directions, and the underlying undirected graph of the instance is a tree (connected and acyclic, so $n \ge 1$). The arcs may be oriented arbitrarily.
