# Well-formed chord-list instances

An instance $(C, K)$, a list of chords and a bound, is well-formed when every chord $(a, b)$ in $C$ has $a < b$, the endpoints of all chords are pairwise distinct (no number occurs twice among them), and $0 < K \le |C|$. This test is shared by GRAPH K-COLORABILITY ON CIRCLE GRAPHS and DOMINATING SET on circle graphs.
