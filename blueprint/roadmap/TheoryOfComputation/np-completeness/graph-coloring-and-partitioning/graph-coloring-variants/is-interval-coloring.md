# Interval edge-colorings

Let $G$ be a simple graph and $t$ a natural number. A proper edge coloring $c$ of $G$ with colors in $\{0, \dots, t-1\}$ (edges sharing an endpoint get different colors) is an interval $t$-coloring when every color is used and, at every vertex $v$, the set of colors of the edges incident to $v$ is a set of consecutive integers (possibly empty).
