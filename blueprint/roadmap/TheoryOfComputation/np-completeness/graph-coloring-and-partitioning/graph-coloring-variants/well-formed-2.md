# Well-formed instances of BIPARTITE EDGE COLORING WITH CONFLICT PARTITION

An instance $((n, E, K), \ell)$ is well-formed for BIPARTITE EDGE COLORING WITH CONFLICT PARTITION when $(n, E, K)$ is a well-formed EDGE COLORING instance (the list $E$ has no repeated entries, and every pair $(u, v)$ in $E$ satisfies $u < n$, $v < n$, $u \ne v$ and $(v, u) \notin E$), the graph on $\{0, \dots, n-1\}$ with edge list $E$ is bipartite, $\ell$ has exactly one label per entry of $E$, and $K > 0$.
