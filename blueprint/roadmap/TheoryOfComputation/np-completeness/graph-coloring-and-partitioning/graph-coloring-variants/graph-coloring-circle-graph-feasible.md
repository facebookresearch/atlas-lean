# Feasible instances of GRAPH K-COLORABILITY ON CIRCLE GRAPHS

An instance $(C, K)$ is feasible for GRAPH K-COLORABILITY ON CIRCLE GRAPHS when the circle graph of $C$ is $K$-colorable. The circle graph has one vertex for each chord, and two distinct chords $(a, b)$ and $(a', b')$ are adjacent when their endpoints interleave: $a < a' < b < b'$ or $a' < a < b' < b$.
