# Instances of BIPARTITE EDGE COLORING WITH CONFLICT PARTITION

An instance of BIPARTITE EDGE COLORING WITH CONFLICT PARTITION is a pair $((n, E, K), \ell)$ of an EDGE COLORING instance $(n, E, K)$ and a list $\ell$ of natural numbers, where the $a$-th entry of $\ell$ is the label of the $a$-th entry of $E$. Edges with equal labels form one set of the partition of the edges.
