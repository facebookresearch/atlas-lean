# Feasible instances of ORIENTED k-COLORING

Fix a natural number $k$. An instance $(n, A)$ is feasible for ORIENTED $k$-COLORING when there are an oriented graph $T$ on $\{0, \dots, k-1\}$ (no loops, and never arcs in both directions between two vertices) and a map $c$ from vertices to $\{0, \dots, k-1\}$ such that every arc $(u, v)$ of $A$ is mapped to an arc $(c(u), c(v))$ of $T$.
