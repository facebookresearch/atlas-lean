# Given 3-coloring of an ANOTHER 3-COLORING instance

For an instance $(n, E, c)$ of ANOTHER 3-COLORING, the given coloring sends each vertex $v < n$ to the remainder of $c(v)$ modulo $3$, a color in $\{0, 1, 2\}$, where $c(v)$ is read as $0$ if the list $c$ has fewer than $v + 1$ entries. Under well-formedness every entry is below $3$, so the given color of $v$ is $c(v)$ itself.
