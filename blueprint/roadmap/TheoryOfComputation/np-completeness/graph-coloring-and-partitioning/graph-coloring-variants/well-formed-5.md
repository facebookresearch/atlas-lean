# Well-formed instances of CHROMATIC INDEX 3 OF CUBIC GRAPHS

An instance $(n, E)$ is well-formed for CHROMATIC INDEX 3 OF CUBIC GRAPHS when the list $E$ has no repeated entries, and every pair $(u, v)$ in $E$ satisfies $u < n$, $v < n$, $u \ne v$ and $(v, u) \notin E$, and the graph of the instance is cubic: every vertex has exactly $3$ neighbors.
