# Instances of CIRCULAR-ARC GRAPH COLORING

An instance of CIRCULAR-ARC GRAPH COLORING is a triple $(L, A, K)$: a natural number $L$, the number of points $0, \dots, L-1$ placed in clockwise order on a circle; a list $A$ of pairs $(a, b)$ of natural numbers, the arcs, each running clockwise from $a$ to $b$; and a natural number $K$, the number of colors.
