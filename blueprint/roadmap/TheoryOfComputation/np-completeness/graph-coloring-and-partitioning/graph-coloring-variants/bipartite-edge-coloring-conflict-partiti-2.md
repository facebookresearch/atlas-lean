# Feasible instances of BIPARTITE EDGE COLORING WITH CONFLICT PARTITION

An instance $((n,E,K),\ell)$ is feasible if there is one color below $K$ for each entry of $E$. Two entries at distinct positions must get different colors if they share an endpoint or have the same partition label. Labels are read by edge position: a missing label is zero. Thus two unlabeled entries conflict even if they have no common endpoint, and an unlabeled entry conflicts with one explicitly labelled zero. Labels beyond the end of $E$ are unused.
