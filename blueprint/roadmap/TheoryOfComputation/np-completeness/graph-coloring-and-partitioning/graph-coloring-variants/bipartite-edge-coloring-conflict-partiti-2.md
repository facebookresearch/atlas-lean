# Feasible instances of BIPARTITE EDGE COLORING WITH CONFLICT PARTITION

An instance $((n, E, K), \ell)$ is feasible for BIPARTITE EDGE COLORING WITH CONFLICT PARTITION when each entry of $E$ can be given a color below $K$ so that any two entries at different positions of $E$ get different colors whenever they share an endpoint or carry the same label in $\ell$.
