# Well-formed instances of ANOTHER 3-COLORING

An instance $(n, E, c)$ of ANOTHER 3-COLORING is well-formed when the list $E$ has no repeated entries, and every pair $(u, v)$ in $E$ satisfies $u < n$, $v < n$, $u \ne v$ and $(v, u) \notin E$; the list $c$ has exactly $n$ entries, each below $3$; and the given coloring is proper: adjacent vertices of the graph of the instance receive different given colors.
