# The GRAPH THICKNESS instance with the same graph

For a natural number $k$ and an instance $(n, E, K)$ given by a vertex count, an edge list and a bound, this is the GRAPH THICKNESS instance $(n, E, k)$: the same vertex count and edge list with the bound $k$, the old bound $K$ being dropped. The construction applies to every $k$; the restriction to a fixed $k \ge 2$ belongs to the hardness statements for graphs of thickness at most $k$. The same construction serves MAXIMUM CUT, DOMINATING SET and INDEPENDENT SET ON GRAPHS OF THICKNESS AT MOST k.
