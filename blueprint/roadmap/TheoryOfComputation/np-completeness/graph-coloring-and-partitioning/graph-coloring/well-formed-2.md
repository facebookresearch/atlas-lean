# Well-formed instances of GRAPH k-COLORABILITY

Fix a natural number $k$. An instance $(n, E, K)$ is well-formed for GRAPH $k$-COLORABILITY when it is a well-formed GRAPH COLORING instance (the list $E$ has no repeated entries, and every pair $(u, v)$ in $E$ satisfies $u < n$, $v < n$, $u \ne v$ and $(v, u) \notin E$) and $K = k$.
