# EDGE EMBEDDING ON A GRID as a decision problem

The decision problem EDGE EMBEDDING ON A GRID accepts a bitstring $x$ exactly when $x$ decodes,
under the canonical bitstring encoding of EDGE EMBEDDING ON A GRID instances, to an instance
that is [well-formed](well-formed.md) and [feasible](edge-embedding-on-agrid-feasible.md). It
rejects every bitstring that does not decode to an instance.
