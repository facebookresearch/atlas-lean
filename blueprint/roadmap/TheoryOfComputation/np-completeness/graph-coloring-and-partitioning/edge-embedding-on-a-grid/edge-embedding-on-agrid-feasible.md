# Feasible EDGE EMBEDDING ON A GRID instances

An EDGE EMBEDDING ON A GRID instance is feasible when some one-to-one placement of the vertices on the cells $(r, c)$ of the $M \times N$ grid ($r < M$, $c < N$) puts the two ends of every edge in a common row or a common column, that is, embeds the graph into the rook graph of the $M \times N$ grid.
