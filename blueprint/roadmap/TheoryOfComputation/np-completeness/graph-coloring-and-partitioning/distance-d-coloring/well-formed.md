# Well-formed instances of DISTANCE-d CHROMATIC NUMBER

An instance $(n, E, K)$ is well-formed for DISTANCE-$d$ CHROMATIC NUMBER when it is a well-formed GRAPH COLORING instance (the list $E$ has no repeated entries, and every pair $(u, v)$ in $E$ satisfies $u < n$, $v < n$, $u \ne v$ and $(v, u) \notin E$) and $0 < K \le n$.
