# Instances of GENERALIZED HYPERTREE WIDTH AT MOST 3

An instance of GENERALIZED HYPERTREE WIDTH AT MOST 3 consists of a natural number $n$ and a list of hyperedges, each a list of natural labels. The labels need not be below $n$: at $n = 1$ the list `[[1]]` is an instance, and its hyperedge projects to the empty vertex set of $\{0, \dots, n-1\}$. Hyperedges are identified by their position in the list, so repeated entries are distinct hyperedges; see the [width condition](is-ghdwidth-at-most-three.md). That every label is below $n$ is checked separately by [validation](well-formed.md).
