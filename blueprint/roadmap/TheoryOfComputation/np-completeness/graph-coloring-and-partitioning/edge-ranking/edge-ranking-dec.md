# EDGE RANKING as a decision problem

The decision problem EDGE RANKING accepts a bitstring $x$ exactly when $x$ decodes, under the
canonical bitstring encoding of EDGE RANKING instances, to an instance that is
[well-formed](../acyclic-coloring/well-formed.md) and [feasible](edge-ranking-feasible.md). It rejects every
bitstring that does not decode to an instance.
