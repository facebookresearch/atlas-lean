# Feasible ELIMINATION DEGREE SEQUENCE instances

An ELIMINATION DEGREE SEQUENCE instance with $n$ vertices and sequence $(d_0, d_1, \dots)$ is feasible when some one-to-one map $f$ from the vertices to $\{0, \dots, n-1\}$ gives every vertex $v$ exactly $d_{f(v)}$ neighbours $u$ with $f(v) < f(u)$, where an entry $d_k$ missing from the sequence is read as $0$. For a [well-formed](well-formed.md) instance the sequence has exactly $n$ entries, so every $d_{f(v)}$ is a listed entry.
