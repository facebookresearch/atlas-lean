# Instances of ELIMINATION DEGREE SEQUENCE

An instance of ELIMINATION DEGREE SEQUENCE consists of a vertex count $n$ (vertices $0, \dots, n-1$), an edge list, and a list of degrees $\langle d_1, d_2, \dots \rangle$. The raw list need not have length $n$, and the edge list need not be simple; both are checked separately by [well-formedness](well-formed.md).
