# Path decompositions

A sequence of bags $X_0, \dots, X_{r-1}$, each a finite set of vertices of a simple graph $G$ on $\{0, \dots, n-1\}$, is a path decomposition of $G$ when every vertex lies in some bag, both ends of every edge lie in a common bag, and every vertex lying in $X_{t_1}$ and $X_{t_3}$ lies in every $X_{t_2}$ with $t_1 \le t_2 \le t_3$.
