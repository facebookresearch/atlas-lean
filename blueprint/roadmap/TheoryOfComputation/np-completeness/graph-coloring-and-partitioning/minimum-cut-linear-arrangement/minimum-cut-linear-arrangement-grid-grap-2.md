# The decision problem MINIMUM CUT LINEAR ARRANGEMENT for grid graphs

MINIMUM CUT LINEAR ARRANGEMENT for grid graphs as a decision problem on bitstrings: a bitstring
is accepted exactly when it decodes, under the canonical bitstring encoding, to a well-formed
instance (a set of grid points and a bound $K$) whose grid graph, taken as a MINIMUM CUT LINEAR
ARRANGEMENT instance with bound $K$, is feasible. A bitstring that does not decode to an
instance is rejected.
