# Well-formed instances of TOPOLOGICAL BANDWIDTH

An instance $(n, E, K)$ is well-formed for TOPOLOGICAL BANDWIDTH when it is a well-formed BANDWIDTH instance (the list $E$ has no repeated entries, and every pair $(u, v)$ in $E$ satisfies $u < n$, $v < n$, $u \ne v$ and $(v, u) \notin E$) and $K > 0$.
