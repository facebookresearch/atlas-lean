# Well-formed instances of CHROMATIC INDEX ON LINE GRAPHS

An instance $(n, E, K)$ is well-formed for CHROMATIC INDEX ON LINE GRAPHS when it is a well-formed EDGE COLORING instance (the list $E$ has no repeated entries, and every pair $(u, v)$ in $E$ satisfies $u < n$, $v < n$, $u \ne v$ and $(v, u) \notin E$), $K > 0$, and the graph on the vertices $0, \dots, n-1$ in which $u$ and $v$ are adjacent when $u \ne v$ and $(u, v)$ or $(v, u)$ is in $E$ is a line graph (isomorphic to the line graph of some simple graph on $\{0, \dots, k-1\}$).
