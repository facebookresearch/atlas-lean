# Feasible instances of STRONG EDGE COLORING

An instance $(n, E, K)$ of EDGE COLORING is feasible for STRONG EDGE COLORING when each entry of $E$ can be given a color below $K$ so that any two entries at different positions of $E$ that are within distance one in the graph with edge list $E$ (they share an endpoint, or some entry of $E$ joins an endpoint of one to an endpoint of the other) get different colors. For a simple edge list this says that every color class is an induced matching.
