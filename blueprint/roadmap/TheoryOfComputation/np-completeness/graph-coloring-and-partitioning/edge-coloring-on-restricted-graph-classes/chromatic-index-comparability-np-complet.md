# CHROMATIC INDEX ON COMPARABILITY GRAPHS is NP-complete

The decision problem CHROMATIC INDEX ON COMPARABILITY GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
