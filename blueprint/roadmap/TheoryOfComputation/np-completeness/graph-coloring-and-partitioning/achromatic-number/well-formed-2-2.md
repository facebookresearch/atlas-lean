# Well-formed ACHROMATIC NUMBER OF COGRAPHS instances

An instance $(n, E, K)$ is well-formed for ACHROMATIC NUMBER OF COGRAPHS when it is a well-formed instance $(n, E, K)$ of ACHROMATIC NUMBER (the list $E$ has no repeated entries, and every pair $(u, v)$ in $E$ satisfies $u < n$, $v < n$, $u \ne v$ and $(v, u) \notin E$), the graph on the vertices $0, \dots, n-1$ in which $u$ and $v$ are adjacent when $u \ne v$ and $(u, v)$ or $(v, u)$ is in $E$ is a cograph, and $K > 0$. Here a cograph is a graph with no induced path on four vertices: no injective map from the vertices of the path $P_4$ preserves both adjacency and non-adjacency.
