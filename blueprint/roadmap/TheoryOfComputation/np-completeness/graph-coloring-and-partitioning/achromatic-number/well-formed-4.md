# Well-formed ACHROMATIC NUMBER OF TREES instances

An instance $(n, E, K)$ is well-formed for ACHROMATIC NUMBER OF TREES when it is a well-formed instance $(n, E, K)$ of ACHROMATIC NUMBER (the list $E$ has no repeated entries, and every pair $(u, v)$ in $E$ satisfies $u < n$, $v < n$, $u \ne v$ and $(v, u) \notin E$), the graph on the vertices $0, \dots, n-1$ in which $u$ and $v$ are adjacent when $u \ne v$ and $(u, v)$ or $(v, u)$ is in $E$ is a tree (connected and acyclic, so in particular $n \ge 1$), and $K > 0$.
