# CHROMATIC INDEX of k-regular graphs is NP-complete for every fixed k ≥ 3

For every natural number $k \ge 3$, the following decision problem is NP-complete: it belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it. Given a simple graph $G$ on $\{0, \dots, n - 1\}$, given by a vertex count $n$ and an edge list without repeated edges (in either orientation) or loops in which every vertex has degree exactly $k$, decide whether the edges of $G$ can be colored with $k$ colors so that any two edges sharing an endpoint get different colors.
