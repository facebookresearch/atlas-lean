# TREEWIDTH: `(T, β)` is a tree decomposition of the finite graph `G`

In TREEWIDTH, `(T, β)` is a tree decomposition of the finite graph `G`, that is, `T` is a tree, every vertex of `G` belongs to some bag, for every edge of `G` some bag contains both endpoints, and for every vertex `v` of `G` the nodes whose bags contain `v` induce a connected subgraph of `T`.
