# Feasible DISTANCE-d PARTITION OF POINTS IN THE PLANE instances

A DISTANCE-d PARTITION OF POINTS IN THE PLANE instance is feasible when some partition of the
points into `K` nonempty sets (a surjective map `c` to `Fin K`) puts two distinct points in the
same set only when their Euclidean distance exceeds `d`: `d² < (u₁ - v₁)² + (u₂ - v₂)²`.
