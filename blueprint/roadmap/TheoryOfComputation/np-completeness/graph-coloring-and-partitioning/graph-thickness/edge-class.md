# Edge Class

For an assignment $f$ of the positions of the edge list to classes $0, \dots, K-1$, class $c$ consists of the listed edges at the positions $e$ with $f(e) = c$, in list order. Repeated entries of the edge list are separate positions and may go to different classes; a [well-formed](../acyclic-coloring/well-formed.md) instance lists every edge once.
