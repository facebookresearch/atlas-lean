# Well-formed MATRIX COVER with a positive definite matrix instances

Well-formedness of a MATRIX COVER instance with a positive definite matrix: the instance is
well-formed for MATRIX COVER ($A$ has $n$ rows of length $n$), and $A$, read as a real matrix,
is positive definite: symmetric, with $x^{\mathsf T} A x > 0$ for every nonzero real vector $x$.
