# Instances of HIERARCHICAL-TREE CLUSTERING (ℓ₁ ultrametric fitting)

An instance of HIERARCHICAL-TREE CLUSTERING (ℓ₁ ultrametric fitting) consists of an arbitrary list of rows of natural numbers, read as the rows of the dissimilarity matrix $w$, and a natural bound $K$. Any list of rows is an instance: two empty rows decode but do not form a square dissimilarity matrix. The matrix shape belongs to [validation](well-formed.md).
