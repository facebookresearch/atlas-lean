# GRUNDY NUMBER as a decision problem

The decision problem GRUNDY NUMBER accepts a bitstring $x$ exactly when $x$ decodes, under the
canonical bitstring encoding of GRUNDY NUMBER instances, to an instance that is
[well-formed](../acyclic-coloring/well-formed.md) and [feasible](grundy-number-feasible.md). It rejects every
bitstring that does not decode to an instance.
