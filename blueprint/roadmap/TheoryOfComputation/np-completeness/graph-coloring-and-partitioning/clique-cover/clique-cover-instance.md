# A clique-cover instance

An instance of CLIQUE COVER is a triple $(n, E, \ell)$: a vertex count $n$, a list $E$ of pairs of natural numbers, the edges on the vertices $0, \dots, n-1$, and a natural number $\ell$, the bound on the number of cliques.

## Sources
