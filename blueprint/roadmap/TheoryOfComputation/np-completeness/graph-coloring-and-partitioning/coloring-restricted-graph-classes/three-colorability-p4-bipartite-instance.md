# Instances of 3-COLORABILITY OF P4-BIPARTITE GRAPHS

An instance of 3-COLORABILITY OF P4-BIPARTITE GRAPHS is a pair $(n, E)$: a natural number $n$, the number of vertices $0, \dots, n-1$, and a list $E$ of pairs of natural numbers, the edges. The number of colors, $3$, is not part of the instance.
