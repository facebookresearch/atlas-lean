# GRAPH COLORING instance with the same graph and three colors

For an instance $(n, E)$ of a 3-colorability problem, given by a vertex count $n$ and an edge list $E$, this is the GRAPH COLORING instance $(n, E, 3)$: the same vertex count and edge list with the bound $K = 3$. No graph-class condition is checked on the input. The same construction serves 3-COLORABILITY OF GRAPHS OF DIAMETER AT MOST 3, OF LINE GRAPHS, OF MONOPOLAR GRAPHS and OF P4-BIPARTITE GRAPHS.
