# DIRECTED OPTIMAL LINEAR ARRANGEMENT as a decision problem

The decision problem DIRECTED OPTIMAL LINEAR ARRANGEMENT accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(n, A, K)$, to an instance that is [well-formed](well-formed.md) and [feasible](directed-optimal-linear-arrangement-feas.md) for DIRECTED OPTIMAL LINEAR ARRANGEMENT. It rejects every bitstring that does not decode to such an instance.
