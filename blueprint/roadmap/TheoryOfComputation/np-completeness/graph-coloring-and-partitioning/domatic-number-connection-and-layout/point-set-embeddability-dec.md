# PLANAR POINT-SET EMBEDDABILITY as a decision problem

The decision problem PLANAR POINT-SET EMBEDDABILITY accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of an edge list and a point list, to an instance that is well-formed and feasible for PLANAR POINT-SET EMBEDDABILITY. It rejects every bitstring that does not decode to such an instance.
