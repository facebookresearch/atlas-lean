# GATE MATRIX LAYOUT is NP-complete

The decision problem GATE MATRIX LAYOUT belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- T. Kashiwabara and T. Fujisawa, "An NP-complete problem on interval graphs", Proceedings of the IEEE International Symposium on Circuits and Systems (1979), 82-83.

- R. Govindan, M. A. Langston and S. Ramachandramurthi, "A practical approach to layout optimization", University of Tennessee Computer Science Technical Report CS-92-176 (1992), Section 3 (problem statement; "Since GML is NP-Complete [KF]").
