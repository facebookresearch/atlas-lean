# GATE MATRIX LAYOUT as a decision problem

The decision problem GATE MATRIX LAYOUT accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of a Boolean matrix and a bound, to an instance that is [well-formed](well-formed-4.md) and [feasible](gate-matrix-layout-feasible.md) for GATE MATRIX LAYOUT. It rejects every bitstring that does not decode to such an instance.
