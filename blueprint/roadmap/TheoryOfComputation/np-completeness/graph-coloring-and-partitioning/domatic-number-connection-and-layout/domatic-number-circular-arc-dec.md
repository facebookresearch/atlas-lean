# DOMATIC NUMBER FOR CIRCULAR-ARC GRAPHS as a decision problem

The decision problem DOMATIC NUMBER FOR CIRCULAR-ARC GRAPHS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of triples $(n, E, K)$ of a vertex count, an edge list and a bound, to an instance that is [well-formed](well-formed-2.md) for DOMATIC NUMBER FOR CIRCULAR-ARC GRAPHS and feasible for DOMATIC NUMBER. It rejects every bitstring that does not decode to such an instance.
