# DIRECTED OPTIMAL LINEAR ARRANGEMENT is NP-complete

The decision problem DIRECTED OPTIMAL LINEAR ARRANGEMENT belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.
