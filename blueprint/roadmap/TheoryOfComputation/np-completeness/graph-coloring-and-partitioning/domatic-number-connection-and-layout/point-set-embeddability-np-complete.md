# PLANAR POINT-SET EMBEDDABILITY is NP-complete

The decision problem PLANAR POINT-SET EMBEDDABILITY belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- S. Cabello, "Planar embeddability of the vertices of a graph using a fixed point set is NP-hard", Journal of Graph Algorithms and Applications 10 (2006), 353-363, doi:10.7155/jgaa.00132 (Theorem 1).
