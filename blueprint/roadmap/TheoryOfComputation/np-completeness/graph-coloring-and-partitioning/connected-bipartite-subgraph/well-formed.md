# Well-formed edge-list instances with 0 < K ≤ |E|

An instance $(n, E, K)$ is well-formed when the edge list has no repeated edge, every edge joins two distinct vertices below $n$, no edge appears in both orientations, and $0 < K \le |E|$, the length of the edge list. This test is shared by CONNECTED BIPARTITE SUBGRAPH, INTERSECTION GRAPH BASIS, EDGE-SUBGRAPH and other problems with the same encoding.
