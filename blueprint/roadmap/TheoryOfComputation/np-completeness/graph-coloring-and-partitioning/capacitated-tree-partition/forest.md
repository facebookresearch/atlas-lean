# Forest

The simple graph on the vertices $0, \dots, n - 1$ made from a list $F$ of weighted edges $(u, v, w)$: distinct $u$ and $v$ are adjacent exactly when $F$ contains an entry $(u, v, w)$ or $(v, u, w)$ for some weight $w$. It is a spanning subgraph of $G$ when $F$ is a sublist of the input edges, as feasibility requires; for an arbitrary $F$ it need not be.
