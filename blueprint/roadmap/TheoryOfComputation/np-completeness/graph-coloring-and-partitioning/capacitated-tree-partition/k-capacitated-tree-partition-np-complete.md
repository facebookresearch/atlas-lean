# k-CAPACITATED TREE PARTITION is NP-complete

The decision problem k-CAPACITATED TREE PARTITION is NP-complete: it belongs to NP, and every
decision problem in NP has a polynomial-time many-one reduction to it.

Source: Crescenzi and Kann, MINIMUM K-CAPACITATED TREE PARTITION; Imielińska, Kalantari and
Khachiyan (1993), as recorded by Goemans and Williamson (1995).
