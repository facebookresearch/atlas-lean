# Feasible instances of PARTITION INTO FORESTS

An instance $(n, E, K)$ is feasible for PARTITION INTO FORESTS when, for some $k \le K$, the vertices $0, \dots, n-1$ can be colored with colors $0, \dots, k-1$ so that each color class induces an acyclic subgraph (a forest) of the graph on the vertices $0, \dots, n-1$ in which $u$ and $v$ are adjacent when $u \ne v$ and $(u, v)$ or $(v, u)$ is in $E$.
