# EDGE PARTITION INTO TRIANGLES is NP-complete

The decision problem EDGE PARTITION INTO TRIANGLES belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- I. Holyer, "The NP-completeness of some edge-partition problems", SIAM Journal on Computing 10(4) (1981), 713-717, doi:10.1137/0210054 (for each fixed `n ≥ 3` it is NP-complete to determine whether an arbitrary graph can be edge-partitioned into subgraphs isomorphic to the complete graph `K_n`; here `n = 3`).
