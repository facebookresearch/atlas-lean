# Feasible instances of EDGE PARTITION INTO TRIANGLES

An instance $(n, E)$ is feasible for EDGE PARTITION INTO TRIANGLES when some set $T$ of triangles (3-cliques) of the graph on the vertices $0, \dots, n-1$ in which $u$ and $v$ are adjacent when $u \ne v$ and $(u, v)$ or $(v, u)$ is in $E$ contains, for every edge $uv$, exactly one triangle with both $u$ and $v$; so the triangles of $T$ partition the edge set.
