# PARTITION INTO CLIQUES ON LOCALLY CONNECTED GRAPHS is NP-complete

The decision problem PARTITION INTO CLIQUES ON LOCALLY CONNECTED GRAPHS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [GT15] PARTITION INTO CLIQUES (the parent problem).
- ISGCI, *Information System on Graph Classes and their Inclusions*, class `gc_932` (locally connected), problem Clique cover: NP-complete, reference `ref_1506` (ISGCI note: adding a universal vertex to a connected graph yields a locally connected graph with the same clique cover number; communicated by P. Irzhavski).
