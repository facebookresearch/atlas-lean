# Feasible instances of PARTITION INTO CLIQUES ON CIRCLE GRAPHS

An instance $(C, K)$ is feasible when, for some $k \le K$, some map $c$ from the positions of $C$ to $\{0, \dots, k-1\}$ makes every block $c^{-1}(j)$ a clique of the circle graph of $C$, in which two distinct chords $(a, b)$ and $(a', b')$ are adjacent when their endpoints interleave: $a < a' < b < b'$ or $a' < a < b' < b$.
