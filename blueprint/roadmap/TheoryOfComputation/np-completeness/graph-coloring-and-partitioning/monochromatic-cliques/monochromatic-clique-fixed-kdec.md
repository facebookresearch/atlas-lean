# The decision problem MONOCHROMATIC K_k

For a fixed natural number $k$, MONOCHROMATIC $K_k$ as a decision problem on bitstrings: a
bitstring is accepted exactly when it decodes, under the canonical bitstring encoding, to an
instance that is well-formed for MONOCHROMATIC TRIANGLE and feasible (for the fixed parameter
$k$). A bitstring that does not decode to an instance is rejected.
