# Well-formed DEADLOCK EXPOSURE IN PACKET SWITCHING NETWORKS instances

An instance $(n, E, b, R, W)$ is well-formed when the edge list has no repeated edge, every edge joins two distinct vertices below $n$, and no edge appears in both orientations; there are $n$ buffer counts, all positive; the routes are pairwise distinct and each is a nonempty path of distinct vertices below $n$ with consecutive vertices adjacent; the window list has no repeated pair and has an entry for exactly the source-destination pairs of the routes.
