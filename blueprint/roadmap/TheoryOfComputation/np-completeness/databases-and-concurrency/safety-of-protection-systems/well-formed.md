# Well-formed instances of SAFETY OF MONO-OPERATIONAL FILE PROTECTION SYSTEMS

An instance of SAFETY OF MONO-OPERATIONAL FILE PROTECTION SYSTEMS is well formed when `|S| ≤ |O|`; every triple of the initial matrix has a subject, an object and a right; every command uses rights of `R` and formal parameters below its parameter count `k`; and `r' ∈ R`.
