# Feasible instances of SIDE-EFFECT-FREE DELETION PROPAGATION (project-join view)

An instance of SIDE-EFFECT-FREE DELETION PROPAGATION (project-join view) is feasible when some deletion of source tuples `T₁ ⊆ R₁`, `T₂ ⊆ R₂` removes exactly `t` from the view. Feasibility does not include well-formedness; the decision problem requires both.
