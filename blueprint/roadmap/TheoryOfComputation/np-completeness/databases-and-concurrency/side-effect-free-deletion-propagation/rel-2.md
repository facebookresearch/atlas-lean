# Relation $R_2(B, C)$ in SIDE-EFFECT-FREE DELETION PROPAGATION (project-join view)

For an instance of SIDE-EFFECT-FREE DELETION PROPAGATION (project-join view), the relation $R_2(B, C)$ over the attributes $B = 1$ and $C = 2$: the set of tuples with value $b$ at $B$, value $c$ at $C$ and undefined at $A$, one for each pair $(b, c)$ in the second list of the instance. A pair listed twice gives one tuple.
