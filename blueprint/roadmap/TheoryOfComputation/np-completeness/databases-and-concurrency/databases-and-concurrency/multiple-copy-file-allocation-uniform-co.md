# MULTIPLE COPY FILE ALLOCATION WITH UNIFORM COSTS as a decision problem

The decision problem MULTIPLE COPY FILE ALLOCATION WITH UNIFORM COSTS accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quadruples $(n, E, (u, s), K)$, to an instance that is [well-formed](well-formed-9.md) for MULTIPLE COPY FILE ALLOCATION WITH UNIFORM COSTS and feasible for MULTIPLE COPY FILE ALLOCATION. It rejects every bitstring that does not decode to such an instance.
