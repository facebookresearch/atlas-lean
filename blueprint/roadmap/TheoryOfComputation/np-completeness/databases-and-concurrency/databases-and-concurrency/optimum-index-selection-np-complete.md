# OPTIMUM INDEX SELECTION is NP-complete

The decision problem OPTIMUM INDEX SELECTION belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- D. Comer, "The difficulty of optimum index selection", ACM Transactions on Database Systems 3 (1978), 440-445, doi:10.1145/320289.320296 (read in the report version, Purdue University Computer Sciences Department, CSD-TR 248, September 1977), Section 2 (the Optimum Index Selection Problem, OISP) and Theorem 1 (OISP is NP-complete, by a reduction from 3-SAT that builds a file with attribute values `0` and `1`).
