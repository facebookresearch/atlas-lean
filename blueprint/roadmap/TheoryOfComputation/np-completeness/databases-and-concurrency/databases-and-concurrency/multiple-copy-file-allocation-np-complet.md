# MULTIPLE COPY FILE ALLOCATION is NP-complete

The decision problem MULTIPLE COPY FILE ALLOCATION belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [SR6] MULTIPLE COPY FILE ALLOCATION (p. 227; transformation from VERTEX COVER), credited there to [Van Sickle and Chandy, 1977], "The complexity of computer network design problems", listed in the book's bibliography as an unpublished manuscript.
