# Instances of ADDITIONAL KEY

An instance is a quadruple $(n, F, R, K)$: the attribute names are $0, \dots, n - 1$; $F$ is a list of functional dependencies, each a pair of lists of names; $R$ is a list of names; and $K$ is a list of known keys, each a list of names. Wherever a list of names stands for a set of attributes, it is read as the set of names below $n$ that it lists, so order and repetition do not matter.
