# CONJUNCTIVE QUERY FOLDABILITY as a decision problem

The decision problem CONJUNCTIVE QUERY FOLDABILITY accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of sextuples $(|D|, R, |X|, |Y|, Q_1, Q_2)$, to an instance that is [well-formed](well-formed-5.md) and [feasible](conjunctive-query-foldability-feasible.md) for CONJUNCTIVE QUERY FOLDABILITY. It rejects every bitstring that does not decode to such an instance.
