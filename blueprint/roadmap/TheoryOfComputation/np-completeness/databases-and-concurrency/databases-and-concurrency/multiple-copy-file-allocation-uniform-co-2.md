# MULTIPLE COPY FILE ALLOCATION WITH UNIFORM COSTS is NP-complete

The decision problem MULTIPLE COPY FILE ALLOCATION WITH UNIFORM COSTS belongs to NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

## Sources

- M. R. Garey and D. S. Johnson, *Computers and Intractability: A Guide to the Theory of NP-Completeness*, W. H. Freeman (1979), problem [SR6] MULTIPLE COPY FILE ALLOCATION, p. 227, comment: "NP-complete in the strong sense, even if all v ∈ V have the same value of u(v) and the same value of s(v)", credited there to [Van Sickle and Chandy, 1977], "The complexity of computer network design problems", listed in the book's bibliography as an unpublished manuscript.
