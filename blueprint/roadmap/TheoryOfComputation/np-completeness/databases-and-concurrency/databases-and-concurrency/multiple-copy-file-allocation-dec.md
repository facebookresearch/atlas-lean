# MULTIPLE COPY FILE ALLOCATION as a decision problem

The decision problem MULTIPLE COPY FILE ALLOCATION accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quadruples $(n, E, (u, s), K)$, to an instance that is [well-formed](well-formed-10.md) and [feasible](multiple-copy-file-allocation-feasible.md) for MULTIPLE COPY FILE ALLOCATION. It rejects every bitstring that does not decode to such an instance.
