# Well-formed instances of MULTIPLE COPY FILE ALLOCATION WITH UNIFORM COSTS

An instance is well-formed when the edge list describes a simple graph on $\{0, \dots, n-1\}$ (no repeated or reversed edge, no loop, endpoints in range), there is one positive pair $(u(v), s(v))$ per vertex, and $K > 0$, and all vertices have the same usage and the same storage cost.
