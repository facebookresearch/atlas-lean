# CONJUNCTIVE QUERY CONTAINMENT as a decision problem

The decision problem CONJUNCTIVE QUERY CONTAINMENT accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of pairs of conjunctive queries, to an instance that is [well-formed](well-formed-4.md) and [feasible](conjunctive-query-containment-feasible.md) for CONJUNCTIVE QUERY CONTAINMENT. It rejects every bitstring that does not decode to such an instance.
