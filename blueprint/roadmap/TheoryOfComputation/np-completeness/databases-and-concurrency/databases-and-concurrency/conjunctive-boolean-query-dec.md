# CONJUNCTIVE BOOLEAN QUERY as a decision problem

The decision problem CONJUNCTIVE BOOLEAN QUERY accepts a bitstring $x$ exactly when $x$ decodes, under the canonical bitstring encoding of quadruples $(|D|, R, l, Q)$, to an instance that is well-formed and feasible for CONJUNCTIVE BOOLEAN QUERY. It rejects every bitstring that does not decode to such an instance.
