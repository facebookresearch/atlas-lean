# Feasible instances of ROOTED TREE STORAGE ASSIGNMENT

An instance of ROOTED TREE STORAGE ASSIGNMENT is feasible when there are supersets $X_i' ⊇ X_i$ with at most $K$ added elements in total, and a tree $T$ on $X$ with root $r$ in which every $X_i'$ is the vertex set of a simple path $p$ from $u$ to $v$ running away from the root ($dist(r, v) = dist(r, u) + length(p)$).
