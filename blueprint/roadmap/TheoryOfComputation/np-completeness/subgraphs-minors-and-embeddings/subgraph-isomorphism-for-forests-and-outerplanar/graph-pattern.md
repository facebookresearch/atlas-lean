# Pattern graph `H` of the instance in SUBGRAPH ISOMORPHISM for connected outerplanar graphs

For an instance `i` of SUBGRAPH ISOMORPHISM for connected outerplanar graphs, the pattern graph `H` of `i`. It is the [graph of an edge list](../../graph-coloring-and-partitioning/graph-3-coloring/part-01/edge-graph.md) on these vertices and pairs.
