# Feasible instances of UNIT-LENGTH TREE EMBEDDING IN THE GRID

An instance $(n, E)$ of UNIT-LENGTH TREE EMBEDDING IN THE GRID is feasible when its graph is contained in the infinite square grid. The graph has vertices $0, \dots, n - 1$, and distinct vertices $u$ and $v$ are adjacent when $(u, v)$ or $(v, u)$ belongs to $E$; pairs with an endpoint at least $n$ contribute no edge. Containment means that there is an injective map $f$ from $\{0, \dots, n - 1\}$ to $\mathbb{Z}^2$ such that $f(u)$ and $f(v)$ are at Manhattan distance $1$ (they differ by $1$ in exactly one coordinate) for every edge $uv$ of the graph. Feasibility does not require the graph to be a tree: the $4$-cycle maps onto the corners of a unit grid square, so it is feasible although it is not well formed. Feasibility does not include well-formedness; the decision problem requires both.
