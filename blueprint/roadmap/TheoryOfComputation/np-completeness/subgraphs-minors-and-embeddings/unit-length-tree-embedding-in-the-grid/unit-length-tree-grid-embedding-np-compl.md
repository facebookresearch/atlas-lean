# UNIT-LENGTH TREE EMBEDDING IN THE GRID is NP-complete

The UNIT-LENGTH TREE EMBEDDING IN THE GRID decision problem lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

Instance: a tree `T`. Question: can `T` be embedded in the infinite square grid with all edges of unit length, that is, is `T` isomorphic to a subgraph of the grid (a *partial grid graph*)?
