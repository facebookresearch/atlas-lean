# TREE MINOR CONTAINMENT is NP-complete

The TREE MINOR CONTAINMENT decision problem lies in NP, and every decision problem in NP has a polynomial-time many-one reduction to it.

Instance: trees `G` and `H`. Question: does `G` contain `H` as a minor?

## Sources
