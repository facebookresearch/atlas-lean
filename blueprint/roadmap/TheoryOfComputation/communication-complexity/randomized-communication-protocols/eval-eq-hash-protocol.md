# Output of the random-hash protocol

$\mathrm{EQ}_n : \{0,1\}^n \times \{0,1\}^n \to \{0, 1\}$ is the equality function ($1$ exactly when $x = y$). Here protocols have inputs $X = Y = \{0,1\}^n$. A (deterministic) protocol is a finite binary tree whose leaves carry output bits and whose internal nodes are owned by Alice, labelled by a map $X \to \{0, 1\}$, or by Bob, labelled by a map $Y \to \{0, 1\}$; on inputs $(x, y)$ the run follows the announced bits from the root to a leaf, whose bit is the output, and the depth is the maximal number of bits announced along a root-to-leaf path. The random-hash protocol for $\mathrm{EQ}_n$ with parameter $k$ is the public-coin protocol whose random strings are all maps $h : \{0,1\}^n \to \{0,1\}^k$: given $h$, Alice announces the $k$ bits of $h(x)$ one at a time, then Bob announces $1$ if the message equals $h(y)$ and $0$ otherwise, and the leaf outputs Bob's bit. For all $n, k \in \mathbb{N}$, every map $h : \{0,1\}^n \to \{0,1\}^k$ and all $x, y \in \{0,1\}^n$, the
protocol run with random string $h$ outputs $1$ on $(x, y)$ if and only if $h(x) = h(y)$.
