# Collision count of a uniformly random function

Let $A$ and $B$ be finite sets and $a, b \in A$ with $a \ne b$. Then the number of maps $h : A \to B$ with
$h(a) = h(b)$, multiplied by $|B|$, equals the number $|B|^{|A|}$ of all maps $A \to B$. So exactly a fraction
$1/|B|$ of the maps collide on $a$ and $b$ (when $B$ is nonempty).
