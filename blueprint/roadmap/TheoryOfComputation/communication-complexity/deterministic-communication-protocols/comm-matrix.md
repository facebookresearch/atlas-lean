# Communication matrix

Let $X$ and $Y$ be sets (the inputs of Alice and of Bob). Let $K$ be a set with distinguished elements $0$ and $1$ (for instance a ring). For $f : X \times Y \to
\{0, 1\}$, the communication matrix of $f$ over $K$ is the matrix with rows indexed by $X$ and columns by $Y$
whose $(x, y)$ entry is $1$ if $f(x, y) = 1$ and $0$ otherwise.
