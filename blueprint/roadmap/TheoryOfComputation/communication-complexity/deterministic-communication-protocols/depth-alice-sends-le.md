# Cost of sending a $b$-bit message

Let $X$ and $Y$ be sets (the inputs of Alice and of Bob). A protocol is a finite binary tree whose leaves are labelled by bits and whose internal nodes are each owned by Alice, labelled by a map $X \to \{0, 1\}$, or by Bob, labelled by a map $Y \to \{0, 1\}$, with a $0$-child and a $1$-child. On inputs $(x, y)$ the run starts at the root; at an Alice node with map $a$ the bit $a(x)$ is announced and the run moves to the child with that bit, at a Bob node with map $b$ the bit $b(y)$ is announced likewise; the output is the label of the leaf reached. The depth of a protocol is the maximal number of bits announced along a root-to-leaf path ($0$ for a leaf). For $b \in \mathbb{N}$, a map $v : X \to \{0,1\}^b$ and protocols $k_m$ indexed by messages $m \in \{0,1\}^b$, the protocol in which Alice sends $v$ and then continues with $k$ consists of $b$ Alice nodes announcing the bits $v(x)_0, \dots, v(x)_{b-1}$ in order, followed by the protocol $k_m$ for the announced message $m$ (just $k_m$ for the empty message if $b = 0$). Let $d \in \mathbb{N}$ be such that every $k_m$ has depth at most $d$. Then the protocol in
which Alice sends $v$ and continues with $k$ has depth at most $b + d$.
