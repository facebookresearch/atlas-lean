# Huang's sensitivity theorem

Every induced subgraph of the $n$-dimensional hypercube $Q_n$ on $2^{n-1} + 1$ vertices has maximum degree at least $\sqrt{n}$. Consequently, for every Boolean function $f$, $bs(f) \le s(f)^4$ and $\deg(f) \le s(f)^2$, so sensitivity is polynomially related to block sensitivity, certificate complexity, decision-tree depth and degree.
