# Theorem 38.11 (Borsuk-Ulam)

Think of $S^{n}$ as the unit vectors in $\mathbb{R}^{n+1}$. For any continuous function $f \colon S^{n} \rightarrow \mathbb{R}^{n}$, there exists $x \in S^{n}$ such that $f(x) = f(-x)$.
