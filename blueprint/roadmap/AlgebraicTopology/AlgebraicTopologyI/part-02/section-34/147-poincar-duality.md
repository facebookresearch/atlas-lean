# Theorem 34.2 (Poincaré duality)

Let $M$ be a topological $n$-manifold that is compact and oriented with respect to a PID $R$. Then there is a unique class $[M] \in H_{n}(M; R)$ that restricts to the orientation class in $H_{n}(M, M - a; R)$ for every $a \in M$. It has the property that $- \cap [M] \colon H^{p}(M; R) \rightarrow H_{q}(M; R)$, $p + q = n$, is an isomorphism for all $p$.
