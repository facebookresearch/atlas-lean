# Theorem 31.5 (Unique path lifting)

Let $p \colon E \rightarrow B$ be a covering space, and $\omega \colon I \rightarrow B$ a path in the base. For any $e \in E$ such that $p(e) = \omega(0)$, there is a unique path $\widetilde{\omega} \colon I \rightarrow E$ in $E$ such that $p\widetilde{\omega} = \omega$ and $\widetilde{\omega}(0) = e$.
