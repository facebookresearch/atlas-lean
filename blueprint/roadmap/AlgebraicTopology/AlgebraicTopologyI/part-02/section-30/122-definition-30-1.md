# Definition 30.1

A (topological) manifold is a Hausdorff space such that every point has an open neighborhood that is homeomorphic to some (finite dimensional) Euclidean space. If all these Euclidean spaces can be chosen to be $\mathbb{R}^{n}$, we have an $n$-manifold.
