# Proposition 10.4

Let $n > 0$ and let $* \in S^{n-1}$ be any point. Then: $H_{q}(S^{n}) = \begin{cases} \mathbb{Z} = \langle[\partial \iota_{n+1}]\rangle & \text{if } q = n > 0 \\ \mathbb{Z} = \langle[c_{*}^{0}]\rangle & \text{if } q = 0,\, n > 0 \\ \mathbb{Z} \oplus \mathbb{Z} = \langle[c_{*}^{0}],[\partial \iota_{1}]\rangle & \text{if } q = n = 0 \\ 0 & \text{otherwise} \end{cases}$ and $H_{q}(D^{n}, S^{n-1}) = \begin{cases} \mathbb{Z} = \langle[\iota_{n}]\rangle & \text{if } q = n \\ 0 & \text{otherwise} \end{cases}$
