# Definition 14.7

A CW-complex is finite-dimensional if $\operatorname{Sk}_{n} X = X$ for some $n$; of finite type if each $A_{n}$ is finite, i.e., finitely many cells in each dimension; and finite if it's finite-dimensional and of finite type.
