# Definition 20.1

Given three $R$-modules, $M, N, P$, a bilinear map (or, to be explicit, $R$-bilinear map) is a function $\beta \colon M \times N \rightarrow P$ such that $\beta(x + x', y) = \beta(x, y) + \beta(x', y)$, $\beta(x, y + y') = \beta(x, y) + \beta(x, y')$ and $\beta(rx, y) = r\beta(x, y)$, $\beta(x, ry) = r\beta(x, y)$, for $x, x' \in M$, $y, y' \in N$, and $r \in R$.
