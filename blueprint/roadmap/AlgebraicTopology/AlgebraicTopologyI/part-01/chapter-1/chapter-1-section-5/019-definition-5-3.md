# Definition 5.3

The homotopy category (of topological spaces) $\operatorname{Ho}(\mathbf{Top})$ has the same objects as $\mathbf{Top}$, but $\operatorname{Ho}(\mathbf{Top})(X, Y) = [X, Y] = \mathbf{Top}(X, Y) / {\simeq}$.
