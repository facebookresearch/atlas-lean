# The class $\ell(c)$

For a function $c$ on subsets of the ground set, $\ell(c)$ is the class of
$\sum_F c_F \, x_F$ in $A^1(M)_\mathbb{R}$, the sum over all nonempty proper flats $F$ (for an infinite matroid, a sum with infinitely many nonzero terms is taken to be $0$). When $c$ is strictly submodular, $\ell(c)$ is the Lefschetz class of the hard
Lefschetz theorem and the Hodge–Riemann relations.
