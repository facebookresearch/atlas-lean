# The class $\beta_M$ does not depend on the element

For a finite matroid $M$ and elements $i, j$ of its ground set,
$\beta_{M,i} = \beta_{M,j}$ in the Chow ring: subtract $\alpha_{M,i} = \alpha_{M,j}$ from
$\alpha_{M,i} + \beta_{M,i} = \sum_F x_F = \alpha_{M,j} + \beta_{M,j}$.
