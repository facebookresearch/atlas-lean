# A strictly submodular function

For a finite matroid on $E$, the function $I \mapsto |I| \, |E \setminus I|$ is strictly
submodular. In particular strictly submodular functions exist, so the hypotheses of the hard
Lefschetz theorem and the Hodge–Riemann relations can be met.

If $I_1, I_2$ are incomparable, write $x = |I_1 \cap I_2|$, $p = |I_1 \setminus I_2|$
and $q = |I_2 \setminus I_1|$, so $p, q \ge 1$. The difference
$c(I_1) + c(I_2) - c(I_1 \cap I_2) - c(I_1 \cup I_2)$ equals $2pq > 0$.
