# The Lefschetz class has degree one

For every function $c$ on subsets of the ground set, the class
$\ell(c) = \sum_F c_F \, x_F$ lies in $A^1(M)_\mathbb{R}$. This is where the hard Lefschetz
theorem and the Hodge–Riemann relations use it: multiplication by $\ell(c)^{r-2q}$ maps
$A^q(M)_\mathbb{R}$ into $A^{r-q}(M)_\mathbb{R}$.
