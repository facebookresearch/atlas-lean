# The class $\alpha_M$

For an element $i$ of the ground set, $\alpha_{M,i} = \sum_{F \ni i} x_F$, the sum over the nonempty proper flats containing $i$ (for an infinite matroid, a sum with infinitely many nonzero terms is taken to be $0$). By the linear relations its class $\alpha_M$ in
$A^1(M)_\mathbb{R}$ does not depend on $i$. The class $\alpha_M$ is nef
(AHK Lemma 9.7), and for a loopless matroid of rank $r + 1$ the class $\alpha_M^r$ has
degree $1$ (AHK Proposition 5.10).
