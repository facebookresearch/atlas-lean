# The class $\alpha_M$ does not depend on the element

For elements $i, j$ of the ground set, $\sum_{F \ni i} x_F = \sum_{F \ni j} x_F$ in the
Chow ring; this is a generator of the ideal $J_M$ when $i \ne j$.
