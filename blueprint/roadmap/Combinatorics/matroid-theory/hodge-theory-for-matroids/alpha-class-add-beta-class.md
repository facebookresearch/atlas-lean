# The classes $\alpha_M$ and $\beta_M$ add up to the sum of all generators

For a finite matroid $M$ and every element $i$,

$$\alpha_{M,i} + \beta_{M,i} = \sum_{F} x_F,$$

the sum over all nonempty proper flats, since each flat either contains $i$ or does not.

## Sources

- K. Adiprasito, J. Huh and E. Katz, *Hodge theory for combinatorial geometries*, Ann. of
  Math. 188 (2018), 381–452, Definition 5.7, https://arxiv.org/abs/1511.02888.
