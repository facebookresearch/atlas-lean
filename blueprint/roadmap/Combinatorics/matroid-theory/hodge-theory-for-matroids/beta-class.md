# The class $\beta_M$

For an element $i$ of the ground set, $\beta_{M,i} = \sum_{F \not\ni i} x_F$, the sum over the nonempty proper flats not containing $i$ (for an infinite matroid, a sum with infinitely many nonzero terms is taken to be $0$). For a finite matroid its class $\beta_M$ in $A^1(M)_\mathbb{R}$ does not depend on $i$, since $\alpha_{M,i} + \beta_{M,i}$ is the
sum of all the $x_F$. The class $\beta_M$ is nef (AHK Lemma 9.7).
