# Indicator vector of a finite set

For a finite set $B \subseteq \iota$, its indicator vector is the zero-one vector
$e_B = \sum_{i \in B} e_i \in \mathbb{N}^\iota$, whose $i$-th coordinate is $1$ if $i \in B$
and $0$ otherwise. Brändén and Huh identify a subset $S \subseteq [n]$ with this vector, and
write $w^S$ for the square-free monomial $\prod_{i \in S} w_i = w^{e_S}$.

## Sources

- P. Brändén and J. Huh, *Lorentzian polynomials*, Ann. of Math. 192 (2020), 821–891,
