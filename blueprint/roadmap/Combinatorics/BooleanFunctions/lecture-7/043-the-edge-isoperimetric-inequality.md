# Theorem 3.1 (The edge isoperimetric inequality)

For all $f \colon \{-1,1\}^n \to \{-1,1\}$ it holds that $$I[f] \geqslant \Pr[f(x) = -1] \log \left(\frac{1}{\Pr[f(x) = -1]}\right).$$
