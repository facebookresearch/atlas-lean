# Definition 1.3

Let $0 \leqslant p < 1/2$. The $p$-biased Kneser graph is a graph whose vertex set is $\mathcal{P}([n])$, and the weight of a set $A$ is $\mu_p(A) = p^{|A|}(1-p)^{n-|A|}$. The edges of the graph are $E = \{(A, B) \mid A \cap B = \emptyset\}$.
