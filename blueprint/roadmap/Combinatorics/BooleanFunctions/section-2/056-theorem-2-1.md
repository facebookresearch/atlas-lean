# Theorem 2.1 (Section 2.1, Set up (Arrow's impossibility theorem))

[Arrow's impossibility theorem] Suppose $f \colon \{-1,1\}^n \to \{-1,1\}$ is an unanimous voting rule, i.e. such that $f(\vec{1}) = 1$, $f(-\vec{1}) = -1$. If in 3-candidate election $f$ always has a Condorcet winner, then $f$ is a dictatorship.
