# Definition 0.1

For any $p \geqslant 1$ we define the $L^p$ norm of $f \colon \{-1,1\}^n \to \mathbb{R}$ as $$\|f\|_p = \left( \underset{x \sim \{-1,1\}^n}{\mathbb{E}} [|f(x)|^p] \right)^{1/p}.$$
