# Claim 2.1 (Lecture 3, Section 2)

For all $\varepsilon, \delta > 0$, there is $q = O\left(\frac{\log(1/\delta)}{\varepsilon^2}\right)$ and an algorithm performing the following task. Given membership queries to $f \colon \{-1,1\}^n \to [-1,1]$, and sets $T \subseteq J \subseteq [n]$, the algorithm outputs a number $b_{T,J}$ such that $\Pr\left[ \left| b_{T,J} - \sum_{S \colon S \cap J = T} \widehat{f}(S)^2 \right| \geqslant \varepsilon \right] \leqslant \delta$.
