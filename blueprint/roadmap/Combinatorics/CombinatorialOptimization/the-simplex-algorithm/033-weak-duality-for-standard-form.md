# Theorem 2 (weak duality for standard form)

For the standard-form primal-dual pair (P) $\max\{c^\top x \mid Ax = b,\; x \geq 0\}$ and (D) $\min\{b^\top y \mid A^\top y \geq c\}$, if both (P) and (D) are feasible then $\operatorname{opt}(P) \leq \operatorname{opt}(D)$ and both optima are finite. In particular (P) is bounded.
