# Theorem 1 (Menger)

A directed graph $G = (V, E)$ admits $k$ edge-disjoint paths from a source $s$ to a sink $t$ if and only if $k$ is at most the size of every directed $s$-$t$ cut; equivalently, the maximum number of edge-disjoint $s$-$t$ paths equals the size of the minimum directed $s$-$t$ cut.
