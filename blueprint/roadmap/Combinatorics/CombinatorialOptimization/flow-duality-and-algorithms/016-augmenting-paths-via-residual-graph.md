# Claim 1 (augmenting paths via residual graph)

An augmenting path for a flow $f$ in $G$ corresponds to a directed $s$-$t$ path in the residual graph $\operatorname{Res}(G)$, and conversely every directed $s$-$t$ path in $\operatorname{Res}(G)$ corresponds to an $f$-augmenting path in $G$.
