# Theorem 5 (large augmenting path exists)

Let $f$ be a flow of value $f$ in a directed network with $m$ edges and let $f^*$ be the value of the maximum flow. There exists an $f$-augmenting path $P$ in the residual graph with capacity $c(P) \geq (f^* - f) / m$.
