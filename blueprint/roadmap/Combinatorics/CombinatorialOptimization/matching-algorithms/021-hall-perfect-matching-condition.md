# Theorem 1 (Hall, perfect matching condition)

Let $G$ be a bipartite graph with vertex partition $(A, B)$. Then $G$ has a perfect matching if and only if $|A| = |B|$ and for every $U \subseteq A$, $|N(U)| \geq |U|$, where $N(U)$ is the set of vertices in $B$ adjacent to some vertex in $U$.
