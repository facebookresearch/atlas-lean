# Theorem 10 (Edmonds' algorithm running time)

A maximum matching in an arbitrary undirected graph $G$ with $n$ vertices and $m$ edges can be computed in time $O(n^4)$ (more precisely $O(m n^2)$) by Edmonds' blossom algorithm.
