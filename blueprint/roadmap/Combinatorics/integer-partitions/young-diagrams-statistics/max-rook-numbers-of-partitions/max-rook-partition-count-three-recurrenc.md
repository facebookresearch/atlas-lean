# Linear recurrence for $R_3(n)$

Let $R_3(n)$ be the number of partitions of $n$ with
max-rook number $3$. For every natural number $n > 14$,
$R_3(n) = 2R_3(n-1) - R_3(n-2) + R_3(n-3) - 2R_3(n-4) + R_3(n-5)$.

## Sources
