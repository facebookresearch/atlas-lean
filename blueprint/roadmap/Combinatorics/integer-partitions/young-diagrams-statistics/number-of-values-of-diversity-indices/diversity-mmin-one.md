# Value of the lower maximal-frequency bound at homozygosity 1

The function $M_{\min}(J) = \frac{1}{c}\left(1 + \sqrt{(cJ - 1)/(c - 1)}\right)$ with $c = \lceil 1/J \rceil$ satisfies $M_{\min}(1) = 1$. Here $c = 1$, and the quotient $(cJ - 1)/(c - 1) = 0/0$ is read as $0$ under the convention $x/0 = 0$.
