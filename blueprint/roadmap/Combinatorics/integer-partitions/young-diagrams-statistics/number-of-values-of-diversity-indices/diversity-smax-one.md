# Value of the upper Shannon bound at maximal frequency 1

For every natural number $I$, the function $S_{\max}(I, M) = M \log(1/M) + (1 - M) \log((I - 1)/(1 - M))$ satisfies $S_{\max}(I, 1) = 0$: the first term is $\log 1 = 0$ and the second has the factor $1 - M = 0$.
