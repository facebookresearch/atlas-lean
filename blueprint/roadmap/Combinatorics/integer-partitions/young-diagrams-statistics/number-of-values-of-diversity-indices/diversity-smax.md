# Upper bounding function for the Shannon index given the maximal frequency

For a natural number $I$ and a real number $M$, the function $S_{\max}$ is

$$S_{\max}(I, M) = M \log \frac{1}{M} + (1 - M) \log \frac{I - 1}{1 - M}.$$

Here $\log$ is the natural logarithm with $\log 0 = 0$ and $\log x = \log |x|$ for $x < 0$, and $1/0 = 0$ and $x/0 = 0$.
