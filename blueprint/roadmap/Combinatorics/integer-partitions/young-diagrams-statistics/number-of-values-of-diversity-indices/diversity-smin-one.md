# Value of the lower Shannon bound at maximal frequency 1

The function $S_{\min}(M) = fM \log(1/M) + (1 - fM) \log(1/(1 - fM))$ with $f = \lfloor 1/M \rfloor$ satisfies $S_{\min}(1) = 0$: here $f = 1$, the first term is $\log 1 = 0$ and the second has the factor $1 - fM = 0$.
