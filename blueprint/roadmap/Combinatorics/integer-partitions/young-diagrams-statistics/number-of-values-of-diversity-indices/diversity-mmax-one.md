# Value of the upper maximal-frequency bound at homozygosity 1

For every natural number $I \ge 1$, the function $M_{\max}(I, J) = \frac{1}{I}\left(1 + \sqrt{(IJ - 1)(I - 1)}\right)$ satisfies $M_{\max}(I, 1) = 1$.
