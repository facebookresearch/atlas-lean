# Upper bounding function for the maximal frequency given homozygosity

For a natural number $I$ and a real number $J$, the function $M_{\max}$ is

$$M_{\max}(I, J) = \frac{1}{I} \left( 1 + \sqrt{(I J - 1)(I - 1)} \right).$$

Here $1/0 = 0$ and $x/0 = 0$, and $\sqrt{x} = 0$ for $x < 0$. For a probability vector on $I$ cells with homozygosity $J = \sum_i p_i^2$, $M_{\max}(I, J)$ is the upper bound for the largest entry.
