# Ordered set partition

Let $S$ be a finite set and let $k$ be a natural number. An ordered set partition of $S$ into $k$
blocks is a tuple $(B_1, \dots, B_k)$ of subsets of $S$ such that $B_i \ne \emptyset$ for
$1 \le i \le k$, $B_i \cap B_j = \emptyset$ for $1 \le i, j \le k$ with $i \ne j$, and
$B_1 \cup \dots \cup B_k = S$.

When $k = 0$, the empty tuple is an ordered set partition of $S$ exactly when $S = \emptyset$.
