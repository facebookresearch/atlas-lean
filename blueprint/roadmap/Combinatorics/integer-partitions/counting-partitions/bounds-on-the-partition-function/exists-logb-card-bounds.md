# Logarithmic bounds for the partition function

Let $p(n)$ be the number of integer partitions of $n$ and $c = \pi \sqrt{2/3} / \ln 2$. There exist
real constants $B$ and $C$ such that

$$c \sqrt{n} - B \log_2 n - C \le \log_2 p(n) \quad \text{for every integer } n \ge 1,$$

$$\log_2 p(n) \le c \sqrt{n} + C \quad \text{for every natural number } n.$$

## Sources

- P. Erdős, *On an elementary proof of some asymptotic formulas in the theory of partitions*, Ann. of Math. (2) 43 (1942), no. 3, 437–450, inequality (4) and formula (1); see also (3), $\log p(n) \sim \pi \sqrt{2/3} \sqrt{n}$.
