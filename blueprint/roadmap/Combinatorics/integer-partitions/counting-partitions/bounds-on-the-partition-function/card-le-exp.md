# Exponential upper bound for the partition function

For every natural number $n$, the number $p(n)$ of integer partitions of $n$ satisfies

$$p(n) \le \exp\left(\pi \sqrt{2/3}\, \sqrt{n}\right).$$

## Sources

- P. Erdős, *On an elementary proof of some asymptotic formulas in the theory of partitions*, Ann. of Math. (2) 43 (1942), no. 3, 437–450, inequality (4).
