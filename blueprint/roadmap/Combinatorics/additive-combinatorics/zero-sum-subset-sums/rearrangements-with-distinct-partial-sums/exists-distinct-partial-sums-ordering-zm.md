# Small sets of nonzero residues have orderings with distinct partial sums

Let $p$ be a prime and let $A$ be a set of nonzero elements of $\mathbb{Z}/p\mathbb{Z}$ with
$|A| \le \log p / \log \log p$ (natural logarithms, computed in the reals). Then the elements of
$A$ can be listed as $a_1, \dots, a_k$, each element of $A$ exactly once, so that the partial sums
$a_1,\ a_1 + a_2,\ \dots,\ a_1 + \dots + a_k$ are pairwise distinct.

## Sources

- Noah Kravitz, "Rearranging Small Sets for Distinct Partial Sums", INTEGERS 24 (2024), Article A113, Theorem 1.
