# Weak Sidon set

A set $A \subseteq \mathbb{N}$ is a *weak Sidon set* (or *well spread*) if
sums of two distinct elements of $A$ are distinct: whenever $a, b, c, d \in A$ satisfy $a < b$,
$c < d$ and $a + b = c + d$, then $a = c$.

## Sources

- Andrzej Nowik, *On the Sidon Ideal*, INTEGERS 25 (2025), Article A91, Definition 11.
