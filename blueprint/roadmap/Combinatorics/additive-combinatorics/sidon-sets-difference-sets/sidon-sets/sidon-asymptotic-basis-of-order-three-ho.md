# An infinite Sidon set that is an asymptotic basis of order 3

A set $A$ of natural numbers is a Sidon set when $a + b = c + d$ with $a, b, c, d \in A$ implies $\{a, b\} = \{c, d\}$. There is an infinite Sidon set $A \subseteq \mathbb{N}$ such that all but finitely many natural numbers are sums of three elements of $A$. Pilatte constructed such a set.
