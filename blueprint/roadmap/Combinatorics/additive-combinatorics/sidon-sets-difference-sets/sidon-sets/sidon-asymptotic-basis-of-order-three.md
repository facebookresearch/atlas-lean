# Erdős problem 157: Sidon sets that are asymptotic bases of order 3

A set $A$ of natural numbers is a Sidon set when $a + b = c + d$ with $a, b, c, d \in A$ implies $\{a, b\} = \{c, d\}$. Erdős problem 157 asks whether there is an infinite Sidon set $A \subseteq \mathbb{N}$ that is an asymptotic additive basis of order $3$: all but finitely many natural numbers are sums $a_1 + a_2 + a_3$ of three elements of $A$.
