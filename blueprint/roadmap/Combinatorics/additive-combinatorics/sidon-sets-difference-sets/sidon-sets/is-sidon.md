# Sidon set

Let $M$ be an additive commutative monoid. A set $A \subseteq M$ is a Sidon set if whenever
$a, b, c, d \in A$ satisfy $a + b = c + d$, either $a = c$ and $b = d$, or $a = d$ and $b = c$.
The elements $a, b$ (and $c, d$) need not be distinct, so in particular $2a = 2b$ with
$a, b \in A$ forces $a = b$.
