# Sets with bounded representation counts have Sidon subsets beyond the square root

A set $A$ of natural numbers is a Sidon set when $a + b = c + d$ with $a, b, c, d \in A$ implies $\{a, b\} = \{c, d\}$. For a finite set $A \subseteq \mathbb{N}$, write $1_A * 1_A(m) = \#\{(a, b) \in A \times A : a + b = m\}$ for the number of ordered representations of $m$. For every integer $k \ge 1$ and every real $C$, for all sufficiently large $n$, every $n$-element set $A \subseteq \mathbb{N}$ with $1_A * 1_A(m) \le k$ for all $m$ contains a Sidon subset of size at least $C\sqrt{n}$. Alon and Erdős proved that such a set contains a Sidon subset of size at least $c(k)\, n^{2/3}$.
