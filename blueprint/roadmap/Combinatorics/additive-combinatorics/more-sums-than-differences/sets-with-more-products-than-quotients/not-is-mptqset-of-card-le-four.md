# No MPTQ set has at most four elements

If $A$ is a finite set of at most four real
numbers, then $A$ is not an MPTQ set.

Items 1 and 2 of Theorem 2 of Shetty and Shankar, which restates Chu's Theorem 1.4, together give
this statement: an MPTQ set of positive reals has at least $8$ elements, and an MPTQ set with a
negative element has at least $5$. Chu's proof of item 2 takes a four-element set to have
$13 - 2k$ quotients, an odd number; this fails when $-1$, which is its own inverse, is a quotient,
as for $\{-2, -1, 2, 4\}$, which has $8$ quotients. A set containing a pair $\pm u$ has the two
distinct quotients $1$ and $-1$ of absolute value $1$, so a correct count treats such sets
separately.

## Sources

- Anupriya Shetty and B. R. Shankar, *On The Minimum Cardinality of MPTQ Sets*, INTEGERS 24 (2024), Article A96, Theorem 2, items 1 and 2 (`integers-2024-A96-thm-2`).
- Hùng Việt Chu, *On sets with more products than quotients*, Rocky Mountain J. Math. 50 (2020), 499–512, Theorem 1.4.
