# Erdős Problem 37 (lacunary essential components)

The statement that some lacunary set is an essential component; here a set $A$ of natural numbers is lacunary when it is the set of terms of a sequence $a_0, a_1, \dots$ of positive integers with $a_{n+1} \ge c\, a_n$ for all $n$, for some $c > 1$, and a set $A$ of natural numbers is an essential component when $\sigma((A \cup \{0\}) + (B \cup \{0\})) > \sigma(B)$ for every set $B$ of natural numbers with $0 < \sigma(B) < 1$, where $\sigma$ is the Schnirelmann density, $\sigma(B) = \inf_{n \ge 1} |B \cap \{1, \dots, n\}|/n$.

This page records the statement as a proposition. Its refutation: [No lacunary set is an essential component](lacunary-essential-component-exists-refu.md).
