# Sets with bounded representation counts need not split

It is not the case that for every integer $C \ge 3$ there is $t$ such that every set $A$ of natural numbers with $r_A(n) \le C$ for all $n$ is the disjoint union of $t$ sets $A_1, \dots, A_t$ with $r_{A_i}(n) < C$ for all $i$ and $n$; here $r_A(n)$ is the number of ordered pairs $(a, b) \in A \times A$ with $a + b = n$.

This refutes [Erdős Problem 328 (splitting sets with bounded representation counts)](bounded-representation-partition.md), the statement recorded as a proposition; the refutation is the published work cited under Sources.
