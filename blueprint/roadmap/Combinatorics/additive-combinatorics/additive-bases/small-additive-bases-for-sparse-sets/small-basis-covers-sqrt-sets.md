# Erdős Problem 806 (Erdős–Newman problem on small bases)

The statement that for every real $\varepsilon > 0$ and all sufficiently large $n$, every set $A \subseteq \{1, \dots, n\}$ of integers with $|A| \le \sqrt n$ satisfies $A \subseteq B + B$ for some set $B$ of integers with $|B| \le \varepsilon\sqrt n$.

This page records the statement as a proposition. Its resolution: [Sets of size square root of n have small bases](small-basis-covers-sqrt-sets-holds.md).
