# Lemma 4.5

Suppose there exists a linear transformation $U: \mathbb{R} P_{i} \rightarrow \mathbb{R} P_{i+1}$ satisfying: (1) $U$ is one-to-one, and (2) for all $x \in P_{i}$, $U(x)$ is a linear combination of elements $y \in P_{i+1}$ satisfying $x < y$ (i.e., $U$ is an order-raising operator). Then there exists an order-matching $\mu: P_{i} \rightarrow P_{i+1}$. Similarly, suppose there exists a linear transformation $U: \mathbb{R} P_{i} \rightarrow \mathbb{R} P_{i+1}$ satisfying: (1) $U$ is onto, and (2) $U$ is an order-raising operator. Then there exists an order-matching $\mu: P_{i+1} \rightarrow P_{i}$.
