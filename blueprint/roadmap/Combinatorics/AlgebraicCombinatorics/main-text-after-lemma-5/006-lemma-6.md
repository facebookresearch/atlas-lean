# Lemma 6

For all $0 \leq j \leq n-1$ there is an integer $h_{j} \geq 0$ such that $a_{0} + a_{1} \zeta^{j} + a_{2} \zeta^{2j} + \cdots + a_{n-1} \zeta^{(n-1)j} = v_{j}(1 - \zeta)^{h_{j}}$, where $v_{j}$ is a unit in $\mathbb{Z}[\zeta]$.
