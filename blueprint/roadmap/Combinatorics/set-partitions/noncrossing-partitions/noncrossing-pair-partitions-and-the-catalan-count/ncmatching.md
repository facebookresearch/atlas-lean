# Noncrossing perfect matchings on $n$ points

For a natural number $n$, this is the set of functions $f : \mathbb{N} \to \mathbb{N}$ that are
[noncrossing perfect matchings](is-ncmatching.md) of $\{0, \dots, n-1\}$. It is finite, since such a
matching is the identity from $n$ on and so is determined by its restriction to
$\{0, \dots, n-1\}$; its number of elements is computed in
[Counting noncrossing perfect matchings](card-nc-matching.md).
