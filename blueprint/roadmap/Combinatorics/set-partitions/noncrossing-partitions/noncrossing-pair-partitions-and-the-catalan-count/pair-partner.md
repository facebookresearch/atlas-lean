# Partner map of a pair partition

For a set partition $P$ of $\{0, \dots, n-1\}$ and $i < n$, the partner of $i$ is
$\bigl(\sum_{x \in B(i)} x\bigr) - i$, where $B(i)$ is the block of $i$; for $i \ge n$ it is $i$.
When $P$ is a [pair partition](is-pair-partition.md), $B(i) = \{i, j\}$ with $j \ne i$, so the
partner of $i$ is $j$. The sum formula defines the partner for every set partition, without
choosing an element of the block.
