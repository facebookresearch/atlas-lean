# The pair partition of a matching

For a [noncrossing perfect matching](is-ncmatching.md) $f$ of $\{0, \dots, n-1\}$, this is the
partition of $\{0, \dots, n-1\}$ whose blocks are the arcs $\{i, f(i)\}$. Its blocks are the classes of the equivalence
relation "$y = x$ or $y = f(x)$", which is an equivalence relation because $f$ is an involution. It
is a noncrossing pair partition.
