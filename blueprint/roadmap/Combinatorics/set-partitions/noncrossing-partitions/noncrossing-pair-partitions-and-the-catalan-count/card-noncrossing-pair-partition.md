# Counting noncrossing pair partitions

For every $n$, the number of noncrossing pair partitions of $\{1, \dots, n\}$ is $C_{n/2}$ if $n$ is
even and $0$ if $n$ is odd. This is the form used for the moments of the semicircle law, which are
$\int x^n \, d\sigma(x) = \#\{\pi \in NC(n) : \pi \text{ a pair partition}\}$ for all $n$.
