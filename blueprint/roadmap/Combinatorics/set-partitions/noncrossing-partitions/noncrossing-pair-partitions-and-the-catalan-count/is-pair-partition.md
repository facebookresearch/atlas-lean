# Pair partition

A set partition $P$ of $\{0, \dots, n-1\}$ is a *pair partition* if
every block of $P$ has exactly two elements. A pair partition exists only when $n$ is even, and
for $n = 2k$ the pair partitions are the perfect matchings of $2k$ points; the noncrossing ones are
counted by the Catalan number $C_k$.

## Sources

- Greg W. Anderson, Alice Guionnet and Ofer Zeitouni, *An Introduction to Random Matrices*, Cambridge
