# No noncrossing pair partition of an odd number of points

For every $k \ge 0$, there is no noncrossing pair partition of $\{0, \dots, 2k\}$: the number of
noncrossing partitions of this set all of whose blocks have two elements is $0$. This is the
combinatorial reason why the odd moments of the semicircle law vanish and why only even powers
contribute in the moment method.
