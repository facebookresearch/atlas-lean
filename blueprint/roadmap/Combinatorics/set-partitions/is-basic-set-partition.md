# Basic set partition

A partition $P$ of $\{1, \dots, n\}$ is basic when its blocks can
 be listed without repetition as $B_1, \dots, B_k$ with $|B_1| \ge |B_2| \ge \dots \ge |B_k|$
 so that $B_1 \cup \dots \cup B_i = \{1, \dots, |B_1| + \dots + |B_i|\}$ for every $i$ with
 $1 \le i \le k$.
