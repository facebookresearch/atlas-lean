# Bell numbers count set partitions

For every finite set $s$, the number of partitions of $s$ into non-empty, pairwise disjoint blocks whose union is $s$ is the Bell number $B_{|s|}$, where

$$B_0 = 1, \qquad B_{n+1} = \sum_{i=0}^{n} \binom{n}{i} B_{n-i}.$$

For $s = \emptyset$ the only partition is the one with no blocks, and $B_0 = 1$.
