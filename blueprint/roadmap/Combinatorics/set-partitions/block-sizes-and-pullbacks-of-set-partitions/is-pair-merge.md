# Merging two blocks of a set partition

A partition of a finite set $s$ is a set of non-empty, pairwise disjoint subsets of $s$ (its blocks) whose union is $s$. For partitions $P$ and $Q$ of $s$, $Q$ is obtained from $P$ by merging two blocks when $P$ refines $Q$ (every block of $P$ is contained in a block of $Q$) and $Q$ has exactly one block fewer than $P$.
