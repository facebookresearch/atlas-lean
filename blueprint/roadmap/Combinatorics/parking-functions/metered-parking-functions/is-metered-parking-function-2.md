# Classical parking functions are metered parking functions

Let $m \le n$. Every partial
parking function $f$ with $m$ cars and $n$ spots is a $t$-metered parking function for every
$t \in \mathbb{N}$.

## Sources

- Spencer Daugherty, Pamela E. Harris, Ian Klein, and Matt McClinton, *Metered Parking Functions*, INTEGERS 25 (2025), Article A73, Proposition 4 (`integers-2025-A73-prop-4`).
