# The affine dependence map of a spanning configuration is surjective

If $v_1, \dots, v_n$ affinely span $E$, then every $(x, c) \in E \times \mathbb{R}$ equals
$\bigl(\sum_i \lambda_i v_i, \sum_i \lambda_i\bigr)$ for some $\lambda \in \mathbb{R}^n$: write
$x = \sum_i a_i v_i$ and $0 = \sum_i b_i v_i$ with $\sum_i a_i = \sum_i b_i = 1$, and take
$\lambda = a + (c - 1) b$.
