# Gale's evenness condition

A set $S \subseteq \{0, 1, \dots, n - 1\}$ satisfies Gale's evenness condition if for any two
indices $j < k$ not in $S$, the number of elements $i \in S$ with $j < i < k$ is even. For
example, with $n = 4$ the sets $\{0, 1\}$, $\{1, 2\}$, $\{2, 3\}$ and $\{0, 3\}$ satisfy it and
$\{0, 2\}$, $\{1, 3\}$ do not: these are the edges and the diagonals of a convex quadrilateral.
