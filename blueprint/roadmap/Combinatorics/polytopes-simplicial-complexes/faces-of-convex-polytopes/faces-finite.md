# A polytope has finitely many faces

For every finite set $s$, the set of faces of $P = \operatorname{conv} s$ is finite: each face is
$\operatorname{conv} T$ for a subset $T \subseteq s$, so there are at most $2^{|s|}$ of them.
This makes the face numbers, which are counts of faces, meaningful.
