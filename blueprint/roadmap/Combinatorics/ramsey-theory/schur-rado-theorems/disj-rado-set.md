# Admissible bounds of a disjunctive Rado problem

Let $m$ be a natural number, $a$ an integer and $C$ a finite set of integers. The set of admissible bounds is the set of natural numbers $R \ge 1$ such that every $2$-coloring of $\{1, \dots, R\}$ admits, for some $c \in C$, a monochromatic solution $x_1, \dots, x_{m-2}, y, z \in \{1, \dots, R\}$ of

$$x_1 + \dots + x_{m-2} + a y - z = c.$$

The two-color disjunctive Rado number of the equations with right-hand sides in $C$ is the least element of this set, when the set is non-empty.

## Sources

- Srashti Dwivedi and Amitabha Tripathi, *On the Two-Color Disjunctive Rado Number for the Equations $\sum_{i=1}^{m-2} x_i + a x_{m-1} - x_m = c_j$, $j = 1, 2$*, INTEGERS 25 (2025), Article A108, Section 1.
