# Monotonicity of the monochromatic-solution property in the bound

Let $m$ be a natural number, $a$ an integer, $C$ a finite set of integers and $R \le R'$ natural numbers. If every $2$-coloring of $\{1, \dots, R\}$ admits, for some $c \in C$, a monochromatic solution $x_1, \dots, x_{m-2}, y, z \in \{1, \dots, R\}$ of $x_1 + \dots + x_{m-2} + a y - z = c$ (with no $x_i$ when $m < 3$), then the same holds with $R'$ in place of $R$.

Hence the set of admissible bounds $R \ge 1$ is closed upward. If it is nonempty, its least element, the disjunctive Rado number, is the threshold from which on every bound is admissible. If it is empty, there is no finite disjunctive Rado number, as for the equations in [Non-existence of the Rado number when a + m and c are odd](disjunctive-rado-numbers/not-rado-good-of-odd.md).
