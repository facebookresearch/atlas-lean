# Disjunctive Rado numbers for two very negative right-hand sides

Let $a \ge 3$ and $m \ge 4$ be natural numbers of the same parity, let $a' = a + m - 3$, and let $c_1, c_2$ be integers with $c_1 < -(a' + 3)(a - 2)$ and $c_2 \le c_1$. Let $R(c_1, c_2)$ be the least $R \ge 1$ such that every $2$-coloring of $\{1, \dots, R\}$ admits, for some $j \in \{1, 2\}$, a monochromatic solution in $\{1, \dots, R\}$ of $\sum_{i=1}^{m-2} x_i + a x_{m-1} - x_m = c_j$. Then:

1. if $c_1 - a' \le c_2$, then $R(c_1, c_2) = (a' + 3)(a' - c_1) + 1$;
2. if $(a' + 2) c_1 - a'(a' + 1) \le c_2 < c_1 - a'$, then $R(c_1, c_2) = (a' + 2)(a' - c_1) + 1$;
3. if $(a' + 3) c_1 - a'(a' + 2) < c_2 < (a' + 2) c_1 - a'(a' + 1)$, then $R(c_1, c_2) = a' - c_2 + 1$;
4. if $c_2 \le (a' + 3) c_1 - a'(a' + 2)$, then $R(c_1, c_2) = (a' + 3)(a' - c_1) + 1$.

All four values are positive, since $c_2 \le c_1 < 0$. When $c_2 = c_1$ only the first case applies, and it gives the Rado number of the single equation.

## Sources

- Srashti Dwivedi and Amitabha Tripathi, *On the Two-Color Disjunctive Rado Number for the Equations $\sum_{i=1}^{m-2} x_i + a x_{m-1} - x_m = c_j$, $j = 1, 2$*, INTEGERS 25 (2025), Article A108, Theorem 6.
