# Rado numbers for very negative right-hand sides

Let $a \ge 3$ and $m \ge 3$ be natural numbers of the same parity, let $a' = a + m - 3$ and let $c$ be an integer such that either

1. $m = 3$ and $c \le -a(a-3)/2$, or
2. $m \ge 4$ and $c < -(a' + 3)(a - 2)$.

Then the Rado number of $\sum_{i=1}^{m-2} x_i + a x_{m-1} - x_m = c$, the least $R \ge 1$ such that every $2$-coloring of $\{1, \dots, R\}$ admits a monochromatic solution in $\{1, \dots, R\}$, equals

$$(a' + 3)(a' - c) + 1.$$

The number $a(a-3)$ is even, so $a(a-3)/2$ is an integer; the value $(a' + 3)(a' - c) + 1$ is positive under either hypothesis.

## Sources

- Srashti Dwivedi and Amitabha Tripathi, *On the Two-Color Disjunctive Rado Number for the Equations $\sum_{i=1}^{m-2} x_i + a x_{m-1} - x_m = c_j$, $j = 1, 2$*, INTEGERS 25 (2025), Article A108, Theorem 3 (quoted from earlier work).
