# Infinite Ramsey theorem

For a set $X$ and a positive integer $k$, let $[X]^k$ be the set of $k$-element subsets of $X$. Let $k$ and $c$ be positive integers and $X$ an infinite set. If $[X]^k$ is coloured with $c$ colours, that is, a function $\chi : [X]^k \to \{1, \dots, c\}$ is given, then $X$ has an infinite monochromatic subset: an infinite $Y \subseteq X$ on whose $k$-subsets $\chi$ is constant.

- R. Diestel, *Graph Theory*, 5th edition, Graduate Texts in Mathematics 173, Springer, 2017, Section 9.1, Theorem 9.1.2.
