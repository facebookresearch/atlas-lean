# Formulas of the random 3-SAT model

A formula with $m$ clauses on $n$ variables is an
ordered $m$-tuple of 3-clauses on $n$ variables, that is, a function from $\{0, \dots, m - 1\}$
to the set of 3-clauses on $n$ variables.

For $n \ge 3$ (or $m = 0$), with the uniform counting measure, this finite set of formulas is the sample space of $m$ clauses chosen uniformly and independently, with replacement. For $n < 3$ there are no 3-clauses, so for $m > 0$ the set of formulas is empty.
