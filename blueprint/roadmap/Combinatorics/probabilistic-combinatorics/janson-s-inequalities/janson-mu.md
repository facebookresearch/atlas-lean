# Expected number of contained sets (Janson's μ)

For a random subset $R$ with independent elements and sets $S_1, \dots, S_k$, $\mu = \sum_i \Pr[S_i \subseteq R]$: the expected number of the sets $S_i$ contained in $R$. It is the [expected count](../first-and-second-moment-methods/expected-count.md) of the events $A_i = \{S_i \subseteq R\}$.
