# The event that a random subset contains a given set

For a finite set $S \subseteq \alpha$, the event $\{S \subseteq R\}$: the indicators $\omega$ with $\omega(a) = \mathrm{true}$ for every $a \in S$. These are the "bad events" $A_i = \{S_i \subseteq R\}$ of Janson's inequalities; they are increasing, so the Harris inequality applies to them.
