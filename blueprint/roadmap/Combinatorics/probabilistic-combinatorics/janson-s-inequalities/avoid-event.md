# The event that a random subset avoids a given set

For a finite set $S \subseteq \alpha$, the event $\{S \cap R = \emptyset\}$: the indicators $\omega$ with $\omega(a) = \mathrm{false}$ for every $a \in S$. It is a decreasing event, the complement-side counterpart of [the event that $R$ contains $S$](contains-event.md); for the random graph it says that a vertex set spans no edge.
