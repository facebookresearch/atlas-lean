# Curling number of the empty string

The empty string $\varepsilon$ has curling number
$\mathcal{C}(\varepsilon) = 1$.

## Sources

- Levi van de Pol, *The Growth Rate of Gijswijt's Sequence*, Journal of Integer Sequences 28 (2025), Article 25.4.6, Section 1.2 ($\mathcal{C}(\varepsilon) := 1$), https://cs.uwaterloo.ca/journals/JIS/VOL28/Vandepol/vandepol5.html
