# Composition Half Index Set

The index set `S(m, n, q)`: the naturals `k` with
`2k ≡ n - q (mod m)` and `k ≤ ⌊(n - 1) / 2⌋`. The bound is written
`2 * k < n`, which is equivalent for naturals (and empty at `n = 0`).
