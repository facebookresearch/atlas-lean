# Domb Type Sum

The source's Domb-type sum
`D(n,r,s,t) = ∑_{k=0}^n choose(n,k)^r choose(2k,k)^s choose(2(n-k),n-k)^t`.
The paper uses positive `r`; the same finite formula is meaningful at `r = 0`.
