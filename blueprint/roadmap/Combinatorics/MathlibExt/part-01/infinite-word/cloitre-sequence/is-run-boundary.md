# Is Run Boundary

Maximal-run boundary for a sequence `s`: `b 0 = 0`, `b` strictly
monotone (so the blocks `[b n, b (n+1))` exhaust `ℕ`), constant on each
block, with adjacent blocks taking distinct values.
