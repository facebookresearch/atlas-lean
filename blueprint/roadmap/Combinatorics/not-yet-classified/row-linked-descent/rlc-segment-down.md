# Rlc Segment Down

Every off-support interior site `z ≠ seed` whose left neighbour is on `Vc` starts a run `z 0 ≤ t
≤ cx` in its row that avoids `Vc` and ends above a site `(cx, z 1 - 1)` off `Vc`. When `seed` is not
the lexicographically least off-support interior site, this fails at the least site
(`sdc_not_forall_segmentDown`).
