# Jcb Col Shift

The overlap cluster of `x_B` has a column function with values in `[m, m']` containing the sites
`(col r, r)` and the corner sites `(col (r - 1), r)`, changing by at most one between rows. Like
`JsiHasMonotoneArc`, when asked for every `x_B` this fails for the all-closed configuration if
`c < d`.
