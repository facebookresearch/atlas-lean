# The LYM inequality from the set-pairs inequality

For an antichain $\mathcal{A}$ of subsets of a finite set $X$ of size $n$,

$$\sum_{S \in \mathcal{A}} \binom{n}{|S|}^{-1} \le 1.$$

The pairs $(S, X \setminus S)$, $S \in \mathcal{A}$, form a set-pair system. Each pair is disjoint, and $S \cap (X \setminus T) \neq \emptyset$ exactly when $S \not\subseteq T$, which holds for distinct members of an antichain. The set-pairs inequality then gives the Lubell–Yamamoto–Meshalkin inequality, which is usually proved by the shadow (local LYM) method; Sperner's theorem follows from either proof.
