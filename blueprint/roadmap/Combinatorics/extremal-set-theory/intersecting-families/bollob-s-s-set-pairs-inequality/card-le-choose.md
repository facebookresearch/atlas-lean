# Uniform set-pairs inequality

If $(A_i, B_i)_{i \in s}$ is a set-pair system, meaning $A_i \cap B_i = \emptyset$ and $A_i \cap B_j \neq \emptyset$ for $i \neq j$, with $|A_i| = a$ and $|B_i| = b$ for every $i$, then

$$|s| \le \binom{a+b}{a}.$$

The bound is attained by the $a$-subsets $A$ of a set $X$ of size $a + b$, each paired with $X \setminus A$.

## Informally uses

- [Bollobás's set-pairs inequality](sum-inv-choose-le-one.md): each term of the sum equals $\binom{a+b}{a}^{-1}$.
