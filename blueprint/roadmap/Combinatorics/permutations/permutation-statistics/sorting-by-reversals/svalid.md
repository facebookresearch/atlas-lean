# Signed permutation of 1, …, n

For a natural number $n$, a list of integers $\pi = (\pi_0, \dots, \pi_{m-1})$ is a signed
permutation of $1, \dots, n$ if its list of absolute values $(|\pi_0|, \dots, |\pi_{m-1}|)$ is a
rearrangement of $(1, 2, \dots, n)$: $\pi$ has length $n$, no entry is $0$, and each of
$1, \dots, n$ occurs exactly once, with either sign. For $n = 0$ only the empty list qualifies
(Shamir and Peer, Lecture 11, signed setting).
