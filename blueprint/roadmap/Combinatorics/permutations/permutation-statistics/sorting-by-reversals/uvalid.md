# Permutation of 1, …, n as a list of integers

For a natural number $n$, a list of integers $\pi$ is a permutation of $1, \dots, n$ (an
unsigned permutation) if it is a rearrangement of the identity list $(1, 2, \dots, n)$: it has
length $n$ and contains each of $1, \dots, n$ exactly once. For $n = 0$ only the empty list
qualifies (Shamir and Peer, Lecture 11, §11.2).
