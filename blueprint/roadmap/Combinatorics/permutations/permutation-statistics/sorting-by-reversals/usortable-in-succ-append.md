# Appending n + 1 preserves sortability in exactly k reversals

For natural numbers $k$ and $n$ and a list of integers $X$: if $X$ [sorts](usortable-in.md) to
$(1, \dots, n)$ in exactly $k$ reversals, then $X$ followed by $n + 1$ sorts to
$(1, \dots, n + 1)$ in exactly $k$ reversals, by the same reversals, which never reach the last
position (Shamir and Peer, Lecture 11, §11.2).
