# Unsigned reversal distance is 0 exactly for the identity

For every natural number $n$ and every [permutation](uvalid.md) $\pi$ of $1, \dots, n$, written
as a list of integers, the [unsigned reversal distance](udist.md) satisfies $d(\pi) = 0$ if and
only if $\pi = (1, 2, \dots, n)$ (Shamir and Peer, Lecture 11, §11.2).
