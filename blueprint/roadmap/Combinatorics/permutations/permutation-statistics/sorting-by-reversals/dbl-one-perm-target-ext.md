# Doubling plus or minus n + 1 gives 2n + 1 and 2n + 2 in some order

For an integer $x$ and a natural number $n$ with $|x| = n + 1$, the [doubled pair](dbl-one.md)
$\delta(x)$ is a rearrangement of $(2n + 1, 2n + 2)$: it is $(2n + 1, 2n + 2)$ for $x = n + 1$
and $(2n + 2, 2n + 1)$ for $x = -(n + 1)$.
