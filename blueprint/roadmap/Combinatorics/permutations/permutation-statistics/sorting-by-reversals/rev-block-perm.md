# A reversal of positions inside the list rearranges it

For a list of integers $\pi$ of length $m$ and natural numbers $i \le j < m$, the
[reversal](rev-block.md) $\operatorname{rev}_{i,j}(\pi)$ of positions $i$ to $j$ is a
rearrangement of $\pi$: both lists have the same entries with the same multiplicities.
