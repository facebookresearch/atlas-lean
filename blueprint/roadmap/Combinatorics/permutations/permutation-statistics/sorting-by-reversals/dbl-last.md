# Second entry of the doubled pair of an integer

For an integer $x$, $\delta_2(x)$ is $2x$ if $x \ge 0$ and $2|x| - 1$ if $x < 0$: the second and
last entry of the [doubled pair](dbl-one.md) $\delta(x)$ (Shamir and Peer, Lecture 11, signed
setting). It is meant for nonzero $x$; for $x = 0$ it is $0$.
