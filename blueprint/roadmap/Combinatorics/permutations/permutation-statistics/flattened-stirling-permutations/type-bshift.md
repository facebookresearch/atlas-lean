# The shift map

For a finite set $S$ of integers, $h(S) = \{|i| + 1 : i \in S\}$, a
finite set of natural numbers.

In particular, for every natural number $n$, $h$ sends subsets of $[-n, n]$ to subsets of
$\{1, \dots, n + 1\}$.
