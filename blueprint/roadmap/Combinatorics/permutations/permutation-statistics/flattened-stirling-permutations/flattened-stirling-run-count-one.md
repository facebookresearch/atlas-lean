# Exactly one flattened Stirling permutation has one run

For every natural number
$n \ge 1$, exactly one flattened Stirling permutation of order $n$ has exactly one run.

## Sources

- Adam Buck, Jennifer Elder, Azia A. Figueroa, Pamela E. Harris, Kimberly J. Harry, and Anthony Simpson, *Flattened Stirling Permutations*, INTEGERS 24 (2024), Article A104, Proposition 2, part 1.
