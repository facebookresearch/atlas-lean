# Indecomposable set partition

A set partition $P$ of $\{0, 1, \dots, n-1\}$ is indecomposable when for every $k$ with $1 \le k < n$ it is not the case that every block of $P$ lies entirely in $\{0, \dots, k-1\}$ or entirely in $\{k, \dots, n-1\}$; equivalently, for every such $k$ some block meets both sets.
