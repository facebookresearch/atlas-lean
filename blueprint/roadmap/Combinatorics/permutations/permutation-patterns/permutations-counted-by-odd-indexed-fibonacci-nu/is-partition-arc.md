# Arc of a set partition

For a set partition $P$ of $\{0, 1, \dots, n-1\}$ and elements $i, j$, the pair $(i, j)$ is an arc of $P$ when $i < j$, $i$ and $j$ lie in the same block $B$ of $P$, and no element $m \in B$ satisfies $i < m < j$.

## Sources

- Juan B. Gil, Felix H. Xu, and William Y. Zhu, "Odd-Indexed Fibonacci Numbers via Pattern-Avoiding Permutations", *INTEGERS* 25 (2025), Article A79, Section 4.1 (arc diagrams).
