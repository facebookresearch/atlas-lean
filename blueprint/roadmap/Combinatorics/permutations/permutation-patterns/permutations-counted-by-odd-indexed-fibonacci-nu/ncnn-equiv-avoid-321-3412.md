# Noncrossing nonnesting partitions correspond to 321- and 3412-avoiding permutations

For every natural number $n \ge 1$, there is a bijection between the noncrossing nonnesting set partitions of $\{0, \dots, n-1\}$ and the permutations in $S_n(321, 3412)$.

$S_n(321, 3412)$ denotes the permutations of $\{0, \dots, n-1\}$ avoiding both classical patterns $321$ and $3412$. A set partition of $\{0, \dots, n-1\}$ is noncrossing and nonnesting when there are no $a < b < c < d$ with $a, c$ in one block and $b, d$ in a different block, and no two arcs $(i_1, j_1)$, $(i_2, j_2)$ with $i_1 < i_2 < j_2 < j_1$; an arc is a pair $i < j$ of elements of one block with no element of that block strictly between them.
