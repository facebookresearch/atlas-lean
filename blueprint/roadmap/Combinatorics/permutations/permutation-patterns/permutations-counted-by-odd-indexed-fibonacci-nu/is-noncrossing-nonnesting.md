# Noncrossing nonnesting set partition

A set partition of $\{0, \dots, n-1\}$ is noncrossing and nonnesting when there are no $a < b < c < d$ with $a, c$ in one block and $b, d$ in a different block, and no two arcs $(i_1, j_1)$, $(i_2, j_2)$ with $i_1 < i_2 < j_2 < j_1$; an arc is a pair $i < j$ of elements of one block with no element of that block strictly between them.

## Sources

- Juan B. Gil, Felix H. Xu, and William Y. Zhu, "Odd-Indexed Fibonacci Numbers via Pattern-Avoiding Permutations", *INTEGERS* 25 (2025), Article A79, Section 4.1.
