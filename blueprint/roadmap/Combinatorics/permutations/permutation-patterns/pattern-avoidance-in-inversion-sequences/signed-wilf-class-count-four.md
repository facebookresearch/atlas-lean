# Signed Wilf classes of sets of four patterns

The number $\mathrm{sw}_4$ of
Wilf-equivalence classes among the sets of $4$ length-2 signed patterns is $195$.

## Sources

- Toufik Mansour and Amir Safadi, *Signed Inversion Sequences Avoiding a Set of Length-2 Signed Patterns*, INTEGERS 26 (2026), Article A74, Theorem 10 (`integers-2026-A74-thm-10`).
