# Alternating recurrence for the Fubini numbers

For every natural number $n$, the Fubini
number $F(n)$ satisfies

$$F(n) = n! - \sum_{j=1}^{n} s(n, n-j)\, F(n-j),$$

where $s(n, k)$ is the signed Stirling number of the first kind.
