# The first five powers of $x^{-1} + 1 + x$

In the ring of Laurent polynomials over
$\mathbb{Z}$,
$(x^{-1} + 1 + x)^0 = 1$,
$(x^{-1} + 1 + x)^1 = x^{-1} + 1 + x$,
$(x^{-1} + 1 + x)^2 = x^{-2} + 2x^{-1} + 3 + 2x + x^2$,
$(x^{-1} + 1 + x)^3 = x^{-3} + 3x^{-2} + 6x^{-1} + 7 + 6x + 3x^2 + x^3$ and
$(x^{-1} + 1 + x)^4 = x^{-4} + 4x^{-3} + 10x^{-2} + 16x^{-1} + 19 + 16x + 10x^2 + 4x^3 + x^4$.
