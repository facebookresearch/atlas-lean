# Defining recurrence of Barry's triangle

For all natural numbers $\beta, n, k$, Barry's
triangle recurrence $s$ satisfies
$s(\beta, n + 1, k + 1) = s(\beta + 1, n, k) + \beta (k + 1)\, s(\beta, n, k + 1)$.

## Sources
