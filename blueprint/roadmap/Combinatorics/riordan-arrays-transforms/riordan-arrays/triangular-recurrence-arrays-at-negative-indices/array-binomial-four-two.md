# The binomial array at $(4, 2)$

$(\alpha, \beta, \gamma; \alpha', \beta', \gamma') = (0, 0, 1; 0, 0, 1)$ of the binomial
coefficients (Table 1), the triangular array $a$ satisfies $a_{4,2} = 6$.
