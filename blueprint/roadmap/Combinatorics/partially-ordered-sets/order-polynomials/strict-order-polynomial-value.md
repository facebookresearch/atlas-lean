# Strict order polynomial

$\bar\Omega_P(m)$ is the number of strictly order-preserving maps $\sigma \colon P \to [m]$, that is,
maps with $s < t \Rightarrow \sigma(s) < \sigma(t)$; equivalently, of strict $P$-partitions with parts in
$[m]$. In Stanley's notation it is $\Omega_{P, \bar\omega}(m)$ for a natural labelling $\omega$, whose
complementary labelling $\bar\omega$ is dual natural.

## Sources

- R. P. Stanley, *Enumerative Combinatorics*, vol. 1, 2nd ed., author's draft of 15 July 2011, https://math.mit.edu/~rstan/ec/ec1.pdf, Section 3.15.3.
