# Surjective order-preserving maps onto $[p]$ are linear extensions

For a poset $P$ with $p$ elements, $e_P(p) = e(P)$, the number of linear extensions: a surjective
map between sets of the same finite size is bijective, and a bijective order-preserving map
$P \to [p]$ is a linear extension. This identifies the leading coefficient of the order polynomial.

## Background

- [Linear extensions of a finite poset](../linear-extensions-of-posets/linear-extensions.md): the definition of $e(P)$ used here, as the number of
  bijective monotone maps $P \to \{0, \dots, p - 1\}$.

## Sources

- R. P. Stanley, *Enumerative Combinatorics*, vol. 1, 2nd ed., author's draft of 15 July 2011, https://math.mit.edu/~rstan/ec/ec1.pdf, Section 3.15.3 ("for any $\omega$ we have $e_{P,\omega}(p) = e(P)$").
