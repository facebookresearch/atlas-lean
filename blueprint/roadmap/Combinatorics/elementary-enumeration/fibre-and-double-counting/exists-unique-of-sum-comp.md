# Unique witnesses transported by finite-sum equality

Let $s$ and $T$ be finite sets and $i$ a map such that $\sum_{a \in s} F(i(a)) = \sum_{b \in T} F(b)$ for every integer-valued function $F$. If a property $Q$ holds for exactly one element of $T$, then $Q(i(a))$ holds for exactly one $a \in s$.
