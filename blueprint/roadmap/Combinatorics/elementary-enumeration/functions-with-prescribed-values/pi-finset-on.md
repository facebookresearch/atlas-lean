# Finite tuples with prescribed default values

For a finite set $\iota$, a property $P$ of elements of $\iota$, finite subsets $(T_i)_{i \in \iota}$ of a set $\sigma$ and $d \in \sigma$, the tuples with default $d$ form the finite set of functions $t : \iota \to \sigma$ with $t_i \in T_i$ when $P(i)$ holds and $t_i = d$ otherwise.
