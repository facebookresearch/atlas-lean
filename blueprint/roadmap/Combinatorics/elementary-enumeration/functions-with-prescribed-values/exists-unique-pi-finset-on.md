# Unique default completion of active coordinates

Let $\iota$ be a finite set, $P$ a property of elements of $\iota$, $(T_i)_{i \in \iota}$ finite subsets of a set $\sigma$, $d \in \sigma$, and $t : \iota \to \sigma$ with $t_i \in T_i$ whenever $P(i)$. Then there is exactly one [tuple with default $d$](pi-finset-on.md) $b$ (that is, $b_i \in T_i$ when $P(i)$ and $b_i = d$ otherwise) with $b_i = t_i$ for every $i$ satisfying $P$.
