# Number of dependent functions with prescribed values

Let $\iota$ be a finite set, $(s_i)_{i \in \iota}$ finite sets, $S \subseteq \iota$, and $(f_i)_{i \in S}$ values with $f_i \in s_i$. The number of tuples $g \in \prod_{i \in \iota} s_i$ with $g_i = f_i$ for all $i \in S$ is

$$\prod_{i \in \iota \setminus S} \lvert s_i\rvert.$$
