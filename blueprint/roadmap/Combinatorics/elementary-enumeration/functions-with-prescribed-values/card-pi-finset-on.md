# Number of default-padded finite tuples

Let $\iota$ be a finite set, $P$ a property of elements of $\iota$, $(T_i)_{i \in \iota}$ finite subsets of a set $\sigma$ and $d \in \sigma$. The set of [tuples with default $d$](pi-finset-on.md), those $t : \iota \to \sigma$ with $t_i \in T_i$ when $P(i)$ and $t_i = d$ otherwise, has

$$\prod_{i \in \iota,\ P(i)} \lvert T_i\rvert$$

elements.
