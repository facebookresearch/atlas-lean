# Division-free count of functions with prescribed values

Let $\iota$ and $\kappa$ be finite sets, $S \subseteq \iota$ and $f : S \to \kappa$. The number $N$ of functions $g : \iota \to \kappa$ that agree with $f$ on $S$ satisfies

$$N \cdot \lvert\kappa\rvert^{\lvert S\rvert} = \lvert\kappa\rvert^{\lvert\iota\rvert}.$$
