# Membership in default-padded finite tuples

Let $\iota$ be a finite set, $P$ a property of elements of $\iota$, $(T_i)_{i \in \iota}$ finite subsets of a set $\sigma$ and $d \in \sigma$. A function $t : \iota \to \sigma$ is a [tuple with default $d$](pi-finset-on.md) if and only if, for every $i$, $t_i \in T_i$ when $P(i)$ holds and $t_i = d$ when it does not.
