# Clusters of an unrooted tree form a binary hierarchy

For every [unrooted binary phylogenetic tree](unrooted-binary-tree.md) on a finite set $X$ and every taxon $a$, the [cluster set](cluster-set.md) seen from $a$ is a [binary hierarchy](is-binary-hierarchy.md) on $X \setminus \{a\}$ (Semple & Steel 2003).

## Sources

- C. Semple and M. Steel, *Phylogenetics*, Oxford University Press (2003).
