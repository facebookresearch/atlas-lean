# Swap equivalence is compatible with forming a node

Let $L$ be a set of labels and consider planar rooted binary trees with leaves labeled in $L$, related by the equivalence relation generated by swaps (exchanging the two children of one internal vertex, anywhere in the tree). If $l$ is equivalent to $l'$ and $r$ is equivalent to $r'$, then the tree with left child $l$ and right child $r$ is equivalent to the tree with left child $l'$ and right child $r'$.
