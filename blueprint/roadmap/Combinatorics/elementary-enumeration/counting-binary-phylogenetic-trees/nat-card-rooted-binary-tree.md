# Schröder's count of rooted binary phylogenetic trees

For every nonempty finite set $X$ of $n$ taxa, the number of [rooted binary phylogenetic trees](rooted-binary-tree.md) on $X$ is

$$(2n - 3)!! = 1 \cdot 3 \cdot 5 \cdots (2n - 3),$$

with truncated subtraction, so the value for $n = 1$ is $0!! = 1$.

## Sources

- C. Semple and M. Steel, *Phylogenetics*, Oxford University Press (2003).
