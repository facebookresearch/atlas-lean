# Generating function of a multiplicity function

For $\mu \colon \mathbb{N} \to \mathbb{N}$, the series $j_\mu(x)$ is the formal power series over $\mathbb{Q}$

$$j_\mu(x) = \sum_{a \ge 1} \mu(a)\, x^a,$$

whose constant term is $0$ whatever $\mu(0)$ is. For a set $A \subseteq \mathbb{N}$, write $j_A = j_{\mathbf{1}_A} = \sum_{a \in A,\, a \ge 1} x^a$.
