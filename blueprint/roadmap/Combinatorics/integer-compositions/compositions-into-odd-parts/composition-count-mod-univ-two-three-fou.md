# The residue of the number of parts is read modulo m

Let $\mathbf{1}_{\mathbb{N}}$ be the multiplicity function of $\mathbb{N}$ (every part allowed, in one color) and let $b_{\mathbb{N}}(m, q; n)$ count the compositions of $n$ whose number of parts $k$ satisfies $k \bmod m = q \bmod m$. Then $b_{\mathbb{N}}(2, 3; 4) = 4$, the same value as $b_{\mathbb{N}}(2, 1; 4)$, since $3 \equiv 1 \pmod 2$.
