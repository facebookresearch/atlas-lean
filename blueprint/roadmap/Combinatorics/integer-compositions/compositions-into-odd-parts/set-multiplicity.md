# Multiplicity function of a set

For a set $A \subseteq \mathbb{N}$, the multiplicity function of $A$ is the function $\mathbb{N} \to \mathbb{N}$, $a \mapsto \mathbf{1}_A(a)$, equal to $1$ on $A$ and $0$ off $A$; it is the indicator sequence $i(A; \cdot)$ of $A$. Used as a multiplicity function $\mu$, it makes each part $a \in A$ available in exactly one color and forbids every part outside $A$.
