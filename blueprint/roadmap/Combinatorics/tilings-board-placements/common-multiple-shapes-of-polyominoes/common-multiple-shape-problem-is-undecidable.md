# The common multiple shape problem for sets of polyominoes is undecidable

No algorithm decides, for two finite sets of polyominoes, whether some polyomino of positive area can be tiled both by copies of pieces of the first set and by copies of pieces of the second, even when every piece has a number of cells bounded by a fixed multiple of the square of the logarithm of the input size.

A *polyomino* is a polygon obtained by joining one or more unit squares of the integer grid edge to edge: a finite, edge-connected union of grid cells, of positive area. The pieces here are simple polyominoes (without holes); a polyomino formed from them may have holes. A *copy* of a piece is a translate of it by an integer vector. For a finite set $S$ of polyominoes let $\widehat S$ be the set of polyominoes that can be tiled by copies of pieces of $S$, each piece usable any number of times, the copies having disjoint interiors and union exactly the polyomino. The *common multiple shape problem* asks, given finite sets $S_1$ and $S_2$ of polyominoes, whether $\widehat{S_1}\cap\widehat{S_2}$ is nonempty; an element of it is a *common multiple shape*. The input is the pair $S_1, S_2$, given by the cells of each piece; the target polyomino is not part of the input.

**Theorem (Banbara, Minato, Ono and Uehara).** The common multiple shape problem is undecidable. More precisely, there is a constant $C$ such that the problem is undecidable already for instances in which every piece of $S_1$ and of $S_2$ has at most $C(\log n)^2$ cells, where $n = |S_1| + |S_2|$ (Theorem 5 and its proof).

Conventions: the target is not part of the input and may have holes even when all pieces are simple. The source calls a set $S$ of polyominoes *small* when its largest piece has $O(|S|^c)$ cells for a positive constant $c$, and states the theorem for small sets; the bound above is the one its proof exhibits, uniform over the reduced instances. The source does not fix which motions a copy may undergo: its proof of Lemma 3 allows a piece to be placed in any orientation and shows that the colours then force all pieces into a single orientation. This page states the case in which copies are translates, which the same reduction proves: a solution of the Post correspondence problem gives aligned tilings by both sets, using translates only, and a tiling by translates is aligned, so Lemmas 3 and 4 apply to it as they stand. The case $|S_1|=|S_2|=1$ is the classical puzzle of polyform compatibility. The variant in which every piece of each set must be used exactly once (the shape logic puzzle) is decidable: the source shows it is strongly NP-complete for small polyominoes and polynomial when the number of pieces is constant. The source also derives that it is undecidable whether copies of a given finite set of small polyominoes form a rectangle.

## Expansion

The proof goes through a jigsaw puzzle with square pieces whose edges carry colors $0,1,\dots,c$ and $\bar1,\dots,\bar c$: adjacent edges must carry complementary colors $i$ and $\bar i$, and exactly the boundary of the region carries color $0$. A fixed set of $11$ pieces tiles a region with boundary color $0$ iff the region is a rectangle of size at least $3\times3$ (Lemma 3), and from an instance of the Post correspondence problem one builds pieces that tile some region with boundary color $0$ iff the instance has a solution (Lemma 4): the top row spells the upper words, the bottom row the lower words, and colored paths match the index of each upper block to that of its lower block. Each colored square becomes a small polyomino by replacing each color by a zigzag edge pattern encoding it in binary, with $O((\log|C|)^2)$ cells. With $S_1$ from Lemma 3 and $S_2$ from Lemma 4, a common multiple shape exists iff the instance is solvable; the number of colours is linear in the input size, which gives the bound on the pieces. A good expansion links the rectangle-forcing jigsaw set of Lemma 3, the reduction from the Post correspondence problem of Lemma 4, and the encoding of coloured jigsaw pieces by polyominoes.
