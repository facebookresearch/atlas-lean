# Lattice cells

For a natural number $d$, a lattice cell in dimension $d$ is a point of
$\mathbb{Z}^d$, that is, a function assigning an integer to each of the $d$ coordinate axes.

## Sources

- Sebastian Luther and Stephan Mertens, *The Perimeter of Proper Polycubes*, Journal of Integer Sequences 20 (2017), Article 17.9.5, Section 1: a $d$-dimensional polycube is a set of face-connected cells in $\mathbb{Z}^d$, <https://cs.uwaterloo.ca/journals/JIS/VOL20/Mertens/mert4.pdf> (also arXiv:1705.03688).
