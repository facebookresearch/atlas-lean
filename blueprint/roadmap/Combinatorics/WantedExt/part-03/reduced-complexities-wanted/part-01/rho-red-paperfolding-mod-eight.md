# Theorem 2

**Theorem 2**: for `n ≥ 2` (at `n = 1` the value is `2`),
`ρ^red_f(n) = 4` if `n ≡ 0, 1, 2, 4, 6 (mod 8)` and `6` if
`n ≡ 3, 5, 7 (mod 8)`.
