# Lemma 11

**Lemma 11**: `|F_{n,ℓ,k+1,ℓk+q}| = |E_{n,ℓ+1,k,q-1}|` for
`n ≥ ℓ + 1`, `k ≥ 2`, and `q ≥ 1`.
