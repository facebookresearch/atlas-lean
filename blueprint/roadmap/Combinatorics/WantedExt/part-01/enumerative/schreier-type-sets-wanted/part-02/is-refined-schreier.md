# Is Refined Schreier

Membership in the refined family `F_{n,ℓ}` of Section 4:
`A = {a_1, …, a_p, n+1}` with `p ≥ 2`, `A` sparse and
`ℓ`-strong Schreier, and `n + 1 + a_{p-1} = 2·a_p` for the two
largest elements `a_{p-1} < a_p` below `n + 1`.
