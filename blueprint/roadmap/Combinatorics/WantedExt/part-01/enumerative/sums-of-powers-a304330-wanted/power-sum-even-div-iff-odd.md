# Proposition 2 (Knuth, 1993)

**Proposition 2 (Knuth, 1993)**: for real coefficients
`a_m`, the identity
`S_{2k}(n)/(2n + 1) = Σ_{m=1}^k a_m·C(n + m, 2m)` (for all `n`)
holds if and only if
`S_{2k-1}(n) = Σ_{m=1}^k ((2m + 1)/m)·a_m·C(n + m, 2m)`
(for all `n`).
