# L

We set `L n 0 := S n 0`, `L n 1 := S n 1`, and `L n 2 := S n 2`.
For `d` larger than 2, we define `L n d := { f ∈ M n d | ∂ᵢf ∈ L n (d−1) for all i ∈ [n] }`.
