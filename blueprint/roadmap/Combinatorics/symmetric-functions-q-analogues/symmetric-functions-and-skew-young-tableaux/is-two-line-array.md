# Two-line array

Let $m$ be a natural number and let $w = [(i_1, j_1), \dots, (i_m, j_m)]$ be a list of $m$ pairs of natural numbers, read as an array whose top line is $i_1, \dots, i_m$ and whose bottom line is $j_1, \dots, j_m$. The list $w$ is a two-line array, also called a generalized permutation, if $i_r \ge 1$ and $j_r \ge 1$ for every $r$, and for all $1 \le r < s \le m$ we have $i_r \le i_s$, and moreover $j_r \le j_s$ whenever $i_r = i_s$. Pairs may repeat, and the empty list is a two-line array.
