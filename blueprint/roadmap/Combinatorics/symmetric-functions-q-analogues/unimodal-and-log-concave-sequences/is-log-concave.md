# Log-concave sequence

A finite sequence $(a_0, a_1, \dots, a_n)$ of real numbers is log-concave if

$$a_i^2 \ge a_{i-1}\, a_{i+1} \qquad (1 \le i \le n - 1).$$

For positive terms this says that $\log a_i$ is a concave function of $i$, equivalently that the
ratios $a_{i+1} / a_i$ are weakly decreasing.
