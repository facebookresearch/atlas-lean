# Number of unate $k$-SAT functions

For natural numbers $k$ and $n$, the number of Boolean
functions $f : \{\mathrm{true}, \mathrm{false}\}^n \to \{\mathrm{true}, \mathrm{false}\}$ that are
$k$-SAT functions on $n$ variables and are unate.
