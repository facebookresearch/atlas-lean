# Few coordinates have large influence

For $f : \{-1, 1\}^n \to \mathbb{R}$ with $\mathbf{I}[f] > 0$, $\varepsilon > 0$ and $k \in \mathbb{N}$, the
set $J = \{j : \mathrm{Inf}_j[f] \ge \varepsilon^2 / (\mathbf{I}[f]^2 9^k)\}$ has

$$|J| \le \frac{\mathbf{I}[f]^3\, 9^k}{\varepsilon^2},$$

because the influences sum to $\mathbf{I}[f]$.

## Sources

- R. O'Donnell, *Analysis of Boolean Functions*, Cambridge University Press, 2014 (arXiv:2105.10386), Theorem 9.28.
