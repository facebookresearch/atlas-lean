# L^p norms under a uniform distribution increase with p

For a real function $f$ on a finite set under the uniform distribution and real exponents $0 < p \le q$, $\|f\|_p \le \|f\|_q$, where $\|f\|_p = (\mathbb{E}|f|^p)^{1/p}$.

## Proof sketch

Jensen's inequality for the convex function $t \mapsto t^{q/p}$ applied to $|f|^p$.
