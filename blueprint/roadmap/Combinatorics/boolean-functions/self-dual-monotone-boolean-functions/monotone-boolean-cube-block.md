# Blocks of a monotone Boolean function are monotone

Let $n$ and $k$ be natural numbers and let $F$ be a monotone Boolean function on $\{0,1\}^{n+k}$ (coordinatewise order, $0 < 1$); for a Boolean function $F$ on $\{0,1\}^{n+k}$ and a natural number $i$, the block $F_i$ is the Boolean function $x \mapsto F(x_0, \dots, x_{n-1}, \beta_0(i), \dots, \beta_{k-1}(i))$ on $\{0,1\}^n$, where $\beta_j(i)$ is bit $j$ of $i$. Then $F_i$ is monotone for every natural number $i$.
