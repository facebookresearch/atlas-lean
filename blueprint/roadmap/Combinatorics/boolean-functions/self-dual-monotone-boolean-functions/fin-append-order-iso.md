# Appending tuples as an order isomorphism

For a preordered type $\alpha$ and natural numbers $m$ and $n$, appending tuples, $(x, y) \mapsto (x_0, \dots, x_{m-1}, y_0, \dots, y_{n-1})$, is an order isomorphism from $\alpha^m \times \alpha^n$ to $\alpha^{m+n}$. Tuples are ordered coordinatewise and pairs componentwise: $(x, y) \le (x', y')$ when $x \le x'$ and $y \le y'$.
