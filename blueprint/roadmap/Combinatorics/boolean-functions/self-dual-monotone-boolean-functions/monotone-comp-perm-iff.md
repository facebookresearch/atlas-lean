# Relabelling the variables preserves and reflects monotonicity

Let $f$ be a Boolean function on $\{0,1\}^n$ and for a permutation $\pi$ of $\{0, \dots, n-1\}$ write $f^\pi$ for the function $x \mapsto f(x \circ \pi)$, where $(x \circ \pi)_i = x_{\pi(i)}$. Then $f^\pi$ is monotone if and only if $f$ is monotone, for the coordinatewise order on inputs with $0 < 1$.
