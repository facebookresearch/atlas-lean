# Relabelling the variables commutes with duality

Let $f$ be any Boolean function on $\{0,1\}^n$, not necessarily monotone, let $f^*(x) = \lnot f(\bar x)$ be its dual, where $\bar x$ is the coordinatewise complement of $x$, and for a permutation $\pi$ of $\{0, \dots, n-1\}$ write $f^\pi$ for the function $x \mapsto f(x \circ \pi)$, where $(x \circ \pi)_i = x_{\pi(i)}$. Then $(f^*)^\pi = (f^\pi)^*$.
