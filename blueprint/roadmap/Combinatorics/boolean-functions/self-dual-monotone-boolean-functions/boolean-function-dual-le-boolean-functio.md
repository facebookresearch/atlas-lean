# Comparing duals of Boolean functions

For all Boolean functions $f$ and $g$ on $\{0,1\}^n$, not necessarily monotone, $f^* \le g^*$ if and only if $g \le f$, where $f^*(x) = \lnot f(\bar x)$ is the dual of $f$, $\bar x$ is the coordinatewise complement of $x$, and functions are ordered pointwise with $0 < 1$.
