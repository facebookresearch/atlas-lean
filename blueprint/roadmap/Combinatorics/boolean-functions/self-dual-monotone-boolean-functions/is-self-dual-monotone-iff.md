# Self-dual monotone Boolean functions

A Boolean function $f$ on $\{0,1\}^n$ is self-dual monotone if and only if it is monotone and equals its dual, $f = f^*$. Order $\{0,1\}$ by $0 < 1$, inputs in $\{0,1\}^n$ coordinatewise and Boolean functions pointwise; $\bar x$ is the coordinatewise complement of $x$ and $f^*(x) = \lnot f(\bar x)$ is the dual of a Boolean function $f$ on $\{0,1\}^n$.
