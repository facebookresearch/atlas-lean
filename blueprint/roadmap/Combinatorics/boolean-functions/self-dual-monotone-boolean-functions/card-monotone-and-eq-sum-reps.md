# Counting monotone Boolean functions with an invariant property by classes

Let $n$ be a natural number and for a permutation $\pi$ of $\{0, \dots, n-1\}$ write $f^\pi$ for the function $x \mapsto f(x \circ \pi)$, where $(x \circ \pi)_i = x_{\pi(i)}$. Let $P$ be a property of Boolean functions on $\{0,1\}^n$ such that $P(b^\pi)$ holds if and only if $P(b)$ holds, for every Boolean function $b$ and every permutation $\pi$. Let $R$ be a finite set of monotone Boolean functions on $\{0,1\}^n$ such that for every monotone Boolean function $f$ on $\{0,1\}^n$ there is exactly one $b \in R$ with $f = b^\pi$ for some permutation $\pi$, and let $\gamma(b)$ be the number of distinct functions $b^\pi$ as $\pi$ ranges over all permutations of $\{0, \dots, n-1\}$. Then the number of monotone Boolean functions $f$ on $\{0,1\}^n$ (for the coordinatewise order with $0 < 1$) with $P(f)$ equals $\sum_{b \in R,\ P(b)} \gamma(b)$.
