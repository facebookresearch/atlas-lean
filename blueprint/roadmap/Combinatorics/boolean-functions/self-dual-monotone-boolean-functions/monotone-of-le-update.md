# Monotonicity on a Boolean cube from single-coordinate steps

Let $\iota$ be a finite type, let $\alpha$ be a preordered type and let $G$ be a function from $\{0,1\}^\iota$ to $\alpha$. Suppose that $G(y) \le G(y')$ whenever $y_j = 0$ for some $j \in \iota$ and $y'$ is $y$ with coordinate $j$ set to $1$. Then $G$ is monotone for the coordinatewise order on $\{0,1\}^\iota$ with $0 < 1$.
