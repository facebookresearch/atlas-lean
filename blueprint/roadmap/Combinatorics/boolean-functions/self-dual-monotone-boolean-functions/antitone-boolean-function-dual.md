# Duality reverses the pointwise order of all Boolean functions

Let $f$ and $g$ be Boolean functions on $\{0,1\}^n$, not necessarily monotone, and let $f^*(x) = \lnot f(\bar x)$ be the dual of $f$, where $\bar x$ is the coordinatewise complement of $x$. If $f \le g$ pointwise (with $0 < 1$), then $g^* \le f^*$.
