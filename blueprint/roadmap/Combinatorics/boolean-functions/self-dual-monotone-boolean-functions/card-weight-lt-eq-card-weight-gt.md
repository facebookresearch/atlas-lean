# Monotone Boolean functions of weight below and above half

For every $n$, the number of monotone Boolean functions $f$ on $\{0,1\}^n$ with $2\,|f^{-1}(1)| < 2^n$ equals the number of monotone Boolean functions $f$ with $2\,|f^{-1}(1)| > 2^n$; here $|f^{-1}(1)|$ is the number of inputs $x$ with $f(x) = 1$, and monotone refers to the coordinatewise order with $0 < 1$. Duality $f \mapsto f^*$, $f^*(x) = \lnot f(\bar x)$, exchanges the two classes.

## Sources

- Bartłomiej Pawelski and Andrzej Szepietowski, *Counting Self-Dual Monotone Boolean Functions*, Journal of Integer Sequences 28 (2025), Article 25.6.5.
