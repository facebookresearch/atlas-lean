# A complementing input rules out invariant self-dual functions

Let $\pi$ be a permutation of $\{0, \dots, n-1\}$ and let $x \in \{0,1\}^n$ satisfy $x \circ \pi = \bar x$, that is, $x_{\pi(i)} = \lnot x_i$ for every $i$. Let $f$ be a Boolean function on $\{0,1\}^n$ with $f = f^*$, where $f^*(u) = \lnot f(\bar u)$ and $\bar u$ is the coordinatewise complement of $u$; $f$ need not be monotone. Then the function $u \mapsto f(u \circ \pi)$, where $(u \circ \pi)_i = u_{\pi(i)}$, differs from $f$.
