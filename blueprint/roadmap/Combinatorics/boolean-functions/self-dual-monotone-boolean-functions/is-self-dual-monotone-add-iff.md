# Self-dual monotone functions on n + k variables via their blocks

Let $n$ and $k$ be natural numbers. Order $\{0,1\}$ by $0 < 1$, inputs coordinatewise and Boolean functions pointwise; let $f^*(x) = \lnot f(\bar x)$ be the dual of $f$, where $\bar x$ is the coordinatewise complement of $x$, and say that $F$ is self-dual monotone when it is monotone and equals its dual. For a Boolean function $F$ on $\{0,1\}^{n+k}$ and a natural number $i$, let $F_i$ be the block $x \mapsto F(x_0, \dots, x_{n-1}, \beta_0(i), \dots, \beta_{k-1}(i))$ on $\{0,1\}^n$, where $\beta_j(i)$ is bit $j$ of $i$. Then $F$ is self-dual monotone if and only if: (a) $F_i$ is monotone for every $i < 2^k$; (b) $F_i \le F_{i + 2^j}$ for all $i < 2^k$ and $j < k$ such that bit $j$ of $i$ is $0$; and (c) $F_{2^k - 1 - i} = (F_i)^*$ for every $i < 2^k$.
