# Opposite blocks of a self-dual monotone function are dual

Let $n$ and $k$ be natural numbers and let $F$ be a self-dual monotone Boolean function on $\{0,1\}^{n+k}$, that is, monotone (coordinatewise order, $0 < 1$) with $F = F^*$, where $f^*(x) = \lnot f(\bar x)$ and $\bar x$ is the coordinatewise complement of $x$. For a natural number $i$, let $F_i$ be the block $x \mapsto F(x_0, \dots, x_{n-1}, \beta_0(i), \dots, \beta_{k-1}(i))$, where $\beta_j(i)$ is bit $j$ of $i$. If $i < 2^k$ and $i' = 2^k - 1 - i$, then $F_{i'} = (F_i)^*$.
