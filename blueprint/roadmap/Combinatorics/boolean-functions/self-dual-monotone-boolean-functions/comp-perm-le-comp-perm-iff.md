# Relabelling the variables preserves and reflects the order

Let $f$ and $g$ be Boolean functions on $\{0,1\}^n$, not necessarily monotone, and for a permutation $\pi$ of $\{0, \dots, n-1\}$ write $f^\pi$ for the function $x \mapsto f(x \circ \pi)$, where $(x \circ \pi)_i = x_{\pi(i)}$. Then $f^\pi \le g^\pi$ if and only if $f \le g$, for the pointwise order with $0 < 1$.
