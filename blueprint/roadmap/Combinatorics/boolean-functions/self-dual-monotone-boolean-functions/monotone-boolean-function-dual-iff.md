# Dual of a Boolean function is monotone exactly when the function is

For every $n$ and every Boolean function $f \colon \{0,1\}^n \to \{0,1\}$, the dual $f^*(x) = \lnot f(\bar x)$, where $\bar x$ is the coordinatewise complement of $x$, is monotone if and only if $f$ is monotone. Here $0 < 1$, inputs in $\{0,1\}^n$ are ordered coordinatewise and Boolean functions pointwise.
