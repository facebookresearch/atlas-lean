# Decision tree querying every variable

For a finite set $E$ and a function $\varphi : \{0, 1\}^E \to \{0, 1\}$, this is the [decision tree](decision-tree.md) that queries every variable of $E$, in a fixed enumeration of $E$, and then outputs $\varphi$ at the configuration given by the answers. It computes $\varphi$, and it queries every variable on every input, so the revealment of each variable is the total mass of the product weight: $1$ under a product of probability weights.
