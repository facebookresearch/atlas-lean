# Discrete derivative in a coordinate

For a set $E$, a function $f : \{0, 1\}^E \to \mathbb{R}$ and $e \in E$, the discrete derivative of $f$ in direction $e$ is

$$\partial_e f(\omega) = f(\omega^{e \to 1}) - f(\omega^{e \to 0}),$$

where $\omega^{e \to b}$ agrees with $\omega$ except that its coordinate $e$ equals $b$.
