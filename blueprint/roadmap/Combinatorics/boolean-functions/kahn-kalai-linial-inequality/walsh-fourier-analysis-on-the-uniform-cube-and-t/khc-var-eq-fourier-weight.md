# Variance as Fourier weight off the empty set

For a finite set $E$ and every $g : \{0, 1\}^E \to \mathbb{R}$, the variance of $g$ under the uniform measure is

$$\mathrm{Var}(g) = \sum_{\emptyset \ne S \subseteq E} \hat g(S)^2,$$

where $\hat g(S)$ are the [Walsh–Fourier coefficients](khc-fourier-coeff.md).
