# Kahn–Kalai–Linial inequality

For every finite nonempty set $E$ and every set $A \subseteq \{0, 1\}^E$, under the uniform measure $P$ on $\{0, 1\}^E$,

$$2\, P(A)\big(1 - P(A)\big) \log \frac{1}{\max_{e \in E} \mathrm{Inf}_e(A)} \le \sum_{e \in E} \mathrm{Inf}_e(A),$$

where $\mathrm{Inf}_e(A)$ is the probability that $e$ is pivotal for $A$ and $\log(1/0)$ is read as $0$ (J. Kahn, G. Kalai, N. Linial, *The influence of variables on Boolean functions*, FOCS 1988).
