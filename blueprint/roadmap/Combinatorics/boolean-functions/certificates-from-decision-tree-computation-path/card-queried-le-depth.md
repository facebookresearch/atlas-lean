# At most depth-many variables are queried

For a [decision tree](../osss-inequality-for-decision-trees/decision-tree.md) $T$ and an input $\omega$, the set of [variables queried](../osss-inequality-for-decision-trees/queried.md) on $\omega$ has at most $\mathrm{depth}(T)$ elements. A variable queried twice on the computation path counts once, so the bound can be strict.
