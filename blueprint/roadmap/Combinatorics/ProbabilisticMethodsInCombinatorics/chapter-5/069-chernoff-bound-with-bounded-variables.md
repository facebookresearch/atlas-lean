# Theorem 5.0.5 (Chernoff bound with bounded variables)

Let each $X_i$ be an independent random variable taking values in $[-1, 1]$ and $\mathbb{E}X_i = 0$. Then $S_n = X_1 + \cdots + X_n$ satisfies $\mathbb{P}(S_n \geq \lambda\sqrt{n}) \leq e^{-\lambda^2/2}$.
