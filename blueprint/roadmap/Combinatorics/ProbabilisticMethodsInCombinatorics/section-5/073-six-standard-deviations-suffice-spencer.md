# Theorem 5.1.3 (Six standard deviations suffice: Spencer 1985)

Let $\mathcal{F}$ be a collection of $n$ subsets of $[n]$. Then there exists some assignment $[n] \to \{-1, 1\}$ so that the sum on every set in $\mathcal{F}$ is at most $6\sqrt{n}$ in absolute value. More generally, if $\mathcal{F}$ is a collection of $m \geq n$ subsets of $[n]$, then we can replace $6\sqrt{n}$ by $O(\sqrt{n \log(2m/n)})$.
