# Conjecture 5.1.5 (Komlós)

There exists some absolute constant $K$ so that for any $v_1, \ldots, v_m \in \mathbb{R}^n$ all lying in the unit ball, there exist $\varepsilon_1, \ldots, \varepsilon_m \in \{-1, 1\}$ such that $\varepsilon_1 v_1 + \cdots + \varepsilon_m v_m \in [-K, K]^n$.
