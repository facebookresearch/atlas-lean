# Lemma 2.5.3

Let $P_k$ denote the set of polynomials $g(p_1, \ldots, p_k)$ of degree $k$, whose coefficients have absolute value $\leq 1$, and the coefficient of $p_1 p_2 \cdots p_k$ is $1$. Then there is a constant $c_k > 0$ such that for all $g \in P_k$, there is some $p_1, \ldots, p_k \in [0, 1]$ with $|g(p_1, \ldots, p_k)| \geq c_k$.
