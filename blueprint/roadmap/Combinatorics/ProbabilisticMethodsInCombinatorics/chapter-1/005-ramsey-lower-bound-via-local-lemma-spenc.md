# Theorem 1.1.9 (Ramsey lower bound via local lemma; Spencer 1977)

If $\left(\binom{k}{2}\binom{n}{k-2} + 1\right) 2^{1-\binom{k}{2}} < 1/e$, then $R(k, k) > n$.
