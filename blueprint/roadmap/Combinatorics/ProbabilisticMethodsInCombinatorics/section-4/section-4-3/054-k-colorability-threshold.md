# Conjecture 4.3.16 (k-colorability threshold)

For every $k \geq 3$ there is some real constant $d_k > 0$ such that for any constant $d > 0$, $\mathbb{P}(G(n, d/n) \text{ is } k\text{-colorable}) \to 1$ if $d < d_k$, and $\mathbb{P}(G(n, d/n) \text{ is } k\text{-colorable}) \to 0$ if $d > d_k$.
