# Definition 6.1.1 (Independence from a set of events)

Here we say that an event $A_0$ is independent from events $A_1, \ldots, A_m$ if $A_0$ is independent of every event of the form $B_1 \wedge \cdots \wedge B_m$ where each $B_i$ is either $A_i$ or $\overline{A_i}$, i.e., $\mathbb{P}(A_0 B_1 \cdots B_m) = \mathbb{P}(A_0)\mathbb{P}(B_1 \cdots B_m)$, or, equivalently, using Bayes's rule: $\mathbb{P}(A_0 \mid B_1 \cdots B_m) = \mathbb{P}(A_0)$.
