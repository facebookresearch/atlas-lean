# Definition 10.1.1

Given a discrete random variable $X$ taking values in $S$, with $p_s \coloneqq \mathbb{P}(X = s)$, its entropy (or binary entropy to emphasize the base-$2$ logarithm) is defined to be $H(X) \coloneqq \sum_{s \in S} -p_s \log_2 p_s$ (by convention if $p_s = 0$ then the corresponding summand is set to zero).
