# Lemma 8.3.3

Let $k_0 = k_0(n)$ be the largest possible integer $k$ so that $\binom{n}{k} 2^{-\binom{k}{2}} \geq 1$. Then $$\mathbb{P}(\alpha(G(n, 1/2)) < k_0 - 3) \leq e^{-n^{2-o(1)}}.$$
