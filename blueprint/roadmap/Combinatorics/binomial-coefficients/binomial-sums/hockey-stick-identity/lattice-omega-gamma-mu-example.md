# Worked example of the lattice statistics omega, gamma and mu

For the lattice sequence $L = (0, 0, 0, 0, 1, 2, 2, 2, 2, 2, 4, 4, 4, 4)$ of width $12$ and height $4$ and $\eta = 9$,

$$\omega_9(L) = L_{10} - L_9 = 2, \qquad \gamma_9(L) = 4, \qquad \mu_9(L) = 9 - 1 - 4 = 4,$$

where $\gamma_9(L)$ is the largest $i < 9$ with $L_i < L_{i+1}$.
