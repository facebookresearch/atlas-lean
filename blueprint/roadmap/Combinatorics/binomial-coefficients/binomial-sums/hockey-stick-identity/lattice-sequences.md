# Lattice sequences of given width and height

For natural numbers $m$ and $h$, the set $\mathcal{L}(m, h)$ of lattice sequences of width $m$ and height $h$ consists of the sequences $(L_0, L_1, \dots, L_{m+1})$ with values in $\{0, 1, \dots, h\}$ such that

$$0 = L_0 \le L_1 \le \dots \le L_{m+1} = h.$$
