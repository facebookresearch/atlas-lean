# Debt payoff plus the equity call payoff equals the firm value

For all real firm values `V` and face values `F`, debt plus equity equals the firm value:
`min(V, F) + max(V - F, 0) = V`, where the debt payoff is `min(V, F)` and the equity payoff is the
European call payoff `max(V - F, 0)` on the firm value with strike `F`.

This is the same statement as
[Debt payoff plus the equity call payoff equals the firm value](../modigliani-miller-theorems/debt-payoff-add-european-call-payoff.md).
