# Payoff to debtholders at maturity

For real firm value `V` and face value `F`, the debt payoff at maturity is `min(V, F)`:
debtholders receive the firm value or the face value, whichever is smaller.

This is the same definition as
[Payoff to debtholders at maturity](../modigliani-miller-theorems/debt-payoff.md).
