# State-price value of a contingent payoff

For a finite set of states `Ω`, real weights `ψ` and a state-contingent payoff `X`, the
weighted-sum value is `∑_{ω ∈ Ω} ψ(ω) * X(ω)`. No positivity or normalization of `ψ` is assumed;
reading `ψ` as a state-price vector is an interpretation, not a hypothesis.
