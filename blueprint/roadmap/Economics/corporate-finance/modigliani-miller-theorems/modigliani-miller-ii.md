# Modigliani–Miller II: equity return = asset return + leverage premium

Modigliani–Miller II, the leverage identity: for real `E`, `D`, `rA`, `rD`, `rE` with equity value
`E ≠ 0`, value-weighted return accounting `(E + D) * rA = E * rE + D * rD` (the total return on
assets equals the value-weighted returns on equity and debt) gives
`rE = rA + (D / E) * (rA - rD)`: equity holders earn the asset return plus a leverage premium
proportional to the debt–equity ratio.
