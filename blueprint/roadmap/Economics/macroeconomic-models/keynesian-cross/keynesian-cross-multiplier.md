# Multiplier form of equilibrium output changes

Let `0 ≤ c < 1`. If `Y₁ = A₁ + c * Y₁` and `Y₂ = A₂ + c * Y₂` are two
Keynesian-cross equilibria with the same marginal propensity to consume `c`,
they differ by the multiplier times the change in autonomous expenditure:
`Y₂ - Y₁ = (A₂ - A₁) / (1 - c)`.
