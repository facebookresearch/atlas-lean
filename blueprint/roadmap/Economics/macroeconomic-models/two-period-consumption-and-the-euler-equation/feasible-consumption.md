# Feasible first-period consumption

The feasible first-period consumptions are the `c₀` with `c₀ ≥ 0` and `c₁ ≥ 0`,
where `c₁ = (1 + r) * (y₀ - c₀) + y₁`: both periods' consumption are
nonnegative. When `0 < 1 + r`, the constraint `0 ≤ c₁` is the natural borrowing
limit `c₀ ≤ y₀ + y₁ / (1 + r)`, so borrowing is bounded. No sign condition on
`1 + r` is imposed: if `1 + r ≤ 0`, the constraint `0 ≤ c₁` does not bound
borrowing.
