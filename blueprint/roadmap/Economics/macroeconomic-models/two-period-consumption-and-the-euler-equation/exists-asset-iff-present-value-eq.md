# Financing by an asset iff the present-value budget holds

Let `1 + r ≠ 0`. A two-date consumption plan `c` is financed by some asset
holding `a` (date-0 budget `c(0) + a = y(0)`, date-1 budget
`c(1) = (1 + r) * a + y(1)`) exactly when the present value of consumption
equals the present value of income at the rate `r`:

`c(0) + c(1) / (1 + r) = y(0) + y(1) / (1 + r)`.
