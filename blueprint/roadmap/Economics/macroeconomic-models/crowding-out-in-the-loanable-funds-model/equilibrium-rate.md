# Equilibrium interest rate of the linear model

The equilibrium interest rate of the linear loanable-funds model with saving
`S(r) = s0 + s1 * r`, investment `I(r) = i0 - i1 * r` and government deficit `D`
is `r* = (i0 + D - s0) / (s1 + i1)`, with the convention `x / 0 = 0`. When
`s1 + i1 ≠ 0` it is the rate that clears the market, `S(r*) = I(r*) + D`.
