# Explicit solution of the linear IS–LM system

Let `0 < b`, `0 < h` and `0 < k`. If `Y` and `r` solve the linear IS–LM system
`Y + b * r = A`, `k * Y - h * r = M`, then

`Y = (h * A + b * M) / (h + b * k)` and `r = (k * A - M) / (h + b * k)`,

the solution given by Cramer's rule for the nonsingular 2 × 2 system.
