# Monetary expansion raises output and lowers the interest rate

Let `0 < b`, `0 < h` and `0 < k`, and let `(Y₁, r₁)` and `(Y₂, r₂)` solve the linear
IS–LM system `Y + b * r = A`, `k * Y - h * r = M` for money supplies `M₁` and `M₂`
respectively, with the same autonomous spending `A`. If `M₁ < M₂`, then `Y₁ < Y₂`
and `r₂ < r₁`.
