# Fiscal expansion raises output and the interest rate

Let `0 < b`, `0 < h` and `0 < k`, and let `(Y₁, r₁)` and `(Y₂, r₂)` solve the linear
IS–LM system `Y + b * r = A`, `k * Y - h * r = M` for autonomous spending `A₁` and
`A₂` respectively, with the same money supply `M`. If `A₁ < A₂`, then `Y₁ < Y₂` and
`r₁ < r₂`.
