# Second eigenvalue equation of the policy matrix

For all real `a`, `b` and `d`, the matrix `A = [[a, b], [0, d]]` satisfies
`A (b, d - a) = d (b, d - a)`. The vector `(b, d - a)` is an eigenvector for `d`
when it is nonzero; it is zero (and both sides are zero) only in the degenerate
case `b = 0` and `a = d`.
