# Ricardian tax-timing invariance in a two-period model

Let `1 + r ≠ 0`, and let two tax paths `(t0, t1)` and `(t0', t1')` finance the
same government spending path `(g0, g1)` at the same rate `r`, each with its own
debt and terminal debt zero: `g0 = t0 + b0`, `g1 + (1 + r) * b0 = t1` and
`g0 = t0' + b0'`, `g1 + (1 + r) * b0' = t1'`. Then the household present-value
budget, after-tax income `(y0 - t0) + (y1 - t1) / (1 + r)`, is unchanged by the
tax-timing shift:

`(y0 - t0) + (y1 - t1) / (1 + r) = (y0 - t0') + (y1 - t1') / (1 + r)`.

No unrestricted Ricardian equivalence is claimed: the statement is only for this
finite model, with lump-sum taxes, the same spending path and the same interest
rate.
