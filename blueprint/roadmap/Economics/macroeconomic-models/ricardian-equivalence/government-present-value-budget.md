# Two-period government present-value budget

Let `1 + r ≠ 0`. With period budgets `g0 = t0 + b0` (date 0: spending is met by
taxes plus new debt) and `g1 + (1 + r) * b0 = t1` (date 1: spending plus debt
repayment is met by taxes, terminal debt zero), the present value of taxes
equals the present value of spending: `t0 + t1 / (1 + r) = g0 + g1 / (1 + r)`.
