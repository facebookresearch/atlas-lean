# Closed-form Solow steady state

The closed-form steady state of the Cobb–Douglas Solow map
`φ(k) = a * k ^ α + b * k` is `k* = (a / (1 - b)) ^ (1 / (1 - α))` (real power). It is
defined for all real `a`, `b` and `α`, with the conventions `x / 0 = 0`, `0 ^ y = 0`
for `y ≠ 0` and `x ^ y = |x| ^ y * cos (π y)` for `x < 0`: for `α = 1` the exponent
is `0` and `k* = 1`, and for `b = 1`, `α ≠ 1` it is `0`. The intended domain is
`a > 0`, `0 ≤ b < 1` and `0 < α < 1`, where it is the unique positive fixed point of
`φ`.
