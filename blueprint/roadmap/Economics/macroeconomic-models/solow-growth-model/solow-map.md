# Reduced-form Cobb–Douglas Solow map

The reduced-form discrete Solow map for Cobb–Douglas technology, with real parameters `a`, `b` and
`α`, is `φ(k) = a * k ^ α + b * k`, where `k ^ α` is the real power. It is defined for all real `a`,
`b`, `α` and `k`, with the conventions `0 ^ 0 = 1`, `0 ^ t = 0` for `t ≠ 0` and
`s ^ t = |s| ^ t * cos (π t)` for `s < 0` (so `φ(-1) = -b` at `α = 1/2`); the intended domain is
`k ≥ 0`, with `a > 0`, `0 ≤ b < 1` and `0 < α < 1`. For intensive production `f(k) = A * k ^ α`, the
per-effective-worker law of the Solow model is this map with `a = s * A / D` and `b = (1 - δ) / D`,
where `D = (1 + n) * (1 + g)`.
