# Reduced-form map agrees with the Cobb–Douglas Solow law

For `D ≠ 0`, the per-effective-worker law with Cobb–Douglas production
`f(k) = A * k ^ α` is the reduced-form Solow map with `a = s * A / D` and
`b = (1 - δ) / D`:

`(s * (A * k ^ α) + (1 - δ) * k) / D = (s * A / D) * k ^ α + ((1 - δ) / D) * k`.

This is an algebraic identity, valid for all real `s`, `δ`, `A`, `α` and `k`.
