# Feasible steady state of the Solow model

A feasible steady state at saving rate `s` is a capital per effective worker `k`
with `k ≥ 0`, output `f(k) ≥ 0` and `0 ≤ s ≤ 1` (so consumption `(1 - s) * f(k)`
and investment `s * f(k)` are nonnegative), satisfying the steady-state equation
`(1 + n) * (1 + g) * k = s * f(k) + (1 - δ) * k`.
