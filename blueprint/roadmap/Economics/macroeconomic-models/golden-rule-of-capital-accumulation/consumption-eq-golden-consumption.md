# Steady-state consumption equals the golden-rule objective

If `k` is a steady state at saving rate `s`, that is
`(1 + n) * (1 + g) * k = s * f(k) + (1 - δ) * k`, then consumption per effective
worker equals the steady-state consumption objective:

`(1 - s) * f(k) = f(k) - (δ + n + g + n * g) * k`.
