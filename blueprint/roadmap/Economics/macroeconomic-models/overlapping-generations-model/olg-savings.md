# Savings of a young worker under log utility

Savings per young worker under log utility, with discount factor `β` and wage
`w`: `s = β / (1 + β) * w`. It is defined for every real `β` and `w`: for `β = -1`
the convention `x / 0 = 0` makes it `0`; the intended domain is `β > 0`. For
`w > 0`, `β > 0` and a positive gross return, this is the saving that maximizes
`log (w - s) + β * log (R * s)` over `0 < s < w`.
