# OLG capital-market recurrence

Let `1 + n ≠ 0` and `1 + β ≠ 0`. In the two-period OLG economy with log utility,
Cobb–Douglas exponent `1/2`, full depreciation and population growth `n`, let
capital per worker follow capital-market clearing,
`k(t + 1) = s(t) / (1 + n)`, where `s(t) = β / (1 + β) * w(t)` is the saving of
the young and `w(t) = A / 2 * √(k(t))` the wage, for every `t`. Then
`k(t + 1) = C * √(k(t))` for every `t`, with `C = β * A / (2 * (1 + β) * (1 + n))`.
