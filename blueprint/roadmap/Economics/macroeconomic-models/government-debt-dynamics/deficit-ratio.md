# Primary-deficit-to-output ratio (restated)

The primary-deficit-to-output ratio at date `t` is `d(t) = D(t) / Y(t)`, the
primary deficit over the output `Y(t)` of the same period (the denominator of
the debt ratio `B(t) / Y(t)`), with the convention `x / 0 = 0`.

This is the same definition as [Primary-deficit-to-output ratio](deficit-ratio-2.md).
