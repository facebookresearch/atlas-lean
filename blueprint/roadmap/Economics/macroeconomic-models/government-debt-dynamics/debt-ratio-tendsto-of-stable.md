# Debt ratio converges at constant deficit ratio and stable coefficient

Let output be nonzero and grow as `Y(t + 1) = (1 + g) * Y(t)` with `1 + g ≠ 0`,
let debt follow `B(t + 1) = (1 + r) * B(t) + D(t + 1)`, and let the deficit ratio
be constant, `D(t + 1) / Y(t + 1) = d` for every `t`. If the coefficient is
stable, `|(1 + r) / (1 + g)| < 1`, the debt ratio `B(t) / Y(t)` converges to

`d / (1 - (1 + r) / (1 + g))`.
