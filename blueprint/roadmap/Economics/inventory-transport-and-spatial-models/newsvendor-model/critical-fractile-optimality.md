# Critical-fractile optimality in the newsvendor model

Let demand $D \ge 0$ be integrable with distribution function $F(q) = P(D \le q)$ and left limit $F(q^-) = P(D < q)$, and let $h, b > 0$ be overage and underage costs. The expected cost $C(q) = E[h(q - D)^+ + b(D - q)^+]$ is finite and convex on $q \ge 0$, with right derivative $(h + b)F(q) - b$ and, for $q > 0$, left derivative $(h + b)F(q^-) - b$. Hence $q > 0$ is a minimizer if and only if $F(q^-) \le b/(b+h) \le F(q)$, and $q = 0$ is a minimizer if and only if $b/(b+h) \le F(0)$. The minimizers form a nonempty closed interval containing the $b/(b+h)$-quantile of $D$; it is a single point unless $F$ equals $b/(b+h)$ on a nondegenerate interval.
