# Choosing after seeing the state is worth at least the best commitment

Raiffa and Schlaifer, Chapter 4, Section 5. Let `Ω` be a finite set of states with nonnegative
weights `p(ω) ≥ 0`, `A` a finite nonempty set of actions and `U(a, ω)` the payoff of action `a` in
state `ω`. Then the expected value of perfect information is nonnegative:
`∑_ω p(ω) maxₐ U(a, ω) - maxₐ ∑_ω p(ω) U(a, ω) ≥ 0`. Choosing the action after seeing the state is
worth at least committing to the best single action.

This is the same result as
[Choosing after seeing the state is worth at least the best commitment](../../corporate-finance/real-options/max-commitment-le-option-value.md).
Here it is written as a nonnegative difference; the linked page writes it as an inequality.
