# Certainty equivalent of a finite monetary lottery

Consider the finite monetary lottery that pays `z(x)` in state `x` of a finite set, with probability
`p(x)` (a probability vector `p`). For a Bernoulli utility `u` and a set `I` of amounts (any subset
of `ℝ`, typically an interval), a number `c` is a certainty equivalent of the lottery on `I` when
`c ∈ I` and the sure amount `c` has the same utility as the lottery: `u(c) = ∑ₓ p(x) u(z(x))`.
