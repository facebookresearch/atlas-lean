# CDF dominance implies upper-set dominance

For lotteries `p`, `q` on a finite linearly ordered set of prizes, if `q` first-order dominates `p`
(`∑_{x ≤ t} q(x) ≤ ∑_{x ≤ t} p(x)` for every `t`), then `q` puts at least as much probability as `p`
on every upward-closed set `U` of prizes: `∑_{x ∈ U} p(x) ≤ ∑_{x ∈ U} q(x)`. This is the upper-set
dominance of Strassen's theorem.
