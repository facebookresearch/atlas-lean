# A monotone coupling orders expected utilities

Let `p`, `q` be lotteries on a finite preordered set of prizes, and let `π(x, y) ≥ 0` be a coupling
with marginals `p` and `q` (`∑_y π(x, y) = p(x)`, `∑_x π(x, y) = q(y)`) supported on the pairs with
`x ≤ y` (`π(x, y) = 0` otherwise). Then `∑ₓ p(x) u(x) ≤ ∑ₓ q(x) u(x)` for every nondecreasing `u`.
