# First-order dominance raises expected utility, given Strassen

Let the set of prizes be finite and linearly ordered, and assume the finite Strassen coupling
theorem: for all nonnegative `p`, `q` on the prizes with equal totals such that
`∑_{x ∈ U} p(x) ≤ ∑_{x ∈ U} q(x)` for every upward-closed set `U`, there is a coupling `π(x, y) ≥ 0`
with marginals `p` and `q` supported on the pairs with `x ≤ y`. Then if the lottery `q` first-order
dominates the lottery `p`, `∑ₓ p(x) u(x) ≤ ∑ₓ q(x) u(x)` for every nondecreasing utility `u`.
