# Expected utility is unique up to positive affine transformation

Uniqueness of expected-utility representations (Gonçalves, Theorem 1(ii)). For a finite set `X` of
outcomes, if `u, v : X → ℝ` both represent the same relation `≿` on lotteries over `X`
(`p ≿ q ⟺ E_p[u] ≥ E_q[u]`, and likewise for `v`), then `v = a u + b` for some `a > 0` and `b ∈ ℝ`.
No nondegeneracy is assumed: if `u` is constant, so is `v`.
