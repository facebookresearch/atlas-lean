# Choice from a represented preference maximizes utility

If a real utility `u` represents a rational preference `≿` (`x ≿ y ⟺ u(x) ≥ u(y)`), then for every
menu `B` the choice set `C(B; ≿) = {x ∈ B | x ≿ y for all y ∈ B}` equals the set
`{x ∈ B | u(y) ≤ u(x) for all y ∈ B}` of maximizers of `u` on `B` (Levin–Milgrom, §4).
