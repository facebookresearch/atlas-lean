# Chained real value of a single component

The chained real value of component `j` is the same two-link chaining applied to
the one-good basket consisting of `j` alone, so each link is `j`'s own Laspeyres
volume growth: `p₀(j) * q₀(j) * g₁(j) * g₂(j)`, where
`g₁(j) = (p₀(j) * q₁(j)) / (p₀(j) * q₀(j))` and
`g₂(j) = (p₁(j) * q₂(j)) / (p₁(j) * q₁(j))`, with the convention `x / 0 = 0`.
