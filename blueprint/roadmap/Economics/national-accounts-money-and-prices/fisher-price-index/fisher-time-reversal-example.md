# Numerical example of Fisher time reversal

For the two-good basket with base prices `(1, 2)`, current prices `(2, 3)` and
basket `(1, 1)` in both periods, the reversed Fisher index times the forward
Fisher index equals `1`. Here Laspeyres = Paasche = `5/3`, so the forward Fisher
index is `5/3` and the reversed index is `3/5`.
