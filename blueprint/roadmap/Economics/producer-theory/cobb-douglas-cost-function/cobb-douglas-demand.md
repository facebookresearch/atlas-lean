# Cobb–Douglas conditional factor demand

For finitely many inputs, the Cobb–Douglas conditional factor demand for input `i` is
`xᵢ* = (aᵢ / wᵢ) · c(w, q)`, where `c(w, q) = (q / A) ∏ᵢ (wᵢ / aᵢ) ^ aᵢ` is the closed-form cost. It
is defined for all real arguments: by the convention `x / 0 = 0`, `xᵢ* = 0` when `wᵢ = 0` or
`A = 0`, and the cost uses `0^0 = 1`, `0^y = 0` for `y ≠ 0` and `x^y = |x|^y cos(π y)` for `x < 0`;
the intended domain is `A > 0`, `aᵢ > 0` and `wᵢ > 0`.
