# Conditional factor demands produce the target output

For finitely many inputs, let `A > 0`, exponents `aᵢ > 0` with `∑ᵢ aᵢ = 1` and input prices
`wᵢ > 0`, and let `q ≥ 0`. Then the conditional factor demands `xᵢ* = (aᵢ / wᵢ) · c(w, q)`, with
`c(w, q) = (q / A) ∏ᵢ (wᵢ / aᵢ) ^ aᵢ`, produce exactly the target output: `A ∏ᵢ (xᵢ*) ^ aᵢ = q`.
