# Cobb–Douglas production function

For finitely many inputs, a productivity `A` and exponents `aᵢ`, the Cobb–Douglas production
function of an input bundle `x` is `f(x) = A ∏ᵢ xᵢ ^ aᵢ` (real powers). It is defined for all real
arguments, with the conventions `0 ^ 0 = 1`, `0 ^ t = 0` for `t ≠ 0` and
`s ^ t = |s| ^ t * cos (π t)` for `s < 0`; the intended domain is `A > 0`, `aᵢ > 0` and `xᵢ ≥ 0`.
