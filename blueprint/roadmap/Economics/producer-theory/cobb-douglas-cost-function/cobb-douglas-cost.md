# Closed-form Cobb–Douglas cost expression

For finitely many inputs, a productivity `A`, exponents `aᵢ`, input prices `wᵢ` and an output level
`q`, the closed-form Cobb–Douglas cost is `c(w, q) = (q / A) ∏ᵢ (wᵢ / aᵢ) ^ aᵢ` (real powers). It is
defined for all real arguments, with the conventions `x / 0 = 0` (so it is `0` when `A = 0`),
`0^0 = 1`, `0^y = 0` for `y ≠ 0` and `x^y = |x|^y cos(π y)` for `x < 0`; the intended domain is
`A > 0`, `aᵢ > 0` and `wᵢ > 0`.
