# Profit-maximizing production plan

For finitely many goods, a production set `Y` of feasible net-output vectors and prices `p`, a plan
`y` maximizes profit when `y ∈ Y` and `p · y' ≤ p · y` for every `y' ∈ Y`: no feasible plan earns
more profit. Price-taking is built in: profit is linear in `y` at the given prices.
