# Nonnegative prices lie in the cost function's domain

For finitely many inputs, if the input requirement set `V` is nonempty and all its bundles are
nonnegative, then every nonnegative price vector `w ≥ 0` lies in the finite-valued domain
`{w | V ≠ ∅ and {w · x | x ∈ V} is bounded below}` of the cost function.
