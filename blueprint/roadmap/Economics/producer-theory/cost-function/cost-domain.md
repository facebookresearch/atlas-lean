# Finite-valued domain of the cost function

For finitely many inputs and an input requirement set `V`, the finite-valued domain of the cost
function `c(w) = inf {w · x | x ∈ V}` is the set `{w | V ≠ ∅ and {w · x | x ∈ V} is bounded below}`
of input prices at which the target output is attainable and cost is bounded below. It is empty when
the target is unattainable, so the convention that the real infimum of the empty set is `0` never
gives a cost on it.
