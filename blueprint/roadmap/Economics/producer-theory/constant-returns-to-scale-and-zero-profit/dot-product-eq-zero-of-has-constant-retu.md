# An attained profit maximum under constant returns is zero

For finitely many goods, let the production set `Y` have constant returns to scale (`y ∈ Y`, `t ≥ 0`
imply `t y ∈ Y`). If a plan `y` maximizes profit at prices `p` (`y ∈ Y` and `p · z ≤ p · y` for
every `z ∈ Y`), then the maximal profit is zero: `p · y = 0`.
