# At a constant-returns profit maximum, no plan earns positive profit

For finitely many goods, let the production set `Y` have constant returns to scale (`y ∈ Y`, `t ≥ 0`
imply `t y ∈ Y`). If some plan maximizes profit over `Y` at prices `p`, then no feasible plan earns
positive profit at `p`: `p · z ≤ 0` for every `z ∈ Y`.
