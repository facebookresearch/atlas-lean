# Input-weighted marginal products sum to output

Let `f` be a production function of finitely many inputs that has derivative `L` (a linear map) at
the input bundle `x` and constant returns along `x`: `f(t x) = t f(x)` for every `t > 0`. Then the
marginal products `∂f/∂xᵢ = L eᵢ` (`eᵢ` the `i`-th unit vector), weighted by the input quantities,
sum to output: `∑ᵢ (∂f/∂xᵢ)(x) · xᵢ = f(x)`.
