# Competitive factor payments exhaust the value of output

Product exhaustion. Let `f` be a production function of finitely many inputs that has derivative `L`
(a linear map) at the input bundle `x` and constant returns along `x`: `f(t x) = t f(x)` for every
`t > 0`. If each input is paid the value of its marginal product at output price `P`,
`wᵢ = P · ∂f/∂xᵢ = P · L eᵢ` (`eᵢ` the `i`-th unit vector), then total factor payments equal the
value of output: `w · x = P f(x)`.
