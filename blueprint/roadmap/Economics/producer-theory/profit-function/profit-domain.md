# Finite-valued domain of the profit function

For finitely many goods and a production set `Y`, the finite-valued domain of the profit function
`π(p) = sup {p · y | y ∈ Y}` is the set `{p | Y ≠ ∅ and {p · y | y ∈ Y} is bounded above}` of prices
at which some plan is feasible and profit is bounded above. It is empty when `Y` is empty, so the
convention that the real supremum of the empty set is `0` never gives a profit on it.
