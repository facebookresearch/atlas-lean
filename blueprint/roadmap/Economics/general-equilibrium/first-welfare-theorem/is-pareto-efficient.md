# Pareto efficient allocation

In a pure exchange economy with finitely many agents, utilities `uᵢ` and endowments `ωᵢ`, an
allocation `x` is Pareto efficient when it is feasible (`xᵢ ≥ 0` and `∑ᵢ xᵢ ≤ ∑ᵢ ωᵢ`) and no
feasible allocation `y` has `uᵢ(yᵢ) ≥ uᵢ(xᵢ)` for every agent and `uᵢ(yᵢ) > uᵢ(xᵢ)` for some agent.
