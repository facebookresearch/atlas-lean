# Examples where a competitive equilibrium is not Pareto optimal

(Externality.) Two agents, two goods, endowments $e_A = (1, 0)$, $e_B = (0, 1)$, utilities $u_A = x_{A1} + x_{A2}$ and $u_B = x_{B1} + x_{B2} - 3x_{A2}$, so $B$'s preferences depend on the whole allocation. In a competitive equilibrium with this externality, each agent maximizes utility over its own budget set taking the other agent's bundle as given, and markets clear. At prices $(1, 1)$ the allocation $x_A = (0, 1)$, $x_B = (1, 0)$ is such an equilibrium: each bundle costs the agent's wealth $1$ and maximizes the agent's utility on the budget set with the other bundle fixed. It gives utilities $(1, -2)$, while the feasible allocation $x_A = (1, 0)$, $x_B = (0, 1)$ gives $(1, 1)$, a Pareto improvement under these allocation-dependent preferences.

(Satiation.) Here each utility depends only on the agent's own bundle, as in the model of a Walrasian equilibrium. Two agents, two goods, $e_A = (2, 2)$, $e_B = (0, 0)$, $u_A = \min(x_{A1}, 1) + \min(x_{A2}, 1)$, which is satiated at every bundle at least $(1, 1)$, and $u_B = x_{B1} + x_{B2}$. At any prices with both entries positive, $x_A = (2, 2)$, $x_B = (0, 0)$ is a Walrasian equilibrium, with utilities $(2, 0)$; the allocation $x_A = x_B = (1, 1)$ gives $(2, 2)$. In both examples a hypothesis of the first welfare theorem fails: no externalities in the first, local nonsatiation in the second.

## Expansion

The externality example needs its own definitions before it can be stated formally: preferences that depend on the whole allocation, competitive equilibrium in which each agent takes the other agents' bundles as given, and Pareto efficiency for such preferences. The existing definition of a Walrasian equilibrium gives each agent a utility of its own bundle only and covers the satiation example.
