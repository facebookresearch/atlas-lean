# Leontief balance condition for gross output

The Leontief balance condition for an input matrix `A` (a square real matrix over a finite set of
sectors), final demand `d` and gross output `x`: gross output equals intermediate demand plus final
demand, `x = A x + d`. Here `A i j` is the input of sector `i` needed per unit of sector `j`'s
output. The condition is only this equation: no sign condition on `A`, `d` or `x` is imposed.
