# Neumann series for the Leontief inverse when row sums are below one

Let `A` be a square matrix over a finite index set with nonnegative entries and every row sum below
one (`∑ⱼ A i j < 1` for each `i`). Then the power series `∑ₙ Aⁿ` (over `n ≥ 0`) converges entrywise
to the inverse `(1 - A)⁻¹` of `1 - A`.
