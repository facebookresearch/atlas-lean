# Final-demand monotonicity of gross output (row-sum contraction regime)

Let `A` be a square input matrix over a finite set of sectors, with nonnegative entries and every
row sum below one: `∑ⱼ A i j < 1` for each `i` (for such `A` this says that its `ℓ∞` operator norm
is `< 1`). If `x = A x + d` and `x' = A x' + d'` with `d ≤ d'` entrywise, then `x ≤ x'` entrywise:
increasing final demand weakly increases the gross output that meets it.
