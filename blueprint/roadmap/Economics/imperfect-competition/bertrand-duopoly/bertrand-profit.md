# Profit of a Bertrand duopolist

When both firms have the same constant marginal cost `c` and no fixed cost, the profit of firm `i`
at the price profile `p` is `πᵢ(p) = (pᵢ - c) qᵢ(p)`, where `qᵢ(p) = D(pᵢ)` if `pᵢ < pⱼ`,
`D(pᵢ) / 2` if `pᵢ = pⱼ` and `0` if `pᵢ > pⱼ` (`j` the rival) is the quantity it sells.
