# Profit shortfall is quadratic in the output gap

In the linear monopoly model (inverse demand `P(q) = a - b q` with `b > 0`, constant marginal cost
`c < a`), with profit `π(q) = (a - b q) q - c q` and monopoly quantity `q_m = (a - c) / (2 b)`, the
profit gap to the monopoly quantity is a scaled square: `π(q_m) - π(q) = b (q - q_m)²` for every
quantity `q`.
