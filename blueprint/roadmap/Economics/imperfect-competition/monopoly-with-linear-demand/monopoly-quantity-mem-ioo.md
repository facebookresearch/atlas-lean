# Monopoly output is positive but below the efficient level

In the linear monopoly model (inverse demand `P(q) = a - b q` with `b > 0`, constant marginal cost
`c < a`), the monopoly trades a positive quantity, strictly less than the efficient quantity:
`0 < q_m < q_c`, where `q_m = (a - c) / (2 b)` and `q_c = (a - c) / b`.
