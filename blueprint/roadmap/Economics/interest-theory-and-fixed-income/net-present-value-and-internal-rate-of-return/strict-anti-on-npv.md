# NPV strictly decreases in r for nonnegative later flows

If the later cash flows are nonnegative, `c_k ≥ 0` for `1 ≤ k ≤ N`, and at least one of them
is positive (`c_0` is arbitrary), the net present value `NPV(r) = ∑_{k=0}^{N} c_k / (1 + r)ᵏ`
is strictly decreasing in the rate `r` on `(-1, ∞)`.

This is the same statement as
[NPV strictly decreases in r for nonnegative later flows (restated)](strict-anti-on-npv-2.md). Here
the net present value is written `∑_{k=0}^{N} c_k / (1 + r)ᵏ`; the linked page writes it with the
discount factors `(1 + r)⁻ᵏ`.
