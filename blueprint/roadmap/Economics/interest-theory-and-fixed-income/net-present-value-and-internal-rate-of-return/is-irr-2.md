# Internal rate of return of a project (restated)

A rate `r` is an internal rate of return of the cash flows `c_0, …, c_N` if `r > -1` and the
net present value computed with the discount factors `(1 + r)⁻ᵏ` is zero there:
`∑_{k=0}^{N} (1 + r)⁻ᵏ c_k = 0`.

This is the same definition as [Internal rate of return of a project](is-irr.md). Here the net
present value is written with the discount factors `(1 + r)⁻ᵏ`; the linked page writes it as
`∑_{k=0}^{N} c_k / (1 + r)ᵏ`.
