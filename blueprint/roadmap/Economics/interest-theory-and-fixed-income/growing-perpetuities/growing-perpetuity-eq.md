# Gordon formula for the value of a growing perpetuity

For real `C₁`, `r` and `g` with `1 + r > 0` and `0 ≤ (1 + g) / (1 + r) < 1`, a growing
perpetuity paying `C₁ (1 + g)ᵗ` at date `t + 1` (`t = 0, 1, 2, …`), discounted at the rate
`r`, is worth `∑_{t=0}^{∞} C₁ (1 + g)ᵗ (1 + r)^{-(t+1)} = C₁ / (r - g)`.

This is the same result as
[Gordon formula for the value of a growing perpetuity](../../corporate-finance/gordon-growth-model/dividend-gordon-tsum.md).
Here the terms are indexed from the first payment; the linked page indexes them by payment date,
starting with a zero term at date 0.
