# Present value of a level annuity-immediate

The present value of a level annuity-immediate, one unit paid at each of the dates `1, …, n`
and discounted at a constant per-period rate `r`, is `a_n = ∑_{t=1}^{n} vᵗ` with
`v = (1 + r)⁻¹`; `a_0 = 0`. It is defined for every real `r`, with the convention `0⁻¹ = 0`:
at `r = -1` every term is `0`, so `a_n = 0`.
