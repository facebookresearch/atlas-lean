# Convexity beats the tangent-line duration approximation

If `c_t ≥ 0` at every date `t` of a finite set `s ⊆ ℕ`, the present value
`P(r) = ∑_{t ∈ s} c_t (1 + r)⁻ᵗ` lies above its tangent line at any yield `r₀ > -1`: for
every `r > -1`, `P(r) ≥ P(r₀) + P′(r₀)(r - r₀)`, where
`P′(r₀) = -(∑_{t ∈ s} t c_t (1 + r₀)⁻ᵗ) / (1 + r₀)` is the derivative of `P` at `r₀`.
