# Feasible portfolio for a target expected return

For finitely many assets with expected returns `μ_i`, a portfolio `w` is feasible for target
expected return `m` when it is fully invested (`∑_i w_i = 1`, the budget constraint) and has
expected return `∑_i μ_i w_i = m` (the mean constraint). Weights may be negative: short sales are
allowed.
