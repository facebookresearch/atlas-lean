# State-price vector from a pricing probability

For a real function `q` on the states (in use, a strictly positive pricing probability) and
a gross risk-free return `R`, the induced state-price vector is `ψ(ω) = q(ω) / R` for every
state `ω`. No condition on `q` or `R` is imposed; with the convention `x / 0 = 0`, `ψ = 0`
when `R = 0`.
