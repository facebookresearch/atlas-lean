# The d₂ term of the Black–Scholes formula

For real `S0`, `K`, `r`, `σ` and `T`, the Black–Scholes `d₂` is `d₂ = d₁ - σ √T`, where
`d₁ = (log (S0 / K) + (r + σ²/2) T) / (σ √T)`. With the conventions `x / 0 = 0` and `√T = 0` for
`T ≤ 0`, `d₂ = d₁ = 0` when `σ = 0` or `T ≤ 0`. When `S0 / K ≤ 0`, [`d₁`](d1.md) uses the
conventions `log 0 = 0` and `log x = log |x|`. It has its usual meaning for `S0, K, σ, T > 0`.
