# The d₁ term of the Black–Scholes formula

For real `S0`, `K`, `r`, `σ` and `T`, the Black–Scholes `d₁` is
`d₁ = (log (S0 / K) + (r + σ²/2) T) / (σ √T)`, with its usual meaning for `S0, K, σ, T > 0`. The
formula is read with the conventions `x / 0 = 0` and `√T = 0` for `T ≤ 0`, so that `d₁ = 0` when
`σ = 0` or `T ≤ 0`, and with `log 0 = 0` and `log x = log |x|` when `S0 / K ≤ 0`.
