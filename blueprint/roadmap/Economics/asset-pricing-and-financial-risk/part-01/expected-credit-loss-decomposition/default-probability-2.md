# Probability of the default event (restated)

The default probability of a default event `D` under a measure `μ` is the real number `μ(D)`:
the probability `P(D)` when `μ` is a probability measure (and `0` by convention if
`μ(D) = ∞`).

This is the same definition as [Probability of the default event](default-probability.md).
