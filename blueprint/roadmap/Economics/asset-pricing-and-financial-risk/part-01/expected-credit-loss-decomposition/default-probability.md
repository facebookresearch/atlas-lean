# Probability of the default event

For a measure `μ` and a default event `D`, the default probability is `μ(D)` as a real number:
the probability `P(D)` of default when `μ` is a probability measure (if `μ(D) = ∞`, the real
value is `0` by convention).

This is the same definition as
[Probability of the default event (restated)](default-probability-2.md).
