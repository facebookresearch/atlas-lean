# Long-only portfolios with a given expected return

For finitely many assets with expected returns `μ_i` and a target return `m`, the long-only
target-return slice is the set of weight vectors `w` with `w_i ≥ 0` for every asset `i`, fully
invested (`∑_i w_i = 1`) and with expected return `∑_i μ_i w_i = m`.
