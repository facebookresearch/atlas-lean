# State-price value of a contingent payoff

For state prices `ψ(ω)` on a finite state space, the state-price value of a state-contingent
payoff `X` is `∑_ω ψ(ω) X(ω)`, a linear pricing functional. No positivity of `ψ` is assumed;
under no arbitrage, the fundamental theorem of asset pricing provides strictly positive state
prices.

This is the same definition as
[State-price value of a contingent payoff](../../../corporate-finance/modigliani-miller-theorems/weighted-value.md).
