# Portfolio return as the value-weighted average of asset returns

Consider holdings `h i` of the assets `i` of a finite set `s`, whose prices move from `P₀ i` to
`P₁ i`, with every initial price `P₀ i` nonzero and nonzero initial wealth
`W₀ = ∑_{i ∈ s} h i · P₀ i`. Then the one-period portfolio return is the initial-value-weighted
average of the asset returns:
`(W₁ - W₀) / W₀ = ∑_{i ∈ s} (h i · P₀ i / W₀) · (P₁ i - P₀ i) / P₀ i`, where
`W₁ = ∑_{i ∈ s} h i · P₁ i`.
