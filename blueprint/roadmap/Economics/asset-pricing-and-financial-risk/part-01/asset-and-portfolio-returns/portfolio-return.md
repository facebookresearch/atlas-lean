# Portfolio return over one period

The one-period return of a portfolio holding `h i` units of each asset `i` of a finite set `s`,
whose prices move from `P₀ i` to `P₁ i`, is `(W₁ - W₀) / W₀`, where `W₀ = ∑_{i ∈ s} h i · P₀ i` and
`W₁ = ∑_{i ∈ s} h i · P₁ i` are the initial and terminal wealth. With the convention `x / 0 = 0`
it is `0` when `W₀ = 0`.
