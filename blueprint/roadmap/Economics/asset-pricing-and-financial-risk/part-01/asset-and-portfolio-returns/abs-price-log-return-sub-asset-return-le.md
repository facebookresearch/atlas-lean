# A change g of size at most 1/2 has log change within g² of g

For real `x₀` and `x₁`, if the percentage change `g = (x₁ - x₀) / x₀` satisfies `|g| ≤ 1/2`, the
log change differs from it by at most its square: `|log (x₁ / x₀) - g| ≤ g²`. For a nonzero base
the condition keeps `x₁ / x₀ = 1 + g` in `[1/2, 3/2]`, so the two values have the same sign (both
positive for a positive base); at a zero base both measures are `0`, by the conventions
`x / 0 = 0` and `log 0 = 0`.
