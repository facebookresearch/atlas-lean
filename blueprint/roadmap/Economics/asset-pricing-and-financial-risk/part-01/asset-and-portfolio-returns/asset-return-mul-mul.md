# A common nonzero rescaling leaves the percentage change unchanged

Multiplying the base and the later value by the same nonzero factor `c` (a change of units
applied to both) leaves the percentage change unchanged: for all real `x₀` and `x₁`,
`(c x₁ - c x₀) / (c x₀) = (x₁ - x₀) / x₀`. At a zero base both sides are `0`, by the convention
`x / 0 = 0`.
