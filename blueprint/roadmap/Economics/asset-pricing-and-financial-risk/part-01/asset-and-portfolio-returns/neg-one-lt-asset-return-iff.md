# A change exceeds −100% iff a positive value stays positive

For a positive base `x₀` and any later value `x₁`, the percentage change exceeds `-1` if and only
if the later value is positive: `(x₁ - x₀) / x₀ > -1` if and only if `x₁ > 0`. A change of exactly
`-1` reaches zero, and a smaller one gives a negative value.
