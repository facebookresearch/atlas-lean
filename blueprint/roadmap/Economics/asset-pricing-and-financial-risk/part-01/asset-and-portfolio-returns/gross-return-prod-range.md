# Gross returns telescope over a price path

For a real price path `P(0), P(1), …` and a number of periods `n ≥ 0` with `P(0) ≠ 0` and
`P(i) ≠ 0` for every `i < n`, the product of the one-period gross returns is the gross return from
`P(0)` to `P(n)`: `∏_{i=0}^{n-1} P(i+1) / P(i) = P(n) / P(0)`. Only the prices that appear as
denominators need to be nonzero: the terminal price `P(n)` may be zero (a total loss), and the
prices after time `n` are unconstrained.
