# Gross return over one period

The gross return over one period from initial price `P₀` to terminal price `P₁`, for real `P₀`
and `P₁`, is `P₁ / P₀`. A zero terminal price is a total loss, with gross return `0`. With the
convention `x / 0 = 0` the gross return is also `0` when `P₀ = 0`, a conventional value rather
than a return.
