# Total log return over several periods

The total log return over a finite set `s` of periods with real per-period gross returns `G i` is
the log return of the compounded gross return, `log ∏_{i ∈ s} G i`. With the conventions
`log 0 = 0` and `log x = log |x|`, it is `0` when some `G i` is `0`, and `log |∏_{i ∈ s} G i|`
when the product is negative.
