# Risk-neutral default probability as a sum of state weights

For any state prices `ψ(ω)` on a finite state space and any set of default states, the
risk-neutral default probability `q_D = (∑_{ω default} ψ(ω)) / D`, where `D = ∑_ω ψ(ω)`, equals
`∑_{ω default} ψ(ω) / D`, the total weight of the default states under the weights `ψ(ω) / D`
(the risk-neutral probabilities when the state prices are positive). With the convention
`x / 0 = 0`, both sides are `0` when `D = 0`.
