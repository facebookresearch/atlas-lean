# Risk-neutral up probability of the binomial model

For real up and down factors `u`, `d` and a per-period gross riskless return `R`, the
risk-neutral up probability is `q = (R - d) / (u - d)`, with the convention x / 0 = 0, so `q = 0`
when `u = d`. No condition is imposed on `u`, `d`, `R`; `q` lies in `(0, 1)` when `d < R < u`.
