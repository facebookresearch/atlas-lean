# No one-step arbitrage iff the risk-neutral probability is in (0, 1)

For `S₀ > 0` and `0 < d < u` (and any real `R`), the one-step bond/stock model (bond price `1`
today and `R` at expiry; stock price `S₀` today and `u * S₀` in the up state or `d * S₀` in the
down state) has no one-step arbitrage if and only if the risk-neutral up probability
`q = (R - d) / (u - d)` satisfies `0 < q < 1`.
