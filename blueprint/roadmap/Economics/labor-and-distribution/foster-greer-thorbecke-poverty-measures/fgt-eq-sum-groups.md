# Subgroup decomposability of FGT

For every poverty line `z` and parameter `α`: if every member of the finite
population `s` is assigned by `g` to a group in the finite set `t`, then

`FGT_α(s) = ∑_{k ∈ t} (|s_k| / |s|) * FGT_α(s_k)`, where `s_k = {i ∈ s : g(i) = k}`,

the population-share-weighted sum of the groups' measures. Empty groups get
weight `0`.
