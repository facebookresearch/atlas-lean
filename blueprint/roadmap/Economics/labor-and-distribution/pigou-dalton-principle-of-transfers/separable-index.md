# Additively separable inequality index

The additively separable inequality index of the income distribution `x` over a
finite population of `n` individuals, for an evaluation function `φ : ℝ → ℝ`, is
`(∑_i φ(x(i))) / n`. It is defined for every finite population: for an empty
population (`n = 0`) the sum is empty and the convention `x / 0 = 0` makes the index
`0`; the intended domain is `n ≥ 1`. The definition puts no condition on `φ`; the
transfer results take `φ` convex. At a fixed mean, `φ(y) = y ^ 2` gives the variance
up to a constant and `φ(y) = y * log y` gives the Theil index up to a constant.
