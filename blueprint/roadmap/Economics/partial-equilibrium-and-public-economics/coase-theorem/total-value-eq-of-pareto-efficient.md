# Efficient allocations have the same total value under any endowment

Coase invariance. For a finite nonempty set of agents with quasilinear utilities `vᵢ(a) + mᵢ`, let
`(a, m)` be Pareto efficient given the money endowment `ω` and `(a', m')` Pareto efficient given the
money endowment `ω'` (two property-rights assignments). Then `∑ᵢ vᵢ(a) = ∑ᵢ vᵢ(a')`; in particular,
if the total-value maximizer is unique, then `a = a'`.
