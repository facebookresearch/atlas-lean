# Efficient, individually rational bargains exist at total-value maxima

For a finite nonempty set of agents with quasilinear utilities `vᵢ(a) + mᵢ`, take any
property-rights assignment: a status-quo allocation `a₀` and money endowment `ω`. If the allocation
`a` maximizes total value (`∑ᵢ vᵢ(a') ≤ ∑ᵢ vᵢ(a)` for every `a'`), there are money holdings `m` such
that `(a, m)` is Pareto efficient given `ω` (in particular `∑ᵢ mᵢ = ∑ᵢ ωᵢ`) and individually
rational relative to the status quo: `vᵢ(a₀) + ωᵢ ≤ vᵢ(a) + mᵢ` for every agent `i`.
