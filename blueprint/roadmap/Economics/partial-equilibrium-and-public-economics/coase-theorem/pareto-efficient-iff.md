# Under quasilinear utility, efficiency maximizes total value

For a finite nonempty set of agents with quasilinear utilities `vᵢ(a) + mᵢ` and money endowment `ω`,
an outcome `(a, m)` is Pareto efficient exactly when the money is feasible, `∑ᵢ mᵢ = ∑ᵢ ωᵢ`, and the
physical allocation `a` maximizes total value: `∑ᵢ vᵢ(a') ≤ ∑ᵢ vᵢ(a)` for every allocation `a'`.
