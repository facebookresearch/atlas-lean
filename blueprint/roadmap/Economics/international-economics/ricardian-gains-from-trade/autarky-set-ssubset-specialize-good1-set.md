# Gains from specializing in good 1 iff world price exceeds autarky

For a [country](country.md) with unit labor requirements `a₁, a₂ > 0` and labor endowment `L > 0`,
and a world relative price `p > 0`, the consumption set `{x ≥ 0 | p x₁ + x₂ ≤ p (L / a₁)}` of
complete specialization in good 1 strictly contains the autarky set `{x ≥ 0 | a₁ x₁ + a₂ x₂ ≤ L}` if
and only if `p` exceeds the autarky price `a₁ / a₂`.
