# Gains from specializing in good 2 iff world price is below autarky

For a [country](country.md) with unit labor requirements `a₁, a₂ > 0` and labor endowment `L > 0`,
and a world relative price `p > 0`, the consumption set `{x ≥ 0 | p x₁ + x₂ ≤ L / a₂}` of complete
specialization in good 2 strictly contains the autarky set `{x ≥ 0 | a₁ x₁ + a₂ x₂ ≤ L}` if and only
if `p` is below the autarky price `a₁ / a₂`.
