# Two-good Cobb–Douglas utility

For a real exponent `α`, the normalized two-good Cobb–Douglas utility of a bundle `x = (x₀, x₁)` is
`u(x) = x₀ ^ α * x₁ ^ (1 - α)` (real powers; the exponents `α` and `1 - α` sum to one). It is
defined for all real `α` and `x`, with the conventions `0 ^ 0 = 1`, `0 ^ t = 0` for `t ≠ 0` and
`s ^ t = |s| ^ t * cos (π t)` for `s < 0`, so a negative good is not raised to a real root: at
`x = (-1, 1)` and `α = 1/3` the value is `1/2`. The intended domain is `0 < α < 1` and `x₀, x₁ ≥ 0`.
