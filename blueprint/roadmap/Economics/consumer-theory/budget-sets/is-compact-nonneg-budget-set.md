# Nonnegative budget sets are compact at positive prices

For finitely many goods and strictly positive prices (`p i > 0` for every `i`), the budget set of
nonnegative bundles `{x | x i ≥ 0 for every i, p · x ≤ w}` is compact, for every wealth `w`.

This is the same statement as
[Nonnegative budget sets are compact at positive prices](../marshallian-demand/is-compact-budget-set-consumption-set.md).
