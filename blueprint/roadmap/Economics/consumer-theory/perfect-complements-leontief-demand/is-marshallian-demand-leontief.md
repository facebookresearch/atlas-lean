# Kink bundle maximizes perfect-complements utility

Let `a, b > 0`, let both prices be positive (`p₀, p₁ > 0`) and let `w ≥ 0`. Then the kink bundle
`x = (t / a, t / b)`, `t = w / (p₀ / a + p₁ / b)`, maximizes the perfect-complements utility
`u(y) = min(a y₀, b y₁)` over the budget set `{y ∈ ℝ² | y ≥ 0, p · y ≤ w}`: it lies in that set and
`u(y) ≤ u(x)` for every `y` in it.
