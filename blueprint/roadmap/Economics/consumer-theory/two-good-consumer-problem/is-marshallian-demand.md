# Utility-maximizing (Marshallian) demand

For a utility `u` on bundles of finitely many goods and a consumption set `X`, a bundle `x` is a
Marshallian (utility-maximizing) demand at prices `p` and wealth `w` when it lies in the budget set
`B(p, w) = {y ∈ X | p · y ≤ w}` and `u(y) ≤ u(x)` for every `y ∈ B(p, w)`.

This is the same definition as
[Utility-maximizing (Marshallian) demand](../duality-of-expenditure-and-indirect-utility/is-marshallian-demand.md).
