# Nonnegative budget sets are compact at positive prices

Levin, *Consumer Theory*, Proposition 1. For finitely many goods and strictly positive prices
(`p l > 0` for every `l`), the budget set of nonnegative bundles `{x ∈ ℝ^L_+ | p · x ≤ w}` is
compact, for every wealth `w`.

This is the same statement as
[Nonnegative budget sets are compact at positive prices](../budget-sets/is-compact-nonneg-budget-set.md).
