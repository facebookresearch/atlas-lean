# Strict quasiconcavity on a convex set

A real function `f` is strictly quasiconcave on a set `s` (of a space with real scalar
multiplication) when `s` is convex and, for distinct `x, y ∈ s` and weights `a, b > 0` with
`a + b = 1`, `f(a x + b y) > min(f(x), f(y))`. This strengthens quasiconcavity and is the utility
counterpart of strictly convex preferences.
