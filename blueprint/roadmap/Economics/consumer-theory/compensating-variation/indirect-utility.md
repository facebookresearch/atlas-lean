# Indirect utility function

For finitely many goods, a utility `u`, a consumption set `X`, prices `p` and wealth `w`, the
indirect utility is the real supremum `v(p, w) = sup {u(x) | x ∈ B(p, w)}` over the budget set
`B(p, w) = {x ∈ X | p · x ≤ w}`. It is the greatest attainable utility only when this supremum
exists; for an empty or unbounded-above set the real supremum is `0` by convention.
