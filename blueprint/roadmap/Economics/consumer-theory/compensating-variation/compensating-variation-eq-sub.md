# Compensating variation as an expenditure difference

For finitely many goods, a utility `u` and a consumption set `X`, suppose baseline expenditure at
the baseline utility recovers wealth: `e(p⁰, v(p⁰, w)) = w` (expenditure–utility duality). Then the
compensating variation of the price change `p⁰ → p¹` is `CV = w - e(p¹, v(p⁰, w))`, where
`e(p, ū) = inf {p · x | x ∈ X, u(x) ≥ ū}` is the expenditure function and
`v(p, w) = sup {u(x) | x ∈ X, p · x ≤ w}` the indirect utility (a real infimum and
supremum: the infimum is `0` for an empty set or one unbounded below, the supremum `0` for an empty
set or one unbounded above).
