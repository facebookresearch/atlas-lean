# A price fall has nonnegative compensating variation

For finitely many goods, let every bundle of the consumption set `X` be nonnegative, and let the new
prices be nonnegative and nowhere above the old ones: `0 ≤ p¹ i ≤ p⁰ i` for every good `i`. Then for
every utility `u` and wealth `w`, `CV = e(p⁰, u⁰) - e(p¹, u⁰) ≥ 0` with `u⁰ = v(p⁰, w)`, where
`e(p, ū) = inf {p · x | x ∈ X, u(x) ≥ ū}` is the expenditure function and
`v(p, w) = sup {u(x) | x ∈ X, p · x ≤ w}` the indirect utility (a real infimum and
supremum: the infimum is `0` for an empty set or one unbounded below, the supremum `0` for an empty
set or one unbounded above).
