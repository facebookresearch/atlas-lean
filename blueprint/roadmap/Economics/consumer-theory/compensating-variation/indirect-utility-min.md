# Indirect utility for perfect complements

Worked example. For the perfect-complements utility `u(x) = min(x₀, x₁)` on the nonnegative quadrant
`{x ∈ ℝ² | x ≥ 0}`, at positive prices `p₀, p₁ > 0` and wealth `w ≥ 0`, the indirect utility is
`v(p, w) = sup {u(x) | x ≥ 0, p · x ≤ w} = w / (p₀ + p₁)`.
