# Compensating variation of a price change

For finitely many goods, a utility `u` and a consumption set `X`, the compensating variation of a
price change `p⁰ → p¹` at wealth `w` is `CV = e(p⁰, u⁰) - e(p¹, u⁰)` at the fixed baseline utility
`u⁰ = v(p⁰, w)`, where `e(p, ū) = inf {p · x | x ∈ X, u(x) ≥ ū}` is the expenditure function and
`v(p, w) = sup {u(x) | x ∈ X, p · x ≤ w}` the indirect utility (a real infimum and
supremum: the infimum is `0` for an empty set or one unbounded below, the supremum `0` for an empty
set or one unbounded above). With this sign convention it is the wealth that can be taken from the
consumer after the change while keeping baseline utility (positive for a welfare gain).
