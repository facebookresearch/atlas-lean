# Piecewise demand maximizes square-root quasilinear utility

Let both prices be positive (`p₀, p₁ > 0`) and let `w ≥ 0`. Then the piecewise bundle (interior
`((p₁ / p₀)², (w - p₁² / p₀) / p₁)` when `p₁² / p₀ ≤ w`, corner `(w / p₀, 0)` otherwise) maximizes
the utility `u(y) = 2 √y₀ + y₁` over the budget set `{y ∈ ℝ² | y ≥ 0, p · y ≤ w}`: it lies in that
set and `u(y) ≤ u(x)` for every `y` in it.
