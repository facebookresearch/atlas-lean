# Piecewise demand for square-root quasilinear utility

The piecewise demand for the utility `u(x) = 2 √x₀ + x₁` at prices `p = (p₀, p₁)` and wealth `w`:
the interior solution `x₀ = (p₁ / p₀)²`, `x₁ = (w - p₁² / p₀) / p₁` when wealth covers the satiation
spending `p₁² / p₀ ≤ w` on good `0`, and otherwise the corner `x₀ = w / p₀`, `x₁ = 0`. It is defined
for all real prices and wealth under the convention `x / 0 = 0`: for `p₀ = 0` it has `x₀ = 0`, and
for `p₁ = 0` and `w ≥ 0` it is `(0, 0)`; the intended domain is `p₀, p₁ > 0` and `w ≥ 0`.
