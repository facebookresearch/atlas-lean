# Least cost of reaching a target utility

For finitely many goods, a utility `u`, a consumption set `X`, prices `p` and a target utility `ū`,
the expenditure function is the real infimum `e(p, ū) = inf {p · x | x ∈ X, u(x) ≥ ū}`. It is the
least cost of reaching `ū` only when some bundle of `X` reaches `ū` and these costs are bounded
below; otherwise the real infimum is `0` by convention.
