# Expenditure is concave in prices

For finitely many goods, let `P` be a convex set of prices, and suppose the target `ū` is feasible
(some `x ∈ X` has `u(x) ≥ ū`) and that for every `p ∈ P` the costs `{p · x | x ∈ X, u(x) ≥ ū}` are
bounded below. Then the expenditure function `p ↦ e(p, ū) = inf {p · x | x ∈ X, u(x) ≥ ū}` is
concave on `P`.
