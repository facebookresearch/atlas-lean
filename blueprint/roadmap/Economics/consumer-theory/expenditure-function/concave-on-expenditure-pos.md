# Expenditure is concave on strictly positive prices

For finitely many goods, suppose every bundle of the consumption set `X` is nonnegative and the
target `ū` is feasible (some `x ∈ X` has `u(x) ≥ ū`). Then the expenditure function
`p ↦ e(p, ū) = inf {p · x | x ∈ X, u(x) ≥ ū}` is concave on the strictly positive prices
`{p | p i > 0 for every i}`.
