# Expenditure is homogeneous of degree one in prices

For finitely many goods, any utility `u`, consumption set `X`, prices `p`, target `ū` and any
`t ≥ 0`, scaling all prices by `t` scales expenditure by `t`: `e(t p, ū) = t e(p, ū)`, where
`e(p, ū) = inf {p · x | x ∈ X, u(x) ≥ ū}` (a real infimum, `0` for an empty or unbounded-below set).
