# Transversal CNOT and CSS codes

Let $S$ be a stabilizer group on $n$ qubits with code space $C(S)$, and let $U = \mathrm{CNOT}^{\otimes n}$ act on two
blocks, with qubit $i$ of the first block controlling qubit $i$ of the second. Then $U$, which is transversal for every code, maps $C(S) \otimes C(S)$ onto
itself if and only if $S$ is generated by elements of the forms $X^a$ and $Z^b$ (with sign $+1$), that is, if the code is
a CSS code. In that case the [logical operators](../stabilizer-formalism/logical-pauli-operators-of-a-stabilizer-code.md)
can be chosen with each $\bar X_j$ of the form $X^a$ and each $\bar Z_j$ of the form $Z^b$, and $U$ acts on the encoded
qubits as a CNOT from the $j$-th encoded qubit of the first block to the $j$-th of the second, for every $j$.

Proof: by the [conjugation rules](../clifford-group/conjugation-of-pauli-operators-by-h-s-and-cnot.md),
$U (X^a \otimes I) U^{*} = X^a \otimes X^a$, $U(I \otimes X^a)U^{*} = I \otimes X^a$, $U (Z^b \otimes I) U^{*} = Z^b \otimes I$ and
$U (I \otimes Z^b) U^{*} = Z^b \otimes Z^b$. If $M = c X^a Z^b \in S$, then $U (M \otimes I) U^{*} = M \otimes X^a$ and
$U (I \otimes M) U^{*} = Z^b \otimes M$ lie in $S \times S$, the stabilizer of $C(S) \otimes C(S)$, exactly when $X^a$ and
$Z^b$ lie in $S$. The same rules applied to $\bar X_j$ and $\bar Z_j$ give the logical action.
