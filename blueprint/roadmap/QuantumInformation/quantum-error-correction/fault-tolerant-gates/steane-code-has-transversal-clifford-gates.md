# Steane's code has transversal Clifford gates

On [Steane's seven-qubit code](../small-stabilizer-codes/steane-seven-qubit-code.md), with basis $|\bar 0\rangle$,
$|\bar 1\rangle$ given by the even- and odd-weight Hamming codewords:

1. $H^{\otimes 7}$ maps the code to itself and acts on it as the logical Hadamard:
   $H^{\otimes 7}|\bar 0\rangle = \tfrac{1}{\sqrt 2}(|\bar 0\rangle + |\bar 1\rangle)$ and
   $H^{\otimes 7}|\bar 1\rangle = \tfrac{1}{\sqrt 2}(|\bar 0\rangle - |\bar 1\rangle)$;
2. $S^{\otimes 7}$ maps the code to itself and acts as the logical $S^{*} = \operatorname{diag}(1, -i)$, so
   $(S^{*})^{\otimes 7}$ performs the logical $S$;
3. $\mathrm{CNOT}^{\otimes 7}$ between two blocks performs the logical CNOT.

So every logical Clifford gate on Steane's code is transversal. Proof: (1) for a linear code $D \subseteq \mathbb{F}_2^7$,
$H^{\otimes 7} \sum_{v \in D} |v\rangle = 2^{-7/2} |D| \sum_{u \in D^{\perp}} |u\rangle$; with $D = C^{\perp}$ this gives
$H^{\otimes 7}|\bar 0\rangle = \tfrac14 \sum_{u \in C} |u\rangle = \tfrac{1}{\sqrt 2}(|\bar 0\rangle + |\bar 1\rangle)$, and
$H^{\otimes 7} X^{\otimes 7} = Z^{\otimes 7} H^{\otimes 7}$ gives the image of $|\bar 1\rangle$ (Preskill's equation (7.94)); (2) $S^{\otimes 7}$ multiplies $|v\rangle$ by $i^{\operatorname{wt}(v)}$, and the
even and odd Hamming codewords have weights $0, 4$ and $3, 7$; (3) is the [CSS case](transversal-cnot-and-css-codes.md).
