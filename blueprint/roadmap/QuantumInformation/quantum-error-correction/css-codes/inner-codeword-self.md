# Norm of a CSS codeword

For every $w$, $\langle c_w | c_w \rangle = |C_1|$, the number of codewords of $C_1$, since each
amplitude is $\pm 1$ on $C_1$ and $0$ elsewhere. As $|C_1| = 2^{\dim C_1}$, the normalised state
$2^{-\dim C_1/2} |c_w\rangle$ of Calderbank and Shor's equation (2) is a unit vector.

## Sources

- A. R. Calderbank and P. W. Shor, *Good quantum error-correcting codes exist*, Phys. Rev. A 54 (1996), 1098–1105, arXiv:quant-ph/9512032, Section III, equation (2).
