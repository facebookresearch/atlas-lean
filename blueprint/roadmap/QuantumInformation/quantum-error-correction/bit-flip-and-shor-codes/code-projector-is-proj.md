# The code projector is an orthogonal projector

The [projector](code-projector.md) $P = |000\rangle\langle 000| + |111\rangle\langle 111|$ of the
bit-flip code is self-adjoint and idempotent: $P^{*} = P$ and $P^2 = P$. These are the hypotheses
on $P$ in the Knill–Laflamme theorem. The proof is entrywise: $P$ is diagonal with entries $0$
and $1$.
