# The five-qubit code

The five-qubit code is the stabilizer code on five qubits whose stabilizer is generated by the four cyclic shifts

$$M_1 = XZZXI, \quad M_2 = IXZZX, \quad M_3 = XIXZZ, \quad M_4 = ZXIXZ$$

(tensor factors listed by qubit); the fifth shift $ZZXIX$ equals $M_1 M_2 M_3 M_4$. The generators square to $I$ and
pairwise commute, each pair having two positions where an $X$ meets a $Z$, and their vectors are linearly independent,
so the code has dimension $2^{5-4} = 2$. With logical operators $\bar X = XXXXX$ and $\bar Z = ZZZZZ$, which commute
with the $M_i$ and anticommute with each other, the basis codewords are
$|\bar 0\rangle \propto \sum_{M \in S} M |00000\rangle$ (nonzero: every element of $S$ other than $I$ has an $X$ or $Y$ factor, so only $I$ contributes to the coefficient of $|00000\rangle$) and $|\bar 1\rangle = \bar X |\bar 0\rangle$. The code is cyclic, and it
is not a CSS code.
