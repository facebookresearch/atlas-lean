# The $[[2m, 2m - 2, 2]]$ error-detecting codes

Let $n = 2m$ with $m \ge 1$. The stabilizer group generated by $X^{\otimes n}$ and $Z^{\otimes n}$, which commute because
$n$ is even, defines an $[[n, n - 2, 2]]$ stabilizer code: it encodes $n - 2$ qubits, its code space is spanned by the
$2^{n-2}$ states $(|x\rangle + |\bar x\rangle)/\sqrt{2}$ for even-weight strings $x$ (where $\bar x$ is the complement of
$x$, and $x$ and $\bar x$ give the same state), and it has distance $2$, since no single-qubit Pauli operator commutes with
both generators, so every single-qubit error is detected. For $m = 1$ this is the Bell state $(|00\rangle + |11\rangle)/\sqrt 2$, a
$[[2, 0, 2]]$ code, and for $m = 2$ the $[[4, 2, 2]]$ code.
