# Steane's seven-qubit code

Let $C \subseteq \mathbb{F}_2^7$ be the [Hamming $(7,4)$ code](../../../InformationTheory/error-correcting-codes/hamming-7-4-code/code.md),
with parity-check matrix $H$ whose column $j$ is the binary expansion of $j$, and let $C^{\perp}$ be its
[dual](../../../InformationTheory/error-correcting-codes/linear-codes/dual.md), the $[7, 3, 4]$ code spanned by the rows of
$H$. The rows of $H$ have weight $4$ and pairwise overlap $2$, so $C^{\perp} \subseteq C$; $C^{\perp}$ is the set of
even-weight words of $C$, and $C = C^{\perp} \cup (C^{\perp} + 1111111)$.

Steane's code is the two-dimensional subspace of seven qubits spanned by

$$|\bar 0\rangle = \tfrac{1}{\sqrt 8} \sum_{v \in C^{\perp}} |v\rangle, \qquad
|\bar 1\rangle = \tfrac{1}{\sqrt 8} \sum_{v \in C^{\perp} + 1111111} |v\rangle .$$

It is the CSS code $Q_{C, C^{\perp}}$ of [CSS codewords](../css-codes/codeword.md) built from $C_1 = C$ and
$C_2 = C^{\perp}$, and the stabilizer code of the group generated by the six operators $X^h$ and $Z^h$ for the three rows
$h$ of $H$. With $\bar X = X^{\otimes 7}$ and $\bar Z = Z^{\otimes 7}$ one has $\bar X |\bar 0\rangle = |\bar 1\rangle$ and
$\bar Z |\bar x\rangle = (-1)^x |\bar x\rangle$, since $1111111$ is an odd-weight word of $C$.
