# Small stabilizer codes

The smallest quantum codes show the constructions at work. The three-qubit phase-flip code is the bit-flip code in the
Hadamard basis. Steane's seven-qubit code is the CSS code of the Hamming code and its dual; it corrects one error and has
transversal Clifford gates. The five-qubit code is the shortest code encoding one qubit against an arbitrary single-qubit
error, and it is perfect. The fifteen-qubit quantum Reed–Muller code admits a transversal $T$ gate, which makes it the
basis of magic-state distillation. The three-qubit bit-flip code and Shor's nine-qubit code are in their own folder.
