# Concatenated quantum code

Let $Q_1$ be an $[[n_1, k, d_1]]$ stabilizer code (the outer code) with stabilizer $S_1$, and $Q_2$ an $[[n_2, 1, d_2]]$
stabilizer code (the inner code) with stabilizer $S_2$ and logical operators $\bar X, \bar Z$, with $\bar Y = i \bar X \bar Z$.
The concatenated code lives on $n_1$ blocks of $n_2$ qubits. Its stabilizer is generated by

1. a copy of each generator of $S_2$ on each block; and
2. for each generator $c\, P_1 \otimes \dots \otimes P_{n_1}$ of $S_1$ ($P_i \in \{I, X, Y, Z\}$), the operator
   $c\, \bar P_1 \otimes \dots \otimes \bar P_{n_1}$, where $\bar P_i$ is the logical version of $P_i$ on block $i$ and $\bar I = I$.

Equivalently, the code space is obtained by encoding each of the $n_1$ qubits of a codeword of $Q_1$ into $Q_2$. Shor's
nine-qubit code is the concatenation of the [three-qubit phase-flip code](../small-stabilizer-codes/three-qubit-phase-flip-code.md)
(outer) with the bit-flip code (inner). Iterating the construction $L$ times with an $[[n, 1, d]]$ code gives codes on
$n^L$ qubits, the basis of the threshold theorem.
