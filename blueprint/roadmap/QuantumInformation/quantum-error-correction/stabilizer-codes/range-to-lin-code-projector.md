# The code projector projects onto the code space

Let $g_1, \dots, g_r$ be signed Pauli operators on $n$ qubits, $g_j = c_j X^{a_j} Z^{b_j}$ with $a_j, b_j \in \mathbb{F}_2^n$ and $c_j \in \mathbb{C}$ that are involutive ($g_j^2 = I$) and pairwise commuting. Then the range of the code projector, the average of the distinct subset products
of the $g_j$, is the code space: the common $+1$ eigenspace of $g_1, \dots, g_r$.
