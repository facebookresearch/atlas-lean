# Subsystem codes

A subsystem code stores information in one factor $A$ of the code space $C = A \otimes B$ and lets errors act freely on
the gauge factor $B$. In the stabilizer setting a gauge group of Pauli operators between the stabilizer and its normalizer
fixes the split, and gauge qubits allow error correction with fewer or lighter measurements and code switching by gauge
fixing (Kribs, Laflamme and Poulin; Poulin).
