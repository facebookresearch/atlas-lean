# Subsystem code

In operator quantum error correction the code space $C$ of an $n$-qubit system factors as $C = A \otimes B$, and
information is stored in the subsystem $A$ only; states $\rho_A \otimes \rho_B$ and $\rho_A \otimes \rho_B'$ count as equal.
Noise with Kraus operators $E_a$ is *correctable on $A$* if one recovery
[channel](../../quantum-operations/quantum-channel.md) $\mathcal{R}$ satisfies, for all states $\rho_A$ and $\rho_B$,
$\mathcal{R}\big(\sum_a E_a (\rho_A \otimes \rho_B) E_a^{*}\big) = \rho_A \otimes \rho_B'$ for some state $\rho_B'$ of $B$. This
holds exactly when $P E_a^{*} E_b P = I_A \otimes g_{ab}^{B}$ for all $a, b$, where $P$ projects onto $C$ and $g_{ab}^B$ are
operators on $B$. For $\dim B = 1$ it is [correctability](../knill-laflamme-conditions/is-correctable.md) on the whole
code, and the conditions are the [Knill–Laflamme conditions](../knill-laflamme-conditions/is-correctable-iff-knill-laflamme.md).

In the stabilizer version, a *subsystem code* is given by a stabilizer group $S$ with $s$ independent generators and a
*gauge group* $G$ generated by $S$, $iI$ and $r$ pairs $g_j^x, g_j^z$ of
[Pauli operators](../../../TheoryOfComputation/randomized-and-quantum-complexity/bounded-error-quantum-polynomial-time-bqp/pauli-group-on-n-qubits.md)
in the normalizer $N(S)$ that act as $X$ and $Z$ on $r$ virtual qubits; the logical group $L = N(S)/G$ is generated by $k$
further pairs, with $s + r + k = n$. Then $A \cong (\mathbb{C}^2)^{\otimes k}$ carries the $k$ logical qubits,
$B \cong (\mathbb{C}^2)^{\otimes r}$ the $r$ gauge qubits, elements of $G$ act on $C$ as $I_A \otimes g^B$, and chosen bare logical representatives of the generators of $L$ act as
$L^A \otimes I_B$. A general element of a coset in $L$ can also act nontrivially on $B$ (with one logical and one gauge
qubit, $X_A \otimes I_B$ and $X_A \otimes X_B$ lie in the same coset), so it determines only the logical action, up to phase.
For $k \ge 1$ the distance $d$ is the least weight of an element of $N(S) \setminus G$, and the code is an
$[[n, k, r, d]]$ code; it corrects errors on up to $\lfloor (d - 1)/2 \rfloor$ qubits. For $k = 0$ there is no protected
qubit and $N(S) = G$, so this minimum is over the empty set (for example $n = 1$, $S = \langle Z \rangle$, $r = 0$). For $r = 0$ it is a stabilizer code.
Shor's nine-qubit code, with part of its stabilizer moved into the gauge group, is a $[[9, 1, 4, 3]]$ subsystem code.
