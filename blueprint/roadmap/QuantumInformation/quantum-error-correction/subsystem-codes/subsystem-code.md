# Subsystem code

In operator quantum error correction the code space $C$ of an $n$-qubit system factors as $C = A \otimes B$, and
information is stored in the subsystem $A$ only; states $\rho_A \otimes \rho_B$ and $\rho_A \otimes \rho_B'$ count as equal.
A set of errors $\{E_a\}$ is correctable on $A$ exactly when $P E_a^{*} E_b P = I_A \otimes g_{ab}^{B}$ for all $a, b$, where
$P$ projects onto $C$ and $g_{ab}^B$ are operators on $B$; for $\dim B = 1$ these are the
[Knill–Laflamme conditions](../knill-laflamme-conditions/is-correctable-iff-knill-laflamme.md).

In the stabilizer version, a *subsystem code* is given by a stabilizer group $S$ with $s$ independent generators and a
*gauge group* $G$ generated by $S$, $iI$ and $r$ pairs $g_j^x, g_j^z$ of
[Pauli operators](../../../TheoryOfComputation/randomized-and-quantum-complexity/bounded-error-quantum-polynomial-time-bqp/pauli-group-on-n-qubits.md)
in the normalizer $N(S)$ that act as $X$ and $Z$ on $r$ virtual qubits; the logical group $L = N(S)/G$ is generated by $k$
further pairs, with $s + r + k = n$. Then $A \cong (\mathbb{C}^2)^{\otimes k}$ carries the $k$ logical qubits,
$B \cong (\mathbb{C}^2)^{\otimes r}$ the $r$ gauge qubits, elements of $G$ act on $C$ as $I_A \otimes g^B$ and elements of
$L$ as $L^A \otimes I_B$. The distance $d$ is the least weight of an element of $N(S) \setminus G$, and the code is an
$[[n, k, r, d]]$ code; it corrects errors on up to $\lfloor (d - 1)/2 \rfloor$ qubits. For $r = 0$ it is a stabilizer code.
Shor's nine-qubit code, with part of its stabilizer moved into the gauge group, is a $[[9, 1, 4, 3]]$ subsystem code.
