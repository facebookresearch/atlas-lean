# The toric code as the homological code of the square torus

For $L \ge 2$, the *toric code* is the CSS code of the cellular chain complex of the $L \times L$ square tiling of the torus with $\mathbb{F}_2$ coefficients, $C_2 \xrightarrow{\partial_2} C_1 \xrightarrow{\partial_1} C_0$ with faces, edges and vertices as bases: qubits sit on the $2L^2$ edges, $X$-checks are plaquettes and $Z$-checks are vertex stars. Its parameters are $[[2L^2, 2, L]]$, logical operators being homologically nontrivial cycles and cocycles, and it is the hypergraph product of two copies of the repetition code on a cycle of length $L$.
