# Subset products of the generators

For generators $g_j = c_j X^{a_j} Z^{b_j}$ ($j = 1, \dots, r$, with arbitrary complex $c_j$), the finite set of the distinct products $\prod_{j \in T} g_j$, taken in index order, over all subsets $T \subseteq \{1, \dots, r\}$. When the generators are involutive ($g_j^2 = I$) and pairwise commuting, this set is the group they generate, the stabilizer group. In general it need not be a group: for the single generator $2I$ the set is $\{I, 2I\}$, which does not contain $(2I)^2 = 4I$.
