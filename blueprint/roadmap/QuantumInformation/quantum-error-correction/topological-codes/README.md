# Topological codes

Kitaev's toric code places qubits on the edges of a square lattice on the torus, with four-qubit check operators on
vertices and faces. It encodes two qubits, its logical operators are products along homologically nontrivial loops, and
its distance is the linear size $L$ of the lattice. The planar surface code replaces the torus by a square with two kinds
of boundary and encodes one qubit with distance $L$. Minimum-weight matching of the defects decodes bit flips, with a
threshold error rate below which decoding succeeds with probability tending to one.
