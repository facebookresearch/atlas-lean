# Stabilizer codes: correctability criterion and distance

Let $S$ be an abelian subgroup of the $n$-qubit Pauli group $\mathcal{P}_n$ with $-I \notin S$, generated by $n - k$ independent elements,
and let $C(S)$ be its joint $+1$ eigenspace. Let $N(S)$ be the normalizer of $S$ in $\mathcal{P}_n$, which here equals its
centralizer, and let $\langle iI \rangle S = \{ i^c s : c \in \{0,1,2,3\},\ s \in S \}$ be $S$ enlarged by global phases.

1. **Correctability.** For a set $\mathcal{E}$ of Pauli errors, $\mathcal{E}$ is correctable on $C(S)$ if and only if
   $E_a^* E_b \notin N(S) \setminus \langle iI \rangle S$ for all $E_a, E_b \in \mathcal{E}$.
2. **Distance.** For every $d$, $C(S)$ has distance at least $d$ if and only if every element of
   $N(S) \setminus \langle iI \rangle S$ has weight at least $d$. For $k \ge 1$ this set is nonempty, so the distance of
   the code is the minimum weight of its elements. For $k = 0$ the set is empty and the code has distance at least $d$
   for every $d$; Gottesman's thesis instead requires an $[n, 0, d]$ code to be nondegenerate, that is, $S$ has no
   element other than $I$ of weight less than $d$.

Working modulo global phases is required: an element of $N(S)$ that differs from an element of $S$ only by a phase, such
as $-I$, acts on $C(S)$ as a scalar and is not a logical error.
