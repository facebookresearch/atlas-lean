# Bosonic codes

Bosonic codes encode a qubit or qudit in an infinite-dimensional system such as a harmonic oscillator, protecting it
against small displacements in phase space rather than against errors on a few of many qubits. The ideal
Gottesman–Kitaev–Preskill code is a joint generalized eigenspace of two commuting displacements, spanned by
non-normalizable combs, and corrects every shift below a fixed size exactly; its normalizable approximations with finite
squeezing correct such shifts approximately.
