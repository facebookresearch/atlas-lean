# Bosonic codes

Bosonic codes encode a qubit or qudit in an infinite-dimensional system such as a harmonic oscillator, protecting it
against small displacements in phase space rather than against errors on a few of many qubits. The
Gottesman–Kitaev–Preskill code is the joint eigenspace of two commuting displacements and corrects all shifts below a
fixed size.
