# Block encoding

For a matrix $A$ on a register indexed by $\iota$, reals $\alpha, \varepsilon$, an ancilla register indexed by $\kappa$ with a reference basis vector $o$, and a matrix $U$ on $\kappa \times \iota$, $U$ is an $(\alpha, \varepsilon)$ block encoding of $A$ when $U$ is unitary, $\lVert A - \alpha\,(\langle o| \otimes I)\,U\,(|o\rangle \otimes I)\rVert \le \varepsilon$, and $\alpha \ge 0$, $\varepsilon \ge 0$.

## Sources

- A. Gilyén, Y. Su, G. H. Low and N. Wiebe, "Quantum singular value transformation and beyond: exponential improvements for quantum matrix arithmetics", *Proceedings of STOC 2019*, Definition 43.
