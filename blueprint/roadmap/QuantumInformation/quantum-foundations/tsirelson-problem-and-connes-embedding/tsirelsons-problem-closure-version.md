# Tsirelson's problem

*Tsirelson's problem* asks whether $C_{qa}(\mathcal{X}, \mathcal{A}) = C_{qc}(\mathcal{X}, \mathcal{A})$ for all finite question and answer sets, that is, whether every commuting-operator correlation of two spatially separated parties is a limit of finite-dimensional tensor-product correlations. The *synchronous* version asks the same for synchronous correlations, those with $p(a, b \mid x, x) = 0$ for $a \ne b$.
