# Membership in a fixed-size quantum correlation set is undecidable

There is a size threshold beyond which membership in the set of quantum-approximate correlations, and in the set of commuting-operator correlations, is undecidable even with the numbers of questions and answers held fixed. The input is a single correlation with real algebraic entries.

**Correlations of a fixed size.** For integers $n_A, n_B, m_A, m_B \geq 1$, a correlation of size $(n_A, n_B, m_A, m_B)$ is a family $P = \{P(a, b \mid x, y)\}$ indexed by $0 \leq a < m_A$, $0 \leq b < m_B$, $0 \leq x < n_A$ and $0 \leq y < n_B$. Here Alice performs one of $n_A$ measurements with $m_A$ outcomes and Bob one of $n_B$ measurements with $m_B$ outcomes. For $t \in \{qa, qc\}$, $C_t(n_A, n_B, m_A, m_B)$ denotes the set of [quantum-approximate or commuting-operator correlations](quantum-correlation-sets-q-qs-qa-qc.md) of that size: limits of finite-dimensional tensor-product correlations, and correlations $\langle\psi, A^x_a B^y_b \psi\rangle$ of commuting measurement families on a single Hilbert space, respectively. Let $\mathbb{K} = \overline{\mathbb{Q}} \cap \mathbb{R}$ be the field of real algebraic numbers.

**Problem.** $\mathrm{Membership}(n_A, n_B, m_A, m_B)_{t, \mathbb{K}}$: given $P \in \mathbb{K}^{n_A n_B m_A m_B}$, is $P \in C_t(n_A, n_B, m_A, m_B)$?

**Theorem (Fu, Miller and Slofstra).** There is an integer $\alpha$ such that $\mathrm{Membership}(n_A, n_B, m_A, m_B)_{t, \mathbb{K}}$ is undecidable for $t \in \{qa, qc\}$ and all $n_A, n_B, m_A, m_B > \alpha$.

Earlier undecidability results for membership let the size of the correlation grow with the instance. This theorem fixes the size, so for large enough sizes there is no description of $C_{qa}$ or $C_{qc}$, for example by polynomial inequalities, from which membership could be decided. The source notes that its proof shows more: for $t = qc$ the fixed-size problem is coRE-complete, and for $t = qa$ it is coRE-hard. The correlations constructed in the proof are synchronous, and their entries can be taken in the real subfield generated by roots of unity.

## Expansion

The proof fixes a Minsky (counter) machine $\mathcal{M}$ with an undecidable halting problem, and goes through the groups of Kharlampovich, Myasnikov and Sapir associated with such machines. For each input $n$ it writes down a finite set $F_n$ of correlations with $F_n \cap C_{qa} \neq \emptyset$ if $\mathcal{M}$ does not accept $n$, and $F_n \cap C_{qc} = \emptyset$ otherwise. Each correlation in $F_n$ has two parts. The first is built from $\mathcal{M}$ with Slofstra's embedding method and does not depend on $n$. The second encodes $n$ with a dihedral-group construction of Fu that keeps the numbers of measurements and outcomes fixed. So all correlations in all $F_n$ have one size depending only on $\mathcal{M}$. Since $C_{qa} \subseteq C_{qc}$, a decision procedure for membership in either set at that size would decide whether $\mathcal{M}$ accepts $n$.
