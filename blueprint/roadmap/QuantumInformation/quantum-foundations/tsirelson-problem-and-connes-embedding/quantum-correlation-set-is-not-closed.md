# The set of finite-dimensional quantum correlations is not closed (Slofstra)

There exist finite sets $\mathcal{X}, \mathcal{A}$ such that $C_q(\mathcal{X}, \mathcal{A}) \subsetneq C_{qa}(\mathcal{X}, \mathcal{A})$; moreover $C_{qs}(\mathcal{X}, \mathcal{A}) \ne C_{qa}(\mathcal{X}, \mathcal{A})$ for suitable finite sets. Equivalently, there is a game whose entangled value is attained only in the limit of increasing dimension.

## Proof sketch

Slofstra embeds finitely presented groups into solution groups of linear constraint system games. Choosing a group in which an element is non-trivial but becomes trivial in every finite-dimensional approximate representation, one obtains a linear system game with a perfect strategy in $C_{qa}$ (approximately) but no perfect strategy in $C_q$ or $C_{qs}$.
