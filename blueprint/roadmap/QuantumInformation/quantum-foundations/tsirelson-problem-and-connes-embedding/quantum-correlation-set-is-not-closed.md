# The set of finite-dimensional quantum correlations is not closed (Slofstra)

There exist finite sets $\mathcal{X}, \mathcal{A}$ such that $C_q(\mathcal{X}, \mathcal{A}) \subsetneq C_{qa}(\mathcal{X}, \mathcal{A})$; moreover $C_{qs}(\mathcal{X}, \mathcal{A}) \ne C_{qa}(\mathcal{X}, \mathcal{A})$ for suitable finite sets. Both follow from a non-local game with a perfect strategy in $C_{qa}$ but no perfect strategy in $C_{qs}$, whose entangled value $1$ is therefore approached only in the limit of increasing dimension.

## Proof sketch

Slofstra embeds finitely presented groups into solution groups of linear constraint system games. A linear system game has a perfect strategy in $C_{qs}$ (equivalently $C_q$) exactly when the distinguished element $J$ of its solution group is non-trivial in some finite-dimensional representation, and it has a perfect strategy in $C_{qa}$ when $J$ is non-trivial in finite-dimensional approximate representations. Proposition 5.1 constructs a solution group in which $J$ is trivial in every finite-dimensional exact representation but non-trivial in finite-dimensional approximate representations; the approximate representations give the perfect strategy in the closure $C_{qa}$, while triviality in exact representations rules out a perfect strategy in $C_{qs}$.
