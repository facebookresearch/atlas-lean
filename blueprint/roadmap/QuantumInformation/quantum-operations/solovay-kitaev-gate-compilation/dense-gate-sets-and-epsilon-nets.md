# Dense inverse-closed gate sets and epsilon-nets in SU(d)

A finite set $\mathcal{G} \subset \mathrm{SU}(d)$ is a *universal gate set* if it is closed under inverses ($g \in \mathcal{G} \Rightarrow g^{-1} \in \mathcal{G}$) and generates a dense subgroup of $\mathrm{SU}(d)$. For $\ell \in \mathbb{N}$ let $\mathcal{G}_\ell$ be the set of products of at most $\ell$ elements of $\mathcal{G}$. A set $S \subseteq \mathrm{SU}(d)$ is an *$\varepsilon$-net* if every $U \in \mathrm{SU}(d)$ satisfies $\min_{V \in S}\|U - V\| \le \varepsilon$ in operator norm.
