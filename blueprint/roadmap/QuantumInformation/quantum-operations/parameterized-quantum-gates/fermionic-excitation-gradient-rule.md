# Gradient rule for fermionic excitation gates

The derivative of an expectation value with respect to the angle of a fermionic excitation gate equals a combination of four expectation values in which the gate is shifted by $\pm\pi/2$ and followed by a fixed phase gate generated by its null-space projector.

Let $G$ be an $n$-fold fermionic excitation generator with null-space projector $P_0$ and $U(\theta)=e^{-i\theta G/2}$. Let $X,Y$ be unitaries, $H$ a Hermitian operator, $|0\rangle$ a normalized state, and $f(\theta)=\langle0|Y^\dagger U(\theta)^\dagger X^\dagger HXU(\theta)Y|0\rangle$. For $\alpha\in\{+1,-1\}$ define

$$
U^{\alpha}_{\pm}(\theta)=U\bigl(\theta\pm\tfrac\pi2\bigr)\,e^{\mp\alpha i\frac\pi4P_0},\qquad f^{\alpha}_{\pm}(\theta)=\langle0|Y^\dagger U^{\alpha}_{\pm}(\theta)^\dagger X^\dagger HXU^{\alpha}_{\pm}(\theta)Y|0\rangle .
$$

Then for all $\theta\in\mathbb R$

$$
f'(\theta)=\frac14\sum_{\alpha\in\{+1,-1\}}\bigl(f^{\alpha}_{+}(\theta)-f^{\alpha}_{-}(\theta)\bigr).
$$

## Context

Research. Expanding $G$ into Pauli strings and applying the two-term shift rule to each costs a number of evaluations growing exponentially with the excitation rank $n$; this rule needs four for any $n$ and any fermion-to-qubit encoding. The authors also give a two-term variant whose exactness requires real matrix elements of the surrounding circuit and observable (for example real $Y|0\rangle$, real circuits $X$ and real $X^\dagger HX$), not merely a real input state. The shift rule is circuit differentiation, with chemistry as its use.

## Expansion

Since $G_+$ and $G_-$ commute, $U(\theta)=e^{-i\theta G_+/4}e^{-i\theta G_-/4}$ (Mathlib `Matrix.exp_add_of_commute`). For a self-inverse Hermitian $K$, $e^{-i\varphi K}=\cos\varphi\,\mathbf 1-i\sin\varphi\,K$, so any expectation $g(\varphi)$ with one factor $e^{-i\varphi K}$ and its adjoint is $a+b\cos2\varphi+c\sin2\varphi$, whence $g'(\varphi)=g(\varphi+\frac\pi4)-g(\varphi-\frac\pi4)$. Apply this to each factor with $\varphi=\theta/4$ (chain rule factor $\frac14$, shift $\theta\pm\pi$ in that factor) and add the two contributions (product rule). Shifting the $G_\alpha$ factor by $\pm\pi$ gives $e^{-i(\theta\pm\pi)G_\alpha/4}e^{-i\theta G_{-\alpha}/4}=U(\theta\pm\frac\pi2)e^{\mp\alpha i\frac\pi4P_0}$, using $G_\pm=G\pm P_0$.
