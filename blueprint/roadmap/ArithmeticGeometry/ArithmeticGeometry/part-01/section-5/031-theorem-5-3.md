# Theorem 5.3

Let $k$ be a field with absolute value $\|\|$ and multiplicative identity $1_{k}$. (a) $\|1_{k}\|=1$. (b) $\|-x\|=\|x\|$. (c) $\|\|$ is nonarchimedean if and only if $\|n\| \leq 1$ for all positive integers $n \in k$.
