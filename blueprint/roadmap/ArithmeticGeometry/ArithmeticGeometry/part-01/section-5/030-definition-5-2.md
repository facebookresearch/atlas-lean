# Definition 5.2

Let $k$ be a field. An absolute value on $k$ is a function $\|\|: k \rightarrow \mathbb{R}_{\geq 0}$ with the following properties: (1) $\|x\|=0$ if and only if $x=0$, (2) $\|xy\|=\|x\| \cdot \|y\|$, (3) $\|x+y\| \leq \|x\|+\|y\|$.
