# Definition 7.14

Let $S$ be any subset of a field $k$ with absolute value $\|\|$. The set $S$ is dense in $k$ if for every $x \in k$ and every $\epsilon > 0$ there exists $y \in S$ such that $\|x - y\| < \epsilon$.
