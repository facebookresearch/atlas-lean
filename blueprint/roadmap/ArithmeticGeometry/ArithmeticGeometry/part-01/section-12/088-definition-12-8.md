# Definition 12.8

If $S$ is a set of polynomials in $A=\bar{k}[x_{1}, \ldots, x_{n}]$, the set of points $Z_{S}=\{P \in \mathbb{A}^{n}: f(P)=0 \text{ for all } f \in S\}$ is called an (affine) algebraic set. If $k \subseteq L \subseteq \bar{k}$, the set of $L$-rational points in $Z_{S}$ is $Z_{S}(L)=Z_{S} \cap \mathbb{A}^{n}(L)$. When $S$ is a singleton $\{f\}$ we may write $Z_{f}$ in place of $Z_{\{f\}}$.
