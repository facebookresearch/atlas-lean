# Theorem 2.6 (Legendre)

Let $a, b, c$ be square-free integers that are pairwise coprime and whose signs are not all the same. The equation $a x^{2}+b y^{2}+c z^{2}=0$ has a rational solution if and only if the congruences $X^{2} \equiv -bc \bmod a$, $Y^{2} \equiv -ca \bmod b$, $Z^{2} \equiv -ab \bmod c$ can be simultaneously satisfied.
