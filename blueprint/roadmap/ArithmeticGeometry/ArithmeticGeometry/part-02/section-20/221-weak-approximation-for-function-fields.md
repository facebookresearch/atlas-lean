# Corollary 20.5 (Weak approximation for function fields)

Let $P_{1}, \ldots, P_{n}$ be distinct places of a function field $F/k$, and let $f_{1}, \ldots, f_{n} \in F$ be given. For every positive integer $N$ there exists $f \in F$ such that $\operatorname{ord}_{P_{i}}(f-f_{i})>N$ for $0 \leq i < n$.
