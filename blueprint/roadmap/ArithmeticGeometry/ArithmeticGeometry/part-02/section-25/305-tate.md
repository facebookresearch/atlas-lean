# Theorem 25.19 (Tate)

Let $S$ be a set and let $r>1$ a real number. Let $\phi: X \rightarrow X$ and $h: X \rightarrow \mathbb{R}$ be functions such that $h \circ \phi=r h+O(1)$, and let $\hat{h}_{\phi}(x)\coloneqq \lim_{n \rightarrow \infty} \frac{1}{r^{n}} h(\phi^{n}(x))$. Then $\hat{h}_{\phi}$ is the unique function $S \rightarrow \mathbb{R}$ for which (i) $\hat{h}_{\phi}=h+O(1)$; (ii) $\hat{h}_{\phi} \circ \phi=r \hat{h}_{\phi}$.
