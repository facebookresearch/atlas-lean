# Theorem 23.16

Let $E / k$ be an elliptic curve with distinguished point $O$. The map $\phi$ that sends the point $P \in E(k)$ to the class of the divisor $P-O$ in $\operatorname{Pic}_{k}^{0}(E)$ is a bijection. This induces a commutative group operation on $E(k)$ defined by $P_{1}+P_{2}\coloneqq \phi^{-1}(\phi(P_{1})+\phi(P_{2}))$ in which $O$ acts as the identity element.
