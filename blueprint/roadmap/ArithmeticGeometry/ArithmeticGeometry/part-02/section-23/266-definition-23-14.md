# Definition 23.14

An elliptic curve $E / k$ is a genus one curve with a distinguished rational point $O$. Equivalently, an elliptic curve is a curve $E / k$ defined by a Weierstrass equation with the distinguished rational point $O=(0: 1: 0)$.
