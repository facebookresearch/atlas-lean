# Fitness-class dynamics with mutation

A population is divided into classes of equal Malthusian fitness, and each birth lands in a class drawn from a mutation kernel that depends on the parent's class. The resulting linear system extends the continuous-time setting of Fisher's fundamental theorem: the rate of change of mean fitness is the fitness variance plus a mutational term, which is negative when offspring tend to be less fit than their parents.
