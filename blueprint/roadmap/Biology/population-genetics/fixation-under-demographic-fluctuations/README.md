# Fixation under demographic fluctuations

When population size is not fixed but fluctuates through births, deaths and competition, the fate of a mutant depends on ecological as well as evolutionary dynamics. In a two-type competitive birth–death diffusion with a stable coexistence point, the weak-selection fixation probability is a correction to the neutral value that separates into a frequency factor, vanishing at the coexistence frequency, and a factor depending only on the initial population size.
