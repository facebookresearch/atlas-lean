# Multiallelic Levene model

Migration–selection model in which zygotes from a single random-mating pool are dispersed to niches with different viabilities and the adults return to the pool in fixed proportions. Allele frequencies are identical across niches after each round, and the dynamics climbs the geometric mean of the niche mean fitnesses, which rules out cycles and chaos and yields global convergence results under concavity.
