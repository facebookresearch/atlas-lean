# Heterozygote advantage on multicopy plasmids

A bacterial cell carrying $n$ copies of a plasmid can hold two alleles at once, but random segregation at division keeps producing homozygous daughters. When only heterozygous cells grow (heterozygote advantage), a multitype branching process gives an exact threshold on heterozygote fitness, decreasing with copy number, below which rescue of a declining population is impossible.
