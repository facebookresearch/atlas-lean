# Similarity-dependent homologous recombination in bacteria

Infinite-population models of bacterial genomes evolving by site-wise mutation and homologous recombination whose rate depends symmetrically on the similarity of the exchanged segments, formulated as nonlinear Markov processes. Relative entropy to the mutation equilibrium is a Lyapunov function, so the population converges to a single genotype distribution and no subspecies can emerge.
