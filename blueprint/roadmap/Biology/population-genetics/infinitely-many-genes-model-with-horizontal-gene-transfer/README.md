# Infinitely-many-genes model with horizontal gene transfer

A Wright–Fisher model of bacterial accessory genomes with gene gain, gene loss and horizontal gene transfer, whose single-gene frequency diffusion behaves like a selected allele; diffusion theory gives the expected gene frequency spectrum and pangenome statistics of a sample.
