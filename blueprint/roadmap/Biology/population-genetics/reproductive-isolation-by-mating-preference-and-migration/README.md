# Reproductive isolation by mating preference and migration

Stochastic birth–death–migration models of a haploid population on two patches in which a single diallelic locus controls both assortative mating preference and mate-searching migration. Their large-population limits have stable states where each allele is fixed in a different patch, and the time the stochastic process needs to reach such a reproductively isolated state is of order $\log K$ in the carrying capacity $K$.
