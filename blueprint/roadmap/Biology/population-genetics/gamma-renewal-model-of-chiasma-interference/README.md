# Gamma renewal model of chiasma interference

Crossovers along a bivalent are not placed independently: chiasmata interfere, spacing themselves more regularly than a Poisson process would. A gamma renewal process on the genetic map, with each chiasma resolved on a randomly chosen pair of chromatids, captures that spacing while preserving the Morgan calibration, and reduces to Haldane's interference-free map function at shape one.
