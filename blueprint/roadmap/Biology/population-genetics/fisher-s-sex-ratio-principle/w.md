# Shaw–Mohler invasion fitness

The Shaw–Mohler invasion fitness of a mutant parent with son fraction `x` in a population with son
fraction `y` is, up to the positive factor `1/4`, `W(x, y) = x / y + (1 - x) / (1 - y)`. It is
defined for all real `x` and `y`: by the convention `a / 0 = 0`, `W(x, 0) = 1 - x` and
`W(x, 1) = x`. The intended domain is `0 < y < 1`, with `0 ≤ x ≤ 1`.
