# Son fraction among offspring for a given investment in sons

A parent investing a fraction `r` of its resources in sons, when a son costs `cs` and a daughter
`cd`, has the son fraction `(r / cs) / (r / cs + (1 - r) / cd)` among its offspring: the number of
sons over the number of offspring. It is defined for all real arguments, with the convention
`a / 0 = 0` (for instance it is `0` when `r / cs + (1 - r) / cd = 0`). The intended domain is
`cs, cd > 0` and `0 ≤ r ≤ 1`, where the denominator is positive.
