# Interactive neutral reproduction and factorial moment duality

A two-type Moran model in which some neutral reproduction events are gated by a third, checking individual: the reproduction happens only if the checker is fit. Its diffusion limit $dX=\sqrt{X(1-X)(r+\kappa(1-X))}\,dB$ (plus selection and mutation drift) arises from several models with variance in offspring number. The model has an exact factorial moment dual whose genealogical meaning emerges only after averaging over the roles of lines in the ancestral influence graph.
