# Covariance of additive social fitness with the trait

For real numbers `α`, `b`, `c` and real functions `y`, `z`, `e` on a finite set of individuals,
the [additive social fitness](additive-fitness.md) `w i = α + b * y i - c * z i + e i` has
[population covariance](pop-cov.md) with the trait
`Cov(w, z) = b Cov(y, z) - c Var(z) + Cov(e, z)`, where `Var(z) = Cov(z, z)`.
