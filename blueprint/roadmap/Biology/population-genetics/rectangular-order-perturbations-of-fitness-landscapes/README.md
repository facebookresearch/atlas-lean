# Rectangular order perturbations of fitness landscapes

A rank order of the $2^n$ genotypes of an $n$-locus biallelic system reveals gene interaction when the sign of the effect of swapping a set of loci depends on the genetic background. Such sign changes live on rectangles of the genotype cube; size-one rectangles are exactly sign epistasis. The rectangles and the resulting perturbations admit closed-form counts.
