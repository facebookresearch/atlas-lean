# Wright's $F_{ST} = 1/(1 + 4Nm)$

For every real $\kappa \ge 0$, the [equilibrium](island-equilibrium.md) $F^*$ for demes of $M = 2N$ gene copies with migration fraction $m = \kappa/(4N)$, so that $4Nm = \kappa$ is held fixed, tends to $1/(1 + \kappa)$ as the natural number $N$ tends to infinity.

## Sources

- S. Wright, *Evolution in Mendelian populations*, Genetics 16 (1931), 97–159.
