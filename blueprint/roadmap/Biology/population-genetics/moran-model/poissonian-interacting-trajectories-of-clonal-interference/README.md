# Poissonian interacting trajectories of clonal interference

In the Gerrish-Lenski regime of a large asexual population, beneficial mutations arrive at rate of order $1/\log N$ per generation, so finitely many contending clones compete at a time. On the time-scale of $\log N$ generations the logarithmic clone sizes converge to a Poissonian system of piecewise linear interacting trajectories (PIT), in which a clone reaching macroscopic size kinks all other trajectories down; the PIT has a positive, finite speed of adaptation with Gaussian fluctuations.
