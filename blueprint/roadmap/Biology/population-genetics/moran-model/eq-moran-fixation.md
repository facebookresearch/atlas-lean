# Uniqueness of the fixation probability

Let $r > 0$ be real and $N \ne 0$ a natural number, and let $\psi$ be a real function on the natural numbers with $\psi(0) = 0$, $\psi(N) = 1$ and

$$\psi(i) = a_i\, \psi(i + 1) + b_i\, \psi(i - 1) + (1 - a_i - b_i)\, \psi(i) \quad \text{for every } 0 < i < N.$$

Then $\psi(i) = \varphi_i$, the [fixation probability](moran-fixation.md), for every $i \le N$.
