# Common ancestor type process

In a stationary population with two types, mutation and selection, the individual whose progeny eventually takes over the population (the common ancestor) has a type that evolves along the ancestral line. Its stationary law, the ancestral type distribution, is biased towards the fit type and is characterized by the fixation probability of the offspring of all fit individuals.
