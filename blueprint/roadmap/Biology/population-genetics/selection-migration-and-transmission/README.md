# Selection, migration and transmission

These topics distinguish one-locus deterministic recurrences, spatial selection, finite-population linkage interference, modifiers of transmission, the structure of fitness landscapes, incompatibilities between diverged genomes in hybrids, sexual selection together with conflicts over transmission, and the dynamical limits on how fast a rapidly evolving population can adapt. This reading order does not assert a common model or a mathematical dependency.
