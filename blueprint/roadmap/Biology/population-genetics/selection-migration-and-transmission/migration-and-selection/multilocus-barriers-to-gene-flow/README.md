# Multilocus barriers to gene flow

Migration–selection–recombination balance for a block of locally deleterious alleles introgressing from a donor into a recipient species, and the resulting reduction of neutral gene flow at linked markers. Sex-linked and autosomal blocks obey the same equations with different sex-averaged parameters.
