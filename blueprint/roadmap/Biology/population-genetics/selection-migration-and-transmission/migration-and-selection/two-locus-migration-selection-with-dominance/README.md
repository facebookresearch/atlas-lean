# Two-locus migration–selection with dominance

Two linked diallelic loci under divergent selection in two demes connected by migration, with additive fitness across loci but arbitrary intermediate dominance within each locus. Dominance changes which equilibria survive gene flow: strictly intermediate dominance keeps a unique stable polymorphism under weak migration, recessive local alleles allow coexisting stable equilibria, and under strong migration only average overdominance can maintain variation. The continent–island limit is solvable in closed form under linkage equilibrium.
