# CRISPR homing drive invasion and stability

Deterministic diploid models of an endonuclease (CRISPR) homing drive at a locus that also carries drive-resistant alleles created by nonhomologous end joining. The transmission probabilities abstract the molecular mechanism, which yields mechanism-free invasion and evolutionary-stability criteria.
