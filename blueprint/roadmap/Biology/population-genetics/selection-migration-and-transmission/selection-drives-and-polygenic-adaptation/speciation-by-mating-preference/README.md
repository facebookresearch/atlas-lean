# Speciation by mating preference

Stochastic and deterministic models of a subdivided population in which two types differ only in mating preference (homogamy). Even a weak preference drives each patch to monomorphism and stops gene flow between patches, giving reproductive isolation after a time of order $\log K$ in a population of size of order $K$.
