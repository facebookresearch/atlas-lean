# Non-crossover gene conversion

Non-crossover (NCO) gene conversion transfers a short tract of sequence from one homolog to the other without exchanging flanking markers. These articles state the stratified estimator of the per-base NCO rate from pedigree data and the binomial test for GC-biased transmission at AT/GC heterozygous sites.
