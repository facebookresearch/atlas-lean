# Two-locus continent–island model

Haldane's continent–island model extended to two linked diallelic loci under genic selection: one-way gene flow at rate $m$ brings the continental haplotype $A_2B_2$ to an island where $A_1$ and $B_1$ are favoured, and recombination at rate $\rho$ breaks up locally adapted haplotypes. The equilibria are explicit, and linkage raises the migration rate up to which local adaptation can be maintained.
