# Moran model with single-crossover recombination

Finite-population recombination dynamics on linearly ordered sites. Tracing the ancestry of a sequence's site blocks backward gives a partitioning process dual to the Moran model; this duality explains linkage disequilibria in finite populations and recovers the deterministic recombination equation in the large-population limit.
