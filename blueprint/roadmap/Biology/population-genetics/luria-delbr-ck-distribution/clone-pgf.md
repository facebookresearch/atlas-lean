# Closed form of the clone-size generating function

For a real number $z$, let $h(z) = 1 + \bigl(\frac{1}{z} - 1\bigr) \log(1 - z)$, with the conventions $1/0 = 0$, $\log 0 = 0$ and $\log u = \log|u|$ for $u < 0$. For $0 < z < 1$ it is the generating function of the [clone-size law](clone-prob.md).
