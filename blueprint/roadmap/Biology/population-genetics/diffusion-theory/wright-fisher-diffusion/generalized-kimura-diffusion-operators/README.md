# Generalized Kimura diffusion operators

Degenerate elliptic operators on manifolds with corners that generalize the multi-allele Wright–Fisher generator. When the boundary weights (mutation rates) are positive, the associated weighted measure is doubling and supports a Poincaré inequality, which yields Harnack inequalities, regularity, heat-kernel bounds and a Weyl law.
