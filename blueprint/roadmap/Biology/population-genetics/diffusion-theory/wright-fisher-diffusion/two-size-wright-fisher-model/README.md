# Two-size Wright-Fisher model

A Wright-Fisher-type model in which offspring of two types consume different amounts of a fixed per-generation resource, so the population size is random and is set by a renewal stopping rule. Its large-resource diffusion limit has a type-dependent diffusion coefficient and, depending on the stopping rule, an overshoot-induced drift favouring the larger type.
