# Patterson's second appendix solution a₂

For a real number `x`, let `a₂(x) = (1 - x) / x`, with the convention `u / 0 = 0`, so that
`a₂(0) = 0`. The intended domain is `0 < x ≤ 1`. There `a₂` is Patterson's second solution (his
Equation A4) of `x² (1 - x) w''(x) / 2 = w(x)` (his Equation A2), which it
[solves on `(0, 1)`](patterson-aux2-ode.md); it vanishes at `x = 1` (his Equation A8).

## Sources

- N. J. Patterson, *How old is the most recent ancestor of two copies of an allele?*, Genetics 169
  (2005), 1093–1104.
