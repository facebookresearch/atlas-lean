# Patterson's second solution solves the killed backward equation

For `0 < x < 1`, `x (1 - x) a₂''(x) / 2 = a₂(x) / x`, where `a₂(x) = (1 - x) / x` is
[Patterson's second solution](patterson-aux2.md); that is, `a₂` solves the killed backward equation
`L₀ w (x) = w(x) / x` for the [neutral generator](../wright-fisher-diffusion/generator.md) `L₀`.
Multiplied by `x`, this is Patterson's Equation A2, `x² (1 - x) a₂''(x) / 2 = a₂(x)`.
