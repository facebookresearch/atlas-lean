# The killed Green's function is a two-solution Green kernel

For `0 < x < 1` and `0 < y < 1`, the killed Green's function [`G_C`](killed-green.md) is the
two-solution Green kernel with left solution [`a₁`](patterson-aux1.md), right solution
[`a₂`](patterson-aux2.md) and coefficient `c(y) = 2 / y²`: `G_C(x, y) = c(y) a₁(x)` if `x ≤ y`, and
`G_C(x, y) = c(y) (a₁(y) / a₂(y)) a₂(x)` if `y < x`.
