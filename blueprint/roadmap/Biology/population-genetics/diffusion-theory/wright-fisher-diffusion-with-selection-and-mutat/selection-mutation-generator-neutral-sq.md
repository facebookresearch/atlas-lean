# The neutral generator sends y² to x(1 − x)

For every real `x`, the [selection–mutation generator](selection-mutation-generator.md) with
`α = θ₁ = θ₂ = 0`, applied to `y ↦ y²`, satisfies `(L_{0,0,0} (y ↦ y²))(x) = x (1 - x)`. For a
frequency `x ∈ [0, 1]` this is the infinitesimal variance of the neutral Wright–Fisher diffusion;
outside `[0, 1]` the value is negative (for example `-2` at `x = 2`) and is not a variance.
