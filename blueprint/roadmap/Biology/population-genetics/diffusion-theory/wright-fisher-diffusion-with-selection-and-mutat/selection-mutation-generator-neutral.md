# The neutral generator is x(1 − x)/2 times the second derivative

For every real function `f` and every real `x`, the [selection–mutation generator](selection-mutation-generator.md) with `α = θ₁ = θ₂ = 0` is
`(L_{0,0,0} f)(x) = x (1 - x) / 2 · f''(x)`, where `f''` is taken to be `0` where it does not
exist.
