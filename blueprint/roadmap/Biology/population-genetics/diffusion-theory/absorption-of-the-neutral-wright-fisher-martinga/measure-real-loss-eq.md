# A neutral solution started at x is lost with probability 1 − x

Let `μ` be a probability measure, `(ℱ_t)_{t ≥ 0}` a filtration and `X` a solution of the
[martingale problem for the Wright–Fisher diffusion](../fixation-and-absorption-in-the-wright-fisher-dif/is-wright-fisher-solution.md)
with `σ = 0` with respect to `(ℱ_t)` and `μ`, with `X_0 = x` `μ`-almost surely. Then the allele is
eventually lost with probability `1 - x`:
`μ(there is t₀ ≥ 0 with X_t = 0 for every t ≥ t₀) = 1 - x`. This is the fixation of the other
allele, whose frequency `1 - X` [is again a neutral solution](is-wright-fisher-solution-one-sub.md).
