# Started at 0 or 1, the absorption time is zero

Let `μ` be a measure and `X` a real process with `X_0 = x` `μ`-almost everywhere, where `x = 0` or
`x = 1`. Then the
[absorption time](../fixation-and-absorption-in-the-wright-fisher-dif/absorption-time.md)
`τ = inf {t ≥ 0 : X_t ∈ {0, 1}}` of `X` satisfies `τ = 0` `μ`-almost everywhere. No equation for `X`
is assumed.
