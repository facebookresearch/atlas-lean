# The scale-function ratio does not depend on the base point

Let `b`, `a` define a [regular diffusion](../selection-duality-and-general-one-dimensional-di/is-regular-diffusion.md) on `(0, 1)`. For all `c, p ∈ [0, 1]`, the
[scale-function ratio](../selection-duality-and-general-one-dimensional-di/fixation-prob.md) `S(p) / S(1)` can be computed with the
[scale function with base point](scale-function-from.md) `c`:

`S(p) / S(1) = (S_c(p) - S_c(0)) / (S_c(1) - S_c(0))`.

The additive normalization constant of the scale function cancels.
