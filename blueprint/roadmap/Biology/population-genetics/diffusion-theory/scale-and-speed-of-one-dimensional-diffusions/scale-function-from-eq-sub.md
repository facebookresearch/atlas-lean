# Changing the base point shifts the scale function by a constant

Let `b`, `a` define a
[regular diffusion](../selection-duality-and-general-one-dimensional-di/is-regular-diffusion.md) on
`(0, 1)` (`a` positive and continuous on `(0, 1)`, `b / a` continuous on `(0, 1)` and integrable on
`[0, 1]`; accessibility of the endpoints and a probability normalization are not part of this). For
all `c, p ∈ [0, 1]`, the [scale function with base point](scale-function-from.md) `c` and the
[scale function](../selection-duality-and-general-one-dimensional-di/scale-function.md) `S`,
normalized by `S(0) = 0`, satisfy `S_c(p) = S(p) - S(c)`. The integrability of `b / a` up to the
endpoints makes the scale density continuous on `[0, 1]`, so these integrals are finite for base
points and arguments up to `0` and `1`.
