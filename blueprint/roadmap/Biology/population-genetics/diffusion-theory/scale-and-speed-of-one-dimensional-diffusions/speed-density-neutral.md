# Speed density of the neutral Wright–Fisher diffusion

For the neutral Wright–Fisher diffusion, with drift `0` and variance `x (1 - x)`, the scale density
is `1` and the [speed density](speed-density.md) is `m(x) = 2 / (x (1 - x))` for every real `x`.
Division by `0` gives `0`, so both sides are `0` at `x = 0` and `x = 1`; the intended domain is
`x ∈ (0, 1)`.
