# Neutral Wright–Fisher Green's function

For real numbers $p$ and $x$, let

$$G(p, x) = \frac{2(1 - p)}{1 - x} \ \text{ if } x \le p, \qquad G(p, x) = \frac{2p}{x} \ \text{ if } p < x,$$

with the convention that division by $0$ gives $0$. For $0 \le p \le 1$ and $0 < x < 1$, $G(p, x)\,dx$ is the expected time that a neutral allele started at frequency $p$ spends at frequencies in $(x, x + dx)$ before loss or fixation, with time in units of $2N$ generations.
