# Time-dependent Poisson random fields

Non-equilibrium versions of the Sawyer–Hartl Poisson random field, in which the site-frequency distribution at time $t$ after a population split mixes transported legacy polymorphisms from the ancestral species with polymorphisms from new mutations. They give the Poisson distribution of polymorphism and fixed-difference counts in two-species McDonald–Kreitman tables.
