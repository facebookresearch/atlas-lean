# Expected number of sites derived in the whole neutral sample

For every real $\theta$ and every natural number $n \ge 1$, the neutral value at $i = n$ of the [expected site frequency spectrum](expected-sfs.md) is $\theta/n$; for $\theta \ge 0$ it is the expected number of sites at which all $n$ sampled copies carry the derived allele. These sites are monomorphic in the sample, so this is not a class of the site frequency spectrum.
