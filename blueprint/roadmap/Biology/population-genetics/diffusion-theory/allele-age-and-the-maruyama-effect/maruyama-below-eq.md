# Sojourn density below the current frequency via fixation probability

For every real $\sigma$ and every $z \in (0, 1)$, the [closed form below the current frequency](maruyama-below.md) is

$$\Psi_1^\sigma(z) = \frac{2\, u_\sigma(z)\bigl(1 - u_\sigma(z)\bigr)}{z(1 - z)\, K_\sigma\, e^{-2\sigma z}},$$

where $u_\sigma$ is [Kimura's fixation probability](../wright-fisher-diffusion/kimura-fixation.md) and $K_\sigma e^{-2\sigma z} = u_\sigma'(z)$, with the [slope constant](../wright-fisher-diffusion/kimura-slope.md) $K_\sigma$.
