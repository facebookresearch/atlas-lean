# Closed form above the current frequency

For all real $\sigma$, $p$, $x$ and $z$ with $0 < p \le x \le z < 1$, the [conditional sojourn density](age-density.md) equals the [closed form above the current frequency](maruyama-above.md): $\Psi_\sigma(p, x; z) = \Psi_2^\sigma(x, z)$, which does not depend on $p$.
