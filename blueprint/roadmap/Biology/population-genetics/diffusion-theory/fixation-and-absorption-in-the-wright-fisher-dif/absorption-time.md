# Absorption time of a frequency path

For a real process $(X_t)_{t \ge 0}$ and an outcome $\omega$, the absorption time is $\tau(\omega) = \inf\{t \ge 0 : X_t(\omega) \in \{0, 1\}\}$, with the convention $\inf \emptyset = 0$. For a [solution of the Wright–Fisher martingale problem](is-wright-fisher-solution.md) the path is [absorbed almost surely](ae-exists-absorbed.md), so the convention only affects a null set.
