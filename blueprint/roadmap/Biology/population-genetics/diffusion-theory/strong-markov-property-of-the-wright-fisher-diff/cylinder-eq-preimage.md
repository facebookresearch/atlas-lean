# A cylinder read through the increasing enumeration of its times

For a finite set `J` of times and a set `S ⊆ [0, 1]^J`, the cylinder `{ω : ω|_J ∈ S}` of
[sample paths](../construction-of-the-neutral-wright-fisher-diffus/sample-path.md) is the set of
paths `ω` with `(ω(j_1), …, ω(j_m)) ∈ e⁻¹(S)`, where `j_1 < ⋯ < j_m` are the elements of `J` in
increasing order and `e : [0, 1]^m → [0, 1]^J` sends `(y_1, …, y_m)` to the function `j_k ↦ y_k`.
