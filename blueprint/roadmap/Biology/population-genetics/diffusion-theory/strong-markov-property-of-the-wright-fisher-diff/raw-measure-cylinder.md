# The path measure of a cylinder is a finite-dimensional law

For every `x ∈ [0, 1]`, every finite set `J` of times, with elements `j_1 < ⋯ < j_m`, and every
measurable `S ⊆ [0, 1]^J`, the
[canonical path measure](../construction-of-the-neutral-wright-fisher-diffus/raw-measure.md) `P_x`
gives the cylinder `{ω : ω|_J ∈ S}` the mass
`P_x({ω : ω|_J ∈ S}) = Q_{0, (j_1, …, j_m)}(x, e⁻¹(S))`, where `Q` is the
[finite-dimensional kernel](../../../../Probability/markov-chains/markov-processes-from-transition-semigroups/finite-chain-kernel.md)
of the
[neutral Wright–Fisher kernels](../construction-of-the-neutral-wright-fisher-diffus/neutral-kernel.md)
and `e : [0, 1]^m → [0, 1]^J` sends `(y_1, …, y_m)` to the function `j_k ↦ y_k`.
