# Path-measure kernel of the neutral Wright–Fisher diffusion

The Markov kernel from `[0, 1]` to the
[sample paths](../construction-of-the-neutral-wright-fisher-diffus/sample-path.md) that sends `x` to
the [canonical path measure](../construction-of-the-neutral-wright-fisher-diffus/raw-measure.md)
`P_x` of the neutral Wright–Fisher diffusion started at `x`; it is a kernel because
[`x ↦ P_x` is measurable](measurable-raw-measure.md).
