# Kimura's fixation probability is below x for σ < 0 and 0 < x < 1

For every real `σ < 0` and every `x ∈ (0, 1)`,
[Kimura's fixation probability](../wright-fisher-diffusion/kimura-fixation.md) satisfies
`u_σ(x) < x`: a deleterious allele is fixed with probability strictly smaller than its initial
frequency.
