# Started at 0, the realization stays at 0 almost surely

For almost every sample path `ω` under the
[canonical path measure](../construction-of-the-neutral-wright-fisher-diffus/raw-measure.md) `P_0`,
the
[continuous realization](../construction-of-the-neutral-wright-fisher-diffus/modified-process.md)
`X` started at `0` satisfies `X_t(ω) = 0` for every time `t ≥ 0`.
