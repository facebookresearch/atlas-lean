# At each fixed time the realization equals the coordinate almost surely

For every `x ∈ [0, 1]` and every time `t ≥ 0`, the
[continuous realization](../construction-of-the-neutral-wright-fisher-diffus/modified-process.md)
`X` started at `x` satisfies `X_t(ω) = ω(t)` for `P_x`-almost every sample path `ω`, where `P_x` is
the [canonical path measure](../construction-of-the-neutral-wright-fisher-diffus/raw-measure.md).
