# Continuous realization as a process with values in the unit interval

For `x ∈ [0, 1]`, a time `t ≥ 0` and a
[sample path](../construction-of-the-neutral-wright-fisher-diffus/sample-path.md) `ω`, the value
`X_t(ω)` of the
[continuous realization](../construction-of-the-neutral-wright-fisher-diffus/modified-process.md)
`X` of the neutral Wright–Fisher process started at `x`, regarded as a point of the state space
`[0, 1]`, which contains every value of `X`.
