# Branching Brownian motion with crowding selection

A fixed-size particle system: particles diffuse with a drift, branch at unit rate, and at each branching event one particle is removed from the most crowded cell of a fine spatial partition. Its hydrodynamic limit is a parabolic free obstacle problem in which removal acts only where the density is maximal.
