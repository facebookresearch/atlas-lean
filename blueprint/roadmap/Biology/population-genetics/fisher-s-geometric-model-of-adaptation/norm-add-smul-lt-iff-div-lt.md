# Beneficial mutation criterion using the outward radial angle

For a phenotype `a ∈ ℝⁿ` at distance `‖a‖ = z > 0` from the optimum `0`, a mutation size `r > 0`
and a unit direction `u` (`‖u‖ = 1`), `‖a + r u‖ < ‖a‖` if and only if `⟪a, u⟫ / z < -r / (2z)`,
that is `cos θ < -r / (2z)` with `cos θ = ⟪a, u⟫ / z`, where `θ` is the angle between `u` and
the outward radial direction `a / z`, pointing from the optimum to the phenotype (the direction
towards the optimum is `-a / z`).
