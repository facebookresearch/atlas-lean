# Exact criterion for a beneficial mutation

For a phenotype `a ∈ ℝⁿ`, a mutation size `r > 0` and a unit direction `u` (`‖u‖ = 1`), the mutant
`a + r u` is strictly closer to the optimum `0` than `a` if and only if `⟪a, u⟫ < -r / 2`. In terms
of the distance `z = ‖a‖ > 0` and `cos θ = ⟪a, u⟫ / z`, this reads
[`cos θ < -r / (2z)`](norm-add-smul-lt-iff-div-lt.md).
