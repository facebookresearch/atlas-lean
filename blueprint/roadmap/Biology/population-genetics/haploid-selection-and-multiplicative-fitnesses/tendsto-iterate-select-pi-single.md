# The fittest present type goes to fixation under repeated selection

Let `w` be positive fitnesses on a finite set of types and `p₀` initial frequencies with `p₀ ≥ 0`
and `∑_j p₀(j) = 1`. If a type `k` is initially present, `p₀(k) > 0`, and strictly fitter than
every other initially present type (`w_j < w_k` whenever `j ≠ k` and `p₀(j) > 0`), then under
repeated [haploid selection](../natural-selection-fisher-s-theorem-and-the-price/select.md) with
the constant fitnesses `w` the frequency vector converges to the vector with `1` at `k` and `0`
elsewhere: type `k` goes to fixation and every other type's frequency tends to `0`.
