# Prestige-biased cultural transmission

Models of cultural transmission in which copiers prefer role-models that are successful (success bias) or already widely copied (prestige bias). Sequential role-model choice with prestige feedback is a Pólya urn, so copier counts follow a Dirichlet-multinomial law whose overdispersion measures the strength of prestige bias.
