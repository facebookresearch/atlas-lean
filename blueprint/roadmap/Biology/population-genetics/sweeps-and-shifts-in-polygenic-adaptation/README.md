# Sweeps and shifts in polygenic adaptation

How the adaptive response of a polygenic trait after an environmental change is distributed across loci: a few large allele-frequency changes (sweeps) or many small ones (shifts). In a redundant-trait model the outcome is set by the stochastic establishment phase, which a Yule pure-birth process of surviving mutant lineages describes, and the decisive parameter is the population-scaled background mutation rate.
