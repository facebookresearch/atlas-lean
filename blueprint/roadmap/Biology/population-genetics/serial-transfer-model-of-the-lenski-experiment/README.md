# Serial-transfer model of the Lenski experiment

Individual-based model of daily serial transfer in long-term bacterial evolution experiments: Yule growth within a day up to a $\gamma$-fold expansion, then uniform sampling of $N$ founders. The neutral genealogy is a Cannings model with a Kingman limit, and a mutant with growth-rate advantage $\varrho_N$ fixes with probability $\sim \varrho_N\gamma\log\gamma/((\gamma-1)r)$.
