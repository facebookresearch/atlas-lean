# First-extinction time under repeated resampling

Repeatedly resampling $N$ draws from a discrete distribution (multinomial Wright–Fisher drift on $M$ states) eventually loses states. Approximating each state's frequency by an independent zero-drift square-root diffusion gives a closed-form law for the time until the first state is lost, whose mean is computable in $O(M)$ instead of the $2^M$ inclusion–exclusion of exact formulas.
