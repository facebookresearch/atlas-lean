# Single-crossover recombination

Recombination in which each recombination event cuts a sequence at one link and relinks a leading with a trailing segment. In continuous time the nonlinear recombination equation has a closed-form solution diagonalised by linkage disequilibria; in discrete time the solution is the law of a segmentation process, computed through ancestral recombination trees.
