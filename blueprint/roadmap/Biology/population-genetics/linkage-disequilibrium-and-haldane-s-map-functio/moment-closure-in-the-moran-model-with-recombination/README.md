# Moment closure in the Moran model with recombination

The finite-population Moran model with general (multiple-crossover) recombination is nonlinear, yet expectations of products of its marginal type counts, indexed by partitions of the sites, satisfy a finite closed system of linear differential equations. Closure survives mutation, and with resampling (genetic drift) the two-site moments still form a closed linear system.
