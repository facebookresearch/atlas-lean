# General multi-parent recombination equation

Deterministic recombination dynamics in which offspring types are assembled from arbitrary partitions of the sites, each block inherited from a different parent. The measure-valued equation is solved exactly through a universal ODE for coefficients indexed by set partitions, interpreted backwards in time as a partitioning process.
