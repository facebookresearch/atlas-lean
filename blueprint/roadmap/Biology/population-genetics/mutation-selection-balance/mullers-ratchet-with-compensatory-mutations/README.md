# Muller's ratchet with compensatory mutations

Fleming–Viot model of an asexual population in which deleterious mutations accumulate along lineages and can be reversed by compensatory mutations. The stochastic system is well posed, and in the infinite-population limit it has an explicit solution converging to a Poisson equilibrium whose mean balances mutation against selection plus compensation.
