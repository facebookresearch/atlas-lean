# Equivalence testing of Hardy-Weinberg equilibrium

Goodness-of-fit tests that establish approximate Hardy-Weinberg equilibrium, rather than merely failing to reject it, by testing whether a disequilibrium distance lies below a margin. For X-chromosomal loci the distance combines female excess heterozygosity with the female-male allele-frequency log odds ratio.
