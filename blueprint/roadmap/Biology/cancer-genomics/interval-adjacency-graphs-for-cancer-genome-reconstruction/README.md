# Interval-adjacency graphs for cancer genome reconstruction

Reconstruction of the block organization of a rearranged cancer genome from paired-end sequencing: intervals of the reference genome, novel adjacencies from discordant read pairs, and copy numbers inferred from read depth. Candidate cancer genomes are alternating Eulerian tours in a multigraph whose edge multiplicities satisfy copy-number balance, and maximum-likelihood multiplicities solve a separable convex flow problem.
