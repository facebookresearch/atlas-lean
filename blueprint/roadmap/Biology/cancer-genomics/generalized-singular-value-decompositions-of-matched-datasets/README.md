# Generalized singular value decompositions of matched datasets

Two genomic datasets measured on the same patients (and platforms) but on different probes, such as tumor and matched normal copy-number profiles, can be decomposed simultaneously with one shared set of patterns across the matched dimensions. The ratio of the generalized singular values, turned into an angular distance, measures whether each pattern is exclusive to one dataset or common to both, which separates tumor-specific alterations from germline and experimental variation.
