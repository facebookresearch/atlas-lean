# Multi-copy copy-number profile transformation

Evolutionary distance between two copy-number profiles (CNPs) measured as the cheapest sequence of segmental amplifications and deletions, where a single event may change copy numbers by more than one. The cost framework covers unit-step (MEDICC-style), doubling-bounded and unconstrained events; computing the distance is strongly NP-hard, while the unconstrained case has a linear-time factor-2 approximation.
