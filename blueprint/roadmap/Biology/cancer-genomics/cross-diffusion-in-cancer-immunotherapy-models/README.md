# Cross-diffusion in cancer immunotherapy models

Spatial versions of the Kirschner–Panetta model of effector cells, tumor cells and interleukin-2 (IL-2), with self-diffusion of each species and a cross-diffusion term through which IL-2 moves along tumor-cell gradients. Treatment by adoptive cellular immunotherapy enters as constant source terms. The cancer-free state has an explicit stability threshold, and cross-diffusion can destabilize the coexistence state into Turing patterns.
