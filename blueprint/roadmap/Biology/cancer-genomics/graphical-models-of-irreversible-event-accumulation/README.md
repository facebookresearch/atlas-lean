# Graphical models of irreversible event accumulation

Conditional-independence structure of binary event indicators (such as somatic mutations) produced by irreversible, inherited accumulation along a latent rooted tree, as in perfect-phylogeny and tumour-progression models. Observing lineages at random stages yields exactly the decomposable models whose Markov graph is the line graph of the tree, while leaf-only sampling collapses the graph to disjoint cliques.
