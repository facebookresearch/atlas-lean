# Allele-specific copy number from logR and BAF

Given tumour purity and ploidy, the expected log copy ratio (logR) and B-allele frequency (BAF) of a heterozygous site determine the copy numbers of both parental alleles in the cancer cells. Inverting this relation is how loss of heterozygosity is called, including at polymorphic loci such as HLA where reads are mapped to the patient's own alleles.
