# Sparse optimal chemotherapy in elastic phase-field tumour models

Optimal control of a Cahn–Hilliard–nutrient tumour model coupled to quasistatic linear elasticity, with time-dependent cytotoxic drug and nutrient-inhibitor controls penalized in $L^1$ as well as $L^2$. The $L^1$ penalty produces sparse treatment schedules: drugs are switched off exactly on the time set where an adjoint-weighted sensitivity stays below the sparsity weight.
