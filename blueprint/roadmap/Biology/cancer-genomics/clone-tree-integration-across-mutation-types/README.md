# Clone tree integration across mutation types

Tumor clones inferred separately from single-nucleotide variants and from copy-number aberrations give two partitions of the same cells, each with sample proportions and a clone tree. Integrating them means finding joint clones, consistent proportions and a common refinement of the two trees; parsimonious versions of this problem are NP-hard.
