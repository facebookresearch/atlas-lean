# Shrinkage-like estimator for progression-tree reconstruction

**Tree-induced distribution.** Let $\mathcal{T}$ be a rooted tree on the event set $G \cup \{\diamond\}$, where $\diamond$ is a special root event present in every sample, and let $\alpha : E(\mathcal{T}) \to [0,1]$ assign an independent firing probability to each edge. A sample is generated by firing edges independently, keeping an event exactly when every edge on its path from $\diamond$ fired. The probability of observing exactly the event set $A \subseteq G$ (necessarily a subtree containing the root) is
$$P_{\mathcal{T}}(A) = \prod_{\substack{(u,v)\in E(\mathcal{T})\\ u,v\in A\cup\{\diamond\}}} \alpha(u,v)\prod_{\substack{(u,v)\in E(\mathcal{T})\\ u\in A\cup\{\diamond\},\ v\notin A}} \bigl(1-\alpha(u,v)\bigr).$$
Along any edge $(u,v)$, $v$ can occur only if $u$ occurs, so $P(u) > P(v)$ whenever $\alpha(u,v) < 1$.

**Estimator.** For events $i \ne j$ with empirical probabilities, define the normalized probability-raising score and the correlation-type correction factor
$$\alpha_{i\to j} = \frac{P(j\mid i) - P(j\mid \bar i)}{P(j\mid i) + P(j\mid \bar i)}, \qquad \beta_{i\to j} = \frac{P(i,j) - P(i)P(j)}{P(i,j) + P(i)P(j)},$$
both taking values in $[-1,1]$, and for a shrinkage-like coefficient $\lambda \in [0,1]$ the combined confidence
$$m_{i\to j} = (1-\lambda)\,\alpha_{i\to j} + \lambda\,\beta_{i\to j}.$$
The reconstruction algorithm (CAPRESE) assigns to each event $j$ the parent $i$ maximizing $m_{i\to j}$ among prima facie causes of $j$ (events with $P(i) > P(j)$ that raise its probability), and replaces that edge by an edge from $\diamond$ when the dependence of $j$ on its best candidate is weaker than its dependence on the root, so that independent progressions form separate subtrees of a forest.

**Properties.**
1. *Monotonic normalization.* $\alpha_{i\to j} > \alpha_{j\to i}$ if and only if $P(j\mid i)/P(j\mid\bar i) > P(i\mid j)/P(i\mid\bar j)$; in particular, under positive dependence, $\alpha_{i\to j} > \alpha_{j\to i}$ iff $P(i) > P(j)$.
2. *Coherence.* $\beta_{i\to j} = \beta_{j\to i}$, and $\beta_{i\to j} > 0 \iff \alpha_{i\to j} > 0 \iff P(i,j) > P(i)P(j)$.
3. *Correctness.* The output is a well-defined forest rooted at $\diamond$: no cycles, no transitive edges and no disconnected components.
4. *Asymptotic convergence.* If the samples are drawn from $P_{\mathcal{T}}$ for a forest $\mathcal{T}$ and the observed frequencies equal the true probabilities (infinite sample size), CAPRESE with $\lambda \to 0$ reconstructs $\mathcal{T}$ exactly; an analogous statement holds under uniform false-positive and false-negative noise below explicit rates.

## Expansion

Property 1: $\alpha_{i\to j} = (r-1)/(r+1)$ with $r = P(j\mid i)/P(j\mid\bar i)$, and $r \mapsto (r-1)/(r+1)$ is strictly increasing on $(0,\infty)$; combine with [the temporal-priority identity](probability-raising-dependence-and-temporal-priority.md). Property 2: $\beta$ is symmetric by definition, and the sign of its numerator is the sign of $P(i,j) - P(i)P(j)$, which by the dependency proposition is the sign of $\alpha_{i\to j}$.

Property 4: in a tree-induced distribution every true parent $u$ of $v$ is a positively dependent, strictly more frequent event, so it is a prima facie cause of $v$. Other events can also be prima facie causes (ancestors further up, or events sharing an ancestor with $v$); the paper's supplementary proof shows that with exact probabilities the direct parent attains the maximal score and that the root filter removes the remaining spurious candidates. The correction $\beta$ matters with finite, noisy samples, where a transitive ancestor can tie with or beat the direct parent on $\alpha$ alone; the paper chooses $\lambda$ empirically (about $1/2$ under noise).
