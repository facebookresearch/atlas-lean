# Somatic variant likelihood-ratio tests

Somatic point mutations are called from matched tumour and normal sequencing reads by comparing, at each genomic site, a model with a variant allele present at some allele fraction against a model in which every non-reference base is a sequencing error. A second likelihood ratio on the normal reads separates somatic from germline variants. These articles give both log-odds scores, their prior-odds thresholds, and the read-count sensitivity they imply.
