# Rectilinear Steiner trees of single-cell copy-number profiles

When copy numbers of $d$ genes are counted in individual tumour cells (for example by multiprobe FISH), each observed cell pattern is a point of $\mathbb{Z}_{\ge 0}^d$, and one gain or loss of one gene moves a cell by one unit along one axis. A most parsimonious progression tree is then a rectilinear Steiner minimum tree on the observed patterns, with unobserved ancestral patterns as Steiner nodes.
