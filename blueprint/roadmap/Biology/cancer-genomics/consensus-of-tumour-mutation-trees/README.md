# Consensus of tumour mutation trees

Tumour phylogeny inference from bulk sequencing typically returns many mutation trees equally consistent with the data. They can be summarized by one or several consensus trees minimizing the parent-child distance: a single consensus tree is a maximum-weight spanning arborescence of the parent-child graph, while choosing several consensus trees jointly with a clustering of the input trees is NP-hard.
