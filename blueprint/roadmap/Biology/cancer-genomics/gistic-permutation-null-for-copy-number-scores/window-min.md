# Window minimum over consecutive markers

For natural numbers $W, n$, real values $y(0), \dots, y(W + n - 1)$ on $W + n$ markers and a starting position $0 \le i < W$, the window minimum is

$$\min_{0 \le k \le n} y(i + k),$$

the minimum over the $n + 1$ consecutive markers starting at $i$ (the per-sample gene-level value of GeneGISTIC).
