# Passenger-mutation clocks for tumour evolution

Neutral passenger mutations accumulate along every cell lineage at a roughly constant rate per cell division. Counting the passengers shared by a set of tumour samples, or private to one of them, therefore measures the number of divisions between successive founding events of the tumour, and a cell-cycle time converts divisions into years.
