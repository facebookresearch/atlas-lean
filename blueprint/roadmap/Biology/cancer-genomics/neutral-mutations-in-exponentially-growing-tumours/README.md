# Neutral mutations in exponentially growing tumours

Multitype branching-process models of tumour growth in which each type founds an exponentially growing wave and neutral passenger mutations accumulate. The population site frequency spectrum has the universal $1/x$ shape, a sample's spectrum depends on the sample size rather than the population size, and the clonal structure within later waves is governed by a Poisson point process with a power-law intensity.
