# Age-structured microlesion model of tumour growth

A solid tumour is modelled as a growing collection of non-interacting microlesions, each characterized by its age and its number of driver mutations; cells escaping from lesions seed new ones. The expected lesion density obeys a McKendrick–von Foerster equation, so the tumour's long-run growth rate is the root of an Euler–Lotka equation, and the model is exactly solvable for surface-growing lesions.
