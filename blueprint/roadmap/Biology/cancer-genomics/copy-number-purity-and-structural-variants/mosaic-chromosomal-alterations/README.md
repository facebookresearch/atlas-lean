# Mosaic chromosomal alterations

A mosaic chromosomal alteration (loss, copy-neutral loss of heterozygosity, or gain) present in a fraction of cells shifts the relative intensity of the two alleles at heterozygous sites. These articles give the allelic imbalance produced by each event type at a given clonal cell fraction, and a haplotype-phase-aware hidden Markov model that aggregates small imbalances along a chromosome into a likelihood-ratio test.

- [Phase-aware hidden Markov model test for mosaic allelic imbalance](phase-aware-hmm-test-for-mosaic-allelic-imbalance.md)
