# Multi-marker circulating tumour DNA detection

Tracking a resected tumour in plasma means testing many patient-specific single-nucleotide variants at every time point and calling the sample positive when enough of them are seen. The call rule is a multiple-testing problem: the per-assay error rate, the panel size and the number of variants demanded jointly fix the false-positive rate of the sample-level call, so enlarging a panel without tightening the per-assay threshold makes spurious detection more likely.
