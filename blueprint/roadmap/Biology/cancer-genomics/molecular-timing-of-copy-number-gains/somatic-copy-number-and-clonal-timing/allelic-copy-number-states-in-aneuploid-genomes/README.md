# Allelic copy-number states in aneuploid genomes

Cancer genomes are aneuploid, so SNP-array signals must be segmented into integer allelic copy-number states rather than diploid genotype calls. The state space of minor and major copy numbers, and the genotype classes each state allows, is the backbone of hidden Markov segmentation of tumour arrays.
