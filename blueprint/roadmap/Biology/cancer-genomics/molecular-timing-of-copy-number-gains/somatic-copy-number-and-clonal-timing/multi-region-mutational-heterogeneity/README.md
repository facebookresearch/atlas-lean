# Multi-region mutational heterogeneity

Quantifying how much the variant allele frequencies of driver mutations differ between samples
of the same tumour, after allowing for binomial read sampling and for differences in tumour cell
fraction: a purity-adjusted pairwise heterogeneity index and an overdispersed binomial regression
test for gene-by-sample interaction.
