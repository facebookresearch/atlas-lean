# Copy-number gain history

A single copy-number event on a region consists of a natural number $c_0$ (the number of copies before the event) and, for each original copy $i \in \{1, \dots, c_0\}$, a natural number $\delta_i$: the number of copies descending from copy $i$ after the event ($0$ if it is lost, $2$ if it is duplicated).
