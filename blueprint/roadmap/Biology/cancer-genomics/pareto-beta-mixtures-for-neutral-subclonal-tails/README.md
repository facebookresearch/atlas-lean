# Pareto–Beta mixtures for neutral subclonal tails

In a growing tumour, neutral passenger mutations accumulating within each clone produce a power-law tail of variant allele frequencies (VAFs) below the clonal peaks, while positively selected subclones produce peaked clusters. Mixing a Pareto (power-law) component with Beta components separates the two before downstream subclonal reconstruction.
