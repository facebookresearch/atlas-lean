# Mutation frequencies in Yule cell populations

An exponentially growing cell population started from one cell, with independent per-site nucleotide mutations at each division, observed when it first reaches $n$ cells. In the regime $n\mu\to\theta$ the number of mutant cells at a site is Luria–Delbrück, and the site frequency spectrum converges to a Poisson-marked stick-breaking measure.
