# Waiting time to cancer in a Wright–Fisher model

A Wright–Fisher model of somatic evolution in which an adenoma of growing size accumulates mutations in any of $d$ susceptible driver genes, each with the same small selective advantage $s$, and the cancer phenotype is reached when one cell carries $k$ driver mutations. The mutant classes form a travelling Gaussian wave whose speed gives an explicit approximation for the waiting time.
