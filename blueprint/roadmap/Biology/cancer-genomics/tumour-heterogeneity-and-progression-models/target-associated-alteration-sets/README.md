# Target-associated alteration sets

Finding a small set of genes whose alterations jointly cover the tumour samples with high values of a quantitative functional target (pathway activity, drug response), with overlaps penalized so that the solution favours mutually exclusive, functionally complementary alterations. The problem is NP-hard, a greedy algorithm is a tight $1/k$ approximation, and it recovers a planted set from polynomially many samples.
