# Zero-agnostic copy number transformations

An evolutionary distance between tumour copy number profiles counting the minimum number of segmental gains and losses, with events allowed to act on loci of any copy number. Passing to adjacent-locus differences turns every event into a two-entry move, which gives a closed-form $\ell_1$ distance, a metric, and efficient or approximate algorithms for small parsimony on copy number trees.
