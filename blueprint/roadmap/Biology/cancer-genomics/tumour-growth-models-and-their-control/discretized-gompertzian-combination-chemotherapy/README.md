# Discretized Gompertzian combination chemotherapy

Combination chemotherapy planned on a log-transformed Gompertz tumor model with one-compartment drug kinetics, fractional log-kill above an effective-concentration threshold, and kill effectiveness that decays as resistance develops. Forward-Euler discretization turns the planning problem into a mixed-integer linear program; the articles record when the discretization is stable and order-preserving, and how a binary-division branching process seeds the initial resistant subpopulations.
