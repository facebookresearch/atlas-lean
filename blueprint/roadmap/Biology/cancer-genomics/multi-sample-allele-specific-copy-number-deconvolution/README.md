# Multi-sample allele-specific copy-number deconvolution

Recovering clone-specific allelic copy numbers and clone proportions from several bulk samples of one tumour. Read-depth ratios are first scaled to fractional copy numbers using segments of known clonal state (diploid, or two clonal states after a whole-genome duplication); the fractional copy numbers are then jointly factored into integer copy-number matrices and a shared clone-proportion matrix under evolutionary constraints.
