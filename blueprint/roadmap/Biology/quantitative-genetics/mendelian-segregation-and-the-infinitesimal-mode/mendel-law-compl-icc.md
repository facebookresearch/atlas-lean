# The Mendelian offspring law puts no mass outside 0 ≤ x ≤ 2

For all natural `g₁, g₂`, the [Mendelian offspring law](mendel-law.md) is supported on
`{0, 1, 2}` (it is a combination of point masses at `0`, `1` and `2`), so it gives the complement
of `[0, 2]` measure `0`. For parental counts `g₁, g₂ ≤ 2`, where it is a probability measure, a
Mendelian draw thus lies in `{0, 1, 2} ⊆ [0, 2]`.
