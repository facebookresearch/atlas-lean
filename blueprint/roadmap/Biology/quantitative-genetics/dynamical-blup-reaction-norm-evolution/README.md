# Dynamical BLUP reaction-norm evolution

Evolution of phenotypic plasticity when the reaction-norm intercepts and slopes of individuals are not observed. A mixed model of the observed traits in the current environment gives BLUP predictions of each individual's additive reaction-norm deviations; Robertson's secondary theorem applied to these predictions updates the population means from one generation to the next, and with unrelated individuals it reproduces the multivariate breeder's equation in selection-gradient form.
