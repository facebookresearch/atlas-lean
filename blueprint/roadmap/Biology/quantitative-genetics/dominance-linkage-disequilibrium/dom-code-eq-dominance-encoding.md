# Dominance coding of allele indicators equals the dominance encoding

Let $x_1, x_2 \in \{0, 1\}$ and $p \in \mathbb{R}$. Then

$$(x_1 - p)(x_2 - p) = \eta_p(x_1 + x_2),$$

where $\eta_p$ is the [dominance encoding](dominance-encoding.md): for $0/1$ alleles the dominance coding depends only on the genotype $x_1 + x_2$.
