# Translation invariance of marker coding

Genomic regression models code each marker numerically (0/1/2, centred, symmetric $-1/0/1$), and these codings differ by a translation of each column. Whether estimates and predictions depend on that choice is decided by which polynomial coefficients the model penalizes.
