# Minorize–maximize REML for variance components

Restricted maximum likelihood (REML) estimates of the variance components of a linear mixed model can be computed by an MM iteration: each step minimizes a surrogate that majorizes the negative restricted log-likelihood, which yields a closed-form multiplicative update that keeps every component positive and never decreases the likelihood.
