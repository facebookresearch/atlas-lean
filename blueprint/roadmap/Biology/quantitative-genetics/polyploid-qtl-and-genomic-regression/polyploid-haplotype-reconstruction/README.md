# Polyploid haplotype reconstruction

Hidden Markov models that reconstruct, marker by marker, which parental homologs an offspring of an autotetraploid cross inherited. The hidden parental-origin process depends on whether each gamete arose from bivalent or quadrivalent pairing, and the observations are allele dosages or allele read counts subject to error.
