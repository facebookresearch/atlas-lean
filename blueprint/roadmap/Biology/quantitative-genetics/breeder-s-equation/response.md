# Response to selection

In a [linear parent–offspring model](model.md) on $\mu$ with mean $m$ and offspring value $O$, the response to selection of a set $s \subseteq \Omega$ (the selected parents) is

$$R(s) = \int O \, d\mu(\cdot \mid s) - m,$$

the mean offspring value of the selected parents relative to the population mean, where $\mu(\cdot \mid s)$ is the conditional measure (taken to be $0$ when $\mu(s) = 0$).
