# Ancestral paths from a non-founder

In a [pedigree](pedigree.md), if $i$ has parents $p_0 = f(i)$, $p_1 = m(i)$, then a sequence $p$ is an [ancestral path](anc-paths.md) from $i$ if and only if $p = (i)$ or $p = (i, q)$ (i.e. $i$ followed by $q$) for an ancestral path $q$ from $p_0$ or from $p_1$.
