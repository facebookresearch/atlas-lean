# Gene-dropping outcome

For a [pedigree](pedigree.md) on $n$ individuals, a gene-dropping outcome is a function $\omega$ assigning to each gene copy $(i, k)$ ($k = 0$ the paternal copy, $k = 1$ the maternal copy) a bit $\omega(i, k) \in \{0, 1\}$: the Mendelian coin saying which copy of the corresponding parent the copy inherits. There are $4^n$ outcomes, all equally likely under gene dropping.
