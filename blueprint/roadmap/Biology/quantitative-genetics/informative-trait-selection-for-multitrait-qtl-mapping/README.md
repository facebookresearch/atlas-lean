# Informative trait selection for multitrait QTL mapping

Joint analysis of several traits can raise or lower the power to detect a quantitative trait locus depending on effect patterns and residual correlations. Conditional Hotelling statistics quantify each trait's contribution, and a strongly correlated trait unaffected by the QTL can sharply increase power.
