# Multivariate assortative mating

Mates often correlate on many traits at once, and the cross-trait correlation between mates need not reduce to one or a few linear combinations. Modeling assortment by a mate cross-correlation matrix in an infinitesimal additive model shows that the law of any bounded set of loci is unaffected by assortment, while the genetic covariance matrix follows a multivariate Bulmer recursion whose fixed point generalizes Wright's and Gimelfarb's univariate limits for the equilibrium heritability.
