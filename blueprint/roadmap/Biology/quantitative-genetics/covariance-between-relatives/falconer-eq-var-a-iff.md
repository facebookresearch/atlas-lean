# Equality case of the phantom heritability inequality

For all [Cockerham–Kempthorne components](cockerham-components.md) $(n, V)$ and every real $C$, [Falconer's estimator](falconer.md) satisfies $F(C) = V_A$ if and only if $V_{ij} = 0$ for all $0 \le i, j \le n$ with $(i, j) \ne (1, 0)$, where $V_A$ is the [additive variance](var-a-2.md).
