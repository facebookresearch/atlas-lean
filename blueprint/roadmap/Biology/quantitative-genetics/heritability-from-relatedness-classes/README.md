# Heritability from relatedness classes

Heritability can be estimated from how phenotypic similarity scales with genetic relatedness, either across all pairs at once in a variance-component model or class by class (siblings, half-siblings, cousins). Close relatives share environment and non-additive genetic effects as well as additive effects, so the choice of relationship classes and kinship matrices decides which components an estimate absorbs. These articles cover a two-component model that separates total narrow-sense from SNP heritability without discarding relatives, a class-wise estimator whose pattern across classes distinguishes shared environment from dominance and epistasis, and the full- versus half-sibling decomposition of liability correlations.
