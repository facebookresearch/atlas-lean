# Shortfall of the naive variance

For real $\sigma_b^2$, $\sigma_e^2$ and natural numbers $D \ne 0$ and $m \ne 0$, the
[true variance](true-var.md) $V_{\mathrm{true}}(D, m) = \sigma_b^2 / D + \sigma_e^2 / (D m)$ and the
[naive variance](naive-var.md) $V_{\mathrm{naive}}(D, m) = (\sigma_b^2 + \sigma_e^2) / (D m)$ differ
by

$$V_{\mathrm{true}}(D, m) - V_{\mathrm{naive}}(D, m) = \frac{\sigma_b^2 (m - 1)}{D m}.$$
