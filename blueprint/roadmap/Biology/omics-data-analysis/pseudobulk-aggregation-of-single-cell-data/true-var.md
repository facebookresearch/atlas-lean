# True variance of the cell-level mean

For real $\sigma_b^2$, $\sigma_e^2$ and natural numbers $D$ and $m$, put

$$V_{\mathrm{true}}(D, m) = \frac{\sigma_b^2}{D} + \frac{\sigma_e^2}{D m}.$$

With the convention $x / 0 = 0$ it is $0$ when $D = 0$ and $\sigma_b^2 / D$ when $m = 0 < D$. For
$D \ge 1$ donors with $m \ge 1$ cells each, it is the
[variance of the cell-level mean](variance-cell-mean.md) of a
[random-intercept model](is-random-intercept.md) under a finite measure.
