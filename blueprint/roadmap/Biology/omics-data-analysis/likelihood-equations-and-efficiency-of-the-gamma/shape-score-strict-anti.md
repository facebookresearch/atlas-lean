# With a positive count the shape score strictly decreases

Let $\iota$ be a finite set of $n$ observations, with counts $k_i \in \mathbb{N}$ and size factors
$s_i$. If some count $k_i$ is positive, then for every real $b$, all real size factors and
$0 < x < y$, the [shape score](shape-score.md) satisfies $S_a(y, b) < S_a(x, b)$.
