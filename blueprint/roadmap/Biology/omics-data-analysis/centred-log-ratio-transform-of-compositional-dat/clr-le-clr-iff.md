# CLR coordinates are ordered as the parts

Let $\iota$ be a finite set of parts, $x$ a [positive composition](pos-composition.md) on
$\iota$ (so $x_i > 0$ for every $i$) and $i, j$ two parts. Then
$\operatorname{clr}(x)_i \le \operatorname{clr}(x)_j$ if and only if $x_i \le x_j$: within one
composition, the [CLR transform](clr.md) preserves and reflects the order of the parts.
