# Omics data analysis

transform of compositional data, centring and covariance choices before PCA, Gamma–Poisson (negative
binomial) count models with size factors, with their empirical-Bayes shrinkage and
maximum-likelihood estimation, and replicate structure in single-cell studies (crossed random
effects, pseudobulk aggregation). Association studies are under
[Statistical genetics](../statistical-genetics/README.md).
