# The population rate score strictly decreases in the rate

Let `μ` be a probability measure on `Ω`, `S : Ω → ℝ` measurable with `S(ω) > 0` for every `ω`, and
`K : Ω → ℕ` measurable and integrable. For `a > 0` and `0 < b < b'`, the
[population rate score](pop-rate-score-log.md) `R(a, b) = a - E[(a + K) b / (b + S)]` satisfies
`R(a, b') < R(a, b)`.
