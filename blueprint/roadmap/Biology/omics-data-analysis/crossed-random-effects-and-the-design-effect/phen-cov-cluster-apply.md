# Entries of σ_c² Z Zᵀ + σ_w² I for a single cluster

For a natural number `m` and real numbers `σ_c²` and `σ_w²`, let `Z` be the
[all-ones design](cluster-design.md) of size `m × 1`. The matrix `V = Z (σ_c² I₁) Zᵀ + σ_w² I_m` has
entries `V_{kl} = σ_c² + [k = l] σ_w²` for `k, l ∈ {0, …, m - 1}`, where `[k = l]` is `1` if `k = l`
and `0` otherwise: `σ_c²` everywhere plus `σ_w²` on the diagonal. The identity is algebraic and
holds for all real `σ_c²` and `σ_w²`.
