# Small pulses from the left nullcline branch make the voltage fall

Let `I` be real and `(v, w)` a state on the voltage nullcline, `v - v³/3 - w + I = 0` (for instance
a rest state), on the left branch `-2 ≤ v < -1`. For every amplitude `δ` with
`0 < δ < (-3v - √(12 - 3v²))/2`, below the [lower root](pulse-root-low.md), the
[voltage falls after the pulse](is-falling-after-pulse.md).
