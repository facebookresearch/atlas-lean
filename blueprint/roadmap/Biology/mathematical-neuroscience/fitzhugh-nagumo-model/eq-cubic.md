# Equilibrium cubic of the FitzHugh–Nagumo model

For real `a`, `b`, `I` and `v`, the equilibrium cubic is `v - v³/3 - (v + a)/b + I`. For `b ≠ 0` it
is the [voltage component](v-field.md) of the field on the recovery nullcline `w = (v + a)/b`. With
the convention `x / 0 = 0` it is `v - v³/3 + I` at `b = 0`.
