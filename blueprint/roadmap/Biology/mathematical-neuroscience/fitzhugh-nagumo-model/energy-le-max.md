# For b, ε > 0, every solution stays in a fixed ellipse

Let `b > 0`, `ε > 0`, `a` and `I` real, and let `(v, w)` be a [solution](is-solution.md). For every
`t ≥ 0`,

`v(t)² + w(t)²/ε ≤ max(v(0)² + w(0)²/ε, C / κ + 1)`,

where `C / κ` is the [trapping radius](trap-radius.md). In particular the solution is bounded on
`[0, ∞)`.
