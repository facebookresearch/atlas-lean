# For 0 < b < 1, ε > 0, the Jacobian is Hurwitz iff v² > 1 − ε b

Let `0 < b < 1`, `ε > 0` and `v` real. The [Jacobian](jacobian.md) at voltage `v` is
[Hurwitz](../../../LinearAlgebra/special-matrices/m-matrices-and-hurwitz-stability/nonsingular-m-matrices/is-hurwitz.md)
(every complex eigenvalue has negative real part) if and only if `v² > 1 - ε b`. The statement is
about the Jacobian at any real voltage `v`; at an [equilibrium](is-equilibrium.md) with voltage `v`
it concerns that rest state.
