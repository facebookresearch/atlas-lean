# Reaching a voltage level within an explicit time

Let `a`, `b`, `ε` and `I` be real, `(v, w)` a [solution](is-solution.md), `T ≥ 0`, `α ≤ γ`, and
`w₀`, `η`, `m` real with `η < m`. Suppose that `|w(t) - w₀| ≤ η` for every `t ∈ [0, T]`, that
`u - u³/3 - w₀ + I ≥ m` for every `u ∈ [α, γ]`, that `γ - α ≤ (m - η) T`, and that `α ≤ v(0)`. Then
`v(t) ≥ γ` for some `t ∈ [0, T]`.
