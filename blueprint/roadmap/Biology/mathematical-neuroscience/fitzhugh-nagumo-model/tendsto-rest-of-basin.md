# For b, ε > 0 and vr² > 1, solutions from a small ball return to rest

Let `a`, `I` be real, `b > 0`, `ε > 0`, `(vr, wr)` an [equilibrium](is-equilibrium.md), and `ρ > 0`
with `|vr| ρ < vr² - 1` (so `vr² > 1`). Every [solution](is-solution.md) `(v, w)` with
`(v(0) - vr)² + (w(0) - wr)²/ε ≤ ρ²` tends to `(vr, wr)` as `t → ∞`, exponentially
([decay from a small ball](rest-energy-le-exp-of-basin.md)).
