# For b, ε > 0 and vr² > 4, every solution returns to rest

Let `a`, `I` be real, `b > 0`, `ε > 0`, and `(vr, wr)` an [equilibrium](is-equilibrium.md) with
`vr² > 4`. Every [solution](is-solution.md) `(v, w)` tends to `(vr, wr)` as `t → ∞`, exponentially
([global bound](rest-energy-le-exp-global.md)).
