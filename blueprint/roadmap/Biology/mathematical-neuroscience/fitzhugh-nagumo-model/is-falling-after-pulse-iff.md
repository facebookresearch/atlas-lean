# On the voltage nullcline with v² ≤ 4, falling pulses avoid the window

Let `I` be real and `(v, w)` a state on the voltage nullcline, `v - v³/3 - w + I = 0` (for instance
a rest state), with `v² ≤ 4`. For every amplitude `δ > 0`, the
[voltage falls after the pulse](is-falling-after-pulse.md) if and only if
`δ < (-3v - √(12 - 3v²))/2` or `δ > (-3v + √(12 - 3v²))/2`, outside the closed interval between the
[lower](pulse-root-low.md) and [upper](pulse-root-high.md) roots of the post-pulse factor.
