# For vr² ≤ 4, the post-pulse factor is positive exactly on the window

For real `vr` with `vr² ≤ 4` and every real `δ`, `1 - vr² - vr δ - δ²/3 > 0` if and only if
`(-3vr - √(12 - 3vr²))/2 < δ < (-3vr + √(12 - 3vr²))/2`, strictly between the
[lower](pulse-root-low.md) and [upper](pulse-root-high.md) roots. For `δ > 0` and a state on the
voltage nullcline this is the [rising-pulse condition](is-rising-after-pulse-iff.md). Every `δ` in
the window is positive when `vr ≤ -1` ([nonnegative lower root](pulse-root-low-nonneg.md)); for
`-1 < vr < 2` the window is nonempty and also contains nonpositive `δ`
([negative lower root](pulse-root-low-neg.md)); at `vr = ±2` it is empty.
