# For b, ε > 0 and vr² ≤ 4, nonconstant periodic orbits enter the window

Let `a`, `I` be real, `b > 0`, `ε > 0`, `(vr, wr)` an [equilibrium](is-equilibrium.md) with
`vr² ≤ 4`, `T > 0`, and `(v, w)` a [solution](is-solution.md) with `v(t + T) = v(t)` and
`w(t + T) = w(t)` for every `t ≥ 0`, which is not constantly at rest: `v(t₀) ≠ vr` or `w(t₀) ≠ wr`
for some `t₀ ≥ 0`. Then for some `t ≥ 0` the voltage displacement `x = v(t) - vr` lies strictly
between the [lower](pulse-root-low.md) and [upper](pulse-root-high.md) roots
`(-3vr ∓ √(12 - 3vr²))/2`, where the [post-pulse factor](rest-factor.md) is positive.

For `vr ≤ -1` the window consists of positive amplitudes, the pulses after which the voltage rises
from rest; for `-1 < vr < 2` it also contains nonpositive displacements, at which the voltage need
not rise; at `vr = ±2` it is empty, so no nonconstant periodic solution exists there.
