# Upper root of the post-pulse factor

For real `v`, the upper root is `(-3v + √(12 - 3v²))/2`. For `v² ≤ 4` it is the larger root in `δ`
of the post-pulse factor `1 - v² - v δ - δ²/3`. For `v² > 4` the square root is `0` by the
convention `√x = 0` for `x < 0`, so the value is `-3v/2`; then the post-pulse factor has no real
root.

For a rest state on the open left branch `-2 < v < -1` it is the upper end of the open interval of
positive pulses after which the voltage rises ([rising window](is-rising-after-pulse-iff.md)).
