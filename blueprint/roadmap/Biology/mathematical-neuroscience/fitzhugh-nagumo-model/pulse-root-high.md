# Upper quadratic-formula expression of the post-pulse factor

For real `v`, the upper pulse root is `r₊(v) = (-3v + √(12 - 3v²))/2`, the quadratic-formula
expression with the plus sign for the post-pulse factor `1 - v² - v δ - δ²/3` in `δ`. For `v² > 4`
the square root is `0` by the convention `√x = 0` for `x < 0`, so the value is `-3v/2`. For `v² ≤ 4`
the post-pulse factor is positive exactly for `r₋(v) < δ < r₊(v)`, with the
[lower expression](pulse-root-low.md) `r₋(v)` ([positivity window](rest-factor-pos-iff.md)).

For a rest state on the open left branch `-2 < v < -1`, `r₊(v)` is the upper end of the open
interval of positive pulses after which the voltage rises
([rising window](is-rising-after-pulse-iff.md)).
