# Lower quadratic-formula expression of the post-pulse factor

For real `v`, the lower pulse root is `r₋(v) = (-3v - √(12 - 3v²))/2`, the quadratic-formula
expression with the minus sign for the post-pulse factor `1 - v² - v δ - δ²/3` in `δ`. For `v² > 4`
the square root is `0` by the convention `√x = 0` for `x < 0`, so the value is `-3v/2`. For `v² ≤ 4`
the post-pulse factor is positive exactly for `r₋(v) < δ < r₊(v)`, with the
[upper expression](pulse-root-high.md) `r₊(v)` ([positivity window](rest-factor-pos-iff.md)).

For a rest state on the open left branch `-2 < v < -1`, `r₋(v)` is
[positive](pulse-root-low-pos.md), and the positive pulses after which the voltage rises are exactly
those between `r₋(v)` and `r₊(v)` ([rising window](is-rising-after-pulse-iff.md)), a nonempty open
interval ([distinct values](pulse-root-low-lt-pulse-root-high.md)).
