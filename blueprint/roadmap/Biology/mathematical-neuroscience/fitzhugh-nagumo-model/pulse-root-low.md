# Lower root of the post-pulse factor

For real `v`, the lower root is `(-3v - √(12 - 3v²))/2`. For `v² ≤ 4` it is the smaller root in `δ`
of the post-pulse factor `1 - v² - v δ - δ²/3`: from a rest state with voltage `v`, a pulse of this
amplitude lands on the voltage nullcline. For `v² > 4` the square root is `0` by the convention
`√x = 0` for `x < 0`, so the value is `-3v/2`; then the post-pulse factor has no real root.

For a rest state on the open left branch `-2 < v < -1` it is positive, and the positive pulses after
which the voltage rises are exactly those between it and the [upper root](pulse-root-high.md)
([rising window](is-rising-after-pulse-iff.md)), a nonempty open interval
([distinct roots](pulse-root-low-lt-pulse-root-high.md)).
