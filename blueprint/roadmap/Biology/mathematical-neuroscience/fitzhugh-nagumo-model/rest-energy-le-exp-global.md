# For ε > 0, a global exponential bound on the centred energy

Let `a`, `b`, `I` be real, `ε > 0`, `(vr, wr)` an [equilibrium](is-equilibrium.md) and `(v, w)` a
[solution](is-solution.md). For every `t ≥ 0`,

`E(t) ≤ e^(-2 min(vr²/4 - 1, b ε) t) E(0)`,

where `E(s)` is the [centred energy](rest-energy.md) `(v(s) - vr)² + (w(s) - wr)²/ε`. The rate
`min(vr²/4 - 1, b ε)` is positive if and only if `vr² > 4` and `b > 0`, and then every solution
[converges to the rest state](tendsto-rest-of-four-lt-sq.md).
