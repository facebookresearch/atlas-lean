# For 0 < b < 1, ε > 0, some eigenvalue has Re > 0 iff v² < 1 − ε b

Let `0 < b < 1`, `ε > 0` and `v` real. The [Jacobian](jacobian.md) at voltage `v` has a complex
eigenvalue with positive real part if and only if `v² < 1 - ε b`. The statement is about the
Jacobian at any real voltage `v`; at an [equilibrium](is-equilibrium.md) with voltage `v` it
concerns that rest state.
