# Trapping radius of the FitzHugh–Nagumo energy

For real `a`, `b`, `ε` and `I`, the trapping radius is `C / κ`, the quotient of the
[constant](absorb-const.md) `C = 5 + I²/2 + a²/(2 b)` by the [decay rate](decay-rate.md)
`κ = min(1, b ε / 2)`. For `b > 0` and `ε > 0`, every ellipse `v² + w²/ε = R` with `R > C / κ` is
trapping: the field points strictly into `v² + w²/ε ≤ R` on it
([trapping](energy-flux-neg-of-energy-eq.md)). With the convention `x / 0 = 0` it is `0` when
`b ε = 0`.
