# On the voltage nullcline with v² ≤ 4, rising pulses form a window

Let `I` be real and `(v, w)` a state on the voltage nullcline, `v - v³/3 - w + I = 0` (for instance
a rest state), with `v² ≤ 4`. For every amplitude `δ > 0`, the
[voltage rises after the pulse](is-rising-after-pulse.md) if and only if
`(-3v - √(12 - 3v²))/2 < δ < (-3v + √(12 - 3v²))/2`, strictly between the [lower](pulse-root-low.md)
and [upper](pulse-root-high.md) roots of the post-pulse factor.
