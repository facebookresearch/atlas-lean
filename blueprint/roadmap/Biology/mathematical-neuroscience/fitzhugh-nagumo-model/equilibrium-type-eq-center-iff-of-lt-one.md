# For 0 < b < 1, ε > 0, the type is a linear center iff v² = 1 − ε b

Let `0 < b < 1`, `ε > 0` and `v` real. The [linearization type](equilibrium-type.md) at voltage `v`
is a linear center (`Δ > 0` and `τ = 0`: purely imaginary eigenvalues, so an equilibrium there is
nonhyperbolic) if and only if `v² = 1 - ε b`. This is a condition on the linearization only: no
transversality or nonlinear nondegeneracy condition, as in a Hopf bifurcation, is part of it.
