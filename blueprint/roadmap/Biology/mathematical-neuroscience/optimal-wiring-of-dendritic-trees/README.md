# Optimal wiring of dendritic trees

Dendritic and axonal arbors can be generated as greedy optimal graphs over a cloud of target ("carrier") points: each new branch minimizes a weighted sum of cable length (material cost) and path length back to the root (conduction-time cost). One balancing parameter interpolates between a minimum spanning tree and a star, and sets the tree's electrotonic compartmentalization.
