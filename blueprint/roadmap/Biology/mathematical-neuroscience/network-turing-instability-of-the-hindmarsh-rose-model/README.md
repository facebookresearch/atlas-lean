# Network Turing instability of the Hindmarsh-Rose model

Hindmarsh-Rose bursting neurons coupled diffusively through a network decouple, after linearization, into one cubic characteristic equation per Laplacian eigenvalue. Routh-Hurwitz conditions on these modes give the network-induced Turing instability, and a delay in the slow feedback adds Hopf bifurcations.
