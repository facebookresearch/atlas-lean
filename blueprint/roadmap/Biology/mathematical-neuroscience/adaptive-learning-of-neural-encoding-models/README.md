# Adaptive learning of neural encoding models

Closed-loop neurotechnologies track drifting relations between neural activity and brain state with adaptive Bayesian filters whose parameter random-walk variance acts as a learning rate. For linear-Gaussian encoding models the steady-state error and convergence speed are explicit functions of that rate, which makes calibration analytic.
