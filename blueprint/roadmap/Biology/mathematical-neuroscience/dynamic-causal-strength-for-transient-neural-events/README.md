# Dynamic causal strength for transient neural events

To quantify directed influence between brain regions around transient events (such as hippocampal sharp-wave ripples), peri-event trials are modelled by a time-inhomogeneous linear structural vector autoregression. Transfer entropy and the interventional causal strength of the arrow from cause to effect are both blind to deterministic, trial-locked components of the cause; a relative causal strength that also replaces the cause by a baseline reference state recovers them.
