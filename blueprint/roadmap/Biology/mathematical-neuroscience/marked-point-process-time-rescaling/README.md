# Marked point process time-rescaling

Population spiking data can be modelled as a marked point process, each spike carrying a mark such as waveform features or neuron identity, with a joint mark intensity. Rescaling each spike time by the integrated intensity at its own mark turns a correctly specified model into a unit-rate marked Poisson process on a random region, which reduces goodness-of-fit for population models to testing uniformity.
