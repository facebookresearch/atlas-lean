# Neural fields with exponential temporal kernel

Amari-type neural field with leakage, finite axonal transmission speed and an exponential (finite-memory) synaptic impulse response. The kernel's factor $\lambda/(\alpha+\lambda)$ in the dispersion relation removes every static instability of the uniform state, so all pattern-forming bifurcations are oscillatory (Hopf or Turing–Hopf), with explicit stability and frequency bounds.
