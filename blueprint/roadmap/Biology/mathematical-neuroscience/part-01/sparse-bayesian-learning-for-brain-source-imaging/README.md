# Sparse Bayesian learning for brain source imaging

EEG and MEG source imaging inverts a linear lead-field model from sensor recordings to cortical source activity. Sparse Bayesian learning (the Champagne family) places independent zero-mean Gaussian priors with learned variances on the sources and fits the variances by minimizing the negative log marginal likelihood; its classical update rules are all majorization–minimization algorithms for that cost.
