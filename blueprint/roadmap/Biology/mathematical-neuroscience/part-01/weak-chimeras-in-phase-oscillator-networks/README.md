# Weak chimeras in phase oscillator networks

A weak chimera is a dynamically invariant set of a symmetric oscillator network on which some, but not all, symmetry-related oscillators share the same asymptotic average frequency. Phrasing this through the isotropy subgroup of the angular frequency vector extends the notion beyond phase oscillators and shows that frequency synchrony is implied by, but does not require, symmetries of the solution.
