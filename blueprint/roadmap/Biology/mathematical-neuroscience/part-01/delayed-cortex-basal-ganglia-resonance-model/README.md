# Delayed cortex-basal ganglia resonance model

A four-population firing-rate model (STN, GPe, excitatory and inhibitory cortex) with synaptic transmission delays, in which the onset of pathological beta oscillations in Parkinson's disease is a Hopf bifurcation in the delay. The characteristic function factors into an STN-GPe loop and a cortical loop, which gives explicit critical delays.
