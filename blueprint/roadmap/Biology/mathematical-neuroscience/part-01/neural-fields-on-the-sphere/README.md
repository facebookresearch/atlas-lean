# Neural fields on the sphere

Neural field models describe coarse-grained cortical activity by integro-differential equations with space-dependent transmission delays. Taking the sphere as the domain, following Nunez's view of each cortical hemisphere and its white-matter connections, makes the problem rotationally symmetric. Isotropic kernels then diagonalize in spherical harmonics, and linear stability of the homogeneous state reduces to one scalar characteristic equation per harmonic degree, the starting point for standing and travelling waves on the sphere.
