# Winner-take-all in adaptive phase oscillator networks

A central phase oscillator with frequency adaptation coupled to peripheral oscillators whose connection strengths grow resonantly when they are in phase with it. Desynchronizing feedback ($b < 0$) makes exactly one peripheral oscillator win the competition for synchronization, a model of attention selection.
