# Granger causality of latent cortical sources

Directional functional connectivity between cortical sources that are observed only through low-dimensional, noisy sensor measurements such as MEG. The sources follow a sparse vector autoregressive model inside a linear state-space model, parameters are fit by regularized expectation–maximization, and Granger-causal links are tested with de-biased likelihood-ratio statistics.
