# Active inference on discrete state-spaces

Active inference models perception, learning and decision-making of an agent with a partially observed Markov decision process (POMDP) generative model. Beliefs about hidden states and parameters minimize a variational free energy; beliefs about policies are a softmax of the negative expected free energy, which splits into risk (divergence of predicted from preferred states) and ambiguity (expected uncertainty of observations given states).
