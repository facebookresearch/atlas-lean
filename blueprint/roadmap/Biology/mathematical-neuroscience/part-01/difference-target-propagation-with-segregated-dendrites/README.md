# Difference target propagation with segregated dendrites

Deep credit assignment without weight transport can be implemented by pyramidal-like neurons whose apical dendrites, electrotonically segregated from the soma, integrate top-down feedback into plateau potentials. The difference between plateaus in a target phase and a forward phase defines local hidden-layer targets, in the manner of difference target propagation, and reducing the local hidden-layer loss provably reduces the output loss under a Jacobian condition.
