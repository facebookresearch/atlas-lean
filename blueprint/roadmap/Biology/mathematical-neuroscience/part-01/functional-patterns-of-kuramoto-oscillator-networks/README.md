# Functional patterns of Kuramoto oscillator networks

A functional pattern of a network of phase oscillators is the matrix of time-averaged cosines of pairwise phase differences; at a phase-locked state it is fixed by $n-1$ phase differences. Whether a prescribed pattern can be produced by tuning the coupling weights is a linear feasibility problem in the weights, governed by the signed incidence matrix and the natural frequencies; the set of patterns that coexist for fixed weights is governed by the cycle space of the network.
