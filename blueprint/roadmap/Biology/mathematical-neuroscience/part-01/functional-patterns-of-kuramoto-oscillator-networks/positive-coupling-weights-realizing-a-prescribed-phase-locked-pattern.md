# Positive coupling weights realizing a prescribed phase-locked pattern

**Setting.** Consider the Kuramoto network on a connected undirected graph $G = (\mathcal O, \mathcal E)$ with $n$ oscillators,

$$\dot\theta_i = \omega_i + \sum_{j} A_{ij}\sin(\theta_j - \theta_i), \qquad A_{ij} = A_{ji},$$

and the functional pattern $R_{ij} = \langle \cos(\theta_j(t) - \theta_i(t))\rangle_t$. On a phase-locked trajectory all oscillators rotate at $\omega_{\mathrm{mean}} = \frac1n\sum_i\omega_i$, the differences $x_{ij} = \theta_j - \theta_i$ are constant and $R_{ij} = \cos x_{ij}$. Let $B \in \mathbb R^{n \times |\mathcal E|}$ be an oriented incidence matrix (for edge $e = (i,j)$, $B_{ie} = -1$, $B_{je} = +1$ and $x_e = \theta_j - \theta_i$), $\delta \in \mathbb R^{|\mathcal E|}$ the edge weights, $D(x) = \mathrm{diag}(\sin x_e)$ and $\tilde\omega = \omega - \omega_{\mathrm{mean}}\mathbf 1$ (zero mean). With orientations chosen consistently, the phase-locked equilibrium condition is the linear equation in $\delta$

$$B\,D(x)\,\delta = \tilde\omega .$$

Write $\bar B = B\,\mathrm{sign}(D(x))$ and $B_{:,e}$ for the column of edge $e$; the arcs of the graph with incidence matrix $\bar B$ point from the $-1$ entry of their column to the $+1$ entry.

**Proposition (sign invariance).** A nonnegative solution $\delta \ge 0$ exists if and only if $\tilde\omega$ lies in the convex cone generated by the columns of $\bar B$. Feasibility therefore depends on $x$ only through the signs of $\sin x_e$: if pattern $x$ is attainable with nonnegative weights, so is every $x'$ with $\mathrm{sign}\,D(x') = \mathrm{sign}\,D(x)$.

**Theorem (sufficient conditions).**

1. If there is a set $S$ of edges with (a) $D_{ee}(x)D_{e'e'}(x)\,B_{:,e}^{\top}B_{:,e'} \le 0$ for all distinct $e, e' \in S$ with nonzero sines, (b) $\tilde\omega^{\top}B_{:,e}D_{ee}(x) > 0$ for all $e \in S$, and (c) $\tilde\omega \in \mathrm{Im}(B_{:,S})$, then $\delta_S = (B_{:,S}D_{S,S}(x))^{\dagger}\tilde\omega \ge 0$, $\delta_{\mathcal E\setminus S} = 0$ solves the equation.
2. If the graph with incidence matrix $\bar B$ contains a directed Hamiltonian path $H$ and $\tilde\omega^{\top}B_{:,e}D_{ee}(x) > 0$ for all $e \in H$, then there is a strictly positive solution $\delta > 0$. After relabeling so that each arc of $H$ goes from $i$ to $j$ with $i < j$, the condition reads $\omega_i < \omega_j$ along the path: natural frequencies increasing along a Hamiltonian path of the signed graph guarantee realizability with all weights positive.

**Optimal correction.** Given current weights $\delta$ and a target pattern $x$, the minimal weight change is the convex quadratic program

$$\min_{\alpha}\ \|\alpha\|_2^2 \quad \text{s.t.}\quad B D(x)(\delta + \alpha) = \tilde\omega,\ \ \delta + \alpha \ge 0 .$$

## Expansion

Factor $D(x) = \mathrm{sign}(D(x))\,|D(x)|$ and substitute $\bar\delta = |D(x)|\delta$, which is nonnegative exactly when $\delta$ is; this gives the cone criterion. Under (a), with the columns of $B_{:,S}D_{S,S}$ linearly independent (otherwise pass to an independent subset), the Gram matrix $M = D_{S,S}B_{:,S}^{\top}B_{:,S}D_{S,S}$ has nonpositive off-diagonal entries and is positive definite, hence a nonsingular M-matrix with entrywise nonnegative inverse; (c) makes the least-squares solution exact and (b) makes $D_{S,S}B_{:,S}^{\top}\tilde\omega$ positive, so $\delta_S = M^{-1}D_{S,S}B_{:,S}^{\top}\tilde\omega \ge 0$. A Hamiltonian path has $n-1$ independent columns spanning $\mathbf 1^{\perp} \ni \tilde\omega$, and distinct path arcs have column inner products in $\{0, -1\}$, so the first statement applies with $S = H$ and gives $\delta_H > 0$; adding a small positive weight vector off the path and re-solving for $\delta_H$ keeps it positive.
