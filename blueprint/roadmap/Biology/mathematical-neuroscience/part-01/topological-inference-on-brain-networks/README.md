# Topological inference on brain networks

Weighted brain connectivity networks can be compared without choosing a single edge threshold by tracking Betti numbers across all thresholds (a graph filtration). Because these curves are monotone step functions, a Kolmogorov–Smirnov-type distance between them has an exactly computable null distribution, avoiding permutation resampling; applied to monozygotic versus dizygotic twin correlation networks it tests heritability of network topology.
