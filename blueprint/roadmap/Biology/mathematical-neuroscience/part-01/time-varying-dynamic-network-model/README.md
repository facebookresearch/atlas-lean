# Time-varying dynamic network model

A linear dynamical model of regional brain activity, $X'(t) = A(t) X(t)$, in which the coupling matrix keeps fixed eigenvectors (stationary spatial modes, read as resting-state networks) while its eigenvalues are piecewise constant in time (brain-state switches). It extends dynamic mode decomposition and the network diffusion model, and supports kernel estimation of the modes and change-point detection of the switches from fMRI or MEG signals.
