# Excitable network attractors in recurrent neural networks

Continuous-time recurrent neural networks can be wired so that each vertex of a prescribed directed graph is a stable equilibrium with one active cell, and each edge is an excitable connection triggered by a small perturbation. This gives a constructive model of finite-state computation and of intermittent, state-switching neural dynamics.
