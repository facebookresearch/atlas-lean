# Bayesian ring attractor networks

Ring attractor networks encode a circular variable such as head direction in the position of an activity bump. If the bump's amplitude is also allowed to vary, it can encode the certainty of the estimate, and suitable recurrent and inhibitory parameters make the network implement approximate Bayesian filtering of the circular variable (a circular Kalman filter).
