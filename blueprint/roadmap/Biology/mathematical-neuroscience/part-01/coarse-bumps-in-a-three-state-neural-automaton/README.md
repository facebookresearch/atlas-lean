# Coarse bumps in a three-state neural automaton

A spatially extended network of neurons cycling through quiescent, spiking and refractory states, coupled by a Mexican-hat kernel, supports localized bumps of activity. Averaging over the fine microstructure gives a neural-field-like threshold equation for the bump width and an explicit coarse stability criterion.
