# Representational models of neural activity

A representational model describes how a population of measurement channels (neurons or voxels) responds across experimental conditions through the distribution of activity profiles, summarized by the second-moment matrix of the condition-by-channel activity patterns. Encoding analysis, representational similarity analysis and pattern-component modelling all test hypotheses about this matrix.
