# Transfer entropy connectivity inference

Directed functional connectivity between neurons can be inferred model-free from activity recordings by asking how much the past of one signal improves prediction of the next value of another. Transfer entropy quantifies this as a conditional Kullback–Leibler divergence; for slow calcium imaging it must be generalized to include same-bin interactions and to condition on the network's dynamical state.
