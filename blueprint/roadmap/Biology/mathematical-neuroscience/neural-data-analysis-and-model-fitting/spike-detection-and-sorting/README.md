# Spike detection and sorting

Extracellular recordings mix the action potentials of several nearby neurons with background noise. Spike sorting detects events with a threshold set from a robust estimate of the noise level, represents each waveform by a few informative features, clusters the features, and assigns the clusters to putative single neurons. Superparamagnetic clustering provides a whole path of partitions indexed by a temperature, from which clusters are selected by size-increment, overlap and regime-border rules.
