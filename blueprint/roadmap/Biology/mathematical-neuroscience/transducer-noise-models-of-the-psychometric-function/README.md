# Transducer-noise models of the psychometric function

Two-alternative forced-choice (2AFC) discrimination modeled by a transducer applied to each stimulus followed by additive internal noise. The psychometric function is the composition of the noise distribution with transducer differences, which yields threshold-normalized forms and limiting behavior for fine thresholds and compressive transducers.
