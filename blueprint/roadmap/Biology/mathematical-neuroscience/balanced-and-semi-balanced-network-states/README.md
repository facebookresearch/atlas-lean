# Balanced and semi-balanced network states

In large recurrent networks of excitatory and inhibitory populations with strong coupling, the total synaptic input to each population stays of order one only if excitation and inhibition cancel. The classical balanced state then predicts population rates that are linear in the stimulus, but every network obeying Dale's law admits positive stimuli for which these predicted rates are negative. Allowing excess inhibition while forbidding excess excitation yields the semi-balanced state, a complementarity problem whose solutions are piecewise linear (ReLU-network-like) functions of the stimulus.
