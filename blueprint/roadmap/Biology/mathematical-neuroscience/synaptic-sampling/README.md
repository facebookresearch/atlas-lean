# Synaptic sampling

Synaptic sampling treats network plasticity as Bayesian inference over synaptic parameters: instead of converging to a single maximum-likelihood weight vector, stochastic plasticity rules make the parameters diffuse so that, in the long run, they are distributed according to a (tempered) posterior that combines a structural prior with the likelihood of the network's inputs.
