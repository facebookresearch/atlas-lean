# Concentration of measure and neuronal selectivity

In high dimension, random stimuli are nearly orthogonal and a single threshold neuron can respond to one stimulus while ignoring exponentially many others. Spherical-cap volume bounds make this quantitative: memory capacity of a single neuron with prescribed reliability grows exponentially with the number of synaptic inputs.
