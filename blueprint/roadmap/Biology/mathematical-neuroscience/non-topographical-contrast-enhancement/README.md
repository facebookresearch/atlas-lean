# Non-topographical contrast enhancement

Contrast enhancement in the olfactory bulb input layer that sharpens odor representations along the axis of ligand–receptor affinity rather than along physical distance between glomeruli. Within a glomerulus, intraglomerular inhibition subtracts a broader, weaker sigmoid from the excitatory one.
