# Goodness-of-fit for spike-train point processes

Testing whether repeated spike trains follow a Poisson or Hawkes model when the intensity must itself be estimated. The time-rescaling theorem turns any point process into a unit-rate Poisson process; cumulating rescaled trials and estimating the intensity on a disjoint subsample restores the exact Kolmogorov–Smirnov limit that naive plug-in destroys, and adaptive kernel estimators supply intensities with oracle guarantees.
