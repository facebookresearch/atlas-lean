# Generalized thinning-and-shift spike trains

The generalized thinning-and-shift (GTaS) construction produces a vector of marginally Poisson spike trains with prescribed spatio-temporal correlations: events of a single Poisson mother process are copied to random subsets of neurons and jittered by subset-dependent shift distributions. Its cross-cumulant densities of every order have closed forms in the model parameters, which makes it a tractable test bed for how higher-order correlations shape network responses.
