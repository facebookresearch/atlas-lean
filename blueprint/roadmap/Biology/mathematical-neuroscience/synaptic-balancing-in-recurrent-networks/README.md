# Synaptic balancing in recurrent networks

Recurrent networks with homogeneous activation functions have a continuous symmetry that rescales each neuron's inputs and outputs reciprocally without changing the computed input-output map. A local plasticity rule that balances incoming and outgoing synaptic costs moves along this symmetry and provably increases robustness to noise.
