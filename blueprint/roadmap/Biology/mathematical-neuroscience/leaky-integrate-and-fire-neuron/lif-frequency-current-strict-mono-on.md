# The firing frequency increases with superthreshold current

Let `τ > 0`, `u_r < θ`, `t_ref ≥ 0`, `u_rest` real and `R > 0`. With the steady value
`u_∞ = u_rest + R I` affine in the current `I`, the firing frequency
`I ↦ 1/(T(u_rest + R I) + t_ref)`, where `T` is the [period](lif-period.md), is strictly increasing
on the superthreshold currents, those with `u_rest + R I > θ`.
