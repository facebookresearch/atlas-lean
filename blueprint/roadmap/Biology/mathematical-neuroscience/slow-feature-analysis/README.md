# Slow feature analysis

An unsupervised learning principle that extracts instantaneous functions of a time-varying input whose outputs vary as slowly as possible, subject to unit variance and decorrelation. For an animal moving through a fixed environment the optimal slow functions can be computed analytically as eigenfunctions of a weighted Laplace-type operator on configuration space, predicting place-cell-like and head-direction-like codes.
