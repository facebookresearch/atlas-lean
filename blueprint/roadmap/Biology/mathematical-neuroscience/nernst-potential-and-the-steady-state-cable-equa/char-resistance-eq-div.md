# Characteristic resistance as membrane resistance over length constant

For real numbers `r_m > 0` and `r_i > 0`, the [characteristic resistance](../../../Analysis/ordinary-differential-equations/linear-systems-and-fundamental-matrices/char-resistance.md) `r∞ = √(r_m r_i)` and the [length constant](../../../Analysis/ordinary-differential-equations/linear-systems-and-fundamental-matrices/length-constant.md)
`λ = √(r_m / r_i)` satisfy

`r∞ = r_m / λ`.

Since `λ² = r_m / r_i`, this is the same value as `r∞ = r_i λ`.
