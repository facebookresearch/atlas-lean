# Equal concentrations give zero Nernst potential

For all real `R`, `T`, `z`, `F` and `c`, the [Nernst potential](nernst-potential.md) with equal
inside and outside concentrations `c` is `0`: `(R T / (z F)) log (c / c) = 0`. This holds for every
real `c`: for `c ≠ 0` because `log 1 = 0`, and for `c = 0` because `0 / 0 = 0` and `log 0 = 0`.
