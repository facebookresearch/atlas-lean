# Capillary transit time heterogeneity

Oxygen extraction from a single capillary is a concave, saturating function of the time red cells spend in it. Across a capillary bed with heterogeneous transit times, concavity makes heterogeneity costly: at a fixed mean transit time it lowers the maximal oxygen extraction fraction, and at high heterogeneity it can make the maximal oxygen metabolism fall as blood flow rises.
