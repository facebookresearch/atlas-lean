# Reinforcement-learning models of choice

Computational models of choice in which values of actions are learned from rewards. Model-free learners cache action values updated by reward prediction errors; model-based learners compute values by planning with a learned transition model. Hybrid models mix the two with a weight that indexes the degree of goal-directed control and is estimated from behavior in sequential decision tasks.
