# Wilson networks for binocular rivalry

Rate models of rivalry in which nodes stand for attribute levels, learned patterns are encoded by excitatory connections, and nodes coding competing levels of one attribute inhibit each other. Symmetry of the network organizes the possible time-periodic states through equivariant Hopf bifurcation, and lateral coupling allows stable rivalry between derived patterns that were never presented.
