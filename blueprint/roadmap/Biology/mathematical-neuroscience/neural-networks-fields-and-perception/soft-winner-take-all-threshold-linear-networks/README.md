# Soft winner-take-all threshold-linear networks

Recurrent networks of linear threshold neurons in which excitatory units amplify themselves and compete through shared inhibition. With asymmetric (excitatory–inhibitory) connectivity there is no energy function; contraction analysis instead classifies each set of active units as permitted (contracting) or forbidden (expanding), and computation is the forced passage through forbidden sets until a permitted one is reached.
