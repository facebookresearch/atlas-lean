# Permitted and forbidden subspaces of a soft winner-take-all network

**Network.** Let $x_1, \dots, x_{N-1} \ge 0$ be excitatory and $x_N \ge 0$ inhibitory linear threshold units, $f(u) = \max(u, 0)$, with self-excitation $\alpha_1$, nearest-neighbour excitation $\alpha_2$, inhibitory feedback $\beta_1$, excitatory drive of the inhibitory unit $\beta_2$, leak $G_i > 0$, time constant $\tau > 0$ and inputs $I_i(t)$:

$$\tau\dot x_i + G_i x_i = f\big(I_i + \alpha_1 x_i + \alpha_2(x_{i-1} + x_{i+1}) - \beta_1 x_N\big), \qquad \tau\dot x_N + G_N x_N = f\Big(\beta_2 \sum_{j<N} x_j\Big),$$

i.e. $\tau\dot x = f(Wx + I) - Gx$ with an asymmetric weight matrix $W$. At a state where the units with indicators $\sigma_i \in \{0,1\}$ are above threshold, the effective (functional) Jacobian is $J = \Sigma W - G$ with $\Sigma = \operatorname{diag}(\sigma_i)$. An active set, with projection $V$ onto the directions in which it cannot be a steady state, is **forbidden** if it is expanding, $\Theta V J V^{\top}\Theta^{-1} > 0$ in some metric $\Theta$, and **permitted** if its effective Jacobian is contracting, $\Theta J \Theta^{-1} < 0$.

**Theorem.**
1. (Contraction) If there is a uniformly positive definite metric $\Theta^{*\top}\Theta$ such that the Hermitian part of $(\dot\Theta + \Theta\,\partial f/\partial x)\Theta^{-1}$ is uniformly negative definite, all trajectories of $\dot x = f(x,t)$ converge exponentially to a single trajectory, at rate $|\sup\lambda_{\max}|$. If instead the minimal eigenvalue of the symmetric part of the generalized Jacobian is positive, neighbouring trajectories diverge exponentially.
2. (Gain) With $\alpha_2 = 0$, unit leak, and a single winner $i$ under constant input $I_i > 0$, the steady state is $x_i = g I_i$ with gain $g = 1/(1 - \alpha_1 + \beta_1\beta_2)$, which can be much larger than $1$.
3. (Mixed eigenvectors) In a forbidden subspace the eigenvector of the maximal (positive) eigenvalue of the effective Jacobian is mixed (it has entries of both signs), so the trajectory drives some active unit below threshold in finite time and the active set changes.
4. (Orderly computation; qualitative conclusion of the source) Assume the source's standing parameter conditions (its Eq. (18)), $1 < \alpha_1 < 2\sqrt{\beta_1\beta_2}$ and $\tfrac14 < \beta_1\beta_2 < 1$, under which every active set is permitted or forbidden. When every forbidden subspace is both expanding and has negative divergence $\operatorname{tr}(J) < 0$, volumes in the active subspace shrink exponentially, the dynamics fall onto successively lower-dimensional sets, and from any input the network passes through a finite sequence of forbidden subspaces and settles in a permitted one, where it amplifies the selected input.

## Expansion

Part 1 is the contraction theorem: the squared length of a virtual displacement $\delta z = \Theta\,\delta x$ obeys $\tfrac{d}{dt}\|\delta z\|^2 = 2\,\delta z^{*\top} F_H\,\delta z$, so a uniform sign of the Hermitian part $F_H$ forces uniform exponential shrinking or growth of every displacement. Part 2 is the fixed-point equation $x_i = I_i + \alpha_1 x_i - \beta_1 x_N$ with $x_N = \beta_2 x_i$. For part 3, if the leading eigenvector $v$ of an expanding active set had all entries non-negative, the state started along $v$ would grow without bound while keeping all units active, so the set would never be left; this contradicts the requirement that $Vx$ cannot stay constant on a forbidden set. Negative divergence is not implied by expansion (the identity matrix expands with positive trace), which is why it is required separately: asymmetric connections create rotation, and fast enough rotation can stabilize an expanding direction, e.g. the matrix $\begin{pmatrix} 1 & a \\ -a & -2 \end{pmatrix}$ has trace $-1$ and is stable exactly when $a^2 > 2$. The result is a network that is globally stable (bounded) yet locally unstable on every non-solution configuration, with high gain permitted in the solution.
