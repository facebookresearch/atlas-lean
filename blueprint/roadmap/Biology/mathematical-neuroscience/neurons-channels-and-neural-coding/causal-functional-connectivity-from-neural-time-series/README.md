# Causal functional connectivity from neural time series

Directed graphical models of recorded neural activity: the unrolled causal graph links neuron–time pairs, and rolling it up over a bounded interaction delay gives a neuron-level causal functional connectome (CFC). For structural-equation dynamics the rolled graph is exactly the set of causal inputs, which justifies estimating it with constraint-based (PC-type) algorithms and answering ablation and stimulation queries by graph surgery.
