# Synchronization of GnRH neuron calcium dynamics

GnRH neurons show asynchronous calcium oscillations punctuated, roughly hourly, by network-wide synchronized calcium peaks associated with hormone pulses. A mesoscopic model couples FitzHugh–Nagumo-type neurons with slow calcium through a single slowly growing synchronization variable that is reset by collective calcium activity; the slow variable sets the interval between synchronization episodes.
