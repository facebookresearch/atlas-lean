# Stochastic FitzHugh–Nagumo neuron

The FitzHugh–Nagumo neuron with channel noise in the recovery variable, studied in the excitable regime (a unique stable focus, no limit cycle). Near the rest state the dynamics linearize to a damped stochastic oscillator whose radial part, with a firing threshold and reset, is a leaky integrate-and-fire model.
