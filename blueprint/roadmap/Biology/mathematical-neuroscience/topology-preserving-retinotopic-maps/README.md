# Topology-preserving retinotopic maps

Retinotopic maps from visual space to visual cortex are, at the scale of an area such as V1, orientation-preserving homeomorphisms, but maps estimated from noisy fMRI violate this near the fovea. Quasiconformal geometry gives a pointwise criterion for topology preservation that can be imposed as a constraint when smoothing measured maps.
