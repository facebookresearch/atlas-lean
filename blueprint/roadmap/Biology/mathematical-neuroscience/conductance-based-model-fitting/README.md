# Conductance-based model fitting

Constraining the maximal conductances of a multi-compartment, conductance-based neuron model by electrophysiological recordings is an inverse problem with many objectives: different features of the voltage response (firing rate, adaptation, spike shape) trade off against one another, and the recordings themselves vary across repetitions. Feature-based error functions measured in units of experimental variability, combined with Pareto-based multiple objective optimization, turn this into the search for a front of optimal trade-offs rather than a single best fit.
