# Predictive coding and backpropagation

Supervised learning in a feedforward network by predictive coding: beliefs about each layer relax to reduce summed squared prediction errors under a hierarchical Gaussian model, and parameters are updated from the relaxed errors. Under the fixed prediction assumption the relaxed errors are exactly the backpropagated gradients, both at the fixed point and after a finite number of unit-step iterations.
