# Curvature of the sealed steady profile

For all real `ℓ`, `L` and `x`, the slope `W'(y) = -sinh ((L - y) / ℓ) / ℓ` of the
[steady profile](sealed-steady.md) is differentiable at `x`, with derivative

`W''(x) = cosh ((L - x) / ℓ) / ℓ²`.

With the convention `u / 0 = 0`, both sides are `0` when `ℓ = 0`.
