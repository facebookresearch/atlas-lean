# Second derivative of a sealed-end mode

For every real `L`, natural number `n` and real `x`, the [mode](cos-mode.md)
`φ_n(x) = cos (n π x / L)` satisfies

`φ_n''(x) = -(n π / L)² φ_n(x)`:

it is an eigenfunction of the second derivative with eigenvalue `-(n π / L)²`. The mode is twice
differentiable, so `φ_n''` is its classical second derivative. At `L = 0` the eigenvalue is `0`,
by the convention `u / 0 = 0`.
