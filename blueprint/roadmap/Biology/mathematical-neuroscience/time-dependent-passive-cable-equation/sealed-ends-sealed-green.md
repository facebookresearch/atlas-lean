# The sealed-cable Green's function has sealed ends for t > 0

For real numbers `τ > 0`, `ℓ ≠ 0` and `L ≠ 0` and every real source position `x₀`, the
[Green's function of the sealed cable](sealed-green.md) `G(t, x; x₀)` has [sealed ends](sealed-ends.md) at every time `t > 0`:
`∂ₓG(t, 0; x₀) = ∂ₓG(t, L; x₀) = 0`.
