# Derivative function of a sealed-end mode

For every real `L` and natural number `n`, the derivative of the [mode](cos-mode.md)
`x ↦ cos (n π x / L)` is the function

`x ↦ -(n π / L) sin (n π x / L)`,

the mode being differentiable at every point. At `L = 0` both are `0`, by the convention
`u / 0 = 0`.
