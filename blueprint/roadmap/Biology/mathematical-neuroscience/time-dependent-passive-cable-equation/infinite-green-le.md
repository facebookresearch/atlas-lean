# For t > 0, the infinite-cable kernel is largest at the input site

For real `τ > 0`, every real `ℓ`, every real source position `x₀`, every time `t > 0` and every
real position `x`, the [Green's function of the infinite cable](infinite-green.md) satisfies

`G(t, x; x₀) ≤ G(t, x₀; x₀)`:

at every positive time the response is largest at the input site. For `ℓ = 0` both sides are `0`.
