# For L ≠ 0, orthogonality relations of the sealed-end modes

For every real `L ≠ 0` and natural numbers `m` and `n`, the [modes](cos-mode.md) satisfy

`∫₀ᴸ cos (m π x / L) cos (n π x / L) dx = 0` if `m ≠ n`, `L / 2` if `m = n ≥ 1`, and `L` if
`m = n = 0`.

The integral is oriented: for `L < 0` it is minus the integral over `[L, 0]`, and the values `L`
and `L / 2` are then negative. For `L > 0` the modes are orthogonal on `[0, L]`, with squared norms
`L` for the uniform mode and `L / 2` for the others.
