# Sealed-end cosine mode of a cable

For a real number `L`, a natural number `n` and a real number `x`, the `n`-th sealed-end mode of a
cable of length `L` is

`φ_n(x) = cos ((n π / L) x)`, written `cos (n π x / L)`.

It is defined for every real `L` and `x`. With the convention `u / 0 = 0`, the frequency `n π / L`
is `0` when `L = 0`, so every mode is then the constant `1`. In the model `L > 0` is the length of
the cable `[0, L]`, and the modes have zero slope at both ends
([at 0](deriv-cos-mode-zero.md), [at L](deriv-cos-mode-length.md)).
