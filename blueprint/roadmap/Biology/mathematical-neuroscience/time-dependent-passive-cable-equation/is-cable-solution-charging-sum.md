# For τ ≠ 0 and ℓ ≠ 0, the charging transient solves the cable equation

For real numbers `τ ≠ 0` and `ℓ ≠ 0`, all real `L` and `c`, every finite set `s` of natural
numbers and all real coefficients `a_n`, the [charging transient](charging-sum.md)
`V(t, x) = c cosh ((L - x) / ℓ) + ∑_{n ∈ s} a_n e^(-k_n t) cos (n π x / L)` is a
[classical solution](is-cable-solution.md) of `τ ∂ₜV = ℓ² ∂ₓ²V - V` on `[0, L]` at every time
`t ∈ ℝ`.
