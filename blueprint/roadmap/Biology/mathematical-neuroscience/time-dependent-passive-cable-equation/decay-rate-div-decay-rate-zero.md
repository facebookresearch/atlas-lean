# For τ ≠ 0, Rall's ratio of mode rates

For real `τ ≠ 0`, all real `ℓ` and `L` and every natural number `n`, the [rates](decay-rate.md)
satisfy

`k_n / k_0 = 1 + (n π ℓ / L)²`.

With the convention `u / 0 = 0` the right-hand side is `1` when `L = 0`. For `τ > 0` the ratio
`k_n / k_0` is the ratio `τ_0 / τ_n` of Rall's equalizing time constants.
