# For L ≠ 0, the transient is sealed at L with a fixed slope at 0

For real `L ≠ 0`, all real `τ`, `ℓ`, `c` and `t`, every finite set `s` of natural numbers and all
real coefficients `a_n`, the [charging transient](charging-sum.md) `V(t, ·)` satisfies

`∂ₓV(t, L) = 0` and `∂ₓV(t, 0) = -c sinh (L / ℓ) / ℓ`:

the far end is sealed, and the axial gradient at `x = 0`, hence the injected current, does not
depend on `t`. With the convention `u / 0 = 0`, the slope at `x = 0` is `0` when `ℓ = 0`.
