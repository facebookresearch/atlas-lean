# Information processing capacity of dynamical systems

A measure of how well linear readouts of an input-driven dynamical system (a recurrent neural network, a reservoir, a physical system) can reconstruct functions of the input history. Summed over an orthogonal family of target functions, the capacity is bounded by the number of observed state variables, with equality for fading-memory systems.
