# Attention-weighted sequential sampling models

Sequential sampling models of binary choice in which noisy evidence accumulates to a threshold and visual fixations modulate the rate at which each option's value is integrated: the attentional drift diffusion model tracks the fixation sequence, while the gaze-weighted linear accumulator uses trial-level gaze proportions and admits closed-form first-passage likelihoods.
