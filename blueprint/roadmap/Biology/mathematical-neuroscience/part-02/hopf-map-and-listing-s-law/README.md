# Hopf map and Listing's law

Eye orientations are unit quaternions acting on the gaze direction by conjugation, and the map sending an orientation to its gaze direction is the Hopf fibration $S^3 \to S^2$. Listing's law restricts orientations reached from the primary position to rotations about axes in a fixed plane; these form a great 2-sphere in $S^3$ on which the Hopf map becomes a branched double covering, so each gaze direction except the backward one is reached by exactly one Listing orientation.
