# Turing completeness of STDP networks

Recurrent networks of Boolean neurons whose synaptic weights take finitely many rational values and change by spike-timing-dependent plasticity (STDP) can store unbounded information in the synapses themselves. Encoding a counter machine's state and counter values in synaptic strengths, and implementing increments, decrements and zero tests by STDP potentiation and depression, gives real-time simulation of any counter machine and hence Turing completeness.
