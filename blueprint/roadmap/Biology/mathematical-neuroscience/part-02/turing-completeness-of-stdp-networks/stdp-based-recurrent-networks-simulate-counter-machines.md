# STDP-based recurrent networks simulate counter machines

**Setting.** A *$k$-counter machine* $C_k = (Q, \Sigma, \delta, q_0, F)$ is deterministic, with finitely many control states $Q$, initial state $q_0 \in Q$, final states $F \subseteq Q$, input alphabet $\Sigma$ and $k$ counters holding non-negative integers, and a partial transition function $\delta : Q \times (\Sigma \cup \{\epsilon\}) \times \{\text{zero}, \text{nonzero}\}^k \to Q \times \{\text{push}, \text{pop}, -\}^k$ that never offers both a regular and an $\epsilon$-transition in the same situation (state and zero-tests). Push maps a counter value $c$ to $c+1$, pop maps it to $\max(c-1, 0)$, and $-$ leaves it unchanged. On input $w$ the machine takes an $\epsilon$-transition whenever one is defined, and otherwise reads the next input symbol; it accepts $w$ if its computation is finite, consumes all of $w$ and stops in a state of $F$. The $\epsilon$-transitions matter: as the source notes, "the class of k-counter machines that do not make use of ϵ-transitions is not Turing complete". An *STDP-based recurrent neural network* is a discrete-time rational-weighted recurrent network in which some synapses are plastic and follow one of two spike-timing-dependent plasticity rules. Writing $\Delta_{ij}(t) = x_i(t+1)x_j(t) - x_i(t)x_j(t+1)$ for presynaptic neuron $j$ and postsynaptic neuron $i$ (with $\Delta_{ij} = 1$ when $j$ spikes one step before $i$, and $-1$ for the reverse order):

- *Rule 1 (bounded Hebbian):* $a_{ij}(t+1) = a_{ij}(t) + \eta\,\Delta_{ij}(t)$, clipped to $[a_{\min}, a_{\max}] \subset (0,1]$, so the weight ranges over finitely many values;
- *Rule 2 (geometric):* $a_{ij}(t+1) = a_{ij}(t) + \tfrac12(1 - a_{ij}(t))$ if $\Delta_{ij}(t) = 1$, $a_{ij}(t+1) = \max\big(a_{ij}(t) - (1 - a_{ij}(t)), 0\big)$ if $\Delta_{ij}(t) = -1$, and unchanged otherwise, so the weight ranges over $\beta_c = 1 - 2^{-c}$, $c = 0, 1, 2, \dots$

**Theorem 1.** For every $k$-counter machine $C_k$, the network $\mathcal N$ obtained from $C_k$ by the paper's construction (Algorithm 1) simulates $C_k$ in real time: on every input $w \in \Sigma^*$, encoded as an input stream $u_w$ of Boolean vectors, the computation of $\mathcal N$ on $u_w$ reproduces the sequence of configurations (control state and counter values) of $C_k$ on $w$, each machine transition, $\epsilon$-transitions included, taking a fixed number of network steps.

**Corollary 1.** A language $L \subseteq \Sigma^*$ is recognisable by some Turing machine if and only if it is recognisable by some STDP-based recurrent neural network.

## Expansion

Under Rule 2 a potentiation maps $1 - 2^{-c}$ to $1 - 2^{-(c+1)}$ and a depression maps it to $1 - 2^{-(c-1)}$ (and $0$ to $0$), so the weight $\beta_c$ of a dedicated plastic synapse stores counter value $c$ exactly; increments and decrements are triggered by forcing the appropriate pre/post spike order, and a zero test compares the synaptic input with a threshold that only $\beta_0 = 0$ fails to reach. The finitely many control states are stored in synapses governed by Rule 1, whose transitions implement the machine's finite transition table. Conversely, a network with rational weights and these computable update rules can be simulated step by step by a Turing machine. Since every Turing machine is simulated by a 2-counter machine (Minsky), Theorem 1 with $k = 2$ gives Corollary 1. The construction places the unbounded memory needed for universal computation in synaptic strengths updated by plasticity, rather than in neuron activations.
