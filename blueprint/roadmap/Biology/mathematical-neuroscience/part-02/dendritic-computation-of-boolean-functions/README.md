# Dendritic computation of Boolean functions

Binary two-stage neuron models in which synaptic inputs are first summed within dendritic sub-units, passed through a nonlinear dendritic activation, and then summed and thresholded at the soma. With excitatory (non-negative) synapses such neurons compute exactly the positive Boolean functions, and the shape of the dendritic nonlinearity (supra-linear spiking versus sub-linear saturating) decides which normal forms can be implemented.
