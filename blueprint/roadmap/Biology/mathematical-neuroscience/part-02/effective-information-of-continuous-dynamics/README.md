# Effective information of continuous dynamics

Effective information measures how strongly a dynamics constrains its next state when the current state is set by a maximum-entropy intervention. For continuous states modeled as a deterministic map with Gaussian noise, it has a closed-form approximation in terms of the log-determinant of the Jacobian, which leads to dimension-averaged measures used to compare micro- and macro-level dynamics in causal emergence.
