# Noise correlations in population codes

How trial-to-trial correlations between neurons' responses change the stimulus information carried by a population, with tuning curves and single-neuron variances held fixed. Coding quality is measured by linear Fisher information or by the accuracy of the optimal linear estimator; both are convex in the noise covariance, which yields the sign rule near independence and pushes optima to the boundary of the set of valid correlation matrices.
