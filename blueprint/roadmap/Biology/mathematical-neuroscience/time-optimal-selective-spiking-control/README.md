# Time-optimal selective spiking control

Underactuated neurostimulation: a single input current drives several leaky integrate-and-fire neurons, and the goal is to make a chosen neuron spike as fast as possible while keeping the others below a guard voltage. Pontryagin and dynamic-programming analysis gives bang/boundary-arc or bang/off/bang optimal stimuli, explicit parameter conditions for when either neuron of a pair can be spiked selectively, and spike orders for which no time-optimal stimulus exists.
