# Theta-modulated gamma spiking

A single type I (theta-neuron or quadratic integrate-and-fire) excitatory cell driven by a slow theta-band oscillation, as a minimal model of theta–gamma cross-frequency coupling in a pyramidal–interneuron gamma network. The timing of the first gamma spike in each theta cycle is computed exactly with Mathieu functions when the cell is an intrinsic oscillator, and asymptotically by slow passage through a saddle-node on invariant circle (SNIC) bifurcation when it is excitable.
