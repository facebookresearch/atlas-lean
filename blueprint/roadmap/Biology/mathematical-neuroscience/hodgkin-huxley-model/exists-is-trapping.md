# For valid parameters every voltage lies in a trapping interval

Let the parameters be [valid](valid.md). For every real $V_0$ there are real numbers
$V_{lo} \le V_0 \le V_{hi}$ such that $[V_{lo}, V_{hi}]$ is a [trapping interval](is-trapping.md);
for example $V_{lo} = \min(E_{Na}, E_K, V_0, E_L + I/g_L - 1)$ and
$V_{hi} = \max(E_{Na}, E_K, V_0, E_L + I/g_L + 1)$.
