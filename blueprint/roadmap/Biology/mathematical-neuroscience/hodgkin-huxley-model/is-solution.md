# Solution of the Hodgkin–Huxley equations for all t ≥ 0

For a [parameter set](params.md), a path $x \colon \mathbb{R} \to \mathbb{R}^4$ is a solution on
$[0, \infty)$ if at every time $t \ge 0$ it is differentiable at $t$ with derivative $x'(t)$ equal
to the [Hodgkin–Huxley vector field](field.md) at $x(t)$. The derivative is two-sided, also at
$t = 0$; nothing else is required at negative times.
