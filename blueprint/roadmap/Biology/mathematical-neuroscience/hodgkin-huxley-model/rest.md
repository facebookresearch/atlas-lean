# The resting state (0, m∞(0), h∞(0), n∞(0))

The state $(V, m, h, n) = (0, m_\infty(0), h_\infty(0), n_\infty(0))$: zero depolarization, with
each gating variable at its steady state for $V = 0$ ([sodium activation](m-rest.md),
[sodium inactivation](h-rest.md), [potassium activation](n-rest.md)). It is an
[equilibrium of the squid equations](field-squid-rest.md), and
[the only one](field-squid-eq-zero-iff.md).
