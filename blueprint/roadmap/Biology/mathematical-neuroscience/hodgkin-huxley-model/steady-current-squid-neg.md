# The squid steady-state current is negative for V ≤ −12

For the [squid parameters](squid.md) and every $V \le -12$, the
[steady-state current](steady-current.md) satisfies $I_\infty(V) < 0$. Indeed
$V \le E_K = -12 < E_L < E_{Na} = 115$ ([leak potential](squid-el-mem.md)), so the sodium and
potassium currents are nonpositive and the leak current is negative.
