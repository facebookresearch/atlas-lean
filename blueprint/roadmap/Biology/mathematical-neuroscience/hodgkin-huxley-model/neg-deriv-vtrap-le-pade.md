# For x ≥ 0 the extension φ of x/(eˣ − 1) has −φ′(x) ≤ (1/2 + x/12)φ(x)

For every real $x \ge 0$, $-\varphi'(x) \le (1/2 + x/12)\,\varphi(x)$, where $\varphi$ is the
[extension of $x/(e^x - 1)$ by $1$ at $0$](vtrap.md), $\varphi(x) = x/(e^x - 1)$ for $x \ne 0$ and
$\varphi(0) = 1$. The proof uses the Padé-type bound $1 + x/2 + x^2/12 \le e^x (1 - x/2 + x^2/12)$
for $x \ge 0$.
