# Steady-state sodium inactivation h∞ is strictly decreasing

The [steady-state sodium inactivation](h-inf.md) $h_\infty$ is strictly decreasing on $\mathbb{R}$:
its derivative $h_\infty (1 - h_\infty)\,\lambda_h$ is negative, since $0 < h_\infty < 1$ and the
[logarithmic derivative](lam-h.md) satisfies $\lambda_h \le -1/20$.
