# Rest is the only zero of the squid steady-state current

For the [squid parameters](squid.md) and every real $V$, the
[steady-state current](steady-current.md) vanishes, $I_\infty(V) = 0$, exactly when $V = 0$: it is
[negative for $V \le -12$](steady-current-squid-neg.md),
[positive for $V \ge 115$](steady-current-squid-pos.md),
[strictly increasing for $-12 \le V \le 115$](strict-mono-on-steady-current-squid.md), and
[$I_\infty(0) = 0$](steady-current-squid-zero.md).
