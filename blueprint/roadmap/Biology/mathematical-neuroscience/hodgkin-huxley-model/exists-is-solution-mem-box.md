# Global existence in a trapping box for valid parameters

Let the parameters be [valid](valid.md), let $[V_{lo}, V_{hi}]$ be a
[trapping interval](is-trapping.md) and let $x_0$ be a state in the [box](box.md)
$[V_{lo}, V_{hi}] \times [0, 1]^3$. There is a [solution](is-solution.md) $x$ on $[0, \infty)$ with
$x(0) = x_0$ and $x(t) \in [V_{lo}, V_{hi}] \times [0, 1]^3$ for every $t \ge 0$.
