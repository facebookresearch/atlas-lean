# Global existence and boundedness for valid parameters

Let the parameters be [valid](valid.md) and let $x_0 = (V_0, m_0, h_0, n_0)$ be a state with
$m_0, h_0, n_0 \in [0, 1]$ (the [gating cube](gating-region.md)); $V_0$ is arbitrary. There is a
[solution](is-solution.md) $x$ on $[0, \infty)$ with $x(0) = x_0$, and there is a
[trapping interval](is-trapping.md) $[V_{lo}, V_{hi}]$ such that
$x(t) \in [V_{lo}, V_{hi}] \times [0, 1]^3$ for every $t \ge 0$.
