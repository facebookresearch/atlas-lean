# Steady-state potassium activation n∞

For every real $V$, $n_\infty(V) = \alpha_n(V)/(\alpha_n(V) + \beta_n(V))$, the
[steady state](steady.md) of the potassium activation kinetics with the rates
[$\alpha_n$](alpha-n.md) and [$\beta_n$](beta-n.md). Both rates are positive, so the denominator is
positive and $0 < n_\infty(V) < 1$.
