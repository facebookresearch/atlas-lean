# Rall's equivalent-cylinder theorem for passive dendritic trees

Consider a passive dendritic tree whose branches obey the linear cable equation, with electrotonic length $L = \ell/\lambda$ for a branch of physical length $\ell$ and space constant $\lambda$, and with the same membrane and axial resistivities $R_M$, $R_A$ in all branches. Rall's conditions (Rall 1959, 1962) for collapsing a parent branch $0$ and two daughters $1$, $2$ into a single cylinder are: (1) all terminal ends have the same boundary condition, for example sealed; (2) the daughters have the same electrotonic length; and (3) the diameters satisfy the 3/2-power rule $d_0^{3/2} = d_1^{3/2} + d_2^{3/2}$, which expresses that the input conductance of the parent matches the sum of those of the daughters, so that there is no impedance mismatch at the branch point. Under these conditions, with input applied at the trunk, the three branches can be replaced by a single cylinder with the diameter of the parent and electrotonic length equal to the sum of the electrotonic lengths of the parent and a daughter; applying this at every branch point collapses a whole tree whose terminals end at a common electrotonic distance into one cylinder (Rall 1962, 1964).

## Expansion

1. The model: the cable equation on a branched tree, with continuity of potential and conservation of axial current at branch points, electrotonic distance, and input conductance of a sealed finite cable.
2. Input conductance of a branch and the 3/2-power rule as the matching condition at a branch point.
3. The symmetry argument: with equal electrotonic lengths and end conditions, and input at the trunk, the potential depends only on electrotonic distance from the trunk, and the branch-point conditions reduce to those of an unbranched cylinder.
4. The statement for transient as well as steady-state voltages, and its failure when any condition is dropped.
