# Time-fractional calcium diffusion with excess buffer

Cytosolic calcium in neurons modelled by a Caputo time-fractional reaction-diffusion equation, linearized by the excess buffer approximation, whose solution is expressed through Mittag-Leffler functions with an order-dependent, algebraically slow relaxation to steady state.
