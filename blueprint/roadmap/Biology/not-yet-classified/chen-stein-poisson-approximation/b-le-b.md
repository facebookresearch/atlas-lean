# `b₃' ≤ b₃`

**`b₃' ≤ b₃`** (Arratia, Goldstein and Gordon 1989, p.10): in the dependent Bernoulli setting
under a probability measure (nonempty countable `I`, measurable `X_α ∈ {0, 1}`, every `p_α > 0`,
`λ = ∑ p_α < ∞`, `α ∈ B_α`), `b₃' ≤ b₃`.

## Sources

- Arratia, Goldstein and Gordon (1989), p.10.
