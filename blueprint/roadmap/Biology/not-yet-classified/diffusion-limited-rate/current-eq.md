# The diffusion-limited rate constant with an interaction potential

**The diffusion-limited rate constant with an interaction potential** (Debye 1942): let
`D, kT, R > 0`, let `U` have derivative `U'(r)` within `[R, ∞)` at every `r ≥ R`, let
`U(r) → 0` as `r → ∞`, and let `r ↦ e^{U(r)/kT} r^{-2}` be integrable on `(R, ∞)`. Then for every
`n₀`, there is a steady radial profile `n` with some current `J`, `n(R) = 0` and `n(r) → n₀`; and
for every such profile and current, `J = 4π D β n₀` with `1/β = ∫_R^∞ e^{U(r)/kT} r^{-2} dr`, i.e.
`J = 4π D n₀ / (1/β)`.
