# Is Ergodic Set

An **ergodic set** with parameters `(q, R)` (Hajnal 1976; Cohen 1982, p. 481): a set of
nonnegative matrices such that every product of `q` matrices from the set is strictly positive,
and every matrix `M` in the set satisfies `min⁺(M) ≥ R · max(M)`, where `min⁺` is the smallest
positive entry.
