# Moduli Ideal

For a finite species set `Sp` (`[Fintype Sp]`), the moduli ideal `M_G = T_G ∩ ℚ[K]`: the
polynomials in the variables `K_i` alone that lie in the toric steady state ideal `T_G`. The
source writes `M_G = T_G ∩ ℚ[κ]`, reading `K_i` as the tree polynomial `K_i(κ)`; as
`ℚ[c, K] ∩ ℚ[κ] = ℚ[K]`, this is the same ideal.
