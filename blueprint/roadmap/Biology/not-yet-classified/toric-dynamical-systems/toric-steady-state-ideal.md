# Toric Steady State Ideal

For a finite species set `Sp` (`[Fintype Sp]`), the toric steady state ideal `T_G` of
`ℚ[c, K]`: the saturation of the ideal generated by the binomials `K_i c^{y_j} - K_j c^{y_i}`, for
`i`, `j` in the same connected component, with respect to the product `c_1 ⋯ c_s` of the
concentration variables. When every connected component is strongly connected this is the
source's toric steady state ideal `(T_{G_1} + ⋯ + T_{G_l}) : (c_1 ⋯ c_s)^∞`, and for a strongly
connected `G` its toric balancing ideal. The source sets `T_G = ⟨1⟩` when some component is not
strongly connected; this definition does not. It is not the source's steady state ideal
`⟨Ψ(c) · A_κ · Y⟩`, which is a different ideal of `ℚ[c, κ]`.
