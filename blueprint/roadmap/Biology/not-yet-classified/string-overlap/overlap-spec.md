# Overlap of two lists is the greatest matching length

For lists $a, b$ over a type with decidable equality, say that $k$ is a matching length when $k \le |a|$, $k \le |b|$, and the last $k$ entries of $a$ equal the first $k$ entries of $b$. Then for every natural number $k$, $k$ equals the overlap of $a$ and $b$ if and only if $k$ is a matching length and every matching length $k'$ satisfies $k' \le k$.
