# The maximum kappa for fixed margins

**The maximum kappa for fixed margins** (Cohen 1960; derived): let `P` be a joint probability
table with chance agreement `p_e < 1`. Then `κ ≤ κ_max`; moreover `κ_max` depends only on the
margins: every joint probability table `Q` with the same row and column margins as `P` has
`κ(Q) ≤ κ_max(P)`.

## Sources

- Cohen (1960).
