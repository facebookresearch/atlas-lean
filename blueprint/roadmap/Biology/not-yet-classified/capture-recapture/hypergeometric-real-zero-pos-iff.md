# When the Lincoln–Petersen estimate is undefined

For `n₁ ≤ N` and
`n₂ ≤ N`, the probability `P(m = 0)` that the second sample contains no marked animal, where the
Lincoln–Petersen estimate `n₁ n₂ / m` is infinite, is positive if and only if `n₁ + n₂ ≤ N`.

## Sources

- D. G. Chapman, "Some properties of the hypergeometric distribution with applications to zoological sample censuses", Univ. California Publ. Statist. 1 (1951) 131–160; derived.
