# F-matrix distances between ranked tree shapes

Encoding a ranked tree shape (an unlabeled tree with its internal nodes ordered in time) as a lower-triangular integer matrix of lineage counts, and using element-wise $L_1$ and $L_2$ norms of these matrices, optionally weighted by inter-event times, as metrics and summary statistics for coalescent genealogies.
