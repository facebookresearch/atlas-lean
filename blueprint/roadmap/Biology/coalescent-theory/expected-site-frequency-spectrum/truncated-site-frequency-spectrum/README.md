# Truncated site frequency spectrum

The expected site frequency spectrum restricted to mutations that occur within the most recent $\tau$ units of coalescent time. It is the building block of dynamic programs that compute the expected joint SFS of several populations related by a tree of population splits, each branch of the tree contributing a truncated SFS over the time it exists.
