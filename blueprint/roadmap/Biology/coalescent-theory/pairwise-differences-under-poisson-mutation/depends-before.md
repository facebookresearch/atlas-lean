# Functions of the first $t$ steps of a history

A real function `X` on the [ranked labeled histories](../ranked-labeled-histories-of-coalescent-trees/ranked-history.md) of `n` genes depends only on the first `t` steps if replacing any
single step `j ≥ t` of any history by any [pair of lineages](../ranked-labeled-histories-of-coalescent-trees/lineage-pair.md) at that step leaves the value of `X`
unchanged. Replacing the steps one at a time, `X` then takes the same value on any two histories
that agree in their steps `0, …, t - 1`. For `t ≥ n - 1` there is no step `j ≥ t`, so every
function qualifies.
