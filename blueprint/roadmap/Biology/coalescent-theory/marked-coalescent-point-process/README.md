# Marked coalescent point process

The genealogy of the individuals alive at a fixed level $\tau$ in a splitting tree (i.i.d. lifetimes, births at constant rate during life) is a coalescent point process. Marking each birth event as clonal or mutant and recording the levels of mutations along each lineage gives the marked coalescent point process, whose large-population limit is a Poisson point process described through the ladder height process of a spectrally positive Lévy process.
