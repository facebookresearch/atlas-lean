# Mean coalescence time at locus B, path form

Let $\rho \ge 0$ and let $(X_t)_{t \ge 0}$ be the continuous-time Markov chain with the [two-locus rate matrix](two-locus-rate.md) $Q_\rho$ started from the state "linked", in its standard path construction. Let $T_B = \inf\{t \ge 0 : \text{locus } B \text{ has coalesced in } X_t\}$, with $\inf \emptyset = \infty$. Then $\mathbb{E}[T_B] = 1$.
