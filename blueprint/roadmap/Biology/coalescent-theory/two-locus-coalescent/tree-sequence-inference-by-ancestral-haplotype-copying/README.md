# Tree-sequence inference by ancestral haplotype copying

Inference of a succinct tree sequence (a genome-wide sequence of correlated marginal genealogies) from phased variation data by reconstructing putative ancestral haplotypes and threading each haplotype through older ones under a Li–Stephens copying model.
