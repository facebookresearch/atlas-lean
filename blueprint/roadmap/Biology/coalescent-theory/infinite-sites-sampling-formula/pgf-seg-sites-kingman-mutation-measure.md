# Generating function in the marked Kingman model

For `θ ≥ 0`, every natural number `n` and every real `s` with `|s| ≤ 1`, in the
[marked Kingman model](../poisson-mutation-on-the-kingman-genealogy/kingman-mutation-measure.md) the
number of segregating sites `S = ∑_b N_b` satisfies, with natural powers and `0^0 = 1` (so that at
`s = 0` the left side is `P(S = 0)`),

`E[s^S] = ∏_{k=1}^{n-1} k / (k + θ (1 - s))`,

with no further hypothesis; for `n ≤ 1` both sides are `1`.
