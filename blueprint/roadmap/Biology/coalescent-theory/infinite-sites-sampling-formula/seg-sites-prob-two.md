# Tavaré's formula for a sample of two genes

For every real number `θ` and every natural number `m`, [Tavaré's formula](seg-sites-prob.md)
for `n = 2` is

`p_{θ,2}(m) = θ^m / (θ + 1)^{m+1}`.

Powers are natural powers with `θ^0 = 1`, so at `θ = 0` the value is `1` for `m = 0` and `0`
otherwise. At `θ = -1` both sides are `0` by the convention `x / 0 = 0`. For `θ ≥ 0` this is the
geometric law: the number of segregating sites in a sample of two genes is geometric.
