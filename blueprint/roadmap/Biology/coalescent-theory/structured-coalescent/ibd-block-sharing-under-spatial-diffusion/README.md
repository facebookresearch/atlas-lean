# IBD block sharing under spatial diffusion

Long blocks of identity by descent (IBD) shared by two genomes record recent coalescence. When the ancestral lineages of the two genomes diffuse in a two-dimensional habitat, the expected number of shared blocks of a given map length decays with the geographic distance between the samples, and the rate of decay separates the dispersal rate from the population density.
