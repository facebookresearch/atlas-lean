# Multifurcating ranked tree shapes

Multiple-merger coalescents produce genealogies whose internal nodes can have more than two children. The rooted, ranked, unlabeled multifurcating tree shapes with $N$ tips form a finite space $\mathcal{MT}_N$ that can be enumerated through a string encoding, ordered by collapsing consecutive internal nodes into a lattice, and explored by Markov chains on the Hasse diagram of that lattice.
