# Number of segregating sites under infinite-sites mutation

For a finite set `B` of branches and natural-number-valued functions `N_b` on `Ω` (`b ∈ B`), the
number of segregating sites is the real-valued function

`S = ∑_{b ∈ B} N_b`.

Under infinite-sites mutation every mutation event falls at a new site, so with `N_b` the number
of mutation events on branch `b`, `S` is the number of segregating sites.
