# Tajima's variance estimator is unbiased in the marked Kingman model

For every natural number `n ≥ 2` and every `θ ≥ 0`, in the
[marked Kingman model](kingman-mutation-measure.md) the number of segregating sites
`S = ∑_b N_b` satisfies

`E[e_1 S + e_2 S (S - 1)] = c_1 θ + c_2 θ²`,

with no further hypothesis, where `c_1`, `c_2`, `e_1 = c_1 / a_1` and `e_2 = c_2 / (a_1² + a_2)`
are [Tajima's constants](../segregating-sites-and-pairwise-differences/tajima-e1.md) of the
sample size `n`.
