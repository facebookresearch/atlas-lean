# Quenched coalescent given the pedigree

Gene genealogies of a sample are usually described by averaging over the population pedigree (the annealed coalescent). The quenched coalescent instead describes the conditional law of the genealogy given the pedigree, which is a random probability measure; in diploid models with selfing it can remain random in the large-population limit.
