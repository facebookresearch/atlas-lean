# Fu's expected site frequency spectrum for Kingman's coalescent

For Kingman's coalescent, `Λ = δ₀`, every real `θ` and `1 ≤ i < n`, the
[expected site frequency spectrum](expected-sfs.md) of a sample of `n` copies is `E ξ_i = θ / i`
(Fu 1995). The identity holds for every real `θ`; for `θ ≥ 0` it is the expected number of
segregating sites whose derived allele is carried by `i` copies under neutral infinite-sites
mutation, while for `θ < 0` the value is negative and not a count.
