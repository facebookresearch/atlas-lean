# Expected site frequency spectrum of the star coalescent

For the star coalescent, `Λ = δ₁`, every real `θ` and every sample size `n ≥ 2`, the
[expected site frequency spectrum](expected-sfs.md) is `E ξ_1 = n θ / 2` and `E ξ_i = 0` for
every `i ≠ 1`. The identity holds for every real `θ`; for `θ ≥ 0` the values are expected numbers
of segregating sites under neutral infinite-sites mutation, while for `θ < 0` they are not counts
(`n = 2`, `θ = -1` gives `E ξ_1 = -1`).
