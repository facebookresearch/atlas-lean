# Pushing the clamped Beta measure back to the real line

For every real `α`, pushing the [Beta-coalescent measure](../merger-rates-and-beta-coalescents/beta-lambda.md)
on `[0, 1]` forward to `ℝ` by the inclusion `[0, 1] ⊆ ℝ` gives back the measure on `ℝ` with
density `x^{1-α} (1 - x)^{α-1} / B(2 - α, α)` on `(0, 1)` and `0` elsewhere (with `1 / 0 = 0` and
a negative density read as `0`), which is the `Beta(2 - α, α)` distribution when `0 < α < 2`.
The clamp onto `[0, 1]` used to define the Beta-coalescent measure changes nothing, since this
measure gives no mass outside `[0, 1]`.
