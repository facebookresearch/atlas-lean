# Kingman lower bound on the tail integral of 1/ψ

For a finite measure `Λ` on `[0, 1]` satisfying [Grey's condition](grey-condition.md) and every
`s > 0`, the [tail integral](psi-tail.md) satisfies `u(s) = ∫_s^∞ dq / ψ(q) ≥ 2 / (Λ([0, 1]) s)`
(Berestycki–Berestycki–Limic, eq. (13)). Equality holds for Kingman's coalescent `Λ = δ₀`, for
which `u(s) = 2 / s`.
