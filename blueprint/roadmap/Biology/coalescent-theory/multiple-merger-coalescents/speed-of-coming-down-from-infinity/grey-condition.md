# Grey's condition

For a finite measure `Λ` on `[0, 1]` with [Laplace exponent](psi.md) `ψ`, **Grey's condition**
(Berestycki–Berestycki–Limic, eq. (4)) holds when `Λ ≠ 0` and `q ↦ 1 / ψ(q)` is integrable on
`(a, ∞)` for some `a > 0`, that is, the integral of the nonnegative function `1 / ψ` over
`(a, ∞)`, taken in `[0, ∞]`, is finite. This is not finiteness of the real-valued
[tail integral](psi-tail.md), which is always finite because it is `0` when `1 / ψ` is not
integrable: for `Λ = δ₁`, `ψ(q) = e^{-q} - 1 + q` grows like `q`, so the integral in `[0, ∞]` is
infinite while the tail integral is `0`. The clause `Λ ≠ 0` excludes the degenerate case
`ψ ≡ 0`, where `1 / ψ` would be the zero function under the convention `1 / 0 = 0`, hence
integrable.
