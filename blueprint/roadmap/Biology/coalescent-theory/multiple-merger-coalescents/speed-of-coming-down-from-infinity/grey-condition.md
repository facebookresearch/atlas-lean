# Grey's condition

For a finite measure `Λ` on `[0, 1]` with [Laplace exponent](psi.md) `ψ`, **Grey's condition**
(Berestycki–Berestycki–Limic, eq. (4)) holds when `Λ ≠ 0` and `q ↦ 1 / ψ(q)` is integrable on
`(a, ∞)` for some `a > 0`, that is `∫_a^∞ dq / ψ(q) < ∞`. The clause `Λ ≠ 0` excludes the
degenerate case `ψ ≡ 0`, where `1 / ψ` would be the zero function under the convention
`1 / 0 = 0`, hence integrable.
