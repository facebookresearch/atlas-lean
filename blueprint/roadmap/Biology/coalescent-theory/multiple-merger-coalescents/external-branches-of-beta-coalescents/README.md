# External branches of Beta-coalescents

Asymptotics of the length of a randomly chosen external branch, of the number of collisions before that branch ends, and of the block-counting process at small times, for $\Lambda$-coalescents whose measure behaves like a $\mathrm{Beta}(2-\alpha,\alpha)$ distribution near zero with $1<\alpha<2$. External branch lengths measure how much private mutation a sampled individual carries and enter Fu–Li-type neutrality tests.
