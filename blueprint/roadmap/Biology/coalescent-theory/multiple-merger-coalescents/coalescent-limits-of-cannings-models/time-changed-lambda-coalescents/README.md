# Time-changed Λ-coalescents under population size change

Multiple-merger coalescents arise as genealogy limits of Cannings models with highly skewed offspring numbers. When the population size fluctuates on the coalescent time scale, the limit becomes a deterministically time-changed Λ-coalescent.
