# The Möhle–Sagitov limit measure is a probability measure

Under the [Möhle–Sagitov conditions](mohle-sagitov-lambda.md) for a sequence of Cannings models
and a measure `Λ` on `[0, 1]`, `Λ([0, 1]) = 1`; `Λ` is not assumed to be finite. Indeed the
probability `q_2` that two sampled lineages share a parent is the
[coalescence probability](../cannings-models/coal-prob.md) `c_N`, so `q_2 / c_N = 1` for all
large `N`, and the condition for `k = 2` gives `∫ 1 dΛ = 1`. For a measure of infinite total mass
this integral is `0`, the value given to non-integrable functions, so such a measure never
satisfies the conditions.
