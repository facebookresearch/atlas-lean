# The tail condition separates Λ from Kingman

Under the [Möhle–Sagitov conditions](mohle-sagitov-lambda.md) for a sequence of Cannings models
and a finite measure `Λ` on `[0, 1]`, the [heavy-tail condition](heavy-tailed.md) holds if and
only if `Λ ≠ δ₀`, that is, if and only if `Λ` has mass away from `0` and the limit coalescent has
multiple mergers.
