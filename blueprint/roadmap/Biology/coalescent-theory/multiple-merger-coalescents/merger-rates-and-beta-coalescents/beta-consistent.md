# Pitman's consistency relation for the Beta-function rates

For `0 < α < 2` and `2 ≤ k ≤ b`, the Beta function satisfies
`B(k - α, b - k + α) = B(k - α, b + 1 - k + α) + B(k + 1 - α, b - k + α)`. Divided by
`B(2 - α, α)`, this is Pitman's [consistency relation](../../coalescents/merger-rate-consistent.md)
`λ_{b,k} = λ_{b+1,k} + λ_{b+1,k+1}` for the [Beta-coalescent rates](merger-rate-beta-lambda.md).
