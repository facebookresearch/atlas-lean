# Consistency unrolls along a row

Let `r(b, k)` be real numbers indexed by natural numbers that satisfy Pitman's consistency
relation `r(b, k) = r(b + 1, k) + r(b + 1, k + 1)` for `2 ≤ k ≤ b`, and let
`m(j) = r(j + 2, j + 2)`. Then for all natural numbers `i` and `c`,
`r(i + 2 + c, i + 2) = ((I - E)^c m)(i)`, where `(I - E) g (j) = g(j) - g(j + 1)`.
