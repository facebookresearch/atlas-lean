# At α = 1 the Beta-coalescent rates are the uniform rates

For `2 ≤ k ≤ b`, the [merger rate](../../coalescents/merger-rate.md) `λ_{b,k}` of the
[Beta(1, 1) measure](beta-lambda.md), which is defined because this measure is a
[probability measure](is-probability-measure-beta-lambda.md) and hence finite, equals that of the
uniform measure on `[0, 1]`, which is
[`(k - 2)! (b - k)! / (b - 1)!`](../../coalescents/merger-rate-volume.md).
