# The ratio of the k-th power to the k-th falling factorial tends to 1

For every `k ∈ ℕ`, `N^k / (N)_k → 1` as `N → ∞`, where `(N)_k = N (N - 1) ⋯ (N - k + 1)` is the
falling factorial. The quotient is defined for every `N`: it is `1` when `k = 0`
(`N^0 = (N)_0 = 1`), `0` when `1 ≤ k` and `N < k` (then `(N)_k = 0` and `x / 0 = 0`), and the
ordinary quotient once `N ≥ k`.
