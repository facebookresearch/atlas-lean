# For x ≥ 0, the floor of x/c times c tends to x as c tends to 0⁺

Let `(c_N)` be a real sequence with `c_N > 0` for all sufficiently large `N` and `c_N → 0`, and let
`x ≥ 0`. Then `⌊x / c_N⌋ c_N → x` as `N → ∞`, where `⌊y⌋` is the largest natural number at most `y`
(and `0` for `y < 0`). Wherever `c_N ≤ 0` (at most finitely many `N`), `x / c_N ≤ 0` (with
`x / 0 = 0`), so `⌊x / c_N⌋ = 0` and the term `⌊x / c_N⌋ c_N` is `0`; this does not affect the
limit.
