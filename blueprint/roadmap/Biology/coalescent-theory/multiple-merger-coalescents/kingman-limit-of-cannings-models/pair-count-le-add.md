# Bounding the pair count by the population size and the triple count

For every parent map `f : {0, …, N - 1} → {0, …, N - 1}` and every real `a ≥ 1`, the
[pair count](pair-count.md) `X = ∑_j ν_j (ν_j - 1)` and the [triple count](triple-count.md)
`T = ∑_j ν_j (ν_j - 1) (ν_j - 2)` satisfy `X ≤ a N + T / a`. Here `ν_j` is the number of children of
parent `j`.
