# Every parent has the same offspring factorial moments

For a [Cannings model](../cannings-models/cannings-model.md) `W` of population size `N`, whose law
is exchangeable in the parents, for every parent `j` (so `N ≥ 1`) and every `m ∈ ℕ`, the
[factorial moment](factorial-moment.md) `μ_m = (1/N) ∑_i E[(ν_i)_m]` equals `E[(ν_j)_m]`. Here
`ν_i = #{c | f c = i}` is the offspring number of parent `i` under the parent map `f`, and
`(ν)_m = ν (ν - 1) ⋯ (ν - m + 1)`.
