# Number of ordered triples of distinct children with a common parent

For a parent map `f : {0, …, N - 1} → {0, …, N - 1}`, the triple count is the real number
`T(f) = ∑_j ν_j (ν_j - 1) (ν_j - 2)`, where `ν_j = #{c | f c = j}` is the number of children of
parent `j`. It is the number of ordered triples of distinct children with a common parent.
