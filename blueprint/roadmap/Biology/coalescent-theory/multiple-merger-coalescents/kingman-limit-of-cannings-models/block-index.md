# Labels of the blocks of a sample partition

Let `ξ` be a [partition](../../partition-valued-kingman-coalescent/sample-partition.md) of the
sample `{0, …, n - 1}` with `b` blocks, and fix a numbering of its blocks by `0, …, b - 1` (an
arbitrary bijection, chosen once for each `ξ`). The label of gene `i` is the number of the block of
`ξ` that contains `i`. Two genes have the same label exactly when they lie in the same block, and
every label in `{0, …, b - 1}` is the label of some gene.
