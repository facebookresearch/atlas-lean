# Number of ordered pairs of distinct children with a common parent

For a parent map `f : {0, …, N - 1} → {0, …, N - 1}`, the pair count is the real number
`X(f) = ∑_j ν_j (ν_j - 1)`, where `ν_j = #{c | f c = j}` is the number of children of parent `j`. It
is the number of ordered pairs of distinct children with a common parent.
