# Number of pairs of lineages that pick the same parent

For `b` lineages that pick the parents `φ(0), …, φ(b - 1)`, given by a map
`φ : {0, …, b - 1} → {0, …, N - 1}`, the number of [pairs](../../../bioinformatics/sequence-alignment/multiple-sequence-alignment/pair-finset.md) `k < l` of lineage
labels with `φ(k) = φ(l)`.
