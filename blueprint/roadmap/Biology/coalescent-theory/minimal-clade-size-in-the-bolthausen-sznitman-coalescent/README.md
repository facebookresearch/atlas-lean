# Minimal clade size in the Bolthausen–Sznitman coalescent

The minimal clade of a sampled individual is its block right after the first merger it takes part in. In the Bolthausen–Sznitman coalescent its size is a uniformly chosen Chinese restaurant table, which gives its exact law, a log-uniform limit and moment asymptotics.
