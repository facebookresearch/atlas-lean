# Fu's SFS covariances for samples of size at most four

Let `n ≤ 4`, let `μ` be a probability measure and let `T_k` (`k ∈ ℕ`) be
[Kingman holding times](../kingman-s-coalescent-and-watterson-s-estimator/kingman-times.md) of a
sample of size `n` under `μ`, each `T_k` measurable: for `2 ≤ k ≤ n`, `T_k` has the exponential law
with rate `C(k, 2)`, and `T_2, …, T_n` are independent. Let `τ` be a random block-size history such
that every preimage `τ⁻¹(A)` is measurable, with the
[random-joining law](../expected-site-frequency-spectrum/random-joining.md) from `n` singletons,
`μ(τ = ps) = R_{n-1}((1, …, 1), ps)` for every `ps`, and independent of the family `(T_k)_{k ∈ ℕ}`.
Let `L_i = ∑_{k=2}^{n} c_{k,i} T_k` be the
[total length of the branches subtending `i` sample copies](../expected-site-frequency-spectrum/sfs-length.md),
where `c_{k,i}` is the number of blocks of size `i` in entry `n - k` of `τ` (the empty list, which
contributes `0`, if `τ` has no such entry), and let `G` be the σ-algebra generated by `τ` and the
`T_k`.

Let `θ` be a real number and let `ξ_i` (`i ∈ ℕ`) be real random variables with the
[conditional moments of the site frequency spectrum](../covariances-of-the-site-frequency-spectrum/sfscond-moments.md)
given `G`: for all `i, j ∈ ℕ`, `ξ_i` and `L_i` are square integrable, and almost surely
`E[ξ_i | G] = (θ / 2) L_i` and `E[ξ_i ξ_j | G] = (θ / 2)² L_i L_j + δ_{ij} (θ / 2) L_i`. Then for
all `1 ≤ i, j ≤ n - 1`,

`Cov(ξ_i, ξ_j) = δ_{ij} θ / i + θ² σ_{ij}`,

with [Fu's closed form](../fu-s-covariances-of-the-site-frequency-spectrum/fu-sigma.md) `σ_{ij}`.
The result holds for every real `θ` and real-valued `ξ_i` with these moments; in the neutral
infinite-sites model with `θ ≥ 0` one may take `ξ_i` to be the number of sites whose derived allele
is carried by exactly `i` of the `n` sample copies.
