# Latent recurrent mutations of rare variants

Copies of the same allele at a site can descend from several independent mutations. For a variant seen in small count in a large sample, the number of these latent mutations has a simple sampling theory: under the standard neutral model it is distributed like the number of alleles in the Ewens sampling formula, and for populations of varying size it follows an independent-Poisson model built from expected branch lengths.
