# Tajima's constant $b_2$

For a natural number $n$, $b_2(n) = \frac{2(n^2 + n + 3)}{9n(n-1)}$, with the convention that division by $0$ gives $0$ (so $b_2(0) = b_2(1) = 0$); the constant is used for $n \ge 2$.

## Sources

- F. Tajima, *Statistical method for testing the neutral mutation hypothesis by DNA polymorphism*, Genetics 123 (1989), 585–595.
