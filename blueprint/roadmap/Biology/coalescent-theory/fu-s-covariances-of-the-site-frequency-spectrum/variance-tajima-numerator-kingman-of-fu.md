# Variance of Tajima's $D$ numerator from the SFS and Fu's closed form

Let `μ` be a probability measure on a measurable space `Ω`, under which expectations, variances and
covariances are taken; let `n ≥ 2` be a natural number and `θ` a real number. Let `T_k` (`k ∈ ℕ`)
be [Kingman holding times](../kingman-s-coalescent-and-watterson-s-estimator/kingman-times.md) of a sample of size `n` under `μ` (for `2 ≤ k ≤ n`, `T_k` has the
exponential law with rate `C(k, 2)`, and `T_2, …, T_n` are independent), each `T_k` measurable.
Let `τ` be a random block-size history (a random list of lists of block sizes) such that every
preimage `τ⁻¹(A)` is measurable, with the [random-joining law](../expected-site-frequency-spectrum/random-joining.md) from `n` singletons,
`μ(τ = ps) = R_{n-1}((1, …, 1), ps)` for every history `ps`, where `(1, …, 1)` has `n` entries,
and independent of the family `(T_k)_{k ∈ ℕ}`. Let `L_i = ∑_{k=2}^{n} N_{k,i} T_k` be the
[total length of the branches subtending `i` sample copies](../expected-site-frequency-spectrum/sfs-length.md), where `N_{k,i}` is the number of blocks of
size `i` in entry `n - k` of `τ` (`0` if there is no such entry), and let `G` be the σ-algebra
generated by `τ` and all the `T_k`. Let the counts `ξ_i` (`i ∈ ℕ`) have the
[conditional moments of the site frequency spectrum](../covariances-of-the-site-frequency-spectrum/sfscond-moments.md) given `G`: for all `i, j ∈ ℕ`,
`ξ_i` and `L_i` are square integrable and, almost surely, `E[ξ_i | G] = (θ / 2) L_i` and
`E[ξ_i ξ_j | G] = (θ / 2)² L_i L_j + δ_{ij} (θ / 2) L_i` (`δ_{ij}` is `1` if `i = j` and `0`
otherwise).

If `Cov(L_i, L_j) = 4 σ_{ij}` for all `1 ≤ i, j ≤ n - 1`, with [Fu's covariance matrix](fu-sigma.md)
`σ` for the sample size `n`, then Tajima's `D` numerator `θ_π - S / a_1(n)`, with
[Tajima's estimator](../site-frequency-spectrum-under-variable-populatio/theta-pi.md) `θ_π = ∑_{i=1}^{n-1} i (n - i) ξ_i / C(n, 2)` and the number of segregating
sites `S = ∑_{i=1}^{n-1} ξ_i`, satisfies

`Var(θ_π - S / a_1(n)) = c_1(n) θ + c_2(n) θ²`

(Tajima 1989), with [Tajima's constants](../segregating-sites-and-pairwise-differences/tajima-c1.md) `c_1(n) = b_1(n) - 1 / a_1(n)` and
`c_2(n) = b_2(n) - (n + 2) / (a_1(n) n) + a_2(n) / a_1(n)²`, where `a_1(n) = ∑_{k=1}^{n-1} 1/k`,
`a_2(n) = ∑_{k=1}^{n-1} 1/k²`, `b_1(n) = (n + 1) / (3 (n - 1))` and
`b_2(n) = 2 (n² + n + 3) / (9 n (n - 1))`. The hypothesis on the covariances of the `L_i` follows
from the others ([Fu's branch-length covariances](../fu-s-branch-length-covariances-for-every-sample/covariance-sfs-length-eq-four-mul-fu-sig.md)). The corresponding numerator identity
with the mean number of pairwise differences `π` in place of `θ_π`,
`Var(π - S / a_1(n)) = c_1(n) θ + c_2(n) θ²`, derived from pairwise coalescence times, is
[Tajima's variance identity](../segregating-sites-and-pairwise-differences/variance-tajima-numerator.md).
