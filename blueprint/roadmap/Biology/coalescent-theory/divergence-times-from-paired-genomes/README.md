# Divergence times from paired genomes

With two sampled gene copies from each of two populations (for example one diploid genome per population), the seven polymorphic sample configurations have probabilities that are explicit in the split times, the drift in each daughter branch and the ancestral coalescent times. Equating observed configuration frequencies with these probabilities gives closed-form estimators of split times measured in generations, the Two-Two (TT) method.
