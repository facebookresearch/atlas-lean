# Renewal seed-bank ancestral process

Wright–Fisher-type models in which an individual's parent may have lived many generations back, with the gap drawn from a seed-bank age distribution. Ancestral lines are discrete renewal processes; finite-mean age distributions give a slowed-down Kingman coalescent, while power-law tails produce regimes with no common ancestor or with infinite expected coalescence time.
