# Recurrence for Fu's $\beta_n(i)$

For natural numbers `n` and `i` with `i ≥ 1` and `i + 1 < n`, [Fu's coefficient](../fu-s-covariances-of-the-site-frequency-spectrum/fu-beta.md)
`β_n(i) = 2n (a_{n+1} - a_i) / ((n - i + 1)(n - i)) - 2 / (n - i)`, with `a_m = ∑_{k=1}^{m-1} 1/k`,
satisfies

`(n - i + 1) β_n(i) - (n - i - 1) β_n(i + 1) = 2 / i`.
