# Clusters of a species tree

The clusters of a [species tree](species-tree.md), the sets of species below its vertices, defined recursively: the leaf $\ell(i)$ has the single cluster $\{i\}$, and a node $(l, r, t)$ has the clusters of $l$ and of $r$ together with the set of all species below $l$ and $r$. So the clusters include the singletons and the full species set of the tree.
