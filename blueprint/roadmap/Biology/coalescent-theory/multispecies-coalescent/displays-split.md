# Gene tree displaying a quartet split

For genes $a, b \in \{0, 1, 2, 3\}$, a gene tree $G$ on four genes, given by its set of clusters, displays the quartet split $ab \mid cd$, where $\{c, d\}$ is the complement of $\{a, b\}$, if $\{a, b\}$ or $\{0, 1, 2, 3\} \setminus \{a, b\}$ is a cluster of $G$. When $G$ is a rooted binary tree and $a \ne b$, this means that forgetting the root, the internal edge separates $\{a, b\}$ from $\{c, d\}$.
