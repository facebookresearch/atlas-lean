# Nonnegativity of the exit law

Let $T$ be a [species tree with nonnegative branch lengths](nonneg-lengths.md) and $k$ a real function of a number of lineages, a list of lineages and a set of clusters such that $k(m, b, A) \ge 0$ whenever $m \ge 1$. Then the [exit law](exit-law.md) satisfies $X_T(k) \ge 0$, because Tavaré's probabilities are nonnegative at nonnegative times.
