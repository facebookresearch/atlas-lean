# Exit law of a constant continuation

Let $T$ be a [species tree](species-tree.md), $c$ a real number and $k$ a real function of a number of lineages, a list of lineages and a set of clusters such that $k(m, b, A) = c$ whenever $m \ge 1$. Then the [exit law](exit-law.md) satisfies $X_T(k) = c$, because Tavaré's probabilities sum to one and random joining is a probability law.
