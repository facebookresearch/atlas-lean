# Normalization of gene-tree probabilities

For every [species tree](species-tree.md) $T$, with arbitrary real branch lengths, the [multispecies coalescent](gene-tree-prob.md) gives weight $1$ to the set of all gene trees: $P_T(\text{all gene trees}) = 1$. With [nonnegativity](gene-tree-prob-nonneg.md) and [additivity](gene-tree-prob-or.md), this makes $P_T$ a probability law on gene trees when $T$ has nonnegative branch lengths.
