# Time-dependent migration in the multispecies coalescent

Species that diverge rarely stop exchanging migrants at once; gene flow typically declines gradually. Letting effective population sizes and emigration fractions vary with time turns the coalescent with migration into a set of competing non-homogeneous Poisson processes, whose waiting times are sampled by inverting integrated hazards.
