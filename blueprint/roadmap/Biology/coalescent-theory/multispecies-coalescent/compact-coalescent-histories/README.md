# Compact coalescent histories

Grouping the coalescent histories of a gene tree inside a species tree by their lineage counts on species-tree branches. Because the coalescent probability factors depend only on these counts, the gene tree probability becomes a sum over far fewer compact histories, computable in polynomial time in the number of sampled lineages when the number of populations is fixed.
