# Root branch length does not affect gene-tree probabilities

For all [species trees](species-tree.md) $l$ and $r$, all real numbers $t$ and $t'$ and every set $E$ of gene trees, the [multispecies coalescent](gene-tree-prob.md) gives the same weight to $E$ on the species trees $(l, r, t)$ and $(l, r, t')$: the branch length stored at the root does not affect the gene tree.
