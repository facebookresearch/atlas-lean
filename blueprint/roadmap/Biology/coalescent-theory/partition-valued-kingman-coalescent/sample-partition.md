# Set partitions of a labeled sample

For a natural number $n$, the set $\mathcal{P}_n$ of set partitions of the sample $\{0, \dots, n-1\}$ of $n$ labeled genes: families of nonempty, pairwise disjoint blocks whose union is $\{0, \dots, n-1\}$. For $n = 0$ it has one element, the partition with no blocks. We write $\bot$ for the partition into singletons and $|\pi|$ for the number of blocks of $\pi$.
