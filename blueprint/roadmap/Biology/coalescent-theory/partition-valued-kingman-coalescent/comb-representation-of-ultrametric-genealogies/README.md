# Comb representation of ultrametric genealogies

Combs encode compact ultrametric spaces, such as the population alive at a fixed time in a genealogy, as functions on an interval whose values are coalescence depths between neighbouring points; spheres of real trees and the Brownian tree yield coalescent point processes.
