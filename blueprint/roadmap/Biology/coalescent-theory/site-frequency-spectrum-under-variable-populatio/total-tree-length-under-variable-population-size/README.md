# Total tree length under variable population size

Exact computation of the marginal distribution of the total branch length of a coalescent genealogy, and of the joint distribution at two linked loci, when the population size varies in time. Distribution functions of path integrals of time-inhomogeneous Markov chains satisfy linear hyperbolic systems of partial differential equations, which can be solved by the method of characteristics; these distributions are building blocks of coalescent hidden Markov models for demographic inference.
