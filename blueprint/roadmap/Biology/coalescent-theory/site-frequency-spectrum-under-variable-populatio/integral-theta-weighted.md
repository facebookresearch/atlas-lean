# Achaz's unbiasedness

Let $\mu$ be a measure, $n$ a natural number, $\theta$ a real number and $\xi_i$ ($i \in \mathbb{N}$) $\mu$-integrable real functions with $\int \xi_i \, d\mu = \theta / i$ for every $1 \le i \le n - 1$, the constant-size spectrum. Then for all real weights $w_i$ with $\sum_{i=1}^{n-1} w_i = 1$, the [weighted estimator](theta-weighted.md) satisfies $\int \theta_w \, d\mu = \theta$.

## Sources

- G. Achaz, *Frequency spectrum neutrality tests: one for all and all for one*, Genetics 183 (2009), 249–258.
