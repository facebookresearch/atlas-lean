# Size function on a piece equals the piece size

For a [piecewise-constant history](piecewise-history.md) with $K$ pieces, sizes $\nu_j$ and start times $s_j$, a natural number $j < K$ and a real $s$ with $s_j \le s$ and, if $j + 1 < K$, $s < s_{j+1}$, the [size function](size-fn.md) satisfies $\eta(s) = \nu_j$.
