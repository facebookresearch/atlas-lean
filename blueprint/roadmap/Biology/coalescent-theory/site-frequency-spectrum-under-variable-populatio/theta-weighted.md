# Achaz's weighted estimator of $\theta$

For a natural number $n$, real weights $w_i$ and real functions $\xi_i$ on a set $\Omega$ ($i \in \mathbb{N}$), the weighted estimator is the function

$$\theta_w = \sum_{i=1}^{n-1} w_i\, i\, \xi_i.$$

## Sources

- G. Achaz, *Frequency spectrum neutrality tests: one for all and all for one*, Genetics 183 (2009), 249–258.
