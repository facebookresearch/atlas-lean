# Tajima's $\theta_\pi$ in site frequency spectrum form

For a natural number $n$ and real functions $\xi_i$ on a set $\Omega$, the [weighted estimator](theta-weighted.md) with weights $w_i = (n - i)/\binom{n}{2}$:

$$\theta_\pi = \binom{n}{2}^{-1} \sum_{i=1}^{n-1} i\,(n-i)\, \xi_i,$$

where division by $0$ gives $0$.
