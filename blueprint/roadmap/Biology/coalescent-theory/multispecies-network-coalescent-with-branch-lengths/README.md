# Multispecies network coalescent with branch lengths

When species histories include hybridization or introgression, gene trees evolve inside a species network: lineages coalesce within branches as in Kingman's coalescent and choose a parent at each reticulation according to inheritance probabilities. Using gene trees with coalescent times, the density factorizes over branches into inverse-gamma kernels in the population sizes, which can then be integrated out in closed form; a birth–hybridization process supplies a generative prior on the networks themselves.
