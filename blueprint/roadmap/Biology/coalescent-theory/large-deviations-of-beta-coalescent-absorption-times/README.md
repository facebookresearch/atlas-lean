# Large deviations of Beta-coalescent absorption times

For the Beta$(a,b)$-coalescent started from $n$ blocks, the time to the most recent common ancestor grows like $\log n$ when $a>1$ and stays bounded when $a<1$ (coming down from infinity). Laplace transforms of integral functionals along the block-counting chain yield a large deviation principle with an explicit Legendre-type rate function in the first case and a polynomial Kolmogorov-distance rate to the limit law in the second.
