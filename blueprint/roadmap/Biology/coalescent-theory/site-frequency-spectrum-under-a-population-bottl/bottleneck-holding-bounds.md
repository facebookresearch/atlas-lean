# Bounds on one time-changed epoch

Let `a` be any real number, `d ≥ 0` and `f > 0` real numbers, `n` a natural number and `T_j`
(`j ∈ ℕ`) real numbers with `T_j ≥ 0` for `2 ≤ j ≤ n`. For every `2 ≤ k ≤ n`, the
[time-changed holding time](bottleneck-holding.md) satisfies `0 ≤ T^b_k ≤ max(1, f) T_k`;
moreover `T^b_k ≤ T_k` if `f ≤ 1`, and `T_k ≤ T^b_k` if `f ≥ 1`.
