# Importance sampling for Lambda-coalescents

Likelihood computation for infinitely-many-sites data when genealogies follow a Lambda-coalescent (multiple mergers). The sampling probability is an expectation over coalescent histories, the optimal importance sampling proposal is the time-reversed history, and practical proposals approximate it by generalizing the Griffiths–Tavaré and Stephens–Donnelly schemes.
