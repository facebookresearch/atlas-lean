# Inverse-gamma integration of species-tree population sizes

Under the multispecies coalescent with a constant population size on each species-tree branch, an inverse-gamma prior on the sizes is conjugate to the coalescent likelihood of the gene trees. The sizes can therefore be integrated out analytically at every step of a Bayesian sampler instead of being sampled.
