# Watterson's estimator from low-coverage sequencing

Shallow short-read data leave each site covered by a different, random subset of the sampled chromosomes and mix true SNPs with sequencing errors. Splitting the alignment into segments of constant sample size and counting segregating sites as sums of SNP posterior probabilities keeps Watterson's estimator of the population mutation rate unbiased.
