# Selection scan against an ancestral admixture model

Genome scans for selection that use ancient DNA: present-day allele frequencies are predicted as mixtures of frequencies in ancient source populations, and SNPs whose present-day frequencies depart from the mixture prediction more than drift allows are candidate targets of selection. Low-coverage ancient genomes enter through read-count likelihoods.
