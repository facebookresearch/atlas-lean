# The McDonald–Kreitman null is neutrality

In every [expected-count model](mkmodel.md),

$$\frac{\mathbb{E}D_n}{\mathbb{E}D_n + \mathbb{E}D_s} = \frac{\mathbb{E}P_n}{\mathbb{E}P_n + \mathbb{E}P_s} \iff A = 0:$$

the proportions of nonsynonymous changes among expected fixed differences and expected polymorphisms agree exactly when there are no adaptive substitutions.
