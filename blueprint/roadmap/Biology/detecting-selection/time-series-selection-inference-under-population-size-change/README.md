# Time-series selection inference under population size change

Exact likelihoods of ancient-DNA or experimental-evolution allele counts sampled at several times, when the population size changes through epochs. Both the discrete Wright–Fisher chain and its diffusion limit admit forward recursions over hidden population frequencies; the diffusion version runs on a spectral (eigenfunction) basis that is re-projected at epoch boundaries. Conditioning on the allele still segregating corrects the ascertainment of polymorphic loci.
