# Latent factor mixed models

Gene–environment association scans test each genetic marker for correlation with an environmental gradient, but population structure creates confounding. Latent factor mixed models absorb the confounders into a low-rank matrix estimated jointly with the environmental effects. With a ridge penalty, the joint estimate has a closed form computed from two singular value decompositions.
