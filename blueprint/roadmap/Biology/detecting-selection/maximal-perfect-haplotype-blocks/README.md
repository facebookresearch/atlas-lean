# Maximal perfect haplotype blocks

A maximal perfect haplotype block is a set of at least two haplotypes that agree exactly on an interval of sites and cannot be extended left, right, or by another haplotype. Long shared blocks are a signature used in rapid genome-wide selection scans; the blocks can be enumerated in time linear in the size of the haplotype matrix.
