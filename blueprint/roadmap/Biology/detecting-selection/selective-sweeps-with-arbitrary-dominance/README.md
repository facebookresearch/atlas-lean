# Selective sweeps with arbitrary dominance

Genetic hitchhiking when the beneficial allele's dominance coefficient is arbitrary. Incompletely dominant sweeps behave like co-dominant ones with an effective selection coefficient $2hs$, but recessive sweeps are qualitatively different: they last of order $\sqrt{N/s}$ generations and leave a narrower, non-star-like footprint in linked diversity.
