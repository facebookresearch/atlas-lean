# HKA variance of the number of segregating sites

For a real $\theta$ and a natural number $n$, put

$$v_S(\theta, n) = \theta\, a_1(n) + \theta^2 a_2(n), \qquad a_1(n) = \sum_{j=1}^{n-1} \frac1j,\quad a_2(n) = \sum_{j=1}^{n-1} \frac{1}{j^2}.$$

For $\theta \ge 0$ it is the variance of the number of segregating sites in a sample of $n$ genes under the neutral infinite-sites model.
