# Reciprocal-denominator bound 1/√e₁ for S = 0 or S ≥ 1 and n ≥ 4

For `n ≥ 4` genes and a real `S` with `S = 0` or `S ≥ 1` (as for a number of segregating sites),
`1 / √(e₁ S + e₂ S (S - 1)) ≤ 1 / √e₁`, where `e₁, e₂` are Tajima's constants (see
[Tajima's D](../tajima-s-d/tajima-d.md)). At `S = 0` the left side is `1 / √0 = 0`, by the
convention `1 / 0 = 0`.
