# All Lᵖ bounds for Tajima count data under a finite measure

Let `μ` be a finite measure, `n ≥ 4`, and `S` an almost everywhere measurable real function with
`S = 0` or `S ≥ 1` almost everywhere. Then `1 / √(e₁ S + e₂ S (S - 1))`, which is `0` where
`S = 0` (by the convention `1 / 0 = 0`), lies in `Lᵖ(μ)` for every exponent `p`, including
`p = ∞`: it is almost everywhere [at most](inv-sqrt-tajima-var-estimator-le.md) `1 / √e₁`.
