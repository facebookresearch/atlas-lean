# Cauchy's count by number of cycles

For all natural numbers $n, k$,

$$\sum_{\pi \,:\, K(\pi) = k} w(\pi) = \Bigl[{n \atop k}\Bigr],$$

the sum over the partitions of $n$ into $k$ parts of the [cycle-type weights](cycle-type-weight.md), where $[{n \atop k}]$ is the unsigned Stirling number of the first kind (the number of permutations of $n$ letters with $k$ cycles).
