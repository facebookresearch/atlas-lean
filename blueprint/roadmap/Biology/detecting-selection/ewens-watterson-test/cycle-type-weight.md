# Number of permutations with a given cycle type

For a partition $\pi$ of a natural number $n$, with $a_j$ parts equal to $j$, put

$$w(\pi) = \frac{n!}{\prod_{j} j^{a_j}\, a_j!},$$

the product running over the distinct part sizes $j$; $w(\pi)$ is the number of permutations of $n$ letters with cycle type $\pi$ (Cauchy's formula).
