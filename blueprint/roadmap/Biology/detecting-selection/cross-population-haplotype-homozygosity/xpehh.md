# Cross-population extended haplotype homozygosity (XP-EHH)

For real numbers $i_A$ and $i_B$ (the integrated haplotype homozygosities of the same core region in two populations), the XP-EHH score is

$$\mathrm{XPEHH}(i_A, i_B) = \log i_A - \log i_B,$$

with the conventions $\log 0 = 0$ and $\log x = \log|x|$ for $x < 0$; it is meaningful for $i_A, i_B > 0$ (Sabeti et al. 2007).
