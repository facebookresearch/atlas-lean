# Equal tails of the log ratio of an exchangeable pair

Let $(X, Y)$ be an [exchangeable pair](is-exchangeable-pair.md) under $\mu$ with $X$ and $Y$ measurable. Then for every real $t$,

$$\mu(\{t \le \log X - \log Y\}) = \mu(\{\log X - \log Y \le -t\}),$$

with the conventions $\log 0 = 0$ and $\log x = \log|x|$ for $x < 0$ (for positive statistics this is the equal-tail property of the log ratio).
