# Gaussian drift model exits the unit interval with positive probability

In the [Gaussian drift model](gaussian-drift-model.md) with one edge and one population, the set of
`ω ∈ ℝ` at which the frequency `1 / 2 + ω` lies outside `[0, 1]` has nonzero standard normal
measure, equivalently positive measure: the frequency leaves `[0, 1]` with positive probability
under the standard normal law of `ω`. The set contains `(1 / 2, ∞)`.
