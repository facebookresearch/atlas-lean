# Double centring of a square matrix

Let $\iota$ be a finite set of $n$ elements. The double centring of a real matrix $t = (t_{ij})_{i, j \in \iota}$ is the matrix

$$(\mathcal{D} t)_{ij} = \frac{1}{n} \sum_{k} t_{ik} + \frac{1}{n} \sum_{k} t_{kj} - t_{ij} - \frac{1}{n^2} \sum_{k, l} t_{kl},$$

with the convention $x/0 = 0$.
