# At α = 0 the admixture model has the frequencies of a star tree

Let `a, b, c` be real numbers and `M` a [drift model](../patterson-s-f-statistics/drift-model.md) on
three populations `A = 0`, `B = 1`, `C = 2` and three edges, with the
[admixture weights](admix-weight.md) at `α = 0` and edge lengths `(a, b, c)`. Then there is a drift
model `M'` on the same measure, with the [star-tree weights](star-weight.md) and the
[matching edge lengths](star-len.md) at `α = 0`, that is `(a + b, 0, c)`, whose population
frequencies are the same functions as those of `M`. At `α = 0` the admixed population `C` descends
from `B` alone, so the admixture degenerates to the star tree.
