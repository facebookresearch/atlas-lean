# Continuous decay is a lower bound for the exact factor under Haldane's map

For every real $d$ and natural number $n$, with Haldane's map function $r(d) = (1 - e^{-2d})/2$,

$$e^{-nd} \le \bigl(1 - r(d)\bigr)^n.$$

So the continuous decay $e^{-nd}$ used by Chakraborty and Weiss (1988) and Loh et al. (2013) is a lower bound for the exact factor.

## Sources

- R. Chakraborty, K. M. Weiss, *Admixture as a tool for finding linked genes and detecting that difference from allelic association between loci*, Proc. Natl. Acad. Sci. USA 85 (1988), 9119–9123.
- P.-R. Loh, M. Lipson, N. Patterson, P. Moorjani, J. K. Pickrell, D. Reich, B. Berger, *Inferring admixture histories of human populations using linkage disequilibrium*, Genetics 193 (2013), 1233–1254.
