# Three-population test: negative f3 rules out a tree

In a [drift model](drift-model.md), if the [f3 statistic](f3.md) of the [population frequencies](freq.md) satisfies $f_3(C; A, B) < 0$ for some populations $C, A, B$, then the model does not have [binary loadings](has-binary-loadings.md); in particular it is not a tree model.
