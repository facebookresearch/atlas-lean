# Binary loadings of a drift model

A [drift model](drift-model.md) has binary loadings if every lineage weight $w(X, e)$ is $0$ or $1$. Every tree model has binary loadings; the converse fails (four populations with weight vectors $00, 10, 01, 11$ on two edges of length $1$ have binary loadings, but their f2 distances form a square, which is not a tree metric).
