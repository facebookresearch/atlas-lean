# Conditionally negative semidefinite matrix

A real matrix `D` indexed by a finite set `P` is conditionally negative semidefinite when
`∑ i, ∑ j, c i * c j * D i j ≤ 0` for every real vector `c` indexed by `P` with `∑ i, c i = 0`.
Symmetry and a zero diagonal are not part of the definition. The
[f2](../patterson-s-f-statistics/f2.md) matrix of square-integrable frequencies has this property.
