# Equality case of the Cauchy–Schwarz inequality for f-statistics

Let `μ` be a measure on `Ω` (not necessarily a probability measure) and let every population
frequency `p X : Ω → ℝ` be square integrable. Then for all populations `A, B, C, D`, equality
`f4(A, B; C, D) ^ 2 = f2(A, B) * f2(C, D)` in the [Cauchy–Schwarz inequality](sq-f4-le-f2-mul-f2.md)
holds if and only if `p A = p B` μ-almost everywhere, or `p C - p D = r (p A - p B)` μ-almost
everywhere for some real `r`.
