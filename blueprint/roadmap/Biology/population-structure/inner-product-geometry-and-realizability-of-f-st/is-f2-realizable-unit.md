# Matrix realized by f2 statistics of frequencies in the unit interval

A real matrix `D` indexed by a set `P` of populations is realizable with frequencies in `[0, 1]`
when there are a probability space `(Ω, μ)` and measurable functions `p X : Ω → ℝ`, one for each
population `X`, with every value `p X ω` in `[0, 1]`, whose
[f2 statistics](../patterson-s-f-statistics/f2.md) are `f2(X, Y) = D X Y` for all `X, Y ∈ P`. No
drift-model structure is required.
