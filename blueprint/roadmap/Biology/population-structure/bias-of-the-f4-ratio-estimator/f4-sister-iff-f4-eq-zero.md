# The f4-ratio sister condition is equivalent to a vanishing f4

In every [drift model](../patterson-s-f-statistics/drift-model.md) and for all populations
`A, O, Y, B, C`, the f4 equality `f4(A, O; Y, C) = f4(A, O; B, C)` assumed by
[f4-ratio estimation](../patterson-s-f-statistics/f4-ratio.md) holds if and only if
`f4(A, O; Y, B) = 0`, where `f4` is the [f4 statistic](../patterson-s-f-statistics/f4.md) of the
[population frequencies](../patterson-s-f-statistics/freq.md): the edge sum of the
[graph criterion](f4-sister-iff-sum-eq-zero.md) is itself an f4 statistic.
