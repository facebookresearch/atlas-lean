# One-edge example where the nonnegativity constraint is active

With one statistic and one edge, `Q = 1`, `B = 1` and `f = -1`, the edge length `0` is a
[constrained maximizer](is-constrained-maximizer.md) of the [score](score-s1.md) `S1`, and it is the
only one: every constrained maximizer `ℓ` has `ℓ = 0`. Here `S1(B ℓ) = -½ (ℓ + 1) ^ 2`, whose
maximizer over all real `ℓ`, `ℓ = -1`, is not a nonnegative edge length.
