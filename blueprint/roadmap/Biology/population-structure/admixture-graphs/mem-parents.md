# Being a parent is adjacency in the network digraph

Let $N$ be a [phylogenetic network](phylo-network.md) on a finite set $V$ of nodes, with root $\rho$
and parent sets $\mathrm{pa}(v)$. For all nodes $u$ and $v$, $u \in \mathrm{pa}(v)$ if and only if
$u \to v$ is an edge of the [digraph](g.md) of the network.
