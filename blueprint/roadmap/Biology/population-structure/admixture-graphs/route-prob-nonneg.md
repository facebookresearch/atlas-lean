# Routing probabilities are nonnegative

In every [admixture graph](admixture-graph.md), for every node `X`, the root included, every
natural number `k` and every assignment `y` of `k` lineages to nodes, the
[routing probability](route-prob.md) is nonnegative: `R(X, y) = ∏_{i < k} a(X, y_i) ≥ 0`, since
admixture proportions are nonnegative.
