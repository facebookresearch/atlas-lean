# At the root every nonempty routing has probability zero

In every [admixture graph](admixture-graph.md) with root `ρ`, for every natural number `k > 0` and
every assignment `y` of `k` lineages to nodes, the [routing probability](route-prob.md) at the root
is `R(ρ, y) = 0`: the root has no parents, so the factor `a(ρ, y_0)` vanishes. For `k = 0` the
empty assignment has [probability `1`](route-prob-zero.md) instead.
