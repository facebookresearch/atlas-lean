# Spatial demography from shared coalescence segments

Inference of recent, spatially varying migration rates and population sizes from counts of long genomic segments over which two haplotypes share a single coalescence time, under a stepping-stone coalescent on a grid of demes, using a recombination map as an absolute clock.
