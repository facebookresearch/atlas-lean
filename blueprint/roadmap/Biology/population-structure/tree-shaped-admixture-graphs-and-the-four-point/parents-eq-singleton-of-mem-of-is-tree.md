# In a tree-shaped admixture graph a parent is the only parent

In an [admixture graph](../admixture-graphs/admixture-graph.md) that is
[tree-shaped](../admixture-graphs/is-tree.md) (every node has at most one parent), if `Y` is a
parent of `X`, then `Y` is the only parent of `X`: `parents(X) = {Y}`.
