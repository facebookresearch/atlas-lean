# The root's lineage visits no other node

In every [admixture graph](../admixture-graphs/admixture-graph.md) with root `ρ`, the
[visit probability](../admixture-graphs/visit.md) of every node `c ≠ ρ` from the root is zero,
`v(ρ, c) = 0`: the root has no parent, so its lineage passes through no other node.
