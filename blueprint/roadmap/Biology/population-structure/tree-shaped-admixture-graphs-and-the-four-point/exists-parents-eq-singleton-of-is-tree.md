# In a tree-shaped admixture graph every non-root node has one parent

In an [admixture graph](../admixture-graphs/admixture-graph.md) that is
[tree-shaped](../admixture-graphs/is-tree.md) (every node has at most one parent), every node `X`
other than the root has exactly one parent: `parents(X) = {Y}` for some node `Y`.
