# Spectral analysis of local ancestry

Local ancestry along a chromosome of an admixed or hybrid individual can be represented as a vector-valued signal whose squared components are ancestry probabilities. Fourier analysis of this signal turns the spatial scale of ancestry tracts into a probability distribution over frequencies, whose entropy measures how fragmented the ancestry is and obeys an uncertainty principle with the ancestry autocorrelation.
