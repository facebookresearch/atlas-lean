# Unpolarized BABA site-pattern indicator

For populations $(P_1, P_2, P_3, O)$ and a configuration $x = (x_1, x_2, x_3, x_4) \in \{0, 1\}^4$ of derived-allele indicators, the unpolarized BABA indicator is $1$ if $x_1 = x_3$, $x_2 = x_4$ and $x_1 \ne x_2$ (the patterns BABA and ABAB), and $0$ otherwise.
