# Archaic introgression detection

Statistical models and algorithms that locate genomic segments inherited from an archaic population (for example Neanderthals or Denisovans) in present-day genomes: reference-free maximum-scoring segment statistics of the S* family, and sampling of ancestral recombination graphs conditioned on a demographic model with migration bands.

- [Demography-aware ARG threading with migration bands](demography-aware-arg-threading-with-migration-bands.md)
