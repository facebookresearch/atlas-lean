# Reference and alternative counts add to the population count

Let $I$ be finite. For every genotype matrix $g$, all [admixture parameters](params.md) $\theta$, populations $k$ and SNPs $j$,

$$R_{kj}(\theta) + S_{kj}(\theta) = C_{kj}(\theta),$$

for the [expected reference](ref-count.md), [alternative](alt-count.md) and [population](pop-count.md) counts.
