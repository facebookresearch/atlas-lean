# Positivity of expected reference counts on polymorphic data

Let $I$ be finite and let $g$ be a [polymorphic](polymorphic.md) genotype matrix. Then for all [admixture parameters](params.md) $\theta$, populations $k$ and SNPs $j$, the [expected reference count](ref-count.md) satisfies $R_{kj}(\theta) > 0$.
