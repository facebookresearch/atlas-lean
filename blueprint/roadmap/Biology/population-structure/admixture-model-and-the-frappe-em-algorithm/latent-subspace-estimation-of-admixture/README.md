# Latent subspace estimation of admixture

The admixture model writes the matrix of individual-specific allele frequencies as a low-rank product of ancestral allele frequencies and admixture proportions. Its row space can be estimated consistently by a bias-corrected principal component analysis of the genotype matrix, after which a constrained factorization within that subspace recovers the admixture parameters without maximizing a likelihood.
