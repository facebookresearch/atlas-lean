# Observation of one allele copy of a genotype

For a genotype matrix $g$ with entries in $\{0, 1, 2\}$, the observation of copy $c \in \{0, 1\}$ of individual $i$ at SNP $j$ is the triple $(i, j, a)$, where $a$ is true exactly when the copy [carries the reference allele](is-ref.md), that is, when $c < g_{ij}$.
