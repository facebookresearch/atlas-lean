# Expected ancestry counts sum to the number of allele copies

Let $J$ be finite and $K$ nonempty. For every genotype matrix $g$, all [admixture parameters](params.md) $\theta$ and every individual $i$,

$$\sum_{k \in K} A_{ik}(\theta) = 2|J|,$$

where $A_{ik}$ is the [expected ancestry count](anc-count.md).
