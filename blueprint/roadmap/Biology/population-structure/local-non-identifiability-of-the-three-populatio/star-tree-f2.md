# Length-to-f2 map of the three-leaf star tree

The linear map `ℝ^3 → ℝ^3`, `(x, y, z) ↦ (x + y, x + z, y + z)`, sending the lengths `x`, `y`, `z`
of the three leaf edges of a star tree to its f2 values `(f2(0, 1), f2(0, 2), f2(1, 2))`. It is
defined for all real lengths; lengths are nonnegative in the intended use.
