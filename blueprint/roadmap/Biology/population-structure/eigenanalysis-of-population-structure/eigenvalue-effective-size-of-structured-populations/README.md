# Eigenvalue effective size of structured populations

The effective size defined by the rate at which genetic variation is lost, the largest non-unit eigenvalue of the allele-frequency Markov chain. For subdivided populations it can be computed from a linear recursion for gene diversities between pairs of subpopulations, built from backward migration and coalescence probabilities.
