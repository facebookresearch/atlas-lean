# f2 is unchanged by a common shift of the lineage weights

Let `M` and `M'` be [drift models](../patterson-s-f-statistics/drift-model.md) with the same
populations and edges, possibly on different measure spaces, with the same drift lengths, and
suppose that for one real vector `c` on the edges the lineage weights satisfy
`w'(X, e) = w(X, e) + c(e)` for every population `X` and every edge `e`. Then the two models give
the same value of the [f2 statistic](../patterson-s-f-statistics/f2.md) `f2(X, Y)` for all
populations `X, Y`.
