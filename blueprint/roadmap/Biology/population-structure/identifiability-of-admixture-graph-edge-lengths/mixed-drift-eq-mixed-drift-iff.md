# Level sets of the mixed drift

For every real `α` and all real `ℓ_a, ℓ_b, ℓ_c, ℓ'_a, ℓ'_b, ℓ'_c`, the
[mixed drift](../outgroup-f3-and-admixed-branches/mixed-drift.md)
`MD(α, ℓ_a, ℓ_b, ℓ_c) = α² ℓ_a + (1 - α)² ℓ_b + ℓ_c` takes the same value at `(ℓ'_a, ℓ'_b, ℓ'_c)` as
at `(ℓ_a, ℓ_b, ℓ_c)` if and only if `ℓ'_c = ℓ_c - α² (ℓ'_a - ℓ_a) - (1 - α)² (ℓ'_b - ℓ_b)`. So each
level set is a plane on which `ℓ'_a` and `ℓ'_b` are free and `ℓ'_c` is determined by them.
