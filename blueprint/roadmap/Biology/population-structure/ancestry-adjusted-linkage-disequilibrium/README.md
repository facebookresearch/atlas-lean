# Ancestry-adjusted linkage disequilibrium

Measures and estimators of linkage disequilibrium that condition on each individual's ancestry, removing the correlation between unlinked sites created by population structure and admixture when the individual parameters capture local ancestry, used for LD pruning and clumping in structured samples.
