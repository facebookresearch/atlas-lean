# Lineage-weight contrasts against a reference population

In a [drift model](../patterson-s-f-statistics/drift-model.md) with finite edge set `E` and lineage
weights `w`, the contrast matrix of populations `L 0, …, L n` is the real matrix with rows
`1 ≤ i ≤ n`, columns the edges `e ∈ E` and entries `C i e = w (L i) e - w (L 0) e`: the lineage
weights of `L 1, …, L n` minus those of the reference `L 0`.
