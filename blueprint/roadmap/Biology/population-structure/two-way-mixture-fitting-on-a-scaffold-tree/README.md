# Two-way mixture fitting on a scaffold tree

Given a tree of approximately unadmixed populations whose branch lengths reproduce pairwise $f_2$ distances, a further population can be modelled as a point mixture of two lineages that split from two branches of the tree. Each such hypothesis implies algebraic relations among $f_2$ statistics, linear in the unknown branch positions once the mixture proportion is fixed, which allows the sources of gene flow and the mixture parameters to be fitted by least squares.
