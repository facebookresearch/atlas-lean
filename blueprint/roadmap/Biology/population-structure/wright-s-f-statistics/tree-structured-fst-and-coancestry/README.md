# Tree-structured F_ST and coancestry

Branch-parameter models in which allele frequencies drift down a rooted population tree, giving closed forms for the correlation-based $F_{ST}^{W}$ (shared ancestry, root to MRCA) and the mismatch-based Hudson $F_{ST}^{H}$ (non-shared ancestry, MRCA to tips), and a fast log least-squares method that estimates both together with the tree, for populations or individual genomes.
