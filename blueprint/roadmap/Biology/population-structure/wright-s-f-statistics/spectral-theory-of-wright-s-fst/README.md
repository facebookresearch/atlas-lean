# Spectral theory of Wright's $F_{ST}$

For a sample drawn from $K$ discrete populations, the centered genotype matrix splits orthogonally into a rank-$(K-1)$ between-population part and a within-population residual. The squared Hilbert–Schmidt norm of the between part is exactly the locus-averaged $F_{ST}$ (scaled genotypes) or $D_{ST}/2$ (unscaled genotypes), which ties principal component analysis eigenvalues to Wright's and Nei's coefficients and extends $F_{ST}$ to adjusted or surrogate genotypes.
