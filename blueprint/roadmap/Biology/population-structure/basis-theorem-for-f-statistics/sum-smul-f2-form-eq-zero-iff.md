# Linear relations among f2 forms and among f2 statistics coincide

Let `s` be a finite set of indices `i`, each with a real coefficient `c i` and populations `A i`,
`B i`. Then the combination of [per-locus f2 forms](f2-form.md) vanishes,
`∑ i ∈ s, c i * (x (A i) - x (B i)) ^ 2 = 0` for every frequency vector `x : P → ℝ`, if and only if
the same combination of [f2 statistics](../patterson-s-f-statistics/f2.md) vanishes,
`∑ i ∈ s, c i * f2(A i, B i) = 0`, for every probability space `(Ω, μ)` and all square-integrable
frequencies `p X : Ω → ℝ`. One direction integrates the forms; the other takes
[Dirac measures](f2-dirac.md).
