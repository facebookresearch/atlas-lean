# A linear relation among all f2 statistics holds among the f2 forms

Let `s` be a finite set of indices `i`, each with a real coefficient `c i` and populations `A i`,
`B i`. If `∑ i ∈ s, c i * f2(A i, B i) = 0` for every probability space `(Ω, μ)` and all
square-integrable frequencies `p X : Ω → ℝ`, where `f2` is the
[f2 statistic](../patterson-s-f-statistics/f2.md) of `p`, then the same combination of
[per-locus f2 forms](f2-form.md) vanishes: `∑ i ∈ s, c i * (x (A i) - x (B i)) ^ 2 = 0` for every
frequency vector `x : P → ℝ`. It suffices to take the [Dirac measure at one point](f2-dirac.md) with
the constant frequencies `x`.
