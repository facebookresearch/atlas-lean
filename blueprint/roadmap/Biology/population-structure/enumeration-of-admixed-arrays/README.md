# Enumeration of admixed arrays

An admixed array pairs a local-ancestry matrix with a genotype matrix over the same haplotype positions. Counting arrays consistent with released summary statistics (per-individual ancestry tallies, per-locus ancestry-specific allele sums) measures how much individual-level information those summaries jointly reveal, and asymptotic enumeration shows when the two summaries narrow the set of configurations independently.
