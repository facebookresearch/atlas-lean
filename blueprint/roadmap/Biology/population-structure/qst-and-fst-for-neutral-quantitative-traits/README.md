# $Q_{ST}$ and $F_{ST}$ for neutral quantitative traits

$Q_{ST}$ measures the proportion of additive genetic variance in a quantitative trait that lies between populations. Under neutral drift with additive gene action it has the same expectation as $F_{ST}$ at the underlying loci, which gives the null expectation for population differences in polygenic traits and polygenic scores.
