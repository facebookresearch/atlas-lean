# Spatially informed multi-omics factor models

Probabilistic factor-analysis models for spatial multi-omics, in which several measured modalities at the same tissue spots share low-dimensional latent factors whose spatial correlation follows a Gaussian-process (kernel) prior over spot coordinates. The Gaussian conjugacy gives closed-form posteriors for the joint latent representation used for spatial-domain detection.
