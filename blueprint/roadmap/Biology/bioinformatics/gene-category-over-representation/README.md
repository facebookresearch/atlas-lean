# Gene category over-representation

Tests of whether a list of genes selected by an experiment (for example, differentially expressed genes on a microarray) contains more members of an annotation category (a Gene Ontology term, pathway or chromosome) than random selection from the assayed genes would give.

- [Hypergeometric over-representation test](hypergeometric-over-representation-test.md)
- [EASE score](ease-score.md)
