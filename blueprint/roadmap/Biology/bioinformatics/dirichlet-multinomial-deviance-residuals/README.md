# Dirichlet–multinomial deviance residuals

Sequencing assays produce sparse count matrices whose per-sample totals are uninformative and whose counts are overdispersed jointly across features. Conditioning independent negative-binomial counts on the sample total yields a Dirichlet–multinomial null, and a fixed-concentration likelihood contrast against that null gives sparse, constant-time residuals that interpolate between multinomial residuals and heavier shrinkage of repeated counts.
