# Metagenomic de Bruijn graph partitioning

Assembly of reads from a mixture of species and subspecies by cutting the de Bruijn graph into
components in which every branch reconverges within a short distance, so that each component
gathers the near-identical genomes of subspecies of one species and can be summarized by a
consensus contig.
