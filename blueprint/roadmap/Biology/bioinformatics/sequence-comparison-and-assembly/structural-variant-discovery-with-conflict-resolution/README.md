# Structural variant discovery with conflict resolution

Discordant paired-end reads that map to many genomic locations are grouped into candidate structural-variant clusters; choosing which clusters to report is a parsimony problem (few variants, many explained reads) constrained by a conflict hypergraph that forbids more than two mutually incompatible variants at a locus of a diploid genome.
