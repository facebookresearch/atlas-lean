# Target–decoy p-values for peptide–spectrum matches

**Setting.** In tandem mass spectrometry, each of $q$ observed spectra $g \in [q]$ is scored against every peptide $P$ in a *target* database $\mathcal{T}$ (real protein sequences) and a *decoy* database $\mathcal{D}$ (e.g. reversed or shuffled sequences that cannot be present), using a score $BF_g(P)$ (in the source, a Bayes factor comparing "spectrum $g$ was generated by $P$" against "spectrum $g$ is noise"). Let

$$z^{(\mathcal{T})}_g = \max_{P \in \mathcal{T}} BF_g(P), \qquad z^{(\mathcal{D})}_g = \max_{P\in\mathcal{D}} BF_g(P),$$

and let $H_g \in \{0,1\}$ indicate whether spectrum $g$ was generated by some peptide of the target database $\mathcal{T}$ ($H_g = 0$: the generating peptide is absent from $\mathcal{T}$). This is database membership, not correctness of the best match: when the generator lies in $\mathcal{T}$ but another target peptide attains $z^{(\mathcal{T})}_g$, the best match is wrong while $H_g = 1$.

**Proposition.** Suppose (i) the triples $(z^{(\mathcal{T})}_g, z^{(\mathcal{D})}_g, H_g)$, $g = 1,\ldots,q$, are i.i.d., and (ii) $z^{(\mathcal{D})}_g \overset{d}{=} \big(z^{(\mathcal{T})}_g \mid H_g = 0\big)$, with continuous distribution function. Then the empirical target–decoy p-value

$$p_g = \frac{1 + \sum_{h=1}^q \mathbf{1}\{z^{(\mathcal{T})}_g \ge z^{(\mathcal{D})}_h\}}{q+1}$$

(written with the score orientation used in the source) is asymptotically uniform under the null:

$$\sup_{u\in[0,1]} \big|\mathbb{P}(p_g \le u \mid H_g = 0) - u\big| = O(q^{-1}).$$

Thus $p_g$ is an approximate p-value for the null hypothesis $H_g = 0$ that spectrum $g$'s generator is not in $\mathcal{T}$, and false discovery rate methods applied to these p-values (Storey's method, in the source) estimate the database-incompleteness local false discovery rate $\mathbb{P}(H_g = 0 \mid \text{data})$. They do not control score-ordering errors, where the generator is in $\mathcal{T}$ but is not the best-scoring target peptide.

## Expansion

Under the null, $z^{(\mathcal{T})}_g$ is exchangeable with the $q$ decoy maxima except for the single decoy $z^{(\mathcal{D})}_g$ from the same spectrum, which is not independent of it; dropping or keeping that one term changes the rank by at most one. The rank of a continuous random variable among $q+1$ exchangeable copies is uniform on $\{1,\ldots,q+1\}$, so $p_g$ is a discretized uniform variable up to an $O(1/q)$ perturbation. The key modelling assumption is (ii): the best decoy score must be distributed like the best target score of a spectrum whose generator is not in $\mathcal{T}$, which is why the score $BF_g$ is built from a noise model calibrated on each spectrum.
