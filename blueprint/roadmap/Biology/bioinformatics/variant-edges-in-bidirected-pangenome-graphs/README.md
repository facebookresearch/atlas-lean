# Variant edges in bidirected pangenome graphs

A pangenome graph stores many haplotypes as walks in a bidirected graph. Choosing a rooted spanning tree (the reference tree) makes the remaining edges a basis of variation: counting how often a haplotype uses each non-tree edge determines the haplotype up to the order of its cycles. These articles set up the definitions and prove reconstruction and locality.
