# Co-orientational order of cytoskeletal fibers

Tissue and cell architecture is organized at several scales: actin fibers, sarcomeric Z-lines, microtubules and cells themselves orient in preferred directions. The orientational order parameter from liquid-crystal theory measures how consistently one family of fibers is aligned; the co-orientational order parameter extends it to two co-localized fiber families and measures how consistently their orientations are correlated, with explicit reference values for independent and noisily coupled families.
