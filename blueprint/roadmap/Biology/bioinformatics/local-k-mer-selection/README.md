# Local k-mer selection

Sketching methods for long-read mapping keep only a subset of k-mers of a sequence. Local methods (minimizers, syncmers, word-based rules) decide from a bounded window of the sequence, so shared regions select the same k-mers; their density, spread and conservation under mutation can be computed exactly for random strings.
