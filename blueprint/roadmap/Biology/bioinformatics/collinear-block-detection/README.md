# Collinear block detection

Collinear blocks are runs of homologous gene pairs that appear in the same order (or the same reversed order) on two chromosomal regions, the footprint of segmental or whole-genome duplication and of conserved synteny between species. They are found by chaining matched gene pairs with dynamic programming over gene orders.
