# Gamma-structures of RNA-RNA interactions

Topological classification of RNA-RNA interaction structures over two backbones: an interaction structure is a $\gamma$-structure when every irreducible shadow it contains has genus at most $\gamma$. For fixed $\gamma$ there are finitely many irreducible building blocks, which yields unambiguous grammars and polynomial-time partition-function algorithms for interaction structures of unbounded total genus.
