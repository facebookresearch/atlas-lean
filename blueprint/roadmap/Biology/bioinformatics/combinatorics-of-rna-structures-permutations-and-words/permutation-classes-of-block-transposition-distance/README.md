# Permutation classes of block transposition distance

Genome rearrangement by block transpositions (exchanging two adjacent segments) and prefix block transpositions (the first segment starts at position 1). For each $k$, the permutations within distance $k$ of the identity form a permutation class; it is the union of inflation-closures of finitely many generating permutations, and its basis has bounded length.
