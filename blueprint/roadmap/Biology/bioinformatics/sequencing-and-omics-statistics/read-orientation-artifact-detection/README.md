# Read-orientation artifact detection

Statistics that separate library-preparation artifacts from true low-allelic-fraction mutations in paired-end sequencing by exploiting the read in which a base change is observed, which is balanced for real variants and strongly biased for damage-induced artifacts such as 8-oxoguanine.
