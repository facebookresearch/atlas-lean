# k-noncrossing RNA structures with minimum arc length

Enumeration of RNA pseudoknot structures modeled as $k$-noncrossing diagrams (at most $k-1$ mutually crossing arcs) in which no base pairs with its two nearest neighbors (arc length at least 3), via a functional equation linking their generating function to that of $k$-noncrossing perfect matchings and singularity analysis.
