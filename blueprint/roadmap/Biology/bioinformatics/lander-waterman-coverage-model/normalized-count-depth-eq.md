# Exact depth law

For $L \le G$, every base $x$ and every natural number $k$, the [normalized count](normalized-count.md) of the start tuples for which the [depth](depth.md) of $x$ is $k$ is

$$\binom{N}{k} \Bigl(\frac{L}{G}\Bigr)^k \Bigl(1 - \frac{L}{G}\Bigr)^{N - k},$$

with truncated subtraction $N - k$.
