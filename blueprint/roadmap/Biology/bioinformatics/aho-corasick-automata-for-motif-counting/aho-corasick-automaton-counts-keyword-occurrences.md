# Aho–Corasick automaton counts keyword occurrences

**Definition.** Let $\mathcal{A}$ be a finite alphabet and $\mathcal{W} \subset \mathcal{A}^*$ a finite nonempty set of keywords (for example all RNA strings matching a base-pairing motif). The Aho–Corasick automaton $AC(\mathcal{W}) = (V, \mathcal{A}, q, f, T)$ has state set $V$ consisting of the empty string $\epsilon$ and all prefixes of words in $\mathcal{W}$, initial state $q = \epsilon$, accepting set $T = \mathcal{W}$, and transition function defined by the longest-prefix-suffix rule: for $u, v \in V$ and $\alpha \in \mathcal{A}$,

$$f(u, \alpha) = v \iff v \text{ is the longest element of } V \text{ such that } u\alpha \text{ ends with } v.$$

Extend $f$ to words letter by letter.

**Lemma.** For every $x \in \mathcal{A}^*$, $f(q, x) = u$ if and only if $u$ is the longest element of $V$ that is a suffix of $x$.

**Theorem.** For $w \in \mathcal{W}$ let $T(w) = \{u \in \mathcal{W} : u \text{ ends with } w\}$. For every $w \in \mathcal{W}$ and $x \in \mathcal{A}^*$, $w$ occurs exactly $m$ times as a substring of $x$ (overlaps counted) if and only if the path of states visited by $AC(\mathcal{W})$ while reading $x$ enters the set $T(w)$ exactly $m$ times.

## Expansion

By the lemma, after reading a prefix $y$ of $x$ the automaton sits at the longest keyword prefix that is a suffix of $y$. An occurrence of $w$ ending at that position means $w$ is a suffix of $y$; since $w \in V$, the current state is at least as long as $w$ and also ends with $w$, and because it is a suffix of $y$ ending in a full keyword it lies in $T(w)$. Conversely, a state in $T(w)$ ends with $w$, so $w$ ends at that position. Counting occurrences therefore reduces to counting visits to a set of states. When $x$ is generated by a memoryless (i.i.d.) source, the state sequence is a homogeneous Markov chain with transition matrix $P = \sum_{\alpha} \Pr(\alpha)\, G_\alpha$, where $G_\alpha(u,v) = [f(u,\alpha) = v]$ (Markov chain embedding), so occurrence counts of several overlapping motifs can be studied with transfer matrices and generating functions.
