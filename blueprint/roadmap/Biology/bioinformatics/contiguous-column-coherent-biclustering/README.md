# Contiguous column coherent biclustering

In a discretized gene expression time series, a contiguous column coherent (CCC) bicluster is a set of genes sharing the same symbol string over a run of consecutive time points. Restricting to contiguous columns turns the NP-hard general biclustering problem into a string problem: maximal CCC-biclusters correspond to special nodes of a generalized suffix tree, and biclusters with a bounded number of errors per gene can be enumerated in polynomial time.
