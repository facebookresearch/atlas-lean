# Unitig safety and bidirected de Bruijn graphs

Unitigs, maximal non-branching paths of a de Bruijn graph, are the basic output of most assemblers and are usually assumed to be correct. With error-free reads but incomplete coverage a unitig can still spell a string absent from the genome; and modelling double-strandedness with a bidirected graph splits palindromic unitigs in half. Both artifacts admit exact combinatorial characterizations.
