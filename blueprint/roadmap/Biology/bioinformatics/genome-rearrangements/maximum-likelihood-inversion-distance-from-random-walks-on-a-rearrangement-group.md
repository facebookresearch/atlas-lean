# Maximum likelihood inversion distance from random walks on a rearrangement group

**Model.** Fix a reference genome with $N$ regions. Genome arrangements reachable by reversible rearrangements (e.g. inversions of adjacent segments on a circular chromosome) are elements of a permutation group $\mathcal{G}$ generated by a set $\mathcal{S}$ of $n = |\mathcal{S}|$ rearrangement events. Evolution is a random walk on the Cayley graph: events occur as a Poisson process with $\lambda = rT$ expected events, each a uniformly chosen generator. Let $\alpha_i(g)$ be the number of length-$i$ walks from the identity $e$ to $g$ (computable by the recursion $\alpha_{i+1}(g) = \sum_{s\in\mathcal{S}}\alpha_i(gs^{-1})$).

**Likelihood.** The likelihood of $\lambda$ for an observed arrangement $g$ is

$$L(\lambda \mid g) = \sum_{i\ge0}\frac{e^{-\lambda}\lambda^i}{i!}\,\frac{\alpha_i(g)}{n^i},$$

and the maximum likelihood estimate $\hat\lambda_g$ is a corrected rearrangement distance. Since physical genomes have no preferred orientation or starting point, a genome is the coset $gD_N$ under the dihedral group, and because $D_N$ normalises $\mathcal{S}$,

$$L(\lambda \mid gD_N) = \sum_{d\in D_N}L(\lambda \mid gd).$$

For example, for a circular genome with three regions and adjacent-pair inversions ($\mathcal{G} = S_3$, $\mathcal{S} = \{(12),(23),(31)\}$): $L(\lambda \mid e) = \frac{e^{-\lambda}}{3}(2 + \cosh\lambda)$, $L(\lambda \mid (12)) = \frac{e^{-\lambda}}{3}\sinh\lambda$, $L(\lambda \mid (123)) = \frac{e^{-\lambda}}{3}(\cosh\lambda - 1)$.

**Proposition.** Let $N_{\mathcal{G}}(\mathcal{S}) = \{h : h^{-1}\mathcal{S}h = \mathcal{S}\}$ be the normaliser of the generating set. If $g_1 = h^{-1}g_2h$ for some $h \in N_{\mathcal{G}}(\mathcal{S})$, then $L(\lambda \mid g_1) \equiv L(\lambda \mid g_2)$, hence $\hat\lambda_{g_1} = \hat\lambda_{g_2}$.

**Non-monotonicity relative to minimal distance.** Because $\mathcal{G}$ is non-abelian, different elements at the same minimal distance $d_{\min}$ have very different walk counts, and the MLE can reverse the order induced by the minimal distance: there are pairs with $d_{\min}(g_1) > d_{\min}(g_2)$ but $\hat\lambda_{g_1} < \hat\lambda_{g_2}$ (e.g. $d_{\min}((2,7,6,5,3)) = 6 < 7 = d_{\min}((2,3)(4,6)(7,9))$ with reversed MLE order).

## Proof sketch

Conditioning on the number $i$ of events gives the Poisson mixture, and uniform choice of events makes each length-$i$ walk equally likely, so $\Pr(g \mid i) = \alpha_i(g)/n^i$. Conjugation by $h \in N_{\mathcal{G}}(\mathcal{S})$ is a graph automorphism of the Cayley graph fixing $e$, mapping walks of length $i$ to walks of length $i$ bijectively, so walk counts and likelihoods agree; the same argument lets walks between two cosets be counted from a single representative. The MLE accounts for the many paths to a genome (saturation), which the minimal distance ignores, and the coset-MLE changes reconstructed phylogenies relative to minimal-distance methods.
