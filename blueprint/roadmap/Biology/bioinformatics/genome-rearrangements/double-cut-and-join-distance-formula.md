# Double-cut-and-join distance formula

This node covers the following result. Let $A$ and $B$ be two genomes defined on the same set of $N$ genes. Then the double-cut-and-join distance is $d_{\mathrm{DCJ}}(A,B) = N - (C + I/2)$, where $C$ is the number of cycles and $I$ the number of odd paths in the adjacency graph $AG(A,B)$. An optimal sorting sequence can be found in $O(N)$ time.
