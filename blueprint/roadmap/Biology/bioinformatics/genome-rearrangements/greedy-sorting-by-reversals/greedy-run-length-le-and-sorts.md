# The greedy algorithm sorts within `φ(π)` reversals

**The greedy algorithm sorts within `φ(π)` reversals** (Kececioglu–Sankoff 1995,
Theorem 1). For every unsigned permutation `π` of `1, …, n` (`UValid n π`), every greedy run
from `π` has at most `ubreaks n π` reversals, and some greedy run from `π` ends at the
identity.

## Sources

- J. Kececioglu and D. Sankoff, Algorithmica 13 (1995) 180-210, Theorem 1.
- J. Kececioglu and D. Sankoff, author's copy of the same paper (revised 19 February 1993), Theorem 1, p. 8, <https://www.cs.arizona.edu/~kece/Research/papers/KS95.ps>.
