# Linear chord diagrams of fixed genus

Topological enumeration of RNA structures with pseudoknots: linear chord diagrams filtered by the genus of their fatgraph, a three-term genus recursion from the Harer–Zagier formula, algebraic generating functions with a genus-independent singularity, and the extension to macromolecular diagrams with minimum helix length.
