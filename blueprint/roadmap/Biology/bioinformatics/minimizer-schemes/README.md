# Minimizer schemes

Sampling schemes that select one $k$-mer from every window of $w$ consecutive $k$-mers of a sequence, used to build compact indexes and sketches for read mapping and assembly. The key quantity is the density, the expected fraction of positions selected on a random sequence; universal sets of $k$-mers in the de Bruijn graph control the density of minimizer orders.
