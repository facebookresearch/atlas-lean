# Longest run subsequence for contig scaffolding

The Longest Run Subsequence problem models scaffolding of genome assemblies against a related assembly: binned contigs are mapped to contigs of the other assembly, and the most consistent partition is a longest subsequence in which every target contig forms a single run. The articles cover the problem and its parameterized and approximation complexity.
