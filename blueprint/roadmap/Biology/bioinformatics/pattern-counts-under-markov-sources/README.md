# Pattern counts under Markov sources

Exact distribution of the number of occurrences of a pattern (a finite set of words or a regular expression, such as a PROSITE signature or a transcription-factor site) in random biological sequences generated by a homogeneous or heterogeneous Markov model. Embedding the pattern in a minimal deterministic automaton turns the count into an additive functional of a finite Markov chain whose generating function is a matrix product.
