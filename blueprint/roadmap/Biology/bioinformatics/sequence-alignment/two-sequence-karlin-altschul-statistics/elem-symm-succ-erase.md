# Splitting one index off an elementary symmetric sum

For a finite set `D`, an element `i ∈ D`, real values `f` and a natural number `k`, the
[elementary symmetric sums](elem-symm.md) satisfy
`e_{k+1}(D) = e_{k+1}(D ∖ {i}) + f(i) e_k(D ∖ {i})`, where `e_k(D)` denotes the sum over the
`k`-element subsets of `D`.
