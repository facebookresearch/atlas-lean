# Error bounds in a Newton-type recursion for elementary symmetric sums

For a finite set `D`, real values `f(i) ≥ 0` for `i ∈ D`, a real `μ` with `f(i) ≤ μ` for every
`i ∈ D`, and a natural number `k`, put `σ = ∑_{i ∈ D} f(i)`. Then the
[elementary symmetric sums](elem-symm.md) satisfy
`0 ≤ σ e_{k+1}(f) - (k + 2) e_{k+2}(f) ≤ μ σ e_k(f)`: the error of the recursion
`(k + 2) e_{k+2} ≈ σ e_{k+1}` is nonnegative and at most `μ σ e_k`.
