# First lattice point strictly above a threshold

For real numbers `h` and `t`, the lattice point above `t` is `t⁺ = (⌊t / h⌋ + 1) h`. For `h > 0` it
is the smallest point of the lattice `hℤ` strictly greater than `t`. The definition is total: with
the convention `x / 0 = 0` it is `0` when `h = 0`, and for `h < 0` it is a point of `hℤ` in
`[t + h, t)`. The intended domain is `h > 0`.
