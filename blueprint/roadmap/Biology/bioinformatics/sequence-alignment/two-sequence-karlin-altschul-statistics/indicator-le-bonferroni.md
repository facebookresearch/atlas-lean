# Bonferroni inequality of even order for a count

For all natural numbers `W` and `r`, `1[W = 0] ≤ ∑_{k=0}^{2r} (-1)^k C(W, k)`, where `1[W = 0]` is
`1` if `W = 0` and `0` otherwise. Taking expectations for a random count `W` gives the
Bonferroni inequality `P(W = 0) ≤ ∑_{k=0}^{2r} (-1)^k E[C(W, k)]`.
