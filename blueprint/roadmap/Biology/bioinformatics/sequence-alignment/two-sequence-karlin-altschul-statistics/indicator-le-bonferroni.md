# Bonferroni inequality of even order for a count

For all natural numbers `W` and `r`, `1[W = 0] ≤ ∑_{k=0}^{2r} (-1)^k C(W, k)`, where `1[W = 0]` is
`1` if `W = 0` and `0` otherwise. For a random count `W` that is bounded, such as the number of
exceeding diagonals of a finite grid, or whose factorial moments `E[C(W, k)]` are finite for
`k ≤ 2r`, taking expectations gives the Bonferroni inequality
`P(W = 0) ≤ ∑_{k=0}^{2r} (-1)^k E[C(W, k)]`. Without such a condition the terms need not be
integrable and the expected inequality can fail.
