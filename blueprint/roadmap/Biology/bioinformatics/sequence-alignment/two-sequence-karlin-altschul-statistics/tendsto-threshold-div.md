# The logarithmic threshold is negligible against the length m

Let `m_N` and `n_N` be natural numbers with `m_N → ∞`, `n_N → ∞` and `log n_N / m_N → 0`, and let
`θ` and `x` be real. Then `(log(m_N n_N) / θ + x) / m_N → 0`: the threshold
`t_N = log(m_N n_N) / θ + x` is `o(m_N)`. This holds for every real `θ`; at `θ = 0` the convention
`y / 0 = 0` makes `t_N = x`. Only large `N` matter, where `m_N, n_N ≥ 1`, so the conventions
`log 0 = 0` and `y / 0 = 0` at `m_N = 0` or `n_N = 0` play no role.
