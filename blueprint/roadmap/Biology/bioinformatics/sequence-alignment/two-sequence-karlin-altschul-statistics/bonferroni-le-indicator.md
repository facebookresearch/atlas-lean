# Bonferroni inequality of odd order for a count

For all natural numbers `W` and `r`, `∑_{k=0}^{2r+1} (-1)^k C(W, k) ≤ 1[W = 0]`, where `1[W = 0]`
is `1` if `W = 0` and `0` otherwise. Taking expectations for a random count `W` gives the
Bonferroni inequality `∑_{k=0}^{2r+1} (-1)^k E[C(W, k)] ≤ P(W = 0)`.
