# Gotoh table row of the empty first suffix

The first row for a sequence $y$ is defined recursively: for empty $y$ it is the single triple $(0, 0, 0)$; for $y = b y'$ it is $(r_Y + o,\ r_Y + o,\ r_Y + e)$ followed by the first row $r, \dots$ of $y'$, where $r = (r_M, r_X, r_Y)$ is its first triple ($(0, 0, 0)$ if it is empty).
