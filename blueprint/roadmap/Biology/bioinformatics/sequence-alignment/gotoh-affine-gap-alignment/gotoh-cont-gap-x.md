# Gotoh continuation value after a gap in the second sequence

The value $X(x, y) = G_{|x| + |y|}(x, y, X)$, where $G$ is the [fuel-bounded recursion](gotoh-aux.md): the best affine score of an alignment of $x$ and $y$ given that the previous column was a gap in the second sequence. The first column is unrestricted; the previous state only makes a following gap in the second sequence cost $e$ instead of $o$.
