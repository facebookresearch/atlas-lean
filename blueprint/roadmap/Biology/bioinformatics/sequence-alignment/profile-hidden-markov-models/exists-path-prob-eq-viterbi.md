# The Viterbi value is attained

For every profile HMM with weights in a linearly ordered semiring and every sequence $x$, some [alignment](../pair-hidden-markov-models/alignments-of.md) of $x$ to the columns has [path weight](path-prob.md) equal to the [Viterbi value](viterbi.md). Without nonnegative weights this does not make it the largest path weight.
