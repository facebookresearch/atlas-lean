# The first m excursion heights are at most t with probability F(t)^m

For a probability measure `P`, a [ladder input](ladder-input.md) under `P` with excursion heights
`Y i` and distribution function `F`, a natural number `m` and a real `t`,
`P(Y 0 ≤ t, …, Y (m - 1) ≤ t) = F(t)^m`, by independence.
