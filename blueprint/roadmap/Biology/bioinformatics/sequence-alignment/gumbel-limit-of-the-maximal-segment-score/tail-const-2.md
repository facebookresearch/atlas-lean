# Excursion-height renewal constant, lattice case

For [lattice ladder renewal data](lattice-ladder-renewal-data.md) with root `θ`, span `h`,
descending-ladder value `D` and [lattice Cramér–Lundberg constant](all-time-const-2.md) `C_∞`, the
lattice excursion-height renewal constant is `C = e^{θ h} C_∞ (1 - E e^{θ D})`, in the
normalization `P(Y > k h) ~ C e^{-θ (k + 1) h}` of a
[lattice renewal input](lattice-renewal-input.md). Here `E e^{θ D} = ∫ e^{θ D} dP` is `0` by
convention when `e^{θ D}` is not integrable; for a probability measure `P` and `θ ≥ 0` it lies in
`(0, 1]`, since `D ≤ 0` almost surely, and the intended case is `θ > 0`.
