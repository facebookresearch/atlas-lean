# Lattice excursion heights have a stepwise distribution function

For a probability measure `P`, a [ladder input](ladder-input.md) under `P` whose excursion heights
`Y i` lie almost surely on the lattice `hℤ` for some `h > 0`, and every real `t`, the distribution
function satisfies `F(t) = F(⌊t / h⌋ h)`: it is constant on each cell `[k h, (k + 1) h)`.
