# Cramér scores admit a ladder input

For scores `X 0, X 1, …` on `(Ω, P)` satisfying the [Cramér conditions](cramer-scores.md), that is
i.i.d. scores with negative mean and a root `θ > 0` of `E e^{θ X} = 1`, there is a
[ladder input](ladder-input.md) for their [maximal segment scores](max-segment-score-rv.md), as
assumed by the Gumbel-tail theorems ([construction](to-ladder-input.md)).
