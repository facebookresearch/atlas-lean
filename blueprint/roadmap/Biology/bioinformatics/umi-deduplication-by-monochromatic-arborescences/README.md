# UMI deduplication by monochromatic arborescences

Droplet single-cell RNA-seq tags each captured molecule with a short unique molecular identifier (UMI); PCR duplicates and UMI sequencing errors must be collapsed to count molecules. Encoding each (UMI, transcript equivalence class) pair as a vertex of a directed graph turns parsimonious deduplication into covering that graph by the fewest arborescences that share a transcript label.
