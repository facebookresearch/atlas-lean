# Circular sequence comparison

Circular genomes (mitochondrial DNA, plasmids, many viral and bacterial genomes) have no canonical start, so comparing two of them means optimizing over all rotations of one sequence. Alignment-free distances built from $q$-gram profiles, made local by splitting sequences into blocks, allow the best rotation to be found exactly in near-linear time.
