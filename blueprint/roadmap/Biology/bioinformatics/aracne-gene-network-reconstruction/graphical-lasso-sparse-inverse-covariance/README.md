# Graphical lasso for sparse inverse covariance estimation

$L_1$-penalized Gaussian maximum likelihood for the precision matrix, whose zero pattern is the conditional-independence graph of the variables (gene networks, cell-signalling networks), and the blockwise coordinate-descent algorithm that solves it through a sequence of coupled lasso regressions.
