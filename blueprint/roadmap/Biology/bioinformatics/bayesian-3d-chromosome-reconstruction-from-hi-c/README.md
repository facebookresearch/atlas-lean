# Bayesian 3D chromosome reconstruction from Hi-C

Reconstruction of a consensus three-dimensional chromatin conformation from a Hi-C contact matrix
by treating loci as beads in space and modelling contact counts as Poisson variables whose rate
decreases with spatial distance and is corrected for local sequence biases.
