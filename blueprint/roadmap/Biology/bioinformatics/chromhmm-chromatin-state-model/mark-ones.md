# Expected number of bins in a state with a mark present

For $T$, sequences $x^{(1)}, \dots, x^{(N)}$ of mark vectors, a [valid parameter](valid.md) $\theta$, a state $s$ and a mark $j$, put $m_1(s, j) = n_1(E_s, j)$, where $E_s(o)$ is the expected number of emissions of $o$ from $s$ (summed over sequences and times, under the posterior of the state paths given each sequence) and $n_1$ the [weight with mark present](ones-count.md).
