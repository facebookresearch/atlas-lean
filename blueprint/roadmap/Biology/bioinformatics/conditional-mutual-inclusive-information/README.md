# Conditional mutual inclusive information

Association measures for gene regulatory network inference that sit between mutual information, which also counts indirect regulation, and conditional mutual information, which can vanish for a true regulation when a third gene is nearly collinear with one of the pair. The measure is built from Kullback–Leibler divergences to interventional distributions that delete one directed edge.
