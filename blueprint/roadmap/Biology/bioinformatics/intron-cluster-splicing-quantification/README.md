# Intron-cluster splicing quantification

Annotation-free quantification of alternative splicing from RNA-seq split reads: introns are grouped into clusters that share splice sites, and intron usage within a cluster is modelled with a Dirichlet-multinomial generalized linear model to test for differential splicing across conditions or genotypes.
