# Ranges of optimal transcript abundance under nonidentifiability

When RNA-seq quantification has many equally likely abundance estimates, each transcript or splicing pattern has a range of optimal expression. It is computed by linear programming in the reference-transcript model and by maximum flow over all decompositions of the splice-graph flow.
