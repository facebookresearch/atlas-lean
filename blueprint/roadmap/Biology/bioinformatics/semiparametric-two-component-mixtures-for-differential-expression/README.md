# Semiparametric two-component mixtures for differential expression

Two-group models for gene-level $z$-scores: a standard normal null component for non-differentially expressed genes and an alternative component that is a skew-normal scale mixture with a nonparametric mixing distribution, allowing skewed and heavy-tailed effect distributions. Identifiability and consistency of the maximum likelihood estimator justify local-FDR based gene selection.
