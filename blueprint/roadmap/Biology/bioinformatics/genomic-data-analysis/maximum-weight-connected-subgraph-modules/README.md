# Maximum-weight connected subgraph modules

Functional modules in a protein–protein interaction network can be defined as connected subnetworks whose genes are jointly enriched for small p-values. Fitting a beta-uniform mixture to the p-values yields an additive log-likelihood-ratio node score with an FDR-interpretable threshold, and the best-scoring module is a maximum-weight connected subgraph, which can be solved to provable optimality through a reduction to the prize-collecting Steiner tree problem.
