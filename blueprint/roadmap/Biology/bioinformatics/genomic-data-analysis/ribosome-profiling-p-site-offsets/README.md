# Ribosome profiling P-site offsets

Locating the ribosomal P-site within sequenced ribosome-protected fragments: length-specific
offsets estimated from read-end occupancy around annotated start codons, a correction step that
makes offsets of rare read lengths coherent with the dominant population, and a periodicity score
that checks the resulting positions.
