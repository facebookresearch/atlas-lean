# Read-based single-individual haplotyping

Single-individual haplotyping phases the heterozygous sites of one diploid genome from sequencing reads that each cover several sites, without a reference panel. Every read carries alleles from one of the two parental chromosomes, so phasing amounts to partitioning reads into two groups and choosing complementary haplotypes that explain them with as few sequencing errors as possible.
