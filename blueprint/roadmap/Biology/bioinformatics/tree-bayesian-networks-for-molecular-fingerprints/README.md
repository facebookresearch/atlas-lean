# Tree Bayesian networks for molecular fingerprints

In small-molecule identification from tandem mass spectra, a predicted molecular fingerprint gives marginal probabilities of binary structural properties. Dependencies between properties are modelled by a tree-structured Bayesian network whose edge distributions are reconstructed from the marginals and a target covariance, then used to score candidate structures.
