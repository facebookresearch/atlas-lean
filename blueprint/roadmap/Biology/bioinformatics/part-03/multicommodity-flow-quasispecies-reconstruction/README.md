# Multicommodity-flow quasispecies reconstruction

An RNA virus persists in a host as a cloud of closely related variants (quasispecies). Reconstructing full-length variants and their frequencies from overlapping amplicon reads can be posed as covering a staged read graph with few unsplittable source–sink flows, one commodity per variant.
