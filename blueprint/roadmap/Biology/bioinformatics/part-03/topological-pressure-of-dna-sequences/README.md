# Topological pressure of DNA sequences

Thermodynamic-formalism statistics for genomic sequences: the topological pressure of a finite DNA word weights each occurring codon-length subword by a trained potential, and its equilibrium (Gibbs) measure, a second-order Markov chain built from a Perron–Frobenius eigenvector, scores coding potential and tracks coding sequence density along chromosomes.
