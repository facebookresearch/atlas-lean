# Haplotype-aware alignment to pangenome graphs

A pangenome graph built from haplotype-resolved assemblies records which haplotypes traverse each vertex. Haplotype-aware alignment and chaining treat a query as an imperfect mosaic of the known haplotypes, in the spirit of the Li–Stephens copying model, and penalize switches between haplotypes (recombinations) along the alignment path.
