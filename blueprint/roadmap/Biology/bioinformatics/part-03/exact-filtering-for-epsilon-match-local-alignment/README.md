# Exact filtering for ε-match local alignment

An ε-match is a local alignment whose edit-distance error rate is at most ε and whose length is at least a minimum. Combining a q-gram parallelogram filter with verification started from error-free seeds whose length is guaranteed by a pigeonhole argument yields a local aligner with full sensitivity for maximal ε-matches.
