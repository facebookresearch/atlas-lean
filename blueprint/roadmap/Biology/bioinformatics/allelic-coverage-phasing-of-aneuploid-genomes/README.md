# Allelic-coverage phasing of aneuploid genomes

In cancer genomes, copy-number imbalance between homologs makes allele-specific read coverage informative about phase. This topic covers likelihood-based coverage matching weights between SNP alleles and the complexity of the constrained graph cut that assembles haplotype fragments from them.
