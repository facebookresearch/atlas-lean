# Intermediate genomes under double-cut-and-join

An intermediate genome of two gene orders is one that lies on some shortest rearrangement path between them. Under the double-cut-and-join (DCJ) model, intermediate genomes reachable by sorting each breakpoint-graph component independently have an exact combinatorial description as non-crossing chord diagrams, and are counted by products of Catalan numbers; this underlies parsimonious ancestral gene-order reconstruction.
