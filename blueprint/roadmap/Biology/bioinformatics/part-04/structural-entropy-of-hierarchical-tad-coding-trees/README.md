# Structural entropy of hierarchical TAD coding trees

Hierarchical topologically associated domains (TADs) inferred from a Hi-C contact matrix by viewing it as a weighted graph on genomic bins and choosing a tree of nested intervals of consecutive bins (a coding tree) of minimum structural entropy. Refinement and binarization never increase the entropy, so optimal trees are found by interval dynamic programming once the number of leaves (or the height) is fixed.
