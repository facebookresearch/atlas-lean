# Fusion, fission and block-interchange distance

Genome rearrangement distance between circular multi-chromosomal genomes, modelled as permutations whose cycles are chromosomes, when the allowed events are chromosome fusions, fissions and block-interchanges; the distance has a closed formula in cycle counts and an optimal canonical-order scenario.
