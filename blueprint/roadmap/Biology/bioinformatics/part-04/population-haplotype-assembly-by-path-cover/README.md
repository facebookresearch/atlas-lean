# Population haplotype assembly by path cover

Assembling an unknown number of haplotypes from reads of a pooled sample. Reads that disagree at a shared SNP cannot come from the same haplotype; the minimum number of haplotypes is the chromatic number of this conflict graph, which for interval-like read sets equals a minimum path cover of a transitive compatibility order and is computed by bipartite matching.
