# LD-based haplotype blocks

Partitioning a chromosome into blocks of SNPs in strong pairwise linkage disequilibrium, following the confidence-interval criterion of Gabriel et al. A signed weight per SNP pair turns the block condition into a nonnegative running sum, which allows linear-memory, pruned scans that reproduce the classical partition exactly.
