# Ordered Jaccard index for segmental duplications

Detecting segmental duplications (long, low-copy paralogous repeats) from k-mer similarity, using a colinear version of the Jaccard index that coincides with the classical one under the standard duplication-then-mutation error model and is computable by a linear scan.
