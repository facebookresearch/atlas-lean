# MicroRNA target-site efficacy regression

Quantitative prediction of how strongly a seed-matched microRNA site represses its mRNA, by
site-type-specific multiple linear regression on normalized sequence, structural and conservation
features, with additive aggregation of site scores per 3' UTR.

- [Context++ regression model of microRNA site efficacy](context-plus-plus-regression-model-of-microrna-site-efficacy.md)

## Sources
