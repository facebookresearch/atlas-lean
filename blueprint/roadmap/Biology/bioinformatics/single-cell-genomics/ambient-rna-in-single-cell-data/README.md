# Ambient RNA in single-cell data

Droplet and microwell single-cell assays capture extracellular "ambient" RNA alongside each cell's own transcripts. Modelling the ambient profile and each cell's contamination fraction turns the detection of a rare transcript class, such as viral RNA, into a per-cell binomial test with a controlled false-positive rate.
