# Negative binomial gamma mixed model

Count models for multi-subject single-cell RNA-seq data in which cell-level counts are negative binomial and a gamma-distributed subject-level random effect captures between-individual overdispersion, chosen so that part of the marginal likelihood is available in closed form.
