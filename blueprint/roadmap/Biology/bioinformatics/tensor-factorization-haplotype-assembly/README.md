# Tensor-factorization haplotype assembly

Haplotype assembly reconstructs the $k$ chromosome copies of a diploid or polyploid individual from sequencing reads that each cover a few variant sites. Encoding alleles as one-hot fibres of a binary tensor turns the minimum error correction (MEC) criterion into a constrained low-rank matrix completion problem, solvable by alternating minimization with recovery guarantees.
