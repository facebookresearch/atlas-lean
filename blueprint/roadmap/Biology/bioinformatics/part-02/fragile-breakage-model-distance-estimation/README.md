# Distance estimation under the fragile breakage model

Under the fragile breakage model, genome rearrangements reuse a limited set of fragile regions, so the parsimonious DCJ distance underestimates the true number of rearrangements once breakpoints are reused. For $k=\gamma n/2$ random DCJs on $n$ fragile regions, the cycle lengths of the breakpoint graph follow the Borel distribution; inverting the expected ratio of DCJ distance to broken regions recovers $\gamma$, and hence both the true distance and the hidden number of fragile regions.
