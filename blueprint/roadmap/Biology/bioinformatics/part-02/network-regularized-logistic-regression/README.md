# Network-regularized logistic regression

To select interpretable, network-connected biomarkers from high-dimensional expression data, logistic regression can be penalized by a lasso term plus a quadratic form in the normalized Laplacian of a gene interaction network. The resulting convex estimator groups the coefficients of correlated neighboring genes, and its regularization path starts at an explicit value of the penalty.
