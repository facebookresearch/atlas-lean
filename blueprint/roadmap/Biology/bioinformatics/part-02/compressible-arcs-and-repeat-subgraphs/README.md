# Compressible arcs and repeat subgraphs

In a de Bruijn graph of reads, an arc is compressible when it is the only way out of its tail and the only way into its head; subgraphs generated by high-copy repeats contain few such arcs, which characterizes repeats topologically but makes finding them NP-complete.
