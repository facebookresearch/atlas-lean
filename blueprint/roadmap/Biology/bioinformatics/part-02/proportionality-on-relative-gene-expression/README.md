# Proportionality on relative gene expression

Log-ratio measures of gene-gene proportionality for compositional expression data (RNA-seq read fractions without absolute normalization). The proportionality coefficient scales the log-ratio variance by the summed variances of the pair; on relative data those variances depend on the log-ratio reference, which can create spurious proportionality.
