# Minimum flow decomposition in graphs with cycles

Exact integer-linear-programming formulations of minimum flow decomposition (writing an integer flow as a minimum number of weighted source-to-sink paths, trails or walks) for flow networks that may contain cycles, as arise in RNA transcript assembly and viral quasispecies graphs. The key ingredient is an Euler-type characterization of which edge multisets can be ordered into one $s$-$t$ trail or walk.
