# Pseudobulk differential expression

In multi-subject single-cell RNA-seq, cells from one subject are correlated replicates. A three-stage gamma–gamma–Poisson hierarchy separates subject-level, cell-level and technical variation and shows that summing counts over cells within a subject yields approximately negative binomial pseudobulk counts, justifying bulk methods for differential expression between subject groups.
