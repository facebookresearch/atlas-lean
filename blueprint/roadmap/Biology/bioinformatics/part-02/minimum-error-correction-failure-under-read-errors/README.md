# Minimum error correction failure under read errors

Minimum error correction (MEC) is the standard objective for assembling the two haplotypes of a diploid from aligned sequencing reads. Its minimizer need not be the true haplotype pair: once more than half of the reads covering a heterozygous site carry an allele-swapping error at that site, a haplotype differing from the truth has strictly smaller MEC. Under independent errors this gives a closed form for the probability that this failure mode is avoided, as a function of the error rate and per-site coverage.
