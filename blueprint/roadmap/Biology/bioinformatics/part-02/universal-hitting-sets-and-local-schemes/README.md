# Universal hitting sets and local schemes

Local and forward schemes sample one position per window of $w$ characters, generalizing minimizers used to sketch sequencing data; their density, the fraction of positions sampled, governs index size. Low-density schemes correspond to small universal hitting sets in the de Bruijn graph that leave only short paths unhit, which yields near-optimal schemes and polynomial path bounds for the Mykkeltveit decycling sets.
