# Local similarity analysis of time series

Local similarity analysis scores pairs of equally spaced biological time series (for example microbial abundances or gene expression profiles) for possibly lagged, locally concentrated co-variation, using a Smith–Waterman-style dynamic program on products of standardized values. Its null distribution is governed by maxima of partial sums, which yields an analytic upper bound on the p-value that replaces permutation testing.
