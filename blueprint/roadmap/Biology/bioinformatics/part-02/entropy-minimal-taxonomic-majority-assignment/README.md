# Entropy-minimal taxonomic majority assignment

An assembled contig carries several gene-level taxonomic annotations, often scattered over a taxonomy tree. Instead of taking their lowest common ancestor (too conservative) or a plain plurality (often weakly supported), one can collapse annotations up the tree just enough to obtain a qualified majority, choosing the collapse that changes the Shannon entropy of the annotation distribution the least.
