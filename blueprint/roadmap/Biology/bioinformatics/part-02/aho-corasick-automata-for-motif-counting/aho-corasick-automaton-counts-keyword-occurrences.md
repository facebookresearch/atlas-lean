# Aho–Corasick automaton counts keyword occurrences

**Definition.** Let $\mathcal{A}$ be a finite alphabet and $\mathcal{W} \subset \mathcal{A}^*$ a finite nonempty set of keywords (for example all RNA strings matching a base-pairing motif). The Aho–Corasick automaton $AC(\mathcal{W}) = (V, \mathcal{A}, q, f, T)$ has state set $V$ consisting of the empty string $\epsilon$ and all prefixes of words in $\mathcal{W}$, initial state $q = \epsilon$, accepting set $T = \mathcal{W}$, and transition function defined by the longest-prefix-suffix rule: for $u, v \in V$ and $\alpha \in \mathcal{A}$,

$$f(u, \alpha) = v \iff v \text{ is the longest element of } V \text{ such that } u\alpha \text{ ends with } v.$$

Extend $f$ to words letter by letter.

**Lemma.** For every $x \in \mathcal{A}^*$, $f(q, x) = u$ if and only if $u$ is the longest element of $V$ that is a suffix of $x$.

**Theorem.** Assume every keyword is nonempty, $\mathcal{W} \subset \mathcal{A}^+$. For $w \in \mathcal{W}$ let $S(w) = \{u \in V : u \text{ ends with } w\}$ be the set of all states, keyword or not, that end with $w$. For $x = x_1 \cdots x_n \in \mathcal{A}^*$ and $1 \le i \le n$, $w$ occurs in $x$ ending at position $i$ (that is, $x_1 \cdots x_i$ ends with $w$) if and only if $f(q, x_1 \cdots x_i) \in S(w)$. Consequently the number of occurrences of $w$ as a substring of $x$ (overlaps counted) equals the number of positions $i \in \{1, \dots, n\}$ with $f(q, x_1 \cdots x_i) \in S(w)$: every position at which the automaton is in $S(w)$ counts, including consecutive positions spent in $S(w)$, and the initial state at position $0$ is not counted.

## Expansion

By the lemma, after reading the prefix $y = x_1 \cdots x_i$ the automaton sits at $u = f(q, y)$, the longest element of $V$ that is a suffix of $y$. If $w$ ends at position $i$, then $w$ is a suffix of $y$ and $w \in V$, so $|u| \ge |w|$; both $u$ and $w$ are suffixes of $y$, hence $u$ ends with $w$ and $u \in S(w)$. Conversely, if $u \in S(w)$ then $u$ ends with $w$ and $y$ ends with $u$, so $w$ ends at position $i$. The state reached need not itself be a keyword: for $\mathcal{W} = \{a, bac\}$ and $x = ba$, the final state is the prefix $ba$, which ends with $a$, while no keyword ending with $a$ is ever visited; this is why $S(w)$ contains all states ending with $w$, and why visits are counted at each position rather than as entries into the set. The empty keyword is excluded because it would also occur at position $0$, which no state visit records. Counting occurrences therefore reduces to counting visits to a set of states. When $x$ is generated by a memoryless (i.i.d.) source, the state sequence is a homogeneous Markov chain with transition matrix $P = \sum_{\alpha} \Pr(\alpha)\, G_\alpha$, where $G_\alpha(u,v) = [f(u,\alpha) = v]$ (Markov chain embedding), so occurrence counts of several overlapping motifs can be studied with transfer matrices and generating functions.
