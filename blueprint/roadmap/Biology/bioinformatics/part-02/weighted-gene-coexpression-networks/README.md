# Weighted gene coexpression networks

Weighted gene coexpression network analysis turns an expression matrix into a weighted network by soft-thresholding absolute correlations, measures the similarity of two genes by their topological overlap (shared weighted neighbors), and finds coexpression modules by hierarchical clustering of the overlap dissimilarity. Modules are then used for functional annotation by enrichment tests.
