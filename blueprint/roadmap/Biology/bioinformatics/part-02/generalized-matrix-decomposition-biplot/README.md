# Generalized matrix decomposition biplot

Microbial community data are usually compared through non-Euclidean dissimilarities such as UniFrac, which ordinary SVD biplots cannot accommodate. The generalized matrix decomposition is a kernel-weighted SVD whose low-rank fit is measured in a norm defined by sample and variable similarity kernels; its right vectors give a biplot that displays sample clustering under the chosen dissimilarity together with the taxa driving it.
