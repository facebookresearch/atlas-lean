# Space lower bounds for k-mer sets

How many bits are needed to store a set of $n$ distinct $k$-mers over an alphabet of size $\sigma$? Information-theoretic counting gives worst-case lower bounds for membership data structures; navigational data structures, which only answer neighbour queries in the de Bruijn graph, can use asymptotically fewer bits per $k$-mer.
