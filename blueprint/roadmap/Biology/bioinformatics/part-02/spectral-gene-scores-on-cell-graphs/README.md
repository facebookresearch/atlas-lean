# Spectral gene scores on cell graphs

Unsupervised feature selection for single-cell data treats each gene as a signal on a graph of cells and scores how smoothly it varies across that graph. Laplacian scores rank genes by graph coherence, and eigenscores decompose that coherence across the eigenvectors of the normalized Laplacian, that is across spatial scales.
