# Isotope-pattern sum formula identification

The elemental composition (sum formula) of a small molecule can be recovered from a high-resolution mass spectrum by enumerating every non-negative integer combination of element masses that matches the monoisotopic mass, simulating the isotope pattern of each candidate, and ranking candidates by the likelihood of the observed peak masses and intensities.
