# Safe paths for minimum flow decomposition

Safety for multi-assembly: a path is safe for a problem whose solutions are sets of paths if it is a subpath of some path in every optimal solution. For minimum flow decomposition (an NP-hard model of RNA transcript assembly), safe paths can be found by group-testing integer linear programs, and deciding safety is itself intractable.
