# Compression-based metabolic network alignment

To align two large reaction-level metabolic networks, each network is first compressed by repeatedly merging pairs of adjacent reactions into supernodes, the compressed networks are aligned, and each aligned supernode pair is refined by a small alignment in the original domain. The compression step at each level is a matching problem, and a greedy minimum-degree rule loses at most a factor two against the optimal compression.
