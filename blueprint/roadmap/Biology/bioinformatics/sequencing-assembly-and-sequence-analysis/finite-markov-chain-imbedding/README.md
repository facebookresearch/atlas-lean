# Finite Markov chain imbedding

Exact distributions of sequence statistics (local scores, pattern counts) obtained by embedding the statistic into a finite Markov chain with an absorbing state, so that p-values become entries of matrix powers computed by vector recurrences, with geometric tail asymptotics from the dominant eigenvalue.
