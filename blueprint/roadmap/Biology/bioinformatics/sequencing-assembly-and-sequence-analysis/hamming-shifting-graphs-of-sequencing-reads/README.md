# Hamming-shifting graphs of sequencing reads

Graphs on distinct short reads in which edges join reads that differ by a few substitutions and/or a small shift, mirroring duplicate sequencing with base-calling errors and random fragmentation. Minimum spanning forests of these graphs give reference chains for compressing reads, and multiple minimizers find the light edges with high probability.
