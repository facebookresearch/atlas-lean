# Phylogenetic double placement of mixed samples

Placing both constituents of a sample that mixes two genomes onto a reference phylogeny using only k-mer Jaccard indices between the mixture and reference genomes. A model of the expected Jaccard index of a mixture deconvolves one observed similarity per reference into distances to the two constituents, constrained by tree additivity.
