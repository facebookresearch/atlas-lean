# Partial order alignment

Alignment of a query sequence to a directed acyclic graph of characters representing a multiple sequence alignment, as used in consensus calling, assembly polishing and pangenome construction. Optimal alignment is a shortest-path problem on the product of the graph and the query, which can be searched with A* using admissible lower bounds derived from path lengths in the graph.
