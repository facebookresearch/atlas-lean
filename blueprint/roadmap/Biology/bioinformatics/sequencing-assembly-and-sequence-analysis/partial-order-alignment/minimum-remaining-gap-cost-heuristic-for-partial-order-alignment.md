# Minimum remaining gap cost heuristic for partial order alignment

Let $G = (V, E)$ be a partial order alignment (POA) graph: a DAG of character-labelled nodes with a start node $\nu$ and end node $\tau$. Aligning a query $Q = q_1 \cdots q_m$ to $G$ means choosing a path $\nu v_1 \cdots v_n \tau$, spelling $R$, and an alignment of $Q$ to $R$ of minimum cost. With linear gap penalties the cost is $C = N_m\Delta_m + N_x\Delta_x + N_g\Delta_g$ for $N_m$ matches, $N_x$ mismatches and total gap length $N_g$, where $\Delta_m = 0$ and $\Delta_x, \Delta_g \ge 0$. Alignment states are pairs $\langle v, i\rangle$ (node $v$, query prefix length $i$), and an optimal alignment is a least-cost path from $\langle \nu, 0\rangle$ to $\langle \tau, m\rangle$ in the alignment graph whose edges are matches or mismatches ($\langle u,i\rangle \to \langle v,i+1\rangle$), insertions ($\langle u,i\rangle \to \langle u,i+1\rangle$) and deletions ($\langle u,i\rangle \to \langle v,i\rangle$) for $(u,v) \in E$.

For each node let $d^{\min}_{v,\tau}$ and $d^{\max}_{v,\tau}$ be the shortest and longest path lengths (in edges) from $v$ to $\tau$, computable in $O(|V| + |E|)$ in reverse topological order, and let $l_r = m - i$ be the unaligned query length. For $v \ne \tau$ every path from $v$ to $\tau$ ends with an edge entering the sentinel $\tau$, which carries no character, so such a path of $d$ edges passes $d - 1$ character nodes after $v$; write $a_v = d^{\min}_{v,\tau} - 1$ and $b_v = d^{\max}_{v,\tau} - 1$.

**Definition (minimum number of indels).** For $v \ne \tau$,

$$N_g^{\min}\langle v,i\rangle = \begin{cases} l_r - b_v, & b_v < l_r,\\ a_v - l_r, & a_v > l_r,\\ 0, & \text{otherwise,}\end{cases}$$

and at the termination node, where no character node remains and only insertions complete the alignment, $N_g^{\min}\langle \tau,i\rangle = l_r$; in particular $h\langle \tau,m\rangle = 0$ at the goal. (Applying the first case at $\tau$, with $d^{\max}_{\tau,\tau} - 1 = -1$, would give the goal a positive value.)

**Lemma (admissibility).** The heuristic $h\langle v,i\rangle = N_g^{\min}\langle v,i\rangle\,\Delta_g$ is a lower bound on the cost of completing the alignment from $\langle v, i\rangle$, so A* with $h$ returns an optimal alignment.

**Greedy matches.** Matches cost $0$ and all other edges cost $\ge 0$. When a state $\langle u, i\rangle$ is expanded, each successor $v$ of $u$ is examined separately: if $v$ is labelled $q_{i+1}$ and $\langle v, i+1\rangle$ is unvisited, that match state is extended depth-first at no cost; if $v$ mismatches $q_{i+1}$, the mismatch state $\langle v, i+1\rangle$, the deletion state $\langle v, i\rangle$ and the insertion state $\langle u, i+1\rangle$ are put on the A* queue. Only when every successor matches are the gap edges at $\langle u, i\rangle$ skipped; a match on one branch does not suppress the gaps through another. (For query `AB` and source-to-sink paths spelling `AXXXX` and `CAB`, with unit gaps and mismatch cost $3$, the optimum, of cost $1$, deletes the `C` on the second branch although the first branch starts with a match.)

**Superbubble pruning.** Let $(s,t)$ be a superbubble (single entrance $s$, single exit $t$, every path from $s$ ends at $t$, and no path from outside enters its interior $U$), and let $\langle v, i\rangle$ with $v \in U \cup \{s\}$ have been reached at cost $C\langle v,i\rangle$. Its **best-case exits** are the states reached by match edges only: $\langle t, j\rangle$ with $i + d^{\min}_{v,t} \le j \le i + d^{\max}_{v,t}$, each at cost $C\langle v,i\rangle$. This interval does not bound the exits reachable from $\langle v,i\rangle$ with gaps: across a single edge $v \to t$ a deletion reaches $\langle t, i\rangle$ and an insertion followed by a match reaches $\langle t, i+2\rangle$. Exit states $\langle t, p\rangle$ already reached at cost $C_p$ give upper bounds through implicitly opened gaps: $C_p + k\Delta_g$ for $\langle t, p+k\rangle$ (insertions) and for a state $k$ deletion edges past $t$ at query position $p$. The source compares each best-case path from $\langle v,i\rangle$, continued along further zero-cost match edges past $t$, with these bounds, and prunes $\langle v,i\rangle$ when every such path is beaten by one (Section 2.4 and Fig. 3c–e; exits reached several times and gap-affine costs are handled in its Supplementary Methods).

## Expansion

Any completion from $\langle v,i\rangle$ with $v \ne \tau$ follows some path from $v$ to $\tau$ with between $a_v$ and $b_v$ character nodes after $v$ and must consume $l_r$ query characters. If the query remainder is longer than the longest path, at least $l_r - b_v$ insertions are forced; if shorter than the shortest path, at least $a_v - l_r$ deletions. From $\langle \tau, i\rangle$ the only completion inserts the $l_r$ remaining characters. Hence $N_g \ge N_g^{\min}$ and $C_r = N_x\Delta_x + N_g\Delta_g \ge N_g^{\min}\Delta_g$. This generalizes the classical gap-cost (diagonal-distance) heuristic for pairwise alignment, where both path lengths equal the remaining reference length. Interleaving depth-first extension of exact matches with the A* queue, as in wavefront alignment, and pruning inside superbubbles means only a small fraction of the $O(|V|m)$ dynamic-programming states is computed. The resulting optimal gap-affine POA algorithm, POASTA, has preprocessing linear in the graph size.
