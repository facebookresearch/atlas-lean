# Novelty detection of non-B DNA from nanopore translocation times

Non-B DNA structures change how fast DNA moves through a nanopore. Treating B-DNA as the reference class, structure calls become a novelty-detection and multiple-testing problem. A discriminative reconstruction loss is optimal for it in the sense of a likelihood-ratio test.
