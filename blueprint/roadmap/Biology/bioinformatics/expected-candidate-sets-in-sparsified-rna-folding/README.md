# Expected candidate sets in sparsified RNA folding

Sparsification speeds up minimum-free-energy RNA folding by restricting the interval-splitting recursion to candidate intervals whose optimal structure cannot be split. The expected number of candidates is governed by the probability that an optimal substructure is irreducible, which can be computed from generating functions of irreducible secondary and fixed-genus pseudoknot structures.
