# Batch-effect identifiability in single-cell designs

When can technical batch effects be separated from biological cell-type differences in single-cell RNA-seq? A hierarchical model with negative-binomial counts, cell-type mixtures and expression-dependent dropout is identifiable not only when every batch contains every cell type, but whenever batches are linked through shared pairs of cell types into a connected design.
