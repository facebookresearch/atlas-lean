# Topological models of protein knot folding

Knot-theoretic descriptions of how a protein chain can become knotted through loop formation, twisting, loop flipping and threading of one terminus. Each pathway ends in a projection whose knot type can be computed; symmetries of the parameters and bridge-number arguments determine which knots the model can produce and which pathways are consistent with twisted hairpin folding.
