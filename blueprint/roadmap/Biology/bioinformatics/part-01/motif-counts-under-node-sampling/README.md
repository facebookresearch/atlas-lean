# Motif counts under node sampling

Estimating the number of occurrences of a small subgraph pattern (a network motif such as a feed-forward loop) in a full biological network, such as the human protein interactome, from the incompletely mapped subnetwork observed so far. Modelling the observed network as an induced subgraph on uniformly sampled nodes gives a scaled-count estimator with an exact bias formula.
