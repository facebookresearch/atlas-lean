# Affix-array search for RNA sequence-structure patterns

Index-based search of RNA databases for short patterns that combine IUPAC sequence constraints with a non-branching base-pairing structure. Matching both partners of a base pair consecutively requires extending a match in both directions; the affix array supports this by linking lcp-intervals of the suffix array of a sequence to those of its reverse.
