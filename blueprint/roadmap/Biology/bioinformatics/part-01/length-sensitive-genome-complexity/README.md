# Length-sensitive genome complexity

String-complexity measures of a genome that count distinct substrings or repeated $k$-mers of one fixed length $k$. Choosing $k$ near the read length makes the measure track how hard it is to place short reads uniquely, and suffix and LCP arrays give all such measures in linear time.
