# Matrix-product encoding of sequencing reads

Reference-free comparison of metagenomic samples by mapping every read to a point in $\mathbb R^4$. Each nucleotide indicator string is encoded as an ordered product of two unimodular $2\times2$ matrices; non-commutativity makes the encoding injective, a weighted trace with linearly independent irrational weights turns it into a single number, and distances between the resulting empirical distributions track genetic distance.
