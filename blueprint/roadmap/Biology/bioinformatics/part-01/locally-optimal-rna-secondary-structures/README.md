# Locally optimal RNA secondary structures

Enumerative combinatorics of RNA secondary structures that are kinetic traps: structures in which no base pair can be added (saturated, locally optimal for the Nussinov energy) or no stem can be extended (G-saturated, locally optimal for the base stacking energy), and of structures with annotated dangling nucleotides. Counts follow the universal tree-like law $c\,\gamma^n n^{-3/2}$.
