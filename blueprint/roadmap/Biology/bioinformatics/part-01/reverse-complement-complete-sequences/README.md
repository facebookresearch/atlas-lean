# Reverse-complement-complete sequences

A de Bruijn sequence contains every $k$-mer exactly once. In double-stranded DNA a $k$-mer and its reverse complement are read together, so it suffices to cover each $k$-mer or its reverse complement. The shortest such sequences are found by paired Eulerian traversals of the de Bruijn graph, and are about half as long as de Bruijn sequences. They are used to design compact probe libraries that cover all $k$-mers, as in protein-binding microarrays.
