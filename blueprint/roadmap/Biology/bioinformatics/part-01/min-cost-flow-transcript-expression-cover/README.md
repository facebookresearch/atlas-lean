# Min-cost flow transcript expression cover

Isoform identification and quantification from RNA-seq can be posed on a splicing graph as the choice of source-to-sink paths with expression levels whose summed coverage best matches the observed exon and junction coverages under convex penalties. That problem reduces to a convex-cost minimum-cost flow on an auxiliary "offset" network, so it is solvable in polynomial time, and every path decomposition of the resulting flow is optimal.
