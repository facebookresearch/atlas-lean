# Stevens' coverage theorem for metagenomes

Stevens' theorem gives the exact distribution of the number of uncovered gaps when random arcs of fixed length are dropped on a circle. Conditioning it on a binomial number of reads coming from one target species in a mixed sample, and summing in closed form, gives exact gap-census and complete-coverage probabilities for metagenomic shotgun sequencing, which account for the target's relative abundance.
