# Jaccard distance between PWM binding-site models

A positional weight matrix with a score threshold defines a set of recognized binding-site words. Comparing two such models through the probability-weighted Jaccard index of their word sets, maximized over relative shifts and strand orientations, gives a metric on binding-site models of all finite widths.
