# The (k-1)-mer walk of a string traverses the de Bruijn multigraph in order

For $k \ge 1$ and every string $s$, let $v_0, \dots, v_m$ be the $(k-1)$-mers of $s$. Then the list of steps $(v_0, v_1), (v_1, v_2), \dots, (v_{m-1}, v_m)$ equals the [de Bruijn multigraph](de-bruijn-edges.md) of $s$ for $k$, edge by edge in order of position.
