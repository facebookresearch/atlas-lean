# EM estimation of haplotype frequencies from reads

Let $\mathbf{H}$ be a finite set of candidate haplotypes of common length, $\mathbf{R}$ the set of possible reads consistent with them, and $u = (u_r)_{r \in \mathbf{R}}$ the observed read counts. Assume each read is generated by drawing a haplotype $h$ from an unknown distribution $p = (p_h)_{h \in \mathbf{H}}$ and then a read uniformly from the $K$ reads consistent with $h$ ($K$ the same for all haplotypes). Then

$$\Pr(R = r) = \sum_{h \in \mathbf{H}} p_h \Pr(R = r \mid H = h), \qquad \Pr(R = r \mid H = h) = \frac{1}{K}\, \mathbf{1}[h \text{ consistent with } r],$$

and $p$ is estimated by maximizing $\ell(p) = \sum_{r} u_r \log \Pr(R = r)$ over the simplex with the EM iteration

$$p_h^{\mathrm{new}} = \frac{1}{\sum_r u_r} \sum_{r \in \mathbf{R}} u_r \frac{p_h \mathbf{1}[h \sim r]}{\sum_{h' \in \mathbf{H}} p_{h'} \mathbf{1}[h' \sim r]},$$

where $h \sim r$ means consistency. Each iteration costs $O(|\mathbf{R}| |\mathbf{H}|)$ and does not decrease $\ell$.

## Expansion

Because $K$ is common to all haplotypes, it cancels from the posterior responsibility of $h$ for read $r$, which is proportional to $p_h$ among consistent haplotypes; the E-step splits each read's count among the haplotypes it could come from, and the M-step sets $p_h$ to the share of reads assigned to $h$. The log-likelihood is concave in $p$ (a sum of logs of linear functions), so every fixed point with full support in the interior is a global maximum, though different haplotype sets can explain the reads equally well when reads are short relative to the spacing of variants. Accuracy measured by Kullback–Leibler divergence from the true population improves with the number of reads, and EM was more accurate than a simple heuristic estimator.
