# Pan-genome and core-genome curves

For a set of genomes of one species clustered into gene families, the pan-genome is the set of families present in at least one genome and the core genome is the set present in all of them. Their sizes as functions of the number of sampled genomes, and power-law extrapolation of these curves, decide whether a species' gene repertoire is open or closed.
