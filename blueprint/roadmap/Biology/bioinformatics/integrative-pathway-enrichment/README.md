# Integrative pathway enrichment

Multi-omics studies give each gene several p-values, one per data type, and ask which pathways are enriched among genes with strong combined evidence. These articles give Brown's moment-matched combination of dependent p-values and the ranked hypergeometric test that scans a significance-ordered gene list for the most enriched prefix.

- [Ranked hypergeometric enrichment test](ranked-hypergeometric-enrichment-test.md)
