# Lookahead scoring for PSSM matching

Exact search for all windows of a sequence whose position-specific scoring matrix (PSSM) score reaches a threshold, accelerated by prefix thresholds that abandon a window as soon as the remaining columns cannot rescue it, combined with enhanced suffix arrays and alphabet reduction.
