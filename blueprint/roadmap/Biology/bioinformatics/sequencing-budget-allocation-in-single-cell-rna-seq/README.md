# Sequencing budget allocation in single-cell RNA-seq

A single-cell RNA-seq experiment with a fixed total number of reads must trade the number of cells against the depth per cell. Under a hierarchical Poisson model of molecule capture, minimax analysis of the estimation error for gene-level distributional quantities gives an explicit optimal trade-off.
