# Microbiome count normalization

Sequencing libraries from microbiome samples differ in size by orders of magnitude, so raw taxon counts are not comparable across samples. This topic collects the count models used to compare taxon (OTU) abundances across libraries of unequal size, and the statistical cost of the common practice of subsampling every library to the smallest size ("rarefying").
