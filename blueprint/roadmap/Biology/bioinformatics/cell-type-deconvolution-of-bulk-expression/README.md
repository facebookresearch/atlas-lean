# Cell-type deconvolution of bulk expression

A bulk expression profile is modelled as a nonnegative mixture of cell-type signature profiles. Constraining the mixture weights to be nonnegative with total at most one leaves room for an uncharacterized remainder (for example tumour cells), and a per-cell-type mRNA-content correction converts mRNA fractions into cell fractions.
