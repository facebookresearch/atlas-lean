# The M-step of the restructured model

Let the set of events be finite and nonempty, with $\alpha < N_j$ for every event $j$. Then for every $\pi$ with $\pi_j > 0$ for all $j$ and $\sum_j \pi_j = 1$,

$$Q_\alpha(\pi) \le Q_\alpha(\hat\pi),$$

where $Q_\alpha$ is the [penalized objective](penalized-q.md) and $\hat\pi$ the [M-step update](m-step.md).
