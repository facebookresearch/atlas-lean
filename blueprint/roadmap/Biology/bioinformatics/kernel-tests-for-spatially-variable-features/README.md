# Kernel tests for spatially variable features

Spatial omics tests for spatially variable genes (Moran's I, Gaussian-process and kernel tests) share one quadratic form $Q_n=\mathbf z^\top\mathbf K\mathbf z$ in the standardized expression vector. Its population version is an HSIC between location and expression, and the spectrum of the centered kernel operator decides which spatial patterns a test can detect at all.
