# The integer list 1, …, n + 1 is 1, …, n followed by n + 1

For every natural number $n$, the identity list of integers $(1, 2, \dots, n + 1)$, which is the
[list](icc.md) $1, \dots, n + 1$ of natural numbers read as integers, is the identity list
$(1, 2, \dots, n)$ with $n + 1$ appended at the end.
