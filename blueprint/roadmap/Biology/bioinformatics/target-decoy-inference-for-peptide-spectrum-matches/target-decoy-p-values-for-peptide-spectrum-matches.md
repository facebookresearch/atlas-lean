# Target–decoy p-values for peptide–spectrum matches

**Setting.** In tandem mass spectrometry, each of $q$ observed spectra $g \in [q]$ is scored against every peptide $P$ in a *target* database $\mathcal{T}$ (real protein sequences) and a *decoy* database $\mathcal{D}$ (e.g. reversed or shuffled sequences that cannot be present), using a score $BF_g(P)$ (in the source, a Bayes factor comparing "spectrum $g$ was generated by $P$" against "spectrum $g$ is noise"). Let
$$z^{(\mathcal{T})}_g = \max_{P \in \mathcal{T}} BF_g(P), \qquad z^{(\mathcal{D})}_g = \max_{P\in\mathcal{D}} BF_g(P),$$
and let $H_g \in \{0,1\}$ indicate whether the best target match of spectrum $g$ is correct ($H_g = 0$: null, incorrect match).

**Proposition.** Suppose (i) the triples $(z^{(\mathcal{T})}_g, z^{(\mathcal{D})}_g, H_g)$, $g = 1,\ldots,q$, are i.i.d., and (ii) $z^{(\mathcal{D})}_g \overset{d}{=} \big(z^{(\mathcal{T})}_g \mid H_g = 0\big)$, with continuous distribution function. Then the empirical target–decoy p-value
$$p_g = \frac{1 + \sum_{h=1}^q \mathbf{1}\{z^{(\mathcal{T})}_g \ge z^{(\mathcal{D})}_h\}}{q+1}$$
(written with the score orientation used in the source) is asymptotically uniform under the null:
$$\sup_{u\in[0,1]} \big|\mathbb{P}(p_g \le u \mid H_g = 0) - u\big| = O(q^{-1}).$$

These p-values can then be passed to standard false discovery rate procedures (e.g. Benjamini–Hochberg) to control the fraction of incorrect peptide identifications.

## Expansion

Under the null, $z^{(\mathcal{T})}_g$ is exchangeable with the $q$ decoy maxima except for the single decoy $z^{(\mathcal{D})}_g$ from the same spectrum, which is not independent of it; dropping or keeping that one term changes the rank by at most one. The rank of a continuous random variable among $q+1$ exchangeable copies is uniform on $\{1,\ldots,q+1\}$, so $p_g$ is a discretized uniform variable up to an $O(1/q)$ perturbation. The key modelling assumption is (ii): decoys must be scored exactly like incorrect target matches, which is why the score $BF_g$ is built from a noise model calibrated on each spectrum.
