# String kernels for biological sequences

Kernel methods such as support vector machines classify DNA or protein sequences through a kernel, an inner product in an implicit feature space. String kernels count shared substrings: the spectrum kernel compares k-mer compositions irrespective of position, while the weighted degree kernel compares substrings position by position, mirroring position weight matrices, which suits signals such as splice sites.
