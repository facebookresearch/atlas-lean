# Subwalk of a circular walk

A sequence $w_0, \dots, w_t$ is a subwalk of the circular walk $a_0, \dots, a_{r-1}$ if there is a natural number $p$ with $a_{(p + i) \bmod r}$ defined and equal to $w_i$ for every $i \le t$: $w$ is read off $a$ from position $p$, wrapping around, possibly several times. The empty sequence is a subwalk of every sequence.
