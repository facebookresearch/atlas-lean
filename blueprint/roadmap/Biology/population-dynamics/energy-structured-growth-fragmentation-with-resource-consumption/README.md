# Energy-structured growth–fragmentation with resource consumption

Individual-based models in which each individual carries an energy (a proxy for size, mass or protein content) that grows or shrinks with the available resource, individuals split by releasing an offspring of fixed energy, and all compete through a shared resource. When growth, birth and death rates are unbounded in energy, well-posedness and large-population limits need weighted measure spaces.
