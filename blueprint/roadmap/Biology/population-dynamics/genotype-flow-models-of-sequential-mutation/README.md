# Genotype flow models of sequential mutation

Continuum models in which genotype density is transported along a mutation axis at a (time-dependent) mutation rate while growing logistically, solved by characteristics; with reverse mutations they become advection-diffusion-reaction equations generalizing quasispecies and Crow-Kimura dynamics.
