# Mate limitation under self-incompatibility

Individual-based birth–death models of hermaphroditic plants with sporophytic self-incompatibility, where only individuals with compatible S-locus phenotypes can mate. In the distylous case the population is a random walk in the positive quadrant that dies as soon as one mating type disappears, which yields explicit bounds on extinction probabilities and an Allee-type cost of self-incompatibility.
