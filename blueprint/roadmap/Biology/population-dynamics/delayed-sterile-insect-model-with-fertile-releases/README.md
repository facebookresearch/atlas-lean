# Delayed sterile insect model with fertile releases

Three-population model of wild, sterile and residually fertile released mosquitoes with saturated release rates and a maturation delay, in which the coexistence equilibrium loses stability through delay-induced Hopf bifurcations and residual fertility strongly affects the outcome of sterile insect releases.
