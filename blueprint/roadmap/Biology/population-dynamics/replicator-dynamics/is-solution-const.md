# A rest point gives a constant solution of the replicator equation

For a finite set `ι` of strategies, a fitness function `f` and a [rest point](is-rest-point.md) `x`
of the replicator equation, `x_i (f_i(x) - f̄(x)) = 0` for every `i` with `f̄` the
[mean fitness](mean-fitness.md), the constant curve `t ↦ x` is a [solution](is-solution.md) of the
replicator equation.
