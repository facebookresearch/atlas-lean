# Rest point of the replicator equation

Let $\iota$ be a finite set and $f \colon \mathbb{R}^\iota \to \mathbb{R}^\iota$. A state
$x \in \mathbb{R}^\iota$ is a rest point of the replicator equation when
$x_i \bigl(f_i(x) - \bar f(x)\bigr) = 0$ for every $i$, where $\bar f$ is the
[mean fitness](mean-fitness.md).
