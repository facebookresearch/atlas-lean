# Chaos in polymatrix replicators

Polymatrix replicators describe a population split into groups, each group choosing among its own strategies, with payoffs from pairwise interactions within and across groups. With three groups of two strategies each the state space is a cube, and even this low-dimensional evolutionary game dynamics can be chaotic: an interior equilibrium of saddle-focus type with a nearby Shilnikov homoclinic orbit produces horseshoes and, after generic perturbation, strange attractors observed for a positive-measure set of parameters.
