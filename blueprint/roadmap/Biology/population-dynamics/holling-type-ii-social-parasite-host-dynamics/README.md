# Holling type II social parasite–host dynamics

Host–parasite models with logistic growth of both species and a Holling type II parasitism term, in which the parasite is obligate ($d>r_2$, it cannot persist without the focal host) or facultative ($d<r_2$). Coupling the ecology to mean-trait dynamics of Darwinian (G-function) type gives conditions for evolutionary stability of boundary equilibria.
