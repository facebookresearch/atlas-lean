# Plant metapopulations with seed banks and ghost individuals

An individual-based Wright-Fisher metapopulation with a seed bank and frequent local extinctions keeps patch sizes constant by filling empty slots with "ghost" individuals that reproduce only when no real individual is sampled. The model has a sharp extinction threshold in the patch extinction probability that increases with the maximal seed dormancy, and in a large-patch, strong-selection limit it reduces to a stochastic patch occupancy model.
