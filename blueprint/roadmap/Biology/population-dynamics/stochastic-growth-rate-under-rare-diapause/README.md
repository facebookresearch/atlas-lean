# Stochastic growth rate under rare diapause

Sensitivity of the stochastic growth rate of a random matrix population model to a small developmental delay. When all births occur at one fixed age, the deterministic life history is a degenerate cyclic migration model whose sites share the same mean growth rate; adding diapause of size $\epsilon$ raises the growth rate by order $1/\log \epsilon^{-1}$, so the growth rate is continuous but not differentiable at $\epsilon = 0$.
