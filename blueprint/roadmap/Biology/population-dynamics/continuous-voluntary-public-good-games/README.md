# Continuous voluntary public good games

Public good games in which individuals evolve both a continuous investment level and a continuous probability of participating. Adaptive dynamics shows a neutral center surrounded by cycles when the synergy factor exceeds two, and in polymorphic populations a covariance condition governs unchecked strategy diversification followed by collapse.
