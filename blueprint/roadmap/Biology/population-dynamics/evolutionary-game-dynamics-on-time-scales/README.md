# Evolutionary game dynamics on time scales

A unified treatment of continuous- and discrete-time evolutionary dynamics (replicator, best reply, logit, projection) through incentive functions and time-scale calculus. Information divergences give Lyapunov functions at incentive-stable and evolutionarily stable states across all time scales $h\mathbb Z$, $0 \le h \le 1$.
