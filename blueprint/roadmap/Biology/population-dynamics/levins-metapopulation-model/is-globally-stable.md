# Global stability for the model with immigration

For real `c`, `e`, `m` and `a` and a set `D` of reals, `a` is globally (asymptotically) stable on
`D` if it is [Lyapunov stable](is-lyapunov-stable.md) for the solutions starting in `D` and
[attracts](is-globally-attracting.md) every
[forward solution of the equation with immigration](is-solution.md) starting in `D`.
