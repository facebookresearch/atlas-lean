# For c, e > 0, extinction is globally attracting iff c ≤ e

**Persistence threshold, global form.** For real numbers `c > 0` and `e > 0`, every
[solution](is-solution-2.md) of the Levins equation `p' = c p (1 - p) - e p` with `p(0) ∈ [0, 1]`
tends to `0` as `t → ∞` if and only if `c ≤ e`. That is, `0`
[attracts](is-globally-attracting-2.md) every solution starting in `[0, 1]` exactly when `c ≤ e`.
