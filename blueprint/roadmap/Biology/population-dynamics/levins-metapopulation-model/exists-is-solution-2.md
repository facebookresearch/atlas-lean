# Global existence of a solution staying in the closed unit interval

For real numbers `c ≥ 0` and `e ≥ 0` and every `p₀ ∈ [0, 1]`, there is a
[solution](is-solution-2.md) `p` of the Levins equation `p' = c p (1 - p) - e p` with `p(0) = p₀`
and `0 ≤ p(t) ≤ 1` for all `t ≥ 0`; the [explicit solution](levins.md) is one.
