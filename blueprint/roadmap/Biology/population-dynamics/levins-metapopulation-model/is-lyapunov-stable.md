# Lyapunov stability for the model with immigration

For real `c`, `e`, `m` and `a` and a set `D` of reals, `a` is Lyapunov stable for the solutions
starting in `D` if for every `ε > 0` there is `δ > 0` such that every
[forward solution of the equation with immigration](is-solution.md) `p` with `p(0) ∈ D` and
`|p(0) - a| < δ` satisfies `|p(t) - a| < ε` for all `t ≥ 0`. Neither `a ∈ D` nor that `a` is an
equilibrium is required.
