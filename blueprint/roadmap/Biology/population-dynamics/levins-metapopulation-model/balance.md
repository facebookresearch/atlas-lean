# Colonization–extinction–immigration balance

For real numbers `c`, `e`, `m` and `p`, the colonization–extinction–immigration balance is
`f(p) = c p (1 - p) - e p + m (1 - p)`: occupied patches colonize the empty fraction `1 - p` at rate
`c`, local populations go extinct at rate `e`, and the mainland colonizes empty patches at rate `m`.

It is defined for all real inputs; the model reads `p ∈ [0, 1]` as the occupied fraction and
`c ≥ 0`, `e ≥ 0`, `m > 0` as rates. [At `m = 0` it is the Levins balance](balance-zero-right.md).
