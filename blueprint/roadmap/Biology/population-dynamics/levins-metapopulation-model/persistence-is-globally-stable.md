# For 0 ≤ e < c, the persistence equilibrium is globally stable

**Global stability of persistence.** If `0 ≤ e < c`, the
[persistence equilibrium](persistence-eq.md) `p* = 1 - e / c`, which lies in `(0, 1]`, is
[globally stable](is-globally-stable-3.md) on `(0, 1]` for the Levins equation
`p' = c p (1 - p) - e p`: for every `ε > 0` there is `δ > 0` such that every
[solution](is-solution-2.md) with `p(0) ∈ (0, 1]` and `|p(0) - p*| < δ` satisfies
`|p(t) - p*| < ε` for all `t ≥ 0`, and every solution with `p(0) ∈ (0, 1]` tends to `p*` as
`t → ∞`. The initial value `0` is excluded, since the constant `0` is a
[solution](is-solution-const-zero.md).
