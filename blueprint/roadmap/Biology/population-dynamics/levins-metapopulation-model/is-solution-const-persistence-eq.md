# For c ≠ 0, the constant function p* solves the Levins equation

For real numbers `c ≠ 0` and `e`, the constant function `p ≡ p*`, where `p* = 1 - e / c` is the
[persistence equilibrium](persistence-eq.md), is a [solution](is-solution-2.md) of the Levins
equation `p' = c p (1 - p) - e p`. Here `p*` need not lie in `[0, 1]`.
