# For c ≠ 0, the balance vanishes exactly at 0 and p*

For real numbers `c ≠ 0` and `e`, a real `p` is a zero of the [balance](balance-2.md),
`c p (1 - p) - e p = 0`, if and only if `p = 0` (extinction) or `p = p*`, where `p* = 1 - e / c`
is the [persistence equilibrium](persistence-eq.md); the two coincide when `e = c`. These are the
equilibria of the Levins equation. Here `p` ranges over all reals, and `p*` need not lie in
`[0, 1]`: it is negative when `0 < c < e`.
