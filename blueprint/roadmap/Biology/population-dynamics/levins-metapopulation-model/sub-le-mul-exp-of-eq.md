# Exponential upper bound on the excess over a positive equilibrium

For `c ≥ 0` and all real `e` and `m`, let `q > 0` be a zero of the [balance](balance.md),
`f(q) = 0`, and `L = c q + m / q`. Every
[forward solution of the equation with immigration](is-solution.md) `p`, whatever `p(0)`, satisfies
`p(t) - q ≤ (p(0) - q) e^{-L t}` for every `t ≥ 0`; equivalently, `(p(t) - q) e^{L t} ≤ p(0) - q`.
