# With nonzero immigration, extinction is not an equilibrium

For all real `c`, `e` and `m`, the [balance](balance.md) at `p = 0` is `f(0) = m`: an empty
landscape receives immigrants at rate `m`. So for `m ≠ 0`, in particular for `m > 0`, extinction
`p = 0` is not an equilibrium; at `m = 0` it is one.
