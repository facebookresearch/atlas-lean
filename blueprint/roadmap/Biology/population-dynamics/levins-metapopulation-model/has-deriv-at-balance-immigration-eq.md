# For m > 0, the slope of the balance at p̂ is minus the return rate

For `c ≥ 0`, `e ≥ 0` and `m > 0`, the [balance](balance.md) `f` has derivative
`f'(p̂) = -(c p̂ + m / p̂) = -L` at the [immigration equilibrium](immigration-eq.md) `p̂`, where `L`
is the [return rate](rate.md). Since `L > 0`, `p̂` is linearly stable. This is a local statement;
[global stability](is-globally-stable-2.md) is a separate result.
