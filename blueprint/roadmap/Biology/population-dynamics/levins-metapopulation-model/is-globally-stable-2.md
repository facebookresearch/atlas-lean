# For m > 0, the immigration equilibrium is globally stable

For `c ≥ 0`, `e ≥ 0` and `m > 0`, the [immigration equilibrium](immigration-eq.md) `p̂`, which lies
in `(0, 1]` ([bounds](immigration-eq-mem-ioc.md)), is [globally stable](is-globally-stable.md) on
`[0, ∞)`. That is, for every `ε > 0` there is `δ > 0` such that every
[forward solution of the equation with immigration](is-solution.md) `p` with `p(0) ≥ 0` and
`|p(0) - p̂| < δ` satisfies `|p(t) - p̂| < ε` for all `t ≥ 0`, and every forward solution with
`p(0) ≥ 0` tends to `p̂` as `t → ∞`.
