# For c ≠ 0, the linearization at p* has slope e − c

For real numbers `c ≠ 0` and `e`, the [balance](balance-2.md) `f(p) = c p (1 - p) - e p` has
derivative `f'(p*) = e - c` at the [persistence equilibrium](persistence-eq.md) `p* = 1 - e / c`. So
`p*` is linearly stable (`f'(p*) < 0`) exactly when `c > e` and linearly unstable exactly when
`c < e`. This concerns the linearization only; for the nonlinear equation, `p*` is
[globally stable on `(0, 1]` when `0 ≤ e < c`](persistence-is-globally-stable.md).
