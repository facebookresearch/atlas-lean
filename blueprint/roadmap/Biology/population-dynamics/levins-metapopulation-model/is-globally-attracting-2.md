# Global attraction for the Levins equation

For real numbers `c` and `e`, a real `a` and a set `D` of reals, `a` attracts every solution
starting in `D` if every [solution](is-solution-2.md) `p` of the Levins equation
`p' = c p (1 - p) - e p` with `p(0) ∈ D` satisfies `p(t) → a` as `t → ∞`. This holds trivially when
no solution starts in `D`.
