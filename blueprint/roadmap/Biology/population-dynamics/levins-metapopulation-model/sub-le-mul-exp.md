# For m > 0, exponential upper bound on the excess over p̂

For `c ≥ 0`, `e ≥ 0` and `m > 0`, every
[forward solution of the equation with immigration](is-solution.md) `p`, whatever `p(0)`, satisfies
`p(t) - p̂ ≤ (p(0) - p̂) e^{-L t}` for every `t ≥ 0`, where `p̂` is the
[immigration equilibrium](immigration-eq.md) and `L = c p̂ + m / p̂` the [return rate](rate.md).
