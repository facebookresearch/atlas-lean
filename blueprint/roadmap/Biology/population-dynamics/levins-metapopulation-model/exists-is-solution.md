# For p₀ ≥ 0, a solution with immigration exists for all t ≥ 0

For `c ≥ 0`, `e ≥ 0`, `m > 0` and every `p₀ ≥ 0`, there is a function `p : ℝ → ℝ` that is a
[forward solution of the equation with immigration](is-solution.md), `p'(t) = f(p(t))` at every
`t ≥ 0` with `f` the [balance](balance.md), and has `p(0) = p₀`. The statement gives existence only,
not uniqueness.
