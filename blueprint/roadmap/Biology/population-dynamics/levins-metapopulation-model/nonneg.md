# For m > 0, a solution that starts nonnegative stays nonnegative

For all real `c` and `e` and every `m > 0`, if `p` is a
[forward solution of the equation with immigration](is-solution.md) with `p(0) ≥ 0`, then `p(t) ≥ 0`
for every `t ≥ 0`. The reason is that the [balance at `0`](balance-zero.md) is `f(0) = m > 0`, so a
solution cannot cross `0` downwards.
