# For 0 ≤ c ≤ e and e > 0, every solution with p(0) ≥ 0 tends to 0

**Extinction.** For real numbers `c` and `e` with `0 ≤ c ≤ e` and `e > 0`, every
[solution](is-solution-2.md) `p` of the Levins equation `p' = c p (1 - p) - e p` with `p(0) ≥ 0`
satisfies `p(t) → 0` as `t → ∞`. For `p(0) > 0` the limit is not reached: such solutions
[stay positive](pos-2.md).
