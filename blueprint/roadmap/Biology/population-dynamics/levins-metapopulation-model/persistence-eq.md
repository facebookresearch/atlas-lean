# Persistence equilibrium of the Levins model

For real numbers `c` and `e`, the persistence equilibrium of the Levins model is
`p* = 1 - e / c`. For `c ≠ 0` the [zeros of the balance](balance-eq-zero-iff-2.md)
`c p (1 - p) - e p` are exactly `p = 0` and `p = p*`, which coincide when `e = c`. With the
convention `x / 0 = 0`, `p* = 1` when `c = 0`; the balance is then `-e p`, so this value is a zero
of it only when `e = 0`. The intended domain is `c > 0`; for `c > 0` and `e ≥ 0`, `p*` lies in
`(0, 1]` exactly when `e < c` (the [persistence threshold](persistence-eq-mem-ioc-iff.md)).
