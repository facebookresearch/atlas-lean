# Discriminant of the equilibrium quadratic

For real `c`, `e` and `m`, `D = (c - e - m)² + 4 c m` is the discriminant of the quadratic
`c p² - (c - e - m) p - m`, which is `-f(p)` for the [balance](balance.md) `f`. It is nonnegative
when `e ≥ 0` and `m ≥ 0`, and it can be negative only if `c m < 0`.
