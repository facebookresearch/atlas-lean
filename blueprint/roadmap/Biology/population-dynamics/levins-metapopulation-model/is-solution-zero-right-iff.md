# Without immigration the solutions are the Levins solutions

For real `c` and `e` and every function `p : ℝ → ℝ`, `p` is a
[forward solution of the equation with immigration](is-solution.md) with `m = 0` if and only if it
is a [forward solution of the Levins equation](is-solution-2.md) `p' = c p (1 - p) - e p` for
`t ≥ 0`.
