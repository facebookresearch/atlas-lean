# For 0 ≤ e < c, every solution with p(0) > 0 tends to p*

**Persistence.** For real numbers `c` and `e` with `0 ≤ e < c`, every [solution](is-solution-2.md)
`p` of the Levins equation `p' = c p (1 - p) - e p` with `p(0) > 0` satisfies `p(t) → p*` as
`t → ∞`, where `p* = 1 - e / c` is the [persistence equilibrium](persistence-eq.md), which lies in
`(0, 1]`. No upper bound on `p(0)` is needed.
