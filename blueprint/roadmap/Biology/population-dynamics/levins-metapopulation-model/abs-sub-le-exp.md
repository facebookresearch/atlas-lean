# For m > 0, exponential decay of the distance to p̂

For `c ≥ 0`, `e ≥ 0` and `m > 0`, every
[forward solution of the equation with immigration](is-solution.md) `p` with `p(0) ≥ 0` satisfies
`|p(t) - p̂| ≤ |p(0) - p̂| e^{-(m / p̂) t}` for every `t ≥ 0`, where `p̂` is the
[immigration equilibrium](immigration-eq.md). Since [`0 < p̂ ≤ 1`](immigration-eq-mem-ioc.md), the
rate `m / p̂` is at least `m`.
