# For 0 ≤ c ≤ e and e > 0, extinction is globally stable

**Global stability of extinction.** If `0 ≤ c ≤ e` and `e > 0`, the extinction equilibrium `p = 0`
is [globally stable](is-globally-stable-3.md) on `[0, 1]` for the Levins equation
`p' = c p (1 - p) - e p`: for every `ε > 0` there is `δ > 0` such that every
[solution](is-solution-2.md) with `p(0) ∈ [0, 1]` and `p(0) < δ` satisfies `|p(t)| < ε` for all
`t ≥ 0`, and every solution with `p(0) ∈ [0, 1]` tends to `0` as `t → ∞`. The condition `e > 0`
cannot be dropped: for `c = e = 0` every solution is constant on `[0, ∞)`, so `0` attracts no
solution starting in `(0, 1]`.
