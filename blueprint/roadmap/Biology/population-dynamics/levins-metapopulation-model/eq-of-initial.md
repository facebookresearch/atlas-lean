# Two solutions with the same initial value agree for t ≥ 0

**Forward uniqueness.** For all real numbers `c` and `e`, if `p` and `q` are
[solutions](is-solution-2.md) of the Levins equation `p' = c p (1 - p) - e p` with `p(0) = q(0)`,
then `p(t) = q(t)` for every `t ≥ 0`. No sign condition on `c`, `e` or `p(0)` is needed.
