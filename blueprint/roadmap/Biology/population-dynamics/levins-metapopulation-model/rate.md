# Return rate at the immigration equilibrium

For real `c`, `e` and `m`, the return rate is `L = c p̂ + m / p̂`, where `p̂` is the
[immigration equilibrium](immigration-eq.md). For `c ≥ 0`, `e ≥ 0` and `m > 0` it is positive and
equals `-f'(p̂)` for the [balance](balance.md) `f`
([slope at the equilibrium](has-deriv-at-balance-immigration-eq.md)): the rate at which the
linearized equation returns to `p̂`. With the convention `x / 0 = 0`, `L = 0` where `p̂ = 0`, for
example at `m = 0`.
