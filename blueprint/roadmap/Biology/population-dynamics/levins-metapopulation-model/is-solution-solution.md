# From p₀ ≥ 0, the explicit solution solves the equation for t ≥ 0

For `c ≥ 0`, `e ≥ 0`, `m > 0` and `p₀ ≥ 0`, the [explicit solution](solution.md) from `p₀` is a
[forward solution of the equation with immigration](is-solution.md): its derivative at every `t ≥ 0`
is `f(p(t))`, with `f` the [balance](balance.md).
