# Sigma rule for games in structured populations

Under weak selection, the competition between two strategies in a structured population is decided by a single structure coefficient $\sigma$ that does not depend on the payoffs. These articles state the sigma rule and its consequence for cooperation on regular graphs, the $b/c > k$ rule.
