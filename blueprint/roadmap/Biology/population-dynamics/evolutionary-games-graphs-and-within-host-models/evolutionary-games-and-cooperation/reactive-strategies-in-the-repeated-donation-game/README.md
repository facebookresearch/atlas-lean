# Reactive strategies in the repeated donation game

A reactive strategy responds only to the co-player's last move. In the infinitely repeated donation game, two reactive strategies settle into explicit stationary cooperation rates, from which payoffs follow. These articles give that formula and a symmetry showing that, without selection, random reactive strategies cooperate exactly half the time.
