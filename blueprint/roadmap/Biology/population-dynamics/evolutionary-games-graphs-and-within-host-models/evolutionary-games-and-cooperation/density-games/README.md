# Density games

Evolutionary games in which the payoff matrix sets frequency-dependent carrying capacities of logistically growing phenotypes, rather than their reproductive rates. Equilibria and monomorphic stability agree with the replicator equation, while the stability of interior equilibria can depend on the growth rates.
