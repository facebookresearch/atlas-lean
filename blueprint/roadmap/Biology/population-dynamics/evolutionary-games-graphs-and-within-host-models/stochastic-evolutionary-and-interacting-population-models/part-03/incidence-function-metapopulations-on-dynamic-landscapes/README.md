# Incidence function metapopulations on dynamic landscapes

Hanski's incidence function model of patch occupancy, extended so that each patch's survival probability and weight follow a Markov chain on a general state space. As the number of patches grows, each patch decouples into an independent Markov chain driven by a deterministic connectivity field, and with phase structure and concave colonization the limiting recursion has a sharp persistence threshold that factorizes into a landscape-dependent life-span term and the spectral radius of the dispersal operator.
