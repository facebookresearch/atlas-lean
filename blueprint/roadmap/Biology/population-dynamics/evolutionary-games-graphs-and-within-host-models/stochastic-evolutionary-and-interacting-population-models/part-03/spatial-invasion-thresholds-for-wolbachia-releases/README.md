# Spatial invasion thresholds for Wolbachia releases

The frequency of *Wolbachia*-infected mosquitoes obeys a bistable reaction–diffusion equation because cytoplasmic incompatibility creates an Allee-type threshold. Whether a release invades is decided by comparing the initial frequency profile with explicit compactly supported "bubbles", which turns release design into geometric and probabilistic questions about the released numbers and their spatial spread.
