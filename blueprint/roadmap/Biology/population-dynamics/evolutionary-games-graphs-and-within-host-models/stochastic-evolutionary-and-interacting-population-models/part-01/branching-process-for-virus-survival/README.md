# Branching process for virus survival

A birth–death process in which each newborn either inherits its parent's birth rate or, by mutation, draws a fresh birth rate from a fixed distribution. Survival can be achieved either by a single supercritical type or collectively by a stream of subcritical types that keep producing mutants.
