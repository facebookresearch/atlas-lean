# Quasispecies in multitype Galton–Watson processes

Branching-process versions of Eigen's quasispecies model: genotypes reproduce independently with fitness-dependent Poisson offspring and mutate per locus. In the long-chain, small-mutation limit the class frequencies of the surviving population converge to an explicit quasispecies distribution above an error threshold.
