# Prey–predator phenotypic coevolution

An individual-based multitype birth–death model in which prey traits set defense, reproduction and competition, and predator traits set consumption and mortality. Its large-population limit is a multitype Lotka–Volterra prey–predator system with a unique globally stable equilibrium; under rare mutations the community jumps between such equilibria, and with small mutation steps the traits follow a coupled canonical equation of adaptive dynamics.
