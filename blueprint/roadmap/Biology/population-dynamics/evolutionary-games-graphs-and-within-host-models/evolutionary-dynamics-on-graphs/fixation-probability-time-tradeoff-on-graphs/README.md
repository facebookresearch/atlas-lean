# Fixation probability and fixation time tradeoff on graphs

For the Moran birth-death process on a graph, structures that raise the fixation probability of an advantageous mutant (amplifiers) usually slow fixation. These articles state a universal lower bound on absorption time that rules out asymptotically faster amplifiers, and describe complete bipartite structures that reach star-like amplification while staying close to well-mixed fixation time.
