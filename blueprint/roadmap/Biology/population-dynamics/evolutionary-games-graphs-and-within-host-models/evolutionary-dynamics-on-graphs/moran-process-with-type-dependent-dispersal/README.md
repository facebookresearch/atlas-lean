# Moran process with type-dependent dispersal

Here mutants and residents have the same reproductive rate but disperse offspring along different graphs on the same set of sites. The neutral fixation probability $1/N$ is then no longer guaranteed, and the difference in structure acts like a difference in fitness. These articles define the model, show that the complete graph is locally optimal, and give bounds for island-like and lattice structures.
