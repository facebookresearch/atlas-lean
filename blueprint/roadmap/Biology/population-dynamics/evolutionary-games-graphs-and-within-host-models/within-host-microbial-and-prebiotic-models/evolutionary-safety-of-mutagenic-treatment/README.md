# Evolutionary safety of mutagenic treatment

A mutagenic antiviral reduces virus load by pushing replication past its error threshold, but it
also raises the rate at which mutants are produced. These articles give the within-host model, the
mutation rate that stops replication outright, and the condition under which raising the mutation
rate does not increase the expected number of mutants.
