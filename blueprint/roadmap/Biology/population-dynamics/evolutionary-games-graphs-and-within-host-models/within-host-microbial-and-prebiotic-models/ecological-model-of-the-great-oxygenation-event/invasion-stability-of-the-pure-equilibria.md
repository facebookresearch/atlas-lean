# Invasion stability of the pure equilibria

In the competition model of anoxygenic and oxygenic photosynthesis with negligible migration
($u_1 = u_2 = 0$), the abiotic state has $y_1 = f_1$, $y_2 = f_2$ and $z = 0$. If $f_1 f_2 > 1$ the
anoxygenic bacteria can grow and the system settles at the equilibrium $E_1$, where only anoxygenic
bacteria are present and there is no oxygen; $E_1$ is stable against invasion by cyanobacteria if
and only if

$$f_1 - f_2 \ >\ \frac{(c+1)(c-1)}{c}.$$

If $c f_2 > 1$ the system also admits the equilibrium $E_2$, where only cyanobacteria are present
and oxygen is abundant; $E_2$ is stable against invasion by anoxygenic bacteria if and only if

$$a\,(c f_2 - 1) \ >\ (b + c)\,(f_1 - c).$$

## Depends on

- [Competition model of anoxygenic and oxygenic photosynthesis](competition-model-of-anoxygenic-and-oxygenic-photosynthesis.md)

## Remarks

The first condition holds when the reductant influx $f_1$ is large or the phosphate influx $f_2$ is
small; its right-hand side increases with the reproduction rate $c$ of cyanobacteria, so faster
cyanobacteria make the anoxygenic world easier to invade. The second condition always holds when
$f_1 < c$, since its left-hand side is positive; otherwise it is met when phosphate influx or
oxygen production is large enough, oxygen stabilizing the cyanobacterial world by oxidizing the
reductant that anoxygenic invaders would need.
