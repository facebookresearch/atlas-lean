# Decomposable branching processes in random environments

Two-type Galton–Watson processes in which type 1 individuals (for example a population on an island with a fluctuating environment) produce both types while type 2 individuals (migrants to a second, constant island) produce only their own type. Survival of the whole population is governed by the interplay between the extinction of the type 1 line and the slow critical decay of type 2 families seeded by migrants.
