# Simultaneous Birth-death and death-Birth amplifiers

Population structures that raise the fixation probability of an advantageous mutant above the well-mixed value under both the Moran Birth-death (Bd) and the Moran death-Birth (dB) update rules. The two update rules pull in opposite directions, so single-rule amplifiers such as the star or the fan suppress under the other rule; weakly linked two-chunk graphs achieve both.
