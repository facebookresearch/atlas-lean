# With zero delay the logistic solution is a solution

For `r ≥ 0`, `K > 0` and a function `φ` with `φ(0) > 0`, the
[explicit logistic solution](../logistic-growth-equation/logistic.md)
`t ↦ K φ(0) e^{r t} / (K + φ(0) (e^{r t} - 1))` is a [solution](is-solution.md) of the delayed
logistic equation with delay `τ = 0` and history `φ`; with zero delay the equation is the logistic
equation `x' = r x (1 - x / K)`.
