# Geometric bound on Wright solutions, window by window

For `r ≥ 0`, `τ > 0`, a [solution](is-wright-solution.md) `y` of Wright's equation
`y'(t) = -r (e^{y(t - τ)} - 1)` and a real `M ≤ 1` with `ρ(r τ, M) ≤ 1`, where `ρ` is the
[contraction factor](contraction-factor.md), if `|y(s)| ≤ M` for every `s ∈ [-τ, 2 τ]`, then for
every natural number `n` and every `t ≥ -τ + 3 τ n`, `|y(t)| ≤ ρ(r τ, M)ⁿ M`. For `ρ(r τ, M) < 1`
this is geometric decay.
