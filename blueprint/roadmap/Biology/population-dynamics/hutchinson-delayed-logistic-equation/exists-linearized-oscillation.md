# Past the critical delay a linearized solution oscillates unboundedly

For `r > 0` and `τ > τ_c = π / (2 r)`, the [critical delay](critical-delay.md), there is a real
function `u` with `u'(t) = -r u(t - τ)` at every real `t` such that, for all reals `M` and `T`,
`u(t) ≥ M` for some `t ≥ T` and `u(t) ≤ -M` for some `t ≥ T`: an oscillation about `0` with
unbounded amplitude.
