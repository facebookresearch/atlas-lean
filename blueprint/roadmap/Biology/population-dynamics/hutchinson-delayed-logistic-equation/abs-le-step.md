# Window contraction for Wright's equation

For `r ≥ 0`, `τ ≥ 0`, a [solution](is-wright-solution.md) `y` of Wright's equation
`y'(t) = -r (e^{y(t - τ)} - 1)`, a time `t ≥ 2 τ` and a real `M ≤ 1` with `|y(s)| ≤ M` for every
`s ∈ [t - 3 τ, t - τ]`, `|y(t)| ≤ ρ(r τ, M) M`, where `ρ` is the
[contraction factor](contraction-factor.md). This is a Razumikhin-type step.
