# Extension of a history to the whole line

For a real number `τ` and a function `φ : ℝ → ℝ`, the extended history is
`t ↦ φ(max(-τ, min(t, 0)))`. For `τ ≥ 0` it equals `φ` on `[-τ, 0]`, `φ(-τ)` for `t ≤ -τ` and
`φ(0)` for `t ≥ 0`, and it is continuous when `φ` is continuous on `[-τ, 0]`. For `τ < 0` it is the
constant `φ(-τ)`.
