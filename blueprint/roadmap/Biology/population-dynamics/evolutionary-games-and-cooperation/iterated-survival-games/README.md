# Iterated survival games

Two-player games against nature in which the payoff of each step is a survival probability, payoffs compound multiplicatively over $n$ steps, and an individual whose partner dies must finish the game alone. Because a lone survivor faces the loner survival probability for the rest of the game, defecting can hurt the defector, and backward induction no longer forces full defection.
