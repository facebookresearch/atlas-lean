# Memory-one strategies in alternating games

In the strictly alternating repeated donation game the two players move in turns, each seeing the other's most recent move before acting. For memory-one strategies this game has an exact Markov-chain payoff formula, a reduction of best responses to four deterministic reactive strategies, and a complete classification of Nash equilibria into partners, defectors and equalizers. With implementation errors the cooperative equilibria shrink to a line segment between Generous Tit-for-Tat and Stochastic Firm-but-Fair, none of which is deterministic.
