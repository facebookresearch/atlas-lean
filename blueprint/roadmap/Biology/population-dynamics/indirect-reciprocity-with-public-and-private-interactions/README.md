# Indirect reciprocity with public and private interactions

Reputation-based cooperation when some interactions are always observed (public) and others only occasionally (private). Strategies may condition on observability, so the model separates honest action rules, which help good recipients everywhere, from hypocritical ones, which help only when watched.
