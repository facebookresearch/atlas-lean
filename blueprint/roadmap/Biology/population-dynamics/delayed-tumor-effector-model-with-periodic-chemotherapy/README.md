# Delayed tumor–effector model with periodic chemotherapy

A two-dimensional delay differential system for tumor cells and immune effector cells in which tumor growth follows a time-periodic Richards-type law that encodes periodic chemotherapy, effector recruitment and neutralization respond to the tumor with two distinct delays, and the analysis combines equilibrium counting, delay-independent stability of the tumor-free state and an implicit-function continuation argument for periodic solutions.
