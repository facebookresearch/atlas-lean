# Leslie matrix

For fertilities $f_0, \dots, f_{n-1}$ and survival probabilities $s_0, \dots, s_{n-1}$ of $n$ age
classes, the Leslie matrix $L$ is the $n \times n$ real matrix whose first row is
$(f_0, \dots, f_{n-1})$, whose subdiagonal entries are $L_{j+1, j} = s_j$, the survival from class $j$
to class $j + 1$, and whose other entries are $0$. The last survival probability $s_{n-1}$ does not
enter $L$.
