# Survivors in the next census, for any index of a later class

Let $L$ be the Leslie matrix of $n$ age classes with fertilities $f_0, \dots, f_{n-1}$ and real survival
coefficients $s_0, \dots, s_{n-1}$. For a population vector $v \in \mathbb{R}^n$ and age classes $i$ and
$j$ with $i = j + 1$, $(Lv)_i = s_j v_j$.
