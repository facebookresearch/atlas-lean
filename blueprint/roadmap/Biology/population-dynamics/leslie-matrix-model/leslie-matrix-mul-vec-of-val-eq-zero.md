# Births in the next census, for any index of the first class

Let $L$ be the Leslie matrix of $n$ age classes with fertilities $f_0, \dots, f_{n-1}$ and real survival
coefficients $s_0, \dots, s_{n-1}$. For a population vector $v \in \mathbb{R}^n$ and an age class $i$
numbered $0$, $(Lv)_i = \sum_j f_j v_j$.
