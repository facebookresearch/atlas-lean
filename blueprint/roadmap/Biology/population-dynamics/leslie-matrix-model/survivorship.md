# Survivorship

For real survival coefficients $s_0, \dots, s_{n-1}$, the survivorship to age class $i$ is
$l_i = \prod_{j < i} s_j$; in particular $l_0 = 1$. When each $s_j \in [0, 1]$ is the probability of
surviving from class $j$ to class $j + 1$, $l_i$ is the probability that a newborn reaches class $i$.
