# Stable age distribution

Let $L$ be the Leslie matrix of $n \ge 1$ age classes with fertilities $f_0, \dots, f_{n-1}$ and
survival probabilities $s_0, \dots, s_{n-1}$. If $Lv = \lambda v$ for some $v \in \mathbb{R}^n$ and some
real $\lambda$, then $v_i \lambda^i = v_0 l_i$ for every age class $i$, where $l_i = s_0 s_1 \cdots s_{i-1}$
is the survivorship, with $l_0 = 1$; the subdiagonal rows force $\lambda v_{j+1} = s_j v_j$.
