# Evolutionary rescue

A population whose wild type has negative growth rate in a new environment escapes extinction only if a beneficial mutant appears and establishes before the wild type dies out. These articles state the Poisson approximation for the rescue probability and the establishment theory for mutations carried on multicopy plasmids, where random segregation adds a layer of drift.
