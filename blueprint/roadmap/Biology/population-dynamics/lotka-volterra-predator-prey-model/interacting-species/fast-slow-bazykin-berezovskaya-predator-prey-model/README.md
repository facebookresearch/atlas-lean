# Fast-slow Bazykin–Berezovskaya predator–prey model

When predation (or resource exploitation) is fast and prey growth with a strong Allee effect is slow, the Bazykin–Berezovskaya predator–prey model becomes a fast–slow system in non-standard form. Its fast subsystem is SIR-like with a conserved quantity, and slow passage along the prey axis is governed by an entry–exit relation, which together classify extinction, heteroclinic and oscillatory outcomes.
