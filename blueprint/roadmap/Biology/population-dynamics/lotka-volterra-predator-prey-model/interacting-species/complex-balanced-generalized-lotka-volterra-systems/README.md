# Complex-balanced generalized Lotka–Volterra systems

Generalized Lotka–Volterra (GLV) systems $\dot x=\mathrm{diag}(x)f(x)$ with generalized-polynomial $f$ (any real exponents) are equivalent, under $x=e^\xi$, to polyexponential systems, which have the same algebraic structure as mass-action kinetics. Transferring complex balancing and the deficiency-zero theorem gives global stability results for GLV systems with no restriction on dimension or degree.
