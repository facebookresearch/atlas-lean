# Global stability of complex-balanced generalized Lotka–Volterra systems

**Construction.** An E-graph is a finite directed graph $G=(V,E)$ without self-loops whose vertices $y_1,\dots,y_m$ lie in $\mathbb R^n$. With edge weights $\kappa\in\mathbb R^E_{>0}$ set

$$f_{(G,\kappa)}(x)=\sum_{(i,j)\in E}\kappa_{ij}\,x^{y_i}(y_j-y_i),\qquad x\in\mathbb R^n_{>0},$$

with real (possibly negative or non-integer) exponents. The GLV system generated by $(G,\kappa)$ is $\dot x=\mathrm{diag}(x)\,f_{(G,\kappa)}(x)$ on $\mathbb R^n_{>0}$. The substitution $x=e^\xi$ turns it into the polyexponential system $\dot\xi=\sum\kappa_{ij}e^{\langle y_i,\xi\rangle}(y_j-y_i)$ on $\mathbb R^n$. A state $x^*$ is complex balanced if at every vertex the weighted inflow $\sum_{i\to j}\kappa_{ij}(x^*)^{y_i}$ equals the weighted outflow $\sum_{j\to k}\kappa_{jk}(x^*)^{y_j}$. Let $S=\mathrm{span}\{y_j-y_i\}$; the compatibility manifolds are $\{x:\log x\in\log x^0+S\}$, and $G$ has deficiency $m-\ell-\dim S$ with $\ell$ connected components.

**Theorem.** Suppose the GLV system generated by $(G,\kappa)$ has a complex-balanced steady state $x^*$. Then:

- a positive state $z$ is a steady state iff $\log z-\log x^*\in S^\perp$, and every positive steady state is complex balanced;
- each compatibility manifold contains exactly one positive steady state, which is globally attracting within it;
- for every positive diagonal matrix $D$, the scaled system $\dot x=D\,\mathrm{diag}(x)f_{(G,\kappa)}(x)$ has the same positive steady states, so a positive state $z$ is a steady state iff $\log z-\log x^*\in S^\perp$; its invariant sets are $\exp(\xi^0+DS)$, $\xi^0\in\mathbb R^n$, rather than the compatibility manifolds, and each such set contains exactly one positive steady state, which is globally attracting within it.

**Deficiency zero.** The GLV system is complex balanced for every $\kappa>0$ iff $G$ is weakly reversible with deficiency zero. If $G$ has deficiency zero and is weakly reversible, then for every $\kappa$ each compatibility manifold has a unique positive steady state, complex balanced and globally stable; if it is not weakly reversible, there is no positive steady state and no positive periodic orbit.

## Expansion

In the variable $\xi=\log x$ the right-hand side $\sum\kappa_{ij}e^{\langle y_i,\xi\rangle}(y_j-y_i)$ is exactly a mass-action field evaluated at $e^\xi$, but without the extra factor that makes mass-action systems live on stoichiometric classes; instead the invariant sets are the affine spaces $\xi^0+S$, and $\xi^0+DS$ for the scaled system, since $\dot\xi=D\sum\kappa_{ij}e^{\langle y_i,\xi\rangle}(y_j-y_i)$ there. Because $s^\top Ds>0$ for $s\ne0$, $DS\cap S^\perp=\{0\}$, so each $\xi^0+DS$ meets the steady-state set $\log x^*+S^\perp$ exactly once. Complex balancing yields the Lyapunov function $L(\xi)=\sum_v c_v\,e^{\langle y_v,\xi-\xi^*\rangle}$-type analogue of the pseudo-Helmholtz function (the Horn–Jackson argument), strictly decreasing off the steady-state set, and the steady-state set meets each class exactly once by a Birch-type theorem; global attraction then follows from LaSalle. Classical cooperative GLV stability (Goh's diagonal-dominance criterion) is recovered as a special case.
