# Dendritic-cell–cytokine checkpoint tumour model

An ODE model coupling tumour cells, CD8+ T cells, dendritic cells, IL-2, IL-12 and an anti-PD-L1 inhibitor. Its tumour-free equilibrium is governed by a T-cell expansion threshold together with the balance of tumour growth against dendritic-cell killing.
