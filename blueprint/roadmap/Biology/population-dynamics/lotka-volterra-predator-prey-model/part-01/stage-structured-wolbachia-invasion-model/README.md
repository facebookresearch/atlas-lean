# Stage-structured Wolbachia invasion model

A compartmental model of egg, larva and adult stages of uninfected and Wolbachia-infected mosquitoes, with maternal transmission, complete cytoplasmic incompatibility and larval carrying capacity. Each cohort has a next-generation number (offspring per adult per generation); the invasion reproduction number is their ratio, and the system is bistable: an unstable endemic state separates the infection-free and complete-infection equilibria, defining the release threshold.
