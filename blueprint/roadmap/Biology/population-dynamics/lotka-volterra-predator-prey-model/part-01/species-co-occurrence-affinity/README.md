# Species co-occurrence affinity

Presence–absence data for two species over $N$ sites form a $2\times2$ table with fixed prevalences. Under an urn model in which the second species occupies sites with different probabilities depending on whether the first is present, the co-occurrence count has the extended (Fisher noncentral) hypergeometric distribution, which depends on the occupancy probabilities only through their log odds ratio. That parameter is a prevalence-independent measure of affinity, with exact test-inverted confidence intervals.
