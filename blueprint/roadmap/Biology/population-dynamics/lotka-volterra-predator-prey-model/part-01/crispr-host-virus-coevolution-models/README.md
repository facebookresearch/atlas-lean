# CRISPR host-virus coevolution models

Lotka-Volterra type models of prokaryotic hosts carrying CRISPR-Cas adaptive immunity, sensitive hosts, and viruses that escape immunity, with immunity acquisition and decay. Linear stability gives the threshold burst size for viral invasion; virus-dependent immunity produces rich bifurcation structure.
