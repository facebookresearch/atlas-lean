# First integral of the Lotka–Volterra system

For real $\alpha, \beta, \gamma, \delta$, the first integral of the Lotka–Volterra system
$x' = \alpha x - \beta x y$, $y' = \delta x y - \gamma y$ is

$$V(x, y) = \delta x - \gamma \log x + \beta y - \alpha \log y.$$

It is meaningful on the open positive quadrant $x, y > 0$; elsewhere the logarithm follows the
conventions $\log 0 = 0$ and $\log x = \log|x|$ for $x < 0$.
