# Phase-type age distributions

When an individual's lifetime is the absorption time of a finite continuous-time Markov chain, its life stages are the transient phases and the lifetime is phase-type distributed. Observing the current phase carries information about age, and the conditional age distribution given the phase depends on how and when the phase is observed.
