# Mean fitness minus the reference fitness on the unit-sum hyperplane

For a finite set `ι`, a fitness function `f` on states of the strategies `ι ∪ {o}` and a state `x`
with `∑_k x_k = 1`, the [mean fitness](../replicator-dynamics/mean-fitness.md)
`f̄(x) = ∑_k x_k f_k(x)` satisfies `f̄(x) - f_o(x) = ∑_{i ∈ ι} x_i (f_i(x) - f_o(x))`.
