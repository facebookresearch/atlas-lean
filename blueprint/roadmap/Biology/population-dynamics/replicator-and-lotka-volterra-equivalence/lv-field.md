# Generalized Lotka–Volterra vector field

For a finite set `ι` of species, intrinsic growth rates `r : ι → ℝ`, an interaction matrix
`B : ι × ι → ℝ` and densities `y : ι → ℝ`, the generalized Lotka–Volterra vector field has
components `y_i (r_i + ∑_j B_ij y_j)`. In the model the densities are positive.
