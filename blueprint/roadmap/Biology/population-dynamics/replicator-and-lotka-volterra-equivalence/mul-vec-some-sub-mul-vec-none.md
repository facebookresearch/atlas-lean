# Fitness differences are Lotka–Volterra rates

For a finite set `ι`, a payoff matrix `A` on the strategies `ι ∪ {o}`, a state `x` with `x_o ≠ 0`
and `i ∈ ι`, `(A x)_i - (A x)_o = x_o (r_i + ∑_j B_ij y_j)`, where `y = (x_j / x_o)_j` are the
[Lotka–Volterra coordinates](to-lv.md), `r` the [growth rates](lv-growth.md) and `B` the
[interaction matrix](lv-interaction.md) of `A`.
