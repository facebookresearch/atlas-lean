# From Lotka–Volterra densities to replicator frequencies

For a finite set `ι` and densities `y : ι → ℝ`, the replicator coordinates on the strategies
`ι ∪ {o}`, with `o` the reference strategy, are `x_o = 1 / (1 + ∑_j y_j)` and
`x_i = y_i / (1 + ∑_j y_j)` for `i ∈ ι`. With the convention `a / 0 = 0`, every coordinate is `0`
when `1 + ∑_j y_j = 0`. When `1 + ∑_j y_j ≠ 0` the state lies in the
[hyperplane `∑_k x_k = 1`](sum-of-lv.md), and for positive `y` it lies in the
[interior of the simplex](of-lv-pos.md).
