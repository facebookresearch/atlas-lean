# The Lotka–Volterra time of a replicator solution is C¹

For a finite set `ι`, a fitness function `f` and a
[replicator solution](../replicator-dynamics/is-solution.md) `x` of `x_k' = x_k (f_k(x) - f̄(x))` for
`t ≥ 0`, the [Lotka–Volterra time](time-change.md) `τ` is continuously differentiable on `ℝ`.
