# Reparametrization by an increasing time change

Let `θ, θ' : ℝ → ℝ` with `θ` having derivative `θ'(s) > 0` at every `s`, so that `θ` is strictly
increasing. If a function `c : ℝ → ℝ` has derivative `θ'(s) v` at a point `s`, then
`u ↦ c(θ⁻¹(u))` has derivative `v` at `θ(s)`, where `θ⁻¹` is a chosen inverse of `θ`: the true
inverse on the range of `θ`, and an unspecified value off it.
