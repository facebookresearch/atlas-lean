# From replicator frequencies to Lotka–Volterra densities

For a finite set `ι` and a state `x` on the strategies `ι ∪ {o}`, with `o` the reference strategy,
the Lotka–Volterra coordinates are `y_i = x_i / x_o` for `i ∈ ι`. With the convention `a / 0 = 0`,
every `y_i` is `0` when `x_o = 0`; the intended domain is `x_o > 0`.
