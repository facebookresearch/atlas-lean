# Extinction barriers in quorum-sensing populations

A cooperative population whose division rate depends on a secreted signal can be bistable between extinction and a cooperative state. Changing the speed of the signal leaves the deterministic equilibria and their stability untouched, but changes the large-deviation barrier for noise-driven collapse, and hence the exponential rate of the mean extinction time.
