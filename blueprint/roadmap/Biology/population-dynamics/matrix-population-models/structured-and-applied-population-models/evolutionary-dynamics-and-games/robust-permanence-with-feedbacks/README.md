# Robust permanence with feedbacks

Ecological models in which per-capita growth rates depend both on species densities and on auxiliary variables (environmental forcing, population structure, evolving traits) that feed back on the densities. Permanence and its robustness under small perturbations follow from an average Lyapunov condition checked on each Morse set of the extinction-set attractor.
