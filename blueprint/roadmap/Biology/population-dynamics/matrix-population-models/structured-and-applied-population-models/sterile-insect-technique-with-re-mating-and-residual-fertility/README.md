# Sterile insect technique with re-mating and residual fertility

Compartmental models of insect pest control by releasing sterile males, extended to females that mate twice and to sterile males that retain a small fraction of fertile sperm. The key quantities are the basic offspring number of the wild population, a ceiling on residual fertility above which no release size eliminates the pest, and a critical release rate above which elimination is guaranteed.
