# Mutant clone sizes under deterministic wild-type growth

Models in which a deterministically growing wild-type population seeds mutant clones that grow as stochastic branching processes, generalizing the Luria–Delbrück and Lea–Coulson setting beyond exponential growth. Applications include drug resistance, bacterial mutation assays and metastasis sizes in cancer.
