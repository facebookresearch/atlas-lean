# Stage-structured models of partial migration

Discrete-time stage-structured population models in which migrant and resident life histories coexist and both contribute eggs. The basic reproduction number of the coupled population depends on how eggs are allocated between the two life histories, and under strongly sublinear density dependence it is a sharp threshold between extinction and convergence to a unique positive equilibrium.
