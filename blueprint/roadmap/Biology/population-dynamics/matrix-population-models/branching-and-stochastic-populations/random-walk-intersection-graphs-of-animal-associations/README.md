# Random-walk intersection graphs of animal associations

Association networks of solitary animals are built from asynchronous use of shared sites (refuges, burrows): agents are linked if they visited a common site within an observation window. Modelling agents as independent random walks on $\mathbb Z^2$ makes the network a random intersection graph whose edge and hyperedge probabilities follow from first-visit distributions of the walk.
