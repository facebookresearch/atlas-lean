# Delay at which a complex number is a characteristic root

For a real number `r` and a complex number `z`, the root delay is `-log(-z / r) / z`, with the
principal complex logarithm. With the conventions `a / 0 = 0` and `log 0 = 0`, it is `0` when
`z = 0` or `r = 0`. For `r ≠ 0`, if the root delay of `z` is a real number `τ ≠ 0`, then `z` is a
root of the [characteristic function](../hutchinson-delayed-logistic-equation/char-fun.md)
`z + r e^{-z τ}`. For `r > 0` the root delay of `i r` is the
[critical delay](../hutchinson-delayed-logistic-equation/critical-delay.md) `π / (2 r)`.
