# Root delay −log(−z / r) / z of a complex number

For a real number `r` and a complex number `z`, the root delay is `-log(-z / r) / z`, with the
principal complex logarithm. With the conventions `a / 0 = 0` and `log 0 = 0`, it is `0` when
`z = 0` or `r = 0`. For `r > 0`, the [root branch](root-branch.md) is a local inverse of it near
`i r`.
