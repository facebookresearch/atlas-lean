# Complex constant (1 + (π / 2) i) / r² of the root branch

For a real number `r`, the complex number `(1 + (π / 2) i) / r²`. With the convention `a / 0 = 0` it
is `0` for `r = 0`. For `r > 0`, the [root branch](root-branch.md) is built with it as the
derivative of the [root delay](root-delay.md) `z ↦ -log(-z / r) / z` at `z = i r`.
