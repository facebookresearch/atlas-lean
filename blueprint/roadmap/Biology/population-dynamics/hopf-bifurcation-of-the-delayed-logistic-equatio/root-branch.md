# Characteristic root branch through i r

For `r > 0` and a real delay `τ`, the root branch at `τ` is the value at `τ` of the local inverse,
at `i r`, of the [root delay](root-delay.md) `z ↦ -log(-z / r) / z`, whose derivative at `i r` is
the nonzero number `(1 + (π / 2) i) / r²`. The local inverse is defined for every `τ` but is
meaningful only near the [critical delay](../hutchinson-delayed-logistic-equation/critical-delay.md)
`τ_c = π / (2 r)`: at `τ_c` the branch takes the value `i r`, and near `τ_c` it is a
[characteristic root](eventually-char-fun-root-branch.md) for the delay `τ`.
