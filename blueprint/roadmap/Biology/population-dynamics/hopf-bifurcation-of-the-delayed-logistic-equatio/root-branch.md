# Root branch: local inverse of the root delay near i r

For `r > 0` and a real delay `τ`, the root branch at `τ` is the value at `τ` of the local inverse of
the [root delay](root-delay.md) `z ↦ -log(-z / r) / z` near `i r` that the inverse function theorem
provides, with the [constant](root-delay-deriv.md) `(1 + (π / 2) i) / r²` as the derivative of the
root delay at `i r`. The local inverse is defined for every `τ` but is meaningful only near the
[critical delay](../hutchinson-delayed-logistic-equation/critical-delay.md) `τ_c = π / (2 r)`, where
the branch is a [characteristic root](eventually-char-fun-root-branch.md) for the delay `τ`.
