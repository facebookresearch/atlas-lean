# Near the critical delay the root branch is a characteristic root

For `r > 0`, there is a neighbourhood of the
[critical delay](../hutchinson-delayed-logistic-equation/critical-delay.md) `τ_c = π / (2 r)` such
that for every delay `τ` in it, the [root branch](root-branch.md) at `τ` is a root of the
[characteristic function](../hutchinson-delayed-logistic-equation/char-fun.md) `z + r e^{-z τ}`.
