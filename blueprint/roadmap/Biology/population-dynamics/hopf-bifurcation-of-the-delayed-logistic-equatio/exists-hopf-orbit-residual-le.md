# The approximate Hopf orbit has an ε⁴ residual in original variables

For `r > 0` and `K ≠ 0` there is a constant `C` such that for all real `ε` with `|ε| ≤ 1` and all
real `t`, `|x_ε'(t) - r x_ε(t) (1 - x_ε(t - τ(ε)) / K)| ≤ C ε⁴`, where `x_ε` is the
[approximate orbit](hopf-orbit.md) (a smooth function, so `x_ε'` is its classical derivative) and
`τ(ε) = α(ε) / r` its [delay](hopf-delay.md). So `x_ε` solves Hutchinson's equation with delay
`τ(ε)` up to a residual of order `ε⁴`, uniformly in time. In the model `K > 0`.
