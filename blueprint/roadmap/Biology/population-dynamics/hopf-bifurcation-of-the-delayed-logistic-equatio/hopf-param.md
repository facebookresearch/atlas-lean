# Bifurcation parameter of the approximate Hopf orbit

For a real number `ε`, the bifurcation parameter is `α(ε) = π / 2 + (3π - 2) ε² / 40`. In the
scaled equation `v'(s) = -α v(s - 1) (1 + v(s))` it plays the role of `r τ`: for `r ≠ 0` the
corresponding delay is [`τ(ε) = α(ε) / r`](hopf-delay.md), so that `α(ε) = r τ(ε)`. (At `r = 0` the
convention `a / 0 = 0` gives `τ(ε) = 0`.)
