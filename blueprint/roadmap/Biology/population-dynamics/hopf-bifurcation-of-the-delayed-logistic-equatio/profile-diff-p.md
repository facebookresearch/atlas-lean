# Divided-difference formula of the profile polynomial, cos argument

For real numbers `ε`, `C`, `S` and `C'`, the polynomial
`D₁ = ε + ε² (2 (C + C') / 5 + S / 5) + ε³ ((C² + C C' + C'²) / 20 - 3 / 80)`. It is the
divided-difference formula of the [profile polynomial](profile-poly.md) `P` in its first argument.
