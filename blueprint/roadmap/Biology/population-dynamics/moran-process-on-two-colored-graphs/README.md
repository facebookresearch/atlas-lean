# Moran process on two-colored graphs

Resource heterogeneity is modeled by coloring the nodes of a population graph: a node's color sets the fitness of whichever type occupies it. For the birth-death Moran process on biregular graphs with a proper two-coloring, the fixation probability has a closed form, and the direction of selection is decided by geometric-mean fitness across colors.
