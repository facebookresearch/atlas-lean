# Feedback stabilization of age-structured competition

Age-structured (McKendrick–von Foerster) multispecies models with nonlocal interaction terms, in which a harvesting or treatment rate applied to one species is used as a feedback control. Projecting each age profile onto the adjoint eigenfunction of its renewal operator reduces the infinite-dimensional dynamics to a finite-dimensional Lotka–Volterra-type system in logarithmic coordinates, which can be globally stabilized by Lyapunov and backstepping designs.
