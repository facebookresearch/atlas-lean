# Blow-up in the diffusive Trojan Y-chromosome model

The Trojan Y-chromosome strategy releases YY supermales so that an invasive population becomes male-biased and declines. In the classical model the logistic factor multiplies every mating term, so once the total density exceeds the carrying capacity the male equation can lose positivity. Adding diffusion under no-flux boundary conditions does not repair this: the spatial model still admits solutions whose $L^p$ norms blow up in finite time, both for large initial data without releases and for any initial data once the release rate is large enough.
