# Volterra-Lyapunov stable stochastic Lotka-Volterra systems

For Lotka-Volterra communities driven by environmental white noise whose interaction matrix is Volterra-Lyapunov stable, coexistence and extinction are decided by the deterministic Lotka-Volterra system with noise-corrected growth rates $\alpha_i-\tfrac12\Sigma_{ii}$.
