# Marginal value theorem of optimal foraging

A forager exploiting resources distributed in discrete patches, with diminishing returns within a patch and travel time between patches, maximizes its long-term rate of gain by leaving each patch when the instantaneous gain rate falls to the habitat-wide average rate. Sensitivity analysis of this optimum predicts how residence times, and hence movement rates, respond to changes in travel time, patch quality and patch frequencies, in homogeneous and heterogeneous habitats.
