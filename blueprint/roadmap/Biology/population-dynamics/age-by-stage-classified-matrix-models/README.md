# Age-by-stage classified matrix models

Matrix population models in which every individual is classified jointly by age and by a stage (size, developmental or health state), so that vital rates can depend on both. The vec-permutation matrix assembles the joint projection matrix from age-specific stage matrices and stage-specific age matrices, and it reproduces the block-Leslie structure.
