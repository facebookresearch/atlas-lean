# Clone-consistent ecosystem models

A general multi-population model is clone-consistent when splitting a population into two groups of identical individuals leaves its predictions unchanged. This topic characterizes the admissible building blocks: impact functions generated by parameter-weighted sums of abundances, and per-capita growth terms.

- [Impact functions are generated by linear combinations of abundances](impact-functions-are-generated-by-linear-combinations-of-abundances.md)
- [Clone-consistent growth terms are per capita](clone-consistent-growth-terms-are-per-capita.md)
