# Phase-type gonotrophic cycle models

Mosquito population models in which the time spent in the biting (blood-feeding) state has a general phase-type distribution, so that repeated or interrupted biting within one gonotrophic cycle can be represented by a linear chain of transient stages. Population persistence is still decided by an explicit basic offspring number.
