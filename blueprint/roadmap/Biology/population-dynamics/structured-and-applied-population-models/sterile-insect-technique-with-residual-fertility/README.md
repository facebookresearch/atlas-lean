# Sterile insect technique with residual fertility

Stage-structured models of pest or vector control by mass release of sterile males when released males keep a small residual fertility $\varepsilon$ and females may re-mate. Elimination relies on a release-induced strong Allee effect, which exists only below an explicit residual-fertility threshold.
