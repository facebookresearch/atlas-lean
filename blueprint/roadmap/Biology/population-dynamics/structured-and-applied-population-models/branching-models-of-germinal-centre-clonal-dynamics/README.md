# Branching models of germinal-centre clonal dynamics

Stochastic models of the B-cell repertoire in a germinal centre: founder B cells immigrate as a time-inhomogeneous Poisson process and each founds a clone that evolves as an age-dependent (Bellman–Harris type) branching process. The models explain when early clones stay dominant and when differential fitness makes dominant clones be replaced over time.
