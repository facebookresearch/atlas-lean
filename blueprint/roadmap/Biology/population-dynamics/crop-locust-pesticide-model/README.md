# Crop–locust–pesticide model

A four-compartment model couples premature and mature crop biomass with logistic growth and harvesting, a locust population that grows by consuming both, and a pesticide pool sprayed in proportion to locust density. Its locust-free equilibrium is always invadable, and the coexistence equilibrium has explicit coordinates.
