# Random Lotka–Volterra communities with block structure

Large Lotka–Volterra communities with random, non-symmetric interactions reach an equilibrium in which some species go extinct and the survivors follow a truncated Gaussian law. When species form communities with block-dependent interaction variances and correlations, approximate message passing yields $2K$ self-consistent equations that determine the equilibrium abundance distribution of each block.
