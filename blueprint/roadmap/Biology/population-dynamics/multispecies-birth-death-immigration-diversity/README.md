# Multispecies birth–death–immigration diversity

Neutral multispecies birth–death–immigration processes in which every immigrant founds a new species, as models of island biodiversity, gene family sizes and lymphocyte clones. The species-count vector has an explicit reversible steady state, giving Poisson numbers of species of each size, Fisher's logarithmic-series abundance law, and a product-form extension when the death rate depends on total population size.
