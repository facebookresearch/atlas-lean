# Best responses among memory-one strategies

In the iterated prisoner's dilemma a memory-one strategy is a vector of four cooperation probabilities conditioned on the previous round. Its long-run payoff against memory-one opponents is a ratio of quadratic forms in that vector, so best responses to a known set of opponents reduce to a finite candidate set of boundary and stationary points; best responses are often not extortionate.
