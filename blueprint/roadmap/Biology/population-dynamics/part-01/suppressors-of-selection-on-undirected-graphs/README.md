# Suppressors of selection on undirected graphs

In the birth–death Moran process on a graph, a structure is a suppressor of selection if an advantageous mutant placed uniformly at random fixes with lower probability than in a well-mixed population of the same size, for every fitness $r > 1$. Undirected suppressors valid for all $r > 1$ exist already on six vertices.
