# Phenotypic heterogeneity competition games

Non-cooperative games in which each species of asexually reproducing microbes is a distribution of individual competitive abilities with a capped mean, and pairwise encounters are won by the more competitive individual. Equilibrium strategies are exactly the maximally heterogeneous (uniform) distributions, which explains coexistence of many competitors in an unstructured environment.
