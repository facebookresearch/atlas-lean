# Fitness-threshold species survival model

A birth–death ecosystem in which each member carries a random fitness and the least fit are removed when the population shrinks (the Guiol–Machado–Schinazi model and its generalization). Read as an empirical process with random sample size, it shows a sharp survival threshold with non-classical fluctuations.
