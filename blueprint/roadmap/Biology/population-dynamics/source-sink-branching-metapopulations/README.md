# Source–sink branching metapopulations

A density-independent, individual-based metapopulation on a graph of patches of varying habitat quality, modeled as a multitype Galton–Watson process whose type is the dwelling patch. Following the path of a single random disperser decouples reproduction from dispersal and gives explicit persistence criteria, growth rates and ancestral occupancy frequencies.
