# Trait-structured chemostat control

A chemostat in which a microbial population is structured by a continuous phenotypic trait, mutation acts as diffusion in trait space, and the dilution rate is the control. Auxostat-type feedback laws regulate the substrate concentration and drive the population to a stationary trait profile given by a principal eigenfunction; combining them yields reach-and-stay controllability of a target set selecting efficient (low half-saturation) traits and existence of a minimum-time optimal control.
