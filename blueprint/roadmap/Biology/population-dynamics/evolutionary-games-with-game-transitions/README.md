# Evolutionary games with game transitions

In evolutionary dynamics with game transitions, every edge of the interaction graph carries a game state that is updated after each round as a function of the current game and of how many of the two players cooperated. Behavior thus feeds back on the environment in which future interactions take place. Under weak selection the competition between cooperators and defectors on a regular graph is decided by a modified benefit-to-cost rule whose correction terms factor into a transition-pattern coefficient and the payoff difference between games, and the whole process acts as if a single synergistic game were played.
