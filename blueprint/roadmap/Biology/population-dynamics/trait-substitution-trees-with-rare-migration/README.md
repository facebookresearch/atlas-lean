# Trait substitution trees with rare migration

Individual-based adaptive-dynamics models with logistic competition in which individuals occasionally move between occupied trait sites (rare migration) and mutants arise on an even longer time scale. Nearest-neighbor competition along a total fitness order produces equilibria in which every second trait survives, and on the mutation time scale the population follows a jump process on such configurations, the trait substitution tree.
