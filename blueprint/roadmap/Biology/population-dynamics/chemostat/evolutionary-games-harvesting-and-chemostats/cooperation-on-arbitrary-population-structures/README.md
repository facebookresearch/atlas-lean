# Cooperation on arbitrary population structures

Weak-selection evolutionary dynamics of the donation game on any weighted graph under death-Birth updating. Fixation probabilities reduce to coalescence times of random walks, which yields a computable critical benefit-to-cost ratio for every population structure and universal bounds on it.
