# Global convergence of the chemostat

This node records an open direction for the single-species chemostat: global convergence of every solution with positive
initial biomass to the interior steady state when $D < D_c$, which needs an argument about two-dimensional global
dynamics beyond the local results and the invariant region in this folder.
