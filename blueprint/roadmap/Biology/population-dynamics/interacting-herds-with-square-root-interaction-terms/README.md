# Interacting herds with square-root interaction terms

Two-population models in which both species gather in packs or herds, so that only individuals on the perimeter of each group interact and the interaction terms scale as $\sqrt{P}\sqrt{Q}$; after the substitution $X=\sqrt{Q/K}$ the singular Jacobian at the boundary disappears and pack predation against herd defense, and competition between herds, can be analyzed with cubic nullclines.
