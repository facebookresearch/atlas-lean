# Age-structured chemostat with actuator dynamics

Feedback stabilization of a McKendrick–von Foerster population in a bioreactor whose dilution rate is itself a dynamic state driven by the control input. The open-loop model has a continuum of equilibria, so a prescribed operating point must be stabilized by feedback, here by backstepping on top of a logarithmic output-feedback law.
