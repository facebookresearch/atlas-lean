# Splitting trees with neutral immigration

Supercritical age-dependent (Crump–Mode–Jagers) branching populations with general lifetimes, fed by Poisson immigration as in island biogeography. Total population size has explicit negative binomial and Gamma laws, and relative family abundances converge to GEM, Dirichlet or normalized Poisson-process limits.
