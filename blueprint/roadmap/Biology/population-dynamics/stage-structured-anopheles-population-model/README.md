# Stage-structured Anopheles population model

A compartmental model of the malaria vector *Anopheles gambiae* with early larval, late larval, pupal and adult female stages, in which crowding acts only on the feeding larval stages. The model has a lifetime-fecundity oviposition rate, a mosquito reproduction number, and a density-regulated equilibrium where the effective reproduction number equals one.
