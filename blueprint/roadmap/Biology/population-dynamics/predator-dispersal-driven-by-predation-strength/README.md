# Predator dispersal driven by predation strength

Two-patch Rosenzweig–MacArthur prey–predator models in which prey are immobile and predators move non-randomly, towards the patch where the prey–predator encounter term is larger; this attraction-driven dispersal can create or destroy interior equilibria and can stabilize coexistence that is oscillatory in each isolated patch.
