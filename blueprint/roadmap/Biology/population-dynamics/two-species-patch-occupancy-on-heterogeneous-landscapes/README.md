# Two-species patch occupancy on heterogeneous landscapes

A Levins-type patch occupancy model on a continuous, spatially heterogeneous habitat: each site is empty or occupied by one of several species, occupied sites go extinct at site-dependent rates, and empty sites are colonized through kernels. The individual-based model has an integro-differential graphon limit, and for two species competing for empty sites, extinction, exclusion and coexistence are decided by spectral radii of first-generation operators.
