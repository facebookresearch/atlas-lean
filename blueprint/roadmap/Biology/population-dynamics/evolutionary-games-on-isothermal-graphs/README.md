# Evolutionary games on isothermal graphs

On a weighted graph whose edge weights sum to the same value at every vertex, the outcome of a
two-strategy game under weak selection is governed by a single statistic, the effective degree: a
remeeting-time-weighted harmonic average of the vertices' Simpson degrees.
