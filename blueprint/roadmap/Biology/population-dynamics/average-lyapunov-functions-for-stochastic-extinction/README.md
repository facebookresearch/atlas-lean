# Average Lyapunov functions for stochastic extinction

Extinction of a stochastic population or epidemic model means convergence of a Markov process to an invariant boundary set $\mathcal{M}_0$ (some species or the infection absent). An average Lyapunov function $V$ that blows up at $\mathcal{M}_0$ and whose generator has positive average under every invariant measure on $\mathcal{M}_0$ turns sign conditions on boundary Lyapunov exponents into almost-sure exponential extinction, with applications to regime-switching network SIS models and discrete-time ecological models.
