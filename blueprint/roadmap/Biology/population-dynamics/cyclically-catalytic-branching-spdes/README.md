# Cyclically catalytic branching SPDEs

Stochastic reaction–diffusion systems in which each type branches at a rate set by the density of the next type in a cycle, so the noise coefficient is $\sqrt{u_i u_{i+1}}$, with additional mutation between types and immigration. Uniqueness is delicate because the noise coefficient is non-Lipschitz on every coordinate face and mutation can push a vanishing coordinate back into the interior.
