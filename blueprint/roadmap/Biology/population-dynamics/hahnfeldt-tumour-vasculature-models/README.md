# Hahnfeldt tumour–vasculature models

Tumour volume grows in Gompertzian fashion toward a carrying capacity set by the supporting vasculature, which is stimulated and inhibited by the tumour itself. Extensions add drug-resistant subpopulations, cytotoxic chemotherapy and anti-angiogenic treatment, and are used to compare treatment schedules.
