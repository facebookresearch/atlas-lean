# Dispersal and total population size in two-patch models

Two source patches with negative density dependence are coupled by symmetric dispersal. The question is how the asymptotic total population size compares with the sum of the two carrying capacities as the dispersal rate grows from isolation to perfect mixing, and beyond in discrete time. Both the discrete-time Beverton–Holt model and the continuous-time logistic model show exactly four response shapes.
