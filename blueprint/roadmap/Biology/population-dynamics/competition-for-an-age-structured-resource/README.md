# Competition for an age-structured resource

Two consumer populations compete for one resource that is structured by age (for example target cells by age since production), each exploiting it through its own age-dependent interaction kernel. The long-run outcome is fully determined by the two basic reproduction numbers and two invasion fitnesses, and differences in the kernels can produce globally stable coexistence by age-mediated niche partitioning.
