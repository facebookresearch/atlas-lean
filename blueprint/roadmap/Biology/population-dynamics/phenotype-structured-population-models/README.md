# Phenotype-structured population models

Non-local partial differential equations for a population density $n(t,x,y)$ structured by a continuous phenotypic trait $y$ (and possibly by space $x$), in which phenotypic changes act as diffusion in $y$ and selection enters through a trait- and density-dependent fitness. Used for cancer cell populations, collective cell migration and invasion fronts.
