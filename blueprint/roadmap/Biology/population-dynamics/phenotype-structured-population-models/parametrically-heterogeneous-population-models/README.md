# Parametrically heterogeneous population models

When individuals differ in a fixed parameter (susceptibility, growth rate), selection changes the parameter distribution over time. For models in which the parameter enters the per-capita rate linearly, the distributed system reduces exactly to a few ODEs driven by the moment generating function of the initial parameter distribution.
