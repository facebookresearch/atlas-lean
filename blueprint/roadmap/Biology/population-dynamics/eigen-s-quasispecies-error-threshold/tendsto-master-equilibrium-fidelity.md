# Fixed mutation load limit

For all real $\sigma$ and $\mu$, take the per-site fidelity $q_L = 1 - \mu/L$, so that the expected
number of mutations per genome copy is $\mu$ and the error-free probability is $q_L^L$. Then, as
$L \to \infty$ over $\mathbb{N}$, the [interior equilibrium](master-equilibrium.md) $x^* = (\sigma Q - 1)/(\sigma - 1)$ at $Q = q_L^L$ converges to its value
$(\sigma e^{-\mu} - 1)/(\sigma - 1)$ at $Q = e^{-\mu}$ (with the quotient read as $0$ when
$\sigma = 1$; for $L = 0$, $\mu/L$ is read as $0$).
