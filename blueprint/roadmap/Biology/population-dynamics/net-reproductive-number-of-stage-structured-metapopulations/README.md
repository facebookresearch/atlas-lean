# Net reproductive number of stage-structured metapopulations

Discrete-time Usher (stage-structured) matrix models on several patches linked by stage-dependent dispersal. The global net reproductive number is the spectral radius of a next-generation matrix that is never irreducible, but it reduces to a small newborn-to-newborn submatrix, is bracketed by column sums and local reproductive numbers, and can exceed one even when every patch is locally doomed.
