# Plasmid-load structured populations

Bacterial populations structured by the number of high-copy plasmids per cell, with plasmid replication, binomial segregation at division and antibiotic killing of plasmid-free cells. The dominant eigenvalue of the plasmid-bearing block decides between plasmid loss and a stable plasmid-bearing subpopulation, and the segregation strategy maximizing it is evolutionarily stable.
