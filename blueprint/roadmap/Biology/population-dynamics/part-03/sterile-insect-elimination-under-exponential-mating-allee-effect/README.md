# Sterile insect elimination under an exponential mating Allee effect

A minimal egg–male–female mosquito model for the sterile and incompatible insect techniques in which the probability that an emerging female mates is $1-e^{-\beta(M+\gamma_i M_i)}$; the resulting mate-finding Allee effect makes the wild population bistable, so that elimination needs only to push the population below a separatrix, and constant, periodic and impulsive release programs can be dimensioned from a single critical sterile-male density.
