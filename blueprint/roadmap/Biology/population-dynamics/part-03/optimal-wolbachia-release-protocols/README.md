# Optimal Wolbachia release protocols

Optimal control of releases of *Wolbachia*-infected mosquitoes under a limited total stock and a maximal release rate, aiming at replacement of the wild population. In the high-fecundity limit the problem reduces to a bistable frequency equation, whose optimal control is a single full-rate release placed at the start or at the end of the window.
