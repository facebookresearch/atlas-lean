# Extinction below the threshold

For a finite set `ι` of patches, a matrix `C` with nonnegative entries, positive rates `e` and
[persistence number](persistence-number.md) `R₀ < 1`, every [solution](is-solution.md) `p` with
`p_i(0) ∈ [0, 1]` for every patch `i` tends to the empty landscape: `p(t) → 0` as `t → ∞`.
