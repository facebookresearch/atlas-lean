# The empty landscape is linearly unstable if and only if R₀ > 1

For a finite set `ι` of patches, a matrix `C` with nonnegative entries and positive rates `e`, the
linearization `C − diag(e)` of the [vector field](field.md) at the empty landscape has a complex
eigenvalue with positive real part if and only if the [persistence number](persistence-number.md)
satisfies `R₀ > 1`.
