# Linear part and crowding term of the vector field

For a finite set `ι` of patches, every real matrix `C`, all real rates `e` and every `p ∈ ℝ^ι`, the
[vector field](field.md) is `F(p) = (C − diag(e)) p − (p_i (C p)_i)_i`: the linear part
`(C − diag(e)) p` minus the quadratic crowding term `p_i (C p)_i` (colonists landing on occupied
patches are lost).
