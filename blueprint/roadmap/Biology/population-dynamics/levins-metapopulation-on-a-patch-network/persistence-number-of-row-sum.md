# Persistence number with constant row sums and a common extinction rate

For a nonempty finite set `ι` of patches, a matrix `C` with nonnegative entries whose rows all sum
to `c`, and a common extinction rate `ε > 0`, the [persistence number](persistence-number.md) is
`R₀ = c / ε`; so `R₀ > 1` is the well-mixed threshold `c > ε`.
