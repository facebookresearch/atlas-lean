# The empty landscape is linearly stable if and only if R₀ < 1

For a finite set `ι` of patches, a matrix `C` with nonnegative entries and positive rates `e`, the
linearization `C − diag(e)` of the [vector field](field.md) at the empty landscape is Hurwitz (every
complex eigenvalue has negative real part) if and only if the
[persistence number](persistence-number.md) satisfies `R₀ < 1`.
