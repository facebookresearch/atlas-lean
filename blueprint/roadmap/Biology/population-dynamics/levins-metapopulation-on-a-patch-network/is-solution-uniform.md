# Uniform states follow the well-mixed Levins equation

For a finite set `ι` of patches, a real matrix `C` whose rows all sum to `c ≥ 0`, a real extinction
rate `ε` common to all patches and `q₀ ≥ 0`, the uniform state `p_i(t) = q(t)` is a
[solution](is-solution.md) for the rates `e_i = ε`, where `q` is the
[explicit solution](../levins-metapopulation-model/levins.md) of the well-mixed Levins equation
`q' = c q (1 − q) − ε q` with `q(0) = q₀`.
