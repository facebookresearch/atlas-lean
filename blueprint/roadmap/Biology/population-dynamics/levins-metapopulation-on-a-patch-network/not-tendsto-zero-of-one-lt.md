# No extinction above the threshold on an irreducible network occupied at the start

For a nonempty finite set `ι` of patches, an irreducible matrix `C` (nonnegative entries, and for
all patches `i` and `j`, `i = j` included, a chain `i = k₀, k₁, …, k_m = j` with `m ≥ 1` and
`C_{k_l k_{l+1}} > 0` for every `l`), positive rates `e` and
[persistence number](persistence-number.md) `R₀ > 1`, no [solution](is-solution.md) `p` with
`p_i(0) ∈ [0, 1]` for every patch `i` and `p_i(0) > 0` for some patch `i` tends to the empty
landscape.
