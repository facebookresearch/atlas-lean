# Persistence above the threshold on an irreducible network

For a nonempty finite set `ι` of patches, an irreducible matrix `C` (nonnegative entries, and the
directed graph on the patches with an edge between `i` and `j` when `C_ij > 0` is strongly
connected), positive rates `e` and [persistence number](persistence-number.md) `R₀ > 1`, no
[solution](is-solution.md) `p` with `p_i(0) ∈ [0, 1]` for every patch `i` and `p_i(0) > 0` for some
patch `i` tends to the empty landscape.
