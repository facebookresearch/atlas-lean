# Moran effect and spatial synchrony

Spatially separated populations fluctuate in synchrony when they are driven by spatially correlated environmental fluctuations, the Moran effect. For linear dynamics the population correlation equals the environmental correlation; with several drivers, cross-covariances between drivers add interaction terms that can reinforce or cancel synchrony, and timescale-specific (wavelet) versions quantify how much observed synchrony a set of drivers explains.
