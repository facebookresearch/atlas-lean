# Perron left vector of the colonization network

For a nonempty finite set `ι` of patches, an irreducible matrix `C` (nonnegative entries, and for
all patches `i` and `j`, `i = j` included, a chain `i = k₀, k₁, …, k_m = j` with `m ≥ 1` and
`C_{k_l k_{l+1}} > 0` for every `l`) and positive rates `e`, there are a real `r ≥ R₀`, where `R₀`
is the [persistence number](persistence-number.md), and a vector `w` with positive entries such that
`∑_j w_j C_ji = r e_i w_i` for every patch `i`.
