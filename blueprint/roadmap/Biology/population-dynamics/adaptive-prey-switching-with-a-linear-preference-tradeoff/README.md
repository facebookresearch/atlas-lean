# Adaptive prey switching with a linear preference tradeoff

One-predator, two-prey Lotka–Volterra systems in which the predator switches its diet between a preferred prey and a defended alternative prey across the line $p_1 = a_q p_2$ set by a linear preference tradeoff. Smooth regularizations of the discontinuous switching model, either a tanh transition or a dynamic preference trait, have different stability properties for the coexistence state.
