# Type I membranes have nonnegative phase-resetting curves

Ermentrout (1996) studies the infinitesimal phase-resetting curve, or response function, of a membrane oscillator near the onset of repetitive firing; the response function is the periodic solution of the adjoint of the linearization about the stable limit cycle (the source credits this characterization to Ermentrout and Kopell 1991). For type I membranes, in which repetitive firing arises through a saddle-node bifurcation on an invariant circle (the Connor model, and the Morris–Lecar model in its type I regime), reduction near the critical current to the normal form $\dot\theta = f(\theta) + g(\theta) S(t)$ with $f(\theta) = q(1 - \cos\theta) + c(1 + \cos\theta)$, $c > 0$, and $g(\theta) = 1 + \cos\theta$ gives the response function $Z(\theta) = K(1 + \cos\theta)$. Hence every type I membrane oscillator near the critical current has a nonnegative infinitesimal phase-resetting curve: a small brief excitatory input can advance the next spike but cannot delay it. For a membrane that begins to oscillate through a supercritical Hopf bifurcation, the oscillation near onset is sinusoidal and the response function has the form $Z(t) = Z_1 \cos\omega t + Z_2 \sin\omega t$, which takes both signs (type II resetting).

## Expansion

1. The model: one-parameter families of membrane equations with a stable limit cycle, and the response function as the normalized periodic solution of the adjoint linearized equation.
2. The type I case: the singular-perturbation and averaging reduction near the saddle-node on the circle to the normal form above, and the computation $Z(\theta) = K(1 + \cos\theta)$ by trigonometric identities.
3. The type II case: the adjoint of a small sinusoidal oscillation at a supercritical Hopf bifurcation.
4. The canonical phase interaction functions and the consequences for synchrony of weakly coupled type I oscillators, as separate statements.
