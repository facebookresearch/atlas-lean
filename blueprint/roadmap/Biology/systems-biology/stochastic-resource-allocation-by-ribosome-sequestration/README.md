# Stochastic resource allocation by ribosome sequestration

A stochastic chemical reaction network for translation under a regulation mechanism of stringent-response type: ribosomes pair with mRNAs, elongating complexes consume charged tRNAs to make proteins, and when the amino-acid supply is low, free tRNAs sequester ribosomes. Scaling limits with $N$ ribosomes show three regimes, one of which (optimal sequestration) keeps elongating ribosomes $O(1)$ while using almost all resources.
