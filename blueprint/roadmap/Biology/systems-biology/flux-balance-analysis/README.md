# Flux balance analysis

Genome-scale metabolic models are analysed at steady state as linear programs: reaction fluxes must balance every internal metabolite and respect capacity bounds, and an objective such as biomass production is optimized. Reconstruction toolboxes build the stoichiometric matrix from genome annotation and databases, and simulate with flux balance analysis and sampling of the feasible flux space.
