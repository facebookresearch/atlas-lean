# Equilibrium of the toggle switch in the closed quadrant

For reals `α₁, α₂`, `β, γ ∈ ℕ` and reals `u, v`, `(u, v)` is an equilibrium of the toggle switch
`u' = α₁ / (1 + v^β) − u`, `v' = α₂ / (1 + u^γ) − v` if `u ≥ 0`, `v ≥ 0` and both right-hand sides
vanish: `u = α₁ / (1 + v^β)` and `v = α₂ / (1 + u^γ)`. Since the denominators are positive for
`u, v ≥ 0`, an equilibrium can exist only when `α₁ ≥ 0` and `α₂ ≥ 0`.
