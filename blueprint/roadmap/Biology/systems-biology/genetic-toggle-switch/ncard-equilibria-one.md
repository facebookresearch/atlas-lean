# For a, b > 0 and β = 1, equilibria are counted by positive roots

For `a > 0` and `b > 0`, the number of [equilibria](is-equilibrium.md) of the toggle switch with
Hill exponent `β = 1`, any `γ ∈ ℕ`, and rates `a = α₁`, `b = α₂` equals the number of positive real
roots of the [equilibrium polynomial](equilibrium-poly-one.md) `X^{γ+1} − a X^γ + (1 + b) X − a`.
