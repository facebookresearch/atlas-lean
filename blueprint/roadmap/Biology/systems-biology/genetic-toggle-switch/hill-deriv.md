# Derivative of the Hill repression function

For a real `α`, `n ∈ ℕ` and a real `x`, `h'(x) = −α n x^{n−1} / (1 + xⁿ)²`, with `n − 1` read as `0`
for `n = 0` (the value is then `0`) and the convention `x / 0 = 0` (the value is `0` when
`xⁿ = −1`). For `x ≥ 0` it is the derivative at `x` of the [Hill repression](hill.md)
`x ↦ α / (1 + xⁿ)`.
