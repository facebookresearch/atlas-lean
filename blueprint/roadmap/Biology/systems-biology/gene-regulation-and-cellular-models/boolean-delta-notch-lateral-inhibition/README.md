# Boolean Delta–Notch lateral inhibition

Asynchronous Boolean models of Delta–Notch signalling on a graph of cells, in which a cell's Notch is activated by Delta in its neighbours and Notch represses the cell's own Delta. Stable spatial patterns are combinatorial objects of the cell graph (minimal vertex covers, or transversals of a hypergraph for threshold variants), every state can reach one, and there are no cyclic attractors.
