# Down-regulation in the ribosome flow model

The ribosome flow model is a deterministic mean-field approximation of the totally asymmetric simple exclusion process for ribosomes moving along an mRNA. Its steady-state production rate is a concave, positively homogeneous function of the transition rates, so minimising translation under a budget of rate reductions is a concave minimisation whose optimum sits at a vertex of the feasible set, and the best single rate to reduce is the one with the largest sensitivity.
