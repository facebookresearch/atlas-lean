# Minimal perturbation of asynchronous Boolean networks

Which smallest set of gene activations and repressions forces a Boolean regulatory network to stay inside, or away from, a set of global states? For asynchronous dynamics this is a reachability question on the state graph, solved for fixed perturbation size in time polynomial in the state graph and scaled up with Petri-net unfoldings, including networks with uncertain regulation functions.
