# Completeness of probabilistic unfolding for uncertain regulation functions

Suppose each gene of an asynchronous Boolean regulatory network has several alternative regulation functions, each with a probability of being the true one, independently across genes. The probability of a set $S$ of regulation functions (at most one per gene) is the product of their probabilities, and a trajectory generated by $S$ uses only functions in $S$. For a threshold $0 \leq \alpha \leq 1$, the network has the **probabilistic phenotype** $P$ with respect to its initial states if every set $S$ with probability $\geq \alpha$ generates only trajectories that remain in $P$; it **avoids** $P$ if no such $S$ generates a trajectory entering $P$. (If the condition holds for $S$ it holds for every $S' \subseteq S$.) Testing all such sets naively is exponential: with $k$ alternatives per gene there are $(k+1)^n$ candidate sets.

Translate the network into a Petri net in which each alternative regulation function contributes its own transitions, and build McMillan's branching process (unfolding) with these modifications. For a configuration $C$, let $\varphi(C)$ be the set of regulation functions its transitions use and $\varphi'(C) \subseteq \varphi(C)$ those with probability $< 1$; a transition may extend $C$ only if $\varphi'(C \cup \{t\})$ is **unambiguous** (no two functions for the same gene). A transition $t$ is a cutoff point if either
1. some transition $t'$ has a local configuration $[t']$ with the same marking, fewer transitions, and $\varphi'([t']) \subseteq \varphi'([t])$; or
2. the product of the probabilities of the functions used in $[t]$ is $< \alpha$.

**Theorem.** In the resulting finite branching process: (i) if some set $F$ of regulation functions with probability $\geq \alpha$ generates a trajectory that leaves the phenotype $P$, then such a trajectory is represented by a configuration $C$ with $\varphi'(C) \subseteq F$; (ii) if some $F$ with probability $\geq \alpha$ generates a trajectory that enters a prohibited phenotype $P$, then such a trajectory is represented by a configuration $C$ with $\varphi'(C) \subseteq F$.

Hence the probabilistic phenotype holds (or the prohibited phenotype is avoided) exactly when no configuration of the finite branching process with probability $\geq \alpha$ reaches a violating marking. Combined with clamping genes, this extends the minimal perturbation search to partially known networks.

## Expansion

The proof is an induction on the length $N$ of a state-graph path to a violating state $S$. Its prefix of length $N-1$ reaches $S'$ and, by induction, is represented by a configuration $C'$ with $\varphi'(C') \subseteq F$. The transition $t'$ realizing the last edge can be appended, since its input places are outputs of $C'$; it is not cut by criterion 2 because all its functions lie in $F$. If criterion 1 cuts it, a smaller local configuration $C''$ with the same marking and $\varphi'(C'') \subseteq \varphi'([t']) \subseteq F$ exists, and the remainder of the trajectory can be replayed from $C''$ in the infinite unfolding (substituting probability-one functions when needed, which leaves the probability unchanged). Repeating at each new cutoff strictly shrinks the local configuration at the cutoff, so the process terminates in a configuration present in the finite unfolding. The added subset condition in criterion 1 prevents pruning a branch whose replacement relies on less likely functions, at the price of a possibly larger branching process than the classical unfolding.
