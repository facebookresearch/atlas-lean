# Trap spaces and motif-avoidant attractors

Let $f = (f_1, \dots, f_N) : \{0,1\}^N \to \{0,1\}^N$ be a Boolean network. Under **asynchronous update**, the state transition graph (STG) has an edge from $x$ to the state obtained by replacing $x_i$ by $f_i(x)$, for each $i$ with $f_i(x) \ne x_i$. An **attractor** is a terminal strongly connected component of the STG (a minimal trap set): a **point attractor** if it is a single state, a **complex attractor** otherwise.

A **subspace** is a subcube $\{x : x_i = c_i \text{ for } i \in I\}$ with some coordinates fixed and the rest free (written e.g. $10{*}{*}$). A **trap space** is a subspace that no transition leaves; a **minimal trap space** contains no smaller trap space. Each minimal trap space is generated by **stable motifs**, self-sustaining feedback configurations among the fixed variables.

1. Trap spaces depend only on $f$, not on the update scheme.
2. Every trap space contains at least one attractor; in particular each minimal trap space contains an attractor.
3. An attractor contained in no minimal trap space is **motif-avoidant** (MAA). For an MAA, the smallest subspace containing it is not a minimal trap space: either it is not a trap space (some state of it has a transition leaving it), or it contains a minimal trap space disjoint from the attractor.
4. The set of minimal trap spaces identifies all attractors exactly when no MAA exists. MAAs are impossible when the interaction graph has no cycles, has only positive or only negative cycles, has no path from a non-positive cycle to a non-negative cycle (cycle signs being products of edge signs $+1$, $-1$, $0$), or is L-cuttable: a linear node (in-degree and out-degree one) occurs in every cycle, self-loops included, and on every path from a node with several targets to a node with several regulators.

MAAs do not require non-monotone update functions or negative self-loops, and low canalization favours them. In large ensembles they are rare: none appeared in published biological Boolean models under their input contexts, under $0.04\%$ of sparse critical random networks ($K = 2$, $N > 10$) carried one, but about $1.6\%$ of dense ones ($N = K = 10$) did; MAAs in biological models arose only after network reduction by deletion of nodes.

## Expansion

Item 1 holds because the condition that no transition leaves a subcube only requires $f_i(x) = c_i$ for every fixed coordinate $i$ and every $x$ in the subcube, a property of $f$ alone. Item 2 follows because a trap space is a closed set of the finite STG, so any terminal strongly connected component reachable inside it stays inside it. MAAs exist because asynchronous dynamics can circulate in a region from which a trap space is combinatorially reachable as a subcube but not dynamically reachable, the required update order never occurring; the smallest example is a two-variable network with an oscillating attractor beside a fixed-point trap space. Since states outside a trap space that can reach it are not in any attractor, any modification making the MAA's states reach the trap space removes it, which is the mechanism exploited by delay insertion. Deleting a node (substituting its update function into its targets) can remove transitions and so create MAAs, cautioning against aggressive model compression.
