# Infinitesimal homeostasis in input-output networks

Infinitesimal homeostasis is the vanishing of the derivative of an output variable with respect to an external input along a stable equilibrium branch of a network ODE. For network-admissible systems it reduces to the vanishing of one irreducible block of a homeostasis matrix, and the blocks are classified from the network graph into appendage and structural types.
