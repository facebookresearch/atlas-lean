# Substrate hypergraph cycles

A substrate hypergraph records which substrates each enzymatic composite reaction consumes and produces. When it is a cycle (strongly connected, each substrate produced and consumed exactly once), every Henri-Michaelis-Menten realization has a unique, persistent positive steady state in each compatibility class, whatever the enzyme assignment; global convergence holds without enzyme sharing, while sharing an enzyme between two of three reactions already permits stable oscillations.
