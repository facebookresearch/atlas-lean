# Analog computation with mass-action systems

A deterministic mass-action system computes a number when a designated concentration converges to it; the exponential rate of that convergence is the speed of computation. Autocatalytic module designs make every elementary arithmetic operation run at speed independent of its inputs, and composing modules in parallel never slows a computation below its slowest step.
