# Multivalued logical networks

Gene regulatory networks whose nodes take $m+1$ ordered expression levels $X_m=\{0,\tfrac1m,\dots,1\}$ can be written with the operations of Łukasiewicz many-valued logic. Every update function is expressible through truncated sum, negation and constants, and networks built only from truncated products of literals have update functions of the form $\max\{0,\text{linear}\}$, which turns steady-state computation into piecewise-linear algebra.
