# Independent decompositions of reaction networks

Splitting the reaction set of a chemical reaction network so that the stoichiometric subspace is the direct sum of the subnetworks' subspaces. Steady states of the whole network are then exactly the common steady states of the pieces, which lets closed-form positive steady states be assembled from small subnetworks.
