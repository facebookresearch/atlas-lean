# Robust Lyapunov functions of reaction networks

Lyapunov functions written in terms of reaction rates that certify convergence of a biochemical network for every monotone kinetics, not just mass action. Their existence reduces to a common Lyapunov function problem for finitely many rank-one linear systems, giving computational and graphical tests of structural attractivity.
