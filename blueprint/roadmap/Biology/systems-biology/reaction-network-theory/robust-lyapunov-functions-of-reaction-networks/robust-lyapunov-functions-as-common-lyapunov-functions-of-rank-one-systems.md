# Robust Lyapunov functions as common Lyapunov functions of rank-one systems

Consider a reaction network with species $X_1, \dots, X_n$, reactions $R_1, \dots, R_\nu$, reactant and product stoichiometric matrices $A, B$, and stoichiometry matrix $\Gamma = B - A \in \mathbb{R}^{n \times \nu}$, with dynamics $\dot x = \Gamma R(x)$ on $\bar{\mathbb{R}}_+^n$. Kinetics $R$ are **admissible** if each $R_j$ is $C^1$, vanishes when any of its reactants is zero, is nondecreasing in each of its reactants and independent of non-reactants, and strictly increasing in its reactants on the open orthant; mass action and Michaelis–Menten kinetics are special cases.

A locally Lipschitz function $\tilde V : \mathbb{R}^\nu \to \mathbb{R}_{\ge 0}$ is a **robust Lyapunov function (RLF)** if $\tilde V(r) = 0$ exactly when $\Gamma r = 0$ and $V(x) = \tilde V(R(x))$ is nonincreasing along trajectories (in the sense of Dini derivatives) for every admissible $R$; a network admitting one is **structurally attractive**.

Let $\mathcal{P} = \{(j,i) : X_i \text{ is a reactant of } R_j\}$ be the reaction–reactant pairs, enumerated $(j_\ell, i_\ell)$, $\ell = 1, \dots, s$, and let $\gamma_i^{\mathsf T}$ be the $i$-th row of $\Gamma$. Define the rank-one matrices

$$Q_\ell = e_{j_\ell}\,\gamma_{i_\ell}^{\mathsf T} \in \mathbb{R}^{\nu \times \nu}, \qquad \ell = 1, \dots, s.$$

**Theorem.** A function $\tilde V : \bar{\mathbb{R}}_+^\nu \to \bar{\mathbb{R}}_+$ is an RLF for the network if and only if it is a common Lyapunov function for the linear systems $\dot r = Q_1 r, \dots, \dot r = Q_s r$ (with zero set $\bigcap_\ell \ker Q_\ell$).

In particular, a convex piecewise-linear candidate $\tilde V(r) = \max_{0 \le k \le m} c_k^{\mathsf T} r$ ($c_0 = 0$) can be searched for by linear programming; when $\Gamma$ has a positive kernel vector it can be written $\|C r\|_\infty$. A **sum-of-currents** RLF has the form $V(x) = \sum_i \xi_i |\dot x_i| = \|\mathrm{diag}(\xi)\,\Gamma R(x)\|_1$ with $\xi > 0$.

## Expansion

Differentiating along trajectories gives $\dot r = (\partial R/\partial x)\,\Gamma\, r$ in rate coordinates, and the admissibility conditions fix the sign pattern of the Jacobian $\partial R/\partial x$: its $(j,i)$ entry is nonnegative when $(j,i) \in \mathcal{P}$ and zero otherwise. Hence $(\partial R/\partial x)\Gamma$ ranges over the convex cone generated by $Q_1, \dots, Q_s$, so decrease for all admissible kinetics is equivalent to decrease along each extremal linear system. This turns a statement quantified over unknown nonlinear kinetics into a finite-dimensional search, implemented by iterative and linear-programming algorithms. Consequences for networks with a piecewise-linear RLF include $P_0$ negative Jacobians, uniqueness and exponential stability of positive steady states in each stoichiometric class when the reduced Jacobian is nonsingular at one point for one admissible kinetics, and non-existence when there is a critical siphon in a conservative network with a nondegenerate positive steady state. Unlike deficiency theory, the approach covers deficiency-one networks such as transcription, translation and phosphorylation cycles.
