# Path connectivity of the multistationarity region

**Setting.** Consider a mass-action reaction network with $n$ species, $r$ reactions, stoichiometric matrix $N$ of rank $s$, rate constants $\kappa \in \mathbb{R}^r_{>0}$ and steady-state variety $V_\kappa = \{x \in \mathbb{R}^n_{>0} : N v_\kappa(x) = 0\}$. Fix the row-reduced matrix $W \in \mathbb{R}^{(n-s) \times n}$ whose rows form a basis of the conservation laws (the left kernel of $N$), with stoichiometric classes $P_c = \{x : Wx = c\}$, and let $i_j$ be the index of the first nonzero entry of row $j$ of $W$. Let $M_\kappa(x)$ be the Jacobian of $x \mapsto N v_\kappa(x)$ with row $i_j$ replaced by row $j$ of $W$, for $j = 1, \dots, n - s$. Assume the network is **dissipative** (trajectories eventually enter a compact set in each class) and has no relevant boundary steady states. Then (Theorem 1, from earlier work) $(\kappa, c)$ enables multistationarity if $(-1)^s \det M_\kappa(x) < 0$ for some $x \in V_\kappa \cap P_c$, and does not if it is positive on all of $V_\kappa \cap P_c$.

Let $\mathcal{V} = \{(x, \kappa) : x \in V_\kappa\}$ and let $\Phi : D \to \mathcal{V}$ be a parametrization (a surjective analytic map, typically rational on a positive orthant). With $g(x, \kappa) = (-1)^s \det M_\kappa(x)$, the **critical function** is $g \circ \Phi : D \to \mathbb{R}$. The **multistationarity region** $\Omega \subseteq \mathbb{R}^r_{>0} \times \mathbb{R}^{n-s}$ is the set of pairs $(\kappa, c)$ that enable multistationarity.

**Theorem 2 (deciding connectivity).** If the closure of $(g \circ \Phi)^{-1}(\mathbb{R}_{<0})$ equals $(g \circ \Phi)^{-1}(\mathbb{R}_{\le 0})$, then the number of path-connected components of $\Omega$ is at most that of $(g \circ \Phi)^{-1}(\mathbb{R}_{<0})$. In particular, $\Omega$ is path connected whenever $(g \circ \Phi)^{-1}(\mathbb{R}_{<0})$ is.

**Theorem 3 (negative preimage of a polynomial).** Let $f : \mathbb{R}^k_{>0} \to \mathbb{R}$ be a polynomial with positive-coefficient exponents $\sigma_+(f)$ and negative-coefficient exponents $\sigma_-(f)$. If there is a strict separating hyperplane, i.e. $(v, a) \in \mathbb{R}^{k+1}$ with $v \cdot \alpha \le a$ for all $\alpha \in \sigma_+(f)$, $v \cdot \beta \ge a$ for all $\beta \in \sigma_-(f)$ and $\sum_{\beta \in \sigma_-(f)} (v \cdot \beta - a) > 0$, then $f^{-1}(\mathbb{R}_{<0})$ is path connected and its closure is $f^{-1}(\mathbb{R}_{\le 0})$.

**Theorem 4 (reduction).** For a conservative network in which species $X_1, \dots, X_k$ each take part in exactly three reactions $\sum_i a_{ij} X_i \rightleftharpoons X_j \to \sum_i b_{ij} X_i$ (an intermediate complex with reversible formation), the bound of Theorem 2 computed for the reduced network, in which each reverse reaction $X_j \to \sum_i a_{ij} X_i$ is removed, bounds the number of path-connected components of the multistationarity regions of both the reduced and the original network.

## Expansion

The determinant criterion turns multistationarity into the existence of a steady state where $g < 0$; projecting the parametrized negativity set onto parameters $(\kappa, Wx)$ gives exactly $\Omega$, and continuous images of path-connected sets are path connected. The closure hypothesis ensures that parameters on the boundary where $g$ vanishes do not create extra components. For polynomials, a strict separating hyperplane lets one deform any negative point along monomial curves $t \mapsto t^{v}$ toward a region where negative monomials dominate, joining all points of the negative set; checking the hyperplane is a linear program, so the method is fully computational. Removing reverse intermediate reactions eliminates extreme rays of the flux cone and reduces the number of variables. The method certifies path connectivity of multistationarity regions for several phosphorylation and signalling cascades.
