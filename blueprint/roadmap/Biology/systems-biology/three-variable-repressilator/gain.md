# Loop gain at the symmetric equilibrium

For `n ∈ ℕ` and a real `p`, `a(p) = n pⁿ / (1 + pⁿ)`, with the convention `x / 0 = 0`: `a(p) = 0`
when `pⁿ = −1` (`n` odd and `p = −1`). For `p ≥ 0` it is minus the
[slope](has-deriv-at-repression.md) at `y = p` of the repression function
`y ↦ p (1 + pⁿ) / (1 + yⁿ)`: the loop gain at the symmetric equilibrium of level `p`.
