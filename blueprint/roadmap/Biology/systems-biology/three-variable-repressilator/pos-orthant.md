# Parameters and states with positive concentrations

The set of pairs `(μ, x) ∈ ℝ × ℝ³` with `x₀, x₁, x₂ > 0`; the parameter `μ` is arbitrary. It is
open, and on it the map `(μ, x) ↦ F(x)`, with `F` the [repressilator field](vector-field.md) with
rate `μ (1 + μⁿ)`, is infinitely differentiable for every `n ∈ ℕ`.
