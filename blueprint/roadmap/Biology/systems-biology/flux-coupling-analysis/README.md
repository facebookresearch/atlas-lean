# Flux coupling analysis

Flux coupling analysis classifies pairs of reactions of a metabolic network by whether a nonzero steady-state flux through one forces a nonzero flux through the other. The relations are determined by the steady-state flux cone, can only take restricted forms depending on the reversibility types of the two reactions, and can be decided by feasibility tests of linear systems instead of optimization.
