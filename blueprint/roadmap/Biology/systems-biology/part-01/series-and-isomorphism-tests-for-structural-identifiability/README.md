# Series and isomorphism tests for structural identifiability

For an analytic input–state–output model $\dot x = f(x,u,\theta)$, $y = h(x,\theta)$, structural identifiability asks whether the parameter vector $\theta$ is determined by noise-free continuous output data. Two classical sufficient tests expand the output in a series at the initial state and solve for $\theta$ from the coefficients; a third, the similarity-transformation test, characterizes global identifiability through the absence of nontrivial state isomorphisms between models with different parameters.
