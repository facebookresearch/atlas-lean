# Reaction network inference from mass-action ODEs

Many systems-biology models are published only as ODEs. When the right-hand sides are mass-action polynomials with symbolic rate constants, the reaction network (reactants, products and stoichiometry) that generated them can be read back from the monomials, and under mild syntactic conditions it is unique.
