# Autocatalytic sets and RAF theory

A catalytic reaction system consists of molecule types, reactions, a catalysis relation and a food set of freely available molecules. A reflexively autocatalytic and food-generated (RAF) set is a set of reactions in which every reaction is catalysed by a molecule of the system and every reactant can be built from the food set using only those reactions. RAF sets give a combinatorial notion of a self-sustaining chemistry; the maximal RAF is unique and computable in polynomial time, whereas minimising the food set needed to sustain a RAF is NP-complete. Applied to the cytosolic metabolic network of *E. coli*, the maxRAF covers almost the whole network.
