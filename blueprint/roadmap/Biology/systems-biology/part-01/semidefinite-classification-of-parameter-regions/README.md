# Semidefinite classification of parameter regions

Convex relaxations of the polynomial steady-state equations of mass-action models, together with measured concentration bounds, decide whether a parameter set is consistent with data. Dual certificates prove inconsistency, and a robust matrix inequality extends one certificate to a whole box of rate constants, so parameter space can be partitioned without sampling gaps.
