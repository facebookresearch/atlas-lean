# Emergence of autocatalytic sets in random catalysis

A reflexively autocatalytic and food-generated (RAF) set is a set of reactions in which every reaction is catalyzed by a molecule of the set and every reactant can be built from a food set. In random catalysis models the question is how much molecular diversity is needed before such sets exist; for elementary networks, where every molecule is made directly from food, this reduces to the appearance of a directed cycle in a random digraph.
