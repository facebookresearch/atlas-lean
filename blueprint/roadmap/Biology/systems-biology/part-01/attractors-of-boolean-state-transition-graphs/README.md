# Attractors of Boolean state transition graphs

Boolean models of gene regulatory networks under synchronous and asynchronous update induce finite state transition graphs whose attractors (steady states and cycles) represent cell phenotypes. Attractors are exactly the terminal strongly connected components, which can be found symbolically from forward and backward reachable sets.
