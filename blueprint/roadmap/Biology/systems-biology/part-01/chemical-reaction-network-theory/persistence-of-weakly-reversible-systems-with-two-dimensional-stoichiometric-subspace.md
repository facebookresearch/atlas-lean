# Persistence of weakly reversible systems with two-dimensional stoichiometric subspace

This node covers the following result. A $\kappa$-variable mass-action system on a reaction network is given by rate functions $K_{y \to y'}(t, x) = \kappa_{y \to y'}(t)\, x^{y}$, where the rate-constant function $\kappa$ is piecewise differentiable on $[0, \infty)$ and takes values in $(\eta, 1/\eta)$ for some $0 < \eta < 1$; the concentrations then solve $\dot x(t) = \sum_{y \to y'} \kappa_{y \to y'}(t)\, x(t)^{y} (y' - y)$. For a weakly reversible $\kappa$-variable mass-action system whose stoichiometric subspace is two-dimensional, every bounded trajectory $x(t)$ with positive initial condition $x(0) \in \mathbb{R}^n_{>0}$ is persistent: $\liminf_{t \to \infty} x_i(t) > 0$ for every species $i$.
