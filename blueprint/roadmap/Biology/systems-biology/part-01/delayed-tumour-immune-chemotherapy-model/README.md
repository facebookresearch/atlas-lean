# Delayed tumour-immune chemotherapy model

A delay differential model of effector immune cells, tumour cells and normal cells, in which immune recruitment responds to the tumour after a delay and a cytotoxic drug kills all three cell types with different efficacies. The topic collects the delay-independent stability threshold of the tumour-free state and the Pontryagin optimality system for chemotherapy dosing under a normal-tissue constraint.
