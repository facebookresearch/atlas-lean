# Piecewise approximate Bayesian computation

For a discretely observed Markov process (for example a stochastic Lotka–Volterra or chemical reaction network), the Markov property factorises the posterior into one factor per observed transition. Running approximate Bayesian computation on each low-dimensional factor avoids summary statistics and permits very small tolerances; the factor densities are then estimated (by Gaussian or Gaussian-kernel fits) and multiplied.
