# Intervention in probabilistic Boolean networks

Therapeutic control of gene regulatory networks modelled as Boolean networks with random perturbations or probabilistic Boolean networks, whose dynamics are ergodic finite Markov chains. Flipping a control gene in one state replaces one row of the transition matrix, a rank-one perturbation whose effect on the stationary distribution is explicit; greedy policies built on this shift move stationary mass away from undesirable phenotypes.
