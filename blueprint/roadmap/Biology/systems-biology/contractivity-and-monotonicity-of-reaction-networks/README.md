# Contractivity and monotonicity of reaction networks

A reaction network whose lifted dynamics are strongly monotone with respect to a polyhedral cone is weakly contractive on each stoichiometric compatibility class with respect to a norm built from that cone. Structural factorizations of the stoichiometric matrix certify such cones for every admissible kinetics, which yields global convergence to equilibria.
