# Cyclic repressor ring oscillators

Rings of genes in which each protein represses the next. The parity of the ring decides the qualitative behavior (even rings are monotone and multistable, odd rings are negative feedback loops that can oscillate), and for odd rings explicit inequalities on Hill coefficient, production gain and decay rates guarantee oscillation.
