# In-tree weights of an irreducible rate matrix are positive

Let $\iota$ be a finite set and $Q \in \mathbb{R}^{\iota \times \iota}$ an [irreducible](is-irreducible.md) rate matrix (nonnegative off-diagonal entries, zero row
sums). Then every [in-tree weight](tree-weight.md) $w(r)$, $r \in \iota$, is positive.
