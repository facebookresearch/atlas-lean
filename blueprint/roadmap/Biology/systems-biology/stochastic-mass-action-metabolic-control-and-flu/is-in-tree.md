# Spanning in-tree rooted at a state

Let $\iota$ be a finite set and $r \in \iota$. A map $t \colon \iota \to \iota$ is a spanning in-tree rooted
at $r$, each $i \ne r$ pointing to its parent $t(i)$, when $t(r) = r$ and every $i \in \iota$ reaches
$r$ under iteration: $t^k(i) = r$ for some $k \ge 0$.
