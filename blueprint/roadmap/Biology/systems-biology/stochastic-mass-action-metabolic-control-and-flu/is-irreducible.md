# Irreducible rate matrix

Let $\iota$ be a finite set and $Q \in \mathbb{R}^{\iota \times \iota}$. The matrix $Q$ is irreducible when every state reaches every other state through positive
jump rates: for all $i, j$ there is a chain $i = a_0, a_1, \dots, a_k = j$, $k \ge 0$, with
$a_{l+1} \ne a_l$ and $Q_{a_l a_{l+1}} > 0$ for every $l < k$.
