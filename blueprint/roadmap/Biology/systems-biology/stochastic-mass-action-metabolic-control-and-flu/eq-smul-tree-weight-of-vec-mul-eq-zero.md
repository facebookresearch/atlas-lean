# Uniqueness in the Markov chain tree theorem

Let $\iota$ be a finite set and $Q \in \mathbb{R}^{\iota \times \iota}$ an [irreducible](is-irreducible.md) rate matrix (nonnegative off-diagonal entries, zero row
sums). If a row vector $\pi \in \mathbb{R}^\iota$ satisfies $\pi Q = 0$, then $\pi = a\, w$ for some
$a \in \mathbb{R}$, where $w$ are the [in-tree weights](tree-weight.md): an invariant vector is proportional, at each state,
to the weight of the spanning in-trees rooted there.
