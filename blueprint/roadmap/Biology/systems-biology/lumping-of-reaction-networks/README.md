# Lumping of reaction networks

Exact linear lumping replaces the species concentrations of a reaction network by fewer linear combinations that obey a closed ODE. For generic rate constants only the obvious reductions exist (dropping non-reactant species and quotienting by stoichiometric first integrals); nontrivial lumpings appear only on algebraic sets of critical parameters.
