# Michaelis-Menten interaction networks

Networks of species with linear decay that activate or inhibit one another through saturating Michaelis-Menten response functions. Because every such response contracts logarithmic distances, these networks have a unique equilibrium that is globally asymptotically stable, even with arbitrary transmission delays.
