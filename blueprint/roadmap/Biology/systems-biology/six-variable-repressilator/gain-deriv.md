# Derivative of the loop gain

For `n ∈ ℕ` and a real `μ`, `a'(μ) = n² μⁿ⁻¹ / (1 + μⁿ)²`, with `n − 1` read as `0` for `n = 0` (the
value is then `0`) and the convention `x / 0 = 0` (the value is `0` when `μⁿ = −1`). For `μ ≥ 0` it
is the [derivative](../three-variable-repressilator/has-deriv-at-gain.md) of the
[loop gain](../three-variable-repressilator/gain.md) `a(μ) = n μⁿ / (1 + μⁿ)`.
