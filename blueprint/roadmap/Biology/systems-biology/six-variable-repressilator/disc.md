# Discriminant of the eigenvalue curve

For `n ∈ ℕ` and real `β` and `μ`, `D(μ) = (1 − β)² + 4 a(μ) β c ∈ ℂ`, where `a` is the
[loop gain](../three-variable-repressilator/gain.md) `a(μ) = n μⁿ / (1 + μⁿ)` and
`c = 1/2 + i √3/2`: the discriminant of `(λ + 1)(λ + β) = a(μ) β c`. With the convention
`x / 0 = 0`, `a(μ) = 0` when `μⁿ = −1` (`n` odd and `μ = −1`); in the model `μ ≥ 0` is the
equilibrium level.
