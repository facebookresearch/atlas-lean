# At a Hopf point, Q − a β c factors with the root iω

For a real `a` and `β > 0` satisfying the [Hopf condition](is-hopf.md)
`3 a² β = (4 − 2 a) (1 + β)²`, the polynomial `Q − a β c`, with `Q = (X + 1)(X + β)` the
[quadratic](quad.md) and `c = 1/2 + i √3/2`, equals `(X − iω)(X − r₂)` with `r₂ = −(1 + β) − iω`,
where `ω` is the [Hopf frequency](hopf-freq.md) `ω = √3 a β / (2 (1 + β))`.
