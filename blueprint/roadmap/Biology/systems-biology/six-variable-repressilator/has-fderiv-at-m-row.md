# Derivative of an mRNA row at the symmetric state

For `n ∈ ℕ`, `p ≥ 0` and indices `i, j ∈ {0, …, 5}`, the function
`x ↦ p (1 + pⁿ) / (1 + x_jⁿ) − x_i` on `ℝ⁶` is differentiable at `(p, …, p)` with derivative
`v ↦ −a(p) v_j − v_i`, where `a` is the [loop gain](../three-variable-repressilator/gain.md)
`a(p) = n pⁿ / (1 + pⁿ)`.
