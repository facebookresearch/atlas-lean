# The eigenvalue curve consists of eigenvalues

For `n ∈ ℕ` and all real `β` and `μ`, `λ(μ)`, the value of the
[eigenvalue curve](hopf-eigenvalue.md), is a root of the characteristic polynomial, with
coefficients in `ℂ`, of the [Jacobian matrix](jacobian.md) `J(a(μ), β)`, where `a` is the
[loop gain](../three-variable-repressilator/gain.md) `a(μ) = n μⁿ / (1 + μⁿ)`.
