# Parameters and states with positive concentrations

The set of pairs `(μ, x) ∈ ℝ × ℝ⁶` with every `x_j > 0`; the parameter `μ` is arbitrary. It is open,
and on it the map `(μ, x) ↦ F(x)`, with `F` the [six-variable field](vector-field.md) with rate
`μ (1 + μⁿ)` and ratio `β`, is infinitely differentiable for every `n ∈ ℕ` and every real `β`.
