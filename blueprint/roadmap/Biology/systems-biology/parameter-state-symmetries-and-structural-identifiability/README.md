# Parameter-state symmetries and structural identifiability

Lie symmetries that move parameters and states together while leaving the observed outputs unchanged at every time point capture exactly the directions in which a mechanistic ODE model cannot be determined from data. Their universal invariants are the locally identifiable parameter combinations and the locally observable states.
