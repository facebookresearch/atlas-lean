# Random catalysis and RAF emergence

Probabilistic models of catalysis on Kauffman's polymer reaction system, asking when a reflexively autocatalytic, food-generated (RAF) set appears with high probability as the number of molecule types grows. Heterogeneous catalytic activity shifts the threshold from average catalysis rates to a weighted catalytic mass, and heavy-tailed activity lets a few catalysts suffice.
