# Two-species negative feedback control models

A minimal ODE template for physiological homeostasis: a controlled species $x$ activates a controller species $y$, which in turn inhibits $x$, each with linear clearance and constant production. Monotonicity of the activation and inhibition functions makes every equilibrium exponentially stable as soon as the activation does not depend on $y$, which covers models of gene-regulatory circuits, glucose–insulin regulation and the muscle stretch reflex.
