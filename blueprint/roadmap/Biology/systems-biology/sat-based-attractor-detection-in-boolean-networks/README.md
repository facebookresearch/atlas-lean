# SAT-based attractor detection in Boolean networks

Finding all attractors of a synchronous Boolean model of a gene regulatory network without enumerating its $2^n$ states. Unrolled transition relations are handed to a satisfiability solver, a path that revisits a state certifies an attractor, and decomposition of the wiring graph into strongly connected components lets attractors be assembled block by block from local attractors.
