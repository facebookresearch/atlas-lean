# The pseudo-Helmholtz function is continuous

For every $c^* \in \mathbb{R}^4$, the
[pseudo-Helmholtz function](../complex-balancing-and-the-deficiency-zero-theore/pseudo-helmholtz.md)
$G(x) = \sum_i x_i (\log x_i - \log c^*_i - 1)$ is continuous on all of $\mathbb{R}^4$, with the
conventions $\log 0 = 0$ and $\log x = \log|x|$ for $x < 0$: each $x_i \log x_i$ tends to $0$ as
$x_i \to 0$.
