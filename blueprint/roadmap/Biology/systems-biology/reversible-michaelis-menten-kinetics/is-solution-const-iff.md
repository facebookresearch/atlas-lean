# A constant curve is a solution exactly at a zero of the field

For all real rate constants and every $x = (x_s, x_c, x_e, x_p) \in \mathbb{R}^4$, the constant
functions $s \equiv x_s$, $c \equiv x_c$, $e \equiv x_e$ and $p \equiv x_p$ form a
[solution](is-solution.md) of the reversible Michaelis–Menten system if and only if $F(x) = 0$ for
the [reversible field](rev-field.md) $F$.
