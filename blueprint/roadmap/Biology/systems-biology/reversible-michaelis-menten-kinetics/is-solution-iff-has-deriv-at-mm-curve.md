# Reversible solutions as integral curves of the field from time zero

For all real rate constants, $(s, c, e, p)$ is a [solution](is-solution.md) of the reversible
Michaelis–Menten system if and only if the
[packed curve](../michaelis-menten-kinetics-and-the-quasi-steady-s/global-positive-trajectories-of-the-michaelis-me/mm-curve.md)
$x(t) = (s(t), c(t), e(t), p(t))$ has the derivative $x'(t) = F(x(t))$ at every $t \ge 0$, for the
[reversible field](rev-field.md) $F$.
