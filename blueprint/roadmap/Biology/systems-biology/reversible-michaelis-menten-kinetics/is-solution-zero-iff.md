# With k₋₂ = 0 the reversible system is the irreversible one

For all real $k_1, k_{-1}, k_2$, functions $(s, c, e, p)$ form a [solution](is-solution.md) of the
reversible Michaelis–Menten system with $k_{-2} = 0$ if and only if they form a
[solution of the irreversible mass-action system](../michaelis-menten-kinetics-and-the-quasi-steady-s/is-solution.md)
with $k_b = k_{-1}$.
