# Positive rates and totals give one nonnegative equilibrium per class

Let $k_1, k_{-1}, k_2, k_{-2} > 0$ and $E_T, S_T > 0$. Then exactly one state $x = (s, c, e, p)$
with nonnegative coordinates has $e + c = E_T$ and $s + c + p = S_T$ and is a zero of the
[reversible field](rev-field.md): the compatibility class $\{e + c = E_T,\ s + c + p = S_T\}$
contains exactly one nonnegative equilibrium. It is [positive](pos-of-equilibrium.md) and satisfies
$p/s = k_1 k_2/(k_{-1} k_{-2})$, the [Haldane equilibrium constant](haldane-div.md).
