# Biphasic dose response

A steady-state dose response is biphasic when the output first rises and then falls (or the reverse) as the input dose increases. For sign-definite input–output systems, biphasic and quasi-adaptive responses are ruled out by the sign pattern of the Jacobian alone, read off as feedback loops and feedforward paths in the interaction graph.
