# Sets of organizational reactions

Reaction-based counterpart of distributed organizations in chemical organization theory. A set of organizational reactions (SOR) is a set of reactions that can all run at positive rates while no species is consumed on balance, and that is closed under the reactions its own species switch on. SORs can be enumerated from the reaction network alone, without kinetic parameters, and they are exactly the candidates for the set of reactions that persist in a solution of any reaction-diffusion system built on the network.
