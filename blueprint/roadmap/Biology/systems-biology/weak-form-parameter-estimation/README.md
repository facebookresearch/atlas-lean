# Weak-form parameter estimation for ODE models

Estimating parameters of ODE models that are linear in their parameters by testing the equations against compactly supported test functions, which turns estimation into a linear regression without forward solves, and correcting the resulting errors-in-variables structure by iterative reweighting (WENDy).
