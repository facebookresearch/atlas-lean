# Stochastic within-host hepatitis B dynamics

Target-cell models of hepatitis B virus infection (uninfected hepatocytes, infected hepatocytes, free virions) perturbed by multiplicative Itô noise. Noise shifts the deterministic threshold: persistence is governed by a noise-corrected reproduction number, clearance by an optimized Lyapunov exponent, and under clearance the healthy hepatocyte pool settles to an inverse-gamma law.
