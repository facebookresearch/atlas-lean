# Control kernels of Boolean networks

A control kernel is a smallest set of nodes of a Boolean regulatory network whose permanent pinning to the values they take in a chosen attractor makes that attractor globally attracting, a model of steering cells to a chosen fate. Its size is bounded below by input nodes plus a minimal witness set separating the target attractor from the others, which explains why kernels in curated biological networks scale like the logarithm of the number of attractors.
