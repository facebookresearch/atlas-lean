# There are at most as many linkage classes as reactions

Let $N$ be a [chemical reaction network](../../../Dynamics/smooth-dynamics/reaction-network.md) with
species set $S$ and finite reaction set $\rho$. Its
[number of linkage classes](../../../Dynamics/smooth-dynamics/num-linkage-classes.md) $\ell$
satisfies $\ell \le |\rho|$: every linkage class contains the source complex of some reaction.
