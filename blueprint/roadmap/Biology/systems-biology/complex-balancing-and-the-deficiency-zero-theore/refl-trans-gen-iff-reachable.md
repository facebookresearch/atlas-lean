# In a weakly reversible network, linkage classes are strongly connected

Let $N$ be a [weakly reversible](../../../Dynamics/smooth-dynamics/is-weakly-reversible.md)
[chemical reaction network](../../../Dynamics/smooth-dynamics/reaction-network.md) with species set
$S$ and reaction set $\rho$. For [complexes](../../../Dynamics/smooth-dynamics/complexes.md) $c$ and
$c'$ of $N$, there is a directed path of reactions from $c$ to $c'$, possibly of length zero (see
the [reaction relation](../../../Dynamics/smooth-dynamics/reacts.md)), if and only if $c$ and $c'$
lie in the same linkage class, that is, are joined by a path in the
[linkage graph](../../../Dynamics/smooth-dynamics/linkage-graph.md). So every linkage class is
strongly connected by the reactions.
