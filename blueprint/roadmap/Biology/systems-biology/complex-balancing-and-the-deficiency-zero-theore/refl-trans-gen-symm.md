# In a weakly reversible network, directed reachability is symmetric

Let $N$ be a [weakly reversible](../../../Dynamics/smooth-dynamics/is-weakly-reversible.md)
[chemical reaction network](../../../Dynamics/smooth-dynamics/reaction-network.md) with species set
$S$ and reaction set $\rho$. For all $y, y' \in \mathbb{N}^S$, if there is a directed path of
reactions $y = y_0 \to y_1 \to \dots \to y_m = y'$ with $m \ge 0$ (see the
[reaction relation](../../../Dynamics/smooth-dynamics/reacts.md)), then there is also a directed
path of reactions from $y'$ to $y$.
