# A network with no reactions has deficiency zero

Let $N$ be a [chemical reaction network](../../../Dynamics/smooth-dynamics/reaction-network.md) with
species set $S$ and an empty set $\rho$ of reactions. Then $N$ has no
[complexes](../../../Dynamics/smooth-dynamics/complexes.md) and no linkage classes, and its
[stoichiometric subspace](../../../Dynamics/smooth-dynamics/stoichiometric-subspace.md) is $\{0\}$,
so its [deficiency](../../../Dynamics/smooth-dynamics/deficiency.md) is $\delta = 0 - 0 - 0 = 0$.
