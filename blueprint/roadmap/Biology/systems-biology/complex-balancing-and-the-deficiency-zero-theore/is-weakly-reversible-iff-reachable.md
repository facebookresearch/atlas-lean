# Weak reversibility is equivalent to strongly connected linkage classes

Let $N$ be a [chemical reaction network](../../../Dynamics/smooth-dynamics/reaction-network.md) with
species set $S$ and reaction set $\rho$. Then $N$ is
[weakly reversible](../../../Dynamics/smooth-dynamics/is-weakly-reversible.md) if and only if, for
all [complexes](../../../Dynamics/smooth-dynamics/complexes.md) $c$ and $c'$ of $N$ in the same
linkage class (joined by a path in the
[linkage graph](../../../Dynamics/smooth-dynamics/linkage-graph.md)), there is a directed path of
reactions from $c$ to $c'$, possibly of length zero (see the
[reaction relation](../../../Dynamics/smooth-dynamics/reacts.md)); that is, if and only if every
linkage class is strongly connected by the reactions.
