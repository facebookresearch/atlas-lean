# Pseudo-Helmholtz function

Let $S$ be a finite set and $c^* \in \mathbb{R}^S$ reference concentrations. The pseudo-Helmholtz
function relative to $c^*$ is

$$G(c) = \sum_{s \in S} c_s \left(\log c_s - \log c^*_s - 1\right) \qquad (c \in \mathbb{R}^S)$$

(Horn and Jackson 1972), with the conventions $\log 0 = 0$ and $\log x = \log|x|$ for $x < 0$; it is meaningful for positive $c$ and $c^*$.
