# Rate ratio at a given steady-state modified fraction

For real $K_1$, $K_2$ and $W$, the rate ratio is

$$\rho(W) = \frac{W (1 - W + K_1)}{(1 - W)(W + K_2)},$$

with quotients by $0$ read as $0$ (for instance at $W = 1$). For $0 < W < 1$ and $K_1, K_2 > 0$ it is the value of
$V_1/V_2$ for which the mole fraction $W$ of modified protein is at steady state (Goldbeter–Koshland
1981, Eq. 8).
