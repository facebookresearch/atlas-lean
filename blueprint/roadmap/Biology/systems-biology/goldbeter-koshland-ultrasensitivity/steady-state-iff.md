# Steady state of the modification cycle

Let $V_1 \in \mathbb{R}$, $V_2 > 0$, $K_1 > 0$, $K_2 > 0$ and $0 < W < 1$. Modification and
demodification balance,

$$\frac{V_1 (1 - W)}{K_1 + 1 - W} = \frac{V_2 W}{K_2 + W},$$

if and only if $V_1/V_2 = \rho(W)$, where $\rho$ is the [rate ratio](rate-ratio.md)
(Goldbeter–Koshland 1981, Eq. 8).
