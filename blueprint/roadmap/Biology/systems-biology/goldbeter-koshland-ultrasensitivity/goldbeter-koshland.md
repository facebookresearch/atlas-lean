# Goldbeter–Koshland function

For real $v$, $K_1$ and $K_2$, the Goldbeter–Koshland function is

$$G(v, K_1, K_2) = \frac{2 v K_2}{\sqrt{(v - 1 - K_1 - K_2 v)^2 + 4 (v - 1) v K_2} - (v - 1 - K_1 - K_2 v)},$$

with quotients by $0$ read as $0$ and the square root of a negative number read as $0$. For $v, K_1, K_2 > 0$ it is
the steady-state mole fraction of modified protein when $V_1/V_2 = v$ (Goldbeter–Koshland 1981, Eq. 7,
rationalized so that it also covers $v = 1$, Eq. 9).
