# The Goldbeter–Koshland function is a steady state

For $v > 0$, $K_1 > 0$ and $K_2 > 0$, the [rate ratio](rate-ratio.md) $\rho(W) = W(1 - W + K_1)/((1 - W)(W + K_2))$ at $W = G(v, K_1, K_2)$, the value of the
[Goldbeter–Koshland function](goldbeter-koshland.md), equals $v$ (Goldbeter–Koshland 1981, Eq. 7).
