# Response coefficient of a covalent modification cycle

For real $K_1$ and $K_2$, the response coefficient is $R_v = \rho(0.9)/\rho(0.1)$, the ratio of the
values of the [rate ratio](rate-ratio.md) $V_1/V_2$ giving 90% and 10% modified protein at steady
state (Goldbeter–Koshland 1981), with quotients by $0$ read as $0$.
