# Autophosphorylation dynamics of Lck

Lck is a Src-family kinase of T cells that phosphorylates itself. Models with autophosphorylation show bistability already for a single phosphorylation site, and a model of wild-type Lck with an activating and an inhibitory site has a Bogdanov–Takens bifurcation and hence oscillations.
