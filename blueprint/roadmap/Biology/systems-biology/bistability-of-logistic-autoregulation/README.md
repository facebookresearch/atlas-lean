# Bistability of logistic autoregulation

Continuous gene-network models translate Boolean rules into ODEs through a sigmoidal kernel. With a logistic kernel the positive-autoregulation motif has an exact saddle-node characterization of its bistable range, which widens without bound as the kernel steepens, recovering the Boolean switch.
