# Time-delay Boolean networks

Boolean gene network models in which a Boolean function of a target's regulators may be only *necessary* for the target to switch on (a prerequisite whose effect can be delayed), rather than fully determining the next state. The topics covered are the prerequisite and similarity relations, inference from noisy binarized expression by an EM-estimated misclassification score, and the number of random input/output samples that is sufficient, and the number that is necessary, for exact identification.
