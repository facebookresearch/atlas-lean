# Change points in switching gene regulatory networks

A time-varying gene regulatory network can be modelled as a linear-in-parameters system that switches among a finite set of static sub-networks. Running a recursive (Kalman) estimator under the static hypothesis, the normalized innovations are white Gaussian exactly when no switch has occurred, which turns change-point detection into a chi-square test.
