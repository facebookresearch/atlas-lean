# Minimum dominating sets of multilayer networks

In dominating-set controllability, a network is controlled from driver nodes that dominate every node. For several network layers on overlapping node sets (for example metabolic networks of different species), a single driver set must dominate every layer; its minimum size lies between the largest single-layer minimum and their sum, and finding it is NP-hard even for very simple layers.
