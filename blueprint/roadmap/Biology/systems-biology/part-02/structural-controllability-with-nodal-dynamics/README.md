# Structural controllability with nodal dynamics

Structural (generic) controllability of a linear network $\dot{\mathbf x} = \hat A \mathbf x + B\mathbf u$ in which every node carries its own intrinsic dynamics, such as a finite time constant from degradation, mortality or membrane leak. Once nodal dynamics are generic, a single time-varying input suffices, whatever the degree distribution, and it only has to reach a minimal set of nodes from which the whole network is downstream.
