# Upstream regulator inference on causal graphs

Given a network of signed and unsigned causal edges and a list of up- and down-regulated transcripts, each candidate upstream regulator defines a contingency table of predicted versus observed directions with fixed margins. Scores such as the enrichment, correctness (ternary) and quaternary scores are tested against the generalized hypergeometric null of random tables with those margins.
