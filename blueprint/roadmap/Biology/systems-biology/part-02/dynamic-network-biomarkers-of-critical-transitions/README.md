# Dynamic network biomarkers of critical transitions

Disease progression is modeled as a noisy dynamical system on a molecular network driven slowly toward a bifurcation. Near the tipping point one eigenvalue of the linearization approaches the unit circle, and a group of molecules (the dominant group, or dynamic network biomarker) shows growing fluctuations and growing mutual correlation before the system tips into the disease state. These articles state the dominant-eigenvalue signature and an entropy-rate indicator built on local network state transitions.
