# Compressive-sensing reconstruction of gene regulatory networks

Writing the time derivatives of gene or protein concentrations as a sparse linear combination of candidate nonlinear basis functions (linear decay, Hill-type activation and inhibition terms) turns network inference from time series into a sparse linear inverse problem. Compressive-sensing theory then states when the sparse influence map is exactly recoverable, and the coherence of the sensing matrix built from the data serves as a performance index and a guide for experiment design.
