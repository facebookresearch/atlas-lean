# Effective networks from steady-state perturbations

Constant perturbations of a gene regulatory system near a stable steady state shift the steady state by an amount governed by the linearized system matrix. When only some species (for example mRNAs) are measured, the identifiable object is a Schur complement of the full Jacobian, whose nonzero pattern is an effective network of paths through unobserved species.
