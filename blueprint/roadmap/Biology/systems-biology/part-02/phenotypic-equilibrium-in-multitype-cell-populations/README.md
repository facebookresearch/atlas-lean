# Phenotypic equilibrium in multitype cell populations

Cell populations that switch among phenotypes (for example stem-like, basal and luminal cancer cells) often return to a fixed phenotypic composition. Modelling cells as a multitype Markov branching process, the expected populations obey a linear ODE whose Perron eigenvector is the equilibrium composition; the frequently used Markov-chain model for the proportions is valid exactly when all phenotypes have the same net growth rate, and the stochastic proportions themselves converge almost surely to the Perron eigenvector on non-extinction.
