# Information capacity of cell signaling

A signaling pathway can be viewed as a noisy channel from a discrete set of stimulus levels to a high-dimensional, continuous single-cell response. Its channel capacity, the maximal mutual information over input distributions, bounds how many stimulus levels a cell can reliably distinguish. For continuous multivariate responses the capacity can be computed by a Blahut–Arimoto alternating maximization in which the posterior over inputs is approximated by a classifier fitted to single-cell data.
