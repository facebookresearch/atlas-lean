# Intein-based integral feedback control

Split inteins splice two protein fragments carrying complementary N- and C-terminal intein halves, so splicing reactions conserve a net "intein charge". Controllers whose species carry such halves implement integral feedback: the charge-weighted sum of controller concentrations integrates the error between a setpoint and the regulated output, giving robust perfect adaptation.
