# Buffering structures of reaction networks

Structural sensitivity analysis asks which steady-state concentrations respond to perturbing a reaction rate, using only the network structure. Buffering structures are subnetworks that confine the effect of perturbations inside them. Writing the augmented Jacobian as a layered mixed matrix (a symbolic part from reaction derivatives and a numeric part from conservation laws) lets Murota's combinatorial canonical form determine both the buffering structures and the full influence pattern.
