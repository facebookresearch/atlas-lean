# Light-cone exclusion model of replication origins

Replication origins on eukaryotic chromosomes show fewer very short and fewer very long spacings than uncorrelated random points. A minimal space-time model places potential initiation events as a planar Poisson process and lets forks move at unit speed, so an event fires only if no earlier event's fork has reached it; the firing origins then show linear repulsion at short range and a Gaussian tail at long range, and coincide with the bottom layer of the flat polynuclear growth model.
