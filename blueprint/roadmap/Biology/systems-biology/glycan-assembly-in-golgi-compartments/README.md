# Glycan assembly in Golgi compartments

Glycans are built one monomer at a time by promiscuous glycosyltransferase enzymes as cargo passes through a series of Golgi compartments. Modelling each compartment as a continuous-time Markov assembly line separates three sources of output heterogeneity (truncated, runaway and divergent reactions), ties them to combinatorial features of the enzyme set, and characterizes exactly which oligomers can be synthesized without byproducts in $N$ compartments.
