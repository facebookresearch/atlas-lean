# Piecewise-affine gene network models

Piecewise-affine differential equation (PADE) models, introduced by Glass and Kauffman, describe gene regulation by step-function switches at concentration thresholds. Their qualitative dynamics reduce to a finite state transition graph on a rectangular partition of state space that depends only on the ordering of threshold and focal parameters, which makes parameter search amenable to symbolic model checking.
