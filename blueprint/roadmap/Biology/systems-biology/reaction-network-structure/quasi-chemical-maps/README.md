# Quasi-chemical maps

Mass-action reaction networks produce polynomial ODEs with a sign restriction: a species can only be consumed by monomials that contain it. The quasi-chemical map translates any polynomial dynamical system far into the positive orthant and adds a small multiplicative correction so that the result is chemical, while preserving the qualitative dynamics of every structurally stable system. Consequences include reaction networks with arbitrarily many limit cycles, chaotic attractors and homoclinic bifurcations, and a bound sandwiching the chemical Hilbert number.
