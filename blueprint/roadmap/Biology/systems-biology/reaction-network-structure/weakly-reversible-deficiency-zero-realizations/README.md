# Weakly reversible deficiency-zero realizations

Different reaction networks can generate the same mass-action ODEs. If some realization is weakly reversible with deficiency zero ($\mathrm{WR}_0$), the deficiency-zero theorem applies to the dynamics. For networks that admit such a realization for every choice of rate constants, the realizing $\mathrm{WR}_0$ network is unique and computable.
