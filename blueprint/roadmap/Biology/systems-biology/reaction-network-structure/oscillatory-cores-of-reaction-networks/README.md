# Oscillatory cores of reaction networks

Under parameter-rich kinetics, the Jacobian of a reaction network factors into stoichiometry times freely tunable reactivities. A square stoichiometric submatrix (a Child-Selection matrix) whose inertia can be changed by positive diagonal rescaling forces a purely imaginary eigenvalue crossing and, through global Hopf bifurcation, periodic orbits. Minimal such submatrices are oscillatory cores: any network containing one can oscillate.
