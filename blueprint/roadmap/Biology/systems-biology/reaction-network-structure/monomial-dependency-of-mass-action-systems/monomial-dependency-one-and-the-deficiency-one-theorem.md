# Monomial dependency one and the deficiency one theorem

**Setting.** A *parametrized system of generalized polynomial equations* is $A\,(c\circ x^B)=0$ for positive unknowns $x\in\mathbb R^n_{>0}$, a coefficient matrix $A\in\mathbb R^{n'\times m}$, a real exponent matrix $B=(b^1,\dots,b^m)\in\mathbb R^{n\times m}$, positive parameters $c\in\mathbb R^m_{>0}$, $x^B=(x^{b^1},\dots,x^{b^m})$ and $\circ$ the componentwise product. Suppose $\ker A=\ker A_1\times\cdots\times\ker A_\ell$ splits the monomials into $\ell$ *classes* of sizes $m_j$. The *coefficient polytope* is $P=(\ker A\cap\mathbb R^m_{>0})\cap(\Delta^{m_1-1}\times\cdots\times\Delta^{m_\ell-1})=P_1\times\cdots\times P_\ell$. The *monomial difference subspace* $L\subseteq\mathbb R^n$ is spanned by the differences of exponent vectors within each class, and the **monomial dependency** is $d=m-\ell-\dim L$, the number of independent affine relations among exponents within classes. For a mass-action reaction network, writing the equilibrium equations in this form makes $d$ a generalization of Feinberg's deficiency $\delta$ that depends on the actual monomials rather than only on the complexes and linkage classes.

**Theorems 3 and 4 (one class, $d=1$, $\dim P=1$).** Suppose $\ker A\cap\mathbb R^m_{>0}\ne\emptyset$. Lump and order the components of the (one-dimensional) dependency vector spanning $\ker M$ along the segment $P$, obtaining $\bar b\in\mathbb R^\omega$. Then the reduced solution set $Y_c$ is nonempty for every $c$ if and only if $\bar b_1\bar b_\omega<0$; and it has exactly one point for every $c$ if moreover the partial sums $\sum_{i'\le i}\bar b_{i'}$ are all $\ge0$ (or all $\le0$) for $i=1,\dots,\omega-1$. The system is then *essentially univariate*: its positive solutions are parametrized by one scalar.

**Corollary 12 (mass-action systems with $d_j\le1$).** Let a mass-action system decompose into $\ell$ independent subnetworks, with the equilibrium equations having a positive kernel vector, and suppose that for each subnetwork $j$: $d_j\le1$, its kinetic, stoichiometric and monomial difference subspaces coincide ($K_j=S_j=L_j$), and if $d_j=1$ its lumped dependency vector $\bar b^j$ satisfies the sign and partial-sum conditions above. Then there is a unique positive equilibrium in every stoichiometric compatibility class.

**Theorem 15 (extended deficiency one theorem).** Let a mass-action system have $\ell$ independent subnetworks, each with deficiency $\delta_j\le1$ and exactly one absorbing strong component ($t_j=1$). If a positive equilibrium exists, then every stoichiometric compatibility class contains exactly one positive equilibrium. If the network is weakly reversible, a positive equilibrium exists for all rate constants.

## Expansion

By a previous structural theorem, the positive solution set factors as a reduced set $Y_c\subseteq P$ cut out by binomial conditions $y^z=c^z$ for $z$ in a dependency basis, times a coset of the toric group $e^{L^\perp}$. When $d=1$ and $P$ is a segment there is a single equation $y^{\bar b}=c^{\bar b}$ on a one-parameter family, and the sign pattern of $\bar b$ decides whether its left side is monotone along the segment, which gives existence and uniqueness. Birch's theorem, $|(x_0+S)\cap(x^*\circ e^{S^\perp})|=1$, then places exactly one equilibrium in each compatibility class when $L=S$. Feinberg's deficiency one theorem is recovered by checking that $\delta_j\le1$ with $t_j=1$ forces these conditions; the proof uses a sign-pattern ("second salt") theorem for the network.
