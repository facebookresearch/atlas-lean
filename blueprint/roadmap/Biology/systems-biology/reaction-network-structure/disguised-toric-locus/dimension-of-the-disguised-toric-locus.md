# Dimension of the disguised toric locus

**Setting.** An E-graph $G = (V, E)$ is a reaction network whose vertices $V \subset \mathbb R^n$ are complexes and whose edges $y \to y'$ are reactions; with rate vector $k \in \mathbb R^E$ it generates the mass-action system $\dot x = \sum_{y \to y' \in E} k_{y \to y'}\, x^{y} (y' - y)$. $\mathcal S_G$ is the stoichiometric subspace. $(G, k)$ is *disguised toric* if the same vector field is generated by a complex-balanced mass-action system on some E-graph $G'$; it suffices to take $G'$ a weakly reversible subgraph of the complete graph $G_c$ on the sources of $G$ (written $G' \sqsubseteq G_c$). The *disguised toric locus* $\mathcal K_{\mathrm{disg}}(G)$ is the set of $k \in \mathbb R^E_{>0}$ for which $(G,k)$ is disguised toric; the *$\mathbb R$-disguised toric locus* $\mathcal K_{\mathbb R\text{-disg}}(G)$ allows arbitrary real $k$. Define the linear spaces

$$\mathcal D(G) = \Bigl\{\lambda \in \mathbb R^E : \sum_{y_0 \to y \in E} \lambda_{y_0 \to y}(y - y_0) = 0 \ \forall y_0 \in V\Bigr\}, \qquad \mathcal J_0(G) = \Bigl\{J \in \mathcal D(G) : \sum_{y \to y_0} J_{y \to y_0} = \sum_{y_0 \to y'} J_{y_0 \to y'} \ \forall y_0\Bigr\},$$

and let $\mathcal J(G', G)$ be the set of complex-balanced flux vectors $J'$ on $G'$ whose net reaction vector at every vertex can be matched by some real flux on $G$.

**Theorem.**

$$\dim \mathcal K_{\mathbb R\text{-disg}}(G) = \max_{G' \sqsubseteq G_c} \Bigl\{ \dim \mathcal J(G', G) + \dim \mathcal S_{G'} + \dim \mathcal J_0(G') - \dim \mathcal D(G) \Bigr\},$$

and if $\mathcal K_{\mathrm{disg}}(G) \ne \emptyset$,

$$\dim \mathcal K_{\mathrm{disg}}(G) = \max_{G' \sqsubseteq G_c,\ \mathcal K_{\mathrm{disg}}(G, G') \ne \emptyset} \Bigl\{ \dim \mathcal J(G', G) + \dim \mathcal S_{G'} + \dim \mathcal J_0(G') - \dim \mathcal D(G) \Bigr\}.$$

## Expansion

For a fixed weakly reversible $G'$, a disguised toric rate vector is parametrised by a complex-balanced flux on $G'$ realizable on $G$, a positive steady state $x$ (modulo the stoichiometric directions, contributing $\dim \mathcal S_{G'}$), and the freedom $\mathcal J_0(G')$ to change the realization without changing the vector field; rate vectors on $G$ generating the same field differ by $\mathcal D(G)$, which is subtracted. The paper builds an explicit map $\hat\Psi$ from (flux, steady state, parameters) to (rate constants, parameters) and proves it is a homeomorphism, so the parameter count is the topological dimension. The locus is a finite union over $G' \sqsubseteq G_c$, hence its dimension is the maximum. Applications include Thomas-type and circadian clock networks.
