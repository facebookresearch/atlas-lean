# Synchronous attractor control of Boolean networks

A control of a Boolean network fixes selected genes ON or OFF (mutations, drugs) so that every attractor of the controlled synchronous dynamics satisfies a desired phenotype. Enumerating all minimal controls is a bilevel integer program; it decomposes into a master problem over controls and subproblems that search for a forbidden attractor, each forbidden attractor or trap space yielding a combinatorial cut.
