# Robust Lyapunov functions of biochemical networks

Kinetics-independent stability certificates for biochemical reaction networks: Lyapunov functions, piecewise linear in the reaction rates, that are non-increasing for every monotone choice of rate functions. The sum-of-currents function $\|\dot x\|_1$ certifies linear networks and survives a list of graph modifications (catalysts, dimers, intermediates, reversals).
