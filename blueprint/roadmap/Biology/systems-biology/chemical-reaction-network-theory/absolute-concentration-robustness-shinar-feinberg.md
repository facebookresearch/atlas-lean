# Absolute concentration robustness (Shinar–Feinberg)

Consider a mass-action reaction system whose network has deficiency one and which admits a positive steady state for the given rate constants. Two complexes "differ only in species $S$" if their difference is a nonzero multiple of the single species $S$, and a complex is non-terminal if it lies outside the terminal strong linkage classes. Shinar and Feinberg (2010) prove: if the network has two non-terminal complexes that differ only in species $S$, then the system has absolute concentration robustness in $S$: the concentration of $S$ takes the same value at every positive steady state, whatever the total amounts.
