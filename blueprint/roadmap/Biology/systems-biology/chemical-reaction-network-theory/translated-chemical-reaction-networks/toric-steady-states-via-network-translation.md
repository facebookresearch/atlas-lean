# Toric steady states via network translation

**Setting.** A chemical reaction network $\mathcal N = (\mathcal S, \mathcal C, \mathcal R)$ on $m$ species with mass-action kinetics has dynamics $\dot{\mathbf x} = \sum_{y_i \to y_j} k_{ij}\,\mathbf x^{y_i}(y_j - y_i)$ and stoichiometric subspace $S = \operatorname{span}\{y_j - y_i\}$. A *translation* $\tilde{\mathcal N}$ of $\mathcal N$ is obtained by adding to the source and product complexes of each reaction a common vector (possibly different for different reactions), so reaction vectors are unchanged, while each translated source complex is assigned as its *kinetic complex* the source complex of one original reaction mapped to it. The translation is *proper* when translated reactions with the same translated source come from reactions with the same original source; then the kinetic complexes are unambiguous and, transferring the rate constants, the translated generalized mass-action system has the same dynamics as $\mathcal N$. It is *strong* when $\tilde{\mathcal N}$ is weakly reversible. An improper strong translation is *weakly resolvable* if the span of the differences between the original source complexes of improper reactions and their assigned kinetic complexes lies in the kinetic-order subspace $\tilde S$, and *strongly resolvable* if, moreover, the resulting kinetic adjustment factors (ratios of tree constants of the translated reaction graph) do not depend on the rate constants of the improper reactions; strong resolvability is what allows the improper translation to be given a generalized mass-action system with the same dynamics. Write $\tilde\delta$ for the deficiency of the translated graph and $\tilde\delta_K$ for its kinetic deficiency. A *toric steady state* is a positive steady state set described by binomials.

**Theorem.** Let $\tilde{\mathcal N}$ be a translation of $\mathcal N$ that is strong and proper, or strongly resolvably improper, with $\tilde\delta = \tilde\delta_K = 0$. Then:

1. $\mathcal N$ has toric steady states for every choice of rate constants $k > 0$;
2. the toric steady state ideal is generated by the binomials $\tilde K_{h(i)}\,\mathbf x^{y_j} - \tilde K_{h(j)}\,\mathbf x^{y_i}$ for reactant complexes $i, j$ whose translates lie in the same linkage class, where $\tilde K$ are the tree constants of the translated reaction graph;
3. the toric steady states are exactly the complex balanced steady states of the translated (generalized mass-action) system, and form $E = \{\mathbf x > 0 : \ln\mathbf x - \ln\mathbf x^* \in \tilde S^\perp\}$, where $\tilde S$ is spanned by differences of kinetic complexes within linkage classes of $\tilde{\mathcal N}$;
4. if the sign patterns satisfy $\sigma(S) = \sigma(\tilde S)$ and $(+,\dots,+) \in \sigma(S^\perp)$, each stoichiometric compatibility class contains exactly one toric steady state; if $\sigma(S) \cap \sigma(\tilde S^\perp) \ne \{0\}$, some rate constants give more than one.

## Expansion

Translation leaves the vector field unchanged but can turn a network that is not weakly reversible into one that is, with deficiency zero. The deficiency zero theorem for generalized mass-action systems (Müller–Regensburger) then supplies complex balanced steady states of the translated system for all rate constants, and the matrix-tree theorem gives them as binomial relations in the tree constants. Since the dynamics coincide, these are steady states of the original network. Uniqueness and multistationarity within compatibility classes reduce to sign-vector conditions comparing the original and kinetic stoichiometric subspaces, as in generalized mass-action theory. Examples include enzymatic mechanisms such as the EnvZ–OmpR and futile-cycle networks.
