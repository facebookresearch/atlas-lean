# Markov chain cell-fate mapping

Single-cell snapshots can be turned into a Markov chain on cells whose transitions follow RNA velocity along a nearest-neighbour graph. Coarse-graining that chain onto a few metastable macrostates identifies initial and terminal states, and absorption probabilities into terminal states give each cell's fate probabilities.
