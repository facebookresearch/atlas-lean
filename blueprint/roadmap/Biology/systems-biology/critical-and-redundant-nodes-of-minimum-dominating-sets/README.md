# Critical and redundant nodes of minimum dominating sets

In minimum-dominating-set (MDS) control of an undirected interaction network, a minimum dominating set of driver nodes is generally not unique. Nodes split into critical ones (in every MDS), redundant ones (in no MDS) and intermittent ones (in some but not all). Simple local degree rules settle many nodes without integer programming, which makes exact classification feasible on proteome-scale protein interaction networks.
