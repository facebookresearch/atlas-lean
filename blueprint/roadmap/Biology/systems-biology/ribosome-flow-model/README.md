# Ribosome flow model

The ribosome flow model (RFM) is the mean-field approximation of the totally asymmetric simple exclusion process (TASEP) for translation: ODEs for the occupancy of consecutive sites along an mRNA, with initiation, elongation and exit rates. It is a cooperative (monotone) tridiagonal system with a unique globally attracting steady state, and with periodic rates it entrains to the forcing period.
