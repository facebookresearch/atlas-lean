# Structured cell-cycle models

Proliferating cell populations described by their position in the cell cycle. A transport PDE with a doubling boundary condition at mitosis (Rubinow's model) produces exponential growth modulated by persistent oscillations with the cycle period, whereas a linear compartment ODE converges to fixed phase proportions; matching cycle-averaged quantities links the two.
