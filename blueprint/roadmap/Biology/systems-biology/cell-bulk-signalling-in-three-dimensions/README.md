# Cell-bulk signalling in three dimensions

Small, dynamically active cells in $\mathbb{R}^3$ that secrete and sense a diffusing, decaying signal. In the small-cell limit the bulk diffusion field reduces to memory kernels in an integro-differential system, and cell-cell coupling is weak, of the order of the cell radius.
