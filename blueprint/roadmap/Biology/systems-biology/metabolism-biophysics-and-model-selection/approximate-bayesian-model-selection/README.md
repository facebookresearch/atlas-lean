# Approximate Bayesian model selection

Stochastic and deterministic models in systems and population biology often have intractable likelihoods but are easy to simulate. Approximate Bayesian computation replaces likelihood evaluation by accepting simulations close to the data; run on the joint space of model indicators and parameters with sequential Monte Carlo, it yields approximate posterior model probabilities and Bayes factors for competing, possibly non-nested, models.
