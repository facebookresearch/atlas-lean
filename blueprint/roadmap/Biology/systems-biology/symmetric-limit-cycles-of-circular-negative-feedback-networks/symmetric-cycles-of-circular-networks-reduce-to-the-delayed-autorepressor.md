# Symmetric cycles of circular networks reduce to the delayed autorepressor

**Model (Eq. 12).** A circular network of $n$ identical genes, each repressing the next after a delay $\tau$, with indices modulo $n$ ($x_0\equiv x_n$):

$$\frac{dx_i}{dt}=\frac{\alpha}{1+x_{i-1}(t-\tau)^h}-x_i(t),\qquad i=1,\dots,n.$$

A $T$-periodic solution is *symmetric* if the cyclic relabeling $x_1\to x_2\to\dots\to x_n\to x_1$ maps it to a time shift of itself: $x_{i-1}(t)=x_i(t-pT/n)$ for all $i$ and some integer $0\le p<n$.

**Lemma 2 (reduction).** $(x_1,\dots,x_n)$ is a symmetric $T$-periodic solution with shift index $p$ if and only if each $x_i$ is a $T$-periodic solution of the single delayed autorepressor

$$\frac{dx}{dt}=\frac{\alpha}{1+x(t-\bar\tau)^h}-x(t),\qquad \bar\tau=\tau+\frac{p}{n}T,$$

and conversely every $T$-periodic solution $x$ of this equation yields the symmetric cycle $x_i(t)=x(t+ipT/n)$. All symmetric cycles of the network are therefore constructed from periodic solutions of one scalar delay equation with a phase-adjusted delay.

**Proposition 2 (irreducibility).** A symmetric cycle with shift index $p$ is irreducible, i.e. not obtained by repeating a symmetric cycle of a smaller circular network, if and only if $\gcd(p,n)=1$. If $\gcd(p,n)=m>1$ with $n=ms$, $p=mq$, the cycle is generated by a symmetric cycle of the $s$-gene network with shift index $q$ repeated $m$ times around the ring. Hence every symmetric cycle is irreducible or generated by an irreducible one (Corollary 1).

## Expansion

If $x$ is $T$-periodic and solves the scalar equation with delay $\bar\tau$, set $x_i(t)=x(t+ipT/n)$. Then $\dot x_i(t)=\alpha/(1+x(t+ipT/n-\tau-pT/n)^h)-x_i(t)=\alpha/(1+x_{i-1}(t-\tau)^h)-x_i(t)$, and $x_0(t)=x(t)=x(t+pT)=x_n(t)$ closes the ring; reading the computation backwards gives the converse. For Proposition 2, take $T$ to be the minimal period; then $x_{i+j}=x_i$ exactly when $n\mid jp$, so the coordinates repeat with index period $s=n/\gcd(p,n)$. When $\gcd(p,n)=m>1$, $(x_1,\dots,x_s)$ with $x_i(t)=x(t+iqT/s)$ is a symmetric cycle of the $s$-gene ring, and the $n$-gene cycle is $m$ copies of it. Numerically, a symmetric cycle is stable only when $n=2m+1$ is odd and consecutive genes are shifted by $mT/n$.
