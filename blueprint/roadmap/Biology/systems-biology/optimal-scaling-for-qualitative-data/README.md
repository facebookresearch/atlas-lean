# Optimal scaling for qualitative data

Many biological measurements are only qualitative or ordinal (categories such as low, medium, high, or rankings). Mechanistic models can be fitted to such data by optimal scaling: for each parameter value, surrogate quantitative data are chosen to agree as well as possible with the simulation while respecting the observed category order, and the model parameters are then fitted to the surrogate data. The inner surrogate-data problem is convex and reduces to a box-constrained problem in half as many variables.
