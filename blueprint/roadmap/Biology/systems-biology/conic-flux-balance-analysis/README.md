# Conic flux balance analysis

Flux balance analysis extended with metabolite concentrations: Michaelis–Menten upper bounds on fluxes are concave in the substrate concentration and are exactly second-order cone representable, so steady-state flux and concentration predictions, their sensitivities, and minimal cut sets involving metabolites become convex conic (or mixed-integer conic) programs.
