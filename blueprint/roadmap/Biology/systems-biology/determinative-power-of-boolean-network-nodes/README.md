# Determinative power of Boolean network nodes

Measures of how strongly a node of a Boolean network controls the others: influences and average sensitivities, expressed through composition operators on the space of Boolean functions, and the determinative power, a sum of mutual informations whose conditional entropies admit closed forms and two-sided polynomial bounds. Ranking nodes by these quantities reduces a network to its most informative components.
