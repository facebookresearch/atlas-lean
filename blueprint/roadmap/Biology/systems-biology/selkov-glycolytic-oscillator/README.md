# Selkov glycolytic oscillator

Two-variable models of the phosphofructokinase step of glycolysis derived by Selkov from a five-species mass-action network: the basic Selkov system with mass-action kinetics and its Michaelis–Menten parent. The main questions are when the unique positive steady state loses stability, what happens to the resulting limit cycle, and whether solutions can escape to infinity.
