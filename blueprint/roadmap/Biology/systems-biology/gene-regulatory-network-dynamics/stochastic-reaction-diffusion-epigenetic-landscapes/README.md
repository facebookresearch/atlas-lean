# Stochastic reaction–diffusion epigenetic landscapes

Cell differentiation modelled as noisy gradient dynamics on a Waddington-type epigenetic landscape, with spatial coupling along a tissue. Small-noise limits select cell types according to basin curvature, and large deviations give the rates of switching between cell types.
