# Asynchronous Boolean network dynamics

Logical models describe a regulatory network by Boolean variables and update rules. Under asynchronous updating only one variable changes per step, so a state can have several successors and all orders of events are explored; stable states coincide with those of the synchronous dynamics, and phenotype probabilities can be defined by a random walk on the asynchronous transition graph. Variables with simple regulatory roles can be eliminated by substituting their rules into their targets, preserving stable states.
