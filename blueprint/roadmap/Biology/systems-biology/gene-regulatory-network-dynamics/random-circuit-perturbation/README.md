# Random circuit perturbation

Random circuit perturbation (RACIPE) studies a gene regulatory circuit through its topology alone. It builds an ensemble of shifted-Hill rate-equation models with randomly sampled kinetic parameters, then reads off the robust behaviours (stable states, multistability) shared across the ensemble. The shifted Hill form bounds every gene's production rate, which confines all trajectories to an explicit box.
