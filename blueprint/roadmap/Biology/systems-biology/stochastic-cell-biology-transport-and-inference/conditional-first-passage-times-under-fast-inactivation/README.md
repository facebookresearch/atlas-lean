# Conditional first passage times under fast inactivation

A mortal searcher (a signaling molecule, a sperm cell, a transcription factor) must find a target before an independent inactivation time. Conditioned on success, its first passage time under fast inactivation is governed only by the short-time behavior of the unconditioned first passage time, which for diffusion is set by a geodesic distance.
