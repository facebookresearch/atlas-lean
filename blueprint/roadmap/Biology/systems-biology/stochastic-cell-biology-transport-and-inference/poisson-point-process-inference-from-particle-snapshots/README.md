# Poisson point process inference from particle snapshots

Fixed-cell imaging (for example single-molecule RNA fluorescence) records the positions of many particles at one instant but no trajectories. When particles are born, diffuse and degrade independently, a snapshot is a Poisson spatial point process whose intensity solves an elliptic boundary value problem, which yields an exact likelihood for the demographic rates.
