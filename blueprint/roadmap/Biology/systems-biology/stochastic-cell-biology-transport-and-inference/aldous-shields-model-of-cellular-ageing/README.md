# Aldous–Shields model of cellular ageing

A growing random binary tree in which an external vertex at depth $i$ splits at rate $c^{-i}$: deeper (older) cells divide more slowly. The depth profile of external vertices has explicit $q$-series moments, and truncating the tree at a maximal depth (replicative senescence, the Hayflick limit) gives an explicit limiting fraction of proliferating cells.
