# ON-step delay of the feed-forward loop

For real $\alpha_y$, $\beta_y$ and $K_{yz}$, the ON-step delay is

$$T_{\mathrm{on}} = \frac{1}{\alpha_y} \log \frac{1}{1 - K_{yz}/Y_{\mathrm{st}}}, \qquad Y_{\mathrm{st}} = \frac{\beta_y}{\alpha_y},$$

with quotients by $0$ read as $0$ and with the conventions $\log 0 = 0$ and $\log x = \log|x|$ for $x < 0$. For $0 < K_{yz} < Y_{\mathrm{st}}$ it is the
time at which the [intermediate factor](y-on.md) crosses the activation threshold $K_{yz}$ of the
target.
