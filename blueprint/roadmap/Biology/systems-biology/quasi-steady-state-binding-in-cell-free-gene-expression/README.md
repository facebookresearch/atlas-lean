# Quasi-steady-state binding in cell-free gene expression

Mechanistic models of transcription and translation in cell-free extracts treat polymerase, sigma-factor, promoter and ribosome binding as fast reversible equilibria. A single equilibrium with conserved totals has an explicit quadratic solution; competition for shared resources couples the equilibria and creates loading effects.
