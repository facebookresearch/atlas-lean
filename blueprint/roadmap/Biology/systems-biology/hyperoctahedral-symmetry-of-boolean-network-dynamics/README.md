# Hyperoctahedral symmetry of Boolean network dynamics

The state-space dynamics of synchronous Boolean networks is symmetric under node-flips and node-label permutations, which generate the hyperoctahedral group of the state cube. These are exactly the state permutations admissible for every network, and their orbits can be counted by Burnside's lemma.
