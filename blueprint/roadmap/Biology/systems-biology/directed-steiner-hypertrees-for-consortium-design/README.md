# Directed Steiner hypertrees for consortium design

Designing a synthetic microbial consortium that produces target compounds from given substrates, while minimizing inserted foreign reactions and inter-species transport, is a minimum-weight production problem on a directed hypergraph assembled from genome-scale metabolic models. The problem generalizes the directed Steiner tree problem and its complexity is governed by the number of targets and the number of substrates of multi-substrate reactions.
