# Cytokine interaction network inference

Reconstruction of direct up- and down-regulatory interactions among cytokines from secretion measurements under stimulation with and without cytokine-blocking antibodies. A multiplicative secretion-rate model makes every network configuration a nested sub-model of the full network, so the configuration with the best Akaike information criterion can be found exactly while fitting only a small fraction of the exponentially many candidates.
