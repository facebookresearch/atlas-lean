# Cylindrical connectivity and unique min-sets

**Setting.** A discrete network node is modelled by an unknown function $f : \{0,\dots,p-1\}^n \to \{0,\dots,p-1\}$ (Boolean when $p = 2$). Data $\mathcal{D}$ consist of an input set $V$ and an output assignment $T : V \to$ outputs. A set of variables is *feasible* if some function of only those variables fits the data; a *min-set* is a minimal feasible set (the unsigned wiring diagram), and a *signed min-set* additionally records whether each variable acts as an activator or inhibitor (for unate functions). The data ideal $I^{\mathrm{ext}}$ generated by pseudomonomials has a primary decomposition that encodes both the unsigned and the signed min-sets.

**Definitions.** A *cylinder* is a set $C = \{s : s_i = u_i \text{ for } i \in N\}$ fixing some coordinates. A set is *connected* if any two points are joined by a path of points at Hamming distance 1 inside it. $V$ is *cylindrically connected* if $C \cap V$ is connected for every cylinder $C$. $V$ has a *diagonal of length $l$* if some $p \in V$ differs from every other point of $V$ in at least $l \ge 2$ coordinates.

**Theorem.** For an input set $V$ the following are equivalent:
1. for every output assignment there is exactly one unsigned min-set;
2. for every cylinder $C$ and every connected $S \subsetneq C \cap V$ there is a connected $S'$ with $S \subsetneq S' \subseteq C\cap V$;
3. $V$ is cylindrically connected.

For Boolean $V$ the same three conditions are equivalent to "every output assignment has at most one signed min-set", and if moreover the data come from a unate function the signed min-set exists and is unique.

**Obstruction.** If $V$ has a diagonal of length $l$, some output assignment has at least $l$ unsigned min-sets, and (for Boolean $V$, or when the diagonal point is a corner) at least $l$ signed min-sets.

## Expansion

A variable $x_k$ is forced into every feasible set exactly when two inputs differing only in coordinate $k$ have different outputs. If $V$ is cylindrically connected, any two inputs with different outputs are joined, inside the smallest cylinder containing both, by a Hamming path, and some single step on that path must change the output; this pins down the variables uniquely. A diagonal point is isolated from the rest of $V$ by $l$ coordinate changes at once, so attributing its different output to any one of those $l$ coordinates gives $l$ distinct minimal explanations. The result tells an experimentalist which perturbation designs suffice to identify the wiring diagram.
