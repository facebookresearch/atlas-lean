# Identifiable reparametrization of ODE models

When a biological ODE model is structurally unidentifiable, it can be rewritten in new state variables and new parameter combinations that are identifiable from input-output data while producing the same input-output equations. Linear compartmental models always admit such a rewrite through the observability matrix.
