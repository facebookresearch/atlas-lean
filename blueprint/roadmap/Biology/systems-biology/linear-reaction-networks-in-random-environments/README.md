# Linear reaction networks in random environments

A linear (first- and zero-order) chemical reaction network whose rate constants are modulated by an independent continuous-time Markov environment. Conditional on the environment path the mean evolves linearly, but averaging over the environment couples rates and state, so the stationary mean is not the mean of the averaged-rate system. It is nevertheless given in closed form by a linear system indexed by environment states.
