# Stable steady states of conjunctive networks and antichains

**Model.** For $N$ variables, input sets $I_i\subseteq\{1,\dots,N\}$, threshold $\theta\in(0,1)$ and Hill coefficient $n$,
$$\frac{dx_i}{dt}=\prod_{k\in I_i}\frac{x_k^n}{\theta^n+x_k^n}-x_i,\qquad i=1,\dots,N .$$
The wiring diagram has an edge $k\to i$ for each $k\in I_i$. Its strongly connected components $G_1,\dots,G_r$ are partially ordered by reachability.

**Theorems** (for large but finite $n$).

- Every stable steady state $\mathbf x_n$ lies in $[0,1]^N$, $\lim_{n\to\infty}\mathbf x_n\in\{0,1\}^N$, and each of the $2^N$ orthants cut out by the hyperplanes $x_i=\theta$ contains at most one stable steady state.
- If the wiring diagram is strongly connected, there are exactly two stable steady states: $\mathbf 0$ and a positive one tending to $(1,\dots,1)$.
- For every antichain $\{G_{k_1},\dots,G_{k_l}\}$ of components there is a stable steady state that vanishes exactly on the variables influenced by (reachable from) the antichain and is positive elsewhere; every stable steady state has this form. Hence stable steady states are in bijection with the antichains of the poset of strongly connected components (the empty antichain giving the all-positive state).
- If the wiring diagram is a disjoint union of two diagrams, the number of stable steady states is the product of the two numbers.
- For every $s\ge1$ some conjunctive network has exactly $s$ stable steady states; if $s=q_1\cdots q_l$, one can use $\sum_i(q_i-1)$ variables, and for $s=2^l$ the minimum number of variables is $l$.
- Up to a set of measure zero, every trajectory converges to a steady state.

## Expansion

As $n\to\infty$ each Hill factor tends to the step function $\mathbf 1\{x_k>\theta\}$, so the vector field approaches the Boolean AND network $x_i\mapsto\prod_{k\in I_i}\mathbf 1\{x_k>\theta\}$ with decay; stable steady states are hyperbolic perturbations of the Boolean fixed points in orthant interiors. A Boolean fixed point is determined by which variables are $0$: if $x_k=0$ then every node downstream of $k$ is $0$, and within a strongly connected component the AND structure makes all-ones self-sustaining. So the zero set is a down-closed (influence-closed) union of components generated by an antichain. A path of $q-1$ self-regulating nodes has a chain as its component poset, with $q$ antichains, so $q$ stable states; disjoint unions multiply the counts, realizing every factorization of $s$. Conversely $k$ variables give at most $2^k$ antichains, which proves sharpness for $s=2^l$.
