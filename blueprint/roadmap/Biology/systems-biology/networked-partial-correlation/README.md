# Networked partial correlation

Edge weights for Gaussian graphical models of gene coexpression obtained from the decomposition of a covariance over the paths of the concentration graph. The weight of a single-edge path inflates the partial correlation by how strongly the gene pair is tied to the rest of the network, separating functional associations from genetic interactions.

- [Single-edge path weight equals partial covariance over one minus squared vector correlation](networked-partial-covariance-from-single-edge-path-weight.md)
