# Analytic steady states of reaction-network ODEs

Imposing that an ODE model of a biochemical network starts at steady state requires solving the steady-state equations for the initial values. Writing each equation as "state equals in-flux over out-flux coefficient" defines a directed steady-state graph; when that graph is acyclic the steady state follows explicitly and nonnegatively by back-substitution, and cycles can be split by conserved quantities or by solving for flux parameters.
