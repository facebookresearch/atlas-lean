# Linear noise approximation

The linear noise approximation describes a density-dependent reaction network of system size $\Omega$ as a deterministic reaction-rate trajectory plus Gaussian fluctuations of order $\Omega^{-1/2}$ that evolve by a linear SDE along that trajectory. Re-anchoring the fluctuations to the closest point of a reference trajectory (phase correction) keeps the approximation accurate for oscillatory and bistable systems.
