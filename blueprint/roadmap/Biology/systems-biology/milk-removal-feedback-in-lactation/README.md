# Milk-removal feedback in lactation

Impulsive models of lactation in which milk accumulates and production decays between removal sessions, and each session up-regulates production by an amount that depends on the milk removed. Composing the wait-phase flow with the removal jump gives a planar map whose fixed points decide whether a regular feeding or pumping schedule sustains lactation.
