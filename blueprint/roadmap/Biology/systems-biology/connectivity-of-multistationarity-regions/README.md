# Connectivity of multistationarity regions

The set of reaction rate constants and total concentrations for which a reaction network admits several positive steady states in one stoichiometric class can be studied through the sign of a determinant along a parametrization of the steady states. When the negativity set of this critical function is path connected, so is the multistationarity region; a separating-hyperplane test on the Newton polytope certifies this computationally.
