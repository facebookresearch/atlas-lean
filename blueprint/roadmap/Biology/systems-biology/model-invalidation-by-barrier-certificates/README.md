# Model invalidation by barrier certificates

A candidate model of a biological system can be proved inconsistent with experimental data, for every parameter value in a given set, by exhibiting a single function of state, parameters and time (a barrier certificate) that separates the reachable trajectories from the measured data. For polynomial models, sum-of-squares relaxations turn the search for such a certificate into a semidefinite program; for discrete-time models the same question becomes emptiness of a semialgebraic set, decided by Positivstellensatz certificates.
