# Duplication–divergence random graphs

Growing random graphs in which each new vertex copies the links of a randomly chosen parent and keeps each copied link independently with probability $p$. They model the evolution of protein-interaction networks by gene duplication followed by divergence. For uniform parent choice the degree of a typical vertex has a stationary power-law limit with exponent $\kappa$ solving $p^\kappa + p\kappa = 1$ when $p\,e^p < 1$.
