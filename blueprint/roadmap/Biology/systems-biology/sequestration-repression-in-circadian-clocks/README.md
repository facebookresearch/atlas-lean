# Sequestration repression in circadian clocks

Mammalian clock models combine a Hill-type transcriptional repression loop with a sequestration loop, in which a repressor complex binds the activator stoichiometrically. In the fast-sequestration limit the activator and repressor never coexist, and a piecewise-affine reduction makes the cycle of switching regions explicit enough to prove a periodic orbit.
