# Solution of the reduced problem on a slow-time window

For real $k_1, k_b, k_2, s_0$ and $T$, a function $u : \mathbb{R} \to \mathbb{R}$ solves the reduced
(outer) problem on the slow-time window $[0, T]$ when $u(0) = 1$ and, at every $\theta \in [0, T]$,
it has a two-sided derivative $u'(\theta) = F(u(\theta))$, with the
[reduced field](reduced-field.md) $F(u) = -(1 + \kappa)\, u/(\kappa + u)$, $\kappa = K_M/s_0$. For
$T < 0$ only $u(0) = 1$ is required.
