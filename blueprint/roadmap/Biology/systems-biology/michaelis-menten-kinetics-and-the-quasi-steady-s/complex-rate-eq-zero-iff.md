# Quasi-steady-state manifold

Let $k_1 > 0$ and $k_b, k_2, e_0, s, c \in \mathbb{R}$, with $K_M + s \ne 0$ for
$K_M = (k_b + k_2)/k_1$ the [Michaelis constant](michaelis-constant.md). With total enzyme $e_0$, so that $e = e_0 - c$, the complex is stationary,
$k_1 (e_0 - c) s - (k_b + k_2) c = 0$, if and only if $c = e_0 s/(K_M + s)$.
