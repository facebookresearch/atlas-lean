# Perfect adaptation

Let $n$ be a finite index set and let $(A, b, c, d)$ be a [linear system](linear-system.md) $\dot x = A x + u b$, $y = c \cdot x + d u$ on $\mathbb{R}^n$. The system has perfect adaptation when, for every constant input $u \in \mathbb{R}$,
the output $c \cdot x + d u$ vanishes at every equilibrium $x$ (every $x$ with $A x + u b = 0$).
