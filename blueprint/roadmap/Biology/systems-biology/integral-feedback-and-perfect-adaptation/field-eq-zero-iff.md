# Unique equilibrium of a nonsingular linear system

Let $n$ be a finite index set and let $(A, b, c, d)$ be a [linear system](../../../Analysis/control-theory/linear-system.md) $\dot x = A x + u b$, $y = c \cdot x + d u$ on $\mathbb{R}^n$, with $A$ nonsingular. For every input $u \in \mathbb{R}$ and state $x \in \mathbb{R}^n$,
$A x + u b = 0$ if and only if $x = -u A^{-1} b$.
