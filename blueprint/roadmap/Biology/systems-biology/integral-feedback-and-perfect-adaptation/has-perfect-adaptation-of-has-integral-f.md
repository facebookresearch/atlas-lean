# Integral feedback implies perfect adaptation

Let $n$ be a finite index set and let $(A, b, c, d)$ be a [linear system](linear-system.md) $\dot x = A x + u b$, $y = c \cdot x + d u$ on $\mathbb{R}^n$. If the system has [integral feedback](has-integral-feedback.md), then it has
[perfect adaptation](has-perfect-adaptation.md).
