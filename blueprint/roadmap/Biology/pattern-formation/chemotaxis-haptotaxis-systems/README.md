# Chemotaxis–haptotaxis systems

Parabolic–parabolic or parabolic–elliptic cell-migration models in which cells respond both to a diffusing chemical signal (chemotaxis) and to a non-diffusing, consumed extracellular matrix (haptotaxis). Typical questions are global existence, boundedness versus blow-up, and convergence to homogeneous equilibria.
