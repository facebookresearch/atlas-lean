# Velocity correlations in animal swarms

Statistical-physics measures of collective behaviour in groups of moving animals: dimensionless
velocity fluctuations about the collective motion, their connected spatial correlation function,
the correlation length, and the integrated correlation (susceptibility), which can be large even
in groups with no global alignment.
