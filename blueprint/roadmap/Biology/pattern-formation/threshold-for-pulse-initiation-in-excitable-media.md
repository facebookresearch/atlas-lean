# Threshold for pulse initiation in excitable media

This node records a research direction: in a specified excitable-medium model, which initial conditions trigger a propagating pulse and which decay? Local stability of an existing pulse is not a global initiation result.

## What would settle it

Fix one partial differential equation model (for example the FitzHugh–Nagumo equations with stated parameters) and a one-parameter family of initial stimuli. Then prove a threshold theorem: below a critical parameter value the solution decays, above it the solution converges to a traveling pulse, under explicit hypotheses.

## Status

Hastings poses the qualitative pulse-initiation question in the cited 2015 slides. The parameterized threshold theorem above is a more specific target, not a theorem supplied by those slides. This page does not certify its present status or novelty. The status evidence for this direction is incomplete; check later literature before relying on it.

In the cited 2015 slides, Hastings recalls local stability of the fast pulse for the FitzHugh–Nagumo model, established through Evans-function analysis of the linearized spectrum. The slides distinguish this from global stability and ask which initial conditions can trigger a pulse. For the scalar bistable equation, they recall the Fife–McLeod global stability theorem for traveling fronts.
