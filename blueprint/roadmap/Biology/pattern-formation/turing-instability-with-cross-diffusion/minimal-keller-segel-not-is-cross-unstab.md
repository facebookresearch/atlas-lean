# For β > 0, the minimal Keller–Segel homogeneous mode is not unstable

Let $\beta > 0$ and $\alpha$ be real. For the minimal Keller–Segel Jacobian
$J = \begin{pmatrix} 0 & 0 \\ \alpha & -\beta \end{pmatrix}$ and every real $2 \times 2$ matrix $D$,
the homogeneous mode $k = 0$ is not [linearly unstable](is-cross-unstable-mode.md): the eigenvalues
of $J$ are $0$ and $-\beta$, so the mode is neutral ($\det J = 0$, conservation of the cell mass).
