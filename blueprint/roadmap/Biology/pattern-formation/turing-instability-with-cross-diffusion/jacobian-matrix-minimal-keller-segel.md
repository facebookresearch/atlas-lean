# The minimal Keller–Segel kinetics have Jacobian ((0, 0), (α, −β))

For real $\alpha$ and $\beta$, the minimal Keller–Segel kinetics ($r = 0$),
$(u, v) \mapsto (0,\ \alpha u - \beta v)$, are linear, so their
[Jacobian matrix](../../../Analysis/real-functions/multivariable-calculus/jacobian-matrix/jacobian-matrix.md)
at every state is $\begin{pmatrix} 0 & 0 \\ \alpha & -\beta \end{pmatrix}$, in particular, for
$\beta \neq 0$, at each steady state $(u_0, \alpha u_0/\beta)$.
