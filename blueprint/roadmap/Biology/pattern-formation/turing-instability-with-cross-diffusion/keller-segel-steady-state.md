# Homogeneous state (1, α/β) of the Keller–Segel kinetics

For real $\alpha$ and $\beta$, the homogeneous state of the Keller–Segel kinetics is
$(1, \alpha/\beta)$, with the quotient read as $0$ when $\beta = 0$. For $\beta \neq 0$ it is a
[steady state](keller-segel-steady-state-2.md) of the [kinetics](keller-segel-kinetics.md).
