# For stable kinetics, the homogeneous mode is stable whatever D

Let $J$ be a real $2 \times 2$ matrix with $\operatorname{tr} J < 0$ and $\det J > 0$ (kinetics
stable without diffusion). Then for every real $2 \times 2$ matrix $D$ the homogeneous mode $k = 0$
is not [linearly unstable](is-cross-unstable-mode.md).
