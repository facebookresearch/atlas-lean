# For diagonal D, cross-diffusion instability is Turing instability

For a real $2 \times 2$ matrix $J$ and real $d_u$, $d_v$ and $k$, the Fourier mode of wavenumber $k$
is [linearly unstable](is-cross-unstable-mode.md) for the diagonal diffusion matrix
$\operatorname{diag}(d_u, d_v)$ if and only if it is
[linearly unstable](../turing-patterns-and-diffusion-driven-instability/is-unstable-mode.md) in the
diagonal theory: both say that $J - k^2 \operatorname{diag}(d_u, d_v)$ has a complex eigenvalue with
positive real part.
