# A mode is unstable iff tr(J − k²D) > 0 or det(J − k²D) < 0

Let $J$ and $D$ be real $2 \times 2$ matrices (the Jacobian of the kinetics at a homogeneous steady
state and a diffusion matrix, possibly non-diagonal), and let $k$ be real. The Fourier mode of
wavenumber $k$ is [linearly unstable](is-cross-unstable-mode.md) if and only if
$\operatorname{tr}(J - k^2 D) > 0$ or $\det(J - k^2 D) < 0$ (Routh–Hurwitz criterion for a real
$2 \times 2$ matrix).
