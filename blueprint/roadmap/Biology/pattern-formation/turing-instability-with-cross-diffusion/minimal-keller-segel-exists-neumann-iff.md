# Minimal Keller–Segel on an interval: some n ≥ 1 unstable iff n = 1 is

Let $\beta > 0$, $d_u, d_v \ge 0$, $L > 0$, and let $\alpha$, $\chi$ and $u_0$ be real. For the
minimal Keller–Segel Jacobian $\begin{pmatrix} 0 & 0 \\ \alpha & -\beta \end{pmatrix}$ and the
[diffusion matrix](keller-segel-diffusion.md)
$D = \begin{pmatrix} d_u & -\chi u_0 \\ 0 & d_v \end{pmatrix}$, some non-homogeneous Neumann mode
$\cos(n\pi x/L)$ with $n \ge 1$ is [linearly unstable](is-cross-unstable-mode.md) if and only if the
first one is, that is, if and only if

$$d_u d_v (\pi/L)^2 < \alpha \chi u_0 - \beta d_u.$$

In the model $\alpha > 0$, $\chi \ge 0$ and $u_0 \ge 0$; the equivalence holds for all real values.
