# For diagonal diffusion, the mode matrix is the Turing mode matrix

For a real $2 \times 2$ matrix $J$ and real $d_u$, $d_v$ and $k$, the
[mode matrix](cross-mode-matrix.md) $J - k^2 D$ with the diagonal
[diffusion matrix](../turing-patterns-and-diffusion-driven-instability/diffusion-matrix.md)
$D = \operatorname{diag}(d_u, d_v)$ is the
[mode matrix](../turing-patterns-and-diffusion-driven-instability/mode-matrix.md)
$J - k^2 \operatorname{diag}(d_u, d_v)$ of the diagonal theory.
