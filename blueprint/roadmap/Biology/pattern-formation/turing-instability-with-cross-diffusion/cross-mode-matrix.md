# Mode matrix J − k²D for a full diffusion matrix

Let $J$ and $D$ be real $2 \times 2$ matrices (the Jacobian of the kinetics at a homogeneous steady
state and a diffusion matrix, possibly non-diagonal), and let $k$ be real. The mode matrix of the
Fourier mode of wavenumber $k$ for the linearized system $w_t = D w_{xx} + J w$ is $J - k^2 D$.
