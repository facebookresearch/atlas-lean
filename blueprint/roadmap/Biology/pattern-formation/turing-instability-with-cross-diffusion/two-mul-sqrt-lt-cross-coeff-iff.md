# 2√(det D det J) < b iff b > 0 and 4 det D det J < b²

Let $J$ and $D$ be real $2 \times 2$ matrices (the Jacobian of the kinetics at a homogeneous steady
state and a diffusion matrix, possibly non-diagonal), and let
$b = J_{00} D_{11} + J_{11} D_{00} - J_{01} D_{10} - J_{10} D_{01}$. Then
$2 \sqrt{\det D \det J} < b$ if and only if $b > 0$ and $4 \det D \det J < b^2$. This holds for all
real inputs: when $\det D \det J < 0$ the square root is read as $0$, and both sides reduce to
$b > 0$.
