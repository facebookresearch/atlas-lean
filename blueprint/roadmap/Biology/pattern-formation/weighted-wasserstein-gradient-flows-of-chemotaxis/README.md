# Weighted Wasserstein gradient flows of chemotaxis

Keller–Segel systems with a volume-filling mobility $m(u) = u^\alpha$, $0 < \alpha < 1$ (cells are slowed by crowding), are gradient flows in the weighted Wasserstein metric of Dolbeault–Nazaret–Savaré, and weak solutions can be built by minimizing movements (JKO schemes). Passing to the limit uses the flow interchange technique, which needs an evolution variational inequality; removing the classical convexity assumption on the habitat domain extends the construction to non-convex domains.
