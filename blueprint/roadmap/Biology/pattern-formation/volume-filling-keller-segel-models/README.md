# Volume-filling Keller–Segel models

Keller–Segel chemotaxis systems in which cell motility and chemotactic sensitivity vanish as the cell density approaches a maximal packing density, preventing blow-up; with degenerate diffusion they still produce nonconstant steady patterns in some parameter regimes.
