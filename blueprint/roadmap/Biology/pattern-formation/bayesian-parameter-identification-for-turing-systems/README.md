# Bayesian parameter identification for Turing systems

Parameters of reaction-diffusion models of pattern formation, including the growth law of an evolving domain, can be inferred from noisy observations of a pattern by a Bayesian inverse problem posed on an infinite-dimensional parameter space. The posterior is defined by a density with respect to the prior, and continuity of the forward map guarantees that it exists and depends continuously on the data before any discretization.
