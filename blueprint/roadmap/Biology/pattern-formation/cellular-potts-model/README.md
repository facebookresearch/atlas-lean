# Cellular Potts model

The cellular Potts (Glazier–Graner–Hogeweg) model represents cells as connected sets of lattice sites carrying a common cell index and evolves the configuration by Metropolis-type index copies driven by a Hamiltonian with adhesion and volume terms. Because new indices are only copied from neighbours, the modified Metropolis dynamics is an absorbing Markov chain: cells disappear one by one, and the only stationary distributions are concentrated on single-cell configurations.
