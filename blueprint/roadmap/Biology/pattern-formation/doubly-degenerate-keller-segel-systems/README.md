# Doubly degenerate Keller–Segel systems

Keller–Segel models in which the cell diffusion coefficient vanishes both where the cells are absent and where the chemical signal is absent, $u_t = \nabla\cdot(uv\nabla u) - \nabla\cdot(u^2v\nabla v)$. Such models describe bacterial colonies on nutrient-poor substrates, where motility requires both neighbours and signal. Although the diffusion is degenerate, the classical Keller–Segel Lyapunov functional survives, and two-dimensional critical-mass thresholds reappear.
