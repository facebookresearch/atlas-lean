# Indirect signal production chemotaxis

Keller–Segel models in which cells produce an intermediate mediator that in turn produces the sensed signal. Closing both signal stages quasi-statically gives a fourth-order elliptic interaction with critical dimension four; keeping the last stage dynamic gives a Volterra (memory) drift.
