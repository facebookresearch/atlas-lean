# Chemotaxis-enhanced reaction rates

How chemical attraction toward an immobile target speeds up reactions such as fertilization or immune targeting, modeled by a Keller–Segel drift coupled to a contact reaction. The analysis rests on sharp convergence-to-equilibrium estimates for Fokker–Planck operators with logarithmic potentials.
