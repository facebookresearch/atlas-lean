# The Ablowitz–Zeppetella profile is a closed traveling front

Let $D, r, C > 0$. The [Ablowitz–Zeppetella profile](az-wave.md) $U(z) = (1 + C e^{\kappa z})^{-2}$,
$\kappa = \sqrt{r/(6D)}$, with its [derivative](az-wave-deriv.md), is a
[closed traveling front](is-closed-front.md) of speed $5\sqrt{rD/6}$, the
[Ablowitz–Zeppetella speed](az-speed.md).
