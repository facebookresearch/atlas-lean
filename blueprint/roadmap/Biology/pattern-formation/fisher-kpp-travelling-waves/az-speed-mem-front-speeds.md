# The Ablowitz–Zeppetella speed carries a strictly decreasing front

Let $D > 0$ and $r > 0$. There is a
[traveling front](../../../Analysis/ordinary-differential-equations/is-front.md) of speed
$5\sqrt{rD/6}$, the [Ablowitz–Zeppetella speed](az-speed.md), with strictly decreasing profile. The
proof takes the [Ablowitz–Zeppetella profile](az-wave.md) with $C = 1$, so no existence theorem is
used.
