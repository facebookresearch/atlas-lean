# The Ablowitz–Zeppetella front

Let $D, r, C > 0$. The [Ablowitz–Zeppetella profile](az-wave.md)
$U(z) = (1 + C e^{\kappa z})^{-2}$, $\kappa = \sqrt{r/(6D)}$, together with its
[derivative](az-wave-deriv.md), is a [traveling front](../../../Analysis/ordinary-differential-equations/is-front.md) of speed $5\sqrt{rD/6}$.
