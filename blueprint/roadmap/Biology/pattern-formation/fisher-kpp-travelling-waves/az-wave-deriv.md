# Derivative of the Ablowitz–Zeppetella profile

For real $D$, $r$ and $C$, the derivative of the [Ablowitz–Zeppetella profile](az-wave.md) is

$$U'(z) = -2\kappa C e^{\kappa z} \left(1 + C e^{\kappa z}\right)^{-3},$$

with $\kappa = \sqrt{r/(6D)}$ the [Ablowitz–Zeppetella rate](az-rate.md) and
$(1 + C e^{\kappa z})^{-1}$ read as $0$ where $1 + C e^{\kappa z} = 0$.
