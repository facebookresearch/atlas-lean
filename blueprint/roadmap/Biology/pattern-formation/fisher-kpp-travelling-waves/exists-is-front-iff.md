# Fronts of speed c exist exactly for c at or above the minimal speed

Let $D > 0$ and $r > 0$. Assume that for every $c' \ge 2\sqrt{rD}$ there is a
[traveling front](../../../Analysis/ordinary-differential-equations/is-front.md) of speed $c'$ with
strictly decreasing profile; the [Kolmogorov–Petrovsky–Piskunov theorem](exists-is-front-of-le.md)
gives this. Then for every real $c$, a
[traveling front](../../../Analysis/ordinary-differential-equations/is-front.md) of speed $c$ exists
if and only if $c \ge 2\sqrt{rD}$. Equivalently, the set of speeds $c$ for which a traveling
front of speed $c$ exists is $[2\sqrt{rD}, \infty)$.
