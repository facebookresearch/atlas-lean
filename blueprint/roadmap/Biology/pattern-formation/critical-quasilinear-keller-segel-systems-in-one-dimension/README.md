# Critical quasilinear Keller–Segel systems in one dimension

Quasilinear Keller–Segel systems $u_t = (D(u)u_x - S(u)v_x)_x$ coupled to a linear signal equation on the interval $(0,1)$, in the critical regime where $S(u)/D(u)$ grows like $u^{2/n} = u^2$. In higher dimensions such critical systems exhibit a critical mass separating global boundedness from blow-up; in one dimension the mass accumulation function satisfies a non-degenerate parabolic equation, and global boundedness can hold for every mass.
