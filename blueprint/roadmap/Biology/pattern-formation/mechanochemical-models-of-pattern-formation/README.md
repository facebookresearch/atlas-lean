# Mechanochemical models of pattern formation

Murray–Oster type models in which cells pull on the extracellular matrix (ECM), the matrix deforms viscoelastically, and the deformation advects cells and matrix. Linear stability of the homogeneous state gives a dispersion relation whose sign structure decides whether spatial patterns form; the stress–strain constitutive law of the matrix changes which modes grow.
