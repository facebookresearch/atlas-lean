# Bistable Keller-Segel models of microvascular patterns

Chemotaxis models with bistable (Allee-type) cell kinetics that reproduce the patterns formed by growing brain microvascular endothelial cells, their linear and nonlinear stability, and two-compartment reductions showing symmetry-breaking bifurcations driven by chemotactic strength.
