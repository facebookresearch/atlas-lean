# Reconstruction of kinetic chemotaxis kernels

Recovering the tumbling kernel of a run-and-tumble kinetic chemotaxis model from velocity-averaged, spatially localized density measurements by PDE-constrained least squares. Local well-posedness hinges on the positive definiteness of the loss Hessian, which depends on the experimental design.
