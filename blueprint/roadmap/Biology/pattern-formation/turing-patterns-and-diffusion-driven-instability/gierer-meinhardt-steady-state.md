# Steady state of the Gierer–Meinhardt kinetics

For real $a$ and $b$, the homogeneous steady state of the [Gierer–Meinhardt kinetics](gierer-meinhardt.md)
is

$$(u_0, v_0) = \left(\frac{a + 1}{b}, \left(\frac{a + 1}{b}\right)^2\right),$$

with $(a + 1)/b$ read as $0$ when $b = 0$. It is an [equilibrium](gierer-meinhardt-steady-state-2.md)
when $a + 1 \ne 0$ and $b \ne 0$.
