# Trace condition for the Gierer–Meinhardt steady state

Let $a$ and $b$ be real with $a + 1 > 0$. The [Gierer–Meinhardt Jacobian](gierer-meinhardt-jacobian.md)
has negative trace if and only if $b(1 - a) < 1 + a$. Since its
[determinant](det-gierer-meinhardt-jacobian.md) is $b$, for $b > 0$ this is the condition for the
steady state to be stable without diffusion.
