# Stability of the Schnakenberg steady state without diffusion

Let $a$ and $b$ be real with $a + b > 0$. The [Schnakenberg Jacobian](schnakenberg-jacobian.md) has
negative trace if and only if $b - a < (a + b)^3$. Its [determinant](det-schnakenberg-jacobian.md)
$(a + b)^2$ is then positive, so this is the condition for stability without diffusion.
