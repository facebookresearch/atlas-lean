# Chemotactic search in shear flow

First-hitting-time analysis of a Brownian agent searching for a small target in a strong fluid shear flow, aided by chemotaxis toward a chemical released by the target. It models fertilization in broadcast spawning and immune-cell search. Strong shear homogenizes the chemical field and reduces the problem to a one-dimensional search.
