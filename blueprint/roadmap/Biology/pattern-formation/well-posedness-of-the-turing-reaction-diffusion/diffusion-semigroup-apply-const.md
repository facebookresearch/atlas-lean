# If H fixes constants, the diffusion operators fix constant fields

Let $K$ be a compact topological space, $H = (H(\tau))_{\tau \ge 0}$ any family of bounded linear
operators on $C(K, \mathbb{R})$ with $H(\tau)\, 1 = 1$ for every $\tau \ge 0$ (as for the Neumann
heat semigroup), and $d_u, d_v \ge 0$. Then the [diffusion operators](diffusion-semigroup.md)
$S(t) = \operatorname{diag}(H(d_u t), H(d_v t))$ fix every constant field: $S(t)\, c = c$ for every
$c \in \mathbb{R}^2$ and every $t \ge 0$.
