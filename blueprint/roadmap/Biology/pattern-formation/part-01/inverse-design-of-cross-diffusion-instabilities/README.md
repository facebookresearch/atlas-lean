# Inverse design of cross-diffusion instabilities

For linearised reaction–cross-diffusion systems $\partial_t u = Ju + \hat D\,\partial_{xx}u$, the classical question fixes $J$ and $\hat D$ and asks whether diffusion destabilises the homogeneous state. The inverse questions fix one of the two matrices and ask whether the other can be chosen to produce a Turing (real) or wave (oscillatory) instability. Eigenvectors of a non-diagonal diffusion matrix let one select an unstable principal submatrix of the reaction Jacobian, which answers both questions constructively.
