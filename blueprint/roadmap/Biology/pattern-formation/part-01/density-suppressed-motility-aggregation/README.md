# Density-suppressed motility aggregation

Direct aggregation without any attractive force: individuals move randomly, but their random motility decreases with the population density they perceive in a neighbourhood. The individual-based stochastic model has a nonlocal, possibly degenerate nonlinear diffusion equation as mean-field limit, which admits measure-valued (clumped) steady states and a Fourier criterion for when uniform densities break up into aggregates.
