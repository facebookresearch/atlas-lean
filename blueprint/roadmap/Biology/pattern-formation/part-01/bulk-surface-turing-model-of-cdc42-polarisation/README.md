# Bulk-surface Turing model of Cdc42 polarisation

A mass-conserving reaction–diffusion model couples a cytosolic Cdc42 pool in the cell interior to active and inactive Cdc42 on the membrane. It admits classic and non-classic diffusion-driven instability, and it can form a single polarity pole.
