# Flux-based auxin canalization

Mitchison's canalization hypothesis models vein formation in plants as a positive feedback between auxin flux through a cell membrane and the insertion of PIN efflux carriers into that membrane. On a graph of cells this gives an ODE system whose steady states orient the graph; the shape of the flux response function decides whether stable patterns are loop-free trees and whether PIN concentrations blow up.
