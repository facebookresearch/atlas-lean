# Inverse problems for attraction–repulsion chemotaxis

Unique identification of chemotactic sensitivities, logistic growth and signal production/decay terms in attraction–repulsion Keller–Segel systems (one attractant, one repellent) from boundary traces and final-time snapshots, in both the parabolic–elliptic–elliptic and fully parabolic regimes, using high-order linearization around constant states.
