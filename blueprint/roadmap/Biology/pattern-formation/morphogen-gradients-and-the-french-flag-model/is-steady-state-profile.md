# Exponential profile is a bounded steady state

Let $D > 0$, $k > 0$ and $j \in \mathbb{R}$. Then the [morphogen profile](profile.md) $c(x) = (j/\sqrt{Dk})\, e^{-x/\lambda}$, $\lambda = \sqrt{D/k}$, together with
$c'(x) = -c(x)/\lambda$, is a [bounded steady state](is-steady-state.md) with source flux $j$.
