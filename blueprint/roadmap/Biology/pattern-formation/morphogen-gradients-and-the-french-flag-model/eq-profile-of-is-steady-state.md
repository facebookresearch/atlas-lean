# Uniqueness of the bounded steady state

Let $D > 0$, $k > 0$ and $j \in \mathbb{R}$. If $(c, c')$ is a
[bounded steady state](is-steady-state.md) with source flux $j$, then for every $x \ge 0$, $c(x)$
equals the [exponential profile](profile.md) $(j/\sqrt{Dk})\, e^{-x/\lambda}$, $\lambda = \sqrt{D/k}$.
