# French-flag boundary

Let $D, k, j, \theta > 0$. For every real $x$, the [morphogen profile](profile.md) $c(x) = (j/\sqrt{Dk})\, e^{-x/\lambda}$, $\lambda = \sqrt{D/k}$, satisfies $c(x) = \theta$ if and only
if $x = x_\theta = \lambda \log(c(0)/\theta)$, the [French-flag boundary](threshold-position.md).
