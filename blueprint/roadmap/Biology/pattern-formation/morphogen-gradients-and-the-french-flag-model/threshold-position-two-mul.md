# Doubling the source flux shifts boundaries by $\lambda \log 2$

Let $D, k, j, \theta > 0$. Doubling the source flux shifts the
[French-flag boundary](threshold-position.md) for the threshold $\theta$ away from the source by
exactly $\lambda \log 2$: $x_\theta(2j) = x_\theta(j) + \lambda \log 2$, with $\lambda = \sqrt{D/k}$.
