# Steady-state exponential morphogen profile

For real $D$, $k$, $j$ and $x$, the steady-state morphogen gradient with source flux $j$ at $x = 0$ is

$$c(x) = \frac{j}{\sqrt{Dk}}\, e^{-x/\lambda}, \qquad \lambda = \sqrt{D/k}$$

the [decay length](decay-length.md), where quotients by $0$ are read as $0$ and the square root of a negative number is read as $0$. The
model has $D, k > 0$.
