# French-flag boundary position for a threshold

For real $D$, $k$, $j$ and $\theta$, the French-flag boundary for the threshold $\theta$ is

$$x_\theta = \lambda \log\frac{c(0)}{\theta}, \qquad c(0) = \frac{j}{\sqrt{Dk}}, \quad \lambda = \sqrt{D/k},$$

where quotients by $0$ are read as $0$, the square root of a negative number is read as $0$, $\log 0 = 0$ and $\log x = \log|x|$ for
$x < 0$. For $D, k, j, \theta > 0$ it is negative exactly when $\theta > c(0)$; then no point
$x \ge 0$ has $c(x) \ge \theta$.
