# Bounded steady state of the synthesis–diffusion–degradation model

Let $D, k, j \in \mathbb{R}$. Functions $c, c' \colon \mathbb{R} \to \mathbb{R}$ form a bounded steady
state of the synthesis–diffusion–degradation model on $[0, \infty)$ with source flux $j$ when:

- for every $x > 0$, $c$ has derivative $c'(x)$ at $x$, and $c'$ has derivative $(k/D)\, c(x)$ at $x$
  (with $k/D$ read as $0$ when $D = 0$), so that $D c'' = k c$ on $(0, \infty)$ when $D \ne 0$;
- $c$ and $c'$ are continuous on $[0, \infty)$;
- the source flux is $-D\, c'(0) = j$;
- $c$ is bounded on $[0, \infty)$.
