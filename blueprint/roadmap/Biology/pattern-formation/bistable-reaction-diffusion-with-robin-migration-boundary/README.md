# Bistable reaction–diffusion with a Robin migration boundary

Steady states of a bistable reaction–diffusion equation for the proportion of one of two competing populations (for instance mosquitoes carrying *Wolbachia* among wild ones) on a treated interval, with a Robin boundary condition modelling migration exchange with an exterior population of fixed proportion. Whether the replacement persists depends on the size of the zone, the migration rate and the exterior proportion.
