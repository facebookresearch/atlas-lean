# Ordered leaf attachment encoding of trees

Rooted binary tree topologies with ordered leaves can be encoded as integer vectors by recording, for each leaf in order, the canonical label of the node it was attached next to. The encoding is a linear-time bijection onto a box of integer sequences and induces a Hamming-type tree distance.
