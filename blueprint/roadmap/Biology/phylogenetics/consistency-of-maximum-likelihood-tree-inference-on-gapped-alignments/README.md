# Consistency of maximum-likelihood tree inference on gapped alignments

Real multiple sequence alignments contain gaps from insertions and deletions, and standard likelihood software treats gaps as missing data. Whether maximum-likelihood tree inference remains statistically consistent then depends on how the indel process interacts with substitutions. With a metric on trees given by the largest discrepancy in leaf-to-leaf path lengths, consistency for ungapped alignments has a short proof through pairwise Kullback–Leibler separation, and it transfers to gapped alignments by splitting columns into finitely many gap-pattern categories.
