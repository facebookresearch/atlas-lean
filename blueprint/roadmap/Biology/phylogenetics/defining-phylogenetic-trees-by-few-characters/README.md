# Defining phylogenetic trees by few characters

A set of characters defines an unrooted binary phylogenetic tree when that tree is the only one on which every character is convex. With $r$-state characters at least $\lceil (n-3)/(r-1)\rceil$ characters are needed for $n$ leaves, and the question is from which leaf number this bound is always attained.
