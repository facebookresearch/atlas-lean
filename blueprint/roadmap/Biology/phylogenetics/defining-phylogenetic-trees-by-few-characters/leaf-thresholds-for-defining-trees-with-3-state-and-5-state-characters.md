# Leaf thresholds for defining trees with 3-state and 5-state characters

**Setting.** Let $\mathcal T$ be an unrooted binary phylogenetic $X$-tree with $n=|X|$ leaves (every interior vertex has degree $3$). A *character* is a map $\chi:X\to C$; it is an *$r$-state character* if $|\chi(X)|=r$. For a state $\alpha$ let $\mathcal T(\alpha)$ be the minimal subtree spanning the leaves of state $\alpha$; $\chi$ is *convex* on $\mathcal T$ if the vertex sets of the subtrees $\mathcal T(\alpha)$, $\alpha\in\chi(X)$, are pairwise disjoint. A set $\mathcal C$ of characters *defines* $\mathcal T$ if every character in $\mathcal C$ is convex on $\mathcal T$ and $\mathcal T$ is, up to isomorphism, the only $X$-tree on which all of $\mathcal C$ is convex. Since each $r$-state character can distinguish at most $r-1$ of the $n-3$ interior edges, at least $\lceil (n-3)/(r-1)\rceil$ characters are needed; it is known that for each $r$ there is a threshold $n_r$ such that every tree with $n\ge n_r$ leaves is defined by exactly $\lceil (n-3)/(r-1)\rceil$ $r$-state characters.

**Statement.**

1. ($r=3$) Every unrooted binary phylogenetic tree with $n\ge 8$ leaves is defined by a set of $\lceil (n-3)/2\rceil$ $3$-state characters, and there is a tree with $7$ leaves that is not defined by any set of $2=\lceil (7-3)/2\rceil$ characters. Hence $n_3=8$.
2. ($r=5$) Every unrooted binary phylogenetic tree with $n\ge 16$ leaves is defined by a set of $\lceil (n-3)/4\rceil$ $5$-state characters, and there is a tree with $15$ leaves that is not defined by any set of $3=\lceil (15-3)/4\rceil$ characters. Hence $n_5=16$.

## Expansion

A set of characters defines $\mathcal T$ exactly when every character is convex, every interior edge is distinguished by some character, and the associated partition intersection graph has a unique minimal restricted chordal completion (Semple-Steel). Lower thresholds are witnessed by internal-subtree obstructions: a tree is defined by at most two characters only if it has no internal subtree isomorphic to the $3$-star, and by at most three characters only if it has no internal subtree isomorphic to the snowflake (Huber et al.). The $7$-leaf counterexample contains an internal $3$-star, and the $15$-leaf counterexample is built from an internal structure that three $5$-state characters cannot resolve. For the upper bounds one verifies the base cases ($n=8,9$ for $r=3$; $n=16,\dots,19$ for $r=5$) by explicit character constructions and then inducts: removing $r-1$ suitably chosen pendant edges whose associated interior edges are pairwise non-adjacent gives a smaller tree, and a defining set for it is extended by one further $r$-state character that distinguishes the $r-1$ restored interior edges, the defining property being checked with the chordal-completion criterion. For $n=8$ and $n=9$ with $r=3$ the base case partitions the interior edges into three sets of at most two pairwise non-adjacent edges, each displayed by one character.
