# Gene tree–species tree reconciliation

Reconciliation maps each node of a gene tree into a species tree and labels it with the event that explains its divergence (speciation, duplication, horizontal transfer, or incomplete lineage sorting), together with the gene losses needed to embed the gene tree. Parsimony reconciliation chooses the event history of minimum weighted cost; allowing polytomies in the species tree lets lineage sorting explain incongruence where the species branching order is unresolved.
