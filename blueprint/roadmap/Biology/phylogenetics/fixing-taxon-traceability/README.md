# Fixing taxon traceability

A combinatorial, polynomial-time checkable sufficient condition for a collection of taxon sets to be phylogenetically decisive (every compatible choice of input trees has a unique supertree). Cross quadruples not covered by any locus are resolved through "fixing taxa" whose swaps are covered.
