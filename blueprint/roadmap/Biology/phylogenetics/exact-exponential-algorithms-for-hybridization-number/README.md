# Exact exponential algorithms for hybridization number

Moderately exponential exact algorithms for the hybridization number of two rooted phylogenetic trees, measured in the number of taxa $n$ rather than in the solution size, obtained by dynamic programming over the subsets of taxa that remain after repeatedly pruning maximal common pendant subtrees.
