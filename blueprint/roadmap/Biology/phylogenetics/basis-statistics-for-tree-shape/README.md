# Basis statistics for tree shape

Many tree balance indices are linear combinations of a few counting statistics: the number of clades of each size, or the number of inner vertices with each pair of daughter-clade sizes. Once the means and covariances of these basis statistics are known under a random-tree model such as the Yule model, the mean, variance and pairwise covariance of every represented index follow by linear algebra.
