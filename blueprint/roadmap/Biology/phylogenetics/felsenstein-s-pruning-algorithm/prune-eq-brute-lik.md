# Felsenstein's pruning algorithm computes the likelihood conditioned on the root state

For every commutative semiring $R$, finite state set $S$, leaf weights $\mathrm{obs}$, [tree](tree.md) $t$ and state $s$, the [pruning recursion](prune.md) equals the [brute-force likelihood](brute-lik.md): $\mathrm{pr}(t, s) = \Lambda(t, s)$.
