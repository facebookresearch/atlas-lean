# CFN likelihood landscape

Geometry of the maximum-likelihood problem for branch parameters of the two-state symmetric (Cavender-Farris-Neyman) model on a known tree. In the regime where ancestral states are reconstructable, the population and finite-sample log-likelihoods are strongly concave and smooth with diagonally dominant Hessians, uniformly over tree shapes, which makes coordinate maximization provably convergent.
