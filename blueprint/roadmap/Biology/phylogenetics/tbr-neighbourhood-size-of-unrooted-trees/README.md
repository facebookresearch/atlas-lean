# TBR neighbourhood size of unrooted trees

Exact counts of the trees one tree bisection and reconnection (TBR) move away from a given unrooted binary phylogenetic tree, expressed through the sum of split-size products, together with the shape-independent SPR count and the extremal tree shapes.
