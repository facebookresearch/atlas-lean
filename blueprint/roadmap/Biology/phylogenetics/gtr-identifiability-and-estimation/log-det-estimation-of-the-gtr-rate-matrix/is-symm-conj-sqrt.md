# Square-root conjugation symmetrizes a matrix in detailed balance

Let `ι` be a finite set of states. Let `π : ι → ℝ` have `π i > 0` for every `i`, and let `Q` be a
real `ι × ι` matrix in
[detailed balance](../../../../Probability/markov-chains/finite-continuous-time-markov-chains/stationarity-and-detailed-balance-for-finite-con/is-detailed-balance.md)
with `π`: `π i · Q i j = π j · Q j i` for all `i`, `j`. Then `diag (√π) · Q · diag (√π)⁻¹`, with
entries `√(π i) · Q i j / √(π j)`, is symmetric.
