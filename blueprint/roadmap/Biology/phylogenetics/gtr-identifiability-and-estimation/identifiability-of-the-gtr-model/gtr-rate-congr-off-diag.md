# The diagonal of the exchangeabilities does not affect the rate matrix

Let `ι` be a finite set of states. Let `π` be real base frequencies. Exchangeabilities `s` and `s'`
that agree off the diagonal, `s i j = s' i j` for all `i ≠ j`, give the same
[GTR rate matrix](../../time-reversible-nucleotide-substitution-models/gtr-rate.md):
`Q(π, s) = Q(π, s')`. So the diagonal of `s` cannot be identified from the rate matrix.
