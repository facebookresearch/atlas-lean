# NNI diameter of unrooted phylogenetic network space

Unrooted binary phylogenetic networks on a taxon set $X$ form a connected graph under nearest-neighbor interchange (NNI) and triangle operations; within a fixed reticulation tier, NNI, SPR and TBR moves define metrics. Counting arguments and explicit transformation paths bound the diameter of each tier between orders $n\log n$ and $n^2$ in the number of vertices.
