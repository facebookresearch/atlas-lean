# Segmental duplication reconciliation

Reconciling several gene trees with one species tree when a single segmental duplication can copy many genes at once, so duplications mapped to the same species node and pairwise incomparable are counted once; includes the synteny-aware super-reconciliation model with partial and full segmental losses.
