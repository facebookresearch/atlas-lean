# Gene tree correction for reconciliation

Editing an estimated gene tree before reconciling it with a species tree, so that duplications inferred by the lowest-common-ancestor mapping reflect real gene duplications rather than misplaced leaves. Corrections either remove the fewest leaves or species so that every remaining duplication is apparent, or rearrange the tree as little as possible in Robinson–Foulds distance so that pairs of genes known to be orthologous descend from speciation nodes.
