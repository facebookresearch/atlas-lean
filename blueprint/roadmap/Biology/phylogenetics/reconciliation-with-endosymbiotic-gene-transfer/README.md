# Reconciliation with endosymbiotic gene transfer

Reconciliation of a gene tree with a species tree when each species carries two genomes (for example mitochondrial and nuclear) and genes can move between them by endosymbiotic gene transfer, either copied or cut. The parsimony problem keeps the classical LCA species mapping and reduces the genome assignment to a Fitch-style labelling problem.
