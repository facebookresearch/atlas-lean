# Level-1 network reconstruction from quarnets

Dense sets of four-leaf triangle-free level-1 networks can be puzzled together into a semi-directed level-1 network: a blobtree is built from quartet support, and each blob is expanded into a cycle ordered by a travelling-salesman tour.
