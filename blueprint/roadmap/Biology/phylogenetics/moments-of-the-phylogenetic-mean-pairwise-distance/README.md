# Moments of the phylogenetic mean pairwise distance

The mean pairwise distance (MPD) of a set of tips on a weighted phylogeny is a standard community-relatedness statistic. Its null distribution over uniformly random tip sets of fixed size has mean, variance and skewness that can all be computed exactly in time linear in the tree size.
