# Orthology graphs of event-labeled gene trees are exactly the cographs

**Setting.** A gene tree $T$ is a rooted tree whose leaves $L(T)$ are genes and whose inner vertices are labeled by a map $t$ as speciations ($\mathrm{SPEC}$) or duplications ($\mathrm{DUPL}$), in a scenario without horizontal gene transfer. Two distinct genes $x, y$ are **orthologs** if $t(\mathrm{lca}_T(x,y)) = \mathrm{SPEC}$ and **paralogs** if $t(\mathrm{lca}_T(x,y)) = \mathrm{DUPL}$ (Fitch's definition). The **orthology graph** $\Theta(T,t)$ has vertex set $L(T)$ and an edge $xy$ for every orthologous pair; the paralogy graph is its complement. A **cograph** is a graph with no induced path on four vertices ($P_4$), equivalently one built from single vertices by disjoint unions and joins.

**Theorem.** A graph $G$ is the orthology graph $\Theta(T,t)$ of some event-labeled tree $(T,t)$ if and only if $G$ is a cograph. Moreover, every cograph is explained by its cotree (join nodes labeled $\mathrm{SPEC}$, union nodes $\mathrm{DUPL}$), the unique least-resolved such tree.

Orthology need not be transitive, but it is always "$P_4$-free": if $a\!-\!b\!-\!c\!-\!d$ were an induced path of orthologs, the LCAs of the pairs would force contradictory event labels on a common ancestor. Consequently an empirically estimated orthology relation (for example reciprocal best matches, which contain the true orthology and may contain false positives) can be corrected by cograph editing, and any induced $P_4$ certifies an error.

## Expansion

For leaves $x, y$ the vertex $\mathrm{lca}_T(x,y)$ determines whether $xy$ is an edge, so the graph restricted to the leaves below an inner vertex $v$ is the join (if $v$ is a speciation) or the disjoint union (if $v$ is a duplication) of the graphs below its children. Recursively, $\Theta(T,t)$ is generated by unions and joins, which is the definition of a cograph; conversely, the cotree decomposition of a cograph is an event-labeled tree realizing it. The same tree-to-graph dictionary underlies best-match graphs and Fitch graphs, the other graph classes encoding gene-family history.
