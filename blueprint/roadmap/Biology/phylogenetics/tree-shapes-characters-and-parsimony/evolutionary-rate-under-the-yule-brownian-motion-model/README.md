# Evolutionary rate under the Yule-Brownian-motion model

When a trait evolves by Brownian motion along a pure-birth (Yule) species tree observed with $n$ tips, the trait values are identically distributed but dependent through shared ancestry. Only the ratio of the Brownian variance to the speciation rate is identifiable from tip data, and a rescaled sample variance estimates it without bias, with a standard error decaying like $1/\log n$.
