# Hierarchical orthologous groups

A hierarchical orthologous group, for a chosen clade of species, is the set of present-day genes descended from one ancestral gene in the clade's last common ancestor. Nested clades give nested groups. On error-free data these groups can be read off the graph of pairwise orthology relations, without building gene trees.
