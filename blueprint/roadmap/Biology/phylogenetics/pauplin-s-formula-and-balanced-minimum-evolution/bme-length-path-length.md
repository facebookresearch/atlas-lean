# Pauplin's formula

For every [unrooted binary tree](../../../GraphTheory/graph-families-and-operations/tree-metrics-and-the-four-point-condition/utree.md) $T$ with real edge lengths,

$$\sum_{(x, y, \ell, \tau)} 2^{1 - \tau}\, \ell = L(T),$$

the sum over the [leaf pairs](../../../GraphTheory/graph-families-and-operations/tree-metrics-and-the-four-point-condition/pairs-2.md) of $T$, where $L(T)$ is the [total edge length](length-2.md) (Pauplin 2000).

## Sources

- Y. Pauplin, *Direct calculation of a tree length using a distance matrix*, J. Mol. Evol. 51 (2000), 41–47.
