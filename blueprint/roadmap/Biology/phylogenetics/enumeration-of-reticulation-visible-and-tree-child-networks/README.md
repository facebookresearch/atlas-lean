# Enumeration of reticulation-visible and tree-child networks

Exact and asymptotic counts of labeled binary phylogenetic networks with a fixed number of reticulations, comparing the tree-child class with the larger reticulation-visible class. The difference between the two counts is controlled by networks that violate the tree-child condition at a single vertex.
