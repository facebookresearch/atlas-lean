# Strict plurality of the induced resolutions

Let `X` be a finite set of taxa. Let `f q ρ` be real numbers, one for each set `q` of taxa and
family `ρ` of subsets, and let `S` be an
[unrooted binary phylogenetic tree](../../../Combinatorics/elementary-enumeration/counting-binary-phylogenetic-trees/unrooted-binary-tree.md)
on `X`. Then `f` is a strict plurality for `S` if for every four-taxon set `q` and all resolutions
`ρ`, `σ` of `q` such that `S` induces `ρ` but not `σ`, `f q σ < f q ρ`: on every four-taxon set the
resolution induced by `S` is strictly more frequent than each other resolution. No majority
`f q ρ > 1/2` is required.
