# The complement of an edge split is an edge split

Let `X` be a finite set of taxa. For every
[unrooted binary phylogenetic tree](../../../Combinatorics/elementary-enumeration/counting-binary-phylogenetic-trees/unrooted-binary-tree.md)
`T` on `X`, if `B` is an [edge split](../splits-compatibility-ultrametrics-and-upgma/edge-splits.md)
of `T`, then so is its complement `X \ B`.
