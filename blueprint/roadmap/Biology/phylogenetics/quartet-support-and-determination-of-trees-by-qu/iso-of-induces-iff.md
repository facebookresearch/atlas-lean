# An unrooted binary tree is determined by its induced quartet trees

Let `X` be a finite nonempty set of taxa. If two
[unrooted binary phylogenetic trees](../../../Combinatorics/elementary-enumeration/counting-binary-phylogenetic-trees/unrooted-binary-tree.md)
`T` and `S` on `X` induce the same resolutions on every four-taxon set, that is, for every
four-taxon set `q` and every resolution `ρ` of `q`, `T` induces `ρ` if and only if `S` does, then
`T` and `S` are
[isomorphic](../../../Combinatorics/elementary-enumeration/counting-binary-phylogenetic-trees/iso.md).
