# Every cluster seen from a leaf is an edge split

Let `X` be a finite set of taxa. For every
[unrooted binary phylogenetic tree](../../../Combinatorics/elementary-enumeration/counting-binary-phylogenetic-trees/unrooted-binary-tree.md)
`T` on `X` and every taxon `a`, every cluster in the
[cluster set](../../../Combinatorics/elementary-enumeration/counting-binary-phylogenetic-trees/cluster-set.md)
of `T` seen from `a` is an
[edge split](../splits-compatibility-ultrametrics-and-upgma/edge-splits.md) of `T`.
