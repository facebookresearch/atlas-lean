# Exactly one resolution of each four-taxon set is induced

Let `X` be a finite set of taxa. For every
[unrooted binary phylogenetic tree](../../../Combinatorics/elementary-enumeration/counting-binary-phylogenetic-trees/unrooted-binary-tree.md)
`T` on `X` and every four-taxon set `q ⊆ X`, a subset with exactly four elements, the
[resolutions](resolutions.md) of `q` that `T` [induces](induces.md) form a set with exactly one
element.
