# Non-transitive orientations of unrooted networks

Orienting an undirected graph so that it has a single source and a single sink and no transitive arc (an arc that is bypassed by a longer directed path) is computationally hard already for cubic graphs. Through a root gadget this transfers to the question whether an unrooted binary phylogenetic network can be rooted as a rooted binary network without shortcuts.
