# Classes of phylogenetic networks

Rooted binary phylogenetic networks generalize phylogenetic trees by allowing reticulation vertices (hybridization, introgression, lateral gene transfer). Restricting their shape gives classes with biological interpretations and better mathematical behavior: tree-child networks, in which every ancestor has a lineage descending without reticulation, and tree-based networks, which are a tree with added linking arcs. These articles state the definitions and the inclusions between the classes.
