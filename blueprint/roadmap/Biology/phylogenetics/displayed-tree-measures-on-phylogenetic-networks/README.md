# Displayed-tree measures on phylogenetic networks

A rooted phylogenetic network on a taxon set induces a set of displayed trees, a set of clusters and a set of tripartitions. Scores defined through these sets let one fit a network to sequence data by parsimony and compare two networks. These articles state the softwired parsimony score of a network and three dissimilarity measures between networks.

- [Softwired parsimony score of a phylogenetic network](softwired-parsimony-score-of-a-phylogenetic-network.md)
