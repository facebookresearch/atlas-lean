# Local search for Robinson–Foulds supertrees

A Robinson–Foulds (RF) supertree for a profile of rooted input trees on overlapping taxa is a binary tree on all taxa minimizing the summed RF distance to the inputs, each compared on its own leaf set. The problem is NP-hard, so it is attacked by hill climbing over subtree prune-and-regraft (SPR) and tree bisection-and-reconnection (TBR) neighbourhoods. LCA mappings make each neighbourhood search fast.
