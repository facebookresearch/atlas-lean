# Min-cut partitioning of phylogenetic trees

Clustering sequences by cutting edges of a (possibly non-ultrametric, unrooted) phylogeny: find the fewest clusters, each a connected component after removing edges, such that every cluster satisfies a heterogeneity constraint (diameter, total branch length, or single-linkage chaining). All three variants are solved exactly by greedy linear-time traversals.
