# Indels as missing data in maximum likelihood

Standard likelihood phylogenetics treats alignment gaps as missing data and scores the remaining characters under a substitution-only model. When the indel process can generate alignments whose non-gap characters carry no substitution signal, this treatment can make every tree equally likely, so maximum likelihood need not be statistically consistent even with the true alignment.
