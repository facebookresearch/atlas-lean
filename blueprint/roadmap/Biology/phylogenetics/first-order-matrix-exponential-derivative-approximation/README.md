# First-order matrix exponential derivative approximation

Gradient-based fitting of continuous-time Markov chain substitution and phylogeographic models needs the derivative of $e^{tQ}$ with respect to the rate matrix $Q$. The naive approximation $t e^{tQ} J$ has an explicit error that, after an affine-in-$t$ correction, decays exponentially in time, and for random rate matrices the error shrinks as the state space grows.
