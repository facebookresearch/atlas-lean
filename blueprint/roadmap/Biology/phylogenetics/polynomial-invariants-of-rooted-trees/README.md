# Polynomial invariants of rooted trees

A bivariate polynomial computed recursively from the leaves to the root can encode a rooted tree shape completely, so that two trees are isomorphic exactly when their polynomials agree. Weighting each edge variable by its branch length extends the encoding to phylogenetic trees with branch lengths, and the coefficients count principal subtrees.
