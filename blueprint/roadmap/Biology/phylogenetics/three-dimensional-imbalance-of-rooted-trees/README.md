# Three-dimensional imbalance of rooted trees

Classical tree balance indices (Colless, Sackin) see only topology. For plant architecture, modelled as a rooted tree embedded in $\mathbb{R}^3$ with weighted edges, imbalance at a node can be measured by how far the centroid of the subtree below it deviates from the direction of growth of its incoming edge. Integrating these node statistics along all edges gives imbalance indices that are invariant to rigid motions, scaling and edge subdivision, computable in linear time, and zero exactly for straight growth at every node.
