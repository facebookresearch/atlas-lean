# The Jukes–Cantor distance correction

For all real $\mu, t$ and every base $i$,

$$d_{JC}\bigl(p_{\mathrm{diff}}(i)\bigr) = \mu t,$$

where $d_{JC}$ is the [Jukes–Cantor distance](jc-distance.md) and $p_{\mathrm{diff}}$ the [difference probability](p-diff.md). For $\mu, t \ge 0$, $\mu t$ is the expected number of substitutions per site, which the distance recovers.
