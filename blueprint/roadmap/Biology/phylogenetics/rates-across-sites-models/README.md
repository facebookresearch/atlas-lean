# Rates-across-sites models

Phylogenetic substitution models in which every site evolves on the same tree but with its own random rate multiplier drawn from a common (possibly unknown, nonparametric) distribution. The central questions are when the tree topology remains identifiable from the leaf distribution and how many sites are needed to reconstruct it.
