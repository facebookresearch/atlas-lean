# Ranked subtree prune and regraft

Treespaces on ranked phylogenetic trees (rooted binary trees with a total order on internal nodes, the discrete shadow of time trees) in which a subtree is pruned and regrafted horizontally at the same rank, optionally together with rank swaps. These spaces are connected metric spaces with quadratic neighbourhoods but, unlike ranked NNI, lack the cluster property, and leaf addition can shrink distances sharply.
