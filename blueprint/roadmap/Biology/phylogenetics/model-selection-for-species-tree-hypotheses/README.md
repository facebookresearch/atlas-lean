# Model selection for species-tree hypotheses

Information criteria for comparing species-tree hypotheses whose parameter spaces have boundaries (star trees) and singularities (unions of competing topologies), as in rooted-triplet models under the multispecies coalescent. A generalized AIC replaces the dimension penalty by the expected covariance between data and fitted value, restoring asymptotic unbiasedness everywhere.
