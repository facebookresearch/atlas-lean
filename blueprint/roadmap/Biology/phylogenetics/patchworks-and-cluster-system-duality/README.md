# Patchworks and cluster-system duality

Set systems on taxa that relax hierarchies (the cluster systems of rooted trees) to accommodate non-tree-like signal from hybridization or lateral transfer. Patchworks are closed under unions and intersections of incompatible clusters; the compatibility adjoint is a Galois connection whose closed systems are exactly the saturated patchworks containing the trivial clusters.
