# Structured Markov genealogy processes

Every member of a broad class of Markov population models (compartmental, multi-deme, with births, deaths, migrations and sampling) induces a unique genealogy process. The likelihood of an observed genealogy is the solution of a filter equation whose structure is read off the population model, which contains the coalescent and the linear birth–death phylodynamic likelihoods as special cases.
