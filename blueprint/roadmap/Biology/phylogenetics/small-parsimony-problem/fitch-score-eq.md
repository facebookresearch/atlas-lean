# Fitch's algorithm computes the small-parsimony score

For a finite state set, observed states $\sigma$ and a tree $t$ with [unit costs](is-unit-cost.md), the count of [Fitch's algorithm](fitch.md) equals $\min_s \mathrm{Sk}(t, s)$, the minimum over root states of [Sankoff's cost](sankoff.md).

## Sources

- W. M. Fitch, *Toward defining the course of evolution: minimum change for a specific tree topology*, Syst. Zool. 20 (1971), 406–416.
- J. A. Hartigan, *Minimum mutation fits to a given tree*, Biometrics 29 (1973), 53–65.
