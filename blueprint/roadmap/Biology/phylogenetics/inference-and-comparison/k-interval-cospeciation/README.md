# k-interval cospeciation

A discrete distance between two phylogenies on associated leaf sets (host and parasite trees, gene trees for one species set): the largest discrepancy between corresponding leaf-to-leaf path lengths. It captures global congruence that survives many local incongruences, and its maximal-distance neighborhoods are combinatorially small.
