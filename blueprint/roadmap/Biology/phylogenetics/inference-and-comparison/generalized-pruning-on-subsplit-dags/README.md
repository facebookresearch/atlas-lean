# Generalized pruning on subsplit DAGs

A subsplit DAG encodes many rooted tree topologies at once, with a prior given by conditional subsplit probabilities on its edges. The Felsenstein pruning algorithm generalizes to it: partial likelihood vectors marginalized over all encoded topologies obey the same two-pass recursions, yielding per-edge marginal likelihoods for branch-length estimation.
