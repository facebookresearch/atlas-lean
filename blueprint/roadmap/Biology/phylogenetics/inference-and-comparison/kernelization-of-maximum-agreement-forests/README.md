# Kernelization of maximum agreement forests

A maximum agreement forest of a set of phylogenetic trees partitions the taxa into the fewest blocks whose induced subtrees are disjoint and identical across all trees; for two trees its size governs the TBR and rSPR distances. Reduction rules shrink an instance to a kernel whose size depends only on the number of blocks and the number of trees.
