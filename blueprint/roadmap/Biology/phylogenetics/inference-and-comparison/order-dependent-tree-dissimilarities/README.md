# Order-dependent tree dissimilarities

Dissimilarities between rooted binary phylogenetic trees computed from vector encodings (ordered leaf attachment, Phylo2Vec, HOP) that depend on an ordering of the leaves, and their relation to agreement-forest measures: the rooted subtree prune and regraft distance and hybridization numbers.
