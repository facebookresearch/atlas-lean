# Node-based and stem-based trees

Phylogenies can be drawn with taxa at vertices (node-based trees) or along edges (stem-based trees). Adding a new root and moving labels from vertices to their parent edges is a bijection between the two encodings, under which subtrees correspond to planted subtrees; monophyletic groups are therefore subtrees in one encoding and planted subtrees in the other.
