# Cycle-breaking approximation of the hybridization number

The hybridization number of two rooted trees equals the size of a maximum acyclic agreement forest minus one. An agreement forest that ignores acyclicity can be repaired by deleting a feedback vertex set of an auxiliary reachability graph, which turns any approximation for Maximum Agreement Forest and Directed Feedback Vertex Set into a constant-ratio approximation of the hybridization number.
