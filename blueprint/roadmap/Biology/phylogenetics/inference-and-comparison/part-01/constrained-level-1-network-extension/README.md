# Constrained level-1 network extension

Given a rooted binary species tree and a multiset of quartet trees (for example, all quartets induced by estimated gene trees), add reticulation edges to the tree so that the resulting level-1 phylogenetic network displays as many input quartets as possible. Because cycles of a level-1 network are vertex-disjoint and each satisfied quartet is credited to exactly one added edge, the problem is solved exactly by dynamic programming over the constraint tree in polynomial time.
