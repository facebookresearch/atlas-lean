# Split-incompatibility scores for majority-rule supertrees

Majority-rule supertree methods generalize the majority-rule consensus to input trees on overlapping taxon sets by comparing a candidate supertree with each input tree either after pruning the supertree (MR(-)) or after grafting missing taxa onto the input tree (MR(+) variants). For bifurcating trees, each of these distances reduces to a count of splits involved in at least one incompatibility, so supertree scores can be read off a split relationship matrix.
