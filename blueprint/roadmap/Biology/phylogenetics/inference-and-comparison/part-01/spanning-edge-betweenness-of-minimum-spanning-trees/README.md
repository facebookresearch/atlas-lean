# Spanning edge betweenness of minimum spanning trees

Minimum spanning trees of allelic-distance graphs are widely used to display relationships among bacterial isolates, but equal-weight edges make the MST non-unique. The fraction of MSTs containing each edge is computable exactly from determinants of contracted graph Laplacians.
