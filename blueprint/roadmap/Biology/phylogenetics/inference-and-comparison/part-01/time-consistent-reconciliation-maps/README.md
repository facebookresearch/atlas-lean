# Time-consistent reconciliation maps

Reconciliation of an event-labeled gene tree (speciation, duplication, horizontal transfer) with a species tree, and the question of whether the reconciliation can be dated so that no gene is transferred into the past. Time-consistency is characterized by acyclicity of auxiliary directed graphs, which gives a near-linear decision and construction algorithm.
