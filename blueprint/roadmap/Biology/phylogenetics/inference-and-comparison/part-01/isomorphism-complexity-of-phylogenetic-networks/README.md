# Isomorphism complexity of phylogenetic networks

How hard it is to decide whether two leaf-labelled phylogenetic networks are isomorphic, by network class. Any metric on a class that is computable in polynomial time and separates non-isomorphic networks (distance $0$ only for isomorphic networks) decides isomorphism in polynomial time, so isomorphism hardness rules out such metrics. For tree-sibling time-consistent networks, polynomial metrics exist under semibinarity, but without it isomorphism is as hard as general graph isomorphism.
