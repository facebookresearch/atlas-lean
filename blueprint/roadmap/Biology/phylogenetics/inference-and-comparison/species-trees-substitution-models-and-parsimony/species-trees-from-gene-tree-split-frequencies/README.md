# Species trees from gene-tree split frequencies

Unrooted STAR (USTAR) methods average graph-theoretic internode distances over unrooted gene trees and apply a distance-based tree builder. Under the multispecies coalescent the expected internode distance is a tree metric for the unrooted species tree, so these methods (including $\mathrm{NJ}_{st}$) are statistically consistent, and they depend on gene trees only through their split frequencies.
