# Likelihood ratio tests at species-tree model singularities

Testing species-tree hypotheses from rooted gene-tree topology counts under the multispecies coalescent leads to trinomial submodels whose null sets have boundaries and singular points, where the usual chi-squared approximation of the likelihood ratio statistic fails. Projecting a Gaussian onto the tangent cones of the null set at finite sample size gives explicit approximating distributions that are accurate near those points.
