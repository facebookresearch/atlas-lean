# Linear noise approximation in phylodynamics

Bayesian inference of stochastic SIR epidemic trajectories and time-varying transmission rates from a dated pathogen genealogy. A structured-coalescent likelihood ties coalescent times to the latent prevalence, and a linear noise approximation supplies tractable Gaussian transition densities for the latent Markov jump process in large populations.
