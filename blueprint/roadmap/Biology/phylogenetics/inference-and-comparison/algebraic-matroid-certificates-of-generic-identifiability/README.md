# Algebraic matroid certificates of generic identifiability

A sufficient criterion for generic identifiability of discrete parameters of algebraic phylogenetic models: a set of coordinates that is algebraically independent on one model but not on the other. The criterion is computable from Jacobians of the parametrizations and gives identifiability of tree parameters in 2-tree mixtures of group-based models and of large-cycle network models.
