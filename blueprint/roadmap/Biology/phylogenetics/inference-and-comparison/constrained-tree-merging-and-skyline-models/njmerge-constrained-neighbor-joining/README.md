# NJMerge: constrained neighbor joining

Neighbor joining run under constraint trees on pairwise disjoint leaf subsets, used to merge independently estimated subset trees into one tree. On a nearly additive distance matrix it returns the true tree whenever the constraints agree with it, which makes divide-and-conquer pipelines statistically consistent.
