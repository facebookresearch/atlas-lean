# Network-based Markov model of site patterns

Let $N'$ be a rooted binary tree-child phylogenetic network on a leaf set $X$ with $|X| = n$, root $\rho$ and reticulation vertices $v_1, \dots, v_r$, where $v_i$ has incoming reticulation edges $e_i^0, e_i^1$. Parameters are a root distribution $\pi \in \Delta^3$ on the states $\{A, G, C, T\}$, a $4 \times 4$ row-stochastic matrix $M^e$ on every edge $e = uv$ (with $M^e_{ij} = P(X_v = j \mid X_u = i)$), and reticulation parameters $\delta_i \in (0, 1)$. For $\sigma \in \{0,1\}^r$ let $T_\sigma$ be the rooted tree obtained by deleting $e_i^0$ when $\sigma_i = 1$ and $e_i^1$ when $\sigma_i = 0$. The probability of the site pattern $\omega \in \{A,G,C,T\}^n$ is

$$p_\omega = \sum_{\sigma \in \{0,1\}^r} \Bigl(\prod_{i=1}^r \delta_i^{\sigma_i} (1 - \delta_i)^{1 - \sigma_i}\Bigr) \sum_{\phi : \phi(X) = \omega} \pi_{\phi(\rho)} \prod_{e = uv \in \Sigma(T_\sigma)} M^e_{\phi(u), \phi(v)},$$

where $\phi$ ranges over assignments of states to the vertices of $T_\sigma$ that restrict to $\omega$ on the leaves (Eq. (1) of the source). The map from parameters to $(p_\omega)_\omega$ is polynomial, and its image is the model $\mathcal M_{N'}$.

Under the Jukes-Cantor, Kimura 2-parameter or Kimura 3-parameter constraints, which fix the uniform root distribution $\pi = (\tfrac14, \tfrac14, \tfrac14, \tfrac14)$ and restrict each $M^e$ to the corresponding symmetric group-based form, the model depends only on the semi-directed network of $N'$, obtained by undirecting all non-reticulation edges, suppressing degree-two vertices and identifying parallel edges: if $N_1'$ and $N_2'$ have the same semi-directed network then $\mathcal M_{N_1'} = \mathcal M_{N_2'}$ (Proposition 1).

## Expansion

Each $\sigma$ selects one parent edge per reticulation vertex, so a site evolves on the tree $T_\sigma$ with probability $\prod_i \delta_i^{\sigma_i}(1-\delta_i)^{1-\sigma_i}$; the inner sum is the usual tree-based marginalization over internal states. For Proposition 1: relocating the root of each displayed tree does not change a tree model under these group-based constraints, because each $M^e$ is symmetric and the root law is uniform, so $\pi_i M^e_{ij} = \pi_j M^e_{ji}$ (Section 2.3). The uniform root law is needed: for a symmetric $M^e$ with $M^e_{ij} > 0$ and a root law with $\pi_i \ne \pi_j$ this reversibility identity fails, so the general mixture formula above holds for every $\pi$, but Proposition 1 and the identifiability results built on it are stated for the constrained models with uniform $\pi$. Next, and two parallel reticulation edges with matrices $M^e, M^f$ can be replaced by one edge with matrix $\delta M^e + (1-\delta) M^f$, because each constraint class is closed under convex combinations (Section 2.3).
