# Uniformization stable Markov models

Continuous-time substitution models whose Markov matrices can be written as the identity plus a rate matrix of the same model, equivalently whose uniformized discrete chains stay in the model. For linear models this property is exactly the existence of a Jordan algebra structure, which covers time-reversible models and gives a classification of the permutation-symmetric cases.
