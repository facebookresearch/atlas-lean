# Total-evidence tip dating

Instead of turning fossils into calibration densities on interior nodes, total-evidence dating places fossils as dated tips alongside extant taxa and analyses morphological and molecular characters jointly under a relaxed clock. This requires a prior on clock trees whose tips have different ages, and a relaxed-clock model.
