# Average internode distance species trees

Summary methods that average the path distances between species over many gene trees and fit a tree to the averaged matrix (NJst, ASTRID and their weighted versions). Under the multispecies coalescent the averaged matrix converges to an additive matrix on the species tree, so any tree-building method with a positive safety radius is statistically consistent.
