# Event-based cophylogenetic reconciliation

Host and associate phylogenies (figs and their pollinating wasps, hosts and parasites) are compared by mapping the associate tree into the host tree with cospeciation, duplication, host-switch, loss and failure-to-diverge events, each with a cost, and testing whether the minimum total cost is lower than for randomized associations.
