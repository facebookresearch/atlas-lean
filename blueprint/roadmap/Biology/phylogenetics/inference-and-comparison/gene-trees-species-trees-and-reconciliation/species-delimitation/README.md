# Species delimitation

Species delimitation from genetic data partitions sampled sequences into putative species using a model of how branching events arise within and between species. Single-locus tree-based methods classify the branches of a gene tree into speciation and within-species (coalescent) processes, while multispecies-coalescent methods compare population-divergence models across many loci and can over-split structured populations; heuristic indices such as the genealogical divergence index summarize how distinct two populations are.
