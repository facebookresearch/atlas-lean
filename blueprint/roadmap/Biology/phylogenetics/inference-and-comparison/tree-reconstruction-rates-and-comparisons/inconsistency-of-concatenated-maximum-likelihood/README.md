# Inconsistency of concatenated maximum likelihood

Species-tree inference by maximum likelihood on concatenated multi-locus alignments, under gene-tree discordance generated by the multispecies coalescent. There are species trees for which concatenation converges to a wrong topology as the number of loci grows.
