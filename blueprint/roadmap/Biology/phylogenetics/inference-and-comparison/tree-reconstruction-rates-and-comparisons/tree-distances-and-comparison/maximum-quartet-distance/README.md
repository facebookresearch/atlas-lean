# Maximum quartet distance

How far apart two phylogenetic trees on the same taxa can be when distance counts four-taxon subsets with different induced topologies. The average over random pairs is two thirds of all quartets, and the Bandelt–Dress conjecture asserts the maximum is asymptotically the same; flag algebras give near-matching upper bounds.
