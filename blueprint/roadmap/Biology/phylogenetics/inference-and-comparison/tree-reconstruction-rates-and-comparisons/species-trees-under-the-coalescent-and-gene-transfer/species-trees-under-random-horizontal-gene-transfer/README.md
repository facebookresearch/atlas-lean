# Species trees under random horizontal gene transfer

A stochastic model in which each gene tree is obtained from the species phylogeny by a Poisson number of horizontal gene transfers, each an SPR move from a random recipient point to a uniformly chosen contemporaneous donor point. When the transfer rate per branch is a small enough constant, logarithmically many distorted ultrametric gene trees suffice to recover the species phylogeny; at a large constant rate, logarithmically many do not, so the bound is tight up to a constant.
