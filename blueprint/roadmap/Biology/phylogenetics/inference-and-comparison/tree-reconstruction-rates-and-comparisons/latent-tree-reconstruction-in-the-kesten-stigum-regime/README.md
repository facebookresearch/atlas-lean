# Latent tree reconstruction in the Kesten–Stigum regime

Reconstructing the topology and edge weights of a tree from independent samples of a Markov model on it, observed only at the leaves (phylogenies from aligned sequence sites, Gaussian latent tree models). Below the Kesten–Stigum threshold, where ancestral states can be estimated from leaves better than chance at any depth, a robust linear estimator of hidden states brings the sample requirement down to $O(\log^2 n)$.
