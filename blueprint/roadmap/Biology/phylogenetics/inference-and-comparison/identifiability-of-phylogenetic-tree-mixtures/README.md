# Identifiability of phylogenetic tree mixtures

A phylogenetic mixture model draws each site from one of several trees with their own Markov parameters. Identifiability asks whether the trees and the numerical parameters can be recovered, up to relabelling the mixture classes, from the mixed site-pattern distribution.
