# Calibrated tree priors

In Bayesian divergence-time estimation, fossil or biogeographic information enters as calibration densities on the ages of internal nodes, combined with a generative tree prior (Yule, birth–death or coalescent). Multiplying the calibration density into the tree prior does not make it the marginal prior of the calibrated age, and can distort the topology prior; the conditional construction divides by the tree prior's own marginal so that the calibration is reproduced exactly.
