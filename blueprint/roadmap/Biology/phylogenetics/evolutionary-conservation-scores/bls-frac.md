# Normalized branch length score

For a tree $T$ with edge lengths $w$ and a set $S$ of taxa, the normalized branch length score is $\mathrm{BLS}(S) / L(T, w)$, where $\mathrm{BLS}$ is the [branch length score](bls.md) and $L$ the [total branch length](total-length.md), with the convention $x/0 = 0$: the fraction of the total branch length that Kheradpour et al. (2007) report as the branch length score.

## Sources

- P. Kheradpour, A. Stark, S. Roy and M. Kellis, *Reliable prediction of regulator targets using 12 Drosophila genomes*, Genome Res. 17 (2007), 1919–1931.
