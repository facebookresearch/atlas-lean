# The SiPhy rate update

For a real matrix $n$, a real function $\tau$, a real matrix $R$ and real weights $\pi$, the rate update is

$$\hat\omega = \frac{N}{\sum_b e_b \pi_b},$$

where $N$ is the [total count](total-count.md) and $e$ the [exchange rates](exit-weight.md), with the convention $x/0 = 0$.
