# Branch length score is at most the tree length for nonnegative lengths

If the edge lengths are [nonnegative](nonneg-weights.md), then $\mathrm{BLS}(S) \le L(T, w)$ for every set $S$ of taxa, where $\mathrm{BLS}$ is the [branch length score](bls.md) and $L$ the [total branch length](total-length.md).
