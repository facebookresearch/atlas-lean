# Total branch length of a tree

For an [unrooted binary phylogenetic tree](../../../Combinatorics/elementary-enumeration/counting-binary-phylogenetic-trees/unrooted-binary-tree.md) $T$ with real edge lengths $w$, the total branch length is

$$L(T, w) = \frac12 \sum_{(p, v)} w(pv),$$

the sum running over the darts (oriented edges) $(p, v)$ of $T$, so that every edge is counted once in each direction.
