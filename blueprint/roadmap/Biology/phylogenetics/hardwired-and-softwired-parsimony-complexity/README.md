# Hardwired and softwired parsimony complexity

Maximum parsimony extends from trees to phylogenetic networks in two ways: the hardwired score counts state changes over every edge of the network, while the softwired score takes the best tree displayed by the network. Their computational complexity differs sharply: the hardwired score is a multiterminal cut problem, polynomial for binary characters, while the softwired score is hard to approximate even for binary characters on restricted networks but fixed-parameter tractable in the network level.
