# Transition parameter recovered from the proportions

For real transition and transversion proportions `P` and `Q`, the transition parameter is
`a(P, Q) = -(1/2) · log (1 - 2P - Q) + (1/4) · log (1 - 2Q)`. Its intended domain is the algebraic
domain `1 - 2P - Q > 0`, `1 - 2Q > 0`, where it is `≥ 0` exactly when moreover
`1 - 2P - Q ≤ √(1 - 2Q)`. It is defined for all real `P` and `Q`, with the conventions `log 0 = 0`
and `log x = log |x|` for `x < 0`: a logarithm whose argument is `0` contributes `0`, and a negative
argument `x` contributes `log |x|`.
