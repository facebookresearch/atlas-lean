# Transversion parameter recovered from the proportion

For a real transversion proportion `Q`, the transversion parameter is
`b(Q) = -(1/4) · log (1 - 2Q)`. Its intended domain is the algebraic domain `1 - 2Q > 0`, where it
is `≥ 0` exactly when moreover `Q ≥ 0`. It is defined for every real `Q`, with the conventions
`log 0 = 0` and `log x = log |x|` for `x < 0`: `b(1/2) = 0`, and `b(Q) = -(1/4) · log (2Q - 1)` for
`Q > 1/2`.
