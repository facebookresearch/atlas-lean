# Block-graph structure of minimal topological lassos

**Lassos.** Let $X$ be a finite set with $|X| \ge 3$ and $T$ a rooted phylogenetic $X$-tree (no degree-two vertices except possibly the root). A *cord* is a $2$-subset $ab$ of $X$; for a set $\mathcal L$ of cords covering $X$, let $\Gamma(\mathcal L)$ be the graph on $X$ with edge set $\mathcal L$. Two edge-weighted $X$-trees are $\mathcal L$-isometric if their induced leaf distances agree on all cords of $\mathcal L$. $\mathcal L$ is a **topological lasso** for $T$ if, whenever an equidistant proper edge-weighting of $T$ (a dendrogram) and one of another $X$-tree $T'$ are $\mathcal L$-isometric, $T$ and $T'$ are equivalent; it is **minimal** if no cord can be removed. So partial distance data on $\mathcal L$ already determine the dendrogram's topology.

For an interior vertex $v$, the *child-edge graph* $G(\mathcal L,v)$ has the child edges of $v$ as vertices, two being adjacent when some cord $ab \in \mathcal L$ has both on its path. $\mathcal L$ is a topological lasso for $T$ if and only if every $G(\mathcal L,v)$ is a clique.

**Theorem.** Let $\mathcal L$ be a minimal topological lasso for $T$.

1. For every interior vertex $v$ with $|ch(v)|$ children, exactly $\binom{|ch(v)|}{2}$ cords have $v$ as the last common ancestor of their endpoints: for any two child edges of $v$ exactly one cord joins leaves below them. In particular $\Gamma(\mathcal L)$ is connected.
2. If $\Gamma(\mathcal L)$ is a **block graph** (every 2-connected component is a clique), then for each interior vertex $v$ there is a unique block $B_v$ with $v = \mathrm{lca}_T(V(B_v))$; the map $v \mapsto B_v$ is a bijection between interior vertices of $T$ and blocks of $\Gamma(\mathcal L)$, and each block $B$ is isomorphic to the child-edge graph of $\mathrm{lca}_T(V(B))$.
3. If $T$ is non-degenerate, every minimal topological lasso can be transformed, through a sequence of minimal topological lassos processed vertex by vertex along an ordering of the interior vertices ending at the root, into a **distinguished** minimal topological lasso $\mathcal L^\dagger$, i.e. one for which $\Gamma(\mathcal L^\dagger)$ is a claw-free block graph.
4. Distinguished minimal topological lassos are exactly the lassos $\mathcal L_{(T,f)}$ generated by a total order $\sigma$ of $X$ and a *cluster marker map* $f$, which assigns to each cluster $A$ of $T$ the $\sigma$-minimal element of $A$ not already used to mark a smaller cluster of $T$ inside $A$.

## Expansion

Item 1 combines the clique criterion with minimality: one cord per pair of child edges is needed to make $G(\mathcal L,v)$ complete, and any extra cord at $v$ could be deleted. If $\Gamma(\mathcal L)$ is a block graph, the cords realizing the clique at $v$ pass through distinct leaves chosen once per child subtree (Proposition 4.1), so they form one block whose last common ancestor is $v$, which gives the bijection. Transforming a minimal lasso into a distinguished one rewires cords at each vertex so that every block becomes a clique on representatives without creating induced claws; cluster markers make the representative choice canonical.
