# Terminals and the nonbinary hybridization number

The hybridization number of two rooted, not necessarily binary, phylogenetic trees is the minimum number of reticulations in a network displaying refinements of both. Taxa that are maximal in a natural containment order on the clusters (terminals) are few, and some small set of them always contains a taxon whose deletion lowers the hybridization number, which gives a simple bounded-search algorithm.
