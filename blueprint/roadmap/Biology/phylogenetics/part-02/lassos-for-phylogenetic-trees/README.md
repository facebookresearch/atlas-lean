# Lassos for phylogenetic trees

A weighted phylogenetic tree is determined by all its leaf-to-leaf distances, but often a small set of leaf pairs suffices. A set of leaf pairs that pins down the edge weights, the topology, or both, from the corresponding distances is a lasso for the tree; triplet covers built from stable transversals of the tree's clusters are minimal lassos with a polynomial-time reconstruction.
