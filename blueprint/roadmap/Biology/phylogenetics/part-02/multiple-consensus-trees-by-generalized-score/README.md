# Multiple consensus trees by generalized score

Deciding whether a collection of gene trees on the same taxa is summarized by one consensus tree or by several, one per group of congruent genes. Each group is represented by its majority-rule consensus weighted by edge support, and a quadratic score over partitions of the gene trees decides between a single, a multiple and an atomic consensus.
