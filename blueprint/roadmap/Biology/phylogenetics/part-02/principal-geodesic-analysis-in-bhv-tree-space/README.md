# Principal geodesic analysis in BHV tree space

Principal component analysis for samples of phylogenetic trees carried out in the Billera–Holmes–Vogtmann space of unrooted metric trees, where straight lines are replaced by bi-infinite geodesics and orthogonal projection by closest-point projection, both well defined because the space is CAT(0).
