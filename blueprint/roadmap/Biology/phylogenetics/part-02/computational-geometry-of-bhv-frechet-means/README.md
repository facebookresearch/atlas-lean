# Computational geometry of BHV Fréchet means

The Fréchet mean and variance of a finite set of metric phylogenetic trees in the Billera–Holmes–Vogtmann (BHV) tree space. The combinatorial type of the geodesic from a fixed tree to a varying tree is constant on the cells of a polyhedral (vistal) subdivision of tree space; on each cell the variance has a fixed smooth algebraic formula, which yields convergent algorithms for the mean.
