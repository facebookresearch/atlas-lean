# Phylogenetic groves

Groves are collections of taxon sets (for instance, clusters of species with sequence data in a database) whose overlap pattern guarantees that a supertree built from trees on them can reveal relationships not displayed by any input tree. Their combinatorics decides whether maximal groves partition a database, which would make them easy to find.
