# Polyhedral covers of BHV tree space

Combinatorial structure of the link of the origin in Billera–Holmes–Vogtmann phylogenetic tree space: a simplicial complex of fully resolved trees with unit total interior length, covered by copies of the associahedron (one per cyclic leaf order) and the permutohedron (caterpillars), from which its homotopy type follows.
