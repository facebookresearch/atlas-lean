# LGT networks and secondary subtrees

An LGT network is a rooted phylogenetic network split into a principal tree, describing the main line of descent, and secondary arcs modelling lateral gene transfers. Each secondary arc yields a secondary subtree, the tree followed by the transferred genes. Under mild restrictions, the principal subtree and the secondary subtrees determine the network uniquely and can be checked and reconstructed in polynomial time.
