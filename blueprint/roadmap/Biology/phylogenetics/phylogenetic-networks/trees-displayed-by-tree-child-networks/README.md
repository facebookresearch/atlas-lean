# Trees displayed by tree-child networks

A binary tree-child network with $n$ leaves has at most $n-1$ reticulations, so it has at most $2^{n-1}$ embeddings of displayed trees. The number of distinct displayed trees is one less, and the extremal networks display exactly one tree twice.
