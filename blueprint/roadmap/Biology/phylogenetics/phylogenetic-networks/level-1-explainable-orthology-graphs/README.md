# Level-1 explainable orthology graphs

An estimated orthology graph is explained by a gene tree with speciation and duplication labels only if it is a cograph. Allowing the explaining structure to be a $0/1$-labeled level-1 phylogenetic network, where two genes are orthologs when their unique lowest common ancestor carries label $1$, enlarges the explainable class to graphs whose primitive pieces are near-cographs, a hereditary class of perfect graphs recognizable in linear time.
