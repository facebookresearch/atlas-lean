# The row marginal of the pair-site law is the base-frequency vector

Let `ι` be a finite set of states. If `(π, s)` lies in the [GTR parameter domain](is-gtrparam.md),
then for every real branch length `t` and every state `i` the [pair-site law](gtr-pair-law.md)
`F(π, s, t) i j = π i · exp (t · Q(π, s)) i j` satisfies `∑_j F(π, s, t) i j = π i`, where `Q(π, s)`
is the [GTR rate matrix](../time-reversible-nucleotide-substitution-models/gtr-rate.md).
