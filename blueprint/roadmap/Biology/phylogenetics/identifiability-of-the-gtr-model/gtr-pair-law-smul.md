# Rate and time are confounded in the pair-site law

Let `ι` be a finite set of states. For all real `π`, `s`, `c` and `t`, the parameters
`(π, c · s, t)` and `(π, s, c · t)` have the same [pair-site law](gtr-pair-law.md):
`F(π, c · s, t) = F(π, s, c · t)`, where `F(π, s, t) i j = π i · exp (t · Q(π, s)) i j` and
`Q(π, s)` is the [GTR rate matrix](../time-reversible-nucleotide-substitution-models/gtr-rate.md).
