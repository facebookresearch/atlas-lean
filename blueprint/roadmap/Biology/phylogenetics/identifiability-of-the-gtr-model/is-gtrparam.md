# GTR parameter domain

Let `ι` be a finite set of states. Base frequencies `π : ι → ℝ` and exchangeabilities `s` (a real
`ι × ι` matrix) lie in the GTR parameter domain if the base frequencies form a strictly positive
probability vector, `π i > 0` for every `i` and `∑_i π i = 1`, and the exchangeabilities are
symmetric, `s i j = s j i`, with `s i j > 0` for `i ≠ j`. The diagonal of `s` is unconstrained: the
[GTR rate matrix](../time-reversible-nucleotide-substitution-models/gtr-rate.md) does not use it.
