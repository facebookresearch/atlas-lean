# The K80 rate matrix determines the transition/transversion ratio

The [K80 rate matrix](../time-reversible-nucleotide-substitution-models/k80-rate.md) with
transition/transversion ratio `κ`, which has rate `κ / 4` for a transition and `1 / 4` for each
transversion, determines `κ`: equal K80 rate matrices for real `κ` and `κ'` force `κ = κ'`.
