# Relabeling equivariance of the GTR rate matrix

Let `ι` be a finite set of states. For all real base frequencies `π`, exchangeabilities `s` and
every permutation `σ` of the states, relabeling the parameters as `(π ∘ σ) i = π (σ i)` and
`s_σ i j = s (σ i) (σ j)` relabels the
[GTR rate matrix](../time-reversible-nucleotide-substitution-models/gtr-rate.md):
`Q(π ∘ σ, s_σ) i j = Q(π, s) (σ i) (σ j)` for all states `i`, `j`.
