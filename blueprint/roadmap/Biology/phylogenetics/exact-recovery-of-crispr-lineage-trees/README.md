# Exact recovery of CRISPR lineage trees

Sample-complexity guarantees for reconstructing a single-cell lineage tree from CRISPR–Cas9 recording sites, which mutate irreversibly at a constant rate into one of many indel states, with possible homoplasy and missing data. Thresholding differences of shared-mutation counts yields a partial triplet oracle, and a logarithmic number of sites in the number of cells suffices for exact recovery.
