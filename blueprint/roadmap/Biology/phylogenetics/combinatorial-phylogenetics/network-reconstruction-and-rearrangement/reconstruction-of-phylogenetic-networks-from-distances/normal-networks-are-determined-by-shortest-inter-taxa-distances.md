# Normal networks are determined by shortest inter-taxa distances

A phylogenetic network $\mathcal{N}$ on a leaf set $X$ is a rooted acyclic directed graph with no parallel edges whose unique root has out-degree two, whose vertices of out-degree zero have in-degree one and form $X$, and whose other vertices are tree vertices (in-degree one, out-degree two) or reticulations (in-degree two, out-degree one); edges into reticulations are reticulation edges, all others tree edges, and $x\in X$ is an outgroup if its parent is the root. A *weighting* $w$ assigns every edge a non-negative real weight, with every tree edge strictly positive; let $(\mathcal{N}, w)$ be such a weighted network. An *up-down path* between leaves $x$ and $y$ climbs from $x$ to a vertex and then descends to $y$. The *minimum distance matrix* $\mathcal{D}_{\min}$ has $(x,y)$-entry $d_{\min}(x,y)$, the minimum length of an up-down path joining $x$ and $y$. A weighting is *equidistant* if all root-to-leaf paths have the same length, and a *reticulation-pair weighting* if the two edges into each reticulation have equal weight. A network is *normal* if it is tree-child (every non-leaf vertex has a non-reticulation child) and has no shortcuts. *Re-weighting the edges at a reticulation* $u$ with parents $p_u,q_u$ and child $v$ changes the weights of $(p_u,u)$, $(q_u,u)$, $(u,v)$ while keeping $w(p_u,u)+w(u,v)$ and $w(q_u,u)+w(u,v)$; if $\mathcal N$ has an outgroup $r$ and $u$ is the other child of the root $\rho$, *re-weighting the edges at the root* changes $w(\rho,r)$ and $w(\rho,u)$ while keeping their sum. Two weighted networks $(\mathcal N,w)$ and $(\mathcal N_1,w_1)$ are *equivalent* if $\mathcal N\cong\mathcal N_1$ and $w_1$ is obtained from $w$ by re-weighting the edges at each reticulation and re-weighting the edges at the root.

**Theorem.**

1. If $(\mathcal{N}, w)$ is an equidistant-weighted normal network on $X$, it is, up to equivalence, the unique such network realizing $\mathcal{D}_{\min}$, and a member of its equivalence class can be computed from $\mathcal{D}_{\min}$ in $O(|X|^3)$ time.
2. If $(\mathcal{N}, w)$ is a reticulation-pair weighted normal network on $X \cup \{r\}$ with outgroup $r$, it is, up to equivalence, the unique such network realizing $\mathcal{D}_{\min}$ on $X$ together with the maximum distance outgroup vector (for each $x$, the maximum length of an up-down path from $x$ to $r$), and a representative can be computed in $O(|X|^3)$ time.

Both statements extend to temporal tree-child networks, which have no shortcuts, but not to general tree-child networks, where shortest distances cannot detect shortcuts.

## Expansion

The algorithm repeatedly takes a pair $\{s,t\}$ minimizing $d_{\min}$. In an equidistant normal network such a pair is a cherry or a reticulated cherry, and which case holds, and which leaf is the reticulation leaf, is read off from the distances to the other taxa ($d_{\min}(s,x) = d_{\min}(t,x)$ for all other $x$ signals a cherry). Reducing the cherry or cutting the reticulated cherry gives a smaller normal network whose minimum distance matrix is computed from the current one, so induction reconstructs the network. Earlier results needed the full set or multiset of all up-down path lengths, of which there can be exponentially many; the theorem shows that only the shortest ones are needed for normal networks.
