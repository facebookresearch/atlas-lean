# Identifiability of tree-child networks under the recombination–mutation model

**Setting.** Let $N$ be a rooted binary phylogenetic network on $X$ with root $\rho$ and $r(N)$ reticulations (in-degree-two vertices). Deleting one of the two incoming arcs at every reticulation gives a rooted tree $T_R$, one for each of the $2^{r(N)}$ choices $R$. Forgetting directions, the **embedded spanning trees** $S(N)$ are these trees up to isomorphisms fixing $X$; thus $1 \le |S(N)| \le 2^{r(N)}$. An **$X$-tree** is an unrooted tree with leaf set exactly $X$ whose internal vertices have degree $2$ or $3$. $N$ is **tree-child** if every non-leaf vertex has a child that is a tree vertex or a leaf.

*Tree model $M(\mu)$.* Characters take values in a finite alphabet $\Sigma$. The root state is uniform on $\Sigma$, and along each arc the state changes to each specific other letter with probability $\mu$, so it changes with probability $(|\Sigma|-1)\mu$. An alignment of length $L$ is an element of $\Sigma^{XL}$.

*Network model $RM(\mu,p)$.* For a network with $\omega$ reticulations such that every tree of $S(N)$ is an $X$-tree and $|S(N)| = 2^\omega$, run a Markov chain on the trees $T_R$: start with a uniformly random parent at each reticulation and, between consecutive sites, switch the parent of each reticulation independently with probability $p$ (recombination). Each site evolves under $M(\mu)$ on the current tree. The stationary probability of each tree is $2^{-\omega}$. Write $D(\Sigma^{XL} \mid N, RM(\mu,p))$ for the induced distribution on alignments.

**Theorem (embedded trees of tree-child networks).** If $N$ is tree-child, then $|S(N)| = 2^{r(N)}$, and for tree-child networks $N, N'$ on $X$, $S(N) = S(N')$ if and only if $N$ and $N'$ are isomorphic. Every element of $S(N)$ is an $X$-tree if and only if no arc joins the root to a reticulation.

**Theorem (identifiability).** Let $N, N'$ be networks on $X$, both with $\omega$ reticulations, such that all trees in $S(N)$ and $S(N')$ are $X$-trees and $|S(N)| = |S(N')| = 2^\omega$, and let $\mu \in (0, 1/|\Sigma|)$. For each $T \in S(N)$ there are $L = L(T) \ge 1$ and $p = p(T) \in (0,1)$ such that equality of the alignment distributions $D(\Sigma^{XL} \mid N, RM(\mu,p)) = D(\Sigma^{XL} \mid N', RM(\mu,p))$ implies $T \in S(N')$. Consequently there exist $L$ and $p$ for which equal distributions force $S(N) = S(N')$, and the class of tree-child networks on $X$ with a fixed number of reticulations and no arc from the root to a reticulation is identifiable under $RM(\mu,p)$.

## Expansion

Tree-child networks have a cherry or a reticulated cherry, and reducing one keeps the network tree-child; induction on this reduction shows that the $2^{r(N)}$ arc choices give pairwise non-isomorphic spanning trees and that the set of spanning trees determines the network. For identifiability, on a single tree a long alignment under $M(\mu)$ with $\mu < 1/|\Sigma|$ has empirical character frequencies concentrated near the tree's predicted frequency vector, and distinct $X$-trees predict distinct vectors; so for each tree $T$ there is a length $L$ and a set $\mathcal{A}_T$ of alignments that is likely under $T$ and unlikely under every other tree in the finite candidate set. With a small switching probability $p$, a window of $L$ consecutive sites is generated by a single embedded tree with probability close to one, so the network distribution assigns $\mathcal{A}_T$ mass bounded below exactly when $T$ is embedded. Comparing these masses recovers $S(N)$, and the tree-child uniqueness theorem then recovers $N$.
