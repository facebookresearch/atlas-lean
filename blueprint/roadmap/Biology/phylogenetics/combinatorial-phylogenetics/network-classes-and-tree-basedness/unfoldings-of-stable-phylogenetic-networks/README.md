# Unfoldings of stable phylogenetic networks

Stable phylogenetic networks are those recovered by folding up their own un-fold, a multi-labelled tree. Choosing one leaf copy per taxon in the un-fold gives a combinatorial handle on which trees a stable network displays, which trees are base trees, and when it is tree-child or reticulation-visible.
