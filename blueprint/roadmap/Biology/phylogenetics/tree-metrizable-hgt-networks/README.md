# Tree-metrizable HGT networks

Horizontal gene transfer (HGT) networks whose average inter-taxon distance, for suitable arc lengths and reticulation probabilities, is a tree metric. Such networks are invisible to distance-based tree reconstruction, and they can carry arbitrarily many non-trivial reticulations.
