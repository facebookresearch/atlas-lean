# Ultrametrics are dated tree metrics

On a nonempty finite set of taxa, a real function $d$ on pairs is an [ultrametric](is-ultrametric.md) if and only if it is the [metric of a dated rooted tree](is-dated-tree-metric.md) (Semple & Steel 2003).

## Sources

- C. Semple and M. Steel, *Phylogenetics*, Oxford University Press (2003).
