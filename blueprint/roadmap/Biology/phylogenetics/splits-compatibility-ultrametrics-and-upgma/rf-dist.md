# Robinson–Foulds distance

For [unrooted binary phylogenetic trees](../../../Combinatorics/elementary-enumeration/counting-binary-phylogenetic-trees/unrooted-binary-tree.md) $T, T'$ on a finite set $X$ and a taxon $a$, the Robinson–Foulds distance is

$$d_{RF}(T, T') = |\mathcal{C}_a(T) \,\triangle\, \mathcal{C}_a(T')|,$$

the number of clusters seen from $a$ ([cluster sets](../../../Combinatorics/elementary-enumeration/counting-binary-phylogenetic-trees/cluster-set.md)) belonging to exactly one of the two trees: each split is counted once, by its side away from $a$.
