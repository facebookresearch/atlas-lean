# Bootstrap support above one half means a majority split

For every estimator $\mathrm{est}$, taxon $a$, alignment $M$ and set $A$, the [bootstrap support](bootstrap-support.md) of $A$ exceeds $\frac12$ if and only if $A$ is a [majority split](majority-splits.md) of the family $(\mathrm{est}(M \circ w))_w$ of bootstrap replicate trees.
