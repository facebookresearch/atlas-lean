# Split set of a tree computed from a leaf

For an [unrooted binary phylogenetic tree](../counting-binary-phylogenetic-trees/unrooted-binary-tree.md) $T$ on a finite set $X$ and a taxon $a$, the split set from $a$ is $\mathcal{C}_a \cup \{X \setminus C : C \in \mathcal{C}_a\}$, where $\mathcal{C}_a$ is the [cluster set](../counting-binary-phylogenetic-trees/cluster-set.md) of $T$ seen from $a$.
