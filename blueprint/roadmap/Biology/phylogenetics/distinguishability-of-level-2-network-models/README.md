# Distinguishability of level-2 network models

Two phylogenetic network models are distinguishable when the intersection of their algebraic varieties is a proper subvariety of each, which implies generic identifiability of the network parameter. For level-2 networks the discrete Fourier transform yields phylogenetic invariants under group-based models on the class of nice networks.
