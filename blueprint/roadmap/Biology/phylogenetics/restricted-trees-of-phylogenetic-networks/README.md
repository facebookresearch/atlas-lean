# Restricted trees of phylogenetic networks

A rooted acyclic phylogenetic network can be collapsed onto a tree by merging bottleneck regions of vertices: sets entered from at most one outside vertex. These restricted sets are closed under overlapping unions, every vertex lies in a smallest one, and merging overlapping smallest restricted sets gives a quotient network, the restricted tree, through which every restricted connected surjective digraph map factors.
