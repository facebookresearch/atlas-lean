# Monophyletic characters

Counting the characters (leaf colourings) on a phylogenetic tree for which some clade carries exactly one trait. An inclusion-exclusion over antichains of vertices gives a general formula, with closed forms for caterpillars, fully balanced trees and binary characters, and expected counts under the uniform and Yule models.
