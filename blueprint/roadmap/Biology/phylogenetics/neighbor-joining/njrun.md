# Runs of neighbor joining

For a real dissimilarity $d$ on a finite set $X$, the runs of neighbor joining are the triples $(S, D, C)$ (a set $S$ of clusters, a cluster dissimilarity $D$, and the set $C$ of clusters formed so far) generated by:

- the start: $S$ is the set of singletons $\{x\}$, $D$ the [initial dissimilarity](initial-dist.md) of $d$, and $C = \emptyset$;
- a join: from a run $(S, D, C)$ with $|S| \ge 4$ and distinct $a, b \in S$ such that $Q(a, b) \le Q(a', b')$ for all distinct $a', b' \in S$ (the [Q-criterion](q-criterion.md) on $S$ for $D$), pass to $\bigl((S \setminus \{a, b\}) \cup \{a \cup b\},\ D',\ C \cup \{a \cup b\}\bigr)$, where $D'$ is the [dissimilarity after joining](join-dist.md) $a$ and $b$.

Ties may be broken arbitrarily.
