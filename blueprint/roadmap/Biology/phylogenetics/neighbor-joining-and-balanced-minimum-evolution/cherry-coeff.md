# Generalized Pauplin coefficient of a cherry tree

For a finite set $S$ of clusters, clusters $a, b$ and clusters $u, v$, put

$$c_{ab}(u, v) = \begin{cases} \frac12 & \{u, v\} = \{a, b\} \text{ with } (u, v) = (a, b) \text{ or } (b, a),\\[2pt] \frac{1}{2(|S| - 2)} & \text{otherwise, if one of } u, v \text{ is } a \text{ or } b,\\[2pt] \frac{1}{|S| - 2} & \text{otherwise,}\end{cases}$$

with the convention $x/0 = 0$. These are the coefficients of the tree $T_{ab}$ obtained from the star on $S$ by joining $a$ and $b$ under a new vertex; values with $u = v$ are not used.
