# Polynomial-time quartet species-tree dynamic programming

Summary methods estimate a species tree from many gene trees by maximizing the number of induced quartet topologies shared with the gene trees, a problem consistent under the multispecies coalescent but NP-hard in general. Restricting the species tree to bipartitions from a constraint set $X$ gives an exact dynamic program over tripartitions. The articles here bound the cost of scoring a tripartition against multifurcating gene-tree nodes and the total running time when $|X|$ grows linearly.
