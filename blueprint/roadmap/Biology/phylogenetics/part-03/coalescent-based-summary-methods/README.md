# Coalescent-based summary methods

Summary methods estimate a species tree by combining estimated gene trees, relying on the multispecies coalescent to relate gene-tree frequencies to the species tree. Their statistical guarantees depend on how gene trees are pre-processed, how quartet frequencies are converted into distances, and whether the data really arose from a tree.
