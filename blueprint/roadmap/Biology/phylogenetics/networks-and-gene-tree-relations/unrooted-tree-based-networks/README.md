# Unrooted tree-based networks

An unrooted phylogenetic network on a taxon set $X$ is tree-based when it has a spanning tree whose leaves are exactly $X$, so that it can be read as a tree with extra edges added between tree edges. Unlike the rooted case, recognising such networks is NP-complete, but low-level networks are always tree-based and the networks in which every embedded tree is a support tree are exactly the level-1 networks.
