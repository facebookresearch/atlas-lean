# Reciprocal best matches and orthology

Reciprocal best matches between genes of different species are the standard proxy for orthology. Under duplication/loss scenarios reconciled with a species tree, every pair of orthologs is a reciprocal best match, so reciprocal best match graphs never produce false negatives; the false positives are characterized exactly by a class of duplication events with complementary gene losses.
