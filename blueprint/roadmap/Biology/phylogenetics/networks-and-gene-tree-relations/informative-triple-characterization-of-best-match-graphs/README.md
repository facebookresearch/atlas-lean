# Informative-triple characterization of best match graphs

A coloured digraph is a best match graph exactly when the tree that BUILD produces from its informative triples explains it again. That tree is then the unique least resolved explanation. The two-colour reduction needs an extra equality check and a sink-free hypothesis.
