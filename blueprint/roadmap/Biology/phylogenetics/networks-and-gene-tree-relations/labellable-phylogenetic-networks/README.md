# Labellable phylogenetic networks

The Erdős–Székely labelling of internal tree vertices extends to exactly those rooted networks in which no two vertices have the same set of children. Labellable networks correspond bijectively to expanding covers of finite sets. They contain the orchard and tree-sibling classes but are not nested with tree-based networks.
