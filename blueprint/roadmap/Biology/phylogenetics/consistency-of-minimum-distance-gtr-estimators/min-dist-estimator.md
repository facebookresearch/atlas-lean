# Chosen minimum-distance estimator

Let `Θ` be a nonempty compact metric space, `σ` a finite set and `law : Θ → (σ → ℝ)` continuous. For
frequency estimates `freq n ω : σ → ℝ`, the chosen estimate `est n ω` is a point of `Θ` that
minimizes the continuous function `θ ↦ d(law θ, freq n ω)`, where `d` is the sup distance on
`σ → ℝ`. A minimizer exists by the extreme value theorem; the estimate is one fixed choice among the
minimizers.
