# Empirical frequencies of measurable columns are measurable

Let `σ` be a set of site patterns with a σ-algebra in which every singleton is measurable. If every
column `X i : Ω → σ` is measurable, then for every `n` the
[empirical site-pattern frequencies](empirical-freq.md) `ω ↦ p̂ₙ(ω)` form a measurable map from `Ω`
to `σ → ℝ`, with the product σ-algebra on `σ → ℝ`.
