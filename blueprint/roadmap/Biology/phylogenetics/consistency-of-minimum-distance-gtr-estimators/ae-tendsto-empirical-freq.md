# Strong law for pairwise independent columns with a common law

Let `σ` be a finite set of site patterns, every subset of which is measurable. Let `P` be a finite
measure on `Ω` and let the columns `X 0, X 1, …` be measurable maps `Ω → σ` that are pairwise
independent and identically distributed under `P`, with `P (X 0 = a) = q a` for every pattern `a`.
Then for `P`-almost every `ω` the [empirical site-pattern frequencies](empirical-freq.md) `p̂ₙ(ω)`
of the first `n` columns converge to `q` as `n → ∞`, at every pattern (the strong law of large
numbers, applied to each pattern indicator). Pairwise independence forces the total mass of `P` to
be `0` or `1`, so `P` is a probability measure unless it is zero.
