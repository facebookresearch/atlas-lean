# F81 rate matrix

For real base frequencies $\pi$ on the four nucleotides, the F81 rate matrix is the [GTR matrix](gtr-rate.md) with all exchangeabilities $1$: rate $\pi_j$ to every other base $j$ (Felsenstein 1981).

## Sources

- J. Felsenstein, *Evolutionary trees from DNA sequences: a maximum likelihood approach*, J. Mol. Evol. 17 (1981), 368–376.
