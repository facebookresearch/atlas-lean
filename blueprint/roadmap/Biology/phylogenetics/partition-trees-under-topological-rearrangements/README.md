# Partition trees under topological rearrangements

In phylogenomic analyses with partitions that cover different taxon subsets, each partition is evaluated on the species tree restricted to its taxa (the partition tree). A rearrangement of the species tree changes a partition tree only when the partition samples every subtree involved in the move, which lets tree searches skip unaffected partitions.
