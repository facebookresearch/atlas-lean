# Ordered leaf attachment vectors

Integer-vector encodings of rooted binary phylogenetic trees that record, for a fixed leaf order, where each successive leaf is attached; their Hamming-type distances, and the exact link between an optimally ordered corrected distance and maximum acyclic agreement forests (reticulation number), including multifurcated input trees.
