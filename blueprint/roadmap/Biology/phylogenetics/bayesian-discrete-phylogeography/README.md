# Bayesian discrete phylogeography

Treating the sampling location of a taxon as a discrete character evolving along a time-measured phylogeny turns the reconstruction of spatial spread into ancestral state reconstruction under a continuous-time Markov chain, estimated jointly with the tree from sequence data. Because a location character provides a single site of data for many possible location pairs, the rate matrix is far too rich for the data, and a sparsity prior on the migration graph, with a Bayes factor read off the posterior inclusion probabilities, is what makes the inference and the hypothesis tests meaningful.
