# Root-placement robustness of phylogenetic networks

Reconstruction methods often return an unrooted phylogenetic network, and the root is placed afterwards on some edge. A network is robust to root placement if every root position yields a valid rooted phylogenetic network, and robustly in a class if every such rooting lands in that class. Sink components characterize robust orientability, and only level-1 networks are robustly tree-child.
