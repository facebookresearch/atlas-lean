# Nonnegativity of labeling weights

If $\mathrm{obs}(l, s) \ge 0$ for all $l, s$ and the tree $t$ has [nonnegative weights](nonneg-weights.md), then every [labeling](../felsenstein-s-pruning-algorithm/labeling.md) of $t$ has nonnegative [weight](../felsenstein-s-pruning-algorithm/weight.md) for every root state.
