# The max-product value bounds the weight of every labeling

If $\mathrm{obs}(l, s) \ge 0$ for all $l, s$ and the tree $t$ has [nonnegative weights](nonneg-weights.md), then $W(t, s, z) \le M(t, s)$ for every state $s$ and every [labeling](../felsenstein-s-pruning-algorithm/labeling.md) $z$, where $W$ is the [weight](../felsenstein-s-pruning-algorithm/weight.md) and $M$ the [max-product recursion](max-prune.md).
