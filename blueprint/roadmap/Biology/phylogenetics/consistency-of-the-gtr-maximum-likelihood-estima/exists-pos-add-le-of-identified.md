# Separation outside an upper level set on a compact space

Let `Θ` be a compact metric space, `M : Θ → ℝ` continuous, `θ₀ ∈ Θ`, and `E ⊆ Θ` a set containing
the upper level set `{θ : M θ ≥ M θ₀}`. For every `ε > 0` there is `δ > 0` such that
`M θ ≤ M θ₀ - δ` for every `θ` at distance at least `ε` from `E`, that is, with
`inf_{θ' ∈ E} d(θ, θ') ≥ ε`. The value `M θ₀` need not be the maximum of `M`.
