# Identified class of the GTR pair-site model

Let `π`, `s` and `t` give each parameter `θ` base frequencies `π θ`, exchangeabilities `s θ` and a
branch length `t θ` on a set `ι` of states. The identified class of `θ₀` is the set of parameters
`θ` with the same base frequencies, `π θ = π θ₀`, and the same off-diagonal products
`t θ · s θ i j = t θ₀ · s θ₀ i j` for all states `i ≠ j`. It allows the two symmetries of a single
branch: rescaling the rates against the branch length, and changing the diagonal of `s`, which the
rate matrix does not use. When `ι` is finite, on the
[GTR parameter domain](../gtr-identifiability-and-estimation/identifiability-of-the-gtr-model/is-gtrparam.md) with positive branch
lengths, it is the set of parameters with the [same pair-site law](gtr-law-eq-iff-mem-gtr-class.md)
as `θ₀`.
