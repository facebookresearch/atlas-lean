# The log-likelihood criterion is continuous for a positive model

Let `Θ` be a topological space, `σ` a finite set and `law : Θ → (σ → ℝ)` continuous with
`law θ a > 0` for all `θ` and `a`. For every `f : σ → ℝ` the [log-likelihood criterion](log-lik.md)
`θ ↦ ∑_a f a · log (law θ a)` is continuous on `Θ`.
