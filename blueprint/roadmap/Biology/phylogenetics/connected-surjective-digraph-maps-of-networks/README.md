# Connected surjective digraph maps of networks

Homomorphisms between rooted phylogenetic networks on a common taxon set that collapse arcs or map them to arcs, are surjective, and have connected fibers. Such maps are exactly sequences of arc contractions, compose well, and allow the image network to be lifted back as an undirected subgraph of the source, so that displayed quartets and rooted triples are inherited; collapsing arcs with equal clusters gives a canonical cluster-distinct quotient.
