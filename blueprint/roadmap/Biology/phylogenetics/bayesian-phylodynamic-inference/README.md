# Bayesian phylodynamic inference

Model components of Bayesian phylodynamic software that infers time-scaled phylogenies jointly with trait evolution: covariate-driven continuous-time Markov models of discrete traits such as location, conditional expectations of trait-change counts along branches, and marginal likelihood estimators used for Bayes-factor model comparison.
