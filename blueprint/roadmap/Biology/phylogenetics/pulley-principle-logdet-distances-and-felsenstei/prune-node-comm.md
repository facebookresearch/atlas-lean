# Partial likelihoods are invariant under swapping subtrees

For all real leaf weights, weight functions $P, Q$ and [trees](../felsenstein-s-pruning-algorithm/tree.md) $l, r$ over a finite state set, the [pruning recursion](../felsenstein-s-pruning-algorithm/prune.md) gives the same partial likelihoods for the node with children $(l, r)$ on edges $(P, Q)$ as for the node with children $(r, l)$ on edges $(Q, P)$.
