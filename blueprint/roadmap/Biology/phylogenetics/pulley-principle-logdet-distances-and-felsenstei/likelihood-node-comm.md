# Likelihood is invariant under swapping root subtrees

For all real leaf weights, weight functions $P, Q$, trees $l, r$ and root distributions $\pi$, the [site likelihood](../felsenstein-s-pruning-algorithm/likelihood.md) of the node with children $(l, r)$ on edges $(P, Q)$ equals that of the node with children $(r, l)$ on edges $(Q, P)$.
