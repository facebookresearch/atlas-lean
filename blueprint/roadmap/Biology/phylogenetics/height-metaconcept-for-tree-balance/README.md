# Height metaconcept for tree balance

Tree (im)balance indices built by summing a function of the heights of all pending subtrees rooted at inner vertices. The construction yields imbalance indices for strictly increasing functions, has the greedy-from-the-bottom tree as a universal minimizer, and settles the extremal trees of the classical $B_1$ index.
