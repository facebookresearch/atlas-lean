# Pattern occurrences in random phylogenetic trees

Asymptotic probability that a large random phylogenetic tree or network (uniform, Yule–Harding, or size-conditioned Galton–Watson) contains a fixed finite pattern. The typical answer is a 0–1 law: a pattern that can occur at all occurs with probability tending to 1.
