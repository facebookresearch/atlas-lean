# Loci versus sequence length trade-off under the multispecies coalescent

Information-theoretic limits for species tree reconstruction from many short genes: under the multispecies coalescent, detecting a short internal branch is a sparse mixture detection problem, and the required number of loci scales inversely with the square root of the sequence length.
