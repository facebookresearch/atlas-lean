# Multilocus distance methods for species trees

Species trees estimated from many loci whose gene trees differ because of incomplete lineage sorting under the multispecies coalescent, using distances that pool sites across loci instead of first estimating each gene tree. Pooled Hamming distances are ultrametric or (after a Jukes–Cantor correction) additive on the species tree, which yields data requirements that scale with the inverse square of the shortest branch.
