# Quartet species trees from multicopy gene trees

Gene families with duplications and losses yield gene trees in which a species can appear several times. Tagging internal nodes as speciations or duplications, and counting only the quartets that reflect speciation, extends quartet-based species-tree estimation from single-copy to multicopy gene trees while remaining statistically consistent.
