# Species-tree relaxed clock

When substitution rates vary among species, every gene tree evolving inside a species tree inherits that variation. A species-tree relaxed clock assigns one relative rate to each species-tree branch and derives each gene-tree branch rate from the species branches that the gene lineage traverses.
