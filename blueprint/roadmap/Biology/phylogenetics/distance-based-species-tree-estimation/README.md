# Distance-based species tree estimation

Species-tree estimation from multilocus data through pairwise summary distances (METAL normalized Hamming distances, STEAC average coalescent distances, GLASS minimum distances) followed by clustering. Their sampling covariance splits into coalescent and substitution components, which explains how the methods relate and when they break down.
