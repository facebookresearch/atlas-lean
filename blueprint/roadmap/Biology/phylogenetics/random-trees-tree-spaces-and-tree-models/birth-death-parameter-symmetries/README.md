# Birth–death parameter symmetries

Exact symmetries of the constant-rate birth–death process and of its reconstructed (sampled) trees: interchanging birth and death rates rescales transition probabilities, and the reconstructed-tree densities conditioned on survival or on the number of sampled tips depend on birth rate, death rate and sampling fraction only through two combinations, which limits what phylodynamic inference based on these conditioned likelihoods can identify.
