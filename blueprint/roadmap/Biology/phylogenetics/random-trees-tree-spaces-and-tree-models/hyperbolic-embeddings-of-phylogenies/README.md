# Hyperbolic embeddings of phylogenies

Representation of a phylogeny by points (one per taxon) in a hyperbolic space, from which a tree with branch lengths is decoded by a distance method. Hyperbolic space is Gromov $\delta$-hyperbolic, with $\delta$ scaling like distances themselves as the curvature changes, and neighbour-joining decodes nearly tree-additive distances stably; moving the taxon points continuously is used to turn tree space into a continuous space for Bayesian sampling.
