# Hyperbolic embeddings of phylogenies

Representation of a phylogeny by points (one per taxon) in a hyperbolic space, from which a tree with branch lengths is decoded by a distance method. Hyperbolic space is Gromov $\delta$-hyperbolic, with $\delta$ shrinking as the curvature becomes more negative, so embedded distances become nearly tree-additive and neighbour-joining decodes them stably; this turns tree space into a continuous space for Bayesian sampling.
