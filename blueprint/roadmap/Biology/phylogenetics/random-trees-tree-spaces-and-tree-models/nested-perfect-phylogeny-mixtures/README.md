# Nested perfect phylogeny mixtures

Bulk or single-cell sequencing measures, for each sample or cell, the fraction of genomes carrying each mutation. Under the infinite-sites model these frequencies factor as a mixture of clones arranged on a perfect phylogeny. When mitochondria evolve inside dividing cells, two trees are present at once, a mitochondrial clone tree nested inside the cell lineage tree, and the factorization must respect both.
