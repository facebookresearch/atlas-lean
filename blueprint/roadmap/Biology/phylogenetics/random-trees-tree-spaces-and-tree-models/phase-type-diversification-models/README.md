# Phase-type diversification models

Macroevolutionary tree models in which the waiting time of a lineage to its next speciation (or extinction) event is a phase-type distribution, the absorption time of a finite continuous-time Markov chain, rather than an exponential. Coxian phase-type laws interpolate between memoryless and age-dependent speciation and produce a wide range of tree balance.
