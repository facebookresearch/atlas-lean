# Error exponents of quartet summary methods

Quartet-based summary methods (such as ASTRAL) infer the species tree agreeing with the most input gene-tree quartets. Their probability of returning a wrong species tree decays exponentially in the number of gene trees, with an explicit large-deviation exponent for four taxa that yields sharp sample-complexity asymptotics under the multispecies coalescent.
