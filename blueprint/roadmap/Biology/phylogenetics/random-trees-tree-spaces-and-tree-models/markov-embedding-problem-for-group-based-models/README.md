# Markov embedding problem for group-based models

When is a transition matrix of a nucleotide (or more general) substitution model the matrix exponential of a rate matrix of the same model, i.e. consistent with a continuous-time, time-homogeneous process? For group-based models the discrete Fourier transform of the group diagonalizes all model matrices, which turns embeddability into explicit inequalities on the eigenvalues.
