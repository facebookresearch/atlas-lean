# UPGMA cones

The UPGMA (average-linkage) clustering method partitions the space of dissimilarity maps according to the ranked tree it returns. Each ranked tree corresponds to a maximal chain in the lattice of set partitions, and the dissimilarity maps returning a given chain form a polyhedral cone whose facets and extreme rays can be written down explicitly; these cones explain why the regions returning a fixed tree topology are not convex and do not form a fan.
