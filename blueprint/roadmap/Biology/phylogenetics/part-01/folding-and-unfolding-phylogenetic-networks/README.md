# Folding and unfolding phylogenetic networks

A rooted phylogenetic network can be unfolded into a multi-labelled tree (MUL-tree) by tracing every directed path from the root, and a MUL-tree can sometimes be folded back into a network that exhibits it. Networks recovered exactly by folding their own unfolding are called stable; the unfolding behaves like the universal cover of a digraph, which links displaying trees in a network to displaying them in its unfolding and to reconciliations.
