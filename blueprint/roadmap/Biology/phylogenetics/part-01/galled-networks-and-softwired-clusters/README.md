# Galled networks and softwired clusters

Rooted phylogenetic networks can summarize incompatible clusters of taxa (for example, clusters from several gene trees). Galled networks, obtained by attaching reticulations to a backbone tree so that each reticulation closes a cycle of tree edges, can represent every set of clusters in the softwired sense, and testing whether an edge represents a cluster is easy for them, unlike for general networks. Computing one with the fewest reticulations decomposes into two NP-hard but practically solvable combinatorial problems.
