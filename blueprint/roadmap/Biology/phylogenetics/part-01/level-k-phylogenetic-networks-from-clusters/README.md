# Level-k phylogenetic networks from clusters

Rooted phylogenetic networks that represent a set of clusters (taxon subsets) coming from several conflicting gene trees, with complexity measured by the level, the maximum number of reticulations in a biconnected component. The incompatibility graph of the clusters decomposes the problem: biconnected components of a minimum-level network can be made to correspond to its connected components.
