# Semialgebraic description of the general Markov model

The set of leaf distributions of the $k$-state general Markov model on a tree is a semialgebraic set strictly smaller than its Zariski closure. Polynomial inequalities built from Cayley's hyperdeterminant and from positive-definiteness of quadratic forms assembled out of marginalizations and slices of the distribution tensor cut out exactly the stochastic model space.
