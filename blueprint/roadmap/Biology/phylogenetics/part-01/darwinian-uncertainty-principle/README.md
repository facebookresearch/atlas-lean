# Darwinian uncertainty principle

Information-theoretic trade-off in ancestral reconstruction of a single discrete character on a phylogeny: tip data become less informative about the root state and (potentially) more informative about the substitution process as the evolutionary rate grows, and the tree shapes for which both can nonetheless be learned.
