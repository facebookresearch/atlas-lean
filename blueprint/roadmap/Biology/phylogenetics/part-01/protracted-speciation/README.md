# Protracted speciation

A lineage-based diversification model in which a newly formed species is incipient for a random duration before it becomes a good species or goes extinct. The reconstructed phylogeny of the species extant at the present (all of them, the good ones, or one representative per good ancestor) is a coalescent point process, which gives an exact product-form likelihood for time-calibrated trees.
