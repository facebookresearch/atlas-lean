# Deep coalescence consensus trees

The minimize-deep-coalescence species tree problem on gene trees with identical leaf sets. Every optimal species tree contains every clade shared by all gene trees (the Pareto property), and each node of the strict consensus tree splits the search into an independent subproblem, which makes large instances tractable.
