# Reconciliation-guided gene tree rearrangement

Gene trees can be improved by local rearrangements (nearest-neighbour interchanges) chosen to lower the most parsimonious duplication–transfer–loss reconciliation cost against a dated species tree. The dynamic-programming cost matrix only needs to be recomputed along the path from the rearranged edge to the root.
