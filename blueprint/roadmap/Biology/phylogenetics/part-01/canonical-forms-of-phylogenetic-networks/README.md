# Canonical forms of phylogenetic networks

Different phylogenetic networks can display exactly the same set of weighted trees and are then indistinguishable from data generated tree by tree. Reducing a network to a funnel-free canonical form picks one representative per indistinguishability class, uniquely under a mild no-equally-long-paths condition.
