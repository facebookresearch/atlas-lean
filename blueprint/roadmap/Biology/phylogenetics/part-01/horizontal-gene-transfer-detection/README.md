# Horizontal gene transfer detection

Statistical tests for whether a gene shared by two genomes was acquired horizontally rather than inherited. A low synteny index (few shared neighbours) is significant only beyond what gene gain and loss produce by chance; to separate transfer from translocation, the gene's sequence divergence is compared with the divergence predicted by a witness gene under constant relative mutability.
