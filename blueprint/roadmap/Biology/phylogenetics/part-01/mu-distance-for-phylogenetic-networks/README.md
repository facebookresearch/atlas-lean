# μ-distance for phylogenetic networks

Comparison of rooted phylogenetic networks through the μ-representation, the multiset of vectors counting paths from each node to each leaf, which characterizes semi-binary tree-sibling time-consistent networks up to isomorphism and yields a metric generalizing the Robinson–Foulds distance.
