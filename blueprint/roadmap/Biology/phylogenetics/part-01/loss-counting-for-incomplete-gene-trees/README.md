# Loss counting for incomplete gene trees

Gene trees that miss species can be reconciled with a species tree under two interpretations: missing taxa as unsampled, where the classical loss formula is exact, or as true gene loss, where losses must be counted on the full species tree.

- [Standard loss count of an incomplete gene tree under taxon sampling](standard-loss-count-under-taxon-sampling.md)
