# Rearrangement moves on rooted phylogenetic networks

Local search over rooted phylogenetic networks needs moves that connect the whole space of networks of a given reticulate complexity. Rooted nearest-neighbour interchange (rNNI) and rooted subtree prune-and-regraft (rSPR) moves generalise their tree counterparts to binary rooted networks; they preserve the number of reticulations, connect all networks with the same number, and every rNNI move is a restricted rSPR move.
