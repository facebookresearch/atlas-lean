# Mimicking by phylogenetic mixture models

When can a mixture of substitution processes on one or several trees produce exactly the same site-pattern distribution as a model on a different tree? Rank conditions on flattenings and linear invariants of group-based models rule mimicking out for few-class mixtures, while mixtures of contracted trees can completely mimic the resolved tree.
