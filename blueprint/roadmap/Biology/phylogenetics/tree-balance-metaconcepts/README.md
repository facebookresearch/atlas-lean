# Tree balance metaconcepts

Families of tree shape statistics of the form $\Phi^{Seq}_f(T)=\sum_i f(Seq(T)_i)$, where $Seq(T)$ is a sequence attached to a rooted tree (balance values, clade sizes, or leaf depths) and $f$ is a real function. Classical imbalance indices (Colless, quadratic Colless, Sackin, total cophenetic, average leaf depth) are special cases, and the choice of $f$ decides which trees are extremal.
