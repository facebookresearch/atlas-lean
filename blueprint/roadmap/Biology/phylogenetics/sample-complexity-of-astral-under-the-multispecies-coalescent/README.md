# Sample complexity of ASTRAL under the multispecies coalescent

How many error-free gene trees a quartet-based summary method needs to recover the species tree when gene tree discordance comes from incomplete lineage sorting. For ASTRAL the answer is of order $f^{-2}\log n$, with $f$ the shortest internal branch length in coalescent units and $n$ the number of species, and this order is tight.
