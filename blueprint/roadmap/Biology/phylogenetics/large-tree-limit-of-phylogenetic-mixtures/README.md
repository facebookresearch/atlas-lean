# Large-tree limit of phylogenetic mixtures

Mixtures of several phylogenies under a common GTR substitution model, studied as the number of leaves grows. By concentration of measure, almost every large mixture (with respect to any leaf-permutation-invariant measure) is identifiable, its components produce nearly disjoint site-pattern distributions, and its topologies can be reconstructed in polynomial time.
