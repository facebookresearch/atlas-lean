# Maximum parsimony distance: metric properties and complexity

The maximum parsimony (MP) distance between two phylogenetic trees is the largest difference between the parsimony scores of a single character on the two trees. It is a metric, a lower bound for the SPR distance, attained by characters convex on one of the trees, and NP-hard to compute.
