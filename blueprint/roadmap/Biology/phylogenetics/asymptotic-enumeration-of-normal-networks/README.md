# Asymptotic enumeration of normal networks

Counting phylogenetic networks with $n$ leaves and $k$ reticulations as $n$ grows. Placing $k$ random arcs on a random binary tree almost always yields a normal network, which gives transparent asymptotics for normal and hybridization networks.
