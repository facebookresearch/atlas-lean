# Boosted polygenic scores with non-additive effects

Building sparse polygenic scores for binary diseases by logistic boosting over genetic variants, where each step fits a genotype-coded score to a weighted working response. Allowing the three genotype classes their own scores captures dominance and recessive effects that an additive dosage coding misses.
