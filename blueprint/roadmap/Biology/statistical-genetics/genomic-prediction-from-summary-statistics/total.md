# Number of individuals in a case-control genotype table

A case-control genotype table is a pair of functions $r, s : \{0, 1, 2\} \to \mathbb{R}$: $r_i$ cases and $s_i$ controls carry $i$ copies of the counted allele (the counts are arbitrary real numbers). Its total is

$$N = \sum_{i=0}^{2} (r_i + s_i).$$
