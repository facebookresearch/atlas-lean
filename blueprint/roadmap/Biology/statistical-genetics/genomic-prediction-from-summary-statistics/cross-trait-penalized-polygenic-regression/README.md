# Cross-trait penalized polygenic regression

Genome-wide penalized regression for predicting a primary trait that borrows strength from correlated secondary traits: a sparsity penalty selects SNPs, and a quadratic (graph Laplacian) penalty pulls each SNP's effects on related traits toward each other or toward published summary statistics.
