# Genotype data, annotations and genomic privacy

choosing tag markers and ordering markers into linkage maps, estimating the coverage of haplotype
databases, combining functional annotations of variants, and releasing genomic data or summary
statistics with privacy guarantees. Reading order does not assert a mathematical dependency.
