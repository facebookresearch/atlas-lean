# Cell-fraction interaction QTLs

In bulk tissue, a cis-regulatory variant whose effect is confined to one cell type produces an expression effect and an allelic imbalance that both scale with that cell type's fraction in each sample. These articles give the mixture model for the allelic fraction of heterozygous carriers, its regression test, and the combination of the allelic and total-expression interaction tests into one statistic.
