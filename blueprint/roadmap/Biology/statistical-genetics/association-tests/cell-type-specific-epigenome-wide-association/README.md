# Cell-type-specific epigenome-wide association

Bulk DNA methylation measurements are mixtures of cell-type-specific methylation profiles weighted by unknown cellular compositions. Because cell proportions act multiplicatively on cell-type-specific phenotype effects, association models that add estimated proportions as covariates test the wrong parameter; a hierarchical mixture model with cell-type-specific effects is identifiable under mild anchor and rank conditions.
