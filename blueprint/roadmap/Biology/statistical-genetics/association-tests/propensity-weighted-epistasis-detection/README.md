# Propensity-weighted epistasis detection

To find SNPs interacting with a target SNP in a GWAS, treat the target as a "treatment" and the rest of the genotype as covariates. Inverse-propensity weighting, with linkage-disequilibrium-aware propensity scores, turns the interaction function into an ordinary regression or weighted classification target whose sparse support identifies the interacting SNPs.
