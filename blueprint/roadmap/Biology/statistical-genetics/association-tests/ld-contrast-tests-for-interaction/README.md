# LD contrast tests for SNP interaction

Two loci acting synergistically on disease risk induce different linkage disequilibrium among cases than among controls, so the case–control difference of composite LD is a test statistic for interaction. Because LD is a sample covariance of genotype codes, the covariance between two such statistics has a closed form in fourth moments, which lets correlated SNP-pair tests be aggregated into a region–region test.
