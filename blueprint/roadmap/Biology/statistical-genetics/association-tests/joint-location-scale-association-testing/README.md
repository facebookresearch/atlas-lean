# Joint location-scale association testing

Detecting a SNP that changes either the mean or the variance of a quantitative trait. Unmodelled gene–environment interaction makes the trait variance differ across genotypes, so a mean (location) test and a variance (scale) test carry complementary evidence; under a homoscedastic normal null the two statistics are independent and can be combined exactly.
