# Association tests

Tests of association between genetic variants and traits, and their calibration: the
Cochran–Armitage trend test of genotype counts, exact and asymptotic tests of Hardy–Weinberg
equilibrium, the SKAT variance-component test with relatedness, and genomic control. Fisher's exact
test, the burden test and SKAT-O, multiple testing across genes, and genomic control with an
estimated inflation factor are under [Hypothesis testing](../../../Probability/hypothesis-testing/README.md)
in Probability.
