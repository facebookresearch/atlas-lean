# Counting vectors with prescribed class counts

For a finite set `ι` of classes, `M ∈ ℕ` and counts `m : ι → ℕ` with `∑ᵢ mᵢ = M`, the number `K` of
vectors of length `M` with entries in `ι` and [class counts](class-count.md) `m` satisfies
`K · ∏ᵢ mᵢ! = M!`; that is, `K = M! / ∏ᵢ mᵢ!` is the multinomial coefficient.
