# A fixed-margin design with a single genotype class has statistic zero

For `R ≤ N` and genotype classes with `g_k = c` for every `k < N`, the
[fixed-margin statistic](fm-stat.md) is `0`. The genotype score has zero sample variance, the
variance factor of the denominator vanishes and the classical statistic is undefined; the value `0`
comes from the convention `x / 0 = 0`.
