# A design without cases has statistic zero

For every `N ∈ ℕ` and all genotype classes `g`, the [fixed-margin statistic](fm-stat.md) with
`R = 0` cases is `0`. The classical statistic is undefined here, since the factor `R` of its
denominator vanishes; the value `0` comes from the convention `x / 0 = 0`.
