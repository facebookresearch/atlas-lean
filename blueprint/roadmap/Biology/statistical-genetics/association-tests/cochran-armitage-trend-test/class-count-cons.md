# Prepending an entry adds one to its class count

For a vector `v = (v_0, …, v_{M−1})` of length `M` with entries in a set `ι` of classes and `a ∈ ι`,
the vector `(a, v_0, …, v_{M−1})` of length `M + 1` has, for every `i ∈ ι`, the
[class count](class-count.md) of `i` in `v` plus `1` if `i = a`, and the class count of `i` in `v`
otherwise.
