# Number of controls in a genotype class, fixed-margin design

In a fixed-margin design the subjects `0, …, R − 1` are the `R` cases, the subjects `R, …, N − 1`
the controls, and subject `k` has genotype class `g_k ∈ ι`. The control count of a class `i ∈ ι` is
the number of `k` with `R ≤ k < N` and `g_k = i`; it is `0` when `N ≤ R`.
