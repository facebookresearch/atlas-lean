# For R ≤ N the case and control counts add up to the genotype margin

For `R ≤ N`, genotype classes `g_k` of the subjects and every class `i`, the
[case count](case-count-2.md) of `i` (among `k < R`) plus the [control count](control-count-2.md) of
`i` (among `R ≤ k < N`) is the [genotype margin](genotype-total.md) of `i` (among `k < N`).
