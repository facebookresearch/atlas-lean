# Singular design: the statistic is almost surely zero

Let `P` be a measure, not necessarily a probability measure, and `S_m = (G_m, Y_m)` subjects that
all have the same law as `S_0` under `P`. If `G_0 = g` almost everywhere for one genotype class `g`
(zero score variance), then almost everywhere the [Cochran–Armitage statistic](ca-stat.md) of the
first `N` subjects is `0` for every `N`. The classical statistic is undefined here, since its
variance factor vanishes; the value `0` comes from the convention `x / 0 = 0`.
