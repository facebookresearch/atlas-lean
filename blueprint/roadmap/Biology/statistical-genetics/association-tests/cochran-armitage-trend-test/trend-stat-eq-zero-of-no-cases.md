# Trend statistic of a table without cases

For real vectors `r` and `s` indexed by the genotype classes `0, 1, 2` with `∑ᵢ rᵢ = 0`, the
[trend statistic](../../genomic-prediction-from-summary-statistics/trend-stat.md) of the table with
case counts `r` and control counts `s` is `0`: the factor `R = ∑ᵢ rᵢ` of its denominator vanishes,
and `x / 0 = 0`. For counts, `∑ᵢ rᵢ = 0` means that the table has no cases; the classical statistic
is undefined there.
