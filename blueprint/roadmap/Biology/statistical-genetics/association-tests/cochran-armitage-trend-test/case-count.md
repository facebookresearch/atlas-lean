# Number of cases in a genotype class among the first N subjects

Let `S_m(ω) = (G_m(ω), Y_m(ω))` be the pair of the genotype class `G_m(ω) ∈ {0, 1, 2}` and the case
status `Y_m(ω)` (true for a case, false for a control) of subject `m = 0, 1, 2, …` at the outcome
`ω`. For `N ∈ ℕ` and a genotype class `i`, the case count `rᵢ(N, ω)` is the number of subjects
`m < N` with `G_m(ω) = i` that are cases, as a real number.
