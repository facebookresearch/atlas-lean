# The χ²₁ tail is strictly decreasing on nonnegative thresholds

For real numbers `a` and `b` with `0 ≤ a < b`,

`P(χ²₁ > b) < P(χ²₁ > a)`:

the [`χ²₁` tail](chi-sq-one-tail.md) is strictly decreasing on `[0, ∞)`, because the interval
`(√a, √b)` has positive standard normal mass and every `x` in it satisfies `a < x² < b`. For
thresholds `c ≤ 0` the tail is constant, equal to `1`.
