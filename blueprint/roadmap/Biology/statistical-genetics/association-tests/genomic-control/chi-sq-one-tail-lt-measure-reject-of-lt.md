# Dividing by a positive λ below the null variance is anti-conservative

Let `P` be a measure, let `Z` be a real random variable with law `𝒩(0, v)` under `P`, and let
`λ` be a real number with `0 < λ < v`. For every threshold `c > 0`,

`P(χ²₁ > c) < P(Z² / λ > c)`:

a marker whose null variance `v` exceeds the factor `λ` used (its inflation is not the common
one) is strictly anti-conservative after genomic control. Here `P(χ²₁ > c)` is the
[`χ²₁` tail](chi-sq-one-tail.md).
