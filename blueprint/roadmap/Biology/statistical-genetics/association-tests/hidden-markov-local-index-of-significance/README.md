# Hidden Markov local index of significance

When association signals cluster along the genome, SNP-level hypotheses can be modelled as hidden states of a Markov chain observed through z-values. The local index of significance (LIS), the posterior probability that a hypothesis is null given all observations, ranks the SNPs, and a step-up rule on ranked LIS values controls the false discovery rate with asymptotically smallest false non-discovery rate.
