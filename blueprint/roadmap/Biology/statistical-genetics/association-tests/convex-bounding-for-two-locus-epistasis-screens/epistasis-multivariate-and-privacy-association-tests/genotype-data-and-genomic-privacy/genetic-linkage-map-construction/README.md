# Genetic linkage map construction

Ordering genetic markers along a chromosome from recombination data. Recombination fractions between marker pairs are monotone in physical enclosure, which turns marker ordering into a minimum-weight traveling-salesman path and, for clean data, into a minimum spanning tree computation; linkage groups are separated by a concentration bound on recombinant counts.
