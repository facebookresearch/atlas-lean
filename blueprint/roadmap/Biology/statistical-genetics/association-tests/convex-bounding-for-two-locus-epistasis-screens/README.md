# Convex bounding for two-locus epistasis screens

Exhaustive genome-wide tests of SNP pairs are quadratic in the number of markers and become prohibitive under permutation testing. When the association statistic is convex in the contingency-table counts, its maximum over all tables compatible with one SNP's data is attained at a vertex of a small polytope, giving an exact upper bound that prunes most pairs without testing them.

- [Vertex-maximum pruning of convex two-locus test statistics](vertex-maximum-pruning-of-convex-two-locus-test-statistics.md)
