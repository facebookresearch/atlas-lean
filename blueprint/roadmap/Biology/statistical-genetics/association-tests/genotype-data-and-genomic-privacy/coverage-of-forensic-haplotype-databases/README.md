# Coverage of forensic haplotype databases

How representative is a database of mitochondrial or Y-chromosome haplotypes, and how many distinct haplotypes remain unseen? Species-richness methods built on the frequency spectrum of the database (how many haplotypes occur once, twice, ...) estimate the sample coverage and the total number of haplotype classes, which in turn calibrates the frequency assigned to a haplotype never observed.
