# STAAR annotation-weighted rare-variant tests

Variant-set association tests for rare variants in which each variant's prior probability of being causal is estimated from functional annotations, the burden, SKAT and ACAT-V statistics are recomputed with each annotation as a weight, and the resulting p-values are aggregated by the Cauchy combination.
