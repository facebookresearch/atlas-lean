# Mixed-model, set-based and EHR association tests

Association tests beyond the single-variant trend test: score tests in logistic mixed models with
a genetic relationship matrix (SAIGE and SAIGE-GENE), the combination of sequenced and imputed
association statistics, set-based quadratic-form tests from GWAS summary statistics (fastBAT, mBAT
and their Cauchy combination), and the effect of outcome misclassification and selection on
logistic association estimates from electronic health records.
