# SAIGE logistic mixed-model association tests

Score tests in a generalized linear mixed model with a genetic relationship matrix, made scalable by a variance ratio estimated once per phenotype and made accurate for unbalanced case–control data by a saddlepoint approximation (SAIGE), and their region-based extension to burden, SKAT and SKAT-O tests (SAIGE-GENE).
