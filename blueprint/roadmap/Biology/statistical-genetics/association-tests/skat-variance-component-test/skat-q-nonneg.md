# With nonnegative weights the SKAT statistic is nonnegative

If all variant weights are nonnegative, `wⱼ ≥ 0`, then for every real `n × q` covariate matrix `X`,
real `n × n` matrix `V`, real `n × m` genotype matrix `G` and phenotype `y ∈ ℝⁿ`, the
[SKAT statistic](skat-q.md) satisfies `Q ≥ 0`. The test of `τ = 0` against `τ > 0` is one-sided and
rejects for large `Q`.
