# For a positive definite covariance the null projection is symmetric

If `V` is a positive definite real `n × n` matrix, then for every real `n × q` covariate matrix `X`
the [null projection](proj-p.md) is symmetric: `Pᵀ = P`. This holds also when `Xᵀ V⁻¹ X` is
singular, its inverse then being taken to be `0`.
