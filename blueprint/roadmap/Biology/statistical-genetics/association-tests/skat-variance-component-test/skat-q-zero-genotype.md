# With no carriers at any variant the SKAT statistic is zero

If the genotype matrix is zero, `G = 0` (no individual carries a minor allele at any variant), the
[SKAT statistic](skat-q.md) vanishes identically: `Q(y) = 0` for every phenotype `y`, every real
`n × q` covariate matrix `X`, every real `n × n` matrix `V` and all weights `w`.
