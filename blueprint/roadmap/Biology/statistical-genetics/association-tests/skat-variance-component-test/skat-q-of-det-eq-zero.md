# A singular null covariance makes the SKAT statistic zero

If `det V = 0`, then the [SKAT statistic](skat-q.md) is `Q(y) = 0` for every phenotype `y`, every
real `n × q` covariate matrix `X`, every real `n × m` genotype matrix `G` and all weights `w`, with
the convention that the inverse of a singular matrix is `0`, so that `V⁻¹ = 0`.
