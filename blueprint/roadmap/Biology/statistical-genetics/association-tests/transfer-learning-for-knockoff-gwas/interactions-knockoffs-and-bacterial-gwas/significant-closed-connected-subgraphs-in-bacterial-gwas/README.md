# Significant closed connected subgraphs in bacterial GWAS

Bacterial genome-wide association studies can test every closed connected subgraph of a compacted de Bruijn graph, with family-wise error control, by combining Tarone's minimal attainable p-values with a reverse-search tree over these subgraphs. The tree is what allows monotone pruning.
