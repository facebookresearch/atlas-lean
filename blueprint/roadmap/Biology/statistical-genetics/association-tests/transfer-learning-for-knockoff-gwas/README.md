# Transfer learning for knockoff GWAS

Knockoff-based conditional association testing in a target population can borrow strength from GWAS data in other populations or related traits. Using external evidence only to reorder or reweight the target knockoff statistics preserves the sign symmetry of null statistics and hence false discovery rate control.
