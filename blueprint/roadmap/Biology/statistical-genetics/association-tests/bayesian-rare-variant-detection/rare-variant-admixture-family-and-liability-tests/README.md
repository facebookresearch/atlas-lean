# Rare-variant, admixture, family and liability tests

Association tests beyond the single-marker case-control test: rare-variant tests that pool variants
in a region (C-alpha overdispersion, collapsing ultra-rare variants, STAAR annotation weighting),
tests in admixed populations that use global or local ancestry (SNP and admixture association,
local ancestry-aware association, admixture mapping), family-based tests of transmission and de novo
variation (the polygenic transmission disequilibrium test, de novo variant burden and the number of
risk genes), liability threshold models that condition on clinical covariates or family history,
tests that combine or contrast several phenotypes (cross-phenotype meta-analysis, case-case
association, conjunction tests), non-additive HLA risk models, and the functional interpretation of
association signals.
