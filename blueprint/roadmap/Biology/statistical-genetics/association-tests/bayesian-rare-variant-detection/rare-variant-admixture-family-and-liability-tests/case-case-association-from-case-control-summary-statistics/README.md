# Case–case association from case–control summary statistics

Comparing cases of two disorders directly requires no new genotyping: allele-frequency differences between the cases of disorders $A$ and $B$ are linear combinations of the two case–control differences, with coefficients set by the lifetime prevalences. These articles state that identity, the resulting CC-GWAS estimators, and the genetic distances between cases and controls of two disorders implied by heritabilities, prevalences and genetic correlation.
