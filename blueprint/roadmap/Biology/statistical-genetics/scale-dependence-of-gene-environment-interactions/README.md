# Scale dependence of gene–environment interactions

Gene-by-environment ($G \times E$) interaction estimates from linear regression depend on the scale on which the phenotype is measured. Monotone convex rescaling and threshold-based (endogenous) treatment each induce interactions whose signs are tied to the signs of the main genetic effects, which gives a diagnostic for spurious $G \times E$ signals.
