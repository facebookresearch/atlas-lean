# Expression-mediated heritability

Part of the heritability of a complex trait acts through the cis-genetic regulation of gene expression. These articles define the expression-mediated heritability $h^2_{\mathrm{med}}$, decompose it into the number of genes, their average squared expression effect and their average cis-heritability, and state the regression of squared SNP effects on eQTL scores (MESC) that estimates it from summary statistics.
