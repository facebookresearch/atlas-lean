# Hierarchical linkage disequilibrium

Haplotype frequencies at $M$ biallelic loci can be reparametrized by the joint cumulants of every subset of loci: allele frequencies, pairwise LD, third-order LD and so on. The hierarchy supports direct estimation and association tests that target only some orders, with fewer degrees of freedom than a full haplotype test.
