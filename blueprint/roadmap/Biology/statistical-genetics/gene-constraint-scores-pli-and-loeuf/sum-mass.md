# Class masses sum to the number of genes

Let $\iota$ be a finite nonempty set, let $\lambda : \iota \to \mathbb{R}$ with $\lambda_c > 0$ for every $c$, let $x_1, \dots, x_N$ be [gene data](gene-data.md), and let $w$ be [strictly positive weights](pos-weights.md) on $\iota$. Then the [class masses](mass.md) add up to the number of genes:

$$\sum_{z \in \iota} M_w(z) = N.$$
