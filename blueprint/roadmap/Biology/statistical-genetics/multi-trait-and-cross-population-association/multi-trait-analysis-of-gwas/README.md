# Multi-trait analysis of GWAS

Joint analysis of GWAS summary statistics for several genetically correlated traits. Treating true per-SNP effects as random with a common covariance across SNPs, a generalized method of moments estimator combines the trait-specific estimates into a more precise estimate for each trait, while allowing sample overlap.
