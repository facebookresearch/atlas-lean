# Polygenic transmission disequilibrium test

Family-based tests that compare an offspring's polygenic score with the mean of its parents' scores. Mendelian segregation makes the mid-parent score the conditional expectation of the offspring score, so a systematic excess in ascertained offspring is evidence of association that cannot be produced by population stratification.
