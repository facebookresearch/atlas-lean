# Stratified trans-ethnic genetic correlation

Causal effect sizes of the same variants can differ between populations. Regressing products of GWAS z-scores from two populations on trans-ethnic LD scores partitions the trans-ethnic genetic covariance across functional annotations, and dividing by the per-annotation heritabilities gives an annotation-specific squared genetic correlation. These articles give the regression and the enrichment statistic built on it.
