# LD-score regression model as a stratified model

Every [LD-score model](../ld-score-regression/model.md) $(h^2, \beta, \varepsilon)$ with $M$ markers defines a [stratified LD-score model](model.md) with the same effects and noise, equal per-marker variances $\sigma^2_k = h^2 / M$ (with $x/0 = 0$) and noise variance $\sigma^2_e = 1 - h^2$.
