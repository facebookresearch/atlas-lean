# Marker-proportion-weighted enrichments sum to one

Let $\sigma^2_1, \dots, \sigma^2_M$ be real per-marker variances with $\sum_k \sigma^2_k \ne 0$, and let $\mathrm{cat}$ label the markers by categories in a finite set $\mathcal{C}$. Then

$$\sum_{C \in \mathcal{C}} \frac{M_C}{M}\, \mathrm{Enr}(C) = 1,$$

where $M_C$ is the [category size](cat-size.md) and $\mathrm{Enr}$ the [enrichment](enrichment.md). Empty categories contribute $0$.
