# Digital twin test for trio studies

Given the parents' haplotypes, an offspring's genome is the outcome of a randomized experiment run by meiosis, with a known law (Haldane's recombination hidden Markov model). Resampling "digital twin" offspring from that law yields exact, finite-sample conditional randomization tests whose rejections certify causal genomic regions, immune to population structure and every other confounder that does not alter Mendelian transmission.
