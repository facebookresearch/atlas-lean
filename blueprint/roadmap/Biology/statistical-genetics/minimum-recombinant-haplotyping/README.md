# Minimum-recombinant haplotyping

Haplotype inference in families by choosing, along a chromosome, the sequence of inheritance vectors consistent with the genotypes that implies the fewest recombinations; a shortest-path dynamic program over inheritance vectors computes it, and the same recursion with likelihood weights gives maximum-likelihood haplotypes.
