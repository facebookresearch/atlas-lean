# IBD detection and genotype error in sequence data

Sequence data are dense, rich in low-frequency variants and carry genotype errors that break long shared haplotypes. Summing per-marker likelihood ratios that allow for allele errors gives a phase-free detector of identity-by-descent (IBD) segments, and the detected segments in turn identify the genotype error rate at low-frequency variants.
