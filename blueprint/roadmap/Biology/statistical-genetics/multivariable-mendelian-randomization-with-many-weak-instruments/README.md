# Multivariable Mendelian randomization with many weak instruments

Summary-data multivariable Mendelian randomization (MVMR) estimates direct causal effects of many correlated exposures on an outcome from GWAS associations of $p$ SNPs. Under many weak instruments, the naive weighted least-squares estimator is biased by measurement error in the SNP–exposure associations; subtracting the known error covariance (debiasing) restores consistency, and penalized versions select exposures and groups of exposures with equal effects with oracle properties.
