# IBD detection from imputed haplotype dosages

A hidden Markov model for identity-by-descent segments between two diploid genomes whose genotypes are imputed and phased from low-coverage (for example ancient) DNA. The observed data are haploid dosages, phase errors are absorbed by switch transitions between IBD states, and segments are called from posterior decoding (ancIBD).
