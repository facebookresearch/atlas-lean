# Phase-aware fetal aneuploidy detection

Detection of fetal trisomy from allelic read counts in maternal plasma cell-free DNA by comparing the best-fitting sequences of maternal inheritance states under trisomy and euploidy, using the chromosomal phase of the mother's heterozygous sites.
