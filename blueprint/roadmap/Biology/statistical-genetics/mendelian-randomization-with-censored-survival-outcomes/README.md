# Mendelian randomization with censored survival outcomes

Causal effect estimation from many weak and possibly invalid genetic instruments when the outcome is a right-censored time to event, using a structural accelerated failure time model, heteroscedasticity-based identification and an augmented inverse-probability-of-censoring-weighted moment function.
