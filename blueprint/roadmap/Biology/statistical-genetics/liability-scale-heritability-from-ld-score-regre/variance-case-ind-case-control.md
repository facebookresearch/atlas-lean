# Variance of the case indicator under case-control sampling

Let `μ` be a probability measure on `Ω`, let `L` be a measurable real function on `Ω`, let `t` be a
real threshold such that the cases `C = {t ≤ L}` satisfy `0 < μ(C) < 1`, and let `0 ≤ P ≤ 1`. Then
under the [case-control law](case-control.md) `μ_cc` with case fraction `P`, the
[case indicator](case-ind.md) `Y = 1{L ≥ t}` has variance

`Var_cc Y = P (1 - P)`.
