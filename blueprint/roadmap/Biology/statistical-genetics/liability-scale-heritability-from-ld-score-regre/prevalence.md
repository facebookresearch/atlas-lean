# Prevalence of the threshold model

For a real threshold `t`, the prevalence of the liability threshold model is

`K(t) = Φ(-t)`,

where `Φ` is the standard normal distribution function. For a liability `L` with the standard normal
law, `K(t) = P(L ≥ t)` is the probability of being a case (the
[fraction of cases](measure-real-case.md)). For every `t`, `0 < K(t) < 1`.
