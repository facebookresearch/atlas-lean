# MAGENTA gene-set enrichment

Gene-set enrichment analysis for genome-wide association summary statistics: SNP p-values are summarized into gene scores corrected for confounding gene properties, and sets of functionally related genes are tested for an excess of high-ranking genes against random gene sets of the same size.
