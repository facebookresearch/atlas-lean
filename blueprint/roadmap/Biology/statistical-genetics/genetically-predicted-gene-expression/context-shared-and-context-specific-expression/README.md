# Context-shared and context-specific components of expression

When gene expression is measured in several contexts (tissues or cell types) of the same individuals, each individual's profile splits into a between-individual mean, shared across contexts, and within-individual deviations, specific to each context. Genetic predictors are fitted to each component separately and recombined by regression into a full per-context predictor for transcriptome-wide association.
