# Genetically predicted gene expression

Models that predict gene expression from cis genotypes and use the predictions in transcriptome-wide association: cross-validated cis prediction from a single mixed-model fit, decompositions of multi-context expression into shared and context-specific components, and sparse canonical correlation features across tissues.
