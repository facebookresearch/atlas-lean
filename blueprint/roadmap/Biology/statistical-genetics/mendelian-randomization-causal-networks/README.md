# Mendelian randomization causal networks

Network Mendelian randomization: with many traits linked by a possibly cyclic linear structural model and SNPs as instrumental variables, pairwise MR ratios estimate total ("MR") effects, which are a column-rescaled inverse of $I-G$ for the direct-effect network $G$. Inverting that relation recovers the direct causal network from GWAS summary statistics.
