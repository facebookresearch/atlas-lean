# Robust tag SNP selection

Tag SNPs are a small subset of markers that still distinguish all common haplotypes in a block, reducing genotyping cost. Because genotype calls go missing, a robust tag set should distinguish every pair of haplotypes even after any $m$ tags are lost; this is a set multicover problem, NP-hard but approximable within logarithmic factors.
