# Covariate-assisted composite null testing

Replicability analysis tests a composite null (a feature is non-null in at most one of two studies). Modelling the primary p-values jointly with an auxiliary covariate in a mixture of hidden states yields a local false discovery rate that borrows prior information from the covariate, and a step-up rule on it that controls the FDR asymptotically.
