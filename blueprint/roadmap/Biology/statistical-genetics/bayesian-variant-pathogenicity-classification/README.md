# Bayesian variant pathogenicity classification

The qualitative evidence criteria used to classify sequence variants can be read as a naive Bayes classifier: each criterion multiplies the odds of pathogenicity by a fixed factor, evidence strengths are integer or fractional powers of one base factor (points), and the posterior probability is compared with fixed thresholds. Co-segregation of a variant with disease in a family contributes points that follow from Mendelian segregation probabilities.
