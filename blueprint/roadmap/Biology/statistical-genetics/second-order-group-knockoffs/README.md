# Second-order group knockoffs

Knockoff variables that are exchangeable with the features only across whole groups, and only up to second moments, test group conditional-independence hypotheses with FDR control from a covariance matrix alone. That makes them usable on GWAS summary statistics. Power depends on how the free block-diagonal matrix $S$ is chosen.
