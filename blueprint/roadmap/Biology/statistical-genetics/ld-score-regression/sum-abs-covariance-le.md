# Bounded LD gives bounded covariance row sums

For a finite measure $\mu$ and statistics $\chi_1, \dots, \chi_M$ satisfying an
[LD-block model](ldblock-model.md) with block size $K$ and variance bound $V$,
$\sum_{k=1}^{M} |\operatorname{Cov}(\chi_j, \chi_k)| \leq K V$ for every marker $j$, the covariances
being taken with respect to $\mu$.
