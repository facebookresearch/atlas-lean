# Variance of a linear combination as a quadratic form

For a finite measure $\mu$, square-integrable real functions $Y_j$ indexed by a finite set and real
coefficients $a_j$,
$\operatorname{Var}(\sum_j a_j Y_j) = \sum_{j,k} a_j a_k \operatorname{Cov}(Y_j, Y_k)$. Here
$\operatorname{Cov}(X, Y) = \int (X - \int X\, d\mu)(Y - \int Y\, d\mu)\, d\mu$ and
$\operatorname{Var} X = \operatorname{Cov}(X, X)$ are taken with respect to $\mu$; for a probability
measure they are the usual covariance and variance.
