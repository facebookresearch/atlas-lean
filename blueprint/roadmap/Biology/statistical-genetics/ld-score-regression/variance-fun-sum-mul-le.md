# Variance of a linear combination under a covariance row-sum bound

For a finite measure $\mu$, square-integrable real functions $Y_j$ indexed by a finite set with
$\sum_k |\operatorname{Cov}(Y_j, Y_k)| \leq R$ for every $j$, and real coefficients $a_j$,
$\operatorname{Var}(\sum_j a_j Y_j) \leq R \sum_j a_j^2$, with variance and covariances taken with
respect to $\mu$.
