# Variance of the least-squares slope

For a finite measure $\mu$, a real vector $x$ indexed by a finite set and square-integrable real
functions $Y_j$ with $\sum_k |\operatorname{Cov}(Y_j, Y_k)| \leq R$ for every $j$, the least-squares
slope $\hat b = S_{xY} / S_{xx}$ of the responses $Y_j$ on $x$, where
$S_{xy} = \sum_j (x_j - \bar x)(y_j - \bar y)$, satisfies
$\operatorname{Var}(\hat b) \leq R / S_{xx}$, with variance and covariances taken with respect to
$\mu$ and the convention $x/0 = 0$: both sides are $0$ when $S_{xx} = 0$.
