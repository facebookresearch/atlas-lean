# The coordinates are orthonormal in L²

For a probability measure $\nu$ on $\mathbb{R}$ satisfying the
[bounded unit law](is-bounded-unit-law.md) condition with bound $C$,
$\int \omega_s \omega_t \, d\nu^{\otimes \mathbb{N}}(\omega) = 1$ if $s = t$ and $0$ otherwise, for
all $s, t \in \mathbb{N}$.
