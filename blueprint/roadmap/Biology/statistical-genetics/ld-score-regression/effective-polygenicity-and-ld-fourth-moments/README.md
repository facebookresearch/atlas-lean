# Effective polygenicity and LD fourth moments

The number of SNPs with nonzero effect depends on detection thresholds and says little about how heritability is spread. The effective number of independently associated SNPs $M_e$ uses the kurtosis of standardized effect sizes instead, and stratified LD fourth moments regression estimates it from GWAS summary statistics.
