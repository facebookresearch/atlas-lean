# The replicated block design

For a [standardized](is-standardized.md) real $g \times k$ template matrix $T$ and a natural number
$b$, the [replicated matrix](replicate.md) with $b$ copies, with the copies as blocks and cohorts
(marker $(u, a)$ in block $u$ and individual $(u, r)$ in cohort $u$), is a
[block design](block-design.md) with $b g$ individuals, $b k$ markers, block size $k$ and cohort
size $g$.
