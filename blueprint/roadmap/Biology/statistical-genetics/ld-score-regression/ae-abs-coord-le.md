# Almost surely every coordinate is bounded by C in absolute value

For a probability measure $\nu$ on $\mathbb{R}$ satisfying the
[bounded unit law](is-bounded-unit-law.md) condition with bound $C$, almost surely under the
[product measure](coord-measure.md) $\nu^{\otimes \mathbb{N}}$, $|\omega_s| \leq C$ for every
coordinate $s \in \mathbb{N}$.
