# A score-level model gives an LD-block model for scaled squared scores

Let $\mu$ be a probability measure, $z_1, \dots, z_M$ scores satisfying a
[score-level LD-block model](score-block-model.md) with block size $K$, $a \in \mathbb{R}$, and $V$
a real number with $\mathbb{E}[(a z_j^2)^2] \leq V$ for every marker $j$. Then the statistics
$a z_j^2$ satisfy an [LD-block model](ldblock-model.md) with the same blocks, block size $K$ and
variance bound $V$.
