# Positive contrast variances form an open set

For a finite index set $r$ and $d \in \mathbb{R}^r$, the set of parameters
$\theta = (\sigma_g^2, \sigma_e^2) \in \mathbb{R}^2$ at which every
[contrast variance](contrast-var.md) $\sigma_g^2 d_i + \sigma_e^2$ is positive is open in
$\mathbb{R}^2$. For empty $r$ it is all of $\mathbb{R}^2$.
