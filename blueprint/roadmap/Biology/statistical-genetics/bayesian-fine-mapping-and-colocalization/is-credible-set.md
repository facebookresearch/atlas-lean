# Credible set of variants

Let $\iota$ be a finite set, let $\alpha : \iota \to \mathbb{R}$ and let $\rho \in \mathbb{R}$. A subset $S \subseteq \iota$ is a $\rho$-credible set for $\alpha$ if

$$\rho \le \sum_{j \in S} \alpha_j.$$

Typically $\alpha$ is the vector of posterior inclusion probabilities, but any real weights are allowed.
