# Nonnegativity of colocalization configuration weights

Let $p_1, p_2, p_{12}$ be [colocalization prior parameters](coloc-prior.md) on a finite set $\iota$ of variants. Then the [unnormalized configuration weight](weight.md) satisfies $w(S) \ge 0$ for every configuration $S \in \iota_\ast \times \iota_\ast$.
