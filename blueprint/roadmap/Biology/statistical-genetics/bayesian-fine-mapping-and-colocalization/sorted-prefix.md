# Prefix of variants in a given order

Let $\iota$ be a finite set with $m$ elements and let $\sigma : \{0, \dots, m-1\} \to \iota$ be a bijection (an ordering of the variants). For a natural number $k$, the prefix of length $k$ is

$$\mathrm{Pre}_\sigma(k) = \{\sigma(i) : 0 \le i < \min(k, m)\},$$

the first $k$ variants in the order $\sigma$ (all of $\iota$ when $k \ge m$).
