# Bayesian variable selection regression

Sparse Bayesian multiple regression of a phenotype on all genotyped variants at once, with spike-and-slab priors on the effects and priors on the sparsity and effect-size hyperparameters. It yields posterior inclusion probabilities for each variant and a posterior for the total proportion of phenotypic variance explained.
