# Admixture mapping

In a recently admixed population, each individual's local ancestry at a locus (the number of copies inherited from each source population) varies along the genome. A phenotype that depends on an allele whose frequency differs between the sources is then associated with local ancestry, and the strength and shape of that association constrain the frequencies of the causal allele in the sources.
