# Mendelian randomization with invalid instruments

Causal inference from genetic instruments when some variants violate the instrumental-variable assumptions through pleiotropy. Voting arguments identify one or several exposure effects when enough instruments are valid, and summary-statistic correlations of pleiotropic deviations identify auxiliary outcome traits whose invalid instruments overlap with those of the target outcome.
