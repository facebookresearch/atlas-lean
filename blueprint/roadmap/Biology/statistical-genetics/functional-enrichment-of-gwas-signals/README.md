# Functional enrichment of GWAS signals

Genome-wide association signals concentrate in regulatory elements of the cell types relevant to a trait. Testing that concentration requires controlling linkage disequilibrium and other features that correlate both with association strength and with annotation overlap. This topic states a logistic-regression enrichment model with feature matching.
