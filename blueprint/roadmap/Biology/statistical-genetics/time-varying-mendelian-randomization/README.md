# Time-varying Mendelian randomization

Mendelian randomization for an exposure that changes over the life course, where the target is an effect function $\beta(t)$ giving the outcome effect of the exposure at each time. Reducing exposure trajectories to a few functional principal components turns the problem into multivariable Mendelian randomization on time-invariant pseudo-exposures, whose estimates are mapped back to $\beta(t)$; identification of the shape of $\beta(t)$ requires genetic effects on the exposure that vary over time.
