# Root causal gene inference

Structural causal models linking genetic variants, gene expression and a phenotype, in which a gene is a root causal gene when the genetic and non-genetic factors acting first on its expression causally affect the phenotype. The conditional root causal effect isolates that contribution, can be written without recovering the unobserved error terms, and together with the causal graph over the phenotype's ancestors is identified from observational expression and genotype data under faithfulness and instrumental-variable style assumptions.
