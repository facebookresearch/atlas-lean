# Quasispecies dynamics with rare sudden mutations

Selection–mutation dynamics in which mutations arrive as rare jumps transferring a fraction of one type to another, rather than as a continuous flux. Expected frequencies solve nonlocal Kolmogorov equations and stay above the classical quasispecies trajectories.
