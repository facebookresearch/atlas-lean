# History graphs for genome evolution under parsimony

History graphs combine two relations on DNA bases: covalent adjacency (which bases are linked in a genome) and descent (which base was copied from which). Substitutions change base labels and double-cut-and-join (DCJ) operations change adjacencies. Exact parsimony cost of an arbitrary history graph is NP-hard, but cheap lower and upper bounds coincide on unambiguous history graphs, and a finite bounded set of such graphs contains every most-parsimonious interpretation.
