# Accessibility percolation on the unoriented hypercube

Accessibility percolation asks whether a fitness-increasing mutational path joins two genotypes in a random fitness landscape. On the binary hypercube with House-of-Cards (independent uniform) fitnesses and back mutations allowed, the existence of an accessible path to the fitness maximum has a sharp threshold in the fitness of the starting genotype, and for any graph accessibility is equivalent to first-passage site percolation with uniform vertex costs.
