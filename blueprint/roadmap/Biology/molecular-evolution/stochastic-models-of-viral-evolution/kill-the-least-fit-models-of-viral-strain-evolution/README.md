# Kill-the-least-fit models of viral strain evolution

Birth–death chains for the number of coexisting virus types, each new type carrying an independent uniform fitness, in which deaths remove the least fit type except for occasional random killings. The long-run behaviour of the maximal fitness and of the age of the fittest type distinguishes influenza-like trees (one long-lived dominant lineage) from HIV-like trees.
