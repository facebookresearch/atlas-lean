# Gauge fixing of sequence-function maps

A function on sequences of length $\ell$ over an alphabet of size $\alpha$ (a fitness or activity landscape) can be written as a sum of weights on subsequences in infinitely many ways. Choosing one representation is gauge fixing. Ridge-type regularizers in the overparameterized weight space simultaneously pick a gauge and impose a Gaussian process prior on the landscape, and the two roles can be separated and computed explicitly.
