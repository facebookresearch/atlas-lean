# Multivariate Bernoulli epistasis measures

Fitness values of the $2^L$ genotypes of $L$ biallelic loci can be read as a parameterisation of a multivariate Bernoulli (MVB) distribution. Under this reading the classical multiplicative (log-additive) epistasis measures are the MVB natural parameters, i.e. log-linear interaction terms, whereas the chimeric formula that mixes additive and multiplicative scales is a joint cumulant, which is not an appropriate interaction measure for binary variables beyond order two.
