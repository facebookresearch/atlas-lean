# Neutral molecular clock under spatial structure

In a population of fixed size and fixed spatial structure, the rate of neutral substitution equals the per-birth mutation rate only when site turnover and site reproductive value are uncorrelated. These articles define the site-level quantities, give the conditions under which the classical identity $K = u$ survives, and bound how far asymmetric structure can slow or accelerate the clock.
