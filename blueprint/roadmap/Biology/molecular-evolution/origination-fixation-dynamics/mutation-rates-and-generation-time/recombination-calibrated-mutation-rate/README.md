# Recombination-calibrated mutation rate

Estimating the long-term per-generation mutation rate from a single diploid genome by comparing local heterozygosity, which scales with mutation rate times coalescence time, with the genetic-distance scale over which it changes, which scales with recombination rate times the same coalescence time.
