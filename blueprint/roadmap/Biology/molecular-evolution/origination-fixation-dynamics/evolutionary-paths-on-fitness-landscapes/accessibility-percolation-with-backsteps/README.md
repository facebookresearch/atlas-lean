# Accessibility percolation with backsteps

Existence of fitness-increasing mutational paths in House-of-Cards landscapes on the hypercube when mutations may also revert earlier changes. The expected number of accessible paths has an explicit exponential rate, which yields critical starting fitnesses depending on the Hamming distance to the fittest genotype.
