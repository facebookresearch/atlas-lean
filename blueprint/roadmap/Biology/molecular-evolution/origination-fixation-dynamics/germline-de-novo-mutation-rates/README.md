# Germline de novo mutation rates

Pedigree sequencing counts de novo mutations directly, one generation at a time. Turning those counts into a per-site rate requires a denominator corrected for detection power, and attributing them to the mother or the father requires a model of which mutations can be phased. Poisson models with linear parental-age effects make both steps explicit.
