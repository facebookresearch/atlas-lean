# Ordered independent loss model of CRISPR spacers

A Markov model of CRISPR array evolution in which new spacers are inserted at the leader end at a constant rate and every present spacer is deleted independently at a constant rate, run along a genealogy. Its tractable distributions of shared-spacer positions yield explicit likelihood estimators for the spacer loss rate.
