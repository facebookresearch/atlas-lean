# Fitness–distance monotonicity and mutation-rate control

In a finite sequence space with Hamming distance, how much fitness tells about distance to an optimum determines how mutation rates should be controlled: when fitness is a function of distance, the optimal number of substitutions can be computed exactly from the combinatorics of Hamming spheres; when fitness carries only partial information, a weak, probabilistic monotonicity still holds near any optimum at which fitness is continuous, suggesting that mutation rates should rise as fitness falls.
