# Last-one-out gene distributions under differential loss

When genes present at the root of a species tree are lost independently along lineages and never regained, a gene on its way to extinction in a clade passes through a state in which only one leaf retains it. Such "last-one-out" patterns mimic recent lateral gene transfer. Their probability on a fixed tree is computed by a leaf-to-root recursion, and it can be surprisingly large for suitable loss rates.
