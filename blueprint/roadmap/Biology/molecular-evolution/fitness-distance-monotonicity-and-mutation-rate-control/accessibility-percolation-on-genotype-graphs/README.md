# Accessibility percolation on genotype graphs

Existence of fitness-increasing mutational paths between distant genotypes in House-of-Cards random fitness landscapes, on genotype spaces built as Cartesian powers of an arbitrary allele graph. A sharp threshold in the fitness difference between start and end genotypes separates asymptotically inaccessible from accessible pairs, and is computed from a matrix exponential of the allele graph.
