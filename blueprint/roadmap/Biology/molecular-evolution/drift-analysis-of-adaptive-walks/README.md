# Drift analysis of adaptive walks

Running-time analysis of adaptation in the weak-mutation regime, where a population is a single genotype on $\{0,1\}^n$ that accepts each point mutation with Kimura's fixation probability. Drift theorems from the analysis of randomized search heuristics turn bounds on the expected one-step progress toward the fitness peak into bounds on the expected number of mutations needed, revealing a logarithmic threshold in selection strength for additive landscapes.
