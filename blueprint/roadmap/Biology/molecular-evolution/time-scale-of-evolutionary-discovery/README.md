# Time scale of evolutionary discovery

How long does an evolving population need to discover a sequence with a new function, as a function of the sequence length $L$? Modeling evolution as an origination–fixation random walk in the space of $4^L$ sequences, with the function present on a broad peak of sequences close to a target center, the expected discovery time has a sharp threshold: it is exponential in $L$ if the peak radius is below $3L/4$ and polynomial if it is at least $3L/4$. Polynomially many independent searches, and many randomly placed peaks, do not remove the exponential barrier.
