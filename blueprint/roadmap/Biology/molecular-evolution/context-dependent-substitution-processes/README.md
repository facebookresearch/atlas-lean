# Context-dependent substitution processes

Interacting particle systems on $\mathbb{Z}$ modelling DNA evolution in which substitution rates at a site depend on neighbouring bases (for example CpG hypermutability). Coupling-from-the-past constructions give conditions for ergodicity, exponential convergence and decay of correlations.
