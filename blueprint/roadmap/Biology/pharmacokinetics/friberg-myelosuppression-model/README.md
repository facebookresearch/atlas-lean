# Friberg myelosuppression model

A semimechanistic pharmacodynamic model of drug-induced hematotoxicity with progenitor proliferation, a chain of maturation compartments and negative feedback from circulating cells. Its homeostatic equilibrium is stable only for sufficiently weak feedback, which constrains fitted parameters.
