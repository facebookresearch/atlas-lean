# Three-compartment pharmacokinetics

Anaesthetic drugs such as propofol distribute from plasma into a rapidly and a slowly equilibrating peripheral tissue compartment and act at an effect site linked to plasma by a first-order delay. The three-compartment mammillary model with an effect compartment is the structural model behind target-controlled infusion of these drugs.
