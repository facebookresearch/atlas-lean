# The steady-state concentration is a constant solution

For `Vmax > 0`, `Km > 0` and every `R < Vmax`, the constant function equal to the
[steady-state concentration](steady-conc.md) `C∞ = R * Km / (Vmax - R)` solves the
[saturable-elimination equation](is-solution.md) `C'(t) = R - Vmax * C(t) / (Km + C(t))` at every
time `t ≥ 0`. In the model `R ≥ 0`, so that `C∞ ≥ 0`.
