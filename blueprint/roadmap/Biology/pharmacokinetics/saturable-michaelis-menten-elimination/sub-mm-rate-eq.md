# The infusion-minus-elimination field in deviation form

For real numbers `Vmax`, `Km`, `R` and `c` with `Km + c ≠ 0` and `Vmax - R ≠ 0`, the right-hand side
of the saturable-elimination equation, written with the [steady-state concentration](steady-conc.md)
`C∞ = R * Km / (Vmax - R)`, is `R - Vmax * c / (Km + c) = -(Vmax - R) * (c - C∞) / (Km + c)`.
