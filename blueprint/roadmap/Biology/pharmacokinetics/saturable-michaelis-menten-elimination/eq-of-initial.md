# Two solutions with the same nonnegative start agree

Let `Vmax ≥ 0`, `Km > 0` and `R ≥ 0`, and let `C` and `D` solve the
[saturable-elimination equation](is-solution.md) `C'(t) = R - Vmax * C(t) / (Km + C(t))` at every
time `t ≥ 0`, with the same initial value `C(0) = D(0) ≥ 0`. Then `C(t) = D(t)` for every `t ≥ 0`.
