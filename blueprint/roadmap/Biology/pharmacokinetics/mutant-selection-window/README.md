# Mutant selection window

Pharmacodynamic theory of drug resistance in which wild-type and resistant pathogens have Hill dose–response curves for their basic reproductive ratio. Drug concentrations split into windows where neither strain grows, only the resistant mutant outcompetes the wild type, or the wild type itself grows; with first-order elimination the time spent in each window after a dose follows from the drug half-life.
