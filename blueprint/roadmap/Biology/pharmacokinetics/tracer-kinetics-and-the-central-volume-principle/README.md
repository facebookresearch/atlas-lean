# Tracer kinetics and the central volume principle

Models of how an injected tracer or contrast agent passes through a tissue region, used to quantify blood flow from the arterial input and the tissue concentration curve. They include the model-independent impulse-response (central volume) description and lumped compartmental exchange models.
