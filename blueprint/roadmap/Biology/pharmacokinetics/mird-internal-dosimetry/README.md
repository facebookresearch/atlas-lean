# MIRD internal dosimetry

The Medical Internal Radiation Dose (MIRD) formalism factors the absorbed dose from an administered radiopharmaceutical into a pharmacokinetic quantity, the time-integrated activity in each source region, and a physical quantity, the S value giving dose to a target per decay in a source. It is the basis of dosimetry for radiopharmaceutical therapy.
