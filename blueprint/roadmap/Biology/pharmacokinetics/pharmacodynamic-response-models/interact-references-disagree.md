# Interaction references are not interchangeable

For the normalized response curve `E(d) = d / (1 + d)` and unit doses of the same agent, the Bliss
reference `E_A + E_B - E_A * E_B` for the two single effects `E(1) = 1/2` is
`1/2 + 1/2 - 1/4 = 3/4`, while the same-curve dose-addition reference `E(1 + 1)` is `2/3`. The
effect `17/24` lies strictly between them, `2/3 < 17/24 < 3/4`, so it departs from the two
references with opposite signs: `17/24 - 3/4 < 0 < 17/24 - 2/3`.
