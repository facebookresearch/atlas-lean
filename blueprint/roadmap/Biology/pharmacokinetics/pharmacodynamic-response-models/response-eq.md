# Explicit Hill form of the response

For all real `E0`, `Emax`, `K`, `h` and `C`, the [response](response.md) is
`E0 + Emax * (C ^ h / (K ^ h + C ^ h))`, with real powers and the conventions stated on the response
page (`x / 0 = 0`, `x ^ 0 = 1`, `0 ^ t = 0` for `t ≠ 0`, `x ^ t = |x| ^ t * cos (π t)` for `x < 0`).
