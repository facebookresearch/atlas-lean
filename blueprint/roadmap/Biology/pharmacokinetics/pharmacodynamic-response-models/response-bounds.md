# The response lies between the baseline and baseline plus increment

For a half-saturation concentration `K > 0`, a Hill coefficient `h > 0`, a maximal increment
`Emax ≥ 0` and every baseline `E0`, the [response](response.md)
`E(C) = E0 + Emax * C ^ h / (K ^ h + C ^ h)` at every concentration `C ≥ 0` satisfies
`E0 ≤ E(C) ≤ E0 + Emax`.
