# For a positive increment the response is strictly increasing

For a half-saturation concentration `K > 0`, a Hill coefficient `h > 0`, a maximal increment
`Emax > 0` and every baseline `E0`, the [response](response.md)
`E(C) = E0 + Emax * C ^ h / (K ^ h + C ^ h)` is strictly increasing on the nonnegative
concentrations `C ≥ 0`.
