# At C = K the response is the baseline plus half the increment

For a half-saturation concentration `K > 0`, a Hill coefficient `h > 0`, a maximal increment
`Emax ≥ 0` and every baseline `E0`, the [response](response.md)
`E(C) = E0 + Emax * C ^ h / (K ^ h + C ^ h)` at `C = K` is the baseline plus half the maximal
increment: `E(K) = E0 + Emax / 2`.
