# Allometric scaling of pharmacokinetic parameters

Population pharmacokinetic models that must apply from neonates to obese adults scale compartment volumes and clearances with body size by power laws, typically with exponent $0.75$ for clearances, and correct the clearances of immature patients with a sigmoid maturation function of age. This yields a single covariate model whose parameters are referenced to a standard patient.
