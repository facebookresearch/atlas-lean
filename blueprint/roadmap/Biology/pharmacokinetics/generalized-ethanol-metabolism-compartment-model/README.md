# Generalized ethanol metabolism compartment model

A three-compartment (gut, blood, liver) model of ethanol absorption and clearance in which hepatic metabolism follows a general nonlinear rate law instead of Michaelis–Menten kinetics, together with a step-size condition under which its Euler discretization keeps the same dynamics.
