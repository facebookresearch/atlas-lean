# Equilibria blow up at the critical rate

Let `Vmax > 0` and `Km > 0`. For every level `M`, all infusion rates `R` close enough to `Vmax` from
below have all their nonnegative equilibria above `M`: there is `δ > 0` such that for
`Vmax - δ < R < Vmax`, every `c ≥ 0` with `Vmax * c / (Km + c) = R` satisfies `M < c`. For
`0 ≤ R < Vmax` the equilibrium is `c = R Km / (Vmax - R)`, which tends to `∞` as `R → Vmax⁻`.
