# A common nonzero offset shifts both visits

For real numbers `m1` and `m2`, the fixed parts of a subject's two visit log-values, and a nonzero
subject offset `b`, both shifted values differ from their fixed parts: `m1 + b ≠ m1` and
`m2 + b ≠ m2`. This is a statement about a common deterministic offset, not about statistical
dependence.
