# Optimal combination therapy for positive bilinear systems

Within-host evolution of drug-resistant HIV mutants under combination drug therapy is a positive (monotone) bilinear system: the mutant populations evolve linearly, and drug doses multiply the state by changing death rates. For a worst-case persistent-disturbance criterion, the optimal dosing is constant in time and solves a finite-dimensional convex program, and its robust version is no harder.
