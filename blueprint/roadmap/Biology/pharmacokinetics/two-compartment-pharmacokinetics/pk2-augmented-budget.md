# Columns of the augmented two-compartment generator sum to zero

For all real rates `k10`, `k12` and `k21`, every column of the
[augmented generator](pk2-augmented-generator.md) sums to zero: `-(k10 + k12) + k12 + k10 = 0`,
`k21 - k21 + 0 = 0` and `0 + 0 + 0 = 0`. So adjoining the elimination sink as a third state makes
the amount dynamics conservative.
