# Normalized washout identifies the elimination rate

For a bolus concentration `C(t) = (D / V) * exp (-(CL / V) * t)` with `D > 0`, `V > 0` and `CL ≥ 0`,
the normalized washout `C(t) / C(0)` at any time `t > 0` recovers exactly the rate `CL / V`:
`-log (C(t) / C(0)) / t = CL / V`. The dose need not be known.
