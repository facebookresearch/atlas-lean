# Without elimination a positive input gives no finite limit

For a positive input `R > 0` and every real `A₀`, the amount `A(t) = A₀ + R * t` of the
one-compartment model with no elimination, `k = 0`, constant input `R` and initial amount `A₀`, has
no finite limit as `t → ∞`: it does not tend to any real `L`.
