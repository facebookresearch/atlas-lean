# Forward uniqueness of the SIS infectives

Two solutions of the SIS system with the same population $S(0) + I(0) = N \ne 0$ and the same $I(0)$ have
the same $I$ on $[0, \infty)$.

Proof: both infective curves solve the scalar equation $x' = (\beta - \gamma) x - (\beta / N) x^2$; on
$[0, t]$ they are bounded, and the polynomial field is Lipschitz on a closed ball containing both, so the
uniqueness theorem for Lipschitz equations applies.
