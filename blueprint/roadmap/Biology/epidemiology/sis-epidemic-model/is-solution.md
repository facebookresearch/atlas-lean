# Solution of the SIS system

Functions $(S, I)$ solve the closed-population SIS system with transmission rate $\beta$, recovery rate
$\gamma$ and population size $N$ if, at every time $t \ge 0$, with two-sided derivatives,
$$S' = -\frac{\beta S I}{N} + \gamma I, \qquad I' = \frac{\beta S I}{N} - \gamma I.$$
