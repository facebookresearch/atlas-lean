# The explicit SIS solution is a logistic formula

For $\beta \ne 0$, $\beta \ne \gamma$ and $N \ne 0$, and for all real $I_0$ and $t$, the explicit SIS solution
equals the closed-form logistic function

$$x(t) = \frac{K I_0 e^{r t}}{K + I_0 (e^{r t} - 1)}$$

with rate $r = \beta - \gamma$ and carrying capacity $K = N (\beta - \gamma) / \beta = N (1 - \gamma / \beta)$,
which is negative when $0 < \beta < \gamma$ and $N > 0$. Where the denominator $K + I_0 (e^{r t} - 1)$
vanishes, the quotient is read as $0$, and so is the explicit SIS solution there. This is an equality of
functions; it says nothing about solving a differential equation at such points.
