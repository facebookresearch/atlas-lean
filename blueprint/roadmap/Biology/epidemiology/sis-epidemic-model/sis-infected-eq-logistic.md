# The explicit SIS solution is a logistic solution

For $\beta \ne 0$, $\beta \ne \gamma$ and $N \ne 0$, the explicit SIS solution is the logistic solution
$$x(t) = \frac{K I_0 e^{r t}}{K + I_0 (e^{r t} - 1)}$$
with rate $r = \beta - \gamma$ and carrying capacity $K = N (\beta - \gamma) / \beta = N (1 - \gamma / \beta)$,
which is negative when $0 < \beta < \gamma$ and $N > 0$.
