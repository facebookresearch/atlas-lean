# Endemic equilibrium of the SIS model

For every $\beta \ne 0$, the constant pair $(S, I) \equiv (N \gamma / \beta, \ N (1 - \gamma / \beta))$
solves the SIS system. For $N > 0$ and nonnegative rates, its infective level
$I^* = N (1 - \gamma / \beta)$ is biologically meaningful, $0 < I^* < N$, exactly when
$\beta > \gamma > 0$ (stated here without proof).
