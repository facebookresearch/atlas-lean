# Basic reproduction number of the SIS model

For $\beta \ge 0$ and $\gamma > 0$, let $F = (\beta)$ and $V = (\gamma)$, the derivatives at the
disease-free equilibrium of the new-infection rate and the recovery transfer. The basic reproduction
number, the spectral radius of the next-generation matrix $F V^{-1} = (\beta / \gamma)$, is
$R_0 = \beta / \gamma$: the next-generation matrix is the scalar matrix $(\beta / \gamma) I$, with spectrum
$\{\beta / \gamma\}$.
