# Endemic limit of the explicit SIS solution

If $0 \le \gamma < \beta$, $N \ne 0$ and $I_0 > 0$, then the explicit SIS solution tends to
$I^* = N (1 - \gamma / \beta)$ as $t \to \infty$. This includes $\gamma = 0$; when $\gamma > 0$, the
condition $\gamma < \beta$ says $R_0 = \beta / \gamma > 1$. The proof goes through the logistic solution and
its limit.
