# Basic reproduction number of the SIS model from the derivatives

For $\beta \ge 0$, $\gamma > 0$ and $N \ne 0$, with $F$ and $V$ built as the derivatives at $I = 0$ of
$\mathcal{F}(N, I) = \beta N I / N$ and $\mathcal{V}(I) = \gamma I$, the basic reproduction number is
$R_0 = \rho(F V^{-1}) = \beta / \gamma$.
