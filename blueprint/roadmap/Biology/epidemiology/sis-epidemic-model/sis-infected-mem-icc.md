# The explicit SIS solution stays between zero and the population size

For $\beta \ge 0$, $\gamma \ge 0$, $N > 0$, $I_0 \in [0, N]$ and $t \ge 0$, the explicit SIS solution stays
in $[0, N]$. For the upper bound, with $e^{r t} = 1 + r \varphi_r(t)$, the inequality
$I_0 e^{r t} \le N (1 + (\beta I_0 / N) \, \varphi_r(t))$ reduces to $I_0 - N \le \gamma I_0 \varphi_r(t)$.
