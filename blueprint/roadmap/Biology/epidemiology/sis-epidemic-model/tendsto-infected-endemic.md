# Endemic limit of every SIS solution

Along a solution of the SIS system with $0 \le \gamma < \beta$, $N > 0$, $S(0) + I(0) = N$ and
$I(0) > 0$, the infectives tend to $I^* = N (1 - \gamma / \beta)$ as $t \to \infty$. This includes
$\gamma = 0$; when $\gamma > 0$, the condition $\gamma < \beta$ says $R_0 = \beta / \gamma > 1$.
