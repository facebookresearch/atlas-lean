# Extinction for the explicit SIS solution

If $0 \le \beta \le \gamma$, $\gamma > 0$ (so $R_0 \le 1$), $N > 0$ and $I_0 \ge 0$, then the explicit SIS
solution tends to $0$ as $t \to \infty$. For $\beta < \gamma$ and $t \ge 0$, $0 \le I(t) \le I_0 e^{(\beta - \gamma) t}$;
for $\beta = \gamma$ and $t > 0$, $0 \le I(t) = I_0 / (1 + \beta I_0 t / N) \le N / (\beta t)$, an algebraic decay.
This includes $\beta = 0$, where $I(t) = I_0 e^{-\gamma t}$.
