# Global existence for the SIS system

For $\beta \ge 0$, $\gamma \ge 0$, $N > 0$ and every $I_0 \in [0, N]$, there is a solution $(S, I)$ of the
SIS system on $[0, \infty)$ with $I(0) = I_0$, $S(0) = N - I_0$ and $I(t) \in [0, N]$ for all $t \ge 0$;
explicitly, $I$ is the explicit SIS solution and $S = N - I$.
