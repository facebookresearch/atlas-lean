# Multi-strain diffusive SIS model

A susceptible–infected–susceptible model with several competing strains, spatially heterogeneous transmission and recovery rates, and diffusion of hosts. The local reproduction functions $R_i = \beta_i/\gamma_i$, the low-risk sets $\{R_i < 1\}$ and the diffusion rate of susceptibles determine extinction, competitive exclusion, and the effect of restricting movement.
