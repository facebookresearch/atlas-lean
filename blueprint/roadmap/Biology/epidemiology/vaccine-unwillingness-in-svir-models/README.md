# Vaccine unwillingness in SVIR models

Compartmental vaccination models usually apply the vaccination rate to all susceptibles. Splitting susceptibles into a willing class, from which vaccination draws, and an unwilling class changes the reproduction number and the endemic state in a way that cannot be mimicked by lowering the vaccination rate constant.
