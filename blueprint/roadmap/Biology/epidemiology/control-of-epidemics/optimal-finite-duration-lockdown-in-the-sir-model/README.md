# Optimal finite-duration lockdown in the SIR model

Minimization of the SIR epidemic final size by a social-distancing control of bounded intensity applied on a time window of prescribed length: the optimal policy is a single maximal-intensity lockdown whose start time is characterized by a scalar equation, and very long lockdowns reach herd immunity only if they are intense enough.
