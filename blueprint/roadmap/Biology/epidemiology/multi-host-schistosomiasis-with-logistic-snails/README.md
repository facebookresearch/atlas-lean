# Multi-host schistosomiasis with logistic snails

Compartmental models of the schistosome life cycle with free-living eggs and cercariae, a logistically growing intermediate snail host and several mammalian definitive hosts (for example humans, bovines and rodents), their reproduction number, disease-free thresholds and optimal combinations of sanitation, molluscicide, habitat modification and chemotherapy.
