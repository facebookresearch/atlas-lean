# Coinfection SIS dynamics

Compartmental models of two infections circulating in one population, with a coinfected class that can transmit both. Beyond reproduction-number thresholds, these models have boundary and interior equilibria whose degenerate bifurcations (cusps and Bogdanov-Takens points of codimension three) produce bistability and oscillations.
