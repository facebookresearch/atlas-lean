# Robust calibration of time-varying SEIR models

Fitting SEIR models with a parametric time-varying transmission rate to reporting-interval incidence by least absolute deviations (LAD) through the forward ODE solver, which limits the leverage of short reporting anomalies. Finite-horizon regularity of the model justifies standard M-estimation asymptotics: consistency and a median-regression type normal limit.
