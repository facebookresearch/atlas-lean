# Capacity-constrained dengue control

Host-vector dengue models in which interventions are limited by real constraints: hospital treatment saturates at a capacity and insecticide fogging is triggered only when case counts cross a threshold. The resulting piecewise-smooth (Filippov) systems keep the classical reproduction-number thresholds within each regime but add sliding dynamics and oscillations across regimes.
