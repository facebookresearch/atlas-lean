# Convex order

For measures $g_1$ and $g_2$ on $\mathbb{R}$, $g_1$ is smaller than $g_2$ in the convex order,
written $g_1 \le_{\mathrm{cx}} g_2$, when

$$\int \varphi \, dg_1 \le \int \varphi \, dg_2$$

for every convex function $\varphi \colon \mathbb{R} \to \mathbb{R}$ that is integrable with respect to
both $g_1$ and $g_2$ (Shaked–Shanthikumar 2007, §3.A).
