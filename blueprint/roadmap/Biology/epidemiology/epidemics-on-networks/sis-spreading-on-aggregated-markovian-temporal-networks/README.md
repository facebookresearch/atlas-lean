# SIS spreading on aggregated-Markovian temporal networks

Stability of networked SIS epidemics when edges switch on and off with arbitrary (phase-type) durations, modeled as functions of hidden Markov chains. Concentration inequalities give extinction thresholds involving only node-sized matrices.
