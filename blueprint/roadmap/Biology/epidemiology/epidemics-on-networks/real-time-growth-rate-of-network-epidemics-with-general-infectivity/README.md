# Real-time growth rate of network epidemics with general infectivity

Early growth of SIR epidemics on locally tree-like configuration networks with arbitrary random infectivity profiles. Repeated contacts along an edge are wasted, which distorts both the reproduction number and the timing of infections; the growth rate solves a Lotka–Euler equation built from the first-contact intensity.
