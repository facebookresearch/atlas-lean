# Contact-tracing likelihood for network epidemics

Bayesian inference for individual-level epidemic models on contact networks, where traced contacts of detected cases are observed only in contact-tracing windows. Treating contacts as a thinned Poisson process gives a likelihood that uses traced contacts where available and integrates them out elsewhere.
