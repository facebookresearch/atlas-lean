# Exact moment closure for SIR on networks

Markovian SIR dynamics on an arbitrary directed contact network generate a hierarchy of equations for the probabilities of subsystem states. Graph separation ("dynamical partitioning" by susceptible nodes) yields exact closures, so the hierarchy closes exactly at pair level on trees and, in general, at the size of the largest transmission block.
