# Age-structured models with nonlinear recidivism

Age-structured partial differential equation models of susceptible, infectious and temporarily recovered individuals, in which recovered individuals relapse at a rate proportional to the force of infection. An Euler–Lotka reproduction number governs local stability of the infection-free state, and a second threshold that ignores removal governs global stability. Between the two, relapse can produce a backward bifurcation.
