# Global air-travel metapopulation model

A metapopulation model of pandemic spread treats each city as a well-mixed compartmental epidemic and couples cities through the passenger flows of the airline network. Travel is a stochastic transport operator acting on every compartment, and the within-city scheme fixes the basic reproduction number.
