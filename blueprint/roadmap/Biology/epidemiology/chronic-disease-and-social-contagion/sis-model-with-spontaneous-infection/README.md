# SIS model with spontaneous infection

The SISa model adds to the SIS contagion model a rate at which susceptible individuals acquire the state spontaneously, independent of contacts. It is used for social contagion of behaviors and health states, and its steady state is positive for every transmission rate, so there is no epidemic threshold.
