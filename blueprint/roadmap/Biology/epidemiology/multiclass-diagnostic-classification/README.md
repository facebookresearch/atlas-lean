# Multiclass diagnostic classification

Probabilistic classification of diagnostic measurements (such as antibody assay readouts) into more than two classes. Class prevalences can be estimated without classifying individual samples by inverting bin probabilities, and the prevalence-weighted misclassification rate is minimized by assigning each measurement to the class with the largest prevalence-weighted density.
