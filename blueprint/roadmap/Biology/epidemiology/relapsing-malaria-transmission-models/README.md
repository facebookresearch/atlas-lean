# Relapsing malaria transmission models

Compartmental models of *Plasmodium vivax*, whose dormant liver-stage parasites (hypnozoites) cause relapses, with case management (blood-stage and radical cure) and imported infections. Equilibrium relations let the transmission rate be calibrated from observed incidence.
