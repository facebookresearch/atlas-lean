# Co-infection reproduction numbers

In models of two pathogens circulating in one host population, possibly with an animal reservoir, the infection-free equilibrium has one reproduction number per pathogen and per host population. When the pathogens interact only through co-infected classes, the next-generation matrix at the infection-free state is block-triangular and the overall threshold is the largest of the single-pathogen reproduction numbers.
