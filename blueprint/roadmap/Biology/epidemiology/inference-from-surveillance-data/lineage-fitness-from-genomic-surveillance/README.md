# Lineage fitness from genomic surveillance

Counts of sequenced pathogen genomes by lineage, region and time carry information about which lineages are growing. A multinomial logistic model turns those counts into relative exponential growth rates, and writing each lineage's growth rate as a sum of mutation effects lets the model share strength across lineages that acquire the same mutation and forecast new lineages from their mutations.
