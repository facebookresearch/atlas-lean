# Density of the rate-one exponential law

The rate-`1` exponential density is the function `p : ℝ → [0, ∞]` given by

`p(x) = exp(-x)` for `x ≥ 0`, and `p(x) = 0` for `x < 0`,

so that `p(0) = 1`. It is a density of the exponential law `Exp(1)` with rate `1` with respect to
Lebesgue measure: `Exp(1)` gives each Borel set `A ⊆ ℝ` the mass `∫_A p(x) dx`.
