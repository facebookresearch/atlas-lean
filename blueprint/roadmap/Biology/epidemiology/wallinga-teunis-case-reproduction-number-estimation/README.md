# Wallinga–Teunis case reproduction number estimation

The case (cohort) reproduction number counts the eventual secondary infections of the people infected at a given time. From a line list of infection or onset times and a generation-interval distribution, the Wallinga–Teunis method splits each case among its possible infectors and sums those shares by infector. In expectation the estimate is the instantaneous reproduction number smoothed forward over the generation interval.
