# Surveillance sensor selection for outbreak detection

Choosing which individuals and locations to test, and how often, so that simulated outbreaks of an infection are detected with high probability under a testing budget. Detection probability over a library of simulated cascades is a monotone submodular function of the monitoring-rate vector, so greedy allocation carries approximation guarantees.
