# Epidemic mean-field games with presymptomatic spread

Mean-field game models in which each agent chooses a level of social activity, trading the reward of activity against the health cost of infection, while the population's aggregate infectious activity drives transmission. When states are fully observed, infected agents isolate and transmission stops. When the presymptomatic state is hidden, decisions depend on a filtered belief of being infected.
