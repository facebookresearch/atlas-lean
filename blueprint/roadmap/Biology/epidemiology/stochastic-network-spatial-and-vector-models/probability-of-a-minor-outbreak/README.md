# Probability of a minor outbreak

Near the disease-free equilibrium a continuous-time Markov chain epidemic model is approximated by a branching process, single-type for the SIR model and multitype for host–vector models. The probability that a few introduced infectives fail to start a major outbreak is then the minimal fixed point of the offspring generating functions, which can be written in closed form in terms of $R_0$.
