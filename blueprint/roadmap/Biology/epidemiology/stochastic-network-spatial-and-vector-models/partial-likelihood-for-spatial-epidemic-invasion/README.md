# Partial likelihood for spatial epidemic invasion

Inference of how an epidemic moves between cities from the order of local epidemic onset times:
a semi-parametric hazard of invasion that depends on population size and on distance or mobility
flows to already infected cities, estimated by a Cox-type partial likelihood that never estimates
the baseline hazard.
