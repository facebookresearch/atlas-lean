# Assortativity of vaccination status and coverage-preserving swaps

Let $G$ be a finite directed network whose nodes carry a type from a finite set (for example vaccinated or unvaccinated, or positive or negative vaccine sentiment). Let $e_{ij}$ be the fraction of edges that go from a node of type $i$ to a node of type $j$, so $\sum_{i,j} e_{ij} = 1$, and let $a_i = \sum_j e_{ij}$ and $b_j = \sum_i e_{ij}$ be the type distributions at edge tails and heads. If $\sum_i a_i b_i < 1$, the assortativity coefficient

$$r = \frac{\sum_i e_{ii} - \sum_i a_i b_i}{1 - \sum_i a_i b_i}$$

satisfies $r \le 1$, with $r = 1$ exactly when every edge joins nodes of the same type, and $r = 0$ whenever $e_{ij} = a_i b_j$ for all $i, j$ (types mixed at random given the marginals).

Clustering of vaccination at fixed coverage is generated by the following procedure. Start from a uniformly random assignment of vaccination status with the desired coverage, so that $r \approx 0$. Repeatedly pick a vaccinated node and an unvaccinated node uniformly at random and swap their statuses; keep the swap only if it strictly increases $r$, and stop once $r$ exceeds the target. Every accepted or rejected swap leaves the number of vaccinated nodes unchanged, so coverage is preserved exactly while $r$ increases monotonically along the accepted swaps.

## Expansion

The numerator compares the observed fraction of within-type edges with its value $\sum_i a_i b_i$ under random mixing, and the denominator is the largest value the numerator can take, reached when $\sum_i e_{ii} = 1$; this gives $r \le 1$. The lower bound is $r \ge -\sum_i a_i b_i / (1 - \sum_i a_i b_i)$, which equals $-1$ only for symmetric marginals, so $r = -1$ is not always attainable. Applied to a follower network of users expressing vaccine sentiment, the coefficient was $r = 0.144$, more than an order of magnitude above the maximum over 10,000 random relabellings of the same network. Feeding coverage-preserving swaps into stochastic SEIR simulations on an empirical school contact network at coverage $0.624$ showed that the probability of large outbreaks rises with $r$: unvaccinated nodes clustered together form connected pockets in which herd protection fails even though average coverage is unchanged, an effect strongest when coverage is close to the herd-immunity threshold computed under random mixing.
