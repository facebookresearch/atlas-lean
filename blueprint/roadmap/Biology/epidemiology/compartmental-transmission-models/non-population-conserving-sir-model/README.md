# Non-population-conserving SIR model

An SIR variant in which removed individuals leave the mixing population, so incidence is normalized by the current number $S + I$ of susceptible and infectious individuals rather than by a conserved total. The ratio $S/I$ then evolves linearly, which gives closed-form epidemic curves, peak size and peak time.
