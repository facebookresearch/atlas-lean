# Viral infection of Varroa-infested honeybee colonies

Compartmental model of a honeybee colony in which a virus (such as deformed wing virus) spreads among bees both directly and through *Varroa destructor* mites, which switch between virus-free and virus-carrying states while feeding. The model is well posed, keeps the bee population between explicit bounds, and has explicit boundary equilibria with feasibility thresholds.
