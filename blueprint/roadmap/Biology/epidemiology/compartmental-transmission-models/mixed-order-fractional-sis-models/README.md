# Mixed-order fractional SIS models

SIS epidemic models in which the susceptible and infected classes evolve with different (fractional or ordinary) orders of differentiation, so that total population is no longer conserved. Covers the Caputo–Fabrizio case, where an exponential memory kernel yields a first integral, a reduction to one scalar equation, explicit fractional endemic equilibria and recovery of the fractional order from long-run data.
