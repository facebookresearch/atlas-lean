# SIRS model with density-dependent mortality

SIRS transmission with loss of immunity, partial vertical transmission, disease-induced mortality and a general density-dependent natural death rate, so that the host population is not constant. Passing to fractions decouples the epidemiology from the population size, and Lyapunov functions give global stability of both the disease-free and the endemic state.
