# Vector-borne disease with infective immigration

Host–vector transmission models with an arbitrary number of infectious host stages, forward (aggravation) and backward (amelioration) transitions between stages, and a recruitment flow that brings latent, infectious and recovered hosts into the population. Infective immigration removes the disease-free equilibrium; the classification of equilibria and their global stability then depend on which stages are imported and which stages transmit to vectors.
