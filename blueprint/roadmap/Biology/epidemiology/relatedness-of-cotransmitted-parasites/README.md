# Relatedness of cotransmitted parasites

A malaria parasite must mate in the mosquito before founding the next human infection, so the strains a single bite delivers are the products of a few meioses rather than independent draws from the population. Counting which parental strains those meioses used fixes how related cotransmitted parasites are, and makes relatedness a function of the complexity of the source infection and of the number of oocysts.
