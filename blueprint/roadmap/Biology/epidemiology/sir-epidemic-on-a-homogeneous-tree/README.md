# SIR epidemic on a homogeneous tree

A discrete-space SIR model on the infinite $(n+1)$-regular tree with time-varying infection rates, arbitrary recovery-time distributions and external (self-) infection. The tree structure makes the time to infection exactly computable through a nonlinear renewal equation, and the high-degree limit yields a master equation for the susceptible fraction.
