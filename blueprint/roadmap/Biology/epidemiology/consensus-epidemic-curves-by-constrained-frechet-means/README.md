# Consensus epidemic curves by constrained Fréchet means

Summarizing several SEIR-type projections of the same epidemic into one representative trajectory. Pointwise means flatten peaks when curves are misaligned and need not solve any compartmental model; a power Fréchet mean in a Sobolev space, constrained to SEIR dynamics and combined with time-shift registration, exists, is unique for $q > 1$ in the convex case, and is robust to an outlying curve for $q = 1$.
