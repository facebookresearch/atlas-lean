# Consequences of under-reporting in count autoregressions

Poisson autoregressions of case counts mirror discrete-time transmission models, with the autoregressive coefficient acting as a reproduction number. When cases are binomially under-reported but the model is fitted as if reporting were complete, the reproduction number is underestimated and the endemic component can be biased in either direction, with explicit asymptotic thresholds.
