# Reverse-time sequential Monte Carlo for epidemic source inference

Inferring where an observed large outbreak started, when only the final configuration of infected individuals is seen, is a rare-event problem for a stopped Markov chain. Building trajectories backwards in time from the observed state, with proposals given by approximate conditional sampling distributions, avoids the need for a reaction coordinate and integrates over the unknown origin automatically.
