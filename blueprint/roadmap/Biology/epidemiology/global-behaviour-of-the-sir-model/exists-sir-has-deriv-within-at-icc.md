# Local existence for the SIR compartments

For all real parameters $\beta, \gamma, N$ and every initial state $(S_0, I_0, R_0)$, there are
$\varepsilon > 0$ and functions $S, I, R$ with these initial values that satisfy the SIR equations on
$[-\varepsilon, \varepsilon]$, with derivatives within the interval (one-sided at the endpoints
$\pm\varepsilon$).
