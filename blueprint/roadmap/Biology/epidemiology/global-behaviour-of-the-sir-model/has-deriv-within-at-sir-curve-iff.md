# Derivative of a packed SIR curve within a set

For a set $s \subseteq \mathbb{R}$ and a point $t$, the packed curve $(S, I, R)$ has derivative
$F(S(t), I(t), R(t))$ at $t$ within $s$, where $F$ is the SIR vector field, if and only if the three SIR
equations hold at $t$ with derivatives within $s$.
