# SIR vector field

The Kermack–McKendrick SIR vector field on $\mathbb{R}^3$, with coordinates $(S, I, R)$, transmission
rate $\beta$, removal rate $\gamma$ and population size $N$, is

$$F(S, I, R) = \Bigl(-\frac{\beta S I}{N}, \ \frac{\beta S I}{N} - \gamma I, \ \gamma I\Bigr),$$

where $\beta S I / N$ is taken to be $0$ when $N = 0$. The field is autonomous: it does not depend on
time.
