# Spatial host–vector epidemic models

Reaction–diffusion compartmental models of vector-borne plant and animal pathogens in which hosts are fixed in space and only vectors move (by heterogeneous diffusion), as for insect-transmitted bacteria such as *Xylella fastidiosa*. With no host or vector renewal, every host is eventually infected and the vector density relaxes to the diffusion-weighted equilibrium.
