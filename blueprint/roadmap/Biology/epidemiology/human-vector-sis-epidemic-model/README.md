# Human-vector SIS epidemic model

A three-dimensional SIS-type model for vector-borne diseases with infected humans, non-carrier vectors and carrier vectors. Monotone-systems arguments give a sharp threshold for global convergence to the disease-free or endemic equilibrium, and the threshold turns the cheapest combination of vector control and personal protection into a constrained static optimization with explicit solution.
