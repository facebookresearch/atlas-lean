# Class-age-structured epidemic models

Epidemic models in which individuals carry a continuous class age, such as time since infection, latency age or time since recovery, giving transport equations coupled to ordinary differential equations. Reproduction numbers are integrals of survival-weighted transition kernels, and global threshold results use asymptotic smoothness and Volterra-type Lyapunov functionals.
