# Coupled disease–behavior models

Epidemic models in which individuals change behavior in response to the epidemic, here through imitation dynamics from evolutionary game theory. When behavior adapts much faster than transmission, geometric singular perturbation theory reduces the dynamics to SIR arcs joined by behavioral switches whose timing is set by entry–exit functions.
