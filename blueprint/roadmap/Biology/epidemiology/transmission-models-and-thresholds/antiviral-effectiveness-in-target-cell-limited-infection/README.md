# Antiviral effectiveness in target-cell-limited infection

In an acute target-cell-limited infection, an antiviral that lowers the infection or replication rate shifts the within-host reproduction number at the moment treatment starts. Whether the drug brings the viral peak forward depends on whether it pushes this number below one, which defines a critical, time-dependent inhibition level; sub-critical treatment started early can paradoxically delay the peak.
