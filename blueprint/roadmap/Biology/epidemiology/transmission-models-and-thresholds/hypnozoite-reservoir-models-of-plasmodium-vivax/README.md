# Hypnozoite reservoir models of Plasmodium vivax

*Plasmodium vivax* leaves dormant liver-stage parasites (hypnozoites) that later activate and cause relapses, so each infective bite adds both a primary infection and a batch of latent future infections. Treating hypnozoites and blood-stage broods as customers in a network of infinite-server queues gives an explicit generating function for each host's hypnozoite burden and multiplicity of blood-stage infection (MOB); coupling it to mosquito dynamics reduces an infinite-compartment population model to one integrodifferential equation with a sharp transmission threshold.
