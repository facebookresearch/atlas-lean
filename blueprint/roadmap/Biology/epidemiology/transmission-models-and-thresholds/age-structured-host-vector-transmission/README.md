# Age-structured host–vector transmission

Vector-borne transmission models in which the human host population is split into age classes linked by maturation, each with its own susceptibility, progression and recovery rates, while infection passes only between humans and vectors. The reproduction number is the spectral radius of a bipartite next-generation matrix and is a geometric mean of the vector-to-host and host-to-vector numbers.
