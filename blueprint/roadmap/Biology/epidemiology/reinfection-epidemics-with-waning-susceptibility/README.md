# Reinfection epidemics with waning susceptibility

In epidemic models with infection-age dependent infectivity and progressive waning of immunity, every individual carries a random infectivity curve and a random susceptibility curve after each infection, so individuals can be reinfected repeatedly. The large-population limit is a closed pair of renewal-type equations for the mean susceptibility and the total force of infection, valid as soon as the maximal infectivity is integrable.
