# Backward bifurcation in epidemic models

Coexistence of a stable disease-free equilibrium with stable endemic equilibria when the reproduction number is below one, detected from the quadratic endemic-equilibrium equation or from the center-manifold bifurcation coefficients, typically caused by imperfect vaccines, reinfection or co-infection.
