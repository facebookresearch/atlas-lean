# Spillover models with psychological incidence

Zoonotic spillover models in which an animal reservoir drives human infection without human-to-human spread, with saturating reservoir incidence and a nonmonotone human incidence reflecting behavioural (psychological) response; threshold dynamics via Lyapunov and Bendixson–Dulac arguments.
