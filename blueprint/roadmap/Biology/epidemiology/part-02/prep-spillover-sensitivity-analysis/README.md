# PrEP spillover sensitivity analysis

Quantifying how pre-exposure prophylaxis (PrEP) given to one HIV risk group changes infections in other groups (spillover) in a multigroup compartmental transmission model. Forward parameter sensitivities of the infected compartments with respect to PrEP uptake give the direct and spillover effects over a time horizon and an explicit approximation of the number needed to treat.
