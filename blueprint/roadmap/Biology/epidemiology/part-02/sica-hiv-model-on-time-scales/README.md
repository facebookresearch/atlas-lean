# SICA HIV model on time scales

The SICA model of HIV/AIDS transmission (susceptible, HIV-infected without treatment, chronic under treatment, AIDS) written as a dynamic equation on an arbitrary time scale, which unifies the continuous-time model, its discrete-time versions and hybrid settings. With an almost periodic force of infection the model is permanent and, under a dominance condition on the rates, has a unique globally attracting almost periodic solution.
