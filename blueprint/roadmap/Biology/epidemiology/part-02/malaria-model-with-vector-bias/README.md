# Malaria model with vector bias

Host–vector malaria transmission in which mosquitoes preferentially bite infected humans (vector bias $p$), with frequency-dependent biting, saturating hospital treatment and fumigation. The vector bias parameter enters the basic reproduction number and, together with treatment saturation, controls whether endemic equilibria can coexist with a stable disease-free state.
