# SIRS with immune boosting and delays

Epidemic models in which infection-induced immunity lasts a fixed time $\tau$ but re-exposure of immune hosts resets the immunity clock (boosting). Boosting turns the SIRS model into a delay system with a constant and a distributed delay; the threshold behavior is classical, but the endemic equilibrium can lose and regain stability several times as the immunity duration varies.
