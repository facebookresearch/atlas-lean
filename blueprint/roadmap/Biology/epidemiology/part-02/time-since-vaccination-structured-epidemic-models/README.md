# Time-since-vaccination structured epidemic models

Epidemic models in which recovered and vaccinated individuals carry the time elapsed since immunization as a structure variable. Protection can then wane at vaccine-specific rates, end after prescribed durations, and be combined across several concurrently administered vaccines and host age classes.
