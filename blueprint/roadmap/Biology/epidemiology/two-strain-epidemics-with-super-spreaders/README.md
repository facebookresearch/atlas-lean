# Two-strain epidemics with super-spreaders

Compartmental models in which an ancestral strain and a more transmissible variant co-circulate with a super-spreader class, leaky waning vaccination and hospitalization. Covers the closed-form basic reproduction number obtained from a single-row next-generation matrix and threshold results for epidemic decay under time-varying transmission and vaccination.
