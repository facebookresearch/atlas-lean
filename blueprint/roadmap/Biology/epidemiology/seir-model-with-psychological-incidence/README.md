# SEIR model with psychological incidence

SEIR dynamics with the non-monotone incidence $\beta_0 SI/(1 + \alpha I^2)$, in which contacts fall as prevalence rises (behavioural response or government measures of strength $\alpha$). The threshold is unchanged by $\alpha$, while the endemic level and the epidemic peak depend on it, and $\alpha$ can serve as a feedback control input.
