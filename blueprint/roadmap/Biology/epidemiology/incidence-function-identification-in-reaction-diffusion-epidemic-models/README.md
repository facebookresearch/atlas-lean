# Incidence-function identification in reaction–diffusion epidemic models

Selecting the incidence function of a spatial SIR model from data by writing the incidence as a convex combination of candidate functions (bilinear, saturated, Beddington–DeAngelis, …) and fitting the mixing weights by Tikhonov-regularized least squares against observed susceptible and infected densities. The weights then quantify each candidate's contribution to transmission.
