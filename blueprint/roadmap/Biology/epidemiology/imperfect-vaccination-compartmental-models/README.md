# Imperfect vaccination compartmental models

Compartmental models in which vaccinated individuals retain reduced susceptibility (leaky vaccines), giving a vaccination-dependent reproduction number, a minimal vaccine efficacy below which no vaccination rate can eliminate the disease, and a critical vaccination rate above it.
