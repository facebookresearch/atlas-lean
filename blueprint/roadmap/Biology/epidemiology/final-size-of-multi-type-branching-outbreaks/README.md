# Final size of multi-type branching outbreaks

The distribution of the total number of infections, by type, in a minor outbreak modeled by a multi-type Galton–Watson process. Covers the final-size generating-function equation, the unique identification of its relevant root inside the unit polydisc, error bounds for fixed-point iteration, and parameter differentiability for likelihood-based inference.
