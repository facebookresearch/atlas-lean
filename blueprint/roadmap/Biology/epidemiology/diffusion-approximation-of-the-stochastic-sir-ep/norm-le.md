# A priori bound on a fluctuation path

Let $\beta, \gamma \ge 0$ and $B, k$ real with $B \ge 0$, let $x$ be continuous on $[0, T]$ with
$\|x(t)\| \le B$ there, and let $U$ be a [fluctuation path](is-fluctuation-path.md): $U$ is
continuous on $[0, T]$ and $U(t) = u_0 + (m(t) - m(0)) + \int_0^t DF(x(s))\, U(s)\, ds$ for
$t \in [0, T]$, with $\|u_0\| \le k$ and $\|m(t)\| \le k$ for $t \in [0, T]$, with the sup norm
$\|h\| = \max(|h_1|, |h_2|)$ on $\mathbb{R}^2$. Then for every $t \in [0, T]$

$$\|U(t)\| \le 3 k\, e^{(2 \beta B + \gamma) t};$$

the increment $m(t) - m(0)$ contributes $2 k$.
