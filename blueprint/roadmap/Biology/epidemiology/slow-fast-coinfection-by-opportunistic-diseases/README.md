# Slow–fast coinfection by opportunistic diseases

Coinfection models in which a long-term primary disease (an SIS process with demography and stage-dependent competition) renders hosts susceptible to a fast opportunistic disease that spreads only among primary-infected hosts; approximate aggregation over the fast time scale collapses the three-dimensional system to a planar primary-disease model whose coefficients carry the opportunistic prevalence.
