# Multilayer bond percolation with quarantine

Early epidemic spread on a locally tree-like contact network whose edges fall into several classes (household, work, casual) with different transmission probabilities, and where each infected individual is isolated with a fixed probability. Probability generating functions of the layer degree distributions give the reproduction number, the extinction probability and the isolation fraction needed for containment.
