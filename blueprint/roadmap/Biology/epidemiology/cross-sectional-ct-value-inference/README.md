# Cross-sectional Ct-value inference of epidemic trajectories

RT-qPCR cycle-threshold (Ct) values encode viral load, and viral load depends on the time since infection. A random cross-section of test results therefore carries information about the recent incidence curve: the observed Ct distribution is a mixture, over infection ages, of the age-specific Ct laws, weighted by the daily infection probabilities.
