# Transmission trees on a fixed phylogeny

With complete sampling and a complete transmission bottleneck, the transmission trees compatible with a known pathogen phylogeny correspond to partitions of the phylogeny's nodes into connected parts, one per host, each containing that host's tip. Simple postorder recursions count these partitions and a preorder pass samples them uniformly.
