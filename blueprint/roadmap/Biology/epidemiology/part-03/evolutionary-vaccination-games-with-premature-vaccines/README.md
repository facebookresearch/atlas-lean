# Evolutionary vaccination games with premature vaccines

Population games in which agents decide whether to take a new, possibly scarce vaccine with uncertain side effects while an SIS epidemic is ongoing. Responses depend on reported infection and vaccination levels, and evolutionary stability decides whether vaccination persists and at what endemic level.
