# SIS epidemics on hypergraphs

Susceptible–infected–susceptible dynamics in which individuals meet in groups (households, workplaces, venues) encoded as hyperedges, and the infection pressure from a hyperedge is a possibly nonlinear function of the number of infected members. Spectral conditions on the hyperedge co-membership matrix guarantee extinction, both for the mean-field equations and for the exact stochastic process.
