# Within-host HIV model with homeostatic proliferation

Target-cell-limited models of early HIV infection extended by a saturating, virus-stimulated homeostatic proliferation term for CD4+ T-cells. The extra term introduces a second reproduction number and produces bistability of viral clearance and persistent infection as well as Hopf bifurcations.
