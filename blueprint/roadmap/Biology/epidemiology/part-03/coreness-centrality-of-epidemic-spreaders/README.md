# Coreness centrality of epidemic spreaders

Which individuals in a contact network seed the largest outbreaks? In susceptible-infected-removed (SIR) spreading on a network, the expected final outbreak size started from a single node is better predicted by the node's position in the $k$-core decomposition (its coreness) than by its degree. Degree, the node H-index, and coreness form one family of centralities linked by iterating a local operator, which lets coreness be computed from neighbor information alone.
