# Adaptive link weights in network SIS games

On a directed contact network, each node can temporarily weaken its outgoing links to reduce its own infection risk at a cost for deviating from its preferred connectivity. Coupling this choice to the deterministic N-intertwined SIS dynamics gives an N-player differential game whose Nash equilibrium link weights follow an explicit saturation rule driven by the costates.
