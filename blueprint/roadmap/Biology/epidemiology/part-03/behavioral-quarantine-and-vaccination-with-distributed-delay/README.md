# Behavioral quarantine and vaccination with distributed delay

Epidemic models in which voluntary isolation and vaccination respond to a memory-weighted history of infections. Behaviour leaves the basic reproduction number unchanged but can create multiple endemic equilibria and delay-induced Hopf bifurcations producing recurrent epidemic waves.
