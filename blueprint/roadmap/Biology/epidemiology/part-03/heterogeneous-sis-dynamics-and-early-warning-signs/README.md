# Heterogeneous SIS dynamics and early warning signs

SIS models in which every individual carries a heterogeneity state (contact behavior, susceptibility, recovery) drawn from a general measure space. With a suitably weighted basic reproduction number, the heterogeneous model has exactly the same global threshold behavior as the homogeneous one; adding noise and a slowly varying transmission rate turns the approach to the outbreak threshold into a critical-slowing-down problem with variance scaling laws.
