# SAIR model on heterogeneous networks

A degree-based mean-field SAIR model separates asymptomatic and symptomatic infection on an uncorrelated contact network: new infections become asymptomatic with probability $\alpha$ or symptomatic otherwise, and asymptomatic individuals either recover or develop symptoms. Its basic reproduction number factorises into an individual-level term, summing the contributions of the asymptomatic and symptomatic stages, times the network amplification factor $\langle k^2\rangle/\langle k\rangle$.
