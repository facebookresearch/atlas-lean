# Non-Markovian SIR on configuration networks

On large configuration-model networks, SIR epidemics with arbitrary (non-exponential) distributions of the time to transmission and of the infectious period are described exactly, in the infinite-network limit, by a message-passing equation for the probability that a neighbour has not yet transmitted. An edge-based compartmental model with age-of-infection structure, built on hazard functions, is equivalent to it and reduces to classical pairwise models in the Markovian or fixed-period cases.
