# Monotone-risk biomarker tests

For a diagnostic test that calls positive when a continuous biomarker exceeds a cut-off, a strictly increasing risk function forces the ROC curve to be concave. Concavity fixes the directions in which sensitivity, specificity and the predictive values move as the cut-off varies.
