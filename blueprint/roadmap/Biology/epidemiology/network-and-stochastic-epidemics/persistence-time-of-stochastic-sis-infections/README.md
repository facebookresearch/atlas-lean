# Persistence time of stochastic SIS infections

In the stochastic SIS model with $R_0 > 1$ in a population of size $N$, the mean time from quasi-stationarity to extinction grows like $e^{N A}$. The exponent $A$ (the action of the WKB / large-deviation optimal extinction path) depends on how infectivity and susceptibility vary across individuals; for one-sided heterogeneity it has a closed form, and more heterogeneity always shortens persistence.
