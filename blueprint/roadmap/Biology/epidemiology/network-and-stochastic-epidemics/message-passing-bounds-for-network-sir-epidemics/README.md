# Message-passing bounds for network SIR epidemics

Message-passing (cavity) equations for stochastic SIR epidemics on arbitrary contact graphs with general, positively correlated contact times and infectious periods. They give rigorous one-sided bounds on each individual's infection probability, are exact on trees, and contain the pairwise and Kermack–McKendrick models as special or limiting cases.
