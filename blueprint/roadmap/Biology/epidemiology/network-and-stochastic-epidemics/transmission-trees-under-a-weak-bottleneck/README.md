# Transmission trees under a weak bottleneck

Reconstruction of who-infected-whom from a timed pathogen phylogeny when a single transmission event may pass several strains (a weak transmission bottleneck). Each host is infected once by a unique infector, so a host labelling of the phylogeny induces a weighted transmission tree; the inference problem becomes computationally hard, while summarizing many candidate trees by a consensus tree stays polynomial.
