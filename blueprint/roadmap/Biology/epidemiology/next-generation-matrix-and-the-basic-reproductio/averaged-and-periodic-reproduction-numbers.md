# Averaged and periodic reproduction numbers

This page covers a research target from Wang and Zhao (2008). For a periodic model in the setting of the [next-generation operator in a periodic environment](periodic-next-generation-operator.md), the reproduction number $[\mathcal{R}_0]$ of the autonomous system with time-averaged coefficients is in general different from the periodic $\mathcal{R}_0 = \rho(L)$, and can be smaller or larger. The target is an explicit model from the source in which the two numbers differ, stated with both values.

## Depends on

- [Basic reproduction number of the next-generation matrix](r0.md)
- [Next-generation operator in a periodic environment](periodic-next-generation-operator.md)

## Expansion

Fix the example from the source, compute $[\mathcal{R}_0] = \rho(\bar F \bar V^{-1})$ from the averages $\bar F, \bar V$ over one period, and show that $\rho(L) \ne [\mathcal{R}_0]$, as a separate statement.

Prerequisites:

- [Next-generation operator in a periodic environment](periodic-next-generation-operator.md)
- [Basic reproduction number of the next-generation matrix](r0.md)
