# Basic reproduction number of the next-generation matrix

For real square matrices $F$ and $V$ indexed by a finite set, the basic reproduction number is the
spectral radius

$$R_0 = \rho(F V^{-1}),$$

the largest modulus of a complex eigenvalue of the next-generation matrix $F V^{-1}$ (van den
Driessche–Watmough 2002, Eq. (4)). When $V$ is singular, $V^{-1}$ is taken to be the zero matrix, so
$R_0 = 0$; a nonsingular M-matrix $V$ is invertible. For the empty index set, $R_0 = 0$.
