# Eigenvalues of a block lower-triangular matrix

Let $A$, $C$ and $D$ be real matrices of sizes $\iota \times \iota$, $\kappa \times \iota$ and
$\kappa \times \kappa$, for finite index sets $\iota$ and $\kappa$. A complex number $\mu$ is an
eigenvalue of the block lower-triangular matrix $\begin{pmatrix} A & 0 \\ C & D \end{pmatrix}$ if and
only if it is an eigenvalue of $A$ or an eigenvalue of $D$.
