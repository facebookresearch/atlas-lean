# Hepatitis C transmission with waning vaccination

Compartmental models of hepatitis C virus transmission with exposed, acute, chronic and treated stages and an imperfect vaccine whose protection wanes. Covers the reproduction number, the coexistence of endemic equilibria below threshold (backward bifurcation), and its removal by a perfect vaccine.
