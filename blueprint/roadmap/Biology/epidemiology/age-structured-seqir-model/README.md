# Age-structured SEQIR model

Age-structured (McKendrick–von Foerster) epidemic model with exposed and quarantined classes and separable age-dependent mixing. It gives an explicit reproduction number summing direct and quarantine-mediated transmission routes, a Lyapunov proof of elimination for $R_0 \le 1$, and optimal vaccination supported on at most three ages.
