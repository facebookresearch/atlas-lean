# Deterministic critical community size

A deterministic counterpart of Bartlett's critical community size: in the SIR model with demography, an infection fades out if the infected density falls below one individual, $1/N$, during the oscillatory approach to the endemic equilibrium. The resulting threshold population size depends on the epidemic time scales, not only on $R_0$, and breaks competitive exclusion between strains.
