# Bayesian spatio-temporal disease mapping

Hierarchical Poisson models for counts of cases by area and time. Indirect standardization supplies expected counts, and spatially and temporally structured random effects absorb unobserved heterogeneity. This leaves covariate effects (for example lagged weather) on the log relative risk.
