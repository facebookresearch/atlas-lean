# Distributed lag non-linear models

Climate affects vector-borne disease with delays (mosquito development, viral incubation) and through non-linear dose–response curves. A distributed lag non-linear model represents the joint effect of an exposure and its lag by a bivariate exposure–lag–response function built from a tensor-product cross-basis, which enters a count regression for disease incidence as an ordinary set of linear terms.
