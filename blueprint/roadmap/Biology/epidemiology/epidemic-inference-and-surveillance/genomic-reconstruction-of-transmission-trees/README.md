# Genomic reconstruction of transmission trees

A dated pathogen phylogeny is not a transmission tree: when hosts carry diverse pathogen populations, transmission events fall on branches rather than at branching points. Colouring the branches of the genealogy by host links the two, and factorizes the likelihood into independent within-host coalescent pieces and a between-host epidemic model.
