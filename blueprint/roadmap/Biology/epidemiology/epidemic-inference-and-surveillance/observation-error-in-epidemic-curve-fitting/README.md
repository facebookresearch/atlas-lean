# Observation error in epidemic curve fitting

Fitting transmission models to outbreak data requires an explicit model of how reported counts arise from the latent epidemic. A stage-structured SEIR model with negative-binomial reporting of new infections makes that observation process explicit, and the covariance structure of accumulated counts shows why least-squares fits to cumulative incidence understate uncertainty.
