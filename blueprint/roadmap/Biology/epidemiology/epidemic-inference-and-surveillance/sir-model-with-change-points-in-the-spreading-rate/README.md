# SIR model with change points in the spreading rate

Non-pharmaceutical interventions act on an epidemic by lowering the rate at which infected people transmit. Modelling each intervention as a change point, a time window over which the spreading rate of a discrete-time SIR model moves from one constant value to another, turns the question "did the intervention work?" into Bayesian inference for the change-point times and the spreading rates before and after them, with an explicit reporting delay between infection and case report.
