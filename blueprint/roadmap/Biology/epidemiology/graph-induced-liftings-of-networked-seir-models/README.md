# Graph-induced liftings of networked SEIR models

Polynomial (Carleman- or Kronecker-type) liftings embed a nonlinear compartmental model into a higher-dimensional system that is linear up to a truncation residual. Selecting the lifted monomials from the transmission graph, rather than taking all Kronecker products, keeps the lifted dimension proportional to the number of transmission channels.
