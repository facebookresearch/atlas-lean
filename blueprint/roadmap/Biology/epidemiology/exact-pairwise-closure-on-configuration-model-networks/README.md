# Exact pairwise closure on configuration-model networks

Pairwise (pair-approximation) SIR models close the hierarchy of moment equations by writing triple counts in terms of pair and singleton counts. On a configuration-model network this closure becomes exact in the large-network limit precisely for a three-member family of degree distributions, the Poisson-type (binomial, Poisson, negative binomial) laws, whose generating functions solve $\psi' = \alpha\psi^{\kappa}$.
