# SIR epidemics with preventive edge dropping

A Markovian SIR epidemic on a configuration-model network in which susceptible individuals drop edges to infectious neighbours. Its deterministic limit, reproduction number and final size coincide with those of the network epidemic without dropping but with recovery rate increased by the dropping rate, while the probability of a major outbreak is strictly larger with dropping.
