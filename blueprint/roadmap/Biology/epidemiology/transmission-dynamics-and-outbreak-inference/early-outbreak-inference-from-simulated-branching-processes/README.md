# Early outbreak inference from simulated branching processes

In the first weeks of an emerging epidemic, case counts are unreliable but an estimate of total epidemic size may be available. Simulating age-dependent branching processes with negative-binomial offspring and keeping the parameter values whose simulations reach the estimated size yields joint posteriors for the basic reproduction number and the dispersion parameter.
