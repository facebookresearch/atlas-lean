# Vector-borne models with within-host viral load and antibodies

Host–vector epidemic models in which infected and recovered hosts are structured by viral load and antibody level through transport equations. Within-host dynamics set the infectious and protected durations, which enter the basic reproduction number and the endemic level; a uniform-host-response reduction yields a distributed-delay system.
