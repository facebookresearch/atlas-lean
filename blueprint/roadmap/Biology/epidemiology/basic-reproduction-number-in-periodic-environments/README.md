# Basic reproduction number in periodic environments

For epidemic models with seasonally varying coefficients, the basic reproduction number is the spectral radius of a next-generation operator on periodic functions. Its threshold coincides with that of the Floquet multiplier of the linearized infection subsystem, and a comparison argument gives global stability of the disease-free periodic state.
