# At nonnegative times the two forms of the deviation agree

For every `N ∈ ℕ`, count paths `S, E, I, R : ℝ → ℕ`, real functions `s`, `e`, `i`, `r` and every
`t ≥ 0`, the `ℓ¹` distance `∑_X |Z_X(t) / N - x_X(t)|` between the scaled
[count vector path](to-path.md) `Z` and the [deterministic vector path](ode-path.md)
`x = (s, e, i, r)` equals the [deviation](deviation.md)

`|S(t) / N - s(t)| + |E(t) / N - e(t)| + |I(t) / N - i(t)| + |R(t) / N - r(t)|`.
