# Count vector path frozen at negative times

For count paths `S, E, I, R : ℝ → ℕ`, the path `Z(t) = (S, E, I, R)(max(t, 0))` of
[vectors](vec4.md) in `ℕ^{S, E, I, R}`: the counts at time `t` for `t ≥ 0`, and their values at time
`0` for `t < 0`, where the [chain-path equations](is-chain-path.md) say nothing.
