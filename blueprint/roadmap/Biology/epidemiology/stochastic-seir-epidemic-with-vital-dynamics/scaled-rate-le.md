# The scaled intensities are bounded on a box

Let `β`, `σ`, `γ`, `μ` be nonnegative, and let `K`, `s`, `e`, `i`, `r` be real with `0 ≤ s ≤ K`,
`0 ≤ i ≤ K`, `e ≤ K` and `r ≤ K` (for example `(s, e, i, r)` in the box `[0, K]⁴`). Then for every
[channel](channel.md) `c` the [scaled intensity](scaled-rate.md) satisfies

`λ_c(s, e, i, r) ≤ μ + β K² + (σ + γ + μ) K`,

the [common bound](rate-bound.md).
