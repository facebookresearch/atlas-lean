# Common bound for the scaled intensities

For real `β`, `σ`, `γ`, `μ` and `K`, the number

`μ + β K² + (σ + γ + μ) K`.

For nonnegative `β`, `σ`, `γ`, `μ` it bounds every [scaled intensity](scaled-rate.md)
`λ_c(s, e, i, r)` at the points with `0 ≤ s ≤ K`, `0 ≤ i ≤ K`, `e ≤ K` and `r ≤ K`, in particular on
the box `[0, K]⁴` ([bound on a box](scaled-rate-le.md)).
