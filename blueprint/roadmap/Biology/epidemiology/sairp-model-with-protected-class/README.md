# SAIRP model with a protected class

A COVID-19 compartmental model with susceptible, asymptomatic, active infected, removed and protected classes, in which a fraction of susceptibles adopts protective behaviour and may abandon it. The basic reproduction number gives sharp global threshold dynamics, and switching parameters between sub- and supercritical regimes produces repeated epidemic waves.
