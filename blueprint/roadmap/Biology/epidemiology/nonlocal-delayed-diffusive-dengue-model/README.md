# Nonlocal delayed diffusive dengue model

Reaction–diffusion host–vector model of dengue with incubation delays in mosquitoes and humans, where movement during incubation produces nonlocal infection terms through the Neumann heat kernel. A Lyapunov functional shows that the positive constant steady state attracts all nontrivial solutions as soon as the basic reproduction number exceeds one.
