# Evolution of latency under superinfection

Adaptive dynamics of the length of an initial low-transmission ("asymptomatic" or latent) stage of infection, in a two-stage susceptible–infected–infected–recovered–susceptible model where hosts in the first stage can be superinfected by a competing strain. Superinfection changes the invasion fitness from resource minimization to a genuinely frequency-dependent quantity, which can create evolutionary branching in latency.
