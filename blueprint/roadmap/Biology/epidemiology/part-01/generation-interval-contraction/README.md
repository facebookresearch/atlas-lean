# Generation interval contraction

In a general stochastic SIR epidemic, the interval between an infector's infection and the infection it causes is shortened by competition among potential infectors: only the first infectious contact infects. Observed generation and serial intervals therefore contract as prevalence (global or local) rises, biasing estimates of reproduction numbers that use a fixed interval distribution.
