# SAIR model with saturated incidence

A susceptible–asymptomatic–infected–recovered model with nonmonotone saturated incidence $\beta_0 S I/(1 + \alpha I^2)$, its basic reproduction number, and a nonstandard finite-difference discretization (with an optional Brownian perturbation of the transmission rate) that keeps solutions positive and preserves the equilibria.
