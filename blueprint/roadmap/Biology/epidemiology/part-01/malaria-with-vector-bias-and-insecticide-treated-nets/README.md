# Malaria with vector bias and insecticide-treated nets

Host–vector malaria models in which mosquitoes preferentially bite infectious humans (vector bias $\pi \ge 1$) and insecticide-treated bed nets with usage $b$ both lower the biting rate and raise mosquito mortality. The bias can produce a backward bifurcation at $R_0 = 1$, so bed-net coverage that merely pushes $R_0$ below one may fail to eliminate the disease.
