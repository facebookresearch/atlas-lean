# Competitive exclusion of viral variants

In a compartmental model where two variants of a virus compete for the same susceptible pool and confer common immunity, the variant-specific basic reproduction numbers decide the long-run outcome: the variant with the larger reproduction number excludes the other, and coexistence occurs only on the non-generic set where the two numbers are equal.
