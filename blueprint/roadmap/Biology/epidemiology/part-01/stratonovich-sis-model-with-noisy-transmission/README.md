# Stratonovich SIS model with noisy transmission

When the transmission rate of the SIS model with demography is perturbed by white noise in the Stratonovich sense, a change of variables turns the infected fraction into a diffusion with gamma stationary law. Its Fokker–Planck operator has a finite discrete spectrum (Laguerre eigenfunctions) and a continuous spectrum (Whittaker eigenfunctions), which yields the full time-dependent distribution of the number infected.
