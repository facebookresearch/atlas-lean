# Herd-immunity equilibrium set of the SIR model

Set-valued stability of the disease-free equilibria of the normalized SIR model: the segment of disease-free states at or below the herd-immunity level is the unique asymptotically stable set, and the herd-immunity level bounds the final susceptible fraction reached by any finite-time intervention.
