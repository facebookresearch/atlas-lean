# Honeybee–Varroa–virus vector dynamics

Models of honeybee colonies parasitized by *Varroa destructor* mites that also vector honeybee viruses, combining a colony Allee effect with parasitism and several virus transmission routes. Explicit thresholds decide mite extinction, virus clearance and colony collapse.
