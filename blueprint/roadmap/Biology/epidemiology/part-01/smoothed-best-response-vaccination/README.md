# Smoothed best-response vaccination

Epidemic models in which susceptibles decide to vaccinate by a logit (smoothed best-response) rule applied to the payoff difference between the current force of infection and a perceived vaccine cost. The rationality parameter $k$ interpolates between indifferent choice ($k=0$) and the discontinuous best response ($k \to \infty$), and it enters the basic reproduction number through the vaccination rate at the disease-free state.
