# Diffusive SIR model with vital dynamics

Adding spatial diffusion (population mobility) with no-flux boundary conditions to the SIR model with recruitment and natural death does not change its threshold behavior: the basic reproduction number of the non-spatial model still decides global convergence to the disease-free or the endemic equilibrium.
