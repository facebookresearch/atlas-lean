# Epidemic spread through a transportation hub

SIRS metapopulation models in which $N$ cities exchange travellers only through a shared public transportation system (a hub) where transmission also occurs. The basic reproduction number interpolates between the isolated-city value and transmission driven by the hub, so that a hub can spread a disease that would die out in every isolated city, or suppress one that would persist.
