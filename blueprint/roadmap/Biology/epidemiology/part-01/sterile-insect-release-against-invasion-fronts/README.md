# Sterile insect release against invasion fronts

Reaction–diffusion models of a mosquito population (aquatic stage, females, fertile and sterile males) in which sterile males are released to reduce mating success. A monostable population exhibits the hair-trigger effect (any introduction invades), so releases must be designed to push the invasion front back rather than to eliminate a local population once.
