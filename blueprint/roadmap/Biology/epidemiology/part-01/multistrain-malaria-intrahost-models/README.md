# Multistrain malaria intrahost models

Within-host models of blood-stage malaria in which healthy red blood cells are recruited by a general homeostatic function, parasitized red blood cells pass through $k$ age classes before bursting and releasing merozoites, and $n$ parasite strains compete for the same red blood cells; Lyapunov functions give global threshold dynamics and a competitive exclusion principle.
