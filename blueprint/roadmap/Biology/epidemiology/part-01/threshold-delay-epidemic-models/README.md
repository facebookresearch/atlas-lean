# Threshold-delay epidemic models

Epidemic models in which the latency or reporting delay is not fixed but is defined by a threshold condition on the infectious state (for instance the time needed to accumulate a given load or exposure), giving state-dependent delay differential equations whose equilibria and bifurcations at $R_c=1$ can differ from those of constant-delay models.
