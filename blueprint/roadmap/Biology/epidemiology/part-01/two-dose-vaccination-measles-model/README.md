# Two-dose vaccination measles model

A compartmental SVEIR model of measles in which susceptibles receive a first vaccine dose, may lose its protection before a second dose, and reach immunity through the second dose. The next-generation reproduction number scales with the disease-free susceptible level left by both doses and sets the threshold for the disease-free state; above it there is a unique endemic equilibrium.
