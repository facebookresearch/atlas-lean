# Activity-network social distancing game

Each individual distributes participation over a set of social activities linked by a connectivity graph, and pays in expected social contacts, a quadratic form in its own and the population's activity frequencies. Nash equilibria of this population game are characterised by equalised contact payoffs on the support, and for unions of independent regular activity groups they have an explicit closed form.
