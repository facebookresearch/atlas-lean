# Paratransgenesis for malaria control

Ross–Macdonald-type malaria models with an extra *removed* mosquito class: mosquitoes that feed on sugar baits laced with genetically modified symbiotic bacteria can no longer transmit the parasite (until the effect wears off), unless sporozoites have already reached their salivary glands. The incubation delay makes the system non-cooperative, and the reproduction number shows how bait density and mosquito sugar-meal preference reduce transmission.
