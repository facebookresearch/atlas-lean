# Caputo fractional SIS model

The SIS epidemic with Caputo time derivatives: conservation of the population reduces it to a fractional Riccati (logistic) equation, which is well posed, recovers the classical logistic solution as the order tends to one, and decays as a Mittag-Leffler function when transmission is switched off.
