# Fractional-order epidemic models

Compartmental epidemic models in which the time derivative is replaced by a Caputo fractional derivative of order $\alpha\in(0,1)$, encoding memory in transmission and progression. Positivity, well-posedness and threshold results at $R_0=1$ carry over through fractional comparison and Lyapunov arguments.
