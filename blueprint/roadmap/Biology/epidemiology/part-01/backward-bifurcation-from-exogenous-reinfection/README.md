# Backward bifurcation from exogenous reinfection

In infections such as tuberculosis, latently infected and recovered individuals can be reinfected from outside. When reinfection of previously infected individuals is strong enough, endemic equilibria persist below the epidemic threshold $\mathcal R_0 = 1$: the bifurcation from the disease-free state is backward, two endemic equilibria coexist for $\mathcal R_0$ slightly below one, and pushing $\mathcal R_0$ below one no longer guarantees elimination.
