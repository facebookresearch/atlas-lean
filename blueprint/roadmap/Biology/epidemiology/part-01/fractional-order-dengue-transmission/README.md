# Fractional-order dengue transmission

Host–vector dengue models whose transmission and recovery have power-law (non-Markovian) waiting times, giving tempered Riemann–Liouville fractional terms. The memory exponents enter the basic reproduction number explicitly and govern elimination and endemic persistence.
