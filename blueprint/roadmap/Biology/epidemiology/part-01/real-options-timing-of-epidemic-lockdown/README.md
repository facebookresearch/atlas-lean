# Real-options timing of epidemic lockdown

When to start and when to lift non-pharmaceutical interventions can be posed as a nested optimal stopping problem on a stochastic epidemic: a social planner holds an option to enter lockdown and, once in lockdown, an option to exit, each exercised at a sunk switching cost. On a finite continuous-time Markov chain the value functions satisfy explicit Bellman recursions whose solutions split the state space into stopping and continuation regions.
