# MPC vaccination of age-structured SIRD models

Model predictive control of vaccine allocation across age groups in a discrete-time age-structured susceptible–infected–recovered–deceased model with a daily vaccine capacity. A terminal cost and terminal set derived from susceptible depletion make the controller recursively feasible and asymptotically stabilising toward the infection-free set, and the optimal cost bounds the future death toll.
