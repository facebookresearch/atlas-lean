# Two-patch SIR model with commuters and permanent residents

An SIR model on two connected territories in which part of each home population commutes to the other patch (leaving and returning at asymmetric rates) while the rest never leaves. Covers the explicit epidemic threshold of the coupled system and how the commuting proportions can be chosen to minimize it.
