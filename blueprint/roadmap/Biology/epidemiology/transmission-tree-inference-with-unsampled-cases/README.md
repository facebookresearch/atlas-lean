# Transmission-tree inference with unsampled cases

Bayesian reconstruction of who infected whom from a timed pathogen phylogeny when some cases are
never sampled and the outbreak may still be ongoing: a branching-process prior on transmission
trees that integrates over excluded lineages, a within-host coalescent likelihood for the
phylogeny, and reversible-jump moves that add or remove unsampled hosts.
