# Multi-host multi-vector staged-progression models

Vector-borne zoonoses in which one pathogen is shared by several host species and transmitted by several arthropod vector species. Each host's infectious period is divided into stages with different infectiousness to each vector. The basic reproduction number is a spectral radius over the bipartite host-vector network, and together with irreducibility of that network it fully determines global extinction or persistence.
