# Optimal timing of a finite-duration lockdown

When social distancing can be imposed only for a bounded duration and at bounded intensity, but its start date is free, the epidemic final size of the SIR model is minimized by a unique bang-bang policy whose onset solves a scalar equation. Whether long lockdowns can stop the outbreak at the herd immunity threshold depends on a critical intensity.
