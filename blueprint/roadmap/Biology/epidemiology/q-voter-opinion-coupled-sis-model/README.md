# q-voter opinion-coupled SIS model

SIS transmission coupled to a two-opinion $q$-voter process: one opinion transmits less, susceptibles change opinion by majority-type persuasion, and infection itself triggers a switch of opinion. Disease-free states with a single dominant opinion have different thresholds, and above an infectivity threshold endemic states with alternative basins coexist.
