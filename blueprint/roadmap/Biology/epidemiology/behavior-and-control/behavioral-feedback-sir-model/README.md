# Behavioral-feedback SIR model

An SIR model in which the transmission rate falls as prevalence rises and may depend on the susceptible fraction, modelling spontaneous behavioural response. It keeps an explicit invariant of motion, which characterizes the epidemic peak and the cost of keeping prevalence below a healthcare threshold.
