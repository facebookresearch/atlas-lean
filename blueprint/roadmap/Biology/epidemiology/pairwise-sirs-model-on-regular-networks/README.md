# Pairwise SIRS model on regular networks

Pair-approximation (moment-closure) ODEs for an SIRS epidemic on a homogeneous network of degree $n$ track nodes and edges by state. With slow waning of immunity the system is slow–fast: fast epidemic outbreaks along a critical manifold of disease-free states, separated by slow replenishment of susceptibles, with a threshold expressed by an edge-based reproduction number.
