# Age- and infection-age-structured malaria models

Human–mosquito malaria transmission models structured simultaneously by chronological age of hosts and vectors, time since infection, and (for humans) time since recovery, so that infectiousness, recovery and waning immunity can depend on these clocks. The basic reproduction number factorizes into a vector/host ratio and two infectiousness kernels, and waning immunity can produce a backward bifurcation.
