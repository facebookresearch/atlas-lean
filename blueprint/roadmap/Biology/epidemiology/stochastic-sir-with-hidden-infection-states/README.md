# Stochastic SIR with hidden infection states

When part of the population is in a hidden state (e.g. asymptomatic) and the infected fraction of that class is only seen through a noisy observation, stochastic SIR dynamics can be closed by replacing the unknown state with its nonlinear filter. Ergodicity of the filter makes a single Lyapunov-exponent threshold decide extinction versus permanence, and it coincides with the threshold of the fully observed system.
