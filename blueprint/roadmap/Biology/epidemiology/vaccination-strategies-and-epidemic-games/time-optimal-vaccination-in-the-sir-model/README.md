# Time-optimal vaccination in the SIR model

Minimum-time control of the SIR system by a bounded vaccination rate that removes susceptibles: the eradication time (first time the infected level falls to a threshold) is minimized, its value function is characterized through Hamilton–Jacobi–Bellman equations in the viscosity sense, and every optimal vaccination rate is a single bang-bang switch from no vaccination to maximal vaccination.
