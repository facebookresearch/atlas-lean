# Multi-strain co-colonization SIS model

An SIS model with $N$ strains that differ only in how prior colonization alters susceptibility to co-colonization. When the strains are similar, a slow–fast decomposition reduces the $1 + N + N^2$ compartments to a replicator equation for strain frequencies.
