# SIR control with a limited strict quarantine

Optimal non-pharmaceutical control of an SIR epidemic on a finite window, where the reproduction number can be set between a strict and a mild quarantine level but the strict level may be used only for a limited total time, and restrictions are lifted afterwards. Optimal controls are bang-bang with a single strict interval, and its onset is characterized by explicit thresholds on the uncontrolled epidemic trajectory.
