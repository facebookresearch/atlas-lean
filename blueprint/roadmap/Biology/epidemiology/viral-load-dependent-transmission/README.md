# Viral-load-dependent transmission

Linking within-host viral kinetics to between-host spread, the probability that an exposure transmits infection is modeled as a dose–response function of the transmitter's current viral load, and the number of exposure contacts per day is drawn from an overdispersed distribution. Summing transmissions over the course of infection gives an individual reproduction number whose distribution, rather than its mean, explains super-spreading.
