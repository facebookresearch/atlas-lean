# Pólya network contagion

An urn-based model of epidemic spread on a network: each node draws from a super urn pooling its own and its neighbours' red (infection) and black (health) balls, and reinforcement of drawn colours produces both temporal and spatial contagion. Covers structural results for allocating curing resources at initialization and the minimax game between curing and infection budgets.
