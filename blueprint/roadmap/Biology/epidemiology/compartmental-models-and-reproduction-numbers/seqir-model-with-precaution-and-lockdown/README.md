# SEQIR model with precaution and lockdown

A susceptible–exposed–quarantined–infected–removed model in which exposed individuals transmit, precautions scale transmission down on both sides of a contact, quarantine can return people to the susceptible class, and a lockdown policy moves susceptibles directly to the removed class. Its threshold is explicit, its endemic equilibrium is locally stable whenever it exists, and the optimal time-varying lockdown is bang-bang or singular.
