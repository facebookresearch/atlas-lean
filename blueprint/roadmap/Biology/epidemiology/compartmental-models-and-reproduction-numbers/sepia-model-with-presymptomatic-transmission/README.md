# SEPIA model with presymptomatic transmission

A compartmental epidemic model that splits the infectious period into a presymptomatic stage
followed by either a severely symptomatic or an asymptomatic/mildly symptomatic stage, coupled
across communities by mobility-dependent contact probabilities, with a spatially explicit
next-generation matrix whose spectral radius is the basic reproduction number.
