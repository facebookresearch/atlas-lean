# Type and target reproduction numbers

When control acts on only part of a transmission system (one host type, one route, one age group), the basic reproduction number $R_0 = \rho(K)$ of the next-generation matrix $K$ does not directly give the required control effort. The type reproduction number and its generalization, the target reproduction number, isolate the contribution of the targeted entries of $K$: preventing a fraction $1 - 1/T_S$ of those contributions eliminates the infection, and $T_S$ crosses $1$ exactly when $R_0$ does.
