# Array group testing with dilution

Linear (Dorfman-type) and square array pooled PCR testing for asymptomatic SARS-CoV-2 screening when pooling dilutes viral load, so that a pool's false negative probability grows with pool size, and a sample's split subsamples share one viral load, which correlates its test results.
