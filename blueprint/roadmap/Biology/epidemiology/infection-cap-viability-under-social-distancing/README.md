# Infection-cap viability under social distancing

Set-valued analysis of compartmental epidemics with a hard cap on the infected fraction: the admissible set (viability kernel), from which some bounded social-distancing or isolation schedule keeps infections below the cap forever, and the maximal robust positively invariant set, from which the cap is respected for every admissible input or parameter uncertainty, characterized through barrier curves obtained from a maximum-principle-type theorem.
