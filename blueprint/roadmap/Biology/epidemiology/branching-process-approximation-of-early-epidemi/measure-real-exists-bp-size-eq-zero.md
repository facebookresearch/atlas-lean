# Extinction probability of the path-space branching process

Let `ξ` be an [offspring family](is-offspring-family.md) under `P` whose law `ν` is a probability
measure. Then the branching process built from `ξ` dies out with probability
`P(Z_n = 0 for some n) = q`, the
[extinction probability](../../../Probability/branching-processes/galton-watson-process/extinction-prob.md)
`q` of `ν`, which is [the least fixed point of the offspring generating function in [0,
1]](../../../Probability/branching-processes/galton-watson-process/is-least-extinction-prob.md).
