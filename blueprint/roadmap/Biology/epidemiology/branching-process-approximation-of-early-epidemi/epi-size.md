# Number of infectives in generation n of the epidemic

For offspring numbers `ξ_n(i) ∈ ℕ` (the contacts of the `i`-th infective of generation `n`), contact
targets `U_0, U_1, …` in a type `α` of individuals (contact number `j` goes to `U_j`) and a finite
set `S₀ ⊆ α` of initially susceptible individuals, `I_n` is the first component of the
[state](epi.md) of the epidemic at generation `n`: the number of infectives of generation `n`, with
`I_0 = 1` for the index case.
