# The epidemic is extinct by generation #S₀ + 1

For offspring numbers `ξ_n(i) ∈ ℕ` (the contacts of the `i`-th infective of generation `n`), contact
targets `U_0, U_1, …` in a type `α` of individuals (contact number `j` goes to `U_j`) and a finite
set `S₀ ⊆ α` of initially susceptible individuals, the [numbers of infectives](epi-size.md) `I_n` of
the epidemic satisfy `I_{#S₀ + 1} = 0`: every infective of a generation `n ≥ 1` is a distinct
initially susceptible individual. Only the set `S₀` needs to be finite, not the population `α`.
