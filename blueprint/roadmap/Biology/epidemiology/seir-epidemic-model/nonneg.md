# Forward invariance of the nonnegative orthant for β, σ, γ, N ≥ 0

Let `(S, E, I, R)` be a [solution of the SEIR system](is-solution.md) with `β, σ, γ, N ≥ 0` and
nonnegative initial compartments `S(0), E(0), I(0), R(0) ≥ 0`. Then
`S(t), E(t), I(t), R(t) ≥ 0` for every `t ≥ 0`. The quotient `β S I / N` in the equations is read
as `0` when `N = 0`, so `N = 0` is allowed.
