# With σ > 0 and I(0) = 0 < E(0), I'(0) = σ E(0) > 0

Let `(S, E, I, R)` be a [solution of the SEIR system](is-solution.md) with `σ > 0` (`β`, `γ` and
`N` arbitrary). If initially there are no infectives but some latent individuals,
`I(0) = 0 < E(0)`, then the derivative of `I` at time `0` is positive:

`I'(0) = σ E(0) - γ I(0) = σ E(0) > 0`.

The solution is differentiable at `t = 0`, so this is the actual derivative.
