# For σ, γ > 0 and β ≥ 0, F − V has an eigenvalue with Re > 0 iff β > γ

Let `β ≥ 0` and `σ, γ > 0`. The infected-block Jacobian at the disease-free equilibrium (when
`N ≠ 0`),

`F - V = [[0, β], [0, 0]] - [[σ, 0], [-σ, γ]]`

(rows listed in order), has a complex eigenvalue with positive real part if and only if `β > γ`,
that is, if and only if `R₀ = β / γ > 1` ([the SEIR next-generation matrix](r0-eq.md), with the
[unstable-mode criterion](../next-generation-matrix-and-the-basic-reproductio/exists-re-pos-iff-one-lt-r0.md)).
This is a statement about the linearization only.
