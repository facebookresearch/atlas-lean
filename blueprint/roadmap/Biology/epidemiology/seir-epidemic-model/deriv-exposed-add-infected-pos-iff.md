# With I(0) > 0, (E + I)'(0) > 0 exactly when R₀ S(0) / N > 1

Let `(S, E, I, R)` be a [solution of the SEIR system](is-solution.md) with `γ > 0` and `N > 0`
(`β` and `σ` arbitrary), write `R₀ = β / γ`, and suppose `I(0) > 0`. Then the derivative at time
`0` of the infected total `E + I` is positive,

`(E + I)'(0) > 0`,   if and only if   `R₀ S(0) / N > 1`.

The solution is differentiable at `t = 0`, so this is the actual derivative, equal to
`γ I(0) (R₀ S(0) / N - 1)`.
