# New-infection rates of the SEIR infected compartments

For real numbers `β`, `N` and a susceptible level `S`, the new-infection rates of the infected
compartments `(E, I)` are

`ℱ(S; E, I) = (β S I / N, 0)`:

new infections enter the latent class `E` only. The quotient is read as `0` when `N = 0`, so then
`ℱ = (0, 0)` identically; the intended domain is `N > 0`.
