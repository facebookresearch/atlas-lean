# Jacobian of the new-infection rates at the disease-free equilibrium

Let `β` and `N ≠ 0` be real numbers. With the susceptible level held at its disease-free value
`S = N`, the [new-infection rates](new-infections.md) `(E, I) ↦ ℱ(N; E, I) = (β I, 0)` have, at
`E = I = 0`, the derivative with matrix

`F = [[0, β], [0, 0]]`

(rows listed in order). For `N = 0` the convention `x / 0 = 0` makes `ℱ` identically zero, so
`N ≠ 0` is needed when `β ≠ 0`.
