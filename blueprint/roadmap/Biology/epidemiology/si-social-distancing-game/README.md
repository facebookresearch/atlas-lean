# SI social-distancing game

In a susceptible–infected epidemic, each susceptible individual chooses how much to spend on distancing, trading prevention cost against the cost of infection, while the epidemic is driven by the population-average choice. With a threshold-linear efficiency the equilibrium is bang-bang, unique, and coincides with the population optimum.
