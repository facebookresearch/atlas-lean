# SIR models with state-dependent contact rates

SIR dynamics in which the contact rate is a function of the current susceptible and infected fractions, modeling behavioral response or government restrictions. Monotone smooth feedback preserves the single-peak structure of the classical epidemic curve, while a lockdown triggered at an infection threshold produces a Filippov system whose infection curve can plateau on a sliding segment.
