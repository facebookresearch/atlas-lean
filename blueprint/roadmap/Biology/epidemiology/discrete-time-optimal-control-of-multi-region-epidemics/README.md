# Discrete-time optimal control of multi-region epidemics

Discrete-time SIR models on several regions coupled by cross-regional transmission, with a per-region control such as vaccination, are optimized with the discrete Pontryagin maximum principle: backward costate recursions together with a projected first-order condition give the optimal control in closed form at each time step.
