# Fractional-order epidemic models

Fractional-order compartmental models replace the time derivative of each compartment by a Caputo derivative of order $\vartheta \in (0, 1]$, giving the dynamics a power-law memory. Stability of equilibria is then decided by the arguments rather than the real parts of Jacobian eigenvalues (Matignon's criterion), and global stability is proved with Volterra-type Lyapunov functions, using inequalities that bound the Caputo derivative of a convex function of the state.
