# Cause-of-death envelope correction

When cause-specific mortality is modelled separately for each cause, the predicted cause-specific deaths need not sum to independently estimated all-cause deaths. Envelope correction reconciles the two, draw by draw, so that uncertainty from both sources is carried into the final estimates.
