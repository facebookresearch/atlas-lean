# Probability that given contacts all reach a given set of individuals

Let the offspring numbers $\xi_{n,i}$ and the contact targets $U_j$ form a
[final-size epidemic model](is-final-size-epidemic.md) on a probability space $(\Omega, P)$, in the
population $\{0, \dots, N-1\}$. For every finite set $J \subseteq \mathbb{N}$ of contact indices and
every set $A$ of individuals,
$P\bigl(U_j \in A \text{ for all } j \in J\bigr) = \Bigl(\frac{\#A}{N}\Bigr)^{\#J}$.
