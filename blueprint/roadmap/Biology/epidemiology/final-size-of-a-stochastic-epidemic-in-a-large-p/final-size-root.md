# Positive root $\tau(R)$ of the final-size equation, $0$ if $R \le 1$

For a real number $R$ define $\tau(R)$ as follows.

If $R > 1$, $\tau(R)$ is a root in $(0, 1)$ of the final-size equation $1 - x = e^{-Rx}$; such a
root [exists](exists-final-size-gap-eq-zero.md), and since the equation has
[at most one positive root](eq-of-final-size-gap-eq-zero.md), $\tau(R)$ is its unique positive root.

If $R \le 1$, $\tau(R) = 0$. For such $R$ the equation has no positive root, so $0$ is its only root
in $[0, 1]$.
