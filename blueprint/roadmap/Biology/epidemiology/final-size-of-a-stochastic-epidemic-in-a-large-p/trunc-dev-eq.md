# Once $F + 1 \le L$, the centered contact count is $C - m(F + 1)$

For a finite set $S_0$ of initially susceptible individuals of the population $\{0, \dots, N-1\}$, a
real number $m$, $L \in \mathbb{N}$ and a [configuration](config.md) $w$, let $F$ be the
[final size](final-size.md) and $C$ the [total number of contacts](total-contacts.md) of the
epidemic of $w$. If $F + 1 \le L$, the [centered contact count](trunc-dev.md) is
$T_{m,L}(w) = C - m(F + 1)$.
