# With fixed targets, earlier offspring numbers determine generation n

Let $\xi$ and $\xi'$ be two arrays of offspring numbers, $U_j$ the target of contact number $j$ in a
population $\alpha$, and $S_0 \subseteq \alpha$ a finite set of initially susceptible individuals.
If $\xi_{m,i} = \xi'_{m,i}$ for all $m < n$ and all $i$, then the
[epidemic states](../branching-process-approximation-of-early-epidemi/epi.md) at generation $n$
computed from $\xi$ and from $\xi'$, with the same targets $U$ and the same $S_0$, are equal.
