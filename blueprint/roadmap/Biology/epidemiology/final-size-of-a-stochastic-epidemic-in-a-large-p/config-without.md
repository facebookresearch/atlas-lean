# Configuration at an outcome with one offspring number set to zero

For maps $\xi_{n,i} : \Omega \to \mathbb{N}$ and $U_j : \Omega \to \{0, \dots, N-1\}$, an index
$p_0 = (n_0, i_0)$ and an outcome $\omega \in \Omega$, the configuration at $\omega$ without $p_0$
is the [configuration](config.md) $w^{p_0}(\omega) = (w_1, w_2)$ with $w_1(n_0, i_0) = 0$,
$w_1(n, i) = \xi_{n,i}(\omega)$ for $(n, i) \ne p_0$, and $w_2(j) = U_j(\omega)$.
