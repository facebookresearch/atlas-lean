# If the first K contacts hit and F < K, the branching process dies out

Let $\xi_{n,i} \in \mathbb{N}$ be offspring numbers, $v : \mathbb{N} \to \{0, \dots, N-1\}$ a
sequence of contact targets, $S_0$ a set of initially susceptible individuals and
$K \in \mathbb{N}$. If each of the contacts $j < K$
[hits](../branching-process-approximation-of-early-epidemi/epi-hit.md) and the
[final size](final-size.md) satisfies $F < K$, then the
[branching process](../branching-process-approximation-of-early-epidemi/bp-size.md) with the same
offspring numbers dies out: $Z_n = 0$ for some $n$.
