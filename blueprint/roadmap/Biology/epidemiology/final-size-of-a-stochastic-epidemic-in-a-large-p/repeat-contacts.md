# Number of the first m contacts to an individual contacted before

For a sequence $v : \mathbb{N} \to \{0, \dots, N-1\}$ of contact targets, the number of the first
$m$ contacts that go to an individual contacted by an earlier contact is
$R_m = \#\{\, j < m : v_{j'} = v_j \text{ for some } j' < j \,\}$.
