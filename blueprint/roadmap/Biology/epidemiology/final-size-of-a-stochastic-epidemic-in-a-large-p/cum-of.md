# Number of infectives of generations 0 to n of a configuration

For a finite set $S_0$ of initially susceptible individuals of the population $\{0, \dots, N-1\}$
and a [configuration](config.md) $w = (w_1, w_2)$, let $I_n$ be the number of infectives in
generation $n$ of the [epidemic of $w$](epi-of.md). The cumulative number of infectives up to
generation $n$ is $I_0 + I_1 + \cdots + I_n$, the index case $I_0 = 1$ included.
