# The final size is at most the number of initial susceptibles

Let $\xi_{n,i} \in \mathbb{N}$ be the number of contacts made by the $i$-th infective of generation
$n$, let $U_j$ be the target of contact number $j$ in a population $\alpha$, and let
$S_0 \subseteq \alpha$ be a finite set of initially susceptible individuals. Then the
[final size](final-size.md) $F$, the number of individuals ever infected, satisfies $F \le \#S_0$,
the number of initially susceptible individuals.
