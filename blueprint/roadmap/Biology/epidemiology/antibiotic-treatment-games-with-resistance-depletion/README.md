# Antibiotic treatment games with resistance depletion

Stochastic games in which physicians decide whether to give empirical antibiotics to patients of uncertain infection status while each use depletes the drug's future effectiveness through resistance. Socially optimal policies treat only high-probability patients, whereas Markov perfect equilibria over-treat; coarsening the diagnostic signal restricts the available deviations and can make the near-optimal policy an equilibrium.
