# SIS epidemics on graphon limits of random networks

An individual-based SIS epidemic on a random graph whose edge probabilities depend on node features converges, as the network grows, to a deterministic integro-differential equation on the graphon, provided the number of edges grows faster than the number of nodes. A coupling with an epidemic on the complete graph with rescaled infection rates controls the error.
