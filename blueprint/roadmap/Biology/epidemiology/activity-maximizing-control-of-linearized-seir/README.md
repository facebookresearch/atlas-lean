# Activity-maximizing control of the linearized SEIR model

Optimal scheduling of transmission-inducing activity at low prevalence, when susceptibles are effectively constant and SEIR dynamics are linear. In the coordinate $V=E/I$ the problem becomes maximizing the time variance of $V$, so constant-rate policies are worst and bang-bang alternation between minimal and maximal activity is best.
