# Log-linear intervention effects on the reproduction number

Cross-country studies of non-pharmaceutical interventions model the time-varying reproduction number as a country-specific baseline multiplied by one factor per active intervention, with intervention effects partially pooled across countries. Effects then combine multiplicatively and are reported as percentage reductions in the reproduction number.
