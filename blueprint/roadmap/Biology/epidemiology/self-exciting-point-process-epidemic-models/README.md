# Self-exciting point-process epidemic models

Epidemic incidence modelled as a Hawkes (self-exciting) point process. Each infection raises the future infection rate by its reproduction number times a generation-interval kernel. Allowing the reproduction number to vary in time tracks interventions, and a susceptible-depletion factor turns the process into a stochastic SIR model.
