# Nonlocal dengue free-boundary model with seasonal impulses

Host–vector dengue model for infected humans and infected mosquitoes with nonlocal (kernel) dispersal on an expanding infected interval whose edges move in proportion to the outward flux, alternating between a dry season (no transmission, frozen boundaries) and a wet season, with an impulsive vector-control map applied once per period. The long-time behavior is a dichotomy between vanishing and spreading, decided by a periodic principal eigenvalue that increases with dry-season length.
