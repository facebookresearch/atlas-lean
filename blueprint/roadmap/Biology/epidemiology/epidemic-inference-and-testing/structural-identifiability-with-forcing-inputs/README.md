# Structural identifiability with forcing inputs

Known time-varying forcing functions, such as rainfall series or dosing schedules, can be inserted into parameterized ODE models by scaling or replacing a parameter. Differential-algebra arguments show that this never destroys structural identifiability and can disentangle additive and multiplicative parameter combinations.
