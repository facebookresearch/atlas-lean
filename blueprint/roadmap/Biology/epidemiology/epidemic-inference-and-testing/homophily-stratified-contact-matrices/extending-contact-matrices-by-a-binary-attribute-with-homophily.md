# Extending contact matrices by a binary attribute with homophily

**Setting.** A population is stratified over a combined attribute space $A$ (for example age groups), with group sizes $N_i$, and $C_{ij}\ge0$ is the mean number of contacts an individual of group $i$ has with group $j$. $C$ is **reciprocal** if $N_iC_{ij}=N_jC_{ji}$ for all $i,j$, so contacts counted from both sides agree. Now add a binary attribute (for example vaccinated or not) whose prevalence $P_i\in[0,1]$ may differ across the groups $i\in A$, giving the extended space $A^\star=A\times\{0,1\}$ with known group sizes $N^\star_{(i,1)}=P_iN_i$, $N^\star_{(i,0)}=(1-P_i)N_i$. For a contact matrix $C^\star$ on $A^\star$, let

$$\phi(C^\star,N^\star)=\frac{\sum_{i,j\in A}\sum_{v\in\{0,1\}}N^\star_{(i,v)}C^\star_{(i,v),(j,v)}}{\sum_{i,j\in A}\sum_{v,w\in\{0,1\}}N^\star_{(i,v)}C^\star_{(i,v),(j,w)}}$$

be the proportion of contacts between individuals with the same attribute value. Its value without homophily is $\mathbb E(\phi)=\phi(C^0,N^\star)$, where $C^0$ distributes each contact by the prevalence of the contacted group, $C^0_{(i,v),(j,1)}=P_jC_{ij}$ and $C^0_{(i,v),(j,0)}=(1-P_j)C_{ij}$. The **homophily** is $h=(\phi-\mathbb E\phi)/(1-\mathbb E\phi)\in[0,1]$ if $\phi\ge\mathbb E\phi$ and $h=(\phi-\mathbb E\phi)/\mathbb E\phi\in[-1,0)$ otherwise, so $h=1$ is complete segregation, $h=0$ random mixing and $h=-1$ complete disassortativity. When the prevalence is the same value $p$ in every group, $\mathbb E(\phi)=p^2+(1-p)^2$, the expected proportion for an undirected graph with prevalence $p$; with group-dependent prevalence $p^2+(1-p)^2$ for the population prevalence $p$ is not the random-mixing value, and using it in (d) can make $h=0$ infeasible. For example, with two equal-sized groups that only contact themselves ($C$ diagonal) and prevalences $P=(0,1)$, every admissible $C^\star$ has $\phi=1=\phi(C^0,N^\star)$, while $p^2+(1-p)^2=1/2$, so with that value only $h=1$ would be feasible and $h_{\min}\le0$ would fail.

**Theorem 2.1 and Corollary 2.2 (reciprocity).** For any contact matrix $C$, the matrix $\tilde C_{ij}=(N_iC_{ij}+N_jC_{ji})/(2N_i)$ is reciprocal; for a reciprocal $C$ the total number of contacts in the population is $\tfrac12\sum_{i,j}N_iC_{ij}$.

**Admissible extensions (Definition 4.1).** Let the original matrix $C$ on $A$ be reciprocal. An extended matrix $C^\star$ on $A^\star$ is admissible if it is (a) reciprocal; (b) preserves each individual's total contacts, $\sum_jC^\star_{(i,0),j}=\sum_jC^\star_{(i,1),j}=\sum_jC_{ij}$; (c) reproduces the original pattern, $\sum_v\frac{N^\star_{(i,v)}}{N_i}\sum_wC^\star_{(i,v),(j,w)}=C_{ij}$; and (d) has the prescribed homophily, $\phi(C^\star,N^\star)=\mathbb E(\phi)(1-h)+h$ for $h\ge0$ and $\phi(C^\star,N^\star)=\mathbb E(\phi)(1+h)$ for $h<0$, with $\mathbb E(\phi)=\phi(C^0,N^\star)$ fixed by $C$, $N$ and $P$. These conditions are linear in the entries of $C^\star$ (condition (d) after multiplying by the denominator of $\phi$, which (b) fixes at $\sum_{i,j}N_iC_{ij}$).

**Theorem 4.2 (feasible homophily interval).** For a reciprocal $C$, there are $h_{\min}\le0\le h_{\max}$ in $[-1,1]$ such that the linear system (a)-(d) has a non-negative solution $C^\star$ if and only if $h\in[h_{\min},h_{\max}]$.

## Expansion

Symmetrizing by averaging the two counts of each contact type enforces reciprocity while keeping total contacts. The admissibility conditions form a linear system in the unknown entries of $C^\star$; its non-negative solution set, intersected with a one-parameter family indexed by the homophily constraint, is a polytope that varies linearly with $h$, so the set of feasible $h$ is an interval. Random mixing ($h=0$) is always feasible: $C^0$, which splits each contact proportionally to the prevalence of the contacted group, is non-negative, reciprocal because $C$ is ($N^\star_{(i,v)}C^0_{(i,v),(j,w)}$ is $N_iC_{ij}$ times the two prevalence factors, symmetric in $(i,v)\leftrightarrow(j,w)$), satisfies (b)-(c), and has $\phi=\mathbb E(\phi)$ by definition, which gives $h_{\min}\le0\le h_{\max}$. Extreme homophily can be infeasible when the attribute's prevalence differs strongly across the original groups, because preserving each group's contact totals then forces cross-attribute contacts. Projected matrices feed directly into next-generation matrices for vaccination or behaviour-stratified epidemic models.
