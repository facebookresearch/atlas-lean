# Homophily-stratified contact matrices

Methods to refine social contact matrices used in epidemic models (for example by age) with an additional binary attribute such as vaccination status, while keeping contacts reciprocal, preserving the original contact patterns and imposing a known level of homophily. Admissible refinements solve a linear system that is feasible exactly on an interval of homophily values.
