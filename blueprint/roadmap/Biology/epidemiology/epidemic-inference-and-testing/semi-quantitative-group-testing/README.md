# Semi-quantitative group testing

Pooled testing designs for pathogen screening in which each pooled qPCR test reports not just positive or negative but a coarse count of infected samples, up to a saturation level. At constant prevalence, nonadaptive designs cannot beat a linear number of tests, which motivates adaptive multi-stage protocols.
