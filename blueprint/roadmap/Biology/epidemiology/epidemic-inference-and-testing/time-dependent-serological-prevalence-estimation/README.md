# Time-dependent serological prevalence estimation

Antibody levels of infected individuals rise and wane with time since infection, so the measurement distribution of positives changes over the course of an epidemic. Modelling it as a mixture over infection days gives unbiased prevalence estimators that need no classification, and time-dependent optimal classification domains.
