# Biphasic environmental decay of pathogens

Linear two-compartment models of pathogen survival in the environment (labile and resistant forms with decay, dormancy and resuscitation) all produce biexponential decay curves. The curve fixes only a few parameter combinations, so survival data alone cannot separate the mechanisms.
