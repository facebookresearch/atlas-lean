# N-intertwined mean-field approximation

The N-intertwined mean-field approximation (NIMFA) replaces the exact Markovian SIS process on a contact network, whose state space has $2^N$ configurations, by $N$ coupled ODEs for the nodes' infection probabilities, closing the dynamics by treating the infection states of neighbours as independent. Its epidemic threshold is set by the spectral radius of the adjacency matrix.
