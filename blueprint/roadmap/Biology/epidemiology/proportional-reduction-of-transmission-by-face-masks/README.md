# Proportional reduction of transmission by face masks

When masks scale down the per-contact transmission probability, the reproduction number is reduced by a population mask effectiveness that factors into filtering efficiency, proper use and availability; the first-wave attack rate then follows from the final-size equation with the reduced reproduction number.
