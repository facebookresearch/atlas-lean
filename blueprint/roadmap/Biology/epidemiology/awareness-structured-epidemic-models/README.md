# Awareness-structured epidemic models

Compartmental epidemic models in which susceptible individuals are split by whether they are aware of the epidemic and follow preventive measures. Awareness reduces susceptibility, and unaware individuals become aware at some rate, so the composition of the susceptible pool changes over the course of an outbreak.
