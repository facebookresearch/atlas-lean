# Fractional Routh–Hurwitz conditions

Local stability of equilibria of Caputo fractional-order systems $D^\alpha x = f(x)$, $0 < \alpha < 1$, used for epidemic, predator–prey and other population models with memory. Stability requires every Jacobian eigenvalue to satisfy $|\arg\lambda| > \alpha\pi/2$, which is weaker than the classical half-plane condition, so the Routh–Hurwitz conditions become sufficient but no longer necessary. Explicit coefficient conditions are available in dimensions one to three.
