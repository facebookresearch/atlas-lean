# Residence-times multipatch SIS model

Multigroup SIS dynamics in which patch residents never relocate but spend fixed fractions of their time in other patches (virtual dispersal). Infection risk is set by the time spent in each patch and by that patch's environmental risk, so no group-to-group contact rates need to be estimated. A residence-times matrix replaces the contact matrix, and its irreducibility gives a sharp global threshold, while patch-level reproduction numbers decide local persistence when it is reducible.
