# Nonautonomous SIQR model with general incidence

SIQR (susceptible, infective, quarantined, recovered) models whose rates are arbitrary bounded time-dependent functions, neither constant nor periodic, with an incidence that may depend on every compartment. Threshold numbers built from time averages of the per-infective incidence along the disease-free total population replace the basic reproduction number and decide permanence or extinction of the infectives.
