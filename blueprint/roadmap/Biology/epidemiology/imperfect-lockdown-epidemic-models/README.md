# Imperfect-lockdown epidemic models

Compartmental models in which a fraction of susceptibles is moved into a lockdown class that is protected only partially (relative susceptibility $r < 1$) and returns to the general susceptible pool after the lockdown period. Lockdown lowers the basic reproduction number, and imperfect efficacy can create multiple endemic equilibria below the threshold.
