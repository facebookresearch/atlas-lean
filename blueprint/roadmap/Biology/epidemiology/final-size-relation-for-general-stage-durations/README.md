# Final size relation for general stage durations

The Kermack–McKendrick final size relation links the basic reproduction number to the fraction of a homogeneously mixing population that is eventually infected. It does not depend on the assumption of exponentially distributed infectious periods: latent stages, several infectious stages, isolation and arbitrarily distributed infectiousness leave it unchanged, while heterogeneous mixing such as a core group can break it.
