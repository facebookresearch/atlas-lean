# Stress-structured epidemic models

Epidemic models in which hosts move between normal and physiologically stressed states that differ in susceptibility, shedding and recovery, as in aquaculture under poor water quality. The basic reproduction number remains the deterministic threshold, but the stochastic outbreak probability depends strongly on the physiological state of the first infected hosts.
