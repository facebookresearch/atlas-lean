# Epidemic population games

Coupled systems in which a population's strategic choices, such as levels of distancing or protection, evolve under bounded-rationality revision protocols while the strategies' aggregate transmission rate drives a normalized compartmental epidemic model. A planner's dynamic payoff mechanism steers the coupled system to the lowest endemic infection level attainable with a given long-run cost. Lyapunov functions certify global convergence and anytime bounds on infections.
