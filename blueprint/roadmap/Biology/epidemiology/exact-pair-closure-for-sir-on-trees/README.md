# Exact pair closure for SIR on trees

Individual-level moment equations for the stochastic SIR epidemic on a fixed transmission network, and the result that the standard pair-level closure of triples is exact when the network is a tree (or reduces to trees after deleting routes that cannot carry infection) and the initial condition is deterministic.
