# Equilibrium identity for the susceptible class

Under `σ > 0`, `γ ≥ 0`, `μ > 0`, `N > 0` and `R₀ > 1`, where `R₀` is the
[basic reproduction number](r0.md) `R₀ = β σ / ((μ + σ) (μ + γ))`, the [susceptible](endemic-s.md)
and [infectious](endemic-i.md) levels satisfy `μ N = μ S* + β S* I* / N`: the right-hand side of
`S' = μ N − β S I / N − μ S` vanishes there.
