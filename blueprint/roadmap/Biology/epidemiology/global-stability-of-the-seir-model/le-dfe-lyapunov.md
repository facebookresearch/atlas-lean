# Each term is bounded by the disease-free Lyapunov function

For `σ > 0`, `μ ≥ 0`, `N > 0`, `S > 0`, `E ≥ 0` and `I ≥ 0`, the
[disease-free Lyapunov function](dfe-lyapunov.md) `V₀` satisfies `g(N, S) ≤ V₀(S, E, I)`,
`E ≤ V₀(S, E, I)` and `I ≤ V₀(S, E, I)`, where `g` is the [Volterra function](volterra.md)
`g(a, x) = x − a − a log(x / a)`.
