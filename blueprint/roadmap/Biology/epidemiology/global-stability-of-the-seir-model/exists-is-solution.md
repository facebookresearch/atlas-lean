# Existence of nonnegative solutions for positive σ, μ and N

For `β ≥ 0`, `σ > 0`, `γ ≥ 0`, `μ > 0`, `N > 0` and initial values `s₀, e₀, i₀, r₀ ≥ 0`, there are
functions `S, E, I, R : ℝ → ℝ` forming a [solution](is-solution.md) with `S(0) = s₀`, `E(0) = e₀`,
`I(0) = i₀`, `R(0) = r₀`, such that `S(t), E(t), I(t), R(t) ≥ 0` and
`S(t) + E(t) + I(t) + R(t) ≤ max(N, s₀ + e₀ + i₀ + r₀)` for every `t ≥ 0`. In particular every
initial state in the open positive orthant has a solution, so the solution hypotheses of the
stability results can be met. Existence itself needs the parameters only
[nonnegative](exists-is-solution-of-nonneg.md).
