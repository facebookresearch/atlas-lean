# Basic reproduction number of the SEIR model with vital dynamics

For real `β, σ, γ, μ`, the basic reproduction number is `R₀ = β σ / ((μ + σ) (μ + γ))`, with the
convention `x / 0 = 0`: `R₀ = 0` when `μ + σ = 0` or `μ + γ = 0`. For `β ≥ 0`, `σ > 0`, `γ ≥ 0` and
`μ > 0`, a newly infected individual survives the latent period with probability `σ / (μ + σ)` and
then infects at rate `β` for a mean time `1 / (μ + γ)`.
