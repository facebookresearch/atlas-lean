# Susceptible level of the endemic equilibrium

For real parameters `β, σ, γ, μ, N`, `S* = N (μ + σ) (μ + γ) / (β σ)`. With the convention
`x / 0 = 0` this equals `N / R₀` for the [basic reproduction number](r0.md) `R₀`, and both are `0`
when `β σ = 0` or `(μ + σ) (μ + γ) = 0`. Under `σ > 0`, `γ ≥ 0`, `μ > 0`, `N > 0` and `R₀ > 1`, `S*`
is the susceptible coordinate of the endemic equilibrium `(S*, E*, I*)`, and
[`S* < N`](endemic-s-lt.md).
