# Equilibrium identity for the exposed class

Under `σ > 0`, `γ ≥ 0`, `μ > 0`, `N > 0` and `R₀ > 1`, where `R₀` is the
[basic reproduction number](r0.md) `R₀ = β σ / ((μ + σ) (μ + γ))`, the endemic levels
[`S*`](endemic-s.md), [`E*`](endemic-e.md) and [`I*`](endemic-i.md) satisfy
`β S* I* / N = (μ + σ) E*`: the right-hand side of `E' = β S I / N − (μ + σ) E` vanishes there.
