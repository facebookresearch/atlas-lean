# Bound on the disease-free Lyapunov derivative when R₀ ≤ 1

For real `β` and `N`, `σ > 0`, `γ ≥ 0` and `μ > 0` with `R₀ ≤ 1`, where `R₀` is the
[basic reproduction number](r0.md) `R₀ = β σ / ((μ + σ) (μ + γ))`, every real `S` and every `I ≥ 0`,
the [disease-free Lyapunov derivative](dfe-lyapunov-deriv.md) `V̇₀` satisfies
`V̇₀(S, I) ≤ −μ (S − N)² / S`; the right-hand side is `≤ 0` when `S > 0`.
