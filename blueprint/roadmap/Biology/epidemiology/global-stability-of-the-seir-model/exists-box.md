# Sublevel sets of the Lyapunov function in the open orthant lie in a positive box

Under `σ > 0`, `γ ≥ 0`, `μ > 0`, `N > 0` and `R₀ > 1`, where `R₀` is the
[basic reproduction number](r0.md) `R₀ = β σ / ((μ + σ) (μ + γ))`, for every real `C` there are
`m > 0` and `M` such that every `(S, E, I)` with `S, E, I > 0` and `V(S, E, I) ≤ C`, for the
[Lyapunov function](lyapunov.md) `V`, satisfies `m ≤ S, E, I ≤ M`.
