# Volterra function

For real `a` and `x`, `g(a, x) = x − a − a log(x / a)`, with the conventions `x / 0 = 0`,
`log 0 = 0` and `log y = log |y|` for `y < 0`; in particular `g(0, x) = x`. The intended domain is
`a, x > 0`, where `g(a, x) ≥ 0`, with equality only at `x = a`. It is the building block of
Goh–Volterra Lyapunov functions.
