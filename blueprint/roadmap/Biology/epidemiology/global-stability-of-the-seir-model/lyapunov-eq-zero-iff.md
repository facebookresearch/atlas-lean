# The Lyapunov function vanishes on the open orthant only at the endemic equilibrium

Under `σ > 0`, `γ ≥ 0`, `μ > 0`, `N > 0` and `R₀ > 1`, where `R₀` is the
[basic reproduction number](r0.md) `R₀ = β σ / ((μ + σ) (μ + γ))`, for all `S, E, I > 0` the
[Lyapunov function](lyapunov.md) `V` satisfies `V(S, E, I) = 0` if and only if
`(S, E, I) = (S*, E*, I*)`, with the endemic levels [`S*`](endemic-s.md), [`E*`](endemic-e.md) and
[`I*`](endemic-i.md).
