# Removed level of the endemic equilibrium

For real parameters `β, σ, γ, μ, N`, `R* = γ I* / μ`, where `I*` is the
[infectious level](endemic-i.md); with the convention `x / 0 = 0`, `R* = 0` when `μ = 0`. The
intended domain is `μ > 0`; under `σ > 0`, `γ ≥ 0`, `μ > 0`, `N > 0` and `R₀ > 1`, where `R₀` is the
[basic reproduction number](r0.md), `R*` is the removed coordinate of the endemic equilibrium.
