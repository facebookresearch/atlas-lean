# SEIR model with a time-varying reproduction number

Public-health interventions change the contact rate during an outbreak. Letting the SEIR transmission rate follow a smooth sigmoidal transition from its pre-intervention to its post-intervention value gives a four-parameter description of the effective reproduction number, and the explicit Lambert-W solution of the SEIR final-size relation turns each reproduction number into a predicted final (or temporarily stable) susceptible fraction.
