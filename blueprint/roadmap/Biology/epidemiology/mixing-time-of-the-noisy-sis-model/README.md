# Mixing time of the noisy SIS model

An SIS contact process on a graph with an external source of infection has no absorbing disease-free state, so it converges to a unique stationary law. Under contraction conditions its mixing time is of order $n\log n$ in the number of vertices, on fixed bounded-degree graphs and on typical random graphs.
