# Immunity-age-structured reinfection models

Epidemic models in which recovered or vaccinated individuals carry an immunity age and become progressively more susceptible to reinfection as protection wanes. The resulting positive feedback can make the bifurcation at $\mathcal R_0 = 1$ backward, with bistability between disease-free and endemic states.
