# Multiplicative regression for the effective reproduction number

Seasonal respiratory pathogens have reproduction numbers that rise and fall with the calendar and with the stock of susceptibles depleted by recent infection, including infection by a cross-immunizing relative. Writing the weekly effective reproduction number as a product of a baseline, depletion factors and a seasonal term turns these competing explanations into separately estimable multiplicative effects.
