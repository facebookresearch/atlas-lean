# Periodic active screening and elimination thresholds

Logistic within-community prevalence models interrupted by periodic mass screening rounds that remove a fixed fraction of the infected (participation times test sensitivity). The post-screening state obeys an affine recursion, which yields a sharp screening-interval threshold for eradication and closed forms for the number of rounds to elimination.
