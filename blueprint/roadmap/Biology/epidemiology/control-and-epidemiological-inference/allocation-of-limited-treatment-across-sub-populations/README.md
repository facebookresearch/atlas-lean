# Allocation of limited treatment across sub-populations

How a fixed treatment budget should be split among independent host sub-populations, each with its own SIS epidemic and a treatment capacity limited by the resources it receives. Long-term prevalence is a concave function of the allocation away from saturation, so optimal allocations concentrate resources and the choice of which sub-populations to saturate is a 0–1 knapsack problem.
