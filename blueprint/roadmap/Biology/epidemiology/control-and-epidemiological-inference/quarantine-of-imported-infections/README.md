# Quarantine of imported infections

Travel-related control of an epidemic in which infected travellers arrive at Poisson times and only not-yet-detected infections can travel. A fixed-duration entry quarantine acts as a filter whose efficacy is the probability that a traveller leaves every undetected infectious state during quarantine, computed from the matrix exponential of the within-host stage transition matrix.
