# Optimal diagnostic classification with indeterminates

Diagnostic assays (for example serological antibody tests) classify a measurement $r$ as positive or negative using the conditional densities of $r$ among positive and negative individuals and the prevalence. Prevalence-weighted density comparison gives the error-minimizing binary rule; when a target accuracy must be met, the optimal rule holds out as indeterminate the measurements with the lowest local accuracy.
