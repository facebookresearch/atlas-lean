# Ordering of elimination across coupled areas

When a disease is eliminated area by area, the order matters: an area cleared first must keep surveillance running against imported cases while its neighbors are still endemic. A two-area accounting model, with burden, vulnerability to importation and program duration tied to each area's transmission potential, decides when targeting the higher-transmission area first minimizes burden or cost.
