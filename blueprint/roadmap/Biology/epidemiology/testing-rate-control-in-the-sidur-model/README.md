# Testing-rate control in the SIDUR model

Epidemic control through diagnostic testing: the SIDUR model separates undetected infected individuals from detected (isolated) ones, with the daily number of tests as control input. Its effective reproduction number decreases with tests per testable person, giving a closed-form minimum testing rate that switches the epidemic from spreading to non-spreading.
