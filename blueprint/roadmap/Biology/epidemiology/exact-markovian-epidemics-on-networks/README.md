# Exact Markovian epidemics on networks

Governing equations of the exact continuous-time Markovian SIR and SIS processes on a graph, written with indicator random variables and the expectation operator without any closure or mean-field approximation. Although pair correlations prevent closed-form solutions, the exact equations still yield a Laplacian identity for the prevalence and a proven upper bound on the SIS epidemic threshold.
