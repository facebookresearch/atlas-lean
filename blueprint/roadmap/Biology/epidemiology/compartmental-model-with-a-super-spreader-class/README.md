# Compartmental model with a super-spreader class

An SEIR-type model in which exposed individuals become symptomatic, super-spreading or asymptomatic, and symptomatic and super-spreading cases may be hospitalized and still transmit. Its basic reproduction number splits into a symptomatic and a super-spreader contribution, each including onward transmission from hospital.
