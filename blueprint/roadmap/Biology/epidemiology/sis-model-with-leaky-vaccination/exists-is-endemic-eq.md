# For 0 < p < 1 and ε < 1, Rᵥ > 1 gives an endemic equilibrium

Let $\beta, \gamma, N > 0$, $0 < p < 1$ and $\varepsilon < 1$. If the
[vaccinated reproduction number](rv.md) $R_v = (\beta / \gamma)(1 - \varepsilon p)$ satisfies
$R_v > 1$, then there is an [endemic equilibrium](is-endemic-eq.md) at coverage $p$. Its total
$I^* = a + c$ solves $f(I^*) = 1$ for a continuous decreasing $f$ on $[0, N]$ with $f(0) = R_v > 1$
and $f(N) \le 1$, by the intermediate value theorem.
