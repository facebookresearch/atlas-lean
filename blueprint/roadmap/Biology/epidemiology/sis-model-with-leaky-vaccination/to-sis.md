# A vaccine of zero efficacy gives the unvaccinated SIS model

If $(S_u, I_u, S_v, I_v)$ is a [solution](is-solution.md) of the SIS model with leaky vaccination,
with transmission rate $\beta$, recovery rate $\gamma$, vaccine efficacy $0$ and population size
$N$, then the totals $S = S_u + S_v$ and $I = I_u + I_v$ form a
[solution of the SIS model](../sis-epidemic-model/is-solution.md) with transmission rate $\beta$,
recovery rate $\gamma$ and population size $N$.
