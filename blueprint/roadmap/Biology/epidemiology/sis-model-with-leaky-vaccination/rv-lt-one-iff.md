# For β, γ, ε > 0, Rᵥ < 1 iff p exceeds the critical coverage

For $\beta, \gamma, \varepsilon > 0$ and every real coverage $p$, the
[vaccinated reproduction number](rv.md) $R_v = (\beta / \gamma)(1 - \varepsilon p)$ satisfies

$$R_v < 1 \iff p > p_c,$$

with the [critical coverage](critical-coverage.md) $p_c = (1 - \gamma / \beta) / \varepsilon$.
