# The disease-free state is a constant solution

For all real $\beta$, $\gamma$, $\varepsilon$, $N$ and $p$, the constant functions
$S_u = (1 - p) N$, $I_u = 0$, $S_v = p N$ and $I_v = 0$ form a [solution](is-solution.md) of the SIS
model with leaky vaccination, with transmission rate $\beta$, recovery rate $\gamma$, vaccine
efficacy $\varepsilon$ and population size $N$.
