# An endemic equilibrium is a constant solution

If $(a, c)$ is an [endemic equilibrium](is-endemic-eq.md) at coverage $p$ for real $\beta$,
$\gamma$, $\varepsilon$ and $N$, then the constant functions $S_u = (1 - p) N - a$, $I_u = a$,
$S_v = p N - c$ and $I_v = c$ form a [solution](is-solution.md) of the SIS model with leaky
vaccination, with transmission rate $\beta$, recovery rate $\gamma$, vaccine efficacy $\varepsilon$
and population size $N$.
