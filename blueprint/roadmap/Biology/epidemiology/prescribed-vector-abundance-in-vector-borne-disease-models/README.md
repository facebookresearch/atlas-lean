# Prescribed vector abundance in vector-borne disease models

Host–vector transmission models in which the total vector population $V(t)$ is not modeled but imposed from data (for instance mosquito trap counts). Prescribing $V$ constrains how infection can partition vectors into susceptible and infectious classes; well-posedness and biological admissibility then require a compatibility condition between the abundance curve and vector mortality.
