# Epidemic coalescent models

Coalescent processes for the genealogies of pathogen samples, where the rate at which sampled lineages merge is set by the prevalence and incidence of an epidemic model rather than by a fixed population size. They connect the effective population size seen in a viral phylogeny to epidemiological quantities.
