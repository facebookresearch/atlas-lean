# Vaccine efficacy from person-time incidence

Estimators of the efficacy of a vaccine in a two-arm randomized trial from case counts and
accumulated person-time at risk: the point estimate as one minus an incidence rate ratio, and the
conjugate beta-binomial posterior obtained by conditioning on the total number of cases.

- [Vaccine efficacy as one minus the incidence rate ratio](vaccine-efficacy-as-one-minus-the-incidence-rate-ratio.md)
- [Beta-binomial posterior for vaccine efficacy](beta-binomial-posterior-for-vaccine-efficacy.md)
