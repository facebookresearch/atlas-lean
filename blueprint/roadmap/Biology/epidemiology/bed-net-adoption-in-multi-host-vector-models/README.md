# Bed-net adoption in multi-host vector models

Vector-borne disease models with two host types (one that can adopt insecticide-treated nets, one that cannot) in which net coverage evolves by imitation dynamics driven by perceived infection risk and vector abundance, and vectors shift biting preference toward unprotected hosts as coverage rises.
