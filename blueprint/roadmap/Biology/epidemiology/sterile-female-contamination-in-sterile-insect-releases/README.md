# Sterile-female contamination in sterile insect releases

Sterile insect technique models in which releases contain accidentally sterilized females and sterile males keep residual fertility. Residual fertility sets the minimal release rate for eliminating the wild vector. Released sterile females, though non-reproductive, can sustain arbovirus transmission once their release rate exceeds an explicit critical value.
