# Effective-degree branching process for network SIR

The early phase of a Markovian SIR epidemic on a configuration-model network, approximated by a multitype branching process whose type is an infective's number of unused edges (its effective degree). The process yields exact real-time expressions for mean prevalence, its variance and covariance function, and extinction probabilities.
