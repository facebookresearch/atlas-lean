# Spectral isolation control of network epidemics

Feedback control of epidemics spreading across a network of regions in which isolation rates are chosen so that the spectral abscissa of the Metzler infected-subsystem matrix stays below a prescribed negative level. Covers Perron-weighted decay certificates, invariant terminal sets from susceptible depletion, and their use in model predictive control.
