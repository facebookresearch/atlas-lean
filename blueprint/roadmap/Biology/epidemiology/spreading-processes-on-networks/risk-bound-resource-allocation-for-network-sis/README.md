# Risk-bound resource allocation for network SIS processes

Allocation of a per-step intervention budget across the edges (transmission reduction) and nodes (recovery increase) of a discrete-time mean-field SIS process on a network, by minimizing a linear upper bound on the discounted outbreak cost. Priority vectors satisfying a Bellman inequality give the bound, the relaxed problem is an exponential cone program, and its receding-horizon use is recursively feasible with a strictly decreasing risk bound.
