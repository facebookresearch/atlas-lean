# Superinfections on sparse random networks

A secondary SIR infection that can only spread among hosts currently carrying a primary SIR infection, on a sparse Erdős–Rényi contact network. In the large-network limit its early spread is a multi-type branching process in a time-varying environment set by the primary epidemic, and survival requires the two infections to run on matched timescales, giving a re-entrant phase boundary in the mean degree.
