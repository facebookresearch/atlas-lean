# Hysteretic behavioral response in epidemic models

Epidemic models in which interventions or individual precautions switch on and off at different infection levels, so the response depends on the history of the epidemic. Heterogeneous two-threshold responses aggregate into a Preisach hysteresis operator, producing continua of equilibria and requiring switched-system Lyapunov arguments.
