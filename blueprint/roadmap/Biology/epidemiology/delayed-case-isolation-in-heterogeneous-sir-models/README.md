# Delayed case isolation in heterogeneous SIR models

Case isolation that removes a fraction of infectious individuals from transmission after a fixed delay, analyzed as delayed feedback in SIR models whose individuals differ in contact rate. Near the disease-free state the heterogeneous model is equivalent to a homogeneous one with an inflated mixing parameter, which yields an explicit maximal tolerable isolation delay.
