# Optimal vaccine allocation in multi-group epidemics

Allocation of a limited vaccine supply among population groups in a multi-group SIR epidemic so as to minimize a weighted final size (infections, deaths). Asymptotic analysis gives explicit optimal policies in two limits: a small but highly vulnerable group, and a small total vaccine supply.
