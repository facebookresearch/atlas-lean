# Outbreak risk from imported cases

When infected travellers seed a destination population, each imported case starts an independent early-outbreak branching process. Combining a binomial model for the number of importations with the extinction probability of a negative-binomial Galton–Watson process gives a closed-form risk of at least one major local outbreak, as a function of the source epidemic size, the connectivity to the source, and the local reproduction number.
