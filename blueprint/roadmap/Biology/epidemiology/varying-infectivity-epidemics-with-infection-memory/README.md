# Varying-infectivity epidemics with infection memory

Individual-based epidemic models in which infectivity and susceptibility vary with the time since infection and with a trait inherited, with random modification, from the previous infection. Large-population limits are age- and trait-structured PDEs whose endemic equilibria are characterized through the Perron eigenfunction of the trait-transition kernel.
