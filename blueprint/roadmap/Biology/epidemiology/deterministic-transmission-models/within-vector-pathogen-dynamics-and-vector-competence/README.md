# Within-vector pathogen dynamics and vector competence

Pathogen load inside the mosquito population modelled as a predator–prey system: the pathogen consumes susceptible vector resources with a saturating (Holling type II) functional response, and vector competence scales both vector growth and susceptibility. Persistence of the pathogen is a threshold in vector competence.
