# Peak prevalence in multistage SIR models

In SIR models with Erlang-distributed infectious periods (infection passes through $k$ stages) the prevalence peak has no closed form, but a weighted aggregate of the stages has an explicit maximum identical to the classical SIR peak formula. Comparing the two quantifies when the weighted surrogate is accurate.
