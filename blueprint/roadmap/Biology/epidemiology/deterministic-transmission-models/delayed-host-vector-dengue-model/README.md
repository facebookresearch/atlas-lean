# Delayed host–vector dengue model

An SEIRS host – SEI vector model for dengue with saturating incidence and discrete delays for the extrinsic and intrinsic incubation periods and for recovery. The threshold for the disease-free state does not involve the delays, which instead shape stability switches of the endemic equilibrium.
