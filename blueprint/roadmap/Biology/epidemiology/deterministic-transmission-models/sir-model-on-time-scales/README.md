# SIR model on time scales

A dynamic SIR model on an arbitrary time scale $\mathbb T$ (a closed subset of $\mathbb R$, such as $\mathbb R$, $h\mathbb Z$ or $q^{\mathbb N_0}$) using delta derivatives and forward shifts chosen so that solutions stay nonnegative and admit closed-form expressions in time-scale exponentials, unifying the continuous, discrete and quantum SIR models.
