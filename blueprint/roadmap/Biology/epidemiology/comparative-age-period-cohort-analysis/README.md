# Comparative age-period-cohort analysis

Incidence or mortality rates indexed by age group and calendar period on a common Lexis diagram are modelled, stratum by stratum, by age-period-cohort models. Comparing strata through cross-hazard rate ratios leads to a small set of proportionality classes, determined by which of the three time scales (age, period, birth cohort) the ratios depend on, and each class constrains the estimable functions of the strata.
