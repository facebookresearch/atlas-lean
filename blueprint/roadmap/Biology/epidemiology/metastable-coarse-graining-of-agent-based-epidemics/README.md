# Metastable coarse-graining of agent-based epidemics

Reduction of spatial agent-based models, in which agents diffuse in a landscape with metastable regions and change status (for example susceptible to infected) through local contacts, to a stochastic metapopulation model on the regions. The reduction is a Galerkin projection of the agent-based generator onto indicator functions of region-wise status counts and yields mass-action reaction rates plus a vanishing cross-region interaction term.
