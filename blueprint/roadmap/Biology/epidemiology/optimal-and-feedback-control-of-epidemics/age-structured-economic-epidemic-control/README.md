# Age-structured economic–epidemic control

Social-planner problems coupling an age-structured SIR epidemic, with infection-dependent mortality, to neoclassical capital accumulation, where lockdown, testing and consumption are chosen by age and time. The problem is recast as an evolution equation in a Hilbert space and attacked by dynamic programming.
