# Testing-rate control of the SIDUR model

Epidemic models in which the daily testing rate is the control input. Tests detect and isolate undetected infected individuals in proportion to their share of a testable population. The results give the minimal testing rate that halts epidemic growth, and the constant allocation of a finite test stockpile that minimises the epidemic peak.
