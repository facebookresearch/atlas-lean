# Viscosity solutions for optimal SIRS vaccination

Infinite-horizon discounted vaccination control of an SIRS epidemic in which immunity wanes: the minimal social cost is a semiconcave viscosity solution of a Hamilton–Jacobi–Bellman equation, a non-smooth verification theorem identifies optimal feedback vaccination rates from supergradients, and the value function is the unique bounded semiconcave solution.
