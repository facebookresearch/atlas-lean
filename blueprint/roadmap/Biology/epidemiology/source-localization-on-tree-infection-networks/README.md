# Source localization on tree infection networks

An SI outbreak spreads from an unknown source along a known tree with independent random edge delays, and only a subset of nodes (observers) report infection times. Which observers matter, and whether the source is identifiable, can be decided from the joint Laplace transform of the observed times, which factors over edges.
