# Acute target-cell-limited infection

Within-host models of an acute viral infection (such as SARS-CoV-2) in which target cells are not replenished on the time scale of infection. The infection-free states form a continuum of equilibria indexed by the remaining target cells; stability holds for the set below a critical target-cell level rather than for any single point.
