# Practical identifiability of the SIR model

Before the epidemic peak, SIR trajectories with very different transmission and recovery rates, but nearly equal growth rate, are almost indistinguishable. Linearizing the early dynamics gives an explicit approximation to the type II error of the most powerful test between nearby parameter values, which quantifies how little noisy early incidence data reveal about $\mathcal{R}_0$.
