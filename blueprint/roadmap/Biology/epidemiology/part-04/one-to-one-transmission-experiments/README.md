# One-to-one transmission experiments

In a one-to-one animal transmission experiment, each of $n$ independent pairs consists of one inoculated (infectious) animal and one susceptible animal, and the outcome of each pair is whether transmission occurred. Modelling each pair as a two-individual stochastic general epidemic turns the binomial count of infected pairs into a statement about the basic reproduction number, and yields exact tests and minimum sample sizes.
