# Surveillance testing and viral load kinetics

Models that couple a within-host viral load trajectory to a test's limit of detection and to infectiousness, used to compare screening programmes by how much transmission they remove. A test that detects every infectious day makes testing frequency and result turnaround, rather than analytical sensitivity, the main levers.
