# Hospital infection control incentives

A hospital is modelled as a chemostat: patients are admitted (some already colonized) and discharged at constant occupancy while a pathogen spreads within the ward. Spending on infection control lowers transmission with diminishing returns; each hospital chooses spending to minimize its own cost, and subsidies from a public authority shift that choice.
