# Action of a group on functions on a permutation set

For a group $G$ acting on a set $\Omega$, an element $g \in G$ and a function $m \colon \Omega \to F$, the function $g \cdot m \colon \Omega \to F$, $(g \cdot m)(\omega) = m(g^{-1}\omega)$; this realizes the permutation module $F\Omega$ as $F^\Omega$.
