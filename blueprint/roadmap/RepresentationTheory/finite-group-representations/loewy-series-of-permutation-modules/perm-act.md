# Action of a group on functions on a permutation set

For a group $G$ acting on a set $\Omega$, an element $g \in G$ and a function $m \colon \Omega \to F$, the function $g \cdot m \colon \Omega \to F$, $(g \cdot m)(\omega) = m(g^{-1}\omega)$. On all functions $F^\Omega$ this is the permutation module $F\Omega$ when $\Omega$ is finite; for infinite $\Omega$ the permutation module consists of the finitely supported functions, and $F^\Omega$ is larger (it contains the constant function $1$).
