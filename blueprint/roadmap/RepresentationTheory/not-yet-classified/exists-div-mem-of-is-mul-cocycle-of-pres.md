# Presentation criterion for multiplicative 1-cocycles

Let `π : M → P` restrict to a
surjective `G`-equivariant homomorphism from a `G`-stable subgroup `Fn` onto `P`, with
`π x = 0 ↔ x ∈ Fn₁` for `x ∈ Fn`, so that the kernel of this restriction is `Fn ∩ Fn₁`. If every
additive 1-cocycle `G → P` is a coboundary, then every multiplicative 1-cocycle `f` with values in
`Fn` is a coboundary up to this kernel: for some `a ∈ Fn`, each `f g / (g • a / a)` lies in `Fn₁`,
hence in `Fn ∩ Fn₁`.
