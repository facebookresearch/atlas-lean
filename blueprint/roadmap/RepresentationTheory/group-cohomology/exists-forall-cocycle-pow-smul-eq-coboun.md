# Uniform exponent for torsion cocycle classes

Let `B` be a commutative Noetherian ring, `R` a commutative `B`-algebra that
is finite as a `B`-module, and `G` a finite group acting on `R` by ring
automorphisms commuting with the action of `B`. For every `t ∈ B` there is
an exponent `e` with the following property. If `y : G → R` is an additive
1-cocycle, `y (g * h) = g • y h + y g`, and some power `t ^ k` sends `y` to
a coboundary, `t ^ k • y g = g • z - z` for some `z ∈ R`, then already `t ^
e • y g = g • z' - z'` for all `g` and some `z' ∈ R`.

The exponent `e` depends only on `t`, not on the cocycle `y`.
