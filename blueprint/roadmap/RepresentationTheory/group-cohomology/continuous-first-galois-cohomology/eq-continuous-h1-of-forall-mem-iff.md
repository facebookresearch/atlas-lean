# Characterization of continuous first cohomology

Let `adm₁` be a `k`-submodule of `H¹(G, M)` such that a class `x` lies in
`adm₁` if and only if `x` is the class of a 1-cocycle `c` for which there is
a finite extension `F` of `ℚ` inside `ℚ̄` with `c (g * s) = c g` whenever `r
s` fixes `F` pointwise. Then `adm₁ = continuousH1 r M`.

Throughout, `k` is a commutative ring, `G` is a group, `r : G → Gal(ℚ̄/ℚ)`
is a group homomorphism, and `M` is a `k`-linear representation of `G`. A
function `f` on `G` is level constant (for `r`) when there is a finite
extension `F` of `ℚ` inside `ℚ̄` such that `f (g * s) = f g` for all `g, s ∈
G` with `r s` fixing `F` pointwise.
