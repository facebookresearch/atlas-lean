# Level-constant cocycles give continuous classes

If a 1-cocycle `c` of `G` with values in `M` is level constant, then its
cohomology class in `H¹(G, M)` lies in the continuous first cohomology
`continuousH1 r M`.

Throughout, `k` is a commutative ring, `G` is a group, `r : G → Gal(ℚ̄/ℚ)`
is a group homomorphism, and `M` is a `k`-linear representation of `G`. A
function `f` on `G` is level constant (for `r`) when there is a finite
extension `F` of `ℚ` inside `ℚ̄` such that `f (g * s) = f g` for all `g, s ∈
G` with `r s` fixing `F` pointwise.
