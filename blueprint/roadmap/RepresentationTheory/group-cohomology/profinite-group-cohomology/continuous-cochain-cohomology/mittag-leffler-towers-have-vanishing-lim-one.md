# Mittag-Leffler towers have vanishing first derived limit

Let $R$ be a ring and $(B_n, d_n)_{n \in \mathbb{N}}$ an inverse system of $R$-modules. It satisfies the
Mittag-Leffler property if for each $n$ the images of the transition maps $B_{n+m} \to B_n$ are the same for all
sufficiently large $m$; every inverse system of finite abelian groups has this property. If $(B_n)$ satisfies the
Mittag-Leffler property, then its [first derived limit](first-derived-limit-of-a-tower.md) vanishes:

$$
\varprojlim\nolimits^1_n B_n = 0.
$$

In particular $\varprojlim^1_n B_n = 0$ for every inverse system of finite abelian groups.
