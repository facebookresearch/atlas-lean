# Continuous cochain cohomology

The continuous cochain cohomology $H^n_{\mathrm{cts}}(G, A)$ of a profinite group $G$ with coefficients in a
topological $G$-module $A$, the cohomology of the complex of continuous homogeneous cochains, following
Neukirch–Schmidt–Wingberg, Chapter II, §7, and Tate's results for finitely generated $\mathbb{Z}_\ell$-modules and
$\mathbb{Q}_\ell$-vector spaces. For a discrete module it is the
[cohomology with discrete coefficients](../discrete-coefficients/cohomology-with-discrete-coefficients.md).
