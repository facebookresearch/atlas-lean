# Modules over a finite p-group with no invariants

Let $p$ be a prime number, $G$ a finite $p$-group and $A$ a $p$-primary $G$-module, that is, every element of $A$ has
$p$-power order. If $A^G = 0$, then $A = 0$. If moreover $A$ has bounded exponent, that is, $p^n A = 0$ for some
$n$ (for instance if $A$ is finite), and $A_G = A / I_G A = 0$, where $I_G A$ is the subgroup generated by the
elements $\sigma a - a$, then $A = 0$.

For $A^G$ the proof reduces to finite $A$, since every element of $A$ generates a finite $G$-submodule, where
$\#A \equiv \#A^G \pmod p$ because the orbits outside $A^G$ have order divisible by $p$. The congruence for the number
of fixed points of a $p$-group acting on a finite set is Mathlib's `IsPGroup.card_modEq_card_fixedPoints`. For $A_G$,
the $G$-module $\operatorname{Hom}(A, \mathbb{Z}/p\mathbb{Z})$ is killed by $p$ and its invariants
$\operatorname{Hom}(A_G, \mathbb{Z}/p\mathbb{Z})$ vanish, so it is zero by the first assertion; hence $A = pA$, and
$A = p^n A = 0$.

The bounded exponent cannot be dropped from the second assertion, which the source states for every $p$-primary $A$:
the group $\{\pm 1\}$ of order $2$ acting on $\mathbb{Q}_2/\mathbb{Z}_2$ by $a \mapsto -a$ has $I_G A = 2A = A$, so
$A_G = 0$ although $A \ne 0$. The duality argument of the source fails there because
$\operatorname{Hom}(\mathbb{Q}_2/\mathbb{Z}_2, \mathbb{Q}_2/\mathbb{Z}_2) \cong \mathbb{Z}_2$ is not $2$-primary.
