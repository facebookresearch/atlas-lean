# Proposition 27.14

Let $Y$ be an irreducible normal algebraic variety. Then (i) The singular locus of $Y$ has codimension $\geq 2$. (ii) If $U \subset Y$ is an open subset and $Y \backslash U$ has codimension $\geq 2$ then any regular function $f$ on $U$ extends to a regular function on $Y$. In particular, any regular function on the smooth locus of $Y$ extends to a regular function on $Y$. (iii) (Zariski main theorem) If $X$ is irreducible and $p: X \rightarrow Y$ is a proper birational morphism then fibers of $p$ are connected.
