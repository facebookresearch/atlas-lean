# Proposition 22.5

(i) If $F_1, F_2$ are projective functors then every morphism $\varphi \colon F_1(\theta) \rightarrow F_2(\theta)$ lifts to a morphism $\hat{\varphi} \colon F_1|_{\operatorname{Rep}(\mathfrak{g})_{\theta}} \rightarrow F_2|_{\operatorname{Rep}(\mathfrak{g})_{\theta}}$. (ii) If $F_1 = F_2$ and $\varphi^2 = \varphi$ then we can choose $\hat{\varphi}$ so that $\hat{\varphi}^2 = \hat{\varphi}$. (iii) If $\varphi$ is an isomorphism then so is $\hat{\varphi}$.
