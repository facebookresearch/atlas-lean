# Lemma 3.2

(i) If a sequence $\{\mu_n, n \geq 1\} \in C(X)^{*}$ is Cauchy then there is a compact subset $K \subset X$ such that $\mu_n \in C(K)^{*} \subset C(X)^{*}$ for all $n$. (ii) $C(X)^{*}$ is sequentially complete.
