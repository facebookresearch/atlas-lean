# Definition 8.2

We say that $V$ has a weight decomposition (with respect to a Cartan subalgebra $\mathfrak{h} \subset \mathfrak{g}$), or is $\mathfrak{h}$-semisimple if $V'=V$, i.e., if $V=\oplus_{\lambda \in \mathfrak{h}^{*}} V[\lambda]$.
