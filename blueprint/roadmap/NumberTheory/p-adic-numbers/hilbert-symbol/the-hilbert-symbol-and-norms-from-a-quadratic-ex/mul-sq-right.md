# The Hilbert symbol depends only on the square class of its second argument

For a field
$F$ and nonzero $a, b, c \in F$, the Hilbert symbol satisfies $(a, b c^2) = (a, b)$ (J.-P. Serre,
*A Course in Arithmetic*, Chapter III, §1.1, p. 19: "(a, b) does not change when a and b are
multiplied by squares"; for the first argument this is `hilbertSymbol.mul_sq_left`).
