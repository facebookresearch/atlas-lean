# A p-adic integer is a unit if and only if its p-adic absolute value is 1

Let $p$ be a prime number and let $\mathbb{Z}_p = \{x \in \mathbb{Q}_p : |x|_p \le 1\}$ be the ring of $p$-adic integers. An element $z \in \mathbb{Z}_p$ is a unit of $\mathbb{Z}_p$, that is, $zw = 1$ for some $w \in \mathbb{Z}_p$, if and only if $|z|_p = 1$.
