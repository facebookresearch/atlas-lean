# The length $L_5(4)$ is at most $1$

For the Ducci map $D$ on $\mathbb{Z}_5^4$ and the basic tuple $u = (0, 0, 0, 1)$, $D^5(u) = D(u)$, so the length $L_5(4)$ of the basic Ducci sequence satisfies $L_5(4) \le 1$.

## Sources

- Mark L. Lewis and Shannon M. Tefft, *The Maximum Length for Ducci Sequences on $\mathbb{Z}_m^n$ when $n$ is Even*, INTEGERS 26 (2026), Article A17, Section 1 (example).
