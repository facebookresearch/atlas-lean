# One Ducci step from the basic tuple in $\mathbb{Z}_5^4$

In $\mathbb{Z}_5^4$ the Ducci map sends the basic tuple $(0, 0, 0, 1)$ to $(0, 0, 1, 1)$.

## Sources

- Mark L. Lewis and Shannon M. Tefft, *The Maximum Length for Ducci Sequences on $\mathbb{Z}_m^n$ when $n$ is Even*, INTEGERS 26 (2026), Article A17, Section 1 (example).
