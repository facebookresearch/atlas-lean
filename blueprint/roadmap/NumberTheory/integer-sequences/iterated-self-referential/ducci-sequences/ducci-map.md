# The Ducci map on $\mathbb{Z}_m^n$

For integers $m \ge 0$ and $n \ge 1$, the Ducci map $D : \mathbb{Z}_m^n \to \mathbb{Z}_m^n$ sends $(x_1, \dots, x_n)$ to $(x_1 + x_2, x_2 + x_3, \dots, x_{n-1} + x_n, x_n + x_1)$: entry $i$ of $D(x)$ is $x_i + x_{i+1}$, with the indices taken cyclically. Write $\mathbb{Z}_m = \mathbb{Z}/m\mathbb{Z}$, so that $\mathbb{Z}_0 = \mathbb{Z}$, and index the entries of a tuple in $\mathbb{Z}_m^n$ by $1, \dots, n$, cyclically, so that entry $n + 1$ is entry $1$.

## Sources

- Mark L. Lewis and Shannon M. Tefft, *The Maximum Length for Ducci Sequences on $\mathbb{Z}_m^n$ when $n$ is Even*, INTEGERS 26 (2026), Article A17, Section 1.
