# Stern's diatomic sequence

The Stern sequence is the function
$s : \mathbb{N} \to \mathbb{N}$ defined by $s(0) = 0$, $s(1) = 1$, and, for every $n \ge 1$,
$s(2n) = s(n)$ and $s(2n + 1) = s(n) + s(n + 1)$.
