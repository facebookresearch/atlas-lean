# The Klarner set has lower density zero

It is not the case that the Klarner set has positive lower density ($\liminf_N |A \cap [0, N)|/N > 0$), where the Klarner set is the smallest set of natural numbers that contains $1$ and is closed under $x \mapsto 2x+1$, $x \mapsto 3x+1$ and $x \mapsto 6x+1$. That is, its lower density is $0$.

The published counting estimate gives more: $|A \cap [1, X]| \ll X^{\tau + o(1)}$ with $\tau \approx 0.900526 < 1$, the positive root of $6^{-\tau} + \sum_{k \ge 0} (3 \cdot 2^k)^{-\tau} = 1$, that is, of $6^{-\tau} + 3^{-\tau}/(1 - 2^{-\tau}) = 1$, so $A$ has natural density $0$. That consequence is stronger than the statement here, which only negates positive lower density.

This refutes [Erdős Problem 1134 (lower density of the set generated by 2x + 1, 3x + 1, 6x + 1)](klarner-set-positive-lower-density.md), the statement recorded as a proposition; the refutation is due to Crampin and Hilton, whose proof Klarner reported in 1982; Lagarias (2016) reproduces it. Both are cited under Sources.
