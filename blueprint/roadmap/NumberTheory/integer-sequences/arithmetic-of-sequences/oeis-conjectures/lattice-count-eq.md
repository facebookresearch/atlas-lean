# Lattice points with bounded coordinates and given $\ell^1$ norm

For $m, k, n \in \mathbb{N}$, $b_{n,k}^{(m)}$ is the number of integer points $(x_1, \dots, x_m) \in \mathbb{Z}^m$ with $\lvert x_i \rvert \le k$ for every $i$ and

$$\sum_{i=1}^{m} \lvert x_i \rvert = n.$$

## Sources
