# Newton sequences

Let $R$ be a commutative semiring and let $a, c \colon \mathbb{N} \to R$.
The sequence $a$ is a Newton sequence generated by $c$ if for every natural number $n$,
$a_{n+1} = \sum_{j=0}^{n-1} a_{n-j} c_{j+1} + (n+1) c_{n+1}$.

Equivalently, $a_m = \sum_{k=1}^{m-1} a_{m-k} c_k + m c_m$ for every $m \ge 1$. The sequences in
the sources begin at index one, so $a_0$ and $c_0$ play no role. The two sources write the
factors in opposite orders, which agree because $R$ is commutative.
