# The only triangular Sylvester number is $3$

Let $S_n$ denote the $n$-th Sylvester
number. A natural number $x$ equals $S_n$ for some $n$ and satisfies $2x = m(m + 1)$ for some
natural number $m \ge 1$ if and only if $x = 3$.
