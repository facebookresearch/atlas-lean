# Erdős Problem 440, first question

The statement that for every strictly increasing sequence $a_0 < a_1 < \cdots$ of positive integers there is a real $C$ with $A(x) \le C\sqrt{x}$ for every $x \in \mathbb{N}$, where $A(x)$ is the number of indices $i$ with $\operatorname{lcm}(a_i, a_{i+1}) \le x$.
