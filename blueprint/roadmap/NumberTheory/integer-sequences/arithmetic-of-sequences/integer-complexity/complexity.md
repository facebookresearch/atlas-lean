# Integer complexity

The integer complexity of a positive integer $n$ is the least
number of ones in an expression whose value is $n$, that is, the least number of ones needed
to write $n$ using $1$, $+$, $\times$ and parentheses.

## Sources

- Juan Arias de Reyna, *Complexity of Natural Numbers*, arXiv:2111.03345 (2021), definition of the complexity $\lVert n \rVert$ as the least number of ones needed to write $n$ with $1$, $+$, $\times$ and parentheses.
