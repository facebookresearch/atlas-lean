# Le log of halving

Let `a : ℕ → ℕ` be a sequence with `a 0 ≤ n` and `a (k + 1) ≤ a k / 2` for every `k` (natural-number division). Then every index `k` with `a k > 0` satisfies `k ≤ log₂ n` (the floor of the base-2 logarithm). This bounds the index of the last positive term, that is, the number of completed halvings.
