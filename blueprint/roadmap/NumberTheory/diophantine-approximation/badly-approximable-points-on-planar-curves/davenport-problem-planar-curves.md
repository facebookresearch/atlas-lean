# Davenport's problem on badly approximable points on planar curves

The statement that for all reals $a < b$, every $f$ that is twice continuously differentiable on $(a, b)$ with $f''(x_0) \ne 0$ for some $x_0 \in (a, b)$, and all reals $i, j > 0$ with $i + j = 1$, the set of points $(x, f(x))$, $x \in (a, b)$, lying in $\mathrm{Bad}(i, j)$ is uncountable. Here $\mathrm{Bad}(i, j)$ is the set of $(x, y)$ with $\max(\|qx\|^{1/i}, \|qy\|^{1/j}) > c/q$ for some $c > 0$ and every integer $q \ge 1$, where $\|t\|$ denotes the distance from a real $t$ to the nearest integer.

This page records the statement as a proposition. Its resolution: [Non-degenerate planar curves contain uncountably many badly approximable points](davenport-problem-planar-curves-holds.md).
