# Weighted badly approximable points in the plane

For reals $i$ and $j$, the set $\mathrm{Bad}(i, j)$ of $(i, j)$-badly approximable points consists of the $(x, y) \in \mathbb{R}^2$ for which there is $c > 0$ with

$$\max\bigl(\|qx\|^{1/i},\, \|qy\|^{1/j}\bigr) > \frac{c}{q}$$

for every integer $q \ge 1$, where $\|t\|$ denotes the distance from a real $t$ to the nearest integer.
