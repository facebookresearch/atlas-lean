# Weighted badly approximable points in the plane

For reals $i$ and $j$, the set $\mathrm{Bad}(i, j)$ consists of the $(x, y) \in \mathbb{R}^2$ for which there is $c > 0$ with

$$\max\bigl(\|qx\|^{1/i},\, \|qy\|^{1/j}\bigr) > \frac{c}{q}$$

for every integer $q \ge 1$, where $\|t\|$ denotes the distance from a real $t$ to the nearest integer. The powers are real powers with $1/0 = 0$, so a zero weight makes its term $t^{1/0} = t^0 = 1$, also when $t = 0$; then every point lies in the set (take $c = 1/2$), and for instance $\mathrm{Bad}(0, 1)$ contains $(0, 0)$.

For positive weights $i, j$ with $i + j = 1$, the case the planar-curve problem uses, this is the classical set of $(i, j)$-badly approximable points. At the endpoint weights the classical set instead drops the term of a zero weight entirely, as in [weighted badly approximable pairs](../weighted-badly-approximable-pairs/is-weighted-badly-approximable.md), which excludes $(0, 0)$.
