# Complete Young graphs

For natural numbers $g$, $k$ and $m$ with $2 \le k < g$, the Young graph
$Y(g,k)$ of the $k$-reverse multiples in base $g$ is complete on $m$ nodes if
its $m$ ordinary nodes include $[0,0]$ and have exactly one directed edge for
each ordered pair, including a loop at each node. The distinct starting node
$[[0,0]]$ has an edge to every ordinary node except $[0,0]$, and no edge ends
at the start. Thus $Y(g,k)$ has $m+1$ nodes in all.
