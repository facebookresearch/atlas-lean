# Palindromic half copies of $5570$ in bases $5$ and $8$

Write $C_b(m)$ for the
palindromic half copy of $m$ in base $b$. For $m = 5570 = (134240)_5 = (12702)_8$,
$C_5(m) = (134431)_5 = 5616$ and $C_8(m) = (12721)_8 = 5585$.
