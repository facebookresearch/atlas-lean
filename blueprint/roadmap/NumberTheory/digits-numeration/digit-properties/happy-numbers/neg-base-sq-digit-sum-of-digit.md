# The digit-square sum of a single digit

Let $b$ and $d$ be integers with $0 < d < -b$, so
that $b \le -2$ and $d$ is a nonzero base-$b$ digit. Then the base-$b$ digit-square sum $S_{2,b}$
satisfies $S_{2,b}(d) = d^2$.
