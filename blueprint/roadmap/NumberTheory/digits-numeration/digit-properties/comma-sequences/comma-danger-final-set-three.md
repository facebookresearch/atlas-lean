# Offsets of final terms in base 3

$U(3, 1) = \{1, 2, 4, 5, 7\}$ and $U(3, 2) = \{1, 2, 4, 7\}$, where for natural numbers $b$ and $d$, $U(b, d)$, the set of offsets $u$ of final terms $d b^k - u$ for $b \ge 2$, $1 \le d < b$ and $k > 2$ (see the [characterization of final values in danger intervals](comma-danger-final-iff-mem.md)), is the set of numbers $u = rb + s$ with digits $r, s < b$ such that, when $d = 1$, $s > 0$ and $r + s \le b$, and when $d \ne 1$, either $s > 0$ and $r + s < b$, or $r + s = b$ and $s < d$.
