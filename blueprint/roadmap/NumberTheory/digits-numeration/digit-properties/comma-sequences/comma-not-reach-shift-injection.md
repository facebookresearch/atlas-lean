# Shifting non-escaping comma values to the next base

For natural numbers $b \ge 3$ and $k \ge 3$, where $I_k(c)$ is the set of $v$ with $c^k - c^2 \le v < c^k$ such that every term reachable from $v$ by base-$c$ comma successor steps is less than $c^k$: (1) for $r, s < b - 1$, if $(b-1)^k - (b-1)^2 + r(b-1) + s \in I_k(b-1)$ then $b^k - b^2 + (r+1)b + s \in I_k(b)$; (2) the map $(r, s) \mapsto b^k - b^2 + (r+1)b + s$ is injective on $r, s < b - 1$; (3) every $w \in I_k(b)$ that is not the image of such $(r, s)$ with preimage in $I_k(b-1)$ is $b^k - b^2 + b + (b - 2)$ or $b^k - b^2 + y$ for some $0 < y < b - 1$.
