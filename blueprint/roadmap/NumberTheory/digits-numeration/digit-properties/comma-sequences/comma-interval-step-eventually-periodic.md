# The comma map is eventually periodic in the exponent

For every base $b \ge 2$ there are $L > 0$ and $K$ such that for all $d, u, u', k, k'$ with $1 \le d < b$, $0 < u \le b^2$, $k, k' \ge K$ and $k \equiv k' \pmod L$, the comma map sends $(d, u, k)$ to $u'$ if and only if it sends $(d, u, k')$ to $u'$. Here, with $T = (d+1)b^k$ for $d < b - 1$ and $T = b^{k+1}$ otherwise, the comma map sends $(d, u, k)$ to $u'$ when $0 < u' \le b^2$, the base-$b$ comma sequence from $db^k - u$ reaches $T - u'$, and $T - u'$ has no comma successor or only comma successors at least $T$. Both subtractions $d b^k - u$ and $T - u'$ are truncated natural subtractions, with value $0$ when the subtrahend is larger: for $(b, d, u, k) = (2, 1, 2, 0)$ the sequence starts at $0$, not at $-1$.
