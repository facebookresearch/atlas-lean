# Comma sequences terminate if and only if the reduced digraph is acyclic

For every base $b \ge 2$, the base-$b$ comma sequence starting at every positive integer terminates if and only if the reduced comma digraph $G_b'$ has no directed cycle.

## Sources

- R. Dougherty-Bliss and N. Ter-Saakov, The comma sequence is finite in other bases, J. Integer Seq. 28 (2025), Article 25.5.5.
