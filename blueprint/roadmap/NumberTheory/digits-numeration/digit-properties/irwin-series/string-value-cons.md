# Value of a digit string with a first digit

For a natural number $b$, a digit
$a < b$ and a string $X$ of base-$b$ digits, the integer value of the string $a X$ is
$a \cdot b^{|X|}$ plus the integer value of $X$.

## Sources

- Jean-François Burnol, *Measures for the Summation of Irwin Series*, INTEGERS 26 (2026), Article A11, Notation and Terminology.
