# Normalized digit-string values lie in $(0, 1)$

For a natural number $b > 1$ and a
string $X$ of base-$b$ digits, the normalized value of $X$ is a real number in $[0, 1)$.

## Sources

- Jean-François Burnol, *Measures for the Summation of Irwin Series*, INTEGERS 26 (2026), Article A11, definition of `μ_k`.
