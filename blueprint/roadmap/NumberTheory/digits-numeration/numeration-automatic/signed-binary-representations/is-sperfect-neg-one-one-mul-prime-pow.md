# Prime-power lifting of {−1, 1}-perfect numbers

Let $n$ be an integer and $p$ a prime with $p \nmid n$. (a) If $n$ is $\{-1, 1\}$-perfect then so is $np^k$ for every $k \ge 1$. (b) If $np$ is $\{-1, 1\}$-perfect then so is $np^{2k-1}$ for every $k \ge 1$. Here for a set $S$ of integers, an integer $n$ with $|n| > 1$ is $S$-perfect when $n = 1 + \sum_d \lambda_d d$, the sum over the divisors $d$ of $|n|$ with $1 < d < |n|$, for some weights $\lambda_d \in S$.
