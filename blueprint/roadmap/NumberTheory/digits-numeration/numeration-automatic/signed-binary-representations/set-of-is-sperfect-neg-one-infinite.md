# Infinitely many {−1, m}-perfect numbers

For every natural number $m \ge 1$ there are infinitely many natural numbers that are $\{-1, m\}$-perfect. Here for a set $S$ of integers, an integer $n$ with $|n| > 1$ is $S$-perfect when $n = 1 + \sum_d \lambda_d d$, the sum over the divisors $d$ of $|n|$ with $1 < d < |n|$, for some weights $\lambda_d \in S$.
