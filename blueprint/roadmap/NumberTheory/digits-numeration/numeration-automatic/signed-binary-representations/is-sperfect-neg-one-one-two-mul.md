# Doubling {−1, 1}-perfect numbers

If an integer $n$ is $\{-1, 1\}$-perfect then so is $2n$. Here for a set $S$ of integers, an integer $n$ with $|n| > 1$ is $S$-perfect when $n = 1 + \sum_d \lambda_d d$, the sum over the divisors $d$ of $|n|$ with $1 < d < |n|$, for some weights $\lambda_d \in S$.
