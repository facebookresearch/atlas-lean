# Monotonicity of S-perfect numbers in the weight set

For every family $(S_i)$ of sets of integers, every integer that is $S_i$-perfect for some $i$ is $\bigcup_i S_i$-perfect, and every $\bigcap_i S_i$-perfect integer is $S_i$-perfect for every $i$. Here for a set $S$ of integers, an integer $n$ with $|n| > 1$ is $S$-perfect when $n = 1 + \sum_d \lambda_d d$, the sum over the divisors $d$ of $|n|$ with $1 < d < |n|$, for some weights $\lambda_d \in S$.
