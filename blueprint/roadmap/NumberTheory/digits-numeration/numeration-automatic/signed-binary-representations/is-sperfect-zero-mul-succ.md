# Lifting {0, m}-perfect numbers

For natural numbers $m \ge 1$, if an integer $n$ is $\{0, m\}$-perfect then so is $(m + 1)n$. Here for a set $S$ of integers, an integer $n$ with $|n| > 1$ is $S$-perfect when $n = 1 + \sum_d \lambda_d d$, the sum over the divisors $d$ of $|n|$ with $1 < d < |n|$, for some weights $\lambda_d \in S$.
