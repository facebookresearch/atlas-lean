# Totient lower bounds for class numbers of imaginary quadratic orders

Let $D < 0$ be a
fundamental discriminant, let $f \ge 1$ be an integer and let $\varphi$ be Euler's totient
function. If $D \notin \{-3, -4\}$, then the Gauss class numbers satisfy
$h(D)\, \varphi(f) \le h(f^2 D)$. If $D \in \{-3, -4\}$, then $\varphi(f) \le 3\, h(f^2 D)$.

Here $h(d)$ is the Gauss class number `gaussClassNumber d`, the number of primitive positive
definite Gauss-reduced binary quadratic forms of discriminant $d$.

## Sources

- Guy Fowler, *Some uniform effective results on André–Oort for sums of powers in* $\mathbb{C}^n$, Math. Proc. Cambridge Philos. Soc. 180 (2026), 607–641, proof of Proposition 2·7, pp. 615–616, which derives both bounds from the class number formula for imaginary quadratic orders (Cox, *Primes of the form* $x^2 + ny^2$, Theorem 7.24, as cited there).
