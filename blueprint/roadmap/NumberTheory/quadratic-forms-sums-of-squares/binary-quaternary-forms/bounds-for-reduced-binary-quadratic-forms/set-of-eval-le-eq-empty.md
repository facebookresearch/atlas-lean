# No values below $c$ off the first axis

For a Gauss-reduced form
$q(x, y) = ax^2 + bxy + cy^2$, the set of pairs
$(m, n) \in \mathbb{Z} \times \mathbb{Z}_{\ge 1}$ with $q(m, n) \le t$ is empty for every real
$t < c$; so its cardinality $N_q(t)$ is $0$.

## Sources

- J. Oesterlé, *Nombres de classes des corps quadratiques imaginaires*, Séminaire Bourbaki, vol. 1983/84, exposé 631, Astérisque 121–122 (1985), 309–323, §1.3 (p. 312): "Le nombre $N_q(t)$ des couples $(m,n) \in \mathbb{Z} \times \mathbb{N}^*$ tels que $q(m,n) \le t$ est nul pour $t < c$".
