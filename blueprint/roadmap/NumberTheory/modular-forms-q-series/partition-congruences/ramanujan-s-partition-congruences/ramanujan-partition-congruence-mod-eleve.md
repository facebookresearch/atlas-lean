# Ramanujan's congruence modulo 11

For every natural number $m$, the number of partitions
of $11m + 6$ is divisible by $11$.

Proof: Hirschhorn's argument extracts the terms of the right residue class from the generating
function, using Euler's pentagonal number theorem and Jacobi's identity for the cube of the Euler
product.
