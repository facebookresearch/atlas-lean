# Archimedean type of a function on adelic GL₂

For a number field $F$, characters $\chi_w$ of the determinant-one row isometries of $\mathrm{GL}_2(F_w)$ for each infinite place $w$, and $\varphi : \mathrm{GL}_2(\mathbb{A}_F) \to \mathbb{C}$, the condition that for every $w$, $\varphi$ has archimedean character $\chi_w$ at an infinite place $w$ when $\varphi(g\,\iota_w(k)) = \chi_w(k)\varphi(g)$ for every $g \in \mathrm{GL}_2(\mathbb{A}_F)$ and every row isometry $k \in \mathrm{GL}_2(F_w)$ of determinant $1$, where $\iota_w$ places $k$ at $w$ and the identity elsewhere.
