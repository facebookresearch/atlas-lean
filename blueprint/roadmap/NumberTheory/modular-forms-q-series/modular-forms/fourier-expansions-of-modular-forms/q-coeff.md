# q-expansion coefficients

For a function $f$ on the upper half-plane and $n \in \mathbb{N}$, $a_n(f)$ is defined formally as $\frac{1}{n!}$ times the $n$-th iterated derivative at $0$ of the width-one cusp function $F$ of $f$, where $F(q) = f(\log q / 2\pi i)$ with the principal logarithm for $0 < |q| < 1$ and $F(0)$ is the limit of $F$ at $0$ (a default value when there is none). The derivative is iterated using the complex derivative operator that returns $0$ at any point where the function is not complex differentiable: for $f(\tau) = \overline{\exp(2\pi i\tau)}$ the cusp function is $F(q) = \bar q$ near $0$, which has no complex derivative at $0$, so $a_1(f) = 0$. When $f$ is $1$-periodic, holomorphic and bounded at infinity, so that $f(\tau) = F(e^{2\pi i\tau})$ with $F$ holomorphic at $0$, this is the coefficient of $q^n$ in the $q$-expansion of $f$ with $q = e^{2\pi i\tau}$. In general $f$ need have no expansion in $q$ (for $f(\tau) = \tau$, the points $i$ and $i + 1$ have the same $q$ but different values), and the coefficient is still defined.
