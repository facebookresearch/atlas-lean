# Ramanujan's theta sum for arbitrary parameters

For complex numbers $a$ and $b$, put
$\sum_{n \in \mathbb{Z}} a^{n(n+1)/2} b^{n(n-1)/2}$ when this series is summable, and $0$
otherwise.

The value $0$ for a non-summable series is a convention. When the series is summable, in
particular when $|ab| < 1$, this is Ramanujan's general theta function $f(a,b)$.
