# Sequences with property P have density zero, as a statement

The statement that for every strictly increasing sequence $a_0 < a_1 < \cdots$ of natural numbers whose set of values has property P, $a_j/j \to \infty$ as $j \to \infty$; here a set $A$ of natural numbers has property P when for every $n \ge 1$ only finitely many $a \in A$ make $n + a$ squarefree.
