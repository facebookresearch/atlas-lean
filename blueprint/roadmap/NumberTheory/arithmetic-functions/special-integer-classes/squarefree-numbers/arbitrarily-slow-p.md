# Sequences with property P can grow arbitrarily slowly beyond linear, as a statement

The statement that for every $f : \mathbb{N} \to \mathbb{N}$ with $f(j) \to \infty$ and $f(j) \ne 0$ for all $j$, there is a strictly increasing sequence $a_0 < a_1 < \cdots$ of natural numbers whose set of values has property P and $a_j/j \le f(j)$ for every $j$ (with $a_0/0 = 0$); here a set $A$ of natural numbers has property P when for every $n \ge 1$ only finitely many $a \in A$ make $n + a$ squarefree.

This page records the statement as a proposition. Its resolution: [Sequences with property P can grow arbitrarily slowly beyond linear](arbitrarily-slow-p-holds.md).
