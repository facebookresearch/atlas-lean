# Sequences with property P can grow arbitrarily slowly beyond linear

For every $f : \mathbb{N} \to \mathbb{N}$ with $f(j) \to \infty$ and $f(j) \ne 0$ for all $j$, there is a strictly increasing sequence $a_0 < a_1 < \cdots$ of natural numbers whose set of values has property P and $a_j/j \le f(j)$ for every $j$ (with $a_0/0 = 0$); here a set $A$ of natural numbers has property P when for every $n \ge 1$ only finitely many $a \in A$ make $n + a$ squarefree.

This resolves [Sequences with property P can grow arbitrarily slowly beyond linear, as a statement](arbitrarily-slow-p.md), the statement recorded as a proposition, in the affirmative; the resolution is due to van Doorn and Tao (2025), cited under Sources.

## Sources

- T. F. Bloom, Erdős Problems, Problem #1102, https://www.erdosproblems.com/1102.
