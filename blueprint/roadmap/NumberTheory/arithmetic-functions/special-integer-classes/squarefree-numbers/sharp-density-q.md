# A squarefree sequence with property Q of density 6/π², as a statement

The statement that there is a strictly increasing sequence $a_0 < a_1 < \cdots$ of squarefree natural numbers whose set of values has property Q and $j/a_j \to 6/\pi^2$; here a set $A$ of natural numbers has property Q when there are infinitely many $n$ such that $n + a$ is squarefree for every $a \in A$ with $a < n$.

This page records the statement as a proposition. Its resolution: [A squarefree sequence with property Q of density 6/π²](sharp-density-q-holds.md).
