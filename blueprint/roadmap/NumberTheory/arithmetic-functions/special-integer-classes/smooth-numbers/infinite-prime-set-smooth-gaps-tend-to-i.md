# Erdős Problem 240 (Wintner's question on gaps between smooth numbers)

The statement that there is an infinite set $P$ of primes such that, if $a_1 < a_2 < \cdots$ are the positive integers all of whose prime factors lie in $P$, then $a_{i+1} - a_i \to \infty$.
