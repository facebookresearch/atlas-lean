# Non-pretentious arithmetic functions

An arithmetic function $f : \mathbb{N} \to \mathbb{C}$ is non-pretentious when for every modulus $q \ge 1$, every Dirichlet character $\chi$ modulo $q$ and every real $t$, the series $\sum_p \bigl(1 - \operatorname{Re}(f(p)\overline{\chi(p)} p^{it})\bigr)/p$ over the primes diverges.
