# Parity of the number of divisors from a set

For a set $A$ of integers at least $2$ and a natural number $n$, $\pi_A(n) = (-1)^{\#\{a \in A : a \mid n\}}$ (for $n \ge 1$ the count is finite; for $n = 0$ every element of $A$ divides $n$, so when $A$ is infinite the count is taken to be $0$, the convention for the size of an infinite set, and $\pi_A(0) = 1$).
