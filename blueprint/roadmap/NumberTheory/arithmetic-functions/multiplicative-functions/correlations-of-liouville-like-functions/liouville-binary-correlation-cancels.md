# AimPL question on the binary Liouville correlation

The statement that for every natural number $N \ge 11$, $\bigl|\sum_{0 < n < N} \lambda(n) \lambda(N - n)\bigr| < N - 1$, where $\lambda$ is the Liouville function, $\lambda(n) = (-1)^{\Omega(n)}$ with $\Omega(n)$ the number of prime factors of $n$ counted with multiplicity.
