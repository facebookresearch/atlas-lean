# Bounded non-pretentious multiplicative functions

An arithmetic function $f$ is admissible when it is multiplicative, $|f(n)| \le 1$ for all $n$, and $f$ is [non-pretentious](is-non-pretentious.md): for every modulus $q \ge 1$, Dirichlet character $\chi$ modulo $q$ and real $t$, the series $\sum_p (1 - \operatorname{Re}(f(p)\overline{\chi(p)} p^{it}))/p$ is not absolutely summable, which, as its terms are nonnegative when $|f| \le 1$, says that it diverges.
