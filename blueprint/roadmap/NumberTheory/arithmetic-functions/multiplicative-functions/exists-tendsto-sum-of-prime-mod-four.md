# Mean values for weights selecting one odd prime class modulo four

Suppose that
$f : \mathbb{N} \to [0,1]$ is completely multiplicative with $f(0)=0$ and $f(1)=1$. Suppose
that on odd primes $f$ equals the indicator of one unit residue class modulo four.
There is an $α > 0$ such that
$\sum_{n \le x} f(n)/n$ is asymptotic to $α\sqrt{\log x}$ and
$\sum_{n \le x} f(n)$ is asymptotic to $(α/2)x/\sqrt{\log x}$.
Both sums start at $n = 1$.

## Sources

- Eduard Wirsing, “Das asymptotische Verhalten von Summen über multiplikative Funktionen”, *Math. Ann.* **143** (1961), 75–102. For the mean-value formula specialized here to $τ = 1/2$, see also Pieter Moree, *Chebyshev's bias for composite numbers with restricted prime divisors*, Theorem 1 ([arXiv:math/0112100](https://arxiv.org/abs/math/0112100)).
