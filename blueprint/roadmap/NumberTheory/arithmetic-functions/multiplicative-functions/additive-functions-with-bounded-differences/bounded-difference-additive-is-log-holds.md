# Additive functions with bounded differences are logarithmic up to a bounded error

For every $f : \mathbb{N} \to \mathbb{R}$ that is additive on the positive integers ($f(ab) = f(a) + f(b)$ for coprime $a, b \ge 1$) and has bounded differences ($|f(n+1) - f(n)| < c$ for some real $c$ and all $n \ge 1$), there are reals $c'$ and $C$ with $|f(n) - c' \log n| \le C$ for every $n \ge 1$.

## Sources

- T. F. Bloom, Erdős Problems, Problem #491, https://www.erdosproblems.com/491.
- E. Wirsing, A characterization of log n as an additive arithmetic function, Symposia Math. (1970), 45–57.
