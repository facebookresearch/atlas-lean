# Erdős Problem 491 (additive functions with bounded differences)

The statement that for every $f : \mathbb{N} \to \mathbb{R}$ that is additive on the positive integers ($f(ab) = f(a) + f(b)$ for coprime $a, b \ge 1$) and has bounded differences ($|f(n+1) - f(n)| < c$ for some real $c$ and all $n \ge 1$), there are reals $c'$ and $C$ with $|f(n) - c' \log n| \le C$ for every $n \ge 1$.

This page records the statement as a proposition. Its resolution: [Additive functions with bounded differences are logarithmic up to a bounded error](bounded-difference-additive-is-log-holds.md).
