# AimPL question on lower bounds for partial sums of totally multiplicative ±1 functions

The statement that there is $\varphi : \mathbb{R} \to \mathbb{R}$, eventually nonnegative, with $\log\log\log\log\log X = o(\varphi(X))$ as $X \to \infty$, such that for every totally multiplicative sign function $f$ there is $c > 0$ with $\bigl|\sum_{n \le X} f(n)\bigr| \ge c\, \varphi(X)$ for arbitrarily large real $X$; here a totally multiplicative sign function is a function $f$ from the positive integers to $\{-1, 1\}$ with $f(mn) = f(m) f(n)$ for all positive integers $m, n$.

This page records the statement as a proposition. Its resolution: [Partial sums of totally multiplicative ±1 functions are often large](conjecture-holds.md).
