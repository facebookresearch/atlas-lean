# Number of coprime pairs

For $n = (n_0, \dots, n_{k-1}) \in \mathbb{N}^k$, the number of
coprime pairs of $n$ is the number of index pairs $(i, j)$ with $0 \le i < j < k$ and
$\gcd(n_i, n_j) = 1$.

In the paper's notation, $\beta_r(n) = 1$ exactly when this count is $r$, $\beta'_r(n) = 1$
exactly when it is at least $r$, and $\beta = \beta_0$.

## Sources

- László Tóth, *On the Asymptotic Density of k-tuples of Positive Integers with Pairwise Non-Coprime Components*, Journal of Integer Sequences 27 (2024), Article 24.8.5, displays (def_beta), (def_beta_exact), (def_beta_least).
