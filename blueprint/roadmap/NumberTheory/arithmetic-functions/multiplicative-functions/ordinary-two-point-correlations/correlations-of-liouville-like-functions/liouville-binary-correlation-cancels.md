# AimPL question on the binary Liouville correlation, for N ≥ 11

The statement that for every natural number $N \ge 11$, $\bigl|\sum_{0 < n < N} \lambda(n) \lambda(N - n)\bigr| < N - 1$, where $\lambda$ is the Liouville function, $\lambda(n) = (-1)^{\Omega(n)}$ with $\Omega(n)$ the number of prime factors of $n$ counted with multiplicity.

The problem list states the inequality with no range for $N$; it fails, with equality, at $N = 2, 3, 5, 10$ (for $N = 10$ every term $\lambda(n)\lambda(10 - n)$ is $1$). This is the version for $N \ge 11$, the range of Mangerel's theorem.

This page records the statement as a proposition. Its resolution: [Cancellation in the binary Liouville correlation](liouville-binary-correlation-cancels-hol.md).
