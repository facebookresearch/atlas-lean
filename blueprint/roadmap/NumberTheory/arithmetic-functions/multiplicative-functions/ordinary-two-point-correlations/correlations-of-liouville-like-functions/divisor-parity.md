# Parity of the number of divisors from a set

For a set $A$ of natural numbers and a natural number $n$, $\pi_A(n) = (-1)^{\#\{a \in A : a \mid n\}}$, where the size of an infinite set is taken to be $0$. For $n \ge 1$ the count is finite. For $n = 0$ every element of $A$ divides $n$, so the count is the size of $A$ when $A$ is finite, and $\pi_A(0) = 1$ when $A$ is infinite. The set $A$ may contain $0$ and $1$: for $A = \{1\}$, $\pi_A(1) = -1$. The restriction to elements $a \ge 2$ belongs to the theorem on vanishing correlations, not to this function.
