# AimPL question on Liouville-like functions with vanishing correlations

The statement that there is a set $A$ of pairwise coprime integers $a \ge 2$ such that for every $k \ge 1$ and all distinct natural numbers $h_1, \dots, h_k$,

$$\frac1X \sum_{n=1}^{X} \pi_A(n + h_1) \cdots \pi_A(n + h_k) \to 0 \quad (X \to \infty),$$

where for a set $A$ of integers at least $2$ and a natural number $n$, $\pi_A(n) = (-1)^{\#\{a \in A : a \mid n\}}$.

This page records the statement as a proposition. Its resolution: [Liouville-like functions with vanishing correlations exist](exists-coprime-set-with-vanishing-correl-2.md).
