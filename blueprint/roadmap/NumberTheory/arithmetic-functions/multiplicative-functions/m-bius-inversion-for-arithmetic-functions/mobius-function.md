# Möbius function

The Möbius function $\mu$ on the positive integers has $\mu(1) = 1$, $\mu(n) = 0$ if $p^2 \mid n$ for some prime $p$, and $\mu(n) = (-1)^k$ if $n = p_1 p_2 \cdots p_k$ is a product of $k \ge 1$ pairwise distinct primes. More precisely, Mathlib defines $\mu$ as an arithmetic function, that is, an integer-valued function on the natural numbers that sends $0$ to $0$, with $\mu(n) = (-1)^{\Omega(n)}$ if $n$ is squarefree and $\mu(n) = 0$ otherwise. Here $\Omega(n)$ is the number of prime factors of $n$ counted with multiplicity, and $n$ is squarefree if every natural number $x$ with $x^2 \mid n$ is equal to $1$. For a squarefree positive integer $n$ the prime factors are pairwise distinct, so $\Omega(n)$ is the number of distinct primes dividing $n$, and $\Omega(1) = 0$ gives $\mu(1) = 1$. Mathlib's convention at $0$ is $\mu(0) = 0$.
