# The Lehmer function $\kappa_r$

For a list $t = (t_1, \dots, t_r)$ of real numbers,

$$\kappa_r(t_1, \dots, t_r) = \frac{t_1 \cdots t_r - 1}{(t_1 - 1) \cdots (t_r - 1)},$$

with division by zero giving $0$ (so $\kappa_r(t) = 0$ when some $t_i = 1$).
