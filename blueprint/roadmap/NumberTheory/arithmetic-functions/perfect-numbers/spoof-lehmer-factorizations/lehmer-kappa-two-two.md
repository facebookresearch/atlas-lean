# The Lehmer function at $(2, 2)$

The Lehmer function
$\kappa_2(t_1, t_2) = (t_1 t_2 - 1) / ((t_1 - 1)(t_2 - 1))$ takes the value $\kappa_2(2, 2) = 3$.
