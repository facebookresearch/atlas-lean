# Number of divisors from a set

For a set $A$ of natural numbers and a natural number $n \ge 1$, $d_A(n)$ is the number of elements of $A$ that divide $n$. At $n = 0$ the count is over the divisors of $0$, of which there are none in this convention, so $d_A(0) = 0$ for every $A$, even $A = \{1\}$.
