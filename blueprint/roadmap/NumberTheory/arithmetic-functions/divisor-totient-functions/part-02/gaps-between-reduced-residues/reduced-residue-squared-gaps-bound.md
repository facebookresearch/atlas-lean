# Erdős Problem 220 (squared gaps between reduced residues)

The statement that there is a real $C$ such that for every $n \ge 1$, $\sum_{1 \le k < r} (a_{k+1} - a_k)^2 \le C n^2/\varphi(n)$, where $a_1 < \dots < a_r$ is the increasing list of the integers $1 \le a < n$ coprime to $n$. For $n \ge 2$, $r = \varphi(n)$; at $n = 1$ the list is empty and the sum is $0$.

This page records the statement as a proposition. Its resolution: [Montgomery–Vaughan bound for squared gaps between reduced residues](reduced-residue-squared-gaps-bound-holds.md).
