# Gaps between consecutive reduced residues

For a natural number $N$, the list of consecutive gaps $a_i - a_{i-1}$, $2 \le i \le r$, where $a_1 < \dots < a_r$ is the increasing list of the integers $1 \le a < N$ coprime to $N$. Here $r = \varphi(N)$ for $N \ge 2$, while the list of residues is empty for $N \le 1$; the list of gaps is empty for $N \le 2$.
