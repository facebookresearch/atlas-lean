# Erdős Problem 48 (common values of the totient and divisor-sum functions)

The statement that there are infinitely many pairs of positive integers $(n, m)$ with $\varphi(n) = \sigma(m)$, where $\varphi$ is Euler's totient function and $\sigma$ the sum-of-divisors function.
