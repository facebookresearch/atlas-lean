# All permutation patterns appear among consecutive totient values

The property holds when, for natural numbers $k$ and $n$, every permutation $\sigma$ of $\{0, \dots, k-1\}$ appears in $\varphi(m + 1), \dots, \varphi(m + k)$ for some $m$ with $m + k \le n$, where $\varphi$ is Euler's totient function and a permutation $\sigma$ of $\{0, \dots, k-1\}$ appears in values $x_0, \dots, x_{k-1}$ when $\sigma(i) < \sigma(j)$ implies $x_i < x_j$.
