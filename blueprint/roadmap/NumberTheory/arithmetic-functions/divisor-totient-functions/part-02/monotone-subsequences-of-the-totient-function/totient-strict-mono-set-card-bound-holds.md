# Sets on which the totient increases have at most (1 + o(1)) π(N) elements

For every real $\varepsilon > 0$ there is $N_0$ such that for every $N \ge N_0$, every set $A \subseteq \{1, \dots, N\}$ on which Euler's totient function $\varphi$ is strictly increasing has $|A| \le (1 + \varepsilon)\pi(N)$, where $\pi(N)$ is the number of primes up to $N$.

This resolves [Erdős Problem 49 (sets on which Euler's totient is increasing)](totient-strict-mono-set-card-bound.md), the statement recorded as a proposition, in the affirmative; the resolution is due to Tao (2024), cited under Sources.
