# Erdős Problem 49 (sets on which Euler's totient is increasing)

The statement that for every real $\varepsilon > 0$ there is $N_0$ such that for every $N \ge N_0$, every set $A \subseteq \{1, \dots, N\}$ on which Euler's totient function $\varphi$ is strictly increasing has $|A| \le (1 + \varepsilon)\pi(N)$, where $\pi(N)$ is the number of primes up to $N$.

This page records the statement as a proposition. Its resolution: [Sets on which the totient increases have at most (1 + o(1)) π(N) elements](totient-strict-mono-set-card-bound-holds.md).
