# Number of dyadic intervals containing a divisor

For a natural number $n$, $\tau^+(n)$ is the number of $k$ such that $n$ has a divisor in $[2^k, 2^{k+1})$: the number of distinct values $\lfloor \log_2 d \rfloor$ over the divisors $d$ of $n$. The divisors of $0$ are taken to be none, so $\tau^+(0) = 0$.
