# Erdős Problem 822 is true

The set $\{n + \varphi(n) : n \in \mathbb{N}\}$, where $\varphi$
is Euler's totient function, has positive lower density in $\mathbb{N}$.

## Sources

- M. R. Gabdullin, V. V. Iudelevich, and F. Luca, Numbers of the form k + f(k), Journal of Number Theory 262 (2024), 58–85, https://doi.org/10.1016/j.jnt.2024.03.010. Moved from `OpenConjectures/NumberTheory/ErdosProblem822`.
