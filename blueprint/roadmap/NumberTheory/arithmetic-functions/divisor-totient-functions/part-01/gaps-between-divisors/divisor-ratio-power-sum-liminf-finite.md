# Erdős Problem 1099 (consecutive divisor ratios)

The statement that for every real $\alpha > 1$ there is a real $C$ with $h_\alpha(n) \le C$ for infinitely many $n$, where for a real $\alpha$ and a natural number $n$ with divisors $1 = d_1 < \dots < d_{\tau(n)} = n$, $h_\alpha(n) = \sum_{i < \tau(n)} (d_{i+1}/d_i - 1)^\alpha$.

This page records the statement as a proposition. Its resolution: [Integers whose consecutive divisor ratios are close to one](divisor-ratio-power-sum-liminf-finite-ho.md).
