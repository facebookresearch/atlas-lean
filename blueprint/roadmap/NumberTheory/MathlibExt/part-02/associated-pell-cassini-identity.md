# Associated Pell Cassini

Cassini's identity for associated Pell numbers: for `Q` with `Q 0 = Q 1 = 1`
and `Q (n + 2) = 2 * Q (n + 1) + Q n`, `Q (k-1) * Q (k+1)`
equals `Q k ^ 2 + 2 * (-1) ^ (k-1)` for all `k ≥ 1`.
