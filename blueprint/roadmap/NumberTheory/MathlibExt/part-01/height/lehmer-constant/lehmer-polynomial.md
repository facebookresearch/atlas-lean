# Lehmer Polynomial

Lehmer's 1933 example polynomial
`X^10 + X^9 - X^7 - X^6 - X^5 - X^4 - X^3 + X + 1`, whose Mahler measure
`1.176280...` is still the smallest known value larger than `1`.
