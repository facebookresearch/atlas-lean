# Jordan Totient eq sum moebius

Source Möbius sum with orientation `μ(n/d) * d^k` (He (2.7)).

Holds for every `k` when `n ≠ 0`, generalizing the positive-`k` source
statement; the hypothesis `0 < k` is therefore omitted.
