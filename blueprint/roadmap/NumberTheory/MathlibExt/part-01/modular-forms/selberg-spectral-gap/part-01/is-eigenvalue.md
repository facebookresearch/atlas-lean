# Is Eigenvalue

`λ` is an eigenvalue of the hyperbolic Laplacian on `L²(Γ \ ℍ)`, in
the smooth eigenfunction sense of this file: some nonzero smooth
`Γ`-invariant square-integrable function satisfies `Δf = λ f`.
