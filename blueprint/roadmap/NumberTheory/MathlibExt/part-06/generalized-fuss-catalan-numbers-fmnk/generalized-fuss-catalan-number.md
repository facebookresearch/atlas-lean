# Generalized Fuss Catalan Number

The generalized Fuss–Catalan number `F_m(n, k)`:
`k * Nat.choose (m * n + k) n / (m * n + k)`.

The source considers `m ≥ 2` and `n, k ≥ 1`. The definition is totalized over natural numbers.
