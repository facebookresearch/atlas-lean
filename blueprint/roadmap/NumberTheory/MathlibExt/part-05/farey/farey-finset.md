# Farey Finset

Finite carrier of Farey fractions of order `n`. Enumerates all
`a/d` with `1 ≤ d ≤ n`, `0 ≤ a ≤ d`. Every `q` with `0 ≤ q ≤ 1`
and `q.den ≤ n` equals `q.num/q.den` with `0 ≤ q.num ≤ q.den`,
hence appears.
