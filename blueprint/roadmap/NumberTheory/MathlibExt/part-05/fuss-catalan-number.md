# Fuss Catalan Number

The Fuss–Catalan number
`Nat.choose (k * m) m / ((k - 1) * m + 1)` for positive chord arity `k`.

Concepts `jis_term_ebafb51c3672353ca538423c` and
`jis_sem_1faa20d56755b6a211607da7`; source JIS VOL23/Young,
