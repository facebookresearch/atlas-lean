# Fermat Sequence

The Fermat sequence generated by a complex sequence `b`, defined by
`a n = ∑ m ∈ n.divisors, m * b m`.

This follows lines 181–190 of B.-S. Du, S.-S. Huang, and M.-C. Li,
*Newton, Fermat, and Exactly Realizable Sequences*, Journal of Integer Sequences 8 (2005):

<https://cs.uwaterloo.ca/journals/JIS/VOL8/Huang/huang11.tex>

The source defines the sequence for positive indices. We totalize it at zero using
`Nat.divisors 0 = ∅`, so its value there is zero.
