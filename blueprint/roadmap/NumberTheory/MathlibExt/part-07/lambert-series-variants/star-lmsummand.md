# Star LMSummand

Summand for Gerhold's Lambert-type variant `L_m^*`.
Concept `jis_sem_e9cabece6d32bf6b52d62673`, source
`jis_f69070cf1636bd79774e81a9`. It is indexed by `k : Nat` with
`n = k + 1`, writing `2 * k + 1` for `2 * n - 1`.
