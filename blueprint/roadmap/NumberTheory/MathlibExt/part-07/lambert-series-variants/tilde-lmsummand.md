# Tilde LMSummand

Tilde summand for Gerhold's Lambert-type variant `\tilde L_m`.
Concept `jis_sem_e9cabece6d32bf6b52d62673`, source
`jis_f199df27bfb37c3d9b045e32`. It is indexed by `k : Nat` with
`n = k + 1`, writing `2 * k + 1` for `2 * n - 1`.
