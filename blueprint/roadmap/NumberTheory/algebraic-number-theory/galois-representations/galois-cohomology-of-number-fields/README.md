# Galois cohomology of number fields

Tate–Shafarevich groups, finiteness and cohomological dimension, Poitou–Tate duality and the nine-term
exact sequence, the global Euler characteristic formula and Wiles's formula comparing dual Selmer groups,
following Neukirch–Schmidt–Wingberg, Chapter VIII, and Milne's *Arithmetic Duality Theorems*, Chapter I,
§§4–5.
