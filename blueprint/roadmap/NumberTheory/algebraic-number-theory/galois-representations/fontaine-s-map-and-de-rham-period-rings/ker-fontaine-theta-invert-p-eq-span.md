# Ker fontaine Theta Invert P eq span

If the kernel of Fontaine's map `θ : W(O♭) →+* O` is generated by `ξ`, then the kernel of `θ`
with `p` inverted (`fontaineThetaInvertP O p`) is generated by the image of `ξ` in `W(O♭)[1/p]`.
This is an instance of `IsLocalization.ker_map`, since `θ` maps the powers of `p` onto the powers
of `p`; it does not need `p` to be a non-zero-divisor on `O`.
