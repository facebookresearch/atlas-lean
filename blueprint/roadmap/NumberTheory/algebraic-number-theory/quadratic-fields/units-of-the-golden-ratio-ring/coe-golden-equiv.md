# Real value of an element of the golden order

For integers $a, b$, the element $a + b\omega$ of $\mathbb{Z}[\omega]$ corresponds to the real number $a + b\varphi$, where $\mathbb{Z}[\omega]$ with $\omega^2 = \omega + 1$ is the quadratic algebra over $\mathbb{Z}$ with elements $a + b\omega$, and $\varphi = (1 + \sqrt5)/2$ is the golden ratio.
