# Idele class characters

Let $R$ be a Dedekind domain with fraction field $K$, and let $\mathbb{A}_{R,K}$ be the adele ring built from the infinite places of $K$ and the height-one primes of $R$, the finite places here. A character $\chi : \mathbb{A}_{R,K}^\times \to \mathbb{C}^\times$ is an idele class character when $\chi$ is trivial on the image of $K^\times$ under the diagonal homomorphism $K^\times \to \mathbb{A}_{R,K}^\times$: $\chi(u) = 1$ for every $u$ in that image. At this generality the diagonal homomorphism need not be injective (for $R = K = \mathbb{F}_3$ the target is trivial).
