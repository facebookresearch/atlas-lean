# Local finiteness of the adelic kernel

For a number field $F$, the statement that for every compact set $C \subseteq \mathrm{GL}_2(\mathbb{A}_F)$ and all $x, y \in \mathrm{GL}_2(\mathbb{A}_F)$, only finitely many $\gamma \in \mathrm{GL}_2(F)$ satisfy $x^{-1}\gamma y \in C$, with $\gamma$ embedded diagonally.
