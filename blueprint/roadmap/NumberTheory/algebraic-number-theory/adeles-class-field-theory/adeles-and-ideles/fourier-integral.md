# Fourier integral against an additive character

For a commutative ring $A$ with a measure $\mu$, an additive character $\psi : A \to \mathbb{C}$, a function $f : A \to \mathbb{C}$ and $w \in A$, $\hat f(w) = \int_A \psi(-vw) f(v)\,d\mu(v)$.

The integral is the Bochner integral, which is $0$ when the integrand is not integrable; no integrability hypothesis is imposed. For example, for the trivial character and the constant function $1$ on $\mathbb{Z}$ with counting measure the ordinary integral diverges, and the value is $0$.
