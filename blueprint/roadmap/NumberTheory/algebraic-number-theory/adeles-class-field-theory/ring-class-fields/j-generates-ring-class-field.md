# The j-invariant of a proper ideal generates the ring class field

Let $K \subset \mathbb{C}$ be an imaginary quadratic field, $\mathcal{O}$ an order in $K$, and
$\mathfrak{a}$ a proper fractional $\mathcal{O}$-ideal, that is, a lattice $\mathfrak{a} \subset K$ in
$\mathbb{C}$ that is a
[proper ideal](../../../../Analysis/special-functions/elliptic-functions/complex-multiplication-of-period-lattices/is-proper-ideal.md)
of $\mathcal{O}$, with $j$-invariant $j(\mathfrak{a})$. Then

$$K(j(\mathfrak{a})) = L,$$

the [ring class field](ring-class-field.md) of $\mathcal{O}$: the single value $j(\mathfrak{a})$ already
generates the field generated by all of them.

By the [Galois group of the ring class field](ring-class-field-galois-group.md), an element $\sigma$ of
$\mathrm{Gal}(L/K)$ with $\Psi(\sigma) = [\mathfrak{c}]$ fixes $j(\mathfrak{a})$ exactly when
$j(\mathfrak{c}^{-1}\mathfrak{a}) = j(\mathfrak{a})$, that is, when $\mathfrak{c}$ is principal, since the
values $j$ of distinct classes are distinct
([integer coefficients of the class equation](class-equation-integer-coefficients.md)). As $\Psi$ is
injective, only the identity fixes $j(\mathfrak{a})$, and $K(j(\mathfrak{a})) = L$ by Galois theory.

For $\mathcal{O} = \mathcal{O}_K$, the
[generation of the Hilbert class field by $j$](../hilbert-class-field/hilbert-class-field-generated-by-j.md)
states more: $K(j(\mathfrak{a}))$ is a Hilbert class field of $K$.

## Proof depends on

- [Galois group of a ring class field](ring-class-field-galois-group.md), for $L/K$ finite Galois and the injective homomorphism $\Psi$ with $\sigma(j(\mathfrak{b})) = j(\mathfrak{c}^{-1}\mathfrak{b})$
- [Integer coefficients of the class equation of an imaginary quadratic order](class-equation-integer-coefficients.md), for $j(\mathfrak{b}) = j(\mathfrak{a})$ only when $[\mathfrak{b}] = [\mathfrak{a}]$
