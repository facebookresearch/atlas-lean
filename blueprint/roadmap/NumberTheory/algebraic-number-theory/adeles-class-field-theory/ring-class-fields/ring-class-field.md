# Ring class field of an imaginary quadratic order

Let $K \subset \mathbb{C}$ be an imaginary quadratic field and $\mathcal{O}$ an order in $K$. A proper
fractional $\mathcal{O}$-ideal is a lattice $\mathfrak{a} \subset K$ in $\mathbb{C}$ that is a
[proper ideal](../../../../Analysis/special-functions/elliptic-functions/complex-multiplication-of-period-lattices/is-proper-ideal.md) of $\mathcal{O}$: its endomorphism ring
$\{\lambda \in \mathbb{C} : \lambda\mathfrak{a} \subseteq \mathfrak{a}\}$ is $\mathcal{O}$. Its
$j$-invariant is
$j(\mathfrak{a}) = 1728\, g_2(\mathfrak{a})^3 / (g_2(\mathfrak{a})^3 - 27\, g_3(\mathfrak{a})^2)$, with
$g_2$ and $g_3$ the Eisenstein invariants of the lattice; for $\mathfrak{a} = \mathbb{Z} + \mathbb{Z}\tau$
with $\tau$ in the upper half-plane, $j(\mathfrak{a}) = j(\tau)$.

The ring class field of $\mathcal{O}$ is the subfield $L \subset \mathbb{C}$ generated over $K$ by the
$j$-invariants $j(\mathfrak{a})$ of all proper fractional $\mathcal{O}$-ideals $\mathfrak{a}$. Since
$j(\mathfrak{a})$ depends only on the class of $\mathfrak{a}$ modulo principal ideals, $L$ is generated
by the finitely many values $j(\mathfrak{a}_1), \ldots, j(\mathfrak{a}_h)$ for representatives of the
class group of $\mathcal{O}$: it is the splitting field over $K$ of the
[class equation](class-equation.md).

For $\mathcal{O} = \mathcal{O}_K$ the ring class field is the Hilbert class field of $K$, as the
[generation of the Hilbert class field by $j$](../hilbert-class-field/hilbert-class-field-generated-by-j.md)
states.
