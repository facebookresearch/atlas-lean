# The class group of a number field is finite

Let $K$ be a number field with ring of integers $\mathcal{O}_K$. Then the ideal class group of $\mathcal{O}_K$ is finite.

## Sources

- F. Keune, *Number Fields*, Radboud University Press, Nijmegen (2023, version 2023-01), open access,
  <https://doi.org/10.54195/IPVU4488>, Theorem 3.26 (the ideal class group of a number field is finite).
