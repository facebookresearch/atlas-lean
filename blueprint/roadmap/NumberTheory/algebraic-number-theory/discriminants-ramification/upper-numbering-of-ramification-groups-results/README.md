# Herbrand's functions, Herbrand's theorem and the Hasse–Arf theorem

of a finite Galois extension of local fields: Herbrand's functions $\varphi_{L/K}$ and $\psi_{L/K}$, the function
$i_G$ of a quotient, Herbrand's theorem and the transitivity of Herbrand's functions, following Serre's *Local
Fields*, Chapter IV, §§1 and 3, and the Hasse–Arf theorem on the jumps of the upper numbering of an abelian
extension.
