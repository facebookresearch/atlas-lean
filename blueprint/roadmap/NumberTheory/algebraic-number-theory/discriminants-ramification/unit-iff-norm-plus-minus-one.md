# An algebraic integer of a number field is a unit if and only if its norm is ±1

Let $K$ be a number field with ring of integers $\mathcal{O}_K$, and let $x \in \mathcal{O}_K$. Then $x$ is a unit of $\mathcal{O}_K$ if and only if its norm $N_{K/\mathbb{Q}}(x)$ satisfies $|N_{K/\mathbb{Q}}(x)| = 1$, that is, $N_{K/\mathbb{Q}}(x) = \pm 1$.
