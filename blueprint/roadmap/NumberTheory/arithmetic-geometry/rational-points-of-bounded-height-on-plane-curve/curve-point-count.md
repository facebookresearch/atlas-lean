# Rational points of bounded height on a plane curve

For a polynomial $P \in \mathbb{Q}[x, y]$ and a natural number $H$, the counting function is the number of zeros $(x, y) \in \mathbb{Q}^2$ of $P$ whose coordinates both have height at most $H$, where a rational number has height at most $H$ when, in lowest terms $a/b$ with $b \ge 1$, both $|a| \le H$ and $b \le H$ (as a natural number, $0$ if there are infinitely many).
