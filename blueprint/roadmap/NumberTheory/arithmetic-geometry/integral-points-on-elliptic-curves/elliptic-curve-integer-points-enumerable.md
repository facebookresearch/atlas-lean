# Hall–Shlapentokh question on enumerating integer points on elliptic curves

The statement that there is a computable function $f$ sending each pair $(A, B)$ of integers to a finite list of pairs of integers such that, whenever $4A^3 + 27B^2 \ne 0$, a pair $(x, y)$ of integers lies on the list exactly when $y^2 = x^3 + Ax + B$: an algorithm lists all integer points of every elliptic curve $y^2 = x^3 + Ax + B$ with integer coefficients.

This page records the statement as a proposition. Its resolution: [Integer points on elliptic curves can be listed by an algorithm](elliptic-curve-integer-points-enumerable-2.md).
