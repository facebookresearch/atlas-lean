# Erdős Problem 275 (covering 2^r consecutive integers)

The statement that for every natural number $r$, all integers $a_1, \dots, a_r$ and positive integers $n_1, \dots, n_r$ (not necessarily distinct): if every integer $x$ in some interval $k \le x < k + 2^r$ satisfies $x \equiv a_i \pmod{n_i}$ for some $i$, then every integer does.

This page records the statement as a proposition. Its resolution: [Congruences covering 2^r consecutive integers cover all integers](covering-consecutive-covers-all-holds.md).
