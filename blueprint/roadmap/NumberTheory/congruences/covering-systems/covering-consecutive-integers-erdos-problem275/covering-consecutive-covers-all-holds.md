# Congruences covering 2^r consecutive integers cover all integers

For every natural number $r$, all integers $a_1, \dots, a_r$ and positive integers $n_1, \dots, n_r$ (not necessarily distinct): if every integer $x$ in some interval $k \le x < k + 2^r$ satisfies $x \equiv a_i \pmod{n_i}$ for some $i$, then every integer does.

This resolves [Erdős Problem 275 (covering 2^r consecutive integers)](covering-consecutive-covers-all.md), the statement recorded as a proposition, in the affirmative; the resolution is the published work cited under Sources.

## Sources

- T. F. Bloom, Erdős Problems, Problem #275, https://www.erdosproblems.com/275.
- R. B. Crittenden and C. L. Vanden Eynden, Any n arithmetic progressions covering the first $2^n$ integers cover all integers, Proc. Amer. Math. Soc. (1970), 475–481.
