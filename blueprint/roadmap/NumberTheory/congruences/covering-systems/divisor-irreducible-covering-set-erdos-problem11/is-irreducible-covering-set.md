# Irreducible covering sets

A finite set $S$ of integers greater than $1$ is an irreducible covering set when it is a covering set and no proper subset of $S$ is a covering set, where a finite set $S$ of integers greater than $1$ is a covering set when residues $a_n$ ($n \in S$) can be chosen so that every integer satisfies $x \equiv a_n \pmod n$ for at least one $n \in S$.
