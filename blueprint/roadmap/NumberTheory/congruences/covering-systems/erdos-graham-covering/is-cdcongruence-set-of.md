# CD congruence sets of $n$

Let $n$ be a natural number and assign to each divisor $d > 1$ of $n$ a residue class
$a(d) \bmod d$, with $a(d) \in \mathbb{Z}$. The assignment is a CD congruence set of $n$ when any two
of these classes with distinct moduli $d \ne d'$ that share an integer have coprime moduli:
$\gcd(d, d') = 1$. For $n = 0$, which has no divisors here, every assignment qualifies.
