# Non-intersecting integers

A natural number $n$ is non-intersecting when it has a CD congruence set: residue classes
$a(d) \bmod d$, one for each divisor $d > 1$ of $n$, such that two classes with distinct moduli
can share an integer only if their moduli are coprime. The divisors are the positive divisors of $n$; for $n = 0$ the indexing set is empty, so zero is non-intersecting.
