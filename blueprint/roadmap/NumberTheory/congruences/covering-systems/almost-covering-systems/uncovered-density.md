# Uncovered density of a system of congruences

For a finite set $S$ of natural numbers and integers $a_n$ ($n \in S$), the uncovered density is the ratio of the number of integers $x \in \{0, 1, \dots, M - 1\}$, $M = \prod_{n \in S} n$, that satisfy none of the congruences $x \equiv a_n \pmod n$, to $M$. When every modulus is positive the uncovered set is periodic modulo $M$, and this is its density. When $0 \in S$, $M = 0$ and the value is $0/0 = 0$, which need not equal the density of the uncovered set. For $S = \{0, 1\}$ the congruence modulo $1$ covers every integer, so the uncovered set is empty and both values are $0$; for $S = \{0\}$ the congruence modulo $0$ is equality, every integer other than $a_0$ is uncovered, and the density is $1$. Problem 27 uses positive moduli only.
