# Erdős Problem 280 (uncovered counts for sparse moduli)

The statement that for every strictly increasing sequence of moduli $n_1 < n_2 < \cdots$ with $n_k > (1 + \varepsilon)k\log k$ for all $k \ge 1$ and some $\varepsilon > 0$, and all integers $a_k$, the number of $m < n_k$ with $m \not\equiv a_i \pmod{n_i}$ for $1 \le i \le k$ is not $o(k)$.

This page records the statement as a proposition.
