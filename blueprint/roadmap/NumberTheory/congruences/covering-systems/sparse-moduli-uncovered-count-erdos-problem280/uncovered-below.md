# Integers below n_k missed by k congruence classes

For moduli $n_0, n_1, n_2, \dots$, integers $a_0, a_1, a_2, \dots$ and $k \in \mathbb{N}$, the number of natural numbers $m$ with $0 \le m < n_k$ and $m \not\equiv a_i \pmod{n_i}$ for every $1 \le i \le k$. At $k = 0$ no congruence class is tested, so the count is $n_0$; $a_0$ is never tested.
