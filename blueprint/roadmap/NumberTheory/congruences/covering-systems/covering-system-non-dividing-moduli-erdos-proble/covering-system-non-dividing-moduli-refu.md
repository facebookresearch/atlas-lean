# Every covering system has a modulus dividing another

It is not the case that there is a covering system, finitely many congruence classes $a_i \bmod m_i$ with every $m_i \ge 2$ whose union is $\mathbb{Z}$, in which no modulus divides another: $m_i \nmid m_j$ for all $i \ne j$. Equivalently, in every covering system of $\mathbb{Z}$ by congruence classes with moduli at least $2$, some modulus divides another.

This refutes [Erdős Problem 586 (covering systems in which no modulus divides another)](covering-system-non-dividing-moduli.md), the statement recorded as a proposition; the refutation is due to Balister, Bollobás, Morris, Sahasrabudhe and Tiba (2022), cited under Sources.
