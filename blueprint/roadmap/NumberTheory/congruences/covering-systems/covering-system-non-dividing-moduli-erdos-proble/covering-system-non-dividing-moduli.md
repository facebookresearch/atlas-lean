# Erdős Problem 586 (covering systems in which no modulus divides another)

The statement that there is a covering system, finitely many congruence classes $a_i \bmod m_i$ with every $m_i \ge 2$ whose union is $\mathbb{Z}$, in which no modulus divides another: $m_i \nmid m_j$ for all $i \ne j$.

This page records the statement as a proposition. Its refutation: [Every covering system has a modulus dividing another](covering-system-non-dividing-moduli-refu.md).
