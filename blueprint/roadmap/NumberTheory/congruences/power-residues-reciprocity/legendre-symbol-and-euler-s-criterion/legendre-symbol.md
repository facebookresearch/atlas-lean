# Legendre symbol

For an odd prime $p$ and an integer $a$, the Legendre symbol $\left(\frac{a}{p}\right)$ is $0$ if $p \mid a$, $1$ if $p \nmid a$ and $a$ is a square modulo $p$, and $-1$ if $p \nmid a$ and $a$ is not a square modulo $p$. Mathlib defines it more generally for every prime $p$, including $p = 2$: for a prime $p$ and an integer $a$, the Legendre symbol $\left(\frac{a}{p}\right)$ is the integer obtained by applying to the residue of $a$ in $\mathbb{Z}/p\mathbb{Z}$ the quadratic character of the finite field $\mathbb{Z}/p\mathbb{Z}$, which takes the value $0$ at $0$, the value $1$ at nonzero squares and the value $-1$ at all other elements. Thus $\left(\frac{a}{p}\right) = 0$ exactly when $p \mid a$, and for $p \nmid a$ it is $1$ or $-1$ according as $a$ is or is not a square modulo $p$. For $p = 2$ the only nonzero residue is the square $1$, so $\left(\frac{a}{2}\right)$ is $0$ for even $a$ and $1$ for odd $a$; it is not the Kronecker symbol with denominator $2$.
