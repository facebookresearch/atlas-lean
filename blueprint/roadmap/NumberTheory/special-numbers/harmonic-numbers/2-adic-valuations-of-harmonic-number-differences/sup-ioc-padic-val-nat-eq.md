# Largest p-adic valuation when an interval contains one multiple

For a prime $p$ and natural numbers $m, n, r, c$ with $p^r(c - 1) \le m < p^r c \le n < p^r(c + 1)$, $\mu_p(m, n) = r + \nu_p(c)$, where $\mu_p(m, n) = \max_{m < k \le n} \nu_p(k)$ is the largest $p$-adic valuation of an element of $\{m + 1, \dots, n\}$.
