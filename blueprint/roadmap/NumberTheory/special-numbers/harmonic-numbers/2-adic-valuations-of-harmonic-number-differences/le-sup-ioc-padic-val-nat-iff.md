# Largest p-adic valuation in an interval, lower bound

For a prime $p$ and natural numbers $m < n$ and $j$, $j \le \mu_p(m, n)$ if and only if $\lfloor m/p^j \rfloor < \lfloor n/p^j \rfloor$, where $\mu_p(m, n) = \max_{m < k \le n} \nu_p(k)$ is the largest $p$-adic valuation of an element of $\{m + 1, \dots, n\}$.
