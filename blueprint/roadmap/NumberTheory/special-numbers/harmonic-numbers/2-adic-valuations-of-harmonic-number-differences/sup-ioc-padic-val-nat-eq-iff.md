# Largest p-adic valuation in an interval, exact value

For a prime $p$ and natural numbers $m < n$ and $a$, $\mu_p(m, n) = a$ if and only if $p^{a+1}\lfloor n/p^{a+1} \rfloor \le m < p^a \lfloor n/p^a \rfloor$, where $\mu_p(m, n) = \max_{m < k \le n} \nu_p(k)$ is the largest $p$-adic valuation of an element of $\{m + 1, \dots, n\}$.
