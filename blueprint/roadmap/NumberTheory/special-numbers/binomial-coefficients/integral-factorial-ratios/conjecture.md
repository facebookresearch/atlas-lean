# Erdős Problem 728: factorial divisibility with a logarithmic excess

The proposition that there is a real number $\delta > 0$ such that for
every real number $\varepsilon$ with $0 < \varepsilon < \delta$ and all real numbers $C > 0$ and
$C' > C$, there are natural numbers $a$, $b$ and $n \ge 1$ with $a > \varepsilon n$,
$b > \varepsilon n$, $a! \, b! \mid n! \, (a + b - n)!$ and $n + C \log n < a + b < n + C' \log n$.

Erdős Problem #728 asks, for $C > 0$ and $\varepsilon > 0$ sufficiently small, whether there are
infinitely many integers $a, b, n$ with $a \ge \varepsilon n$, $b \ge \varepsilon n$,
$a!\,b! \mid n!\,(a+b-n)!$ and $a + b > n + C \log n$. The problem page notes that this question
is ambiguous as written and has trivial solutions with very large $a$ and $b$; the upper bound
$a + b < n + C' \log n$ above rules these out.
