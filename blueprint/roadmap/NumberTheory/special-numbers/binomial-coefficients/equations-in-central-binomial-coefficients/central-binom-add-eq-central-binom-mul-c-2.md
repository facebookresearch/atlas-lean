# Central binomial products with $a + b \le 10$

Let $x$, $a$, $b$ be positive integers
with $a + b \le 10$. Then $\binom{2(a+b)}{a+b} = \binom{2a}{a}\binom{x+2b}{b}$ if and only if
$x = 1$ and $a = 1$.

## Sources
