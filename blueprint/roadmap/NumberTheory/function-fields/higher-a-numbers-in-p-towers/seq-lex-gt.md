# Lexicographic order on integer sequences

For sequences
$a, b \colon \mathbb{N} \to \mathbb{Z}$, $a$ is lexicographically larger than $b$ when there is
an index $m$ with $a_j = b_j$ for all $j < m$ and $a_m > b_m$. This is the order used in
Definition 1.
