# Corollary 23.30

Let $E/k$ be an elliptic curve and let $n$ be a positive integer prime to the
 characteristic of $k$. If $E[n] \subseteq E(k)$ then $\mu_n \subseteq
 k^{\times}$. In particular, if $k = \mathbb{Q}$ then $E[n] \subseteq E(k)$
 can occur only for $n \leq 2$, and if $k = \mathbb{F}_q$ then $E[n]
 \subseteq E(k)$ can occur only if $q \equiv 1 \bmod n$.
