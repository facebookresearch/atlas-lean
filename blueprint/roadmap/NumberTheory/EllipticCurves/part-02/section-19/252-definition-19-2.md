# Definition 19.2

Let $\Gamma$ be a congruence subgroup. A modular function for $\Gamma$ is a
 $\Gamma$-invariant meromorphic function $f: \mathbb{H} \rightarrow
 \mathbb{C}$ that is meromorphic at the cusps; equivalently, it is a
 meromorphic function $g: X_{\Gamma} \rightarrow \mathbb{C}$.
