# Definition 19.1

Let $f: \mathbb{H} \rightarrow \mathbb{C}$ be a meromorphic function that is
 $\Gamma$-invariant for some congruence subgroup $\Gamma$. The function
 $f(\tau)$ is said to be meromorphic at the cusps if for every $\gamma \in
 \mathrm{SL}_{2}(\mathbb{Z})$ the function $f(\gamma \tau)$ is meromorphic at
 $\infty$.
