# Theorem 22.3

Let $\varphi: E \rightarrow E'$ be an $\ell$-isogeny of elliptic curves
 defined over a field $k$. Then $\operatorname{End}^0(E') \simeq
 \operatorname{End}^0(E)$, and if $\operatorname{End}^0(E) = K$ is an
 imaginary quadratic field then $\operatorname{End}(E) = \mathcal{O}$ and
 $\operatorname{End}(E') = \mathcal{O}'$ are orders in $K$ such that one of
 the following holds: (i) $\mathcal{O} = \mathcal{O}'$, (ii) $[\mathcal{O} :
 \mathcal{O}'] = \ell$, (iii) $[\mathcal{O}' : \mathcal{O}] = \ell$.
