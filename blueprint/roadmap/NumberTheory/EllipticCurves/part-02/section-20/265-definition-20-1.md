# Definition 20.1

If $L_{1}$ is a sublattice of $L_{2}$ for which the group $L_{2} / L_{1}$ is
 cyclic, then we say that $L_{1}$ is a cyclic sublattice of $L_{2}$.
 Similarly, an isogeny $\phi: E_{1} \rightarrow E_{2}$ is said to be cyclic
 if its kernel is a cyclic group. If $\phi$ is induced by the lattice
 inclusion $L_{1} \subseteq L_{2}$ then $\phi$ is cyclic if and only if
 $L_{1}$ is a cyclic sublattice of $L_{2}$.
