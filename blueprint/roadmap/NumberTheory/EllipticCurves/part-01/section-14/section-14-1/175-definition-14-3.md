# Definition 14.3

A fundamental parallelogram for $L=\left[\omega_{1}, \omega_{2}\right]$ is
 any set of the form $\mathcal{F}_{\alpha}=\left\{\alpha+t_{1}
 \omega_{1}+t_{2} \omega_{2} \mid \alpha \in \mathbb{C}, 0 \leq t_{1},
 t_{2}<1\right\}$.
