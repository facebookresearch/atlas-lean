# Lemma 15.10

The set $\mathcal{F}=\{\tau \in \mathbb{H} \mid \operatorname{re}(\tau) \in
 [-1/2,1/2) \text{ and } |\tau| \geq 1, \text{ such that } |\tau|>1 \text{ if
 } \operatorname{re}(\tau)>0\}$ is a fundamental domain for $\mathbb{H} /
 \Gamma$.
