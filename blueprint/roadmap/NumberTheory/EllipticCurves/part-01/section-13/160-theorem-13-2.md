# Theorem 13.2

Let $\phi: E_{1} \rightarrow E_{2}$ be an isogeny of elliptic curves. Then
 $E_{1}$ is supersingular if and only if $E_{2}$ is supersingular (and
 $E_{1}$ is ordinary if and only if $E_{2}$ is ordinary).
