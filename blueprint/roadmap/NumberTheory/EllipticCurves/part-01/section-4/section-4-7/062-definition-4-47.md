# Definition 4.47

Let $R$ be a commutative ring. For any $R$-ideal $I$ we define $\sqrt{I} =
 \{x \in R \mid x^r \in I \text{ for some integer } r > 0\}$ and say that $I$
 is a radical ideal if $I = \sqrt{I}$.
