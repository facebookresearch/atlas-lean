# Definition 4.46

For an algebraic set $Z \subseteq \mathbb{A}^n$, the ideal of $Z$ is the set
 $I(Z) = \{f \in \bar{k}[x_1, \ldots, x_n] \mid f(P) = 0 \text{ for all } P
 \in Z\}$.
