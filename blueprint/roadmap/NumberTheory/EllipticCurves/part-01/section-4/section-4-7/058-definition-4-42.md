# Definition 4.42

If $S$ is a set of polynomials in $\bar{k}[x_1, \ldots, x_n]$, the set of
 points $Z_S \coloneqq \{P \in \mathbb{A}^n \mid f(P) = 0 \text{ for all } f
 \in S\}$ is called an (affine) algebraic set. If $k \subseteq L \subseteq
 \bar{k}$, the set of $L$-rational points in $Z_S$ is $Z_S(L) = Z_S \cap
 \mathbb{A}^n(L)$. When $S$ is a singleton $\{f\}$ we may write $Z_f$ in
 place of $Z_{\{f\}}$.
