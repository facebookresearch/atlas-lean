# Definition 11.7

Let $N = 2^s t + 1$ be an odd integer, with $t$ odd. An integer $a \not\equiv
 0 \bmod N$ is a witness for (the compositeness of) $N$ if both of the
 following hold: (i) $a^t \not\equiv 1 \bmod N$; (ii) $a^{2^i t} \not\equiv
 -1 \bmod N$ for $0 \leq i < s$.
