# Definition 24.5

For a Galois extension of number fields $L / K$ we define the integers $e_{0}(L / K) \coloneqq \prod_{v \nmid \infty} e_{v}$, $e_{\infty}(L / K) \coloneqq \prod_{v \mid \infty} e_{v}$, $e(L / K) \coloneqq e_{0}(L / K) e_{\infty}(L / K)$.
