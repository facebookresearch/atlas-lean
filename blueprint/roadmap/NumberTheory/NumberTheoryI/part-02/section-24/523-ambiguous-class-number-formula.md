# Theorem 24.11 (Ambiguous class number formula)

Let $L / K$ be a cyclic extension of number fields with Galois group $G$. The $G$-invariant subgroup of the $G$-module $\mathrm{Cl}_{L}$ has cardinality $\# \mathrm{Cl}_{L}^{G} = \frac{e(L / K) \# \mathrm{Cl}_{K}}{n(L / K)[L : K]}$ where $n(L / K) \coloneqq [\mathcal{O}_{K}^{\times} : N(L^{\times}) \cap \mathcal{O}_{K}^{\times}] \in \mathbb{Z}_{\geq 1}$.
