# Definition 26.2

Let $K$ be a global field. The idele group of $K$ is the topological group $\mathbb{I}_{K}\coloneqq \prod_{v}(K_{v}^{\times}, \mathcal{O}_{v}^{\times})$ with multiplication defined component-wise, which we view as the subgroup $\mathbb{A}_{K}^{\times}$ of $\mathbb{A}_{K}$ endowed with the restricted product topology rather than the subspace topology. The canonical embedding $K \hookrightarrow \mathbb{A}_{K}$ restricts to a canonical embedding $K^{\times} \hookrightarrow \mathbb{I}_{K}$, and we define the idele class group $C_{K}\coloneqq \mathbb{I}_{K} / K^{\times}$, a topological group.
