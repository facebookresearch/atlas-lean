# Definition 22.12

Let $\chi_{1}, \chi_{2}$ be ray class characters of moduli $\mathfrak{m}_{1}, \mathfrak{m}_{2}$ of a number field $K$, with $\mathfrak{m}_{1} \mid \mathfrak{m}_{2}$. If $\chi_{2}(I)=\chi_{1}(I)$ for all $I \in \mathcal{I}_{K}^{\mathfrak{m}_{2}}$, then $\chi_{2}$ is induced by $\chi_{1}$. A ray class character is primitive if it is not induced by any ray class character other than itself.
