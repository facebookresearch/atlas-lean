# Definition 21.10

Let $K$ be a number field and let $S$ be a set of primes of $K$. The partial Dedekind zeta function associated to $S$ is the complex function $\zeta_{K, S}(s)\coloneqq \prod_{\mathfrak{p} \in S}(1-\mathrm{N}(\mathfrak{p})^{-s})^{-1}$ which converges to a holomorphic function on $\operatorname{Re}(s)>1$.
