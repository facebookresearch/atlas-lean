# Definition 21.11

If for some integer $n \geq 1$ the function $\zeta_{K, S}^{n}$ extends to a meromorphic function on a neighborhood of 1, the polar density of $S$ is defined by $\rho(S)\coloneqq \frac{m}{n}$, $m=-\operatorname{ord}_{s=1} \zeta_{K, S}^{n}(s)$ (so $m$ is the order of the pole at $s=1$, if one is present). Note that if $\zeta_{K, S}^{n_{1}}$ and $\zeta_{K, S}^{n_{2}}$ both extend to a meromorphic function on a neighborhood of 1 then we necessarily have $n_{2} \operatorname{ord}_{s=1} \zeta_{K, S}^{n_{1}}(s)=\operatorname{ord}_{s=1} \zeta_{K, S}^{n_{1} n_{2}}=n_{1} \operatorname{ord}_{s=1} \zeta_{K, S}^{n_{2}}(s)$ which implies that $\rho(S)$ does not depend on the choice of $n$.
