# Definition 21.3

Let $\mathfrak{m}$ be a modulus for a number field $K$. The ray class group for the modulus $\mathfrak{m}$ is the quotient $\mathrm{Cl}_{K}^{\mathfrak{m}} \coloneqq \mathcal{I}_{K}^{\mathfrak{m}} / \mathcal{R}_{K}^{\mathfrak{m}}$.
