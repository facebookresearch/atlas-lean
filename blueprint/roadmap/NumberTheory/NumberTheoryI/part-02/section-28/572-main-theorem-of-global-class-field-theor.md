# Theorem 28.7 (Main theorem of global class field theory)

Let $K$ be a global field. The global Artin homomorphism $\theta_{K}$ induces a canonical isomorphism $\widehat{\theta}_{K}: \widehat{C_{K}} \xrightarrow{\sim} \operatorname{Gal}\left(K^{\mathrm{ab}} / K\right)$ of profinite groups. We then have an inclusion reversing bijection between finite index open subgroups $H$ of $C_{K}$ and finite abelian extensions $L / K$ in $K^{\mathrm{ab}}$, given by $H \mapsto\left(K^{\mathrm{ab}}\right)^{\theta_{K}(H)}$ and $L \mapsto \mathrm{N}_{L / K}\left(C_{L}\right)$, and corresponding isomorphisms $C_{K} / H \simeq \operatorname{Gal}(L / K)$, where $H=\mathrm{N}_{L / K}\left(C_{L}\right)$.
