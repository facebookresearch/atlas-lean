# Theorem 28.6 (Global Existence Theorem)

Let $K$ be a global field. For every finite index open subgroup $H$ of $C_{K}$ there is a unique finite abelian extension $L / K$ in $K^{\mathrm{ab}}$ for which $\mathrm{N}_{L / K}\left(C_{L}\right)=H$.
