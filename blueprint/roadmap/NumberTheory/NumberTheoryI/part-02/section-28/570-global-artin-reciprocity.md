# Theorem 28.4 (Global Artin Reciprocity)

Let $K$ be a global field. The kernel of the global Artin homomorphism $\theta_{K}$ contains $K^{\times}$, and we thus have a continuous homomorphism $\theta_{K}: C_{K} \rightarrow \operatorname{Gal}\left(K^{\mathrm{ab}} / K\right)$, with the property that for every finite abelian extension $L / K$ in $K^{\mathrm{ab}}$ the homomorphism $\theta_{L / K}: C_{K} \rightarrow \operatorname{Gal}(L / K)$ obtained by composing $\theta_{K}$ with the natural map $\operatorname{Gal}\left(K^{\mathrm{ab}} / K\right) \rightarrow \operatorname{Gal}(L / K)$ is surjective with kernel $\mathrm{N}_{L / K}\left(C_{L}\right)$, inducing an isomorphism $C_{K} / \mathrm{N}_{L / K}\left(C_{L}\right) \simeq \operatorname{Gal}(L / K)$.
