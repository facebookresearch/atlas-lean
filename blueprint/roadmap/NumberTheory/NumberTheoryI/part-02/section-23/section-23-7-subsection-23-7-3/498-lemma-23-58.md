# Lemma 23.58

Let $\varphi: M \rightarrow N$ and $\phi: N \rightarrow P$ be morphisms of $R$-modules. The sequence $M \xrightarrow{\varphi} N \xrightarrow{\phi} P \longrightarrow 0$ is exact if and only if for every $R$-module $A$ the sequence $0 \longrightarrow \operatorname{Hom}_{R}(P, A) \xrightarrow{\phi^{*}} \operatorname{Hom}_{R}(N, A) \xrightarrow{\varphi^{*}} \operatorname{Hom}_{R}(M, A)$ is exact.
