# Definition 23.16

A category containing finite coproducts (such as direct sums) in which each set of morphisms between objects has the structure of an abelian group whose addition distributes over composition (and vice versa) is called an additive category. A functor $F$ between additive categories is an additive functor if it maps zero objects to zero objects and satisfies $F(X \oplus Y) \simeq F(X) \oplus F(Y)$, where the isomorphism commutes with the natural inclusion and projection maps for the direct sums on both sides.
