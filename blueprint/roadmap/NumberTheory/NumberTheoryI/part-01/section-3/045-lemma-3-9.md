# Lemma 3.9

Let $\mathfrak{p}$ be a nonzero prime ideal in a Dedekind domain $A$. If $I$ is an ideal of $A$ then $v_{\mathfrak{p}}(I)=0$ if and only if $\mathfrak{p}$ does not contain $I$. In particular, if $\mathfrak{q}$ is any nonzero prime ideal different from $\mathfrak{p}$ then $v_{\mathfrak{q}}(\mathfrak{p})=v_{\mathfrak{p}}(\mathfrak{q})=0$.
