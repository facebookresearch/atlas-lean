# Lemma 14.3

A subgroup $G \subseteq V \simeq \mathbb{R}^{n}$ is finitely generated if and only if it is discrete, in which case $G \simeq \mathbb{Z}^{m}$ for some $m \leq n$ and $G$ is then cocompact if and only if $m=n$.
