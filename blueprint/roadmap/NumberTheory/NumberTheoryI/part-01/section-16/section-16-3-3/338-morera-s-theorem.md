# Theorem 16.28 (Morera's Theorem)

Let $f$ be a continuous function on an open set $U$, and suppose that for every simple closed curve $\gamma$ contained in $U$ we have $$\int_{\gamma} f(z)\, dz = 0.$$ Then $f$ is holomorphic on $U$.
