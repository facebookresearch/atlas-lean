# Theorem 16.26 (Cauchy's Integral Formula)

Let $U$ be an open set containing a simple closed curve $\gamma$. For any function $f$ holomorphic on $U$ and $a$ in the interior of $\gamma$, $$f(a) = \frac{1}{2\pi i} \int_{\gamma} \frac{f(z)}{z - a}\, dz.$$
