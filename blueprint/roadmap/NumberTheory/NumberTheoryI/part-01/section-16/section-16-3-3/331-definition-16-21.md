# Definition 16.21

A parameterized curve is a continuous function $\gamma:[a,b] \rightarrow \mathbb{C}$ whose domain is a compact interval $[a,b] \subseteq \mathbb{R}$. We say that $\gamma$ is smooth if it has a continuous nonzero derivative on $[a,b]$, and piecewise-smooth if $[a,b]$ can be partitioned into finitely many subintervals on which the restriction of $\gamma$ is smooth. We say that $\gamma$ is closed if $\gamma(a) = \gamma(b)$, and simple if it is injective on $[a,b)$ and $(a,b]$. Henceforth we will use the term curve to refer to any piecewise-smooth parameterized curve $\gamma$, or to its oriented image in the complex plane (directed from $\gamma(a)$ to $\gamma(b)$), which we may also denote $\gamma$.
