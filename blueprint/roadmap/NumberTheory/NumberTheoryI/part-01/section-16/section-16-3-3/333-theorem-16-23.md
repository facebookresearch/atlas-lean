# Theorem 16.23

Let $\gamma:[a,b] \rightarrow \mathbb{C}$ be a curve in an open set $\Omega$ and let $f: \Omega \rightarrow \mathbb{C}$ be a holomorphic function. Then $$\int_{\gamma} f'(z)\, dz = f(\gamma(b)) - f(\gamma(a)).$$
