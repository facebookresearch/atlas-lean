# Definition 17.12

The Gamma function $$\Gamma(s)\coloneqq \mathcal{M}\left(e^{-t}\right)(s)=\int_{0}^{\infty} e^{-t} t^{s-1} d t$$ is the Mellin transform of $e^{-t}$. Since $\int_{0}^{\infty}\left|e^{-t}\right| t^{\sigma-1} d t$ converges for all $\sigma>0$, the integral defines a holomorphic function on $\operatorname{Re}(s)>0$.
