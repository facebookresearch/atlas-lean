# Definition 13.4

If $L/K$ is an extension of global fields, for every place $w$ of $L$, any absolute value $|\,|_w$ that represents the equivalence class $w$ restricts to an absolute value on $K$ that represents a place $v$ of $K$ that is independent of the choice of $|\,|_w$. We write $w \mid v$ to indicate this relationship and say that $w$ extends $v$ or that $w$ lies above $v$.
