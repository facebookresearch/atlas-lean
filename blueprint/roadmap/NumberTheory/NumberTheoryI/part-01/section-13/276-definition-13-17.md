# Definition 13.17

Let $K$ be a global field. For each place $v$ of $K$ the normalized absolute value $\|\,\|_{v}: K_{v} \rightarrow \mathbb{R}_{\geq 0}$ on the completion of $K$ at $v$ is defined by $\|x\|_{v}\coloneqq \frac{\mu(xS)}{\mu(S)}$ where $\mu$ is a Haar measure on $K_{v}$ and $S \subseteq K_{v}$ is a measurable set with finite nonzero measure (such as the set $\{x \in K_{v}:|x|_{v} \leq 1\}$, for example).
