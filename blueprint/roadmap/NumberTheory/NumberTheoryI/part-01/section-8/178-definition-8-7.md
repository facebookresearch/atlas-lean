# Definition 8.7

A directed set is a set $I$ with a relation "$\leq$" that is reflexive ($i \leq i$), antisymmetric ($i \leq j \leq i \Rightarrow i = j$), and transitive ($i \leq j \leq k \Rightarrow i \leq k$), in which every finite subset has an upper bound (in particular, $I$ is non-empty).
