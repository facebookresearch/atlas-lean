# Definition 8.8

An inverse system (projective system) in a category is a family of objects $\{X_i : i \in I\}$ indexed by a directed set $I$ and a family of morphisms $\{f_{ij} : X_i \leftarrow X_j : i \leq j\}$ (note the direction) such that each $f_{ii}$ is the identity and $f_{ik} = f_{ij} \circ f_{jk}$ for all $i \leq j \leq k$.
