# Definition 8.2

An abelian group $G$ is a topological group if it is a topological space in which the map $G \times G \rightarrow G$ defined by $(g, h) \mapsto g+h$ and the map $G \rightarrow G$ defined by $g \mapsto -g$ are both continuous (here $G \times G$ has the product topology). A commutative ring $R$ is a topological ring if it is a topological space in which the maps $R \times R \rightarrow R$ defined by $(r, s) \mapsto r+s$ and $(r, s) \mapsto rs$ are both continuous; the additive group of $R$ is then a topological group, since $(-1, s) \mapsto -s$ is continuous, but the unit group $R^{\times}$ need not be a topological group, in general. A field $K$ is a topological field if it is a topological ring whose unit group is a topological group.
