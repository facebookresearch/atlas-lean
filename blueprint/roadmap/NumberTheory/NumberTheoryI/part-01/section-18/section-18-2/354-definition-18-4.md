# Definition 18.4

A function $f \colon \mathbb{Z} \to \mathbb{C}$ is called an arithmetic function. The function $f$ is multiplicative if $f(1) = 1$ and $f(mn) = f(m)f(n)$ for all coprime $m, n \in \mathbb{Z}$; it is totally multiplicative (or completely multiplicative) if $f(1) = 1$ and $f(mn) = f(m)f(n)$ for all $m, n \in \mathbb{Z}$. For $m \in \mathbb{Z}_{>0}$ we say that $f$ is $m$-periodic if $f(n+m) = f(n)$ for all $n \in \mathbb{Z}$, and we call $m$ the period of $f$ if it is the least $m > 0$ for which this holds.
