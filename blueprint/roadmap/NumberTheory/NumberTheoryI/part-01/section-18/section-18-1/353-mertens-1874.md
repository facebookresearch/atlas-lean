# Theorem 18.3 (Mertens 1874)

As $x \to \infty$ we have (1) $\sum_{p \leq x} \frac{\log p}{p} = \log x + R(x)$, where $|R(x)| < 2$. (2) $\sum_{p \leq x} \frac{1}{p} = \log \log x + B + O(1/\log x)$, where $B = 0.261497\ldots$ is Mertens' constant; (3) $\sum_{p \leq x} \log(1 - 1/p) = -\log \log x - \gamma + O(1/\log x)$, where $\gamma = 0.577216\ldots$ is Euler's constant.
