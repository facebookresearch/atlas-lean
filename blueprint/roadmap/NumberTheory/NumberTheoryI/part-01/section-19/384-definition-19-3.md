# Definition 19.3

Let $X$ and $Y$ be metric spaces. A function $f: X \rightarrow Y$ is Lipschitz continuous if there exists $c \in \mathbb{R}_{>0}$ such that for all $x_{1}, x_{2} \in X$ we have $$d\left(f\left(x_{1}\right), f\left(x_{2}\right)\right) \leq c \cdot d\left(x_{1}, x_{2}\right).$$
