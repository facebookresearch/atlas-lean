# Level N structure package

Structure of the level-`N` algebra generated by `j` and the Fricke functions: the
stabilizer of the Fricke functions at nonzero labels under the label action is `±Γ(N)`;
`SL(2, ℤ)`-invariant ratios are rational functions of `j`; each Fricke function at a nonzero
label is integral over `ℂ[j]`; `j` is transcendental; and the algebra consists of holomorphic
functions and has no zero divisors.
