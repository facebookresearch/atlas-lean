# Exists int eq wilson Quotient ZPlus two mul and mod Eq

Morozov's Theorem 5: for the integer value of `Z^+(2n)`,
it is `0 [ZMOD 2n]` when `n = 2` or `n` is composite, and
`n + 1 [ZMOD 2n]` when `n` is an odd prime.
