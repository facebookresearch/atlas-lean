# Neg one pow mul factorial mul factorial mod Eq neg one iff

Morozov's Corollary 1: for `1 ≤ n` and `k < n`,
`(-1) ^ k * k ! * (n - k - 1)! ≡ -1 [ZMOD n]` if and only if
`n` is `1` or prime.
