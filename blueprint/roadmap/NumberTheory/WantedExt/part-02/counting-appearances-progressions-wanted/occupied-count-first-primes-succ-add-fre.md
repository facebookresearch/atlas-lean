# Lemma 3, occupied recurrence

**Lemma 3, occupied recurrence**:
`occ(k+1) + free(k) = P_k + (p_{k+1} - 1)·occ(k)` for every
choice of residue classes (paper form
`occ(k+1) = P_k + (p_{k+1} - 1)·occ(k) - free(k)`).
