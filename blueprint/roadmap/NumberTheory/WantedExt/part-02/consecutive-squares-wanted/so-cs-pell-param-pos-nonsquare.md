# So CS pell param pos nonsquare

For a SoCS solution `(a, b, c)`, the Pell-type parameter
`A = 3 * (b - c)^2 * (12 * (b - a)^2 * (c - b)^2 - (a - 2b + c)^4)` is
positive and is not a square.
