# So CS infinite family plane

From any SoCS solution `(a, b, c)` one obtains an infinite family of
integer solutions of the SoCS equation, all lying in the plane
`(b - c) * x + (c - a) * y + (a - b) * z = 0`, with `z - x ≡ c - a (mod 2)`.
