# Ψ star

Define `ψ⋆ : ℕ → ℝ≥0∞` by `ψ⋆ : q ↦ φ(q) * sup {ψ(n)/n : n ∈ ℕ+, q|n}`, where `φ` denotes
Euler's totient function.
