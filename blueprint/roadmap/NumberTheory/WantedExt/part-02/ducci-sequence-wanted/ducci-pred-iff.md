# Theorem 2

**Theorem 2**: for even `n`, a tuple
`x ∈ ℤ_m^n` has a Ducci predecessor (a tuple `y` with
`y_i + y_{i+1} = x_i` for all `i`, indices cyclically)
if and only if the alternating sum
`x_1 - x_2 + ⋯ + x_{n-1} - x_n` vanishes in `ℤ_m`.
