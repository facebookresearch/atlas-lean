# Lemma 4

**Lemma 4**: with `n = p^k * n₁` as in Lemma 3, for
`c ≥ 1` and `0 ≤ b < n₁`,
`a_{c * p^k, b * p^k + 1} ≡ a*_{c, b + 1} (mod p)`, where
`a*` denotes the coefficients for `n₁`.
