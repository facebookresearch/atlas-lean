# Lemma 2

**Lemma 2**: for an odd prime `p`, `k > 1`, and
`j ≤ p^k - p^{k-1}`,
`C(p^k - p^{k-1}, j) ≡ (-1)^c (mod p)` if
`j = c * p^{k-1}` for some `c`, and `≡ 0 (mod p)`
otherwise.
