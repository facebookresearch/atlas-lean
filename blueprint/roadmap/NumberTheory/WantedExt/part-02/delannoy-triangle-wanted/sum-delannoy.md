# Theorem 9

**Theorem 9**: for an odd prime `p`,
`∑_{0 ≤ k ≤ n ≤ p-1} C(n, k)_{[2]} ≡ (2 / p) (mod p)`,
where `(2 / p)` is the Legendre symbol.
