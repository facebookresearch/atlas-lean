# Lemma 5

**Lemma 5**: for an odd prime `p`, an integer `s`,
and `1 ≤ k ≤ p - 1`,
`C(sp-1, k) ≡ (-1)^k (1 - sp H_k
  + (s^2 p^2 / 2) (H_k^2 - H_{k,2})) (mod p^3)`, where
the binomial coefficient is written as
`∏_{i=1}^k (sp - i) / k!` in `ZMod (p^3)`.
