# Multiplicative additive on sum two triangular zero of five ne zero

Park's Lemma 4: under the same hypotheses, if `f 2 = 0` and
`f 5 ≠ 0`, then `f n = 0` for `2 ≤ n ≤ 21` with `n ≠ 5`.
