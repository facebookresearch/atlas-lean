# Dusart Pi Lower Second Order Wanted

Dusart second-order lower bound for `π(x)`: for `x ≥ 88789`,
`π(x) ≥ x / log x * (1 + 1 / log x + 2 / (log x)^2)`, with `π` as
`Nat.primeCounting ⌊x⌋₊`.
