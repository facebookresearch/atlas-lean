# Dusart Pi Upper Second Order Wanted

Dusart second-order upper bound for `π(x)`: for `x > 1`,
`π(x) ≤ x / log x * (1 + 1 / log x + 2.53816 / (log x)^2)`, with `π` as
`Nat.primeCounting ⌊x⌋₊`.
