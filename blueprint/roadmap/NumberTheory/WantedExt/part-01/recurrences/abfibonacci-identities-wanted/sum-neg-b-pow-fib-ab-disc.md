# Theorem 10(a)

**Theorem 10(a)**: if `Δ = a^2 + 4b ≠ 0` then
(i) `∑_{i=0}^n (-b)^(n-i) F_{2i}
  = (L_{2n+1} + (-1)^(n+1) a b^n) / Δ` and
(ii) `∑_{i=0}^n (-b)^(n-i) F_{2i+1}
  = (L_{2n+2} + (-1)^n 2 b^(n+1)) / Δ`.
