# Theorem 10(b)

**Theorem 10(b)**: the Fibonacci case `(a, b) = (1, 1)`:
`∑ (-1)^i F_{2i} = ((-1)^n L_{2n+1} - 1) / 5`,
`∑ (-1)^i L_{2i} = (-1)^n F_{2n+1} + 1`,
`∑ (-1)^i F_{2i+1} = ((-1)^n L_{2n+2} + 2) / 5`,
`∑ (-1)^i L_{2i+1} = (-1)^n F_{2n+2}`.
