# Theorem 10(c)

**Theorem 10(c)**: the Pell case `(a, b) = (2, 1)`
(`P` and `Q` in the paper):
`∑ (-1)^i P_{2i} = ((-1)^n Q_{2n+1} - 2) / 8`,
`∑ (-1)^i Q_{2i} = (-1)^n P_{2n+1} + 1`,
`∑ (-1)^i P_{2i+1} = ((-1)^n Q_{2n+2} + 2) / 8`,
`∑ (-1)^i Q_{2i+1} = (-1)^n P_{2n+2}`.
