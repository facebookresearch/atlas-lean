# Theorem 1

**Theorem 1**: Sury's identity for a second-order recurrence with
`A 0 = 1`.  With `t = c₁ - A 1`, assumed nonzero as in the source,
the weighted initial segment determines `A (n+2) - A 1 * A (n+1)`.
