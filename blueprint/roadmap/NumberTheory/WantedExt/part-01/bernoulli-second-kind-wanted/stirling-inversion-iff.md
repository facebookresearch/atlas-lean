# Lemma 3

**Lemma 3** (Stirling inversion): for rational
sequences `u, v`, `u n = ∑_{k=0}^n s(n,k) v k` for all `n`
if and only if `v n = ∑_{k=0}^n S(n,k) u k` for all `n`
(paper: complex sequences).
