# Theorem 1

**Theorem 1**: if
`liminf (log Aₙ / log a_{n+1}) > 2` (stated with a finite
margin, which also covers the paper's `+∞` case: some
`c > 2` is eventually below the quotient), then `a` is
a Bonse sequence.
