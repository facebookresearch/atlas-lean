# Theorem 2

**Theorem 2**: if
`(n log log aₙ) / log a_{n+1} → 0` and
`liminf (log Aₙ / log a_{n+1}) < 2` (stated as: the
quotient is frequently below some `c < 2`), then `a` is
not a Bonse sequence.
