# Lemma 6

**Lemma 6**(b), with the single-wrap hypothesis (see
the module docstring): if `m` is the smallest nonnegative
integer with `J_k(n) + k * m > n + m` and moreover
`J_k(n) + k * m ≤ 2 * (n + m)`, then
`J_k(n + m) = J_k(n) + k * m - (n + m)`.
