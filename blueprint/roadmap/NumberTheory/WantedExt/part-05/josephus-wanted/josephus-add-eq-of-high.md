# Theorem 9

**Theorem 9**(a): if `n_e ≥ 2k - 3` is a high
extremal point and `j := J_k(n_e + 1)`, then
`J_k(n_e + 1 + m) = j + k * m` for all
`m ≤ ⌊(n_e - (j - 1)) / (k - 1)⌋`.
