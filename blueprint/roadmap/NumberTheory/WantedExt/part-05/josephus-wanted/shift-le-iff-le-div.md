# Lemma 8

**Lemma 8**(a): if `j := J_k(n + 1) ∈ [[1, k - 1]]`
(so `n + 1` is a low extremal point), the nonnegative
solutions of `j + k * m ≤ n + 1 + m` are exactly
`m ≤ ⌊(n - (j - 1)) / (k - 1)⌋`, and that bound is at
least `1` when `n ≥ k - 2 + j`.
