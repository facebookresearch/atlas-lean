# Theorem 2

**Theorem 2**: with `p := J_k(n)`, if
`p + k ∈ [[ℓ(n+1) + 1, (ℓ+1)(n+1)]]` for some
nonnegative integer `ℓ`, then
`J_k(n+1) = p + k - ℓ(n+1)`.
