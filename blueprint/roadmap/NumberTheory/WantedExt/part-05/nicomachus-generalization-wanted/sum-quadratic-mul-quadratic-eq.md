# Theorem 2 (18)

**Theorem 2 (18)**: with `(a, b, c) = (1, α_k, -(1 + α_k))`
and `(d, e, f) = (-a, -c, -b)` as in (17),
`Σ_{j=1}^m (a + bj + cj²)(d + ej + fj²)
= T_{m-1}·((1 + m)(2 - 3m²)/(3(3 + 2u_k)) + (3 + 2m)T_{m-1})`.
