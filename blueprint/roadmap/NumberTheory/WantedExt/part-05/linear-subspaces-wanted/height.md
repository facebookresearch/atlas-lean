# Height

For a rational subspace `V ≤ ℝᵈ`, choose a basis `v₁, ... vₖ` for the subgroup `V ∩ ℤᵈ`.
The height is defined as `H(v) = ‖v₁ ∧ ··· ∧ vₖ‖`, where the norm on `⋀ᵏ ℝᵈ` is the usual
Euclidean norm.
