# Proposition 7

**Proposition 7**(i): for `p ≥ 2` and `n ≥ 1`,
`A_p(n) = A_p(n-1) + A_p(n-p-1) + 1` if `n ≡ 1 (mod p)`,
else `A_p(n-1) + A_p(n-p-1)` (fails at `p = 1`).
