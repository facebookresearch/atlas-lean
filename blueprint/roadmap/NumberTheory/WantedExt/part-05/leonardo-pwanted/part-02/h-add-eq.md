# Corollary 11

**Corollary 11** (convolution identity): for
`ℋ ∈ H(p)` and `m, n > 0`,
`ℋ(m+n) = ℋ(m)A_p(n+1) + ∑_{i=1}^{p-1} ℋ(m-i)B_p(n-p+i+1)
- ∑_{i=0}^p ℋ(m-p-i)A_p(n-p+i)`.
