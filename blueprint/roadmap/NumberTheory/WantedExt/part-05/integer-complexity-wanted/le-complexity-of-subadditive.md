# Proposition 2

**Proposition 2**: if `P : ℕ → ℝ` satisfies `P 1 = 1`
and `P (n + m) ≤ P n + P m`, `P (n * m) ≤ P n + P m` for
all positive `n, m`, then `P n ≤ ‖n‖` for all positive
`n`.
