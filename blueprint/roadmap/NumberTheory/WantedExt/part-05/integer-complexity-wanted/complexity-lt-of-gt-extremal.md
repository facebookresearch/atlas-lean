# Corollary 2

**Corollary 2**, second claim: writing an integer
`v > 1` uniquely as `v = 2a + 3b` with `a ∈ {0, 1, 2}`,
the number `2^a * 3^b` is the greatest `m` with
`‖m‖ = v`; in particular `m > 2^a * 3^b` implies
`‖m‖ > 2a + 3b`.
