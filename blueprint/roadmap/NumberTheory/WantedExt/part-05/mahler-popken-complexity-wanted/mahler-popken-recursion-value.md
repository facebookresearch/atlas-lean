# Mahler Popken Recursion Value

The right-hand side of the recursion (9): the minimum of
`∥d∥ₘ + ∥n/d∥ₘ` over divisors `d ∣ n` with `d ≠ 1` and `d ≠ n`,
and of `∥η∥ₘ + ∥n - η∥ₘ` over `0 < η < n`.
