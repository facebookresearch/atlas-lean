# Statement

The sequence `{L_n mod m : n ≥ 0}` is a complete residue system modulo `m`
if and only if `m ∈ {2, 4, 6, 7, 14}` or `m = 3 ^ k` for some integer `k ≥ 1`
(OPG-37402, Lucas Numbers Modulo m [OpenGarden]).
