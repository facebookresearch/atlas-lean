# Proposition 3

**Proposition 3** (= **Theorem 1**(1)): for `m ≥ 1` and
positive even `n` with `2^m < n ≤ 2^(m+1)`, `‖n‖₂ = m + 1`
if and only if `n = 2^m + 2^t` for some `1 ≤ t ≤ m`
(the case `t = m` gives `n = 2^(m+1)`).
