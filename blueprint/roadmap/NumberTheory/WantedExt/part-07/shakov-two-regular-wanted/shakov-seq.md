# Shakov Seq

Shakov's `2`-regular sequence: `s(1) = 0`,
`s(2) = s(3) = 1`, and
`s(4k) = 2 s(2k) - s(k)`,
`s(4k+1) = 2 s(2k) + s(2k+1)`,
`s(4k+2) = 2 s(2k+1) + s(2k)`,
`s(4k+3) = 2 s(2k+1) - s(k)`.
The value at `0` is a dummy.
