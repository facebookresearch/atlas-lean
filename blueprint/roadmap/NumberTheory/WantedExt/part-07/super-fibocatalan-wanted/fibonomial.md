# Fibonomial

The paper's fibonomial coefficient
`⟨n k⟩_F = F_n!/(F_k! F_{n-k}!)`, in `ℚ`, for `k ≤ n`;
extended by `0` for `k > n` (outside the paper's domain the
raw quotient would use truncated subtraction).
