# Corollary 12

**Corollary 12**: for `n ≥ 1`, the number
`{2n+1} {2} {2n}!/({n+2}! {n}!)`, which equals
`{2} (1/{n+2}) ⟨2n+1 n⟩` (the displayed equality cleared of
denominators), is a polynomial with non-negative integer
coefficients.
