# Theorem 3

**Theorem 3** (corrected): if `p^a` is
`[2,ℓ]`-deficient-perfect then `ℓ = 1` and (`a = 2` or
`p^a = 2`); the printed exception `a = 2`, `ℓ = 1` omits
the solution `p = 2`, `a = 1`, `ℓ = 1`, `d = 1` (the
number `2` of Corollary 1).
