# Corollary 2

**Corollary 2**, first formula: for positive `n, r`
with `n ≥ r + 1`, `(-1)ⁿ Bₙ = (n/(2ⁿ-1)) ∑_{k=1}^{n-r}
(∑_{j=0}^r (-1)^{k+j+r+1} 2^{r-j} (k+j-1)!/k! S(r,j))
Δᵏ0^{n-r}/2^{k+r}`.
