# Theorem 4.1

**Theorem 4.1**: for `m ≥ 2` and `n ≤ 2m + 1`,
`E_n(x) = ∑_{k=0}^m (-1)^k (m + 1 choose k + 1) / 2^k
  ∑_{j=0}^k (k choose j) (x + j - (k + 1) / 2)^n`.
