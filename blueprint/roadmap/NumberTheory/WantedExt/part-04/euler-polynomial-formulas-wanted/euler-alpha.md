# Euler Alpha

The Taylor coefficients `α_k` of
`(2 + 2z) / (2 + 2z + z^2)`, defined by the recurrence
`2 α_{k+2} + 2 α_{k+1} + α_k = 0` with `α_0 = 1`,
`α_1 = 0`.
