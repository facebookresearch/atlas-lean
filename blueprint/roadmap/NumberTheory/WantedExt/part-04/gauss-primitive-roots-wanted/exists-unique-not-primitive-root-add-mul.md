# Corollary 1

**Corollary 1**: if `g` is a primitive root of the odd prime
`p`, then there exists a unique `m` modulo `p` such that `g + mp`
is not a primitive root of `p²`, and `g + kp` is a primitive root
of `p²` for every other `k` modulo `p`.
