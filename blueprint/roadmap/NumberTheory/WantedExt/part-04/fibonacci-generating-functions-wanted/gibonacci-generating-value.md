# Gibonacci Generating Value

The value at `x` of the Fibonacci-like generating function
`G^{(a,b)}(x) = ((b - a) x + a) / (1 - x - x ^ 2)` attached to the
Gibonacci sequence with `G^{(a,b)}_0 = a` and `G^{(a,b)}_1 = b`
(`gibonacciNumber a b`).
