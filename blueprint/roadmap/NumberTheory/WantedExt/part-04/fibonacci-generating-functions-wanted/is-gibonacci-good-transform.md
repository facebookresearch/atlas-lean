# Is Gibonacci Good transform

Integrality propagates along the two fractional transforms: if
`p / q` (in lowest terms) is good for `(a, b)`, then so are
`q / (p + q)` (when `p + q ≠ 0`) and `(q - p) / p` (when `p ≠ 0`).
