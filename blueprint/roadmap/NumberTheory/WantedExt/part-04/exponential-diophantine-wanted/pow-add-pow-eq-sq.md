# Theorem 6

**Theorem 6**: the Diophantine equation
`p^x + (p + a)^y = z^2`, where `a ≡ 0 (mod 4)` and
`a ≡ -1 (mod p)`, has no solution other than
`(x, y, z) = (0, 1, √(p + a + 1))` when `p + a + 1` is a
perfect square, provided `p ≠ 3` and `p`, `p + a` are
both odd primes.
