# Lemma 2

**Lemma 2**: if `x ≡ 1 (mod 3)`, then `3` exactly divides
`x^2 + x + 1`, in the sense `3 ∣ x^2 + x + 1` but
`¬ 9 ∣ x^2 + x + 1`.
