# Lemma 4

**Lemma 4**: a nonzero-`x` integer point on
`y^2 = a*x^4 + c*x^2 + e` yields an integer point with nonzero
`X`-coordinate on `Y^2 = X^3 + c*X^2 + a*e*X`.
