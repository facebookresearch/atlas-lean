# Theorem 1

**Theorem 1**(1): for `n ≥ 1`,
`a_n = (1/6) ∑_{m=0}^{n} C(n, m) 4^{n-m} f_m`, where
`f_m` is the Franel number
`MetaMathlibExt.binomialPowerSeq 3 0 m`.
