# Corollary 2

**Corollary 2**(1): the ordinary generating function
satisfies `∑_{n ≥ 0} a_n x^n
= (₂F₁(1/3, 2/3; 1; 27x(1 - 4x)^2) + 5) / 6` on the
common convergence domain.
