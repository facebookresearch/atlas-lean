# Exists is PFrobenius Number star of le nine

The `6 ≤ n ≤ 9` case of Theorem 1: for `p = 0, 1, 2`, the
`p`-Frobenius number of the three consecutive star numbers is
`2n * S_{n+1} + (p + 2) * n * S_{n+2} - S_n` (written over `ℤ`).
