# Is Nondeficient

Zelinsky's *non-deficient*: a positive integer with
`σ(n) ≥ 2n`. (Positivity is part of the notion: with
`Nat.divisors 0 = ∅` the bare divisor-sum inequality would make
`0` vacuously non-deficient.)
