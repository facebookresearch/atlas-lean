# Theorem 3

**Theorem 3**: if `n = 2` and `p ≡ 3 (mod 4)`,
then `(x, y, z)` is a nonnegative integer solution
of Equation (1) if and only if it is `(3, 0, 3)`,
or `(6, 2, 17)` with `p = 3`, or `(0, 1, z)` with
`z^2 = 5p + 1`.
