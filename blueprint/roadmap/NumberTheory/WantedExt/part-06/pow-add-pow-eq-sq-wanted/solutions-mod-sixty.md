# Theorem 4

**Theorem 4**: if `n ≡ 3 (mod 60)` or
`n ≡ 27 (mod 60)`, and `p ≡ 7 (mod 12)` with
`gcd(n, p) = gcd(n, 5p - 1) = 1`, then `(x, y, z)`
is a nonnegative integer solution of Equation (1)
if and only if it is `(0, 1, z)` with `z^2 = 5p + 1`
or `(1, 0, z)` with `z^2 = n + 1`.
