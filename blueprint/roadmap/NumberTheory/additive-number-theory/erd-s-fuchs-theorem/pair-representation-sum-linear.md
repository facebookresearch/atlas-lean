# Erdős Problem 763 (Erdős–Turán question on representation counts)

The statement that there are a set $A$ of natural numbers and reals $c > 0$ and $C$ with $\bigl|\sum_{n=0}^{N} r_A(n) - cN\bigr| \le C$ for every natural number $N$, where $r_A(n)$ is the number of ordered pairs $(a, b) \in A \times A$ with $a + b = n$.
