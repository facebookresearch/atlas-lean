# Erdős Problem 343 (Folkman's problem on dense multisets)

The statement that there is a real $C > 0$ such that every multiset $A$ of positive integers, with $m(n)$ copies of each $n$ and $\sum_{n=1}^{N} m(n) \ge C N$ for all sufficiently large $N$, is subcomplete: its set $P(A)$ of finite subsums contains an infinite arithmetic progression $a, a + d, a + 2d, \dots$ with $d \ge 1$.
