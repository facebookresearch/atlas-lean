# Erdős Problem 347 (doubling sequences with dense subset sums)

The statement that there is a non-decreasing sequence $a_0 \le a_1 \le \cdots$ of positive integers with $a_{i+1}/a_i \to 2$ such that for every cofinite set $I$ of indices, $|P_I(a) \cap \{1, \dots, N\}|/N \to 1$ as $N \to \infty$; here for a sequence $a$ of natural numbers and a set $I$ of indices, $P_I(a)$ is the set of sums $\sum_{i \in T} a_i$ over the finite sets $T \subseteq I$ (repeated values count separately).

This page records the statement as a proposition.
