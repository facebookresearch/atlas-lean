# Erdős Problem 344 (Folkman's conjecture)

The statement that there is an absolute constant $C > 0$ such that every set $A$ of natural numbers with $|A \cap \{1, \dots, N\}| \ge C\sqrt N$ for all sufficiently large $N$ is subcomplete: the set of sums of finite subsets of $A$ contains an infinite arithmetic progression.

This page records the statement as a proposition. Its resolution: [Square-root dense sets are subcomplete](sqrt-dense-subcomplete-holds.md).
