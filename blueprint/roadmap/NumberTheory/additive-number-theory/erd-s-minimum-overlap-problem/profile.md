# Fifteen-step functions on $(-1, 1)$

For heights `w : ℕ → ℕ` in units of $10^{-8}$,
`profile w` vanishes outside $[-1, 1]$, takes the value `w i / 10⁸` on the cell
$[2i/15 - 1, 2(i + 1)/15 - 1)$ for $i < 15$, and takes the value `w 15 / 10⁸` at $1$.
Haugland's 15-step function is `profile weight`.

## Sources

- the step functions with $n$ steps in Jan Kristian Haugland, *The minimum overlap problem revisited* (2016), arXiv:1609.08000, moved from $[0, 2]$ to $[-1, 1]$.
