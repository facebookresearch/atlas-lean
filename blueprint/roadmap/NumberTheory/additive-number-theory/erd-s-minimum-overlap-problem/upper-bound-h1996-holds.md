# Haugland's 1996 upper bound for the minimum-overlap constant

The continuous Erdős
minimum-overlap constant $C_{1b}$ satisfies $C_{1b} \le 0.382002$.

## Sources

- Jan Kristian Haugland, *Advances in the minimum overlap problem*, Journal of Number Theory 58 (1996), no. 1, 71–78; *Optimization Constants in Mathematics* (crowdsourced repository curated by Terence Tao), Constant 1b, https://teorth.github.io/optimizationproblems/constants/1b.html.
