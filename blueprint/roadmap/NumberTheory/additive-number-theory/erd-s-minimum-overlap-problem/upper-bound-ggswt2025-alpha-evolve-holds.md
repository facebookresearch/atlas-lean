# AlphaEvolve upper bound for the minimum-overlap constant

The continuous Erdős
minimum-overlap constant $C_{1b}$ satisfies $C_{1b} \le 0.380924$.

## Sources

- Bogdan Georgiev, Javier Gómez-Serrano, Terence Tao, and Adam Zsolt Wagner, *Mathematical exploration and discovery at scale*, arXiv:2511.02864 (2025); *Optimization Constants in Mathematics* (crowdsourced repository curated by Terence Tao), Constant 1b, https://teorth.github.io/optimizationproblems/constants/1b.html.
