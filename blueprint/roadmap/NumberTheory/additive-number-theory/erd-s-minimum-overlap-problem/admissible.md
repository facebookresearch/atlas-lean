# Haugland's 15-step pair is admissible

Haugland's 15-step function `profile weight` and
its complement `profile complement` form an admissible pair for the continuous minimum-overlap
problem; in particular `profile weight` has integral $1$.

## Sources

- Jan Kristian Haugland, *The minimum overlap problem revisited* (2016), arXiv:1609.08000.
