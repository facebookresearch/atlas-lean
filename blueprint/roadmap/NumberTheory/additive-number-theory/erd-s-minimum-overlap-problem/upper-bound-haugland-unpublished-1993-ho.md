# Haugland's unpublished 1993 upper bound for the minimum-overlap constant

The continuous
Erdős minimum-overlap constant $C_{1b}$ satisfies $C_{1b} \le 0.385694$.

## Sources

- Jan Kristian Haugland, unpublished (1993), as recorded in *Optimization Constants in Mathematics* (crowdsourced repository curated by Terence Tao), Constant 1b, https://teorth.github.io/optimizationproblems/constants/1b.html.
