# Świerczkowski's lower bound $C_{1b} \ge (4 - \sqrt{6})/5$

The continuous Erdős
minimum-overlap constant $C_{1b}$ satisfies $(4 - \sqrt{6})/5 \le C_{1b}$.

## Sources

- Stanisław Świerczkowski, *On the intersection of a linear set with the translation of its complement*, Colloquium Mathematicum 5 (1958), 185–197; *Optimization Constants in Mathematics* (crowdsourced repository curated by Terence Tao), Constant 1b, https://teorth.github.io/optimizationproblems/constants/1b.html.
