# Moser's lower bound $C_{1b} \ge \sqrt{4 - \sqrt{15}}$

The continuous Erdős minimum-overlap
constant $C_{1b}$ satisfies $\sqrt{4 - \sqrt{15}} \le C_{1b}$.

## Sources

- Leo Moser, *On the minimum overlap problem of Erdős*, Acta Arithmetica 5 (1959), 117–119; *Optimization Constants in Mathematics* (crowdsourced repository curated by Terence Tao), Constant 1b, https://teorth.github.io/optimizationproblems/constants/1b.html.
