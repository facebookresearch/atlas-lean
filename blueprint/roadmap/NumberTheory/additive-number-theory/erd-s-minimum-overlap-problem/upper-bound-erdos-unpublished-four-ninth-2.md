# Erdős's unpublished upper bound $4/9$ for the minimum-overlap constant

The continuous
Erdős minimum-overlap constant $C_{1b}$ satisfies $C_{1b} \le 4/9$.

## Sources

- Erdős, unpublished, as recorded in *Optimization Constants in Mathematics* (crowdsourced repository curated by Terence Tao), Constant 1b, https://teorth.github.io/optimizationproblems/constants/1b.html.
