# Multiples of the first k primes are not always the largest coprime-free sets

It is not the case that for every $k \ge 1$ and every $N \ge p_k$, where $p_k$ is the $k$-th prime, every set $A \subseteq \{1, \dots, N\}$ with no $k + 1$ pairwise coprime elements has at most as many elements as the set of integers in $\{1, \dots, N\}$ divisible by one of the first $k$ primes.

## Sources
