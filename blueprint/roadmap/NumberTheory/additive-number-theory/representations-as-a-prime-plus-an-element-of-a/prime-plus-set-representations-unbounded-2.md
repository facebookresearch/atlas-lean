# Unboundedly many representations as a prime plus an element of a set

For every set $A$ of natural numbers with $|A \cap \{1, \dots, N\}| \ge c \log N$ for some $c > 0$ and all sufficiently large $N$, and every natural number $M$, there are infinitely many $n$ with $f(n) \ge M$, where for a set $A$ of natural numbers and $n \in \mathbb{N}$, $f(n)$ is the number of $a \in A$ with $a \le n$ and $n - a$ prime, the number of representations $n = p + a$.
