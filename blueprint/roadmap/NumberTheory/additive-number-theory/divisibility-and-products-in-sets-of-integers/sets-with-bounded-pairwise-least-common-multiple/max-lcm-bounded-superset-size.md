# Largest extension of Erdős's construction with bounded least common multiples

For a natural number $N$, $|C_N|$ is the largest size of a set $C$ with $B_N \subseteq C \subseteq \{1, \dots, N\}$ and $\operatorname{lcm}(a, b) \le N$ for all $a, b \in C$, where $B_N$ consists of the integers in $[1, (N/2)^{1/2}]$ together with the even integers up to $(2N)^{1/2}$.
