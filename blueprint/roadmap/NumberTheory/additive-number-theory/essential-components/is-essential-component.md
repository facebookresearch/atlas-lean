# Essential components

A set $A$ of natural numbers is an essential component when $\sigma((A \cup \{0\}) + (B \cup \{0\})) > \sigma(B)$ for every set $B$ of natural numbers with $0 < \sigma(B) < 1$, where $\sigma$ is the Schnirelmann density, $\sigma(B) = \inf_{n \ge 1} |B \cap \{1, \dots, n\}|/n$.
