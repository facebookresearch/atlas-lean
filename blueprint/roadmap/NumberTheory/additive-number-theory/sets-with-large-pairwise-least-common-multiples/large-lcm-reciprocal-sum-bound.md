# Erdős Problem 542, first question

The statement that for every $n$, every set $A \subseteq \{1, \dots, n\}$ with $\operatorname{lcm}(a, b) > n$ for all distinct $a, b \in A$ satisfies $\sum_{a \in A} 1/a \le 31/30$.

This page records the statement as a proposition. Its resolution: [Reciprocal sums of sets with large pairwise least common multiples](large-lcm-reciprocal-sum-bound-holds.md).
