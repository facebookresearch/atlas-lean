# Reciprocal sums of sets with large pairwise least common multiples

For every $n$, every set $A \subseteq \{1, \dots, n\}$ with $\operatorname{lcm}(a, b) > n$ for all distinct $a, b \in A$ satisfies $\sum_{a \in A} 1/a \le 31/30$.
