# Order of the largest sets with no square subset sum

There are reals $c > 0$ and $C$ such that for all sufficiently large $N$ the largest size $f(N)$ of a set $A \subseteq \{1, \dots, N\}$ no nonempty subset of which sums to a perfect square satisfies $c N^{1/3} \le f(N) \le N^{1/3} (\log N)^C$.
