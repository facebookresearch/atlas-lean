# Smith's upper bound for the Schur–Siegel–Smyth trace constant

The
Schur–Siegel–Smyth trace constant $C_{86}$, an extended real number, satisfies
$C_{86} < 1.89831$.

## Sources

- Smith (2024): the strict upper bound $C_{86} < 1.89831$, disproving the conjectured value $2$; infinitely many totally positive algebraic integers have absolute trace below $1.89831$.
