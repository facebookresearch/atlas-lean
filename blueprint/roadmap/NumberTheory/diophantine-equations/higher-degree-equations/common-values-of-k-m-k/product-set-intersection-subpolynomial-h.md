# Values k(m − k) and l(n − l) share few elements

For every real $\varepsilon > 0$ there is $n_0$ such that for all $n_0 < n < m$ the sets $\{k(m - k) : 1 \le k \le \lfloor m/2 \rfloor\}$ and $\{l(n - l) : 1 \le l \le \lfloor n/2 \rfloor\}$ have fewer than $(mn)^\varepsilon$ common elements.
