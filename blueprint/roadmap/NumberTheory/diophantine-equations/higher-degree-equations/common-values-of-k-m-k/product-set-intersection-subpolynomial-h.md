# Values k(m − k) and l(n − l) share few elements for distinct parameters

For every real $\varepsilon > 0$ there is $n_0$ such that for all $n_0 < n < m$ the sets $\{k(m - k) : 1 \le k \le \lfloor m/2 \rfloor\}$ and $\{l(n - l) : 1 \le l \le \lfloor n/2 \rfloor\}$ have fewer than $(mn)^\varepsilon$ common elements.

This resolves [Erdős Problem 443, second question, for distinct parameters](product-set-intersection-subpolynomial.md), the statement recorded as a proposition, in the affirmative for distinct parameters $n < m$ (the diagonal $m = n$ is excluded, since there the sets share $\lfloor n/2 \rfloor$ elements); the resolution is due to Hegyvári (2025), cited under Sources.
