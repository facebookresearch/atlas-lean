# Erdős Problem 443, second question

The statement that for every real $\varepsilon > 0$ there is $n_0$ such that for all $n_0 < n < m$ the sets $\{k(m - k) : 1 \le k \le \lfloor m/2 \rfloor\}$ and $\{l(n - l) : 1 \le l \le \lfloor n/2 \rfloor\}$ have fewer than $(mn)^\varepsilon$ common elements.
