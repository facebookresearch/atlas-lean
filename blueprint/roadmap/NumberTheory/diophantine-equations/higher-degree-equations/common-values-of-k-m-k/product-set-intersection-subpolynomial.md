# Erdős Problem 443, second question, for distinct parameters

The statement that for every real $\varepsilon > 0$ there is $n_0$ such that for all $n_0 < n < m$ the sets $\{k(m - k) : 1 \le k \le \lfloor m/2 \rfloor\}$ and $\{l(n - l) : 1 \le l \le \lfloor n/2 \rfloor\}$ have fewer than $(mn)^\varepsilon$ common elements. The question as printed asks about all sufficiently large $m, n$; for $m = n$ the map $k \mapsto k(n - k)$ is strictly increasing on $1 \le k \le \lfloor n/2 \rfloor$, so the two sets share all $\lfloor n/2 \rfloor$ elements, and $\lfloor n/2 \rfloor > (n^2)^{1/4}$ for all large $n$. The statement here is therefore the question for distinct parameters $n < m$.

This page records the statement as a proposition.
