# The number of disjoint unit sums is not o(log N)

It is not the case that $k(N) = o(\log N)$, where $k(N)$ is the largest $k$ for which there are $k$ pairwise disjoint subsets of $\{1, \dots, N\}$ each with reciprocal sum $1$.
