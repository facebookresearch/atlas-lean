# Erdős Problem 299 (bounded-gap sequences avoiding unit sums)

The statement that there is a strictly increasing sequence $a_0 < a_1 < \cdots$ of positive integers with bounded gaps ($a_{i+1} - a_i \le K$ for some $K$ and all $i$) such that no finite set $S$ of indices has $\sum_{i \in S} 1/a_i = 1$.

This page records the statement as a proposition. Its refutation: [Every bounded-gap sequence has a unit sum](bounded-gap-sequence-avoids-unit-sum-ref.md).
