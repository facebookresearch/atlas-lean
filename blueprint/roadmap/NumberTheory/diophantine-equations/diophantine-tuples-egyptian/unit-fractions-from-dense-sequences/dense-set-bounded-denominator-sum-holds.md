# Dense sets have reciprocal subsums with bounded denominators

For every real $\alpha > 0$ there is a natural number $B$ such that for every $N \ge 1$, every set $A \subseteq \{1, \dots, N\}$ with $|A| \ge \alpha N$ has a subset $S$ with $\sum_{n \in S} 1/n = a/b$ for some natural numbers $0 < a \le b \le B$.

This resolves [Erdős Problem 310 (unit sums with bounded denominators in dense sets)](dense-set-bounded-denominator-sum.md), the statement recorded as a proposition, in the affirmative; the resolution is due to Liu and Sawhney (2024), cited under Sources.
