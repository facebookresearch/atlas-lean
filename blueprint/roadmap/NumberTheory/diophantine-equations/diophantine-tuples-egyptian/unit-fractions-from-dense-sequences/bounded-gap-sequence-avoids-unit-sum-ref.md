# Every bounded-gap sequence has a unit sum

It is not the case that there is a strictly increasing sequence $a_0 < a_1 < \cdots$ of positive integers with bounded gaps ($a_{i+1} - a_i \le K$ for some $K$ and all $i$) such that no finite set $S$ of indices has $\sum_{i \in S} 1/a_i = 1$. Equivalently, every strictly increasing sequence of positive integers with bounded gaps has finitely many distinct terms whose reciprocals sum to $1$.
