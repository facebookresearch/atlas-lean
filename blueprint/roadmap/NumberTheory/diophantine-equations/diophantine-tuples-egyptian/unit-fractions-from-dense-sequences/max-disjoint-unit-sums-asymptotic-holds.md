# Number of disjoint unit sums in an initial segment

$k(N)/\log N \to 1$ as $N \to \infty$, where $k(N)$ is the largest $k$ for which there are $k$ pairwise disjoint subsets of $\{1, \dots, N\}$ each with reciprocal sum $1$.
