# Erdős Problem 298 (unit sums in sets of positive density)

The statement that every set $A$ of positive integers with positive upper density (some $\delta > 0$ has $|A \cap \{1, \dots, N\}| \ge \delta N$ for infinitely many $N$) contains a finite set $S$ with $\sum_{n \in S} 1/n = 1$.
