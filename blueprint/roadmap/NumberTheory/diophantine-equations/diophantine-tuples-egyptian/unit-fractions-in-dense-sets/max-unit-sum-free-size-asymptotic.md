# Erdős Problem 300 (largest unit-sum-free subsets)

The statement that $A(N)/N \to 1 - 1/e$ as $N \to \infty$, where for a natural number $N$, $A(N)$ is the largest size of a set $A \subseteq \{1, \dots, N\}$ such that no subset $S \subseteq A$ has $\sum_{n \in S} 1/n = 1$.
