# Erdős Problem 303 (monochromatic solutions of 1/a = 1/b + 1/c)

The statement that for every colouring of the positive integers with finitely many colours there are distinct positive integers $a, b, c$ of the same colour with $1/a = 1/b + 1/c$.

## Sources

- T. F. Bloom, Erdős Problems, Problem #303, https://www.erdosproblems.com/303.
