# Diophantine tuples

A finite set $s$ of natural numbers is a Diophantine tuple when every
element of $s$ is positive and, for all $a, b \in s$ with $a < b$, the number $ab + 1$ is a perfect
square.

## Sources

- Bo He, Alain Togbé, and Volker Ziegler, *There is no Diophantine quintuple*, Transactions of the American Mathematical Society 371 (2019), 6665–6709, https://doi.org/10.1090/tran/7573 (arXiv:1610.04020), whose abstract defines Diophantine $m$-tuples.
