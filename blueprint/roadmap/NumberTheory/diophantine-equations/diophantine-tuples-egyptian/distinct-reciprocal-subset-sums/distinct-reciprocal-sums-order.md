# Erdős Problem 321 (largest sets with distinct reciprocal subset sums)

The statement that there are reals $c, C > 0$ such that for all sufficiently large $N$ and every $k \ge 3$ with $\log_j N \ge 1$ for all $j \le k$ and $\log_k N \le e$,

$$c\, \frac{N}{\log N} \prod_{j=3}^{k} \log_j N \le R(N) \le C\, \frac{N}{\log N} \prod_{j=3}^{k} \log_j N,$$

where $\log_j$ is the $j$-fold iterated natural logarithm and $R(N)$ is the largest size of a set $A \subseteq \{1, \dots, N\}$ such that the sums $\sum_{n \in S} 1/n$ over the subsets $S \subseteq A$ are pairwise distinct.
