# Egyptian fractions for one with prescribed smallest denominator

The property holds when, for natural numbers $t$ and $N$, there is a finite set $S$ of natural numbers with $t \in S$, every element in $[t, N]$, and $\sum_{n \in S} 1/n = 1$ in the rationals, where $1/0$ is read as $0$. For $t \ge 1$ this says that $1 = 1/n_1 + \dots + 1/n_k$ has a solution with $t = n_1 < \dots < n_k \le N$. For $t = 0$ the convention matters: $S = \{0, 1\}$ witnesses the property at $N = 1$, though it is not an Egyptian fraction representation.
