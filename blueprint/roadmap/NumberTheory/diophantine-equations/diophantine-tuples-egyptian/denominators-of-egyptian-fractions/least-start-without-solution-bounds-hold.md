# Bounds for the least impossible smallest denominator

There is a real $K$ with $\dfrac{N}{(\log N)(\log\log N)^3 (\log\log\log N)^K} = O(t(N))$, and $t(N) = O(N/\log N)$, as $N \to \infty$, where for a natural number $N$, $t(N)$ is the least positive integer $t$ for which $1 = 1/n_1 + \dots + 1/n_k$ has no solution with $t = n_1 < \dots < n_k \le N$.

This resolves [Erdős Problem 294 (least start of an impossible Egyptian fraction)](least-start-without-solution-bounds.md), the statement recorded as a proposition, in the affirmative; the resolution is due to Liu and Sawhney (2024), cited under Sources.
