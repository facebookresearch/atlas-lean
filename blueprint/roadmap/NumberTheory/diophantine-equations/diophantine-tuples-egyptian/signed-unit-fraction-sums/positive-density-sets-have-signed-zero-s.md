# Erdős Problem 318, second question

The statement that every set of positive integers with positive natural density has property $P_1$, where a set $A$ of positive integers has property $P_1$ when for every non-constant $f : A \to \{-1, 1\}$ some finite nonempty $S \subseteq A$ has $\sum_{n \in S} f(n)/n = 0$.

This page records the statement as a proposition. Its refutation: [Some sets of positive density lack vanishing signed unit fraction sums](positive-density-sets-have-signed-zero-s-2.md).
