# Squares have vanishing signed unit fraction sums

The set of squares $k^2$ with $k \ge 2$ has property $P_1$, where a set $A$ of positive integers has property $P_1$ when for every non-constant $f : A \to \{-1, 1\}$ some finite nonempty $S \subseteq A$ has $\sum_{n \in S} f(n)/n = 0$.
