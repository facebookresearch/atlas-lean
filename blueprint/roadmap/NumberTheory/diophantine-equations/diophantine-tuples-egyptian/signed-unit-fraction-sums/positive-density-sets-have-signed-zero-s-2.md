# Some sets of positive density lack vanishing signed unit fraction sums

It is not the case that every set of positive integers with positive natural density has property $P_1$, where a set $A$ of positive integers has property $P_1$ when for every non-constant $f : A \to \{-1, 1\}$ some finite nonempty $S \subseteq A$ has $\sum_{n \in S} f(n)/n = 0$.
