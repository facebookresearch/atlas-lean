# Erdős Problem 318, first question

The statement that every infinite arithmetic progression $\{a + kd : k \in \mathbb{N}\}$ with $a, d \ge 1$ has property $P_1$, where a set $A$ of positive integers has property $P_1$ when for every non-constant $f : A \to \{-1, 1\}$ some finite nonempty $S \subseteq A$ has $\sum_{n \in S} f(n)/n = 0$.
