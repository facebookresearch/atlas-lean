# Arithmetic progressions have vanishing signed unit fraction sums

Every infinite arithmetic progression $\{a + kd : k \in \mathbb{N}\}$ with $a, d \ge 1$ has property $P_1$, where a set $A$ of positive integers has property $P_1$ when for every non-constant $f : A \to \{-1, 1\}$ some finite nonempty $S \subseteq A$ has $\sum_{n \in S} f(n)/n = 0$.

This resolves [Erdős Problem 318, first question](arithmetic-progressions-have-signed-zero.md), the statement recorded as a proposition, in the affirmative; the resolution is due to Sattler (1982), cited under Sources.
