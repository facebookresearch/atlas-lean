# Number of reflex angles of a closed polygon

For a closed polygon with vertices $v_0, \dots, v_{N-1}$ (and $v_{N} = v_0$, $v_{N+1} = v_1$ for the
periodic sequences used here), $\mu(P)$ is the number of indices $k < N$ at which the turn
$\operatorname{Im}\bigl(\overline{(v_{k+1} - v_k)}\,(v_{k+2} - v_{k+1})\bigr)$ has sign opposite to the
orientation $\sum_{i < N} \operatorname{Im}\bigl(\overline{v_i}\, v_{i+1}\bigr)$, strictly. For a
non-self-intersecting polygon these are exactly the vertices with interior angle greater than
$\pi$.
