# $2$ is an Amato parameter for the cathetus $4$

The number $2$ belongs to Amato's parameter
set $C(4)$ for the cathetus $4$.

With $x = 4$ and $d = 2$, the formulas $x^2 / (2d) \mp d / 2$ give $3$ and $5$, so $2$ generates
the triple $(4, 3, 5)$.
