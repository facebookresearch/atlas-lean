# Value of the Pell interpolation function u at 0

For all integers $D$, $\alpha$, $\beta$,
the function $u(x) = ((\alpha + \beta\sqrt D)^x + (\alpha - \beta\sqrt D)^x)/2$ of a real
variable $x$ satisfies $u(0) = 1$.
