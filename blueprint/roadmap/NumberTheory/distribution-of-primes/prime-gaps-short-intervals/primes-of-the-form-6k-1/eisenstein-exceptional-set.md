# Exceptional set for sums of distinct Eisenstein primes

The exceptional set $B = A \cup A\omega \cup \{1 + \omega, 2 + 2\omega, 2 + 4\omega, 4 + 2\omega\}$ with $A = \{1, 3, 4, 6, 8, 9, 10, 12, 14, 15, 20, 21, 26, 27, 32, 37, 38, 44, 50, 67, 79\}$, a finite subset of the additive set $E = \{a + b\omega : a, b \in \mathbb{N}\}$ with $\omega = e^{2\pi i/3}$, written as pairs $(a, b)$ for $a + b\omega$.

## Sources
