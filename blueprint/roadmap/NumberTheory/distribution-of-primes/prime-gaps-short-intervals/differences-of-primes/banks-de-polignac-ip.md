# Banks's theorem on de Polignac numbers in IP sets

Every IP set of even natural numbers contains infinitely many de Polignac numbers. Here a set $A$ of natural numbers is an IP set when there is an infinite set $M$ of positive integers such that $A$ is the set of sums of the nonempty finite subsets of $M$, and a natural number $m$ is a de Polignac number when $p_{n+1} - p_n = m$ for infinitely many $n$, where $p_0 = 2 < p_1 = 3 < \cdots$ are the primes.

- W. D. Banks, Consecutive primes and IP sets, arXiv:2403.10637 (2024), https://arxiv.org/abs/2403.10637.
