# The explicit 40-tuple has diameter 186

Let $h = (h_0, \dots, h_{39})$ be the explicit
$40$-tuple of integers $(0, 2, 6, \dots, 182, 186)$. The largest value in the set
$\{h_0, \dots, h_{39}\}$ minus the smallest value in it equals $186$.
