# Selberg sieve

Selberg's $\Lambda^2$ sieve bounds the number of elements of a finite set free of a given set of primes by replacing the indicator $\mathbf 1_{(n, P) = 1}$ with the square $(\sum_{d \mid (n, P)} \lambda_d)^2$, $\lambda_1 = 1$, and then optimising the quadratic form in the $\lambda_d$.
