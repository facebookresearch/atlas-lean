# Chebyshev's theta bounds the number of n-bit primes

For $n \ge 2$, $\vartheta(2^n) - \vartheta(2^{n-1}) \le P_n \cdot n\log 2$, where $\vartheta(x) = \sum_{p \le x}\log p$ is Chebyshev's function and $P_n$ is the number of $n$-bit primes, the primes $p$ with $2^{n-1} \le p < 2^n$.

## Sources

- J. Katz and Y. Lindell, Introduction to Modern Cryptography, 2nd ed., Section 8.2.1.
