# Explicit lower bound for the number of n-bit primes

For $n \ge 2$, with $y = 2^{n-1}$ and $A = \log\bigl(2^{1/2} 3^{1/3} 5^{1/5}/30^{1/30}\bigr)$, $\Bigl(2Ay - \tfrac{12}{5}A\sqrt{2y} - \tfrac{5}{8\log 6}(\log 2y)^2 - \tfrac{15}{4}\log 2y - 3\Bigr) - \Bigl(\tfrac65 Ay - A\sqrt y + \tfrac{5}{4\log 6}(\log y)^2 + \tfrac52\log y + 2\Bigr) < P_n \cdot n\log 2$, where $P_n$ is the number of primes $p$ with $2^{n-1} \le p < 2^n$.

## Sources

- J. Katz and Y. Lindell, Introduction to Modern Cryptography, 2nd ed., Section 8.2.1.
