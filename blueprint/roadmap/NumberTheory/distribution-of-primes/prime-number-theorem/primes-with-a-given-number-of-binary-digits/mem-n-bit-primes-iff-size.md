# n-bit primes have n binary digits

For natural numbers $n$ and $p$, $p$ is an $n$-bit prime if and only if $p$ is prime and its binary representation has exactly $n$ digits; here for a natural number $n$, the $n$-bit primes are the primes $p$ with $2^{n-1} \le p < 2^n$.

## Sources

- J. Katz and Y. Lindell, Introduction to Modern Cryptography, 2nd ed., Section 8.2.1.
