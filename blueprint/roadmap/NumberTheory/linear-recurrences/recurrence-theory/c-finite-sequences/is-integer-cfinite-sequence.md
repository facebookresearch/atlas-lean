# C-finite integer sequences

An integer sequence $s \colon \mathbb{N} \to \mathbb{Z}$ is
C-finite if there are $p, q \in \mathbb{N}$ and integers $c_0, \dots, c_{p-1}$ such that
$s(n + p) = \sum_{i=0}^{p-1} c_i \, s(n + i)$ for every $n \ge q$.
