# Delta-wye resistance function

For elements $x$, $y$, $z$ of a field $K$, the delta-wye
resistance function is $\Delta(x, y, z) = \frac{xy}{x + y + z}$.

Division follows the convention $a / 0 = 0$, so $\Delta(x, y, z) = 0$ when $x + y + z = 0$.
