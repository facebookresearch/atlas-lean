# Irregular recurrences when p divides the discriminant

Let $a, b$ be integers and $(w_n)_{n \ge 0}$ an integer sequence with $w_{n+2} = aw_{n+1} + bw_n$, and write $D = a^2 + 4b$. Let $p$ be an odd prime with $p \nmid b$, $p$ not dividing both $w_0$ and $w_1$, and $p \mid D$. Then $p \nmid a$; $w$ is not $p$-regular if and only if $w_1 \equiv (a/2)w_0 \pmod p$; and in that case $w_n \equiv (a/2)^n w_0 \pmod p$ for all $n$. Here $w$ is $p$-regular when $w_0 w_2 - w_1^2 \not\equiv 0 \pmod p$.
