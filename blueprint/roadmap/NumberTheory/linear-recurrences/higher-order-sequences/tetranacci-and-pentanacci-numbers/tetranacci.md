# Tetranacci sequence

The Tetranacci sequence $(T_n)_{n \ge 0}$ is defined by $T_0 = T_1 = T_2 = 0$, $T_3 = 1$ and
$T_{n+4} = T_{n+3} + T_{n+2} + T_{n+1} + T_n$ for every $n \ge 0$, so each term after the first
four is the sum of its four predecessors; it begins $0, 0, 0, 1, 1, 2, 4, 8, \dots$ (OEIS A000078).
