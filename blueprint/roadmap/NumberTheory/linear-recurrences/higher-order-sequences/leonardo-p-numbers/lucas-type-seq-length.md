# Length of a Lucas-type list

For every set $\alpha$ with elements $0$ and $1$ and a binary operation $+$,
every natural number $p$, all $a_0, c \in \alpha$ and every natural number $n$, the Lucas-type
list with parameters $p$, $a_0$, $c$ ending at index $n$ has exactly $n + 1$ entries.

## Sources

- Amine Belkhir and Elif Tan, *Combinatorial Insights into Leonardo $p$-Numbers and Lucas-Leonardo $p$-Numbers*, INTEGERS 25 (2025), Article A57, Section 1.
