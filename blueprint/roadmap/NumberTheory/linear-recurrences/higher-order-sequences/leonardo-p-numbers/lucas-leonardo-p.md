# Lucas-Leonardo $p$-numbers

For a natural number $p$, the Lucas-Leonardo $p$-numbers are
the integers $R_{p,n}$ given by $R_{p,0} = p^2 + p + 1$, $R_{p,i} = 1$ for $1 \le i \le p$, and
$R_{p,n} = R_{p,n-1} + R_{p,n-p-1} + p$ for $n > p$.
