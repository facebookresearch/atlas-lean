# Tribonacci sequence

The Tribonacci sequence $(T_n)_{n \ge 0}$ is defined by $T_0 = 0$,
$T_1 = 0$, $T_2 = 1$ and $T_{n+3} = T_{n+2} + T_{n+1} + T_n$ for $n \ge 0$; it begins
$0, 0, 1, 1, 2, 4, \dots$ (OEIS A000073).

## Sources
