# Forward step of a Fibonacci-type pair

For a pair $(x, y)$ of integers, the pair $(y, x + y)$: one step $(H_n, H_{n+1}) \mapsto (H_{n+1}, H_{n+2})$ along a sequence with $H_{n+2} = H_{n+1} + H_n$.
