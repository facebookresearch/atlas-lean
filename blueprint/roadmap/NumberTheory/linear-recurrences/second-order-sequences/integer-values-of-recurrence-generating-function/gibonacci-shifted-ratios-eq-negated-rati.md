# Ratios of a shifted Gibonacci sequence are negated reciprocal ratios

Let $a$ and $b$ be integers. Let $(H_n)_{n \in \mathbb{Z}}$ be the two-sided integer sequence with $H_0 = -b$, $H_1 = a$ and $H_{n+2} = H_{n+1} + H_n$, and let $(G_n)_{n \in \mathbb{Z}}$ be the two-sided Gibonacci sequence with $G_0 = a$, $G_1 = b$ and the same recurrence. Then the set of rational numbers $H_n / H_{n+1}$, over the integers $n$ with $H_{n+1} \ne 0$, equals the set of rational numbers $-G_{n+1} / G_n$, over the integers $n$ with $G_n \ne 0$.

## Sources

- Michael P. Knapp, *Fibonacci Generating Functions*, Journal of Integer Sequences 27 (2024), Article 24.3.1, Lemma 9.
