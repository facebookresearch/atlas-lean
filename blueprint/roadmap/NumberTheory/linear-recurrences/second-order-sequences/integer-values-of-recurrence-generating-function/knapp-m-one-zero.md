# Knapp's M at the pair (1, 0)

For all integers $a$ and $b$, $M(a, b, 1, 0) = a - b$, where $M(a, b, p, q) = \frac{(2p + q)((b - a)p + aq)}{q^2 - pq - p^2} - a + b$ (with division by zero giving $0$).

## Sources

- Knapp, Fibonacci generating functions, J. Integer Seq. 27 (2024), Article 24.3.1, Section 3.
