# Two-sided orbit of a Fibonacci-type pair

For a pair $v$ of integers, the set of consecutive pairs $(H_n, H_{n+1})$, $n \in \mathbb{Z}$, of the two-sided sequence with $H_{n+2} = H_{n+1} + H_n$ and $(H_0, H_1) = v$: the pairs obtained from $v$ by finitely many forward steps or finitely many backward steps.
