# Archimedean factor of an L-datum

For an L-datum and $s \in \mathbb{C}$, $\gamma(s) = \prod_{\mu \in \Gamma_\mathbb{R}} \Gamma_\mathbb{R}(s + \mu) \prod_{\mu \in \Gamma_\mathbb{C}} \Gamma_\mathbb{C}(s + \mu)$, where $\Gamma_\mathbb{R}(s) = \pi^{-s/2}\Gamma(s/2)$ and $\Gamma_\mathbb{C}(s) = 2(2\pi)^{-s}\Gamma(s)$.
