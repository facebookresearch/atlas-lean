# $9$ is not a $5$-Carmichael number

The number $9$ is not a $D$-Carmichael number for
$D = 5$. Indeed, the Jacobi symbol $(5 \mid 9)$ equals $1$, and the Fibonacci sequence
$U(1, -1)$ has $F_8 = 21$, which $9$ does not divide.
