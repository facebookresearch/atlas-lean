# $s$-Cullen numbers

For natural numbers $s$ and $n$, write $C_{n,s} = n s^n + 1$ for the
$s$-Cullen value. A natural number $m$ is an $s$-Cullen number when $s \ge 2$ and $m = C_{n,s}$
for some natural number $n \ge 1$.
