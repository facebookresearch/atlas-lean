# Sticky Cantor sets in dimensions at least four

The statement that for every $d \ge 4$ there is a sticky Cantor set in $\mathbb{R}^d$: a subset homeomorphic to the Cantor space $\{0,1\}^{\mathbb{N}}$ that is sticky. A subset $C \subseteq \mathbb{R}^d$ is sticky when there is $\varepsilon > 0$ such that for every ambient isotopy $(H_t)_{t \in [0,1]}$ of $\mathbb{R}^d$ (homeomorphisms $H_t$ of $\mathbb{R}^d$ depending jointly continuously on $(x,t)$, with $H_0 = \mathrm{id}$) that moves every point by less than $\varepsilon$ at every time, $H_1(C) \cap C \neq \emptyset$. The Open Problem Garden asks for which dimensions sticky Cantor sets exist; this statement covers $d \ge 4$ only.
