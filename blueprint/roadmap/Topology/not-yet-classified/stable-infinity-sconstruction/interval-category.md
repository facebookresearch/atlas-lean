# Interval Category

For a natural number $n$, let $[n] = \{0 < 1 < \dots < n\}$, viewed as a category with a morphism $i \to j$ exactly when $i \le j$. The interval category is its arrow category $\mathrm{Ar}[n]$. Its objects are the intervals $(i, j)$ with $i \le j$ in $[n]$, and there is a morphism $(i, j) \to (i', j')$, necessarily unique, exactly when $i \le i'$ and $j \le j'$.
