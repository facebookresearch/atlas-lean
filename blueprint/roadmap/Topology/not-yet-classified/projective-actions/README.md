# Projective Actions

For groups `H`, `G` and `φ : H →* G`, coinduction of an `H`-action `X`
uses the products of `X.V` indexed by `G` and by `H × G` and the equalizer
of the two equivariance maps; these products and equalizers must exist in
`C`. If `φ` is injective, the product-to-coinduction split reads coordinates
at chosen coset representatives and reconstructs all other coordinates by
the `H`-action. It does not preserve arbitrary input coordinates pointwise.
