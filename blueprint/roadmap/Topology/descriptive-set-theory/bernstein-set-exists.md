# Existence of a Bernstein set

There is a set $B \subseteq \mathbb{R}$ such that every closed,
uncountable set $F \subseteq \mathbb{R}$ meets both $B$ and its complement $\mathbb{R} \setminus B$.

## Sources

- F. Bernstein (construction); J. C. Oxtoby, Measure and Category, 2nd ed. (1980); A. S. Kechris, Classical Descriptive Set Theory, Thm 8.24 (1995). Proves `Wanted` entry `bernstein_set_exists`.
