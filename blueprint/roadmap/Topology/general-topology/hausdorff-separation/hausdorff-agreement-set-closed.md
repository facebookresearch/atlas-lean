# The set where two continuous maps into a Hausdorff space agree is closed

Let $X$ be a topological space, let $Y$ be a Hausdorff space and let $f, g\colon X \to Y$ be continuous maps. Then the set $\{x \in X : f(x) = g(x)\}$ is closed in $X$.
