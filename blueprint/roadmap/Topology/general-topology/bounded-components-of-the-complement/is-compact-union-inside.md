# A compact set together with its inside is compact

Let $F$ be a real normed vector space that is proper (closed bounded sets are compact), and let $K \subseteq F$ be compact. Write $\operatorname{ins} K$ for the inside of $K$, the set of points $x \notin K$ whose connected component in $F \setminus K$ is bounded. Then $K \cup \operatorname{ins} K$ is compact.

For a simple closed curve $K$ in $\mathbb{C}$ this is the curve together with the region it encloses.
