# The frontier of the inside of a closed set lies in the set

Let $X$ be a locally connected topological space with a bornology, and let $K \subseteq X$ be closed. Write $\operatorname{ins} K$ for the inside of $K$, the set of points $x \notin K$ whose connected component in $X \setminus K$ is bounded. Then the frontier of $\operatorname{ins} K$ is contained in $K$:

$$\partial(\operatorname{ins} K) \subseteq K.$$
