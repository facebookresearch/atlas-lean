# Path component of a point

Let $X$ be a topological space, and give the unit interval $I = [0, 1]$ the subspace topology from $\mathbb{R}$. Points $x, y \in X$ are *joined by a path* if there is a continuous map $\gamma\colon I \to X$ with $\gamma(0) = x$ and $\gamma(1) = y$. The *path component* of a point $x \in X$ is the set of all points $y \in X$ that are joined to $x$ by a path. Being joined by a path is an equivalence relation on $X$: a constant path joins $x$ to itself, $s \mapsto \gamma(1 - s)$ reverses a path, and two paths with a common endpoint can be concatenated. So the path components of the points of $X$ are the equivalence classes of this relation, and they partition $X$. Allowing paths parametrised by an arbitrary closed interval $[a, b]$ with $a < b$ gives the same relation, by the affine change of parameter $t \mapsto (t - a)/(b - a)$.
