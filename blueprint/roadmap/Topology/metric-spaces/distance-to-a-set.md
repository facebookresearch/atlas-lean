# The distance to a set is 1-Lipschitz

Let $(E,d)$ be a pseudo-metric space and $C\subseteq E$, and put $d(x,C)=\inf_{c\in C}d(x,c)$ (with $d(x,\emptyset)=0$). Then $x\mapsto d(x,C)$ is $1$-Lipschitz:

$$\lvert d(x,C)-d(y,C)\rvert\le d(x,y)\qquad\text{for all }x,y\in E,$$

and in particular continuous.
