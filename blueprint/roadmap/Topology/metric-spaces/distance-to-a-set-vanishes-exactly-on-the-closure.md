# The distance to a nonempty set vanishes exactly on its closure

Let $(E,d)$ be a pseudo-metric space, $C\subseteq E$ nonempty and $x\in E$, and put $d(x,C)=\inf_{c\in C}d(x,c)$. Then

$$x\in\overline C\iff d(x,C)=0 .$$

In particular, for a closed nonempty set $C$ the function $d(\cdot,C)$ vanishes exactly on $C$.

- W. Rudin, *Principles of Mathematical Analysis*, 3rd ed., McGraw-Hill, 1976, Chapter 4, Exercise 20.
