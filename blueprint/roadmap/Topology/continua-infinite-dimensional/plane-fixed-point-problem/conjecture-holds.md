# Path-connected nonseparating plane continua have the fixed point property

Let $K$ be a
nonempty, compact, path-connected subset of the Euclidean plane $\mathbb{R}^2$ whose complement
$\mathbb{R}^2 \setminus K$ is connected. Then $K$ has the fixed point property: every continuous
map $f \colon K \to K$ has a point $x \in K$ with $f(x) = x$.

This settles the path-connected case of the plane fixed point problem, the nonseparating planar
continuum conjecture in the form stated here: Hagopian (A fixed-point theorem for plane continua,
Bull. AMS 77 (1971), 351-354; addendum 1972) proved that every arcwise connected nonseparating
plane continuum has the fixed point property, and compact path-connected subsets of the plane are
arcwise connected. It does not settle the plane fixed point problem itself, which asks whether
every nonseparating plane continuum has the fixed point property.
