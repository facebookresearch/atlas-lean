# Compact space

A topological space $X$ is compact when every cover of $X$ by open sets has a finite subcover, and a subset $Y \subseteq X$ is compact when $Y$ with the subspace topology is a compact space. Mathlib defines compactness through filters: a set $s \subseteq X$ is compact when every nontrivial filter on $X$ that contains $s$ has a cluster point in $s$, a point every neighborhood of which meets every set of the filter, and the space $X$ is compact, a property recorded as a class, when the whole set $X$ is compact; no Hausdorff, metric or other separation condition is included. Mathlib proves that a set $s$ is compact exactly when every family of open sets whose union contains $s$, indexed by a type in the same universe as $X$, has a finite subfamily whose union contains $s$, which covers every collection of open sets since a collection can index itself. It also proves that the space $X$ is compact exactly when the whole set $X$ is compact, and that a subset is compact exactly when it is a compact space in the subspace topology.
