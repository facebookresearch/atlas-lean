# A semisimplicial homotopy induces an alternating-face chain homotopy

For a semisimplicial homotopy H between f, g : X ⟶ Y in a preadditive category C, the family
s_n = −∑ k : Fin (n + 1), (−1)^k • H.h k defines a chain homotopy between the alternating-face
chain maps of f and g. In degree n + 1 it satisfies f_(n+1) = d_X(n+1,n) ≫ s_n + s_(n+1) ≫
d_Y(n+2,n+1) + g_(n+1); in degree zero it satisfies f₀ = s₀ ≫ d_Y(1,0) + g₀.
