# The chain-homotopy components are negative alternating sums

For a semisimplicial homotopy H between f, g : X ⟶ Y in a preadditive category C, define hom H
p q : X_p ⟶ Y_q to be zero unless p + 1 = q. In that adjacent case it is −∑ k : Fin (p + 1),
(−1 : ℤ)^k • H.h k, followed by the object-equality transport from Y_(p+1) to Y_q.
