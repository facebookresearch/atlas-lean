# Face-compatible maps define a semisimplicial morphism

Let X and Y be semisimplicial objects in a category C and let a_n : X_n ⟶ Y_n be maps for all
n : ℕ. If X.δ i ≫ a_n = a_(n+1) ≫ Y.δ i for every n and i : Fin (n + 2), these maps define a
natural transformation X ⟶ Y with degree-n component a_n.
