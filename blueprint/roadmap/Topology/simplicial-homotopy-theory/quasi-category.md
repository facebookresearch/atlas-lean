# Quasi-categories and inner horn fillers

A simplicial set $S$ is a *quasi-category* if it has the following property for all integers $n \ge 2$ and $0 < i < n$. Every map of simplicial sets $\sigma_0\colon \Lambda^n_i \to S$ from the inner horn $\Lambda^n_i \subseteq \Delta^n$ extends to a map $\sigma\colon \Delta^n \to S$, meaning that $\sigma_0$ is the composite of the inclusion $\Lambda^n_i \hookrightarrow \Delta^n$ with $\sigma$. The extension is not required to be unique.
