# Embedding of contained ambient cells into the subcomplex cells

For a subcomplex `A` of a simplicial set `X`, `ambientCellsEmbedding A : AmbientCells A ↪ A.N`
sends a contained nondegenerate ambient cell to the same simplex and dimension in `A`.
Equality in `A.N` implies equality of the ambient cells, so this map is injective.
