# Ordered topological spaces

Order topologies and order-closed topologies on ordered sets: the intermediate value theorem, compactness of intervals, monotone functions and their one-sided limits, liminf and limsup, local extrema, semicontinuity, the extended real line, upper, lower, Scott and Lawson topologies, topological lattices, and Priestley and Esakia spaces.
