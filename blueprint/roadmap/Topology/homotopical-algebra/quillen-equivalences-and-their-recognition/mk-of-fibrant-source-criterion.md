# Recognizing Quillen equivalences on bifibrant sources

Let $L \dashv R$ be a Quillen adjunction between model categories $C$ and $D$, with $L : C \to D$. Suppose that for every object $X$ of $C$ that is both cofibrant and fibrant, every fibrant object $Y$ of $D$ and every morphism $f : L(X) \to Y$, $f$ is a weak equivalence if and only if its adjunct $\tilde f : X \to R(Y)$ is a weak equivalence. Then $L \dashv R$ is a [Quillen equivalence](is-quillen-equivalence.md): the same equivalence holds for every cofibrant $X$.
