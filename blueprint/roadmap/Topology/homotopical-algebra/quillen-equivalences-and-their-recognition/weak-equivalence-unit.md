# The unit of a Quillen equivalence at a cofibrant object

Let $L \dashv R$ be a [Quillen equivalence](is-quillen-equivalence.md) between model categories $C$ and $D$, with $L : C \to D$ and unit $\eta$. If $X$ is a cofibrant object of $C$ and $L(X)$ is fibrant in $D$, then $\eta_X : X \to R(L(X))$ is a weak equivalence.
