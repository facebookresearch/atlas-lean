# Every cofibration has a cofiber

Let $C$ be a category with a zero object and a [Waldhausen structure without gluing](waldhausen-category-without-gluing.md). For every cofibration $f : X \to Y$ there are an object $Z$ and a morphism $g : Y \to Z$ such that $f$ and $g$ form a [cofibration sequence](is-cofibration-sequence.md).
