# Waldhausen categories without the gluing axiom

Let $C$ be a category with a zero object $0$. A Waldhausen structure without gluing on $C$ consists of two classes of morphisms, the cofibrations and the weak equivalences, such that:

- each class contains every identity and is closed under composition;
- each class is closed under composition with isomorphisms on either side;
- every morphism $0 \to X$ out of the zero object is a cofibration;
- for every cofibration $i : X \to Y$ and every morphism $f : X \to X'$ there is a pushout square of $f$ and $i$ whose leg $X' \to P$, opposite $i$, is again a cofibration.

Pushouts are required only along cofibrations. The gluing axiom is not required: it would say that a morphism between two spans along cofibrations that is a weak equivalence at each of the three objects induces a weak equivalence of their pushouts. No two-out-of-three, saturation, factorization or cylinder axiom is imposed either.
