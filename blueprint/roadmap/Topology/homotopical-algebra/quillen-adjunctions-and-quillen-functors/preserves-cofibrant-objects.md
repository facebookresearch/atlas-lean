# Functors preserving cofibrant objects

Let $C$ and $D$ be categories with initial objects, each with a class of cofibrations; an object $X$ is cofibrant when the unique morphism $\bot \to X$ from the chosen initial object $\bot$ is a cofibration. A functor $F : C \to D$ preserves cofibrant objects when $F(X)$ is cofibrant for every cofibrant object $X$ of $C$. The functor is not required to preserve initial objects.
