# Functors preserving fibrant objects

Let $C$ and $D$ be categories with terminal objects, each with a class of fibrations; an object $X$ is fibrant when the unique morphism $X \to \top$ to the chosen terminal object $\top$ is a fibration. A functor $F : C \to D$ preserves fibrant objects when $F(X)$ is fibrant for every fibrant object $X$ of $C$. The functor is not required to preserve terminal objects.
