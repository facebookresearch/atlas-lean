# n-connected pair of spaces

Let $n \ge 0$ be an integer, $X$ a topological space and $A \subseteq X$ a subspace. The pair $(X, A)$ is *$n$-connected* if both of the following hold:

- every path component of $X$ contains a point of $A$;
- for every $x_0 \in A$ and every $1 \le i \le n$, the relative homotopy set $\pi_i(X, A, x_0)$ (a group when $i \ge 2$) consists only of its distinguished element $0$.

For $n = 0$ only the first condition remains: it says that the map $\pi_0(A) \to \pi_0(X)$ induced by the inclusion is surjective.
