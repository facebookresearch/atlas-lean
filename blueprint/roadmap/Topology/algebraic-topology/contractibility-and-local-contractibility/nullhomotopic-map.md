# Nullhomotopic map

Let $X$ and $Y$ be topological spaces. A continuous map $f\colon X \to Y$ is *nullhomotopic* if it is homotopic to a constant map: for some point $y_0 \in Y$ there is a homotopy from $f$ to the map $X \to Y$ that sends every point to $y_0$.

- Allen Hatcher, Algebraic Topology, Cambridge University Press, 2002.
