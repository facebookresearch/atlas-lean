# Reverse of a path

Let $X$ be a topological space, let $I = [0, 1]$, and let $f\colon I \to X$ be a path from $x$ to $y$. The *reverse*, or *inverse path*, of $f$ is the map $\bar{f}\colon I \to X$ given by $\bar{f}(s) = f(1 - s)$. It is the composite of $f$ with the continuous map $s \mapsto 1 - s$ of $I$, so it is a path from $y$ to $x$.
