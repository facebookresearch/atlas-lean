# Brouwer's theorem for the simplex, fixed-point form

Every continuous self-map $f$ of the standard simplex has a fixed point, that is, a point $x$ with $f(x) = x$. This is
[Brouwer's fixed-point theorem for the standard simplex](exists-fixed-point.md), phrased as the existence of a fixed
point of $f$.

## Informally uses

- [Brouwer's fixed-point theorem for the standard simplex](exists-fixed-point.md): the same statement, written as $f(x) = x$.
