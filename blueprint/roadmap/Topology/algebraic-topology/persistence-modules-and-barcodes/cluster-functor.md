# The cluster functor (zero-dimensional persistence)

For a dissimilarity $d \colon X \times X \to \mathbb{R}$, the cluster functor goes from
$(\mathbb{R}, \le)$ to the category of sets: it sends $r$ to the set $X/{\sim_r}$ of single-linkage
clusters at scale $r$, and $r \le s$ to the map sending each $r$-cluster to the $s$-cluster
containing it. It is an $\mathbb{R}$-persistence object in the category of sets (Carlsson, *Topology
and data*, Bull. AMS 2009, Def. 2.9 and §3.2, where single-linkage clusters are $\pi_0$ of the
Vietoris–Rips complex).
