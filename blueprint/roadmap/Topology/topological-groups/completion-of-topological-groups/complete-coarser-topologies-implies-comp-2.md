# Abelian groups complete in every coarser group topology are compact

A Hausdorff abelian topological group $(G, \tau)$ is compact if $G$ is complete, for the uniformity of the group, in every Hausdorff group topology $\tau' \subseteq \tau$; Kourovka Problem 16.42 has a positive answer. Banakh proves the equivalence: an abelian topological group is compact if and only if it is complete in each weaker Hausdorff group topology.
