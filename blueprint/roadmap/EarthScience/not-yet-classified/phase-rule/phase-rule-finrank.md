# Gibbs phase rule as a rank-nullity count

For natural numbers $C \ge 1$ and $P \ge 1$ with $P \le C + 2$, and any surjective real linear map $f : \mathbb{R}^{P(C-1)+2} \to \mathbb{R}^{C(P-1)}$, the kernel of $f$ has dimension $C + 2 - P$. Here $f$ is an arbitrary surjective linear map; it is not identified with the linearized chemical-potential equalities at an equilibrium.
