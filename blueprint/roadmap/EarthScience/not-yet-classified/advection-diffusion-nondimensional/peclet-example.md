# Péclet number example

With $L = 2$, $U = 3$ and $D = 1$, the Péclet number is $\mathrm{Pe} = UL/D = 6$, and the scaled derivative values $\hat c_{\hat t} = 1$, $\hat c_{\hat x} = 2$, $\hat c_{\hat x \hat x} = 18$ satisfy the nondimensional advection-diffusion equation $\hat c_{\hat t} + \hat c_{\hat x} = \mathrm{Pe}^{-1} \hat c_{\hat x \hat x}$, that is, $1 + 2 = \tfrac{1}{6} \cdot 18$.
