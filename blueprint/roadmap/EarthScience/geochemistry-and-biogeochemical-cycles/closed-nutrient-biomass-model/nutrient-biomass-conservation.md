# The closed nutrient–biomass total has zero derivative

Closed nutrient–biomass model (the model of Franks (2002) without zooplankton), with one
nutrient-equivalent unit for both compartments: for any uptake rate function `u` and any real
loss rate `r`, if at time `t` the nutrient `N` and the biomass `B` have derivatives
`-u(N t) * B t + r * B t` and `u(N t) * B t - r * B t`, then the total `N + B` has derivative
`0` at `t`.
