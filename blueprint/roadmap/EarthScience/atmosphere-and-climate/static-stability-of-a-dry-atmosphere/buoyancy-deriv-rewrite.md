# Buoyancy law rewritten with the squared buoyancy frequency

For `θ0 ≠ 0`: if `v` is differentiable at `t` with `v'(t) = g (θ0 - (θ0 + a ζ(t))) / θ0`, then
`v'(t) = -(g a / θ0) ζ(t)`. This only rewrites the derivative value; it does not relate `v` to
the derivative of `ζ`, so it is not an oscillator equation, which needs in addition `ζ' = v`.
