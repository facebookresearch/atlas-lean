# The Clausius–Clapeyron derivative is positive

For `es0 > 0`, `L > 0`, `Rv > 0`, every real `T0` and every temperature `T > 0`, the
derivative of the saturation vapour pressure `es(T) = es0 exp((L / Rv) (1 / T0 - 1 / T))` is
positive: `es(T) L / (Rv T²) > 0`. For `T0 = 0`, `1 / T0 = 0` by the convention `x / 0 = 0`, so that
`es(T) = es0 exp(-L / (Rv T))`.

In the physical reading, `T0 > 0` is a reference absolute temperature, at which the saturation
vapour pressure is `es(T0) = es0`; the result holds more generally for every real `T0`.
