# Isothermal profile satisfies hydrostatic balance

For all real `p0`, `g`, `R`, `T` and every height `z`, the isothermal profile
`p(z) = p0 exp(-g z / (R T))` is differentiable at `z` with `p'(z) = -(p(z) / (R T)) g`, that
is `p' = -ρ g` with ideal-gas density `ρ = p / (R T)`. No sign condition is needed; with the
convention `x / 0 = 0`, when `R T = 0` the profile is the constant `p0` and both sides are `0`.
