# Hydrostatic isothermal atmosphere and its scale height

For `p0, g, R, T > 0`, the isothermal ideal-gas profile `p(z) = p0 exp(-g z / (R T))`
satisfies the hydrostatic relation `p'(z) = -(p(z) / (R T)) g` at every height `z` (density
`ρ = p / (R T)`), has `p(0) = p0`, is positive at every height, is strictly decreasing in `z`,
and takes the value `p0 / e` at one scale height `z = R T / g`.
