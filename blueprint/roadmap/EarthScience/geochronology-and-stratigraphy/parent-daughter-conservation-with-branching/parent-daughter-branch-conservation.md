# Branch-weighted parent–daughter conservation as an identity

For every real `λ`, `P0`, `D0` and `t` and every branch fraction `f ≠ 0`, the parent
`P(t) = P0 * exp (-λ * t)` and the daughter `D(t) = D0 + f * (P0 - P(t))` satisfy
`P(t) + D(t) / f = P0 + D0 / f`. This describes a closed parent/daughter decay system only on the
physical domain `λ > 0`, `P0 ≥ 0`, `D0 ≥ 0`, `0 < f ≤ 1`, `t ≥ 0`.
