# A closed parent–daughter system conserves its branch-weighted total

A closed single-step parent/daughter system conserves nuclei after accounting for the branch
fraction: for a decay constant `λ > 0`, initial parent and daughter inventories `P0 ≥ 0` and
`D0 ≥ 0`, a branch fraction `0 < f ≤ 1` and an elapsed time `t ≥ 0`, the parent
`P(t) = P0 * exp (-λ * t)` and the daughter `D(t) = D0 + f * (P0 - P(t))` satisfy
`P(t) + D(t) / f = P0 + D0 / f`. The identity itself holds for every real `λ`, `P0`, `D0`, `t`
and every `f ≠ 0`; the other conditions state the physical domain.
