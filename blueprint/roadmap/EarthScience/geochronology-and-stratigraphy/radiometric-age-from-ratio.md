# Radiometric age from the daughter–parent ratio

Age inversion recovers time from the daughter/parent ratio: for a decay constant `λ > 0`, an
initial parent `P0 > 0` and an age `t ≥ 0`, in a closed single-step system with no initial
daughter, parent `P(t) = P0 * exp (-λ * t)` and daughter `D(t) = P0 - P(t)`, the age recovered
from the daughter/parent ratio, `log (1 + D(t) / P(t)) / λ`, equals `t`. The ratio is
nonnegative (zero at `t = 0`), and the logarithm's argument `1 + D(t) / P(t) = exp (λ * t)` is
positive.
