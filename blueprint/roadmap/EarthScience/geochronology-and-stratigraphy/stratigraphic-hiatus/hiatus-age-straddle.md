# Age difference across a hiatus

For depths `d₁ < h ≤ d₂` on either side of a hiatus at depth `h` with gap `g`, the age difference
is the constant-accumulation difference offset by the gap: `(d₂ - d₁) / v + g`. This holds for
all real `v` and `g`; with the convention `x / 0 = 0` the difference is `g` when `v = 0`. The
intended domain is `v > 0`.
