# The dipole component ratio is twice the tangent of latitude

For a dipole moment factor `C ≠ 0` of either sign, a distance `r > 0` and a colatitude `θ` off the
axis, `sin θ ≠ 0`, the components `B_r = 2 * C * cos θ / r ^ 3` and `B_θ = C * sin θ / r ^ 3` have
the signed ratio `B_r / B_θ = 2 * tan λ`, where `λ = π / 2 - θ` is the magnetic latitude. When
`B_θ < 0`, that is for `C < 0` and `0 < θ < π`, this ratio is `tan I`; off the equator it is `tan I`
only then, and at the equator both are `0`.
