# Zero thickness gives zero phase retardation

For all real indices `n₁` and `n₂` and every vacuum wavelength `λ`, a slab of thickness `h = 0`
has phase retardation `δ = (2 * π / λ) * (n₁ - n₂) * 0 = 0`. At `λ = 0` the factor `2 * π / λ`
is `0` by the convention `x / 0 = 0`; the physical domain is `λ > 0`.
