# Closed form of the phase retardation

For all real indices `n₁` and `n₂`, thickness `h` and vacuum wavelength `λ`, the phase
retardation `δ = (2 * π / λ) * (n₁ - n₂) * h` equals `2 * π * (n₁ - n₂) * h / λ`. With the
convention `x / 0 = 0` both sides are `0` when `λ = 0`; the physical domain is `h ≥ 0`, `λ > 0`.
