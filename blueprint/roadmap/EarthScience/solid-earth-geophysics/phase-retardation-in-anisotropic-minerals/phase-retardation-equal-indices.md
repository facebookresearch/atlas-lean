# Equal indices give zero phase retardation

When the two principal indices coincide, `n₁ = n₂ = n`, the phase retardation
`δ = (2 * π / λ) * (n - n) * h` is `0`, for every real `n`, thickness `h` and wavelength `λ`.
At `λ = 0` the factor `2 * π / λ` is `0` by the convention `x / 0 = 0`; the physical domain is
`h ≥ 0`, `λ > 0`.
