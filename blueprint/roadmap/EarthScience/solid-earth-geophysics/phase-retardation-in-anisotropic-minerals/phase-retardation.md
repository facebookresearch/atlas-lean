# Signed phase retardation of a two-mode slab

The signed phase retardation of mode 1 relative to mode 2 for a lossless two-mode slab with
refractive indices `n₁` and `n₂`: `δ = k₀ * (n₁ - n₂) * h`, where `k₀ = 2 * π / λ` is the vacuum
wavenumber, `λ` the vacuum wavelength and `h` the thickness, with `δ` in radians. It is the
physical retardation only for `h ≥ 0` and `λ > 0`, where `δ` is positive exactly when `h > 0` and
mode 1 is the slow mode (`n₁ > n₂`). It is defined for all real arguments, with the convention
`x / 0 = 0`: `δ = 0` when `λ = 0`, and a negative `h` or `λ` reverses the sign.
