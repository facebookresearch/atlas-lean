# Moment magnitude of an earthquake

The moment magnitude `Mw(M) = (2 / 3) * (log₁₀ M - c)` of a seismic moment `M`, with zero-point
`c` for one fixed moment unit and `log₁₀ M = log M / log 10`. It is defined for all real `c` and
`M`, with the conventions `log 0 = 0` and `log x = log |x|`: `Mw(0) = -(2 / 3) * c`, and
`Mw(M) = Mw(-M)` for `M < 0`. It is a magnitude only on the intended domain `M > 0`.
