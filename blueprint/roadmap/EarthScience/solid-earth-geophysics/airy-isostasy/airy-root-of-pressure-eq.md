# Equal compensation pressure forces the Airy root

Take a physical column: crust density `ρc > 0` below the mantle density `ρm > ρc`, relief `h ≥ 0`,
reference crust thickness `T ≥ 0`, and a root `r` whose base lies at or above the compensation
depth, `T + r ≤ D`. If the elevated column has the pressure of the reference column,
`ρc * (T + h + r) + ρm * (D - T - r) = ρc * T + ρm * (D - T)`, then `r = ρc * h / (ρm - ρc)`,
and the root and every layer of the elevated column have nonnegative thickness: `r ≥ 0`,
`T + h + r ≥ 0` and `D - T - r ≥ 0`.
