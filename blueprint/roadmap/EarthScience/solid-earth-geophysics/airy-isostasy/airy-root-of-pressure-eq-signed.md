# Equal column pressures force the Airy root in signed algebra

For a crust density `ρc > 0` and a mantle density `ρm > ρc`, and all real `h`, `T`, `D` and `r`,
including negative layer thicknesses that describe no physical column: if
`ρc * (T + h + r) + ρm * (D - T - r) = ρc * T + ρm * (D - T)`, then `r = ρc * h / (ρm - ρc)`.
