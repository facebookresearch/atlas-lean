# Airy root equalizes compensation pressure

Take a physical column: crust density `ρc > 0` below the mantle density `ρm > ρc`, relief `h ≥ 0`,
reference crust thickness `T ≥ 0`, the Airy root `r = ρc * h / (ρm - ρc)`, and a compensation
depth `D` at or below the base of the root, `T + r ≤ D`. Then every layer of the elevated column
has nonnegative thickness (root `r`, crust `T + h + r`, mantle `D - T - r`), and its pressure
equals that of the reference column:
`ρc * (T + h + r) + ρm * (D - T - r) = ρc * T + ρm * (D - T)`.
