# Distinct positive slowness models with the same single-row travel time

For every rational `t ≠ 0` with `-1/2 < t < 1/4`, the perturbed model
`(1/2, 1/4) + t (1, -1) = (1/2 + t, 1/4 - t)` has positive slowness in both cells, differs from
`s = (1/2, 1/4)`, and gives the same travel time as `s` on the single retained row `(1, 1)`.
