# Equal travel times exactly when the perturbation is in the null space

Let `A` be a real matrix of ray lengths, with a row for each ray and a column for each of finitely
many slowness cells, so that a slowness model `s` gives the travel times
`(A s)_i = ∑_j A_ij s_j`. For every model `s` and perturbation `v`, the models `s` and `s + v` give
the same travel times if and only if `A v = 0`: a perturbation in the null space of `A` is
invisible to the data.
