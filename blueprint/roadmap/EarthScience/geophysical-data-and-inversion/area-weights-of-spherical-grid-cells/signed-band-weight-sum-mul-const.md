# Signed band weights integrate a constant C to C times 4πR²

Let `φ_0, …, φ_n` be real numbers with `φ_0 = -π/2` and `φ_n = π/2`, in any order, let `m ≠ 0`
be a number of longitude cells and let `R` and `C` be real. Then
`∑_{i < n} ∑_{j < m} R² (sin φ_{i+1} - sin φ_i) (2π / m) C = C * 4π R²`: the
[signed band weights](signed-band-weight-sum.md) integrate the constant `C` to `C` times the area
`4π R²` of the sphere.
