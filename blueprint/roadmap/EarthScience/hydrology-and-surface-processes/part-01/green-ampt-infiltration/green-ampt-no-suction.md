# Green–Ampt infiltration without suction head is constant-rate

Let `K > 0` and `t₀ ≤ t`. If `F : ℝ → ℝ` satisfies `F(t₀) = F₀` and the Green–Ampt equation with
no suction head, `F'(s) = K * (1 + 0 / F(s))`, at every `s ∈ [t₀, t]`, then
`t - t₀ = (F(t) - F₀) / K`. The rate `K * (1 + 0 / F(s))` is the constant `K` whatever the value of
`F(s)`, since `0 / x = 0` also for `x = 0`; so no positivity of `F` or `F₀` is assumed, and the dry
start `F(t₀) = F₀ = 0` is covered.
