# Deviatoric stress invariant q

For a real `3 × 3` stress matrix `σ`, with deviatoric part `s = σ - (tr σ / 3) I`, the deviatoric
invariant in Frobenius form is `q = √(3/2 * tr (sᵀ s))`; the radicand is a sum of squares, so it is
never negative. For a symmetric (Cauchy) stress
[it is `√(3 J₂)`](deviatoric-invariant-eq-sqrt-neg-stress.md); for a nonsymmetric matrix it is the
Frobenius extension, not `√(3 J₂)`.
