# Rankine earth pressure

Rankine's active earth pressure: the coefficient $K_a = (1 - \sin \varphi) / (1 + \sin \varphi)$
and the Mohr–Coulomb limit condition, which, for principal stresses $0 \le \sigma_3 \le \sigma_1$, a
cohesion $c \ge 0$ and a friction angle $0 \le \varphi < \pi / 2$, holds exactly when
$\sigma_3 = K_a \sigma_1 - 2 c \sqrt{K_a}$.
