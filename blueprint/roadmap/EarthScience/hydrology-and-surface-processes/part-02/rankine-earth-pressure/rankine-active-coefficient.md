# Rankine active earth-pressure coefficient

For a real number $\varphi$, let

$$K_a(\varphi) = \frac{1 - \sin \varphi}{1 + \sin \varphi} ,$$

read as $0$ when $\sin \varphi = -1$. For a friction angle $0 \le \varphi < \pi / 2$ it is the
Rankine active earth-pressure coefficient, and then
[$0 < K_a(\varphi) \le 1$](rankine-active-coefficient-pos-le-one.md).
