# The Mohr–Coulomb limit condition gives the Rankine active pressure

Let $\sigma_1$ and $\sigma_3$ be principal stresses (compression positive) with
$0 \le \sigma_3 \le \sigma_1$, let $c \ge 0$ be the cohesion and let $\varphi$ be a friction angle
with $0 \le \varphi < \pi / 2$. Then the limit condition

$$\frac{\sigma_1 - \sigma_3}{2} = \frac{\sigma_1 + \sigma_3}{2} \sin \varphi + c \cos \varphi$$

holds if and only if $\sigma_3 = K_a \sigma_1 - 2 c \sqrt{K_a}$, where
$K_a = (1 - \sin \varphi) / (1 + \sin \varphi)$ is the Rankine active coefficient.
