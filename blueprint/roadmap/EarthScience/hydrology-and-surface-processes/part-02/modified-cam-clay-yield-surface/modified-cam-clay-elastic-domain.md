# Elastic domain of the modified Cam-Clay model

For real `M` and `pc`, the closed modified Cam-Clay elastic domain is the set of points `(p, q)`
of the plane with `F(p, q) ≤ 0`, where `F(p, q) = q ^ 2 + M ^ 2 * p * (p - pc)`. For `M = 0` it is
the whole line `q = 0`, and for `pc = 0`, `M ≠ 0` it is the single point `(0, 0)`.
