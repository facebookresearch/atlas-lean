# Existence and uniqueness for the nonsingular finite Biot rate system

For finite index sets, let `K` be invertible with inverse `Kinv` (`K Kinv = Kinv K = I`) and let
the reduced storage matrix `S = Qᵀ Kinv Q + C` be symmetric positive definite; `H`, the constant
load rate `df` and the constant source `s` are arbitrary. Then for all initial values `u0` and
`p0` there are differentiable paths `u`, `p` with `u(0) = u0` and `p(0) = p0` satisfying, at every
time, the rate system `K u' + Q p' = df` and `-Qᵀ u' + C p' = s - H p`; and any other
differentiable solution with the same initial values equals `(u, p)`.
