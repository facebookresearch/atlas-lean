# The depth-averaged excess pore pressure of the consolidation mode

For real numbers $u_0$, $c_v$, $t$ and $H \neq 0$, the drained consolidation mode
$u(z, t) = u_0 e^{-c_v (\pi / H)^2 t} \sin(\pi z / H)$ has depth average

$$\frac{1}{H} \int_0^H u(z, t)\, dz = \frac{2 u_0}{\pi}\, e^{-c_v (\pi / H)^2 t} .$$
