# Submerged unit weight of a saturated soil

For a fully saturated soil with specific gravity of solids `Gs`, void ratio `e` and water unit
weight `γw`, the submerged unit weight is `γ_sub = (Gs - 1) * γw / (1 + e)`. It is defined for all
real arguments: with the convention `x / 0 = 0` it is `0` when `e = -1`. The intended domain is
`Gs > 0`, `e ≥ 0` and `γw > 0`.
