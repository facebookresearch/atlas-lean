# Hyperbolic cumulative production starts at zero

For all real `qi`, `Di` and `b`, the hyperbolic cumulative production
`Np(t) = qi * (1 - (1 + b * Di * t) ^ ((b - 1) / b)) / ((1 - b) * Di)` vanishes at `t = 0`:
`Np(0) = 0`. For `b = 1` or `Di = 0`, where the denominator vanishes, this is `qi * 0 / 0 = 0` by
the convention `x / 0 = 0`.
