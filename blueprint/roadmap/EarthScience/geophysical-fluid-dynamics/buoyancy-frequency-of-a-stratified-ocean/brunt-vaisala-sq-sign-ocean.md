# Sign of the squared buoyancy frequency in a stratified fluid

For `g > 0`, `ρ0 > 0` and every real `β`, the squared Brunt–Väisälä frequency `N² = g β / ρ0` is
zero if and only if `β = 0` (uniform density), positive if and only if `β > 0` (stable) and negative
if and only if `β < 0` (unstable). Read with `β` the vertical potential-temperature gradient and
`ρ0` the reference potential temperature, the same rule is the static-stability criterion of a dry
atmosphere.
