# Vertically integrated Ekman transport

For a density `ρ₀`, a Coriolis parameter `f` and a wind stress `τ = (τ₀, τ₁, τ₂)`, the
vertically integrated Ekman transport is `M = (τ₁ / (ρ₀ f), -τ₀ / (ρ₀ f), 0)`; the vertical
stress component `τ₂` is not used. It is defined for all real `ρ₀` and `f`; with the
convention `x / 0 = 0`, it is `0` when `ρ₀ f = 0` (for instance at the equator, `f = 0`). The
intended domain is `ρ₀ > 0` and `f ≠ 0`.
