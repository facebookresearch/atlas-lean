# Plane Rossby mode solves the beta-plane vorticity equation

For `k² + l² ≠ 0` and all real `A` and `β`, the mode `ψ(t, x, y) = A cos(k x + l y - ω t)`
with the dispersion relation `ω = -β k / (k² + l²)` satisfies the linearized β-plane vorticity
equation about a state of rest, `∂ₜ(∂ₓ²ψ + ∂ᵧ²ψ) + β ∂ₓψ = 0`, at every `(t, x, y)`.
