# At nonpositive depth the Riemann-invariant transport can fail

For `g > 0`, every point `(t, x)` and every depth value `d ≤ 0`, there are fields `h` and `u`
with `h(t, x) = d`, whose time and space slices are differentiable at `(t, x)` and which
satisfy both primitive equations there, but for which both paired transport equations fail at
`(t, x)`: `(∂ₜ + (u + c) ∂ₓ)(u + 2 c) ≠ 0` and `(∂ₜ + (u - c) ∂ₓ)(u - 2 c) ≠ 0`, with
`c = √(g h)`. Here `√y = 0` for `y ≤ 0`, and a derivative is taken to be `0` where a slice is
not differentiable. So the transport of the Riemann invariants needs positive depth: `h ≥ 0`
is not enough.
