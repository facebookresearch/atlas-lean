# Theorem 4

**Theorem 4** (Landau, via Moon): a nondecreasing
sequence `s_1 ≤ ⋯ ≤ s_n` is the score sequence of a
tournament if and only if `∑_{i=1}^k s_i ≥ C(k, 2)` for
`1 ≤ k ≤ n`, with equality when `k = n`.
