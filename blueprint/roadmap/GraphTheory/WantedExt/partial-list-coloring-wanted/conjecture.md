# Conjecture

Iradmusa's conjecture: for a graph with choice number `χ_ℓ` (via the
shared `SimpleGraph.IsChoiceNumber` predicate) and `1 ≤ r ≤ s ≤ χ_ℓ`, one
has `λ_r / r ≥ λ_s / s`.
