# Extremal number for one forbidden graph

For a natural number $n$ and a simple graph $H$, write $\operatorname{ex}(n;H)$ for the maximum number of edges of a simple graph $G$ on $n$ vertices with no subgraph isomorphic to $H$. The forbidden copy need not be induced. The maximum over an empty set of admissible hosts is zero. The vertex type of $H$ is arbitrary in this definition; the host can be labeled by $\{0,\ldots,n-1\}$ without changing the value.

This is the extremal number for one forbidden graph, not the extremal number for a family of forbidden graphs.
