# Erdős Problem 715, second question

The statement that for every natural number $r \ge 4$, every $r$-regular simple graph on a finite nonempty vertex set contains a $3$-regular subgraph: a subgraph, not necessarily spanning or induced, with a nonempty vertex set in which every vertex has exactly $3$ neighbours in the subgraph.
