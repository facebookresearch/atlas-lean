# Erdős Problem 715, first question (Berge)

The statement that every $4$-regular simple graph on a finite nonempty vertex set contains a $3$-regular subgraph: a subgraph, not necessarily spanning or induced, with a nonempty vertex set in which every vertex has exactly $3$ neighbours in the subgraph. Stated here as a proposition; its resolution: [Every 4-regular graph contains a 3-regular subgraph](four-regular-contains-cubic-subgraph-hol.md).
