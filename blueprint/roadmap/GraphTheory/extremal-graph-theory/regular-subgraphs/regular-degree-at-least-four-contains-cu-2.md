# Every r-regular graph with r at least 4 contains a 3-regular subgraph

For every natural number $r \ge 4$, every $r$-regular simple graph on a finite nonempty vertex set contains a $3$-regular subgraph: a subgraph, not necessarily spanning or induced, with a nonempty vertex set in which every vertex has exactly $3$ neighbours in the subgraph. That is, the proposition [A stronger form of Erdős Problem 715, second question](regular-degree-at-least-four-contains-cu.md) holds; this answers the second question of Problem 715, which asks only for some such $r$, in a stronger form.
