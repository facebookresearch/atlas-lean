# Common graph

A simple graph $H$ on $\{0, \dots, k-1\}$ with $e(H)$ edges is common when $2^{1 - e(H)} \le t(H, W) + t(H, 1 - W)$ for every graphon $W$, where $t$ is the [homomorphism density](../../random-graphs/graph-limits/graphon-hom-density.md) and a [graphon](../../random-graphs/finitely-forcible-graphons/is-graphon.md) is a measurable symmetric function $W : \mathbb{R}^2 \to [0, 1]$, of which only the values on $[0, 1]^2$ matter.
