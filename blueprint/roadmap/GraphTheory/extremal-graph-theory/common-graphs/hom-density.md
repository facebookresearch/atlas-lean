# Homomorphism density in a graphon

For a simple graph $H$ on $\{0, \dots, k-1\}$ and a function $W : \mathbb{R}^2 \to \mathbb{R}$, the homomorphism density is

$$t(H, W) = \int_{[0,1]^k} \prod_{uv} W(x_u, x_v)\, dx,$$

the product running over the edges $uv$ of $H$, each taken once as the pair $(u, v)$ with $u < v$.
