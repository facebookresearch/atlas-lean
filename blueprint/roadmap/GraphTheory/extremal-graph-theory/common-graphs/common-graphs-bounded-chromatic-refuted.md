# Common graphs have unbounded chromatic number

It is not the case that there is a natural number $C$ such that every common simple graph $H$ on $\{0, \dots, k-1\}$, for every $k$, has chromatic number at most $C$. Here $H$ with $e(H)$ edges is common when $2^{1 - e(H)} \le t(H, W) + t(H, 1 - W)$ for every graphon $W$, $t(H, W)$ being the homomorphism density of $H$ in $W$. Equivalently, for every natural number $C$ some common graph has chromatic number greater than $C$. That is, the proposition [Do common graphs have bounded chromatic number?](common-graphs-bounded-chromatic.md) is false.
