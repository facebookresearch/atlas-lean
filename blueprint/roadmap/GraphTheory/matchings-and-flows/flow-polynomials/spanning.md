# Spanning subgraph of a multigraph on an edge set

For a finite multigraph given by finite sets $V$ of vertices and $E$ of edges and an end map assigning to each edge an unordered pair of vertices (loops and parallel edges allowed) and a set $A$ of edges, the spanning subgraph on $A$ is the simple graph on $V$ in which distinct $u, v$ are adjacent exactly when some edge of $A$ has ends $\{u, v\}$ (loops and multiplicities dropped).
