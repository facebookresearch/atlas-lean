# The core of the marriage game equals the set of stable matchings

In the one-to-one two-sided matching game (with strict preferences, complete or incomplete lists, possibly unequal sides), a matching is in the core (no coalition of agents can match among themselves so that all members are strictly better off) if and only if it is stable; with strict preferences the same holds for the weak core (no coalition makes all members weakly and one strictly better off).

## Proof sketch

A blocking pair is a blocking coalition of size two; conversely any blocking coalition contains a member matched to another member it prefers, and that pair blocks.
