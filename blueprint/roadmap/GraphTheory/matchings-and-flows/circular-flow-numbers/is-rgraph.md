# $r$-graphs among loopless multigraphs

For a natural number $r$ and a loopless multigraph $M$ with vertex set $V$ and edge set $E$, each edge having an unordered pair of distinct ends and parallel edges allowed, $M$ is an $r$-graph when every vertex has degree $r$ and $|\partial(X)| \ge r$ for every finite set $X$ of vertices of odd size, $\partial(X)$ being the set of edges with exactly one end in $X$. Degrees and [cut sizes](cut-size.md) are natural-number cardinalities, taken as $0$ when infinite: with two vertices joined by infinitely many parallel edges the condition holds at $r = 0$, although neither vertex lies on exactly zero edges.
