# Coalitional incentive axioms for housing mechanisms

A **housing mechanism** maps each profile of reported strict preferences to an allocation. It is **non-bossy** if whenever an agent's report change leaves its own house unchanged, the whole allocation is unchanged. It is **group strategy-proof** if no coalition $S$ can jointly misreport so that every member of $S$ weakly prefers its new house and some member strictly prefers it, with the other agents' reports fixed; it is **weakly group strategy-proof** if no coalition can make all members strictly better off.
