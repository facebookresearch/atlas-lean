# Resolution of Erdős Problem 632

It is not the case that for all positive integers $a, b, m$, every simple graph on $\{0, \dots, n-1\}$, for every $n$, that is $(a, b)$-choosable is $(am, bm)$-choosable. A simple graph $G$ is $(a, b)$-choosable when for every assignment of a set $L(v)$ of exactly $a$ natural-number colours to each vertex $v$ there are sets $S(v) \subseteq L(v)$ of exactly $b$ colours with $S(u) \cap S(v) = \emptyset$ for all adjacent $u, v$. That is, the proposition [Erdős Problem 632 (scaling $(a, b)$-choosability)](choosability-scales.md) is false.
