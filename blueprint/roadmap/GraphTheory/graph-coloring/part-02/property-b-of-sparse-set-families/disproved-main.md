# Erdős Problem 1022, negated form

The statement that it is not the case that there is a function $c : \mathbb{N} \to \mathbb{R}$ with $c(t) \to \infty$ such that for every $t$ the sparsity condition $(t, c(t))$ forces property B, where the sparsity condition $(t, c)$ forces property B when every finite family of finite sets of natural numbers, each of size at least $t$, in which every nonempty finite set $X$ contains fewer than $c|X|$ members of the family, has a $2$-colouring of the natural numbers with no monochromatic member.
