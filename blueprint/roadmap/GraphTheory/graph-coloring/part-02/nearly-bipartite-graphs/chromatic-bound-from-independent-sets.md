# Erdős Problem 922 (large independent sets bound the chromatic number)

The statement that for every natural number $k$, every simple graph $G$ on a finite vertex set in which every set $S$ of vertices contains an independent set $I \subseteq S$ with $|S| - k \le 2|I|$, that is, $|I| \ge (|S| - k)/2$ has a proper colouring with $k + 2$ colours. Stated here as a proposition; its resolution: [Resolution of Erdős Problem 922](chromatic-bound-from-independent-sets-ho.md).
