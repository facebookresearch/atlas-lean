# Resolution of Erdős Problem 922

For every natural number $k$, every simple graph $G$ on a finite vertex set in which every set $S$ of vertices contains an independent set $I \subseteq S$ with $|S| - k \le 2|I|$, that is, $|I| \ge (|S| - k)/2$ has a proper colouring with $k + 2$ colours. That is, the proposition [Erdős Problem 922 (large independent sets bound the chromatic number)](chromatic-bound-from-independent-sets.md) holds.
