# Resolution of Erdős Problem 73

For every natural number $k$ there is a natural number $C$ such that every simple graph $G$ on a finite vertex set in which every set $S$ of vertices contains an independent set $I \subseteq S$ with $|S| - k \le 2|I|$, that is, $|I| \ge (|S| - k)/2$ has a set $T$ of at most $C$ vertices whose deletion leaves a bipartite graph: the subgraph induced on the complement of $T$ is properly $2$-colourable. That is, the proposition [Erdős Problem 73 (bipartite after deleting boundedly many vertices)](near-bipartite-of-large-independent-sets.md) holds.
