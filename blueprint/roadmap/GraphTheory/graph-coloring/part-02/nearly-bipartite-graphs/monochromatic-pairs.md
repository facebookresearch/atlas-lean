# Monochromatic adjacent pairs inside a vertex set

For a simple graph $G$, a finite vertex set $S$ and a $2$-colouring $c$ of the vertices, the number of ordered pairs $(u, v)$ of distinct adjacent vertices of $S$ with $c(u) = c(v)$, twice the number of edges of $G[S]$ inside the colour classes; $G[S]$ becomes bipartite after deleting $m$ edges exactly when some $c$ makes this at most $2m$.
