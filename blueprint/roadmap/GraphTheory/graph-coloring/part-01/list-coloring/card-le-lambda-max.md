# A properly list-coloured vertex set has at most $\lambda_L$ vertices

Let $G$ be a simple graph on a finite vertex set $V$. A map $f : V \to \mathbb{N}$ is a proper $L$-colouring of a set $S \subseteq V$ when $f(v) \in L(v)$ for every $v \in S$ and $f(v) \ne f(w)$ for all adjacent $v, w \in S$. For an assignment $L$ of a finite set $L(v)$ of natural-number colours to each vertex $v$, $\lambda_L$ is the largest $k$ such that some $k$-element set of vertices has a proper $L$-colouring. If $f$ is a proper $L$-colouring of $S$, then $|S| \le \lambda_L$.
