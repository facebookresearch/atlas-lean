# Lists on the triangles of Noel's graph

For $i = 0, 1, 2, 3$, the list on the $i$-th triangle of Noel's graph is $\{0, 2\}$, $\{0, 3\}$, $\{1, 2\}$ and $\{1, 3\}$ respectively, a set of natural-number colours. With the source's colours $1, 2, 3, 4$ written as $0, 1, 2, 3$, these are the lists $\{1, 3\}$, $\{1, 4\}$, $\{2, 3\}$, $\{2, 4\}$ of the triangles $T_1, \dots, T_4$.

## Sources

- J. A. Noel, *The Partial List Colouring Conjecture is False*, arXiv:2609.23291, Theorem 1.1.
