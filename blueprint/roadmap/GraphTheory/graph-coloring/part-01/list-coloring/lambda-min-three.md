# $\lambda_3$ of Noel's graph is fourteen

Noel's graph $N$ has fourteen vertices: two terminals $s_1, s_2$ and, for each $i \in \{0, 1, 2, 3\}$, vertices $u_i, v_i, p_i$. Its edges are those of the four triangles $\{u_i, v_i, p_i\}$ and the edges from each terminal to every $u_i$ and every $v_i$; there are no other edges, so $s_1$ and $s_2$ are not adjacent and each $p_i$ is adjacent only to $u_i$ and $v_i$. For a graph on a finite vertex set and a natural number $t$, $\lambda_t$ is the minimum, over all assignments of a set of exactly $t$ natural-number colours to each vertex, of the largest number of vertices that can be properly coloured from their lists. For Noel's graph, $\lambda_3 = 14$: every assignment of three-colour lists allows a proper colouring of all fourteen vertices.

## Sources

- J. A. Noel, *The Partial List Colouring Conjecture is False*, arXiv:2609.23291, Theorem 1.1.
