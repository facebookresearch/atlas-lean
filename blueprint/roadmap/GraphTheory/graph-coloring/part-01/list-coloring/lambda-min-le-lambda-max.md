# $\lambda_t$ is at most $\lambda_L$ for lists of size $t$

Let $G$ be a simple graph on a finite vertex set $V$. For an assignment $L$ of a finite set $L(v)$ of natural-number colours to each vertex $v$, $\lambda_L$ is the largest $k$ such that some $k$-element set of vertices has a proper $L$-colouring. For a natural number $t$, $\lambda_t$ is the minimum of $\lambda_L$ over all assignments $L$ with $|L(v)| = t$ for every vertex $v$. If $|L(v)| = t$ for every vertex $v$, then $\lambda_t \le \lambda_L$.
