# $\lambda_L$ is at most the number of vertices

Let $G$ be a simple graph on a finite vertex set $V$. For an assignment $L$ of a finite set $L(v)$ of natural-number colours to each vertex $v$, $\lambda_L$ is the largest $k$ such that some $k$-element set of vertices has a proper $L$-colouring. Then $\lambda_L \le |V|$ for every assignment $L$.
