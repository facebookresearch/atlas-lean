# Dual 3-edge-colouring test for an oriented map

For permutations $\alpha$ and $\sigma$ of a set $D$ of darts, the condition holds when there is a map $c : D \to \{0, 1, 2\}$ with $c(\alpha(d)) = c(d)$ for every dart $d$ and $c(\sigma(\alpha(d))) \ne c(d)$ for every dart $d$: consecutive darts along each cycle of $\sigma\alpha$ get different colours. For an oriented combinatorial map with edges $\{d, \alpha(d)\}$ and faces the cycles of $\sigma\alpha$ that is a triangulation (every face of length $3$), this says that the dual is properly $3$-edge-coloured, the three edges around every face having distinct colours, and a face containing both darts of one edge (a loop of the dual) admits no such colouring. For general permutations the test compares only consecutive darts: on four darts with $\sigma\alpha = (0\,1\,2\,3)$ and $\alpha = (0\,2)(1\,3)$, alternating two colours around the face satisfies both conditions, although each edge is a loop of the dual.
