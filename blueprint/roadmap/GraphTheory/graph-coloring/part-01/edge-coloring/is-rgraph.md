# $r$-graphs

For a natural number $r$ and a multigraph given by a set $V$ of vertices (not necessarily finite) and a finite set $E$ of edges, each edge $e$ joining $s(e)$ and $t(e)$, with parallel edges allowed, the multigraph is an $r$-graph when it has no loops ($s(e) \ne t(e)$), every vertex has degree $r$ (counting endpoint incidences), and for every finite set $X$ of vertices of odd size at least $r$ edges have exactly one end in $X$.
