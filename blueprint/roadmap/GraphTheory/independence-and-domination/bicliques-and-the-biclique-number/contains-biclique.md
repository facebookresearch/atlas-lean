# Graph containing a (c, d)-biclique

Let $G$ be a simple graph on a finite vertex set $V$ and let $c, d$ be natural numbers. $G$ contains a $(c, d)$-biclique if there are disjoint sets $X, Y \subseteq V$ with $|X| = c$ and $|Y| = d$ such that every $x \in X$ is adjacent to every $y \in Y$; that is, $G$ contains the complete bipartite graph $K_{c,d}$ as a (not necessarily induced) subgraph.

No positivity is required of $c$ and $d$: when $c = 0$ (or $d = 0$) the condition only asks for a set of $d$ (or $c$) vertices.
