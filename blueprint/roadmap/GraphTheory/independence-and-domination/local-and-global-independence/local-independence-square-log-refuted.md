# Resolution of Erdős Problem 804, first question

It is not the case that for every real $\varepsilon > 0$ and all sufficiently large $n$, every simple graph on $\{0, \dots, n-1\}$ in which every set of $\lfloor (\log n)^2 \rfloor$ vertices contains an independent set of at least $\lceil \log n \rceil$ vertices (natural logarithm) has an independent set of at least $n^{1/2 - \varepsilon}$ vertices. Equivalently, for some $\varepsilon > 0$ there are infinitely many $n$ with such a graph whose independent sets all have fewer than $n^{1/2 - \varepsilon}$ vertices. That is, the proposition [Erdős Problem 804, first question](local-independence-square-log.md) is false.
