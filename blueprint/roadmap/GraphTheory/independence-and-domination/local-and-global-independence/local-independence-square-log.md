# Erdős Problem 804, first question

The statement that for every real $\varepsilon > 0$ and all sufficiently large $n$, every simple graph on $\{0, \dots, n-1\}$ in which every set of $\lfloor (\log n)^2 \rfloor$ vertices contains an independent set of at least $\lceil \log n \rceil$ vertices (natural logarithm) has an independent set of at least $n^{1/2 - \varepsilon}$ vertices. Stated here as a proposition; its resolution: [Resolution of Erdős Problem 804, first question](local-independence-square-log-refuted.md).
