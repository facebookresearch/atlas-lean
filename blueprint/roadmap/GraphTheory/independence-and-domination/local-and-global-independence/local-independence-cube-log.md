# Erdős Problem 804, second question

The statement that there is a real $c > 0$ such that for all sufficiently large $n$, every simple graph on $\{0, \dots, n-1\}$ in which every set of $\lfloor (\log n)^3 \rfloor$ vertices contains an independent set of at least $\lceil \log n \rceil$ vertices (natural logarithm) has an independent set of at least $c\,(\log n)^3$ vertices.
