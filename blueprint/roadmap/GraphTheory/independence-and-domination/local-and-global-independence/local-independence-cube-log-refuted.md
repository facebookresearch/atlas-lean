# Resolution of Erdős Problem 804, second question

It is not the case that there is a real $c > 0$ such that for all sufficiently large $n$, every simple graph on $\{0, \dots, n-1\}$ in which every set of $\lfloor (\log n)^3 \rfloor$ vertices contains an independent set of at least $\lceil \log n \rceil$ vertices (natural logarithm) has an independent set of at least $c\,(\log n)^3$ vertices. Equivalently, for every $c > 0$ there are infinitely many $n$ with such a graph whose independent sets all have fewer than $c\,(\log n)^3$ vertices. That is, the proposition [Erdős Problem 804, second question](local-independence-cube-log.md) is false.
