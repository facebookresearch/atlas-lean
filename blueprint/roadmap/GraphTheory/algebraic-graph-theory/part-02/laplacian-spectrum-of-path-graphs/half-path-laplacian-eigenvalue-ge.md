# Smallest nonzero eigenvalue of the half path Laplacian

Let $A_n = \tfrac12 L(P_n)$ be one half of the real Laplacian matrix of the path graph $P_n$ on the vertices $0, 1, \dots, n-1$ (with $j$ adjacent to $j + 1$). For $n \ge 2$, every nonzero eigenvalue $\mu$ of $A_n$ (a real $\mu \ne 0$ with $A_n v = \mu v$ for some nonzero $v$) satisfies

$$\mu \ge 1 - \cos(\pi / n),$$

and $1 - \cos(\pi / n)$ is itself an eigenvalue: $A_n v = (1 - \cos(\pi / n))\, v$ for some nonzero $v \in \mathbb{R}^n$.
