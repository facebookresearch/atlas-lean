# Eigenvalues of the half path Laplacian

Let $A_n = \tfrac12 L(P_n)$ be one half of the real Laplacian matrix of the path graph $P_n$ on the vertices $0, 1, \dots, n-1$ (with $j$ adjacent to $j + 1$). For $n \ge 1$, a real number $\mu$ is an eigenvalue of $A_n$ (there is a nonzero $v \in \mathbb{R}^n$ with $A_n v = \mu v$) if and only if

$$\mu = 1 - \cos(\pi k / n) \quad\text{for some natural number } k < n.$$
