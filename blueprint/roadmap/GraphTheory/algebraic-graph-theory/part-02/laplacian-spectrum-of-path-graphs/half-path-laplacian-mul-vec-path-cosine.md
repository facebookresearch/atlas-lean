# Eigen-equation of the path cosine modes

Let $A_n = \tfrac12 L(P_n)$ be one half of the real Laplacian matrix of the path graph $P_n$ on the vertices $0, 1, \dots, n-1$ (with $j$ adjacent to $j + 1$), and let $v_k(j) = \cos\bigl(\pi k (j + \tfrac12) / n\bigr)$ for $j = 0, \dots, n-1$. For every $n \ge 1$ and every natural number $k$,

$$A_n v_k = \bigl(1 - \cos(\pi k / n)\bigr) v_k.$$

The identity holds for all $k$, including those for which $v_k$ is the zero vector (such as $k = n$).
