# Ramanujan graphs and bipartite Ramanujan graphs

A connected $d$-regular graph with adjacency eigenvalues $d = \lambda_1 \ge \lambda_2 \ge \cdots \ge \lambda_N$ is *Ramanujan* if $|\lambda_i| \le 2\sqrt{d-1}$ for every $\lambda_i \ne \pm d$. A $d$-regular bipartite graph (whose spectrum is symmetric, with $\lambda_N = -d$) is *bipartite Ramanujan* if $|\lambda_i| \le 2\sqrt{d-1}$ for all $2 \le i \le N - 1$. By the Alon-Boppana bound, $2\sqrt{d-1}$ is the smallest possible asymptotic bound for $\lambda_2$ in any infinite family of $d$-regular graphs.
