# Cyclomatic number $|E| + 1 - |V|$ of a finite graph

For a simple graph $G$ on a finite vertex set $V$, the cyclomatic number is the natural number

$$(|E(G)| + 1) - |V|,$$

with truncated subtraction (it is $0$ when $|E(G)| + 1 < |V|$). For a connected graph it equals the cycle rank, the dimension of the cycle space.
