# Cycle rank of a finite graph

For a simple graph $G$ on a vertex set $V$, the cycle rank (nullity, first Betti number) is the natural number

$$\beta(G) = (|E(G)| + c(G)) - |V|,$$

where $c(G)$ is the number of connected components, the subtraction is truncated at $0$, and cardinalities of infinite sets are taken to be $0$. For finite $V$ the difference is never negative.
