# Edges of the grid $\{-n, \dots, n\}^2$

For a natural number $n$, the finite set of edges of the grid on $\{-n, \dots, n\}^2$: the horizontal edges $\{(a, b), (a+1, b)\}$ with $-n \le a \le n - 1$, $-n \le b \le n$, together with the vertical edges $\{(a, b), (a, b+1)\}$ with $-n \le a \le n$, $-n \le b \le n - 1$.
