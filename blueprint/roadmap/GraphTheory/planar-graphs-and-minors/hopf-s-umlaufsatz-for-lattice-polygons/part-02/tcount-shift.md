# Every direction is left by equally many left turns

Let $n \ge 1$ and let $d = (d_0, \dots, d_{n-1})$ be a cyclic sequence of directions $d_i \in \mathbb{Z}/4\mathbb{Z}$, indices taken modulo $n$. If every turn $d_{i+1} - d_i$ is $0$ or $1$, then for every direction $c \in \mathbb{Z}/4\mathbb{Z}$ the number of indices $i$ with $d_i = c$, $d_{i+1} = c + 1$ equals the number of indices $i$ with $d_i = c + 1$, $d_{i+1} = c + 2$.
