# A single top run makes the top row contiguous

Let $n \ge 1$ and let $d = (d_0, \dots, d_{n-1})$ be a cyclic sequence of directions $d_i \in \mathbb{Z}/4\mathbb{Z}$, indices taken modulo $n$. Direction $k$ is the unit step $s(k)$, with $s(0) = (1, 0)$ (east), $s(1) = (0, 1)$ (north), $s(2) = (-1, 0)$ (west), $s(3) = (0, -1)$ (south), and the walk with step directions $d$ has vertices $p_k = \sum_{0 \le i < k} s(d_i)$ for $k = 0, \dots, n-1$ (so $p_0 = 0$; vertex indices are also taken modulo $n$). Suppose the walk is closed, $\sum_{i} s(d_i) = 0$, $M$ is an index such that $p_M$ has the largest $y$-coordinate among all vertices, and the walk has a single top run from $M$ (every vertex at height $y(p_M)$ is $p_M - (j, 0)$ for some $j$ with $d_{M+i} = 2$ for all $i < j$). Then the top row of the walk is contiguous: for some index $M'$ of maximal height, every lattice point between two vertices at height $y(p_{M'})$ on that row is a vertex.
