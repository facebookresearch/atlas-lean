# Adding an edge between two components merges them

Let $G$ be a simple graph on a vertex set $V$ with finitely many connected components, and let $a, b \in V$ be vertices not joined by any walk in $G$. Then adding the edge $\{a, b\}$ merges two components:

$$c(G + ab) + 1 = c(G),$$

where $c$ denotes the number of connected components.
