# Number of finite components of the region graph

Let $P$ be a finite graph with an injective map into $\mathbb{Z}^2$ sending edges to edges of the square lattice, with image graph $H$. The region count of $P$ is the number of connected components with finitely many vertices of the region graph of $H$: the square lattice with every edge $\{f, g\}$ removed for which $\{\rho^{-1}(f), \rho^{-1}(g)\}$ is an edge of $H$, where $\rho(a, b) = (-b, a)$. (Rotating by $\rho$, this is the number of finite components of the square lattice with the edges of $H$ deleted.)
