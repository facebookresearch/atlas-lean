# Quarter-turn isomorphism onto the region graph

For a simple graph $H$ on $\mathbb{Z}^2$, the rotation $\rho(a, b) = (-b, a)$ is a graph isomorphism from the square lattice with the edges of $H$ deleted onto the region graph of $H$ (the square lattice with every edge $\{f, g\}$ removed for which $\{\rho^{-1}(f), \rho^{-1}(g)\}$ is an edge of $H$).
