# Veblen's theorem step for unions of cycles

Let $K$ be a simple graph on a finite vertex set $V$ in which every vertex has degree $0$ or $2$, and suppose $K$ has at least one edge. Then there is a subgraph $K' \le K$ in which every vertex has degree $0$ or $2$, with $|E(K')| < |E(K)|$ and $F(K') + 1 = F(K)$, where $F(H) = \beta(H) + 1$ is the face count and $\beta(H) = |E(H)| + c(H) - |V|$ the cycle rank ($c(H)$ the number of connected components). This is one step of Veblen's theorem that a graph in which every vertex has even degree is an edge-disjoint union of cycles.

## Sources

- Oswald Veblen, *An application of modular equations in analysis situs*, Annals of Mathematics (2) 14 (1912), 86–94, DOI 10.2307/1967604, §3 (pp. 87–88): a set of edges with even incidences decomposes into edge-disjoint circuits.
