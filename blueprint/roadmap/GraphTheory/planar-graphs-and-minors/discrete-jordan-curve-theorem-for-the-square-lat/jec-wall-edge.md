# Wall edges below a site

For a site $z \in \mathbb{Z}^2$, an unordered pair of sites is a wall edge of $z$ when it is a horizontal lattice edge $\{(z_0 - 1, r), (z_0, r)\}$ with $r \le z_1 - 1$; these are the edges crossed by the vertical ray going down from the point $(z_0 - \tfrac12, z_1 - \tfrac12)$.
