# Outer region of the rotated region graph

For a finite graph $G = (V, E)$ with an injective map $\iota : V \to \mathbb{Z}^2$ sending edges to lattice edges, with image $H$, and the chosen radius $R$ with $\iota(V) \subseteq \{-R, \dots, R\}^2$: the connected component containing $(R + 1, R + 1)$ of the region graph of $H$, the square lattice with every edge $\{f, g\}$ removed for which $\{\rho^{-1}(f), \rho^{-1}(g)\}$ is an edge of $H$, where $\rho(a, b) = (-b, a)$.
