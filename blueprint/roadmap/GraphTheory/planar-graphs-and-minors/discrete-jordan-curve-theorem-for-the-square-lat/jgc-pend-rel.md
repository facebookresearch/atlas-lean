# Adjacency relation of a 4-cycle with a pendant edge

The adjacency relation of the graph on $\{0, 1, 2, 3, 4\}$ with edges $\{0, 1\}, \{1, 2\}, \{2, 3\}, \{3, 0\}, \{0, 4\}$ (a $4$-cycle with a pendant edge), as a Boolean-valued function true exactly on the ordered pairs $(i, j)$ with $\{i, j\}$ one of these edges.
