# Flood fill avoiding a set of sites

For a set $B \subseteq \mathbb{Z}^2$ and a site $s$, the flood fill of $s$ avoiding $B$ is the set of sites $z$ joined to $s$ by a walk in the square lattice with every edge having an endpoint in $B$ deleted. For $s \notin B$ these are $s$ and the sites reachable from $s$ by lattice walks avoiding $B$; for $s \in B$ it is $\{s\}$.
