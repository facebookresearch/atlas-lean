# Book thickness is not bounded by that of the once-subdivided graph

It is not the case that there is a function $f : \mathbb{N} \to \mathbb{N}$ such that for all simple graphs $G$ and $G'$ on finite vertex sets, where $G'$ is obtained from $G$ by subdividing every edge exactly once, and every natural number $k$, if $G'$ has a $k$-page book embedding then $G$ has an $f(k)$-page book embedding: the book thickness of a finite graph is bounded by a function of the book thickness of its once-subdivided graph. A $k$-page book embedding orders the vertices along a spine and puts the edges on $k$ pages so that crossing edges are on different pages. Equivalently, for every $f : \mathbb{N} \to \mathbb{N}$ some finite graph $G$ and some $k$ are such that the once-subdivided graph of $G$ has a $k$-page book embedding but $G$ has no $f(k)$-page book embedding.
