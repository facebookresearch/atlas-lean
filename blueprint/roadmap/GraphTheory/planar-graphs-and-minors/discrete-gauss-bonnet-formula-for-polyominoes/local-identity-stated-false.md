# Failure of the local identity without a pinch term

It is not true that for all $e, w, n, s, ne, nw, se, sw \in \{0, 1\}$ (indicators of the eight neighbouring cells of a new cell)

$$J(w + s + sw) + J(e + se + s) + J(n + nw + w) + J(ne + n + e) = 4\,(\Delta V - \Delta E + 1),$$

where $J(m) = w_c(m+1) - w_c(m)$ with $w_c(k) = \mathbf{1}[k = 1] - \mathbf{1}[k = 3]$, $\Delta V = \mathbf{1}[w + s + sw = 0] + \mathbf{1}[e + se + s = 0] + \mathbf{1}[n + nw + w = 0] + \mathbf{1}[ne + n + e = 0]$ and $\Delta E = (1 - s) + (1 - n) + (1 - w) + (1 - e)$. So the change of the corner defect is not always four times the change of the Euler characteristic.
