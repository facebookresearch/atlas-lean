# Membership in the star hull

For a set $K \subseteq \mathbb{Z}^2$, membership in the star hull of $K$ is defined inductively by three rules:

- every site of $K$ is a member;
- if $(a, b)$ and $(a+1, b+1)$ are members, then $(a+1, b)$ is a member;
- if $(a+1, b)$ and $(a, b+1)$ are members, then $(a, b)$ is a member.

The members are exactly the sites obtained from $K$ by finitely many applications of these rules.
