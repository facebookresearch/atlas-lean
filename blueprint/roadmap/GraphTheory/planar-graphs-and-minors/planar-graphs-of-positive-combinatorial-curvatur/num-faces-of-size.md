# Number of faces of a given size

Let $G$ be a simple graph on a finite vertex set $V$, with darts (ordered pairs $(u, v)$ of adjacent vertices) and a permutation $\rho$ of the darts. For a natural number $k$, the number of faces of size $k$ is the number of darts lying on a face of size $k$, divided by $k$ (natural division; each such face has $k$ darts).

The words face, corner and facial walk describe an embedding only when $\rho$ is a [rotation system](is-rotation-system.md); for an arbitrary permutation $\rho$ the quantities here are orbit counts of the face permutation.
