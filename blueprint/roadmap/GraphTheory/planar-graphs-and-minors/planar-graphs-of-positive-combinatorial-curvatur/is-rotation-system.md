# Rotation system

Let $G$ be a simple graph on a finite vertex set $V$, with darts (ordered pairs $(u, v)$ of adjacent vertices) and a permutation $\rho$ of the darts. Then $\rho$ is a rotation system when it preserves the tail of every dart and, for any two darts $d, d'$ with the same tail, $\rho^k(d) = d'$ for some $k \ge 0$: $\rho$ cycles through the darts at each vertex in one cycle (their cyclic order around the vertex).
