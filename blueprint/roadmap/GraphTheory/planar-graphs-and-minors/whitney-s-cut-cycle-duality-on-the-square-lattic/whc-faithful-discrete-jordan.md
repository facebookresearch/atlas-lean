# Faithful discrete Jordan statement for the face count

A finite graph $G = (V, E)$ with an injective map into $\mathbb{Z}^2$ sending edges to lattice edges has this property when the connected components with finitely many faces of the face-region graph of its image are in bijection with $\{0, 1, \dots, \beta(G) - 1\}$, where $\beta(G) = |E| + c(G) - |V|$ is the cycle rank; that is, the number of bounded faces equals the cycle rank. Only the number is asserted, not which cycle bounds which face.
