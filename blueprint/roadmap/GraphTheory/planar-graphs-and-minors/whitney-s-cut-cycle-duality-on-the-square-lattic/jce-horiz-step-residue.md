# Parity coloring changes across vertical contour edges

The statement that, for every finite closed contour $E$ (every site of $\mathbb{Z}^2$ has even degree in $E$) and all integers $a, b$, the vertical edge $\{(a + 1, b), (a + 1, b + 1)\}$ belongs to $E$ if and only if the faces $(a, b)$ and $(a + 1, b)$ have different parity colours, where a face $(f_0, f_1)$ is coloured when an odd number of edges $\{(f_0, h), (f_0 + 1, h)\}$ with $h \le f_1$ belong to $E$.
