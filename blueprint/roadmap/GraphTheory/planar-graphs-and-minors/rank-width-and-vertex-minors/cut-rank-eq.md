# Locally equivalent graphs have the same cut-rank function

If $H$ is locally equivalent to $G$, then $\rho_H(X) = \rho_G(X)$ for every vertex set $X$.

## Sources

- S. Oum, *Rank-width and vertex-minors*, J. Combin. Theory Ser. B 95 (2005) 79–100; read in the author's revised preprint of 18 April 2005 (https://sangil.dimag.kr/pdf/vertexminor-revision.pdf), whose numbering is cited here, Proposition 2.6 and Corollary 2.7.
