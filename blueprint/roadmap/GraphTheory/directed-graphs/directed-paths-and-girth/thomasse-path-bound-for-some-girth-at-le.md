# Thomassé's path bound for some girth at least four

The statement that Thomassé's path bound holds for some girth $g \ge 4$: for some $g \ge 4$, every digraph on a finite vertex set of girth $g$ (shortest directed cycle with $g$ vertices) has a directed path with $\delta^+ (g - 1)$ arcs, $\delta^+$ being its minimum out-degree. Stated here as a proposition; its resolution: [Thomassé's path bound fails for every girth at least four](thomasse-path-bound-for-some-girth-at-le-2.md).
