# Thomassé's path bound for some girth at least four

The statement that Thomassé's path bound holds for some girth $g \ge 4$: for some $g \ge 4$, every digraph on a finite vertex set of girth $g$ (shortest directed cycle with $g$ vertices) has a directed path with $\delta^+ (g - 1)$ arcs, $\delta^+$ being its minimum out-degree.

## Sources

- B. Sullivan, A summary of problems and results related to the Caccetta-Häggkvist conjecture (AIM workshop problem list), Conjecture 6.34 (Thomassé), https://aimath.org/WWN/caccetta/caccetta.pdf.
