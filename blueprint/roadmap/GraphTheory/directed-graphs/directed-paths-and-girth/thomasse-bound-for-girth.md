# Thomassé's path bound for a given girth

For a natural number $g$, Thomassé's path bound holds for girth $g$ when every digraph $G$ on a finite vertex set of girth $g$ has a directed path with $\delta^+(G)\,(g - 1)$ arcs, where $\delta^+(G)$ is the minimum out-degree, the least number of out-neighbours of a vertex.
