# Initial sums of a monotone sequence are minimal among sums over sets of the same size

Let $M$ be an ordered additive commutative monoid (a partial order on $M$ for which $a \le b$ implies $a + c \le b + c$) and let $s : \{0, 1, \dots, n-1\} \to M$ be monotone. For every set $S \subseteq \{0, 1, \dots, n-1\}$, with $k = |S|$,

$$\sum_{i=0}^{k-1} s(i) \le \sum_{i \in S} s(i).$$

The sum on the left runs over the $k$ smallest indices; the hypothesis $k \le n$, which always holds, is what places them in $\{0, 1, \dots, n-1\}$.
