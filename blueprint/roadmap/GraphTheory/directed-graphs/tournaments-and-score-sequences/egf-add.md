# Sum rule for exponential generating functions

For sequences $a, b, c : \mathbb{N} \to \mathbb{N}$ with $c(n) = a(n) + b(n)$ for every $n$, the exponential generating functions satisfy $C(x) = A(x) + B(x)$, where the exponential generating function of a sequence $u : \mathbb{N} \to \mathbb{N}$ is the formal power series $\sum_{n \ge 0} u(n)\, x^n / n!$ over $\mathbb{Q}$.
