# Strongly connected vertex set of a digraph

For a relation $T$ on $\{0, \dots, n-1\}$ and a set $W$ of vertices, $W$ induces a strongly connected subdigraph when for all $u, v \in W$ there is a directed path from $u$ to $v$, following arcs of $T$, all of whose vertices lie in $W$ (a vertex reaches itself by the empty path).
