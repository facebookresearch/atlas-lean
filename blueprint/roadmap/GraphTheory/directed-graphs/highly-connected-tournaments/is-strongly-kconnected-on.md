# Strongly k-connected vertex set of a digraph

For a relation $T$ on $\{0, \dots, n-1\}$, a set $W$ of vertices and a natural number $k$, $W$ induces a strongly $k$-connected subdigraph when $|W| > k$ and for every set $S \subseteq W$ of fewer than $k$ vertices, $W \setminus S$ induces a strongly connected subdigraph.
