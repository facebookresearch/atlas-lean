# $\Delta(T_2, T_2, T_2)$-free tournaments have near-linear transitive subsets

For every real $\varepsilon > 0$ there is a real $c > 0$ such that every tournament $G$ on a finite nonempty vertex set that does not contain $\Delta(T_2, T_2, T_2)$ as an induced subtournament has a transitive set of at least $c\,|V(G)|^{1 - \varepsilon}$ vertices. Here the tournament $\Delta(T_2, T_2, T_2)$ has vertices $(i, j)$ with $i \in \{0, 1, 2\}$ and $j \in \{0, 1\}$, and $(i, j) \to (i', j')$ exactly when $i = i'$ and $j < j'$, or $i' = i + 1$ modulo $3$: three parts, each inducing the transitive tournament $T_2$ on two vertices, with every vertex of part $i$ beating every vertex of part $i + 1$, and a set is transitive when it induces no directed cycle. That is, the proposition [Seymour's statement 8 (near-linear transitive subsets)](near-linear-transitive-subsets.md) holds.
