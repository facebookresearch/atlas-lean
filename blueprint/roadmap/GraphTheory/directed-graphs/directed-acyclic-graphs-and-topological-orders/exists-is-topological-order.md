# Every finite acyclic digraph has a topological order

Let $G$ be an acyclic digraph on a finite vertex type $V$. Then $G$ has a topological order: there is a bijection $\sigma : V \to \{0, 1, \dots, |V|-1\}$ with $\sigma(u) < \sigma(v)$ for every edge $u \to v$ of $G$. Such an order is a linear extension of the reachability order of $G$.
