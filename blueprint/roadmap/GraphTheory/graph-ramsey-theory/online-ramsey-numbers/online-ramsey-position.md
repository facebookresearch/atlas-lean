# Positions of the online Ramsey game

A position of the online Ramsey game is a finite list of pairs $(e, b)$, where $e$ is an unordered pair of natural numbers (an edge Builder has drawn) and $b$ is the colour Painter gave it, red (true) or blue (false). Builder draws edges on the vertex set of natural numbers and Painter colours each one as it is drawn.

A position here is an arbitrary list: it may repeat an edge, contain a loop $\{x, x\}$, or record one edge in both colours. Positions reached in an actual game from the empty position have none of these; the definitions apply to every list.
