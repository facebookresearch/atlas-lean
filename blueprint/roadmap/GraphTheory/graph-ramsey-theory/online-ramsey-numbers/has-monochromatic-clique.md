# Monochromatic clique in an online Ramsey position

A position of the online Ramsey game is a finite list of pairs $(e, b)$, where $e$ is an unordered pair of natural numbers (an edge Builder has drawn) and $b$ is the colour Painter gave it, red (true) or blue (false). Such a position $P$ has a monochromatic $K_n$ when there are a colour $b$ and a set $S$ of exactly $n$ natural numbers such that $(\{x, y\}, b)$ occurs in $P$ for all distinct $x, y \in S$ (the clique test is on distinct vertices and distinct pairs).

A position here is an arbitrary list: it may repeat an edge, contain a loop $\{x, x\}$, or record one edge in both colours. Positions reached in an actual game from the empty position have none of these; the definitions apply to every list.
