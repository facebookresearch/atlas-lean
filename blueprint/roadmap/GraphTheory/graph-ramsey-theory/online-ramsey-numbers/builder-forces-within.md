# Builder forcing a monochromatic clique within a number of moves

A position of the online Ramsey game is a finite list of pairs $(e, b)$, where $e$ is an unordered pair of natural numbers (an edge Builder has drawn) and $b$ is the colour Painter gave it, red (true) or blue (false). Builder can force a monochromatic $K_n$ from a position $P$ within $k$ moves when: for $k = 0$, $P$ already has a monochromatic $K_n$; for $k + 1$, either $P$ already has one, or there are distinct $x, y$ such that the edge $\{x, y\}$ does not occur in $P$ in either colour and, for both colours $b$, Builder can force a monochromatic $K_n$ within $k$ moves from the position obtained by adding $(\{x, y\}, b)$ to $P$. A position has a [monochromatic $K_n$](has-monochromatic-clique.md) when for some colour $b$ there is a set of $n$ distinct natural numbers with every pair of distinct members recorded in $P$ with colour $b$; loops $\{x, x\}$ in the list play no role, and for $n = 1$ the empty position already has one. Painter's colour is chosen adversarially at every move.

A position here is an arbitrary list: it may repeat an edge, contain a loop $\{x, x\}$, or record one edge in both colours. Positions reached in an actual game from the empty position have none of these; the definitions apply to every list.
