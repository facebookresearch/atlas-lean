# Graphs arrowing a path

A simple graph $G$ on a vertex set $V$ arrows the path $P_n$ on $n$ vertices when for every map $c$ from the unordered pairs of $V$ to two colours there is a colour $b$ such that the edges $e$ of $G$ with $c(e) = b$ form a graph containing a copy of $P_n$, not necessarily induced.
