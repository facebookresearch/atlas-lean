# Size Ramsey number

The size Ramsey number $\hat R(G)$ of a simple graph $G$ is the least $m$ such that some simple graph on $\{0, \dots, N-1\}$, for some $N$, with exactly $m$ edges is Ramsey for $G$ (every red/blue colouring of its edges has a monochromatic copy of $G$, not necessarily induced), and $0$ if there is none, as for a graph on an infinite vertex set.
