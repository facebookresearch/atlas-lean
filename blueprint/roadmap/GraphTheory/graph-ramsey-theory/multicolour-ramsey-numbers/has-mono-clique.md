# Monochromatic clique of given size in an edge colouring

A colouring of the edges of $K_m$ with $k$ colours is a map $c$ from the unordered pairs of $\{0, \dots, m-1\}$ to $\{0, \dots, k-1\}$; only pairs of distinct vertices matter. The colouring $c$ has a monochromatic $K_n$ of colour $i$ when there is a set $S$ of exactly $n$ vertices with $c(\{x, y\}) = i$ for all distinct $x, y \in S$.

For $n = 3$ this is a monochromatic triangle of colour $i$: three pairwise distinct vertices $x, y, z$ with $c(\{x, y\}) = c(\{y, z\}) = c(\{x, z\}) = i$, the three-element set being $\{x, y, z\}$.
