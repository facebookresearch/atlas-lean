# Resolution of Erdős Problem 615

It is not the case that there is a real $c > 0$ such that for all sufficiently large $n$, every simple graph $G$ on the vertex set $\{0, \dots, n-1\}$ with at least $(1/8 - c)n^2$ edges contains $K_4$ or has an independent set of at least $n / \log n$ vertices, that is, $\alpha(G) \ge n/\log n$, with $\log$ the natural logarithm. Equivalently, for every real $c > 0$ there are infinitely many $n$ for which some $K_4$-free simple graph on $\{0, \dots, n-1\}$ has at least $(1/8 - c)n^2$ edges and independence number less than $n / \log n$. That is, the proposition [Erdős Problem 615 (Ramsey–Turán problem for $K_4$)](ramsey-turan-kfour-log-independence.md) is false.
