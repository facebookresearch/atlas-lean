# Pairs of vertices

The two-element subsets $\{i, j\}$ of $\{0, \dots, n-1\}$: the $\binom n2$ possible edges of a simple graph on $n$ vertices. A graph is the same thing as a set of pairs, and a uniformly random graph is a [random subset](../../../Combinatorics/probabilistic-combinatorics/janson-s-inequalities/random-subset-law.md) of the pairs, each kept with probability $1/2$.
