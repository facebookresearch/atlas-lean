# A copy of K_k gives a monochromatic k-set

If the [graph with edge set](pair-graph.md) $\omega$ contains a copy of $K_k$, its vertex set is a $k$-set $R$ all of whose [pairs](pairs-in.md) belong to $\omega$; if the complement contains a copy of $K_k$, all pairs of $R$ lie outside $\omega$. This translates "contains $K_k$" into the events $\{S \subseteq \omega\}$ and $\{S \cap \omega = \emptyset\}$ of the random-subset model.
