# Existence of Ramsey numbers for cliques

For all natural numbers $s$ and $t$ there is an $N$ such that every simple graph on $N$ vertices contains $K_s$ or has $K_t$ in its complement. Colour each pair of vertices by whether it is an edge; the [finite Ramsey theorem for pairs](../../../Combinatorics/ramsey-theory/structural-ramsey/ramsey-two-uniform.md) gives a monochromatic set of size $\max(s, t)$, which contains a $K_s$ in the graph or a $K_t$ in its complement. Hence the set defining the [classical Ramsey number](graph-ramsey.md) $R(s,t)$ is nonempty, and $R(s,t)$ is a genuine minimum.
