# Pairs inside a vertex set

For a set $R$ of vertices, the pairs $\{i, j\} \subseteq R$; there are $\binom{|R|}{2}$ of them. $R$ is a clique of the graph with edge set $\omega$ when all of them are in $\omega$, and an independent set when none is.
