# Erdős Problem 1031 (regular induced subgraphs)

The statement that there is a real $c > 0$ such that for all sufficiently large $n$, every simple graph $G$ on the vertex set $\{0, \dots, n-1\}$ in which every clique and every independent set has fewer than $10 \log n$ vertices (with $\log$ the natural logarithm) has a vertex set $s$ with $|s| \ge c \log n$ that is neither a clique nor an independent set and induces a regular subgraph: for some $d$, every vertex of $s$ has exactly $d$ neighbours in $s$. Stated here as a proposition; its resolution: [Resolution of Erdős Problem 1031](ramsey-graph-large-regular-induced-holds.md).
