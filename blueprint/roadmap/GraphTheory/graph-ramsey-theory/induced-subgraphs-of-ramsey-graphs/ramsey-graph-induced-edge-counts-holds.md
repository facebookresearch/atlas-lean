# Resolution of Erdős Problem 88

For every real $\varepsilon > 0$ there is a real $\delta > 0$ such that for every natural number $n$ and every simple graph $G$ on the vertex set $\{0, \dots, n-1\}$ in which every clique and every independent set has fewer than $\varepsilon \log n$ vertices (with $\log$ the natural logarithm), and for every natural number $m \le \delta n^2$, some set $S$ of vertices induces a subgraph with exactly $m$ edges. That is, the proposition [Erdős Problem 88 (induced subgraphs with every number of edges)](ramsey-graph-induced-edge-counts.md) holds.

The statement quantifies over every $n$, with the convention $\log 0 = 0$.
