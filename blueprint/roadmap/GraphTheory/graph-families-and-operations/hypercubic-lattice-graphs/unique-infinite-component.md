# Complement of a finite set in $\mathbb{Z}^d$ has one infinite component

Let $d \ge 2$ and let $F \subseteq \mathbb{Z}^d$ be a finite set of sites. The subgraph of the hypercubic lattice $\mathbb{Z}^d$ induced on $\mathbb{Z}^d \setminus F$ has exactly one connected component with infinitely many vertices.
