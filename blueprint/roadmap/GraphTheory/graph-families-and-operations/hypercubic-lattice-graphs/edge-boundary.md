# Edge boundary of a set of sites

For a natural number $d$ and a set $S \subseteq \mathbb{Z}^d$ of sites, the edge boundary of $S$ is the set of ordered pairs $(x, y)$ of nearest-neighbour sites of $\mathbb{Z}^d$ such that exactly one of $x$ and $y$ lies in $S$. Both orientations of each boundary edge belong to it.
