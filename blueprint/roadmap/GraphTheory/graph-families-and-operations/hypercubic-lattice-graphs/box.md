# Box $\{-n, \dots, n\}^d$ in the hypercubic lattice

For natural numbers $d$ and $n$, the box of radius $n$ in $\mathbb{Z}^d$ is the set of sites all of whose coordinates have absolute value at most $n$:

$$B_n = \{x \in \mathbb{Z}^d : |x_i| \le n \text{ for } i = 0, \dots, d-1\} = \{-n, \dots, n\}^d.$$
