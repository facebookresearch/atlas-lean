# Vertex boundary of the box $\{-n, \dots, n\}^d$ as a finite set

For natural numbers $d$ and $n$, the finite set $\{-n, \dots, n\}^d \setminus \{-m, \dots, m\}^d \subset \mathbb{Z}^d$ with $m = n - 1$ computed by truncated subtraction of natural numbers. It is empty for $n = 0$; for $n \ge 1$ it consists of the sites of the box having some coordinate equal to $\pm n$.
