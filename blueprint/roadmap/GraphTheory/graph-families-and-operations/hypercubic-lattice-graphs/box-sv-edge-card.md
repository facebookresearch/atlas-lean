# Number of nearest-neighbour pairs inside the box $\{-n, \dots, n\}^d$

For natural numbers $d$ and $n$, the number of ordered pairs $(x, y)$ of sites of the box $\{-n, \dots, n\}^d$ that are nearest neighbours, that is, with $\sum_{i=0}^{d-1} |x_i - y_i| = 1$. Each edge of the lattice inside the box is counted twice, once for each orientation.
