# Non-negative Ollivier–Ricci curvature

Let $G$ be a simple graph on a finite vertex set $V$. $G$ has non-negative Ollivier–Ricci curvature when for every edge $xy$, with the lazy walk $P(x, y)$, equal to $1/2$ if $x = y$, to $1/(2\deg x)$ if $y$ is adjacent to $x$, and to $0$ otherwise, some coupling $\pi$ of $P(x, \cdot)$ and $P(y, \cdot)$, a nonnegative function on $V \times V$ with row sums $P(x, \cdot)$ and column sums $P(y, \cdot)$, has $\sum_{u, v} \pi(u, v)\, d(u, v) \le 1$, $d$ the graph distance; that is, $\kappa(x, y) = 1 - W_1(P(x, \cdot), P(y, \cdot)) \ge 0$.
