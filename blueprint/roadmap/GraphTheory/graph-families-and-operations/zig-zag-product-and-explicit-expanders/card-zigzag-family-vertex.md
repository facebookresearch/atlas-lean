# Size of the zig-zag expander family

For a finite set $K$ and every natural number $t$, the [vertex set of the $t$-th graph of the zig-zag family](zig-zag-family-vertex.md) has $\lvert K\rvert^{t+1}$ elements; with $\lvert K\rvert = D^4$ this is the $N_i = D^{4i}$ of Reingold, Vadhan and Wigderson, Theorem 1.4, for $i = t + 1$.
