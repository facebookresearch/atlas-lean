# Relabelling preserves the $(N, D, \lambda)$ property

Let $V$, $L$ and $L'$ be finite sets, $\mathrm{rot}$ a [rotation map](rotation-map.md) on $V \times L$ and $e : L \to L'$ a bijection. If $\mathrm{rot}$ describes an [$(N, D, \lambda)$-graph](is-ndlambda-graph.md) with parameter $\lambda$, so does the [relabelled](relabel.md) rotation map.
