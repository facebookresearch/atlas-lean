# Vertex types of the zig-zag family

For a set $K$ and a natural number $t$, the vertex set of the $t$-th graph of the zig-zag expander family is defined recursively by $V_0 = K$ and $V_{t+1} = V_t \times K$, so $V_t$ is $K$, $K \times K$, $(K \times K) \times K$, …, with $\lvert K\rvert^{t+1}$ elements when $K$ is finite ([size of the zig-zag expander family](card-zigzag-family-vertex.md)).
