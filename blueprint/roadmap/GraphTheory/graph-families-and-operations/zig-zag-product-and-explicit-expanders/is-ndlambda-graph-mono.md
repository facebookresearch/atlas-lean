# The $(N, D, \lambda)$ property is monotone in $\lambda$

Let $V$ and $L$ be finite sets and $\mathrm{rot}$ a [rotation map](rotation-map.md) on $V \times L$. If $\mathrm{rot}$ describes an [$(N, D, \lambda)$-graph](is-ndlambda-graph.md) with parameter $\lambda$ and $\lambda \le \lambda'$, then it describes one with parameter $\lambda'$.
