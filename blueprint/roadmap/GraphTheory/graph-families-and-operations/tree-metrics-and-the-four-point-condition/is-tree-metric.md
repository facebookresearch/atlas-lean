# Tree metric

A real function $d$ on pairs of elements of a set $X$ is a tree metric if there are a finite tree $G$, edge lengths $w_e > 0$ on its edges and a map $\iota$ from $X$ to the vertices of $G$ such that, for all $x, y \in X$, $d(x, y)$ is the total length of the path from $\iota(x)$ to $\iota(y)$. Internal vertices need not be taxa, and distinct taxa may share a vertex.
