# Buneman's four-point theorem

Let $X$ be a finite set and $d$ a real function on pairs with $d(x, x) = 0$ and $d(x, y) = d(y, x)$ for all $x, y$. Then $d$ is a [tree metric](is-tree-metric.md) if and only if it satisfies the [four-point condition](four-point-condition.md).

## Sources

- P. Buneman, *A note on the metric properties of trees*, J. Combin. Theory Ser. B 17 (1974), 48–50.
- C. Semple and M. Steel, *Phylogenetics*, Oxford University Press (2003).
