# End-devouring rays with prescribed start vertices exist

For every simple graph $G$ (on a vertex set of any cardinality) and every ray $r_0$ of $G$ whose end $\omega$ is countable, meaning that some countable set of rays of $\omega$ devours $\omega$ (every ray of $\omega$ meets one of them), and every infinite set $R$ of pairwise vertex-disjoint rays of $\omega$, there is a set $R'$ of pairwise vertex-disjoint rays of $\omega$ that devours $\omega$ and has the same set of start vertices as $R$. Here a ray is a sequence of distinct vertices, consecutive ones adjacent, and a ray belongs to $\omega$ when no finite vertex set separates its tail from that of $r_0$. That is, the proposition [Georgakopoulos's end-devouring rays problem](end-devouring-rays.md) holds.
