# Independent codes for the modular cycle

Let $q$ and $n$ be natural numbers. A finite set $A$ of words of length $n$ over $\mathbb{Z}/q\mathbb{Z}$ (over $\mathbb{Z}$ when $q = 0$) is an independent code modulo $q$ when every difference $x = a_1 - a_2$ with $a_1, a_2 \in A$ whose coordinates all lie in $\{-1, 0, 1\}$ is the zero word. For $q \ge 3$ this says exactly that $A$ is an independent set in the $n$-th strong power of the cycle graph $C_q$; for $q = 0$ it is a condition on integer words, not on a finite cycle.

The source uses odd $q \ge 7$; the definition is stated for every $q$.
