# Tandon's dimension-500 code for the 7-cycle

Let $M^*$ be Tandon's dimension-500 code
size. There is an independent code for the $7$-cycle consisting of words of length $500$ over
$\mathbb{Z}/7\mathbb{Z}$ with exactly $M^*$ codewords.

## Sources

- Ravi Tandon, *Strengthening Recursive Constructions for Zero-Error Shannon Capacity*, arXiv:2608.30273v1 (2026), exact dimension-500 construction; its disclosure of AI use states that ChatGPT and Claude assisted with exploration, proof development and checking, search and verification code, and manuscript refinement.
