# Stable sets lie in the theta body

If $S$ is a stable set of $G$, then $\chi^S \in \mathrm{TH}(G)$: for every orthogonal labeling $a$ and handle $c$, $\sum_v \mathrm{cost}_c(a_v)\, \chi^S_v = \sum_{v \in S} \mathrm{cost}_c(a_v) \le 1$ because [stable sets have total cost at most one](sum-cost-le-one.md).

## Sources
