# Theta is at most the chromatic number of the complement

For every finite graph $G$, $\vartheta(G) \le \chi(\bar G)$, the least number of cliques of $G$ that cover its vertices. The chromatic number of a finite graph is finite and is read as a natural number.

## Sources
