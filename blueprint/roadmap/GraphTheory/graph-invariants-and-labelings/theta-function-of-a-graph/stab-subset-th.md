# The stable set polytope lies in the theta body

$\mathrm{STAB}(G) \subseteq \mathrm{TH}(G)$: the theta body contains every [characteristic vector of a stable set](char-vec-mem-th.md) and [is convex](convex-th.md), so it contains their convex hull.

## Sources

- D. E. Knuth, *The Sandwich Theorem*, Electron. J. Combin. 1 (1994), #A1, arXiv:math/9312214v1, Lemma 2.
