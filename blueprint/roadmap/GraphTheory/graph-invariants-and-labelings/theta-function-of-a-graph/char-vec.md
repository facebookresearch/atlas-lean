# Characteristic vector of a vertex set

For $S \subseteq V$, the characteristic vector $\chi^S \in \mathbb{R}^V$ has $\chi^S_v = 1$ for $v \in S$ and $\chi^S_v = 0$ otherwise. Knuth calls it the characteristic labeling of $S$; for a stable set it is a stable labeling, for a clique a clique labeling.

## Sources

- D. E. Knuth, *The Sandwich Theorem*, Electron. J. Combin. 1 (1994), #A1, arXiv:math/9312214v1, §2.
