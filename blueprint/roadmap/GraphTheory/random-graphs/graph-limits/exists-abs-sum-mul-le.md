# Weighted sums are bounded by subset sums

Let $s$ be a finite set and $a, g$ real functions with $0 \le a(x) \le 1$ for every $x$. Then there is $S \subseteq s$ with

$$\Big\lvert \sum_{x \in s} a(x)\, g(x) \Big\rvert \le \Big\lvert \sum_{x \in S} g(x) \Big\rvert,$$

for instance the set of $x \in s$ where $g(x)$ has the sign of the weighted sum.
