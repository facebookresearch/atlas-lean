# Measure-preserving maps of the unit interval

The measure-preserving maps of the unit interval are the maps $\varphi : \mathbb{R} \to \mathbb{R}$ that are measurable and carry Lebesgue measure restricted to $[0, 1]$ to itself: $\lambda(\varphi^{-1}(B) \cap [0, 1]) = \lambda(B \cap [0, 1])$ for every Borel set $B$.
