# Weight of a map into a weighted graph

Let $F$ be a simple graph on a finite set $A$, $V$ a finite set and $w$ a real weight on the unordered pairs of $V$. The weight of a map $\varphi : A \to V$ is

$$\hom_\varphi(F, w) = \prod_{ij \in E(F)} w(\varphi(i), \varphi(j))$$

(Lovász–Szegedy, *Limits of dense graph sequences*, §2.1, $\hom_\varphi(F, G)$ with node weights $1$).
