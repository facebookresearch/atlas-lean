# Uniqueness of the limit

Two graphons $U, W$ with values in $[0, 1]$ satisfy $\delta_\square(U, W) = 0$ if and only if $t(F, U) = t(F, W)$ for every simple graph $F$. So the graphon limit of a convergent graph sequence is unique up to cut distance $0$ (weak isomorphism).
