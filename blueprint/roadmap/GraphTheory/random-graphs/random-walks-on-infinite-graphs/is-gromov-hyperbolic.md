# Gromov hyperbolic graph

Let $G$ be a simple graph on a vertex set $V$. $G$ is Gromov hyperbolic when there is a real $\delta$ such that $(x \mid z)_w \ge \min\{(x \mid y)_w, (y \mid z)_w\} - \delta$ for all vertices $x, y, z, w$, where $(x \mid y)_w = \tfrac12(d(x, w) + d(y, w) - d(x, y))$ for the graph distance $d$, which is taken as $0$ between vertices in different components (see the [Gromov product](gromov-product.md)).
