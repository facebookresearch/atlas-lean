# Bipartition number of a graph

For a simple graph $G$, the bipartition number $\tau(G)$ of a simple graph $G$ is the least $k$ such that $G$ is the union of $k$ pairwise edge-disjoint complete bipartite subgraphs, each with two nonempty sides: there are subgraphs $B_1, \dots, B_k \le G$, each complete bipartite with nonempty sides, whose edge sets are pairwise disjoint and together equal the edge set of $G$. It is $0$ if no such $k$ exists; the graph with no edges has $\tau = 0$.
