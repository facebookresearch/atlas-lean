# Block-model graph law as a probability mass function

For a finite linearly ordered vertex set $V$, a finite set of classes $K$ and admissible block-model parameters $(p, W)$, the block-model graph law is the probability mass function on simple graphs $G$ on $V$ with mass the block-model graph weight $\sum_{z : V \to K} \prod_v p_{z(v)} \cdot (\text{edge factor of } z \text{ at } G)$; admissibility makes these weights nonnegative and summing to one.
