# Prior weight of a block-model labeling

For a finite vertex set $V$, a finite set of classes $K$, real class weights $p \in \mathbb{R}^K$ and a labeling $z : V \to K$, the prior weight of $z$ is $\prod_{v \in V} p_{z(v)}$. When $p$ is a probability vector it is the probability of $z$ when each vertex draws its class independently with law $p$.
