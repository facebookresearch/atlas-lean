# Covariance matrix of an exponential random graph model

For a finite vertex set $V$, a statistic $t$ assigning to each simple graph $G$ on $V$ a vector $t(G) \in \mathbb{R}^\iota$ over a finite index set $\iota$, and $\theta \in \mathbb{R}^\iota$, the covariance matrix of the statistic under the exponential random graph law is $\Sigma_{jk}(\theta) = \sum_G P_\theta(G)\, (t_j(G) - \mu_j(\theta))(t_k(G) - \mu_k(\theta))$, where $\mu(\theta)$ is the mean statistic.
