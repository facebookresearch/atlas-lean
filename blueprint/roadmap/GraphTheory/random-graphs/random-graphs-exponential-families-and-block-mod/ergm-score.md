# Score of an exponential random graph model

For a finite vertex set $V$, a statistic $t$ of simple graphs on $V$ with values in $\mathbb{R}^\iota$ for a finite index set $\iota$, $\theta \in \mathbb{R}^\iota$ and a graph $y$, the score of the exponential random graph model is the observed statistic minus its mean, $U(\theta; y) = t(y) - \mu(\theta)$. Its zero set is the moment equation (Snijders 2002, equation (24)).
