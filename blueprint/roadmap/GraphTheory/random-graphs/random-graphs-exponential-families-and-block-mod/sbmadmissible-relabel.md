# Admissibility of block-model parameters is preserved under relabeling

Let $K$ be a finite set of classes and $\sigma$ a permutation of $K$. If the block-model parameters $(p, W)$ are admissible (positive class probabilities summing to one and a symmetric affinity matrix with entries in $[0, 1]$), then so are the relabeled parameters $(p \circ \sigma, (W_{\sigma(i)\sigma(j)})_{i,j})$.
