# Relabeled admissible parameters give the same block-model law

Let $V$ be a finite linearly ordered vertex set, $K$ a finite set of classes and $\sigma$ a permutation of $K$. For admissible block-model parameters $(p, W)$, the relabeled parameters $(p \circ \sigma, (W_{\sigma(i)\sigma(j)})_{i,j})$ are admissible and give the same block-model graph law on $V$.
