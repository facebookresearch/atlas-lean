# Normalizing constant of an exponential random graph model

For a finite vertex set $V$, a statistic $t$ assigning to each simple graph $G$ on $V$ a vector $t(G) \in \mathbb{R}^\iota$ over a finite index set $\iota$, and $\theta \in \mathbb{R}^\iota$, the normalizing constant of the exponential random graph model is $\kappa(\theta) = \sum_G e^{\langle\theta, t(G)\rangle}$, the sum over all simple graphs on $V$; it is $e^{\psi(\theta)}$ with $\psi = \log \kappa$ the log-normalizer.
