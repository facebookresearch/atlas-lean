# Mean statistic of an exponential random graph model

For a finite vertex set $V$, a statistic $t$ of simple graphs on $V$ with values in $\mathbb{R}^\iota$ for a finite index set $\iota$, and $\theta \in \mathbb{R}^\iota$, the mean statistic of the exponential random graph model is $\mu_k(\theta) = \sum_G P_\theta(G)\, t_k(G)$ for each $k \in \iota$.
