# Exponential random graph law as a probability mass function

For a finite vertex set $V$, a statistic $t$ of simple graphs on $V$ with values in $\mathbb{R}^\iota$ for a finite index set $\iota$, and $\theta \in \mathbb{R}^\iota$, the exponential random graph law as a probability mass function on simple graphs gives each graph $G$ the mass $P_\theta(G) = e^{\langle\theta, t(G)\rangle} / \sum_H e^{\langle\theta, t(H)\rangle}$; these masses are positive and sum to one.
