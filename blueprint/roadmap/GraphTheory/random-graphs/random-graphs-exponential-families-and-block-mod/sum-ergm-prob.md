# Exponential random graph probabilities sum to one

For a finite vertex set $V$, a statistic $t$ of simple graphs on $V$ with values in $\mathbb{R}^\iota$ for a finite index set $\iota$, and every $\theta \in \mathbb{R}^\iota$, the exponential random graph probabilities $P_\theta(G) = e^{\langle\theta, t(G)\rangle}/\sum_H e^{\langle\theta, t(H)\rangle}$ sum to $1$ over all simple graphs $G$ on $V$.
