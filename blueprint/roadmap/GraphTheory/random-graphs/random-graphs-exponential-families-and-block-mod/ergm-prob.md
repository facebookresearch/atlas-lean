# Exponential-family random graph law

For a finite vertex set $V$, a statistic $t$ assigning to each simple graph $G$ on $V$ a vector $t(G) \in \mathbb{R}^\iota$ over a finite index set $\iota$, and $\theta \in \mathbb{R}^\iota$, the exponential-family random graph law gives $G$ the probability $P_\theta(G) = e^{\langle\theta, t(G)\rangle} / \kappa(\theta)$, where $\kappa(\theta) = \sum_H e^{\langle\theta, t(H)\rangle}$ is the sum over all simple graphs on $V$.
