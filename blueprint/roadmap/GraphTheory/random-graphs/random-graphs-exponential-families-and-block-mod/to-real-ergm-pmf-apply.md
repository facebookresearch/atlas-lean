# Real values of the exponential random graph law

For a finite vertex set $V$, a statistic $t$ of simple graphs on $V$ with values in $\mathbb{R}^\iota$ for a finite index set $\iota$, $\theta \in \mathbb{R}^\iota$ and a graph $G$, the real value of the mass that the exponential random graph law, as a probability mass function, gives to $G$ is the probability $P_\theta(G) = e^{\langle\theta, t(G)\rangle}/\sum_H e^{\langle\theta, t(H)\rangle}$.
