# Identifiability of exponential random graph models

Let $V$ be a finite vertex set and $t$ a statistic assigning to each simple graph $G$ on $V$ a vector $t(G) \in \mathbb{R}^\iota$ over a finite index set $\iota$. The map $\theta \mapsto P_\theta$ from parameters to exponential random graph laws is injective if and only if the statistic has no affine dependence: whenever $\langle v, t(G)\rangle = c$ for all graphs $G$, with one constant $c$, then $v = 0$.
