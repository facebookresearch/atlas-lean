# Coordinate derivative of the exponential random graph log-likelihood

For a finite vertex set $V$, a statistic $t$ of simple graphs on $V$ with values in $\mathbb{R}^\iota$ for a finite index set $\iota$, $\theta \in \mathbb{R}^\iota$, a graph $y$ and a coordinate $k$, the log-likelihood $\ell(\theta; y)$ as a function of the $k$-th coordinate of $\theta$ alone is differentiable at $\theta_k$ with derivative $U_k(\theta; y) = t_k(y) - \mu_k(\theta)$, the $k$-th coordinate of the score.
