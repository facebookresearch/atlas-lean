# Values of the block-model law as a probability mass function

For a finite linearly ordered vertex set $V$, a finite set of classes $K$ and admissible block-model parameters $(p, W)$, the block-model graph law as a probability mass function gives each simple graph $G$ on $V$ the mass equal to its block-model graph weight $\sum_{z : V \to K} \prod_v p_{z(v)} \cdot (\text{edge factor of } z \text{ at } G)$, read as an extended nonnegative real.
