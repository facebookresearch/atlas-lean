# Moment equation of an exponential random graph model

For a finite vertex set $V$, a statistic $t$ of simple graphs on $V$ with values in $\mathbb{R}^\iota$ for a finite index set $\iota$, $\theta \in \mathbb{R}^\iota$ and a graph $y$, the score $t(y) - \mu(\theta)$ of the exponential random graph model vanishes if and only if the observed statistic equals its mean, $t(y) = \mu(\theta)$: the moment equation.
