# Edge-disjoint Hamilton cycles

A simple graph $G$ on $\{0, \dots, n-1\}$ contains $r$ pairwise edge-disjoint Hamilton cycles when there are closed walks $C_1, \dots, C_r$ in $G$, each a Hamiltonian cycle (a cycle through every vertex exactly once), such that no edge of $C_i$ is an edge of $C_j$ for $i \ne j$.
