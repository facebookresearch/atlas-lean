# The threshold probabilities exist

For every $c \in \mathbb{R}$ there is a sequence $p_n \in [0, 1]$ with $p_n = (\log n + c)/n$ for all large $n$. Clip $(\log n + c)/n$ to $[0, 1]$; for large $n$ the value already lies in $[0, 1]$. The hypotheses of the connectivity statements in this folder are therefore satisfiable, for every $c$.
