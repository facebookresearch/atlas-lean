# The exact threshold sequence satisfies $n p_n - \log n \to c$

If $p_n = (\log n + c)/n$ for all large $n$, then $n p_n - \log n = c$ for all large $n$, so in particular $n p_n - \log n \to c$. The statements proved under the general hypothesis $n p_n - \log n \to c$ therefore apply to the exact threshold sequence.
