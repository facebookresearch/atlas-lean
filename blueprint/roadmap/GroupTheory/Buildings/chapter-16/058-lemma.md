# Lemma (Chapter 16, Section 16.6)

Let $\lambda$ be an affine functional on an apartment $A'$ in the thick affine building $X$ which vanishes on a wall $\eta$ in $A'$. Then either $\lambda$ is bounded above, or is bounded below on the sector $\mathcal{C}'$. That is, either there is a constant $\lambda_o$ so that $\lambda(z) \leq \lambda_o$ for all $z \in \mathcal{C}'$, or else there is a constant $\lambda_o$ so that $\lambda(z) \geq \lambda_o$ for all $z \in \mathcal{C}'$.
