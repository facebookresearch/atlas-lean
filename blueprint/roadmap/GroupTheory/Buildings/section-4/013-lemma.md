# Lemma (Section 4.1)

Let $X$ be a thick building with apartment system $\mathcal{A}$. If two apartments $A$, $A' \in \mathcal{A}$ both contain a chamber $C$, then there is a chamber-complex isomorphism $\varphi \colon A \to A'$ which fixes $A \cap A'$ pointwise.
