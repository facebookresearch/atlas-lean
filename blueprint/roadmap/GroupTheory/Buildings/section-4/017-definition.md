# Definition (Section 4.4)

In a simplicial complex $X$, the link $\operatorname{lk}_X(x)$ of a simplex $x$ is defined to be the subcomplex of $X$ consisting of simplices $y$ so that, on one hand, there is no simplex $z$ so that $z \leq x$ and $z \leq y$, but there is a simplex $w$ so that $w \geq x$ and $w \geq y$.
