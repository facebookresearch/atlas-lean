# Definition (Coxeter system of type A_{n-1})

The symmetric group $S_n$ is a Coxeter group, generated by adjacent transpositions $\alpha_j = (j,\, j{+}1)$. The 3-cycle $\alpha_j \alpha_{j+1}$ has order 3, and $\alpha_i \alpha_j = \alpha_j \alpha_i$ if $|i - j| \neq 1$. This is the Coxeter system of type $A_{n-1}$.
