# Theorem (Section 18.3)

Let $k$ be a complete ultrametric field with valuation ring $o$. Let $f(x)$ be a non-constant polynomial with coefficients in $o$. Let $x_o \in o$ so that $|f(x_o)| < 1$ and $|f'(x_o)| = 1$. Then the sequence $x_1, x_2, x_3, \ldots$ defined recursively by $x_{n+1} = x_n - f(x_n) / f'(x_n)$ converges to a root of the equation $f(x) = 0$.
