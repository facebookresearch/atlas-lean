# Proposition (Negative Curvature Inequality)

Let $X$ be an affine building with canonical metric $d = d_X$. For $x, y, z \in |X|$, let $z_t = tx + (1 - t)y$. Then $d^2(z, z_t) \leq t\, d^2(z, x) + (1 - t)\, d^2(z, y) - t(1 - t)\, d^2(x, y)$.
