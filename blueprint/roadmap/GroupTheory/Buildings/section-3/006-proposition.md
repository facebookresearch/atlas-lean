# Proposition (Section 3.3)

Let $f$ be a reversible folding. Let $C, C'$ be adjacent chambers so that $C \in \Phi$ and $C' \notin \Phi$. Then $\Phi$ is the set of chambers $D$ so that $d(C, D) < d(C', D)$.
