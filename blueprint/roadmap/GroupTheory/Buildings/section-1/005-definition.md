# Definition (Section 1.8)

For $v, w \in W$ write $v \to w$ if there is $t \in T$ so that $vt = w$ and $\ell(v) < \ell(w)$. Define the Bruhat order $<$ by saying that $v < w$ if there is a sequence $v = w_0 \to w_1 \to w_2 \to \cdots \to w_n = w$.
