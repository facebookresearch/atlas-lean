# Theorem (Section 1 (Bruhat order context))

Let $w = s_1 \cdots s_n$ be a fixed reduced expression of $w \in W$. Then $v \leq w$ if and only if $v$ can be obtained as a subexpression of $s_1 \cdots s_n$, that is, if and only if $v$ can be written in the form $v = s_{i_1} \cdots s_{i_m}$ where $1 \leq i_1 < i_2 < \cdots < i_m \leq n$.
