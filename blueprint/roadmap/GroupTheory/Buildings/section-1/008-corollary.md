# Corollary (Section 1 (Bruhat order context))

Let $v < w$ in $W$. Then there are elements $w_1, \ldots, w_n$ in $W$ so that $v = w_1 < \cdots < w_n = w$ and $\ell(w_i) + 1 = \ell(w_{i+1})$ for all $i$.
