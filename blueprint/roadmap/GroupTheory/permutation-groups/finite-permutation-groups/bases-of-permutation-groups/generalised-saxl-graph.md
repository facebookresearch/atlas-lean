# The generalised Saxl graph

For a group $G$ of permutations of a set $\Omega$, the generalised Saxl graph of $G$ is the simple graph on $\Omega$ in which distinct points $\alpha$ and $\beta$ are adjacent when some minimum base of $G$ contains both. A minimum base is a finite set $B \subseteq \Omega$ whose pointwise stabilizer in $G$ is trivial and whose size is minimal among all such sets. When the minimum base size is $2$ this is the Saxl graph of Burness and Giudici.
