# Free soluble groups of rank two have test elements

For every $d > 2$, the free soluble group $F_2/F_2^{(d)}$ of rank $2$ and derived length $d$ has a
test element: an element $u$ such that every endomorphism of the group that fixes $u$ is an
automorphism.

This answers Kourovka Problem 14.88 (B. Fine, V. Shpilrain): the Kourovka Archive answers "Yes, it
does" (Timoshenko).
