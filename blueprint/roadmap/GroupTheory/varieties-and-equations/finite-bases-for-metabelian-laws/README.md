# Finite bases for metabelian laws

A group $H$ satisfies a single law $w$, an element of the free group on $x_0, x_1, x_2, \dots$, when $w(h_0, h_1, \dots) = 1$ for every sequence $h_0, h_1, \dots \in H$. This is the case $W = \{w\}$ of [groups satisfying a set of laws](../test-ranks-of-relatively-free-groups/satisfies-laws.md): $H$ satisfies $w$ exactly when it satisfies the set $\{w\}$, since the homomorphisms from the free group to $H$ are exactly the maps sending each $x_i$ to some $h_i$.
