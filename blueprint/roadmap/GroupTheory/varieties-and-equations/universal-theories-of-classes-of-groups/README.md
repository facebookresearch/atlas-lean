# Universal theories of classes of groups

The universal theory of a class of groups is the set of universal first-order sentences true in every group of the class. These pages record classes whose universal theory is undecidable.

- [The universal theory of groups of a fixed large odd composite exponent is undecidable](universal-theory-torsion-classes-undecidable.md)
- [The universal theory of hyperbolic groups is undecidable](universal-theory-hyperbolic-groups-undecidable.md)
- [The universal theory of finite solvable groups of derived length at most 3 is undecidable](universal-theory-finite-solvable-groups-undecidable.md)
