# Values of a word

For a word $v$ in the free group on $n$ generators and a group $G$, the
set of values of $v$ on $G$ is the set of elements $v(g_1, \dots, g_n)$ obtained by substituting
elements $g_1, \dots, g_n \in G$ for the generators, that is, the set of images of $v$ under all
homomorphisms from that free group to $G$.
