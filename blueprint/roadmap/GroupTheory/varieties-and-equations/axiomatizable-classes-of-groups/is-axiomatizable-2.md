# Classes of groups defined by a first-order theory

A class $K$ of groups is axiomatizable when there is a theory $T$ in the first-order language of
groups such that a group $G$ belongs to $K$ if and only if $G$ is a model of $T$. The definition is
the same as that of [first-order axiomatizable classes of groups](is-axiomatizable.md); it is stated
again for the question on homomorphic images.
