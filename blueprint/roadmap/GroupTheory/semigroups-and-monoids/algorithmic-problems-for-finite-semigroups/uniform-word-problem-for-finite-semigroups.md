# The uniform word problem for finite semigroups is undecidable

No algorithm decides, given finitely many semigroup relations and one more relation, whether the latter holds in every finite semigroup satisfying the former; equivalently, the universal theory of finite semigroups is undecidable.

Quasi-identities and the *uniform word problem* for a class $\mathcal K$ of semigroups (given a quasi-identity, does it hold in every semigroup of $\mathcal K$?) are defined on the page on [semigroup presentations](../decision-problems-in-semigroups/semigroup-presentations-and-the-word-problem.md). Since the finite semigroups form a class closed under subsemigroups, the problem here asks, equivalently, whether $U = V$ in every finite semigroup generated by elements satisfying $L$.

**Theorem (Gurevich, 1966).** The uniform word problem for the class of finite semigroups is undecidable. Equivalently, the universal theory of finite semigroups is undecidable.

Each single finite semigroup has decidable word problem; the theorem says there is no algorithm uniform over all of them. Sapir characterized, for every variety $\mathcal V$ of semigroups defined by finitely many identities, when the uniform word problem for the finite members of $\mathcal V$ is decidable; Gurevich's theorem is the case of the variety of all semigroups.

## Expansion

The proof simulates a two-counter (Minsky) machine $M$ in a finitely presented semigroup with an extra counter that counts how often the first counter is emptied, the counter being a subgroup isomorphic to $\mathbb Z$. For the quasi-identity $L \to W = 0$, where $L$ is the conjunction of the defining relations and $W$ encodes the input configuration $(1; 2^m, 0)$: if $M$ accepts this input, only finitely many elements divide $W$, which yields a finite semigroup satisfying $L$ in which $W \ne 0$; if $M$ runs forever, every periodic semigroup satisfying $L$ has $W = 0$. So the quasi-identities that fail in some finite semigroup are recursively inseparable from those that hold in every periodic semigroup, using a Minsky machine whose set of accepted inputs is not recursive. A good expansion links the finiteness of the set of divisors of $W$ for accepting runs and the existence of the required Minsky machine (Theorem 2.3 of the survey).
