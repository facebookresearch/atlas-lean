# Whether a matrix semigroup contains a nonnegative matrix is undecidable

No algorithm decides whether the semigroup generated by finitely many given square matrices with rational entries contains a matrix all of whose entries are nonnegative; for commuting generators the problem is decidable assuming Schanuel's conjecture.

Use the semigroup generated by finitely many matrices from the [decision problems for finitely generated matrix semigroups](decision-problems-for-matrix-semigroups.md). A matrix is *nonnegative* if all its entries are nonnegative. The *nonnegative membership problem* asks, given $d \times d$ matrices $M_1, \dots, M_k$ with rational entries, whether $\langle M_1, \dots, M_k \rangle$ contains a nonnegative matrix; the dimension $d$ and the number $k$ of generators are part of the input.

**Theorem (D'Costa, Ouaknine and Worrell).** The nonnegative membership problem is undecidable (Theorem 21).

By contrast, the source shows that the problem is decidable when $M_1, \dots, M_k$ commute, subject to Schanuel's conjecture, and that it is decidable whether the powers of a single matrix are ultimately nonnegative.

## Expansion

The proof reduces the threshold problem for probabilistic automata: given stochastic matrices $A_1, \dots, A_k \in \mathbb{Q}^{d \times d}$ and vectors $u, v \in \mathbb{Q}^d$, is there a product $A$ of the $A_i$ with $u^{\mathsf{T}} A v \geq 1/2$? From such an instance one builds $(d + 2) \times (d + 2)$ matrices $U$, $A'_1, \dots, A'_k$ and $V$, each with first row starting $(1, -1/2)$, where $A'_i$ carries $A_i$ in its lower right block and $U$ and $V$ carry $u$ and $v$. Every product that does not end with a factor $U A'_{i_1} \cdots A'_{i_s} V$ has entry $-1/2$ in position $(1, 2)$; for those that do, that entry is $u^{\mathsf{T}} A_{i_1} \cdots A_{i_s} v - 1/2$, the $(1, 1)$ entry is $1$ and all other entries are $0$. So the new semigroup contains a nonnegative matrix exactly when the threshold instance is positive.
