# Navas's Question 4 (groups all of whose fixed-point-free orientation-preserving line actions are globally contracting)

The proposition that there is an infinite finitely generated group $G$ that has an action on $\mathbb{R}$ by orientation-preserving (non-decreasing) homeomorphisms without a global fixed point (every $x$ is moved by some element), and all of whose actions on $\mathbb{R}$ by orientation-preserving homeomorphisms without a global fixed point are of type (iii).

An action $\rho$ of a group $G$ on $\mathbb{R}$ by homeomorphisms is of type (iii) (globally contracting) if there are an action $\psi$ of $G$ on $\mathbb{R}$ by non-decreasing (orientation-preserving) homeomorphisms and a continuous non-decreasing map $\varphi : \mathbb{R} \to \mathbb{R}$ with $\varphi(x) \to \pm\infty$ as $x \to \pm\infty$ such that $\varphi(\rho(g)x) = \psi(g)\varphi(x)$ for all $g, x$, the action $\psi$ is minimal (every orbit is dense), and for all reals $a, b$ there is a point $x$ such that for every $\varepsilon > 0$ some $g \in G$ maps $[a, b]$ into $(x - \varepsilon, x + \varepsilon)$ under $\psi(g)$.

Source: A. Navas, Group actions on 1-manifolds: a list of very concrete open questions, Proceedings of the International Congress of Mathematicians 2018, Vol. 2, World Scientific (2018), 2029-2056, arXiv:1712.06462, Question 4.
