# C^(1+α) diffeomorphisms of the circle

For a real $\alpha$, a homeomorphism $f$ of the circle $\mathbb{R}/\mathbb{Z}$ is an orientation-preserving $C^{1+\alpha}$ diffeomorphism if there is a $C^1$ function $F : \mathbb{R} \to \mathbb{R}$ with $f(x + \mathbb{Z}) = F(x) + \mathbb{Z}$ for all real $x$, $F(x + 1) = F(x) + 1$, $F'(x) > 0$ for all $x$, and, for some constant $C$, $|F'(x) - F'(y)| \le C\,|x - y|^{\alpha}$ for all real $x, y$.

Source: A. Navas, Group actions on 1-manifolds: a list of very concrete open questions, Proceedings of the International Congress of Mathematicians 2018, Vol. 2, World Scientific (2018), 2029-2056, arXiv:1712.06462, Question 13.
