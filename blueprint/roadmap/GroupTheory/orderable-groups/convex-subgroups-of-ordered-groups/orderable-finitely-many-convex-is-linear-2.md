# Ordered groups with finitely many convex subgroups need not be linear

There is a group admitting an ordering with only finitely many convex subgroups that has no injective homomorphism into $\mathrm{GL}_n(K)$ for any field $K$ and any $n$. An ordering of a group is a strict total order $<$ with $b < c \Rightarrow ab < ac$ and $ba < ca$ for all $a$; a subgroup $H$ is convex if $h_1 < g < h_2$ with $h_1, h_2 \in H$ implies $g \in H$. This answers Kourovka Problem 2.31 negatively. It is the negation of the proposition on [Kourovka Problem 2.31 (ordered groups with finitely many convex subgroups)](orderable-finitely-many-convex-is-linear.md).

Source: E. I. Khukhro and V. D. Mazurov (eds.), Unsolved Problems in Group Theory: The Kourovka Notebook, 21st issue, arXiv:1401.0300v49 (2026), Archive of Solved Problems, Problem 2.31 (V. M. Kopytov); resolution: V. A. Churkin (1969), as recorded in the Kourovka Archive.
