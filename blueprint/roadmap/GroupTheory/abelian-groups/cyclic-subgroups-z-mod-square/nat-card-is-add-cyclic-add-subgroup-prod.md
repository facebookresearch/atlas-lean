# Nat Card is Add Cyclic add Subgroup prod eq dedekind Psi

Let $n$ be a positive integer. The number of subgroups $H \le (\mathbb{Z}/n\mathbb{Z}) \times (\mathbb{Z}/n\mathbb{Z})$ that are cyclic of order $|H| = n$ equals the Dedekind psi function

$$\psi(n) = \prod_{p^k \parallel n} p^{k-1} (p + 1),$$

the product running over the primes $p$ dividing $n$, with $p^k$ the exact power of $p$ dividing $n$.
