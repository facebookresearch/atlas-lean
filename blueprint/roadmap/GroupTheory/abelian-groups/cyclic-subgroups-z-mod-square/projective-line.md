# Projective Line

Let $R$ be a commutative ring. The projective line $\mathbb{P}^1(R)$ is the quotient of the set of unimodular rows over $R$ (pairs $(a, c) \in R \times R$ with $x a + y c = 1$ for some $x, y \in R$) by the equivalence relation

$$(a, c) \sim (a', c') \iff \text{there is a unit } u \in R^\times \text{ with } u a = a' \text{ and } u c = c'.$$
