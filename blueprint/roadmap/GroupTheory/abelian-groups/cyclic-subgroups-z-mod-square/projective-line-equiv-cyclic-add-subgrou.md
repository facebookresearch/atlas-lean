# Projective Line Equiv Cyclic Add Subgroup

Let $N$ be a positive integer. The map $[v] \mapsto \langle v \rangle$, sending the class of a unimodular row $v$ to the subgroup it generates, is a bijection from the projective line $\mathbb{P}^1(\mathbb{Z}/N\mathbb{Z})$ onto the set of subgroups $H \le (\mathbb{Z}/N\mathbb{Z})^2$ that are cyclic of order $|H| = N$.
