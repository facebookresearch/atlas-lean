# Map

Let $R$ and $S$ be commutative rings and $f : R \to S$ a ring homomorphism. The induced map $\mathbb{P}^1(R) \to \mathbb{P}^1(S)$ sends the class of a unimodular row $(a, c)$ to the class of $(f(a), f(c))$, which is again unimodular since $x a + y c = 1$ gives $f(x) f(a) + f(y) f(c) = 1$. The map is well defined because $(u a, u c)$ with $u \in R^\times$ is sent to $(f(u) f(a), f(u) f(c))$ and $f(u) \in S^\times$.
