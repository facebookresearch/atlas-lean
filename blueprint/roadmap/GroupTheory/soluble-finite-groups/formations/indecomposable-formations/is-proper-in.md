# A class that omits a finite group of $\mathfrak{F}_T$

For a group $T$ and a class $\mathfrak{X}$ of groups, this is the property that $\mathfrak{X}$ does
not contain all of $\mathfrak{F}_T$: some finite group with a subnormal series all of whose factors
are isomorphic to $T$ does not belong to $\mathfrak{X}$. It does not assert that $\mathfrak{X}$ is
contained in $\mathfrak{F}_T$; for a class $\mathfrak{X} \subseteq \mathfrak{F}_T$, as in Kourovka
Problem 12.97, it says that $\mathfrak{X}$ is a proper subclass of $\mathfrak{F}_T$.
