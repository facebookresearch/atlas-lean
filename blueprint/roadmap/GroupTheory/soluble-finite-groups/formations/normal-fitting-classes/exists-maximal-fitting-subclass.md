# Fitting classes maximal in the smallest normal Fitting class (Kourovka 9.18)

The statement (Kourovka Problem 9.18, H. Lausch) that some Fitting class is maximal in the [smallest normal Fitting class](in-smallest-normal-fitting-class.md) $\mathfrak{S}_*$. Precisely: there is a [Fitting class of finite soluble groups](is-soluble-fitting-class.md) $\mathfrak{X}$ such that every finite group in $\mathfrak{X}$ lies in $\mathfrak{S}_*$, some finite group in $\mathfrak{S}_*$ is not in $\mathfrak{X}$, and for every Fitting class of finite soluble groups $\mathfrak{Y}$ whose finite members satisfy $\mathfrak{X} \subseteq \mathfrak{Y} \subseteq \mathfrak{S}_*$, either $\mathfrak{Y} \subseteq \mathfrak{X}$ or $\mathfrak{S}_* \subseteq \mathfrak{Y}$, again on finite members. All inclusions compare finite members only.

The answer is no: [no Fitting class is maximal in the smallest normal Fitting class](exists-maximal-fitting-subclass-refuted.md).
