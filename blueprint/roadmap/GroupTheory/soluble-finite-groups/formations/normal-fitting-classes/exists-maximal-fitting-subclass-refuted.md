# No Fitting class is maximal in the smallest normal Fitting class

There is no Fitting class of finite soluble groups that is maximal in the [smallest normal Fitting class](in-smallest-normal-fitting-class.md) $\mathfrak{S}_*$: for every [Fitting class of finite soluble groups](is-soluble-fitting-class.md) $\mathfrak{X}$ whose finite members lie in $\mathfrak{S}_*$ and which misses some finite group of $\mathfrak{S}_*$, there is a Fitting class of finite soluble groups strictly between $\mathfrak{X}$ and $\mathfrak{S}_*$, on finite members. This answers [Kourovka Problem 9.18](exists-maximal-fitting-subclass.md) in the negative.

The Kourovka Archive answers Problem 9.18 "No, there are no such classes", citing Vorob'ev.

## Sources

- E. I. Khukhro and V. D. Mazurov (eds.), Unsolved Problems in Group Theory: The Kourovka Notebook, 21st issue, arXiv:1401.0300v49 (2026), Archive of Solved Problems, Problem 9.18 (H. Lausch): No, there are no such classes.
- N. T. Vorob'ev, Dokl. Akad. Nauk Belorus. SSR 35 (1991), no. 6, 485-487 (Russian).
