# The smallest normal Fitting class

A group $G$ lies in the smallest normal Fitting class $\mathfrak{S}_*$ if $G$ lies in every [normal Fitting class](is-normal-fitting-class.md); that is, $\mathfrak{S}_*$ is the intersection of all normal Fitting classes. The membership is used for finite groups $G$.

The normal Fitting classes are exactly the Fitting classes $\mathfrak{X}$ of finite soluble groups with $\mathfrak{X}^* = \mathfrak{S}$, in Lockett's notation, where $\mathfrak{S}$ is the class of all finite soluble groups (Reifferscheid, Theorem 3.1.3, citing Doerk and Hawkes). So this intersection is the class $\mathfrak{S}_*$ of Lausch's problem, defined as the intersection of the Fitting classes $\mathfrak{X}$ with $\mathfrak{X}^* = \mathfrak{S}$.

## Sources

- S. Reifferscheid, On the theory of Fitting classes of finite soluble groups, Dissertation, Universität Tübingen, 2002, Section 1.2 and Theorem 3.1.3 (citing K. Doerk and T. Hawkes, Finite Soluble Groups, de Gruyter, 1992, X.3.7).
