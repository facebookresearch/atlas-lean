# Supersoluble groups via cyclic normal series

A group $G$ is supersoluble if there are a
natural number $k$ and subgroups $1 = S_0 \le S_1 \le \cdots \le S_k = G$, each normal in $G$, such
that for every $i < k$ we have $S_i \le S_{i+1}$ and there is an element $x \in S_{i+1}$ such that
$S_{i+1}$ is generated by $x$ and $S_i$; that is, every factor $S_{i+1}/S_i$ is cyclic.
