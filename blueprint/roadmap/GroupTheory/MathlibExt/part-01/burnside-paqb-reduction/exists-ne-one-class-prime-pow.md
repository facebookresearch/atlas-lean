# Exists ne one class prime pow

A Sylow-center element has prime-power conjugacy class. From `|G| = p^a q^b`
with `b ≥ 1`, get `g ≠ 1` in the center of a Sylow `q`-subgroup whose class has
size `p^k`, `k ≤ a`.
