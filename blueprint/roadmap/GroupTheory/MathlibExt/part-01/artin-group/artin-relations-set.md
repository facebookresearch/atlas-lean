# Artin Relations Set

The set of Artin relations of `M`: one braid relation for each ordered pair of distinct
generators whose off-diagonal entry is finite (`M i j ≠ 0`, i.e. `m i j ≠ ∞`). Pairs with
`M i j = ∞` contribute no relation.
