# A finitely generated branch group with solvable word problem and unsolvable conjugacy problem

There exist finitely generated branch groups with solvable word problem and unsolvable conjugacy problem, answering a question of Bartholdi, Grigorchuk and Šunić.

A [branch group](../maximal-subgroups-of-branch-groups/is-branch-group-2.md) is a group isomorphic to a subgroup of the automorphism group of a spherically homogeneous rooted tree that acts spherically transitively and in which, for every level, the subgroup generated by the rigid stabilizers of the vertices of that level has finite index.

**Theorem.** There exist finitely generated branch groups with solvable word problem and unsolvable conjugacy problem (Theorem A of the source).

The source deduces this from a conjugacy-preserving embedding theorem: every finitely generated residually finite group $G$ embeds in a finitely generated branch group $\Gamma$ such that two elements of $G$ are conjugate in $G$ if and only if they are conjugate in $\Gamma$ (a Frattini embedding); if $G$ is moreover recursively presented and effectively residually finite with co-semi-decidable word problem, then $\Gamma$ can be chosen with the same two properties (Theorem B, proved as Theorem 5.4 and Section 6). In particular, if $G$ has unsolvable conjugacy problem, so does the branch group of the construction (Corollary 5.5). Whether every finitely generated residually finite group with solvable word problem embeds in a finitely generated branch group with solvable word problem is left open.

## Expansion

The proof applies the embedding theorem to a group of Miller: a finitely presented residually finite group $H$ with unsolvable conjugacy problem (Miller's theorem, which has no page here). Being finitely presented and residually finite, $H$ is recursively presented and effectively residually finite with co-semi-decidable word problem, so the embedding theorem gives a finitely generated branch group $\Gamma$ that is recursively presented and effectively residually finite with co-semi-decidable word problem, hence has solvable word problem (Corollary 2.3), and in which $H$ is Frattini embedded, hence has unsolvable conjugacy problem. Both Miller's theorem and the embedding theorem are results without pages.
