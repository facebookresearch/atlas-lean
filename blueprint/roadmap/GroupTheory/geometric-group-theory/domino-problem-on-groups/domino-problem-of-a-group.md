# Domino problem of a finitely generated group

The domino problem of a finitely generated group $G$ is the set of finite sets of forbidden patterns, over a finite alphabet, that no coloring of $G$ avoids; $G$ has decidable domino problem when an algorithm decides membership in this set.

Let $G$ be a group with a finite generating set $S$ and let $\mathcal{A}$ be a finite alphabet. A configuration is a map $x\colon G \to \mathcal{A}$, and $G$ acts on the set $\mathcal{A}^G$ of configurations by translation, $(g \cdot x)(h) = x(g^{-1}h)$. A pattern is a map $p\colon F \to \mathcal{A}$ defined on a finite set $F \subseteq G$, its support; it appears in $x$ if some translate $g \cdot x$ agrees with $p$ on $F$. For a set $\mathcal{F}$ of patterns, the subshift

$$
X_{\mathcal{F}} = \{ x \in \mathcal{A}^G : \text{no pattern of } \mathcal{F} \text{ appears in } x \}
$$

is of finite type when $\mathcal{F}$ is finite. Patterns are coded by writing each element of their support as a word over $S \cup S^{-1}$. The domino problem of $G$ is the set

$$
\mathrm{DP}(G) = \{ \langle \mathcal{F} \rangle : \mathcal{F} \text{ a finite set of patterns over some finite alphabet}, \ X_{\mathcal{F}} = \emptyset \}
$$

of codings of finite pattern sets whose subshift is empty; $G$ has decidable domino problem if this set is recursive, and undecidable domino problem otherwise.

## Expansion

For two finite generating sets the two domino problems are many-one equivalent, so decidability is a property of the group; it is also invariant under commensurability, and a group containing a finitely generated subgroup with undecidable domino problem has undecidable domino problem. For $G = \mathbb{Z}^2$ with nearest-neighbour patterns this is the Wang tiling problem. Some sources take instead the set of $\mathcal{F}$ with $X_{\mathcal{F}} \ne \emptyset$, the complement; it has the same decidability, but hardness statements for many-one reductions refer to the convention used.
