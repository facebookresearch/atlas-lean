# Domino problem of a finitely generated group

The domino problem of a finitely generated group $G$ is the set of finite sets of forbidden pattern codings, over a finite alphabet, that no coloring of $G$ avoids; $G$ has decidable domino problem when an algorithm decides membership in this set.

Let $G$ be a group with a finite generating set $S$ and let $\mathcal{A}$ be a finite alphabet. A configuration is a map $x\colon G \to \mathcal{A}$, and $G$ acts on the set $\mathcal{A}^G$ of configurations by translation, $(g \cdot x)(h) = x(g^{-1}h)$. A pattern is a map $p\colon F \to \mathcal{A}$ defined on a finite set $F \subseteq G$, its support; it appears in $x$ if some translate $g \cdot x$ agrees with $p$ on $F$. For a set $\mathcal{F}$ of patterns, the subshift

$$
X_{\mathcal{F}} = \{ x \in \mathcal{A}^G : \text{no pattern of } \mathcal{F} \text{ appears in } x \}
$$

is of finite type when $\mathcal{F}$ is finite.

An algorithm receives patterns as *pattern codings*. A pattern coding over $\mathcal{A}$ is a finite set $c = \{(w_i, a_i)\}_{i \in I}$ of pairs of a word $w_i$ over $S \cup S^{-1}$ and a letter $a_i \in \mathcal{A}$. Writing $\bar{w}$ for the element of $G$ that a word $w$ represents, the coding $c$ *occurs* in $x$ if there is $g \in G$ with $x(g\bar{w}_i) = a_i$ for every $i \in I$. Two words of $c$ may represent the same element while carrying different letters; such an *inconsistent* coding occurs in no configuration. A consistent coding is the coding of the pattern $\bar{w}_i \mapsto a_i$, and it occurs in $x$ exactly when that pattern appears in $x$. For a set $C$ of pattern codings, $X_C$ is the set of configurations in which no coding of $C$ occurs; it depends only on the consistent codings of $C$.

An instance of the domino problem is a pair $(\mathcal{A}, C)$ of a finite alphabet, given by its list of letters, and a finite set $C$ of pattern codings over $\mathcal{A}$, with no promise that the codings are consistent. The domino problem of $G$ is the set

$$
\mathrm{DP}(G) = \{ (\mathcal{A}, C) : C \text{ a finite set of pattern codings over } \mathcal{A}, \ X_C = \emptyset \}
$$

of instances whose subshift is empty; $G$ has decidable domino problem if this set is recursive, and undecidable domino problem otherwise. Deciding in advance whether a coding is consistent can require solving the word problem of $G$, so the instances include inconsistent codings, which add no constraint.

## Expansion

For two finite generating sets the two domino problems are many-one equivalent, so decidability is a property of the group; it is also invariant under commensurability, and a group containing a finitely generated subgroup with undecidable domino problem has undecidable domino problem. For $G = \mathbb{Z}^2$ with nearest-neighbour patterns this is the Wang tiling problem. Some sources take instead the set of $\mathcal{F}$ with $X_{\mathcal{F}} \ne \emptyset$, the complement; it has the same decidability, but hardness statements for many-one reductions refer to the convention used.
