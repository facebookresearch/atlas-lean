# An amenable group with Hilbert space compression below 1/2

There are a finitely generated amenable group $G$, a finite generating set $S$ and a real $\alpha < 1/2$ that is not attained, where an exponent $\alpha$ is attained if there are a separable real Hilbert space $\mathcal{H}$, a map $f : G \to \mathcal{H}$ with $\lVert f(g) - f(h) \rVert \le d_S(g, h)$ for all $g, h$, and constants $C > 0$ and $D \in \mathbb{R}$ with $C\, d_S(g, h)^{\alpha} - D \le \lVert f(g) - f(h) \rVert$ for all $g, h$. $d_S$ denotes the word distance of a finite subset $S \subseteq G$: the graph distance in the Cayley graph of $S$, in which distinct $u, v \in G$ are adjacent when $us = v$ or $vs = u$ for some $s \in S$. Austin constructs a finitely generated amenable group with no such embedding of positive compression exponent into a Hilbert space, so its Hilbert space compression is $0$; this answers Arzhantseva's question positively.

Austin, Amenable groups with very poor compression into Lebesgue spaces, Duke Math. J. 159 (2011), 187-222, DOI 10.1215/00127094-1415860, arXiv:0909.2047, Theorem 1.1.
