# Word-hyperbolic groups

A group $G$ is word-hyperbolic if there are a finite index set $\iota$ and a family $(s_i)_{i \in \iota}$ of elements generating $G$ such that $G$, equipped with the word metric $d(g, h) = |g^{-1} h|$ of this generating family, is $\delta$-hyperbolic for some real number $\delta$.

This is Gromov's Definition 2.1.A. Gromov shows (Corollary 2.3.E) that the choice of the finite generating set does not matter, although $\delta$ does depend on it; see [Hyperbolicity does not depend on the finite generating set](is-delta-hyperbolic-of-is-hyperbolic.md). Finite groups and the infinite cyclic group are word-hyperbolic; $\mathbb{Z}^2$ is not.
