# Bestvina Question 1.12 (finite-index subgroups isomorphic to infinite-index ones)

The proposition that some one-ended hyperbolic group $\Gamma$ has a subgroup $H$ of finite index and a subgroup $K$ of infinite index with $H \cong K$. A group is one-ended if for some finite generating set $S$ its Cayley graph (distinct $u, v$ adjacent when $us = v$ or $vs = u$ for some $s \in S$) has exactly one end. A group is hyperbolic if for some finite generating family its word metric is $\delta$-hyperbolic for some real $\delta$.

Source: M. Bestvina, Questions in Geometric Group Theory (updated July 2004), Q 1.12 (Whyte), https://www.math.utah.edu/~bestvina/eprints/questions-updated.pdf.
