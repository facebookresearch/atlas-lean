# One-ended groups

A group $\Gamma$ is one-ended if there is a finite generating set $S$ of $\Gamma$ such that the Cayley graph of $S$ (distinct $u, v$ adjacent when $us = v$ or $vs = u$ for some $s \in S$) has exactly one end, ends being compatible choices, for every finite set of vertices, of a connected component of its complement. Finite groups have no ends and two-ended groups two, so both are excluded.

Source: M. Bestvina, Questions in Geometric Group Theory (updated July 2004), Q 1.12 (Whyte), https://www.math.utah.edu/~bestvina/eprints/questions-updated.pdf.
