# Claim of Kourovka Problem 16.62

The statement that for every group $G$: if every automorphism of $G$ sends each element $g \in G$ to
a conjugate of $g$ (equivalently, maps every conjugacy class of $G$ into itself), then every
automorphism of $G$ is inner, that is, of the form $x \mapsto h x h^{-1}$ for some $h \in G$.
