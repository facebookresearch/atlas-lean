# Abelian group

An *abelian group* is a group whose operation is commutative. Explicitly, it is a set $G$ with a binary operation $(a, b) \mapsto ab$, an element $1 \in G$ and a map $a \mapsto a^{-1}$ from $G$ to $G$, such that:

- the operation is associative: $(ab)c = a(bc)$ for all $a, b, c \in G$;
- the operation is commutative: $ab = ba$ for all $a, b \in G$;
- $1$ is an identity: $1a = a1 = a$ for every $a \in G$;
- each element has a left inverse: $a^{-1}a = 1$ for every $a \in G$.

These axioms imply $aa^{-1} = 1$ for every $a \in G$.
