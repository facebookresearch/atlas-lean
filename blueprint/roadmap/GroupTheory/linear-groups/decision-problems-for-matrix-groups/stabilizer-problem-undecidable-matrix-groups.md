# The stabilizer problem for finitely generated rational matrix groups is undecidable

For $n \ge 9$, no algorithm decides, for a finitely generated subgroup $G$ of $\mathrm{GL}_n(\mathbb{Q})$ and a vector $u \in \mathbb{Q}^n$, whether some non-identity element of $G$ fixes $u$. This answers a question of Dixon from 1985.

The stabilizer problem on $\mathbb{Q}^n$ is the decision problem

- input: a finite set $X \subseteq \mathrm{GL}_n(\mathbb{Q})$ and a vector $u \in \mathbb{Q}^n$;
- question: is there $g \in \langle X \rangle$ with $g \ne 1$ and $g u = u$?

For $n \ge 9$ the stabilizer problem on $\mathbb{Q}^n$ is undecidable (Theorem 3 of the source). The source proves that the analogous problem over $\mathbb{Z}$, for finitely generated subgroups of $\mathrm{GL}_n(\mathbb{Z})$, is already undecidable. Dixon had shown that the orbit problem (whether some element of $G$ maps $u$ to a given $v$) is undecidable.

## Expansion

Let $G$ be Borisov's torsion-free finitely presented group with undecidable word problem, and $M_1(G) = \{(x, y, z) \in F_2^3 : x = y,\ (y, z) \in M(G)\}$, where $M(G) \le F_2 \times F_2$ is Mihailova's fibre product; $M_1(G)$ is generated by $17$ elements. For $w \ne 1$ in $F_2 = \langle a, b \rangle$, the centralizer of $(a, b, w)$ in $F_2^3$ meets $M_1(G)$ nontrivially exactly when $w$ has finite order in $G$ (Theorem 5 of the source). Embedding $F_2$ in $\mathrm{SL}_2(\mathbb{Z})$, $M_1(G)$ acts by conjugation on triples of trace-zero $2 \times 2$ matrices, a space of dimension $9$, and the stabilizer of the vector built from $(a, b, w)$ is that centralizer. So the stabilizer problem would decide whether $w$ has finite order in $G$, which, $G$ being torsion-free, is its word problem.
