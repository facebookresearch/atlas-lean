# The zero-in-the-corner problems for finitely generated rational matrix groups are undecidable

No algorithm decides, for a finite set of invertible rational $n \times n$ matrices with $n \ge 6$, whether the group they generate contains a matrix with $(1,1)$-entry zero; for $n \ge 9$, none decides whether it contains a non-identity matrix with $(1,n)$-entry zero.

Let $n \ge 1$ and let the input be a finite set $X$ of matrices in $\mathrm{GL}_n(\mathbb{Q})$, generating the subgroup $G = \langle X \rangle$. Then (source):

1. for $n \ge 6$ it is undecidable whether $G$ contains a matrix whose upper left $(1,1)$-entry is zero (Theorem 1);
2. for $n \ge 9$ it is undecidable whether $G$ contains a matrix other than the identity whose upper right $(1,n)$-entry is zero (Theorem 2).

The identity is excluded in the second problem because it always has zero off-diagonal entries. The source states that both results already hold with 17 generators. The analogous problems for semigroups of integer matrices are undecidable by reductions from the Post correspondence problem.

## Expansion

The proofs reduce from the membership problem in $F_k \times F_k$, undecidable by Mihailova's construction from a finitely presented group with undecidable word problem: for a $k$-generated group $Q$, the subgroup $\{(x, y) \in F_k \times F_k : x = y \text{ in } Q\}$ is finitely generated, and membership in it is the word problem of $Q$. The source embeds $F_2$, and hence $F_k \times F_k$, in $\mathrm{GL}_n(\mathbb{Q})$ so that a computable element $g$ lies in a given finitely generated subgroup exactly when a suitably enlarged subgroup contains a matrix with a vanishing corner entry.
