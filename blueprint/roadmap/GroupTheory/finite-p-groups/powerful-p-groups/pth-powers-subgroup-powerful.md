# Kourovka 21.137, main question

The proposition that there is a prime $p$ such that for
every finite $p$-group $G$ and every subgroup $P$ of $G$ whose underlying set is exactly the set
$\{x^p : x \in G\}$ of $p$-th powers in $G$, the subgroup $P$ is powerful: its commutator subgroup
$[P, P]$ is contained in the subgroup $P^m$ generated by the $m$-th powers of the elements of $P$,
where $m = p$ for odd $p$ and $m = 4$ for $p = 2$.

Kourovka Problem 21.137 (L. Wilson) asks this for each prime; it is stated here for some prime, so
that its refutation covers all of them.
