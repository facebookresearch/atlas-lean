# Breuillard Green Tao Small Doubling Wanted

The **Breuillard–Green–Tao structure theorem** (small-doubling form): a
nonempty finite set of bounded doubling in an arbitrary group is controlled by
a subgroup with nilpotent quotient of bounded rank. More precisely, if
`σₘ[A] ≤ K` then there is a subgroup `N` with a normal subgroup `D` such that
`N ⧸ D` is nilpotent of bounded class and is generated by a finite set of
bounded size, `D` sits inside a bounded power of `A / A`, and `A` is covered
by boundedly many cosets of `N`.
