# Strunkov's two-generation criterion fails (Kourovka 12.79)

It is not true that for every
finite group $G$ and all $a, b \in G$ such that Strunkov's class function
$1^G - 1_{\langle a \rangle}^G - 1_{\langle b \rangle}^G - 1_{\langle ab \rangle}^G + 2$ is a
character of $G$, the elements $a$ and $b$ generate $G$. Here $1_H^G$ is the permutation character
of $G$ on the cosets of a subgroup $H$, $1^G = 1_1^G$, $\langle x \rangle$ is the cyclic subgroup
generated by $x$, and $2$ is the constant function with value $2$.

Counterexample (S. V. Skresanov, 2019): $G = A_4$ and $a = b = (1\,2\,3)$. The function takes the
values $2, 2, -1, -1$ on the classes of $1$, $(1\,2)(3\,4)$, $(1\,2\,3)$, $(1\,3\,2)$, so it is
the sum of the two nontrivial linear characters of $A_4$, while $\langle a, b \rangle$ has
order $3$.
