# Strunkov's class function

For elements $a, b$ of a group $G$, Strunkov's function
$\varphi : G \to \mathbb{C}$ is

$$\varphi = 1^G - 1_{\langle a \rangle}^G - 1_{\langle b \rangle}^G - 1_{\langle ab \rangle}^G + 2$$

where $1_H^G$ is the complex permutation character of $G$ on the cosets of a subgroup $H$,
$1^G = 1_1^G$ is the one for the trivial subgroup, $\langle x \rangle$ is the cyclic subgroup
generated by $x$, and $2$ is the constant function with value $2$.
