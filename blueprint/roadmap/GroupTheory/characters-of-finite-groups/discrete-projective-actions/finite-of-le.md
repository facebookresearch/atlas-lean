# Finite of le

Let $K_0 \subseteq K$ be fields, $v$ a valuation on $K$ with values in a linearly ordered commutative group with zero $\Gamma_0$, and $\rho : G \to \mathrm{PGL}_2(K_0)$ a discrete homomorphism. If $\varepsilon, \varepsilon' \in \Gamma_0$ with $\varepsilon \neq 0$ and $\varepsilon \le \varepsilon'$, then the set

$$\left\{ \gamma \in G : \exists\, g \in \mathrm{GL}_2(K_0),\ [g] = \rho(\gamma),\ v(g_{ij}) \le 1 \text{ for all } i, j,\ \varepsilon' \le v(\det g) \right\}$$

is finite, since it is contained in the corresponding finite set for $\varepsilon$.
