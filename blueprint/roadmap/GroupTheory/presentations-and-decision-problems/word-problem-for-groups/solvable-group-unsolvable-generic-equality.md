# Some finitely presented solvable group has unsolvable generic equality problem

The finitely presented solvable groups with unsolvable word problem constructed by Kharlampovich have unsolvable generic equality problem: for no generic set of words $S$ does a partial algorithm that never answers wrongly decide equality on $S \times S$. More generally, a recursively presented amenable group has solvable word problem exactly when it has solvable generic equality problem.

Let $\Gamma$ be a group generated by a finite set $X$, with $\pi_\Gamma\colon F_X \to \Gamma$ the canonical map from the free group on $X$, and let $B_n$ be the ball of radius $n$ in $F_X$. A subset $S \subseteq F_X$ is generic if $|S \cap B_n| / |B_n| \to 1$ as $n \to \infty$. The equality problem is solvable on $S$ if some partial algorithm with input $(\omega_1, \omega_2) \in F_X \times F_X$ halts on every pair in $S \times S$ and, on every pair on which it halts, correctly says whether $\pi_\Gamma(\omega_1) = \pi_\Gamma(\omega_2)$. This is the convention of Miasnikov and Osin that the source follows, and the proof of its Lemma 5.2 uses correct answers on pairs outside $S \times S$. The group $\Gamma$ has solvable generic equality problem if there are a finite generating set $X$ and a generic subset $S \subseteq F_X$ on which the equality problem is solvable.

The finitely presented groups $G(M)$ of Kharlampovich, which are solvable and have unsolvable word problem, have unsolvable generic equality problem (the corollary in the introduction of the source). This rests on the equivalence, for every amenable and recursively presented group $\Gamma$: $\Gamma$ has solvable word problem if and only if $\Gamma$ has solvable generic equality problem (Theorem B and Theorem 5.1).

These are the first finitely presented groups with unsolvable generic equality problem. The groups $G(M)$ have solvable generic word problem (Kapovich, Miasnikov, Schupp and Shpilrain), so for finitely presented groups solvability of the generic word problem does not imply solvability of the generic equality problem.

## Expansion

Solvable groups are amenable, so Theorem 5.1 applies to $G(M)$. For the nontrivial direction, if the equality problem is solvable on a generic set $S$, then for every finite $F \subseteq F_X$ some translate $Fy$ lies in $S$, so $\pi_\Gamma(S)$ contains Følner sets; in a recursively presented amenable group, computing one-to-one preimages of Følner sets for every $n$ solves the word problem, and the equality algorithm on $S$ provides them through an enumeration of candidate finite sets. A good expansion links pages for the unsolvability of the word problem in the groups $G(M)$ of Kharlampovich, for the characterization of solvable word problem by computable one-to-one preimages of Følner sets (Theorem 4.1 of the source), and for Lemma 5.2.
