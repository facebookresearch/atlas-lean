# A torsion-free group with solvable word problem not embeddable in one with solvable conjugacy problem

There is a finitely generated torsion-free group with solvable word problem that embeds in no finitely generated group with solvable conjugacy problem; Darbinyan's examples are even finitely presented. Kourovka Problem 5.21 has a negative answer. It is the negation of the proposition on [Kourovka Problem 5.21 (solvable word problem versus solvable conjugacy problem)](torsion-free-solvable-word-problem-embed.md).
