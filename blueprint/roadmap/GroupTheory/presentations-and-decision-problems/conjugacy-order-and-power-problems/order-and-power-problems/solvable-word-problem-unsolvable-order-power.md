# A finitely presented group with solvable word problem and unsolvable order and power problems

There is a finitely presented group $L$ with solvable word problem whose order problem and power problem are unsolvable. Moreover no algorithm decides, given finitely many elements of $L$, whether the subgroup they generate is finite, free abelian, or free.

There exists a finitely presented group $L$ with solvable word problem such that (McCool, Theorem 2):

1. the order problem for $L$ is unsolvable; the proof shows that already finiteness of the order of a given element is undecidable;
2. the power problem for $L$ is unsolvable;
3. there is no algorithm that decides, given a finite set of elements of $L$ (as words in a finite generating set), whether the subgroup $H$ they generate is (i) finite, (ii) free abelian, (iii) free.

Earlier examples of finitely presented groups with unsolvable order and power problems (Baumslag, Boone and Neumann) had unsolvable word problem.

## Expansion

Take a one-to-one recursive function $\phi$ whose range is not recursive. The recursive presentations

$$
\Pi_1 = \langle x_n \ (n \ge 1) \mid x_{\phi(n)}^{\,n} = 1 \ (n \ge 1) \rangle, \qquad \Pi_2 = \langle y_n, z_n \ (n \ge 1) \mid y_n z_n = z_n y_n,\ y_{\phi(n)} = z_{\phi(n)}^{\,n} \ (n \ge 1) \rangle
$$

have solvable word problem, yet $x_r$ has finite order, and $y_r \in \langle z_r \rangle$, exactly when $r$ is in the range of $\phi$; and $\langle x_r \rangle$ is infinite cyclic (free abelian, free) exactly when it is not. McCool's Theorem 1, combining his embedding theorem for countable groups with a result of Clapham, effectively embeds a recursively presented group with solvable word problem into a finitely presented group $L_i$ with solvable word problem, in which membership in the embedded copy is decidable. Then $L = L_1 \times L_2$ has the stated properties.
