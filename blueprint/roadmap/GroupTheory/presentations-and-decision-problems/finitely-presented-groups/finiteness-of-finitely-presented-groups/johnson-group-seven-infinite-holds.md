# Johnson's group with n = 7 is infinite

The group $\langle a, b \mid a^{7} = 1,\ ab = b^3a^3 \rangle$ is infinite: it contains the Fibonacci group $F(3, 7)$ as a subgroup of index $7$, which is infinite. This settles the case $n = 7$ of Kourovka Problem 8.10.
