# Submonoid membership problem

The submonoid membership problem of a finitely generated monoid or group asks for an algorithm that decides, given finitely many words $w_1, \dots, w_m$ and a word $w$ over the generators, whether $w$ represents an element of the submonoid generated by the elements that $w_1, \dots, w_m$ represent.

Let $M$ be a monoid, $A$ a finite set and $\pi\colon A^* \to M$ a surjective monoid homomorphism from the free monoid on $A$. For a group $G$ generated as a group by a finite set $X$, take $A = X \cup X^{-1}$ and $\pi$ the canonical homomorphism, so that $\pi(x^{-1}) = \pi(x)^{-1}$. The submonoid membership problem for $M$ is the decision problem

- input: a finite set $W = \{w_1, \dots, w_m\} \subseteq A^*$ and a word $w \in A^*$;
- question: is $\pi(w) \in \pi(W^*)$, where $W^*$ is the set of all finite concatenations of elements of $W$, the empty word included?

The set $\pi(W^*)$ is the submonoid of $M$ generated by $\pi(w_1), \dots, \pi(w_m)$. The problem is decidable when some algorithm answers it on every input. For a group, the subgroup membership problem (generalized word problem) is the variant asking whether $\pi(w) \in \pi((W \cup W^{-1})^*)$, where $W^{-1}$ is the set of formal inverses of the words of $W$; it is a special case of the submonoid membership problem.

## Expansion

Decidability does not depend on the finite generating set $A$. If a fixed finitely generated submonoid $N$ of $M$ has undecidable membership problem in the sense of [Membership problem for a subset of a finitely generated group](membership-problem-for-a-subset.md), then the submonoid membership problem for $M$ is undecidable: fix $W$ to be a finite set of words representing generators of $N$. Every finitely generated submonoid is a rational subset, so decidability of the [Rational subset membership problem](rational-subset-membership-problem.md) implies decidability of the submonoid membership problem.
