# Generators of the Suzuki group

Let $n$ be a natural number, $q = 2^{2n+1}$,
$\theta = 2^{n+1}$ and $F = \mathrm{GF}(q)$. The generating set of $\mathrm{Sz}(q)$ is the set of
$4 \times 4$ matrices over $F$ of the following three kinds: for $a, b \in F$, the root element
with rows $(1, a, b, a^{2+\theta} + ab + b^{\theta})$, $(0, 1, a^{\theta}, a^{1+\theta} + b)$,
$(0, 0, 1, a)$ and $(0, 0, 0, 1)$; for nonzero $x \in F$, the torus element with diagonal entries
$x^{1+2^n}$, $x^{2^n}$, $x^{-2^n}$, $x^{-(1+2^n)}$ and zeros elsewhere; and the Weyl element, the
matrix with ones on the antidiagonal and zeros elsewhere.

The map $z \mapsto z^{\theta}$ is the Tits automorphism of $F$: its square is $z \mapsto z^2$.
