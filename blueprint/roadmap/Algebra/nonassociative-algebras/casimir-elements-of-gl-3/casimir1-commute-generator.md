# First Casimir element commutes with the generators

Let $A$ be a (not necessarily commutative) ring and $E = (E_{ij})_{i,j \in \{0,1,2\}}$ a family of elements of $A$ satisfying the $\mathfrak{gl}_3$ bracket relations $E_{ab}E_{cd} - E_{cd}E_{ab} = \delta_{bc}E_{ad} - \delta_{da}E_{cb}$ for all $a,b,c,d$. Then the trace $C_1(E) = \sum_i E_{ii}$ commutes with every generator: $C_1(E)\,E_{ij} = E_{ij}\,C_1(E)$ for all $i, j \in \{0,1,2\}$.
