# Skew brace

For a set $B$ carrying a group structure $\cdot$ and an additive group structure $+$ (not necessarily commutative), the proposition that $(B, +, \cdot)$ is a skew brace: $a(b + c) = ab - a + ac$ for all $a, b, c \in B$.

Source: E. I. Khukhro and V. D. Mazurov (eds.), Unsolved Problems in Group Theory: The Kourovka Notebook, 21st issue, arXiv:1401.0300v49 (2026), Problem 20.109 (C. Tsang).
