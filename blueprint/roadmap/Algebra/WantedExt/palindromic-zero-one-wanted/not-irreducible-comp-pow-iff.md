# Theorem 1.2

**Theorem 1.2**: let `f(x) ∈ ℤ[x]` be irreducible
and `r ≥ 2`. Then `f(x^r)` is reducible if and only if
either `f(x^p)` is reducible for some prime `p`
dividing `r`, or `4 ∣ r` and `f(x^4)` is reducible.
