# Bijective sum pow mul pow zmod

Ding and Zieve's Theorem 1 (the result quoted from the earlier
paper): under the displayed congruences, the function
`c ↦ ∑ n ∈ [1,k], n ^ t * c ^ n` permutes `ZMod p`.
