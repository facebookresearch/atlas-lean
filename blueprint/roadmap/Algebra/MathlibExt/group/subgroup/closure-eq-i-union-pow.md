# Pointwise

Source 2310.10246 D01 (main.tex:146): for a group `G` and `X ⊆ G`,
with `X⁰ = {e}`, `X¹ = X`, `Xⁿ⁺¹ = Xⁿ * X` (Mathlib pointwise `Set` powers),
if `X = X⁻¹` then the subgroup generated by `X` equals `⋃ n : ℕ, X ^ n`,
i.e. `↑(Subgroup.closure X) = ⋃ n, X ^ n`.
