# The ranges of all module colimit legs span the colimit module

Let R be a ring in universe u, J a category in object and morphism universes uJ,vJ, and
D:J→ModuleCat_v(R). If c is a colimit cocone with legs ι_j, then ⋁_{j∈J}im_R(ι_j)=⊤ as
submodules of c.pt. Every colimit element is therefore in the R-submodule generated by all
source-leg images.
