# A module cocone leg has its underlying R-linear map

Let R be a ring in universe u, J a category with independent object and morphism universes
uJ,vJ, and D:J→ModuleCat_v(R). For a cocone c and j∈J, its leg ι_j:D(j)→c.pt has the same
underlying R-linear map D(j)→c.pt. No colimit assumption is needed to define this map.
