# Varieties of algebras

A variety is the class of all algebras of a given finite type that satisfy a given set of identities.

Let $\tau$ be a finite type. A *variety* of type $\tau$ is a class $\mathcal{V}$ of [algebras](algebras-of-a-finite-type.md) of type $\tau$ for which there is a set $\Sigma$ of identities such that $\mathcal{V}$ consists of exactly the algebras of type $\tau$ that [satisfy](identities-satisfied-by-an-algebra.md) $\Sigma$. By Birkhoff's theorem, a class of algebras of type $\tau$ is a variety exactly when it is closed under homomorphic images, subalgebras and direct products.
