# Varieties of algebras and finitely generated varieties

A variety is the class of all algebras of a given finite type that satisfy a set of identities; the variety generated by a finite algebra consists of the algebras satisfying every identity true in it, and the algebra is finitely based when finitely many of those identities imply all of them.

Fix a finite *type* $\tau$: a finite set of operation symbols, each with an arity $n \ge 0$. An *algebra* of type $\tau$ is a nonempty set $A$ with an operation $\omega^{A} \colon A^n \to A$ for each symbol $\omega$ of arity $n$; it is *finite* when $A$ is finite. Terms are built from variables with the operation symbols.

- An *identity* is a sentence $\forall \bar x\, (s(\bar x) = t(\bar x))$ with terms $s, t$. A *variety* is the class of all algebras of type $\tau$ that satisfy a given set $\Sigma$ of identities; by Birkhoff's theorem, a class is a variety exactly when it is closed under homomorphic images, subalgebras and direct products.
- The *variety generated* by an algebra $A$, written $\mathcal{V}(A)$, is the class of algebras of type $\tau$ that satisfy every identity true in $A$; it is the least variety containing $A$. A variety of the form $\mathcal{V}(A)$ with $A$ finite is *finitely generated*.
- $A$ is *finitely based* when the set of identities true in $A$ follows from a finite subset of it, equivalently when $\mathcal{V}(A)$ is the class of models of finitely many identities.

Decision problems about finitely generated varieties take as input a finite algebra of finite type, given by its type and the tables of its operations, or a finite set of identities.

## Expansion

Tarski asked whether some algorithm decides, for a finite algebra, whether it is finitely based; McKenzie answered no in 1996 by attaching to each Turing machine $T$ a finite algebra $A(T)$ whose variety has a finite residual bound exactly when $T$ halts (see [congruences and subdirectly irreducible algebras](congruences-and-subdirectly-irreducible-algebras.md)). The linked result pages refine this construction.
