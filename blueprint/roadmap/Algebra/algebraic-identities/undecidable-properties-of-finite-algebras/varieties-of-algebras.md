# Varieties of algebras

A variety is the class of all algebras of a given finite type that satisfy a given set of identities.

Let $\tau$ be a finite type. A *variety* of type $\tau$ is a class $\mathcal{V}$ of [algebras](algebras-of-a-finite-type.md) of type $\tau$ for which there is a set $\Sigma$ of identities, equations $s \approx t$ between terms each read as its universal closure, such that $\mathcal{V}$ consists of exactly the $\Sigma$-algebras of type $\tau$, the models of every member of $\Sigma$, as in [equational consequence and E-algebras](../../../Logic/first-order-logic/equational-logic/equational-consequence-and-e-algebras.md). By Birkhoff's theorem, a class of algebras of type $\tau$ is a variety exactly when it is closed under homomorphic images, subalgebras and direct products.
