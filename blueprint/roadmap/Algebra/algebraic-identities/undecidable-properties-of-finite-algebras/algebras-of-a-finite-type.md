# Algebras of a finite type

A finite type is a finite set of operation symbols with arities, and an algebra of that type is a nonempty set with one operation of the right arity for each symbol.

A *finite type* $\tau$ is a finite set of operation symbols, each with an arity $n \ge 0$. An *algebra* of type $\tau$ is a nonempty set $A$ together with an operation $\omega^{A} \colon A^n \to A$ for each symbol $\omega$ of $\tau$ of arity $n$ (a symbol of arity $0$ names an element of $A$). The algebra is *finite* when $A$ is finite; a finite algebra of finite type is given by $\tau$ and the tables of its operations.
