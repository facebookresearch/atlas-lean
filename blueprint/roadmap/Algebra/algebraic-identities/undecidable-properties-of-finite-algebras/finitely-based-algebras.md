# Finitely based algebras

An algebra is finitely based when finitely many of the identities it satisfies imply all the others.

An *identity* is an equation $s \approx t$ between terms, read as its universal closure, and an algebra satisfies a set $E$ of identities when it is an $E$-algebra, a model of every member of $E$, as in [equational consequence and E-algebras](../../../Logic/first-order-logic/equational-logic/equational-consequence-and-e-algebras.md). An [algebra](algebras-of-a-finite-type.md) $A$ of a finite type is *finitely based* when there is a finite set $\Sigma_0$ of identities satisfied by $A$ such that every $\Sigma_0$-algebra of the same type satisfies every identity satisfied by $A$; equivalently, the [variety generated](variety-generated-by-an-algebra.md) by $A$ is the class of all algebras satisfying $\Sigma_0$.

## Expansion

Tarski asked whether some algorithm decides, for a finite algebra, whether it is finitely based. McKenzie attached to each Turing machine $T$ a finite algebra $A(T)$ whose variety has a finite [residual bound](residual-bound-of-a-variety.md) exactly when $T$ halts, and in 1996 answered Tarski's question negatively using a similar construction. Willard later showed that $A(T)$ itself is finitely based exactly when $T$ halts.
