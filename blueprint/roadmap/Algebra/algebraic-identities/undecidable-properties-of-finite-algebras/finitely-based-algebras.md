# Finitely based algebras

An algebra is finitely based when finitely many of the identities it satisfies imply all the others.

An [algebra](algebras-of-a-finite-type.md) $A$ of a finite type is *finitely based* when there is a finite set $\Sigma_0$ of identities satisfied by $A$ such that every algebra of the same type that [satisfies](identities-satisfied-by-an-algebra.md) $\Sigma_0$ satisfies every identity satisfied by $A$; equivalently, the [variety generated](variety-generated-by-an-algebra.md) by $A$ is the class of all algebras satisfying $\Sigma_0$.

## Expansion

Tarski asked whether some algorithm decides, for a finite algebra, whether it is finitely based; McKenzie answered no in 1996 by attaching to each Turing machine $T$ a finite algebra $A(T)$ whose variety has a finite [residual bound](residual-bound-of-a-variety.md) exactly when $T$ halts.
