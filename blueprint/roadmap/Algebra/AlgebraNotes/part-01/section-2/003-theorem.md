# Theorem (Section 2, Subsection 2.4 (Cyclic Groups))

Let $S = \{n \in \mathbb{Z} \mid g^n = e\}.$ Then $S$ is a subgroup of $\mathbb{Z},$ so $S = d\mathbb{Z}$ or $S = \{0\}$, leading to two cases: (1) If $S = \{0\},$ then $\langle g \rangle$ is infinite and all the $g^k$ are distinct. (2) If $S = d\mathbb{Z},$ then $\langle g \rangle = \{e, g, g^2, \cdots, g^{d-1}\} \subset G,$ which is finite.
