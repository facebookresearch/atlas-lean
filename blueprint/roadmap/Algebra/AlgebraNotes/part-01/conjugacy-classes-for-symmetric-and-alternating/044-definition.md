# Definition (Conjugacy Classes for Symmetric and Alternating Groups, Section: Cycle Type)

Given $\sigma \in S_n$, the cycle type of $\sigma$ is the number of 1-cycles, 2-cycles, and so on, that show up in the cycle notation.
