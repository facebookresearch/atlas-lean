# Corollary (Counting Formula for Orbits)

The number of cosets of $H$, which is the order $|G/H|$, is equal to the size of the orbit of $s,$ since there is a bijective correspondence between them. So $|O_s| = [G : \operatorname{Stab}(s)].$
