# Definition (Section: Fields and Vector Spaces, Bases and Dimension subsection)

A set of vectors $S = \{\vec{v}_1, \cdots, \vec{v}_n\}$ is a **basis** if $S$ spans $V$ and is linearly independent. Equivalently, each $\vec{v} \in V$ can be written uniquely as $\vec{v} = a_1\vec{v}_1 + \cdots + a_n \vec{v}_n$, where the $a_i$ are called the **coordinates** of $\vec{v}$ in the basis $S.$
