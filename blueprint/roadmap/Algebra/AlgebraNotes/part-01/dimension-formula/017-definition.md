# Definition (Dimension Formula, Section on Eigenvectors, Eigenvalues, and Diagonalizable Matrices)

Given a matrix $A,$ if there exists some invertible $P$ such that $P^{-1}AP = D$ for some diagonal matrix $D$, then $A$ is called **diagonalizable**.
