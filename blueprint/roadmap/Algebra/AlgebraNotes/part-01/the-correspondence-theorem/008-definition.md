# Definition (The Correspondence Theorem, Normal Subgroups)

If $xH = Hx$ for each $x \in G,$ $H \subseteq G$ is called a **normal subgroup**. Equivalently, the subgroup $H$ is normal if and only if it is invariant under conjugation by $x$; that is, $xHx^{-1} = H$. A subgroup $H$ is normal if and only if $\varphi_x(H) = H$ for all $x \in G.$
