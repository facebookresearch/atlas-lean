# Proposition (Hilbert's Third Problem, Some Algebra)

The definition has a few consequences: (1) $0 \otimes h = g \otimes 0 = 0$. (2) If $a \in \mathbb{Z}$, then $(ag) \otimes h = a(g \otimes h) = g \otimes ah$ (by using linearity). (3) If we take lists of generators $G = \langle g_1, \ldots, g_r\rangle$ and $H = \langle h_1, \ldots, h_s\rangle$, then $G \otimes H = \langle g_i \otimes h_j \rangle$.
