# Definition (Section: Euclidean and Hermitian Spaces, Subsection: Complex Linear Operators)

A linear operator $T:V \to V$ is **normal** if $TT^* = T^*T$, which is equivalent to $\langle v, T^*Tw \rangle = \langle Tv, Tw \rangle = \langle T^*v, T^*w \rangle = \langle v, TT^*w \rangle.$
