# Definition (Section: Characters and Schur's Lemma, Subsection: Schur's Lemma)

Suppose $\rho : G \to \operatorname{GL}(V)$ and $\psi : G \to \operatorname{GL}(W)$ are (not necessarily irreducible) representations. Then define $\operatorname{Hom}_G(\rho, \psi) = \{f : V \to W \mid f \text{ is a linear map such that } f(\rho_g(v)) = \psi_g(f(v)) \text{ for all } g, v\}.$ Such linear maps $f$ are called $G$-equivariant.
