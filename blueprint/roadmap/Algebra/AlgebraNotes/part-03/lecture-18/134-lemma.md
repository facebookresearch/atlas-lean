# Lemma (Lecture 18, Section: The Ideal Class Group, Subsection: Finiteness of the Class Group)

An ideal $I$ of norm $n$ contains a nonzero element $\alpha \neq 0$ with $\alpha\overline{\alpha} \leq \mu n$.
