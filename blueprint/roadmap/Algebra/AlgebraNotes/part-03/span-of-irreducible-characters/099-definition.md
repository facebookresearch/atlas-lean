# Definition (Section: Span of Irreducible Characters)

For a function $f : G \to \mathbb{C}$ (not necessarily a class function) and a representation $\rho : G \to \operatorname{GL}(V)$, define $\rho(f) = \sum_{g \in G} f(g)\rho_g$.
