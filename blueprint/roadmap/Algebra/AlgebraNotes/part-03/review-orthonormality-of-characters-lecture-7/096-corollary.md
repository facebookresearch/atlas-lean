# Corollary (Section: Review: Orthonormality of Characters (Lecture 7))

If $\rho = \bigoplus \rho_i^{n_i}$, then $\langle \chi_\rho, \chi_\rho \rangle = \sum n_i^2$. In particular, $\rho$ is irreducible if and only if $\langle \chi_\rho, \chi_\rho \rangle = 1$.
