# Definition (Section: Decomposition of Modules, Subsubsection: Uniqueness of Subgroups)

The set of elements with finite order is called the **torsion subgroup** $A_f$, so we have $A_f = \mathbb{Z}/d_1\mathbb{Z} \times \cdots \times \mathbb{Z}/d_n\mathbb{Z}$.
