# Fibres of a homogeneous system with only the trivial common zero are finite

For all $m, n, d \in \mathbb{N}$ and all polynomials $f_1, \dots, f_n \in \mathbb{C}[x_1, \dots, x_m]$ homogeneous of degree $d$ whose only common zero is $0$, every fibre $\{x \in \mathbb{C}^m : f_i(x) = b_i \text{ for all } i\}$ ($b \in \mathbb{C}^n$) is finite. (An infinite fibre would make the projective closure of the system positive-dimensional, giving a nonzero common zero of the $f_i$ at infinity.)

Source: AIM Problem Lists, *Extensions of Hilbert's tenth problem*, Question 36 (Jarden), https://aimath.org/WWN/hilberts10th/hilberts10th.pdf and its solution paragraph.
