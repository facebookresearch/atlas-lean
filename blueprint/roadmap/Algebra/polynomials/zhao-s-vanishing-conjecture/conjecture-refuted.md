# Zhao's vanishing conjecture for quartic forms is false

It is not the case that for every $n$ and every homogeneous quartic $P \in \mathbb{C}[X_1, \dots, X_n]$, if $\Delta^m(P^m) = 0$ for all $m \ge 1$, where $\Delta = \sum_i \partial^2/\partial X_i^2$, then $\Delta^m(P^{m+1}) = 0$ for all sufficiently large $m$. Zhao proved this statement (over all $n$) equivalent to the Jacobian conjecture, which has counterexamples in three and more variables.
