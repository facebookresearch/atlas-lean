# A multiplicative quartic norm form forces a square parameter

Let $D, c \in \mathbb{Z}$ with $D > 0$ and $c > 0$. Let $P \in \mathbb{Q}[X_0, X_1, X_2, X_3]$ be homogeneous of degree $4$ and let $F : \mathbb{Z}^4 \to \mathbb{N}$ satisfy $F(v) = P(v)$ (in $\mathbb{Q}$) for every $v \in \mathbb{Z}^4$. Assume:

- $F(1, 0, 0, 0) = 1$;
- for all $v, w \in \mathbb{Z}^4$, $F(v \ast w) = F(v)\,F(w)$, where

$$v \ast w = \bigl(v_0w_0 + Dv_1w_1 + cv_2w_2 + Dcv_3w_3,\ v_0w_1 + v_1w_0 + c(v_2w_3 + v_3w_2),\ v_0w_2 + v_2w_0 + D(v_1w_3 + v_3w_1),\ v_0w_3 + v_3w_0 + v_1w_2 + v_2w_1\bigr);$$

- for every $r \in \mathbb{Z}$ with $r^2 = Dc$, $F(r, 0, 0, 1) = 0$.

Then $D$ or $c$ is a perfect square in $\mathbb{Z}$.
