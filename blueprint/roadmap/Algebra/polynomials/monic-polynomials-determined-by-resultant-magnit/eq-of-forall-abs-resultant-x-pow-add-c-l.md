# Monic rational polynomials determined by resultant magnitudes

Let `P` and `Q` be monic polynomials with rational coefficients of the same
degree, and let `S` be a set of integers that is unbounded above and
unbounded below. Suppose that for every positive integer `n` and every `c ∈
S` with `Res(X ^ n + c, P) ≠ 0`, one has `|Res(X ^ n + c, Q)| ≤ |Res(X ^ n +
c, P)|`. Then `P = Q`.
