# Integral balanced tensors with identity reduction

Let `R` be a ring that is free of finite rank as a `ℤ`-module, `ℓ` a prime,
`n` a nonempty finite index set, and `ψ : R → M_n(𝔽_ℓ)` a surjective ring
homomorphism onto the `n × n` matrices over `𝔽_ℓ` whose kernel is `ℓ R`. If
`R ⊗_ℤ R` contains a nonzero balanced element `c₀`, meaning `(x ⊗ 1) c₀ = c₀
(1 ⊗ x)` for every `x ∈ R`, then it contains a balanced element `c` whose
image under the multiplication map `R ⊗_ℤ R → R` is sent by `ψ` to the
identity matrix.
