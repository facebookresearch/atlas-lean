# Centralizer of a non-scalar rational quaternion

Let $a, b$ be nonzero rationals and consider the quaternion algebra over $\mathbb{Q}$ with basis $1, i, j, k$, $i^2 = a$, $j^2 = b$. Let $\alpha$ be an element whose $i$-, $j$- and $k$-components are not all zero. Then an element $x$ satisfies $x\alpha = \alpha x$ if and only if $x = c + e\,\alpha$ for some $c, e \in \mathbb{Q}$.
