# Truncated subadditivity defect of a cocycle

For a map $T : \Omega \to \Omega$, functions $X_n : \Omega \to \mathbb{R}$ ($n \ge 0$) and a real number $M$, the
truncated defect is the positive part of the [shifted defect](sc.md):

$$V^M_n(\omega) = \bigl(X_n(\omega) + M n - A_n(\omega)\bigr)^+,$$

which for $n \ge 1$ equals $(M n - Z_n(\omega))^+$, with $Z_n$ the [subadditivity defect](zc.md).
