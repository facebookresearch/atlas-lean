# Kingman's subadditive ergodic theorem for nonnegative cocycles

Let $\mu$ be a finite measure on $\Omega$, $T : \Omega \to \Omega$ a measurable map preserving $\mu$, and
$X_n : \Omega \to \mathbb{R}$ ($n \ge 0$) integrable functions such that $X_n \ge 0$ $\mu$-almost everywhere for every
$n$ and, for all $m, n \ge 0$, $X_{m+n}(\omega) \le X_m(\omega) + X_n(T^m \omega)$ for $\mu$-almost every $\omega$.
Then there is an integrable function $g : \Omega \to \mathbb{R}$ with $g(T\omega) = g(\omega)$ for $\mu$-almost every
$\omega$ and

$$\frac{X_n(\omega)}{n} \longrightarrow g(\omega) \qquad \text{for } \mu\text{-almost every } \omega.$$

Compared with the [nonnegative case on a probability space](kingman-subadditive.md), the measure only needs to be
finite, and neither the measurability of each $X_n$ nor $X_0 = 0$ is assumed.
