# Block decomposition bound for a subadditive cocycle

Let $(X_n)_{n \ge 0}$ be a [subadditive cocycle](subadditive-cocycle.md) over a map $T : \Omega \to \Omega$ for a measure $\mu$. Then for $\mu$-almost every $\omega$, for
all $k \ge 0$ and $q \ge 1$,

$$X_{qk}(\omega) \le \sum_{j=0}^{q-1} X_k(T^{jk} \omega).$$
