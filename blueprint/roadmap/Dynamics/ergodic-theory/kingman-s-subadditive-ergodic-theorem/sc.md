# Shifted subadditivity defect of a cocycle

For a map $T : \Omega \to \Omega$, functions $X_n : \Omega \to \mathbb{R}$ ($n \ge 0$) and a real number $M$, the shifted
defect is

$$S^M_n(\omega) = X_n(\omega) + M n - A_n(\omega),$$

where $A_n$ is the [additive cocycle](add-coc.md) of Birkhoff sums of $X_1$. When $X$ is a
[subadditive cocycle](subadditive-cocycle.md) for a finite measure, so is $S^M$, for every $M$.
