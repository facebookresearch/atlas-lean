# Cocycle inequality holds for all indices almost everywhere

Let $(X_n)_{n \ge 0}$ be a [subadditive cocycle](subadditive-cocycle.md) over a map $T : \Omega \to \Omega$ for a measure $\mu$. Then for $\mu$-almost every $\omega$ the
cocycle inequality

$$X_{m+n}(\omega) \le X_m(\omega) + X_n(T^m \omega)$$

holds for all $m, n \ge 0$ simultaneously (a countable intersection of sets of full measure).
