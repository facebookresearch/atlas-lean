# Time constant of a subadditive cocycle

For a [subadditive cocycle](subadditive-cocycle.md) $(X_n)_{n \ge 0}$ over $T$ for a measure $\mu$, the time constant is

$$\gamma = \inf_{n \ge 1} \frac{1}{n} \int X_n \, d\mu.$$

When these numbers are bounded below, $\gamma$ is also the limit of $\frac{1}{n} \int X_n \, d\mu$
([Fekete's lemma](tendsto-exp-seq-div.md)); when they are not, the infimum of a set of reals that is not bounded
below is taken to be $0$, so $\gamma = 0$ by convention.
