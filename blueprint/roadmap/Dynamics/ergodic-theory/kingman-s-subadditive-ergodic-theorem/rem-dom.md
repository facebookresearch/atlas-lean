# Dominating function for remainder terms in Kingman's theorem

For functions $X_n : \Omega \to \mathbb{R}$ ($n \ge 0$) and $k \ge 0$, the dominating function for the remainder terms
$X_r$, $r < k$, is

$$R_k(\omega) = \sum_{r=0}^{k-1} X_r(\omega)^+, \qquad t^+ = \max(t, 0).$$

It is nonnegative, dominates each $X_r$ with $r < k$, and is integrable when $X_0, \dots, X_{k-1}$ are.
