# Bad set in the greedy decomposition for Kingman's theorem

For a map $T : \Omega \to \Omega$, functions $X_n : \Omega \to \mathbb{R}$, a real number $\varepsilon$ and an
integer $N$, the bad set is

$$B = \{\omega \in \Omega : X_m(\omega) > (g(\omega) + \varepsilon)\, m \text{ for every } 1 \le m \le N\},$$

where $g$ is the [real lower limit](g-low.md) of $X_n/n$: the points from which no block of length at most $N$
achieves the rate $g + \varepsilon$.
