# Oscillation set of Birkhoff averages is null

Let $\mu$ be a finite measure on $X$, $T : X \to X$ a measurable map preserving $\mu$, and $f : X \to \mathbb{R}$
an integrable function. For all real numbers $a < b$, the [oscillation set](level-set.md)
$\{f_* < a\} \cap \{b < f^*\}$ of the Birkhoff averages of $f$ has measure $0$.
