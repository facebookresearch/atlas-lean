# Oscillation set of Birkhoff averages

For a map $T : X \to X$, a function $f : X \to \mathbb{R}$ and real numbers $a$ and $b$, the oscillation set is

$$\{x \in X : f_*(x) < a \text{ and } b < f^*(x)\},$$

where $f_*$ and $f^*$ are the [lower](f-star-low.md) and [upper](f-star.md) limits of the Birkhoff averages of $f$:
for $a < b$, the set where the Birkhoff averages oscillate across $[a, b]$. It is invariant under $T$, since $f_*$ and
$f^*$ are.
