# Maximal ergodic inequality on an invariant set

Let $\mu$ be a measure on $X$, $T : X \to X$ a measurable map preserving $\mu$, $g : X \to \mathbb{R}$ an integrable
function, and $E$ a $\mu$-measurable [invariant set](is-invariant-set.md) such that every $x \in E$ has some
$n \ge 1$ with $\sum_{k=0}^{n-1} g(T^k x) > 0$. Then

$$\int_E g \, d\mu \ge 0.$$
