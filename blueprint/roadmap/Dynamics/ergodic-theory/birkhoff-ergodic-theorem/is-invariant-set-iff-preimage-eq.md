# Invariant set as a set equal to its preimage

For a map $T : X \to X$, a set $E \subseteq X$ is [invariant](is-invariant-set.md) ($x \in E \iff Tx \in E$ for
every $x$) if and only if $T^{-1} E = E$. This is the notion of invariance in the definition of ergodicity and of
the σ-algebra of invariant sets.
