# Rationally independent integer polynomials

Integer polynomials $p_1, \dots, p_\ell \in \mathbb{Z}[t]$ are rationally independent when no nontrivial integer combination of them is constant: if $\sum_i c_i p_i$ is a constant polynomial for integers $c_1, \dots, c_\ell$, then $c_1 = \dots = c_\ell = 0$.
