# Frantzikinakis’s Problem 25 on recurrence along Hardy sequences

The statement that every family $a_1, \dots, a_\ell$ of functions in a common Hardy field, each of polynomial growth, with every nonzero linear combination logarithmically separated from all real multiples of integer polynomials ($|f(t) - c\,p(t)| / \log t \to \infty$), is good for $\ell$-recurrence of a single invertible measure-preserving transformation.

## Sources

- N. Frantzikinakis, Some open problems on multiple ergodic averages, Bull. Hellenic Math. Soc. 60 (2016), 41-90, arXiv:1103.3808, Problem 25.
