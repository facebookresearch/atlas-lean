# Functions in a common Hardy field

Functions $a_1, \dots, a_\ell : \mathbb{R} \to \mathbb{R}$ lie in a common Hardy field when some set $H$ with the following properties contains all of them. A Hardy-field family here is a set $H$ of functions $\mathbb{R} \to \mathbb{R}$ containing the constants, closed under sums and products, containing the reciprocal of each member that is eventually nonzero, whose members are eventually differentiable with derivative in $H$, and in which any two members are eventually comparable.
