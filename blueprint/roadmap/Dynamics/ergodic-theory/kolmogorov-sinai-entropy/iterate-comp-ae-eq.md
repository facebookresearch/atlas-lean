# Almost-everywhere semiconjugacy passes to iterates

Let $(X, \mu)$ be a measure space, $T : X \to X$ a quasi-measure-preserving map ($T$ is measurable and
$\mu(T^{-1} A) = 0$ whenever $\mu(A) = 0$), $S : Y \to Y$ a map of a set $Y$, and $\pi : X \to Y$ a map with
$\pi \circ T = S \circ \pi$ $\mu$-almost everywhere. Then for every $k \ge 0$,

$$\pi \circ T^k = S^k \circ \pi \quad \mu\text{-almost everywhere}.$$
