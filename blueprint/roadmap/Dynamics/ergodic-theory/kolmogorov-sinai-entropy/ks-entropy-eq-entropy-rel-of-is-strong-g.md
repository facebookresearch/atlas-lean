# Sinai's generator theorem, noninvertible case

Let $T$ be a measure-preserving transformation of a probability space $(X, \mathcal{B}, \mu)$, not
necessarily invertible, and let $\xi = (C_1, \dots, C_r)$ be a
[measurable partition modulo null sets](is-measurable-partition.md) which is a *strong generator*: every
measurable set is $\mu$-almost everywhere equal to a set of the σ-algebra generated by the sets $T^{-i} C_j$,
$i \ge 0$, $1 \le j \le r$. Then $h_\mu(T) = h_\mu(T, \xi)$.

This is the form used for one-sided shifts, where the partition into 1-cylinders is a strong generator;
compare the [invertible statement](ks-entropy-eq-entropy-rel-of-is-generato.md).

- O. Sarig, *Lecture Notes on Ergodic Theory* (2023), Definition 4.4 (strong generator) and Theorem 4.4, whose
