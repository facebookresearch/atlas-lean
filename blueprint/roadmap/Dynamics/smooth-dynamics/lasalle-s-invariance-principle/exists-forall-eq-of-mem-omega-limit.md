# A function nonincreasing along an orbit is constant on its ω-limit set

Let $\varphi = (\varphi_t)_{t \ge 0}$ be a continuous semiflow on a topological space $X$ (jointly continuous in $(t, x)$, with $\varphi_0 = \mathrm{id}$ and $\varphi_{s+t} = \varphi_s \circ \varphi_t$), let $V : X \to \mathbb{R}$ be continuous, and let $x \in X$ have its forward orbit in a compact set
$K$: $\varphi_t(x) \in K$ for every $t \ge 0$. If $t \mapsto V(\varphi_t(x))$ is nonincreasing, then there is a
constant $c$ (the limit of $V(\varphi_t(x))$) such that

$$V(\varphi_t(y)) = c \qquad \text{for every } y \in \omega^+(x) \text{ and every } t \ge 0,$$

where $\omega^+(x) = \bigcap_{s \ge 0} \overline{\{\varphi_t(x) : t \ge s\}}$ is the ω-limit set of $x$.
