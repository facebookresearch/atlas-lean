# The ω-limit set lies in every closed set containing the orbit

Let $\varphi = (\varphi_t)_{t \ge 0}$ be a continuous semiflow on a topological space $X$ (jointly continuous in $(t, x)$, with $\varphi_0 = \mathrm{id}$ and $\varphi_{s+t} = \varphi_s \circ \varphi_t$), let $x \in X$ and let $K \subseteq X$ be a closed set with $\varphi_t(x) \in K$ for every $t \ge 0$.
Then the ω-limit set $\omega^+(x) = \bigcap_{s \ge 0} \overline{\{\varphi_t(x) : t \ge s\}}$ is contained in $K$.
