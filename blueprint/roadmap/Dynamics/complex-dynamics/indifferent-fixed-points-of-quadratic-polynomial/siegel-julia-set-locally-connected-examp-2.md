# A Siegel quadratic polynomial with locally connected Julia set

Petersen proves that for every `α` of bounded type (for instance the golden mean)
`P_α` is a Siegel polynomial whose Julia set is locally connected.

## Sources

- J. Milnor (ed.), Problems in holomorphic dynamics (Stony Brook, 1992), arXiv:math/9205209, Problems on local connectivity, Problem 9, https://www.math.stonybrook.edu/open-problems-dynamical-systems; resolution: C. L. Petersen, Local connectivity of some Julia sets containing a circle with an irrational rotation, Acta Math. 177 (1996), 163-224, main theorem (Zbl 0884.30020): for θ of constant (bounded) type, the Julia set of P_θ(z) = e^\{2πiθ\} z + z², which has a Siegel disc around 0, is locally connected and has Lebesgue measure zero; e.g. θ = (√5 - 1)/2, https://doi.org/10.1007/BF02392621.
