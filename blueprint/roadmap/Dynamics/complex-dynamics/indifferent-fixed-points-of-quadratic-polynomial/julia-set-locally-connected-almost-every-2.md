# Quadratic Siegel Julia sets are locally connected for almost every rotation number

Petersen and Zakeri prove that the Julia set of `P_α` is locally connected (and of
measure zero) whenever the continued fraction digits of `α` satisfy `log a_n = O(√n)`, which holds
for Lebesgue almost every `α`.

## Sources

- J. Milnor (ed.), Problems in holomorphic dynamics (Stony Brook, 1992), arXiv:math/9205209, Problems on local connectivity, Problem 9, https://www.math.stonybrook.edu/open-problems-dynamical-systems; resolution: C. L. Petersen and S. Zakeri, On the Julia set of a typical quadratic polynomial with a Siegel disk, Ann. of Math. 159 (2004), 1-52, main theorem (Zbl 1069.37038): if the continued fraction digits a_n of θ satisfy log a_n = O(√n), a condition satisfied by a set of θ of full measure, the Julia set of z² + e^\{2πiθ\} z is locally connected and has Lebesgue measure zero, https://doi.org/10.4007/annals.2004.159.1.
