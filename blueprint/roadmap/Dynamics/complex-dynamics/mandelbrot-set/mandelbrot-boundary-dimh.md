# Hausdorff dimension of the Mandelbrot boundary (Shishikura)

The boundary of the
Mandelbrot set $M \subseteq \mathbb{C}$ has Hausdorff dimension $2$.

## Sources

- M. Shishikura, The Hausdorff dimension of the boundary of the Mandelbrot set and Julia sets, Ann. of Math. 147 (1998). Listed as §260 in O. Knill, Some Fundamental Theorems in Mathematics (https://people.math.harvard.edu/~knill/graphgeometry/papers/fundamental.pdf). Knill, §260.
