# A quadratic Julia set of positive area

Buff and Chéritat proved that some quadratic polynomials have a Julia set of positive
Lebesgue measure; a polynomial Julia set is the boundary of the compact filled Julia set, so it is
nowhere dense. Each such polynomial is affinely conjugate to some `z ↦ z² + c`, which preserves
positive area.

## Sources

- M. Lyubich, Stony Brook - Open Problems in Dynamical Systems (1992), problem P1, https://www.math.stonybrook.edu/open-problems-dynamical-systems; resolution: X. Buff and A. Chéritat, Quadratic Julia sets with positive area, Ann. of Math. 176 (2012), 673-746, arXiv:math/0605514, main theorem: quadratic polynomials with a Cremer point, a Siegel disk, or infinitely many satellite renormalizations whose Julia set has positive area, https://arxiv.org/abs/math/0605514.
