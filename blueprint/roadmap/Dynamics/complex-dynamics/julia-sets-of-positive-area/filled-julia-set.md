# Filled Julia set of $z^2 + c$, for Julia sets of positive area

For $c \in \mathbb{C}$, the filled Julia set of $z \mapsto z^2 + c$ is the set of $z \in \mathbb{C}$
whose orbit is bounded: there is a real $R$ such that the $k$-th iterate of $z$ has absolute value at
most $R$ for every $k \ge 0$. The definition is the same as that of the
[filled Julia set](../fatou-julia-dichotomy/filled-julia.md); it is stated again for the question on
Julia sets of positive area.
