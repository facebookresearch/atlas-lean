# Julia sets of positive area

Lyubich's question whether a rational map can have a nowhere dense Julia set of positive area. It is
answered within the quadratic family $z^2 + c$: some quadratic polynomials have Julia sets of positive
Lebesgue measure (Buff and Chéritat), and the Julia set of a polynomial, the boundary of its filled
Julia set, is nowhere dense.
