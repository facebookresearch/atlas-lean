# The Mandelbar set is not path-connected

The Mandelbar set (tricorn), the set of
$c \in \mathbb{C}$ for which the orbit of $0$ under $z \mapsto \bar z^2 + c$ is bounded, is not
path-connected.

This is the degree-2 case of the Hubbard–Schleicher theorem that multicorns are not
path-connected.

## Sources

- John H. Hubbard and Dierk Schleicher, *Multicorns are not path connected*, in *Frontiers in Complex Dynamics*,
  Princeton University Press (2014), 73–102; arXiv:1209.1753 (2012) (main theorem, for every degree $d \ge 2$).
- Oliver Knill, *Some Fundamental Theorems in Mathematics* (2023), §62 (Quadratic map; the tricorn is mentioned
  after the theorem), <https://people.math.harvard.edu/~knill/graphgeometry/papers/fundamental.pdf>.
- Problem `mandelbar_not_path_connected` of the lean-eval benchmark.
