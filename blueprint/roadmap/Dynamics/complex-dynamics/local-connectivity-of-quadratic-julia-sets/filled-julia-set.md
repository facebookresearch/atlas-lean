# Filled Julia set of $z^2 + e^{2\pi i \alpha} z$

For a real number $\alpha$, let $P_\alpha(z) = z^2 + e^{2\pi i \alpha} z$, which fixes $0$ with
multiplier $e^{2\pi i \alpha}$. Its filled Julia set is the set of $z \in \mathbb{C}$ whose orbit under
$P_\alpha$ is bounded: there is a real $R$ with $|P_\alpha^k(z)| \le R$ for every $k \ge 0$. It is the
[filled Julia set](../fatou-julia-dichotomy/filled-julia.md) of the polynomial $P_\alpha$ instead of
$z^2 + c$.
