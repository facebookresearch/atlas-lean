# Julia sets of z² + c are locally connected for real c in [−2, 1/4]

Levin and van Strien prove that the Julia set of `z² + c` is locally connected for
every real `c ∈ [-2, 1/4]` (and totally disconnected for the other real `c`).

## Sources

- J. Milnor (ed.), Problems in holomorphic dynamics (Stony Brook, 1992), arXiv:math/9205209, Problems on local connectivity, Problem 13, https://www.math.stonybrook.edu/open-problems-dynamical-systems; resolution: G. Levin and S. van Strien, Local connectivity of the Julia set of real polynomials, Ann. of Math. (2) 147 (1998); arXiv:math/9504227, Main Theorem (abstract): for z^d + c with d even and c real the Julia set is either totally disconnected or locally connected; 'In particular, the Julia set of z² + c is locally connected if c ∈ [-2, 1/4] and totally disconnected otherwise', https://doi.org/10.2307/120958.
