# Jordan curves in the plane

A set $S \subseteq \mathbb{C}$ is a Jordan curve when there is
a continuous injective map $f$ from the unit circle $\{z \in \mathbb{C} : |z| = 1\}$ to
$\mathbb{C}$ whose image is exactly $S$.
