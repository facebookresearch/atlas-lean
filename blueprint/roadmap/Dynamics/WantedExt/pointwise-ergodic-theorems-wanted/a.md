# A

Given a real number `N ≥ 0`, `P₁, P₂ ∈ ℤ[X]`, `f,g : X → ℂ`, we define the bilinear
averages by the formula
`A T N P₁ P₂ f g x := ⌊N⌋⁻¹ ∑_{n=1}^{⌊N⌋} f(T^{P₁(n)} x) g(T^{P₂(n)} x)`.
