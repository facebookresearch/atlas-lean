# Is Affine Symmetric IFS

An IFS on `ℝᵈ` is **affine-symmetric** with common contraction factor
`λ ∈ (0,1)` if each map is `fᵢ(x) = λ · Aᵢ(x) + βᵢ` with `Aᵢ` a linear isometry
(orthogonal transformation) and `βᵢ` a translation.
