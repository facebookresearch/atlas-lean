# Is Multiply Recurrent

A point `x : X` is **multiply recurrent** for `T : X → X` if for
every `d ≥ 1` there is a strictly increasing `n : ℕ → ℕ` such that
`T^{j · n_k}(x) → x` for every `j ∈ {1, …, d}`.
