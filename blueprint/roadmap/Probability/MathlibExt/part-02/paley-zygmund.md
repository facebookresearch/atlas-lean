# The Paley-Zygmund Inequality

**The Paley-Zygmund Inequality**: If `Z ≥ 0` is a random variable with finite variance, and if
`0 ≤ θ ≤ 1`, then `P(Z > θ * EZ) ≥ (1-θ)^2 (EZ)^2/E(Z^2)`.
