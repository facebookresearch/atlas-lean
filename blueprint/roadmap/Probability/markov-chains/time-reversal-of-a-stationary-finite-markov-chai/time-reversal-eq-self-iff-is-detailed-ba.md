# A chain equals its time reversal iff detailed balance holds

Let $P$ be a row-stochastic matrix on a finite state space and $\pi$ a stationary distribution
($\pi P = \pi$) with $\pi_i > 0$ for all $i$ and $\sum_i \pi_i = 1$. Then the time-reversed matrix
$(\pi_j P_{ji} / \pi_i)_{ij}$ equals $P$ if and only if $P$ satisfies detailed balance with respect
to $\pi$.
