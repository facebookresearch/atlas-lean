# Variance of a function under a weight vector

For a finite set $S$, $\pi : S \to \mathbb{R}$ and $f : S \to \mathbb{R}$,

$$\operatorname{Var}_\pi(f) = \frac{1}{2} \sum_{x, y \in S} \bigl(f(x) - f(y)\bigr)^2 \pi(x)\pi(y) .$$

For a probability vector $\pi$ this is $\sum_x \pi(x) (f(x) - \mathbb E_\pi f)^2$.

## Sources

- P. Diaconis and L. Saloff-Coste, *Logarithmic Sobolev inequalities for finite Markov chains*, Annals of Applied Probability 6 (1996), 695–750, equation (1.4).
