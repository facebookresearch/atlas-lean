# Elements of the domain vanishing outside a set

Let $\mathcal E$ be a [symmetric form](symmetric-form.md) on $L^2(X; m)$, with $X$ a topological
space, and $F \subseteq X$. Then

$$D[\mathcal E]_F = \{ u \in D[\mathcal E] : u = 0 \ m\text{-a.e. on } X \setminus F \} .$$

## Sources

- M. Röckner and B. Schmuland, *Quasi-regular Dirichlet forms: examples and counterexamples*, Canadian Journal of Mathematics 47 (1995), 165–200, Definition 0.5(i), equation (0.3).
