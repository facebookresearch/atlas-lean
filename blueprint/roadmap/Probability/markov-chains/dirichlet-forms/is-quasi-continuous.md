# Quasi-continuous functions

Let $X$ be a topological space with a measure $m$ and $\mathcal E$ a [symmetric
form](symmetric-form.md) on $L^2(X; m)$. A function $f : X \to \mathbb{R}$ is
$\mathcal E$-quasi-continuous if there is an [$\mathcal E$-nest](is-nest.md) $(F_k)$ such that the
restriction of $f$ to each $F_k$ is continuous. A function defined only quasi-everywhere is
represented by any extension, its values off $\bigcup_k F_k$ playing no role.

## Sources

- M. Röckner and B. Schmuland, *Quasi-regular Dirichlet forms: examples and counterexamples*, Canadian Journal of Mathematics 47 (1995), 165–200, Definition 0.5(iv).
