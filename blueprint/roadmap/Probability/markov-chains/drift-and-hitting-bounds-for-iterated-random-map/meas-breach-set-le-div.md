# Horizon breach bound for a positive finite threshold

Let $D$ carry a probability law, let the inputs be independent with that law, let $f : S \times D \to S$ be jointly measurable and $V : S \to [0, \infty]$ measurable, and let $0 < c < \infty$ and $\beta \in [0, \infty]$. If $\mathbb{E}[V(f(x, d))] \le V(x) + \beta$ at every state with $V(x) < c$, then the probability that the chain started at $x_0$ reaches level $c$ at some mark $n \le N$ is at most $(V(x_0) + N \beta)/c$.
