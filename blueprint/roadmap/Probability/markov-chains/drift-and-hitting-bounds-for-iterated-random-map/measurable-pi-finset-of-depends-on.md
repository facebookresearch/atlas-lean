# Measurability of functions reading finitely many coordinates

Let $D$ be a nonempty measurable space and $\Phi$ a measurable function of paths $\omega : \mathbb{N} \to D$ that reads only the coordinates in a finite set $s$: $\Phi(\omega) = \Phi(\omega')$ whenever $\omega_i = \omega'_i$ for all $i \in s$. Then $\Phi$ is measurable for the σ-algebra generated by the coordinates in $s$.
