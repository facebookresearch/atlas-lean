# The stopped chain agrees with the free chain before the first breach

For a step map $f$, a level function $V$, a level $c$, a start $x_0$, an input path $\omega$ and a mark $n$, if the free chain has $c \not\le V(x_k)$ at every mark $k < n$, then the chain stopped at level $c$ agrees with the free chain at mark $n$.
