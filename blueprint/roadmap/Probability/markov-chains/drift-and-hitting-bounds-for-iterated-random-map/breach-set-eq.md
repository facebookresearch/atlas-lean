# Breach event of the free chain as a terminal event of the stopped chain

For a step map $f : S \times D \to S$, a level function $V : S \to [0, \infty]$, a level $c$, a start $x_0$ and a horizon $N$, the event that the chain driven by $f$ from $x_0$ reaches level $c$ (that is, $V \ge c$) at some mark $n \le N$ equals the event that the chain stopped at level $c$ has $V \ge c$ at mark $N$. Pointwise, for every input path $\omega$: the free chain satisfies $c \le V(x_n)$ at some mark $n \le N$ if and only if the chain stopped at level $c$ satisfies $c \le V$ at mark $N$.
