# The stopped chain stays at a level once reached

For a step map $f$, a level function $V$, a level $c$, a start $x_0$ and an input path $\omega$, if the chain stopped at level $c$ has $c \le V$ at mark $n$, then it has $c \le V$ at every later mark $m \ge n$: once the stopped chain has reached level $c$, it stays there.
