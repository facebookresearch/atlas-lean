# Reaching a level by a horizon, via the stopped chain

For a step map $f$, a level function $V$, a level $c$, a start $x_0$, an input path $\omega$ and a horizon $N$, the free chain reaches $c \le V(x_n)$ at some mark $n \le N$ if and only if the chain stopped at level $c$ satisfies $c \le V$ at mark $N$.
