# Law of an independent input path

For a measure $\lambda$ on $D$, the path measure is the infinite product measure $\lambda^{\otimes \mathbb{N}}$ on input paths $\mathbb{N} \to D$. When $\lambda$ is a probability law, as in the results that use it, it is a probability measure: the law of an input path whose inputs are independent, each distributed as $\lambda$.
