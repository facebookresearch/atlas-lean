# Transition kernel of a stochastic matrix evaluated on a set

Let $P$ be a [stochastic matrix](../kolmogorov-s-criterion-for-reversibility/stochastic-matrix.md)
on the states $\{0, 1, \dots, M\}$ with [transition kernel](finite-chain-kernel.md) $\kappa_P$.
For every state $x$ and every set of states $B$,

$$\kappa_P(x, B) = \sum_{j \in B} P(x, j) .$$
