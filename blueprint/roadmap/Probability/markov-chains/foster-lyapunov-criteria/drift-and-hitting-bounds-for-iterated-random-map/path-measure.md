# Law of an independent input path

For a measure $\lambda$ on $D$, the path measure on input paths $\mathbb{N} \to D$ has two cases. If $\lambda$ is a probability measure, it is the infinite product measure $\lambda^{\otimes \mathbb{N}}$, the law of an input path whose inputs are independent, each distributed as $\lambda$; it is then a probability measure. Otherwise it is the zero measure: for example, for $\lambda = 2\delta_x$ even the whole path space has measure $0$.
