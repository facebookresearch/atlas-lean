# Continuity of the sticky kernel in the persistence

For every $\pi : S \to \mathbb{R}$, the map $c \mapsto K_\pi(c)$ from $\mathbb{R}$ to the
$S \times S$ real matrices (with the entrywise topology), sending the persistence $c$ to the
[sticky kernel](sticky-kernel.md) $K_\pi(c) = cI + (1 - c)\mathbf 1 \pi^\top$, is continuous.
