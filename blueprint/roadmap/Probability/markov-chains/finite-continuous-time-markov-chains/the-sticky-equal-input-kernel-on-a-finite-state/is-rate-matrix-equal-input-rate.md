# Equal-input generator is a rate matrix

Let $S$ be a finite set, $\pi$ a probability vector on $S$ ($\pi \ge 0$, $\sum_i \pi(i) = 1$) and
$\kappa \ge 0$. Then the [equal-input generator](equal-input-rate.md) $\kappa(\mathbf 1 \pi^\top - I)$
is a [rate matrix](../rate-matrices-of-finite-continuous-time-markov-c/is-rate-matrix.md).
