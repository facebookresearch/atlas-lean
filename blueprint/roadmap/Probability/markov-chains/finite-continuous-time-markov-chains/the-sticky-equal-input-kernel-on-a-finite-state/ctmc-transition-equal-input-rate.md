# The sticky kernel is the equal-input transition function

Let $S$ be a finite set and $\pi : S \to \mathbb{R}$ with $\sum_i \pi(i) = 1$. For all real $\kappa$
and $t$, the [transition function](../the-transition-semigroup-of-a-finite-continuous/ctmc-transition.md)
of the [equal-input generator](equal-input-rate.md) $\kappa(\mathbf 1 \pi^\top - I)$ is the [sticky
kernel](sticky-kernel.md) with persistence $e^{-\kappa t}$:

$$e^{t \kappa (\mathbf 1 \pi^\top - I)} = K_\pi\bigl(e^{-\kappa t}\bigr) .$$
