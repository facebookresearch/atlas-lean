# Path restarts at a jump time

Let $Q$ be a real square matrix indexed by a set $S$, $i \in S$, $\omega$ a step sequence and
$n \in \mathbb{N}$ with $T_n(i, \omega) < \infty$. Then for every $s \ge 0$,

$$X_{T_n(i, \omega) + s}(i, \omega) = X_s\bigl(Y_n(i, \omega), \theta_n \omega\bigr):$$

after the [jump time](ctmc-jump-time.md) $T_n$, the [path](ctmc-path.md) is the path started at
$Y_n$ driven by the [shifted steps](ctmc-shift.md) $\theta_n \omega$.
