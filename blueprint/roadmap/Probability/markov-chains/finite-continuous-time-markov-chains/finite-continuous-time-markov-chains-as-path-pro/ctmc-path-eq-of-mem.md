# Path value between consecutive jump times

Let $Q$ be a real square matrix indexed by a set $S$, $i \in S$, $\omega$ a step sequence, $t \ge 0$
and $n \in \mathbb{N}$. If $T_n(i, \omega) \le t < T_{n+1}(i, \omega)$, then the [path](ctmc-path.md)
satisfies $X_t(i, \omega) = Y_n(i, \omega)$, where $T$ are the [jump times](ctmc-jump-time.md) and
$Y$ the [jump chain](ctmc-jump-chain.md).
