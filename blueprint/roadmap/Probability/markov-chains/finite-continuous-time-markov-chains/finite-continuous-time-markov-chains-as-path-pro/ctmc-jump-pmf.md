# Row of the jump matrix as a probability mass function

Let $Q$ be a [rate matrix](../rate-matrices-of-finite-continuous-time-markov-c/is-rate-matrix.md) on a
finite set $S$ and $i \in S$. Row $i$ of its [jump matrix](ctmc-jump-matrix.md) defines the
probability mass function $j \mapsto \Pi(i, j)$ on $S$ (its entries are nonnegative and sum to $1$).
