# Jump times of a continuous-time Markov chain

Let $Q$ be a real square matrix indexed by a set $S$, $i \in S$ and $\omega$ a step sequence, with
[holding times](ctmc-holding-time.md) $S_k = S_k(i, \omega) \in [0, \infty]$. The $n$-th jump time is

$$T_n = S_0 + S_1 + \dots + S_{n-1} \in [0, \infty], \qquad T_0 = 0 .$$
