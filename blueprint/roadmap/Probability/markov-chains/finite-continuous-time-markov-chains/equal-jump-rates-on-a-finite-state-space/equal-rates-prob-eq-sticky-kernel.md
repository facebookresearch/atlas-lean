# Equal jump rates give the sticky kernel

On $n + 1$ states, with rate $\mu$ and time $t$, the equal-rates transition matrix equals the sticky kernel $c I + (1 - c)\, \mathbf 1 \pi^{\mathsf T}$ with $c = e^{-(n+1)\mu t/n}$ and uniform redraw probabilities $\pi_j = 1/(n+1)$: keep the current state with weight $c$, otherwise redraw a state uniformly.
