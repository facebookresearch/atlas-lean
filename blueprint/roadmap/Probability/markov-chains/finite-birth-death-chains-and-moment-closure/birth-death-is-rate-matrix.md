# The birth–death generator is a rate matrix

For a natural number `N`, a real `α ≥ 0` and a function `f : ℕ → ℝ` with `f(i) ≥ 0` for every
`i ≤ N`, the [birth–death generator](birth-death-generator.md) is a
[rate matrix](../finite-continuous-time-markov-chains/rate-matrices-of-finite-continuous-time-markov-c/is-rate-matrix.md):
its off-diagonal entries are nonnegative and every row sums to zero.
