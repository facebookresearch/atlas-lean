# No death from state 0 and no birth from state N

For a natural number `N`, a real `α` and a function `f : ℕ → ℝ`, the death-rate formula `α i` is
`0` at `i = 0` and the birth-rate formula `(N - i) f(i)` is `0` at `i = N`: the
[birth–death generator](birth-death-generator.md) has no death from state `0` and no birth from
state `N`.
