# Reindexing an ordered vector by a finite set

Let $J \subset [0, \infty)$ be a finite set with $k$ elements and increasing enumeration
$j_0 < j_1 < \dots < j_{k-1}$. Reindexing by $J$ is the bimeasurable bijection
$E^k \to E^J$ sending $(y_0, \dots, y_{k-1})$ to the family $(z_t)_{t \in J}$ with $z_{j_i} = y_i$.
