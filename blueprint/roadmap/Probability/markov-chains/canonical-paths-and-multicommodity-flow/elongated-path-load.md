# Length-weighted flow of a path system through an oriented edge

For canonical paths $\gamma_{xy}$ and weights $\pi$, the length-weighted load of the oriented edge $(u,v)$ is $\sum_{x \ne y}\pi(x)\pi(y)\,|\gamma_{xy}|\,m_{xy}(u,v)$, with $m_{xy}(u,v)$ the number of times $\gamma_{xy}$ uses $(u,v)$ and $|\gamma_{xy}|$ its number of edges. For simple paths this is the numerator of $\bar\rho(\Gamma) = \max_e Q(e)^{-1}\sum_{\gamma_{xy} \ni e}\pi(x)\pi(y)|\gamma_{xy}|$, equation (4) of A. Sinclair, *Combinatorics, Probability and Computing* 1 (1992).
