# $\ell_1$ norm on a support set bounded by the $\ell_2$ norm

For a finite set $S$ of coordinates and every vector $\Delta$,

$$\|\Delta_S\|_1 \le \sqrt{|S|}\, \|\Delta\|_2,$$

by the Cauchy–Schwarz inequality.

## Sources

- T. Hastie, R. Tibshirani and M. J. Wainwright, *Statistical Learning with Sparsity: The Lasso and Generalizations*, CRC Press, 2015: <https://hastie.su.domains/StatLearnSparsity/>, proof of Theorem 11.1.
