# Unbiasedness of the generalized least-squares estimator

Let $m, k$ be finite index sets, $X$ a real $m \times k$ matrix and $V$ a real $m \times m$ matrix such that $X^\top V^{-1} X$ is invertible. Then the [GLS matrix](gls-matrix.md) $B = (X^\top V^{-1} X)^{-1} X^\top V^{-1}$ satisfies $BX = I_k$, so the GLS estimator is unbiased.
