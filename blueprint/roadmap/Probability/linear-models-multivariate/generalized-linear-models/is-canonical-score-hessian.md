# Canonical-link score and Hessian identities

For a design $X$, responses $y$, a mean function $\mu = b'$ and a weight function $V = b''$, a score $U$ and Hessian $H$ satisfy the canonical-link identities if $U(\beta) = X^\top(y - \mu(X\beta))$ and $H(\beta) = -X^\top W(\beta)X$ with $W(\beta) = \operatorname{diag}(V((X\beta)_i))$ for every $\beta$; observed and Fisher information then coincide.
