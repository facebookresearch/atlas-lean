# Mixed second derivative of the negative binomial log mass function

For a shape $\theta$, a response $y$ and a linear predictor $\eta$, the mixed second derivative of the log mass function in $\theta$ and $\eta$ is $(y - \mu)\mu/(\theta + \mu)^2$ with $\mu = e^\eta$. For any real $\theta$; a zero denominator $(\theta + \mu)^2 = 0$ gives $0$.
