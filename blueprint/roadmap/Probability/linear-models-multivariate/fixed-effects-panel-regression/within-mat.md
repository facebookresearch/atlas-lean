# Within transformation of a regressor matrix

For an assignment $g : \iota \to G$ of a finite set of observations to groups and a real $\iota \times \pi$ matrix $X$, the within transformation is $\ddot X_{ij} = X_{ij} - \bar X_{g(i), j}$, where $\bar X_{h, j}$ is the mean of column $j$ over group $h$.
