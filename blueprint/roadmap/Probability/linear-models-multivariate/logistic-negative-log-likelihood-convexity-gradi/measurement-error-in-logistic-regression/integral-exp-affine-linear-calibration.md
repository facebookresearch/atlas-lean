# Log-linear risk with a linear calibration function

For all $\alpha, \beta, \mu_x, \rho, w \in \mathbb{R}$ and $\tau^2 \ge 0$,

$$\int e^{\alpha + \beta x}\,d\mathcal N\big(\mu_x + \rho(w - \mu_x), \tau^2\big)(x) = \exp\big(\alpha + \beta^2\tau^2/2 + \beta(1 - \rho)\mu_x + \rho\beta w\big):$$

the induced model is log-linear in $w$ with the attenuated slope $\rho\beta$.
