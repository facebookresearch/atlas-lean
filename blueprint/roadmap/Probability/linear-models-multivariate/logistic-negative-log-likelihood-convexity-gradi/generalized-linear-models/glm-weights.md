# Working weights of a generalized linear model

Let $(\Theta, b, \mu, V)$ be a canonical cumulant specification: an open convex natural-parameter domain $\Theta \subseteq \mathbb{R}$, a cumulant $b$ with $b' = \mu$ and $\mu' = V \ge 0$ on $\Theta$. The working weights are $W_i(\beta) = V(\eta_i(\beta))$, where $\eta(\beta) = X\beta + o$.
