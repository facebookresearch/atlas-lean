# Cumulant specification of a canonical-link generalized linear model

A canonical cumulant specification consists of an open convex natural-parameter domain $\Theta \subseteq \mathbb{R}$ (possibly empty), a cumulant function $b$, a mean function $\mu$ and a variance function $V$ with $b' = \mu$, $\mu' = V$ and $V \ge 0$ on $\Theta$. No base measure is specified, so it does not by itself define a distribution.
