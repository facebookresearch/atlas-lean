# Coefficient domain of a generalized linear model

Let $(\Theta, b, \mu, V)$ be a canonical cumulant specification: an open convex natural-parameter domain $\Theta \subseteq \mathbb{R}$, a cumulant $b$ with $b' = \mu$ and $\mu' = V \ge 0$ on $\Theta$. For a design $X$ and offset $o$, the coefficient domain is the set of $\beta$ whose linear predictor $X\beta + o$ lies in $\Theta$ in every coordinate.
