# Complete separation prevents a logistic maximum-likelihood estimate

For the single-covariate design $x = (-1, 1)$ without intercept or offset and responses $y = (0, 1)$, the logistic log-likelihood $\ell(\beta) = -2\log(1 + e^{-\beta})$ has no maximizer, although the design has full column rank so a maximizer would be unique.
