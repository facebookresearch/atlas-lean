# Observed shape information of a negative binomial count

For a shape $\theta$, a count $y$ and a linear predictor $\eta$, the observed shape information is $\sum_{j<y}\frac1{(\theta + j)^2} - \frac1\theta + \frac1{\theta + \mu} - \frac{y - \mu}{(\theta + \mu)^2}$ with $\mu = e^\eta$. For any real $\theta$; real division and inversion use $x/0 = 0$ and $0^{-1} = 0$.
