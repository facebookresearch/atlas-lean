# Negative binomial log-likelihood kernel

For a shape $\theta$, a response $y$ and a linear predictor $\eta$ (mean $e^\eta$), the negative binomial kernel is $y\eta - (y + \theta)\log(\theta + e^\eta)$, the part of the log mass function depending on $\eta$. For any real $\theta$; here $\log$ is the real logarithm extended by $\log 0 = 0$ and $\log x = \log|x|$ for $x < 0$.
