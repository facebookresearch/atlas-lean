# The profile is attained at a section maximizer

For a design $X$, offset $o$ and counts $y$, let $\ell(\beta, \theta)$ be the joint negative binomial log-likelihood, $\ell_0(\theta) = \ell(\beta_0, \theta)$ its restriction to the null $\beta = \beta_0$, and $\ell_{\mathrm{prof}}(\theta) = \sup_\beta\ell(\beta, \theta)$ the profile log-likelihood of the shape. If $\beta$ maximizes $b \mapsto \ell(b, \theta)$, then $\ell_{\mathrm{prof}}(\theta) = \ell(\beta, \theta)$.
