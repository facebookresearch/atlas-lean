# The composite likelihood-ratio statistic as a difference

For every reference parameter $p_0$, the composite likelihood-ratio statistic $2\sum_{i<n}(\log f_{\hat p}(z_i) - \log f_{(\beta_0, \tilde\theta)}(z_i))$ equals $2\sum_{i<n}(\log f_{\hat p}(z_i) - \log f_{p_0}(z_i)) - 2\sum_{i<n}(\log f_{(\beta_0, \tilde\theta)}(z_i) - \log f_{p_0}(z_i))$.
