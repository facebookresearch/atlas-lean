# The joint log-likelihood is below the profile

For a design $X$, offset $o$ and counts $y$, let $\ell(\beta, \theta)$ be the joint negative binomial log-likelihood, $\ell_0(\theta) = \ell(\beta_0, \theta)$ its restriction to the null $\beta = \beta_0$, and $\ell_{\mathrm{prof}}(\theta) = \sup_\beta\ell(\beta, \theta)$ the profile log-likelihood of the shape. For $\theta > 0$ and every $\beta$, $\ell(\beta, \theta) \le \ell_{\mathrm{prof}}(\theta)$.
