# All components explain all of the variance

Let $X$ be a real $n \times p$ data matrix whose rows are observations. If its [sample covariance matrix](sample-cov.md) $S$ has $\operatorname{tr} S > 0$ and $k \ge p$, then the first $k$ principal components explain all of the variance: the [proportion of variance explained](variance-explained.md) is $1$.
