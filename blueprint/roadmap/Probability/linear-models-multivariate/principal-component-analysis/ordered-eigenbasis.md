# Ordered orthonormal eigenbasis of a symmetric matrix

Let $S$ be a real symmetric $p \times p$ matrix with eigenvalues $\lambda_0 \ge \dots \ge \lambda_{p-1}$. An ordered orthonormal eigenbasis is an orthonormal basis $v_0, \dots, v_{p-1}$ of $\mathbb{R}^p$ with $S v_k = \lambda_k v_k$ for every $k$; for a covariance matrix these are the principal axes.
