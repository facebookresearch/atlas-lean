# Rank criterion

Let $R$ be a field, $n$ a finite index set and $(A_k)_{k \in \kappa}$ a finite family of $n \times n$ matrices over $R$ with $\sum_k A_k = I$. Then

$$\sum_k \operatorname{rank} A_k = |n| \iff A_k^2 = A_k \text{ for every } k \text{ and } A_k A_l = 0 \text{ for all } k \ne l.$$

## Sources

- W. G. Cochran, *The distribution of quadratic forms in a normal system, with applications to the analysis of covariance*, Proc. Cambridge Philos. Soc. 30 (1934), 178–191.
