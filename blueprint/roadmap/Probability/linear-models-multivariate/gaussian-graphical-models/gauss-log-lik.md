# Gaussian log-likelihood of a precision matrix

Let $\iota$ be a finite index set and $S, K$ real $\iota \times \iota$ matrices. The Gaussian log-likelihood objective of the precision matrix $K$ is

$$\ell(S, K) = \log \det K - \operatorname{tr}(S K),$$

with the convention $\log x = \log |x|$ and $\log 0 = 0$.
