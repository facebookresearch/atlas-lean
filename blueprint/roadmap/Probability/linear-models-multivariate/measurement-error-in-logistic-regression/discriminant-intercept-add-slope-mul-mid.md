# Logistic discriminant lines pass through the prior log odds at the midpoint

For a prior $p$, class means $\mu_0, \mu_1$ and any variance $v$, the discriminant line $\alpha + \beta x$ (with $\beta = (\mu_1 - \mu_0)/v$ and $\alpha = \log\frac{p}{1-p} - \beta\frac{\mu_0 + \mu_1}{2}$) takes the value $\log\frac{p}{1-p}$ at $x = (\mu_0 + \mu_1)/2$.
