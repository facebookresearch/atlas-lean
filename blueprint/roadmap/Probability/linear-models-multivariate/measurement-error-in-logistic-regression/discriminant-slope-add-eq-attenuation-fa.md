# Measurement error attenuates the discriminant slope

For class means $\mu_0, \mu_1$ and variances $v \ne 0$ and $v_u$, $\frac{\mu_1 - \mu_0}{v + v_u} = \frac{v}{v + v_u}\cdot\frac{\mu_1 - \mu_0}{v}$: adding measurement-error variance multiplies the slope by the reliability ratio (with $a/0 = 0$).
