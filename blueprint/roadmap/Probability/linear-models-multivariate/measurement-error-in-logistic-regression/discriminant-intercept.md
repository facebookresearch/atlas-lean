# Intercept of the normal discriminant model

For a prior $p$, class means $\mu_0, \mu_1$ and a common variance $v$, the logistic intercept of the normal discriminant model is $\log\frac{p}{1-p} - \frac{\mu_1 - \mu_0}{v}\cdot\frac{\mu_0 + \mu_1}{2}$. Real division and inversion use $x/0 = 0$ and $0^{-1} = 0$. Here $\log$ is the real logarithm extended by $\log 0 = 0$ and $\log x = \log|x|$ for $x < 0$.
