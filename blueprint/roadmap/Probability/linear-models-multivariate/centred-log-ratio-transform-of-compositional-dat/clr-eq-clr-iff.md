# Two positive compositions have the same CLR iff they are proportional

Let $\iota$ be a finite set of parts and $x, y$ [positive compositions](pos-composition.md) on
$\iota$. Then $\operatorname{clr}(x) = \operatorname{clr}(y)$ if and only if $y = t \cdot x$
for some real $t > 0$, where $t \cdot x = (t x_i)_{i \in \iota}$. So the positive compositions
with the same [CLR transform](clr.md) as $x$ form exactly the ray $\{t \cdot x : t > 0\}$.
