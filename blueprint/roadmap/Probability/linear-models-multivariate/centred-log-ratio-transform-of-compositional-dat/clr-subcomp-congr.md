# Compositions with equal CLR have subcompositions with equal CLR

Let $\iota$ be a finite set of parts, $S \subseteq \iota$ a set of parts and $x, y$
[positive compositions](pos-composition.md) on $\iota$ with the same [CLR transform](clr.md),
$\operatorname{clr}(x) = \operatorname{clr}(y)$. Then their [subcompositions](subcomp.md) on
$S$ have the same CLR transform over the parts of $S$:
$\operatorname{clr}(x_S) = \operatorname{clr}(y_S)$. So the CLR of a subcomposition is a
function of the full CLR alone.
