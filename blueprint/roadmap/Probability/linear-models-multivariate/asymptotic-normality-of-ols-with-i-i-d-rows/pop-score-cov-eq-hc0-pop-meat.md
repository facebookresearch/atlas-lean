# Population score covariance equals the population HC0 meat

For a regressor vector $X_0$ with values in $\mathbb{R}^k$, $k$ finite, an error $U_0$ and a measure $\mu$, the population score covariance matrix is, by definition, the population meat of the HC0 sandwich covariance, the matrix with entries $\int U_0^2\, X_{0,a} X_{0,b} \, d\mu$ (no centring is applied).
