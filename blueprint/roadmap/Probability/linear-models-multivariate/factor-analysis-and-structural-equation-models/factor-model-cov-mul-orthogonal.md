# Orthogonal rotation preserves the factor-model covariance

For intercepts $\nu$, a loading matrix $\Lambda$, factor means $a$, a factor covariance $\Phi$ and an error covariance $\Theta$, the factor model implies mean $\nu + \Lambda a$ and covariance $\Lambda\Phi\Lambda^\top + \Theta$. If $UU^\top = I$, then $\Lambda U\,(\Lambda U)^\top + \Theta = \Lambda\Lambda^\top + \Theta$: rotating the loadings leaves the covariance with $\Phi = I$ unchanged.
