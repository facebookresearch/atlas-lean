# Population attenuation identity

Let $X$, $e$, $\varepsilon$ be square-integrable, pairwise independent random variables on a probability space, $W = X + e$ and $Y = \alpha + \beta X + \varepsilon$. Then

$$\frac{\mathrm{Cov}(W, Y)}{\mathrm{Var}(W)} = \frac{\mathrm{Var}(X)}{\mathrm{Var}(X) + \mathrm{Var}(e)}\,\beta,$$

with both quotients read as $0$ when the denominator is $0$.
