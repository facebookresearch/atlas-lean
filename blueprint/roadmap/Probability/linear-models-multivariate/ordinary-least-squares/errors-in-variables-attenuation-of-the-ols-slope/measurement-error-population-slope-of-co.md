# Population least-squares slope under measurement error

Let $(\Omega, \mu)$ be a probability space and $X, e, \varepsilon$ square-integrable real random variables that are pairwise uncorrelated, let $\alpha, \beta \in \mathbb{R}$, and set $Y = \alpha + \beta X + \varepsilon$ and $W = X + e$ with $\operatorname{Var}(W) \neq 0$. For $b \in \mathbb{R}$, the residual $Y - bW$ is uncorrelated with $W$ if and only if

$$b = \frac{\operatorname{Var}(X)}{\operatorname{Var}(X) + \operatorname{Var}(e)}\,\beta.$$
