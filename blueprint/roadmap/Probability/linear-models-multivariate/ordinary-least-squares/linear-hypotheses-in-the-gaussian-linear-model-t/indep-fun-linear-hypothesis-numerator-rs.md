# Independence of the linear-hypothesis numerator and the residual sum of squares

Let $X$ be a real $m \times k$ design matrix with $X^\top X$ invertible, and consider the linear model $y = X\beta + \varepsilon$ with $\beta \in \mathbb{R}^k$ and a random error vector $\varepsilon$ in $\mathbb{R}^m$ on a probability space. Write $\hat\beta(y) = (X^\top X)^{-1} X^\top y$ for the ordinary least-squares estimator. Suppose $\sigma > 0$ and $\sigma^{-1}\varepsilon$ is a standard Gaussian vector (independent standard normal coordinates). Let $C$ be any real $r \times k$ matrix and $c \in \mathbb{R}^r$, and write $N = (C\hat\beta - c)^\top\big(C(X^\top X)^{-1}C^\top\big)^{-1}(C\hat\beta - c)/\sigma^2$ for $\hat\beta = \hat\beta(X\beta + \varepsilon)$ (matrix inverse, zero when singular). Then $N$ is independent of $\|y - X\hat\beta\|^2/\sigma^2$, $y = X\beta + \varepsilon$; no null hypothesis is needed.
