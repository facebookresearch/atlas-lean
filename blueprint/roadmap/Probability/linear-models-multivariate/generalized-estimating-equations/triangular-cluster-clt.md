# Triangular-array central limit theorem for cluster scores

Let rows of cluster scores $U_{n,i}$, $i < n$, on a probability space be independent within rows, measurable, mean zero and bounded by $Km_{n,i}$ for some $K \ge 0$, with row variance $B_n^2$ eventually positive. If $KM_n/B_n \to 0$, then $\sum_{i<n}U_{n,i}/B_n$ converges in distribution to a standard normal variable.
