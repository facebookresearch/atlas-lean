# A growing dominant cluster breaks the Lindeberg condition

On a probability space, for the cluster sizes with cluster $0$ of row $n$ of size $n$ and the others of size $1$, and measurable square-integrable cluster scores with $\mathbb{E}[U_{n,i}^2] = c\,m_{n,i}$, $c > 0$, the normalized array $U_{n,i}/B_n$ fails the Lindeberg condition.
