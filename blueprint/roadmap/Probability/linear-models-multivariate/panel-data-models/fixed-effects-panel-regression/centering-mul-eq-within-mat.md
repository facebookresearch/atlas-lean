# Time-demeaning as the within transformation of a matrix

Let $\tau$ be a finite set of $T$ periods and $Q = I - T^{-1}J$ the time-demeaning matrix ($J$ the all-ones matrix). For every real $T \times k$ matrix $X$, $QX$ is the column-wise within transformation of $X$ with all periods in one group: $(QX)_{tj} = X_{tj} - \frac1T\sum_s X_{sj}$.
