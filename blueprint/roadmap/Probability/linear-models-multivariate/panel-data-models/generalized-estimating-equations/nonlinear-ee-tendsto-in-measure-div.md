# Triangular weak law for a cluster estimating function

Fix $\beta$ and let the cluster contributions $\psi_{n,i}(\beta)$, $i < n$, be square integrable and pairwise independent within rows on a probability space, with $a_n \ne 0$ eventually. If $\sum_i\mathbb{E}[\psi_{n,i}(\beta)]/a_n \to c$ and $\sum_i\operatorname{Var}(\psi_{n,i}(\beta))/a_n^2 \to 0$, then $\Psi_n(\beta)/a_n \to c$ in probability.
