# An all-success sample has no estimating-equation root

If every observation is a success ($S_i = m_i$) and some cluster is nonempty, then $\sum_{i<n}(S_i - m_ig(\beta)) \ne 0$ for every $\beta$, where $g(\beta) = e^\beta/(1+e^\beta)$ is the logistic mean, so the binary estimating equation has no root.
