# Linearization bound for a root

Let $f$ have derivative $f'$ on $[\beta_0 - \delta, \beta_0 + \delta]$ with $|f'(\beta) + D| \le \varepsilon D$ there, where $D > 0$ and $0 \le \varepsilon < 1$. If $b$ lies in the interval and $f(b) = 0$, then $|D(b - \beta_0) - f(\beta_0)| \le \frac\varepsilon{1 - \varepsilon}|f(\beta_0)|$.
