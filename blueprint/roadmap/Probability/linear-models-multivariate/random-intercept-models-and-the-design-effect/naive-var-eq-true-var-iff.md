# Naive variance is exact iff no donor variance or one cell per donor

For real $\sigma_b^2$, $\sigma_e^2$ and natural numbers $D \ne 0$ and $m \ne 0$, the
[naive variance](naive-var.md) $V_{\mathrm{naive}}(D, m) = (\sigma_b^2 + \sigma_e^2) / (D m)$ equals
the [true variance](true-var.md) $V_{\mathrm{true}}(D, m) = \sigma_b^2 / D + \sigma_e^2 / (D m)$ if
and only if $\sigma_b^2 = 0$ or $m = 1$.
