# Pseudobulk value of a donor

Let $\kappa$ be a finite set of $m$ cell slots. For cell values
$Y_{(d, c)} : \Omega \to \mathbb{R}$, the pseudobulk value of donor $d$ is the mean of its $m$
cells,

$$\bar Y_d(\omega) = \frac{1}{m} \sum_{c \in \kappa} Y_{(d, c)}(\omega).$$

With the convention $x / 0 = 0$ it is $0$ when $m = 0$.
