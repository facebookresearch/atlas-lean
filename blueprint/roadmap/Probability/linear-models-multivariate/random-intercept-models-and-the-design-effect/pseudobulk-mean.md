# Mean of the pseudobulk values

Let $\delta$ be a finite set of $D$ donors and $\kappa$ a finite set of $m$ cell slots, so that
every donor has $m$ cells $i = (d, c)$ (a balanced design). The mean of the $D$
[pseudobulk values](pseudobulk.md) $\bar Y_d$ is

$$\bar Y_{\mathrm{pb}}(\omega) = \frac{1}{D} \sum_{d \in \delta} \bar Y_d(\omega),$$

which is $0$ when $D = 0$, by the convention $x / 0 = 0$.
