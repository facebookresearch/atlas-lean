# Mass of a set under the stick-breaking measure

For real proportions $b = (b_k)$, atoms $\theta = (\theta_k)$ in a measurable space $X$ and a measurable set $A \subseteq X$, the [stick-breaking measure](stick-breaking-measure.md) gives

$$A \mapsto \sum_{k \ge 0} \max\big(\pi_k(b), 0\big)\, \mathbf{1}_A(\theta_k).$$
