# Predictive probability of a set in the Blackwell–MacQueen urn

For $\alpha \in \mathbb{R}$, a measure $H$ on a measurable space $X$, $x_0, \dots, x_{n-1} \in X$ and a measurable set $A \subseteq X$, the [predictive law](polya-urn-predictive.md) gives

$$A \mapsto \frac{\alpha H(A) + \#\{i < n : x_i \in A\}}{\alpha + n},$$

with the conventions of the predictive law for $\alpha \le 0$.
