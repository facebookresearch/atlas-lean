# Last draw opens a new block iff it is new

For a set $X$, $x_0, \dots, x_{n-1} \in X$ and $x \in X$, the [tie partition](tie-partition.md) of $(x_0, \dots, x_{n-1}, x)$ is the tie partition of $(x_0, \dots, x_{n-1})$ with $n$ added as a new singleton block (a new table in the Chinese restaurant) if and only if $x \notin \{x_0, \dots, x_{n-1}\}$.
