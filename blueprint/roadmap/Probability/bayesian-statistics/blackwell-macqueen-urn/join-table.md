# Seating a customer at an occupied table

For a natural number $n$, a set partition $\pi$ of $\{0, \dots, n-1\}$ and a block $B$ of $\pi$, the set partition of $\{0, \dots, n\}$ in which the block $B$ becomes $B \cup \{n\}$ and the other blocks of $\pi$ are unchanged: customer $n$ joins the table $B$.
