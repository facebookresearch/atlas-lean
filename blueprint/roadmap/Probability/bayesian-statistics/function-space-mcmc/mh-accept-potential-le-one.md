# The acceptance probability is at most one

For every potential $\Phi$ and all $u$, $v$, $a(u, v) = \min\{1, \exp(\Phi(u) - \Phi(v))\} \le 1$, so
$1 - a(u, v)$ is a genuine rejection probability.
