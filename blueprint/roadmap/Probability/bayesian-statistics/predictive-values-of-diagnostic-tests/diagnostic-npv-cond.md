# Negative predictive value as a conditional probability

Let $D$ (disease) and $T$ (positive test) be measurable events on a probability space with $P(D \cap T) = \pi\,\mathrm{se}$, $P(D \cap T^c) = \pi(1 - \mathrm{se})$, $P(D^c \cap T) = (1 - \pi)(1 - \mathrm{sp})$ and $P(D^c \cap T^c) = (1 - \pi)\mathrm{sp}$, for a prevalence $\pi$, sensitivity $\mathrm{se}$ and specificity $\mathrm{sp}$. If $(1 - \pi)\mathrm{sp} + \pi(1 - \mathrm{se}) \ne 0$, then $P(D^c \mid T^c) = (1 - \pi)\mathrm{sp}/((1 - \pi)\mathrm{sp} + \pi(1 - \mathrm{se}))$.
