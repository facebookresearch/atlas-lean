# Positive predictive value

Let $D$ (disease) and $T$ (positive test) be measurable events on a probability space with $P(D \cap T) = \pi\,\mathrm{se}$, $P(D \cap T^c) = \pi(1 - \mathrm{se})$, $P(D^c \cap T) = (1 - \pi)(1 - \mathrm{sp})$ and $P(D^c \cap T^c) = (1 - \pi)\mathrm{sp}$, for a prevalence $\pi$, sensitivity $\mathrm{se}$ and specificity $\mathrm{sp}$. If $\pi\,\mathrm{se} + (1 - \pi)(1 - \mathrm{sp}) \ne 0$, then

$$\frac{P(D \cap T)}{P(T)} = \frac{\pi\,\mathrm{se}}{\pi\,\mathrm{se} + (1 - \pi)(1 - \mathrm{sp})}.$$
