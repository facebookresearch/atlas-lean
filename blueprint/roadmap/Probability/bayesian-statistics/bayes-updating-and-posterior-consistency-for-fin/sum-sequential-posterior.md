# Normalization of the sequential posterior

Let $\Theta$ be a finite set of hypotheses, $\pi : \Theta \to \mathbb{R}$ prior weights and $L : \Theta \to \mathbb{R}$ likelihood weights; write $E(\pi, L) = \sum_\theta \pi(\theta) L(\theta)$ for the evidence and $\pi_L(\theta) = \pi(\theta)L(\theta)/E(\pi, L)$ for the Bayes update (the zero function when $E(\pi, L) = 0$, by $x/0 = 0$). For a list $L_1, \dots, L_k$ of likelihood weights write $\prod_j L_j$ for their pointwise product (the batch likelihood, $1$ for the empty list) and $\pi_{L_1, \dots, L_k}$ for the sequential posterior, obtained by updating on $L_1$, then $L_2$, and so on. If $\pi \ge 0$, $\sum_\theta \pi(\theta) = 1$, every $L_j \ge 0$ and $E(\pi, \prod_j L_j) > 0$, then the sequential posterior sums to $1$.
