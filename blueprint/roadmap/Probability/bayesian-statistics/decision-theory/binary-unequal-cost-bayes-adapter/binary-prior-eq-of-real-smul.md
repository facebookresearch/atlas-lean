# Binary Prior eq of Real smul

For all real numbers $\pi_0, \pi_1$, the binary prior on $\{0, 1\}$ (false $= 0$, true $= 1$) equals

$$\max(\pi_0, 0)\, \delta_0 + \max(\pi_1, 0)\, \delta_1,$$

with the weights $\max(\pi_i, 0)$ read as extended nonnegative reals in $[0, \infty]$ rather than as nonnegative reals.
