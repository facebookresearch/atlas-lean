# Pooled shrinkage

For a nonempty finite set of cells with size factors `sⱼ > 0`, counts `kⱼ ∈ ℕ`, `K = ∑ⱼ kⱼ` and
`S = ∑ⱼ sⱼ`, real `a` and `b > 0`, `(a + K) / (b + S) = w · (K / S) + (1 − w) · (a / b)` with the
[shrinkage weight](shrinkage-weight.md) `w = S / (b + S)`. For `a > 0` the left side is the pooled
posterior mean: the pooled rate estimate `K / S` shrunk toward the prior mean `a / b`.
