# Method-of-moments rate estimate

For real numbers `s`, `M` and `V`, the rate estimate is `b̂ = s M / (V − M)`, with the convention
`x / 0 = 0` when `V = M`. For a size factor `s > 0` and overdispersed moments `0 < M < V` it inverts
