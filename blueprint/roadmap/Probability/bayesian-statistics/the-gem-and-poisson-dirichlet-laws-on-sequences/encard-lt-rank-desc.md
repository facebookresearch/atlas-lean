# The k-th largest values have the same counting function

For a real sequence $p$ that is bounded above and every threshold $t$, the number of indices $k$ with $t <$ ($k$-th largest value of $p$) equals the number of indices $i$ with $t < p_i$, counted in $\mathbb{N} \cup \{\infty\}$: the sequence of [$k$-th largest values](rank-desc.md) ($k = 0, 1, \dots$; each the supremum over $(k+1)$-element index sets of the minimum, in general not an entry of $p$) has the same counting function as $p$.
