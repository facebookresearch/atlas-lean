# The decreasing-rearrangement map is measurable

The map sending a real sequence $p$ to its decreasing rearrangement $(\text{the } k\text{-th largest value of } p)_{k \in \mathbb{N}}$, each entry the real supremum of the minima over $(k+1)$-element index sets (read as $0$ when unbounded), is measurable from $\mathbb{R}^\mathbb{N}$ to $\mathbb{R}^\mathbb{N}$.
