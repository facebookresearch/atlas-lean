# The closed-form expected number of ones tends to $N\alpha$

For $\alpha \ge 0$ and $N \in \mathbb{N}$, the [closed-form expected number of ones](expected-ones.md) $N\alpha/(1 + \alpha/K)$ of the finite feature model tends to $N\alpha$ as the number of features $K \to \infty$. The source reads this as consistent with the expected number of entries of the Indian buffet process, $N\alpha$, which follows from each object having a $\mathrm{Poisson}(\alpha)$ number of features.

## Sources

- Thomas L. Griffiths and Zoubin Ghahramani, *The Indian buffet process: an introduction and review*, J. Mach. Learn. Res. 12 (2011), 1185–1224, Section 4.6 (the limit of Equation 11).
