# Number of objects possessing a feature

For a binary feature matrix $Z = (z_{ik})$ with $N$ rows and $r$ columns ($z_{ik} \in \{0, 1\}$) and a column $k$, the feature count $m_k = \sum_i z_{ik}$ is the number of rows with a one in column $k$.
