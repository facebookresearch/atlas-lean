# Bin event of a sensor on a linearly damaged component

Let $\Omega$ be a finite scenario type, $E$ a type of components, $g \ne 0$, $b \in \mathbb{R}$, $i_0 \in E$, $d_0, r : E \to \Omega \to \mathbb{R}$, $\varepsilon : \Omega \to \mathbb{R}$, $t \in \mathbb{R}_{\ge 0}$ and $z_{\mathrm{lo}}, z_{\mathrm{hi}} \in \mathbb{R}$. A scenario $\omega$ lies in the bin event of the reading $\omega \mapsto g\,(d_0(i_0, \omega) + r(i_0, \omega)\, t) + b + \varepsilon(\omega)$ exactly when

$$z_{\mathrm{lo}} \le g\,\big(d_0(i_0, \omega) + r(i_0, \omega)\, t\big) + b + \varepsilon(\omega) \le z_{\mathrm{hi}} .$$
