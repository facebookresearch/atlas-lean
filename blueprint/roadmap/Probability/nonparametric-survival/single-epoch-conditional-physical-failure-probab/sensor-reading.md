# Calibrated sensor reading

For a gain $g \in \mathbb{R}$ with $g \ne 0$, an offset $b \in \mathbb{R}$, a damage value $d$ and a sensor error $\varepsilon$, the sensor reading is

$$z = g\, d + b + \varepsilon .$$

The condition $g \ne 0$ is an argument of the definition, so a reading with zero gain cannot be formed.
