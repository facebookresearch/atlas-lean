# The observed process is frozen after exit

In the random-censorship model, a subject has latent failure time $T$ and censoring time $C$ on a measurable space, observed time $X = \min(T, C)$, counting process $N(t) = \mathbf 1\{T \le C, T \le t\}$, censoring process $N^c(t) = \mathbf 1\{C < T, C \le t\}$ and at-risk process $Y(t) = \mathbf 1\{t \le X\}$. For $X \le s \le u$, $(N(u), N^c(u)) = (N(s), N^c(s))$.
