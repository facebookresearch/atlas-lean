# Greenwood's estimate with undefined terms set to zero

For every real $t$,

$$\hat V(t) = \hat S(t)^2 \sum_{t_j \le t} \frac{d_j}{Y_j (Y_j - d_j)},$$

where a summand with denominator $0$ is taken to be $0$. At a time with $d_j = Y_j$ the textbook summand
is undefined, so this is an identity under that convention, not agreement with the textbook formula;
the textbook formula holds when $d_j < Y_j$ at every $t_j \le t$.
