# The Nelson–Aalen error path at the grid times

Fix $\tau > 0$ and $K$ grid steps of length $\tau/K$. Let $N$ be a counting process, $Y$ an at-risk process, $\alpha$ a deterministic cumulative hazard, $\hat A = Y^{-1}\bullet N$ the Nelson–Aalen process, $\Lambda^* = \mathbf 1\{Y \ne 0\}\bullet\alpha$ and $M = N - Y\bullet\alpha$. Here $Y^{-1}$ is read as $0$ where $Y = 0$ (zero risk). For $k \le K$, the error path at $k\tau/K$ equals $\sqrt n(\hat A_k - (\alpha_k - \alpha_0))$.
