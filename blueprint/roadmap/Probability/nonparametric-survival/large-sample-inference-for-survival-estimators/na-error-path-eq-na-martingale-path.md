# On a supported horizon the error path is the martingale path

Fix $\tau > 0$ and $K$ grid steps of length $\tau/K$. Let $N$ be a counting process, $Y$ an at-risk process, $\alpha$ a deterministic cumulative hazard, $\hat A = Y^{-1}\bullet N$ the Nelson–Aalen process, $\Lambda^* = \mathbf 1\{Y \ne 0\}\bullet\alpha$ and $M = N - Y\bullet\alpha$. If $Y_{i+1}(\omega) \ne 0$ for every $i < K$, the Nelson–Aalen error path and martingale path coincide.
