# On a supported horizon the error path is the martingale path

Fix a real $\tau$ and $K$ grid steps of length $\tau/K$. Let $N$ and $Y$ be real-valued processes on the grid and $\alpha$ a deterministic real sequence (no counting-process structure is assumed; the counting model with at-risk process $Y$ and cumulative hazard $\alpha$ is an application), $\hat A = Y^{-1}\bullet N$ the Nelson–Aalen process, $\Lambda^* = \mathbf 1\{Y \ne 0\}\bullet\alpha$ and $M = N - Y\bullet\alpha$. Here $Y^{-1}$ is read as $0$ where $Y = 0$ (zero risk). If $Y_{i+1}(\omega) \ne 0$ for every $i < K$, the Nelson–Aalen error path and martingale path coincide.
