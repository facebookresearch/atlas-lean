# Observed event mass

Let the event time $T$ and the censoring time $C$ take values in a finite grid, and let $\mu$ be a measure
on the pairs $(T, C)$. The observed event mass at a grid point $j$ is the real number
$\mu(\{\min(T, C) = j, \ T \le C\})$, taken to be $0$ if this mass is infinite; ties count as events.
When $\mu$ is the joint law of $(T, C)$, it is the probability that follow-up ends at $j$ with an observed
event.
