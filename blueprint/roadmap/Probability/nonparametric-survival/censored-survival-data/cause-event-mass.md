# Observed cause-specific event mass

With competing risks, let $\mu$ be a measure on the triples $((T, J), C)$ of an event time $T$ and a
censoring time $C$ in a finite grid and a cause $J$ in a finite set. The observed event mass of cause $c$
at a grid point $j$ is the real number $\mu(\{\min(T, C) = j, \ T \le C, \ J = c\})$, taken to be $0$ if
this mass is infinite. When $\mu$ is the joint law of $((T, J), C)$, it is the probability of that event.
