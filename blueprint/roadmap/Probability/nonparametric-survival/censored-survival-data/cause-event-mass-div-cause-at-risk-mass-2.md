# Identification of the cause-specific hazard under independent censoring

Let $X = \min(T, C)$ and $\delta = 1[T \le C]$. Under independent censoring, if the observed at-risk
mass $\Pr[X \ge j]$ is nonzero, then the observed cause-$c$ event ratio
$\Pr[X = j, \ \delta = 1, \ J = c] / \Pr[X \ge j]$ equals the cause-specific hazard
$\Pr[T = j, \ J = c] / \Pr[T \ge j]$.
