# Grouping censored subject records

Let $t_1 < \dots < t_k$ be observation times, and let each of $n$ subjects $i$ be recorded at the time
$t_{g(i)}$, with an event if $\delta_i = 1$ and censored if $\delta_i = 0$. The grouped right-censored
data have $d_j = |\{i : g(i) = j, \ \delta_i = 1\}|$ deaths and $c_j = |\{i : g(i) = j, \ \delta_i = 0\}|$
censorings at $t_j$.
