# Response Positivity iff

Let $\mu$ be a measure on a measurable space $\Omega$, $R \subseteq \Omega$ and $X : \Omega \to \mathcal X$ with $\mathcal X$ finite. Write $e(x) = \mu(R \cap \{X = x\}) / \mu(X = x)$ (with $e(x) = 0$ when the denominator is $0$). Then response positivity, the existence of $\varepsilon > 0$ with $\varepsilon \le e(x)$ for every $x$ with $\mu(X = x) \ne 0$, holds if and only if

$$e(x) > 0 \quad \text{for every } x \in \mathcal X \text{ with } \mu(X = x) \ne 0.$$
