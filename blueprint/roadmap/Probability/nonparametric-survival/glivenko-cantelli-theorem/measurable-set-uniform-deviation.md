# Measurability of the uniform deviation event

Let $X_1, \dots, X_n : \Omega \to \mathbb{R}$ be measurable, let $F_n^\omega$ be the empirical distribution function of the sample $X_1(\omega), \dots, X_n(\omega)$ (identically $0$ when $n = 0$), let $F : \mathbb{R} \to \mathbb{R}$ be any function and $\varepsilon \in \mathbb{R}$. Then the event

$$\big\{\omega \in \Omega : |F_n^\omega(q) - F(q)| > \varepsilon \text{ for some } q \in \mathbb{Q}\big\}$$

is measurable, for every sample size $n$, including $n = 0$.
