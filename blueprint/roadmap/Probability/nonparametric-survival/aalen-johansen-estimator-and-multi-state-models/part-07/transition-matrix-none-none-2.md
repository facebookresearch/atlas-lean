# Aalen–Johansen survival equals Kaplan–Meier

For grouped competing-risks data viewed as multi-state data with a transient state and one absorbing state per cause, let $\hat P$ be the Aalen–Johansen transition matrix and $s$ precede every observation time. Then the transient-to-transient entry of $\hat P(s, t)$ is the Kaplan–Meier estimate $\hat S(t)$.
