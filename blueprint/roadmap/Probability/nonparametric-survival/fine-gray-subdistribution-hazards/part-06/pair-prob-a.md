# Cause-of-interest event mass of the first status map

Let $S$ be a measurable space, $\mu_0$ a measure on $S$, $\iota$ a set of causes with cause of interest $c \in \iota$, and $\varepsilon_a$ a map from $S$ to $\iota \cup \{\star\}$ ($\star$ meaning censored). The cause-of-interest event mass is

$$
p_a = \mu_0\bigl(\{x \in S : \varepsilon_a(x) = c\}\bigr) \in \mathbb{R},
$$

where the measure of a set that need not be measurable is its outer measure, and an infinite value is read as $0$.
