# Probability of a cause-specific failure in a window

Let $T$ be a failure time and $J$ a failure cause on a finite measure space with measure $P$, $F_c(t) = P(T \le t, J = c)$ the cumulative incidence of cause $c$ and $F_c(t-) = P(T < t, J = c)$. For $h \ge 0$, $P(t \le T < t + h, J = c) = F_c((t + h)-) - F_c(t-)$.
