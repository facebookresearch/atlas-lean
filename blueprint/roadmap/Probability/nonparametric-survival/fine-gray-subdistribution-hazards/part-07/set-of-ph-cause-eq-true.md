# Cause-of-interest event of the proportional subdistribution hazards family

Let $J(\omega) = \mathrm{true}$ if $\omega < 1$ and $J(\omega) = \mathrm{false}$ if $\omega \ge 1$ be the [failure cause](ph-cause.md) on $\mathbb{R}$. Then $\{\omega \in \mathbb{R} : J(\omega) = \mathrm{true}\} = (-\infty, 1)$.
