# The subdistribution-hazard quotient in terms of the cumulative incidence

Let $T$ be a failure time and $J$ a failure cause on a probability space, $F_c(t) = P(T \le t, J = c)$ the cumulative incidence of cause $c$ and $F_c(t-) = P(T < t, J = c)$. For $h \ge 0$, the difference quotient $P(t \le T < t + h, J = c \mid T \ge t\text{ or }(T < t, J \ne c))/h$ equals $\big(F_c((t + h)-) - F_c(t-)\big)/h/(1 - F_c(t-))$, with the conventions $x/0 = 0$ (also when $h = 0$) and $P[\cdot \mid \emptyset] = 0$ (when $F_c(t-) = 1$).
