# Measurability of the cause-of-interest event in the proportional subdistribution hazards family

On $\mathbb{R}$ with its Borel $\sigma$-algebra, let $J(\omega) = \mathrm{true}$ if $\omega < 1$ and $J(\omega) = \mathrm{false}$ if $\omega \ge 1$ be the failure cause of the [proportional subdistribution hazards family](ph-cause.md). Then the cause-of-interest event $\{\omega \in \mathbb{R} : J(\omega) = \mathrm{true}\}$ is Borel measurable.
