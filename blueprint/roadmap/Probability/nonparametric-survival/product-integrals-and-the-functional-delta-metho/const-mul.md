# Multiples of controlled functions

A function $A$ is controlled on $[a, b]$ by a nondecreasing $V$ if $|A(x) - A(y)| \le V(x) - V(y)$ for $a \le y \le x \le b$; write $P(A)(y, x] = \prod_{(y,x]}(1 + dA)$ for the product integral. If $c \ge 0$ and $A$ is controlled by $V$, then $cA$ is controlled by $cV$.
