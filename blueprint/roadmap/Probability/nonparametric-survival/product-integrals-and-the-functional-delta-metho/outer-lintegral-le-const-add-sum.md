# Riemann-sum bound for the outer integral

For an arbitrary map $f$ into $[0, \infty]$, $E^*f$ denotes the outer integral (the infimum of $\int g$ over measurable $g \ge f$ almost everywhere) and $P^*$ the outer probability. On a probability space, if $f \le c + \sum_{i<k}c\mathbf 1_{s_i}$ pointwise, then $E^*f \le c + \sum_{i<k}cP^*(s_i)$.
