# Outer portmanteau theorem: closed sets

For an arbitrary map $f$ into $[0, \infty]$, $E^*f$ denotes the outer integral (the infimum of $\int g$ over measurable $g \ge f$ almost everywhere) and $P^*$ the outer probability. Write $X_n \rightsquigarrow L$ for outer weak convergence: $E^*f(X_n) \to \int f\,dL$ for every bounded continuous $f \ge 0$. Let $E$ be a space in which every closed set is a decreasing limit of bounded continuous functions into $[0, 1]$, as in a metric space. If $X_n \rightsquigarrow L$ in $E$, then $\limsup P^*(X_n \in F) \le L(F)$ for every closed $F$.
