# Existence of the Duhamel integral

A function $A$ is controlled on $[a, b]$ by a nondecreasing $V$ if $|A(x) - A(y)| \le V(x) - V(y)$ for $a \le y \le x \le b$; write $P(A)(y, x] = \prod_{(y,x]}(1 + dA)$ for the product integral. If $a \le b$, $A$ is controlled on $[a, b]$ and $h$ is a uniform limit on $[a, b]$ of controlled functions, then the two-tag Duhamel sums converge along refinement.
