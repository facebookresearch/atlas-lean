# The forward product-integral factor has bounded variation

A function $A$ is controlled on $[a, b]$ by a nondecreasing $V$ if $|A(x) - A(y)| \le V(x) - V(y)$ for $a \le y \le x \le b$; write $P(A)(y, x] = \prod_{(y,x]}(1 + dA)$ for the product integral. If $A$ is controlled by $V$ on $[a, b]$, then $u \mapsto P(A)(a, u]$ is controlled by $x \mapsto e^{V(x) - V(a)}$.
