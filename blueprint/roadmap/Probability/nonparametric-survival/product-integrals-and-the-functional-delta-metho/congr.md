# Controls depend only on values on the interval

For functions $A, V : \mathbb{R} \to \mathbb{R}$ and reals $a, b$, say that $V$ is a control for $A$ on $[a, b]$ if $|A(x) - A(y)| \le V(x) - V(y)$ for all $a \le y \le x \le b$.

Let $A, B, V : \mathbb{R} \to \mathbb{R}$ and $a, b \in \mathbb{R}$. If $V$ is a control for $A$ on $[a, b]$ and $A(x) = B(x)$ for every $x \in [a, b]$, then $V$ is a control for $B$ on $[a, b]$.
