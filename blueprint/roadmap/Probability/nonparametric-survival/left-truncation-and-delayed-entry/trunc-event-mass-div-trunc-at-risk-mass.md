# Identification of the hazard under left truncation

Let the event time $T \sim p_T$, censoring time $C \sim p_C$ and entry time $L \sim p_L$ on a finite grid be mutually independent, and $X = \min(T, C)$. If $P(L < j \le X) \ne 0$, then $P(X = j, T \le C, L < j)/P(L < j \le X) = P(T = j)/P(T \ge j)$.
