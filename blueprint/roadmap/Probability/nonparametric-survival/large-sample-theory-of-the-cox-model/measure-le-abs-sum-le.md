# Lenglart’s inequality for a martingale difference row

On a probability space, let $x_0, x_1, \dots$ be strongly measurable, square-integrable random variables with $\mathbb{E}[x_k \mid \mathcal F_k] = 0$ for a filtration $(\mathcal F_k)$ (no adaptedness is assumed). Then for $\varepsilon, \eta > 0$ and every $K$,

$$P\Big(\Big|\sum_{k<K}x_k\Big| \ge \varepsilon\Big) \le P\Big(\sum_{k<K}\mathbb{E}[x_k^2 \mid \mathcal F_k] > \eta\Big) + \frac{\eta}{\varepsilon^2}.$$

## Sources

- E. Lenglart, "Relation de domination entre deux processus", Ann. Inst. H. Poincaré 13 (1977), 171–179.
