# Identified set of a failure probability

For a measure $P$ on $\mathbb{R} \times \{0, 1\}$, the identified set of $P(T \le t)$ is the set of values $\mu(T \le t)$ over all probability measures $\mu$ on $\mathbb{R}^2$ (joint laws of $(T, C)$) whose observed-data measure is $P$; it is empty unless $P$ is a probability measure.
