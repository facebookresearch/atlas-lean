# The censored factor is a survival mass

For a measure $\mu_0$ on $\mathbb{R}$, let $S_0(z)$ be the real number $\mu_0(z, \infty)$, taken to be $0$ if this mass is infinite. If $\sigma > 0$, the censored likelihood contribution at $y$ is the real number $\nu(y, \infty)$ (again $0$ if infinite) for the log-linear measure $\nu$, the image of $\mu_0$ under $e \mapsto \eta + \sigma e$. When $\mu_0$ is the error law, this is the survival probability $P(\log T > y)$.
