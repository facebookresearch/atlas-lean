# The hazard depends only on two distribution-function values

Let $p_T, p_T'$ be laws of an event time $T$ on a finite grid, with distribution functions $F, F'$. Write $h(j) = P(T = j) / P(T \ge j)$ for the [discrete hazard](../../censored-survival-data/hazard.md), with $0/0 = 0$, the value when $P(T \ge j) = 0$. If $F(j) = F'(j)$ and $P(T < j) = P'(T < j)$, the two laws have the same hazard at $j$.
