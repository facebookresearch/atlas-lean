# Observed truncated event mass

Let $\mu$ be a measure on the grid triples $((T, C), L)$ of an event time, a censoring time and an entry time. The truncated event mass at a grid point $j$ is the real number $\mu(\{\min(T, C) = j,\ T \le C,\ L < j\})$, taken to be $0$ if this mass is infinite. When $\mu$ is the joint law of $((T, C), L)$, it is the probability $P(\min(T, C) = j, T \le C, L < j)$.
