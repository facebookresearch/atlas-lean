# The Nelson–Aalen error path at the grid times

Fix $\tau > 0$ and $K$ grid steps of length $\tau/K$; the grid time $k\tau/K$ is read as $0$ when $K = 0$. Let $N$ and $Y$ be real-valued processes on the grid and $\alpha$ a deterministic real sequence (no counting-process structure is assumed; the counting model with at-risk process $Y$ and cumulative hazard $\alpha$ is an application), $\hat A = Y^{-1}\bullet N$ the Nelson–Aalen process, $\Lambda^* = \mathbf 1\{Y \ne 0\}\bullet\alpha$ and $M = N - Y\bullet\alpha$. Here $Y^{-1}$ is read as $0$ where $Y = 0$ (zero risk). For $k \le K$, the error path at $k\tau/K$ equals $\sqrt n(\hat A_k - (\alpha_k - \alpha_0))$.
