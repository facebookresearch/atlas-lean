# Portmanteau theorem on preimages

Let $E$ be a topological space with a σ-algebra in which every open set is measurable and every closed set is the pointwise limit of a decreasing sequence of bounded continuous functions with values in $[0, 1]$ (as in a pseudometric space). Let random variables $X_n$ in $E$ on a probability space $(\Omega, P)$ converge in distribution to $Z$, defined on a possibly different probability space $(\Omega', P')$. If $B$ is a measurable set whose frontier is null for the law of $Z$, then $P(X_n \in B) \to P'(Z \in B)$.
