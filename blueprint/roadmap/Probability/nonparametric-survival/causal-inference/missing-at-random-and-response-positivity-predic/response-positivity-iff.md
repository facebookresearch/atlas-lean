# Positivity for a finitely valued covariate

Let $\mu$ be a measure on a measurable space $\Omega$, $R \subseteq \Omega$ and $X : \Omega \to \mathcal X$ with $\mathcal X$ finite. Write $e(x) = \mu_{\mathbb R}(R \cap \{X = x\}) / \mu_{\mathbb R}(X = x)$, where $\mu_{\mathbb R}(A)$ is the real number $\mu(A)$ when $\mu(A) < \infty$ and $0$ when $\mu(A) = \infty$, and $x / 0 = 0$. Then response positivity, the existence of $\varepsilon > 0$ with $\varepsilon \le e(x)$ for every $x$ with $\mu(X = x) \ne 0$ (the measure itself, in $[0, \infty]$), holds if and only if

$$e(x) > 0 \quad \text{for every } x \in \mathcal X \text{ with } \mu(X = x) \ne 0.$$
