# Exposed Set

Let $U$ be a finite set of units, $\Omega$ a set of assignments, $\Delta$ a set of exposure values, and $e : U \times \Omega \to \Delta$ an exposure mapping, so $e_i(z)$ is the exposure of unit $i$ under assignment $z$. For $d \in \Delta$ and $z \in \Omega$, the exposed set is the set of units receiving exposure $d$ under assignment $z$:

$$E_d(z) = \{\, i \in U : e_i(z) = d \,\}.$$
