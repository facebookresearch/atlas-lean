# Variance outcome Error

Let $(\Omega, \mu)$ be a probability space, $u, \eta : \Omega \to \mathbb R$ independent standard normal random variables, and $\sigma_{11}, \sigma_{12} \in \mathbb R$ with $\sigma_{12}^2 \le \sigma_{11}$ (the covariance matrix with $\operatorname{Var} U_1 = \sigma_{11}$, $\operatorname{Cov}(U_1, u) = \sigma_{12}$, $\operatorname{Var} u = 1$ is valid). Then the outcome error $U_1 = \sigma_{12} u + \sqrt{\sigma_{11} - \sigma_{12}^2}\, \eta$ has variance

$$\operatorname{Var}_\mu(U_1) = \sigma_{11}.$$
