# Covariance outcome Error selection Error

Let $(\Omega, \mu)$ be a probability space, $u, \eta : \Omega \to \mathbb R$ independent standard normal random variables, and $\sigma_{11}, \sigma_{12} \in \mathbb R$. Define the outcome error $U_1 = \sigma_{12} u + \sqrt{\sigma_{11} - \sigma_{12}^2}\, \eta$, where $\sqrt{x} = 0$ for $x < 0$. Then its covariance with the selection error $u$ is

$$\operatorname{Cov}_\mu(U_1, u) = \sigma_{12}.$$
