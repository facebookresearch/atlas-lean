# Band coverage as a weighted sup event

For an estimate $e$, weights $w$, a critical value $c$ and sample size $n$, the simultaneous band is $\{f : |e_i - f_i| \le cw_i/\sqrt n\ \forall i\}$ and the pointwise interval at $i$ is $\{x : |e_i - x| \le cw_i/\sqrt n\}$. On a nonempty finite grid, if $w > 0$ and $n > 0$, then $\theta$ lies in the band if and only if $\sqrt n\max_i|e_i - \theta_i|/w_i \le c$.
