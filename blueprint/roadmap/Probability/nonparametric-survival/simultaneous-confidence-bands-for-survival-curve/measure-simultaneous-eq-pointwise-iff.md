# When simultaneous and pointwise coverage agree

For an estimate $e$, weights $w$, a critical value $c$ and sample size $n$, the simultaneous band is $\{f : |e_i - f_i| \le cw_i/\sqrt n\ \forall i\}$ and the pointwise interval at $i$ is $\{x : |e_i - x| \le cw_i/\sqrt n\}$. For a finite measure under which the event that the band covers $\theta$ is null-measurable, simultaneous coverage equals pointwise coverage at $i$ if and only if almost surely covering $\theta_i$ implies covering the whole curve.
