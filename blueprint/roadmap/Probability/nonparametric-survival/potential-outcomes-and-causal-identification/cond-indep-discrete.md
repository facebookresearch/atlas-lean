# Conditional independence given a discrete variable

For a measure $\mu$ on $\Omega$, an event $T$ and variables $V$ (in a measurable space) and $W$, the event $T$ is conditionally independent of $V$ given $W$ if, for every measurable set $B$ and every value $w$,

$$\mu(T \cap \{V \in B\} \cap \{W = w\})\, \mu(W = w) = \mu(T \cap \{W = w\})\, \mu(\{V \in B\} \cap \{W = w\}),$$

with masses read as real numbers. For a $W$ with countably many values this is the conditional independence of the indicator of $T$ and $V$ given $W$.
