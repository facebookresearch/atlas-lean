# Compliance type of a pair of potential treatments

The compliance type of a pair $(d_0, d_1) \in \{0, 1\}^2$ of potential treatments is the [compliance type](compliance-type.md)

- complier if $(d_0, d_1) = (0, 1)$;
- always-taker if $(d_0, d_1) = (1, 1)$;
- never-taker if $(d_0, d_1) = (0, 0)$;
- defier if $(d_0, d_1) = (1, 0)$.
