# The forced flow law

For a system with resources $k = 1, \dots, K$ observed over an interval with $C > 0$ system completions, the throughput of resource $k$ and the system throughput, as [operational quantities](operational-quantities-of-an-observation-interval.md), satisfy $X_k = V_k X$, since $C_k/T = (C_k/C)(C/T)$. The flows in all parts of a system are proportional to one another: if each job makes on average $6$ accesses to a disk that serves $12$ requests from such jobs per second, the system throughput is $2$ jobs per second.
