# Exists is Compact measure Real not Mem le

Let $(\Omega, P)$ be a probability space and let $W : \Omega \to C([0,1], \mathbb{R})$ be a measurable random continuous path. For every $b > 0$ there is a compact set $C \subseteq C([0,1], \mathbb{R})$ with

$$P(\{\omega : W(\omega) \notin C\}) \le b.$$

That is, the law of a single $C([0,1])$-valued random variable is tight, since $C([0,1], \mathbb{R})$ is Polish.
