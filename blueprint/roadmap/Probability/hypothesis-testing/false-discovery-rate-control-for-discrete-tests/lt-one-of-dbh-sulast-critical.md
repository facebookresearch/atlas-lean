# Null distribution functions stay below one at the last critical value

For a level $\alpha$, null distribution functions $F_1, \dots, F_m$ and a finite support set $A$, let $\tau_m$ be the maximum of $0$ and all $t \in A$ with every $F_i(t) < 1$ and $\frac1m\sum_iF_i(t)/(1 - F_i(t)) \le \alpha$, and $\tau_k$ the maximum of $0$ and all $t \in A$ with $t \le \tau_m$ and $\frac1m\sum_iF_i(t)/(1 - F_i(\tau_m)) \le \alpha k/m$ (the discrete Benjamini–Hochberg critical values). If $F_i(0) = 0$ for every $i$, then $F_i(\tau_m) < 1$ for every $i$.
