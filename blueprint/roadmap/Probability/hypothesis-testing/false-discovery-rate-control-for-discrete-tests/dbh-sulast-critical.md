# Last critical value of the discrete Benjamini–Hochberg procedure

For a level $\alpha$, null distribution functions $F_1, \dots, F_m$ and a finite support set $A$, the last critical value $\tau_m$ is the largest $t \in A \cup \{0\}$ with every $F_i(t) < 1$ and $\frac1m\sum_iF_i(t)/(1 - F_i(t)) \le \alpha$ ($0$ if none qualifies). Real division and inversion use $x/0 = 0$ and $0^{-1} = 0$.
