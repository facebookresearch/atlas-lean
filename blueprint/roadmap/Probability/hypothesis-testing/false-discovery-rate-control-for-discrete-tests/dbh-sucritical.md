# Critical values of the discrete Benjamini–Hochberg procedure

For a level $\alpha$, null distribution functions $F_i$, a finite support set $A$ and $k$, the critical value $\tau_k$ is the largest $t \in A \cup \{0\}$ with $t \le \tau_m$ and $\frac1m\sum_iF_i(t)/(1 - F_i(\tau_m)) \le \alpha k/m$, where $\tau_m$ is the last critical value. Real division and inversion use $x/0 = 0$ and $0^{-1} = 0$.
