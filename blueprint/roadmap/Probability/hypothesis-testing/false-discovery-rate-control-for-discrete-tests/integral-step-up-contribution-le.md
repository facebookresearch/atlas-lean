# Bound on the contribution of a true null to the step-up false discovery rate

On a probability space, for measurable, mutually independent p-values, critical values $c$ and an index $i$ with $P(p_i \le t) \le F(t)$ for all $t$, the expected contribution $\mathbb{E}\big[\sum_{k=1}^m\frac1k\mathbf 1\{p_i \le c_k, K_i = k\}\big]$ is at most $\sum_kP(K_i = k)F(c_k)/k$, with $K_i$ the leave-one-out step-up index.
