# A uniform noise gives a valid p-value at exponent one

Let $U_1, \dots, U_k$ be noise variables and $c$ a map from endpoints to clusters, and let endpoint $j$ report the Lehmann p-value $p_j = \max(U_{c(j)}, 0)^{\theta_j}$ with exponent $\theta_j$. Suppose $U_{c(j)}$ is uniform on $[0, 1]$. If $\theta_j = 1$, then $p_j$ is a valid p-value.
