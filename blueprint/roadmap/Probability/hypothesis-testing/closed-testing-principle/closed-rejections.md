# Closed testing procedure

Let $m \in \mathbb{N}$ and suppose that for every $J \subseteq \{0, \dots, m-1\}$ a local test of the intersection hypothesis $H_J = \bigcap_{j \in J} H_j$ has been carried out, with decision $\varphi(J)$ (true when the local test rejects). The closed testing procedure rejects $H_i$ exactly when $\varphi(J)$ holds for every $J$ containing $i$:

$$R = \{i : \varphi(J) \text{ for every } J \ni i\}.$$
