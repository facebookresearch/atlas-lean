# Knockoff selected set

Let $c \in \mathbb{N}$, $q \in \mathbb{R}$ and $W \in \mathbb{R}^p$, and let $T_c$ be the [knockoff threshold](knockoff-threshold.md). The knockoff selected set is

$$\hat S_c = \{j : W_j \ge T_c\};$$

it is empty when $T_c = +\infty$.

## Sources

- R. F. Barber and E. J. Candès, *Controlling the false discovery rate via knockoffs*, Ann. Statist. 43 (2015), arXiv:1404.5609, Definitions 1 and 2.
