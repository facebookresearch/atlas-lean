# Number of heterozygous individuals

Let $N \in \mathbb{N}$ and consider the $2N$ gamete slots $(j, c)$, $j \in \{0, \dots, N-1\}$, $c \in \{0, 1\}$, two per individual. If the copies of allele $A$ occupy the set $s$ of slots, the number of heterozygous individuals is the number of $j$ for which exactly one of $(j, 0)$ and $(j, 1)$ lies in $s$.
