# The SKAT-O matrix with unit diagonal and off-diagonal entries ρ

For a finite set of `m` variants and a real number `ρ`, the SKAT-O matrix is the `m × m` matrix

`R_ρ = (1 - ρ) I + ρ 𝟙 𝟙ᵀ`,

whose diagonal entries are `1` and whose off-diagonal entries are `ρ`. It is defined for every real
`ρ`. For `ρ ∈ [0, 1]`, a convex combination of `I` and `𝟙 𝟙ᵀ`, it is a correlation matrix: the
exchangeable correlation that Lee, Wu and Lin (2012) give to the effects of the variants of a
region.
