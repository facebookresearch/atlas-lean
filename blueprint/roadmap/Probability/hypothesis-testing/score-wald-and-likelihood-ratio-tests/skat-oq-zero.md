# At ρ = 0 the SKAT-O statistic is SKAT with squared weights

For a real `n × q` covariate matrix `X`, a real `n × n` matrix `V`, a real `n × m` genotype matrix
`G`, variant weights `a ∈ ℝᵐ` and every phenotype `y ∈ ℝⁿ`, the [SKAT-O statistic](skat-oq.md)
`Q_ρ = (1 - ρ) Q_S + ρ Q_B` at `ρ = 0` is the
[SKAT statistic](../../../Biology/statistical-genetics/association-tests/skat-variance-component-test/skat-q.md) with weights `wⱼ = aⱼ²`:
`Q_0(y) = Q_S(y)`.
