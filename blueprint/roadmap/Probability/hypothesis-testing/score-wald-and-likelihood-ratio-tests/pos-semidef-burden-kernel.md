# The burden kernel is positive semidefinite

For finitely many individuals, every real `n × m` genotype matrix `G` and all variant weights
`a ∈ ℝᵐ`, the [burden kernel](burden-kernel.md) `K_B = C Cᵀ`, `C = G a`, is positive semidefinite:
it is symmetric and `xᵀ K_B x = (Cᵀ x)² ≥ 0` for every `x ∈ ℝⁿ`.
