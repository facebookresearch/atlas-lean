# Residuals of a symmetric algorithm are equivariant

If the fitted regression function does not depend on the order of the data points,
$A(z \circ \sigma) = A(z)$ for every permutation $\sigma$, then the absolute residual score is
permutation equivariant. The full conformal coverage theorems therefore apply to the regression
set of Lei et al., equations (4) and (7), up to the treatment of ties discussed on the page of the
[full conformal prediction set](full-conformal-set.md).

Assoc. 113 (2018) 1094–1111. Theorem and equation numbers refer to the arXiv version, which is the one read. Section 2.1 (the requirement that $\hat\mu$ be a symmetric function of the data).
