# A rejection with futility is a rejection without futility

For efficacy cutoffs $c_k$, futility cutoffs $d_k$, efficacy p-values $p_k$ and futility p-values $q_k$, a trial with $K$ planned looks continues before look $j$ if $c_i < p_i$ and $d_i < q_i$ for all $i < j$; it rejects if some $j < K$ is reached with $p_j \le c_j$, and stops for futility if some $j < K$ is reached with $c_j < p_j$ and $q_j \le d_j$. If the trial rejects, then the efficacy-only design (looks with $p_k \le c_k$) rejects.
