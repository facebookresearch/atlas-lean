# Pocock-type spending function

The Lan–DeMets Pocock-type spending function at level $\alpha$ is $t \mapsto \alpha\log(1 + (e - 1)t)$. It is defined for every real $t$, with $\log 0 = 0$ and $\log x = \log|x|$ for $x < 0$; for $t \in [0, 1]$ the argument lies in $[1, e]$.

## Sources

- Lan and DeMets (1983).
