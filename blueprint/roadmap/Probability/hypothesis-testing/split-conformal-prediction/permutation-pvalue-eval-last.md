# Permutation p-value of the test score

Let $n \in \mathbb{N}$ and $\omega \in \mathbb{R}^{n+1}$. For the group of permutations of $\{1, \dots, n+1\}$ acting by $(\sigma \cdot \omega)_i = \omega_{\sigma^{-1}(i)}$ and the statistic $T(\omega) = \omega_{n+1}$, the permutation p-value is

$$\frac{n + 1 - L(\omega)}{n + 1},$$

where $L(\omega)$ is the number of calibration scores strictly below the test score. Each coordinate is moved to the test position by $n!$ permutations.
