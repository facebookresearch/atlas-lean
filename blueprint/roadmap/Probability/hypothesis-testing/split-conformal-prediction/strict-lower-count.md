# Strict lower count of the test score

Let $n \in \mathbb{N}$ and $\omega = (\omega_1, \dots, \omega_{n+1}) \in \mathbb{R}^{n+1}$, with calibration scores $\omega_1, \dots, \omega_n$ and test score $\omega_{n+1}$. The strict lower count is the number of calibration scores strictly below the test score:

$$L(\omega) = \#\{i \le n : \omega_i < \omega_{n+1}\}.$$
