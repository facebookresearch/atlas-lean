# Strict rank count

Let $\iota$ be a finite set, $\omega : \iota \to \mathbb{R}$ and $i \in \iota$. The strict rank count of $i$ is the number of coordinates strictly below it, $r_\omega(i) = \#\{j : \omega(j) < \omega(i)\}$; with distinct values, $r_\omega(i) + 1$ is the rank of $\omega(i)$ among the values of $\omega$.
