# Characterisation of the order statistic

Let $\iota$ be a finite set, $f : \iota \to \mathbb{R}$, $k \ge 1$ and $x \in \mathbb{R}$. Then $f_{(k)} = x$ if and only if fewer than $k$ values are strictly below $x$ and at least $k$ values are at most $x$:

$$f_{(k)} = x \iff \#\{i : f(i) < x\} < k \le \#\{i : f(i) \le x\},$$

the usual characterisation of the $k$-th order statistic with multiplicity.
