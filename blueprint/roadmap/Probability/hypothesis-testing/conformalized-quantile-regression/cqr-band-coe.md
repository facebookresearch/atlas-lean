# The CQR band for a finite threshold is an interval

Let $\mathcal{X}$ be a set, $q_{\mathrm{lo}}, q_{\mathrm{hi}} : \mathcal{X} \to \mathbb{R}$, $Q \in \mathbb{R}$ and $x \in \mathcal{X}$. The [CQR band](cqr-band.md) is the closed interval

$$C_Q(x) = [q_{\mathrm{lo}}(x) - Q,\ q_{\mathrm{hi}}(x) + Q].$$
