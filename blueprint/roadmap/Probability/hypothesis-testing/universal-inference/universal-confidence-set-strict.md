# Strict universal confidence set

For densities $p_\theta$, an estimator $\hat\theta_1$ fitted on the estimation split and $\alpha$, the strict universal confidence set at $z = (D_0, D_1)$ is $\{\theta : p_{\hat\theta_1(D_1)}(D_0)/p_\theta(D_0) < 1/\alpha\}$, with the real ratio. Quotients with zero denominator are $0$, and $1/0 = 0$.
