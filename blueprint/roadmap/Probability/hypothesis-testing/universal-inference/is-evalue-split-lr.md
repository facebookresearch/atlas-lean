# The split likelihood ratio is an e-value

Let $p_\theta$ be probability densities (nonnegative, total mass at most $1$) with respect to a reference measure on the inference-split space, the data split as $z = (D_0, D_1)$ with $D_0$ the inference split and $D_1$ the estimation split, $\hat\theta_1(D_1)$ any estimator fitted on $D_1$, and the joint law $P_{\theta^*} \otimes \nu$ with $\nu$ an arbitrary probability law of $D_1$ (and the reference measure s-finite). For a denominator $L$, write $T_L(z) = p_{\hat\theta_1(D_1)}(D_0)/L(D_0)$ for the split likelihood ratio, assumed measurable. If $L \ge p_{\theta^*}$ pointwise and $p_{\theta^*}$ is measurable, then $T_L$ is an e-value under $P_{\theta^*} \otimes \nu$.
