# Coverage of the strict universal confidence set

Let $p_\theta$ be probability densities (nonnegative, total mass at most $1$) with respect to a reference measure on the inference-split space, the data split as $z = (D_0, D_1)$ with $D_0$ the inference split and $D_1$ the estimation split, $\hat\theta_1(D_1)$ any estimator fitted on $D_1$, and the joint law $P_{\theta^*} \otimes \nu$ with $\nu$ an arbitrary probability law of $D_1$ (and the reference measure s-finite). Let $p_{\theta^*}$ be measurable with the statistic $p_{\hat\theta_1(D_1)}(D_0)/p_{\theta^*}(D_0)$ measurable, and $\alpha > 0$. Then the probability that $\theta^*$ lies outside $\{\theta : p_{\hat\theta_1(D_1)}(D_0)/p_\theta(D_0) < 1/\alpha\}$ is at most $\alpha$.
