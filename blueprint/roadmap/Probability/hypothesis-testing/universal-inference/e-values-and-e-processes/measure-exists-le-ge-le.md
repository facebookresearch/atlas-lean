# Ville’s inequality for e-processes, finite horizon

An e-process for a filtration under $P$ is a nonnegative adapted process $(E_n)$ whose value at every bounded stopping time is an e-value (nonnegative, expectation at most $1$). Then for every horizon $N$ and $c > 0$, $P(\exists n \le N : E_n \ge c) \le 1/c$.
