# Split likelihood ratio

For densities $p_\theta$, an estimator $\hat\theta_1$ fitted on the estimation split $D_1$ and a denominator $L$, the split likelihood ratio at $z = (D_0, D_1)$ is $p_{\hat\theta_1(D_1)}(D_0)/L(D_0)$ (with value $0$ where $L(D_0) = 0$).

## Sources
