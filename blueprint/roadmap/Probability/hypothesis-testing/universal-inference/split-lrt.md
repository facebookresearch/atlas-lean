# Split likelihood-ratio test statistic

For densities $p_\theta$, an estimator $\hat\theta_1$ fitted on the estimation split and a null maximum-likelihood estimator $\hat\theta_0$ fitted on the inference split $D_0$, the split likelihood-ratio statistic is $T = p_{\hat\theta_1(D_1)}(D_0)/p_{\hat\theta_0(D_0)}(D_0)$.
