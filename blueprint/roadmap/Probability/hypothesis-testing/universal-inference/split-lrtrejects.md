# Rejection region of the split likelihood-ratio test

The level-$\alpha$ split likelihood-ratio test rejects when $p_{\hat\theta_0(D_0)}(D_0) < \alpha\,p_{\hat\theta_1(D_1)}(D_0)$. Where the null likelihood $p_{\hat\theta_0(D_0)}(D_0)$ is positive and $\alpha > 0$, this is $T > 1/\alpha$ for the split likelihood ratio $T = p_{\hat\theta_1(D_1)}(D_0)/p_{\hat\theta_0(D_0)}(D_0)$; where the null likelihood vanishes and $\alpha > 0$, the test rejects exactly when $p_{\hat\theta_1(D_1)}(D_0) > 0$.
