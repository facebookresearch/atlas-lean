# Benjamini–Hochberg controls the false discovery rate on an independent event

Let $x_1, \dots, x_k$ be measurable, mutually independent p-values on a probability space with valid true-null p-values ($H_0$), and $G = \{Y \in B\}$ an event determined by a measurable $Y$ independent of the p-value vector. Then $\mathbb{E}[\mathrm{FDP}(\mathrm{BH}_q)\mathbf 1_G] \le q|H_0|P(G)/k$.
