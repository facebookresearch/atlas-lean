# Two-groups model

The two-groups model of Efron, Tibshirani, Storey and Tusher (2001) consists of

- a prior null probability $\pi_0 \in [0, 1]$, the probability that a case is null;
- a null density $f_0$ and a non-null density $f_1$ of the z-value: measurable, nonnegative, Lebesgue-integrable functions $\mathbb{R} \to \mathbb{R}$ with $\int f_0 = \int f_1 = 1$.

## Sources

- B. Efron, "Microarrays, empirical Bayes and the two-groups model", *Statist. Sci.* 23 (2008) 1–22, arXiv:0808.0572. Equation (2.1).
