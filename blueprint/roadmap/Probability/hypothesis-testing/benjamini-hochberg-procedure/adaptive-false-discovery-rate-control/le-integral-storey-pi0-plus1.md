# Storey’s estimator is conservative in expectation

On a probability space, if every true-null p-value is valid, the p-values are measurable and $0 \le \lambda < 1$, then $\mathbb{E}[\hat\pi_0(\lambda)] \ge |H_0|/m$ for the finite-sample (plus-one) [Storey estimator](storey-pi0-plus1.md) $\hat\pi_0(\lambda) = (\#\{j : p_j > \lambda\} + 1)/((1-\lambda)m)$; no independence is needed.
