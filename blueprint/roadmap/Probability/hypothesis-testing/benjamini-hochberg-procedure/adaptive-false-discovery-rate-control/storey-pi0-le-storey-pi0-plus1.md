# The finite-sample Storey estimator dominates the original

For $\lambda \le 1$ and all p-values, $\#\{j : p_j > \lambda\}/((1 - \lambda)m) \le (\#\{j : p_j > \lambda\} + 1)/((1 - \lambda)m)$.

## Sources

- J. D. Storey, "A direct approach to false discovery rates", *Journal of the Royal Statistical Society Series B* 64 (2002), 479–498.
