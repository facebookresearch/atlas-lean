# Storey’s estimator of the proportion of true nulls

For p-values $p_1, \dots, p_m$ and a tuning parameter $\lambda$, Storey's finite-sample estimator of the proportion of true nulls is $\hat\pi_0(\lambda) = (\#\{j : p_j > \lambda\} + 1)/((1 - \lambda)m)$. If $(1 - \lambda)m = 0$ the estimate is $0$ ($x/0 = 0$).

## Sources

- J. D. Storey, J. E. Taylor and D. Siegmund, "Strong control, conservative point estimation and simultaneous conservative consistency of false discovery rates: a unified approach", *Journal of the Royal Statistical Society Series B* 66 (2004), 187–205.
