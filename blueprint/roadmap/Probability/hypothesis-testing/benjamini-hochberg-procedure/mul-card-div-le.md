# For q ≥ 0, q times the fraction of true nulls is at most q

For a real number `q ≥ 0`, a natural number `m` and a subset `H0` of `{0, …, m - 1}`,
`q |H0| / m ≤ q`, since `|H0| ≤ m`; for `m = 0` the left side is `0` by the convention
`x / 0 = 0`. So the [FDR bound](integral-fdp-bh-rejections-tail-pvalue-l.md) `q |H0| / m` is at
most the nominal level `q`.
