# The step-up false discovery rate as a sum of leave-one-out contributions

For measurable p-values on a probability space, a set $H_0$ of true nulls and nondecreasing nonnegative critical values $c$, the false discovery rate of the step-up procedure equals $\sum_{i \in H_0}\sum_{k=1}^m\frac1kP(p_i \le c_k, K_i = k)$, where $K_i$ is the step-up index with $p_i$ replaced by $0$.
