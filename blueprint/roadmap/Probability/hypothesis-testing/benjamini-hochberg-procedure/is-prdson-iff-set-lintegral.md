# Positive regression dependence via a monotone conditional probability

On a nonzero finite measure space, p-values $p_1, \dots, p_m$ are positively regression dependent on a subset $H_0$ (PRDS) if for every $i \in H_0$ and every measurable increasing set $D \subseteq \mathbb{R}^m$, $x \mapsto P((p_1, \dots, p_m) \in D \mid p_i = x)$ has a nondecreasing version. For measurable p-values, PRDS on $H_0$ holds if and only if for every $i \in H_0$ and measurable increasing $D$ there is a nondecreasing $g$ with $P((p_1, \dots, p_m) \in D, p_i \in B) = \int_Bg\,dP_{p_i}$ for every Borel set $B$.
