# False discovery rate control for self-consistent procedures

A rejection set $R$ is self-consistent for e-values $e_1, \dots, e_m$ at level $\alpha$ if $m \le \alpha|R|e_i$ for every $i \in R$. If every true-null statistic is an e-value, $R(\omega)$ is self-consistent for every outcome, $\alpha \ge 0$, and the false discovery proportion is almost everywhere measurable, then it is integrable and the false discovery rate is at most $\alpha|H_0|/m$, under arbitrary dependence.
