# Unit Poisson deviance

The unit Poisson deviance of an observation $y$ against a fitted mean $\mu$ is $2\big(y\log(y/\mu) - (y - \mu)\big)$, with the convention $0\log 0 = 0$; it is meaningful for $y \ge 0$ and $\mu > 0$. As a function of all real $y, \mu$ it uses $x/0 = 0$, $\log 0 = 0$ and $\log x = \log|x|$ for $x < 0$.
