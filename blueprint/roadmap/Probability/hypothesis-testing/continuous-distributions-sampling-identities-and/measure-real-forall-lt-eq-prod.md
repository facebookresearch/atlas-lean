# Measure Real forall lt eq prod

Let $(T_i)_{i \in \mathbb{N}}$ be mutually independent real random variables on $(\Omega, P)$, let $n \in \mathbb{N}$ and $x \in \mathbb{R}$. Then the probability that each of the first $n$ link strengths exceeds the load $x$ is the product of the individual survival probabilities:

$$P\bigl( T_i > x \text{ for all } i < n \bigr) = \prod_{i=0}^{n-1} P(T_i > x).$$
