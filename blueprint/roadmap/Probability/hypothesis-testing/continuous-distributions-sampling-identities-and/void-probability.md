# Void Probability

For a nucleation intensity $\kappa \in \mathbb{R}$ and a volume $v \in \mathbb{R}$, the JMAK void probability, the probability that a region of volume $v$ contains no nucleus, is

$$p_\kappa(v) = e^{-\kappa v}.$$

This is a model assumption; it is not derived from a Poisson point process.
