# Sample Std Dev

For real observations $X_0(\omega), \dots, X_{n-1}(\omega)$ with sample mean $\bar{X}_n(\omega) = \frac{1}{n} \sum_{i=0}^{n-1} X_i(\omega)$, the sample standard deviation is

$$s_n(\omega) = \sqrt{\frac{1}{n-1} \sum_{i=0}^{n-1} \bigl( X_i(\omega) - \bar{X}_n(\omega) \bigr)^2 },$$

the square root of the unbiased sample variance, with the convention $x / 0 = 0$. In particular $s_1 = 0$ and $s_0 = 0$.
