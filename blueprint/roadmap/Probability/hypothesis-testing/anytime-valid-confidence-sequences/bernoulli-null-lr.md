# Bernoulli likelihood-ratio process

For observations $X_0, X_1, \dots \in \mathbb{N}$, a reference alternative $p_0$ and a null value $q$, the likelihood-ratio process is

$$\Lambda_n = \prod_{i=0}^{n}\frac{\ell(p_0; X_i)}{\ell(q; X_i)},$$

where $\ell(p; 1) = p$, $\ell(p; 0) = 1 - p$ and $\ell(p; x) = 0$ otherwise (with $a/0 = 0$).
