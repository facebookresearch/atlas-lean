# Confidence sequence from e-processes

For a family of real processes $E_t(n, x)$ indexed by parameters $t \in \Theta$, times $n$ and observations $x$, and a level $\alpha$, the inverted confidence sequence is $C_n(x) = \{t \in \Theta : E_t(n, x) < 1/\alpha\}$: the parameters whose null process stays below $1/\alpha$ at time $n$. With $1/0 = 0$, at $\alpha = 0$ the set is $\{t : E_t(n, x) < 0\}$.
