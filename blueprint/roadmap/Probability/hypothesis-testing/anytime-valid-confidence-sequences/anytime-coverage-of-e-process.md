# Anytime-valid coverage by inverting e-processes

For each parameter $t$ in a set $\Theta$ let $\mu_t$ be a probability measure on a measurable space $\mathcal X$ and $E_t(n, \cdot)$ real processes; the e-process confidence sequence at level $\alpha$ is $C_n(x) = \{t : E_t(n, x) < 1/\alpha\}$. Let $\alpha \in (0, 1)$ and suppose that for each $t$ the process $E_t$ is a nonnegative supermartingale under $\mu_t$ for some filtration, with $\mathbb{E}_{\mu_t}[E_t(0, \cdot)] \le 1$. Then for every $t$

$$\mu_t\big(t \in C_n \text{ for all } n\big) \ge 1 - \alpha.$$
