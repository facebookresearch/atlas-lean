# Replacing a rejected p-value by zero keeps the step-up index

For thresholds $c_0, c_1, \dots$ and p-values $p_1, \dots, p_m$, let $N(t) = \#\{i : p_i \le t\}$ and let the step-up index $k^*$ be the largest $k \le m$ with $N(c_k) \ge k$. Let all thresholds be nonnegative and let $k_i^*$ be the step-up index after replacing $p_i$ by $0$. If $p_i \le c_{k_i^*}$, then $k^* = k_i^*$.
