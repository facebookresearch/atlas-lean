# Type I error of a p-value rejection rule

A p-value $p$ is valid under a measure $\mu$ if $\mu(p \le t) \le t$ for every $t \in [0, 1]$. If $p$ is valid under $\mu$ and $\alpha \in [0, 1]$, then rejecting when $p \le \alpha$ has type I error $\mu(p \le \alpha) \le \alpha$ (as a real number). No finiteness of $\mu$ is needed.
