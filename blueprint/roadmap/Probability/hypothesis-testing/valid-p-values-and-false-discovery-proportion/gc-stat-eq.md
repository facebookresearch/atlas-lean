# Closed form of the estimated-factor statistic

For all real scores `z_0, …, z_{m-1}` and every gene `j`, the [estimated-factor
statistic](gc-stat.md) is

`T_j = z_j² / λ̂ = m z_j² / ∑ₖ zₖ²`,

so the score of gene `j` enters its own denominator. When all scores vanish both sides are `0`, by
the convention `x / 0 = 0`.
