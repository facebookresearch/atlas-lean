# Equal pairwise covariances of λ̂-corrected statistics are −v/(m − 1)

Let `P` be a probability measure on a measurable space `Ω`, `m ≥ 2`, and let the random scores
`Z_0, …, Z_{m-1}` be measurable and almost surely not all zero. If all [corrected
statistics](gc-stat-rv.md) have the same variance, `Var(T_i) = v` for every `i`, and all pairs of
distinct genes the same covariance, `Cov(T_i, T_k) = γ` for `i ≠ k` (as for exchangeable scores),
then

`γ = -v / (m - 1)`.

The negative coupling is thus determined exactly: `γ ≤ 0` and `|γ| = v / (m - 1)`.
