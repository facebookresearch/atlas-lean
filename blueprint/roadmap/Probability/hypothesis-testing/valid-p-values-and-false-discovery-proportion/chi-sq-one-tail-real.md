# The χ²₁ tail as a real-valued function

The real-valued `χ²₁` tail is `G(c) = P(χ²₁ > c)`, the [`χ²₁` tail](../../../Biology/statistical-genetics/association-tests/genomic-control/chi-sq-one-tail.md) at the real
threshold `c`, which is finite, read as a real number: `G(c) ∈ [0, 1]` is the probability that a
`χ²₁` variable exceeds `c`. It is the reference upper tail of every gene when the estimated-factor
statistics are treated as a [tail-calibrated
family](../benjamini-hochberg-procedure/is-tail-calibrated-family.md).
