# The λ̂-corrected statistics are square integrable

Let `P` be a finite measure on a measurable space `Ω` and let the random scores `Z_0, …, Z_{m-1}` be
measurable. Every [corrected statistic](gc-stat-rv.md) `T_j` is measurable and takes values in
`[0, m]` ([bound](gc-stat-le-card.md)), hence is square integrable: `T_j ∈ L²(P)`.
