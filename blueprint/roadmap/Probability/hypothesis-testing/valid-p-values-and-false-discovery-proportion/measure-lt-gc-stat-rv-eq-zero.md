# The λ̂-corrected test never rejects at a threshold c ≥ m

Let `P` be any measure on a measurable space `Ω`, `Z_0, …, Z_{m-1}` any real functions on `Ω`
(random scores) and `j` a gene. For every threshold `c ≥ m`, the [corrected
statistic](gc-stat-rv.md) `T_j` never exceeds `c`, so

`P(T_j > c) = 0`.

The event `{T_j > c}` is empty, because `T_j ≤ m` at every sample point
([bound](gc-stat-le-card.md)); no assumption on the law of the scores is involved.
