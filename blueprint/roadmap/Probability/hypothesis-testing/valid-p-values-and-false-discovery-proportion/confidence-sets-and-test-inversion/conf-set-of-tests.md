# Confidence set from a family of tests

Let $\mathcal X$ be a set of observations and $\mathcal T$ a set of estimand values, and for each $t \in \mathcal T$ let $R_t \subseteq \mathcal X$ be the rejection region of a test of the null value $t$. The confidence set obtained by inverting the tests is

$$C(x) = \{t \in \mathcal T : x \notin R_t\},$$

the estimand values whose test does not reject the observation $x$.
