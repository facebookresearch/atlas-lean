# Setting a p-value to zero does not decrease the step-up index

For thresholds $c_0, c_1, \dots$ and p-values $p_1, \dots, p_m$, let $N(t) = \#\{i : p_i \le t\}$ and let the step-up index $k^*$ be the largest $k \le m$ with $N(c_k) \ge k$. If all thresholds are nonnegative, replacing any $p_i$ by $0$ does not decrease $k^*$.
