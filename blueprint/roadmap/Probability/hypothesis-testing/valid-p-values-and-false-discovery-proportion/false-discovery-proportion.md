# False discovery proportion

Let $m \in \mathbb{N}$, $H_0 \subseteq \{0, \dots, m-1\}$ the set of true null hypotheses and $R \subseteq \{0, \dots, m-1\}$ a rejection set. The false discovery proportion is

$$\mathrm{FDP}(H_0, R) = \frac{|R \cap H_0|}{\max(|R|, 1)},$$

which is $0$ when nothing is rejected.
