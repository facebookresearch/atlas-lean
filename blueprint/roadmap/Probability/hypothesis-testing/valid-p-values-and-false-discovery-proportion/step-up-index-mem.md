# The step-up index is a qualifying index

For real numbers $p_1, \dots, p_m$ and real thresholds $c_0, c_1, \dots$, the step-up index is itself a qualifying index: it is some $k \le m$ with at least $k$ of the $p_i$ at most $c_k$ ($k = 0$ always qualifies). The multiple-testing application takes p-values for the $p_i$.
