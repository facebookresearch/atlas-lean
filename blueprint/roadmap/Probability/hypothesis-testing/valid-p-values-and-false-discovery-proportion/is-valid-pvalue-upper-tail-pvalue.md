# Validity of the upper-tail p-value

If a count $X$ has the probability law $\nu$, then its exact upper-tail p-value $P$ satisfies
$\Pr[P \le s] \le s$ for every $s \in [0, 1]$. The event $P \le s$ is $X \ge k_0$ for the least cutoff
$k_0$ whose tail is at most $s$, or empty if there is none.

## Sources

- Lehmann and Romano (2005), Lemma 3.3.1.
