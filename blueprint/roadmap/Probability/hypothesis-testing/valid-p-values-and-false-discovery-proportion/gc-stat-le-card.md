# The estimated-factor statistic never exceeds the number of genes

For all real scores `z_0, …, z_{m-1}` and every gene `j`, the [estimated-factor
statistic](gc-stat.md) satisfies

`T_j = z_j² / λ̂ ≤ m`.

Indeed `z_j²` is one of the summands of `m λ̂ = ∑ₖ zₖ²`; when all scores vanish, `T_j = 0` by the
convention `x / 0 = 0`.
