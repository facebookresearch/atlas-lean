# Validity from conditional validity with a bounded count

On a probability space, a p-value $p$ is valid if $P(p \le t) \le t$ for every $t \in [0, 1]$. Let $S$ be a measurable count with $S \le N$ almost surely and $p = q_{S}$ wherever $S \le N$. If each $q_t$, $t \le N$, is valid conditionally on $S = t$, then $p$ is valid.
