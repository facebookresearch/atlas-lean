# The step-up index as a finite supremum

For real numbers $p_1, \dots, p_m$ and real thresholds $c_0, c_1, \dots$, the step-up index, the largest $k \in \{0, \dots, m\}$ such that at least $k$ of the $p_i$ are at most $c_k$, equals the finite supremum $\max_{k \le m} \bigl(k \text{ if } k \le \#\{i : p_i \le c_k\}, \text{ else } 0\bigr)$, the form used to prove its measurability. The multiple-testing application takes p-values for the $p_i$.
