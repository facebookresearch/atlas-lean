# Exact calibration of the upper-tail p-value at attainable levels

For a probability measure $\nu$ on $\mathbb{N}$ write $U_\nu(k) = \nu(\{j \ge k\})$ and $L_\nu(k) = \nu(\{j \le k\})$ for the upper and lower tails. If a count $X$ has law $\nu$ under $\mu$, then for every $k$, $\mu\big(U_\nu(X) \le U_\nu(k)\big) = U_\nu(k)$, an equality of extended masses in $[0, \infty]$ (the tails of the probability measure $\nu$ are finite).
