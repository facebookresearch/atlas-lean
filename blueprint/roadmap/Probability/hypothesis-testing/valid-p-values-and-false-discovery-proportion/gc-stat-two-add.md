# With two genes and a nonzero score vector, T₀ + T₁ = 2

For two genes with real scores `z_0, z_1` that are not both zero (`z_0² + z_1² ≠ 0`), the
[estimated-factor statistics](gc-stat.md) satisfy

`T_0 + T_1 = 2`,

so the coupling is total: each statistic determines the other. This is the case `m = 2` of the
[constant sum](sum-gc-stat.md) `∑ⱼ T_j = m`.
