# Valid p-value

Let $\mu$ be a measure on a measurable space $\Omega$. A function $X : \Omega \to \mathbb{R}$ is a *valid* (super-uniform) p-value under $\mu$ if

$$\mu(X \le t) \le t \quad \text{for every } t \in [0, 1].$$

Uniform p-values are the equality case. The measure $\mu$ is not required to be a probability measure.
