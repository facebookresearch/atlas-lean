# Validity of the lower-tail p-value

For a probability measure $\nu$ on $\mathbb{N}$ write $U_\nu(k) = \nu(\{j \ge k\})$ and $L_\nu(k) = \nu(\{j \le k\})$ for the upper and lower tails. If a count $X$ has law $\nu$ under $\mu$, then $\mu\big(L_\nu(X) \le s\big) \le s$ for every $s \in [0, 1]$.

## Sources

- E. L. Lehmann and J. P. Romano, *Testing Statistical Hypotheses*, 3rd ed., Springer (2005), Lemma 3.3.1.
