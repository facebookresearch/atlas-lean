# Validity of the lower-tail p-value

For a probability measure $\nu$ on $\mathbb{N}$ write $L_\nu(k) = \nu(\{j \le k\})$ for the lower tail. If a count $X$ has law $\nu$ under $\mu$, then $\mu\big(L_\nu(X) \le s\big) \le s$ for every $s \in [0, 1]$. Since $X$ has the probability law $\nu$ under $\mu$, $\mu$ is a probability measure.

- E. L. Lehmann and J. P. Romano, *Testing Statistical Hypotheses*, 3rd ed., Springer (2005), Lemma 3.3.1.
