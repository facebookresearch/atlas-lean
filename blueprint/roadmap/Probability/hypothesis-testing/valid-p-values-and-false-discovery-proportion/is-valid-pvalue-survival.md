# Survival-function p-values are valid

Let $Y$ be a real random variable with law $\nu$ under a measure $\mu$, $\nu$ a probability measure (atoms allowed). Then $\omega \mapsto \nu([Y(\omega), \infty))$ is a valid p-value: $\mu\big(\nu([Y, \infty)) \le t\big) \le t$ for every $t \in [0, 1]$, an inequality between extended masses in $[0, \infty]$; the measure $\mu$ need not be finite.

- Lehmann–Romano (2005), Lemma 3.3.1.
