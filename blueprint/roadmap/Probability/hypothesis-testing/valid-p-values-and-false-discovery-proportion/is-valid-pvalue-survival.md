# Survival-function p-values are valid

Let $Y$ be a real random variable with law $\nu$ under a measure $\mu$, $\nu$ a probability measure (atoms allowed). Then $\omega \mapsto \nu([Y(\omega), \infty))$ is a valid p-value: $\mu\big(\nu([Y, \infty)) \le t\big) \le t$ for every $t \in [0, 1]$. Since $Y$ has the probability law $\nu$ under $\mu$, $\mu$ is a probability measure.
