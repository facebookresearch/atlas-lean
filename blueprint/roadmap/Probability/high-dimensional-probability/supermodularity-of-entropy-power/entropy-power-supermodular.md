# Supermodularity of entropy power

For real random variables with densities, write $H$ for differential entropy, $H(X) = -\int f\log f$ with $f$ the density of $X$. The question (Madiman) asks whether, for all independent real random variables $X_1, X_2, X_3$ with densities such that $X_2$, $X_1 + X_2$, $X_2 + X_3$ and $X_1 + X_2 + X_3$ have densities $f$ with $f\log f$ integrable, the inequality $e^{2H(X_1+X_2)} + e^{2H(X_2+X_3)} \le e^{2H(X_1+X_2+X_3)} + e^{2H(X_2)}$ holds.
