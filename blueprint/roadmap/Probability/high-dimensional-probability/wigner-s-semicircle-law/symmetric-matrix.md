# Symmetric matrix of an upper-triangular array

For an array $X : \{0, \dots, N-1\}^2 \to (\Omega \to \mathbb{R})$, the $N \times N$ matrix with
entries $X_{\min(i,j), \max(i,j)}$, viewed as a complex Hermitian matrix with real eigenvalues
$\lambda_1, \dots, \lambda_N$. Only the entries with $i \le j$ are used. It is the [Wigner matrix](wigner-matrix.md)
of the array, indexed by $\{0, \dots, N-1\}$.
