# Unique optimum up to a global phase

Let $C$ be an $n \times n$ complex matrix. A vector $\hat x \in \mathbb{C}^n$ is the unique optimum up to phase of the problem $\max \operatorname{Re}(x^\ast C x)$ subject to $|x_k| = 1$ for all $k$ when

- $\hat x$ is feasible: $|\hat x_k| = 1$ for every $k$;
- $\operatorname{Re}(y^\ast C y) \le \operatorname{Re}(\hat x^\ast C \hat x)$ for every feasible $y$;
- every feasible $y$ attaining the maximum is $y = e^{i\theta}\hat x$ for some real $\theta$.
