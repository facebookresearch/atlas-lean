# Ellipsoid in $\mathbb{R}^n$

Let $n \in \mathbb{N}$. A set $A \subseteq \mathbb{R}^n$ is an ellipsoid if there are an invertible linear map $T : \mathbb{R}^n \to \mathbb{R}^n$ and a centre $c \in \mathbb{R}^n$ with

$$A = \{x \in \mathbb{R}^n : \|T(x - c)\| \le 1\},$$

where $\|\cdot\|$ is the Euclidean norm. Such an ellipsoid is closed, full-dimensional and possibly translated.
