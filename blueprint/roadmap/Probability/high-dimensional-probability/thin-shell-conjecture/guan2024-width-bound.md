# Guan's thin-shell bound

There are a real $C > 0$ and a natural number $N \ge 3$ such
that for every natural number $n \ge N$ the thin-shell width $\sigma_n \in [0, \infty]$ of
dimension $n$ satisfies $\sigma_n \le C \log \log n$.
