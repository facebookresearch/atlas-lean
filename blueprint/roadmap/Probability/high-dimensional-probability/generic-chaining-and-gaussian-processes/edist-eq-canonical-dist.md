# The metric is the canonical distance

If every increment $X_s - X_t$ is square-integrable and the metric of $T$ is
$d(s, t) = (\mathbb{E}(X_s - X_t)^2)^{1/2}$ for all $s, t$, then the
extended distance of $T$ equals the canonical distance of the process, so $\gamma_2$ computed
for the metric and for the canonical distance agree. This links the generic chaining bound for Gaussian
processes, stated with the metric, to the majorizing measure theorem, stated with the canonical distance.
