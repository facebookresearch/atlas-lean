# Translation invariance of Rademacher complexity

For a finite set $A \subseteq \mathbb{R}^n$, let $\hat{\mathfrak R}(A) = 2^{-n}\sum_{\sigma \in \{\pm1\}^n}\max_{a \in A}\frac1n\sum_i\sigma_ia_i$ be its empirical Rademacher complexity (one-sided, $0$ for $A = \emptyset$). For every finite $A$ and $c \in \mathbb{R}^n$, $\hat{\mathfrak R}(A + c) = \hat{\mathfrak R}(A)$. For nonempty $A$ this is the finite-set case of [translation invariance](../../../../ComputerScience/machine-learning/generalization-bounds-and-concentration/rademacher-complexity/rademacher-complexity-add-singleton.md), stated for nonempty bounded sets; for $A = \emptyset$ both sides are $0$.
