# Law of completed paths from a start state

Let $S$ be a finite set of states with stop probabilities $q$ and a nonnegative survival kernel $Q$ such that $q(j) + \sum_k Q(j, k) = 1$ for every $j$ and every row sum of $Q$ is at most some $c < 1$. For a start state $i$, the completed-path law is the probability mass function on lists of states that gives each list starting at $i$ its completed-path weight, and every other list mass $0$.
