# Path weight of a list of states from a start state

For stop probabilities $q$, a survival kernel $Q$ on a set of states $S$, and a start state $i$, the path weight of a list of states is $0$ for the empty list and for a list that does not start at $i$; for a list starting at $i$ it is its completed-path weight, read as an extended nonnegative real (a negative weight is read as $0$).
