# Conditional optional stopping for uniformly integrable submartingales

Let $\mu$ be a probability measure, $(\mathcal{F}_n)$ a filtration, and $(f_n)$ a uniformly
integrable submartingale. For stopping times $L \le M$, possibly infinite,
$f_L \le \mathbb{E}[f_M \mid \mathcal{F}_L]$ almost everywhere, where on $\{\tau = \infty\}$ the
value $f_\tau$ means the limit $\lim_n f_n$.
