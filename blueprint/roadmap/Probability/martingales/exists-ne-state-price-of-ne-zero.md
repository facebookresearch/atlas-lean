# Perturbation lemma

**Perturbation lemma.** Let $\Omega$ be a finite set of states, $A$ a set of assets, and $g : A \times \Omega \to \mathbb{R}$ the gains, $g_a(\omega)$ the gain of asset $a$ in state $\omega$. Let $q : \Omega \to \mathbb{R}$ be a strictly positive normalized state-price vector,

$$q(\omega) > 0 \ \text{for all } \omega, \qquad \sum_{\omega} q(\omega) = 1, \qquad \sum_{\omega} q(\omega)\, g_a(\omega) = 0 \ \text{for all } a \in A,$$

and let $d : \Omega \to \mathbb{R}$ be nonzero with $\sum_\omega d(\omega) = 0$ and $\sum_\omega d(\omega)\, g_a(\omega) = 0$ for all $a \in A$. Then there is a strictly positive normalized state-price vector $q' \ne q$, that is, $q'(\omega) > 0$ for all $\omega$, $\sum_\omega q'(\omega) = 1$ and $\sum_\omega q'(\omega)\, g_a(\omega) = 0$ for all $a$.
