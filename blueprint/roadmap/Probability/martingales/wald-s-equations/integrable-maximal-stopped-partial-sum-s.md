# Square-integrability of the maximal stopped partial sum

Let $\mu$ be a probability measure and let $X_0, X_1, \dots$ be measurable, independent,
identically distributed real random variables with $\mathbb{E}[X_0] = 0$ and
$\mathbb{E}[X_0^2] < \infty$; put $S_k = \sum_{i < k} X_i$. Let $T$ be an $\mathbb{N}$-valued
stopping time for the filtration $\mathcal{F}_k = \sigma(X_0, \dots, X_{k-1})$ with
$\mathbb{E}[T] < \infty$. Then $\max_{0 \le k \le T} S_k^2$ is integrable.
