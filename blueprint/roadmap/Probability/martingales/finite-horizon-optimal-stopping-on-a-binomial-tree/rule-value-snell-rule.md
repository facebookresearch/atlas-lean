# The Snell rule attains the Snell envelope

On a binary tree with real branch weight $p$ and real discount $\delta$, for every exercise payoff $g$, the rule that exercises as soon as the payoff reaches the Snell envelope has value equal to the Snell envelope, at every number of periods left and every node. The identity holds for all real $p$ and $\delta$; for $p \in [0, 1]$ and $\delta \ge 0$ it says that this rule attains the optimal discounted expected payoff.
