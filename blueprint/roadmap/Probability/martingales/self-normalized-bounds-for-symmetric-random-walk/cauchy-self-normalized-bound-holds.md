# Time-uniform self-normalized bound for Cauchy increments

Let $X_1, X_2, \dots$ be independent standard Cauchy random variables, $S_t = \sum_{i \le t}X_i$ and $V_t = \sum_{i \le t}X_i^2$. For all $m, x \ge 0$, $P\big(\exists t:\ S_t/(V_t + m) > x\big) \le e^{-2mx^2}$. This follows from de la Peña's bound for symmetric increments, as shown by Howard, Ramdas, McAuliffe and Sekhon (2020).
