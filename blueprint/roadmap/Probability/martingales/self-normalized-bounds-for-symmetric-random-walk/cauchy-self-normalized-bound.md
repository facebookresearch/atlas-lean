# Self-normalized bound for Cauchy random walks

Let $X_1, X_2, \dots$ be independent standard Cauchy random variables, $S_t = \sum_{i \le t}X_i$ and $V_t = \sum_{i \le t}X_i^2$. The claim (AimPL Stein's method problem list, Problem 1.15) is that for all $m, x \ge 0$, $P\big(\exists t:\ S_t/(V_t + m) > x\big) \le e^{-2mx^2}$.
