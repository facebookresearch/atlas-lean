# Optimal threshold of the secretary problem

For $n \in \mathbb{N}$, the optimal threshold is $r_1 = \min\{r \ge 1 : T_r \le 1\}$, with $T_r$
the [harmonic tail](harmonic-tail.md), that is
$r_1 = \min\{r \ge 1 : \sum_{k=r+1}^{n} 1/(k - 1) \le 1\}$; the set contains $\max(n, 1)$.

For $n = 1, \dots, 8$ Ferguson's table gives $r_1 = 1, 1, 2, 2, 3, 3, 3, 4$.

## Sources

- T. S. Ferguson, *Optimal Stopping and Applications*, online text (UCLA Department of Mathematics), Chapter 2, §2.1, equation (4).
