# The maximising weights are the nonzero multiples of the matched weight

For a finite index set `ι`, a positive definite `ι × ι` matrix `R`, `s₀ ≠ s₁` in `ℝ^ι` and a nonzero
weight `w`, with `d = s₁ - s₀` and `SNR(w) = (wᵀ d)² / (wᵀ R w)`, `SNR(w) = SNR(R⁻¹ d)` if and only
if `w = c R⁻¹ d` for some real `c ≠ 0`.
