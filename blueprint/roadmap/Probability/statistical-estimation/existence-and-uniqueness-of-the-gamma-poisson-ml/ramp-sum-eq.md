# Ramp sums are affine between consecutive integers

Let `m ≤ k` be natural numbers and `u` a real number with `m - 1 ≤ u`, and also `u ≤ m` if `m < k`.
Then the [ramp sum](ramp-sum.md) is `R_k(u) = m u - m (m - 1) / 2`. On this range the ramps
`max (u - h) 0` with `h < m` equal `u - h` and those with `m ≤ h < k` vanish. So `R_k` is affine
with slope `m` on each interval `[m - 1, m]` with `m < k`, and affine with slope `k` on
`[k - 1, ∞)`.
