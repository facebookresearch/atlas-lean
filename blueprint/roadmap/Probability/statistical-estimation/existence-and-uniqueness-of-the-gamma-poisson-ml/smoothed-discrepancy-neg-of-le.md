# Once negative on u ≥ 0, the integrated discrepancy stays negative

For a nonempty finite family of counts and reals `0 ≤ u₀ ≤ u`, if Levin and Reeds's
[integrated discrepancy](smoothed-discrepancy.md) satisfies `H(u₀) < 0`, then `H(u) < 0`. So on
`[0, ∞)` the function `H` changes sign at most once, from nonnegative to negative (Levin and Reeds
1977, Lemma 2.3). The condition `u₀ ≥ 0` matters: `H(u) = -n u² / 2 < 0` for every `u < 0`.
