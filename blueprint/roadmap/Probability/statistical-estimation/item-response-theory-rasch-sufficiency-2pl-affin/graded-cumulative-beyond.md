# Graded-response cumulative probability beyond the last threshold

In the graded-response model with discrimination $a$, thresholds $b_1, \dots, b_m$ and ability $\theta$, the cumulative probability at every index $j > m$, beyond the last threshold, is $0$.

## Sources

- J. P. Weeks, "plink: An R package for linking mixed-format tests using IRT-based methods", Journal of Statistical Software 35(12) (2010), equation (2).
