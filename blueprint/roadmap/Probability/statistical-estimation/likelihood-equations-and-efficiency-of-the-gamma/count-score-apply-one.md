# Rate component of the score of one count

For a real size factor $\sigma$, every $\theta = (a, b) \in \mathbb{R}^2$ and every count $k$, the
second coordinate of the [score of one count](count-score.md) $\psi_\sigma(\theta, k)$ is
$a / b - (a + k) / (b + \sigma)$, with the convention $x / 0 = 0$.
