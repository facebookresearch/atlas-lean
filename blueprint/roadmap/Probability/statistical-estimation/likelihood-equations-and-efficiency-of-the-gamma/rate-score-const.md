# Rate score at a common size factor

Let $\iota$ be a finite set of $n$ observations, with counts $k_i \in \mathbb{N}$ and size factors
$s_i$. For real $a$ and $b$, and size factors equal to a common real value $\sigma$, the
[rate score](rate-score.md) is

$$S_b(a, b) = \frac{n a}{b} - \frac{n a + \sum_i k_i}{b + \sigma},$$

both sides with the convention $x / 0 = 0$.
