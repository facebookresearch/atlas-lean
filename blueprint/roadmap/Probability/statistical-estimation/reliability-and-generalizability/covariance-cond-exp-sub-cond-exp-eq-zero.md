# True score and error are uncorrelated

Let $X$ be an integrable real random variable on a probability space $(\Omega, \mathcal F, \mu)$ and $\mathcal G \subseteq \mathcal F$ a sub-$\sigma$-algebra; write $T = \mathbb{E}[X \mid \mathcal G]$ for the true score and $X - T$ for the error. If $X$ is square integrable, then $\operatorname{Cov}(T, X - T) = 0$.
