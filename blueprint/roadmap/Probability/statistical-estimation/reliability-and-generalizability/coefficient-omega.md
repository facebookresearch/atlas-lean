# McDonald's coefficient omega

For loadings $\lambda_1, \dots, \lambda_k$, a factor variance $\varphi$ and an error covariance matrix $\Theta$ of a one-factor congeneric model, coefficient omega is

$$\omega = \frac{(\sum_i\lambda_i)^2\varphi}{(\sum_i\lambda_i)^2\varphi + \sum_{i,j}\Theta_{ij}}$$

(with $a/0 = 0$).

## Sources

- Bollen (1980) and Raykov (2001), as cited in the documentation of the semTools reliability function.
