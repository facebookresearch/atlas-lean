# Error variances of a fixed person in a crossed design

In a crossed person-by-item design with $m \ge 1$ items, write $X_{pi} = \mu + P_p + I_i + e_{pi}$, the absolute error $\Delta_p = \frac1m\sum_iX_{pi} - (\mu + P_p)$ and the relative error $\delta_p = \frac1m\sum_iX_{pi} - (\mu + P_p + \frac1m\sum_iI_i)$. Fix a person $p$ and suppose, on a probability space, the item effects $I_i$ and residuals $e_{pi}$ are square integrable with $\operatorname{Cov}(I_i, I_j) = \sigma_I^2\mathbf 1[i = j]$, $\operatorname{Cov}(e_{pi}, e_{pj}) = \sigma_e^2\mathbf 1[i = j]$ and $\operatorname{Cov}(I_i, e_{pj}) = 0$. Then $\operatorname{Var}(\Delta_p) = (\sigma_I^2 + \sigma_e^2)/m$ and $\operatorname{Var}(\delta_p) = \sigma_e^2/m$.
