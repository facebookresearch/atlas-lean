# Total variance splits into true-score and error variance

For a probability measure $\mu$, a sub-$\sigma$-algebra $\mathcal G$ and a square-integrable random variable $X$,

$$\operatorname{Var}(X) = \operatorname{Var}\big(\mathbb E[X \mid \mathcal G]\big) + \operatorname{Var}\big(X - \mathbb E[X \mid \mathcal G]\big).$$
