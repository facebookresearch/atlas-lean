# The log-partition function with base weights is convex

Let $X$ be a finite set, $\iota$ a finite index set, $h : X \to \mathbb{R}$ base weights and $T : X \to \mathbb{R}^\iota$ a sufficient statistic, with $h(x) \ge 0$ for every $x$ and $\sum_x h(x) > 0$. Then the log-partition
function $A(\eta) = \log \sum_x h(x) e^{\eta \cdot T(x)}$ is convex on $\mathbb{R}^\iota$. This is the
form with base weights of [the convexity of the log-partition function](convex-on-log-partition.md).
