# Observed regression function of a sharp regression-discontinuity design

For a cutoff $c$ and functions $m_0, m_1 : \mathbb{R} \to \mathbb{R}$ (versions of $x \mapsto \mathbb{E}[Y(d) \mid X = x]$), the observed regression function of the sharp design is $r(x) = m_1(x)$ for $x \ge c$ and $r(x) = m_0(x)$ for $x < c$.
