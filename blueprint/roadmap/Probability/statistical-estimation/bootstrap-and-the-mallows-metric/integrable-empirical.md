# Every function is integrable for the empirical distribution

For data $x_0, x_1, \dots$ in a measurable space with a zero element and $n \in \mathbb{N}$, let $\hat P_n = \frac1n\sum_{i<n}\delta_{x_i}$ be the empirical distribution ($\hat P_0 = \delta_0$). If singletons are measurable, every real function is integrable with respect to $\hat P_n$.
