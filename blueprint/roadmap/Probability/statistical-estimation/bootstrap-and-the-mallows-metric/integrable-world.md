# Integrability of functions of one bootstrap draw

For data $x_0, x_1, \dots$ in a measurable space with a zero element and $n \in \mathbb{N}$, let $\hat P_n = \frac1n\sum_{i<n}\delta_{x_i}$ be the empirical distribution ($\hat P_0 = \delta_0$). The bootstrap world of the data is the probability measure on arrays $\omega = (\omega_{n,k})_{n,k \in \mathbb{N}}$ under which all entries are independent and each $\omega_{n,k}$ has law $\hat P_n$; the resample at size $n$ is $(\omega_{n,0}, \dots, \omega_{n,n-1})$. If singletons are measurable and $f$ is a measurable real function, then $\omega \mapsto f(\omega_{n,k})$ is integrable under the bootstrap world for all $n, k$.
