# Lindeberg condition for the bootstrap array from the data

For real data $x_0, x_1, \dots$ let $\bar x_n = \frac1n\sum_{i<n}x_i$, and let the bootstrap coupling be the probability measure on arrays $(\omega_{n,k})$ with independent entries, $\omega_{n,k}$ having the empirical law of $x_0, \dots, x_{\max(n,1)-1}$; write $Y_{n,k} = (\omega_{n,k} - \bar x_n)/\sqrt n$ for the bootstrap triangular array. If for every $\varepsilon > 0$, $\frac1n\sum_{i<n}(x_i - \bar x_n)^2\mathbf 1\{|x_i - \bar x_n| > \varepsilon\sqrt n\} \to 0$, then the array $(Y_{n,k})_{k<n}$ satisfies the Lindeberg condition: $\sum_{k<n}\mathbb{E}[Y_{n,k}^2\mathbf 1\{|Y_{n,k}| > \varepsilon\}] \to 0$ for every $\varepsilon > 0$.
