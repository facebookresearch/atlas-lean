# Canonical bootstrap coupling

For data $x_0, x_1, \dots$ in a measurable space, the bootstrap coupling is the probability measure on arrays $\omega = (\omega_{n,k})_{n,k \in \mathbb{N}}$ under which all entries are independent and every entry in row $n$ has the empirical law of $x_0, \dots, x_{\max(n,1)-1}$; $\omega_{n,k}$ is the $k$-th resampled value in row $n$.
