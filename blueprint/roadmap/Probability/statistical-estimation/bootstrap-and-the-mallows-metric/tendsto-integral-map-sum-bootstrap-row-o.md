# Central limit theorem for bootstrap rows with positive variance

For real data $x_0, x_1, \dots$ let $\bar x_n = \frac1n\sum_{i<n}x_i$, and let the bootstrap coupling be the probability measure on arrays $(\omega_{n,k})$ with independent entries, $\omega_{n,k}$ having the empirical law of $x_0, \dots, x_{\max(n,1)-1}$; write $Y_{n,k} = (\omega_{n,k} - \bar x_n)/\sqrt n$ for the bootstrap triangular array. If $\sum_{k<n}\mathbb{E}[Y_{n,k}^2] \to s^2$ with $s > 0$ and the array satisfies the Lindeberg condition, then for every bounded continuous $f$, $\mathbb{E}[f(\sum_{k<n}Y_{n,k})] \to \int f\,d\mathcal N(0, s^2)$.
