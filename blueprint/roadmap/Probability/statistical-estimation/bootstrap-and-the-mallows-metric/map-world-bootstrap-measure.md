# The bootstrap world and the canonical bootstrap coupling

For data $x_0, x_1, \dots$ in a measurable space with a zero element and $n \in \mathbb{N}$, let $\hat P_n = \frac1n\sum_{i<n}\delta_{x_i}$ be the empirical distribution ($\hat P_0 = \delta_0$). The bootstrap world of the data is the probability measure on arrays $\omega = (\omega_{n,k})_{n,k \in \mathbb{N}}$ under which all entries are independent and each $\omega_{n,k}$ has law $\hat P_n$; the resample at size $n$ is $(\omega_{n,0}, \dots, \omega_{n,n-1})$. Replacing the unused row $n = 0$ by the constant $x_0$ maps the bootstrap world onto the canonical bootstrap coupling of the data, in which every row $n$ is an independent sequence drawn from the empirical distribution of $x_0, \dots, x_{n-1}$; the rows $n \ge 1$ are unchanged.
