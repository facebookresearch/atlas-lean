# Linearization of an estimating equation at a root

Let $\psi_\theta(x) \in E$ be differentiable in $\theta$ on $B(\theta_0, \delta)$ with $\|D\psi_\theta(x) - D\psi_{\theta_0}(x)\| \le M(x)\|\theta - \theta_0\|$ there. If $\theta \in B(\theta_0, \delta)$ solves $\sum_{i<n}\psi_\theta(x_i) = 0$, then

$$\Big\|\sum_{i<n}\psi_{\theta_0}(x_i) + \Big(\sum_{i<n}D\psi_{\theta_0}(x_i)\Big)(\theta - \theta_0)\Big\| \le \Big(\sum_{i<n}M(x_i)\Big)\|\theta - \theta_0\|^2.$$
