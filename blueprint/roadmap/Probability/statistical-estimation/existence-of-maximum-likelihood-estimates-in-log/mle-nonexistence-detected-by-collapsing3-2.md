# Collapsing does not detect all nonexistence of the MLE

For an $I \times J \times K$ contingency table $n$ of counts, the maximum likelihood estimate under the no three-way interaction model exists if some table with strictly positive real entries has the same two-way margins as $n$. A collapsing to a $2 \times 2 \times 2$ table merges the three levels of each variable into two nonempty classes and adds the corresponding cells. The conjecture is false: for some $3 \times 3 \times 3$ table the two conditions differ. Eriksson found a table with no maximum likelihood estimate although every collapsing has one (see also Eriksson, Fienberg, Rinaldo and Sullivant).
