# The Bernoulli likelihood depends only on the number of successes

For a binary sample $x \in \{0, 1\}^n$ with $k$ successes, write $L(\theta) = \prod_i\theta^{x_i}(1 - \theta)^{1 - x_i}$ for the Bernoulli likelihood and $\hat p = k/n$ for the sample proportion. Then $L(\theta) = \theta^k(1 - \theta)^{n-k}$ for every $\theta \in \mathbb{R}$.
