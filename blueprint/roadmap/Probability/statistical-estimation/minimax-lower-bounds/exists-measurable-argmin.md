# Measurable choice of a minimiser

Let $\iota$ be a finite nonempty set and $L_i : \Omega \to [0, \infty]$, $i \in \iota$, measurable
functions. Then there is a map $g : \Omega \to \iota$ whose fibres $g^{-1}(i)$ are measurable and
which selects a minimiser: $L_{g(\omega)}(\omega) \le L_i(\omega)$ for all $\omega$ and $i$. One takes the
first minimiser for a fixed enumeration of $\iota$.
