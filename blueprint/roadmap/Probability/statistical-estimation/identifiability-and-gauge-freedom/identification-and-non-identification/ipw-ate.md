# Inverse-probability-weighted treatment effect functional

For a measure $\nu$ on triples $(x, t, y)$ with law-read propensity $e(x)$, the inverse-probability-weighted functional is

$$\int\Big(\frac{\mathbf 1\{t = 1\}\,y}{e(x)} - \frac{\mathbf 1\{t = 0\}\,y}{1 - e(x)}\Big)\,d\nu(x, t, y),$$

with $a/0 = 0$.
