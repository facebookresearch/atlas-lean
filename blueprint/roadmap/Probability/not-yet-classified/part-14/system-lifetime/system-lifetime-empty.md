# System lifetime of the empty event is zero

For a finite set of components with lifetimes $T_e \in [0, \infty]$, the system lifetime of a set $A$ of up-configurations is the maximum over $x \in A$ of the configuration lifetimes $\min\{T_e : x_e \text{ up}\}$. When $A$ is empty, the system lifetime is $0$.
