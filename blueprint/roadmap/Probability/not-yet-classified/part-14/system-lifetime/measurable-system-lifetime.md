# Measurability of the system lifetime

Let a system have finitely many components $e$ with measurable random lifetimes $T_e : \Omega \to [0, \infty]$, and let $A$ be a fixed set of up/down configurations. The system lifetime is the maximum over configurations $x \in A$ of $\min_{e : x_e = \text{up}} T_e$ (with the empty minimum $\infty$ and the empty maximum $0$). Then the system lifetime is a measurable function of $\omega$. No probability measure or independence is needed.
