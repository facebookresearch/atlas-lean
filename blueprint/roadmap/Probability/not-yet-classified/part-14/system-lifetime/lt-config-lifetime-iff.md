# Lifetime of a component configuration exceeds t iff every selected component does

For a finite set of components with lifetimes $T_e \in [0, \infty]$ and a selection $x$ of components, let the configuration lifetime be $\min\{T_e : x_e \text{ selected}\}$ (equal to $\infty$ when nothing is selected). For every finite $t \ge 0$, $t$ is below the configuration lifetime if and only if $t < T_e$ for every selected $e$.
