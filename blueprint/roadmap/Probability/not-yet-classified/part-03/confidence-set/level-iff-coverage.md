# Test inversion

Let $(P_\theta)_{\theta \in \Theta}$ be probability measures on a measurable space $X$, $\tau : \Theta \to T$ an estimand, and $R_t \subseteq X$ measurable rejection sets for the null hypotheses $\tau(\theta) = t$. Let $C(x) = \{t : x \notin R_t\}$ be the inverted confidence set. Then

$$\bigl(\forall \theta,\ P_\theta(R_{\tau(\theta)}) \le \alpha\bigr) \iff \bigl(\forall \theta,\ P_\theta(\{x : \tau(\theta) \in C(x)\}) \ge 1 - \alpha\bigr).$$
