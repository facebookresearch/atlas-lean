# Gaussian affine failure bracket

Let $g$ be a function on $\mathbb{R}^n$, $L \ne 0$ a linear functional, $a, R, \delta$ real, and suppose $|g(z) - (a + L z)| \le \delta$ for all $\|z\| \le R$. With $Z$ standard Gaussian, $\Phi$ the standard normal distribution function and $p_R = P(\|Z\| > R)$,

$$P(g(Z) \le 0) \le \Phi\Big(\frac{\delta - a}{\|L\|}\Big) + p_R \quad\text{and}\quad \Phi\Big(\frac{-\delta - a}{\|L\|}\Big) \le P(g(Z) \le 0) + p_R.$$
