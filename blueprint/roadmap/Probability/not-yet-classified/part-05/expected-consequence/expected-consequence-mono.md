# Expected consequence is monotone in the loss

Let $\mu$ be a probability measure and $\kappa$ a Markov kernel, and define the expected consequence of a loss $L \ge 0$ (with values in $[0,\infty]$) as $\int\!\int L(b)\,\kappa(a, db)\,\mu(da)$. If $L \le L'$ pointwise, then the expected consequence of $L$ is at most that of $L'$.
