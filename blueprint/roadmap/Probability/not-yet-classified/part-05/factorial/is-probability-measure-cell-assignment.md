# Complete randomization over four cells is a probability measure

Let $\iota$ be a finite set of units and let $n_1, \dots, n_4$ be positive cell sizes with $n_1 + \dots + n_4 = |\iota|$. The uniform distribution on assignments $\iota \to \{1, 2, 3, 4\}$ that put exactly $n_c$ units in cell $c$ is a probability measure.
