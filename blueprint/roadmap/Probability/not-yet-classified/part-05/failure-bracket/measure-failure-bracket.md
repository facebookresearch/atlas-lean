# Failure-probability bracket

Let $\mu$ be any measure, $g$ and $L$ real functions, $B$ a set and $\delta$ real, with $|g(\omega) - L(\omega)| \le \delta$ for every $\omega \in B$. Then, with truncated subtraction in $[0, \infty]$,

$$\mu\{L \le -\delta\} - \mu(B^c) \le \mu\{g \le 0\} \le \mu\{L \le \delta\} + \mu(B^c).$$
