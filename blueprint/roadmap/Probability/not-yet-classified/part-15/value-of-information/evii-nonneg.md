# Value of information is nonnegative

For a nonempty finite set of actions, finitely many states and evidence outcomes, arbitrary real joint weights $w(\omega, e)$ and utilities $U(a, \omega)$, $\sum_e \max_a \sum_\omega w(\omega, e) U(a, \omega) - \max_a \sum_{\omega, e} w(\omega, e) U(a, \omega) \ge 0$: choosing a best action for each observation is worth at least as much as any fixed action.
