# Expected value of imperfect information

For a nonempty finite set of actions, finite sets of states $\Omega$ and evidence outcomes, joint weights $w(\omega, e)$ and utilities $U(a, \omega)$, the unnormalized expected value of imperfect information is $\sum_e \max_a \sum_\omega w(\omega, e) U(a, \omega) - \max_a \sum_\omega \sum_e w(\omega, e) U(a, \omega)$.
