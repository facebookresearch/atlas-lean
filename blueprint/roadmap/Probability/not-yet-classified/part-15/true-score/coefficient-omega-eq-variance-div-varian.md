# Coefficient omega as a variance ratio

On a probability space, let $X_i = \nu_i + \lambda_i F + E_i$ for $i = 1, \dots, k$, with $F$ and every $E_i$ square integrable, $\operatorname{Cov}(F, E_i) = 0$, $\operatorname{Var}F = \varphi$ and $\operatorname{Cov}(E_i, E_j) = \Theta_{ij}$. If $\operatorname{Var}\big(\sum_i X_i\big) > 0$, then coefficient omega,

$$\omega = \frac{(\sum_i \lambda_i)^2\varphi}{(\sum_i \lambda_i)^2\varphi + \sum_{i,j}\Theta_{ij}},$$

equals $\operatorname{Var}\big((\sum_i \lambda_i)F\big)/\operatorname{Var}\big(\sum_i X_i\big)$.
