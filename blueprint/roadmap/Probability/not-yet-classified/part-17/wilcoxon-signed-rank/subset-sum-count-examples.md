# Wilcoxon's worked cases

For `15` pairs, `∑_{t ≤ 24} c_15(t) = 676`, so
`P(W⁺ ≤ 24) = 676 / 32768 ≈ 0.0206`, inside the source's range `[0.019, 0.054]`; for `8` pairs,
`∑_{t ≤ 3} c_8(t) = 5`, so `P(W⁺ ≤ 3) = 5 / 256`.

## Sources

- F. Wilcoxon, "Individual comparisons by ranking methods", Biometrics Bull. 1 (1945) 80–83, Table II and the worked examples.
