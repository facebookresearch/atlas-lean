# Probability distributions on a finite set

A function $q : Z \to \mathbb{R}$ on a
finite set $Z$ is a probability distribution when $q(z) \ge 0$ for every $z \in Z$ and
$\sum_{z \in Z} q(z) = 1$.

On a finite set of pure strategies, such a function is a mixed strategy, a point of the simplex: the
condition used for
[symmetric Nash equilibria](../../Biology/population-dynamics/stability-of-evolutionarily-stable-states/is-nash.md)
and [evolutionarily stable states](../../Biology/population-dynamics/stability-of-evolutionarily-stable-states/is-ess.md).
