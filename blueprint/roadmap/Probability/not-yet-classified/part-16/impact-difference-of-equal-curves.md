# Group impact under equal item curves

Let two groups have latent distributions $\pi_A, \pi_B$ on the same finite set of latent states $Z$, and let each group's binary item responses be locally independent given $z$, with success probabilities $q_A(z, i), q_B(z, i) \in [0, 1]$. If item $i$ has the same curve in both groups, $q_A(z, i) = q_B(z, i)$ for every $z$, then the difference of the groups' marginal success probabilities on item $i$ is $\sum_{z}\big(\pi_A(z) - \pi_B(z)\big)q_A(z, i)$.
