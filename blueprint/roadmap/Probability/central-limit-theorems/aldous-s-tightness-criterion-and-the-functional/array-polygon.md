# Polygonal process of a triangular array

For a triangular array $(\xi_{n,i})$, an outcome $\omega$ and $n \in \mathbb{N}$, the polygonal process of row $n$ is the continuous path on $[0, 1]$ that linearly interpolates the partial sums $k \mapsto \sum_{i<k} \xi_{n,i}(\omega)$ at the grid times $k/n$. It is Donsker's polygonal process of the rescaled sequence $\sqrt n\, \xi_{n,i}$, that is, Donsker's process with the $1/\sqrt n$ normalization undone.
