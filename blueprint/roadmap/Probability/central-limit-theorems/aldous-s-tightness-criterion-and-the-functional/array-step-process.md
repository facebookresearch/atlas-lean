# Step process of a triangular array

The step process of a triangular array $\xi$ in $D([0,1])$: row $n$ places the increments
$\xi_{n,0}, \dots, \xi_{n,n-1}$ at the times $1/n, \dots, 1$, so the path is
$t \mapsto \sum_{i < \lfloor n t \rfloor} \xi_{n,i}$. There is no $1/\sqrt n$ normalization, because
an array row carries its own scaling.
