# Interpolation formula for the polygonal process

For every $n$, every triangular array $(\xi_{n,i})$, every outcome $\omega$ and every $t \in [0, 1]$, write $k = \lfloor n t\rfloor$. The polygonal process of row $n$ at time $t$ is $\sum_{i<k} \xi_{n,i}(\omega) + (n t - k)\, \xi_{n,k}(\omega)$ when $k < n$, and $\sum_{i<k} \xi_{n,i}(\omega)$ when $k = n$: the partial sum up to $\lfloor n t\rfloor$ plus the fractional part of the next increment.
