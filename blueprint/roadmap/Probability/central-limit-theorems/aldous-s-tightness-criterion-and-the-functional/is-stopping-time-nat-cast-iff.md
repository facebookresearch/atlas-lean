# Natural-number random times as stopping times

Let $(\mathcal F_i)_{i \in \mathbb{N}}$ be a filtration and $\sigma$ a random time with values in $\mathbb{N}$. Then $\sigma$, viewed as a random time with values in $\mathbb{N} \cup \{\infty\}$, is a stopping time if and only if $\{\sigma \le i\} \in \mathcal F_i$ for every $i$.
