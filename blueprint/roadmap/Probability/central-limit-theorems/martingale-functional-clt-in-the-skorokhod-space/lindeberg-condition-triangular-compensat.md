# Lindeberg condition for the compensated Bernoulli array

Let $\xi_0, \xi_1, \dots$ take values in $\{0, 1\}$ and let $0 < p < 1$. The array $(\xi_k - p)/\sqrt n$ satisfies the Lindeberg condition for triangular arrays: every entry is bounded by $1/\sqrt n$, so all truncated second moments vanish once $1/\sqrt n < \varepsilon$.
