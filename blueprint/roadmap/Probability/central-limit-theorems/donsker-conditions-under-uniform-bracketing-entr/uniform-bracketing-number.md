# Uniform bracketing number

Let $S$ be a measurable space, $(F_i)_{i \in \iota}$ a family of real functions on $S$ and $\varepsilon \in \mathbb{R}$. The uniform (sup-norm) bracketing number is

$$N_{[\,]}(\varepsilon, F, \lVert \cdot \rVert_\infty) = \inf\{ n \in \mathbb{N} : F \text{ has a uniform bracket cover of width } \varepsilon \text{ with } n \text{ brackets} \} \in \mathbb{N} \cup \{\infty\},$$

where a uniform bracket cover consists of measurable $l_j \le u_j$ with $u_j - l_j \le \varepsilon$ pointwise such that each $F_i$ satisfies $l_j \le F_i \le u_j$ for some $j$. It is $\infty$ when no finite cover exists.
