# Common Covariance Log LR

Let $\iota$ be a finite index set and identify vectors in $\mathbb{R}^\iota$ with column vectors. For $s_1, s_0, y \in \mathbb{R}^\iota$ and a real $\iota \times \iota$ matrix $R$, the common-covariance Gaussian log-likelihood ratio statistic is

$$\Lambda(y) = (s_1 - s_0)^{\mathsf T} R^{-1} y - \tfrac12 \bigl(s_1^{\mathsf T} R^{-1} s_1 - s_0^{\mathsf T} R^{-1} s_0\bigr),$$

where $R^{-1}$ is the matrix inverse, taken to be the zero matrix when $R$ is singular.
