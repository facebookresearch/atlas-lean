# Recurrence for the upper incomplete gamma function

For $a > 0$ and $x \ge 0$, the [upper incomplete gamma function](upper-incomplete-gamma.md) satisfies

$$\Gamma(a + 1, x) = x^a e^{-x} + a\, \Gamma(a, x),$$

which follows by integration by parts.
