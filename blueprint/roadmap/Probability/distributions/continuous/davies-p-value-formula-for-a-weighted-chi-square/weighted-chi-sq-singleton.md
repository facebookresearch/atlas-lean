# No atoms

Let $k$ be a finite index set, $\lambda \in \mathbb{R}^k$, and let $Q = \sum_j \lambda_j \xi_j^2$ with $\xi_j$ independent standard normal, so that $Q$ has the weighted chi-square law $\sum_j \lambda_j \chi^2_1$. If $\lambda_j \ne 0$ for some $j$, then $Q$ has no atoms: $P(Q = q) = 0$ for every $q \in \mathbb{R}$.
