# Integrable id weighted Chi Sq

Let $k$ be a finite index set, $\lambda \in \mathbb{R}^k$, and let $Q = \sum_j \lambda_j \xi_j^2$ with $\xi_j$ independent standard normal, so that $Q$ has the weighted chi-square law $\sum_j \lambda_j \chi^2_1$. Then $Q$ is integrable, that is, $\mathbb{E}\lvert Q\rvert < \infty$; equivalently the identity function is integrable for the weighted chi-square law.
