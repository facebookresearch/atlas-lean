# Maxwell speed density

For a scale $a$ (for a gas, $a^2 = k_B T / m$) and a speed $v$, the Maxwell speed density is

$$f_a(v) = \sqrt{\frac{2}{\pi}}\, \frac{v^2}{a^3} \exp\Bigl( -\frac{v^2}{2 a^2} \Bigr),$$

given by this formula for all real $a$ and $v$ (with $x / 0 = 0$), without a piecewise extension. It is intended for $a > 0$ and $v > 0$.
