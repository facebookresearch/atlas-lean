# Weibull survival function

For real parameters $k$ (shape) and $\lambda$ (scale), the Weibull survival function is

$$S(x) = \begin{cases} 1 & \text{if } x < 0, \\ \exp\bigl( -(x/\lambda)^k \bigr) & \text{if } x \ge 0, \end{cases}$$

where $(x/\lambda)^k$ is the real power and $x / 0 = 0$. It is intended for $k > 0$ and $\lambda > 0$.
