# Void Probability

For a nucleation intensity $\kappa \in \mathbb{R}$ and a volume $v \in \mathbb{R}$, the JMAK void probability is

$$p_\kappa(v) = e^{-\kappa v}.$$

For $\kappa \ge 0$ and $v \ge 0$ it is read as the probability that a region of volume $v$ contains no nucleus.

This is a model assumption; it is not derived from a Poisson point process.
