# Gumbel CDF

For real parameters $\mu$ and $\beta$, the Gumbel distribution function is

$$F_{\mu,\beta}(x) = \exp\!\Big(-\exp\!\Big(-\frac{x - \mu}{\beta}\Big)\Big), \qquad x \in \mathbb{R}.$$

The formula is taken literally for every real $\mu$ and $\beta$, with the convention $y / 0 = 0$, so $F_{\mu,0} \equiv e^{-1}$. For scale $\beta > 0$ it is the cumulative distribution function of the Gumbel law with location $\mu$ and scale $\beta$.
