# Gumbel quantile function

For real parameters $\mu$, $\beta$ and $q$, the Gumbel quantile is

$$Q_{\mu,\beta}(q) = \mu - \beta \log(-\log q).$$

The formula is taken literally for all real arguments, with the conventions $\log 0 = 0$ and $\log y = \log\lvert y \rvert$ for $y < 0$.

For $\beta > 0$ and $0 < q < 1$, $Q_{\mu,\beta}(q)$ is the $q$-quantile of the Gumbel distribution with location $\mu$ and scale $\beta$; outside that range it is only the formula.
