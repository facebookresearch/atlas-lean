# Means below the Garwood upper bound are exactly the non-rejected ones

Let $0 < \alpha < 1$, $k \in \mathbb{N}$ and $x \ge 0$. Then $x \le u_\alpha(k)$ if and only if
$\alpha \le F_k(x)$, where $u_\alpha$ is [Garwood's upper bound](garwood-upper.md) and $F_k$ the
[Poisson distribution function](../poisson-gamma-duality-identity/poisson-cdf.md).
