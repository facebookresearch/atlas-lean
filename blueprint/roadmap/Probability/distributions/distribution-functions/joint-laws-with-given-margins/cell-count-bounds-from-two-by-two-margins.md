# Cell bounds from the margins of a two-by-two table

For a $2 \times 2$ table of nonnegative counts with row totals $r_1, r_2$, column totals $c_1, c_2$ and $n = r_1 + r_2 = c_1 + c_2$, the top-left cell satisfies $\max(0, r_1 + c_1 - n) \le n_{11} \le \min(r_1, c_1)$, and every integer in this range is attained by a table with these margins, namely $n_{12} = r_1 - n_{11}$, $n_{21} = c_1 - n_{11}$, $n_{22} = n - r_1 - c_1 + n_{11}$. For nonnegative real masses with the same margins, every real number in the interval is attained.
