# Values of a strictly increasing distribution function lie strictly between 0 and 1

Let $\mu$ be a probability measure on $\mathbb{R}$ whose distribution function $F$ is strictly increasing. Then $0 < F(x) < 1$ for every $x$: if $F(x) = 0$, any $y < x$ would have $F(y) < 0$, and if $F(x) = 1$, any $y > x$ would have $F(y) > 1$. Continuity of $F$ is not needed.
