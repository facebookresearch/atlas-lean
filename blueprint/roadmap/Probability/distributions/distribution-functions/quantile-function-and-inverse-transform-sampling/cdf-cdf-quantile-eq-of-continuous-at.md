# The distribution function at the quantile equals the level at continuity points

Let $\mu$ be a measure on $\mathbb{R}$ with distribution function $F$ and generalized inverse quantile $Q$, and let $0 < u < 1$. If $F$ is continuous at $Q(u)$, then $F(Q(u)) = u$. Here $F$ is the cumulative distribution function attached to every measure on $\mathbb{R}$: a monotone, right-continuous function with values in $[0, 1]$. It coincides with $x \mapsto \mu((-\infty, x])$ when $\mu$ is a probability measure, and need not for other measures.
