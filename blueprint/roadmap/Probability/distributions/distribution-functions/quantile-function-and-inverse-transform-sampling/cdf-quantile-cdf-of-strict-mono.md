# The quantile inverts a strictly increasing distribution function

Let $\mu$ be a probability measure on $\mathbb{R}$ whose distribution function $F$ is strictly increasing, and let $Q$ be its generalized inverse quantile. Then $Q(F(x)) = x$ for every $x$; strict monotonicity keeps every value of $F$ inside $(0, 1)$. Here $F$ is the cumulative distribution function attached to every measure on $\mathbb{R}$: a monotone, right-continuous function with values in $[0, 1]$. It coincides with $x \mapsto \mu((-\infty, x])$ when $\mu$ is a probability measure, and need not for other measures.
