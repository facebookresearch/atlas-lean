# The quantile inverts a strictly increasing distribution function

Let $\mu$ be a probability measure on $\mathbb{R}$ whose distribution function $F$ is strictly increasing, and let $Q$ be its generalized inverse quantile. Then $Q(F(x)) = x$ for every $x$; strict monotonicity keeps every value of $F$ inside $(0, 1)$. Here $F(x) = \mu((-\infty, x])$.
