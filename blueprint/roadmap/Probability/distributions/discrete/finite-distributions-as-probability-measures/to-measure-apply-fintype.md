# Measure of a set under a probability mass function on a finite type

Let $p$ be a probability mass function on a finite type $\alpha$ carrying a σ-algebra in which singletons are measurable, and let $\mu_p$ be the measure associated to $p$. Then for every set $s \subseteq \alpha$,

$$\mu_p(s) = \sum_{x \in \alpha} \mathbf 1_s(x)\, p(x).$$
