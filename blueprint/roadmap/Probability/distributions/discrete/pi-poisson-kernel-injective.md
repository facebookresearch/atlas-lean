# Pi Poisson Kernel injective

Let $\iota$ be a finite index set and let $\kappa$ be the product Poisson kernel from $[0, \infty)^\iota$ to $\mathbb{N}^\iota$, $\kappa(r) = \bigotimes_{i \in \iota} \mathrm{Po}(r_i)$, where $\mathrm{Po}(r)(\{n\}) = e^{-r} r^n / n!$. Then $r \mapsto \kappa(r)$ is injective: for $r, s \in [0, \infty)^\iota$, $\kappa(r) = \kappa(s)$ implies $r = s$.
