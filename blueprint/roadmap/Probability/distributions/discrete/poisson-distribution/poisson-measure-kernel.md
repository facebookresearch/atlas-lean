# The Poisson kernel

The Poisson kernel is the Markov kernel from $[0, \infty)$ to $\mathbb{N}$ that sends a mean $r \ge 0$ to the Poisson law

$$r \longmapsto \mathrm{Po}(r), \qquad \mathrm{Po}(r)(\{n\}) = e^{-r} \frac{r^n}{n!}, \quad n \in \mathbb{N}.$$

It is a kernel because $r \mapsto \mathrm{Po}(r)$ is measurable, and each $\mathrm{Po}(r)$ is a probability measure.
