# Log-concave function on $\mathbb{R}^d$

Let $d \in \mathbb{N}$. A function $f : \mathbb{R}^d \to \mathbb{R}$ is log-concave if $f(x) \ge 0$ for all $x$ and

$$f\big((1 - t) x + t y\big) \ge f(x)^{1 - t} f(y)^{t}$$

for all $x, y \in \mathbb{R}^d$ and all $t \in [0, 1]$, with real powers of nonnegative numbers and the convention $0^0 = 1$. No measurability is required.
