# σ-algebra of the configuration outside a region

For a set $E$ and $\Lambda \subseteq E$, the σ-algebra $\mathcal{F}_{\Lambda^c}$ on $\{0, 1\}^E$ generated by the coordinates $\omega \mapsto \omega_e$, $e \in E \setminus \Lambda$: the information about a configuration visible from outside the region $\Lambda$.
