# Upper bounds on clopen-event probabilities pass to weak limits

Let $E$ be a countable set, $(\mu_n)$ and $\nu$ probability measures on $\{0, 1\}^E$ with $\mu_n \to \nu$ [weakly](weak-converges-to.md), $\rho$ a measure on $\{0, 1\}^E$ and $A$ a clopen event. If $\mu_n(A) \le \rho(A)$ for every $n$, then $\nu(A) \le \rho(A)$. Here $\rho(A)$ is read as a real number, with the value $0$ when $\rho(A) = \infty$.
