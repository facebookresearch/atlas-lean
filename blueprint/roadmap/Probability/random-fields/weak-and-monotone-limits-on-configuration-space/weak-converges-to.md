# Weak convergence of probability measures on configuration space

For a countable set $E$, a sequence $(\mu_n)$ of probability measures on $\{0, 1\}^E$ converges weakly to a probability measure $\nu$ if it converges in the topology of weak convergence on probability measures, the coarsest topology making $\mu \mapsto \int f\, d\mu$ continuous for every bounded continuous $f : \{0, 1\}^E \to \mathbb{R}$.
