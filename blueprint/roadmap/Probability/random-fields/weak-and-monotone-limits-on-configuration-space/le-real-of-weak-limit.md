# Lower bounds on clopen-event probabilities pass to weak limits

Let $E$ be a countable set, $(\mu_n)$ and $\nu$ probability measures on $\{0, 1\}^E$ with $\mu_n \to \nu$ [weakly](weak-converges-to.md), $\rho$ a measure on $\{0, 1\}^E$ and $A$ a clopen increasing event. If $\rho(A) \le \mu_n(A)$ for every $n$, then $\rho(A) \le \nu(A)$. Here $\rho(A)$ is read as a real number, with the value $0$ when $\rho(A) = \infty$.
