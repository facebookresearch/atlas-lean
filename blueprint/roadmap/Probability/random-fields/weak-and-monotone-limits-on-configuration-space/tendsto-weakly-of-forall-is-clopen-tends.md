# Convergence on clopen events implies weak convergence

Let $E$ be a countable set and $(\mu_n)$ probability measures on $\{0, 1\}^E$. If for every clopen set $A$ the sequence $\mu_n(A)$ converges to some $L(A) \in [0, \infty)$, then $(\mu_n)$ converges [weakly](weak-converges-to.md) to some probability measure $\nu$: all subsequential limits, which exist by Prokhorov's theorem, agree on clopen sets and hence coincide.
