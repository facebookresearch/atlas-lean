# Subsequential weak limits are determined by clopen-event limits

Let $E$ be a countable set, $(\mu_n)$ probability measures on $\{0, 1\}^E$ and $L$ a function from sets to $[0, \infty)$ with $\mu_n(A) \to L(A)$ for every clopen $A$. If $\xi$ is a probability measure with $\mu_{\psi(n)} \to \xi$ weakly along a strictly increasing $\psi : \mathbb{N} \to \mathbb{N}$, then $\xi(A) = L(A)$ for every clopen $A$.
