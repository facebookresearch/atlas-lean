# Ergodic measure on configuration space

Let a group $G$ act on a set $E$. A measure $\mu$ on $\{0, 1\}^E$ is ergodic for the [shift action](shift.md) of $G$ if it is [translation invariant](is-translation-invariant.md) and every measurable set $s$ with $\{\omega : g \cdot \omega \in s\} = s$ for all $g \in G$ has $\mu(s) = 0$ or $\mu(s) = \mu(\{0, 1\}^E)$. Only exactly invariant sets are required to be trivial (not almost invariant ones).
