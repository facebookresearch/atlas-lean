# Number of open clusters with wired boundary conditions

Let $G$ be a graph on a finite vertex set $V$, $B \subseteq V$ a set of boundary vertices and $\omega$ a configuration on the unordered pairs of elements of $V$. The number of open clusters with wired boundary conditions is the number of connected components of the [wired open graph](wired-graph.md), in which all boundary vertices lie in a single cluster.
