# Bernoulli distribution as a two-point measure

For $p \in [0, 1]$, the [Bernoulli distribution](bernoulli-measure.md) $\mu_p$ on $\{0, 1\}$ is the two-point probability measure $p\, \delta_1 + (1 - p)\, \delta_0$, the Bernoulli measure with value $1$ taken with probability $p$ and value $0$ with probability $1 - p$.
