# Mass of a configuration on a finite index set is its product weight

Let $E$ be a finite set and $p \in [0, 1]$. For every $\omega \in \{0, 1\}^E$, $\mathbb{P}_p(\{\omega\}) = \prod_{e \in E} p^{\omega_e} (1 - p)^{1 - \omega_e}$, the [product weight](../../correlation-inequalities/harris-fkg-bk/russo-s-formula-and-pivotal-coordinates/config-weight.md) of $\omega$.
