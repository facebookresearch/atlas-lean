# Mass of a configuration under a finite Bernoulli product measure

Let $E$ be a finite set and $p \in [0, 1]$. For every configuration $\omega \in \{0, 1\}^E$, the [Bernoulli product measure](bernoulli-product-measure.md) $\mathbb{P}_p$ satisfies

$$\mathbb{P}_p(\{\omega\}) = \prod_{e \in E} \mu_p(\{\omega_e\}),$$

where $\mu_p$ is the [Bernoulli distribution](bernoulli-measure.md) with parameter $p$ (as values in $[0, \infty]$).
