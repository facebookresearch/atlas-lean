# Bernoulli product measure on configuration space

For a set $E$ and $p \in [0, 1]$, the Bernoulli product measure $\mathbb{P}_p$ on $\{0, 1\}^E$ (with the product σ-algebra) is the product of the [Bernoulli distributions](bernoulli-measure.md) $\mu_p$: the coordinates $\omega_e$, $e \in E$, are independent and each equals $1$ with probability $p$. It is a probability measure. Identifying a configuration with the set $\{e : \omega_e = 1\}$, it is the law of the random subset of $E$ containing each element independently with probability $p$.
