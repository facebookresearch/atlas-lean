# Sums of independent sub-exponential variables

Let $X_i$, $i \in s$, be independent measurable real random variables, each sub-exponential with
parameters $(\nu_i, \alpha)$ for a common $\alpha$. Then $\sum_{i \in s} X_i$ is sub-exponential
with parameters $\big(\sqrt{\sum_{i \in s} \nu_i^2},\, \alpha\big)$.

The source allows different $\alpha_i$ and takes $\alpha = \max_i \alpha_i$; since a variable
that is sub-exponential with parameter $\alpha_i$ is so with every larger parameter, that case
reduces to this one.
