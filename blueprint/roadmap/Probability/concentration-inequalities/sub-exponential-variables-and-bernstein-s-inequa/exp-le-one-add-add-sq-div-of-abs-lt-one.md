# Exponential series bound for Bernstein's inequality

For every real $y$ with $|y| < 1$,

$$e^y \le 1 + y + \frac{y^2}{2(1 - |y|)}.$$

It follows from $e^y = \sum_n y^n / n!$, the bound $n! \ge 2$ for $n \ge 2$ and the geometric
series.
