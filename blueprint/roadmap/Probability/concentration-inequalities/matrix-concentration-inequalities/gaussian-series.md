# Matrix Gaussian series

Let $n$ be a nonempty finite index set and $\mathbb{K} = \mathbb{R}$ or $\mathbb{C}$. For matrices
$A_0, \dots, A_{N-1} \in \mathbb{K}^{n \times n}$ and a coefficient vector $\omega \in \mathbb{R}^N$,
put $Y(\omega) = \sum_k \omega_k A_k$. When $\omega$ is a standard Gaussian vector this is the
matrix Gaussian series $Y = \sum_k \gamma_k A_k$, the basic model of a random matrix with Gaussian
coefficients and arbitrary correlations between its entries.
