# Trace moment generating function

Let $n$ be a nonempty finite index set and $\mathbb{K} = \mathbb{R}$ or $\mathbb{C}$. For a random
matrix $Y : \Omega \to \mathbb{K}^{n \times n}$, $\theta \in \mathbb{R}$ and $\omega \in \Omega$,
put $\operatorname{Re} \operatorname{tr} e^{\theta Y(\omega)}$, the real part of the trace of the
matrix exponential. Its expectation $\theta \mapsto \mathbb{E} \operatorname{tr} e^{\theta Y}$ is the
trace moment generating function, the matrix analogue of $\mathbb{E}\, e^{\theta X}$ in the scalar
Laplace transform (Chernoff) method.
