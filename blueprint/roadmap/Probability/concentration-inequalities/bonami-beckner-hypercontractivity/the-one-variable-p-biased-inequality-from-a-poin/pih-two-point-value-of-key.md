# p-biased two-point inequality from the pointwise bound

Let $0 < p < 1$ and $1 \le q \le 2$, and suppose that the [pointwise bound](pih-key.md) holds for
$p$ and for $1 - p$ (with the same $q$). Then for all real $u$ and $v$,

$$\big((1 - p) u + p v\big)^2 + 4(q - 1) p^2 (1 - p)^2 (u - v)^2 \le \big((1 - p)|u|^q + p|v|^q\big)^{2/q} .$$
