# $p$-biased noise operator on the Fourier side

For a finite set $\iota$, real $p, \rho$ and $f : \{0, 1\}^\iota \to \mathbb{R}$,

$$T_\rho f = \sum_{S \subseteq \iota} \rho^{|S|}\, \hat f(S)\, \varphi_S ,$$

with the [$p$-biased Fourier coefficients](ptn-coeff.md) $\hat f(S)$ and
[characters](ptn-pchar.md) $\varphi_S$.
