# $p$-biased variance as Fourier weight off the empty set

Let $\iota$ be a finite set and $0 < p < 1$. For every $f : \{0, 1\}^\iota \to \mathbb{R}$,
$\operatorname{Var}_p(f) = \mathbb{E}_p[f^2] - \mathbb{E}_p[f]^2 = \sum_{S \ne \emptyset} \hat f(S)^2$,
with the [$p$-biased Fourier coefficients](ptn-coeff.md).
