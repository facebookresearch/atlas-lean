# Law of a random element

Let $\nu$ be a probability measure on a measurable space $\Omega$ and let $f \colon \Omega \to \Omega'$ be a map
into a measurable space $\Omega'$. The push-forward $f_*\nu$ of $\nu$ along $f$ is a probability measure on
$\Omega'$. When $f$ is almost everywhere measurable, it is $\nu \circ f^{-1}$: it gives each measurable set
$A \subseteq \Omega'$ the mass $\nu(f^{-1}(A))$; for a random element $f$ this is its law, or distribution. For a
map that is not almost everywhere measurable, the push-forward is defined by a convention, an arbitrary point mass,
which is not a law of the map but is still a probability measure.
