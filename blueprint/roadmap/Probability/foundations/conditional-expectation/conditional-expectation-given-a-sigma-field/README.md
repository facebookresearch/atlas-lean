# Conditional expectation given a σ-field

Given an integrable random variable $X$ and a σ-field $\mathcal F$ of events, a conditional expectation
$E(X \mid \mathcal F)$ is an $\mathcal F$-measurable random variable $Y$ with $\int_A Y \, dP = \int_A X \, dP$ for every
$A \in \mathcal F$: a prediction of $X$ that uses only the information in $\mathcal F$ and has the right average over
each event of $\mathcal F$.

## Idea

If $\mathcal F$ is generated by a partition of $\Omega$ into countably many events $\Omega_1, \Omega_2, \dots$ of
positive probability, then $E(X \mid \mathcal F) = E(X 1_{\Omega_i}) / P(\Omega_i)$ on $\Omega_i$, the elementary
conditional mean. In general a conditional expectation exists and two versions agree almost surely: the other statements
of this card give a version, measurable for $\mathcal F$ and with the integrals of $X$ over the events of $\mathcal F$,
and its uniqueness; the section cited below proves existence with the Radon–Nikodym theorem. If $\mathcal F$ is trivial
then $E(X \mid \mathcal F) = EX$, and if $X$ is $\mathcal F$-measurable then $X$ itself is a version of
$E(X \mid \mathcal F)$, so every version equals $X$ almost surely.
