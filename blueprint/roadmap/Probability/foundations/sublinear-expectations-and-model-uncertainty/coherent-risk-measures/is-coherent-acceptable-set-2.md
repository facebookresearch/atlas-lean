# The acceptance set of a coherent risk measure

Let $\mathcal{H}$ be a linear space of real functions on a set $\Omega$. If $\rho$ is a [coherent
risk measure](is-coherent-risk-measure.md) on $\mathcal{H}$, then
$A_\rho = \{X \in \mathcal{H} : \rho(X) \le 0\}$ is a [coherent acceptable
set](is-coherent-acceptable-set.md).
