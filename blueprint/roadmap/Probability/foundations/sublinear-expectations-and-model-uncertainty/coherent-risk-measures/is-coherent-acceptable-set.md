# Coherent acceptable set

Let $\mathcal{H}$ be a linear space of real functions on a set $\Omega$. A set $A$ of real
functions on $\Omega$ is a coherent acceptable set if $A \subseteq \mathcal{H}$ and:
$Y \in A$ whenever $X \in A$, $Y \in \mathcal{H}$ and $X \le Y$; $0 \in A$; the constant $-1$ is
not in $A$; $cX \in A$ for $X \in A$ and $c \ge 0$; and $aX + (1 - a)Y \in A$ for $X, Y \in A$ and
$0 \le a \le 1$.
