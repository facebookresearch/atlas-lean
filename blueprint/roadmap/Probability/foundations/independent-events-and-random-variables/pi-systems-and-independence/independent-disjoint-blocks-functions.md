# Functions of disjoint blocks of independent random variables

For $1 \le i \le n$ and $1 \le j \le m(i)$ let $X_{i,j}$ be independent real random variables on a
probability space, and for each $i$ let $f_i \colon \mathbb R^{m(i)} \to \mathbb R$ be Borel measurable. Then the random
variables $f_1(X_{1,1}, \dots, X_{1,m(1)}), \dots, f_n(X_{n,1}, \dots, X_{n,m(n)})$ are independent.

## Proof

For each $i$ let $\mathcal A_i$ be the collection of events $\bigcap_{j=1}^{m(i)} \{X_{i,j} \in B_{i,j}\}$ with Borel
sets $B_{i,j} \subseteq \mathbb R$. Each $\mathcal A_i$ is a π-system, and the collections
$\mathcal A_1, \dots, \mathcal A_n$ are independent because all the $X_{i,j}$ are. Since independent π-systems generate
independent σ-fields, the σ-fields $\mathcal G_i = \sigma(\mathcal A_i)$ are independent. The Borel σ-field of
$\mathbb R^{m(i)}$ is its product σ-field, which is generated by products of half-lines, so the vector
$(X_{i,1}, \dots, X_{i,m(i)})$ is $\mathcal G_i$-measurable, and so is $f_i(X_{i,1}, \dots, X_{i,m(i)})$. Random
variables that are measurable for independent σ-fields are independent.
