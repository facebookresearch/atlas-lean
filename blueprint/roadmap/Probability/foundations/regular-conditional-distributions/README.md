# Regular conditional distributions

Let $\mu$ be a measure on $\alpha$, and let $X : \alpha \to \beta$ and $Y : \alpha \to \Omega$ be maps. A kernel $\kappa$ from $\beta$ to $\Omega$ is a regular conditional distribution of $Y$ given $X$ under $\mu$ if $X$ and $Y$ are measurable, $\kappa$ is a Markov kernel (each $\kappa(b)$ is a probability measure on $\Omega$, depending measurably on $b$), and for every measurable set $s \subseteq \Omega$ the real-valued function $a \mapsto \kappa(X(a))(s)$ is $\mu$-almost everywhere equal to the conditional expectation $\mu[\mathbf{1}_{Y^{-1}(s)} \mid \sigma(X)]$, where $\sigma(X)$ is the σ-algebra on $\alpha$ generated by $X$.

## Idea

Each conditional probability $P(Y \in s \mid X)$ is defined only up to a null set, and the null set depends on $s$. With uncountably many sets $s$ there is no reason for arbitrary choices to fit together into a measure. A regular conditional distribution makes a coherent choice: one probability measure $\kappa(x)$ for each value $x$ of $X$, so that conditional expectations can be computed by integration, $\mathbb{E}[\varphi(Y) \mid X] = \int \varphi \, d\kappa(X)$ for bounded measurable $\varphi$. Such a kernel exists when $\mu$ is finite and $\Omega$ is a nonempty standard Borel space; it is obtained by disintegrating the joint law of $(X, Y)$. For example, if $(X, Y)$ has a joint density $p(x, y)$ with respect to Lebesgue measure on $\mathbb{R}^2$, then a regular conditional distribution can be chosen so that $\kappa(x)$ has density $p(x, y) / \int p(x, y') \, dy'$ wherever the denominator is positive and finite; any other version agrees with this one for almost every $x$ under the law of $X$, and may differ on a null set of values.
