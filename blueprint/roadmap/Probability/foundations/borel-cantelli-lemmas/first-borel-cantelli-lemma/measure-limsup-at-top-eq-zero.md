# First Borel–Cantelli lemma for outer measures

Let $\mu$ be an outer measure on a set $\alpha$, or any function on the subsets of $\alpha$ of a class that
behaves like one (monotone, countably subadditive and zero on $\emptyset$), such as a measure applied to arbitrary
subsets. Let $(s_i)_{i \in \mathbb N}$ be subsets of $\alpha$ with $\sum_{i} \mu(s_i) < \infty$, the sum taken in
$[0, \infty]$. Then $\mu\big(\limsup_i s_i\big) = 0$, where $\limsup_i s_i = \bigcap_{n} \bigcup_{i \ge n} s_i$ is the set
of points that lie in infinitely many $s_i$. No measurability of the sets is assumed.
