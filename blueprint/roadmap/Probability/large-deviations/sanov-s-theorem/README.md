# Sanov's theorem

The empirical measures $L_n = \frac1n \sum_{i<n} \delta_{X_i}$ of an i.i.d. sample with law $\alpha$ on a Polish space satisfy a large deviation principle in the weak topology with rate function $\beta \mapsto \mathrm{KL}(\beta \,\|\, \alpha)$: the probability that the sample looks as if drawn from $\beta$ is about $e^{-n \mathrm{KL}(\beta \| \alpha)}$. Cramér's theorem for means follows by the contraction principle when the moment generating function is finite.
