# A bound for the log moment generating function in the coordinate directions

For a random vector $X : \Omega \to \mathbb{R}^d$ under a measure $\mu$, with [real log moment
generating function](log-mgfvec.md) $\Lambda$ and coordinate vectors $e_1, \dots, e_d$, put

$$C = \sum_{i=1}^{d} \big(|\Lambda(e_i)| + |\Lambda(-e_i)|\big).$$

It [dominates](log-mgfvec-single-le-coord-bound.md) $\Lambda(\pm e_i)$ for every $i$.
