# Extended log moment generating function of a random vector

For a measure $\mu$ on $\Omega$, $X : \Omega \to \mathbb{R}^d$ and $t \in \mathbb{R}^d$,

$$\bar\Lambda(t) = \log \int e^{\langle t, X(\omega)\rangle} \, d\mu(\omega) \in [-\infty, \infty],$$

with the integral taken in $[0, \infty]$ and $\log \infty = \infty$, $\log 0 = -\infty$. Directions
with an infinite exponential moment get the value $\infty$.
