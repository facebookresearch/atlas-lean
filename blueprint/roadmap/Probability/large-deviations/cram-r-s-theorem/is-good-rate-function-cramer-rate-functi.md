# Compact sub-level sets of the Cramér rate function

Let $\mu$ be a probability measure and let $X_0 : \Omega \to \mathbb{R}^d$ satisfy
$\mathbb{E}[e^{\langle t, X_0\rangle}] < \infty$ for every $t \in \mathbb{R}^d$. Then every
sub-level set $\{x : I(x) \le a\}$, $a \in \mathbb{R}$, of the [Cramér rate
function](cramer-rate-function.md) $I$ is contained in a coordinate box, and $I$ is a good rate
function: lower semicontinuous with compact sub-level sets $\{I \le a\}$ for every real $a$.
