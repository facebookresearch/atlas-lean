# Convexity of the Cramér rate function

Let $\mu$ be a measure on $\Omega$ and $X : \Omega \to \mathbb{R}^d$. Then the [Cramér rate
function](cramer-rate-function.md) $I$ is convex: for $x, y \in \mathbb{R}^d$ and $a, b \ge 0$
with $a + b = 1$, $I(ax + by) \le a\, I(x) + b\, I(y)$ in $[0, \infty]$.
