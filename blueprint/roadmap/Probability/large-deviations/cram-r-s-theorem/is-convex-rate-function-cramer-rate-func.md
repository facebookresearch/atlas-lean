# Cramér rate function is a convex rate function

Let $\mu$ be a measure on $\Omega$ and $X : \Omega \to \mathbb{R}^d$. Then the [Cramér rate
function](cramer-rate-function.md) $I$ is a convex rate function: it is lower semicontinuous and
satisfies $I(ax + by) \le a\, I(x) + b\, I(y)$ for all $x, y$ and $a, b \ge 0$ with $a + b = 1$. No
finiteness of the moment generating function is needed.
