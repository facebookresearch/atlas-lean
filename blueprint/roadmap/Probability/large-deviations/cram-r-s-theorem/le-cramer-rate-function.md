# Extended Fenchel–Young inequality for the Cramér rate function

Let $\mu$ be a measure on $\Omega$, $X : \Omega \to \mathbb{R}^d$ and $x, t \in \mathbb{R}^d$. Then
$\big(\langle t, x\rangle - \bar\Lambda(t)\big)^+ \le I(x)$, where $\bar\Lambda$ is the [extended
log moment generating function](extended-log-mgfvec.md), $(\cdot)^+$ sends negative values of
$[-\infty, \infty]$ to $0$, and $I$ is the [Cramér rate function](cramer-rate-function.md).
