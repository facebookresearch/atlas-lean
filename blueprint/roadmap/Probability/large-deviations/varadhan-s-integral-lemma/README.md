# Varadhan's integral lemma

The Laplace method for large deviation principles: if $\mu_n$ satisfies an LDP with rate function $I$ and $F$ is bounded and continuous, then $\frac1n \log \int e^{nF}\,d\mu_n \to \sup_x (F(x) - I(x))$. Logarithms of exponential moments are Legendre-dual to rate functions; this is the bridge from large deviations to free energies and variational formulas.
