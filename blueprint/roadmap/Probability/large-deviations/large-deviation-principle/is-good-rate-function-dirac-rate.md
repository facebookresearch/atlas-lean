# The Dirac rate function is good

On a $T_1$ space $X$, the rate function of a Dirac mass at $x_0$,

$$I(x) = \begin{cases} 0 & x = x_0, \\ \infty & x \ne x_0, \end{cases}$$

is a good rate function: it is lower semicontinuous, and each sub-level set $\{I \le a\}$ with
$a$ finite is the compact singleton $\{x_0\}$.
