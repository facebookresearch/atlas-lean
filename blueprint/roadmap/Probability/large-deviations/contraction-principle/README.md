# Contraction principle

Large deviation principles transfer along continuous maps: if $\mu_n$ satisfies an LDP with a good rate function $I$ and $F$ is continuous into a Hausdorff space, the image measures $F_*\mu_n$ satisfy an LDP with the good rate function $J(y) = \inf\{I(x) : F(x) = y\}$. Goodness of $I$ is what makes $J$ lower semicontinuous: wherever $J(y) < \infty$ the infimum is attained, and the sub-level sets of $J$ are images of compact sets.
