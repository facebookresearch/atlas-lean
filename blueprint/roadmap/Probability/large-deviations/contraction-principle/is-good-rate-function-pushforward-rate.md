# The push-forward of a good rate function is a good rate function

Let $X$ and $Y$ be topological spaces with $Y$ Hausdorff, let $F : X \to Y$ be continuous and let
$I$ be a good rate function on $X$. Then the [push-forward rate function](pushforward-rate.md)
$J(y) = \inf\{I(x) : F(x) = y\}$ is a good rate function on $Y$: it is lower semicontinuous and
its sub-level sets $\{J \le a\}$, $a \in \mathbb{R}$, are compact.

## Sources

- S. R. S. Varadhan, *Large Deviations*, lecture notes, New York University, Spring 2010,
  Section 2, Theorem 2.7.
