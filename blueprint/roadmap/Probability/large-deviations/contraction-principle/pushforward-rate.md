# Push-forward rate function

For a map $F : X \to Y$ between sets and $I : X \to [0, \infty]$, the push-forward rate function
is

$$J(y) = \inf\{I(x) : F(x) = y\} \in [0, \infty],$$

which is $\infty$ off the range of $F$. It is the rate function of the contraction principle.
