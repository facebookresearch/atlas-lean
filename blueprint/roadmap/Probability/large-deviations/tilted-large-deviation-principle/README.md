# Tilted large deviation principle

Reweighting by an exponential of $n$ times a bounded continuous function preserves large deviation principles: if $\mu_n$ satisfies an LDP with rate function $I$, the Gibbs measures $Q_n \propto e^{nF}\mu_n$ satisfy an LDP with rate $J = \sup(F - I) - (F - I)$, which vanishes exactly at the maximisers of $F - I$. This is the large deviation form of the Gibbs conditioning and exponential tilting used in statistical mechanics.
