# Cauchy-Schwarz for finite covariance

On a finite set with nonnegative weights $p$, for any real functions $X$, $Y$, $\mathrm{Cov}_p(X, Y)^2 \le \mathrm{Var}_p(X)\, \mathrm{Var}_p(Y)$, where $\mathrm{Cov}_p(X, Y) = \mathbb{E}_p[(X - \mathbb{E}_p X)(Y - \mathbb{E}_p Y)]$ and $\mathrm{Var}_p(X) = \mathrm{Cov}_p(X, X)$.
