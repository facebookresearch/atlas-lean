# Determinant of the Gram matrix of the simple linear model

For data $x : \iota \to \mathbb{R}$ on a finite index set with $n$ elements, the design matrix $X$ of the simple linear model, with rows $(1, x_i)$, satisfies $\det(X^{\mathsf T} X) = n\, S_{xx}$, where $S_{xx} = \sum_i (x_i - \bar x)^2$.
