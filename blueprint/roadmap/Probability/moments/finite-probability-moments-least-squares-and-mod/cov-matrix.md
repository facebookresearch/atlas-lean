# Covariance matrix of a finite random vector

A weight on a finite type $\alpha$ is a function $p : \alpha \to \mathbb{R}$; it is a finite
distribution when $p \ge 0$ and $\sum_x p(x) = 1$. For a random vector
$X : \alpha \to (n \to \mathbb{R})$, the covariance matrix under $p$ has entry $(i, j)$ equal to the
covariance of the coordinates $X_i$ and $X_j$ under $p$.
