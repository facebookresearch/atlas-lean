# Expectation is linear

For a finite set $\alpha$, any weight $p$, functions $X, Y : \alpha \to \mathbb{R}$ and reals $a, b$, the weighted expectation $\mathbb{E}_p[Z] = \sum_x p(x) Z(x)$ is linear: $\mathbb{E}_p[aX + bY] = a\,\mathbb{E}_p[X] + b\,\mathbb{E}_p[Y]$. The weight need not be nonnegative or sum to one.
