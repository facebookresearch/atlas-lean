# Expectation of the least-squares slope

For a fixed design $x : \iota \to \mathbb{R}$ on a finite index set and any measure $\mu$ with responses $Y_i$ integrable with respect to $\mu$, $\int \hat b(x, Y)\, d\mu = \hat b\bigl(x, \int Y\, d\mu\bigr)$, since the slope is linear in the responses; for a probability measure this reads $\mathbb{E}[\hat b(x, Y)] = \hat b(x, \mathbb{E} Y)$.
