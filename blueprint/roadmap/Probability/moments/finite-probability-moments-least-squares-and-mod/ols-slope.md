# Least-squares slope

For paired data $x, y$ on a finite index set, the least-squares slope is $S_{xy} / S_{xx}$, with
$S_{xy} = \sum_i (x_i - \bar x)(y_i - \bar y)$ and $S_{xx}$ the same sum with $y = x$. Division by
zero gives $0$, so the slope is $0$ when $S_{xx} = 0$, where it is not identified.
