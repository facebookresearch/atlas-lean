# Divide-by-(n − 1) sample variance

For data $x : \iota \to \mathbb{R}$ on a finite index set with $n$ elements, the divide-by-$(n - 1)$
sample variance is $(\sum_i (x_i - \bar x)^2) / (n - 1)$, meant for $n \ge 2$, where it is unbiased
for i.i.d. samples. For $n \le 1$ the value is $0$: the sum is empty for $n = 0$, and $n = 1$
divides by $0$.
