# Covariance is linear in its second argument

For a finite set $\alpha$, any weight $p$, functions $X, Y_1, Y_2 : \alpha \to \mathbb{R}$ and reals $a, b$, the weighted covariance satisfies $\operatorname{Cov}_p(X, a Y_1 + b Y_2) = a \operatorname{Cov}_p(X, Y_1) + b \operatorname{Cov}_p(X, Y_2)$, where $\operatorname{Cov}_p(X, Y) = \mathbb{E}_p[(X - \mathbb{E}_p X)(Y - \mathbb{E}_p Y)]$ and $\mathbb{E}_p[Z] = \sum_x p(x) Z(x)$. The weight need not be nonnegative or sum to one.
