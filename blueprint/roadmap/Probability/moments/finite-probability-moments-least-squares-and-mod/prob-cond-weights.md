# Probability of an event under conditioned weights

For a weight $p$ on a set $\Omega$, an event $A$ with $P(A) = \sum_{\omega \in A} p(\omega) > 0$ and an event $F$, the weights conditioned on $A$ give $F$ the weight $P(A \cap F)/P(A)$. Only $P(A) > 0$ is used, so the identity also holds for signed weights; for nonnegative weights it is the conditional probability of $F$ given $A$.
