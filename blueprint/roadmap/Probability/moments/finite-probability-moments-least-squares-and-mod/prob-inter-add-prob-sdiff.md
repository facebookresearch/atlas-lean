# Additivity of event weights over a two-set partition

For a weight $p$ on a set $\alpha$ and finite sets $s, t$, $P(s \cap t) + P(s \setminus t) = P(s)$, where $P(A) = \sum_{a \in A} p(a)$ is the event weight. The identity holds for signed weights; for a probability law it is total probability for a two-set partition.
