# Credible interval under a finite posterior

For a finite parameter set $\Theta$, a real parameter $\theta : \Theta \to \mathbb{R}$, a posterior weight $\pi$ and a level $c$, the interval $[l, h]$ is a level-$c$ credible interval when $\pi$ is a finite distribution (nonnegative, summing to $1$) and $\pi(\{t : \theta(t) \in [l, h]\}) = c$. This is a statement about the posterior only and asserts no frequentist coverage.
