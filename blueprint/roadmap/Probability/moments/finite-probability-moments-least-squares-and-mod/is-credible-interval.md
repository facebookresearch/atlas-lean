# Credible interval under a finite posterior

For a finite parameter type $\Theta$, a real parameter $\theta : \Theta \to \mathbb{R}$, a posterior
weight `post` and a level $c$, the interval $[lo, hi]$ is a level-$c$ credible interval when `post`
is a finite distribution (nonnegative, summing to $1$) and the posterior probability that
$\theta \in [lo, hi]$ equals $c$. This is a statement about the posterior only; it asserts no
frequentist coverage.
