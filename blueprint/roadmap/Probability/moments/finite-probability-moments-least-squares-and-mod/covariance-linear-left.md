# Covariance is linear in its first argument

For a finite set $\alpha$, any weight $p$, functions $X_1, X_2, Y : \alpha \to \mathbb{R}$ and reals $a, b$, the weighted covariance satisfies $\operatorname{Cov}_p(a X_1 + b X_2, Y) = a \operatorname{Cov}_p(X_1, Y) + b \operatorname{Cov}_p(X_2, Y)$, where $\operatorname{Cov}_p(X, Y) = \mathbb{E}_p[(X - \mathbb{E}_p X)(Y - \mathbb{E}_p Y)]$ and $\mathbb{E}_p[Z] = \sum_x p(x) Z(x)$. The weight need not be nonnegative or sum to one.
