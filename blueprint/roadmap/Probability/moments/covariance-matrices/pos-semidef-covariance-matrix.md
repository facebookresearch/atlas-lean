# The covariance matrix is positive semidefinite

Let $X_i$, $i$ in a finite index set, be square-integrable real random variables on a finite measure space. Then the matrix $(\operatorname{Cov}(X_i, X_j))_{i,j}$ is symmetric and positive semidefinite, since $x^\top Cx = \operatorname{Var}(\sum_i x_iX_i) \ge 0$.
