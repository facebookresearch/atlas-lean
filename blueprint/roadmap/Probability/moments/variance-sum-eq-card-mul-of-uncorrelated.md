# Variance of a sum of uncorrelated variables with equal variance

Let $R_i$, $i$ in a finite index set of size $n$, be square-integrable real random variables on a finite measure space with $\operatorname{Var}(R_i) = \sigma^2$ for all $i$ and $\operatorname{Cov}(R_i, R_j) = 0$ for $i \ne j$. Then $\operatorname{Var}(\sum_iR_i) = n\sigma^2$. Independence is not assumed.
