# The largest continuous increment tends to `0`

Assume `∀ n i, IdentDistrib (Z n i) (Z 0 0) μ μ` and `Integrable (fun ω => Z 0 0 ω ^ 4) μ`.

For increments `s n i * Z n i` with every
`Z n i` distributed as `Z 0 0` with finite fourth moment and `∑_{i ≤ L n} (s n i)⁴ → 0`, the
largest of `|s n i * Z n i|`, `i ≤ L n`, tends to `0` in probability.
