# Pathwise perturbation bound

For increments $c_0, c_1, \dots$ with $|c_i| \le M$ for $i \le N$ and any increments $J_0, J_1, \dots$, the realized bipower variation over the first $N + 1$ increments satisfies $\bigl|\mathrm{BV}_N(c + J) - \mathrm{BV}_N(c)\bigr| \le 2M \sum_{i \le N} |J_i| + 3 \sum_{i<N} |J_i|\, |J_{i+1}|$.
