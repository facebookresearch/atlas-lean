# Time shifts of a stationary Ornstein–Uhlenbeck process

If $X$ is a [stationary Ornstein–Uhlenbeck process](is-stationary-ornstein-uhlenbeck.md) with rate $\theta$ and noise
amplitude $\sigma$, then for every $h \ge 0$ the shifted process $(X_{t + h})_{t \ge 0}$ is a stationary
Ornstein–Uhlenbeck process with the same parameters.
