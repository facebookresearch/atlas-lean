# Doob's clock for the Ornstein–Uhlenbeck process from zero

For $\theta \in \mathbb{R}$ and $t \ge 0$, Doob's clock is

$$\tau(t) = \frac{e^{2\theta t} - 1}{2\theta} \ge 0,$$

with the convention that a quotient with zero denominator is $0$ (so $\tau = 0$ for $\theta = 0$); the value is
nonnegative for every real $\theta$.
