# Linear Brownian motion hits every level

Let $B$ be a real Brownian motion (finite-dimensional laws of Brownian motion and almost surely continuous
paths). Then almost surely, for every $a \in \mathbb{R}$, there is a time $t$ with $B_t = a$: the hitting time
$T_a = \inf\{t \ge 0 : B_t = a\}$ is finite for every $a$.

## Informally uses

- [Brownian motion is unbounded above and below at infinity](ae-unbounded-at-top.md): the path
  takes values above and below every level, and the intermediate value theorem on a continuous
  path gives a time where it equals the level.
