# Tightness transfer from realized to predictable variation

On a probability space, let $(\xi_{n,i})$ be a triangular array and, for each row $n$, $(\mathcal F_{n,i})_i$ a filtration, with each $\xi_{n,i}$ strongly $\mathcal F_{n,i+1}$-measurable and square integrable, and with the array satisfying the Lindeberg condition for triangular arrays. Let $k_n \le n$. If the realized variations $\sum_{j < k_n} \xi_{n,j}^2$ are bounded in probability, so are the predictable variations $\sum_{j < k_n} \mathbb{E}[\xi_{n,j}^2 \mid \mathcal F_{n,j}]$.
