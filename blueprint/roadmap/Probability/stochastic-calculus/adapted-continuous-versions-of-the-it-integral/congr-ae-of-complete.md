# Adaptedness of modifications under a complete filtration

Let $I$ be a preordered index type, $(\Omega,\mathcal A,P)$ a measure space, $E$ a measurable space, and $(\mathcal F_t)_{t\in I}$ a filtration of sub-sigma-algebras of $\mathcal A$. Suppose every $P$-null set belongs to every $\mathcal F_t$.

If $X:I\times\Omega\to E$ is adapted and, for every fixed $t$, $X_t=Y_t$ almost surely, then $Y$ is adapted to the same filtration.

Neither a probability measure nor continuity of the processes is required. Completeness of the ambient measure alone is insufficient: each filtration sigma algebra must contain the null sets. The proof transfers measurability of each inverse image using its almost-sure equality with the corresponding inverse image under $X_t$. No replacement filtration is used.
