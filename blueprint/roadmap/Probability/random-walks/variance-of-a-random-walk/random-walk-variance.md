# Variance of a random walk grows linearly in the horizon

On a measure space, let $\varepsilon_0, \varepsilon_1, \dots$ be square-integrable, pairwise independent random variables with a common variance. Then for every horizon $h$, the random walk $S_h = \sum_{i<h} \varepsilon_i$ has $\operatorname{Var}(S_h) = h \operatorname{Var}(\varepsilon_0)$. In particular, the formula holds for mutually independent innovations, which are pairwise independent; and for $h = 4$ and common variance $3$ it gives $\operatorname{Var}(\varepsilon_0 + \varepsilon_1 + \varepsilon_2 + \varepsilon_3) = 12$.
