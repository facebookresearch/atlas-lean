# The first descending ladder epoch as a hitting time

For every path of real scores, the time equal to the
[first descending ladder epoch](desc-ladder-epoch.md) when the walk
[drops below `0`](has-desc-ladder.md), and to `∞` otherwise, is the first time `k ≥ 1` at which the
walk `S_k = x 0 + ⋯ + x (k - 1)` enters `(-∞, 0)` (the hitting time after time `1`, with value `∞`
when there is none).
