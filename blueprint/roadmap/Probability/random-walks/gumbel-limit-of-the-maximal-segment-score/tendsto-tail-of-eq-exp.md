# An exact exponential tail gives the renewal tail limit

For a function `F : ℝ → ℝ` and reals `θ` and `p` with `1 - F(t) = p e^{-θ t}` for every `t ≥ 0`,
`(1 - F(t)) e^{θ t} → p` as `t → ∞`. Applied to the excursion-height distribution function, this
is the renewal tail of a [nonlattice renewal input](nonlattice-renewal-input.md) with constant
`C = p`, so `K = p / A`.
