# On a ladder-good path the count reaches i iff epoch i is at most n

For a [ladder-good](is-ladder-good.md) path of real scores and natural numbers `i` and `n`,
`i ≤ Nₙ` if and only if `T_i ≤ n`, where `Nₙ` is the [ladder count](ladder-count.md) and `T_i` the
`i`-th [ladder epoch](ladder-epoch.md).
