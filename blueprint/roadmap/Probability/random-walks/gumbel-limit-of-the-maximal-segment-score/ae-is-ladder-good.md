# Almost every path of Cramér scores is ladder-good

For scores `X 0, X 1, …` on `(Ω, P)` satisfying the [Cramér conditions](cramer-scores.md), for
`P`-almost every `ω` the path `(X 0 ω, X 1 ω, …)` is [ladder-good](is-ladder-good.md): every
restart of the walk eventually drops below its starting value.
