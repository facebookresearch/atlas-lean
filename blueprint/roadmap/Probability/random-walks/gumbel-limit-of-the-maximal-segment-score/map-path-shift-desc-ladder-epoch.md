# The path restarted at the ladder epoch has the law of the path

For scores `X 0, X 1, …` on `(Ω, P)` satisfying the [Cramér conditions](cramer-scores.md), the path
[seen from](path-shift.md) its [first descending ladder epoch](desc-ladder-epoch.md) `τ₋`,
`(X τ₋, X (τ₋ + 1), …)`, has the same law as the original path `(X 0, X 1, …)`.
