# The moment generating function at half the Cramér root is below one

For a probability measure `P` and a real random variable `Z` with `E Z < 0` and a real `θ > 0` with
`E e^{θ Z} = 1`, `E e^{θ Z / 2} < 1`. Indeed `E e^{θ Z / 2} = 1 - E (1 - e^{θ Z / 2})² / 2`, and
`E (1 - e^{θ Z / 2})² = 0` would force `Z = 0` almost surely, contradicting `E Z < 0`.
