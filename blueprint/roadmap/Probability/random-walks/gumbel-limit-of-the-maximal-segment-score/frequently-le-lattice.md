# Lattice case: the upper Gumbel bound is approached infinitely often

Let `P` be a probability measure, a [ladder input](ladder-input.md) under `P` for statistics `M n`,
with excursion heights on the lattice `hℤ` almost surely, distribution function `F` and mean
excursion length `A > 0`, and reals `θ > 0`, `h > 0` and `C` with `(1 - F(k h)) e^{θ (k + 1) h} → C`
as `k → ∞`. Then for every real `x` and every `ε > 0`, infinitely often
`exp(-K e^{-θ (x + h)}) - ε ≤ P(M n ≤ log n / θ + x)`, where `K = C / A`.
