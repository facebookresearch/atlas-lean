# Cramér root of a difference of exponential variables

Let `E₁` and `E₂` be measurable real random variables on `(Ω, P)`, independent under `P`, with laws
`Exp(a)` and `Exp(b)` (so `P` is a probability measure), where `0 < b < a`. Then `θ = a - b` solves
the Cramér equation for `X = E₁ - E₂`: `E e^{θ X} = a / (a - θ) · b / (b + θ) = (a / b)(b / a) = 1`.
Here `E X = 1 / a - 1 / b < 0`.
