# The excursion height is attained by a walk increment inside it

For every path of real scores and every natural number `k`, some `b` with `T_k ≤ b ≤ T_{k+1}`,
where `T_k` is the `k`-th [ladder epoch](ladder-epoch.md), has `S_b - S_{T_k} = Y_k`, the
[height](excursion-height.md) of the `k`-th excursion.
