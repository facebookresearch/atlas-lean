# Renewal law of large numbers for the ladder count

For scores `X 0, X 1, …` on `(Ω, P)` satisfying the [Cramér conditions](cramer-scores.md), for
`P`-almost every `ω` the [ladder count](ladder-count.md) of the path `(X 0 ω, X 1 ω, …)` satisfies
`Nₙ / n → 1 / A`, where `A = E τ₋` is the mean [first descending ladder epoch](desc-ladder-epoch.md).
