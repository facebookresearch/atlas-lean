# First strict descending ladder epoch of a score walk

For a path of real scores `x` with walk `S_k = x 0 + ⋯ + x (k - 1)`, the first strict descending
ladder epoch is `τ₋ = min {k ≥ 1 : S_k < 0}`. When the walk
[never drops below `0`](has-desc-ladder.md) the set is empty and `τ₋ = 0` by convention, a value
outside the intended range `τ₋ ≥ 1`.
