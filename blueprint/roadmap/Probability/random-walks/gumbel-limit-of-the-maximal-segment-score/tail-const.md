# Excursion-height renewal constant, nonlattice case

For [nonlattice ladder renewal data](ladder-renewal-data.md) with root `θ`, descending-ladder value
`D` and [Cramér–Lundberg constant](all-time-const.md) `C_∞`, the excursion-height renewal constant
is `C = C_∞ (1 - E e^{θ D})` (Iglehart 1972), where `E e^{θ D} = ∫ e^{θ D} dP` is `0` by convention
when `e^{θ D}` is not integrable. For a probability measure `P` and `θ ≥ 0` it lies in `(0, 1]`,
since `D ≤ 0` almost surely; the intended case is `θ > 0`.
