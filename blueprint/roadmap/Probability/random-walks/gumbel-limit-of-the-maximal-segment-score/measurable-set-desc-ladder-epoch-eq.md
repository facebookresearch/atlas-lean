# The event of first descent at time t is determined by t scores

For every natural number `t`, the set of paths whose walk [drops below `0`](has-desc-ladder.md)
with [first descending ladder epoch](desc-ladder-epoch.md) equal to `t` belongs to the
[σ-algebra of the first `t` scores](past-measurable-space.md) (for `t = 0` it is empty).
