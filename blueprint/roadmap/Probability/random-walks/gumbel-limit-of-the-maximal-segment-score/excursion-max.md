# Maximal height of the first descending ladder excursion

For a path of real scores with walk `S_j = x 0 + ⋯ + x (j - 1)` and
[first descending ladder epoch](desc-ladder-epoch.md) `τ₋`, the maximal height of the first
excursion is `max_{0 ≤ j ≤ τ₋} S_j`. It is at least `S₀ = 0`, and it is `0` when the walk never
drops below `0` (where `τ₋ = 0` by convention).
