# Characterization of the first descending ladder epoch

For a path of real scores `x` and a natural number `t`, the walk
[drops below `0`](has-desc-ladder.md) and its [first descending ladder epoch](desc-ladder-epoch.md)
equals `t` if and only if `t ≥ 1`, `S_t < 0` and `S_j ≥ 0` for every `0 < j < t`. So this event
depends only on the first `t` scores.
