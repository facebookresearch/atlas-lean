# Later terms are measurable for the σ-algebra from a given index

Let $X_0, X_1, \dots$ be
real-valued functions on a set $\Omega$, and for $n \in \mathbb{N}$ let
$\sigma(X_n, X_{n+1}, \dots)$ be the smallest σ-algebra on $\Omega$ for which every $X_i$ with
$i \ge n$ is Borel measurable. If $n \le i$, then $X_i$ is measurable with respect to
$\sigma(X_n, X_{n+1}, \dots)$.
