# A limit superior +∞ of a random walk is measurable from every index

Let
$X_0, X_1, \dots$ be real-valued functions on a set $\Omega$, let $S_m = \sum_{i < m} X_i$ be their
partial sums, and for $n \in \mathbb{N}$ let $\sigma(X_n, X_{n+1}, \dots)$ be the smallest
σ-algebra on $\Omega$ for which every $X_i$ with $i \ge n$ is Borel measurable. For every $n$, the
set of $\omega \in \Omega$ with $\limsup_{m \to \infty} S_m(\omega) = +\infty$, the limit superior
taken in the extended reals, is measurable with respect to $\sigma(X_n, X_{n+1}, \dots)$.
