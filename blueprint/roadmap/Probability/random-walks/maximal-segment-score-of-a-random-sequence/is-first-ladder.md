# Segment ending at the first strict ascending ladder epoch

A list of real scores `u = (x₀, …, x_{k-1})`, with partial sums `S_j = x₀ + ⋯ + x_{j-1}`, ends at
the first strict ascending ladder epoch of its walk when `S_k > 0` while `S_j ≤ 0` for every
`j < k` (in particular `u` is nonempty). The ladder epoch is then `τ₊ = k` and the ladder height
is `H = S_k`.
