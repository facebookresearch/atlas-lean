# Agreement with Kadane's maximum subarray sum

For a list of real scores and a real number `m` that is its
[maximum subarray sum](../../../ComputerScience/dynamic-programming/maximum-subarray-problem/is-max-subarray-sum.md)
over nonempty contiguous runs (so the list is nonempty), the
[maximal segment score](max-seg-score.md), which also allows the empty run, is `max(0, m)`.
