# A sum of lattice values is a lattice value

For every real number `h` and every list of real numbers each of the form `k h` with `k` an
integer, the sum of the list is also of the form `k h` with `k` an integer. In lattice form: if
every entry of the list lies in the lattice `hℤ = {k h : k ∈ ℤ}`, so does its sum (for `h = 0` the
lattice is `{0}`).
