# The maximal segment score of measurable scores is measurable

For real scores `X 0, X 1, …` on a measurable space `Ω`, each a measurable function of `ω`, and
every natural number `n`, the
[maximal segment score](../gumbel-limit-of-the-maximal-segment-score/max-segment-score-rv.md)
`Mₙ(ω)` of `X 0 ω, …, X (n - 1) ω` is a measurable function of `ω`.
