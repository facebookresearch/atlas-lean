# Graph-coded free spanning-forest cylinder law

Code simple graphs on the naturals by symmetric Boolean adjacency matrices with false diagonal and possible edges by strictly increasing pairs. For a connected locally finite graph use an increasing exhaustion by finite nonempty connected subgraphs, not necessarily induced, containing every edge eventually. A finite cylinder asks that a finite set of possible edges be included and another finite set excluded. The free forest model uses the corresponding limits of uniform finite spanning-tree probabilities, retaining both types of constraint. A factor rule is jointly Borel in graph, labels and edge, takes IID uniform vertex labels, and is equivariant for simultaneous relabelling of those three inputs. This definition of the target law does not assume an arbitrary exhaustion gives the claimed limits before the relevant relation is proved.
