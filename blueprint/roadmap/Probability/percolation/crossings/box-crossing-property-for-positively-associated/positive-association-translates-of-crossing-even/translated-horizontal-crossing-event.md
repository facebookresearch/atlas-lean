# Left–right crossing event of a translated rectangle

For $v \in \mathbb{Z}^2$ and $a, b \in \mathbb{Z}$, the event that the rectangle $v + [0, a] \times [0, b]$ has an open left–right crossing: the set of configurations $\omega$ whose [translate](translate-config.md) $\omega_v$ lies in the [left–right crossing event](../../rectangle-crossings-on-the-square-lattice/horizontal-crossing-event.md) of $[0, a] \times [0, b]$.
