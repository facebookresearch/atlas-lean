# Positive association for probability measures is the Harris–FKG inequality

Let $E$ be a set and $\mu$ a probability measure on $\{0, 1\}^E$. Then $\mu$ is [positively associated](positively-associated.md) if and only if

$$\mu(A)\, \mu(B) \le \mu(A \cap B)$$

for all measurable increasing events $A, B$.
