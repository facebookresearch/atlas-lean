# Separating set for a lattice rectangle

Let $P \subseteq \mathbb{Z}^2$ and $\alpha, \beta, c, d \in \mathbb{Z}$, and let $R = ([\alpha, \beta] \times [c, d]) \cap \mathbb{Z}^2$. The set $P$ separates the sides of $R$ if there is a set $S \subseteq \mathbb{Z}^2$ that contains every site of $R$ on the left side $\{x_1 = \alpha\}$, contains no site of $R$ on the right side $\{x_1 = \beta\}$, and is such that every lattice edge $\{u, v\}$ with $u, v \in R$ and exactly one endpoint in $S$ has an endpoint in $P$.
