# Dual bottom–top crossing of a rectangle

With the dual lattice $(\mathbb{Z}^2)^\ast = (\tfrac12, \tfrac12) + \mathbb{Z}^2$ and the dual configuration $\omega^\ast(e^\ast) = 1 - \omega(e)$ of a bond configuration $\omega$ on $\mathbb{Z}^2$ (see the [dual left–right crossing](dual-horizontal-crossing.md)), the configuration $\omega$ has a dual bottom–top crossing of $R = [a, b] \times [c, d]$, $a, b, c, d \in \mathbb{Z}$, if $\omega^\ast$ has an open path of dual edges inside the dual rectangle $R^\ast = (\tfrac12, \tfrac12) + R$ from its bottom side $\{x_2 = c + \tfrac12\}$ to its top side $\{x_2 = d + \tfrac12\}$.
