# Uniform two-sided box-crossing property

Let $\Xi$ be a set and $(\mu_{\xi, n})_{\xi \in \Xi, n \in \mathbb{N}}$ a family of real-valued functions on sets of bond configurations of $\mathbb{Z}^2$. The family has the uniform two-sided box-crossing property if for every $\alpha > 0$ there is $c > 0$ with

$$c \le \mu_{\xi, n}\big(H_\alpha(n)\big) \le 1 - c \quad \text{for all } \xi \in \Xi \text{ and } n \in \mathbb{N},$$

where $H_\alpha(n)$ is the [left–right crossing event](box-crossing-event.md) of $[0, \lfloor \alpha n \rfloor] \times [0, n]$.
