# Measurability of connection inside a set

For $d \in \mathbb{N}$, $S \subseteq \mathbb{Z}^d$ and $x, y \in S$, the event that $x$ and $y$ are joined by an open path [inside](../../../phase-transition/percolation-probability-and-critical-point/connected-within.md) $S$ is measurable for the product σ-algebra on bond configurations of $\mathbb{Z}^d$.
