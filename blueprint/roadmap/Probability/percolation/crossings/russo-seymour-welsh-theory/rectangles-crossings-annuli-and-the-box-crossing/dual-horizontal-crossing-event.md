# Dual left–right crossing event

For $a, b, c, d \in \mathbb{Z}$, the event that the rectangle $R = [a, b] \times [c, d]$ has a [dual left–right crossing](dual-horizontal-crossing.md): an open path of the dual configuration inside $(\tfrac12, \tfrac12) + R$ from its left side to its right side.
