# Dual bottom–top crossing event

For $a, b, c, d \in \mathbb{Z}$, this is the set of primal bond configurations $\omega$ for which $R = [a, b] \times [c, d]$ has a [dual bottom–top crossing](dual-vertical-crossing.md): a path inside $(\tfrac12, \tfrac12) + R$ from its bottom side to its top side, using only dual edges that cross primal edges closed in $\omega$. The path may consist of a single vertex if the two sides coincide; an empty rectangle has no crossing.
