# Dual bottom–top crossing event

For $a, b, c, d \in \mathbb{Z}$, the event that the rectangle $R = [a, b] \times [c, d]$ has a [dual bottom–top crossing](dual-vertical-crossing.md): an open path of the dual configuration inside $(\tfrac12, \tfrac12) + R$ from its bottom side to its top side.
