# Edges of a box in the square lattice

For $a, b \in \mathbb{N}$, the edge set of the box $[0, a] \times [0, b]$ of the square lattice $\mathbb{Z}^2$ is the disjoint union of

- the horizontal edges $(x, y) \text{–} (x + 1, y)$ with $0 \le x < a$ and $0 \le y \le b$, indexed by $\{0, \dots, a-1\} \times \{0, \dots, b\}$, and
- the vertical edges $(x, y) \text{–} (x, y + 1)$ with $0 \le x \le a$ and $0 \le y < b$, indexed by $\{0, \dots, a\} \times \{0, \dots, b-1\}$.

So the box has $a(b+1) + (a+1)b$ edges.
