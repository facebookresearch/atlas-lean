# Anchor sites for dual circuits

For $\ell \in \mathbb{N}$, the set of $2\ell$ anchor sites $\{(j, 0) : 0 \le j < \ell\} \cup \{(j, -1) : 0 \le j < \ell\}$ of $\mathbb{Z}^2$. Read as lower-left corners of unit faces, these are the faces directly above and below the first $\ell$ edges of the positive horizontal axis.
