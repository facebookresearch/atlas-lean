# Exit dart of a finite origin cluster

Let $\omega$ be a bond configuration on $\mathbb{Z}^2$ whose open cluster $C$ of the origin is finite. The [exit dart](exit-dart.md) from $(j, 0)$ to $(j + 1, 0)$, where $j$ is the [exit index](exit-index.md), viewed as an element of the set of boundary darts of $C$ (darts whose tail lies in $C$ and whose head does not).
