# Event that every edge of the canonical contour is closed

Let $\omega$ be a bond configuration on $\mathbb{Z}^2$ whose open cluster of the origin is finite. The event is the set of bond configurations $\eta$ such that $\eta(\{x, y\}) = 0$ for every [dart](exit-dart.md) $(x, y)$ of the [canonical contour](canonical-contour-darts.md) of $\omega$.
