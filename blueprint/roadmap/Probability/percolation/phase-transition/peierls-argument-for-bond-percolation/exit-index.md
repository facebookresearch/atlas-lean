# Exit index of a finite origin cluster

Let $\omega$ be a bond configuration on $\mathbb{Z}^2$ whose open cluster $C$ of the origin is finite. The exit index is the least $j \in \mathbb{N}$ such that $(j + 1, 0) \notin C$. Such a $j$ exists because $C$ is finite, and $(0, 0), (1, 0), \dots, (j, 0)$ all lie in $C$.
