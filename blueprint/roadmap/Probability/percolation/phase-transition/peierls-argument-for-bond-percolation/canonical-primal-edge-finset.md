# Primal edges of the canonical contour

Let $\omega$ be a bond configuration on $\mathbb{Z}^2$ whose open cluster $C$ of the origin is finite. The primal edges of the canonical contour form the finite set of [undirected lattice edges](dart-primal-edge.md) $\{x, y\}$ underlying the [darts of the canonical contour](canonical-contour-darts.md).
