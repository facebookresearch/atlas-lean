# Face above the exit edge

Let $\omega$ be a bond configuration on $\mathbb{Z}^2$ whose open cluster of the origin is finite, with [exit index](exit-index.md) $j$. The upper exit face is the unit face $[j, j + 1] \times [0, 1]$ directly above the exit edge from $(j, 0)$ to $(j + 1, 0)$; its lower-left corner is $(j, 0)$.
