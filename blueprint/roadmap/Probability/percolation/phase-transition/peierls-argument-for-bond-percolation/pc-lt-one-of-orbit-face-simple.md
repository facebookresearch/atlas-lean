# $p_c(\mathbb{Z}^2) < 1$ assuming simple exit orbits

Assume that for every bond configuration $\omega$ on $\mathbb{Z}^2$ whose open cluster of the origin is finite, the exit orbit is [simple](orbit-face-simple.md) and contains the [left exit dart](exit-darts-same-orbit.md). Then the [critical probability](../percolation-probability-and-critical-point/pc.md) of bond percolation on $\mathbb{Z}^2$ satisfies $p_c(2) < 1$.
