# $p_c(\mathbb{Z}^2) < 1$ via exit dart orbits, assuming linked exits

Assume that for every bond configuration on $\mathbb{Z}^2$ whose open cluster of the origin is finite, the [enclosing contour links the two axis exits](enclosing-contour-links-exits.md). Then the [critical probability](../percolation-probability-and-critical-point/pc.md) of bond percolation on $\mathbb{Z}^2$ satisfies $p_c(2) < 1$.
