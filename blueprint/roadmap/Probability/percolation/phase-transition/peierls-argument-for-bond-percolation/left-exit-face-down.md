# Face below the left exit edge

Let $\omega$ be a bond configuration on $\mathbb{Z}^2$ whose open cluster of the origin is finite, with [left exit index](left-exit-index.md) $k$. The lower left exit face is the unit face $[-k - 1, -k] \times [-1, 0]$ directly below the left exit edge from $(-k, 0)$ to $(-k - 1, 0)$; its lower-left corner is $(-k - 1, -1)$.
