# Canonical orbit cycle condition

Let $\omega$ be a bond configuration on $\mathbb{Z}^2$ whose open cluster $C$ of the origin is finite. The canonical orbit cycle condition holds if the [face loop of the exit orbit](exit-orbit-face-loop.md) is a cycle of the face-boundary graph of $C$ and the [left exit dart lies in the boundary orbit of the exit dart](exit-darts-same-orbit.md).
