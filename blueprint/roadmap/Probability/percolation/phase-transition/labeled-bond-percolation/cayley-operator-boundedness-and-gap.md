# Operator boundedness and a nonuniqueness gap for arbitrary Cayley generators

Let $\Lambda$ be finitely generated and fail the right Følner condition specified in the [labelled bond model](labelled-independent-bond-law.md). For any finite symmetric generating set $S$ omitting the identity, use the Cayley graph with one unoriented edge for each distinct pair $\{x,xs\}$. Then the two-point matrix at $p_c$ defines a bounded operator on complex $\ell^2(\Lambda)$ and $p_c<p_2\le p_u$, for the [usual thresholds of this bond law](labelled-independent-bond-law.md). With independent uniform labels on distinct edges there are $p_c<a<b<1$ such that almost surely infinitely many infinite clusters exist simultaneously at every parameter of $[a,b]$. For every fixed $p_c<p<p_u$, there are infinitely many infinite clusters almost surely under the $p$-law. This variant does not state the from-below norm identity.

**Conventions.** Use the Cayley edge set with unordered endpoint pairs and the threshold definitions of the labelled bond model.
