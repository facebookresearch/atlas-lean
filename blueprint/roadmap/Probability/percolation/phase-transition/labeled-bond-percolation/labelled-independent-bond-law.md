# Independent bonds with separate edge labels

A labelled bond graph is a map from a separate edge type to unordered vertex pairs, with repetitions allowed in a pair. Equal endpoints give a loop; different edge labels can have the same pair. Local finiteness counts the set of incident labels at each vertex, including loops and parallel labels, not just the set of neighbors. An automorphism consists of bijections on both vertices and edge labels that preserve the endpoint map. Quasi-transitivity requires finitely many vertex orbits under these automorphisms.

Retain the labels independently with Bernoulli parameter $p\in[0,1]$. For connectivity, two vertices are connected if a finite open path joins them, allowing length zero. Deleting a loop step does not change which vertices can be reached. The simple connectivity graph omits loops and joins distinct vertices if at least one retained label joins them; this does not delete loop labels from the product law or incidence data, or identify the parallel Bernoulli trials. The cluster of a vertex is its reachability class.

The critical threshold $p_c$ is the infimum in $[0,1]$ of parameters for which the probability of *some* infinite cluster is positive, independent of any choice of root. The uniqueness threshold $p_u$ is the infimum in $[0,1]$ of parameters with exactly one infinite cluster almost surely. The two-point entry at $(x,y)$ is the real connection probability under the $p$-law. A bounded operator with this matrix on complex $\ell^2$ must send the basis vector at $y$ to a vector with coordinate $x$ equal to that entry. The operator threshold $p_2$ is the supremum in $[0,1]$ of parameters admitting such an operator, and the extended nonnegative norm quantity is the infimum of norms of these operators, with value $+\infty$ if none exists. In the common-label coupling each edge label is assigned its own independent uniform $[0,1]$ variable, and is retained when this variable is at most $p$.

The vertex boundary of a finite set is the set of neighbors outside it; the vertex expansion is the infimum of its cardinality relative to the size of the set, over nonempty finite sets. Intrinsic distances use the simple open connectivity graph and ambient distances its all-edge version. In the Cayley specialization one uses right multiplication by generators, with one label for each distinct unordered pair of endpoints, not one label per oriented generator-step. The right Følner condition is that for every finite $K$ and every $\epsilon>0$ some finite nonempty $A$ satisfies $|(Ak)\setminus A|<\epsilon|A|$ for every $k\in K$.
