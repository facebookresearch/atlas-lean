# Connection by an open path

Let $d \in \mathbb{N}$ and let $\omega$ be a bond configuration on $\mathbb{Z}^d$. Two sites $x, y \in \mathbb{Z}^d$ are connected by an open path, written $x \leftrightarrow y$, if they are reachable from each other in the [open subgraph](open-subgraph.md) of $\omega$: there is a path $x = z_0, z_1, \dots, z_k = y$ of nearest neighbours with every edge $\{z_{i-1}, z_i\}$ open. The case $k = 0$ is allowed, so $x \leftrightarrow x$.
