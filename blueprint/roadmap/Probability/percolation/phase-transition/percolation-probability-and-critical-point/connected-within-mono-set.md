# Open connection within a set is monotone in the set

Let $d \in \mathbb{N}$, let $\omega$ be a bond configuration on $\mathbb{Z}^d$ and let $S \subseteq T \subseteq \mathbb{Z}^d$. If $x, y \in S$ are [connected by an open path inside](connected-within.md) $S$, then they are connected by an open path inside $T$.
