# Measurability of the one-arm event

Let $d, n \in \mathbb{N}$. The one-arm event that the origin is joined by an open path to some site outside the box $\Lambda_{n-1} = [-(n-1), n-1]^d \cap \mathbb{Z}^d$ is measurable for the product σ-algebra on bond configurations of $\mathbb{Z}^d$. Here $n - 1$ is truncated subtraction, so for $n = 0$ the box is $\Lambda_0 = \{0\}$.
