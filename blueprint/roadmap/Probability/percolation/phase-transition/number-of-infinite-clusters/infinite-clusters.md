# Set of infinite open clusters

Let $d \in \mathbb{N}$ and let $\omega$ be a bond configuration on $\mathbb{Z}^d$. The set of infinite open clusters of $\omega$ is the set of subsets $C \subseteq \mathbb{Z}^d$ that are infinite and equal to the [open cluster](../percolation-probability-and-critical-point/cluster.md) $C(x)$ of some site $x$.
