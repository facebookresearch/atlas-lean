# Representative sites of the infinite clusters

Let $d \in \mathbb{N}$, fix an enumeration (an injection into $\mathbb{N}$) of the sites of $\mathbb{Z}^d$, and let $\omega$ be a bond configuration on $\mathbb{Z}^d$. The set of representative sites consists of the sites $x$ whose [open cluster](../percolation-probability-and-critical-point/cluster.md) $C(x)$ is infinite and which come first in the enumeration among all sites of $C(x)$. It contains exactly one site of each infinite open cluster.
