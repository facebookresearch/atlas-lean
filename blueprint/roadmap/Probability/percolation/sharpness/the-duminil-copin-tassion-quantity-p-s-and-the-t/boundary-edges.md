# Oriented edge boundary of a finite lattice set

Let $d \in \mathbb{N}$ and let $S \subseteq \mathbb{Z}^d$ be finite. The oriented edge boundary of $S$ is the finite set of ordered pairs

$$\partial S = \{(x, x \pm e_i) : x \in S,\ 1 \le i \le d,\ x \pm e_i \notin S\},$$

each written with its endpoint in $S$ first.
