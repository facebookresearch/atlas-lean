# Duminil-Copin–Tassion threshold

For $d \in \mathbb{N}$, the Duminil-Copin–Tassion threshold is

$$\tilde p_c(d) = \sup \{p \in [0, 1] : \varphi_p(S) < 1 \text{ for some finite } S \ni 0\},$$

the supremum of the [densities with a finite set of small Duminil-Copin–Tassion quantity](tilde-pc-set.md). The set contains $p = 0$ (take $S = \{0\}$), so $\tilde p_c(d) \in [0, 1]$.
