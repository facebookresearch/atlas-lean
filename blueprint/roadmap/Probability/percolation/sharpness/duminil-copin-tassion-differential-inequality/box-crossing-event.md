# Box-crossing event

For $d, n \in \mathbb{N}$, let $\Lambda_n = [-n, n]^d \cap \mathbb{Z}^d$ and let $\partial \Lambda_n = \Lambda_n \setminus \Lambda_{n-1}$ be its vertex boundary (with $n - 1$ truncated at $0$, so $\partial \Lambda_0 = \emptyset$). The box-crossing event $A_n$ is the set of bond configurations in which the origin is joined to some site of $\partial \Lambda_n$ by an open path [inside](../../phase-transition/percolation-probability-and-critical-point/connected-within.md) $\Lambda_n$.
