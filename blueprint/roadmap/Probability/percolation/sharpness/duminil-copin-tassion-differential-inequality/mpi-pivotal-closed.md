# Event that an edge is closed and pivotal

For a set $V$, an unordered pair $e$ of elements of $V$ and an event $A$ of configurations on these pairs, the set of configurations $\omega$ with $\omega_e = 0$ in which $e$ is [pivotal](../../../correlation-inequalities/harris-fkg-bk/russo-s-formula-and-pivotal-coordinates/is-pivotal.md) for $A$.
