# Set of sites not connected to the box boundary

For $d, n \in \mathbb{N}$ and a bond configuration $\omega$ on $\mathbb{Z}^d$, the random finite set $\mathcal{S}(\omega)$ of sites $x \in \Lambda_n$ that are not joined inside $\Lambda_n$ to the vertex boundary $\partial \Lambda_n$ by an open path (see [connection to the box boundary](conn-bdry.md)).
