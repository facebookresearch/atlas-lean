# Vertices not connected to a target set

Let $G$ be a graph on a finite vertex set $V$, $B \subseteq V$ and $\omega$ a configuration on the unordered pairs of elements of $V$. The set of vertices $x \in V$ that are not joined to any vertex of $B$ by a path of open edges of $G$ (an edge $e$ of $G$ being open when $\omega_e = 1$).
