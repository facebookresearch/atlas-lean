# Aizenman–Barsky inequality for all $\beta$ and $h$

A function $M : \mathbb{R}^2 \to \mathbb{R}$ satisfies the Aizenman–Barsky inequality with constant $J \in \mathbb{R}$ if

$$\partial_\beta M(\beta, h) \le J\, M(\beta, h)\, \partial_h M(\beta, h) \quad \text{for all } \beta, h \in \mathbb{R},$$

where a partial derivative is read as $0$ at points where the function is not differentiable.
