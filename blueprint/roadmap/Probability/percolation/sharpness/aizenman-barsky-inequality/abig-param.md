# Edge parameters as nonnegative reals

Let $V$ be a set, $J$ a real function on unordered pairs of elements of $V$ and $\beta, h \in \mathbb{R}$. The edge parameters are $p_e = \max(r_e, 0) \in [0, 1)$, where $r_e$ are the [real edge parameters with a ghost field](abig-real-param.md); negative values are replaced by $0$.
