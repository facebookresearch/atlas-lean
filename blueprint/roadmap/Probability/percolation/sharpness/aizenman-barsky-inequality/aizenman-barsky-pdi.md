# Second Aizenman–Barsky inequality

A function $M : \mathbb{R}^2 \to \mathbb{R}$ satisfies the second Aizenman–Barsky inequality if

$$M \le h\, \partial_h M + M^2 + \beta\, M\, \partial_\beta M \quad \text{at every } (\beta, h) \in \mathbb{R}^2,$$

where a partial derivative is read as $0$ at points where the function is not differentiable.
