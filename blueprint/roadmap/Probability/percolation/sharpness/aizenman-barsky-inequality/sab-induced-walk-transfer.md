# Transfer of an open walk between agreeing configurations

Let $G$ be a graph on $V$, $A \subseteq V$, and $\omega, \omega'$ configurations on unordered pairs of elements of $V$. If $w$ is a walk inside $A$ using only open edges of $G$ for $\omega$, and $\omega$ and $\omega'$ agree on the [edges traversed by $w$](sab-induced-edge-set.md), then $w$, with the same vertices, is a walk inside $A$ using only open edges for $\omega'$.
