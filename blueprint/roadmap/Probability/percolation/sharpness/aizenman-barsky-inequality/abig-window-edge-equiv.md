# Unordered pairs of the extended set as window edges

For a finite set $S \subseteq V$, the bijection between unordered pairs of elements of $S \cup \{\ast\}$ and the [internal edges](abig-internal-edges.md) of the [ghost window](abig-ghost-window.md) $S \cup \{\mathfrak{g}\}$, induced by the [identification](abig-ghost-window-equiv.md) of $S \cup \{\ast\}$ with $S \cup \{\mathfrak{g}\}$.
