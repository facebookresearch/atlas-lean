# Ghost window as a set with one added point

For a finite set $S \subseteq V$, the bijection between $S \cup \{\ast\}$ ($S$ with one added point) and the [ghost window](abig-ghost-window.md) $S \cup \{\mathfrak{g}\} \subseteq V \cup \{\mathfrak{g}\}$, sending the added point to the ghost $\mathfrak{g}$ and each $x \in S$ to itself.
