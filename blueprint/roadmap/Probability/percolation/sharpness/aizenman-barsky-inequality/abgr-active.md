# Sites connected to $o$ with ghost edges closed

Let $G$ be a graph on a finite vertex set $V$, $o \in V$, and $\omega$ a configuration on unordered pairs of elements of $V \cup \{\mathfrak{g}\}$. The set of sites $x \in V$ joined to $o$ by an open path of the ghost graph in the configuration obtained from $\omega$ by [closing all ghost edges](abgr-close-ghost.md).
