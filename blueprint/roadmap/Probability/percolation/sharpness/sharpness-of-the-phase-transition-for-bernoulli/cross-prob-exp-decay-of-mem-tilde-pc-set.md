# Exponential decay of the one-arm probability below the threshold

Let $d \in \mathbb{N}$ and let $p \in [0, 1]$ admit a finite set $S \subseteq \mathbb{Z}^d$ containing the origin with [Duminil-Copin–Tassion quantity](../the-duminil-copin-tassion-quantity-p-s-and-the-t/phi.md) $\varphi_p(S) < 1$. Then there are $c, C > 0$ such that the [one-arm probability](../exponential-decay-below-the-critical-point/cross-prob.md) satisfies

$$\mathbb{P}_p(0 \leftrightarrow \mathbb{Z}^d \setminus \Lambda_{n-1}) \le C e^{-cn} \quad \text{for all } n \in \mathbb{N}.$$
