# Connection inside a finite set depends on finitely many edges

For $d \in \mathbb{N}$, a finite set $S \subseteq \mathbb{Z}^d$ and sites $o, x$, the event $\{o \xleftrightarrow{S} x\}$ depends only on the coordinates $\omega(e)$ for $e$ in the set of [unordered pairs of sites of $S$](../duminil-copin-tassion-differential-inequality/edges-within-finset.md): two configurations that agree on these pairs both belong to the event or both do not.
