# The densities with $\varphi_p(S) < 1$ for some $S$ form a down-set

Let $d \in \mathbb{N}$ and $0 \le p \le q$. If $q \in [0, 1]$ and some finite $S \ni 0$ has $\varphi_q(S) < 1$, then $p$ also belongs to the [set defining $\tilde p_c(d)$](../the-duminil-copin-tassion-quantity-p-s-and-the-t/tilde-pc-set.md): some finite $S \ni 0$ has $\varphi_p(S) < 1$ (the same $S$ works, by [monotonicity of $\varphi$](phi-mono.md)).
