# Connection inside a set is an increasing event

For $d \in \mathbb{N}$, $S \subseteq \mathbb{Z}^d$ and sites $o, x$, the event $\{o \xleftrightarrow{S} x\}$ that [$o$ and $x$ are joined by an open path inside $S$](../duminil-copin-tassion-differential-inequality/within-conn-event.md) is [increasing](../../../correlation-inequalities/harris-fkg-bk/increasing-events-and-the-fkg-lattice-condition/is-increasing.md): opening edges keeps an open path open.
