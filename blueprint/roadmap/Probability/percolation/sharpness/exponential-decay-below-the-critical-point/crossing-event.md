# One-arm event from the origin

For $d, n \in \mathbb{N}$, the event $\{0 \leftrightarrow \mathbb{Z}^d \setminus \Lambda_{n-1}\}$ that the origin is joined by an open path to some site outside $\Lambda_{n-1} = [-(n-1), n-1]^d \cap \mathbb{Z}^d$. Here $n - 1$ is truncated at $0$, so the events for $n = 0$ and $n = 1$ coincide.
