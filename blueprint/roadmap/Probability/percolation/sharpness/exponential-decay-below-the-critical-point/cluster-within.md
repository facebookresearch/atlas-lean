# Open cluster of a site inside a set

For $d \in \mathbb{N}$, a bond configuration $\omega$ on $\mathbb{Z}^d$, a set $S \subseteq \mathbb{Z}^d$ and a site $o$, the open cluster of $o$ inside $S$ is

$$C_S(o) = \{y \in S : o \in S \text{ and } o \xleftrightarrow{S} y\},$$

the set of sites of $S$ joined to $o$ by an open path [inside](../../phase-transition/percolation-probability-and-critical-point/connected-within.md) $S$. It is empty when $o \notin S$.
