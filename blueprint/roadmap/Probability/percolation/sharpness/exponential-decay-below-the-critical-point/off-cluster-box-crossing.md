# Crossing inside the box that avoids a cluster

For $d, n \in \mathbb{N}$, a set $C \subseteq \mathbb{Z}^d$, a site $y$ and a bond configuration $\omega$, the condition that $y \in \Lambda_n \setminus C$ and $y$ is joined by an open path inside $\Lambda_n \setminus C$ to some site $z \in \Lambda_n \setminus C$ outside $\Lambda_{n-1}$ (with $n - 1$ truncated at $0$).
