# Crossing to the box exterior that avoids a cluster

For $d, n \in \mathbb{N}$, a set $C \subseteq \mathbb{Z}^d$, a site $y$ and a bond configuration $\omega$, the condition that $y \notin C$ and $y$ is joined by an open path inside $\mathbb{Z}^d \setminus C$ to some site $v \notin C$ outside $\Lambda_{n-1}$ (with $n - 1$ truncated at $0$).
