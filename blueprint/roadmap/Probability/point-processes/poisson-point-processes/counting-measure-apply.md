# Counting measure of a set as a sum of indicators

Let $E$ be a measurable space, $x = (x_0, \dots, x_{n-1}) \in E^n$ and $s \subseteq E$ measurable.
Then the [counting measure](counting-measure.md) of $x$ gives

$$\Big(\sum_{i < n} \delta_{x_i}\Big)(s) = \sum_{i < n} \mathbf{1}_s(x_i) = \#\{i < n : x_i \in s\} .$$
