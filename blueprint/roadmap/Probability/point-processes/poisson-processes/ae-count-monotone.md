# Counting process has nondecreasing paths almost surely

Let $r > 0$ and let $T_0, T_1, \dots$ be independent random variables on $(\Omega, P)$, each with
the exponential law of rate $r$. Then almost surely $t \mapsto N_t$ is nondecreasing, where $N$
is the [counting process](count.md) of the interarrival times $T_i$: the arrival times tend to
infinity almost surely, so every arrival set in $[0, t]$ is finite.
