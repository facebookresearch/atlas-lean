# Counting process of interarrival times

For interarrival times $T_0, T_1, \dots$ with [arrival times](arrival-time.md) $S_n$, the counting
process at time $t \ge 0$ is $N_t = \#\{n \ge 1 : S_n \le t\}$, the number of arrivals in
$[0, t]$, taken to be $0$ when this set is infinite (a null event for exponential interarrivals of
positive rate).
