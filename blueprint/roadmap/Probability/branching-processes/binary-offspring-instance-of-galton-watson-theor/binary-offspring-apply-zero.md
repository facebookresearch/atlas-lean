# Binary Offspring apply zero

For every $p \in \mathbb{R}$, the binary offspring measure $\nu_p = (1 - p)^{+} \delta_0 + p^{+} \delta_2$ on $\mathbb{N}$, with $x^{+} = \max(x, 0)$, satisfies

$$\nu_p(\{0\}) = (1 - p)^{+}.$$

It is a probability measure, the binary offspring law, exactly when $0 \le p \le 1$.

In particular $\nu_p(\{0\}) = 1 - p$ when $p \le 1$.
