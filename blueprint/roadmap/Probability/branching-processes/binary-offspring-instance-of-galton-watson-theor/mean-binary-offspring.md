# Mean binary Offspring

For every $p \in \mathbb{R}$, the mean offspring number of the binary offspring law $\nu_p = (1 - p)^{+} \delta_0 + p^{+} \delta_2$, computed in $[0, \infty]$, is

$$m(\nu_p) = \sum_{k \in \mathbb{N}} k\, \nu_p(\{k\}) = (2p)^{+} = \max(2p, 0).$$

For $0 \le p \le 1$ this is $2p$, so $m(\nu_p) \le 1$ exactly when $p \le 1/2$.
