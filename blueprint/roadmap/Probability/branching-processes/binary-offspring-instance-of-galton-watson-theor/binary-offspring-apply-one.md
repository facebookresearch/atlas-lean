# Binary Offspring apply one

For every $p \in \mathbb{R}$, the binary offspring measure $\nu_p = (1 - p)^{+} \delta_0 + p^{+} \delta_2$ on $\mathbb{N}$ satisfies

$$\nu_p(\{1\}) = 0.$$

It is a probability measure, the binary offspring law, exactly when $0 \le p \le 1$.

In particular $\nu_p(\{1\}) \ne 1$, so the binary law is never the degenerate law with exactly one child.
