# Kendall's extinction probability for the birth–death process

For real numbers $b, d, t$ put $E = e^{(b - d) t}$ and define

$$\alpha(t) = \frac{d\,(E - 1)}{b E - d} \quad \text{if } b \ne d, \qquad \alpha(t) = \frac{b t}{1 + b t} \quad \text{if } b = d,$$

where a quotient with zero denominator is read as $0$. For $b, d \ge 0$ and $t \ge 0$ this is
Kendall's probability $P(X_t = 0 \mid X_0 = 1)$ that the linear birth–death process with
per-capita birth rate $b$ and death rate $d$, started from one individual, is extinct at time
$t$.

## Sources

- D. G. Kendall, *On the generalized "birth-and-death" process*, Annals of Mathematical
  Statistics 19 (1948), 1–15.
