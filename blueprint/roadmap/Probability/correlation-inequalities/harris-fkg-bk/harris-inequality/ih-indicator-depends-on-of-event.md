# Indicator of an event depends on the coordinates the event depends on

Let $E$ be a set, $S \subseteq E$ and $A \subseteq \{0,1\}^E$. If the event $A$ depends only on the coordinates in $S$ (configurations agreeing on $S$ are both in $A$ or both outside $A$), then its indicator function $\mathbf{1}_A : \{0,1\}^E \to \mathbb{R}$ depends only on $S$.
