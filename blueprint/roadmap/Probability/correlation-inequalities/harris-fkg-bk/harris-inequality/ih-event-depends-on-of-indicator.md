# An event depends on the coordinates its indicator depends on

Let $E$ be a set, $S \subseteq E$ and $A \subseteq \{0,1\}^E$. If the indicator function $\mathbf{1}_A : \{0,1\}^E \to \mathbb{R}$ depends only on the coordinates in $S$ (configurations that agree on $S$ have the same indicator value), then the event $A$ depends only on $S$: whenever $\omega$ and $\omega'$ agree on $S$, $\omega \in A$ if and only if $\omega' \in A$.
