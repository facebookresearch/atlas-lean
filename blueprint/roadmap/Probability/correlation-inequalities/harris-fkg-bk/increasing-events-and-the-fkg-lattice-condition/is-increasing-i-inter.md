# Arbitrary intersections of increasing events are increasing

Let $E$ be a set and $(A_i)_{i \in I}$ a family of increasing events in $\{0,1\}^E$, indexed by an arbitrary (possibly empty) index set $I$. Then $\bigcap_{i \in I} A_i$ is increasing; for $I$ empty this intersection is the whole space $\{0,1\}^E$.
