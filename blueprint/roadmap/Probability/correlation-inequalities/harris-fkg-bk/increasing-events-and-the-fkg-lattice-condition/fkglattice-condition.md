# FKG lattice condition

Let $E$ be a set and order $\{0,1\}^E$ coordinatewise, with $\omega \vee \omega'$ and $\omega \wedge \omega'$ the coordinatewise maximum and minimum. A weight $\pi : \{0,1\}^E \to \mathbb{R}$ satisfies the *FKG lattice condition* if

$$\pi(\omega)\,\pi(\omega') \le \pi(\omega \vee \omega')\,\pi(\omega \wedge \omega') \quad \text{for all } \omega, \omega' \in \{0,1\}^E.$$

No sign condition is imposed on $\pi$. For a positive weight the condition says that $\log \pi$ is supermodular (log-supermodularity).
