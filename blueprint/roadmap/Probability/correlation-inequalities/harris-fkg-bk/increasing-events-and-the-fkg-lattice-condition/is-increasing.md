# Increasing event

Let $E$ be a set and let $\{0,1\}^E$ be the space of configurations $\omega : E \to \{0,1\}$, ordered coordinatewise ($\omega \le \omega'$ if $\omega(e) \le \omega'(e)$ for every $e \in E$). An event $A \subseteq \{0,1\}^E$ is *increasing* if it is an upper set: $\omega \in A$ and $\omega \le \omega'$ imply $\omega' \in A$.
