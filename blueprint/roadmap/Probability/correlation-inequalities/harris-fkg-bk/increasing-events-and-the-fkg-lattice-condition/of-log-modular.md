# Log-modular weights satisfy the FKG lattice condition

Let $E$ be a set and $\pi : \{0,1\}^E \to \mathbb{R}$ a log-modular weight, that is,

$$\pi(\omega)\,\pi(\omega') = \pi(\omega \vee \omega')\,\pi(\omega \wedge \omega') \quad \text{for all } \omega, \omega'.$$

Then $\pi$ satisfies the FKG lattice condition.
