# Open connection inside a set to a target set

Let $G$ be a simple graph on $V$, $\omega \in \{0,1\}^{V^{(2)}}$, $A, B \subseteq V$ and $u \in V$. Then $u$ is connected to $B$ inside $A$ if $u \in A$ and there is a vertex $b \in A \cap B$ such that $u$ and $b$ are [connected by an open path inside $A$](conn-within.md).
