# Occurrence of an event on a coordinate set

Let $E$ be a set, $A \subseteq \{0,1\}^E$ an event, $K \subseteq E$ and $\omega \in \{0,1\}^E$. The event $A$ *occurs on* $K$ at $\omega$ if every configuration that [agrees with](agree-on.md) $\omega$ on $K$ lies in $A$:

$$\omega' \in \{0,1\}^E,\ \omega'|_K = \omega|_K \implies \omega' \in A.$$

The set $K$ is arbitrary (not required to be finite).
