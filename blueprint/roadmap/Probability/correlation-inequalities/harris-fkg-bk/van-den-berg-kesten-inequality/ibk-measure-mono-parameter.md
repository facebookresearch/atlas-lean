# Increasing-event probabilities are monotone in the parameter

Let $E$ be a countable set, $0 \le p \le q \le 1$, and $\mathbb{P}_p$, $\mathbb{P}_q$ the Bernoulli product measures on $\{0,1\}^E$. If $A \subseteq \{0,1\}^E$ is an increasing event depending only on the coordinates of a finite set $F \subseteq E$, then $\mathbb{P}_p(A) \le \mathbb{P}_q(A)$.

The proof uses [Russo's formula](../russo-s-formula-and-pivotal-coordinates/has-deriv-at-prob-eq-sum-pivotal-prob.md).
