# FKG inequality for increasing events

Let $E$ be a finite set and $\pi : \{0,1\}^E \to \mathbb{R}$ a probability weight ($\pi \ge 0$, $\sum_\omega \pi(\omega) = 1$) satisfying the FKG lattice condition. Write $\pi(A) = \sum_{\omega \in A} \pi(\omega)$. Then any two increasing events $A, B \subseteq \{0,1\}^E$ are positively correlated:

$$\pi(A)\,\pi(B) \le \pi(A \cap B).$$

## Sources

- C. M. Fortuin, P. W. Kasteleyn and J. Ginibre, *Correlation inequalities on some partially ordered sets*, Comm. Math. Phys. 22 (1971), 89–103.
