# Holley inequality for increasing events

Let $E$ be a finite set and $\mu_1, \mu_2 : \{0,1\}^E \to \mathbb{R}$ nonnegative weights with equal total mass, $\sum_\omega \mu_1(\omega) = \sum_\omega \mu_2(\omega)$, satisfying the Holley lattice condition

$$\mu_1(a)\,\mu_2(b) \le \mu_1(a \wedge b)\,\mu_2(a \vee b) \quad \text{for all } a, b \in \{0,1\}^E.$$

Then for every increasing event $A \subseteq \{0,1\}^E$,

$$\sum_{\omega \in A} \mu_1(\omega) \le \sum_{\omega \in A} \mu_2(\omega).$$

## Sources

- R. Holley, *Remarks on the FKG inequalities*, Comm. Math. Phys. 36 (1974), 227–231.
