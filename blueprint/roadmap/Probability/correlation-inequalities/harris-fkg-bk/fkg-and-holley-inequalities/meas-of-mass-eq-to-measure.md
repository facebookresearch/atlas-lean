# Normalized point masses define a probability measure

Let $E$ be a finite set and $\mu : \{0,1\}^E \to \mathbb{R}$ with $\sum_\omega \max(\mu(\omega), 0) = 1$. Then the measure $m_\mu = \sum_\omega \max(\mu(\omega), 0)\,\delta_\omega$ is the probability measure on $\{0,1\}^E$ whose probability mass function is $\omega \mapsto \max(\mu(\omega), 0)$.
