# Harris–FKG inequality for increasing events

Let $E$ be a finite set and $\varphi : E \times \{0,1\} \to \mathbb{R}$ a product probability weight ($\varphi_x(b) \ge 0$, $\varphi_x(0) + \varphi_x(1) = 1$), with $P_\varphi(S) = \sum_{\omega \in S} \prod_x \varphi_x(\omega(x))$. If $A, B \subseteq \{0,1\}^E$ are increasing, then

$$P_\varphi(A)\, P_\varphi(B) \le P_\varphi(A \cap B).$$
