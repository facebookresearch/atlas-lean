# Event determined by a set of coordinates

Let $E$ be a set, $A \subseteq \{0,1\}^E$ and $K \subseteq E$. The event $A$ is *determined by* $K$ if membership in $A$ depends only on the values on $K$: whenever $\omega$ and $\omega'$ agree on $K$, $\omega \in A$ if and only if $\omega' \in A$. This is the same notion as an event depending only on the coordinates in $K$.
