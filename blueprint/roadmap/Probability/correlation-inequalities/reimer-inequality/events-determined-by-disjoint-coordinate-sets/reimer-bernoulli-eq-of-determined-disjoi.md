# Reimer equality for events determined by disjoint coordinates

Let $E$ be a finite set, $p \in [0,1]$ and $\mathbb{P}_p$ the Bernoulli product measure on $\{0,1\}^E$. Let $K, L \subseteq E$ be disjoint, $A$ an event determined by $K$ and $B$ an event determined by $L$. Then Reimer's inequality holds with equality:

$$\mathbb{P}_p(A \mathbin{\square} B) = \mathbb{P}_p(A)\, \mathbb{P}_p(B).$$
