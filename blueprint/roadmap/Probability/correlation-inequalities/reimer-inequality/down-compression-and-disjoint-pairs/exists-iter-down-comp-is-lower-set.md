# Iterated down-compression reaches a lower set

Let $\alpha$ be a set and $\mathcal{A}$ a finite family of finite subsets of $\alpha$. There is a finite list of coordinates $c_1, \dots, c_k \in \alpha$ such that the [iterated down-compression](iter-down-comp.md) $C_{c_1} \cdots C_{c_k}\mathcal{A}$ is a lower set (closed under taking subsets).
