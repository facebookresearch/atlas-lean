# Reimer equality for a left event and a right event

Let $\alpha$ be a finite set and $\varphi : (\alpha \sqcup \alpha) \times \{0,1\} \to \mathbb{R}$ with $\varphi_x(0) + \varphi_x(1) = 1$ for every $x$ (no sign condition), and write $P_\varphi(S) = \sum_{\omega \in S} \prod_x \varphi_x(\omega(x))$. For all $A, B \subseteq \{0,1\}^\alpha$, with $\tilde A$ the [left event](left-event.md) of $A$ and $\tilde B$ the [right event](right-event.md) of $B$,

$$P_\varphi(\tilde A \mathbin{\square} \tilde B) = P_\varphi(\tilde A)\, P_\varphi(\tilde B).$$
