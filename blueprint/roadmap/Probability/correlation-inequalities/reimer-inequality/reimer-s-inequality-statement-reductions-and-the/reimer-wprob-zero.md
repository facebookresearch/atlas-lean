# Reimer's inequality on the one-point configuration space

Let $\varphi$ be any weight on the empty coordinate set (the configuration space $\{0,1\}^{\emptyset}$ has a single point). For all events $A, B \subseteq \{0,1\}^{\emptyset}$,

$$P_\varphi(A \mathbin{\square} B) \le P_\varphi(A)\, P_\varphi(B),$$

where $P_\varphi(S)$ is $1$ if $S$ contains the unique configuration and $0$ otherwise.
