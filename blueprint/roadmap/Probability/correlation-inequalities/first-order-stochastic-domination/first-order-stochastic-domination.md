# First-order stochastic domination

Let $\alpha$ be a preordered set with a $\sigma$-algebra. A measure $\mu$ on $\alpha$ *stochastically dominates* a measure $\nu$, written $\nu \preceq_{\mathrm{st}} \mu$, if $\nu(U) \le \mu(U)$ for every measurable upper set $U$ (a set with $x \in U$, $x \le y \Rightarrow y \in U$). For discrete distributions $p, q$ on a preordered set, $q \preceq_{\mathrm{st}} p$ means $q(U) \le p(U)$ for every upper set $U$. The relation is reflexive and transitive.
