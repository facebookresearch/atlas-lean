# Definition 1.11

A random variable $X$ is said to be sub-exponential with parameter $\lambda$ (denoted $X \sim \mathsf{subE}(\lambda)$) if $\mathbb{E}[X] = 0$ and its moment generating function satisfies $$\mathbb{E}\left[e^{sX}\right] \leq e^{s^2\lambda^2/2}, \qquad \forall\, |s| \leq \frac{1}{\lambda}.$$
