# Definition 2.10

The hard thresholding estimator with threshold $2\tau > 0$ is denoted by $\hat{\theta}^{\mathrm{HRD}}$ and has coordinates $\hat{\theta}_j^{\mathrm{HRD}} = y_j$ if $|y_j| > 2\tau$, and $\hat{\theta}_j^{\mathrm{HRD}} = 0$ if $|y_j| \leq 2\tau$, for $j = 1, \ldots, d$. In short, we can write $\hat{\theta}_j^{\mathrm{HRD}} = y_j \mathbb{1}(|y_j| > 2\tau)$.
