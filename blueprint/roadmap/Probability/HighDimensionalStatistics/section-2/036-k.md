# Assumption INC(k)

We say that the design matrix $\mathbb{X}$ has incoherence $k$ for some integer $k > 0$ if $|\mathbb{X}^\top \mathbb{X}/n - I_d|_\infty \leq 1/(14k)$, where $|A|_\infty$ denotes the largest element of $A$ in absolute value. Equivalently: 1. For all $j = 1, \ldots, d$, $||\mathbb{X}_j|_2^2/n - 1| \leq 1/(14k)$. 2. For all $1 \leq i, j \leq d$, $i \neq j$, $|\mathbb{X}_i^\top \mathbb{X}_j / n| \leq 1/(14k)$.
