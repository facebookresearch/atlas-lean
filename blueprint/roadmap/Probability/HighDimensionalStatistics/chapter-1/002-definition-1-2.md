# Definition 1.2

A random variable $X \in \mathbb{R}$ is said to be sub-Gaussian with variance proxy $\sigma^2$ if $\mathbb{E}[X] = 0$ and its moment generating function satisfies $\mathbb{E}[\exp(sX)] \leq \exp(\sigma^2 s^2 / 2)$, for all $s \in \mathbb{R}$. In this case we write $X \sim \mathsf{subG}(\sigma^2)$.
