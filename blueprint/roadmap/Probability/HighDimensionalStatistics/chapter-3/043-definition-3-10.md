# Definition 3.10

Fix parameters $\beta \in \{1, 2, \ldots\}$ and $L > 0$. The Sobolev class of functions $W(\beta, L)$ is defined by $W(\beta, L) = \{ f : [0,1] \to \mathbb{R} \mid f \in L_2([0,1]),\, f^{(\beta-1)} \text{ is absolutely continuous and } \int_0^1 [f^{(\beta)}]^2 \leq L^2,\, f^{(j)}(0) = f^{(j)}(1),\, j = 0, \ldots, \beta-1 \}$.
