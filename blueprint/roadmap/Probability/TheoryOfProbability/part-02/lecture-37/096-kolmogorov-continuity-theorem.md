# Kolmogorov continuity theorem

Suppose $E|X_s - X_t|^{\beta} \leq K |t - s|^{1+\alpha}$ where $\alpha, \beta > 0$. If $\gamma < \alpha / \beta$ then with probability one there is a constant $C(\omega)$ so that $|X(q) - X(r)| \leq C |q - r|^{\gamma}$ for all $q, r \in \mathbb{Q}_2 \cap [0, 1]$.
