# Definition (Transition probability)

Consider a measurable space $(S, \mathcal{S})$. A function $p \colon S \times \mathcal{S} \to \mathbb{R}$ is a transition probability if (1) for each $x \in S$, $A \mapsto p(x, A)$ is a probability measure on $(S, \mathcal{S})$, and (2) for each $A \in \mathcal{S}$, the map $x \mapsto p(x, A)$ is a measurable function.
