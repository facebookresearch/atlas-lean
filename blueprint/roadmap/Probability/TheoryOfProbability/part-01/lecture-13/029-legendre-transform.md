# Definition (Legendre transform)

The Legendre transform (or Legendre dual) of a function $\Lambda \colon \mathbb{R}^d \to \mathbb{R}$ is defined by $\Lambda^*(x) = \sup_{\lambda \in \mathbb{R}^d} \{\langle \lambda, x \rangle - \Lambda(\lambda)\}$.
