# Jensen's inequality

If $\mu$ is a probability measure and $\varphi \colon \mathbb{R} \to \mathbb{R}$ is convex then $\varphi\!\left(\int f \, d\mu\right) \leq \int \varphi(f) \, d\mu$. If $X$ is a random variable then $E[\varphi(X)] \geq \varphi(E[X])$.
