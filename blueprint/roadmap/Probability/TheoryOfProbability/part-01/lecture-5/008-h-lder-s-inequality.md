# Hölder's inequality

Write $\|f\|_p = \left(\int |f|^p \, d\mu\right)^{1/p}$ for $1 \leq p < \infty$. If $1/p + 1/q = 1$, then $\int |fg| \, d\mu \leq \|f\|_p \, \|g\|_q$.
