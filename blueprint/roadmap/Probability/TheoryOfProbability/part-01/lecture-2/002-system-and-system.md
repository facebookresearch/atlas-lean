# Theorem (π-system and λ-system)

If $P$ is a $\pi$-system and $L$ is a $\lambda$-system that contains $P$, then $\sigma(P) \subset L$, where $\sigma(\mathcal{A})$ denotes the smallest $\sigma$-algebra containing $\mathcal{A}$.
