# Definition (lattice random variable)

If $\phi_X(\lambda) = 1$ for some $\lambda \neq 0$ then $X$ is supported on (some translation of) $(2\pi / \lambda)\mathbb{Z}$. When this holds but $\phi_X$ is not identically $1$ (i.e., $\phi_X$ is periodic but not identically $1$) we call $X$ a lattice random variable.
