# Theorem (Conditional variance theorem)

If $X_n$ is a martingale with $E[X_n^2] < \infty$ for all $n$ then $E[(X_n - X_m)^2 \mid \mathcal{F}_m] = E[X_n^2 \mid \mathcal{F}_m] - X_m^2$.
