# Jordan decomposition of a finite signed measure

Let $s$ be a signed measure, with real values and hence finite, on a set $\alpha$ with a
σ-algebra. Its Jordan decomposition is the pair $(s^+, s^-)$ of finite measures on $\alpha$ defined from a Hahn
decomposition of $s$, that is, a measurable set $i$ with $s(E) \ge 0$ for measurable $E \subseteq i$ and
$s(E) \le 0$ for measurable $E \subseteq \alpha \setminus i$, by $s^+(E) = s(E \cap i)$ and
$s^-(E) = -s(E \cap (\alpha \setminus i))$; these two measures are mutually singular. Then
$s(E) = s^+(E) - s^-(E)$ for every measurable set $E$.
