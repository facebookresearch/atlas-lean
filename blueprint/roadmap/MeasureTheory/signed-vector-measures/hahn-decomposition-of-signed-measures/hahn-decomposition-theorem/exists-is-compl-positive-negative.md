# Hahn decomposition of a finite signed measure

Let $s$ be a signed measure on a set $\alpha$ with a σ-algebra: a countably additive function
from the measurable sets to $\mathbb{R}$, so that $s$ is finite. Then there are measurable sets $i$ and $j$ with
$i \cap j = \emptyset$ and $i \cup j = \alpha$ such that $s(E) \ge 0$ for every measurable set $E \subseteq i$ and
$s(E) \le 0$ for every measurable set $E \subseteq j$.
