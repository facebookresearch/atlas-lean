# Mutually singular vector measures

Let $\alpha$ be a set with a σ-algebra and let $v$ and $w$ be vector measures on $\alpha$ with
values in additive commutative monoids $M$ and $N$ carrying topologies. Then $v$ and $w$ are mutually singular,
written $v \perp w$, if there is a measurable set $s \subseteq \alpha$ such that $v(t) = 0$ for every
$t \subseteq s$ and $w(t) = 0$ for every $t \subseteq \alpha \setminus s$.
