# Lebesgue decomposition of a measure

Let $\mu$ and $\nu$ be measures on a set $\alpha$ with a σ-algebra that have a Lebesgue decomposition, as every pair of σ-finite measures does. Then

$$\mu = \mu_{\mathrm s} + \nu.\mathrm{withDensity}\Bigl(\frac{d\mu}{d\nu}\Bigr),$$

where the singular part $\mu_{\mathrm s}$ of $\mu$ with respect to $\nu$ is mutually singular with $\nu$, and $d\mu/d\nu \colon \alpha \to [0, \infty]$ is the measurable Radon–Nikodym derivative of $\mu$ with respect to $\nu$, so that the second summand $E \mapsto \int_E (d\mu/d\nu)\, d\nu$ is absolutely continuous with respect to $\nu$.
