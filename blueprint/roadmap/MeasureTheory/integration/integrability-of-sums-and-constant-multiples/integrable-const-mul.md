# Integrability of a constant left multiple

Let $\mu$ be a measure on a measurable space $\Omega$, and let $R$ be a
normed ring. If $f:\Omega\to R$ is $\mu$-integrable, then the function
$\omega\mapsto c f(\omega)$ is $\mu$-integrable for every $c\in R$, including
$c=0$.
