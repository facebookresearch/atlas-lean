# Diagonal indicator, counting measure inside

Let $\Delta = \{(x, x) : x \in [0, 1]\}$ be the diagonal of $[0, 1]^2$, let $m$ be Lebesgue measure
and $\#$ counting measure on $[0, 1]$. Then

$$\int_{[0,1]} \Big( \int_{[0,1]} 1_\Delta(x, y) \, d\#(y) \Big) \, dm(x) = 1,$$

because the inner integral is $\#\{x\} = 1$ for every $x \in [0, 1]$.
