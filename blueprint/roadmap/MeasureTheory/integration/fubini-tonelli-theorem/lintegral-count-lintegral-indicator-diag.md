# Diagonal indicator, Lebesgue measure inside

With $\Delta$, $m$ and $\#$ as for the [other order](lintegral-lintegral-count-indicator-diag.md),

$$\int_{[0,1]} \Big( \int_{[0,1]} 1_\Delta(x, y) \, dm(x) \Big) \, d\#(y) = 0,$$

because the inner integral is $m(\{y\}) = 0$ for every $y$. So the two iterated integrals of the
indicator of a closed, hence measurable, set differ.
