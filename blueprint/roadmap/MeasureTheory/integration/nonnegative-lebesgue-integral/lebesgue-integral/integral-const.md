# Integral of a constant

Let $\mu$ be a measure on a set $\alpha$ with a σ-algebra, and let $E$ be a real Banach space. For every $c \in E$,

$$\int c \, d\mu = \mu(\alpha) \, c,$$

where the integral is the Bochner integral of the constant function $c$, and $\mu(\alpha)$ is read as a real number,
$0$ if $\mu(\alpha) = \infty$.
