# Monotonicity of the integral of integrable functions

Let $\mu$ be a measure on a set $\alpha$ with a σ-algebra, and let $E$ be a real normed vector space with a partial
order compatible with addition and with multiplication by nonnegative reals, in which every set $\{y : y \ge x\}$ is
closed, such as $\mathbb{R}$. For integrable functions $f, g \colon \alpha \to E$ with $f(x) \le g(x)$ for every
$x \in \alpha$,

$$\int f \, d\mu \le \int g \, d\mu,$$

where the integral is the Bochner integral, which for real functions is the Lebesgue integral.
