# A nonnegative function with integral zero vanishes almost everywhere

Let $\mu$ be a measure on a set $\alpha$ with a σ-algebra and let $f \colon \alpha \to [0, \infty]$ be
measurable. Then $\int f \, d\mu = 0$ if and only if $f = 0$ $\mu$-almost everywhere, that is,
$\mu(\{x \in \alpha : f(x) \ne 0\}) = 0$.
