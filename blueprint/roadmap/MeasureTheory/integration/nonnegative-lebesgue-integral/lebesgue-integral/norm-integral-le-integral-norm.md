# Norm of an integral

Let $\mu$ be a measure on a set $\alpha$ with a σ-algebra, and let $G$ be a real normed vector space. For every function
$f \colon \alpha \to G$,

$$\Big\| \int f \, d\mu \Big\| \le \int \|f\| \, d\mu,$$

where the integrals are Bochner integrals, which are $0$ for functions that are not integrable; for real or complex $f$
this is $|\int f \, d\mu| \le \int |f| \, d\mu$.
