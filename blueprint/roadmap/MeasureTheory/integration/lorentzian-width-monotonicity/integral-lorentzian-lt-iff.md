# Strict width monotonicity of Lorentzian integrals

Let $\mu$ be a finite measure on $\mathbb{R}$ (the zero measure included) and $0 < \Gamma_1 < \Gamma_2$.
Then

$$\int \frac{\Gamma_1^2}{E^2 + \Gamma_1^2}\, d\mu(E) < \int \frac{\Gamma_2^2}{E^2 + \Gamma_2^2}\, d\mu(E)$$

if and only if $\mu(\mathbb{R} \setminus \{0\}) > 0$. The kernel equals $1$ at $E = 0$ for every
width, so mass at the origin never contributes to the increase; in particular the zero measure, and
any multiple of the Dirac mass at $0$, give equal integrals.
