# Tails of a minimizing-movement sequence

If $(\rho_k)$ is a [minimizing-movement sequence](is-minimizing-movement.md), so is
$(\rho_{j+k})_{k \ge 0}$ for every $j$: the scheme has no memory beyond the previous state. This
reduces estimates between $\rho_j$ and $\rho_{j+n}$ to estimates from the starting point.
