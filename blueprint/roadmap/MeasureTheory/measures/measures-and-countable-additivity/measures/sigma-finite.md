# σ-finite measure

Let $\mu$ be a measure on a set $\alpha$ with a σ-algebra. The measure $\mu$ is σ-finite if there
are subsets $A_0, A_1, A_2, \ldots$ of $\alpha$ with $\mu(A_i) < \infty$ for every $i$ and
$\bigcup_i A_i = \alpha$. The sets $A_i$ need not be measurable, $\mu$ being applied to them as to arbitrary
subsets; replacing each $A_i$ by a measurable set of the same measure that contains it gives measurable such
sets.
