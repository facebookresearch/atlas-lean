# Almost everywhere

Let $\mu$ be a function from the subsets of a set $\alpha$ to $[0, \infty]$ that is zero on $\emptyset$,
monotone, and countably subadditive on pairwise disjoint sequences: $\mu\big(\bigcup_n s_n\big) \le \sum_n \mu(s_n)$
whenever $s_0, s_1, \ldots$ are pairwise disjoint. Outer measures are such functions, and so is a measure applied to
arbitrary subsets, the value on a set that is not measurable being the infimum of the measures of the measurable sets
containing it. The almost everywhere filter of $\mu$ consists of the sets
$s \subseteq \alpha$ whose complement has measure zero, $\mu(\alpha \setminus s) = 0$; it is closed under countable
intersections. A property of the points of $\alpha$ holds $\mu$-almost everywhere when the set of points where it
holds belongs to this filter, that is, when the set of points where it fails has measure zero. For a measure, a set
has measure zero in this sense exactly when it is contained in a measurable set of measure zero.
