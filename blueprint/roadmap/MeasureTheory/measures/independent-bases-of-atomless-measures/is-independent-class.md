# Stochastically independent class of sets

Let $\mu$ be a measure on a measurable space
$X$. A class $B$ of subsets of $X$ is stochastically independent with respect to $\mu$ if for
every finite collection of distinct sets $A_1, \dots, A_n$ in $B$, including the empty one,
$\mu(A_1 \cap \dots \cap A_n) = \mu(A_1) \cdots \mu(A_n)$. The empty intersection is $X$ and the
empty product is $1$, so this forces $\mu(X) = 1$. The sets in $B$ need not be measurable; on
such sets $\mu$ is the outer measure.
