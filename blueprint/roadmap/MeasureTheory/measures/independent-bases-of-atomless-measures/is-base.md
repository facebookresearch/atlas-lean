# Base of a measure

Let $\mu$ be a measure on a measurable space $X$. A class $B$ of
subsets of $X$ is a base of $\mu$ if every set in $B$ is measurable, $B$ is stochastically
independent with respect to $\mu$, and every measurable set $A \subseteq X$ agrees up to a null
set with a set $C$ in the $\sigma$-algebra generated by $B$, that is, $\mu(A \triangle C) = 0$.
