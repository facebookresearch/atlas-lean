# Carathéodory measurable sets

Let $m$ be an outer measure on a set $\alpha$. A set $s \subseteq \alpha$ is Carathéodory measurable for $m$ when it
splits every set additively: $m(t) = m(t \cap s) + m(t \setminus s)$ for every $t \subseteq \alpha$.

## Idea

An outer measure is defined on every subset but is only countably subadditive. Carathéodory's theorem says that the
sets that split every test set additively form a σ-algebra, on which the outer measure is countably additive, so it
restricts to a complete measure there. Lebesgue measure arises this way from Lebesgue outer measure, and the
Carathéodory extension theorem extends a premeasure on an algebra of sets through the outer measure it induces. For a
metric outer measure, such as a Hausdorff measure, every Borel set is Carathéodory measurable.
