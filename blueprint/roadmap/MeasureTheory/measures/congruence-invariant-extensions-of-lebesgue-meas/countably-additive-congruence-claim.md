# Problem of a congruence-invariant countably additive plane measure

The countably additive reading of Problem 169 of the Scottish Book asks for a function $\mu$,
defined on all subsets of the Euclidean plane $\mathbb{R}^2$ with values in $[0, \infty]$, that takes
equal values on congruent sets, is [countably additive](is-countably-additive.md), and extends the
linear measure of Carathéodory: it agrees, on every Borel set, with Carathéodory's linear measure,
the one-dimensional measure of plane sets that generalises length (a segment has linear measure equal
to its length, and a set of positive area has infinite linear measure).

The same question with plane Lebesgue (area) measure in place of the linear measure has the same
negative answer for countably additive $\mu$ ([refutation](no-countably-additive-congruence-measure.md)).
