# No countably additive congruence-invariant extension of linear measure to all plane sets

No function $\mu$ defined on all subsets of $\mathbb{R}^2$, with values in $[0, \infty]$, is
invariant under congruence, countably additive, and equal to Carathéodory's linear measure on
Borel sets. This answers the countably additive reading of Problem 169 of the Scottish Book in the
negative.

## Idea

The argument is Vitali's. Pick one point of $[0, 1]$ in each coset of $\mathbb{Q}$ and form the set
$V$ of these points on a horizontal line. Its translates by the rationals of $[-1, 1]$ are pairwise
disjoint and congruent, so they all have the same value $c$. Their union contains a segment of
linear measure $1$ and lies in one of linear measure $3$, so countable additivity forces
$1 \le \sum_n c \le 3$, which is impossible. The same argument, with the vertical unit segments above
the points of $V$ in place of $V$, and the unit square and the strip $[-1, 2] \times [0, 1]$ in place
of the two segments, shows that no such function extends plane Lebesgue measure either. The problem asked only for an "additive" function: for
finitely additive functions extending plane Lebesgue measure the answer is positive, by Banach's
theorem of 1923.
