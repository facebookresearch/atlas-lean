# Countably additive set function

A function $\mu$ from the subsets of the Euclidean plane $\mathbb{R}^2$ to $[0, \infty]$ is countably
additive if $\mu\big(\bigcup_i E_i\big) = \sum_i \mu(E_i)$ for every sequence $(E_i)_{i \in \mathbb{N}}$
of pairwise disjoint plane sets. This is the countably additive reading of "additive" in
Problem 169; the typescript does not say whether finite or countable additivity is meant.
