# Vitali's theorem

There exists a subset of $\mathbb{R}$ that is not Lebesgue measurable.

## Background

- [Lebesgue measurability by outer approximation](../../lebesgue-measure/lebesgue-measurability/null-measurable-set-iff-forall-exists-is.md):
  background; Lebesgue measurability (null-measurability for Lebesgue measure) is equivalent to Tao's
  definition by open outer approximation, so the Vitali set is one that no open set approximates
  from outside.

## Sources

- G. Vitali, *Sul problema della misura dei gruppi di punti di una retta*, Tipografia Gamberini e Parmeggiani, Bologna, 1905. Here `NullMeasurableSet` w.r.t. `volume` is the Lebesgue-measurability notion, i.e. measurability for the completion of Lebesgue measure.
