# Measure of a set as an infimum over open supersets

Let $\alpha$ be a topological space with a σ-algebra and let $\mu$ be an outer regular measure
on $\alpha$: for every measurable set $A$ and every $r > \mu(A)$ there is an open set $U \supseteq A$ with
$\mu(U) < r$. Then for every subset $A$ of $\alpha$, measurable or not,

$$\mu(A) = \inf\{\mu(U) : U \supseteq A,\ U \text{ open}\},$$

where for a set $A$ that is not measurable, $\mu(A)$ is the outer measure
$\inf\{\mu(B) : B \supseteq A,\ B \text{ measurable}\}$.
