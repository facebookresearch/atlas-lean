# Regular measure

Let $\alpha$ be a topological space with a σ-algebra. A measure $\mu$ on $\alpha$ is regular if
it satisfies three conditions. First, $\mu(K) < \infty$ for every compact set $K$. Second, $\mu$ is outer regular:
for every measurable set $A$ and every $r > \mu(A)$ there is an open set $U \supseteq A$ with $\mu(U) < r$. Third,
$\mu$ is inner regular on open sets with respect to compact sets: for every open set $U$ and every $r < \mu(U)$
there is a compact set $K \subseteq U$ with $r < \mu(K)$.
