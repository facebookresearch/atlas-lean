# Sets of finite Lebesgue measure contain no half-line

Let $E \subseteq \mathbb{R}$ have finite Lebesgue outer measure; $E$ need not be measurable. Then
for every real $X$ there is a real $x > X$ with $x \notin E$, that is, $E$ contains no half-line
$(X, \infty)$.

## Idea

A half-line has infinite Lebesgue measure and outer measure is monotone, so a set containing one
has infinite outer measure. Finite measure does not make a set bounded: the union of the
intervals $[n, n + 2^{-n}]$ has measure $2$ and points arbitrarily far out. What it does give is
that the set misses points arbitrarily far out.
