# Measurable sets are $G_\delta$ sets up to null sets

Let $\mu$ be a measure on a topological space $X$ whose Borel sets are measurable, and suppose
that $\mu$ is outer regular ($\mu(A) = \inf\{\mu(U) : U \supseteq A \text{ open}\}$ for measurable $A$)
and $\sigma$-finite; Lebesgue measure on $\mathbb{R}^d$ is the main example. Then $E \subseteq X$ is null-measurable if and only if $E \subseteq G$ for some $G_\delta$
set $G$ with $\mu(G \setminus E) = 0$, that is, iff $E$ is a $G_\delta$ set minus a null set.
