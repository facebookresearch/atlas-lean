# Open outer approximation gives a $G_\delta$ hull

Let $\mu$ be any measure on a topological space $X$ and $E \subseteq X$. If for every
$\varepsilon > 0$ there is an open set $U \supseteq E$ with $\mu(U \setminus E) \le \varepsilon$
(outer measure), then there is a $G_\delta$ set $G \supseteq E$ (a countable intersection of open
sets) with $\mu(G \setminus E) = 0$: take $G = \bigcap_n U_n$ with
$\mu(U_n \setminus E) \le 1/n$.
