# Lebesgue measurability

Tao defines a set $E \subseteq \mathbb{R}^d$ to be Lebesgue measurable when for every
$\varepsilon > 0$ it lies in an open set $U$ with $m^*(U \setminus E) \le \varepsilon$; the
measure-theoretic definition is null-measurability for Lebesgue measure ($E$ differs from a
measurable set by a subset of a null set). The two agree, for every outer regular,
$\sigma$-finite measure on a topological space, and so do the forms "a $G_\delta$ set minus a null
set" and "nearly contains a closed set".
