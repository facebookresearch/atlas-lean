# Inner approximation by closed sets

Let $\mu$ be a measure on a topological space $X$ whose Borel sets are measurable, and suppose
that $\mu$ is outer regular ($\mu(A) = \inf\{\mu(U) : U \supseteq A \text{ open}\}$ for measurable $A$)
and $\sigma$-finite; Lebesgue measure on $\mathbb{R}^d$ is the main example. Then $E \subseteq X$ is null-measurable if and only if for every $\varepsilon > 0$ there
is a closed set $F \subseteq E$ with $\mu(E \setminus F) \le \varepsilon$. It follows from outer
approximation applied to the complement of $E$.
