# Tao's definition of Lebesgue measurability implies null-measurability

Let $\mu$ be a measure on a topological space $X$ whose Borel sets are measurable, and let
$E \subseteq X$. If for every $\varepsilon > 0$ there is an open set $U \supseteq E$ with
$\mu(U \setminus E) \le \varepsilon$ (outer measure), then $E$ is null-measurable. No regularity
or finiteness of $\mu$ is needed.

For Lebesgue measure on $\mathbb{R}^d$ the hypothesis is Tao's definition of a Lebesgue
measurable set, and the conclusion is null-measurability.
