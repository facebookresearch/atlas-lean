# The graph of a measurable function is a null set

The graph $\{(x, f(x)) : x \in \mathbb{R}^d\}$ of a Borel measurable function
$f : \mathbb{R}^d \to \mathbb{R}$ is a Borel subset of $\mathbb{R}^{d+1}$ of Lebesgue measure $0$.

## Idea

Null sets are the sets measure theory ignores, and many proofs end by showing that an exceptional
set is one. Tonelli's theorem computes the measure of the graph as the integral over $x$ of the
measure of its vertical slice $\{f(x)\}$, a single point, so the measure is $0$; measurability of
$f$ makes the graph a Borel set, so that Tonelli's theorem applies.
