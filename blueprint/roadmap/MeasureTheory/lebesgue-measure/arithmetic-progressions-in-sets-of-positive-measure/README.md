# Three-term progressions in sets of positive measure

For every Borel set $A \subseteq \mathbb{R}$ of positive Lebesgue measure there are $x \in A$ and
$y > 0$ with $x + y \in A$ and $x - y \in A$.

## Idea

A set of positive measure is nearly an interval somewhere: by the Lebesgue density theorem there
is an interval $I$ in which $A$ fills a proportion of length greater than $3/4$. For $0 < y$ small
compared with the length of $I$, each of the sets $A \cap I$, $(A \cap I) - y$ and $(A \cap I) + y$
misses less than a third of $I$, so the three have a common point $x$; then $x$, $x + y$ and
$x - y$ lie in $A$. The same argument gives progressions of any finite length.
