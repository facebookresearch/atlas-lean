# Planar Falconer distance threshold

The planar distance threshold is the infimum, in $[0, \infty]$, of all $s \in [0, 2]$ such that every
compact set $E \subseteq \mathbb{R}^2$ of Hausdorff dimension greater than $s$ has a distance set
$\{|x - y| : x, y \in E\}$ of positive one-dimensional Lebesgue measure.

## Idea

The threshold is the critical dimension of the planar Falconer problem: above it every compact set
has a distance set of positive length, and below it this can fail. Falconer's conjecture is that it
equals $1$. The bounds represented on the other cards of this topic are the lower bound $1$, from
Falconer's examples, and the upper bounds $3/2$ (Falconer), $4/3$ (Wolff) and $5/4$ (Guth, Iosevich,
Ou and Wang). The basic facts here show that the threshold is a well-defined
number in $[0, 2]$, since $2$ qualifies because planar sets have dimension at most $2$. They also
show that the infimum is attained, and they relate it to its real-valued form.
