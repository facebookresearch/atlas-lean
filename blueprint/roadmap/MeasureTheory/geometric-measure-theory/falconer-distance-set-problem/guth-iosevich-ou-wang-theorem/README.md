# Guth–Iosevich–Ou–Wang distance set theorem

Every compact set $E \subseteq \mathbb{R}^2$ whose Hausdorff dimension is strictly greater than
$5/4$ has a distance set $\{|x - y| : x, y \in E\}$ of positive one-dimensional Lebesgue measure.

## Idea

Guth, Iosevich, Ou and Wang lowered the planar exponent from Wolff's $4/3$ to $5/4$. Instead of
considering all distances at once, they show that some point $x \in E$ already has a pinned
distance set $\{|x - y| : y \in E\}$ of positive measure, and the proof relies on decoupling
estimates from Fourier analysis. Equivalently, the planar threshold is at most
$5/4$, still above the conjectured value $1$.
