# Wolff's distance set theorem

Every compact set $E \subseteq \mathbb{R}^2$ whose Hausdorff dimension is greater than $4/3$ has a
distance set $\{|x - y| : x, y \in E\}$ of positive Lebesgue measure.

## Idea

Wolff improved Falconer's planar exponent $3/2$ to $4/3$ in 1999. The method is the same: the
distance set of $E$ has positive measure as soon as the circular means of the Fourier transform of a
measure on $E$ decay fast enough, on average, and Wolff proved a sharp estimate for this average
decay. Equivalently, the planar threshold is at most $4/3$.
