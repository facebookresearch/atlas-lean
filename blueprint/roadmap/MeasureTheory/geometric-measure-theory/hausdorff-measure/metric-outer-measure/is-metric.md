# Metric outer measure

Let $X$ be an extended metric space. An outer measure $\mu$ on $X$ is metric if
$\mu(s \cup t) = \mu(s) + \mu(t)$ for all metrically separated sets $s, t \subseteq X$, meaning that there is a
number $r > 0$ with $r \le \operatorname{edist}(x, y)$ for all $x \in s$ and $y \in t$.
