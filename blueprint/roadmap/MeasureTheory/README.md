# Measure Theory

Measure theory provides the language of size and integration underlying probability and modern analysis.

[Geometric measure theory](geometric-measure-theory/README.md), the largest field, is mostly the
[Falconer distance set problem](geometric-measure-theory/falconer-distance-set-problem/README.md) in the plane: the
infimum of the $s$ such that every compact $E \subseteq \mathbb{R}^2$ of Hausdorff dimension greater than $s$ has a
distance set of positive Lebesgue measure is at least $1$ and at most $3/2$ (both Falconer), $4/3$ (Wolff) and $5/4$
(Guth, Iosevich, Ou and Wang). By Moran's formula, a
[self-similar set](geometric-measure-theory/hausdorff-dimension-of-self-similar-sets/README.md) generated by $n$
similarities of ratio $\lambda$ under the open set condition has Hausdorff dimension $\log n / \log(1/\lambda)$.
[Measures and measurable sets](measures/README.md) run from Carathéodory's extension theorem to Vitali's nonmeasurable
set and the [Banach–Tarski paradox](measures/banach-tarski-paradox/README.md), and integration, Lebesgue spaces, Haar
measure and optimal transport make up most of the rest.
