# Unimodularity of GL(2, F)

Let $F$ be a field with a topology making it a topological ring, such that $GL(2, F)$ is locally
compact. Then the modular character of $GL(2, F)$ is identically $1$: the group is unimodular.

## Idea

A left Haar measure need not be right-invariant; the modular character measures the defect, and
a group is unimodular when it is trivial, so that left and right Haar measures agree. Abelian and
compact groups are unimodular, while the group of affine maps $x \mapsto ax + b$ of the line is
not. For $GL(2, \mathbb{R})$ a Haar measure is $|\det g|^{-2}\, dg$, where $dg$ is Lebesgue measure
on the four matrix entries, and it is visibly invariant under multiplication on either side.
Unimodularity makes a Haar measure invariant under inversion as well, which the other statements
record.
