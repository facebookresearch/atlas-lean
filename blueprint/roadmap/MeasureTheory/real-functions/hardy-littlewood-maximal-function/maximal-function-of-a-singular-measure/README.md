# The maximal function of a singular measure is infinite almost everywhere for that measure

Let $\mu$ be a Borel measure on $\mathbb{R}^n$ that is mutually singular with Lebesgue measure $m_n$,
and let $M_\mu(x) = \sup_{r > 0} \mu(B(x, r)) / m_n(B(x, r))$, over open balls. Then
$\mu(\{x : M_\mu(x) < \infty\}) = 0$.

## Idea

A maximal function records the largest average of a function or a measure over balls around a
point. A singular measure lives on a Lebesgue-null set, and the statement says that the supremum
over all radii of the ratio of $\mu$ to Lebesgue measure on balls, the maximal function of $\mu$, is
infinite $\mu$-almost everywhere. For a locally finite $\mu$ the differentiation theory of measures
says more: the ratio tends to infinity as the radius shrinks to $0$, at $\mu$-almost every point.
