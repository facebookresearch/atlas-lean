# The indicator of an interval agrees almost everywhere with no continuous function

There is no continuous function $f : \mathbb{R} \to \mathbb{R}$ that equals the indicator function
of $[0, 1]$ almost everywhere for Lebesgue measure.

## Idea

A continuous function equal to the indicator almost everywhere would take the value $1$ on a dense
subset of $(0, 1)$ and the value $0$ on a dense subset of $(1, 2)$, so by continuity
$f(1) = 1$ and $f(1) = 0$. The example separates two notions that sound alike. The indicator of
$[0, 1]$ is continuous almost everywhere, since it is continuous away from the two endpoints, but
it is not almost everywhere equal to a continuous function. The first notion is the one in
Lebesgue's criterion for Riemann integrability.
