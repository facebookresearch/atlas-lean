# The levelwise comparison on classes

Let `A` and `B` be commutative rings with `B` an `A`-algebra, `𝔭` an ideal
of `A`, and `n` a natural number. The `A`-linear isomorphism `B ⧸ (𝔭 B) ^ n
≃ B ⧸ 𝔭 ^ n • B` between the level-`n` quotient for the extended ideal `𝔭 B
= 𝔭.map (algebraMap A B)` and the level-`n` quotient for `𝔭` acting on the
`A`-module `B` sends the class of each `b ∈ B` to the class of the same
element `b`.
