# For an integral extension R ⊆ S with S an integral domain, R is a field if and only if S is

Let $R$ and $S$ be commutative rings with identity, where $S$ is an integral domain, and let $R \to S$ be an injective ring homomorphism such that $S$ is integral over $R$: every element of $S$ is a root of a monic polynomial with coefficients in $R$, mapped to $S$ by this homomorphism. Then $R$ is a field if and only if $S$ is a field.

## Sources

- David Eisenbud, Commutative Algebra with a View Toward Algebraic Geometry, Graduate Texts in Mathematics 150, Springer-Verlag, 1995.
