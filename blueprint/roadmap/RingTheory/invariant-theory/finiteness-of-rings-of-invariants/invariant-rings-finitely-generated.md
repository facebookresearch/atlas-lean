# Hilbert's fourteenth problem for linear algebraic groups

This is the proposition that for every $n$ and every Zariski closed subgroup $G \le \mathrm{GL}_n(\mathbb{C})$ (a linear algebraic group acting linearly), the ring of invariants $\mathbb{C}[x_1, \dots, x_n]^G = \{f : f(gx) = f(x) \text{ for all } g \in G\}$ is a finitely generated $\mathbb{C}$-algebra.

Source: D. Hilbert, *Mathematical problems* (Paris, 1900), Bull. Amer. Math. Soc. 8 (1902), 437–479, Problem 14.
