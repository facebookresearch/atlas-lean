# Linear change of variables by an invertible matrix

For an invertible complex $n \times n$ matrix $g$, the $\mathbb{C}$-algebra automorphism of $\mathbb{C}[x_1, \dots, x_n]$ given by $x_i \mapsto \sum_j g_{ij} x_j$, so that $f \mapsto (x \mapsto f(gx))$.

Source: D. Hilbert, *Mathematical problems* (Paris, 1900), Bull. Amer. Math. Soc. 8 (1902), 437–479, Problem 14.
