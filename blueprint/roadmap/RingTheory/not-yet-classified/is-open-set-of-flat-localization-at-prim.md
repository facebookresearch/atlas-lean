# Openness of the flat locus

For a finite type algebra `B` over a Noetherian ring `A`, the
set of primes of `B` at which `B` is flat over `A` is open.

## Sources

- [Stacks Project, Theorem 10.129.4 (Tag 00RC)](https://stacks.math.columbia.edu/tag/00RC), stated there for a finitely presented module over a finitely presented algebra.
