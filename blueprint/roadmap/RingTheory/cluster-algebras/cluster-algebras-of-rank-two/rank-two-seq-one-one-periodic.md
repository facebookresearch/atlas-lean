# Five-periodicity in type $A_2$

Let $(z_k)$ be the rank-two exchange recurrence with $b = c = 1$ over a field, and suppose that
every term $z_k$ is nonzero. Then $z_{k+5} = z_k$ for every $k$: the cluster variables of the
coefficient-free cluster algebra $\mathcal{A}(1, 1)$ repeat with period $5 = h + 2$, where
$h = 3$ is the Coxeter number of $A_2$. The nonvanishing hypothesis holds, for instance, for
positive real initial values (see [Positivity of the rank-two recurrence](rank-two-seq-pos.md)).
