# Cluster variables of type $A_2$

Let $(z_k)$ be the rank-two exchange recurrence with $b = c = 1$ over a field, with $z_0 = x$
and $z_1 = y$, and suppose that every term $z_k$ is nonzero. Then

$$z_2 = \frac{y + 1}{x}, \qquad z_3 = \frac{x + y + 1}{xy}, \qquad z_4 = \frac{x + 1}{y}.$$

These are the cluster variables of the coefficient-free cluster algebra $\mathcal{A}(1, 1)$ that
follow the initial cluster $(x, y)$.
