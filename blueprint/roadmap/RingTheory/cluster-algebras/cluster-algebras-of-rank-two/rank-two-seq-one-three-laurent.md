# Cluster variables of type $G_2$

Let $(z_k)$ be the rank-two exchange recurrence with $b = 1$ and $c = 3$ over a field, with
$z_0 = x$ and $z_1 = y$, and suppose that every term $z_k$ is nonzero. Then

$$z_2 = \frac{y^3 + 1}{x}, \qquad z_3 = \frac{x + y^3 + 1}{xy}, \qquad
z_4 = \frac{x^3 + 3x^2 + 3xy^3 + 3x + y^6 + 2y^3 + 1}{x^2 y^3},$$

$$z_5 = \frac{x^2 + 2x + y^3 + 1}{xy^2}, \qquad z_6 = \frac{x^3 + 3x^2 + 3x + y^3 + 1}{xy^3},
\qquad z_7 = \frac{x + 1}{y}.$$

These are the cluster variables of the coefficient-free cluster algebra $\mathcal{A}(1, 3)$ that
follow the initial cluster $(x, y)$; each is a Laurent polynomial with a monomial denominator.
