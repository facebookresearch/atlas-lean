# Finite type criterion for cluster algebras

For a skew-symmetrizable integer matrix $B$, the coefficient-free seed pattern through $((X_i), B)$
has finitely many cluster variables if and only if every matrix $B'$ obtained from $B$ by iterated
mutation satisfies $|b'_{ij} b'_{ji}| \le 3$ for all $i, j$ (Fomin and Zelevinsky, *Cluster algebras
II: Finite type classification*, Invent. Math. 154 (2003), Theorem 1.8, (ii) ⇔ (iii)). The source
theorem is for arbitrary coefficients and sign-skew-symmetric $B$; this is its coefficient-free,
skew-symmetrizable case.
