# Skew-symmetrizable integer matrix

An integer square matrix $B = (b_{ij})$ is skew-symmetrizable if there are positive integers $d_i$
with $d_i b_{ij} = -d_j b_{ji}$ for all $i, j$ (Fomin, Williams and Zelevinsky, *Introduction to
cluster algebras, Chapters 1–3*, arXiv:1608.05735v5, Definition 2.7.4).
