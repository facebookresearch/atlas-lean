# Matrix mutation preserves skew-symmetrizability

If positive integers $d_i$ satisfy $d_i b_{ij} = -d_j b_{ji}$ for all $i, j$, then they also
skew-symmetrize the mutation $\mu_k(B)$ of the integer square matrix $B$ in every direction $k$
(Fomin, Williams and Zelevinsky, *Introduction to cluster algebras, Chapters 1–3*,
arXiv:1608.05735v5, Exercise 2.7.7(1), square case).
