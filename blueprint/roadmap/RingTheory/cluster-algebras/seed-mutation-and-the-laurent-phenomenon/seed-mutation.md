# Seed mutation without frozen variables

For a cluster $x = (x_i)_{i \in n}$ in a field $K$ and an exchange matrix $B$, the mutation in
direction $k$ replaces $x_k$ by

$$x_k' = \frac{\prod_{b_{ik} > 0} x_i^{b_{ik}} + \prod_{b_{ik} < 0} x_i^{-b_{ik}}}{x_k}$$

and keeps the other cluster variables, while $B$ becomes $\mu_k(B)$ (Fomin, Williams and Zelevinsky,
*Introduction to cluster algebras, Chapters 1–3*, arXiv:1608.05735v5, Definition 3.1.3, exchange
relation (3.1.2), in the coefficient-free case $m = n$).
