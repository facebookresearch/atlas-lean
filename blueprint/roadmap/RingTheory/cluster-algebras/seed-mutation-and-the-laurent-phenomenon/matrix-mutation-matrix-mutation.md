# Matrix mutation is an involution

Mutating an integer square matrix $B$ twice in the same direction $k$ returns the original matrix:
$\mu_k(\mu_k(B)) = B$ (Fomin, Williams and Zelevinsky, *Introduction to cluster algebras, Chapters
1–3*, arXiv:1608.05735v5, Exercise 2.7.7(2)). The proof uses only formula (2.7.1), so it holds for
every integer square matrix, skew-symmetrizable or not.
