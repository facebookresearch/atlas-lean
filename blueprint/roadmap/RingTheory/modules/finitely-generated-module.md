# Finitely generated module

Let $R$ be a semiring and let $M$ be an $R$-module, with $M$ a commutative monoid under addition; modules over rings with identity, in particular vector spaces, are special cases. The module $M$ is *finitely generated* if there are finitely many elements $x_1, \dots, x_n \in M$ such that $M = Rx_1 + \cdots + Rx_n$, that is, every element of $M$ can be written as $r_1 x_1 + \cdots + r_n x_n$ for some $r_1, \dots, r_n \in R$. Equivalently, $M$ is the submodule spanned by a finite subset of $M$. The case $n = 0$ is allowed: the zero module is generated by the empty set.
