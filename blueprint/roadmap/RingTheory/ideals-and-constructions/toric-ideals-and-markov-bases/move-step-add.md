# Moves are translation invariant

Let $X$ be a set of cells, possibly infinite, and let $T$ assign to each cell $x$ a finitely
supported exponent vector $T(x) \in \mathbb{N}^{(J)}$, for a set $J$ of parameters. Tables of counts
are finitely supported maps $X \to \mathbb{N}$, moves are finitely supported maps
$X \to \mathbb{Z}$, and the sufficient statistic of a table $a$ is $T(a) = \sum_x a(x)\, T(x)$.
Steps of the moves chain are translation invariant: if one step of the family of moves $(f_i)$ leads
from the table $g$ to the table $h$, then one step leads from $g + c$ to $h + c$ for every table
$c$.
