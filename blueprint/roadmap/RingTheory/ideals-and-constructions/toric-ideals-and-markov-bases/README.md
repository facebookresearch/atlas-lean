# Toric ideals and Markov bases

Throughout, $X$ is a set of cells, possibly infinite, and $T$ assigns to each cell $x$ a finitely
supported vector $T(x) \in \mathbb{N}^{(J)}$ of nonnegative exponents. Tables of counts are finitely
supported maps $X \to \mathbb{N}$, moves are finitely supported maps $X \to \mathbb{Z}$, and the
sufficient statistic of a table $a$ is $T(a) = \sum_x a(x)\, T(x)$. For a field $k$, the toric ideal
$I_T$ is the kernel of the monomial map $k[X] \to k[t_j : j \in J]$, $x \mapsto t^{T(x)}$. It is
generated by binomials, and by the Diaconis–Sturmfels theorem the move binomials $x^{f^+} - x^{f^-}$
of a family of moves generate it exactly when the moves form a Markov basis, that is, connect every
fibre of the sufficient statistic, which is what a Metropolis chain for an exact conditional test
needs.
