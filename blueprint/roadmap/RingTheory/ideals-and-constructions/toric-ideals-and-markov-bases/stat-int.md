# Integer form of a sufficient statistic

Let $X$ be a set of cells, possibly infinite, and let $T$ assign to each cell $x$ a finitely
supported exponent vector $T(x) \in \mathbb{N}^{(J)}$, for a set $J$ of parameters. Tables of counts
are finitely supported maps $X \to \mathbb{N}$, moves are finitely supported maps
$X \to \mathbb{Z}$, and the sufficient statistic of a table $a$ is $T(a) = \sum_x a(x)\, T(x)$. The
integer form of $T$ regards each exponent vector $T(x) \in \mathbb{N}^{(J)}$ as an integer vector in
$\mathbb{Z}^{(J)}$, so that $\sum_x f(x)\, T(x) \in \mathbb{Z}^{(J)}$ is defined for every move $f$.
