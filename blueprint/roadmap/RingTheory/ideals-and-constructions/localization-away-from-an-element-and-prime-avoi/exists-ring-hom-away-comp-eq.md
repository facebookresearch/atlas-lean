# Induced map on localizations away from an element

Let `f : B → B'` be a homomorphism of commutative rings and `g ∈ B`. There
is a ring homomorphism `B[1/g] → B'[1/f(g)]` whose composite with the
localization map `B → B[1/g]` equals the composite of `f` with the
localization map `B' → B'[1/f(g)]`.
