# Fps lagrange burmann coeff'

Lagrange–Bürmann inversion formula, coefficient form, from the fixed-point equation alone:
if `A = X * subst A phi`, then for `n ≥ 1`,
`n * [X^n](subst A g) = [X^(n-1)](derivative g * phi ^ n)`.
