# Dedekind domains: PID iff trivial class group

A Dedekind domain $R$ is a principal ideal
domain if and only if its ideal class group is trivial.

## Sources

- A. V. Sutherland, *Number Theory I*, MIT 18.785 lecture notes (Fall 2021), Lecture 3, Corollary 3.15 (the second equivalence), https://ocw.mit.edu/courses/18-785-number-theory-i-fall-2021/.
