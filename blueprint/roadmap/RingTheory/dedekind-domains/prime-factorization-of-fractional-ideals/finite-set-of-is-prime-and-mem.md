# Finitely many primes contain a nonzero element

In a Dedekind domain $A$, every nonzero
element $a$ lies in only finitely many prime ideals of $A$.

## Sources

- A. V. Sutherland, *Number Theory I*, MIT 18.785 lecture notes (Fall 2021), Lecture 3, Lemma 3.6, https://ocw.mit.edu/courses/18-785-number-theory-i-fall-2021/.
