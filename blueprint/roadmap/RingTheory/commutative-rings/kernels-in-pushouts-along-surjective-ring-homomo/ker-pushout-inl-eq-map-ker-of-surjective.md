# The kernel of a base-changed surjection

Let `R,A,B,P` be commutative rings and `f : R → A`, `g : R → B`, `inl : A → P`, `inr : B → P`
be ring homomorphisms forming a pushout square in `CommRingCat`. If `g` is surjective, then
`RingHom.ker inl = (RingHom.ker g).map f`. This kernel is the ideal generated by `{f r | g r =
0}`.
