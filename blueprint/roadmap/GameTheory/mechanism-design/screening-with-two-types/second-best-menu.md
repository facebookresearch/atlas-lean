# Second-best menu in the linear-quadratic two-type model

For types `θ_L`, `θ_H` and type probabilities `p_L`, `p_H`, the second-best menu of the
linear-quadratic two-type model is `q_L = θ_L - (p_H / p_L)(θ_H - θ_L)`, `t_L = θ_L q_L`,
`q_H = θ_H`, `t_H = θ_H q_H - (θ_H - θ_L) q_L` (with `p_H / p_L` read as `0` when `p_L = 0`).
