# Second-best menu is individually rational and incentive compatible

For types `θ_L < θ_H` and probabilities `p_L > 0`, `p_H ≥ 0` in the regime
`p_H (θ_H - θ_L) ≤ p_L θ_L` (which makes `q_L ≥ 0`), the second-best menu
`q_L = θ_L - (p_H / p_L)(θ_H - θ_L)`, `t_L = θ_L q_L`, `q_H = θ_H`,
`t_H = θ_H q_H - (θ_H - θ_L) q_L` is individually rational (`θ_L q_L - t_L ≥ 0`,
`θ_H q_H - t_H ≥ 0`) and incentive compatible (each type weakly prefers its own contract to the
other's).
