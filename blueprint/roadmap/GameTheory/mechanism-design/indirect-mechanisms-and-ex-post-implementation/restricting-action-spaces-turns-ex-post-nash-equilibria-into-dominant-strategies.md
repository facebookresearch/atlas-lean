# Restricting action spaces turns ex-post Nash equilibria into dominant strategies

Let $s$ be an ex-post Nash equilibrium of a game with incomplete information. In the game obtained by restricting each player's action space to the range $\{s_i(t_i) : t_i \in T_i\}$, the profile $s$ is a dominant-strategy equilibrium.

## Proof sketch

In the restricted game every opponent action profile is $s_{-i}(t_{-i})$ for some types, against which $s_i(t_i)$ is a best response by the ex-post condition.
