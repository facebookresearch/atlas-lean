# Truthful optimal makespan scheduling on related machines

On uniformly related machines with private speeds, the work rule that selects, among makespan-optimal assignments, the lexicographically optimal one with respect to a fixed machine order is antitone. With Archer–Tardos payments it yields a truthful, individually rational mechanism that minimizes makespan exactly (ignoring computational cost).

## Proof sketch

If a machine slows down, the lexicographic tie-breaking among optimal schedules can only move work away from it, which is antitonicity; truthfulness follows from the characterization.
