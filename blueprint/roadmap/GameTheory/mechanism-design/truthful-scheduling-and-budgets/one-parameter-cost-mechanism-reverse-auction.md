# One-parameter cost mechanism (reverse auction)

In a *one-parameter cost environment* each agent $i$ has a private unit cost $c_i > 0$, the mechanism assigns work $w_i(c) \ge 0$ and pays $P_i(c)$, and agent $i$'s utility is $P_i(c) - c_i w_i(c)$. The work rule is *antitone* if increasing an agent's own reported cost never increases its assigned work. Scheduling on uniformly related machines is the case $c_i = 1/s_i$, with work the total weight assigned.
