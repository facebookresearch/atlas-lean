# Strategy-proof mechanisms are Bayesian incentive compatible

Let $I$ be a finite set of agents with finite type sets $\Theta_i$ and an outcome set $O$, in a
private-values model: agent $i$'s utility $w_i(\theta_i, o)$ depends only on its own type. A
dominant-strategy incentive-compatible direct mechanism $f : \prod_i \Theta_i \to O$ is Bayesian incentive
compatible, with the utilities $u_i(\theta, o) = w_i(\theta_i, o)$, for every prior $p$ that is a
probability distribution on type profiles.
