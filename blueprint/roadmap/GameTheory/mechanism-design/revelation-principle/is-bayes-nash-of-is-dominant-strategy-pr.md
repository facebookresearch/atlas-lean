# Dominant strategies are Bayesian Nash

Let $I$ be a finite set of agents with finite type sets $\Theta_i$, action sets $X_i$, an outcome set $O$ and
a mechanism $g : \prod_i X_i \to O$, in a private-values model: agent $i$'s utility $w_i(\theta_i, o)$
depends only on its own type. A profile $s$ of dominant strategies in $g$ is a Bayesian Nash equilibrium of
$g$, with the utilities $u_i(\theta, o) = w_i(\theta_i, o)$, for every prior $p$ that is a probability
distribution on type profiles.
