# Pivot terms independent of the own report

Throughout, $I$ is a finite set of agents and $A$ a set of alternatives; a valuation profile $v = (v_i)_{i \in I}$ gives each agent a valuation $v_i : A \to \mathbb{R}$, and $(w, v_{-i})$ denotes the profile $v$ with $v_i$ replaced by $w$.
A family $(h_i)_{i \in I}$ of pivot terms, each a real function of profiles, does not depend on the agents'
own reports if $h_i(w, v_{-i}) = h_i(v)$ for every agent $i$, every profile $v$ and every valuation
$w : A \to \mathbb{R}$: each $h_i(v)$ depends only on $v_{-i}$.
