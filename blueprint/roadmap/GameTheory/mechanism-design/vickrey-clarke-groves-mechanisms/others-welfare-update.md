# The others' welfare ignores the own valuation

Let $I$ be a finite set of agents and $A$ a set of alternatives. For every valuation profile
$v = (v_i)_{i \in I}$ with $v_i : A \to \mathbb{R}$, every agent $i$, every valuation $w : A \to \mathbb{R}$
and every alternative $a$, replacing $v_i$ by $w$ does not change the welfare of the agents other than $i$:
$W_{-i}((w, v_{-i}), a) = W_{-i}(v, a)$, where $(w, v_{-i})$ is the profile $v$ with $v_i$ replaced by $w$.
