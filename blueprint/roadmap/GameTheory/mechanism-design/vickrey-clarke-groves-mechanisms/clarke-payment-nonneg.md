# No positive transfers

Let $I$ be a finite set of agents and $A$ a finite nonempty set of alternatives. For every alternative rule
$f$, every valuation profile $v$ and every agent $i$, the Groves payment with the Clarke pivot term is
nonnegative:

$$p_i(v) = \max_{b \in A} W_{-i}(v, b) - W_{-i}(v, f(v)) \ge 0,$$

so no agent is ever paid (Nisan 2007, Lemma 9.20, first part).

## Sources

- N. Nisan, "Introduction to mechanism design (for computer scientists)", Chapter 9 of N. Nisan, T. Roughgarden, É. Tardos and V. V. Vazirani (eds.), *Algorithmic Game Theory*, Cambridge University Press, 2007, Lemma 9.20.
