# Welfare of the others

Let $I$ be a finite set of agents and $A$ a set of alternatives. For a valuation profile
$v = (v_i)_{i \in I}$ with $v_i : A \to \mathbb{R}$, an agent $i$ and an alternative $a \in A$, the welfare
of the others is the total value of $a$ for the agents other than $i$:

$$W_{-i}(v, a) = \sum_{j \in I,\ j \neq i} v_j(a).$$
