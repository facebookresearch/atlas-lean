# The Clarke pivot term ignores the own report

Let $I$ be a finite set of agents and $A$ a finite nonempty set of alternatives. The Clarke pivot terms
$h_i(v) = \max_{b \in A} \sum_{j \neq i} v_j(b)$ do not depend on the agents' own reports:
$h_i(w, v_{-i}) = h_i(v)$ for every agent $i$, every valuation profile $v$ and every valuation
$w : A \to \mathbb{R}$, where $(w, v_{-i})$ is $v$ with $v_i$ replaced by $w$.
