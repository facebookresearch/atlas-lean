# Welfare decomposition

Let $I$ be a finite set of agents and $A$ a set of alternatives. For every valuation profile
$v = (v_i)_{i \in I}$ with $v_i : A \to \mathbb{R}$, every agent $i$ and every alternative $a$, the social
welfare is agent $i$'s value plus the welfare of the others:
$W(v, a) = v_i(a) + W_{-i}(v, a)$.
