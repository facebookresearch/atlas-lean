# VCG with Clarke pivot payments is incentive compatible

Let $I$ be a finite set of agents and $A$ a finite nonempty set of alternatives, with real valuations. If
the alternative rule $f$ chooses a welfare-maximizing alternative for every reported profile
($W(v, a) \le W(v, f(v))$ for all $v$ and $a$), then the mechanism that uses $f$ and charges the Groves
payments with the Clarke pivot terms, $p_i(v) = \max_{b \in A} W_{-i}(v, b) - W_{-i}(v, f(v))$, is
incentive compatible.
