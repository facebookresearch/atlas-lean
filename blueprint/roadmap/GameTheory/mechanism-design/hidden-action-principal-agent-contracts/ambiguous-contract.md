# Ambiguous contract and max-min agent

In a principal-agent instance, an ambiguous contract is a finite set $\tau = \{t^1, \dots, t^k\}$ of contracts. The agent, who is ambiguity averse, evaluates action $i$ by its worst-case utility $\min_{\ell} \bigl(T_i(t^\ell) - c_i\bigr)$ and chooses an action maximizing it; the principal then selects which contract of $\tau$ to apply, and $\tau$ must be consistent: every contract of $\tau$ yields the same expected payment $T_i(t^\ell)$ for the action $i$ the agent chooses, so the principal is indifferent among them. The principal's utility is $R_i - T_i(t^\ell)$.
