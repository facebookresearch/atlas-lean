# Linear contract and its critical values

In a principal-agent instance, the linear contract with parameter $\alpha \in [0, 1]$ pays $t_j = \alpha r_j$ on outcome $j$. Under it the agent's utility from action $i$ is $\alpha R_i - c_i$ and the principal's is $(1 - \alpha) R_i$. The agent's best-response correspondence is constant on the open intervals between finitely many critical values $0 \le \alpha_1 < \alpha_2 < \dots < \alpha_K \le 1$, the breakpoints of the upper envelope $\alpha \mapsto \max_i (\alpha R_i - c_i)$.
