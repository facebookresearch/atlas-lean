# Option sets are closed intervals; Ching's peaks-only theorem

For a strategy-proof rule on single-peaked preferences over $[a, b]$, the option set of an agent (the set of outcomes it can induce given the others' reports) is closed; for strategy-proof onto rules it is a closed interval $[l, u]$ and the outcome is the point of $[l, u]$ closest to the agent's peak. Consequently every strategy-proof onto rule is peaks-only: the outcome depends only on the reported peaks.

## Proof sketch

Strategy-proofness means the agent gets its favourite point of its option set; single-peakedness makes that the closest point, which depends only on the peak once the option set is an interval.
