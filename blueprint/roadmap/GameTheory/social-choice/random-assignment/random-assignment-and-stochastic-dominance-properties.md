# Random assignment and stochastic-dominance properties

With $n$ agents holding strict preferences over $n$ objects, a *random assignment* is a bistochastic $n \times n$ matrix $P$, row $i$ giving agent $i$'s lottery over objects. Agent $i$'s lottery $P_i$ *sd-dominates* $Q_i$ if for every object $o$ the probability of getting an object at least as good as $o$ is at least as large under $P_i$. A random assignment is *sd-efficient* if no other assignment sd-dominates it for all agents with strict dominance for some; a rule is *sd-envy-free* if each agent's lottery sd-dominates every other agent's lottery, satisfies *equal treatment of equals* if agents with identical preferences get identical lotteries, and is *sd-strategy-proof* if the truthful lottery sd-dominates the lottery from any misreport.
