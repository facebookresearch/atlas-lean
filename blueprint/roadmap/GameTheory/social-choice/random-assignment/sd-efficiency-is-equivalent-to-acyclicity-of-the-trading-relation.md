# sd-efficiency is equivalent to acyclicity of the trading relation

A random assignment $P$ is sd-efficient if and only if the relation "object $a$ is traded to object $b$", defined to hold when some agent prefers $a$ to $b$ while holding positive probability of $b$, has no cycle. Every sd-efficient random assignment is ex-post efficient.

## Proof sketch

A cycle allows a small simultaneous exchange of probability shares along it that sd-improves every participating agent. Conversely, if the relation is acyclic, objects can be ordered so that any sd-improvement would have to move probability against the order, which is impossible.
