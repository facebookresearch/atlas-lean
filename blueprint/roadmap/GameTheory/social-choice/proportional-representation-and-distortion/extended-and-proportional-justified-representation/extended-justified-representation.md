# Extended justified representation

An approval election consists of a finite set $N$ of $n$ voters, a finite set $C$ of candidates, approval ballots $A_i \subseteq C$ for $i \in N$, and a committee size $k$ with $1 \le k \le \lvert C \rvert$; a committee is a set $W \subseteq C$ with $\lvert W \rvert = k$. A committee $W$ provides extended justified representation (EJR) if for every $\ell \in \{1, \dots, k\}$ and every $\ell$-cohesive group $N'$ there is a voter $i \in N'$ with $\lvert A_i \cap W \rvert \ge \ell$.
