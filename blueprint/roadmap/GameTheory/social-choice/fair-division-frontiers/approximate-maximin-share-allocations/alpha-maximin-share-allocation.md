# Alpha-maximin share allocation

Throughout, $N = \{1, \dots, n\}$ is a finite set of agents and $M$ a finite set of indivisible goods; agent $i$ has an additive valuation $v_i(S) = \sum_{g \in S} v_i(g)$ with $v_i(g) \ge 0$. The maximin share of agent $i$ is $\mu_i = \max_{(P_1, \dots, P_n)} \min_k v_i(P_k)$, the maximum over partitions of $M$ into $n$ bundles. For $\alpha \in (0, 1]$, a complete allocation $X$ is $\alpha$-MMS if $v_i(X_i) \ge \alpha\, \mu_i$ for every agent $i$; it is MMS if it is $1$-MMS.
