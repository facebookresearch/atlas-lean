# Binary additive valuations

Throughout, $N = \{1, \dots, n\}$ is a finite set of agents and $M$ a finite set of indivisible goods; agent $i$ has an additive valuation $v_i(S) = \sum_{g \in S} v_i(g)$ with $v_i(g) \ge 0$. The valuations are binary (dichotomous) if $v_i(g) \in \{0, 1\}$ for every agent $i$ and good $g$; then $v_i(S) = \lvert S \cap D_i \rvert$ where $D_i = \{ g : v_i(g) = 1 \}$ is the set of goods agent $i$ desires. A binary instance is equivalently a bipartite graph between agents and goods, and an allocation gives each agent the number of her desired goods she receives.
