# Degree structure of the Lemke–Howson graph

Suppose both systems in the Lemke–Howson graph are nondegenerate (each vertex of the $n$-dimensional polyhedron has exactly $n$ tight rows) and bounded. Then in the Lemke–Howson graph for missing label $k$, every completely labelled vertex pair has degree $1$ and every other node has degree $2$. Consequently the number of completely labelled vertex pairs is even.

## Proof sketch

A completely labelled pair has exactly one way to drop label $k$. A $k$-almost completely labelled pair that is not completely labelled has exactly one duplicate label, and dropping either occurrence gives exactly two neighbours. A finite graph with all degrees in $\{1,2\}$ has an even number of degree-one nodes.
