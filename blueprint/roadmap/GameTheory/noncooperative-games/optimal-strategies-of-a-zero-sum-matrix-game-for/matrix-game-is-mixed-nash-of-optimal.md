# Optimal strategies of a finite zero-sum matrix game form a mixed Nash equilibrium

Let `A` be an `m × n` real matrix with `m ≥ 1` and `n ≥ 1`, viewed as a two-player zero-sum game. If `p` is a maximin strategy of the row player and `q` a minimax strategy of the column player, then the pair `(p, q)` is a mixed Nash equilibrium of the zero-sum game with payoffs `A` and `-A`.
