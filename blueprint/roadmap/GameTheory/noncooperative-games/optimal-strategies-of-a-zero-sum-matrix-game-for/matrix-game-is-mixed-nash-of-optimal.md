# Optimal strategies of a finite zero-sum matrix game form a mixed Nash equilibrium

Let $A$ be an $m \times n$ real matrix, read as the zero-sum game in which the row player, playing the mixed strategy $p \in \Delta_m$ against the column player's $q \in \Delta_n$, receives $p^{\mathsf T} A q$ and the column player pays it; $\Delta_k$ is the set of probability vectors in $\mathbb{R}^k$, which is empty when $k = 0$. Let $m \ge 1$ and $n \ge 1$. If $p$ is a [maximin strategy](is-maximin-strategy.md) and $q$ a [minimax strategy](is-minimax-strategy.md), then $(p, q)$ is a mixed Nash equilibrium of the [two-player game](zero-sum-payoffs.md) with payoffs $A$ and $-A$. The game has a value by von Neumann's minimax theorem, so [optimal strategies form a mixed Nash equilibrium](is-mixed-nash-of-optimal-of-value-eq.md) applies.
