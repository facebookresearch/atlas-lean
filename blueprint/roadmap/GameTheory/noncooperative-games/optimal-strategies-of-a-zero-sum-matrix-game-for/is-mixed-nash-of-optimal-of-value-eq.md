# Optimal strategies form a mixed Nash equilibrium

Let `A` be an `m × n` real matrix game that has a value (`sup_p inf_q pᵀ A q = inf_q sup_p pᵀ A q`). If `p` is a maximin strategy and `q` a minimax strategy, then `(p, q)` is a mixed Nash equilibrium of the two-player game with payoffs `A` and `-A`.
