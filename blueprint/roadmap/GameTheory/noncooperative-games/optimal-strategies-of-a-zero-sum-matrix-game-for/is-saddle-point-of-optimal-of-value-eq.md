# Optimal strategies form a saddle point

Let `A` be an `m × n` real matrix game that has a value: `sup_p inf_q pᵀ A q = inf_q sup_p pᵀ A q` over mixed strategies. If `p` is a maximin strategy and `q` a minimax strategy, then `(p, q)` is a saddle point: `p'ᵀ A q ≤ pᵀ A q` for every mixed row strategy `p'`, and `pᵀ A q ≤ pᵀ A q'` for every mixed column strategy `q'`.
