# Fair cost-sharing game

In the fair cost-sharing network design game, player $i$ chooses a strategy $a \in S_i$ that uses
a set $R_i(a)$ of edges, every edge $e$ has a cost $c_e \ge 0$, and the cost of each edge is
split equally among the players using it: player $i$ pays $\sum_{e \in R_i(s_i)} c_e / n_e(s)$.
In the network design setting $S_i$ is the set of $s_i$–$t_i$ paths of a graph.
