# Mossel–Roch: local submodularity implies global submodularity

In the general threshold model, if every local threshold function $g_v$ is monotone and submodular, then the influence function $\sigma$ is monotone and submodular.

## Proof sketch

Mossel and Roch couple the processes for nested seed sets through a time-layered antisense construction that reduces global submodularity to local submodularity at each vertex and each step.
