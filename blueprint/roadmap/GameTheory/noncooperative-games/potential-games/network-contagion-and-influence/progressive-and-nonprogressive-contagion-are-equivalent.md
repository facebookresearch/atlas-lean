# Progressive and nonprogressive contagion are equivalent

For a locally finite graph and $q \le 1$, there is a finite set contagious under the best-response dynamics $h_q$ if and only if there is a finite set contagious under the progressive dynamics $\bar h_q$.

## Proof sketch

A progressive contagious set yields, after finitely many steps, a finite set (discarding isolated vertices) that is closed under $h_q$ and keeps growing; conversely nonprogressive contagion implies progressive contagion since $h_q(S) \subseteq \bar h_q(S)$ and the progressive dynamics are monotone.
