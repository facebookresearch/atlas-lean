# Congestion game

A congestion game has players $i \in I$, a set $R$ of resources (finite in what follows), for every player a set
$S_i$ of strategies, each strategy $a$ using a set $R_i(a) \subseteq R$ of resources, and for every
resource $e$ a delay function $d_e : \mathbb N \to \mathbb R$: when $n$ players use $e$, each of
them pays $d_e(n)$ for it.

## Sources

- R. W. Rosenthal, "A class of games possessing pure-strategy Nash equilibria", Int. J. Game Theory 2 (1973), 65–67.
