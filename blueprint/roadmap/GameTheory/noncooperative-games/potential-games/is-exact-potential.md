# Exact potential

A function $\Phi$ on strategy profiles is an exact potential for the costs $c_i$ if every
unilateral deviation changes the deviating player's cost by exactly the change in $\Phi$:

$$c_i(a, s_{-i}) - c_i(s) = \Phi(a, s_{-i}) - \Phi(s)$$

for every profile $s$, player $i$ and strategy $a \in S_i$. A game with an exact potential is an
(exact) potential game.

## Sources

- D. Monderer and L. S. Shapley, "Potential games", Games Econom. Behav. 14 (1996), 124–143, §2.
