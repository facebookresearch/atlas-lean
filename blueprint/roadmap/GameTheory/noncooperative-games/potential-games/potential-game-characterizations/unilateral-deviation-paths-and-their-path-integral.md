# Unilateral deviation paths and their path integral

A *unilateral path* in a game is a finite sequence of profiles $\gamma = (s^0, s^1, \dots, s^m)$ in which consecutive profiles differ in the strategy of exactly one player $i_k$. Its *path integral* is $I(\gamma) = \sum_{k=1}^m \bigl(c_{i_k}(s^k) - c_{i_k}(s^{k-1})\bigr)$. The path is *closed* if $s^m = s^0$ and *simple closed* if in addition $s^0, \dots, s^{m-1}$ are distinct.
