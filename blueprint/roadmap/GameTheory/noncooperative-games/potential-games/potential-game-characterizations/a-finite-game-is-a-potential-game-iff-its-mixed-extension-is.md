# A finite game is a potential game iff its mixed extension is

Let $G$ be a finite game and $w$ any real weight vector. Then $G$ admits a $w$-potential if and only if its mixed extension, the game on products of simplices with expected costs, admits a $w$-potential. In the forward direction the multilinear extension $\bar\Phi(p) = \sum_s \bigl(\prod_i p_i(s_i)\bigr) \Phi(s)$ is a $w$-potential of the mixed extension; the same holds for exact potentials.

## Proof sketch

Expected costs and $\bar\Phi$ are both affine in each player's mixed strategy, so the potential identity for pure deviations extends by linearity. Restricting a potential of the mixed extension to pure profiles gives the converse.
