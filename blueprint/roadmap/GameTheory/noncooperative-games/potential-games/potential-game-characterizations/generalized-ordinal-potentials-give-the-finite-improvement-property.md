# Generalized ordinal potentials give the finite improvement property

A game has the finite improvement property (no infinite sequence of strictly improving unilateral deviations) if and only if the improvement relation is well founded. Every finite game with a generalized ordinal potential has the finite improvement property, every finite game with the finite improvement property has a pure Nash equilibrium reachable from every profile by improvement steps, and a $w$-potential with all $w_i > 0$ is an ordinal potential.

## Proof sketch

Along an improvement path the potential strictly decreases, and a finite game has finitely many profiles, so no path is infinite. The last profile of a maximal improvement path is a pure Nash equilibrium.
