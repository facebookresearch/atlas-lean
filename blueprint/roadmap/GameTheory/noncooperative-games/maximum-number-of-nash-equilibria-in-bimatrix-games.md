# Maximum number of Nash equilibria in bimatrix games

This node records a research direction: the sharp asymptotic growth, as n tends to infinity, of the largest number of Nash equilibria of a nondegenerate n × n bimatrix game.

## What would settle it

Prove an upper bound on the number of equilibria valid for every nondegenerate n × n game, and a family of nondegenerate games whose number of equilibria matches it asymptotically. Nondegeneracy is essential: degenerate games can have infinitely many equilibria. A small-n statement does not settle the asymptotic question.

## Status

No cited source poses this question in the form above; it is a research direction motivated by the cited results. This page does not certify the status or novelty of any particular formulation.

Ickstadt, Theobald and von Stengel recall the Quint–Shubik conjecture that a nondegenerate n × n game has at most 2ⁿ − 1 Nash equilibria, true for n ≤ 4 and false for n ≥ 6, and prove it for n = 5 through a stable-set bound for the graphs of the associated polytopes.
