# A pure Nash equilibrium is a correlated equilibrium

If $s^\circ$ is a pure Nash equilibrium, the point mass at $s^\circ$ is a correlated equilibrium:
the only nonzero term of each correlated equilibrium sum is
$c_i(s^\circ) - c_i(k, s^\circ_{-i}) \le 0$.
