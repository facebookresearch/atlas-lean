# The set of correlated equilibria is compact

For every $\varepsilon$, the set of correlated $\varepsilon$-equilibria is compact: it is a closed
subset of the simplex of probability distributions on the finite set of profiles. Together with
convexity, this makes it a convex polytope, cut out of the simplex by finitely many linear
inequalities. When every action set is nonempty, it is nonempty for $\varepsilon \ge 0$: it contains the Nash equilibria, which
exist by Nash's theorem, or directly by linear duality as in Hart and Schmeidler 1989.
