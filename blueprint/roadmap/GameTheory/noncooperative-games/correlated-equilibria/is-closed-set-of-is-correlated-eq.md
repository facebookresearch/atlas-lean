# The set of correlated equilibria is closed

For every $\varepsilon$, the set of correlated $\varepsilon$-equilibria is closed in
$\mathbb R^S$, as an intersection of finitely many closed half-spaces and hyperplanes.

## Sources

- S. Hart and A. Mas-Colell, "A simple adaptive procedure leading to correlated equilibrium", Econometrica 68(5) (2000), 1127–1150, §2.
