# Correlated equilibria are exactly the distributions of Bayes-rational play

A distribution $\psi$ on the action profiles of a finite game is a correlated equilibrium if and
only if there exist a finite set $\Theta$ of states, a common prior $p$ on $\Theta$, information
partitions $\mathcal P_i$ and an action profile $s : \Theta \to \prod_i S_i$, with each $s_i$
constant on the cells of $\mathcal P_i$, such that every player is Bayes rational at every state
and $\psi$ is the distribution of $s$ under $p$.

One direction is Aumann's Main Theorem, the other his converse. In Aumann's words, "under
Bayesian rationality, the set of all information systems corresponds precisely to the set of all
correlated equilibria".
