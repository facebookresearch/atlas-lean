# The set of correlated equilibria is convex

For every $\varepsilon$, the set of correlated $\varepsilon$-equilibria is convex: the conditions
$\psi \ge 0$, $\sum_s \psi(s) = 1$ and the correlated equilibrium inequalities are all linear in
$\psi$.

## Sources

- S. Hart and A. Mas-Colell, "A simple adaptive procedure leading to correlated equilibrium", Econometrica 68(5) (2000), 1127–1150, §2 ("the set of correlated equilibria is nonempty, closed and convex") and §1
  ("a convex polytope").
