# Atomic congestion games with affine delays

In an atomic congestion game each player is a unit of traffic. With affine delays the game is $(5/3, 1/3)$-smooth, so pure Nash equilibria, coarse correlated equilibria and no-regret play all cost at most $5/2$ times the optimum, against $4/3$ for nonatomic routing.
