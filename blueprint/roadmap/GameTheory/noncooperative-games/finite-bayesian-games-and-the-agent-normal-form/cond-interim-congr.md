# Cond Interim congr

For a finite Bayesian game, a player `i` and a type `θᵢ` of `i`, if two strategy profiles `s₁` and `s₂` realise the same action vector, `(j ↦ s₁ j (θ j)) = (j ↦ s₂ j (θ j))`, at every type profile `θ` with `θ i = θᵢ`, then player `i`'s ex-interim utility at type `θᵢ` is the same under `s₁` and `s₂`.
