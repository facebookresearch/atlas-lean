# Agent dev agree

Let `s` give each player `j` a plan `s j : Θ j → X j` from types to actions, and fix a player `i`, a type `θᵢ` of `i` and an action `t`. Compare two deviations: in the agent normal form, only the type-agent `(i, θᵢ)` switches to `t`; in the plan view, player `i` switches to the constant plan `t`. For every type profile `θ` with `θ i = θᵢ`, the two deviations realise the same action vector `j ↦ s' j (θ j)`.
