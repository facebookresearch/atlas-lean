# Interdependent security game

In an *interdependent security* game each agent $i$ decides whether to invest in protection at cost $c_i$. An unprotected agent suffers a direct disaster with probability $p_i$; independently, each unprotected peer $j$ transmits a disaster to $i$ with probability $q_{ji}$, which affects $i$ whether or not it invested; losses are $L_i$ and are non-additive (a disaster happens at most once). Agent $i$ minimizes expected loss plus investment cost.
