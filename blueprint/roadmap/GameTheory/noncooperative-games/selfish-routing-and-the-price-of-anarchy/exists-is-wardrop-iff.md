# Wardrop equilibria exist exactly at admissible demands

Let `N` be a routing instance with finitely many edges, finitely many paths and latency functions that are continuous on `[0, ∞)`. For a demand vector `r`, some flow that is feasible for `r` is a Wardrop equilibrium if and only if `r i ≥ 0` for every commodity `i` and `r i = 0` for every commodity that no path serves. Under continuity, then, an equilibrium exists exactly when a feasible flow does.
