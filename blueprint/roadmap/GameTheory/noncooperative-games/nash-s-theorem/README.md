# Nash's theorem

Every finite game has a Nash equilibrium in mixed strategies. The two-player zero-sum case is von
Neumann's minimax theorem; potential games even have pure equilibria. The theorem is proved from
Brouwer's fixed-point theorem for products of simplices, by Nash's 1951 argument.
