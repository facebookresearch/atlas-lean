# Player-symmetric game and symmetric equilibrium

A finite game with players $I$ and a common action set $S_i = X$ is *symmetric* if $c_i(s \circ \pi) = c_{\pi(i)}(s)$ for every permutation $\pi$ of $I$ and every profile $s : I \to X$. A mixed profile is *symmetric* if all players use the same mixed strategy. A bimatrix game $(A, B)$ on a common strategy set is symmetric when $B = A^\top$, and $x$ is a *symmetric Nash equilibrium* if $(x, x)$ is a Nash equilibrium.
