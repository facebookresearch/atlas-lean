# Nash's symmetric equilibrium theorem

Every finite symmetric game with a nonempty common action set has a symmetric mixed Nash equilibrium: there is a mixed strategy $x$ such that the profile in which every player plays $x$ is a mixed Nash equilibrium. In particular every symmetric bimatrix game has a symmetric Nash equilibrium.

## Proof sketch

Symmetry makes Nash's improvement map commute with the permutation action, so it maps the diagonal of identical mixed strategies into itself; Brouwer's fixed point theorem on that single simplex gives a symmetric fixed point, which is an equilibrium.
