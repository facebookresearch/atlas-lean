# Local neighbourhood equivalence characterizes payoff equivalence in graphical games

If $\sigma$ and $\tau$ are locally neighbourhood equivalent with respect to $G$, then every graphical game on $G$ gives every player the same expected payoff under $\sigma$ as under $\tau$. Conversely, if $\sigma$ and $\tau$ are not locally neighbourhood equivalent, there is a graphical game on $G$ with payoffs in $\{0, 1\}$ in which some player's expected payoff differs under $\sigma$ and $\tau$.

## Proof sketch

Expected payoffs of player $i$ depend only on the $N[i]$-marginal. If marginals differ at some neighbourhood profile, the indicator of that profile as player $i$'s payoff separates the two distributions.
