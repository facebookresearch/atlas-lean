# Exists is Mixed Nash of brouwer

Nash's theorem, assuming Brouwer's fixed-point theorem: let finitely many players each have a finite nonempty set of actions and payoff functions `u`. Suppose every function from profiles of real vectors to themselves that is continuous on the set of profiles of probability vectors and maps that set into itself has a fixed point in it, which is Brouwer's theorem for this product of simplices. Then the game has a mixed Nash equilibrium.
