# Perfect recall

For a node $u$ and player $i$, the *sequence* $\sigma_i(u)$ is the list of pairs (information set of $i$, choice taken) on the path from the root to $u$. Player $i$ has *perfect recall* if any two nodes in the same information set $h \in H_i$ have the same sequence $\sigma_i$; equivalently, player $i$ never forgets its own earlier information and choices. Under perfect recall each information set $h$ has a unique preceding sequence $\sigma_h$.
