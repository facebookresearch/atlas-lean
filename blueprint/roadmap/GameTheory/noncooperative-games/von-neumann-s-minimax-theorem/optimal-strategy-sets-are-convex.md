# Optimal strategy sets of a finite zero-sum game are convex polytopes

In a finite two-player zero-sum game with payoff matrix $A$ ($m \times n$, row player maximizing) and value $v$, the set of optimal (maximin) mixed strategies of the row player is $\{x \in \Delta_m : x^{\mathsf T}Ae_j \ge v \text{ for } j = 1, \dots, n\}$, the intersection of the simplex with $n$ closed half-spaces. It is therefore a convex polytope, and it is nonempty by the minimax theorem; the same holds for the column player. Any convex combination of optimal strategies is optimal.

## Proof depends on

- [Von Neumann's minimax theorem](matrix-game-minimax.md): existence of optimal strategies and the value.
