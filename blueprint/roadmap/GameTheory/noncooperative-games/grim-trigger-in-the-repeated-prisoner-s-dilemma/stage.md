# Stage

A player's stage payoff from their own action `me` and the opponent's action `other`
(`true` = cooperate, `false` = defect), own action first:

| own action | opponent's action | stage payoff |
|---|---|---|
| cooperate | cooperate | reward |
| cooperate | defect | sucker |
| defect | cooperate | temptation |
| defect | defect | punishment |
