# Is Simplex

A function `p : K → ℝ` lies in the probability simplex when it is the weight function of a point of the standard simplex on `K`: finitely supported nonnegative weights summing to one. The action type `K` need not be finite; a point mass at one action is an example on any type. When `K` is finite, `p` lies in the simplex exactly when `p a ≥ 0` for every `a` and `∑ₐ p a = 1`.
