# Rotate value le

Let `v` be valuations of finitely many goods, `A` an allocation and `c : ZMod m → ι` (with `m ≥ 2`) an injective envy cycle, so that each `c t` envies `c (t + 1)` under `A`. After rotating goods along the cycle, every agent's value for its own bundle is at least its value before.
