# Rotate value lt on Cycle

Let `v` be valuations of finitely many goods, `A` an allocation and `c : ZMod m → ι` (with `m ≥ 2`) an injective envy cycle, so that each `c t` envies `c (t + 1)` under `A`. After rotating goods along the cycle, every agent `c t` on the cycle strictly increases its value for its own bundle.
