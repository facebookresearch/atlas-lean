# Bounded envy existence

For a finite nonempty set of agents, a finite set of goods and nonnegative valuations `v`, some allocation `A` bounds all envy by a single good: whenever `i` envies `j`, some good `g` in `j`'s bundle has `vᵢ(bundle j \ {g}) ≤ vᵢ(bundle i)` and `vᵢ(bundle j) - vᵢ(bundle i) ≤ v i g`.
