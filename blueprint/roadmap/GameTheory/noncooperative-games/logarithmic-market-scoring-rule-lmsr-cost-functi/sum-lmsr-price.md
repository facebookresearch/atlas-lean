# Sum lmsr Price

For a finite nonempty set of outcomes, every real `b` and every share vector `q`, the LMSR prices `exp(q i / b) / ∑ⱼ exp(q j / b)` sum to `1` over all outcomes `i`.

At zero liquidity, $b = 0$, every quotient $q_j/b$ is $0$ and each of the $n$ prices is $1/n$ (see the [LMSR price](lmsr-price.md)).
