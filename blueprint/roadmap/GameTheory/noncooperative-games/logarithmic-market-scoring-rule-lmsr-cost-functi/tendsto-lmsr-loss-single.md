# Tendsto lmsr Loss single

For a finite nonempty set of `n` outcomes, a liquidity parameter `b > 0` and an outcome `i`, the market maker's loss when `i` occurs after trades from `0` to the share vector with `t` shares of `i` and none of the others tends to `b · log n` as `t → ∞`; so the worst-case loss bound `b · log n` is tight.
