# Expected vector payoff of a mixed action

Let $A$ be a finite set of actions, $B$ a set of opponent actions, $E$ a real inner product space and
$v : A \times B \to E$ a vector payoff. For weights $q : A \to \mathbb{R}$ (a mixed action when $q$ is a
probability vector) and an opponent action $b$, the expected vector payoff is
$v(q, b) = \sum_{a \in A} q(a)\, v(a, b)$.
