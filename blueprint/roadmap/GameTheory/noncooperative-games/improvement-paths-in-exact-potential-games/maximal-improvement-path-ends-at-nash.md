# Maximal improvement path ends at nash

In a game with finitely many players and finite nonempty strategy sets, the last profile `s` of a maximal strict improvement path is a pure Nash equilibrium: no player can lower its cost by deviating alone, since such a deviation would extend the path.

In particular, a maximal finite strict improvement path is nonempty, and its last profile is a pure Nash equilibrium.

Equivalently, no profile is reached from `s` by a strict better-response step: such a step would extend the path, and since real costs are linearly ordered, having no strictly cheaper unilateral deviation is exactly the pure-Nash inequalities.
