# Strict better response decreases potential

Let `Φ` be an exact potential for the cost functions `c` of a game with finitely many players and finite nonempty strategy sets, so that every unilateral deviation changes the deviator's cost by exactly the change in `Φ`. If `s'` arises from `s` by a deviation of player `i` with `c i s' < c i s`, then `Φ s' < Φ s`. With costs, a strict better response strictly decreases the potential; in the payoff convention the potential is `-Φ` and increases.

Equivalently, every strict better-response step from `s` to `s'` (a unilateral deviation strictly lowering the deviator's cost) satisfies `Φ s' < Φ s`.
