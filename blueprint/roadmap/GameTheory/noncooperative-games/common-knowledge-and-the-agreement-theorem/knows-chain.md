# Iterated knowledge along a chain of agents

For agents with knowledge operators $K_i$ and a finite sequence of agents $i_1, \dots, i_k$, the
event

$$K_{i_1} K_{i_2} \cdots K_{i_k}(E)$$

"agent $i_1$ knows that agent $i_2$ knows that … agent $i_k$ knows $E$"; the empty sequence gives
$E$ itself. Repetitions are allowed.

## Background

- [Knowledge operator](knows.md): applied once for each agent of the sequence.

## Sources

- R. J. Aumann, "Agreeing to disagree", Ann. Statist. 4(6) (1976), 1236–1239, p. 1237 (the sentences "$i$ knows that $i'$ knows that $i$ knows … $E$").
