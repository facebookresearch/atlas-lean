# Knowledge operator

An agent with information partition $\mathcal P$ knows the event $E \subseteq \Omega$ at the state
$\omega$ when its cell is inside the event, $P(\omega) \subseteq E$. The knowledge operator maps
$E$ to the event "the agent knows $E$",

$$K(E) = \{\omega : P(\omega) \subseteq E\}.$$

What is known is true: $K(E) \subseteq E$.

## Background

- [Information cell](cell.md): knowledge is defined through the cell of the true state.

## Sources

- R. J. Aumann, "Agreeing to disagree", Ann. Statist. 4(6) (1976), 1236–1239, p. 1237 ("to say that 1 'knows' $E$ means that $E$ includes $P_1$").
