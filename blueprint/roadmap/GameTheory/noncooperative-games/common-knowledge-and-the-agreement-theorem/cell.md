# Information cell

In a partition model, the information of an agent is a partition $\mathcal P$ of the set $\Omega$
of states of the world, here an equivalence relation $r$ on $\Omega$. At the state $\omega$ the
agent is told the cell

$$P(\omega) = \{\omega' \in \Omega : \omega' \sim_r \omega\}$$

that contains $\omega$, and cannot distinguish $\omega$ from the other states of that cell.

## Sources

- R. J. Aumann, "Agreeing to disagree", Ann. Statist. 4(6) (1976), 1236–1239, p. 1237 ("if the true state of the world is $\omega$, then $i$ is informed of that element $\mathcal P_i(\omega)$ of $\mathcal P_i$ that contains $\omega$").
