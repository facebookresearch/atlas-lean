# Competitive equilibria lie in the core of the economy

In an exchange economy with locally nonsatiated utilities, a nonempty coalition *blocks* an allocation if it can redistribute its own endowments so that every member is weakly better off and some member strictly better off. Every competitive equilibrium allocation is unblocked: it lies in the core, and in particular it is Pareto optimal and individually rational.

## Proof sketch

Apply the first welfare argument to the coalition: a blocking redistribution would cost the coalition more than the value of its endowments at equilibrium prices.
