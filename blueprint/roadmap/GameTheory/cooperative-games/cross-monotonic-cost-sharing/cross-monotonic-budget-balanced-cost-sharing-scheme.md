# Cross-monotonic γ-budget-balanced cost-sharing scheme

A *cost-sharing scheme* for a cost-sharing game $c$ on agents $A$ assigns to each coalition $S$ and each $j \in S$ a share $\xi(S, j)$. It is *$\gamma$-budget-balanced* if $\gamma\, c(S) \le \sum_{j \in S} \xi(S, j) \le c(S)$ for every $S$, and *cross-monotonic* if $\xi(S, j) \ge \xi(T, j)$ whenever $j \in S \subseteq T$: an agent's share never increases as the coalition grows.
