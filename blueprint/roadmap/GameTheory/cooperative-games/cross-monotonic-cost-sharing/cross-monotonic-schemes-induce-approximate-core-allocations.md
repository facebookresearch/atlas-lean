# Cross-monotonic schemes induce approximate-core allocations

If $\xi$ is a $\gamma$-budget-balanced cross-monotonic cost-sharing scheme, then the vector $(\xi(A, j))_{j \in A}$ lies in the $\gamma$-core; in particular a $1$-budget-balanced cross-monotonic scheme yields a core allocation, for the grand coalition and for every subcoalition.

## Proof sketch

For a coalition $S$, cross-monotonicity gives $\sum_{j \in S} \xi(A, j) \le \sum_{j \in S} \xi(S, j) \le c(S)$.
