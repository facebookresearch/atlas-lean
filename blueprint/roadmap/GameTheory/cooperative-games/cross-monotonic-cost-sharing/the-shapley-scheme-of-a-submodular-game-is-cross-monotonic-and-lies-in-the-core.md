# The Shapley scheme of a submodular game is cross-monotonic and lies in the core

For a submodular cost-sharing game, the scheme assigning to each coalition $S$ the Shapley value of the game restricted to $S$ is cross-monotonic and $1$-budget-balanced. In particular the Shapley value lies in the core.

## Proof sketch

In the random-order formula, adding agents to the coalition can only enlarge an agent's set of predecessors, and by submodularity marginal costs decrease with the predecessor set.
