# The TU game of a linear exchange economy has a nonempty core

Let finitely many agents hold nonnegative endowments of finitely many divisible goods and have linear utilities $u_i(x) = \sum_g a_{ig} x_g$ with $a_{ig} \ge 0$. Define the transferable-utility game whose value $v(S)$ is the maximum total utility coalition $S$ can obtain by redistributing its own endowments. Then $v(S)$ is attained by a feasible redistribution, and the allocation of utilities obtained from a market-price allocation lies in the core of this game; in particular the core is nonempty.

## Proof sketch

With linear utilities, the optimum for a coalition gives each good to a member valuing it most. Pricing each good at the maximum marginal utility in the grand coalition and paying each agent the value of its endowment gives a payoff vector that no coalition can improve on, since each coalition's value is at most the price of its endowment.
