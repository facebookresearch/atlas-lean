# Nontransferable-utility cooperative game and its core

An *NTU game* on agents $A$ assigns to each coalition $S$ a set $V(S) \subseteq \mathbb{R}^A$ of feasible utility vectors, a cylinder in the coordinates outside $S$. An allocation $x \in V(A)$ is in the *core* if no nonempty coalition $S$ has $y \in V(S)$ with $y_i > x_i$ for all $i \in S$. The game is *balanced* if for every balanced collection $\mathcal B$ of coalitions, any vector lying in $V(S)$ for all $S \in \mathcal B$ lies in $V(A)$.
