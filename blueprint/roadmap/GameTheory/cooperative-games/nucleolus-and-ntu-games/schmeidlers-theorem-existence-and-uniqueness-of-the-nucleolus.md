# Schmeidler's theorem: existence and uniqueness of the nucleolus

Lexicographic minimization of the sorted excess vector over any nonempty compact set of payoff vectors has a minimizer, and over a nonempty compact convex set the minimizer is unique. Consequently the prenucleolus of every TU game is a single point, and when the individually rational efficient set is nonempty the nucleolus is a single point. If the core is nonempty, the nucleolus lies in the core.

## Proof sketch

The $k$-th largest excess is a continuous function of $x$ (a max-min of finitely many affine functions), giving existence by successive minimization. If $x \ne y$ both minimize, the midpoint has strictly smaller sorted excess vector by Schmeidler's midpoint lemma. Core vectors have all excesses nonpositive, so the lexicographic minimizer does too.
