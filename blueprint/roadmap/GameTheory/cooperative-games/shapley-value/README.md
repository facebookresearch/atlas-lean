# Shapley value

The Shapley value (Shapley 1953) divides the worth of the grand coalition of a game with transferable utility among the players. It is the only linear rule that is efficient, symmetric and gives nothing to null players; on a fixed finite player set this follows from the basis of unanimity games, and the value is given by Shapley's formula, the average of a player's marginal contributions over all orders of arrival of the players. Aumann and Shapley (1974) extended the value to games with a continuum of players.
