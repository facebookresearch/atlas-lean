# Cooperative game with transferable utility

Given a set $N$ of players, a cooperative
game on $N$ is a function $v$ that assigns to every coalition $S \subseteq N$ a real number
$v(S)$, the worth of $S$, such that $v(\emptyset) = 0$.

The normalisation $v(\emptyset) = 0$ is part of the definition here; the source defines the worth of
nonempty coalitions only.

## Sources

- R. Serrano, "Cooperative games: core and Shapley value", CEMFI Working Paper 0709 (2007), §2.2 (transferable utility games $(N, v)$; secondary source).
