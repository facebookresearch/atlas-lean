# Null player

Let $v$ be a cooperative game on a finite set $N$ of players. A player
$i \in N$ is a null player of $v$ if $v(S \cup \{i\}) = v(S)$ for every coalition
$S \subseteq N$ with $i \notin S$.

## Sources

- R. Serrano, "Cooperative games: core and Shapley value", CEMFI Working Paper 0709 (2007), §4.1, axiom (iv) "Dummy player: if a player contributes nothing to every coalition" (secondary source).
