# Group strategyproof facility location

A facility-location mechanism $f$ maps reported agent locations $x \in \mathbb R^\iota$ to a facility location, and agent $i$'s cost is $|f(x) - x_i|$. It is group strategyproof when no nonempty coalition $S$ can change only its own members' reports, from $x$ to $x'$, so that $|f(x') - x_i| < |f(x) - x_i|$ for every $i \in S$.
