# Truthful scheduling rules are weakly monotone

Consider an allocation rule assigning tasks to machines from reported nonnegative processing times, with payments. If the mechanism is truthful (no machine gains, payment minus true load, by misreporting any nonnegative row), then the rule is weakly monotone: whenever only machine $i$'s row changes from $t$ to $t'$, both nonnegative, the $t$-load of $i$'s old bundle minus the $t$-load of its new bundle is at most the same difference measured with $t'$.
