# Route travel time on link-simple routes

For finitely many routes, each given as a list of arcs with no repeated arc, arc latencies $\ell_e$ and route flows $f$, the travel time of route $p$ in the induced routing instance equals $\sum_{e \in p} \ell_e(x_e)$, where $x_e$ is the total flow of the routes using arc $e$.
