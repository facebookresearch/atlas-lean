# Counting through a map that is injective on a finite set

Let $s$ be a finite set of elements of a type $\alpha$, let $t$ be a finite set of elements of a type $\beta$, and let
$f \colon \alpha \to \beta$ be a map such that $f(a) \in t$ for every $a \in s$ and $f$ is injective on $s$. Then

$$
|s| \le |t|.
$$
