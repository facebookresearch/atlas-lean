# An injective map from a finite set to itself is surjective

Let $A$ be a finite set, that is, a set in bijection with $\{0, 1, \dots, n - 1\}$ for some natural number $n$. Then every injective function $f\colon A \to A$ is surjective.

## Sources

- Herbert B. Enderton, Elements of Set Theory, Academic Press, 1977.
