# Quotient set: the set of equivalence classes

Let $R$ be an equivalence relation on a set $A$. The *quotient set* of $A$ by $R$ is the set $A/R = \{[y]_R : y \in A\}$ whose elements are the equivalence classes $[y]_R = \{x \in A : x \mathrel{R} y\}$ of the elements of $A$.
