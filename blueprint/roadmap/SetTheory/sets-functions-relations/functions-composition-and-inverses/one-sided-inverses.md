# A function on a nonempty set has a left inverse if and only if it is injective

Let $f\colon A \to B$ be a function, where the set $A$ is nonempty. Then $f$ is injective if and only if $f$ has a left inverse, a function $g\colon B \to A$ with $g(f(a)) = a$ for every $a \in A$.

## Sources

- Herbert B. Enderton, Elements of Set Theory, Academic Press, 1977.
