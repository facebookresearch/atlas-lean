# A function has a right inverse if and only if it is surjective

Let $f\colon A \to B$ be a function. Then $f$ maps $A$ onto $B$ if and only if $f$ has a right inverse, a function $g\colon B \to A$ with $f(g(b)) = b$ for every $b \in B$. Constructing a right inverse of a surjective function uses the axiom of choice; that a function with a right inverse is surjective needs no choice.
