# Bijective function

Let $A$ and $B$ be sets and let $f\colon A \to B$ be a function from $A$ into $B$. Then $f$ is *bijective*, or a *bijection* of $A$ onto $B$, if it is both injective and surjective. Injective means that $f(x) = f(y)$ implies $x = y$ for all $x, y \in A$; surjective means that every $b \in B$ is $f(a)$ for some $a \in A$.
