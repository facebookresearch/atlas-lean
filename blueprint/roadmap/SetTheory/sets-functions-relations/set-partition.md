# Partition of a set into nonempty pairwise disjoint blocks

A partition of a set $A$ is a set $\Pi$ of nonempty subsets of $A$, any two distinct members of which are disjoint, whose union is $A$. Mathlib defines, for a type $\alpha$, a set $c$ of subsets of $\alpha$ to be a partition of $\alpha$ when the empty set is not a member of $c$ and every element of $\alpha$ lies in exactly one member of $c$; a partition of a set $A$ is a partition of the type of elements of $A$, and when $A$ is empty its only partition is the empty family. Mathlib proves that the members of a partition are nonempty and pairwise disjoint and that their union is all of $\alpha$; conversely, it proves that a set of pairwise disjoint subsets of $\alpha$ that does not contain the empty set and has every element of $\alpha$ in some member is a partition, the uniqueness of the member containing an element coming from disjointness.
