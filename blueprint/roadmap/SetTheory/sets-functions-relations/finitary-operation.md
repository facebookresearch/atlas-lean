# Operation of finite arity on a set

An $n$-ary operation on a set $U$, for an integer $n \ge 1$, is a function $f \colon U^n \to U$ from $n$-tuples of elements of $U$ to $U$; a binary operation is a function $U \times U \to U$. Universal algebra also allows $n = 0$ on a nonempty set $U$: $U^0$ is then a one-point set, so that a nullary operation $U^0 \to U$ amounts to an element of $U$, and the operations of positive arity are the case $n \ge 1$ of this definition. Mathlib's type of $n$-ary functions is the curried form, which takes the $n$ arguments one at a time. For types $\alpha$ and $\beta$ in the same universe and a natural number $n$, Mathlib's $\operatorname{OfArity}(\alpha, \beta, n)$ is defined by recursion on $n$: for $n = 0$ it is $\beta$, and for $n + 1$ it is the type of functions from $\alpha$ to $\operatorname{OfArity}(\alpha, \beta, n)$. An element is thus a function $\alpha \to (\alpha \to \cdots (\alpha \to \beta))$ with $n$ arguments. A curried function is not literally a function on tuples, but Mathlib's equivalence $\operatorname{curryEquiv}$ is a bijection from the functions $(\operatorname{Fin} n \to \alpha) \to \beta$, which take an $n$-tuple indexed by $\{0, \dots, n - 1\}$, onto $\operatorname{OfArity}(\alpha, \beta, n)$, with inverse given by uncurrying. Taking $\alpha = \beta = U$ and $n \ge 1$, and identifying $U^n$ with the tuples $\operatorname{Fin} n \to U$, gives the familiar notion. For $n = 2$ the curried operations $U \to (U \to U)$ correspond to the binary operations $U \times U \to U$, and no algebraic law is imposed. For $n = 0$, $\operatorname{OfArity}(U, U, 0)$ is $U$ itself, matching the nullary operations, and it needs no nonemptiness: for $U$ empty there is no function from the one-point set $U^0$ to $U$, and $\operatorname{OfArity}(U, U, 0)$ is empty.
