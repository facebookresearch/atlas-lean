# Well-ordering theorem: every set admits a well-ordering

Every set $A$ admits a well-ordering: there is a linear order $\le$ on $A$ whose strict order $<$ is well-founded, that is, every nonempty subset of $A$ has a $<$-minimal element, which for a linear order is its least element.

## Sources

- Herbert B. Enderton, Elements of Set Theory, Academic Press, 1977.
