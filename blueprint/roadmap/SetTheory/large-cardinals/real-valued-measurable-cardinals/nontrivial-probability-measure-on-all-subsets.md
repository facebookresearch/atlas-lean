# Nontrivial probability measure on all subsets

For a set $I$ and a (countably additive) measure $\mu$ defined on all subsets of $I$ (the $\sigma$-algebra of all subsets), the proposition that $\mu$ is a nontrivial probability measure: $\mu(I) = 1$ and $\mu(\{x\}) = 0$ for every $x \in I$.

Source: Jech.
