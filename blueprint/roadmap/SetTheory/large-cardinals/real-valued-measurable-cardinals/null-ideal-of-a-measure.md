# Null ideal of a measure

For a measurable space $I$ and a measure $\mu$ on it, the null ideal of $\mu$ is the family

$$I_\mu = \{\, A \subseteq I : \mu(A) = 0 \,\},$$

where $\mu(A)$ is defined for every subset $A$ (as the outer measure of $A$, which agrees with $\mu(A)$ for measurable $A$).

Source: Jech.
