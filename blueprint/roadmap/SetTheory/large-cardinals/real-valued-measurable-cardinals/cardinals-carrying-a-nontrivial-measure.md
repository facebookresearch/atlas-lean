# Cardinals carrying a nontrivial measure

For a cardinal $c$, the proposition that $c$ carries a nontrivial measure: there is a set $I$ with $|I| = c$ (in the same universe) and a countably additive measure $\mu$ on all subsets of $I$ with $\mu(I) = 1$ and $\mu(\{x\}) = 0$ for every $x \in I$.

Source: Jech.
