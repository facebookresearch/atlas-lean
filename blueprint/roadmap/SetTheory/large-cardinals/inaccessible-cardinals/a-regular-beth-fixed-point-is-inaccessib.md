# A regular beth fixed point is inaccessible

If $\kappa$ is a regular cardinal with $\beth_\kappa = \kappa$, then $\kappa$ is inaccessible.

Proof: $\kappa$ is uncountable. For a cardinal $x < \kappa$ with initial ordinal $\alpha$,
$2^x \le 2^{\beth_\alpha} = \beth_{\alpha + 1} < \beth_\kappa = \kappa$, because the initial ordinal
of $\kappa$ is a limit ordinal. So $\kappa$ is a strong limit.

Regularity is needed: the least beth fixed point is singular.
