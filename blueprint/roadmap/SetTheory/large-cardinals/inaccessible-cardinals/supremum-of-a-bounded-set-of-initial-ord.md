# Supremum of a bounded set of initial ordinals is initial

The supremum of a bounded set of initial ordinals is an initial ordinal.

Proof: let $\sigma$ be the supremum and $\beta$ the initial ordinal of the cardinality of
$\sigma$, so $\beta \le \sigma$. If $\beta < \sigma$, some member $t$ of the set satisfies
$t > \beta$. But $t \le \sigma$ and $t$ is initial, so $t$ is at most the initial ordinal of the
cardinality of $\sigma$, that is $t \le \beta$: a contradiction.
