# Ordered pair of sets

Work in Zermelo–Fraenkel set theory, where every member of a set is itself a set. For sets $x$ and $y$, the *ordered pair* $(x, y)$ is the set $\{\{x\}, \{x, y\}\}$, whose members are the singleton $\{x\}$ and the pair set $\{x, y\}$. The sets $x$ and $y$ are its first and second coordinates.

## Sources

- Herbert B. Enderton, Elements of Set Theory, Academic Press, 1977.
