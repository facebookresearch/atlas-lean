# The union of a set of transitive sets is transitive

Work in Zermelo–Fraenkel set theory, where every member of a set is itself a set. A set $T$ is *transitive* if every member of $T$ is a subset of $T$. Let $\mathcal{A}$ be a set every member of which is transitive. Then the union $\bigcup \mathcal{A}$ is transitive.

## Sources

- Herbert B. Enderton, Elements of Set Theory, Academic Press, 1977, Chapter 4, p. 73, Exercise 5(a).
