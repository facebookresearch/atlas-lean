# Martin's Borel determinacy theorem

For every non-empty set of moves `A`, every Borel
payoff set `S ⊆ A^ℕ` (for the product of the discrete topologies) is determined
(D. A. Martin, *Borel determinacy*, Ann. of Math. 102 (1975) 363–371; Moschovakis,
*Descriptive Set Theory*, 2nd ed., AMS 2009, Theorem 6F.1, which also allows games with rules).
The Borel sets here are those of the σ-algebra generated by the open sets, as in Moschovakis §6A;
`A` may be uncountable.

Friedman (1971) showed that Borel determinacy is not provable in Zermelo set theory with choice: Martin's proof uses the axiom of replacement to build closed games on iterated power sets of the moves (Woodin, *The continuum hypothesis, Part I*, Notices AMS 48 (2001)). Woodin calls it "the strongest theorem one can hope to prove without appealing to new axioms", because the determinacy of all analytic sets cannot be proved in ZFC (Woodin, *The continuum hypothesis, Part I*, Notices AMS 48 (2001); for the latter fact see also Moschovakis, Exercise 6A.12).

## Informally uses

- [Gale–Stewart theorem, open case](../gale-stewart-games/determined-of-is-open.md): Martin's proof assigns to the Borel set, by induction on its Borel rank, an open set of plays on a larger set of moves, determined by the Gale–Stewart theorem, from whose determinacy that of the Borel set follows (Woodin, *The continuum hypothesis, Part I*, Notices AMS 48 (2001), section "Projective Determinacy and Large Cardinals").
