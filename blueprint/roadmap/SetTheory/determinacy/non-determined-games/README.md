# Non-determined games

With the axiom of choice, some game on `{0, 1}` is not determined (Gale and Stewart, 1953): a diagonalisation over the continuum many strategies, each of which has continuum many plays. Hence the axiom of determinacy, that every subset of Baire space is determined, contradicts the axiom of choice; results "under AD" are stated with determinacy hypotheses on specific classes of sets instead.
