# Gale–Stewart theorem, open case

If the set of moves `A` is non-empty and `A^ℕ` carries
the product of the discrete topologies, every open payoff set `S ⊆ A^ℕ` is determined
(Gale and Stewart, *Infinite games with perfect information*, Ann. of Math. Stud. 28 (1953);
Moschovakis, *Descriptive Set Theory*, 2nd ed., AMS 2009, Theorem 6A.2 and 6A.4).

Moschovakis obtains the open case from the closed case by adding a dummy first move, which swaps the roles of the players (Theorem 6A.4). Alternatively, the lemma behind the closed case applies directly to player I and the open set `S`.
