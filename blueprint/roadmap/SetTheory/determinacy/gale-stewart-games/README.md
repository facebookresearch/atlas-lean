# Gale–Stewart games

Two players alternately choose moves `x 0, x 1, x 2, …` from a set `A`, each seeing all earlier moves; player I wins if the play lies in the payoff set `S ⊆ A^ℕ`. A strategy maps finite histories to moves, and `S` is determined if one player has a winning strategy. The Gale–Stewart theorem says that open and closed payoff sets are determined; standard proofs of the Borel and projective determinacy theorems (Martin's for Borel sets, Martin–Steel's for projective sets under Woodin cardinals) reduce the game at hand to a closed game on a larger set of moves.
