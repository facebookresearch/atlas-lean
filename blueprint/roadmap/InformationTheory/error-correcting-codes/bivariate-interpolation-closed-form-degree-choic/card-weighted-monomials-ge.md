# Lower bound D + 1 on the weighted monomial count

For natural numbers $w$ and $D$, the number of pairs $(i, j)$ with $0 \le i, j \le D$ and $i + wj \le D$ is at least $D + 1$ (the pairs with $j = 0$). This holds for every $w$, including $w = 0$: at $D = 2$ and $w = 0$ the count is $9$. Without the box $0 \le i, j \le D$ the set would be infinite for $w = 0$.
