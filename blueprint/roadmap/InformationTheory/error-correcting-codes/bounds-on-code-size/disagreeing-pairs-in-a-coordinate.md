# Disagreeing pairs in a coordinate

Let $C$ be a code over an alphabet with $q$ letters and $j$ a coordinate. At most a $1 - 1/q$
fraction of the $|C|^2$ ordered pairs of codewords disagree at $j$:

$$q \cdot |\{(c, c') \in C^2 : c_j \ne c'_j\}| \le (q - 1) |C|^2.$$

If $m_a$ codewords have symbol $a$ at $j$, the agreeing pairs number $\sum_a m_a^2$, which is at
least $(\sum_a m_a)^2 / q = |C|^2 / q$ by Cauchy–Schwarz.
