# Codes attaining the generalized Singleton bound (LD-MDS codes)

A linear $[n, k]$ code $C$ over $\mathbb{F}_q$ is *$\mathrm{LD}$-$\mathrm{MDS}(L)$* (list-decoding MDS of order $L$, Roth's higher-order MDS notion) if it is $\big(\frac{L}{L+1}\cdot\frac{n-k}{n}, L\big)$-list decodable, i.e. it attains the generalized Singleton bound for list size $L$. It is $\mathrm{LD}$-$\mathrm{MDS}(\le L)$ if it is $\mathrm{LD}$-$\mathrm{MDS}(L')$ for all $L' \le L$; $\mathrm{LD}$-$\mathrm{MDS}(1)$ is the MDS property.
