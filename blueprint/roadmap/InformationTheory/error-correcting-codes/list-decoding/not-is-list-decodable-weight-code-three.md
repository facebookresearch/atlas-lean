# Weight-three code beyond the binary Johnson radius

For every natural number $n \ge 7$, the binary code of all words in $(\mathbb{Z}/2\mathbb{Z})^n$ with exactly three nonzero coordinates is not list decodable from $3$ errors with list size $2 \cdot 2 \cdot n = 4n$: some Hamming ball of radius $3$ contains more than $4n$ codewords.

Indeed all $\binom{n}{3}$ codewords lie within distance $3$ of the zero word, and $\binom{n}{3} > 4n$ for $n \ge 7$. The code has minimum distance $2$ and $J(2, 2/n)\, n < 3$, so the list size $q d n$ that the $q$-ary Johnson bound gives below the radius fails at radius $3$.
