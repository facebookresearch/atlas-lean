# Generator/parity-check duality

Let $F$ be a field, $\kappa$ and $\iota$ finite index
sets and $\rho$ any index set, and let $G$ be a $\kappa \times \iota$ matrix and $H$ a
$\rho \times \iota$ matrix over $F$. The code generated by $G$ equals the code with parity-check
matrix $H$ if and only if $G H^{\mathsf{T}} = 0$ and $\operatorname{rank} G + \operatorname{rank} H$
equals $|\iota|$, the length of the code.
