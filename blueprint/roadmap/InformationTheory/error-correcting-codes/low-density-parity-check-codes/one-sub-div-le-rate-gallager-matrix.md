# Rate of Gallager's low-density codes

For $m, k > 0$ and every choice of the column permutations, the code of
[Gallager's matrix](gallager-matrix.md) with $n = mk$ columns has rate at least $1 - j/k$:

$$1 - \frac{j}{k} \le \frac{\dim C}{mk}.$$

So every code of Gallager's $(n, j, k)$ ensemble has rate at least $1 - j/k$.
