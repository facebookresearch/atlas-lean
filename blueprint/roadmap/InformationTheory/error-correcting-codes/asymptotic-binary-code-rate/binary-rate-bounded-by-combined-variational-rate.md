# Binary code rate bounded by the combined variational rate

For every real $0<\delta<1/2$, $R(\delta)\le V(\delta)$, where $V$ is the minimum of the Hamming and Johnson variational infima.

## Expansion

Develop the Hamming and constant-weight coding inequalities, including the shell-to-full-code bound, and pass from their finite size estimates to the two infima at the same relative distance.
