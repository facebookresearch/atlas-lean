# Combined variational rate strictly below the second MRRW rate

For every real $0<\delta<1/2$, $V(\delta)<R_2(\delta)$. This compares variational objectives, before using either to bound the actual code rate.

## Expansion

Compare the feasible objectives with the second MRRW minimization, including where its minimizing parameter is at an endpoint and where the Hamming or Johnson bound supplies strictness.
