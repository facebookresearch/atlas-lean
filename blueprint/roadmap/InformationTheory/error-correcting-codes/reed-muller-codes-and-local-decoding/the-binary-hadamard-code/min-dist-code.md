# Minimum distance of the positive-order Hadamard code

For $m \ge 1$, the Hadamard code of order $m$ has minimum distance $2^{m-1}$. For $m \ge 1$, the minimum weight of a nonzero codeword is likewise $2^{m-1}$, since minimum distance equals minimum nonzero weight for a linear code. For $m = 0$ the code has a single word and its [minimum distance is $\infty$](min-dist-code-zero.md).
