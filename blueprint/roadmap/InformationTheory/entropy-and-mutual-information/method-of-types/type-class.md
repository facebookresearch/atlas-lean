# Type class

For an $n$-type $s$, the **type class** $T_s$ is the set of sequences $x \in \alpha^n$ whose
[type](seq-type.md) is $s$. Type classes partition $\alpha^n$
([the type classes partition the sequences](sum-iid-prob-type-class.md)) and are never empty
([every type is realised](exists-seq-type-eq.md)).
