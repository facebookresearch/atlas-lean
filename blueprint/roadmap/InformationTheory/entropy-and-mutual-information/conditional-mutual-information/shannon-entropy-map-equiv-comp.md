# Entropy of a pushforward is invariant under relabeling

Let $p$ be a probability mass function on a set $\tau$ and $f : \tau \to \delta$ to a finite set a map, with pushforward $f_*p$.
For every bijection $e$ from $\delta$ onto a finite set, $H((e \circ f)_* p) = H(f_* p)$: relabeling the image
by a bijection preserves entropy.
