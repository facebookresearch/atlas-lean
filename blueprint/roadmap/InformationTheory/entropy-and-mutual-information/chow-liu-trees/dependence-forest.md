# Dependence forest

A dependence forest on a set $\iota$ of variables (Chow–Liu 1968) gives each variable $i$ at most one parent
$j(i) \in \iota$, together with a rank function $r : \iota \to \mathbb{N}$ such that $r(j(i)) < r(i)$ whenever
$i$ has a parent; the rank certifies that the parent relation has no cycles.
