# Lintegral sq error heavy Tail Reconstruction

Let $\mu$ be the heavy-tailed reconstruction, the image of $\mathcal{N}(0, 1)$ under $x \mapsto \left(x, x - e^{x^2/4}\right)$. Its square error has infinite integral:

$$\int (x - y)^2 \, d\mu(x, y) = \int e^{x^2/2} \, d\mathcal{N}(0, 1)(x) = \infty,$$

the integral of the nonnegative function $(x - y)^2$, with values in $[0, \infty]$.
