# Finite-distortion equivalence

Let $\sigma^2 \ge 0$ and $D \ge 0$. A probability measure $\mu$ on $\mathbb{R}^2$ is distortion-feasible at level $D$ for $\sigma^2$ if and only if its first marginal is $\mathcal{N}(0, \sigma^2)$, the square error $(x, y) \mapsto (x - y)^2$ is $\mu$-integrable, and

$$\int (x - y)^2 \, d\mu(x, y) \le D.$$

A probability measure $\mu$ on $\mathbb{R}^2$ is distortion-feasible at level $D$ for the source variance $\sigma^2$ if $D \ge 0$, the first marginal of $\mu$ is $\mathcal{N}(0, \sigma^2)$, and $\int (x - y)^2 \, d\mu(x, y) \le D$, the integral of a nonnegative function, possibly infinite.
