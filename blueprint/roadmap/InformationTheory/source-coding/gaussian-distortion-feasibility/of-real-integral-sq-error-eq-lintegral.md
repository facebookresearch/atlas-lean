# Of Real integral sq error eq lintegral

Let $\mu$ be a probability measure on $\mathbb{R} \times \mathbb{R}$ for which the square error $(x, y) \mapsto (x - y)^2$ is $\mu$-integrable. Then its expectation as a real integral agrees with its integral as a nonnegative function with values in $[0, \infty]$:

$$\int (x - y)^2 \, d\mu(x, y) \in \mathbb{R} \text{ equals } \int (x - y)^2 \, d\mu(x, y) \in [0, \infty].$$
