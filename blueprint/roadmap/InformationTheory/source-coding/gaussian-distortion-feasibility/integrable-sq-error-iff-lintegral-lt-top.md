# Integrable sq error iff lintegral lt top

Let $\mu$ be a probability measure on $\mathbb{R} \times \mathbb{R}$. The square error $(x, y) \mapsto (x - y)^2$ is $\mu$-integrable if and only if

$$\int (x - y)^2 \, d\mu(x, y) < \infty,$$

the integral of the nonnegative function $(x - y)^2$, with values in $[0, \infty]$.
