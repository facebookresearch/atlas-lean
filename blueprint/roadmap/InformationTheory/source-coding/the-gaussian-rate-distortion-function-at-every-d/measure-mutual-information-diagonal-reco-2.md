# Measure Mutual Information diagonal Reconstruction zero

For the degenerate source $\mathcal{N}(0, 0) = \delta_0$, a point mass, the exact reconstruction, the joint law $\delta_{(0, 0)}$ of $(X, X)$, has zero mutual information:

$$I(\delta_{(0,0)}) = 0.$$

So the claim that zero distortion forces infinite information fails for an atomic source.
