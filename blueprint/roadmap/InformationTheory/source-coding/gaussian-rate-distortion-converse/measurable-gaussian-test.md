# Measurable gaussian Test

For all $D, \sigma^2 \ge 0$, the Gaussian test function

$$t_{D, \sigma^2}(x, y) = \ln \varphi_D(x - y) - \ln \varphi_{\sigma^2}(x)$$

is Borel measurable on $\mathbb{R}^2$, where $\varphi_v$ is the Gaussian density for $v > 0$, extended by the zero function at $v = 0$, with $\ln 0 = 0$.
