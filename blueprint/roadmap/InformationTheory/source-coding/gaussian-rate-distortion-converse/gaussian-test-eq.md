# Gaussian Test eq

Let $D > 0$ and $\sigma^2 > 0$. For all $(x, y) \in \mathbb{R}^2$ the Gaussian test function $t_{D, \sigma^2}(x, y) = \ln \varphi_D(x - y) - \ln \varphi_{\sigma^2}(x)$, where $\varphi_v$ is the centered Gaussian density with variance $v$, equals

$$t_{D, \sigma^2}(x, y) = \frac{1}{2} \ln \frac{\sigma^2}{D} - \frac{(x - y)^2}{2D} + \frac{x^2}{2\sigma^2}.$$
