# Gaussian Test zero zero

Let $D > 0$ and $\sigma^2 > 0$. At the origin the Gaussian test function takes the value

$$t_{D, \sigma^2}(0, 0) = \frac{1}{2} \ln \frac{\sigma^2}{D}.$$

Here $t_{D, \sigma^2}(x, y) = \ln \varphi_D(x - y) - \ln \varphi_{\sigma^2}(x)$ is the Gaussian test function, $\varphi_v$ being the centered Gaussian density with variance $v$ (with $\varphi_0 \equiv 0$ and $\ln 0 = 0$).
