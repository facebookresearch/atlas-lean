# Fixed-length source coding theorem

Let $X_1, X_2, \dots$ be independent and identically distributed on a finite alphabet with entropy $H$.
For every $R > H$ there are block codes mapping $X^n$ to $\lceil nR \rceil$ bits whose decoding error
probability tends to $0$, and for every $R < H$ every sequence of block codes of rate $R$ has error
probability tending to $1$.
