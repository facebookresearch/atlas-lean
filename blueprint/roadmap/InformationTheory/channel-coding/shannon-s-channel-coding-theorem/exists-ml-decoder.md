# A maximum-likelihood decoder exists

For a code $C = (x_1, \dots, x_M)$ with $M \ge 1$ words there is a decoder $g$ that returns, for every
output $y$, a message $g(y)$ maximising $W^N(y \mid x_m)$ over $m$. Ties are broken arbitrarily.
