# The sum inside $E_0$ is positive

For every $\rho$, $\sum_b g_b(\rho)^{1+\rho} > 0$: some input $a$ has $p(a) > 0$, some output $b$
has $W(b \mid a) > 0$, and then $g_b(\rho) \ge p(a) W(b \mid a)^{1/(1+\rho)} > 0$. Hence
$E_0(\rho, p)$ is minus the logarithm of a positive number.
