# Hölder's inequality, geometric-mean form

For a finite index set, nonnegative $X_i$, $Y_i$ and $0 < \mu < 1$,

$$\sum_i X_i^{\mu}\, Y_i^{1-\mu} \le \Big(\sum_i X_i\Big)^{\mu} \Big(\sum_i Y_i\Big)^{1-\mu}.$$

It is Hölder's inequality with the conjugate exponents $1/\mu$ and $1/(1-\mu)$ applied to
$X_i^{\mu}$ and $Y_i^{1-\mu}$.
