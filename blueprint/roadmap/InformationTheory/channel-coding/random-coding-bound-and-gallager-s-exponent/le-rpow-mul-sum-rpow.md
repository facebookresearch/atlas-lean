# The inequality behind Gallager's bound (6)

Let $a \ge 0$, let $f_j \ge 0$ for $j$ in a finite set, and suppose $a \le f_{j_0}$ for one index
$j_0$. Then for every $\rho \ge 0$, with $s = 1/(1 + \rho)$,

$$a \le a^{s} \Big(\sum_j f_j^{s}\Big)^{\rho}.$$

If $a > 0$, the sum is at least $f_{j_0}^s \ge a^s$, and $a^s (a^s)^\rho = a^{s(1+\rho)} = a$. If
$a = 0$ both sides are nonnegative.
