# Probability of a code word in Gallager's ensemble

In Gallager's ensemble each letter of a code word is drawn independently with law $p$, so the word
$x = (x_1, \dots, x_N)$ has probability $P(x) = \prod_{i=1}^{N} p(x_i)$.
