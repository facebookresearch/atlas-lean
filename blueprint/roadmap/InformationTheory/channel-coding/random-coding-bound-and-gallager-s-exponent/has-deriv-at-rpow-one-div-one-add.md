# Derivative of $w^{1/(1+\rho)}$ at $\rho = 0$

For every real $w \ge 0$, the function $\rho \mapsto w^{1/(1+\rho)}$ has derivative $-w \ln w$ at
$\rho = 0$. For $w > 0$ this is the chain rule for $e^{\ln w/(1+\rho)}$. For $w = 0$ the function
is $0$ for every $\rho > -1$, and $-0 \cdot \ln 0 = 0$ with the convention $0 \ln 0 = 0$.
