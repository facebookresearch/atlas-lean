# Not scalar Power Bound const of lt

Let $(\Omega, \mu)$ be a probability space and $c, P \in \mathbb{R}$ with $0 \le P < c^2$. The constant random variable $X \equiv c$ has $\operatorname{Var}(X) = 0 \le P$, yet it violates the power bound at budget $P$: it is not true that $\int_\Omega X^2 \, d\mu = c^2 \le P$. So a bound on the second moment is strictly stronger than a bound on the variance.
