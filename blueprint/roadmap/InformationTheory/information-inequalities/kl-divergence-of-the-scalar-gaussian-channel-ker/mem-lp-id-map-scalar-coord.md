# Mem Lp id map scalar Coord

Let $\iota : \mathbb{R} \to \mathbb{R}^1$ be the linear isometry onto one-dimensional Euclidean space sending $x$ to the vector $(x)$ whose only coordinate is $x$.

Let $\mu$ be a measure on $\mathbb{R}$ with finite second moment, that is, the identity function lies in $L^2(\mu)$ (so $\int x^2 \, d\mu(x) < \infty$). Then the image measure $\iota_* \mu$ on $\mathbb{R}^1$ also has finite second moment: the identity of $\mathbb{R}^1$ lies in $L^2(\iota_* \mu)$.
