# Rényi moment

**Rényi moment** of order `α` of `μ` with respect to `ν`: `∫⁻ x, (∂μ/∂ν) x ^ α ∂ν` when
`μ ≪ ν` and `1 < α` (Mironov, arXiv:1702.07476v3, Definition 3, the expectation
`E_{x ∼ Q} (P(x) / Q(x)) ^ α`), and `∞` otherwise. The value `∞` at `α ≤ 1` is a convention of
this file, not part of the cited definition, which covers only `α > 1`.
