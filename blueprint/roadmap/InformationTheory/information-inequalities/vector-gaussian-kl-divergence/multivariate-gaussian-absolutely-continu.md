# Absolute continuity, density discharged

Let $\iota$ be a finite index set with $n = \lvert \iota \rvert$, and write $\mathcal{N}(m, S)$ for the Gaussian measure on the Euclidean space $\mathbb{R}^{\iota}$ with mean $m$ and covariance matrix $S$.

Let $m, q \in \mathbb{R}^{\iota}$ and let $S, T$ be positive definite real $\iota \times \iota$ matrices. Then $\mathcal{N}(m, S)$ is absolutely continuous with respect to $\mathcal{N}(q, T)$: every Borel set of $\mathcal{N}(q, T)$-measure zero has $\mathcal{N}(m, S)$-measure zero.
