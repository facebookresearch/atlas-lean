# Equal covariances

Let $\iota$ be a nonempty finite index set with $n = \lvert \iota \rvert \ge 1$, and write $\mathcal{N}(m, S)$ for the Gaussian measure on the Euclidean space $\mathbb{R}^{\iota}$ with mean $m$ and covariance matrix $S$.

Let $m, q \in \mathbb{R}^{\iota}$ and let $S$ be a positive definite real $\iota \times \iota$ matrix. The Kullback-Leibler divergence between Gaussians with the same covariance is half the Mahalanobis term:

$$\mathrm{KL}\big(\mathcal{N}(m, S) \,\|\, \mathcal{N}(q, S)\big) = \frac{(m - q)^{\top} S^{-1} (m - q)}{2}.$$
