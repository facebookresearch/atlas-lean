# Self Information Nats Zero Extension

Let $p$ be a probability mass function on a set $\alpha$. The real-valued zero extension of self-information, in nats, is

$$I_p(a) = \begin{cases} -\log p(a) & \text{if } p(a) > 0, \\ 0 & \text{if } p(a) = 0. \end{cases}$$

The value $0$ off the support is only a representative for weighted sums; the genuine information of an impossible outcome is infinite.
