# Two Point Score

The two-point score is the function $s : \{\mathrm{true}, \mathrm{false}\} \to \mathbb{R}$ given by

$$s(\mathrm{true}) = \ln \tfrac{3}{2}, \qquad s(\mathrm{false}) = \ln \tfrac{1}{2}.$$

It is normalized against the uniform law: $\tfrac{1}{2} e^{s(\mathrm{true})} + \tfrac{1}{2} e^{s(\mathrm{false})} = 1$.
