# Bsc finite Mutual Information uniform

Let $\delta \in [0, 1]$. For the binary symmetric channel with crossover probability $\delta$ and uniform input on $\{0, 1\}$, the mutual information between input and output, in bits, is

$$I(X; Y) = 1 - \frac{h(\delta)}{\ln 2},$$

where $h(\delta) = -\delta \ln \delta - (1 - \delta) \ln(1 - \delta)$ is the binary entropy in nats, with $0 \ln 0 = 0$.
