# Kl Div prod reference eq add

Let $X$ and $Y$ be measurable spaces with $X$ standard Borel and nonempty, let $\mu$ be a probability measure on $X \times Y$ with marginals $\mu_X$ and $\mu_Y$, and let $Q$ be a probability measure on $Y$. Then, as an identity in $[0, \infty]$,

$$D_{\mathrm{KL}}(\mu \parallel \mu_X \otimes Q) = D_{\mathrm{KL}}(\mu \parallel \mu_X \otimes \mu_Y) + D_{\mathrm{KL}}(\mu_Y \parallel Q).$$
