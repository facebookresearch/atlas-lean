# Rows of a kernel are within Dobrushin's coefficient

For a Markov kernel $\kappa$ and all inputs $x, x'$,
$\mathrm{TV}(\kappa(x), \kappa(x')) \le \eta_{\mathrm{TV}}(\kappa)$.

## Sources

- Y. Polyanskiy and Y. Wu, Information Theory: From Coding to Learning (Cambridge University Press, 2025), Theorem 33.4.
