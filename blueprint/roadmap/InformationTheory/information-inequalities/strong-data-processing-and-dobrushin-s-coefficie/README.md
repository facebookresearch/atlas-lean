# Strong data processing and Dobrushin's coefficient

A Markov kernel $\kappa$ contracts total variation by Dobrushin's coefficient $\eta_{\mathrm{TV}}(\kappa) = \sup_{x, x'} \mathrm{TV}(\kappa(x), \kappa(x'))$, and point masses show that no smaller constant works. The same coefficient bounds the contraction of the Kullback–Leibler divergence and of every f-divergence, the starting point of strong data-processing inequalities.
