# Integrable output Quadratic

Let $\kappa$ and $\iota$ be finite index sets, $H$ a real $\iota \times \kappa$ matrix, $q \in \mathbb{R}^{\iota}$ and $T$ any real $\iota \times \iota$ matrix. Let $\mu$ be a probability measure on $\mathbb{R}^{\kappa}$ with finite second moment ($\int \lVert x \rVert^2 \, d\mu < \infty$). Then

$$x \mapsto (H x - q)^{\top} T^{-1} (H x - q)$$

is $\mu$-integrable, where $T^{-1} = 0$ if $T$ is singular.
