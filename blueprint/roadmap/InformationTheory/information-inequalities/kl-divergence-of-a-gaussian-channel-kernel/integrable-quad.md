# Integrable quad

Let $(\alpha, \rho)$ be a measure space, let $\iota$ be a finite index set, and let $u : \alpha \to \mathbb{R}^{\iota}$ be in $L^2(\rho)$ (almost everywhere strongly measurable with $\int \lVert u \rVert^2 \, d\rho < \infty$). Then for every real $\iota \times \iota$ matrix $M$ the function

$$a \mapsto u(a)^{\top} M\, u(a)$$

is $\rho$-integrable.
