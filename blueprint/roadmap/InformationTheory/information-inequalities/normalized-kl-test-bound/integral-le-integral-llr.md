# Normalized test bound on the expected log-likelihood ratio

Let $\mu$ and $\nu$ be probability measures on a measurable space, with $\mu \ll \nu$ and the log-likelihood ratio $\log\frac{d\mu}{d\nu}$ integrable with respect to $\mu$. Let $f$ be a real function with $f$ integrable for $\mu$, $e^{f}$ integrable for $\nu$, and

$$\int e^{f}\, d\nu = 1.$$

Then

$$\int f\, d\mu \le \int \log\frac{d\mu}{d\nu}\, d\mu.$$
