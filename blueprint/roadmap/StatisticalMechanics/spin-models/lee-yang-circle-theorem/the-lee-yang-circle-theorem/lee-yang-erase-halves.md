# Removal of listed half-edge variables from a variable set

Let $G = (V, E)$ be a finite simple graph and $\beta \in \mathbb{R}$. For a list $L$ of pairs $(v, e)$ of a vertex and an edge and a set $S$ of the [variables](lee-yang-var.md) of the half-edge polynomial (an anchor variable $z_v$ for each vertex $v$ and a variable $w_{v,e}$ for each pair of a vertex $v$ and an edge $e$),
the set obtained by removing from $S$ the half-edge variables $w_{v, e}$ of the pairs $(v, e)$ in $L$.
