# Consistency of a variable set with a list of incidences

Let $G = (V, E)$ be a finite simple graph and $\beta \in \mathbb{R}$. A set $S$ of the [variables](lee-yang-var.md) of the half-edge polynomial (an anchor variable $z_v$ for each vertex $v$ and a variable $w_{v,e}$ for each pair of a vertex $v$ and an edge $e$) is consistent with a list $L$ of pairs $(v, e)$ when, for
every $(v, e)$ in $L$, the anchor variable $z_v$ lies in $S$ if and only if the half-edge variable
$w_{v, e}$ does.
