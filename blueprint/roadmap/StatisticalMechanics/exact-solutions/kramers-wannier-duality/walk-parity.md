# Crossing parity of a walk with respect to an edge set

Let $G_p$ be a simple graph on a set $V$, $\delta$ a finite set of unordered pairs, and $W$ a walk of $G_p$ with vertices $w_0, \dots, w_m$. The crossing parity is the parity of the number of steps $i$ with $\{w_i, w_{i+1}\} \in \delta$ (even, that is false, for the trivial walk).
