# Spin configuration from crossing parities along walks

Let $G_p$ be a simple graph on a finite set $V$ that is connected, $\delta$ a finite set of unordered pairs, and $v_0 \in V$. The parity configuration assigns to $v \in V$ the [crossing parity](walk-parity.md) with respect to $\delta$ of a chosen walk of $G_p$ from $v_0$ to $v$.
