# List of first-return segments avoiding a state

For a set $E$, $e, r \in E$ and a list of lists $(s^1, \dots, s^k)$, the list is valid when every $s^i$ is a first-return segment at $e$ none of whose entries equals $r$; here a first-return segment at $e$ is a list $(e, y_1, \dots, y_k, e)$ with all $y_i \ne e$.
