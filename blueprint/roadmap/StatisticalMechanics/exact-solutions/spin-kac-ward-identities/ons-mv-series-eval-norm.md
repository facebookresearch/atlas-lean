# Sum of absolute values of an evaluated power series

For a set $E$, a power series $\Phi = \sum_m \phi_m X^m$ and weights $\eta : E \to \mathbb{C}$, the value is $\sum_m |\phi_m\, \eta^m|$ over all finitely supported exponents (a non-summable family counting as $0$), where $\eta^m = \prod_e \eta(e)^{m(e)}$.
