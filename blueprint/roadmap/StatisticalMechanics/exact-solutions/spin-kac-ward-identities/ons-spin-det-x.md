# Sector determinant as a function of $x$

For $L \in \mathbb{N}$, $x \in \mathbb{R}$ and $a, b \in \{0, 1\}$, the value is

$$D_L(x; a, b) = \prod_{i=0}^{L-1} \prod_{j=0}^{L-1} \Big((1 + x^2)^2 - 2x(1 - x^2)\big(\cos\theta_i^a + \cos\theta_j^b\big)\Big), \qquad \theta_i^a = \frac{2\pi(i + a/2)}{L}.$$
