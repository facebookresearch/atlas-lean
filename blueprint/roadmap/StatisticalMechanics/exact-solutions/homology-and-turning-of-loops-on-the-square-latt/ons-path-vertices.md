# Lattice points visited by a path from the origin

For a list $(d_0, \dots, d_{m-1})$ of directions, the vertex list is $(z_0, z_1, \dots, z_m)$ with $z_k = s(d_0) + \dots + s(d_{k-1})$ (so $z_0 = (0, 0)$), of length $m + 1$, where directions are labelled $0, 1, 2, 3$ with unit steps $s(0) = (1, 0)$, $s(1) = (0, 1)$, $s(2) = (-1, 0)$, $s(3) = (0, -1)$.
