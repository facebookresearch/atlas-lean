# Edge set of a closed walk of darts

For $L, n \in \mathbb{N}$ and darts $d_0, \dots, d_{n-1}$ of the discrete torus $T_L = (\mathbb{Z}/L\mathbb{Z})^2$ ($L \in \mathbb{N}$, with $\mathbb{Z}/0\mathbb{Z} = \mathbb{Z}$), the edge set is the set of the edges $\{p_k, p_k + s(\mu_k)\}$ of the darts $d_k = (p_k, \mu_k)$, where directions are labelled $0, 1, 2, 3$ with unit steps $s(0) = (1, 0)$, $s(1) = (0, 1)$, $s(2) = (-1, 0)$, $s(3) = (0, -1)$ (repeated edges are counted once).
