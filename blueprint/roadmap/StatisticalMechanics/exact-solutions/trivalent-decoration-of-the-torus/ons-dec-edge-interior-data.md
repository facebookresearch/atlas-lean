# Interior points of the route of a decorated edge

For $L \in \mathbb{N}$ and darts $d = (p, \mu)$, $e$, the interior data is a list of three [micro points](ons-dec-micro-point.md) (a cell and an offset in $\{0, \dots, 7\}^2$). If $e = \bar d$ it is: for $\mu = 0$: $(p; 7, 4), (p + s(0); 0, 4), (p + s(0); 1, 4)$; for $\mu = 1$: $(p; 4, 7), (p + s(1); 4, 0), (p + s(1); 4, 1)$; for $\mu = 2$: $(p; 1, 4), (p; 0, 4), (p + s(2); 7, 4)$; for $\mu = 3$: $(p; 4, 1), (p; 4, 0), (p + s(3); 4, 7)$. Otherwise, for the internal pairs of directions $(\mu, \nu)$ of $d$ and $e$: $(0, 1)$: $(p; 6, 5), (p; 6, 6), (p; 5, 6)$; $(1, 0)$: the reverse list; $(1, 2)$: $(p; 3, 6), (p; 2, 6), (p; 2, 5)$; $(2, 1)$: the reverse; $(2, 3)$: $(p; 2, 3), (p; 2, 2), (p; 3, 2)$; $(3, 2)$: the reverse; and the empty list in all other cases.
