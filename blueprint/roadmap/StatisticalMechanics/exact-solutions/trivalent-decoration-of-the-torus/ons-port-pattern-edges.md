# Torus edge set of a port pattern

For $L \ge 1$ and a port pattern $P$, the torus edge set is $\{\{p, p + s(\mu)\} : P(p, \mu) = 1\}$, the [underlying edges](ons-port-edge.md) of the darts with bit $1$; here a [port pattern](ons-port-pattern.md) $P$ assigns a bit $P(d) \in \mathbb{Z}/2$ to each dart with $P(\bar d) = P(d)$ and $\sum_{\mu} P(p, \mu) = 0$ at every site $p$.
