# Even decorated subgraph determined by a port pattern

For $L \ge 1$ and a port pattern $P$, the decorated edge set is the set of edges $e$ of the [decorated graph](ons-dec-graph.md) $\mathcal{D}_L$ whose [bit](ons-dec-edge-bit.md) for $P$ is $1$; here a [port pattern](ons-port-pattern.md) $P$ assigns a bit $P(d) \in \mathbb{Z}/2$ to each dart with $P(\bar d) = P(d)$ and $\sum_{\mu} P(p, \mu) = 0$ at every site $p$.
