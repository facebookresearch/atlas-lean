# Adjacency through an edge of a multigraph edge set

Let $V$ be a finite set and $\iota$ a finite index set with an endpoint map $i \mapsto \mathrm{ends}(i)$ to unordered pairs of $V$ (a multigraph). For $K \subseteq \iota$ and $a, b \in V$, $a$ and $b$ are adjacent through $K$ when $a \ne b$ and
$\mathrm{ends}(i) = \{a, b\}$ for some $i \in K$.
