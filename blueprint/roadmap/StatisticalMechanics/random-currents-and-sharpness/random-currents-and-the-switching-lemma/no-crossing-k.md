# Multigraph edge set with no edge crossing a vertex set

Let $V$ be a finite set and $\iota$ a finite index set with an endpoint map $i \mapsto \mathrm{ends}(i)$ to unordered pairs of $V$ (a multigraph). For $m \subseteq \iota$ and $S \subseteq V$, this condition holds when every $i \in m$ lies inside $S$ or inside
$V \setminus S$.
