# Cluster of a vertex in a multigraph edge set

Let $V$ be a finite set and $\iota$ a finite index set with an endpoint map $i \mapsto \mathrm{ends}(i)$ to unordered pairs of $V$ (a multigraph). For $K \subseteq \iota$ and $u \in V$, the cluster of $u$ in $K$ is the set of $x \in V$
[connected](conn-k.md) to $u$ through $K$; it always contains $u$.
