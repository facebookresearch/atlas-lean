# High-temperature source sum

For a finite set $V$, a finite set $E$ of unordered pairs, weights $t_e \in \mathbb{R}$ and $A \subseteq V$, the high-temperature source
sum is

$$\sum_{\substack{F \subseteq E \\ \partial F = A}} \prod_{e \in F} t_e,$$

where $\partial F$ is the set of the vertices lying in an odd number of pairs of $F$.
