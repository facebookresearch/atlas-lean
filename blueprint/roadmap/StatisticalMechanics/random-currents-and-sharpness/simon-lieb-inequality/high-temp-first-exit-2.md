# Chosen first-exit data

For a finite simple graph $G$, a set $K$ of edges of $G$ whose [odd-degree vertices](has-odd-boundary.md) form
$\{o\} \,\triangle\, \{z\}$, and a vertex set $S$ with $o \in S$ and $z \notin S$, this is a fixed choice of
[first-exit data](high-temp-first-exit.md) for $K$, $o$, $z$ and $S$ (such data always exist).
