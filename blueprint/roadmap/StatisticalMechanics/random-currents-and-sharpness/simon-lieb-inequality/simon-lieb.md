# Simon–Lieb type inequality for a nonnegative two-point function

For a set $V$, a function $\tau \colon V \times V \to \mathbb{R}$, a root $o$, a finite set $S$, weights $w \colon V \times V \to \mathbb{R}$ and a
finite set $B$ of boundary targets, this condition holds when $\tau \ge 0$, $w \ge 0$ and

$$\tau(o, z) \le \sum_{x \in S} \sum_{y \in B} w(x, y)\, \tau(y, z) \quad \text{for every } z \notin S.$$
