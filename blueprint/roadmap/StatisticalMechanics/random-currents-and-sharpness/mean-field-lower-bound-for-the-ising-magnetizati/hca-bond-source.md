# Ghost source set of a bond covariance

For a finite set $V$ with an added ghost vertex $\mathfrak g$, a vertex $o$ and a pair $e = \{x, y\}$, the ghost source set
is $\{\mathfrak g\} \cup (\{o\} \,\triangle\, \{x, y\}) \subseteq V \sqcup \{\mathfrak g\}$, attached to the covariance of
$\sigma_o$ and $\sigma_x \sigma_y$.
