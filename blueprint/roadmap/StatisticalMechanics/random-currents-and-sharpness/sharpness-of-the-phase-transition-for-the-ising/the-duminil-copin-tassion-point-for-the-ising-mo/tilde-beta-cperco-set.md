# Inverse temperatures with a percolation witness $\varphi(S) < 1$

For $d \in \mathbb{N}$, this is the set of $\beta \ge 0$ for which some finite $S \subseteq \mathbb{Z}^d$ containing the origin satisfies
$\varphi_p(S) < 1$ at $p = 1 - e^{-\beta}$, with $\varphi_p$ the [percolation quantity](phi-beta.md).
