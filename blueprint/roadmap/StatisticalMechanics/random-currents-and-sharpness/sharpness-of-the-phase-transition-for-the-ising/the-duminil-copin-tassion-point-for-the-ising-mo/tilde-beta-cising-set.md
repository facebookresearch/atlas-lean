# Inverse temperatures with an Ising witness $\varphi_\beta(S) < 1$

For $d \in \mathbb{N}$, this is the set of $\beta \ge 0$ for which some finite $S \subseteq \mathbb{Z}^d$ containing the origin satisfies
$\varphi_\beta(S) < 1$, with $\varphi_\beta$ the [Duminil-Copin–Tassion quantity](phi-ising.md).
