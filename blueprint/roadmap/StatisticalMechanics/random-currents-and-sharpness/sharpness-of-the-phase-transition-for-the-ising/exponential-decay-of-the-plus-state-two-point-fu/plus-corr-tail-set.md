# Tail set of plus-state correlations

For $d, n \in \mathbb{N}$ and $\beta \in \mathbb{R}$, this is the set $\{0\} \cup \{\langle \sigma_0 \sigma_z \rangle^+_\beta : \|z\|_1 \ge n\}$, with
$\langle \sigma_0 \sigma_z \rangle^+_\beta$ the zero-field plus-state [two-point function](../../simon-lieb-inequality/plus-corr.md) and $\|z\|_1 = \sum_i |z_i|$.
