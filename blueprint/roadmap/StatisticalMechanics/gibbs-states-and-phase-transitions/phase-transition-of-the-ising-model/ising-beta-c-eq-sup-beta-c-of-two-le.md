# Inf-based and sup-based Ising critical points agree for $d \ge 2$

For $d \ge 2$, with $m^*$ the [spontaneous magnetization](magnetization.md),

$$\inf\{\beta \ge 0 : m^*(\beta) > 0\} = \sup\{\beta > 0 : m^*(\beta) = 0\},$$

where an empty infimum is $0$ and the supremum of a set that is empty or unbounded above is $0$.
