# Off-centre domination of all-plus events

For $d \in \mathbb{N}$, $\beta, h \in \mathbb{R}$ and $g \in \mathbb{Z}^d$, this condition holds when for every finite
set $T \subseteq \mathbb{Z}^d$ there is $c \in \mathbb{N}$ such that for every $m \in \mathbb{N}$,

$$\mu^+_{m+c}(O_T) \le \mu^+_m(O_{T - g}) \le \mu^+_{m \dot- c}(O_T),$$

with $\mu^+_n$ the [plus-boundary box measures](../dlr-states-of-the-ising-model/plus-measure.md) $\mu^+_n$, $O_T = \{\omega : \omega_x = + \text{ for all } x \in T\}$, $T - g = \{x - g : x \in T\}$ and
$m \dot- c = \max(m - c, 0)$.
