# Extreme point of the DLR states

For $d \in \mathbb{N}$, $\beta, h \in \mathbb{R}$ and a measure $\mu$ on the configurations $\omega \in \{+, -\}^{\mathbb{Z}^d}$, this condition holds
when for all probability measures $\nu_1, \nu_2$ that are [DLR states](../dlr-states-of-the-ising-model/is-dlrstate.md) and all
finite $a, b > 0$ with $a + b = 1$, the equality $\mu = a \nu_1 + b \nu_2$ implies $\nu_1 = \nu_2$. When $\mu$ is
itself a DLR probability measure, this says that $\mu$ is an extreme point of the convex set of DLR probability
measures; the condition does not require $\mu$ to be one (it holds, for instance, for $\mu = 0$).
