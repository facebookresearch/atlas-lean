# Boltzmann weight on a set with a boundary condition

For $d \in \mathbb{N}$, a configuration $\eta$, a finite set $S \subseteq \mathbb{Z}^d$, $\beta, h \in \mathbb{R}$ and
spins $\tau$ on $S$, the Boltzmann weight is $w_\eta(\tau) = e^{-\beta H_\eta(\tau)}$, with $H_\eta(\tau)$ the
[energy](gv-energy.md) on $S$ with boundary condition $\eta$.
