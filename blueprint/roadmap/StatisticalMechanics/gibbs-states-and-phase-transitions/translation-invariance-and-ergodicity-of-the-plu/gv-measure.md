# Finite-volume Gibbs measure on a finite set

For $d \in \mathbb{N}$, a configuration $\eta$, a finite set $S \subseteq \mathbb{Z}^d$ and $\beta, h \in \mathbb{R}$, the
finite-volume Gibbs measure on $S$ with boundary condition $\eta$ is $\sum_\tau P_\eta(\tau)\, \delta_{\eta\tau}$,
the sum over all spin assignments $\tau$ on $S$, with $P_\eta$ the [Gibbs probability](gv-prob.md) and
$\eta\tau$ the [glued configuration](gv-glue.md).
