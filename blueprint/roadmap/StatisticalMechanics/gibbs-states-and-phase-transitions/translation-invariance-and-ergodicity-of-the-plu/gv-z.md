# Partition function on a set with a boundary condition

For $d \in \mathbb{N}$, a configuration $\eta$, a finite set $S \subseteq \mathbb{Z}^d$ and $\beta, h \in \mathbb{R}$, the
partition function is $Z_\eta = \sum_\tau w_\eta(\tau)$, the sum of the [Boltzmann weights](gv-weight.md)
over all spin assignments $\tau$ on $S$.
