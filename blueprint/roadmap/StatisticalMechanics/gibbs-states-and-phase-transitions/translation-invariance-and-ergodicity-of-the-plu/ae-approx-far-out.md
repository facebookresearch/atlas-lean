# Approximation in measure by events measurable outside every box

For $d \in \mathbb{N}$, a measure $\mu$ on the configurations $\omega \in \{+, -\}^{\mathbb{Z}^d}$ and an event $s$, this condition holds when for
every box $\Lambda_k$ and every $\varepsilon > 0$ there is an event $A$ determined by the spins outside
$\Lambda_k$ with $\mu(s \,\triangle\, A) < \varepsilon$.
