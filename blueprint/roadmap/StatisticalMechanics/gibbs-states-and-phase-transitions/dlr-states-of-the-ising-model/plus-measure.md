# Plus-boundary Ising measure in a box

For $d, n \in \mathbb{N}$ and $\beta, h \in \mathbb{R}$, the plus-boundary Ising measure in $\Lambda_n = \{x \in \mathbb{Z}^d : |x_i| \le n \text{ for all } i\}$
is the [finite-volume Gibbs measure](fv-measure.md) with the all-plus boundary condition and the [bonds touching](bond-finset-touch.md)
$\Lambda_n$.
