# Finite-volume partition function with a boundary condition

Let $d, n \in \mathbb{N}$, $\eta$ a configuration of $\mathbb{Z}^d$, $B$ a finite set of unordered pairs of
sites and $\beta, h \in \mathbb{R}$. The partition function is $Z_\eta = \sum_\tau w_\eta(\tau)$, the sum of
the [Boltzmann weights](fv-weight.md) over all spin assignments $\tau$ on $\Lambda_n = \{x \in \mathbb{Z}^d : |x_i| \le n \text{ for all } i\}$.
