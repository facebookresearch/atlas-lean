# Stochastic domination on increasing clopen events

For a set $E$ and measures $\mu, \nu$ on $\{+, -\}^E$, $\mu$ is dominated by $\nu$ on increasing clopen
events when $\mu(A) \le \nu(A)$ (as real numbers, an infinite mass counting as $0$) for every
[increasing clopen event](clopen-up-system.md) $A$.
