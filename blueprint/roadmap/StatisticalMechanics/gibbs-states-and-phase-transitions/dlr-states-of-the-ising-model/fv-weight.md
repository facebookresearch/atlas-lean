# Finite-volume Boltzmann weight with a boundary condition

Let $d, n \in \mathbb{N}$, $\eta$ a configuration of $\mathbb{Z}^d$, $B$ a finite set of unordered pairs of
sites and $\beta, h \in \mathbb{R}$. For spins $\tau$ on $\Lambda_n = \{x \in \mathbb{Z}^d : |x_i| \le n \text{ for all } i\}$, the Boltzmann weight is
$w_\eta(\tau) = e^{-\beta H_\eta(\tau)}$, with $H_\eta(\tau)$ the [box energy](fv-energy.md) with boundary
condition $\eta$.
