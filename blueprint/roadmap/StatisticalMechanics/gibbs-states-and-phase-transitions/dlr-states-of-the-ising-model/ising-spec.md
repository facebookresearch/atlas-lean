# Ising specification in a box

For $d, n \in \mathbb{N}$, a finite bond set $B$ and $\beta, h \in \mathbb{R}$, the Ising specification in
$\Lambda_n$ is the kernel $\eta \mapsto \gamma^\eta_n$, where $\gamma^\eta_n$ is the [finite-volume Gibbs measure](fv-measure.md) with
boundary condition $\eta$ and bond set $B$, viewed as measurable with respect to the σ-algebra generated
by the spins outside $\Lambda_n$.
