# Infinite-volume minus state as a subsequential weak limit

For $d \in \mathbb{N}$ and $\beta, h \in \mathbb{R}$, the minus state is the [chosen subsequential weak limit](limit-state.md) of the
[minus-boundary box measures](minus-measure.md): a probability measure on the configurations of
$\mathbb{Z}^d$ to which some subsequence converges weakly. The definition does not assert that the whole
sequence converges.
