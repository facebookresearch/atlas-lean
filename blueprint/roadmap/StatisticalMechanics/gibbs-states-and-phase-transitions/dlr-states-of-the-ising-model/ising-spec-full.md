# Ising specification as a Markov kernel

For $d, n \in \mathbb{N}$, a finite bond set $B$ and $\beta, h \in \mathbb{R}$, the Ising specification in
$\Lambda_n$ is the Markov kernel $\eta \mapsto \gamma^\eta_n$ from the configurations of $\mathbb{Z}^d$ (with
the full Borel σ-algebra) to themselves, where $\gamma^\eta_n$ is the [finite-volume Gibbs measure](fv-measure.md) with boundary condition
$\eta$ and bond set $B$.
