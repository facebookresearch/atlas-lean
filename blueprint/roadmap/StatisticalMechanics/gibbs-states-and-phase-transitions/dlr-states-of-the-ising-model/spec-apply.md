# Specification applied to a function

For $d, n \in \mathbb{N}$, a finite bond set $B$, $\beta, h \in \mathbb{R}$ and a function $f$ on the
configurations of $\mathbb{Z}^d$, the specification applied to $f$ is $\eta \mapsto \int f\, d\gamma^\eta_n$,
with $\gamma^\eta_n$ the [finite-volume Gibbs measure](fv-measure.md) in $\Lambda_n$ with boundary condition $\eta$ and bond set $B$ (the
integral being $0$ when $f$ is not integrable).
