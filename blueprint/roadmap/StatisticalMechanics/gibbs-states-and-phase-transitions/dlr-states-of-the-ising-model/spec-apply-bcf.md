# Specification applied to a bounded continuous function

For $d, n \in \mathbb{N}$, a finite bond set $B$, $\beta, h \in \mathbb{R}$ and a bounded continuous function
$f$ on the configurations of $\mathbb{Z}^d$, the function $\eta \mapsto \int f\, d\gamma^\eta_n$, with
$\gamma^\eta_n$ the [finite-volume Gibbs measure](fv-measure.md) with boundary condition $\eta$, is bounded and continuous; this is that
function as a bounded continuous function.
