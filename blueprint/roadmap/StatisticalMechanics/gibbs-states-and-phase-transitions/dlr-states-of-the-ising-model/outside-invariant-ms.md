# $\sigma$-algebra of events determined outside a region

For a set $E$ and a region $\Lambda \subseteq E$, this is the σ-algebra of events $A \subseteq \{+, -\}^E$
determined by the spins outside $\Lambda$: whenever $\omega$ and $\omega'$ agree at every site outside
$\Lambda$, $\omega \in A$ if and only if $\omega' \in A$.
