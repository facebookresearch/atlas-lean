# Configuration glued from inside spins and a boundary condition

For $d, n \in \mathbb{N}$, a configuration $\eta$ of $\mathbb{Z}^d$ and spins $\tau$ on $\Lambda_n = \{x \in \mathbb{Z}^d : |x_i| \le n \text{ for all } i\}$, the
glued configuration $\eta\tau$ is equal to $\tau$ in $\Lambda_n$ and to $\eta$ outside $\Lambda_n$.
