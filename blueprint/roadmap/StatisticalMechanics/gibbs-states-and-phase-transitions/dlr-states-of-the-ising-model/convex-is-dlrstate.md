# Convexity of the set of DLR states

Let $d \in \mathbb{N}$, $\beta, h \in \mathbb{R}$, let $a, b \in [0, \infty]$ with $a + b = 1$, and let $\mu_1$
and $\mu_2$ be finite measures on the configurations of $\mathbb{Z}^d$ such that $a \mu_1 + b \mu_2$ is
finite. If $\mu_1$ and $\mu_2$ are [DLR state](is-dlrstate.md)s, then so is $a \mu_1 + b \mu_2$.
