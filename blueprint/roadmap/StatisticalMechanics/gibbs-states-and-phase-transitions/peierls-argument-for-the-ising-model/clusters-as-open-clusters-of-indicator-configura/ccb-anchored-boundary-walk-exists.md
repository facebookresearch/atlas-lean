# Anchored closed-walk decoding of cluster contours in $\mathbb{Z}^2$

For $n, \ell \in \mathbb{N}$, with $d = 2$, the box $\Lambda_n = \{x \in \mathbb{Z}^d : |x_i| \le n \text{ for all } i\}$ and $B_n$ the set of nearest-neighbour bonds of $\mathbb{Z}^d$ with at least one endpoint in $\Lambda_n$, this condition holds when there
is a map assigning a finite set of edges to every closed nearest-neighbour walk of $\mathbb{Z}^2$ such that for every connected cluster in $\Lambda_n$ (a set $K \subseteq \Lambda_n$ containing the origin whose sites are all joined to the origin by nearest-neighbour paths inside $K$) whose contour length (the number of bonds of $B_n$ with exactly one endpoint in $K$) is $\ell$, the
set of bonds of $B_n$ crossing $K$ is assigned to some closed walk of length $\ell$ based at a site of
the [anchor row](ccb-anchor-row.md) $\{(j, 0) : 0 \le j < \ell\}$.
