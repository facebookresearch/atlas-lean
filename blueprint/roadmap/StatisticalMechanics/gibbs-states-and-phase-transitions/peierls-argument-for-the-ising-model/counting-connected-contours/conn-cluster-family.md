# Connected clusters in the box containing the origin

For $d, n \in \mathbb{N}$, this is the family of [connected clusters](is-connected-cluster.md) contained in
the box $\Lambda_n = \{x \in \mathbb{Z}^d : |x_i| \le n \text{ for all } i\}$: the sets $K \subseteq \Lambda_n$ that contain the origin and whose sites are all joined to the
origin by nearest-neighbour paths inside $K$.
