# Finite face set containing the face-boundary support

The faces of $\mathbb{Z}^2$ are the unit squares, each labelled by its lower-left corner. For a finite set $K \subseteq \mathbb{Z}^2$, this is a fixed choice of a finite set of faces
containing every face incident to an edge of the face-boundary graph of $K$ (adjacent faces joined when the primal edge between them has exactly one endpoint in $K$).
