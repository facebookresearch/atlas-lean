# Connectedness of the face-boundary graph on a face set

The faces of $\mathbb{Z}^2$ are the unit squares, each labelled by its lower-left corner. For a set $K \subseteq \mathbb{Z}^2$ and a finite set $T$ of faces, this condition holds
when the face-boundary graph of $K$ (adjacent faces joined when the primal edge between them has exactly one endpoint in $K$), restricted to $T$, is connected (in particular $T$ is nonempty).
