# Exterior component of the complement of a set

For $S \subseteq \mathbb{Z}^2$ and $n \in \mathbb{N}$, this is the set of sites joined to the site
$(n + 1, n + 1)$, outside $\Lambda_n$, by a nearest-neighbour path all of whose sites lie outside $S$ (it
reduces to $\{(n + 1, n + 1)\}$ if that site lies in $S$).
