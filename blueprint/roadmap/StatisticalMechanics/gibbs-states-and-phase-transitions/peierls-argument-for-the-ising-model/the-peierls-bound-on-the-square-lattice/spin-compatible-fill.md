# Set with its holes filled

For $S \subseteq \mathbb{Z}^2$ and $n \in \mathbb{N}$, let $b = (n + 1, n + 1)$. The filled set is the complement of the
[exterior component](outer-exterior-component.md) of $S$, that is, of the set consisting of $b$ and of the sites joined to
$b$ by a nearest-neighbour path all of whose sites lie outside $S$. When $S \subseteq \Lambda_n = \{-n, \dots, n\}^2$, the site
$b$ lies in the unbounded component of $\mathbb{Z}^2 \setminus S$, and the filled set is $S$ together with its holes (the finite
components of $\mathbb{Z}^2 \setminus S$). For general $S$ this description can fail: if $b \in S$, the exterior component is
$\{b\}$ and the filled set is $\mathbb{Z}^2 \setminus \{b\}$, which does not contain $S$.
