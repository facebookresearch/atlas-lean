# The outer contour map exists in every box

For every $n \in \mathbb{N}$, the [outer contour map condition](../outer-contours-on-the-square-lattice/outer-contour-map.md)
holds in $\Lambda_n = \{-n, \dots, n\}^2$. An interior assignment that witnesses it sends a closed walk to the
connected set in $\Lambda_n$ containing the origin whose crossing bonds the walk traces, which is unique, and each
configuration with the origin minus is sent to a simple cycle through the whole contour of its
[filled](spin-compatible-fill.md) minus cluster, based at a site $(j, 0)$ with $j$ less than the contour length.
