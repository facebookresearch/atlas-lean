# Origin-only minus configuration satisfies the filled-cluster data

The faces of $\mathbb{Z}^2$ are the unit squares, each labelled by its lower-left corner. For every $n \in \mathbb{N}$, with $\Lambda_n = \{-n, \dots, n\}^2$ and $B_n$ the nearest-neighbour bonds with at least one endpoint in $\Lambda_n$, there is a spin
assignment $\tau$ on $\Lambda_n$ (the one with only the origin minus) such that the configuration $\sigma_\tau$ equal to $\tau$ in $\Lambda_n$ and plus outside is minus at
the origin and the set $K = \{0\}$ is a connected cluster in $\Lambda_n$ for which the
[contour event](../contours-of-minus-clusters/contour-event.md) of $K$ for $B_n$ holds for $\sigma_\tau$,
and there are a finite set $T$ of faces containing every face incident to an edge of the face-boundary graph of $K$ (adjacent faces joined when the primal edge between them has exactly one endpoint in $K$),
on which that graph is connected, and an integer $j$ with $0 \le j < \ell(K)$ and $(j, 0) \in T$, $\ell(K)$ being the number of
bonds of $B_n$ with exactly one endpoint in $K$.
