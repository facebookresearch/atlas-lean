# Closed-walk decoding of each realised contour from an anchor pool

For $d, n, \ell \in \mathbb{N}$, this condition holds when there are a set of at most $\ell$ anchor sites and
a map assigning a finite set of edges to every closed nearest-neighbour walk of $\mathbb{Z}^d$ such that every contour of length $\ell$ realised by a connected cluster in the box $\Lambda_n = \{x \in \mathbb{Z}^d : |x_i| \le n \text{ for all } i\}$
is assigned to some closed walk of length $\ell$ based at one of the anchors.
