# Closed-walk decoding of each realised contour from an axis site

For $d, n, \ell \in \mathbb{N}$, this condition holds when there is a map assigning a finite set of edges to every closed nearest-neighbour walk of $\mathbb{Z}^d$ such that every contour of
length $\ell$ realised by a connected cluster in the box $\Lambda_n = \{x \in \mathbb{Z}^d : |x_i| \le n \text{ for all } i\}$ (the set of bonds touching $\Lambda_n$ that
cross the cluster) is assigned to some closed walk of length $\ell$ based at an
[axis site](axis-vertex.md) $(j, 0, \dots, 0)$ with $0 \le j < \ell$.
