# Faces of a set reachable from a face in the face-boundary graph

The faces of $\mathbb{Z}^2$ are the unit squares, each labelled by its lower-left corner. For a set $K \subseteq \mathbb{Z}^2$, a finite set $T$ of faces and a face $f$, this is the
set of faces $g \in T$ joined to $f$ by a path in the face-boundary graph of $K$ (adjacent faces joined when the primal edge between them has exactly one endpoint in $K$).
