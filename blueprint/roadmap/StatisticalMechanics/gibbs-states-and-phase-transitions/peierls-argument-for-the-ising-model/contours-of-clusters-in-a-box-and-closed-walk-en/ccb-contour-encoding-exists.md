# Injective closed-walk encoding of clusters of contour length $\ell$

For $d, n, \ell \in \mathbb{N}$, this condition holds when there are a set of at most $\ell$ anchor sites and
a map assigning to each finite set of sites a closed nearest-neighbour walk of $\mathbb{Z}^d$, such that every
set in the [contour fibre](ccb-contour-fiber.md) (the connected clusters in $\Lambda_n$ with contour
length $\ell$) is sent to a walk of length $\ell$ based at an anchor, and the map is injective on the
fibre.
