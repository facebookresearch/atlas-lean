# Connected clusters in a box with contour length $\ell$

For $d, n, \ell \in \mathbb{N}$, with the box $\Lambda_n = \{x \in \mathbb{Z}^d : |x_i| \le n \text{ for all } i\}$ and $B_n$ the set of nearest-neighbour bonds of $\mathbb{Z}^d$ with at least one endpoint in $\Lambda_n$, the contour fibre is the set of the
$K$ that are a connected cluster in $\Lambda_n$ (a set $K \subseteq \Lambda_n$ containing the origin whose sites are all joined to the origin by nearest-neighbour paths inside $K$) and have contour length (the number of bonds of $B_n$ with exactly one endpoint in $K$) exactly $\ell$.
