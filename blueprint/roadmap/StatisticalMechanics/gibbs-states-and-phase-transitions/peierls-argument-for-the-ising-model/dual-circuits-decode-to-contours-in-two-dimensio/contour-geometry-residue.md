# Connected face-boundary graphs at the axis for all connected clusters

The faces of $\mathbb{Z}^2$ are the unit squares, each labelled by its lower-left corner $f \in \mathbb{Z}^2$. For $n, \ell \in \mathbb{N}$, with $d = 2$ and $\Lambda_n = \{-n, \dots, n\}^2$, this
condition holds when every connected cluster $K$ in $\Lambda_n$ whose contour length (for the bonds
touching $\Lambda_n$) is $\ell$ satisfies: the face-boundary graph of $K$ (adjacent faces joined when the primal edge between them has exactly one endpoint in $K$), restricted to $T_K$, is connected (and $T_K$
is nonempty), and $T_K$ contains an axis face $(j, 0)$ with $0 \le j < \ell$, where $T_K$ a fixed choice, for each finite $K$, of a finite set of faces containing every face incident to an edge of the face-boundary graph of $K$.
