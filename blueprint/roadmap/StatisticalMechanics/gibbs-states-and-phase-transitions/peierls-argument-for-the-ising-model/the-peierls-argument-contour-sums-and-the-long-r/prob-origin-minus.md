# Probability that the origin spin is minus

For $d, n \in \mathbb{N}$, a boundary condition $\eta$, a finite bond set $B$ and $\beta, h \in \mathbb{R}$, this is
the probability that the spin at the origin is minus under the [finite-volume Gibbs measure](../../dlr-states-of-the-ising-model/fv-measure.md) in $\Lambda_n$ with boundary
condition $\eta$, bond set $B$, inverse temperature $\beta$ and field $h$.
