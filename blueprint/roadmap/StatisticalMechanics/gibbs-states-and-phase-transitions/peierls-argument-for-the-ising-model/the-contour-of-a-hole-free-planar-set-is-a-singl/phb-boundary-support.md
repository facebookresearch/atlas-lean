# Support of the face-boundary graph of a finite set

The faces of $\mathbb{Z}^2$ are the unit squares, each labelled by its lower-left corner. For a finite set $K \subseteq \mathbb{Z}^2$, this is the set of faces incident to an edge
of the face-boundary graph of $K$ (adjacent faces joined when the primal edge between them has exactly one endpoint in $K$); it is finite.
