# Face-boundary graph of a finite set as a planar subgraph

The faces of $\mathbb{Z}^2$ are the unit squares, each labelled by its lower-left corner. For a finite set $K \subseteq \mathbb{Z}^2$, this is the face-boundary graph of $K$ (adjacent faces joined when the primal edge between them has exactly one endpoint in $K$), restricted to
the faces incident to its edges, viewed as a finite graph embedded in $\mathbb{Z}^2$ whose edges are lattice
edges.
