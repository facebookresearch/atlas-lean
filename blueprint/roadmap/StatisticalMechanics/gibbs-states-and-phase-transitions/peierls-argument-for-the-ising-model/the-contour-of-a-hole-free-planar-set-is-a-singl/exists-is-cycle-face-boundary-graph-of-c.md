# Contour of a hole-free set as a single simple cycle

Let $K \subseteq \mathbb{Z}^2$ be a finite set with a site in $K$ and a site outside $K$, such that any two
sites of $K$, and any two sites outside $K$, are joined by a path in the
[square lattice with the boundary edges of $K$ removed](../../../../GraphTheory/planar-graphs-and-minors/discrete-jordan-curve-theorem-for-the-square-lat/lattice-minus-barrier.md).
Then for every face $f$ that is an endpoint of an edge of the
[face-boundary graph](../../../../GraphTheory/planar-graphs-and-minors/discrete-jordan-curve-theorem-for-the-square-lat/face-boundary-graph.md)
of $K$, there is a simple cycle of that graph based at $f$ that passes through every edge of the graph.
