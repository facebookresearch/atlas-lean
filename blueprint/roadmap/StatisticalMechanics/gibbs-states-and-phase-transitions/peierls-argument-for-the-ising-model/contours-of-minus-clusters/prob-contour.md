# Probability of the contour event of a set

For $d, n \in \mathbb{N}$, a set $K \subseteq \mathbb{Z}^d$, a boundary condition $\eta$, a finite bond set $B$ and
$\beta \in \mathbb{R}$, this is the probability of the [contour event](contour-event.md) of $K$ (for the bond
set $B$) under the [finite-volume Gibbs measure](../../dlr-states-of-the-ising-model/fv-measure.md) in
$\Lambda_n$ with boundary condition $\eta$, bond set $B$ and zero field.
