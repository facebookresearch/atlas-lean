# Inside configuration with the spins in a set flipped

For $d, n \in \mathbb{N}$, a set $K \subseteq \mathbb{Z}^d$ and spins $\tau$ on the box $\Lambda_n = \{x \in \mathbb{Z}^d : |x_i| \le n \text{ for all } i\}$, this is the spin
assignment on $\Lambda_n$ obtained from $\tau$ by reversing the spins at the sites of $K \cap \Lambda_n$.
