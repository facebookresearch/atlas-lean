# Flipping spins in a set as an involutive equivalence

For $d, n \in \mathbb{N}$ and a set $K \subseteq \mathbb{Z}^d$, [flipping the spins in $K$](flip-interior-on.md) is a
bijection of the spin assignments on the box $\Lambda_n = \{x \in \mathbb{Z}^d : |x_i| \le n \text{ for all } i\}$ that is its own inverse.
