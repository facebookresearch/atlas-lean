# Contour event of a set: opposite spins across every crossing bond

For $d \in \mathbb{N}$, a set $K \subseteq \mathbb{Z}^d$ and a finite set $B$ of unordered pairs of sites, the contour
event of $K$ is the set of configurations $\sigma$ such that every bond $\{x, y\} \in B$ with exactly one
endpoint in $K$ has opposite spins at its endpoints, $\sigma_x \sigma_y = -1$.
