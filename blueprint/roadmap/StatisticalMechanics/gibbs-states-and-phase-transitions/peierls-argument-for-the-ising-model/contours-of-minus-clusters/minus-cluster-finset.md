# Minus cluster of the origin as a finite set

For $d, n \in \mathbb{N}$ and spins $\tau$ on the box $\Lambda_n = \{x \in \mathbb{Z}^d : |x_i| \le n \text{ for all } i\}$ such that the configuration equal to $\tau$ in
$\Lambda_n$ and plus outside is minus at the origin, this is the [minus cluster](minus-cluster.md) of the
origin in that configuration; it is contained in $\Lambda_n$, hence finite.
