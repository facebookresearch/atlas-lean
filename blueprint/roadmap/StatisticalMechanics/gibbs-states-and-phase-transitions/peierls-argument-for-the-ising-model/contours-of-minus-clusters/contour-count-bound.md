# Peierls series bound on the cluster-family contour sum

For $d, n \in \mathbb{N}$ and $\beta \in \mathbb{R}$, with the box $\Lambda_n = \{x \in \mathbb{Z}^d : |x_i| \le n \text{ for all } i\}$ and $B_n$ the set of nearest-neighbour bonds of $\mathbb{Z}^d$ with at least one endpoint in $\Lambda_n$, this condition holds
when

$$\sum_{K \subseteq \Lambda_n} e^{-2\beta\, |\partial_n K|} \le \sum_{\ell \ge 0} \ell (2d)^\ell e^{-2\beta \ell},$$

where $|\partial_n K|$ is the [contour length](contour-len.md) of $K$ (the number of bonds of $B_n$ with
exactly one endpoint in $K$) and the series on the right is taken to be $0$ when it diverges.
