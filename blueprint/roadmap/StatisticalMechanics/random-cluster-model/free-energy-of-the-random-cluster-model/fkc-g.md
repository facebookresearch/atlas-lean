# Van Hove comparison value for a fixed box side

For $d, m \in \mathbb{N}$ and $s, q \in \mathbb{R}$, put

$$g(m) = \frac{2m}{2m + 1}\, f(m) + \Big(1 - \frac{2m}{2m + 1}\Big)\big(-\log(1 - \sigma(s))\big),$$

where $f(m)$ is the [per-edge box free energy](fkc-f.md) of $\Lambda_m = \{-m, \dots, m\}^d$ and $\sigma(s) = e^s/(1 + e^s)$.
