# An edge between differently tagged sites meets a coordinate hyperplane

Let $d, K \in \mathbb{N}$ and let $x, y$ be adjacent sites of the nearest-neighbour graph on $\Lambda_{2K+1} = \{-(2K+1), \dots, 2K+1\}^d$. If $x$ and $y$ have different [orthant tags](qp-box-tag.md) (counting "no tag" as a value), then $x$ or $y$ has some coordinate equal to $0$.
