# Restriction does not increase straddling edges of a tag

Let $K_0$ be a simple graph on a finite set $U$ and let $\tau : U \to T$ assign a tag to each vertex, let $\theta$ be a tag and $S$ a finite set of tags. The number of edges of the [graph induced on the vertices with tags in $S \cup \{\theta\}$](qp-rest-g.md) straddling its set of vertices of tag $\theta$ is at most the number of edges of $K_0$ straddling the set of vertices of tag $\theta$, where an edge straddles a set $A$ of vertices when exactly one of its endpoints lies in $A$.
