# Isomorphism from the all-tag restriction to $\Lambda_{2K+1}$

For $d, K \in \mathbb{N}$, the graph induced by the nearest-neighbour graph on $\Lambda_{2K+1} = \{-(2K+1), \dots, 2K+1\}^d$ on the sites whose [orthant tag](qp-box-tag.md) (or absence of tag) lies in the set of all possible tag values is isomorphic to the nearest-neighbour graph on $\Lambda_{2K+1}$, via the map that forgets the tag condition.
