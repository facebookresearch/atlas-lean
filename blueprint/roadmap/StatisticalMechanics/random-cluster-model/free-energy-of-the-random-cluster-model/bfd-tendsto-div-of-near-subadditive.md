# Fekete's lemma with a sublinear correction

Let $(u_n)$ and $(c_n)$ be real sequences indexed by $n \in \mathbb{N}$ such that $a_n = u_n + c_n$ is subadditive ($a_{m+n} \le a_m + a_n$ for all $m, n$), the set $\{a_n/n : n \in \mathbb{N}\}$ is bounded below (with $a_0/0$ read as $0$), and $c_n/n \to 0$. Then

$$\frac{u_n}{n} \to \inf_{n \ge 1} \frac{a_n}{n} \qquad (n \to \infty).$$
