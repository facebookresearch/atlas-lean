# Bound on the edge gap $|E(\Lambda_{2K+1})| - 2^d |E(\Lambda_K)|$

For $d \ge 1$ and $K \in \mathbb{N}$,

$$|E(\Lambda_{2K+1})| - 2^d\, |E(\Lambda_K)| \le d\,(d + 2)\,(4K + 3)^{d-1},$$

where $|E(\Lambda_n)|$ is the number of edges of the nearest-neighbour graph on $\Lambda_n = \{-n, \dots, n\}^d$.
