# Edges straddling a tag are incident to the hyperplane set

For $d, K \in \mathbb{N}$ and each value $\theta$ of the [orthant tag](qp-box-tag.md) (a sign pattern, or no tag), every edge of the nearest-neighbour graph on $\Lambda_{2K+1} = \{-(2K+1), \dots, 2K+1\}^d$ straddling the set of sites with tag $\theta$ (exactly one endpoint in it) is incident to some site of $J$, where $J$ is the [set of sites of $\Lambda_{2K+1} = \{-(2K+1), \dots, 2K+1\}^d$ with some coordinate equal to $0$](qp-jset.md).
