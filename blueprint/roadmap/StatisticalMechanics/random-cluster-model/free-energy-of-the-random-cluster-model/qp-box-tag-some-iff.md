# Coordinate description of the sites with a given orthant tag

Let $d, K \in \mathbb{N}$, $x \in \Lambda_{2K+1} = \{-(2K+1), \dots, 2K+1\}^d$ and $s \in \{+, -\}^d$. The [orthant tag](qp-box-tag.md) of $x$ is $s$ if and only if, for every coordinate $i$, $1 \le x_i \le 2K + 1$ when $s_i = +$ and $-(2K + 1) \le x_i \le -1$ when $s_i = -$.
