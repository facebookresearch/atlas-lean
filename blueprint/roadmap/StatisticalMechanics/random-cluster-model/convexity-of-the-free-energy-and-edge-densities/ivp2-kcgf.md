# Log-sum-exp cumulant generating function

Let $I$ be a finite set and $w, a : I \to \mathbb{R}$. The log-sum-exp function is

$$K(t) = \log \sum_{i \in I} w_i e^{a_i t}, \qquad t \in \mathbb{R},$$

where $\log x$ means $\log |x|$ for $x \ne 0$ and $\log 0 = 0$ (relevant only when the sum is not positive). For nonnegative weights that are not all zero it is the cumulant generating function of $a$ under the weights $w$.
