# A convex function with both one-sided derivatives logistic

There is a convex function $g : \mathbb{R} \to \mathbb{R}$ such that, for every $t \in \mathbb{R}$, both the [right derivative](pressure-right-deriv.md) $g'_+(t)$ and the [left derivative](pressure-left-deriv.md) $g'_-(t)$ equal $\sigma(t) = e^t/(1 + e^t)$. (The softplus function $t \mapsto \log(1 + e^t)$ is such a function.)
