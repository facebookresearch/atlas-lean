# Convex function has equal one-sided derivatives off a countable set

If $g : \mathbb{R} \to \mathbb{R}$ is convex, then the set $\{x \in \mathbb{R} : g'_-(x) \ne g'_+(x)\}$ is countable, where $g'_-$ and $g'_+$ are the [left](pressure-left-deriv.md) and [right derivatives](pressure-right-deriv.md) of $g$.
