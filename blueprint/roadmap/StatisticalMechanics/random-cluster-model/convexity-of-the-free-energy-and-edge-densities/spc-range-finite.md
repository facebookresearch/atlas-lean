# Tilted log normalizers on a fixed box take finitely many values

Let $d, N \in \mathbb{N}$, let $(G_n)_{n \in \mathbb{N}}$ be simple graphs on the vertex set of the box $\Lambda_N = \{-N, \dots, N\}^d$, and let $t \in \mathbb{R}$. Then the set $\{F_{G_n,2}(t) : n \in \mathbb{N}\}$ is finite, where $F_{G,2}$ is the [ambient tilted log-normalizer](ivp2-ambient-tilt-log-z.md) at $q = 2$.
