# Origin-to-$\partial\Lambda_n$ event as an event on $\Lambda_{n+1}$

For $d, n \in \mathbb{N}$, the inner boundary-connection event is the set of configurations $\rho$ of $\Lambda_{n+1} = \{-(n+1), \dots, n+1\}^d$ whose restriction to the pairs of vertices of $\Lambda_n$ joins the origin to some vertex of $\partial\Lambda_n = \Lambda_n \setminus \Lambda_{n-1}$ by a path of open edges of $\Lambda_n$.
