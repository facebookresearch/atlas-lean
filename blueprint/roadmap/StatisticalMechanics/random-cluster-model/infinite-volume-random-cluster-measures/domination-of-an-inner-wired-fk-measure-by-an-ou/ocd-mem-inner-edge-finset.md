# Inner edge set is the range of the edge map

Let $G_{\mathrm{in}}$ and $G_{\mathrm{out}}$ be simple graphs on finite sets $V_{\mathrm{in}}$ and $V_{\mathrm{out}}$, and $\iota : V_{\mathrm{in}} \to V_{\mathrm{out}}$ a map. An unordered pair $e$ of elements of $V_{\mathrm{out}}$ belongs to the [set of inner pairs](ocd-inner-edge-finset.md) if and only if $e = \{\iota x, \iota y\}$ for some $x, y \in V_{\mathrm{in}}$.
