# Edges of the inner graph map onto the inner edges of the outer graph

Let $G_{\mathrm{in}}$ and $G_{\mathrm{out}}$ be simple graphs on finite sets $V_{\mathrm{in}}$ and $V_{\mathrm{out}}$, and $\iota : V_{\mathrm{in}} \to V_{\mathrm{out}}$ an injective map that [matches adjacency](ocd-adj-match.md) ($x \sim y$ in $G_{\mathrm{in}}$ if and only if $\iota x \sim \iota y$ in $G_{\mathrm{out}}$). The image under $\{x, y\} \mapsto \{\iota x, \iota y\}$ of the edge set of $G_{\mathrm{in}}$ is the set of edges of $G_{\mathrm{out}}$ that are [inner pairs](ocd-inner-edge-finset.md).
