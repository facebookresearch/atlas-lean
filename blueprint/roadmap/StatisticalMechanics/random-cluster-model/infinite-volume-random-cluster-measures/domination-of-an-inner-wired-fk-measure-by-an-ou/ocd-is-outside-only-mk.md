# Cluster of a vertex is outside-only iff the vertex is

Let $G_{\mathrm{in}}$ and $G_{\mathrm{out}}$ be simple graphs on finite sets $V_{\mathrm{in}}$ and $V_{\mathrm{out}}$, and $\iota : V_{\mathrm{in}} \to V_{\mathrm{out}}$ a map, and let $\partial_{\mathrm{out}} \subseteq V_{\mathrm{out}}$ be a set of boundary vertices, and let $\psi$ be a configuration on $V_{\mathrm{out}}$. For every $v \in V_{\mathrm{out}}$, the component of $v$ in the outside graph $O_\psi$ is [outside-only](ocd-is-outside-only.md) if and only if $v$ is [outside-only](ocd-outside-only.md).
