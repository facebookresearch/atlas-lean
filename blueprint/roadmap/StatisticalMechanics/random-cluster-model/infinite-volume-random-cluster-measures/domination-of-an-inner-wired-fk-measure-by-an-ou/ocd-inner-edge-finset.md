# Finite set of inner edges

Let $G_{\mathrm{in}}$ and $G_{\mathrm{out}}$ be simple graphs on finite sets $V_{\mathrm{in}}$ and $V_{\mathrm{out}}$, and $\iota : V_{\mathrm{in}} \to V_{\mathrm{out}}$ a map. The set of inner pairs is the (finite) set $\{\{\iota x, \iota y\} : x, y \in V_{\mathrm{in}}\}$ of images under $\iota$ of all unordered pairs of elements of $V_{\mathrm{in}}$, loops included.
