# Wired $q = 2$ increasing-event probabilities do not grow with the box

Let $d, N, m \in \mathbb{N}$ with $N \le m$, $0 < p < 1$, and let $S$ be an increasing set of configurations of $\Lambda_N$. For a set $S$ of configurations of $\Lambda_N = \{-N, \dots, N\}^d$, $C_S$ denotes the cylinder event of the configurations of $\mathbb{Z}^d$ whose restriction to the pairs of vertices of $\Lambda_N$ lies in $S$. Then $\phi^1_{m+1}(C_S) \le \phi^1_m(C_S)$, where $\phi^1_{m}$ is the [wired box measure](../finite-and-infinite-volume-fk-measures-on-d/wired-finite-measure.md) on $\Lambda_m = \{-m, \dots, m\}^d$ at parameters $(p, 2)$.
