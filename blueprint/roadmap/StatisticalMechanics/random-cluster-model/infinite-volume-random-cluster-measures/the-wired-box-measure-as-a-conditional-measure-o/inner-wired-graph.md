# Open graph of a box configuration with the box boundary wired

For $d, n \in \mathbb{N}$ and a configuration $\omega$ of $\Lambda_n$, where $\Lambda_m = \{-m, \dots, m\}^d$, the wired graph is the wired graph $H_\omega$ of $\Lambda_n$ (the edges of $\Lambda_n$ open in $\omega$ together with all pairs of distinct vertices of $\partial\Lambda_n = \Lambda_n \setminus \Lambda_{n-1}$).
