# Box as an induced subgraph of the next box

For $d, n \in \mathbb{N}$, the inclusion $\Lambda_n \subseteq \Lambda_{n+1}$, where $\Lambda_m = \{-m, \dots, m\}^d$ carries its nearest-neighbour graph, is an embedding of graphs: it is injective, and two vertices of $\Lambda_n$ are adjacent in $\Lambda_n$ if and only if they are adjacent in $\Lambda_{n+1}$.
