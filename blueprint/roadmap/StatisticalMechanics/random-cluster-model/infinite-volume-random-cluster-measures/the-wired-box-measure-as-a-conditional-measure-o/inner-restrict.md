# Restriction of a next-box configuration to the inner edges

For $d, n \in \mathbb{N}$ and a configuration $\rho$ of $\Lambda_{n+1}$, where $\Lambda_m = \{-m, \dots, m\}^d$, the restriction $\rho|_n$ is the configuration of $\Lambda_n$ that gives each pair of vertices of $\Lambda_n$ its state in $\rho$.
