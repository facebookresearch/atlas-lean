# Wiring with every edge inside the annulus

For $d, n \in \mathbb{N}$, a graph $D$ on $\Lambda_{n+1}$, where $\Lambda_m = \{-m, \dots, m\}^d$, is an annulus wiring when no edge of $D$ has an endpoint in $\Lambda_n$ (for every edge $\{u, v\}$ of $D$, $u \notin \Lambda_n$; by symmetry also $v \notin \Lambda_n$).
