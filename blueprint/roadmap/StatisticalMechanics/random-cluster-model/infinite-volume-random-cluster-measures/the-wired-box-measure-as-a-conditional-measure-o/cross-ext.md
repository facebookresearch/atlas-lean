# Extension of a configuration closing the annulus edges

For $d, n \in \mathbb{N}$ and a configuration $\omega$ of $\Lambda_n$, where $\Lambda_m = \{-m, \dots, m\}^d$, the closed-annulus extension $\tilde\omega$ is the configuration of $\Lambda_{n+1}$ that gives each pair with both elements in $\Lambda_n$ its state in $\omega$ and declares every other pair of vertices of $\Lambda_{n+1}$ closed.
