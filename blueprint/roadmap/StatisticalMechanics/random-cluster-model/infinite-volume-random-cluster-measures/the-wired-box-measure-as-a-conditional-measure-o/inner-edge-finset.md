# Edges of the next box coming from the inner box

For $d, n \in \mathbb{N}$, the inner pair set is the set of unordered pairs of vertices of $\Lambda_{n+1}$ with both elements in $\Lambda_n$ (the images of all pairs of vertices of $\Lambda_n$, loops included), where $\Lambda_m = \{-m, \dots, m\}^d$.
