# Boundary connection of $\Lambda_n$ is a $\Lambda_m$ cylinder event

For $d, n, m \in \mathbb{N}$ with $n \le m$, the [box-boundary connection event](../box-boundary-connection-probabilities-for-the-wi/box-bdry-conn-event.md) $\{0 \leftrightarrow \partial\Lambda_n\}$ equals the set of configurations of $\mathbb{Z}^d$ whose restriction to $\Lambda_m$ lies in the [event on $\Lambda_m$](conn-to-bdry-event-le.md) that the further restriction to $\Lambda_n$ joins the origin to $\partial\Lambda_n$ by open edges of $\Lambda_n$.
