# Events $0 \leftrightarrow \partial\Lambda_n$ decrease in $n \ge 1$

For $d, k, n \in \mathbb{N}$ with $1 \le k \le n$, $\{0 \leftrightarrow \partial\Lambda_n\} \subseteq \{0 \leftrightarrow \partial\Lambda_k\}$, where $\{0 \leftrightarrow \partial\Lambda_n\}$ is the [box-boundary connection event](../box-boundary-connection-probabilities-for-the-wi/box-bdry-conn-event.md) (the origin joined to $\partial\Lambda_n = \Lambda_n \setminus \Lambda_{n-1}$ by open edges of $\Lambda_n$).
