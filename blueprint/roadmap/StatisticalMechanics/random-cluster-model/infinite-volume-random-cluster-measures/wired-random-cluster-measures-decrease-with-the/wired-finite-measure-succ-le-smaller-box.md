# Wired box measures decrease on increasing cylinder events at $q = 2$

Let $d, n \in \mathbb{N}$, $0 < p < 1$, and $S$ an increasing set of configurations of $\Lambda_n = \{-n, \dots, n\}^d$ whose cylinder event $C_S$ (configurations of $\mathbb{Z}^d$ with restriction to $\Lambda_n$ in $S$) is measurable. Then

$$\phi^1_{n+1}(C_S) \le \sum_{\omega \in S} \phi^w_{\Lambda_n,p,2}(\omega),$$

where $\phi^1_{m}$ is the [wired box measure](../finite-and-infinite-volume-fk-measures-on-d/wired-finite-measure.md) on $\Lambda_m = \{-m, \dots, m\}^d$ at parameters $(p, 2)$ and $\phi^w_{\Lambda_n,p,2}$ is the [wired random-cluster probability](../finite-and-infinite-volume-fk-measures-on-d/wired-fk-prob.md) of $\Lambda_n$ with boundary $\partial\Lambda_n$.
