# Inner vertices next to the annulus lie on $\partial\Lambda_n$

Let $d, n \in \mathbb{N}$ with $n \ge 1$, $\omega$ a configuration of $\mathbb{Z}^d$, $x \in \Lambda_n$ and $z \in \Lambda_{n+1} \setminus \Lambda_n$, where $\Lambda_m = \{-m, \dots, m\}^d$. If $\{x, z\}$ is an edge of $\Lambda_{n+1}$ open in $\omega$, then $x \in \partial\Lambda_n = \Lambda_n \setminus \Lambda_{n-1}$.
