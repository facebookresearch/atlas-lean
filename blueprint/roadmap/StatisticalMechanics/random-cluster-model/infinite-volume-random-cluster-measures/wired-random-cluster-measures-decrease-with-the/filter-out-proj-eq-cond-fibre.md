# Configurations with a given outer part form its conditioning fibre

Let $d, n \in \mathbb{N}$ and $\Lambda_m = \{-m, \dots, m\}^d$. Let $F$ be the set of unordered pairs of vertices of $\Lambda_{n+1}$ with both elements in $\Lambda_n$. If $\psi$ is a configuration of $\Lambda_{n+1}$ with $\Pi(\psi) = \psi$, where $\Pi$ is the [outer projection](out-proj.md) (which closes every pair of $F$ and keeps the other pairs), then $\{\rho : \Pi(\rho) = \psi\}$ is the set of configurations agreeing with $\psi$ off $F$.
