# Restriction of a configuration from $\Lambda_m$ to $\Lambda_n$

For $d, n, m \in \mathbb{N}$ with $n \le m$ and a configuration $\eta$ of $\Lambda_m$, the restriction $\eta|_n$ is the configuration of $\Lambda_n$ giving each pair of vertices of $\Lambda_n$ its state in $\eta$, where $\Lambda_m = \{-m, \dots, m\}^d$.
