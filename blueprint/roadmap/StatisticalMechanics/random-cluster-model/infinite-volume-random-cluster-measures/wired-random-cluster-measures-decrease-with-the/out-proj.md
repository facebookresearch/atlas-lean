# Outer part of a configuration on $\Lambda_{n+1}$

For $d, n \in \mathbb{N}$ and a configuration $\rho$ of $\Lambda_{n+1}$, where $\Lambda_m = \{-m, \dots, m\}^d$, the outer projection $\Pi(\rho)$ is the [glued configuration](../boundary-conditions-induced-on-a-box-by-the-oute/psi-ext.md) of $\rho$ with the all-closed configuration of $\Lambda_n$: it closes every pair with both elements in $\Lambda_n$ and keeps the state of every other pair.
