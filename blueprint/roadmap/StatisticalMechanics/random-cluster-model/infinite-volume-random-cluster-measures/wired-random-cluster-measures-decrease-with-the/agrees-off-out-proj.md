# Outer projection agrees with the configuration off $\Lambda_n$

Let $d, n \in \mathbb{N}$ and $\Lambda_m = \{-m, \dots, m\}^d$. Let $F$ be the set of unordered pairs of vertices of $\Lambda_{n+1}$ with both elements in $\Lambda_n$. For every configuration $\rho$ of $\Lambda_{n+1}$, the [outer projection](out-proj.md) $\Pi(\rho)$ agrees with $\rho$ on every pair outside $F$.
