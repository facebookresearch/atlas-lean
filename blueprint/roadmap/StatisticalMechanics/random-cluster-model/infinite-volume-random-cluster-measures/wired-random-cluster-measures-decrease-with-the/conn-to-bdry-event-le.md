# Boundary-connection event of $\Lambda_n$ as an event on $\Lambda_m$

For $d, n, m \in \mathbb{N}$ with $n \le m$, the event is the set of configurations $\eta$ of $\Lambda_m$ whose [restriction](box-restrict-le.md) to $\Lambda_n$ joins the origin to some vertex of $\partial\Lambda_n = \Lambda_n \setminus \Lambda_{n-1}$ by a path of open edges of $\Lambda_n$, where $\Lambda_m = \{-m, \dots, m\}^d$.
