# Configurations agreeing off $F$ have equal conditional probabilities

Let $G$ and $C$ be simple graphs on a finite set $V$, $p, q \in \mathbb{R}$, $F$ a finite set of unordered pairs of elements of $V$, and $\psi, \psi', \omega$ configurations on $V$. If $\psi$ and $\psi'$ agree off $F$, then $\phi^C(\omega \mid F, \psi) = \phi^C(\omega \mid F, \psi')$, where $\phi^C(\cdot \mid F, \psi)$ is the [conditional random-cluster measure with boundary wiring $C$](../../fkg-inequality-and-monotonicity-of-random-cluste/cond-bc-prob.md) on $G$.
