# Leaving $\Lambda_n$ implies connecting to $\partial\Lambda_n$

For $d, n \in \mathbb{N}$ with $n \ge 1$, $\mathrm{Cross}_{n+1} \subseteq \{0 \leftrightarrow \partial\Lambda_n\}$, where $\mathrm{Cross}_{n+1}$ is the event that the origin is joined by an open path to some site outside $\Lambda_n$, and $\{0 \leftrightarrow \partial\Lambda_n\}$ is the [box-boundary connection event](../box-boundary-connection-probabilities-for-the-wi/box-bdry-conn-event.md) (the origin joined to $\partial\Lambda_n = \Lambda_n \setminus \Lambda_{n-1}$ by open edges of $\Lambda_n$).
