# Origin-to-boundary connection is an increasing event

For $d, n \in \mathbb{N}$, the set of configurations of $\Lambda_n = \{-n, \dots, n\}^d$ in which the origin is joined to some vertex of $\partial\Lambda_n = \Lambda_n \setminus \Lambda_{n-1}$ by a path of open edges of $\Lambda_n$ is increasing.
