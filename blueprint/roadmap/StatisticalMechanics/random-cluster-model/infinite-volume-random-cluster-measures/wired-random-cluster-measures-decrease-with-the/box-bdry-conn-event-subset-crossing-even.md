# Boundary connection inside $\Lambda_n$ reaches outside $\Lambda_{n-1}$

For $d, n \in \mathbb{N}$, $\{0 \leftrightarrow \partial\Lambda_n\} \subseteq \mathrm{Cross}_n$, where $\{0 \leftrightarrow \partial\Lambda_n\}$ is the [box-boundary connection event](../box-boundary-connection-probabilities-for-the-wi/box-bdry-conn-event.md) (the origin joined to $\partial\Lambda_n = \Lambda_n \setminus \Lambda_{n-1}$ by open edges of $\Lambda_n$) and $\mathrm{Cross}_n$ is the event that the origin is joined by an open path to some site outside $\Lambda_{n-1}$ ($n - 1$ truncated at $0$).
