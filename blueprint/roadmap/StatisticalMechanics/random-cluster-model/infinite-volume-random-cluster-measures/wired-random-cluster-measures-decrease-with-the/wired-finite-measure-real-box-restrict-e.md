# Wired $\Lambda_m$ measure of a $\Lambda_m$ cylinder event as a sum

Let $d, m \in \mathbb{N}$, $0 < p < 1$, and $S$ a set of configurations of $\Lambda_m = \{-m, \dots, m\}^d$ whose cylinder event $C_S$ (configurations of $\mathbb{Z}^d$ with restriction to $\Lambda_m$ in $S$) is measurable. Then

$$\phi^1_m(C_S) = \sum_{\omega \in S} \phi^w_{\Lambda_m,p,2}(\omega),$$

where $\phi^1_{m}$ is the [wired box measure](../finite-and-infinite-volume-fk-measures-on-d/wired-finite-measure.md) on $\Lambda_m = \{-m, \dots, m\}^d$ at parameters $(p, 2)$ and $\phi^w_{\Lambda_m,p,2}$ is the [wired random-cluster probability](../finite-and-infinite-volume-fk-measures-on-d/wired-fk-prob.md) of $\Lambda_m$ with boundary $\partial\Lambda_m$.
