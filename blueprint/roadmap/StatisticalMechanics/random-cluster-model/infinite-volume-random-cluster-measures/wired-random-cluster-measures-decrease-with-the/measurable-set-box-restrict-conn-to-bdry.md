# Cylinder form of the $\Lambda_n$ boundary connection is measurable

For $d, n, m \in \mathbb{N}$ with $n \le m$, the set of configurations of $\mathbb{Z}^d$ whose restriction to $\Lambda_m$ lies in the [event on $\Lambda_m$](conn-to-bdry-event-le.md) that the origin is joined to $\partial\Lambda_n$ inside $\Lambda_n$ is measurable.
