# Crossing events intersect to the percolation event

For every $d \in \mathbb{N}$, the intersection over $n \in \mathbb{N}$ of the crossing events $\mathrm{Cross}_n$ (the origin is joined by an open path to some site outside $\Lambda_{n-1}$, with $n - 1$ truncated at $0$) equals the event that the open cluster of the origin is infinite.
