# An outer cluster avoids the inner box iff its representative does

Let $d, n \in \mathbb{N}$, $\Lambda_m = \{-m, \dots, m\}^d$ (so $\Lambda_n \subseteq \Lambda_{n+1}$), and let $\psi$ be a configuration of $\Lambda_{n+1}$ (an assignment of open/closed states to the unordered pairs of vertices of $\Lambda_{n+1}$). For every $v \in \Lambda_{n+1}$, the component of $v$ in the outer open graph $O^0_\psi$ [avoids the inner box](is-outside-only-free.md) if and only if $v$ is [avoiding](outside-only-free.md).
