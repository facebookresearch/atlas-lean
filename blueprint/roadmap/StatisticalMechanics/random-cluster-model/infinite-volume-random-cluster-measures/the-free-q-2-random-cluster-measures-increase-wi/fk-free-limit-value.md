# Limit of free $q = 2$ box measures of a cylinder event

Let $d, N \in \mathbb{N}$, $0 < p < 1$, and $S$ a set of configurations of $\Lambda_N$. For a set $S$ of configurations of $\Lambda_N = \{-N, \dots, N\}^d$, $C_S$ denotes the cylinder event of the configurations of $\mathbb{Z}^d$ whose restriction to the pairs of vertices of $\Lambda_N$ lies in $S$. The limit value of $S$ is

$$L(S) = \sup_{k \in \mathbb{N}} \phi^0_{N+k}(C_S),$$

where $\phi^0_{m}$ is the [free box measure](../finite-and-infinite-volume-fk-measures-on-d/free-finite-measure.md) on $\Lambda_m = \{-m, \dots, m\}^d$ at parameters $(p, 2)$ (the supremum exists since these values lie in $[0, 1]$).
