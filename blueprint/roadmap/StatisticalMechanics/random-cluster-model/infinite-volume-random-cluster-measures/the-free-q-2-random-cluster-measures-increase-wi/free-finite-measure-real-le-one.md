# Free box measures are at most one

For $d, m \in \mathbb{N}$, $0 < p < 1$ and every set $A$ of configurations of $\mathbb{Z}^d$, the real value of the [free box measure](../finite-and-infinite-volume-fk-measures-on-d/free-finite-measure.md) $\phi^0_m$ of $\Lambda_m = \{-m, \dots, m\}^d$ at $(p, 2)$ satisfies $\phi^0_m(A) \le 1$ (for a non-measurable $A$ the outer measure is meant).
