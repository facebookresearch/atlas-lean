# Conditional free measure as an induced-wiring measure

Let $d, n \in \mathbb{N}$, $0 < p < 1$ and $q > 0$, let $\Lambda_m = \{-m, \dots, m\}^d$, $F$ the set of unordered pairs of vertices of $\Lambda_{n+1}$ with both elements in $\Lambda_n$, $\psi$ a configuration of $\Lambda_{n+1}$, and $B$ a set of configurations of $\Lambda_{n+1}$. Then

$$\sum_{\rho \in B,\ \rho = \psi \text{ off } F} \phi(\rho \mid F, \psi) = \sum_{\omega :\ \psi \oplus \omega \in B} \phi^{W^0_\psi}_{\Lambda_n,p,q}(\omega),$$

with the [conditional free random-cluster probability](../../random-cluster-measures-on-finite-graphs/cond-fk-prob.md), the [glued configuration](../boundary-conditions-induced-on-a-box-by-the-oute/psi-ext.md) $\psi \oplus \omega$, the free induced wiring $W^0_\psi$ (distinct $x, y \in \Lambda_n$ joined by a path of edges of $\Lambda_{n+1}$ open in $\psi$ without both endpoints in $\Lambda_n$), and the [random-cluster probability with boundary wiring](../../fkg-inequality-and-monotonicity-of-random-cluste/bc-prob.md) $\phi^{W^0_\psi}_{\Lambda_n,p,q}$.
