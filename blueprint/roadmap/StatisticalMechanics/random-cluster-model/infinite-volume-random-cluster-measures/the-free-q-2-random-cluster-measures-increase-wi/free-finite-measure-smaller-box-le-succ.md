# Increasing box events gain free $q = 2$ probability in the next box

Let $d, n \in \mathbb{N}$, $0 < p < 1$, and $S$ an increasing set of configurations of $\Lambda_n = \{-n, \dots, n\}^d$ whose cylinder event $C_S$ is measurable. For a set $S$ of configurations of $\Lambda_n$, $C_S$ denotes the cylinder event of the configurations of $\mathbb{Z}^d$ whose restriction to the pairs of vertices of $\Lambda_n$ lies in $S$. Then

$$\sum_{\omega \in S} \phi_{\Lambda_n,p,2}(\omega) \le \phi^0_{n+1}(C_S),$$

where $\phi_{G,p,q}$ is the [random-cluster probability](../../random-cluster-measures-on-finite-graphs/fk-prob.md) on $G$ and $\phi^0_{m}$ is the [free box measure](../finite-and-infinite-volume-fk-measures-on-d/free-finite-measure.md) on $\Lambda_m = \{-m, \dots, m\}^d$ at parameters $(p, 2)$.
