# Event that the open cluster of a site is infinite

For $d \in \mathbb{N}$ and $x \in \mathbb{Z}^d$, the event $\{|C(x)| = \infty\}$ is the set of configurations of $\mathbb{Z}^d$ (assignments of open/closed states to all unordered pairs of sites) in which the open cluster of $x$ (the set of sites joined to $x$ by paths of open nearest-neighbour edges) is infinite.
