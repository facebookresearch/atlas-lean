# Restriction of a configuration of $\mathbb{Z}^d$ to a box

For $d, n \in \mathbb{N}$ and a configuration $\omega$ of $\mathbb{Z}^d$, the restriction to $\Lambda_n = \{-n, \dots, n\}^d$ is the configuration of $\Lambda_n$ that gives each unordered pair of vertices of $\Lambda_n$ its state in $\omega$.
