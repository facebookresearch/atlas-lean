# Event that the box origin connects to the box boundary

For $d, n \in \mathbb{N}$, the box-boundary connection event is the set of configurations of $\mathbb{Z}^d$ (assignments of open/closed states to all unordered pairs of sites) in which the origin is joined to some site of the vertex boundary $\partial\Lambda_n$ of $\Lambda_n = \{-n, \dots, n\}^d$ (the sites of $\Lambda_n$ not in $\Lambda_{n-1}$, with $n - 1$ truncated at $0$) by a path of open nearest-neighbour edges inside $\Lambda_n$.
