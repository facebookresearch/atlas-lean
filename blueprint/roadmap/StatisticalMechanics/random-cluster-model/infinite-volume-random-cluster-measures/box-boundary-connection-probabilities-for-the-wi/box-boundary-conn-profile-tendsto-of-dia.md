# Box-boundary profile tends to $\theta(p,2)$ if wired probabilities do

Let $d \in \mathbb{N}$ and $0 < p < 1$. If

$$\phi^1_{\Lambda_n,p,2}(0 \leftrightarrow \partial\Lambda_n) \to \theta^1(p, 2) \qquad (n \to \infty),$$

where $\phi^1_{\Lambda_n,p,2}$ is the [wired box measure](../finite-and-infinite-volume-fk-measures-on-d/wired-finite-measure.md) and $\{0 \leftrightarrow \partial\Lambda_n\}$ the [box-boundary connection event](box-bdry-conn-event.md), then the [box-boundary connection profile](../../edwards-sokal-coupling-and-the-fk-representation/magnetization-equals-fk-percolation-probability/box-boundary-conn-profile.md) $\phi^w_{\Lambda_n,\partial\Lambda_n,p}(0 \leftrightarrow \partial\Lambda_n)$ also tends to $\theta^1(p, 2)$, the [wired percolation probability](../../critical-point-of-the-random-cluster-model/the-critical-point-of-the-random-cluster-model/fk-theta.md) on $\mathbb{Z}^d$.
