# Event that a box edge is open

For $d, N \in \mathbb{N}$ and an unordered pair $e$ of vertices of $\Lambda_N = \{-N, \dots, N\}^d$, the event that $e$ is open is the set of configurations of $\Lambda_N$ (assignments of open/closed states to the unordered pairs of vertices of $\Lambda_N$) in which $e$ is open.
