# Edge-open indicator as a bounded continuous function

For $d \in \mathbb{N}$ and an unordered pair $e$ of sites, the edge indicator $\omega \mapsto \mathbf{1}[e \text{ open in } \omega]$ is a bounded continuous real function on configurations of $\mathbb{Z}^d$ (assignments of open/closed states to all unordered pairs of sites).
