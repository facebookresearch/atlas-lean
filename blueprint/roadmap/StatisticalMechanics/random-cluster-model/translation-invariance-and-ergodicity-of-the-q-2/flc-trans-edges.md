# Box edge set included into $\Lambda_m$ and translated by $v$

For $d, N, m \in \mathbb{N}$ with $N \le m$, $v \in \mathbb{Z}^d$, and a finite set $t$ of unordered pairs of vertices of $\Lambda_N$, the translated set is $t^{(m)} + v$: the pairs of $t$ viewed in $\Lambda_m$ and then translated by $v$, as pairs of vertices of the translated box $\Lambda_m + v$ (where $\Lambda_k = \{-k, \dots, k\}^d$).
