# Realized edge sets stay realized in larger boxes

Let $d, N_0, N \in \mathbb{N}$ with $N_0 \le N$, $s$ a finite set of unordered pairs of sites, and $t$ a set of pairs of vertices of $\Lambda_{N_0}$ with $s = t$ as sets of pairs of sites. Then $s$ also equals the set $t$ viewed in $\Lambda_N$, where $\Lambda_k = \{-k, \dots, k\}^d$.
