# Extreme point of the invariant probability measures

Let a group $G$ act on a set $E$, and let $G$ act on configurations $\omega \in \{0, 1\}^E$ by $(\tau_g\omega)(e) = \omega(g^{-1}e)$. A measure $\mu$ on $\{0, 1\}^E$ is an extreme invariant point when it is a translation-invariant probability measure and, whenever $\mu = a\nu_1 + b\nu_2$ with $\nu_1, \nu_2$ translation-invariant probability measures and $a, b \in (0, \infty]$ with $a + b = 1$, one has $\nu_1 = \nu_2$.
