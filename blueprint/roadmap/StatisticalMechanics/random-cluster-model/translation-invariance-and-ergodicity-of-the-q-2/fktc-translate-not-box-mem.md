# Unit translations are not box symmetries

For $d \in \mathbb{N}$ and a coordinate $j$ (so $d \ge 1$), the translation $x \mapsto x + e_j$ does not preserve every box: it is not true that $x + e_j \in \Lambda_n \iff x \in \Lambda_n$ for all $n \in \mathbb{N}$ and $x \in \mathbb{Z}^d$, where $\Lambda_n = \{-n, \dots, n\}^d$.
