# Event that every edge of a finite set is open

For $d \in \mathbb{N}$ and a finite set $s$ of unordered pairs of sites, $O_s$ is the set of configurations of $\mathbb{Z}^d$ (assignments of open/closed states to all unordered pairs of sites) in which every pair of $s$ is open ($O_\emptyset$ is the whole space).
