# Monomial indicator as a bounded continuous function

For $d \in \mathbb{N}$ and a finite set $s$ of unordered pairs of sites, the monomial indicator $\omega \mapsto \prod_{e \in s} \mathbf{1}[e \text{ open in } \omega]$ is a bounded continuous real function on configurations of $\mathbb{Z}^d$ (assignments of open/closed states to all unordered pairs of sites) (product topology).
