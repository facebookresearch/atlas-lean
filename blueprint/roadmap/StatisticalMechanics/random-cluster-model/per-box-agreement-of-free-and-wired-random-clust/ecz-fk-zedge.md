# Edge partition function of the random-cluster model

For a simple graph $G$ on a finite set $V$ and $p, q \in \mathbb{R}$, the edge partition function is

$$Z^{e}_G(p, q) = \sum_{\omega} p^{o(\omega)}(1 - p)^{c(\omega)} q^{k(\omega)},$$

the sum of the [random-cluster weights](../random-cluster-measures-on-finite-graphs/fk-weight.md) over the [configurations closed off $G$](ecz-closed-off.md) (every pair that is not an edge of $G$ is closed), with $o, c$ the numbers of open and closed edges and $k$ the number of open clusters.
