# Per-coordinate free energy on a box

For $d, N \in \mathbb{N}$ and $G : \mathbb{R} \to \mathbb{R}$, the per-coordinate function assigns to an unordered pair $e'$ of vertices of $\Lambda_N = \{-N, \dots, N\}^d$ the function $G$ when $e'$ is an edge of $\Lambda_N$, and the function $s \mapsto s/2$ otherwise (loops and non-adjacent pairs).
