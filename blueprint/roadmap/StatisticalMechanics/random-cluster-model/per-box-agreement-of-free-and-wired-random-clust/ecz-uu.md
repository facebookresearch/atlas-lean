# Negative log edge partition function of a graph

For a simple graph $G$ on a finite set and $p, q \in \mathbb{R}$, the value is $-\log Z^{e}_G(p, q)$, where $Z^{e}_G(p, q)$ is the [edge partition function](ecz-fk-zedge.md) (the sum of the random-cluster weights over the configurations closed on every pair that is not an edge of $G$) and $\log$ is the real logarithm ($\log x = \log|x|$, $\log 0 = 0$).
