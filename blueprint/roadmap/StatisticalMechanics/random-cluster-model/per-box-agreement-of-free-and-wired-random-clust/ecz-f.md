# Per-edge negative log edge partition function of a box

For $d, n \in \mathbb{N}$ and $s \in \mathbb{R}$, the value is $f(n) = u(n)/E(n)$ (read as $0$ when $E(n) = 0$), where $u(n) = -\log Z^{e}_{\Lambda_n}(\sigma(s), 2)$ is the [negative log edge partition function](ecz-u.md) of the box $\Lambda_n = \{-n, \dots, n\}^d$ with its nearest-neighbour graph and $E(n)$ is the number of edges of the nearest-neighbour graph on $\Lambda_n = \{-n, \dots, n\}^d$.
