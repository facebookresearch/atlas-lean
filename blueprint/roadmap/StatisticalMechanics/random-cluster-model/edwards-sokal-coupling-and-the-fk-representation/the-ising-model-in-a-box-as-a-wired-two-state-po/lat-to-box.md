# Box configuration as a coloring of the next larger box

Let $d, n \in \mathbb{N}$ and let $\tau : \Lambda_n \to \{\text{true}, \text{false}\}$ be a configuration on the box $\Lambda_n = \{-n, \dots, n\}^d \subseteq \mathbb{Z}^d$. The associated two-state coloring of $\Lambda_{n+1}$ gives a vertex $v \in \Lambda_n$ the color $0$ if $\tau(v)$ is true and $1$ if it is false, and gives every $v \in \Lambda_{n+1} \setminus \Lambda_n$ the color $0$.
