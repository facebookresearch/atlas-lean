# Plus-boundary Ising partition function on a graph

Let $G = (V, E)$ be a finite simple graph and $\partial \subseteq V$ a set of boundary vertices and $\beta \in \mathbb{R}$. The plus-boundary partition function is $Z^+_\beta = \sum_\sigma w^+_\beta(\sigma)$, the sum over all two-state colorings $\sigma : V \to \{0, 1\}$ of the [plus-boundary Ising weight](ising-wired-weight.md).
