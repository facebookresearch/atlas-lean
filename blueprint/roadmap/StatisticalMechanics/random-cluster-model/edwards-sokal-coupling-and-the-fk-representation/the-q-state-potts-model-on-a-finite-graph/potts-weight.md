# Potts Boltzmann weight

Let $G = (V, E)$ be a finite simple graph, $q \in \mathbb{N}$ and $\beta, J \in \mathbb{R}$. The Potts weight of a coloring $\sigma : V \to \{0, \dots, q - 1\}$ is $e^{\beta J a(\sigma)}$, where $a(\sigma)$ is the [agreement count](agreement.md), the number of edges of $G$ whose endpoints have the same color.
