# Potts partition function

Let $G = (V, E)$ be a finite simple graph, $q \in \mathbb{N}$ and $\beta, J \in \mathbb{R}$. The Potts partition function is

$$Z_{G,q}(\beta, J) = \sum_\sigma e^{\beta J a(\sigma)},$$

the sum over all colorings $\sigma : V \to \{0, \dots, q - 1\}$, with $a(\sigma)$ the [agreement count](agreement.md).
