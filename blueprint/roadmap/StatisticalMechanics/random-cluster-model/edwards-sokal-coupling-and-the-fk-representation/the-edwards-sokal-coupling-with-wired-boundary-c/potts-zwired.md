# Potts partition function with fixed boundary color

Let $G = (V, E)$ be a finite simple graph and $\partial \subseteq V$ a set of boundary vertices, $q \in \mathbb{N}$, $b \in \{0, \dots, q - 1\}$ and $\beta, J \in \mathbb{R}$. The Potts partition function with boundary color $b$ is $Z^b = \sum_\sigma w^b(\sigma)$, the sum over all colorings $\sigma : V \to \{0, \dots, q - 1\}$ of the [Potts weight with boundary color $b$](potts-weight-wired.md).
