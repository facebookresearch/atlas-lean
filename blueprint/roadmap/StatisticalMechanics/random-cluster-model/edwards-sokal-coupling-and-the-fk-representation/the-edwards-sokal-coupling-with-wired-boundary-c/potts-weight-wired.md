# Potts weight with fixed boundary color

Let $G = (V, E)$ be a finite simple graph and $\partial \subseteq V$ a set of boundary vertices, $q \in \mathbb{N}$, $b \in \{0, \dots, q - 1\}$ and $\beta, J \in \mathbb{R}$. The Potts weight with boundary color $b$ of a coloring $\sigma : V \to \{0, \dots, q - 1\}$ is $e^{\beta J a(\sigma)}$ if $\sigma_x = b$ for every $x \in \partial$, and $0$ otherwise, where $a(\sigma)$ is the number of edges of $G$ whose endpoints have the same color.
