# Edwards–Sokal factor of an arbitrary coordinate and state

Let $G = (V, E)$ be a finite simple graph, $q \in \mathbb{N}$, $p \in \mathbb{R}$ and $\sigma : V \to \{0, \dots, q - 1\}$. For an unordered pair $e$ of vertices and a state $s \in \{\text{open}, \text{closed}\}$, the coefficient is: $p\,\mathbf{1}[\sigma_x = \sigma_y]$ if $e = \{x, y\} \in E$ and $s$ is open; $1 - p$ if $e \in E$ and $s$ is closed; and $1$ if $e \notin E$.
