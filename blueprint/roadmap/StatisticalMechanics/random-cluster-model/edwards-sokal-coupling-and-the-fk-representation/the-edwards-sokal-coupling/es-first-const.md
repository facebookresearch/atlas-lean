# Normalizing constant relating the bond sum to the Potts weight

Let $G = (V, E)$ be a finite simple graph and $\beta, J \in \mathbb{R}$. The normalizing constant is

$$c_G(\beta, J) = 2^{N - |E|}\, \big(e^{-\beta J}\big)^{|E|},$$

where $N = |V|(|V| + 1)/2$ is the number of unordered pairs of vertices, loops included, so $N - |E| \ge 0$ counts the pairs that are not edges. For example, a graph with one vertex and no edges gives $c_G = 2$.
