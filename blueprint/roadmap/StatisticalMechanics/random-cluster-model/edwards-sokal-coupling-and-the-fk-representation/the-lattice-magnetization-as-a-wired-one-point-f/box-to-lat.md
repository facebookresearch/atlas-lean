# Restriction of a box coloring to the inner box

Let $d, n \in \mathbb{N}$ and let $\sigma : \Lambda_{n+1} \to \{0, 1\}$ be a two-state coloring of the box $\Lambda_{n+1}$, where $\Lambda_m = \{-m, \dots, m\}^d$. The associated configuration on $\Lambda_n$ is $x \mapsto$ true if $\sigma_x = 0$ and $x \mapsto$ false if $\sigma_x = 1$, for $x \in \Lambda_n$.
