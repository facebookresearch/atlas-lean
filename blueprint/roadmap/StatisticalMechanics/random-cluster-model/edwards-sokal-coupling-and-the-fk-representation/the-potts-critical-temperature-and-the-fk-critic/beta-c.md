# Critical inverse temperature of a magnetization curve

For a function $m^* : \mathbb{R} \to \mathbb{R}$, the critical inverse temperature is

$$\beta_c(m^*) = \sup\{\beta \in \mathbb{R} : \beta > 0 \text{ and } m^*(\beta) = 0\},$$

the supremum in $\mathbb{R}$, where the supremum of a set that is empty or not bounded above is taken to be $0$. In particular, if $m^*$ is identically zero the set is $(0, \infty)$ and $\beta_c(m^*) = 0$, and if $m^*(\beta) \ne 0$ for every $\beta > 0$ then $\beta_c(m^*) = 0$ as well.
