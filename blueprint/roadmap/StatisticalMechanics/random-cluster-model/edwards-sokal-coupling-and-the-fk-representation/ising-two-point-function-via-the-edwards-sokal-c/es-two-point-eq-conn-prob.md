# Ising two-point function equals the $q = 2$ connection probability

Let $G = (V, E)$ be a finite simple graph, $p \in \mathbb{R}$ and $x, y \in V$. Then the [Edwards–Sokal two-point function](es-two-point.md) equals the [random-cluster connection probability](conn-prob.md) at $q = 2$:

$$\langle s(\sigma_x)\, s(\sigma_y) \rangle^{ES}_p = \phi_{G,p,2}(x \leftrightarrow y)$$

(Edwards–Sokal 1988; Grimmett, *The Random-Cluster Model*, 2006, Theorem 1.16).
