# Functions equal at two points as functions omitting one point

Let $C$ be a finite set, $q \in \mathbb{N}$, and $a, b \in C$ with $a \ne b$. Restriction to $C \setminus \{b\}$ is a bijection from the functions $f : C \to \{0, \dots, q - 1\}$ with $f(a) = f(b)$ onto all functions $C \setminus \{b\} \to \{0, \dots, q - 1\}$; its inverse extends $g$ by $f(b) = g(a)$.
