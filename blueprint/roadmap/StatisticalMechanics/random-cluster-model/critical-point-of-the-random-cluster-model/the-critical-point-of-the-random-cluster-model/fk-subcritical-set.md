# Non-percolating parameters of the wired random-cluster measure

For $d \in \mathbb{N}$ and $q \in \mathbb{R}$, the subcritical set is the set of $p \in (0, 1)$ such that $q > 0$ and $\theta^1(p, q) = 0$, where $\theta^1$ is the [wired percolation probability](fk-theta.md) on $\mathbb{Z}^d$. It is empty when $q \le 0$.
