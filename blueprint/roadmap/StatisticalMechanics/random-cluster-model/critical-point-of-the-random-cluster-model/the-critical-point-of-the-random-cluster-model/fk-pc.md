# Critical parameter $p_c(q)$ of the random-cluster model

For $d \in \mathbb{N}$ and $q \in \mathbb{R}$, the critical parameter of the random-cluster model on $\mathbb{Z}^d$ is the supremum of the [subcritical set](fk-subcritical-set.md),

$$p_c(q) = \sup\{p \in (0, 1) : q > 0 \text{ and } \theta^1(p, q) = 0\},$$

where $\theta^1$ is the [wired percolation probability](fk-theta.md) and the supremum of the empty set is taken to be $0$ (so $p_c(q) = 0$ for $q \le 0$).
