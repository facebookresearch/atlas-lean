# The percolation event is increasing

For every $d \in \mathbb{N}$, the event that the open cluster of the origin of $\mathbb{Z}^d$ is infinite is increasing: if it holds for a configuration $\omega$ and $\omega \le \omega'$ coordinatewise, it holds for $\omega'$. Configurations assign open/closed states to all unordered pairs of sites, and the open cluster of the origin is the set of sites joined to the origin by paths of open nearest-neighbour edges.
