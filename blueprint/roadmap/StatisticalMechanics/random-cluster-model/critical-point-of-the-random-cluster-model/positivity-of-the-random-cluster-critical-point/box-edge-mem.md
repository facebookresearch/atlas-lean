# Box edge with a lattice-edge image is a box-graph edge

Let $d, n \in \mathbb{N}$, let $b$ be an unordered pair of vertices of the box $\Lambda_n = \{-n, \dots, n\}^d \subseteq \mathbb{Z}^d$, and let $x, y \in \mathbb{Z}^d$ be nearest neighbours. If $b$, viewed as a pair of sites of $\mathbb{Z}^d$, equals $\{x, y\}$, then $b$ is an edge of the nearest-neighbour graph on $\Lambda_n$.
