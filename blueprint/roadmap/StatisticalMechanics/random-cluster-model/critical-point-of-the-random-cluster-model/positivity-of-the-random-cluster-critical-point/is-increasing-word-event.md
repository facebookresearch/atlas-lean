# Event that a given walk is open is increasing

Let $d, m \in \mathbb{N}$. A word $g = (g_k)_{k \in \mathbb{N}}$ of steps $g_k = (i_k, s_k)$, with $i_k \in \{1, \dots, d\}$ a coordinate direction and $s_k \in \{+1, -1\}$ a sign, encodes the lattice path $x_0 = 0$, $x_{k+1} = x_k + s_k e_{i_k}$ in $\mathbb{Z}^d$; its $k$-th edge is $\{x_k, x_{k+1}\}$. For every word $g$, the event that the first $m$ edges $\{x_k, x_{k+1}\}$, $0 \le k < m$, of its path are all open is increasing: if $\omega$ lies in it and $\omega \le \omega'$ coordinatewise, then $\omega'$ lies in it.
