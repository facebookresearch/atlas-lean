# Open edges of an extended box configuration are box edges

Let $d, n \in \mathbb{N}$, let $\omega$ be a configuration of the box $\Lambda_n = \{-n, \dots, n\}^d \subseteq \mathbb{Z}^d$, and let $e$ be an unordered pair of sites of $\mathbb{Z}^d$. If $e$ is open in the [extension](../../infinite-volume-random-cluster-measures/finite-and-infinite-volume-fk-measures-on-d/extend-edge.md) $\bar\omega$ of $\omega$ to $\mathbb{Z}^d$, then both endpoints of $e$ lie in $\Lambda_n$.
