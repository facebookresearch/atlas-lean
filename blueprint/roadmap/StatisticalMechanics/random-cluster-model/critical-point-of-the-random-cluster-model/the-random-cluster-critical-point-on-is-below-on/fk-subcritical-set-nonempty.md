# Nonempty subcritical set on $\mathbb{Z}^2$ for $q \ge 1$

For $q \ge 1$, the [subcritical set](../the-critical-point-of-the-random-cluster-model/fk-subcritical-set.md) $\{p \in (0, 1) : \theta^1(p, q) = 0\}$ of $\mathbb{Z}^2$ is nonempty, where $\theta^1$ is the [wired percolation probability](../the-critical-point-of-the-random-cluster-model/fk-theta.md).
