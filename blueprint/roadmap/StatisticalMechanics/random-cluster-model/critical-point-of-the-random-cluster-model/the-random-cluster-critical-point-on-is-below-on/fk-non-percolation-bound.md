# Peierls bound hypothesis for the wired measure on $\mathbb{Z}^2$

For $0 < p < 1$ and $q > 0$, the Peierls bound at $(p, q)$ holds when

$$1 - \theta^1(p, q) \le \sum_{\ell \ge 0} \ell\, 4^\ell (1 - p)^\ell,$$

where $\theta^1$ is the [wired percolation probability](../the-critical-point-of-the-random-cluster-model/fk-theta.md) on $\mathbb{Z}^2$ and the right-hand side is the [Peierls series](fk-pc-upper-bound.md) for $d = 2$, read as $0$ when it diverges (that is, for $p \le 3/4$).
