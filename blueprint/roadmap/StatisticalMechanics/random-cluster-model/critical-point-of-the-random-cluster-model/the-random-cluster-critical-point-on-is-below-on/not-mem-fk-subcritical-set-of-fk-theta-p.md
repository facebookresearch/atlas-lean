# Positive percolation probability rules out subcriticality

Let $0 < p < 1$ and $q > 0$. If $\theta^1(p, q) > 0$, then $p$ is not in the [subcritical set](../the-critical-point-of-the-random-cluster-model/fk-subcritical-set.md) $\{p \in (0, 1) : \theta^1(p, q) = 0\}$ of $\mathbb{Z}^2$, where $\theta^1$ is the [wired percolation probability](../the-critical-point-of-the-random-cluster-model/fk-theta.md) on $\mathbb{Z}^2$.
