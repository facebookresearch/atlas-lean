# Finite-cluster event is covered by closed-circuit events

For every $o \in \mathbb{Z}^2$, every configuration of $\mathbb{Z}^2$ in which the open cluster of $o$ is finite lies in the [closed-circuit event](closed-circuit-event.md) of some cycle (based at some site) of the nearest-neighbour graph of $\mathbb{Z}^2$.
