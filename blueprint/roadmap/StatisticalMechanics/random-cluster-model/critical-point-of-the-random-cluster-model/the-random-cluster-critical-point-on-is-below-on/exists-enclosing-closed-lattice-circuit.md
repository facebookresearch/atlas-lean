# Finite cluster in $\mathbb{Z}^2$: closed circuit, separated point, odd crossings

Let $\omega$ be a configuration of $\mathbb{Z}^2$ and $o \in \mathbb{Z}^2$ a site whose open cluster $C$ is finite. Then there is a site $z \in \mathbb{Z}^2$ such that:

- there is a cycle $c$ in the nearest-neighbour graph of $\mathbb{Z}^2$ with $\omega$ in its [closed-circuit event](closed-circuit-event.md);
- $z$ cannot be reached from $o$ in the nearest-neighbour graph of $\mathbb{Z}^2$ with all edges having exactly one endpoint in $C$ removed;
- every walk from $o$ to $z$ in the nearest-neighbour graph of $\mathbb{Z}^2$ uses an odd number of edges (counted with multiplicity) having exactly one endpoint in $C$.
