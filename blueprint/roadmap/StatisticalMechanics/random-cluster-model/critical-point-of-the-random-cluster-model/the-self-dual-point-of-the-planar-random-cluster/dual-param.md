# Planar dual parameter $p^{\ast}$

For $p, q \in \mathbb{R}$, the planar dual parameter is

$$p^\ast = \frac{(1 - p)\, q}{(1 - p)\, q + p},$$

a rational function of $(p, q)$ defined everywhere by reading the quotient as $0$ when the denominator $(1 - p)q + p$ vanishes. On the physical domain $0 < p < 1$, $q > 0$ one has $0 < p^\ast < 1$, and $p^\ast$ is the unique solution of

$$\frac{p^\ast}{1 - p^\ast} \cdot \frac{p}{1 - p} = q.$$

Outside that domain this odds identity can fail: for instance $p = 0$, $q = 1$ gives $p^\ast = 1$.
