# Fibre of configurations agreeing off an edge set

Let $V$ be a finite set, $F$ a finite set of unordered pairs of elements of $V$, and $\psi$ a configuration on $V$. The fibre $\mathcal{F}_\psi$ is the finite set of configurations $\omega$ that [agree with $\psi$ off $F$](agrees-off.md), that is, $\omega(e) = \psi(e)$ for every pair $e \notin F$.
