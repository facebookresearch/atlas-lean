# Agreement of configurations off an edge set

Let $V$ be a finite set, $F$ a finite set of unordered pairs of elements of $V$, and $\psi, \omega$ configurations (assignments $\omega$ of open/closed states to all unordered pairs of elements of $V$, loops and non-edges included). The configuration $\omega$ agrees with $\psi$ off $F$ when $\omega(e) = \psi(e)$ for every pair $e \notin F$.
