# Open subgraph as the meet of $G$ with the open-edge graph

Let $G = (V, E)$ be a simple graph on a finite set $V$. For every configuration $\omega$, the [open subgraph](open-sub.md) equals the intersection of $G$ with the graph on $V$ whose edges are the open pairs $\{x, y\}$, $x \ne y$, of $\omega$.
