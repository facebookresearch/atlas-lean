# Partition function of the inhomogeneous random-cluster measure

Let $G = (V, E)$ be a simple graph on a finite set $V$, let $(p_e)$, $e$ ranging over the unordered pairs of elements of $V$, be edge parameters, and $q \in \mathbb{R}$. The partition function is $Z^{\mathbf p}_{G,q} = \sum_\omega w^{\mathbf p}_{G,q}(\omega)$, the sum of the [inhomogeneous weights](fk-weight-w.md) over all configurations.
