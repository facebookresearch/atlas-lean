# Relabelling as a permutation of the configuration space

For a finite set $V$ and a permutation $\sigma$ of $V$, [relabelling](re-cfg.md) $\omega \mapsto \omega^\sigma$, $\omega^\sigma(e) = \omega(\sigma(e))$, is a bijection of the configuration space, with inverse the relabelling by $\sigma^{-1}$.
