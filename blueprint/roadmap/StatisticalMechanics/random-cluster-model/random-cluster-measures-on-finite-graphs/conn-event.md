# Event that two vertices are joined by open edges

Let $G = (V, E)$ be a simple graph on a finite set $V$ and $x, y \in V$. The connection event $\{x \leftrightarrow y\}$ is the set of configurations $\omega$ in which $x$ and $y$ are joined by a path in the [open subgraph](open-sub.md) (edges of $G$ open in $\omega$); when $x = y$ it contains every configuration.
