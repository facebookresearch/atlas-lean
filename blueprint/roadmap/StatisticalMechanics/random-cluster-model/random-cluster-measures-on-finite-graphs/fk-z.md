# Ambient FK normalizer

Let $G = (V, E)$ be a simple graph on a finite set $V$ and $p, q \in \mathbb{R}$. The partition function is $Z_G(p, q) = \sum_\omega w_{G,p,q}(\omega)$, the sum of the [random-cluster weights](fk-weight.md) over all configurations (assignments $\omega$ of open/closed states to all unordered pairs of elements of $V$, loops and non-edges included); each non-edge pair contributes a factor $2$.
