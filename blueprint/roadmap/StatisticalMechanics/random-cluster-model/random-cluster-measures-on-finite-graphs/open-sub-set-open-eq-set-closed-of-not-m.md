# Toggling a non-edge leaves the open subgraph unchanged

Let $G = (V, E)$ be a simple graph on a finite set $V$ and $e$ an unordered pair that is not an edge of $G$. For every configuration $\omega$, the [open subgraphs](open-sub.md) of $\omega^{e,\mathrm{open}}$ and $\omega^{e,\mathrm{closed}}$ coincide.
