# Opening an edge lowers the cluster count by at most one

Let $G = (V, E)$ be a simple graph on a finite set $V$. For every unordered pair $e$ and configuration $\omega$, $k(\omega^{e,\mathrm{closed}}) \le k(\omega^{e,\mathrm{open}}) + 1$, where $k$ is the [number of open clusters](num-clusters.md) and $\omega^{e,\mathrm{open}}$, $\omega^{e,\mathrm{closed}}$ are $\omega$ with $e$ set open, resp. closed.
