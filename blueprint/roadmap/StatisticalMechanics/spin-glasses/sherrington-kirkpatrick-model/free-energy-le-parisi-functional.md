# Guerra's replica-symmetry-breaking bound for the SK model at every system size

For every `β`, every field `h`, all admissible Parisi parameters `k, m, q` and every `N ≥ 1`, the
free energy of the SK model satisfies `F_N ≤ P_k(m, q)`, where `P_k` is the Parisi functional for
`ξ(x) = β² x² / 2`.

## Sources

- F. Guerra, *Broken replica symmetry bounds in the mean field spin glass model*, Comm. Math. Phys. 233 (2003), 1–12; arXiv:cond-mat/0205123, Section 4, Theorem 3 (its first bound, for a piecewise constant functional order parameter; the source writes the field term as `βh ∑_i σ_i`).
