# Admissible Parisi parameters

An integer $k$ and real sequences $m = (m_\ell)_{\ell \in \mathbb{N}}$ and $q = (q_\ell)_{\ell \in \mathbb{N}}$
are admissible Parisi parameters when $k \ge 1$,

$$0 = m_0 \le m_1 \le \dots \le m_{k-1} \le m_k = 1 \quad\text{and}\quad 0 = q_0 \le q_1 \le \dots \le q_k \le q_{k+1} = 1$$

(Talagrand, *The Parisi formula*, Ann. of Math. 163 (2006), (1.6)–(1.7)); the terms $m_\ell$ for $\ell > k$ and $q_\ell$ for $\ell > k + 1$ play
no role. Such parameters describe a probability measure on $[0, 1]$ charging at most $k$ points, $q_\ell$
with mass $m_\ell - m_{\ell-1}$.
