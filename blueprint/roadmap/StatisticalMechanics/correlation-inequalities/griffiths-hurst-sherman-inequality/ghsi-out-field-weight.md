# Inhomogeneous field weight of the disagreement set

For a finite set $V$, site fields $h \in \mathbb{R}^V$ and configurations $q$ and $a$, with $A_q$ the [agreement set](ghs-lagree-finset.md) of $q$,
the field weight of the disagreement set is $\exp\bigl(\sum_{v \notin A_q} 2h_v \sigma_v(a)\bigr)$.
