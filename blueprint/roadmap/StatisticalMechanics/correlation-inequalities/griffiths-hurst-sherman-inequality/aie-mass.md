# Mass of sub-currents with a given source set

Let $V$ and $\iota$ be finite sets and let each index $i \in \iota$ label an edge with endpoints $\mathrm{ends}(i)$, an unordered pair of elements of $V$ (loops allowed); a current is a finite set of edge indices; the sources of a set $K$ of edge indices are the vertices of odd degree in $K$ (the degree of $x$ counts the edges of $K$ containing $x$). For a current $m$, a real function $\varphi$ on sets of edge indices
and $S \subseteq V$, the mass of $S$ is $\sum \varphi(K)$ over the sub-currents $K \subseteq m$ whose set
of sources is exactly $S$.
