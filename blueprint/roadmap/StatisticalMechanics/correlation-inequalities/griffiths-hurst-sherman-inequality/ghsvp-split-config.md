# Splitting a configuration into a set and its complement

For a finite set $W$ and $S \subseteq W$, restriction to $S$ and to $W \setminus S$ is a bijection between
the spin configurations on $W$ and the pairs of a configuration on $S$ and a configuration on
$W \setminus S$, with inverse the [merging](ghsvp-merge-config.md) of the two.
