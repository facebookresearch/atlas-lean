# Partition function with inhomogeneous couplings and site fields

Let $V$ be a finite set, $E$ a finite set of unordered pairs of elements of $V$ (loops $\{x, x\}$ allowed), $J$ real couplings on the pairs and $h \colon V \to \mathbb{R}$ site fields. The partition function is $Z = \sum_\sigma w(\sigma)$, the sum of the
[Boltzmann weights](w-j.md) over all spin configurations $\sigma$ on $V$.
