# Increasing paths as images of subsets of all nodes

For $n \in \mathbb{N}$ and nodes $j, i \in \{0, \dots, n-1\}$, the set of increasing paths from $j$ to $i$ equals the set of increasing listings of those subsets $S \subseteq \{0, \dots, n-1\}$ that contain $j$ and $i$ and satisfy $j \le k \le i$ for all $k \in S$.
