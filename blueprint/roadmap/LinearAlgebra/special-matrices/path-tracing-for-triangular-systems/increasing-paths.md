# Increasing paths between two nodes

For $n \in \mathbb{N}$ and nodes $j, i \in \{0, \dots, n-1\}$, the increasing paths from $j$ to $i$ form the finite set of lists obtained as follows: for every subset $S$ of the interval $[j, i] = \{k : j \le k \le i\}$ that contains both $j$ and $i$, take the elements of $S$ in increasing order. It is empty when $i < j$ and equals $\{[j]\}$ when $i = j$.
