# Is Nonsingular MMatrix diagonal

Let $\iota$ be a finite index set. A real matrix $V \in \mathbb{R}^{\iota \times \iota}$ is a nonsingular M-matrix if it is a Z-matrix ($V_{ij} \le 0$ for all $i \ne j$) and every complex eigenvalue of $V$ has positive real part, that is, $-V$ is Hurwitz.

If $e \colon \iota \to \mathbb{R}$ satisfies $e_i > 0$ for every $i$, then the diagonal matrix $\operatorname{diag}(e)$ is a nonsingular M-matrix.
