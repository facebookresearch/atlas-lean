# Nu-lambda Pascal matrices

Let $N$ and $n$ be natural numbers with $n > 0$, and let $\nu, \lambda, \beta_0, \dots, \beta_{N-1} \in \mathbb{C}$. An array $S = (S_{i,j})_{i, j \ge 0}$ of complex numbers is a $(\nu, \lambda)$-Pascal matrix of size $2n$ with coefficients $\beta$ when $S_{i,j} = 0$ whenever $i \ge 2n$ or $j \ge 2n$; $S_{i,j} = -S_{j,i}$; $S_{2n-2,\,2n-1} = 1$; $S_{j,\,2n-1} = \sum_{t=0}^{N-1} \beta_t S_{j+t+1,\,2n-1}$ for every $j < 2n - 2$; and $S_{i,j} = \lambda S_{i+1,j+1} + \nu(S_{i+1,j} + S_{i,j+1})$ for all $i, j < 2n - 1$.

## Idea

Pascal's triangle is generated by the rule that each entry is the sum of two neighbours. A $(\nu, \lambda)$-Pascal matrix is a skew-symmetric array of size $2n$ filled by a weighted version of that rule, $S_{i,j} = \lambda S_{i+1,j+1} + \nu(S_{i+1,j} + S_{i,j+1})$, starting from its last column, which is prescribed by a linear recurrence with coefficients $\beta_t$ and the normalization $S_{2n-2,\,2n-1} = 1$. The rule determines the whole array from its last column. The basic facts record the skew-symmetry, the finite support, the corner entry and the two recurrences in the form used in the source.
