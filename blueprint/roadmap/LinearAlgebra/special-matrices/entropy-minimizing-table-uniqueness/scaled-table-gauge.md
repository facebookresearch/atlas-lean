# Scaled table gauge

Let $\iota$ and $\kappa$ be index sets, $K \colon \iota \times \kappa \to \mathbb{R}$, $a \colon \iota \to \mathbb{R}$, $b \colon \kappa \to \mathbb{R}$, and let $c \in \mathbb{R}$ with $c \ne 0$. Rescaling the factors to $(c\,a, b / c)$ leaves the scaled table unchanged: for all $i, j$,

$$(c\, a_i)\, K_{ij}\, \frac{b_j}{c} = a_i K_{ij} b_j.$$

In particular the scaling factors of a scaled table are not unique.
