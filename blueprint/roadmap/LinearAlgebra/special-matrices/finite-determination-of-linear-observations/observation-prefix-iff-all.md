# Observation prefix iff all

Let $K$ be a field and $d_1, d_2 \in \mathbb{N}$ (either may be zero). Let $A_1$ be a $d_1 \times d_1$ matrix and $x_1, c_1 \in K^{d_1}$, and let $A_2$ be a $d_2 \times d_2$ matrix and $x_2, c_2 \in K^{d_2}$, all over $K$. Then

$$c_1^{\top} A_1^n x_1 = c_2^{\top} A_2^n x_2 \quad \text{for all } n < d_1 + d_2$$

if and only if the same equality holds for every $n \in \mathbb{N}$.
