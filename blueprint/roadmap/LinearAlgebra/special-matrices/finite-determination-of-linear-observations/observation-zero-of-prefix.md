# Observation zero of prefix

Let $K$ be a field, $V$ a finite-dimensional vector space over $K$ of dimension $d$, $T : V \to V$ a linear map, $z \in V$ and $\ell : V \to K$ a linear functional. If

$$\ell(T^j z) = 0 \quad \text{for all } 0 \le j < d,$$

then $\ell(T^n z) = 0$ for every $n \in \mathbb{N}$.
