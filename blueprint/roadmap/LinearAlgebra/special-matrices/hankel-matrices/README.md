# Hankel matrices

For $n \in \mathbb{N}$ and a sequence $s : \mathbb{N} \to \alpha$ with values in a set $\alpha$, the $n \times n$ Hankel matrix generated by $s$ has rows and columns indexed by $\{0, \dots, n - 1\}$ and $(i, j)$ entry $s_{i+j}$.

## Idea

A Hankel matrix is constant along its antidiagonals, the mirror image of a Toeplitz matrix. Hankel matrices of moments $s_k = \int x^k\, d\mu$ are positive semidefinite, and the Hamburger moment problem asks which sequences arise in this way. Their determinants, the Hankel determinants, are central in the theory of orthogonal polynomials and continued fractions: for the Catalan numbers they all equal $1$. In combinatorics, many identities are proved by computing Hankel determinants of counting sequences.
