# Scaled Table col sum

Let $m, n \in \mathbb{N}$, $a \in \mathbb{R}^m$, $K \in \mathbb{R}^{m \times n}$, $b \in \mathbb{R}^n$ and $c \in \mathbb{R}^n$, and let $T_{ij} = a_i K_{ij} b_j$ be the scaled table. If for every $j$

$$b_j \sum_i K_{ij} a_i = c_j,$$

then $T$ has column sums $c$: $\sum_i T_{ij} = c_j$ for every $j$.
