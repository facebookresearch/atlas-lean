# The condition number is at least one

In a normed ring with $\|1\| = 1$, every invertible $A$ has $\kappa(A) = \|A\|\,\|A^{-1}\| \ge 1$, since $1 = \|A A^{-1}\| \le \|A\|\,\|A^{-1}\|$ (J. W. Demmel, Math 221 Lecture 3 notes, UC Berkeley, 2024). Orthogonal and unitary matrices have $\kappa_2 = 1$.
