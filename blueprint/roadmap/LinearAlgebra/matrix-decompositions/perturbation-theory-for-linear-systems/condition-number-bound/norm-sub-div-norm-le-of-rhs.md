# Condition number bound, right-hand side perturbed only

If $A$ is an invertible bounded operator on a Banach space, $Ax = b \ne 0$ and $A(x + \delta x) = b + f$, then

$$\frac{\|\delta x\|}{\|x\|} \le \|A\|\,\|A^{-1}\|\,\frac{\|f\|}{\|b\|}.$$

It is the case $E = 0$ of the general bound. For a nonsingular matrix it is sharp: some $b$ and $f$ attain it.
