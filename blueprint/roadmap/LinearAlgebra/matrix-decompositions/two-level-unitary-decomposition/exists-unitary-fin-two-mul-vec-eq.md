# Exists unitary fin two mul Vec eq

For all $c_1, c_2 \in \mathbb{C}$ there is a unitary matrix $V \in U(2)$ with

$$V \begin{pmatrix} c_1 \\ c_2 \end{pmatrix} = \begin{pmatrix} \sqrt{\lvert c_1 \rvert^2 + \lvert c_2 \rvert^2} \\ 0 \end{pmatrix}.$$

Thus $V$ maps the vector to the nonnegative real multiple of the first standard basis vector with the same Euclidean length.
