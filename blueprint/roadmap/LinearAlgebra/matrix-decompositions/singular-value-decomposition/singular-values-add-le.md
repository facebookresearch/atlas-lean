# Upper half of Weyl's inequality for singular values

For linear maps $T, U : E \to F$ between finite-dimensional inner product spaces and every
$k$, $\sigma_k(T + U) \le \sigma_k(T) + \|U\|_2$.

## Informally uses

- Eckart–Young theorem in operator norm: both sides are Eckart–Young distances to maps of rank at most $k$.
