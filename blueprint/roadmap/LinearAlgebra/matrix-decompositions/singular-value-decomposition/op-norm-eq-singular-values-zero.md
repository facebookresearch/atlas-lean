# The spectral norm is the largest singular value

For a linear map $T : E \to F$ between finite-dimensional inner product spaces over
$\mathbb{R}$ or $\mathbb{C}$, the operator norm induced by the inner-product norms is the largest
singular value: $\|T\|_2 = \sigma_0(T)$ (singular values indexed from $0$).

Proof: the case $k = 0$ of the Eckart–Young theorem, the only map of rank $0$ being $0$.
