# Column amplification of a submodule

Let R be a commutative semiring. For an R-submodule U ⊆ R^J and a set D, write U^D for the
submodule of x : J × D → R whose columns xₐ(j) = x(j,a) all belong to U. Equivalently, U^D
consists of D-tuples of elements of U, with their coordinates arranged on J × D.
