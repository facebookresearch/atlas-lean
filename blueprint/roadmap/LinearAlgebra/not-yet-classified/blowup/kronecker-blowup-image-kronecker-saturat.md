# Saturation preserves the image of a blow-up

Let R be a commutative semiring. Let J,D be finite, B ⊆ Mat(I,J;R) and S ⊆ R^(J × D). Write
B^[D] = span{A ⊗ T : A ∈ B, T ∈ Mat(D,D;R)}, B^[D]&#40;S) for its image span, and Sat(S) =
span{(I_J ⊗ T)x : T ∈ Mat(D,D;R), x ∈ S}. Then B^[D]&#40;Sat(S)) = B^[D]&#40;S).
