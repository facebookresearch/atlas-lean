# Schur elimination: reduced system yields a block solution

Let $m, n, p$ be finite index sets, $A \in \mathbb{R}^{m \times n}$, $B \in \mathbb{R}^{m \times p}$, $C \in \mathbb{R}^{p \times n}$ and $D \in \mathbb{R}^{p \times p}$ invertible, and let $S = A - B D^{-1} C$ be the Schur complement of $D$. Let $x \in \mathbb{R}^n$, $u \in \mathbb{R}^m$, $v \in \mathbb{R}^p$. If $S x = u - B D^{-1} v$, then $y = D^{-1}(v - C x)$ satisfies

$$A x + B y = u, \qquad C x + D y = v.$$
