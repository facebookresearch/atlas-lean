# Trace exponential dominates each eigenvalue

For a Hermitian matrix $A$, a real number $\theta$ and each index $i$,

$$e^{\theta \lambda_i(A)} \le \operatorname{tr} e^{\theta A},$$

because $\operatorname{tr} e^{\theta A} = \sum_j e^{\theta\lambda_j(A)}$ is a sum of positive terms.
