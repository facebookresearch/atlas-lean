# Positivity of the trace exponential

For a Hermitian matrix $A$ indexed by a nonempty finite set and a real number $\theta$, $\operatorname{tr} e^{\theta A} > 0$.

## Sources

- J. A. Tropp, An Introduction to Matrix Concentration Inequalities, Found. Trends Mach. Learn. 8 (2015), 1–230, arXiv:1501.01571, §2.1.11 ($e^{A}$ is positive definite).
