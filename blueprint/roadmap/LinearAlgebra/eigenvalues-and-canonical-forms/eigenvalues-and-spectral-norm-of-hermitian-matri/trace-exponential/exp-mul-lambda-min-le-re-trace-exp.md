# Trace exponential dominates the bottom eigenvalue

For a Hermitian matrix $A$ indexed by a nonempty finite set and every real $\theta$,

$$e^{\theta\lambda_{\min}(A)} \le \operatorname{tr} e^{\theta A}.$$

For $\theta < 0$ this is the step behind the lower tail of the matrix Laplace transform method, since then $\theta\lambda_{\min}(A) = \lambda_{\max}(\theta A)$.
