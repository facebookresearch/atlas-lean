# Nonnegativity of the trace exponential

For a Hermitian matrix $A$ and a real number $\theta$, $\operatorname{tr} e^{\theta A} \ge 0$; this version also covers the empty index set.

## Sources

- J. A. Tropp, An Introduction to Matrix Concentration Inequalities, Found. Trends Mach. Learn. 8 (2015), 1–230, arXiv:1501.01571, §2.1.11.
