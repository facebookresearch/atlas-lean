# Tangent space to a fixed-rank matrix locus

Let $K$ be a field and $F$ a matrix over $K$ with finite row index set $\iota$ and column index set $\kappa$. The tangent space at $F$ is the subspace

$$T_F = \{X \in K^{\iota \times \kappa} : u^{\top} X v = 0 \text{ for all } u \in K^{\iota},\ v \in K^{\kappa} \text{ with } u^{\top} F = 0 \text{ and } F v = 0\}.$$

Over $\mathbb{R}$ it is the tangent space at $F$ to the manifold of matrices of rank $\operatorname{rank} F$.
