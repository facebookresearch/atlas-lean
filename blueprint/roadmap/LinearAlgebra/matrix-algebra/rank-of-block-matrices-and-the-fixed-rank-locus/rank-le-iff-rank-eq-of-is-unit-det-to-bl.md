# On a block chart, rank at most k is rank exactly k

Let $K$ be a field, $m$, $p$, $q$ finite index sets, and $M$ a block matrix $\begin{pmatrix} A & B \\ C & D \end{pmatrix}$ over $K$ with rows indexed by $m \sqcup p$ and columns by $m \sqcup q$, whose top-left block $A$ is invertible. Then $\operatorname{rank} M \le |m|$ if and only if $\operatorname{rank} M = |m|$.
