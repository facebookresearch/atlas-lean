# Normal space to a fixed-rank matrix locus

Let $K$ be a field and $F$ a matrix over $K$ with finite row index set $\iota$ and column index set $\kappa$. The normal space at $F$ is the subspace

$$N_F = \{Y \in K^{\iota \times \kappa} : F^{\top} Y = 0 \text{ and } Y F^{\top} = 0\}$$

of matrices whose columns lie in the left kernel of $F$ and whose rows lie in the kernel of $F$.
