# Tangent cone of the rank-at-most-k locus

Let $F$ be a real matrix with finite row and column index sets and rank $k$. The tangent cone at $F$ of the set $\{M : \operatorname{rank} M \le k\}$ (the set of limits of $c_j d_j$ with $c_j$ real scalars, $d_j \to 0$ and $F + d_j$ of rank at most $k$) equals the tangent space $T_F = \{X : u^{\top} X v = 0 \text{ for all } u, v \text{ with } u^{\top} F = 0 \text{ and } F v = 0\}$.
