# Adding a positive semidefinite matrix does not decrease the determinant: $\det B \le \det(A + B)$

For positive semidefinite complex $n \times n$ matrices $A$ and $B$,
$\operatorname{Re} \det B \le \operatorname{Re} \det(A + B)$. Both determinants are nonnegative real numbers,
so this is $\det B \le \det(A + B)$.
