# Matched-filter quotient of the zero signal

Let $\iota$ be a finite index set, $R \in \mathbb{R}^{\iota \times \iota}$ any real matrix and $w \in \mathbb{R}^{\iota}$ nonzero. Then the matched-filter quotient of the zero signal is $0$: $(w^{\top} 0)^2 / (w^{\top} R w) = 0$, using the convention $x / 0 = 0$ when $w^{\top} R w = 0$ (for instance when $R = 0$).
