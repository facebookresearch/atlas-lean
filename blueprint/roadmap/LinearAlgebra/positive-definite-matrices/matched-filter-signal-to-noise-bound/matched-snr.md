# Matched-filter signal-to-noise quotient

For a finite index set $\iota$, a real matrix $R \in \mathbb{R}^{\iota \times \iota}$ and vectors $s, w \in \mathbb{R}^{\iota}$, the matched-filter quotient is $\mathrm{SNR}_R(s, w) = (w^{\top} s)^2 / (w^{\top} R w)$, with $x/0 = 0$. When $R$ is the covariance matrix of the noise and the output noise variance $w^{\top} R w$ is positive, it is the output signal-to-noise ratio of the linear filter $w$ for signal $s$.
