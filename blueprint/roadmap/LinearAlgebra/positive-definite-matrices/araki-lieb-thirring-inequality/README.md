# Araki–Lieb–Thirring inequality

The Araki–Lieb–Thirring inequality $\operatorname{tr}(A^{1/2} B A^{1/2})^{rq} \le \operatorname{tr}(A^{r/2} B^r A^{r/2})^q$ for positive semidefinite $A, B$, $q \ge 0$, $r \ge 1$, reversed for $0 \le r \le 1$; its case $q = 1$ is the Lieb–Thirring trace inequality.
