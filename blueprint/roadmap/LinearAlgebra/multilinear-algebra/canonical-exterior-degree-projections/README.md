# Canonical exterior-degree projections

The direct-sum grading of the exterior algebra of a module over a commutative
ring gives a linear projection to each exterior power. These projections
retract homogeneous inclusions, kill the other degrees, and commute with maps
of modules. The grade involution acts on degree `n` by `(-1)^n`.
