# Left partial trace of a density matrix has trace one

Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$, let $m$ and $n$ be finite index sets, and let $A$
be a square matrix over $\mathbb{K}$ with rows and columns indexed by $m \times n$ and
$\operatorname{tr} A = 1$. Then the [partial trace over the first factor](partial-trace-left.md)
also has trace $1$: $\operatorname{tr} \operatorname{tr}_1(A) = 1$. In particular this holds for
every density matrix.
