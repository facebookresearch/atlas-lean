# The two-element lattice is continuous

The two-element lattice $\{\bot < \top\}$, the truth values with false below true, is a continuous lattice. Every element is way below itself, because its principal upper set is Scott-open. This is the simplest instance of Scott's remark that every finite lattice is continuous (D. Scott, *Continuous Lattices*, Oxford PRG-7 (1971), Proposition 2.8). It is also the lattice with which Scott starts his example of the inverse-limit construction (end of §4), and it shows that the hypothesis of the [inverse-limit theorem](../scott-s-inverse-limit-theorem.md) can be met by a lattice with two distinct elements.
