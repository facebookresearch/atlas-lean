# Continuous lattice

A complete lattice $D$ is a continuous lattice when every element is the supremum of the elements way below it: $y = \bigsqcup \{x \mid x \ll y\}$ for all $y \in D$ (D. Scott, *Continuous Lattices*, Oxford PRG-7 (1971), Definition 2.3).
