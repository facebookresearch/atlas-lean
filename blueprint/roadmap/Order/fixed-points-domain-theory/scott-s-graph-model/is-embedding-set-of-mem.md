# Scott's embedding map

Let $X$ be a $T_0$ space whose topology is generated by open sets $U_0, U_1, \ldots$. Then the map

$$e(x) = \{n \mid x \in U_n\}$$

is a topological embedding of $X$ into $P(\omega)$ with its Scott topology (D. Scott, *Data types as lattices*, SIAM J. Comput. 5(3) (1976), Theorem 1.6, where the $U_n$ form a countable basis; here they need only generate the topology). The $T_0$ hypothesis makes $e$ injective. $e$ is continuous because $\{x \mid n \in e(x)\} = U_n$ is open. $e$ is an embedding because $U_n$ is the preimage of the Scott-open set $\{z \mid n \in z\}$. These are the steps of Scott's proof (Appendix A).
