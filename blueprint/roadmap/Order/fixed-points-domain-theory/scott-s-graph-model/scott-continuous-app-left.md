# Application in `P(ω)` is Scott-continuous in the function

For every $x \subseteq \mathbb{N}$, the map $u \mapsto \operatorname{app}(u, x)$ preserves all unions, in particular directed ones, so it is Scott-continuous. Scott remarks that application is even distributive in $u$ (D. Scott, *Data types as lattices*, SIAM J. Comput. 5(3) (1976), 522–587, Appendix A, on equation (2.9)).
