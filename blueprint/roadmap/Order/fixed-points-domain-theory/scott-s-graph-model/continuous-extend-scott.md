# Scott's extension is continuous

For every map $f : X \to P(\omega)$ on a subset $X$ of a topological space $Y$, whether continuous or not, Scott's extension $\bar f : Y \to P(\omega)$ is continuous for the Scott topology. Scott notes this explicitly: $\bar f$ is continuous "no matter what function $f$ is given" (D. Scott, *Data types as lattices*, SIAM J. Comput. 5(3) (1976), Appendix A, proof of Theorem 1.5). His proof shows that each set $\{y \mid m \in \bar f(y)\}$ is a union of open sets.
