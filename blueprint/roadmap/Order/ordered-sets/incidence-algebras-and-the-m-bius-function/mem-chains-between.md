# Membership in the chains between two elements

A map $f \colon \{0, \dots, i\} \to P$ is a chain of length $i$ from $a$ to $b$ exactly when it is
strictly increasing with $f(0) = a$ and $f(i) = b$. That its values lie in $[a, b]$, which the
definition requires in order to make the set finite, is automatic.
