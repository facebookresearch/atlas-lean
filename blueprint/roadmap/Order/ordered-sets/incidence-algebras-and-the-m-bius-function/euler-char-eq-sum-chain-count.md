# Philip Hall's theorem for a bounded poset

If $\hat P$ is a locally finite poset with a least element $\hat 0$ and a greatest element $\hat 1$
(hence finite), then

$$\mu(\hat 0, \hat 1) = c_0 - c_1 + c_2 - \cdots,$$

where $c_i$ is the number of chains $\hat 0 = t_0 < \cdots < t_i = \hat 1$. This is Stanley's
statement verbatim.

## Sources

- R. P. Stanley, *Enumerative Combinatorics*, vol. 1, 2nd ed., author's draft of 15 July 2011, https://math.mit.edu/~rstan/ec/ec1.pdf, Proposition 3.8.5.
