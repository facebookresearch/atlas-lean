# Number of chains of length $i$ between two elements

$c_i(a, b)$ is the number of chains $a = t_0 < t_1 < \cdots < t_i = b$ of length $i$ in a locally
finite poset.

## Background

- [Chains of length $i$ between two elements](chains-between.md): the finite set that $c_i(a, b)$
  counts.

## Sources

- R. P. Stanley, *Enumerative Combinatorics*, vol. 1, 2nd ed., author's draft of 15 July 2011, https://math.mit.edu/~rstan/ec/ec1.pdf, Proposition 3.8.5, there for $a = \hat 0$ and $b = \hat 1$.
