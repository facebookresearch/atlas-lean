# ATLAS

A map of the archived ATLAS v1 targets and the root ATLAS v2 libraries. The
standalone developments under `Atlas/` remain outside the roadmap and its
progress percentages until their `MAPPED` coverage rows are decomposed. Each
subject leads with the ATLAS v2 libraries: every documented public MathlibExt,
CSLibExt and WantedExt declaration is an article whose statement is its
docstring. The 26 textbooks
formalized by the archived ATLAS v1 release follow as source tracks, one article
per statement v1 selected from each book. All pages are generated by
`scripts/generate_wiki.py`; edit the generator, not the pages.

- [Roadmap](roadmap/README.md): subjects, books, chapters, and statements,
  with the dependencies between statements.
- [Coverage](coverage/README.md): which parts of the repository the roadmap
  covers, and which it does not yet.
