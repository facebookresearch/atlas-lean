# Proposition (Espérance de $g(X)$ (cas général))

CDIS id 48. For a real random variable X and a Borel function g, g(X) is integrable iff ∫ |g(x)| P_X(dx) < ∞, and then E(g(X)) = ∫ g(x) P_X(dx).
