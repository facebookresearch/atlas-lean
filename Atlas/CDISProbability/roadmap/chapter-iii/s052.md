# Proposition (Proposition)

CDIS id 52. If (X, Y) has a density, then for every g with g(X, Y) integrable, E(g(X, Y)) = ∫ (∫ g(x, y) f_{Y|X=x}(y) dy) f_X(x) dx; in particular P(X ∈ B_1, Y ∈ B_2) = ∫_{B_1} (∫_{B_2} f_{Y|X=x}(y) dy) f_X(x) dx.

Note: proved for every measurable g with g(X, Y) integrable, as in the course, and separately for nonnegative g with values in [0, ∞] (lintegral), which needs no integrability.
