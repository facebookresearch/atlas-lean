# Proposition (Densité conditionnelle)

CDIS id 51. If (X, Y) has density f_{X,Y} and 0 < f_X(x) < ∞, then y ↦ f_{X,Y}(x, y) / f_X(x) is a density on ℝ, the conditional density f_{Y|X=x} of Y given X = x. For P_X-almost every x, the conditional law of Y given X = x is f_{Y|X=x}(y) dy.

Note: the course only asks f_X(x) > 0. Finiteness is needed too: changing f_{X,Y} on a null line can make f_X(x) = ∞ at one point, and then the ratio is 0. The density statement holds at every such x, while the conditional law is only defined up to a P_X-null set, so that statement is almost everywhere.
