# Proposition (Densité conditionnelle)

CDIS id 51. If (X, Y) has density f_{X,Y} and f_X(x) > 0, then y ↦ f_{X,Y}(x, y) / f_X(x) is a density on ℝ, the conditional density f_{Y|X=x} of Y given X = x, and the conditional law of Y given X = x is f_{Y|X=x}(y) dy.

Note: only CausalSmith has conditional densities, for finite causal DAGs.
