# Definition (Espérance conditionnelle)

CDIS id 56. For Y ∈ L¹, E(Y | X = x) = ∫ y P_{Y|X=x}(dy), and E(Y | X) is the random variable ψ(X) where ψ(x) = E(Y | X = x).
