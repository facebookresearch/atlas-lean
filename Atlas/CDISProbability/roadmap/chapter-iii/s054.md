# Proposition (Formule de balayage conditionnel)

CDIS id 54. P_Y(B) = ∫ P_{Y|X=x}(B) P_X(dx) for every Borel B. If X is discrete, P(Y ∈ B) = Σ_x P(Y ∈ B | X = x) P(X = x). If (X, Y) has a density, f_Y(y) = ∫ f_{Y|X=x}(y) f_X(x) dx, and f_{X|Y=y}(x) = f_{Y|X=x}(y) f_X(x) / f_Y(y) when f_X(x) > 0 and f_Y(y) > 0 (Bayes formula for densities).

Note: density formula holds for almost every y (densities are a.e. objects).
