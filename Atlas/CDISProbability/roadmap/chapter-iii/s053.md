# Theorem (Fubini conditionnel)

CDIS id 53. Conditional Fubini: for real random variables X, Y there is a family of probabilities (P_{Y|X=x}) on ℝ, unique for P_X-almost every x, with P(X ∈ B_1, Y ∈ B_2) = ∫_{B_1} P_{Y|X=x}(B_2) P_X(dx) for all Borel B_1, B_2; moreover E(g(X, Y)) = ∫ (∫ g(x, y) P_{Y|X=x}(dy)) P_X(dx) whenever g(X, Y) is integrable.
