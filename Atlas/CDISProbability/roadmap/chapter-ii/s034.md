# Proposition (Inégalité de Cauchy-Schwarz)

CDIS id 34. For square-integrable X, Y, |E(XY)| ≤ E(|XY|) ≤ √(E(X²) E(Y²)), with equality if and only if X and Y are almost surely proportional.

Note: the equality case is that of |E(XY)| = √(E(X²) E(Y²)), which Mathlib does not state for random variables; it is proved in L² from norm_inner_eq_norm_tfae.
