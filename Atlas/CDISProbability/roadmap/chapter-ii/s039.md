# Definition (Vecteur espérance et covariance)

CDIS id 39. For a random vector X = (X_1, ..., X_n) with integrable components, E(X) = (E X_1, ..., E X_n); if the components are square integrable, the covariance matrix of X is C_X = (Cov(X_i, X_j))_{i,j}.
