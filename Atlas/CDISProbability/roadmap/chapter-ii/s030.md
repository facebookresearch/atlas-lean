# Proposition (Propriétés de base)

CDIS id 30. L¹ is a vector space and E is linear on it; X ∈ L¹ iff |X| ∈ L¹, and then |E(X)| ≤ E(|X|); if X ≥ 0 and X ∈ L¹ then E(X) ≥ 0; if |X| ≤ b for a constant b, then X ∈ L¹ and E(X) ≤ b.
