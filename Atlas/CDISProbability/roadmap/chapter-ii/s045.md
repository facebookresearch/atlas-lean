# Proposition (Méthode de la fonction muette)

CDIS id 45. If there is a function f such that E(h(X)) = ∫ h(x) f(x) dx for every measurable h with h f integrable, then X has density f.

Note: take h = indicator of a Borel set, then Measure.ext.
