# Definition (Vecteur aléatoire à densité)

CDIS id 36. A random vector X in ℝⁿ has density f if f is nonnegative and integrable with ∫ f = 1 and P(X_1 ≤ x_1, ..., X_n ≤ x_n) = ∫_{-∞}^{x_1} ... ∫_{-∞}^{x_n} f for all x.
