# Proposition (Espérance de $g(X)$)

CDIS id 35. If X has density f and g is measurable from ℝ to ℝ, then g(X) is integrable iff ∫ |g(x)| f(x) dx < ∞, and then E(g(X)) = ∫ g(x) f(x) dx.
