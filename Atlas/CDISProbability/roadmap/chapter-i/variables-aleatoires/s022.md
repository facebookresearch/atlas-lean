# Proposition (Conséquences)

CDIS id 22. For real random variables X, Y and (X_n): X + Y, XY and X / Y (where Y ≠ 0) are random variables; finite and countable suprema and infima of the X_n are random variables; a pointwise limit of the X_n is a random variable; 1_A is a random variable iff A is an event.
