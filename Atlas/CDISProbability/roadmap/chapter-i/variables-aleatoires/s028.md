# Proposition (Fonction de répartition d'une variable aléatoire à densité)

CDIS id 28. Let X have density f and distribution function F. (1) F is continuous, so P(X = x) = 0 for every x. (2) F is differentiable at every point where f is continuous, with F′ = f there. (3) Conversely, if F is continuous and piecewise continuously differentiable, then X has density F′.

Note: converse proved for F continuous and differentiable off a countable set, which covers the course's piecewise case.
