# Proposition (Loi d'une variable aléatoire)

CDIS id 15. If X is a map from (Ω, A, P) to a set E with a σ-algebra E such that X⁻¹(B) ∈ A for B ∈ E: (a) the sets B ⊆ E with X⁻¹(B) ∈ A form a σ-algebra; (b) P_X(B) = P(X⁻¹(B)) defines a probability on (E, E), the law of X.
