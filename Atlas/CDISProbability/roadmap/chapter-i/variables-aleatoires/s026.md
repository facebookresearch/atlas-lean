# Definition (Densité de probabilité)

CDIS id 26. A density is a nonnegative integrable function f on ℝ with ∫ f = 1. If f is a density, F(x) = ∫_{-∞}^{x} f is the distribution function of a probability on ℝ.

Note: withDensity is a probability; deps 25.
