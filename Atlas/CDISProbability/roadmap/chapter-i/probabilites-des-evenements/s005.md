# Proposition (Propriétés élémentaires)

CDIS id 5. For events A, B and A_1, ..., A_n: (1) P(A) ∈ [0,1] and P(Aᶜ) = 1 - P(A); (2) A ⊆ B implies P(A) ≤ P(B); (3) P(A ∪ B) = P(A) + P(B) - P(A ∩ B); (4) P(⋃ A_i) ≤ Σ P(A_i) (Boole); (5) P(⋃ A_i) = Σ_{k=1}^{n} (-1)^{k+1} Σ_{i_1<...<i_k} P(A_{i_1} ∩ ... ∩ A_{i_k}) (Poincaré).
