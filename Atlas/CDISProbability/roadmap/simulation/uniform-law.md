# Uniform law on a Borel set

CDIS id 95. The uniform law on `A` with `0 < ℓ(A) < ∞` has density `1_A / ℓ(A)`.
 Mathlib: `MeasureTheory.pdf.IsUniform` (the law is `ℓ` conditioned on `A`).
