# Theorem (Inégalité de Markov)

CDIS id 62. Markov: for p ∈ ℕ*, a > 0 and X ∈ Lᵖ, P(|X| ≥ a) ≤ E(|X|ᵖ) / aᵖ.

Note: erratum. The course writes a ∈ ℝ*, and the bound is false for a < 0 (CDIS.not_markov_of_neg); it is proved for a > 0 (CDIS.markov_abs_pow).
