# Corollary (Inégalité de Bienaymé-Chebyshev)

CDIS id 63. Bienaymé-Chebyshev: for X ∈ L² and a > 0, P(|X - E X| > a) ≤ Var(X) / a².

Note: erratum. The course does not quantify a, and the bound is false for a < 0 (CDIS.not_chebyshev_of_neg); it is proved for a > 0 (CDIS.chebyshev_abs_sub).
