# Corollary (Inégalité de Bienaymé-Chebyshev)

CDIS id 63. Bienaymé-Chebyshev: for X ∈ L² and a > 0, P(|X - E X| > a) ≤ Var(X) / a². [fix: the course does not quantify a; the bound is false for a < 0]

Note: ERRATUM: a is not quantified in the course; false for a < 0 (counterexample proved). The positive case is left to Paul.
