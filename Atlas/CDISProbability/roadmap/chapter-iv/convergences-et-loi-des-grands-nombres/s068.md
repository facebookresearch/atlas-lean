# Definition (Modes de convergences)

CDIS id 68. X_n converges to X almost surely if P(X_n → X) = 1; in probability if P(|X_n - X| > ε) → 0 for every ε > 0; in Lᵖ if X_n and X are in Lᵖ and E(|X_n - X|ᵖ) → 0 (p = 1 is convergence in mean).
