# Definition (Modes de convergences)

CDIS id 68. X_n converges to X almost surely if P(X_n → X) = 1; in probability if P(|X_n - X| > ε) → 0 for every ε > 0; in Lᵖ if E(|X_n - X|ᵖ) → 0.
