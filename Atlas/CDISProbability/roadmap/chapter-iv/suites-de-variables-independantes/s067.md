# Lemma (Borel-Cantelli)

CDIS id 67. Borel-Cantelli: if Σ P(A_n) < ∞ then P(limsup A_n) = 0; if Σ P(A_n) = ∞ and the A_n are independent then P(limsup A_n) = 1.
