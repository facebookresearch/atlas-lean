# Theorem (de Lévy)

CDIS id 90. Lévy: (1) if X_n converges in law to X then φ_{X_n} → φ_X pointwise; (2) if φ_{X_n} converges pointwise to a function φ continuous at 0, then φ is the characteristic function of a random vector X and X_n converges in law to X.

Note: part 2 (limit continuous at 0 is a charFun) is not stated in Mathlib; proved here from Prokhorov.
