# Theorem (central limite multi-dimensionnel)

CDIS id 80. If the X_n are i.i.d. random vectors in ℝ^d, square integrable, with mean m and covariance matrix C, then (S_n - n m) / √n converges in law to a centered Gaussian vector with covariance matrix C.

Note: Cramér-Wold + 1D CLT; limit is Mathlib's multivariateGaussian 0 C with C the covariance matrix of id 39.
